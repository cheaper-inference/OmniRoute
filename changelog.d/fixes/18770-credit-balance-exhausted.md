- **fix(openai):** a 429 whose body carries only `error.code: credit_balance_exhausted` is now classified as terminal credit exhaustion instead of a retryable rate limit. That is the code OpenAI returns once an eligible ChatGPT Pro or Business subscription's monthly API grant is spent, and it cannot clear until someone buys credits — so the account is parked instead of being re-selected on a short backoff on every request.
