- **fix(media):** stored video and media files are now capped at 2 GiB in total. When a new file pushes the folder past the cap, the oldest files are removed first. The file just written always stays, so a single file larger than 2 GiB can keep the folder over the cap. Before, only age (7 days) limited the folder, so a burst of video jobs could fill the disk.
