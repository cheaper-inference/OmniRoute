- **fix(quota):** quota-share combos now take the model-scoped weekly windows of Claude accounts into account when ordering targets. The per-model check never ran. The usage reader looked for model windows in the wrong map, and the ordering looked them up under the combo's virtual model name. An account whose weekly window for the requested model is exhausted is now tried last. Credential selection's rule decides when the window is exhausted. The account stays in the list as a fallback. Requests for other models on that account are not affected ([#20816](https://github.com/cheaper-inference/OmniRoute/pull/20816)).
