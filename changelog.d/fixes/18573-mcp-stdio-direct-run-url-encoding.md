- **fix(mcp):** `omniroute --mcp` (and `node open-sse/mcp-server/server.ts`) no longer exits silently with code 0 when the install path contains a space, `%`, `#` or a non-ASCII character, for example `C:\Program Files\…` or `~/Library/Application Support/…`. The "run directly" check compared the percent-encoded `import.meta.url` with the raw `process.argv[1]`, so the stdio transport never started and MCP clients saw a server that never answered `initialize`. It now compares `import.meta.url` with `pathToFileURL(process.argv[1]).href`.
