- **fix(sse):** `OMNI_MAX_CONCURRENT_CONNECTIONS` now counts the requests that are in flight. It counted sticky-routing sessions, which outlive their request by `OMNIROUTE_SESSION_TTL_MIN`, so a few finished requests filled the cap and the next one got `429 Server busy` with no stream open. A request aborted before its response exists frees its slot at once ([#21163](https://github.com/cheaper-inference/OmniRoute/pull/21163)).
