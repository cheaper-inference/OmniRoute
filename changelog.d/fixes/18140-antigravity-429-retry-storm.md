- **fix(antigravity):** a request Cloud Code refuses with a hintless `429 Resource has been exhausted (e.g. check quota)` no longer turns into dozens of upstream calls. The refusal was multiplied by three layers — the executor's 4 tries per host on every host, the chat handler's cooldown-aware retry restarting the whole request (and re-running the quota preflight each time), and the client re-sending the body. Now the executor spends a per-request budget of upstream 429s across all hosts (`ANTIGRAVITY_MAX_429_ATTEMPTS`, default 2, 1–12) and returns the 429, the chat handler does not restart an `agy`/`antigravity` request after it, and an identical re-send of a body that spent the budget is answered locally (429 + `Retry-After`, zero upstream calls) for the upstream hint, else 2 min doubling to 30 min. The local answer is a verdict on that request, so it does not cool the connection down, mark it quota-exhausted, or trip the provider breaker (#18140).
