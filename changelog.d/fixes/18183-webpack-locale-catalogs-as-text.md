- **fix(build):** webpack builds bundle the locale catalogs (`src/i18n/messages/*.json`) as minified text that `src/i18n/request.ts` parses once per locale, instead of as `json` modules. Measured with the persistent webpack cache off (as #18141 sets it), the server compile holds about 1 GB less heap after code generation, and a clean build completes under a 4096 MB heap cap that ran out of heap before; the default caps (6144 MB in Docker, 8192 MB elsewhere) are unchanged ([#18183](https://github.com/diegosouzapw/OmniRoute/pull/18183)) — thanks @HouMinXi
