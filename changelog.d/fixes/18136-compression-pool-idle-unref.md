- **fix(compression):** an idle compression pool worker no longer keeps a short-lived process (a script, the eval runner, a test file) alive for its 60 s idle window. The worker is unref'd when it goes idle and ref'd again before the next job is posted, so a job in flight still holds the process; the idle termination and the server are unchanged ([#18136](https://github.com/diegosouzapw/OmniRoute/pull/18136)) — thanks @HouMinXi
