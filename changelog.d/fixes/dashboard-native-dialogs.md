- **fix(dashboard):** The dashboard no longer opens the browser's native `confirm()` / `alert()` dialogs. The 34 confirmations (API key delete and regenerate, pricing reset, batch cancel and retry, combo and pool deletes, and more) now use the kit `ConfirmModal` through a new `useConfirmDialog()` hook, and the 8 alerts now show as toasts. The action still runs only after Confirm, and Cancel does nothing. A guard test keeps native dialogs out of `src/app` and `src/shared` ([#19066](https://github.com/cheaper-inference/OmniRoute/issues/19066))
