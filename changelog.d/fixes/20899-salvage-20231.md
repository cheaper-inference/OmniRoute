- **fix(models):** `GET /v1/models` no longer lists chat capabilities for image models. Codex image ids such as `cx/gpt-6.1-sol-image` carried vision, tool calling, reasoning, effort tiers and chat token limits, because their id starts with the chat model's id. An image row now reports tool calling and reasoning as off and keeps its own image modalities. Salvaged from [#20231](https://github.com/cheaper-inference/OmniRoute/pull/20231) by @serenity-X.
- **fix(guardrails):** The opt-in credential masker now also masks a value behind a label (`DB_PASSWORD=…`, `AWS_SECRET_ACCESS_KEY=…`, `client_secret: …`, `?api_key=…`) in requests, responses and streams, so a pasted `.env` file or config dump no longer leaks its unprefixed secrets. Values shorter than 12 characters and `${VAR}` references are left alone. Salvaged from [#20231](https://github.com/cheaper-inference/OmniRoute/pull/20231) by @serenity-X.
- **fix(network):** The direct egress dispatcher now sends a request to the connection that holds the fewest running and queued requests, instead of rotating blindly, so a new request no longer waits behind an unrelated long streaming response while other connections are idle. Salvaged from [#20231](https://github.com/cheaper-inference/OmniRoute/pull/20231) by @serenity-X.
- **fix(usage):** Cline free-bucket models (`cline-free/*`) now have a zero price row, so a USD-limited API key no longer fails closed after one request to them. Salvaged from [#20231](https://github.com/cheaper-inference/OmniRoute/pull/20231) by @serenity-X.
- **perf(usage):** the plausibility check for a provider-reported input token count no longer serializes the whole request body when the count is at most 8192 tokens, which is plausible for any body (two serializations per non-streaming success before). Salvaged from [#20231](https://github.com/cheaper-inference/OmniRoute/pull/20231) by @serenity-X.
