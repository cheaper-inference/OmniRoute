- **fix(guardrails):** With PII and credential masking both on, an API token in a request, a non-streaming response or a streamed response is now redacted as one credential. Before, the phone rule masked the digits in its middle and left the rest in clear. The credential masker now runs first, so the visible placeholder for such a key changes from `[API_KEY_REDACTED]` to `[REDACTED:<provider>]` (for example `[REDACTED:openai]`).
