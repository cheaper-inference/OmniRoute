- **fix(sse):** a Qoder queue throttle (`503 upstream_busy`, upstream code `10605`) no longer parks the whole connection. Qoder multiplexes every model behind one connection, and `qoder` was missing from the `hasPerModelQuota()` allowlist, so one queued model put the account into a connection-wide cooldown and every sibling model looked dead until it expired. The queued model now takes the cooldown alone and its siblings stay routable.
