- **fix(translator):** `translateRequest` no longer edits the message objects the caller gives it. A combo shares message objects between its targets, so an earlier target's edits (stripping `reasoning_content` for a non-reasoning model, filling tool call ids and arguments, moving a late tool result) changed what a later target received; a reasoning model that needed the client `reasoning_content` then lost it. The messages and their tool calls are now copied once at entry (about 0.4 ms for a 12 MiB body).
