- Keep the Codex upstream request faithful to what the client sent: native Codex passthrough no longer gets a placeholder `instructions` or an unrequested `reasoning.summary`, translated clients (OpenCode, SDKs) get neutral instructions instead of the Codex CLI persona (removed), and the upstream `session_id` header carries the client's own session instead of the account-wide `workspaceId`, which merged every conversation on an account into one session.
- The Codex WebSocket transport now builds its headers from the client's own headers and body, like the HTTP path, so an opted-in `codexTransport: "websocket"` connection forwards the client's session instead of none.
