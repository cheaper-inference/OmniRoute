- **fix(runtime):** A production process started from a path with a `test` segment (such as `/opt/omniroute-test/`) is no longer taken for a test run, which silently turned off SQLite auto-backup, migrations behaviour, cloud sync, health checks and quota recovery; test mode now comes only from signals the runners set themselves (`NODE_ENV=test`, `VITEST`, `JEST_WORKER_ID`, node:test's `NODE_TEST_CONTEXT`, an exact `--test` flag, or a test-file or runner-binary entry script) ([#19237](https://github.com/cheaper-inference/OmniRoute/pull/19237)) — thanks @aldoeliacim
