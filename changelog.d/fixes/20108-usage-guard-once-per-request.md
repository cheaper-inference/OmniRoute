- **fix(sse):** the usage guard computes the request body size and the input-token estimate once per request instead of on every streamed chunk that carries usage, so an upstream that repeats `usage` (for example with 0 input tokens) on each chunk no longer re-serializes and re-tokenizes a large request per chunk and starves the event loop, and a Responses passthrough stream no longer rebuilds the accounting receipt for every delta ([#20086](https://github.com/cheaper-inference/OmniRoute/issues/20086), [#20480](https://github.com/cheaper-inference/OmniRoute/issues/20480)) — thanks @mmatus3 and @javargasm
