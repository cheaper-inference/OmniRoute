- **fix(models):** stop the context-window reconcile from blocking the event loop — each `auto:discovery` override write bumped the model catalog cache version, so the next model in the same pass rebuilt the whole synced vision-verdict map (every synced catalog, re-parsed). With ~6,300 synced models and ~1,400 discovered windows that differ from the catalog, every pass took ~10.7 s, and since #11016 a pass runs after every synced catalog write. The pass now invalidates once at the end and skips rewriting an override that already holds the discovered window: ~0.5 s for the first pass, ~0.35 s for a pass that changes nothing; `refreshedAt` therefore keeps the time of the last real write instead of moving on every pass ([#17296](https://github.com/diegosouzapw/OmniRoute/pull/17296))
