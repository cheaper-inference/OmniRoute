- **fix(guardrails):** the Vision Bridge auto-router could pick a vision model on a no-auth provider that was disabled via `blockedProviders`; dispatch then refused the provider and the request failed with a misleading `401 provider_not_configured`. Bridge credential checks now treat a blocked no-auth provider as unusable (synthetic and stored-row paths alike, on fresh scans and cached picks; the audio bridge shares this credential gate) and the router skips it before per-model selection, so image requests reroute to an enabled describer. Keyed providers are unaffected: dispatch never consults `blockedProviders` for them.
