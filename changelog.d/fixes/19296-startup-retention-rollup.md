- **fix(compliance):** the boot-time retention pass now rolls usage_history into `daily_usage_summary` and `daily_team_usage_summary` before it deletes the rows. It used to delete them outright, so whatever aged out while the process was down never reached either summary. Rollup and delete use the same whole-day boundary as the periodic `cleanupUsageHistory()` job, so a day is never half rolled up and half deleted, and a rollup that fails or reports errors leaves the rows in place for the next pass instead of dropping them uncounted ([#19296](https://github.com/cheaper-inference/OmniRoute/pull/19296) — thanks @HouMinXi)
