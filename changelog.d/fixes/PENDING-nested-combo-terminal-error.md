- **fix(combo):** when every unit of a nested combo fails, the error message now lists each failed unit's reason (an empty reply rejected by quality validation, an HTTP 500, a pre-dispatch skip) instead of only the last unit's, which was often just "Model X is unavailable". Each reason is collapsed to one line, sanitized and capped at 300 characters; at most 5 units are listed, the rest as `(+N more)`. Status code, headers, quota classification and diagnostics are unchanged.
