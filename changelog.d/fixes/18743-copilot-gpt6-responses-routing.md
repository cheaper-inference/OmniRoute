- **fix(copilot):** `gpt-6.x` and `gpt-5.5+` ids (and codex ids) on GitHub Copilot and GitHub Enterprise Copilot now go to `/responses` even when a synced catalog row carries no endpoint metadata, instead of failing with HTTP 400 on `/chat/completions`. A synced `gpt-6-*` row that lists no chat endpoint now defaults to Responses (it stayed on Chat Completions since #15337); rows that declare a chat endpoint are unchanged. GitHub Enterprise Copilot also drops `temperature` for the same family and lists the `gpt-6*` models in its static registry (#18743).
