- **fix(sse):** a chat or Responses request whose model is `<namespace>/<name>` with a namespace that is not a known provider (and no exact combo match) crashed with `ReferenceError: getComboByName is not defined` instead of resolving the client-namespaced combo or returning the normal "provider not found" error. The combo read-cache change (#17304) dropped the import while the client-namespaced combo lookup still called it. That lookup now uses the same version-keyed `getCachedComboByName()` reader as the rest of `getCombo()`.
