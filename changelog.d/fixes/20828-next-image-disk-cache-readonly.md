- **fix(build):** The Next.js image optimizer no longer creates a disk cache under `dist/.build/next/cache` on `/_next/image` requests. Images are served unoptimized, so the cache was never used, and on a global npm install run by an account that cannot write the install tree (systemd `ProtectSystem=full`) that `mkdir` failed inside the package ([#20828](https://github.com/cheaper-inference/OmniRoute/pull/20828))
