- **fix(plugins):** a plugin `onRequest` hook that lets a request through unchanged is no longer called again when that request fails over to another account of the same provider and model, so request-counting plugins no longer count a failover twice. A block, a body rewrite (in place or a new body), a new provider or model, or a caller without a headers snapshot still calls the hook again. ([#20372](https://github.com/cheaper-inference/OmniRoute/pull/20372))
