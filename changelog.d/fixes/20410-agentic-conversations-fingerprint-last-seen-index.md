- **fix(db):** Conversation tracking no longer stalls the event loop on large fingerprint buckets. A new migration indexes `agentic_conversations` by `(fingerprint_hash, last_seen_at)`, so the per-request lookup of a bucket's most recent conversations reads them straight from the index instead of sorting the whole bucket (one ~770k-row bucket took ~1.8 s per request and timed out the Docker healthcheck). The single-column fingerprint index it makes redundant is dropped ([#20410](https://github.com/cheaper-inference/OmniRoute/pull/20410)) — thanks @mikney
