- **fix(cursor):** Cursor Grok 4.7 now resolves to its 256k standard window instead of the provider's 200k default (an authoritative provider window, no extra static catalog row). Dropping the `max` effort tier, which Cursor's docs do not list, is opt-in behind the new `CURSOR_GROK_47_DROP_MAX_EFFORT` flag (default off): when on, the `grok-4.7-max` fallback alias leaves the catalog and a `max` request is sent without an effort parameter, while Grok 4.5/4.6 keep their tiers; when off, `max` stays offered and forwarded as before (#17386, [#17388](https://github.com/cheaper-inference/OmniRoute/pull/17388) — thanks @fidelix)
