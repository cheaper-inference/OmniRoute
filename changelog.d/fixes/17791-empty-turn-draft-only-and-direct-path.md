- **fix(sse):** the flush-empty retry loop (`FLUSH_EMPTY_RETRY_ENABLED`, opt-in) now also covers direct, non-translated turns, and a turn whose whole output is draft/system-echo markup (`<summary>`, `<analysis>`, `<system-reminder>`) counts as an empty turn instead of a normal one. The loop used to be armed for translated streams only, so a direct openai→openai turn never reached it, and the draft skeleton a model emits instead of an answer was classified as usable content — the client stripped the tags, was left with an empty turn and killed the stream. The recovery stays opt-in and bounded: the turn is retried on another connection within the existing retry budget, and a turn the judge cannot summarize still passes through unchanged. A block carrying 1000+ characters of content (the Claude Code compaction reply shape, same threshold as the system-preamble stripper) still counts as a real answer and is never retried. Behavior change: a whitespace-only content turn no longer counts as content, so it now falls through to the reasoning-only and zero-valuable-chunk checks (a reasoning-only turn with blank text becomes retryable). With the flag on, the bounded pre-first-byte buffering now also applies to direct streaming paths. ([#17791](https://github.com/diegosouzapw/OmniRoute/pull/17791)) - thanks @skygunner
