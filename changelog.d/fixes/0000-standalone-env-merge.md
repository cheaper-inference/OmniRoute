- **fix(cli):** the standalone launcher (`run-standalone`, Docker) now reads the same `.env` files as `omniroute`: the `DATA_DIR` file first, then the default data directory file, merged key by key (the earlier file wins), and it honours `OMNIROUTE_CLI_SKIP_DEFAULT_DATA_ENV=1`. A key that only the later file supplies used to reach a CLI launch but not a direct standalone launch; the launcher now names such a key on stderr when it takes effect (never the value)
