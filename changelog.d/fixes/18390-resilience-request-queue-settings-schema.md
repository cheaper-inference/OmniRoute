- **fix(resilience):** Settings > Resilience > Request Queue can be saved again. The settings API rejected `requestQueue.globalConcurrentRequests`, which the card always sends, and `waitForCooldown.budgetMs`, which the runtime already reads; both are now accepted within the normalizer bounds (0 to 100000 and 0 to 300000 ms), and the legacy `defaults.globalConcurrentRequests` key is applied instead of being dropped ([#18390](https://github.com/diegosouzapw/OmniRoute/issues/18390))
