- **fix(models):** operator-defined custom models now appear on curated-only providers (CodeBuddy CN/intl, Kimi Web, Z.ai Web, ChatGPT Web). "Curated" only means the provider publishes no upstream model-catalog endpoint, so the dashboard already hid "Import Models" and skipped every synced-catalog loop; that flag leaked into the custom-model paths too. A row added through "Add Custom Model" was saved in the database but then dropped by `mergeProviderModelListing` (never shown in _Available Models_), by `GET /api/providers/[id]/models` (never returned to the dashboard) and by `GET /v1/models` (never routable), which made the model impossible to use. Discovery behaviour is unchanged — no sync is attempted for these providers, and only the operator's own rows are kept.
