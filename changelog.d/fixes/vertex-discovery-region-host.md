- **fix(providers):** Vertex model discovery lists Model Garden publishers on the same host the connection's region uses for requests (`aiplatform.eu.rep.googleapis.com` for `eu`), so a project whose org policy pins the EU regional endpoint (`constraints/gcp.restrictEndpointUsage`) can sync its catalog instead of falling back to the cached one; other regions keep the global host. When every publisher list fails, the sync now reports the HTTP status (for example `HTTP 403`) instead of `EMPTY_CATALOG`. `getVertexHost` now lives in `open-sse/config/vertexModels.ts` and is shared by the executor and discovery ([#18790](https://github.com/cheaper-inference/OmniRoute/issues/18790)) — thanks @fabioluissilva
