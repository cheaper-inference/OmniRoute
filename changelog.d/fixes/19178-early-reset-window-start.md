- **fix(usage):** A weekly quota window whose previous reset time is still in the future is no longer dated as starting there. That happens when a window restarts early (a reset the account redeems upstream) and, far more often, when an unused rolling window slides its reset time forward with the clock; the recorded window could start up to a week in the future, so API key usage limits dropped the weekly spend made since. Such a window now starts at the earlier of its observation and its new reset minus a week (the reset itself for an early reset seen by a later poll), and rows recorded by the previous rule are read the same way. Scheduled rollovers and same-reset refills keep their start. (thanks @aldoeliacim)
