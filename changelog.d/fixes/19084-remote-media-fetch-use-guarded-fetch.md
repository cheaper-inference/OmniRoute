- **fix(sse):** result files whose URL comes back in a provider response (Udio, Kie and SYNTX audio; SYNTX, Magnific, Haiper, Ideogram and Leonardo images; SYNTX, Haiper, Leonardo and Runway videos) are now downloaded over HTTPS from public addresses only, with every redirect hop checked, at most 3 redirects and a direct connection pinned to the checked address; on a proxied connection the download stays on the proxy, which resolves the name itself. Before, a bare `fetch()` followed the URL to loopback, private or metadata addresses and returned the body to the caller. Size caps: images 25 MiB, audio 50 MiB, video 100 MiB, all Runway outputs of one task 100 MiB together; SYNTX keeps its 50 MiB limit and its 413. A failed result download returns 502. The AI Horde R2 download follows the same pinning rule. The Gladia and Azure Document Intelligence polls, which carry the API key, now go only to the configured API origin and refuse redirects. A pinned connection that fails at connect time (for example ENETUNREACH) now rejects the request instead of raising an uncaught exception (#19084)
