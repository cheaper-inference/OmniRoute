- **fix(admission):** A request that is small in bytes but heavy in structure (200 or more messages, or 64 or more tools) now takes the same heavyweight admission lease on `/v1/messages`, `/v1/completions`, `/v1/api/chat`, `/v1/providers/{provider}/chat/completions` and the other `withChatAdmission` routes as it already did on `/v1/chat/completions` and `/v1/responses`. Before, only the byte check ran there, so a burst of such requests (a coding agent fanning out) skipped the concurrency bound. A light body is not affected.
