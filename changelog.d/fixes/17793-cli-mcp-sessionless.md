- **fix(cli):** MCP-backed CLI commands (`mcp call`, `combo suggest`, `compression`, `oneproxy`, `resilience`, `skills`) no longer require a `Mcp-Session-Id` after `initialize`, so they keep working against a stateless Streamable HTTP handler: they send `notifications/initialized`, attach the session header only when the server issued one, and `DELETE` the session (tolerating 405) only after the response has been fully read. `tools/call` is never retried, so a slow or failing tool is no longer run twice. `mcp call` now uses the shared client. Its `tools/call` still has no client-side deadline by default, as before; an explicit `--timeout`, else `OMNIROUTE_HTTP_TIMEOUT_MS`, limits the whole call, from sending it until the result (or the last `--stream` frame) has been read, and on expiry it prints `MCP tools/call timed out after <ms>ms`, exits 1 and sends a best-effort `notifications/cancelled` to a sessionful server. `initialize` and `notifications/initialized` use `--timeout`, else `OMNIROUTE_HTTP_TIMEOUT_MS`, else 30 s, per attempt and until the response starts; `initialize` is tried up to 3 times, so a server that never answers fails after about 92 s by default. `--timeout 0` means no client-side deadline, while `OMNIROUTE_HTTP_TIMEOUT_MS=0` counts as unset; values above 2147483647 ms are clamped to that limit instead of aborting after 1 ms, and a `--timeout` or `OMNIROUTE_HTTP_TIMEOUT_MS` value that is not a plain non-negative integer (blank, surrounding whitespace, leading zeros such as `00`, signs, units such as `300ms`, decimals) prints a warning and is ignored; it also honours `--base-url`, `--context` and `--api-key`. Session `DELETE` uses a fixed 3 s timeout; a tool result with `isError` now prints `MCP error: <text>` to stderr and exits 1 (previously stdout, exit 0); `--scope` was never used and now prints a deprecation warning. HTTP failures read `MCP <method> failed: HTTP <status> — <body>` and keep `err.status` (the compression REST fallback on 404/501 is unchanged); JSON-RPC errors keep `err.code`. No `MCP-Protocol-Version` header is sent, and the unused `X-MCP-Scopes` header is removed.
