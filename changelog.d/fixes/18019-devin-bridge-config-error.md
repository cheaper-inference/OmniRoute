- **fix(devin):** an unset `DEVIN_AGENTIC_HOME` now fails the Devin agentic bridge (`dva/...`) with a 503 `devin_bridge_not_configured` error that names the variable, instead of a 500 that read as a temporary server fault; a set but unsafe value keeps `unsafe_devin_home` (also 503). Both are treated as local configuration errors: no connection cooldown, no provider circuit breaker trip, no same-account retry, and no fallback wait before the next combo target ([#18019](https://github.com/diegosouzapw/OmniRoute/issues/18019))
