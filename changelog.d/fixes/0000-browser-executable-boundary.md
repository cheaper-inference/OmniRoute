- **fix(providers):** the ChatGPT Web browser providers no longer launch a caller-chosen executable. Validation of `chatgpt-web-codex` now honours the local-execution permission, so a remote management request (`POST /api/providers/bulk`, the connection test) never makes the host start a browser and gets "needs a request from this machine" instead; and a connection's stored `chromeExecutablePath` may only select a browser the operator configured (`CHROME_PATH`, `CHATGPT_WEB_CODEX_CHROME_PATH`, `CHATGPT_WEB_CHROME_PATH`) or a known Chrome/Chromium install location — any other path is ignored. If you pointed the dashboard at a Chrome in a non-standard location, set one of those variables instead.
