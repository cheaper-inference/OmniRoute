- **fix(ws):** with `REQUIRE_API_KEY=true`, the `/v1/ws` bridge upgraded a socket that carried no API key, or only an invalid `?api_key=`, and only the requests sent over it got `401`. The handshake now needs a valid API key or dashboard session, as on `/v1/responses`, and refuses before upgrading: `401 ws_auth_required` without a credential, `403 ws_auth_invalid` for an invalid query key. The dashboard's plain handshake `GET` is unchanged. ([#18540](https://github.com/cheaper-inference/OmniRoute/pull/18540)) — thanks @HouMinXi
