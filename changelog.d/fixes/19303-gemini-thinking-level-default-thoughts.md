- **fix(translator):** Gemini 3.8 and Gemini 4 (`agy/gemini-4-argon-*`, `vertex/gemini-4-argon`) stream thought summaries by default again, like every other Gemini thinking path (#4170). Before, the thinking-level path only set `includeThoughts` when the client asked, so a long think sent no bytes at all and the stream was cut by the response-start deadline (an 80 s pre-header 504 on Antigravity). Clients can still opt out with `include_thoughts: false` ([#19303](https://github.com/cheaper-inference/OmniRoute/pull/19303)) — thanks @xiaoyaner0201
