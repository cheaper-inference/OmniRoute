- **fix(api):** the Telegram bot (`/api/telegram/update`, webhook and Mini App) can now be limited to specific Telegram users: set `TELEGRAM_USER_ALLOWLIST_ENABLED=true` and list numeric user ids in `TELEGRAM_ALLOWED_USER_IDS` (invalid entries and an unrecognised switch value are reported once at startup); unlisted senders get 403 on the Mini App and their webhook messages are dropped. Off by default, so existing bots keep serving every user (#0000)
