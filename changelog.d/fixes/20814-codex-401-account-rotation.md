- **fix(combo):** A Codex 401 that wraps a revoked or closed session in the generic `invalid_request_error` type (`token_invalidated`, `token_revoked`, or no code at all) now marks that account unavailable and rotates to the next one. It used to be treated as request-scoped, so the dead account was neither excluded nor cooled down and every request kept landing on it and returning its 401 ([#20814](https://github.com/cheaper-inference/OmniRoute/issues/20814)) — thanks @javargasm
