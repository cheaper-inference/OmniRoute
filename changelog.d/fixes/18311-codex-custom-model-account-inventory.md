- **fix(providers):** A custom Codex model that no synced account inventory lists (for example one released after the last sync) no longer fails with `provider_not_configured` while Codex accounts are active. Account inventories now filter Codex accounts only when at least one inventory advertises the requested model, so a model listed by one account still routes only to that account and image models stay exempt ([#18311](https://github.com/diegosouzapw/OmniRoute/issues/18311))
