- **fix(docker):** a published image tag now always holds both `linux/amd64` and `linux/arm64`. The publish workflow checks every flavor in both registries, skips a version only when the mandatory Node and Web images are complete, and publishes the best-effort Bun images all-or-nothing, so a failing Bun build can no longer block the supported images or leave a single-architecture `-bun` tag (#18749).
