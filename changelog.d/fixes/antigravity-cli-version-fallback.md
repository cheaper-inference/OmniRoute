- **fix(antigravity):** the CLI version claimed in the upstream User-Agent now tracks the live release. The fallback constant was pinned at `1.3.4` while the release feed served `1.5.8`, and a failed lookup was neither cached nor logged, so every request on an unreachable feed paid the five-second fetch timeout again and went out reporting a version two minor releases old. A failed lookup is now remembered for 60 seconds, reported once per outage, and re-armed after recovery; `ANTIGRAVITY_CLI_VERSION` / `ANTIGRAVITY_IDE_VERSION` let a deployment pin either version. Same fix covers the synchronous header path used by the CLI fingerprint table, which cannot await the resolver ([#20151](https://github.com/cheaper-inference/OmniRoute/pull/20151))
