- **fix(logging):** The status at the end of a terminal `[STREAM]` line can now be colored by outcome (green `complete`, yellow `client_disconnect`/`aborted`, red `error:`). It is opt-in: on only when stdout is a TTY and `NO_COLOR` is not set, or when `APP_LOG_COLORS=true`; Docker, journald and log collectors keep the plain text, and the log file never carries ANSI codes. Salvaged from [#20290](https://github.com/cheaper-inference/OmniRoute/pull/20290) by @KiaroSama.
