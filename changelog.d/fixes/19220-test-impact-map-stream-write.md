- **perf(ci):** the test-impact map is written entry by entry through a 1 MiB buffer instead of being serialised into one string first. The release map reaches about 502 MiB when serialised whole, which is close to the runtime's maximum string length, so a branch that added a few hundred edges made the Fast Quality Gates job die with `RangeError: Invalid string length` before it could report anything. The output is also compact now, which leaves more room under the limit that remains: `select-impacted-tests.mjs` and `check-forgotten-sibling-tests.mjs` still read the file as one string, so they stop working if it passes 512 MiB.
