- **fix(usage-analytics):** cost panels dropped the API-equivalent value of legacy zero-cost summary rows. A `daily_usage_summary` row with `total_cost = 0` is priced from its token totals, but its tokens were also being summed into the raw token columns, and `computeUsageRowCost` preferred the stored cost over that estimate — so the panel showed `$0` for a period that did have billable tokens. `SUMMARY_COST_COLUMNS` now zeroes `cost_tokens_input`/`cost_tokens_output` when `total_cost > 0` (never price a row twice), `getModelUsageMatrixRows` splits `storedCost` into `aggregatedStoredCost` and `rawStoredCost` (both rolled up additively), and `computeUsageRowCost` returns `aggregatedStoredCost + rawStoredCost + token estimate` instead of early-returning the stored cost.
