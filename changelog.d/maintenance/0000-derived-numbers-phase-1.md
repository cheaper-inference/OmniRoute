- **feat(ci):** derived numbers are resolved at release, not in every PR. `check:docs-counts` gains a `pr` mode for feature PRs (diff against the PR base: it fails only a managed number the PR wrote or a required claim it removed, never a base that moved) and keeps today's strict comparison as the `release` mode; a facts-collection timeout is now an infrastructure error (exit 2) instead of a false drift. New `npm run facts` (every derived number as JSON), the committed snapshot `docs/reference/derived-facts.json` that the README SVG generators read, and `npm run release:refresh-derived [--check]`, which rewrites every derived value in one pass. Release-Green reports the strict view as drift instead of opening a base-red, and a nightly workflow keeps one `chore/derived-refresh` PR with the refreshed values.
