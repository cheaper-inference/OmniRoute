- **ci:** `.github/workflows/ui-kit-sync.yml` checks the Keak CI UI Kit once a day and opens a `chore/ui-kit-sync-<version>` PR against the highest release branch when the kit's `main` moves past the snapshot pinned in `packages/ui-kit/UPSTREAM.md`. It holds during a release freeze and needs the `secrets.UI_KIT_READ_TOKEN` repository secret. `scripts/dev/sync-ui-kit.sh` now also moves the workspace version and its lockfile entry (`scripts/dev/sync-ui-kit-version.mjs`).
