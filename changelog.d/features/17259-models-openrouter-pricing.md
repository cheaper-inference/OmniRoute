- **feat(api):** `GET /v1/models` entries carry an OpenRouter-compatible `pricing` object (`prompt`, `completion`, `input_cache_read`, `input_cache_write` as USD-per-token decimal strings). The existing per-1M numeric fields stay in the same object. Prices come from the pricing table cost accounting uses. Combos are now priced as their first visible target, synthetic variants copy their base model's price, free models read `"0"`, and an unknown price omits the object ([#17259](https://github.com/diegosouzapw/OmniRoute/pull/17259))
