- **feat(dashboard):** the dashboard and the standalone pages (login, status, error, legal, docs) run on the Keak CI UI Kit (KEA-7886), vendored as the `packages/ui-kit` workspace at a pinned upstream commit (`packages/ui-kit/UPSTREAM.md`, byte-identity guarded by `npm run check:ui-kit-snapshot`). The Keak identity replaces the old one — lime accent, self-hosted Inter / Instrument Serif / IBM Plex Mono, kit radius and surfaces, no background grid — and the theme follows the system by default with light and dark from the kit; the accent color presets in Settings › Appearance are retired (an old saved preset is ignored). The shell is the kit's sidebar and header with a Keak product switcher, and the command palette is a kit dialog. `@/shared/components` keeps its public API as adapters over the kit, so screens kept their imports, and every icon is a Lucide glyph through `<Icon>` / `ICON_MAP`. See `docs/architecture/DESIGN_SYSTEM.md`.
