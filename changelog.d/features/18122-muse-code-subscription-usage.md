- **feat(providers):** Muse Code connections show their subscription usage, the 5-hour session window and the weekly allowance, each with its reset time, on the usage page and in quota-aware routing. The figures come from the `response.subscription_usage` event Meta sends at the end of every Muse Code response; OmniRoute keeps the latest one on the connection and passes the stream to the client unchanged ([#18122](https://github.com/cheaper-inference/OmniRoute/pull/18122)) — thanks @aldoeliacim
