- **feat(api):** `POST /v1/systemone` serves typed decision models (System One: `noul` / `choice` / `score` answers with calibrated probabilities, not text) through the connection named by the model prefix, using the same `<gateway>/<provider>/<model>` convention as chat. `typesafe/jev-latest` calls TypeSafe directly with a new `typesafe` API-key provider, `openrouter/typesafe/jev-1.13` goes through the OpenRouter connection, and `ollama-local/<model>` uses a configured local Ollama (0.35 or later). An unqualified id such as `jev-latest` keeps using OpenRouter, and a missing direct connection never falls back to a gateway. The shared request envelope is validated once; backend limits (Ollama candidates, images and body size, native Jev criteria) apply per backend. Requests honor API-key endpoint (`systemone` category), connection and model restrictions on the resolved target; upstream errors are sanitized, 401/403/429/5xx cool down the connection, and a missing local model locks only that model. Cost comes from OpenRouter's `usage.cost` (a reported zero is a known cost), from TypeSafe's published Jev rate, or is zero for a local host; an unpriced model is reported as unknown instead of free (#13987).
- **feat(api):** `GET /v1/systemone/models` lists the decision models of the configured TypeSafe, OpenRouter and Ollama connections as `{ object: "list", data }`, with the gateway-qualified ids `POST /v1/systemone` accepts and each backend's own pricing. It is filtered by the key's provider, connection and model rules, keeps listing healthy backends when one is down (reported in `X-OmniRoute-Catalog-Status`), and returns an error only when every configured backend fails. Decision-only models never appear as chat models, and a chat request to one is rejected before any upstream call (#13987).
- **feat(dashboard):** the Endpoints page shows both System One routes as compact cards with the live model count.

- **Migration:** a vendor model that was reachable only through OpenRouter, such as `typesafe/jev-1.13`, now resolves to the direct TypeSafe provider. Use `openrouter/typesafe/jev-1.13` to keep going through OpenRouter. Unqualified Jev IDs and the legacy `~typesafe/jev-latest` alias retain their OpenRouter destination.
