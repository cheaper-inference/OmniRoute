- **feat(guardrails):** `agent-guard` block mode. With `AGENT_GUARD_MODE=block` (default `off`), requests to the `claude` and `anthropic` providers from a known third-party agent are refused with HTTP 403 (`error.code: client_agent_not_allowed`). `AGENT_GUARD_STRICT=true` also refuses clients that cannot be identified. The decision is made on the provider the request resolved to. It covers provider aliases, bare model ids and combo targets, and cannot be switched off per request. A refusal does not count as a provider failure. Client headers can be forged, so this deters unmodified third-party agents and is not access control ([#20833](https://github.com/cheaper-inference/OmniRoute/pull/20833))
