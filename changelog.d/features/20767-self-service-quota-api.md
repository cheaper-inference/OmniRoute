- **feat(api):** self-service quota API for API key holders, off by default behind the new `QUOTA_SELF_PANEL` feature flag. `GET /v1/me/quota/{provider}` returns the quota-share pools the key is allocated in for that provider, with the key's fair share and consumption per window, the schedule windows and per-model caps it is under, and its expiry. Account bars and per-model windows need the `self:account-quota` scope and a provider the key's settings share, and only cover connections the key may use. A number that cannot be read is reported as unavailable or `null`, never as zero. Pool display names and schedule labels are shown to key holders as the administrator wrote them. The key needs the `self:usage` scope and is read from headers only. New optional `OMNIROUTE_PUBLIC_API_BASE_URL` sets the API origin reported to key holders ([#20767](https://github.com/cheaper-inference/OmniRoute/pull/20767)).
