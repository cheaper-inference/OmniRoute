- **feat(api):** Added System One typed-decision models as a first-class model kind (`decisions`) with a public `POST /v1/systemone` route and an OpenRouter-alpha-compatible `POST /v1/decisions` alias (#13987). The backend is selected by model id: `typesafe/jev-*` or a bare `jev-*` alias routes natively to api.typesafe.ai, `openrouter/<vendor>/<model>` routes to OpenRouter's alpha decisions endpoint using existing gateway credentials, quota preflight, cooldowns, call logs and `X-OmniRoute-*` cost telemetry. Decisions models never appear in chat pickers or combos.
