- **feat(api):** `GET /v1/me/usage?range=1d|7d|30d|90d` returns the usage and cost series of an API key's own requests: totals, one entry per UTC day, per day and model, per provider-and-model pair (the 50 with the most requests) and per provider. Each entry carries the billed cost, where flat-rate subscriptions count $0, next to the list price. The range defaults to `30d`, and `coverage` reports the window and the operator's raw usage-history retention setting. Rows are selected by the calling key's id only, and a built series is reused for 60 seconds per key and range, with at most 64 kept in memory. The route shares the `QUOTA_SELF_PANEL` feature flag, the `self:usage` scope and the header-only authentication of `GET /v1/me/quota/{provider}` ([#20787](https://github.com/cheaper-inference/OmniRoute/pull/20787))
