- **feat(compression):** New opt-in flag `COMPRESSION_CACHE_AUTOMATIC_PREFIX_ESTIMATE` (default off): compression cache stats then count a request to an automatic-prefix-caching provider (OpenAI, Codex, Azure) as an estimated cache hit without `cache_control` markers. The estimate is a cache-eligibility signal, not an observed hit. With the flag off the stats are unchanged ([#17114](https://github.com/diegosouzapw/OmniRoute/pull/17114)) — thanks @aldoeliacim
