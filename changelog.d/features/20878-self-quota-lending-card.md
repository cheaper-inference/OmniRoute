- **feat(dashboard):** the self-service quota page (`/quota/{provider}`) gains a lending card in pools that lend by consent. A key holder sets the percentage of idle share to lend and how long it lasts, then saves. In a pool that does not lend by consent, a stored percentage can be withdrawn. Each refused save is explained on the card, and a failed save never forgets the key by itself ([#20878](https://github.com/cheaper-inference/OmniRoute/pull/20878))
