- **Dots Studio tool-call markup**: `<dots_function_call>` text blocks (structured `<invoke>` or pure JSON) are converted into real tool calls in the Claude stream translator and the OpenAI response sanitizer, accepting both OpenAI-shaped and Anthropic-shaped client tools (including tools declared without a schema). On the Claude stream an unfinished block, or an opener split mid-tag across chunks, is held back until it completes; on the OpenAI leg the scrub covers non-streaming responses only (streamed OpenAI deltas are passed through unchanged) (#18024).
