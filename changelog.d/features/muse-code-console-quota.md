- **feat(providers):** the Muse Code connection form now accepts the Meta developer-console session cookie (`providerSpecificData.museConsoleSession`) plus an optional `museTeamId`, so the live 5-hour and weekly quota that the inference key cannot read can be fetched from the console. The cookie is stored encrypted alongside the other console credentials and stripped from API responses; on edit a blank input keeps the stored value. The `MUSE_CONSOLE_SESSION` env var remains the fallback for the same cookie.
