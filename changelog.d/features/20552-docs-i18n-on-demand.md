- **feat(docs):** npm installs serve translated `/docs` pages again. With no bundled `docs/i18n` tree, the first request for a translated page fetches that one mirror from the installed version's GitHub tag and caches it under `DATA_DIR/cache/docs-i18n/`. The host is pinned, redirects are refused, requests are capped at 5 s and 2 MB, and misses are remembered. Any failure serves the English page. Docker and Electron still bundle the mirrors and never fetch. Set `OMNIROUTE_DOCS_I18N_REMOTE=false` to turn it off ([#20552](https://github.com/cheaper-inference/OmniRoute/pull/20552), part of #20439)
