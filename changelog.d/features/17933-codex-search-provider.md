- **feat(search):** Add `codex-search` (alias `codex_search`) for web/news search through connected Codex (ChatGPT) accounts. A request that names `codex-search` uses it directly; automatic selection is opt-in behind the `CODEX_SEARCH_AUTO_FALLBACK_ENABLED` flag (default off), which keeps configured search providers first and tries Codex before keyless fallbacks while preserving other providers' order, API-key connection scopes and REST provider blocks. Parse bounded SSE responses into source-grounded rows and log upstream tokens/search counts. Search failures only apply an in-memory search-specific backoff, capped at 60 seconds; they never change shared chat-account health. Searches consume subscription quota, use a 60-second default timeout unless explicitly configured otherwise, and treat time/domain constraints as hints. A search-locked account is skipped in favour of another provider rather than another Codex account. ([#17933](https://github.com/cheaper-inference/OmniRoute/pull/17933)) — thanks @xiaoyaner0201
