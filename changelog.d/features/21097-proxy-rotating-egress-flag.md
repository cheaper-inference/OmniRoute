- **feat(db):** a registry proxy can be marked as a rotating endpoint (`rotatingEgress`, off by default): a gateway that hands out a new exit address per connection is no longer set aside for 5–15 minutes after a per-IP quota 429, and it never counts as sharing a refused neighbor's observed address. Every other refusal policy (unreachable, transport, slow, geo-blocked, operator-reported) still applies to it, and marking a member ends a quota set-aside already in force. Edge relays have no egress key and stay unaffected.
