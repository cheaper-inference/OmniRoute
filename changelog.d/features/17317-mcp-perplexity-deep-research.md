- **feat(mcp):** `omniroute_perplexity_research` runs one Perplexity Deep Research report through the active perplexity-web connection named by `connectionId` (any other connection is refused). It is off by default and registered only when `OMNIROUTE_PPLX_RESEARCH_ENABLED=1`; each connection runs one report at a time with a one minute cooldown after a finished report, the remaining Deep Research quota is checked before a run, and the tool sends the same headers as the web executor (shared `buildPplxHeaders`) ([#17317](https://github.com/diegosouzapw/OmniRoute/pull/17317)) — thanks @HouMinXi
