- **feat(oauth):** added **Qoder CN** (`qoder.cn`) as its own provider (`qoder-cn`) instead of repointing the global `qoder` OAuth env vars at the China deployment. It shares the executor and the model catalog with the global entry, so a model added upstream lands on both; only the host, the provider id and the OAuth endpoints differ. Browser OAuth stays env-only (`QODER_CN_OAUTH_*`) — no client credentials are embedded (Hard Rule #11). Existing global `qoder` connections are untouched.
