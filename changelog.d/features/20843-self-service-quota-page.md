- **feat(dashboard):** self-service quota page for API key holders at `/quota/{provider}`, off by default behind the `QUOTA_SELF_PANEL` feature flag. The holder types the key and sees its share of each quota-share pool per window and how full the account is (with the `self:account-quota` scope). The page also shows the per-model limits of each account, notices for a schedule block or a per-model cap, and the key's own usage. A reading the API cannot provide is shown as unavailable with its reason, never as zero. The key is sent only as a request header, kept in `sessionStorage` unless "Remember on this device" is chosen, removed from storage when refused, and can be forgotten in one click. While the flag is off every `/quota/*` path answers 404 ([#20843](https://github.com/cheaper-inference/OmniRoute/pull/20843))
