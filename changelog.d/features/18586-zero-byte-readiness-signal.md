- **feat(sse):** a `STREAM_READINESS_TIMEOUT` now says which failure shape it was: the result carries `anyByteAt` (null = the upstream went fully silent, not one raw byte; an epoch-ms value = transport alive with keepalive bytes but no content event) and the 504 response repeats it in an `X-OmniRoute-Any-Byte-At` header for external tooling. The timeout log line names the shape too. Pure telemetry — no routing or retry decision reads it.
