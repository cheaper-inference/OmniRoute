- **feat(codex):** New opt-in `OMNIROUTE_CODEX_ZSTD_BODY` (off by default): a Codex request body of 4096+ characters is sent with `Content-Encoding: zstd` to cut upload bytes. The upstream support is unverified, so a refusal (415, or a 400/403 that names the encoding) resends the same request uncompressed once and turns zstd off for that origin for an hour. Other errors are never resent. ([#20237](https://github.com/cheaper-inference/OmniRoute/pull/20237))
