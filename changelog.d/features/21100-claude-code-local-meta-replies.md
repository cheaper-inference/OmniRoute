- **feat(sse):** Claude Code helper requests can be answered locally, without a provider call, behind three default-off flags (`claude-cli` client only): bash command-prefix classification (`CLAUDE_CODE_LOCAL_COMMAND_PREFIX_ENABLED`), next-prompt suggestion mode answered empty (`CLAUDE_CODE_LOCAL_SUGGESTION_ENABLED`) and file-path extraction for plain readers, listings and simple `grep` (`CLAUDE_CODE_LOCAL_FILEPATHS_ENABLED`). Detection is strict: a single user turn with no tools for the prefix and file-path requests, the last user message only for suggestion mode, and any compound, globbed or option-bearing command still goes to the provider. With the flags off nothing changes.
