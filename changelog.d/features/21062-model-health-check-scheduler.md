- **feat(providers):** Opt-in scheduled model health check per connection. Models that fail with a hard error are hidden; the scheduler restores only models it hid itself. Rate limits, timeouts, transient errors, quota exhaustion and skipped probes change nothing. Interval set by `MODEL_HEALTH_CHECK_INTERVAL_HOURS` (default 12).
