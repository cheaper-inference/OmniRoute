- **feat(auth):** dashboard OIDC login can now be admitted by a role/group claim in addition to the subject/email allowlist. A new optional `oidcAdmissionClaim` setting (`{ path, values }`, written through `PATCH /api/settings`) is checked against the verified ID token before the dashboard session is minted; it fails closed on a missing, malformed or non-array claim, and when both the subject allowlist and the claim policy are set both must pass. The setting is Zod-validated, rejected when malformed, and counts as a security-impacting key (password re-auth required). A rejected login redirects to `/login?oidc_error=role_not_allowed`. Existing subject-only configurations are unchanged ([#17968](https://github.com/diegosouzapw/OmniRoute/issues/17968))
