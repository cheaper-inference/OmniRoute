- **feat(dashboard):** Oh My Pi gets a CLI Agents card for per-role model selection. Each omp role (default, smol, slow, vision, plan, designer, commit, tiny, task, advisor) is picked from the active OmniRoute models. Apply goes through `/api/cli-tools/omp-settings`, which backs the files up, refuses to overwrite an unparsable one (409) and only adds or removes `modelRoles` values that point at OmniRoute; the card then shows the roles the route read back. The route now writes the key into `~/.omp/agent/models.yml` by env-var name (`OMNIROUTE_API_KEY`) and never returns a stored key.
