- **feat(sse):** a 429 that a provider meters per egress address, received through a connection proxy pool member, can now be re-sent with the same account through another pool member that was not tried yet, before the account is cooled or another account is tried. Opt-in through the `PROXY_REEGRESS_ON_QUOTA_429` feature flag (default off); `PROXY_REEGRESS_MAX_ATTEMPTS` bounds the re-sends per request (default 3, range 1–8). Only pool egress qualifies, only before any response byte reached the client, never on a daily or subscription quota message; a one-member or fully set-aside pool returns the 429 as before
