- **feat(cli):** `OMNIROUTE_STANDALONE_ENV_MERGE_ENABLED=1` makes the standalone launcher (`run-standalone`, `run-next`, Docker) read the same `.env` files as `omniroute`: the `DATA_DIR` file first, then the default data directory file, merged key by key (the earlier file wins). It names each key that only the later file supplies on stderr, never the value. Off by default: the launcher reads the first existing `.env` alone, as before.
