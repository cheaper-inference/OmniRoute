- **feat(oauth):** added a first-party **email + password sign-in** for the `devin-desktop` provider, alongside the existing token import. Devin Auth replaced Windsurf's Firebase login and the resulting `ide_token` is machine-bound, so a new account could no longer obtain one through the browser flow that only yields a paste-able token — users of the provider were left with no way in. The password is sent exactly once, in the login frame only, and a rejected password maps to `401` without leaking the upstream body.
