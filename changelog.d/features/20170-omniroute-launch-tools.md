- **feat(cli):** `omniroute launch <tool>` starts any of 19 coding tools (Claude Code, Codex, OpenCode, Aider, Gemini CLI, Goose, Kilo and more) already wired to OmniRoute, with no configuration. Each launch joins or starts a local gateway, mints a short-lived session token scoped to the parent API key so the tool never sees a provider key, lists only the models of the providers you connected, writes the tool's config to a temp dir through env vars and flags, and on exit prints the session's requests, tokens and cost, then revokes the token. `omniroute launch --list` and `--cleanup` run on the same core, and `omniroute gateway status|keep|stop` manages the shared gateway. Thanks @kkkamur07 ([#20170](https://github.com/cheaper-inference/OmniRoute/pull/20170))
