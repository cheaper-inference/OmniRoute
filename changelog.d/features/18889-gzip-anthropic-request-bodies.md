- **feat(executors):** Gzip request bodies of 4096+ characters sent to the official `api.anthropic.com`, as Claude Code 2.1.3xx does. Long agent sessions re-upload 0.5-10 MB of JSON each turn; it compresses 3-4x (gzip level 3: 3 MB in 27 ms). Skipped behind a proxy, TLS impersonation or `NODE_EXTRA_CA_CERTS`. A refused encoding (415, a non-Anthropic 400/403, or an origin JSON-parse 400) is resent uncompressed once and that origin stays uncompressed for one hour; ordinary API errors are never resent. Opt out with `OMNIROUTE_GZIP_REQUEST_BODIES=0`.
