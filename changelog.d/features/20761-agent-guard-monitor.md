- **feat(guardrails):** new `agent-guard` guardrail in observation mode. With `AGENT_GUARD_MODE=monitor` (default `off`) it logs requests to the `claude` and `anthropic` providers whose client is not Claude Code or an official Anthropic SDK. A known third-party agent is logged at `warn`, an unidentified client at `info`. Only model ids with a provider prefix are observed. It never blocks, and client headers can be forged, so it is observation, not access control ([#20761](https://github.com/cheaper-inference/OmniRoute/pull/20761)).
