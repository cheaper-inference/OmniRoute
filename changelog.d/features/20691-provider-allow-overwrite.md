- **feat(providers):** `POST /api/providers` accepts an optional `allowOverwrite: false`: a name or API key that matches a stored connection answers 409 `PROVIDER_NAME_CONFLICT` (with `existingId`) instead of replacing the stored key, for scripts that import pools or rotate keys. Omitting the field keeps today's update-in-place behaviour. Creating a connection now renumbers priorities in one transaction and skips rows that keep their rank.
