- **feat(auth):** Native Google OAuth 2.0 and GitHub OAuth login for the dashboard. Providers are opt-in per operator and deny-by-default (a non-empty `AUTH_ALLOWED_EMAILS` allowlist is required; `*` is ignored; `googleAuthEnabled`/`githubAuthEnabled: false` switch a provider off), only a verified e-mail authorizes a session, domain entries need the provider's proof of the domain (Google `hd`, GitHub primary e-mail) and never match public mail providers, GitHub accounts can be listed by numeric id (`github:<id>`), the flow uses PKCE (S256), sessions go through the canonical minter (sign-out and password changes end them; allowlist or credential changes end older sessions), every social setting needs password re-auth and is dropped by the JSON import, the callback query and provider responses are schema-validated and fail closed, and the client secrets never leave the instance (settings API, JSON export, config sync). ([#15153](https://github.com/diegosouzapw/OmniRoute/pull/15153))
