- **feat(providers):** a custom model can be marked "Thinking capable" in the add and edit forms (opt-in, off by default). The flag is stored on the model, the API accepts `supportsThinking` on `POST` and `PUT /api/provider-models`, and the capability lookup uses it, so reasoning routing and the thinking-budget logic treat a self-hosted reasoning model as one. Unmarked models are unchanged. ([#20687](https://github.com/cheaper-inference/OmniRoute/pull/20687))
