- **feat(api):** `QUOTA_PANEL_PORT` opens a dedicated port for the self-service quota page. It relays only the page, its two API routes and their aliases, and its build assets. Every other path answers 404, and only GET and HEAD are relayed. The port is off by default and binds to `127.0.0.1` unless `QUOTA_PANEL_HOST` is set ([#20856](https://github.com/cheaper-inference/OmniRoute/pull/20856))
