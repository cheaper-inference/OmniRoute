- **feat(routing):** Opt-in `CLAUDE_CLIENT_ANTHROPIC_ENDPOINT` sends Claude-format clients to a provider's own Anthropic endpoint when it declares one, so the OpenAI hub no longer drops Claude-only fields.
- **feat(routing):** Opt-in `OMNIROUTE_CLAUDE_SESSION_CACHE_KEY` reuses the Claude Code session id as `prompt_cache_key` on OpenAI Chat and Responses targets, so one session keeps one upstream prompt cache.
- **feat(chat):** set `OMNIROUTE_CONTEXT_HEADERS=true` to add `X-OmniRoute-Context-Window` and `X-OmniRoute-Context-Remaining` headers to non-streaming chat responses (off by default).
- **feat(gemini):** the in-memory Gemini thought-signature cache now evicts the least recently used entry, so a signature read on every turn of a long tool loop is no longer dropped by a burst of newer ones.
- **feat(sse):** a 200 stream whose first frame is `{choices: [], error}` (a relay forwarding a dead downstream) now fails the turn before any content, so combo fallback runs, instead of returning an empty 200. Frames after real content are unchanged.
- **feat(chat):** new opt-in `OMNIROUTE_STREAMING_POLICY` sets `allow`, `deny` or `always` streaming per route prefix, so operators can answer SSE-broken clients with a clear 400 or force SSE behind proxies with idle timeouts; unset = no change.
- **feat(combo):** opt-in `OMNIROUTE_TOOL_REJECTION_DEFER=true` tries a combo target last for tool requests after it rejects 3 distinct tool requests with a provider 400 inside 1 h (6 h soft defer, cleared by a served tool request). Off by default.
- **feat(claude):** opt-in `OMNIROUTE_DEDUP_WEB_TOOLS=true` drops the built-in WebSearch and WebFetch tools from a Claude Code request that already carries an Exa or Tavily MCP search/fetch tool (exact names only), so the model sees fewer duplicate tool schemas. Off by default.
