## Κατηγορίες

- **Δωρεάν** — δωρεάν επίπεδο με κλειδί API (διαμορφωμένο μέσω του πίνακα ελέγχου)
- **Όχι-auth** — δημόσια τελικά σημεία που δεν απαιτούν καθόλου κλειδί ή σύνδεση
- **OAuth** Η ροή εισόδου — χειρίζεται το OmniRoute, δεν χρειάζεται κλειδί API
- **Web cookie** — αναδιπλώνει την εφαρμογή web του παρόχου μέσω ταυτότητας cookie
- **κλειδί API** Ο πάροχος επί πληρωμή — διαμορφώθηκε μέσω του κλειδιού API (ενδέχεται να ισχύουν δωρεάν πιστώσεις)
- **Τοπικός** — εκτελείται στον υπολογιστή του χρήστη (Ollama, LM Studio, vLLM, κ.λπ.)
- **Ερευνα** πάροχοι αναζήτησης ιστού —
- **Ήχος** Πάροχοι μόνο ήχου — (TTS/STT)
- **Upstream proxy** παρόχους — που διαβιβάζουν μεσολάβηση σε άλλους παρόχους
- **Cloud agent** Πράκτορες κωδικοποίησης μακράς διάρκειας — (Codex Cloud, Devin, Jules)
- **Σύστημα** — OmniRoute-εσωτερικοί πάροχοι (loopback, κ.λπ.)

Πρόσθετες ετικέτες: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (όπου φαίνεται): `native` — πραγματική κλήση συνάρτησης API; `emulated` — ο πίνακας `tools` προσομοιώνεται με προτροπή μέσω `webTools.ts` (μπλοκ `<tool>{...}</tool>` αναλυμένα με regex). `none` — `tools` αυτή τη στιγμή απορρίπτεται αθόρυβα. Δείτε #7286.

Χρησιμοποιήστε τον πίνακα ελέγχου στο `/dashboard/providers` για να ενεργοποιήσετε, να διαμορφώσετε και να δοκιμάσετε κάθε πάροχο.
