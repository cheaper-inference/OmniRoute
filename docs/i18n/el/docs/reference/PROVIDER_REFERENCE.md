## Κατηγορίες

- **Δωρεάν** — δωρεάν βαθμίδα με κλειδί API (διαμορφώνεται μέσω του πίνακα ελέγχου)
- **Χωρίς έλεγχο ταυτότητας** — δημόσια τελικά σημεία που δεν απαιτούν καθόλου κλειδί ή σύνδεση
- **OAuth** — η ροή σύνδεσης διεκπεραιώνεται από το OmniRoute, χωρίς να απαιτείται κλειδί API
- **Cookie ιστού** — περιβάλλει τη διαδικτυακή εφαρμογή του παρόχου χρησιμοποιώντας έλεγχο ταυτότητας μέσω cookie
- **Κλειδί API** — πάροχος επί πληρωμή που διαμορφώνεται μέσω κλειδιού API (ενδέχεται να παρέχονται δωρεάν πιστώσεις)
- **Τοπικός** — εκτελείται στον υπολογιστή του χρήστη (Ollama, LM Studio, vLLM κ.λπ.)
- **Αναζήτηση** — πάροχοι αναζήτησης στον ιστό
- **Ήχος** — πάροχοι αποκλειστικά για ήχο (TTS/STT)
- **Ανοδικός διακομιστής μεσολάβησης** — πάροχοι που λειτουργούν ως διακομιστές μεσολάβησης προς άλλους παρόχους
- **Πράκτορας cloud** — πράκτορες προγραμματισμού μακράς διάρκειας (Codex Cloud, Devin, Jules)
- **Σύστημα** — εσωτερικοί πάροχοι του OmniRoute (loopback κ.λπ.)

Πρόσθετες ετικέτες: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Κλήση εργαλείων` (όπου εμφανίζεται): `native` — πραγματικό API κλήσης συναρτήσεων· `emulated` — ο πίνακας `tools` προσομοιώνεται μέσω προτροπής από το `webTools.ts` (μπλοκ `<tool>{...}</tool>` που αναλύονται με κανονικές εκφράσεις)· `none` — το `tools` προς το παρόν απορρίπτεται σιωπηρά. Δείτε το #7286.

Χρησιμοποιήστε τον πίνακα ελέγχου στη διεύθυνση `/dashboard/providers` για να ενεργοποιήσετε, να διαμορφώσετε και να δοκιμάσετε κάθε πάροχο.
