> `src/app/api/settings/obsidian/webdav/route.ts` (API ρυθμίσεων). Η καταχώριση εργαλείων
> και η σύνδεση εμβελειών βρίσκονται στο `open-sse/mcp-server/server.ts`.

## Τι είναι

Το OmniRoute συνδέεται σε ένα vault του **Obsidian** ως **πηγή περιβάλλοντος** — μια τοπική
βάση γνώσεων Markdown την οποία οι agents διαβάζουν και επεξεργάζονται μέσω του ενσωματωμένου
διακομιστή MCP. Η ενσωμάτωση επικοινωνεί με το πρόσθετο κοινότητας **Obsidian Local REST API**
που εκτελείται μέσα στην εφαρμογή για υπολογιστές, ώστε οι agents να μπορούν να αναζητούν
σημειώσεις, να διαβάζουν/γράφουν/τροποποιούν αρχεία, να εμφανίζουν τα περιεχόμενα του vault,
να εργάζονται με ημερήσιες/εβδομαδιαίες περιοδικές σημειώσεις, να διαχειρίζονται ετικέτες,
να εκτελούν εντολές του Obsidian και (προαιρετικά) να συντονίζουν έναν αμφίδρομο συγχρονισμό
vault μεταξύ υπολογιστή↔κινητού.

Ο πελάτης (`src/lib/obsidian/api.ts`) περιβάλλει το Local REST API με:

- **Επανάληψη με σταδιακή καθυστέρηση** για προσωρινά σφάλματα `5xx`, **χρονικό όριο 30 δευτερολέπτων** μέσω `AbortController`.
- **Τυποποιημένη ταξινόμηση σφαλμάτων** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`.
- Μια **φιλική υπόδειξη «δεν είναι δυνατή η σύνδεση με το Obsidian»**, η οποία επισημαίνει
  το συνηθισμένο λάθος θύρας (HTTP στη `27123`, **όχι** το endpoint MCP στη `27124`) και τη μορφή Tailscale.
- **Κωδικοποίηση διαδρομών** σχετικών με το vault, ώστε οι διαδρομές σημειώσεων με κενά/καθέτους να είναι ασφαλείς.

## Ρύθμιση

Δεν υπάρχει **μεταβλητή περιβάλλοντος** για το token ή το βασικό URL του Obsidian — και τα δύο
αποθηκεύονται στον πίνακα SQLite `key_value` (namespace `obsidian`) μέσω του
`src/lib/db/obsidian.ts`. Το token είναι **κρυπτογραφημένο κατά την αποθήκευση** (AES-256-GCM, με
εναλλακτική συμβατότητα προς τα πίσω για απλό κείμενο). Διαμορφώστε το από την καρτέλα **Πηγές περιβάλλοντος** του
πίνακα ελέγχου Endpoint (`ObsidianSourceCard`) ή μέσω του REST API ρυθμίσεων.

> [!IMPORTANT]
> Το πρόσθετο **Obsidian Local REST API** πρέπει να είναι εγκατεστημένο και να εκτελείται. Η διεπαφή REST
> ακούει στη διεύθυνση **HTTP `127.0.0.1:27123`** (το προεπιλεγμένο βασικό URL). Η θύρα `27124`
> είναι ένα _ξεχωριστό_ τελικό σημείο MCP/HTTPS και απορρίπτεται ρητά από τη διαδρομή ρυθμίσεων.
> Εάν συνδέεστε από άλλη συσκευή, χρησιμοποιήστε `http://<tailscale-ip>:27123`.

### Κλειδιά διαμόρφωσης (SQLite `key_value`, namespace `obsidian`)

| Κλειδί            | Σκοπός                                                       | Κρυπτογραφημένο |
| ----------------- | ------------------------------------------------------------ | --------------- |
| `api_key`         | Token bearer του Local REST API                              | ναι             |
| `base_url`        | Βασικό URL REST (προεπιλογή `http://127.0.0.1:27123`)        | όχι             |
| `vault_path`      | Απόλυτη διαδρομή προς τον κατάλογο vault (για συγχρονισμό)   | όχι             |
| `webdav_username` | Δημιουργημένο όνομα χρήστη WebDAV (συγχρονισμός vault)       | όχι             |
| `webdav_password` | Δημιουργημένος κωδικός πρόσβασης WebDAV (συγχρονισμός vault) | ναι             |
| `webdav_enabled`  | Εάν είναι ενεργοποιημένος ο συγχρονισμός vault μέσω WebDAV   | όχι             |

### Διαμόρφωση μέσω REST

```bash
# Αποθήκευση + επικύρωση του token του Local REST API (το POST επικυρώνει μέσω ελέγχου κατάστασης)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# Έλεγχος κατάστασης σύνδεσης (επιστρέφει connected, hasToken, baseUrl, vaultPath)
curl http://localhost:20128/api/settings/obsidian

# Αποσύνδεση (διαγράφει το αποθηκευμένο token)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

Όλες οι μέθοδοι απαιτούν έλεγχο ταυτότητας στον πίνακα ελέγχου. Το `POST` απορρίπτει οποιοδήποτε URL στη θύρα `27124`
και επικυρώνει το token καλώντας το τελικό σημείο κατάστασης του Local REST API πριν από την αποθήκευση.

### Συγχρονισμός vault μέσω WebDAV

Το `src/app/api/settings/obsidian/webdav/route.ts` διαχειρίζεται έναν προαιρετικό συγχρονισμό
vault με υποστήριξη WebDAV (ο οποίος εκτελείται από το `src/lib/obsidianSync.ts`). Η ενεργοποίησή του κατευθύνει το OmniRoute σε έναν
τοπικό κατάλογο vault και δημιουργεί ένα τυχαίο ζεύγος ονόματος χρήστη/κωδικού πρόσβασης WebDAV:

```bash
# Ενεργοποίηση συγχρονισμού WebDAV για έναν κατάλογο vault (δημιουργεί όνομα χρήστη/κωδικό πρόσβασης)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# Λήψη κατάστασης συγχρονισμού WebDAV (τα διαπιστευτήρια επιστρέφονται μόνο όσο είναι ενεργοποιημένος)
curl http://localhost:20128/api/settings/obsidian/webdav

# Απενεργοποίηση συγχρονισμού WebDAV (διαγράφει τα διαπιστευτήρια + το διαχειριζόμενο .stignore)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### Ασφάλεια & Μεταφορές

Ο έλεγχος ταυτότητας WebDAV επιβάλλει την παρακολούθηση αποτυχίας ανά IP και το κλείδωμα (10 αποτυχημένες προσπάθειες μέσα σε ένα παράθυρο 60 δευτερολέπτων ενεργοποιούν ένα κλείδωμα 5 λεπτών με `429 Too Many Requests` και `Retry-After`). Επειδή WebDAV μεταδίδει τα βασικά διαπιστευτήρια ελέγχου ταυτότητας, ο τερματισμός TLS (ή η δρομολόγηση μέσω ασφαλούς σήραγγας όπως Tailscale ή Cloudflare Tunnel) συνιστάται ανεπιφύλακτα κατά την πρόσβαση στο τελικό σημείο WebDAV έξω από το loopback.

### Πηγή περιβάλλοντος ανά κλειδί API (προαιρετικά)

Η διαμόρφωση του Obsidian μπορεί να οριστεί **ανά κλειδί API** μέσω του πίνακα `api_key_context_sources`
(`src/lib/db/apiKeyContextSources.ts`). Όταν μια κλήση MCP περιλαμβάνει ένα ταυτοποιημένο αναγνωριστικό κλειδιού API,
η `getObsidianConfigForApiKey()` προτιμά το token/βασικό URL/διαδρομή vault του συγκεκριμένου κλειδιού
(`source: "api_key"`) και διαφορετικά επιστρέφει στην καθολική διαμόρφωση (`source: "global"`).

Τα εργαλεία MCP που δεν αφορούν συγχρονισμό απαιτούν μια προσδιορισμένη ταυτότητα καλούντος πριν από την ανάγνωση αυτής της διαμόρφωσης.
Ένας καλών χωρίς ταυτότητα λαμβάνει `Obsidian API token not configured` και δεν αποστέλλεται κανένα αίτημα προς το vault.
Οι καλούντες HTTP προσδιορίζονται μέσω των διαπιστευτηρίων του αιτήματός τους· οι καλούντες stdio
μπορούν να προσδιοριστούν μέσω του `OMNIROUTE_API_KEY` ή του `ROUTER_API_KEY`. Ένας μη προσδιορισμένος καλών HTTP
δεν μπορεί να κληρονομήσει την ταυτότητα περιβάλλοντος του διακομιστή. Τα αναγνωριστικά κράτησης θέσης από μόνα τους δεν εξουσιοδοτούν
την πρόσβαση· εξακολουθεί να υποστηρίζεται ένα έγκυρο διαπιστευτήριο περιβάλλοντος που αντιστοιχεί σε `env-key`.
Τα ταυτοποιημένα κλειδιά χωρίς διαμόρφωση Obsidian ανά κλειδί διατηρούν την καθολική εναλλακτική.
Τα τέσσερα εργαλεία `obsidian_sync_*` διατηρούν τη δική τους ξεχωριστή συμπεριφορά token συγχρονισμού.

## εργαλεία MCP (22)

Ορίζεται σε `open-sse/mcp-server/tools/obsidianTools.ts`. Το token/base-URL επιλύεται ανά κλήση (πρώτα ανά κλειδί API και μετά καθολικό). Εργαλεία που χτυπούν το OmniRoute** διακομιστή συγχρονισμού** (τα τέσσερα εργαλεία `obsidian_sync_*` ) απαιτούν επιπλέον το διακριτικό ελέγχου ταυτότητας συγχρονισμού που έχει διαμορφωθεί στις ρυθμίσεις OmniRoute.

### Εργαλεία ανάγνωσης (`read:obsidian`)

| Εργαλείο                     | Περιγραφή                                                                                                                         |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `obsidian_check_status`      | Ελέγξτε εάν το Τοπικό REST API είναι προσβάσιμο και πιστοποιημένο.                                                                |
| `obsidian_search_simple`     | Αναζήτηση σε πλήρες κείμενο περιεχομένου σημειώσεων. επιστρέφει αποσπάσματα με διαδρομές αρχείων.                                 |
| `obsidian_search_structured` | Αναζήτηση χρησιμοποιώντας μια έκφραση JSON Logic ( φίλτρα and/or/regex/path ).                                                    |
| `obsidian_read_note`         | Διαβάστε μια σημείωση ανά διαδρομή που σχετίζεται με το θησαυροφυλάκιο. προαιρετικά ένα συγκεκριμένο heading/block/frontmatter.   |
| `obsidian_list_vault`        | Λίστα αρχείων και καταλόγων στο θησαυροφυλάκιο (δέντρο καταχωρήσεων).                                                             |
| `obsidian_get_document_map`  | Λάβετε τη δομή επικεφαλίδων της σημείωσης ως χάρτη με αριθμούς γραμμών επικεφαλίδων →.                                            |
| `obsidian_get_note_metadata` | Λάβετε πρωτοποριακά στοιχεία, ετικέτες, συνδέσμους, πλήθος char/word χωρίς το πλήρες περιεχόμενο.                                 |
| `obsidian_get_active_file`   | Λάβετε το περιεχόμενο της διαδρομής + του τρέχοντος ενεργού αρχείου στο Obsidian.                                                 |
| `obsidian_get_periodic_note` | Λάβετε την περιοδική σημείωση daily/weekly/monthly για μια ημερομηνία (σήμερα εάν παραλειφθεί).                                   |
| `obsidian_get_tags`          | Καταχωρίστε όλες τις ετικέτες vault με τις συχνότητές τους.                                                                       |
| `obsidian_list_commands`     | Καταχωρίστε τη διαθέσιμη εντολή Obsidian IDs (χρήση με `obsidian_execute_command`).                                               |
| `obsidian_sync_status`       | Κατάσταση διακομιστή συγχρονισμού OmniRoute : εκτέλεση, όνομα θησαυροφυλακίου, θύρα, χρόνος λειτουργίας, τελευταίος συγχρονισμός. |
| `obsidian_sync_conflicts`    | Καταχωρίστε τις ανεπίλυτες διενέξεις συγχρονισμού (διαδρομή, διαδρομή διένεξης, εντοπισμός-στο).                                  |

### Εργαλεία γραφής (`write:obsidian`)

| Εργαλείο                         | Περιγραφή                                                                                                          |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `obsidian_write_note`            | Δημιουργήστε ή αντικαταστήστε μια σημείωση με δεδομένο περιεχόμενο Markdown.                                       |
| `obsidian_append_note`           | Προσθήκη περιεχομένου σε μια σημείωση. προαιρετικά σε ένα συγκεκριμένο heading/block.                              |
| `obsidian_patch_note`            | Χειρουργικά append/prepend/replace σε πεδίο κατεύθυνσης, μπλοκ ή μπροστινού θέματος.                               |
| `obsidian_delete_note`           | Διαγράψτε οριστικά μια σημείωση από το θησαυροφυλάκιο.                                                             |
| `obsidian_move_note`             | Μετακινήστε ή μετονομάστε μια σημείωση μέσα στο θησαυροφυλάκιο.                                                    |
| `obsidian_execute_command`       | Εκτελέστε μια εντολή Obsidian με την εντολή ID.                                                                    |
| `obsidian_open_file`             | Ανοίξτε ένα αρχείο στο Obsidian (το δημιουργεί αν δεν υπάρχει).                                                    |
| `obsidian_sync_trigger`          | Ενεργοποιήστε έναν άμεσο αμφίδρομο επιτραπέζιο συγχρονισμό θησαυροφυλακίου για φορητές συσκευές ↔.                 |
| `obsidian_sync_resolve_conflict` | Επιλύστε μια διένεξη συγχρονισμού: διατηρήστε `local` (κινητό), `remote` (επιτραπέζιος υπολογιστής) ή `keep-both`. |

> [!NOTE]
> Οι στόχοι `obsidian_patch_note` δέχονται `targetType` του `heading | block | frontmatter` και `operation` του `append | prepend | replace`, με προαιρετικό `createTargetIfMissing`. Τα τέσσερα εργαλεία `obsidian_sync_*` συνομιλούν με τον τοπικό διακομιστή συγχρονισμού (`http://127.0.0.1:27781` από προεπιλογή) και απαιτούν το διακριτικό συγχρονισμού.

### Πεδίο εφαρμογής

Τα εργαλεία ανάγνωσης απαιτούν `read:obsidian`. Τα εργαλεία εγγραφής απαιτούν `write:obsidian`. Η επιβολή είναι πανομοιότυπη με Notion — που χειρίζεται `withScopeEnforcement()` στο `open-sse/mcp-server/server.ts`, κλείνεται στο `OMNIROUTE_MCP_ENFORCE_SCOPES=true` και επιβάλλεται για καλούντες HTTP/SSE των οποίων το κλειδί API στερείται `manage`/`admin`, με επιτρεπόμενα πεδία που προέρχονται από `OMNIROUTE_MCP_SCOPES` ή το πλαίσιο εύρους του κλειδιού API. Δείτε [MCP-SERVER.md](./MCP-SERVER.md).

## Τελικά σημεία

| Μέθοδος  | Διαδρομή                        | Σκοπός                                                                        |
| -------- | ------------------------------- | ----------------------------------------------------------------------------- |
| `GET`    | `/api/settings/obsidian`        | Επιστρέφει `{ connected, hasToken, baseUrl, vaultPath }`.                     |
| `POST`   | `/api/settings/obsidian`        | Αποθηκεύει και επικυρώνει το token (απορρίπτει τη θύρα `27124`).              |
| `DELETE` | `/api/settings/obsidian`        | Αποσυνδέει (διαγράφει το αποθηκευμένο token).                                 |
| `GET`    | `/api/settings/obsidian/webdav` | Κατάσταση συγχρονισμού WebDAV και διαπιστευτήρια (όσο είναι ενεργοποιημένος). |
| `POST`   | `/api/settings/obsidian/webdav` | Ενεργοποιεί τον συγχρονισμό WebDAV για έναν κατάλογο vault.                   |
| `DELETE` | `/api/settings/obsidian/webdav` | Απενεργοποιεί τον συγχρονισμό WebDAV.                                         |

> Αυτές είναι διαδρομές ρυθμίσεων του πίνακα ελέγχου. Η πρόσβαση στο ίδιο το vault γίνεται μέσω του Obsidian
> Local REST API (του διαμορφωμένου `base_url`) και μέσω των παραπάνω εργαλείων MCP — δεν υπάρχει
> δημόσιο τελικό σημείο διαμεσολάβησης `/v1` για το Obsidian.

## Περιπτώσεις χρήσης

- **Απαντήσεις βασισμένες στο vault** — `obsidian_search_simple` / `obsidian_search_structured`
  και έπειτα `obsidian_read_note`, ώστε ένας agent να απαντά με βάση τις πραγματικές σας σημειώσεις.
- **Σύνταξη σημειώσεων / τήρηση ημερολογίου** — `obsidian_write_note`, `obsidian_append_note` ή
  το χειρουργικά ακριβές `obsidian_patch_note`, για την καταγραφή εξόδου του agent, συνόψεων ή ημερήσιων σημειώσεων
  (`obsidian_get_periodic_note`) στο vault.
- **Πλοήγηση στο vault** — `obsidian_list_vault`, `obsidian_get_document_map` και
  `obsidian_get_tags` για εξερεύνηση της δομής πριν από την ανάγνωση/εγγραφή.
- **Αυτοματοποίηση του Obsidian** — `obsidian_list_commands` + `obsidian_execute_command` για
  τον χειρισμό προσθέτων/εντολών από έναν agent· `obsidian_open_file` για την εμφάνιση μιας σημείωσης στο περιβάλλον χρήστη.
- **Συγχρονισμός με κινητές συσκευές** — ενεργοποιήστε τον συγχρονισμό WebDAV και έπειτα χρησιμοποιήστε τα `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`
  για τον συντονισμό υπολογιστή↔κινητού και την επίλυση διενέξεων.
