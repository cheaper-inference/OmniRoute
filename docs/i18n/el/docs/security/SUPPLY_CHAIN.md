Το OmniRoute δημοσιεύει τεχνουργήματα npm + Docker. Αυτές οι πύλες παρέχουν προέλευση,
απογραφή (SBOM) και σάρωση CVE, όλα OSS, ενσωματωμένα στις ροές εργασίας κυκλοφορίας.
**Πρώτα η συμβουλευτική** στάση — αναφέρουν τώρα, προωθούν σε αποκλεισμό μετά την 1η
πράσινη κυκλοφορία.

| Πύλη                 | Εργαλείο                                       | Πού                               | Αποκλείει;                    | Έξοδος                                        |
| -------------------- | ---------------------------------------------- | --------------------------------- | ----------------------------- | --------------------------------------------- |
| Προέλευση SLSA (npm) | `npm --provenance` (OIDC)                      | `npm-publish.yml`                 | μόνο αν αποτύχει η δημοσίευση | σήμα npmjs / `npm audit signatures`           |
| SBOM npm             | `@cyclonedx/cyclonedx-npm`                     | `npm-publish.yml`                 | μόνο αν αποτύχει η δημιουργία | Στοιχείο κυκλοφορίας + τεχνούργημα            |
| SBOM εικόνας         | `anchore/sbom-action` (syft)                   | `docker-publish.yml` (συγχώνευση) | συμβουλευτική                 | Τεχνούργημα CycloneDX                         |
| Trivy CVE (SARIF)    | `aquasecurity/trivy-action`                    | `docker-publish.yml` (συγχώνευση) | συμβουλευτική                 | SARIF (HIGH+CRITICAL) → Καρτέλα Ασφάλειας     |
| Πύλη Trivy CRITICAL  | `aquasecurity/trivy-action`                    | `docker-publish.yml` (συγχώνευση) | **αποκλεισμός**               | `exit-code: '1'` σε διορθώσιμο CRITICAL       |
| osv vulnCount        | `osv-scanner` (`check:vuln-ratchet --ratchet`) | `ci.yml` (`quality-extended`)     | **αποκλεισμός**               | αυξάνει `metrics.vulnCount` (κατεύθυνση:κάτω) |
| OpenSSF Scorecard    | `ossf/scorecard-action`                        | `scorecard.yml` (cron)            | συμβουλευτική                 | SARIF → Ασφάλεια + σήμα                       |

Η αύξηση CVE της εικόνας χρησιμοποιεί **δύο βήματα** στο `docker-publish.yml`: το βήμα SARIF
(`HIGH,CRITICAL`, `exit-code: 0`) διατηρεί τα HIGH+CRITICAL ορατά στην καρτέλα Ασφάλειας
χωρίς αποκλεισμό. Το βήμα _CRITICAL gate_ (`severity: CRITICAL`, `ignore-unfixed: true`,
`exit-code: 1`) αποτυγχάνει την κυκλοφορία σε ένα CRITICAL CVE **με διαθέσιμη διόρθωση**. Το `ignore-unfixed`
αποτρέπει τον αποκλεισμό της κυκλοφορίας για ένα CVE βασικής εικόνας χωρίς upstream patch.

## ⚠️ Διακύμανση CVE (έλεγχοι osv/Trivy που μπλοκάρουν)

Τα osv και Trivy συγκρίνουν τις εξαρτήσεις με βάσεις δεδομένων CVE που **επεκτείνονται συνεχώς**. Ένα PR
που **δεν τροποποιεί καμία εξάρτηση** μπορεί ξαφνικά να αποτύχει, επειδή γνωστοποιήθηκε ένα νέο CVE
σε μια υπάρχουσα εξάρτηση (osv: το μετρημένο `vulnCount` > τιμή αναφοράς· Trivy: ένα νέο
διορθώσιμο CRITICAL στην εικόνα). **Αυτή είναι ΑΝΑΜΕΝΟΜΕΝΗ λειτουργική συμπεριφορά ενός ελέγχου
CVE που μπλοκάρει, όχι παλινδρόμηση του προϊόντος.**

Όταν το osv ή το Trivy αποτυγχάνει λόγω ενός CVE που γνωστοποιήθηκε πρόσφατα, η λύση είναι:

1. **Αναβαθμίστε την επηρεαζόμενη εξάρτηση** (προτιμώμενο) — αναβαθμίστε στη διορθωμένη έκδοση μέσω των `package.json`
   `overrides` (μεταβατικές εξαρτήσεις) ή δημιουργήστε ξανά την εικόνα χρησιμοποιώντας μια διορθωμένη εικόνα βάσης.
2. **Εάν μια αποκατάσταση δεν είναι διαθέσιμη:** διατηρήστε το μετρημένο εύρημα και παρακολουθήστε την επηρεασμένη εξάρτηση ή εικόνα. Μην ανεβάσετε τη βασική γραμμή ευπάθειας για να πραγματοποιήσετε αποτυχία υποψηφίου. `ignore-unfixed: true` της Trivy αποκλείει ήδη ευπάθειες εικόνας χωρίς upstream patch. Οποιαδήποτε εξαίρεση απαιτεί μια ελεγμένη ευπάθεια ID, ακριβή διαδρομή πακέτου, λήξη και πρόβλημα παρακολούθησης στην πολιτική. δεν είναι αυτόματη συνέπεια μιας αποτυχημένης σάρωσης.

Οι απαιτούμενες εκτελέσεις OSV (`check:vuln-ratchet -- --ratchet`) αποτυγχάνουν με ασφαλή τρόπο με
`INCOMPLETE` και κωδικό εξόδου 2, όταν δεν είναι δυνατή η επικύρωση του σαρωτή, της αναφοράς ή της τιμής αναφοράς.
Μια μετρημένη παλινδρόμηση επιστρέφει κωδικό εξόδου 1. Η συμβουλευτική εκτέλεση μπορεί ακόμη να αναφέρει `SKIP` με
κωδικό εξόδου 0, κάτι που δεν τεκμηριώνει ότι οι εξαρτήσεις πέρασαν επιτυχώς τη σάρωση. Το βήμα αποκλεισμού
του Trivy απαιτεί επίσης επιτυχή μέτρηση: μη διαθέσιμα εργαλεία, αποτυχημένες εργασίες
και ελλιπή αποδεικτικά στοιχεία εικόνας δεν μπορούν να πιστοποιήσουν μια εικόνα ως καθαρή.

## Πολιτική σάρωσης εικόνας

Το τρέχον `.trivyignore.yaml` δεν περιέχει εξαιρέσεις ευπάθειας. `npm run check:trivy-ignore-policy` επικυρώνει τη δομημένη πολιτική σε τοπικά προφίλ σάρωσης, CI και Ποιότητα. Άγνωστο IDs, ευρύτερες διαδρομές, διπλότυπες καταχωρήσεις και ληγμένες εξαιρέσεις απορρίπτονται. το `.trivyignore` παλαιού τύπου δεν αποτελεί είσοδο στις σαρώσεις που μετεγκαταστάθηκαν.

Docker ελέγχει τα εργαλεία πολιτικής από `github.workflow_sha` και την πολιτική προέλευσης εικόνας με τον ίδιο επιλογέα πηγής με το build. Ο επιλογέας πολιτικής απορρίπτει μη συμβατά πεδία και προετοιμάζει ένα αρχείο και για τις δύο σαρώσεις Trivy. Μια ιστορική πηγή χωρίς δομημένη πολιτική δεν δέχεται εξαιρέσεις. Και οι δύο σαρώσεις καρφιτσώνουν το Trivy `v0.70.0`. Η επικύρωση πολιτικής αποδεικνύει τη συνέπεια της διαμόρφωσης. η εικόνα εξακολουθεί να χρειάζεται επιτυχή σάρωση.

## Κίνδυνος εξάρτησης από σύνταξη

Το ριζικό αρχείο κλειδώματος δεν περιλαμβάνει πλέον `extract-zip` ή ακμή εξάρτησης από αυτό μετά την αναβάθμιση του καρφιτσωμένου εργαλείου ανάπτυξης promptfoo. Αυτό αποσύρει την προηγουμένως αποδεκτή αλυσίδα `promptfoo` → `@openai/codex-security` → `extract-zip` που παρακολουθείται σε #14482. Οι έλεγχοι παλινδρόμησης στο `tests/unit/extract-zip-14482-exposure.test.ts` απορρίπτουν την επανεισαγωγή του και διατηρούν την απαγόρευση εισαγωγών από τον κωδικό παραγωγής.

Η τρέχουσα επιδιόρθωση εξάρτησης καλύπτει επίσης τις παρακάμψεις συμβατότητας στον πελάτη MSAL της ταυτότητας Azure και στον πελάτη FTP του get-uri. Η απόκτηση διακριτικού Azure και η ανάκτηση FTP ελέγχονται με ελεγχόμενες μεταφορές. Και τα δύο πακέτα OpenCode τρέχουν τις δικές τους σουίτες κατασκευής και δοκιμών. Οι συμβουλευτικές μετρήσεις μητρώου είναι μετρήσεις σε μια χρονική στιγμή και μπορούν να αλλάξουν μετά τη δέσμευση του αρχείου κλειδώματος.
