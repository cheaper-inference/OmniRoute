Το `devin-cli-agentic` επιτρέπει στο πραγματικό runtime του Claude Code να χρησιμοποιεί το τοπικό
endpoint Anthropic Messages του OmniRoute, ενώ το επίσημο Devin CLI παρέχει αποκρίσεις μοντέλου μέσω ACP stdio. Δεν
τροποποιεί τους υπάρχοντες παρόχους Anthropic, Claude OAuth, Claude Web ή `devin-cli`.

Για κλήσεις εργαλείων που ανήκουν στον client, πραγματοποιήστε τη δρομολόγηση μέσω του `devin-cli-agentic` (ψευδώνυμο `dva`), του
παρόχου με δυνατότητα χρήσης εργαλείων και μορφή Claude. Ο παλαιού τύπου εκτελεστής ACP `devin-cli` (`dv`) είναι
μόνο για κείμενο: εκτελεί το summarizer χωρίς εργαλεία του Devin και δεν μπορεί να επιστρέψει κλήσεις εργαλείων. Τα μεταδεδομένα
του μοντέλου του έχουν επισημανθεί αναλόγως, ώστε η δρομολόγηση συνδυασμών που απαιτούν εργαλεία να τον αποφεύγει.

> **Τρέχουσα κατάσταση: καθηλωμένο Claude Code `2.1.258`· η τελευταία επικύρωση εκτός σύνδεσης και σε πραγματικό περιβάλλον καταγράφηκε
> στην έκδοση `2.1.220`.** Η καθήλωση στην έκδοση `2.1.220` ολοκλήρωσε τρία απομονωμένα σενάρια μέσω του Devin CLI
> `3000.2.17` και του μοντέλου `swe-1-7-lightning`· εκείνη η τελική εκτέλεση σε πραγματικό περιβάλλον απέδειξε κύκλους `Read`,
> `Edit` και `Bash` που ανήκουν στον client, επιτυχή αποτελέσματα του `npm test`, εντοπισμό εντολών και δεξιοτήτων
> έργου, δρομολόγηση αποκλειστικά μέσω Devin και μηδενική εξερχόμενη κίνηση προς το Claude. Στη συνέχεια, η καθήλωση αναβαθμίστηκε στην έκδοση `2.1.258`
> (τη γενιά του CLI την οποία υποδύεται η ταυτότητα Claude του OmniRoute και την πρώτη σειρά εκδόσεων που παρέχει
> εγγενώς τη βαθμίδα Fable 5.1). Στη νέα καθήλωση, το επίπεδο εγκατάστασης και το `claude --version`
> επαληθεύτηκαν στη συγκεκριμένη βασική εικόνα, ενώ η σουίτα μονάδων της γέφυρας, το `compose config` και η
> στατική απόδειξη απομόνωσης ολοκληρώνονται επιτυχώς — όμως το σενάριο mock εκτός σύνδεσης και η σουίτα τριών σεναρίων
> σε πραγματικό περιβάλλον δεν έχουν εκτελεστεί ξανά ακόμη. Εκτελέστε τα ξανά (δείτε «Ενημέρωση καθηλωμένων εργαλείων») προτού βασιστείτε
> στη γέφυρα με αυτή την καθήλωση.

## Αρχιτεκτονική

```text
Claude Code 2.1.258 (απομονωμένο κοντέινερ Linux χωρίς δικαιώματα root)
  -> http://omniroute:20128/v1/messages
  -> devin-cli-agentic (μορφή Claude, πάροχος χωρίς έλεγχο ταυτότητας)
  -> devin acp --agent-type summarizer (επίσημο ACP stdio, χωρίς εργαλεία Devin)
  -> λογαριασμός Devin στο αποκλειστικό volume devin-auth
```

Ο προεπιλεγμένος agent ACP του επίσημου CLI μπορεί να εκτελεί τα δικά του εργαλεία, επομένως αυτή η γέφυρα δεν τον
χρησιμοποιεί. Εκκινεί τον σταθερό agent ACP `summarizer`, του οποίου η επίσημη λειτουργία CLI δεν διαθέτει εργαλεία, και
πλαισιώνει το σειριοποιημένο αίτημα Anthropic ως ίχνος εκτέλεσης. Όταν απαιτείται άλλη ενέργεια που ανήκει στο Claude,
η απόκριση πρέπει να περιέχει ακριβώς έναν φάκελο εργαλείου του client. Οποιοδήποτε ACP
`tool_call` ή `tool_call_update` απορρίπτεται προτού μια απόκριση μπορέσει να αναφερθεί ως
επιτυχής.

Ο σειριοποιητής στο `open-sse/executors/devin-agentic/serializer.ts` διατηρεί τα `system`,
`text`, `tool_use`, `tool_result`, `thinking`, `redacted_thinking`, `tool_choice` και τα
εργαλεία που παρέχονται από το Claude Code. Οι εικόνες και τα άγνωστα blocks αποτυγχάνουν ρητά. Τα μεγάλα αποτελέσματα εργαλείων
χρησιμοποιούν έναν ορατό δείκτη περικοπής.

Ο parser δέχεται έναν αυτόνομο φάκελο `<tool>{...}</tool>` ανά κύκλο μοντέλου. Ελέγχει
το όνομα σε σχέση με τη λίστα εργαλείων του αιτήματος, επικυρώνει τα ορίσματα βάσει του JSON
Schema αυτού του εργαλείου, απορρίπτει μεικτή αφήγηση/ενέργειες και επιτρέπει μία περιορισμένη προσπάθεια διόρθωσης. Στη συνέχεια, το Claude Code
εκτελεί το προκύπτον Anthropic `tool_use` τοπικά και στέλνει το `tool_result` πίσω μέσω
του OmniRoute.

## Αυτόματη δρομολόγηση

Ο πάροχος είναι επιλέξιμος στις δεξαμενές υποψηφίων `auto/*` του OmniRoute όταν δεν είναι αποκλεισμένος.
Η επιλεξιμότητα ως υποψήφιος δεν εγγυάται την επιλογή: η στρατηγική δρομολόγησης του συνδυασμού (για παράδειγμα,
last-known-good) ενδέχεται να προτιμήσει άλλον πάροχο. Χρησιμοποιήστε το `dva/<model>` ή έναν συνδυασμό με προτεραιότητα στο Devin όταν
απαιτείτε κάθε αίτημα να διέρχεται μέσω του Devin.

## Απομόνωση και μοντέλο απειλών

Η εγκατάσταση, ο λογαριασμός και η διαμόρφωση του Claude στον κεντρικό υπολογιστή είναι εκτός πεδίου εφαρμογής και θεωρούνται
απαγορευμένα. Οι υπηρεσίες Compose:

- εκτελούνται με UID/GID `10001:10001`, με ριζικό σύστημα αρχείων μόνο για ανάγνωση, καταργημένες δυνατότητες και
  `no-new-privileges`;
- χρησιμοποιούν έναν ιδιωτικό κατάλογο `/home/bridge`, έναν αποκλειστικό τόμο διαμόρφωσης του Claude, απομονωμένα δεδομένα OmniRoute
  και έναν ξεχωριστό τόμο `devin-auth`;
- προσαρτούν μόνο αναλώσιμους χώρους εργασίας/αποδεικτικά στοιχεία `.sandbox`;
- δεν προσαρτούν τον προσωπικό κατάλογο του κεντρικού υπολογιστή, το Keychain, διαπιστευτήρια SSH, διαπιστευτήρια cloud ή το socket του Docker;
- δημιουργούν ρητά περιβάλλοντα και αφαιρούν μεταβλητές API/OAuth/δρομολόγησης του Anthropic;
- κατευθύνουν τη συμπερασματολογία του Claude Code μόνο στο `http://omniroute:20128` με ένα κλειδί αποκλειστικά τοπικής χρήσης.

Το προφίλ εκτός σύνδεσης χρησιμοποιεί ένα εσωτερικό δίκτυο. Στο ζωντανό προφίλ, το OmniRoute αποκτά πρόσβαση στα
επίσημα τελικά σημεία του Devin μόνο μέσω του `network-guard`· άσχετοι προορισμοί απορρίπτονται.
Το Claude Code διαθέτει ξεχωριστό μηχανισμό προστασίας εξερχόμενης κίνησης που απορρίπτει τα πάντα και μπορεί να αποκτήσει πρόσβαση μόνο στην τοπική υπηρεσία OmniRoute
μέσω του `NO_PROXY`. Τα αρχεία ελέγχου των μηχανισμών προστασίας προσαρτώνται μόνο από την αντίστοιχη διεργασία προστασίας. Τα
σενάρια επαληθεύουν την ιδιοκτησία, τη λειτουργία και το πλήθος συνδέσμων των αρχείων, καθώς και κάθε απόφαση, πριν εξαγάγουν
αποδεικτικά στοιχεία χωρίς διακριτικά.

Εκτελέστε ανεξάρτητα την απόδειξη απομόνωσης:

```bash
./scripts/devin-bridge/verify-anthropic-isolation
```

Επικυρώνει την τοπολογία, τις επώνυμες προσαρτήσεις, τις ρυθμίσεις μη ριζικού χρήστη/μόνο για ανάγνωση, τη ρητή τοπική δρομολόγηση,
την απουσία ευαίσθητων μεταβλητών περιβάλλοντος, την απουσία του socket του Docker, τον αποκλεισμό πρόσβασης στα
`api.anthropic.com` και `claude.ai`, την επιλογή παρόχου αποκλειστικά για το Devin και τη ρητή αποτυχία όταν
το backend ACP δεν είναι διαθέσιμο.

## Αρχική ρύθμιση και κανονική χρήση

Δημιουργήστε την εικόνα με κλειδωμένη έκδοση:

```bash
./scripts/devin-bridge/build
```

Πραγματοποιήστε έλεγχο ταυτότητας μόνο στον απομονωμένο τόμο Devin:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/login-devin
```

Η εντολή σύνδεσης χρησιμοποιεί την επίσημη ροή χειροκίνητου διακριτικού που προορίζεται για απομακρυσμένα περιβάλλοντα/περιβάλλοντα
container. Η τιμή εισάγεται απευθείας στην προτροπή του CLI· δεν μεταβιβάζεται ως
όρισμα διεργασίας, δεν εγγράφεται στο Git και δεν αντιγράφεται από τον κεντρικό υπολογιστή.

Εκκινήστε το απομονωμένο περιβάλλον εκτέλεσης του Claude Code:

```bash
./scripts/devin-bridge/launch
```

Το `launch` επανελέγχει την απομόνωση, τον έλεγχο ταυτότητας στο Devin και τον εντοπισμό μοντέλων πριν ξεκινήσει το
Claude Code μέσα σε container. Δεν εκτελεί ποτέ το εκτελέσιμο αρχείο Claude του κεντρικού υπολογιστή. Τα ψευδώνυμα μοντέλων μπορούν να
οριστούν στο `.env.devin-bridge`· κάθε διαμορφωμένη τιμή πρέπει να διατηρεί το πρόθεμα
`devin-cli-agentic/`.

## Εντολές επικύρωσης

Η αναπαραγώγιμη διαδρομή εκτός σύνδεσης δεν απαιτεί λογαριασμό Devin και δεν έχει πρόσβαση στο Διαδίκτυο κατά την εκτέλεση:

```bash
./scripts/devin-bridge/test-unit
./scripts/devin-bridge/test-contract
./scripts/devin-bridge/test-e2e-mock
./scripts/devin-bridge/verify-anthropic-isolation
```

Η προαιρετική ζωντανή διαδρομή με έλεγχο ταυτότητας είναι:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/test-live-devin
```

Ο ζωντανός εκτελεστής περιμένει μεταξύ των σεναρίων, ώστε να αποφεύγει το άνοιγμα συνεδριών ACP κατά ριπές, και
επικυρώνει δομημένα συμβάντα ροής του Claude αντί να εμπιστεύεται ισχυρισμούς σε μορφή κειμένου. Τα τρία
σενάριά του αποδεικνύουν:

1. άμεσες αναγνώσεις του έργου και ανάλυση ελαττωμάτων·
2. ένα πραγματικό `Edit`, ένα `Bash` `npm test` υπό τον έλεγχο του πελάτη και ένα τελικό αποτέλεσμα·
3. `/bridge-check` μαζί με εντοπισμό του `bridge-proof`, αναγνώσεις του έργου, ένα ακόμη επιτυχημένο
   `npm test` υπό τον έλεγχο του πελάτη και ολοκλήρωση χωρίς εκκρεμή εργασία.

Ο τελικός έλεγχος εξετάζει επίσης το αρχείο ελέγχου δικτύου του Devin και απαιτεί το αρχείο ελέγχου εξερχόμενης κίνησης του Claude να
παραμένει κενό.

## Ενημέρωση καρφιτσωμένων εργαλείων

Η εικόνα καρφιτσώνει τα Node, Claude Code και Devin CLI στο
`docker/devin-bridge/Dockerfile`. Για ενημέρωση:

1. αλλάξτε τις ρητά καθορισμένες εκδόσεις,
2. αντικαταστήστε και τα δύο αθροίσματα ελέγχου του αρχείου Devin για τις συγκεκριμένες αρχιτεκτονικές με τις τιμές του επίσημου τεχνουργήματος,
3. δημιουργήστε ξανά την εικόνα και εκτελέστε κάθε εντολή επικύρωσης εκτός σύνδεσης,
4. επιβεβαιώστε τις εκδόσεις μέσα στην εικόνα,
5. εκτελέστε ξανά την πιστοποιημένη ζωντανή σουίτα τριών σεναρίων.

Μην εγκαταστήσετε κανένα από τα δύο CLI καθολικά στο σύστημα υποδοχής και μην αντικαταστήσετε την επαλήθευση αθροίσματος ελέγχου με μη επαληθευμένη λήψη.

## Διάγνωση και εκκαθάριση

- Η εντολή `docker compose -f docker/devin-bridge/compose.yml --profile offline logs omniroute`
  εμφανίζει την τοπική δρομολόγηση και τα εξυγιασμένα σφάλματα του εκτελεστή.
- Το `.sandbox/evidence/mock-acp.jsonl` καταγράφει τις ντετερμινιστικές ενέργειες του εικονικού ACP.
- Το `.sandbox/evidence/claude-stream.jsonl` καταγράφει την πραγματική εκτέλεση του Claude Code εκτός σύνδεσης.
- Το `.sandbox/evidence/live-*.jsonl` καταγράφει τις τρεις επικυρωμένες ζωντανές ροές.
- Τα `.sandbox/evidence/egress.jsonl` και `.sandbox/evidence/claude-egress.jsonl` είναι επικυρωμένα,
  αντίγραφα των ελέγχων προστασίας χωρίς διακριτικά πρόσβασης.

Σταματήστε τα ιδιόκτητα κοντέινερ και δίκτυα, διατηρώντας τους τόμους σύνδεσης/διαμόρφωσης:

```bash
./scripts/devin-bridge/clean
```

Καταργήστε ολόκληρο το περιβάλλον που ανήκει στη γέφυρα, συμπεριλαμβανομένων των ονομασμένων τόμων:

```bash
./scripts/devin-bridge/clean --all
```

## Περιορισμοί

- Η γέφυρα βασίζεται στον σταθερό ρόλο `summarizer` χωρίς εργαλεία, επειδή το Devin CLI `3000.2.17`
  δεν παρέχει ουδέτερο πράκτορα ACP χωρίς εργαλεία. Ο προσαρμογέας αντισταθμίζει τις ενδιάμεσες αποκρίσεις
  που έχουν μορφή σύνοψης, αλλά μία περιορισμένη απόπειρα επιδιόρθωσης μπορεί ακόμη να αποτύχει ρητά.
- Οι ζωντανές κλήσεις ACP μπορούν να επιστρέψουν παροδικές αποκρίσεις `502`/`504`. Το πλαίσιο δοκιμών αφήνει χρονικά διαστήματα μεταξύ των σεναρίων.
  Η επίμονη αποτυχία παραμένει ασφαλής και δεν επιλέγει ποτέ άλλον πάροχο.
- Το περιβάλλον ACP ανακατασκευάζεται από κάθε αίτημα Anthropic· δεν υπάρχει συνάφεια διεργασίας/συνεδρίας.
- Υποστηρίζεται μία κλήση εργαλείου ανά απόκριση μοντέλου· οι παράλληλες κλήσεις απορρίπτονται.
- Οι εικόνες δεν υποστηρίζονται ρητά. Δεν διαφημίζονται δυνατότητες όρασης, έξοδος συλλογισμού, έλεγχοι προσπάθειας ή παράθυρο περιβάλλοντος 1M.
- Το SSE χρησιμοποιεί έγκυρα συμβάντα κύκλου ζωής Anthropic, αλλά εκπέμπεται αφού συλλεχθεί ο περιορισμένος κύκλος ACP· τα τμήματα ACP δεν προωθούνται σταδιακά.
