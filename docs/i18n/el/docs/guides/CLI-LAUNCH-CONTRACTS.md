Το ουδέτερο συμβόλαιο `config/cli-tools-manifest.json` δηλώνει κανονικό IDs, ψευδώνυμα, δυαδικούς υποψηφίους, συνταγές εγκατάστασης, ορίσματα μοντέλων και δυνατότητες. Ο απλός προσαρμογέας Node στο `bin/cli/cli-manifest.mjs` και ο προσαρμογέας TypeScript στο `src/shared/constants/cliIntegrationManifest.ts` διαβάζουν το ίδιο αρχείο. Ο χρόνος εκτέλεσης, ο κατάλογος, η διαμόρφωση, η ολοκλήρωση, οι γεννήτριες και η εγγραφή στο backend ελέγχονται μαζί από `tests/unit/cli/cli-manifest-drift.test.ts`. Η καταλογογράφηση δεν σημαίνει ότι ένα εργαλείο μπορεί να ξεκινήσει ή να διαμορφωθεί. Συγκεκριμένα, το 5dive παραμένει μόνο για διαμόρφωση.

## Παιδικό περιβάλλον και κύκλος ζωής

`omniroute run`, `omniroute launch` και `omniroute launch-codex` κληρονομούν μια λίστα επιτρεπόμενων συμβατότητας OS/terminal και εισάγουν τα διαπιστευτήρια του επιλεγμένου στόχου. Τα μυστικά άσχετων παρόχων και βάσεων δεδομένων δεν κληρονομούνται από προεπιλογή. `--inherit-env` αποκαθιστά ρητά την πλήρη κληρονομιά γονέα-περιβάλλοντος. χρησιμοποιήστε το μόνο όταν η επιλεγμένη διαδικασία τρίτου μέρους πρέπει να λάβει αυτές τις τιμές. Αυτό είναι φιλτράρισμα περιβάλλοντος, όχι sandbox OS : η διαδικασία εξακολουθεί να εκτελείται με τα δικαιώματα συστήματος αρχείων του καλούντος.

Τα σήματα διακοπής και τερματισμού προωθούνται στο παιδί. Ο εκκινητής περιμένει το συμβάν κλεισίματος του παιδιού πριν καταργήσει την προσωρινή διαμόρφωση. `OMNIROUTE_CHILD_SIGNAL_TIMEOUT_MS` ελέγχει την περίοδο χάριτος πριν από τον αναγκαστικό τερματισμό (προεπιλογή 5000 χιλιοστά του δευτερολέπτου).

## επίμονη ρύθμιση Gemini

```bash
omniroute setup-gemini --remote https://omni.example --model provider/model --yes
omniroute configure gemini --model provider/model --yes
omniroute run gemini --model provider/model --dry-run --json
```

Οι δύο πρώτες εντολές διαμορφώνουν αυτό το μηχάνημα για τον επιλεγμένο τοπικό ή απομακρυσμένο διακομιστή. Το πρόγραμμα Εγκατάστασης διατηρεί άσχετες ρυθμίσεις JSON, επιλέγει τον έλεγχο ταυτότητας κλειδιού API Gemini και εγγράφει το τελικό σημείο και τα διαπιστευτήρια σε ένα ιδιωτικό αρχείο `.gemini/.env`. Απορρίπτει το μη έγκυρο JSON αντί να το αντικαθιστά. Το τελικό σημείο URLs πρέπει να είναι HTTP(S), χωρίς ενσωματωμένα διαπιστευτήρια, παραμέτρους ερωτήματος ή τμήματα. Η ξηρή εκτέλεση εκτυπώνει διαδρομές, όχι τιμές διαπιστευτηρίων.

`GEMINI_CLI_HOME` ή `--gemini-home` επιλέγει την επίμονη αρχική ρίζα. Ένα πραγματικό `run gemini` δημιουργεί και αργότερα αφαιρεί το δικό του προσωρινό σπίτι. Καμία λειτουργία δεν παρακάμπτει τους ελέγχους αξιοπιστίας χώρου εργασίας του Gemini.

## προφίλ Codex

`configure codex` γράφει ένα ιδιωτικό `<name>.config.toml` με ένα μοντέλο και το τελικό σημείο του παρόχου OmniRoute. Τα διαπιστευτήρια αναφέρονται μέσω `OMNIROUTE_API_KEY`, δεν ενσωματώνονται ποτέ. Η εντολή εκκίνησης θέτει το επιλεγμένο μοντέλο στο πλήκτρο `model` ανώτατου επιπέδου, όχι μέσα `model_providers`.

Τα ξεχωριστά αρχεία προφίλ είναι η τρέχουσα τεκμηριωμένη σύμβαση Codex. επικαλύπτουν τις ρυθμίσεις παραμέτρων χρήστη όταν επιλέγονται με `codex --profile <name>`. Δείτε [την επίσημη αναφορά προφίλ](https://learn.chatgpt.com/docs/config-file/config-advanced#profiles) και [τον οδηγό OmniRoute Codex](./CODEX-CLI-CONFIGURATION.md).

## Ερμητική εκτέλεση εντολών

Με ένα ρητό `DATA_DIR`, η ρύθμιση `OMNIROUTE_CLI_SKIP_DEFAULT_DATA_ENV=1` αποτρέπει την εκκίνηση από το να πέσει στο περιβάλλον διαπιστευτηρίων του προεπιλεγμένου καταλόγου δεδομένων χρήστη. Αυτό είναι χρήσιμο για μεμονωμένες δοκιμές. Δεν απενεργοποιεί άλλα ρητά επιλεγμένα αρχεία περιβάλλοντος.

## Κατάλογος εργασίας `.env`

Το CLI διαβάζει τα αρχεία `.env` με αυτή τη σειρά και το πρώτο αρχείο που ορίζει ένα κλειδί κερδίζει: το ρητό `DATA_DIR`, τον προεπιλεγμένο κατάλογο δεδομένων, τον τρέχοντα κατάλογο εργασίας και μετά τον κατάλογο πακέτων. Οι μεταβλητές Shell πάντα κερδίζουν.

Ο κατάλογος εργασίας μπορεί να ανήκει σε κάποιον άλλο (ένα κλωνοποιημένο αποθετήριο, ένα μη συσκευασμένο αρχείο) και `omniroute serve` μεταβιβάζει το περιβάλλον CLI στον διακομιστή και σε κάθε εργαλείο που εκτελεί ο διακομιστής. Έτσι, ένα `.env` εκεί μπορεί να ορίσει μόνο αυτά τα κλειδιά, που αναφέρονται στο `bin/cli/utils/untrustedCwdEnv.mjs`:

| Κλειδί                          | Αποδεκτές αξίες                                                                            |
| ------------------------------- | ------------------------------------------------------------------------------------------ |
| `REQUIRE_API_KEY`               | `true`, `1` ή `yes` σε κάθε περίπτωση, οι τιμές που ο διακομιστής αντιμετωπίζει ως ενεργές |
| `LANG`, `LC_ALL`, `LC_MESSAGES` | έως 64 γράμματα, ψηφία, `_`, `.`, `@` ή `-`                                                |
| `LANGUAGE`                      | το ίδιο, συν `:`                                                                           |
| `TZ`                            | έως 64 γράμματα, ψηφία, `_`, `+`, `-` ή `/`, που δεν ξεκινούν με `/`                       |
| `NO_COLOR`, `FORCE_COLOR`       | έως 16 γράμματα και ψηφία                                                                  |

Κάθε τιμή που δέχεται `REQUIRE_API_KEY` ενεργοποιεί τον έλεγχο, επομένως το αρχείο δεν μπορεί να απενεργοποιήσει τον έλεγχο από μόνο του. Ωστόσο, δεν αποφασίζει το αποτέλεσμα: ο διακομιστής διαβάζει μια παράκαμψη `REQUIRE_API_KEY` που είναι αποθηκευμένη στη βάση δεδομένων πριν από το περιβάλλον, ενώ η προειδοποίηση εκκίνησης για ακρόαση σε όλες τις διεπαφές χωρίς κλειδί API διαβάζει μόνο το περιβάλλον. Με μια αποθηκευμένη παράκαμψη του `false`, ένας κατάλογος εργασίας `REQUIRE_API_KEY=true` αφήνει το API ανοιχτό και κρύβει αυτήν την προειδοποίηση. Ο κανόνας `TZ` είναι στενότερος από POSIX: απορρίπτει `.`, `:`, `,` και `<>`, επομένως η μορφή `:Area/City` και κανόνες όπως `EST5EDT,M3.2.0,M11.1.0` πρέπει να οριστούν στο κέλυφος ή στο `<DATA_DIR>/.env`.

Τα ονόματα πρέπει να ταιριάζουν ακριβώς, με κεφαλαία. Οποιαδήποτε άλλη γραμμή, μια τιμή που αποτυγχάνει στον έλεγχο και ένα όνομα που δεν είναι απλά γράμματα ASCII, ψηφία και `_` (για παράδειγμα, μια με ένα byte NUL ή ένα γράμμα που μοιάζει με γράμμα) παραλείπονται. Το CLI εκτυπώνει μια προειδοποίηση που ονομάζει τα κλειδιά που δεν μπορεί να ορίσει και μια που ονομάζει επιτρεπόμενα κλειδιά που αγνοήθηκε, το καθένα με τι πρέπει να αλλάξει (`TZ (expected a zone name such as Europe/Berlin)`, `lang (write the name as LANG)`). Κανένα από τα δύο δεν εκτυπώνει τις τιμές. Οι διαδρομές αρχείων σε αυτά τα μηνύματα και οι αναφορές `.env` διαδρομής `omniroute doctor` διαφεύγουν όταν περιέχουν χαρακτήρες ελέγχου ή bidi. Ο περιορισμός δεν ισχύει όταν ο κατάλογος εργασίας είναι ο κατάλογος δεδομένων ή ο κατάλογος πακέτων.

`PORT`, `API_PORT` και `DASHBOARD_PORT` δεν είναι στη λίστα. Χωρίς ένα βασικό URL από μια πηγή υψηλότερης προτεραιότητας, το CLI συνομιλεί με `localhost:<PORT>` και ό,τι ακούει εκεί λαμβάνει το κλειδί API του CLI, το διακριτικό περιβάλλοντος και το διακριτικό μηχανής CLI (`x-omniroute-cli-token`, βλέπε [CLI_TOKEN.md](../security/CLI_TOKEN.md) ), τα οποία ο τοπικός διακομιστής δέχεται για κλήσεις διαχείρισης από το loopback. Μια θύρα από τον κατάλογο εργασίας θα επέτρεπε σε αυτό το αρχείο να επιλέξει τον ακροατή, επομένως ορίστε τις θύρες στο κέλυφος, σε `<DATA_DIR>/.env` ή με την επιλογή `--port` των εντολών που έχουν μία (`serve`, `launch`, `run`).

Ο αναλυτής δεν έχει σύνταξη `export`. Μια γραμμή όπως `export LD_PRELOAD=...` ονομάζει μια μεταβλητή `export LD_PRELOAD`. από τον κατάλογο εργασίας παραλείπεται και σε άλλα αρχεία `.env` ορίζει αυτό το κυριολεκτικό όνομα, το οποίο δεν διαβάζεται τίποτα.

Το CLI αντιστοιχίζει το αποθηκευμένο διακριτικό ενός περιβάλλοντος (διακριτικό πρόσβασης ή κλειδί API παλαιού τύπου) μόνο με την προέλευση αυτού του περιβάλλοντος: σχήμα, κεντρικό υπολογιστή και θύρα, σε σύγκριση με `URL.origin`. Αυτό ισχύει για αιτήματα που γίνονται μέσω του πελάτη HTTP του CLI(`--base-url`, `OMNIROUTE_BASE_URL`, `omniroute connect <new-url>`) και για τις εντολές `launch`, `launch codex`, `configure` και `setup-*` που γράφουν μια βάση URL και κλειδί στη διαμόρφωση άλλου εργαλείου. Κατευθύνονται σε έναν άλλο διακομιστή με `--remote`, χρησιμοποιούν ένα ρητό `--api-key` ή `OMNIROUTE_API_KEY` εάν έχει οριστεί, και κανένα διακριτικό περιβάλλοντος. Η σύγκριση είναι ακριβής, επομένως `localhost` και `127.0.0.1`, ή ένας κεντρικός υπολογιστής με και χωρίς τελική κουκκίδα, υπολογίζονται ως διαφορετικοί διακομιστές και δεν λαμβάνουν διακριτικό περιβάλλοντος. Ένα URL με πληροφορίες χρήστη, ανάστροφη κάθετο ή κενό διάστημα δεν ταιριάζει ποτέ, επειδή άλλοι αναλυτές URL (για παράδειγμα, `urllib` και `httpx` της Python) μπορούν να διαβάσουν έναν διαφορετικό κεντρικό υπολογιστή από αυτό. Για αιτήματα, το CLI στέλνει στον εαυτό του, αυτός ο έλεγχος καλύπτει μόνο το σχήμα και την αρχή, επομένως ένα αναγνωριστικό με ένα διάστημα στη διαδρομή ή το ερώτημα διατηρεί το διακριτικό.
