Το `@omniroute/opencode-plugin-v2` προσθέτει ολόκληρο τον κατάλογο OmniRoute — μοντέλα, combos και
auto-combos — στον επιλογέα μοντέλων του OpenCode v2, μαζί με εμφανιζόμενα ονόματα, τιμολόγηση και όρια
δωρεάν χρήσης.

Είναι ξεχωριστό πακέτο από το `@omniroute/opencode-plugin`, επειδή τα OpenCode v1 και v2 φορτώνουν
τα plugins μέσω διαφορετικών συμβάσεων. Επιλέξτε αυτό που αντιστοιχεί στην κύρια έκδοση του OpenCode που χρησιμοποιείτε· τίποτα δεν
είναι κοινό μεταξύ τους, επομένως η αναβάθμιση του ενός δεν επιβάλλει ποτέ την αναβάθμιση του άλλου.

## Απαιτήσεις

- OpenCode v2.
- Μια προσβάσιμη πύλη OmniRoute (`http://localhost:20128` από προεπιλογή).
- Node.js 22 ή 24.

## Εγκατάσταση

Προσθέστε το plugin στο `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

Στη συνέχεια, τα μοντέλα εμφανίζονται ως `omniroute/<provider>/<model>`· το `providerId` καθορίζει αυτό το πρόθεμα και
το αναγνωριστικό της ενσωμάτωσης κάτω από το οποίο το OpenCode αποθηκεύει το διαπιστευτήριο.

## Διαπιστευτήρια

Το plugin αναζητά ένα κλειδί πύλης σε τρία σημεία, με την ακόλουθη σειρά:

1. **Το διαπιστευτήριο που συνδέσατε στο OpenCode.** Το plugin καταχωρίζει μια ενσωμάτωση, ώστε
   η ροή ελέγχου ταυτότητας του OpenCode να μπορεί να αποθηκεύσει το κλειδί. Τίποτα δεν καταλήγει στο `opencode.json` — προτιμήστε αυτήν την επιλογή.
2. Το `apiKey` στις επιλογές του plugin, για παράκαμψη ανά έργο. Αυτό τοποθετεί το κλειδί σε ένα αρχείο που
   ενδέχεται να καταχωρείτε στο αποθετήριο.
3. Το `OMNIROUTE_API_KEY` στο περιβάλλον.

Αν δεν υπάρχει κανένα από τα τρία, ο κατάλογος είναι κενός και το plugin το αναφέρει μία φορά κατά την εκκίνηση, αντί
να σας αφήσει με έναν σιωπηρά κενό επιλογέα.

### Το διακριτικό διαχείρισης είναι διαφορετικό κλειδί

Τα combos, η κατάσταση των παρόχων και ο εμπλουτισμός (εμφανιζόμενα ονόματα, τιμολόγηση, όρια δωρεάν χρήσης) προέρχονται από
τα endpoints `/api/*` της πύλης, τα οποία οι περισσότερες εγκαταστάσεις προστατεύουν με ένα διακριτικό **διαχείρισης**
και όχι με το κλειδί inference:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<management read token>"
}
```

Αν δεν οριστεί, το `managementReadToken` χρησιμοποιεί ως εφεδρικό το `apiKey`. Όταν μια πύλη απορρίπτει αυτήν την εφεδρική επιλογή,
ο κατάλογος εξακολουθεί να δημοσιεύεται, αλλά με τα ακατέργαστα αναγνωριστικά μοντέλων αντί για εμφανιζόμενα ονόματα, χωρίς απαλοιφή διπλοτύπων
κανονικών ψευδωνύμων, χωρίς τιμολόγηση και χωρίς combos. Το plugin προειδοποιεί μία φορά ανά endpoint όταν συμβαίνει αυτό,
κατονομάζοντας το endpoint και ό,τι χάθηκε — έτσι ένας υποβαθμισμένος επιλογέας δεν αποτελεί ποτέ μυστήριο.

## Πώς ο κατάλογος παραμένει φρέσκος

Ο κατάλογος λαμβάνεται νωχελικά και αποθηκεύεται προσωρινά για `modelCacheTtlMs`, και ένα στιγμιότυπο δίσκου διατηρεί τον τελευταίο γνωστό κατάλογο διαθέσιμο όταν η πύλη δεν είναι προσβάσιμη — μια διακοπή δεν σας κοστίζει παρά μόνο φρεσκάδα. Τα μοντέλα και οι συνδυασμοί δημοσιεύονται αμέσως μόλις φτάσουν. Οι αυτόματες συνδυασμοί, η λίστα παρόχων και η επικάλυψη εμπλουτισμού διπλώνουν όταν προσγειώνονται, έτσι ένα αργό τελικό σημείο δεν μπορεί να κρατήσει όμηρο ολόκληρο τον επιλογέα.

Τα ονόματα ακολουθούν `Provider - Model[ (Editor)][ · budget][ (route)]`: ο πάροχος εμφανίζεται όποτε το αναγνωριστικό φέρει ένα (ένα αναγνωριστικό χωρίς κάθετο αποδίδεται χωρίς πρόθεμα), ένα κορυφαίο `🆓` επισημαίνει τις δωρεάν καταχωρήσεις και ο προϋπολογισμός του ελεύθερου επιπέδου παραμένει ως επίθημα `· 1M tokens/month`, ο επεξεργαστής ενός σαφούς ονόματος `Editor: Model` μετακινείται σε μια παρένθεση στο τέλος (χωρίς άλλα ονόματα συντάκτης είναι δωρεάν και χωρίς άλλα ονόματα επεξεργασίας). `combo - <slug>`. Δύο καταχωρήσεις που μοιράζονται ένα όνομα παίρνουν ένα επίθημα διαδρομής — `(no-think)` —, ώστε να παραμένουν διακριτές. `providerTag` (προεπιλογή `true`) αλλάζει την παρένθεση του τελευταίου προγράμματος επεξεργασίας.

Δεν υπάρχει εντολή μη αυτόματης ανανέωσης: οι εντολές OpenCode v2 είναι πρότυπα προτροπής, όχι επανακλήσεις, επομένως μια προσθήκη δεν μπορεί να εκθέσει μία. Οι ανανεώσεις ακολουθούν το TTL. Ο κεντρικός υπολογιστής καλείται να επαναφορτώσει μόνο όταν ο κατάλογος ή η επικάλυψη άλλαξε πραγματικά, ποτέ μία φορά ανά ανανέωση.

## Κλήση εργαλείων στο Gemini

Το Gemini απορρίπτει ολόκληρο το αίτημα όταν οι δηλώσεις εργαλείων του περιέχουν `$schema` ή
`additionalProperties`, απαντώντας με `400 INVALID_ARGUMENT`. Το πρόσθετο αφαιρεί αυτές τις λέξεις-κλειδιά από
τα σχήματα εργαλείων που προορίζονται για ένα μοντέλο Gemini αυτού του παρόχου και αφήνει κάθε άλλο αίτημα ανέπαφο.
Ένα εργαλείο που περιέχει `$ref` προωθείται ανέπαφο αντί να αφαιρεθούν στοιχεία του, καθώς η αφαίρεση της
αναφοράς θα διεύρυνε το σχήμα ώστε να «δέχεται οτιδήποτε».
Ορίστε `"geminiSanitization": false` για να το απενεργοποιήσετε.

## Αντιμετώπιση προβλημάτων

| Σύμπτωμα                                                                | Αιτία                                                                                                                                                             |
| ----------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Το Picker δεν δείχνει κανένα μοντέλο OmniRoute                          | Δεν επιλύθηκε κανένα κλειδί (ελέγξτε την προειδοποίηση εκκίνησης) ή η πύλη δεν είναι προσβάσιμη                                                                   |
| Ακατέργαστα αναγνωριστικά μοντέλων, χωρίς συνδυασμούς, χωρίς τιμολόγηση | Τα τελικά σημεία διαχείρισης απέρριψαν το διακριτικό σύνολο — `managementReadToken`                                                                               |
| Σύντομος ή κενός κατάλογος `freeOnly`                                   | Κανένα διακριτικό διαχείρισης ή απορριφθέν διακριτικό — διάβασε τη γραμμή σύνοψης ανανέωσης (πλήθος `unmatched-free` ) στο αρχείο καταγραφής κεντρικού υπολογιστή |
| Μια συνεδρία καρφιτσωμένη στο `opencode-<id>/...`                       | Το πρόσθετο v1 δημοσιεύτηκε `opencode-<id>`; Το v2 δημοσιεύει `<id>` bare, επομένως επιλέξτε ξανά το μοντέλο κάτω από `<id>/...`                                  |

Οι μεταβλητές περιβάλλοντος πρέπει να φτάσουν στη διαδικασία διακομιστή ανοιχτού κώδικα: όταν ο κεντρικός υπολογιστής εκτελείται ως υπηρεσία, το κέλυφος που εκτελεί `opencode models` και το περιβάλλον διακομιστή διαφέρουν, επομένως εξάγετε το κλειδί όπου το διαβάζει ο διακομιστής.
