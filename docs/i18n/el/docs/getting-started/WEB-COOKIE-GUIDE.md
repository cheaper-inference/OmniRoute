Οι πάροχοι Web Cookie επιτρέπουν στο OmniRoute να χρησιμοποιεί μια υπηρεσία AI μέσω της υπάρχουσας περιόδου σύνδεσης του προγράμματος περιήγησής σας, αντί για ένα κλειδί API. Είναι χρήσιμοι όταν έχετε ήδη πρόσβαση σε μια υπηρεσία μέσω του ιστότοπού της και θέλετε το OmniRoute να χρησιμοποιεί την ίδια πιστοποιημένη περίοδο σύνδεσης.

Σε αντίθεση με τους παρόχους που χρησιμοποιούν κλειδιά API, οι πάροχοι Web Cookie πραγματοποιούν έλεγχο ταυτότητας χρησιμοποιώντας τα διαπιστευτήρια που αποστέλλει το πρόγραμμα περιήγησής σας στον ιστότοπο.

---

# Πριν ξεκινήσετε

> **Σημαντικό:** Αντιγράφετε πάντα τα διαπιστευτήρια από ένα **ενεργό αίτημα δικτύου** και **όχι** από τον χώρο αποθήκευσης cookie του προγράμματος περιήγησής σας.

Πολλά προβλήματα ελέγχου ταυτότητας προκαλούνται από την αντιγραφή cookie από λάθος σημείο.

## ΜΗΝ αντιγράφετε από τον χώρο αποθήκευσης cookie

Τα περισσότερα προγράμματα περιήγησης εμφανίζουν τα αποθηκευμένα cookie μέσω των εξής επιλογών:

```
Εργαλεία προγραμματιστή
→ Εφαρμογή (ή Χώρος αποθήκευσης)
→ Cookie
```

Παρόλο που αυτά τα cookie φαίνονται σωστά, ενδέχεται να είναι:

- παρωχημένα
- ελλιπή
- χωρίς cookie που αποστέλλονται μόνο σε πιστοποιημένα αιτήματα

Η χρήση αυτών των τιμών ενδέχεται να προκαλέσει αποτυχίες ελέγχου ταυτότητας, ακόμη και αν φαίνονται έγκυρες.

## Αντιγραφή από ενεργό αίτημα

Αντ' αυτού, χρησιμοποιήστε τα cookie από ένα επιτυχημένο αίτημα:

```
Εργαλεία προγραμματιστή
→ Δίκτυο
→ Ανανεώστε τη σελίδα
→ Ανοίξτε ένα αίτημα συνομιλίας
→ Κεφαλίδες αιτήματος
→ Cookie
```

Η κεφαλίδα αιτήματος `Cookie` περιέχει τις ακριβείς πληροφορίες ελέγχου ταυτότητας που χρησιμοποίησε επιτυχώς το πρόγραμμα περιήγησής σας.

Για τους περισσότερους παρόχους Web Cookie, αυτή είναι η τιμή που πρέπει να επικολληθεί στο OmniRoute.

# Γενική ρύθμιση

Η διαδικασία ρύθμισης είναι ίδια για τους περισσότερους παρόχους Web Cookie.

1. Συνδεθείτε στον ιστότοπο του παρόχου.
2. Ανοίξτε τα Εργαλεία προγραμματιστή του προγράμματος περιήγησης.
3. Ανοίξτε την καρτέλα **Δίκτυο**.
4. Ανανεώστε τη σελίδα.
5. Ανοίξτε ένα πιστοποιημένο αίτημα συνομιλίας.
6. Αντιγράψτε τα απαιτούμενα διαπιστευτήρια ελέγχου ταυτότητας.
7. Ανοίξτε το OmniRoute.
8. Μεταβείτε στην επιλογή **Πάροχοι → Προσθήκη παρόχου**.
9. Επιλέξτε τον πάροχο Web Cookie.
10. Επικολλήστε τα διαπιστευτήρια.
11. Κάντε κλικ στην επιλογή **Δοκιμή σύνδεσης**.
12. Αποθηκεύστε τον πάροχο.

Τα ακριβή διαπιστευτήρια που απαιτούνται εξαρτώνται από τον πάροχο.

## NoTrack (notrack-web)

Το NoTrack ([notrack.ai](https://notrack.ai)) είναι μια δωρεάν πλατφόρμα συνομιλίας για καταναλωτές, χωρίς να απαιτείται εγγραφή — η συνεδρία δημιουργείται ανώνυμα κατά την πρώτη επίσκεψη και διατηρείται μέσω τριών cookies: `uid`, `si_usr_id` και `si_ses_id`. Το OmniRoute προωθεί μέσω διακομιστή μεσολάβησης το ίδιο τελικό σημείο `/api/dispatch` χρησιμοποιώντας ένα μόνο αναγνωριστικό μοντέλου (`notrack-c`, ψευδώνυμο `ntw`).

### Βήματα σύνδεσης

1. Ανοίξτε το [notrack.ai](https://notrack.ai) στο πρόγραμμα περιήγησής σας και αφήστε να οριστεί το cookie ανώνυμης συνεδρίας.
2. Ανοίξτε τα **Εργαλεία προγραμματιστή → Δίκτυο**, ανανεώστε τη σελίδα και κάντε κλικ σε οποιοδήποτε αίτημα `/api`.
3. Στις **Κεφαλίδες αιτήματος**, αντιγράψτε ολόκληρη την τιμή της κεφαλίδας `Cookie`.
4. Στο OmniRoute, μεταβείτε στην επιλογή **Πάροχοι → Προσθήκη παρόχου → NoTrack Web (Δωρεάν)**.
5. Επικολλήστε τη συμβολοσειρά cookie στο πεδίο `apiKey` και επιλέξτε **Αποθήκευση**.

Το OmniRoute εξάγει τα `uid`, `si_usr_id` και `si_ses_id` από την επικολλημένη συμβολοσειρά και αναδημιουργεί μια καθαρή κεφαλίδα `Cookie` μόνο με αυτά τα ζεύγη — συν το `nt_session` (το διακριτικό `ntk_…` που ορίζεται για συνδεδεμένους λογαριασμούς), όταν υπάρχει. Αν λείπει οποιοδήποτε από τα τρία, η αρχική επικολλημένη συμβολοσειρά προωθείται χωρίς αλλαγές, ώστε οι διαχειριστές να μπορούν να πειραματιστούν με εναλλακτικές μορφές.

### Αναγνωριστικά μοντέλων

| Αναγνωριστικό μοντέλου | Εμφανιζόμενο όνομα | Σημειώσεις                                                            |
| ---------------------- | ------------------ | --------------------------------------------------------------------- |
| `notrack-c`            | NoTrack C          | Προεπιλογή — το μοντέλο δρομολόγησης ανάντη `C`.                      |
| `C`                    | NoTrack C          | Ψευδώνυμο του `notrack-c` (ακατέργαστος κωδικός δρομολόγησης ανάντη). |
| `notrack`              | NoTrack C          | Ψευδώνυμο του `notrack-c`.                                            |
| `ntw`                  | NoTrack C          | Σύντομο ψευδώνυμο του `notrack-c`.                                    |

Και τα τέσσερα αναγνωριστικά μοντέλων αντιστοιχίζονται στο ίδιο μοντέλο δρομολόγησης ανάντη (`C`).

### Επιλογές αιτήματος

Ο εκτελεστής δέχεται τα ακόλουθα προαιρετικά πεδία στο σώμα του αιτήματος:

| Πεδίο σώματος         | Προεπιλογή | Σκοπός                                                                                        |
| --------------------- | ---------- | --------------------------------------------------------------------------------------------- |
| `notrack_mode`        | `usual`    | Λειτουργία δρομολόγησης (συμβολοσειρά ελεύθερης μορφής· το ανάντη σύστημα δέχεται `usual`, …) |
| `notrack_max_turns`   | `6`        | Αριθμός εσωτερικών γύρων που μπορεί να εκτελέσει το ανάντη σύστημα πριν απαντήσει.            |
| `notrack_chat_id`     | `null`     | Συνέχιση υπάρχουσας συνομιλίας ανάντη (παραλείψτε το για νέα συνομιλία).                      |
| `notrack_attachments` | `[]`       | Πίνακας περιγραφέων συνημμένων του ανάντη συστήματος, ο οποίος μεταβιβάζεται αυτούσιος.       |
| `notrack_regenerate`  | `false`    | Ορίστε το σε `true` για να ζητήσετε αναδημιουργημένη απάντηση για τον προηγούμενο γύρο.       |

### Δυνατότητες

- **Ροή και απαντήσεις χωρίς ροή** για ολοκληρώσεις συνομιλίας.
- **Κλήση εργαλείων** — ορίστε `tools: [...]` στο αίτημα· ο εκτελεστής τα σειριοποιεί σε μια σύμβαση φακέλου κλήσης εργαλείου και αναλύει τις απαντήσεις του μοντέλου ξανά σε `tool_calls` του OpenAI.
- **`response_format`** — υποστηρίζονται τα `json_object` και `json_schema`. Ο εκτελεστής εξάγει το πρώτο αντικείμενο JSON από την απάντηση του μοντέλου και το μετατρέπει σε συμβολοσειρά πριν το επιστρέψει.
- **Ένδειξη συλλογισμού** — ο εκτελεστής εκπέμπει ένα τμήμα `reasoning` όταν το ανάντη σύστημα στέλνει ένα συμβάν `thinking`.

### Περιορισμοί

- Το ανάντη σύστημα επιβάλλει ποσοστώσεις ανώνυμης χρήσης — όταν αυτές ξεπεραστούν, ο εκτελεστής επιστρέφει σφάλμα 429 με ένα φιλικό μήνυμα.
- Όλα τα αναγνωριστικά μοντέλων αντιστοιχούν στο ίδιο μοντέλο δρομολόγησης ανάντη· δεν υπάρχει δυνατότητα εναλλαγής ανά μοντέλο.
- Ο εκτελεστής δεν καλεί το τελικό σημείο `/api/chats` του ανάντη συστήματος, επομένως το ιστορικό συνομιλιών και οι συνεδρίες δεν διαχειρίζονται αυτόματα. Χρησιμοποιήστε το `notrack_chat_id` για να συνεχίσετε μια υπάρχουσα συνομιλία ανάντη.

# Τι μπορούν και τι δεν μπορούν να κάνουν οι πάροχοι Web Cookie

Οι πάροχοι Web Cookie επαναχρησιμοποιούν τη διεπαφή συνομιλίας ενός ιστοτόπου. **Δεν** παρέχουν τις ίδιες δυνατότητες με τα επίσημα API.

## Υποστηρίζεται

- Έλεγχος ταυτότητας με χρήση της υπάρχουσας συνεδρίας του προγράμματος περιήγησής σας
- Πρόσβαση στα μοντέλα που είναι διαθέσιμα μέσω του λογαριασμού σας
- Ροή απαντήσεων συνομιλίας
- Δεν απαιτείται κλειδί API

## Δεν υποστηρίζεται

- Κλήση συναρτήσεων
- Κλήση εργαλείων
- Αυτόματη επεξεργασία αρχείων
- Ροές εργασίας IDE με πράκτορες
- Δυνατότητες διαθέσιμες μόνο μέσω API

Αυτή είναι αναμενόμενη συμπεριφορά και **δεν** αποτελεί σφάλμα.

Εάν χρειάζεστε εκτέλεση εργαλείων, αυτόματη επεξεργασία αρχείων ή άλλες ροές εργασίας με πράκτορες, χρησιμοποιήστε έναν **πάροχο με κλειδί API** αντί για έναν πάροχο Web Cookie.

# Επιφύλαξη σχετικά με την επικύρωση

Μια επιτυχής **Δοκιμή σύνδεσης** ή επικύρωση cookie επιβεβαιώνει μόνο ότι τα παρεχόμενα διαπιστευτήρια φαίνεται να έχουν την αναμενόμενη μορφή.

Μέχρι να επιλυθεί το ζήτημα #7857, η επιτυχής επικύρωση **δεν εγγυάται** ότι ο πάροχος θα ολοκληρώσει επιτυχώς τον έλεγχο ταυτότητας.

Εάν ο έλεγχος ταυτότητας εξακολουθεί να αποτυγχάνει, επαληθεύστε ότι αντιγράψατε τα διαπιστευτήρια από ένα ενεργό αίτημα δικτύου και όχι από τον χώρο αποθήκευσης cookie του προγράμματος περιήγησης.

# Αντιμετώπιση προβλημάτων

## Ο έλεγχος ταυτότητας αποτυγχάνει

Επαληθεύστε ότι τα διαπιστευτήρια αντιγράφηκαν από:

```
Network
→ Request Headers
→ Cookie
```

και **όχι** από:

```
Application
→ Cookies
```

---

## Το cookie λειτουργεί στο πρόγραμμα περιήγησης αλλά όχι στο OmniRoute

Ορισμένοι πάροχοι περιλαμβάνουν cookie που αποστέλλονται μόνο κατά τη διάρκεια αιτημάτων με έλεγχο ταυτότητας.

Αντιγράψτε ξανά τα διαπιστευτήρια από ένα νέο αίτημα δικτύου αφού ανοίξετε επιτυχώς μια συνομιλία.

---

## Η συνεδρία έληξε

Οι πάροχοι Web Cookie χρησιμοποιούν την υπάρχουσα συνεδρία του προγράμματος περιήγησής σας.

Εάν λήξει η συνεδρία του προγράμματος περιήγησής σας ή αποσυνδεθείτε, πρέπει να αντιγράψετε ένα νέο σύνολο διαπιστευτηρίων. Για να αυτοματοποιήσετε την ανανέωση των cookie για υποστηριζόμενους παρόχους ιστού, ανατρέξτε στο συνοδευτικό εργαλείο [Επέκταση συγχρονισμού συνεδρίας προγράμματος περιήγησης](../guides/SESSION-SYNC-EXTENSION.md).

---

## Η δοκιμή σύνδεσης επιτυγχάνει αλλά τα αιτήματα αποτυγχάνουν

Μέχρι να επιλυθεί το ζήτημα #7857, η επιτυχής επικύρωση δεν εγγυάται ότι το αίτημα ελέγχου ταυτότητας θα ολοκληρωθεί επιτυχώς.

Αντιγράψτε ξανά τα διαπιστευτήριά σας από ένα νέο αίτημα με έλεγχο ταυτότητας πριν προχωρήσετε σε περαιτέρω αντιμετώπιση προβλημάτων.

## Το ChatGPT Web αποτυγχάνει με το μήνυμα "Unsupported ChatGPT integrity dependency"

```
[502] ChatGPT Web first-party bridge module failed to load:
pageerror: Unsupported ChatGPT integrity dependency: DD
```

Τα διαπιστευτήρια είναι έγκυρα — αυτό το σφάλμα προέρχεται από τη γέφυρα και όχι από τη συνεδρία. Το chatgpt.com εκχωρεί τα
αναγνωριστικά των λειτουργικών μονάδων του ανά ανάπτυξη και η γέφυρα προηγουμένως καθόριζε σταθερά το αναγνωριστικό του βοηθητικού Sentinel που αρχικοποιεί, οπότε μια
νέα έκδοση του chatgpt.com που μετονόμασε το βοηθητικό στοιχείο προκαλούσε αποτυχία σε κάθε αλληλεπίδραση, ενώ το cookie παρέμενε έγκυρο. Η εκ νέου εξουσιοδότηση
της σύνδεσης δεν μπορεί να το διορθώσει.

Οι εκδόσεις που επιλύουν τη λειτουργική μονάδα μέσω του ίδιου του περιβάλλοντος εκτέλεσης της σελίδας δεν καθορίζουν σταθερά κανένα αναγνωριστικό και δεν αντιμετωπίζουν αυτό το πρόβλημα. Εάν δείτε αυτό το
σφάλμα, αναβαθμίστε το OmniRoute και εκτελέστε ξανά τον έλεγχο σύνδεσης.

# Παράδειγμα παρόχου

Για έναν πλήρη οδηγό ειδικά για τον πάροχο, ανατρέξτε στο:

- **Claude Web** — `docs/providers/CLAUDE_WEB.md`

Ο οδηγός Claude Web παρουσιάζει την πλήρη διαδικασία ρύθμισης ενός παρόχου Web Cookie και λειτουργεί ως υλοποίηση αναφοράς.

# Βέλτιστες πρακτικές

- Αντιγράφετε τα διαπιστευτήρια από ένα νέο αίτημα με έλεγχο ταυτότητας.
- Αποφεύγετε την επαναχρησιμοποίηση παλιών cookie.
- Διατηρείτε ενεργή τη συνεδρία του προγράμματος περιήγησής σας κατά τη χρήση παρόχων Web Cookie.
- Αντιμετωπίζετε τα αντιγραμμένα cookie ως ευαίσθητα διαπιστευτήρια.
- Χρησιμοποιείτε παρόχους με κλειδί API όταν χρειάζεστε κλήση συναρτήσεων ή ροές εργασίας με πράκτορες.
