> **TL;DR** : Φέρτε τους δικούς σας κατάλληλους λογαριασμούς παρόχου. OmniRoute συνδυάζει τις συνδέσεις που ρυθμίζετε. δεν εκδίδει τον διαφημιζόμενο συγκεντρωτικό προϋπολογισμό συμβολικών. Η δωρεάν πρόσβαση μπορεί να απαιτεί εγγραφή, κλειδί API, έγκριση ή μέθοδο πληρωμής. Τα όρια παρόχων, οι πολιτικές απορρήτου και οι όροι εξακολουθούν να ισχύουν.

## Τι είναι τα δωρεάν επίπεδα;

Πολλοί πάροχοι AI προσφέρουν κάποια μορφή** δωρεάν πρόσβαση** . Ανάλογα με τον πάροχο, αυτό μπορεί να σημαίνει μη εξουσιοδοτημένο τελικό σημείο, επαναλαμβανόμενο όριο, περιορισμένη βάσει ποσοστού πρόσβαση χωρίς περιορισμό, επιχορήγηση εγγραφής, μη αυτόματη έγκριση ή προσωρινή προώθηση. Ορισμένες επιλογές απαιτούν λογαριασμό, κλειδί API, πιστωτική κάρτα, KYC ή αποδοχή όρων για συγκεκριμένους παρόχους.

OmniRoute** αδρανή** ρυθμισμένες συνδέσεις σε ένα τελικό σημείο. Εξακολουθείτε να εγγράφεστε ξεχωριστά για κάθε πάροχο που απαιτεί λογαριασμό. Συνδέστε αυτούς τους λογαριασμούς και χρησιμοποιήστε `model: "auto"` για δρομολόγηση μεταξύ των κατάλληλων στόχων. Μια νέα εγκατάσταση δεν μπορεί να έχει κατάλληλο στόχο χωρίς κλειδί. Η εγκατάσταση OmniRoute από μόνη της δεν εγγυάται μια επιτυχημένη απόκριση συνομιλίας.

## Πώς να στοιβάζετε δωρεάν επίπεδα

Η μαγεία του OmniRoute είναι** στοίβαξη ελεύθερων επιπέδων** . Αντί να βασίζεστε σε έναν πάροχο, συνδέετε πολλούς δωρεάν παρόχους και αφήνετε OmniRoute να επιλέξει αυτόματα τον καλύτερο για κάθε αίτημα.

### Παράδειγμα: Ευρύτερη κάλυψη ελεύθερου επιπέδου

Συνδέστε πολλούς παρόχους για να μειώσετε την εξάρτηση από οποιαδήποτε μεμονωμένη ποσόστωση:

1. **Gemini** — επαναλαμβανόμενο όριο κλειδιού API
2. **Groq** — επαναλαμβανόμενο όριο κλειδιού API
3. **Επικονιάσεις** — χωρίς κλειδί, πρόσβαση με περιορισμένη ταχύτητα
4. **LongCat** — εφάπαξ επιχορήγηση εγγραφής (απαιτείται KYC)

Στη συνέχεια χρησιμοποιήστε `model: "auto"` και OmniRoute θα:

- Δοκιμάστε πρώτα την κατάλληλη σύνδεση με την υψηλότερη κατάταξη
- Εάν το όριο ή ο έλεγχος υγείας του αποτύχει → δοκιμάστε τον επόμενο διαμορφωμένο πάροχο
- Εάν ο πάροχος χωρίς κλειδί δεν είναι διαθέσιμος, → συνεχίστε στους υπόλοιπους στόχους
- Εάν καμία κατάλληλη σύνδεση δεν επιτύχει → επιστρέψτε ένα σφάλμα. Οι πιστώσεις εγγραφής μπορούν να χρησιμοποιηθούν μόνο όταν είναι έγκυρες και διαθέσιμες

**Αποτέλεσμα** : ευρύτερη κάλυψη ελεύθερου επιπέδου με αυτόματη εναλλακτική — δεν αποτελεί εγγύηση απεριόριστης χωρητικότητας.

## Πώς να συνδέσετε δωρεάν παρόχους

### Βήμα 1: Ανοίξτε τον Πίνακα ελέγχου

Μεταβείτε στο `http://localhost:20128` στο πρόγραμμα περιήγησής σας.

### Βήμα 2: Μεταβείτε στους Παρόχους

Κλικ** Παρόχους** στην πλαϊνή μπάρα.

### Βήμα 3: Κάντε κλικ στην Προσθήκη παρόχου

Κάντε κλικ στο**+ Προσθήκη παρόχου** κουμπί.

### Βήμα 4: Επιλέξτε έναν δωρεάν πάροχο

Περιηγηθείτε στον κατάλογο και επιθεωρήστε τα τρέχοντα μεταδεδομένα `hasFree`, auth, όριο, απόρρητο και ToS κάθε παρόχου. Η κάρτα παρόχου και η [Αναφορά Free Tiers](../reference/FREE_TIERS.md) διακρίνουν τις επαναλαμβανόμενες ομάδες, την πρόσβαση uncapped/keyless, τις πιστώσεις εγγραφής, τις καταχωρίσεις που έχουν διακοπεί και τις πηγές υψηλότερου κινδύνου.

### Βήμα 5: Κάντε κλικ στο Connect

Για έναν πάροχο `NOAUTH`, OmniRoute δεν ζητά διαπιστευτήριο ανάντη. Αυτό δεν εγγυάται ότι το upstream δέχεται τρίτους πελάτες ή ότι έχει διαθέσιμη χωρητικότητα. Οι πάροχοι OAuth και κλειδιών API πρέπει να συνδέονται μέσω της τεκμηριωμένης ροής του λογαριασμού τους. Ο πελάτης σας εξακολουθεί να χρησιμοποιεί ένα κλειδί OmniRoute API που δημιουργήθηκε στο** Πλήκτρα ταμπλό → API** (εμφανίζεται μόνο μία φορά, κατά τη δημιουργία) όταν είναι ενεργοποιημένος ο έλεγχος ταυτότητας δρομολογητή.

### Βήμα 6: Επαναλάβετε

Συνδέστε πολλούς παρόχους των οποίων οι όροι και το μοντέλο απορρήτου ταιριάζουν στην περίπτωση χρήσης σας.

## Προερχόμενος από το dsh "Το δωρεάν μοντέλο μας"

Η προσθήκη [dsh-our-free-model](https://github.com/Ebony-Vinyl/dsh-our-free-model) για τον κεντρικό υπολογιστή πράκτορα dsh φτάνει σε δύο upstreams. OmniRoute έχει ήδη έναν πάροχο για τον καθένα, αλλά μόνο ένας από αυτούς είναι δωρεάν διαδρομή στο OmniRoute:

| Λωρίδα προσθήκης | Αντίθετα στο ρεύμα                          | πάροχος OmniRoute               | Δωρεάν στο OmniRoute; | Πώς να συνδεθείτε                                                                           |
| ---------------- | ------------------------------------------- | ------------------------------- | --------------------- | ------------------------------------------------------------------------------------------- |
| Κανάλι κιλών     | Kilo AI gateway (`api.kilo.ai/api/gateway`) | `kilo-gateway` (ψευδώνυμο `kg`) | Ναί                   | Το κλειδί API προαιρετικό: αφήστε το κενό για να χρησιμοποιήσετε τη δωρεάν πισίνα της πύλης |
| Ελεύθερη λωρίδα  | OpenCode Zen (`opencode.ai`)                | `opencode-zen`                  | Οχι                   | Το δικό σας κλειδί OpenCode API από [opencode.ai/zen](https://opencode.ai/zen)              |

**Κιλό.** Καλέστε τη δωρεάν πισίνα ως `kilo-gateway/<model>` ή `kg/<model>`, για παράδειγμα `kg/kilo-auto/free` (δωρεάν αυτόματος δρομολογητής Kilo) ή ένα από τα μοντέλα `:free` της πύλης. Το ελεύθερο σετ περιστρέφεται. `kilo-gateway` περνά μέσα από αναγνωριστικά μοντέλων που δεν βρίσκονται στην ενσωματωμένη λίστα του OmniRoute, επομένως ένα μοντέλο που παραθέτει σήμερα η πύλη μπορεί να καλείται πριν το συμπεριλάβει ο κατάλογος. Οι κάρτες δωρεάν μοντέλων της Kilo αναφέρουν ότι τα μηνύματα ενδέχεται να καταγράφονται από τον ανάντη πάροχο και να χρησιμοποιηθούν για τη βελτίωση των υπηρεσιών του, επομένως μην στέλνετε ευαίσθητα δεδομένα.

**OpenCode.** Η δωρεάν λωρίδα της προσθήκης είναι η προσφορά του OpenCode χωρίς κλειδί. OmniRoute δεν παρέχει αυτήν την προσφορά ως δωρεάν πρόσβαση:

- Ο πάροχος OpenCode χωρίς κλειδί της OmniRoute καταργήθηκε κατόπιν αιτήματος του χειριστή του OpenCode(δείτε [Καταργημένες υπηρεσίες παροχής](../reference/REMOVED_PROVIDERS.md) ).
- [Η τεκμηρίωση τελικού σημείου](https://opencode.ai/v2/docs/console/models/#endpoints) του OpenCode συνδέει τις δωρεάν προσφορές συνομιλίας του με τον πελάτη του ίδιου του OpenCode, επομένως OmniRoute δεν τις υπολογίζει ούτε τις χαρακτηρίζει ως δωρεάν.

Τα αναγνωριστικά μοντέλου που εμφανίζει η προσθήκη, όπως `deepseek-v4.1-flash-free`, `mimo-v2.6-flash-free` και `nemotron-3.5-lightning-free`, βρίσκονται στον κατάλογο `opencode-zen`. Συνδέστε `opencode-zen` με το δικό σας κλειδί OpenCode για να τα χρησιμοποιήσετε σύμφωνα με τους όρους του λογαριασμού σας OpenCode.

**Η τοπική θύρα του plugin.** Η προσθήκη μπορεί να εκθέσει τα μοντέλα της σε μια τοπική θύρα συμβατή με OpenAI (προεπιλογή `18899`). Οποιοδήποτε τέτοιο τελικό σημείο μπορεί να προστεθεί ως [προσαρμοσμένος πάροχος συμβατός με OpenAI](../guides/USER_GUIDE.md#custom-openai-compatible-providers), αλλά OmniRoute δεν εγκαθιστά, εκκινεί ή ενημερώνει την προσθήκη και η προσθήκη αποφασίζει ποιο upstream εξυπηρετεί κάθε αίτημα. Οι παραπάνω περιορισμοί OpenCode ισχύουν για την προσφορά του OpenCode όποιος πελάτης στείλει το αίτημα.

## Διαβάζοντας σωστά τον Κατάλογο

- `NOAUTH` σημαίνει ότι OmniRoute δεν σας ζητά διαπιστευτήρια παρόχου. δεν εγγυάται χρόνο λειτουργίας, ιδιωτικότητα ή απεριόριστη χωρητικότητα.
- `hasFree` είναι μεταδεδομένα ανακάλυψης. Μπορεί να αντιπροσωπεύει ένα επαναλαμβανόμενο όριο, πρόσβαση χωρίς κλειδί, πίστωση εγγραφής, πρόγραμμα έγκρισης ή προώθηση.
- `recurring-uncapped` σημαίνει ότι δεν υπήρχε δημοσιευμένο ανώτατο όριο συμβολικών. εξακολουθούν να ισχύουν τα όρια συντελεστών και συγχρονισμού.
- `one-time-initial` δεν επαναλαμβάνεται μετά την κατανάλωση της επιχορήγησης εγγραφής.
- Οι πάροχοι `tos: avoid` εξαιρούνται από την αυτόματη δρομολόγηση από προεπιλογή (`excludeTosAvoid`). Η σύνδεση ενός λογαριασμού δεν παρακάμπτει αυτό το φίλτρο. Οποιαδήποτε παράκαμψη παρόχου θα πρέπει να ακολουθεί την αναθεώρηση των όρων παρόχου και του κινδύνου λογαριασμού.
- Οι συμμετοχές με την ένδειξη `discontinued` παραμένουν ιστορικά στοιχεία και δεν πρέπει να παρουσιάζονται ως δωρεάν.

## Πώς OmniRoute κάνει τα δωρεάν επίπεδα καλύτερα

### 1. Αυτόματη επιστροφή

Εάν ένας δωρεάν πάροχος είναι απασχολημένος ή απενεργοποιημένος, OmniRoute δοκιμάζει αυτόματα τον επόμενο. Δεν χρειάζεται να κάνετε τίποτα.

### 2. Έξυπνη δρομολόγηση

OmniRoute διαλέγει το** καλύτερος δωρεάν πάροχος** για κάθε αίτημα με βάση:

- Speed — Ποιος πάροχος είναι ο ταχύτερος αυτή τη στιγμή;
- Ποιότητα — Ποιος πάροχος είναι ο καλύτερος για αυτήν την εργασία;
- Χωρητικότητα — Ποιος πάροχος έχει υπόλοιπο ποσό;

### 3. Token Savings

Ο αγωγός συμπίεσης του OmniRoute μπορεί να μειώσει τα κατάλληλα κουπόνια προτροπής και εξόδου εργαλείου. Η πραγματική εξοικονόμηση εξαρτάται από το περιεχόμενο, τις επιλεγμένες μηχανές, τη λογιστική παρόχου και τις ρυθμίσεις πιστότητας. Η συμπίεση δεν πολλαπλασιάζει κάθε όριο παρόχου με ένα σταθερό ποσό.

### 4. Υποστήριξη πολλών λογαριασμών

Εάν οι όροι του παρόχου επιτρέπουν πολλαπλούς λογαριασμούς ή διαπιστευτήρια, OmniRoute μπορεί να αντιμετωπίσει κάθε σύνδεση ως ξεχωριστή υποψήφια δρομολόγηση. Μην δημιουργείτε επιπλέον λογαριασμούς για να αποφύγετε το όριο ή την πολιτική πρόσβασης ενός παρόχου.

## Δωρεάν Μαθηματικά Βαθμίδας

Ο ζωντανός κατάλογος που έχει αφαιρεθεί από τα διπλότυπα αυτή τη στιγμή αναφέρει:

| Μετρικός                               |        Τρέχουσα ελεγμένη αξία | Ερμηνεία                                                                                            |
| -------------------------------------- | ----------------------------: | --------------------------------------------------------------------------------------------------- |
| Επαναλαμβανόμενη ποσοτική επιχορήγηση  | **~ 90M δωρεάν tokens/month** | Οι κοινόχρηστες πισίνες μετρήθηκαν μία φορά. εξαιρεί τους παρόχους χωρίς περιορισμό από το άθροισμα |
| Πρώτος μήνας με επιχορηγήσεις εγγραφής | **~ 153M τον πρώτο σας μήνα** | Επαναλαμβανόμενο σύνολο συν εφάπαξ και επαναλαμβανόμενες πιστώσεις                                  |

Αυτές είναι εκτιμήσεις σε ολόκληρο τον κατάλογο για χωριστούς επιλέξιμους λογαριασμούς, όχι για αποζημίωση που παρέχεται από OmniRoute ή για πρόβλεψη για νέα εγκατάσταση. Η χρησιμοποιήσιμη χωρητικότητά σας εξαρτάται από τους παρόχους που συνδέετε και τις τρέχουσες συνθήκες τους. Οι τιμές υπολογίζονται από `open-sse/config/freeModelCatalog.ts`. Ανατρέξτε στην [Αναφορά Free Tiers](../reference/FREE_TIERS.md) για την κατάργηση διπλότυπων ομάδων, τις σημαίες ToS, τις καταχωρίσεις που έχουν διακοπεί και τη μεθοδολογία εγγραφής-πίστωσης.

## Κοινές Ερωτήσεις

### "Είναι πραγματικά δωρεάν;"

Ο κατάλογος καταγράφει όρους που έχουν δημοσιευτεί από τον πάροχο και έρευνα έργου, αλλά οι προσφορές μπορούν να αλλάξουν. Επαληθεύστε την τρέχουσα τιμολόγηση, το όριο, την πολιτική απορρήτου και την καταλληλότητα του παρόχου πριν από τη χρήση.

### "Θα εξαντληθεί το ελεύθερο επίπεδο;"

Κάθε πάροχος μπορεί να ορίσει όριο τιμών, να αλλάξει μοντέλα, να αναστείλει την πρόσβαση ή να βγει εκτός σύνδεσης. Οι πολλαπλές συνδέσεις βελτιώνουν την εναλλακτική κάλυψη, αλλά δεν εγγυώνται μια διαθέσιμη δωρεάν διαδρομή.

### "Μπορώ να χρησιμοποιήσω δωρεάν παρόχους για παραγωγή;"

Μόνο εάν το SLA, ο χειρισμός δεδομένων, τα όρια και οι όροι του παρόχου πληρούν τις απαιτήσεις παραγωγής σας. Οι κρίσιμοι φόρτοι εργασίας θα πρέπει να έχουν παρακολουθούμενη, συμβατικά κατάλληλη εναλλακτική.

### «Ποιο είναι το αλιεύμα;»

Οι συναλλαγές μπορεί να περιλαμβάνουν αυστηρά όρια, λίστες αναμονής, KYC, επαλήθευση πιστωτικής κάρτας, εκπαίδευση σχετικά με προτροπές, ασθενέστερο απόρρητο, χωρίς SLA, αλλαγή μοντέλου, γεωγραφικούς περιορισμούς, υπέρβαση επί πληρωμή ή κίνδυνο πολιτικής λογαριασμού. OmniRoute εμφανίζει τα διαθέσιμα μεταδεδομένα. εσείς επιλέγετε τι να ενεργοποιήσετε.

### "Πώς μπορώ να αποκτήσω περισσότερη δωρεάν ποσόστωση;"

1. Συνδέστε περισσότερους δωρεάν παρόχους
2. Ενεργοποιήστε τους κατάλληλους κινητήρες συμπίεσης και μετρήστε την εξοικονόμηση πόρων για τον φόρτο εργασίας σας
3. Χρησιμοποιήστε `auto/cheap` για να δώσετε προτεραιότητα στους παρόχους free/cheap
4. Προσθέστε επιπλέον επιτρεπόμενους παρόχους ή διαπιστευτήρια χωρίς να παραβιάζετε τους όρους παρόχου

### "Οι δωρεάν πάροχοι έχουν χειρότερη ποιότητα;"

Όχι απαραίτητα. Ορισμένοι πάροχοι εκθέτουν τις ίδιες οικογένειες μοντέλων που διατίθενται μέσω δρομολογίων επί πληρωμή, αλλά τα όρια, η καθυστέρηση, το απόρρητο, η αξιοπιστία και οι εκδόσεις μοντέλων μπορεί να διαφέρουν. Χρησιμοποιήστε τη σελίδα Κατατάξεις δωρεάν παρόχων ως σήμα ποιότητας και επαληθεύστε το πραγματικό μοντέλο που εξυπηρετείται.
