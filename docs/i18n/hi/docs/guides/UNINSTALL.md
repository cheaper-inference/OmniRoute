## क्लाइंट कॉन्फ़िगरेशन पूर्ववत करें

अनइंस्टॉलर PM2 द्वारा प्रबंधित OmniRoute प्रक्रिया को रोक देता है, यदि मौजूद है, और क्लाइंट कॉन्फ़िगरेशन को जगह पर छोड़ देता है। जो ग्राहक अभी भी OmniRoute को इंगित करते हैं वे बंद होने पर अपना कनेक्शन खो देते हैं। पूर्ण निष्कासन इसके क्लाइंट कॉन्फ़िगरेशन बैकअप के साथ, डिफ़ॉल्ट रूप से डेटा निर्देशिका, `~/.omniroute` भी हटा देता है।

### 1. जब OmniRoute चल रहा हो तो डैशबोर्ड का उपयोग करें

खुला**CLI कोड** (`/dashboard/cli-code`) डैशबोर्ड में और ढूंढें**Claude कोड** कार्ड.** आवेदन करना** डिफ़ॉल्ट रूप से OmniRoute होस्ट की Claude कोड सेटिंग्स फ़ाइल, `~/.claude/settings.json` को लिखता है। यदि आपके पास OmniRoute सेटिंग्स लागू करने से पहले का बैकअप है, तो खोलें** बैकअप** और इसे पुनर्स्थापित करें. अन्यथा, चयन करें** रीसेट करें** `env` से गेटवे सेटिंग्स को हटाने के लिए। लागू करें और पहले मौजूदा फ़ाइल का बैकअप लेकर रीसेट करें। बैकअप `<DATA_DIR>/backups` के अंतर्गत संग्रहीत किए जाते हैं।

यदि `CLI_ALLOW_CONFIG_WRITES=false` या डैशबोर्ड अनुपलब्ध है, तो फ़ाइल को हाथ से वापस लाएँ। यदि OmniRoute Docker में चलता है और क्लाइंट होस्ट पर चलता है, तो होस्ट कॉन्फ़िगरेशन को वापस लाएँ। अनमाउंट कंटेनर होम में फ़ाइलों का होस्ट क्लाइंट पर कोई प्रभाव नहीं पड़ता है।

### 2. शेष परिवर्तनों को हाथ से वापस लाएँ

Claude कोड के लिए, `~/.claude/settings.json` जांचें, यदि सेट है तो `CLAUDE_CONFIG_DIR` में `settings.json` और प्रोजेक्ट का `.claude/settings.json` जांचें। रीसेट निम्नलिखित कुंजियों को `env` से हटा देता है। OmniRoute के लिए आपके द्वारा जोड़े गए मान हटाएँ या अपने पिछले मान पुनर्स्थापित करें।

- `"ANTHROPIC_BASE_URL"`, `"ANTHROPIC_AUTH_TOKEN"`, और `"ANTHROPIC_API_KEY"`
- `"ANTHROPIC_DEFAULT_OPUS_MODEL"`, `"ANTHROPIC_DEFAULT_SONNET_MODEL"`, और `"ANTHROPIC_DEFAULT_HAIKU_MODEL"`
- `"API_TIMEOUT_MS"`

`ANTHROPIC_MODEL` `env` में रीसेट करें और शीर्ष-स्तरीय `model` और `apiKeyHelper` सेटिंग्स को यथास्थान रखें। यदि वे OmniRoute मॉडल या क्रेडेंशियल का चयन करते हैं तो उन्हें हाथ से हटा दें या पुनर्स्थापित करें। `~/.claude/profiles/<name>/` के अंतर्गत `omniroute setup-claude` द्वारा बनाई गई किसी भी OmniRoute प्रोफ़ाइल का उपयोग करना बंद करें, या उसके `settings.json` वापस लाएं। सेटअप कमांड डिफ़ॉल्ट सेटिंग्स फ़ाइल को बदले बिना या टोकन सहेजे बिना प्रोफ़ाइल लिखता है। अपनी शेल स्टार्टअप फ़ाइलों में मेल खाने वाले निर्यात को हटाएं या पुनर्स्थापित करें और वर्तमान शेल से पुराने मान साफ़ करें। `omniroute launch` और `omniroute run claude` केवल चाइल्ड प्रोसेस के लिए गेटवे URL और टोकन सेट करते हैं।

For Codex, restore the previous provider and model in `~/.codex/config.toml` if it contains `model_provider = "omniroute"`. Remove `[model_providers.omniroute]` if it was added for this gateway. Restore or remove `openai_base_url` if it points to OmniRoute. For OpenAI-compatible clients, restore or clear `OPENAI_BASE_URL` wherever you set it for OmniRoute.

### 3. सत्यापित करें कि क्लाइंट OmniRoute बंद होने के साथ काम करता है

डिफ़ॉल्ट Claude कोड सेटिंग्स और वर्तमान शेल वातावरण की जाँच करें।

```bash
grep -n ANTHROPIC ~/.claude/settings.json
env | grep ANTHROPIC
```

किसी भी चेक में `ANTHROPIC_BASE_URL` OmniRoute की ओर इंगित करते हुए नहीं दिखाया जाना चाहिए। यदि आप किसी प्रोफ़ाइल या प्रोजेक्ट सेटिंग्स का उपयोग करते हैं, तो उन फ़ाइलों की भी जाँच करें। OmniRoute बंद होने और आपका सामान्य प्रमाणीकरण बहाल होने पर, सीधे Claude कोड चलाएँ।

```bash
claude -p "say hello"
```

Claude कोड को पुनर्स्थापित कॉन्फ़िगरेशन का उपयोग करके प्रतिक्रिया देनी चाहिए। यदि यह अभी भी रुके हुए गेटवे की ओर इशारा करता है, तो कनेक्शन त्रुटि के साथ अनुरोध विफल हो जाता है।

## त्वरित अनइंस्टॉल (v3.6.2 +)

> पहले [क्लाइंट कॉन्फ़िगरेशन को वापस लाएं](#revert-client-configuration), जबकि OmniRoute अभी भी चल रहा है।

OmniRoute साफ़ निष्कासन के लिए दो अंतर्निहित स्क्रिप्ट प्रदान करता है:

### अपना डेटा रखें

```bash
npm run uninstall
```

यह OmniRoute एप्लिकेशन को हटा देता है लेकिन** बरकरार रखता है** `~/.omniroute/` में आपका डेटाबेस, कॉन्फ़िगरेशन, API कुंजियाँ और प्रदाता सेटिंग्स। यदि आप बाद में पुनः स्थापित करने की योजना बना रहे हैं और अपना सेटअप रखना चाहते हैं तो इसका उपयोग करें।

### पूर्ण निष्कासन

```bash
npm run uninstall:full
```

इससे एप्लिकेशन हट जाता है** और स्थायी रूप से मिटा देता है** सभी डेटा:

- डेटाबेस (`storage.sqlite`)
- प्रदाता कॉन्फ़िगरेशन और API कुंजियाँ
- बैकअप फ़ाइलें
- फाइल्स लॉग करें # लॉग फाइलें
- `~/.omniroute/` निर्देशिका में सभी फ़ाइलें

> ⚠️** चेतावनी:** `npm run uninstall:full` अपरिवर्तनीय है. आपके सभी प्रदाता कनेक्शन, कॉम्बो, API कुंजियाँ और उपयोग इतिहास स्थायी रूप से हटा दिए जाएंगे।

## मैन्युअल अनइंस्टॉल

> पहले [क्लाइंट कॉन्फ़िगरेशन को वापस लाएं](#revert-client-configuration), जबकि OmniRoute अभी भी चल रहा है।

### NPM ग्लोबल इंस्टाल

```bash
# Remove the global package
npm uninstall -g omniroute

# (Optional) Remove data directory
rm -rf ~/.omniroute
```

### पीएनपीएम ग्लोबल इंस्टाल

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# Stop and remove the container
docker stop omniroute
docker rm omniroute

# Remove the volume (deletes all data)
docker volume rm omniroute-data

# (Optional) Remove the image
docker rmi cheaperinference/omniroute:latest
# Older installs pulled the legacy name:
docker rmi diegosouzapw/omniroute:latest
```

### Docker लिखें

```bash
# Stop and remove containers
docker compose down

# Also remove volumes (deletes all data)
docker compose down -v
```

### Electron डेस्कटॉप ऐप

**Windows:**

- `Settings → Apps → OmniRoute → Uninstall` खोलें
- या इंस्टाल डायरेक्टरी से NSIS अनइंस्टॉलर चलाएँ

**macOS:**

- `OmniRoute.app` `/Applications` से ट्रैश में खींचें
- डेटा हटाएँ: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- AppImage फ़ाइल हटाएँ
- डेटा हटाएँ: `rm -rf ~/.omniroute`

### स्रोत इंस्टॉल (गिट क्लोन)

```bash
# Remove the cloned directory
rm -rf /path/to/omniroute

# (Optional) Remove data directory
rm -rf ~/.omniroute
```

## डेटा डायरेक्टरियाँ

OmniRoute डिफ़ॉल्ट रूप से निम्न स्थानों पर डेटा संग्रहीत करता है:

| प्लेटफ़ॉर्म | डिफ़ॉल्ट पथ                           | ओवरराइड                               |
| ----------- | ------------------------------------- | ------------------------------------- |
| Linux       | `~/.omniroute/`                       | `DATA_DIR` एनवायरनमेंट वेरिएबल        |
| macOS       | `~/.omniroute/`                       | `DATA_DIR` एनवायरनमेंट वेरिएबल        |
| Windows     | `%APPDATA%/omniroute/`                | `DATA_DIR` एनवायरनमेंट वेरिएबल        |
| Docker      | `/app/data/` (माउंट किया गया वॉल्यूम) | `DATA_DIR` एनवायरनमेंट वेरिएबल        |
| XDG-अनुपालक | `$XDG_CONFIG_HOME/omniroute/`         | `XDG_CONFIG_HOME` एनवायरनमेंट वेरिएबल |

### डेटा डायरेक्टरी की फ़ाइलें

| फ़ाइल/डायरेक्टरी     | विवरण                                               |
| -------------------- | --------------------------------------------------- |
| `storage.sqlite`     | मुख्य डेटाबेस (प्रदाता, कॉम्बो, सेटिंग्स, कुंजियाँ) |
| `storage.sqlite-wal` | SQLite राइट-अहेड लॉग (अस्थायी)                      |
| `storage.sqlite-shm` | SQLite साझा मेमोरी (अस्थायी)                        |
| `call_logs/`         | अनुरोध पेलोड अभिलेखागार                             |
| `backups/`           | स्वचालित डेटाबेस बैकअप                              |
| `log.txt`            | लेगेसी अनुरोध लॉग (वैकल्पिक)                        |

## पूर्ण निष्कासन सत्यापित करें

अनइंस्टॉल करने के बाद, सत्यापित करें कि कोई फ़ाइल शेष नहीं है:

```bash
# वैश्विक npm पैकेज की जाँच करें
npm list -g omniroute 2>/dev/null

# डेटा डायरेक्टरी की जाँच करें
ls -la ~/.omniroute/ 2>/dev/null

# चल रही प्रक्रियाओं की जाँच करें
pgrep -f omniroute
```

यदि कोई प्रक्रिया अभी भी चल रही है, तो उसे रोकें:

```bash
pkill -f omniroute
```
