> **Mmelite ikpeazụ:** 2026-06-28 — v3.8.40

OmniRoute na-abịa na sistemụ plugin yiri nke WordPress. Plugins bụ ndekọ
nwere onwe ha — nke ọ bụla nwere manifest `plugin.json` na faịlụ mbata — ndị na-ejikọta
na usoro nhazi arịrịọ (`onRequest` / `onResponse` / `onError`) nakwa na
mmemme okirikiri ndụ (`onInstall` / `onActivate` / `onDeactivate` / `onUninstall`).

**Ebe Ahịa Plugin** bụ oyi akwa nchọpụta dị n'elu sistemụ ahụ. Ọ
na-enye katalọgụ plugins enwere ike ịgagharị ma wụnye. Na ndabara, katalọgụ ahụ bụ
obere ndekọ mkpụrụ arụnyere n'ime ya; onye nchịkwa nwere ike iduzi ya gaa na URL
ndekọ mpụga ahaziri iche, ebe a na-eme ka nchọta ahụ sie ike site na ihe nche SSRF
na-edozi DNS (lee [Nchekwa](#security)).

Ụzọ plugin ọ bụla bụ **maka loopback naanị** (Tier 1 — `LOCAL_ONLY`): plugins na-ebunye
ma na-agba koodu n'ime child processes, ya mere enweghị ike iru ụzọ ndị ahụ site na
isi mmalite na-abụghị loopback n'agbanyeghị nkwenye njirimara. Lee
[`docs/security/ROUTE_GUARD_TIERS.md`](../security/ROUTE_GUARD_TIERS.md).

## Ka o si dabara Together

```
Dashboard (/dashboard/plugins)
  ├─ "Installed" tab  → GET /api/plugins            (listPlugins)
  │                     POST /api/plugins/scan      (pluginManager.scan)
  │                     POST /api/plugins/{name}/activate|deactivate
  │                     DELETE /api/plugins/{name}   (uninstall)
  └─ "Marketplace" tab → GET /api/plugins/marketplace
                          → listMarketplacePlugins()
                            ├─ no custom URL → built-in SEED_REGISTRY
                            └─ custom URL → isSafeMarketplaceUrl() SSRF guard
                                          → safeOutboundFetch(guard:"public-only")
```

- **oyi akwa ndekọ** — `src/lib/plugins/marketplace.ts`: depụtara / na-enyocha katalọgụ ahụ, na-adaghachi na ndekọ mkpụrụ na ọdịda ọ bụla.
- **oyi akwa ndụ okirikiri** — `src/lib/plugins/manager.ts` (`pluginManager` singleton): wụnye, kwalite, rụọ ọrụ, gbanyụọ, iwepụ, nyocha, ibu mmalite.
- **Ngosipụta oyi akwa** — `src/lib/plugins/manifest.ts`: Zod schema + ndabara maka `plugin.json`.
- **Ihe nyocha** — `src/lib/plugins/scanner.ts`: na-achọpụta plugins na diski n'okpuru ndekọ ndekọ plugins.
- **Ibu Ibu** — `src/lib/plugins/loader.ts`: na-eme ka ngwa mgbakwunye ọ bụla na usoro Node.js dị iche iche na ndị na-ere ahịa na-akpọ oku IPC. Nwatakịrị ahụ abụghị igbe ájá (lee "Plugin execution iche" n'okpuru).

## Katalọgụ Ebe Ahịa

`listMarketplacePlugins()` (`src/lib/plugins/marketplace.ts`) na-eweghachi ndepụta
ihe `MarketplaceEntry`:

| Oghere        | Ụdị      | Nkọwa                                            |
| ------------- | -------- | ------------------------------------------------ |
| `name`        | string   | Aha plugin n'ụdị kebab-case                      |
| `version`     | string   | semver                                           |
| `description` | string   | Nchịkọta dị mkpirikpi                            |
| `author`      | string   | Onye odee / ụlọ ọrụ                              |
| `license`     | string   | NJ ikike n'ụdị SPDX                              |
| `downloadUrl` | string   | URL nbudata isi mmalite (ọ nwere ike ịbụ oghere) |
| `repository`  | string?  | URL repository nhọrọ                             |
| `tags`        | string[] | Tags ọchụchọ/nzacha                              |
| `downloads`   | number   | Ọnụọgụ nbudata                                   |
| `rating`      | number   | 0–5                                              |
| `verified`    | boolean  | Ma akara ntinye ahụ egosiri na a kwadoro ya      |
| `lastUpdated` | string   | Eriri ụbọchị yiri ISO                            |

Mgbe ahazighị URL ndekọ pụrụ iche, katalọgụ ahụ bụ
`SEED_REGISTRY` arụnyere n'ime ya (ugbu a `request-logger`, `rate-limiter`, `cost-tracker`, na

ndekọ mpụga ahaziri, ọ weghachite ọnọdụ na-abụghị `200`, ma ọ bụ weghachite ahụ
a na-amaghị, `listMarketplacePlugins()` na-edekọ ịdọ aka ná ntị ma laghachi na ndepụta mkpụrụ.

> Rịba ama: ejikọtala **katalọgụ** ebe ahịa (ịgagharị/ịchọ) site na mmalite ruo na njedebe, mana
> **nrụnye** otu-pịa sitere na katalọgụ ahụ amalitebeghị — bọtịnụ "Install" nke

## REST API

Ebe njedebe niile chọrọ nyocha njikwa (`requireManagementAuth`)** na** bụ loopback-naanị — `/api/plugins` na `/api/plugins/` ka edepụtara na `LOCAL_ONLY_API_PREFIXES` (`src/server/authz/routeGuard.ts`).

| Ebe njedebe                        | Usoro  | Nkọwa                                                      |
| ---------------------------------- | ------ | ---------------------------------------------------------- |
| `/api/plugins`                     | GET    | Ndepụta plugins arụnyere (nyocha `?status=` nhọrọ)         |
| `/api/plugins`                     | POST   | Wụnye ngwa mgbakwunye sitere na ndekọ aha ngwa mgbakwunye  |
| `/api/plugins/scan`                | POST   | Nyochaa ndekọ ihe mgbakwunye wee debanye aha plugins ọhụrụ |
| `/api/plugins/marketplace`         | GET    | Depụta ndenye katalọgụ ahịa                                |
| `/api/plugins/marketplace/install` | POST   | Wụnye ngwa mgbakwunye ahịa n'aha                           |
| `/api/plugins/[name]`              | GET    | Nweta nkọwa ngwa mgbakwunye arụnyere                       |
| `/api/plugins/[name]`              | DELETE | Wepu ngwa mgbakwunye                                       |
| `/api/plugins/[name]/activate`     | POST   | Gbanyụọ (ịkwado ndebanye aha + )                           |
| `/api/plugins/[name]/deactivate`   | POST   | Gbanyụọ (ọkụ `onDeactivate`, nko na-edebanye aha)          |
| `/api/plugins/[name]/config`       | GET    | Nweta ngwa mgbakwunye config + config schema               |
| `/api/plugins/[name]/config`       | PUT    | Melite nhazi ngwa mgbakwunye (nke kwadoro megide schema)   |

Ihe nzacha `GET /api/plugins` `status` na-anabata otu n'ime `installed` / `active` / `inactive` / `error`. Uru ezighi ezi na-eweghachi `400`.

### Depụta plugins arụnyere

```bash
curl http://localhost:20128/api/plugins \
  -H "Cookie: auth_token=..."
```

### Wụnye site na ụzọ mpaghara

```bash
curl -X POST http://localhost:20128/api/plugins \
  -H "Cookie: auth_token=..." \
  -H "Content-Type: application/json" \
  -d '{ "path": "/absolute/path/to/my-plugin" }'
```

`path` ga-abụrịrị otu** zuru oke** ụzọ na ndekọ** n'ime plugin isi mmalite ndekọ** : `plugin-sources` na-esote mgbọrọgwụ ngwa mgbakwunye, yabụ `~/.omniroute/plugin-sources/` na ndabara, ma ọ bụ `<parent of OMNIROUTE_PLUGINS_DIR>/plugin-sources/` mgbe edobere mgbanwe ahụ (`getPluginSourcesDir()` na `src/lib/plugins/installSource.ts`). Detuo ma ọ bụ mechie ngwa mgbakwunye ahụ nke mbụ. Ajụrụ ihe nrụnye na `400` mgbe ụzọ ahụ nwere `..` ma ọ bụ byte efu, dina n'èzí ndekọ ahụ, kpebie na mpụga ya site na symlink, nwere symlink nke ebumnuche ya dị na mpụga ya, ma ọ bụ mgbe ndekọ ahụ adịghị. Akwụkwọ ndekọ aha ga-enwerịrị `plugin.json` ziri ezi (ma ọ bụ bụrụ nne na nna nke otu). Na ịga nke ọma nzaghachi bụ `201` na ahịrị plugin arụnyere.

N'adịghị ka ụzọ ngwa mgbakwunye ndị ọzọ, nke a chọrọ nzere njikwa (nnọkọ dashboard ma ọ bụ igodo API jikwaa) ọbụlagodi mgbe nbanye nwere nkwarụ (`requireLogin=false`): itinye koodu abụghị ihe a na-amaghị ama. Otu a na-emetụta `POST /api/plugins/marketplace/install` (anụ ahụ `{ "name": "<plugin>" }`).

### Chọgharịa n'ahịa

```bash
curl http://localhost:20128/api/plugins/marketplace \
  -H "Cookie: auth_token=..."
```

### Melite nhazi ngwa mgbakwunye

```bash
curl -X PUT http://localhost:20128/api/plugins/my-plugin/config \
  -H "Cookie: auth_token=..." \
  -H "Content-Type: application/json" \
  -d '{ "config": { "level": "debug", "maxItems": 100 } }'
```

`PUT .../config` na-akwado ahụ megide `configSchema` ngwa mgbakwunye (kpọpụtara na ngosipụta) yana `validatePluginConfig()` sitere na `src/lib/plugins/manifest.ts`: a ga-ekwupụta igodo ọ bụla na atụmatụ ahụ, ụkpụrụ ga-adakọrịrị ụdị ekwuputara, mpaghara `number` sọpụrụ `min`/`max`, na mpaghara `select` ga-adabarịrị na `enum` ekwuputara. Mmebi ọ bụla na-alaghachi `400` na ọ nweghị ihe echekwara. Ngwa mgbakwunye na-ekwupụta na ọ nweghị `configSchema` enweghị igodo nhazi, ya mere a jụrụ arịrịọ a na `400` ("ngwa mgbakwunye anaghị ekwupụta igodo nhazi ọ bụla").

## Nhazi

### Ndekọ plugin

Plugin dị n'okpuru ndekọ data OmniRoute:

```
~/.omniroute/plugins/<plugin-name>/
  ├─ plugin.json
  └─ index.js          # (ma ọ bụ faịlụ ọ bụla manifest.main na-arụtụ aka na ya)
```

`getDefaultPluginDir()` (`src/lib/plugins/scanner.ts`) na-ekpebi ndekọ ahụ site na
nzọụkwụ atọ:

1. **`OMNIROUTE_PLUGINS_DIR`**, mgbe edobere ya — a na-eji ya kpọmkwem dịka ọ dị, n'agbanyeghị ihe `HOME` kwuru. Nke a bụ
   njikwa doro anya maka Docker/K8s, ebe a na-eme bind-mount nke osisi plugin n'ụzọ
   nke na-enweghịkarị ihe jikọrọ ya na ndekọ ụlọ nke container (#11827).
2. `<home>/.omniroute/plugins`, ebe `<home>` si na environment variables `HOME` / `USERPROFILE`
   abịa.
3. `/tmp/.omniroute/plugins`, mgbe process ahụ na-ebupụghị ebe obibi ọ bụla ma ọlị.

A na-edekọ ndekọ ekpebiri otu ugboro mgbe mmalite dịka `scanner.dir_resolved`, na-akpọ aha
ntinye meriri (`OMNIROUTE_PLUGINS_DIR`, `home`, ma ọ bụ `no-home-fallback`) — ya mere image
nke rutere na nzọụkwụ 3 na nzuzo na-ekwu ya, kama naanị ịkọpụta ndepụta plugin tọgbọ chakoo.
`POST /api/plugins/scan` na-achọpụta subdirectory ọ bụla nọ ebe ahụ nke nwere
`plugin.json` ziri ezi ma debanye ya; otu ndekọ ahụ bụkwa root ebe
`pluginManager.install()` na-edepụta plugin banye, ya mere override na-ebukọ nchọpụta na
nwụnye ọnụ.

> **`OMNIROUTE_PLUGINS_DIR` abụghị `OMNIROUTE_PLUGIN_PATH`.** A na-agụ nke ikpeazụ naanị site na
> CLI command-plugin loader (`bin/cli/plugins.mjs`) iji chọta ngwugwu npm `omniroute-cmd-*`
> ndị na-agbakwunye subcommand `omniroute` — ọ naghị emetụta runtime scanner
> a kọwara ebe a. Lee [PLUGINS.md](./PLUGINS.md) maka akụkụ ahụ.

### URL registry marketplace ahaziri iche

A na-agụ isi mmalite katalọgụ marketplace site na ntọala `pluginMarketplaceUrl`
(`src/lib/plugins/marketplace.ts` na-agụ `settings.pluginMarketplaceUrl`). Mgbe
edobere ya ka ọ bụrụ URL `http(s)`, `listMarketplacePlugins()` na-fetch URL ahụ ma nabata
ma JSON array nke ndenye dị n'ogo kachasị elu ma ọ bụ object nwere array `plugins`;
a na-ewepụ ndenye ndị na-enweghị `name` nke bụ string. Mgbe edoghị ya (ma ọ bụ mgbe fetch
dara na nchedo SSRF / weghachiri nzaghachi ọjọọ), a na-eji seed registry e wuru n'ime.

Taabụ "Marketplace" nke dashboard na-egosi field maka URL a (nke a na-agụghachi site na
`GET /api/settings`).

> Ndetu mmejuputa: omume "Save" nke dashboard na-eziga
> `pluginMarketplaceUrl` na `PATCH /api/settings`. N'oge edere nke a,
> ekwupụtaghị key a na `updateSettingsSchema`
> (`src/shared/validation/settingsSchemas.ts`), ya mere nyochaa na ọ na-adịgide na
> release gị tupu ịdabere na ya — ụzọ **ọgụgụ** (`getSettings()` →
> `listMarketplacePlugins()`) na-asọpụrụ key ahụ ozugbo ọ dị na settings
> store.

## Nchekwa

### Ụzọ tier — loopback naanị

Ngwa mgbakwunye na-arụ koodu n'ime usoro ụmụaka agbasapụtara, ya mere a na-ekewa elu `/api/plugins` dum `LOCAL_ONLY` (Tier 1). Mmanye loopback na-aga n'enweghị ihe ọ bụla** mbụ** nlele auth ọ bụla, yabụ akara njikwa leaked na-eru igbe n'elu ọwara enweghị ike ịwụnye, rụọ ọrụ, ma ọ bụ wepu ngwa mgbakwunye. Hụ [`docs/security/ROUTE_GUARD_TIERS.md`](../security/ROUTE_GUARD_TIERS.md) na Iwu siri ike #15 / #17.

### Ebe nchekwa ndekọ SSRF nche

Ndebanye aha URL omenala bụ nhazi nke na-emetụta onye na-awakpo, yabụ tupu ị nweta ya `listMarketplacePlugins()` na-agba ya n'ọkwa abụọ:

1. **`isSafeMarketplaceUrl(url)`** (`src/lib/plugins/marketplace.ts`):
   - Na-ajụ ihe ọ bụla na-abụghị `http:` / `https:`.
   - Na-ajụ ndị ọbịa private/loopback/link-local/ULA nkịtị (IPv4** na** IPv6, gụnyere IPv4-mapped) site na canonical `isPrivateHost` (`src/shared/network/outboundUrlGuard.ts`).
   - Na-edozi** ha abụọ** `A` na `AAAA` ndekọ ma na-ajụ ma ọ bụrụ** nke ọ bụla** Adreesị edoziziri bụ — nkeonwe na-emechi aha ọha-onye ọbịa → nzuzo-IP uzo.
   - **Emechiri emechi** : ọdịda mkpebi DNS jụrụ URL.
2. **`safeOutboundFetch(url, { guard: "public-only", timeoutMs: 5000 })`** (`src/shared/network/safeOutboundFetch.ts`): na-etinyekwa onye nche URL naanị ọha na eze n'oge ewepụtara na** na-egbochi redirects** (enweghị → ọha `30x` pivot nzuzo).

URL nke na-ada n'ụdị ọ bụla anaghị ewepụ arịrịọ — ebe a na-ere ahịa na-adaba jụụ na ndekọ mkpụrụ nke arụnyere ma dekọọ ịdọ aka ná ntị.

> Onye nche a gbasiri ike na PR #3774 kpọmkwem iji dozie A + AAAA wee jiri canonical `isPrivateHost` kama nlele IPv4-only.

### Mwepu ngwa mgbakwunye

> **Ejighi ndabara tinye ihe mgbakwunye.** Nwatakịrị bụ usoro Node.js nkịtị na-agba ọsọ dị ka onye ọrụ OmniRoute, na-enweghị ọnọdụ VM na enweghị ọkọlọtọ ikike Node.js, yabụ ngwa mgbakwunye koodu nwere ike ịgụ ma dee faịlụ ọ bụla onye ọrụ nwere ike, mee mmemme wee rute netwọkụ. `requires.permissions` na-ekpebi naanị ụdị mgbanwe gburugburu ebe nwa na-enweta; A naghị etinye ikike ndị ọzọ. Ọkọlọtọ Nwepu-na `PLUGIN_PERMISSION_MODEL_ENABLED` (gbanyụọ na ndabara) na-agba ngwa mgbakwunye ọ bụla n'okpuru ụdị ikike Node.js wuru site na ikike ndị ahụ, ewezuga `network`, nke Node.js enweghị ike igbochi (lee [`PLUGIN_SDK.md`](./PLUGIN_SDK.md#sistem%E1%BB%A5-ikike) ). Wụnye naanị plugins ị tụkwasịrị obi. Oke usoro dị n'okpuru nwere mkpọka na kpọgidere; ọ bughi ókè-ala nche.

- **Kewapụ usoro** — `loadPlugin()` (`src/lib/plugins/loader.ts`) na-ewepụta ngwa mgbakwunye ọ bụla na usoro Node.js nwa dị iche ma na-ekwurịta okwu n'elu IPC. Oku nko nwere oge nkwụsị na mmụba `SIGTERM` → `SIGKILL`.
- **Ndepụta ikike Env** — nwa ahụ na-enweta naanị ndenye aha aha nke mgbanwe gburugburu ebe obibi; A na-enye ntọala sara mbara naanị mgbe ihe ngosi ahụ rịọrọ ikike `env`.
- **Wụnye njide isi mmalite** — `POST /api/plugins` na-agụ naanị site na akwụkwọ ndekọ aha ngwa mgbakwunye (lee "Wụnye site na mpaghara mpaghara"): a na-ahazi ụzọ ahụ na `realpath`, ga-anọrịrị n'ime akwụkwọ ndekọ ahụ, na osisi isi iyi na-ebu symlink nke na-agbanarị a jụrụ tupu e depụtaghachi ihe ọ bụla.
- **njide ụzọ** — install/upgrade/uninstall kwuputara na ndekọ ngwa mgbakwunye na `manifest.main` kpebiri** n'ime** mgbọrọgwụ ngwa mgbakwunye a na-achịkwa tupu mbipụta ma ọ bụ ihichapụ ọ bụla (na-eche nche megide ụzọ DB emejọ na `../` traversal na `manifest.main`). Mmalite na-edozi symlinks site na `realpath` wee jụ ịkwanye ebe ntinye na-agbanarị ndekọ ngwa mgbakwunye.
- **Ntụtụ iguzosi ike n'ezi ihe nhọrọ** — ihe ngosi nwere ike kwupụta mpaghara `integrity` (`sha256-<base64>`, usoro SRI ). Mgbe ọ dị, onye na-ebu ibu na-enyocha hash faịlụ ntinye n'oge ibu ma jụ ịgbalite na enweghị nkwekọrịta. Ọ bụ Nwepu-nchọpụta mebie,** ọ bụghị** oke nchekwa: ọ naghị ejedebe ihe ngwa mgbakwunye eburu ibu nwere ike ime.
- **Enweghị nzere ndị ahịa na nko** — ihe gbara ya gburugburu na `onRequest`, `onResponse` na `onError` ka ewepụrụ isi `authorization`, `x-api-key`, `proxy-authorization` na `cookie`, na ndekọ igodo API enweghị uru isi (`redactPluginContext()` na `src/lib/plugins/hooks.ts`).

## Usoro Lifecycle

```
install (POST /api/plugins, path)
  → nyochaa/kwado manifest → detuo ya na staging → hụ na main dị n'ime dir
  → jiri atomic rename bugharịa ya na ~/.omniroute/plugins/<name> → tinye ahịrị DB
  → kpọọ onInstall → ọ bụrụ na enabledByDefault: activate

activate (POST /api/plugins/{name}/activate)
  → lelee njide realpath → loadPlugin() (malite child process)
  → debanye hooks ndị ekwuputara → status = "active" → kpọọ onActivate

deactivate (POST /api/plugins/{name}/deactivate)
  → kpọọ onDeactivate (TUPU unregister) → unregister hooks
  → kwụsị child process → status = "inactive"

uninstall (DELETE /api/plugins/{name})
  → deactivate ma ọ bụrụ na ọ na-arụ ọrụ → kpọọ onUninstall
  → hichapụ plugin dir n'ụzọ recursive mgbe enyochachara njide ya → hichapụ ahịrị DB
```

Ịgba `install` ọzọ megide directory nke ụdị manifest ya **dị ọhụrụ karịa kpọmkwem**
ụdị arụnyere ga-eme auto-upgrade (nrụnye ọhụrụ dị ọcha; config ga-alaghachi
na defaults). A ga-ajụ ụdị bụ otu ma ọ bụ nke ochie.

## Dashboard

Ibe dashboard dị na `/dashboard/plugins` (`src/app/(dashboard)/dashboard/plugins/page.tsx`) na-enye taabụ abụọ:

- **arụnyere** — depụtara plugins arụnyere na nko ha ekwuputara, ihe ngbanwe activate/deactivate, bọtịnụ iwepụ, na ihe omume "Nyocha maka plugins" (`POST /api/plugins/scan`).
- **Ebe ahịa** — na-egosi katalọgụ si `GET /api/plugins/marketplace` nwere ubi iji tọọ ndekọ ahaziri URL.

Ibe ahụ na-egosi mgbe niile ịdọ aka ná ntị na plugins na-eji ikike zuru oke nke usoro OmniRoute.

Ibe nhazi ngwa mgbakwunye kwa-ebi na `/dashboard/plugins/[name]/config` (`src/app/(dashboard)/dashboard/plugins/[name]/config/page.tsx`).
