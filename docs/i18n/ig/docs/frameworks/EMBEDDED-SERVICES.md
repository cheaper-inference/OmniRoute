## 2. Architecture — 4 n'ígwé

```
┌────────────────────────────────────────────────────────────────────┐
│  Layer 1 — UI                                                      │
│  /dashboard/providers/services  (tabs: CLIProxyAPI | 9Router | Mux)│
│  Logs live (SSE), Start/Stop/Restart/Update, Settings, Install     │
│                                                                    │
│  src/app/(dashboard)/dashboard/providers/services/                 │
│    ├── page.tsx               Shell + tab routing by ?tab=         │
│    ├── tabs/                  CliproxyServiceTab, NinerouterServiceTab,│
│    │                          MuxServiceTab                        │
│    └── components/            ServiceStatusCard, ServiceLifecycleButtons,│
│                               ServiceLogsPanel, ApiKeyCard, ...    │
└──────────────────────┬─────────────────────────────────────────────┘
                       │ HTTP (Next.js fetch)
┌──────────────────────▼─────────────────────────────────────────────┐
│  Layer 2 — API (LOCAL_ONLY — loopback only)                        │
│                                                                    │
│  /api/services/9router/{install|start|stop|restart|update|         │
│                          rotate-key|status|auto-start|logs}        │
│  /api/services/cliproxy/{install|start|stop|restart|update|        │
│                           status|auto-start|logs}                  │
│  /api/services/mux/{install|start|stop|restart|update|             │
│                      status|auto-start|logs}                       │
│  /dashboard/providers/services/9router/embed/[...path]             │
│    (reverse HTTP + WebSocket proxy → 9Router upstream)             │
│                                                                    │
│  Gate: LOCAL_ONLY_API_PREFIXES includes "/api/services/" and       │
│        "/dashboard/providers/services/*/embed/"                    │
└──────────────────────┬─────────────────────────────────────────────┘
                       │ in-process calls
┌──────────────────────▼─────────────────────────────────────────────┐
│  Layer 3 — ServiceSupervisor (src/lib/services/)                   │
│                                                                    │
│  ServiceSupervisor.ts   Generic supervisor (child_process.spawn)   │
│    ├── install:    execFile('npm', ['install', pkg, '--prefix'])    │
│    ├── start:      spawn(node, [entrypoint], {env, cwd})           │
│    ├── api_key:    crypto.randomBytes(32) → env NINEROUTER_API_KEY  │
│    ├── port:       20130 for 9Router (configurable)                │
│    ├── logs:       stdio ring buffer 5 MB → SSE events             │
│    ├── health:     HTTP GET /health every 2–5 s, lazy recovery     │
│    └── lifecycle:  SIGTERM 15 s → SIGKILL                          │
│                                                                    │
│  registry.ts        getSupervisor(name) / registerSupervisor()     │
│  bootstrap.ts       Bootstraps all SERVICES[] at process start     │
│  apiKey.ts          getOrCreateApiKey(), generateServiceApiKey()   │
│  modelSync.ts       Periodic GET /v1/models → service_models table │
│  ringBuffer.ts      Circular log buffer (5 MB per service)         │
│  healthCheck.ts     Polling HTTP health probe                      │
│  installers/        ninerouter.ts, cliproxy.ts, mux.ts, openwa.ts  │
│                      (installer adapters)                          │
└──────────────────────┬─────────────────────────────────────────────┘
                       │ OpenAI-compatible HTTP (loopback)
┌──────────────────────▼─────────────────────────────────────────────┐
│  Layer 4 — Provider / Routing                                      │
│                                                                    │
│  open-sse/executors/ninerouter.ts                                  │
│    Re-looks up port and API key per-request (no caching).          │
│    Strips "9router/" prefix from model id before proxying.         │
│    Returns 503 service_not_running if supervisor not in "running". │
│                                                                    │
│  src/shared/constants/providers.ts                                 │
│    Entry for "9router": isEmbeddedService: true                    │
│                                                                    │
│  open-sse/config/providerRegistry.ts                               │
│    Models stored as "9router/{sub}/{model}" (prefixed).            │
│    Synced every 5 min by modelSync.ts.                             │
│                                                                    │
│  Mux is lifecycle-managed ONLY (Layers 1-3) — it is an agent-       │
│  orchestration daemon, not an LLM proxy, so it has no Layer 4      │
│  executor/provider entry and is never a routing target.            │
└────────────────────────────────────────────────────────────────────┘
```

## 3. Igwe ọnọdụ okirikiri ndụ

```
                    install()
  ┌─────────────┐ ──────────► ┌─────────────┐
  │ not_installed│             │   stopped   │◄──────────────────┐
  └─────────────┘             └──────┬──────┘                   │
                                     │ start()                   │
                                     ▼                           │ stop()
                               ┌──────────┐                      │
                               │ starting │                      │
                               └────┬─────┘                     │
             nyocha ahụike dị mma   │         ndakpọ / SIGTERM  │
                               ┌────▼─────┐  (ọpụpụ n'ime 5s)   │
                               │ running  │──── ndakpọ ─────────►┤
                               └────┬─────┘                   ┌─▼────┐
                             stop() │                          │error │
                                    ▼                          └──────┘
                               ┌──────────┐
                               │ stopping │
                               └──────────┘
```

A na-echekwa ọnọdụ na tebụl DB `version_manager` (kọlụm `status`) ma na-emepụtakwa ha
n'ọnọdụ ebe nchekwa `ServiceSupervisor`. Ọnọdụ ebe nchekwa bụ nke a ga-adabere na ya maka
usoro na-arụ ọrụ; ọnọdụ DB bụ ndabere na-adịgide adịgide mgbe a na-ebido sistemụ.

### Mgbanwe ọnọdụ

| Site na         | Ihe omume                            | Gaa na                   |
| --------------- | ------------------------------------ | ------------------------ |
| `not_installed` | `install()` gara nke ọma             | `stopped`                |
| `stopped`       | akpọrọ `start()`                     | `starting`               |
| `starting`      | nyocha ahụike weghachiri 200         | `running`                |
| `starting`      | usoro kwụsịrị tupu ọ dị mma          | `error`                  |
| `running`       | akpọrọ `stop()`                      | `stopping` → `stopped`   |
| `running`       | usoro kwụsịrị na-atụghị anya (< 5 s) | `error` (ndakpọ ọsọ ọsọ) |
| `running`       | usoro kwụsịrị na-atụghị anya (> 5 s) | `error`                  |
| `error`         | akpọrọ `start()`                     | `starting`               |
| nke ọ bụla      | `stop()` mgbe ọ nọ na `stopping`     | enweghị ihe a ga-eme     |

### Mkpọchi ọrụ

`ServiceSupervisor` na-ahazi ọrụ okirikiri ndụ n'otu n'otu site na mkpọchi ọrụ async
(`withLock()`). Ọkpụkpọ `start()` ndị na-eme n'otu oge n'otu supervisor na-ebute naanị
otu mmalite usoro; onye kpọrọ nke abụọ na-echere ma weghachite ọnọdụ dị adị. Nke a na-egbochi
ọnọdụ mpi mgbe, dịka ọmụmaatụ, mmalite-akpaka na bọtịnụ UI malitere n'otu oge.

## 4. API

Ụzọ niile dị n'okpuru `/api/services/` bụ**LOCAL_ONLY** (naanị loopback, iwu siri ike #17). Arịrịọ ndị na-abụghị loopback na-enweta `403 LOCAL_ONLY` n'agbanyeghị akara nyocha.

### 4.1 9Router njedebe (ụzọ 11)

#### `POST /api/services/9router/install`

Wụnye 9Router site na npm. Na-emepụta `DATA_DIR/services/9router/` na `package.json` na `node_modules/` nke ya. Adịghị emegide na deps nke OmniRoute.

**Rịọ ahụ** (nhọrọ niile):

```json
{ "version": "latest" }
```

| Ubi       | Ụdị      | Ọdabara    | Nkọwa                                   |
| --------- | -------- | ---------- | --------------------------------------- |
| `version` | `string` | `"latest"` | npm ụdị mkpado ma ọ bụ semver iji wụnye |

**Azịza ya:**

| Ọnọdụ | Nkọwa                                                  |
| ----- | ------------------------------------------------------ |
| `200` | `{ ok: true, installedVersion: "x.y.z", path: "..." }` |
| `400` | Otu arịrịọ ezighi ezi ( ọdịda nkwado Zod )             |
| `409` | Ugbua etinyere (njide mkpọchi)                         |
| `500` | npm wụnye dara — hụ `message` maka njehie enyi         |

**ndetu:** Na-eji `execFile('npm', [...])` — enweghị shei, enweghị interpolation (iwu siri ike #13). A na-egosiputa njehie EACCES dị ka ozi enyi na enyi.

---

#### `POST /api/services/9router/start`

Malite 9Router. Debanye aha onye nlekọta ma ọ bụrụ na edebeghị aha ya, wee kpọọ `supervisor.start()`. Enweghị ike mgbe ọ na-agba ọsọ.

**Òtù rịọrọ:** onweghi

**Azịza ya:**

| Ọnọdụ | Nkọwa                                               |
| ----- | --------------------------------------------------- |

### 4.9 Reverse proxy (9Router dashboard agbakwunyere)

Dashboard ahụ na-etinye 9Router web UI n'ime iframe site na proxy nke ime na:

```
GET|POST|... /dashboard/providers/services/9router/embed/[...path]
```

Nke a proxy:

- Bugharịa arịrịọ ahụ na `http://127.0.0.1:{port}/{path}` (naanị loopback)
- Mwepu ndị isi `cookie` na `authorization` na-abata (enweghị nkwụsị nke nnọkọ OmniRoute )
- Na-agbanye `Authorization: Bearer {apiKey}` maka nyocha 9Router
- Mwepụ `set-cookie`, `content-security-policy`, `x-frame-options`, `cross-origin-*` na nzaghachi
- Na-edegharị nzaghachi HTML iji gbaa `<base href>` wee hazie ụzọ zuru oke (`/foo` → `/dashboard/.../embed/foo`)

WebSocket nkwalite maka dashboard agbakwunyere na-ejikwa ihe nkesa ibe na ọdụ ụgbọ mmiri raara onwe ya nye (lee `src/lib/services/embedWsProxy.ts`).

**Nchekwa:** Ụzọ proxy agbakwunyere bụ nkewa n'okpuru `LOCAL_ONLY_API_PREFIXES` na enwere ike ịnweta ya site na loopback. Onye mwakpo nke nwetara JWT site na ọwara Cloudflare/Ngrok enweghị ike onye nnọchi anya ọrụ agbakwunyere.

## 5. Nchekwa

### Mmanye LOCAL_ONLY (iwu siri ike #17)

A na-ekewa ụzọ niile dị n'okpuru `/api/services/` na `/dashboard/providers/services/*/embed/`
dị ka LOCAL_ONLY n'ime `src/server/authz/routeGuard.ts`. Nlele loopback
na-agba ọsọ mgbe niile tupu ngalaba nyocha njirimara ọ bụla:

```
arịrịọ bịarutere
  → isLocalOnlyPath(path)?
      → abụghị loopback → 403 LOCAL_ONLY (mgbe niile, tupu nlele njirimara)
      → loopback        → gaa n'ihu na nyocha njirimara nkịtị
```

Nke a na-egbochi JWT agbapụtara (dịka ọmụmaatụ, site na tunnel) ịkpalite `npm install` ma ọ bụ
ịmalite process. Lee `docs/security/ROUTE_GUARD_TIERS.md` maka matriks tier
zuru ezu.

### Itinye API key

9Router na Mux chọrọ API key/bearer token maka endpoint HTTP nke ha.
OmniRoute:

1. Na-emepụta key site na `crypto.randomBytes(32).toString("base64url")` nke nwere
   prefix pụrụ iche maka service (`nr_` maka 9Router, `mx_` maka Mux).
2. Na-eji AES-256-GCM ezoro ya ezo mgbe echekwara ya (otu cipher ahụ a na-eji maka credentials provider).
3. Na-ewepụ nzuzo ya ma tinye ya dịka environment variable n'oge spawn —
   `NINEROUTER_API_KEY` maka 9Router, `MUX_SERVER_AUTH_TOKEN` maka Mux (ọ bụghị CLI
   flag ma ọlị, ka token ahụ ghara ịpụta na `ps`/ndepụta process).
4. Ọ dịghị mgbe ọ na-eweghachi key plaintext na nzaghachi HTTP ọ bụla.

CLIProxyAPI na-enweta key data-plane raara onwe ya nye nke a na-etinye n'oge spawn
(`needsApiKey: true` — a na-eji ya maka mmekọrịta model sync na adapter).

### Nchedo SSRF

E debere reverse HTTP proxy (`/dashboard/.../embed/[...path]`) ka o zipụ
naanị na `http://127.0.0.1:{port}`. Ọ dịghị mgbe ọ na-eso redirects gaa ebe
na-abụghị loopback. A na-eji library `ssrf-req-filter` ajụ URL upstream ọ bụla nke
na-resolve n'èzí loopback range.

### Nchekwa shell (iwu siri ike #13)

A na-akpọ `npm install` site na `execFile('npm', ['install', pkg, '--prefix', dir])` —
enweghị template literals, enweghị shell, enweghịkwa itinye external paths n'ime command
string site na interpolation. A na-ebufe runtime values (ports, API keys) site na object `env` nke child ahụ.

### Nhicha error (iwu siri ike #12)

Nzaghachi error niile sitere na `/api/services/*` na-agafe na `buildErrorBody()` ma ọ bụ
`sanitizeErrorMessage()`. Ọ dịghị mgbe a na-eweghachi raw `err.stack` na `err.message`
kpọmkwem nye onye kpọrọ ya.

### Nzọụkwụ 2 — Debanye aha na bootstrap

#### Nkwekọrịta provider-plugin enwere ike itinye dochie ọzọ (Phase 1, #7333)

`src/lib/services/providerPlugins/` na-ewebata nkwekọrịta `ServiceProviderPlugin` nke
na-achịkọta fields `ServiceEntry` nke `bootstrap.ts` nke backend na fields manifest-template
nke `serviceBackends.ts` n'ime otu object, kama ịkọwa ọdịdị otu backend ahụ
iche iche n'ime faịlụ abụọ na-enweghị njikọ. Ka ọ dị n'oge a na-ede ihe a, **naanị `9router` ka
ebufere** — `bootstrap.ts` na-enweta entry `SERVICES[]` ya site na
`getServiceProviderPlugin("9router")` (`src/lib/services/providerPlugins/registry.ts`),
ma na-atụpụ startup error ma ọ bụrụ na plugin ahụ efuo n'oge ọ bụla. `cliproxy`, `mux`, na `bifrost`
ka na-eji inline literals `SERVICES[]` dịbu adị na-enweghị mgbanwe.

`open-sse/config/providerPluginManifest.ts` nwetakwara helper mgbakwunye
`createServiceBackendManifestEntry(pluginId, template)` nke na-ewulite
`ProviderPluginManifestEntry` ahaziri nke ọma site na entry `SERVICE_BACKEND_MANIFEST_TEMPLATE` — e
**jikọbeghị** ya na live request path ọ bụla ugbu a (ma `generateProviderPluginManifestFromRegistry()`
ma `/v1/providers/[provider]/models`); nke ahụ ka bụ ọrụ ga-esochi mgbe egosiri na
nkwekọrịta ahụ na-arụ ọrụ maka backend nke abụọ.

E yigharịrị ihe ndị a gaa na PR ndị ga-esochi, nke a na-enyocha n'okpuru issue #7333: ibufe `cliproxyapi` site na
otu registry ahụ, ime ka `mux`/`bifrost` bụrụ akụkụ izugbe nke union `ServiceBackendPluginId`,
itinye special-casing nke executor-routing (`open-sse/executors/index.ts`,
`open-sse/handlers/chatCore/executorProxy.ts`) n'ime nkwekọrịta plugin, na ijikọ
`createServiceBackendManifestEntry()` na live manifest/models code path.

## 7. Nchọpụta na ndozi nsogbu

### Ọrụ anaghị amalite

**Mgbaàmà:** Bọtịnụ mmalite na-eweghachi 503, ọnọdụ na-anọgide na `"error"` ma ọ bụ `"starting"`.

**Ndepụta nyocha:**

1. Lelee `GET /api/services/{name}/logs` (ma ọ bụ ogwe Logs dị na dashboard). Chọọ
   ahịrị dịka `Error: ENOENT`, `address already in use`, ma ọ bụ `Cannot find module`.
2. Nyochaa na `npm` dị na PATH: jiri `which npm` site n'otu akaụntụ onye ọrụ ahụ na-agba OmniRoute.
3. Nyochaa na arụnyere ọrụ ahụ: lelee `GET /api/services/{name}/status` maka
   `installedVersion`. Ọ bụrụ na ọ bụ `null`, buru ụzọ mee nrụnye.
4. Lelee na `DATA_DIR/services/{name}/node_modules/` dị ma ọ bụghị ihe tọgbọ chakoo.
5. Lelee oghere `lastError` na nzaghachi ọnọdụ maka ihe kpatara nkwụsị ahụ nke e mere ka ọ dị nchebe.

---

### Mmalite oyi na-adị nwayọọ (> 10 s iji ruo `running`)

**Mgbaàmà:** Ọnọdụ na-anọgide na `"starting"` ogologo oge tupu ọ gaa na `"running"` ma ọ bụ `"error"`.

**Nkọwa:** Mmalite oyi nke 9Router gụnyere ibubata nnukwu osisi ndabere (DNS,
tunnel, modul MITM). Oge ndabara maka nyocha ahụike bụ 2 s, yana mbọ 3 tupu
supervisor ekwupụta na oge agwụla (mana ọ na-aga n'ihu na-enyocha).

**Ndozi:** Enwere ike ịhazi oge nkwụsị `healthIntervalMs` na `waitForHealthy`
(`healthIntervalMs * 3`) na `bootstrap.ts`. Maka ọrụ ndị na-ewe ogologo oge
ịmalite, bulie `healthIntervalMs` ruo 5000 na `stopTimeoutMs` ruo 30 000.

---

### Esemokwu ọdụ ụgbọ (`EADDRINUSE`)

**Mgbaàmà:** Logs na-egosi `address already in use :::20130`.

**Ihe kpatara ya:**

- Usoro ọzọ na-eji ọdụ ụgbọ 20130 ugbu a.
- Usoro 9Router gara aga akwụsịghị kpamkpam (PID zombie).

**Ndozi:**

1. Gbanwee ọdụ ụgbọ ndabara site na mgbanwe gburugburu `NINEROUTER_PORT` n'ime `.env`.
2. Chọta ma kwụsị usoro na-akpata esemokwu ahụ: `lsof -ti :20130 | xargs kill -9`.
3. Enwere ike ịhazi ọdụ ụgbọ maka ọrụ ọ bụla na `bootstrap.ts` site na oghere `port`.

**Rịba ama:** 9Router na-eji ọdụ ụgbọ 20130 na ndabara kpọmkwem iji zere esemokwu na
ọdụ ụgbọ ndabara 20128 nke OmniRoute.

---

### Ajụrụ ikike (EACCES) n'oge nrụnye

**Mgbaàmà:** Nrụnye na-eweghachi 500, logs na-egosi `EACCES` ma ọ bụ `permission denied`.

**Ihe kpatara ya:**

- Usoro OmniRoute enweghị ikike ide ihe na `DATA_DIR` ma ọ bụ ndekọ nne na nna ya.
- Ịgba ọsọ n'ime Docker rootless na-enweghị ikike ide ihe na volume e jikọtara.

**Ndozi:**

1. Lelee `DATA_DIR` (ndabara: `~/.omniroute/`): `ls -la ~/.omniroute/`
2. Gbaa mbọ hụ na onye ọrụ nke usoro OmniRoute bụ onye nwe ndekọ ahụ: `chown -R $USER ~/.omniroute/`
3. N'ime Docker, gbaa mbọ hụ na volume mount nwere ikike ziri ezi maka onye ọrụ container ahụ.

---

### Mmelite anaghị aga nke ọma (oge `npm install` agwụla ma ọ bụ njehie netwọkụ)

**Mgbaàmà:** Mmelite na-eweghachi 500 yana `InstallError`, logs na-egosi na oge netwọkụ agwụla.

**Ndepụta nyocha:**

1. Kwenye na enwere ike iru npm registry: `npm ping`.
2. Lelee ma e nwere proxy ụlọ ọrụ: `npm config get proxy`, `npm config get https-proxy`.
3. Gbalịa iji aka mee nrụnye ahụ: `npm install {package}@latest --prefix ~/.omniroute/services/{name}/`.
4. Ọ bụrụ na ị nọ n'azụ air-gap, buru ụzọ budata tarball ahụ ma jiri `npm install /path/to/tarball.tgz`.

---

### Ọrụ na-egosi ọnọdụ `"error"` ozugbo ọ malitechara (nkwụsị ngwa ngwa)

**Mgbaàmà:** Ọnọdụ na-agbanwe site na `"starting"` gaa na `"error"` n'ime ihe na-erughị sekọnd 5.
`lastError` na-egosi `"Fast crash (exited with code 1)"`.

**Ndepụta nyocha:**

1. Gụọ njedebe log zuru ezu: `GET /api/services/{name}/logs?tail=500`.
2. Ihe na-akpatakarị ya: mgbanwe gburugburu ndị ọrụ ahụ na-atụ anya adịghị.
3. Maka 9Router: nyochaa na `NINEROUTER_DISABLE_MITM=true` na
   `NINEROUTER_DISABLE_TUNNEL=true` dị na env ebufere n'oge spawn (lee
   `installers/ninerouter.ts` `resolveSpawnArgs`).

## 8. Ajụjụ ndị a na-ajụkarị

**Ajụjụ: Enwere m ike ime ka endpoint nke ọrụ ndị agbakwunyere dịrị ndị ahịa na-abụghị loopback?**

Mba. Ọkwa LOCAL_ONLY bụ ihe e mere ụma (iwu siri ike #17). Route ndị nwere ike ịkpọ
`npm install` ma ọ bụ ịmalite process `node` agaghị abụ ndị traffic na-abụghị loopback
nwere ike iru, n’ihi na JWT e kpughere site na tunnel (Cloudflare, Ngrok, Tailscale)
ga-eme ka e nwee ike ịmalite process ọ bụla. Enweghị ohere ịpụ na iwu a maka
`/api/services/` — n’adịghị ka `/api/mcp/`, ewepụla ya na ndepụta ndị nwere ike ịgafe
manage-scope. Lee `docs/security/ROUTE_GUARD_TIERS.md`.

---

**Ajụjụ: 9Router na CLIProxyAPI hà ga-adị na deployment production/cloud?**

Ee. Ọrụ abụọ ahụ na-agbaso otu model local-first ahụ OmniRoute n’onwe ya na-agbaso.
Ha na-arụ ọrụ n’otu igwe ma na-ekwurịta okwu site na loopback. “Production” n’ebe a
pụtara VPS ma ọ bụ sava mpaghara e tinyere OmniRoute na ya, ọ bụghị provider cloud
dịpụrụ adịpụ.

---

**Ajụjụ: Olee otu m ga-esi debug supervisor?**

1. Soro stream log SSE: `curl -N http://localhost:20128/api/services/9router/logs`.
2. Lelee log ahaziri ahazi na output pino nke OmniRoute, nke e ji namespace
   `service:supervisor` nyochaa.
3. Nyochaa row DB: `sqlite3 ~/.omniroute/omniroute.db "SELECT * FROM version_manager WHERE tool='9router'"`.
4. Jiri `GET /api/services/9router/status` hụ state dị ugbu a, PID, health,
   na `lastError` n’otu oku.

---

**Ajụjụ: Supervisor na-egosi `health: "degraded"` ma ọ bụ `health: "unknown"` mana state bụ `"running"`. Nke ahụ ọ bụ nsogbu?**

`"degraded"` pụtara na health probe weghachiri response na-abụghị 200. `"unknown"`
pụtara na ọ nweghị probe mechara (ọsọ dị n’etiti ya na poll mbụ). Ha abụọ na-adị
nwa oge mgbe startup na-eme. Ọ bụrụ na health anọgide na-abụ `"degraded"` ruo ihe
karịrị `healthIntervalMs * 3` ms mgbe ọ ghọrọ `"running"`, ọrụ agbakwunyere ahụ
na-arụ ọrụ mana HTTP API ya anaghị aza. Lelee ma port ahụ ò ziri ezi na status
response nakwa ma ọrụ ahụ ọ̀ na-ege ntị n’ezie na port ahụ.

---

**Ajụjụ: Enwere m ike ịgbanwe API key nke 9Router n’emeghị restart zuru ezu?**

Mba. A na-enyefe 9Router API key site na environment variable mgbe a na-amalite
process. A pụghị ịgbanwe environment variable n’ime process na-arụ ọrụ. `POST .../rotate-key`
na-akwụsị ma malitegharịa ọrụ ahụ na-akpaghị aka ka o jiri key ọhụrụ ahụ. Mgbanwe key
ahụ na-amalite ịrụ ọrụ n’ime `stopTimeoutMs` nke ọrụ ahụ (default bụ 15 s) gbakwunyere
oge startup ya.

---

**Ajụjụ: Gịnị bụ oke ring buffer, gịnịkwa na-eme mgbe o juputara?**

Ọrụ ọ bụla nwere ring buffer 5 MB nke ya. Mgbe buffer ahụ juputara, a na-ewepụ
ahịrị log ndị kacha ochie iji nye ndị ọhụrụ ohere. Event SSE `snapshot` na-eweghachi
ahịrị ndị kacha ọhụrụ n’ime oke `tail`. A naghị echekwa log na disk ọ gwụla ma
edobere `logsBufferPath` na row DB ahụ.
