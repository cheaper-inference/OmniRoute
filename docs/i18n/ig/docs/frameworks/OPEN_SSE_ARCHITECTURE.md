## Gịnị Mere E Ji Nwee Ngwugwu Workspace Dị Iche?

`open-sse/` bụ **workspace kwụụrụ onwe ya** n'ime monorepo OmniRoute n'ihi ọtụtụ ihe:

1. **Enwere ike iji ya ọzọ** — a na-ebipụta `open-sse` dị ka `@omniroute/open-sse` na npm, ya mere ọrụ ndị ọzọ nwere ike iji ya n'onwe ha
2. **Oke doro anya** — e kewapụrụ injin nkwanye data ahụ na oyi akwa UI/DB nke OmniRoute
3. **Ọsọ arụmọrụ** — injin ahụ enweghị ndabere Next.js, nke na-eme ka mmalite oyi dị ngwa karịa n'ọnọdụ CLI/serverless
4. **Njikwa ụdị** — `open-sse` nwere ike iwepụta ụdị ọhụrụ dịka usoro oge nke ya si dị


## Usoro Nhazi Arịrịọ

Arịrịọ LLM ọ bụla na-agafe **usoro nwere ọkwa 5**:

```
                              ┌──────────────┐
   Arịrịọ HTTP                 │  1. ROUTE    │   idozi combo, ịhọrọ model
   (ụzọ Next.js)               └──────┬───────┘
                                     │
                                     ▼
                              ┌──────────────┐
                              │  2. TRANSLATE│   ntụgharị usoro (OpenAI ↔ Claude ↔ Gemini)
                              └──────┬───────┘
                                     │
                                     ▼
                              ┌──────────────┐
                              │  3. EXECUTE  │   executor onye na-eweta ọrụ, HTTP, nnwale ọzọ, breaker
                              └──────┬───────┘
                                     │
                                     ▼
                              ┌──────────────┐
                              │  4. STREAM   │   mgbanwe SSE, backpressure
                              └──────┬───────┘
                                     │
                                     ▼
                              ┌──────────────┐
                              │  5. RECORD   │   nsuso ojiji, ndekọ oku, nhazi njehie
                              └──────┬───────┘
                                     │
                                     ▼
                              Nzaghachi HTTP (SSE ma ọ bụ JSON)
```

### Ọkwa 1: Duzie Ụzọ (services/combo.ts)

**Ebe ntinye**: `handleComboChat()` dị na `services/combo.ts`

Ọ na-edozi arịrịọ ahụ ka ọ bụrụ tuple `(provider, model, account, credentials)` doro anya:

- Chọta combo site na ID (ma ọ bụ wuo combo mebere maka model `auto/*`)
- Tinye atụmatụ ndugharị ụzọ n'ọrụ (mkpa, ịdị arọ, round-robin, wdg.)
- Wepụ ndị na-eweta ọrụ na-adịghị arụ ọrụ nke ọma (circuit breaker)
- Họrọ ebe ọzọ nwere ike ịrụ ọrụ

Maka model `auto/*`, ọkwa a na-emekwa ihe ndị a:

- Na-agba algọridim **ntule ihe 16** (`services/autoCombo/`)
- Na-ahọrọ ụzọ abụọ `provider+model` dabere na ahụike, ọnụ ahịa, latency, wdg.

### Ọkwa 2: Tụgharịa (translator/)

Ọ bụrụ na usoro isi mmalite (dịka ọmụmaatụ, OpenAI) dị iche na usoro ebe a na-aga (dịka ọmụmaatụ, Claude), a na-**atụgharị** arịrịọ ahụ:

- System prompt → system message
- Nkọwa ngwa ọrụ → usoro ngwa ọrụ pụrụ iche nke onye na-eweta ọrụ
- Paramita reasoning/thinking → ihe kwekọrọ na ha nke onye na-eweta ọrụ
- Ịhazigharị role ozi (`developer` → `system` maka ndị na-abụghị OpenAI)

`translator/index.ts` na-ekpughe:

```ts
translateRequest(body, sourceFormat, targetFormat): TranslatedRequest
needsTranslation(source, target): boolean
```

### Ọkwa 3: Mee (executors/)

**Ebe ntinye**: `getExecutor(providerId).execute(request, options)`

Ndị na-eweta ọrụ niile na-eji `DefaultExecutor` (`executors/default.ts`) site na fallback nke factory `getExecutor()`. Executor ahụ:

- Na-ewu URL upstream (`buildUrl()`)
- Na-agbakwunye headers pụrụ iche nke onye na-eweta ọrụ (`buildHeaders()`)
- Na-agbanwe body arịrịọ (`transformRequest()`)
- Na-eziga arịrịọ HTTP yana nnwale ọzọ + exponential backoff
- Na-ahụ maka auth refresh ma ọ bụrụ na ọ dị mkpa (ndị na-eweta ọrụ OAuth)

Executor niile na-eketa `BaseExecutor` (`executors/base.ts`, ahịrị koodu 1170), nke na-enye:

- Usoro nnwale ọzọ nkịtị
- Njikọ proxy
- Njikọ circuit breaker
- Hooks maka idekọ ojiji

### Ọkwa 4: Kwasaa Data (utils/stream.ts)

Maka nzaghachi ndị a na-akwasa, executor na-eweghachi **ReadableStream**. Handler ahụ:

- Na-ebufe ya site na mgbanwe SSE (`createSSETransformStreamWithLogger`)
- Na-etinye heartbeat pings iji chọpụta njikọ ndị kwụsịrị
- Na-ejikwa nkwụsị njikọ client nke ọma (`pipeWithDisconnect`)
- Na-agbanwe SSE → JSON maka client ndị na-anaghị eji nkwasa data

Maka nzaghachi ndị anaghị eji nkwasa data, executor na-eweghachi object JSON a haziri, nke a na-ebufe n'enweghị mgbanwe.

### Ọkwa 5: Dekọọ (services/usage.ts)

Mgbe nzaghachi gasịrị (ma ọ gara nke ọma ma ọ bụ daa), a na-edekọ ojiji:

- `prompt_tokens`, `completion_tokens`, `cached_tokens` sitere na nzaghachi ahụ
- `cost_usd` nke a gbakọrọ site na data ọnụahịa
- `latency_ms`, `status`, `error_class` ma ọ bụrụ na ọ daa
- A na-echekwa ya na tebụl `usage_history`

A na-ede ihe ndekọ oku (ọ bụrụ na agbanyere ya) na `${DATA_DIR}/call_logs/`.

### chatCore.ts (ahịrị 5977)

Nke** onye isi arịrịọ** . N'agbanyeghị nha ya, ọ nwere nhazi doro anya:

```ts
// Pseudo-structure of chatCore.ts
export async function handleChat(request: NextRequest) {
  // 1. Auth + CORS
  await authenticateRequest(request);
  applyCorsHeaders(response);

  // 2. Body validation
  const body = await parseRequestBody(request);

  // 3. Format detection + translation
  const sourceFormat = detectFormat(request);
  const targetFormat = getTargetFormat(providerId);
  if (needsTranslation(sourceFormat, targetFormat)) {
    body = translateRequest(body, sourceFormat, targetFormat);
  }

  // 4. Combo routing
  const targets = await resolveComboTargets(comboId, body);
  for (const target of targets) {
    try {
      const result = await executeOnTarget(target, body);
      await recordUsage(result);
      return result;
    } catch (err) {
      // Continue to next target
    }
  }

  // 5. Emergency fallback
  return await emergencyFallback(body);
}
```

N'agbanyeghị na ọ bụ otu nnukwu ọrụ, a haziri ya** ngalaba kwuru** map ahụ gaa na pipeline nke 5.

````
Karịrị otu faịlụ kwa onye na-eweta ya. Klaasị ndị mmebe niile na-agbatị `BaseExecutor` wee kpochapụ ihe dị iche; modul ndị ọzọ bụ ndị na-enyere onye ọ bụla aka (usoro ihe eji eme ihe, fetch/TTS adapters, quirk handlers).

### Ụkpụrụ nkịtị

A na-edozi ndị na-enye ya site na `getExecutor(providerId)`, nke na-eweghachite onye nhazi ahaziri. ndị na-enye OpenAI/Anthropic-compatible na-eji `DefaultExecutor` (`executors/default.ts`). A haziri omume akọwapụtara nke onye na-eweta ( URL, auth nkụnye eji isi mee, ụdị API ) na `open-sse/config/providers/`, ebe a na-edozi mgbanwe ahụ na `open-sse/translator/`.

**Omenala URL** atọrọ site na nhazi onye na-eweta:

```ts
// Provider config in open-sse/config/providers/
export default {
  id: "together",
  baseURL: "https://api.together.xyz/v1/chat/completions",
}
````

**Nyocha omenala** A na-edozi site na nhazi auth ndekọ nke onye na-eweta ( igodo API, OAuth, profaịlụ nkụnye eji isi mee ).

**Òtù arịrịọ omenala** mgbanwe (dịka ọmụmaatụ, Anthropic nkewapụ `system` na `messages`) ka edebanyere aha onye ọ bụla na `open-sse/translator/`.

````
### The Executor Factory

`executors/index.ts` exports `getExecutor(providerId)`:

```ts
import { getExecutor } from "@omniroute/open-sse/executors";

const executor = getExecutor("anthropic");
const result = await executor.execute({
  model: "claude-sonnet-4-5",
  messages: [...],

````

Mkpebi na-aga site na `ExecutorRegistry` (`executors/registry.ts`): A na-ekwupụta onye ọrụ ọ bụla pụrụ iche na tebụl wuru n'ime `executors/index.ts` wee debanye aha ya site na `registerExecutor(alias, instance)` na ibu modul; `getExecutor()` na-enyocha ndekọ ahụ wee daa azụ na `DefaultExecutor` echekwara n'isi maka onye na-eweta ọ bụla na-enweghị ntinye pụrụ iche. A na-eji eserese ọla edo mara → nke na-eme maapụ a na-akpọ `tests/unit/executor-map-golden.test.ts`.

## Ndị ntụgharị

Tụgharịa n'etiti **usoro 3**: OpenAI, Anthropic, Gemini, tinyere Responses API ọhụrụ.

### Mgbe Ntughari Na-eme

```ts
import { needsTranslation, translateRequest } from "@omniroute/open-sse/translator";

if (needsTranslation(sourceFormat, targetFormat)) {
  body = translateRequest(body, sourceFormat, targetFormat);
}
```

Ntughari ndị a na-ahụkarị:

- `OpenAI → Anthropic`: kewapụ ubi `system`, jiri nkụnyeisi `x-api-key`
- `OpenAI → Gemini`: jiri `contents` kama `messages`, `systemInstruction`
- `OpenAI → Responses API`: n'usoro n'usoro `input`, steeti `previous_response_id`

### Ọnọdụ Pụrụ Iche A Na-ahụ Maka Ha

- Ọrụ `developer` → `system` maka ndị na-abụghị OpenAI
- Ọrụ `system` → jikọta ya n'ime ozi onye ọrụ mbụ maka GLM/ERNIE
- `json_schema` → `responseMimeType` + `responseSchema` nke Gemini
- `tools` → usoro ngwa ọrụ akọwapụtara maka onye na-enye ọrụ ọ bụla
- Paramita echiche (o1, Claude) → ihe ha na ya hà nke onye na-enye ọrụ ọ bụla

## Sava MCP

`open-sse/mcp-server/` na-emejuputa sava **Model Context Protocol**:

- **Ngwa ọrụ 110** (njikwa ndị na-enye ọrụ, ngwakọta, ebe nchekwa, cache, mkpakọ, proxy, nkà, ime ka ọ dị ka egwuregwu, plugins, Notion, Obsidian, corpus mpaghara)
- **Ụzọ mbufe 3**: stdio, SSE, Streamable HTTP
- **Scopes 33** maka ikike nwere njikwa zuru ezu

### Ndebanye Aha Ngwa Ọrụ

A na-edebanye ngwa ọrụ dị ka faịlụ kwụụrụ onwe ha n'ime `open-sse/mcp-server/tools/`, nke ọ bụla na-ebupụ aha, schema, handler, na scope:

```ts
// open-sse/mcp-server/tools/getHealth.ts
import { z } from "zod";
export default {
  name: "omniroute_get_health",
  description: "Get system health snapshot",
  scope: "read:health",
  inputSchema: z.object({}),
  handler: async (_args, ctx) => {
    return await getSystemHealth();
  },
};
```

### Ụzọ Mbufe

```ts
// stdio (ojiji CLI)
startMcpStdio(server);

// SSE (nkwanye data dabere na HTTP)
startMcpSse(server, port);

// Streamable HTTP (MCP ọgbara ọhụrụ)
startMcpStreamable(server, port);
```

### Inye Ikike

Oku ngwa ọrụ ọ bụla na-agafe nyocha scope (`open-sse/mcp-server/auth/`):

```ts
if (!hasScope(apiKey, "providers:read")) {
  throw new Error("Insufficient scope");
}
```

## Ndị Ntụgharị Ọdịdị

`open-sse/transformer/` na-atụgharị n'etiti usoro **Chat Completions** na **Responses API**.

### Gịnị Mere E Ji Nwee Transformer Dị Iche?

Responses API bụ usoro ọhụrụ nke OpenAI nwere **mkparịta ụka na-edobe steeti** (`previous_response_id`). Mgbe onye ahịa zipụrụ arịrịọ Responses, OmniRoute:

1. Na-atụgharị Responses → Chat Completions n'ime sistemụ
2. Na-ezigara ya onye na-enye ọrụ (onye na-enye ọrụ ọ bụla na-akwado Chat Completions)
3. Na-atụgharị nzaghachi ahụ laghachi n'usoro Responses
4. Na-ezigara onye ahịa nzaghachi a tụgharịrị dị ka iyi data

Transformer (`transformer/responsesTransformer.ts`) na-enye:

```ts
createResponsesApiTransformStream(): TransformStream
```

Nke a na-ahụ maka:

- Ihe omume `response.output_item.added`
- Ihe omume `response.output_text.delta`
- Ihe omume `response.completed`
- Nhazi oku ngwa ọrụ (`function_call` ↔ `tool_calls`)

## Ụkpụrụ Ndị A Ga-ezere

❌ **Oku DB synchronous na `combo.ts`** — gbakọọ tupu oge eruo ma chekwaa na cache
❌ **Usoro ịnwa ọzọ n'ime handlers** — jiri `retry()` sitere na ọrụ resilience
❌ **Ịnweta nhazi provider ozugbo** — jiri getters nke `providerRegistry`
❌ **Usoro fallback edere ozugbo** — kọwaa ha na `modelFamilyFallback.ts`
❌ **Mgbanwe state n'etiti arịrịọ ndị na-aga n'otu oge** — jiri naanị context nke metụtara arịrịọ ahụ

## Ịgbakwunye Komponentị Ọhụrụ

### Ịgbakwunye Ọrụ Ọhụrụ

1. Mepụta `open-sse/services/[serviceName].ts` nwere ọrụ a kapịrị ọnụ
2. Bupụ function handler bụ isi na constants ọ bụla
3. Tinye unit tests na `tests/unit/services/[serviceName].test.mjs`
4. Tinye ya n'ime pipeline arịrịọ na `handlers/chatCore.ts` (ọ bụrụ na ọ metụtara nhazi ụzọ)
5. Melite usoro nhazi ụzọ na `combo.ts` ma ọ bụrụ na ọrụ ahụ na-emetụta nhọrọ ebe ezubere
6. Detuo ya n'ime faịlụ a

### Ịgbakwunye Executor Ọhụrụ

1. Mepụta `open-sse/executors/[provider].ts` nke na-agbatị `BaseExecutor`
2. Debanye aha ya na `config/providerRegistry.ts`
3. Tinye ya na factory nke `executors/index.ts`
4. Tinye unit tests maka executor ahụ
5. Detuo ya na `docs/architecture/ARCHITECTURE.md`

### Ịgbakwunye Ngwaọrụ MCP Ọhụrụ

1. Mepụta ma ọ bụ melite `open-sse/mcp-server/tools/[category]Tools.ts`
2. Kọwaa schema Zod maka inputs
3. Debanye aha ngwaọrụ ahụ na `mcp-server/index.ts`
4. Tinye ya na matriks scope dị na `mcp-server/auth/`
5. Tinye unit tests
