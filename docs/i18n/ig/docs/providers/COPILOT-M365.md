`copilot-m365-web` (aha ọzọ ya bụ `m365copilot`) na-eziga arịrịọ nkata n'ụdị OpenAI site na
nnọkọ ihe nchọgharị Microsoft 365 Copilot BizChat e mere nyocha njirimara na ya na
`m365.cloud.microsoft/chat`. Nke a bụ njikọ na-abụghị nke gọọmentị.

> **Ị bụ onye ọhụrụ n'iji ndị na-eweta Web Cookie?**
>
> Gụọ **`docs/getting-started/WEB-COOKIE-GUIDE.md`** maka usoro nhazi izugbe, ntụziaka nyocha njirimara, oke ndị dị, na idozi nsogbu tupu ị soro ntuziaka a pụrụ iche maka onye na-eweta ọrụ a.
>
> **Ihe dị mkpa:** Ozi njirimara maka onye na-eweta ọrụ a **abụghị cookie**. Eṅomila
> cookies site na `m365.cloud.microsoft`. Ozi njirimara ahụ bụ paramita ajụjụ URL WebSocket
> na akụkụ ụzọ, a na-agụ ha abụọ site na taabụ Network nke DevTools.

## Ihe ndị achọrọ tupu ịmalite

- Akaụntụ Microsoft 365 nwere ikike iji BizChat na `m365.cloud.microsoft/chat`
- Ihe nchọgharị dabeere na Chromium (Chrome, Edge) maka inyocha WebSocket na DevTools
- Ikikere M365 Copilot (a na-etinye ya n'ọtụtụ atụmatụ Microsoft 365 Business/Enterprise)

## Inweta ozi njirimara (usoro WebSocket)

1. Banye na `https://m365.cloud.microsoft/chat` wee malite mkparịta ụka.
2. Mepee **DevTools → Network**.
3. Jiri **WS** (WebSocket) nyochaa.
4. Pịa njikọ WebSocket Chathub. Chọọ URL na-amalite na
   `wss://substrate.office.com/m365Copilot/Chathub/`.
5. Site na **Request URL** ya, detuo:
   - Uru paramita ajụjụ `access_token` (JWT nke na-adịru obere oge).
   - Akụkụ ụzọ Chathub dị mgbe `/Chathub/` gasịrị (dịka `<oid>@<tenant>`).

URL zuru ezu nwere ụdị a:

```
wss://substrate.office.com/m365Copilot/Chathub/<oid>@<tenant>?...&access_token=<jwt>
```

6. Na OmniRoute, gaa na **Providers → Add Provider**, họrọ **Microsoft 365 Copilot
   (BizChat)**, wee mado ozi njirimara ahụ n'ụdị a:

```
access_token=<jwt>; chathubPath=<oid>@<tenant>
```

7. Pịa **Test Connection** na **Save**.

## Inweta ozi njirimara (mbubata HAR)

Kama iji aka detuo uru ndị ahụ site na URL WebSocket, ị nwere ike ibupụ faịlụ HAR nke DevTools:

1. Mepee **DevTools → Network**.
2. Malite ma ọ bụ gaa n'ihu na mkparịta ụka BizChat (nke a na-akpalite njikọ WebSocket).
3. Pịa aka nri na panel Network wee họrọ **Save all as HAR with content**.
4. Na OmniRoute, jiri bọtịnụ **Import .har file** dị na dialog njikọ onye na-eweta ọrụ.

OmniRoute na-enyocha HAR maka URL WebSocket Chathub, wepụta
`access_token` na `chathubPath`, ma mejupụta mpaghara ozi njirimara na-akpaghị aka. Mbubata
HAR na-akọwa oge JWT ga-agwụ ma gosipụta oge token fọdụrụ.

> **Etinyela mbupụ HAR n'ezie, access token, ma ọ bụ refresh token n'ime commit.** Uru nnwale na
> nke akwụkwọ ntụziaka ga-abụrịrị ihe nnọchi anya mgbe niile.

## Ogologo ndụ token na mmeghari

`access_token` na-adị ndụ obere oge (na-abụkarị **~nkeji 75**). Enweghị token mmeghari
a pụrụ iji, ị ga-ejidekwa nzere ahụ ọzọ mgbe ọ gwụchara.

### Mmeghari akpaghị aka na `refreshToken`

Na dialog **Tinye njikọ** ma ọ bụ **Dezie njikọ** nke onye na-enye ọrụ Microsoft 365, mepee
**Ntọala dị elu → Token mmeghari (nhọrọ)**. Tapawa token mmeghari Microsoft OAuth
maka scope `substrate.office.com/sydney` ma chekwaa ya. A na-ezo ihe ntinye ahụ, a naghị etinyekwa token echekwara n'ime ya na mbụ. Mgbe ị na-edezi, hapụ ya oghere iji debe token dị ugbu a;
tapawa token ọhụrụ iji dochie ya.

Nweta token mmeghari ahụ site na usoro koodu-ngwaọrụ Microsoft ma ọ bụ usoro koodu ikike
nke ejiri scope `substrate.office.com/sydney`; dashboard ahụ anaghị enweta ya n'aha gị.
Mgbe ahaziri token mmeghari, OmniRoute na-enyocha `access_token` tupu arịrịọ ma na-emegharị ya naanị mgbe ọ dị mkpa ka emegharịa ya. Mmeghari gara nke ọma na-echekwakwa token mmeghari a gbanwere, na-ezere ijide nzere ọzọ iji aka mgbe token mmeghari ahụ ka dị irè.

Ọ bụrụ na edobebeghị `refreshToken`, ị ga-eji aka gị jide nzere WebSocket ahụ ọzọ
mgbe ọ bụla ọ gwụchara.

### Nhọrọ ọkwa

| Ọkwa         | Aha ọzọ     | Ebe eji ya                    |
| ------------ | ----------- | ----------------------------- |
| `individual` | _(ndabara)_ | M365 Copilot ndị ahịa         |
| `edu`        | `included`  | M365 Copilot maka agụmakwụkwọ |
| `enterprise` | `work`      | M365 Copilot maka ọrụ         |

Debe ọkwa ahụ na **Ntọala dị elu → Ọkwa Copilot**. Ọkwa ahụ na-emetụta
ntụgharị BizChat na ohere iji ụdị.

## Ụdị nchekwa

- **Njikọ na-abụghị nke gọọmentị kwadoro.** Onye na-eweta ọrụ a na-enyocha ma na-ewughachi usoro
  BizChat WebSocket. Ọ nwere ike ịkwụsị ịrụ ọrụ na-enweghị ọkwa mgbe Microsoft gbanwere endpoint ahụ.
- Ọkọlọtọ `subscriptionRisk: true` na-egosi na njikọ ahụ dabere na endpoint
  a na-edeghị akwụkwọ maka ya. Mgbochi akaụntụ nwere ike ime, mana ekwenyebeghị ya.
- Access token ahụ bụ JWT nke na-adịru obere oge. Were ya dịka okwuntughe: etinyela ya na commit,
  edekọla ya na log, ma ọ bụ kesaa ya.
- Refresh token ahụ na-enye ohere ogologo oge ịnweta elu BizChat. Chekwaa ya nke ọma
  dịka ị ga-esi chekwaa API key.

## Nchọpụta nsogbu

### Nyocha njirimara na-ada ozugbo

- Nyochaa na i depụtaghachara site na **WebSocket URL**, ọ bụghị site na arịrịọ XHR/Fetch. Nzere ahụ dị na parameter ajụjụ `access_token` nke njikọ Chathub WebSocket — ọ bụghị n’isi `Authorization: Bearer`.
- Jide n’aka na `chathubPath` nwere akụkụ `<oid>@<tenant>` zuru ezu sitere n’ụzọ URL.

### Token na-agwụ mgbe ihe dị ka nkeji 75 gachara

Nke a bụ ihe a tụrụ anya ya. Ọ bụrụ na enweghị `refreshToken`, access token na-adịru obere oge. Mee otu n’ime ndị a:

- Jide nzere ọhụrụ ọzọ site na DevTools, ma ọ bụ
- Hazie **Ntọala dị elu → Refresh token (nhọrọ)** n’ime dialog njikọ Tinye ma ọ bụ Dezie, ka ọ na-emegharị na-akpaghị aka.

### Nnwale Njikọ gafere mana nkata na-eweghachi 401

Token ahụ nwere ike ịgwụla n’etiti nkwenye na arịrịọ mbụ. Jide nzere ọhụrụ ọzọ.

### Copilot apụtaghị na ndepụta ndị na-eweta ọrụ

Jide n’aka na agbanyere `copilot-m365-web` na **Dashboard → Ndị na-eweta ọrụ**. Enwere ike izo onye na-eweta ọrụ ahụ na ndabara n’ụfọdụ tiers.
