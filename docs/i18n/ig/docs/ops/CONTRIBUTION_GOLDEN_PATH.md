Jiri ntuziaka a họrọ usoro mmepe kacha nta a pụrụ ịtụkwasị obi maka pull request. Ọ naghị
anọchi akwụkwọ nhazi usoro na nchekwa ndị metụtara mpaghara kpọmkwem e jikọtara n'okpuru; ọ na-ejikọta ụdị
mgbanwe ọ bụla a na-ahụkarị na nkwekọrịta ya, nyocha ndị e lekwasịrị anya na ha, na mkpuchi CI.

## Ụzọ mgbanwe ọ bụla na-agbaso

1. **Họrọ ntọala tupu ịmalite idezi.** Chọta alaka `release/v*` kacha elu nke ka na-arụ ọrụ wee mepụta alaka site
   na nsọtụ ya. Mee ka alaka ahụ bụrụ ebe ị na-ezubere, ọ bụghị `main`. Ọ bụrụ na nkwụsị mgbanwe tupu mwepụta na-arụ ọrụ, ezubela alaka
   ahụ akpọchiri akpọchi; jiri usoro na-arụ ọrụ na-esote nke akọwara na
   [Ụdị Nhazi Alaka na Mwepụta](BRANCHING_MODEL.md).
2. **Kpọpụta nkwekọrịta ndị ahụ.** Chọpụta katalọgụ, schema, artifact emepụtara, API ọha, ma ọ bụ interface onye ọrụ
   ọ bụla mgbanwe ahụ na-emetụta. Tebụl dị n'okpuru na-enye nchịkọta kacha nta a ga-eji malite.
3. **Dee ma ọ bụ melite ule ndị e lekwasịrị anya na ha.** Mgbanwe production dị na `src/`, `open-sse/`, `electron/`, ma ọ bụ
   `bin/` chọrọ ule akpaghị aka n'otu PR ahụ. Gbaa faịlụ ule kacha nta ndị na-egosi
   omume ahụ, wee gbaa ọnụ ụzọ nyocha ndị e depụtara.
4. **Hapụ CI ka ọ gbaa matrix sara mbara.** Unit shards zuru ezu, Vitest, coverage ratchet, na
   production build na-agba na PR ahụ. Gbaa suite sara mbara n'igwe gị naanị mgbe ọdịda nlele a lekwasịrị anya na ya na-egosi
   mmetụta sara mbara karị ma ọ bụ mgbe mgbanwe ahụ gafere ọtụtụ subsystem.
5. **Mee ka ihe kwekọọ tupu review.** Fetch ntọala na-arụ ọrụ, nyochaa commit ọhụrụ ya na diff gị megide
   ya, wee rebase ma ọ bụ merge ntọala ahụ dịka usoro ọrụ onye ntinye aka si dị. Dozie esemokwu faịlụ
   emepụtara na katalọgụ site na isi mmalite ha, mepụtaghachi ha, gbakwaa usoro a lekwasịrị anya na ya, ma gosi na
   PR ahụ ka na-ezubere alaka mwepụta na-arụ ọrụ.
6. **Dekọọ ihe akaebe.** N'ime template PR, depụta command ndị a gbara, faịlụ ule ọ bụla agbakwunyere ma ọ bụ gbanwere,
   migration ma ọ bụ feature flag, yana nkwado ọ bụla ga-eme naanị na CI nke ka na-echere.

## Ụzọ kachasị mma dịka ụdị mgbanwe si dị

Command ndị dị n'okpuru bụ nyocha kacha nta e lekwasịrị anya na ha, ọ bụghị ikike ịwụfe ule nke na-enyocha
omume ị gbanwere ozugbo.

### Provider

**Nkwekọrịta**

- Nkọwa provider dị na `src/shared/constants/providers/` na otu e si chịkọta ya na
  `src/shared/constants/providers.ts`.
- Model na capability dị na `open-sse/config/providerRegistry.ts` ma ọ bụ faịlụ registry e wepụtara na ya.
- Nhọrọ executor/translator, nhazi OAuth ma ọ bụ API key, asset dashboard, na reference
  provider emepụtara mgbe ọ dị mkpa.
- Credential ọha ga-eji `resolvePublicCred()`; response njehie ga-eji helper njehie e kesara nke
  e sachapụrụ ozi nzuzo. Lee `docs/security/PUBLIC_CREDS.md` (git; anaghị etinye ya n'ime `/docs`) na
  [Nsachapụ Ozi Njehie](../security/ERROR_SANITIZATION.md).

**Usoro e lekwasịrị anya na ya**

```bash
npm run check:provider-consistency
npm run check:provider-assets
node --import tsx/esm --test tests/unit/provider-translate-path-golden.test.ts
node --import tsx/esm --test tests/unit/<provider-or-executor>.test.ts
npm run gen:provider-reference   # mgbe katalọgụ gbanwere; commit diff emepụtara
npm run lint
```

Nweekwa ule maka request family ọ bụla emetụtara: chat, Responses, images, embeddings, audio, ma ọ bụ video.
Nyochaa katalọgụ emepụtara na golden diff dịka mgbanwe nkwekọrịta; anabatala ha n'enweghị nyocha.

### Routing

**Nkwekọrịta**

- Uru strategy ọha na metadata UI dị na `src/shared/constants/routingStrategies.ts`.
- Dispatch na ordering n'okpuru `open-sse/services/combo.ts` na `open-sse/services/combo/`.
- Schema combo, persistence, resilience state, capability model, na njikwa API/UI.
- [Auto-Combo Engine](../routing/AUTO-COMBO.md) na akwụkwọ resilience mgbe omume gbanwere.

**Usoro e lekwasịrị anya na ya**

```bash
node --import tsx/esm --test tests/unit/combo-<behavior>.test.ts
npm run test:combo:matrix        # mgbanwe strategy ma ọ bụ dispatch
npm run check:known-symbols      # mgbanwe ndebanye strategy
npm run lint
```

Jiri ule mocked-upstream nwere nsonaazụ a pụrụ ibu amụma n'igwe gị. Live combo smoke chọrọ credential ma bụrụ
nke a na-eji aka eme, ọ bụghị ihe nnọchi anya CI.

### UI / UX

**Nkwekọrịta**

- Route/page Next.js na oke shared component n'okpuru `src/app/` na
  `src/shared/components/`.
- Ọdịdị response API, ọnọdụ loading/empty/error, omume keyboard na screen reader,
  layout responsive, theming, na mgbasawanye locale.
- String UI Bekee ndị bụ isi dị na `src/i18n/messages/en.json`; etinyela copy ọhụrụ onye ọrụ ga-ahụ kpọmkwem n'ime koodu.

**Usoro e lekwasịrị anya na ya**

```bash
node --import tsx --test tests/unit/dashboard/<feature>.test.ts
npx vitest run --config vitest.config.ts tests/unit/ui/<component>.test.tsx
npm run check:dashboard-typecheck
npm run lint
```

Gbaa app ahụ maka mgbanwe interaction ma ọ bụ visual ma lelee viewport dị warara na nke sara mbara. CI na-agba
production build na suite ndị sara mbara karị; omume visual ka chọrọ component a lekwasịrị anya na ya, Playwright,
ma ọ bụ nyocha e ji aka mee nke edekọtara nke dabara na mgbanwe ahụ.

### i18n

**Nkwekọrịta**

- `src/i18n/messages/en.json` bụ isi mmalite UI; `config/i18n.json` bụ isi mmalite locale.
- Katalọgụ CLI dị iche n'okpuru `bin/cli/locales/`.
- Debe placeholder na tag ICU otu ha dị kpọmkwem. Atụgharịla aha product/provider/model,
  aha protocol na header, command, identifier code/JSON, URL, environment variable, ma ọ bụ
  mkpụrụokwu echedoro dịka `OmniRoute`, `OAuth`, `MCP`, na `A2A`. Ndepụta isi mmalite ugbu a bụ
  `scripts/i18n/glossary/protected-terms.json`.

**Usoro e lekwasịrị anya na ya**

```bash
npm run i18n:sync-ui:dry
npm run i18n:check-ui-coverage
npm run i18n:check-value-drift
npm run i18n:check-glossary
npm run check:cli-i18n          # mgbe string/katalọgụ CLI gbanwere
npm run lint
```

Nke a bụ ntuziaka maka sistemụ dị ugbu a, ọ bụghị ọkpụkpọ oku ka a gbasaa tooling ma ọ bụ key model ya.
Mee ka patch i18n metụta naanị ihe dị mkpa mgbe a ka na-emepụta sistemụ ga-anọchi ya. Agbala command translation
ndị na-akpọ service mpụga ma ọ bụrụ na ọrụ ahụ achọghị translation emepụtara kpọmkwem ma
ị nyochabeghị diff sitere na ya.

### CLI

**Nkwekọrịta**

- Iwu ọha na flags dị na `bin/cli/`, iwu API ndị emepụtara, koodu ọpụpụ, stdout/stderr na
  ọdịdị mmepụta JSON, omume nhazi/environment, na faịlụ ndị e tinyere na ngwugwu.
- Eriri ederede CLI ndị ọrụ na-ahụ ga-eji oyi akwa i18n nke CLI ma mee ka katalọgụ `en`/`pt-BR` kwekọọ.
- Chekwaa Node dịka runtime a na-akwado yana nkwekọrịta binary e bipụtara.

**Usoro nnwale a gbadoro anya**

```bash
node --import tsx/esm --test tests/unit/cli/<command>.test.ts
npm run check:cli-i18n
npm run build:cli             # mgbanwe CLI emepụtara/e jikọtara ọnụ
npm run check:pack-policy     # mgbanwe n'akụkụ ngwugwu
npm run lint
```

Jiri iwu ahụ kpọmkwem n'ime ndekọ data nwa oge mgbe omume dabere na parsing, faịlụ, ma ọ bụ ọnọdụ
ọpụpụ. CI na-eme nyocha sara mbara karị nke artifact ngwugwu na ecosystem.

### Ebe nchekwa data

**Nkwekọrịta**

- Modul domain ndị dị n'okpuru `src/lib/db/`; bubata modul ndị akọwapụtara ozugbo (e wepụrụ oyi akwa ochie `localDb.ts` nke na-eme re-export).
- SQL migrations ndị e tinyere nọmba ma bụrụ idempotent n'okpuru `src/lib/db/migrations/`, nchekwa transaction, omume
  upgrade, indexes, na caller ọ bụla schema ahụ metụtara.
- Routes na handlers anaghị enye raw SQL ozugbo.

**Usoro nnwale a gbadoro anya**

```bash
npm run check:migration-numbering
npm run check:db-rules
node --import tsx/esm --test tests/unit/db/<domain>.test.ts
node --import tsx/esm --test tests/unit/db/migration-<number>.test.ts
npm run lint
```

Nwalee ma ebe nchekwa data ọhụrụ ma upgrade sitere na schema gara aga mgbe ị na-agbakwunye migration. Nnwale ebe nchekwa data
ga-emechi handles ma kpọọ `resetDbInstance()` n'oge nhicha. Gbaa `npm run test:bun:db` naanị mgbe
ụzọ adapter Bun nke best-effort gbanwere; Node ka bụ isi ikike.

### Build / deploy

**Nkwekọrịta**

- Manifests/lockfile nke root na workspace, `scripts/build/`, nchịkọta standalone nke Next.js, ọdịnaya ngwugwu
  `dist/`, metadata platform Electron, workflows CI, na sentinels deployment.
- Oke Node ndị a na-akwado na ojiji Bun e tinyere na allow-list n'ime `CLAUDE.md` ga-anọgide dịka ha dị.
- Artifacts build agaghị eso na tracking; iwu dependency, license, workflow, na ngwugwu ga-adị irè.

**Usoro nnwale a gbadoro anya**

```bash
node --import tsx/esm --test tests/unit/build/<behavior>.test.ts
npm run check:build-scope
npm run check:lockfile         # mgbanwe dependency ma ọ bụ lockfile
npm run check:pack-policy      # mgbanwe n'akụkụ ngwugwu e bipụtara
npm run lint
```

Jiri `npm run build` na mpaghara gị naanị mgbe mgbanwe ahụ metụtara compilation, nchịkọta standalone, assets,
ma ọ bụ bundling runtime. Jiri `npm run build:release` naanị maka nkwado release/deploy. Build CI bụ
akara ikpeazụ gafee platforms; mgbanwe Electron pụrụ iche nye platform chọrọ build a gbadoro anya kwekọrọ
ma ọ bụ ihe akaebe smoke.

## Skript ndị nrụpụta maka igwe a na-ekekọrịta

Ndị enyemaka abụọ dị na `scripts/dev/` na-ahazi usoro ọrụ mpaghara na devbox ebe nnọkọ ndị ọzọ na-arụ ọrụ:

```bash
scripts/dev/typecheck-touched.sh --base release/vX.Y.Z   # faịlụ sitere na merge-base(HEAD, base)..HEAD
scripts/dev/typecheck-touched.sh src/a.ts tests/unit/b.test.ts   # naanị faịlụ ndị a kpọmkwem
scripts/dev/new-worktree.sh fix/1234-slug release/vX.Y.Z  # worktree dịpụrụ adịpụ, dị nchebe ịrụ n'otu oge
```

- `typecheck-touched.sh` na-enyocha ụdị naanị maka faịlụ `.ts/.tsx` ndị emetụrụ site na
  `tsconfig.touched.tmp.json` nwa oge (`extends ./tsconfig.json`, `types: ["node"]`, `noEmit`,
  `incremental: false`) n'okpuru heap 6 GB, ya mere ọ na-anọchi `tsc -p tsconfig.json` nke
  ọrụ ahụ dum, nke na-enweta OOM n'igwe nwere ibu ọrụ. Ọ na-ebipụta njehie dị na faịlụ ndị emetụrụ
  tinyere otu ahịrị nchịkọta, wee jiri `1` kwụsị ma ọ bụrụ na njehie dị na faịlụ ndị emetụrụ,
  `2` mgbe naanị njehie ndị ahụ dị na faịlụ ndị ebubatara ma ọ bụ mgbe tsc nwụrụ n'enweghị
  diagnostics (gụpụta ndekọ ọ kpọrọ aha n'okpuru `_artifacts/typecheck-touched/`), na `0` mgbe
  ihe niile dị ọcha. A na-ewepụ tsconfig nwa oge ahụ mgbe niile; etinyekwala nke ọ bụla na commit.
- `new-worktree.sh` na-eme ka arụmọrụ ndị na-aga n'otu oge soro ibe ha n'usoro na
  `<git-common-dir>/omniroute-new-worktree.lock` (ọ na-echere ruo 600 s na ndabara, ma na-egosi
  ozi a na-ahụ anya; isi skript ahụ na-akọwa otu esi agbanwe nke a), ma na-akagbu
  branch o mepụtara mgbe `git worktree add` dara tupu worktree ahụ adị, ya mere ịnwa ọzọ
  achọghị iji aka mee `git branch -D`. `node_modules` ejikọrọ site na hard link na oyiri `.husky/_`
  anaghị agbanwe.

## Usoro candidate mpaghara

Nnwale source enweghị ike igosi na artifact e tinyere na package ga-ebido: ndepụta packaging,
dependencies e belatara, na native binaries na-ada naanị mgbe e wụnyere tarball ma malite ya.
`npm run dev:candidate` (`scripts/dev/candidate.mjs`) bụ akụkụ mpaghara nke usoro wuo-otu-ugboro /
nyochaa / kwalite sitere na RFC #8084: ọ na-ewu otu candidate, na-enyocha kpọmkwem artifact ahụ,
na-akwalite ya site n'ịgbanwe aha directory, ma na-eweghachi ya azụ mgbe slot e kwalitere dara
health check ya.

```bash
npm run dev:candidate -- run --dry-run --json  # bipụta atụmatụ ahụ, agbanwela ihe ọ bụla
npm run dev:candidate -- run                   # wuo + nyochaa + kwalite, weghachi azụ na-akpaghị aka
npm run dev:candidate -- build                 # npm pack + wụnye n'ime _artifacts/candidate/<id>/
npm run dev:candidate -- validate --id <id>    # bido na port efu, /api/health + /v1/models
npm run dev:candidate -- promote --id <id>     # <id> → current, current → previous
npm run dev:candidate -- rollback              # gbanwere current na previous
npm run dev:candidate -- run --from-tarball <file.tgz>  # jiri ọzọ tarball e wuru ebe ọzọ (CI)
```

- **Wuo naanị otu ugboro.** `build` na-etinye tree dị ugbu a na package (ọ chọrọ
  `dist/server.js`, ya mere buru ụzọ mee `npm run build:release`) ma ọ bụ na-eṅomi
  `--from-tarball`, wee wụnye tarball ahụ n'ime npm prefix dịpụrụ adịpụ, n'ihi na tarball ahụ
  enweghị `node_modules`. Id ahụ bụ sha dị mkpirikpi nke `HEAD` (`-dirty` mgbe tree ahụ nwere
  mgbanwe mpaghara) ma ọ bụ `tgz-<sha256>` maka tarball. A na-eji id dị ọcha nke e wurula ọzọ
  kama iwughachi ya; nyefee `--force` iji wughachi ya.
- **Nyochaa package ahụ, ọ bụghị source ahụ.** `validate` na-amalite CLI e wụnyere
  (`serve --port <free port>`) site na `DATA_DIR=<candidate>/data` ọhụrụ, secrets adịgboroja, ma
  wepụ `OMNIROUTE_API_KEY`, `STORAGE_ENCRYPTION_KEY` na `INITIAL_PASSWORD` nke onye ọrụ nchịkwa
  na environment, ka o wee nyochaa ọnọdụ keyless loopback nke nrụnye ọhụrụ. Ọ na-echere ka
  `GET /api/health` weghachi 200, na-achọ ka `GET /v1/models` weghachi 200, na-akwụsị process group,
  ma dekọọ mkpebi ahụ na `validation.json` tinyere hash tarball ahụ.
- **Kwalite otu artifact ahụ.** `promote` na-ajụ candidate na-enweghị validation gara nke ọma maka
  hash tarball ya dị ugbu a. Slot na-arụ ọrụ na ndabara bụ `_artifacts/candidate/current`;
  `--target <dir>` na-ahọrọ directory ọzọ dị na otu filesystem ahụ, slot gara aga ya bụkwa
  `<dir>.previous`. Mgbanwe aha nke ọ bụla bụ atomic, ma ọdịda n'etiti usoro ahụ na-atụgharị
  mgbanwe aha ndị emerela.
- **Weghachi azụ.** `run` na-enyocha slot e kwalitere ọzọ ma na-agbanweghachi `current` na
  `previous` mgbe nyocha ahụ dara. A naghị akwalite candidate nke dara validation mbụ.

A na-ede ihe niile n'okpuru `_artifacts/candidate/` nke git na-eleghara anya; a naghị emetụ nrụnye
OmniRoute dịbu adị na data directory ya aka. CLI e kwalitere bụ
`_artifacts/candidate/current/prefix/bin/omniroute`; jiri `DATA_DIR` nke gị malite ya mgbe ị na-eji
ya. Koodu nkwụsị: `0` ihe ịga nke ọma, `1` validation ma ọ bụ promotion dara, `2` njehie ojiji ma ọ
bụ build na-efu.

## Usoro mpaghara ma e jiri ya tụnyere CI

| Gbaa na mpaghara maka patch ọ bụla                                          | CI na-enye akara sara mbara                                   |
| --------------------------------------------------------------------------- | ------------------------------------------------------------- |
| Nnwale omume kpọmkwem na ọnụ ụzọ otu ndị dị n’elu                           | Nchịkọta nnwale unit zuru ezu e kewara ekewa na nnwale serial |
| `npm run lint`                                                              | Nchịkọta nnwale Vitest na ratchet mkpuchi/ịdịmma              |
| Nyocha ụdị ma ọ bụ build naanị mgbe nkwekọrịta emetụtara chọrọ ya           | Build mmepụta, nchekwa, docs, dependency, na ọnụ ụzọ iwu PR   |
| Mkparịta ụka aka/live checks naanị mgbe akpaaka enweghị ike igosi omume ahụ | Njikọ gafee job na nyocha platform ndị workflow haziri        |

Usoro lekwasịrị anya nke na-acha akwụkwọ ndụ bụ ihe akaebe gbasara nkwekọrịta a gbanwere, ọ bụghị ihe akaebe na nyocha CI ndị ọzọ na-enweghị njikọ
ga-aga nke ọma. N’aka nke ọzọ, emela ka ndezi mpaghara ọ bụla chere matriks repository zuru ezu.

## Ndepụta nyocha maka ime ka ihe kwekọọ

Tupu ịrịọ maka nyocha:

- Kwenye na ntọala PR ka bụ alaka `release/v*` kacha elu nke ka na-arụ ọrụ.
- Fetch ntọala ahụ ma nyochaa commit ndị batara kemgbe i mepụtara alaka gị.
- Nyochaa `git diff <active-base>...HEAD` maka mgbanwe mberede ma ọ bụ ndị emepụtara na-enweghị isi.
- Dozie esemokwu catalog na generated-document site n’imelite isi mmalite ma mepụtaghachi output.
- Gbaa ule/ọnụ ụzọ niile lekwasịrị anya ndị edepụtara na nkọwa PR ọzọ mgbe emechara ime ka ihe kwekọọ.
- Ebelatala assertions ma ọ bụ wepụ ule achọrọ naanị iji kwekọọ na ntọala a kwagara.

Maka iwu release-freeze na retargeting, jiri
[Ụdị Alaka na Mwepụta](BRANCHING_MODEL.md). Maka ndepụta CI zuru ezu, jiri
[Ntụaka Ọnụ Ụzọ Ịdịmma](../architecture/QUALITY_GATES.md).
