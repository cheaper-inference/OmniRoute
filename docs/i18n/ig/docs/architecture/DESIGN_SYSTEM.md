> **Ọnọdụ:** e wuru dashboard ahụ n'elu **Keak CI UI Kit** (`@keak/cheaper-inference-ui-kit`), ma tinye ya
> dị ka workspace `packages/ui-kit` (`@omniroute/ui-kit`; edobere snapshot nke upstream n'ime
> `packages/ui-kit/UPSTREAM.md`, ebe `npm run check:ui-kit-snapshot` na-echekwa ya). Light bụ theme
> ntụaka; mmasị ndabara bụ `system`. Palette ndabara bụ ọdịdị **Editions** nke kit ahụ
> (agba akwụkwọ na-anọpụ iche ndị na-ekpo ọkụ na agba mgbakwunye ọla kọpa `#e5ac82`, `packages/ui-kit/src/ci-editions.css`); Settings →
> Appearance → Color palette na-enye **Classic**, ya bụ token ndị bụ isi nke kit ahụ nwere agba mgbakwunye lime. Switzer bụ
> naanị font family maka UI, ederede ngosi na ederede code (`--ci-font-ui`; `--ci-font-display` na
> `--ci-font-mono` na-arụtụ aka na ya), kit ahụ n'onwe ya na-akwado ya (`packages/ui-kit/src/ci-fonts.css`,
> nke `ci-tokens.css` na-ebubata). Script ndị Switzer na-enweghị na-eji font ndị ọzọ glyph n'otu n'otu (`src/app/globals.css`):
> Inter maka Cyrillic, Greek na Vietnamese, ma naanị n'okpuru `html[dir="rtl"]`, Vazirmatn maka script Arabic.
> Akara ngosi ọ bụla bụ glyph Lucide.

## 1. Ebe ihe dị

- **Ngwá ọrụ.** `packages/ui-kit/src` bụ oyiri byte-for-byte nke upstream `src/` na commit e debere na
  `packages/ui-kit/UPSTREAM.md` (nke na-edekwa ikike iji ikike ngwanrọ ahụ); `PATCHES.md` depụtara
  patches mpaghara (ọ dịghị). A na-eji ya dị ka source, na-enweghị build: `next.config.mjs` na-eme
  transpile ya, ebe `tsconfig.json` na-atụgharị `@omniroute/ui-kit` → `packages/ui-kit/src` na
  `@omniroute/ui-kit/*` → `packages/ui-kit/src/*` (`vitest.config.ts` na `vitest.mcp.config.ts` nwekwara alias
  ahụ). Bubata component kit site na subpath ya (`@omniroute/ui-kit/table`, `@omniroute/ui-kit/page-header`…), ọ bụghị
  site na barrel nke `@omniroute/ui-kit`: barrel ahụ na-ebubata component niile (gụnyere date picker)
  n'ime importer ọ bụla. Stylesheet kit na-abata site na `src/app/globals.css`
  (`@import "../../packages/ui-kit/src/ci-styles.css"`, sheet zuru ezu: core `ci-ui.css` tinyere ezinụlọ pattern niile).
- **Tokens.** `packages/ui-kit/src/ci-tokens.css` na-ekwupụta tokens `--ci-*`; `src/app/globals.css`
  na-ejikọta ha na aha OmniRoute ochie (`--color-*`, `--radius-*`, `--font-sans`/`--font-mono`,
  `--table-*`, `--orch-status-*`, `--color-fd-*`), ka reads `var(--color-*)` dị ugbu a na
  Tailwind utilities wee gaa n'ihu na-arụ ọrụ. Koodu ọhụrụ na-eji Tailwind utilities (`bg-surface`, `text-text-muted`,
  `border-border`, `text-success`, `bg-success-bg`, `bg-chart-1`…) ma ọ bụ classes kit — ọ dịghị mgbe a na-eji
  uru hex (`tests/unit/design-kit-bridge.test.ts` na-amanye bridge ahụ). `text-primary` na-edozi gaa na
  `--color-primary-ink` site na `--text-color-primary`, ya mere ederede primary na-anọgide na-agụpụta nke ọma,
  ebe `bg-primary`/`border-primary` na-edobe elu accent: n'okpuru Editions ọ bụ kit
  `--ci-color-accent-active` (deep copper `#99562f` na light, copper accent na dark); n'okpuru Classic,
  lime-800 na light na lime accent na dark. Usoro chart na-eji
  `--color-chart-1` … `--color-chart-8`, nke ọ bụla nwekwara `--color-chart-N-ink` nke dị mma maka ederede na
  `--color-chart-N-subtle` chip tint na-enweghị nghọta, e kenyere ha n'usoro series kit (`ciChartSeriesOrder`).
- **Themes.** `<html className="ci-theme">` (`src/app/layout.tsx`) na-etinye akwụkwọ ahụ n'ime theme kit.
  Nhọrọ ahụ bụ `light`, `dark` ma ọ bụ `system` (`THEME_CONFIG.defaultTheme = "system"` na
  `src/shared/constants/appConfig.ts`; `system` na-agbaso `prefers-color-scheme`). `applyTheme()` na
  `src/store/themeStore.ts` (nke `THEME_BOOT_SCRIPT` na-emekọrịta, a na-etinye ya inline na
  `src/app/layout.tsx`, ọ na-agba ọsọ tupu hydration) na-edobe `data-theme="dark"|"light"` ma na-agbanwe
  class `.dark` na `<html>` n'otu oge. Dark token set nke kit na-adabere na `data-theme="dark"`
  (`packages/ui-kit/src/ci-tokens.css`); dark overrides nke OmniRoute (`.dark` block dị na `globals.css`) na
  legacy Tailwind `dark:` utilities na-adabere na class `.dark`. Enweghị accent color presets: accent na-abịa
  mgbe niile site na kit, a na-atụfukwa preset e debere site na build ochie mgbe store na-ebu.
- **Palettes.** Abụọ, ha abụọ sitere na kit (`src/shared/constants/appearancePalette.ts`): `editions`, nke bụ
  ndabara, na `classic`. Editions bụ attribute `data-ci-appearance="editions"` nke kit na `<html>`, nke
  `ci-editions.css` (nke `ci-ui.css` na-ebubata) na-ejikọta na `data-theme`; Classic bụ enweghị attribute ahụ.
  Root layout na-eme server-render attribute ahụ, ya mere onye bịara na-enweghị ihe echekwara (ma ọ bụ na-enweghị JS)
  na-enweta Editions n'elu surface niile — dashboard, login, `/status`, error pages, `/docs` na PWA. A na-echekwa
  nhọrọ ahụ n'akụkụ theme n'otu `theme` store (`palette`, `setPalette()`, `applyPalette()` dị na
  `src/store/themeStore.ts`) ma tinye ya tupu paint site na `THEME_BOOT_SCRIPT`
  (`src/shared/utils/themeBootScript.ts`, nke a na-etinye inline na `<head>` nke layout), nke na-ewepụ attribute ahụ
  naanị mgbe palette echekwara bụ `"classic"`; `src/app/global-error.tsx`, nke dị n'èzí root layout, na-etinye
  ya site na store ahụ. Etinyela `data-ci-appearance` na element ọzọ ọ bụla: kit na-eji
  `html:root:has([data-ci-appearance="editions"])` dakọrịta ya, ya mere otu descendant ga-agbanwe akwụkwọ ahụ dum.
  Editions `data-ci-editions-variant="landing"` variant bụ maka ibe ahịa, ọ bụghị dashboard.
  Browser chrome: server na-ewepụta ndabara, Editions, na `viewport.themeColor` (otu tag maka
  `prefers-color-scheme` ọ bụla) na web manifest — `PWA_THEME_COLORS` dị na
  `src/shared/constants/pwaThemeColors.ts`, otu mirror nke Editions `--ci-color-background`
  (`#f3f1e9` / `#11120f`), nke `tests/unit/pwa-theme-colors.test.ts` kpọgidere na
  `ci-editions.css`. `<meta name="theme-color">` dị ndụ na-esokwa palette na mode echekwara: `THEME_BOOT_SCRIPT`
  na-edegharị tags ahụ tupu paint, actions nke theme store na-emekwa ya na mgbanwe ọ bụla
  (`resolveThemeColor()` / `applyThemeColor()` dị na `src/shared/utils/themeColorMeta.ts`, tinyere
  `CLASSIC_PAGE_BACKGROUND` nke a na-agụ site na `ciTokens` kit). Theme light/dark doro anya na-edobe tag ọ bụla
  na mode ahụ; `system` na-edobe otu agba maka scheme ọ bụla. Manifest na-anọgide Editions: a na-ebudata ya otu ugboro
  kwa install, na-enweghị preference ahụ. Monaco na-agụ agba ya site na probe (`monacoKitTheme.ts`);
  n'okpuru Editions, ọgụgụ probe na-agbanwe root `data-theme` maka otu synchronous pass, n'ihi na kit na-edozi
  Editions light/dark site na root.
- **Components (adapters).** `src/shared/components/index.tsx` na-edobe API component OmniRoute (otu aha,
  default exports na props), primitives dị n'azụ ya bụkwa adapters n'elu kit: forms
  (`Button`, `Input`, `Textarea`, `Checkbox`, `Select`, `Toggle`, `Badge`, `Card`), overlays na feedback
  (`Modal`/`ConfirmModal`, `Tooltip`/`InfoTooltip`, `NotificationToast`, `EmptyState`, `Loading`),
  nhazi
  (`Collapsible`, `CollapsibleSection`, `SegmentedControl`, `Breadcrumbs`, `Avatar`) na tables
  (`DataTable`, `FilterBar`, `ColumnToggle`, `FilterPills`, `PresetSlider`). Adapter na-ebubata
  kit component site na subpath ma na-map legacy props gaa na ya — dịka ọmụmaatụ `Button variant="primary"` bụ
  button `default` nke kit (`--ci-button-primary-*`: inverse surface na light, accent tinyere
  `--ci-color-accent-foreground` ink ya na dark), `danger` bụ `destructive`, `warning` bụkwa kit `warning`
  button. `Badge` status variants bụ kit tones, `Select` nwere ụmụ `<option>` na-eme render kit
  `NativeSelect`.
  A na-ebubata adapters abụọ site na path, ọ bụghị site na index: `InteractiveTableRow`
  (`src/shared/components/InteractiveTableRow.tsx`), kit `TableRow` nke na-anata `onActivate` na
  `selected` ma na-aza Tab, Enter na Space, na `CodePreview`
  (`src/shared/components/CodePreview.tsx`), code block kit nke a sụgharịrị copy labels ya.
  `tests/unit/ui/adapters/*.test.tsx` na-akpọgide adapter ọ bụla.
- **Shell.** `src/app/(dashboard)/layout.tsx` na-ewepụta `DashboardLayout`, nke na-ewepụta
  `src/shared/components/layouts/DashboardShell.tsx`: kit `SidebarProvider` / `Sidebar` /
  `SidebarInset` (`packages/ui-kit/src/sidebar.tsx`), tinyere mgbagha igodo OmniRoute dị na
  `src/shared/components/Sidebar.tsx`. Njikọ “wụpụ gaa n’ọdịnaya” nke na-aga `#main-content` bụ ihe mbụ a pụrụ ilekwasị anya na ya. `src/shared/components/Header.tsx` nwere kit `SidebarTrigger` (naanị ihe na-agbanwe sidebar nke shell), Keak `ProductSwitcher` na onye na-emepe command palette; ọ na-egosi aha ụzọ ahụ naanị mgbe enweghị kit `PageHeader` (`.ci-page-header`) etinyere n’ime `#main-content`, ya mere ibe nwere `PageHeader` nke ya nwere otu `h1`. `src/shared/components/CommandPalette.tsx` bụ kit `Dialog`.

- **Akara ngosi.** `<Icon name="material_name">` (`src/shared/components/Icon.tsx`) na-achọpụta aha ahụ (okwu Material Symbols nke screens na-eji) site na `ICON_MAP` (`src/shared/constants/iconMap.ts`) gaa na akara Lucide. Font na package Material Symbols adịghịzi: aha na-adịghị na map ahụ na-ewepụta akara nnọchi na-anọpụ iche (`data-icon-missing="true"`) ma na-edekọ ịdọ aka ná ntị na console n’èzí production. `npm run gen:icon-map` na-ebipụta aha ndị a na-eji nke na-adịghị na map ahụ
  (`tests/unit/icon-map-coverage.test.ts` na-ada ma ọ bụrụ na aha ọ bụla enweghị akara Lucide;
  `tests/unit/icon-map-object-values.test.ts` na-ekpuchi aha ndị echekwara n’ihe lookup objects);
  `scripts/dev/codemod-material-icons.mjs <dir|file>... [--write]` na-agbanwe spans nkịtị
  `<span className="material-symbols-outlined">` gaa na `<Icon>`.

- **Akara ụlọ ọrụ.** `src/shared/components/OmniRouteLogo.tsx` na-ekechi kit: default export `OmniRouteLogo`
  na-ewepụta `ProductIcon product="omniroute" variant="glyph"` (inline SVG, `basePath`-safe), ebe
  `OmniRouteLockup` na-ewepụta `ProductLockup product="omniroute"` (aha a pụrụ ịnweta bụ "Keak OmniRoute") ma ọ bụ, maka ndị ọrụ white-label, `name`/`logoSrc` nke ha. Ebe ProductSwitcher na-aga dị na
  `src/shared/constants/keakProducts.ts` (`KEAK_PRODUCT_LINKS`, `KEAK_ACTIVE_PRODUCT`). Screens kwụụrụ onwe ha — `src/app/login/page.tsx`, `src/app/status/page.tsx`, `src/app/maintenance/page.tsx`,
  `src/app/offline/page.tsx`, `src/app/not-found.tsx` na `src/shared/components/ErrorPageScaffold.tsx`
  — na-egosi lockup ahụ; `tests/unit/brand-pages-static.test.ts` na-echekwa nke a.

## 2. Iwu

1. Tokens, ọ bụghị literals. Ewezuga ndị a ka echekwara n’ebumnuche: terminal console nke na-adị ọchịchịrị mgbe niile na
   `STATUS_HEX` (`src/shared/constants/statusColors.ts`), mirror hex a kpebisiri ike nke palette ọnọdụ kit
   maka ndị na-akpọ ya chọrọ hex literal. Palette categorical abụghịzi ewezuga:
   ha na-eji tokens chart asatọ nke kit (`--color-chart-1..8`, tinyere `-ink`/`-subtle`), n’usoro usoro kit,
   site na `src/shared/utils/categoricalPalette.ts` na, maka atụmatụ routing,
   `src/app/(dashboard)/dashboard/combos/strategyPalette.ts`; edges ReactFlow na canvas orchestration
   na-agụ variables `--orch-status-*` nke maara theme (`src/shared/components/flow/edgeStyles.ts`).
2. Egbula aka dezie `packages/ui-kit/src`: jiri `scripts/dev/sync-ui-kit.sh <commit>` mee sync; gate pre-commit
   `npm run check:ui-kit-snapshot` (`.husky/pre-commit`) na-ada ma ọ bụrụ na byte ọ bụla dị iche na commit upstream
   e tinyere akara (ọ na-amapụ ya na ịdọ aka ná ntị mgbe clone upstream,
   `UI_KIT_CLONE` ma ọ bụ `_references/cheaper-inference-ui-kit`, adịghị). Mgbe kit enweghị ihe,
   chọta ụzọ gburugburu ya n’adapter ma ọ bụ screen, ma rịọ upstream maka ya.
3. Ndabara ederede kit bụ Bekee (`label = "Loading"`, `loadingLabel = "Loading table"`…) — nyefee
   eriri atụgharịrị sitere na `useTranslations(...)` mgbe ọ bụla akụrụngwa kit na-egosipụta ederede.
4. Tailwind utilities na-emeri klaasị akụrụngwa kit (kit na-ekwupụta
   `@layer theme, base, components, utilities` ma iwu ya dị na `components`) — jiri utilities maka oghere
   na nhazi layout, ọ bụghị iji gbanwee agba akụrụngwa kit. Typography bụ ewezuga:
   `packages/ui-kit/src/ci-typography.css` ka a na-import n’èzí layer ọ bụla, ya mere iwu tag ya na-emeri
   utilities. Klaasị weight, `tracking-*` na `leading-*` enweghị mmetụta na `h1`–`h6`, weight na
   `tracking-*` enweghị mmetụta na cells tebụl, weight enweghịkwa mmetụta na buttons
   (`tests/unit/dead-typography-classes.test.ts` na-ajụ ha n’ebe ndị ahụ); `font-mono` enweghị mmetụta na
   `th`, `td`, `button`, `input` na `textarea`. Utilities size, colour na `uppercase` ka na-arụ ọrụ.
5. Headings: `.ci-heading` maka aha peeji na ngalaba; `.ci-dashboard-display` naanị maka nnukwu ederede
   display nke nwere oghere zuru ezu dịka koodu ọnọdụ peeji njehie. Ha abụọ na-eji Switzer.
6. `tests/unit/dashboard-kit-sweep.test.ts` na-echekwa nnabata kit: enweghị Material ligature span n’okpuru
   `src/app` ma ọ bụ `src/shared/components`; n’osisi dashboard (`src/app/(dashboard)` na
   `src/shared/components`) enweghị raw `<select>`, `<textarea>` ma ọ bụ `<table>` na enweghị hand-rolled
   `role="dialog"` n’èzí ewezuga ndị e depụtara (native branch nke `Select` adapter,
   `RequestLoggerDetail`); raw `<button>` ma ọ bụ `<input>` ọ bụla nọ ebe ahụ chọrọ comment nwere
   `kit-exception:` (tinyere ihe kpatara ya) nke na-akwụsị karịa ahịrị 3 tupu ya; palette hues na `dark:` variants
   naanị n’ime faịlụ test ahụ depụtara.
7. Tupu PR, nyochaa themes abụọ na viewport 390 px (screenshots); `tests/e2e/a11y.spec.ts` na-agba
   axe.
8. Utility colour ga-akpọrịrị token dị na `@theme` block nke `src/app/globals.css`: aha na-adịghị ebe ahụ
   (`text-text`, `bg-bg-muted`, `text-danger`…) anaghị emepụta CSS, element ahụ ana-edobe colour o ketara
   (`tests/unit/theme-color-classes.test.ts`). Enweghị klaasị `card`: jiri `Card` adapter
   (`tests/unit/no-bare-card-class.test.ts`). Ederede dị na chart colour na-eji `text-chart-N-ink`;
   `text-chart-N` bụ maka icons na strokes
   (`tests/unit/chart-ink-for-text.test.ts`). A na-eji `color-mix` wuo colour translucent, ọ bụghị
   site n’ịgbakwunye hex alpha na uru nwere ike ịbụ `var()`
   (`tests/unit/color-alpha-concatenation.test.ts`).

## 5. Imelite ngwa ahụ

`npm run check:ui-kit-upstream` tụlere ụdị nke etinyere na `packages/ui-kit/UPSTREAM.md` na mkpado `v*` kachasị ọhụrụ nke repo elu wee bipụta iwu mmekọrịta mgbe mwepụta pụtara.

Usoro ọrụ `UI Kit upstream watch` kwa ụbọchị (`.github/workflows/ui-kit-upstream-watch.yml`) na-eme otu nlele ahụ. Mgbe ntụtụ dị n'azụ, `scripts/ci/ui-kit-sync-pr.sh` na-edobe otu PR mmekọrịta ghere oghe megide alaka `release/vX.Y.Z` kachasị elu, na ngalaba na-atụgharị `chore/ui-kit-sync-latest`. Ọ dịghị mgbe ọ na-ejikọta: ngwa ngwa ọ bụla ntọhapụ ka chọrọ nlele anya na VPS mpaghara. A na-ewughachi alaka ụlọ ọrụ ahụ mgbe ewepụtara ọhụrụ wee hapụ naanị ya ma ọ bụghị ya. Agaghị edegharị PR mepere emepe nke ejiri aka kwalie, yana PR maka ụdị nke onye na-echekwa mechiri ejikọtaghị ọnụ na-anọkwa na-emechi ruo mgbe ewepụtara ọhụrụ.

Mgbe enweghị ike imeghe PR (ntọhapụ ebumnuche ahụ jụrụ oyi, PR emeela site n'aka, mechiri PR, ma ọ bụ enweghị akara PR edobere) usoro ọrụ na-eme ka otu okwu nsochi meghere nke na-ekwu ihe kpatara ya.

Usoro a na-eji ụzọ abụọ eme ihe:

- `secrets.UI_KIT_READ_TOKEN`: akara naanị ọgụgụ maka repo elu nkeonwe. Mgbe usoro ọrụ enweghị ike ịgụ elu elu (enweghị akara, akara nke kwụsịrị ịrụ ọrụ, ma ọ bụ GitHub enweghị ike iru) ọsọ ahụ na-adịgide ndụ ndụ mana ọ na-ede ịdọ aka ná ntị ma na-eme ka otu okwu dị iche meghee, nke na-emechi onwe ya otu ugboro na-agba ọsọ nwere ike ịgụ elu ọzọ.
- `secrets.UI_KIT_SYNC_PR_TOKEN`: akara mara mma na ebe nchekwa a nwere ọdịnaya yana arịrịọ dọpụta dee ohere. `GITHUB_TOKEN` ndabara enweghị ike ịmepụta PRs ebe a, na PR ọ meghere agaghị akpalite CI. Na-enweghị akara ngosi a, usoro ọrụ na-akpali alaka ụlọ ọrụ naanị.

`scripts/dev/sync-ui-kit.sh <commit|latest> [clone]` na-eṅomi `src/` nke dị elu na ntinye ahụ (`latest` = mkpado `v*` ọhụrụ) n'ime `packages/ui-kit/src`, na-etinye mgbanwe otu ekwenyere (ọ na-ewepụ suffix `.js` site na mbubata ndị ikwu), ma debe ụdị ọrụ na `packages/ui-kit/package.json` na `package-lock.json` gaa na nke elu. Mgbe ahụ: nyochaa `git diff packages/ui-kit`, mee ihe ngosi anya na ndị na-enye, ntọala, combos, ojiji na njedebe na isiokwu abụọ ahụ, na-agba ọsọ `npm run check:ui-kit-snapshot` na `npm run test:vitest:ui`, ma mepee PR na elu mgbanwe mgbanwe.
