## 1. Ngwá Teknụzụ

| Ihe gbasara     | Nhọrọ                                                                                                                          |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Framework weebụ | **Next.js 16** (App Router, mmepụta kwụ ọtọ, enweghị middleware zuru ụwa ọnụ)                                                  |
| Asụsụ           | **TypeScript 6.0+** — ebumnuche `ES2022`, `module: esnext`, `moduleResolution: bundler`, `strict: false`                       |
| Oge ọrụ         | **Node.js** `>=22.22.2 <23` ma ọ bụ `>=24.0.0 <27` (a na-amanye ya site na `engines` + `SUPPORTED_NODE_RANGE`)                 |
| Nchekwa data    | **SQLite** site na `better-sqlite3` (singleton, ndekọ WAL)                                                                     |
| Desktọpụ        | **Electron 41** + `electron-builder` 26.10 (ohere ọrụ dị iche na `electron/`)                                                  |
| Ule             | **Ihe na-agba ule nke Node n'onwe ya** (otu/njikota), **Vitest** (MCP, autoCombo, cache), **Playwright** (e2e + protocols-e2e) |
| Iwulite         | Next.js kwụ ọtọ site na `scripts/build/build-next-isolated.mjs`                                                                |
| Ntụle/Ọdịdị     | ESLint flat config + Prettier (`lint-staged` site na Husky pre-commit)                                                         |
| Sistemu modul   | ESM n'ebe niile (`"type": "module"`)                                                                                           |
| UI Dashboard    | **Tailwind CSS 4** + **Keak CI UI Kit** a tinyere n'ime (`packages/ui-kit`), akara Lucide — lee `DESIGN_SYSTEM.md`             |
| Ohere ọrụ       | npm workspaces — `open-sse`, `packages/browser-pool`, `packages/ui-kit`                                                        |

Aha ọzọ ụzọ (`tsconfig.json`):

- `@/*` → `src/*`
- `@omniroute/open-sse` → `open-sse/index.ts`
- `@omniroute/open-sse/*` → `open-sse/*`
- `@omniroute/ui-kit` → `packages/ui-kit/src`, `@omniroute/ui-kit/*` → `packages/ui-kit/src/*`

Port HTTP ndabara: **`20128`** (API na dashboard na-eji otu process arụ ọrụ). Ndekọ
data bụ mgbanwe gburugburu `DATA_DIR`, nke na-adabere na `~/.omniroute/`.

## 11. Ụkpụrụ

- **Ụdị koodu**: oghere 2 maka indent, akara nhota abụọ, obosara mkpụrụedemede 100, semicolon,
  trailing comma `es5` — Prettier na-amanye nke a site na `lint-staged`.
- **Mbubata**: nke mpụga → nke ime (`@/`, `@omniroute/open-sse`) → nke metụtara ebe dị nso.
- **Ịkpọ aha**: faịlụ `camelCase` ma ọ bụ `kebab-case`, components `PascalCase`,
  constants `UPPER_SNAKE`.
- **ESLint**: `no-eval`, `no-implied-eval`, `no-new-func` = `error` n'ebe niile;
  `no-explicit-any` = `warn` na `open-sse/` na `tests/`, ma bụrụ error n'ebe ndị ọzọ.
- **TypeScript**: `strict: false` (ọnọdụ e ketara n'usoro ochie). Họrọ ụdị akọwapụtara nke ọma karịa
  inference maka oke dị n'etiti modul.
- **Database**: edela raw SQL ozugbo n'ime routes ma ọ bụ handlers — gafee
  modul `src/lib/db/` mgbe niile. Ejila barrel-import mgbe ọ bụla — jiri kpọmkwem modul `src/lib/db/*`.
- **Ịkọwa ụdị entity DB (#3512)**: ọrụ na-ede ma ọ bụ na-agụ ọdịdị row nke tebụl DB
  kwesịrị ịnata/weghachite interface TS nwere aha nke na-egosipụta columns tebụl ahụ
  1:1, ọ bụghị `any` ma ọ bụ ụdị anonymous edere n'otu ahịrị n'ebe a kpọrọ ọrụ ahụ. Debe
  interface ahụ n'akụkụ ọrụ ahụ (dịka `export interface UsageEntry` n'ime
  `src/lib/usage/usageHistory.ts` n'elu `saveRequestUsage`), hapụ field nke ọ bụla
  ka ọ bụrụ optional/nullable mgbe ndị odee dị iche iche na-ejupụta row ahụ
  nke nta nke nta, ma họrọ `unknown` karịa `any` maka field nke ọdịdị ya
  na-agbanwe n'etiti ndị na-akpọ ya (kọwaa nke a na field ahụ, dịka `UsageEntry.tokens`
  na-anabata ma raw usage nwere ọdịdị nke provider ma ọdịdị normalized). Ozugbo
  ọnụọgụ `any` nke faịlụ rutere efu site n'ụzọ a, tinye ya na allowlist
  `check:any-budget:t11` (`scripts/check/check-t11-any-budget.mjs`,
  `maxAny: 0`) ka ọ ghara ịlaghachi azụ. Nke a bụ ụkpụrụ maka akụkụ mbụ — nhicha
  sara mbara nke "enweghị anonymous `any`" na-aga n'ihu n'usoro n'akụkụ ndị ọzọ nke
  codebase.
- **Njehie**: jiri try/catch nwere ụdị njehie akọwapụtara, ma jiri context pino dekọọ log. Ekwela
  ka njehie n'ime stream SSE laa n'iyi n'enweghị ngosi; jiri abort signals maka nhicha.
- **Nchekwa**: ejila `eval()` / `new Function()` / implied eval mgbe ọ bụla. Jiri Zod kwado
  inputs niile. Zoo credentials n'ụdị encryption mgbe echekwara ha (AES-256-GCM). Mee ka
  denylist `src/shared/constants/upstreamHeaders.ts` kwekọọ na oyi akwa
  sanitize/validation.
- **Commits**: Conventional Commits — `feat(scope): subject`. Scopes ndị e kwere:
  `db`, `sse`, `oauth`, `dashboard`, `api`, `cli`, `docker`, `ci`, `mcp`,
  `a2a`, `memory`, `skills`.
- **Branches**: prefixes `feat/`, `fix/`, `refactor/`, `docs/`, `test/`,
  `chore/`. Etinyela commit ozugbo na `main`.
- **Husky**: pre-commit na-agba `lint-staged` + `check:docs-sync` +
  `check:any-budget:t11`; pre-push na-agba `check:any-budget:t11` + `check:tracked-artifacts` (nnyocha ngwa ngwa; ọ naghị agụnye `test:unit`).
