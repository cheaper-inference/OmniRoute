Akwụkwọ a bụ ntụaka kachasị ikike maka ọnụ ụzọ ogo CI niile dị na OmniRoute.
Ọ na-akọwa ọnụ ụzọ ọ bụla, ihe ọ na-enyocha, ọrụ CI ọ na-arụ n'ime ya, ma ọ na-eji
ntọala ratchet ma ọ bụ iwu ngafe/ọdịda, yana ma ọ na-egbochi build ka ọ bụ naanị ndụmọdụ.

Maka nchịkọta dị mkpirikpi na iwu allowlist, lee ngalaba "Quality Gates & Ratchets"
dị na `AGENTS.md`. Maka nyocha dị mkpa, nhazi ọkwa ntozu-oke, na atụmatụ mmegharị
nke otu sistemụ ahụ na-adabereghị na ngwá ọrụ ọ bụla, lee
[Quality Gate Playbook](../ops/QUALITY_GATE_PLAYBOOK.md).

## Ndepụta gate na profaịlụ ọgbaọsọ

### Nnabata onye a họọrọ

Usoro ọrụ CI na Quality Gates na-emepụta mkpebi kwụsie ike nke ọ bụla: `Gate / CI` na
`Gate / Quality`. Amụma nnabata ha nke a na-edebe n'ụdị na-edepụta ọrụ upstream ọ bụla
dị ka ihe achọrọ ma ọ bụ ndụmọdụ. Ọrụ achọrọ nke metụtara ga-agara nke ọma: nsonaazụ
furu efu, nke a kagburu, nke a gafere, nke na-echere na nke amaghi enweghị ike iguzobe
PASS. Nhazi dị irè nke bụ naanị-akwụkwọ ma ọ bụ naanị-katalọg nwere ike ime ka ụzọ
koodu ghara imetụta; PR draft abụghị onye a nabatara. Akara `hotfix` anaghị ewepụ ihe
akaebe achọrọ.

Usoro ọrụ abụọ ahụ na-ekpuchi PR na-abanye n'ime alaka main/release, push na `main`,
dispatch aka na ihe omume merge group. Push, dispatch na merge group na-agba nhọrọ
zuru oke. Push na `release/**` anaghị amalite ha (2026-10-18): mgbanwe ọ bụla agbaala
matrix na PR ya, na ngwakọta e jikọtara bụ ọrụ Release-Green (`docs/ops/RUNNER_BOX.md`
→ Hosted lane). Forks na merge groups na-eji hosted runners maka ọrụ ndị ga-ahọrọ
self-hosted runners; a ga-enyocha ikike hosted zuru oke tupu mwepụta.

Akwụkwọ nnata JSON ọ bụla na-egosi SHA e mere checkout, ọgbaọsọ usoro ọrụ na mbọ.
CLI na-ajụ ihe adabaghị n'etiti SHA nke checkout na ihe omume. Ule usoro ọrụ na-eke
ndị otu amụma na ndepụta `needs` nke ọrụ mkpebi ka ụzọ ọhụrụ ma ọ bụ nke e wepụrụ
ghara ịfụfu n'ime nzuzo. Akwụkwọ nnata ndị ahụ na-ekpuchi usoro ọrụ nke ha, ọ bụghị
mbipụta, mwunye, ma ọ bụ ihe dị n'ime ngwá nchọpụta ndụmọdụ dị adị. Ịmee ka aha
nyocha abụọ ahụ rụọ ọrụ n'iwu alaka bụ mgbanwe nchịkwa dị iche; itinye ọrụ ndị a
anaghị n'onwe ya chebe alaka.

### Ndepụta nchọpụta statik

Ndepụta npm-alias nke a na-edebe n'ụdị na ndị otu nchọpụta statik bi na
`config/quality/gate-manifest.json`. Gba `npm run check:gate-manifest` iji nyochaa
aha script na iwu ziri ezi megide `package.json`; mgbakwunye, mwepụ na ịgbanwe iwu
na-eme ka hook mpaghara na ọrụ nhazi mgbanwe dị na CI daa. Alias abụghị ọrụ usoro
ọrụ, ihe atụ matrix ma ọ bụ ikpe ule: a gaghị-egosi ọnụ ọgụgụ ndị a dị ka ihe nwere
ike ịgbanwe ibe ya.

Jiri `npm run quality:scan -- --list` ma ọ bụ `npm run quality:scan:fast -- --list`
chọpụta alias a họọrọ na-enaghị agba ha ọrụ. Runner ahụ na-akpọ npm entrypoint, ya
mere a na-echekwa runtime ya (gụnyere Bun ebe a haziri ya). Manifest na-edekọ alias
ndị dị n'èzí profaịlụ ndị ahụ dị ka ndị a kpọrọ iche iche, ma a machibidoro iwu
nlekọta n'ime profaịlụ nchọpụta nke naanị-ịgụ.

Profaịlụ ndị a na-ekpuchi naanị nchọpụta statik. Ha anaghị akwado ule ngwaahịa,
mkpuchi, nkwakọba, nyocha mpụga ma ọ bụ nnabata mwepụta zuru oke nke onye a họọrọ.
Nnabata usoro ọrụ na-eji `config/quality/admission-policy.json` e jikọtara na
`scripts/quality/admission-verdict.mjs`. Profaịlụ onye na-elele mwepụta ka dị iche;
chọpụta nyocha ha metụtara na akwụkwọ nnata ha n'onwe ha. Ndepụta ederede dị n'okpuru
bụ ihe ntụaka, ọ bụghị ihe akaebe na gate gara n'ezie.

Scripts bi n'okpuru `scripts/check/` (gate amụma) na `scripts/quality/` (injin ratchet).
Isi eziokwu nke CI bụ `.github/workflows/ci.yml`.

### Ụzọ ngwa-ngwa nke Release PR (`quality.yml`)

`.github/workflows/quality.yml` na-ezụzu CI na PR main/release, push na `main`,
dispatch na merge groups. PR na-eji nyocha ngwa-ngwa e kpuchara site na ụzọ. A wepụrụ
build oyiri nke a gbanyụrụ ruo mgbe ebighị ebi; nyocha build/package/boot n'ezie ka
dị na CI.

| `Fast Quality Gates`                             | PR koodu; nyocha statik, typecheck, typecheck dashboard, ule unit metụtara                                                                                                                       | Ee                |
| `Forgotten sibling tests`                        | PR koodu; modul a gbanwere nke a sotere ruo ndị na-eji ha statik na ule sibling a họọrọ; a na-akọ ụzọ barrel na dynamic-import dị ka nyocha ndụmọdụ, yana ndị e wepụrụ n'allowlist a kpọtụrụ aha | **Ndụmọdụ**       |

#### Akụkọ ule sibling a chefuru

`npm run check:forgotten-sibling-tests` na-eji ọzọ import resolver dị n'azụ maapụ mmetụta ule.
Maka module mmepụta ọ bụla gbanwere, ọ na-akọwa usoro `changed module/symbol -> static consumer -> candidate sibling test` nke a pụrụ ịtụpụta mgbe candidate test ahụ anọghị na diff nke pull request. A na-edebe nchịkọta Markdown na nsonaazụ JSON dị ka workflow artifact `forgotten-sibling-tests` maka ịtụle ka ọ dị tupu a malite rollout ọ bụla na-egbochi.

Barrel re-exports na dynamic imports bụ naanị nyocha nhazi; ha anaghị emepụta nchọpụta na-egbochi. Exceptions a tụlere bi na
`config/quality/forgotten-sibling-allowlist.json`. Entry ọ bụla ga-akpọ aha consumer na candidate test, nye ihe kpatara ya nke oke, jikọọkwa GitHub issue ma ọ bụ pull request. Entries na-ezighi ezi na-ada n'ọnọdụ mechiri emechi. Exceptions enweghị ike igbochi candidate test a hichapụrụ ma ọ bụ diff na-agbakwụnye `.skip`/`.todo`; ịbelata assertion na ndị ọzọ ịkpuchie ka nọ n'aka
`check:test-masking` gate nke na-egbochi n'onwe ya.

#### `check-ui-value-drift` — gate ntụgharị asụsụ ochie

Ọ na-ekwụdo otu mmebi i18n nke gates ndị ọzọ na-apụghị ịhụ n'usoro ha: e degharịa otu
value Bekee ọzọ, ma ntụgharị asụsụ sitere na Bekee _gara aga_ ka nọrọ n'azụ, ka ndị ọrụ
na-abụghị ndị Bekee na-agụkwa ederede e dere n'okwukwe zuru ezu nke ugbu a na-ezighị ezi.

Nke a mere n'ezie. E degharịrị `oauthModal.googleOAuthWarning` mgbe Antigravity
login helper rutere (#5203); **locale 39 n'ime 43** ka ji ederede na-agwa ndị ọrụ ka ha
"depụta URL zuru oke ma tinye ya n'okpuru" — usoro nke na-apụghị ịgụsị maka provider ahụ.
Ọ gara na-enweghị onye rịb ama ruo #8463 n'ihi na:

- `sync-ui-keys` na-ejupụta naanị keys ndị **enweghị**, ọ naghị ejupụta ndị **ochie**;
- `check-ui-keys-coverage` na-agụta _ịnọ_ nke key, yabụ ntụgharị asụsụ ochie na-agụta dị ka e kpuchiri ya;
- `check-translation-drift` na-eso ntụgharị akwụkwọ `docs/i18n/<locale>/**.md` —
  ọ naghị agụ `src/i18n/messages/*.json` ma ọlị. Na-egbochi na job `docs-sync-strict`
  kemgbe re-sync 2026-09: dezie core doc → `npm run i18n:run -- --files=<doc>` (ọkwa section, dị ọnụ ala).

**Nke na-ele diff anya, ọ bụghị nke baseline na-akwado.** Ọ na-atụnye `en.json` na merge base megide
working tree; maka key ọ bụla nke uru Bekee ya gbanwere, locale ọ bụla ka na-ejide
ntụgharị asụsụ a naghị emetụ bụ ochie. Nke a mere n'echiche **ịme ka ụgwọ dị adị kwụsị (freeze)** — diff
enweghị ike igosi Bekee ochie nke ntụgharị asụsụ ogologo sitere, ya mere gate ahụ na-ekpe
ikpe naanị ihe mgbanwe ugbu a metụtara. Nhọrọ ọzọ ahụ (baseline hash maka key ọ bụla) ga-eri
faịlụ e mepụtara nke ~600 KB, ugboro atọ nke baseline kacha ukwuu dị adị, na-agbanwe agbanwe na i18n PR ọ bụla.

Ụzọ abụọ iji mezuo ya:

1. melite ntụgharị asụsụ ndị metụtara, ma ọ bụ
2. debe ha na `__MISSING__:<new english>` — runtime ga-enye Bekee e doziri
   (`src/i18n/request.ts::deepMergeFallback`, #7258) ma key ahụ ga-etinye n'ahịrị maka ntụgharị asụsụ.

Ọ bụrụ na **nkowa** string ahụ gbanwere, họrọ **ịgbanwe aha key ahụ**: key ọhụrụ enweghị ike
ịbụ nke sitere n'aka ntụgharị asụsụ ochie. Nke ahụ bụ usoro #8463 jiri.

```bash
npm run i18n:check-value-drift          # siri ike (ihe CI na-agba)
npm run i18n:check-value-drift:warn     # naanị akụkọ
BASE_REF=origin/release/vX.Y.Z npm run i18n:check-value-drift
```

**Ụdị koodu ọhụrụ (Clean-as-You-Code) — kemgbe 2026-08-30, naanị ụzọ ọsọ ọsọ PR**

## Iwu Ndepụta Ikike

Ọnụ ụzọ nyocha ọ bụla nke na-agaghị ada n’ihi mmebi ndị dịbu adị na-eji ndepụta ikike a kpọchiri akpọchi
(dịka, `KNOWN_STALE_DOC_REFS`, `KNOWN_MISSING`, `KNOWN_RAW_SQL`). Iwu ahụ bụ:

**Dozie isi ihe kpatara nsogbu ahụ; jiri ndepụta ikike naanị mgbe mmebi ahụ dịbu adị ma
enweghị ike idozi ya n’otu PR ahụ.**

Mgbe ị na-agbakwunye ntinye na ndepụta ikike:

1. Tinye nkọwa na-akọwa ihe mere e ji mee ya.
2. Rụtụ aka n’okwu nlekota ahụ (dịka, `// #3498 — Njirimara Phase 2, emebebeghị ya`).
3. Wepụ ntinye ahụ n’otu PR ahụ nke na-edozi mmebi ahụ — ntinye ochie nke na-anaghịzi
   egbochi mmebi na-arụ ọrụ bụkwa ntụpọ (mmanye iwu megide ntinye ochie nke 6A.3 ga-eme ka
   ọnụ ụzọ nyocha ahụ daa n’ihi ntinye ndepụta ikike na-enweghịzi ihe ọ metụtara ozugbo etinyere ya n’ọrụ).

**Etinyela** ntinye na ndepụta ikike iji mee ka ule gafee ngwa ngwa. Ọnụ ụzọ nyocha na-acha akwụkwọ ndụ ebe
ndepụta ikike na-aga n’ihu na-eto eto na-enye echiche ụgha banyere ịdịmma.

### Mgbe ọnụ ụzọ nyocha dara na PR gị

1. **Jiri nlezianya gụọ nsonaazụ ọnụ ụzọ nyocha ahụ** — ọ na-agwa gị kpọmkwem faịlụ ma ọ bụ akara nke
   mebiri iwu ahụ.
