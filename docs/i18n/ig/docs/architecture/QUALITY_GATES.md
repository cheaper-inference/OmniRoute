Ọ na-akọwa ọnụ ụzọ ọ bụla, ihe ọ na-enyocha, ọrụ CI ọ na-arụ n'ime ya, ma ọ na-eji
ntọala ratchet ma ọ bụ iwu ngafe/ọdịda, yana ma ọ na-egbochi build ka ọ bụ naanị ndụmọdụ.

Maka nchịkọta dị mkpirikpi na iwu allowlist, lee ngalaba "Quality Gates & Ratchets"
dị na `AGENTS.md`. Maka nyocha dị mkpa, nhazi ọkwa ntozu-oke, na atụmatụ mmegharị
nke otu sistemụ ahụ na-adabereghị na ngwá ọrụ ọ bụla, lee
[Quality Gate Playbook](../ops/QUALITY_GATE_PLAYBOOK.md).

## Ndepụta ọnụ ụzọ na profaịlụ mmezu

### Nnabata ndị ga-abụ ndị a họpụtara

Usoro ọrụ CI na Quality Gates nke ọ bụla na-ewepụta mkpebi kwụsie ike: `Gate / CI` na
`Gate / Quality`. Usoro iwu nnabata nke nwere ụdị ya na-edepụta ọrụ upstream ọ bụla dị ka nke achọrọ ma ọ bụ nke ndụmọdụ. Ọrụ achọrọ nke metụtara ya ga-eme nke ọma: nsonaazụ na-efu, kagburu, gafere, na-eche, ma ọ bụ nke a na-amaghị enweghị ike iguzobe PASS. Nhazi ziri ezi nke naanị-docs ma ọ bụ naanị-catalog nwere ike ime ka ahịrị koodu ghara ịdị mkpa; PR draft abụghị onye a nabatara. Label `hotfix` anaghị ewepụ mkpa nke ihe akaebe.

Usoro ọrụ abụọ ahụ na-ekpuchi PR ndị na-abanye na ngalaba main/release, pushes na `main`, dispatch nke aka, na ihe omume merge-group. Push, dispatch, na merge-group na-eme nhọrọ zuru ezu. Pushes na `release/**` anaghị ebido ha (2026-10-18): mgbanwe ọ bụla agbaalarị matrix na PR ya, ngwakọta e jikọtara ọnụ bụ ọrụ Release-Green (`docs/ops/RUNNER_BOX.md` → Ahịrị Hosted). Forks na merge groups na-eji hosted runners maka ọrụ ndị ga-ahọrọ self-hosted runners n’ọnọdụ ọzọ; a ga-enyocha na hosted capacity zuru ezu tupu mwepụta.

Akwụkwọ nnata JSON ọ bụla na-akọwa SHA a checkout-ro, workflow run na mbọ. CLI na-ajụ checkout/event SHA ndị na-adabaghị. Nnwale workflow na-ejikọta ịbụ onye so na policy na ndepụta `needs` nke ọrụ verdict ka lane ọhụrụ ma ọ bụ ewepụrụ ghara ifu n’enweghị onye hụrụ ya. Akwụkwọ nnata ndị a na-ekpuchi workflow nke ha, ọ bụghị mbipụta, deployment, ma ọ bụ ime nke scanner ndụmọdụ dị adị. Ịrụ ọrụ aha nlele abụọ ahụ na branch rules bụ mgbanwe nchịkwa dị iche; itinye ọrụ ndị a anaghị echekwa branch n’onwe ya.

### Ndepụta static scan

Ndepụta npm-alias nke nwere ụdị ya na ịbụ onye so na static-scan dị na
`config/quality/gate-manifest.json`. Gbaa `npm run check:gate-manifest` iji kwado aha script na iwu ziri ezi megide `package.json`; mgbakwunye, mwepụ, na mgbanwe iwu na-eme ka local hook na change-classification jobs dị na CI daa.
Alias abụghị workflow job, matrix instance, ma ọ bụ test case: a gaghị ewepụta ọnụ ọgụgụ ndị a dị ka ihe na-agbanwe ibe ha.

Jiri `npm run quality:scan -- --list` ma ọ bụ `npm run quality:scan:fast -- --list`
iji lelee aliases ndị a họọrọ n’enweghị ime ha. Runner na-akpọ npm entrypoint, ya mere a na-echekwa runtime ya (gụnyere Bun ebe ahaziri ya). Manifest na-edekọ aliases ndị na-adịghị n’ime profaịlụ ndị ahụ dị ka ndị a na-akpọ iche, a machibidokwara maintenance commands na read-only scan profiles.

Profaịlụ ndị a na-ekpuchi naanị static scan. Ha anaghị akwado product tests, coverage, packaging, external checks, ma ọ bụ nnabata mwepụta zuru ezu nke candidate. Workflow admission na-eji `config/quality/admission-policy.json` na `scripts/quality/admission-verdict.mjs` ejikọtara. Release-observer profiles ka dị iche; nyochaa checks na akwụkwọ nnata ndị metụtara ha n’onwe ha. Ndepụta e dere n’okpuru bụ ntụaka, ọ bụghị ihe akaebe na gate mere n’ezie.

Scripts dị n’okpuru `scripts/check/` (policy gates) na `scripts/quality/` (ratchet engine). Ebe bụ isi nke eziokwu CI bụ `.github/workflows/ci.yml`.

### Ụzọ ọsọ maka Release PR (`quality.yml`)

`.github/workflows/quality.yml` na-emeju CI na main/release PRs, pushes na `main`,
dispatch na merge groups. PRs na-eji fast checks nke path-filtered. E wepụrụ duplicate build nke a kwụsịrị ruo mgbe ebighị ebi; build/package/boot checks nke dị adị ka dị na CI.

| Job                                              | Scope                                                                                                                                                                                                       | Blocking          |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------- |
| `Docs Gates (fast-path)`                         | Docs/code PRs; API docs refs na docs-all                                                                                                                                                                    | Ee                |
| `Fast Quality Gates`                             | Code PRs; static checks, typecheck, dashboard typecheck, impacted unit tests                                                                                                                                | Ee                |
| `Forgotten sibling tests`                        | Code PRs; modules gbanwere nke e soro ruo na static consumers na candidate sibling tests; a na-akọ barrel na dynamic-import paths dị ka diagnostics ndụmọdụ, tinyere allowlist exceptions ndị a kpọtụrụ aha | **Ndụmọdụ**       |
| `Vitest (fast-path)`                             | Code PRs; fast vitest suite                                                                                                                                                                                 | Ee                |
| `Unit Tests fast-path`                           | Code PRs; unit suite nwere shards 4                                                                                                                                                                         | Ee                |
| `No new ESLint warnings`                         | Code PRs; lint guard nke maara suppressions                                                                                                                                                                 | Ee, gụnyere forks |
| `Merge integrity (changelog + generated skills)` | PR ndị na-abụghị draft; changelog na generated skill sync                                                                                                                                                   | Ee, gụnyere forks |

#### Report nke Forgotten sibling tests

`npm run check:forgotten-sibling-tests` na-ejikwa onye na-achọpụta mbubata nke dị n’azụ maapụ mmetụta ule.
Maka modul mmepụta ọ bụla gbanwere, ọ na-akọ usoro
`changed module/symbol -> static consumer -> candidate sibling test` ndị a na-ekpebi mgbe niile mgbe ule
onye a chọrọ adịghị na ọdịiche arịrịọ-mwekota. A na-echekwa nchịkọta Markdown na nsonaazụ JSON dịka
ihe nrụpụta usoro `forgotten-sibling-tests` maka nhazi tupu ewebata mgbochi ọ bụla.

Nbugharị aha barrel na mbubata dị ike bụ naanị nyocha nchọpụta; ha anaghị emepụta
nchọpụta na-egbochi. Mwepu ndị a nyochara dị na
`config/quality/forgotten-sibling-allowlist.json`. Ndenye ọ bụla ga-akpọpụta onye na-eji ya na ule
onye a chọrọ, nye ihe kpatara doro anya, ma tinye njikọ gaa na okwu GitHub ma ọ bụ arịrịọ mwekota. Ndenye ndị mebiri emebi na-eme ka usoro daa n’ụzọ mechiri emechi. Mwepu enweghị ike igbochi ule onye a chọrọ nke ehichapụrụ ma ọ bụ ọdịiche na-agbakwunye `.skip`/`.todo`;
ime ka nkwupụta sie ike ma ọ bụ ụzọ mkpuchi ndị ọzọ ka bụ ọrụ nke ọnụ ụzọ
`check:test-masking` nke na-egbochi n’onwe ya.

- `check-ui-keys-coverage` na-agụ naanị _ịnọ_ nke igodo, ya mere nsụgharị ochie na-enweta akara na ọ kpuchiri;
- `check-translation-drift` na-enyocha naanị enyo akwụkwọ `docs/i18n/<locale>/**.md` —

  2026-09: dezie isi akwụkwọ → `npm run i18n:run -- --files=<doc>` (ọkwa ngalaba, dị ọnụ ala).

**Ọ na-amata ọdịiche, ọ bụghị baseline.** Ọ na-atụnyere `en.json` dị na merge base na

**Ụdị koodu ọhụrụ (Clean-as-You-Code) — kemgbe 2026-08-30, naanị ụzọ ọsọ ọsọ PR**

Na event `pull_request`, `quality.yml` na-enyefe `--base-ref <PR base SHA>` na `check:file-size`,
`check:complexity-ratchets` na `check:dead-code`. Maka `check:complexity-ratchets` na
`check:dead-code`, ọnụ ụzọ ahụ na-atụnyere HEAD na merge-base **naanị n'ime faịlụ ndị PR
metụrụ** (`scripts/check/newCodeMode.mjs`: a na-emepụta merge-base n'ime
`git worktree` nwa oge, ESLint/knip na-agba ebe ahụ na na HEAD, wee gbakọọ ọdịiche nke ọnụ ọgụgụ
kwa faịlụ):

- **na-egbochi** — PR tinyere mmebi cyclomatic/cognitive ma ọ bụ dead exports na faịlụ ndị ọ gbanwere
  (`complexityNewCode=`, `cognitiveComplexityNewCode=`, `deadExportsNewCode=` n'ime log);

  eme ka PR na-enweghị mmejọ daa; a na-akpụkọ drift ahụ ọzọ n'oge mmezi release, ọrụ headroom

ọ na-enyocha faịlụ source na test ọ bụla dị n'osisi ahụ, na-eji `git show` gụọ ọnụ ọgụgụ ahịrị nke

dị na ntọala ahụ. A na-akọ ntụgharị ntọala gafere oke ahụ (`base drift herdado`) mana ọ dịghị

## Ịchekwa Mbelata Ratchet — ụzọ mgbada (#8584)

Ratchet ahụ bụ naanị ọkara akpaaka, ọ bụkwa ọkara na-ezighi ezi. **Ibulite** cap bụ

mbelata (−1); e dekwara “mee ka ọ sie ike site na `--update` na cycle na-esote” ugboro 31 ma mee ya
naanị otu ugboro. Cap nke na-adị ndụ karịa koodu nke mere ka e nwee ya na-eji nwayọ agbanwe

`nightly-release-green.yml` → ọrụ **`bank-ratchet-shrinks`** na-emechi okirikiri ahụ:

|            |                                                                                                                   |
| ---------- | ----------------------------------------------------------------------------------------------------------------- |
| Na-arụ na  | `schedule` (3×/ụbọchị) + `workflow_dispatch` — a kpachapụrụ anya mee ka ọ **ghara** ịbụ `push`                    |

## Iwu Ndepụta Ikike

Ọnụ ụzọ nyocha ọ bụla nke na-agaghị ada n’ihi mmebi ndị dịbu adị na-eji ndepụta ikike a kpọchiri akpọchi

Mgbe ị na-agbakwunye ntinye na ndepụta ikike:
