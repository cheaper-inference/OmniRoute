Omenala JSON API ọnụ na-ejikọ ebe njedebe azụmahịa JSON nke na-anaghị asụ usoro OpenAI ma ọ bụ Anthropic. OmniRoute na-ejupụta template arịrịọ JSON, ziga ya na njedebe njedebe URL zuru ezu, gụọ azịza site na ụzọ nzaghachi wee weghachi ya na onye ahịa n'ụdị nke onye ahịa (Mmecha nkata, nzaghachi, ozi, ...).

Ọ bụ ọnụ ọnụ OpenAI dakọtara na `apiType: "custom-json"`; id ya nwere udi `openai-compatible-custom-json-<suffix>`. Ụdị dashboard adịghị ugbu a. Mepụta ma dezie ọnụ ndị a site na onye na-eweta-node API dị n'okpuru.

## Mepụta ọnụ

`POST /api/provider-nodes` (auth njikwa):

```json
{
  "type": "openai-compatible",
  "apiType": "custom-json",
  "name": "Business API",
  "prefix": "biz",
  "baseUrl": "https://api.example.com/v1/answer",
  "customHeaders": { "X-Tenant": "demo" },
  "customJson": {
    "method": "POST",
    "authType": "api-key",
    "authHeader": "X-Service-Key",
    "requestTemplate": {
      "project_id": "demo-project",
      "question": "{{prompt}}",
      "history": "{{messages}}"
    },
    "responsePath": "data.answer"
  }
}
```

- `baseUrl` bu** zuru oke** njedebe URL. Ọ nweghị ihe agbakwunyere (enweghị `/chat/completions`, enweghị `/models`) yana, n'adịghị ka ọnụ ọnụ OpenAI dakọtara ọzọ, ọ nweghị URL ndabara. Ọ ga-abụrịrị `http(s)`, na-enweghị nzere agbakwunyere ma ọ bụ `#fragment`, ọ na-agafe otu nche URL na-apụ apụ dị ka ọnụ ahịa ọ bụla na-enye, ma mgbe echekwara ọnụ na na arịrịọ ọ bụla.
- Ọnụ na-eziga igodo njikọ (`authType` `bearer` ma ọ bụ `api-key`, gụnyere nke ndabara) ga-eji `https://`. A na-anabata `http://` dị larịị naanị maka onye nnabata loopback (`localhost`, `127.0.0.0/8`, `::1`) ma ọ bụ jiri `authType: "none"`, nke na-ezigaghị igodo ọ bụla. Adreesị LAN nkeonwe (`10.x`, `172.16-31.x`, `192.168.x`) enweghị atụ: onye ọ bụla nọ na netwọk ahụ nwere ike ịgụ igodo ahụ. Ịchekwa ọnụ ọnụ dị otú ahụ na-ada na `400`, na ọnụ ụzọ echekwara na mbụ na-ada ada na arịrịọ ọ bụla nwere otu ozi ahụ, tupu izipu arịrịọ ọ bụla. Maka isi njedebe igodo na LAN, tinye ya n'azụ TLS (dịka ọmụmaatụ proxy ntụgharị).
- `customJson` kwadoro ya na Zod; Ajụjụ igodo amaghị. Ogige ọ bụla bụ nhọrọ:

| Ubi               | Ụkpụrụ                                | Ọdabara                                                |
| ----------------- | ------------------------------------- | ------------------------------------------------------ |
| `method`          | `POST`, `PUT`, `PATCH`                | `POST`                                                 |
| `authType`        | `bearer`, `api-key`, `none`           | `bearer`                                               |
| `authHeader`      | aha nkụnye eji isi mee mgbe `api-key` | `X-API-Key`                                            |
| `requestTemplate` | ihe JSON (≤ 64 KB, omimi ≤ 32)        | `{ "model": "{{model}}", "messages": "{{messages}}" }` |
| `responsePath`    | ụzọ ubi, ma ọ bụ `$` maka ahụ dum     | `choices[0].message.content`                           |

- Ihe nzuzo na-anọ na igodo API njikọ, ọ dịghị mgbe ọ dị na ndebiri. `bearer` na-eziga `Authorization: Bearer <key>`; `api-key` na-eziga `<authHeader>: <key>`. Isi edemede enweghị ike ịbụ `Host`, `Content-Type`, `Content-Length`, `Connection`, `Transfer-Encoding`, `Authorization`, `Cookie` ma ọ bụ nkụnye eji isi mee hop-by-hop. Na `none`, njikọ adịghị mkpa igodo.
- Ndị nkụnye eji isi mee kwụ ọtọ na-eji `customHeaders` oge niile (otu nkwado dị ka ọnụ ọnụ ndị ọzọ dakọtara; anabataghị nkụnye eji isi mee ihe ebe ahụ).

`PUT /api/provider-nodes/<id>` na-anabata otu `customJson` wee degharịa `baseUrl` na nhazi na njikọ ọ bụla dị na ọnụ. Ịhapụ `customJson` na-edobe config; Ịgbanwe `apiType` na `chat` ma ọ bụ `responses` na-ewepụ ya na ọnụ na njikọ ya.

Wee tinye njikọ na ọnụ ọnụ dị ka ọ na-emebu (`POST /api/providers` na id node) wee rịọ `<prefix>/<model>`, dịka ọmụmaatụ `biz/assistant-v1`. Ebe njedebe ekpughere enweghị ndepụta ụdị, yabụ tinye ids ụdị n'aka.

## Rịọ ndebiri

Templates dị larịị JSON. Uru eriri nwere ike ịnwe akara `{{placeholder}}` ; Ọ dịghị ihe a na-enyocha ma ọ bụ gbuo, ma ọ dịghị mgbe ọ bụla ọ bụla dochie igodo ihe.

| Onye njide           | Uru                                                                            |
| -------------------- | ------------------------------------------------------------------------------ |
| `{{prompt}}`         | Ederede ozi njirimara kachasị ọhụrụ (akụkụ ederede jikọtara ya na ahịrị ọhụrụ) |
| `{{messages}}`       | Mkparịta ụka n'ụdị nkata OpenAI                                                |
| `{{model}}`          | Ihe ngosi ụdị achọrọ, na-enweghị prefix nke ndị na-eweta ya                    |
| `{{stream}}`         | Mgbe niile `false` — njedebe njedebe na-eji otu akwụkwọ JSON                   |
| `{{request.<path>}}` | Arịrịọ nke ntụgharị asụsụ (OpenAI chat format).                                |

- Uru nke bụ kpọmkwem otu ebe nchekwa na-edobe ụdị JSON ya (`"{{messages}}"` na-aghọ nhazi); etinyere onye na-edobe n'ime eriri ogologo dị ka ederede.
- Onye na-edobe ebe na-ekpebi na ọ nweghị ihe ga-ada arịrịọ ya na HTTP 400 kama izipu ụgwọ akwụghị ụgwọ.
- Ụzọ na-eji akara ntụpọ na ọnụọgụ ọnụọgụ (`data.items[0].text`). `__proto__`, `prototype` na `constructor` jụrụ na igodo na ụzọ.

## Azịza ya

Uru dị na `responsePath` na-aghọ nzaghachi inyeaka: eriri na-agafe, ụkpụrụ JSON ndị ọzọ ka edobere usoro. Ogige na-efu ma ọ bụ `null`, ma ọ bụ ahụ na-abụghị JSON, na-alaghachi HTTP 502. A na-agafe ọkwa njehie n'elu. Maka ndị ahịa na-enuba OmniRoute na-echere nzaghachi JSON dum wee wepụta ya dị ka otu ọdịnaya chunk gbakwunyere nchacha; nke a abụghị nkwanye ugwu. Edepụtaghị oku akụrụngwa na mpaghara ojiji.

## Emeghachibeghị ya

Arịrịọ azụmahịa nwere ike inwe mmetụta ọ bụrụgodị na ọ daa. OmniRoute ya mere ezipu ya otu ugboro:

- ọ dịghị njem ọzọ na-enweghị redirect na-esonụ;
- ọ dịghị agbalị ọzọ njikọ (akaụntụ fallback) — ọdịda na-eweghachiri dị ka-dị na njikọ adịghị mma;
- enweghị ndaba na ebumnuche ngwakọta na-esote, ọbụlagodi maka nzaghachi efu ma ọ bụ nke dara ada.

Arịrịọ ndị ahịa dị iche, yana paịlụ ngwakọta nke na-akpọ ọtụtụ ụdị n'ezoghị ọnụ, ka na-akpọku njedebe njedebe n'adabereghị.

## Na-anwale ọnụ ọnụ

Ịchekwa njikọ, njikọ** Nwalee** bọtịnụ na nyocha ahụike ndabere anaghị akpọ ebe njedebe: naanị ha na-akwado nhazi echekwabara wee kọọ njikọ ahụ ka enweghị nkwenye.

`POST /api/provider-nodes/validate` nwere `"apiType": "custom-json"` na oghere ọnụ (`baseUrl`, `apiKey`, `customJson`, nhọrọ `customHeaders` na `modelId`) na-eziga kpọmkwem otu arịrịọ n'ezie, yana `ping` dị ka ederede njirimara kachasị ọhụrụ. Ọ na-aza `{ "valid": true }` ma ọ bụ ọkwa elu (ọ dịghị mgbe ahụ elu).
