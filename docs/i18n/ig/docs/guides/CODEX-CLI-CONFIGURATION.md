> **TOML bụ naanị usoro na-arụ ọrụ.** Codex ọgbara ọhụrụ na-agụ naanị
> `~/.codex/config.toml` (e jiri codex-cli 0.147.0 nyochaa ya: `codex --help`
> kọwara na `-c/--config` na-akagbu ntọala ndị “loaded from
> `~/.codex/config.toml`”). `~/.codex/config.yaml` ochie bụ nke npm CLI
> gara aga, a na-eleghara ya anya n’enweghị ọkwa ọ bụla. Ihe nrụpụta ntọala
> dị na dashboard (`/api/cli-tools/apply`, ngwá ọrụ `codex`) na-ede TOML site
> na njikọta akpachapụ anya — a na-echekwa keys ndị dịbu na blocks nke providers
> ndị ọzọ, API key na-anọgide na `OMNIROUTE_API_KEY` (ọ dịghị mgbe ọ na-abanye
> na faịlụ ahụ), a na-akọkwa `config.yaml` ochie fọdụrụ dịka ndetu migration
> n’emetụghị ya aka.

## config.toml dị njikere ka e detuo ma mado

Jiri ụkpụrụ nke gị dochie `<YOUR_HOST>` na `<YOUR_KEY>`:

```toml
# ~/.codex/config.toml
model                          = "cx/gpt-5.5"
model_provider                 = "omniroute"
model_reasoning_effort         = "xhigh"
model_context_window           = 400000
model_auto_compact_token_limit = 350000
tool_output_token_limit        = 32768    # oke nchekwa akụkọ ihe mere eme maka oku ngwá ọrụ ọ bụla

[model_providers.omniroute]
name                 = "OmniRoute"
base_url             = "http://<YOUR_HOST>:20128/v1"
env_key              = "OMNIROUTE_API_KEY"
requires_openai_auth = false
wire_api             = "responses"
```

```bash
# ~/.bashrc ma ọ bụ ~/.zshrc — ezigbo uru key, etinyela ya na config.toml
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

### macOS: Codex etinyere n’ime ngwa ChatGPT

Ọ bụrụ na i tinyere Codex site na ngwa desktop ChatGPT, `codex` binary nwere ike
ịdị naanị n’ime app bundle ma ọ gaghị adị na shell `PATH` gị. Tinye resources
directory na faịlụ mmalite shell gị:

```bash
export PATH="/Applications/ChatGPT.app/Contents/Resources:$PATH"
```

Mepee shell ọhụrụ, wee nyochaa ya:

```bash
command -v codex
codex --version
```

### OmniRoute mpaghara na-enweghị authentication: placeholder key ezuru

Codex na-enyocha na environment variable nke `env_key` kpọrọ aha dị
**tupu** arịrịọ mbụ apụ na CLI. Ọ bụrụ na instance OmniRoute **mpaghara** gị
achọghị auth, placeholder ọ bụla na-abụghị ihe efu ga-arụ ọrụ:

```bash
export OMNIROUTE_API_KEY="${OMNIROUTE_API_KEY:-local}"
```

Jiri ezigbo key kama nke ahụ mgbe e chebere server OmniRoute gị ma ọ bụ mgbe ọ dị n’ebe dị anya.

> **Nhọrọ host ndị a na-ejikarị**
>
> | Ụzọ nnweta       | URL                           |
> | ---------------- | ----------------------------- |
> | Netwọkụ mpaghara | `http://192.168.0.1:20128/v1` |
> | Tailscale        | `http://100.x.x.x:20128/v1`   |
> | Loopback         | `http://localhost:20128/v1`   |

## `wire_api = "responses"` — ihe mere o ji arụ ọrụ maka models niile

Codex CLI kwụsịrị ịkwado `wire_api = "chat"` (Chat Completions) na Febrụwarị 2026 ma ugbu a **na-achọ** `wire_api = "responses"` (OpenAI Responses API). Ịtọ `wire_api = "chat"` na-eme ka mmalite daa ozugbo kemgbe v0.138.

Ọtụtụ providers, gụnyere GLM na Kimi, ka na-enye naanị Chat Completions endpoint. DeepSeek V4 na-enyezi Responses API nke ya yana endpoint dakọtara na Anthropic; OmniRoute na-eji Responses dịka ndabara ma na-enye connection DeepSeek ọ bụla ohere ịhọrọ ndakọrịta Anthropic.

**OmniRoute na-edozi nke a n’ụzọ doro onye ọrụ anya:**

```
Codex CLI
  → wire_api = "responses"
  → POST /v1/responses (OmniRoute)
    → OmniRoute na-ahọrọ protocol nke provider ahụ ma na-atụgharị ya mgbe ọ dị mkpa
    → POST /responses (DeepSeek V4) ma ọ bụ /chat/completions (Mistral / GLM / Kimi / ndị ọzọ)
```

Ọ dịghị mgbe ị ga-achọ translation proxy dị iche mgbe ị na-eji OmniRoute. **Models niile na-eji `wire_api = "responses"`** — OmniRoute na-ahụ maka ihe ndị ọzọ.

> **`wire_api` bụ ndabara** — field ahụ na-eji `"responses"` dịka ndabara, a pụkwara iwepụ ya kpamkpam na `config.toml`. Tọọ ya kpọmkwem naanị ma ọ bụrụ na ị na-edekọ ebumnuche ahụ.

## Windo ọnọdụ na mkpakọ

### Oghere nhazi token

| Oghere                           | Nkọwa                                                                                                                                                                                                                |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `model_context_window`           | Ngụkọta oke token maka model na-arụ ọrụ. Tọọ ya ka ọ bụrụ oke model ahụ kwupụtara.                                                                                                                                   |
| `model_auto_compact_token_limit` | Ọnụ ụzọ na-akpalite mkpakọ akụkọ ihe mere eme na-akpaghị aka. **Kachasị elu: 90% nke `model_context_window`** — a na-eleghara ụkpụrụ karịrị 90% anya na-enweghị ọkwa.                                                |
| `tool_output_token_limit`        | Oke token a na-echekwa maka nsonaazụ oku tool ọ bụla n'akụkọ ihe mere eme. Ọ na-egbochi otu nnukwu nzaghachi tool ijupụta na windo ahụ. **Nke a abụghị nsonaazụ kachasị elu** — ọ bụ oke nchekwa akụkọ ihe mere eme. |
| `compact_prompt`                 | Ntọgharị inline maka system prompt a na-eji mgbe a na-eme mkpakọ (v0.138+).                                                                                                                                          |

> **Nkọwa gbasara `model_max_output_tokens`**: Oghere a **abụghị akụkụ nke schema nhazi Codex CLI** (ọ dịghị na codebase Codex Rust). Ọ bụrụ na atọọ ya, a na-eleghara ya anya na-enweghị ọkwa. Atụkwasịla ya obi — jiri `tool_output_token_limit` chịkwaa oke nsonaazụ tool a na-echekwa n'akụkọ ihe mere eme.

## Mgbalị Ntụgharị Uche

Na-achịkwa ókè ụdịdị ahụ ga-eji “chee echiche” tupu ọ zaghachi.

| Uru      | Jiri ya maka                                          |
| -------- | ----------------------------------------------------- |
| `none`   | Enweghị ntụgharị uche — nzaghachi ozugbo              |
| `low`    | Ọrụ ndị dị mfe (ịgbanwe aha, ịhazi usoro)             |
| `medium` | **Ndabara sava** mgbe akọwapụtaghị ya                 |
| `high`   | Ọrụ etiti (imegharị koodu, ịchọta njehie)             |
| `xhigh`  | Nhazi ụlọ, nyocha miri emi, nsogbu ndị mgbagwoju anya |

```bash
# Gbanwee maka otu mkpọku
codex -c model_reasoning_effort=low "rename variable x to count"
codex -c model_reasoning_effort=xhigh "design the auth module"
```

Tọọkwa **nchịkọta** ntụgharị uche ka Desktop nwee ike igosipụta ederede echiche (ọ bụghị naanị ngwugwu ezoro ezo):

```toml
# ~/.codex/config.toml
model_reasoning_effort = "xhigh"   # ma ọ bụ ultra mgbe a na-akwado ya
model_reasoning_summary = "detailed"  # auto | concise | detailed | none
```

### Oke Echiche OmniRoute (ntọala sava)

N’elu igwe nnabata OmniRoute, **Settings → AI → Thinking Budget** ga-abụrịrị **`passthrough`** ka mgbalị/nchịkọta Codex ruo n’ọrụ dị n’elu. Ọnọdụ **`auto` strips** na-ewepụ oghere `reasoning` / `reasoning_effort` niile nke klayenti ma mee ka panel echiche tọgbọ chakoo ọbụna mgbe ahaziri Codex nke ọma.

Ntuziaka zuru ezu: [THINKING_BUDGET.md](./THINKING_BUDGET.md).

Mkpakọ na cache prompt anaghị adabere na nke a ma na-aga n’ihu ịrụ ọrụ n’okpuru `passthrough`.

## Profaịlụ — nhazi ndị a kpọrọ aha maka ụdịdị/usoro ọrụ ọ bụla

Profaịlụ na-enye gị ohere iji otu ọkọlọtọ gbanwee ụdịdị + windo context. Profaịlụ ọ bụla bụ faịlụ dị larịị
`~/.codex/<name>.config.toml` nke na-ekpuchi akụkụ nke `config.toml` bụ isi.

> **Iwu ịkpọ aha (Codex CLI v0.137+):** faịlụ ahụ ga-abụrịrị `~/.codex/<name>.config.toml` — **etinyela prefix `profile-`**.
> CLI na-atụgharị `-p kimi-k27` → `~/.codex/kimi-k27.config.toml`. Ọ bụrụ na ahụghị faịlụ ahụ, a ga-eji ndabara n’enweghị ọkwa ọ bụla.

```bash
codex --profile kimi-k27 "analyze 10k lines of this codebase"
codex -p glm52 "architecture review"
codex --profile deepseek-flash "rename variable"   # ngwa ngwa, dị ọnụ ala
```

## Iji `omniroute setup-codex` mepụta profaịlụ na-akpaghị aka

Ọ bụrụ na ị na-agba OmniRoute na VPS, ị nwere ike imepụta faịlụ profaịlụ na-akpaghị aka site na katalọgụ model dị ugbu a:

```bash
# Site na VPS (na-eji OmniRoute mpaghara na port 20128)
omniroute setup-codex

# Site na igwe ọ bụla — tụọ ya aka na VPS gị
omniroute setup-codex --remote http://100.x.x.x:20128 --api-key sk-xxx

# Lelee ihe ga-apụta n'ebughị faịlụ
omniroute setup-codex --remote http://100.x.x.x:20128 --dry-run

# Mepụta naanị profaịlụ GLM na Kimi
omniroute setup-codex --only glm,kimi

# Dee ha na ndekọ ahaziri iche
omniroute setup-codex --codex-home /path/to/.codex
```

Iwu ahụ na-eweta `/v1/models`, na-eji profaịlụ ahaziri nke ọma maka model ndị amaara, na-adabere na metadata katalọgụ maka model ederede ndị ọzọ dakọtara, ma na-ede `~/.codex/<name>.config.toml` maka nke ọ bụla. Ọ bụ idempotent — ọ dị mma ịgba ya ọzọ.

Ọ bụrụ na `config.toml` bụ isi enweghị nkọwa `model_providers.omniroute`, ịkpọ
`setup-codex` kpọmkwem ga-etinye nkọwa ahụ n'ime overlay ọ bụla emepụtara, na-eji endpoint
mpaghara ma ọ bụ remote ahọpụtara. Ọ naghị agbanwe faịlụ bụ isi. A ga-eketa nkọwa provider
dị adị, gụnyere endpoint ya na ntọala authentication ya. TOML bụ isi na-adịghị irè
ga-akwụsị mmepụta tupu e dee profaịlụ.

Mgbe ị nyere `--api-key` ma ọ bụ `OMNIROUTE_API_KEY`, provider akọwapụtara ọhụrụ ga-arụtụ aka na
`env_key = "OMNIROUTE_API_KEY"`; a naghị echekwa key ahụ n'onwe ya ma ọ bụ bipụta ya na
nlele tupu ide. Tọọ variable ahụ na environment ebe ị na-ebido Codex. Ọ bụrụ na enyeghị
key, nkọwa ọhụrụ ahụ agaghị achọ key, maka instance OmniRoute
ahaziri ịnakwere arịrịọ na-enweghị authentication.

Auto-sync katalọgụ a na-ahọrọ isonye na ya nke akọwara n'okpuru na-echekwa nkọwa provider ndị dịlarị
n'ime overlay mana ọ naghị ebido ntọala provider ọhụrụ; buru ụzọ hazie provider
site na setup kpọmkwem ma ọ bụ dashboard. A naghị egosi ntọala provider ndị dị adị
na nlele dry-run n'ihi na ha nwere ike ịnwe credentials ndị operator na-elekọta.

OmniRoute nwekwara ike ime **auto-sync** nke otu faịlụ profaịlụ ndị a mgbe nchọpụta/mbubata model provider gara nke ọma gbanwere katalọgụ dị ugbu a. Nke a bụ **ihe a ga-ahọrọ isonye na ya ma agbanyụghị ya na ndabara**: gbanye ya site na **CLI Code dashboard** ("CLI profile auto-sync" → Codex), ma ọ bụ tọọ `OMNIROUTE_AUTO_SYNC_CODEX_PROFILES=true` (ọ na-asọpụrụkwa `CLI_ALLOW_CONFIG_WRITES`, nke agbanyere na ndabara). Mgbe agbanyere ya, ọ na-ede naanị faịlụ profaịlụ `~/.codex/*.config.toml` dị iche iche; ọ dịghị mgbe ọ na-agbanwe `~/.codex/config.toml` nke na-arụ ọrụ/ndabara, ntọala Codex-lb, auth, ma ọ bụ nhọrọ provider.

## Ọrụ na-adịte aka

Ihe ndabara OmniRoute abụọ nwere ike mebie nnọkọ Codex CLI ọtụtụ awa. Ọ bụghịkwa Codex CLI ntọala — ha abụọ bi n'akụkụ OmniRoute. Ndị ọrụ na-akwaga nhazi site na proxies dị elu nke na-atụnye akaụntụ ma gbanyụọ nkwụsị ọrụ na-adakarị ma kwubie OmniRoute "enweghị ike ịkwado ogologo oge."

| Mgbaàmà                                                                        | O yikarịrị ka ọ kpatara ya                                                          | Mkpọchi                  |
| ------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------- | ------------------------ |
| Oge na-aga n'ihu na-agbanwe akaụntụ / cache ozugbo na-efunahụ n'etiti ntụgharị | Affinity TTL bụ `0` (nwere nkwarụ)                                                  | `sessionAffinityTtlMs`   |
| Njikọ na-anwụ n'etiti echiche na-enweghị ọsọ ọsọ na-eche ndị ahịa ihu          | Stream nche nche na-adịghị arụ ọrụ gbara ka nkeji iri gachara na-enweghị mkpụkọ elu | `STREAM_IDLE_TIMEOUT_MS` |

Mkparịta ụka ndị emetụtara: [#7126](https://github.com/cheaper-inference/OmniRoute/discussions/7126) (ogologo ọrụ na-adaba), [#5718](https://github.com/cheaper-inference/OmniRoute/discussions/5718) ( gịnị kpatara mmekọ na-apụ apụ). Ndepụta: [#7287](https://github.com/cheaper-inference/OmniRoute/issues/7287).

### 1. Oge mmekọ — pinye otu mkparịta ụka n'otu akaụntụ

**Ebube:** `sessionAffinityTtlMs = 0` (nkwarụ).

**Ebe ịtọ ya**

- Dashboard →** Ntọala → Routing** →** Mmekọrịta nnọkọ** →** Affinity TTL (sekọnd)** (`ComboDefaultsTab`)
- Ma ọ bụ ntọala PATCH nwere `sessionAffinityTtlMs` in** millisekọnd** (Zod nso `0`–`86_400_000`, ntụgharị ruo awa 24)

> A kpọgharịrị aha ya na #7274 site na Codex-naanị `codexSessionAffinityTtlMs`. A ka na-anabata igodo ihe nketa ka ọ bụrụ utu aha-agụ naanị; nhazi ọhụrụ kwesịrị iji `sessionAffinityTtlMs`. Mmekọrịta ugbu a na-emetụta** nke ọ bụla** onye na-eweta ozugbo TTL dị n'elu `0`, ọ bụghị naanị Codex — hụ [`docs/architecture/RESILIENCE_GUIDE.md`](../architecture/RESILIENCE_GUIDE.md) → Mmekọrịta Oge.

**Kedu ihe na-agbaji ma ọ nọrọ na 0**

Ntụgharị ọ bụla nke mkparịta ụka Codex nwere ọtụtụ ntụgharị na-emeri onwe ya site na atụmatụ combo na-arụ ọrụ ma nwee ike ịdaba na a** akaụntụ dị iche iche kwa ntụgharị** . Nke ahụ na-agbaji nnọkọ elu / cache ozugbo. OmniRoute na-enyocha Codex nnọkọ nkụnye eji isi mee (`x-codex-session-id` / `x-session-id` / `x-omniroute-session`) na mpaghara ahụ dị ka `prompt_cache_key` / `session_id` mgbe TTL karịrị `0` (`extractSessionAffinityKey` na `src/sse/services/auth.ts`).

**Akwadoro maka otu ọrụ ọtụtụ awa**

Tọọ TTL** n'elu ogologo elekere mgbidi a na-atụ anya nke ọrụ ahụ** (UI max bụ** 86400 sekọnd** = awa 24):

| Ogologo ọrụ a tụrụ anya ya | Affinity TTL (UI, sekọnd) | `sessionAffinityTtlMs` |
| -------------------------- | ------------------------- | ---------------------- |
| Awa ole na ole             | `14400` (4h)              | `14400000`             |
| N'abalị / ~ 12h            | `43200` (12h)             | `43200000`             |
| Ụbọchị zuru ezu            | `86400` (24h, kacha)      | `86400000`             |

Nbanye bụ ụma: imebi mmekọrịta na-akwado ibu-nhazi n'ofe akaụntụ; na-enyere ya aka ịga n'ihu maka otu nnọkọ ogologo oge. Ntuziaka a na-eme** ọ bụghị** gbanwee ndị na-arụ ọrụ — ndabara na-arụ ogologo ọrụ Codex ga-abanyerịrị.

### 2. iyi na-abaghị uru oge nkwụsị — egbula jụụ echiche tụgharịa

**Ebube:** `STREAM_IDLE_TIMEOUT_MS = 600000` (10 nkeji). Ọ na-eketa site na `REQUEST_TIMEOUT_MS` mgbe edobereghị ya; ntọala nkekọrịtara bụkwa 600000. Lee [`docs/guides/SETUP_GUIDE.md`](SETUP_GUIDE.md) → Timeouts.

**Kedu ihe na-agbaji na ndabara**

Ntụgharị echiche Codex / ngwa ọrụ na-agbachi nkịtị ihe karịrị nkeji iri** ọ dịghị ezigbo upstream chunk** bụ ike-emechi site na SSE na-adịghị arụ ọrụ nchedog (`open-sse/utils/stream.ts`). Onye ahịa na-ahụkarị njikọ efu dobe — dakọtara "kwụsị na-akpaghị aka na-enweghị ọkwa ọ bụla."

Nkọwa dị mkpa: OmniRoute's synthetic SSE** nkụda obi anaghị atọgharị** elekere na-abaghị uru. Naanị ezigbo mkpọ anụ ahụ na-emelite `lastChunkTime`. Ụdị dị jụụ nke ka na-eche echiche na-adị ka nke a kwụsịrị n'elu elu site n'echiche onye nche.

Undici arụghị ọrụ emetụtara: `FETCH_BODY_TIMEOUT_MS` (na-adabakwa n'otu usoro nkeji nkeji iri ahụ; `0` na-ewepụ ya). Maka nkwanye ugwu, `FETCH_TIMEOUT_MS` na-ekpuchi naanị ntọala njikọ / isi nke mbụ — ozugbo iyi ahụ na-arụ ọrụ, `STREAM_IDLE_TIMEOUT_MS` na `FETCH_BODY_TIMEOUT_MS` na-achịkwa ụlọ ahịa.

**Akwadoro maka otu ọrụ ọtụtụ awa**

Na gburugburu usoro OmniRoute (`.env` / compose / systemd):

```bash
# Disable stream idle + body inactivity cutoffs for long reasoning turns
STREAM_IDLE_TIMEOUT_MS=0
FETCH_BODY_TIMEOUT_MS=0
```

Ma ọ bụ bulite ha n'elu oghere dị jụụ kachasị ogologo ị tụrụ anya (ụkpụrụ bụ milliseconds):

```bash
# Example: allow up to 2 hours of silence between upstream chunks
STREAM_IDLE_TIMEOUT_MS=7200000
FETCH_BODY_TIMEOUT_MS=7200000
```

Malitegharịa OmniRoute mgbe ịgbanwere env vars ndị a.

### Concrete uzommeputa — multi-hour Codex ọrụ

1. **Tinye akaụntụ ahụ:** Dashboard → Settings → Routing → Oge mmekọ → Affinity TTL = `43200` (12h) ma ọ bụ `86400` (24h max).
2. **Welie/ gbanyụọ mpụ ndị na-abaghị uru** na gburugburu OmniRoute:

```bash
STREAM_IDLE_TIMEOUT_MS=0
FETCH_BODY_TIMEOUT_MS=0
```

3. Debe Codex `config.toml` (`wire_api = "responses"`, ziri ezi `base_url`, `OMNIROUTE_API_KEY`) — enweghị Codex-akụkụ affinity/idle knobs dị maka omume abụọ a.
4. Malitegharịa OmniRoute, wee malite ogologo ọrụ Codex.

### Mkpebi ezighi ezi (#7287)

| Mkpọchi                  | Ndabara ụgbọ mmiri | Gbanwee na ntuziaka a?                                                                               |
| ------------------------ | ------------------ | ---------------------------------------------------------------------------------------------------- |
| `sessionAffinityTtlMs`   | `0` (apụ)          | **Mba** — na-anọgide na-nbanye (load-balance vs continuity; lee Mkparịta ụka #5718)                  |
| `STREAM_IDLE_TIMEOUT_MS` | `600000` (10 min)  | **Mba** — na-anọ nkeji iri maka okporo ụzọ izugbe; ndị ọrụ Codex ogologo na-ebuli ma ọ bụ gbanyụọ ya |

Ịtụgharị ndabara n'ụwa niile ga-agbanwe omume maka onye ahịa ọ bụla nke ihe atụ, ọ bụghị naanị Codex. Detuo isi ihe; Hapụ ndị ndabara naanị ruo mgbe mkpebi onye ọrụ doro anya kwuru ihe ọzọ.

### Na-achọpụta mbepụ na-abaghị uru

Mgbe onye nche na-abaghị uru gbara ọkụ, OmniRoute na-edekọ ahịrị dị ka:

```text
[STREAM] Idle timeout: no data from codex for 600000ms (model: cx/gpt-5.5)
```

Grep maka `Idle timeout: no data from` (ma ọ bụ koodu `stream_idle_timeout` / aha njehie `StreamIdleTimeoutError`). Akụkụ ndị na-eweta bụ OmniRoute ọ bụla ejiri mee ihe maka arịrịọ ahụ (`codex`, id onye na-eweta ọrụ ọzọ, ma ọ bụ `provider` ma ọ bụrụ na amabeghị) — ọ bụghị mgbe niile ka ọ bụ eriri nkịtị `codex`.

## Nchọpụta na idozi nsogbu

**`Error: wire_api = "chat" is no longer supported`**
Wepụ `wire_api = "chat"` na nhazi gị. Tọọ `wire_api = "responses"` ma ọ bụ hapụ oghere ahụ (ọ na-eji `"responses"` na ndabara kemgbe v0.138).

**`Error: model not found`**
Nyochaa na model ahụ dị na OmniRoute ma nwee prefix ziri ezi. Jiri `omniroute models list` ma ọ bụ mepee `/dashboard/providers/<provider>`.

**`Authentication error`**
Kwenye na ebupụla `OMNIROUTE_API_KEY`: `echo $OMNIROUTE_API_KEY`.

**`ERROR: Missing environment variable: OMNIROUTE_API_KEY`**
Codex na-enyocha na env var ahụ dị tupu o zipụ arịrịọ mbụ. Bupụ
igodo n'ezie maka sava e chebere, ma ọ bụ placeholder na-abụghị ihe tọgbọ chakoo dịka
`OMNIROUTE_API_KEY=local` mgbe instance OmniRoute **local** gị anaghị
achọ nkwenye njirimara. Malitegharịa shell ma ọ bụrụ na ị gbakwunyere ya na `~/.bashrc` ma ọ bụ `~/.zshrc`.

**`Connection refused`**
Nyochaa na OmniRoute na-arụ ọrụ nakwa na host/port nke `base_url` ziri ezi maka netwọkụ gị (local vs Tailscale vs VPS).

**Session na-akwụsị na mberede mgbe ọ rutere nso oke context**
Tọọ `model_context_window` na `model_auto_compact_token_limit` kpọmkwem. Lee tebụl context window dị n'elu.

**Compaction na-amalite oge gafere**
Belata `model_auto_compact_token_limit` ruo 80–85% nke window ahụ. Etinyekwala ya karịa 90%.

**Profile anaghị ebunye (`-p <name>` ka a na-eleghara anya n'enweghị ozi)**
Kwenye na faịlụ ahụ dị na `~/.codex/<name>.config.toml` (enweghị prefix `profile-`). Gbaa `ls ~/.codex/*.config.toml`.

**Ọrụ Codex toro ogologo na-akwụsị n'etiti ya / na-agbanwe akaụntụ n'etiti turns**
Lee [Ọrụ na-ewe ogologo oge](#long-running-tasks). Kwado session affinity (TTL karịrị ogologo oge ọrụ ahụ) ma bulie ma ọ bụ gbanyụọ `STREAM_IDLE_TIMEOUT_MS` / `FETCH_BODY_TIMEOUT_MS`. Jiri grep chọọ `Idle timeout: no data from` n'ime log OmniRoute.
