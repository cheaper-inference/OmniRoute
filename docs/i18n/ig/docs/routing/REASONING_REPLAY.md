OmniRoute na-ejide `reasoning_content` inyeaka emepụtara site n'ụdị ụdị echiche wee na-emegharị ya n'ụzọ doro anya na arịrịọ ọtụtụ ntụgharị mgbe onye na-eweta elu chọrọ ya. Nke a na-ewepụ njehie HTTP 400 nke ndị na-eweta ọrụ siri ike na-ebuli mgbe mkparịta ụka onye ahịa na-efunahụ echiche ntụgharị mbụ.

## Ihe Mere Nke a Ji Dị

Ọtụtụ ndị na-enye ụdị echiche na-ajụ ntụgharị nsonye ma ọ bụrụ na nke a** Ozi enyemaka gara aga gụnyere `reasoning_content` izizi** . Mgbago elu weghachiri 400 nwere ozi dịka:

```
Param Incorrect: The reasoning_content in the thinking mode must be passed back to the API.
```

Mana ndị ahịa na-ahụkarị (Cursor, Cline, Roo Code, OpenAI SDK) wepụ `reasoning_content` na akụkọ ihe mere eme ha na-emegharị. OmniRoute na-eweghachi ya site na cache n'akụkụ sava ka arịrịọ nke elu na-ahụ anya na-agbanwe agbanwe. Esemokwu #1628 webatara ntachi obi memory/SQLite ngwakọ ka cache wee dịrị ndụ usoro malitegharịa.

## Nhazi

```
Turn N (assistant generates):
  → response contains reasoning_content + tool_calls
  → if requiresReasoningReplay(provider, model): cacheReasoningFromAssistantMessage()
      writes (memory + DB), one entry per tool_call.id within the request scope
  → forward response to client (which may or may not retain reasoning)

Turn N+1 (client sends follow-up):
  → translator detects: requiresReasoningReplay(provider, model) === true
  → for each assistant message with tool_calls and no reasoning_content:
      lookupReasoning(buildToolCallCacheKey(scope, toolCalls[0].id)) → memory → DB
      hit  → msg.reasoning_content = cached; recordReplay()
      miss → msg.reasoning_content = "" (legacy fallback for older DeepSeek)
  → upstream sees consistent history → no 400
```

Njide na-eme na `open-sse/handlers/chatCore.ts` (saịtị abụọ, na saịtị oku `cacheReasoningFromAssistantMessage` abụọ). Mkpọgharị na-eme na `open-sse/translator/index.ts` ka mmanye schema gachara mana tupu izipu ya.

A na-echekwa ndenye ọkpụkpọ oku n'okpuru `buildToolCallCacheKey()`, mgbari nke oke arịrịọ yana id oku ngwaọrụ, yabụ otu id ejiri igodo API ọzọ ma ọ bụ nnọkọ anaghị ahọrọ ntinye. Oke ahụ sitere na `buildReasoningCacheScope()`: id igodo API, gbakwunyere igodo nnọkọ mgbe arịrịọ ahụ nwere otu. Kọlụm `tool_call_id` na dashboard gosipụtara mgbari a maka ndenye ndị ahụ.

A na-atụgharị ntụgharị enyemaka dị larịị (na-abụghị ọkpụkpọ oku) n'ụzọ dị iche: `buildAssistantMessageCacheKey()` na-agbari oge nnọkọ yana gbakwunyere transcript nke OpenAI-format emeziri ruo n'akụkụ ahụ, n'ihi na DeepSeek chọrọ echiche nke _ọ bụla_ tupu oge `tools` dị. Maka azịza-API lekwasịrị anya (dịka ọmụmaatụ `opencode-go/deepseek-v4-flash`, gafere `/responses`) ahụ dị n'elu na-ebu `input`, ọ bụghị `messages`, yabụ `translateRequest()` (`open-sse/translator/index.ts`) na-akọ transcript pivot ọ gbarie site na nhọrọ ịkpọghachi ma saịtị weghara na-agbari otu transcript ahụ. Nkwụghachi nzaghachi nzaghachi na-agba na pivot OpenAI maka usoro isi mmalite ọ bụla, yabụ a na-emegharịkwa ndị ahịa Anthropic Message (Claude → OpenAI → Responses) kwa.

## Nchekwa — ngwakọ ebe nchekwa + SQLite

Ụzọ na-ekpo ọkụ na-eji `Map` in-memory (LRU-site-creation) kwadoro site na tebụl SQLite maka mgbake mgbake na visibiliti dashboard.

| oyi akwa    | Mmejuputa                                      | Ebumnuche                                            |
| ----------- | ---------------------------------------------- | ---------------------------------------------------- |
| Ebe nchekwa | `Map` na `open-sse/services/reasoningCache.ts` | Nleba anya ngwa ngwa, chụpụrụ ndị kacha ochie na 200 |
| DB          | tebụl `reasoning_cache` (`src/lib/db/`)        | Na-aga n'ihu na mmalite mmalite, stats draịva        |

Edere na-aga ma. Na-agụ na mbụ nyochaa ebe nchekwa, wee daa azụ na DB (DB hits na-akwalite azụ n'ime ebe nchekwa). ọdịda DB adịghị egbu egbu — ebe nchekwa nchekwa na-aga n'ihu na-eje ozi n'ụzọ dị ọkụ.

**Ihe ndapụta:**

- TTL: `2h` (`TTL_MS = 2 * 60 * 60 * 1000`)
- Ndenye ebe nchekwa kacha: `200` (`MAX_MEMORY_ENTRIES`)
- Nchụpụ: `createdAt` kacha ochie

## Atụmatụ nchekwa data

Mbugharị: `src/lib/db/migrations/033_create_reasoning_cache.sql`

```sql
CREATE TABLE IF NOT EXISTS reasoning_cache (
  tool_call_id   TEXT PRIMARY KEY,
  provider       TEXT NOT NULL,
  model          TEXT NOT NULL,
  reasoning      TEXT NOT NULL,
  char_count     INTEGER NOT NULL DEFAULT 0,
  created_at     TEXT NOT NULL DEFAULT (datetime('now')),
  expires_at     INTEGER NOT NULL
);
```

Index: `expires_at`, `provider`, `model`, `created_at`. A na-echekwa `expires_at` dị ka nkeji oge Unix; oyi akwa SELECT na-emezi ụkpụrụ ederede nkeonwe site na `EXPIRES_AT_EPOCH_SQL`.

## Ndetu arụmọrụ

- **Hichapụ:** `cleanupReasoningCache()` na-ehichapụ ndenye ebe nchekwa kubie ume ma na-agba `DELETE FROM reasoning_cache WHERE expires_at <= unixepoch('now')`. Ndị ọrụ na-elele ahụike na-akpọ nke a kwa oge.
- **mgbake okuku:** Ka ịmalitegharịa, ebe nchekwa adịghị efu mana DB ka nwere ndenye agwụbeghị. Nchọ mbụ maka `tool_call_id` e nyere bụ ihe ọkụkụ DB ; Nleba anya na-esote bụ ebe nchekwa akụ.
- **Enweghị echiche, enweghị cache:** `cacheReasoningFromAssistantMessage` na-alaghachi `0` mgbe ozi inyeaka enweghị mpaghara `reasoning_content` / `reasoning`, yabụ nzaghachi ndị na-abụghị echiche anaghị efu ihe ọ bụla.
- **Edemedekwara nke ọma:** ma saịtị oku na `chatCore.ts` (na-abụghị nkwanye na nkwanye) na-akpọ `cacheReasoningFromAssistantMessage()` naanị mgbe `requiresReasoningReplay(provider, model)` bụ `true` — otu predicate na-agụ n'akụkụ checks. Ihe nrụnye na-emetụghị onye na-eweta replay kwụsị ịkwụ ụgwọ maka ide, mmelite ndeksi na try/catch na nzaghachi ọ bụla na-enye echiche.
- **Ndị na-eweta ihe adịghị mkpa:** Mgbe `requiresReasoningReplay` bụ `false` na usoro ebumnuche bụ OpenAI, onye ntụgharị** ibe** ubi `reasoning_content` ọ bụla sitere na ozi na-apụ apụ — OpenAI Chat Mmecha anaghị anabata ya.

## Muse Opaque-Reasoning Nwe

Muse (`muse-code`) na-eweghachite echiche opaque nke onye na-akpọ oku (`encrypted_content`). Ịmegharị ya n'okpuru akaụntụ dị iche ma ọ bụ nzere echetara na-ada n'elu, ya mere arịrịọ OAuth nke ala na-eji nwe ọkwa-ọkwa kama ntụgharị nke arịrịọ ọ bụla (`src/sse/services/museSessionOwnership.ts`, manyere na `src/sse/handlers/chat.ts`). Njikọ igodo API ahọpụtara nke ọma yana nhazi naanị igodo API na-ejigide ụzọ ụzọ ha dị na-enweghị ụdị nwe a.

- Weta ID kwụsiri ike na ntụgharị ọ bụla: `x-omniroute-session-id`, `x-omniroute-session`, `x-session-id`, ma ọ bụ `x-codex-session-id`; ọzọ jiri `prompt_cache_key`, `session_id`, `conversation_id`, ma ọ bụ `metadata.session_id` n'ime ahụ (n'usoro ụzọ ahụ). Na-efu ma ọ bụ oghere IDs nloghachi 400 mgbe akaụntụ OAuth abụọ ma ọ bụ karịa na-arụ ọrụ; na otu akaụntụ OAuth ọ nweghị ihe ị ga-atụgharị na ya, ya mere arịrịọ dị otú ahụ na-eme ka ọ na-emepe emepe. Ogo ahụ gụnyere OmniRoute API-igodo ID onye ọkpụkpọ.
- Oge izugbe nọọrọ onwe ya ọhụrụ gafee akaụntụ OAuth ala na-arụ ọrụ nke iwu njikọ API-igodo nyere ikike, nke njikọ ID nyere iwu. Round-robin na-amafe akaụntụ na njikọ jụrụ oyi, yana ọkwa njedebe (`banned`, `expired`, `credits_exhausted`), ma ọ bụ ekpochi ụdị maka ụdị a rịọrọ; Ọdịda nke Muse n'elu na-edekọ ọnọdụ jụrụ oyi na ọnọdụ mmebi dị ka ndị na-enye ndị ọzọ. Njikọ amanye nke ọma na-agafe gburugburu-robin maka nnọkọ ọhụrụ mana enweghị ike ịkagbu onye nwe ya.

Ndekọ nwere njikọ IDs na hashes nke njirimara akaụntụ, nzere, ọdịnaya na-adịghị ahụkebe, na ntụnyere aka n'ihu, ọ bụghị nzuzo ma ọ bụ akụkọ mkparịta ụka.
