## Ntụgharị-Ụzọ Akpaaka Na-Enweghị Nhazi (`auto/` prefix)

> **IHE ỌHỤRỤ:** Ọ dịghị mkpa ịmepụta combo. Jiri `auto/` prefix ozugbo n'ime client ọ bụla.

### Ọmụmaatụ Ngwa Ngwa

| ID Model       | Ụdị     | Omume                                                                                     |
| -------------- | ------- | ----------------------------------------------------------------------------------------- |
| `auto`         | ndabara | Ndị na-eweta ọrụ niile ejikọrọ, atụmatụ LKGP, arọ ndị ahaziri nhata                       |
| `auto/coding`  | coding  | Arọ ndị na-ebute ogo ụzọ, dabara maka imepụta koodu                                       |
| `auto/fast`    | fast    | Nhọrọ nwere arọ na obere latency                                                          |
| `auto/cheap`   | cheap   | Ntụgharị-ụzọ ahaziri iji belata ọnụ ahịa (ọnụ ahịa kacha ala na mbụ)                      |
| `auto/offline` | offline | Na-akwado ndị na-eweta ọrụ nwere oke ojiji kacha dị ukwuu                                 |
| `auto/smart`   | smart   | Ogo ụzọ + ọnụego nyocha dị elu (10%) iji chọpụta model ka mma                             |
| `auto/lkgp`    | lkgp    | LKGP akọwapụtara kpọmkwem (otu ihe ahụ dị ka `auto` ndabara)                              |
| `auto/chaos`   | chaos   | Mgbasa yiri ibe ya, otu model maka onye na-eweta ọrụ ọ bụla (ọ bụghị itinye nsogbu n'ọrụ) |

### Ngwakọta Otu × Ọkwa (`auto/<category>:<tier>`)

Suffix ndị yiri nke OpenRouter na-ekewa **ụdị ụzọ ọ bụ** (otu) na **otu esi ahazi ya nke ọma** (ọkwa), ka ị nwee ike ijikọta ha n'enweghị mgbochi (#4235 Phase B, `open-sse/services/autoCombo/suffixComposition.ts`):

- **Otu dị iche iche** (na-enyocha ọdọ ndị a ga-ahọrọ dịka ike ha si dị): `coding` · `reasoning` · `vision` · `chat` · `multimodal`. `vision`/`multimodal` na-edobe model ndị nwere ike vision; `reasoning` na-edobe model ndị nwere ike reasoning/thinking.
- **Ọkwa dị iche iche** (na-ahọrọ arọ akara / ihe nzacha ọdọ): `fast` (zipụ-ngwa-ngwa) · `cheap` (aha ọzọ bụ `floor`, onye na-echekwa ọnụ ahịa) · `reliable` (ahụike circuit-breaker + nkwụsi ike latency) · `free` / `pro` (na-eji `classifyTier` enyocha ọdọ ahụ dịka ọkwa model si dị — ọkwa efu megide nke premium).

| Ọmụmaatụ               | Na-aghọ                                                             |
| ---------------------- | ------------------------------------------------------------------- |
| `auto/coding:fast`     | ọdọ coding, arọ nwere obere latency                                 |
| `auto/coding:cheap`    | ọdọ coding, nke ahaziri maka ọnụ ahịa (aha ọzọ `auto/coding:floor`) |
| `auto/reasoning:pro`   | naanị model reasoning/thinking, ọkwa premium                        |
| `auto/vision`          | model ndị nwere ike vision (enweghị ọkwa → arọ ndị ahaziri nhata)   |
| `auto/multimodal:free` | model ndị nwere ike multimodal, naanị ọkwa efu                      |

`auto/<category>[:<tier>]` ọ bụla ziri ezi na-edozi mgbe achọrọ ya; a na-egosi obere nchịkọta a họpụtara nke ọma na `/v1/models` nakwa na dashboard (`AUTO_SUFFIX_VARIANTS` dị na `open-sse/services/autoCombo/builtinCatalog.ts`). Nzacha a bụ **fail-open** — ọ bụrụ na iwu enweghị model ejikọrọ ọ bụla dabara na ya, a ga-eji ọdọ niile ka ntụgharị-ụzọ ghara ịkwụsị ịrụ ọrụ. Onye isi na-enye akara (`combo.ts`) agbanwebeghị; a na-etinye ihe nzacha otu/ọkwa n'ime `buildAutoCandidates`.

> **Ọgụgụ isi model ozugbo:** ọkwa **Arena ELO** ndị dị ugbu a + data ọkwa **models.dev** na-enye aka n'ịtụ ịdị mma nke ntụgharị-ụzọ akpaaka mgbe flag `ARENA_ELO_SYNC_ENABLED` dị ọkụ (ma ọ bụghị ya, ọ na-alaghachi na map ịdị mma static).

**Otu esi eji ya:**

```bash
# IDE ma ọ bụ ngwa CLI ọ bụla na-akwado usoro OpenAI
Base URL: http://localhost:20128/v1
API Key:  <igodo-endpoint-gị>

# N'ime koodu/nhazi gị, tọọ model ka ọ bụrụ:
model: "auto"                 # ndabara ahaziri nhata
model: "auto/coding"          # kacha mma maka ọrụ coding
model: "auto/fast"            # nke kacha ọsọ dị
model: "auto/cheap"           # nke kacha ọnụ ala kwa token
```

**Ihe na-eme:**

1. OmniRoute na-achọpụta `auto/` prefix n'ime `src/sse/handlers/chat.ts`
2. Na-ajụ nchekwa data maka **njikọ ndị na-eweta ọrụ niile nọ n'ọrụ**
3. Na-enyocha ma hapụ naanị ndị nwere nzere ziri ezi (API key ma ọ bụ OAuth token)
4. Na-ekpebi model maka njikọ ọ bụla (`connection.defaultModel` ma ọ bụ model mbụ nke onye na-eweta ọrụ)
5. Na-ewulite **virtual combo** n'ime ebe nchekwa (anaghị echekwa ya na DB)
6. Na-eme ntụgharị-ụzọ site na iji profaịlụ arọ nke ụdị ahọpụtara + atụmatụ LKGP

**Njirimara ndị bụ isi:**

- ✅ **Na-arụ ọrụ mgbe niile:** Enweghị toggle, enweghị imepụta combo, enweghị nhazi achọrọ
- ✅ **Na-agbanwe agbanwe:** Na-egosipụta ndị na-eweta ọrụ ejikọrọ ugbu a na-akpaghị aka
- ✅ **Ịrapara na session:** LKGP na-ahụ na a na-ebute onye na-eweta ọrụ ikpeazụ rụrụ nke ọma ụzọ
- ✅ **Na-aghọta ọtụtụ account:** Njikọ onye na-eweta ọrụ ọ bụla na-aghọ candidate dị iche
- ✅ **Enweghị ide na DB:** Virtual combo dị naanị maka request ahụ, enweghị ibu persistence ọ bụla

### Njikwa candidate nke igodo ọ bụla (#7819, Ọkwa 1+2)

`GET /v1/auto-combo/{channel}/candidates` (`{channel}` = suffix na-esote `auto/`, ma ọ bụ
`auto` kpọmkwem maka channel bụ isi) bụ endpoint **naanị maka ịgụ** nke na-edepụta
ọdọ candidate dị ugbu a nke channel `auto/*`, tinyere ozi nnweta ozugbo, site n'iji
ọgụgụ resilience ndị dị ugbu a emegharị (ọ bụghị breaker `state` raw):

- circuit breaker nke onye na-eweta ọrụ — `getCircuitBreaker(provider).getStatus()` / `.canExecute()`
- cooldown nke njikọ — `rateLimitedUntil` / `testStatus` n'ahịrị
  `provider_connections` e kpebiri
- mkpọchi model — `isModelLocked(provider, connectionId, model)`

Candidate ọ bụla nwekwara flag `excluded` nke API key a. A na-echekwa mwepu
maka API-key ọ bụla (`auto_candidate_overrides` table, migration `128`) — OmniRoute bụ
single-tenant na-enweghị table `users`, ya mere `apiKeyId` bụ njirimara onye na-akpọ oku
kachasị nso n'ezie — a na-etinyekwa ya n'ọrụ n'ebe njedebe ọdọ candidate dị na
`open-sse/services/autoCombo/virtualFactory.ts` site na `filterExcludedCandidates()`
dị ọcha ma nwalee unit (`open-sse/services/autoCombo/candidateOverrides.ts`).
Ihe nzacha ahụ bụ **fail-open**: apiKeyId/channel a na-edobeghị ma ọ bụ ọdịda nchọta DB
ga-ahapụ ọdọ ahụ n'enweghị nzacha, ka onye nchịkwa na-enweghị override ọ bụla ahaziri
wee hụ ntụgharị-ụzọ nke byte ọ bụla yiri nnọọ nke dị tupu atụmatụ a.

**Ebugharịrị gaa n'okwu a ga-esochi:** ibu arọ nke onye ndọrọ ọ bụla + nhazi pořọdụ doro anya (Ọkwa 3
— na-abanye n'ụzọ atụmatụ ibu arọ/ebute ụzọ ndị dị ugbu a) na ịtụgide atụmatụ
`combo.ts` akọwapụtara maka channel `auto/*` ọ bụla (Ọkwa 4). Lee atụmatụ #7819 maka ajụjụ
ka ghe oghe gbasara ma overrides kwesịrị ịdịgide n'otu API key ọ bụla, ka ọ bụ bụrụ nke zuru ụwa ọnụ n'ihi
ụdị single-tenant ahụ.

**Ihe na-eme n'azụ:**

```txt
Arịrịọ: { model: "auto/coding" }
   ↓
src/sse/handlers/chat.ts na-achọpụta prefix
   ↓
createVirtualAutoCombo('coding') → candidatePool sitere na njikọ ndị nọ n'ọrụ

handleComboChat (otu engine ahụ dị ka combos echekwara)
   ↓
Auto-scoring na-ahọrọ provider/model kacha mma maka arịrịọ ọ bụla
```

## Mmasị akaụntụ maka combos akpaaka echekwara

Onye ndezi akpaaka nwere ọgụgụ isi na-enye nhọrọ** Mmasị akaụntụ** ngalaba. Njikọ ọ bụla nwere ike masịrị, Nkịtị (nke ndabara), Nchekwa ma ọ bụ Wepu. Njikọ ọtụtụ nwere ike kesaa ọkwa. Akpaaka na-ahọrọ n'ime ọkwa mbụ tozuru oke, na-ejigide omume scoring/router ya ebe ahụ; mgbalị ndị dara ada na-adaba na akaụntụ ndị fọdụrụnụ, masịrị tupu nkịtị tupu idobere. Ngwakọta anaghị eji njikọ ewepu.

A na-echekwa ntọala ahụ dị ka `config.accountPreferences`, nke ejiri njikọ ID tinye ya:

```json
{
  "accountPreferences": {
    "connection-a": "preferred",
    "connection-b": "preferred",
    "connection-c": "reserve",
    "connection-d": "excluded"
  }
}
```

Maapụ ewepụrụ ma ọ bụ ihe efu na-ejigide ụzọ ụzọ dị adị. Mmasị anaghị enyere njikọ nwere nkwarụ aka, nye ohere igodo API, weghachi ndị chọrọ oke egbochiri, ma ọ bụ gafere nlele mmefu ego. Mgbalị ọ bụla bụ naanị na njikọ ya siri ike, yabụ ọdịda akaụntụ enweghị ike ịwụ elu n'azụ rawụta combo. Mmekọrịta nnọkọ dị adị nwere ike idowe akaụntụ ntozu; ewepu akaụntụ ahụ ejikọta na ntụgharị nwa amaala na-akwụsị na-atụgharị kama ịgbachi nkịtị na-agbanwe akaụntụ.

Mmasị ahaziri ahazi na-eji ụzọ akpaaka maara akaụntụ: enweghị oghere- oghere, smart-pipeline, ọgba aghara na ụzọ mkpirisi onyinyo adịghị ezipụ. Akwụsịla mgbochi ntule maka arịrịọ ndị a, yabụ akaụntụ nchekwa enweghị ike ịgba ọsọ nke ndị ahọrọ. Atụmatụ ngwakọta ndị ọzọ anaghị akọwa ntọala a. Ịgbanwe combo pụọ na akpaaka na-edobe mmasị echekwara maka ngbanwe ọzọ ma emechaa.

## Aha Combo Ndị Dabara na Ezigbo Model Id

Combo nke `name` ya bụ otu ihe kpọmkwem na model id nkịtị (dịka ọmụmaatụ, combo a kpọrọ
`gpt-5.5`) bụ **usoro e bu n’obi ma na-akwado**, ọ bụghị ntụpọ: ọ bụ
usoro eji eme ndabere provider maka model-id ọ bụla nke akọwara na
[#6940](https://github.com/diegosouzapw/OmniRoute/issues/6940). Ebe ọ bụ na a na-ebu ụzọ elele
mkpebi combo tupu mkpebi bare-model-id
(`getComboForModel()` dị na `src/sse/services/model.ts`), a na-eziga arịrịọ maka id nkịtị
`gpt-5.5` site na targets nke combo ahụ (dịka ọmụmaatụ
`acme-responses/gpt-5.5`, `backup-responses/gpt-5.5`) kama iziga ya ozugbo na
otu provider — nke a na-eji ọzọ combo-before-rewrite precedence e wuru maka
[#3227/#3233](https://github.com/diegosouzapw/OmniRoute/issues/3227), a na-ejikwa
`tests/unit/responses-combo-resolution-3227.test.ts` na
`tests/unit/combo-name-codex-responses-rewrite.test.ts` nwalee ya iji gbochie regression.

A naghị **ajụ ma ọlị** imepụta combo ma ọ bụ ịgbanwe aha ya ka ọ bụrụ aha na-ekpuchi ezigbo model id — ime nke ahụ ga-emebi usoro ọrụ a edekọtara. Kama nke ahụ
(#8530), `POST /api/combos` na `PUT /api/combos/[id]` na-agbakwunye field
`warning` nke na-adịghị egbochi ọrụ na response mgbe aha (ọhụrụ) ahụ dakọtara na ezigbo
model id:

```json
{
  "warning": {
    "code": "COMBO_NAME_SHADOWS_MODEL",
    "modelId": "gpt-5.5",
    "providerId": "openai"
  }
}
```

Mgbe usoro na-ebido, `scanComboModelNameCollisionsAtBoot()`
(`src/instrumentation-node.ts`) na-edekwa ịdọ aka ná ntị `[STARTUP]` nke otu ahịrị
nke na-edepụta combo niile dị adị na-ekpuchi model id, ka ndị na-ahụ maka sistemụ
ndị zutere nke a na mberede (kama ime ya n’ebumnobi, dịka #6940 si kwuo) nwee ihe ngosi.
Helper nchọpụta ahụ dị na `src/lib/combos/modelNameCollision.ts`.

## Ịkpọ Custom Combo Site na Client

A na-eji combos echekwara (Ntọala → Combos) naanị mgbe client zigara **aha combo ahụ kpọmkwem** na field `model` — enweghị fuzzy matching ma ọ bụ partial matching nke aha combo ahụ, a naghịkwa eji prefix `auto/`. Usoro mkpebi (`getComboForModel()` dị na `src/sse/services/model.ts`):

1. ndakọrịta aha combo kpọmkwem (`model: "my-combo"`),
2. prefix `combo/<name>` (`model: "combo/my-combo"`),
3. model→combo glob mappings (`/api/model-combo-mappings`).

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{"model":"my-combo","messages":[{"role":"user","content":"Hello"}]}'
```

Nsogbu abụọ a na-ahụkarị:

- **`auto` anaghị eji combos gị.** `auto`/`auto/*` na-ewu candidate pool nke ya na-achọghị nhazi ọ bụla, ọ na-elelekwa combos echekwara naanị ma ọ bụrụ na e nwere combo a kpọrọ `auto` kpọmkwem (anaghị atụ aro ya). Iji zipụ arịrịọ site na combo, ziga aha ya kpọmkwem — ọ bụghị `auto`.
- **`openrouter/auto` bụ ezigbo ngwaahịa OpenRouter a na-akwụ ụgwọ maka ya** ("Auto Best Available"), ọ bụghị alias OmniRoute. Ọ bụ otu static model entry dị na registry OpenRouter (`open-sse/config/providers/registry/openrouter/index.ts`), a na-akwụkwa ụgwọ ya iche. Jiri Ntọala → Routing → Zoo models a na-akwụ ụgwọ iji wepụ ya na `auto` pools.

Lee [#7992](https://github.com/diegosouzapw/OmniRoute/issues/7992) na [#7111](https://github.com/diegosouzapw/OmniRoute/issues/7111) maka mgbagwoju anya mbụ nke akwụkwọ a na-akọwa.

## Otu ọ na-arụ ọrụ (na-adịgide adịgide Auto-Combos)

Igwe nchikota akpaaka na-ahọrọ provider/model kacha mma maka arịrịọ ọ bụla site na iji a** Ọrụ akara 16** (akọwapụtara na `open-sse/services/autoCombo/scoring.ts` → `DEFAULT_WEIGHTS`). ### `weighted` semantics

`weighted` bu a** nhata random eserese kwa arịrịọ** (`open-sse/services/combo/targetSorters.ts` → `selectWeightedTarget`), ọ bụghị ihe nhata:

- Arịrịọ ọ bụla na-adọta** otu** nzọụkwụ na puru omume `weight / totalWeight`; A na-enye iwu usoro ndị fọdụrụ site n'ịgbadata ibu dị ka agbụ azụ azụ maka arịrịọ ahụ.
- Nzọụkwụ nke ibu ya bụ `0` (ma ọ bụ efu) bụ** mgbe e sere** ebe nzọụkwụ ọ bụla ọzọ nwere arọ > 0 — ọ nwere ike na-eje ozi dị ka ọdịda mgbe nzọụkwụ a dọtara daa. Naanị mgbe** niile** arọ bụ 0 ka nhọrọ na-aghọ otu.
- A na-ewepụ nzọụkwụ ndị ebumnuche ha niile adịghịzi — onye na-eweta sekit sekit `OPEN`, njikọ cooldown, ụdị mkpọchi — na-ewepụ na eserese ahụ tupu ya emee (`open-sse/services/combo/targetResolution.ts`), yabụ otu nzọụkwụ ahụike nwere ike imeri arịrịọ ọ bụla nwa oge.
- `stickyWeightedLimit` (nhazi combo, ndabara `1` = gbanyụọ) na-atụnye nzọụkwụ adọtara maka ọtụtụ ihe ịga nke ọma n'usoro tupu ịdegharịa.

Maka ntụgharị siri ike jiri `round-robin`; nha nha nha na `weighted` na-enye — statistical ọ bụghị nguzozi — siri ike.

### Ụdị pipeline

Ngwakọta `pipeline` nwere opekata mpe ụdị abụọ nwere ike ịbanye na planner/executor iji `config.agenticOrchestration.enabled` banye. Ebumnuche nke mbụ nwere atụmatụ na azịza ikpeazụ; ebumnobi nke abụọ na-ebute oku ngwa ngwa nke ndị ahịa. OmniRoute na-achọpụta na-aga n'ihu na nsonaazụ ngwa site na usoro arịrịọ ahụ, jụọ onye nhazi ma ọ dị mkpa okirikiri ngwaọrụ ọzọ, ma na-eme ka onye ọrụ ma ọ bụ onye na-eme atụmatụ bụrụ onye ahịa na-eche nzọụkwụ ikpeazụ ihu.

Nhọrọ `config.agenticOrchestration.contextCompaction` na-etinye mmefu ego ịkwụ ụgwọ dị iche tupu onye nhazi ọ bụla ma ọ bụ onye mmebe ezipụ. Kwado ya nke ọma:

```json
{
  "enabled": true,
  "defaultMaxChars": 400000,
  "targetRatio": 0.72,
  "toolResultMaxChars": 24000,
  "modelMaxChars": { "provider/planner": 175000, "provider/executor": 300000 }
}
```

Ndị a bụ usoro mmefu ego agwa JSON ahaziri nke onye ọrụ ahọpụtara, ọbụghị mpio ihe ngosi akara ma ọ bụ oke elu ekwenyere. Ụdị IDs ziri ezi na-ewepụ ndabara. N'elu ọnụ ụzọ ahụ, kọmpat na-ewepụ nkọwa ngwa ọrụ yiri nke ahụ, jiri mgbari na-ewepụ ihe akaebe ngwaọrụ buru ibu, ma wepụ otu akụkọ ihe mere eme ochie zuru oke na oke ebumnuche. Ọ na-ejigide ntụzịaka system/developer, arịrịọ onye ọrụ kachasị ọhụrụ, ngwa ọrụ ikpeazụ gụnyere calls/results yiri ya, yana nkuzi ụzọ Gemini nke na-eduga. A na-echekwa ntuziaka ọkwa dị elu na ntọala ngwaọrụ. Ihe ndekọ ihe nrịbama ewepụrụ akụkọ ihe mere eme; Nke a bụ trimming deterministic, ọ bụghị nchịkọta nke semantic. Ọ bụrụ na ọnọdụ pinned ka karịrị mmefu ego, arịrịọ ahụ ga-alaghachi 413 tupu ịkpọtụrụ ihe nlereanya ahụ. Na mkpịsị aka nwere nkwarụ ma ọ bụ n'okpuru ọnụ ụzọ, arịrịọ ahụ na-agafe na-agbanweghị agbanwe.

N'ịga n'ihu na nsonaazụ ngwa, OmniRoute na-akwụsịkwa ogbugbu mgbe agba abụọ emechara n'otu oge na-emegharị otu oku ngwaọrụ na-enwe nsonaazụ agbanweghị, ma ọ bụ mgbe nsonaazụ ọ bụla akara n'ụzọ doro anya na agba abụọ sochiri anya dara. Nsonaazụ gbanwere na-enye ohere oku ugboro ugboro (dịka ọmụmaatụ, ntuli aka). Onye nche na-amalitegharị na arịrịọ onye ọrụ ọhụrụ, otu oku na-adakọ na otu okirikiri, ma na-akwado Anthropic, Mkparịta ụka mmecha, nzaghachi na akụkọ Gemini. Onye na-eme atụmatụ na-enweta ihe kpatara ya ma nwee azịza ikpeazụ ọ bụrụgodị na ọ na-arịọ ngwá ọrụ ọzọ gburugburu.

Ụdị agbakwunyere mgbe ebumnuche nke abụọ gachara ka a na-enye iwu nkwado ndabere nke ndị mmebe. Nzaghachi HTTP dara ada ma ọ bụ mbugharị mwepu na-aga n'ihu na onye ọrụ na-esote, na-ebu otu mkpebi onye nhazi yana ngwa ala mana nzọụkwụ nke onye mmebe ahụ ozugbo wee kpebie njikọ. A na-eweghachi nzaghachi nke ọma nke mbụ na-agbanweghị, gụnyere SSE gụgharia; Enweghị ike ịnwagharị ọdịda mgbe mmiri malitere ịga nke ọma ebe a. A na-echekwa mkpebi ndị na-eme atụmatụ ime, ebe nzaghachi ndị ahịa ahọpụtara na-echekwa mmasị mbugharị mbugharị.

### `round-robin` nnyapade ogbe na mgbasawanye akaụntụ

A na-achịkọta gburugburu-robin, ọ bụghị otu arịrịọ-kwa-nzọụkwụ:

- `stickyRoundRobinLimit` (nhazi combo, wee `comboStickyRoundRobinLimit`, wee `settings.stickyRoundRobinLimit`, ndabara** 3** ) na-edobe otu ebumnuche ahụ maka ọtụtụ ihe ịga nke ọma n'usoro tupu ịtụgharị. Tọọ mbufe ngwakọta na `1` maka ntụgharị otu arịrịọ. Onye nchịkọta akụkọ combo na-egosi uru bara uru yana oyi akwa ọ si na ya pụta.
- `connectionAwareExpansion` (nhazi nhazi, wee ntọala, ndabere** ụgha** ) na-agbasa ọkwa ọkwa onye ọ bụla n'ime ebumnuche akaụntụ ọ bụla tupu ntụgharị. Atụmatụ otu-B (ihe dị mkpa, arọ, gburugburu-robin, random, p2c, obere-eji, ọnụ ahịa kacha mma, lkgp, fill-akpa, siri ike-random, ọnọdụ-kachasị mma, cache-optimized, context-relay, fusion, pipeline, jev) debe nlele ọkwa onye na-eweta ruo mgbe nke a ga-eme. Onye nchịkọta akụkọ combo na-ekpughe ihe nketa / gbanye / gbanyụọ; eketa na-eji ndabara zuru ụwa ọnụ (gbanyụọ).
- Ntugharị mpaghara cache ozugbo (`promptCacheAffinityEnabled`, ndabara** eziokwu** ) na-enyegharị njikọ ndị etinyere iwu ka igodo cache dabara adaba nọrọ n'otu akaụntụ. Ọ na-ebute ụzọ karịa gburugburu-robin na ngbanwe dị arọ gafere usoro akaụntụ ọ bụla etinyere. Gbanyụọ ya n'okpuru Ntọala → Combo ndabara ma ọ bụrụ na ịchọrọ ntụgharị siri ike. Enweghị nfefe n'otu n'otu.

Maka ntụgharị akaụntụ ọtụtụ n'otu ụdị, masịrị** otu dynamic-akaụntụ nzọụkwụ** ( `connectionId` efu, ọdọ mmiri dum) nwere oke nnyapade `1`, ọ bụghị atọ `connectionId` s pinned. Nzọụkwụ agbakwunyere gbakwunyere mmekọrịta na-adaba na otu akaụntụ ọbụlagodi mgbe RR counter na-aga n'ihu.

## Ngwakọta Strategy

`fusion` bụ otu atụmatụ na-eme** ọ bụghị** họrọ otu ebumnuche. Ọ na-akwado ngwa ngwa** ụdị panel ọ bụla n'otu n'otu** , mgbe ahụ a configurable** nlereanya ikpe** synthesizes otu ikpeazụ azịza si panel niile nzaghachi. Ebutere site na `decolua/9router` elu (OpenRouter's Fusion design); mmejuputa iwu na `open-sse/services/fusion.ts`.

Ka o si arụ ọrụ:

0. **Ngafe na-ebu ngwá ọrụ** — arịrịọ nke na-ebu usoro `tools` na-adịghị efu na `tool_choice` abụghị n'ụzọ doro anya `"none"` na-awụpụ panel ahụ kpamkpam: ọ na-aga ozugbo na otu ụdị (onye ọka ikpe ahaziri, ma ọ bụ `panel[0]`) na `tools`/`tool_choice` gafere n'enweghị mgbanwe. Ndị otu panel enweghị ohere ịnweta ngwa ọrụ yana ntuziaka nchịkọta nke onye ọka ikpe na-akụda ikuku ịkpọ oku ngwá ọrụ, yabụ ndị ahịa agentic/tool-calling na-enweta mkpebi ọkpụkpọ oku n'ezie kama ịmekọrịta prose (#6771).
1. **Fans-apụ** (arịrịọ na-abụghị ngwá ọrụ naanị) — ezigara ngwa ngwa ahụ na ụdị panel ọ bụla n'otu oge, na-amanye na-enweghị nkwanye na ngwá ọrụ yipụrụ (onye ọka ikpe chọrọ nkọwa zuru ezu iji mejupụta).
2. **Nchịkọta Kworum-amara** — ozugbo azịza `minPanel` bịarutere, obere oge amara ga-amalite maka ndị na-akpagbu, mgbe ahụ ngwakọta na-aga n'ihu na ihe ọ bụla anakọtara. Nke a na-ekpuchi ntaramahụhụ ụdịdị kacha nwayọ n'oge mgbidi, nke oge nkwụsị siri ike gbachiri.
3. **Nchịkọta ikpe** Azịza — panel bụ amaghị aha (`Source 1`, `Source 2`, … — ya mere ọkàikpe na-atụle ihe, ọ bụghị akara ngosi) ma nyefee onye ọka ikpe, nke na-enyocha nkwenye / esemokwu / mkpuchi ihu / nghọta pụrụ iche / ntụpọ kpuru, wee dee.** otu** azịza ikike. Oku onye ọka ikpe na-edobe ngwa + `stream` onye ahịa mbụ, yabụ iji ngwa mgbasa ozi na mgbada ala ka na-arụ ọrụ.
4. **Mmebi dị mma** — 0 panel zara → `503`; kpọmkwem 1 onye lanarịrị → a na-eweghachi azịza ya ozugbo (ọ nweghị ihe ọ ga-agwakọta); otu ihe nlereanya na-aza ozugbo.

Onye otu panel nwekwara ike ịbụ nzọụkwụ `combo-ref` (`{kind: "combo-ref", comboName: "..."}`) na-ezo aka — combo ọzọ ọ na-edozi dị ka** otu olu igbe igbe ojii** (nzigharị nzigharị zuru oke n'ime ngwakọta a kpọtụrụ aha, ọ bụghị onye na-akwado ebumnuche nke combo ahụ), na-eji otu nchekwa depth/cycle usoro ọ bụla ọzọ na-eri combo-ref na-eji (#6764).

### Nhazi

Haziri na combo's `config` blob (enweghị mbugharị — ọ na-eji tebụl `combos` dị ugbu a):

| Ubi                                      | Ụdị      | Ọdabara             | Ebumnuche                                                                            |
| :--------------------------------------- | :------- | :------------------ | :----------------------------------------------------------------------------------- |

| `config.fusionTuning.stragglerGraceMs`   | `number` | `8000`              | Ogologo oge ole ka a ga-echere lagd ozugbo kworum ruru                               |
| `config.fusionTuning.panelHardTimeoutMs` | `number` | `90000`             | Okpu zuru oke ka otu ụdị kwụgburu enweghị ike ịkwụsị arịrịọ ahụ                      |

## Ụlọ Ọrụ Virtual Auto-Combo

Injin Auto Combo anaghị achọ ka akọwapụta combo tupu oge eruo. Kama nke ahụ, `open-sse/services/autoCombo/virtualFactory.ts` na-emepụta ndị a ga-atụle ozugbo:

1. Ọ na-ewepụta `getProviderConnections({ isActive: true })` (njikọ niile enyere aka)
2. Ọ na-enyocha ma hapụ naanị ndị nwere credentials ziri ezi (API key ma ọ bụ OAuth token na-agwụbeghị oge site na `hasUsableOAuthToken()`)
3. Ọ na-atụnyere ha na `getProviderRegistry()` maka nnweta model + ọnụahịa
4. Maka tuple ọ bụla `(provider, model, connection)`, ọ na-emepụta `VirtualAutoComboCandidate`
5. Ọ na-ahọrọ `connection.defaultModel` (ma ọ bụ model mbụ dị na registry) dịka ebe a ga-eziga arịrịọ
6. Ọ na-enye candidate ọ bụla akara site na iji `scorePool()` nwere ihe 16 na ngwugwu weight nke variant ahụ
7. Ọ na-eweghachi `AutoComboConfig` nke sitere na ya ma dị na memory maka `handleComboChat()` — anaghị echekwa ya na DB ma ọlị

Nke a pụtara na **ịgbakwunye provider ọhụrụ nke enyere `auto/*` aka na-agbasawanye candidate pool na-akpaghị aka** — ọ dịghị mkpa iji aka dezie combo. A na-ewughachi virtual combo maka arịrịọ ọ bụla, ya mere a na-achọpụta njikọ ọhụrụ agbakwunyere ma ọ bụ ndị laghachiri n'ọnọdụ ahụike ozugbo.

## Mmezi Onwe Ya

- **Mwepụ nwa oge**: Score < 0.2 → ewepụ ya maka nkeji 5 (backoff na-abawanye nwayọ nwayọ, nke kachasị bụ nkeji 30)
- **Ịmara ọnọdụ circuit breaker**: OPEN → ewepụ ya na-akpaghị aka; HALF_OPEN → arịrịọ nnwale
- **Ọnọdụ nsogbu**: >50% OPEN → gbanyụọ exploration, mee ka nkwụsi ike ruo ogo kachasị
- **Nlaghachi mgbe cooldown gasịrị**: Mgbe mwepụ ahụ kwụsịrị, arịrịọ mbụ bụ "probe" nwere timeout ebelatara

## Nnyocha Bandit

A na-eziga 5% nke arịrịọ (enwere ike ịhazi ya) n'aka provider ndị ahọrọghị n'usoro maka exploration. A na-agbanyụ ya n'ọnọdụ nsogbu.

## API

Ọ dịghị **ebe njedebe `POST /api/combos/auto` pụrụ iche** — a na-eji Auto-Combo eme ihe n'ụzọ abụọ:

1. **Nhazi-efu (a tụrụ aro):** Zipụ arịrịọ mmecha nkata ọ bụla nwere `model: "auto"` ma ọ bụ `model: "auto/<variant>"`. Ụlọ nrụpụta mebere na-emepụta kombọ ahụ maka arịrịọ ọ bụla — enweghị nchekwa na-adịgide adịgide ma ọ bụ oku API achọrọ.

2. **Kombiso echekwara nwere `strategy: "auto"`:** Mepụta kombọ nkịtị site na `POST /api/combos` ma tọọ `strategy: "auto"` tinyere `config.auto.weights` / `config.auto.candidatePool`. A na-eji otu injin akara ahụ; a na-echekwa kombọ ahụ na `combos`, a pụkwara iji ID ya mee ihe ọzọ.

Maka nchọpụta, `GET /api/combos/auto` na-edepụta ụdịdị niile tinyere ọdọ ndị ndoro-ndoro edoziworo ya yana `context_length` / `max_output_tokens` — uru kacha elu n'ime windo niile nke ọdọ ndị ndoro-ndoro ahụ. Ndị ahịa (dịka ọmụmaatụ, ngwa mgbakwunye opencode) ga-akpọsa ụkpụrụ ndị a kama `0`: ogologo ọnọdụ efu na-agbanyụ mkpakọ-akpaka nke opencode kpamkpam, na-eme ka nnọkọ na-eto ruo mgbe nhichapụ akụkọ ihe mere eme nke gateway bibiri ọnọdụ ahụ. Ọ dị nchebe ịkpọsa uru kacha elu n'ihi na ihe nzacha ọnọdụ tupu nhọpụta nke auto-combo na-eziga arịrịọ ndị buru oke ibu na ndị ndoro-ndoro nwere windo buru ibu.

### Atụmatụ router auto

Kombiso `strategy: "auto"` echekwara nwere ike ịtọ `config.routerStrategy` (ma ọ bụ nke ochie
`config.auto.routerStrategy`) ka ọ bụrụ otu n'ime ndị a:

- `rules` — akara ndabara e nyere ibu
- `score` — na-ahọrọ akara kachasị elu e nyere ibu nke ahaziri. Mgbe akara hà nhata kpọmkwem, a na-edobe
  usoro ndị ndoro-ndoro ahaziri; `explorationRate` dị ugbu a na-ahọrọ n'omume site n'ọdọ niile a haziri n'usoro.
- `cost` / `eco` — onye na-eweta ọrụ ahụike dị ọnụ ala karịa
- `latency` / `fast` — latency p95 kacha ala nwere ntaramahụhụ ntụkwasị obi
- `sla-aware` / `sla` — na-ahọrọ ndị ndoro-ndoro na-emezu latency p95, ọnụọgụ njehie, yana
  SLO ọnụahịa ma ọ bụrụ na e nyere ya
- `lkgp` — onye na-eweta ọrụ ikpeazụ a maara na ọ dị mma ga-ebu ụzọ
- `nadir` — jụọ API mkpebi nke [Nadir](https://getnadir.com) ụdị model dị n'ọdọ ahụ nke
  prompt chọrọ; a ga-ahọrọ ịgbanye ya, ma ọ bụrụ na ọ daa, ọ ga-emeghe laghachi na `rules`

### Nkọwa zuru ezu banyere atụmatụ router

Injin auto-combo na-enye mmejuputa **RouterStrategy** 7 a pụrụ itinye ma gbanwee,
nke ị nwere ike ịgbanwe site na `config.routerStrategy` (ma ọ bụ nke ochie `config.auto.routerStrategy`).
Atụmatụ ọ bụla na-ahọrọ otu onye na-eweta ọrụ site n'ọdọ ndị ndoro-ndoro, dabere na `RoutingContext`
(ụdị ọrụ, ntụnye ngwá ọrụ/ọhụụ, atụmatụ token, iwu SLA ma ọ bụrụ na e nyere ya, yana
onye na-eweta ọrụ ikpeazụ a maara na ọ dị mma ma ọ bụrụ na e nyere ya).

#### 1. `rules` (ndabara) — akara e nyere ibu nke ihe 16

Ọ na-ekpuchi injin akara dị ugbu a. Ọ na-ewepụ ndị ndoro-ndoro circuit-breaker
ha bụ `OPEN`, wee jiri ụdị ọrụ dị ugbu a na `getTaskFitness()` kpọọ `scorePool()`,
na-ahọrọ onye na-eweta ọrụ nwere akara kacha elu.

```ts
class RulesStrategyImpl implements RouterStrategy {
  readonly name = "rules";
  readonly description = "16-factor weighted scoring (see DEFAULT_WEIGHTS)";

  select(pool, context) {
    const eligible = pool.filter((c) => c.circuitBreakerState !== "OPEN");
    const ranked = scorePool(
      eligible.length > 0 ? eligible : pool,
      context.taskType,
      undefined,
      getTaskFitness
    );
    return { provider: ranked[0].provider /* ... */ };
  }
}
```

**Mgbe e kwesịrị iji ya**: Ndabara. Jiri ya mgbe ịchọrọ nguzozi kwesịrị ekwesị n'etiti mgbaàmà niile.

**Aha ọzọ**: `rules` (enweghị aha ọzọ)

---

#### 2. `cost` / `eco` — onye na-eweta ọrụ ahụike dị ọnụ ala karịa

Ọ na-ahazi ọdọ ndị ndoro-ndoro site na `costPer1MTokens` (site na nke kacha nta ruo nke kacha ukwuu) wee họrọ nke dị ọnụ ala karịa.
Ọ na-ebu ụzọ wepụ ndị ndoro-ndoro `OPEN`.

```ts
class CostStrategyImpl implements RouterStrategy {
  readonly name = "cost";
  readonly description = "Always selects cheapest available provider";

  select(pool, context) {
    const healthy = pool.filter((c) => c.circuitBreakerState !== "OPEN");
    const sorted = [...healthy].sort((a, b) => a.costPer1MTokens - b.costPer1MTokens);
    return { provider: sorted[0].provider /* ... */ };
  }
}
```

**Mgbe e kwesịrị iji ya**: Ọrụ ndị na-elekwasị anya n'ọnụahịa, nhazi ogbe, ma ọ bụ ọrụ ndabere.

**Aha ndị ọzọ**: `cost`, `eco`

---

#### 3. `latency` / `fast` — latency p95 kacha ala nwere ntaramahụhụ ntụkwasị obi

Ọ na-ahazi site na `p95LatencyMs + (errorRate * 1000)`. Ntaramahụhụ ọnụọgụ njehie na-eme ka
ndị na-eweta ọrụ a na-apụghị ịdabere na ha nọrọ n'ọkwa dị ala, ọbụna ma latency aha ha dị ala.

```ts
class LatencyStrategyImpl implements RouterStrategy {
  readonly name = "latency";
  readonly description = "Prioritizes lowest p95 latency with reliability weighting";

  select(pool, context) {
    const healthy = pool.filter((c) => c.circuitBreakerState !== "OPEN");
    const sorted = [...healthy].sort(
      (a, b) => a.p95LatencyMs + a.errorRate * 1000 - (b.p95LatencyMs + b.errorRate * 1000)
    );
    return { provider: sorted[0].provider /* ... */ };
  }
}
```

**Mgbe e kwesịrị iji ya**: Ọrụ ndị na-elekwasị anya na latency dịka nkata ozugbo, mmecha-akpaka, ma ọ bụ
ndị enyemaka ide koodu mmekọrịta.

**Aha ndị ọzọ**: `latency`, `fast`

---

#### 4. `sla-aware` / `sla` — nrubeisi na SLO latency/njehie/ọnụahịa

Ọ na-enye onye ndoro-ndoro ọ bụla akara dabere n'otú o si emezu iwu SLO ahaziri:

| Ihe na-emetụta   | Arọ | Usoro mgbakọ                                                   |
| ---------------- | --- | -------------------------------------------------------------- |
| Akara igbu oge   | 35% | `threshold / max(value, ε)`                                    |
| Akara njehie     | 35% | `threshold / max(value, ε)`                                    |
| Akara ahụike     | 15% | `1.0` (CLOSED) / `0.5` (HALF_OPEN) / `0.0` (OPEN)              |
| Akara ọnụ ahịa   | 10% | `threshold / max(value, ε)` ma ọ bụ nke ahaziri n'ụzọ ntụgharị |
| Akara nkwụsi ike | 5%  | stddev nke igbu oge ahaziri n'ụzọ ntụgharị                     |

Mgbe `hardConstraints: true`, a na-ahazi ndị ndoro-ndoro ọkachasị site na **akara mmebi**
(ókè ha gafere SLO ọ bụla), emesịa site na akara ngwakọta. Ma ọ bụghị ya, a na-eji naanị
akara ngwakọta ahụ.

```ts
class SLAStrategyImpl implements RouterStrategy {
  readonly name = "sla-aware";
  readonly description =
    "Selects the provider most likely to satisfy latency, error-rate, and cost SLOs";

  select(pool, context) {
    // ... na-enye onye ndoro-ndoro ọ bụla akara dabere na iwu: { targetP95Ms, maxErrorRate, maxCostPer1MTokens, hardConstraints }
  }
}
```

**Oghere SLA** (a na-etinye ha na nhazi combo):

```json
{
  "strategy": "auto",
  "config": {
    "routerStrategy": "sla-aware",
    "slaTargetP95Ms": 1500,
    "slaMaxErrorRate": 0.05,
    "slaMaxCostPer1MTokens": 5,
    "slaHardConstraints": true
  }
}
```

**Mgbe a ga-eji ya**: Ibu ọrụ mmepụta nwere oke siri ike maka igbu oge, ọnụọgụ njehie, ma ọ bụ mmefu ego.

**Aha nnọchi**: `sla-aware`, `sla`

#### 5. `lkgp` — buru ụzọ jiri onye na-eweta ọrụ ikpeazụ a maara na ọ dị mma

Ọ na-ebu ụzọ nwalee **onye na-eweta ọrụ ikpeazụ a maara na ọ dị mma** (ọ bụrụ na edobere ya), emesịa ọ laghachi na
atụmatụ `rules`. Ọ bara uru maka ijigide otu onye na-eweta ọrụ n'ime nnọkọ — otu onye na-eweta ọrụ ahụ na-ahụ maka
arịrịọ ndị na-esochi n'ime mkparịta ụka.

```ts
class LKGPStrategyImpl implements RouterStrategy {
  readonly name = "lkgp";
  readonly description = "Tries last known good provider first, then falls back to rules";

  select(pool, context) {
    if (context.lkgpEnabled === false) {
      return getStrategy("rules").select(pool, context);
    }

    if (context.lastKnownGoodProvider) {
      const candidates = pool.filter(
        (c) => c.provider === context.lastKnownGoodProvider && c.circuitBreakerState !== "OPEN"
      );
      if (candidates.length > 0) {
        return { provider: candidates[0].provider /* ... */ };
      }
    }

    // Laghachi na atụmatụ rules
    return getStrategy("rules").select(pool, context);
  }
}
```

**Mgbe a ga-eji ya**: Mkparịta ụka nwere ọtụtụ ntụgharị ebe ịchọrọ ka otu onye na-eweta ọrụ ahụ na-ahụ maka
arịrịọ ndị na-esochi (dịka ọmụmaatụ, maka caching, ịga n'ihu nke context, ma ọ bụ ịdị n'otu nke ọnụ ahịa).

**Aha nnọchi**: `lkgp` (enweghị aha nnọchi)

#### 6. `nadir` — ịhọrọ model dabere na prompt site na Nadir

Atụmatụ ọ bụla dị n'elu na-ahazi ndị ndoro-ndoro site na telemetry nke ya; ọ dịghị nke ọ bụla n'ime ha na-agụ
arịrịọ ahụ. `nadir` na-eziga ntụgharị ikpeazụ nke onye ọrụ yana model ids dị na pool ahụ na
API mkpebi nke [Nadir](https://getnadir.com) (`POST /v1/bucket`) ma duru arịrịọ ahụ gaa na model
Nadir họọrọ n'ime ndepụta ahụ (`simple` → model kacha ọnụ ala nke nwere ike ịrụ ọrụ ahụ, `complex` → model
frontier). A ka na-eji `rules` ahọrọ njikọ na-enye model ahụ, yabụ quota,
ahụike na ọnụ ahịa ka na-ekpebi account a ga-eji.

```json
{
  "strategy": "auto",
  "config": {
    "routerStrategy": "nadir",
    "nadir": {
      "apiKey": "ndr_...",
      "baseUrl": "https://api.getnadir.com",
      "timeoutMs": 2000
    }
  }
}
```

`OMNIROUTE_NADIR_API_KEY` na `OMNIROUTE_NADIR_BASE_URL` bụ env fallbacks maka string abụọ ahụ.
`baseUrl` dị mkpa naanị maka Nadir ị na-akwado n'onwe gị (a na-anabata `/v1` dị na njedebe).
Oku ndị na-enweghị key na-abanye na ọkwa anonymous nke Nadir, nke nwere mmachi ọnụego maka IP ọ bụla. Site na key
([mepụta otu](https://app.getnadir.com/dashboard/api-keys)), a na-edekọ mkpebi ọ bụla
na dashboard Nadir gị. Nhazi na nkwenye zuru ezu:
[getnadir.com/docs/gateway-omniroute](https://getnadir.com/docs/gateway-omniroute/).

Ihe na-apụ na sistemụ: ederede nke ozi ikpeazụ onye ọrụ zitere (mkpụrụedemede 16k mbụ), model ids
ndị ndoro-ndoro na channel tag `source: "omniroute"`. A naghị eziga system prompt, akụkọ gara aga, tools ma ọ bụ
headers.

Omume mgbe ọdịda mere bụ fail-open: timeout (ndabara bụ 2000 ms), nzaghachi na-abụghị 2xx, host
a na-apụghị iru, nzaghachi na-adịghị n'ụdị ziri ezi, ma ọ bụ nhọrọ na-adịghị n'ime pool ga-alaghachi na mkpebi `rules`,
a ga-etinyekwa `NadirStrategy: fallback (…)` na mbido ihe kpatara ya. Mgbe oku dara, atụmatụ ahụ na-awụli netwọkụ
maka 30 s, ya mere outage na-efu naanị otu timeout kwa 30 s kama ịbụ otu maka arịrịọ ọ bụla. Routing events na-akọ
`strategy: "nadir"` naanị mgbe Nadir mere nhọrọ ahụ n'ezie.

**Mgbe a ga-eji ya**: traffic nwere ogo isi ike dị iche iche n'ime pool nke nwere ọkwa model dị iche iche (obere model, model etiti
na model frontier), ebe iji frontier mgbe niile bụ ọnụ ahịa ịchọrọ ibelata.

**Aha nnọchi**: `nadir` (enweghị aha nnọchi)

class MyCustomStrategy implements RouterStrategy {

## Otu tiers si daba na Auto-Combo

Ọrụ ntule nwere ihe 16 (`open-sse/services/autoCombo/scoring.ts`) na-ewere ịbụ onye otu tier dị ka akara abụọ: `tierPriority` (0.0476) na `tierAffinity` (0.0476). Lee [tebụl ihe ntule bụ isi](#how-it-works-persisted-auto-combos) dị n’elu maka nchịkọta `DEFAULT_WEIGHTS` zuru ezu — edepụtara mgbanwe pụrụ iche maka pack ọ bụla (ship-fast/cost-saver/quality-first/
offline-friendly) na tebụl "Profaịlụ ibu maka pack ọ bụla".

Tier naanị ya **anaghị** eme ka Tier 1 buru ụzọ — ọ bụrụ na latency nke Tier 1 adịghị mma ma ọ bụ na ntụnyere ọnụahịa na ogo adịghị mma, Tier 2 ga-emeri. Iji manye usoro tier, jiri atụmatụ combo `priority` ma hazie ndị na-eweta ọrụ dịka tier ha si dị.

Iji nye Tier 1 (ndebanye aha) nnukwu uru, bulie ibu `tierPriority`:

```json
{
  "strategy": "auto",
  "config": { "auto": { "weights": { "tierPriority": 0.3, "costInv": 0.05 } } }
}
```

Lee [`docs/guides/TIERS.md`](../guides/TIERS.md) maka nkọwa tier na nhazi ndị na-eweta ọrụ.

### Matriks nke na-ekpebi ụzọ ntụgharị (`npm run test:combo:matrix`)

`tests/integration/combo-matrix/*.test.ts` na-egosi ụzọ** mkpebi** n'ime atụmatụ ọha 21 niile na-ejedebe ruo-ọgwụgwụ site n'ezigbo pipeline nke nwere ihe na-akwa emo. Mkpuchi gụnyere:

- `context-relay` mkpuchi aka zuru ụwa ọnụ gafee ọnụọgụ ebumnuche ọ bụla.

Ụlọ ọrụ a na-agba ọsọ na CI (ọrụ `test:integration` ) na `--test-concurrency=1` na `--test-force-exit` ya mere ọ na-ekpebi ma ọ dịghị achọ nzere ndụ.
