## 1. Teknoloji Yığını

| Konu             | Tercih                                                                                                                             |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| Web çatısı       | **Next.js 16** (App Router, bağımsız çıktı, global middleware yok)                                                                 |
| Dil              | **TypeScript 6.0+** — hedef `ES2022`, `module: esnext`, `moduleResolution: bundler`, `strict: false`                               |
| Çalışma zamanı   | **Node.js** `>=22.22.2 <23` veya `>=24.0.0 <27` (`engines` + `SUPPORTED_NODE_RANGE` aracılığıyla zorunlu kılınır)                  |
| Veritabanı       | `better-sqlite3` aracılığıyla **SQLite** (singleton, WAL günlükleme)                                                               |
| Masaüstü         | **Electron 41** + `electron-builder` 26.10 (`electron/` altında ayrı çalışma alanı)                                                |
| Testler          | **Node yerel test çalıştırıcısı** (birim/entegrasyon), **Vitest** (MCP, autoCombo, önbellek), **Playwright** (e2e + protocols-e2e) |
| Derleme          | `scripts/build/build-next-isolated.mjs` aracılığıyla bağımsız Next.js                                                              |
| Lint/biçim       | ESLint düz yapılandırması + Prettier (Husky pre-commit aracılığıyla `lint-staged`)                                                 |
| Modül sistemi    | Her yerde ESM (`"type": "module"`)                                                                                                 |
| Panel arayüzü    | **Tailwind CSS 4** + projeye dahil edilmiş **Keak CI UI Kit** (`packages/ui-kit`), Lucide simgeleri — bkz. `DESIGN_SYSTEM.md`      |
| Çalışma alanları | npm çalışma alanları — `open-sse`, `packages/browser-pool`, `packages/ui-kit`                                                      |

Yol takma adları (`tsconfig.json`):

- `@/*` → `src/*`
- `@omniroute/open-sse` → `open-sse/index.ts`
- `@omniroute/open-sse/*` → `open-sse/*`
- `@omniroute/ui-kit` → `packages/ui-kit/src`, `@omniroute/ui-kit/*` → `packages/ui-kit/src/*`

Varsayılan HTTP portu: **`20128`** (API ve panel aynı süreci paylaşır). Veri
dizini `DATA_DIR` ortam değişkenidir; varsayılan değeri `~/.omniroute/` şeklindedir.

### 3.1 `src/app/` — App Router

App Router, hem kontrol paneli kullanıcı arayüzünü hem de genel/yönetim HTTP API'sini sunar.
**Global ara yazılım yoktur** — müdahale her rota için ayrı ayrı gerçekleştirilir.

`src/app/` altındaki üst düzey segmentler:

| Yol                                                                           | Amaç                                                          |
| ----------------------------------------------------------------------------- | ------------------------------------------------------------- |
| `api/`                                                                        | Tüm HTTP API rotaları (aşağıdaki döküme bakın)                |
| `a2a/`                                                                        | A2A JSON-RPC 2.0 uç noktası (`POST /a2a`)                     |
| `.well-known/agent.json/`                                                     | A2A Agent Card keşif belgesi                                  |
| `(dashboard)/`                                                                | Kontrol paneli kullanıcı arayüzü (rota grubu, URL ön eki yok) |
| `auth/`, `login/`, `forgot-password/`, `callback/`                            | Kimlik doğrulama akışları                                     |
| `landing/`                                                                    | Pazarlama/açılış sayfası                                      |
| `docs/`                                                                       | Gömülü API belgeleri görüntüleyicisi                          |
| `status/`, `maintenance/`, `offline/`                                         | Operasyonel sayfalar                                          |
| `privacy/`, `terms/`                                                          | Yasal sayfalar                                                |
| `400/`, `401/`, `403/`, `408/`, `429/`, `500/`, `502/`, `503/`                | Statik hata sayfaları                                         |
| `error.tsx`, `global-error.tsx`, `not-found.tsx`, `forbidden/`, `loading.tsx` | Framework hata/yükleme sınırları                              |
| `layout.tsx`, `page.tsx`, `globals.css`, `manifest.ts`                        | Kök kabuk                                                     |

#### 3.1.2a `src/app/api/services/` — Gömülü Hizmetler yönetimi

9Router ve CLIProxyAPI'yi yüklemek, başlatmak, durdurmak ve izlemek için rotalar.
Tüm yollar, `npm install` komutunu çalıştırabildikleri ve alt süreçler oluşturabildikleri
için **LOCAL_ONLY** (yalnızca geri döngü, katı kural #17) olarak sınıflandırılır.

```
src/app/api/services/
├── 9router/
│   ├── _lib.ts             getOrInitSupervisor() yardımcısı
│   ├── install/route.ts    POST — execFile aracılığıyla npm install
│   ├── start/route.ts      POST — supervisor.start()
│   ├── stop/route.ts       POST — supervisor.stop()
│   ├── restart/route.ts    POST — supervisor.restart()
│   ├── update/route.ts     POST — daha yeni sürüm için npm install
│   ├── rotate-key/route.ts POST — yeni API anahtarı oluştur + yeniden başlat
│   ├── status/route.ts     GET  — canlı + DB durumu + sürüm meta verileri
│   └── auto-start/route.ts POST — auto_start bayrağını aç/kapat
├── cliproxy/
│   ├── _lib.ts             getOrInitSupervisor() yardımcısı
│   ├── install/route.ts    POST — npm install
│   ├── start/route.ts      POST — supervisor.start()
│   ├── stop/route.ts       POST — supervisor.stop()
│   ├── restart/route.ts    POST — supervisor.restart()
│   ├── update/route.ts     POST — daha yeni sürüm için npm install
│   ├── status/route.ts     GET  — canlı + DB durumu + sürüm meta verileri
│   └── auto-start/route.ts POST — auto_start bayrağını aç/kapat
└── [name]/
    └── logs/route.ts       GET  — SSE günlük kuyruğu (tüm hizmetler tarafından paylaşılır)
```

İlgili pano kullanıcı arayüzü:
`src/app/(dashboard)/dashboard/providers/services/` — iki sekmeli sayfa (CLIProxyAPI + 9Router).
9Router gömülü kullanıcı arayüzü için ters proxy:
`src/app/(dashboard)/dashboard/providers/services/[name]/embed/[[...path]]/route.ts`

Ayrıntılı inceleme: `docs/frameworks/EMBEDDED-SERVICES.md`

   altındaki biçime özgü kayıt defterinde) kaydedin.

1. `src/app/api/your-route/route.ts` dosyasını oluşturun.

4. Yalnızca yönetim amaçlıysa yolu `src/shared/constants/publicApiRoutes.ts`
   içine ekleyin (genel API yüzeyi için engelleme listesi).
5. Testleri `tests/unit/` altına ekleyin.
6. `docs/reference/API_REFERENCE.md` ve `docs/openapi.yaml` dosyalarını güncelleyin.

### Yeni bir DB modülü ekleme

1. `src/lib/db/yourModule.ts` dosyasını oluşturun ve `./core.ts` içinden `getDbInstance()` işlevini içe aktarın.
2. Alanınız için CRUD işlevlerini dışa aktarın.
3. Yeni tablolar varsa `src/lib/db/migrations/` altına sıralı olarak
   numaralandırılmış, idempotent ve işlemsel bir migrasyon ekleyin.

4. Testleri `open-sse/mcp-server/__tests__/` altına ekleyin.

## 11. Kurallar

- **Kod stili**: 2 boşluklu girinti, çift tırnak, 100 karakter genişliği, noktalı virgüller,
  `es5` son virgülleri — Prettier tarafından `lint-staged` aracılığıyla uygulanır.
- **İçe aktarmalar**: harici → dahili (`@/`, `@omniroute/open-sse`) → göreli.
- **Adlandırma**: dosyalar `camelCase` veya `kebab-case`, bileşenler `PascalCase`,
  sabitler `UPPER_SNAKE`.
- **ESLint**: `no-eval`, `no-implied-eval`, `no-new-func` = her yerde `error`;
  `no-explicit-any` = `open-sse/` ve `tests/` içinde `warn`, diğer yerlerde `error`.
- **TypeScript**: `strict: false` (eski yaklaşım). Modüller arası sınırlarda
  çıkarım yerine açık türleri tercih edin.
- **Veritabanı**: rotalarda veya işleyicilerde asla ham SQL yazmayın — her zaman
  `src/lib/db/` modüllerini kullanın. Asla barrel içe aktarması kullanmayın — belirli `src/lib/db/*` modüllerini doğrudan kullanın.
- **DB varlık türleri (#3512)**: Bir DB tablosunun satır yapısını yazan veya
  okuyan bir işlev, çağrı noktasında `any` ya da satır içi anonim bir tür yerine,
  o tablonun sütunlarını bire bir yansıtan adlandırılmış bir TS arayüzünü parametre
  olarak almalı veya döndürmelidir. Arayüzü işlevin yanına yerleştirin (ör. `saveRequestUsage`
  üzerinde, `src/lib/usage/usageHistory.ts` içinde `export interface UsageEntry`);
  farklı yazıcılar satırı kademeli olarak dolduruyorsa tek tek alanları isteğe bağlı/nullable
  tutun ve yapısı çağıranlara göre değişen bir alan için `any` yerine `unknown`
  tercih edin (alan üzerinde belgelendiği şekilde; ör. `UsageEntry.tokens` hem sağlayıcı
  biçimindeki ham kullanımı hem de normalleştirilmiş biçimi kabul eder). Bir dosyanın
  `any` sayısı bu yöntemle sıfıra ulaştığında, gerilememesi için dosyayı
  `check:any-budget:t11` izin listesine (`scripts/check/check-t11-any-budget.mjs`,
  `maxAny: 0`) ekleyin. Bu, ilk dilime yönelik bir kuraldır — daha geniş kapsamlı
  "anonim `any` yok" temizliği kod tabanının geri kalanında yinelemeli olarak yürütülür.
- **Hatalar**: Belirli hata türleriyle try/catch kullanın, pino bağlamıyla günlükleyin. SSE
  akışlarında hataları asla sessizce yutmayın; temizlik için iptal sinyallerini kullanın.
- **Güvenlik**: Asla `eval()` / `new Function()` / örtük eval kullanmayın. Tüm
  girdileri Zod ile doğrulayın. Kimlik bilgilerini bekleme hâlindeyken şifreleyin (AES-256-GCM).
  `src/shared/constants/upstreamHeaders.ts` engelleme listesini
  temizleme/doğrulama katmanıyla uyumlu tutun.
- **Commit'ler**: Conventional Commits — `feat(scope): subject`. İzin verilen kapsamlar:
  `db`, `sse`, `oauth`, `dashboard`, `api`, `cli`, `docker`, `ci`, `mcp`,
  `a2a`, `memory`, `skills`.
- **Dallar**: `feat/`, `fix/`, `refactor/`, `docs/`, `test/`,
  `chore/` önekleri. Asla doğrudan `main` dalına commit göndermeyin.
- **Husky**: pre-commit, `lint-staged` + `check:docs-sync` +
  `check:any-budget:t11` çalıştırır; pre-push, `check:any-budget:t11` + `check:tracked-artifacts` çalıştırır (hızlı denetimler; `test:unit` hariç).
