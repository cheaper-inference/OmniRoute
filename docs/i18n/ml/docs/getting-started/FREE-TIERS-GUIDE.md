> **TL;DR** : നിങ്ങളുടെ സ്വന്തം യോഗ്യരായ ദാതാവിൻ്റെ അക്കൗണ്ടുകൾ കൊണ്ടുവരിക. നിങ്ങൾ കോൺഫിഗർ ചെയ്യുന്ന കണക്ഷനുകളെ OmniRoute സംയോജിപ്പിക്കുന്നു; ഇത് പരസ്യപ്പെടുത്തിയ മൊത്തം ടോക്കൺ ബജറ്റ് നൽകുന്നില്ല. സൗജന്യ ആക്സസിന് സൈൻ അപ്പ്, ഒരു API കീ, അംഗീകാരം അല്ലെങ്കിൽ ഒരു പേയ്മെൻ്റ് രീതി എന്നിവ ആവശ്യമാണ്. ദാതാവിൻ്റെ പരിധികൾ, സ്വകാര്യതാ നയങ്ങൾ, നിബന്ധനകൾ എന്നിവ ഇപ്പോഴും ബാധകമാണ്.

## എന്താണ് ഫ്രീ ടയറുകൾ?

പല AI ദാതാക്കളും ചില രൂപങ്ങൾ വാഗ്ദാനം ചെയ്യുന്നു** സൗജന്യ ആക്സസ്** . ദാതാവിനെ ആശ്രയിച്ച്, നോ-ഓത്ത് എൻഡ്പോയിൻ്റ്, ആവർത്തിച്ചുള്ള ക്വാട്ട, റേറ്റ്-ലിമിറ്റഡ് അൺക്യാപ്പ്ഡ് ആക്സസ്, സൈൻഅപ്പ് ഗ്രാൻ്റ്, സ്വമേധയാലുള്ള അംഗീകാരം അല്ലെങ്കിൽ താൽക്കാലിക പ്രമോഷൻ എന്നിവ അർത്ഥമാക്കാം. ചില ഓപ്ഷനുകൾക്ക് ഒരു അക്കൗണ്ട്, API കീ, ക്രെഡിറ്റ് കാർഡ്, KYC അല്ലെങ്കിൽ ദാതാവ്-നിർദ്ദിഷ്ട നിബന്ധനകളുടെ സ്വീകാര്യത എന്നിവ ആവശ്യമാണ്.

OmniRoute** സമാഹരിക്കുന്നു** കണക്ഷനുകൾ ഒരു അവസാന പോയിൻ്റിലേക്ക് ക്രമീകരിച്ചു. അക്കൗണ്ട് ആവശ്യമുള്ള ഓരോ ദാതാവിനും വേണ്ടി നിങ്ങൾ ഇപ്പോഴും പ്രത്യേകം സൈൻ അപ്പ് ചെയ്യുന്നു. ആ അക്കൗണ്ടുകൾ ബന്ധിപ്പിച്ച് യോഗ്യമായ ലക്ഷ്യങ്ങൾക്കിടയിൽ റൂട്ട് ചെയ്യാൻ `model: "auto"` ഉപയോഗിക്കുക. ഒരു പുതിയ ഇൻസ്റ്റാളേഷന് യോഗ്യതയുള്ള കീലെസ് ടാർഗെറ്റ് ഉണ്ടാകില്ല; OmniRoute ഇൻസ്റ്റാൾ ചെയ്യുന്നത് വിജയകരമായ ചാറ്റ് പ്രതികരണത്തിന് ഉറപ്പുനൽകുന്നില്ല.

## പ്രതിനിധി സൗജന്യ-ആക്സസ് ദാതാക്കൾ

## എങ്ങനെ സൗജന്യ നിരകൾ അടുക്കിവെക്കാം

OmniRoute യുടെ മാന്ത്രികതയാണ്** സ്വതന്ത്ര നിരകൾ അടുക്കുന്നു** . ഒരു ദാതാവിനെ ആശ്രയിക്കുന്നതിനുപകരം, നിങ്ങൾ ഒന്നിലധികം സൗജന്യ ദാതാക്കളെ ബന്ധിപ്പിക്കുകയും ഓരോ അഭ്യർത്ഥനയ്ക്കും ഏറ്റവും മികച്ചത് തിരഞ്ഞെടുക്കാൻ OmniRoute അനുവദിക്കുകയും ചെയ്യുന്നു.

### ഉദാഹരണം: ബ്രോഡർ ഫ്രീ-ടയർ കവറേജ്

ഏതെങ്കിലും ഒരു ക്വാട്ടയെ ആശ്രയിക്കുന്നത് കുറയ്ക്കാൻ നിരവധി ദാതാക്കളെ ബന്ധിപ്പിക്കുക:

1. **Gemini** — ആവർത്തന API-കീ ക്വാട്ട
2. **Groq** — ആവർത്തന API-കീ ക്വാട്ട
3. **പരാഗണങ്ങൾ** — കീലെസ്, നിരക്ക്-പരിമിതമായ ആക്സസ്
4. **LongCat** — ഒറ്റത്തവണ സൈൻഅപ്പ് ഗ്രാൻ്റ് ( KYC ആവശ്യമാണ്)

തുടർന്ന് `model: "auto"`, OmniRoute ഉപയോഗിക്കുക:

- ഏറ്റവും ഉയർന്ന റാങ്കുള്ള യോഗ്യതയുള്ള കണക്ഷൻ ആദ്യം പരീക്ഷിക്കുക
- അതിൻ്റെ ക്വാട്ട അല്ലെങ്കിൽ ആരോഗ്യ പരിശോധന → പരാജയപ്പെട്ടാൽ അടുത്ത കോൺഫിഗർ ചെയ്ത ദാതാവിനെ പരീക്ഷിക്കുക
- കീലെസ് പ്രൊവൈഡർ ലഭ്യമല്ലെങ്കിൽ, ശേഷിക്കുന്ന ടാർഗെറ്റുകളിലൂടെ → തുടരുക
- യോഗ്യമായ ഒരു കണക്ഷനും വിജയിച്ചില്ലെങ്കിൽ → ഒരു പിശക് തിരികെ നൽകുക; സൈൻഅപ്പ് ക്രെഡിറ്റുകൾ സാധുതയുള്ളതും ലഭ്യവുമാകുമ്പോൾ മാത്രമേ ഉപയോഗിക്കാനാവൂ

**ഫലം** : ഓട്ടോമാറ്റിക് ഫാൾബാക്ക് — ഉള്ള വിശാലമായ ഫ്രീ-ടയർ കവറേജ് പരിധിയില്ലാത്ത ശേഷിയുടെ ഗ്യാരണ്ടിയല്ല.

## സൗജന്യ ദാതാക്കളെ എങ്ങനെ ബന്ധിപ്പിക്കാം

### ഘട്ടം 1: ഡാഷ്ബോർഡ് തുറക്കുക

നിങ്ങളുടെ ബ്രൗസറിൽ `http://localhost:20128` ലേക്ക് പോകുക.

### ഘട്ടം 2: ദാതാക്കളിലേക്ക് പോകുക

ക്ലിക്ക് ചെയ്യുക** ദാതാക്കൾ** സൈഡ്ബാറിൽ.

### ഘട്ടം 3: ദാതാവിനെ ചേർക്കുക ക്ലിക്ക് ചെയ്യുക

ക്ലിക്ക് ചെയ്യുക**+ ദാതാവിനെ ചേർക്കുക** ബട്ടൺ.

### ഘട്ടം 4: ഒരു സൗജന്യ ദാതാവിനെ തിരഞ്ഞെടുക്കുക

കാറ്റലോഗ് ബ്രൗസുചെയ്ത് ഓരോ ദാതാവിൻ്റെയും നിലവിലെ `hasFree`, auth, ക്വോട്ട, സ്വകാര്യത, ToS മെറ്റാഡാറ്റ എന്നിവ പരിശോധിക്കുക. പ്രൊവൈഡർ കാർഡും [ഫ്രീ ടയർ റഫറൻസും](../reference/FREE_TIERS.md) ആവർത്തിച്ചുള്ള പൂളുകൾ, uncapped/keyless ആക്സസ്, സൈൻഅപ്പ് ക്രെഡിറ്റുകൾ, നിർത്തലാക്കിയ എൻട്രികൾ, ഉയർന്ന അപകടസാധ്യതയുള്ള ഉറവിടങ്ങൾ എന്നിവയെ വേർതിരിക്കുന്നു.

### ഘട്ടം 5: കണക്റ്റ് ക്ലിക്ക് ചെയ്യുക

ഒരു `NOAUTH` ദാതാവിനായി, OmniRoute ഒരു അപ്സ്ട്രീം ക്രെഡൻഷ്യൽ അഭ്യർത്ഥിക്കുന്നില്ല. അപ്സ്ട്രീം മൂന്നാം കക്ഷി ക്ലയൻ്റുകളെ സ്വീകരിക്കുന്നുവെന്നോ അല്ലെങ്കിൽ ലഭ്യമായ ശേഷി ഉണ്ടെന്നോ ഇത് ഉറപ്പുനൽകുന്നില്ല. OAuth, API-കീ ദാതാക്കളെ അവരുടെ ഡോക്യുമെൻ്റഡ് അക്കൗണ്ട് ഫ്ലോ വഴി ബന്ധിപ്പിച്ചിരിക്കണം. നിങ്ങളുടെ ക്ലയൻ്റ് ഇപ്പോഴും സൃഷ്ടിക്കപ്പെട്ട ഒരു OmniRoute API കീ ഉപയോഗിക്കുന്നു** ഡാഷ്ബോർഡ് → API കീകൾ** റൂട്ടർ പ്രാമാണീകരണം പ്രവർത്തനക്ഷമമാക്കുമ്പോൾ (സൃഷ്ടിയിൽ ഒരിക്കൽ മാത്രം കാണിക്കുന്നു).

### ഘട്ടം 6: ആവർത്തിക്കുക

നിങ്ങളുടെ ഉപയോഗത്തിന് അനുയോജ്യമായ നിബന്ധനകളും സ്വകാര്യതാ മോഡലും ഉള്ള നിരവധി ദാതാക്കളെ ബന്ധിപ്പിക്കുക.

## dsh "ഞങ്ങളുടെ സൗജന്യ മോഡൽ" ൽ നിന്ന് വരുന്നു

dsh ഏജൻ്റ് ഹോസ്റ്റിനുള്ള [dsh-our-free-model](https://github.com/Ebony-Vinyl/dsh-our-free-model) പ്ലഗിൻ രണ്ട് അപ്സ്ട്രീമുകളിൽ എത്തുന്നു. OmniRoute ഇതിനകം ഓരോന്നിനും ഒരു ദാതാവ് ഉണ്ട്, എന്നാൽ അവയിലൊന്ന് മാത്രമാണ് OmniRoute ൽ ഒരു സൗജന്യ പാത:

| പ്ലഗിൻ പാത    | അപ്സ്ട്രീം                                   | OmniRoute ദാതാവ്              | OmniRoute യിൽ സൗജന്യമാണോ? | എങ്ങനെ ബന്ധിപ്പിക്കാം                                                                    |
| ------------- | -------------------------------------------- | ----------------------------- | ------------------------- | ---------------------------------------------------------------------------------------- |
| കിലോ ചാനൽ     | കിലോ AI ഗേറ്റ്വേ (`api.kilo.ai/api/gateway`) | `kilo-gateway` (അപരനാമം `kg`) | അതെ                       | API കീ ഓപ്ഷണൽ: ഗേറ്റ്വേയുടെ ഫ്രീ പൂൾ ഉപയോഗിക്കുന്നതിന് അത് ശൂന്യമായി വിടുക               |
| സ്വതന്ത്ര പാത | OpenCode സെൻ (`opencode.ai`)                 | `opencode-zen`                | ഇല്ല                      | [opencode.ai/zen](https://opencode.ai/zen) ൽ നിന്നുള്ള നിങ്ങളുടെ സ്വന്തം OpenCode API കീ |

**കിലോ.** സൗജന്യ പൂളിനെ `kilo-gateway/<model>` അല്ലെങ്കിൽ `kg/<model>` എന്ന് വിളിക്കുക, ഉദാഹരണത്തിന് `kg/kilo-auto/free` (കിലോയുടെ സൗജന്യ ഓട്ടോ-റൗട്ടർ) അല്ലെങ്കിൽ ഗേറ്റ്വേയുടെ `:free` മോഡലുകളിലൊന്ന്. സ്വതന്ത്ര സെറ്റ് കറങ്ങുന്നു; `kilo-gateway` OmniRoute ൻ്റെ ബിൽറ്റ്-ഇൻ ലിസ്റ്റിൽ ഇല്ലാത്ത മോഡൽ ഐഡികളിലൂടെ കടന്നുപോകുന്നു, അതിനാൽ ഇന്ന് ഗേറ്റ്വേ ലിസ്റ്റ് ചെയ്യുന്ന ഒരു മോഡലിനെ കാറ്റലോഗിൽ ഉൾപ്പെടുത്തുന്നതിന് മുമ്പ് വിളിക്കാം. കിലോയുടെ സൗജന്യ മോഡൽ കാർഡുകൾ പറയുന്നത് അപ്സ്ട്രീം ദാതാവ് നിർദ്ദേശങ്ങൾ ലോഗ് ചെയ്ത് അതിൻ്റെ സേവനങ്ങൾ മെച്ചപ്പെടുത്താൻ ഉപയോഗിച്ചേക്കാം, അതിനാൽ സെൻസിറ്റീവ് ഡാറ്റ അയയ്ക്കരുത്.

**OpenCode.** OpenCode ൻ്റെ കീ-ഫ്രീ ഓഫറാണ് പ്ലഗിൻ്റെ സൗജന്യ പാത. OmniRoute ആ ഓഫർ സൗജന്യ ആക്സസ് ആയി നൽകുന്നില്ല:

- OmniRoute യുടെ കീലെസ്സ് OpenCode പ്രൊവൈഡർ OpenCode യുടെ ഓപ്പറേറ്ററുടെ അഭ്യർത്ഥന പ്രകാരം നീക്കം ചെയ്തു ( [നീക്കം ചെയ്ത ദാതാക്കൾ](../reference/REMOVED_PROVIDERS.md) കാണുക).
- OpenCode യുടെ [എൻഡ്പോയിൻ്റ് ഡോക്യുമെൻ്റേഷൻ](https://opencode.ai/v2/docs/console/models/#endpoints) അതിൻ്റെ സൗജന്യ ചാറ്റ് ഓഫറുകളെ OpenCode യുടെ സ്വന്തം ക്ലയൻ്റുമായി ബന്ധിപ്പിക്കുന്നു, അതിനാൽ OmniRoute അവയെ സൗജന്യമായി കണക്കാക്കുകയോ ബാഡ്ജ് ചെയ്യുകയോ ചെയ്യുന്നില്ല.

പ്ലഗിൻ കാണിക്കുന്ന `deepseek-v4.1-flash-free`, `mimo-v2.6-flash-free`, `nemotron-3.5-lightning-free` തുടങ്ങിയ മോഡൽ ഐഡികൾ `opencode-zen` കാറ്റലോഗിലാണ്. നിങ്ങളുടെ OpenCode അക്കൗണ്ടിൻ്റെ നിബന്ധനകൾക്ക് കീഴിൽ ഉപയോഗിക്കുന്നതിന് നിങ്ങളുടെ സ്വന്തം OpenCode കീ ഉപയോഗിച്ച് `opencode-zen` ബന്ധിപ്പിക്കുക.

**പ്ലഗിൻ്റെ ലോക്കൽ പോർട്ട്.** ഒരു ലോക്കൽ OpenAI-അനുയോജ്യമായ പോർട്ടിൽ (സ്ഥിരസ്ഥിതി `18899`) പ്ലഗിന് അതിൻ്റെ മോഡലുകൾ വെളിപ്പെടുത്താൻ കഴിയും. [ഇഷ്ടാനുസൃതമായ ഓപ്പൺഎഐ-അനുയോജ്യ ദാതാവായി](../guides/USER_GUIDE.md#custom-openai-compatible-providers) അത്തരത്തിലുള്ള ഏതൊരു എൻഡ്പോയിൻ്റും ചേർക്കാൻ കഴിയും, എന്നാൽ OmniRoute പ്ലഗിൻ ഇൻസ്റ്റാൾ ചെയ്യുകയോ ആരംഭിക്കുകയോ അപ്ഡേറ്റ് ചെയ്യുകയോ ചെയ്യുന്നില്ല, കൂടാതെ ഓരോ അഭ്യർത്ഥനയും ഏത് അപ്സ്ട്രീം നൽകണമെന്ന് പ്ലഗിൻ തീരുമാനിക്കുന്നു. ഏത് ക്ലയൻ്റ് അഭ്യർത്ഥന അയച്ചാലും OpenCode ൻ്റെ ഓഫറിന് മുകളിലുള്ള OpenCode നിയന്ത്രണങ്ങൾ ബാധകമാണ്.

## കാറ്റലോഗ് ശരിയായി വായിക്കുന്നു

- `NOAUTH` എന്നാൽ OmniRoute നിങ്ങളോട് ഒരു ദാതാവിൻ്റെ ക്രെഡൻഷ്യൽ ആവശ്യപ്പെടുന്നില്ല എന്നാണ് അർത്ഥമാക്കുന്നത്; ഇത് പ്രവർത്തനസമയം, സ്വകാര്യത അല്ലെങ്കിൽ പരിധിയില്ലാത്ത ശേഷി എന്നിവ ഉറപ്പുനൽകുന്നില്ല.
- `hasFree` എന്നത് കണ്ടെത്തൽ മെറ്റാഡാറ്റയാണ്. ഇതിന് ആവർത്തിച്ചുള്ള ക്വാട്ട, കീലെസ്സ് ആക്സസ്, സൈൻഅപ്പ് ക്രെഡിറ്റ്, അപ്രൂവൽ പ്രോഗ്രാം അല്ലെങ്കിൽ പ്രമോഷൻ എന്നിവയെ പ്രതിനിധീകരിക്കാനാകും.
- `recurring-uncapped` എന്നാൽ പ്രസിദ്ധീകരിച്ച ടോക്കൺ പരിധി ലഭ്യമല്ല; നിരക്കും കൺകറൻസി പരിധികളും ഇപ്പോഴും ബാധകമാണ്.
- സൈൻഅപ്പ് ഗ്രാൻ്റ് ഉപയോഗിച്ചതിന് ശേഷം`one-time-initial` ആവർത്തിക്കില്ല.
- സ്വതവേ സ്വയമേവയുള്ള റൂട്ടിംഗിൽ നിന്ന്`tos: avoid` ദാതാക്കളെ ഒഴിവാക്കിയിരിക്കുന്നു (`excludeTosAvoid`). ഒരു അക്കൗണ്ട് ബന്ധിപ്പിക്കുന്നത് ഈ ഫിൽട്ടറിനെ മറികടക്കുന്നില്ല. ഏതൊരു ഓപ്പറേറ്റർ അസാധുവാക്കലും ദാതാവിൻ്റെ നിബന്ധനകളുടെയും അക്കൗണ്ട് അപകടസാധ്യതയുടെയും അവലോകനം പാലിക്കണം.
- `discontinued` എന്ന് അടയാളപ്പെടുത്തിയിട്ടുള്ള എൻട്രികൾ ചരിത്രപരമായ തെളിവായി തുടരുന്നു, അവ നിലവിൽ സൗജന്യമായി അവതരിപ്പിക്കാൻ പാടില്ല.

## OmniRoute എങ്ങനെ ഫ്രീ ടയറുകളെ മികച്ചതാക്കുന്നു

### 1. ഓട്ടോമാറ്റിക് ഫാൾബാക്ക്

ഒരു സൗജന്യ ദാതാവ് തിരക്കിലാണെങ്കിൽ അല്ലെങ്കിൽ കുറവാണെങ്കിൽ, OmniRoute യാന്ത്രികമായി അടുത്തത് പരീക്ഷിക്കുന്നു. നിങ്ങൾ ഒന്നും ചെയ്യേണ്ടതില്ല.

### 2. സ്മാർട്ട് റൂട്ടിംഗ്

OmniRoute തിരഞ്ഞെടുക്കുന്നു** മികച്ച സൗജന്യ ദാതാവ്** ഓരോ അഭ്യർത്ഥനയ്ക്കും അടിസ്ഥാനമാക്കി:

- സ്പീഡ് — ഏത് ദാതാവാണ് ഇപ്പോൾ ഏറ്റവും വേഗതയുള്ളത്?
- ഗുണനിലവാരം — ഏത് ദാതാവാണ് ഈ ടാസ്ക്കിന് മികച്ചത്?
- ശേഷി — ഏത് ദാതാവിനാണ് ക്വാട്ട ശേഷിക്കുന്നത്?

### 3. ടോക്കൺ സേവിംഗ്സ്

OmniRoute യുടെ കംപ്രഷൻ പൈപ്പ്ലൈന് യോഗ്യതയുള്ള പ്രോംപ്റ്റ്, ടൂൾ-ഔട്ട്പുട്ട് ടോക്കണുകൾ കുറയ്ക്കാൻ കഴിയും. യഥാർത്ഥ സമ്പാദ്യം ഉള്ളടക്കം, തിരഞ്ഞെടുത്ത എഞ്ചിനുകൾ, ദാതാവിൻ്റെ അക്കൗണ്ടിംഗ്, വിശ്വസ്തത ക്രമീകരണങ്ങൾ എന്നിവയെ ആശ്രയിച്ചിരിക്കുന്നു; കംപ്രഷൻ എല്ലാ പ്രൊവൈഡർ ക്വാട്ടയെയും ഒരു നിശ്ചിത തുക കൊണ്ട് ഗുണിക്കുന്നില്ല.

### 4. മൾട്ടി-അക്കൗണ്ട് പിന്തുണ

ദാതാവിൻ്റെ നിബന്ധനകൾ ഒന്നിലധികം അക്കൗണ്ടുകൾ അല്ലെങ്കിൽ ക്രെഡൻഷ്യലുകൾ അനുവദിക്കുകയാണെങ്കിൽ, OmniRoute ഓരോ കണക്ഷനും പ്രത്യേക റൂട്ടിംഗ് കാൻഡിഡേറ്റായി കണക്കാക്കാം. ഒരു ദാതാവിൻ്റെ ക്വാട്ടയോ ആക്സസ് നയമോ ഒഴിവാക്കാൻ അധിക അക്കൗണ്ടുകൾ സൃഷ്ടിക്കരുത്.

## സ്വതന്ത്ര ടയർ ഗണിതം

തത്സമയ, പൂൾ-ഡീപ്ലിക്കേറ്റഡ് കാറ്റലോഗ് നിലവിൽ റിപ്പോർട്ട് ചെയ്യുന്നു:

| മെട്രിക്                          |            നിലവിലെ ഓഡിറ്റഡ് മൂല്യം | വ്യാഖ്യാനം                                                                                  |
| --------------------------------- | ---------------------------------: | ------------------------------------------------------------------------------------------- |
| ആവർത്തിച്ചുള്ള അളവ് ഗ്രാൻ്റ്      |      **~ 90M സൗജന്യ tokens/month** | പങ്കിട്ട കുളങ്ങൾ ഒരിക്കൽ എണ്ണപ്പെട്ടു; തുകയിൽ നിന്ന് പരിധിയില്ലാത്ത ദാതാക്കളെ ഒഴിവാക്കുന്നു |
| സൈൻഅപ്പ് ഗ്രാൻ്റുകളുള്ള ആദ്യ മാസം | **നിങ്ങളുടെ ആദ്യ മാസത്തിൽ ~ 153M** | ആവർത്തന മൊത്തവും ഒറ്റത്തവണയും ആവർത്തിച്ചുള്ള ക്രെഡിറ്റുകളും                                 |

പ്രത്യേക യോഗ്യതയുള്ള അക്കൗണ്ടുകളിലുടനീളമുള്ള കാറ്റലോഗ്-വൈഡ് എസ്റ്റിമേറ്റുകളാണ് ഇവ, OmniRoute നൽകുന്ന അലവൻസോ പുതിയ ഇൻസ്റ്റാളേഷനുള്ള പ്രവചനമോ അല്ല. നിങ്ങളുടെ ഉപയോഗയോഗ്യമായ ശേഷി നിങ്ങൾ കണക്റ്റ് ചെയ്യുന്ന ദാതാക്കളെയും അവരുടെ നിലവിലെ അവസ്ഥകളെയും ആശ്രയിച്ചിരിക്കുന്നു. മൂല്യങ്ങൾ `open-sse/config/freeModelCatalog.ts` ൽ നിന്ന് കണക്കാക്കുന്നു; പൂൾ ഡീപ്ലിക്കേഷൻ, ToS ഫ്ലാഗുകൾ, നിർത്തലാക്കിയ എൻട്രികൾ, സൈൻഅപ്പ്-ക്രെഡിറ്റ് മെത്തഡോളജി എന്നിവയ്ക്കായുള്ള [ഫ്രീ ടയർ റഫറൻസ്](../reference/FREE_TIERS.md) കാണുക.

## സാധാരണ ചോദ്യങ്ങൾ

### "ഇത് ശരിക്കും സൗജന്യമാണോ?"

ദാതാവ് പ്രസിദ്ധീകരിച്ച നിബന്ധനകളും പദ്ധതി ഗവേഷണവും കാറ്റലോഗ് രേഖപ്പെടുത്തുന്നു, എന്നാൽ ഓഫറുകൾ മാറാം. ഉപയോഗിക്കുന്നതിന് മുമ്പ് ദാതാവിൻ്റെ നിലവിലെ വില, ക്വാട്ട, സ്വകാര്യതാ നയം, യോഗ്യത എന്നിവ പരിശോധിച്ചുറപ്പിക്കുക.

### "ഫ്രീ ടയർ തീരുമോ?"

ഓരോ ദാതാവിനും റേറ്റിംഗ്-പരിമിതപ്പെടുത്താനും മോഡലുകൾ മാറ്റാനും ആക്സസ് താൽക്കാലികമായി നിർത്താനും ഓഫ്ലൈനിൽ പോകാനും കഴിയും. ഒന്നിലധികം കണക്ഷനുകൾ ഫാൾബാക്ക് കവറേജ് മെച്ചപ്പെടുത്തുന്നു, എന്നാൽ ലഭ്യമായ സൗജന്യ റൂട്ടിന് ഗ്യാരണ്ടി നൽകുന്നില്ല.

### "എനിക്ക് ഉത്പാദനത്തിനായി സൗജന്യ ദാതാക്കളെ ഉപയോഗിക്കാമോ?"

ദാതാവിൻ്റെ SLA, ഡാറ്റ കൈകാര്യം ചെയ്യൽ, പരിധികൾ, നിബന്ധനകൾ എന്നിവ നിങ്ങളുടെ പ്രൊഡക്ഷൻ ആവശ്യകതകൾ നിറവേറ്റുന്നുവെങ്കിൽ മാത്രം. നിർണ്ണായകമായ ജോലിഭാരങ്ങൾ നിരീക്ഷിക്കുകയും കരാറിന് അനുയോജ്യമായ ഫാൾബാക്ക് ഉണ്ടായിരിക്കുകയും വേണം.

### "എന്താ ക്യാച്ച്?"

ട്രേഡ്ഓഫുകളിൽ കർശനമായ പരിധികൾ, വെയ്റ്റ്ലിസ്റ്റുകൾ, KYC, ക്രെഡിറ്റ്-കാർഡ് പരിശോധന, പ്രോംപ്റ്റുകളെക്കുറിച്ചുള്ള പരിശീലനം, ദുർബലമായ സ്വകാര്യത, SLA ഇല്ല, മോഡൽ ചംക്രമണം, ഭൂമിശാസ്ത്രപരമായ നിയന്ത്രണങ്ങൾ, പണമടച്ചുള്ള ഓവർേജ് അല്ലെങ്കിൽ അക്കൗണ്ട്-പൊളിസി റിസ്ക് എന്നിവ ഉൾപ്പെട്ടേക്കാം. ലഭ്യമായ മെറ്റാഡാറ്റയെ OmniRoute ഉപരിതലമാക്കുന്നു; എന്താണ് പ്രവർത്തനക്ഷമമാക്കേണ്ടതെന്ന് നിങ്ങൾ തിരഞ്ഞെടുക്കുന്നു.

### "എനിക്ക് എങ്ങനെ കൂടുതൽ സൗജന്യ ക്വാട്ട ലഭിക്കും?"

1. കൂടുതൽ സൗജന്യ ദാതാക്കളെ ബന്ധിപ്പിക്കുക
2. ഉചിതമായ കംപ്രഷൻ എഞ്ചിനുകൾ പ്രവർത്തനക്ഷമമാക്കുക, നിങ്ങളുടെ ജോലിഭാരത്തിൻ്റെ സമ്പാദ്യം അളക്കുക
3. free/cheap ദാതാക്കളുടെ മുൻഗണന നൽകാൻ `auto/cheap` ഉപയോഗിക്കുക
4. ദാതാവിൻ്റെ നിബന്ധനകൾ ലംഘിക്കാതെ അധികമായി അനുവദനീയമായ ദാതാക്കളെയോ ക്രെഡൻഷ്യലുകളെയോ ചേർക്കുക

### "സൗജന്യ ദാതാക്കൾക്ക് മോശമായ ഗുണനിലവാരമുണ്ടോ?"

നിർബന്ധമില്ല. ചില ദാതാക്കൾ പണമടച്ചുള്ള റൂട്ടുകളിലൂടെ ലഭ്യമായ അതേ മാതൃകാ കുടുംബങ്ങളെ തുറന്നുകാട്ടുന്നു, എന്നാൽ പരിധികൾ, ലേറ്റൻസി, സ്വകാര്യത, വിശ്വാസ്യത, മോഡൽ പതിപ്പുകൾ എന്നിവ വ്യത്യാസപ്പെടാം. ഒരു ഗുണമേന്മയുള്ള സിഗ്നലായി സൗജന്യ ദാതാവിൻ്റെ റാങ്കിംഗ് പേജ് ഉപയോഗിക്കുക, നൽകിയിരിക്കുന്ന യഥാർത്ഥ മോഡൽ പരിശോധിക്കുക.
