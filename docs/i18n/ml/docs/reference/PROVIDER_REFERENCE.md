ആകെ പ്രൊവൈഡർമാർ: **375**. വിഭാഗം തിരിച്ചുള്ള വിശദാംശങ്ങൾ താഴെ കാണുക.

## വിഭാഗങ്ങൾ

- **സൗജന്യം** — API കീ ഉപയോഗിച്ചുള്ള സൗജന്യ ടയർ (ഡാഷ്ബോർഡ് വഴി കോൺഫിഗർ ചെയ്യുന്നത്)
- **ഓതന്റിക്കേഷൻ ആവശ്യമില്ല** — കീയോ സൈൻ-ഇന്നോ ഒട്ടും ആവശ്യമില്ലാത്ത പൊതു എൻഡ്പോയിന്റുകൾ
- **OAuth** — OmniRoute കൈകാര്യം ചെയ്യുന്ന സൈൻ-ഇൻ പ്രവാഹം; API കീ ആവശ്യമില്ല
- **വെബ് കുക്കി** — കുക്കി ഓതന്റിക്കേഷൻ വഴി പ്രൊവൈഡറുടെ വെബ് ആപ്പിനെ റാപ്പ് ചെയ്യുന്നു
- **API കീ** — API കീ വഴി കോൺഫിഗർ ചെയ്യുന്ന പണമടച്ചുള്ള പ്രൊവൈഡർ (സൗജന്യ ക്രെഡിറ്റുകൾ ബാധകമായേക്കാം)
- **ലോക്കൽ** — ഉപയോക്താവിന്റെ മെഷീനിൽ പ്രവർത്തിക്കുന്നു (Ollama, LM Studio, vLLM മുതലായവ)
- **തിരയൽ** — വെബ് തിരയൽ പ്രൊവൈഡർമാർ
- **ഓഡിയോ** — ഓഡിയോ മാത്രമുള്ള പ്രൊവൈഡർമാർ (TTS/STT)
- **അപ്സ്ട്രീം പ്രോക്സി** — മറ്റ് പ്രൊവൈഡർമാരിലേക്ക് പ്രോക്സി ചെയ്യുന്ന പ്രൊവൈഡർമാർ
- **ക്ലൗഡ് ഏജന്റ്** — ദീർഘകാലം പ്രവർത്തിക്കുന്ന കോഡിംഗ് ഏജന്റുമാർ (Codex Cloud, Devin, Jules)
- **സിസ്റ്റം** — OmniRoute-ന്റെ ആഭ്യന്തര പ്രൊവൈഡർമാർ (ലൂപ്പ്ബാക്ക് മുതലായവ)

അധിക ടാഗുകൾ: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`ടൂൾ കോളിംഗ്` (കാണിച്ചിരിക്കുന്നിടത്ത്): `native` — യഥാർഥ ഫങ്ഷൻ-കോളിംഗ് API; `emulated` — `webTools.ts` വഴി `tools` അറേ പ്രോംപ്റ്റിൽ അനുകരിക്കുന്നു (റെഗുലർ എക്സ്പ്രഷൻ ഉപയോഗിച്ച് പാർസ് ചെയ്യുന്ന `<tool>{...}</tool>` ബ്ലോക്കുകൾ); `none` — `tools` നിലവിൽ അറിയിപ്പില്ലാതെ ഒഴിവാക്കുന്നു. #7286 കാണുക.

ഓരോ പ്രൊവൈഡറെയും പ്രവർത്തനക്ഷമമാക്കാനും കോൺഫിഗർ ചെയ്യാനും പരിശോധിക്കാനും `/dashboard/providers`-ലെ ഡാഷ്ബോർഡ് ഉപയോഗിക്കുക.
