## വിഭാഗങ്ങൾ

- **സൗജന്യം** API കീ ഉള്ള — ഫ്രീ ടയർ (ഡാഷ്ബോർഡ് വഴി ക്രമീകരിച്ചത്)
- **നോ-ഓഥ്** കീയോ സൈൻ-ഇനോ ആവശ്യമില്ലാത്ത — പൊതു എൻഡ്പോയിൻ്റുകൾ
- **OAuth** — സൈൻ ഇൻ ഫ്ലോ കൈകാര്യം ചെയ്യുന്നത് OmniRoute ആണ്, API കീ ആവശ്യമില്ല
- **വെബ് കുക്കി** കുക്കി ഓത്ത് വഴി ദാതാവിൻ്റെ വെബ് ആപ്പ് — പൊതിയുന്നു
- **API കീ** — പെയ്ഡ് പ്രൊവൈഡർ API കീ വഴി കോൺഫിഗർ ചെയ്തു (സൗജന്യ ക്രെഡിറ്റുകൾ ബാധകമായേക്കാം)
- **പ്രാദേശിക** — ഉപയോക്താവിൻ്റെ മെഷീനിൽ പ്രവർത്തിക്കുന്നു (Ollama, LM സ്റ്റുഡിയോ, vLLM, മുതലായവ)
- **തിരയുക** — വെബ് തിരയൽ ദാതാക്കൾ
- **ഓഡിയോ** — ഓഡിയോ-മാത്രം ദാതാക്കൾ (TTS/STT)
- **അപ്സ്ട്രീം പ്രോക്സി** മറ്റ് ദാതാക്കൾക്ക് പ്രോക്സി നൽകുന്ന — ദാതാക്കൾ
- **ക്ലൗഡ് ഏജൻ്റ്** — ദീർഘകാല കോഡിംഗ് ഏജൻ്റുകൾ (Codex ക്ലൗഡ്, Devin, Jules)
- **സിസ്റ്റം** — OmniRoute-ആന്തരിക ദാതാക്കൾ (ലൂപ്പ്ബാക്ക് മുതലായവ)

അധിക ടാഗുകൾ: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (കാണിച്ചിരിക്കുന്നിടത്ത്): `native` — യഥാർത്ഥ പ്രവർത്തനം-കോളിംഗ് API; `emulated` — `tools` അറേ `webTools.ts` വഴി പ്രോംപ്റ്റ്-എമുലേറ്റ് ചെയ്യുന്നു (regex-parsed `<tool>{...}</tool>` ബ്ലോക്കുകൾ); `none` — `tools` നിലവിൽ നിശബ്ദമായി ഉപേക്ഷിച്ചിരിക്കുന്നു. #7286 കാണുക.

ഓരോ ദാതാവിനെയും പ്രവർത്തനക്ഷമമാക്കുന്നതിനും കോൺഫിഗർ ചെയ്യുന്നതിനും പരിശോധിക്കുന്നതിനും `/dashboard/providers` യിലെ ഡാഷ്ബോർഡ് ഉപയോഗിക്കുക.
