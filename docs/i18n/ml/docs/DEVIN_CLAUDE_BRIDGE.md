`devin-cli-agentic`, യഥാർഥ Claude Code റൺടൈമിന് OmniRoute-ന്റെ ലോക്കൽ Anthropic
Messages എൻഡ്പോയിന്റ് ഉപയോഗിക്കാൻ അനുവദിക്കുന്നു; അതേസമയം ഔദ്യോഗിക Devin CLI, ACP stdio വഴി മോഡൽ പ്രതികരണങ്ങൾ നൽകുന്നു. നിലവിലുള്ള Anthropic, Claude OAuth, Claude Web, അല്ലെങ്കിൽ `devin-cli` പ്രൊവൈഡറുകളിൽ ഇത് മാറ്റങ്ങളൊന്നും വരുത്തുന്നില്ല.

ക്ലയന്റ് നിയന്ത്രിക്കുന്ന ടൂൾ കോളുകൾക്കായി, Claude ഫോർമാറ്റിലുള്ള ടൂൾ പിന്തുണയുള്ള പ്രൊവൈഡറായ
`devin-cli-agentic` (അപരനാമം `dva`) വഴി റൂട്ട് ചെയ്യുക. പഴയ `devin-cli` (`dv`) ACP എക്സിക്യൂട്ടർ
ടെക്സ്റ്റ് മാത്രം പിന്തുണയ്ക്കുന്നതാണ്: ഇത് ടൂളുകളില്ലാത്ത Devin summarizer പ്രവർത്തിപ്പിക്കുന്നതിനാൽ ടൂൾ കോളുകൾ തിരികെ നൽകാൻ കഴിയില്ല. അതിന്റെ മോഡൽ
മെറ്റാഡാറ്റയും അതനുസരിച്ച് അടയാളപ്പെടുത്തിയിരിക്കുന്നതിനാൽ, ടൂൾ നിർബന്ധമായ കോംബോ റൂട്ടിംഗ് അതിനെ ഒഴിവാക്കും.

> **നിലവിലെ സ്ഥിതി: Claude Code `2.1.258`-ലേക്ക് പിൻ ചെയ്തിരിക്കുന്നു; ഓഫ്ലൈൻ, ലൈവ് സാധൂകരണങ്ങൾ അവസാനമായി രേഖപ്പെടുത്തിയത്
> `2.1.220`-ലാണ്.** `2.1.220` പിൻ, Devin CLI
> `3000.2.17`, `swe-1-7-lightning` മോഡൽ എന്നിവയിലൂടെ പരസ്പരം ഒറ്റപ്പെടുത്തിയ മൂന്ന് സാഹചര്യങ്ങൾ പൂർത്തിയാക്കി; ആ അവസാന ലൈവ് റൺ, ക്ലയന്റ് നിയന്ത്രിക്കുന്ന `Read`,
> `Edit`, `Bash` ഘട്ടങ്ങൾ, വിജയകരമായ `npm test` ഫലങ്ങൾ, പ്രോജക്റ്റ് കമാൻഡുകളുടെയും സ്കില്ലുകളുടെയും
> കണ്ടെത്തൽ, Devin-മാത്രമുള്ള റൂട്ടിംഗ്, Claude-ലേക്കുള്ള പുറത്തേക്കുള്ള ട്രാഫിക് ഒന്നുമില്ലായ്മ എന്നിവ തെളിയിച്ചു. തുടർന്ന് പിൻ `2.1.258`-ലേക്ക് ഉയർത്തി
> (OmniRoute-ന്റെ Claude ഐഡന്റിറ്റി അനുകരിക്കുന്ന CLI തലമുറയും Fable 5.1 ടയർ
> നേറ്റീവായി ഉൾപ്പെടുത്തുന്ന ആദ്യ പതിപ്പുമാണിത്). പുതിയ പിന്നിൽ, പിൻ ചെയ്ത ബേസ് ഇമേജിൽ ഇൻസ്റ്റാൾ ലെയറും `claude --version`-ഉം
> പരിശോധിച്ചു; ബ്രിഡ്ജ് യൂണിറ്റ് സ്യൂട്ട്, `compose config`, സ്റ്റാറ്റിക് ഐസൊലേഷൻ തെളിവ് എന്നിവ വിജയിക്കുന്നു — എന്നാൽ ഓഫ്ലൈൻ മോക്ക് സാഹചര്യവും ലൈവ് മൂന്ന്-സാഹചര്യ
> സ്യൂട്ടും ഇതുവരെ വീണ്ടും പ്രവർത്തിപ്പിച്ചിട്ടില്ല. ഈ പിന്നോടുകൂടി ബ്രിഡ്ജിനെ ആശ്രയിക്കുന്നതിന് മുമ്പ് അവ വീണ്ടും പ്രവർത്തിപ്പിക്കുക
> ("പിൻ ചെയ്ത ടൂളുകൾ അപ്ഡേറ്റ് ചെയ്യൽ" കാണുക).

## ആർക്കിടെക്ചർ

```text
Claude Code 2.1.258 (ഒറ്റപ്പെടുത്തിയ non-root Linux കണ്ടെയ്നർ)
  -> http://omniroute:20128/v1/messages
  -> devin-cli-agentic (Claude ഫോർമാറ്റ്, auth ആവശ്യമില്ലാത്ത പ്രൊവൈഡർ)
  -> devin acp --agent-type summarizer (ഔദ്യോഗിക ACP stdio, Devin ടൂളുകളില്ല)
  -> സമർപ്പിത devin-auth വോള്യത്തിലുള്ള Devin അക്കൗണ്ട്
```

ഔദ്യോഗിക CLI-യുടെ ഡിഫോൾട്ട് ACP ഏജന്റിന് സ്വന്തം ടൂളുകൾ പ്രവർത്തിപ്പിക്കാൻ കഴിയുന്നതിനാൽ, ഈ ബ്രിഡ്ജ്
അത് ഉപയോഗിക്കുന്നില്ല. പകരം, ഔദ്യോഗിക CLI മോഡിൽ ടൂളുകളൊന്നുമില്ലാത്ത നിശ്ചിത `summarizer` ACP ഏജന്റിനെ ഇത് ആരംഭിക്കുകയും
സീരിയലൈസ് ചെയ്ത Anthropic അഭ്യർത്ഥനയെ ഒരു എക്സിക്യൂഷൻ ട്രേസായി ഫ്രെയിം ചെയ്യുകയും ചെയ്യുന്നു. Claude നിയന്ത്രിക്കുന്ന മറ്റൊരു
പ്രവർത്തനം ആവശ്യമാകുമ്പോൾ, പ്രതികരണത്തിൽ കൃത്യമായി ഒരു ക്ലയന്റ് ടൂൾ എൻവലപ്പ് ഉണ്ടായിരിക്കണം. ഒരു പ്രതികരണം
വിജയകരമാണെന്ന് റിപ്പോർട്ട് ചെയ്യുന്നതിന് മുമ്പ് ഏതൊരു ACP `tool_call` അല്ലെങ്കിൽ `tool_call_update`-ഉം നിരസിക്കപ്പെടും.

`open-sse/executors/devin-agentic/serializer.ts`-ലെ സീരിയലൈസർ `system`,
`text`, `tool_use`, `tool_result`, `thinking`, `redacted_thinking`, `tool_choice` എന്നിവയും
Claude Code നൽകുന്ന ടൂളുകളും അതേപടി നിലനിർത്തുന്നു. ചിത്രങ്ങളോ അജ്ഞാത ബ്ലോക്കുകളോ ഉണ്ടെങ്കിൽ വ്യക്തമായി പരാജയപ്പെടും. വലിയ ടൂൾ ഫലങ്ങളിൽ
ദൃശ്യമായ ഒരു വെട്ടിച്ചുരുക്കൽ മാർക്കർ ഉപയോഗിക്കുന്നു.

ഓരോ മോഡൽ ഘട്ടത്തിലും ഒറ്റയ്ക്ക് നിലനിൽക്കുന്ന ഒരു `<tool>{...}</tool>` എൻവലപ്പ് പാർസർ സ്വീകരിക്കുന്നു. ഇത്
അഭ്യർത്ഥനയിലെ ടൂൾ ലിസ്റ്റുമായി പേര് പരിശോധിക്കുകയും ആ ടൂളിന്റെ JSON
Schema അനുസരിച്ച് ആർഗ്യുമെന്റുകൾ സാധൂകരിക്കുകയും വിവരണവും പ്രവർത്തനങ്ങളും കലർന്ന പ്രതികരണങ്ങൾ നിരസിക്കുകയും പരിമിതമായ ഒരു റിപ്പയർ അനുവദിക്കുകയും ചെയ്യുന്നു. തുടർന്ന് Claude Code
ലഭിക്കുന്ന Anthropic `tool_use` ലോക്കലായി പ്രവർത്തിപ്പിച്ച് `tool_result` OmniRoute വഴി തിരികെ അയയ്ക്കുന്നു.

## ഓട്ടോ-റൂട്ടിംഗ്

തടയപ്പെട്ടിട്ടില്ലെങ്കിൽ, OmniRoute-ന്റെ `auto/*` കാൻഡിഡേറ്റ് പൂളുകളിൽ ഈ പ്രൊവൈഡർ യോഗ്യമാണ്.
കാൻഡിഡേറ്റ് യോഗ്യത തിരഞ്ഞെടുപ്പ് ഉറപ്പാക്കുന്നില്ല: കോംബോയുടെ റൂട്ടിംഗ് തന്ത്രം (ഉദാഹരണത്തിന്,
last-known-good) മറ്റൊരു പ്രൊവൈഡറിന് മുൻഗണന നൽകിയേക്കാം. എല്ലാ അഭ്യർത്ഥനയും Devin വഴി തന്നെ പോകണമെന്ന്
നിർബന്ധമാണെങ്കിൽ `dva/<model>` അല്ലെങ്കിൽ Devin-ന് മുൻഗണന നൽകുന്ന ഒരു കോംബോ ഉപയോഗിക്കുക.

## ഒറ്റപ്പെടുത്തലും ഭീഷണി മാതൃകയും

ഹോസ്റ്റിലെ Claude ഇൻസ്റ്റലേഷൻ, അക്കൗണ്ട്, കോൺഫിഗറേഷൻ എന്നിവ പരിധിക്ക് പുറത്തുള്ളവയും
നിരോധിക്കപ്പെട്ടവയുമായി കണക്കാക്കുന്നു. Compose സേവനങ്ങൾ:

- റീഡ്-ഒൺലി റൂട്ട് ഫയൽസിസ്റ്റം, ഒഴിവാക്കിയ ശേഷികൾ, `no-new-privileges` എന്നിവയോടെ UID/GID `10001:10001` ആയി പ്രവർത്തിക്കുന്നു;
- സ്വകാര്യമായ `/home/bridge`, സമർപ്പിത Claude കോൺഫിഗറേഷൻ വോള്യം, ഒറ്റപ്പെടുത്തിയ OmniRoute ഡാറ്റ,
  പ്രത്യേക `devin-auth` വോള്യം എന്നിവ ഉപയോഗിക്കുന്നു;
- ഉപേക്ഷിക്കാവുന്ന `.sandbox` വർക്ക്സ്പേസുകൾ/തെളിവുകൾ മാത്രം മൗണ്ട് ചെയ്യുന്നു;
- ഹോസ്റ്റ് ഹോം, Keychain, SSH, ക്ലൗഡ് ക്രെഡൻഷ്യലുകൾ, അല്ലെങ്കിൽ Docker സോക്കറ്റ് എന്നിവ മൗണ്ട് ചെയ്യുന്നില്ല;
- പരിതസ്ഥിതികൾ വ്യക്തമായി നിർമ്മിക്കുകയും Anthropic API/OAuth/റൂട്ടിങ് വേരിയബിളുകൾ നീക്കം ചെയ്യുകയും ചെയ്യുന്നു;
- പ്രാദേശിക ഉപയോഗത്തിനുള്ള കീ ഉപയോഗിച്ച് Claude Code ഇൻഫറൻസ് `http://omniroute:20128`-ലേക്ക് മാത്രം നയിക്കുന്നു.

ഓഫ്ലൈൻ പ്രൊഫൈൽ ഒരു ആന്തരിക നെറ്റ്വർക്ക് ഉപയോഗിക്കുന്നു. ലൈവ് പ്രൊഫൈലിൽ, OmniRoute ഔദ്യോഗിക Devin എൻഡ്പോയിന്റുകളിലേക്ക് എത്തുന്നത് `network-guard` വഴിമാത്രമാണ്; ബന്ധമില്ലാത്ത ലക്ഷ്യസ്ഥാനങ്ങൾ നിരസിക്കപ്പെടുന്നു.
Claude Code-ന് പ്രത്യേകമായ എല്ലാ എഗ്രസ് ഗതാഗതവും നിരസിക്കുന്ന ഗാർഡ് ഉണ്ട്, കൂടാതെ `NO_PROXY` വഴി പ്രാദേശിക OmniRoute
സേവനത്തിലേക്ക് മാത്രമേ എത്താൻ കഴിയൂ. ഗാർഡ് ഓഡിറ്റ് ഫയലുകൾ അവയുടെ ഗാർഡ് പ്രോസസ് മാത്രമാണ് മൗണ്ട് ചെയ്യുന്നത്.
ടോക്കണുകളില്ലാത്ത തെളിവുകൾ എക്സ്പോർട്ട് ചെയ്യുന്നതിന് മുമ്പ് സ്ക്രിപ്റ്റുകൾ ഫയൽ ഉടമസ്ഥാവകാശം, മോഡ്, ലിങ്കുകളുടെ എണ്ണം, ഓരോ തീരുമാനവും പരിശോധിക്കുന്നു.

ഒറ്റപ്പെടുത്തലിന്റെ തെളിവ് സ്വതന്ത്രമായി പ്രവർത്തിപ്പിക്കുക:

```bash
./scripts/devin-bridge/verify-anthropic-isolation
```

ഇത് ടോപ്പോളജി, നാമകരണം ചെയ്ത മൗണ്ടുകൾ, നോൺ-റൂട്ട്/റീഡ്-ഒൺലി ക്രമീകരണങ്ങൾ, വ്യക്തമായ പ്രാദേശിക റൂട്ടിങ്,
സെൻസിറ്റീവ് എൻവയൺമെന്റ് വേരിയബിളുകളുടെ അഭാവം, Docker സോക്കറ്റിന്റെ അഭാവം, `api.anthropic.com`, `claude.ai` എന്നിവയിലേക്കുള്ള തടയപ്പെട്ട ആക്സസ്, Devin-മാത്രമുള്ള പ്രൊവൈഡർ തിരഞ്ഞെടുക്കൽ, ACP ബാക്ക്എൻഡ് ലഭ്യമല്ലാത്തപ്പോൾ വ്യക്തമായ പരാജയം എന്നിവ സാധൂകരിക്കുന്നു.

## ആദ്യതവണത്തെ സജ്ജീകരണവും സാധാരണ ഉപയോഗവും

പിൻ ചെയ്ത ഇമേജ് ബിൽഡ് ചെയ്യുക:

```bash
./scripts/devin-bridge/build
```

ഒറ്റപ്പെടുത്തിയ Devin വോള്യം മാത്രം പ്രാമാണീകരിക്കുക:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/login-devin
```

റിമോട്ട്/കണ്ടെയ്നർ പരിതസ്ഥിതികൾക്കായി ഉദ്ദേശിച്ചിട്ടുള്ള ഔദ്യോഗിക മാനുവൽ-ടോക്കൺ രീതിയാണ് ലോഗിൻ കമാൻഡ് ഉപയോഗിക്കുന്നത്.
മൂല്യം CLI പ്രോംപ്റ്റിലേക്ക് നേരിട്ട് നൽകുന്നു; അത് ഒരു പ്രോസസ് ആർഗ്യുമെന്റായി കൈമാറുകയോ,
Git-ലേക്ക് എഴുതുകയോ ഹോസ്റ്റിൽനിന്ന് പകർത്തുകയോ ചെയ്യുന്നില്ല.

ഒറ്റപ്പെടുത്തിയ Claude Code റൺടൈം ആരംഭിക്കുക:

```bash
./scripts/devin-bridge/launch
```

കണ്ടെയ്നറിലുള്ള Claude Code ആരംഭിക്കുന്നതിന് മുമ്പ് `launch`, ഒറ്റപ്പെടുത്തൽ, Devin പ്രാമാണീകരണം,
മോഡൽ കണ്ടെത്തൽ എന്നിവ വീണ്ടും പരിശോധിക്കുന്നു. ഇത് ഹോസ്റ്റിലെ Claude എക്സിക്യൂട്ടബിൾ ഒരിക്കലും പ്രവർത്തിപ്പിക്കില്ല. മോഡൽ അപരനാമങ്ങൾ
`.env.devin-bridge`-ൽ സജ്ജീകരിക്കാം; കോൺഫിഗർ ചെയ്ത എല്ലാ മൂല്യങ്ങളും
`devin-cli-agentic/` പ്രിഫിക്സ് നിലനിർത്തണം.

## സാധൂകരണ കമാൻഡുകൾ

പുനരാവർത്തിക്കാവുന്ന ഓഫ്ലൈൻ പാതയ്ക്ക് Devin അക്കൗണ്ട് ആവശ്യമില്ല, കൂടാതെ റൺടൈം ഇന്റർനെറ്റും ഇല്ല:

```bash
./scripts/devin-bridge/test-unit
./scripts/devin-bridge/test-contract
./scripts/devin-bridge/test-e2e-mock
./scripts/devin-bridge/verify-anthropic-isolation
```

പ്രാമാണീകരിച്ച, സ്വമേധയാ തിരഞ്ഞെടുക്കാവുന്ന ലൈവ് പാത:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/test-live-devin
```

ACP സെഷനുകൾ ഒരുമിച്ച് തുറക്കുന്നത് ഒഴിവാക്കാൻ ലൈവ് റണ്ണർ സാഹചര്യങ്ങൾക്കിടയിൽ കാത്തിരിക്കുകയും
ടെക്സ്റ്റ് രൂപത്തിലുള്ള അവകാശവാദങ്ങൾ വിശ്വസിക്കുന്നതിന് പകരം ഘടനാപരമായ Claude സ്ട്രീം ഇവന്റുകൾ സാധൂകരിക്കുകയും ചെയ്യുന്നു. അതിന്റെ മൂന്ന്
സാഹചര്യങ്ങൾ ഇനിപ്പറയുന്നവ തെളിയിക്കുന്നു:

1. നേരിട്ടുള്ള പ്രോജക്റ്റ് വായനയും തകരാർ വിശകലനവും;
2. യഥാർത്ഥ `Edit`, ക്ലയന്റിന്റെ ഉടമസ്ഥതയിലുള്ള `Bash` `npm test`, ടെർമിനൽ ഫലം;
3. `/bridge-check`, `bridge-proof` കണ്ടെത്തൽ, പ്രോജക്റ്റ് വായനകൾ, വിജയകരമായ മറ്റൊരു
   ക്ലയന്റിന്റെ ഉടമസ്ഥതയിലുള്ള `npm test`, തീർപ്പാക്കാത്ത ജോലികളില്ലാതെയുള്ള പൂർത്തീകരണം.

അന്തിമ ഗേറ്റ് Devin നെറ്റ്വർക്ക് ഓഡിറ്റും പരിശോധിക്കുകയും Claude എഗ്രസ് ഓഡിറ്റ്
ശൂന്യമായി തുടരണമെന്ന് നിർബന്ധിക്കുകയും ചെയ്യുന്നു.

## പിൻ ചെയ്ത ടൂളുകൾ അപ്ഡേറ്റ് ചെയ്യൽ

ഇമേജിൽ Node, Claude Code, Devin CLI എന്നിവയുടെ പതിപ്പുകൾ
`docker/devin-bridge/Dockerfile`-ൽ പിൻ ചെയ്തിരിക്കുന്നു. അപ്ഡേറ്റ് ചെയ്യാൻ:

1. വ്യക്തമായി നൽകിയിരിക്കുന്ന പതിപ്പുകൾ മാറ്റുക;
2. ആർക്കിടെക്ചർ അനുസരിച്ചുള്ള രണ്ട് Devin ആർക്കൈവ് ചെക്ക്സമുകളും ഔദ്യോഗിക
   ആർട്ടിഫാക്റ്റിനുള്ള മൂല്യങ്ങൾ ഉപയോഗിച്ച് മാറ്റിസ്ഥാപിക്കുക;
3. വീണ്ടും ബിൽഡ് ചെയ്ത് എല്ലാ ഓഫ്ലൈൻ വാലിഡേഷൻ കമാൻഡുകളും പ്രവർത്തിപ്പിക്കുക;
4. ഇമേജിനുള്ളിലെ പതിപ്പുകൾ സ്ഥിരീകരിക്കുക;
5. ഓതന്റിക്കേഷൻ ആവശ്യമായ മൂന്ന്-സാഹചര്യ ലൈവ് സ്യൂട്ട് വീണ്ടും പ്രവർത്തിപ്പിക്കുക.

രണ്ട് CLI-കളിൽ ഒന്നും ഹോസ്റ്റിൽ ഗ്ലോബലായി ഇൻസ്റ്റാൾ ചെയ്യരുത്; അതുപോലെ ചെക്ക്സം പരിശോധനയ്ക്ക് പകരം
പരിശോധിക്കാത്ത ഡൗൺലോഡ് ഉപയോഗിക്കരുത്.

## രോഗനിർണയവും വൃത്തിയാക്കലും

- `docker compose -f docker/devin-bridge/compose.yml --profile offline logs omniroute`
  ലോക്കൽ റൂട്ടിങ്ങും ശുദ്ധീകരിച്ച എക്സിക്യൂട്ടർ പിശകുകളും കാണിക്കുന്നു.
- `.sandbox/evidence/mock-acp.jsonl` നിർണായകമായ മോക്ക് ACP പ്രവർത്തനങ്ങൾ രേഖപ്പെടുത്തുന്നു.
- `.sandbox/evidence/claude-stream.jsonl` യഥാർത്ഥ Claude Code ഓഫ്ലൈൻ റൺ രേഖപ്പെടുത്തുന്നു.
- `.sandbox/evidence/live-*.jsonl` സാധൂകരിച്ച മൂന്ന് ലൈവ് സ്ട്രീമുകൾ രേഖപ്പെടുത്തുന്നു.
- `.sandbox/evidence/egress.jsonl`, `.sandbox/evidence/claude-egress.jsonl` എന്നിവ ഗാർഡ് ഓഡിറ്റുകളുടെ സാധൂകരിച്ച,
  ടോക്കൺ-രഹിത പകർപ്പുകളാണ്.

ലോഗിൻ/കോൺഫിഗ് വോള്യങ്ങൾ നിലനിർത്തിക്കൊണ്ട് ഉടമസ്ഥതയിലുള്ള കണ്ടെയ്നറുകളും നെറ്റ്വർക്കുകളും നിർത്തുക:

```bash
./scripts/devin-bridge/clean
```

നാമകരണം ചെയ്ത വോള്യങ്ങൾ ഉൾപ്പെടെ ബ്രിഡ്ജിന്റെ ഉടമസ്ഥതയിലുള്ള പരിസ്ഥിതി പൂർണമായും നീക്കം ചെയ്യുക:

```bash
./scripts/devin-bridge/clean --all
```

## പരിമിതികൾ

- Devin CLI `3000.2.17` ഒരു നിഷ്പക്ഷവും ടൂളുകളില്ലാത്തതുമായ ACP ഏജന്റിനെ ലഭ്യമാക്കാത്തതിനാൽ, ബ്രിഡ്ജ് സ്ഥിരമായ ടൂളുകളില്ലാത്ത `summarizer` റോളിനെ ആശ്രയിക്കുന്നു. സംഗ്രഹത്തിന്റെ രൂപത്തിലുള്ള
  ഇടക്കാല പ്രതികരണങ്ങൾക്കായി അഡാപ്റ്റർ പരിഹാരം നൽകുന്നുണ്ടെങ്കിലും, പരിധിയിട്ട ഒരു റിപ്പയർ ശ്രമം വ്യക്തമായി പരാജയപ്പെടാൻ ഇപ്പോഴും സാധ്യതയുണ്ട്.
- ലൈവ് ACP കോളുകൾ താൽക്കാലികമായ `502`/`504` പ്രതികരണങ്ങൾ നൽകാം. ഹാർനെസ് സാഹചര്യങ്ങൾക്കിടയിൽ ഇടവേള നൽകുന്നു;
  തുടർച്ചയായ പരാജയം ഫെയിൽ-ക്ലോസ്ഡ് ആയി തുടരുകയും മറ്റൊരു പ്രൊവൈഡറെ ഒരിക്കലും തിരഞ്ഞെടുക്കാതിരിക്കുകയും ചെയ്യുന്നു.
- ഓരോ Anthropic അഭ്യർത്ഥനയിൽനിന്നും ACP കോൺടെക്സ്റ്റ് പുനർനിർമ്മിക്കപ്പെടുന്നു; പ്രോസസ്/സെഷൻ
