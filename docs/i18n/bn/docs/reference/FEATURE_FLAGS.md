> ওই ফাইল থেকে তথ্য পড়ে, তাই নিচের টেবিলটি এর সঙ্গে 1:1 মিল রেখে তৈরি করা হয়েছে।

## ফিচার ফ্ল্যাগ কী

ফিচার ফ্ল্যাগ হলো একটি নামযুক্ত টগল (boolean বা enum), যার মান রানটাইমে
পরিবর্তন করে ডেটাবেসে সংরক্ষণ করা যায় এবং এর জন্য প্রসেস পুনরায় ডিপ্লয় করার
প্রয়োজন হয় না। প্রতিটি ফ্ল্যাগ একটি `FeatureFlagDefinition` দ্বারা বর্ণিত হয়,
যাতে একটি `key`, `label`, `description`, `category`, `defaultValue`, `type` এবং
একটি `requiresRestart` ইঙ্গিত থাকে।

### রেজোলিউশনের ক্রম

কোনো ফ্ল্যাগের **কার্যকর মান**
[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) দ্বারা নিচের
অগ্রাধিকার অনুযায়ী নির্ধারিত হয় (সর্বোচ্চ অগ্রাধিকার জয়ী হয়):

1. **DB ওভাররাইড** — `feature_flags` নেমস্পেসের অধীনে `key_value` টেবিলে
   সংরক্ষিত একটি মান (ড্যাশবোর্ড বা REST API-এর মাধ্যমে সেট করা হয়)।
2. **এনভায়রনমেন্ট ভেরিয়েবল** — `process.env[<KEY>]`, যদি সেট করা থাকে এবং খালি না হয়।
3. **সংজ্ঞার ডিফল্ট** — `featureFlagDefinitions.ts` থেকে নেওয়া `defaultValue`।

কোনো boolean ফ্ল্যাগের কার্যকর মান `"true"`, `"1"` বা `"yes"` হলে সেটিকে
**সক্রিয়** হিসেবে বিবেচনা করা হয় (`isFeatureFlagEnabled()` দেখুন)।

> [!NOTE]
> অধিকাংশ ফ্ল্যাগের জন্য [`ENVIRONMENT.md`](./ENVIRONMENT.md)-এ নথিভুক্ত
> **একই নামের** একটি সংশ্লিষ্ট এনভায়রনমেন্ট ভেরিয়েবলও রয়েছে। ফ্ল্যাগটির DB
> ওভাররাইড ওই এনভায়রনমেন্ট ভেরিয়েবলের চেয়ে অগ্রাধিকার পায়। `requiresRestart: true`
> থাকা কোনো ফ্ল্যাগ সঙ্গে সঙ্গে সংরক্ষিত হয়, তবে কেবল প্রসেস চালু হওয়ার সময়
> পুনরায় পড়া হয় — এটি টগল করলে ড্যাশবোর্ডে একটি **"সার্ভার পুনরায় চালু করুন"**
> ব্যানার প্রদর্শিত হয়।

| `CREDENTIAL_GATE_AUTH_DIAGNOSES_ONLY`     | বুলিয়ান | `false` | কম্বো শংসাপত্রের গেটটি সংকীর্ণ করুন যাতে একটি ক্যাশ করা ব্যর্থ শংসাপত্র প্রোব শুধুমাত্র তখনই একটি সংযোগকে ব্লক করে যখন এর নির্ণয় খারাপ প্রমাণপত্রাদি প্রমাণ করে (`upstream_auth_error`, `auth_missing`, `token_expired`, `token_refresh_failed`, `reauth_required`, `account_deactivated`, `auth_required`)। পরিবহন নির্ণয় (`network_error`, `upstream_unavailable`, `upstream_rate_limited`) সর্বদা অনিশ্চিত থাকে এবং এই পতাকা বন্ধ থাকা অবস্থায়ও প্রেরণকে অবরুদ্ধ করে না। সক্রিয় করা হলে, অন্যান্য অনিয়ন্ত্রিত রোগ নির্ণয় (অস্পষ্ট ত্রুটি, অসমর্থিত প্রোব এবং টাইপ না করা সময়সূচী ত্রুটি) অজানা হিসাবে বিবেচিত হয়, যা ট্রাফিকের অনুমতি দেয়। ডিফল্টরূপে বন্ধ: অন্যান্য ক্যাশ করা প্রোব ত্রুটি এখনও ক্যাশে TTL (5 মিনিট) এর জন্য প্রেরণকে অবরুদ্ধ করে। |

> [!NOTE]
> `INPUT_SANITIZER_BLOCK_THRESHOLD` এবং এর লিগ্যাসি ওরফে `INJECTION_GUARD_BLOCK_THRESHOLD` `INJECTION_GUARD_MODE` এর `block` মোড টিউন করে, কিন্তু তারা [`src/shared/utils/injectionSeverity.ts`](../../src/shared/utils/injectionSeverity.ts) দ্বারা পড়া প্লেইন এনভায়রনমেন্ট ভেরিয়েবল, ফিচার ফ্ল্যাগ নয়: তাদের DB ওভাররাইড নেই এবং কোনো ড্যাশবোর্ড টগল নেই। [`ENVIRONMENT.md`](./ENVIRONMENT.md#4-security--authentication) দেখুন।

> [!NOTE]
> `Restart` কলাম `requiresRestart: true` — দিয়ে পতাকা চিহ্নিত করে মানটি অবিলম্বে বজায় থাকে কিন্তু প্রক্রিয়াটি পুনরায় লোড হওয়ার পরেই কার্যকর হয়। Enum পতাকাগুলি তাদের অনুমোদিত সেটের বাইরে যে কোনও মান প্রত্যাখ্যান করে ( `setFeatureFlagOverride()` এবং REST `PUT` হ্যান্ডলার উভয় ক্ষেত্রেই সার্ভার-সাইড বৈধ)।

## টগল করা পতাকা

### ড্যাশবোর্ড

নেভিগেট করুন** ড্যাশবোর্ড → সেটিংস → বৈশিষ্ট্য পতাকা** (`/dashboard/settings/feature-flags`) গ্রিড (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`) সমর্থন করে:

- **অনুসন্ধান করুন** কী বা বর্ণনা দ্বারা, এবং** ফিল্টার** বিভাগ দ্বারা (প্লাস একটি সিন্থেটিক** রিস্টার্ট প্রয়োজন** দেখুন)।
- ক** টগল** বুলিয়ান পতাকা এবং ক** ড্রপডাউন** enum পতাকা জন্য (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`)।
- ক** উৎস ব্যাজ** প্রতি পতাকা — `DB`, `ENV`, বা `DEF` — দেখায় যে কার্যকর মানটি কোথা থেকে এসেছে।
- ক** রিসেট করুন** ওভাররাইড ড্রপ করার জন্য বোতাম (শুধুমাত্র `DB` -sourced পতাকাগুলির জন্য দেখানো হয়েছে) এবং ক** সমস্ত ওভাররাইড রিসেট করুন** নীচে বোতাম।
- ক** সার্ভার পুনরায় চালু করুন** ব্যানার যখন একটি `requiresRestart` পতাকা পরিবর্তন করা হয়।

### REST API

সমস্ত ক্রিয়াকলাপ একটি একক রুটের মধ্য দিয়ে যায়: [`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts) । প্রতিটি পদ্ধতির জন্য একটি প্রমাণীকৃত ড্যাশবোর্ড সেশন প্রয়োজন ( অন্যথায়`401` )।

#### `GET /api/settings/feature-flags`

প্রতিটি পতাকাকে তার কার্যকরী মান, উৎস এবং একটি সারসংক্ষেপ প্রদান করে।

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Require API Key",
      "description": "Require an API key for all incoming requests",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... all 114 flags
  ],
  "summary": {
    "total": 114,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

একটি একক ওভাররাইড সেট করুন বা সরান৷ শরীর: `{ key: string; value?: string }`। `value` বাদ দিলে ওভাররাইড মুছে যায় (env/ডিফল্ট পুনরুদ্ধার করা)।

```bash
# Set a DB override
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# Remove the override (no "value")
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

প্রতিক্রিয়াটি নতুন `effectiveValue`/`source`, `previousValue`/ `previousSource` এবং `requiresRestart` প্রতিধ্বনি করে। অজানা কী এবং রেঞ্জের বাইরের enum মান `400` দিয়ে প্রত্যাখ্যান করা হয়।

#### `DELETE /api/settings/feature-flags`

সাফ করে** সব** DB একবারে ওভাররাইড করে, প্রতিটি পতাকাকে তার env/ডিফল্ট মানতে পুনরুদ্ধার করে। `{ cleared: <count>, message: "..." }` ফেরত দেয়।

> [!NOTE]
> `requiresRestart: true` সহ পতাকাগুলি শুধুমাত্র একটি প্রক্রিয়া পুনরায় লোড করার পরে কার্যকর হয়৷ ড্যাশবোর্ডের রিস্টার্ট ফ্লো `POST /api/restart` কল করে এবং তারপর সার্ভার ব্যাক আপ না হওয়া পর্যন্ত `GET /api/health/ping` পোল করে।

## জরুরি বাজেট ফলব্যাক

`OMNIROUTE_EMERGENCY_FALLBACK` (`runtime` বিভাগ, ডিফল্ট `true`)
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts)-এ
জরুরি বিনামূল্যের ফলব্যাক পথ নিয়ন্ত্রণ করে। এটি সক্রিয় থাকলে, যেসব অনুরোধের
বাজেট শেষ হয়ে যায়, সেগুলো সরাসরি ব্যর্থ হওয়ার পরিবর্তে একটি বিনামূল্যের ফলব্যাক
প্রোভাইডার/মডেলে রাউট করা হয়। এই আচরণ নিষ্ক্রিয় করতে এবং বাজেট শেষ হয়ে যাওয়া
অনুরোধগুলোকে ব্যর্থ হতে দিতে ড্যাশবোর্ড টগল, একটি DB ওভাররাইড, অথবা
`OMNIROUTE_EMERGENCY_FALLBACK` এনভায়রনমেন্ট ভেরিয়েবলের মাধ্যমে এটিকে `false`
(অথবা `0`) সেট করুন। (PRs #3741 / #3752-এ ড্যাশবোর্ড টগল হিসেবে প্রদর্শিত।)

এই ফলব্যাকের মাধ্যমে পরিবেশিত প্রতিক্রিয়ায়
`X-OmniRoute-Emergency-Fallback: from=<provider/model>; to=<provider/model>` থাকে,
যাতে কোনো ক্লায়েন্ট তার অনুরোধের সঙ্গে `X-OmniRoute-Provider`-এর পার্থক্য যাচাই
না করেই বুঝতে পারে যে অনুরোধটি পুনরায় রাউট করা হয়েছিল। অন্য সব প্রতিক্রিয়ায়
এই হেডারটি অনুপস্থিত থাকে।
