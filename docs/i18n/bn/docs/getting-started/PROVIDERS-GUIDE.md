> **সংক্ষেপে**: একটি প্রোভাইডার হলো কোনো AI পরিষেবার সঙ্গে সংযোগ (যেমন OpenAI, Anthropic, Google)। OmniRoute ব্যবহার করতে আপনার অন্তত একটি প্রোভাইডার প্রয়োজন।

---

## প্রোভাইডার কী?

একটি প্রোভাইডারকে **মোবাইল অপারেটর** হিসেবে ভাবুন। কল করার জন্য যেমন আপনার একটি মোবাইল অপারেটর প্রয়োজন, তেমনি AI মডেল ব্যবহার করার জন্য আপনার একটি AI প্রোভাইডার প্রয়োজন। OmniRoute এমন একটি ফোনের মতো, যা **সব অপারেটরের** সঙ্গে কাজ করে — আপনি স্বয়ংক্রিয়ভাবে এগুলোর মধ্যে পরিবর্তন করতে পারেন।

### প্রোভাইডারের ধরন

| ধরন             | এটি কী                          | উদাহরণ                          | খরচ                               |
| --------------- | ------------------------------- | ------------------------------- | --------------------------------- |
| **বিনামূল্যের** | কোনো অর্থপ্রদান প্রয়োজন নেই    | Kiro, Pollinations              | $0                                |
| **API Key**     | আপনার একটি API key প্রয়োজন     | OpenAI, Anthropic, Google       | ব্যবহার অনুযায়ী মূল্য            |
| **OAuth**       | আপনার অ্যাকাউন্ট দিয়ে লগইন     | Claude Code, GitHub Copilot     | সাবস্ক্রিপশন                      |
| **Web Cookie**  | আপনার ব্রাউজার সেশন ব্যবহার করে | ChatGPT Web (Codex), Gemini Web | $0 (আপনার অ্যাকাউন্ট ব্যবহার করে) |

### Web Cookie প্রোভাইডার

সাধারণ সেটআপ নির্দেশনা, সীমাবদ্ধতা, সমস্যা সমাধান এবং প্রোভাইডার-নির্দিষ্ট প্রমাণীকরণ নির্দেশিকার জন্য **[WEB-COOKIE-GUIDE.md](./WEB-COOKIE-GUIDE.md)** দেখুন।

## দ্রুত শুরু: আপনার প্রথম প্রোভাইডার সংযুক্ত করুন

### ঐচ্ছিক প্রথম-চালনার ফ্রি-প্রোভাইডার সেটআপ

প্রথম-চালনার উইজার্ডে একটি সুস্পষ্ট **ফ্রি প্রোভাইডার সেট আপ করুন** কার্ড রয়েছে। এটি OmniRoute-এর প্রমাণীকরণ-বিহীন প্রোভাইডার রেজিস্ট্রি থেকে বর্তমান
যোগ্য তালিকা তৈরি করে, তারপর নিশ্চিত করার আগে আপনাকে প্রতিটি
প্রোভাইডার পর্যালোচনা ও নির্বাচনমুক্ত করতে দেয়। OmniRoute প্রোভাইডারের সতর্কতামূলক বিজ্ঞপ্তি এবং তার সাইটের একটি লিংক দেখায়,
যাতে আপনি আগে তৃতীয় পক্ষের শর্তাবলি, গোপনীয়তা, প্রাপ্যতা এবং রেট লিমিট পর্যালোচনা করতে পারেন।

এই পদক্ষেপটি ঐচ্ছিক: উইজার্ড সম্পন্ন করলে কখনোই নীরবে ফ্রি-প্রোভাইডার সংযোগ তৈরি হয় না।
এটি শুধু এখনো অনুপস্থিত প্রোভাইডারগুলো তৈরি করে, বিদ্যমান কাস্টমাইজ করা সংযোগগুলো
অপরিবর্তিত রাখে এবং তৈরি হওয়া, ইতিমধ্যে-কনফিগার করা ও ব্যর্থ প্রোভাইডারগুলো আলাদাভাবে রিপোর্ট করে। আংশিক ফলাফলের পরে আপনি
নিরাপদে শুধু ব্যর্থ প্রোভাইডারগুলো পুনরায় চেষ্টা করতে পারেন।

### বিকল্প A: ফ্রি প্রোভাইডার (ক্রেডিট কার্ড ছাড়া)

1. `http://localhost:20128`-এ ড্যাশবোর্ড খুলুন
2. **প্রোভাইডার** → **প্রোভাইডার যোগ করুন**-এ যান
3. এই ফ্রি প্রোভাইডারগুলোর যেকোনো একটি নির্বাচন করুন:
   - **Kiro AI** — বিনামূল্যের Claude মডেল (প্রমাণীকরণের প্রয়োজন নেই)
   - **Pollinations** — বিনামূল্যের GPT-5, Claude, Gemini (কোনো কী প্রয়োজন নেই)
   - **LongCat** — 10M টোকেন বিনামূল্যে (এককালীন বরাদ্দ, অ্যাকাউন্ট + KYC প্রয়োজন)
   - **Cloudflare AI** — 50+ মডেল, প্রতিদিন 10K নিউরন
   - **MLX Gemma 26B** — স্থানীয় Apple Silicon মডেল (~38.5 tok/s, ~15.9GB RAM)
   - **MLX Qwen 3.8 27B** — স্থানীয় Apple Silicon মডেল (~9.1 tok/s, ~13.1GB RAM)
4. **সংযুক্ত করুন**-এ ক্লিক করুন
5. সম্পন্ন! এখন আপনার বিনামূল্যে AI ব্যবহারের সুযোগ রয়েছে।

### বিকল্প B: API কী প্রোভাইডার (পেইড)

1. প্রোভাইডারের ওয়েবসাইট থেকে একটি API কী সংগ্রহ করুন:
   - **OpenAI**: https://platform.openai.com/api-keys
   - **Anthropic**: https://console.anthropic.com/
   - **Google**: https://aistudio.google.com/apikey
   - **DeepSeek**: https://platform.deepseek.com/
   - **Groq**: https://console.groq.com/
2. `http://localhost:20128`-এ ড্যাশবোর্ড খুলুন
3. **প্রোভাইডার** → **প্রোভাইডার যোগ করুন**-এ যান
4. আপনার প্রোভাইডার নির্বাচন করুন
5. আপনার API কী পেস্ট করুন
6. **সংযুক্ত করুন**-এ ক্লিক করুন
7. সম্পন্ন! এখন আপনার সেই প্রোভাইডারের মডেলগুলো ব্যবহারের সুযোগ রয়েছে।

### বিকল্প C: OAuth প্রোভাইডার (সাবস্ক্রিপশন)

1. `http://localhost:20128`-এ ড্যাশবোর্ড খুলুন
2. **প্রোভাইডার** → **প্রোভাইডার যোগ করুন**-এ যান
3. আপনার প্রোভাইডার নির্বাচন করুন (যেমন, Claude Code, GitHub Copilot)
4. **OAuth দিয়ে সংযুক্ত করুন**-এ ক্লিক করুন
5. আপনার অ্যাকাউন্ট দিয়ে লগইন করুন
6. সম্পন্ন! এখন আপনার সাবস্ক্রিপশনের মডেলগুলো ব্যবহারের সুযোগ রয়েছে।

### বিকল্প D: স্থানীয় MLX মডেল (Apple Silicon)

ইউনিফায়েড মেমোরিসহ Apple Silicon Mac-এর জন্য, OmniRoute নিয়মিত OpenAI-সামঞ্জস্যপূর্ণ স্থানীয় প্রোভাইডার হিসেবে `mlx-lm.server`-এর মাধ্যমে চলমান স্থানীয় MLX মডেলের সঙ্গে সংযোগ সমর্থন করে।

#### পূর্বশর্ত

- **Apple Silicon Mac** (M1/M2/M3/M4), 24GB+ ইউনিফায়েড মেমোরি সুপারিশ করা হয়
- **uv** প্যাকেজ ম্যানেজার: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**: `uv pip install mlx-lm`

#### দ্রুত শুরু

1. **ডিপেন্ডেন্সি ইনস্টল করুন**:

   ```bash
   # uv আগে থেকে ইনস্টল করা না থাকলে ইনস্টল করুন
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # mlx-lm ইনস্টল করুন
   uv pip install mlx-lm
   ```

2. **MLX সার্ভারগুলো ম্যানুয়ালি চালু করুন** (আলাদা টার্মিনালে):

   ```bash
   # টার্মিনাল 1: Gemma 4 26B A4B IT-QAT (পোর্ট 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # টার্মিনাল 2: Qwen 3.8 27B MLX Mixed (পোর্ট 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **OmniRoute ড্যাশবোর্ডে সংযুক্ত করুন**:
   - **প্রোভাইডার** → **প্রোভাইডার যোগ করুন**-এ যান
   - **MLX Gemma 26B** অথবা **MLX Qwen 3.8 27B** নির্বাচন করুন
   - **সংযুক্ত করুন**-এ ক্লিক করুন (কোনো API কী প্রয়োজন নেই)

4. **OpenCode-এর সঙ্গে ব্যবহার করুন**:
   ```bash
   # OmniRoute ব্যবহারের জন্য OpenCode কনফিগার করুন
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <your-omniroute-api-key>

   # MLX মডেল ব্যবহার করুন
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

#### মেমোরি ব্যবস্থাপনা

**গুরুত্বপূর্ণ**: 24GB ইউনিফায়েড মেমোরিতে একবারে শুধু **একটি বড় MLX মডেল চলতে পারে**।

- Gemma 26B: সর্বোচ্চ ~15.9GB মেমোরি
- Qwen 3.8 27B: সর্বোচ্চ ~13.1GB মেমোরি

আপনাকে এটি ম্যানুয়ালি পরিচালনা করতে হবে:

- একবারে শুধু একটি MLX সার্ভার চালান, অথবা
- দুটি আলাদা মেশিনে চালান, অথবা
- অন্যটি চালু করার আগে একটি বন্ধ করুন

OmniRoute স্বয়ংক্রিয়ভাবে MLX সার্ভার প্রসেস পরিচালনা করে না — এটি শুধু আপনার কনফিগার করা OpenAI-সামঞ্জস্যপূর্ণ এন্ডপয়েন্টে রিকোয়েস্ট রাউট করে।

#### টুল কলিং সমর্থন

দুটি মডেলই OpenAI-সামঞ্জস্যপূর্ণ টুল কলিং সমর্থন করে। এটি দিয়ে পরীক্ষা করুন:

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mlx-gemma/gemma-4-26b",
    "messages": [{"role": "user", "content": "What is 2+2? Use the calculator tool."}],
    "tools": [{"type": "function", "function": {"name": "calculator", "description": "Calculate", "parameters": {"type": "object", "properties": {"expression": {"type": "string"}}, "required": ["expression"]}}}]
  }'
```

### ধাপ 1: ড্যাশবোর্ড খুলুন

**+ প্রদানকারী যোগ করুন** বোতামে ক্লিক করুন।

### ধাপ 4: আপনার প্রদানকারী নির্বাচন করুন

তালিকাটি দেখুন অথবা আপনার প্রদানকারীকে খুঁজুন। সেটিতে ক্লিক করুন।

### ধাপ 5: পরিচয়পত্র লিখুন

- **বিনামূল্যের প্রদানকারী**: কোনো পরিচয়পত্রের প্রয়োজন নেই — শুধু **সংযুক্ত করুন**-এ ক্লিক করুন
- **API কী প্রদানকারী**: আপনার API কী পেস্ট করুন
- **OAuth প্রদানকারী**: **OAuth দিয়ে সংযুক্ত করুন**-এ ক্লিক করে লগইন করুন

## একাধিক প্রোভাইডার ব্যবহার

OmniRoute **একাধিক প্রোভাইডারের** সঙ্গে সবচেয়ে ভালো কাজ করে। এতে আপনি পাবেন:

- **স্বয়ংক্রিয় ফলব্যাক** — একটি প্রোভাইডার ব্যর্থ হলে, OmniRoute পরবর্তীটি চেষ্টা করে
- **খরচ অপ্টিমাইজেশন** — OmniRoute প্রতিটি অনুরোধের জন্য সবচেয়ে সাশ্রয়ী প্রোভাইডার বেছে নেয়
- **গতি অপ্টিমাইজেশন** — OmniRoute প্রতিটি অনুরোধের জন্য সবচেয়ে দ্রুত প্রোভাইডার বেছে নেয়
- **গুণমান অপ্টিমাইজেশন** — OmniRoute প্রতিটি কাজের জন্য সবচেয়ে ভালো প্রোভাইডার বেছে নেয়

### প্রস্তাবিত সেটআপ

সেরা অভিজ্ঞতার জন্য অন্তত **3টি প্রোভাইডার** সংযুক্ত করুন:

1. **একটি বিনামূল্যের প্রোভাইডার** (Kiro বা Pollinations) — সবসময় উপলভ্য
2. **একটি দ্রুত প্রোভাইডার** (Groq, Cerebras) — দ্রুত প্রতিক্রিয়ার জন্য
3. **একটি উচ্চমানের প্রোভাইডার** (OpenAI, Anthropic, Google) — জটিল কাজের জন্য

এরপর `model: "auto"` ব্যবহার করুন, এবং OmniRoute প্রতিটি অনুরোধের জন্য স্বয়ংক্রিয়ভাবে সেরা প্রোভাইডারটি বেছে নেবে।

### Qoder: ক্রেডেনশিয়াল পরিবহন পদ্ধতি বেছে নিন

Qoder-এর জন্য ক্রেডেনশিয়াল প্রয়োজন। এর দুটি পরিবহন পদ্ধতির সক্ষমতা ভিন্ন; শুধু একটি মডেলের নাম
দিয়ে কোনো নির্দিষ্ট সংযোগ কী করতে পারে তা শনাক্ত করা যায় না।

| ক্রেডেনশিয়াল                     | OmniRoute পরিবহন                                    | কলার টুল কলিং                                           | স্ট্রিমিং                                                      |
| --------------------------------- | --------------------------------------------------- | ------------------------------------------------------- | -------------------------------------------------------------- |
| `pt-` দিয়ে শুরু হওয়া PAT        | OmniRoute হোস্টে স্থানীয় `qodercli` প্রসেস         | সমর্থিত নয়                                             | বাফার করা: CLI সম্পূর্ণ উত্তর দেওয়ার পরেই কেবল SSE নির্গত হয় |
| Non-PAT অ্যাক্সেস টোকেন বা API কী | DashScope-এর OpenAI-সামঞ্জস্যপূর্ণ HTTP এন্ডপয়েন্ট | আপস্ট্রিম মডেল/কীর সীমাবদ্ধতা সাপেক্ষে পাস-থ্রু করা হয় | আপস্ট্রিম HTTP/SSE পাথ                                         |

PAT-এর ক্ষেত্রে, OmniRoute যে হোস্ট বা কনটেইনারে রয়েছে, সেখানেই Qoder CLI ইনস্টল করুন। এক্সিকিউটেবলটি
`qodercli` হিসেবে আবিষ্কারযোগ্য হতে হবে, অথবা এর এক্সিকিউটেবল পাথে `CLI_QODER_BIN` সেট করুন। শুধু
Docker হোস্টে ইনস্টল করা CLI কনটেইনারে স্বয়ংক্রিয়ভাবে উপলভ্য হয় না। বাইনারি অনুপস্থিত থাকলে
একটি স্পষ্ট ত্রুটি দেখানো হয়, যা আপনাকে ইনস্টলেশন বা পাথ সেটিংয়ের দিকে নির্দেশ করে।

PAT চ্যাট পাথে 45-সেকেন্ডের প্রসেস টাইমআউট রয়েছে। এটি কথোপকথনটিকে একটি
প্রম্পটে সমতল করে এবং নন-স্ট্রিমিং প্রিন্ট মোডে CLI চালু করে। `stream: true` অনুরোধ করলে
রেসপন্স এনভেলপ SSE-তে পরিবর্তিত হয়; এটি ক্রমবর্ধমান আপস্ট্রিম টোকেন সরবরাহ করে না।
CLI যাচাইকরণ/মডেল তালিকাকরণে পৃথক 20-সেকেন্ডের টাইমআউট ব্যবহৃত হয়। এগুলো বর্তমান কোডের
ডিফল্ট, কনফিগারযোগ্য ড্যাশবোর্ড সেটিংস নয়।

সাধারণ চ্যাটের জন্য PAT সংযোগ ব্যবহার করুন। `tools` বা লিগ্যাসি `functions` বহনকারী এজেন্ট অনুরোধগুলো
ক্রেডেনশিয়াল নির্বাচনের সময় PAT অ্যাকাউন্ট বাদ দেয়, যার মধ্যে পিন করা কম্বো টার্গেটও অন্তর্ভুক্ত। একটি মিশ্র
Qoder পুল তবুও তার HTTP অ্যাকাউন্ট নির্বাচন করতে পারে। PAT এক্সিকিউটরে সরাসরি কলও
টুলের সংজ্ঞা নীরবে বাদ দেওয়ার পরিবর্তে CLI চালু করার আগেই স্পষ্টভাবে ব্যর্থ হয়। এই
সীমাবদ্ধতা API কলারের সরবরাহ করা টুলগুলোর ক্ষেত্রে প্রযোজ্য, Qoder
CLI নিজে ব্যবহার করতে পারে এমন কোনো অভ্যন্তরীণ টুলের ক্ষেত্রে নয়। একটি HTTP কী থাকলেই যে প্রতিটি মডেল টুল সমর্থন করবে, তার
নিশ্চয়তা নেই; মডেলের স্বাভাবিক সক্ষমতা যাচাই এখনও প্রযোজ্য।

ব্রাউজার OAuth কেবল তখনই উপলভ্য, যখন অ্যাডমিনিস্ট্রেটর পাঁচটি সেটিংই কনফিগার করেন:
`QODER_OAUTH_AUTHORIZE_URL`, `QODER_OAUTH_TOKEN_URL`, `QODER_OAUTH_USERINFO_URL`,
`QODER_OAUTH_CLIENT_ID`, এবং `QODER_OAUTH_CLIENT_SECRET`। এগুলোর ডিফল্ট মান খালি; একটি
কনফিগার না করা ইনস্টলেশনে ব্রাউজার সাইন-ইন ফ্লো প্রস্তুত আছে ধরে নেওয়ার পরিবর্তে
সমর্থিত ক্রেডেনশিয়াল ইমপোর্ট ব্যবহার করা উচিত।

## সাধারণ প্রশ্নাবলি

### "OmniRoute ব্যবহার করতে কি আমাকে অর্থ প্রদান করতে হবে?"

**না!** OmniRoute বিনামূল্যের এবং ওপেন সোর্স। কোনো অর্থ প্রদান ছাড়াই আপনি বিনামূল্যের প্রদানকারী (Kiro, Pollinations) ব্যবহার করতে পারেন। আপনি অর্থপ্রদত্ত প্রদানকারী ব্যবহার করার সিদ্ধান্ত নিলেই কেবল অর্থ প্রদান করতে হবে।

### "কোন প্রদানকারী দিয়ে শুরু করা উচিত?"

**Kiro AI** দিয়ে শুরু করুন—এটি বিনামূল্যের, কোনো API key প্রয়োজন হয় না এবং Claude models ব্যবহারের সুযোগ দেয়। এরপর প্রয়োজন অনুযায়ী আরও প্রদানকারী যোগ করুন।

### "আমি কি একই সঙ্গে একাধিক প্রদানকারী ব্যবহার করতে পারি?"

**হ্যাঁ!** এটিই OmniRoute-এর মূল উদ্দেশ্য। একাধিক প্রদানকারী সংযুক্ত করুন এবং প্রতিটি অনুরোধের জন্য OmniRoute-কে সেরা প্রদানকারীটি বেছে নিতে দিতে `model: "auto"` ব্যবহার করুন।

### "কোনো প্রদানকারীর পরিষেবা বন্ধ হয়ে গেলে কী হবে?"

OmniRoute স্বয়ংক্রিয়ভাবে ব্যর্থ প্রদানকারীদের এড়িয়ে যায় এবং পরবর্তী প্রদানকারীকে চেষ্টা করে। আপনাকে কিছুই করতে হবে না।

### "কোনো প্রদানকারীর সংযোগ কীভাবে বিচ্ছিন্ন করব?"

Providers-এ যান → প্রদানকারীটিতে ক্লিক করুন → **Disconnect**-এ ক্লিক করুন।

### "আমি কি আমার বিদ্যমান API key ব্যবহার করতে পারি?"

**হ্যাঁ!** OpenAI, Anthropic, Google ইত্যাদির জন্য আপনার কাছে আগে থেকেই API key থাকলে, সেগুলো OmniRoute-এ ব্যবহার করতে পারেন। প্রদানকারী সংযুক্ত করার সময় শুধু সেগুলো পেস্ট করুন।
