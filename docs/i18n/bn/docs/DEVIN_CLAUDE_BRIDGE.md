`devin-cli-agentic` প্রকৃত Claude Code রানটাইমকে OmniRoute-এর স্থানীয় Anthropic
Messages এন্ডপয়েন্ট ব্যবহার করতে দেয়, অন্যদিকে অফিসিয়াল Devin CLI ACP stdio-এর মাধ্যমে
মডেল প্রতিক্রিয়া সরবরাহ করে। এটি বিদ্যমান Anthropic, Claude OAuth, Claude Web, বা
`devin-cli` প্রোভাইডারগুলো পরিবর্তন করে না।

ক্লায়েন্ট-নিয়ন্ত্রিত টুল কলের জন্য `devin-cli-agentic` (উপনাম `dva`)—Claude-ফরম্যাটের
টুল-সক্ষম প্রোভাইডার—এর মাধ্যমে রাউট করুন। লিগ্যাসি `devin-cli` (`dv`) ACP এক্সিকিউটরটি
শুধু-টেক্সট: এটি Devin-এর টুলবিহীন summarizer চালায় এবং টুল কল ফেরত দিতে পারে না। এর মডেল
মেটাডেটা সেই অনুযায়ী চিহ্নিত করা হয়েছে, যাতে টুল-আবশ্যক কম্বো রাউটিং এটিকে এড়িয়ে যায়।

> **বর্তমান অবস্থা: Claude Code `2.1.258`-এ পিন করা; অফলাইন ও লাইভ যাচাইকরণ সর্বশেষ
> `2.1.220`-এ রেকর্ড করা হয়েছে।** `2.1.220` পিনটি Devin CLI `3000.2.17` এবং
> `swe-1-7-lightning` মডেলের মাধ্যমে তিনটি বিচ্ছিন্ন দৃশ্যপট সম্পন্ন করেছে; সেই চূড়ান্ত লাইভ রান
> ক্লায়েন্ট-নিয়ন্ত্রিত `Read`, `Edit`, এবং `Bash` টার্ন, সফল `npm test` ফলাফল, প্রজেক্ট কমান্ড
> ও স্কিল আবিষ্কার, শুধু-Devin রাউটিং এবং Claude-এ শূন্য বহির্গামী ট্র্যাফিক প্রমাণ করেছে। এরপর পিনটি
> `2.1.258`-এ উন্নীত করা হয় (OmniRoute-এর Claude পরিচয় যে CLI প্রজন্মের ছদ্মবেশ ধারণ করে,
> এবং যে প্রথম লাইনে Fable 5.1 টিয়ার নেটিভভাবে অন্তর্ভুক্ত)। নতুন পিনে পিন করা বেস ইমেজের ওপর
> ইনস্টলেশন স্তর এবং `claude --version` যাচাই করা হয়েছে, এবং ব্রিজ ইউনিট স্যুট,
> `compose config` ও স্ট্যাটিক আইসোলেশন প্রমাণ সফল হয়েছে—কিন্তু অফলাইন মক দৃশ্যপট এবং লাইভ
> তিন-দৃশ্যপটের স্যুট এখনো পুনরায় চালানো হয়নি। এই পিনসহ ব্রিজের ওপর নির্ভর করার আগে সেগুলো
> পুনরায় চালান ("পিন করা টুল আপডেট করা" দেখুন)।

## আর্কিটেকচার

```text
Claude Code 2.1.258 (বিচ্ছিন্ন non-root Linux কনটেইনার)
  -> http://omniroute:20128/v1/messages
  -> devin-cli-agentic (Claude-ফরম্যাট, প্রমাণীকরণবিহীন প্রোভাইডার)
  -> devin acp --agent-type summarizer (অফিসিয়াল ACP stdio, কোনো Devin টুল নেই)
  -> নিবেদিত devin-auth ভলিউমে Devin অ্যাকাউন্ট
```

অফিসিয়াল CLI-এর ডিফল্ট ACP এজেন্ট নিজস্ব টুল চালাতে পারে, তাই এই ব্রিজ সেটি ব্যবহার করে না।
এটি নির্দিষ্ট `summarizer` ACP এজেন্ট চালু করে, যার অফিসিয়াল CLI মোডে কোনো টুল নেই, এবং
সিরিয়ালাইজ করা Anthropic অনুরোধকে একটি এক্সিকিউশন ট্রেস হিসেবে ফ্রেম করে। Claude-নিয়ন্ত্রিত
আরেকটি অ্যাকশনের প্রয়োজন হলে, প্রতিক্রিয়ায় অবশ্যই ঠিক একটি ক্লায়েন্ট টুল এনভেলপ থাকতে হবে।
কোনো প্রতিক্রিয়াকে সফল হিসেবে রিপোর্ট করার আগেই যেকোনো ACP `tool_call` বা
`tool_call_update` প্রত্যাখ্যান করা হয়।

`open-sse/executors/devin-agentic/serializer.ts`-এর সিরিয়ালাইজার `system`, `text`,
`tool_use`, `tool_result`, `thinking`, `redacted_thinking`, `tool_choice`, এবং Claude Code
সরবরাহ করা টুলগুলো সংরক্ষণ করে। ইমেজ এবং অজানা ব্লক স্পষ্টভাবে ব্যর্থ হয়। বড় টুল ফলাফলে
একটি দৃশ্যমান ছাঁটাই চিহ্ন ব্যবহার করা হয়।

পার্সারটি প্রতিটি মডেল টার্নে একটি স্বতন্ত্র `<tool>{...}</tool>` এনভেলপ গ্রহণ করে। এটি
অনুরোধের টুল তালিকার বিপরীতে নামটি পরীক্ষা করে, সেই টুলের JSON Schema অনুযায়ী আর্গুমেন্ট
যাচাই করে, মিশ্র বর্ণনা/অ্যাকশন প্রত্যাখ্যান করে এবং একটি সীমাবদ্ধ মেরামতের অনুমতি দেয়। এরপর
Claude Code ফলস্বরূপ Anthropic `tool_use` স্থানীয়ভাবে চালায় এবং `tool_result`-টি OmniRoute-এর
মাধ্যমে ফেরত পাঠায়।

## স্বয়ংক্রিয় রাউটিং

প্রোভাইডারটি ব্লক করা না থাকলে OmniRoute-এর `auto/*` ক্যান্ডিডেট পুলে যোগ্য হয়।
ক্যান্ডিডেট হিসেবে যোগ্যতা নির্বাচন নিশ্চিত করে না: কম্বোটির রাউটিং কৌশল (উদাহরণস্বরূপ,
last-known-good) অন্য কোনো প্রোভাইডারকে অগ্রাধিকার দিতে পারে। প্রতিটি অনুরোধ Devin-এর
মাধ্যমে পাঠানো আবশ্যক হলে `dva/<model>` বা Devin-প্রথম কম্বো ব্যবহার করুন।

## বিচ্ছিন্নতা এবং হুমকি মডেল

হোস্টের Claude ইনস্টলেশন, অ্যাকাউন্ট এবং কনফিগারেশন এই পরিধির বাইরে এবং নিষিদ্ধ হিসেবে
বিবেচিত। Compose সার্ভিসগুলো:

- UID/GID `10001:10001` হিসেবে চলে, যেখানে রয়েছে একটি শুধু-পঠনযোগ্য রুট ফাইলসিস্টেম, বাদ দেওয়া capability এবং
  `no-new-privileges`;
- একটি ব্যক্তিগত `/home/bridge`, একটি নিবেদিত Claude config volume, বিচ্ছিন্ন OmniRoute ডেটা
  এবং একটি পৃথক `devin-auth` volume ব্যবহার করে;
- শুধু নিষ্পত্তিযোগ্য `.sandbox` workspace/evidence মাউন্ট করে;
- হোস্টের home, Keychain, SSH, cloud credential বা Docker socket মাউন্ট করে না;
- সুস্পষ্ট environment তৈরি করে এবং Anthropic API/OAuth/routing variable সরিয়ে দেয়;
- শুধু একটি local-only key দিয়ে `http://omniroute:20128`-এ Claude Code inference পাঠায়।

অফলাইন প্রোফাইলটি একটি অভ্যন্তরীণ নেটওয়ার্ক ব্যবহার করে। লাইভ প্রোফাইলে OmniRoute শুধু
`network-guard`-এর মাধ্যমে অফিসিয়াল Devin endpoint-এ পৌঁছায়; সম্পর্কহীন destination প্রত্যাখ্যান করা হয়।
Claude Code-এর জন্য একটি পৃথক deny-all egress guard রয়েছে এবং এটি শুধু `NO_PROXY`-এর মাধ্যমে স্থানীয় OmniRoute
সার্ভিসে পৌঁছাতে পারে। Guard audit file শুধু সংশ্লিষ্ট guard process দ্বারা মাউন্ট করা হয়। স্ক্রিপ্টগুলো
token-মুক্ত evidence export করার আগে file ownership, mode, link count এবং প্রতিটি সিদ্ধান্ত যাচাই করে।

বিচ্ছিন্নতার প্রমাণটি স্বতন্ত্রভাবে চালান:

```bash
./scripts/devin-bridge/verify-anthropic-isolation
```

এটি topology, named mount, non-root/read-only setting, সুস্পষ্ট local routing,
সংবেদনশীল environment variable-এর অনুপস্থিতি, Docker socket-এর অনুপস্থিতি, `api.anthropic.com`
ও `claude.ai`-এ অবরুদ্ধ access, শুধু Devin provider নির্বাচন এবং ACP backend অনুপলভ্য হলে
সুস্পষ্ট failure যাচাই করে।

## প্রথমবারের সেটআপ এবং স্বাভাবিক ব্যবহার

Pinned image তৈরি করুন:

```bash
./scripts/devin-bridge/build
```

শুধু বিচ্ছিন্ন Devin volume-কে authenticate করুন:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/login-devin
```

Login command-টি remote/container environment-এর জন্য নির্ধারিত অফিসিয়াল manual-token flow
ব্যবহার করে। মানটি সরাসরি CLI prompt-এ প্রবেশ করানো হয়; এটি process argument হিসেবে পাঠানো হয় না,
Git-এ লেখা হয় না বা হোস্ট থেকে কপি করা হয় না।

বিচ্ছিন্ন Claude Code runtime চালু করুন:

```bash
./scripts/devin-bridge/launch
```

Containerized Claude Code শুরু করার আগে `launch` বিচ্ছিন্নতা, Devin authentication এবং model discovery
পুনরায় পরীক্ষা করে। এটি কখনোই হোস্টের Claude executable চালায় না। Model alias
`.env.devin-bridge`-এ সেট করা যায়; কনফিগার করা প্রতিটি মানে অবশ্যই
`devin-cli-agentic/` prefix বজায় রাখতে হবে।

## যাচাইকরণ command

পুনরুৎপাদনযোগ্য offline path-এর জন্য কোনো Devin account প্রয়োজন হয় না এবং এতে runtime Internet নেই:

```bash
./scripts/devin-bridge/test-unit
./scripts/devin-bridge/test-contract
./scripts/devin-bridge/test-e2e-mock
./scripts/devin-bridge/verify-anthropic-isolation
```

Authenticated opt-in live path হলো:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/test-live-devin
```

Live runner একসঙ্গে অনেক ACP session খোলা এড়াতে scenario-গুলোর মধ্যে অপেক্ষা করে এবং
পাঠ্যভিত্তিক দাবি বিশ্বাস করার পরিবর্তে structured Claude stream event যাচাই করে। এর তিনটি
scenario প্রমাণ করে:

1. সরাসরি project read এবং defect analysis;
2. একটি বাস্তব `Edit`, client-owned `Bash` `npm test` এবং একটি terminal result;
3. `/bridge-check` ও `bridge-proof` discovery, project read, আরেকটি সফল
   client-owned `npm test` এবং কোনো pending work ছাড়াই completion।

চূড়ান্ত gate-টি Devin network audit-ও পরীক্ষা করে এবং Claude egress audit খালি থাকা
আবশ্যক করে।

## পিন করা টুল আপডেট করা

ইমেজটি `docker/devin-bridge/Dockerfile`-এ Node, Claude Code এবং Devin CLI-এর নির্দিষ্ট সংস্করণ পিন করে। আপডেট করতে:

1. স্পষ্টভাবে উল্লেখ করা সংস্করণগুলো পরিবর্তন করুন;
2. উভয় আর্কিটেকচার-নির্দিষ্ট Devin আর্কাইভ চেকসামকে অফিসিয়াল
   আর্টিফ্যাক্টের মান দিয়ে প্রতিস্থাপন করুন;
3. পুনরায় বিল্ড করুন এবং প্রতিটি অফলাইন যাচাইকরণ কমান্ড চালান;
4. ইমেজের ভেতরের সংস্করণগুলো নিশ্চিত করুন;
5. প্রমাণীকৃত তিন-দৃশ্যকল্পের লাইভ স্যুটটি পুনরায় চালান।

হোস্টে কোনো CLI-ই গ্লোবালি ইনস্টল করবেন না বা চেকসাম যাচাইকরণকে কোনো
যাচাইবিহীন ডাউনলোড দিয়ে প্রতিস্থাপন করবেন না।

## রোগনির্ণয় এবং পরিষ্কারকরণ

- `docker compose -f docker/devin-bridge/compose.yml --profile offline logs omniroute`
  স্থানীয় রাউটিং এবং সংবেদনশীল তথ্য অপসারিত এক্সিকিউটর ত্রুটি দেখায়।
- `.sandbox/evidence/mock-acp.jsonl` নির্ধারিত মক ACP অ্যাকশন রেকর্ড করে।
- `.sandbox/evidence/claude-stream.jsonl` প্রকৃত Claude Code অফলাইন রান রেকর্ড করে।
- `.sandbox/evidence/live-*.jsonl` যাচাইকৃত তিনটি লাইভ স্ট্রিম রেকর্ড করে।
- `.sandbox/evidence/egress.jsonl` এবং `.sandbox/evidence/claude-egress.jsonl` হলো গার্ড
  অডিটের যাচাইকৃত, টোকেন-মুক্ত কপি।

লগইন/কনফিগ ভলিউম সংরক্ষণ করে ব্রিজের মালিকানাধীন কনটেইনার এবং নেটওয়ার্ক বন্ধ করুন:

```bash
./scripts/devin-bridge/clean
```

নামযুক্ত ভলিউমসহ ব্রিজের মালিকানাধীন সম্পূর্ণ পরিবেশ সরিয়ে ফেলুন:

```bash
./scripts/devin-bridge/clean --all
```

## সীমাবদ্ধতা

- ব্রিজটি নির্দিষ্ট নো-টুলস `summarizer` ভূমিকার ওপর নির্ভর করে, কারণ Devin CLI `3000.2.17`
  কোনো নিরপেক্ষ নো-টুলস ACP এজেন্ট প্রকাশ করে না। অ্যাডাপ্টারটি সারাংশ-আকৃতির
  মধ্যবর্তী প্রতিক্রিয়াগুলোর জন্য ক্ষতিপূরণ দেয়, তবে একটি সীমাবদ্ধ মেরামত তবুও স্পষ্টভাবে ব্যর্থ হতে পারে।
- লাইভ ACP কলগুলো ক্ষণস্থায়ী `502`/`504` প্রতিক্রিয়া দিতে পারে। হার্নেসটি দৃশ্যকল্পগুলোর মধ্যে
  বিরতি রাখে; স্থায়ী ব্যর্থতার ক্ষেত্রে এটি বন্ধই থাকে এবং কখনো অন্য কোনো প্রোভাইডার নির্বাচন করে না।
- প্রতিটি Anthropic অনুরোধ থেকে ACP প্রসঙ্গ পুনর্গঠন করা হয়; কোনো প্রসেস/সেশন
  অ্যাফিনিটি নেই।
- প্রতিটি মডেল প্রতিক্রিয়ায় একটি টুল কল সমর্থিত; সমান্তরাল কল প্রত্যাখ্যান করা হয়।
- ইমেজ স্পষ্টভাবে অসমর্থিত। ভিশন, থিংকিং আউটপুট, প্রচেষ্টা নিয়ন্ত্রণ এবং 1M
  কনটেক্সট উইন্ডোর সমর্থন ঘোষণা করা হয় না।
- SSE বৈধ Anthropic লাইফসাইকেল ইভেন্ট ব্যবহার করে, তবে সীমাবদ্ধ ACP টার্নটি
  সংগ্রহ করার পরে সেগুলো নির্গত হয়; ACP চাঙ্কগুলো ক্রমবর্ধমানভাবে ফরোয়ার্ড করা হয় না।
