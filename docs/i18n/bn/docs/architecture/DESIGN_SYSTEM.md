## 1. জিনিসগুলো কোথায় থাকে

- **কিট।** `packages/ui-kit/src` হলো আপস্ট্রিম `src/`-এর বাইট-ফর-বাইট কপি, যা `packages/ui-kit/UPSTREAM.md`-এ পিন করা কমিটে নেওয়া হয়েছে (এতে লাইসেন্স অনুমোদনও রেকর্ড করা আছে); `PATCHES.md` লোকাল প্যাচের তালিকা রাখে (কোনোটিই নেই)। এটি সোর্স হিসেবে ব্যবহৃত হয়, কোনো বিল্ড ছাড়াই: `next.config.mjs` এটি ট্রান্সপাইল করে, এবং `tsconfig.json` `@omniroute/ui-kit` → `packages/ui-kit/src` এবং `@omniroute/ui-kit/*` → `packages/ui-kit/src/*` ম্যাপ করে (`vitest.config.ts` এবং `vitest.mcp.config.ts`-এ একই অ্যালিয়াস আছে)। কিট কম্পোনেন্ট তার সাবপাথ দিয়ে ইমপোর্ট করুন (`@omniroute/ui-kit/table`, `@omniroute/ui-kit/page-header`…), কখনোই `@omniroute/ui-kit` ব্যারেলের মাধ্যমে নয়: ব্যারেল প্রতিটি ইমপোর্টারে সব কম্পোনেন্ট (ডেট পিকারসহ) টেনে আনে। কিট স্টাইলশিট `src/app/globals.css` এর মাধ্যমে আসে (`@import "../../packages/ui-kit/src/ci-ui.css"`)।
- **টোকেন।** `packages/ui-kit/src/ci-tokens.css` `--ci-*` টোকেনগুলো ডিক্লেয়ার করে; `src/app/globals.css` সেগুলোকে লেগেসি OmniRoute নামগুলোর সাথে ব্রিজ করে (`--color-*`, `--radius-*`, `--font-sans`/`--font-mono`, `--table-*`, `--orch-status-*`, `--color-fd-*`), যাতে বিদ্যমান `var(--color-*)` রিড এবং Tailwind ইউটিলিটিগুলো কাজ করতে থাকে। নতুন কোডে Tailwind ইউটিলিটি (`bg-surface`, `text-text-muted`, `border-border`, `text-success`, `bg-success-bg`, `bg-chart-1`…) বা কিট ক্লাস ব্যবহার হয় — কখনোই হেক্স ভ্যালু নয় (`tests/unit/design-kit-bridge.test.ts` ব্রিজটি এনফোর্স করে)। `text-primary` `--text-color-primary` এর মাধ্যমে `--color-primary-ink`-এ রিজলভ হয় (লাইটে lime-800, ডার্কে lime অ্যাকসেন্ট), তাই প্রাইমারি টেক্সট পঠনযোগ্য থাকে, অথচ `bg-primary`/`border-primary` lime সারফেস ধরে রাখে। চার্ট সিরিজ `--color-chart-1` … `--color-chart-5` ব্যবহার করে।
- **থিম।** `<html className="ci-theme">` (`src/app/layout.tsx`) ডকুমেন্টকে কিট থিমে অপ্ট-ইন করে। প্রেফারেন্স হলো `light`, `dark` অথবা `system` (`THEME_CONFIG.defaultTheme = "system"` `src/shared/constants/appConfig.ts`-এ; `system` `prefers-color-scheme` অনুসরণ করে)। `src/store/themeStore.ts`-এর `applyTheme()` (যা `src/app/layout.tsx`-এর ইনলাইন বুটস্ট্র্যাপ স্ক্রিপ্ট দ্বারা মিরর করা, এবং হাইড্রেশনের আগে চলে) `data-theme="dark"|"light"` সেট করে এবং `<html>`-এ `.dark` ক্লাস একসাথে টগল করে। কিটের ডার্ক টোকেন সেট `data-theme="dark"`-এ কি-ড (`packages/ui-kit/src/ci-tokens.css`); OmniRoute-এর নিজস্ব ডার্ক ওভাররাইড (`globals.css`-এর `.dark` ব্লক) এবং লেগেসি Tailwind `dark:` ইউটিলিটিগুলো `.dark` ক্লাসে কি-ড। কোনো অ্যাকসেন্ট কালার প্রিসেট নেই: অ্যাকসেন্ট সবসময় কিট থেকে আসে, এবং পুরোনো বিল্ড থেকে পার্সিস্ট করা প্রিসেট স্টোর লোডের সময় বাদ পড়ে যায়।
- **কম্পোনেন্ট (অ্যাডাপ্টার)।** `src/shared/components/index.tsx` OmniRoute কম্পোনেন্ট API বজায় রাখে (একই নাম, ডিফল্ট এক্সপোর্ট ও প্রপস), আর এর পেছনের প্রিমিটিভগুলো কিটের উপর অ্যাডাপ্টার: ফর্ম (`Button`, `Input`, `Textarea`, `Checkbox`, `Select`, `Toggle`, `Badge`, `Card`), ওভারলে ও ফিডব্যাক (`Modal`/`ConfirmModal`, `Tooltip`/`InfoTooltip`, `NotificationToast`, `EmptyState`, `Loading`), স্ট্রাকচার (`Collapsible`, `CollapsibleSection`, `SegmentedControl`, `Breadcrumbs`, `Avatar`) এবং টেবিল (`DataTable`, `FilterBar`, `ColumnToggle`, `FilterPills`, `PresetSlider`)। একটি অ্যাডাপ্টার কিট কম্পোনেন্ট সাবপাথ দিয়ে ইমপোর্ট করে এবং লেগেসি প্রপসগুলো তার উপর ম্যাপ করে — উদাহরণস্বরূপ `Button variant="primary"` হলো কিটের `default` বাটন (`--ci-button-primary-*`: লাইটে ইনভার্স সারফেস, ডার্কে `--ci-color-accent-foreground` ইংকসহ অ্যাকসেন্ট), `danger` হলো `destructive`, আর `warning` হলো `outline` সাথে `.ci-button--warning` এক্সটেনশন। `globals.css`-এর শেষের `.ci-button--warning` ও `.ci-badge[data-tone]` রুলগুলো (`@layer components`) কিট ক্লাসের উপর OmniRoute-এর এক্সটেনশন। `tests/unit/ui/adapters/*.test.tsx` প্রতিটি অ্যাডাপ্টার পিন করে।
- **শেল।** `src/app/(dashboard)/layout.tsx` `DashboardLayout` রেন্ডার করে, যা `src/shared/components/layouts/DashboardShell.tsx` রেন্ডার করে: কিটের `SidebarProvider` / `Sidebar` / `SidebarInset` (`packages/ui-kit/src/sidebar.tsx`), সাথে OmniRoute-এর নেভিগেশন লজিক `src/shared/components/Sidebar.tsx`-এ। `#main-content`-এ যাওয়ার একটি "skip to content" লিংক প্রথম ফোকাসযোগ্য এলিমেন্ট। `src/shared/components/Header.tsx`-এ কিটের `SidebarTrigger` (শেলের একমাত্র সাইডবার টগল), Keak `ProductSwitcher` এবং কমান্ড-প্যালেট ওপেনার আছে; এটি রুট টাইটেল শুধু তখনই দেখায় যখন `#main-content`-এর ভেতরে কোনো কিট `PageHeader` (`.ci-page-header`) মাউন্ট করা নেই, যাতে নিজস্ব `PageHeader` থাকা পেজে একটি মাত্র `h1` থাকে। `src/shared/components/CommandPalette.tsx` একটি কিট `Dialog`।
- **আইকন।** `<Icon name="material_name">` (`src/shared/components/Icon.tsx`) নামটি (স্ক্রিনগুলোর ব্যবহৃত Material Symbols ভোকাবুলারি) `ICON_MAP` (`src/shared/constants/iconMap.ts`) এর মাধ্যমে একটি Lucide গ্লিফে রিজলভ করে। Material Symbols ফন্ট ও প্যাকেজ আর নেই: ম্যাপে অনুপস্থিত নাম একটি নিরপেক্ষ প্লেসহোল্ডার গ্লিফ রেন্ডার করে (`data-icon-missing="true"`) এবং প্রোডাকশনের বাইরে কনসোল ওয়ার্নিং লগ করে। `npm run gen:icon-map` ব্যবহৃত নামগুলোর মধ্যে ম্যাপে অনুপস্থিতগুলো প্রিন্ট করে (`tests/unit/icon-map-coverage.test.ts` Lucide আইকন ছাড়া যেকোনো নামে ফেইল করে; `tests/unit/icon-map-object-values.test.ts` লুকআপ অবজেক্টে সংরক্ষিত নামগুলো কভার করে); `scripts/dev/codemod-material-icons.mjs <dir|file>... [--write]` লিটারেল `<span className="material-symbols-outlined">` স্প্যানগুলোকে `<Icon>`-এ রিরাইট করে।
- **ব্র্যান্ড।** `src/shared/components/OmniRouteLogo.tsx` কিটকে র্যাপ করে: ডিফল্ট এক্সপোর্ট `OmniRouteLogo` `ProductIcon product="omniroute" variant="glyph"` রেন্ডার করে (ইনলাইন SVG, `basePath`-সেফ) এবং `OmniRouteLockup` `ProductLockup product="omniroute"` রেন্ডার করে (অ্যাক্সেসিবল নাম "Keak OmniRoute") অথবা, হোয়াইট-লেবেল অপারেটরদের জন্য, তাদের নিজস্ব `name`/`logoSrc`। প্রোডাক্ট-সুইচার ডেস্টিনেশনগুলো `src/shared/constants/keakProducts.ts`-এ থাকে (`KEAK_PRODUCT_LINKS`, `KEAK_ACTIVE_PRODUCT`)। স্ট্যান্ডঅ্যালোন স্ক্রিনগুলো — `src/app/login/page.tsx`, `src/app/status/page.tsx`, `src/app/maintenance/page.tsx`, `src/app/offline/page.tsx`, `src/app/not-found.tsx` এবং `src/shared/components/ErrorPageScaffold.tsx` — লকআপটি দেখায়; `tests/unit/brand-pages-static.test.ts` এটি পাহারা দেয়।

## ২. নিয়মাবলি

1. টোকেন, কখনোই লিটারাল নয়। ইচ্ছাকৃতভাবে রাখা ব্যতিক্রমগুলো: সর্বদা-ডার্ক কনসোল টার্মিনাল,
   `STATUS_HEX` (`src/shared/constants/statusColors.ts`) এর মাধ্যমে ReactFlow SVG স্ট্রোক, এবং
   ক্যাটাগরিক্যাল প্যালেট `STRATEGY_COLORS`
   (`src/app/(dashboard)/dashboard/combos/live/nodes/StrategyNode.tsx`) ও
   `LAYER_COLORS` (`src/app/(dashboard)/dashboard/compression/studio/nodes/EngineNode.tsx`)।
2. `packages/ui-kit/src` কখনো হাতে প্যাচ করবেন না: `scripts/dev/sync-ui-kit.sh <commit>` দিয়ে সিঙ্ক
   করুন; প্রি-কমিট গেট `npm run check:ui-kit-snapshot` (`.husky/pre-commit`) পিন করা আপস্ট্রিম কমিট
   থেকে এক বাইট ভিন্ন হলেই ব্যর্থ হয় (আপস্ট্রিম ক্লোন, `UI_KIT_CLONE` বা
   `_references/cheaper-inference-ui-kit`, অনুপস্থিত থাকলে এটি সতর্কতা সহ এড়িয়ে যায়)। কিটে কিছু না
   থাকলে, অ্যাডাপ্টারে বা স্ক্রিনে তার ওয়ার্কঅ্যারাউন্ড করুন এবং আপস্ট্রিমে সেটির জন্য অনুরোধ করুন।
3. কিটের টেক্সট ডিফল্ট ইংরেজি (`label = "Loading"`, `loadingLabel = "Loading table"`…) — যখনই কোনো
   কিট কম্পোনেন্ট টেক্সট রেন্ডার করে, `useTranslations(...)` থেকে অনূদিত স্ট্রিং পাঠান।
4. Tailwind ইউটিলিটিগুলো কিট কম্পোনেন্ট ক্লাসের উপর জেতে (কিটটি
   `@layer theme, base, components, utilities` ঘোষণা করে এবং এর নিয়মগুলো `components`-এ থাকে) —
   স্পেসিং ও লেআউটের জন্য ইউটিলিটি ব্যবহার করুন, কিট কম্পোনেন্ট পুনরায় রঙ করার জন্য নয়।
5. হেডিং: পেজ ও সেকশন শিরোনামের জন্য `.ci-heading` (Inter, ট্র্যাকিং ছাড়া);
   `.ci-dashboard-display` (Instrument Serif) শুধুমাত্র বড়, বিক্ষিপ্ত ডিসপ্লে টেক্সটের জন্য, যেমন
   এরর-পেজের স্ট্যাটাস কোড।
6. `tests/unit/dashboard-kit-sweep.test.ts` কিট অংগীকরণ পাহারা দেয়: `src/app` বা
   `src/shared/components`-এর নিচে কোনো Material লিগেচার স্প্যান নেই; ড্যাশবোর্ড ট্রিতে
   (`src/app/(dashboard)` এবং `src/shared/components`) কোনো কাঁচা `<select>`, `<textarea>` বা
   `<table>` নেই এবং তালিকাভুক্ত ব্যতিক্রমগুলোর (`Select` অ্যাডাপ্টারের নেটিভ ব্রাঞ্চ,
   `RequestLoggerDetail`) বাইরে কোনো হাতে-তৈরি `role="dialog"` নেই; সেখানে প্রতিটি কাঁচা `<button>`
   বা `<input>`-এর জন্য `kit-exception:` (কারণসহ) ধারণকারী একটি কমেন্ট প্রয়োজন যা তার সর্বোচ্চ
   ৩ লাইন উপরে শেষ হয়; প্যালেট হিউ এবং `dark:` ভ্যারিয়েন্ট শুধুমাত্র টেস্টে তালিকাভুক্ত ফাইলগুলোতে।
7. PR-এর আগে উভয় থিম এবং 390 px ভিউপোর্ট যাচাই করুন (স্ক্রিনশট); `tests/e2e/a11y.spec.ts` axe চালায়।

## ৩. স্ক্রিন যোগ করা

1. কিট `PageHeader` (`@omniroute/ui-kit/page-header`, ড্যাশবোর্ডের ভিতরে `compact`) দিয়ে পেজটি শুরু
   করুন — শিরোনাম, বিবরণ এবং `actions`। শেল হেডার তখন তার নিজের শিরোনাম বাদ দেয়।
2. `@/shared/components` (অ্যাডাপ্টারগুলো) থেকে কন্ট্রোল তৈরি করুন এবং যেখানে কোনো অ্যাডাপ্টার নেই
   সেখানে সাবপাথ দিয়ে কিট কম্পোনেন্ট ব্যবহার করুন (`Table`/`TableScrollArea`/`DataTableShell`,
   `Field`, `Alert`, `Tabs`, `RadioGroup`, `Slider`…)।
3. আইকন: `<Icon name="…" />`। নতুন নাম শব্দার্থগতভাবে মানানসই Lucide কম্পোনেন্টসহ `ICON_MAP`-এ
   যায়; `npm run gen:icon-map` এখনো অনুপস্থিত নামগুলো তালিকাভুক্ত করে।
4. রং: সেমান্টিক ইউটিলিটি (`text-success`, `bg-warning-bg`, `border-border`…) এবং চার্ট সিরিজের জন্য
   `var(--color-chart-N)`; কোনো হেক্স মান নেই এবং এমন কোনো `dark:` ভ্যারিয়েন্ট নেই যা শুধুমাত্র
   একটি রং পুনরাবৃত্তি করে।
5. টেক্সট: প্রতিটি স্ট্রিং, কিট কম্পোনেন্টে আপনার পাঠানো লেবেলসহ, `useTranslations` থেকে আসে। নতুন
   কীগুলো `src/i18n/messages/en.json`, `pt-BR.json` এবং `vi.json`-এ যায় (ভিয়েতনামি প্যারিটি টেস্ট
   প্রতিটি ইংরেজি কী পিন করে); অন্যান্য লোকেল i18n সিঙ্ক দ্বারা পূরণ হয়।
6. PR-এর আগে গার্ডগুলো চালান: `tests/unit/dashboard-kit-sweep.test.ts`,
   `tests/unit/icon-map-coverage.test.ts`, `tests/unit/icon-map-object-values.test.ts`,
   `npm run check:dashboard-typecheck` (একমাত্র চেক যা `iconMap.ts`-এ ডুপ্লিকেট ইমপোর্ট ধরতে পারে),
   `npm run check:ui-icu`, এবং স্ক্রিনের নিজস্ব টেস্টগুলো।

## 4. অ্যাডাপ্টার যোগ করা বা পরিবর্তন করা

1. `src/shared/components/index.tsx`-এর পাবলিক API অক্ষত রাখুন: একই এক্সপোর্ট নাম, ডিফল্ট এক্সপোর্ট এবং গৃহীত প্রপস। অ্যাডাপ্টারের ভেতরে লেগ্যাসি প্রপসগুলোকে কিটে ম্যাপ করুন (দেখুন `Button.tsx`: `VARIANT_TO_KIT`, `SIZE_TO_KIT`)।
2. সাবপাথ দিয়ে কিট ইমপোর্ট করুন (`@omniroute/ui-kit/<component>`)।
3. কিটের ঘাটতির ওয়ার্কঅ্যারাউন্ডগুলো অ্যাডাপ্টারে থাকে (অথবা `globals.css`-এর `@layer components`-এ যখন সমাধানটি স্টাইল সংক্রান্ত), কখনই `packages/ui-kit/src`-এ নয়।
4. `tests/unit/ui/adapters/<name>.test.tsx` যোগ করুন বা আপডেট করুন। অনেক কলার থাকা অ্যাডাপ্টারের জন্য, পরিবর্তনের আগে ও পরে রেন্ডার করা মার্কআপ তুলনা করুন — প্যাডিং বা র্যাপার পরিবর্তন প্রতিটি স্ক্রিনে ছড়িয়ে পড়ে।

## 5. কিট আপডেট করা

`scripts/dev/sync-ui-kit.sh <commit> [clone]` ওই কমিটের আপস্ট্রিম `src/` কে `packages/ui-kit/src`-এ কপি করে এবং একমাত্র অনুমোদিত রূপান্তর প্রয়োগ করে (এটি রিলেটিভ ইমপোর্ট থেকে `.js` সাফিক্স বাদ দেয়)। তারপর: `git diff packages/ui-kit` পর্যালোচনা করুন, উভয় থিমে প্রোভাইডার, সেটিংস, কম্বো, ইউসেজ এবং এন্ডপয়েন্ট অংশে ভিজ্যুয়াল পাস করুন, `npm run check:ui-kit-snapshot` এবং `npm run test:vitest:ui` চালান, এবং আপস্ট্রিম চেঞ্জলগ সহ PR ওপেন করুন।
