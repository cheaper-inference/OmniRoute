`@omniroute/opencode-plugin-v2` আপনার সম্পূর্ণ OmniRoute ক্যাটালগ — মডেল, কম্বো এবং
অটো-কম্বো — প্রদর্শনের নাম, মূল্য এবং ফ্রি-টিয়ার বাজেটসহ OpenCode v2-এর মডেল পিকারে
যুক্ত করে।

এটি `@omniroute/opencode-plugin` থেকে আলাদা একটি প্যাকেজ, কারণ OpenCode v1 এবং v2 ভিন্ন
কন্ট্রাক্টের মাধ্যমে প্লাগইন লোড করে। আপনার OpenCode-এর মেজর সংস্করণের সঙ্গে মেলে এমনটি
বেছে নিন; এদের মধ্যে কিছুই শেয়ার করা হয় না, তাই একটি আপগ্রেড করলে অন্যটি আপগ্রেড করতে হয় না।

## প্রয়োজনীয়তা

- OpenCode v2।
- অ্যাক্সেসযোগ্য একটি OmniRoute গেটওয়ে (ডিফল্টভাবে `http://localhost:20128`)।
- Node.js 22 বা 24।

## ইনস্টলেশন

`opencode.json`-এ প্লাগইনটি যোগ করুন:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

এরপর মডেলগুলো `omniroute/<provider>/<model>` হিসেবে দেখা যাবে; `providerId` ওই প্রিফিক্স এবং
যে ইন্টিগ্রেশনের অধীনে OpenCode ক্রেডেনশিয়াল সংরক্ষণ করে, তার আইডি নির্ধারণ করে।

## ক্রেডেনশিয়াল

প্লাগইনটি নিচের তিনটি স্থানে এই ক্রমে গেটওয়ে কী খোঁজে:

1. **OpenCode-এ আপনার সংযুক্ত করা ক্রেডেনশিয়াল।** প্লাগইনটি একটি ইন্টিগ্রেশন নিবন্ধন করে, ফলে
   OpenCode-এর নিজস্ব অথেন্টিকেশন ফ্লো কীটি সংরক্ষণ করতে পারে। `opencode.json`-এ কিছুই লেখা হয় না — এটিই অগ্রাধিকার দিন।
2. প্রতি-প্রজেক্ট ওভাররাইডের জন্য প্লাগইন অপশনের `apiKey`। এতে কীটি এমন একটি ফাইলে রাখা হয়
   যা আপনি কমিট করে ফেলতে পারেন।
3. এনভায়রনমেন্টের `OMNIROUTE_API_KEY`।

এই তিনটির কোনোটিই না থাকলে ক্যাটালগটি খালি থাকে এবং নীরবে একটি খালি পিকার দেখানোর পরিবর্তে
প্লাগইনটি স্টার্টআপের সময় একবার তা জানায়।

### ম্যানেজমেন্ট টোকেনটি একটি আলাদা কী

কম্বো, প্রোভাইডারের স্বাস্থ্য এবং সমৃদ্ধকরণের তথ্য (প্রদর্শনের নাম, মূল্য, ফ্রি-টিয়ার বাজেট)
গেটওয়ের `/api/*` এন্ডপয়েন্ট থেকে আসে, যেগুলো অধিকাংশ ডিপ্লয়মেন্টে ইনফারেন্স কীর পরিবর্তে একটি
**ম্যানেজমেন্ট** টোকেন দিয়ে সুরক্ষিত থাকে:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<management read token>"
}
```

সেট না করা থাকলে `managementReadToken`, `apiKey`-তে ফলব্যাক করে। কোনো গেটওয়ে সেই ফলব্যাক
প্রত্যাখ্যান করলে ক্যাটালগ তবুও প্রকাশিত হয়, তবে প্রদর্শনের নামের পরিবর্তে অপরিবর্তিত মডেল আইডি থাকে,
ক্যানোনিক্যাল অ্যালিয়াস ডিডুপ্লিকেশন, মূল্য এবং কম্বো থাকে না। এমনটি ঘটলে প্লাগইনটি প্রতিটি এন্ডপয়েন্টের
জন্য একবার সতর্ক করে এবং এন্ডপয়েন্ট ও কী হারিয়েছে তা উল্লেখ করে — ফলে অবনমিত পিকার কখনোই রহস্যজনক থাকে না।

| চাবি                             | ডিফল্ট                                      | নোট                                                                                                                                                                                                                                                                                                                                                                           |
| -------------------------------- | ------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `providerId`                     | `"omniroute"`                               | প্রদানকারী আইডি, ইন্টিগ্রেশন আইডি, এবং উপসর্গ মডেলের অধীনে প্রদর্শিত হয়                                                                                                                                                                                                                                                                                                      |
| `baseURL`                        | প্রয়োজনীয়                                 | গেটওয়ে রুট, শুধুমাত্র `http(s)` ; যেখানে প্রয়োজন সেখানে `/v1` প্রত্যয় যোগ করা হয়                                                                                                                                                                                                                                                                                          |
| `apiKey`                         | সংযুক্ত শংসাপত্র, তারপর `OMNIROUTE_API_KEY` | `/v1/*` এর জন্য চ্যাট কী                                                                                                                                                                                                                                                                                                                                                      |
| `managementReadToken`            | `apiKey` ফিরে পড়ে                          | সাধারণত `/api/*` — এর জন্য কী** না** একই এক                                                                                                                                                                                                                                                                                                                                   |
| `displayName`                    | `"OmniRoute"`                               | পিকারে প্রদানকারীর নাম                                                                                                                                                                                                                                                                                                                                                        |
| `timeoutMs`                      | `10000`                                     | প্রতি-এন্ডপয়েন্ট ফেচ টাইমআউট (অটো-কম্বো 5s ব্যবহার করে)                                                                                                                                                                                                                                                                                                                      |
| `modelCacheTtlMs`                | `300000`                                    | ক্যাটালগ ক্যাশে TTL; একটি ডিস্ক স্ন্যাপশট ঠান্ডা শুরু গরম                                                                                                                                                                                                                                                                                                                     |
| `timeouts`                       | `timeoutMs` ফিরে পড়ে                       | ms-এ প্রতি-এন্ডপয়েন্ট বাজেট: `models`, `combos`, `autoCombos`, `enrichment`                                                                                                                                                                                                                                                                                                  |
| `enrichment`                     | `true`                                      | নাম, মূল্য এবং মুক্ত-স্তরের বাজেট আনুন                                                                                                                                                                                                                                                                                                                                        |
| `providerTag`                    | `true`                                      | ট্রেলিং এডিটর বন্ধনী টগল করুন: `Provider - Model (Editor)`। প্রদানকারী (মডেল পরিবেশনকারী রুট) সর্বদা দেখানো হয়; সম্পাদক (যিনি মডেল তৈরি করেছেন) শুধুমাত্র বন্ধনীতে উপস্থিত হয়। উদাহরণ: `Openrouter - MoonshotAI: Kimi K 3.1 Pro` -> `Openrouter - Kimi K 3.1 Pro (MoonshotAI)`। সম্পাদক এবং প্রদানকারী একটি নাম শেয়ার করলে বাদ দেওয়া হয়। এটি ফেলে দিতে `false` সেট করুন। |
| `usableOnly`                     | `false`                                     | শুধুমাত্র প্রদানকারীদের গেটওয়ে রিপোর্টগুলি বিধান হিসাবে রাখুন৷                                                                                                                                                                                                                                                                                                               |
| `combosSource`                   | `"api"`                                     | `"models"` `/api/combos` এড়িয়ে যায় এবং `/v1/models` কম্বো সারি প্রকাশ করে; সদস্য-স্তরের ফিল্টার `"api"` রাখে                                                                                                                                                                                                                                                               |
| `showcasePerOwner`               | `10`                                        | ডিফল্ট-ভিউ এন্ট্রি প্রদানকারী প্রতি রাখা                                                                                                                                                                                                                                                                                                                                      |
| `freshPerOwner`                  | `10`                                        | ডিফল্ট-দেখুন তাজা এন্ট্রি প্রতি প্রদানকারী রাখা                                                                                                                                                                                                                                                                                                                               |
| `freshWindowDays`                | `90`                                        | তাজা শাখার জন্য দিনের মধ্যে সতেজতা উইন্ডো                                                                                                                                                                                                                                                                                                                                     |
| `usageMemory`                    | `true`                                      | 30-দিনের ব্যবহার বিশ্লেষণ দ্বারা নামকৃত স্ট্যাটিকলি বাদ দেওয়া এন্ট্রিগুলি পুনরুদ্ধার করুন (একটি ব্যবস্থাপনা টোকেন প্রয়োজন)                                                                                                                                                                                                                                                  |
| `visibleModels` / `hiddenModels` | `[]`                                        | সঠিক-বা-প্রত্যয় অনুমোদিত তালিকা; জয় অস্বীকার করা; `*` সম্পূর্ণ ক্যাটালগ প্রকাশ করে (অন্যান্য ফিল্টার এখনও প্রযোজ্য)                                                                                                                                                                                                                                                         |
| `geminiSanitization`             | `true`                                      | টুল স্কিমা থেকে Gemini প্রত্যাখ্যান করে JSON-Schema কীওয়ার্ডগুলি সরিয়ে ফেলুন (`$ref` টুলগুলিকে অস্পর্শিত ফরওয়ার্ড করা হয়েছে)                                                                                                                                                                                                                                              |
| `apiFormat.allowAnthropic`       | `false`                                     | Anthropic API ব্লকের মাধ্যমে অনুমোদিত তালিকাভুক্ত আইডি রুট করুন                                                                                                                                                                                                                                                                                                               |
| `apiFormat.anthropicModels`      | `[]`                                        | সম্পূর্ণ মডেল আইডি Anthropic তে রাউট করা হয়েছে                                                                                                                                                                                                                                                                                                                               |
| `logLevel` / `startupDebug`      | `warn` / `false`                            | লগার শব্দচয়ন                                                                                                                                                                                                                                                                                                                                                                 |

ব্যবহার মেমরি ডিফল্টরূপে চালু আছে. একটি ব্যবস্থাপনা টোকেন ছাড়া এটি নিষ্ক্রিয় থাকে (একটি স্টার্টআপ বিজ্ঞপ্তি লগ করা হয়) এবং কিছুই পুনরুদ্ধার করা হয় না।

## কিভাবে ক্যাটালগ তাজা থাকে

ক্যাটালগটি অলসভাবে আনা হয় এবং `modelCacheTtlMs` জন্য ক্যাশে করা হয়, এবং একটি ডিস্ক স্ন্যাপশট সর্বশেষ পরিচিত ক্যাটালগটি উপলব্ধ রাখে যখন গেটওয়ে — পৌঁছানো যায় না এবং বিভ্রাটের জন্য আপনার সতেজতা ছাড়া আর কিছুই খরচ হয় না। তারা আসার সাথে সাথে মডেল এবং কম্বো প্রকাশিত হয়; স্বয়ংক্রিয়-কম্বোস, প্রদানকারীর তালিকা এবং সমৃদ্ধকরণ ওভারলে যখন তারা অবতরণ করে তখন ভাঁজ হয়ে যায়, তাই একটি ধীর শেষ বিন্দু পুরো পিকারকে জিম্মি করতে পারে না।

নামগুলি `Provider - Model[ (Editor)][ · budget][ (route)]` অনুসরণ করে : যখনই একটি আইডি বহন করে (একটি স্ল্যাশ-লেস আইডি উপসর্গ ছাড়াই রেন্ডার করে) তখনই প্রদানকারীকে দেখানো হয়, একটি অগ্রণী `🆓` বিনামূল্যে এন্ট্রি চিহ্নিত করে এবং তাদের মুক্ত-স্তরের বাজেট একটি `· 1M tokens/month` প্রত্যয় হিসাবে থাকে, একটি সুস্পষ্ট `Editor: Model` নামের সম্পাদক একটি trailing-এ চলে যায় এবং অন্য বন্ধনী থেকে নামটি সম্পাদনা করা হয়, একটি বিনামূল্যে আইকন ছাড়া `combo - <slug>` হিসাবে. একটি নাম ভাগ করে এমন দুটি এন্ট্রি একটি রুট প্রত্যয় — `(no-think)` — পায় যাতে তারা আলাদা থাকে। `providerTag` (ডিফল্ট `true`) ট্রেলিং এডিটর বন্ধনীকে টগল করে।

কোন ম্যানুয়াল রিফ্রেশ কমান্ড নেই: OpenCode v2 কমান্ড হল প্রম্পট টেমপ্লেট, কলব্যাক নয়, তাই একটি প্লাগইন একটি প্রকাশ করতে পারে না। রিফ্রেশ TTL অনুসরণ করে; হোস্টকে শুধুমাত্র তখনই পুনরায় লোড করতে বলা হয় যখন ক্যাটালগ বা ওভারলে প্রকৃতপক্ষে পরিবর্তিত হয়, প্রতি রিফ্রেশে একবারও নয়।

## Gemini-তে টুল কলিং

এই প্রোভাইডারের কোনো Gemini মডেলের জন্য পাঠানো টুল স্কিমায় `$schema` বা `additionalProperties` থাকলে Gemini পুরো অনুরোধটি প্রত্যাখ্যান করে এবং `400 INVALID_ARGUMENT` উত্তর দেয়। প্লাগইনটি সেইসব টুল স্কিমা থেকে ওই কীওয়ার্ডগুলো সরিয়ে দেয় এবং অন্য সব অনুরোধ অপরিবর্তিত রাখে। `$ref` থাকা কোনো টুলকে কিছু না সরিয়েই ফরওয়ার্ড করা হয়, কারণ রেফারেন্সটি সরালে স্কিমাটি প্রসারিত হয়ে "যেকোনো কিছু গ্রহণ করুন"-এ পরিণত হবে।
এটি বন্ধ করতে `"geminiSanitization": false` সেট করুন।

## সমস্যা সমাধান

| উপসর্গ                                         | কারণ                                                                                                                    |
| ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| পিকার কোন OmniRoute মডেল দেখায় না             | কোন কী সমাধান করা হয়নি (স্টার্টআপ সতর্কতা পরীক্ষা করুন), বা গেটওয়েটি পৌঁছানো যাচ্ছে না                                |
| কাঁচা মডেল আইডি, কোন কম্বোস, কোন মূল্য নেই     | ম্যানেজমেন্ট এন্ডপয়েন্ট টোকেন — সেট `managementReadToken` প্রত্যাখ্যান করেছে                                           |
| সংক্ষিপ্ত বা খালি `freeOnly` ক্যাটালগ          | কোন ব্যবস্থাপনা টোকেন বা একটি প্রত্যাখ্যান টোকেন — হোস্ট লগে রিফ্রেশ সারাংশ লাইন (`unmatched-free` গণনা) পড়ে না        |
| একটি সেশন `opencode-<id>/...` এ পিন করা হয়েছে | v1 প্লাগইন `opencode-<id>` প্রকাশ করেছে; v2 `<id>` বেয়ার প্রকাশ করে, তাই `<id>/...` অধীনে মডেলটি পুনরায় নির্বাচন করুন |

এনভায়রনমেন্ট ভেরিয়েবলগুলি অবশ্যই ওপেনকোড সার্ভার প্রক্রিয়ায় পৌঁছাতে হবে: যখন হোস্ট একটি পরিষেবা হিসাবে চলে, তখন `opencode models` চালিত শেল এবং সার্ভারের পরিবেশ ভিন্ন হয়, তাই সার্ভার যেখানে এটি পড়ে সেখানে কীটি রপ্তানি করুন৷
