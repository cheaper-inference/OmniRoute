`devin-cli-agentic` ବାସ୍ତବ Claude Code ରନ୍ଟାଇମ୍କୁ OmniRouteର ସ୍ଥାନୀୟ Anthropic
Messages ଏଣ୍ଡପଏଣ୍ଟ ବ୍ୟବହାର କରିବାକୁ ଦିଏ, ଯେତେବେଳେ ଆଧିକାରିକ Devin CLI ACP stdio ମାଧ୍ୟମରେ ମଡେଲ୍ ପ୍ରତିକ୍ରିୟା ଯୋଗାଏ। ଏହା
ବିଦ୍ୟମାନ Anthropic, Claude OAuth, Claude Web, କିମ୍ବା `devin-cli` ପ୍ରଦାତାଗୁଡ଼ିକୁ ପରିବର୍ତ୍ତନ କରେ ନାହିଁ।

କ୍ଲାଏଣ୍ଟ-ନିୟନ୍ତ୍ରିତ ଟୁଲ୍ କଲ୍ଗୁଡ଼ିକ ପାଇଁ, Claude-ଫର୍ମାଟ୍ର ଟୁଲ୍-ସକ୍ଷମ ପ୍ରଦାତା
`devin-cli-agentic` (ଉପନାମ `dva`) ମାଧ୍ୟମରେ ରୁଟ୍ କରନ୍ତୁ। ପୁରୁଣା `devin-cli` (`dv`) ACP ନିଷ୍ପାଦକଟି
କେବଳ-ଟେକ୍ସ୍ଟ: ଏହା Devinର ଟୁଲ୍-ବିହୀନ ସାରାଂଶକାରୀକୁ ଚଲାଏ ଏବଂ ଟୁଲ୍ କଲ୍ ଫେରାଇ ପାରେ ନାହିଁ। ଏହାର ମଡେଲ୍
ମେଟାଡାଟାକୁ ସେହି ଅନୁଯାୟୀ ଚିହ୍ନିତ କରାଯାଇଛି, ଯାହାଦ୍ୱାରା ଟୁଲ୍-ଆବଶ୍ୟକ କମ୍ବୋ ରାଉଟିଂ ଏହାକୁ ଏଡ଼ାଇବ।

> **ବର୍ତ୍ତମାନର ସ୍ଥିତି: ପିନ୍ କରାଯାଇଥିବା Claude Code `2.1.258`; ଅଫ୍ଲାଇନ୍ ଏବଂ ଲାଇଭ୍ ବୈଧତାକରଣ ଶେଷଥର
> `2.1.220`ରେ ରେକର୍ଡ କରାଯାଇଥିଲା।** `2.1.220` ପିନ୍ଟି Devin CLI
> `3000.2.17` ଏବଂ ମଡେଲ୍ `swe-1-7-lightning` ମାଧ୍ୟମରେ ତିନୋଟି ପୃଥକ ପରିଦୃଶ୍ୟ ସମ୍ପୂର୍ଣ୍ଣ କରିଥିଲା; ସେହି ଅନ୍ତିମ ଲାଇଭ୍ ଚାଳନା କ୍ଲାଏଣ୍ଟ-ନିୟନ୍ତ୍ରିତ `Read`,
> `Edit`, ଏବଂ `Bash` ଟର୍ନ୍, ସଫଳ `npm test` ଫଳାଫଳ, ପ୍ରକଳ୍ପ କମାଣ୍ଡ ଏବଂ ସ୍କିଲ୍
> ଆବିଷ୍କାର, କେବଳ-Devin ରାଉଟିଂ, ଏବଂ ଶୂନ୍ୟ Claude ବାହ୍ୟ ଟ୍ରାଫିକ୍ ପ୍ରମାଣିତ କରିଥିଲା। ପରେ ପିନ୍ଟିକୁ `2.1.258`
> କୁ ବୃଦ୍ଧି କରାଯାଇଥିଲା (ଯେଉଁ CLI ପିଢ଼ିକୁ OmniRouteର Claude ପରିଚୟ ଅନୁକରଣ କରେ, ଏବଂ ଯେଉଁ ପ୍ରଥମ ଲାଇନ୍
> Fable 5.1 ସ୍ତରକୁ ସ୍ୱାଭାବିକ ଭାବରେ ଯୋଗାଇଥାଏ)। ନୂତନ ପିନ୍ରେ, ପିନ୍ କରାଯାଇଥିବା ବେସ୍ ଇମେଜ୍ରେ ଇନ୍ଷ୍ଟଲ୍ ସ୍ତର ଏବଂ `claude --version`
> ଯାଞ୍ଚ କରାଯାଇଥିଲା, ଏବଂ ବ୍ରିଜ୍ ୟୁନିଟ୍ ସୁଇଟ୍, `compose config` ଏବଂ
> ସ୍ଥିର ପୃଥକୀକରଣ ପ୍ରମାଣ ସଫଳ ହୋଇଛି — କିନ୍ତୁ ଅଫ୍ଲାଇନ୍ ମକ୍ ପରିଦୃଶ୍ୟ ଏବଂ ଲାଇଭ୍ ତିନି-ପରିଦୃଶ୍ୟ
> ସୁଇଟ୍କୁ ଏପର୍ଯ୍ୟନ୍ତ ପୁନଃଚାଳନା କରାଯାଇନାହିଁ। ଏହି ପିନ୍ ସହିତ ବ୍ରିଜ୍ରେ ନିର୍ଭର କରିବା ପୂର୍ବରୁ ସେଗୁଡ଼ିକୁ ପୁନଃଚାଳନା କରନ୍ତୁ
> ("Updating pinned tools" ଦେଖନ୍ତୁ)।

## ସ୍ଥାପତ୍ୟ

```text
Claude Code 2.1.258 (ପୃଥକ କରାଯାଇଥିବା ଅଣ-root Linux କଣ୍ଟେନର୍)
  -> http://omniroute:20128/v1/messages
  -> devin-cli-agentic (Claude-ଫର୍ମାଟ୍, ପ୍ରମାଣୀକରଣ-ବିହୀନ ପ୍ରଦାତା)
  -> devin acp --agent-type summarizer (ଆଧିକାରିକ ACP stdio, କୌଣସି Devin ଟୁଲ୍ ନାହିଁ)
  -> ଉତ୍ସର୍ଗୀକୃତ devin-auth ଭଲ୍ୟୁମ୍ରେ Devin ଆକାଉଣ୍ଟ
```

ଆଧିକାରିକ CLIର ଡିଫଲ୍ଟ ACP ଏଜେଣ୍ଟ ନିଜସ୍ୱ ଟୁଲ୍ଗୁଡ଼ିକୁ ନିଷ୍ପାଦନ କରିପାରେ, ତେଣୁ ଏହି ବ୍ରିଜ୍ ଏହାକୁ ବ୍ୟବହାର କରେ ନାହିଁ।
ଏହା ସ୍ଥିର `summarizer` ACP ଏଜେଣ୍ଟକୁ ଆରମ୍ଭ କରେ, ଯାହାର ଆଧିକାରିକ CLI ମୋଡ୍ରେ କୌଣସି ଟୁଲ୍ ନାହିଁ, ଏବଂ
କ୍ରମିକୀକୃତ Anthropic ଅନୁରୋଧକୁ ଏକ ନିଷ୍ପାଦନ ଟ୍ରେସ୍ ଭାବରେ ଫ୍ରେମ୍ କରେ। ଯେତେବେଳେ ଅନ୍ୟ ଏକ Claude-ନିୟନ୍ତ୍ରିତ
କାର୍ଯ୍ୟ ଆବଶ୍ୟକ ହୁଏ, ପ୍ରତିକ୍ରିୟାରେ ଠିକ୍ ଗୋଟିଏ କ୍ଲାଏଣ୍ଟ ଟୁଲ୍ ଏନ୍ଭେଲପ୍ ରହିବା ଆବଶ୍ୟକ। କୌଣସି ACP
`tool_call` କିମ୍ବା `tool_call_update`କୁ ଏକ ପ୍ରତିକ୍ରିୟା ସଫଳ ବୋଲି ରିପୋର୍ଟ କରାଯିବା ପୂର୍ବରୁ ପ୍ରତ୍ୟାଖ୍ୟାନ କରାଯାଏ।

`open-sse/executors/devin-agentic/serializer.ts`ରେ ଥିବା ସିରିଆଲାଇଜର୍ `system`,
`text`, `tool_use`, `tool_result`, `thinking`, `redacted_thinking`, `tool_choice`, ଏବଂ
Claude Code ଦ୍ୱାରା ଯୋଗାଇ ଦିଆଯାଇଥିବା ଟୁଲ୍ଗୁଡ଼ିକୁ ଅପରିବର୍ତ୍ତିତ ରଖେ। ଇମେଜ୍ ଏବଂ ଅଜଣା ବ୍ଲକ୍ଗୁଡ଼ିକ ସ୍ପଷ୍ଟ ଭାବରେ ବିଫଳ ହୁଅନ୍ତି। ବଡ଼ ଟୁଲ୍ ଫଳାଫଳଗୁଡ଼ିକ
ଏକ ଦୃଶ୍ୟମାନ ଛୋଟକରଣ ଚିହ୍ନ ବ୍ୟବହାର କରନ୍ତି।

ପାର୍ସର୍ ପ୍ରତ୍ୟେକ ମଡେଲ୍ ଟର୍ନ୍ ପାଇଁ ଗୋଟିଏ ସ୍ୱତନ୍ତ୍ର `<tool>{...}</tool>` ଏନ୍ଭେଲପ୍ ଗ୍ରହଣ କରେ। ଏହା
ଅନୁରୋଧର ଟୁଲ୍ ତାଲିକା ସହିତ ନାମକୁ ଯାଞ୍ଚ କରେ, ସେହି ଟୁଲ୍ର JSON Schema ଅନୁଯାୟୀ ଆର୍ଗୁମେଣ୍ଟଗୁଡ଼ିକୁ ବୈଧ କରେ,
ମିଶ୍ରିତ ବର୍ଣ୍ଣନା/କାର୍ଯ୍ୟକୁ ପ୍ରତ୍ୟାଖ୍ୟାନ କରେ, ଏବଂ ଗୋଟିଏ ସୀମିତ ମରାମତିକୁ ଅନୁମତି ଦିଏ। ତା’ପରେ Claude Code
ଫଳସ୍ୱରୂପ ମିଳିଥିବା Anthropic `tool_use`କୁ ସ୍ଥାନୀୟ ଭାବରେ ନିଷ୍ପାଦନ କରେ ଏବଂ `tool_result`କୁ OmniRoute ମାଧ୍ୟମରେ ପୁନଃ ପଠାଏ।

## ସ୍ୱୟଂଚାଳିତ ରାଉଟିଂ

ପ୍ରଦାତାଟି ବ୍ଲକ୍ ହୋଇନଥିବାବେଳେ OmniRouteର `auto/*` ପ୍ରାର୍ଥୀ ପୁଲ୍ଗୁଡ଼ିକରେ ଯୋଗ୍ୟ ଅଟେ।
ପ୍ରାର୍ଥୀ ଯୋଗ୍ୟତା ଚୟନର ନିଶ୍ଚିତତା ଦିଏ ନାହିଁ: କମ୍ବୋର ରାଉଟିଂ କୌଶଳ (ଉଦାହରଣ ସ୍ୱରୂପ,
ଶେଷ-ଜଣା-ଭଲ) ଅନ୍ୟ ଏକ ପ୍ରଦାତାକୁ ପସନ୍ଦ କରିପାରେ। ପ୍ରତ୍ୟେକ ଅନୁରୋଧ Devin ମାଧ୍ୟମରେ ଯିବା ଆବଶ୍ୟକ ହେଲେ,
`dva/<model>` କିମ୍ବା ଏକ Devin-ପ୍ରଥମ କମ୍ବୋ ବ୍ୟବହାର କରନ୍ତୁ।

## ପୃଥକୀକରଣ ଏବଂ ବିପଦ ମଡେଲ୍

ହୋଷ୍ଟର Claude ଇନଷ୍ଟଲେସନ୍, ଆକାଉଣ୍ଟ ଏବଂ ବିନ୍ୟାସ ଏହାର ପରିସର ବାହାରେ ଅଛି ଏବଂ ସେଗୁଡ଼ିକୁ
ନିଷିଦ୍ଧ ଭାବେ ବିବେଚନା କରାଯାଏ। Compose ସେବାଗୁଡ଼ିକ:

- କେବଳ-ପଠନୀୟ ରୁଟ୍ ଫାଇଲ୍ ସିଷ୍ଟମ୍, ଅପସାରିତ କ୍ଷମତା ଏବଂ
  `no-new-privileges` ସହିତ UID/GID `10001:10001` ଭାବେ ଚାଲେ;

  ଏବଂ ଏକ ଅଲଗା `devin-auth` ଭଲ୍ୟୁମ୍ ବ୍ୟବହାର କରେ;
- କେବଳ ଅସ୍ଥାୟୀ `.sandbox` କାର୍ଯ୍ୟକ୍ଷେତ୍ର/ପ୍ରମାଣକୁ ମାଉଣ୍ଟ କରେ;
- ହୋଷ୍ଟର ହୋମ୍, Keychain, SSH, କ୍ଲାଉଡ୍ ପ୍ରମାଣପତ୍ର କିମ୍ବା Docker ସକେଟ୍କୁ ମାଉଣ୍ଟ କରେ ନାହିଁ;

- କେବଳ ଏକ ସ୍ଥାନୀୟ କୀ ସହିତ Claude Code ଇନଫରେନ୍ସକୁ `http://omniroute:20128` ଆଡ଼କୁ ନିର୍ଦ୍ଦେଶିତ କରେ।

ଅଫ୍ଲାଇନ୍ ପ୍ରୋଫାଇଲ୍ ଏକ ଆଭ୍ୟନ୍ତରୀଣ ନେଟୱର୍କ ବ୍ୟବହାର କରେ। ଲାଇଭ୍ ପ୍ରୋଫାଇଲ୍ରେ, OmniRoute କେବଳ
`network-guard` ମାଧ୍ୟମରେ ଆଧିକାରିକ Devin ଏଣ୍ଡପଏଣ୍ଟଗୁଡ଼ିକୁ ପହଞ୍ଚେ; ଅସମ୍ବନ୍ଧିତ ଗନ୍ତବ୍ୟଗୁଡ଼ିକୁ ଅସ୍ୱୀକାର କରାଯାଏ।
Claude Code ପାଇଁ ଏକ ପୃଥକ ସମସ୍ତ-ନିଷେଧକାରୀ ଆଉଟ୍ଗୋଇଂ ଟ୍ରାଫିକ୍ ଗାର୍ଡ ଅଛି ଏବଂ ଏହା `NO_PROXY` ମାଧ୍ୟମରେ କେବଳ ସ୍ଥାନୀୟ OmniRoute
ସେବାକୁ ପହଞ୍ଚିପାରେ। ଗାର୍ଡ ଅଡିଟ୍ ଫାଇଲ୍ଗୁଡ଼ିକ କେବଳ ସେମାନଙ୍କର ଗାର୍ଡ ପ୍ରକ୍ରିୟା ଦ୍ୱାରା ମାଉଣ୍ଟ କରାଯାଏ। ସ୍କ୍ରିପ୍ଟଗୁଡ଼ିକ
ଟୋକେନ୍-ମୁକ୍ତ ପ୍ରମାଣ ଏକ୍ସପୋର୍ଟ କରିବା ପୂର୍ବରୁ ଫାଇଲ୍ ମାଲିକାନା, ମୋଡ୍, ଲିଙ୍କ୍ ସଂଖ୍ୟା ଏବଂ ପ୍ରତ୍ୟେକ ନିଷ୍ପତ୍ତିକୁ ଯାଞ୍ଚ କରନ୍ତି।

ପୃଥକୀକରଣ ପ୍ରମାଣକୁ ସ୍ୱାଧୀନ ଭାବେ ଚଲାନ୍ତୁ:

```bash
./scripts/devin-bridge/verify-anthropic-isolation
```

ଏହା ଟୋପୋଲୋଜି, ନାମିତ ମାଉଣ୍ଟ, ଅଣ-ରୁଟ୍/କେବଳ-ପଠନୀୟ ସେଟିଂ, ସ୍ପଷ୍ଟ ସ୍ଥାନୀୟ ରାଉଟିଂ,
ସମ୍ବେଦନଶୀଳ ପରିବେଶ ଭେରିଏବଲ୍ର ଅନୁପସ୍ଥିତି, Docker ସକେଟ୍ର ଅନୁପସ୍ଥିତି, `api.anthropic.com`
ଏବଂ `claude.ai`କୁ ଅବରୋଧିତ ପ୍ରବେଶ, କେବଳ-Devin ପ୍ରଦାତା ଚୟନ ଏବଂ ACP ବ୍ୟାକ୍ଏଣ୍ଡ
ଉପଲବ୍ଧ ନଥିବାବେଳେ ସ୍ପଷ୍ଟ ବିଫଳତାକୁ ବୈଧ କରେ।

## ପ୍ରଥମ ଥର ସେଟ୍ଅପ୍ ଏବଂ ସାଧାରଣ ବ୍ୟବହାର

ପିନ୍ କରାଯାଇଥିବା ଇମେଜ୍ ନିର୍ମାଣ କରନ୍ତୁ:

```bash
./scripts/devin-bridge/build
```

କେବଳ ପୃଥକୀକୃତ Devin ଭଲ୍ୟୁମ୍କୁ ପ୍ରମାଣୀକୃତ କରନ୍ତୁ:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/login-devin
```

ଲଗ୍ଇନ୍ କମାଣ୍ଡ ରିମୋଟ୍/କଣ୍ଟେନର୍ ପରିବେଶ ପାଇଁ ଉଦ୍ଦିଷ୍ଟ ଆଧିକାରିକ ମାନୁଆଲ୍-ଟୋକେନ୍
ପ୍ରବାହ ବ୍ୟବହାର କରେ। ମୂଲ୍ୟଟି ସିଧାସଳଖ CLI ପ୍ରମ୍ପ୍ଟରେ ପ୍ରବେଶ କରାଯାଏ; ଏହାକୁ ଏକ
ପ୍ରକ୍ରିୟା ଆର୍ଗୁମେଣ୍ଟ ଭାବେ ପଠାଯାଏ ନାହିଁ, Gitରେ ଲେଖାଯାଏ ନାହିଁ କିମ୍ବା ହୋଷ୍ଟରୁ କପି କରାଯାଏ ନାହିଁ।

ପୃଥକୀକୃତ Claude Code ରନ୍ଟାଇମ୍ ଆରମ୍ଭ କରନ୍ତୁ:

```bash
./scripts/devin-bridge/launch
```

କଣ୍ଟେନର୍ଭିତ୍ତିକ Claude Code ଆରମ୍ଭ କରିବା ପୂର୍ବରୁ `launch` ପୃଥକୀକରଣ, Devin ପ୍ରମାଣୀକରଣ
ଏବଂ ମଡେଲ୍ ଆବିଷ୍କାରକୁ ପୁନଃଯାଞ୍ଚ କରେ। ଏହା କେବେବି ହୋଷ୍ଟର Claude ଏକ୍ସିକ୍ୟୁଟେବଲ୍ ଚଲାଏ ନାହିଁ। ମଡେଲ୍ ଉପନାମଗୁଡ଼ିକୁ
`.env.devin-bridge`ରେ ସେଟ୍ କରାଯାଇପାରେ; ବିନ୍ୟାସ କରାଯାଇଥିବା ପ୍ରତ୍ୟେକ ମୂଲ୍ୟରେ
`devin-cli-agentic/` ପ୍ରିଫିକ୍ସ ରହିବା ଆବଶ୍ୟକ।

## ବୈଧକରଣ କମାଣ୍ଡଗୁଡ଼ିକ

ପୁନରୁତ୍ପାଦନଯୋଗ୍ୟ ଅଫ୍ଲାଇନ୍ ପଥ ପାଇଁ କୌଣସି Devin ଆକାଉଣ୍ଟ ଆବଶ୍ୟକ ନୁହେଁ ଏବଂ ଏଥିରେ ରନ୍ଟାଇମ୍ ଇଣ୍ଟରନେଟ୍ ନାହିଁ:

```bash
./scripts/devin-bridge/test-unit
./scripts/devin-bridge/test-contract
./scripts/devin-bridge/test-e2e-mock
./scripts/devin-bridge/verify-anthropic-isolation
```

ପ୍ରମାଣୀକୃତ ବୈକଳ୍ପିକ ଲାଇଭ୍ ପଥ ହେଉଛି:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/test-live-devin
```

ଏକାଥରେ ବହୁ ACP ସେସନ୍ ଖୋଲିବାକୁ ଏଡ଼ାଇବା ପାଇଁ ଲାଇଭ୍ ରନର୍ ପରିଦୃଶ୍ୟଗୁଡ଼ିକ ମଧ୍ୟରେ ଅପେକ୍ଷା କରେ ଏବଂ
ପାଠ୍ୟ ଦାବିଗୁଡ଼ିକୁ ବିଶ୍ୱାସ କରିବା ପରିବର୍ତ୍ତେ ସଂରଚିତ Claude ଷ୍ଟ୍ରିମ୍ ଇଭେଣ୍ଟଗୁଡ଼ିକୁ ବୈଧ କରେ। ଏହାର ତିନୋଟି
ପରିଦୃଶ୍ୟ ନିମ୍ନଲିଖିତ ବିଷୟ ପ୍ରମାଣ କରେ:

1. ସିଧାସଳଖ ପ୍ରୋଜେକ୍ଟ ପଠନ ଏବଂ ତ୍ରୁଟି ବିଶ୍ଳେଷଣ;
2. ଏକ ବାସ୍ତବ `Edit`, କ୍ଲାଏଣ୍ଟ-ମାଲିକାନାଧୀନ `Bash` `npm test` ଏବଂ ଏକ ଟର୍ମିନାଲ୍ ଫଳାଫଳ;
3. `/bridge-check` ସହିତ `bridge-proof` ଆବିଷ୍କାର, ପ୍ରୋଜେକ୍ଟ ପଠନ, ଅନ୍ୟ ଏକ ସଫଳ
   କ୍ଲାଏଣ୍ଟ-ମାଲିକାନାଧୀନ `npm test` ଏବଂ କୌଣସି ବିଚାରାଧୀନ କାର୍ଯ୍ୟ ବିନା ସମାପ୍ତି।

ଅନ୍ତିମ ଗେଟ୍ Devin ନେଟୱର୍କ ଅଡିଟ୍କୁ ମଧ୍ୟ ଯାଞ୍ଚ କରେ ଏବଂ Claude ଆଉଟ୍ଗୋଇଂ ଟ୍ରାଫିକ୍ ଅଡିଟ୍
ଖାଲି ରହିବା ଆବଶ୍ୟକ କରେ।

## ପିନ୍ କରାଯାଇଥିବା ଟୁଲ୍ଗୁଡ଼ିକୁ ଅଦ୍ୟତନ କରିବା

ଇମେଜ୍ଟି `docker/devin-bridge/Dockerfile`ରେ Node, Claude Code, ଏବଂ Devin CLIକୁ ପିନ୍ କରେ।
ଅଦ୍ୟତନ କରିବା ପାଇଁ:

1. ସ୍ପଷ୍ଟ ଭାବେ ଉଲ୍ଲେଖିତ ସଂସ୍କରଣଗୁଡ଼ିକୁ ପରିବର୍ତ୍ତନ କରନ୍ତୁ;
2. ଉଭୟ ଆର୍କିଟେକ୍ଚର୍-ନିର୍ଦ୍ଦିଷ୍ଟ Devin ଆର୍କାଇଭ୍ ଚେକ୍ସମ୍କୁ ଅଫିସିଆଲ୍
   ଆର୍ଟିଫ୍ୟାକ୍ଟର ମୂଲ୍ୟଗୁଡ଼ିକ ସହିତ ବଦଳାନ୍ତୁ;
3. ପୁନଃ ବିଲ୍ଡ କରନ୍ତୁ ଏବଂ ପ୍ରତ୍ୟେକ ଅଫ୍ଲାଇନ୍ ବୈଧତା ଯାଞ୍ଚ କମାଣ୍ଡ ଚଲାନ୍ତୁ;
4. ଇମେଜ୍ ଭିତରେ ସଂସ୍କରଣଗୁଡ଼ିକ ନିଶ୍ଚିତ କରନ୍ତୁ;
5. ପ୍ରମାଣିତ ତିନି-ପରିଦୃଶ୍ୟ ବିଶିଷ୍ଟ ଲାଇଭ୍ ସୁଇଟ୍କୁ ପୁନଃ ଚଲାନ୍ତୁ।

ହୋଷ୍ଟରେ କୌଣସି CLIକୁ ଗ୍ଲୋବାଲ୍ ଭାବେ ଇନ୍ଷ୍ଟଲ୍ କରନ୍ତୁ ନାହିଁ କିମ୍ବା ଚେକ୍ସମ୍ ଯାଞ୍ଚକୁ
ଏକ ଅଯାଞ୍ଚିତ ଡାଉନ୍ଲୋଡ୍ରେ ବଦଳାନ୍ତୁ ନାହିଁ।
