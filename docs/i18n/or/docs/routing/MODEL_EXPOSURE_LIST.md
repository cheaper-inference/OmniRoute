## ଏହା କାହିଁକି ଅଛି \|

`hidePaidModels` ଉତ୍ତର "ଏହି ମଡେଲ୍ ମୁକ୍ତ କି?" ଏବଂ `hideAutoCombos` ଉତ୍ତରଗୁଡିକ " `auto/*` ଭର୍ଚୁଆଲ୍ id ଗୁଡିକ ଆଦ advert ବିଜ୍ଞାପନ କରାଯିବା ଉଚିତ କି?" — ନା ଏକ ଅପରେଟରକୁ ମଡେଲଗୁଡିକର ଏକ ଇଚ୍ଛାଧୀନ ସବ୍ସେଟ୍ କୁରେଟ୍ କରିବାକୁ ଦିଏ ନାହିଁ (ଉଦାହରଣ ସ୍ୱରୂପ ନିର୍ଦ୍ଦିଷ୍ଟ Claude କୋଡ୍ / OpenCode କ୍ଲାଏଣ୍ଟ ଦେଖିବା ଉଚିତ, ମୂଲ୍ୟ ନିର୍ଧାରଣରୁ ନିରପେକ୍ଷ) \| # #11481 ଯୋଗ କରେ ଯେ ଦୁଇଟି ସ୍ independent ାଧୀନ, ଅପ୍ଟ-ଇନ୍ ଷ୍ଟ୍ରିଙ୍ଗ୍-ଆରେ ସେଟିଙ୍ଗ୍ ଭାବରେ \|

- `src/app/api/v1/models/catalog.ts` — ନିଜେ `/v1/models` ତାଲିକାଭୁକ୍ତ, ସମାନ 5 ପ୍ରତି ଉତ୍ସ ଚୋକପଏଣ୍ଟ `shouldHidePaid()` ପୂର୍ବରୁ ଫାଟକ (ଷ୍ଟାଟିକ୍ `PROVIDER_MODELS`, ସିଙ୍କ୍ ପ୍ରଦାନକାରୀ ଧାଡି, କଷ୍ଟମ୍ ଧାଡି, ଛଦ୍ମନାମ ସମର୍ଥିତ ଧାଡି, ପରିଚାଳନା-ଫଲବ୍ୟାକ୍ ଧାଡି) \|
- `open-sse/services/autoCombo/modelExposureFilter.ts::filterModelExposureCandidates()` — `virtualFactory.ts::buildPreparedPool` ରୁ ଡାକିଲା, ସମାନ `filterPaidOnlyCandidates()` କଲ ପରେ ତୁରନ୍ତ, ତେଣୁ ଏକ ପ୍ରତ୍ୟାଖ୍ୟାନ ମଡେଲକୁ `auto/*` ପ୍ରାର୍ଥୀ ପୁଲରେ ମଧ୍ୟ ଚୟନ କରାଯାଇପାରିବ ନାହିଁ \|

## NOT ଫିଲ୍ଟର୍ କଣ \|

ଦର୍ପଣ `hideAutoCombos` ର ବିଦ୍ୟମାନ ଆଚରଣ: ଏକ ମଡେଲ୍ id ପଠାଯାଇଛି \|** ସ୍ପଷ୍ଟ ଭାବରେ** ( `auto/*` ମାଧ୍ୟମରେ ନୁହେଁ, ଏବଂ କାଟାଲଗ୍ ତାଲିକା ମାଧ୍ୟମରେ ଆବିଷ୍କୃତ ହୋଇନାହିଁ) — ପଠାଇବାରେ କଦାପି ଅବରୋଧ କରାଯାଇ ନାହିଁ କେବଳ advertisement/candidate-pool ସଦସ୍ୟତା ଫିଲ୍ଟର୍ ହୋଇଥାଏ \| ଏହା `hidePaidModels` ଠାରୁ ସ୍ୱାଧୀନ; ଏକ ଅପରେଟର୍ ହୁଏତ ଏକ କ୍ୟୁରେଟେଡ୍ ସେଟ୍ ଚାହିଁପାରେ ଯାହାର ମୂଲ୍ୟ ସହିତ କ to ଣସି ସମ୍ପର୍କ ନାହିଁ, ତେଣୁ ଉଭୟ ସେଟିଙ୍ଗ୍ ସ୍ independent ାଧୀନ ଏବଂ ଏଡ୍ ଫିଲ୍ଟର୍ ଭାବରେ ରଚନା କରେ, `catalog.ts` ରେ ଥିବା ମଲ୍ଟି ଫ୍ଲାଗ୍ ରଚନା ସହିତ ସମାନ \|

ସେଟିଂସମୂହ ରପ୍ତାନି (`GET /api/settings/export-json`) ଉଭୟ ଆରେ ଭର୍ବାଟିମ୍ ଅନ୍ତର୍ଭୂକ୍ତ କରେ, ଯେପରି `hidePaidModels` ର କମ୍ବୋ-ଷ୍ଟେପ୍ ରପ୍ତାନି ଫିଲ୍ଟର୍ ପରି ଅନ୍ୟ ସେଟିଙ୍ଗ୍ ଫିଲ୍ଡ —, ଏଠାରେ ପୁନ re- ହାଇଡ୍ରେସନ୍ ବିପଦ ନାହିଁ: ଏକ ରପ୍ତାନି ହୋଇଥିବା କମ୍ବୋ ଷ୍ଟେପ୍ ରେ ସନ୍ନିବେଶିତ id ହେଉଛି ଅପରେଟରଙ୍କର ନିଜସ୍ୱ ସ୍ପଷ୍ଟ ରାଉଟିଙ୍ଗ୍ ପସନ୍ଦ, ରପ୍ତାନି ସୀମାକୁ ଛଡ଼ାଇବା ଆବଶ୍ୟକ ନୁହେଁ \|

## କମ୍ବୋସ୍-କେବଳ ତାଲିକା (`exposeCombosOnly`)

ଏକ ପୃଥକ ବୁଲିୟନ୍, ଡିଫଲ୍ଟ ଭାବରେ ଅପ୍ଟ-ଇନ୍ ଏବଂ `false`, ନିୟୋଜନ ପାଇଁ ଯେଉଁଠାରେ କମ୍ବୋ ସର୍ବସାଧାରଣ ମଡେଲ୍ ପୃଷ୍ଠ ଏବଂ ପ୍ରଦାନକାରୀ କେବଳ ବ୍ୟାକେଣ୍ଡ୍ \| ଯେତେବେଳେ ଏହା `true` ଅଟେ, ସର୍ବସାଧାରଣ ତାଲିକା (`GET /v1/models`, `GET /v1`, ଏବଂ `getUnifiedModelsResponse()` ଉପରେ ନିର୍ମିତ ଅନ୍ୟ `/v1` ଆବିଷ୍କାର ମାର୍ଗ) କେବଳ `owned_by: "combo"` ସହିତ ଧାଡି ରଖେ: ଉପଭୋକ୍ତା କମ୍ବୋ ଏବଂ ବିଲ୍ଟ-ଇନ୍ `auto/*` କମ୍ବୋ (ଯଦି `hideAutoCombos` ସେମାନଙ୍କୁ ଲୁଚାଇ ନଥାଏ) \| ଏହା ପ୍ରତି ଧାଡି `catalogScope: "combos"` ସହିତ ସମାନ ଧାଡି ପରୀକ୍ଷା ବ୍ୟବହାର କରେ, ଏବଂ ଏକ ଚାବିର ନିଜସ୍ୱ allow/deny/scope ଫିଲ୍ଟରଗୁଡ଼ିକ ଉପରେ ମଧ୍ୟ ପ୍ରୟୋଗ ହୁଏ \|

ଏହାକୁ ଟୋଗଲ୍ କରନ୍ତୁ \|** ସେଟିଂସମୂହ → ରାଉଟିଙ୍ଗ୍ → ମଡେଲଗୁଡିକ API ତାଲିକା \|** , କିମ୍ବା `PATCH /api/settings {"exposeCombosOnly": true}` ସହିତ \|

ଉପରୋକ୍ତ ତାଲିକା ପରି, ଏହା କେବଳ ବିଜ୍ଞାପନ ପରିବର୍ତ୍ତନ କରେ:

- ଏକ ସ୍ପଷ୍ଟ `provider/model` id ତଥାପି ପଠାଏ, ଏବଂ `GET /v1/models/{id}` ତଥାପି ଏହାକୁ ସମାଧାନ କରେ;
- ଡ୍ୟାସବୋର୍ଡ କାଟାଲଗ୍ (`GET /api/models/catalog`, ମଡେଲ୍ ପିକର୍ ଦ୍ୱାରା ବ୍ୟବହୃତ) ସଂକୀର୍ଣ୍ଣ ନୁହେଁ;
- ଏହା `auto/*` ପ୍ରାର୍ଥୀ ପୁଲରେ ପ୍ରତିବିମ୍ବିତ ନୁହେଁ, ତେଣୁ `auto/*` କମ୍ବୋ ସେମାନଙ୍କର ପୂର୍ଣ୍ଣ ପୁଲ୍ ରଖେ \|
