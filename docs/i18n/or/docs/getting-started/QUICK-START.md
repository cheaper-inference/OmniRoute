> **TL;DR**: ଇନଷ୍ଟଲ୍ କରନ୍ତୁ → ଏକ ଯୋଗ୍ୟ ପ୍ରଦାତାଙ୍କୁ ସଂଯୋଗ କରନ୍ତୁ → ଆପଣଙ୍କ IDEକୁ OmniRoute ଆଡ଼କୁ ନିର୍ଦ୍ଦେଶ କରନ୍ତୁ। ବାସ୍, ଏତିକି।

## ପଦକ୍ଷେପ 1: OmniRoute ଇନ୍ଷ୍ଟଲ୍ କରନ୍ତୁ

ଆପଣଙ୍କ ପସନ୍ଦର ପଦ୍ଧତି ବାଛନ୍ତୁ:

### ବିକଳ୍ପ A: npm (ସୁପାରିଶକୃତ)

```bash
npm install -g omniroute
```

### ବିକଳ୍ପ B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` ହେଉଛି ସର୍ବୋଚ୍ଚ **ପ୍ରକାଶିତ** ସ୍ଥିର SemVer। ଏହା git `main`କୁ ଅନୁସରଣ କରେ **ନାହିଁ**। GitOps ପାଇଁ `diegosouzapw/omniroute:X.Y.Z`କୁ ପିନ୍ କରନ୍ତୁ। [ଇମେଜ୍ ଟ୍ୟାଗ୍ଗୁଡ଼ିକ / ରିଲିଜ୍ ଚ୍ୟାନେଲ୍ଗୁଡ଼ିକ](../guides/DOCKER_GUIDE.md#release-channels) ଦେଖନ୍ତୁ।

### ବିକଳ୍ପ C: ଉତ୍ସ କୋଡ୍ରୁ

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

## ପଦକ୍ଷେପ 2: OmniRoute ଆରମ୍ଭ କରନ୍ତୁ

```bash
omniroute
```

OmniRoute `http://localhost:20128`ରେ ଆରମ୍ଭ ହୁଏ। ଡ୍ୟାସ୍ବୋର୍ଡ ସ୍ୱୟଂଚାଳିତ ଭାବରେ ଖୋଲିଯାଏ।

---

## ପଦକ୍ଷେପ 3: ଏକ ଯୋଗ୍ୟ ପ୍ରଦାତାକୁ ସଂଯୋଗ କରନ୍ତୁ

ଆପଣଙ୍କ ଆବଶ୍ୟକତା ସହ ମେଳ ଖାଉଥିବା ସର୍ତ୍ତାବଳୀ ଏବଂ କୋଟା ଥିବା ଏକ ପ୍ରଦାତା ବାଛନ୍ତୁ। **Dashboard → Providers**ରେ ନିଜ ଆକାଉଣ୍ଟ କିମ୍ବା API କୀ ସଂଯୋଗ କରନ୍ତୁ, ତା’ପରେ ସଂଯୋଗଟିକୁ ପରୀକ୍ଷା କରନ୍ତୁ। ମାଗଣା ଆକ୍ସେସ୍ ଏବଂ କୀ ବିନା ଉପଲବ୍ଧତା ନିଶ୍ଚିତ ନୁହେଁ।

ଡିଫଲ୍ଟ ଭାବେ `auto`, Kiro ସମେତ `tos: avoid` ଭାବେ ଚିହ୍ନିତ ପ୍ରଦାତାମାନଙ୍କୁ ବାଦ ଦିଏ। ଏକ ଆକାଉଣ୍ଟ ସଂଯୋଗ କରିବା ଦ୍ୱାରା ସେହି ନୀତି ପରିବର୍ତ୍ତନ ହୁଏ ନାହିଁ। **Dashboard → Combos**ରେ ଥିବା ଅପ୍ଟ-ଇନ୍ ସମସ୍ତ ଅଟୋ କମ୍ବୋ ପାଇଁ ପ୍ରଯୁଜ୍ୟ। ପ୍ରଦାତା ବାଛିବା ପୂର୍ବରୁ [ମାଗଣା ଟିଅର୍ଗୁଡ଼ିକର ମାର୍ଗଦର୍ଶିକା](./FREE-TIERS-GUIDE.md) ସମୀକ୍ଷା କରନ୍ତୁ।

## ପଦକ୍ଷେପ 4: ଏହା କାମ କରୁଛି କି ନାହିଁ ଯାଞ୍ଚ କରନ୍ତୁ

[API Keys](http://localhost:20128/dashboard/api-manager)ରୁ ଏକ ନୂଆ କୀ ସୃଷ୍ଟି କରନ୍ତୁ। ଏହି କୀ ପୁଣିଥରେ ଦେଖାଯିବ ନାହିଁ, ତେଣୁ ଏହାକୁ ସଂରକ୍ଷଣ କରନ୍ତୁ। ମନେ ରଖନ୍ତୁ, ଏହି କୀଟି ଟୁଲ୍ଗୁଡ଼ିକ ଦ୍ୱାରା OmniRouteକୁ ଆକ୍ସେସ୍ କରିବା ପାଇଁ, ଅପ୍ଷ୍ଟ୍ରିମ୍ ପ୍ରଦାନକାରୀଙ୍କୁ ଆକ୍ସେସ୍ କରିବା ପାଇଁ ନୁହେଁ।

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

ଆପଣଙ୍କ ସଂଯୋଜିତ ମଡେଲ୍ଗୁଡ଼ିକ ତାଲିକାଭୁକ୍ତ ହୋଇଥିବା ଦେଖିବା ଉଚିତ।

## ପଦକ୍ଷେପ 5: ଆପଣଙ୍କ IDE କିମ୍ବା CLIକୁ OmniRoute ଆଡ଼କୁ ନିର୍ଦ୍ଦେଶ କରନ୍ତୁ

ଆପଣଙ୍କ IDE କିମ୍ବା CLI ଟୁଲ୍ରେ ଏଗୁଡ଼ିକ ସେଟ୍ କରନ୍ତୁ:

```
Base URL: http://localhost:20128/v1
API Key:  [copy from Dashboard → Endpoints]
Model:    auto
```

ବାସ୍, ଏତିକି! ଆପଣଙ୍କ IDE ବର୍ତ୍ତମାନ ସ୍ୱୟଂଚାଳିତ ପ୍ରଦାନକାରୀ ଚୟନ ସହିତ OmniRoute ବ୍ୟବହାର କରୁଛି।

### IDE ଉଦାହରଣ: VSCode/Continue.dev

1. VSCodeରେ [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue) ଏକ୍ସଟେନ୍ସନ୍ ଇନ୍ଷ୍ଟଲ୍ କରନ୍ତୁ।
2. ନିମ୍ନଲିଖିତ ଧାଡ଼ିଗୁଡ଼ିକ ଯୋଡ଼ିବା ପାଇଁ ଆପଣଙ୍କ `~/.continue/config.yaml` ଅପଡେଟ୍ କରନ୍ତୁ:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. Continue.dev ଚାଟ୍ ପେନ୍ରେ `OmniRoute - Auto` ବାଛନ୍ତୁ, ଏବଂ ଆପଣ OmniRouteକୁ ଅନୁରୋଧ ପଠାଇପାରିବେ।
4. (ଇଚ୍ଛାଧୀନ) ପାଠକଙ୍କ ପାଇଁ ଅଭ୍ୟାସ — ଅନ୍ୟ ସମସ୍ତ ପୂର୍ବନିର୍ମିତ କନ୍ଫିଗରେସନ୍ ସହିତ `config.yaml` ଅପଡେଟ୍ କରିବାକୁ ଆପଣଙ୍କ IDEକୁ କହନ୍ତୁ 😊

### CLI ଉଦାହରଣ: Codex CLI

1. ଆପଣଙ୍କ ଅପରେଟିଂ ସିଷ୍ଟମ୍ରେ ଏନ୍ଭାଇରନ୍ମେଣ୍ଟ ଭେରିଏବଲ୍କୁ ସ୍ଥାୟୀ ଭାବରେ ସେଟ୍ କରନ୍ତୁ।
   macOS/Linux ପାଇଁ (ଆପଣଙ୍କ `~/.bashrc` କିମ୍ବା `~/.zshrc`ରେ ଯୋଡ଼ନ୍ତୁ):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Windows (Command Prompt) ପାଇଁ:

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. ବର୍ତ୍ତମାନ OmniRoute ପାଇଁ କନ୍ଫିଗର୍ କରାଯାଇଥିବା Codex ଚାଲୁ କରିବା। ଏହା ଚଲାନ୍ତୁ:

```
omniroute launch-codex --model auto
```

ଏଣ୍ଡପଏଣ୍ଟ ଏବଂ API କୀ ନିର୍ଦ୍ଦିଷ୍ଟ କରିବା ପାଇଁ ଆପଣ `codex` ଏବଂ କମାଣ୍ଡ ଲାଇନ୍ ପାରାମିଟର୍ଗୁଡ଼ିକ ବ୍ୟବହାର କରି ଏହାକୁ ମାନୁଆଲ୍ ଭାବରେ କରିପାରିବେ, କିନ୍ତୁ ଉପରୋକ୍ତ କମାଣ୍ଡ ସହିତ OmniRoute ଆପଣଙ୍କ ପାଇଁ ସବୁକିଛିର ଯତ୍ନ ନିଏ।

ଜେନେରିକ୍ ଲଞ୍ଚର୍ ମାଧ୍ୟମରେ ଅନ୍ୟ CLIଗୁଡ଼ିକ ପାଇଁ ମଧ୍ୟ ସେହି ଏକ-କମାଣ୍ଡ ଲଞ୍ଚ କାମ କରେ — `omniroute run <target>` ଦ୍ୱାରା `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen`, ଏବଂ `gemini` ସମର୍ଥିତ (ଦେଖନ୍ତୁ [CLI ଇଣ୍ଟିଗ୍ରେସନ୍ଗୁଡ଼ିକ](../guides/CLI-INTEGRATIONS.md))।

3. CLI ବର୍ତ୍ତମାନ OmniRouteକୁ ଅନୁରୋଧ ପଠାଉଥିବା ଉଚିତ।

### ଆପଣଙ୍କ ଟୁଲ୍ OmniRouteକୁ ରାଉଟ୍ କରୁଛି କି ନାହିଁ ନିଶ୍ଚିତ କରନ୍ତୁ

ବାମ ସାଇଡ୍ବାର୍ରୁ [Monitoring/Logs](http://localhost:20128/dashboard/logs) କ୍ଲିକ୍ କରି ଆପଣ ଅନୁରୋଧର ବିବରଣୀ ଦେଖିପାରିବେ। ଏହା ଭିତରେ କ୍ଲିକ୍ କଲେ ଆପଣ ଅଧିକ ବିବରଣୀ ଦେଖିପାରିବେ। ଏକ ଅତିରିକ୍ତ ସୂଚନା ଭାବରେ, ଆପଣଙ୍କ ପସନ୍ଦର ହାର୍ନେସ୍ରୁ କେଉଁ ସୂଚନା ପଠାଯାଉଛି ତାହା ଦେଖିପାରିବେ। ଶିକ୍ଷଣ ଏବଂ ଡିବଗିଂ ଦୃଷ୍ଟିକୋଣରୁ ଏହା ସହାୟକ।

## ସାଧାରଣ ପ୍ରଶ୍ନଗୁଡ଼ିକ

### "ମୋତେ ଏକ API କି ଆବଶ୍ୟକ କି?"

OmniRoute API କି ଆପଣଙ୍କ ଟୁଲ୍ଗୁଡ଼ିକୁ ପ୍ରମାଣିତ କରେ। ଅପ୍ଷ୍ଟ୍ରିମ୍ ପରିଚୟପତ୍ର ପ୍ରଦାତା ଉପରେ ନିର୍ଭର କରେ: କେତେକ ପ୍ରଦାତାଙ୍କ ପାଇଁ ଏକ API କି କିମ୍ବା ଆକାଉଣ୍ଟ୍ ଲଗ୍ଇନ୍ ଆବଶ୍ୟକ। ମାଗଣା ପ୍ରବେଶର ନିଶ୍ଚିତତା ନାହିଁ।

### "`auto` କ’ଣ?"

`auto` OmniRouteକୁ ପ୍ରତ୍ୟେକ ଅନୁରୋଧ ପାଇଁ ସ୍ୱୟଂଚାଳିତ ଭାବରେ ସର୍ବୋତ୍ତମ ପ୍ରଦାତା ବାଛିବାକୁ କହେ। ଏହା ଗତି, ଖର୍ଚ୍ଚ, ଗୁଣବତ୍ତା ଏବଂ ଉପଲବ୍ଧତାକୁ ବିଚାର କରେ। ବିବରଣୀ ପାଇଁ [Auto-Combo ମାର୍ଗଦର୍ଶିକା](./AUTO-COMBO-GUIDE.md) ଦେଖନ୍ତୁ।

### "ଏହାର ଖର୍ଚ୍ଚ କେତେ?"

OmniRoute ନିଜେ **ମାଗଣା ଏବଂ ମୁକ୍ତ ଉତ୍ସଯୁକ୍ତ**। ଆପଣ କେବଳ ବ୍ୟବହାର କରୁଥିବା ପ୍ରଦାତାମାନଙ୍କ ପାଇଁ ଦେୟ ଦିଅନ୍ତି। ଅନେକ ପ୍ରଦାତାଙ୍କର ମାଗଣା ସ୍ତର ରହିଛି — [ମାଗଣା ସ୍ତର ମାର୍ଗଦର୍ଶିକା](./FREE-TIERS-GUIDE.md) ଦେଖନ୍ତୁ।

### "ମୁଁ ଏହାକୁ Claude Code / Cursor / Copilot ସହିତ ବ୍ୟବହାର କରିପାରିବି କି?"

**ହଁ!** OmniRoute, OpenAI ଫର୍ମାଟ୍ ସମର୍ଥନ କରୁଥିବା ଯେକୌଣସି ଟୁଲ୍ ସହିତ କାମ କରେ। କେବଳ ବେସ୍ URLକୁ `http://localhost:20128/v1` ଭାବେ ସେଟ୍ କରନ୍ତୁ। ନିର୍ଦ୍ଦିଷ୍ଟ ସେଟ୍ଅପ୍ ନିର୍ଦ୍ଦେଶାବଳୀ ପାଇଁ [CLI ଟୁଲ୍ ମାର୍ଗଦର୍ଶିକା](../reference/CLI-TOOLS.md) ଦେଖନ୍ତୁ।

### "ଯଦି କୌଣସି ପ୍ରଦାତା ବନ୍ଦ ହୋଇଯାଏ, ତେବେ କ’ଣ ହେବ?"

OmniRoute ସ୍ୱୟଂଚାଳିତ ଭାବରେ ବିଫଳ ପ୍ରଦାତାମାନଙ୍କୁ ଏଡ଼ାଇ ଯାଇ ପରବର୍ତ୍ତୀ ପ୍ରଦାତାକୁ ଚେଷ୍ଟା କରେ। ଆପଣଙ୍କୁ କିଛି କରିବାକୁ ପଡ଼ିବ ନାହିଁ। ବିବରଣୀ ପାଇଁ [Auto-Combo ମାର୍ଗଦର୍ଶିକା](./AUTO-COMBO-GUIDE.md) ଦେଖନ୍ତୁ।
