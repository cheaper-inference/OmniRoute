## ଏକ ରିଲିଜ୍ ଶାଖାରେ ଅବତରଣ।

Omni-que `release/vX.Y.Z` ରେ ଅବତରଣକୁ ନିୟନ୍ତ୍ରଣ କରେ। PR ଅବତରଣ କରିବା ପୂର୍ବରୁ ଡିଫଲ୍ଟ ଶାଖାରେ `config/merge-queue/config.json` ରେ ଶୀର୍ଷ ସ୍ତରୀୟ `mode` ପ Read ନ୍ତୁ। [ଓମନି-କ୍ୟୁ](OMNI_QUEUE.md) ଦେଖନ୍ତୁ।

- **`shadow`** ବ valid ଧତା ଚଲାଇଥାଏ ଏବଂ ଏକ ମାନୁଆଲ୍ ମିଶ୍ରଣରେ ଅବତରଣ ଛାଡିଥାଏ। ଏହାର ଅନ୍ତିମ ମୁଣ୍ଡରେ `omni-queue` କୁ ଅନୁମୋଦିତ PR ରେ ପ୍ରୟୋଗ କରନ୍ତୁ। `npm run queue -- why <PR>` ସହିତ ଯୋଗ୍ୟତା ଯାଞ୍ଚ କରନ୍ତୁ। `npm run queue -- history --base <branch>` ରେ ସେହି ମୁଣ୍ଡ ପାଇଁ ରାୟକୁ ଅପେକ୍ଷା କରନ୍ତୁ। `would-land` ରେ ଅଗ୍ରଗତି କରନ୍ତୁ। `culprit-found` କିମ୍ବା `would-dequeue` ଉପରେ, ମିଶ୍ରଣକୁ ଧରି ରଖନ୍ତୁ ଏବଂ ଏହାର କାରଣ ଠିକ କରନ୍ତୁ।
- **ଛାୟା ବ୍ୟତିକ୍ରମ।** ସାମ୍ପ୍ରତିକ ବେସ୍ ଟିପ୍ ବିରୁଦ୍ଧରେ ସବୁଜ ପୂର୍ଣ୍ଣ CI ସହିତ ଏକ ଟ୍ରେନ୍ ଅଲଗା ଧାଡି ରାୟ ବିନା ଆଗକୁ ବ can ିପାରେ। ସମାନ ବ୍ୟତିକ୍ରମ ପ୍ରଯୁଜ୍ୟ ଯେତେବେଳେ PR ହେଡ୍ ସାମ୍ପ୍ରତିକ ଆଧାର ଟିପ୍ ଧାରଣ କରିସାରିଛି।
- **`live`** ଅବତରଣକୁ ଟ୍ରିଗର କରିବା ପାଇଁ `omni-queue` ଲେବଲ୍ ବ୍ୟବହାର କରେ। କେବଳ ଧାଡ଼ିଟି PR କୁ ଅବତରଣ କରେ। ମିଶ୍ରଣ ନିର୍ଦ୍ଦେଶଗୁଡିକ ଛାଡିଦିଅ ଏବଂ ଧାଡିରେ ସିଧାସଳଖ ପୁସ୍।

ପ୍ରତ୍ୟେକ ଅବତରଣ ମାଲିକଙ୍କ ପ୍ରାଧିକରଣ ଏବଂ ପ୍ରଯୁଜ୍ୟ ଆବଶ୍ୟକୀୟ ଯାଞ୍ଚ ଆବଶ୍ୟକ କରେ। ମାଲିକ ଅବତରଣ କରିବାକୁ ଅନୁମତି ଦେବା ପରେ ହିଁ `omni-queue` ପ୍ରୟୋଗ କରନ୍ତୁ। ସଂରକ୍ଷିତ ପଥକୁ ଛୁଇଁଥିବା PRs ମଧ୍ୟ ସେହି PR ପାଇଁ ମାଲିକର `protected-approved` ନିଷ୍ପତ୍ତି ଆବଶ୍ୟକ କରେ।

"ସକ୍ରିୟ ରିଲିଜ୍ ଉପରେ ସବୁଜ ଫାଟକ ଆବଶ୍ୟକ" ନିୟମ ମୁଣ୍ଡରେ ସବୁଜ `Gate / CI` ଏବଂ `Gate / Quality` ଆବଶ୍ୟକ କରେ। ଲାଲ୍ ଗେଟ୍ ବାଇପାସ୍ କରିବାକୁ `--admin` ବ୍ୟବହାର କରନ୍ତୁ ନାହିଁ। ଏକ ରିଲିଜ୍ ଫ୍ରିଜ୍ ବ୍ଲକ୍ ଫ୍ରିଜ୍ ଶାଖାରେ ମିଶ୍ରିତ ହୁଏ। [କଠିନ ନିୟମ 21](HARD_RULES_DETAIL.md) ଦେଖନ୍ତୁ। ଅନ୍ୟ ଅଧିବେଶନ କାର୍ଯ୍ୟ କରୁଥିବା ଏକ ଟାଣ ଅନୁରୋଧକୁ କେବେବି ଲେବଲ୍, ମିଶ୍ରଣ କିମ୍ବା ଠେଲି ଦିଅନ୍ତୁ ନାହିଁ। [ହାର୍ଡ ନିୟମ 22](HARD_RULES_DETAIL.md) ଦେଖନ୍ତୁ।

## ଟ୍ରେନ୍ ଟାଣ ଅନୁରୋଧ।

1. ସାମ୍ପ୍ରତିକ ରିଲିଜ୍ ବେସ୍ ଟିପ୍ ରେ ଏକ ଟ୍ରେନ୍ ଶାଖା ଆରମ୍ଭ କରନ୍ତୁ। ମିଶ୍ରଣ କାର୍ଯ୍ୟ ବ୍ୟବହାର କରି ସଠିକ୍ ଅନୁମୋଦିତ ସଦସ୍ୟ ମୁଣ୍ଡଗୁଡ଼ିକୁ ଏକତ୍ର କରନ୍ତୁ। ସ୍କ୍ୱାସ୍ ଏବଂ ରିସେଜ୍ ଠାରୁ ଦୂରେଇ ସେମାନଙ୍କ ପ୍ରତିବଦ୍ଧ ଇତିହାସକୁ ସଂରକ୍ଷଣ କରନ୍ତୁ।
2. ଟ୍ରେନ୍ ଶାଖା ପାଇଁ ଗୋଟିଏ ଟାଣ ଅନୁରୋଧ ଖୋଲ। ସାମ୍ପ୍ରତିକ ଆଧାର ଟିପ୍ ଉପରେ ସେହି PR ନିଜର ସମ୍ପୂର୍ଣ୍ଣ CI ସହିତ ବ Val ଧ କରନ୍ତୁ। ଅବତରଣ କରିବା ପୂର୍ବରୁ ବେସ୍ ଟିପ୍ ଏବଂ ଅନୁମୋଦିତ ସଦସ୍ୟ ମୁଣ୍ଡଗୁଡିକ ଯାଞ୍ଚ କରନ୍ତୁ। ବ valid ଧ ପ୍ରାର୍ଥୀ ପରିବର୍ତ୍ତନ ହେଲେ ଟ୍ରେନ୍ ଏବଂ ଏହାର CI ସତେଜ କରନ୍ତୁ।
3. ପ୍ରଯୁଜ୍ୟ କ୍ୟୁ ମୋଡ୍ ଅନ୍ତର୍ଗତ ମିଶ୍ରଣ ପ୍ରତିଶ୍ରୁତି ସହିତ ଟ୍ରେନ୍ PR ଅବତରଣ କର। ଲାଇଭ୍ ମୋଡ୍ ରେ, କ୍ରମର `merge-ff` ଅବତରଣ ପଦ୍ଧତି ମିଶ୍ରଣ କାର୍ଯ୍ୟକୁ ସଂରକ୍ଷଣ କରେ। ମୂଳ ସଦସ୍ୟ ମୁଖ୍ୟମାନେ ରିଲିଜ୍ ଶାଖାରୁ ପହଞ୍ଚି ପାରିବେ। GitHub ସଦସ୍ୟ ଭାବରେ PRs ଚିହ୍ନିତ କରେ ଏବଂ ପ୍ରତିବଦ୍ଧତା ସେମାନଙ୍କର ଲେଖକମାନଙ୍କୁ ରଖେ।

ଏକ ସର୍ବସାଧାରଣ ଉଦାହରଣ ହେଉଛି [PR #21071](https://github.com/cheaper-inference/OmniRoute/pull/21071)। ଏହା 18 ସଦସ୍ୟ PRs ମିଶାଇ 2026-11-24 ରେ ଏକ ମିଶ୍ରଣ ପ୍ରତିଶ୍ରୁତି ସହିତ ଅବତରଣ କଲା।

`main` ରୁ ପରବର୍ତ୍ତୀ ରିଲିଜ୍ ଶାଖାକୁ ଏକ ସିଙ୍କ-ବ୍ୟାକ୍ ମଧ୍ୟ ଏକ ମିଶ୍ରଣ ପ୍ରତିଶ୍ରୁତି ମାଧ୍ୟମରେ ଅବତରଣ କରେ। ପରବର୍ତ୍ତୀ ସିଙ୍କ-ବ୍ୟାକ୍ ପାଇଁ `main` ପ ry ତୃକ ସଂରକ୍ଷଣ ଆବଶ୍ୟକ। [ୱାର୍କଟ୍ରି ବିଚ୍ଛିନ୍ନତା](WORKTREE_ISOLATION.md#sync-back-landings-are-merge-commits-never-squash) ଦେଖନ୍ତୁ।

## ସ୍ଥାନୀୟ ମିଶ୍ରଣ-ଟ୍ରେନ୍ ବ valid ଧତାକାରୀ।

```bash
scripts/release/merge-train.sh [--plan] [--fast] <base-branch> <PR#> [<PR#>...]
```

ବ valid ଧତାକାରୀ ବେସ୍ ଏବଂ PR ହେଡ୍ ଆଣନ୍ତି ଏବଂ ସେମାନଙ୍କୁ ଏକ ନିଷ୍କ୍ରିୟ ୱାର୍କଟ୍ରିରେ ମିଶ୍ରଣ କରନ୍ତି। ଫଳାଫଳ ଗଛରେ ଏହା ଥରେ ଏହାର ପ୍ୟାରିଟି ସୁଟ୍ ଚଲାଇଥାଏ। ଏକ ବିଫଳ ହେଡ୍ ଆଣିବା କିମ୍ବା ମିଶ୍ରଣ ଦ୍ୱନ୍ଦକୁ ବାହାର କରିଥାଏ ଯାହାକି PR ଏବଂ ସ୍କ୍ରିପ୍ଟ ଅବଶିଷ୍ଟ PRs ସହିତ ଜାରି ରହିଥାଏ।

- **`--plan`** ମନୋନୀତ ମୋଡ୍ ର ଷ୍ଟେପ୍ ପ୍ରିଣ୍ଟ୍ କରେ ଏବଂ ୱାର୍କଟ୍ରି ସୃଷ୍ଟି ନକରି କିମ୍ବା ରିମୋଟ ସହିତ ଯୋଗାଯୋଗ ନକରି ପ୍ରସ୍ଥାନ କରେ। ଦ୍ରୁତ ଯୋଜନା ଯାଞ୍ଚ କରିବାକୁ ଏହାକୁ `--fast` ସହିତ ମିଶାନ୍ତୁ।
- **`--fast`** ସାଧାରଣ ଷ୍ଟାଟିକ୍ ଗେଟ୍ସ, `tests/unit/` ଅନ୍ତର୍ଗତ ମନୋନୀତ ପରିବର୍ତ୍ତିତ `node:test` ଫାଇଲଗୁଡ଼ିକୁ ଚଲାଇଥାଏ, ଏବଂ `npm run test:vitest`। ଦ୍ରୁତ ମୋଡ୍ ବ୍ୟବହାର କରିବା ସମୟରେ ଜମା ହୋଇଥିବା ଟିପ୍ ଉପରେ ଦିନକୁ ଅତି କମରେ ଏକ ପୂର୍ଣ୍ଣ ସ୍ଥାନୀୟ ବ valid ଧତା ଚଲାନ୍ତୁ।
- **ପୂର୍ଣ୍ଣ ମୋଡ୍।** ପୂର୍ଣ୍ଣ-କେବଳ ଷ୍ଟାଟିକ୍ ଗେଟ୍ ଯୋଗ କରେ ଏବଂ `npm run test:unit` ଏବଂ `npm run test:vitest` ଚଲାଇଥାଏ।

## `merge-train.sh` ପାଇଁ ସତେଜ-ଚେକଆଉଟ୍ ପୂର୍ବ ସର୍ତ୍ତ।

ୱାର୍କଟ୍ରି ସୃଷ୍ଟି କରିବା ପୂର୍ବରୁ ପ୍ରିଫ୍ଲାଇଟ୍ ଚାଲିଥାଏ। `npm ci` ସହିତ ନିର୍ଭରଶୀଳତା ସଂସ୍ଥାପନ କରନ୍ତୁ। ନିଶ୍ଚିତ କରନ୍ତୁ ଯେ `node_modules/.bin/tsc` ଏକଜେକ୍ୟୁଟେବଲ୍ ଏବଂ `node_modules/node_modules` ଅନୁପସ୍ଥିତ। `node_modules/.bin/bun --version` ସଫଳ ହୋଇଛି କି ନାହିଁ ଯାଞ୍ଚ କରନ୍ତୁ।

ଯଦି Bun ପୋଷ୍ଟଇନଷ୍ଟଲକୁ ଛାଡ଼ିଦିଆଯାଏ, `(cd node_modules/bun && node install.js)` ଚଲାନ୍ତୁ। ପ୍ରଦାନକାରୀ ସ୍ଥିରତା ଏବଂ ଜଣାଶୁଣା-ପ୍ରତୀକ ଯାଞ୍ଚଗୁଡ଼ିକ Bun ବ୍ୟବହାର କରନ୍ତି। ବ valid ଧତାକାରୀ ଏକ ଅବରୋଧକାରୀ ଗେଟ୍ ଭାବରେ `npm run check:cycles:ratchet` ଚଲାଇଥାଏ। ସ୍ୱତନ୍ତ୍ର `npm run check:cycles` ନିର୍ଦ୍ଦେଶ ପରାମର୍ଶଦାତା ଅଟେ।
