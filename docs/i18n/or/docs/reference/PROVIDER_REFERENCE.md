## ଶ୍ରେଣୀଗୁଡ଼ିକ

- **ମାଗଣା** — API କି ସହିତ ମାଗଣା ଟାୟର୍ (ଡ୍ୟାସବୋର୍ଡ ମାଧ୍ୟମରେ ବିନ୍ୟାସିତ)
- **ପ୍ରମାଣୀକରଣ ନାହିଁ** — ସାର୍ବଜନୀନ ଏଣ୍ଡପଏଣ୍ଟ ଯାହାକୁ କୌଣସି କିମ୍ବା ସାଇନ୍-ଇନ୍ ଆବଶ୍ୟକ ନାହିଁ
- **OAuth** — OmniRoute ଦ୍ୱାରା ପରିଚାଳିତ ସାଇନ୍-ଇନ୍ ଫ୍ଲୋ, କୌଣସି API କି ଆବଶ୍ୟକ ନାହିଁ
- **ୱେବ୍ କୁକି** — ପ୍ରଦାନକାରୀଙ୍କ ୱେବ୍ ଆପ୍ କୁକି ପ୍ରମାଣୀକରଣ ମାଧ୍ୟମରେ ରାପ୍ କରେ
- **API କି** — API କି ମାଧ୍ୟମରେ ବିନ୍ୟାସିତ ଦେୟଯୁକ୍ତ ପ୍ରଦାନକାରୀ (ମାଗଣା କ୍ରେଡିଟ୍ ପ୍ରଯୁଜ୍ୟ ହୋଇପାରେ)
- **ସ୍ଥାନୀୟ** — ଉପଭୋକ୍ତାଙ୍କ ମେସିନରେ ଚାଲୁଛି (Ollama, LM Studio, vLLM, ଇତ୍ୟାଦି)
- **ସନ୍ଧାନ** — ୱେବ୍ ସନ୍ଧାନ ପ୍ରଦାନକାରୀ
- **ଅଡିଓ** — କେବଳ ଅଡିଓ ପ୍ରଦାନକାରୀ (TTS/STT)
- **ଅପଷ୍ଟ୍ରିମ୍ ପ୍ରକ୍ସି** — ଅନ୍ୟ ପ୍ରଦାନକାରୀଙ୍କୁ ପ୍ରକ୍ସି କରୁଥିବା ପ୍ରଦାନକାରୀ
- **କ୍ଲାଉଡ୍ ଏଜେଣ୍ଟ** — ଦୀର୍ଘ ସମୟ ଧରି ଚାଲୁଥିବା କୋଡିଂ ଏଜେଣ୍ଟ (Codex Cloud, Devin, Jules)
- **ସିଷ୍ଟମ୍** — OmniRoute-ଆଭ୍ୟନ୍ତରୀଣ ପ୍ରଦାନକାରୀ (ଲୁପବ୍ୟାକ୍, ଇତ୍ୟାଦି)

ଅତିରିକ୍ତ ଟ୍ୟାଗ୍: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`।

`ଟୁଲ୍ କଲିଂ` (ଯେଉଁଠାରେ ଦେଖାଯାଏ): `native` — ପ୍ରକୃତ ଫଙ୍କସନ୍-କଲିଂ API; `emulated` — `tools` ଆରେ `webTools.ts` (regex-parsed `<tool>{...}</tool>` ବ୍ଲକ) ମାଧ୍ୟମରେ ପ୍ରମ୍ପ୍ଟ-ଏମୁଲେଟେଡ୍ ହୋଇଛି; `none` — `tools` ବର୍ତ୍ତମାନ ନୀରବରେ ଛାଡି ଦିଆଯାଇଛି। #7286 ଦେଖନ୍ତୁ।

ପ୍ରତ୍ୟେକ ପ୍ରଦାନକାରୀଙ୍କୁ ସକ୍ଷମ, ବିନ୍ୟାସ ଏବଂ ପରୀକ୍ଷା କରିବା ପାଇଁ `/dashboard/providers` ରେ ଡ୍ୟାସବୋର୍ଡ ବ୍ୟବହାର କରନ୍ତୁ।
