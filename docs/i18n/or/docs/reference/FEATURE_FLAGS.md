## ଫିଚର୍ ଫ୍ଲାଗ୍ କ'ଣ

ଏକ ଫିଚର୍ ଫ୍ଲାଗ୍ ହେଉଛି ଏକ ନାମିତ ଟଗଲ୍ (ବୁଲିଆନ୍ କିମ୍ବା ଏନମ୍) ଯାହାର ମୂଲ୍ୟ ରନଟାଇମ୍ ରେ ପରିବର୍ତ୍ତନ କରାଯାଇପାରିବ ଏବଂ ଡାଟାବେସ୍ ରେ ସ୍ଥାୟୀ ଭାବରେ ସଂରକ୍ଷିତ ହୋଇପାରିବ, କୌଣସି ପ୍ରକ୍ରିୟା ରିଡିପ୍ଲୟ ଆବଶ୍ୟକ ନାହିଁ। ପ୍ରତ୍ୟେକ ଫ୍ଲାଗ୍ ଏକ `FeatureFlagDefinition` ଦ୍ୱାରା ବର୍ଣ୍ଣିତ ହୋଇଥାଏ ଯେଉଁଥିରେ ଏକ `key`, `label`, `description`, `category`, `defaultValue`, `type`, ଏବଂ ଏକ `requiresRestart` ସୂଚନା ଥାଏ।

### ରିଜୋଲ୍ୟୁସନ୍ ଅର୍ଡର

ଏକ ଫ୍ଲାଗ୍ ର **ପ୍ରଭାବଶାଳୀ ମୂଲ୍ୟ** ଏହି ପ୍ରାଧାନ୍ୟ (ସର୍ବୋଚ୍ଚ ବିଜୟ) ସହିତ
[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) ଦ୍ୱାରା ରିଜୋଲ୍ଭ କରାଯାଏ:

1.  **DB override** — `key_value` ଟେବୁଲ୍ ରେ `feature_flags` ନାମସ୍ପେସ୍ ଅଧୀନରେ ସଂରକ୍ଷିତ ଏକ ମୂଲ୍ୟ (ଡ୍ୟାସବୋର୍ଡ କିମ୍ବା REST API ମାଧ୍ୟମରେ ସେଟ୍ କରାଯାଇଛି)।
2.  **ପରିବେଶ ଭେରିଏବଲ୍** — `process.env[<KEY>]`, ଯଦି ସେଟ୍ ହୋଇଛି ଏବଂ ଖାଲି ନୁହେଁ।
3.  **ଡେଫିନିସନ୍ ଡିଫଲ୍ଟ** — `featureFlagDefinitions.ts` ରୁ `defaultValue`।

ଏକ ବୁଲିଆନ୍ ଫ୍ଲାଗ୍ **ସକ୍ଷମ** ବୋଲି ବିବେଚନା କରାଯାଏ ଯେତେବେଳେ ଏହାର ପ୍ରଭାବଶାଳୀ ମୂଲ୍ୟ `"true"`, `"1"`, କିମ୍ବା `"yes"` ହୋଇଥାଏ (`isFeatureFlagEnabled()` ଦେଖନ୍ତୁ)।

> [!NOTE]
> ଅଧିକାଂଶ ଫ୍ଲାଗ୍ ରେ [`ENVIRONMENT.md`](./ENVIRONMENT.md) ରେ ଡକ୍ୟୁମେଣ୍ଟ୍ ହୋଇଥିବା **ସମାନ ନାମ** ର ଏକ ମେଳ ଖାଉଥିବା ପରିବେଶ ଭେରିଏବଲ୍ ମଧ୍ୟ ଥାଏ। ଫ୍ଲାଗ୍ ର DB ଓଭରରାଇଡ୍ ସେହି ପରିବେଶ ଭେରିଏବଲ୍ ଉପରେ ପ୍ରାଧାନ୍ୟ ନେଇଥାଏ। `requiresRestart: true` ଥିବା ଏକ ଫ୍ଲାଗ୍ ତୁରନ୍ତ ସ୍ଥାୟୀ ହୋଇଥାଏ କିନ୍ତୁ କେବଳ ପ୍ରକ୍ରିୟା ଆରମ୍ଭରେ ପୁନଃ ପଢ଼ାଯାଏ — ଏହାକୁ ଟଗଲ୍ କରିବା ଦ୍ୱାରା ଡ୍ୟାସବୋର୍ଡରେ ଏକ **"ସର୍ଭର ପୁନଃ ଆରମ୍ଭ କରନ୍ତୁ"** ବ୍ୟାନର୍ ଦେଖାଯାଏ।

## ପତାକା ଟୋଗଲ୍ କରିବା।

### ଡ୍ୟାସବୋର୍ଡ।

କୁ ନେଭିଗେଟ୍ କରନ୍ତୁ।** ଡ୍ୟାସବୋର୍ଡ → ସେଟିଂସମୂହ → ବ ature ଶିଷ୍ଟ୍ୟ ପତାକା।** (`/dashboard/settings/feature-flags`) ଗ୍ରୀଡ୍ (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`) ସମର୍ଥନ କରେ:

- **ସନ୍ଧାନ କର।** କି କିମ୍ବା ବର୍ଣ୍ଣନା ଦ୍ୱାରା, ଏବଂ** ଫିଲ୍ଟର୍** ବର୍ଗ ଅନୁଯାୟୀ (ଏକ ସିନ୍ଥେଟିକ୍ ସହିତ।** ପୁନ Rest ଆରମ୍ଭ ଆବଶ୍ୟକ କରେ।** ଦର୍ଶନ)।
- କ** ଟୋଗଲ୍ କରନ୍ତୁ।** ବୁଲିଆନ୍ ପତାକା ଏବଂ a** ଡ୍ରପଡାଉନ୍** enum flags (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`) ପାଇଁ।
- କ** ଉତ୍ସ ବ୍ୟାଜ୍** ପ୍ରତି ଫ୍ଲାଗ୍ — `DB`, `ENV`, କିମ୍ବା `DEF` — ଦର୍ଶାଉଛି ଯେ ପ୍ରଭାବଶାଳୀ ମୂଲ୍ୟ କେଉଁଠୁ ଆସିଛି।
- କ** ପୁନ et ସେଟ୍ କରନ୍ତୁ।** ଓଭରବାଇଡ୍ ଡ୍ରପ୍ କରିବାକୁ ବଟନ୍ (କେବଳ `DB` -sourced ଫ୍ଲାଗ୍ସ ପାଇଁ ଦେଖାଯାଏ), ଏବଂ a** ସମସ୍ତ ଓଭରବ୍ରିଡ୍ ପୁନ Res ସେଟ୍ କରନ୍ତୁ।** ତଳେ ଥିବା ବଟନ୍।
- କ** ସର୍ଭରକୁ ପୁନ Rest ଆରମ୍ଭ କରନ୍ତୁ।** ଯେତେବେଳେ ଏକ `requiresRestart` ପତାକା ପରିବର୍ତ୍ତନ ହୁଏ ବ୍ୟାନର।

### REST API

ସମସ୍ତ ଅପରେସନ୍ ଗୋଟିଏ ମାର୍ଗ ଦେଇ ଗତି କରେ: [`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts)। ପ୍ରତ୍ୟେକ ପଦ୍ଧତି ଏକ ପ୍ରାମାଣିକ ଡ୍ୟାସବୋର୍ଡ ଅଧିବେଶନ ଆବଶ୍ୟକ କରେ (ଅନ୍ୟଥା`401` )।

ଲଗଇନ୍ ଅକ୍ଷମ ହେବା ସହିତ (`requireLogin=false`) ସଂରକ୍ଷିତ ପତାକା ବ୍ୟତୀତ ମାର୍ଗ ଖୋଲା ଅଛି: ସୁରକ୍ଷା ବର୍ଗର ପ୍ରତ୍ୟେକ ପତାକା `OMNIROUTE_ALLOW_PRIVATE_PROVIDER_URLS`, `OMNIROUTE_ALLOW_LOCAL_PROVIDER_URLS`, `MITM_DISABLE_TLS_VERIFY`, `OMNIROUTE_MCP_ENFORCE_SCOPES` ଏବଂ `SKILLS_SANDBOX_NETWORK_ENABLED` ( `protectedFeatureFlags.ts` ରେ`isProtectedFeatureFlag()` )। ସେମାନଙ୍କ ମଧ୍ୟରୁ ଗୋଟିଏ ଉପରେ `PUT`, ଏବଂ ଗୋଟିଏ `DELETE` ଥିବାବେଳେ ସେମାନଙ୍କ ମଧ୍ୟରୁ ଗୋଟିଏରେ DB ଓଭରଡାଇଡ୍ ଅଛି, ତଥାପି ଏକ ଡ୍ୟାସବୋର୍ଡ ଅଧିବେଶନ, ଏକ `manage` -scope API ଚାବି, ଲେଖା ପରିସର କିମ୍ବା ଅଧିକ ସହିତ `oma_` ପ୍ରବେଶ ଟୋକେନ୍, କିମ୍ବା ଲୁକବ୍ୟାକ୍ ରୁ ପଠାଯାଇଥିବା CLI ଟୋକେନ୍ କିମ୍ବା ଆଭ୍ୟନ୍ତରୀଣ ସେବା ଟୋକେନ୍ ଆବଶ୍ୟକ। ସେହି ସେଟ୍ ଲଗଇନ୍ ଅପେକ୍ଷା ଅଧିକ ପ୍ରଶସ୍ତ, ଯେଉଁଠାରେ ମାର୍ଗ କେବଳ ଏକ ଅଧିବେଶନ କିମ୍ବା `manage` -scope କି ଗ୍ରହଣ କରେ।

#### `GET /api/settings/feature-flags`

ପ୍ରତ୍ୟେକ ପତାକାକୁ ଏହାର ପ୍ରଭାବଶାଳୀ ମୂଲ୍ୟ, ଉତ୍ସ ଏବଂ ଏକ ସାରାଂଶ ସହିତ ଫେରସ୍ତ କରେ।

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Require API Key",
      "description": "Require an API key for all incoming requests",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... all 119 flags
  ],
  "summary": {
    "total": 119,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

ଗୋଟିଏ ଓଭରବ୍ରିଡ୍ ସେଟ୍ କିମ୍ବା ଅପସାରଣ କରନ୍ତୁ। ଶରୀର: `{ key: string; value?: string }` `value` ଛାଡିବା ଦ୍ୱାରା ଓଭରବ୍ରିଡ୍ ଅପସାରଣ ହୁଏ (env / default ପୁନରୁଦ୍ଧାର)।

```bash
# Set a DB override
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# Remove the override (no "value")
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

ପ୍ରତିକ୍ରିୟା ନୂତନ `effectiveValue`/`source`, `previousValue`/ `previousSource`, ଏବଂ `requiresRestart` କୁ ପ୍ରତିଫଳିତ କରେ। ଅଜ୍ known ାତ କି ଏବଂ ଆଉଟ-ରେ range ୍ଜ enum ମୂଲ୍ୟଗୁଡ଼ିକ `400` ସହିତ ପ୍ରତ୍ୟାଖ୍ୟାନ।

#### `DELETE /api/settings/feature-flags`

ସଫା** ସମସ୍ତ** DB ଏକାସାଙ୍ଗରେ ଅତିକ୍ରମ କରେ, ପ୍ରତ୍ୟେକ ପତାକାକୁ ଏହାର env / ଡିଫଲ୍ଟ ମୂଲ୍ୟରେ ପୁନ oring ସ୍ଥାପିତ କରେ। `{ cleared: <count>, message: "..." }` ଫେରସ୍ତ କରେ

> [!NOTE]
> `requiresRestart: true` ସହିତ ପତାକା କେବଳ ଏକ ପ୍ରକ୍ରିୟା ପୁନ o ଲୋଡ୍ ପରେ କାର୍ଯ୍ୟକାରୀ ହୁଏ। ଡ୍ୟାସବୋର୍ଡର ପୁନ rest ଆରମ୍ଭ ପ୍ରବାହ `POST /api/restart` କଲ୍ କରେ ଏବଂ ସର୍ଭର ବ୍ୟାକଅପ୍ ନହେବା ପର୍ଯ୍ୟନ୍ତ `GET /api/health/ping` ପୋଲ୍ କରେ।

## ଜରୁରୀକାଳୀନ ବଜେଟ୍ ଫଲ୍ବ୍ୟାକ୍

`OMNIROUTE_EMERGENCY_FALLBACK` (ଶ୍ରେଣୀ `runtime`, ଡିଫଲ୍ଟ `true`)
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts)ରେ ଥିବା
ଜରୁରୀକାଳୀନ ମାଗଣା ଫଲ୍ବ୍ୟାକ୍ ପଥକୁ ନିୟନ୍ତ୍ରଣ କରେ।
ଏହା ସକ୍ଷମ ଥିବାବେଳେ, ଯେଉଁ ଅନୁରୋଧଗୁଡ଼ିକର ବଜେଟ୍ ଶେଷ ହୋଇଯାଏ, ସେଗୁଡ଼ିକୁ ସିଧାସଳଖ ବିଫଳ କରିବା ପରିବର୍ତ୍ତେ ଏକ ମାଗଣା ଫଲ୍ବ୍ୟାକ୍
ପ୍ରଦାନକାରୀ/ମଡେଲ୍କୁ ରାଉଟ୍ କରାଯାଏ। ଏହି ଆଚରଣକୁ ଅକ୍ଷମ କରିବା ଏବଂ ବଜେଟ୍ ଶେଷ ହୋଇଥିବା ଅନୁରୋଧଗୁଡ଼ିକୁ
ବିଫଳ ହେବାକୁ ଦେବା ପାଇଁ, ଡ୍ୟାସ୍ବୋର୍ଡ ଟଗଲ୍, ଏକ DB ଓଭର୍ରାଇଡ୍ କିମ୍ବା
`OMNIROUTE_EMERGENCY_FALLBACK` ପରିବେଶ ଭେରିଏବଲ୍ ମାଧ୍ୟମରେ ଏହାକୁ `false` (କିମ୍ବା `0`)ରେ ସେଟ୍ କରନ୍ତୁ।
(PR #3741 / #3752ରେ ଏକ ଡ୍ୟାସ୍ବୋର୍ଡ ଟଗଲ୍ ଭାବେ ଉପଲବ୍ଧ କରାଯାଇଛି।)

ଏହି ଫଲ୍ବ୍ୟାକ୍ ଦ୍ୱାରା ପ୍ରଦାନ କରାଯାଇଥିବା ପ୍ରତିକ୍ରିୟାରେ
`X-OmniRoute-Emergency-Fallback: from=<provider/model>; to=<provider/model>` ଥାଏ, ଯାହାଫଳରେ ଏକ
କ୍ଲାଏଣ୍ଟ୍ ନିଜ ଅନୁରୋଧ ସହିତ `X-OmniRoute-Provider`ର ପାର୍ଥକ୍ୟ ତୁଳନା ନକରି ମଧ୍ୟ ଏହା ପୁନଃରାଉଟ୍ କରାଯାଇଥିବା ଜାଣିପାରେ।
ଅନ୍ୟ ପ୍ରତ୍ୟେକ ପ୍ରତିକ୍ରିୟାରେ ଏହି ହେଡର୍ ଅନୁପସ୍ଥିତ ଥାଏ।
