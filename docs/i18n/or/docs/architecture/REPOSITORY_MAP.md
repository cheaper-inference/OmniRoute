> କୋଡବେସ୍ ଚାରିପାଖରେ ଆପଣଙ୍କର ରାସ୍ତା ଖୋଜିବା ପାଇଁ ଏହି ମାନଚିତ୍ର ବ୍ୟବହାର କରନ୍ତୁ, ତାପରେ ଉତ୍ସର୍ଗୀକୃତ ଡକଗୁଡିକର ଲିଙ୍କଗୁଡିକ ଅନୁସରଣ କରନ୍ତୁ। ଉପରୋକ୍ତ ତାରିଖ ଉପରେ `git ls-files` ସହିତ ଫାଇଲ୍ ଗଣନା କରାଯାଇଥିଲା। ସେମାନେ ପ୍ରାୟ ପ୍ରତ୍ୟେକ ପ୍ରକାଶନ ସହିତ ପରିବର୍ତ୍ତନ କରନ୍ତି, ତେଣୁ ସେମାନଙ୍କୁ ବଡ଼ତାର ଆଦେଶ ଭାବରେ ବ୍ୟବହାର କରନ୍ତୁ।

## ଶୀର୍ଷ ସ୍ତରୀୟ ବୃକ୍ଷ।

```
OmniRoute/
├── src/              # Next.js 16 app: dashboard, /api and /v1 routes, server libs, domain, i18n
├── open-sse/         # Streaming engine workspace (@omniroute/open-sse): handlers, executors, translator, services, MCP server
├── packages/         # npm workspaces: ui-kit (vendored Keak CI UI Kit) and browser-pool
├── @omniroute/       # Separately published npm packages (OpenCode plugins and provider)
├── bin/              # Published `omniroute` CLI, MCP/bridge entry points, self-host ops scripts (*.sh)
├── electron/         # Desktop app (Electron main/preload + helpers + icons)
├── public/           # Static assets served by Next.js (provider logos, PWA icons, sw.js, openapi.yaml copy)
├── skills/           # Agent Skills (SKILL.md) served by /api/agent-skills, MCP and A2A
├── tests/            # All test suites: unit, integration, e2e, homolog, fixtures, snapshots
├── scripts/          # Build, quality gates, i18n, release, ops, perf and one-off scripts (allow-listed subfolders)
├── config/           # Versioned config: i18n, payload rules, CLI manifest, quality-gate baselines, release inventories
├── changelog.d/      # Per-PR changelog fragments, aggregated into CHANGELOG.md at release time
├── docs/             # Public documentation (served at /docs via Fumadocs) + translated mirrors in docs/i18n/
├── examples/         # Example plugins and quickstart clients
├── deploy/           # Kubernetes deployment: Helm chart + Kustomize base/overlays
├── docker/           # Auxiliary container images (not the main image, which is the root Dockerfile)
├── contrib/          # Community recipes: Podman quadlets, VPS compose, Windows launchers, session-sync note
├── .github/          # GitHub Actions workflows, composite actions, issue/PR templates, CODEOWNERS, labels
├── .husky/           # Tracked git hooks: commit-msg, pre-commit, pre-push
├── .vale/            # Vale prose-lint vocabulary (styles/Vocab/OmniRoute/accept.txt)
├── .vscode/          # Shared VS Code workspace settings (settings.json)
└── (root files — see below)
```

ସ୍ଥାନୀୟ, ଉତ୍ପାଦିତ କିମ୍ବା ବ୍ୟକ୍ତିଗତ ପଥଗୁଡିକ (ସମସ୍ତ ଗିଟିନୋର୍ଡ୍, କଦାପି ପ୍ରତିବଦ୍ଧ ନୁହେଁ, ଆଗକୁ ବର୍ଣ୍ଣନା କରାଯାଇ ନାହିଁ):

```
node_modules/            # npm dependencies
.build/                  # Next.js build output (default distDir .build/next, see next.config.mjs)
dist/                    # npm staging directory assembled by scripts/build/prepublish.ts
.source/                 # fumadocs-mdx output that feeds the /docs viewer
.husky/_/                # Husky runtime generated on install (core.hooksPath target)
coverage/ logs/ test-results/ playwright-report/   # coverage, runtime logs, Playwright output
.env                     # local secrets generated from .env.example
_*/                      # private local-only folders (anchored /_* ignore); never tracked
.claude/ .agents/        # local AI-assistant state and skills; never tracked
```

## ମୂଳ ଫାଇଲଗୁଡିକ।

ରେପୋଜିଟୋରୀ ରୁଟ୍ (`git ls-files | grep -v /`) ରେ ସମସ୍ତ ଟ୍ରାକ୍ ହୋଇଥିବା ଫାଇଲଗୁଡ଼ିକ, ଫଙ୍କସନ୍ ଦ୍ୱାରା ଗ୍ରୁପ୍ ହୋଇଛି।

### ପ୍ରୋଜେକ୍ଟ ଡକ୍ୟୁମେଣ୍ଟେସନ୍।

| ଫାଇଲ୍।                   | ଉଦ୍ଦେଶ୍ୟ                                                                          |
| ------------------------ | --------------------------------------------------------------------------------- |
| `README.md`              | ଅବତରଣ ପୃଷ୍ଠା: ବ feature ଶିଷ୍ଟ୍ୟ ସମୀକ୍ଷା, ଶୀଘ୍ର ଆରମ୍ଭ, ସଂସ୍ଥାପନ ପଦ୍ଧତି।            |
| `CHANGELOG.md`           | ପ୍ରତି-ରିଲିଜ୍ ଚେଞ୍ଜେଲଗ୍ ( `changelog.d/` ରୁ ଖଣ୍ଡଗୁଡ଼ିକ ଏଠାରେ ଫୋଲ୍ଡ୍ ହୋଇଛି)।        |
| `ROADMAP.md`             | ଜନସାଧାରଣ ରୋଡ୍ ମ୍ୟାପ୍।                                                             |
| `LICENSE`                | MIT ଲାଇସେନ୍ସ।                                                                     |
| `THIRD_PARTY_NOTICES.md` | ବଣ୍ଡଲ୍ ହୋଇଥିବା ତୃତୀୟ-ପକ୍ଷ କୋଡ୍ ପାଇଁ ବିଜ୍ଞପ୍ତିଗୁଡିକ (ଉଦାହରଣ ସ୍ୱରୂପ wreq-js ବନ୍ଧନ)। |
| `CONTRIBUTING.md`        | ଯୋଗଦାନକାରୀ ଗାଇଡ୍: ସେଟଅପ୍, ପାରମ୍ପାରିକ କାର୍ଯ୍ୟ, ପରୀକ୍ଷା ମ୍ୟାଟ୍ରିକ୍ସ, PR ପ୍ରବାହ।     |
| `SECURITY.md`            | ଦୁର୍ବଳତା ରିପୋର୍ଟ ନୀତି।                                                            |
| `CODE_OF_CONDUCT.md`     | ସମ୍ପ୍ରଦାୟର ଆଚରଣ ଆଶା।                                                              |
| `llm.txt`                | LLM କ୍ରଲର୍ ଏବଂ ସହାୟକମାନଙ୍କ ପାଇଁ ସାଧା-ପାଠ୍ୟ ପ୍ରକଳ୍ପ ସାରାଂଶ।                        |

### ପ୍ୟାକେଜ୍ ପ୍ରଦର୍ଶନ ଏବଂ ନୋଡ୍ ଟୁଲ୍ ଚେନ୍।

## `src/` — Next.js ପ୍ରୟୋଗ।

ପ୍ରାୟ 4,550 ଟ୍ରାକ୍ ଫାଇଲ୍। ପଥ ଛଦ୍ମନାମ `@/*` → `src/*`।

```
src/
├── app/                  # App Router: pages, layouts and route handlers (file-convention loaded)
│   ├── (dashboard)/      # Route group for the dashboard: dashboard/<section>/ pages + home widgets
│   ├── api/              # HTTP routes: v1/ (OpenAI-compatible), v1beta/ (Gemini-style), management routes
│   ├── docs/             # Embedded docs viewer (lib/openapi.generated.ts is generated)
│   ├── a2a/ .well-known/ # A2A JSON-RPC entry point and Agent Card discovery
│   ├── healthz/ livez/ readyz/ status/   # Health probes and status page
│   ├── landing/ login/ auth/ authorize/ callback/ connect/   # Public, auth and OAuth pages
│   ├── miniapp/          # Telegram Mini App page
│   └── 400/ … 503/       # Static HTTP error pages
├── lib/                  # Server-side libraries and domain modules (largest folder)
├── shared/               # Code shared by server and client: components, constants, validation, utils
├── sse/                  # Next.js side of the SSE pipeline: handlers/ (chat*), services/ (auth, leases, quotas)
├── mitm/                 # MITM / TPROXY capture: cert/, dns/, handlers/, targets/, inspector/, tproxy/ (C addon)
├── server/               # Server-only: authz/ (route guard pipeline), auth/, cors/, origin/, ws/
├── domain/               # Policy engine, fallback, cost rules, lockout, quota cache, assessment/
├── i18n/                 # next-intl: messages/ (67 locales), global-error-messages/ (generated), routeNamespaces.generated.json
├── store/                # Zustand client stores (theme, notifications, …)
├── hooks/                # Client hooks (live dashboard, compression preview, breaker health)
├── types/                # Ambient and shared type declarations
├── models/               # Compatibility barrel re-exporting db functions
├── middleware/           # promptInjectionGuard.ts (facade over the guardrail system)
├── scripts/              # backfillAggregation.ts (`npm run backfill-aggregation`)
├── proxy.ts              # Next.js 16 proxy: headless gate + authz pipeline for dashboard, /api and /v1-style paths
├── instrumentation.ts    # Next.js instrumentation hook (delegates Node-only work)
└── instrumentation-node.ts   # Node-only startup work
```

```
└── package.json · tsconfig.json · types.d.ts
```
