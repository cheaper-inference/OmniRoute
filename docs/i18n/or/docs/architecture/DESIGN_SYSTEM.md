> **ସ୍ଥିତି:** ଡ୍ୟାସବୋର୍ଡ଼ଟି **Keak CI UI Kit** (`@keak/cheaper-inference-ui-kit`) ଉପରେ ନିର୍ମିତ, ଯାହାକୁ ୱର୍କସ୍ପେସ୍ `packages/ui-kit` (`@omniroute/ui-kit`) ଭାବରେ ଭେଣ୍ଡର କରାଯାଇଛି; ଅପଷ୍ଟ୍ରିମ୍ ସ୍ନାପସଟ୍ `packages/ui-kit/UPSTREAM.md` ରେ ପିନ୍ କରାଯାଇଛି ଏବଂ `npm run check:ui-kit-snapshot` ଦ୍ୱାରା ସୁରକ୍ଷିତ। Light ହେଉଛି ଆଧିକାରିକ ଥିମ୍; ଡିଫଲ୍ଟ ପସନ୍ଦ `system` ଅଟେ। ଆକ୍ସେଣ୍ଟ ହେଉଛି Keak lime (`--ci-color-accent`)। Inter (letter-spacing 0, `--ci-letter-spacing-ui`) ହେଉଛି UI ଫଣ୍ଟ ପରିବାର, Instrument Serif କେବଳ ବଡ଼ ବିରଳ ଡିସପ୍ଲେ ଟେକ୍ସଟ୍ (`.ci-dashboard-display`) ପାଇଁ, IBM Plex Mono କୋଡ୍ ପାଇଁ — ସମସ୍ତ `src/app/globals.css` ର ଶୀର୍ଷରେ ଥିବା `@fontsource/*` ଇମ୍ପୋର୍ଟଗୁଡ଼ିକ ମାଧ୍ୟମରେ ସେଲ୍ଫ-ହୋଷ୍ଟ କରାଯାଇଛି। ପ୍ରତ୍ୟେକ ଆଇକନ୍ ଏକ Lucide ଗ୍ଲିଫ୍ ଅଟେ।

## 1. ଜିନିଷଗୁଡ଼ିକ କେଉଁଠାରେ ଅଛି

- **କିଟ୍।** `packages/ui-kit/src` ହେଉଛି `packages/ui-kit/UPSTREAM.md` ରେ ପିନ୍ କରାଯାଇଥିବା କମିଟ୍ ଅନୁଯାୟୀ ଅପଷ୍ଟ୍ରିମ୍ `src/` ର ବାଇଟ୍-ପାଇ-ବାଇଟ୍ ନକଲ (ଯାହା ଲାଇସେନ୍ସ ଅନୁମତି ମଧ୍ୟ ରେକର୍ଡ କରେ); `PATCHES.md` ସ୍ଥାନୀୟ ପ୍ୟାଚ୍ଗୁଡ଼ିକୁ ତାଲିକାଭୁକ୍ତ କରେ (କିଛି ନାହିଁ)। ଏହା ସୋର୍ସ ଭାବରେ ବ୍ୟବହୃତ ହୁଏ, କୌଣସି ବିଲ୍ଡ ବିନା: `next.config.mjs` ଏହାକୁ ଟ୍ରାନ୍ସପାଇଲ୍ କରେ, ଏବଂ `tsconfig.json` `@omniroute/ui-kit` → `packages/ui-kit/src` ଏବଂ `@omniroute/ui-kit/*` → `packages/ui-kit/src/*` କୁ ମ୍ୟାପ୍ କରେ (`vitest.config.ts` ଏବଂ `vitest.mcp.config.ts` ସମାନ ଏଲିୟାସ୍ ବହନ କରନ୍ତି)। କିଟ୍ କମ୍ପୋନେଣ୍ଟକୁ ତା'ର ସବପାଥ୍ ଦ୍ୱାରା ଇମ୍ପୋର୍ଟ କରନ୍ତୁ (`@omniroute/ui-kit/table`, `@omniroute/ui-kit/page-header`…), କେବେବି `@omniroute/ui-kit` ବ୍ୟାରେଲ୍ ମାଧ୍ୟମରେ ନୁହେଁ: ବ୍ୟାରେଲ୍ ପ୍ରତ୍ୟେକ କମ୍ପୋନେଣ୍ଟ (ଡେଟ୍ ପିକର୍ ସହିତ) ପ୍ରତ୍ୟେକ ଇମ୍ପୋର୍ଟର ଭିତରକୁ ଟାଣି ଆଣେ। କିଟ୍ ଷ୍ଟାଇଲସିଟ୍ `src/app/globals.css` ମାଧ୍ୟମରେ ପ୍ରବେଶ କରେ (`@import "../../packages/ui-kit/src/ci-ui.css"`)।
- **ଟୋକେନ୍।** `packages/ui-kit/src/ci-tokens.css` `--ci-*` ଟୋକେନ୍ଗୁଡ଼ିକୁ ଘୋଷଣା କରେ; `src/app/globals.css` ସେଗୁଡ଼ିକୁ ଲିଗାସି OmniRoute ନାମ (`--color-*`, `--radius-*`, `--font-sans`/`--font-mono`, `--table-*`, `--orch-status-*`, `--color-fd-*`) ସହିତ ସେତୁବନ୍ଧ କରେ, ଯାହାଫଳରେ ବିଦ୍ୟମାନ `var(--color-*)` ପଢ଼ା ଏବଂ Tailwind ୟୁଟିଲିଟିଗୁଡ଼ିକ କାମ କରିବା ଜାରି ରଖନ୍ତି। ନୂଆ କୋଡ୍ Tailwind ୟୁଟିଲିଟି (`bg-surface`, `text-text-muted`, `border-border`, `text-success`, `bg-success-bg`, `bg-chart-1`…) କିମ୍ବା କିଟ୍ କ୍ଲାସ୍ ବ୍ୟବହାର କରେ — କେବେବି ହେକ୍ସ ମୂଲ୍ୟ ନୁହେଁ (`tests/unit/design-kit-bridge.test.ts` ବ୍ରିଜ୍କୁ ବାଧ୍ୟାତ୍ମକ କରେ)। `text-primary` `--text-color-primary` ମାଧ୍ୟମରେ `--color-primary-ink` କୁ ସମାଧାନ ହୁଏ (ଲାଇଟ୍ରେ lime-800, ଡାର୍କରେ ଲାଇମ୍ ଆକ୍ସେଣ୍ଟ), ଯାହାଫଳରେ ପ୍ରାଇମାରି ଟେକ୍ସଟ ପଢ଼ନୀୟ ରହେ ଯେତେବେଳେ `bg-primary`/`border-primary` ଲାଇମ୍ ସର୍ଫେସ୍ ରଖନ୍ତି। ଚାର୍ଟ ସିରିଜ୍ଗୁଡ଼ିକ `--color-chart-1` … `--color-chart-5` ବ୍ୟବହାର କରନ୍ତି।
- **ଥିମ୍।** `<html className="ci-theme">` (`src/app/layout.tsx`) ଡକ୍ୟୁମେଣ୍ଟକୁ କିଟ୍ ଥିମ୍ରେ ଅପ୍ଟ୍-ଇନ୍ କରେ। ପସନ୍ଦଟି ହେଉଛି `light`, `dark` କିମ୍ବା `system` (`src/shared/constants/appConfig.ts` ରେ `THEME_CONFIG.defaultTheme = "system"`; `system` `prefers-color-scheme` ଅନୁସରଣ କରେ)। `src/store/themeStore.ts` ରେ `applyTheme()` (`src/app/layout.tsx` ରେ ଇନଲାଇନ୍ ବୁଟଷ୍ଟ୍ରାପ୍ ସ୍କ୍ରିପ୍ଟ ଦ୍ୱାରା ଦର୍ପଣିତ, ଯାହା ହାଇଡ୍ରେସନ୍ ପୂର୍ବରୁ ଚାଲେ) `data-theme="dark"|"light"` ସେଟ୍ କରେ ଏବଂ `<html>` ଉପରେ `.dark` କ୍ଲାସ୍କୁ ଏକାସାଥେ ଟୋଗଲ୍ କରେ। କିଟ୍ର ଡାର୍କ ଟୋକେନ୍ ସେଟ୍ `data-theme="dark"` ଉପରେ କୀ କରାଯାଇଛି (`packages/ui-kit/src/ci-tokens.css`); OmniRoute ର ନିଜସ୍ୱ ଡାର୍କ ଓଭରରାଇଡ୍ (`globals.css` ରେ `.dark` ବ୍ଲକ୍) ଏବଂ ଲିଗାସି Tailwind `dark:` ୟୁଟିଲିଟିଗୁଡ଼ିକ `.dark` କ୍ଲାସ୍ ଉପରେ କୀ ହୋଇଛନ୍ତି। କୌଣସି ଆକ୍ସେଣ୍ଟ ରଙ୍ଗ ପ୍ରିସେଟ୍ ନାହିଁ: ଆକ୍ସେଣ୍ଟ ସର୍ବଦା କିଟ୍ରୁ ଆସେ, ଏବଂ ପୁରୁଣା ବିଲ୍ଡର ସଂରକ୍ଷିତ ପ୍ରିସେଟ୍ ଷ୍ଟୋର ଲୋଡ୍ ହେବା ବେଳେ ବାଦ୍ ଦିଆଯାଏ।
- **କମ୍ପୋନେଣ୍ଟ (ଆଡାପ୍ଟର)।** `src/shared/components/index.tsx` OmniRoute କମ୍ପୋନେଣ୍ଟ API ରଖେ (ସମାନ ନାମ, ଡିଫଲ୍ଟ ଏକ୍ସପୋର୍ଟ ଏବଂ props), ଏବଂ ଏହା ପଛରେ ଥିବା ପ୍ରାଇମିଟିଭ୍ଗୁଡ଼ିକ କିଟ୍ ଉପରେ ଆଡାପ୍ଟର ଅଟନ୍ତି: ଫର୍ମ (`Button`, `Input`, `Textarea`, `Checkbox`, `Select`, `Toggle`, `Badge`, `Card`), ଓଭରଲେ ଏବଂ ଫିଡବ୍ୟାକ୍ (`Modal`/`ConfirmModal`, `Tooltip`/`InfoTooltip`, `NotificationToast`, `EmptyState`, `Loading`), ସ୍ଟ୍ରକ୍ଚର (`Collapsible`, `CollapsibleSection`, `SegmentedControl`, `Breadcrumbs`, `Avatar`) ଏବଂ ଟେବୁଲ୍ (`DataTable`, `FilterBar`, `ColumnToggle`, `FilterPills`, `PresetSlider`)। ଏକ ଆଡାପ୍ଟର କିଟ୍ କମ୍ପୋନେଣ୍ଟକୁ ସବପାଥ୍ ଦ୍ୱାରା ଇମ୍ପୋର୍ଟ କରେ ଏବଂ ଲିଗାସି props କୁ ଏହା ଉପରକୁ ମ୍ୟାପ୍ କରେ — ଉଦାହରଣ ସ୍ୱରୂପ `Button variant="primary"` ହେଉଛି କିଟ୍ `default` ବଟନ୍ (`--ci-button-primary-*`: ଲାଇଟ୍ରେ ବିପରୀତ ସର୍ଫେସ୍, ଡାର୍କରେ ତା'ର `--ci-color-accent-foreground` ଇଙ୍କ ସହିତ ଆକ୍ସେଣ୍ଟ), `danger` ହେଉଛି `destructive`, ଏବଂ `warning` ହେଉଛି `outline` ଏବଂ `.ci-button--warning` ଏକ୍ସଟେନସନ୍। `globals.css` ଶେଷରେ ଥିବା `.ci-button--warning` ଏବଂ `.ci-badge[data-tone]` ନିୟମଗୁଡ଼ିକ (`@layer components`) କିଟ୍ କ୍ଲାସ୍ ଉପରେ OmniRoute ଏକ୍ସଟେନସନ୍ ଅଟନ୍ତି। `tests/unit/ui/adapters/*.test.tsx` ପ୍ରତ୍ୟେକ ଆଡାପ୍ଟରକୁ ପିନ୍ କରନ୍ତି।
- **ସେଲ୍।** `src/app/(dashboard)/layout.tsx` `DashboardLayout` ରେଣ୍ଡର କରେ, ଯାହା `src/shared/components/layouts/DashboardShell.tsx` ରେଣ୍ଡର କରେ: କିଟ୍ `SidebarProvider` / `Sidebar` / `SidebarInset` (`packages/ui-kit/src/sidebar.tsx`), `src/shared/components/Sidebar.tsx` ରେ OmniRoute ର ନେଭିଗେସନ୍ ଲଜିକ୍ ସହିତ। `#main-content` କୁ ଯାଉଥିବା ଏକ "ବିଷୟବସ୍ତୁକୁ ଯାଅ" ଲିଙ୍କ ପ୍ରଥମ ଫୋକସଯୋଗ୍ୟ ଉପାଦାନ ଅଟେ। `src/shared/components/Header.tsx` କିଟ୍ `SidebarTrigger` (ସେଲ୍ର ଏକମାତ୍ର ସାଇଡବାର୍ ଟୋଗଲ୍), Keak `ProductSwitcher` ଏବଂ କମାଣ୍ଡ-ପ୍ୟାଲେଟ୍ ଖୋଲାଳି ଧାରଣ କରେ; ଏହା କେବଳ ରାଉଟ୍ ଶୀର୍ଷକ ଦେଖାଏ ଯେତେବେଳେ `#main-content` ଭିତରେ କୌଣସି କିଟ୍ `PageHeader` (`.ci-page-header`) ମାଉଣ୍ଟ ହୋଇନଥାଏ, ଯାହାଫଳରେ ନିଜସ୍ୱ `PageHeader` ଥିବା ପେଜ୍ରେ ଗୋଟିଏ `h1` ଥାଏ। `src/shared/components/CommandPalette.tsx` ଏକ କିଟ୍ `Dialog` ଅଟେ।

   ପୁନରାବୃତ୍ତି କରୁଥିବା `dark:` ଭେରିଆଣ୍ଟ ନାହିଁ।
5. ଟେକ୍ସ୍ଟ: ପ୍ରତ୍ୟେକ ଷ୍ଟ୍ରିଙ୍ଗ୍, ଆପଣ କିଟ୍ କମ୍ପୋନେଣ୍ଟଗୁଡ଼ିକୁ ଦେଉଥିବା ଲେବଲ୍ଗୁଡ଼ିକ ସହିତ,
   `useTranslations` ରୁ ଆସେ। ନୂତନ କିଗୁଡ଼ିକ `src/i18n/messages/en.json`, `pt-BR.json` ଏବଂ
   `vi.json` ରେ ଯାଏ (ଭିଏତନାମୀ ପାରିଟି ଟେଷ୍ଟ ପ୍ରତ୍ୟେକ ଇଂରାଜୀ କିକୁ ପିନ୍ କରେ); ଅନ୍ୟ
   ଲୋକେଲ୍ଗୁଡ଼ିକ i18n ସିଙ୍କ୍ ଦ୍ୱାରା ପୂରଣ ହୁଏ।
6. PR ପୂର୍ବରୁ ଗାର୍ଡଗୁଡ଼ିକ ଚଲାନ୍ତୁ: `tests/unit/dashboard-kit-sweep.test.ts`,
   `tests/unit/icon-map-coverage.test.ts`, `tests/unit/icon-map-object-values.test.ts`,
   `npm run check:dashboard-typecheck` (`iconMap.ts` ରେ ନକଲ ଆମଦାନୀକୁ ଧରୁଥିବା ଏକମାତ୍ର ଯାଞ୍ଚ),
   `npm run check:ui-icu`, ଏବଂ ସ୍କ୍ରିନର ନିଜ ଟେଷ୍ଟଗୁଡ଼ିକ।

## 4. ଆଡାପ୍ଟର ଯୋଡ଼ିବା କିମ୍ବା ପରିବର୍ତ୍ତନ କରିବା

1. `src/shared/components/index.tsx` ର ପବ୍ଲିକ୍ API ଅପରିବର୍ତ୍ତିତ ରଖନ୍ତୁ: ସମାନ ଏକ୍ସପୋର୍ଟ ନାମ, ଡିଫଲ୍ଟ ଏକ୍ସପୋର୍ଟ ଏବଂ
   ଗ୍ରହଣୀୟ ପ୍ରପ୍ସ। ଆଡାପ୍ଟର ଭିତରେ ଲେଗାସି ପ୍ରପ୍ସଗୁଡ଼ିକୁ କିଟ୍ ଉପରକୁ ମ୍ୟାପ୍ କରନ୍ତୁ (ଦେଖନ୍ତୁ `Button.tsx`: `VARIANT_TO_KIT`,
   `SIZE_TO_KIT`)।
2. ସବ୍ପାଥ୍ ଦ୍ୱାରା କିଟ୍ ଇମ୍ପୋର୍ଟ କରନ୍ତୁ (`@omniroute/ui-kit/<component>`)।
3. କିଟ୍ ଗ୍ୟାପ୍ ପାଇଁ ୱାର୍କଆରାଉଣ୍ଡଗୁଡ଼ିକ ଆଡାପ୍ଟରରେ ରହେ (କିମ୍ବା ଯଦି ଫିକ୍ସ ଏକ ଷ୍ଟାଇଲ୍ ହୁଏ, ତେବେ `globals.css` ର
   `@layer components` ରେ), କେବେବି `packages/ui-kit/src` ରେ ନୁହେଁ।
4. `tests/unit/ui/adapters/<name>.test.tsx` ଯୋଡ଼ନ୍ତୁ କିମ୍ବା ଅଦ୍ୟତନ କରନ୍ତୁ। ଅନେକ କଲର୍ ଥିବା ଆଡାପ୍ଟର ପାଇଁ,
   ପରିବର୍ତ୍ତନ ପୂର୍ବରୁ ଏବଂ ପରେ ରେଣ୍ଡର୍ ହୋଇଥିବା ମାର୍କଅପ୍ ତୁଳନା କରନ୍ତୁ — ପ୍ୟାଡିଂ କିମ୍ବା ର୍ୟାପର୍ ପରିବର୍ତ୍ତନଗୁଡ଼ିକ ପ୍ରତ୍ୟେକ ସ୍କ୍ରିନକୁ ବ୍ୟାପିଯାଏ।

## 5. କିଟ୍ ଅଦ୍ୟତନ କରିବା

`scripts/dev/sync-ui-kit.sh <commit> [clone]` ସେହି କମିଟ୍ରେ ଥିବା ଅପ୍ଷ୍ଟ୍ରିମ୍ `src/` କୁ
`packages/ui-kit/src` ଭିତରକୁ କପି କରେ ଏବଂ ଏକମାତ୍ର ଅନୁମୋଦିତ ରୂପାନ୍ତରଣ ପ୍ରୟୋଗ କରେ (ଏହା ରିଲେଟିଭ୍
ଇମ୍ପୋର୍ଟଗୁଡ଼ିକରୁ `.js` ସଫିକ୍ସ ହଟାଏ)। ତାପରେ: `git diff packages/ui-kit` ସମୀକ୍ଷା କରନ୍ତୁ, ଉଭୟ ଥିମ୍ରେ
ପ୍ରୋଭାଇଡର୍ସ, ସେଟିଂସ୍, କମ୍ବୋସ୍, ବ୍ୟବହାର ଏବଂ ଏଣ୍ଡପଏଣ୍ଟ ଉପରେ ଭିଜୁଆଲ୍ ଯାଞ୍ଚ କରନ୍ତୁ, `npm run check:ui-kit-snapshot` ଏବଂ
`npm run test:vitest:ui` ଚଲାନ୍ତୁ, ଏବଂ ଅପ୍ଷ୍ଟ୍ରିମ୍ ଚେଞ୍ଜଲଗ୍ ସହିତ PR ଖୋଲନ୍ତୁ।
