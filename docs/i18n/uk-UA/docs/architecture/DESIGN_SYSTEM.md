> **Статус:** дашборд побудовано на основі **Keak CI UI Kit** (`@keak/cheaper-inference-ui-kit`), вендореного
> як workspace `packages/ui-kit` (`@omniroute/ui-kit`; знімок апстріму зафіксовано в
> `packages/ui-kit/UPSTREAM.md` і захищено командою `npm run check:ui-kit-snapshot`). Світла тема є канонічною;
> типове налаштування — `system`. Акцентний колір — Keak lime (`--ci-color-accent`). Inter
> (letter-spacing 0, `--ci-letter-spacing-ui`) — шрифт інтерфейсу, Instrument Serif — лише для великих поодиноких
> дисплейних написів (`.ci-dashboard-display`), IBM Plex Mono — для коду; усі вони самохостинговані через
> імпорти `@fontsource/*` на початку `src/app/globals.css`. Кожна іконка — це гліф Lucide.

## 1. Де що знаходиться

- **Набір.** `packages/ui-kit/src` — це побайтова копія апстрімного `src/` на коміті, закріпленому в
  `packages/ui-kit/UPSTREAM.md` (який також фіксує ліцензійний дозвіл); `PATCHES.md` перелічує локальні
  патчі (жодного). Він споживається як вихідний код, без збірки: `next.config.mjs` транспілює його, а
  `tsconfig.json` відображає `@omniroute/ui-kit` → `packages/ui-kit/src` і `@omniroute/ui-kit/*` →
  `packages/ui-kit/src/*` (`vitest.config.ts` та `vitest.mcp.config.ts` несуть той самий аліас). Імпортуйте
  компонент набору за його підшляхом (`@omniroute/ui-kit/table`, `@omniroute/ui-kit/page-header`…), ніколи
  через барель `@omniroute/ui-kit`: барель затягує кожен компонент (включно з елементом вибору дати) в
  кожного імпортера. Таблиця стилів набору потрапляє через `src/app/globals.css`
  (`@import "../../packages/ui-kit/src/ci-ui.css"`).
- **Токени.** `packages/ui-kit/src/ci-tokens.css` оголошує токени `--ci-*`; `src/app/globals.css`
  з'єднує їх мостом із застарілими іменами OmniRoute (`--color-*`, `--radius-*`, `--font-sans`/`--font-mono`,
  `--table-*`, `--orch-status-*`, `--color-fd-*`), тож наявні використання `var(--color-*)` і утиліти
  Tailwind продовжують працювати. Новий код використовує утиліти Tailwind (`bg-surface`, `text-text-muted`,
  `border-border`, `text-success`, `bg-success-bg`, `bg-chart-1`…) або класи набору — ніколи не hex-значення
  (`tests/unit/design-kit-bridge.test.ts` забезпечує дотримання мосту). `text-primary` розв'язується в
  `--color-primary-ink` через `--text-color-primary` (lime-800 у світлій темі, лаймовий акцент — у темній),
  тож основний текст лишається читабельним, тоді як `bg-primary`/`border-primary` зберігають лаймову
  поверхню. Серії графіків використовують `--color-chart-1` … `--color-chart-5`.
- **Теми.** `<html className="ci-theme">` (`src/app/layout.tsx`) підключає документ до теми набору.
  Налаштування — `light`, `dark` або `system` (`THEME_CONFIG.defaultTheme = "system"` у
  `src/shared/constants/appConfig.ts`; `system` слідує за `prefers-color-scheme`). `applyTheme()` у
  `src/store/themeStore.ts` (дзеркалюється вбудованим bootstrap-скриптом у `src/app/layout.tsx`, який
  виконується до гідратації) встановлює `data-theme="dark"|"light"` і разом із цим перемикає клас `.dark`
  на `<html>`. Темні токени набору прив'язані до `data-theme="dark"` (`packages/ui-kit/src/ci-tokens.css`);
  власні темні перевизначення OmniRoute (блок `.dark` у `globals.css`) і застарілі утиліти Tailwind `dark:`
  прив'язані до класу `.dark`. Пресетів акцентного кольору немає: акцент завжди надходить із набору, а
  збережений пресет зі старішої збірки відкидається під час завантаження стора.
- **Компоненти (адаптери).** `src/shared/components/index.tsx` зберігає API компонентів OmniRoute (ті самі
  імена, експорти за замовчуванням і пропси), а примітиви за ним — це адаптери поверх набору: форми
  (`Button`, `Input`, `Textarea`, `Checkbox`, `Select`, `Toggle`, `Badge`, `Card`), оверлеї та зворотний
  зв'язок (`Modal`/`ConfirmModal`, `Tooltip`/`InfoTooltip`, `NotificationToast`, `EmptyState`, `Loading`),
  структура (`Collapsible`, `CollapsibleSection`, `SegmentedControl`, `Breadcrumbs`, `Avatar`) і таблиці
  (`DataTable`, `FilterBar`, `ColumnToggle`, `FilterPills`, `PresetSlider`). Адаптер імпортує компонент
  набору за підшляхом і відображає на нього застарілі пропси — наприклад, `Button variant="primary"` — це
  `default`-кнопка набору (`--ci-button-primary-*`: інвертована поверхня у світлій темі, акцент із
  відповідним йому кольором тексту `--ci-color-accent-foreground` у темній), `danger` — це `destructive`, а
  `warning` — це `outline` плюс розширення `.ci-button--warning`. Правила `.ci-button--warning` і
  `.ci-badge[data-tone]` наприкінці `globals.css` (`@layer components`) — це розширення OmniRoute поверх
  класів набору. `tests/unit/ui/adapters/*.test.tsx` фіксують кожен адаптер.
- **Оболонка.** `src/app/(dashboard)/layout.tsx` рендерить `DashboardLayout`, який рендерить
  `src/shared/components/layouts/DashboardShell.tsx`: `SidebarProvider` / `Sidebar` / `SidebarInset` набору
  (`packages/ui-kit/src/sidebar.tsx`), із навігаційною логікою OmniRoute в
  `src/shared/components/Sidebar.tsx`. Посилання «Перейти до вмісту» на `#main-content` — перший
  фокусований елемент. `src/shared/components/Header.tsx` містить `SidebarTrigger` набору (єдиний
  перемикач бічної панелі в оболонці), `ProductSwitcher` від Keak і кнопку відкриття командної палітри; він
  показує заголовок маршруту лише доти, доки всередині `#main-content` не змонтовано жодного `PageHeader`
  набору (`.ci-page-header`), тож сторінка з власним `PageHeader` має єдиний `h1`.
  `src/shared/components/CommandPalette.tsx` — це `Dialog` набору.
- **Іконки.** `<Icon name="material_name">` (`src/shared/components/Icon.tsx`) розв'язує ім'я (словник
  Material Symbols, який використовують екрани) через `ICON_MAP` (`src/shared/constants/iconMap.ts`) у гліф
  Lucide. Шрифт і пакет Material Symbols видалено: ім'я, відсутнє в мапі, рендерить нейтральний
  гліф-заглушку (`data-icon-missing="true"`) і записує попередження в консоль поза продакшеном.
  `npm run gen:icon-map` виводить імена, які використовуються, але відсутні в мапі
  (`tests/unit/icon-map-coverage.test.ts` падає на будь-якому імені без іконки Lucide;
  `tests/unit/icon-map-object-values.test.ts` покриває імена, збережені в lookup-об'єктах);
  `scripts/dev/codemod-material-icons.mjs <dir|file>... [--write]` переписує літеральні спани
  `<span className="material-symbols-outlined">` на `<Icon>`.
- **Бренд.** `src/shared/components/OmniRouteLogo.tsx` обгортає набір: експорт за замовчуванням
  `OmniRouteLogo` рендерить `ProductIcon product="omniroute" variant="glyph"` (вбудований SVG, безпечний
  щодо `basePath`), а `OmniRouteLockup` рендерить `ProductLockup product="omniroute"` (доступне ім'я
  "Keak OmniRoute") або, для white-label-операторів, їхні власні `name`/`logoSrc`. Пункти призначення
  перемикача продуктів зберігаються в `src/shared/constants/keakProducts.ts` (`KEAK_PRODUCT_LINKS`,
  `KEAK_ACTIVE_PRODUCT`). Автономні екрани — `src/app/login/page.tsx`, `src/app/status/page.tsx`,
  `src/app/maintenance/page.tsx`, `src/app/offline/page.tsx`, `src/app/not-found.tsx` і
  `src/shared/components/ErrorPageScaffold.tsx` — показують локап; `tests/unit/brand-pages-static.test.ts`
  стежить за цим.

## 2. Правила

1. Токени, ніколи літерали. Винятки залишено навмисно: завжди темний консольний термінал, SVG-контури
   ReactFlow через `STATUS_HEX` (`src/shared/constants/statusColors.ts`), а також категоріальні палітри
   `STRATEGY_COLORS` (`src/app/(dashboard)/dashboard/combos/live/nodes/StrategyNode.tsx`) і
   `LAYER_COLORS` (`src/app/(dashboard)/dashboard/compression/studio/nodes/EngineNode.tsx`).
2. Ніколи не редагуйте `packages/ui-kit/src` вручну: синхронізуйте через `scripts/dev/sync-ui-kit.sh <commit>`;
   pre-commit перевірка `npm run check:ui-kit-snapshot` (`.husky/pre-commit`) падає на будь-якому байті, що
   відрізняється від закріпленого upstream-коміту (вона пропускається з попередженням, коли upstream-клон,
   `UI_KIT_CLONE` або `_references/cheaper-inference-ui-kit`, відсутній). Коли в кіті чогось бракує,
   реалізуйте обхід в адаптері або на екрані та попросіть про це upstream.
3. Стандартні тексти кіта — англійські (`label = "Loading"`, `loadingLabel = "Loading table"`…) — передавайте
   перекладені рядки з `useTranslations(...)` щоразу, коли компонент кіта відображає текст.
4. Утиліти Tailwind мають перевагу над класами компонентів кіта (кіт оголошує
   `@layer theme, base, components, utilities`, і його правила живуть у `components`) — використовуйте утиліти
   для відступів і розкладки, а не для перефарбовування компонентів кіта.
5. Заголовки: `.ci-heading` (Inter, без трекінгу) для заголовків сторінок і розділів; `.ci-dashboard-display`
   (Instrument Serif) лише для великого, рідко вживаного акцентного тексту, як-от коду статусу на сторінці помилки.
6. `tests/unit/dashboard-kit-sweep.test.ts` контролює впровадження кіта: жодних лігатурних span Material під
   `src/app` або `src/shared/components`; у дереві дашборда (`src/app/(dashboard)` і
   `src/shared/components`) жодних сирих `<select>`, `<textarea>` або `<table>` і жодних саморобних
   `role="dialog"` поза переліченими винятками (нативна гілка адаптера `Select`,
   `RequestLoggerDetail`); кожен сирий `<button>` або `<input>` там потребує коментаря, що містить
   `kit-exception:` (з причиною) і закінчується щонайбільше за 3 рядки вище нього; відтінки палітри та
   `dark:`-варіанти — лише у файлах, які перелічує тест.
7. Перевірте обидві теми та вʼюпорт 390 px перед PR (скріншоти); `tests/e2e/a11y.spec.ts` запускає
   axe.

## 3. Додавання екрана

1. Відкривайте сторінку кіт-компонентом `PageHeader` (`@omniroute/ui-kit/page-header`, `compact` усередині
   дашборда) — заголовок, опис і `actions`. Тоді заголовок оболонки прибирає власний заголовок.
2. Будуйте елементи керування з `@/shared/components` (адаптерів) і використовуйте компоненти кіта за
   підшляхом там, де адаптера немає (`Table`/`TableScrollArea`/`DataTableShell`, `Field`, `Alert`, `Tabs`,
   `RadioGroup`, `Slider`…).
3. Іконки: `<Icon name="…" />`. Нове імʼя додається в `ICON_MAP` разом із семантично відповідним компонентом
   Lucide; `npm run gen:icon-map` показує, яких імен ще бракує.
4. Кольори: семантичні утиліти (`text-success`, `bg-warning-bg`, `border-border`…) і
   `var(--color-chart-N)` для серій графіків; жодних hex-значень і жодних `dark:`-варіантів, які лише дублюють колір.
5. Текст: кожен рядок, включно з лейблами, які ви передаєте компонентам кіта, береться з `useTranslations`.
   Нові ключі додаються в `src/i18n/messages/en.json`, `pt-BR.json` і `vi.json` (тест паритету вʼєтнамської
   локалі фіксує кожен англійський ключ); решта локалей заповнюється синхронізацією i18n.
6. Запустіть захисні перевірки перед PR: `tests/unit/dashboard-kit-sweep.test.ts`,
   `tests/unit/icon-map-coverage.test.ts`, `tests/unit/icon-map-object-values.test.ts`,
   `npm run check:dashboard-typecheck` (єдина перевірка, що виявляє дубльований імпорт в `iconMap.ts`),
   `npm run check:ui-icu` і власні тести екрана.

## 4. Додавання або зміна адаптера

1. Зберігайте публічний API `src/shared/components/index.tsx`: ті самі імена експортів, експорти за замовчуванням і прийняті пропси. Зіставляйте застарілі пропси з кітом усередині адаптера (див. `Button.tsx`: `VARIANT_TO_KIT`,
   `SIZE_TO_KIT`).
2. Імпортуйте кіт за підшляхом (`@omniroute/ui-kit/<component>`).
3. Обхідні рішення для прогалин кіта розміщуються в адаптері (або в `globals.css` `@layer components`, коли виправлення стосується стилю), ніколи в `packages/ui-kit/src`.
4. Додайте або оновіть `tests/unit/ui/adapters/<name>.test.tsx`. Для адаптера з великою кількістю викликів порівняйте відрендерену розмітку до й після зміни — зміни відступів чи обгорток поширюються на кожен екран.

## 5. Оновлення кіта

`scripts/dev/sync-ui-kit.sh <commit> [clone]` копіює `src/` апстріму за вказаним комітом у
`packages/ui-kit/src` і застосовує єдину дозволену трансформацію (вилучає суфікс `.js` з
відносних імпортів). Далі: перегляньте `git diff packages/ui-kit`, зробіть візуальний прохід по провайдерах, налаштуваннях, комбо,
використанні та ендпоінті в обох темах, запустіть `npm run check:ui-kit-snapshot` і `npm run test:vitest:ui` та
відкрийте PR із журналом змін апстріму.

## 6. Довідковий індекс

- `src/app/globals.css` — міст токенів, перевизначення `.dark`, розширення OmniRoute `@layer components`
- `packages/ui-kit/UPSTREAM.md` — закріплений коміт апстріму та авторизація ліцензії; `packages/ui-kit/PATCHES.md`
- `packages/ui-kit/src/ci-tokens.css`, `packages/ui-kit/src/ci-ui.css`, `packages/ui-kit/src/keak-brand.tsx`
