## Що таке провайдер?

Уявіть провайдера як **оператора мобільного зв’язку**. Так само як для здійснення дзвінків вам потрібен оператор мобільного зв’язку, для використання моделей ШІ вам потрібен провайдер ШІ. OmniRoute схожий на телефон, який працює з **усіма операторами** — ви можете автоматично перемикатися між ними.

### Типи провайдерів

| Тип              | Що це таке                                 | Приклади                        | Вартість                              |
| ---------------- | ------------------------------------------ | ------------------------------- | ------------------------------------- |
| **Безкоштовний** | Оплата не потрібна                         | Kiro, Pollinations              | $0                                    |
| **API-ключ**     | Вам потрібен API-ключ                      | OpenAI, Anthropic, Google       | Оплата за використання                |
| **OAuth**        | Вхід за допомогою вашого облікового запису | Claude Code, GitHub Copilot     | Передплата                            |
| **Веб-cookie**   | Використовує сеанс вашого браузера         | ChatGPT Web (Codex), Gemini Web | $0 (використовує ваш обліковий запис) |

### Провайдери веб-cookie

Загальні інструкції з налаштування, відомості про обмеження й усунення несправностей, а також рекомендації з автентифікації для окремих провайдерів див. у **[WEB-COOKIE-GUIDE.md](./WEB-COOKIE-GUIDE.md)**.

## Швидкий старт: підключіть свого першого провайдера

### Необов’язкове початкове налаштування безкоштовних провайдерів

Майстер першого запуску пропонує окрему картку **Налаштувати безкоштовних провайдерів**. Він формує поточний
список доступних варіантів із реєстру провайдерів OmniRoute, які не потребують автентифікації, а потім дає змогу переглянути кожного
провайдера та зняти з нього вибір перед підтвердженням. OmniRoute показує попередження провайдера та посилання на його сайт,
щоб ви могли заздалегідь ознайомитися з умовами стороннього постачальника, політикою конфіденційності, доступністю та обмеженнями швидкості.

Ця дія необов’язкова: завершення роботи майстра ніколи не створює підключення до безкоштовних провайдерів без вашого відома.
Він створює лише підключення до провайдерів, яких досі немає, залишає наявні налаштовані підключення
без змін і окремо повідомляє про створених, уже налаштованих провайдерів і провайдерів, підключити яких не вдалося. Після часткового виконання
можна безпечно повторити спробу лише для невдалих підключень.

### Варіант A: безкоштовний провайдер (без кредитної картки)

1. Відкрийте панель керування за адресою `http://localhost:20128`
2. Перейдіть до **Провайдери** → **Додати провайдера**
3. Виберіть одного із цих безкоштовних провайдерів:
   - **Kiro AI** — безкоштовні моделі Claude (автентифікація не потрібна)
   - **Pollinations** — безкоштовні GPT-5, Claude, Gemini (ключ не потрібен)
   - **LongCat** — 10 млн безкоштовних токенів (одноразове нарахування, потрібні обліковий запис і KYC)
   - **Cloudflare AI** — понад 50 моделей, 10 тис. нейронів на день
   - **MLX Gemma 26B** — локальна модель для Apple Silicon (~38.5 токена/с, ~15.9GB ОЗП)
   - **MLX Qwen 3.8 27B** — локальна модель для Apple Silicon (~9.1 токена/с, ~13.1GB ОЗП)
4. Натисніть **Підключити**
5. Готово! Тепер у вас є безкоштовний доступ до ШІ.

### Варіант B: провайдер із ключем API (платний)

1. Отримайте ключ API на вебсайті провайдера:
   - **OpenAI**: https://platform.openai.com/api-keys
   - **Anthropic**: https://console.anthropic.com/
   - **Google**: https://aistudio.google.com/apikey
   - **DeepSeek**: https://platform.deepseek.com/
   - **Groq**: https://console.groq.com/
2. Відкрийте панель керування за адресою `http://localhost:20128`
3. Перейдіть до **Провайдери** → **Додати провайдера**
4. Виберіть свого провайдера
5. Вставте свій ключ API
6. Натисніть **Підключити**
7. Готово! Тепер у вас є доступ до моделей цього провайдера.

### Варіант C: провайдер OAuth (підписка)

1. Відкрийте панель керування за адресою `http://localhost:20128`
2. Перейдіть до **Провайдери** → **Додати провайдера**
3. Виберіть свого провайдера (наприклад, Claude Code, GitHub Copilot)
4. Натисніть **Підключитися через OAuth**
5. Увійдіть за допомогою свого облікового запису
6. Готово! Тепер у вас є доступ до моделей, доступних за вашою підпискою.

### Варіант D: локальні моделі MLX (Apple Silicon)

Для комп’ютерів Mac з Apple Silicon та уніфікованою пам’яттю OmniRoute підтримує підключення локальних моделей MLX, запущених через `mlx-lm.server`, як звичайних локальних провайдерів, сумісних з OpenAI.

#### Передумови

- **Mac з Apple Silicon** (M1/M2/M3/M4); рекомендовано щонайменше 24GB уніфікованої пам’яті
- Менеджер пакетів **uv**: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**: `uv pip install mlx-lm`

#### Швидкий старт

1. **Установіть залежності**:

   ```bash
   # Установіть uv, якщо його ще не встановлено
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # Установіть mlx-lm
   uv pip install mlx-lm
   ```

2. **Запустіть сервери MLX вручну** (в окремих терміналах):

   ```bash
   # Термінал 1: Gemma 4 26B A4B IT-QAT (порт 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # Термінал 2: Qwen 3.8 27B MLX Mixed (порт 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **Підключіть у панелі керування OmniRoute**:
   - Перейдіть до **Провайдери** → **Додати провайдера**
   - Виберіть **MLX Gemma 26B** або **MLX Qwen 3.8 27B**
   - Натисніть **Підключити** (ключ API не потрібен)

4. **Використовуйте з OpenCode**:
   ```bash
   # Налаштуйте OpenCode для використання OmniRoute
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <your-omniroute-api-key>

   # Використовуйте моделі MLX
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

#### Керування пам’яттю

**Важливо**: за наявності 24GB уніфікованої пам’яті одночасно може працювати лише **одна велика модель MLX**.

- Gemma 26B: пікове використання пам’яті ~15.9GB
- Qwen 3.8 27B: пікове використання пам’яті ~13.1GB

Цим потрібно керувати вручну:

- Запускайте лише один сервер MLX одночасно, або
- Запускайте обидва на окремих комп’ютерах, або
- Зупиняйте один перед запуском іншого

OmniRoute не керує процесами сервера MLX автоматично — він лише спрямовує запити до налаштованих вами кінцевих точок, сумісних з OpenAI.

#### Підтримка виклику інструментів

Обидві моделі підтримують виклик інструментів у форматі, сумісному з OpenAI. Перевірте за допомогою:

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mlx-gemma/gemma-4-26b",
    "messages": [{"role": "user", "content": "What is 2+2? Use the calculator tool."}],
    "tools": [{"type": "function", "function": {"name": "calculator", "description": "Calculate", "parameters": {"type": "object", "properties": {"expression": {"type": "string"}}, "required": ["expression"]}}}]
  }'
```

#### Усунення несправностей

| Проблема                          | Рішення                                                                                                       |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| Сервер не запускається            | Перевірте `uv run mlx_lm.server --help` і правильність ідентифікаторів моделей                                |
| Бракує пам’яті                    | Переконайтеся, що працює лише одна модель; закрийте інші програми; перевірте Моніторинг системи               |
| Відмовлено в підключенні          | Переконайтеся, що сервер працює на правильному порту (11435/11436)                                            |
| Повільні відповіді                | Перший запит завантажує модель у пам’ять (~30-60с); наступні запити виконуються швидко                        |
| Не вдається викликати інструменти | Переконайтеся, що модель підтримує інструменти; перевірте журнали OmniRoute на наявність помилок перетворення |

## Як підключити провайдера (покроково)

### Крок 1: відкрийте панель керування

Перейдіть у браузері за адресою `http://localhost:20128`.

### Крок 2: перейдіть до розділу провайдерів

Натисніть **Провайдери** на бічній панелі.

### Крок 3: натисніть «Додати провайдера»

Натисніть кнопку **+ Додати провайдера**.

### Крок 4: виберіть свого провайдера

Перегляньте список або знайдіть свого провайдера через пошук. Натисніть на нього.

### Крок 5: введіть облікові дані

- **Безкоштовні провайдери**: облікові дані не потрібні — просто натисніть **Підключити**
- **Провайдери з API-ключем**: вставте свій API-ключ
- **Провайдери з OAuth**: натисніть **Підключити через OAuth** та увійдіть у систему

### Крок 6: перевірте підключення

Натисніть **Перевірити підключення**, щоб переконатися, що воно працює.

### Крок 7: готово!

Тепер вашого провайдера підключено. Ви можете використовувати його з `model: "auto"` або вказати провайдера безпосередньо.

## Використання кількох провайдерів

OmniRoute найкраще працює з **кількома провайдерами**. Це дає вам:

- **Автоматичне перемикання** — якщо один провайдер не працює, OmniRoute пробує наступного
- **Оптимізацію вартості** — OmniRoute вибирає найдешевшого провайдера для кожного запиту
- **Оптимізацію швидкості** — OmniRoute вибирає найшвидшого провайдера для кожного запиту
- **Оптимізацію якості** — OmniRoute вибирає найкращого провайдера для кожного завдання

### Рекомендоване налаштування

Підключіть щонайменше **3 провайдерів** для найкращої роботи:

1. **Один безкоштовний провайдер** (Kiro або Pollinations) — завжди доступний
2. **Один швидкий провайдер** (Groq, Cerebras) — для швидких відповідей
3. **Один якісний провайдер** (OpenAI, Anthropic, Google) — для складних завдань

Потім використовуйте `model: "auto"`, і OmniRoute автоматично вибиратиме найкращого провайдера для кожного запиту.

## Налаштування для конкретних провайдерів

### OpenAI

1. Отримайте ключ API: https://platform.openai.com/api-keys
2. В OmniRoute: Провайдери → Додати провайдера → OpenAI
3. Вставте ключ API → Підключити

### Anthropic

1. Отримайте ключ API: https://console.anthropic.com/
2. В OmniRoute: Провайдери → Додати провайдера → Anthropic

### Qoder: вибір способу передавання облікових даних

Qoder потребує облікових даних. Два способи їх передавання мають різні можливості; сама лише назва моделі
не визначає, що може робити конкретне підключення.

| Облікові дані                            | Спосіб передавання OmniRoute                   | Виклик інструментів клієнтом                                                | Потокове передавання                                                           |
| ---------------------------------------- | ---------------------------------------------- | --------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| PAT, що починається з `pt-`              | Локальний процес `qodercli` на хості OmniRoute | Не підтримується                                                            | Буферизоване: SSE надсилається лише після того, як CLI поверне повну відповідь |
| Токен доступу, що не є PAT, або ключ API | HTTP-кінцева точка DashScope, сумісна з OpenAI | Передається без змін з урахуванням обмежень моделі/ключа на стороні сервісу | Висхідний шлях HTTP/SSE                                                        |

Для PAT установіть Qoder CLI на тому самому хості або в тому самому контейнері, що й OmniRoute. Виконуваний файл
має бути доступний як `qodercli`; інакше задайте шлях до нього в `CLI_QODER_BIN`. CLI,
установлений лише на хості Docker, не стає автоматично доступним у контейнері. За відсутності
виконуваного файла з’являється явна помилка з указівкою встановити його або налаштувати шлях.

Для чату через PAT установлено 45-секундний тайм-аут процесу. Розмову перетворюють на єдиний
запит і передають CLI в непотоковому режимі друку. Запит із `stream: true` змінює
формат відповіді на SSE, але не забезпечує поступового передавання токенів від висхідного сервісу.
Для перевірки CLI та отримання списку моделей використовується окремий 20-секундний тайм-аут. Це поточні
значення за замовчуванням у коді, а не параметри, які можна налаштувати на панелі керування.

Використовуйте підключення PAT для звичайного чату. Під час вибору облікових даних запити агентів, що містять `tools` або застарілі `functions`,
виключають облікові записи PAT, зокрема закріплені комбіновані цілі. Змішаний
пул Qoder усе одно може вибрати свій HTTP-обліковий запис. Прямі виклики виконавця PAT також завершуються
явною помилкою перед запуском CLI замість неявного відкидання визначень інструментів. Це
обмеження стосується інструментів, наданих клієнтом API, а не внутрішніх інструментів, які
може використовувати сам Qoder CLI. HTTP-ключ не гарантує, що кожна модель підтримує інструменти;
стандартні перевірки можливостей моделі все одно застосовуються.

OAuth через браузер доступний лише тоді, коли адміністратор налаштує всі п’ять параметрів:
`QODER_OAUTH_AUTHORIZE_URL`, `QODER_OAUTH_TOKEN_URL`, `QODER_OAUTH_USERINFO_URL`,
`QODER_OAUTH_CLIENT_ID` і `QODER_OAUTH_CLIENT_SECRET`. За замовчуванням вони порожні; у
неналаштованій інсталяції слід використовувати підтримуваний імпорт облікових даних, а не вважати,
що вхід через браузер уже готовий.

Посилання на реалізацію: [виконавець Qoder](../../open-sse/executors/qoder.ts),
[середовище виконання CLI](../../open-sse/services/qoderCli.ts) і
[конфігурація OAuth](../../src/lib/oauth/constants/oauth.ts). Поступове потокове передавання для PAT
і налаштовуваний тайм-аут є окремими вдосконаленнями; описана поведінка не передбачає їхньої наявності.

## Поширені запитання

### «Чи потрібно платити за використання OmniRoute?»

**Ні!** OmniRoute є безкоштовним програмним забезпеченням із відкритим кодом. Ви можете користуватися безкоштовними провайдерами (Kiro, Pollinations), нічого не сплачуючи. Платити потрібно лише в тому разі, якщо ви вирішите використовувати платних провайдерів.

### «З якого провайдера варто почати?»

Почніть із **Kiro AI** — він безкоштовний, не потребує ключа API й надає доступ до моделей Claude. Потім за потреби додайте інших провайдерів.

### «Чи можна використовувати кількох провайдерів одночасно?»

**Так!** Саме для цього й створено OmniRoute. Підключіть кількох провайдерів і використовуйте `model: "auto"`, щоб OmniRoute вибирав найкращого для кожного запиту.

### «Що станеться, якщо провайдер припинить працювати?»

OmniRoute автоматично пропускає провайдерів, у роботі яких стався збій, і пробує наступного. Вам не потрібно нічого робити.

### «Як відключити провайдера?»

Перейдіть до Providers → натисніть потрібного провайдера → натисніть **Disconnect**.

### «Чи можна використовувати наявні ключі API?»

**Так!** Якщо у вас уже є ключі API для OpenAI, Anthropic, Google тощо, ви можете використовувати їх в OmniRoute. Просто вставте їх під час підключення провайдера.
