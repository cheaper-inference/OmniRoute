## Quando escolher o OmniRoute

- Você faz auto-hospedagem e quer **cobertura máxima de provedores** (376 provedores, 155 entradas de catálogo gratuitas/sem autenticação)
- Você precisa de um **servidor MCP integrado** (ferramentas de LLM, memória e skills expostas como ferramentas)
- Você precisa do **protocolo A2A** para fluxos de trabalho agente a agente
- Você quer **furtividade de fingerprint** (JA3/JA4) para evitar detecção por CAPTCHAs upstream
- Você precisa de **recursos corporativos** (guardrails, evals, trilha de auditoria) sem uma fatura de SaaS

## Quando escolher o LiteLLM

- Você prioriza **Python** e precisa de integração estreita com `litellm.completion()`
- Você precisa de **receitas maduras para implantação em produção** (k8s, charts do Helm)
- Sua equipe já opera microsserviços em Python

## Quando escolher o OpenRouter (SaaS)

- Você não quer se auto-hospedar
- Você aceita pagar por token com a margem adicional do SaaS
- Você precisa de uma **única forma de pagamento** para todos os provedores

## Quando escolher o Portkey

- Você precisa de um **SLA comercial** com garantias de disponibilidade
- Você prefere um **painel gerenciado** sem sobrecarga operacional
- Você precisa de **recursos de conformidade empresarial** prontos para uso
