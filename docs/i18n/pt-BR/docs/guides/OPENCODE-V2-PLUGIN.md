`@omniroute/opencode-plugin-v2` disponibiliza todo o seu catálogo do OmniRoute — modelos, combos e
auto-combos — no seletor de modelos do OpenCode v2, com nomes de exibição, preços e limites
do nível gratuito.

Ele é um pacote separado de `@omniroute/opencode-plugin` porque o OpenCode v1 e o v2 carregam
plugins por meio de contratos diferentes. Escolha aquele que corresponde à versão principal do seu OpenCode; nada é
compartilhado entre eles, portanto atualizar um nunca força a atualização do outro.

## Requisitos

- OpenCode v2.
- Um gateway OmniRoute acessível (`http://localhost:20128` por padrão).
- Node.js 22 ou 24.

## Instalação

Adicione o plugin ao `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

Os modelos aparecerão como `omniroute/<provider>/<model>`; `providerId` define esse prefixo e
o id da integração sob a qual o OpenCode armazena a credencial.

## Credenciais

O plugin procura uma chave do gateway em três locais, nesta ordem:

1. **A credencial que você conectou no OpenCode.** O plugin registra uma integração, portanto
   o próprio fluxo de autenticação do OpenCode pode armazenar a chave. Nada é gravado no `opencode.json` — prefira esta opção.
2. `apiKey` nas opções do plugin, para uma substituição específica por projeto. Isso coloca a chave em um arquivo que
   você pode estar enviando ao repositório.
3. `OMNIROUTE_API_KEY` no ambiente.

Sem nenhuma das três, o catálogo fica vazio, e o plugin informa isso uma vez na inicialização, em vez de
deixar você com um seletor vazio sem qualquer aviso.

### O token de gerenciamento é uma chave diferente

Combos, integridade dos provedores e enriquecimento (nomes de exibição, preços e limites do nível gratuito) vêm
dos endpoints `/api/*` do gateway, que na maioria das implantações são protegidos por um token de
**gerenciamento**, em vez da chave de inferência:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<token de leitura de gerenciamento>"
}
```

Quando não definido, `managementReadToken` usa `apiKey` como alternativa. Quando um gateway rejeita essa alternativa,
o catálogo ainda é publicado, mas com ids de modelo brutos em vez de nomes de exibição, sem
desduplicação de aliases canônicos, sem preços e sem combos. O plugin emite um aviso uma vez por endpoint quando isso acontece,
indicando o endpoint e o que foi perdido — assim, um seletor degradado nunca é um mistério.

## Opções

| Chave                            | Padrão                                          | Notas                                                                                                                                                                                                                                                                                                                                                                                 |
| -------------------------------- | ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `providerId`                     | `"omniroute"`                                   | O ID do provedor, o ID de integração e os modelos de prefixo aparecem em                                                                                                                                                                                                                                                                                                              |
| `baseURL`                        | obrigatório                                     | Raiz do gateway, somente `http(s)` ; o sufixo `/v1` é adicionado quando necessário                                                                                                                                                                                                                                                                                                    |
| `apiKey`                         | credencial conectada, então `OMNIROUTE_API_KEY` | Chave de bate-papo para `/v1/*`                                                                                                                                                                                                                                                                                                                                                       |
| `managementReadToken`            | volta para `apiKey`                             | Chave para `/api/*` — normalmente** não** o mesmo                                                                                                                                                                                                                                                                                                                                     |
| `displayName`                    | `"OmniRoute"`                                   | Nome do provedor no seletor                                                                                                                                                                                                                                                                                                                                                           |
| `timeoutMs`                      | `10000`                                         | Tempo limite de busca por endpoint (combos automáticos usam 5s)                                                                                                                                                                                                                                                                                                                       |
| `modelCacheTtlMs`                | `300000`                                        | Cache de catálogo TTL; um instantâneo de disco aquece inicializações a frio                                                                                                                                                                                                                                                                                                           |
| `timeouts`                       | volta para `timeoutMs`                          | Orçamentos por endpoint em ms: `models`, `combos`, `autoCombos`, `enrichment`                                                                                                                                                                                                                                                                                                         |
| `enrichment`                     | `true`                                          | Busque nomes, preços e orçamentos de nível gratuito                                                                                                                                                                                                                                                                                                                                   |
| `providerTag`                    | `true`                                          | Alterne o parêntese do editor final: `Provider - Model (Editor)`. O provedor (rota que atende o modelo) é sempre mostrado; o editor (que fez o modelo) aparece apenas entre parênteses. Exemplo: `Openrouter - MoonshotAI: Kimi K 3.1 Pro` -> `Openrouter - Kimi K 3.1 Pro (MoonshotAI)`. Omitido quando o editor e o provedor compartilham um nome. Defina `false` para descartá-lo. |
| `usableOnly`                     | `false`                                         | Mantenha apenas os provedores dos relatórios de gateway conforme provisionados                                                                                                                                                                                                                                                                                                        |
| `combosSource`                   | `"api"`                                         | `"models"` ignora `/api/combos` e publica as linhas combinadas `/v1/models` ; filtros em nível de membro mantêm `"api"`                                                                                                                                                                                                                                                               |
| `showcasePerOwner`               | `10`                                            | Entradas de visualização padrão mantidas por provedor                                                                                                                                                                                                                                                                                                                                 |
| `freshPerOwner`                  | `10`                                            | Visualização padrão de novas entradas mantidas por provedor                                                                                                                                                                                                                                                                                                                           |
| `freshWindowDays`                | `90`                                            | Janela de frescor em dias para o galho fresco                                                                                                                                                                                                                                                                                                                                         |
| `usageMemory`                    | `true`                                          | Restaurar entradas descartadas estaticamente nomeadas pela análise de uso de 30 dias (precisa de um token de gerenciamento)                                                                                                                                                                                                                                                           |
| `visibleModels` / `hiddenModels` | `[]`                                            | Listas de permissões exatas ou com sufixo; negar vitórias; `*` publica o catálogo completo (outros filtros ainda se aplicam)                                                                                                                                                                                                                                                          |
| `geminiSanitization`             | `true`                                          | Retire as palavras-chave JSON-Schema Gemini rejeita dos esquemas de ferramentas (as ferramentas `$ref` são encaminhadas intactas)                                                                                                                                                                                                                                                     |
| `apiFormat.allowAnthropic`       | `false`                                         | Rotear IDs permitidos por meio do bloco Anthropic API                                                                                                                                                                                                                                                                                                                                 |
| `apiFormat.anthropicModels`      | `[]`                                            | IDs completos do modelo roteados para Anthropic                                                                                                                                                                                                                                                                                                                                       |
| `logLevel` / `startupDebug`      | `warn` / `false`                                | Detalhamento do registrador                                                                                                                                                                                                                                                                                                                                                           |

O uso da memória está ativado por padrão. Sem um token de gerenciamento ele permanece inerte (um aviso de inicialização é registrado) e nada é restaurado.

## Como o catálogo permanece atualizado

O catálogo é buscado lentamente e armazenado em cache para `modelCacheTtlMs`, e um instantâneo de disco mantém o último catálogo conhecido disponível quando o gateway está inacessível — uma interrupção não custa nada além de atualização. Os modelos e combos são publicados assim que chegam; os combos automáticos, a lista de provedores e a sobreposição de enriquecimento se dobram quando chegam, de modo que um endpoint lento não pode manter todo o selecionador como refém.

Os nomes seguem `Provider - Model[ (Editor)][ · budget][ (route)]`: o provedor é mostrado sempre que o id carrega um (um id sem barra é renderizado sem um prefixo), um `🆓` inicial marca entradas gratuitas e seu orçamento de nível gratuito permanece como um sufixo `· 1M tokens/month`, o editor de um nome `Editor: Model` explícito move-se para um parêntese final (nenhum editor é adivinhado a partir de outros nomes) e os combos são renderizados como `combo - <slug>` sem um ícone livre. Duas entradas que compartilham um nome recebem um sufixo de rota — `(no-think)` — para que permaneçam distinguíveis. `providerTag` (padrão `true`) alterna os parênteses finais do editor.

Não há comando de atualização manual: os comandos OpenCode v2 são modelos de prompt, não retornos de chamada, portanto, um plug-in não pode expor um. As atualizações seguem o TTL; o host é solicitado a recarregar somente quando o catálogo ou a sobreposição realmente for alterado, nunca uma vez por atualização.

## Chamada de ferramentas no Gemini

O Gemini rejeita uma solicitação inteira quando suas declarações de ferramentas contêm `$schema` ou
`additionalProperties`, respondendo com `400 INVALID_ARGUMENT`. O plugin remove essas palavras-chave dos
schemas de ferramentas destinados a um modelo Gemini deste provedor e mantém todas as outras solicitações inalteradas.
Uma ferramenta que contém um `$ref` é encaminhada sem alterações, em vez de ter palavras-chave removidas, pois remover a
referência ampliaria o schema para "aceitar qualquer coisa".
Defina `"geminiSanitization": false` para desativar esse comportamento.

## Solução de problemas

| Sintoma                                           | Causa                                                                                                                             |
| ------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| O selecionador não mostra nenhum modelo OmniRoute | Nenhuma chave foi resolvida (verifique o aviso de inicialização) ou o gateway está inacessível                                    |
| IDs de modelo brutos, sem combos, sem preços      | Os endpoints de gerenciamento recusaram o token — set `managementReadToken`                                                       |
| Catálogo `freeOnly` curto ou vazio                | Nenhum token de gerenciamento ou um token recusado — leu a linha de resumo de atualização (`unmatched-free` count) no log do host |
| Uma sessão fixada em `opencode-<id>/...`          | O plugin v1 publicou `opencode-<id>`; v2 publica `<id>` bare, então selecione novamente o modelo em `<id>/...`                    |

As variáveis de ambiente devem atingir o processo do servidor opencode: quando o host é executado como um serviço, o shell que executa `opencode models` e o ambiente do servidor são diferentes, então exporte a chave onde o servidor a lê.
