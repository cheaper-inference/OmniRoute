## Categorias

- **Livre** nível gratuito — com chave API (configurado via painel)
- **Sem autenticação** Endpoints públicos — que não exigem nenhuma chave ou login
- **OAuth** Fluxo de login — manipulado por OmniRoute, nenhuma chave API necessária
- **Cookie da Web** — envolve o aplicativo da web do provedor por meio de autenticação de cookie
- **chave API** Provedor pago — configurado via chave API (podem ser aplicados créditos gratuitos)
- **Local** — é executado na máquina do usuário (Ollama, LM Studio, vLLM, etc.)
- **Procurar** provedores de pesquisa na web —
- **Áudio** provedores — somente de áudio (TTS/STT)
- **Proxy ascendente** Provedores — que fazem proxy para outros provedores
- **Agente de nuvem** agentes de codificação de longa duração — (Codex Cloud, Devin, Jules)
- **Sistema** Provedores internos — OmniRoute (loopback, etc.)

Tags adicionais: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (onde mostrado): `native` — chamada de função real API; `emulated` — o array `tools` é emulado via `webTools.ts` (blocos `<tool>{...}</tool>` analisados por regex); `none` — `tools` está atualmente descartado silenciosamente. Veja #7286.

Use o painel do `/dashboard/providers` para habilitar, configurar e testar cada provedor.
