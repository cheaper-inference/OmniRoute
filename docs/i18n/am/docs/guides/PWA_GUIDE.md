ከመነሻ ስክሪን ወይም ከዴስክቶፕዎ ሆነው በብቸኛ መስኮት ለመክፈት OmniRoute ዳሽቦርዱን እንደ ተራማጅ የድር መተግበሪያ ይጫኑት። የተጫነው መተግበሪያ አሁንም ለማሰስ፣ ዳሽቦርድ ውሂብ እና API ጥያቄዎች ከ OmniRoute አገልጋይዎ ጋር ግንኙነት ይፈልጋል። የተሸጎጡ የማይንቀሳቀሱ ንብረቶች ከመስመር ውጭ መግቢያ በር ወይም ከመስመር ውጭ ዳሽቦርድ አይሰጡም።

## PWA ምንድን ነው?

ተራማጅ የድር መተግበሪያ የድር ዳሽቦርዱን ከመተግበሪያ አዶ እና የተለየ መስኮት ጋር ይጠቀማል። አንዴ ከተጫነ OmniRoute:

- ከእርስዎ መነሻ ስክሪን ወይም ዴስክቶፕ ይጀምራል
- ከአሳሹ የተለመደ የአድራሻ አሞሌ እና ትሮች በሌለበት ለብቻው ይከፈታል።
- የተመረጡ የማይንቀሳቀሱ ንብረቶች መሸጎጫዎች
- የቁም እና የመሬት አቀማመጥ አቅጣጫዎችን ይደግፋል

## መጫን

በሌላ መሳሪያ ላይ ላለ አገልጋይ HTTPS አድራሻ ተጠቀም። አገልጋዩ በተመሳሳዩ መሳሪያ ላይ ሲሰራ፣ `http://localhost:20128` የአሳሽ መጫኛ መስፈርቶችንም ያሟላል። ግልጽ የሆነ `http://YOUR_IP:20128` አድራሻ እነዚህን መስፈርቶች አያሟላም። የመጫኛ ምናሌዎች እና ጥያቄዎች በአሳሹ እና በስርዓተ ክወናው ላይ ይወሰናሉ. [MDN's PWA የመጫኛ መስፈርቶችን](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable#https_localhost_or_loopback_are_required) ይመልከቱ።

### አንድሮይድ (Chrome)

1. የእርስዎን OmniRoute HTTPS አድራሻ ወይም `http://localhost:20128` ለተመሳሳይ ስልክ አገልጋይ ይክፈቱ።
2. ክፈት**⋮** ምናሌ እና ይምረጡ** መተግበሪያን ጫን** ወይም** ወደ መነሻ ማያ ገጽ ያክሉ** , ከቀረበ.
3. መጠየቂያውን ያረጋግጡ።
4. OmniRoute ን ከመነሻ ማያ ገጽ ይክፈቱ።

### iOS (Safari)

1. OmniRoute HTTPS አድራሻዎን በ Safari ውስጥ ይክፈቱ።
2. መታ ያድርጉ** አጋራ** →** ወደ መነሻ ማያ ገጽ ያክሉ** .
3. ስሙን ያረጋግጡ እና ይንኩ።** አክል** .
4. OmniRoute ን ከመነሻ ማያ ገጽ ይክፈቱ።

### ዴስክቶፕ (Chrome / Edge)

1. የእርስዎን OmniRoute ዳሽቦርድ ይክፈቱ።
2. የአሳሹን የመጫኛ አዶ ይጠቀሙ ወይም የ** መተግበሪያን ጫን** የምናሌ ግቤት፣ ከቀረበ።
3. OmniRoute በራሱ መስኮት ለመክፈት ጥያቄውን ያረጋግጡ።

## ባህሪያት

### ገለልተኛ መስኮት

አንጸባራቂው `display: "standalone"` እና `start_url: "/dashboard"` ያዘጋጃል። የተጫነው መተግበሪያ ዳሽቦርዱን በመተግበሪያ መስኮት ውስጥ ይከፍታል። የአሳሽ እና የስርዓተ ክወና ቁጥጥሮች አሁንም ሊታዩ ይችላሉ; አንጸባራቂው የሙሉ ማያ ገጽ ሁነታን አይጠይቅም።

### የግንኙነት ገጽ

`/offline` ገጹ የግንኙነት መልእክት፣ የ online/offline አመልካች፣ ሀ** ግንኙነትን እንደገና ይሞክሩ** አዝራር እና የሁኔታ ገጽ አገናኝ. ነው።** አስቀድሞ አልተሸጎጠም።** እና የአገልግሎት ሰራተኛው ይሠራል** አይደለም** ያልተሳኩ አሰሳዎችን ወደ እሱ አዙር። የእሱ መኖር ከአገልጋዩ ውጭ አዳዲስ ገጾችን ተደራሽ አያደርግም።

### ራስ-ሰር ምዝገባ

`PwaRegister` አሳሹ የአገልግሎት ሰራተኞችን ሲደግፍ ሰራተኛውን በምርት ላይ ይመዘግባል። የዕድገት ሁነታ ሠራተኞችን ከመመዝገብ ይሰርዛል እና የቆዩ ንብረቶች በሙቅ ዳግም መጫን ላይ ጣልቃ እንዳይገቡ መሸጎጫዎችን ያጸዳል። የመጫን ጥያቄዎች የአሳሽ ውሳኔ ይቀራሉ።

## የቴክኒክ አርክቴክቸር

የአንጸባራቂው ስም እና መግለጫ በዚያ የምንጭ ፋይል ውስጥ የማይንቀሳቀሱ እሴቶች ናቸው። የተጫነው አንጸባራቂ የአብነት-ስም ቅንብርን ወይም በእያንዳንዱ ጉብኝት ላይ ያለውን ገባሪ ቤተ-ስዕል አይከተልም።

### የአገልግሎት ሰራተኛ

[`public/sw.js`](../../public/sw.js) ምንም የአገልግሎት-ሰራተኛ ማዕቀፍ ጥገኝነት የለውም፡-

- **ጫን፡** ከላይ የተዘረዘሩትን አራቱን መርጃዎች አስቀድሞ በመሸጎጥ አዲሱን ሠራተኛ ያነቃል።
- **አግብር፡** የቆዩ የመሸጎጫ ትውልዶችን ያስወግዳል እና ደንበኞችን ይጠይቃሉ።
- **አምጣ፡** ከላይ ያሉትን የማይንቀሳቀስ ንብረት ስልቶችን እና የመንገድ ማግለሎችን ተግባራዊ ያደርጋል።
- **ስሪት ማውጣት፡** የምንጭ መሸጎጫ ስም `omniroute-pwa-v3` ነው; የምርት ግንባታው የመሸጎጫውን ማንነት ያስተካክላል.
- **ማሳወቂያዎች፡-** መጪ `push` ክስተቶችን ያስተናግዳል እና ማሳወቂያ ጠቅ ሲደረግ መስኮት ያተኩራል ወይም ይከፍታል።

የግፊት ክስተት ተቆጣጣሪዎች ብቻ ንቁ የግፋ ደንበኝነት ምዝገባ ወይም የተዋቀረ የአገልጋይ አቅርቦት አይመሰርቱም። PWA ስለተጫነ ብቻ ማሳወቂያዎች እንደነቁ አድርገው አያስቡ።

### የአቀማመጥ ዲበ ውሂብ እና ምዝገባ

[`src/app/layout.tsx`](../../src/app/layout.tsx) አንጸባራቂውን አገናኝ፣ አፕል ራሱን የቻለ ሜታዳታ፣ የገጽታ ቀለሞች እና `viewport-fit: cover` ያቀርባል። የገጽ ርዕስ እና የአፕል ድር መተግበሪያ ርዕስ የአብነት ስሙን ይጠቀማሉ። የቀጥታ አሳሽ ገጽታ ቀለም ቤተ-ስዕል ይከተላል; የመጫኛ አንጸባራቂ ነባሪውን የብርሃን ቀለም ይጠቀማል።

[`PwaRegister`](../../src/shared/components/PwaRegister.tsx) በደንበኛው ላይ ይሰራል እና `/sw.js` ከግንባታው ID ጋር በ URL ይመዘግባል። ያልተዛመዱ የመሸጎጫ ትውልዶችን ፈልጎ ያገኛል እና ሰራተኛውን ዳግም ያስጀምረዋል እና ከአሮጌ ጭነት ለማገገም አንድ ጊዜ እንደገና መጫን ይችላል። የምዝገባ አለመሳካት ዳሽቦርዱን አያግደውም።

## በTermux (አንድሮይድ) ይጠቀሙ

1. OmniRoute በ Termux ይጀምሩ: `npx -y omniroute@latest`.
2. Chromeን በተመሳሳይ ስልክ ክፈት `http://localhost:20128`.
3. በአሳሹ መጫኛ ሜኑ በኩል PWA ይጫኑ።
4. ዳሽቦርዱን በሚጠቀሙበት ጊዜ Termux አገልጋዩ እንዲሰራ ያድርጉት።

ስልኩ መግቢያውን እና ዳሽቦርዱን ሁለቱንም ያስተናግዳል። የርቀት AI አቅራቢዎች ጥያቄዎች አሁንም የአውታረ መረብ መዳረሻ ያስፈልጋቸዋል። ለማዋቀር እና የአንድሮይድ ሂደት-የህይወት ጊዜ ግምትን ለማግኘት [የTermux መመሪያን](TERMUX_GUIDE.md) ይመልከቱ።

## ከሌሎች መሳሪያዎች ተጠቀም

የአገልጋዩን HTTPS አድራሻ በስልክ፣ ታብሌት ወይም ዴስክቶፕ ይክፈቱ፣ ከዚያ የአሳሹን የመጫኛ ፍሰት ይከተሉ። አገልጋዩ ከእያንዳንዱ መሳሪያ ሊደረስበት የሚችል ሆኖ መቆየት አለበት። የርቀት መዳረሻ አማራጮችን ለማግኘት [የዋሻው መመሪያን](../ops/TUNNELS_GUIDE.md) ይመልከቱ።

## ማበጀት

### የምሳሌ ስም

የ** የምሳሌ ስም** ቅንብር የዳሽቦርድ ሜታዳታ፣ የገጽ ርዕስ እና የአፕል ድር መተግበሪያ ርዕስን ጨምሮ ይለውጣል። የመነጨው አንጸባራቂ የማይንቀሳቀስ ስም ነው የሚጠቀመው፣ ስለዚህ ይህ ቅንብር አስቀድሞ የተጫነ መተግበሪያ ዳግም ለመሰየም ዋስትና አይሰጥም።

### ብጁ Favicon

ብጁ ፋቪኮን የአሳሹን favicon ይለውጣል። የመጫኛ አንጸባራቂ አሁንም ከላይ ያሉትን PNG ፋይሎችን ያስተዋውቃል; ፋቪኮን መቀየር እነዚያን የመነሻ ስክሪን አዶዎች አይተኩም።

## ገደቦች

- **የአገልጋይ ግንኙነት ያስፈልጋል፡-** የገጽ አሰሳ፣ ዳሽቦርድ ሁኔታ እና API ጥያቄዎች ከመስመር ውጭ መመለስ የላቸውም።
- **የበስተጀርባ ማመሳሰል የለም፡** ከመስመር ውጭ ድርጊቶች ለመድገም አልተሰለፉም።
- **የአሳሽ ልዩነቶች፡-** የመጫኛ ምናሌዎች፣ የመስኮት አቀራረብ እና የማሳወቂያ ድጋፍ እንደ መድረክ ይለያያሉ።
- **ምንም API ምላሽ መሸጎጫ የለም** ሰራተኛው API፣ ዳሽቦርድ እና የማረጋገጫ መንገዶችን አያካትትም።
- **የማይንቀሳቀሱ የመጫኛ አዶዎች፡-** እነዚያን አዶዎች ማዘመን የማስታወቂያ ንብረቶችን መለወጥ ያስፈልገዋል; አሳሾች የተጫነውን ሜታዳታ ማቆየት ይችላሉ።
