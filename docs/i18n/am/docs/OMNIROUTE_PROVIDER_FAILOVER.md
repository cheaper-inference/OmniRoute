ድክመቶች እንደገና ከመሞከርዎ በፊት ይመደባሉ.

እንደ የጊዜ ማብቂያዎች፣ የአውታረ መረብ ስህተቶች፣ የዋጋ ገደቦች እና የአቅራቢ 5xx ምላሾች ያሉ ጊዜያዊ ውድቀቶች ሊሳኩ ይችላሉ። የተሟጠጠ ኮታ ወይም ክሬዲት (ኮታ 429፣ ወይም 402 ክፍያ የሚፈለግ) በአንድ አቅራቢ ላይ በጭራሽ አይሞከርም ነገር ግን ኮታው የተለየ ከሆነ ለሌላ አልተሳካም። የማረጋገጫ ስህተቶች፣ የፈቃድ ስህተቶች፣ ልክ ያልሆኑ ጥያቄዎች፣ የማይገኙ ሞዴሎች እና ያልታወቁ ውድቀቶች በጭፍን አይሞከሩም።

ነባሪው የአቅራቢዎች ፖሊሲ እስከ ሶስት የአቅራቢዎች ሙከራዎችን ይፈቅዳል፣ የታሪፍ ገደቦችን እና የጊዜ ማብቂያዎችን እንደገና ይሞክራል፣ በተዳከመ ኮታ ላይ አይሳካም እና የአስተዳደር አካል ጉዳተኝነትን ከጊዜያዊ የወረዳ ሁኔታ ይለያል።

## የት እንደሚተገበር

- **ኮምቦስ** በኮምቦው በራሱ ስልት እና መቼት መሰረት በዒላማቸው መካከል አለመሳካቱ።
- **ባዶ ሞዴል መታወቂያ** (ምንም `provider/` ቅድመ ቅጥያ የለም) የሚያገለግሉት በርካታ አቅራቢዎች፣ ምንም አይነት ትክክለኛ ስም ሳይኖራቸው፣ መጀመሪያ ወደ አቅራቢው ምርጫዎች ይላካሉ። ያ ሙከራው ፖሊሲው በማይሳካበት መንገድ ካልተሳካ፣ ተመሳሳዩ ጥያቄ መታወቂያውን ለሚያገለግለው ቀጣዩ ንቁ አቅራቢ ይላካል። ምላሹ ከመለሰው በፊት ከተሞከሩት የአቅራቢዎች ብዛት ጋር `x-omniroute-fallback-attempts` ይይዛል።
  - እያንዳንዱ ተለዋጭ በትክክል እንደተመረጠው ሁሉ ተፈቅዶለታል። API ቁልፍን ያግዳል ወይም ያላመነ ዒላማ ያለ የላይ ዥረት ጥሪ ተዘሏል፣ እና ደንበኛው እውነተኛውን የወራጅ ስሕተት ነው የሚያገኘው እንጂ ፈፅሞ ያልተሰየመውን ኢላማ ውድቅ የሚያደርግ አይደለም።
  - ያልተሳካ ምላሽ ብቻ ነው የሚሄደው፡ ከመጀመሪያው የተለቀቀ ባይት በኋላ ምንም ነገር አይሳካም።
  - የአደጋ ጊዜ መመለሻ ሞዴል መለዋወጥ ተግባራዊ የሚሆነው እያንዳንዱ የተጠየቀው ሞዴል አቅራቢ ካልተሳካ በኋላ ነው።
  - በግንኙነት (`x-omniroute-connection`) ላይ የተለጠፈ ጥያቄ በእሱ ላይ ይቆያል።
  - ቅድመ ቅጥያ መታወቂያ (`provider/model`) በጭራሽ ወደ ሌላ አቅራቢ አይዛወርም።

የወረዳ ግዛቶች `closed`፣ `open` እና `half_open` ናቸው። አንድ ማቀዝቀዣ የታሰሩ መጠይቅን መርሐግብር; የተሳካ መጠይቅ ወረዳውን ይዘጋዋል እና ያልተሳካለት ምርመራ እንደገና ይከፍታል.
