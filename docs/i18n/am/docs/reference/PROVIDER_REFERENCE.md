## ምድቦች

- **ነፃ** — በAPI ቁልፍ የሚገኝ ነፃ ደረጃ (በዳሽቦርዱ በኩል የሚዋቀር)
- **ማረጋገጫ የማይፈልግ** — ምንም ቁልፍ ወይም መግባት የማይፈልጉ ይፋዊ መዳረሻዎች
- **OAuth** — በOmniRoute የሚከናወን የመግቢያ ሂደት፤ የAPI ቁልፍ አያስፈልግም
- **የድር ኩኪ** — የኩኪ ማረጋገጫን በመጠቀም የአቅራቢውን የድር መተግበሪያ ይጠቀልላል
- **API ቁልፍ** — በAPI ቁልፍ የሚዋቀር ክፍያ የሚጠይቅ አቅራቢ (ነፃ ክሬዲቶች ሊኖሩ ይችላሉ)
- **አካባቢያዊ** — በተጠቃሚው ማሽን ላይ ይሰራል (Ollama, LM Studio, vLLM, ወዘተ)
- **ፍለጋ** — የድር ፍለጋ አቅራቢዎች
- **ድምፅ** — ድምፅ-ብቻ አቅራቢዎች (TTS/STT)
- **የላይኛው ዥረት ፕሮክሲ** — ወደ ሌሎች አቅራቢዎች በፕሮክሲ የሚያስተላልፉ አቅራቢዎች
- **የደመና ወኪል** — ለረጅም ጊዜ የሚሰሩ የኮድ ማዘጋጃ ወኪሎች (Codex Cloud, Devin, Jules)
- **ስርዓት** — የOmniRoute ውስጣዊ አቅራቢዎች (loopback, ወዘተ)

ተጨማሪ መለያዎች፦ `image`፣ `video`፣ `aggregator`፣ `enterprise`፣ `embed/rerank`፣ `self-hosted`።

`Tool calling` (በሚታይበት ቦታ)፦ `native` — እውነተኛ የተግባር-ጥሪ API፤ `emulated` — የ`tools` ድርድሩ በ`webTools.ts` በኩል በመጠየቂያ የተመሰለ ነው (በመደበኛ አገላለጽ የሚተነተኑ `<tool>{...}</tool>` ብሎኮች)፤ `none` — `tools` በአሁኑ ጊዜ ያለማሳወቂያ ይተዋል። #7286ን ይመልከቱ።

እያንዳንዱን አቅራቢ ለማንቃት፣ ለማዋቀር እና ለመፈተሽ በ`/dashboard/providers` ላይ ያለውን ዳሽቦርድ ይጠቀሙ።
