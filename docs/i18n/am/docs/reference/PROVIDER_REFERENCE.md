## ምድቦች

- **ነፃ** — የAPI ቁልፍ ያለው ነፃ ደረጃ (በዳሽቦርዱ በኩል የሚዋቀር)
- **ማረጋገጫ የሌለው** — ምንም ቁልፍ ወይም መግባት የማይፈልጉ ይፋዊ መገናኛ ጫፎች
- **OAuth** — በOmniRoute የሚስተናገድ የመግቢያ ሂደት፤ የAPI ቁልፍ አያስፈልግም
- **የድር ኩኪ** — የአቅራቢውን የድር መተግበሪያ በኩኪ ማረጋገጫ ይጠቀልላል
- **የAPI ቁልፍ** — በAPI ቁልፍ የሚዋቀር የሚከፈልበት አቅራቢ (ነፃ ክሬዲቶች ሊኖሩ ይችላሉ)
- **አካባቢያዊ** — በተጠቃሚው ማሽን ላይ ይሰራል (Ollama, LM Studio, vLLM, ወዘተ)
- **ፍለጋ** — የድር ፍለጋ አቅራቢዎች
- **ድምፅ** — ለድምፅ ብቻ የሚያገለግሉ አቅራቢዎች (TTS/STT)
- **የላይኛው ደረጃ ፕሮክሲ** — ወደ ሌሎች አቅራቢዎች ፕሮክሲ የሚያደርጉ አቅራቢዎች
- **የደመና ወኪል** — ለረጅም ጊዜ የሚሰሩ የኮድ ጽሑፍ ወኪሎች (Codex Cloud, Devin, Jules)
- **ስርዓት** — የOmniRoute ውስጣዊ አቅራቢዎች (loopback, ወዘተ)

ተጨማሪ መለያዎች፦ `image`፣ `video`፣ `aggregator`፣ `enterprise`፣ `embed/rerank`፣ `self-hosted`።

`የመሣሪያ ጥሪ` (በታየበት ቦታ)፦ `native` — እውነተኛ የፈንክሽን ጥሪ API፤ `emulated` — የ`tools` ድርድሩ በ`webTools.ts` በኩል በመጠየቂያ የተመሰለ ነው (በregex የሚተነተኑ `<tool>{...}</tool>` ብሎኮች)፤ `none` — `tools` በአሁኑ ጊዜ ያለማሳወቅ ይተዋል። #7286ን ይመልከቱ።

እያንዳንዱን አቅራቢ ለማንቃት፣ ለማዋቀር እና ለመፈተሽ በ`/dashboard/providers` ያለውን ዳሽቦርድ ይጠቀሙ።
