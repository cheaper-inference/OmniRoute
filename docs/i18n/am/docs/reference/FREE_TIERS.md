## TL;DR — ምን ያህል ነፃ መረጃ በትክክል OmniRoute ?

እነዚህ አኃዞች በካታሎግ ውስጥ የተለያዩ የሶስተኛ ወገን መለያዎችን እና የብቁነት ሁኔታዎችን ያብራራሉ። OmniRoute ይህንን በጀት አይሰጥም፡ የሚፈለጉትን ሂሳቦች ወይም ምስክርነቶች ማግኘት፣ ብቁ አቅራቢዎችን ማገናኘት እና ገደባቸውን ማክበር አለቦት። ምንም ብቁ መንገድ በሌለው አዲስ ተከላ ላይ ዜሮን ጨምሮ ትክክለኛው ጥቅም ላይ ሊውል የሚችል አቅም ዝቅተኛ ሊሆን ይችላል። `tos: avoid` ምልክት የተደረገባቸው አቅራቢዎች በነባሪ ከራስ-ሰር ማዘዋወር የተገለሉ ናቸው።

**የተረጋገጠ 2026-10-08:** [Cerebras](https://www.cerebras.ai/pricing) የመክፈያ ዘዴ የሚያስፈልገው የአንድ ጊዜ $5 የማስተዋወቂያ ክሬዲት ያቀርባል፣ ከ30 ቀናት በኋላ ጊዜው ያበቃል። [Gemini](https://ai.google.dev/gemini-api/docs/rate-limits) project/model/tier መጠን ገደቦችን ያትማል; ከተገመተው ወርሃዊ አርእስት ውጭ ይቆያል።

- **ምን መግቢያ በእርግጥ ማረጋገጫ ይሰጣል።** ምንም ግቤት በየረድፉ በራስ የመተማመን ደረጃን አይሰጥም፣ እና API ምንም — አያገለግልም ከላይ ያለውን እያንዳንዱን ምስል እንደ ተመሳሳይ ያልተገለጸ የጥራት ግምት ነው። ሁለት እውነታዎች የተለያዩ ናቸው፣ ምክንያቱም እነሱ ከመገመት ይልቅ በእጅ የተያዙ ናቸው፡ 44 ግቤቶች በገለልተኛነት የተረጋገጠ ደረቅ ማቆሚያ (39ኙ የ xKiro ረድፎች፣ ሁሉም አንድ የቀን አበል የሚካፈሉ) እና 22 ግቤቶች ፈጣን የስልጠና መረጃን ይይዛሉ። `hardStopGuaranteed` የሚዘጋጀው የአቅራቢው የራሱ ውል ከነፃ አበል ማለፍ ጥያቄውን ውድቅ የሚያደርገው በጸጥታ ማስከፈል ከመጀመር ይልቅ፣ ከመግቢያው ቀጥሎ ባለው አስተያየት ምንጩ ሲናገር ብቻ ነው። መቼም ለ `true` ነባሪው አይደለም፣ እና ማንም ያልተረጋገጠ ግቤት እንዳልተዋቀረ ይቆያል። ስለዚህ የጠፋ ባንዲራ ማለት "አልተቋቋመም" ማለት አይደለም "ለእርስዎ ለማስከፈል አይታወቅም" ማለት አይደለም.**STRICT ሁነታ** (የመርጦ መግቢያ `freeAccessPolicy=strict` ማዞሪያ ጠባቂ) ባንዲራውን የያዙ ግቤቶችን ብቻ ያምናል፤ ሁሉም ሌሎች ነፃ እርከኖች እንደ `no-hard-stop` ተገለሉ ( `open-sse/services/autoCombo/strictZeroCostFilter.ts` ይመልከቱ)። ጠባቂው ገንዳውን ሲያጣራ ኦፕሬተር-የሚታየው ምዝግብ ማስታወሻ ሁለቱንም የተገለሉበትን ብዛት እና `no-hard-stop` ድርሻውን ሪፖርት ያደርጋል።
- `estMonthlyFreeTokens` = ተደጋጋሚ ወርሃዊ ቶከኖች ብቻ።** የአንድ ጊዜ የመመዝገቢያ ክሬዲቶች አይደጋገሙም።** እና እንደ 0 ይቁጠሩ። የተቋረጡ ደረጃዎች እንዲሁ 0 ናቸው።
- ዕለታዊ ማስመሰያ ካፕ → `monthly = daily × 30`. RPD ብቻ የተመዘገበ → `RPD × ~800 output tokens × 30`. RPM/TPM ብቻ (የዕለታዊ ካፕ የለም) →** ያልተሸፈነ** (ከዚህ በታች ይመልከቱ).
- **ነፃ መዳረሻ፣ ግን ምንም የታተመ የማስመሰያ ካፕ የለም።** (`glm-cn`, `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `nvidia`) እነዚህ ናቸው rate/concurrency-limited. ን እንመድባቸዋለን `recurring-uncapped` እና** መቼም አይጠቃለልም።** — ማባዛት `RPM × 24/7 × 30d` ምናባዊ ጣራ ይፈጥራል (የምንቀበለው የዋጋ ግሽበት)። NVIDIA's API ለሙከራ-አጠቃቀም ብቻ ነው; ከታች ያለውን ToS caveat ይመልከቱ.
- **የተቀማጭ መክፈቻ ጭማሪ፡** ነጻ ኮታ በቋሚነት የሚያነሳ የአንድ ጊዜ ትንሽ ክፍያ (OpenRouter: $10 → 1000 req/day ≈ +24M/mo)። እንደ የተለየ አሃዝ ሪፖርት ተደርጓል፣ ከቋሚ አርዕስተ ዜና ውጪ።
- **ብቁነት-የተከለለ ኮታዎች** (`eligibilityGate: "regional-identity"`): ከክልል ጋር የተያያዘ የማንነት ማረጋገጫ (ሜይንላንድ-ቻይና እውነተኛ ስም ዛሬ ከተረጋገጠ) በኋላ ብቻ የሚከፈት እውነተኛ ተደጋጋሚ ኮታ። ከተመሳሳዩ የፑል-ዲዱፔ ህግ ጋር ወደ ተለየ አሃዝ (`gatedRecurringTokens`) ተቆጥሯል፣ ወደ ጽኑ ርዕስ በጭራሽ። ገዥው አካል (`freeType`) አልተለወጠም, ስለዚህ ማዞሪያው አልተለወጠም.
- **የማስረጃ ክፍሎች.** ደንቡ፡ በካታሎግ ውስጥ ያለ ቁጥር ምንጩን ጠቅሷል `// evidence:` አስተያየት ከመግቢያው ቀጥሎ — `public-page` (የአቅራቢው ገጽ ማንም ሊያነበው ይችላል)፣ `api-public` (ያልተረጋገጠ የአቅራቢው የመጨረሻ ነጥብ፣ ለምሳሌ NaraRouter's public plans endpoint at router.bynara.id) ወይም `console-verified <date> por <who>` (ሥዕሉ በአካውንት ኮንሶል ውስጥ ብቻ ነው የሚታየው፣ አስተያየቱ ማን እንደሆነ እና መቼ እንደሆነ መዝግቧል)። ግዛቱ ዛሬ፡ በ2026-09-02 እንደገና ኦዲት የተደረገው አምስቱ ብሎኮች ተሸክመውታል (`gemini`, `groq`, `mistral`, `ollama-cloud`, `nara`); ከ2026-09-02 ድጋሚ ኦዲት በፊት የነበሩ ግቤቶች እስኪነኩ ድረስ የቀደመውን ጥናት ይወርሳሉ። ማንኛውም** አዲስ ወይም ተለውጧል** ያለ ማስረጃ አስተያየት ቁጥር ስህተት ነው። ዛሬ `mistral` ብቻ በኮንሶል የተረጋገጠ ነው።

## ለምን ቁጥራችን ከሌሎች ሰብሳቢዎች ያነሰ ነው

በዚህ ቦታ ውስጥ ያሉት አብዛኛዎቹ "ነጻ ቶከኖች በወር" ቁጥሮች የአንድ ሞዴል መለያዎች ድምር ናቸው። የኛ ሆን ተብሎ አይደለም፡-

- **እያንዳንዱ የጋራ ገንዳ አንድ ጊዜ ይቆጠራል.** ከአንድ አበል ጀርባ አምስት ሞዴሎች አንድ አበል እንጂ አምስት አይደሉም። የረድፍ-በረድፍ ንባብ ተመሳሳይ ካታሎግ እና ለምን እንደምናተም, [እንዴት እንደምንቆጥር](#how-we-count) ላይ ነው.
- **ዕለታዊ ካፕቶች ይለወጣሉ፣ ተመኖች አይደሉም።** የተመዘገበ tokens/day ካፕ `× 30` ይሆናል; የሰነድ requests/day ካፕ `RPD × ~800 tokens × 30` ይሆናል; በደቂቃ ጥያቄዎችን ብቻ የሚያትም አቅራቢ አለው።** አይ** ወርሃዊ ምስል እና _ያልተጠረጠረ_ ተብሎ ተዘርዝሯል፣ በጭራሽ አልተጠቃለልም። የዋጋ ንረትን በ 24/7 ማባዛት እምቢ ያልነው የዋጋ ግሽበት ነው።
- **ከክልላዊ ማንነት ማረጋገጫ በስተጀርባ ያሉት ኮታዎች ተለያይተው ይታያሉ** (`+~6M behind regional identity verification`), ምክንያቱም አብዛኛዎቹ አንባቢዎች ሊጠቀሙባቸው አይችሉም.
- **የመመዝገቢያ ክሬዲቶች የመጀመሪያ ወር ብቻ ናቸው።** እና እንደ ሁለተኛ አሃዝ ሪፖርት ተደርጓል፣ ወደ ቋሚ ቁጥር ፈጽሞ አልተቀላቀለም።
- **የሰነዶች ቼክ ምን እንደሚሰራ።** `npm run check:docs-counts` (የመልቀቅ ሁኔታ) ትክክለኛውን አሃዝ ፣የመጀመሪያውን ወር አሃዝ እና ሁለት ረድፍ-በረድፍ ድምርን ከካታሎግ ያሰላል እና README፣ይህ ገጽ ወይም ነፃ የደረጃ መመሪያው የተለየ እሴት ሲያትሙ ወይም ትልቁን ምስል ያለ መለያው እና እውነተኛው ሲያትሙ አይሳካም። የበጀት ካርዱ በሚለቀቅበት ጊዜ ከተመሳሳይ እውነታዎች ተዘጋጅቷል።

## የToS ትኩረት ሰንጠረዥ

> **የToS ምልክት ምክረ ሃሳብ ብቻ ነው፣ የማዞሪያ መግቢያ መስፈርት አይደለም።** `tos` ምልክት የተሰጣቸው አቅራቢዎች አሁንም በነባሪነት በማዞሪያ እና በጥምረት/መተኪያ ውስጥ ይካተታሉ፤ ምልክቱ በ`/dashboard/free-tiers` እና `/api/free-tier/summary` ላይ ብቻ ይታያል። `excludeTosAvoid` የጥያቄ መለኪያው የማጠቃለያ እይታን ብቻ ይነካል፣ አጠቃላይ ማዞሪያን አይነካም። ውሳኔው በ`open-sse/config/freeTierCatalog.ts` ውስጥ ይገኛል (መረጃ ለመስጠት ብቻ ነው፣ በማዞሪያ ሞተሮች አይነበብም)።

> ራስዎ ለሚያስተናግዱት፣ ለአንድ ተጠቃሚ የግል ፕሮክሲ የእያንዳንዱ አቅራቢ የአጠቃቀም ደንቦች አጭር ግምገማ። `caution` = ሊመረመር የሚገባ የግል አጠቃቀም ወይም የፕሮክሲ አንቀጽ፤ `ambiguous` = ግልጽ ያልሆነ፤ `ok` = በግልጽ የተፈቀደ። ለመረጃ ብቻ ነው፣ የሕግ ምክር አይደለም — ውሳኔውን እርስዎ ይወስናሉ።
