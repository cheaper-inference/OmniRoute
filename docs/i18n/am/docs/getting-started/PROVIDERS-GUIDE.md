## አቅራቢ ምንድን ነው?

አቅራቢን እንደ **ስልክ አገልግሎት ሰጪ** ያስቡት። ለመደወል የስልክ አገልግሎት ሰጪ እንደሚያስፈልግዎት ሁሉ፣ የAI ሞዴሎችን ለመጠቀም የAI አቅራቢ ያስፈልግዎታል። OmniRoute ከ**ሁሉም አገልግሎት ሰጪዎች** ጋር እንደሚሠራ ስልክ ነው — በመካከላቸው በራስ-ሰር መቀያየር ይችላሉ።

| ----------- | ------------------- | ------------------------------- | ---------------- |

## ፈጣን ጅምር፦ የመጀመሪያውን አቅራቢዎ ያገናኙ

### በመጀመሪያ ማስኬድ ወቅት የሚደረግ አማራጭ የነፃ አቅራቢ ማዋቀር

የመጀመሪያ ማስኬድ አዋቂው ግልጽ የሆነ **ነፃ አቅራቢዎችን ያዋቅሩ** ካርድ ያቀርባል። አሁን ብቁ የሆኑትን
ዝርዝር ከOmniRoute ማረጋገጫ የማይጠይቁ አቅራቢዎች መዝገብ ያወጣል፤ ከዚያም ከማረጋገጥዎ በፊት እያንዳንዱን
አቅራቢ እንዲገመግሙ እና ከምርጫ እንዲያስወግዱ ያስችልዎታል። OmniRoute የአቅራቢውን የጥንቃቄ ማሳሰቢያ እና ወደ ድረ ገጹ የሚወስድ አገናኝ ያሳያል፤
ይህም በመጀመሪያ የሦስተኛ ወገን ውሎችን፣ ግላዊነትን፣ ተገኝነትን እና የአጠቃቀም መጠን ገደቦችን እንዲገመግሙ ያስችልዎታል።

ይህ እርምጃ አማራጭ ነው፦ አዋቂውን መጨረስ የነፃ አቅራቢ ግንኙነቶችን በድብቅ ፈጽሞ አይፈጥርም።
አሁንም ያልተጨመሩ አቅራቢዎችን ብቻ ይፈጥራል፣ ነባር ብጁ ግንኙነቶችን
ሳይነካ ይተዋል፣ እንዲሁም የተፈጠሩ፣ አስቀድመው የተዋቀሩ እና ያልተሳኩ አቅራቢዎችን ለየብቻ ያሳውቃል። ከፊል ውጤት ካገኙ በኋላ
ያልተሳኩትን ብቻ በደህንነት እንደገና መሞከር ይችላሉ።

### አማራጭ A፦ ነፃ አቅራቢ (የብድር ካርድ አያስፈልግም)

1. ዳሽቦርዱን በ`http://localhost:20128` ይክፈቱ
2. ወደ **አቅራቢዎች** → **አቅራቢ ያክሉ** ይሂዱ
3. ከእነዚህ ነፃ አቅራቢዎች አንዱን ይምረጡ፦
   - **Kiro AI** — ነፃ Claude ሞዴሎች (ማረጋገጫ አያስፈልግም)
   - **Pollinations** — ነፃ GPT-5፣ Claude፣ Gemini (ቁልፍ አያስፈልግም)
   - **LongCat** — 10M ቶከኖች በነፃ (የአንድ ጊዜ ስጦታ፣ መለያ + KYC ያስፈልጋል)
   - **Cloudflare AI** — 50+ ሞዴሎች፣ 10K ኒውሮኖች/ቀን
   - **MLX Gemma 26B** — የአካባቢ Apple Silicon ሞዴል (~38.5 tok/s፣ ~15.9GB RAM)
   - **MLX Qwen 3.8 27B** — የአካባቢ Apple Silicon ሞዴል (~9.1 tok/s፣ ~13.1GB RAM)
4. **ያገናኙ**ን ጠቅ ያድርጉ
5. ተጠናቋል! አሁን ነፃ የAI መዳረሻ አለዎት።

### አማራጭ D፦ የአካባቢ MLX ሞዴሎች (Apple Silicon)

የጋራ ማህደረ ትውስታ ላላቸው Apple Silicon Macs፣ OmniRoute በ`mlx-lm.server` በኩል የሚሰሩ የአካባቢ MLX ሞዴሎችን እንደ መደበኛ OpenAI-ተኳኋኝ የአካባቢ አቅራቢዎች ማገናኘትን ይደግፋል።

#### ቅድመ ሁኔታዎች

- **Apple Silicon Mac** (M1/M2/M3/M4)፤ 24GB+ የጋራ ማህደረ ትውስታ ይመከራል
- **uv** የጥቅል አስተዳዳሪ፦ `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**: `uv pip install mlx-lm`

#### ፈጣን ጅምር

1. **ጥገኛዎችን ይጫኑ**፦

   ```bash
   # uv አስቀድሞ ካልተጫነ ይጫኑ
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # mlx-lmን ይጫኑ
   uv pip install mlx-lm
   ```

2. **የMLX ሰርቨሮችን በእጅ ያስጀምሩ** (በተለያዩ ተርሚናሎች)፦

   ```bash
   # ተርሚናል 1፦ Gemma 4 26B A4B IT-QAT (ወደብ 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # ተርሚናል 2፦ Qwen 3.8 27B MLX Mixed (ወደብ 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **በOmniRoute ዳሽቦርድ ውስጥ ያገናኙ**፦
   - ወደ **አቅራቢዎች** → **አቅራቢ ያክሉ** ይሂዱ
   - **MLX Gemma 26B** ወይም **MLX Qwen 3.8 27B**ን ይምረጡ
   - **ያገናኙ**ን ጠቅ ያድርጉ (የAPI ቁልፍ አያስፈልግም)

4. **ከOpenCode ጋር ይጠቀሙ**፦
   ```bash
   # OmniRouteን እንዲጠቀም OpenCodeን ያዋቅሩ
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <your-omniroute-api-key>

   # የMLX ሞዴሎችን ይጠቀሙ
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

እንደ `qodercli` ሊገኝ ይገባል፣ ወይም `CLI_QODER_BIN`ን ወደ ተፈጻሚው ዱካ ያቀናብሩ። በDocker አስተናጋጅ ላይ
ብቻ የተጫነ CLI በኮንቴነሩ ውስጥ በራስ-ሰር አይኖርም። የሌሉ ባይነሪዎች ወደ መጫኑ ወይም የዱካ ቅንብሩ
የሚመራዎትን ግልጽ ስህተት ያስከትላሉ።

የPAT ውይይት ዱካ የ45 ሰከንድ የሂደት ጊዜ ገደብ አለው። ውይይቱን ወደ አንድ
መጠየቂያ ያጠቃልልና CLIን ዥረት በሌለው የህትመት ሁነታ ይጠራል። `stream: true`ን መጠየቅ
የምላሹን ኤንቨሎፕ ወደ SSE ይቀይረዋል፤ ነገር ግን ከላይኛው ምንጭ ቶከኖችን በቅደም ተከተል ማድረስን አያቀርብም።
የCLI ማረጋገጥ/የሞዴል ዝርዝር ማውጣት የተለየ የ20 ሰከንድ ጊዜ ገደብ ይጠቀማል። እነዚህ የአሁኑ የኮድ
ነባሪዎች ናቸው፤ ሊዋቀሩ የሚችሉ የዳሽቦርድ ቅንብሮች አይደሉም።

ለቀላል ውይይት የPAT ግንኙነቶችን ይጠቀሙ። `tools`ን ወይም የቆዩ `functions`ን
የያዙ የወኪል ጥያቄዎች፣ የተሰኩ የጥምር ኢላማዎችን ጨምሮ፣ በማረጋገጫ መረጃ ምርጫ ወቅት የPAT መለያዎችን
ያስወግዳሉ። የተቀላቀለ የQoder ስብስብ አሁንም የHTTP መለያውን መምረጥ ይችላል። ወደPAT አስፈጻሚው
የሚደረጉ ቀጥተኛ ጥሪዎችም የመሣሪያ ትርጓሜዎችን በጸጥታ ከመጣል ይልቅ CLIን ከማስጀመራቸው በፊት
ግልጽ በሆነ ሁኔታ ይወድቃሉ። ይህ ገደብ የሚመለከተው በAPI ጠሪው የቀረቡ መሣሪያዎችን እንጂ Qoder
CLI ራሱ ሊጠቀምባቸው የሚችሉ ማንኛውንም ውስጣዊ መሣሪያዎች አይደለም። የHTTP ቁልፍ እያንዳንዱ ሞዴል
መሣሪያዎችን እንደሚደግፍ ዋስትና አይሰጥም፤ መደበኛ የሞዴል ችሎታ ማረጋገጫዎች አሁንም ተግባራዊ ይሆናሉ።

የአሳሽ OAuth የሚገኘው አስተዳዳሪው አምስቱንም ቅንብሮች ሲያዋቅር ብቻ ነው፦

## የተለመዱ ጥያቄዎች

### "OmniRouteን ለመጠቀም መክፈል ያስፈልገኛል?"

**አይ!** OmniRoute ነፃና ክፍት ምንጭ ነው። ነፃ አቅራቢዎችን (Kiro, Pollinations) ምንም ሳይከፍሉ መጠቀም ይችላሉ። የሚከፍሉት የሚከፈልባቸውን አቅራቢዎች ለመጠቀም ከመረጡ ብቻ ነው።

### "በየትኛው አቅራቢ መጀመር አለብኝ?"

በ**Kiro AI** ይጀምሩ — ነፃ ነው፣ API key አያስፈልገውም፣ እንዲሁም Claude ሞዴሎችን እንዲጠቀሙ ያስችልዎታል። ከዚያም እንደ አስፈላጊነቱ ተጨማሪ አቅራቢዎችን ያክሉ።

### "ብዙ አቅራቢዎችን በአንድ ጊዜ መጠቀም እችላለሁ?"

**አዎ!** የOmniRoute ዋና ዓላማ ይኸው ነው። ብዙ አቅራቢዎችን ያገናኙና OmniRoute ለእያንዳንዱ ጥያቄ ምርጡን እንዲመርጥ `model: "auto"`ን ይጠቀሙ።

### "አንድ አቅራቢ መስራት ቢያቆምስ?"

OmniRoute ያልተሳካላቸውን አቅራቢዎች በራስ-ሰር ይዘላቸዋልና ቀጣዩን ይሞክራል። እርስዎ ምንም ማድረግ አያስፈልግዎትም።

### "አንድን አቅራቢ እንዴት አቋርጣለሁ?"

ወደ Providers ይሂዱ → አቅራቢውን ጠቅ ያድርጉ → **Disconnect**ን ጠቅ ያድርጉ።

### "አሁን ያሉኝን API keys መጠቀም እችላለሁ?"

**አዎ!** ለOpenAI, Anthropic, Google, ወዘተ API keys ካሉዎት፣ በOmniRoute ውስጥ ሊጠቀሙባቸው ይችላሉ። አቅራቢውን ሲያገናኙ በቀላሉ ይለጥፏቸው።
