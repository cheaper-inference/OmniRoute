## Kategorier

- **Gratis** — gratis niveau med API-nøgle (konfigureres via kontrolpanelet)
- **Uden godkendelse** — offentlige slutpunkter, der slet ikke kræver en nøgle eller et login
- **OAuth** — loginforløb håndteres af OmniRoute, ingen API-nøgle nødvendig
- **Webcookie** — integrerer udbyderens webapp via cookiegodkendelse
- **API-nøgle** — betalt udbyder konfigureret via API-nøgle (gratis kreditter kan være tilgængelige)
- **Lokal** — kører på brugerens maskine (Ollama, LM Studio, vLLM osv.)
- **Søgning** — udbydere af websøgning
- **Lyd** — udbydere kun til lyd (TTS/STT)
- **Opstrømsproxy** — udbydere, der fungerer som proxy for andre udbydere
- **Cloudagent** — langvarigt kørende kodeagenter (Codex Cloud, Devin, Jules)
- **System** — interne OmniRoute-udbydere (loopback osv.)

Yderligere tags: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (hvor det vises): `native` — ægte API til funktionskald; `emulated` — `tools`-arrayet emuleres via prompten gennem `webTools.ts` (regex-fortolkede `<tool>{...}</tool>`-blokke); `none` — `tools` ignoreres i øjeblikket uden besked. Se #7286.

Brug kontrolpanelet på `/dashboard/providers` til at aktivere, konfigurere og teste hver udbyder.
