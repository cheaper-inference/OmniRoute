## Kategorier

- **Gratis** — gratistjänst med API-nyckel (konfigureras via kontrollpanelen)
- **Ingen autentisering** — offentliga slutpunkter som inte kräver någon nyckel eller inloggning alls
- **OAuth** — inloggningsflöde hanteras av OmniRoute, ingen API-nyckel behövs
- **Webbkaka** — omsluter leverantörens webbapp via kakaautentisering
- **API-nyckel** — betald leverantör konfigurerad via API-nyckel (gratis krediter kan gälla)
- **Lokal** — körs på användarens maskin (Ollama, LM Studio, vLLM, etc.)
- **Sök** — webbsöksleverantörer
- **Ljud** — endast ljudleverantörer (TTS/STT)
- **Uppströms proxy** — leverantörer som proxar till andra leverantörer
- **Molnagent** — långvariga kodningsagenter (Codex Cloud, Devin, Jules)
- **System** — OmniRoute-interna leverantörer (loopback, etc.)

Ytterligare taggar: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (Verktygsanrop) (där det visas): `native` — verklig funktionanrops-API; `emulated` — `tools`-arrayen är prompt-emulerad via `webTools.ts` (regex-parsade `<tool>{...}</tool>`-block); `none` — `tools` ignoreras för närvarande tyst. Se #7286.

Använd kontrollpanelen på `/dashboard/providers` för att aktivera, konfigurera och testa varje leverantör.
