> OmniRoute-un davranışını **yenidən yerləşdirmə olmadan** dəyişən icra vaxtı keçidləri.
> Burada sadalanan hər bir bayraq
> [`src/shared/constants/featureFlagDefinitions.ts`](../../src/shared/constants/featureFlagDefinitions.ts)
> faylında müəyyən edilib — bu, yeganə həqiqət mənbəyidir. Həm idarə paneli, həm də REST API
> həmin fayldan məlumat oxuyur, buna görə də aşağıdakı cədvəl ona 1:1 uyğun olacaq şəkildə yaradılıb.

---

## Funksiya Bayraqları Nədir

Funksiya bayrağı, dəyəri icra vaxtında dəyişdirilə və verilənlər bazasında saxlanıla bilən,
prosesin yenidən yerləşdirilməsini tələb etməyən adlandırılmış keçiddir (boolean və ya enum).
Hər bir bayraq `key`, `label`, `description`, `category`, `defaultValue`, `type` və
`requiresRestart` göstərişinə malik `FeatureFlagDefinition` vasitəsilə təsvir olunur.

### Həll Etmə Ardıcıllığı

Bayrağın **qüvvədə olan dəyəri**
[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) tərəfindən aşağıdakı
üstünlük sırasına əsasən müəyyən edilir (daha yüksək olan qalib gəlir):

1. **DB əvəzləməsi** — `feature_flags` ad fəzası altında `key_value` cədvəlində
   saxlanılan dəyər (idarə paneli və ya REST API vasitəsilə təyin edilir).
2. **Mühit dəyişəni** — təyin edilibsə və boş deyilsə, `process.env[<KEY>]`.
3. **Tərifdəki standart dəyər** — `featureFlagDefinitions.ts` faylındakı `defaultValue`.

Boolean bayrağının qüvvədə olan dəyəri `"true"`, `"1"` və ya `"yes"` olduqda,
o, **aktiv** hesab edilir (`isFeatureFlagEnabled()` funksiyasına baxın).

> [!NOTE]
> Əksər bayraqların [`ENVIRONMENT.md`](./ENVIRONMENT.md) sənədində göstərilən,
> **eyni ada** malik uyğun mühit dəyişəni də var. Bayrağın DB əvəzləməsi həmin
> mühit dəyişənindən üstündür. `requiresRestart: true` olan bayraq dərhal saxlanılır,
> lakin yalnız proses başladıqda yenidən oxunur — onu dəyişdirmək idarə panelində
> **"Serveri yenidən başladın"** bannerini göstərir.

## Funksiya bayraqlarının dəyişdirilməsi

### İdarəetmə paneli

**İdarəetmə paneli → Parametrlər → Funksiya bayraqları** bölməsinə keçin
(`/dashboard/settings/feature-flags`). Cədvəl
(`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`)
aşağıdakıları dəstəkləyir:

- Açar və ya təsvir üzrə **axtarış**, həmçinin kateqoriya üzrə **filtrləmə** (əlavə olaraq sintetik
  **Yenidən başlatma tələb edir** görünüşü).
- Məntiqi bayraqlar üçün **keçid**, enum bayraqları üçün isə **açılan siyahı**
  (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`).
- Hər bayraq üçün qüvvədə olan dəyərin haradan gəldiyini göstərən **mənbə nişanı** — `DB`, `ENV` və ya `DEF`.
- Əvəzləməni silmək üçün **Sıfırla** düyməsi (yalnız mənbəyi `DB` olan bayraqlar üçün göstərilir)
  və aşağı hissədə **Bütün əvəzləmələri sıfırla** düyməsi.
- `requiresRestart` bayrağı dəyişdirildikdə **Serveri yenidən başladın** banneri.

### REST API

Bütün əməliyyatlar vahid marşrut vasitəsilə həyata keçirilir:
[`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts).
Hər bir metod autentifikasiya edilmiş idarəetmə paneli sessiyası tələb edir (əks halda `401`).

#### `GET /api/settings/feature-flags`

Hər bir bayrağı onun qüvvədə olan dəyəri, mənbəyi və xülasəsi ilə birlikdə qaytarır.

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Require API Key",
      "description": "Require an API key for all incoming requests",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... 111 bayrağın hamısı
  ],
  "summary": {
    "total": 56,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

Tək bir əvəzləməni təyin edir və ya silir. Sorğu gövdəsi: `{ key: string; value?: string }`.
`value` göstərilmədikdə əvəzləmə silinir (mühit / standart dəyər bərpa olunur).

```bash
# DB əvəzləməsini təyin edin
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# Əvəzləməni silin ("value" yoxdur)
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

Cavab yeni `effectiveValue`/`source`, əvvəlki `previousValue`/
`previousSource` və `requiresRestart` dəyərlərini qaytarır. Naməlum açarlar və icazə verilən diapazondan kənar enum
dəyərləri `400` xətası ilə rədd edilir.

#### `DELETE /api/settings/feature-flags`

Bütün DB əvəzləmələrini bir dəfəyə təmizləyərək hər bir bayrağı mühit / standart
dəyərinə qaytarır. `{ cleared: <count>, message: "..." }` qaytarır.

> [!NOTE]
> `requiresRestart: true` olan bayraqlar yalnız proses yenidən yükləndikdən sonra qüvvəyə minir.
> İdarəetmə panelinin yenidən başlatma axını `POST /api/restart` çağırışını edir və sonra server yenidən əlçatan olana qədər
> `GET /api/health/ping` sorğusunu təkrarlayır.

## Fövqəladə Büdcə Ehtiyat Mexanizmi

`OMNIROUTE_EMERGENCY_FALLBACK` (`runtime` kateqoriyası, standart dəyər `true`)
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts)
faylındakı fövqəladə pulsuz ehtiyat marşrutunu idarə edir. Aktiv olduqda, büdcəsini
tükədən sorğular tamamilə uğursuz olmaq əvəzinə pulsuz ehtiyat provayderə/modelə
yönləndirilir. Bu davranışı deaktiv etmək və büdcəsi tükənmiş sorğuların uğursuz
olmasına imkan vermək üçün idarəetmə panelindəki keçid, verilənlər bazası
parametrinin əvəzlənməsi və ya `OMNIROUTE_EMERGENCY_FALLBACK` mühit dəyişəni
vasitəsilə onu `false` (və ya `0`) olaraq təyin edin. (PR-lər #3741 / #3752-də
idarəetmə paneli keçidi kimi təqdim edilib.)

Bu ehtiyat mexanizmi vasitəsilə təqdim edilən cavab
`X-OmniRoute-Emergency-Fallback: from=<provider/model>; to=<provider/model>`
başlığını daşıyır; beləliklə, müştəri `X-OmniRoute-Provider` başlığını öz sorğusu
ilə müqayisə etmədən sorğunun yenidən yönləndirildiyini müəyyən edə bilər. Bu
başlıq bütün digər cavablarda mövcud deyil.
