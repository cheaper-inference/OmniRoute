Ümumi provayder sayı: **376**. Aşağıdakı kateqoriyalar üzrə bölgüyə baxın.

## Kateqoriyalar

- **Pulsuz** — API açarı ilə pulsuz tarif (idarəetmə paneli vasitəsilə konfiqurasiya edilir)
- **Autentifikasiyasız** — heç bir açar və ya giriş tələb etməyən açıq son nöqtələr
- **OAuth** — giriş prosesi OmniRoute tərəfindən idarə olunur, API açarı tələb edilmir
- **Veb kukisi** — kuki autentifikasiyası vasitəsilə provayderin veb tətbiqini əhatələyir
- **API açarı** — API açarı vasitəsilə konfiqurasiya edilən ödənişli provayder (pulsuz kreditlər tətbiq oluna bilər)
- **Lokal** — istifadəçinin kompüterində işləyir (Ollama, LM Studio, vLLM və s.)
- **Axtarış** — veb axtarış provayderləri
- **Audio** — yalnız audio provayderləri (TTS/STT)
- **Yuxarı axın proksisi** — digər provayderlərə proksi rolunu oynayan provayderlər
- **Bulud agenti** — uzunmüddətli kodlaşdırma agentləri (Codex Cloud, Devin, Jules)
- **Sistem** — OmniRoute-un daxili provayderləri (loopback və s.)

Əlavə teqlər: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (göstərildiyi hallarda): `native` — real funksiya çağırma API-si; `emulated` — `tools` massivi `webTools.ts` vasitəsilə prompt səviyyəsində emulyasiya edilir (regex ilə təhlil olunan `<tool>{...}</tool>` blokları); `none` — `tools` hazırda heç bir xəbərdarlıq edilmədən nəzərə alınmır. #7286-ya baxın.

Hər bir provayderi aktivləşdirmək, konfiqurasiya etmək və sınaqdan keçirmək üçün `/dashboard/providers` ünvanındakı idarəetmə panelindən istifadə edin.
