## `src/` — Next.js tətbiqi

```
src/
├── app/                 # App Router (səhifələr + API marşrutları + status səhifələri + açılış səhifəsi)
├── lib/                 # Əsas kitabxanalar / domen modulları (80 alt qovluq + ~70 üst səviyyəli fayl)
├── domain/              # Təmiz domen məntiqi (policy engine, fallback, cost, lockout, comboResolver, assessment)
├── server/              # Yalnız-server modulları (authz pipeline, cors, auth middleware) — klientdən import edilə bilməz
├── shared/              # Təhlükəsiz olduğu yerlərdə server və klient arasında paylaşılan (constants, types, validation, contracts, utils)
├── i18n/                # next-intl konfiqurasiyası + hər lokal üçün mesaj JSON-u (67 lokal)
├── middleware/          # Next.js middleware-i (sorğu zənginləşdirilməsi, lokal aşkarlanması)
├── mitm/                # MITM proxy nüvəsi: sertifikat yaradılması/quraşdırılması, handlers, targets, inspector, masks, passthrough
│   ├── handlers/        # MitmHandlerBase-i genişləndirən 9 IDE-agent handler sinfi (antigravity, kiro, copilot, codex, cursor, zed, claudeCode, openCode, trae)
│   └── inspector/       # Trafik tutma qatı: buffer (yaddaşdaxili halqa), sseMerger, conversationNormalizer, kindDetector, contextKey, httpProxyServer, systemProxyConfig
├── models/              # Model adapter birləşdiricisi (legacy shim)
├── scripts/             # Ağacdaxili baxım skriptləri (məs., backfillAggregation)
├── sse/                 # Legacy SSE handler-ləri/servisləri (chat.ts, chatHelpers.ts, services/auth.ts)
├── store/               # Legacy yaddaşdaxili store (src/lib/db xeyrinə tədricən çıxarılır)
├── types/               # Paylaşılan TS tip faylları
├── instrumentation.ts   # Next.js telemetriya hook-u (brauzer + edge)
├── instrumentation-node.ts  # Yalnız Node üçün instrumentalizasiya
└── proxy.ts             # HTTP-proxy giriş shim-i
```

## `_ideia/`, `_mono_repo/`, `_references/`, `_tasks/` — Ağacdan kənar qovluqlar

Bu alt xətt prefiksli qovluqlar çatdırılmayan (shipping-ə daxil olmayan) məzmunu saxlayır:

- **`_ideia/`** — dizayn qeydləri (defer / notfit / viable kateqoriyaları)
- **`_mono_repo/`** — tarixi altlayihələr (omnirouteCloud, omnirouteSite, vscode-extension)
- **`_references/`** — inkişaf zamanı çarpaz istinad üçün əlaqəli OSS layihələrinin yalnız-oxunan klonları (LiteLLM, 9router, ClawRouter, CLIProxyAPI, modelrelay, new-api və s.)
- **`_tasks/`** — hər buraxılış üçün tapşırıq izləmə faylları (qeyri-rəsmi)

`npm pack` çıxışına daxil deyil. Bax: `.npmignore`.

## Naviqasiya məsləhətləri

- **Yeni töhfəçi?** Oxuyun: `CONTRIBUTING.md` → `CLAUDE.md` → `docs/architecture/ARCHITECTURE.md` → `docs/architecture/CODEBASE_DOCUMENTATION.md`.
- **Provayder əlavə edirsiniz?** `docs/architecture/ARCHITECTURE.md § Adding a New Provider` bölməsini izləyin + `docs/reference/PROVIDER_REFERENCE.md` ilə çarpaz yoxlayın.
- **Route əlavə edirsiniz?** `docs/architecture/ARCHITECTURE.md § Adding a New API Route` + `src/shared/validation/schemas.ts`.
- **MCP aləti əlavə edirsiniz?** `docs/frameworks/MCP-SERVER.md § Adding a Tool`.
- **A2A bacarığı əlavə edirsiniz?** `docs/frameworks/A2A-SERVER.md § Adding a New Skill`.
- **Lokalda işə salırsınız?** `docs/guides/SETUP_GUIDE.md`.
- **Deploy edirsiniz?** `docs/guides/DOCKER_GUIDE.md` / `docs/ops/VM_DEPLOYMENT_GUIDE.md` / `docs/ops/FLY_IO_DEPLOYMENT_GUIDE.md`.
- **Reliz edirsiniz?** `docs/ops/RELEASE_CHECKLIST.md` (və `/generate-release-cc` Claude Code bacarığı).
