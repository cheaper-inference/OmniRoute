ការបរាជ័យត្រូវបានចាត់ថ្នាក់មុននឹងការសម្រេចចិត្តសាកល្បងម្តងទៀត។

ការបរាជ័យបណ្តោះអាសន្នដូចជាការអស់ពេល កំហុសបណ្តាញ ដែនកំណត់អត្រា និងការឆ្លើយតប 5xx របស់អ្នកផ្តល់សេវាអាចនឹងបរាជ័យ។ កូតា ឬឥណទានដែលអស់ (កូតា 429 ឬ 402 តម្រូវឱ្យបង់ប្រាក់) មិនត្រូវបានព្យាយាមម្តងទៀតលើអ្នកផ្តល់សេវាដូចគ្នាទេ ប៉ុន្តែមិនបានសម្រេចលើអ្នកផ្តល់សេវាផ្សេងទៀត ដែលកូតាគឺដាច់ដោយឡែកពីគ្នា។ កំហុសក្នុងការផ្ទៀងផ្ទាត់ភាពត្រឹមត្រូវ កំហុសការអនុញ្ញាត សំណើមិនត្រឹមត្រូវ ម៉ូដែលដែលមិនអាចប្រើបាន និងការបរាជ័យដែលមិនស្គាល់មិនត្រូវបានព្យាយាមម្តងទៀតដោយងងឹតងងល់នោះទេ។

គោលការណ៍អ្នកផ្តល់សេវាឆ្លងតាមលំនាំដើមអនុញ្ញាតឱ្យមានការប៉ុនប៉ងអ្នកផ្តល់សេវារហូតដល់បីដង ការកំណត់អត្រាការព្យាយាមឡើងវិញ និងការអស់ពេល បរាជ័យលើសកូតាអស់ហើយ និងរក្សាការបិទដំណើរការរដ្ឋបាលដាច់ដោយឡែកពីស្ថានភាពសៀគ្វីបណ្តោះអាសន្ន។

## កន្លែងដែលវាអនុវត្ត

- **បន្សំ** បរាជ័យរវាងគោលដៅរបស់ពួកគេ យោងទៅតាមយុទ្ធសាស្ត្រ និងការកំណត់ផ្ទាល់ខ្លួនរបស់បន្សំ។
- **លេខសម្គាល់ម៉ូដែលទទេ** (គ្មានបុព្វបទ `provider/` ) ដែលអ្នកផ្តល់សេវាសកម្មជាច្រើនបម្រើ ដោយគ្មានបន្សំនៃឈ្មោះពិតប្រាកដនោះ ត្រូវបានផ្ញើជាលើកដំបូងទៅកាន់អ្នកផ្តល់សេវាជ្រើសរើស។ ប្រសិនបើការប៉ុនប៉ងនោះបរាជ័យតាមរបៀបដែលគោលការណ៍នេះបរាជ័យ សំណើដូចគ្នានេះត្រូវបានផ្ញើទៅអ្នកផ្តល់សេវាសកម្មបន្ទាប់ដែលបម្រើលេខសម្គាល់។ ការឆ្លើយតបមាន `x-omniroute-fallback-attempts` ជាមួយនឹងចំនួនអ្នកផ្តល់សេវាដែលបានព្យាយាមមុនអ្នកដែលឆ្លើយ។
  - ជម្មើសជំនួសនីមួយៗត្រូវបានអនុញ្ញាតយ៉ាងពិតប្រាកដដូចជាប្រសិនបើការសន្និដ្ឋានបានជ្រើសរើសវា។ គោលដៅដែលប្លុកគ្រាប់ចុច API ឬមិនទទួលស្គាល់ត្រូវបានរំលងដោយគ្មានការហៅឡើងលើ ហើយអតិថិជនទទួលបានកំហុសឆ្គងពិតប្រាកដ មិនមែនជាការបដិសេធគោលនយោបាយសម្រាប់គោលដៅដែលវាមិនដែលមានឈ្មោះនោះទេ។
  - មានតែការឆ្លើយតបដែលបរាជ័យប៉ុណ្ណោះដែលបន្តដំណើរការ៖ គ្មានអ្វីដែលបរាជ័យបន្ទាប់ពីការផ្សាយបៃលើកដំបូង។
  - ការប្តូរគំរូជំនួសពេលសង្គ្រោះបន្ទាន់អនុវត្តតែបន្ទាប់ពីអ្នកផ្តល់សេវាទាំងអស់នៃគំរូដែលបានស្នើសុំបានបរាជ័យ។
  - សំណើដែលបានភ្ជាប់ទៅនឹងការតភ្ជាប់ (`x-omniroute-connection`) ស្ថិតនៅលើវា។
  - លេខសម្គាល់បុព្វបទ (`provider/model`) មិនត្រូវបានបញ្ជូនបន្តទៅកាន់អ្នកផ្តល់សេវាផ្សេងទៀតទេ។

ស្ថានភាពសៀគ្វីគឺ `closed`, `open`, និង `half_open`។ Cooldown កំណត់កាលវិភាគនៃការស៊ើបអង្កេតដែលមានព្រំដែន; ការស៊ើបអង្កេតជោគជ័យបិទសៀគ្វី ហើយការស៊ើបអង្កេតដែលបរាជ័យបើកវាឡើងវិញ។
