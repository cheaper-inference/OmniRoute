> ជ្រើសរើសចូល បិទតាមលំនាំដើម (`modelVisibilityAllowlist`/`modelVisibilityDenylist` ទាំងពីរទទេទុកកាតាឡុក `/v1/models` AND គ្រប់បេក្ខជន `auto/*` បៃបៃ-ដូចគ្នាបេះបិទ)។ បងប្អូនបង្កើតរបស់ `hidePaidModels`/`hideAutoCombos` (`src/lib/db/settings.ts`) សម្រាប់ប្រតិបត្តិករដែលចង់បានបញ្ជីគំរូដែលបានរៀបចំសម្រាប់ហេតុផលដែលមិនពាក់ព័ន្ធនឹងការចំណាយ។

## ហេតុអ្វីបានជាវាមាន

`hidePaidModels` ឆ្លើយ "តើម៉ូដែលនេះឥតគិតថ្លៃទេ?" ហើយ `hideAutoCombos` ឆ្លើយថា "តើលេខសម្គាល់និម្មិត `auto/*` គួរតែត្រូវបានផ្សាយពាណិជ្ជកម្មទាល់តែសោះ?" — ក៏មិនអនុញ្ញាតឱ្យប្រតិបត្តិកររៀបចំសំណុំរងតាមអំពើចិត្តនៃម៉ូដែលដែរ (ឧ. ការបង្ហាញម៉ូដែលដែលបានផ្តល់ឱ្យ Claude Code / OpenCode គួរតែមើលឃើញដោយឯករាជ្យនៃតម្លៃ)។ #11481 បន្ថែមថាជាជម្រើសឯករាជ្យពីរ ជ្រើសរើសក្នុងការកំណត់ខ្សែអក្សរអារេ។

## ការកំណត់

| សោ                         | ប្រភេទ     | លំនាំដើម | អត្ថន័យ                                                      |
| -------------------------- | ---------- | -------- | ------------------------------------------------------------ |
| `modelVisibilityDenylist`  | `string[]` | `[]`     | ធាតុដែលត្រូវគ្នានឹងបេក្ខជនលាក់វាពីអាង catalog/candidate ។    |
| `modelVisibilityAllowlist` | `string[]` | `[]`     | នៅពេលដែលមិនទទេ ធាតុ ONLY ដែលផ្គូផ្គងនឹងបេក្ខជននៅតែលាតត្រដាង។ |

ទាំងពីរទទួលយករហូតដល់ 500 ធាតុរហូតដល់ 200 តួអក្សរនីមួយៗ (Zod-validated in `src/shared/validation/settingsSchemas.ts`) ។ ធាតុចូលគឺ៖

- លេខសម្គាល់កាតាឡុកពិតប្រាកដ — `"gpt-4o"` (លេខសម្គាល់គំរូទទេ) ឬ `"openai/gpt-4o"` (បុព្វបទអ្នកផ្តល់សេវា) ឬ
- លំនាំ glob ដោយប្រើ `*`/`?` — ឧ. `"openai/gpt-4*"` ឬ `"anthropic/*"` — ត្រូវបានដោះស្រាយតាមរយៈឧបករណ៍ផ្គូផ្គង `globToRegex()` ដែលបានចែករំលែកដូចគ្នា (`src/shared/utils/globPattern.ts`) ដែលប្រើរួចហើយដោយការគូសផែនទីបន្សំក្នុងមួយគំរូរបស់ `ModelRoutingSection` និង `freeModels.ts::matchesOnlyPaidModels`.

អាទិភាព៖ បញ្ជីបដិសេធត្រូវបានពិនិត្យជាមុន (ធាតុដែលត្រូវបានបដិសេធតែងតែត្រូវបានលាក់ ទោះបីជាវាត្រូវគ្នានឹងបញ្ជីអនុញ្ញាតក៏ដោយ) នៅពេលដែលបញ្ជីអនុញ្ញាតគឺមិនទទេ មានតែធាតុដែលវាត្រូវគ្នាប៉ុណ្ណោះដែលនៅរស់។

## ចំណុចទាញពីរ មិនមែនមួយទេ។

មេរៀនពី #6512 (តម្រងកាតាឡុក `hidePaidModels` -only នៅតែអនុញ្ញាតឱ្យ `auto/*` ផ្លូវទៅកាន់គំរូដែលបានបង់ ចាប់តាំងពីក្រុមបេក្ខជនបន្សំត្រូវបានបង្កើតដោយឯករាជ្យ) អនុវត្តដូចគ្នានៅទីនេះ។ ការផ្គូផ្គង predicate `isModelExposureAllowed()` (`src/shared/utils/modelExposureList.ts`) ត្រូវបានគេហៅថាពី BOTH:

- `src/app/api/v1/models/catalog.ts` — បញ្ជី `/v1/models` ដោយខ្លួនវាផ្ទាល់ នៅចំណុចដូចគ្នា 5 ក្នុងមួយប្រភព `shouldHidePaid()` ច្រកទ្វាររួចហើយ ( `PROVIDER_MODELS` ឋិតិវន្ត , ជួរអ្នកផ្តល់សេវាដែលបានធ្វើសមកាលកម្ម ជួរដេកផ្ទាល់ខ្លួន ជួរដេកដែលគាំទ្រដោយឈ្មោះក្លែងក្លាយ ជួរដែលបានគ្រប់គ្រង - ត្រឡប់ថយក្រោយ) ។
- `open-sse/services/autoCombo/modelExposureFilter.ts::filterModelExposureCandidates()` — ហៅពី `virtualFactory.ts::buildPreparedPool` ភ្លាមៗបន្ទាប់ពីការហៅ `filterPaidOnlyCandidates()` សមមូល ដូច្នេះគំរូដែលត្រូវបានបដិសេធមិនអាចត្រូវបានជ្រើសរើសទៅក្នុងក្រុមបេក្ខជន `auto/*` ទេ។

## អ្វីដែលត្រូវបានត្រង NOT

ឥរិយាបថដែលមានស្រាប់របស់កញ្ចក់ `hideAutoCombos`៖ លេខសម្គាល់គំរូដែលបានផ្ញើ** យ៉ាងច្បាស់លាស់** (មិនមែនតាមរយៈ `auto/*` និងមិនត្រូវបានរកឃើញតាមរយៈបញ្ជីកាតាឡុក) មិនត្រូវបានរារាំងនៅពេលបញ្ជូន — មានតែសមាជិកភាព advertisement/candidate-pool ប៉ុណ្ណោះដែលត្រូវបានត្រង។ នេះគឺឯករាជ្យនៃ `hidePaidModels`; ប្រតិបត្តិករអាចចង់បានសំណុំដែលបានរៀបចំសម្រាប់ហេតុផលដែលមិនពាក់ព័ន្ធនឹងការចំណាយ ដូច្នេះការកំណត់ទាំងពីរផ្សំជាតម្រង AND-ed ឯករាជ្យ ដូចគ្នានឹងសមាសភាពពហុទង់ដែលមានស្រាប់នៅក្នុង `catalog.ts`។

ការកំណត់ការនាំចេញ (`GET /api/settings/export-json`) រួមបញ្ចូលអារេទាំងសងខាង ដូចជាវាលការកំណត់ផ្សេងទៀតណាមួយ — មិនដូចតម្រងនាំចេញជំហានបន្សំរបស់ `hidePaidModels` មិនមានហានិភ័យនៃការផ្តល់ជាតិទឹកឡើងវិញនៅទីនេះទេ៖ លេខសម្គាល់ដែលត្រូវបានបដិសេធដែលបានបង្កប់នៅក្នុងជំហានបន្សំដែលបាននាំចេញគឺជាជម្រើសផ្លូវច្បាស់លាស់ផ្ទាល់ខ្លួនរបស់ប្រតិបត្តិករ មិនមែនជាអ្វីដែលព្រំដែននាំចេញត្រូវការដកចេញនោះទេ។

## ការចុះបញ្ជីសម្រាប់តែបន្សំ (`exposeCombosOnly`)

ប៊ូលីនដាច់ដោយឡែក ក៏ជ្រើសរើសចូល និង `false` តាមលំនាំដើម សម្រាប់ការដាក់ឱ្យប្រើប្រាស់ដែលបន្សំគឺជាផ្ទៃគំរូសាធារណៈ ហើយអ្នកផ្តល់សេវាគ្រាន់តែជាផ្នែកខាងក្រោយប៉ុណ្ណោះ។ នៅពេលដែលវាជា `true` ការចុះបញ្ជីជាសាធារណៈ (`GET /v1/models`, `GET /v1`, និងផ្លូវស្វែងរក `/v1` ផ្សេងទៀតដែលបានសាងសង់នៅលើ `getUnifiedModelsResponse()`) រក្សាតែជួរដេកជាមួយ `owned_by: "combo"`: បន្សំអ្នកប្រើប្រាស់បូកនឹងបន្សំ `auto/*` ដែលភ្ជាប់មកជាមួយ (លុះត្រាតែ `hideAutoCombos` លាក់ពួកវា) ។ វាប្រើការធ្វើតេស្តជួរដេកដូចគ្នានឹង `catalogScope: "combos"` ក្នុងមួយគ្រាប់ចុច ហើយតម្រង allow/deny/scope ផ្ទាល់ខ្លួនរបស់សោនៅតែអនុវត្តនៅលើកំពូល។

បិទបើកវាចូល** ការកំណត់ → កំណត់ផ្លូវ → ម៉ូដែល API ការចុះបញ្ជី** ឬជាមួយ `PATCH /api/settings {"exposeCombosOnly": true}`។

ដូចបញ្ជីខាងលើ វាផ្លាស់ប្តូរតែការផ្សាយពាណិជ្ជកម្មប៉ុណ្ណោះ៖

- លេខសម្គាល់ `provider/model` ច្បាស់លាស់នៅតែបញ្ជូន ហើយ `GET /v1/models/{id}` នៅតែដោះស្រាយវា;
- កាតាឡុកផ្ទាំងគ្រប់គ្រង (`GET /api/models/catalog` ប្រើដោយអ្នកជ្រើសរើសម៉ូដែល) មិនត្រូវបានរួមតូចទេ។
- វាមិនត្រូវបានឆ្លុះបញ្ចាំងចូលទៅក្នុងអាងបេក្ខជន `auto/*` ទេ ដូច្នេះបន្សំ `auto/*` រក្សាអាងពេញលេញរបស់ពួកគេ។
