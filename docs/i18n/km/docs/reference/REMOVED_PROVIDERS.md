## គោលការណ៍

1. **សំណើដកចេញពីប្រតិបត្តិករសេវាកម្មត្រូវបានគោរព មិនមែនយកមកចរចាទេ។** OmniRoute
   មិនមានទំនាក់ទំនងជាផ្លូវការជាមួយសេវាកម្មដើមណាមួយឡើយ។ នៅពេលប្រតិបត្តិករនៃសេវាកម្មមួយស្នើឱ្យដក
   ការរួមបញ្ចូលចេញ វាត្រូវតែត្រូវបានដកចេញ ទោះបីជាការរួមបញ្ចូលនោះបានប្រើ API ផ្លូវការ ឬអត់ក៏ដោយ។
2. **"បានដកចេញ" មានន័យថាគ្រប់ផ្ទៃប្រើប្រាស់ទាំងអស់ដែល OmniRoute គ្រប់គ្រង។** កម្មវិធីប្រតិបត្តិ ធាតុក្នុងបញ្ជីឈ្មោះ លេខសម្គាល់អ្នកផ្តល់សេវា
   និងឈ្មោះក្លែងកាត់ បញ្ជីម៉ូដែល ចំណុចចុង បរិស្ថានអថេរ រូបតំណាង កាតផ្ទាំងគ្រប់គ្រង
   ឯកសារយោងអ្នកផ្តល់សេវាដែលបានបង្កើត `FREE_TIERS.md` ឯកសារយោងបរិស្ថាន ចំនួនក្នុង README
   ច្បាប់ចម្លង `llm.txt` តេស្តជាក់លាក់ និងរូបថតគំរូយោង មតិយោបល់ក្នុងកូដ ចំណុចរាយក្នុង CHANGELOG
   (ជាមួយការផ្ទៀងផ្ទាត់ដែលបានចុះកំណត់ត្រា សូមមើល `config/release/changelog-reconciliations.json`)
   កំណត់ចំណាំ GitHub Releases វិគី ព្រមទាំងបញ្ហា កិច្ចពិភាក្សា និង pull request របស់ GitHub ដែលមាន
   ប្រធានបទអំពីអ្នកផ្តល់សេវានោះ (បញ្ហា និងកិច្ចពិភាក្សាត្រូវបានលុប; pull request ត្រូវបានប្តូរចំណងជើង ការពិពណ៌នា
   របស់វាត្រូវបានជំនួស ហើយខ្សែសន្ទនាត្រូវបានចាក់សោ ព្រោះ GitHub មិនអាចលុប pull request បានទេ)។
3. **កុំដាក់ធាតុណាមួយនៅលើទំព័រនេះបញ្ចូលឡើងវិញដោយគ្មានការអនុញ្ញាតជាលាយលក្ខណ៍អក្សរ។** នេះរួមបញ្ចូលទាំង
   ការបន្ថែមលេខសម្គាល់ ឬឈ្មោះក្លែងកាត់ទៅក្នុងកាតាឡុកអ្នកផ្តល់សេវាណាមួយវិញ ការបន្ថែមដែនទៅក្នុងកម្មវិធីប្រតិបត្តិ
   ការទទួលយក PR របស់អ្នករួមចំណែកដែល "ស្ដារ" វាឡើងវិញ ការបន្ថែមវាទៅក្នុងកាតាឡុកម៉ូដែលឥតគិតថ្លៃ ឬ
   ការចងក្រងឯកសារអំពីវិធីធ្វើដោយដៃដើម្បីចូលប្រើវាតាមរយៈ OmniRoute។ បិទ PR និងបញ្ហាបែបនេះ ដោយភ្ជាប់
   តំណទៅកាន់ទំព័រនេះ។

   ការដាក់បញ្ចូលឡើងវិញប៉ុណ្ណោះ៖ អត្តសញ្ញាណសម្គាល់ ដែន កាលបរិច្ឆេទ និង pull request ដែលបានអនុវត្តការដកចេញ។
   កុំពិពណ៌នាអំពីរបៀបដែលការរួមបញ្ចូលបានដំណើរការ។
