## ប្រភេទ

- **ឥតគិតថ្លៃ** — កម្រិតប្រើប្រាស់ឥតគិតថ្លៃជាមួយ API key (កំណត់រចនាសម្ព័ន្ធតាម dashboard)
- **មិនទាមទារការផ្ទៀងផ្ទាត់** — endpoint សាធារណៈដែលមិនទាមទារ key ឬការចូលគណនីទាល់តែសោះ
- **OAuth** — លំហូរចូលគណនីត្រូវបានគ្រប់គ្រងដោយ OmniRoute ដោយមិនត្រូវការ API key
- **Web cookie** — គ្របដណ្តប់ web app របស់អ្នកផ្តល់សេវាតាមរយៈការផ្ទៀងផ្ទាត់ដោយ cookie
- **API key** — អ្នកផ្តល់សេវាបង់ប្រាក់ដែលកំណត់រចនាសម្ព័ន្ធតាមរយៈ API key (អាចមាន credit ឥតគិតថ្លៃ)
- **មូលដ្ឋាន** — ដំណើរការលើម៉ាស៊ីនរបស់អ្នកប្រើប្រាស់ (Ollama, LM Studio, vLLM ជាដើម)
- **ស្វែងរក** — អ្នកផ្តល់សេវាស្វែងរកលើបណ្ដាញ
- **អូឌីយ៉ូ** — អ្នកផ្តល់សេវាសម្រាប់តែអូឌីយ៉ូប៉ុណ្ណោះ (TTS/STT)
- **ប្រូកស៊ីខាងដើម** — អ្នកផ្តល់សេវាដែលធ្វើប្រូកស៊ីទៅកាន់អ្នកផ្តល់សេវាផ្សេងទៀត
- **ភ្នាក់ងារ Cloud** — ភ្នាក់ងារសរសេរកូដដែលដំណើរការរយៈពេលយូរ (Codex Cloud, Devin, Jules)
- **ប្រព័ន្ធ** — អ្នកផ្តល់សេវាផ្ទៃក្នុងរបស់ OmniRoute (loopback ជាដើម)

ស្លាកបន្ថែម៖ `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`។

`Tool calling` (នៅកន្លែងដែលបង្ហាញ)៖ `native` — API សម្រាប់ហៅ function ពិតប្រាកដ; `emulated` — អារេ `tools` ត្រូវបានត្រាប់តាមរយៈ prompt ដោយប្រើ `webTools.ts` (ប្លុក `<tool>{...}</tool>` ដែលញែកដោយ regex); `none` — បច្ចុប្បន្ន `tools` ត្រូវបានបោះបង់ដោយស្ងៀមស្ងាត់។ សូមមើល #7286។

ប្រើ dashboard នៅ `/dashboard/providers` ដើម្បីបើក កំណត់រចនាសម្ព័ន្ធ និងសាកល្បងអ្នកផ្តល់សេវានីមួយៗ។
