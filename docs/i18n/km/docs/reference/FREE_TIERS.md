- **ប្រភេទភស្តុតាង។** ច្បាប់គឺ៖ លេខមួយក្នុងកាតាឡុកត្រូវដកស្រង់ប្រភពរបស់វាក្នុង comment `// evidence:` នៅក្បែរធាតុនោះ — `public-page` (ទំព័ររបស់អ្នកផ្ដល់សេវាដែលអ្នកណាក៏អាចអានបាន), `api-public` (endpoint ដែលមិនតម្រូវឱ្យ authenticate របស់អ្នកផ្ដល់សេវា ឧ. endpoint សម្រាប់គម្រោងសាធារណៈរបស់ NaraRouter នៅ router.bynara.id), ឬ `console-verified <date> por <who>` (តួលេខអាចមើលឃើញតែនៅក្នុង console របស់គណនីប៉ុណ្ណោះ; comment កត់ត្រាថានរណាបានឃើញវា និងនៅពេលណា ព្រមទាំងទំព័រសាធារណៈដែលបញ្ជាក់ថាកម្រិតនេះមាន)។ ស្ថានភាពបច្ចុប្បន្ន៖ block ទាំងប្រាំដែលបានធ្វើសវនកម្មឡើងវិញនៅថ្ងៃទី 2026-09-02 មានវា (`gemini`, `groq`, `mistral`, `ollama-cloud`, `nara`); ធាតុដែលមានមុនការធ្វើសវនកម្មឡើងវិញនៅថ្ងៃទី 2026-09-02 បន្តប្រើការស្រាវជ្រាវមុន រហូតដល់ពួកវាត្រូវបានកែប្រែ; លេខ **ថ្មី ឬបានផ្លាស់ប្ដូរ** ណាមួយដែលគ្មាន comment ភស្តុតាង គឺជា bug។ បច្ចុប្បន្នមានតែ `mistral` ប៉ុណ្ណោះដែលជា console-verified។

## ហេតុអ្វីបានជាតួលេខរបស់យើងតូចជាងតួលេខរបស់អ្នកប្រមូលផ្តុំផ្សេងទៀត

តួលេខ "ថូខិនឥតគិតថ្លៃក្នុងមួយខែ" ភាគច្រើននៅក្នុងវិស័យនេះ គឺជាផលបូកនៃកូតាដែលដាក់ស្លាកតាមម៉ូដែលនីមួយៗ។ ដោយចេតនា តួលេខរបស់យើងមិនមែនដូច្នោះទេ៖

- **កូតារួមនីមួយៗត្រូវបានរាប់តែម្តង។** គម្រោងឥតគិតថ្លៃរបស់ Mistral គឺជាកូតា 1B/ខែ មួយសម្រាប់អង្គការនីមួយៗ; ការរាយវានៅក្រោមម៉ូដែលប្រាំ មិនធ្វើឱ្យវាក្លាយជា 5B ទេ។ ប្រសិនបើបូកតាមម៉ូដែល កាតាឡុករបស់យើងផ្ទាល់នឹងបង្ហាញ **~7.4B** (គណនាឡើងវិញនៅថ្ងៃទី 2026-09-03; តួលេខនេះមិនត្រូវបានត្រួតពិនិត្យដោយ CI ទេ — សូមវាស់វែងឡើងវិញរាល់ពេលកាតាឡុកផ្លាស់ប្តូរ) — ចំណងជើងបង្ហាញ **~1.47B** ពីព្រោះនោះជាចំនួនដែលគណនីមួយពីអ្នកផ្តល់សេវានីមួយៗពិតជាអាចប្រើបាន។

## តារាងចំណុចដែលត្រូវយកចិត្តទុកដាក់អំពី ToS

> **សញ្ញាសម្គាល់ ToS គ្រាន់តែជាការណែនាំប៉ុណ្ណោះ មិនមែនជាច្រកទប់ស្កាត់ការកំណត់ផ្លូវទេ។** តាមលំនាំដើម អ្នកផ្តល់សេវាដែលត្រូវបានសម្គាល់ជា `tos` នៅតែត្រូវបានរួមបញ្ចូលក្នុងការកំណត់ផ្លូវ និងបន្សំ/ផ្លូវបម្រុង; សញ្ញាសម្គាល់នេះគ្រាន់តែបង្ហាញនៅលើ `/dashboard/free-tiers` និង `/api/free-tier/summary` ប៉ុណ្ណោះ។ ប៉ារ៉ាម៉ែត្រសំណួរ `excludeTosAvoid` ប៉ះពាល់តែទិដ្ឋភាពសង្ខេបប៉ុណ្ណោះ មិនប៉ះពាល់ដល់ការកំណត់ផ្លូវសកលទេ។ សេចក្តីវិនិច្ឆ័យស្ថិតនៅក្នុង `open-sse/config/freeTierCatalog.ts` (សម្រាប់ផ្តល់ព័ត៌មានប៉ុណ្ណោះ មិនត្រូវបានអានដោយម៉ាស៊ីនកំណត់ផ្លូវទេ)។
