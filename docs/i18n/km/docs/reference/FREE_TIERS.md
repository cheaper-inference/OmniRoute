## TL;DR — តើការសន្និដ្ឋានដោយឥតគិតថ្លៃប៉ុន្មាន OmniRoute ពិតជាសរុប?

តួលេខទាំងនេះពិពណ៌នាអំពីគណនីភាគីទីបីដាច់ដោយឡែក និងលក្ខខណ្ឌសិទ្ធិទទួលបាននៅទូទាំងកាតាឡុក។ OmniRoute មិនផ្តល់ថវិកានេះទេ៖ អ្នកត្រូវតែទទួលបានគណនីដែលត្រូវការ ឬលិខិតសម្គាល់ ភ្ជាប់អ្នកផ្តល់សេវាដែលមានសិទ្ធិ និងគោរពដែនកំណត់របស់ពួកគេ។ សមត្ថភាពដែលអាចប្រើប្រាស់បានពិតប្រាកដអាចទាបជាង រួមទាំងសូន្យនៅលើការដំឡើងថ្មីដោយគ្មានផ្លូវដែលមានសិទ្ធិ។ អ្នកផ្តល់សេវាដែលបានសម្គាល់ `tos: avoid` ត្រូវបានដកចេញពីការបញ្ជូនដោយស្វ័យប្រវត្តិតាមលំនាំដើម។

- **ជួរកាតាឡុកជាមួយនឹងការចូលប្រើដោយឥតគិតថ្លៃ** (214 ថ្ងៃនេះ)៖ មួយជួរក្នុងមួយអ្នកផ្តល់សេវា និងម៉ូដែល។
- **អាងដែលមានកូតាបោះផ្សាយ** (12 ថ្ងៃនេះ)៖ កូតាចែករំលែកនៅពីក្រោយតួលេខពិត នីមួយៗរាប់ម្តង។

- **បានដាក់ទង់ជាមួយនឹងការផ្តល់ជូនដោយឥតគិតថ្លៃ** (140 + ថ្ងៃនេះ)៖ រាល់អ្នកផ្តល់សេវាដែលមានបញ្ជីឈ្មោះផ្ទុក `hasFree` រួមទាំងការស្វែងរក សំឡេង និងអ្នកផ្តល់ប្រព័ន្ធផ្សព្វផ្សាយ ការសាកល្បង និងក្រេឌីតចុះឈ្មោះ។

## របៀបដែលយើងរាប់

តួលេខបីបានមកពីកាតាឡុកដូចគ្នា បានធ្វើសវនកម្មនៅថ្ងៃទី 2026-11-23៖

- **តួលេខពិតប្រាកដ ~ 90M ថូខឹនឥតគិតថ្លៃក្នុងមួយខែ។** កូតាដែលបានចែករំលែកនីមួយៗត្រូវបានរាប់ម្តង ដូច្នេះគំរូចំនួនប្រាំនៅពីក្រោយប្រាក់ឧបត្ថម្ភប្រចាំថ្ងៃមួយគឺជាប្រាក់ឧបត្ថម្ភមួយ។ នេះគឺជាគណនីមួយដែលអ្នកផ្តល់សេវានីមួយៗអាចប្រើប្រាស់បាន ជាមួយនឹងក្រេឌីតចុះឈ្មោះតែម្តងគត់ ~ 153M ក្នុងខែដំបូងរបស់អ្នក។
- **តួរលេខធំ ~ 11.3B បូកសរុបមួយជួរ** រួមបញ្ចូលការផ្តល់ជូនដែលបានបញ្ចប់។ នេះជាវិធីរាប់កាតាឡុកផ្សេងទៀត។ ស្ទើរតែទាំងអស់វាជាប្រវត្តិសាស្ត្រ៖ 98.6% ពីការផ្តល់ជូនដែលមិនមានទៀតទេ។ យើងបោះពុម្ពវាតែជាមួយស្លាករបស់វា និងជាមួយនឹងតួលេខពិតនៅជាប់នឹងវា។
- **កាតាឡុកបន្តផ្ទាល់ ~ 159M បូកសរុបក្នុងមួយជួរបន្តផ្ទាល់** ៖ ផលបូកពីមួយជួរដូចគ្នាដោយគ្មានការផ្តល់ជូនដែលបានបញ្ចប់។

តួលេខ "ថូខឹនឥតគិតថ្លៃក្នុងមួយខែ" ភាគច្រើននៅក្នុងចន្លោះនេះគឺជាផលបូកនៃស្លាកតាមគំរូ។ របស់យើងមិនមែនក្នុងគោលបំណង៖

- **អាងចែករំលែកនីមួយៗត្រូវបានរាប់ម្តង។** គំរូប្រាំនៅពីក្រោយប្រាក់ឧបត្ថម្ភមួយគឺជាប្រាក់ឧបត្ថម្ភមួយមិនមែនប្រាំ។ ការអានមួយជួរដោយជួរដេកនៃកាតាឡុកដូចគ្នា ហើយហេតុអ្វីបានជាយើងបោះពុម្ពវា គឺនៅលើ [របៀបដែលយើងរាប់](#how-we-count) ។
- **មួកប្រចាំថ្ងៃត្រូវបានបំប្លែង អត្រាមិនមែនទេ។** មួក tokens/day ដែលបានចងក្រងជា `× 30`; មួក requests/day ដែលបានចងក្រងជាឯកសារក្លាយជា `RPD × ~800 tokens × 30`; អ្នកផ្តល់សេវាដែលបោះពុម្ពតែសំណើក្នុងមួយនាទីមាន** ទេ** តួលេខប្រចាំខែ និងត្រូវបានរាយបញ្ជីជា _uncapped_ មិនដែលបូកសរុបទេ។ ការគុណដែនកំណត់អត្រាដោយ 24/7 គឺជាអតិផរណាដែលយើងបដិសេធ។
- **កូតានៅពីក្រោយការត្រួតពិនិត្យអត្តសញ្ញាណក្នុងតំបន់ត្រូវបានបង្ហាញដាច់ដោយឡែក** (`+~6M behind regional identity verification`) ពីព្រោះអ្នកអានភាគច្រើនមិនអាចប្រើវាបាន។
- **ឥណទានចុះឈ្មោះគឺសម្រាប់តែខែដំបូងប៉ុណ្ណោះ។** ហើយបានរាយការណ៍ថាជាតួលេខទីពីរ មិនដែលបញ្ចូលគ្នាទៅក្នុងចំនួនថេរឡើយ។
- **អ្វីដែលឯកសារត្រួតពិនិត្យធ្វើ។** `npm run check:docs-counts` (របៀបចេញផ្សាយ) គណនាឡើងវិញនូវតួរលេខពិត តួលេខខែដំបូង និងការបូកសរុបពីរជួរដោយជួរដេកពីកាតាឡុក ហើយបរាជ័យនៅពេលដែល README ទំព័រនេះ ឬមគ្គុទ្ទេសក៍ថ្នាក់ឥតគិតថ្លៃបោះពុម្ពតម្លៃផ្សេង ឬបោះពុម្ពតួលេខធំដោយគ្មានស្លាក និងរូបពិត។ កាតថវិកាត្រូវបានគូរឡើងវិញពីការពិតដូចគ្នានៅពេលចេញផ្សាយ។

## តារាងយកចិត្តទុកដាក់ចំពោះ ToS

> **សញ្ញា ToS គឺជាការណែនាំ មិនមែនជាច្រកកំណត់ការបញ្ជូនទេ។** អ្នកផ្តល់សេវាដែលមានសញ្ញា `tos` នៅតែត្រូវបានរួមបញ្ចូលក្នុងការបញ្ជូន និង combo/fallback តាមលំនាំដើម។ សញ្ញានេះគ្រាន់តែបង្ហាញនៅលើ `/dashboard/free-tiers` និង `/api/free-tier/summary` ប៉ុណ្ណោះ។ ប៉ារ៉ាម៉ែត្រ query `excludeTosAvoid` មានឥទ្ធិពលតែលើទិដ្ឋភាពសង្ខេបប៉ុណ្ណោះ មិនមែនលើការបញ្ជូនសកលទេ។ សេចក្តីសម្រេចស្ថិតនៅក្នុង `open-sse/config/freeTierCatalog.ts` (សម្រាប់ព័ត៌មានប៉ុណ្ណោះ មិនត្រូវបានអានដោយម៉ាស៊ីនបញ្ជូនទេ)។

> ការអានរហ័សអំពីលក្ខខណ្ឌរបស់អ្នកផ្តល់សេវានីមួយៗ សម្រាប់ប្រូកស៊ីផ្ទាល់ខ្លួនដែលបង្ហោះដោយខ្លួនឯង និងប្រើដោយអ្នកប្រើម្នាក់។ `caution` = មានខ្លឹមសារអំពីការប្រើប្រាស់ផ្ទាល់ខ្លួន ឬប្រូកស៊ីដែលគួរពិនិត្យ; `ambiguous` = មិនច្បាស់លាស់; `ok` = អនុញ្ញាតយ៉ាងច្បាស់។ សម្រាប់ព័ត៌មានប៉ុណ្ណោះ មិនមែនជាដំបូន្មានផ្នែកច្បាប់ទេ — អ្នកជាអ្នកសម្រេច។

### ⚠️ ប្រុងប្រយ័ត្ន — ខ្លឹមសារអំពីការប្រើប្រាស់ផ្ទាល់ខ្លួន / ប្រូកស៊ីដែលគួរពិនិត្យ (16)

> ការចូលប្រើដោយឥតគិតថ្លៃរបស់ពួកគេគឺពិតប្រាកដ ហើយ OmniRoute អាចបញ្ជូនទៅកាន់ពួកគេបាន; ខ្លឹមសារខាងក្រោមគ្រាន់តែជាចំណុចដែលគួរដឹងប៉ុណ្ណោះ។ សេវាដែលប្រើ OAuth/keyless មិនអាចវាស់វែងតាមចំនួន token បានទេ ដូច្នេះវាមិនត្រូវបានរាប់បញ្ចូលក្នុងចំនួនសរុបសំខាន់ទេ (មិនមែនដោយសារវាមិនអាចប្រើបានឡើយ)។
