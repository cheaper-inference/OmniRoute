## តារាងចំណុចដែលត្រូវយកចិត្តទុកដាក់អំពី ToS

> **សញ្ញាសម្គាល់ ToS គ្រាន់តែជាការណែនាំប៉ុណ្ណោះ មិនមែនជាច្រកទប់ស្កាត់ការកំណត់ផ្លូវទេ។** តាមលំនាំដើម អ្នកផ្តល់សេវាដែលត្រូវបានសម្គាល់ជា `tos` នៅតែត្រូវបានរួមបញ្ចូលក្នុងការកំណត់ផ្លូវ និងបន្សំ/ផ្លូវបម្រុង; សញ្ញាសម្គាល់នេះគ្រាន់តែបង្ហាញនៅលើ `/dashboard/free-tiers` និង `/api/free-tier/summary` ប៉ុណ្ណោះ។ ប៉ារ៉ាម៉ែត្រសំណួរ `excludeTosAvoid` ប៉ះពាល់តែទិដ្ឋភាពសង្ខេបប៉ុណ្ណោះ មិនប៉ះពាល់ដល់ការកំណត់ផ្លូវសកលទេ។ សេចក្តីវិនិច្ឆ័យស្ថិតនៅក្នុង `open-sse/config/freeTierCatalog.ts` (សម្រាប់ផ្តល់ព័ត៌មានប៉ុណ្ណោះ មិនត្រូវបានអានដោយម៉ាស៊ីនកំណត់ផ្លូវទេ)។
