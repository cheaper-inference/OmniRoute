# មុនពេលអ្នកចាប់ផ្តើម

> **សំខាន់៖** ត្រូវចម្លងព័ត៌មានសម្ងាត់ពី **សំណើបណ្តាញដែលកំពុងដំណើរការ** ជានិច្ច ហើយ **កុំ** ចម្លងពីកន្លែងផ្ទុក cookie របស់កម្មវិធីរុករក។

បញ្ហាផ្ទៀងផ្ទាត់អត្តសញ្ញាណជាច្រើនកើតឡើងដោយសារការចម្លង cookie ពីកន្លែងខុស។

## កុំចម្លងពីកន្លែងផ្ទុក Cookie

កម្មវិធីរុករកភាគច្រើនបង្ហាញ cookie ដែលបានរក្សាទុកតាមរយៈ៖

```
DevTools
→ Application (or Storage)
→ Cookies
```

ទោះបីជា cookie ទាំងនេះមើលទៅត្រឹមត្រូវក៏ដោយ ក៏ពួកវាអាច៖

- ហួសសុពលភាព
- មិនពេញលេញ
- ខ្វះ cookie ដែលត្រូវបានផ្ញើតែលើសំណើដែលបានផ្ទៀងផ្ទាត់អត្តសញ្ញាណប៉ុណ្ណោះ

ការប្រើតម្លៃទាំងនេះអាចបណ្តាលឱ្យការផ្ទៀងផ្ទាត់អត្តសញ្ញាណបរាជ័យ ទោះបីជាពួកវាមើលទៅមានសុពលភាពក៏ដោយ។

## ចម្លងពីសំណើដែលកំពុងដំណើរការ

ជំនួសមកវិញ សូមប្រើ cookie ពីសំណើដែលបានជោគជ័យ៖

```
DevTools
→ Network
→ Refresh the page
→ Open a chat or conversation request
→ Request Headers
→ Cookie
```

ក្បាលសំណើ `Cookie` មានព័ត៌មានផ្ទៀងផ្ទាត់អត្តសញ្ញាណពិតប្រាកដដែលកម្មវិធីរុករករបស់អ្នកបានប្រើដោយជោគជ័យ។

សម្រាប់អ្នកផ្តល់សេវា Web Cookie ភាគច្រើន នេះគឺជាតម្លៃដែលគួរបិទភ្ជាប់ទៅក្នុង OmniRoute។

# ការដំឡើងទូទៅ

ដំណើរការដំឡើងគឺដូចគ្នាសម្រាប់អ្នកផ្តល់សេវា Web Cookie ភាគច្រើន។

1. ចូលគណនីនៅលើគេហទំព័ររបស់អ្នកផ្តល់សេវា។
2. បើកឧបករណ៍អ្នកអភិវឌ្ឍន៍របស់កម្មវិធីរុករក។
3. បើកផ្ទាំង **Network**។
4. ផ្ទុកទំព័រឡើងវិញ។
5. បើកសំណើជជែក ឬការសន្ទនាដែលបានផ្ទៀងផ្ទាត់អត្តសញ្ញាណ។
6. ចម្លងព័ត៌មានសម្ងាត់សម្រាប់ការផ្ទៀងផ្ទាត់អត្តសញ្ញាណដែលត្រូវការ។
7. បើក OmniRoute។
8. ចូលទៅកាន់ **Providers → Add Provider**។
9. ជ្រើសរើសអ្នកផ្តល់សេវា Web Cookie របស់អ្នក។
10. បិទភ្ជាប់ព័ត៌មានសម្ងាត់។
11. ចុច **Test Connection**។
12. រក្សាទុកអ្នកផ្តល់សេវា។

ព័ត៌មានសម្ងាត់ជាក់លាក់ដែលត្រូវការ អាស្រ័យលើអ្នកផ្តល់សេវា។

## NoTrack (notrack-web)

NoTrack ([notrack.ai](https://notrack.ai)) គឺជាវេទិកាជជែកឥតគិតថ្លៃសម្រាប់អ្នកប្រើប្រាស់ ដែលមិនតម្រូវឱ្យចុះឈ្មោះទេ — សម័យត្រូវបានបង្កើតដោយអនាមិកនៅពេលចូលមើលលើកដំបូង ហើយបន្តរក្សាទុកតាមរយៈ cookie ចំនួនបី៖ `uid`, `si_usr_id` និង `si_ses_id`។ OmniRoute បញ្ជូនបន្ត endpoint `/api/dispatch` ដូចគ្នាតាមរយៈលេខសម្គាល់ម៉ូដែលតែមួយ (`notrack-c` ដែលមានឈ្មោះក្លែងកាត់ថា `ntw`)។

### ជំហានសម្រាប់ភ្ជាប់

1. បើក [notrack.ai](https://notrack.ai) នៅក្នុងកម្មវិធីរុករករបស់អ្នក ហើយទុកឱ្យ cookie សម័យអនាមិកត្រូវបានកំណត់។
2. បើក **ឧបករណ៍អ្នកអភិវឌ្ឍន៍ → បណ្ដាញ** ផ្ទុកទំព័រឡើងវិញ ហើយចុចលើសំណើ `/api` ណាមួយ។
3. នៅក្នុង **បឋមកថាសំណើ** ចម្លងតម្លៃពេញលេញនៃបឋមកថា `Cookie`។
4. នៅក្នុង OmniRoute សូមចូលទៅកាន់ **អ្នកផ្ដល់សេវា → បន្ថែមអ្នកផ្ដល់សេវា → NoTrack Web (ឥតគិតថ្លៃ)**។
5. បិទភ្ជាប់ខ្សែអក្សរ cookie ទៅក្នុងវាល `apiKey` ហើយចុច **រក្សាទុក**។

OmniRoute ស្រង់យក `uid`, `si_usr_id` និង `si_ses_id` ពីខ្សែអក្សរដែលបានបិទភ្ជាប់ ហើយបង្កើតបឋមកថា `Cookie` ស្អាតឡើងវិញដោយប្រើតែគូទាំងនោះ — បូកជាមួយ `nt_session` (token `ntk_…` ដែលត្រូវបានកំណត់សម្រាប់គណនីដែលបានចូលប្រើ) នៅពេលវាមានវត្តមាន។ ប្រសិនបើតម្លៃណាមួយក្នុងចំណោមតម្លៃទាំងបីបាត់ ខ្សែអក្សរដើមដែលបានបិទភ្ជាប់នឹងត្រូវបញ្ជូនបន្តដោយមិនកែប្រែ ដើម្បីឱ្យប្រតិបត្តិករអាចសាកល្បងទម្រង់ជំនួសផ្សេងៗបាន។

### សមត្ថភាព

- ការបំពេញការជជែកទាំងបែប **ស្ទ្រីម និងមិនស្ទ្រីម**។
- **ការហៅឧបករណ៍** — កំណត់ `tools: [...]` នៅក្នុងសំណើ; កម្មវិធីប្រតិបត្តិនឹងបម្លែងពួកវាទៅជាទម្រង់កិច្ចសន្យាស្រោមសំបុត្រហៅឧបករណ៍ ហើយញែកការឆ្លើយតបរបស់ម៉ូដែលត្រឡប់ទៅជា `tool_calls` របស់ OpenAI។
- **`response_format`** — គាំទ្រ `json_object` និង `json_schema`។ កម្មវិធីប្រតិបត្តិស្រង់យក JSON object ដំបូងពីការឆ្លើយតបរបស់ម៉ូដែល ហើយបម្លែងវាទៅជាខ្សែអក្សរមុនពេលបញ្ជូនត្រឡប់។
- **តម្រុយអំពីការវែកញែក** — កម្មវិធីប្រតិបត្តិបញ្ចេញ delta `reasoning` នៅពេលសេវាដើមផ្ញើព្រឹត្តិការណ៍ `thinking`។
