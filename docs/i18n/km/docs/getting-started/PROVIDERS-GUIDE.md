## អ្នកផ្តល់សេវាគឺជាអ្វី?

សូមគិតថាអ្នកផ្តល់សេវាប្រៀបដូចជា **ក្រុមហ៊ុនផ្តល់សេវាទូរសព្ទ**។ ដូចដែលអ្នកត្រូវការក្រុមហ៊ុនផ្តល់សេវាទូរសព្ទដើម្បីធ្វើការហៅទូរសព្ទ អ្នកក៏ត្រូវការអ្នកផ្តល់សេវា AI ដើម្បីប្រើម៉ូដែល AI ផងដែរ។ OmniRoute ប្រៀបដូចជាទូរសព្ទដែលអាចប្រើជាមួយ **ក្រុមហ៊ុនផ្តល់សេវាទាំងអស់** — អ្នកអាចប្តូររវាងពួកវាដោយស្វ័យប្រវត្តិ។

## ចាប់ផ្តើមរហ័ស៖ ភ្ជាប់អ្នកផ្តល់សេវាដំបូងរបស់អ្នក

### ការដំឡើងអ្នកផ្តល់សេវាឥតគិតថ្លៃជាជម្រើសនៅពេលដំណើរការលើកដំបូង

អ្នកជំនួយការដំឡើងនៅពេលដំណើរការលើកដំបូង ផ្តល់កាត **ដំឡើងអ្នកផ្តល់សេវាឥតគិតថ្លៃ** យ៉ាងច្បាស់លាស់។ វាកំណត់បញ្ជីដែលមានសិទ្ធិបច្ចុប្បន្នពីបញ្ជីចុះឈ្មោះអ្នកផ្តល់សេវាដែលមិនត្រូវការការផ្ទៀងផ្ទាត់របស់ OmniRoute បន្ទាប់មកអនុញ្ញាតឱ្យអ្នកពិនិត្យមើល និងដកការជ្រើសរើសអ្នកផ្តល់សេវានីមួយៗ មុនពេលបញ្ជាក់។ OmniRoute បង្ហាញសេចក្តីជូនដំណឹងអំពីការប្រុងប្រយ័ត្នរបស់អ្នកផ្តល់សេវា និងតំណទៅកាន់គេហទំព័ររបស់ពួកគេ ដើម្បីឱ្យអ្នកអាចពិនិត្យមើលលក្ខខណ្ឌ ភាពឯកជន ភាពអាចប្រើបាន និងដែនកំណត់អត្រារបស់ភាគីទីបីជាមុន។

សកម្មភាពនេះជាជម្រើស៖ ការបញ្ចប់អ្នកជំនួយការនឹងមិនបង្កើតការតភ្ជាប់ទៅអ្នកផ្តល់សេវាឥតគិតថ្លៃដោយស្ងាត់ៗឡើយ។ វាបង្កើតតែអ្នកផ្តល់សេវាដែលនៅមិនទាន់មាន ទុកការតភ្ជាប់ដែលមានស្រាប់ និងបានកែសម្រួលតាមតម្រូវការឱ្យនៅដដែល ហើយរាយការណ៍ដោយឡែកពីគ្នាអំពីអ្នកផ្តល់សេវាដែលបានបង្កើត បានកំណត់រចនាសម្ព័ន្ធរួចហើយ និងបានបរាជ័យ។ បន្ទាប់ពីទទួលបានលទ្ធផលមួយផ្នែក អ្នកអាចព្យាយាមម្តងទៀតដោយសុវត្ថិភាពសម្រាប់តែអ្នកផ្តល់សេវាដែលបានបរាជ័យប៉ុណ្ណោះ។

### ជម្រើស A៖ អ្នកផ្តល់សេវាឥតគិតថ្លៃ (មិនត្រូវការកាតឥណទាន)

1. បើកផ្ទាំងគ្រប់គ្រងនៅ `http://localhost:20128`
2. ចូលទៅកាន់ **អ្នកផ្តល់សេវា** → **បន្ថែមអ្នកផ្តល់សេវា**
3. ជ្រើសរើសអ្នកផ្តល់សេវាឥតគិតថ្លៃមួយក្នុងចំណោមអ្នកផ្តល់សេវាទាំងនេះ៖
   - **Kiro AI** — ម៉ូដែល Claude ឥតគិតថ្លៃ (មិនត្រូវការការផ្ទៀងផ្ទាត់)
   - **Pollinations** — GPT-5, Claude, Gemini ឥតគិតថ្លៃ (មិនត្រូវការ key)
   - **LongCat** — token 10M ឥតគិតថ្លៃ (ផ្តល់ជូនតែម្តង តម្រូវឱ្យមានគណនី + KYC)
   - **Cloudflare AI** — ម៉ូដែលជាង 50, neuron 10K/ថ្ងៃ
   - **MLX Gemma 26B** — ម៉ូដែល Apple Silicon មូលដ្ឋាន (~38.5 tok/s, RAM ~15.9GB)
   - **MLX Qwen 3.8 27B** — ម៉ូដែល Apple Silicon មូលដ្ឋាន (~9.1 tok/s, RAM ~13.1GB)
4. ចុច **ភ្ជាប់**
5. រួចរាល់! ឥឡូវនេះ អ្នកមានសិទ្ធិចូលប្រើ AI ដោយឥតគិតថ្លៃ។

### ជម្រើស B៖ អ្នកផ្តល់សេវាដោយប្រើ API Key (បង់ប្រាក់)

1. ទទួលយក API key ពីគេហទំព័ររបស់អ្នកផ្តល់សេវា៖
   - **OpenAI**: https://platform.openai.com/api-keys
   - **Anthropic**: https://console.anthropic.com/
   - **Google**: https://aistudio.google.com/apikey
   - **DeepSeek**: https://platform.deepseek.com/
   - **Groq**: https://console.groq.com/
2. បើកផ្ទាំងគ្រប់គ្រងនៅ `http://localhost:20128`
3. ចូលទៅកាន់ **អ្នកផ្តល់សេវា** → **បន្ថែមអ្នកផ្តល់សេវា**
4. ជ្រើសរើសអ្នកផ្តល់សេវារបស់អ្នក
5. បិទភ្ជាប់ API key របស់អ្នក
6. ចុច **ភ្ជាប់**
7. រួចរាល់! ឥឡូវនេះ អ្នកមានសិទ្ធិចូលប្រើម៉ូដែលរបស់អ្នកផ្តល់សេវានោះ។

### ជម្រើស C៖ អ្នកផ្តល់សេវា OAuth (ការជាវ)

1. បើកផ្ទាំងគ្រប់គ្រងនៅ `http://localhost:20128`
2. ចូលទៅកាន់ **អ្នកផ្តល់សេវា** → **បន្ថែមអ្នកផ្តល់សេវា**
3. ជ្រើសរើសអ្នកផ្តល់សេវារបស់អ្នក (ឧ. Claude Code, GitHub Copilot)
4. ចុច **ភ្ជាប់ជាមួយ OAuth**
5. ចូលដោយប្រើគណនីរបស់អ្នក
6. រួចរាល់! ឥឡូវនេះ អ្នកមានសិទ្ធិចូលប្រើម៉ូដែលក្នុងការជាវរបស់អ្នក។

### ជម្រើស D៖ ម៉ូដែល MLX មូលដ្ឋាន (Apple Silicon)

សម្រាប់កុំព្យូទ័រ Mac ដែលប្រើ Apple Silicon និងមានអង្គចងចាំរួម OmniRoute គាំទ្រការភ្ជាប់ទៅម៉ូដែល MLX មូលដ្ឋានដែលកំពុងដំណើរការតាមរយៈ `mlx-lm.server` ក្នុងនាមជាអ្នកផ្តល់សេវាមូលដ្ឋានដែលឆបគ្នាជាមួយ OpenAI ធម្មតា។

#### តម្រូវការជាមុន

- **Apple Silicon Mac** (M1/M2/M3/M4) ដែលមានអង្គចងចាំរួម 24GB+ ត្រូវបានណែនាំ
- កម្មវិធីគ្រប់គ្រងកញ្ចប់ **uv**៖ `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**៖ `uv pip install mlx-lm`

#### ចាប់ផ្តើមរហ័ស

1. **ដំឡើង dependency**៖

   ```bash
   # ដំឡើង uv ប្រសិនបើមិនទាន់បានដំឡើង
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # ដំឡើង mlx-lm
   uv pip install mlx-lm
   ```

2. **ចាប់ផ្តើម server MLX ដោយដៃ** (ក្នុង terminal ដាច់ដោយឡែក)៖

   ```bash
   # Terminal 1៖ Gemma 4 26B A4B IT-QAT (port 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # Terminal 2៖ Qwen 3.8 27B MLX Mixed (port 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **ភ្ជាប់ក្នុងផ្ទាំងគ្រប់គ្រង OmniRoute**៖
   - ចូលទៅកាន់ **អ្នកផ្តល់សេវា** → **បន្ថែមអ្នកផ្តល់សេវា**
   - ជ្រើសរើស **MLX Gemma 26B** ឬ **MLX Qwen 3.8 27B**
   - ចុច **ភ្ជាប់** (មិនត្រូវការ API key)

4. **ប្រើជាមួយ OpenCode**៖
   ```bash
   # កំណត់រចនាសម្ព័ន្ធ OpenCode ឱ្យប្រើ OmniRoute
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <your-omniroute-api-key>

   # ប្រើម៉ូដែល MLX
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

#### ការគ្រប់គ្រងអង្គចងចាំ

**សំខាន់**៖ ជាមួយអង្គចងចាំរួម 24GB អាចដំណើរការបានតែ **ម៉ូដែល MLX ធំមួយប៉ុណ្ណោះក្នុងពេលតែមួយ**។

- Gemma 26B៖ អង្គចងចាំអតិបរមា ~15.9GB
- Qwen 3.8 27B៖ អង្គចងចាំអតិបរមា ~13.1GB

អ្នកត្រូវតែគ្រប់គ្រងវាដោយដៃ៖

- ដំណើរការ server MLX តែមួយក្នុងពេលតែមួយ ឬ
- ដំណើរការទាំងពីរនៅលើម៉ាស៊ីនដាច់ដោយឡែក ឬ
- បញ្ឈប់មួយ មុនពេលចាប់ផ្តើមមួយទៀត

OmniRoute មិនគ្រប់គ្រងដំណើរការ server MLX ដោយស្វ័យប្រវត្តិទេ — វាគ្រាន់តែបញ្ជូនសំណើទៅកាន់ endpoint ដែលឆបគ្នាជាមួយ OpenAI ដែលអ្នកបានកំណត់រចនាសម្ព័ន្ធប៉ុណ្ណោះ។

#### ការគាំទ្រការហៅ Tool

ម៉ូដែលទាំងពីរគាំទ្រការហៅ tool ដែលឆបគ្នាជាមួយ OpenAI។ សាកល្បងដោយប្រើ៖

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mlx-gemma/gemma-4-26b",
    "messages": [{"role": "user", "content": "What is 2+2? Use the calculator tool."}],
    "tools": [{"type": "function", "function": {"name": "calculator", "description": "Calculate", "parameters": {"type": "object", "properties": {"expression": {"type": "string"}}, "required": ["expression"]}}}]
  }'
```

## របៀបភ្ជាប់អ្នកផ្តល់សេវា (ជាជំហានៗ)

### ជំហានទី 1៖ បើកផ្ទាំងគ្រប់គ្រង

ចូលទៅកាន់ `http://localhost:20128` ក្នុងកម្មវិធីរុករករបស់អ្នក។

### ជំហានទី 2៖ ចូលទៅកាន់អ្នកផ្តល់សេវា

ចុច **អ្នកផ្តល់សេវា** នៅក្នុងរបារចំហៀង។

### ជំហានទី 3៖ ចុចបន្ថែមអ្នកផ្តល់សេវា

ចុចប៊ូតុង **+ បន្ថែមអ្នកផ្តល់សេវា**។

### ជំហានទី 4៖ ជ្រើសរើសអ្នកផ្តល់សេវារបស់អ្នក

រុករកបញ្ជី ឬស្វែងរកអ្នកផ្តល់សេវារបស់អ្នក។ ចុចលើវា។

### ជំហានទី 5៖ បញ្ចូលព័ត៌មានសម្គាល់

- **អ្នកផ្តល់សេវាឥតគិតថ្លៃ**៖ មិនត្រូវការព័ត៌មានសម្គាល់ទេ — គ្រាន់តែចុច **ភ្ជាប់**
- **អ្នកផ្តល់សេវាដែលប្រើសោ API**៖ បិទភ្ជាប់សោ API របស់អ្នក
- **អ្នកផ្តល់សេវា OAuth**៖ ចុច **ភ្ជាប់ជាមួយ OAuth** ហើយចូលគណនី

### ជំហានទី 6៖ សាកល្បងការតភ្ជាប់

ចុច **សាកល្បងការតភ្ជាប់** ដើម្បីផ្ទៀងផ្ទាត់ថាវាដំណើរការ។

### ជំហានទី 7៖ រួចរាល់!

ឥឡូវនេះ អ្នកផ្តល់សេវារបស់អ្នកត្រូវបានភ្ជាប់ហើយ។ អ្នកអាចប្រើវាជាមួយ `model: "auto"` ឬបញ្ជាក់អ្នកផ្តល់សេវាដោយផ្ទាល់។
