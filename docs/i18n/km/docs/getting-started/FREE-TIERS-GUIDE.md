## តើ Free Tiers ជាអ្វី?

អ្នកផ្តល់សេវា AI ជាច្រើនផ្តល់ជូននូវទម្រង់មួយចំនួន** ការចូលប្រើដោយឥតគិតថ្លៃ** . អាស្រ័យលើអ្នកផ្តល់សេវា នោះអាចមានន័យថា ចំណុចបញ្ចប់គ្មានការផ្ទៀងផ្ទាត់ កូតាកើតឡើងដដែលៗ អត្រាការចូលប្រើដោយមិនមានកំណត់ ជំនួយការចុះឈ្មោះ ការយល់ព្រមដោយដៃ ឬការផ្សព្វផ្សាយបណ្តោះអាសន្ន។ ជម្រើសមួយចំនួនតម្រូវឱ្យមានគណនី សោ API កាតឥណទាន KYC ឬការទទួលយកលក្ខខណ្ឌជាក់លាក់របស់អ្នកផ្តល់សេវា។

OmniRoute** សរុប** បានកំណត់រចនាសម្ព័ន្ធការតភ្ជាប់ទៅក្នុងចំណុចបញ្ចប់មួយ។ អ្នកនៅតែចុះឈ្មោះដាច់ដោយឡែកសម្រាប់អ្នកផ្តល់សេវានីមួយៗដែលទាមទារគណនី។ ភ្ជាប់គណនីទាំងនោះ ហើយប្រើ `model: "auto"` ដើម្បីធ្វើដំណើរក្នុងចំណោមគោលដៅដែលមានសិទ្ធិ។ ការដំឡើងថ្មីអាចមិនមានគោលដៅគ្មានសោសិទ្ធិ។ ការដំឡើង OmniRoute តែម្នាក់ឯងមិនធានាការឆ្លើយតបការជជែកដោយជោគជ័យទេ។

## ការអានកាតាឡុកឱ្យបានត្រឹមត្រូវ

- `NOAUTH` មានន័យថា OmniRoute មិនសួរអ្នកសម្រាប់លិខិតសម្គាល់អ្នកផ្តល់សេវាមួយ; វាមិនធានានូវពេលវេលា ភាពឯកជន ឬសមត្ថភាពគ្មានដែនកំណត់។

- `one-time-initial` មិនកើតឡើងវិញទេបន្ទាប់ពីជំនួយការចុះឈ្មោះត្រូវបានប្រើប្រាស់។
- អ្នកផ្តល់សេវា`tos: avoid` ត្រូវបានដកចេញពីការបញ្ជូនដោយស្វ័យប្រវត្តិតាមលំនាំដើម (`excludeTosAvoid`) ។ ការភ្ជាប់គណនីមិនឆ្លងកាត់តម្រងនេះទេ។ ការបដិសេធប្រតិបត្តិករណាមួយគួរតែអនុវត្តតាមការពិនិត្យឡើងវិញនូវលក្ខខណ្ឌនៃអ្នកផ្តល់សេវា និងហានិភ័យគណនី។
- ធាតុដែលបានសម្គាល់ `discontinued` នៅតែជាភ័ស្តុតាងប្រវត្តិសាស្ត្រ ហើយមិនត្រូវបង្ហាញថាបច្ចុប្បន្នឥតគិតថ្លៃទេ។

## សំណួរទូទៅ

### "តើនេះពិតជាទំនេរមែនទេ?"

កាតាឡុកកត់ត្រាលក្ខខណ្ឌដែលបានបោះពុម្ពដោយអ្នកផ្តល់សេវា និងការស្រាវជ្រាវគម្រោង ប៉ុន្តែការផ្តល់ជូនអាចផ្លាស់ប្តូរបាន។ ផ្ទៀងផ្ទាត់តម្លៃបច្ចុប្បន្ន កូតា គោលការណ៍ឯកជនភាព និងសិទ្ធិទទួលបានរបស់អ្នកផ្តល់សេវាមុនពេលប្រើប្រាស់។

### "តើថ្នាក់ឥតគិតថ្លៃនឹងអស់ទេ?"

អ្នកផ្តល់សេវានីមួយៗអាចវាយតម្លៃកម្រិតកំណត់ ផ្លាស់ប្តូរម៉ូដែល ផ្អាកការចូលប្រើ ឬទៅក្រៅបណ្តាញ។ ការតភ្ជាប់ជាច្រើនធ្វើអោយប្រសើរឡើងនូវការគ្របដណ្តប់ត្រឡប់មកវិញ ប៉ុន្តែមិនធានានូវផ្លូវឥតគិតថ្លៃដែលមានទេ។

### "តើខ្ញុំអាចប្រើអ្នកផ្តល់សេវាឥតគិតថ្លៃសម្រាប់ផលិតកម្មបានទេ?"

លុះត្រាតែ SLA របស់អ្នកផ្តល់សេវា ការគ្រប់គ្រងទិន្នន័យ ដែនកំណត់ និងលក្ខខណ្ឌបំពេញតាមតម្រូវការផលិតកម្មរបស់អ្នក។ បន្ទុកការងារសំខាន់ៗគួរត្រូវបានត្រួតពិនិត្យ និងសមស្របតាមកិច្ចសន្យា។

### "ចាប់បានអី?"

ការដោះដូរអាចរួមបញ្ចូលដែនកំណត់តឹងរឹង បញ្ជីរង់ចាំ KYC ការផ្ទៀងផ្ទាត់កាតឥណទាន ការបណ្តុះបណ្តាលលើការជំរុញ ភាពឯកជនខ្សោយជាង គ្មាន SLA ការបង្រួបបង្រួមគំរូ ការរឹតត្បិតភូមិសាស្ត្រ ការបង់ប្រាក់លើស ឬហានិភ័យគោលនយោបាយគណនី។ OmniRoute បង្ហាញទិន្នន័យមេតាដែលមាន។ អ្នកជ្រើសរើសអ្វីដែលត្រូវបើក។

### "តើខ្ញុំទទួលបានកូតាឥតគិតថ្លៃបន្ថែមទៀតដោយរបៀបណា?"

1. ភ្ជាប់អ្នកផ្តល់សេវាឥតគិតថ្លៃបន្ថែមទៀត
2. បើកដំណើរការម៉ាស៊ីនបង្ហាប់ដែលសមស្រប និងវាស់វែងការសន្សំសម្រាប់បន្ទុកការងាររបស់អ្នក។
3. ប្រើ `auto/cheap` ដើម្បីផ្តល់អាទិភាពដល់អ្នកផ្តល់ free/cheap
4. បន្ថែមអ្នកផ្តល់ការអនុញ្ញាត ឬព័ត៌មានបញ្ជាក់អត្តសញ្ញាណបន្ថែមដោយមិនបំពានលក្ខខណ្ឌអ្នកផ្តល់សេវា

### "តើអ្នកផ្តល់សេវាឥតគិតថ្លៃមានគុណភាពកាន់តែអាក្រក់ទេ?"

មិនចាំបាច់ទេ។ អ្នកផ្តល់សេវាមួយចំនួនបង្ហាញក្រុមគ្រួសារគំរូដូចគ្នាដែលមានតាមរយៈផ្លូវបង់ប្រាក់ ប៉ុន្តែដែនកំណត់ ភាពយឺតយ៉ាវ ភាពឯកជន ភាពជឿជាក់ និងកំណែគំរូអាចខុសគ្នា។ ប្រើទំព័រចំណាត់ថ្នាក់អ្នកផ្តល់សេវាឥតគិតថ្លៃជាសញ្ញាគុណភាព និងផ្ទៀងផ្ទាត់គំរូពិតប្រាកដដែលបានបម្រើ។
