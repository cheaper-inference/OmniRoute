ដំឡើងផ្ទាំងគ្រប់គ្រង OmniRoute ជា Progressive Web App ដើម្បីបើកវាពីអេក្រង់ដើម ឬកុំព្យូទ័រលើតុរបស់អ្នកនៅក្នុងបង្អួចដាច់ដោយឡែក។ កម្មវិធីដែលបានដំឡើងនៅតែត្រូវការការតភ្ជាប់ទៅម៉ាស៊ីនមេ OmniRoute របស់អ្នកសម្រាប់ការរុករក ទិន្នន័យផ្ទាំងគ្រប់គ្រង និងសំណើ API ។ ទ្រព្យសកម្មឋិតិវន្តដែលបានរក្សាទុកមិនផ្តល់ច្រកចេញក្រៅបណ្តាញ ឬផ្ទាំងគ្រប់គ្រងក្រៅបណ្តាញទេ។

## តើ PWA ជាអ្វី?

កម្មវិធីគេហទំព័រ Progressive ប្រើផ្ទាំងគ្រប់គ្រងគេហទំព័រដែលមានរូបតំណាងកម្មវិធី និងបង្អួចដាច់ដោយឡែក។ នៅពេលដំឡើងរួច OmniRoute:

- បើកដំណើរការពីអេក្រង់ដើម ឬកុំព្យូទ័រលើតុរបស់អ្នក។
- បើកក្នុងទម្រង់ឯកឯង ដោយគ្មានរបារអាសយដ្ឋាន និងផ្ទាំងធម្មតារបស់កម្មវិធីរុករកតាមអ៊ីនធឺណិត
- ឃ្លាំងសម្ងាត់ដែលបានជ្រើសរើសទ្រព្យសម្បត្តិឋិតិវន្ត
- គាំទ្រការតំរង់ទិសបញ្ឈរ និងទេសភាព

## ការដំឡើង

ប្រើអាសយដ្ឋាន HTTPS សម្រាប់ម៉ាស៊ីនមេនៅលើឧបករណ៍ផ្សេងទៀត។ នៅពេលដែលម៉ាស៊ីនមេដំណើរការលើឧបករណ៍តែមួយ `http://localhost:20128` ក៏បំពេញតាមតម្រូវការនៃការដំឡើងកម្មវិធីរុករកផងដែរ។ អាសយដ្ឋាន `http://YOUR_IP:20128` ធម្មតាមិនបំពេញតាមតម្រូវការទាំងនោះទេ។ ម៉ឺនុយដំឡើង និងប្រអប់បញ្ចូលអាស្រ័យលើកម្មវិធីរុករក និងប្រព័ន្ធប្រតិបត្តិការ។ មើល [តម្រូវការដំឡើង PWA របស់MDN](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable#https_localhost_or_loopback_are_required) ។

### ប្រព័ន្ធប្រតិបត្តិការ Android (Chrome)

1. បើកអាសយដ្ឋាន OmniRoute HTTPS របស់អ្នក ឬ `http://localhost:20128` សម្រាប់ម៉ាស៊ីនមេនៅលើទូរសព្ទតែមួយ។
2. បើក**⋮** ម៉ឺនុយហើយជ្រើសរើស** ដំឡើងកម្មវិធី** ឬ** បន្ថែមទៅអេក្រង់ដើម** ប្រសិនបើផ្តល់ជូន។
3. បញ្ជាក់ការជម្រុញ។
4. បើក OmniRoute ពីអេក្រង់ដើម។

### iOS (សាហ្វារី)

1. បើកអាសយដ្ឋាន OmniRoute HTTPS របស់អ្នកនៅក្នុង Safari ។
2. ប៉ះ** ចែករំលែក** →** បន្ថែមទៅអេក្រង់ដើម** .
3. បញ្ជាក់ឈ្មោះ ហើយចុច** បន្ថែម** .
4. បើក OmniRoute ពីអេក្រង់ដើម។

### ផ្ទៃតុ (Chrome / Edge)

1. បើកផ្ទាំងគ្រប់គ្រង OmniRoute របស់អ្នក។
2. ប្រើរូបតំណាងដំឡើងរបស់កម្មវិធីរុករកឬ** ដំឡើងកម្មវិធី** ធាតុម៉ឺនុយប្រសិនបើត្រូវបានផ្តល់ជូន។
3. បញ្ជាក់ការជម្រុញឱ្យបើក OmniRoute នៅក្នុងបង្អួចផ្ទាល់ខ្លួនរបស់វា។

### បុគ្គលិកសេវាកម្ម

[`public/sw.js`](../../public/sw.js) មិនមានការពឹងផ្អែកលើក្របខណ្ឌអ្នកបម្រើសេវា៖

- **ដំឡើង៖** ដាក់ឃ្លាំងសម្ងាត់ជាមុននូវធនធានទាំងបួនដែលបានរាយបញ្ជីខាងលើ និងធ្វើឱ្យបុគ្គលិកថ្មីសកម្ម។
- **ធ្វើឱ្យសកម្ម៖** លុបជំនាន់ឃ្លាំងសម្ងាត់ចាស់ ហើយទាមទារអតិថិជន។
- **ទៅយក៖** អនុវត្តយុទ្ធសាស្រ្តឋិតិវន្ត-ទ្រព្យសកម្ម និងការបដិសេធផ្លូវខាងលើ។
- **កំណែទម្រង់៖** ឈ្មោះឃ្លាំងសម្ងាត់ប្រភពគឺ `omniroute-pwa-v3`; ការបង្កើតផលិតកម្មបោះត្រាអត្តសញ្ញាណឃ្លាំងសម្ងាត់។
- **ការជូនដំណឹង៖** គ្រប់គ្រងព្រឹត្តិការណ៍ `push` ចូលមក ហើយផ្ដោត ឬបើកបង្អួច នៅពេលការជូនដំណឹងត្រូវបានចុច។
