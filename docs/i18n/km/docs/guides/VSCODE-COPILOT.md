## រៀបចំ

1. **រត់ OmniRoute** — `npm install -g omniroute && omniroute` (ផ្ទាំងគ្រប់គ្រងនៅលើ `http://localhost:20128`) ។
2. **ដំឡើងផ្នែកបន្ថែម** — ស្វែងរក "OmniRoute" នៅក្នុងទិដ្ឋភាពផ្នែកបន្ថែម។
3. **ភ្ជាប់** — រក្សា `http://localhost:20128` លំនាំដើម ឬកំណត់ម៉ាស៊ីនមេ URL និង API របស់អ្នកតាមរយៈ**OmniRoute: គ្រប់គ្រងការភ្ជាប់** .
4. **ជ្រើសរើសម៉ូដែល** — Copilot កម្មវិធីជ្រើសរើសម៉ូដែល → ជជែក →** គ្រប់គ្រងម៉ូដែល...** →**OmniRoute** បន្ទាប់មកគូសអ្វីដែលអ្នកចង់បាន។

សម្រាប់ការកំណត់ការតភ្ជាប់សូមបើក** រូបតំណាង OmniRoute នៅក្នុងរបារសកម្មភាព** (ឬដំណើរការ `OmniRoute: Manage Connection`) ហើយកំណត់៖

- **ម៉ាស៊ីនមេ URL** — root ម៉ាស៊ីនមេ ឧទាហរណ៍ `http://omniroute.example.com:20128`។ បច្ច័យ `/v1` ត្រូវបានបន្ថែមដោយផ្នែកបន្ថែម។ កុំរួមបញ្ចូលវា។
- **គ្រាប់ចុច API** — ទាមទារនៅពេលដែលគោលការណ៍ផ្ទៀងផ្ទាត់ការសន្និដ្ឋានរបស់ម៉ាស៊ីនមេទាមទារមួយ។ រក្សាទុកតាមរយៈ VS កូដ SecretStorage មិនដែលនៅក្នុង `settings.json`; មានគ្រាប់ចុចជាក់លាក់នៃកន្លែងធ្វើការ។ ប្រើសោដែលបានអនុញ្ញាតសម្រាប់ម៉ូដែលដែលអ្នកចង់បង្ហាញ។

ផ្នែកបន្ថែមនេះក៏ផ្តល់នូវការចង្អុលបង្ហាញអំពីការតភ្ជាប់ ការធ្វើឱ្យទាន់សម័យគំរូ បរិបទគំរូ និងទិន្នន័យមេតាតម្លៃ (រួមបញ្ចូល) ការស្ទ្រីមហេតុផលជាមួយនឹង** ការព្យាយាមគិត** ម៉ឺនុយនៅលើ VS លេខកូដ 1.120 + ដែលជារបារស្ថានភាព សូចនាករដែនកំណត់ប្រចាំថ្ងៃ និងបន្ទះប្រើប្រាស់ (OmniRoute 3.8.50 +) ការកំណត់រចនាសម្ព័ន្ធ CLI និងផ្ទាំងគ្រប់គ្រងជាជម្រើស។ គំរូដែលបានជ្រើសរើស និងគោលការណ៍ម៉ាស៊ីនមេកំណត់សមត្ថភាពដែលអ្នកអាចប្រើ។

## អ្វីដែលកម្មវិធីជ្រើសរើសនឹងបង្ហាញ

ផ្នែកបន្ថែមមិនបង្ហាញ payload ដើមរបស់ `GET /v1/models` ទេ — វារៀបចំទ្រង់ទ្រាយ payload នោះ ហើយចំនួនដែលអ្នក
ឃើញនឹងតិចជាងទំហំ catalog ដោយសារហេតុផលចេតនាពីរ។

### វាស្នើសុំ id មួយសម្រាប់ម៉ូដែលនីមួយៗ

`MODELS_CATALOG_PREFIX_MODE` មានលំនាំដើមជា **`dual`** ដែលផ្សព្វផ្សាយម៉ូដែលនីមួយៗពីរដង — ម្តង
ក្រោម alias prefix ខ្លី និងម្តងក្រោម canonical provider prefix — ដូច្នេះការកំណត់របស់ client ចាស់ៗ
នៅតែអាចដោះស្រាយទម្រង់ទាំងពីរបាន៖

```
cc/claude-sonnet-4-6        ← alias prefix
claude/claude-sonnet-4-6    ← canonical prefix, ម៉ូដែលដូចគ្នា
```

ផ្នែកបន្ថែមស្នើសុំ **`GET /v1/models?prefix=alias`** ដើម្បីឱ្យទទួលបាន id មួយសម្រាប់ម៉ូដែលនីមួយៗ ដោយមិន
ផ្លាស់ប្តូរការកំណត់ទូទាំងម៉ាស៊ីនមេសម្រាប់ client ផ្សេងទៀតរបស់អ្នក។ លើ instance យោងមួយ វាបានកាត់បន្ថយ
**ពី 2345 ធាតុមកត្រឹម 1396 — 949 ជាធាតុស្ទួន ដោយមិនបាត់ម៉ូដែលណាមួយឡើយ។**
