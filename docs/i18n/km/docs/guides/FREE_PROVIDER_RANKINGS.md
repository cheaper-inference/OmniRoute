### API endpoint

ទំព័រនេះដំណើរការដោយមាន endpoint អានជាសាធារណៈនៅពីក្រោយ
(`src/app/api/free-provider-rankings/route.ts`)៖

```
GET /api/free-provider-rankings
GET /api/free-provider-rankings?category=coding
GET /api/free-provider-rankings?category=coding&limit=20
```

ប៉ារ៉ាម៉ែត្រសំណួរ (បានផ្ទៀងផ្ទាត់ដោយ Zod)៖

| ប៉ារ៉ាម៉ែត្រ | ប្រភេទ | លំនាំដើម | កំណត់សម្គាល់                                                                                                       |
| ------------ | ------ | -------- | ------------------------------------------------------------------------------------------------------------------ |
| `category`   | string | (គ្មាន)  | មួយក្នុងចំណោម `default`, `coding`, `review`, `documentation`, `debugging`។ កុំបញ្ចូល ដើម្បីទទួលបានចំណាត់ថ្នាក់រួម។ |
| `limit`      | number | `50`     | ត្រូវបានកម្រិតឱ្យស្ថិតក្នុងចន្លោះ `1–100`។                                                                         |

ទម្រង់ response៖

```json
{
  "rankings": [
    {
      "id": "<provider-id>",
      "name": "<provider name>",
      "icon": "<icon>",
      "color": "<hex color>",
      "textIcon": "<short label>",
      "category": "noauth | oauth | apikey",
      "topModel": {
        "modelId": "<registry model id>",
        "modelName": "<model display name>",
        "score": 0.0,
        "eloRaw": 0,
        "confidence": "high | medium | low",
        "category": "<task category>"
      },
      "averageScore": 0.0,
      "modelCount": 0
    }
  ]
}
```

`eloRaw` គឺជាតម្លៃ Arena ELO ដើម ខណៈដែល `score` គឺជាតម្លៃភាពសមស្របនឹងកិច្ចការដែលបានធ្វើឱ្យមានស្តង់ដារ
(សូមមើលខាងក្រោម)។ អ្នកផ្តល់សេវាដែលគ្មានម៉ូដែលមានពិន្ទុ ត្រូវបានដកចេញពី response។

### ការធ្វើសមមាត្រ (ពិន្ទុ task-fit)

ពិន្ទុ ELO ឆៅត្រូវបានធ្វើសមមាត្រតាម leaderboard នីមួយៗទៅជា **តម្លៃ task-fit ក្នុង `[0.4, 0.98]`**៖

```
taskFit = 0.4 + 0.58 * ((elo - minElo) / (maxElo - minElo))
```

ពិន្ទុមិនដែលឈានដល់ `0` ឬ `1` ដើម្បីទុកចន្លោះសម្រាប់ការជំនួសរបស់អ្នកប្រើប្រាស់។ នេះគឺជាវាល
`score` ដែលអ្នកឃើញក្នុងការឆ្លើយតប API និងស្លាកដែលបង្ហាញនៅលើ dashboard។

### របៀបដែលអ្នកផ្តល់សេវាត្រូវបានចំណាត់ថ្នាក់

សម្រាប់អ្នកផ្តល់សេវាឥតគិតថ្លៃនីមួយៗ ម៉ាស៊ីនឱ្យពិន្ទុម៉ូដែលទាំងអស់ក្នុងកាតាឡុករបស់វា បន្ទាប់មក៖

- **ម៉ូដែលកំពូល** = ម៉ូដែលដែលមានពិន្ទុខ្ពស់បំផុតរបស់អ្នកផ្តល់សេវា។
- **ពិន្ទុមធ្យម** = ពិន្ទុមធ្យមនៃម៉ូដែលដែលបានឱ្យពិន្ទុទាំងអស់របស់អ្នកផ្តល់សេវានោះ។
- **ម៉ូដែល** = ចំនួនម៉ូដែលរបស់អ្នកផ្តល់សេវាដែលមានពិន្ទុ Arena។

អ្នកផ្តល់សេវាត្រូវបានតម្រៀបតាម **ពិន្ទុម៉ូដែលកំពូល** ជាមុនសិន បន្ទាប់មកតាមពិន្ទុមធ្យម។ នេះផ្តល់រង្វាន់
ដល់អ្នកផ្តល់សេវាដែលចេញផ្សាយម៉ូដែលឥតគិតថ្លៃខ្លាំងយ៉ាងហោចណាស់មួយ។

## ការប្រើប្រាស់វាដើម្បីជ្រើសរើសអ្នកផ្តល់សេវាឥតគិតថ្លៃ
