> ដែលត្រូវបាន vendored ជា workspace `packages/ui-kit` (`@omniroute/ui-kit`; snapshot នៃ upstream ត្រូវបាន pin
> នៅក្នុង `packages/ui-kit/UPSTREAM.md` ហើយត្រូវបានការពារដោយ `npm run check:ui-kit-snapshot`)។ Light គឺជា
> theme ផ្លូវការ; ចំណូលចិត្តលំនាំដើមគឺ `system`។ ពណ៌ accent គឺ Keak lime (`--ci-color-accent`) ។ Switzer គឺជាគ្រួសារពុម្ពអក្សរចម្បងសម្រាប់ UI និងអត្ថបទបង្ហាញ (`--ci-font-ui`; `--ci-font-display` និង `--ci-font-mono` ដោះស្រាយវា) រៀបចំដោយខ្លួនឯងដោយឧបករណ៍ខ្លួនវា (`packages/ui-kit/src/ci-fonts.css` នាំចូលដោយ `ci-tokens.css`) ។ រូបតំណាងនីមួយៗគឺ Lucide glyph ។
>
> Inter ជាពុម្ពអក្សរបម្រុងសម្រាប់ glyph ដែលខ្វះក្នុង Switzer; `--font-mono` ចង្អុលទៅបញ្ជីពុម្ពអក្សរទទឹងស្មើរបស់ប្រព័ន្ធ `--ci-font-code`។

  --font-mono: var(--ci-font-code);
}

## 1. កន្លែងដែលអ្វីៗស្ថិតនៅ

- **Kit.** `packages/ui-kit/src` គឺជាច្បាប់ចម្លងដ៏ដូចគ្នាគ្រប់ byte នៃ `src/` របស់ upstream នៅ commit ដែលបានកំណត់ទុកក្នុង
  `packages/ui-kit/UPSTREAM.md` (ដែលក៏កត់ត្រាការអនុញ្ញាតអាជ្ញាប័ណ្ណផងដែរ); `PATCHES.md` រាយបញ្ជី patch ក្នុងស្រុក
  (គ្មាន)។ វាត្រូវបានប្រើប្រាស់ជា source ដោយគ្មាន build៖ `next.config.mjs` ធ្វើ transpile វា ហើយ
  `tsconfig.json` map `@omniroute/ui-kit` → `packages/ui-kit/src` និង `@omniroute/ui-kit/*` →
  `packages/ui-kit/src/*` (`vitest.config.ts` និង `vitest.mcp.config.ts` មាន alias ដូចគ្នា)។ សូម import component
  របស់ kit តាម subpath របស់វា (`@omniroute/ui-kit/table`, `@omniroute/ui-kit/page-header`…) កុំ import តាម
  barrel `@omniroute/ui-kit` ដាច់ខាត៖ barrel នឹងទាញ component ទាំងអស់ (រួមទាំង date picker) ចូលទៅក្នុង
  importer នីមួយៗ។ Stylesheet របស់ kit ចូលតាមរយៈ `src/app/globals.css`
  (`@import "../../packages/ui-kit/src/ci-ui.css"`)។
- **Token.** `packages/ui-kit/src/ci-tokens.css` ប្រកាស token `--ci-*`; `src/app/globals.css`
  ភ្ជាប់ពួកវាទៅឈ្មោះ legacy របស់ OmniRoute (`--color-*`, `--radius-*`, `--font-sans`/`--font-mono`,
  `--table-*`, `--orch-status-*`, `--color-fd-*`) ដើម្បីឱ្យការអាន `var(--color-*)` ដែលមានស្រាប់ និង Tailwind
  utility នៅតែបន្តដំណើរការ។ កូដថ្មីប្រើ Tailwind utility (`bg-surface`, `text-text-muted`,
  `border-border`, `text-success`, `bg-success-bg`, `bg-chart-1`…) ឬ class របស់ kit — កុំប្រើតម្លៃ hex ដាច់ខាត
  (`tests/unit/design-kit-bridge.test.ts` បង្ខំឱ្យគោរព bridge នេះ)។ `text-primary` បំលែងទៅជា
  `--color-primary-ink` តាមរយៈ `--text-color-primary` (lime-800 ក្នុងរបៀបភ្លឺ ហើយ lime accent ក្នុងរបៀបងងឹត)
  ដូច្នេះអត្ថបទ primary នៅតែអានបានងាយ ខណៈដែល `bg-primary`/`border-primary` រក្សាផ្ទៃ lime នោះ។ Chart series
  ប្រើ `--color-chart-1` … `--color-chart-5`។

  របៀបងងឹតរបស់ kit ផ្អែកលើ `data-theme="dark"` (`packages/ui-kit/src/ci-tokens.css`); dark override
  ផ្ទាល់ខ្លួនរបស់ OmniRoute (ប្លុក `.dark` ក្នុង `globals.css`) និង legacy Tailwind `dark:` utility វិញ

  build ចាស់ ត្រូវបានបោះបង់ចោលនៅពេល store ផ្ទុកឡើង។

## 2. ច្បាប់

## 3. ការបន្ថែម screen

1. បើកទំព័រជាមួយ kit `PageHeader` (`@omniroute/ui-kit/page-header`, ប្រើ `compact` នៅក្នុង dashboard) — ចំណងជើង ការពិពណ៌នា និង `actions`។ បន្ទាប់មក shell header នឹងដកចំណងជើងរបស់ខ្លួនចេញ។
2. សាងសង់ controls ពី `@/shared/components` (adapters) ហើយប្រើ kit components តាម subpath នៅកន្លែងដែលមិនមាន adapter (`Table`/`TableScrollArea`/`DataTableShell`, `Field`, `Alert`, `Tabs`, `RadioGroup`, `Slider`…)។
3. Icons: `<Icon name="…" />`។ ឈ្មោះថ្មីត្រូវបន្ថែមទៅក្នុង `ICON_MAP` ជាមួយ Lucide component ដែលត្រូវគ្នាតាមអត្ថន័យ; `npm run gen:icon-map` រាយឈ្មោះដែលនៅខ្វះ។
4. ពណ៌៖ semantic utilities (`text-success`, `bg-warning-bg`, `border-border`…) និង `var(--color-chart-N)` សម្រាប់ chart series; មិនអនុញ្ញាតតម្លៃ hex និង `dark:` variants ដែលគ្រាន់តែធ្វើពណ៌ដដែលម្តងទៀត។
5. អត្ថបទ៖ រាល់ string រួមទាំង labels ដែលអ្នកបញ្ជូនទៅ kit components ត្រូវមកពី `useTranslations`។ keys ថ្មីត្រូវបន្ថែមទៅក្នុង `src/i18n/messages/en.json`, `pt-BR.json` និង `vi.json` (Vietnamese parity test កំណត់រាល់ English key ទាំងអស់); locales ផ្សេងទៀតនឹងត្រូវបានបំពេញដោយ i18n sync។
6. ដំណើរការ guards មុនពេលបង្កើត PR៖ `tests/unit/dashboard-kit-sweep.test.ts`, `tests/unit/icon-map-coverage.test.ts`, `tests/unit/icon-map-object-values.test.ts`, `npm run check:dashboard-typecheck` (ការពិនិត្យតែមួយគត់ដែលចាប់បាន duplicated import នៅក្នុង `iconMap.ts`), `npm run check:ui-icu` និង tests ផ្ទាល់ខ្លួនរបស់ screen នោះ។

   style) មិនដែលនៅក្នុង `packages/ui-kit/src` ឡើយ។

## 5. ការធ្វើបច្ចុប្បន្នភាព kit

usage និង endpoint ក្នុង theme ទាំងពីរ ដំណើរការ `npm run check:ui-kit-snapshot` និង `npm run test:vitest:ui` ហើយ
