OmniRoute/
├── src/                  # កម្មវិធី Next.js 16 (UI + ផ្លូវ API + បណ្ណាល័យ + ដូមែន + ម៉ាស៊ីនបម្រើ)

├── packages/            # កន្លែងធ្វើការ npm៖ ui-kit (Keak CI UI Kit ដែលបានដាក់បញ្ចូលក្នុងគម្រោង) និង browser-pool
├── electron/             # ស្រទាប់កម្មវិធីផ្ទៃតុ (Electron 41 + electron-builder 26.10)
├── bin/                  # ចំណុចចូល CLI និងកម្មវិធីដោះស្រាយពាក្យបញ្ជា
├── scripts/              # ស្គ្រីបសម្រាប់បង្កើត ពិនិត្យ ធ្វើសមកាលកម្ម និងកិច្ចការប្រើតែមួយលើក
├── docs/                 # ឯកសារណែនាំសាធារណៈ (អ្នកកំពុងនៅទីនេះ)
├── tests/                # សំណុំតេស្តទាំងអស់ (ឯកតា សមាហរណកម្ម e2e និងម៉ាស៊ីនភ្ញៀវពិធីការ)
├── public/               # ធនធានឋិតិវន្តរបស់ Next.js, manifest របស់ PWA, service worker និងរូបតំណាង
├── config/               # ការកំណត់រចនាសម្ព័ន្ធឋិតិវន្ត + ស្ថានភាពច្រកត្រួតពិនិត្យគុណភាព (i18n, payloadRules, quality/)
├── images/               # ធនធានរូបភាពសម្រាប់ទីផ្សារ / README
├── @omniroute/           # កញ្ចប់បន្ថែមដែលអាចបោះពុម្ពផ្សាយបាន (opencode-plugin, opencode-provider)
├── skills/               # កញ្ចប់ជំនាញ CLI/ភ្នាក់ងារ (cli-* + omni-* + config-codex-cli)
├── examples/             # កម្មវិធីជំនួយគំរូ + គម្រោងចាប់ផ្ដើម omniroute-cmd-hello
├── contrib/              # ការរួមចំណែកពីសហគមន៍ (podman/)
├── .source/              # ការកំណត់រចនាសម្ព័ន្ធប្រភព Fumadocs (source.config.mjs + server/browser/dynamic)
├── .github/              # លំហូរការងារ GitHub Actions + គំរូបញ្ហា + គំរូ PR
├── .husky/               # Git hooks (pre-commit, pre-push)
├── .claude/              # ពាក្យបញ្ជាសញ្ញា slash របស់ Claude Code (មានវិសាលភាពត្រឹមគម្រោង)
├── .agents/              # លំហូរការងារ + ជំនាញរបស់ Codex / ភ្នាក់ងារទូទៅ (ច្បាប់ចម្លងនៃ .claude/)
├── .vscode/              # ការកំណត់កន្លែងធ្វើការរបស់ VS Code
├── _ideia/               # កំណត់ត្រាផែនការ (ក្រៅផ្លូវការ; មិនត្រូវបានចែកចាយ)
├── _mono_repo/           # គម្រោងរងប្រវត្តិសាស្ត្រ (cloud, site, vscode-extension)
├── _references/          # ច្បាប់ចម្លងយោងបានតែអានពីគម្រោង OSS ដែលពាក់ព័ន្ធ
├── _tasks/               # ឯកសារតាមដានកិច្ចការសម្រាប់ការចេញផ្សាយនីមួយៗ (ក្រៅផ្លូវការ)
├── .build/ .worktrees/ dist/   # ទីតាំងបណ្ដោះអាសន្នក្នុងម៉ាស៊ីនសម្រាប់ build / git-worktree / លទ្ធផល build (gitignored)
├── .issues/              # ឃ្លាំងសម្ងាត់បញ្ហាក្នុងម៉ាស៊ីន (gitignored)
├── .playwright-mcp/      # ធនធានដែលបង្កើតពីតេស្ត Playwright MCP
├── coverage/             # លទ្ធផល coverage របស់ c8 (gitignored)
├── logs/                 # កំណត់ហេតុពេលដំណើរការ (gitignored)
├── node_modules/         # ធាតុអាស្រ័យ (gitignored)
├── package/              # តំបន់បណ្ដោះអាសន្នសម្រាប់ npm pack (ធនធារដែលបានពីការ build)
├── .next/                # លទ្ធផល build របស់ Next.js (gitignored)
└── (ឯកសារនៅថតឫស — សូមមើលខាងក្រោម)

## `_ideia/`, `_mono_repo/`, `_references/`, `_tasks/` — នៅក្រៅ source tree

ថតដែលផ្តើមដោយសញ្ញា underscore ទាំងនេះផ្ទុកមាតិកាដែលមិនត្រូវបានចែកចាយ៖

- **`_ideia/`** — កំណត់ចំណាំការរចនា (ប្រភេទ defer / notfit / viable)
- **`_mono_repo/`** — project រងចាស់ៗ (omnirouteCloud, omnirouteSite, vscode-extension)
- **`_references/`** — clone សម្រាប់តែអាននៃ project OSS ដែលពាក់ព័ន្ធ (LiteLLM, 9router, ClawRouter, CLIProxyAPI, modelrelay, new-api ជាដើម) សម្រាប់យោងផ្ទៀងផ្ទាត់ក្នុងអំឡុងពេលអភិវឌ្ឍ
- **`_tasks/`** — ឯកសារតាមដាន task សម្រាប់ release នីមួយៗ (ក្រៅផ្លូវការ)

មិនត្រូវបានរួមបញ្ចូលក្នុងលទ្ធផល `npm pack` ទេ។ សូមមើល `.npmignore`។

## គន្លឹះសម្រាប់ការរុករក

- **អ្នករួមចំណែកថ្មីមែនទេ?** សូមអាន `CONTRIBUTING.md` → `CLAUDE.md` → `docs/architecture/ARCHITECTURE.md` → `docs/architecture/CODEBASE_DOCUMENTATION.md`។
- **កំពុងបន្ថែម provider មែនទេ?** អនុវត្តតាម `docs/architecture/ARCHITECTURE.md § Adding a New Provider` + ផ្ទៀងផ្ទាត់ជាមួយ `docs/reference/PROVIDER_REFERENCE.md`។
- **កំពុងបន្ថែម route មែនទេ?** `docs/architecture/ARCHITECTURE.md § Adding a New API Route` + `src/shared/validation/schemas.ts`។
- **កំពុងបន្ថែមឧបករណ៍ MCP មែនទេ?** `docs/frameworks/MCP-SERVER.md § Adding a Tool`។
- **កំពុងបន្ថែមជំនាញ A2A មែនទេ?** `docs/frameworks/A2A-SERVER.md § Adding a New Skill`។
- **កំពុងដំណើរការក្នុងមូលដ្ឋានមែនទេ?** `docs/guides/SETUP_GUIDE.md`។
- **កំពុងដាក់ឱ្យប្រើប្រាស់មែនទេ?** `docs/guides/DOCKER_GUIDE.md` / `docs/ops/VM_DEPLOYMENT_GUIDE.md` / `docs/ops/FLY_IO_DEPLOYMENT_GUIDE.md`។
- **កំពុងចេញផ្សាយមែនទេ?** `docs/ops/RELEASE_CHECKLIST.md` (និងជំនាញ Claude Code `/generate-release-cc`)។
