`copilot-m365-web` (alias `m365copilot`) ផ្ញើសំណើជជែកតាមទម្រង់ OpenAI តាមរយៈវគ្គ Microsoft 365 Copilot ដែលបានផ្ទៀងផ្ទាត់នៅ `m365.cloud.microsoft/chat`។ នេះគឺជាការរួមបញ្ចូលដើមមិនផ្លូវការ៖ គ្មានដំណើរការប្រូកស៊ីដាច់ដោយឡែក ឬម៉ាស៊ីនមូលដ្ឋានត្រូវបានទាមទារ។ អ្នកផ្តល់សេវា ID ឈ្មោះក្លែងក្លាយ និងការតភ្ជាប់ដែលបាននាំចូលដែលមានស្រាប់គឺមិនផ្លាស់ប្តូរទេ។ `copilot-web` គឺជាអ្នកផ្តល់សេវាផ្សេងសម្រាប់អតិថិជននៅ `copilot.microsoft.com`។

> **ថ្មីចំពោះអ្នកផ្តល់ខូឃីគេហទំព័រ?**
>
> អាន**`docs/getting-started/WEB-COOKIE-GUIDE.md`** សម្រាប់ដំណើរការរៀបចំទូទៅ ការណែនាំអំពីការផ្ទៀងផ្ទាត់ ការកំណត់ និងការដោះស្រាយបញ្ហា មុនពេលធ្វើតាមការណែនាំជាក់លាក់របស់អ្នកផ្តល់សេវានេះ។
>
> **សម្រាប់ការនាំចូលកេរ្តិ៍ដំណែល៖** លិខិតសម្គាល់សម្រាប់អ្នកផ្តល់សេវានេះគឺ** មិនមែនជាខូគីទេ។** . កុំចម្លងខូគីពី `m365.cloud.microsoft`។ លិខិតសម្គាល់គឺជាប៉ារ៉ាម៉ែត្រសំណួរ WebSocket URL និងផ្នែកផ្លូវ ទាំងពីរបានអានពីផ្ទាំងបណ្តាញ DevTools ។

## តម្រូវការជាមុន

- គណនី Microsoft 365 ដែលមានសិទ្ធិចូលប្រើ Copilot នៅ `m365.cloud.microsoft/chat`
- កម្មវិធីរុករកតាមអ៊ីនធឺណិតដែលមានមូលដ្ឋានលើ Chromium (Chrome, Edge) សម្រាប់ការត្រួតពិនិត្យ DevTools WebSocket
- ចូលប្រើគំរូដែលបានស្នើសុំនៅលើគណនីនោះ; ភាពអាចរកបានប្រែប្រួលតាមអ្នកជួល និងអាជ្ញាប័ណ្ណ

## ការចូលដើម (គណនីការងារ ឬសាលា)

ជ្រើសរើស**Microsoft 365 Copilot → ភ្ជាប់** និងរៀបចំការប៉ុនប៉ងចូល។ ផ្ទាំងគ្រប់គ្រងប្រើប្រាស់លំហូរកូដអនុញ្ញាតជាមួយ PKCE; វាមិនសួររកពាក្យសម្ងាត់ Microsoft ឬលេខកូដ MFA របស់អ្នកទេ។

1. បើក ក** ផ្ទាំងកម្មវិធីរុករកទទេ** បន្ទាប់មកបើក**DevTools → បណ្តាញ** និងបើក** រក្សាទុកកំណត់ហេតុ** . ធ្វើដូចនេះមុនពេលរុករកទៅ Microsoft: Windows SSO អាចបញ្ចប់ភ្លាមៗ។
2. ចម្លងការអនុញ្ញាត URL ដែលបង្ហាញដោយប្រអប់តភ្ជាប់ ហើយរុករកវានៅក្នុងផ្ទាំងដែលបានរៀបចំនោះ។ បំពេញការជ្រើសរើសគណនីរបស់ Microsoft ឬ MFA ប្រសិនបើត្រូវបានស្នើសុំ។
3. នៅក្នុងកំណត់ហេតុបណ្តាញដែលបានរក្សាទុក ស្វែងរកសំណើទៅ `https://login.microsoftonline.com/common/oauth2/nativeclient` ហើយចម្លងវាពេញ** ស្នើសុំ URL** .
4. បិទភ្ជាប់ URL នោះទៅក្នុងប្រអប់តភ្ជាប់ ហើយភ្ជាប់។ កុំបិទភ្ជាប់កូដឆៅ ឬរបារអាសយដ្ឋាន `wrongplace` ចុងក្រោយ URL: ការហៅត្រឡប់មកវិញដែលត្រូវការគឺជាការរុករកបណ្តោះអាសន្ន។

ការប៉ុនប៉ងនីមួយៗផុតកំណត់បន្ទាប់ពីដប់នាទី ហើយអាចប្រើបានតែម្តងគត់។ ម៉ាស៊ីនមេពិនិត្យស្ថានភាពរបស់វា អ្នកផ្ទៀងផ្ទាត់ PKCE និងគោលដៅផ្ទៀងផ្ទាត់ភាពត្រឹមត្រូវមុនពេលផ្លាស់ប្តូរលេខកូដ។ បន្ទាប់ពីផុតកំណត់ ឬបរាជ័យក្នុងការផ្លាស់ប្តូរ សូមចាប់ផ្តើមការប៉ុនប៉ងថ្មី។ ការប៉ុនប៉ងមិនអាចរស់រានពីការចាប់ផ្តើមម៉ាស៊ីនមេឡើងវិញបានទេ។

ថូខឹនប្រើឃ្លាំងសម្ងាត់ការតភ្ជាប់ដែលមានស្រាប់ និងផ្លូវធ្វើឱ្យស្រស់។ ការផ្ទៀងផ្ទាត់ការតភ្ជាប់ឡើងវិញតម្រូវឱ្យមានអត្តសញ្ញាណ Microsoft tenant/object ដូចគ្នា មិនមែនគ្រាន់តែអ៊ីមែលដូចគ្នានោះទេ។ វារក្សាប្រតិបត្តិករ naming/settings និងជំនួសលិខិតសម្គាល់ដែលបាននាំចូលដែលលែងប្រើ។ ការចូលដើមគឺសម្រាប់គណនី work/school ; ផ្លូវនាំចូលចាស់នៅតែមានសម្រាប់ការតភ្ជាប់ដែលមានស្រាប់ និងការកំណត់រចនាសម្ព័ន្ធកម្រិតដែលគាំទ្រ។

URL callback ពេញលេញគឺជាលិខិតបញ្ជាក់តែមួយដង។ កុំបញ្ចូលវាទៅក្នុងរូបថតអេក្រង់ កំណត់ហេតុ សារគាំទ្រ ឬការប្តេជ្ញាចិត្ត។ លំហូរនេះមិនបើកកម្មវិធីរុករកលើម៉ាស៊ីនមេ ពិនិត្យមើលប្រវត្តិកម្មវិធីរុករករបស់អ្នក ឬចាប់ផ្តើមម៉ាស៊ីនមេហៅត្រឡប់ក្នុងស្រុកទេ។

## ការចាប់យកអត្តសញ្ញាណ (វិធីសាស្ត្រ WebSocket )

1. ចូលនៅ `https://m365.cloud.microsoft/chat` ហើយចាប់ផ្តើមការសន្ទនា។
2. បើក**DevTools → បណ្តាញ** .
3. ត្រងដោយ**WS** (WebSocket) ។
4. ចុចការតភ្ជាប់ Chathub WebSocket ។ រកមើល URL ចាប់ផ្តើមដោយ `wss://substrate.office.com/m365Copilot/Chathub/`។
5. ពីរបស់វា។** ស្នើសុំ URL** , ចម្លង៖
   - តម្លៃប៉ារ៉ាម៉ែត្រសំណួរ `access_token` ( JWT ខ្លី ) ។
   - ផ្នែកផ្លូវ Chathub បន្ទាប់ពី `/Chathub/` (ឧ. `<oid>@<tenant>`).

URL ពេញលេញមានទម្រង់:

```
wss://substrate.office.com/m365Copilot/Chathub/<oid>@<tenant>?...&access_token=<jwt>
```

6. នៅក្នុង OmniRoute ជ្រើសរើស**Microsoft 365 Copilot** ជ្រើសរើសជម្រើស API-key/import កេរ្តិ៍ដំណែល ហើយបិទភ្ជាប់ព័ត៌មានសម្ងាត់ក្នុងទម្រង់៖

```
access_token=<jwt>; chathubPath=<oid>@<tenant>
```

7. ចុច** ការភ្ជាប់សាកល្បង** និង** រក្សាទុក** .

## ការចាប់យកអត្តសញ្ញាណ (ការនាំចូល HAR )

ជំនួសឱ្យការចម្លងតម្លៃដោយដៃពី WebSocket URL អ្នកអាចនាំចេញឯកសារ DevTools HAR ៖

1. បើក**DevTools → បណ្តាញ** .
2. ចាប់ផ្តើម ឬបន្តការសន្ទនា Microsoft 365 Copilot (នេះបង្កឱ្យមានការតភ្ជាប់ WebSocket ) ។
3. ចុចកណ្ដុរស្ដាំលើបន្ទះបណ្តាញ ហើយជ្រើសរើស** រក្សាទុកទាំងអស់ជា HAR ជាមួយនឹងមាតិកា** .
4. នៅក្នុង OmniRoute សូមប្រើ** នាំចូលឯកសារ .har** ប៊ូតុងនៅលើប្រអប់តភ្ជាប់អ្នកផ្តល់សេវា។

សម្រាប់ព័ត៌មានសម្ងាត់ដែលបានបិទភ្ជាប់ Test Connection ពិនិត្យមើលរូបរាងអត្តសញ្ញាណប័ណ្ណ ហើយនៅពេលដែលសញ្ញាសម្ងាត់ផ្ទុកការផុតកំណត់ ថាសញ្ញាសម្ងាត់ដែលអ្នកផ្តល់សេវានឹងប្រើមិនផុតកំណត់ទេ (និមិត្តសញ្ញាដែលបានរក្សាទុករបស់ការតភ្ជាប់ឈ្នះការបិទភ្ជាប់ដែលជាប់គាំង។ និមិត្តសញ្ញាធ្វើឱ្យស្រស់រាប់ថាអាចបន្តបាន)។ សញ្ញាសម្ងាត់ដែលត្រូវបានដកហូតមុនពេលវាផុតកំណត់នៅតែឆ្លងកាត់ការសាកល្បង។ ជជែកបន្ទាប់មកត្រឡប់មកវិញ** ៤០១** `m365_unauthorized` ប្រើ** ចូលជាមួយ Microsoft** ម្តងទៀត ឬចាប់យកលិខិតបញ្ជាក់ថ្មីឡើងវិញ។

### Copilot មិនបង្ហាញនៅក្នុងបញ្ជីអ្នកផ្តល់សេវាទេ។
