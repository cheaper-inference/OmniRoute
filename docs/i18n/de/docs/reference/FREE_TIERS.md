## TL;DR — Wie viel freie Inferenz aggregiert OmniRoute tatsächlich?

Diese Zahlen beschreiben separate Drittanbieterkonten und Berechtigungsbedingungen im gesamten Katalog. OmniRoute gewährt dieses Budget nicht: Sie müssen die erforderlichen Konten oder Anmeldeinformationen erhalten, berechtigte Anbieter verbinden und deren Grenzen einhalten. Die tatsächlich nutzbare Kapazität kann niedriger sein, einschließlich Null bei einer Neuinstallation ohne geeignete Route. Mit `tos: avoid` gekennzeichnete Anbieter sind standardmäßig vom automatischen Routing ausgeschlossen.

**Geprüft am 08.10.2026:** [Cerebras](https://www.cerebras.ai/pricing) bietet ein einmaliges Werbeguthaben in Höhe von 5 $ an, das eine Zahlungsmethode erfordert und nach 30 Tagen abläuft. ## 2026-10-18 Korrektur der kostenlosen SiliconFlow-Modelle (#17028)

Zehn SiliconFlow-Flaggschiffmodelle mit veröffentlichten positiven Preisen pro Token wurden fälschlicherweise
als kostenloser `recurring-uncapped`-Zugang ausgeliefert. Diese zehn Zeilen wurden aus dem
statischen Katalog **entfernt**, der nun **467 Einträge** enthält. SiliconFlow trägt nicht länger eine
bedingungslos kostenlose Modellzeile oder einen dauerhaft kostenlosen Anbieter zu den statischen Gesamtwerten bei.

Das bedeutet **nicht**, dass SiliconFlow keine kostenlosen Modelle hat. Der Nur-kostenlos-Import und das Kostenlos-Badge
erfordern jetzt **einen positiven Nachweis pro Modell aus den Live-Modelldaten des Anbieters**, beispielsweise eine
explizite boolesche Kostenlos-Markierung oder Token-Preise von jeweils null. Eine explizite Kostenpflicht-Markierung oder ein
positiver numerischer Preis hat Vorrang vor einer optimistischen Kostenlos-Markierung. Ein Modell ohne
verfügbare Live-Nachweise wird **nicht** als kostenlos angenommen; das einmalige Guthaben für neue Konten kann
keine wiederkehrende kostenlose Zuteilung belegen. Falls die aktuelle Anbieter-API keine zuverlässigen
Preise auf Modellebene bereitstellen kann, bestätigen Sie diese vor dem Routing in der Anbieterkonsole. Diese konservative
Entscheidung verhindert unerwartete Kosten durch Nur-kostenlos-Importe und automatische Kombinationen.

Die nachstehende historische Anbietertabelle ist keine verbindliche Zusage der aktuellen Verfügbarkeit. Ihr früherer
SiliconFlow-Eintrag für unbegrenzten Zugang/10 Modelle fehlt bewusst, da er keine
nachgewiesene wiederkehrende kostenlose Zuteilung mehr darstellt.

## 2026-10-15 Korrektur zu Bytez und Nous

Die [Bytez-Abrechnung](https://docs.bytez.com/model-api/docs/billing) beschränkt die
offenen Modelle des Free-Tarifs auf 7B Parameter. Die Einträge für 70B und 72B
erfordern eine Freischaltung durch den Kauf von Guthaben und wurden entfernt.
Mistral-7B bleibt `recurring-credit`: Das Guthaben wird alle vier Wochen
erneuert, die Abrechnung erfolgt jedoch pro Inferenzsekunde, und es wird kein
Token-Kontingent veröffentlicht. Seine Token-Zähler sind null, um eine
unbekannte Menge darzustellen, und ersetzen die nicht belegte Schätzung von
1M Token; dies bedeutet nicht, dass es kein kostenloses Guthaben gibt. Die
Änderungen zu Nous werden im nachstehenden Anbieterhinweis ausführlich
beschrieben.

## Zwei Regelwerke — Zählen vs. Entscheiden

OmniRoute beantwortet die Frage „Ist es kostenlos?“ anhand zweier Regelwerke,
die absichtlich unterschiedliche Quellen heranziehen:

| Regelwerk             | Maßgebliche Quelle                                                                                                                                                                    | Anwendungsbereiche                                                                                                            |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| **Zählen / Anzeigen** | Aufgelöster Katalog — die ausgelieferte Basisversion, überlagert durch den Radar-Feed (`getRadarCatalog`)                                                                             | Free-Tier-Gesamtsummen, Budgetkarte, Dashboards                                                                               |
| **Entscheiden**       | Nur der ausgelieferte Katalog (`FREE_MODEL_BUDGETS` in `open-sse/config/freeModelCatalog.data.ts`) sowie die lokalen Heuristiken (Suffix `:free`, Preis von null, `grantsFreeAccess`) | Alle Nutzer von `src/shared/utils/freeModels.ts`: Modellimport, `auto/*`-Routing, `GET /v1/models` und die Browser-Vorschauen |

Das Zählen kann sich verbessern, sobald ein Feed verfügbar ist. Das Entscheiden
bleibt an das Release-Artefakt gebunden, sodass die Antwort im Browser und auf
dem Server identisch, offline reproduzierbar und ohne Datenbank testbar ist.
Würde die Browser-Vorschau eine Quelle verwenden, während der Server-Import
eine andere nutzt, könnte die Vorschau dem widersprechen, was beim Anklicken
tatsächlich geschieht — diese Trennung wird absichtlich beibehalten.

## Methodik und Vorbehalte

- Zahlen sind** Schätzungen der Obergrenze** von den dokumentierten Free-Kontingent-Limits jedes Anbieters ab** 17.06.2026** , gesammelt durch Webrecherche. Die kostenlosen Stufen ändern sich ständig. Überprüfen Sie —, bevor Sie sich auf eine Zahl verlassen.
- **Wofür ein Eintrag eigentlich bürgt.** Kein Eintrag verfügt über eine Konfidenzbewertung pro Zeile, und die API dient keiner — Betrachtung aller oben genannten Zahlen als Schätzung derselben, nicht angegebenen Qualität. Zwei Fakten sind unterschiedlich, weil sie von Hand kuratiert und nicht abgeleitet werden: 44 Einträge tragen einen unabhängig dokumentierten Hard Stop (39 davon die xKiro Zeilen, die sich alle ein Tagesgeld teilen), und 22 Einträge tragen eine prompte Trainingsoffenlegung. `hardStopGuaranteed` wird nur gesetzt, wenn die eigenen Bedingungen des Anbieters besagen, dass bei Überschreitung des kostenlosen Kontingents die Anfrage abgelehnt wird, anstatt stillschweigend mit der Rechnungsstellung zu beginnen, wobei die Quelle in einem Kommentar neben dem Eintrag steht; Die Standardeinstellung lautet nie `true` und ein Eintrag, den niemand überprüft hat, bleibt deaktiviert. Eine fehlende Hard-Stop-Flagge bedeutet also „nicht etabliert“ und nicht „bekanntermaßen in Rechnung gestellt“.**STRICT -Modus** (der opt-in `freeAccessPolicy=strict` Routing Guard) vertraut nur Einträgen, die das Flag tragen; jede andere kostenlose Stufe ist als `no-hard-stop` ausgeschlossen (siehe `open-sse/services/autoCombo/strictZeroCostFilter.ts`). Wenn der Wächter einen Pool filtert, meldet das für den Bediener sichtbare Protokoll sowohl die Ausschlussanzahl als auch seinen `no-hard-stop` Anteil.
- Nur wiederkehrende monatliche `estMonthlyFreeTokens` = Token.** Einmalige Anmeldegutschriften werden nicht wiederholt** und zählen als 0. Auslaufstufen sind ebenfalls 0.
- Tägliche Token-Obergrenze → `monthly = daily × 30`. Nur RPD dokumentiert → `RPD × ~800 output tokens × 30`. Nur RPM/TPM (keine Tagesobergrenze) →** ohne Deckel** (siehe unten).
- **Kostenloser Zugang, aber keine veröffentlichte Token-Obergrenze** (`glm-cn`, `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `nvidia`): Dies sind rate/concurrency-limited. Wir klassifizieren sie `recurring-uncapped` und** Fassen Sie sie niemals zusammen** — multipliziert mit `RPM × 24/7 × 30d` würde eine Fantasieobergrenze ergeben (die Inflation, die wir ablehnen). NVIDIAAPI ist nur zur Testversion gedacht; siehe den ToS Vorbehalt unten.
- **Einzahlungs-Freischalt-Boost:** eine einmalige kleine Aufladung, die dauerhaft ein kostenloses Kontingent erhöht (OpenRouter: 10 $ → 1000 req/day ≈ +24M/mo). Wird als separate Zahl ausgewiesen und nicht in die ständige Schlagzeile aufgenommen.
- **Berechtigungsgesteuerte Quoten** (`eligibilityGate: "regional-identity"`): ein echtes wiederkehrendes Kontingent, das erst nach einer regionalen Identitätsprüfung geöffnet wird (heute Echtnamenüberprüfung Festland-China). Wird mit der gleichen Pool-Deduplizierungsregel in eine separate Zahl (`gatedRecurringTokens`) gezählt, niemals in die stetige Überschrift. Das Regime (`freeType`) bleibt unverändert, daher bleibt das Routing unverändert.
- **Beweisklassen.** Die Regel: Eine Zahl im Katalog nennt ihre Quelle in einem `// evidence:` -Kommentar neben dem Eintrag — `public-page` (eine Anbieterseite, die jeder lesen kann), `api-public` (ein nicht authentifizierter Endpunkt des Anbieters, z. B. NaraRouter Endpunkt für öffentliche Pläne unter router.bynara.id) oder `console-verified <date> por <who>` (die Zahl ist nur innerhalb einer Kontokonsole sichtbar; der Kommentar zeichnet auf, wer sie wann gesehen hat, und die öffentliche Seite, die besagt, dass die Obergrenze existiert). Der Zustand heute: Die fünf Blöcke, die am 02.09.2026 erneut geprüft wurden, tragen es (`gemini`, `groq`, `mistral`, `ollama-cloud`, `nara`); Einträge, die vor dem erneuten Audit vom 02.09.2026 erstellt wurden, übernehmen die früheren Recherchen, bis sie geändert werden. beliebig** neu oder geändert** Nummer ohne Beweiskommentar ist ein Fehler. Heute ist nur `mistral` konsolenverifiziert.

## Warum unsere Anzahl kleiner ist als die anderer Aggregatoren

Die meisten „kostenlosen Token pro Monat“-Zahlen in diesem Bereich sind Summen der Bezeichnungen pro Modell. Unseres ist es mit Absicht nicht:

- **Jeder gemeinsam genutzte Pool wird einmal gezählt.** Der kostenlose Plan von Mistral umfasst eine 1B/month Zulage pro Organisation. Die Auflistung unter fünf Modellen macht es nicht zu 5B. Pro Modell summiert würde unser eigener Katalog lauten**~ 7,4B** (neu berechnet am 03.09.2026; diese Zahl ist nicht CI-gesteuert — messen Sie sie erneut, wenn sich der Katalog ändert) — heißt es in der Überschrift**~ 1,47B** denn das ist, was ein Konto jedes Anbieters tatsächlich ausgeben kann.
- **Tagesobergrenzen werden umgerechnet, Kurse jedoch nicht.** Eine dokumentierte tokens/day -Obergrenze wird zu `× 30`; eine dokumentierte requests/day Obergrenze wird zu `RPD × ~800 tokens × 30`; Ein Anbieter, der nur Anfragen pro Minute veröffentlicht, hat** NEIN** monatliche Zahl und wird als _unbegrenzt_ aufgeführt, nie summiert. Die Multiplikation einer Zinsgrenze mit 24/7 ist die Inflation, die wir ablehnen.
- **Kontingente hinter einer regionalen Identitätsprüfung werden gesondert ausgewiesen** (`+~6M behind regional identity verification`), da die meisten Leser sie nicht verwenden können.
- **Anmeldeguthaben gelten nur für den ersten Monat** und als zweite Zahl gemeldet, nie in die stetige Zahl eingeblendet.
- **Die Zahl wird durch CI erzwungen.** `npm run check:docs-counts` berechnet die Gesamtsummen aus dem Katalog neu und schlägt beim Erstellen fehl, wenn diese Datei, der README oder die Budgetkarte davon abweichen.

## Glossar

| Begriff                       | Bedeutung                                                                                           |
| ----------------------------- | --------------------------------------------------------------------------------------------------- |
| **RPM / RPD / RPH**           | Anfragen pro Minute / Tag / Stunde                                                                  |
| **TPM / TPD**                 | Token pro Minute / Tag                                                                              |
| **Dokumentiertes Kontingent** | Der Anbieter veröffentlicht ein explizites tägliches/monatliches Token-Limit (verlässliches Budget) |
| **Theoretische Obergrenze**   | `rate-limit × 24/7 × 30d` — ein Maximum, kein gewährtes Budget                                      |
| **Neuron**                    | Cloudflare-Recheneinheit (~1 Ausgabe-Token)                                                         |
