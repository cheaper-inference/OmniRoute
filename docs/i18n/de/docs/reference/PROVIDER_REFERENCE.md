## Kategorien

- **Kostenlos** — kostenloses Kontingent mit API-Schlüssel (über das Dashboard konfiguriert)
- **Ohne Authentifizierung** — öffentliche Endpunkte, die weder einen Schlüssel noch eine Anmeldung erfordern
- **OAuth** — der Anmeldevorgang wird von OmniRoute abgewickelt, kein API-Schlüssel erforderlich
- **Web-Cookie** — bindet die Web-App des Anbieters über Cookie-Authentifizierung ein
- **API-Schlüssel** — kostenpflichtiger Anbieter, der über einen API-Schlüssel konfiguriert wird (möglicherweise mit kostenlosem Guthaben)
- **Lokal** — wird auf dem Rechner des Benutzers ausgeführt (Ollama, LM Studio, vLLM usw.)
- **Suche** — Anbieter für die Websuche
- **Audio** — reine Audioanbieter (TTS/STT)
- **Upstream-Proxy** — Anbieter, die Anfragen an andere Anbieter weiterleiten
- **Cloud-Agent** — lang laufende Coding-Agenten (Codex Cloud, Devin, Jules)
- **System** — OmniRoute-interne Anbieter (Loopback usw.)

Zusätzliche Tags: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool-Aufrufe` (sofern angegeben): `native` — echte API für Funktionsaufrufe; `emulated` — das `tools`-Array wird über `webTools.ts` im Prompt emuliert (per regulärem Ausdruck analysierte `<tool>{...}</tool>`-Blöcke); `none` — `tools` wird derzeit stillschweigend verworfen. Siehe #7286.

Verwenden Sie das Dashboard unter `/dashboard/providers`, um die einzelnen Anbieter zu aktivieren, zu konfigurieren und zu testen.
