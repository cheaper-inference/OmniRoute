மறுமுயற்சி முடிவுகளை எடுப்பதற்கு முன் தோல்விகள் வகைப்படுத்தப்படுகின்றன.

நேரமுடிவுகள், நெட்வொர்க் பிழைகள், விகித வரம்புகள் மற்றும் வழங்குநர் 5xx பதில்கள் போன்ற தற்காலிக தோல்விகள் தோல்வியடையலாம். தீர்ந்த கோட்டா அல்லது கிரெடிட் (ஒதுக்கீடு 429, அல்லது 402 செலுத்துதல் தேவை) ஒரே வழங்குநரிடம் மீண்டும் முயற்சிக்கப்படாது, ஆனால் வேறொருவருக்கு ஒதுக்கப்படும், அதன் ஒதுக்கீடு தனித்தனியாக உள்ளது. அங்கீகாரப் பிழைகள், அனுமதிப் பிழைகள், தவறான கோரிக்கைகள், கிடைக்காத மாதிரிகள் மற்றும் அறியப்படாத தோல்விகள் ஆகியவை கண்மூடித்தனமாக மீண்டும் முயற்சிக்கப்படுவதில்லை.

இயல்புநிலை குறுக்கு வழங்குநர் கொள்கையானது மூன்று வழங்குநர் முயற்சிகள் வரை அனுமதிக்கிறது, விகித வரம்புகள் மற்றும் காலக்கெடுவை மீண்டும் முயற்சிக்கிறது, தீர்ந்து போன ஒதுக்கீட்டில் தோல்வியடைகிறது, மேலும் தற்காலிக சுற்று நிலையிலிருந்து நிர்வாக முடக்கத்தை தனித்தனியாக வைத்திருக்கும்.

## அது எங்கே பொருந்தும்

- **காம்போஸ்** காம்போவின் சொந்த மூலோபாயம் மற்றும் அமைப்புகளின்படி அவர்களின் இலக்குகளுக்கு இடையில் தோல்வியடைகிறது.
- **ஒரு வெற்று மாதிரி ஐடி** ( `provider/` முன்னொட்டு இல்லை) பல செயலில் உள்ள வழங்குநர்கள் சேவை செய்கிறார்கள், அந்த சரியான பெயரின் சேர்க்கை இல்லாமல், முதலில் வழங்குநரின் அனுமானத் தேர்வுகளுக்கு அனுப்பப்படும். அந்த முயற்சி தோல்வியடைந்தால், பாலிசி தோல்வியடைந்தால், அதே கோரிக்கை ஐடியை வழங்கும் அடுத்த செயலில் உள்ள வழங்குநருக்கு அனுப்பப்படும். பதில் வழங்கியவருக்கு முன் முயற்சித்த வழங்குநர்களின் எண்ணிக்கையுடன் `x-omniroute-fallback-attempts` உள்ளது.
  - ஒவ்வொரு மாற்றீடும் அனுமானம் எடுத்தது போல் சரியாக அங்கீகரிக்கப்படுகிறது. API விசையைத் தடுக்கும் அல்லது ஒப்புக்கொள்ளாத இலக்கு, அப்ஸ்ட்ரீம் அழைப்பு இல்லாமல் தவிர்க்கப்பட்டது, மேலும் வாடிக்கையாளர் உண்மையான அப்ஸ்ட்ரீம் பிழையைப் பெறுகிறார், அது பெயரிடப்படாத இலக்குக்கான கொள்கை நிராகரிப்பு அல்ல.
  - தோல்வியுற்ற பதில் மட்டுமே நகர்கிறது: முதல் ஸ்ட்ரீம் செய்யப்பட்ட பைட்டுக்குப் பிறகு எதுவும் தோல்வியடையாது.
  - கோரப்பட்ட மாதிரியின் ஒவ்வொரு வழங்குநரும் தோல்வியடைந்த பின்னரே எமர்ஜென்சி ஃபால்பேக் மாடல் ஸ்வாப் பொருந்தும்.
  - ஒரு இணைப்பில் பின் செய்யப்பட்ட கோரிக்கை (`x-omniroute-connection`) அதில் இருக்கும்.
  - முன்னொட்டு ஐடி (`provider/model`) வேறொரு வழங்குநருக்கு மாற்றப்படாது.

சர்க்யூட் நிலைகள் `closed`, `open` மற்றும் `half_open` ஆகும். ஒரு கூல்டவுன் ஒரு எல்லைக்குட்பட்ட ஆய்வை திட்டமிடுகிறது; ஒரு வெற்றிகரமான ஆய்வு சுற்றுகளை மூடுகிறது மற்றும் தோல்வியுற்ற ஆய்வு அதை மீண்டும் திறக்கிறது.
