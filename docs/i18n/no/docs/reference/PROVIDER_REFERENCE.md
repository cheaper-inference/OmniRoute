## Kategorier

- **Gratis** — gratisnivå med API-nøkkel (konfigureres via kontrollpanelet)
- **Ingen autentisering** — offentlige endepunkter som ikke krever nøkkel eller innlogging
- **OAuth** — innloggingsflyt som håndteres av OmniRoute, uten behov for API-nøkkel
- **Nettinformasjonskapsel** — pakker inn leverandørens nettapp via autentisering med informasjonskapsel
- **API-nøkkel** — betalt leverandør som konfigureres via API-nøkkel (gratis kreditter kan være tilgjengelige)
- **Lokal** — kjører på brukerens maskin (Ollama, LM Studio, vLLM osv.)
- **Søk** — leverandører av nettsøk
- **Lyd** — leverandører kun for lyd (TTS/STT)
- **Oppstrømsproxy** — leverandører som videresender til andre leverandører
- **Skyagent** — langvarige kodeagenter (Codex Cloud, Devin, Jules)
- **System** — interne OmniRoute-leverandører (tilbakekobling osv.)

Tilleggstagger: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (der det vises): `native` — ekte API for funksjonskall; `emulated` — `tools`-matrisen emuleres via ledeteksten ved hjelp av `webTools.ts` (regulære uttrykk analyserer `<tool>{...}</tool>`-blokker); `none` — `tools` ignoreres for øyeblikket uten varsel. Se #7286.

Bruk kontrollpanelet på `/dashboard/providers` for å aktivere, konfigurere og teste hver leverandør.
