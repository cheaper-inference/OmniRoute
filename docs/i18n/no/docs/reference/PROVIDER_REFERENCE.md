## Kategorier

- **Gratis** — gratisnivå med API-nøkkel (konfigureres via kontrollpanelet)
- **Uten autentisering** — offentlige endepunkter som ikke krever nøkkel eller innlogging
- **OAuth** — innloggingsflyt håndtert av OmniRoute, ingen API-nøkkel nødvendig
- **Nettinformasjonskapsel** — pakker inn leverandørens nettapp via informasjonskapselbasert autentisering
- **API-nøkkel** — betalt leverandør konfigurert via API-nøkkel (gratis kreditter kan være tilgjengelige)
- **Lokal** — kjører på brukerens maskin (Ollama, LM Studio, vLLM osv.)
- **Søk** — leverandører av nettsøk
- **Lyd** — leverandører kun for lyd (TTS/STT)
- **Oppstrømsproxy** — leverandører som videresender til andre leverandører
- **Skyagent** — langvarige kodeagenter (Codex Cloud, Devin, Jules)
- **System** — interne OmniRoute-leverandører (loopback osv.)

Ytterligere tagger: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Verktøykall` (der det vises): `native` — ekte API for funksjonskall; `emulated` — `tools`-matrisen emuleres via ledeteksten med `webTools.ts` (regulært uttrykk-tolkede `<tool>{...}</tool>`-blokker); `none` — `tools` forkastes for øyeblikket uten varsel. Se #7286.

Bruk kontrollpanelet på `/dashboard/providers` for å aktivere, konfigurere og teste hver leverandør.
