## 何時選擇OmniRoute

- 您自行託管並且想要**最大提供者覆蓋範圍**（394 個提供者，155 個free/no-auth目錄條目）
- 你需要一個**內建MCP伺服器**（LLM工具、記憶、作為工具暴露的技能）
- 你需要**A2A協議**適用於客服人員到客服人員的工作流程
- 你想要**指紋隱形**(JA3/JA4) 以避免被上游CAPTCHAs偵測
- 你需要**企業特色**（護欄、評估、審計追蹤）無需SaaS法案

## 適合選擇 LiteLLM 的情況

- 您**以 Python 為主**，並需要與 `litellm.completion()` 緊密整合
- 您需要**成熟的生產環境部署方案**（k8s、Helm charts）
- 您的團隊已在執行 Python 微服務

## 適合選擇 OpenRouter (SaaS) 的情況

- 您不想自行託管
- 您可接受按權杖付費及 SaaS 加價
- 您需要使用**單一付款方式**支付所有提供者的費用

## 適合選擇 Portkey 的情況

- 您需要具備正常運作時間保證的**商業 SLA**
- 您偏好使用**受管理的儀表板**，而不想承擔維運負擔
- 您需要開箱即用的**企業合規**功能
