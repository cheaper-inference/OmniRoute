## 何時選擇 OmniRoute

- 您自行託管，並希望獲得**最大的提供者涵蓋範圍**（375 家提供者、155 個免費/免驗證的目錄項目）
- 您需要**內建 MCP 伺服器**（LLM 工具、記憶、以工具形式公開的技能）
- 您需要 **A2A 協定**來實現代理對代理（agent-to-agent）的工作流程
- 您需要**指紋隱匿**（JA3/JA4），以避免被上游 CAPTCHA 偵測
- 您需要**企業級功能**（防護機制、評估、稽核追蹤），且不想支付 SaaS 帳單

## 適合選擇 LiteLLM 的情況

- 您**以 Python 為主**，並需要與 `litellm.completion()` 緊密整合
- 您需要**成熟的生產環境部署方案**（k8s、Helm charts）
- 您的團隊已在執行 Python 微服務

## 適合選擇 OpenRouter (SaaS) 的情況

- 您不想自行託管
- 您可接受按權杖付費及 SaaS 加價
- 您需要使用**單一付款方式**支付所有提供者的費用

## 適合選擇 Portkey 的情況

- 您需要具備正常運作時間保證的**商業 SLA**
- 您偏好使用**受管理的儀表板**，而不想承擔維運負擔
- 您需要開箱即用的**企業合規**功能
