有些服務曾整合至 OmniRoute，之後因其營運者提出要求而移除。本頁是這些移除事項的永久記錄。其唯一目的是防止它們意外重新出現：當貢獻者找到舊分支、快取的 npm tarball、已封存的 issue，或收到「還原提供者 X」的要求時，需要有一個明確指出**不得重新引入**的地方。

本頁**不是**已停止或終止營運服務的清單。這些服務記錄於
[`FREE_TIERS.md`](FREE_TIERS.md)（「已移除／無免費方案」），若服務恢復營運，便可重新加入。以下項目只有在取得請求中所列營運者的書面許可後才能重新加入，且該許可必須從對應項目連結。

## 政策

1. **服務營運者提出的下架要求應予遵從，不作協商。** OmniRoute 與任何上游服務均無關聯。當服務營運者要求移除整合時，就必須移除，無論該整合是否使用官方 API。
2. **「已移除」是指 OmniRoute 所控制的所有介面與內容。** 執行器、註冊表項目、提供者 id 與別名、模型清單、端點、環境變數、圖示、儀表板卡片、產生的提供者參考文件、`FREE_TIERS.md`、環境參考文件、README 中的數量、`llm.txt` 鏡像、專用測試與黃金快照、程式碼註解、CHANGELOG 項目（包含已登錄的核對記錄，請參閱 `config/release/changelog-reconciliations.json`）、GitHub Releases 說明、wiki，以及主題為該提供者的 GitHub issues、discussions 與 pull requests（issues 與 discussions 應刪除；pull requests 應重新命名、替換其說明並鎖定討論串，因為 GitHub 無法刪除 pull requests）。
3. **未取得書面許可，不得重新引入本頁中的任何項目。** 這包括將 id 或別名重新加入任何提供者目錄、將網域加入執行器、接受「還原」該項目的貢獻者 PR、將其加入免費模型目錄，或記錄任何可透過 OmniRoute 手動存取該服務的方法。關閉此類 PR 與 issue，並附上本頁連結。
4. **保持項目內容精簡。** 僅記錄審查者識別重新引入行為所需的資訊：識別碼、網域、日期，以及執行移除作業的 pull request。請勿說明整合的運作方式。
5. **迴歸防護機制是 `tests/unit/removed-providers-blocklist.test.ts`。** 若下列任何識別碼或網域再次出現在提供者目錄、執行器映射或提供者註冊表原始碼中，此測試便會失敗。新增一列至此處時，請在同一個 PR 中將新的識別碼加入該測試。

## 新增項目

收到新的下架要求時：

1. 確認要求來自服務營運者（其支援地址或由其控制的網域），並私下保存該訊息。
2. 按照政策第 2 項中的檢查清單移除整合。無金鑰提供者請以
   [#12440](https://github.com/diegosouzapw/OmniRoute/pull/12440) 作為參考；具有已儲存連線的 API 金鑰提供者則以 [#10210](https://github.com/diegosouzapw/OmniRoute/pull/10210) 作為參考（需新增遷移）。
3. 在同一個 PR 中，於上表新增一列，並將識別碼加入
   `tests/unit/removed-providers-blocklist.test.ts`。
4. PR 合併後回覆營運者，列出已移除的內容，以及 OmniRoute 無法變更的項目（已發布的 npm 與 Docker 版本、git 歷史記錄、第三方分支）。
