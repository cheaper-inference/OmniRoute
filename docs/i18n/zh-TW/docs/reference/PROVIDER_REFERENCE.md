## 類別

- **免費** — 提供免費方案，需使用 API 金鑰（透過儀表板設定）
- **無需驗證** — 完全不需要金鑰或登入的公開端點
- **OAuth** — 登入流程由 OmniRoute 處理，不需要 API 金鑰
- **Web Cookie** — 透過 Cookie 驗證封裝提供者的 Web 應用程式
- **API 金鑰** — 透過 API 金鑰設定的付費提供者（可能提供免費點數）
- **本機** — 在使用者的機器上執行（Ollama、LM Studio、vLLM 等）
- **搜尋** — Web 搜尋提供者
- **音訊** — 僅限音訊的提供者（TTS/STT）
- **上游代理** — 代理至其他提供者的提供者
- **雲端代理程式** — 長時間執行的程式開發代理程式（Codex Cloud、Devin、Jules）
- **系統** — OmniRoute 內部提供者（回送等）

其他標籤：`image`、`video`、`aggregator`、`enterprise`、`embed/rerank`、`self-hosted`。

`工具呼叫`（若有顯示）：`native` — 真正的函式呼叫 API；`emulated` — `tools` 陣列透過 `webTools.ts` 以提示詞模擬（使用正規表示式剖析 `<tool>{...}</tool>` 區塊）；`none` — 目前會直接捨棄 `tools`，且不顯示任何提示。請參閱 #7286。

請使用 `/dashboard/providers` 的儀表板來啟用、設定及測試各個提供者。
