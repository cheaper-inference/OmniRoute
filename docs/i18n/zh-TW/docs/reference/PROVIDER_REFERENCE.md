## 類別

- **自由的**帶有API密鑰的—免費套餐（透過儀表板配置）
- **無授權**根本不需要金鑰或登入的—公共端點
- **OAuth** —登入流程由OmniRoute處理，無需API金鑰
- **網路cookie** —透過 cookie 驗證包裝提供者的 Web 應用程式
- **API鍵**透過API金鑰配置的—付費提供者（可能適用免費積分）
- **當地的**—在使用者的電腦上運作（Ollama、 LM Studio、 vLLM等）
- **搜尋**—網路搜尋提供者
- **聲音的**—純音訊提供者 (TTS/STT)
- **上游代理**代理其他提供者的—提供者
- **雲端代理**—長時間運行的編碼代理程式（Codex Cloud、 Devin、 Jules）
- **系統**— OmniRoute-內部提供者（環回等）

其他標籤： `image`、 `video`、 `aggregator`、 `enterprise`、 `embed/rerank`、 `self-hosted`。

`Tool calling` （如圖所示）： `native` —實際函數呼叫API； `emulated` — `tools`陣列透過`webTools.ts` （正規表示式解析的`<tool>{...}</tool>`區塊）進行提示模擬； `none` — `tools`目前已悄悄刪除。參見#7286。

使用`/dashboard/providers`的儀表板來啟用、設定和測試每個提供者。
