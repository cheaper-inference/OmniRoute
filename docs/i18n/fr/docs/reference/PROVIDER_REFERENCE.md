## Catégories

- **Gratuit** — offre gratuite avec une clé API (configurée via le tableau de bord)
- **Sans authentification** — points de terminaison publics ne nécessitant aucune clé ni connexion
- **OAuth** — flux de connexion géré par OmniRoute, sans clé API requise
- **Cookie web** — encapsule l’application web du fournisseur via une authentification par cookie
- **Clé API** — fournisseur payant configuré via une clé API (des crédits gratuits peuvent être proposés)
- **Local** — s’exécute sur la machine de l’utilisateur (Ollama, LM Studio, vLLM, etc.)
- **Recherche** — fournisseurs de recherche sur le Web
- **Audio** — fournisseurs exclusivement audio (TTS/STT)
- **Proxy en amont** — fournisseurs servant de proxy vers d’autres fournisseurs
- **Agent cloud** — agents de programmation à exécution prolongée (Codex Cloud, Devin, Jules)
- **Système** — fournisseurs internes à OmniRoute (bouclage, etc.)

Étiquettes supplémentaires : `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Appel d’outils` (lorsqu’indiqué) : `native` — véritable API d’appel de fonctions ; `emulated` — le tableau `tools` est émulé par invite via `webTools.ts` (blocs `<tool>{...}</tool>` analysés par expression régulière) ; `none` — `tools` est actuellement ignoré silencieusement. Voir #7286.

Utilisez le tableau de bord à l’adresse `/dashboard/providers` pour activer, configurer et tester chaque fournisseur.
