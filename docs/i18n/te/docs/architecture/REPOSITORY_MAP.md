## అగ్ర-స్థాయి ట్రీ

```
OmniRoute/
├── src/                  # Next.js 16 అప్లికేషన్ (UI + API రూట్లు + లైబ్రరీలు + డొమైన్ + సర్వర్)
├── open-sse/             # స్ట్రీమింగ్ ఇంజిన్ వర్క్స్పేస్ (హ్యాండ్లర్లు, ఎగ్జిక్యూటర్లు, ట్రాన్స్లేటర్, MCP సర్వర్)
├── packages/            # npm వర్క్స్పేస్లు: ui-kit (వెండర్ చేయబడిన Keak CI UI Kit) మరియు browser-pool
├── electron/             # డెస్క్టాప్ ర్యాపర్ (Electron 41 + electron-builder 26.10)
├── bin/                  # CLI ఎంట్రీ పాయింట్ మరియు కమాండ్ హ్యాండ్లర్లు
├── scripts/              # బిల్డ్, తనిఖీ, సింక్ మరియు ఒకసారి అమలు చేసే స్క్రిప్ట్లు
├── docs/                 # పబ్లిక్ డాక్యుమెంటేషన్ (మీరు ఇక్కడ ఉన్నారు)
├── tests/                # అన్ని టెస్ట్ సూట్లు (యూనిట్, ఇంటిగ్రేషన్, e2e, ప్రోటోకాల్ క్లయింట్లు)
├── public/               # Next.js స్టాటిక్ అసెట్లు, PWA మానిఫెస్ట్, సర్వీస్ వర్కర్, ఐకాన్లు
├── config/               # స్టాటిక్ కాన్ఫిగ్ + క్వాలిటీ-గేట్ స్థితి (i18n, payloadRules, quality/)
├── images/               # మార్కెటింగ్ / README ఇమేజ్ అసెట్లు
├── @omniroute/           # ప్రచురించగల అనుబంధ ప్యాకేజీలు (opencode-plugin, opencode-provider)
├── skills/               # CLI/ఏజెంట్ స్కిల్ ప్యాక్లు (cli-* + omni-* + config-codex-cli)
├── examples/             # నమూనా ప్లగిన్లు + omniroute-cmd-hello స్టార్టర్
├── contrib/              # కమ్యూనిటీ సహకారాలు (podman/)
├── .source/              # Fumadocs సోర్స్ కాన్ఫిగ్ (source.config.mjs + server/browser/dynamic)
├── .github/              # GitHub Actions వర్క్ఫ్లోలు + ఇష్యూ టెంప్లేట్లు + PR టెంప్లేట్
├── .husky/               # Git హుక్స్ (pre-commit, pre-push)
├── .claude/              # Claude Code స్లాష్ కమాండ్లు (ప్రాజెక్ట్ పరిధిలో)
├── .agents/              # Codex / సాధారణ ఏజెంట్ వర్క్ఫ్లోలు + స్కిల్స్ (.claude/ యొక్క ప్రతిరూపం)
├── .vscode/              # VS Code వర్క్స్పేస్ సెట్టింగ్లు
├── _ideia/               # ప్రణాళిక గమనికలు (అనధికారికం; పంపిణీ చేయబడవు)
├── _mono_repo/           # చారిత్రక ఉపప్రాజెక్ట్లు (cloud, site, vscode-extension)
├── _references/          # సంబంధిత OSS ప్రాజెక్ట్ల నుండి చదవడానికి-మాత్రమే ఉద్దేశించిన రిఫరెన్స్ క్లోన్లు
├── _tasks/               # ప్రతి విడుదలకు సంబంధించిన టాస్క్ ట్రాకింగ్ ఫైల్లు (అనధికారికం)
├── .build/ .worktrees/ dist/   # స్థానిక బిల్డ్ / git-worktree / బిల్డ్-అవుట్పుట్ తాత్కాలిక ఫైల్లు (gitignored)
├── .issues/              # స్థానిక ఇష్యూ క్యాష్ (gitignored)
├── .playwright-mcp/      # Playwright MCP టెస్ట్ ఆర్టిఫాక్ట్లు
├── coverage/             # c8 కవరేజ్ అవుట్పుట్ (gitignored)
├── logs/                 # రన్టైమ్ లాగ్లు (gitignored)
├── node_modules/         # డిపెండెన్సీలు (gitignored)
├── package/              # npm pack స్టేజింగ్ ప్రాంతం (బిల్డ్ ఆర్టిఫాక్ట్)
├── .next/                # Next.js బిల్డ్ అవుట్పుట్ (gitignored)
└── (రూట్ ఫైల్లు — క్రింద చూడండి)
```
