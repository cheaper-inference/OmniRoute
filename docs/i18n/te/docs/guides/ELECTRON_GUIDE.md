> **సత్యానికి మూలం:** `electron/` కార్యస్థలం** చివరిగా నవీకరించబడింది:** 2026-06-28 — v3.8.40

OmniRoute ఒక క్రాస్-ప్లాట్ఫారమ్ డెస్క్టాప్ యాప్ను (Windows / macOS / Linux) నిర్మించింది**Electron 41** +** ఎలక్ట్రాన్-బిల్డర్ 26.10** . డెస్క్టాప్ యాప్ Next.js స్వతంత్ర సర్వర్ను చైల్డ్ ప్రాసెస్గా రూపొందిస్తుంది, దానిపై `BrowserWindow` ని చూపుతుంది మరియు సిస్టమ్ ట్రే, ఆటో-అప్డేటర్, IPC బ్రిడ్జ్ మరియు జీరో-కాన్ఫిగర్ రహస్య బూట్స్ట్రాప్ను జోడిస్తుంది.

## ఆర్కిటెక్చర్

```
┌──────────────────────────────────────────────┐
│ Electron main process (electron/main.js)     │
│ ├─ Single-instance lock                       │
│ ├─ Child process: Next.js standalone server  │
│ │   (spawned with Electron's Node runtime)   │
│ ├─ BrowserWindow → http://localhost:PORT     │
│ ├─ System tray + context menu                │
│ ├─ Auto-update via electron-updater          │
│ ├─ Content Security Policy (session headers) │
│ └─ Secret bootstrap (JWT / API_KEY_SECRET)   │
└──────────────────────────────────────────────┘
            ↕ IPC bridge (electron/preload.js)
┌──────────────────────────────────────────────┐
│ Renderer (Next.js dashboard)                  │
│   window.electronAPI.* (contextIsolation)     │
└──────────────────────────────────────────────┘
```

| `npm run electron:build:win`      | Windows NSIS ఇన్స్టాలర్ + పోర్టబుల్ (x64)ని రూపొందిస్తుంది                                      |

`electron/` కార్యస్థలం కూడా బహిర్గతం చేస్తుంది:

- `npm run prepare:bundle` — `scripts/build/prepare-electron-standalone.mjs` ని నడుపుతుంది
- `npm run build:mac-x64` / `build:mac-arm64` — సింగిల్-ఆర్చ్ macOS బిల్డ్లు
- `npm run pack` — డైరెక్టరీ-లోకల్ టెస్టింగ్ కోసం మాత్రమే బిల్డ్ (ఇన్స్టాలర్ లేదు)

## ఐచ్ఛిక రన్టైమ్ ప్యాక్లు

డెస్క్టాప్ బిల్డ్లు వాటి ఇన్స్టాలర్లతో పాటు ఐచ్ఛిక రన్టైమ్ ఆర్కైవ్లను ప్రచురించగలవు. ఇన్స్టాల్ చేయబడిన సర్వర్ పేలోడ్లో `optional-packs.index.json` ఉంది ( Windows మరియు Linux లో `resources/app` కింద). `browser-runtime` ఎంట్రీ కోసం, `packs[].tarball` చదివి డౌన్లోడ్ చేయండి** అదే విడుదల నుండి ఖచ్చితమైన ఫైల్ పేరు** . ఆర్కైవ్ పేర్లలో SHA-256 డైజెస్ట్ ఉంటుంది; వేర్వేరు నిర్మాణాలకు వేర్వేరు ఆర్కైవ్లు అవసరం కావచ్చు. డౌన్లోడ్ చేసిన ఫైల్ పేరును మార్చకుండా ఉంచండి.

ఇన్స్టాల్ చేయబడిన యాప్ ఇండెక్స్ మరియు ఎంచుకున్న ఆర్కైవ్ను ఒక డైరెక్టరీలోకి కాపీ చేసి, అదే విడుదల నుండి CLI ఉపయోగించండి:

```bash
omniroute packs list --source /path/to/packs
omniroute packs install browser-runtime --source /path/to/packs
```

`packs list` సంస్థాపన మరియు ధృవీకరణ స్థితిని ప్రదర్శిస్తుంది, ఆర్కైవ్ ఫైల్ పేరు కాదు. బండిల్ చేయబడిన సూచిక ఆర్కైవ్ను ఎంచుకుంటుంది. ఇన్స్టాలేషన్ దాని ఆర్కైవ్ చెక్సమ్ను వెలికితీసే ముందు మరియు దాని ప్యాకేజీ చెక్సమ్లను ఇన్స్టాల్ చేసిన ప్యాక్ను భర్తీ చేయడానికి ముందు ధృవీకరిస్తుంది. ఇది స్థానిక ఫైళ్లను చదువుతుంది; అది తప్పిపోయిన ఆర్కైవ్లను డౌన్లోడ్ చేయదు. ఇన్స్టాలేషన్ తర్వాత అప్లికేషన్ను రీస్టార్ట్ చేయండి. విడుదలకు సరిపోలే ఆస్తి లేకుంటే, ఆ విడుదల ఆస్తుల ద్వారా ఐచ్ఛిక ప్యాక్ అందుబాటులో ఉండదు.

## IPC వంతెన (`preload.js`)

ప్రీలోడ్ `contextIsolation: true` మరియు `nodeIntegration: false` తో `contextBridge` ఉపయోగించి `window.electronAPI` లో వైట్లిస్ట్ చేయబడిన API బహిర్గతం చేస్తుంది.

```javascript
const VALID_CHANNELS = {
  invoke: [
    "get-app-info",
    "open-external",
    "get-data-dir",
    "restart-server",
    "check-for-updates",
    "download-update",
    "install-update",
    "get-app-version",
  ],
  send: ["window-minimize", "window-maximize", "window-close"],
  receive: ["server-status", "port-changed", "update-status"],
};
```

బహిర్గత పద్ధతులు:

| రెండరర్ కాల్                                                      | టైప్ చేయండి                      |
| ----------------------------------------------------------------- | -------------------------------- |
| `getAppInfo()` → `{ name, version, platform, isDev, port }`       | ఆవాహన చేయండి                     |
| `openExternal(url)`                                               | ఆవాహన చేయండి                     |
| `getDataDir()`                                                    | ఆవాహన చేయండి                     |
| `restartServer()`                                                 | ఆవాహన చేయండి                     |
| `getAppVersion()`                                                 | ఆవాహన చేయండి                     |
| `checkForUpdates()` / `downloadUpdate()` / `installUpdate()`      | ఆవాహన చేయండి                     |
| `minimizeWindow()` / `maximizeWindow()` / `closeWindow()`         | పంపండి                           |
| `onServerStatus(cb)` / `onPortChanged(cb)` / `onUpdateStatus(cb)` | స్వీకరించు (రిటర్న్స్ డిస్పోజర్) |

స్వీకరించే సహాయకులు తిరిగి ఎ** డిస్పోజర్ ఫంక్షన్** `removeAllListeners` — పై ఆధారపడకుండా ఇది React కాంపోనెంట్లను రీమౌంట్ చేసినప్పుడు శ్రోతల సంచితాన్ని నిరోధిస్తుంది.

## సర్వర్ జీవితచక్రం

సిస్టమ్ నోడ్తో స్థానిక-మాడ్యూల్ ABI అసమతుల్యతను నివారించడానికి`main.js` నేరుగా Electron నోడ్ రన్టైమ్తో Next.js స్వతంత్ర బండిల్ను ఉత్పత్తి చేస్తుంది:

```js
spawn(process.execPath, [serverScript], {
  cwd: NEXT_SERVER_PATH,
  env: { ...serverEnv, PORT, NODE_ENV: "production", ELECTRON_RUN_AS_NODE: "1", NODE_PATH },
  stdio: "pipe",
});
```

ముఖ్యాంశాలు:

- `waitForServer()` విండోను చూపించే ముందు 30 సెకన్ల వరకు URL పోల్ చేస్తుంది (కోల్డ్ స్టార్ట్లో ఖాళీ స్క్రీన్ లేదు).
- `stdio: "pipe"` stdout/stderr ని సంగ్రహిస్తుంది; సిద్ధంగా ఉన్న పదబంధాలు (`Ready` / `listening`) IPC పై `server-status: running` విడుదల చేస్తాయి.
- `before-quit` ఆకర్షణీయమైన SIGTERM (WAL చెక్పాయింట్) కోసం 5 సెకన్ల వరకు వేచి ఉండి, ఆపై SIGKILL పంపుతుంది.
- ట్రేలోని పోర్ట్ స్విచ్చర్ (`20128`, `3000`, `8080`) ఆపి సర్వర్ని పునఃప్రారంభించి, ఆపై BrowserWindow ని మళ్లీ లోడ్ చేస్తుంది.

## జీరో-కాన్ఫిగర్ సీక్రెట్ బూట్స్ట్రాప్

మొదటి ప్రయోగ సమయంలో, ప్రధాన ప్రక్రియ తప్పిపోయిన రహస్యాలను స్వయంచాలకంగా ఉత్పత్తి చేస్తుంది మరియు కొనసాగుతుంది:

| రహస్యం                   | మూలం                                                                                                     |
| ------------------------ | -------------------------------------------------------------------------------------------------------- |
| `JWT_SECRET`             | `crypto.randomBytes(64).toString("hex")`                                                                 |
| `STORAGE_ENCRYPTION_KEY` | `crypto.randomBytes(32).toString("hex")` (ఎన్క్రిప్టెడ్ క్రెడిట్లు ఇప్పటికే ఉన్నట్లయితే తిరస్కరిస్తుంది) |
| `API_KEY_SECRET`         | `crypto.randomBytes(32).toString("hex")`                                                                 |

`<DATA_DIR>/server.env` వరకు పట్టుబట్టారు. `DATA_DIR` పరిష్కరిస్తుంది:

- Windows: `%APPDATA%\omniroute`
- Linux: `$XDG_CONFIG_HOME/omniroute` లేదా `~/.omniroute`
- macOS: `~/.omniroute`

## పర్యావరణ ఫైల్ శోధన

సర్వర్ను పుట్టించే ముందు, ప్రధాన ప్రక్రియ ( `electron/main.js` లో`getPreferredEnvFilePath()` ) ఎంపిక చేయబడుతుంది** ఒకటి** `.env` ఫైల్: ఉనికిలో ఉన్న వాటిలో మొదటిది.

1. `$DATA_DIR/.env`, వాతావరణంలో `DATA_DIR` సెట్ చేయబడినప్పుడు అనువర్తనం ప్రారంభించబడింది.
2. `<resolved DATA_DIR>/.env`, పైన పేర్కొన్న అదే డిఫాల్ట్లను ఉపయోగిస్తుంది: `%APPDATA%\omniroute\.env` పై Windows, `$XDG_CONFIG_HOME/omniroute/.env` లేదా `~/.omniroute/.env` Linux మరియు macOS.
3. ప్రక్రియ వర్కింగ్ డైరెక్టరీలో`.env`.

ప్రధాన ప్రక్రియ ఆ ఫైల్ను మాత్రమే చదువుతుంది; తర్వాత అభ్యర్థులు విలీనం చేయబడలేదు. సర్వర్ పర్యావరణం ఈ ప్రాధాన్యతతో నిర్మించబడింది (అత్యధిక మొదటిది):

1. Electron ప్రాసెస్ ఎన్విరాన్మెంట్ (యాప్ని ప్రారంభించిన దాని నుండి వేరియబుల్స్ వారసత్వంగా పొందబడతాయి).
2. ఎంచుకున్న `.env` ఫైల్.
3. `<DATA_DIR>/server.env` (పైన ఉన్న బూట్స్ట్రాప్ రహస్యాలు).

యాప్ ప్రారంభమైనప్పుడు ప్రాసెస్ ఎన్విరాన్మెంట్ క్యాప్చర్ చేయబడుతుంది, కాబట్టి యాప్ రన్ అవుతున్నప్పుడు సిస్టమ్ లేదా యూజర్ ఎన్విరాన్మెంట్ వేరియబుల్ సెట్ చేయబడింది (విండో మూసివేయబడిన తర్వాత ట్రేలో కూర్చుని ఉండటంతో సహా) యాప్ పూర్తిగా నిష్క్రమించి, మళ్లీ ప్రారంభించబడే వరకు సర్వర్ని చేరుకోదు. `CONTEXT_LENGTH_<PROVIDER>` వంటి రన్టైమ్ నాబ్ల కోసం ( [ఎన్విరాన్మెంట్ వేరియబుల్స్: పర్-ప్రొవైడర్ కాంటెక్స్ట్ లెంగ్త్](../reference/ENVIRONMENT.md#per-provider-context-length-context_length_provider) చూడండి), `.env` ఫైల్ను ఇష్టపడండి, ఆపై పూర్తిగా నిష్క్రమించండి (ట్రే,** నిష్క్రమించు** ) మరియు పునఃప్రారంభించండి.

## స్వీయ-నవీకరణ

GitHub ప్రొవైడర్ (`diegosouzapw/OmniRoute`)తో `electron-updater` ఉపయోగిస్తుంది.

- `autoDownload = false`, `autoInstallOnAppQuit = true`
- ఈవెంట్లు `update-status` IPC ద్వారా రెండరర్కు ఫార్వార్డ్ చేయబడ్డాయి: `checking`, `available`, `not-available`, `downloading` ( `percent` తో), `downloaded`, `error`
- `installUpdate()` సర్వర్ను చంపి, ఆపై `autoUpdater.quitAndInstall()` పిలుస్తుంది
- దేవ్ మోడ్లో దాటవేయబడింది (`!app.isPackaged`)

## పైప్లైన్ను నిర్మించండి

1. `.next/standalone` లో`npm run build` → Next.js స్వతంత్రంగా ఉంది.
2. `prepare-electron-standalone.mjs` → `.next/electron-standalone` లోకి మళ్లీ దశలు మరియు `server.js` + `required-server-files.json` లోపల సంపూర్ణ మార్గాలను తిరిగి వ్రాస్తుంది కాబట్టి బండిల్ రీలొకేటబుల్ అవుతుంది.
3. `electron-builder` ప్యాకేజీలు `main.js`, `preload.js`, `node_modules` మరియు `extraResources: { ../.next/electron-standalone → app }`.

### లక్ష్యాలను నిర్మించండి

| OS      | లక్ష్యాలు                                    |
| ------- | -------------------------------------------- |
| Windows | NSIS ఇన్స్టాలర్ + పోర్టబుల్ (x64)            |
| macOS   | DMG (ఇంటెల్ + arm64, డ్రాగ్-టు-అప్లికేషన్స్) |
| Linux   | AppImage + DEB (x64 + arm64)                 |

NSIS సెట్టింగ్లు: `oneClick: false`, ఇన్స్టాల్ డైరెక్టరీని ఎంచుకోవడానికి వినియోగదారుని అనుమతిస్తుంది, డెస్క్టాప్ మరియు స్టార్ట్-మెనూ షార్ట్కట్లను సృష్టిస్తుంది.

## స్మోక్ టెస్టింగ్ ప్యాకేజ్డ్ బిల్డ్

```bash
npm run electron:smoke:packaged
```

`scripts/dev/smoke-electron-packaged.mjs`:

- ప్రస్తుత ప్లాట్ఫారమ్ కోసం `electron/dist-electron/` లో ప్యాక్ చేయబడిన బైనరీని స్వయంచాలకంగా కనుగొంటుంది.
- వివిక్త `HOME`/`APPDATA`/`XDG_*` డైరెక్టరీలతో లాంచ్ అవుతుంది కాబట్టి ఇది డెవలపర్ డేటాను తాకదు.
- 45 సెకన్లలోపు HTTP 200 కోసం పోల్స్ `http://127.0.0.1:20128/login`.
- ప్రాణాంతక నమూనాల కోసం stderr/stdout గడియారాలు (`Cannot find module`, `MODULE_NOT_FOUND`, `ERR_DLOPEN_FAILED`, `Failed to start server`, మొదలైనవి).
- సంసిద్ధత తర్వాత స్థిరమైన రన్టైమ్లో 2 సెకన్లు వేచి ఉండి, ఆపై SIGTERM జారీ చేసి, పోర్ట్ ఖాళీ అయ్యే వరకు వేచి ఉంటుంది.
- CI లో, స్వయంచాలకంగా `--no-sandbox --disable-gpu` (మరియు Linux లో `--disable-dev-shm-usage` ) దాటిపోతుంది.

ఎన్వి ఓవర్రైడ్లు: `ELECTRON_SMOKE_APP_EXECUTABLE`, `ELECTRON_SMOKE_URL`, `ELECTRON_SMOKE_TIMEOUT_MS`, `ELECTRON_SMOKE_SETTLE_MS`, `ELECTRON_SMOKE_DATA_DIR`, `ELECTRON_SMOKE_KEEP_DATA`, `ELECTRON_SMOKE_STREAM_LOGS`.

## కోడ్ సంతకం

`electron/package.json` చేస్తుంది** కాదు** నేరుగా ఆధారాలపై సంతకం చేయడం. వాటిని env vars ద్వారా `electron-builder` కి పంపండి:

### macOS

```bash
export APPLE_ID=<email>
export APPLE_APP_SPECIFIC_PASSWORD=<password>
export APPLE_TEAM_ID=<id>
export CSC_LINK=path/to/cert.p12
export CSC_KEY_PASSWORD=<cert-password>
npm run electron:build:mac
```

### Windows

```bash
export CSC_LINK=path/to/cert.pfx
export CSC_KEY_PASSWORD=<cert-password>
npm run electron:build:win
```

### Linux

సంతకం చేస్తేAppImage సంతకం ఐచ్ఛికం — సెట్ `LINUX_GPG_KEY`.
