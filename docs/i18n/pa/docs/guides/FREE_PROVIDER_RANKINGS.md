> (LMArena-ਸ਼ੈਲੀ) ELO ਸਕੋਰਾਂ** ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਰੈਂਕ ਕਰਦਾ ਹੈ। ਇਹ ਦੇਖਣ ਲਈ ਕਿ ਕਿਹੜੇ ਮੁਫ਼ਤ ਪ੍ਰਦਾਤਾ ਤੁਹਾਡੇ ਕੰਮ ਲਈ ਸਭ ਤੋਂ ਮਜ਼ਬੂਤ ਮਾਡਲ ਪ੍ਰਦਾਨ ਕਰਦੇ ਹਨ —
> ਸਮੁੱਚੇ ਤੌਰ 'ਤੇ, ਜਾਂ ਸ਼੍ਰੇਣੀ (ਕੋਡਿੰਗ, ਸਮੀਖਿਆ, ਦਸਤਾਵੇਜ਼ੀਕਰਨ, ਡੀਬੱਗਿੰਗ) ਅਨੁਸਾਰ ਫਿਲਟਰ ਕਰਕੇ — ਡੈਸ਼ਬੋਰਡ ਵਿੱਚ **ਮੁਫ਼ਤ ਪ੍ਰਦਾਤਾ ਰੈਂਕਿੰਗਾਂ** ਪੰਨਾ ਖੋਲ੍ਹੋ।

## ਇਹ ਕੀ ਹੈ

OmniRoute ਨੇ 377 ਪ੍ਰਦਾਤਾਵਾਂ ਨੂੰ ਰਜਿਸਟਰ ਕੀਤਾ, ਜਿਸ ਵਿੱਚ 155 ਕੈਟਾਲਾਗ ਐਂਟਰੀਆਂ ਸ਼ਾਮਲ ਹਨ**free/no-auth** (no-auth, free-tier OAuth, ਜਾਂ free-tier API ਕੁੰਜੀ — [ਫ੍ਰੀ ਟਾਇਰ ਗਾਈਡ](../getting-started/FREE-TIERS-GUIDE.md) ਅਤੇ ਪੂਰੀ [ਫ੍ਰੀ ਟਾਇਰ ਡਾਇਰੈਕਟਰੀ](../reference/FREE_TIERS.md) ਦੇਖੋ)। ਕੈਚ: ਮੁਫਤ ਪ੍ਰਦਾਤਾ ਮਾਡਲ ਦੀ ਗੁਣਵੱਤਾ ਵਿੱਚ ਬਹੁਤ ਵੱਖਰੇ ਹੁੰਦੇ ਹਨ। ਇੱਕ ਫਰੰਟੀਅਰ ਮਾਡਲ ਦੀ ਸੇਵਾ ਕਰਨ ਵਾਲਾ ਇੱਕ ਗੈਰ-ਪ੍ਰਮਾਣਿਕ ਪ੍ਰਦਾਤਾ ਇੱਕ ਛੋਟੇ ਪੁਰਾਤਨ ਮਾਡਲ ਦੀ ਸੇਵਾ ਕਰਨ ਨਾਲੋਂ ਕਿਤੇ ਜ਼ਿਆਦਾ ਉਪਯੋਗੀ ਹੈ।

**ਮੁਫ਼ਤ ਪ੍ਰਦਾਤਾ ਦਰਜਾਬੰਦੀ** ਜਵਾਬ"** ਕਿਹੜਾ ਮੁਫ਼ਤ ਪ੍ਰਦਾਤਾ ਮੈਨੂੰ ਸਭ ਤੋਂ ਵਧੀਆ ਮਾਡਲ ਦਿੰਦਾ ਹੈ?** ਹਰ ਇੱਕ ਮੁਫਤ ਪ੍ਰਦਾਤਾ ਦੇ ਕੈਟਾਲਾਗ ਵਿੱਚ ਸ਼ਾਮਲ ਹੋ ਕੇ** ਭੀੜ-ਸਰੋਤ ਗੁਣਵੱਤਾ ਸਕੋਰ** ਤੋਂ** ਅਰੇਨਾ AI ਲੀਡਰਬੋਰਡ** (ਮਨੁੱਖੀ-ਤਰਜੀਹੀ ELO, LMArena ਚੈਟਬੋਟ ਅਖਾੜੇ ਦੇ ਪਿੱਛੇ ਉਹੀ ਵਿਚਾਰ)। ਫਿਰ ਪ੍ਰਦਾਤਾਵਾਂ ਨੂੰ ਉਹਨਾਂ ਦੀ ਤਾਕਤ ਦੁਆਰਾ ਦਰਜਾ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ** ਵਧੀਆ ਮੁਫ਼ਤ ਮਾਡਲ** .

ਦਰਜਾਬੰਦੀ ਦੀ ਗਣਨਾ ਤਿੰਨ ਅਸਲ ਸਰੋਤਾਂ ਤੋਂ ਕੀਤੀ ਜਾਂਦੀ ਹੈ:

1. ਮੁਫਤ-ਪ੍ਰਦਾਤਾ ਸੂਚੀਆਂ — `NOAUTH_PROVIDERS`, ਪਲੱਸ `OAUTH_PROVIDERS` / `APIKEY_PROVIDERS` ਐਂਟਰੀਆਂ ਫਲੈਗ ਕੀਤੀਆਂ `hasFree` (`src/shared/constants/providers.ts`)।
2. ਪ੍ਰਦਾਤਾ ਰਜਿਸਟਰੀ (`open-sse/config/providerRegistry.ts`) ਤੋਂ ਹਰੇਕ ਪ੍ਰਦਾਤਾ ਦਾ ਮਾਡਲ ਕੈਟਾਲਾਗ।
3. ਏਰੀਨਾ ELO ਸਿੰਕ ਇੰਜਣ (`src/lib/arenaEloSync.ts`) ਦੁਆਰਾ `model_intelligence` DB ਟੇਬਲ ਵਿੱਚ ਸਟੋਰ ਕੀਤੇ ELO-ਪ੍ਰਾਪਤ ਟਾਸਕ-ਫਿੱਟ ਸਕੋਰ।

ਜੁਆਇਨ ਤਰਕ `src/lib/freeProviderRankings.ts` ਵਿੱਚ ਰਹਿੰਦਾ ਹੈ।

### ਡੈਸ਼ਬੋਰਡ ਪੰਨਾ

ਡੈਸ਼ਬੋਰਡ ਖੋਲ੍ਹੋ ਅਤੇ **ਲਾਗਤਾਂ → ਮੁਫ਼ਤ ਪ੍ਰਦਾਤਾ ਰੈਂਕਿੰਗਾਂ** 'ਤੇ ਜਾਓ, ਜਾਂ ਸਿੱਧਾ ਇੱਥੇ ਜਾਓ:

```
/dashboard/free-provider-rankings
```

ਇਹ ਪੰਨਾ (`src/app/(dashboard)/dashboard/free-provider-rankings/page.tsx`) ਹੇਠਾਂ ਦਿੱਤੀਆਂ ਚੀਜ਼ਾਂ ਦਿਖਾਉਂਦਾ ਹੈ:

- ਸਭ ਤੋਂ ਉੱਚੀ ਰੈਂਕਿੰਗ ਵਾਲੇ ਮੁਫ਼ਤ ਪ੍ਰਦਾਤਾਵਾਂ ਦਾ **ਸਿਖਰਲੇ-3 ਦਾ ਮੰਚ** (🥇 🥈 🥉)।
- ਇਨ੍ਹਾਂ ਕਾਲਮਾਂ ਵਾਲੀ ਪੂਰੀ **ਰੈਂਕਿੰਗ ਸਾਰਣੀ**: **ਰੈਂਕ**, **ਪ੍ਰਦਾਤਾ**, **ਸਿਖਰਲਾ ਮਾਡਲ**,
  **ਸਕੋਰ**, **ਔਸਤ ਸਕੋਰ**, **ਮਾਡਲ**, **ਕਿਸਮ**।
- **ਸ਼੍ਰੇਣੀ ਫਿਲਟਰ ਬਟਨ**: _ਸਾਰੀਆਂ ਸ਼੍ਰੇਣੀਆਂ_, _ਮੂਲ_, _ਕੋਡਿੰਗ_, _ਸਮੀਖਿਆ_,
  _ਦਸਤਾਵੇਜ਼ੀਕਰਨ_, _ਡੀਬੱਗਿੰਗ_।

ਹਰ ਪ੍ਰਦਾਤਾ ਦਾ **ਕਿਸਮ** ਬੈਜ ਦੱਸਦਾ ਹੈ ਕਿ ਉਹ ਕਿਵੇਂ ਮੁਫ਼ਤ ਹੈ:

| ਬੈਜ      | ਅਰਥ                                           |
| -------- | --------------------------------------------- |
| `NOAUTH` | ਹਮੇਸ਼ਾ ਮੁਫ਼ਤ, ਕਿਸੇ ਪ੍ਰਮਾਣ-ਪੱਤਰ ਦੀ ਲੋੜ ਨਹੀਂ    |
| `OAUTH`  | ਮੁਫ਼ਤ ਟੀਅਰ (`hasFree`) ਵਾਲਾ OAuth ਪ੍ਰਦਾਤਾ     |
| `APIKEY` | ਮੁਫ਼ਤ ਟੀਅਰ (`hasFree`) ਵਾਲਾ API-ਕੁੰਜੀ ਪ੍ਰਦਾਤਾ |

ਸਕੋਰ ਕੱਚੇ ਅੰਕਾਂ ਦੀ ਬਜਾਏ ਮਨੁੱਖਾਂ ਲਈ ਪੜ੍ਹਨਯੋਗ ਲੇਬਲਾਂ (ਉਦਾਹਰਨ ਲਈ _ਸਰਵੋਤਮ_, _ਸ਼ਾਨਦਾਰ_, _ਬਹੁਤ ਵਧੀਆ_,
_ਵਧੀਆ_, _ਔਸਤ_) ਦੇ ਰੂਪ ਵਿੱਚ ਦਿਖਾਏ ਜਾਂਦੇ ਹਨ, ਕਿਉਂਕਿ ਅਧਾਰਭੂਤ ਮੁੱਲ ਇੱਕ ਸਾਪੇਖ
ਰੈਂਕਿੰਗ ਗੁਣਵੱਤਾ ਹੈ, ਪ੍ਰਤੀਸ਼ਤ ਨਹੀਂ।

### API ਐਂਡਪੌਇੰਟ

ਇਹ ਪੰਨਾ ਇੱਕ ਜਨਤਕ ਰੀਡ ਐਂਡਪੌਇੰਟ
(`src/app/api/free-provider-rankings/route.ts`) ਦੁਆਰਾ ਸਮਰਥਿਤ ਹੈ:

```
GET /api/free-provider-rankings
GET /api/free-provider-rankings?category=coding
GET /api/free-provider-rankings?category=coding&limit=20
```

ਕੁਐਰੀ ਪੈਰਾਮੀਟਰ (Zod ਨਾਲ ਪ੍ਰਮਾਣਿਤ):

| ਪੈਰਾਮੀਟਰ   | ਕਿਸਮ   | ਮੂਲ ਮੁੱਲ   | ਨੋਟਸ                                                                                                     |
| ---------- | ------ | ---------- | -------------------------------------------------------------------------------------------------------- |
| `category` | string | (ਕੋਈ ਨਹੀਂ) | `default`, `coding`, `review`, `documentation`, `debugging` ਵਿੱਚੋਂ ਇੱਕ। ਸੰਯੁਕਤ ਰੈਂਕਿੰਗ ਲਈ ਇਸਨੂੰ ਛੱਡ ਦਿਓ। |
| `limit`    | number | `50`       | `1–100` ਦੀ ਰੇਂਜ ਤੱਕ ਸੀਮਿਤ ਕੀਤਾ ਜਾਂਦਾ ਹੈ।                                                                 |

ਜਵਾਬ ਦੀ ਬਣਤਰ:

```json
{
  "rankings": [
    {
      "id": "<provider-id>",
      "name": "<provider name>",
      "icon": "<icon>",
      "color": "<hex color>",
      "textIcon": "<short label>",
      "category": "noauth | oauth | apikey",
      "topModel": {
        "modelId": "<registry model id>",
        "modelName": "<model display name>",
        "score": 0.0,
        "eloRaw": 0,
        "confidence": "high | medium | low",
        "category": "<task category>"
      },
      "averageScore": 0.0,
      "modelCount": 0
    }
  ]
}
```

`eloRaw` ਮੂਲ Arena ELO ਮੁੱਲ ਹੈ; `score` ਸਧਾਰਨਕ੍ਰਿਤ ਕਾਰਜ-ਅਨੁਕੂਲਤਾ ਮੁੱਲ ਹੈ
(ਹੇਠਾਂ ਵੇਖੋ)। ਜਿਨ੍ਹਾਂ ਪ੍ਰਦਾਤਾਵਾਂ ਕੋਲ ਕੋਈ ਸਕੋਰ ਕੀਤਾ ਮਾਡਲ ਨਹੀਂ ਹੈ, ਉਨ੍ਹਾਂ ਨੂੰ ਜਵਾਬ ਵਿੱਚੋਂ ਹਟਾ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ।

## ਸਕੋਰ ਕਿਵੇਂ ਕੰਮ ਕਰਦੇ ਹਨ

### ਸਰੋਤ: Arena AI ਲੀਡਰਬੋਰਡ

Arena ELO ਸਿੰਕ ਇੰਜਣ (`src/lib/arenaEloSync.ts`) Arena AI ਲੀਡਰਬੋਰਡ API
(`https://api.wulong.dev/arena-ai-leaderboards/v1/leaderboard`) ਤੋਂ ਦੋ ਲੀਡਰਬੋਰਡ — `text`
ਅਤੇ `code` — ਲੈ ਆਉਂਦਾ ਹੈ। ਜਦੋਂ ਉਹ API ਕੋਈ ਵਰਤੋਂਯੋਗ ਬੋਰਡ ਨਹੀਂ ਦਿੰਦਾ, ਤਾਂ ਇੰਜਣ Hugging Face
datasets-server ਉੱਤੇ ਅਧਿਕਾਰਕ `lmarena-ai/leaderboard-dataset` ਵੱਲ ਮੁੜ ਜਾਂਦਾ ਹੈ
(`src/lib/arenaEloHfSource.ts`, CC-BY-4.0; `overall` → `text`,
`coding` → `code`); `GET /api/intelligence/sync` `activeSource`, `lastError` ਅਤੇ
`lastFailedAt` ਰਿਪੋਰਟ ਕਰਦਾ ਹੈ। ਹਰ ਲੀਡਰਬੋਰਡ ਐਂਟਰੀ ਵਿੱਚ
ਮਾਡਲ ਦਾ ਨਾਮ, ਵੈਂਡਰ, ELO `score`, ਕਾਨਫੀਡੈਂਸ ਇੰਟਰਵਲ ਅਤੇ ਵੋਟ ਗਿਣਤੀ ਹੁੰਦੀ ਹੈ।

ਲੀਡਰਬੋਰਡ ਸ਼੍ਰੇਣੀਆਂ OmniRoute ਟਾਸਕ ਸ਼੍ਰੇਣੀਆਂ ਨਾਲ ਇਸ ਤਰ੍ਹਾਂ ਮੈਪ ਹੁੰਦੀਆਂ ਹਨ:

| Arena ਲੀਡਰਬੋਰਡ | OmniRoute ਟਾਸਕ ਸ਼੍ਰੇਣੀਆਂ                          |
| -------------- | ------------------------------------------------- |
| `text`         | `default`, `review`, `documentation`, `debugging` |
| `code`         | `coding`                                          |

### ਨਾਰਮਲਾਈਜ਼ੇਸ਼ਨ (ਟਾਸਕ-ਫਿੱਟ ਸਕੋਰ)

ਰੌ ELO ਸਕੋਰ ਹਰ ਲੀਡਰਬੋਰਡ ਦੇ ਅੰਦਰ **`[0.4, 0.98]` ਵਿੱਚ ਇੱਕ ਟਾਸਕ-ਫਿੱਟ ਮੁੱਲ** ਵਿੱਚ ਨਾਰਮਲਾਈਜ਼ ਕੀਤੇ ਜਾਂਦੇ ਹਨ:

```
taskFit = 0.4 + 0.58 * ((elo - minElo) / (maxElo - minElo))
```

ਸਕੋਰ ਕਦੇ ਵੀ `0` ਜਾਂ `1` ਤੱਕ ਨਹੀਂ ਪਹੁੰਚਦਾ, ਜਿਸ ਨਾਲ ਯੂਜ਼ਰ ਓਵਰਰਾਈਡਸ ਲਈ ਥਾਂ ਰਹਿੰਦੀ ਹੈ। ਇਹੀ ਉਹ
`score` ਫ਼ੀਲਡ ਹੈ ਜੋ ਤੁਸੀਂ API ਰਿਸਪਾਂਸ ਵਿੱਚ ਦੇਖਦੇ ਹੋ ਅਤੇ ਡੈਸ਼ਬੋਰਡ ਉੱਤੇ ਦਿਖਾਇਆ ਜਾਂਦਾ ਲੇਬਲ ਹੈ।

### ਕਾਨਫੀਡੈਂਸ

ਹਰ ਐਂਟਰੀ ਨੂੰ Arena ਵੋਟ ਗਿਣਤੀ ਦੇ ਆਧਾਰ ਉੱਤੇ ਇੱਕ ਕਾਨਫੀਡੈਂਸ ਲੈਵਲ ਮਿਲਦਾ ਹੈ:

| ਕਾਨਫੀਡੈਂਸ | ਵੋਟਾਂ   |
| --------- | ------- |
| `high`    | ≥ 5,000 |
| `medium`  | ≥ 1,000 |
| `low`     | < 1,000 |

### ਸਟੋਰੇਜ ਅਤੇ ਤਾਜ਼ਗੀ

ਨਾਰਮਲਾਈਜ਼ ਕੀਤੀਆਂ ਐਂਟਰੀਆਂ `source = "arena_elo"` ਦੇ ਨਾਲ `model_intelligence` DB ਟੇਬਲ ਵਿੱਚ ਲਿਖੀਆਂ ਜਾਂਦੀਆਂ ਹਨ
(`src/lib/db/modelIntelligence.ts`)। ਐਂਟਰੀਆਂ **7 ਦਿਨ ਬਾਅਦ ਖਤਮ ਹੋ ਜਾਂਦੀਆਂ ਹਨ**, ਇਸ ਲਈ ਕੋਈ ਪ੍ਰੋਵਾਈਡਰ ਜੋ ਸਿੰਕ ਕਰਨਾ ਬੰਦ ਕਰ ਦਿੰਦਾ ਹੈ
ਅਖੀਰ ਵਿੱਚ ਪੁਰਾਣਾ ਡਾਟਾ ਦੇਣ ਦੀ ਬਜਾਏ ਸੂਚੀ ਤੋਂ ਹਟ ਜਾਂਦਾ ਹੈ।

ਸਿੰਕ **ਡਿਫਾਲਟ ਤੌਰ ਉੱਤੇ ਚਾਲੂ** ਹੁੰਦਾ ਹੈ:

- ਇਹ ਸਰਵਰ ਸ਼ੁਰੂ ਹੋਣ ਸਮੇਂ ਇੱਕ ਵਾਰ ਚੱਲਦਾ ਹੈ ਅਤੇ ਫਿਰ ਇੱਕ ਪੀਰੀਅਡਿਕ ਟਾਈਮਰ ਉੱਤੇ
  (`src/lib/arenaEloSync.ts`, `src/instrumentation-node.ts` ਤੋਂ ਜੋੜਿਆ ਗਿਆ)।
- ਇਹ **ਨਾਨ-ਬਲਾਕਿੰਗ ਹੈ ਅਤੇ ਕਦੇ ਵੀ ਘਾਤਕ ਨਹੀਂ** — ਜੇ ਅੱਪਸਟਰੀਮ ਫੈਚ ਅਸਫਲ ਹੋ ਜਾਵੇ, ਤਾਂ OmniRoute
  ਚੱਲਦਾ ਰਹਿੰਦਾ ਹੈ ਅਤੇ ਰੈਂਕਿੰਗ ਆਖਰੀ ਸਹੀ ਡਾਟਾ (ਜਾਂ ਖਾਲੀ ਸਥਿਤੀ) ਦਿਖਾਉਂਦੀਆਂ ਹਨ।

ਦੋ ਐਨਵਾਇਰਨਮੈਂਟ ਵੇਰੀਏਬਲ ਇਸਨੂੰ ਕੰਟਰੋਲ ਕਰਦੇ ਹਨ (ਦਸਤਾਵੇਜ਼
[`docs/reference/ENVIRONMENT.md`](../reference/ENVIRONMENT.md) ਵਿੱਚ):

| ਵੇਰੀਏਬਲ                   | ਡਿਫਾਲਟ        | ਉਦੇਸ਼                                           |
| ------------------------- | ------------- | ----------------------------------------------- |
| `ARENA_ELO_SYNC_ENABLED`  | `true`        | ਆਊਟਬਾਊਂਡ ਸਿੰਕ ਤੋਂ ਬਾਹਰ ਹੋਣ ਲਈ `false` ਸੈੱਟ ਕਰੋ। |
| `ARENA_ELO_SYNC_INTERVAL` | `86400` (24h) | ਸਿੰਕ ਇੰਟਰਵਲ, ਸਕਿੰਟਾਂ ਵਿੱਚ।                      |

### ਮੈਨੂਅਲ ਸਿੰਕ / ਸਥਿਤੀ / ਸਾਫ਼ ਕਰਨਾ

ਓਪਰੇਟਰਾਂ ਲਈ, ਇੱਕ ਪ੍ਰਮਾਣਿਤ ਮੈਨੇਜਮੈਂਟ ਐਂਡਪੁਆਇੰਟ ਮੈਨੂਅਲ ਕੰਟਰੋਲ ਦਿੰਦਾ ਹੈ
(`src/app/api/intelligence/sync/route.ts` — ਮੈਨੇਜਮੈਂਟ ਪ੍ਰਮਾਣੀਕਰਨ ਲੋੜੀਂਦਾ ਹੈ):

```
GET    /api/intelligence/sync          # ਮੌਜੂਦਾ ਸਿੰਕ ਸਥਿਤੀ (enabled, lastSync, nextSync, intervalMs)
POST   /api/intelligence/sync          # ਮੈਨੂਅਲ ਸਿੰਕ ਚਲਾਓ; ਬਿਨਾਂ ਲਿਖੇ ਝਲਕ ਲਈ body: { "dryRun": true }
DELETE /api/intelligence/sync          # ਸਾਰੀਆਂ ਸਿੰਕ ਕੀਤੀਆਂ arena_elo ਇੰਟੈਲੀਜੈਂਸ ਐਂਟਰੀਆਂ ਸਾਫ਼ ਕਰੋ
```

ਜੇ ਰੈਂਕਿੰਗ ਪੰਨਾ ਖਾਲੀ ਹੈ, ਤਾਂ ਮੈਨੂਅਲ `POST /api/intelligence/sync` (ਜਾਂ ਸਰਵਰ ਨੂੰ ਸਿਰਫ਼
ਮੁੜ-ਚਾਲੂ ਕਰਨਾ) ਇਸਨੂੰ ਦੁਬਾਰਾ ਭਰ ਦਿੰਦਾ ਹੈ।

### ਮਾਡਲਾਂ ਨੂੰ ਲੀਡਰਬੋਰਡ ਨਾਲ ਮੇਲ ਕਰਵਾਉਣਾ

ਰਜਿਸਟਰੀ ਮਾਡਲ IDs ਅਤੇ Arena ਮਾਡਲ ਨਾਮ ਹਮੇਸ਼ਾ ਬਿਲਕੁਲ ਮੇਲ ਨਹੀਂ ਖਾਂਦੇ। ਰੈਂਕਿੰਗ ਲਚਕਦਾਰ ਮੈਚਿੰਗ ਵਰਤਦਾ ਹੈ
(`findMatchingIntelligence` `src/lib/freeProviderRankings.ts` ਵਿੱਚ):

1. ਨਾਰਮਲਾਈਜ਼ ਕੀਤੀ ਮਾਡਲ ID ਉੱਤੇ ਸਟੀਕ ਮੈਚ।
2. ਅਖੀਰਲਾ ਵਰਜ਼ਨ ਸਫ਼ਿਕਸ ਹਟਾਉਣ ਤੋਂ ਬਾਅਦ ਮੈਚ (ਉਦਾਹਰਨ: `kimi-k2.6` → `kimi-k2`)।
3. ਪ੍ਰੀਫ਼ਿਕਸ ਮੈਚ (ਲੀਡਰਬੋਰਡ ਮਾਡਲ ਨਾਮ ਰਜਿਸਟਰੀ ID ਦਾ ਪ੍ਰੀਫ਼ਿਕਸ ਹੈ)।

ਸਿੰਕ ਸਾਈਡ ਉੱਤੇ, ਜਾਣੇ-ਪਛਾਣੇ ਵੈਂਡਰ ਪ੍ਰੀਫ਼ਿਕਸ (`anthropic/`, `openai/`, `google/`, …) ਹਟਾਏ ਜਾਂਦੇ ਹਨ
ਅਤੇ ਇੱਕ ਛੋਟਾ ਐਲੀਅਸ ਮੈਪ ਕੈਨੋਨੀਕਲ ਨਾਵਾਂ ਨੂੰ ਉਹਨਾਂ ਰੂਪਾਂ ਵਿੱਚ ਫੈਲਾਉਂਦਾ ਹੈ ਜੋ OmniRoute
ਅੰਦਰੂਨੀ ਤੌਰ ਉੱਤੇ ਵਰਤਦਾ ਹੈ, ਤਾਂ ਜੋ ਮਾਡਲ ਕਿਸੇ ਵੀ ਨਾਮ ਹੇਠ ਲੱਭੇ ਜਾ ਸਕਣ।

### ਪ੍ਰੋਵਾਈਡਰ ਦੀ ਰੈਂਕਿੰਗ ਕਿਵੇਂ ਹੁੰਦੀ ਹੈ

ਹਰ ਮੁਫ਼ਤ ਪ੍ਰੋਵਾਈਡਰ ਲਈ, ਇੰਜਣ ਉਸਦੇ ਕੈਟਾਲਾਗ ਦੇ ਹਰ ਮਾਡਲ ਨੂੰ ਸਕੋਰ ਕਰਦਾ ਹੈ, ਫਿਰ:

- **Top Model** = ਪ੍ਰੋਵਾਈਡਰ ਦਾ ਸਭ ਤੋਂ ਉੱਚ-ਸਕੋਰ ਵਾਲਾ ਮਾਡਲ।
- **Avg Score** = ਉਸ ਪ੍ਰੋਵਾਈਡਰ ਦੇ ਸਾਰੇ ਸਕੋਰ ਕੀਤੇ ਮਾਡਲਾਂ ਦਾ ਔਸਤ ਸਕੋਰ।
- **Models** = ਪ੍ਰੋਵਾਈਡਰ ਦੇ ਕਿੰਨੇ ਮਾਡਲਾਂ ਕੋਲ Arena ਸਕੋਰ ਸੀ।

ਪ੍ਰੋਵਾਈਡਰਾਂ ਨੂੰ ਪਹਿਲਾਂ **ਟਾਪ-ਮਾਡਲ ਸਕੋਰ** ਅਨੁਸਾਰ, ਫਿਰ ਔਸਤ ਸਕੋਰ ਅਨੁਸਾਰ ਕ੍ਰਮਬੱਧ ਕੀਤਾ ਜਾਂਦਾ ਹੈ। ਇਹ ਉਸ
ਪ੍ਰੋਵਾਈਡਰ ਨੂੰ ਇਨਾਮ ਦਿੰਦਾ ਹੈ ਜੋ ਘੱਟੋ-ਘੱਟ ਇੱਕ ਮਜ਼ਬੂਤ ਮੁਫ਼ਤ ਮਾਡਲ ਪੇਸ਼ ਕਰਦਾ ਹੈ।

## ਮੁਫ਼ਤ ਪ੍ਰਦਾਤਾ ਚੁਣਨ ਲਈ ਇਸਦੀ ਵਰਤੋਂ

1. **ਸਹੀ ਸ਼੍ਰੇਣੀ ਚੁਣੋ।** ਏਜੰਟਿਕ/ਕੋਡ ਵਰਕਲੋਡਾਂ ਲਈ **Coding** ਫਿਲਟਰ ਵਰਤੋ, ਜਾਂ
   ਆਮ ਚੈਟ ਲਈ ਇਸਨੂੰ **All Categories** / **Default** 'ਤੇ ਹੀ ਰਹਿਣ ਦਿਓ। ਇੱਕੋ ਪ੍ਰਦਾਤਾ
   ਵੱਖ-ਵੱਖ ਸ਼੍ਰੇਣੀਆਂ ਵਿੱਚ ਵੱਖਰੀ ਰੈਂਕਿੰਗ ਪ੍ਰਾਪਤ ਕਰ ਸਕਦਾ ਹੈ, ਕਿਉਂਕਿ ਹਰ ਲੀਡਰਬੋਰਡ ਅਨੁਸਾਰ ਇਸਦਾ ਸਿਖਰਲਾ ਮਾਡਲ ਵੱਖਰਾ ਹੁੰਦਾ ਹੈ।
2. **ਇੱਕ-ਵਾਰੀ ਸੈੱਟਅੱਪਾਂ ਲਈ ਪੋਡੀਅਮ ਨੂੰ ਤਰਜੀਹ ਦਿਓ।** ਜੇ ਤੁਸੀਂ ਸਿਰਫ਼ ਇੱਕ ਜਾਂ ਦੋ ਮੁਫ਼ਤ
   ਪ੍ਰਦਾਤਾਵਾਂ ਨੂੰ ਕਨੈਕਟ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ, ਤਾਂ ਆਪਣੀ ਸ਼੍ਰੇਣੀ ਲਈ ਸਭ ਤੋਂ ਉੱਚੀ ਰੈਂਕਿੰਗ ਵਾਲਿਆਂ ਤੋਂ ਸ਼ੁਰੂ ਕਰੋ।
3. **Type ਬੈਜ ਦੀ ਜਾਂਚ ਕਰੋ।** `NOAUTH` ਪ੍ਰਦਾਤਾ ਸਭ ਤੋਂ ਤੇਜ਼ੀ ਨਾਲ ਕਨੈਕਟ ਹੁੰਦੇ ਹਨ (ਕੋਈ
   ਕ੍ਰੈਡੈਂਸ਼ੀਅਲ ਨਹੀਂ)। `OAUTH` / `APIKEY` ਮੁਫ਼ਤ ਟੀਅਰਾਂ ਲਈ ਤੁਰੰਤ ਸਾਈਨ-ਅੱਪ ਦੀ ਲੋੜ ਹੁੰਦੀ ਹੈ, ਪਰ ਉਹ ਅਕਸਰ
   ਵਧੇਰੇ ਸਮਰੱਥ ਮਾਡਲ ਉਪਲਬਧ ਕਰਵਾਉਂਦੇ ਹਨ। ਕਨੈਕਸ਼ਨ ਦੇ ਕਦਮਾਂ ਲਈ [ਮੁਫ਼ਤ ਟੀਅਰ ਗਾਈਡ](../getting-started/FREE-TIERS-GUIDE.md) ਵੇਖੋ।
4. **ਕਈਆਂ ਨੂੰ ਕਨੈਕਟ ਕਰੋ ਅਤੇ Auto-Combo ਨੂੰ ਫ਼ੈਸਲਾ ਕਰਨ ਦਿਓ।** ਉਹੀ Arena ELO ਡਾਟਾ ਜੋ
   ਇਸ ਪੰਨੇ ਨੂੰ ਸੰਚਾਲਿਤ ਕਰਦਾ ਹੈ, Auto-Combo ਸਕੋਰਿੰਗ ਇੰਜਣ ਦੇ **ਟਾਸਕ-ਅਨੁਕੂਲਤਾ ਕਾਰਕ** ਨੂੰ ਵੀ ਡਾਟਾ ਦਿੰਦਾ ਹੈ
   (`open-sse/services/autoCombo/taskFitness.ts`, ਨਿਰਧਾਰਨ ਕ੍ਰਮ
   `user_override → arena_elo → models_dev_tier → static table`)। ਇਸ ਲਈ, ਸਿਖਰਲੇ ਮੁਫ਼ਤ ਪ੍ਰਦਾਤਾਵਾਂ ਨੂੰ ਕਨੈਕਟ ਕਰਨ ਤੋਂ ਬਾਅਦ,
   `model: "auto"` (ਉਦਾਹਰਨ ਲਈ `auto/coding`) ਨਾਲ ਰਾਊਟਿੰਗ ਹਰ ਬੇਨਤੀ ਲਈ
   ਉੱਚ-ਗੁਣਵੱਤਾ ਵਾਲੇ ਮੁਫ਼ਤ ਮਾਡਲਾਂ ਨੂੰ ਆਪਣੇ-ਆਪ ਤਰਜੀਹ ਦੇਵੇਗੀ। ਪੂਰੀ 16-ਕਾਰਕ ਸਕੋਰਿੰਗ ਲਈ
   [Auto-Combo](../routing/AUTO-COMBO.md) ਵੇਖੋ।
