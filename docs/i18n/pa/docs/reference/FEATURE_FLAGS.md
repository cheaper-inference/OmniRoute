> ਉਸ ਫਾਈਲ ਤੋਂ ਪੜ੍ਹਦੇ ਹਨ, ਇਸਲਈ ਹੇਠਾਂ ਦਿੱਤੀ ਸਾਰਣੀ ਇਸ ਨਾਲ 1:1 ਮੇਲ ਕਰਨ ਲਈ ਤਿਆਰ ਕੀਤੀ
> ਗਈ ਹੈ।

## ਫੀਚਰ ਫਲੈਗ ਕੀ ਹਨ

ਇੱਕ ਫੀਚਰ ਫਲੈਗ ਇੱਕ ਨਾਮੀ ਟੌਗਲ (ਬੂਲੀਅਨ ਜਾਂ ਐਨਮ) ਹੈ ਜਿਸਦਾ ਮੁੱਲ ਰਨਟਾਈਮ 'ਤੇ ਬਦਲਿਆ
ਜਾ ਸਕਦਾ ਹੈ ਅਤੇ ਡੇਟਾਬੇਸ ਵਿੱਚ ਸਥਾਈ ਕੀਤਾ ਜਾ ਸਕਦਾ ਹੈ, ਜਿਸ ਲਈ ਕਿਸੇ ਪ੍ਰਕਿਰਿਆ ਨੂੰ
ਮੁੜ-ਤੈਨਾਤ ਕਰਨ ਦੀ ਲੋੜ ਨਹੀਂ ਹੈ। ਹਰੇਕ ਫਲੈਗ ਨੂੰ ਇੱਕ `FeatureFlagDefinition` ਦੁਆਰਾ
ਵਰਣਨ ਕੀਤਾ ਗਿਆ ਹੈ ਜਿਸ ਵਿੱਚ ਇੱਕ `key`, `label`, `description`, `category`,
`defaultValue`, `type`, ਅਤੇ ਇੱਕ `requiresRestart` ਸੰਕੇਤ ਸ਼ਾਮਲ ਹਨ।

### ਰੈਜ਼ੋਲੂਸ਼ਨ ਆਰਡਰ

ਇੱਕ ਫਲੈਗ ਦਾ **ਪ੍ਰਭਾਵੀ ਮੁੱਲ** [`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts)
ਦੁਆਰਾ ਇਸ ਤਰਜੀਹ (ਸਭ ਤੋਂ ਉੱਚਾ ਜਿੱਤਦਾ ਹੈ) ਨਾਲ ਹੱਲ ਕੀਤਾ ਜਾਂਦਾ ਹੈ:

1. **DB ਓਵਰਰਾਈਡ** — `key_value` ਸਾਰਣੀ ਵਿੱਚ `feature_flags` ਨਾਮਸਪੇਸ ਦੇ ਅਧੀਨ
   ਸਟੋਰ ਕੀਤਾ ਗਿਆ ਇੱਕ ਮੁੱਲ (ਡੈਸ਼ਬੋਰਡ ਜਾਂ REST API ਰਾਹੀਂ ਸੈੱਟ ਕੀਤਾ ਗਿਆ)।
2. **ਵਾਤਾਵਰਣ ਵੇਰੀਏਬਲ** — `process.env[<KEY>]`, ਜੇਕਰ ਸੈੱਟ ਕੀਤਾ ਗਿਆ ਹੈ ਅਤੇ ਖਾਲੀ
   ਨਹੀਂ ਹੈ।
3. **ਪਰਿਭਾਸ਼ਾ ਡਿਫੌਲਟ** — `featureFlagDefinitions.ts` ਤੋਂ `defaultValue`।

ਇੱਕ ਬੂਲੀਅਨ ਫਲੈਗ ਨੂੰ **ਸਮਰੱਥ** ਮੰਨਿਆ ਜਾਂਦਾ ਹੈ ਜਦੋਂ ਇਸਦਾ ਪ੍ਰਭਾਵੀ ਮੁੱਲ `"true"`,
`"1"`, ਜਾਂ `"yes"` ਹੁੰਦਾ ਹੈ (ਦੇਖੋ `isFeatureFlagEnabled()`)।

> [!NOTE]
> ਜ਼ਿਆਦਾਤਰ ਫਲੈਗਾਂ ਵਿੱਚ [`ENVIRONMENT.md`](./ENVIRONMENT.md) ਵਿੱਚ ਦਸਤਾਵੇਜ਼ੀ
> **ਉਸੇ ਨਾਮ** ਦਾ ਇੱਕ ਮੇਲ ਖਾਂਦਾ ਵਾਤਾਵਰਣ ਵੇਰੀਏਬਲ ਵੀ ਹੁੰਦਾ ਹੈ। ਫਲੈਗ ਦਾ DB
> ਓਵਰਰਾਈਡ ਉਸ ਵਾਤਾਵਰਣ ਵੇਰੀਏਬਲ 'ਤੇ ਤਰਜੀਹ ਲੈਂਦਾ ਹੈ। `requiresRestart: true` ਵਾਲਾ
> ਇੱਕ ਫਲੈਗ ਤੁਰੰਤ ਸਥਾਈ ਹੋ ਜਾਂਦਾ ਹੈ ਪਰ ਸਿਰਫ ਪ੍ਰਕਿਰਿਆ ਸ਼ੁਰੂ ਹੋਣ 'ਤੇ ਮੁੜ-ਪੜ੍ਹਿਆ
> ਜਾਂਦਾ ਹੈ — ਇਸਨੂੰ ਟੌਗਲ ਕਰਨ ਨਾਲ ਡੈਸ਼ਬੋਰਡ ਵਿੱਚ ਇੱਕ **"ਸਰਵਰ ਮੁੜ-ਚਾਲੂ ਕਰੋ"** ਬੈਨਰ
> ਦਿਖਾਈ ਦਿੰਦਾ ਹੈ।

| `CREDENTIAL_GATE_AUTH_DIAGNOSES_ONLY`     | ਬੁਲੀਅਨ   | `false` | ਕੰਬੋ ਕ੍ਰੈਡੈਂਸ਼ੀਅਲ ਗੇਟ ਨੂੰ ਸੰਕੁਚਿਤ ਕਰੋ ਤਾਂ ਕਿ ਇੱਕ ਕੈਸ਼ ਕੀਤੀ ਅਸਫਲ ਕ੍ਰੈਡੈਂਸ਼ੀਅਲ ਪੜਤਾਲ ਇੱਕ ਕੁਨੈਕਸ਼ਨ ਨੂੰ ਉਦੋਂ ਹੀ ਰੋਕਦੀ ਹੈ ਜਦੋਂ ਇਸਦਾ ਨਿਦਾਨ ਗਲਤ ਪ੍ਰਮਾਣ ਪੱਤਰ ਸਾਬਤ ਕਰਦਾ ਹੈ (`upstream_auth_error`, `auth_missing`, `token_expired`, `token_refresh_failed`, `reauth_required`, `account_deactivated`, `auth_required`)। ਟ੍ਰਾਂਸਪੋਰਟ ਡਾਇਗਨੋਸਿਸ (`network_error`, `upstream_unavailable`, `upstream_rate_limited`) ਹਮੇਸ਼ਾ ਨਿਰਣਾਇਕ ਰਹਿੰਦੇ ਹਨ ਅਤੇ ਡਿਸਪੈਚ ਨੂੰ ਬਲੌਕ ਨਹੀਂ ਕਰਦੇ, ਭਾਵੇਂ ਇਹ ਫਲੈਗ ਬੰਦ ਹੋਵੇ। ਜਦੋਂ ਯੋਗ ਕੀਤਾ ਜਾਂਦਾ ਹੈ, ਤਾਂ ਹੋਰ ਅਢੁੱਕਵੇਂ ਨਿਦਾਨਾਂ (ਅਸਪੱਸ਼ਟ ਤਰੁਟੀਆਂ, ਅਸਮਰਥਿਤ ਪੜਤਾਲਾਂ ਅਤੇ ਟਾਈਪ ਨਾ ਕੀਤੀਆਂ ਸ਼ਡਿਊਲਰ ਗਲਤੀਆਂ) ਨੂੰ ਵੀ ਅਣਜਾਣ ਮੰਨਿਆ ਜਾਂਦਾ ਹੈ, ਜਿਸ ਨਾਲ ਟ੍ਰੈਫਿਕ ਦੀ ਇਜਾਜ਼ਤ ਮਿਲਦੀ ਹੈ। ਮੂਲ ਰੂਪ ਵਿੱਚ ਬੰਦ: ਹੋਰ ਕੈਸ਼ ਪੜਤਾਲ ਗਲਤੀਆਂ ਅਜੇ ਵੀ ਕੈਸ਼ TTL (5 ਮਿੰਟ) ਲਈ ਡਿਸਪੈਚ ਨੂੰ ਰੋਕਦੀਆਂ ਹਨ। |

> [!NOTE]
> `INPUT_SANITIZER_BLOCK_THRESHOLD` ਅਤੇ ਇਸਦਾ ਪੁਰਾਤਨ ਉਰਫ `INJECTION_GUARD_BLOCK_THRESHOLD` `INJECTION_GUARD_MODE` ਦੇ `block` ਮੋਡ ਨੂੰ ਟਿਊਨ ਕਰਦੇ ਹਨ, ਪਰ ਇਹ [`src/shared/utils/injectionSeverity.ts`](../../src/shared/utils/injectionSeverity.ts) ਦੁਆਰਾ ਪੜ੍ਹੇ ਗਏ ਸਾਦੇ ਵਾਤਾਵਰਣ ਵੇਰੀਏਬਲ ਹਨ, ਵਿਸ਼ੇਸ਼ਤਾ ਫਲੈਗ ਨਹੀਂ: ਉਹਨਾਂ ਕੋਲ ਕੋਈ DB ਓਵਰਰਾਈਡ ਨਹੀਂ ਹੈ ਅਤੇ ਕੋਈ ਡੈਸ਼ਬੋਰਡ ਟੌਗਲ ਨਹੀਂ ਹੈ। [`ENVIRONMENT.md`](./ENVIRONMENT.md#4-security--authentication) ਦੇਖੋ।

> [!NOTE]
> `Restart` ਕਾਲਮ `requiresRestart: true` — ਦੇ ਨਾਲ ਫਲੈਗ ਚਿੰਨ੍ਹਿਤ ਕਰਦਾ ਹੈ, ਮੁੱਲ ਤੁਰੰਤ ਬਰਕਰਾਰ ਰਹਿੰਦਾ ਹੈ ਪਰ ਪ੍ਰਕਿਰਿਆ ਦੇ ਮੁੜ ਲੋਡ ਹੋਣ ਤੋਂ ਬਾਅਦ ਹੀ ਪ੍ਰਭਾਵੀ ਹੁੰਦਾ ਹੈ। Enum ਫਲੈਗ ਉਹਨਾਂ ਦੇ ਪ੍ਰਵਾਨਿਤ ਸੈੱਟ ਤੋਂ ਬਾਹਰ ਕਿਸੇ ਵੀ ਮੁੱਲ ਨੂੰ ਅਸਵੀਕਾਰ ਕਰਦੇ ਹਨ ( `setFeatureFlagOverride()` ਅਤੇ REST `PUT` ਹੈਂਡਲਰ ਦੋਵਾਂ ਵਿੱਚ ਪ੍ਰਮਾਣਿਤ ਸਰਵਰ-ਸਾਈਡ)।

## ਟੌਗਲ ਕਰਨ ਵਾਲੇ ਝੰਡੇ

### ਡੈਸ਼ਬੋਰਡ

'ਤੇ ਨੈਵੀਗੇਟ ਕਰੋ** ਡੈਸ਼ਬੋਰਡ → ਸੈਟਿੰਗਾਂ → ਫੀਚਰ ਫਲੈਗ** (`/dashboard/settings/feature-flags`) ਗਰਿੱਡ (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`) ਦਾ ਸਮਰਥਨ ਕਰਦਾ ਹੈ:

- **ਖੋਜ** ਕੁੰਜੀ ਜਾਂ ਵਰਣਨ ਦੁਆਰਾ, ਅਤੇ** ਫਿਲਟਰ** ਸ਼੍ਰੇਣੀ ਦੁਆਰਾ (ਨਾਲ ਹੀ ਇੱਕ ਸਿੰਥੈਟਿਕ** ਰੀਸਟਾਰਟ ਦੀ ਲੋੜ ਹੈ** ਦ੍ਰਿਸ਼)।
- ਏ** ਟੌਗਲ** ਬੂਲੀਅਨ ਫਲੈਗ ਅਤੇ ਏ** ਡਰਾਪ ਡਾਉਨ** enum ਝੰਡੇ (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`) ਲਈ।
- ਏ** ਸਰੋਤ ਬੈਜ** ਪ੍ਰਤੀ ਫਲੈਗ — `DB`, `ENV`, ਜਾਂ `DEF` — ਦਿਖਾ ਰਿਹਾ ਹੈ ਕਿ ਪ੍ਰਭਾਵਸ਼ਾਲੀ ਮੁੱਲ ਕਿੱਥੋਂ ਆਇਆ ਹੈ।
- ਏ** ਰੀਸੈਟ ਕਰੋ** ਓਵਰਰਾਈਡ ਛੱਡਣ ਲਈ ਬਟਨ (ਕੇਵਲ `DB` -sourced ਫਲੈਗ ਲਈ ਦਿਖਾਇਆ ਗਿਆ ਹੈ), ਅਤੇ a** ਸਾਰੇ ਓਵਰਰਾਈਡਾਂ ਨੂੰ ਰੀਸੈਟ ਕਰੋ** ਤਲ 'ਤੇ ਬਟਨ.
- ਏ** ਸਰਵਰ ਰੀਸਟਾਰਟ ਕਰੋ** ਬੈਨਰ ਜਦੋਂ ਇੱਕ `requiresRestart` ਝੰਡਾ ਬਦਲਿਆ ਜਾਂਦਾ ਹੈ।

### REST API

ਸਾਰੇ ਓਪਰੇਸ਼ਨ ਇੱਕ ਸਿੰਗਲ ਰੂਟ ਰਾਹੀਂ ਹੁੰਦੇ ਹਨ: [`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts). ਹਰ ਵਿਧੀ ਲਈ ਇੱਕ ਪ੍ਰਮਾਣਿਤ ਡੈਸ਼ਬੋਰਡ ਸੈਸ਼ਨ ਦੀ ਲੋੜ ਹੁੰਦੀ ਹੈ (`401` ਨਹੀਂ ਤਾਂ)।

ਲੌਗਇਨ ਅਯੋਗ (`requireLogin=false`) ਨਾਲ ਰੂਟ ਖੁੱਲ੍ਹਾ ਹੈ, ਸੁਰੱਖਿਅਤ ਫਲੈਗਾਂ ਨੂੰ ਛੱਡ ਕੇ: ਸੁਰੱਖਿਆ ਸ਼੍ਰੇਣੀ ਵਿੱਚ ਹਰ ਫਲੈਗ ਪਲੱਸ `OMNIROUTE_ALLOW_PRIVATE_PROVIDER_URLS`, `OMNIROUTE_ALLOW_LOCAL_PROVIDER_URLS`, `MITM_DISABLE_TLS_VERIFY`, `OMNIROUTE_MCP_ENFORCE_SCOPES` ਅਤੇ `SKILLS_SANDBOX_NETWORK_ENABLED` ( `protectedFeatureFlags.ts` ਵਿੱਚ `isProtectedFeatureFlag()` )। ਉਹਨਾਂ ਵਿੱਚੋਂ ਇੱਕ 'ਤੇ ਇੱਕ `PUT`, ਅਤੇ ਇੱਕ `DELETE` ਜਦੋਂ ਕਿ ਉਹਨਾਂ ਵਿੱਚੋਂ ਇੱਕ ਕੋਲ ਇੱਕ DB ਓਵਰਰਾਈਡ ਹੈ, ਫਿਰ ਵੀ ਇੱਕ ਡੈਸ਼ਬੋਰਡ ਸੈਸ਼ਨ, ਇੱਕ `manage` -scope API ਕੁੰਜੀ, ਇੱਕ `oma_` ਐਕਸੈਸ ਟੋਕਨ ਲਿਖਣ ਦੇ ਸਕੋਪ ਜਾਂ ਵੱਧ, ਜਾਂ ਲੂਪਬੈਕ ਤੋਂ ਭੇਜੇ ਗਏ CLI ਟੋਕਨ ਜਾਂ ਅੰਦਰੂਨੀ-ਸੇਵਾ ਟੋਕਨ ਦੀ ਲੋੜ ਹੈ। ਉਹ ਸੈੱਟ ਲੌਗਇਨ ਆਨ ਨਾਲੋਂ ਚੌੜਾ ਹੈ, ਜਿੱਥੇ ਰੂਟ ਸਿਰਫ਼ ਇੱਕ ਸੈਸ਼ਨ ਜਾਂ ਇੱਕ `manage` -scope ਕੁੰਜੀ ਨੂੰ ਸਵੀਕਾਰ ਕਰਦਾ ਹੈ।

#### `GET /api/settings/feature-flags`

ਹਰ ਫਲੈਗ ਨੂੰ ਇਸਦੇ ਪ੍ਰਭਾਵੀ ਮੁੱਲ, ਸਰੋਤ, ਅਤੇ ਸਾਰਾਂਸ਼ ਨਾਲ ਵਾਪਸ ਕਰਦਾ ਹੈ।

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Require API Key",
      "description": "Require an API key for all incoming requests",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... all 126 flags
  ],
  "summary": {
    "total": 126,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

ਇੱਕ ਸਿੰਗਲ ਓਵਰਰਾਈਡ ਸੈੱਟ ਕਰੋ ਜਾਂ ਹਟਾਓ। ਸਰੀਰ: `{ key: string; value?: string }`. `value` ਨੂੰ ਛੱਡਣਾ ਓਵਰਰਾਈਡ ਨੂੰ ਹਟਾਉਂਦਾ ਹੈ (env / ਡਿਫੌਲਟ ਨੂੰ ਰੀਸਟੋਰ ਕਰਨਾ)।

```bash
# Set a DB override
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# Remove the override (no "value")
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

ਜਵਾਬ ਨਵੇਂ `effectiveValue`/`source`, `previousValue`/ `previousSource`, ਅਤੇ `requiresRestart` ਨੂੰ ਗੂੰਜਦਾ ਹੈ। ਅਣਜਾਣ ਕੁੰਜੀਆਂ ਅਤੇ ਰੇਂਜ ਤੋਂ ਬਾਹਰ ਦੇ enum ਮੁੱਲਾਂ ਨੂੰ `400` ਨਾਲ ਰੱਦ ਕਰ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ।

#### `DELETE /api/settings/feature-flags`

ਸਾਫ਼ ਕਰਦਾ ਹੈ** ਸਾਰੇ** DB ਇੱਕ ਵਾਰ 'ਤੇ ਓਵਰਰਾਈਡ ਕਰਦਾ ਹੈ, ਹਰ ਫਲੈਗ ਨੂੰ ਇਸਦੇ env / ਡਿਫਾਲਟ ਮੁੱਲ ਵਿੱਚ ਬਹਾਲ ਕਰਦਾ ਹੈ। `{ cleared: <count>, message: "..." }` ਵਾਪਸ ਕਰਦਾ ਹੈ।

> [!NOTE]
> `requiresRestart: true` ਨਾਲ ਫਲੈਗ ਸਿਰਫ਼ ਇੱਕ ਪ੍ਰਕਿਰਿਆ ਨੂੰ ਰੀਲੋਡ ਕਰਨ ਤੋਂ ਬਾਅਦ ਹੀ ਪ੍ਰਭਾਵੀ ਹੁੰਦੇ ਹਨ। ਡੈਸ਼ਬੋਰਡ ਦਾ ਰੀਸਟਾਰਟ ਫਲੋ `POST /api/restart` ਕਾਲ ਕਰਦਾ ਹੈ ਅਤੇ ਫਿਰ ਸਰਵਰ ਦੇ ਬੈਕਅੱਪ ਹੋਣ ਤੱਕ `GET /api/health/ping` ਪੋਲ ਕਰਦਾ ਹੈ।

## ਐਮਰਜੈਂਸੀ ਬਜਟ ਫਾਲਬੈਕ

`OMNIROUTE_EMERGENCY_FALLBACK` (ਸ਼੍ਰੇਣੀ `runtime`, ਡਿਫਾਲਟ `true`)  
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts) ਵਿੱਚ ਐਮਰਜੈਂਸੀ ਮੁਫ਼ਤ-ਫਾਲਬੈਕ ਮਾਰਗ ਨੂੰ ਨਿਯੰਤਰਿਤ ਕਰਦਾ ਹੈ।
ਸਮਰੱਥ ਹੋਣ 'ਤੇ, ਜਿਹੜੀਆਂ ਬੇਨਤੀਆਂ ਆਪਣਾ ਬਜਟ ਖ਼ਤਮ ਕਰ ਲੈਂਦੀਆਂ ਹਨ, ਉਹਨਾਂ ਨੂੰ ਸਿੱਧੇ ਅਸਫਲ ਕਰਨ ਦੀ ਬਜਾਏ ਕਿਸੇ ਮੁਫ਼ਤ ਫਾਲਬੈਕ ਪ੍ਰਦਾਤਾ/ਮਾਡਲ ਵੱਲ ਰੂਟ ਕੀਤਾ ਜਾਂਦਾ ਹੈ। ਇਸ ਵਿਹਾਰ ਨੂੰ ਅਸਮਰੱਥ ਕਰਨ ਅਤੇ ਬਜਟ ਖ਼ਤਮ ਕਰ ਚੁੱਕੀਆਂ ਬੇਨਤੀਆਂ ਨੂੰ ਅਸਫਲ ਹੋਣ ਦੇਣ ਲਈ—ਡੈਸ਼ਬੋਰਡ ਟੌਗਲ, DB ਓਵਰਰਾਈਡ, ਜਾਂ `OMNIROUTE_EMERGENCY_FALLBACK` ਵਾਤਾਵਰਣ ਵੇਰੀਏਬਲ ਰਾਹੀਂ—ਇਸਨੂੰ `false` (ਜਾਂ `0`) 'ਤੇ ਸੈੱਟ ਕਰੋ। (PRs #3741 / #3752 ਵਿੱਚ ਡੈਸ਼ਬੋਰਡ ਟੌਗਲ ਵਜੋਂ ਉਪਲਬਧ ਕਰਵਾਇਆ ਗਿਆ।)

ਇਸ ਫਾਲਬੈਕ ਰਾਹੀਂ ਦਿੱਤੇ ਗਏ ਜਵਾਬ ਵਿੱਚ
`X-OmniRoute-Emergency-Fallback: from=<provider/model>; to=<provider/model>` ਹੁੰਦਾ ਹੈ, ਤਾਂ ਜੋ ਕਲਾਇੰਟ ਆਪਣੀ ਬੇਨਤੀ ਨਾਲ `X-OmniRoute-Provider` ਦੀ ਤੁਲਨਾ ਕੀਤੇ ਬਿਨਾਂ ਇਹ ਜਾਣ ਸਕੇ ਕਿ ਇਸਨੂੰ ਮੁੜ ਰੂਟ ਕੀਤਾ ਗਿਆ ਸੀ। ਹਰ ਹੋਰ ਜਵਾਬ ਵਿੱਚ ਇਹ ਹੈਡਰ ਮੌਜੂਦ ਨਹੀਂ ਹੁੰਦਾ।
