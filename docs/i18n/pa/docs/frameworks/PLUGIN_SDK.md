## ਤੇਜ਼ ਸ਼ੁਰੂਆਤ

```ts
import { definePlugin } from "omniroute/plugins/sdk";

export default definePlugin({
  name: "my-plugin",
  priority: 50,
  onRequest: async (ctx) => {
    console.log(`Request ${ctx.requestId} for ${ctx.model}`);
  },
  onResponse: async (ctx, response) => {
    console.log(`Response for ${ctx.requestId}`);
    return response;
  },
  onError: async (ctx, error) => {
    console.error(`Error: ${error.message}`);
  },
});
```

## API ਹਵਾਲਾ

### `definePlugin(def: PluginDefinition): Plugin`

ਫੈਕਟਰੀ ਫੰਕਸ਼ਨ ਜੋ ਡਿਫੌਲਟ ਨਾਲ ਇੱਕ ਪਲੱਗਇਨ ਆਬਜੈਕਟ ਬਣਾਉਂਦਾ ਹੈ।

**ਪੈਰਾਮੀਟਰ:**

- ਕਬਾਬ-ਕੇਸ ਵਿੱਚ `name` (ਸਤਰ, ਲੋੜੀਂਦਾ) — ਪਲੱਗਇਨ ਨਾਮ
- `priority` (ਨੰਬਰ, ਵਿਕਲਪਿਕ, ਡਿਫੌਲਟ: 100) — ਲੋਅਰ ਪਹਿਲਾਂ ਚੱਲਦਾ ਹੈ
- `enabled` (ਬੁਲੀਅਨ, ਵਿਕਲਪਿਕ, ਡਿਫੌਲਟ: ਸਹੀ) — ਸਟਾਰਟ ਸਮਰੱਥ ਹੈ?
- `onRequest` (ਫੰਕਸ਼ਨ, ਵਿਕਲਪਿਕ) — ਚੈਟ ਹੈਂਡਲਰ ਤੋਂ ਪਹਿਲਾਂ ਚੱਲਦਾ ਹੈ
- `onResponse` (ਫੰਕਸ਼ਨ, ਵਿਕਲਪਿਕ) — ਚੈਟ ਹੈਂਡਲਰ ਤੋਂ ਬਾਅਦ ਚੱਲਦਾ ਹੈ
- `onError` (ਫੰਕਸ਼ਨ, ਵਿਕਲਪਿਕ) — ਹੈਂਡਲਰ ਗਲਤੀ 'ਤੇ ਚੱਲਦਾ ਹੈ

### `blockRequest(response?): BlockingHookResult`

ਬੇਨਤੀ ਨੂੰ ਬਲੌਕ ਕਰੋ ਅਤੇ ਵਿਕਲਪਿਕ ਤੌਰ 'ਤੇ ਇੱਕ ਕਸਟਮ ਜਵਾਬ ਵਾਪਸ ਕਰੋ।

```ts
onRequest: (ctx) => {
  if (!ctx.headers?.["x-client-team"]) {
    return blockRequest({ error: "Missing x-client-team header", status: 400 });
  }
};
```

### `modifyBody(body): PluginResult`

ਪ੍ਰਦਾਤਾ ਤੱਕ ਪਹੁੰਚਣ ਤੋਂ ਪਹਿਲਾਂ ਬੇਨਤੀ ਬਾਡੀ ਨੂੰ ਸੋਧੋ।

```ts
onRequest: (ctx) => {
  return modifyBody({ ...ctx.body, temperature: 0.7 });
};
```

### `addMetadata(metadata): PluginResult`

ਬੇਨਤੀ ਸੰਦਰਭ ਵਿੱਚ ਮੈਟਾਡੇਟਾ ਨੱਥੀ ਕਰੋ।

```ts
onRequest: (ctx) => {
  return addMetadata({ source: "my-plugin", version: "1.0.0" });
};
```

## ਪਲੱਗਇਨ ਸੰਦਰਭ (`PluginContext`)

| ਖੇਤਰ         | ਟਾਈਪ ਕਰੋ                  | ਵਰਣਨ                          |
| ------------ | ------------------------- | ----------------------------- |
| `requestId`  | `string`                  | ਵਿਲੱਖਣ ਬੇਨਤੀ ਪਛਾਣਕਰਤਾ         |
| `model`      | `string`                  | ਮਾਡਲ ਨਾਮ ਦੀ ਬੇਨਤੀ ਕੀਤੀ        |
| `provider`   | `string`                  | ਟੀਚਾ ਪ੍ਰਦਾਤਾ ID               |
| `body`       | `Record<string, unknown>` | ਸਰੀਰ ਨੂੰ ਬੇਨਤੀ ਕਰੋ            |
| `headers`    | `Record<string, string>`  | ਬੇਨਤੀ ਹੈਡਰ (ਨੋਟ ਦੇਖੋ)         |
| `metadata`   | `Record<string, unknown>` | ਪਰਿਵਰਤਨਸ਼ੀਲ ਮੈਟਾਡੇਟਾ          |
| `timestamp`  | `number`                  | ਟਾਈਮਸਟੈਂਪ ਦੀ ਬੇਨਤੀ ਕਰੋ        |
| `apiKeyInfo` | `object` (ਵਿਕਲਪਿਕ)        | API ਕੁੰਜੀ ਮੈਟਾਡੇਟਾ (ਨੋਟ ਦੇਖੋ) |

ਸੰਦਰਭ ਕਦੇ ਵੀ ਕਲਾਇੰਟ ਦੇ ਪ੍ਰਮਾਣ ਪੱਤਰਾਂ ਨੂੰ ਨਹੀਂ ਰੱਖਦਾ: `authorization`, `x-api-key`, `proxy-authorization` ਅਤੇ `cookie` ਸਿਰਲੇਖਾਂ ਨੂੰ ਹਟਾ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ (ਕੋਈ ਵੀ ਕੇਸਿੰਗ), ਅਤੇ `apiKeyInfo` ਕੁੰਜੀ ਦਾ ਮੈਟਾਡੇਟਾ ਰੱਖਦਾ ਹੈ (ਜਿਵੇਂ ਕਿ `id`, `name` ਅਤੇ `scopes`) ਪਰ ਕੁੰਜੀ ਮੁੱਲ ਜਾਂ ਇਸਦੇ ਫਿੰਗਰਪ੍ਰਿੰਟ (`redactPluginContext()` ) `src/lib/plugins/hooks.ts` ਨਹੀਂ ਰੱਖਦਾ। ਇਹ `onRequest`, `onResponse` ਅਤੇ `onError`'ਤੇ ਲਾਗੂ ਹੁੰਦਾ ਹੈ।

## ਮੈਨੀਫੈਸਟ (`plugin.json`)

```json
{
  "name": "my-plugin",
  "version": "1.0.0",
  "description": "A sample plugin",
  "author": "your-name",
  "main": "index.js",
  "hooks": {
    "onRequest": { "enabled": true, "priority": 50 },
    "onResponse": true,
    "onError": false
  },
  "requires": {
    "permissions": ["network", "file-read"]
  },
  "enabledByDefault": false,
  "configSchema": {
    "apiKey": {
      "type": "string",
      "description": "API key for external service"
    },
    "maxRetries": { "type": "number", "min": 1, "max": 10, "default": 3 },
    "debug": { "type": "boolean", "default": false },
    "mode": { "type": "string", "enum": ["fast", "slow"], "default": "fast" }
  }
}
```

### Hook ਦੀ ਤਰਜੀਹ

Hooks ਨੂੰ ਤਰਜੀਹ ਨਾਲ ਸੰਰਚਿਤ ਕੀਤਾ ਜਾ ਸਕਦਾ ਹੈ (ਘੱਟ = ਪਹਿਲਾਂ ਚੱਲਦਾ ਹੈ):

```json
{
  "hooks": {
    "onRequest": { "enabled": true, "priority": 10 },
    "onResponse": { "enabled": true, "priority": 100 }
  }
}
```

ਜਾਂ ਸਧਾਰਨ boolean ਮੁੱਲਾਂ ਵਜੋਂ (ਡਿਫਾਲਟ ਤਰਜੀਹ 100):

```json
{
  "hooks": {
    "onRequest": true,
    "onResponse": true
  }
}
```

## ਇਜਾਜ਼ਤ ਸਿਸਟਮ

ਮੂਲ ਰੂਪ ਵਿੱਚ ਪਲੱਗਇਨ ਹਨ** ਸੈਂਡਬਾਕਸਡ ਨਹੀਂ** . ਹਰੇਕ ਕਿਰਿਆਸ਼ੀਲ ਪਲੱਗਇਨ ਇੱਕ ਵੱਖਰੀ, ਆਮ Node.js ਚਾਈਲਡ ਪ੍ਰਕਿਰਿਆ ( `src/lib/plugins/loader.ts` ਵਿੱਚ `loadPlugin()` ) ਉਸੇ ਓਪਰੇਟਿੰਗ-ਸਿਸਟਮ ਉਪਭੋਗਤਾ OmniRoute ਦੇ ਅਧੀਨ ਚਲਦੀ ਹੈ, ਬਿਨਾਂ VM ਸੰਦਰਭ ਅਤੇ ਕੋਈ Node.js ਅਨੁਮਤੀ ਫਲੈਗ ਦੇ ਬਿਨਾਂ। ਪਲੱਗਇਨ ਕੋਡ `node:fs`, `node:child_process`, `fetch` ਅਤੇ ਹਰ ਦੂਜੇ Node.js API ਵਰਤੋਂ ਕਰ ਸਕਦਾ ਹੈ: ਇਹ ਕਿਸੇ ਵੀ ਫਾਈਲ ਨੂੰ ਪੜ੍ਹ ਅਤੇ ਲਿਖ ਸਕਦਾ ਹੈ ਜੋ OmniRoute ਉਪਭੋਗਤਾ (ਡਾਟਾ ਡਾਇਰੈਕਟਰੀ ਸਮੇਤ), ਪ੍ਰੋਗਰਾਮ ਚਲਾ ਸਕਦਾ ਹੈ ਅਤੇ ਨੈਟਵਰਕ ਤੱਕ ਪਹੁੰਚ ਸਕਦਾ ਹੈ।

ਮੈਨੀਫੈਸਟ ਦਾ `requires.permissions` `network`, `file-read`, `file-write`, `env` ਅਤੇ `exec` ਸਵੀਕਾਰ ਕਰਦਾ ਹੈ। ਡਿਫੌਲਟ ਸੈਟਿੰਗਾਂ ਦੇ ਨਾਲ ਰਨਟਾਈਮ 'ਤੇ ਸਿਰਫ `env` ਪ੍ਰਭਾਵ ਹੁੰਦਾ ਹੈ।

### ਆਪਟ-ਇਨ ਅਨੁਮਤੀ ਮਾਡਲ (`PLUGIN_PERMISSION_MODEL_ENABLED`)

`PLUGIN_PERMISSION_MODEL_ENABLED` ਵਿਸ਼ੇਸ਼ਤਾ ਝੰਡਾ (ਸ਼੍ਰੇਣੀ `security`,** ਮੂਲ ਰੂਪ ਵਿੱਚ ਬੰਦ** ) ਹਰੇਕ ਪਲੱਗਇਨ ਪ੍ਰਕਿਰਿਆ ਨੂੰ [Node.js ਅਨੁਮਤੀ ਮਾਡਲ](https://nodejs.org/api/permissions.html) (`--permission`, ਹਰ ਸਮਰਥਿਤ Node.js ਲਾਈਨ ਦੁਆਰਾ ਸਵੀਕਾਰ ਕੀਤਾ ਜਾਂਦਾ ਹੈ: 22.22 +, 24 ਅਤੇ 26) ਨਾਲ ਸ਼ੁਰੂ ਕਰਦਾ ਹੈ। ਝੰਡੇ `src/lib/plugins/permissionModel.ts` ਵਿੱਚ `buildPermissionModelArgs()` ਦੁਆਰਾ ਮੈਨੀਫੈਸਟ ਤੋਂ ਬਣਾਏ ਗਏ ਹਨ। ਫਲੈਗ ਨੂੰ ਉਦੋਂ ਪੜ੍ਹਿਆ ਜਾਂਦਾ ਹੈ ਜਦੋਂ ਇੱਕ ਪਲੱਗਇਨ ਐਕਟੀਵੇਟ ਹੁੰਦਾ ਹੈ, ਇਸਲਈ ਇਹ ਬਦਲਾਅ ਤੋਂ ਬਾਅਦ ਐਕਟੀਵੇਟ ਕੀਤੇ ਪਲੱਗਇਨਾਂ 'ਤੇ ਲਾਗੂ ਹੁੰਦਾ ਹੈ; ਇਸ ਨੂੰ ਲਾਗੂ ਕਰਨ ਲਈ ਚੱਲ ਰਹੇ ਪਲੱਗਇਨ ਨੂੰ ਅਕਿਰਿਆਸ਼ੀਲ ਅਤੇ ਕਿਰਿਆਸ਼ੀਲ ਕਰੋ।

ਪਲੱਗਇਨ ਡਾਟਾ ਡਾਇਰੈਕਟਰੀ ਪਲੱਗਇਨ ਰੂਟ ਦੇ ਅੱਗੇ `plugin-data/<plugin-name>` ਹੈ (`~/.omniroute/plugin-data/<plugin-name>` ਮੂਲ ਰੂਪ ਵਿੱਚ, `getPluginDataDir()`)। ਫਲੈਗ ਚਾਲੂ ਹੋਣ ਦੇ ਨਾਲ, ਇਸਦਾ ਮਾਰਗ ਪਲੱਗਇਨ ਨੂੰ `PLUGIN_DATA_DIR` ਵਜੋਂ ਪਾਸ ਕੀਤਾ ਜਾਂਦਾ ਹੈ।

| ਇਜਾਜ਼ਤ       | ਫਲੈਗ ਆਫ (ਡਿਫੌਲਟ)                                                                                                                                                                                                                         | ਫਲੈਗ ਚਾਲੂ ਕਰੋ                                                                                                                                                                                                                                                            |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |

| `file-read`  | ਕੋਈ ਨਹੀਂ (ਸਿਰਫ਼ ਘੋਸ਼ਣਾ)                                                                                                                                                                                                                  | ਪਲੱਗਇਨ ਡਾਟਾ ਡਾਇਰੈਕਟਰੀ ਵੀ ਪੜ੍ਹਨਯੋਗ ਬਣ ਜਾਂਦੀ ਹੈ (ਜੇ ਗੁੰਮ ਹੈ ਤਾਂ ਇਹ ਬਣਾਈ ਜਾਂਦੀ ਹੈ)।                                                                                                                                                                                         |
| `file-write` | ਕੋਈ ਨਹੀਂ (ਸਿਰਫ਼ ਘੋਸ਼ਣਾ)                                                                                                                                                                                                                  | ਪਲੱਗਇਨ ਡਾਟਾ ਡਾਇਰੈਕਟਰੀ ਪੜ੍ਹਨਯੋਗ ਅਤੇ ਲਿਖਣਯੋਗ ਬਣ ਜਾਂਦੀ ਹੈ (`--allow-fs-write`)। ਹੋਰ ਕੁਝ ਵੀ ਲਿਖਣਯੋਗ ਨਹੀਂ ਹੈ।                                                                                                                                                                 |
| `exec`       | ਕੋਈ ਨਹੀਂ (ਸਿਰਫ਼ ਘੋਸ਼ਣਾ)                                                                                                                                                                                                                  | ਬਾਲ ਪ੍ਰਕਿਰਿਆਵਾਂ ਦੀ ਇਜਾਜ਼ਤ ਹੈ (`--allow-child-process`)। Node.js `NODE_OPTIONS` ਰਾਹੀਂ ਚਾਈਲਡ Node.js ਪ੍ਰਕਿਰਿਆਵਾਂ ਨੂੰ ਇਜਾਜ਼ਤ ਦੇ ਫਲੈਗ ਪਾਸ ਕਰਦਾ ਹੈ, ਪਰ ਕੋਈ ਵੀ ਹੋਰ ਪ੍ਰੋਗਰਾਮ ਬਿਨਾਂ ਪਾਬੰਦੀਆਂ ਦੇ ਚੱਲਦਾ ਹੈ, ਇਸਲਈ `exec` ਫਾਈਲ-ਸਿਸਟਮ ਦੀਆਂ ਸੀਮਾਵਾਂ ਨੂੰ ਪ੍ਰਭਾਵਸ਼ਾਲੀ ਢੰਗ ਨਾਲ ਚੁੱਕਦਾ ਹੈ। |
| `network`    | ਕੋਈ ਨਹੀਂ (ਸਿਰਫ਼ ਘੋਸ਼ਣਾ)                                                                                                                                                                                                                  | ਕੋਈ ਨਹੀਂ। Node.js ਅਨੁਮਤੀ ਮਾਡਲ ਆਊਟਬਾਉਂਡ ਨੈੱਟਵਰਕ ਪਹੁੰਚ ਨੂੰ ਸੀਮਤ ਨਹੀਂ ਕਰਦਾ ਹੈ, ਇਸਲਈ `network` ਇੱਕ ਘੋਸ਼ਣਾ ਬਣਿਆ ਰਹਿੰਦਾ ਹੈ ਅਤੇ ਕਦੇ ਵੀ ਲਾਗੂ ਨਹੀਂ ਹੁੰਦਾ ਹੈ।                                                                                                                      |

ਫਲੈਗ ਨੂੰ ਬਰੇਕ ਪਲੱਗਇਨਾਂ 'ਤੇ ਚਾਲੂ ਕਰਨਾ ਜੋ ਉਹਨਾਂ ਦੀ ਆਪਣੀ ਡਾਇਰੈਕਟਰੀ ਤੋਂ ਬਾਹਰ ਫਾਈਲਾਂ ਨੂੰ ਪੜ੍ਹਦੇ ਹਨ (ਉਦਾਹਰਨ ਲਈ ਇੱਕ ਮਾਤਾ-ਪਿਤਾ `node_modules` ਤੋਂ ਹੱਲ ਕੀਤਾ ਗਿਆ ਮੋਡੀਊਲ), ਉਹਨਾਂ ਦੀ ਡੇਟਾ ਡਾਇਰੈਕਟਰੀ ਤੋਂ ਇਲਾਵਾ ਕਿਤੇ ਵੀ ਲਿਖੋ, ਜਾਂ `exec` ਘੋਸ਼ਿਤ ਕੀਤੇ ਬਿਨਾਂ ਪ੍ਰਕਿਰਿਆਵਾਂ ਨੂੰ ਸਪੋਨ ਕਰੋ। ਪਲੱਗਇਨ 'ਤੇ ਫਲੈਗ ਦੇ ਨਾਲ ਵੀ ਨੈਟਵਰਕ ਐਕਸੈਸ ਰੱਖਦਾ ਹੈ ਅਤੇ OmniRoute ਉਪਭੋਗਤਾ ਵਜੋਂ ਚਲਦਾ ਹੈ, ਇਸਲਈ ਸਿਰਫ ਉਹ ਪਲੱਗਇਨ ਸਥਾਪਿਤ ਕਰੋ ਜਿਨ੍ਹਾਂ ਦੇ ਸਰੋਤ 'ਤੇ ਤੁਸੀਂ ਭਰੋਸਾ ਕਰਦੇ ਹੋ।

## ਕੌਂਫਿਗ ਸਕੀਮਾ

ਕੌਂਫਿਗਰ ਕਰਨ ਯੋਗ ਸੈਟਿੰਗਾਂ ਨੂੰ `configSchema` ਵਿੱਚ ਪਰਿਭਾਸ਼ਿਤ ਕਰੋ:

```json
{
  "configSchema": {
    "apiKey": { "type": "string", "description": "External API key" },
    "maxRetries": { "type": "number", "min": 1, "max": 10, "default": 3 },
    "debug": { "type": "boolean", "default": false },
    "mode": { "type": "string", "enum": ["fast", "slow"], "default": "fast" }
  }
}
```

ਫ਼ੀਲਡ ਕਿਸਮਾਂ: `string`, `number`, `boolean`, `select`

ਫ਼ੀਲਡ ਵਿਕਲਪ: `default`, `min`, `max`, `enum`, `description`

ਕੌਂਫਿਗ ਮੁੱਲ ਡੇਟਾਬੇਸ ਵਿੱਚ ਸਥਾਈ ਤੌਰ 'ਤੇ ਸੁਰੱਖਿਅਤ ਕੀਤੇ ਜਾਂਦੇ ਹਨ ਅਤੇ ਡੈਸ਼ਬੋਰਡ ਕੌਂਫਿਗ ਪੰਨੇ ਰਾਹੀਂ ਪਹੁੰਚਯੋਗ ਹੁੰਦੇ ਹਨ।

## ਉਦਾਹਰਨਾਂ

### ਲੌਗਰ ਦੀ ਬੇਨਤੀ ਕਰੋ

```ts
import { definePlugin } from "omniroute/plugins/sdk";

export default definePlugin({
  name: "request-logger",
  onRequest: async (ctx) => {
    console.log(`[${new Date().toISOString()}] ${ctx.method} ${ctx.model} -> ${ctx.provider}`);
  },
});
```

### ਦਰ ਸੀਮਾ

```ts
import { definePlugin, blockRequest } from "omniroute/plugins/sdk";

const requests = new Map<string, number[]>();

export default definePlugin({
  name: "rate-limiter",
  priority: 10,
  onRequest: async (ctx) => {
    const key = ctx.apiKeyInfo?.id || "anonymous";
    const now = Date.now();
    const window = 60000; // 1 minute
    const maxRequests = 100;

    const timestamps = (requests.get(key) || []).filter((t) => t > now - window);
    timestamps.push(now);
    requests.set(key, timestamps);

    if (timestamps.length > maxRequests) {
      return blockRequest({ error: "Rate limit exceeded", status: 429 });
    }
  },
});
```

### ਜਵਾਬ ਟ੍ਰਾਂਸਫਾਰਮਰ

```ts
import { definePlugin } from "omniroute/plugins/sdk";

export default definePlugin({
  name: "response-transformer",
  onResponse: async (ctx, response) => {
    if (response.choices) {
      response.choices = response.choices.map((c: any) => ({
        ...c,
        message: { ...c.message, content: c.message.content.trim() },
      }));
    }
    return response;
  },
});
```
