## ਟੈਬਸ

### ਖੋਜ ਟੈਬ

ਮੌਜੂਦਾ `SearchForm` + `ResultsPanel` + `RerankPanel` ਨੂੰ ਇੱਕ ਟੈਬ ਵਿੱਚ ਵਿਕਸਿਤ ਕਰਦਾ ਹੈ:

- → ਨਤੀਜਿਆਂ ਦੀ ਪੁੱਛਗਿੱਛ ਕਰੋ (ਸਿਰਲੇਖ, URL, ਸਨਿੱਪਟ, ਪ੍ਰਸੰਗਿਕਤਾ ਸਕੋਰ)।
- ਕੌਂਫਿਗ ਪੈਨ ਵਿੱਚ ਪ੍ਰਦਾਤਾ ਮੈਟਾਡੇਟਾ (ਲਾਗਤ, ਕੋਟਾ, ਸਥਿਤੀ)।
- ਰੀਰੈਂਕ ਸੈਕਸ਼ਨ: ਰੀਰੈਂਕ ਮਾਡਲ ਚੁਣੋ, ਨਤੀਜਿਆਂ ਨੂੰ ਮੁੜ ਕ੍ਰਮਬੱਧ ਕਰੋ, `positionDelta` ਦਿਖਾਓ।
- CTA ਨਾਲ ਖਾਲੀ ਸਥਿਤੀ ਜਦੋਂ ਕੋਈ ਖੋਜ ਪ੍ਰਦਾਤਾ ਕੌਂਫਿਗਰ ਨਹੀਂ ਕੀਤਾ ਜਾਂਦਾ ਹੈ।
- `SearchHistory.tsx` ਰਾਹੀਂ ਇਤਿਹਾਸ ਖੋਜੋ।
- ਕਾਲ `POST /v1/search` (ਮੌਜੂਦਾ ਅੰਤ ਬਿੰਦੂ, ਕੋਈ ਬਦਲਾਅ ਨਹੀਂ)।

### ਸਕ੍ਰੈਪ ਟੈਬ

`POST /v1/web/fetch` ਰਾਹੀਂ URL ਤੋਂ ਸਮੱਗਰੀ ਕੱਢਣ ਲਈ ਨਵੀਂ ਟੈਬ (ਯੋਜਨਾ 05 ਵਿੱਚ ਬਣਾਈ ਗਈ):

- ਇਨਪੁਟ: URL + ਪੂਰੇ-ਪੰਨੇ ਟੌਗਲ + ਫਾਰਮੈਟ ਚੋਣਕਾਰ (ਮਾਰਕਡਾਊਨ / ਟੈਕਸਟ / HTML)।
- → ਪ੍ਰਾਪਤ ਕਰੋ → ਰੈਂਡਰ `ScrapeResult.tsx` ਸਪੁਰਦ ਕਰੋ।
- `ScrapeResult` ਮਾਰਕਡਾਊਨ ਪ੍ਰੀਵਿਊ + ਰਾਅ ਟੌਗਲ ਨੂੰ ਰੈਂਡਰ ਕਰਦਾ ਹੈ।
- ਕੈਪ: ਜੇ ਜਵਾਬ ਸਰੀਰ >** 256 KB** , UI `(truncated, view raw)` ਦਿਖਾਉਂਦਾ ਹੈ ਅਤੇ ਮੋਨਾਕੋ ਮੋਡਲ (D21) ਵਿੱਚ ਕੱਚਾ ਖੋਲ੍ਹਦਾ ਹੈ।
- ਮੈਟਾਡੇਟਾ ਪੈਨਲ: ਪ੍ਰਦਾਤਾ (firecrawl/jina-reader/tavily-search/tinyfish/nimble-search/anysearch-search/parallel-search/keenable-search), ਲੇਟੈਂਸੀ, ਲਾਗਤ, ਜਵਾਬ ਦਾ ਆਕਾਰ, ਲਿੰਕਾਂ ਦੀ ਗਿਣਤੀ।
- `useScrapeFetch.ts` ਹੁੱਕ ਦੀ ਵਰਤੋਂ ਕਰਦਾ ਹੈ।

### ਟੈਬ ਦੀ ਤੁਲਨਾ ਕਰੋ

ਤੱਕ ਦੇ ਪਾਰ ਇੱਕੋ query/URL ਚਲਾਉਂਦਾ ਹੈ** ਸਮਾਨਾਂਤਰ ਵਿੱਚ 4 ਪ੍ਰਦਾਤਾ** (D22):

- ਪ੍ਰਤੀ ਪ੍ਰਦਾਤਾ ਦੇ ਨਾਲ-ਨਾਲ ਕਾਲਮ।
- ਮੈਟ੍ਰਿਕਸ: ਲੇਟੈਂਸੀ, ਲਾਗਤ, ਨਤੀਜੇ ਦੀ ਗਿਣਤੀ, ਜਵਾਬ ਦਾ ਆਕਾਰ।
- ਖੋਜ ਲਈ URL ਓਵਰਲੈਪ ਗਣਨਾ (ਸਾਂਝੇ URLs ਬਨਾਮ ਸ਼ੁਰੂਆਤੀ ਨਤੀਜੇ ਦੀ ਸੰਖਿਆ)।
- `POST /v1/search` (ਖੋਜ) ਜਾਂ `POST /v1/web/fetch` (ਸਕ੍ਰੈਪ) ਪ੍ਰਤੀ ਪ੍ਰਦਾਤਾ ਨੂੰ ਕਾਲ ਕਰਦਾ ਹੈ।

## ਪ੍ਰਦਾਤਾ ਕੈਟਾਲਾਗ

`ProviderCatalog.tsx` `GET /api/search/providers` ਤੋਂ ਪੂਰੀ ਪ੍ਰਦਾਤਾ ਸੂਚੀ ਨੂੰ ਉਜਾਗਰ ਕਰਦਾ ਹੈ (ਫਚ ਪ੍ਰਦਾਤਾਵਾਂ ਨੂੰ ਸ਼ਾਮਲ ਕਰਨ ਲਈ F4 ਵਿੱਚ ਵਿਸਤ੍ਰਿਤ):

| `kind` | `"search"` (24 ਪ੍ਰਦਾਤਾ) ਜਾਂ `"fetch"` (ਫਾਇਰਕ੍ਰੌਲ, ਜੀਨਾ-ਰੀਡਰ, ਟੈਵੀਲੀ-ਸਰਚ, ਟਿਨੀਫਿਸ਼, ਨਿੰਬਲ-ਸਰਚ, ਕੋਈ ਵੀ ਖੋਜ-ਖੋਜ, ਸਮਾਨਾਂਤਰ-ਖੋਜ, ਉਤਸੁਕ-ਖੋਜ) |

ਸਥਿਤੀ ਹੈ** ਬੇਨਤੀ ਸਮੇਂ 'ਤੇ ਲਿਆ ਗਿਆ** ਜਾਂਚ ਕਰਕੇ ਕਿ ਕੀ ਪ੍ਰਮਾਣ ਪੱਤਰ ਮੌਜੂਦ ਹਨ ਅਤੇ ਕੀ ਸਾਰੀਆਂ ਕੁੰਜੀਆਂ ਇਸ ਸਮੇਂ ਕੂਲਡਾਊਨ ਵਿੱਚ ਹਨ।

`codex-search` (Codex ਵੈੱਬ ਖੋਜ) ਦੀ ਆਪਣੀ ਕੋਈ ਕੁੰਜੀ ਨਹੀਂ ਹੈ: ਇਹ ਇੱਕ ਜੁੜੇ Codex (ChatGPT) ਖਾਤੇ ਦੀ ਮੁੜ ਵਰਤੋਂ ਕਰਦਾ ਹੈ, ਇਸਲਈ ਹਰੇਕ ਖੋਜ ChatGPT ਗਾਹਕੀ ਕੋਟਾ ਖਰਚ ਕਰਦੀ ਹੈ ਅਤੇ ਲਗਭਗ 10-40 ਸਕਿੰਟ ਲੈਂਦੀ ਹੈ। ਇਹ ਉਦੋਂ ਚਲਦਾ ਹੈ ਜਦੋਂ ਕੋਈ ਬੇਨਤੀ ਇਸਦਾ ਨਾਮ ਦਿੰਦੀ ਹੈ; ਸਵੈਚਲਿਤ ਚੋਣ ਲਈ `CODEX_SEARCH_AUTO_FALLBACK_ENABLED` ਵਿਸ਼ੇਸ਼ਤਾ ਫਲੈਗ ਦੀ ਲੋੜ ਹੁੰਦੀ ਹੈ (ਮੂਲ ਰੂਪ ਵਿੱਚ ਬੰਦ)।

## ਕੋਡ ਐਕਸਪੋਰਟ

`ExportCodeModal` (Playground Studio ਤੋਂ ਇੰਪੋਰਟ ਕੀਤਾ ਗਿਆ) + `codeExport.ts`, `/v1/search` ਅਤੇ `/v1/web/fetch`
ਦੋਵਾਂ ਕਾਲਾਂ ਲਈ curl / Python / TypeScript ਸਨਿੱਪਟ ਤਿਆਰ ਕਰਦੇ ਹਨ।
API ਕੁੰਜੀ ਲਈ ਪਲੇਸਹੋਲਡਰ ਹਮੇਸ਼ਾ `$OMNIROUTE_API_KEY` ਹੁੰਦਾ ਹੈ (D11, Playground Studio ਨਾਲ ਸਾਂਝਾ)।

## ਬੈਕਐਂਡ ਬਦਲਾਅ

ਇਸ ਵਿਸ਼ੇਸ਼ਤਾ ਲਈ ਸਿਰਫ਼ ਇੱਕ ਬੈਕਐਂਡ ਤਬਦੀਲੀ ਦੀ ਲੋੜ ਸੀ:

### ਵਿਸਤ੍ਰਿਤ `GET /api/search/providers`

`src/app/api/search/providers/route.ts` ਨੂੰ ਅੱਗੇ ਵਧਾਇਆ ਗਿਆ ਸੀ:

- ਐਰੇ ਵਿੱਚ ਹਰੇਕ ਪ੍ਰਾਪਤ ਕਰਨ ਵਾਲੇ ਪ੍ਰਦਾਤਾ (`firecrawl`, `jina-reader`, `tavily-search`, `tinyfish`, `nimble-search`, `anysearch-search`, `parallel-search`, `keenable-search`) ਨੂੰ ਸ਼ਾਮਲ ਕਰੋ।
- ਹਰ ਆਈਟਮ ਵਿੱਚ `kind: "search" | "fetch"` ਸ਼ਾਮਲ ਕਰੋ।
- ਲਾਈਵ ਕ੍ਰੈਡੈਂਸ਼ੀਅਲ ਸਥਿਤੀ ਤੋਂ ਲਿਆ ਗਿਆ `status: "configured" | "missing" | "rate_limited"` ਸ਼ਾਮਲ ਕਰੋ।
- — ਮੌਜੂਦਾ ਫੀਲਡਾਂ (`id`, `name`, ਆਦਿ) ਨੂੰ ਬਿਨਾਂ ਕਿਸੇ ਬਦਲਾਅ ਦੇ ਪਿੱਛੇ ਅਨੁਕੂਲਤਾ ਬਣਾਈ ਰੱਖੋ।
