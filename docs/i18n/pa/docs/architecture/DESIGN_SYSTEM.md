> `packages/ui-kit/UPSTREAM.md` ਵਿੱਚ ਪਿੰਨ ਕੀਤਾ ਗਿਆ ਹੈ ਅਤੇ `npm run check:ui-kit-snapshot` ਦੁਆਰਾ ਸੁਰੱਖਿਅਤ ਹੈ) ਵਜੋਂ ਵੈਂਡਰ ਕੀਤਾ ਗਿਆ ਹੈ। Light ਕੈਨੋਨੀਕਲ

## 1. ਚੀਜ਼ਾਂ ਕਿੱਥੇ ਰਹਿੰਦੀਆਂ ਹਨ

- **ਕਿੱਟ।** `packages/ui-kit/src` ਅੱਪਸਟ੍ਰੀਮ `src/` ਦੀ ਬਾਈਟ-ਦਰ-ਬਾਈਟ ਨਕਲ ਹੈ, ਜੋ
  `packages/ui-kit/UPSTREAM.md` ਵਿੱਚ ਪਿੰਨ ਕੀਤੇ ਕਮਿੱਟ ਉੱਤੇ ਹੈ (ਜੋ ਲਾਇਸੰਸ ਅਧਿਕਾਰ ਵੀ ਦਰਜ ਕਰਦਾ ਹੈ); `PATCHES.md` ਸਥਾਨਕ
  ਪੈਚਾਂ ਦੀ ਸੂਚੀ ਦਿੰਦਾ ਹੈ (ਕੋਈ ਨਹੀਂ)। ਇਸਨੂੰ ਸਰੋਤ ਦੇ ਤੌਰ 'ਤੇ ਵਰਤਿਆ ਜਾਂਦਾ ਹੈ, ਬਿਨਾਂ ਕਿਸੇ ਬਿਲਡ ਦੇ: `next.config.mjs` ਇਸਨੂੰ ਟ੍ਰਾਂਸਪਾਇਲ ਕਰਦਾ ਹੈ, ਅਤੇ
  `tsconfig.json` `@omniroute/ui-kit` → `packages/ui-kit/src` ਅਤੇ `@omniroute/ui-kit/*` →
  `packages/ui-kit/src/*` ਨੂੰ ਮੈਪ ਕਰਦਾ ਹੈ (`vitest.config.ts` ਅਤੇ `vitest.mcp.config.ts` ਉਹੀ ਅਲੀਅਸ ਰੱਖਦੇ ਹਨ)। ਕਿਸੇ
  ਕਿੱਟ ਕੰਪੋਨੈਂਟ ਨੂੰ ਇਸਦੇ ਸਬਪਾਥ (`@omniroute/ui-kit/table`, `@omniroute/ui-kit/page-header`…) ਰਾਹੀਂ ਇੰਪੋਰਟ ਕਰੋ, ਕਦੇ ਵੀ
  `@omniroute/ui-kit` ਬੈਰਲ ਰਾਹੀਂ ਨਹੀਂ: ਬੈਰਲ ਹਰ ਕੰਪੋਨੈਂਟ (ਡੇਟ ਪਿੱਕਰ ਸਮੇਤ)
  ਨੂੰ ਹਰ ਇੰਪੋਰਟਰ ਵਿੱਚ ਖਿੱਚ ਲੈ ਜਾਂਦਾ ਹੈ। ਕਿੱਟ ਸਟਾਇਲਸ਼ੀਟ `src/app/globals.css` ਰਾਹੀਂ ਦਾਖਲ ਹੁੰਦੀ ਹੈ
  (`@import "../../packages/ui-kit/src/ci-ui.css"`)।
- **ਟੋਕਨ।** `packages/ui-kit/src/ci-tokens.css` `--ci-*` ਟੋਕਨਾਂ ਦੀ ਘੋਸ਼ਣਾ ਕਰਦਾ ਹੈ; `src/app/globals.css`
  ਉਨ੍ਹਾਂ ਨੂੰ ਪੁਰਾਣੇ OmniRoute ਨਾਵਾਂ (`--color-*`, `--radius-*`, `--font-sans`/`--font-mono`,
  `--table-*`, `--orch-status-*`, `--color-fd-*`) ਨਾਲ ਜੋੜਦਾ ਹੈ, ਤਾਂ ਜੋ ਮੌਜੂਦਾ `var(--color-*)` ਰੀਡ ਅਤੇ Tailwind
  ਯੂਟਿਲਿਟੀਆਂ ਕੰਮ ਕਰਦੀਆਂ ਰਹਿਣ। ਨਵਾਂ ਕੋਡ Tailwind ਯੂਟਿਲਿਟੀਆਂ (`bg-surface`, `text-text-muted`,
  `border-border`, `text-success`, `bg-success-bg`, `bg-chart-1`…) ਜਾਂ ਕਿੱਟ ਕਲਾਸਾਂ ਦੀ ਵਰਤੋਂ ਕਰਦਾ ਹੈ — ਕਦੇ ਵੀ ਹੈਕਸ ਵੈਲਯੂ
  ਨਹੀਂ (`tests/unit/design-kit-bridge.test.ts` ਇਸ ਬ੍ਰਿਜ ਨੂੰ ਲਾਗੂ ਕਰਦਾ ਹੈ)। `text-primary`
  `--text-color-primary` ਰਾਹੀਂ `--color-primary-ink` ਵਿੱਚ ਹੱਲ ਹੁੰਦਾ ਹੈ (ਲਾਈਟ ਵਿੱਚ lime-800, ਡਾਰਕ ਵਿੱਚ ਲਾਈਮ ਐਕਸੈਂਟ), ਇਸ ਲਈ
  ਪ੍ਰਾਇਮਰੀ ਟੈਕਸਟ ਪੜ੍ਹਨਯੋਗ ਰਹਿੰਦਾ ਹੈ ਜਦਕਿ `bg-primary`/`border-primary` ਲਾਈਮ ਸਤਹ ਬਣਾਈ ਰੱਖਦੇ ਹਨ। ਚਾਰਟ ਸੀਰੀਜ਼
  `--color-chart-1` … `--color-chart-5` ਵਰਤਦੀਆਂ ਹਨ।
- **ਥੀਮ।** `<html className="ci-theme">` (`src/app/layout.tsx`) ਡੌਕਿਊਮੈਂਟ ਨੂੰ ਕਿੱਟ ਥੀਮ ਵਿੱਚ ਸ਼ਾਮਲ ਕਰਦਾ ਹੈ।
  ਤਰਜੀਹ `light`, `dark` ਜਾਂ `system` ਹੈ (`src/shared/constants/appConfig.ts` ਵਿੱਚ `THEME_CONFIG.defaultTheme = "system"`; `system` `prefers-color-scheme` ਦੀ ਪਾਲਣਾ ਕਰਦਾ ਹੈ)।
  `src/store/themeStore.ts` ਵਿੱਚ `applyTheme()` (ਜਿਸਦੀ ਨਕਲ `src/app/layout.tsx` ਦੀ ਇਨਲਾਈਨ ਬੂਟਸਟ੍ਰੈਪ ਸਕ੍ਰਿਪਟ ਕਰਦੀ ਹੈ, ਜੋ
  ਹਾਈਡ੍ਰੇਸ਼ਨ ਤੋਂ ਪਹਿਲਾਂ ਚੱਲਦੀ ਹੈ) `data-theme="dark"|"light"` ਸੈੱਟ ਕਰਦਾ ਹੈ ਅਤੇ `<html>` ਉੱਤੇ `.dark` ਕਲਾਸ ਨੂੰ ਇਕੱਠੇ
  ਟੌਗਲ ਕਰਦਾ ਹੈ।
  ਕਿੱਟ ਦਾ ਡਾਰਕ ਟੋਕਨ ਸੈੱਟ `data-theme="dark"` ਉੱਤੇ ਕੁੰਜੀਬੱਧ ਹੈ (`packages/ui-kit/src/ci-tokens.css`);
  OmniRoute ਦੇ ਆਪਣੇ ਡਾਰਕ ਓਵਰਰਾਈਡ (`globals.css` ਵਿੱਚ `.dark` ਬਲਾਕ) ਅਤੇ ਪੁਰਾਣੀਆਂ Tailwind `dark:`
  ਯੂਟਿਲਿਟੀਆਂ `.dark` ਕਲਾਸ ਉੱਤੇ ਕੁੰਜੀਬੱਧ ਹਨ। ਕੋਈ ਐਕਸੈਂਟ ਰੰਗ ਪ੍ਰੀਸੈੱਟ ਨਹੀਂ ਹਨ: ਐਕਸੈਂਟ ਹਮੇਸ਼ਾ
  ਕਿੱਟ ਤੋਂ ਆਉਂਦਾ ਹੈ, ਅਤੇ ਕਿਸੇ ਪੁਰਾਣੇ ਬਿਲਡ ਤੋਂ ਪਰਸਿਸਟ ਕੀਤਾ ਪ੍ਰੀਸੈੱਟ ਸਟੋਰ ਲੋਡ ਹੋਣ ਵੇਲੇ ਛੱਡ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ।
- **ਕੰਪੋਨੈਂਟ (ਐਡਾਪਟਰ)।** `src/shared/components/index.tsx` OmniRoute ਕੰਪੋਨੈਂਟ API ਨੂੰ ਕਾਇਮ ਰੱਖਦਾ ਹੈ (ਉਹੀ
  ਨਾਂ, ਡਿਫੌਲਟ ਐਕਸਪੋਰਟ ਅਤੇ ਪ੍ਰੌਪਸ), ਅਤੇ ਇਸਦੇ ਪਿੱਛੇ ਮੌਜੂਦ ਪ੍ਰਾਇਮਿਟਿਵ ਕਿੱਟ ਉੱਤੇ ਐਡਾਪਟਰ ਹਨ: ਫਾਰਮ
  (`Button`, `Input`, `Textarea`, `Checkbox`, `Select`, `Toggle`, `Badge`, `Card`), ਓਵਰਲੇਅ ਅਤੇ ਫੀਡਬੈਕ
  (`Modal`/`ConfirmModal`, `Tooltip`/`InfoTooltip`, `NotificationToast`, `EmptyState`, `Loading`),
  ਢਾਂਚਾ (`Collapsible`, `CollapsibleSection`, `SegmentedControl`, `Breadcrumbs`, `Avatar`) ਅਤੇ ਟੇਬਲ
  (`DataTable`, `FilterBar`, `ColumnToggle`, `FilterPills`, `PresetSlider`)। ਇੱਕ ਐਡਾਪਟਰ ਕਿੱਟ
  ਕੰਪੋਨੈਂਟ ਨੂੰ ਸਬਪਾਥ ਰਾਹੀਂ ਇੰਪੋਰਟ ਕਰਦਾ ਹੈ ਅਤੇ ਪੁਰਾਣੇ ਪ੍ਰੌਪਸ ਨੂੰ ਇਸ ਉੱਤੇ ਮੈਪ ਕਰਦਾ ਹੈ — ਉਦਾਹਰਣ ਲਈ `Button variant="primary"`
  ਕਿੱਟ ਦਾ `default` ਬਟਨ ਹੈ (`--ci-button-primary-*`: ਲਾਈਟ ਵਿੱਚ ਉਲਟ ਸਤਹ, ਡਾਰਕ ਵਿੱਚ ਆਪਣੇ
  `--ci-color-accent-foreground` ਇੰਕ ਵਾਲਾ ਐਕਸੈਂਟ), `danger` `destructive` ਹੈ, ਅਤੇ `warning` `outline` ਨਾਲ ਨਾਲ
  `.ci-button--warning` ਐਕਸਟੈਂਸ਼ਨ ਹੈ। `globals.css` (`@layer components`) ਦੇ ਅਖੀਰ ਵਿੱਚ ਮੌਜੂਦ
  `.ci-button--warning` ਅਤੇ `.ci-badge[data-tone]` ਨਿਯਮ ਕਿੱਟ ਕਲਾਸਾਂ ਦੇ ਉੱਪਰ OmniRoute ਐਕਸਟੈਂਸ਼ਨ ਹਨ।
  `tests/unit/ui/adapters/*.test.tsx` ਹਰ ਐਡਾਪਟਰ ਨੂੰ ਪਿੰਨ ਕਰਦਾ ਹੈ।
- **ਸ਼ੈੱਲ।** `src/app/(dashboard)/layout.tsx` `DashboardLayout` ਨੂੰ ਰੈਂਡਰ ਕਰਦਾ ਹੈ, ਜੋ
  `src/shared/components/layouts/DashboardShell.tsx` ਨੂੰ ਰੈਂਡਰ ਕਰਦਾ ਹੈ: ਕਿੱਟ `SidebarProvider` / `Sidebar` /
  `SidebarInset` (`packages/ui-kit/src/sidebar.tsx`), ਨਾਲ OmniRoute ਦੀ ਨੈਵੀਗੇਸ਼ਨ ਲੌਜਿਕ
  `src/shared/components/Sidebar.tsx` ਵਿੱਚ। `#main-content` ਵੱਲ ਇੱਕ "ਸਮੱਗਰੀ ਵੱਲ ਜਾਓ" ਲਿੰਕ ਪਹਿਲਾ ਫੋਕਸਯੋਗ
  ਤੱਤ ਹੈ। `src/shared/components/Header.tsx` ਕਿੱਟ `SidebarTrigger` (ਸ਼ੈੱਲ ਦਾ ਇਕਲੌਤਾ ਸਾਈਡਬਾਰ
  ਟੌਗਲ), Keak `ProductSwitcher` ਅਤੇ ਕਮਾਂਡ-ਪੈਲੇਟ ਓਪਨਰ ਰੱਖਦਾ ਹੈ; ਇਹ ਰੂਟ ਟਾਈਟਲ ਸਿਰਫ਼ ਉਦੋਂ ਤੱਕ ਦਿਖਾਉਂਦਾ ਹੈ
  ਜਦੋਂ ਤੱਕ `#main-content` ਅੰਦਰ ਕੋਈ ਕਿੱਟ `PageHeader` (`.ci-page-header`) ਮਾਊਂਟ ਨਹੀਂ ਹੁੰਦਾ, ਤਾਂ ਜੋ ਆਪਣੇ
  `PageHeader` ਵਾਲੇ ਪੇਜ ਵਿੱਚ ਇੱਕ ਹੀ `h1` ਹੋਵੇ। `src/shared/components/CommandPalette.tsx` ਇੱਕ ਕਿੱਟ `Dialog` ਹੈ।
- **ਆਈਕਨ।** `<Icon name="material_name">` (`src/shared/components/Icon.tsx`) ਨਾਮ ਨੂੰ (ਸਕ੍ਰੀਨਾਂ ਵਲੋਂ ਵਰਤੀ ਜਾਂਦੀ
  Material Symbols ਸ਼ਬਦਾਵਲੀ) `ICON_MAP` (`src/shared/constants/iconMap.ts`) ਰਾਹੀਂ ਇੱਕ
  Lucide ਗਲਿਫ਼ ਵਿੱਚ ਹੱਲ ਕਰਦਾ ਹੈ। Material Symbols ਫੋਂਟ ਅਤੇ ਪੈਕੇਜ ਹੁਣ ਨਹੀਂ ਰਹੇ: ਨਕਸ਼ੇ ਵਿੱਚੋਂ ਗੈਰਹਾਜ਼ਰ ਨਾਮ
  ਇੱਕ ਨਿਰਪੱਖ ਪਲੇਸਹੋਲਡਰ ਗਲਿਫ਼ (`data-icon-missing="true"`) ਰੈਂਡਰ ਕਰਦਾ ਹੈ ਅਤੇ ਪ੍ਰੋਡਕਸ਼ਨ ਤੋਂ ਬਾਹਰ
  ਕੰਸੋਲ ਚੇਤਾਵਨੀ ਲੌਗ ਕਰਦਾ ਹੈ।

## 3. ਸਕਰੀਨ ਜੋੜਨਾ

   ਕੰਪੋਨੈਂਟ ਵਰਤੋ (`Table`/`TableScrollArea`/`DataTableShell`, `Field`, `Alert`, `Tabs`, `RadioGroup`,
   `Slider`…)।

   ਹੈ; `npm run gen:icon-map` ਅਜੇ ਵੀ ਗੈਰਹਾਜ਼ਰ ਨਾਵਾਂ ਦੀ ਸੂਚੀ ਦਿੰਦਾ ਹੈ।
4. ਰੰਗ: ਸੀਮੈਂਟਿਕ ਯੂਟਿਲਿਟੀਆਂ (`text-success`, `bg-warning-bg`, `border-border`…) ਅਤੇ ਚਾਰਟ ਸੀਰੀਜ਼ ਲਈ
   `var(--color-chart-N)`; ਕੋਈ ਹੈਕਸ ਮੁੱਲ ਨਹੀਂ ਅਤੇ ਕੋਈ ਅਜਿਹੇ `dark:` ਵੇਰੀਐਂਟ ਨਹੀਂ ਜੋ ਸਿਰਫ਼ ਰੰਗ ਨੂੰ ਦੁਹਰਾਉਂਦੇ
   ਹੋਣ।
5. ਟੈਕਸਟ: ਹਰ ਸਟ੍ਰਿੰਗ, ਸਮੇਤ ਉਹ ਲੇਬਲ ਜੋ ਤੁਸੀਂ ਕਿੱਟ ਕੰਪੋਨੈਂਟਸ ਨੂੰ ਪਾਸ ਕਰਦੇ ਹੋ, `useTranslations` ਤੋਂ ਆਉਂਦੀ ਹੈ।

## 4. ਅਡੈਪਟਰ ਜੋੜਨਾ ਜਾਂ ਬਦਲਣਾ

1. `src/shared/components/index.tsx` ਦਾ ਪਬਲਿਕ API ਕਾਇਮ ਰੱਖੋ: ਉਹੀ ਐਕਸਪੋਰਟ ਨਾਮ, ਡਿਫੌਲਟ ਐਕਸਪੋਰਟਸ ਅਤੇ
   ਸਵੀਕਾਰ ਕੀਤੇ props। ਅਡੈਪਟਰ ਦੇ ਅੰਦਰ legacy props ਨੂੰ ਕਿੱਟ 'ਤੇ ਮੈਪ ਕਰੋ (ਦੇਖੋ `Button.tsx`: `VARIANT_TO_KIT`,

## 5. ਕਿੱਟ ਅੱਪਡੇਟ ਕਰਨਾ

`scripts/dev/sync-ui-kit.sh <commit> [clone]` ਉਸ commit 'ਤੇ ਮੌਜੂਦ upstream `src/` ਨੂੰ
`packages/ui-kit/src` ਵਿੱਚ ਕਾਪੀ ਕਰਦਾ ਹੈ ਅਤੇ ਇਕੋ ਇੱਕ ਮਨਜ਼ੂਰਸ਼ੁਦਾ ਤਬਦੀਲੀ ਲਾਗੂ ਕਰਦਾ ਹੈ (ਇਹ relative imports ਤੋਂ `.js` ਸਫਿਕਸ ਹਟਾ ਦਿੰਦਾ ਹੈ)। ਫਿਰ: `git diff packages/ui-kit` ਦੀ ਸਮੀਖਿਆ ਕਰੋ, ਦੋਵੇਂ ਥੀਮਾਂ ਵਿੱਚ ਪ੍ਰੋਵਾਈਡਰਾਂ, ਸੈਟਿੰਗਾਂ, ਕੰਬੋ,
ਵਰਤੋਂ ਅਤੇ ਐਂਡਪੌਇੰਟ ਦੀ ਵਿਜ਼ੂਅਲ ਜਾਂਚ ਕਰੋ, `npm run check:ui-kit-snapshot` ਅਤੇ `npm run test:vitest:ui` ਚਲਾਓ, ਅਤੇ
upstream changelog ਦੇ ਨਾਲ PR ਖੋਲ੍ਹੋ।
