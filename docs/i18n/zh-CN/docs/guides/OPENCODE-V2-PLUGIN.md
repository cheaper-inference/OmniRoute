`@omniroute/opencode-plugin-v2` 会将你的整个 OmniRoute 目录（模型、组合和自动组合）添加到 OpenCode v2 的模型选择器中，并提供显示名称、定价和免费额度预算。

它是一个独立于 `@omniroute/opencode-plugin` 的包，因为 OpenCode v1 和 v2 使用不同的契约加载插件。请选择与你的 OpenCode 主版本匹配的插件；二者之间不共享任何内容，因此升级其中一个绝不会强制升级另一个。

## 要求

- OpenCode v2。
- 可访问的 OmniRoute 网关（默认为 `http://localhost:20128`）。
- Node.js 22 或 24。

## 安装

将插件添加到 `opencode.json`：

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

随后，模型将显示为 `omniroute/<provider>/<model>`；`providerId` 决定该前缀，以及 OpenCode 用于存储凭据的集成 ID。

## 凭据

插件会按以下顺序在三个位置查找网关密钥：

1. **你在 OpenCode 中连接的凭据。** 插件会注册一个集成，因此 OpenCode 自身的身份验证流程可以存储该密钥。不会有任何内容写入 `opencode.json`——请优先使用此方式。
2. 插件选项中的 `apiKey`，用于按项目覆盖。它会将密钥放入你可能会提交的文件中。
3. 环境中的 `OMNIROUTE_API_KEY`。

如果这三项都没有，目录将为空，并且插件会在启动时提示一次，而不是只留下一个没有任何提示的空白选择器。

### 管理令牌是另一种密钥

组合、提供者运行状况和补充信息（显示名称、定价、免费额度预算）来自网关的 `/api/*` 端点。大多数部署使用**管理**令牌而不是推理密钥来保护这些端点：

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<管理读取令牌>"
}
```

如果未设置，`managementReadToken` 会回退到 `apiKey`。当网关拒绝该回退值时，目录仍会发布，但只包含原始模型 ID，不包含显示名称、规范别名去重、定价和组合。发生这种情况时，插件会针对每个端点警告一次，并指出端点和缺失的内容——因此，选择器功能降级的原因绝不会令人费解。

| -------------------------------- | ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `providerId`                     | `"omniroute"`                                  | 提供者 ID、集成 ID，以及模型显示时使用的前缀                                                                                                                                                                                                                                            |

| `timeouts`                       | falls back to `timeoutMs`                      | 每个端点的毫秒级预算：`models`、`combos`、`autoCombos`、`enrichment`                                                                                                                                                                                                                    |

| `visibleModels` / `hiddenModels` | `[]`                                           | 精确匹配或后缀匹配的允许列表；拒绝规则优先；`*` 发布完整目录（其他筛选器仍然生效）                                                                                                                                                                                                      |

## 目录如何保持最新

目录会延迟加载，并按 `modelCacheTtlMs` 缓存；磁盘快照则会在网关无法访问时保留上次已知的目录——服务中断不会带来任何影响，除了无法获取最新内容。模型和组合项一到达就会立即发布；自动组合、提供者列表和增强覆盖层也会在各自到达时并入，因此某个缓慢的端点不会拖住整个选择器。

名称遵循 `Provider - Model[ (Editor)][ · budget][ (route)]`：只要 ID 中包含提供者，就会显示提供者（不含斜杠的 ID 不显示前缀）；前导 `🆓` 表示免费条目，其免费层级额度会保留为 `· 1M tokens/month` 后缀；显式 `Editor: Model` 名称中的编辑器会移至末尾括号中（不会根据其他名称猜测编辑器）；组合项显示为 `combo - <slug>`，不带免费图标。两个条目名称相同时，会添加路由后缀——`(no-think)`——以便区分。`providerTag`（默认为 `true`）用于切换末尾的编辑器括号。

没有手动刷新命令：OpenCode v2 命令是提示模板，而不是回调，因此插件无法提供此类命令。刷新会遵循 TTL；仅当目录或覆盖层确实发生变化时，才会要求主机重新加载，并且每次刷新最多请求一次。

## Gemini 上的工具调用

如果工具声明包含 `$schema` 或 `additionalProperties`，Gemini 会拒绝整个请求，并返回 `400 INVALID_ARGUMENT`。该插件会从发往此提供者 Gemini 模型的工具 schema 中移除这些关键字，而其他所有请求均保持不变。包含 `$ref` 的工具会原样转发，而不会进行清理，因为移除该引用会将 schema 放宽为“接受任何内容”。

设置 `"geminiSanitization": false` 可将其关闭。

## 故障排除

| 症状                              | 原因                                                                                  |
| --------------------------------- | ------------------------------------------------------------------------------------- |
| Picker 中不显示 OmniRoute 模型    | 未解析到密钥（检查启动警告），或网关无法访问                                          |
| 显示原始模型 id、没有组合项或价格 | 管理端点拒绝了令牌 — 设置 `managementReadToken`                                       |
| `freeOnly` 目录较短或为空         | 没有管理令牌，或令牌被拒绝 — 在主机日志中读取刷新摘要行（`unmatched-free` 计数）      |
| 会话固定到 `opencode-<id>/...`    | v1 插件发布了 `opencode-<id>`；v2 直接发布 `<id>`，因此请在 `<id>/...` 下重新选择模型 |

环境变量必须传递到 opencode 服务器进程：当主机作为服务运行时，运行
`opencode models` 的 shell 与服务器环境不同，因此请在服务器读取密钥的位置导出该密钥。
