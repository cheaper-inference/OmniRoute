## 功能简介

OmniRoute 将 **Obsidian** 仓库连接为**上下文源**——这是一个本地 Markdown
知识库，智能体通过内置 MCP 服务器对其进行读写。此集成与运行在
桌面应用中的 **Obsidian Local REST API** 社区插件通信，因此智能体可以搜索笔记、
读取/写入/修补文件、列出仓库内容、处理每日/每周周期笔记、管理标签、运行 Obsidian
命令，以及（可选）协调桌面端↔移动端的双向仓库同步。

客户端（`src/lib/obsidian/api.ts`）对 Local REST API 进行了封装，提供：

- 针对临时性 `5xx` 错误的**退避重试**，并通过 `AbortController` 实现**30 秒超时**。
- **类型化错误分类**——`ObsidianAuthError`（401/403）、
  `ObsidianNotFoundError`（404）、`ObsidianServerError`（5xx）、`ObsidianTimeoutError`。
- 友好的**“无法连接到 Obsidian”提示**，明确指出常见的端口错误
  （HTTP 使用 `27123`，**而不是** `27124` 上的 MCP 端点），并说明 Tailscale 地址格式。
- 仓库相对路径的**路径编码**，确保包含空格/斜杠的笔记路径可安全使用。

## 设置

Obsidian 令牌或基础 URL **没有对应的环境变量**——二者均通过
`src/lib/db/obsidian.ts` 存储在 SQLite 的 `key_value` 表（命名空间为 `obsidian`）中。
令牌会进行**静态加密**（AES-256-GCM，并提供明文向后兼容回退）。可通过 Endpoint
仪表板的 **Context Sources** 选项卡（`ObsidianSourceCard`）或设置 REST API 进行配置。

> [!IMPORTANT]
> 必须安装并运行 **Obsidian Local REST API** 插件。其 REST
> 接口监听 **HTTP `127.0.0.1:27123`**（默认基础 URL）。端口 `27124`
> 是一个_独立的_ MCP/HTTPS 端点，设置路由会明确拒绝该端口。
> 如果从其他设备连接，请使用 `http://<tailscale-ip>:27123`。

### 配置键（SQLite `key_value`，命名空间为 `obsidian`）

| 键                | 用途                                             | 是否加密 |
| ----------------- | ------------------------------------------------ | -------- |
| `api_key`         | Local REST API 持有者令牌                        | 是       |
| `base_url`        | REST 基础 URL（默认为 `http://127.0.0.1:27123`） | 否       |
| `vault_path`      | 仓库目录的绝对路径（用于同步）                   | 否       |
| `webdav_username` | 生成的 WebDAV 用户名（仓库同步）                 | 否       |
| `webdav_password` | 生成的 WebDAV 密码（仓库同步）                   | 是       |
| `webdav_enabled`  | 是否启用 WebDAV 仓库同步                         | 否       |

### 通过 REST 配置

```bash
# 保存并验证 Local REST API 令牌（POST 通过状态检查进行验证）
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# 检查连接状态（返回 connected、hasToken、baseUrl、vaultPath）
curl http://localhost:20128/api/settings/obsidian

# 断开连接（清除已存储的令牌）
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

所有方法均要求通过仪表板身份验证。`POST` 会拒绝端口为 `27124` 的任何 URL，
并会在持久化之前，通过调用 Local REST API 状态端点来验证令牌。

### WebDAV 仓库同步

`src/app/api/settings/obsidian/webdav/route.ts` 管理可选的、由 WebDAV 支持的
仓库同步（由 `src/lib/obsidianSync.ts` 驱动）。启用后，它会将 OmniRoute 指向
本地仓库目录，并生成一对随机的 WebDAV 用户名和密码：

```bash
# 为仓库目录启用 WebDAV 同步（生成用户名和密码）
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# 获取 WebDAV 同步状态（仅在启用时返回凭据）
curl http://localhost:20128/api/settings/obsidian/webdav

# 禁用 WebDAV 同步（清除凭据和托管的 .stignore）
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### 安全与交通

WebDAV身份验证强制执行每个 IP 的故障跟踪和锁定（60 秒窗口内 10 次失败尝试会触发`429 Too Many Requests`和`Retry-After`的 5 分钟锁定）。由于WebDAV传输基本身份验证凭据，因此强烈建议在访问环回外部的WebDAV端点时终止TLS （或通过Tailscale或Cloudflare Tunnel等安全隧道进行路由）。

### 按 API 密钥配置上下文源（可选）

可以通过 `api_key_context_sources` 表按 **API 密钥**限定 Obsidian 配置的作用域
（`src/lib/db/apiKeyContextSources.ts`）。当 MCP 调用携带经过身份验证的 API
密钥 ID 时，`getObsidianConfigForApiKey()` 会优先使用该密钥自己的令牌、基础 URL
和仓库路径（`source: "api_key"`），否则回退到全局配置（`source: "global"`）。

非同步 MCP 工具在读取此配置前，需要解析出调用方身份。没有身份的调用方会收到
`Obsidian API token not configured`，且不会发送仓库请求。HTTP 调用方通过其请求凭据
解析身份；stdio 调用方可以通过 `OMNIROUTE_API_KEY` 或 `ROUTER_API_KEY` 解析身份。
无法解析身份的 HTTP 调用方不能继承服务器的环境身份。仅有占位符 ID 并不能授权访问；
仍支持能够解析为 `env-key` 的有效环境凭据。没有按密钥配置 Obsidian 的已验证密钥仍会
回退到全局配置。四个 `obsidian_sync_*` 工具继续使用各自独立的同步令牌行为。

## MCP工具 (22)

在`open-sse/mcp-server/tools/obsidianTools.ts`中定义。 token/base-URL每次调用都会解析（首先是每个 API 密钥，然后是全局）。影响OmniRoute的工具**同步服务器**（四个`obsidian_sync_*`工具）还需要在OmniRoute设置中配置同步身份验证令牌。

### 阅读工具（`read:obsidian`）

| 工具                         | 描述                                                                          |
| ---------------------------- | ----------------------------------------------------------------------------- |
| `obsidian_check_status`      | 检查本地REST API是否可达且已通过认证。                                        |
| `obsidian_search_simple`     | 笔记内容全文检索；返回带有文件路径的片段。                                    |
| `obsidian_search_structured` | 使用JSON逻辑表达式（and/or/regex/path过滤器）进行搜索。                       |
| `obsidian_read_note`         | 按保管库相对路径阅读注释；可选的特定heading/block/frontmatter.                |
| `obsidian_list_vault`        | 列出 Vault 中的文件和目录（条目树）。                                         |
| `obsidian_get_document_map`  | 获取笔记的标题结构作为标题→行号的映射。                                       |
| `obsidian_get_note_metadata` | 获取 frontmatter、标签、链接、 char/word计数，而无需完整内容。                |
| `obsidian_get_active_file`   | 获取Obsidian中当前活动文件的路径+内容。                                       |
| `obsidian_get_periodic_note` | 获取某个日期的daily/weekly/monthly定期记录（如果省略，则为今天）。            |
| `obsidian_get_tags`          | 列出所有保管库标签及其频率。                                                  |
| `obsidian_list_commands`     | 列出可用的Obsidian命令IDs （与`obsidian_execute_command`一起使用）。          |
| `obsidian_sync_status`       | OmniRoute同步服务器状态：正在运行、保管库名称、端口、正常运行时间、上次同步。 |
| `obsidian_sync_conflicts`    | 列出未解决的同步冲突（路径、冲突路径、检测到）。                              |

### 编写工具（`write:obsidian`）

| 工具                             | 描述                                                                  |
| -------------------------------- | --------------------------------------------------------------------- |
| `obsidian_write_note`            | 使用给定的 Markdown 内容创建或覆盖笔记。                              |
| `obsidian_append_note`           | 将内容附加到注释；可选择特定的heading/block.                          |
| `obsidian_patch_note`            | 在标题、区块或前沿领域进行外科手术append/prepend/replace 。           |
| `obsidian_delete_note`           | 从保管库中永久删除注释。                                              |
| `obsidian_move_note`             | 在库中移动或重命名注释。                                              |
| `obsidian_execute_command`       | 通过命令ID执行Obsidian命令。                                          |
| `obsidian_open_file`             | 在Obsidian中打开文件（如果不存在则创建它）。                          |
| `obsidian_sync_trigger`          | 立即触发双向桌面↔移动保管库同步。                                     |
| `obsidian_sync_resolve_conflict` | 解决同步冲突：保留`local` （移动）、 `remote` （桌面）或`keep-both`。 |

> [!NOTE]
> `obsidian_patch_note`目标接受`heading | block | frontmatter`的`targetType`和`append | prepend | replace`的`operation` ，并带有可选的`createTargetIfMissing`。四个`obsidian_sync_*`工具与本地同步服务器（默认为`http://127.0.0.1:27781` ）通信并需要同步令牌。

### 范围

读取工具需要`read:obsidian`；编写工具需要`write:obsidian`。强制执行与Notion —相同，由`open-sse/mcp-server/server.ts`中的`withScopeEnforcement()`处理，在`OMNIROUTE_MCP_ENFORCE_SCOPES=true`上进行门控，并对API密钥缺少`manage`/`admin`的HTTP/SSE调用者强制执行，允许的范围源自`OMNIROUTE_MCP_SCOPES`或API密钥的范围上下文。参见[MCP-SERVER.md](./MCP-SERVER.md) 。

## 端点

| 方法     | 路径                            | 用途                                                 |
| -------- | ------------------------------- | ---------------------------------------------------- |
| `GET`    | `/api/settings/obsidian`        | 返回 `{ connected, hasToken, baseUrl, vaultPath }`。 |
| `POST`   | `/api/settings/obsidian`        | 保存并验证令牌（拒绝端口 `27124`）。                 |
| `DELETE` | `/api/settings/obsidian`        | 断开连接（清除已存储的令牌）。                       |
| `GET`    | `/api/settings/obsidian/webdav` | WebDAV 同步状态和凭据（启用期间）。                  |
| `POST`   | `/api/settings/obsidian/webdav` | 为某个仓库目录启用 WebDAV 同步。                     |
| `DELETE` | `/api/settings/obsidian/webdav` | 禁用 WebDAV 同步。                                   |

> 这些是仪表板设置路由。仓库本身通过 Obsidian
> Local REST API（配置的 `base_url`）以及上述 MCP 工具进行访问——不存在公开的
> `/v1` Obsidian 代理端点。

## 使用场景

- **基于仓库内容的回答** — 先使用 `obsidian_search_simple` / `obsidian_search_structured`，
  然后使用 `obsidian_read_note`，让智能体根据你的真实笔记作答。
- **笔记撰写 / 日志记录** — 使用 `obsidian_write_note`、`obsidian_append_note` 或
  可进行精准修改的 `obsidian_patch_note`，将智能体输出、摘要或每日笔记
  （`obsidian_get_periodic_note`）记录到仓库中。
- **仓库导航** — 使用 `obsidian_list_vault`、`obsidian_get_document_map` 和
  `obsidian_get_tags`，在读取/写入之前探索结构。
- **Obsidian 自动化** — 使用 `obsidian_list_commands` + `obsidian_execute_command`
  让智能体驱动插件/命令；使用 `obsidian_open_file` 在 UI 中显示笔记。
- **移动端同步** — 启用 WebDAV 同步，然后使用 `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`
  协调桌面端↔移动端同步并解决冲突。
