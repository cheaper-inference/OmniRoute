## Bezplatné tokeny za mesiac: ~ 11,3 B podľa počtu ostatných · ~ 90 miliónov skutočných

</div>

> **~ 11,3 miliardy bezplatných tokenov / mesiac**<br/> <sub> sa počítalo tak, ako sa počítajú ostatné katalógy: každý riadok sa sčítal, vrátane ukončených ponúk </sub>
>
> **~ 90 miliónov dnes**<br/> <sub> každá zdieľaná kvóta sa počíta raz: čo môžete skutočne použiť </sub>
>
> **Všetko je tu zadarmo. Žiadny paywall.**<br/> ★ [Páči sa vám to? Zahviezdite nás na GitHub](https://github.com/cheaper-inference/OmniRoute)

Ostatné katalógy si účtujú od US USD ročne do US USD za doživotný prístup k živým údajom. Tu je všetko zadarmo. <sub> Ceny skontrolované 18. 11. 2026.</sub>

<sub>Katalóg bol naposledy kontrolovaný 23.11.2026. [Ako počítame →](docs/reference/FREE_TIERS.md#how-we-count)</sub>

> **Prineste si vlastné účty poskytovateľa.** Toto sú bezplatné úrovne tretích strán, nie symbolický grant od OmniRoute. Zaregistrujte sa, získajte poverenia tam, kde ich poskytovateľ požaduje, a pripojte tie, ktoré môžete použiť. Každý poskytovateľ si stanovuje vlastné limity, dostupnosť a podmienky.
>
> Ručné skladanie bezplatných úrovní znamená desiatky SDKs, desiatky limitov sadzieb a žiadnu jasnú predstavu o tom, čo vám zostáva. OmniRoute uchováva 214 riadkov katalógu s voľným prístupom a vypočítava skutočnú hodnotu z 12 oblastí so zverejnenou kvótou, pričom každá zdieľaná oblasť sa počíta raz. Kvóty, ktoré sa otvárajú až po kontrole regionálnej identity (dnes, ModelScope), sú zobrazené oddelene, +~ 6 miliónov po overení regionálnej identity, a nikdy sa nepridávajú k skutočnému údaju. To, čo zostalo, sa zobrazí na prístrojovej doske (`/dashboard/free-tiers`).

<img src="./docs/diagrams/works-zero-config.svg" width="100%" alt="Four steps to use OmniRoute. Install with npm install -g omniroute, run omniroute, connect a provider and create an API key in the dashboard, then call http://localhost:20128/v1 with model auto."/>

```bash
# After connecting a provider, create your OmniRoute key in Dashboard → API Keys:
curl http://localhost:20128/v1/chat/completions \

  -H "Content-Type: application/json" \
  -d '{"model":"auto","messages":[{"role":"user","content":"Hello!"}]}'
```

## Kombinácia: vlajková loď

1. **Začnite s `auto`.** Nastavte model vo svojom klientovi kompatibilnom s OpenAI. OmniRoute vytvára virtuálne kombo z pripojených poskytovateľov a boduje kandidátov naživo.
2. **Uložte si kombináciu pre väčšiu kontrolu.** Vyberte názov, cieľový zoznam a stratégiu a potom použite toto meno ako model. Stratégia stanovuje, ktorý cieľ ide ako prvý a ako sa skúša zvyšok.

Kombinácia prechádza medzi modelmi automaticky. Pri vyčerpaní kvóty, zlyhaní poskytovateľa alebo zablokovaní modelu skúša ďalší vhodný, zdravý cieľ.

### Zero-config: stačí použiť `auto`

```bash
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <your-omniroute-key>" \
  -H "Content-Type: application/json" \
  -d '{"model": "auto", "messages": [{"role": "user", "content": "Hello"}]}'
```

Varianty ladia váhy. Smerovanie podľa posledného známeho dobrého zostáva u posledného úspešného poskytovateľa, až kým nezlyhá, a potom sa znova vyhodnotí. `auto/fast` a `auto/cheap` vyjadrujú preferencie bez zaručenia najrýchlejšieho alebo najlacnejšieho modelu.

| Model ID            | Správanie                                                                                                                                                                                                                                                                     |
| :------------------ | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `auto`              | Vyvážené predvolené váhy.                                                                                                                                                                                                                                                     |
| `auto/fast`         | Uprednostňuje nízku latenciu a zdravie poskytovateľa.                                                                                                                                                                                                                         |
| `auto/cheap`        | Uprednostňuje nižšie katalógové ceny.                                                                                                                                                                                                                                         |
| `auto/coding`       | Kvalita na prvom mieste pri generovaní kódu.                                                                                                                                                                                                                                  |
| `auto/smart`        | Váhy na prvom mieste s 10 % prieskumom (predvolené 5 %).                                                                                                                                                                                                                      |
| `auto/lkgp`         | Explicitné smerovanie posledného známeho dobrého s rovnakými váhami ako `auto`.                                                                                                                                                                                               |
| `auto/subscription` | Používa iba kvótu plánu overeného naživo. Vráti HTTP 503, keď žiadna nie je k dispozícii, a zabráni záložnému účtu.                                                                                                                                                           |
| `auto/thrifty`      | Plan → keyless → free → lacný → premium. Môže dosiahnuť fakturované modely a vrátiť sa k plánu, keď to kvóta a cooldown dovolia.                                                                                                                                              |
| `auto/offline`      | Uprednostňuje priestor pre kvóty a limity sadzieb. Žiadosti stále smerujú k vašim poskytovateľom.                                                                                                                                                                             |
| `auto/chaos`        | Jeden model na poskytovateľa paralelne, štandardne až päť alebo desať pri konfigurácii. Jeden upstream hovor na model. Ak top model zlyhá, vráti odpoveď s najvyšším hodnotením alebo poslednú úspešnú odpoveď panelu. Použite `fusion` na syntetizovanie odpovedí so sudcom. |

Príklady kategórií a voliteľných vrstiev zahŕňajú `auto/coding:fast`, `auto/coding:free`, `auto/reasoning:pro` a `auto/vision`. Ak sa nezhoduje žiadny pripojený kandidát, požiadavka vráti HTTP 503 a skupina zostane úzka. [Sprievodca automatickým kombinovaním](./docs/routing/AUTO-COMBO.md) · [Smerovanie podľa predplatného](./docs/routing/SUBSCRIPTION_LADDER.md)

### Alebo si vytvorte vlastnú: 22 stratégií smerovania

```bash
omniroute combo create my-pool --strategy fill-first \
  --models "provider-a/model-1,provider-b/model-2"
```

### Odolnosť je zabudovaná: 3 nezávislé vrstvy

Poruchy sa riešia v troch rozsahoch, takže jeden zlý model nezruší svoj účet a jeden zlý účet nezruší svojho poskytovateľa.

<img src="./docs/diagrams/resilience-layers.svg" width="100%" alt="OmniRoute resilience: 3 independent self-healing layers, the right layer for the right failure. Layer 1, provider circuit breaker (whole provider): trips only on 408/500/502/503/504, opens after 8 failures for OAuth providers or 12 for API-key providers, resets after 60s or 30s into a HALF-OPEN probe, lazy recovery; while OPEN the combo reroutes to the next provider. Layer 2, connection cooldown (one key or account): base 5s OAuth or 3s API-key, exponential backoff with an anti-thundering-herd guard, success clears the error state; one cooling key is skipped while sibling keys keep serving. Layer 3, model lockout (one model): per-model 429, 404 or access denials lock just that model, never the whole connection. Terminal states (banned, expired, credits exhausted) wait for the operator; they are not cooldowns."/>

#### Ak je výpadok celého poskytovateľa

The** istič poskytovateľa** otvorí sa po 8 (OAuth) alebo 12 (kľúč API ) zlyhaniach so stavom 408, 500, 502, 503 alebo 504. Kombinácie preskočia daného poskytovateľa, kým je otvorený. Po 60 s alebo 30 s jedna požiadavka sondy rozhodne, či sa zatvorí.

#### Ak je jeden kľúč alebo účet obmedzený sadzbou

The** cooldown pripojenia** lavice iba toto spojenie, s exponenciálnym stiahnutím od 5 s (OAuth) alebo 3 s ( kľúč API ). Iné kľúče pre toho istého poskytovateľa sa naďalej zobrazujú.

#### Ak je jeden model odmietnutý

The** uzamknutie modelu** blokuje iba tento model na tomto pripojení po zamietnutí prístupu 429, 404 pre každý model. Ostatné modely na rovnakom pripojení naďalej slúžia.

Zakázané pripojenia, pripojenia s vypršanou platnosťou a bez kreditu sú terminálové stavy, nie cooldowny: čakajú, kým ich opravíte.

## Úplné CLI, MCP a A2A

> OmniRoute dodáva klienta príkazového riadku s** 91 príkazov najvyššej úrovne a skupín príkazov** (754 príkazov počítajúcich čiastkové príkazy), an**MCP server so 110 nástrojmi a 33 rozsahmi** a an**A2A agent so 6 schopnosťami** . Skripty, terminály a agenti AI môžu všetky prevádzkovať rovnakú bránu.

### Skutočné CLI, nielen `start`

```bash
omniroute                 # start the gateway and dashboard (port 20128)
omniroute setup           # guided first-run wizard
omniroute repl            # interactive chat in the terminal (/model /combo /skill /memory)
omniroute chat "hello"    # one-shot prompt; also reads --file or --stdin
omniroute doctor          # check config, database, ports, Node runtime and native deps
```

Globálny príznak `--output table|json|jsonl|csv` umožňuje použiť rovnaké príkazy zo skriptov a CI.

### Vzdialený režim: CLI na vašom notebooku, OmniRoute na serveri

Prihláste sa raz na vzdialený server. CLI ho uloží ako a** kontext** a neskoršie príkazy bežia na tomto serveri, kým neprepnete späť.

```bash
omniroute connect omniroute.example.com          # asks for the password, saves a scoped token as a context
omniroute models                                 # runs against the remote server
omniroute configure codex                        # picks a remote model, writes a local Codex profile
omniroute tokens create --name ci --scope read   # mint a narrower token for another machine
omniroute contexts use default                   # switch back to the local server
```

- **spustenie MCP nad HTTP je zakázané.** Zapnite ho pomocou `omniroute mcp enable --transport streamable-http` alebo zo stránky Koncové body ovládacieho panela. Naraz je aktívny jeden prenos HTTP : `streamable-http` slúži `/api/mcp/stream`, `sse` slúži `/api/mcp/sse`.

### Ako to funguje — pipeline, architektúra a matematika úspor

<img src="./docs/diagrams/compression-pipeline.svg" width="100%" alt="OmniRoute compression pipeline: an illustrative 10,000-token client request passes through 12 composable engines — Session-Dedup, CCR, Lite, RTK, Responses Tool Output, Headroom, Relevance, Caveman, Aggressive, LLMLingua-2, Ultra and OmniGlyph — and can reach the provider at about 1,080 tokens in the documented stacked example. Structured content is protected by preservation guards and per-step fidelity gates; explicit lossy or experimental modes may transform eligible content."/>

Predvolené skladané kombo spúšťa `RTK → Caveman`. Keď obe fungujú na rovnakom užitočnom zaťažení tool/context, zlúčenina úspory:

```txt
combined = 1 − (1 − RTK) × (1 − Caveman_input)
average  = 1 − (1 − 0.80) × (1 − 0.46) = 89.2%
range    = 78.4 – 94.6%
```

Sú to bloky kódu, URLs, JSON a štruktúrované dáta** vždy chránený** konzervačným motorom.

> **Prečo používať veľa žetónov, keď málo žetónov funguje?** Každá požiadavka prechádza kompresným potrubím OmniRoute** transparentne** — žiadne zmeny klienta. Teraz je to a** stoh 12 skladateľných motorov** ktoré bežia v poradí a miešajú a spájajú podľa smerovacieho komba — pričom stavajú na nápadoch od [RTK](https://github.com/rtk-ai/rtk), [Caveman](https://github.com/JuliusBrussee/caveman) (⭐ 90K +), [LLMLingua-2](https://github.com/microsoft/LLMLingua) a [Troglodita](https://github.com/leninejunior/troglodita) (PT-BR).

**🥟 Bun**

Štandardná `bun install` a globálna inštalácia (`bun install -g omniroute`) sú podporované prostredníctvom detekcie runtime Bun :

- **Vstavaná `bun:sqlite`** : OmniRoute používa vstavaný ovládač `bun:sqlite` Bun keď beží pod Bun, spadá späť na `better-sqlite3` na Node.js alebo `sql.js`.
- **Automatický výber balíka Webpack vo vývoji** : Vývoj (`bun run dev`) automaticky deteguje Bun a deaktivuje Turbopack v prospech Webpack, aby sa predišlo nekompatibilite natívnych väzieb V8. Produkčné zostavy (`bun run build`) sledujú `OMNIROUTE_USE_TURBOPACK` presne ako na Node: Turbopack predvolene, `OMNIROUTE_USE_TURBOPACK=0` na zostavenie s Webpack (`Dockerfile.bun` ho odkryje ako `--build-arg`).
- **Vyhradený Bun Dockerfile** : Viacstupňové `Dockerfile.bun` pre natívne produkčné nasadenia Bun (`docker build -f Dockerfile.bun -t omniroute:bun .`).

```bash
# Install and run with Bun
bun install
bun run dev
```

**⚡ Rýchlejšia / štíhlejšia inštalácia (preskočte natívnu zostavu)**

Natívny motor SQLite (`better-sqlite3`) je an** voliteľné** závislosť, takže globálna inštalácia nikdy neblokuje kompiláciu zo zdroja: používa vopred zostavený binárny súbor, keď sa zhoduje s vaším platform/Node, a inak sa transparentne vráti k čistému JS enginu (`node:sqlite` na Node 22 +, inak pribalený `sql.js` WASM) — nie sú potrebné žiadne nástroje na zostavovanie.

Ak chcete preskočiť po inštalácii** natívna rozcvička** úplne (CI, bezhlavé alebo pomalé stroje). Poznámka: týmto sa preskočí iba natívny krok zahrievania SQLite (`scripts/postinstall.mjs`); hák binary-copy/repair (`scripts/build/postinstall.mjs`) stále beží normálne:

```bash
OMNIROUTE_SKIP_POSTINSTALL=1 npm install -g omniroute   # CI=1 also skips it
```

Pre najrýchlejšiu inštaláciu uprednostňujte** pnpm** (obchod s adresou obsahu + pevné odkazy — pozri vyššie). Pre bezhlavý runtime bez palubnej dosky použite profil Docker `base` (vyššie) alebo [príručku Termux](docs/guides/TERMUX_GUIDE.md). CLI a webový dashboard sú obsluhované rovnakým procesom na jednom porte, takže dnes neexistuje samostatný balík iba pre CLI.

3. Vytvorte si pobočku funkcií (`git checkout -b feat/amazing-feature`)
4. Potvrdiť zmeny (`git commit -m 'feat: add amazing feature'`)
5. Tlačiť na pobočku (`git push origin feat/amazing-feature`)
6. Otvorte žiadosť o stiahnutie pomocou** základná = tá `release/vX.Y.Z` vetva**

Podrobné pokyny nájdete [CONTRIBUTING.md](CONTRIBUTING.md).

## Poďakovanie

OmniRoute stojí na pleciach obrov. Začalo to ako rozchod** [9 smerovač](https://github.com/decolua/9router)** a port TypeScript projektu Go** [CLIProxyAPI](https://github.com/router-for-me/CLIProxyAPI)** — a odtiaľ bol každý podsystém nižšie inšpirovaný projektom s otvoreným zdrojovým kódom, ktorý sa tam dostal ako prvý. Každý z nich vytvaroval konkrétny kus OmniRoute. Týmto im všetkým patrí naše poďakovanie. 🙏

> Počet hviezd ⭐ overený z 16. novembra 2026 GitHubREST API — týmto projektom ohodnotiť hviezdičkou. Počty sú presným dátumom a budú sa prirodzene meniť. GrokBridge vrátil HTTP 404 v ten deň; jeho priradenie sa zachová.
