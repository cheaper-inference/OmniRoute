> **Stav:** dashboard je postavený na **Keak CI UI Kit** (`@keak/cheaper-inference-ui-kit`), vložený
> ako súčasť workspace `packages/ui-kit` (`@omniroute/ui-kit`; upstream snapshot je zafixovaný v
> `packages/ui-kit/UPSTREAM.md` a kontrolovaný pomocou `npm run check:ui-kit-snapshot`). Kanonickou
> témou je svetlá; predvolená preferencia je `system`. Akcentovou farbou je Keak limetková (`--ci-color-accent`). Inter
> (letter-spacing 0, `--ci-letter-spacing-ui`) je rodina písiem pre UI, Instrument Serif iba pre veľký riedky
> text (`.ci-dashboard-display`), IBM Plex Mono pre kód — všetky sú self-hostované cez
> importy `@fontsource/*` na začiatku `src/app/globals.css`. Každá ikona je glyf Lucide.

## 1. Kde sa čo nachádza

- **Kit.** `packages/ui-kit/src` je bajt po bajte identická kópia upstream `src/` na commite pripnutom v
  `packages/ui-kit/UPSTREAM.md` (ktorý zároveň zaznamenáva licenčné povolenie); `PATCHES.md` uvádza lokálne
  záplaty (žiadne). Používa sa ako zdrojový kód, bez buildu: `next.config.mjs` ho transpiluje a
  `tsconfig.json` mapuje `@omniroute/ui-kit` → `packages/ui-kit/src` a `@omniroute/ui-kit/*` →
  `packages/ui-kit/src/*` (`vitest.config.ts` a `vitest.mcp.config.ts` nesú rovnaký alias). Komponent kitu
  importujte cez jeho subpath (`@omniroute/ui-kit/table`, `@omniroute/ui-kit/page-header`…), nikdy
  nie cez barrel `@omniroute/ui-kit`: barrel do každého importéra vtiahne všetky komponenty (vrátane výberu
  dátumu). Štýly kitu vstupujú cez `src/app/globals.css`
  (`@import "../../packages/ui-kit/src/ci-ui.css"`).
- **Tokeny.** `packages/ui-kit/src/ci-tokens.css` deklaruje tokeny `--ci-*`; `src/app/globals.css`
  ich premostíva na staré názvy OmniRoute (`--color-*`, `--radius-*`, `--font-sans`/`--font-mono`,
  `--table-*`, `--orch-status-*`, `--color-fd-*`), takže existujúce čítania `var(--color-*)` a Tailwind
  utility fungujú ďalej. Nový kód používa Tailwind utility (`bg-surface`, `text-text-muted`,
  `border-border`, `text-success`, `bg-success-bg`, `bg-chart-1`…) alebo triedy kitu — nikdy hex hodnotu
  (`tests/unit/design-kit-bridge.test.ts` premostenie vynucuje). `text-primary` sa rozlíši na
  `--color-primary-ink` cez `--text-color-primary` (lime-800 vo svetlom režime, lime akcent v tmavom), takže
  primárny text ostáva čitateľný, zatiaľ čo `bg-primary`/`border-primary` si ponechávajú lime plochu. Série
  grafov používajú `--color-chart-1` … `--color-chart-5`.
- **Témy.** `<html className="ci-theme">` (`src/app/layout.tsx`) prihlási dokument do témy kitu.
  Preferencia je `light`, `dark` alebo `system` (`THEME_CONFIG.defaultTheme = "system"` v
  `src/shared/constants/appConfig.ts`; `system` sleduje `prefers-color-scheme`). `applyTheme()` v
  `src/store/themeStore.ts` (zrkadlená inline bootstrap skriptom v `src/app/layout.tsx`, ktorý beží
  pred hydratáciou) nastaví `data-theme="dark"|"light"` a súčasne prepne triedu `.dark` na `<html>`.
  Tmavá sada tokenov kitu je kľúčovaná na `data-theme="dark"` (`packages/ui-kit/src/ci-tokens.css`);
  vlastné tmavé prepísania OmniRoute (blok `.dark` v `globals.css`) a staré Tailwind `dark:`
  utility sa kľúčujú na triedu `.dark`. Neexistujú žiadne presety akcentovej farby: akcent vždy pochádza z
  kitu a uložený preset zo staršieho buildu sa pri načítaní store zahodí.
- **Komponenty (adaptéry).** `src/shared/components/index.tsx` zachováva API komponentov OmniRoute (rovnaké
  názvy, default exporty a props) a primitívy za ním sú adaptéry nad kitom: formuláre
  (`Button`, `Input`, `Textarea`, `Checkbox`, `Select`, `Toggle`, `Badge`, `Card`), overlaye a spätná väzba
  (`Modal`/`ConfirmModal`, `Tooltip`/`InfoTooltip`, `NotificationToast`, `EmptyState`, `Loading`),
  štruktúra (`Collapsible`, `CollapsibleSection`, `SegmentedControl`, `Breadcrumbs`, `Avatar`) a tabuľky
  (`DataTable`, `FilterBar`, `ColumnToggle`, `FilterPills`, `PresetSlider`). Adaptér importuje komponent
  kitu cez subpath a mapuje naň staré props — napríklad `Button variant="primary"` je kit tlačidlo
  `default` (`--ci-button-primary-*`: inverzná plocha vo svetlom režime, akcent so svojím atramentom
  `--ci-color-accent-foreground` v tmavom), `danger` je `destructive` a `warning` je `outline` plus
  rozšírenie `.ci-button--warning`. Pravidlá `.ci-button--warning` a `.ci-badge[data-tone]` na
  konci `globals.css` (`@layer components`) sú rozšírenia OmniRoute nad triedami kitu.
  `tests/unit/ui/adapters/*.test.tsx` pripínajú každý adaptér.
- **Shell.** `src/app/(dashboard)/layout.tsx` renderuje `DashboardLayout`, ktorý renderuje
  `src/shared/components/layouts/DashboardShell.tsx`: kit `SidebarProvider` / `Sidebar` /
  `SidebarInset` (`packages/ui-kit/src/sidebar.tsx`), s navigačnou logikou OmniRoute v
  `src/shared/components/Sidebar.tsx`. Odkaz „preskočiť na obsah" smerujúci na `#main-content` je prvým
  fokusovateľným prvkom. `src/shared/components/Header.tsx` obsahuje kit `SidebarTrigger` (jediný
  prepínač sidebaru shellu), Keak `ProductSwitcher` a otvárač príkazovej palety; názov route zobrazuje len
  vtedy, kým vo vnútri `#main-content` nie je namontovaný žiadny kit `PageHeader` (`.ci-page-header`),
  takže stránka s vlastným `PageHeader` má jediný `h1`. `src/shared/components/CommandPalette.tsx` je kit
  `Dialog`.
- **Ikony.** `<Icon name="material_name">` (`src/shared/components/Icon.tsx`) rozlíši názov (slovník
  Material Symbols, ktorý obrazovky používajú) cez `ICON_MAP` (`src/shared/constants/iconMap.ts`) na glyf
  Lucide. Font a balík Material Symbols sú preč: názov, ktorý v mape chýba, renderuje neutrálny zástupný
  glyf (`data-icon-missing="true"`) a mimo produkcie loguje varovanie do konzoly.
  `npm run gen:icon-map` vypíše používané názvy, ktoré v mape chýbajú
  (`tests/unit/icon-map-coverage.test.ts` zlyhá na akomkoľvek názve bez ikony Lucide;
  `tests/unit/icon-map-object-values.test.ts` pokrýva názvy uložené vo vyhľadávacích objektoch);
  `scripts/dev/codemod-material-icons.mjs <dir|file>... [--write]` prepíše literálne
  spany `<span className="material-symbols-outlined">` na `<Icon>`.
- **Značka.** `src/shared/components/OmniRouteLogo.tsx` obaľuje kit: default export `OmniRouteLogo`
  renderuje `ProductIcon product="omniroute" variant="glyph"` (inline SVG, bezpečné voči `basePath`) a
  `OmniRouteLockup` renderuje `ProductLockup product="omniroute"` (prístupný názov „Keak OmniRoute") alebo,
  pre white-label operátorov, ich vlastné `name`/`logoSrc`. Ciele prepínača produktov žijú v
  `src/shared/constants/keakProducts.ts` (`KEAK_PRODUCT_LINKS`, `KEAK_ACTIVE_PRODUCT`). Samostatné
  obrazovky — `src/app/login/page.tsx`, `src/app/status/page.tsx`, `src/app/maintenance/page.tsx`,
  `src/app/offline/page.tsx`, `src/app/not-found.tsx` a `src/shared/components/ErrorPageScaffold.tsx`
  — zobrazujú lockup; `tests/unit/brand-pages-static.test.ts` ho stráži.

## 2. Pravidlá

1. Tokeny, nikdy literály. Výnimky sú ponechané zámerne: vždy tmavý terminál konzoly, ťahy SVG
   ReactFlow cez `STATUS_HEX` (`src/shared/constants/statusColors.ts`) a kategorické palety
   `STRATEGY_COLORS` (`src/app/(dashboard)/dashboard/combos/live/nodes/StrategyNode.tsx`) a
   `LAYER_COLORS` (`src/app/(dashboard)/dashboard/compression/studio/nodes/EngineNode.tsx`).
2. Nikdy neupravujte `packages/ui-kit/src` ručne: synchronizujte pomocou
   `scripts/dev/sync-ui-kit.sh <commit>`; pre-commit brána `npm run check:ui-kit-snapshot`
   (`.husky/pre-commit`) zlyhá pri každom bajte, ktorý sa líši od pripnutého upstream commitu
   (preskočí sa s varovaním, keď upstream klon, `UI_KIT_CLONE` alebo
   `_references/cheaper-inference-ui-kit`, chýba). Keď kit niečo postráda, obíďte to v adaptéri
   alebo na obrazovke a požiadajte o to upstream.
3. Predvolené texty kitu sú anglické (`label = "Loading"`, `loadingLabel = "Loading table"`…) —
   vždy, keď komponent kitu vykresľuje text, odovzdajte preložené reťazce z `useTranslations(...)`.
4. Utility Tailwindu majú prednosť pred triedami komponentov kitu (kit deklaruje
   `@layer theme, base, components, utilities` a jeho pravidlá žijú v `components`) — utility
   používajte na medzery a rozloženie, nie na prefarbenie komponentov kitu.
5. Nadpisy: `.ci-heading` (Inter, bez trackingu) pre názvy stránok a sekcií;
   `.ci-dashboard-display` (Instrument Serif) len pre veľký, riedky zobrazovací text, ako je
   stavový kód chybovej stránky.
6. `tests/unit/dashboard-kit-sweep.test.ts` stráži prijatie kitu: žiadny span s ligatúrou Material
   pod `src/app` alebo `src/shared/components`; v strome dashboardu (`src/app/(dashboard)` a
   `src/shared/components`) žiadne surové `<select>`, `<textarea>` alebo `<table>` a žiadny ručne
   vytvorený `role="dialog"` mimo uvedených výnimiek (natívna vetva adaptéra `Select`,
   `RequestLoggerDetail`); každý surový `<button>` alebo `<input>` tam potrebuje komentár
   obsahujúci `kit-exception:` (s dôvodom), ktorý končí najviac 3 riadky nad ním; odtiene palety
   a varianty `dark:` len v súboroch, ktoré test uvádza.
7. Pred PR overte obe témy a viewport 390 px (screenshoty); `tests/e2e/a11y.spec.ts` spúšťa axe.

## 3. Pridanie obrazovky

1. Stránku otvorte s `PageHeader` z kitu (`@omniroute/ui-kit/page-header`, `compact` vnútri
   dashboardu) — titulok, popis a `actions`. Hlavička shellu potom zahodí vlastný titulok.
2. Ovládacie prvky budujte z `@/shared/components` (adaptéry) a komponenty kitu používajte cez
   subpath tam, kde adaptér neexistuje (`Table`/`TableScrollArea`/`DataTableShell`, `Field`,
   `Alert`, `Tabs`, `RadioGroup`, `Slider`…).
3. Ikony: `<Icon name="…" />`. Nový názov ide do `ICON_MAP` so sémanticky zodpovedajúcim
   komponentom Lucide; `npm run gen:icon-map` vypíše názvy, ktoré ešte chýbajú.
4. Farby: sémantické utility (`text-success`, `bg-warning-bg`, `border-border`…) a
   `var(--color-chart-N)` pre série grafov; žiadne hex hodnoty a žiadne varianty `dark:`, ktoré
   len opakujú farbu.
5. Text: každý reťazec, vrátane štítkov, ktoré odovzdávate komponentom kitu, pochádza z
   `useTranslations`. Nové kľúče idú do `src/i18n/messages/en.json`, `pt-BR.json` a `vi.json`
   (test vietnamskej parity fixuje každý anglický kľúč); ostatné lokály dopĺňa synchronizácia
   i18n.
6. Pred PR spustite stráže: `tests/unit/dashboard-kit-sweep.test.ts`,
   `tests/unit/icon-map-coverage.test.ts`, `tests/unit/icon-map-object-values.test.ts`,
   `npm run check:dashboard-typecheck` (jediná kontrola, ktorá zachytí duplicitný import v
   `iconMap.ts`), `npm run check:ui-icu` a vlastné testy obrazovky.

## 4. Pridanie alebo zmena adaptéra

1. Zachovajte verejné API súboru `src/shared/components/index.tsx`: rovnaké názvy exportov, predvolené exporty a
   akceptované props. Staršie props mapujte na kit vo vnútri adaptéra (pozrite `Button.tsx`: `VARIANT_TO_KIT`,
   `SIZE_TO_KIT`).
2. Kit importujte cez podcestu (`@omniroute/ui-kit/<component>`).
3. Obchádzky pre nedostatky kitu patria do adaptéra (alebo do `globals.css` `@layer components`, ak je opravou
   štýl), nikdy do `packages/ui-kit/src`.
4. Pridajte alebo aktualizujte `tests/unit/ui/adapters/<name>.test.tsx`. Pri adaptéri s mnohými volajúcimi porovnajte
   vykreslený markup pred zmenou a po nej — zmeny paddingu alebo wrappera sa prejavia na každej obrazovke.

## 5. Aktualizácia kitu

`scripts/dev/sync-ui-kit.sh <commit> [clone]` skopíruje upstream `src/` na danom commite do
`packages/ui-kit/src` a aplikuje jedinú povolenú transformáciu (odstráni príponu `.js` z relatívnych
importov). Potom: skontrolujte `git diff packages/ui-kit`, vizuálne prejdite poskytovateľov, nastavenia, kombinácie,
využitie a endpoint v oboch témach, spustite `npm run check:ui-kit-snapshot` a `npm run test:vitest:ui` a
otvorte PR s upstream changelogom.
