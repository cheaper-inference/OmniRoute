`@omniroute/opencode-plugin-v2` sprístupňuje celý váš katalóg OmniRoute — modely, kombinácie a
automatické kombinácie — vo výbere modelov OpenCode v2 spolu so zobrazovanými názvami, cenami a
limitmi bezplatnej úrovne.

Ide o samostatný balík od `@omniroute/opencode-plugin`, pretože OpenCode v1 a v2 načítavajú
pluginy prostredníctvom odlišných rozhraní. Vyberte si ten, ktorý zodpovedá hlavnej verzii vášho OpenCode;
nič medzi nimi nie je zdieľané, takže aktualizácia jedného nikdy nevynúti aktualizáciu druhého.

## Požiadavky

- OpenCode v2.
- Dostupná brána OmniRoute (predvolene `http://localhost:20128`).
- Node.js 22 alebo 24.

## Inštalácia

Pridajte plugin do súboru `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

Modely sa potom zobrazia ako `omniroute/<provider>/<model>`; `providerId` určuje tento prefix a
identifikátor integrácie, pod ktorým OpenCode ukladá prihlasovací údaj.

## Prihlasovacie údaje

Plugin hľadá kľúč brány na troch miestach v tomto poradí:

1. **Prihlasovací údaj, ktorý ste pripojili v OpenCode.** Plugin zaregistruje integráciu, takže
   vlastný autorizačný proces OpenCode môže kľúč uložiť. Nič sa nezapíše do `opencode.json` — túto možnosť uprednostnite.
2. `apiKey` v možnostiach pluginu na prepísanie nastavenia pre konkrétny projekt. Kľúč sa tým uloží do súboru,
   ktorý môžete odosielať do repozitára.
3. `OMNIROUTE_API_KEY` v prostredí.

Ak nie je k dispozícii žiadna z týchto troch možností, katalóg zostane prázdny a plugin to oznámi raz pri spustení
namiesto toho, aby vám ponechal prázdny výber bez upozornenia.

### Token na správu je iný kľúč

Kombinácie, stav poskytovateľov a obohatenie (zobrazované názvy, ceny a limity bezplatnej úrovne) pochádzajú z
koncových bodov brány `/api/*`, ktoré väčšina nasadení chráni **správcovským** tokenom,
nie inferenčným kľúčom:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<správcovský token na čítanie>"
}
```

Ak `managementReadToken` nie je nastavený, použije sa `apiKey`. Keď brána toto náhradné riešenie odmietne,
katalóg sa aj tak zverejní, ale s nespracovanými identifikátormi modelov namiesto zobrazovaných názvov, bez
odstraňovania duplicít kanonických aliasov, cien a kombinácií. Keď k tomu dôjde, plugin upozorní raz pre každý koncový bod,
pričom uvedie koncový bod a chýbajúce údaje — zhoršená podoba výberu tak nikdy nebude záhadou.

## Možnosti

| kľúč                             | Predvolené                                     | Poznámky                                                                                                                                                                                                                                                                                                                                                                            |
| -------------------------------- | ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `providerId`                     | `"omniroute"`                                  | ID poskytovateľa, integračné ID a modely predpony sa zobrazia pod                                                                                                                                                                                                                                                                                                                   |
| `baseURL`                        | požadované                                     | Koreň brány, iba `http(s)` ; tam, kde je to potrebné, sa pridá prípona `/v1`                                                                                                                                                                                                                                                                                                        |
| `apiKey`                         | pripojené poverenia, potom `OMNIROUTE_API_KEY` | Chat kľúč pre `/v1/*`                                                                                                                                                                                                                                                                                                                                                               |
| `managementReadToken`            | spadá späť do `apiKey`                         | Zvyčajne kľúč pre `/api/*` —** nie** ten istý                                                                                                                                                                                                                                                                                                                                       |
| `displayName`                    | `"OmniRoute"`                                  | Názov poskytovateľa vo výbere                                                                                                                                                                                                                                                                                                                                                       |
| `timeoutMs`                      | `10000`                                        | Časový limit načítania pre každý koncový bod (automatické kombinácie používajú 5 s)                                                                                                                                                                                                                                                                                                 |
| `modelCacheTtlMs`                | `300000`                                       | Katalógová vyrovnávacia pamäť TTL; snímka disku ohrieva studené štarty                                                                                                                                                                                                                                                                                                              |
| `timeouts`                       | spadá späť do `timeoutMs`                      | Rozpočty na koncový bod v ms: `models`, `combos`, `autoCombos`, `enrichment`                                                                                                                                                                                                                                                                                                        |
| `enrichment`                     | `true`                                         | Získajte názvy, ceny a rozpočty bezplatných úrovní                                                                                                                                                                                                                                                                                                                                  |
| `providerTag`                    | `true`                                         | Prepnite koncovú zátvorku editora: `Provider - Model (Editor)`. Poskytovateľ (trasa obsluhujúca model) je vždy zobrazený; editor (ktorý vytvoril model) sa zobrazuje iba v zátvorkách. Príklad: `Openrouter - MoonshotAI: Kimi K 3.1 Pro` -> `Openrouter - Kimi K 3.1 Pro (MoonshotAI)`. Vynechané, keď editor a poskytovateľ zdieľajú meno. Nastavte `false`, aby ste to upustili. |
| `usableOnly`                     | `false`                                        | Hlásenia brány ponechajte iba poskytovateľom ako poskytnuté                                                                                                                                                                                                                                                                                                                         |
| `combosSource`                   | `"api"`                                        | `"models"` preskočí `/api/combos` a zverejní kombinované riadky `/v1/models` ; filtre na úrovni členov ponechávajú `"api"`                                                                                                                                                                                                                                                          |
| `showcasePerOwner`               | `10`                                           | Položky predvoleného zobrazenia uchovávané podľa poskytovateľa                                                                                                                                                                                                                                                                                                                      |
| `freshPerOwner`                  | `10`                                           | Predvolené zobrazenie nových záznamov uchovávaných podľa poskytovateľa                                                                                                                                                                                                                                                                                                              |
| `freshWindowDays`                | `90`                                           | Okno čerstvosti v dňoch pre čerstvú vetvu                                                                                                                                                                                                                                                                                                                                           |
| `usageMemory`                    | `true`                                         | Obnoviť staticky vyradené položky pomenované podľa 30-dňovej analýzy používania (vyžaduje token správy)                                                                                                                                                                                                                                                                             |
| `visibleModels` / `hiddenModels` | `[]`                                           | presné alebo príponové zoznamy povolených; popierať výhry; `*` zverejňuje celý katalóg (iné filtre stále platia)                                                                                                                                                                                                                                                                    |
| `geminiSanitization`             | `true`                                         | Odstráňte kľúčové slová schémy JSON, Gemini odmieta, zo schém nástrojov (nástroje `$ref` sa posielajú ďalej nedotknuté)                                                                                                                                                                                                                                                             |
| `apiFormat.allowAnthropic`       | `false`                                        | Smerujte identifikátory zo zoznamu povolených cez blok Anthropic API                                                                                                                                                                                                                                                                                                                |
| `apiFormat.anthropicModels`      | `[]`                                           | Úplné ID modelov smerované do Anthropic                                                                                                                                                                                                                                                                                                                                             |
| `logLevel` / `startupDebug`      | `warn` / `false`                               | Výrečnosť zapisovača                                                                                                                                                                                                                                                                                                                                                                |

Využitie pamäte je predvolene zapnuté. Bez riadiaceho tokenu zostane inertný (zaznamená sa upozornenie na spustenie) a nič sa neobnoví.

## Ako zostane katalóg čerstvý

Katalóg sa načítava lenivo a ukladá do vyrovnávacej pamäte pre `modelCacheTtlMs` a snímka disku uchováva posledný známy katalóg dostupný, keď je brána nedostupná — výpadok vás nestojí nič iné ako čerstvosť. Modely a kombá sú zverejnené hneď, ako prídu; automatické kombá, zoznam poskytovateľov a prekrytie obohatenia sa po pristátí zložia, takže jeden pomalý koncový bod nemôže držať celý výber ako rukojemníka.

Názvy nasledujú `Provider - Model[ (Editor)][ · budget][ (route)]`: poskytovateľ sa zobrazí vždy, keď id nesie jedno (identifikátor bez lomky sa vykresľuje bez predpony), prvé `🆓` označuje voľné položky a ich voľný rozpočet zostane ako prípona `· 1M tokens/month`, editor explicitného názvu `Editor: Model` sa presunie do koncovej zátvorky (z iných názvov sa nedá uhádnuť žiadny editor) a bez kombá sa vykreslí ikona zdarma ako `combo - <slug>` Dva záznamy, ktoré majú rovnaký názov, dostanú príponu trasy — `(no-think)` —, aby zostali rozlíšiteľné. `providerTag` (predvolené `true`) prepína koncové zátvorky editora.

Neexistuje žiadny manuálny príkaz na obnovenie: príkazy OpenCode v2 sú šablóny výziev, nie spätné volania, takže doplnok ich nemôže odhaliť. Obnovenie nasleduje po TTL; hostiteľ je požiadaný o opätovné načítanie iba vtedy, keď sa katalóg alebo prekrytie skutočne zmení, nikdy nie raz za obnovenie.

## Volanie nástrojov v Gemini

Gemini odmietne celú požiadavku, ktorej deklarácie nástrojov obsahujú `$schema` alebo
`additionalProperties`, a odpovie `400 INVALID_ARGUMENT`. Doplnok odstráni tieto kľúčové slová zo
schém nástrojov určených pre model Gemini tohto poskytovateľa a všetky ostatné požiadavky ponechá nezmenené.
Nástroj obsahujúci `$ref` sa odošle bez zmeny namiesto odstránenia kľúčových slov, pretože odstránenie
odkazu by rozšírilo schému tak, aby „prijímala čokoľvek“.
Ak to chcete vypnúť, nastavte `"geminiSanitization": false`.

## Riešenie problémov

| Symptóm                                                 | Príčina                                                                                                                            |
| ------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| Picker neukazuje žiadny model OmniRoute                 | Nevyriešil sa žiadny kľúč (skontrolujte varovanie pri spustení) alebo je brána nedostupná                                          |
| Nespracované ID modelov, žiadne kombinácie, žiadne ceny | Koncové body správy odmietli token — set `managementReadToken`                                                                     |
| Krátky alebo prázdny katalóg `freeOnly`                 | Žiadny riadiaci token alebo odmietnutý token — nečítal súhrnný riadok obnovenia (počet `unmatched-free` ) v hostiteľskom protokole |
| Relácia pripnutá k `opencode-<id>/...`                  | Plugin v1 zverejnil `opencode-<id>`; v2 publikuje `<id>` holé, takže znova vyberte model pod `<id>/...`                            |

Premenné prostredia sa musia dostať do procesu servera s otvoreným kódom: keď hostiteľ beží ako služba, prostredie, na ktorom beží `opencode models`, a prostredie servera sú odlišné, takže exportujte kľúč tam, kde ho server číta.
