## kategórie

- **Zadarmo** — voľná úroveň s kľúčom API (konfigurovaná cez dashboard)
- **Nie-autor** verejné koncové body —, ktoré nevyžadujú žiadny kľúč ani prihlásenie
- **OAuth** Prihlasovací tok — spravuje OmniRoute, nie je potrebný žiadny kľúč API
- **Webový súbor cookie** — obalí webovú aplikáciu poskytovateľa prostredníctvom overenia súborov cookie
- **kľúč API** Platený poskytovateľ — nakonfigurovaný pomocou kľúča API (môžu sa uplatniť bezplatné kredity)
- **Miestne** — beží na počítači používateľa (Ollama, LM Studio, vLLM atď.)
- **Hľadať** poskytovatelia webového vyhľadávania —
- **Zvuk** — poskytovatelia iba zvuku (TTS/STT)
- **Upstream proxy** — poskytovateľov, ktorí proxy dávajú iným poskytovateľom
- **Cloudový agent** — dlhotrvajúci kódovací agenti (Codex Cloud, Devin, Jules)
- **Systém** — OmniRoute-interní poskytovatelia (loopback atď.)

Ďalšie značky: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (kde je znázornené): `native` — volanie reálnej funkcie API; `emulated` — pole `tools` je promptne emulované cez `webTools.ts` (bloky `<tool>{...}</tool>` analyzované regulárnym výrazom); `none` — `tools` je momentálne ticho zrušený. Pozri #7286.

Na aktiváciu, konfiguráciu a testovanie každého poskytovateľa použite panel `/dashboard/providers`.
