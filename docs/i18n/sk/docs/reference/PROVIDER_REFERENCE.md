## Kategórie

- **Bezplatné** — bezplatná úroveň s API kľúčom (konfiguruje sa prostredníctvom ovládacieho panela)
- **Bez autentifikácie** — verejné koncové body, ktoré vôbec nevyžadujú kľúč ani prihlásenie
- **OAuth** — prihlasovací proces zabezpečuje OmniRoute, API kľúč nie je potrebný
- **Webový súbor cookie** — sprístupňuje webovú aplikáciu poskytovateľa prostredníctvom autentifikácie pomocou súboru cookie
- **API kľúč** — platený poskytovateľ nakonfigurovaný prostredníctvom API kľúča (môžu byť k dispozícii bezplatné kredity)
- **Lokálne** — spúšťa sa na zariadení používateľa (Ollama, LM Studio, vLLM atď.)
- **Vyhľadávanie** — poskytovatelia webového vyhľadávania
- **Zvuk** — poskytovatelia zameraní výhradne na zvuk (TTS/STT)
- **Nadradený proxy server** — poskytovatelia, ktorí sprostredkúvajú prístup k iným poskytovateľom
- **Cloudový agent** — dlhodobo bežiace programovacie agenty (Codex Cloud, Devin, Jules)
- **Systémové** — interní poskytovatelia OmniRoute (loopback atď.)

Ďalšie značky: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (ak je uvedené): `native` — skutočné API na volanie funkcií; `emulated` — pole `tools` je emulované prostredníctvom promptu pomocou `webTools.ts` (bloky `<tool>{...}</tool>` analyzované regulárnym výrazom); `none` — pole `tools` sa v súčasnosti bez upozornenia zahadzuje. Pozrite si #7286.

Na povolenie, konfiguráciu a testovanie jednotlivých poskytovateľov použite ovládací panel na adrese `/dashboard/providers`.
