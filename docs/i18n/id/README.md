## Token Gratis Sebulan: ~ 11,3 miliar sebagaimana Jumlah Lainnya · ~ 90 juta nyata

</div>

> **~ 11.3B token gratis / bulan**<br/> <sub> menghitung cara katalog lain menghitung: setiap baris dijumlahkan, penawaran berakhir termasuk </sub>
>
> **~ 90M nyata hari ini**<br/> <sub> setiap kuota bersama dihitung satu kali: apa yang sebenarnya dapat Anda gunakan </sub>
>
> **Semuanya di sini gratis. Tidak ada penghalang pembayaran.**<br/> ★ [Suka? Bintangi kami di GitHub](https://github.com/cheaper-inference/OmniRoute)

Katalog lain mengenakan biaya mulai dari US$19 per tahun hingga US$49 untuk akses seumur hidup ke data langsung. Di sini semuanya gratis. <sub> Harga diperiksa pada 18-11-2026.</sub>

<sub>Katalog terakhir diaudit pada 23-11-2026. [Bagaimana kita menghitung →](docs/reference/FREE_TIERS.md#how-we-count)</sub>

> **Bawalah akun penyedia Anda sendiri.** Ini adalah tingkatan gratis pihak ketiga, bukan hibah token dari OmniRoute. Daftar, dapatkan kredensial saat penyedia memintanya, dan sambungkan kredensial yang dapat Anda gunakan. Setiap penyedia menetapkan batasan, ketersediaan, dan ketentuannya sendiri.
>
> Menumpuk tingkatan gratis dengan tangan berarti puluhan SDKs, lusinan batas tarif, dan tidak ada gambaran jelas tentang apa yang tersisa. OmniRoute menyimpan 214 baris katalog dengan akses gratis dan menghitung angka sebenarnya dari 12 kumpulan dengan kuota yang dipublikasikan, setiap kumpulan bersama dihitung satu kali. Kuota yang hanya dibuka setelah pemeriksaan identitas daerah (hari ini, ModelScope) ditampilkan terpisah, +~ 6M di belakang verifikasi identitas daerah, dan tidak pernah ditambahkan ke angka sebenarnya. Yang tersisa muncul di dasbor (`/dashboard/free-tiers`).

## Instal, sambungkan penyedia, lalu rutekan melalui satu titik akhir

<img src="./docs/diagrams/works-zero-config.svg" width="100%" alt="Four steps to use OmniRoute. Install with npm install -g omniroute, run omniroute, connect a provider and create an API key in the dashboard, then call http://localhost:20128/v1 with model auto."/>

```bash
# After connecting a provider, create your OmniRoute key in Dashboard → API Keys:
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer YOUR_OMNIROUTE_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"auto","messages":[{"role":"user","content":"Hello!"}]}'
```

<sub>`auto` membutuhkan rute yang memenuhi syarat. Instalasi baru tidak boleh memiliki target tanpa kunci yang memenuhi syarat, dan penyedia tanpa kunci dapat menolak klien pihak ketiga. Penyedia yang ditandai `tos: avoid`, termasuk Kiro, dikecualikan dari perutean otomatis secara default; menghubungkan akun tidak mengesampingkan pengaturan itu. ## Combo: andalan

1. **Mulailah dengan `auto`.** Tetapkan model di klien Anda yang kompatibel dengan OpenAI. OmniRoute membangun kombo virtual dari penyedia yang terhubung dan menilai kandidat secara langsung.
2. **Simpan kombo untuk kontrol lebih besar.** Pilih nama, daftar target dan strategi, lalu gunakan nama tersebut sebagai model. Strategi menetapkan target mana yang didahulukan dan bagaimana sisanya dicoba.

Kombo merutekan seluruh model secara otomatis. Jika kuota habis, kegagalan penyedia, atau penguncian model, perusahaan akan mencoba target berikutnya yang memenuhi syarat dan sehat.

### Konfigurasi nol: cukup gunakan `auto`

```bash
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <your-omniroute-key>" \
  -H "Content-Type: application/json" \
  -d '{"model": "auto", "messages": [{"role": "user", "content": "Hello"}]}'
```

Varian menyesuaikan bobotnya. Perutean yang terakhir diketahui-baik tetap berada pada penyedia terakhir yang berhasil sampai gagal, lalu mencetak ulang. `auto/fast` dan `auto/cheap` mengungkapkan preferensi tanpa menjamin model tercepat atau termurah.

| Model ID            | Perilaku                                                                                                                                                                                                                                                                                                        |
| :------------------ | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `auto`              | Bobot default yang seimbang.                                                                                                                                                                                                                                                                                    |
| `auto/fast`         | Mendukung latensi rendah dan kesehatan penyedia.                                                                                                                                                                                                                                                                |
| `auto/cheap`        | Mendukung harga katalog yang lebih rendah.                                                                                                                                                                                                                                                                      |
| `auto/coding`       | Bobot yang mengutamakan kualitas untuk pembuatan kode.                                                                                                                                                                                                                                                          |
| `auto/smart`        | Bobot kualitas pertama dengan eksplorasi 10% (default 5%).                                                                                                                                                                                                                                                      |
| `auto/lkgp`         | Perutean barang terakhir yang diketahui secara eksplisit dengan bobot yang sama dengan `auto`.                                                                                                                                                                                                                  |
| `auto/subscription` | Hanya menggunakan kuota paket yang terverifikasi langsung. Mengembalikan HTTP 503 ketika tidak ada yang tersedia dan menghindari fallback yang ditagih.                                                                                                                                                         |
| `auto/thrifty`      | Paket → keyless → gratis → murah → premium. Dapat menjangkau model yang ditagih dan kembali ke paket ketika kuota dan waktu tunggu memungkinkan.                                                                                                                                                                |
| `auto/offline`      | Mendukung kuota dan ruang kepala batas tarif. Permintaan masih masuk ke penyedia Anda.                                                                                                                                                                                                                          |
| `auto/chaos`        | Satu model per penyedia secara paralel, hingga lima model secara default atau sepuluh saat dikonfigurasi. Satu panggilan upstream per model. Mengembalikan balasan peringkat teratas atau balasan panel terakhir yang berhasil jika model teratas gagal. Gunakan `fusion` untuk menyatukan balasan dengan juri. |

Contoh kategori dan tingkat opsional mencakup `auto/coding:fast`, `auto/coding:free`, `auto/reasoning:pro` dan `auto/vision`. Jika tidak ada kandidat terhubung yang cocok, permintaan akan mengembalikan HTTP 503 dan kumpulan tetap sempit. [Panduan Kombo Otomatis](./docs/routing/AUTO-COMBO.md) · [Perutean langganan pertama](./docs/routing/SUBSCRIPTION_LADDER.md)

### Atau buat sendiri: 22 strategi perutean

```bash
omniroute combo create my-pool --strategy fill-first \
  --models "provider-a/model-1,provider-b/model-2"
```

CLI menerima 15 dari 22 strategi. Dasbor dan kombo API menerima semua 22.

| Strategi            | Perilaku                                                                                                                                                                                                                                 |
| :------------------ | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `auto`              | Kandidat peringkat hidup dengan pencetak gol Kombo Otomatis 16 faktor.                                                                                                                                                                   |
| `cache-optimized`   | Lebih suka akun yang cenderung menyimpan awalan prompt di cache.                                                                                                                                                                         |
| `context-optimized` | Coba jendela konteks terbesar yang diketahui terlebih dahulu.                                                                                                                                                                            |
| `context-relay`     | Simpan pesanan Anda dan sampaikan ringkasan percakapan saat berpindah akun.                                                                                                                                                              |
| `cost-optimized`    | Urutkan berdasarkan harga input-token katalog, yang terakhir tidak diketahui. Biaya permintaan akhir dapat berbeda.                                                                                                                      |
| `expiry-first`      | Kuota pembelanjaan kemungkinan akan habis masa berlakunya, sisa tertinggi per jam hingga disetel ulang terlebih dahulu.                                                                                                                  |
| `fill-first`        | Tetap pada target pertama yang tersedia sampai habis atau gagal, lalu lanjutkan.                                                                                                                                                         |
| `fusion`            | Kueri panel secara paralel dan mintalah juri mensintesis satu jawaban.                                                                                                                                                                   |
| `headroom`          | Pilih kapasitas paling bebas dalam jangka waktu 5 jam dan mingguan.                                                                                                                                                                      |
| `jev`               | TypeSafe Jev memilih entri mana dalam daftar peringkatmu yang dijalankan. Aktifkan `COMBO_JEV_STRATEGY_ENABLED` untuk mengirim kutipan per permintaan dan menggunakan panggilan TypeSafe berbayar. Jika dimatikan, pesanan Anda berlaku. |
| `least-used`        | Pilih target dengan permintaan tercatat paling sedikit dalam kombo ini.                                                                                                                                                                  |
| `lkgp`              | Coba penyedia terakhir yang berhasil terlebih dahulu, jika tidak, pertahankan pesanan Anda.                                                                                                                                              |
| `p2c`               | Ambil contoh dua target dan pilih berdasarkan tingkat keberhasilan dan latensi.                                                                                                                                                          |
| `pipeline`          | Masukkan keluaran setiap langkah ke target berikutnya secara berurutan dan kembalikan hanya jawaban akhir.                                                                                                                               |
| `priority`          | Coba target dalam pesanan Anda. Kelengketan sesi mempertahankannya.                                                                                                                                                                      |
| `quota-weighted`    | Lewati akun yang habis dan gunakan sisa kuota dan muatan dalam penerbangan.                                                                                                                                                              |
| `random`            | Acak untuk setiap permintaan. Target pertama yang sama bisa terulang.                                                                                                                                                                    |
| `reset-aware`       | Dapatkan sisa kuota dan waktu untuk menyetel ulang di seluruh sesi dan jendela mingguan.                                                                                                                                                 |
| `reset-window`      | Coba akun yang jendela kuotanya paling cepat direset.                                                                                                                                                                                    |
| `round-robin`       | Putar secara berurutan, tiga keberhasilan per target secara default.                                                                                                                                                                     |
| `strict-random`     | Menangani dari dek yang dikocok sehingga setiap target mengarah satu kali sebelum diulang.                                                                                                                                               |
| `weighted`          | Gambarkan target pertama berdasarkan beratnya dan simpan sisanya sebagai cadangan. Perpecahannya bersifat statistik. Gunakan `round-robin` untuk rotasi yang ketat.                                                                      |

Strategi kuota menggunakan data langsung yang dilaporkan oleh penyedia, termasuk periode berlangganan 5 jam dan mingguan. `fusion` dan `pipeline` melakukan beberapa panggilan upstream per permintaan.

Pencetak skor 16 faktor ini menggunakan kuota, kesehatan, biaya, latensi, kesesuaian tugas, stabilitas, prioritas tingkat, afinitas tingkat, kecocokan spesifisitas, afinitas konteks, afinitas cache, ketersediaan sesi, afinitas jendela reset, kepadatan koneksi, kualitas, dan keandalan. Bobot bervariasi berdasarkan profil. Afinitas cache, afinitas jendela reset, dan keandalan tidak memiliki bobot secara default. [Faktor penilaian](./docs/routing/AUTO-COMBO.md#how-it-works-persisted-auto-combos)

### Ketahanan dibangun dalam: 3 lapisan independen

Kegagalan ditangani dalam tiga cakupan, jadi satu model yang buruk tidak menghapus akunnya, dan satu akun buruk tidak menghapus penyedianya.

<img src="./docs/diagrams/resilience-layers.svg" width="100%" alt="OmniRoute resilience: 3 independent self-healing layers, the right layer for the right failure. Layer 1, provider circuit breaker (whole provider): trips only on 408/500/502/503/504, opens after 8 failures for OAuth providers or 12 for API-key providers, resets after 60s or 30s into a HALF-OPEN probe, lazy recovery; while OPEN the combo reroutes to the next provider. Layer 2, connection cooldown (one key or account): base 5s OAuth or 3s API-key, exponential backoff with an anti-thundering-herd guard, success clears the error state; one cooling key is skipped while sibling keys keep serving. Layer 3, model lockout (one model): per-model 429, 404 or access denials lock just that model, never the whole connection. Terminal states (banned, expired, credits exhausted) wait for the operator; they are not cooldowns."/>

#### Jika seluruh penyedia sedang down

Itu** pemutus sirkuit penyedia** terbuka setelah 8 (OAuth) atau 12 ( kunci API ) gagal dengan status 408, 500, 502, 503 atau 504. Kombo melewati penyedia itu saat sedang terbuka. Setelah 60 atau 30 detik, satu permintaan probe memutuskan apakah probe akan ditutup.

#### Jika satu kunci atau akun dibatasi tarifnya

Itu** waktu tunggu koneksi** hanya membuat koneksi itu, dengan kemunduran eksponensial dari 5 detik (OAuth) atau 3 detik ( kunci API ). Kunci lain untuk penyedia yang sama tetap ditayangkan.

#### Jika salah satu model ditolak

Itu** penguncian model** hanya memblokir model tersebut pada koneksi tersebut setelah per-model 429, 404 atau penolakan akses. Model lain pada koneksi yang sama tetap melayani.

Koneksi yang dilarang, kedaluwarsa, dan kehabisan kredit adalah status terminal, bukan cooldown: koneksi tersebut menunggu Anda untuk memperbaikinya.

## CLI penuh, MCP dan A2A

> OmniRoute mengirimkan klien baris perintah dengan** 91 perintah tingkat atas dan grup komando** (754 perintah menghitung sub-perintah), an** server MCP dengan 110 alat dan 33 cakupan** , dan sebuah** agen A2A dengan 6 keterampilan** . Skrip, terminal, dan agen AI semuanya dapat mengoperasikan gateway yang sama.

### CLI yang nyata, bukan hanya `start`

```bash
omniroute                 # start the gateway and dashboard (port 20128)
omniroute setup           # guided first-run wizard
omniroute repl            # interactive chat in the terminal (/model /combo /skill /memory)
omniroute chat "hello"    # one-shot prompt; also reads --file or --stdin
omniroute doctor          # check config, database, ports, Node runtime and native deps
```

Bendera global `--output table|json|jsonl|csv` membuat perintah yang sama dapat digunakan dari skrip dan CI.

### Mode jarak jauh: CLI di laptop Anda, OmniRoute di server

Masuk sekali ke server jauh. CLI menyimpannya sebagai a** konteks** , dan perintah selanjutnya dijalankan pada server tersebut hingga Anda beralih kembali.

```bash
omniroute connect omniroute.example.com          # asks for the password, saves a scoped token as a context
omniroute models                                 # runs against the remote server
omniroute configure codex                        # picks a remote model, writes a local Codex profile
omniroute tokens create --name ci --scope read   # mint a narrower token for another machine
omniroute contexts use default                   # switch back to the local server
```

| Ruang lingkup token | <img width="2000" height="0" alt=""> Apa yang diperbolehkan                   |
| ------------------- | ----------------------------------------------------------------------------- |
| `read`              | Daftar dan periksa: model, status, log, penggunaan                            |
| `write`             | `read` plus konfigurasikan dan terapkan: pengaturan klien, kunci, konfigurasi |
| `admin`             | `write` plus kelola: token, penyedia, layanan, kebijakan                      |

Host kosong mendapat `http://` dan port 20128; meneruskan `https://` URL penuh ketika server berada di belakang TLS. Rute yang dapat memunculkan proses tetap hanya loopback, apa pun tokennya.

### Hubungkan agen

Agen, atau kode Anda sendiri, dapat mengarahkan perutean, penyedia, kombo, cache, kompresi, dan memori melalui salah satu antarmuka ini. jalur HTTP dilayani oleh gateway, secara default di `http://localhost:20128`.

| Antarmuka                             | Titik akhir atau perintah  | Gunakan untuk                                                                      |
| ------------------------------------- | -------------------------- | ---------------------------------------------------------------------------------- |
| MCP melalui stdio                     | `omniroute --mcp`          | Claude Desktop, Cursor dan klien MCP lokal lainnya                                 |
| MCP melalui HTTP yang dapat dialirkan | `/api/mcp/stream`          | Klien MCP jarak jauh: 110 alat, 33 cakupan, setiap panggilan ditulis ke log audit  |
| MCP di atas SSE                       | `/api/mcp/sse`             | Klien yang masih menggunakan transportasi SSE                                      |
| penemuan A2A                          | `/.well-known/agent.json`  | Kartu Agen: memberi tahu agen lain apa yang dapat dilakukan OmniRoute              |
| eksekusi A2A                          | `POST /a2a`                | Tugas JSON-RPC 2.0, disinkronkan atau dialirkan melalui SSE, di 6 keterampilan     |
| REST API                              | `/v1/*`                    | Obrolan, Respons, penyematan, gambar, audio, dan OCR yang kompatibel dengan OpenAI |
| Webhook                               | `/api/webhooks`            | Acara ke Slack, Discord, Telegram, atau URL apa pun dengan penandatanganan HMAC    |
| CLI jarak jauh                        | `omniroute connect <host>` | Mendorong instance jarak jauh dengan token akses terbatas                          |

Enam keterampilan A2A adalah `smart-routing`, `quota-management`, `provider-discovery`, `cost-analysis`, `health-report` dan `list-capabilities`.

**Sebelum Anda terhubung:**

- **MCP melalui HTTP mulai dinonaktifkan.** Aktifkan dengan `omniroute mcp enable --transport streamable-http` atau dari halaman Endpoint dasbor. Satu transportasi HTTP aktif pada satu waktu: `streamable-http` melayani `/api/mcp/stream`, `sse` melayani `/api/mcp/sse`.
- **A2A mulai dinonaktifkan.** Aktifkan di halaman Titik Akhir dasbor. `POST /a2a` kemudian mengikuti aturan kunci API yang sama seperti `/v1`.
- **MCP jarak jauh membutuhkan kunci yang sesuai.** `/api/mcp/*` hanya menjawab loopback secara default. Dari host lain, kirim kunci dengan `manage` atau `admin` (semua alat), atau dengan `mcp:connect` ditambah cakupan alat yang Anda perlukan. Untuk kunci tanpa `manage`/`admin`, cakupan alat selalu diterapkan.

```bash
# Give Claude Code the OmniRoute toolset over MCP:
omniroute mcp enable --transport streamable-http
claude mcp add --transport http omniroute http://localhost:20128/api/mcp/stream \
  --header "Authorization: Bearer <api-key-with-manage-scope>"
```

## Hemat 15–95% Token — Secara Otomatis

### Cara kerjanya pipa —, arsitektur & matematika tabungan

<img src="./docs/diagrams/compression-pipeline.svg" width="100%" alt="OmniRoute compression pipeline: an illustrative 10,000-token client request passes through 12 composable engines — Session-Dedup, CCR, Lite, RTK, Responses Tool Output, Headroom, Relevance, Caveman, Aggressive, LLMLingua-2, Ultra and OmniGlyph — and can reach the provider at about 1,080 tokens in the documented stacked example. Structured content is protected by preservation guards and per-step fidelity gates; explicit lossy or experimental modes may transform eligible content."/>

Kombo bertumpuk default dijalankan `RTK → Caveman`. Ketika keduanya bekerja pada muatan tool/context yang sama, penghematan bertambah:

```txt
combined = 1 − (1 − RTK) × (1 − Caveman_input)
average  = 1 − (1 − 0.80) × (1 − 0.46) = 89.2%
range    = 78.4 – 94.6%
```

Blok kode, URLs, JSON dan data terstruktur adalah** selalu terlindungi** oleh mesin pelestarian.

> **Mengapa menggunakan banyak token ketika hanya sedikit token yang berhasil?** Setiap permintaan melewati pipa kompresi OmniRoute** secara transparan** — tidak ada perubahan klien. Sekarang a** tumpukan 12 mesin yang dapat dikomposisi** yang dijalankan secara berurutan dan memadupadankan per kombo perutean — berdasarkan ide dari [RTK](https://github.com/rtk-ai/rtk), [Caveman](https://github.com/JuliusBrussee/caveman) (⭐ 90K +), [LLMLingua-2](https://github.com/microsoft/LLMLingua), dan [Troglodita](https://github.com/leninejunior/troglodita) (PT-BR).

### Tumpukan 12 mesin

Mesin berjalan sesuai urutan pipa; masing-masing dapat diubah dan dikonfigurasi secara independen per kombo:

### Di luar gaya keluaran mesin —, dial adaptif & kontrol per permintaan

Bentuk balasannya, targetkan jendela konteks model, atau pilih rencana kompresi per permintaan.

#### Gaya keluaran

| Gaya                                     | <img width="2000" height="0" alt=""> Apa fungsinya                                                                      |
| ---------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Prosa singkat                            | Memotong pengisi dan lindung nilai sambil menjaga detail teknis.                                                        |
| Lebih sedikit kode                       | Meminta perubahan kerja terkecil dan menggunakan kembali kode yang ada.                                                 |
| Ekor kuda (pengembang senior yang malas) | Memeriksa apa yang dapat digunakan kembali atau dihapus dan meminta perbaikan akar permasalahan.                        |
| Saya punya ADHD (aksi pertama)           | Memimpin dengan tindakan, memberi nomor pada langkah-langkahnya, dan mengakhiri dengan satu langkah konkrit berikutnya. |
| Terse CJK (文言)                         | Menggunakan bahasa Mandarin klasik yang ringkas. Tersedia untuk `zh`.                                                   |

Setiap gaya memiliki intensitas `lite`, `full` dan `ultra`. Tambahkan gaya dengan entri di registri gaya keluaran.

#### Anggaran konteks adaptif

| Pengaturan | Pilihan                                                                                                                                                                                                          |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Kebijakan  | `reserve-output` (default) memberikan ruang untuk balasan dan margin keamanan. `percentage` menggunakan bagian dari jendela konteks. `absolute` menetapkan target token tetap.                                   |
| Mode       | `floor` dapat meningkatkan rencana yang dipilih agar sesuai dengan jendela konteks. `replace-autotrigger` menggunakan anggaran untuk eskalasi otomatis. `off` mempertahankan pemicu otomatis ambang batas token. |

#### Dimana kompresi diputuskan

| Memesan | Sumber <img width="2000" height="0" alt="">                      |
| ------- | ---------------------------------------------------------------- |
| 1       | Header permintaan `x-omniroute-compression` yang dikenali        |
| 2       | Penggantian kombo perutean                                       |
| 3       | Profil bernama aktif                                             |
| 4       | Anggaran konteks adaptif atau pemicu otomatis ambang batas token |
| 5       | Default panel kompresi                                           |
| 6       | Mati ketika tidak ada rencana yang berlaku                       |

Sakelar kompresi global mengambil prioritas di atas tabel ini. Header respons `X-OmniRoute-Compression` melaporkan `<mode>; source=<source>`.

[Panduan kompresi](docs/compression/COMPRESSION_GUIDE.md) · [kompresi RTK](docs/compression/RTK_COMPRESSION.md) · [Mesin kompresi](docs/compression/COMPRESSION_ENGINES.md)

Harness eval keikutsertaan (`npm run eval:compression`) membandingkan fidelitas respons dan penghematan token pada korpus tetap.

**Permintaan pertama**

```bash
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer YOUR_OMNIROUTE_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"auto","messages":[{"role":"user","content":"Hello!"}]}'
```

**Periksa model mana yang dapat dijangkau oleh kunci Anda**

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_OMNIROUTE_KEY"
```

**Pengaturan alat manual**

```txt
Base URL: http://localhost:20128/v1
API Key:  [the key from Dashboard → API Keys]
Model:    auto            (routes among eligible connections — or choose provider/model)
```

## Metode pemasangan lainnya — Docker, sumber, pnpm, Arch

**🐳 Docker**

```bash
docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 \
  -p 127.0.0.1:20128:20128 -v omniroute-data:/app/data cheaperinference/omniroute:latest
```

`:latest` mengikuti yang tertinggi** diterbitkan** SemVer stabil. Itu tidak melacak git `main`. Sematkan `:X.Y.Z` untuk GitOps. Lihat [Saluran Rilis Docker](docs/guides/DOCKER_GUIDE.md#release-channels). Pin gambar**`OMNIROUTE_MEMORY_MB=1024`** . Cukup untuk dashboard dan ngobrol ringan.** Agen pengkodean** (`POST /v1/responses` dari Kode Claude, Codex, Grok, …) memerlukan tumpukan V8 yang jauh lebih besar atau proses `FATAL ERROR` s di ~ 12 GiB dalam dua konteks panjang yang tumpang tindih. Ukuran wadah di atas heap (buffer asli berada di luar V8):

| <img width="2000" height="0" alt=""> Beban Kerja | Tumpukan (`-e OMNIROUTE_MEMORY_MB`) | Wadah (`--memory`) |
| ------------------------------------------------ | ----------------------------------- | ------------------ |
| Dasbor/obrolan ringan                            | `1024` (gambar default)             | ≥ 2 gram           |
| Satu agen pengkodean                             | `8192`                              | ≥ 10 gram          |
| Dua `/v1/responses` panjang bersamaan            | `10240`–`12288`                     | ≥ 12–16 gram       |

```bash
docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 \
  -e OMNIROUTE_MEMORY_MB=8192 --memory=10g \
  -p 127.0.0.1:20128:20128 -v omniroute-data:/app/data cheaperinference/omniroute:latest
```

Tabel lengkap: [Panduan Docker — runtime RAM](docs/guides/DOCKER_GUIDE.md#runtime-ram-for-coding-agents).

> **Saluran Docker pra-rilis:** `diegosouzapw/omniroute:next` dan `diegosouzapw/omniroute:next-web` mengikuti cabang `release/v*` default saat ini. Tag yang dapat diubah ini dimaksudkan hanya untuk menguji perbaikan yang belum dirilis dan memang demikian** tidak didukung untuk produksi** . Lihat [Saluran Rilis Docker](docs/guides/DOCKER_GUIDE.md#release-channels).

**🥟 Bun**

`bun install` standar dan instalasi global (`bun install -g omniroute`) didukung melalui deteksi waktu proses Bun :

- **`bun:sqlite` bawaan** : OmniRoute menggunakan driver `bun:sqlite` bawaan Bun saat berjalan di bawah Bun, kembali ke `better-sqlite3` di Node.js atau `sql.js`.
- **Pemilihan bundler Webpack otomatis di dev** : Pengembangan (`bun run dev`) secara otomatis mendeteksi Bun dan menonaktifkan Turbopack demi Webpack untuk mencegah ketidakcocokan pengikatan V8 asli. Pembuatan produksi (`bun run build`) mengikuti `OMNIROUTE_USE_TURBOPACK` persis seperti pada Node: Turbopack secara default, `OMNIROUTE_USE_TURBOPACK=0` untuk dibuat dengan Webpack (`Dockerfile.bun` memaparkannya sebagai `--build-arg`).
- **Bun Dockerfile khusus** : `Dockerfile.bun` multi-tahap untuk penerapan produksi Bun asli (`docker build -f Dockerfile.bun -t omniroute:bun .`).

```bash
# Install and run with Bun
bun install
bun run dev
```

**⚡ Penginstalan lebih cepat/lebih ramping (lewati versi asli)**

Mesin SQLite asli (`better-sqlite3`) adalah sebuah** opsional** ketergantungan, jadi instalasi global tidak pernah memblokir kompilasi dari sumber: ia menggunakan biner yang sudah dibuat sebelumnya ketika cocok dengan platform/Node Anda, dan jika tidak, kembali secara transparan ke mesin JS murni (`node:sqlite` di Node 22 +, jika tidak, `sql.js` WASM yang dibundel) — tidak memerlukan alat build.

Untuk melewati pasca instalasi** pemanasan asli** seluruhnya ( mesin CI, tanpa kepala, atau lambat). Catatan: ini hanya melewatkan langkah pemanasan SQLite asli (`scripts/postinstall.mjs`); kait binary-copy/repair (`scripts/build/postinstall.mjs`) masih berjalan normal:

```bash
OMNIROUTE_SKIP_POSTINSTALL=1 npm install -g omniroute   # CI=1 also skips it
```

Untuk pemasangan tercepat lebih disukai** pnpm** (toko beralamat konten + tautan keras — lihat di atas). Untuk runtime tanpa kepala dan tanpa dasbor, gunakan profil Docker `base` (di atas) atau [panduan Termux](docs/guides/TERMUX_GUIDE.md). CLI dan dasbor web dilayani dengan proses yang sama pada satu port, jadi saat ini tidak ada paket khusus CLI yang terpisah.

  <tr><td nowrap><b>Basis data</b></td><td>SQLite dengan penjurnalan WAL melalui better-sqlite3, dengan rantai fallback driver — 178 modul di <code>src/lib/db/</code>, 252 migrasi</td></tr>
  <tr><td nowrap><b>Ingatan</b></td><td>SQLite FTS5 penelusuran teks lengkap + int8-quantized penyematan vektor dengan peluruhan yang diketik; opsional Qdrant</td></tr>

  <tr><td nowrap><b>Protokol</b></td><td>MCP (stdio / SSE / Streamable HTTP, 110 alat) + A2A v0.3 (JSON-RPC 2.0 + SSE) dengan kompatibilitas klien A2A v1.0</td></tr>
  <tr><td nowrap><b>Mengalir</b></td><td>Peristiwa Terkirim Server (SSE) + WebSocket bridge (<code>/v1/ws</code>)</td></tr>
  <tr><td nowrap><b>Kompresi</b></td><td>15 mesin bawaan, termasuk RTK, Caveman, LLMLingua-2 (ONNX, TinyBERT secara default), headroom dan OmniGlyph</td></tr>
  <tr><td nowrap><b>Keamanan autentikasi &amp;</b></td><td>OAuth 2.0 (PKCE) + JWT + API kunci + MCP scoped auth · opsional Entra ID, OIDC dan TOTP sign-in · AES-256-GCM at rest · DOMPurify</td></tr>
  <tr><td nowrap><b>Diam-diam</b></td><td>wreq-js — JA3 / JA4 TLS peniruan sidik jari, proksi 3 tingkat</td></tr>
  <tr><td nowrap><b>Ketangguhan</b></td><td>Pemutus sirkuit penyedia, cooldown koneksi, penguncian model, backoff eksponensial, penerimaan adaptif</td></tr>

  <tr><td nowrap><b>Pengujian</b></td><td>Node.js test runner + Vitest + Playwright — 9.500 + file uji di bawah <code>tests/</code> (unit, integrasi, E2E, keamanan, ekosistem)</td></tr>

OmniRoute berdiri di atas bahu para raksasa. Ini dimulai sebagai sebuah garpu** [9router](https://github.com/decolua/9router)** dan port TypeScript dari proyek Go** [CLIProxyAPI](https://github.com/router-for-me/CLIProxyAPI)** — dan dari sana, setiap subsistem di bawah ini terinspirasi oleh proyek sumber terbuka yang pertama kali hadir.
