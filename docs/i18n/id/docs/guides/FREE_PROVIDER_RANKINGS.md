> **TL;DR**: OmniRoute memeringkat penyedia **gratis** berdasarkan kualitas model menggunakan **skor ELO Arena AI
> (bergaya LMArena)**. Buka halaman **Peringkat Penyedia Gratis** di
> dasbor untuk melihat penyedia gratis mana yang menyediakan model terkuat untuk tugas Anda —
> secara keseluruhan, atau difilter berdasarkan kategori (coding, peninjauan, dokumentasi, debugging).

---

## Apa Itu

OmniRoute mendaftarkan 377 penyedia, termasuk 155 entri katalog yang ditandai**free/no-auth** (tanpa autentikasi, OAuth tingkat gratis, atau kunci API tingkat gratis — lihat [Panduan Tingkatan Gratis](../getting-started/FREE-TIERS-GUIDE.md) dan [direktori Tingkatan Gratis](../reference/FREE_TIERS.md) selengkapnya). Hasil tangkapannya: penyedia gratis sangat bervariasi dalam kualitas model. Penyedia tanpa autentikasi yang melayani model frontier jauh lebih berguna daripada penyedia yang melayani model lama yang kecil.

**Peringkat Penyedia Gratis** jawaban "** penyedia gratis mana yang memberi saya model terbaik?** " dengan bergabung dalam katalog masing-masing penyedia gratis** skor kualitas yang bersumber dari banyak orang** dari** Papan peringkat arena AI** (preferensi manusia ELO, ide yang sama di balik arena chatbot LMArena). Penyedia kemudian diberi peringkat berdasarkan kekuatan mereka** model gratis terbaik** .

Pemeringkatan dihitung dari tiga sumber nyata:

1. Daftar penyedia gratis — `NOAUTH_PROVIDERS`, ditambah entri `OAUTH_PROVIDERS` / `APIKEY_PROVIDERS` ditandai `hasFree` (`src/shared/constants/providers.ts`).
2. Katalog model masing-masing penyedia dari registri penyedia (`open-sse/config/providerRegistry.ts`).
3. Skor kesesuaian tugas yang diturunkan dari ELO disimpan dalam tabel `model_intelligence` DB oleh mesin sinkronisasi Arena ELO (`src/lib/arenaEloSync.ts`).

Logika join ada di `src/lib/freeProviderRankings.ts`.

## Cara Mengakses

### Halaman dasbor

Buka dasbor dan masuk ke **Biaya → Peringkat Penyedia Gratis**, atau navigasikan langsung ke:

```
/dashboard/free-provider-rankings
```

Halaman tersebut (`src/app/(dashboard)/dashboard/free-provider-rankings/page.tsx`) menampilkan:

- **Podium 3 teratas** (🥇 🥈 🥉) untuk penyedia gratis dengan peringkat terbaik.
- **Tabel peringkat** lengkap dengan kolom: **Peringkat**, **Penyedia**, **Model Teratas**,
  **Skor**, **Skor Rata-rata**, **Model**, **Jenis**.
- **Tombol filter kategori**: _Semua Kategori_, _Default_, _Coding_, _Peninjauan_,
  _Dokumentasi_, _Debugging_.

Lencana **Jenis** setiap penyedia memberi tahu Anda bagaimana layanan tersebut tersedia secara gratis:

| Lencana  | Arti                                                 |
| -------- | ---------------------------------------------------- |
| `NOAUTH` | Selalu gratis, tidak memerlukan kredensial           |
| `OAUTH`  | Penyedia OAuth dengan tingkat gratis (`hasFree`)     |
| `APIKEY` | Penyedia kunci API dengan tingkat gratis (`hasFree`) |

Skor ditampilkan sebagai label yang mudah dibaca manusia (misalnya _Elite_, _Luar Biasa_, _Sangat Baik_,
_Baik_, _Rata-rata_), bukan sebagai angka mentah, karena nilai dasarnya merupakan kualitas
peringkat relatif, bukan persentase.

### Endpoint API

Halaman ini didukung oleh endpoint baca publik
(`src/app/api/free-provider-rankings/route.ts`):

```
GET /api/free-provider-rankings
GET /api/free-provider-rankings?category=coding
GET /api/free-provider-rankings?category=coding&limit=20
```

Parameter kueri (divalidasi dengan Zod):

| Parameter  | Jenis  | Default     | Catatan                                                                                                          |
| ---------- | ------ | ----------- | ---------------------------------------------------------------------------------------------------------------- |
| `category` | string | (tidak ada) | Salah satu dari `default`, `coding`, `review`, `documentation`, `debugging`. Hilangkan untuk peringkat gabungan. |
| `limit`    | number | `50`        | Dibatasi ke rentang `1–100`.                                                                                     |

Bentuk respons:

```json
{
  "rankings": [
    {
      "id": "<provider-id>",
      "name": "<provider name>",
      "icon": "<icon>",
      "color": "<hex color>",
      "textIcon": "<short label>",
      "category": "noauth | oauth | apikey",
      "topModel": {
        "modelId": "<registry model id>",
        "modelName": "<model display name>",
        "score": 0.0,
        "eloRaw": 0,
        "confidence": "high | medium | low",
        "category": "<task category>"
      },
      "averageScore": 0.0,
      "modelCount": 0
    }
  ]
}
```

`eloRaw` adalah nilai ELO Arena asli; `score` adalah nilai kesesuaian tugas yang dinormalisasi
(lihat di bawah). Penyedia yang tidak memiliki model dengan skor tidak disertakan dalam respons.

## Cara Kerja Skor

### Sumber: Arena AI leaderboard

Mesin sinkronisasi Arena ELO (`src/lib/arenaEloSync.ts`) mengambil dua papan peringkat — `text`
dan `code` — dari API Arena AI leaderboard
(`https://api.wulong.dev/arena-ai-leaderboards/v1/leaderboard`). Ketika API tersebut tidak
mengembalikan papan yang dapat digunakan, mesin beralih ke `lmarena-ai/leaderboard-dataset` resmi
di Hugging Face datasets-server (`src/lib/arenaEloHfSource.ts`, CC-BY-4.0; `overall` → `text`,
`coding` → `code`); `GET /api/intelligence/sync` melaporkan `activeSource`, `lastError`, dan
`lastFailedAt`. Setiap entri papan peringkat
memuat nama model, vendor, `score` ELO, interval keyakinan, dan jumlah suara.

Kategori papan peringkat dipetakan ke kategori tugas OmniRoute:

| Arena leaderboard | Kategori tugas OmniRoute                          |
| ----------------- | ------------------------------------------------- |
| `text`            | `default`, `review`, `documentation`, `debugging` |
| `code`            | `coding`                                          |

### Normalisasi (skor kesesuaian tugas)

Skor ELO mentah dinormalisasi per papan peringkat menjadi **nilai kesesuaian tugas dalam rentang `[0.4, 0.98]`**:

```
taskFit = 0.4 + 0.58 * ((elo - minElo) / (maxElo - minElo))
```

Skor tidak pernah mencapai `0` atau `1`, sehingga menyisakan ruang untuk penimpaan oleh pengguna.
Inilah field `score` yang Anda lihat di respons API dan label yang ditampilkan di dasbor.

### Tingkat Keyakinan

Setiap entri mendapatkan tingkat keyakinan berdasarkan jumlah suara Arena:

| Keyakinan | Suara   |
| --------- | ------- |
| `high`    | ≥ 5,000 |
| `medium`  | ≥ 1,000 |
| `low`     | < 1,000 |

### Penyimpanan dan kebaruan

Entri yang dinormalisasi ditulis ke tabel DB `model_intelligence` dengan
`source = "arena_elo"` (`src/lib/db/modelIntelligence.ts`). Entri **kedaluwarsa setelah
7 hari**, sehingga provider yang berhenti melakukan sinkronisasi pada akhirnya akan hilang
dari daftar alih-alih menyajikan data usang.

Sinkronisasi berjalan **aktif secara default**:

- Berjalan sekali saat server dinyalakan, lalu secara berkala melalui timer
  (`src/lib/arenaEloSync.ts`, dihubungkan dari `src/instrumentation-node.ts`).
- Sifatnya **non-blocking dan tidak pernah fatal** — jika pengambilan dari upstream gagal,
  OmniRoute tetap berjalan dan peringkat cukup menampilkan data baik terakhir (atau keadaan kosong).

Dua variabel lingkungan mengendalikannya (didokumentasikan di
[`docs/reference/ENVIRONMENT.md`](../reference/ENVIRONMENT.md)):

| Variabel                  | Default       | Tujuan                                                   |
| ------------------------- | ------------- | -------------------------------------------------------- |
| `ARENA_ELO_SYNC_ENABLED`  | `true`        | Atur ke `false` untuk menonaktifkan sinkronisasi keluar. |
| `ARENA_ELO_SYNC_INTERVAL` | `86400` (24h) | Interval sinkronisasi, dalam detik.                      |

### Sinkronisasi manual / status / hapus

Untuk operator, endpoint manajemen terautentikasi menyediakan kendali manual
(`src/app/api/intelligence/sync/route.ts` — memerlukan autentikasi manajemen):

```
GET    /api/intelligence/sync          # status sinkronisasi saat ini (enabled, lastSync, nextSync, intervalMs)
POST   /api/intelligence/sync          # picu sinkronisasi manual; body: { "dryRun": true } untuk pratinjau tanpa menulis
DELETE /api/intelligence/sync          # hapus semua entri intelligence arena_elo yang telah disinkronkan
```

Jika halaman peringkat kosong, `POST /api/intelligence/sync` manual (atau cukup dengan
memulai ulang server) akan mengisinya kembali.

### Mencocokkan model dengan papan peringkat

ID model di registry dan nama model Arena tidak selalu sama persis. Pemeringkatan menggunakan
pencocokan fleksibel (`findMatchingIntelligence` di `src/lib/freeProviderRankings.ts`):

1. Pencocokan persis pada ID model yang dinormalisasi.
2. Pencocokan setelah menghapus akhiran versi di bagian belakang (mis. `kimi-k2.6` → `kimi-k2`).
3. Pencocokan awalan (nama model di papan peringkat merupakan awalan dari ID registry).

Di sisi sinkronisasi, awalan vendor yang dikenal (`anthropic/`, `openai/`, `google/`, …)
dihapus dan peta alias kecil memperluas nama kanonis menjadi varian yang digunakan OmniRoute
secara internal, sehingga model tetap dapat ditemukan dengan nama apa pun.

### Cara provider diperingkat

Untuk setiap provider gratis, mesin memberi skor pada setiap model dalam katalognya, lalu:

- **Model Teratas** = model dengan skor tertinggi milik provider tersebut.
- **Skor Rata-rata** = skor rata-rata di seluruh model provider tersebut yang telah diberi skor.
- **Model** = berapa banyak model provider yang memiliki skor Arena.

Provider diurutkan berdasarkan **skor model teratas** terlebih dahulu, lalu berdasarkan skor
rata-rata. Ini memberi penghargaan kepada provider yang menyediakan setidaknya satu model gratis
yang kuat.

## Menggunakannya untuk Memilih Penyedia Gratis

1. **Pilih kategori yang tepat.** Gunakan filter **Coding** untuk beban kerja agen/kode, atau
   biarkan pada **All Categories** / **Default** untuk percakapan umum. Penyedia yang sama dapat
   memiliki peringkat berbeda di setiap kategori karena model terbaiknya berbeda pada tiap papan peringkat.
2. **Utamakan posisi podium untuk penyiapan sekali jalan.** Jika Anda hanya ingin menghubungkan satu atau dua
   penyedia gratis, mulailah dengan penyedia berperingkat tertinggi untuk kategori Anda.
3. **Periksa lencana Type.** Penyedia `NOAUTH` paling cepat dihubungkan (tanpa
   kredensial). Tingkat gratis `OAUTH` / `APIKEY` memerlukan pendaftaran singkat, tetapi sering kali menyediakan
   model yang lebih canggih. Lihat [Panduan Tingkat Gratis](../getting-started/FREE-TIERS-GUIDE.md) untuk
   langkah-langkah koneksi.
4. **Hubungkan beberapa penyedia dan biarkan Auto-Combo menentukan pilihan.** Data Arena ELO yang sama yang mendukung
   halaman ini juga digunakan sebagai **faktor kecocokan tugas** oleh mesin penilaian Auto-Combo
   (`open-sse/services/autoCombo/taskFitness.ts`, urutan resolusi
   `user_override → arena_elo → models_dev_tier → static table`). Jadi, setelah Anda menghubungkan
   penyedia gratis teratas, perutean dengan `model: "auto"` (misalnya `auto/coding`) akan
   secara otomatis mengutamakan model gratis berkualitas lebih tinggi untuk setiap permintaan. Lihat
   [Auto-Combo](../routing/AUTO-COMBO.md) untuk sistem penilaian 16 faktor secara lengkap.
