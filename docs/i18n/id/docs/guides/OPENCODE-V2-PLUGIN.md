`@omniroute/opencode-plugin-v2` memasukkan seluruh katalog OmniRoute Anda — model, combo, dan
auto-combo — ke pemilih model OpenCode v2, lengkap dengan nama tampilan, harga, dan
anggaran tingkat gratis.

Paket ini terpisah dari `@omniroute/opencode-plugin` karena OpenCode v1 dan v2 memuat
plugin melalui kontrak yang berbeda. Pilih paket yang sesuai dengan versi mayor OpenCode Anda;
tidak ada komponen yang digunakan bersama, sehingga meningkatkan versi salah satunya tidak pernah
memaksa peningkatan versi yang lain.

## Persyaratan

- OpenCode v2.
- Gateway OmniRoute yang dapat dijangkau (`http://localhost:20128` secara default).
- Node.js 22 atau 24.

## Instalasi

Tambahkan plugin ke `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

Model kemudian muncul sebagai `omniroute/<provider>/<model>`; `providerId` menentukan prefiks
tersebut dan id integrasi tempat OpenCode menyimpan kredensial.

## Kredensial

Plugin mencari kunci gateway di tiga tempat, dengan urutan berikut:

1. **Kredensial yang Anda hubungkan di OpenCode.** Plugin mendaftarkan integrasi, sehingga
   alur autentikasi bawaan OpenCode dapat menyimpan kunci tersebut. Tidak ada yang disimpan dalam
   `opencode.json` — utamakan cara ini.
2. `apiKey` dalam opsi plugin, untuk penimpaan per proyek. Cara ini menempatkan kunci dalam sebuah
   file yang mungkin Anda commit.
3. `OMNIROUTE_API_KEY` dalam environment.

Jika ketiganya tidak tersedia, katalog akan kosong dan plugin akan memberitahukannya sekali saat
startup, alih-alih membiarkan Anda menghadapi pemilih kosong tanpa penjelasan.

### Token manajemen adalah kunci yang berbeda

Combo, status penyedia, dan pengayaan (nama tampilan, harga, serta anggaran tingkat gratis) berasal
dari endpoint `/api/*` milik gateway, yang pada sebagian besar deployment dilindungi oleh token
**manajemen**, bukan kunci inferensi:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<token baca manajemen>"
}
```

Jika tidak ditetapkan, `managementReadToken` akan menggunakan `apiKey` sebagai fallback. Ketika
gateway menolak fallback tersebut, katalog tetap dipublikasikan, tetapi menggunakan id model mentah
alih-alih nama tampilan, tanpa deduplikasi alias kanonis, tanpa harga, dan tanpa combo. Plugin
memberikan peringatan satu kali per endpoint ketika hal itu terjadi, dengan menyebutkan endpoint dan
apa yang hilang — sehingga penyebab pemilih yang terdegradasi selalu jelas.

## Pilihan

| Kunci                            | Bawaan                                         | Catatan                                                                                                                                                                                                                                                                                                                                                                             |
| -------------------------------- | ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `providerId`                     | `"omniroute"`                                  | Id penyedia, id integrasi, dan model awalan muncul di bawah                                                                                                                                                                                                                                                                                                                         |
| `baseURL`                        | diperlukan                                     | Akar gerbang, hanya `http(s)` ; akhiran `/v1` ditambahkan jika diperlukan                                                                                                                                                                                                                                                                                                           |
| `apiKey`                         | kredensial terhubung, lalu `OMNIROUTE_API_KEY` | Kunci obrolan untuk `/v1/*`                                                                                                                                                                                                                                                                                                                                                         |
| `managementReadToken`            | jatuh kembali ke `apiKey`                      | Kunci untuk `/api/*` — biasanya** bukan** yang sama                                                                                                                                                                                                                                                                                                                                 |
| `displayName`                    | `"OmniRoute"`                                  | Nama penyedia di pemilih                                                                                                                                                                                                                                                                                                                                                            |
| `timeoutMs`                      | `10000`                                        | Batas waktu pengambilan per titik akhir (kombo otomatis menggunakan 5 detik)                                                                                                                                                                                                                                                                                                        |
| `modelCacheTtlMs`                | `300000`                                       | Cache katalog TTL; snapshot disk yang menghangat mulai dingin                                                                                                                                                                                                                                                                                                                       |
| `timeouts`                       | jatuh kembali ke `timeoutMs`                   | Anggaran per titik akhir dalam ms: `models`, `combos`, `autoCombos`, `enrichment`                                                                                                                                                                                                                                                                                                   |
| `enrichment`                     | `true`                                         | Ambil nama, harga, dan anggaran tingkat gratis                                                                                                                                                                                                                                                                                                                                      |
| `providerTag`                    | `true`                                         | Alihkan tanda kurung editor di akhir: `Provider - Model (Editor)`. Penyedia (rute yang melayani model) selalu ditampilkan; editor (yang membuat model) hanya muncul di dalam tanda kurung. Contoh: `Openrouter - MoonshotAI: Kimi K 3.1 Pro` -> `Openrouter - Kimi K 3.1 Pro (MoonshotAI)`. Dihilangkan ketika editor dan penyedia berbagi nama. Atur `false` untuk menjatuhkannya. |
| `usableOnly`                     | `false`                                        | Pertahankan hanya penyedia yang dilaporkan oleh gateway sebagaimana disediakan                                                                                                                                                                                                                                                                                                      |
| `combosSource`                   | `"api"`                                        | `"models"` melewatkan `/api/combos` dan menerbitkan baris kombo `/v1/models` ; filter tingkat anggota tetap `"api"`                                                                                                                                                                                                                                                                 |
| `showcasePerOwner`               | `10`                                           | Entri tampilan default disimpan per penyedia                                                                                                                                                                                                                                                                                                                                        |
| `freshPerOwner`                  | `10`                                           | Entri baru tampilan default disimpan per penyedia                                                                                                                                                                                                                                                                                                                                   |
| `freshWindowDays`                | `90`                                           | Jendela kesegaran dalam beberapa hari untuk cabang segar                                                                                                                                                                                                                                                                                                                            |
| `usageMemory`                    | `true`                                         | Pulihkan entri yang dihapus secara statis yang diberi nama berdasarkan analisis penggunaan 30 hari (membutuhkan token manajemen)                                                                                                                                                                                                                                                    |
| `visibleModels` / `hiddenModels` | `[]`                                           | Daftar yang diizinkan persis atau akhiran; menyangkal kemenangan; `*` menerbitkan katalog lengkap (filter lain masih berlaku)                                                                                                                                                                                                                                                       |
| `geminiSanitization`             | `true`                                         | Hapus kata kunci JSON-Schema yang ditolak Gemini dari skema alat ( alat `$ref` diteruskan tanpa disentuh)                                                                                                                                                                                                                                                                           |
| `apiFormat.allowAnthropic`       | `false`                                        | Rutekan id yang diizinkan melalui blok Anthropic API                                                                                                                                                                                                                                                                                                                                |
| `apiFormat.anthropicModels`      | `[]`                                           | Id model lengkap dialihkan ke Anthropic                                                                                                                                                                                                                                                                                                                                             |
| `logLevel` / `startupDebug`      | `warn` / `false`                               | Catat verbositas                                                                                                                                                                                                                                                                                                                                                                    |

Memori penggunaan diaktifkan secara default. Tanpa token manajemen, token tersebut tetap inert (pemberitahuan startup dicatat) dan tidak ada yang dipulihkan.

## Bagaimana katalognya tetap segar

Katalog diambil dengan lambat dan di-cache untuk `modelCacheTtlMs`, dan snapshot disk membuat katalog terakhir yang diketahui tetap tersedia ketika gateway tidak dapat dijangkau — jika pemadaman tidak mengeluarkan biaya apa pun selain kesegaran. Model dan kombo diterbitkan segera setelah tiba; kombo otomatis, daftar penyedia dan hamparan pengayaan terlipat saat mendarat, sehingga satu titik akhir yang lambat tidak dapat menyandera seluruh pemilih.

Nama mengikuti `Provider - Model[ (Editor)][ · budget][ (route)]`: penyedia ditampilkan setiap kali id membawa satu (id tanpa garis miring ditampilkan tanpa awalan), `🆓` di awal menandai entri gratis dan anggaran tingkat gratisnya tetap sebagai akhiran `· 1M tokens/month`, editor nama `Editor: Model` eksplisit berpindah ke tanda kurung di akhir (tidak ada editor yang dapat ditebak dari nama lain), dan kombo dirender sebagai `combo - <slug>` tanpa ikon gratis. Dua entri yang memiliki nama yang sama mendapatkan akhiran rute — `(no-think)` — sehingga tetap dapat dibedakan. `providerTag` (default `true`) mengaktifkan tanda kurung editor di akhir.

Tidak ada perintah penyegaran manual: perintah OpenCode v2 adalah templat prompt, bukan callback, sehingga plugin tidak dapat mengeksposnya. Penyegaran ikuti TTL; host diminta untuk memuat ulang hanya ketika katalog atau overlay benar-benar berubah, tidak pernah satu kali pun untuk menyegarkan.

## Pemanggilan alat di Gemini

Gemini menolak seluruh permintaan yang deklarasi alatnya memuat `$schema` atau
`additionalProperties`, dengan respons `400 INVALID_ARGUMENT`. Plugin menghapus kata kunci tersebut dari
skema alat yang ditujukan untuk model Gemini dari penyedia ini dan membiarkan setiap permintaan lainnya
tidak berubah. Alat yang memuat `$ref` diteruskan tanpa perubahan alih-alih dihapus, karena menghapus
referensi tersebut akan memperluas skema menjadi "terima apa pun".
Atur `"geminiSanitization": false` untuk menonaktifkannya.

## Pemecahan masalah

| Gejala                                    | Menyebabkan                                                                                                                    |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Picker tidak menunjukkan model OmniRoute  | Tidak ada kunci yang terselesaikan (periksa peringatan pengaktifan), atau gateway tidak dapat dijangkau                        |
| ID model mentah, tanpa kombo, tanpa harga | Titik akhir manajemen menolak token — set `managementReadToken`                                                                |
| Katalog `freeOnly` pendek atau kosong     | Tidak ada token manajemen atau token yang ditolak — membaca baris ringkasan penyegaran ( jumlah `unmatched-free` ) di log host |
| Sesi disematkan ke `opencode-<id>/...`    | Plugin v1 menerbitkan `opencode-<id>`; v2 menerbitkan `<id>` telanjang, jadi pilih kembali model di bawah `<id>/...`           |

Variabel lingkungan harus mencapai proses server kode terbuka: ketika host dijalankan sebagai layanan, shell yang menjalankan `opencode models` dan lingkungan server berbeda, jadi ekspor kunci tempat server membacanya.
