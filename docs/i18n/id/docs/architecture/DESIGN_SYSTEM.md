> **Status:** dashboard dibangun di atas **Keak CI UI Kit** (`@keak/cheaper-inference-ui-kit`), di-vendor
> sebagai workspace `packages/ui-kit` (`@omniroute/ui-kit`; snapshot upstream disematkan di
> `packages/ui-kit/UPSTREAM.md` dan dijaga oleh `npm run check:ui-kit-snapshot`). Light adalah tema
> kanonik; preferensi default-nya adalah `system`. Aksennya adalah Keak lime (`--ci-color-accent`). Inter
> (letter-spacing 0, `--ci-letter-spacing-ui`) adalah famili font UI, Instrument Serif hanya untuk teks
> tampilan besar yang jarang (`.ci-dashboard-display`), IBM Plex Mono untuk kode — semuanya di-hosting
> sendiri melalui impor `@fontsource/*` di bagian atas `src/app/globals.css`. Setiap ikon adalah glif Lucide.

## 1. Di mana semuanya berada

- **Kit.** `packages/ui-kit/src` adalah salinan byte-per-byte dari `src/` upstream pada commit yang di-pin di
  `packages/ui-kit/UPSTREAM.md` (yang juga mencatat otorisasi lisensi); `PATCHES.md` mencantumkan patch
  lokal (tidak ada). Kit ini dikonsumsi sebagai sumber, tanpa build: `next.config.mjs` mentranspilasinya,
  dan `tsconfig.json` memetakan `@omniroute/ui-kit` → `packages/ui-kit/src` dan `@omniroute/ui-kit/*` →
  `packages/ui-kit/src/*` (`vitest.config.ts` dan `vitest.mcp.config.ts` membawa alias yang sama). Impor
  komponen kit melalui subpath-nya (`@omniroute/ui-kit/table`, `@omniroute/ui-kit/page-header`…), jangan
  pernah melalui barrel `@omniroute/ui-kit`: barrel menarik setiap komponen (termasuk date picker) ke
  setiap pengimpor. Stylesheet kit masuk melalui `src/app/globals.css`
  (`@import "../../packages/ui-kit/src/ci-ui.css"`).
- **Token.** `packages/ui-kit/src/ci-tokens.css` mendeklarasikan token `--ci-*`; `src/app/globals.css`
  menjembatani token tersebut ke nama OmniRoute legasi (`--color-*`, `--radius-*`,
  `--font-sans`/`--font-mono`, `--table-*`, `--orch-status-*`, `--color-fd-*`), sehingga pembacaan
  `var(--color-*)` yang sudah ada dan utilitas Tailwind tetap berfungsi. Kode baru menggunakan utilitas
  Tailwind (`bg-surface`, `text-text-muted`, `border-border`, `text-success`, `bg-success-bg`,
  `bg-chart-1`…) atau kelas kit — tidak pernah nilai hex (`tests/unit/design-kit-bridge.test.ts`
  menegakkan jembatan tersebut). `text-primary` meresolusi ke `--color-primary-ink` melalui
  `--text-color-primary` (lime-800 di mode terang, aksen lime di mode gelap), sehingga teks primer tetap
  terbaca sementara `bg-primary`/`border-primary` mempertahankan permukaan lime. Seri chart menggunakan
  `--color-chart-1` … `--color-chart-5`.
- **Tema.** `<html className="ci-theme">` (`src/app/layout.tsx`) mengaktifkan tema kit pada dokumen.
  Preferensinya adalah `light`, `dark` atau `system` (`THEME_CONFIG.defaultTheme = "system"` di
  `src/shared/constants/appConfig.ts`; `system` mengikuti `prefers-color-scheme`). `applyTheme()` di
  `src/store/themeStore.ts` (dicerminkan oleh skrip bootstrap inline di `src/app/layout.tsx`, yang berjalan
  sebelum hydration) menetapkan `data-theme="dark"|"light"` dan men-toggle kelas `.dark` pada `<html>`
  secara bersamaan. Set token gelap kit dikaitkan pada `data-theme="dark"`
  (`packages/ui-kit/src/ci-tokens.css`); override gelap milik OmniRoute sendiri (blok `.dark` di
  `globals.css`) dan utilitas `dark:` Tailwind legasi dikaitkan pada kelas `.dark`. Tidak ada preset warna
  aksen: aksen selalu berasal dari kit, dan preset tersimpan dari build lama dibuang saat store dimuat.
- **Komponen (adapter).** `src/shared/components/index.tsx` mempertahankan API komponen OmniRoute (nama
  yang sama, default export dan props), dan primitif di baliknya adalah adapter di atas kit: form
  (`Button`, `Input`, `Textarea`, `Checkbox`, `Select`, `Toggle`, `Badge`, `Card`), overlay dan umpan
  balik (`Modal`/`ConfirmModal`, `Tooltip`/`InfoTooltip`, `NotificationToast`, `EmptyState`, `Loading`),
  struktur (`Collapsible`, `CollapsibleSection`, `SegmentedControl`, `Breadcrumbs`, `Avatar`) dan tabel
  (`DataTable`, `FilterBar`, `ColumnToggle`, `FilterPills`, `PresetSlider`). Sebuah adapter mengimpor
  komponen kit berdasarkan subpath dan memetakan props legasi ke komponen tersebut — misalnya
  `Button variant="primary"` adalah tombol `default` kit (`--ci-button-primary-*`: permukaan terbalik di
  mode terang, aksen dengan tinta `--ci-color-accent-foreground`-nya di mode gelap), `danger` adalah
  `destructive`, dan `warning` adalah `outline` plus ekstensi `.ci-button--warning`. Aturan
  `.ci-button--warning` dan `.ci-badge[data-tone]` di akhir `globals.css` (`@layer components`) adalah
  ekstensi OmniRoute di atas kelas kit. `tests/unit/ui/adapters/*.test.tsx` mem-pin setiap adapter.
- **Shell.** `src/app/(dashboard)/layout.tsx` me-render `DashboardLayout`, yang me-render
  `src/shared/components/layouts/DashboardShell.tsx`: `SidebarProvider` / `Sidebar` / `SidebarInset` kit
  (`packages/ui-kit/src/sidebar.tsx`), dengan logika navigasi OmniRoute di
  `src/shared/components/Sidebar.tsx`. Tautan "lewati ke konten" ke `#main-content` adalah elemen yang
  dapat difokuskan pertama. `src/shared/components/Header.tsx` menampung `SidebarTrigger` kit (satu-satunya
  toggle sidebar milik shell), `ProductSwitcher` Keak dan pembuka command-palette; ia menampilkan judul
  rute hanya selama tidak ada `PageHeader` kit (`.ci-page-header`) yang ter-mount di dalam
  `#main-content`, sehingga halaman dengan `PageHeader`-nya sendiri memiliki satu `h1`.
  `src/shared/components/CommandPalette.tsx` adalah `Dialog` kit.
- **Ikon.** `<Icon name="material_name">` (`src/shared/components/Icon.tsx`) meresolusi nama (kosakata
  Material Symbols yang digunakan layar-layar) melalui `ICON_MAP` (`src/shared/constants/iconMap.ts`)
  menjadi glyph Lucide. Font dan paket Material Symbols sudah tidak ada: nama yang tidak ada di map
  merender glyph placeholder netral (`data-icon-missing="true"`) dan mencatat peringatan konsol di luar
  produksi. `npm run gen:icon-map` mencetak nama-nama yang digunakan yang tidak ada di map
  (`tests/unit/icon-map-coverage.test.ts` gagal pada nama apa pun tanpa ikon Lucide;
  `tests/unit/icon-map-object-values.test.ts` mencakup nama yang disimpan dalam objek lookup);
  `scripts/dev/codemod-material-icons.mjs <dir|file>... [--write]` menulis ulang span literal
  `<span className="material-symbols-outlined">` menjadi `<Icon>`.
- **Merek.** `src/shared/components/OmniRouteLogo.tsx` membungkus kit: default export `OmniRouteLogo`
  me-render `ProductIcon product="omniroute" variant="glyph"` (SVG inline, aman terhadap `basePath`) dan
  `OmniRouteLockup` me-render `ProductLockup product="omniroute"` (nama aksesibel "Keak OmniRoute") atau,
  untuk operator white-label, `name`/`logoSrc` mereka sendiri. Tujuan product-switcher berada di
  `src/shared/constants/keakProducts.ts` (`KEAK_PRODUCT_LINKS`, `KEAK_ACTIVE_PRODUCT`). Layar-layar
  standalone — `src/app/login/page.tsx`, `src/app/status/page.tsx`, `src/app/maintenance/page.tsx`,
  `src/app/offline/page.tsx`, `src/app/not-found.tsx` dan
  `src/shared/components/ErrorPageScaffold.tsx` — menampilkan lockup;
  `tests/unit/brand-pages-static.test.ts` menjaganya.

## 2. Aturan

1. Token, jangan pernah literal. Pengecualian sengaja dipertahankan: terminal konsol yang selalu gelap, goresan SVG ReactFlow melalui `STATUS_HEX` (`src/shared/constants/statusColors.ts`), dan palet kategoris `STRATEGY_COLORS` (`src/app/(dashboard)/dashboard/combos/live/nodes/StrategyNode.tsx`) serta `LAYER_COLORS` (`src/app/(dashboard)/dashboard/compression/studio/nodes/EngineNode.tsx`).
2. Jangan pernah menambal `packages/ui-kit/src` secara manual: sinkronkan dengan `scripts/dev/sync-ui-kit.sh <commit>`; gerbang pra-commit `npm run check:ui-kit-snapshot` (`.husky/pre-commit`) gagal pada byte apa pun yang berbeda dari commit upstream yang di-pin (dilewati dengan peringatan ketika clone upstream, `UI_KIT_CLONE` atau `_references/cheaper-inference-ui-kit`, tidak ada). Ketika kit kekurangan sesuatu, siasati di adapter atau layar dan mintakan ke upstream.
3. Default teks kit adalah bahasa Inggris (`label = "Loading"`, `loadingLabel = "Loading table"`…) — teruskan string terjemahan dari `useTranslations(...)` setiap kali komponen kit merender teks.
4. Utility Tailwind mengalahkan kelas komponen kit (kit mendeklarasikan `@layer theme, base, components, utilities` dan aturannya berada di `components`) — gunakan utility untuk spasi dan tata letak, bukan untuk mewarnai ulang komponen kit.
5. Heading: `.ci-heading` (Inter, tanpa tracking) untuk judul halaman dan bagian; `.ci-dashboard-display` (Instrument Serif) hanya untuk teks display besar yang jarang, seperti kode status halaman error.
6. `tests/unit/dashboard-kit-sweep.test.ts` menjaga adopsi kit: tidak ada span ligatur Material di bawah `src/app` atau `src/shared/components`; di pohon dashboard (`src/app/(dashboard)` dan `src/shared/components`) tidak ada `<select>`, `<textarea>` atau `<table>` mentah dan tidak ada `role="dialog"` buatan manual di luar pengecualian yang terdaftar (cabang native milik adapter `Select`, `RequestLoggerDetail`); setiap `<button>` atau `<input>` mentah di sana memerlukan komentar berisi `kit-exception:` (beserta alasannya) yang berakhir maksimal 3 baris di atasnya; hue palet dan varian `dark:` hanya di file yang tercantum dalam pengujian.
7. Verifikasi kedua tema dan viewport 390 px sebelum PR (screenshot); `tests/e2e/a11y.spec.ts` menjalankan axe.

## 3. Menambahkan layar

1. Buka halaman dengan `PageHeader` kit (`@omniroute/ui-kit/page-header`, `compact` di dalam dashboard) — judul, deskripsi, dan `actions`. Header shell kemudian menghilangkan judulnya sendiri.
2. Bangun kontrol dari `@/shared/components` (adapter) dan gunakan komponen kit melalui subpath di mana adapter belum ada (`Table`/`TableScrollArea`/`DataTableShell`, `Field`, `Alert`, `Tabs`, `RadioGroup`, `Slider`…).
3. Ikon: `<Icon name="…" />`. Nama baru masuk ke `ICON_MAP` dengan komponen Lucide yang cocok secara semantik; `npm run gen:icon-map` mencantumkan nama yang masih belum ada.
4. Warna: utility semantik (`text-success`, `bg-warning-bg`, `border-border`…) dan `var(--color-chart-N)` untuk seri grafik; tanpa nilai hex dan tanpa varian `dark:` yang sekadar mengulang warna.
5. Teks: setiap string, termasuk label yang Anda teruskan ke komponen kit, berasal dari `useTranslations`. Kunci baru masuk ke `src/i18n/messages/en.json`, `pt-BR.json` dan `vi.json` (pengujian paritas Bahasa Vietnam mengunci setiap kunci bahasa Inggris); locale lainnya diisi oleh sinkronisasi i18n.
6. Jalankan penjaga sebelum PR: `tests/unit/dashboard-kit-sweep.test.ts`, `tests/unit/icon-map-coverage.test.ts`, `tests/unit/icon-map-object-values.test.ts`, `npm run check:dashboard-typecheck` (satu-satunya pemeriksaan yang menangkap impor duplikat di `iconMap.ts`), `npm run check:ui-icu`, dan pengujian milik layar itu sendiri.

## 4. Menambahkan atau mengubah adapter

1. Pertahankan API publik `src/shared/components/index.tsx`: nama ekspor yang sama, ekspor default, dan
   props yang diterima. Petakan props lama ke kit di dalam adapter (lihat `Button.tsx`: `VARIANT_TO_KIT`,
   `SIZE_TO_KIT`).
2. Impor kit melalui subpath (`@omniroute/ui-kit/<component>`).
3. Solusi sementara untuk kekurangan kit ditempatkan di adapter (atau di `globals.css` `@layer components`
   jika perbaikannya berupa gaya), tidak pernah di `packages/ui-kit/src`.
4. Tambahkan atau perbarui `tests/unit/ui/adapters/<name>.test.tsx`. Untuk adapter dengan banyak pemanggil,
   bandingkan markup yang dirender sebelum dan sesudah perubahan — perubahan padding atau wrapper menyebar
   ke setiap layar.

## 5. Memperbarui kit

`scripts/dev/sync-ui-kit.sh <commit> [clone]` menyalin `src/` upstream pada commit tersebut ke
`packages/ui-kit/src` dan menerapkan satu-satunya transformasi yang diizinkan (menghapus akhiran `.js`
dari impor relatif). Kemudian: tinjau `git diff packages/ui-kit`, lakukan pemeriksaan visual pada halaman
provider, pengaturan, kombo, penggunaan, dan endpoint di kedua tema, jalankan `npm run check:ui-kit-snapshot`
dan `npm run test:vitest:ui`, lalu buka PR dengan changelog upstream.
