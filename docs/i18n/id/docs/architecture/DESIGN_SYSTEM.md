> **Status:** dasbor dibangun menggunakan **Keak CI UI Kit** (`@keak/cheaper-inference-ui-kit`), yang disertakan
> sebagai workspace `packages/ui-kit` (`@omniroute/ui-kit`; snapshot upstream disematkan di
> `packages/ui-kit/UPSTREAM.md` dan dijaga oleh `npm run check:ui-kit-snapshot`). Light adalah tema
> kanonis; preferensi default adalah `system`. Aksennya menggunakan warna lime Keak (`--ci-color-accent`). Inter
> (letter-spacing 0, `--ci-letter-spacing-ui`) adalah jenis huruf UI, Instrument Serif hanya untuk teks tampilan
> berukuran besar dan renggang (`.ci-dashboard-display`), serta IBM Plex Mono untuk kode — semuanya di-hosting sendiri melalui
> impor `@fontsource/*` di bagian atas `src/app/globals.css`. Setiap ikon merupakan glif Lucide.

## 1. Lokasi berbagai komponen

- **Kit.** `packages/ui-kit/src` adalah salinan byte-per-byte dari `src/` upstream pada commit yang dipatok dalam
  `packages/ui-kit/UPSTREAM.md` (yang juga mencatat otorisasi lisensi); `PATCHES.md` mencantumkan patch lokal
  (tidak ada). Paket ini digunakan sebagai source tanpa proses build: `next.config.mjs` mentranspilasinya, dan
  `tsconfig.json` memetakan `@omniroute/ui-kit` → `packages/ui-kit/src` dan `@omniroute/ui-kit/*` →
  `packages/ui-kit/src/*` (`vitest.config.ts` dan `vitest.mcp.config.ts` memiliki alias yang sama). Impor
  komponen kit berdasarkan subpath-nya (`@omniroute/ui-kit/table`, `@omniroute/ui-kit/page-header`…), jangan
  pernah melalui barrel `@omniroute/ui-kit`: barrel tersebut menarik setiap komponen (termasuk pemilih tanggal)
  ke dalam setiap pengimpor. Stylesheet kit dimuat melalui `src/app/globals.css`
  (`@import "../../packages/ui-kit/src/ci-ui.css"`).
- **Token.** `packages/ui-kit/src/ci-tokens.css` mendeklarasikan token `--ci-*`; `src/app/globals.css`
  menjembataninya dengan nama lama OmniRoute (`--color-*`, `--radius-*`, `--font-sans`/`--font-mono`,
  `--table-*`, `--orch-status-*`, `--color-fd-*`), sehingga pembacaan `var(--color-*)` yang sudah ada dan
  utilitas Tailwind tetap berfungsi. Kode baru menggunakan utilitas Tailwind (`bg-surface`, `text-text-muted`,
  `border-border`, `text-success`, `bg-success-bg`, `bg-chart-1`…) atau class kit — jangan pernah menggunakan
  nilai heksadesimal (`tests/unit/design-kit-bridge.test.ts` memastikan keberadaan bridge tersebut). `text-primary`
  di-resolve menjadi `--color-primary-ink` melalui `--text-color-primary` (lime-800 dalam tema terang, aksen lime
  dalam tema gelap), sehingga teks primer tetap mudah dibaca sementara `bg-primary`/`border-primary`
  mempertahankan permukaan lime. Seri grafik menggunakan `--color-chart-1` … `--color-chart-5`.
- **Tema.** `<html className="ci-theme">` (`src/app/layout.tsx`) mengikutsertakan dokumen dalam tema kit.
  Preferensinya adalah `light`, `dark`, atau `system` (`THEME_CONFIG.defaultTheme = "system"` dalam
  `src/shared/constants/appConfig.ts`; `system` mengikuti `prefers-color-scheme`). `applyTheme()` dalam
  `src/store/themeStore.ts` (dicerminkan oleh skrip bootstrap inline dalam `src/app/layout.tsx`, yang dijalankan
  sebelum hidrasi) menetapkan `data-theme="dark"|"light"` dan mengaktifkan atau menonaktifkan class `.dark`
  pada `<html>` secara bersamaan. Kumpulan token gelap kit menggunakan `data-theme="dark"` sebagai acuan
  (`packages/ui-kit/src/ci-tokens.css`); override gelap milik OmniRoute sendiri (blok `.dark` dalam `globals.css`)
  dan utilitas lama Tailwind `dark:` menggunakan class `.dark` sebagai acuan. Tidak ada preset warna aksen:
  aksen selalu berasal dari kit, dan preset tersimpan dari build lama dihapus ketika store dimuat.
- **Komponen (adapter).** `src/shared/components/index.tsx` mempertahankan API komponen OmniRoute (nama,
  ekspor default, dan props yang sama), dan primitive di belakangnya merupakan adapter atas kit: formulir
  (`Button`, `Input`, `Textarea`, `Checkbox`, `Select`, `Toggle`, `Badge`, `Card`), overlay dan umpan balik
  (`Modal`/`ConfirmModal`, `Tooltip`/`InfoTooltip`, `NotificationToast`, `EmptyState`, `Loading`),
  struktur (`Collapsible`, `CollapsibleSection`, `SegmentedControl`, `Breadcrumbs`, `Avatar`) dan tabel
  (`DataTable`, `FilterBar`, `ColumnToggle`, `FilterPills`, `PresetSlider`). Sebuah adapter mengimpor komponen
  kit berdasarkan subpath dan memetakan props lama ke komponen tersebut — misalnya `Button variant="primary"`
  adalah tombol `default` milik kit (`--ci-button-primary-*`: permukaan invers dalam tema terang, aksen dengan
  tinta `--ci-color-accent-foreground` dalam tema gelap), `danger` adalah `destructive`, dan `warning` adalah
  `outline` ditambah ekstensi `.ci-button--warning`. Aturan `.ci-button--warning` dan `.ci-badge[data-tone]`
  pada akhir `globals.css` (`@layer components`) merupakan ekstensi OmniRoute di atas class kit.
  `tests/unit/ui/adapters/*.test.tsx` mengunci perilaku setiap adapter.
- **Shell.** `src/app/(dashboard)/layout.tsx` merender `DashboardLayout`, yang merender
  `src/shared/components/layouts/DashboardShell.tsx`: kit `SidebarProvider` / `Sidebar` /
  `SidebarInset` (`packages/ui-kit/src/sidebar.tsx`), dengan logika navigasi OmniRoute dalam
  `src/shared/components/Sidebar.tsx`. Tautan "lewati ke konten" menuju `#main-content` adalah elemen pertama
  yang dapat menerima fokus. `src/shared/components/Header.tsx` memuat `SidebarTrigger` milik kit (satu-satunya
  tombol pengalih sidebar pada shell), `ProductSwitcher` Keak, dan pembuka palet perintah; komponen ini hanya
  menampilkan judul rute selama tidak ada `PageHeader` kit (`.ci-page-header`) yang terpasang di dalam
  `#main-content`, sehingga halaman yang memiliki `PageHeader` sendiri hanya memiliki satu `h1`.
  `src/shared/components/CommandPalette.tsx` adalah `Dialog` kit.
- **Ikon.** `<Icon name="material_name">` (`src/shared/components/Icon.tsx`) me-resolve nama tersebut
  (kosakata Material Symbols yang digunakan layar) melalui `ICON_MAP` (`src/shared/constants/iconMap.ts`) menjadi
  glyph Lucide. Font dan paket Material Symbols telah dihapus: nama yang tidak ada dalam peta akan merender glyph
  placeholder netral (`data-icon-missing="true"`) dan mencatat peringatan konsol di luar production.
  `npm run gen:icon-map` mencetak nama yang sedang digunakan tetapi tidak ada dalam peta
  (`tests/unit/icon-map-coverage.test.ts` gagal untuk setiap nama tanpa ikon Lucide;
  `tests/unit/icon-map-object-values.test.ts` mencakup nama yang disimpan dalam objek pencarian);
  `scripts/dev/codemod-material-icons.mjs <dir|file>... [--write]` menulis ulang span literal
  `<span className="material-symbols-outlined">` menjadi `<Icon>`.
- **Merek.** `src/shared/components/OmniRouteLogo.tsx` membungkus kit: ekspor default `OmniRouteLogo`
  merender `ProductIcon product="omniroute" variant="glyph"` (SVG inline, aman untuk `basePath`) dan
  `OmniRouteLockup` merender `ProductLockup product="omniroute"` (nama yang dapat diakses "Keak OmniRoute") atau,
  untuk operator white-label, `name`/`logoSrc` milik mereka sendiri. Tujuan product switcher berada dalam
  `src/shared/constants/keakProducts.ts` (`KEAK_PRODUCT_LINKS`, `KEAK_ACTIVE_PRODUCT`). Layar mandiri —
  `src/app/login/page.tsx`, `src/app/status/page.tsx`, `src/app/maintenance/page.tsx`,
  `src/app/offline/page.tsx`, `src/app/not-found.tsx` dan `src/shared/components/ErrorPageScaffold.tsx`
  — menampilkan lockup tersebut; `tests/unit/brand-pages-static.test.ts` menjaganya.

## 2. Aturan

1. Token, jangan pernah literal. Pengecualian dipertahankan dengan sengaja: terminal konsol yang
   selalu gelap dan `STATUS_HEX` (`src/shared/constants/statusColors.ts`), cermin hex yang sudah
   di-resolve dari palet status kit untuk pemanggil yang membutuhkan hex literal. Palet kategorikal
   tidak lagi menjadi pengecualian: palet tersebut memakai lima token chart milik kit
   (`--color-chart-1..5`) melalui `src/shared/utils/categoricalPalette.ts` dan, untuk strategi
   routing, `src/app/(dashboard)/dashboard/combos/strategyPalette.ts`; edge ReactFlow dan kanvas
   orkestrasi membaca variabel `--orch-status-*` yang peka tema
   (`src/shared/components/flow/edgeStyles.ts`).
2. Jangan pernah menambal `packages/ui-kit/src` secara manual: sinkronkan dengan
   `scripts/dev/sync-ui-kit.sh <commit>`; gerbang pre-commit `npm run check:ui-kit-snapshot`
   (`.husky/pre-commit`) gagal pada setiap byte yang berbeda dari commit upstream yang di-pin
   (dilewati dengan peringatan ketika clone upstream, `UI_KIT_CLONE` atau
   `_references/cheaper-inference-ui-kit`, tidak ada). Ketika kit tidak menyediakan sesuatu, atasi
   di adapter atau di layar dan ajukan permintaan ke upstream.
3. Default teks kit adalah bahasa Inggris (`label = "Loading"`, `loadingLabel = "Loading table"`…) —
   berikan string terjemahan dari `useTranslations(...)` setiap kali komponen kit merender teks.
4. Utility Tailwind menang atas kelas komponen kit (kit mendeklarasikan
   `@layer theme, base, components, utilities` dan aturannya berada di `components`) — gunakan
   utility untuk spasi dan tata letak, bukan untuk mewarnai ulang komponen kit.
5. Heading: `.ci-heading` (Inter, tanpa tracking) untuk judul halaman dan bagian;
   `.ci-dashboard-display` (Instrument Serif) hanya untuk teks display besar yang jarang, seperti
   kode status halaman error.
6. `tests/unit/dashboard-kit-sweep.test.ts` menjaga adopsi kit: tidak boleh ada span ligatur
   Material di bawah `src/app` atau `src/shared/components`; di pohon dashboard
   (`src/app/(dashboard)` dan `src/shared/components`) tidak boleh ada `<select>`, `<textarea>`
   atau `<table>` mentah maupun `role="dialog"` buatan sendiri di luar pengecualian yang tercantum
   (cabang native milik adapter `Select`, `RequestLoggerDetail`); setiap `<button>` atau `<input>`
   mentah di sana memerlukan komentar berisi `kit-exception:` (beserta alasannya) yang berakhir
   paling banyak 3 baris di atasnya; hue palet dan varian `dark:` hanya di file yang tercantum
   dalam test tersebut.
7. Verifikasi kedua tema dan viewport 390 px sebelum membuat PR (screenshot);
   `tests/e2e/a11y.spec.ts` menjalankan axe.

## 3. Menambahkan layar

1. Buka halaman dengan `PageHeader` dari kit (`@omniroute/ui-kit/page-header`, gunakan `compact` di dalam dashboard) — judul, deskripsi, dan `actions`. Header shell kemudian tidak menampilkan judulnya sendiri.
2. Buat kontrol dari `@/shared/components` (adaptor) dan gunakan komponen kit melalui subpath jika adaptor tidak tersedia (`Table`/`TableScrollArea`/`DataTableShell`, `Field`, `Alert`, `Tabs`, `RadioGroup`, `Slider`…).
3. Ikon: `<Icon name="…" />`. Nama baru dimasukkan ke `ICON_MAP` dengan komponen Lucide yang cocok secara semantik; `npm run gen:icon-map` mencantumkan nama yang masih belum tersedia.
4. Warna: gunakan utilitas semantik (`text-success`, `bg-warning-bg`, `border-border`…) dan `var(--color-chart-N)` untuk seri bagan; jangan gunakan nilai hex dan jangan gunakan varian `dark:` yang hanya mengulangi warna.
5. Teks: setiap string, termasuk label yang diteruskan ke komponen kit, berasal dari `useTranslations`. Key baru dimasukkan ke `src/i18n/messages/en.json`, `pt-BR.json`, dan `vi.json` (pengujian paritas bahasa Vietnam menyematkan setiap key bahasa Inggris); locale lainnya diisi melalui sinkronisasi i18n.
6. Jalankan pemeriksaan sebelum membuat PR: `tests/unit/dashboard-kit-sweep.test.ts`, `tests/unit/icon-map-coverage.test.ts`, `tests/unit/icon-map-object-values.test.ts`, `npm run check:dashboard-typecheck` (satu-satunya pemeriksaan yang mendeteksi impor duplikat di `iconMap.ts`), `npm run check:ui-icu`, serta pengujian untuk layar tersebut.

## 4. Menambahkan atau mengubah adapter

1. Pertahankan API publik `src/shared/components/index.tsx`: nama ekspor, ekspor default, dan
   props yang diterima harus tetap sama. Petakan props lama ke kit di dalam adapter (lihat `Button.tsx`: `VARIANT_TO_KIT`,
   `SIZE_TO_KIT`).
2. Impor kit melalui subpath (`@omniroute/ui-kit/<component>`).
3. Solusi sementara untuk kekurangan kit harus berada di adapter (atau di `globals.css` dalam `@layer components` jika
   perbaikannya berupa gaya), dan tidak boleh berada di `packages/ui-kit/src`.
4. Tambahkan atau perbarui `tests/unit/ui/adapters/<name>.test.tsx`. Untuk adapter yang memiliki banyak pemanggil, bandingkan
   markup yang dirender sebelum dan sesudah perubahan — perubahan padding atau wrapper akan menyebar ke setiap layar.

## 5. Memperbarui kit

`scripts/dev/sync-ui-kit.sh <commit> [clone]` menyalin `src/` upstream pada commit tersebut ke
`packages/ui-kit/src` dan menerapkan satu-satunya transformasi yang diizinkan (menghapus akhiran `.js` dari
impor relatif). Kemudian: tinjau `git diff packages/ui-kit`, lakukan pemeriksaan visual pada provider, pengaturan, combo,
penggunaan, dan endpoint dalam kedua tema, jalankan `npm run check:ui-kit-snapshot` dan `npm run test:vitest:ui`, lalu
buka PR dengan changelog upstream.
