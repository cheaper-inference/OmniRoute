> **Status:** dashboard dibangun di atas **Keak CI UI Kit** (`@keak/cheaper-inference-ui-kit`), di-vendorkan
> sebagai workspace `packages/ui-kit` (`@omniroute/ui-kit`; snapshot upstream dikunci di
> `packages/ui-kit/UPSTREAM.md` dan dijaga oleh `npm run check:ui-kit-snapshot`). Light adalah tema
> kanonis; preferensi default-nya adalah `system`. Aksennya adalah Keak lime (`--ci-color-accent`). Inter
> (letter-spacing 0, `--ci-letter-spacing-ui`) adalah famili font UI, Instrument Serif hanya untuk teks
> display besar yang minim (`.ci-dashboard-display`), IBM Plex Mono untuk kode — semuanya di-host sendiri
> melalui impor `@fontsource/*` di bagian atas `src/app/globals.css`. Setiap ikon adalah glyph Lucide.

## 1. Di mana semuanya berada

- **Kit.** `packages/ui-kit/src` adalah salinan byte-for-byte dari `src/` upstream pada commit yang disematkan di
  `packages/ui-kit/UPSTREAM.md` (yang juga mencatat otorisasi lisensi); `PATCHES.md` mencantumkan patch
  lokal (tidak ada). Kit ini dikonsumsi sebagai source, tanpa build: `next.config.mjs` mentranspilasinya, dan
  `tsconfig.json` memetakan `@omniroute/ui-kit` → `packages/ui-kit/src` dan `@omniroute/ui-kit/*` →
  `packages/ui-kit/src/*` (`vitest.config.ts` dan `vitest.mcp.config.ts` membawa alias yang sama). Impor
  komponen kit melalui subpath-nya (`@omniroute/ui-kit/table`, `@omniroute/ui-kit/page-header`…), jangan pernah
  melalui barrel `@omniroute/ui-kit`: barrel menarik setiap komponen (termasuk date picker)
  ke setiap pengimpor. Stylesheet kit masuk melalui `src/app/globals.css`
  (`@import "../../packages/ui-kit/src/ci-ui.css"`).
- **Tokens.** `packages/ui-kit/src/ci-tokens.css` mendeklarasikan token `--ci-*`; `src/app/globals.css`
  menjembatani mereka ke nama OmniRoute lawas (`--color-*`, `--radius-*`, `--font-sans`/`--font-mono`,
  `--table-*`, `--orch-status-*`, `--color-fd-*`), sehingga pembacaan `var(--color-*)` yang ada dan utility
  Tailwind tetap berfungsi. Kode baru menggunakan utility Tailwind (`bg-surface`, `text-text-muted`,
  `border-border`, `text-success`, `bg-success-bg`, `bg-chart-1`…) atau kelas kit — tidak pernah nilai hex
  (`tests/unit/design-kit-bridge.test.ts` menegakkan bridge tersebut). `text-primary` meresolusi ke
  `--color-primary-ink` melalui `--text-color-primary` (lime-800 di mode light, aksen lime di mode dark), sehingga
  teks primary tetap terbaca sementara `bg-primary`/`border-primary` mempertahankan surface lime. Seri chart menggunakan
  `--color-chart-1` … `--color-chart-5`.
- **Themes.** `<html className="ci-theme">` (`src/app/layout.tsx`) mengikutsertakan dokumen ke dalam tema kit.
  Preferensinya adalah `light`, `dark` atau `system` (`THEME_CONFIG.defaultTheme = "system"` di
  `src/shared/constants/appConfig.ts`; `system` mengikuti `prefers-color-scheme`). `applyTheme()` di
  `src/store/themeStore.ts` (dicerminkan oleh skrip bootstrap inline di `src/app/layout.tsx`, yang berjalan
  sebelum hydration) mengatur `data-theme="dark"|"light"` dan mengaktifkan/menonaktifkan kelas `.dark` pada `<html>` secara bersamaan.
  Set token dark kit dikunci pada `data-theme="dark"` (`packages/ui-kit/src/ci-tokens.css`);
  override dark milik OmniRoute sendiri (blok `.dark` di `globals.css`) dan utility Tailwind lawas `dark:`
  dikunci pada kelas `.dark`. Tidak ada preset warna aksen: aksen selalu berasal dari
  kit, dan preset yang tersimpan dari build lama dibuang saat store dimuat.
- **Komponen (adapter).** `src/shared/components/index.tsx` mempertahankan API komponen OmniRoute (nama
  yang sama, default export, dan props), dan primitif di belakangnya adalah adapter di atas kit: form
  (`Button`, `Input`, `Textarea`, `Checkbox`, `Select`, `Toggle`, `Badge`, `Card`), overlay dan feedback
  (`Modal`/`ConfirmModal`, `Tooltip`/`InfoTooltip`, `NotificationToast`, `EmptyState`, `Loading`),
  struktur (`Collapsible`, `CollapsibleSection`, `SegmentedControl`, `Breadcrumbs`, `Avatar`) dan tabel
  (`DataTable`, `FilterBar`, `ColumnToggle`, `FilterPills`, `PresetSlider`). Sebuah adapter mengimpor
  komponen kit melalui subpath dan memetakan props lawas ke komponen tersebut — misalnya `Button variant="primary"` adalah
  tombol `default` kit (`--ci-button-primary-*`: surface terbalik di mode light, aksen dengan ink
  `--ci-color-accent-foreground`-nya di mode dark), `danger` adalah `destructive`, dan `warning` adalah `outline` ditambah
  ekstensi `.ci-button--warning`. Aturan `.ci-button--warning` dan `.ci-badge[data-tone]` di
  akhir `globals.css` (`@layer components`) adalah ekstensi OmniRoute di atas kelas kit.
  `tests/unit/ui/adapters/*.test.tsx` menyematkan setiap adapter.
- **Shell.** `src/app/(dashboard)/layout.tsx` me-render `DashboardLayout`, yang me-render
  `src/shared/components/layouts/DashboardShell.tsx`: `SidebarProvider` / `Sidebar` /
  `SidebarInset` kit (`packages/ui-kit/src/sidebar.tsx`), dengan logika navigasi OmniRoute di
  `src/shared/components/Sidebar.tsx`. Tautan "skip to content" ke `#main-content` adalah elemen
  pertama yang dapat difokuskan. `src/shared/components/Header.tsx` memegang `SidebarTrigger` kit (satu-satunya
  toggle sidebar milik shell), `ProductSwitcher` Keak, dan pembuka command palette; ia menampilkan judul rute hanya selama
  tidak ada `PageHeader` kit (`.ci-page-header`) yang ter-mount di dalam `#main-content`, sehingga halaman dengan
  `PageHeader`-nya sendiri memiliki satu `h1`. `src/shared/components/CommandPalette.tsx` adalah `Dialog` kit.
- **Ikon.** `<Icon name="material_name">` (`src/shared/components/Icon.tsx`) meresolusi nama (kosakata
  Material Symbols yang digunakan layar) melalui `ICON_MAP` (`src/shared/constants/iconMap.ts`) ke
  glyph Lucide. Font dan paket Material Symbols sudah tidak ada: nama yang tidak ada di map me-render
  glyph placeholder netral (`data-icon-missing="true"`) dan mencatat peringatan konsol di luar produksi.
  `npm run gen:icon-map` mencetak nama-nama yang digunakan tetapi tidak ada di map
  (`tests/unit/icon-map-coverage.test.ts` gagal pada nama apa pun tanpa ikon Lucide;
  `tests/unit/icon-map-object-values.test.ts` mencakup nama yang disimpan dalam objek lookup);
  `scripts/dev/codemod-material-icons.mjs <dir|file>... [--write]` menulis ulang span literal
  `<span className="material-symbols-outlined">` menjadi `<Icon>`.
- **Brand.** `src/shared/components/OmniRouteLogo.tsx` membungkus kit: default export `OmniRouteLogo`
  me-render `ProductIcon product="omniroute" variant="glyph"` (SVG inline, aman terhadap `basePath`) dan
  `OmniRouteLockup` me-render `ProductLockup product="omniroute"` (nama aksesibel "Keak OmniRoute") atau, untuk
  operator white-label, `name`/`logoSrc` mereka sendiri. Tujuan product-switcher berada di
  `src/shared/constants/keakProducts.ts` (`KEAK_PRODUCT_LINKS`, `KEAK_ACTIVE_PRODUCT`). Layar-layar
  standalone — `src/app/login/page.tsx`, `src/app/status/page.tsx`, `src/app/maintenance/page.tsx`,
  `src/app/offline/page.tsx`, `src/app/not-found.tsx` dan `src/shared/components/ErrorPageScaffold.tsx`
  — menampilkan lockup; `tests/unit/brand-pages-static.test.ts` menjaganya.

## 2. Aturan

1. Token, jangan pernah literal. Pengecualian sengaja dipertahankan: terminal konsol yang selalu gelap
   dan `STATUS_HEX` (`src/shared/constants/statusColors.ts`), cerminan hex yang sudah di-resolve dari
   palet status kit untuk pemanggil yang membutuhkan hex literal. Palet kategorikal tidak lagi menjadi
   pengecualian: palet tersebut berjalan di atas lima token chart kit (`--color-chart-1..5`) melalui
   `src/shared/utils/categoricalPalette.ts` dan, untuk strategi routing,
   `src/app/(dashboard)/dashboard/combos/strategyPalette.ts`; edge ReactFlow dan kanvas orkestrasi
   membaca variabel `--orch-status-*` yang peka tema (`src/shared/components/flow/edgeStyles.ts`).
2. Jangan pernah menambal `packages/ui-kit/src` secara manual: sinkronkan dengan
   `scripts/dev/sync-ui-kit.sh <commit>`; gerbang pre-commit `npm run check:ui-kit-snapshot`
   (`.husky/pre-commit`) gagal pada byte apa pun yang berbeda dari commit upstream yang di-pin
   (pemeriksaan ini dilewati dengan peringatan ketika clone upstream, `UI_KIT_CLONE` atau
   `_references/cheaper-inference-ui-kit`, tidak ada). Ketika kit kekurangan sesuatu, akali di adapter
   atau di layar dan ajukan permintaan ke upstream.
3. Default teks kit adalah Bahasa Inggris (`label = "Loading"`, `loadingLabel = "Loading table"`…) —
   berikan string terjemahan dari `useTranslations(...)` setiap kali komponen kit merender teks.
4. Utilitas Tailwind mengalahkan kelas komponen kit (kit mendeklarasikan
   `@layer theme, base, components, utilities` dan aturannya berada di `components`) — gunakan utilitas
   untuk spasi dan tata letak, bukan untuk mewarnai ulang komponen kit.
5. Heading: `.ci-heading` (Inter, tanpa tracking) untuk judul halaman dan bagian;
   `.ci-dashboard-display` (Instrument Serif) hanya untuk teks display yang besar dan jarang seperti
   kode status halaman error.
6. `tests/unit/dashboard-kit-sweep.test.ts` menjaga adopsi kit: tidak boleh ada span ligatur Material
   di bawah `src/app` atau `src/shared/components`; di pohon dashboard (`src/app/(dashboard)` dan
   `src/shared/components`) tidak boleh ada `<select>`, `<textarea>` atau `<table>` mentah maupun
   `role="dialog"` buatan manual di luar pengecualian yang tercantum (cabang native adapter `Select`,
   `RequestLoggerDetail`); setiap `<button>` atau `<input>` mentah di sana memerlukan komentar yang
   berisi `kit-exception:` (beserta alasannya) yang berakhir paling banyak 3 baris di atasnya; hue
   palet dan varian `dark:` hanya di file yang dicantumkan tes tersebut.
7. Verifikasi kedua tema dan viewport 390 px sebelum PR (screenshot); `tests/e2e/a11y.spec.ts`
   menjalankan axe.

## 3. Menambahkan layar

1. Mulai halaman dengan `PageHeader` kit (`@omniroute/ui-kit/page-header`, `compact` di dalam
   dashboard) — judul, deskripsi, dan `actions`. Header shell kemudian menghilangkan judulnya sendiri.
2. Bangun kontrol dari `@/shared/components` (para adapter) dan gunakan komponen kit lewat subpath jika
   belum ada adapter (`Table`/`TableScrollArea`/`DataTableShell`, `Field`, `Alert`, `Tabs`,
   `RadioGroup`, `Slider`…).
3. Ikon: `<Icon name="…" />`. Nama baru dimasukkan ke `ICON_MAP` dengan komponen Lucide yang cocok
   secara semantik; `npm run gen:icon-map` mencantumkan nama yang masih belum ada.
4. Warna: utilitas semantik (`text-success`, `bg-warning-bg`, `border-border`…) dan
   `var(--color-chart-N)` untuk seri chart; tanpa nilai hex dan tanpa varian `dark:` yang sekadar
   mengulang warna.
5. Teks: setiap string, termasuk label yang Anda berikan ke komponen kit, berasal dari
   `useTranslations`. Kunci baru masuk ke `src/i18n/messages/en.json`, `pt-BR.json` dan `vi.json` (tes
   paritas bahasa Vietnam mengunci setiap kunci bahasa Inggris); locale lainnya diisi oleh sinkronisasi
   i18n.
6. Jalankan semua penjaga sebelum PR: `tests/unit/dashboard-kit-sweep.test.ts`,
   `tests/unit/icon-map-coverage.test.ts`, `tests/unit/icon-map-object-values.test.ts`,
   `npm run check:dashboard-typecheck` (satu-satunya pemeriksaan yang mendeteksi import ganda di
   `iconMap.ts`), `npm run check:ui-icu`, dan tes milik layar itu sendiri.

## 4. Menambahkan atau mengubah adapter

1. Pertahankan API publik `src/shared/components/index.tsx`: nama ekspor yang sama, ekspor default, dan
   props yang diterima. Petakan props lawas ke kit di dalam adapter (lihat `Button.tsx`: `VARIANT_TO_KIT`,
   `SIZE_TO_KIT`).
2. Impor kit melalui subpath (`@omniroute/ui-kit/<component>`).
3. Workaround untuk celah kit berada di adapter (atau di `globals.css` `@layer components` ketika
   perbaikannya berupa style), tidak pernah di `packages/ui-kit/src`.
4. Tambahkan atau perbarui `tests/unit/ui/adapters/<name>.test.tsx`. Untuk adapter dengan banyak pemanggil,
   bandingkan markup yang dirender sebelum dan sesudah perubahan — perubahan padding atau wrapper menyebar
   ke setiap layar.

## 5. Memperbarui kit

`scripts/dev/sync-ui-kit.sh <commit> [clone]` menyalin `src/` upstream pada commit tersebut ke
`packages/ui-kit/src` dan menerapkan satu-satunya transformasi yang diizinkan (menghapus akhiran `.js` dari
impor relatif). Kemudian: tinjau `git diff packages/ui-kit`, lakukan pemeriksaan visual pada halaman
penyedia, pengaturan, kombo, penggunaan, dan endpoint di kedua tema, jalankan
`npm run check:ui-kit-snapshot` dan `npm run test:vitest:ui`, lalu buka PR dengan changelog upstream.

## 6. Diagram README

Dua belas diagram yang disematkan `README.md` di root (`docs/diagrams/*.svg`) adalah kit yang diterapkan
pada gambar statis, dan diagram itu dihasilkan, bukan digambar dengan tangan: 13 file generator di
`scripts/docs/gen-readme-*.mjs` (dua belas diagram ditambah driver `gen-readme-diagrams.mjs`) dan 12 uji
staleness di `tests/unit/docs/readme-*-svg.test.ts`, satu per diagram, masing-masing membandingkan file
yang di-commit byte demi byte dengan output generatornya (job `test-unit`).

- **Token.** `scripts/docs/readme-diagram-theme.mjs` menyalin palet dari `packages/ui-kit/src/ci-tokens.css`
  (ditambatkan pada file tersebut oleh `tests/unit/docs/readme-diagram-theme.test.ts`) dan mendefinisikan
  peran teks pada typeface kit — Instrument Serif untuk display, Inter untuk teks UI, IBM Plex Mono untuk
  angka dan kode, paket `@fontsource` yang sama dengan yang dimuat `src/app/globals.css` untuk dashboard.
  Nilai terang berada di `:root`, nilai gelap di balik `prefers-color-scheme: dark`, di dalam file, sehingga
  setiap gambar mengikuti skema warna penampil di GitHub.
- **Font.** `scripts/docs/readme-fonts.mjs` membuat subset file woff2 tersebut menjadi hanya glif yang
  digambar setiap diagram dan menyematkannya sebagai URI `data:` `@font-face` — satu-satunya cara tipografi
  kit menjangkau gambar README, karena GitHub Markdown tidak membawa CSS dan proxy camo memblokir setiap
  fetch eksternal. Subset tersebut hanya latin; glif simbol yang fallback ke stack sistem diizinkan satu per
  satu di `SYMBOL_FALLBACKS`, dan glif lain yang tidak tercakup akan melempar error.
- **Regenerasi.** `npm run docs:readme-diagrams` menulis ulang kedua belasnya dalam urutan README dan
  mencetak satu baris per file beserta ukurannya. Satu generator juga dapat dijalankan sendiri
  (`node scripts/docs/gen-readme-<name>.mjs`; `free-tier-budget` memerlukan `node --import tsx/esm` karena
  angkanya berasal dari loader katalog live di `open-sse/config/freeModelCatalog.ts`; konsekuensi CI dari
  perubahan katalog ada di `docs/architecture/QUALITY_GATES.md` → `docs-sync-strict`). Commit generator dan
  SVG secara bersamaan.
- **Bukti.** `scripts/docs/readme-svg-shots.mjs <file.svg> <outdir>` merender file sebagaimana GitHub
  menyajikannya (tag `<img>`, `Content-Security-Policy` camo, `image/svg+xml`), menangkap satu frame terang
  dan satu frame gelap, lalu melaporkan permintaan font eksternal yang dilakukan halaman (harus 0).
- **Anggaran.** Di bawah 200 KB per file (setiap uji staleness memastikannya); 500 KB adalah batas mutlak
  untuk gambar README mana pun (aturan validator studio SVG).
- **Teks tidak berubah, angka dari gate.** Rebrand mengubah tipografi dan palet, bukan kata-kata: setiap
  generator membawa teks diagramnya dalam konstanta `*_COPY` (atau membangunnya dari katalog live) yang
  sekaligus menjadi teks yang digambar dan input subset font. Angka kanonik tetap berada di node `<text>`,
  dibaca oleh `check:docs-counts` (`scripts/check/check-docs-counts-sync.mjs`); uji staleness diagram yang
  dibaca gate tersebut juga menjalankan validatornya pada file yang dihasilkan, sehingga angka yang
  menyimpang dari kode akan menggagalkan pengujian — perbaiki sumber yang dibaca gate, jangan pernah angka
  di dalam generator.
