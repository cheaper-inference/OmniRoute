`copilot-m365-web` (`m365copilot` ಎಂಬ ಪರ್ಯಾಯ ಹೆಸರು) ದೃಢೀಕೃತ Microsoft 365 Copilot BizChat ಬ್ರೌಸರ್ ಸೆಷನ್ ಮೂಲಕ `m365.cloud.microsoft/chat` ಗೆ OpenAI-ಸ್ವರೂಪದ ಚಾಟ್ ವಿನಂತಿಗಳನ್ನು ಕಳುಹಿಸುತ್ತದೆ. ಇದು ಅನಧಿಕೃತ ಏಕೀಕರಣವಾಗಿದೆ.

> **Web Cookie ಪೂರೈಕೆದಾರರು ನಿಮಗೆ ಹೊಸದೇ?**
>
> ಈ ಪೂರೈಕೆದಾರ-ನಿರ್ದಿಷ್ಟ ಮಾರ್ಗದರ್ಶಿಯನ್ನು ಅನುಸರಿಸುವ ಮೊದಲು ಸಾಮಾನ್ಯ ಸೆಟಪ್ ಪ್ರಕ್ರಿಯೆ, ದೃಢೀಕರಣ ಮಾರ್ಗದರ್ಶನ, ಮಿತಿಗಳು ಮತ್ತು ಸಮಸ್ಯೆ ನಿವಾರಣೆಗಾಗಿ **`docs/getting-started/WEB-COOKIE-GUIDE.md`** ಓದಿ.
>
> **ಮುಖ್ಯ:** ಈ ಪೂರೈಕೆದಾರರ ರುಜುವಾತು **ಕುಕೀ ಅಲ್ಲ**. `m365.cloud.microsoft` ನಿಂದ
> ಕುಕೀಗಳನ್ನು ನಕಲಿಸಬೇಡಿ. ರುಜುವಾತು WebSocket URL ಕ್ವೆರಿ ಪ್ಯಾರಾಮೀಟರ್ ಮತ್ತು ಪಥದ
> ವಿಭಾಗವಾಗಿದ್ದು, ಎರಡನ್ನೂ DevTools Network ಟ್ಯಾಬ್ನಿಂದ ಓದಲಾಗುತ್ತದೆ.

## ಪೂರ್ವಾಪೇಕ್ಷೆಗಳು

- `m365.cloud.microsoft/chat` ನಲ್ಲಿ BizChat ಪ್ರವೇಶವಿರುವ Microsoft 365 ಖಾತೆ
- DevTools WebSocket ಪರಿಶೀಲನೆಗಾಗಿ Chromium-ಆಧಾರಿತ ಬ್ರೌಸರ್ (Chrome, Edge)
- M365 Copilot ಪರವಾನಗಿ (ಅನೇಕ Microsoft 365 Business/Enterprise ಯೋಜನೆಗಳಲ್ಲಿ ಸೇರಿಸಲಾಗಿದೆ)

## ರುಜುವಾತು ಸೆರೆಹಿಡಿಯುವಿಕೆ (WebSocket ವಿಧಾನ)

1. `https://m365.cloud.microsoft/chat` ನಲ್ಲಿ ಸೈನ್ ಇನ್ ಮಾಡಿ ಮತ್ತು ಸಂಭಾಷಣೆಯನ್ನು ಪ್ರಾರಂಭಿಸಿ.
2. **DevTools → Network** ತೆರೆಯಿರಿ.
3. **WS** (WebSocket) ಮೂಲಕ ಫಿಲ್ಟರ್ ಮಾಡಿ.
4. Chathub WebSocket ಸಂಪರ್ಕವನ್ನು ಕ್ಲಿಕ್ ಮಾಡಿ. `wss://substrate.office.com/m365Copilot/Chathub/` ನಿಂದ ಪ್ರಾರಂಭವಾಗುವ URL ಅನ್ನು ಹುಡುಕಿ.
5. ಅದರ **Request URL** ನಿಂದ ಇವುಗಳನ್ನು ನಕಲಿಸಿ:
   - `access_token` ಕ್ವೆರಿ ಪ್ಯಾರಾಮೀಟರ್ ಮೌಲ್ಯ (ಅಲ್ಪಾವಧಿಯ JWT).
   - `/Chathub/` ನಂತರದ Chathub ಪಥ ವಿಭಾಗ (ಉದಾ. `<oid>@<tenant>`).

ಪೂರ್ಣ URL ಈ ಸ್ವರೂಪದಲ್ಲಿರುತ್ತದೆ:

```
wss://substrate.office.com/m365Copilot/Chathub/<oid>@<tenant>?...&access_token=<jwt>
```

6. OmniRoute ನಲ್ಲಿ **Providers → Add Provider** ಗೆ ಹೋಗಿ, **Microsoft 365 Copilot
   (BizChat)** ಆಯ್ಕೆಮಾಡಿ ಮತ್ತು ರುಜುವಾತನ್ನು ಈ ಸ್ವರೂಪದಲ್ಲಿ ಅಂಟಿಸಿ:

```
access_token=<jwt>; chathubPath=<oid>@<tenant>
```

7. **Test Connection** ಮತ್ತು **Save** ಕ್ಲಿಕ್ ಮಾಡಿ.

## ರುಜುವಾತು ಸೆರೆಹಿಡಿಯುವಿಕೆ (HAR ಆಮದು)

WebSocket URL ನಿಂದ ಮೌಲ್ಯಗಳನ್ನು ಹಸ್ತಚಾಲಿತವಾಗಿ ನಕಲಿಸುವ ಬದಲು, ನೀವು DevTools HAR
ಫೈಲ್ ಅನ್ನು ರಫ್ತು ಮಾಡಬಹುದು:

1. **DevTools → Network** ತೆರೆಯಿರಿ.
2. BizChat ಸಂಭಾಷಣೆಯನ್ನು ಪ್ರಾರಂಭಿಸಿ ಅಥವಾ ಮುಂದುವರಿಸಿ (ಇದು WebSocket ಸಂಪರ್ಕವನ್ನು ಪ್ರಚೋದಿಸುತ್ತದೆ).
3. Network ಫಲಕದಲ್ಲಿ ರೈಟ್-ಕ್ಲಿಕ್ ಮಾಡಿ ಮತ್ತು **Save all as HAR with content** ಆಯ್ಕೆಮಾಡಿ.
4. OmniRoute ನಲ್ಲಿ, ಪೂರೈಕೆದಾರ ಸಂಪರ್ಕ ಸಂವಾದ ಪೆಟ್ಟಿಗೆಯಲ್ಲಿರುವ **Import .har file** ಬಟನ್ ಬಳಸಿ.

OmniRoute, Chathub WebSocket URL ಗಾಗಿ HAR ಅನ್ನು ಸ್ಕ್ಯಾನ್ ಮಾಡುತ್ತದೆ, `access_token` ಮತ್ತು `chathubPath` ಅನ್ನು ಹೊರತೆಗೆಯುತ್ತದೆ ಮತ್ತು ರುಜುವಾತು ಕ್ಷೇತ್ರಗಳನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಭರ್ತಿ ಮಾಡುತ್ತದೆ. HAR ಆಮದು JWT ಅವಧಿ ಮುಗಿಯುವ ಸಮಯವನ್ನು ಡಿಕೋಡ್ ಮಾಡಿ, ಉಳಿದಿರುವ ಟೋಕನ್ ಜೀವಿತಾವಧಿಯನ್ನು ತೋರಿಸುತ್ತದೆ.

> **ನೈಜ HAR ರಫ್ತು, ಪ್ರವೇಶ ಟೋಕನ್ ಅಥವಾ ರಿಫ್ರೆಶ್ ಟೋಕನ್ ಅನ್ನು ಎಂದಿಗೂ ಕಮಿಟ್ ಮಾಡಬೇಡಿ.** ಪರೀಕ್ಷೆ ಮತ್ತು
> ದಾಖಲಾತಿ ಮೌಲ್ಯಗಳು ಯಾವಾಗಲೂ ಪ್ಲೇಸ್ಹೋಲ್ಡರ್ಗಳಾಗಿರಬೇಕು.

## ಟೋಕನ್ನ ಜೀವಿತಾವಧಿ ಮತ್ತು ರಿಫ್ರೆಶ್

`access_token` ಅಲ್ಪಾವಧಿಯದ್ದಾಗಿದೆ (ಸಾಮಾನ್ಯವಾಗಿ **~75 ನಿಮಿಷಗಳು**). ಬಳಸಬಹುದಾದ ರಿಫ್ರೆಶ್
ಟೋಕನ್ ಇಲ್ಲದಿದ್ದರೆ, ಅವಧಿ ಮುಗಿದ ನಂತರ ನೀವು ಕ್ರೆಡೆನ್ಷಿಯಲ್ ಅನ್ನು ಮತ್ತೊಮ್ಮೆ ಪಡೆಯಬೇಕು.

### `refreshToken` ಮೂಲಕ ಸ್ವಯಂಚಾಲಿತ ರಿಫ್ರೆಶ್

Microsoft 365 ಪ್ರೊವೈಡರ್ನ **ಸಂಪರ್ಕ ಸೇರಿಸಿ** ಅಥವಾ **ಸಂಪರ್ಕ ಸಂಪಾದಿಸಿ** ಸಂವಾದದಲ್ಲಿ,
**ಸುಧಾರಿತ ಸೆಟ್ಟಿಂಗ್ಗಳು → ರಿಫ್ರೆಶ್ ಟೋಕನ್ (ಐಚ್ಛಿಕ)** ತೆರೆಯಿರಿ. `substrate.office.com/sydney`
ಸ್ಕೋಪ್ಗಾಗಿ Microsoft OAuth ರಿಫ್ರೆಶ್ ಟೋಕನ್ ಅನ್ನು ಅಂಟಿಸಿ ಮತ್ತು ಉಳಿಸಿ. ಇನ್ಪುಟ್ ಮರೆಮಾಡಲ್ಪಟ್ಟಿರುತ್ತದೆ
ಮತ್ತು ಸಂಗ್ರಹಿಸಲಾದ ಟೋಕನ್ನಿಂದ ಎಂದಿಗೂ ಮುಂಚಿತವಾಗಿ ತುಂಬಲಾಗುವುದಿಲ್ಲ. ಸಂಪಾದಿಸುವಾಗ, ಅಸ್ತಿತ್ವದಲ್ಲಿರುವ ಟೋಕನ್ ಅನ್ನು
ಉಳಿಸಿಕೊಳ್ಳಲು ಅದನ್ನು ಖಾಲಿ ಬಿಡಿ; ಬದಲಾಯಿಸಲು ಹೊಸ ಟೋಕನ್ ಅನ್ನು ಅಂಟಿಸಿ.

`substrate.office.com/sydney` ಸ್ಕೋಪ್ಗೆ ಸೀಮಿತಗೊಳಿಸಲಾದ Microsoft device-code ಅಥವಾ authorization-code
ಫ್ಲೋದಿಂದ ರಿಫ್ರೆಶ್ ಟೋಕನ್ ಪಡೆಯಿರಿ; ಡ್ಯಾಶ್ಬೋರ್ಡ್ ಅದನ್ನು ನಿಮ್ಮ ಪರವಾಗಿ ಪಡೆಯುವುದಿಲ್ಲ.
ರಿಫ್ರೆಶ್ ಟೋಕನ್ ಅನ್ನು ಕಾನ್ಫಿಗರ್ ಮಾಡಿದಾಗ, OmniRoute ವಿನಂತಿಗಳ ಮೊದಲು `access_token` ಅನ್ನು ಪರಿಶೀಲಿಸುತ್ತದೆ
ಮತ್ತು ರಿಫ್ರೆಶ್ ಅಗತ್ಯವಿದ್ದಾಗ ಮಾತ್ರ ಅದನ್ನು ರಿಫ್ರೆಶ್ ಮಾಡುತ್ತದೆ. ಯಶಸ್ವಿಯಾದ ರಿಫ್ರೆಶ್ ತಿರುಗಿಸಲಾದ ರಿಫ್ರೆಶ್
ಟೋಕನ್ ಅನ್ನು ಸಹ ಉಳಿಸುತ್ತದೆ. ಇದರಿಂದ ರಿಫ್ರೆಶ್ ಟೋಕನ್ ಮಾನ್ಯವಾಗಿರುವವರೆಗೆ ಅದನ್ನು ಕೈಯಾರೆ ಮತ್ತೊಮ್ಮೆ
ಪಡೆಯುವ ಅಗತ್ಯವಿರುವುದಿಲ್ಲ.

`refreshToken` ಅನ್ನು ಹೊಂದಿಸದಿದ್ದರೆ, ಪ್ರತಿ ಅವಧಿ ಮುಗಿದ ನಂತರ WebSocket ಕ್ರೆಡೆನ್ಷಿಯಲ್ ಅನ್ನು ಕೈಯಾರೆ
ಮತ್ತೊಮ್ಮೆ ಪಡೆಯಬೇಕು.

### ಟಿಯರ್ ಆಯ್ಕೆ

| ಟಿಯರ್        | ಅಲಿಯಾಸ್      | ಸರ್ಫೇಸ್                |
| ------------ | ------------ | ---------------------- |
| `individual` | _(ಡೀಫಾಲ್ಟ್)_ | Consumer M365 Copilot  |
| `edu`        | `included`   | Education M365 Copilot |
| `enterprise` | `work`       | M365 Copilot for Work  |

**ಸುಧಾರಿತ ಸೆಟ್ಟಿಂಗ್ಗಳು → Copilot ಟಿಯರ್** ನಲ್ಲಿ ಟಿಯರ್ ಹೊಂದಿಸಿ. ಟಿಯರ್
BizChat ರೌಟಿಂಗ್ ಮತ್ತು ಮಾದರಿ ಪ್ರವೇಶದ ಮೇಲೆ ಪರಿಣಾಮ ಬೀರುತ್ತದೆ.

## ಭದ್ರತಾ ಮಾದರಿ

- **ಅಧಿಕೃತವಲ್ಲದ ಏಕೀಕರಣ.** ಈ ಪೂರೈಕೆದಾರವು BizChat WebSocket
  ಪ್ರೋಟೋಕಾಲ್ ಅನ್ನು ರಿವರ್ಸ್-ಎಂಜಿನಿಯರ್ ಮಾಡುತ್ತದೆ. Microsoft ಎಂಡ್ಪಾಯಿಂಟ್ ಅನ್ನು ಬದಲಾಯಿಸಿದಾಗ ಇದು ಯಾವುದೇ ಮುನ್ಸೂಚನೆಯಿಲ್ಲದೆ ಕಾರ್ಯನಿರ್ವಹಿಸುವುದನ್ನು ನಿಲ್ಲಿಸಬಹುದು.
- `subscriptionRisk: true` ಫ್ಲ್ಯಾಗ್, ಈ ಏಕೀಕರಣವು ದಾಖಲಾತಿಯಿಲ್ಲದ
  ಎಂಡ್ಪಾಯಿಂಟ್ ಅನ್ನು ಅವಲಂಬಿಸಿದೆ ಎಂಬುದನ್ನು ಸೂಚಿಸುತ್ತದೆ. ಖಾತೆಯ ಮೇಲೆ ನಿರ್ಬಂಧಗಳು ವಿಧಿಸುವ ಸಾಧ್ಯತೆಯಿದೆ, ಆದರೆ ಅದನ್ನು ದೃಢೀಕರಿಸಲಾಗಿಲ್ಲ.
- ಪ್ರವೇಶ ಟೋಕನ್ ಅಲ್ಪಾವಧಿಯ JWT ಆಗಿದೆ. ಅದನ್ನು ಪಾಸ್ವರ್ಡ್ನಂತೆ ಪರಿಗಣಿಸಿ: ಅದನ್ನು commit ಮಾಡಬೇಡಿ,
  ಲಾಗ್ ಮಾಡಬೇಡಿ ಅಥವಾ ಹಂಚಿಕೊಳ್ಳಬೇಡಿ.
- ರಿಫ್ರೆಶ್ ಟೋಕನ್ BizChat ಮೇಲ್ಮೈಗೆ ದೀರ್ಘಾವಧಿಯ ಪ್ರವೇಶವನ್ನು ನೀಡುತ್ತದೆ. ಅದನ್ನು
  API ಕೀಲಿಯಷ್ಟೇ ಎಚ್ಚರಿಕೆಯಿಂದ ಸಂಗ್ರಹಿಸಿ.

## ಸಮಸ್ಯೆ ಪರಿಹಾರ

### ದೃಢೀಕರಣವು ತಕ್ಷಣವೇ ವಿಫಲವಾಗುತ್ತದೆ

- ನೀವು XHR/Fetch ವಿನಂತಿಯಿಂದಲ್ಲ, **WebSocket URL** ನಿಂದ ನಕಲಿಸಿರುವುದನ್ನು ಪರಿಶೀಲಿಸಿ. ರುಜುವಾತು `access_token` query parameterನಲ್ಲಿ, Chathub WebSocket ಸಂಪರ್ಕದಲ್ಲಿದೆ — `Authorization: Bearer` ಹೆಡರ್ನಲ್ಲಿ ಇಲ್ಲ.
- `chathubPath` ನಲ್ಲಿ URL ಪಥದಲ್ಲಿರುವ ಸಂಪೂರ್ಣ `<oid>@<tenant>` ವಿಭಾಗ ಸೇರಿದೆ ಎಂಬುದನ್ನು ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಿ.

### ಟೋಕನ್ ಸುಮಾರು 75 ನಿಮಿಷಗಳ ನಂತರ ಅವಧಿ ಮೀರಿಸುತ್ತದೆ

ಇದು ನಿರೀಕ್ಷಿತ ವರ್ತನೆಯಾಗಿದೆ. `refreshToken` ಇಲ್ಲದೆ, access tokenನ ಅವಧಿ ಕಡಿಮೆಯಾಗಿರುತ್ತದೆ. ಈ ಕೆಳಗಿನವುಗಳಲ್ಲಿ ಒಂದನ್ನು ಮಾಡಿ:

- DevTools ನಿಂದ ರುಜುವಾತನ್ನು ಮತ್ತೊಮ್ಮೆ ಸೆರೆಹಿಡಿಯಿರಿ, ಅಥವಾ
- ಸ್ವಯಂಚಾಲಿತ ರಿಫ್ರೆಶ್ಗಾಗಿ Add or Edit connection ಸಂವಾದದಲ್ಲಿನ **ಮುಂದುವರಿದ ಸೆಟ್ಟಿಂಗ್ಗಳು → ರಿಫ್ರೆಶ್ ಟೋಕನ್ (ಐಚ್ಛಿಕ)** ಅನ್ನು ಸಂರಚಿಸಿ.

### ಸಂಪರ್ಕ ಪರೀಕ್ಷೆ ಯಶಸ್ವಿಯಾಗುತ್ತದೆ, ಆದರೆ ಚಾಟ್ 401 ಅನ್ನು ಹಿಂತಿರುಗಿಸುತ್ತದೆ

ಮೌಲ್ಯೀಕರಣ ಮತ್ತು ಮೊದಲ ವಿನಂತಿಯ ನಡುವೆ ಟೋಕನ್ನ ಅವಧಿ ಮೀರಿರಬಹುದು. ಹೊಸ ರುಜುವಾತನ್ನು ಮತ್ತೊಮ್ಮೆ ಸೆರೆಹಿಡಿಯಿರಿ.

### ಪೂರೈಕೆದಾರರ ಪಟ್ಟಿಯಲ್ಲಿ Copilot ಕಾಣಿಸುವುದಿಲ್ಲ

**Dashboard → Providers** ನಲ್ಲಿ `copilot-m365-web` ಸಕ್ರಿಯಗೊಳಿಸಿರುವುದನ್ನು ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಿ. ಕೆಲವು ಹಂತಗಳಲ್ಲಿ ಪೂರೈಕೆದಾರವನ್ನು ಪೂರ್ವನಿಯೋಜಿತವಾಗಿ ಮರೆಮಾಡಿರಬಹುದು.
