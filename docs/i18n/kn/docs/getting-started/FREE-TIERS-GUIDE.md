OmniRoute ನೀವು ಕಾನ್ಫಿಗರ್ ಮಾಡುವ ಸಂಪರ್ಕಗಳನ್ನು ಸಂಯೋಜಿಸುತ್ತದೆ; ಇದು ಜಾಹೀರಾತು ಮಾಡಲಾದ ಒಟ್ಟು ಟೋಕನ್ ಬಜೆಟ್ ಅನ್ನು ನೀಡುವುದಿಲ್ಲ. ಉಚಿತ ಪ್ರವೇಶಕ್ಕೆ ಸೈನ್ ಅಪ್, API ಕೀ, ಅನುಮೋದನೆ ಅಥವಾ ಪಾವತಿ ವಿಧಾನದ ಅಗತ್ಯವಿರುತ್ತದೆ. ಪೂರೈಕೆದಾರರ ಮಿತಿಗಳು, ಗೌಪ್ಯತೆ ನೀತಿಗಳು ಮತ್ತು ನಿಯಮಗಳು ಇನ್ನೂ ಅನ್ವಯಿಸುತ್ತವೆ.

## ಉಚಿತ ಶ್ರೇಣಿಗಳು ಯಾವುವು?

ಅನೇಕ AI ಪೂರೈಕೆದಾರರು ಕೆಲವು ರೂಪಗಳನ್ನು ನೀಡುತ್ತಾರೆ** ಉಚಿತ ಪ್ರವೇಶ** . ಪೂರೈಕೆದಾರರನ್ನು ಅವಲಂಬಿಸಿ, ಯಾವುದೇ ದೃಢೀಕರಣದ ಅಂತ್ಯಬಿಂದು, ಮರುಕಳಿಸುವ ಕೋಟಾ, ದರ-ಸೀಮಿತ ಅನ್ಕ್ಯಾಪ್ಡ್ ಪ್ರವೇಶ, ಸೈನ್ಅಪ್ ಅನುದಾನ, ಹಸ್ತಚಾಲಿತ ಅನುಮೋದನೆ ಅಥವಾ ತಾತ್ಕಾಲಿಕ ಪ್ರಚಾರವನ್ನು ಅರ್ಥೈಸಬಹುದು. ಕೆಲವು ಆಯ್ಕೆಗಳಿಗೆ ಖಾತೆ, API ಕೀ, ಕ್ರೆಡಿಟ್ ಕಾರ್ಡ್, KYC, ಅಥವಾ ಪೂರೈಕೆದಾರ-ನಿರ್ದಿಷ್ಟ ನಿಯಮಗಳ ಸ್ವೀಕಾರದ ಅಗತ್ಯವಿರುತ್ತದೆ.

OmniRoute** ಒಟ್ಟುಗೂಡಿಸುತ್ತದೆ** ಸಂಪರ್ಕಗಳನ್ನು ಒಂದು ಅಂತಿಮ ಬಿಂದುವಾಗಿ ಕಾನ್ಫಿಗರ್ ಮಾಡಲಾಗಿದೆ. ಖಾತೆಯ ಅಗತ್ಯವಿರುವ ಪ್ರತಿ ಪೂರೈಕೆದಾರರಿಗೆ ನೀವು ಇನ್ನೂ ಪ್ರತ್ಯೇಕವಾಗಿ ಸೈನ್ ಅಪ್ ಮಾಡಿ. ಆ ಖಾತೆಗಳನ್ನು ಸಂಪರ್ಕಿಸಿ ಮತ್ತು ಅರ್ಹ ಗುರಿಗಳ ನಡುವೆ ಮಾರ್ಗ ಮಾಡಲು `model: "auto"` ಬಳಸಿ. ತಾಜಾ ಅನುಸ್ಥಾಪನೆಯು ಯಾವುದೇ ಅರ್ಹವಾದ ಕೀಲಿರಹಿತ ಗುರಿಯನ್ನು ಹೊಂದಿರುವುದಿಲ್ಲ; OmniRoute ಸ್ಥಾಪಿಸುವುದು ಯಶಸ್ವಿ ಚಾಟ್ ಪ್ರತಿಕ್ರಿಯೆಯನ್ನು ಖಾತರಿಪಡಿಸುವುದಿಲ್ಲ.

## ಪ್ರತಿನಿಧಿ ಉಚಿತ-ಪ್ರವೇಶ ಪೂರೈಕೆದಾರರು

## ಉಚಿತ ಶ್ರೇಣಿಗಳನ್ನು ಹೇಗೆ ಜೋಡಿಸುವುದು

OmniRoute ದ ಮಾಂತ್ರಿಕತೆ** ಉಚಿತ ಶ್ರೇಣಿಗಳನ್ನು ಪೇರಿಸುವುದು** . ಒಬ್ಬ ಪೂರೈಕೆದಾರರ ಮೇಲೆ ಅವಲಂಬಿತರಾಗುವ ಬದಲು, ನೀವು ಬಹು ಉಚಿತ ಪೂರೈಕೆದಾರರನ್ನು ಸಂಪರ್ಕಿಸುತ್ತೀರಿ ಮತ್ತು ಪ್ರತಿ ವಿನಂತಿಗೆ OmniRoute ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಅತ್ಯುತ್ತಮವಾದದನ್ನು ಆಯ್ಕೆ ಮಾಡಲು ಅವಕಾಶ ಮಾಡಿಕೊಡಿ.

### ಉದಾಹರಣೆ: ವಿಶಾಲವಾದ ಮುಕ್ತ-ಶ್ರೇಣಿಯ ವ್ಯಾಪ್ತಿ

ಯಾವುದೇ ಒಂದೇ ಕೋಟಾದ ಮೇಲಿನ ಅವಲಂಬನೆಯನ್ನು ಕಡಿಮೆ ಮಾಡಲು ಹಲವಾರು ಪೂರೈಕೆದಾರರನ್ನು ಸಂಪರ್ಕಿಸಿ:

1. **Gemini** — ಮರುಕಳಿಸುವ API-ಕೀ ಕೋಟಾ
2. **Groq** — ಮರುಕಳಿಸುವ API-ಕೀ ಕೋಟಾ
3. **ಪರಾಗಸ್ಪರ್ಶಗಳು** — ಕೀಲಿರಹಿತ, ದರ-ಸೀಮಿತ ಪ್ರವೇಶ
4. **LongCat** — ಒಂದು ಬಾರಿ ಸೈನ್ ಅಪ್ ಅನುದಾನ ( KYC ಅಗತ್ಯವಿದೆ)

ನಂತರ `model: "auto"` ಮತ್ತು OmniRoute ಅನ್ನು ಬಳಸಿ:

- ಮೊದಲು ಅತ್ಯುನ್ನತ ಶ್ರೇಣಿಯ ಅರ್ಹ ಸಂಪರ್ಕವನ್ನು ಪ್ರಯತ್ನಿಸಿ
- ಅದರ ಕೋಟಾ ಅಥವಾ ಆರೋಗ್ಯ ತಪಾಸಣೆ ವಿಫಲವಾದರೆ → ಮುಂದಿನ ಕಾನ್ಫಿಗರ್ ಮಾಡಲಾದ ಪೂರೈಕೆದಾರರನ್ನು ಪ್ರಯತ್ನಿಸಿ
- ಕೀಲಿ ರಹಿತ ಪೂರೈಕೆದಾರರು ಲಭ್ಯವಿಲ್ಲದಿದ್ದರೆ → ಉಳಿದ ಗುರಿಗಳ ಮೂಲಕ ಮುಂದುವರಿಯಿರಿ
- ಯಾವುದೇ ಅರ್ಹ ಸಂಪರ್ಕವು ಯಶಸ್ವಿಯಾಗದಿದ್ದರೆ → ದೋಷವನ್ನು ಹಿಂತಿರುಗಿಸಿ; ಸೈನ್ ಅಪ್ ಕ್ರೆಡಿಟ್ಗಳು ಮಾನ್ಯವಾದಾಗ ಮತ್ತು ಲಭ್ಯವಿರುವಾಗ ಮಾತ್ರ ಬಳಸಬಹುದಾಗಿದೆ

**ಫಲಿತಾಂಶ** : ಸ್ವಯಂಚಾಲಿತ ಫಾಲ್ಬ್ಯಾಕ್ — ಜೊತೆಗೆ ವಿಶಾಲವಾದ ಮುಕ್ತ-ಶ್ರೇಣಿಯ ಕವರೇಜ್ ಅನಿಯಮಿತ ಸಾಮರ್ಥ್ಯದ ಗ್ಯಾರಂಟಿ ಅಲ್ಲ.

## ಉಚಿತ ಪೂರೈಕೆದಾರರನ್ನು ಹೇಗೆ ಸಂಪರ್ಕಿಸುವುದು

### ಹಂತ 1: ಡ್ಯಾಶ್ಬೋರ್ಡ್ ತೆರೆಯಿರಿ

ನಿಮ್ಮ ಬ್ರೌಸರ್ನಲ್ಲಿ `http://localhost:20128` ಗೆ ಹೋಗಿ.

### ಹಂತ 2: ಪೂರೈಕೆದಾರರಿಗೆ ಹೋಗಿ

ಕ್ಲಿಕ್ ಮಾಡಿ** ಪೂರೈಕೆದಾರರು** ಸೈಡ್ಬಾರ್ನಲ್ಲಿ.

### ಹಂತ 3: ಒದಗಿಸುವವರನ್ನು ಸೇರಿಸಿ ಕ್ಲಿಕ್ ಮಾಡಿ

ಕ್ಲಿಕ್ ಮಾಡಿ**+ ಪೂರೈಕೆದಾರರನ್ನು ಸೇರಿಸಿ** ಬಟನ್.

### ಹಂತ 4: ಉಚಿತ ಪೂರೈಕೆದಾರರನ್ನು ಆಯ್ಕೆಮಾಡಿ

ಕ್ಯಾಟಲಾಗ್ ಅನ್ನು ಬ್ರೌಸ್ ಮಾಡಿ ಮತ್ತು ಪ್ರತಿ ಪೂರೈಕೆದಾರರ ಪ್ರಸ್ತುತ `hasFree`, ದೃಢೀಕರಣ, ಕೋಟಾ, ಗೌಪ್ಯತೆ ಮತ್ತು ToS ಮೆಟಾಡೇಟಾವನ್ನು ಪರೀಕ್ಷಿಸಿ. ಪೂರೈಕೆದಾರರ ಕಾರ್ಡ್ ಮತ್ತು [ಉಚಿತ ಶ್ರೇಣಿಗಳ ಉಲ್ಲೇಖವು](../reference/FREE_TIERS.md) ಮರುಕಳಿಸುವ ಪೂಲ್ಗಳು, uncapped/keyless ಪ್ರವೇಶ, ಸೈನ್ಅಪ್ ಕ್ರೆಡಿಟ್ಗಳು, ಸ್ಥಗಿತಗೊಂಡ ನಮೂದುಗಳು ಮತ್ತು ಹೆಚ್ಚಿನ ಅಪಾಯದ ಮೂಲಗಳನ್ನು ಪ್ರತ್ಯೇಕಿಸುತ್ತದೆ.

### ಹಂತ 5: ಸಂಪರ್ಕ ಕ್ಲಿಕ್ ಮಾಡಿ

`NOAUTH` ಪೂರೈಕೆದಾರರಿಗೆ, OmniRoute ಅಪ್ಸ್ಟ್ರೀಮ್ ರುಜುವಾತುಗಳನ್ನು ವಿನಂತಿಸುವುದಿಲ್ಲ. ಅಪ್ಸ್ಟ್ರೀಮ್ ಮೂರನೇ ವ್ಯಕ್ತಿಯ ಕ್ಲೈಂಟ್ಗಳನ್ನು ಸ್ವೀಕರಿಸುತ್ತದೆ ಅಥವಾ ಲಭ್ಯವಿರುವ ಸಾಮರ್ಥ್ಯವನ್ನು ಹೊಂದಿದೆ ಎಂದು ಇದು ಖಾತರಿಪಡಿಸುವುದಿಲ್ಲ. OAuth ಮತ್ತು API-ಕೀ ಪೂರೈಕೆದಾರರು ತಮ್ಮ ದಾಖಲಿತ ಖಾತೆಯ ಹರಿವಿನ ಮೂಲಕ ಸಂಪರ್ಕ ಹೊಂದಿರಬೇಕು. ನಿಮ್ಮ ಕ್ಲೈಂಟ್ ಇನ್ನೂ ರಚಿಸಲಾದ OmniRoute API ಕೀಲಿಯನ್ನು ಬಳಸುತ್ತದೆ** ಡ್ಯಾಶ್ಬೋರ್ಡ್ → API ಕೀಗಳು** (ಸೃಷ್ಟಿಯಲ್ಲಿ ಒಮ್ಮೆ ಮಾತ್ರ ತೋರಿಸಲಾಗಿದೆ) ರೂಟರ್ ದೃಢೀಕರಣವನ್ನು ಸಕ್ರಿಯಗೊಳಿಸಿದಾಗ.

### ಹಂತ 6: ಪುನರಾವರ್ತಿಸಿ

ನಿಮ್ಮ ಬಳಕೆಯ ಸಂದರ್ಭಕ್ಕೆ ಸೂಕ್ತವಾದ ನಿಯಮಗಳು ಮತ್ತು ಗೌಪ್ಯತೆ ಮಾದರಿಯ ಹಲವಾರು ಪೂರೈಕೆದಾರರನ್ನು ಸಂಪರ್ಕಿಸಿ.

## dsh "ನಮ್ಮ ಉಚಿತ ಮಾದರಿ" ನಿಂದ ಬರುತ್ತಿದೆ

dsh ಏಜೆಂಟ್ ಹೋಸ್ಟ್ಗಾಗಿ [dsh-our-free-model](https://github.com/Ebony-Vinyl/dsh-our-free-model) ಪ್ಲಗಿನ್ ಎರಡು ಅಪ್ಸ್ಟ್ರೀಮ್ಗಳನ್ನು ತಲುಪುತ್ತದೆ. OmniRoute ಈಗಾಗಲೇ ಪ್ರತಿಯೊಂದಕ್ಕೂ ಒದಗಿಸುವವರನ್ನು ಹೊಂದಿದೆ, ಆದರೆ ಅವುಗಳಲ್ಲಿ ಒಂದು ಮಾತ್ರ OmniRoute ನಲ್ಲಿ ಉಚಿತ ಮಾರ್ಗವಾಗಿದೆ:

| ಪ್ಲಗಿನ್ ಲೇನ್ | ಅಪ್ಸ್ಟ್ರೀಮ್                                | OmniRoute ಒದಗಿಸುವವರು          | OmniRoute ನಲ್ಲಿ ಉಚಿತ? | ಹೇಗೆ ಸಂಪರ್ಕಿಸುವುದು                                                          |
| ------------ | ------------------------------------------ | ----------------------------- | --------------------- | --------------------------------------------------------------------------- |
| ಕಿಲೋ ಚಾನಲ್   | ಕಿಲೋ AI ಗೇಟ್ವೇ (`api.kilo.ai/api/gateway`) | `kilo-gateway` (ಅಲಿಯಾಸ್ `kg`) | ಹೌದು                  | API ಕೀ ಐಚ್ಛಿಕ: ಗೇಟ್ವೇಯ ಉಚಿತ ಪೂಲ್ ಅನ್ನು ಬಳಸಲು ಅದನ್ನು ಖಾಲಿ ಬಿಡಿ               |
| ಉಚಿತ ಲೇನ್    | OpenCode ಝೆನ್ (`opencode.ai`)              | `opencode-zen`                | ಸಂ                    | [opencode.ai/zen](https://opencode.ai/zen) ನಿಂದ ನಿಮ್ಮ ಸ್ವಂತ OpenCode API ಕೀ |

**ಕಿಲೋ.** ಉಚಿತ ಪೂಲ್ ಅನ್ನು `kilo-gateway/<model>` ಅಥವಾ `kg/<model>` ಎಂದು ಕರೆ ಮಾಡಿ, ಉದಾಹರಣೆಗೆ `kg/kilo-auto/free` (ಕಿಲೋದ ಉಚಿತ ಸ್ವಯಂ-ರೂಟರ್) ಅಥವಾ ಗೇಟ್ವೇನ `:free` ಮಾದರಿಗಳಲ್ಲಿ ಒಂದಾಗಿದೆ. ಉಚಿತ ಸೆಟ್ ತಿರುಗುತ್ತದೆ; `kilo-gateway` OmniRoute ನ ಅಂತರ್ನಿರ್ಮಿತ ಪಟ್ಟಿಯಲ್ಲಿಲ್ಲದ ಮಾದರಿ ಐಡಿಗಳ ಮೂಲಕ ಹಾದುಹೋಗುತ್ತದೆ, ಆದ್ದರಿಂದ ಕ್ಯಾಟಲಾಗ್ ಒಳಗೊಂಡಿರುವ ಮೊದಲು ಗೇಟ್ವೇ ಪಟ್ಟಿ ಮಾಡುವ ಮಾದರಿಯನ್ನು ಕರೆಯಬಹುದು. ಕಿಲೋದ ಉಚಿತ ಮಾಡೆಲ್ ಕಾರ್ಡ್ಗಳು ಪ್ರಾಂಪ್ಟ್ಗಳನ್ನು ಅಪ್ಸ್ಟ್ರೀಮ್ ಪೂರೈಕೆದಾರರು ಲಾಗ್ ಮಾಡಬಹುದು ಮತ್ತು ಅದರ ಸೇವೆಗಳನ್ನು ಸುಧಾರಿಸಲು ಬಳಸಬಹುದೆಂದು ಹೇಳುತ್ತಾರೆ, ಆದ್ದರಿಂದ ಸೂಕ್ಷ್ಮ ಡೇಟಾವನ್ನು ಕಳುಹಿಸಬೇಡಿ.

**OpenCode.** ಪ್ಲಗಿನ್ನ ಉಚಿತ ಲೇನ್ OpenCode ನ ಕೀ-ಮುಕ್ತ ಕೊಡುಗೆಯಾಗಿದೆ. OmniRoute ಆ ಕೊಡುಗೆಯನ್ನು ಉಚಿತ ಪ್ರವೇಶವಾಗಿ ಒದಗಿಸುವುದಿಲ್ಲ:

- OmniRoute ನ ಕೀಲೆಸ್ OpenCode ಪೂರೈಕೆದಾರರನ್ನು OpenCode ನ ಆಪರೇಟರ್ನ ಕೋರಿಕೆಯ ಮೇರೆಗೆ ತೆಗೆದುಹಾಕಲಾಗಿದೆ ( [ತೆಗೆದುಹಾಕಿದ ಪೂರೈಕೆದಾರರನ್ನು](../reference/REMOVED_PROVIDERS.md) ನೋಡಿ).
- OpenCode ನ [ಅಂತಿಮ ದಸ್ತಾವೇಜನ್ನು](https://opencode.ai/v2/docs/console/models/#endpoints) ಅದರ ಉಚಿತ ಚಾಟ್ ಕೊಡುಗೆಗಳನ್ನು OpenCode ನ ಸ್ವಂತ ಕ್ಲೈಂಟ್ಗೆ ಜೋಡಿಸುತ್ತದೆ, ಆದ್ದರಿಂದ OmniRoute ಅವುಗಳನ್ನು ಉಚಿತವೆಂದು ಪರಿಗಣಿಸುವುದಿಲ್ಲ ಅಥವಾ ಬ್ಯಾಡ್ಜ್ ಮಾಡುವುದಿಲ್ಲ.

ಪ್ಲಗಿನ್ ತೋರಿಸುವ ಮಾದರಿ ಐಡಿಗಳಾದ `deepseek-v4.1-flash-free`, `mimo-v2.6-flash-free` ಮತ್ತು `nemotron-3.5-lightning-free`, `opencode-zen` ಕ್ಯಾಟಲಾಗ್ನಲ್ಲಿವೆ. ನಿಮ್ಮ OpenCode ಖಾತೆಯ ನಿಯಮಗಳ ಅಡಿಯಲ್ಲಿ ಅವುಗಳನ್ನು ಬಳಸಲು ನಿಮ್ಮ ಸ್ವಂತ OpenCode ಕೀಲಿಯೊಂದಿಗೆ `opencode-zen` ಸಂಪರ್ಕಿಸಿ.

**ಪ್ಲಗಿನ್ನ ಸ್ಥಳೀಯ ಪೋರ್ಟ್.** ಪ್ಲಗಿನ್ ತನ್ನ ಮಾದರಿಗಳನ್ನು ಸ್ಥಳೀಯ OpenAI-ಹೊಂದಾಣಿಕೆಯ ಪೋರ್ಟ್ನಲ್ಲಿ ಬಹಿರಂಗಪಡಿಸಬಹುದು (ಡೀಫಾಲ್ಟ್ `18899`). ಅಂತಹ ಯಾವುದೇ ಅಂತಿಮ ಬಿಂದುವನ್ನು [ಕಸ್ಟಮ್ OpenAI-ಹೊಂದಾಣಿಕೆಯ ಪೂರೈಕೆದಾರರಾಗಿ](../guides/USER_GUIDE.md#custom-openai-compatible-providers) ಸೇರಿಸಬಹುದು, ಆದರೆ OmniRoute ಪ್ಲಗಿನ್ ಅನ್ನು ಸ್ಥಾಪಿಸುವುದಿಲ್ಲ, ಪ್ರಾರಂಭಿಸುವುದಿಲ್ಲ ಅಥವಾ ನವೀಕರಿಸುವುದಿಲ್ಲ ಮತ್ತು ಪ್ರತಿ ವಿನಂತಿಯನ್ನು ಯಾವ ಅಪ್ಸ್ಟ್ರೀಮ್ ಪೂರೈಸುತ್ತದೆ ಎಂಬುದನ್ನು ಪ್ಲಗಿನ್ ನಿರ್ಧರಿಸುತ್ತದೆ. ಮೇಲಿನ OpenCode ನಿರ್ಬಂಧಗಳು OpenCode ನ ಕೊಡುಗೆಗೆ ಯಾವುದೇ ಕ್ಲೈಂಟ್ ವಿನಂತಿಯನ್ನು ಕಳುಹಿಸುತ್ತದೆ.

## ಕ್ಯಾಟಲಾಗ್ ಅನ್ನು ಸರಿಯಾಗಿ ಓದುವುದು

- `NOAUTH` ಎಂದರೆ OmniRoute ನಿಮ್ಮನ್ನು ಒದಗಿಸುವವರ ರುಜುವಾತುಗಳನ್ನು ಕೇಳುವುದಿಲ್ಲ; ಇದು ಅಪ್ಟೈಮ್, ಗೌಪ್ಯತೆ ಅಥವಾ ಅನಿಯಮಿತ ಸಾಮರ್ಥ್ಯವನ್ನು ಖಾತರಿಪಡಿಸುವುದಿಲ್ಲ.
- `hasFree` ಎಂಬುದು ಡಿಸ್ಕವರಿ ಮೆಟಾಡೇಟಾ. ಇದು ಮರುಕಳಿಸುವ ಕೋಟಾ, ಕೀಲೆಸ್ ಪ್ರವೇಶ, ಸೈನ್ ಅಪ್ ಕ್ರೆಡಿಟ್, ಅನುಮೋದನೆ ಪ್ರೋಗ್ರಾಂ ಅಥವಾ ಪ್ರಚಾರವನ್ನು ಪ್ರತಿನಿಧಿಸಬಹುದು.
- `recurring-uncapped` ಎಂದರೆ ಯಾವುದೇ ಪ್ರಕಟಿತ ಟೋಕನ್ ಸೀಲಿಂಗ್ ಲಭ್ಯವಿಲ್ಲ; ದರ ಮತ್ತು ಏಕಕಾಲಿಕ ಮಿತಿಗಳು ಇನ್ನೂ ಅನ್ವಯಿಸುತ್ತವೆ.
- ಸೈನ್ ಅಪ್ ಅನುದಾನವನ್ನು ಸೇವಿಸಿದ ನಂತರ `one-time-initial` ಮರುಕಳಿಸುವುದಿಲ್ಲ.
- `tos: avoid` ಪೂರೈಕೆದಾರರನ್ನು ಪೂರ್ವನಿಯೋಜಿತವಾಗಿ ಸ್ವಯಂಚಾಲಿತ ರೂಟಿಂಗ್ನಿಂದ ಹೊರಗಿಡಲಾಗಿದೆ (`excludeTosAvoid`). ಖಾತೆಯನ್ನು ಸಂಪರ್ಕಿಸುವುದು ಈ ಫಿಲ್ಟರ್ ಅನ್ನು ಬೈಪಾಸ್ ಮಾಡುವುದಿಲ್ಲ. ಯಾವುದೇ ಆಪರೇಟರ್ ಅತಿಕ್ರಮಣವು ಒದಗಿಸುವವರ ನಿಯಮಗಳು ಮತ್ತು ಖಾತೆಯ ಅಪಾಯದ ಪರಿಶೀಲನೆಯನ್ನು ಅನುಸರಿಸಬೇಕು.
- `discontinued` ಎಂದು ಗುರುತಿಸಲಾದ ನಮೂದುಗಳು ಐತಿಹಾಸಿಕ ಪುರಾವೆಯಾಗಿ ಉಳಿದಿವೆ ಮತ್ತು ಪ್ರಸ್ತುತ ಉಚಿತ ಎಂದು ಪ್ರಸ್ತುತಪಡಿಸಬಾರದು.

## OmniRoute ಉಚಿತ ಶ್ರೇಣಿಗಳನ್ನು ಹೇಗೆ ಉತ್ತಮಗೊಳಿಸುತ್ತದೆ

### 1. ಸ್ವಯಂಚಾಲಿತ ಫಾಲ್ಬ್ಯಾಕ್

ಒಬ್ಬ ಉಚಿತ ಪೂರೈಕೆದಾರರು ಕಾರ್ಯನಿರತವಾಗಿದ್ದರೆ ಅಥವಾ ಡೌನ್ ಆಗಿದ್ದರೆ, OmniRoute ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಮುಂದಿನದನ್ನು ಪ್ರಯತ್ನಿಸುತ್ತದೆ. ನೀವು ಏನನ್ನೂ ಮಾಡಬೇಕಾಗಿಲ್ಲ.

### 2. ಸ್ಮಾರ್ಟ್ ರೂಟಿಂಗ್

OmniRoute ಆಯ್ಕೆಮಾಡುತ್ತದೆ** ಅತ್ಯುತ್ತಮ ಉಚಿತ ಪೂರೈಕೆದಾರ** ಪ್ರತಿ ವಿನಂತಿಯನ್ನು ಆಧರಿಸಿ:

- Speed — ಇದೀಗ ಯಾವ ಪೂರೈಕೆದಾರರು ವೇಗವಾಗಿದ್ದಾರೆ?
- ಗುಣಮಟ್ಟ — ಈ ಕಾರ್ಯಕ್ಕೆ ಯಾವ ಪೂರೈಕೆದಾರರು ಉತ್ತಮ?
- ಸಾಮರ್ಥ್ಯ — ಯಾವ ಪೂರೈಕೆದಾರರು ಕೋಟಾ ಉಳಿದಿದ್ದಾರೆ?

### 3. ಟೋಕನ್ ಉಳಿತಾಯ

OmniRoute ನ ಕಂಪ್ರೆಷನ್ ಪೈಪ್ಲೈನ್ ಅರ್ಹ ಪ್ರಾಂಪ್ಟ್ ಮತ್ತು ಟೂಲ್-ಔಟ್ಪುಟ್ ಟೋಕನ್ಗಳನ್ನು ಕಡಿಮೆ ಮಾಡುತ್ತದೆ. ನಿಜವಾದ ಉಳಿತಾಯವು ವಿಷಯ, ಆಯ್ಕೆಮಾಡಿದ ಎಂಜಿನ್ಗಳು, ಪೂರೈಕೆದಾರರ ಲೆಕ್ಕಪತ್ರ ನಿರ್ವಹಣೆ ಮತ್ತು ನಿಷ್ಠೆ ಸೆಟ್ಟಿಂಗ್ಗಳ ಮೇಲೆ ಅವಲಂಬಿತವಾಗಿರುತ್ತದೆ; ಸಂಕೋಚನವು ಪ್ರತಿ ಪೂರೈಕೆದಾರರ ಕೋಟಾವನ್ನು ನಿಗದಿತ ಮೊತ್ತದಿಂದ ಗುಣಿಸುವುದಿಲ್ಲ.

### 4. ಬಹು-ಖಾತೆ ಬೆಂಬಲ

ಒದಗಿಸುವವರ ನಿಯಮಗಳು ಬಹು ಖಾತೆಗಳು ಅಥವಾ ರುಜುವಾತುಗಳನ್ನು ಅನುಮತಿಸಿದರೆ, OmniRoute ಪ್ರತಿ ಸಂಪರ್ಕವನ್ನು ಪ್ರತ್ಯೇಕ ರೂಟಿಂಗ್ ಅಭ್ಯರ್ಥಿಯಾಗಿ ಪರಿಗಣಿಸಬಹುದು. ಒದಗಿಸುವವರ ಕೋಟಾ ಅಥವಾ ಪ್ರವೇಶ ನೀತಿಯಿಂದ ತಪ್ಪಿಸಿಕೊಳ್ಳಲು ಹೆಚ್ಚುವರಿ ಖಾತೆಗಳನ್ನು ರಚಿಸಬೇಡಿ.

## ಸಾಮಾನ್ಯ ಪ್ರಶ್ನೆಗಳು

### "ಇದು ನಿಜವಾಗಿಯೂ ಉಚಿತವೇ?"

ಕ್ಯಾಟಲಾಗ್ ಒದಗಿಸುವವರು ಪ್ರಕಟಿಸಿದ ನಿಯಮಗಳು ಮತ್ತು ಪ್ರಾಜೆಕ್ಟ್ ಸಂಶೋಧನೆಯನ್ನು ದಾಖಲಿಸುತ್ತದೆ, ಆದರೆ ಕೊಡುಗೆಗಳು ಬದಲಾಗಬಹುದು. ಬಳಕೆಗೆ ಮೊದಲು ಒದಗಿಸುವವರ ಪ್ರಸ್ತುತ ಬೆಲೆ, ಕೋಟಾ, ಗೌಪ್ಯತೆ ನೀತಿ ಮತ್ತು ಅರ್ಹತೆಯನ್ನು ಪರಿಶೀಲಿಸಿ.

### "ಮುಕ್ತ ಶ್ರೇಣಿ ಖಾಲಿಯಾಗುತ್ತದೆಯೇ?"

ಪ್ರತಿಯೊಬ್ಬ ಪೂರೈಕೆದಾರರು ರೇಟ್-ಮಿತಿಯನ್ನು ಮಾಡಬಹುದು, ಮಾದರಿಗಳನ್ನು ಬದಲಾಯಿಸಬಹುದು, ಪ್ರವೇಶವನ್ನು ಅಮಾನತುಗೊಳಿಸಬಹುದು ಅಥವಾ ಆಫ್ಲೈನ್ಗೆ ಹೋಗಬಹುದು. ಬಹು ಸಂಪರ್ಕಗಳು ಫಾಲ್ಬ್ಯಾಕ್ ವ್ಯಾಪ್ತಿಯನ್ನು ಸುಧಾರಿಸುತ್ತವೆ ಆದರೆ ಲಭ್ಯವಿರುವ ಉಚಿತ ಮಾರ್ಗವನ್ನು ಖಾತರಿಪಡಿಸುವುದಿಲ್ಲ.

### "ಉತ್ಪಾದನೆಗಾಗಿ ನಾನು ಉಚಿತ ಪೂರೈಕೆದಾರರನ್ನು ಬಳಸಬಹುದೇ?"

ಒದಗಿಸುವವರ SLA, ಡೇಟಾ ನಿರ್ವಹಣೆ, ಮಿತಿಗಳು ಮತ್ತು ನಿಯಮಗಳು ನಿಮ್ಮ ಉತ್ಪಾದನಾ ಅವಶ್ಯಕತೆಗಳನ್ನು ಪೂರೈಸಿದರೆ ಮಾತ್ರ. ನಿರ್ಣಾಯಕ ಕೆಲಸದ ಹೊರೆಗಳು ಮೇಲ್ವಿಚಾರಣೆಯನ್ನು ಹೊಂದಿರಬೇಕು, ಒಪ್ಪಂದಕ್ಕೆ ಸೂಕ್ತವಾದ ಫಾಲ್ಬ್ಯಾಕ್.

### "ಕ್ಯಾಚ್ ಏನು?"

ಟ್ರೇಡ್ಆಫ್ಗಳು ಕಟ್ಟುನಿಟ್ಟಾದ ಮಿತಿಗಳು, ಕಾಯುವಿಕೆ ಪಟ್ಟಿಗಳು, KYC, ಕ್ರೆಡಿಟ್-ಕಾರ್ಡ್ ಪರಿಶೀಲನೆ, ಪ್ರಾಂಪ್ಟ್ಗಳ ಮೇಲೆ ತರಬೇತಿ, ದುರ್ಬಲ ಗೌಪ್ಯತೆ, ಯಾವುದೇ SLA, ಮಾದರಿ ಮಂಥನ, ಭೌಗೋಳಿಕ ನಿರ್ಬಂಧಗಳು, ಪಾವತಿಸಿದ ಮಿತಿಮೀರಿದ ಅಥವಾ ಖಾತೆ-ನೀತಿ ಅಪಾಯವನ್ನು ಒಳಗೊಂಡಿರಬಹುದು. OmniRoute ಲಭ್ಯವಿರುವ ಮೆಟಾಡೇಟಾವನ್ನು ಮೇಲ್ಮೈ ಮಾಡುತ್ತದೆ; ಯಾವುದನ್ನು ಸಕ್ರಿಯಗೊಳಿಸಬೇಕು ಎಂಬುದನ್ನು ನೀವು ಆರಿಸಿಕೊಳ್ಳಿ.

### "ನಾನು ಹೆಚ್ಚು ಉಚಿತ ಕೋಟಾವನ್ನು ಹೇಗೆ ಪಡೆಯುವುದು?"

1. ಹೆಚ್ಚು ಉಚಿತ ಪೂರೈಕೆದಾರರನ್ನು ಸಂಪರ್ಕಿಸಿ
2. ಸೂಕ್ತವಾದ ಕಂಪ್ರೆಷನ್ ಇಂಜಿನ್ಗಳನ್ನು ಸಕ್ರಿಯಗೊಳಿಸಿ ಮತ್ತು ನಿಮ್ಮ ಕೆಲಸದ ಹೊರೆಗಾಗಿ ಉಳಿತಾಯವನ್ನು ಅಳೆಯಿರಿ
3. free/cheap ಪೂರೈಕೆದಾರರಿಗೆ ಆದ್ಯತೆ ನೀಡಲು `auto/cheap` ಬಳಸಿ
4. ಒದಗಿಸುವವರ ನಿಯಮಗಳನ್ನು ಉಲ್ಲಂಘಿಸದೆ ಹೆಚ್ಚುವರಿ ಅನುಮತಿಸಲಾದ ಪೂರೈಕೆದಾರರು ಅಥವಾ ರುಜುವಾತುಗಳನ್ನು ಸೇರಿಸಿ

### "ಉಚಿತ ಪೂರೈಕೆದಾರರು ಕೆಟ್ಟ ಗುಣಮಟ್ಟವನ್ನು ಹೊಂದಿದ್ದಾರೆಯೇ?"

ಅನಿವಾರ್ಯವಲ್ಲ. ಕೆಲವು ಪೂರೈಕೆದಾರರು ಪಾವತಿಸಿದ ಮಾರ್ಗಗಳ ಮೂಲಕ ಲಭ್ಯವಿರುವ ಅದೇ ಮಾದರಿ ಕುಟುಂಬಗಳನ್ನು ಬಹಿರಂಗಪಡಿಸುತ್ತಾರೆ, ಆದರೆ ಮಿತಿಗಳು, ಸುಪ್ತತೆ, ಗೌಪ್ಯತೆ, ವಿಶ್ವಾಸಾರ್ಹತೆ ಮತ್ತು ಮಾದರಿ ಆವೃತ್ತಿಗಳು ಭಿನ್ನವಾಗಿರಬಹುದು. ಉಚಿತ ಪೂರೈಕೆದಾರರ ಶ್ರೇಯಾಂಕಗಳ ಪುಟವನ್ನು ಗುಣಮಟ್ಟದ ಸಂಕೇತವಾಗಿ ಬಳಸಿ ಮತ್ತು ಒದಗಿಸಿದ ನಿಜವಾದ ಮಾದರಿಯನ್ನು ಪರಿಶೀಲಿಸಿ.
