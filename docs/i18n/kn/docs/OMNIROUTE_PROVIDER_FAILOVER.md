ಮರುಪ್ರಯತ್ನ ನಿರ್ಧಾರಗಳನ್ನು ತೆಗೆದುಕೊಳ್ಳುವ ಮೊದಲು ವೈಫಲ್ಯಗಳನ್ನು ವರ್ಗೀಕರಿಸಲಾಗಿದೆ.

ಅವಧಿ ಮೀರುವಿಕೆಗಳು, ನೆಟ್ವರ್ಕ್ ದೋಷಗಳು, ದರ ಮಿತಿಗಳು ಮತ್ತು ಪೂರೈಕೆದಾರರ 5xx ಪ್ರತಿಕ್ರಿಯೆಗಳಂತಹ ತಾತ್ಕಾಲಿಕ ವೈಫಲ್ಯಗಳು ವಿಫಲವಾಗಬಹುದು. ಖಾಲಿಯಾದ ಕೋಟಾ ಅಥವಾ ಕ್ರೆಡಿಟ್ (ಕೋಟಾ 429, ಅಥವಾ 402 ಪಾವತಿ ಅಗತ್ಯವಿದೆ) ಒಂದೇ ಪೂರೈಕೆದಾರರ ಮೇಲೆ ಎಂದಿಗೂ ಮರುಪ್ರಯತ್ನಿಸುವುದಿಲ್ಲ ಆದರೆ ಇನ್ನೊಬ್ಬರಿಗೆ ವಿಫಲಗೊಳ್ಳುತ್ತದೆ, ಅವರ ಕೋಟಾ ಪ್ರತ್ಯೇಕವಾಗಿದೆ. ದೃಢೀಕರಣ ದೋಷಗಳು, ಅನುಮತಿ ದೋಷಗಳು, ಅಮಾನ್ಯ ವಿನಂತಿಗಳು, ಲಭ್ಯವಿಲ್ಲದ ಮಾದರಿಗಳು ಮತ್ತು ಅಜ್ಞಾತ ವೈಫಲ್ಯಗಳನ್ನು ಕುರುಡಾಗಿ ಮರುಪ್ರಯತ್ನಿಸಲಾಗುವುದಿಲ್ಲ.

ಡೀಫಾಲ್ಟ್ ಕ್ರಾಸ್-ಪ್ರೊವೈಡರ್ ನೀತಿಯು ಮೂರು ಪೂರೈಕೆದಾರರ ಪ್ರಯತ್ನಗಳನ್ನು ಅನುಮತಿಸುತ್ತದೆ, ದರ ಮಿತಿಗಳು ಮತ್ತು ಸಮಯ ಮೀರುವಿಕೆಯನ್ನು ಮರುಪ್ರಯತ್ನಿಸುತ್ತದೆ, ಖಾಲಿಯಾದ ಕೋಟಾದಲ್ಲಿ ವಿಫಲಗೊಳ್ಳುತ್ತದೆ ಮತ್ತು ತಾತ್ಕಾಲಿಕ ಸರ್ಕ್ಯೂಟ್ ಸ್ಥಿತಿಯಿಂದ ಆಡಳಿತದ ನಿಷ್ಕ್ರಿಯತೆಯನ್ನು ಪ್ರತ್ಯೇಕಿಸುತ್ತದೆ.

## ಇದು ಎಲ್ಲಿ ಅನ್ವಯಿಸುತ್ತದೆ

- **ಸಂಯೋಜನೆಗಳು** ಕಾಂಬೊದ ಸ್ವಂತ ತಂತ್ರ ಮತ್ತು ಸೆಟ್ಟಿಂಗ್ಗಳ ಪ್ರಕಾರ ಅವರ ಗುರಿಗಳ ನಡುವೆ ವಿಫಲಗೊಳ್ಳುತ್ತದೆ.
- **ಒಂದು ಬೇರ್ ಮಾಡೆಲ್ ಐಡಿ** ( `provider/` ಪೂರ್ವಪ್ರತ್ಯಯವಿಲ್ಲ) ಹಲವಾರು ಸಕ್ರಿಯ ಪೂರೈಕೆದಾರರು ಸೇವೆ ಸಲ್ಲಿಸುತ್ತಾರೆ, ಆ ನಿಖರವಾದ ಹೆಸರಿನ ಯಾವುದೇ ಸಂಯೋಜನೆಯಿಲ್ಲದೆ, ಮೊದಲು ಒದಗಿಸುವವರ ತೀರ್ಮಾನದ ಆಯ್ಕೆಗಳಿಗೆ ಕಳುಹಿಸಲಾಗುತ್ತದೆ. ಆ ಪ್ರಯತ್ನವು ವಿಫಲವಾದರೆ ನೀತಿಯು ವಿಫಲವಾದ ರೀತಿಯಲ್ಲಿ, ಅದೇ ವಿನಂತಿಯನ್ನು ಐಡಿಯನ್ನು ಪೂರೈಸುವ ಮುಂದಿನ ಸಕ್ರಿಯ ಪೂರೈಕೆದಾರರಿಗೆ ಕಳುಹಿಸಲಾಗುತ್ತದೆ. ಪ್ರತಿಕ್ರಿಯೆಯು ಉತ್ತರಿಸುವ ಮೊದಲು ಪ್ರಯತ್ನಿಸಿದ ಪೂರೈಕೆದಾರರ ಸಂಖ್ಯೆಯೊಂದಿಗೆ `x-omniroute-fallback-attempts` ಹೊಂದಿರುತ್ತದೆ.
  - ಪ್ರತಿ ಪರ್ಯಾಯವನ್ನು ನಿಖರವಾಗಿ ನಿರ್ಣಯಿಸಿದಂತೆ ಅಧಿಕೃತಗೊಳಿಸಲಾಗುತ್ತದೆ. API ಕೀಯನ್ನು ನಿರ್ಬಂಧಿಸುತ್ತದೆ ಅಥವಾ ಒಪ್ಪಿಕೊಳ್ಳದ ಗುರಿಯು ಅಪ್ಸ್ಟ್ರೀಮ್ ಕರೆ ಇಲ್ಲದೆ ಸ್ಕಿಪ್ ಆಗುತ್ತದೆ ಮತ್ತು ಕ್ಲೈಂಟ್ ನಿಜವಾದ ಅಪ್ಸ್ಟ್ರೀಮ್ ದೋಷವನ್ನು ಪಡೆಯುತ್ತದೆ, ಅದು ಎಂದಿಗೂ ಹೆಸರಿಸದ ಗುರಿಗೆ ನೀತಿ ನಿರಾಕರಣೆ ಅಲ್ಲ.
  - ವಿಫಲವಾದ ಪ್ರತಿಕ್ರಿಯೆಯು ಮಾತ್ರ ಚಲಿಸುತ್ತದೆ: ಮೊದಲ ಸ್ಟ್ರೀಮ್ ಮಾಡಿದ ಬೈಟ್ ನಂತರ ಏನೂ ವಿಫಲವಾಗುವುದಿಲ್ಲ.
  - ವಿನಂತಿಸಿದ ಮಾದರಿಯ ಪ್ರತಿ ಪೂರೈಕೆದಾರರು ವಿಫಲವಾದ ನಂತರವೇ ತುರ್ತು ಫಾಲ್ಬ್ಯಾಕ್ ಮಾಡೆಲ್ ಸ್ವಾಪ್ ಅನ್ವಯಿಸುತ್ತದೆ.
  - ಸಂಪರ್ಕಕ್ಕೆ ಪಿನ್ ಮಾಡಲಾದ ವಿನಂತಿಯು (`x-omniroute-connection`) ಅದರ ಮೇಲೆ ಉಳಿಯುತ್ತದೆ.
  - ಪೂರ್ವಪ್ರತ್ಯಯದ ಐಡಿ (`provider/model`) ಅನ್ನು ಎಂದಿಗೂ ಮತ್ತೊಂದು ಪೂರೈಕೆದಾರರಿಗೆ ಮರುಮಾರ್ಗಗೊಳಿಸಲಾಗುವುದಿಲ್ಲ.

ಸರ್ಕ್ಯೂಟ್ ಸ್ಟೇಟ್ಸ್ `closed`, `open` ಮತ್ತು `half_open`. ಕೂಲ್ಡೌನ್ ಒಂದು ಬೌಂಡೆಡ್ ಪ್ರೋಬ್ ಅನ್ನು ನಿಗದಿಪಡಿಸುತ್ತದೆ; ಯಶಸ್ವಿ ಶೋಧಕವು ಸರ್ಕ್ಯೂಟ್ ಅನ್ನು ಮುಚ್ಚುತ್ತದೆ ಮತ್ತು ವಿಫಲವಾದ ಪ್ರೋಬ್ ಅದನ್ನು ಪುನಃ ತೆರೆಯುತ್ತದೆ.
