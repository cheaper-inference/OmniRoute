## ಇದು ಏನು

OmniRoute 377 ಪೂರೈಕೆದಾರರನ್ನು ನೋಂದಾಯಿಸುತ್ತದೆ, ಇದರಲ್ಲಿ 155 ಕ್ಯಾಟಲಾಗ್ ನಮೂದುಗಳನ್ನು ಗುರುತಿಸಲಾಗಿದೆ**free/no-auth** (no-auth, free-tier OAuth, ಅಥವಾ free-tier API ಕೀ - [ಉಚಿತ ಶ್ರೇಣಿಗಳ ಮಾರ್ಗದರ್ಶಿ](../getting-started/FREE-TIERS-GUIDE.md) ಮತ್ತು ಪೂರ್ಣ [ಉಚಿತ ಶ್ರೇಣಿಗಳ ಡೈರೆಕ್ಟರಿಯನ್ನು](../reference/FREE_TIERS.md) ನೋಡಿ). ಕ್ಯಾಚ್: ಉಚಿತ ಪೂರೈಕೆದಾರರು ಮಾದರಿ ಗುಣಮಟ್ಟದಲ್ಲಿ ಹುಚ್ಚುಚ್ಚಾಗಿ ಬದಲಾಗುತ್ತಾರೆ. ಗಡಿನಾಡು ಮಾದರಿಯನ್ನು ಒದಗಿಸುವ ಯಾವುದೇ ದೃಢೀಕರಣ ಪೂರೈಕೆದಾರರು ಸಣ್ಣ ಪರಂಪರೆಯ ಮಾದರಿಯನ್ನು ಪೂರೈಸುವುದಕ್ಕಿಂತ ಹೆಚ್ಚು ಉಪಯುಕ್ತವಾಗಿದೆ.

**ಉಚಿತ ಪೂರೈಕೆದಾರರ ಶ್ರೇಯಾಂಕಗಳು** ಉತ್ತರಗಳು "** ಯಾವ ಉಚಿತ ಪೂರೈಕೆದಾರರು ನನಗೆ ಉತ್ತಮ ಮಾದರಿಯನ್ನು ನೀಡುತ್ತಾರೆ?** " ಪ್ರತಿ ಉಚಿತ ಪೂರೈಕೆದಾರರ ಕ್ಯಾಟಲಾಗ್ಗೆ ಸೇರುವ ಮೂಲಕ** ಗುಂಪಿನ ಮೂಲದ ಗುಣಮಟ್ಟದ ಅಂಕಗಳು** ನಿಂದ** ಅರೆನಾ AI ಲೀಡರ್ಬೋರ್ಡ್** (ಮಾನವ ಆದ್ಯತೆಯ ELO, LMArena ಚಾಟ್ಬಾಟ್ ಅರೇನಾದ ಹಿಂದೆ ಅದೇ ಕಲ್ಪನೆ). ಪೂರೈಕೆದಾರರನ್ನು ನಂತರ ಅವರ ಸಾಮರ್ಥ್ಯದಿಂದ ಶ್ರೇಣೀಕರಿಸಲಾಗುತ್ತದೆ** ಅತ್ಯುತ್ತಮ ಉಚಿತ ಮಾದರಿ** .

ಶ್ರೇಯಾಂಕವನ್ನು ಮೂರು ನೈಜ ಮೂಲಗಳಿಂದ ಲೆಕ್ಕಹಾಕಲಾಗಿದೆ:

1. ಉಚಿತ ಒದಗಿಸುವವರ ಪಟ್ಟಿಗಳು — `NOAUTH_PROVIDERS`, ಜೊತೆಗೆ `OAUTH_PROVIDERS` / `APIKEY_PROVIDERS` ನಮೂದುಗಳನ್ನು ಫ್ಲ್ಯಾಗ್ ಮಾಡಲಾದ `hasFree` (`src/shared/constants/providers.ts`).
2. ಪೂರೈಕೆದಾರರ ನೋಂದಣಿಯಿಂದ (`open-sse/config/providerRegistry.ts`) ಪ್ರತಿ ಪೂರೈಕೆದಾರರ ಮಾದರಿ ಕ್ಯಾಟಲಾಗ್.
3. ಅರೆನಾ ELO ಸಿಂಕ್ ಎಂಜಿನ್ (`src/lib/arenaEloSync.ts`) ಮೂಲಕ `model_intelligence` DB ಕೋಷ್ಟಕದಲ್ಲಿ ಸಂಗ್ರಹಿಸಲಾದ ELO- ಪಡೆದ ಟಾಸ್ಕ್-ಫಿಟ್ ಸ್ಕೋರ್ಗಳು.

ಸೇರಲು ತರ್ಕವು `src/lib/freeProviderRankings.ts` ನಲ್ಲಿ ವಾಸಿಸುತ್ತದೆ.

## ಪ್ರವೇಶಿಸುವ ವಿಧಾನ

### ಡ್ಯಾಶ್ಬೋರ್ಡ್ ಪುಟ

ಡ್ಯಾಶ್ಬೋರ್ಡ್ ತೆರೆಯಿರಿ ಮತ್ತು **ವೆಚ್ಚಗಳು → ಉಚಿತ ಪೂರೈಕೆದಾರರ ಶ್ರೇಯಾಂಕಗಳು** ಎಂಬುದಕ್ಕೆ
ಹೋಗಿ, ಅಥವಾ ನೇರವಾಗಿ ಇಲ್ಲಿಗೆ ನ್ಯಾವಿಗೇಟ್ ಮಾಡಿ:

```
/dashboard/free-provider-rankings
```

ಈ ಪುಟವು (`src/app/(dashboard)/dashboard/free-provider-rankings/page.tsx`) ಇವುಗಳನ್ನು
ತೋರಿಸುತ್ತದೆ:

- ಅತ್ಯುತ್ತಮ ಶ್ರೇಯಾಂಕ ಪಡೆದ ಉಚಿತ ಪೂರೈಕೆದಾರರ **ಅಗ್ರ-3 ವೇದಿಕೆ** (🥇 🥈 🥉).
- **ಶ್ರೇಣಿ**, **ಪೂರೈಕೆದಾರರು**, **ಅಗ್ರ ಮಾದರಿ**, **ಸ್ಕೋರ್**, **ಸರಾಸರಿ ಸ್ಕೋರ್**,
  **ಮಾದರಿಗಳು**, **ಪ್ರಕಾರ** ಎಂಬ ಕಾಲಮ್ಗಳಿರುವ ಸಂಪೂರ್ಣ **ಶ್ರೇಯಾಂಕ ಕೋಷ್ಟಕ**.
- **ವರ್ಗದ ಫಿಲ್ಟರ್ ಬಟನ್ಗಳು**: _ಎಲ್ಲಾ ವರ್ಗಗಳು_, _ಡೀಫಾಲ್ಟ್_, _ಕೋಡಿಂಗ್_,
  _ಪರಿಶೀಲನೆ_, _ದಸ್ತಾವೇಜೀಕರಣ_, _ಡೀಬಗ್ಗಿಂಗ್_.

ಪ್ರತಿ ಪೂರೈಕೆದಾರರ **ಪ್ರಕಾರ** ಬ್ಯಾಡ್ಜ್, ಅದು ಯಾವ ರೀತಿಯಲ್ಲಿ ಉಚಿತವಾಗಿದೆ ಎಂಬುದನ್ನು ತಿಳಿಸುತ್ತದೆ:

| ಬ್ಯಾಡ್ಜ್ | ಅರ್ಥ                                                  |
| -------- | ----------------------------------------------------- |
| `NOAUTH` | ಯಾವಾಗಲೂ ಉಚಿತ, ರುಜುವಾತುಗಳ ಅಗತ್ಯವಿಲ್ಲ                   |
| `OAUTH`  | ಉಚಿತ ಹಂತವನ್ನು ಹೊಂದಿರುವ OAuth ಪೂರೈಕೆದಾರರು (`hasFree`)  |
| `APIKEY` | ಉಚಿತ ಹಂತವನ್ನು ಹೊಂದಿರುವ API-ಕೀ ಪೂರೈಕೆದಾರರು (`hasFree`) |

ಸ್ಕೋರ್ಗಳನ್ನು ಕಚ್ಚಾ ಸಂಖ್ಯೆಗಳ ಬದಲಿಗೆ, ಮನುಷ್ಯರು ಸುಲಭವಾಗಿ ಅರ್ಥಮಾಡಿಕೊಳ್ಳಬಹುದಾದ ಲೇಬಲ್ಗಳಾಗಿ
(ಉದಾ. _ಅತ್ಯುನ್ನತ_, _ಅತ್ಯುತ್ತಮ_, _ಬಹಳ ಉತ್ತಮ_, _ಉತ್ತಮ_, _ಸರಾಸರಿ_) ತೋರಿಸಲಾಗುತ್ತದೆ,
ಏಕೆಂದರೆ ಆಧಾರವಾಗಿರುವ ಮೌಲ್ಯವು ಶೇಕಡಾವಾರು ಅಲ್ಲ, ಬದಲಿಗೆ ಸಾಪೇಕ್ಷ ಶ್ರೇಯಾಂಕ ಗುಣಮಟ್ಟವಾಗಿದೆ.

### API ಎಂಡ್ಪಾಯಿಂಟ್

ಈ ಪುಟವು ಸಾರ್ವಜನಿಕ ರೀಡ್ ಎಂಡ್ಪಾಯಿಂಟ್
(`src/app/api/free-provider-rankings/route.ts`) ಅನ್ನು ಆಧರಿಸಿದೆ:

```
GET /api/free-provider-rankings
GET /api/free-provider-rankings?category=coding
GET /api/free-provider-rankings?category=coding&limit=20
```

ಕ್ವೆರಿ ಪ್ಯಾರಾಮೀಟರ್ಗಳು (Zod ಮೂಲಕ ಮೌಲ್ಯೀಕರಿಸಲಾಗಿದೆ):

| ಪ್ಯಾರಾಮೀಟರ್ | ಪ್ರಕಾರ | ಡೀಫಾಲ್ಟ್      | ಟಿಪ್ಪಣಿಗಳು                                                                                                            |
| ----------- | ------ | ------------- | --------------------------------------------------------------------------------------------------------------------- |
| `category`  | string | (ಯಾವುದೂ ಇಲ್ಲ) | `default`, `coding`, `review`, `documentation`, `debugging` ಇವುಗಳಲ್ಲಿ ಒಂದು. ಸಂಯೋಜಿತ ಶ್ರೇಯಾಂಕಕ್ಕಾಗಿ ಇದನ್ನು ಬಿಟ್ಟುಬಿಡಿ. |
| `limit`     | number | `50`          | `1–100` ವ್ಯಾಪ್ತಿಗೆ ಸೀಮಿತಗೊಳಿಸಲಾಗಿದೆ.                                                                                  |

ಪ್ರತಿಕ್ರಿಯೆಯ ಸ್ವರೂಪ:

```json
{
  "rankings": [
    {
      "id": "<provider-id>",
      "name": "<provider name>",
      "icon": "<icon>",
      "color": "<hex color>",
      "textIcon": "<short label>",
      "category": "noauth | oauth | apikey",
      "topModel": {
        "modelId": "<registry model id>",
        "modelName": "<model display name>",
        "score": 0.0,
        "eloRaw": 0,
        "confidence": "high | medium | low",
        "category": "<task category>"
      },
      "averageScore": 0.0,
      "modelCount": 0
    }
  ]
}
```

`eloRaw` ಮೂಲ Arena ELO ಮೌಲ್ಯವಾಗಿದೆ; `score` ಸಾಮಾನ್ಯೀಕರಿಸಿದ ಕಾರ್ಯ-ಹೊಂದಾಣಿಕೆ
ಮೌಲ್ಯವಾಗಿದೆ (ಕೆಳಗೆ ನೋಡಿ). ಸ್ಕೋರ್ ಮಾಡಲಾದ ಯಾವುದೇ ಮಾದರಿಗಳನ್ನು ಹೊಂದಿರದ ಪೂರೈಕೆದಾರರನ್ನು
ಪ್ರತಿಕ್ರಿಯೆಯಿಂದ ಕೈಬಿಡಲಾಗುತ್ತದೆ.

## ಸ್ಕೋರ್ಗಳು ಹೇಗೆ ಕೆಲಸ ಮಾಡುತ್ತವೆ

### ಮೂಲ: Arena AI ಲೀಡರ್ಬೋರ್ಡ್

Arena ELO ಸಿಂಕ್ ಎಂಜಿನ್ (`src/lib/arenaEloSync.ts`) Arena AI ಲೀಡರ್ಬೋರ್ಡ್ API
(`https://api.wulong.dev/arena-ai-leaderboards/v1/leaderboard`) ನಿಂದ ಎರಡು ಲೀಡರ್ಬೋರ್ಡ್ಗಳನ್ನು — `text`
ಮತ್ತು `code` — ಪಡೆಯುತ್ತದೆ. ಆ API ಯಾವುದೇ ಬಳಸಬಹುದಾದ ಬೋರ್ಡ್ ಅನ್ನು ಹಿಂತಿರುಗಿಸದಿದ್ದಾಗ, ಎಂಜಿನ್
Hugging Face datasets-server ನಲ್ಲಿರುವ ಅಧಿಕೃತ `lmarena-ai/leaderboard-dataset` ಗೆ
ಫಾಲ್ಬ್ಯಾಕ್ ಆಗುತ್ತದೆ (`src/lib/arenaEloHfSource.ts`, CC-BY-4.0; `overall` → `text`,
`coding` → `code`); `GET /api/intelligence/sync` `activeSource`, `lastError` ಮತ್ತು
`lastFailedAt` ಅನ್ನು ವರದಿ ಮಾಡುತ್ತದೆ. ಪ್ರತಿ ಲೀಡರ್ಬೋರ್ಡ್ ನಮೂದು
ಮಾಡೆಲ್ ಹೆಸರು, ವೆಂಡರ್, ELO `score`, ಕಾನ್ಫಿಡೆನ್ಸ್ ಇಂಟರ್ವಲ್ ಮತ್ತು ವೋಟ್ ಸಂಖ್ಯೆಯನ್ನು ಹೊಂದಿರುತ್ತದೆ.

ಲೀಡರ್ಬೋರ್ಡ್ ವರ್ಗಗಳು OmniRoute ಟಾಸ್ಕ್ ವರ್ಗಗಳಿಗೆ ಮ್ಯಾಪ್ ಆಗುತ್ತವೆ:

| Arena ಲೀಡರ್ಬೋರ್ಡ್ | OmniRoute ಟಾಸ್ಕ್ ವರ್ಗಗಳು                          |
| ----------------- | ------------------------------------------------- |
| `text`            | `default`, `review`, `documentation`, `debugging` |
| `code`            | `coding`                                          |

### ನಾರ್ಮಲೈಸೇಶನ್ (ಟಾಸ್ಕ್-ಫಿಟ್ ಸ್ಕೋರ್)

ಕಚ್ಚಾ ELO ಸ್ಕೋರ್ಗಳನ್ನು ಪ್ರತಿ ಲೀಡರ್ಬೋರ್ಡ್ಗೆ **`[0.4, 0.98]` ನಲ್ಲಿನ ಟಾಸ್ಕ್-ಫಿಟ್ ಮೌಲ್ಯ**ಕ್ಕೆ ನಾರ್ಮಲೈಸ್ ಮಾಡಲಾಗುತ್ತದೆ:

```
taskFit = 0.4 + 0.58 * ((elo - minElo) / (maxElo - minElo))
```

ಸ್ಕೋರ್ ಎಂದಿಗೂ `0` ಅಥವಾ `1` ಅನ್ನು ತಲುಪುವುದಿಲ್ಲ, ಬಳಕೆದಾರ ಓವರ್ರೈಡ್ಗಳಿಗೆ ಅವಕಾಶ ಉಳಿಸುತ್ತದೆ. ಇದು
API ಪ್ರತಿಕ್ರಿಯೆಯಲ್ಲಿ ನೀವು ನೋಡುವ `score` ಫೀಲ್ಡ್ ಮತ್ತು ಡ್ಯಾಶ್ಬೋರ್ಡ್ನಲ್ಲಿ ತೋರಿಸಲಾಗುವ ಲೇಬಲ್ ಆಗಿದೆ.

### ಕಾನ್ಫಿಡೆನ್ಸ್

ಪ್ರತಿ ನಮೂದು Arena ವೋಟ್ ಸಂಖ್ಯೆಯ ಆಧಾರದ ಮೇಲೆ ಕಾನ್ಫಿಡೆನ್ಸ್ ಹಂತವನ್ನು ಪಡೆಯುತ್ತದೆ:

| ಕಾನ್ಫಿಡೆನ್ಸ್ | ವೋಟ್ಗಳು |
| ------------ | ------- |
| `high`       | ≥ 5,000 |
| `medium`     | ≥ 1,000 |
| `low`        | < 1,000 |

### ಸಂಗ್ರಹಣೆ ಮತ್ತು ತಾಜಾತನ

ನಾರ್ಮಲೈಸ್ ಮಾಡಲಾದ ನಮೂದುಗಳನ್ನು `source = "arena_elo"` ನೊಂದಿಗೆ `model_intelligence` DB
ಟೇಬಲ್ಗೆ ಬರೆಯಲಾಗುತ್ತದೆ (`src/lib/db/modelIntelligence.ts`). ನಮೂದುಗಳು **7 ದಿನಗಳ ನಂತರ
ಅವಧಿ ಮೀರುತ್ತವೆ**, ಆದ್ದರಿಂದ ಸಿಂಕ್ ಮಾಡುವುದನ್ನು ನಿಲ್ಲಿಸಿದ ಪ್ರೊವೈಡರ್ ಹಳೆಯ ಡೇಟಾವನ್ನು
ನೀಡುವ ಬದಲು ಕ್ರಮೇಣ ಹೊರಬೀಳುತ್ತದೆ.

ಸಿಂಕ್ **ಡೀಫಾಲ್ಟ್ ಆಗಿ ಆನ್ ಆಗಿದೆ**:

- ಇದು ಸರ್ವರ್ ಸ್ಟಾರ್ಟಪ್ನಲ್ಲಿ ಒಮ್ಮೆ ರನ್ ಆಗುತ್ತದೆ ಮತ್ತು ನಂತರ ಆವರ್ತಕ ಟೈಮರ್ನ ಮೇಲೆ ರನ್ ಆಗುತ್ತದೆ
  (`src/lib/arenaEloSync.ts`, `src/instrumentation-node.ts` ನಿಂದ ವೈರ್ಡ್ ಮಾಡಲಾಗಿದೆ).
- ಇದು **ನಾನ್-ಬ್ಲಾಕಿಂಗ್ ಮತ್ತು ಎಂದಿಗೂ ಫೇಟಲ್ ಅಲ್ಲ** — ಅಪ್ಸ್ಟ್ರೀಮ್ ಫೆಚ್ ವಿಫಲವಾದರೂ, OmniRoute
  ರನ್ ಆಗುತ್ತಲೇ ಇರುತ್ತದೆ ಮತ್ತು ರ್ಯಾಂಕಿಂಗ್ಗಳು ಕೇವಲ ಕೊನೆಯ ಒಳ್ಳೆಯ ಡೇಟಾವನ್ನು ತೋರಿಸುತ್ತವೆ (ಅಥವಾ ಖಾಲಿ ಸ್ಥಿತಿಯನ್ನು).

ಎರಡು ಎನ್ವಿರಾನ್ಮೆಂಟ್ ವೇರಿಯಬಲ್ಗಳು ಇದನ್ನು ನಿಯಂತ್ರಿಸುತ್ತವೆ (
[`docs/reference/ENVIRONMENT.md`](../reference/ENVIRONMENT.md) ನಲ್ಲಿ ಡಾಕ್ಯುಮೆಂಟ್ ಮಾಡಲಾಗಿದೆ):

| ವೇರಿಯಬಲ್                  | ಡೀಫಾಲ್ಟ್      | ಉದ್ದೇಶ                                              |
| ------------------------- | ------------- | --------------------------------------------------- |
| `ARENA_ELO_SYNC_ENABLED`  | `true`        | ಔಟ್ಬೌಂಡ್ ಸಿಂಕ್ನಿಂದ ಹೊರಗುಳಿಯಲು `false` ಗೆ ಸೆಟ್ ಮಾಡಿ. |
| `ARENA_ELO_SYNC_INTERVAL` | `86400` (24h) | ಸಿಂಕ್ ಇಂಟರ್ವಲ್, ಸೆಕೆಂಡುಗಳಲ್ಲಿ.                      |

### ಮ್ಯಾನ್ಯುವಲ್ ಸಿಂಕ್ / ಸ್ಥಿತಿ / ತೆರವುಗೊಳಿಸುವುದು

ಆಪರೇಟರ್ಗಳಿಗಾಗಿ, ದೃಢೀಕೃತ ಮ್ಯಾನೇಜ್ಮೆಂಟ್ ಎಂಡ್ಪಾಯಿಂಟ್ ಮ್ಯಾನ್ಯುವಲ್ ನಿಯಂತ್ರಣವನ್ನು ಒದಗಿಸುತ್ತದೆ
(`src/app/api/intelligence/sync/route.ts` — ಮ್ಯಾನೇಜ್ಮೆಂಟ್ ಆಥ್ ಅಗತ್ಯ):

```
GET    /api/intelligence/sync          # ಪ್ರಸ್ತುತ ಸಿಂಕ್ ಸ್ಥಿತಿ (enabled, lastSync, nextSync, intervalMs)
POST   /api/intelligence/sync          # ಮ್ಯಾನ್ಯುವಲ್ ಸಿಂಕ್ ಟ್ರಿಗರ್ ಮಾಡಿ; ಬರೆಯದೆ ಪ್ರಿವ್ಯೂ ಮಾಡಲು body: { "dryRun": true }
DELETE /api/intelligence/sync          # ಎಲ್ಲಾ ಸಿಂಕ್ ಮಾಡಲಾದ arena_elo ಇಂಟೆಲಿಜೆನ್ಸ್ ನಮೂದುಗಳನ್ನು ತೆರವುಗೊಳಿಸಿ
```

ರ್ಯಾಂಕಿಂಗ್ ಪೇಜ್ ಖಾಲಿಯಾಗಿದ್ದರೆ, ಮ್ಯಾನ್ಯುವಲ್ `POST /api/intelligence/sync` (ಅಥವಾ ಸರಳವಾಗಿ
ಸರ್ವರ್ ಅನ್ನು ಮರುಪ್ರಾರಂಭಿಸುವುದು) ಅದನ್ನು ಮರುಭರ್ತಿ ಮಾಡುತ್ತದೆ.

### ಲೀಡರ್ಬೋರ್ಡ್ಗೆ ಮಾಡೆಲ್ಗಳನ್ನು ಹೊಂದಿಸುವುದು

ರಿಜಿಸ್ಟ್ರಿ ಮಾಡೆಲ್ ID ಗಳು ಮತ್ತು Arena ಮಾಡೆಲ್ ಹೆಸರುಗಳು ಯಾವಾಗಲೂ ನಿಖರವಾಗಿ ಹೊಂದಿಕೆಯಾಗುವುದಿಲ್ಲ. ರ್ಯಾಂಕಿಂಗ್
ಫ್ಲೆಕ್ಸಿಬಲ್ ಮ್ಯಾಚಿಂಗ್ ಅನ್ನು ಬಳಸುತ್ತದೆ (`src/lib/freeProviderRankings.ts` ನಲ್ಲಿ `findMatchingIntelligence`):

1. ನಾರ್ಮಲೈಸ್ ಮಾಡಲಾದ ಮಾಡೆಲ್ ID ಯ ಮೇಲೆ ನಿಖರ ಹೊಂದಾಣಿಕೆ.
2. ಕೊನೆಯ ವರ್ಷನ್ ಸಫಿಕ್ಸ್ ಅನ್ನು ತೆಗೆದ ನಂತರ ಹೊಂದಾಣಿಕೆ (ಉದಾ. `kimi-k2.6` → `kimi-k2`).
3. ಪ್ರಿಫಿಕ್ಸ್ ಹೊಂದಾಣಿಕೆ (ಲೀಡರ್ಬೋರ್ಡ್ ಮಾಡೆಲ್ ಹೆಸರು ರಿಜಿಸ್ಟ್ರಿ ID ಯ ಪ್ರಿಫಿಕ್ಸ್ ಆಗಿದೆ).

ಸಿಂಕ್ ಭಾಗದಲ್ಲಿ, ತಿಳಿದಿರುವ ವೆಂಡರ್ ಪ್ರಿಫಿಕ್ಸ್ಗಳನ್ನು (`anthropic/`, `openai/`, `google/`, …)
ತೆಗೆಯಲಾಗುತ್ತದೆ ಮತ್ತು ಸಣ್ಣ ಅಲಿಯಾಸ್ ಮ್ಯಾಪ್ ಕ್ಯಾನನಿಕಲ್ ಹೆಸರುಗಳನ್ನು OmniRoute ಆಂತರಿಕವಾಗಿ ಬಳಸುವ
ವೇರಿಯಂಟ್ಗಳಾಗಿ ವಿಸ್ತರಿಸುತ್ತದೆ, ಆದ್ದರಿಂದ ಮಾಡೆಲ್ಗಳು ಯಾವುದೇ ಹೆಸರಿನಲ್ಲಿ ಹುಡುಕಲು ಲಭ್ಯವಿರುತ್ತವೆ.

### ಪ್ರೊವೈಡರ್ ಅನ್ನು ಹೇಗೆ ರ್ಯಾಂಕ್ ಮಾಡಲಾಗುತ್ತದೆ

ಪ್ರತಿ ಉಚಿತ ಪ್ರೊವೈಡರ್ಗಾಗಿ, ಎಂಜಿನ್ ಅದರ ಕ್ಯಾಟಲಾಗ್ನಲ್ಲಿನ ಪ್ರತಿ ಮಾಡೆಲ್ ಅನ್ನು ಸ್ಕೋರ್ ಮಾಡುತ್ತದೆ, ನಂತರ:

- **ಟಾಪ್ ಮಾಡೆಲ್** = ಪ್ರೊವೈಡರ್ನ ಅತ್ಯಧಿಕ ಸ್ಕೋರ್ ಪಡೆದ ಮಾಡೆಲ್.
- **ಸರಾಸರಿ ಸ್ಕೋರ್** = ಆ ಪ್ರೊವೈಡರ್ನ ಸ್ಕೋರ್ ಮಾಡಲಾದ ಎಲ್ಲಾ ಮಾಡೆಲ್ಗಳ ಸರಾಸರಿ ಸ್ಕೋರ್.
- **ಮಾಡೆಲ್ಗಳು** = ಪ್ರೊವೈಡರ್ನ ಎಷ್ಟು ಮಾಡೆಲ್ಗಳು Arena ಸ್ಕೋರ್ ಹೊಂದಿದ್ದವು.

ಪ್ರೊವೈಡರ್ಗಳನ್ನು ಮೊದಲು **ಟಾಪ್-ಮಾಡೆಲ್ ಸ್ಕೋರ್** ಮೂಲಕ, ನಂತರ ಸರಾಸರಿ ಸ್ಕೋರ್ ಮೂಲಕ ಕ್ರಮಿಸಲಾಗುತ್ತದೆ. ಇದು
ಕನಿಷ್ಠ ಒಂದು ಬಲಶಾಲಿ ಉಚಿತ ಮಾಡೆಲ್ ಅನ್ನು ನೀಡುವ ಪ್ರೊವೈಡರ್ಗೆ ಬಹುಮಾನ ನೀಡುತ್ತದೆ.

## ಉಚಿತ ಪೂರೈಕೆದಾರರನ್ನು ಆಯ್ಕೆ ಮಾಡಲು ಇದನ್ನು ಬಳಸುವುದು

1. **ಸರಿಯಾದ ವರ್ಗವನ್ನು ಆಯ್ಕೆಮಾಡಿ.** ಏಜೆಂಟ್-ಆಧಾರಿತ/ಕೋಡ್ ಕಾರ್ಯಭಾರಗಳಿಗಾಗಿ **ಕೋಡಿಂಗ್** ಫಿಲ್ಟರ್ ಬಳಸಿ, ಅಥವಾ
   ಸಾಮಾನ್ಯ ಚಾಟ್ಗಾಗಿ ಅದನ್ನು **ಎಲ್ಲಾ ವರ್ಗಗಳು** / **ಡೀಫಾಲ್ಟ್** ಆಯ್ಕೆಯಲ್ಲೇ ಬಿಡಿ. ಪ್ರತಿ ಲೀಡರ್ಬೋರ್ಡ್ನಲ್ಲಿ ಅದರ
   ಅಗ್ರ ಮಾಡೆಲ್ ಭಿನ್ನವಾಗಿರುವುದರಿಂದ, ಒಂದೇ ಪೂರೈಕೆದಾರನು ವಿವಿಧ ವರ್ಗಗಳಲ್ಲಿ ವಿಭಿನ್ನ ಶ್ರೇಣಿ
   ಪಡೆಯಬಹುದು.
2. **ಒಂದೇ ಬಾರಿ ಮಾಡುವ ಸೆಟಪ್ಗಳಿಗೆ ಅಗ್ರ ಮೂರು ಸ್ಥಾನಗಳಿಗೆ ಆದ್ಯತೆ ನೀಡಿ.** ನೀವು ಕೇವಲ ಒಂದು ಅಥವಾ ಎರಡು ಉಚಿತ
   ಪೂರೈಕೆದಾರರನ್ನು ಸಂಪರ್ಕಿಸಲು ಬಯಸಿದರೆ, ನಿಮ್ಮ ವರ್ಗದಲ್ಲಿ ಅಗ್ರ ಶ್ರೇಣಿ ಪಡೆದಿರುವವುಗಳಿಂದ ಪ್ರಾರಂಭಿಸಿ.
3. **ಪ್ರಕಾರದ ಬ್ಯಾಡ್ಜ್ ಪರಿಶೀಲಿಸಿ.** `NOAUTH` ಪೂರೈಕೆದಾರರನ್ನು ಅತ್ಯಂತ ವೇಗವಾಗಿ ಸಂಪರ್ಕಿಸಬಹುದು (ಯಾವುದೇ
   ರುಜುವಾತುಗಳ ಅಗತ್ಯವಿಲ್ಲ). `OAUTH` / `APIKEY` ಉಚಿತ ಹಂತಗಳಿಗೆ ತ್ವರಿತ ನೋಂದಣಿ ಅಗತ್ಯವಿದೆ, ಆದರೆ ಅವು ಸಾಮಾನ್ಯವಾಗಿ
   ಹೆಚ್ಚು ಸಾಮರ್ಥ್ಯವಿರುವ ಮಾಡೆಲ್ಗಳನ್ನು ಒದಗಿಸುತ್ತವೆ. ಸಂಪರ್ಕಿಸುವ ಹಂತಗಳಿಗಾಗಿ
   [ಉಚಿತ ಹಂತಗಳ ಮಾರ್ಗದರ್ಶಿ](../getting-started/FREE-TIERS-GUIDE.md) ನೋಡಿ.
4. **ಹಲವಾರು ಪೂರೈಕೆದಾರರನ್ನು ಸಂಪರ್ಕಿಸಿ ಮತ್ತು Auto-Combo ನಿರ್ಧರಿಸಲು ಬಿಡಿ.** ಈ ಪುಟವನ್ನು ಚಾಲಿತಗೊಳಿಸುವ ಅದೇ Arena ELO ಡೇಟಾವು
   Auto-Combo ಸ್ಕೋರಿಂಗ್ ಎಂಜಿನ್ನ **ಕಾರ್ಯ-ಸೂಕ್ತತೆ ಅಂಶ**ಕ್ಕೂ ಪೂರೈಕೆಯಾಗುತ್ತದೆ
   (`open-sse/services/autoCombo/taskFitness.ts`, ನಿರ್ಧಾರ ಕ್ರಮ
   `user_override → arena_elo → models_dev_tier → static table`). ಆದ್ದರಿಂದ ನೀವು ಅಗ್ರ ಉಚಿತ ಪೂರೈಕೆದಾರರನ್ನು ಸಂಪರ್ಕಿಸಿದ ನಂತರ,
   `model: "auto"` (ಉದಾ. `auto/coding`) ಬಳಸಿ ರೂಟಿಂಗ್ ಮಾಡಿದಾಗ, ಪ್ರತಿ ವಿನಂತಿಗೂ
   ಹೆಚ್ಚಿನ ಗುಣಮಟ್ಟದ ಉಚಿತ ಮಾಡೆಲ್ಗಳಿಗೆ ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಆದ್ಯತೆ ನೀಡಲಾಗುತ್ತದೆ. ಸಂಪೂರ್ಣ 16-ಅಂಶಗಳ ಸ್ಕೋರಿಂಗ್ಗಾಗಿ
   [Auto-Combo](../routing/AUTO-COMBO.md) ನೋಡಿ.
