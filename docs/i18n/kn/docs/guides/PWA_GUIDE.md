ನಿಮ್ಮ ಹೋಮ್ ಸ್ಕ್ರೀನ್ ಅಥವಾ ಡೆಸ್ಕ್ಟಾಪ್ನಿಂದ ಸ್ವತಂತ್ರ ವಿಂಡೋದಲ್ಲಿ ತೆರೆಯಲು OmniRoute ಡ್ಯಾಶ್ಬೋರ್ಡ್ ಅನ್ನು ಪ್ರಗತಿಶೀಲ ವೆಬ್ ಅಪ್ಲಿಕೇಶನ್ನಂತೆ ಸ್ಥಾಪಿಸಿ. ನ್ಯಾವಿಗೇಷನ್, ಡ್ಯಾಶ್ಬೋರ್ಡ್ ಡೇಟಾ ಮತ್ತು API ವಿನಂತಿಗಳಿಗಾಗಿ ಸ್ಥಾಪಿಸಲಾದ ಅಪ್ಲಿಕೇಶನ್ಗೆ ಇನ್ನೂ ನಿಮ್ಮ OmniRoute ಸರ್ವರ್ಗೆ ಸಂಪರ್ಕದ ಅಗತ್ಯವಿದೆ. ಕ್ಯಾಶ್ ಮಾಡಿದ ಸ್ಥಿರ ಸ್ವತ್ತುಗಳು ಆಫ್ಲೈನ್ ಗೇಟ್ವೇ ಅಥವಾ ಆಫ್ಲೈನ್ ಡ್ಯಾಶ್ಬೋರ್ಡ್ ಅನ್ನು ಒದಗಿಸುವುದಿಲ್ಲ.

## PWA ಎಂದರೇನು?

ಒಂದು ಪ್ರಗತಿಶೀಲ ವೆಬ್ ಅಪ್ಲಿಕೇಶನ್ ವೆಬ್ ಡ್ಯಾಶ್ಬೋರ್ಡ್ ಅನ್ನು ಅಪ್ಲಿಕೇಶನ್ ಐಕಾನ್ ಮತ್ತು ಪ್ರತ್ಯೇಕ ವಿಂಡೋದೊಂದಿಗೆ ಬಳಸುತ್ತದೆ. ಒಮ್ಮೆ ಸ್ಥಾಪಿಸಿದ ನಂತರ, OmniRoute:

- ನಿಮ್ಮ ಹೋಮ್ ಸ್ಕ್ರೀನ್ ಅಥವಾ ಡೆಸ್ಕ್ಟಾಪ್ನಿಂದ ಪ್ರಾರಂಭಿಸುತ್ತದೆ
- ಬ್ರೌಸರ್ನ ಸಾಮಾನ್ಯ ವಿಳಾಸ ಪಟ್ಟಿ ಮತ್ತು ಟ್ಯಾಬ್ಗಳಿಲ್ಲದೆಯೇ ಸ್ವತಂತ್ರ ಮೋಡ್ನಲ್ಲಿ ತೆರೆಯುತ್ತದೆ
- ಸಂಗ್ರಹಗಳನ್ನು ಆಯ್ಕೆಮಾಡಿದ ಸ್ಥಿರ ಸ್ವತ್ತುಗಳು
- ಭಾವಚಿತ್ರ ಮತ್ತು ಭೂದೃಶ್ಯದ ದೃಷ್ಟಿಕೋನಗಳನ್ನು ಬೆಂಬಲಿಸುತ್ತದೆ

## ಅನುಸ್ಥಾಪನೆ

ಇನ್ನೊಂದು ಸಾಧನದಲ್ಲಿ ಸರ್ವರ್ಗಾಗಿ HTTPS ವಿಳಾಸವನ್ನು ಬಳಸಿ. ಸರ್ವರ್ ಒಂದೇ ಸಾಧನದಲ್ಲಿ ಚಲಿಸಿದಾಗ, `http://localhost:20128` ಬ್ರೌಸರ್ ಸ್ಥಾಪನೆಯ ಅಗತ್ಯತೆಗಳನ್ನು ಸಹ ಪೂರೈಸುತ್ತದೆ. ಒಂದು ಸರಳ `http://YOUR_IP:20128` ವಿಳಾಸವು ಆ ಅವಶ್ಯಕತೆಗಳನ್ನು ಪೂರೈಸುವುದಿಲ್ಲ. ಅನುಸ್ಥಾಪನ ಮೆನುಗಳು ಮತ್ತು ಪ್ರಾಂಪ್ಟ್ಗಳು ಬ್ರೌಸರ್ ಮತ್ತು ಆಪರೇಟಿಂಗ್ ಸಿಸ್ಟಮ್ ಅನ್ನು ಅವಲಂಬಿಸಿರುತ್ತದೆ. [MDN ನ PWA ಅನುಸ್ಥಾಪನೆಯ ಅವಶ್ಯಕತೆಗಳನ್ನು](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable#https_localhost_or_loopback_are_required) ನೋಡಿ.

### ಆಂಡ್ರಾಯ್ಡ್ (ಕ್ರೋಮ್)

1. ನಿಮ್ಮ OmniRoute HTTPS ವಿಳಾಸವನ್ನು ತೆರೆಯಿರಿ, ಅಥವಾ ಅದೇ ಫೋನ್ನಲ್ಲಿ ಸರ್ವರ್ಗಾಗಿ `http://localhost:20128`.
2. ತೆರೆಯಿರಿ**⋮** ಮೆನು ಮತ್ತು ಆಯ್ಕೆ** ಅಪ್ಲಿಕೇಶನ್ ಸ್ಥಾಪಿಸಿ** ಅಥವಾ** ಮುಖಪುಟ ಪರದೆಗೆ ಸೇರಿಸಿ** , ನೀಡಿದರೆ.
3. ಪ್ರಾಂಪ್ಟ್ ಅನ್ನು ದೃಢೀಕರಿಸಿ.
4. ಮುಖಪುಟ ಪರದೆಯಿಂದ OmniRoute ತೆರೆಯಿರಿ.

### iOS (ಸಫಾರಿ)

1. ಸಫಾರಿಯಲ್ಲಿ ನಿಮ್ಮ OmniRoute HTTPS ವಿಳಾಸವನ್ನು ತೆರೆಯಿರಿ.
2. ಟ್ಯಾಪ್ ಮಾಡಿ** ಹಂಚಿಕೊಳ್ಳಿ** →** ಹೋಮ್ ಸ್ಕ್ರೀನ್ಗೆ ಸೇರಿಸಿ** .
3. ಹೆಸರನ್ನು ದೃಢೀಕರಿಸಿ ಮತ್ತು ಟ್ಯಾಪ್ ಮಾಡಿ** ಸೇರಿಸಿ** .
4. ಮುಖಪುಟ ಪರದೆಯಿಂದ OmniRoute ತೆರೆಯಿರಿ.

### ಡೆಸ್ಕ್ಟಾಪ್ (ಕ್ರೋಮ್ / ಎಡ್ಜ್)

1. ನಿಮ್ಮ OmniRoute ಡ್ಯಾಶ್ಬೋರ್ಡ್ ತೆರೆಯಿರಿ.
2. ಬ್ರೌಸರ್ನ ಸ್ಥಾಪನೆ ಐಕಾನ್ ಅಥವಾ ದಿ** ಅಪ್ಲಿಕೇಶನ್ ಸ್ಥಾಪಿಸಿ** ಮೆನು ನಮೂದು, ನೀಡಿದರೆ.
3. OmniRoute ಅದರ ಸ್ವಂತ ವಿಂಡೋದಲ್ಲಿ ತೆರೆಯಲು ಪ್ರಾಂಪ್ಟ್ ಅನ್ನು ದೃಢೀಕರಿಸಿ.

## ವೈಶಿಷ್ಟ್ಯಗಳು

### ಸ್ವತಂತ್ರ ವಿಂಡೋ

ಮ್ಯಾನಿಫೆಸ್ಟ್ `display: "standalone"` ಮತ್ತು `start_url: "/dashboard"` ಅನ್ನು ಹೊಂದಿಸುತ್ತದೆ. ಸ್ಥಾಪಿಸಲಾದ ಅಪ್ಲಿಕೇಶನ್ ಡ್ಯಾಶ್ಬೋರ್ಡ್ ಅನ್ನು ಅಪ್ಲಿಕೇಶನ್ ವಿಂಡೋದಲ್ಲಿ ತೆರೆಯುತ್ತದೆ. ಬ್ರೌಸರ್ ಮತ್ತು ಆಪರೇಟಿಂಗ್ ಸಿಸ್ಟಮ್ ನಿಯಂತ್ರಣಗಳು ಇನ್ನೂ ಕಾಣಿಸಿಕೊಳ್ಳಬಹುದು; ಮ್ಯಾನಿಫೆಸ್ಟ್ ಪೂರ್ಣಪರದೆಯ ಮೋಡ್ ಅನ್ನು ವಿನಂತಿಸುವುದಿಲ್ಲ.

### ಸಂಗ್ರಹಿಸಿದ ಸ್ವತ್ತುಗಳು ಮತ್ತು ನೆಟ್ವರ್ಕ್ ಅಗತ್ಯತೆಗಳು

[ಸೇವಾ ಕೆಲಸಗಾರನು](../../public/sw.js) ಆಯ್ಕೆಮಾಡಿದ ಅದೇ ಮೂಲದ ಸಂಪನ್ಮೂಲಗಳನ್ನು ಸಂಗ್ರಹಿಸುತ್ತಾನೆ:

| ವಿನಂತಿ ಅಥವಾ ಆಸ್ತಿ                           | ತಂತ್ರ           | ನಡವಳಿಕೆ                                                                                                                          |
| ------------------------------------------- | --------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| ಅನುಸ್ಥಾಪನಾ ಸಮಯದ ಸಂಪನ್ಮೂಲಗಳು                 | ಪೂರ್ವ-ಸಂಗ್ರಹ    | ಕೆಲಸಗಾರರ ಸ್ಥಾಪನೆಯ ಸಮಯದಲ್ಲಿ`/`, `/manifest.webmanifest`, `/icon-512.png` ಮತ್ತು `/apple-touch-icon.png` ಅನ್ನು ಸಂಗ್ರಹಿಸಲಾಗುತ್ತದೆ    |
| Next.js ಸ್ಥಿರ ಸ್ವತ್ತುಗಳು (`/_next/`)        | ನೆಟ್ವರ್ಕ್-ಮೊದಲು | ಯಶಸ್ವಿ ಪ್ರತಿಕ್ರಿಯೆಗಳು ಸಂಗ್ರಹವನ್ನು ನವೀಕರಿಸಿ; ನೆಟ್ವರ್ಕ್ ದೋಷವು ಅಸ್ತಿತ್ವದಲ್ಲಿರುವ ಕ್ಯಾಶ್ ಮಾಡಿದ ಪ್ರತಿಕ್ರಿಯೆಗೆ ಹಿಂತಿರುಗುತ್ತದೆ           |
| ಇತರೆ ಸ್ಥಿರ CSS, JS, ಚಿತ್ರಗಳು ಮತ್ತು ಫಾಂಟ್ಗಳು | ಸಂಗ್ರಹ-ಮೊದಲು    | ಅಸ್ತಿತ್ವದಲ್ಲಿರುವ ಕ್ಯಾಶ್ ಮಾಡಿದ ಪ್ರತಿಕ್ರಿಯೆಯನ್ನು ಮರುಬಳಕೆ ಮಾಡಲಾಗಿದೆ; ಯಶಸ್ವಿ ನೆಟ್ವರ್ಕ್ ಪ್ರತಿಕ್ರಿಯೆಗಳನ್ನು ಮಿಸ್ನಲ್ಲಿ ಸಂಗ್ರಹಿಸಲಾಗುತ್ತದೆ |
| ಪುಟ ಸಂಚರಣೆ                                  | ಬೈಪಾಸ್          | ಬ್ರೌಸರ್ ನೇರವಾಗಿ ಪುಟವನ್ನು ಪಡೆಯುತ್ತದೆ; ಯಾವುದೇ ಆಫ್ಲೈನ್ ಫಾಲ್ಬ್ಯಾಕ್ ನೀಡಲಾಗಿಲ್ಲ                                                        |
| API, ಡ್ಯಾಶ್ಬೋರ್ಡ್ ಮತ್ತು ದೃಢೀಕರಣ ಮಾರ್ಗಗಳು    | ಬೈಪಾಸ್          | ಕೆಲಸಗಾರನು ಈ ವಿನಂತಿಗಳನ್ನು ತಡೆಹಿಡಿಯುವುದಿಲ್ಲ ಅಥವಾ ಸಂಗ್ರಹಿಸುವುದಿಲ್ಲ                                                                  |
| ಇತರ ಸ್ಥಿರವಲ್ಲದ ವಿನಂತಿಗಳು                    | ನೆಟ್ವರ್ಕ್       | ಯಾವುದೇ ಕ್ಯಾಶ್ ಲುಕಪ್ ಅಥವಾ ಸಂಗ್ರಹಣೆ ಇಲ್ಲ                                                                                           |

ಹೊರಗಿಡಲಾದ ಮಾರ್ಗಗಳೆಂದರೆ `/api`, `/a2a`, `/dashboard`, `/v1`, `/v1beta`, `/models`, `/chat`, `/responses`, `/codex`, `/callback` ಮತ್ತು `/login`, ಪಥದ ಗಡಿಗಳಲ್ಲಿ ಕೇಸ್-ಸೂಕ್ಷ್ಮವಾಗಿ ಹೊಂದಾಣಿಕೆಯಾಗುತ್ತವೆ. ಕ್ರಾಸ್-ಮೂಲ ಮತ್ತು GET ಅಲ್ಲದ ವಿನಂತಿಗಳು ಸಹ ಕೆಲಸಗಾರನನ್ನು ಬೈಪಾಸ್ ಮಾಡುತ್ತವೆ.

### ಸಂಪರ್ಕ ಪುಟ

`/offline` ಪುಟವು ಸಂಪರ್ಕ ಸಂದೇಶವನ್ನು ಒದಗಿಸುತ್ತದೆ, online/offline ಸೂಚಕ, a** ಸಂಪರ್ಕವನ್ನು ಮರುಪ್ರಯತ್ನಿಸಿ** ಬಟನ್ ಮತ್ತು ಸ್ಥಿತಿ ಪುಟಕ್ಕೆ ಲಿಂಕ್. ಇದು** ಪೂರ್ವ-ಸಂಗ್ರಹಿಸಲಾಗಿಲ್ಲ** ಮತ್ತು ಸೇವಾ ಕೆಲಸಗಾರನು ಮಾಡುತ್ತಾನೆ** ಅಲ್ಲ** ವಿಫಲವಾದ ನ್ಯಾವಿಗೇಷನ್ಗಳನ್ನು ಅದಕ್ಕೆ ಮರುನಿರ್ದೇಶಿಸುತ್ತದೆ. ಇದರ ಅಸ್ತಿತ್ವವು ಸರ್ವರ್ ಇಲ್ಲದೆ ಹೊಸ ಪುಟಗಳನ್ನು ಪ್ರವೇಶಿಸುವಂತೆ ಮಾಡುವುದಿಲ್ಲ.

### ಅಪ್ಲಿಕೇಶನ್ ಐಕಾನ್ಗಳು

ಮ್ಯಾನಿಫೆಸ್ಟ್ ಈ PNG ಐಕಾನ್ಗಳನ್ನು ಜಾಹೀರಾತು ಮಾಡುತ್ತದೆ:

| ಫೈಲ್                   | ಗಾತ್ರ   | ಬಳಸಿ                                            |
| ---------------------- | ------- | ----------------------------------------------- |
| `icon-192.png`         | 192×192 | ಸಾಮಾನ್ಯ ಅಪ್ಲಿಕೇಶನ್ ಐಕಾನ್                        |
| `icon-512.png`         | 512×512 | ಸಾಮಾನ್ಯ ಮತ್ತು ಮಾಸ್ಕ್ ಮಾಡಬಹುದಾದ ಅಪ್ಲಿಕೇಶನ್ ಐಕಾನ್ |
| `apple-touch-icon.png` | 180×180 | ಆಪಲ್ ಹೋಮ್ ಸ್ಕ್ರೀನ್ ಐಕಾನ್                        |

ಅನುಸ್ಥಾಪನೆಯ ಗುರಿಗಾಗಿ ಬ್ರೌಸರ್ ಸೂಕ್ತವಾದ ಐಕಾನ್ ಅನ್ನು ಆಯ್ಕೆ ಮಾಡುತ್ತದೆ.

### ಸ್ವಯಂಚಾಲಿತ ನೋಂದಣಿ

ಬ್ರೌಸರ್ ಸೇವಾ ಕಾರ್ಯಕರ್ತರನ್ನು ಬೆಂಬಲಿಸಿದಾಗ `PwaRegister` ಕೆಲಸಗಾರನನ್ನು ಉತ್ಪಾದನೆಯಲ್ಲಿ ನೋಂದಾಯಿಸುತ್ತದೆ. ಡೆವಲಪ್ಮೆಂಟ್ ಮೋಡ್ ಕಾರ್ಮಿಕರ ನೋಂದಣಿಯನ್ನು ರದ್ದುಗೊಳಿಸುತ್ತದೆ ಮತ್ತು ಹಾಟ್ ರೀಲೋಡ್ನಲ್ಲಿ ಮಧ್ಯಪ್ರವೇಶಿಸುತ್ತಿರುವ ಹಳೆಯ ಸ್ವತ್ತುಗಳನ್ನು ತಪ್ಪಿಸಲು ಕ್ಯಾಶ್ಗಳನ್ನು ತೆರವುಗೊಳಿಸುತ್ತದೆ. ಇನ್ಸ್ಟಾಲ್ ಪ್ರಾಂಪ್ಟ್ಗಳು ಬ್ರೌಸರ್ ನಿರ್ಧಾರವಾಗಿ ಉಳಿಯುತ್ತವೆ.

## ತಾಂತ್ರಿಕ ವಾಸ್ತುಶಿಲ್ಪ

### ವೆಬ್ ಅಪ್ಲಿಕೇಶನ್ ಮ್ಯಾನಿಫೆಸ್ಟ್

Next.js [`src/app/manifest.ts`](../../src/app/manifest.ts) ನಿಂದ `/manifest.webmanifest` ಉತ್ಪಾದಿಸುತ್ತದೆ. ಇದರ ಪ್ರಮುಖ ಸೆಟ್ಟಿಂಗ್ಗಳು:

| ಸೆಟ್ಟಿಂಗ್                   | ಮೌಲ್ಯ                                            |
| --------------------------- | ------------------------------------------------ |
| `short_name`                | `OmniRoute`                                      |
| `start_url`                 | `/dashboard`                                     |
| `scope`                     | `/`                                              |
| `display`                   | `standalone`                                     |
| `orientation`               | `any`                                            |
| ಹಿನ್ನೆಲೆ ಮತ್ತು ಥೀಮ್ ಬಣ್ಣಗಳು | `PWA_THEME_COLORS` ನಿಂದ ಡೀಫಾಲ್ಟ್ ಬೆಳಕಿನ ಪ್ಯಾಲೆಟ್ |

ಮ್ಯಾನಿಫೆಸ್ಟ್ನ ಹೆಸರು ಮತ್ತು ವಿವರಣೆಯು ಆ ಮೂಲ ಫೈಲ್ನಲ್ಲಿ ಸ್ಥಿರ ಮೌಲ್ಯಗಳಾಗಿವೆ. ಸ್ಥಾಪಿಸಲಾದ ಮ್ಯಾನಿಫೆಸ್ಟ್ ಪ್ರತಿ ಭೇಟಿಯಲ್ಲಿ ನಿದರ್ಶನ-ಹೆಸರು ಸೆಟ್ಟಿಂಗ್ ಅಥವಾ ಸಕ್ರಿಯ ಪ್ಯಾಲೆಟ್ ಅನ್ನು ಅನುಸರಿಸುವುದಿಲ್ಲ.

### ಸೇವಾ ಕಾರ್ಯಕರ್ತ

[`public/sw.js`](../../public/sw.js) ಯಾವುದೇ ಸೇವಾ-ಕಾರ್ಮಿಕರ ಚೌಕಟ್ಟಿನ ಅವಲಂಬನೆಯನ್ನು ಹೊಂದಿಲ್ಲ:

- **ಸ್ಥಾಪಿಸು:** ಮೇಲೆ ಪಟ್ಟಿ ಮಾಡಲಾದ ನಾಲ್ಕು ಸಂಪನ್ಮೂಲಗಳನ್ನು ಪೂರ್ವ-ಕ್ಯಾಶ್ ಮಾಡುತ್ತದೆ ಮತ್ತು ಹೊಸ ಕೆಲಸಗಾರನನ್ನು ಸಕ್ರಿಯಗೊಳಿಸುತ್ತದೆ.
- **ಸಕ್ರಿಯಗೊಳಿಸಿ:** ಹಳೆಯ ಸಂಗ್ರಹ ತಲೆಮಾರುಗಳನ್ನು ತೆಗೆದುಹಾಕುತ್ತದೆ ಮತ್ತು ಕ್ಲೈಂಟ್ಗಳನ್ನು ಕ್ಲೈಮ್ ಮಾಡುತ್ತದೆ.
- **ತರಲು:** ಮೇಲಿನ ಸ್ಥಿರ-ಸ್ವತ್ತು ತಂತ್ರಗಳು ಮತ್ತು ಮಾರ್ಗದ ಹೊರಗಿಡುವಿಕೆಗಳನ್ನು ಅನ್ವಯಿಸುತ್ತದೆ.
- **ಆವೃತ್ತಿ:** ಮೂಲ ಸಂಗ್ರಹದ ಹೆಸರು `omniroute-pwa-v3` ಆಗಿದೆ; ಉತ್ಪಾದನೆಯ ನಿರ್ಮಾಣವು ಸಂಗ್ರಹ ಗುರುತನ್ನು ಮುದ್ರೆ ಮಾಡುತ್ತದೆ.
- **ಅಧಿಸೂಚನೆಗಳು:** ಒಳಬರುವ `push` ಈವೆಂಟ್ಗಳನ್ನು ನಿರ್ವಹಿಸುತ್ತದೆ ಮತ್ತು ಅಧಿಸೂಚನೆಯನ್ನು ಕ್ಲಿಕ್ ಮಾಡಿದಾಗ ವಿಂಡೋವನ್ನು ಕೇಂದ್ರೀಕರಿಸುತ್ತದೆ ಅಥವಾ ತೆರೆಯುತ್ತದೆ.

ಪುಶ್ ಈವೆಂಟ್ ಹ್ಯಾಂಡ್ಲರ್ಗಳು ಮಾತ್ರ ಸಕ್ರಿಯ ಪುಶ್ ಚಂದಾದಾರಿಕೆ ಅಥವಾ ಕಾನ್ಫಿಗರ್ ಮಾಡಿದ ಸರ್ವರ್ ವಿತರಣೆಯನ್ನು ಸ್ಥಾಪಿಸುವುದಿಲ್ಲ. PWA ಅನ್ನು ಸ್ಥಾಪಿಸಿರುವುದರಿಂದ ಅಧಿಸೂಚನೆಗಳನ್ನು ಸಕ್ರಿಯಗೊಳಿಸಲಾಗಿದೆ ಎಂದು ಭಾವಿಸಬೇಡಿ.

### ಲೇಔಟ್ ಮೆಟಾಡೇಟಾ ಮತ್ತು ನೋಂದಣಿ

[`src/app/layout.tsx`](../../src/app/layout.tsx) ಮ್ಯಾನಿಫೆಸ್ಟ್ ಲಿಂಕ್, Apple ಸ್ವತಂತ್ರ ಮೆಟಾಡೇಟಾ, ಥೀಮ್ ಬಣ್ಣಗಳು ಮತ್ತು `viewport-fit: cover` ಒದಗಿಸುತ್ತದೆ. ಪುಟದ ಶೀರ್ಷಿಕೆ ಮತ್ತು Apple ವೆಬ್-ಅಪ್ಲಿಕೇಶನ್ ಶೀರ್ಷಿಕೆಯು ನಿದರ್ಶನದ ಹೆಸರನ್ನು ಬಳಸುತ್ತದೆ. ಲೈವ್ ಬ್ರೌಸರ್ ಥೀಮ್ ಬಣ್ಣವು ಪ್ಯಾಲೆಟ್ ಅನ್ನು ಅನುಸರಿಸುತ್ತದೆ; ಅನುಸ್ಥಾಪನಾ ಮ್ಯಾನಿಫೆಸ್ಟ್ ಡೀಫಾಲ್ಟ್ ಬೆಳಕಿನ ಬಣ್ಣವನ್ನು ಬಳಸುತ್ತದೆ.

[`PwaRegister`](../../src/shared/components/PwaRegister.tsx) ಕ್ಲೈಂಟ್ನಲ್ಲಿ ಚಲಿಸುತ್ತದೆ ಮತ್ತು ಅದರ URL ನಲ್ಲಿ ಬಿಲ್ಡ್ ID ನೊಂದಿಗೆ `/sw.js` ನೋಂದಾಯಿಸುತ್ತದೆ. ಇದು ಹೊಂದಿಕೆಯಾಗದ ಸಂಗ್ರಹ ತಲೆಮಾರುಗಳನ್ನು ಪತ್ತೆ ಮಾಡುತ್ತದೆ ಮತ್ತು ಹಳೆಯ ಸ್ಥಾಪನೆಯಿಂದ ಚೇತರಿಸಿಕೊಳ್ಳಲು ಕೆಲಸಗಾರನನ್ನು ಮರುಹೊಂದಿಸಬಹುದು ಮತ್ತು ಒಮ್ಮೆ ಮರುಲೋಡ್ ಮಾಡಬಹುದು. ನೋಂದಣಿ ವೈಫಲ್ಯವು ಡ್ಯಾಶ್ಬೋರ್ಡ್ ಅನ್ನು ನಿರ್ಬಂಧಿಸುವುದಿಲ್ಲ.

## ಟರ್ಮಕ್ಸ್ (ಆಂಡ್ರಾಯ್ಡ್) ಜೊತೆಗೆ ಬಳಸಿ

1. Termux ನಲ್ಲಿ OmniRoute ಪ್ರಾರಂಭಿಸಿ: `npx -y omniroute@latest`.
2. ಅದೇ ಫೋನ್ನಲ್ಲಿ Chrome ತೆರೆಯಿರಿ: `http://localhost:20128`.
3. ಬ್ರೌಸರ್ನ ಅನುಸ್ಥಾಪನಾ ಮೆನು ಮೂಲಕ PWA ಅನ್ನು ಸ್ಥಾಪಿಸಿ.
4. ಡ್ಯಾಶ್ಬೋರ್ಡ್ ಬಳಸುವಾಗ ಟರ್ಮಕ್ಸ್ ಸರ್ವರ್ ಅನ್ನು ಚಾಲನೆಯಲ್ಲಿಡಿ.

ಫೋನ್ ಗೇಟ್ವೇ ಮತ್ತು ಅದರ ಡ್ಯಾಶ್ಬೋರ್ಡ್ ಎರಡನ್ನೂ ಹೋಸ್ಟ್ ಮಾಡುತ್ತದೆ. ರಿಮೋಟ್ AI ಪೂರೈಕೆದಾರರ ವಿನಂತಿಗಳಿಗೆ ಇನ್ನೂ ನೆಟ್ವರ್ಕ್ ಪ್ರವೇಶದ ಅಗತ್ಯವಿದೆ. ಸೆಟಪ್ ಮತ್ತು Android ಪ್ರಕ್ರಿಯೆ-ಜೀವಮಾನದ ಪರಿಗಣನೆಗಳಿಗಾಗಿ [Termux ಮಾರ್ಗದರ್ಶಿ](TERMUX_GUIDE.md) ನೋಡಿ.

## ಇತರ ಸಾಧನಗಳಿಂದ ಬಳಸಿ

ಫೋನ್, ಟ್ಯಾಬ್ಲೆಟ್ ಅಥವಾ ಡೆಸ್ಕ್ಟಾಪ್ನಲ್ಲಿ ಸರ್ವರ್ನ HTTPS ವಿಳಾಸವನ್ನು ತೆರೆಯಿರಿ, ನಂತರ ಬ್ರೌಸರ್ನ ಅನುಸ್ಥಾಪನಾ ಹರಿವನ್ನು ಅನುಸರಿಸಿ. ಪ್ರತಿ ಸಾಧನದಿಂದ ಸರ್ವರ್ ತಲುಪುವಂತೆ ಇರಬೇಕು. ದೂರಸ್ಥ ಪ್ರವೇಶ ಆಯ್ಕೆಗಳಿಗಾಗಿ [ಸುರಂಗ ಮಾರ್ಗಸೂಚಿಯನ್ನು](../ops/TUNNELS_GUIDE.md) ನೋಡಿ.

## ಗ್ರಾಹಕೀಕರಣ

### ನಿದರ್ಶನದ ಹೆಸರು

ದಿ** ನಿದರ್ಶನದ ಹೆಸರು** ಪುಟದ ಶೀರ್ಷಿಕೆ ಮತ್ತು Apple ವೆಬ್ ಅಪ್ಲಿಕೇಶನ್ ಶೀರ್ಷಿಕೆ ಸೇರಿದಂತೆ ಡ್ಯಾಶ್ಬೋರ್ಡ್ ಮೆಟಾಡೇಟಾವನ್ನು ಬದಲಾಯಿಸುತ್ತದೆ. ರಚಿಸಲಾದ ಮ್ಯಾನಿಫೆಸ್ಟ್ ಸ್ಥಿರ ಹೆಸರನ್ನು ಬಳಸುತ್ತದೆ, ಆದ್ದರಿಂದ ಈ ಸೆಟ್ಟಿಂಗ್ ಈಗಾಗಲೇ ಸ್ಥಾಪಿಸಲಾದ ಅಪ್ಲಿಕೇಶನ್ ಅನ್ನು ಮರುಹೆಸರಿಸಲಾಗಿದೆ ಎಂದು ಖಾತರಿ ನೀಡುವುದಿಲ್ಲ.

### ಕಸ್ಟಮ್ ಫೆವಿಕಾನ್

ಕಸ್ಟಮ್ ಫೆವಿಕಾನ್ ಬ್ರೌಸರ್ ಫೆವಿಕಾನ್ ಅನ್ನು ಬದಲಾಯಿಸುತ್ತದೆ. ಇನ್ಸ್ಟಾಲ್ ಮ್ಯಾನಿಫೆಸ್ಟ್ ಇನ್ನೂ ಮೇಲಿನ PNG ಫೈಲ್ಗಳನ್ನು ಜಾಹೀರಾತು ಮಾಡುತ್ತದೆ; ಫೆವಿಕಾನ್ ಅನ್ನು ಬದಲಾಯಿಸುವುದರಿಂದ ಆ ಹೋಮ್-ಸ್ಕ್ರೀನ್ ಐಕಾನ್ಗಳನ್ನು ಬದಲಾಯಿಸುವುದಿಲ್ಲ.

## ಮಿತಿಗಳು

- **ಸರ್ವರ್ ಸಂಪರ್ಕ ಅಗತ್ಯವಿದೆ:** ಪುಟ ಸಂಚರಣೆ, ಡ್ಯಾಶ್ಬೋರ್ಡ್ ಸ್ಥಿತಿ ಮತ್ತು API ವಿನಂತಿಗಳು ಆಫ್ಲೈನ್ ಫಾಲ್ಬ್ಯಾಕ್ ಹೊಂದಿಲ್ಲ.
- **ಯಾವುದೇ ಹಿನ್ನೆಲೆ ಸಿಂಕ್ ಇಲ್ಲ:** ಆಫ್ಲೈನ್ ಕ್ರಿಯೆಗಳು ಮರುಪಂದ್ಯಕ್ಕಾಗಿ ಸರದಿಯಲ್ಲಿಲ್ಲ.
- **ಬ್ರೌಸರ್ ವ್ಯತ್ಯಾಸಗಳು:** ಅನುಸ್ಥಾಪನಾ ಮೆನುಗಳು, ವಿಂಡೋ ಪ್ರಸ್ತುತಿ ಮತ್ತು ಅಧಿಸೂಚನೆ ಬೆಂಬಲವು ವೇದಿಕೆಯಿಂದ ಬದಲಾಗುತ್ತದೆ.
- **API ಪ್ರತಿಕ್ರಿಯೆ ಸಂಗ್ರಹವಿಲ್ಲ:** ಕೆಲಸಗಾರನು API, ಡ್ಯಾಶ್ಬೋರ್ಡ್ ಮತ್ತು ದೃಢೀಕರಣ ಮಾರ್ಗಗಳನ್ನು ಹೊರತುಪಡಿಸುತ್ತಾನೆ.
- **ಸ್ಥಾಯೀ ಸ್ಥಾಪನೆ ಐಕಾನ್ಗಳು:** ಆ ಐಕಾನ್ಗಳನ್ನು ನವೀಕರಿಸಲು ಜಾಹೀರಾತು ಸ್ವತ್ತುಗಳನ್ನು ಬದಲಾಯಿಸುವ ಅಗತ್ಯವಿದೆ; ಬ್ರೌಸರ್ಗಳು ಸ್ಥಾಪಿಸಲಾದ ಮೆಟಾಡೇಟಾವನ್ನು ಉಳಿಸಿಕೊಳ್ಳಬಹುದು.
