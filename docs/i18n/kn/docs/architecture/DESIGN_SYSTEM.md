> **ಸ್ಥಿತಿ:** ಡ್ಯಾಶ್ಬೋರ್ಡ್ ಅನ್ನು **Keak CI UI Kit** (`@keak/cheaper-inference-ui-kit`) ಆಧರಿಸಿ ನಿರ್ಮಿಸಲಾಗಿದೆ ಮತ್ತು ಅದನ್ನು
> `packages/ui-kit` (`@omniroute/ui-kit`) ಕಾರ್ಯಸ್ಥಳವಾಗಿ ವೆಂಡರ್ ಮಾಡಲಾಗಿದೆ; ಅಪ್ಸ್ಟ್ರೀಮ್ ಸ್ನ್ಯಾಪ್ಶಾಟ್ ಅನ್ನು
> `packages/ui-kit/UPSTREAM.md` ನಲ್ಲಿ ಪಿನ್ ಮಾಡಲಾಗಿದೆ ಮತ್ತು `npm run check:ui-kit-snapshot` ಮೂಲಕ ಸಂರಕ್ಷಿಸಲಾಗಿದೆ. ಲೈಟ್ ಅಂಗೀಕೃತ
> ಥೀಮ್ ಆಗಿದೆ; ಡೀಫಾಲ್ಟ್ ಆದ್ಯತೆ `system` ಆಗಿದೆ. ಆಕ್ಸೆಂಟ್ Keak ಲೈಮ್ (`--ci-color-accent`) ಆಗಿದೆ. Inter
> (ಅಕ್ಷರ-ಅಂತರ 0, `--ci-letter-spacing-ui`) UI ಫಾಂಟ್ ಕುಟುಂಬವಾಗಿದೆ, Instrument Serif ಅನ್ನು ದೊಡ್ಡದಾದ, ವಿರಳವಾದ
> ಪ್ರದರ್ಶನ ಪಠ್ಯಕ್ಕೆ (`.ci-dashboard-display`) ಮಾತ್ರ ಬಳಸಲಾಗುತ್ತದೆ ಮತ್ತು IBM Plex Mono ಅನ್ನು ಕೋಡ್ಗಾಗಿ ಬಳಸಲಾಗುತ್ತದೆ — ಇವೆಲ್ಲವನ್ನೂ
> `src/app/globals.css` ನ ಮೇಲ್ಭಾಗದಲ್ಲಿರುವ `@fontsource/*` ಇಂಪೋರ್ಟ್ಗಳ ಮೂಲಕ ಸ್ವಯಂ-ಹೋಸ್ಟ್ ಮಾಡಲಾಗಿದೆ. ಪ್ರತಿಯೊಂದು ಐಕಾನ್ Lucide ಗ್ಲಿಫ್ ಆಗಿದೆ.

## 1. ವಿಷಯಗಳು ಎಲ್ಲಿವೆ

- **ಕಿಟ್.** `packages/ui-kit/src` ಎಂಬುದು
  `packages/ui-kit/UPSTREAM.md` ನಲ್ಲಿ ಪಿನ್ ಮಾಡಲಾದ ಕಮಿಟ್ನಲ್ಲಿರುವ ಅಪ್ಸ್ಟ್ರೀಮ್ `src/` ನ ಬೈಟ್-ಫಾರ್-ಬೈಟ್ ನಕಲು
  (`packages/ui-kit/UPSTREAM.md` ಪರವಾನಗಿ ಅನುಮತಿಯನ್ನೂ ದಾಖಲಿಸುತ್ತದೆ); `PATCHES.md` ಸ್ಥಳೀಯ ಪ್ಯಾಚ್ಗಳನ್ನು
  ಪಟ್ಟಿ ಮಾಡುತ್ತದೆ (ಯಾವುದೂ ಇಲ್ಲ). ಇದನ್ನು ಯಾವುದೇ ಬಿಲ್ಡ್ ಇಲ್ಲದೆ ಮೂಲವಾಗಿಯೇ ಬಳಸಲಾಗುತ್ತದೆ: `next.config.mjs`
  ಅದನ್ನು ಟ್ರಾನ್ಸ್ಪೈಲ್ ಮಾಡುತ್ತದೆ ಮತ್ತು `tsconfig.json` ನಲ್ಲಿ `@omniroute/ui-kit` →
  `packages/ui-kit/src` ಹಾಗೂ `@omniroute/ui-kit/*` → `packages/ui-kit/src/*` ಎಂದು ಮ್ಯಾಪ್ ಮಾಡಲಾಗಿದೆ
  (`vitest.config.ts` ಮತ್ತು `vitest.mcp.config.ts` ನಲ್ಲಿಯೂ ಅದೇ ಅಲಿಯಾಸ್ ಇದೆ). ಕಿಟ್ ಕಾಂಪೊನೆಂಟ್ ಅನ್ನು ಅದರ
  ಉಪಪಥದ ಮೂಲಕ (`@omniroute/ui-kit/table`, `@omniroute/ui-kit/page-header`…) ಆಮದು ಮಾಡಿ,
  `@omniroute/ui-kit` ಬ್ಯಾರಲ್ ಮೂಲಕ ಎಂದಿಗೂ ಆಮದು ಮಾಡಬೇಡಿ: ಬ್ಯಾರಲ್ ಪ್ರತಿಯೊಂದು ಕಾಂಪೊನೆಂಟ್ಅನ್ನೂ (ದಿನಾಂಕ
  ಪಿಕರ್ ಸೇರಿದಂತೆ) ಪ್ರತಿ ಆಮದುಗಾರನಲ್ಲಿ ಸೇರಿಸುತ್ತದೆ. ಕಿಟ್ ಸ್ಟೈಲ್ಶೀಟ್ `src/app/globals.css` ಮೂಲಕ
  ಪ್ರವೇಶಿಸುತ್ತದೆ (`@import "../../packages/ui-kit/src/ci-ui.css"`).
- **ಟೋಕನ್ಗಳು.** `packages/ui-kit/src/ci-tokens.css` ನಲ್ಲಿ `--ci-*` ಟೋಕನ್ಗಳನ್ನು ಘೋಷಿಸಲಾಗಿದೆ;
  `src/app/globals.css` ಅವುಗಳನ್ನು ಹಳೆಯ OmniRoute ಹೆಸರುಗಳಿಗೆ (`--color-*`, `--radius-*`,
  `--font-sans`/`--font-mono`, `--table-*`, `--orch-status-*`, `--color-fd-*`) ಸೇತುವೆ ಮಾಡುತ್ತದೆ, ಆದ್ದರಿಂದ
  ಈಗಿರುವ `var(--color-*)` ಓದುವಿಕೆಗಳು ಮತ್ತು Tailwind ಯುಟಿಲಿಟಿಗಳು ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತಲೇ ಇರುತ್ತವೆ. ಹೊಸ ಕೋಡ್
  Tailwind ಯುಟಿಲಿಟಿಗಳನ್ನು (`bg-surface`, `text-text-muted`, `border-border`, `text-success`,
  `bg-success-bg`, `bg-chart-1`…) ಅಥವಾ ಕಿಟ್ ಕ್ಲಾಸ್ಗಳನ್ನು ಬಳಸುತ್ತದೆ — ಹೆಕ್ಸ್ ಮೌಲ್ಯವನ್ನು ಎಂದಿಗೂ ಬಳಸುವುದಿಲ್ಲ
  (`tests/unit/design-kit-bridge.test.ts` ಈ ಸೇತುವೆಯನ್ನು ಕಡ್ಡಾಯಗೊಳಿಸುತ್ತದೆ). `text-primary`,
  `--text-color-primary` ಮೂಲಕ `--color-primary-ink` ಗೆ ಪರಿಹಾರಗೊಳ್ಳುತ್ತದೆ (ಲೈಟ್ನಲ್ಲಿ lime-800,
  ಡಾರ್ಕ್ನಲ್ಲಿ ಲೈಮ್ ಆಕ್ಸೆಂಟ್), ಆದ್ದರಿಂದ `bg-primary`/`border-primary` ಲೈಮ್ ಮೇಲ್ಮೈಯನ್ನು ಉಳಿಸಿಕೊಳ್ಳುವಾಗ
  ಪ್ರೈಮರಿ ಪಠ್ಯವು ಓದಲು ಸುಲಭವಾಗಿರುತ್ತದೆ. ಚಾರ್ಟ್ ಸರಣಿಗಳು `--color-chart-1` … `--color-chart-5` ಅನ್ನು ಬಳಸುತ್ತವೆ.
- **ಥೀಮ್ಗಳು.** `<html className="ci-theme">` (`src/app/layout.tsx`) ಡಾಕ್ಯುಮೆಂಟ್ಗೆ ಕಿಟ್ ಥೀಮ್ ಅನ್ನು
  ಸಕ್ರಿಯಗೊಳಿಸುತ್ತದೆ. ಆದ್ಯತೆಯು `light`, `dark` ಅಥವಾ `system` ಆಗಿರುತ್ತದೆ
  (`src/shared/constants/appConfig.ts` ನಲ್ಲಿ `THEME_CONFIG.defaultTheme = "system"`; `system`,
  `prefers-color-scheme` ಅನ್ನು ಅನುಸರಿಸುತ್ತದೆ). `src/store/themeStore.ts` ನಲ್ಲಿರುವ `applyTheme()`
  (ಹೈಡ್ರೇಷನ್ಗಿಂತ ಮೊದಲು ರನ್ ಆಗುವ `src/app/layout.tsx` ನ ಇನ್ಲೈನ್ ಬೂಟ್ಸ್ಟ್ರ್ಯಾಪ್ ಸ್ಕ್ರಿಪ್ಟ್ನಲ್ಲಿಯೂ
  ಪ್ರತಿಬಿಂಬಿಸಲಾಗಿದೆ) `data-theme="dark"|"light"` ಅನ್ನು ಹೊಂದಿಸುತ್ತದೆ ಮತ್ತು ಅದೇ ಸಮಯದಲ್ಲಿ `<html>` ಮೇಲಿನ
  `.dark` ಕ್ಲಾಸ್ ಅನ್ನು ಟಾಗಲ್ ಮಾಡುತ್ತದೆ. ಕಿಟ್ನ ಡಾರ್ಕ್ ಟೋಕನ್ ಸೆಟ್ `data-theme="dark"` ಅನ್ನು ಆಧರಿಸಿದೆ
  (`packages/ui-kit/src/ci-tokens.css`); OmniRoute ನ ಸ್ವಂತ ಡಾರ್ಕ್ ಓವರ್ರೈಡ್ಗಳು (`globals.css` ನಲ್ಲಿನ
  `.dark` ಬ್ಲಾಕ್) ಮತ್ತು ಹಳೆಯ Tailwind `dark:` ಯುಟಿಲಿಟಿಗಳು `.dark` ಕ್ಲಾಸ್ ಅನ್ನು ಆಧರಿಸಿವೆ. ಯಾವುದೇ ಆಕ್ಸೆಂಟ್
  ಬಣ್ಣದ ಪ್ರಿಸೆಟ್ಗಳಿಲ್ಲ: ಆಕ್ಸೆಂಟ್ ಯಾವಾಗಲೂ ಕಿಟ್ನಿಂದ ಬರುತ್ತದೆ ಮತ್ತು ಹಳೆಯ ಬಿಲ್ಡ್ನಿಂದ ಉಳಿಸಿಕೊಂಡಿರುವ ಪ್ರಿಸೆಟ್
  ಅನ್ನು ಸ್ಟೋರ್ ಲೋಡ್ ಆಗುವಾಗ ತೆಗೆದುಹಾಕಲಾಗುತ್ತದೆ.
- **ಕಾಂಪೊನೆಂಟ್ಗಳು (ಅಡಾಪ್ಟರ್ಗಳು).** `src/shared/components/index.tsx` OmniRoute ಕಾಂಪೊನೆಂಟ್ API ಅನ್ನು
  (ಅದೇ ಹೆಸರುಗಳು, ಡೀಫಾಲ್ಟ್ ಎಕ್ಸ್ಪೋರ್ಟ್ಗಳು ಮತ್ತು ಪ್ರಾಪ್ಗಳು) ಉಳಿಸಿಕೊಳ್ಳುತ್ತದೆ ಮತ್ತು ಅದರ ಹಿಂದಿರುವ
  ಪ್ರಿಮಿಟಿವ್ಗಳು ಕಿಟ್ ಮೇಲಿನ ಅಡಾಪ್ಟರ್ಗಳಾಗಿವೆ: ಫಾರ್ಮ್ಗಳು (`Button`, `Input`, `Textarea`, `Checkbox`,
  `Select`, `Toggle`, `Badge`, `Card`), ಓವರ್ಲೇಗಳು ಮತ್ತು ಪ್ರತಿಕ್ರಿಯೆ (`Modal`/`ConfirmModal`,
  `Tooltip`/`InfoTooltip`, `NotificationToast`, `EmptyState`, `Loading`), ರಚನೆ (`Collapsible`,
  `CollapsibleSection`, `SegmentedControl`, `Breadcrumbs`, `Avatar`) ಮತ್ತು ಟೇಬಲ್ಗಳು (`DataTable`,
  `FilterBar`, `ColumnToggle`, `FilterPills`, `PresetSlider`). ಅಡಾಪ್ಟರ್ ಕಿಟ್ ಕಾಂಪೊನೆಂಟ್ ಅನ್ನು ಉಪಪಥದ ಮೂಲಕ
  ಆಮದು ಮಾಡಿ, ಹಳೆಯ ಪ್ರಾಪ್ಗಳನ್ನು ಅದಕ್ಕೆ ಮ್ಯಾಪ್ ಮಾಡುತ್ತದೆ — ಉದಾಹರಣೆಗೆ `Button variant="primary"` ಎಂಬುದು
  ಕಿಟ್ನ `default` ಬಟನ್ ಆಗಿದೆ (`--ci-button-primary-*`: ಲೈಟ್ನಲ್ಲಿ ವ್ಯತಿರಿಕ್ತ ಮೇಲ್ಮೈ, ಡಾರ್ಕ್ನಲ್ಲಿ ಅದರ
  `--ci-color-accent-foreground` ಇಂಕ್ನೊಂದಿಗಿನ ಆಕ್ಸೆಂಟ್), `danger` ಎಂಬುದು `destructive` ಆಗಿದ್ದು,
  `warning` ಎಂಬುದು `outline` ಜೊತೆಗೆ `.ci-button--warning` ವಿಸ್ತರಣೆಯಾಗಿದೆ. `globals.css` ನ ಕೊನೆಯಲ್ಲಿರುವ
  (`@layer components`) `.ci-button--warning` ಮತ್ತು `.ci-badge[data-tone]` ನಿಯಮಗಳು ಕಿಟ್ ಕ್ಲಾಸ್ಗಳ ಮೇಲಿನ
  OmniRoute ವಿಸ್ತರಣೆಗಳಾಗಿವೆ. `tests/unit/ui/adapters/*.test.tsx` ಪ್ರತಿ ಅಡಾಪ್ಟರ್ ಅನ್ನು ಸ್ಥಿರಗೊಳಿಸುತ್ತದೆ.
- **ಶೆಲ್.** `src/app/(dashboard)/layout.tsx`, `DashboardLayout` ಅನ್ನು ರೆಂಡರ್ ಮಾಡುತ್ತದೆ; ಅದು
  `src/shared/components/layouts/DashboardShell.tsx` ಅನ್ನು ರೆಂಡರ್ ಮಾಡುತ್ತದೆ: ಕಿಟ್ನ `SidebarProvider` /
  `Sidebar` / `SidebarInset` (`packages/ui-kit/src/sidebar.tsx`), ಜೊತೆಗೆ
  `src/shared/components/Sidebar.tsx` ನಲ್ಲಿ OmniRoute ನ ನ್ಯಾವಿಗೇಷನ್ ಲಾಜಿಕ್. `#main-content` ಗೆ
  “ವಿಷಯಕ್ಕೆ ತೆರಳಿ” ಲಿಂಕ್ ಮೊದಲ ಫೋಕಸ್ ಮಾಡಬಹುದಾದ ಎಲಿಮೆಂಟ್ ಆಗಿದೆ. `src/shared/components/Header.tsx` ಕಿಟ್ನ

## 5. ಕಿಟ್ ಅನ್ನು ನವೀಕರಿಸುವುದು

`scripts/dev/sync-ui-kit.sh <commit> [clone]` ಆ commit ನಲ್ಲಿರುವ upstream `src/` ಅನ್ನು
`packages/ui-kit/src` ಗೆ ನಕಲಿಸುತ್ತದೆ ಮತ್ತು ಅನುಮತಿಸಲಾದ ಏಕೈಕ ಪರಿವರ್ತನೆಯನ್ನು ಅನ್ವಯಿಸುತ್ತದೆ (ಇದು relative imports ನಿಂದ `.js` suffix ಅನ್ನು
ತೆಗೆದುಹಾಕುತ್ತದೆ). ನಂತರ: `git diff packages/ui-kit` ಅನ್ನು ಪರಿಶೀಲಿಸಿ, ಎರಡೂ themes ನಲ್ಲಿ providers, settings, combos,
usage ಮತ್ತು endpoint ಗಳ ದೃಶ್ಯ ಪರಿಶೀಲನೆ ನಡೆಸಿ, `npm run check:ui-kit-snapshot` ಮತ್ತು `npm run test:vitest:ui` ಅನ್ನು ಚಲಾಯಿಸಿ ಹಾಗೂ
upstream changelog ನೊಂದಿಗೆ PR ತೆರೆಯಿರಿ.
