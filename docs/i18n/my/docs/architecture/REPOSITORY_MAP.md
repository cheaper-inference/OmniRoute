## ထိပ်ဆုံးအဆင့် tree

```
OmniRoute/
├── src/                  # Next.js 16 application (UI + API routes + libs + domain + server)
├── open-sse/             # Streaming engine workspace (handlers၊ executors၊ translator၊ MCP server)
├── packages/            # npm workspaces: ui-kit (ထည့်သွင်းပေးထားသော Keak CI UI Kit) နှင့် browser-pool
├── electron/             # Desktop wrapper (Electron 41 + electron-builder 26.10)
├── bin/                  # CLI entry point နှင့် command handlers
├── scripts/              # Build၊ check၊ sync နှင့် တစ်ကြိမ်သုံး scripts
├── docs/                 # အများပြည်သူသုံး documentation (သင် ယခုရောက်နေသောနေရာ)
├── tests/                # Test suites အားလုံး (unit၊ integration၊ e2e၊ protocol clients)
├── public/               # Next.js static assets၊ PWA manifest၊ service worker၊ icons
├── config/               # Static config + quality-gate state (i18n၊ payloadRules၊ quality/)
├── images/               # Marketing / README image assets
├── @omniroute/           # Publish လုပ်နိုင်သော companion packages (opencode-plugin၊ opencode-provider)
├── skills/               # CLI/agent skill packs (cli-* + omni-* + config-codex-cli)
├── examples/             # နမူနာ plugins + omniroute-cmd-hello starter
├── contrib/              # Community contributions (podman/)
├── .source/              # Fumadocs source config (source.config.mjs + server/browser/dynamic)
├── .github/              # GitHub Actions workflows + issue templates + PR template
├── .husky/               # Git hooks (pre-commit၊ pre-push)
├── .claude/              # Claude Code slash commands (project အတွက်သာ)
├── .agents/              # Codex / generic agent workflows + skills (.claude/ ၏ mirror)
├── .vscode/              # VS Code workspace settings
├── _ideia/               # အစီအစဉ်ရေးဆွဲမှုမှတ်စုများ (အလွတ်သဘော၊ ဖြန့်ချိမှုတွင် မပါဝင်)
├── _mono_repo/           # သမိုင်းဝင် subprojects (cloud၊ site၊ vscode-extension)
├── _references/          # ဆက်စပ် OSS projects များမှ ဖတ်ရှုရန်သာဖြစ်သော reference clones
├── _tasks/               # Release တစ်ခုချင်းစီအလိုက် task tracking files (အလွတ်သဘော)
├── .build/ .worktrees/ dist/   # Local build / git-worktree / build-output ယာယီနေရာ (gitignored)
├── .issues/              # Local issue cache (gitignored)
├── .playwright-mcp/      # Playwright MCP test artifacts
├── coverage/             # c8 coverage output (gitignored)
├── logs/                 # Runtime logs (gitignored)
├── node_modules/         # Dependencies (gitignored)
├── package/              # npm pack staging area (build artifact)
├── .next/                # Next.js build output (gitignored)
└── (root files — အောက်တွင်ကြည့်ပါ)
```

## `src/` — Next.js အက်ပ်လီကေးရှင်း

```
src/
├── app/                 # App Router (စာမျက်နှာများ + API လမ်းကြောင်းများ + အခြေအနေစာမျက်နှာများ + လမ်းညွှန်စာမျက်နှာ)
├── lib/                 # အဓိကလိုင်ဘရာရီများ / ဒိုမိန်းမော်ဂျူးများ (ဖိုင်တွဲခွဲ 80 ခု + ထိပ်တန်းအဆင့်ဖိုင် ~70 ခု)
├── domain/              # သန့်စင်သောဒိုမိန်းလော့ဂျစ် (မူဝါဒအင်ဂျင်၊ အရန်လုပ်ဆောင်ချက်၊ ကုန်ကျစရိတ်၊ လော့ခ်ချမှု၊ comboResolver၊ အကဲဖြတ်မှု)
├── server/              # ဆာဗာသီးသန့်မော်ဂျူးများ (authz pipeline၊ cors၊ အထောက်အထားစစ်ဆေးရေး middleware) — client မှ import လုပ်၍မရပါ
├── shared/              # ဘေးကင်းသည့်နေရာများတွင် ဆာဗာနှင့် client ကြား မျှဝေထားသည် (ကိန်းသေများ၊ အမျိုးအစားများ၊ အတည်ပြုစစ်ဆေးမှု၊ စာချုပ်များ၊ အသုံးဝင်ကိရိယာများ)
```

| Path                     | ရည်ရွယ်ချက်                                               |
| ------------------------ | --------------------------------------------------------- |
| `workflows/*-ag.md`      | Workflow သတ်မှတ်ချက် 11 ခု (`.claude/commands/` ၏ မိတ္တူ) |
| `skills/<name>/SKILL.md` | Codex Execution Notes ပါဝင်သည့် skill သတ်မှတ်ချက် 9 ခု    |

> **မှတ်ချက်:** Workflow နှင့် command များသည် လောလောဆယ် byte တစ်လုံးချင်းစီအထိ တူညီနေသည်။ `.agents/` သည် မတူညီသော agent runtime (Codex) အတွက် ရည်ရွယ်ထားခြင်းဖြစ်ပါက variant များတွင် အဓိပ္ပာယ်ရှိသော ကွဲပြားမှုများ လိုအပ်သည်။

## `_ideia/`, `_mono_repo/`, `_references/`, `_tasks/` — ပင်မဖွဲ့စည်းပုံပြင်ပ

ရှေ့တွင် underscore ပါသော ဤ directory များတွင် ဖြန့်ချိမှု၌ မပါဝင်သည့် အကြောင်းအရာများကို သိမ်းဆည်းထားသည်-

- **`_ideia/`** — design note များ (defer / notfit / viable အမျိုးအစားများ)
- **`_mono_repo/`** — ယခင် subproject များ (omnirouteCloud၊ omnirouteSite၊ vscode-extension)
- **`_references/`** — ဖွံ့ဖြိုးတိုးတက်ရေးအတွင်း အပြန်အလှန်ကိုးကားရန် သက်ဆိုင်ရာ OSS project များ၏ ဖတ်ရှုရန်သာ clone များ (LiteLLM၊ 9router၊ ClawRouter၊ CLIProxyAPI၊ modelrelay၊ new-api စသည်)
- **`_tasks/`** — release တစ်ခုချင်းစီအလိုက် task ခြေရာခံဖိုင်များ (အလွတ်သဘော)

`npm pack` output တွင် မပါဝင်ပါ။ `.npmignore` ကို ကြည့်ပါ။
