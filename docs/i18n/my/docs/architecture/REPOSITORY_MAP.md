## ထိပ်ဆုံးအဆင့် tree

```
OmniRoute/
├── src/                  # Next.js 16 application (UI + API routes + libs + domain + server)
├── open-sse/             # Streaming engine workspace (handlers၊ executors၊ translator၊ MCP server)
├── packages/            # npm workspaces: ui-kit (ထည့်သွင်းပေးထားသော Keak CI UI Kit) နှင့် browser-pool
├── electron/             # Desktop wrapper (Electron 41 + electron-builder 26.10)
├── bin/                  # CLI entry point နှင့် command handlers
├── scripts/              # Build၊ check၊ sync နှင့် တစ်ကြိမ်သုံး scripts
├── docs/                 # အများပြည်သူသုံး documentation (သင် ယခုရောက်နေသောနေရာ)
├── tests/                # Test suites အားလုံး (unit၊ integration၊ e2e၊ protocol clients)
├── public/               # Next.js static assets၊ PWA manifest၊ service worker၊ icons
├── config/               # Static config + quality-gate state (i18n၊ payloadRules၊ quality/)
├── images/               # Marketing / README image assets
├── @omniroute/           # Publish လုပ်နိုင်သော companion packages (opencode-plugin၊ opencode-provider)
├── skills/               # CLI/agent skill packs (cli-* + omni-* + config-codex-cli)
├── examples/             # နမူနာ plugins + omniroute-cmd-hello starter
├── contrib/              # Community contributions (podman/)
├── .source/              # Fumadocs source config (source.config.mjs + server/browser/dynamic)
├── .github/              # GitHub Actions workflows + issue templates + PR template
├── .husky/               # Git hooks (pre-commit၊ pre-push)
├── .claude/              # Claude Code slash commands (project အတွက်သာ)
├── .agents/              # Codex / generic agent workflows + skills (.claude/ ၏ mirror)
├── .vscode/              # VS Code workspace settings
├── _ideia/               # အစီအစဉ်ရေးဆွဲမှုမှတ်စုများ (အလွတ်သဘော၊ ဖြန့်ချိမှုတွင် မပါဝင်)
├── _mono_repo/           # သမိုင်းဝင် subprojects (cloud၊ site၊ vscode-extension)

├── .issues/              # Local issue cache (gitignored)
├── .playwright-mcp/      # Playwright MCP test artifacts
├── coverage/             # c8 coverage output (gitignored)
├── logs/                 # Runtime logs (gitignored)
├── node_modules/         # Dependencies (gitignored)
```

## `src/` — Next.js လျှောက်လွှာ

```
src/
├── app/                 # App Router (pages + API routes + status pages + landing)
├── lib/                 # Core libraries / domain modules (80 subdirs + ~70 top-level files)
├── domain/              # Pure domain logic (policy engine, fallback, cost, lockout, comboResolver, assessment)
├── server/              # Server-only modules (authz pipeline, cors, auth middleware) — cannot import from client
├── shared/              # Shared between server and client where safe (constants, types, validation, contracts, utils)
├── i18n/                # next-intl config + per-locale message JSON (67 locales)
├── middleware/          # Next.js middleware (request enrichment, locale detection)
├── mitm/                # MITM proxy core: cert gen/install, handlers, targets, inspector, masks, passthrough
│   ├── handlers/        # 9 IDE-agent handler classes extending MitmHandlerBase (antigravity, kiro, copilot, codex, cursor, zed, claudeCode, openCode, trae)
│   └── inspector/       # Traffic capture layer: buffer (in-memory ring), sseMerger, conversationNormalizer, kindDetector, contextKey, httpProxyServer, systemProxyConfig
├── models/              # Model adapter glue (legacy shim)
├── scripts/             # In-tree maintenance scripts (e.g., backfillAggregation)
├── sse/                 # Legacy SSE handlers/services (chat.ts, chatHelpers.ts, services/auth.ts)
├── store/               # Legacy in-memory store (being phased out for src/lib/db)
├── types/               # Shared TS type files
├── instrumentation.ts   # Next.js telemetry hook (browser + edge)
├── instrumentation-node.ts  # Node-only instrumentation
└── proxy.ts             # HTTP-proxy entry shim
```

ဖြန့်ချိထားသော configuration template များနှင့် commit လုပ်ထားသော အရည်အသွေးစစ်ဆေးရေးအဆင့် baseline များ
(repo ပင်မနေရာကို ရှင်းလင်းပေါ့ပါးစေရန် v3.8.26 တွင် ဤနေရာသို့ ရွှေ့ထားသည်)။

| လမ်းကြောင်း                                   | ရည်ရွယ်ချက်                                                                         |
| --------------------------------------------- | ----------------------------------------------------------------------------------- |
| `config/i18n.json`                            | Locale စာရင်း + metadata (locale 42 ခုရှိကြောင်းအတွက် တရားဝင်အရင်းအမြစ်)            |
| `config/i18n-schema.json`                     | `i18n.json` ကို စစ်ဆေးအတည်ပြုသည့် JSON schema                                       |
| `config/payloadRules.json`                    | Upstream payload သန့်စင်ရေးစည်းမျဉ်းများ                                            |
| `config/quality/quality-baseline.json`        | မက်ထရစ်မျိုးစုံပါ ratchet baseline (`scripts/quality/check-quality-ratchet.mjs`)    |
| `config/quality/complexity-baseline.json`     | ပုံသေသတ်မှတ်ထားသော ESLint complexity baseline (`check-complexity.mjs`)              |
| `config/quality/duplication-baseline.json`    | ပုံသေသတ်မှတ်ထားသော jscpd duplication baseline (`check-duplication.mjs`)             |
| `config/quality/file-size-baseline.json`      | ပုံသေသတ်မှတ်ထားသော ဖိုင်တစ်ခုချင်းစီ၏ အရွယ်အစား baseline (`check-file-size.mjs`)    |
| `config/quality/test-discovery-baseline.json` | ပုံသေသတ်မှတ်ထားသော orphan-test baseline (`check-test-discovery.mjs`)                |
| `config/quality/dependency-allowlist.json`    | အတည်ပြုထားသော dependency ခွင့်ပြုစာရင်း (`check-deps.mjs`)                          |
| `config/quality/.license-allowlist.json`      | SPDX license ခွင့်ပြုစာရင်း (`check-licenses.mjs`)                                  |
| `config/quality/quality-metrics.json`         | ယာယီစုဆောင်းထားသော မက်ထရစ်များ (`collect-metrics.mjs` က ထုတ်ပေးသည်၊ **gitignored**) |

## `_ideia/`, `_mono_repo/`, `_references/`, `_tasks/` — ပင်မဖွဲ့စည်းပုံပြင်ပ

ရှေ့တွင် underscore ပါသော ဤ directory များတွင် ဖြန့်ချိမှု၌ မပါဝင်သည့် အကြောင်းအရာများကို သိမ်းဆည်းထားသည်-

- **`_ideia/`** — design note များ (defer / notfit / viable အမျိုးအစားများ)
- **`_mono_repo/`** — ယခင် subproject များ (omnirouteCloud၊ omnirouteSite၊ vscode-extension)
- **`_references/`** — ဖွံ့ဖြိုးတိုးတက်ရေးအတွင်း အပြန်အလှန်ကိုးကားရန် သက်ဆိုင်ရာ OSS project များ၏ ဖတ်ရှုရန်သာ clone များ (LiteLLM၊ 9router၊ ClawRouter၊ CLIProxyAPI၊ modelrelay၊ new-api စသည်)
- **`_tasks/`** — release တစ်ခုချင်းစီအလိုက် task ခြေရာခံဖိုင်များ (အလွတ်သဘော)

`npm pack` output တွင် မပါဝင်ပါ။ `.npmignore` ကို ကြည့်ပါ။
