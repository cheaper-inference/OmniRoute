သင်၏ပင်မစခရင် သို့မဟုတ် ဒက်စ်တော့မှ သီးသန့်ဝင်းဒိုးတွင် ၎င်းကိုဖွင့်ရန်အတွက် OmniRoute ဒက်ရှ်ဘုတ်ကို တိုးတက်မှု ဝဘ်အက်ပ်အဖြစ် ထည့်သွင်းပါ။ ထည့်သွင်းထားသောအက်ပ်သည် လမ်းညွှန်မှု၊ ဒက်ရှ်ဘုတ်ဒေတာနှင့် API တောင်းဆိုမှုများအတွက် သင်၏ OmniRoute ဆာဗာသို့ ချိတ်ဆက်မှုတစ်ခု လိုအပ်နေသေးသည်။ သိမ်းဆည်းထားသော တည်ငြိမ်သောပိုင်ဆိုင်မှုများသည် အော့ဖ်လိုင်းဝင်ပေါက် သို့မဟုတ် အော့ဖ်လိုင်းဒက်ရှ်ဘုတ်ကို မပေးဆောင်ပါ။

## PWA ဆိုတာ ဘာလဲ ?

တိုးတက်သောဝဘ်အက်ပ်တစ်ခုသည် အက်ပ်အိုင်ကွန်တစ်ခုနှင့် သီးခြားဝင်းဒိုးတစ်ခုဖြင့် ဝဘ်ဒိုင်ခွက်ကို အသုံးပြုသည်။ တပ်ဆင်ပြီးသည်နှင့် OmniRoute:

- သင့်ပင်မစခရင် သို့မဟုတ် ဒက်စ်တော့မှ စတင်သည်။
- ဘရောက်ဆာ၏ ပုံမှန်လိပ်စာဘားနှင့် တဘ်များမပါဘဲ သီးခြားမုဒ်တွင် ဖွင့်သည်။
- ကက်ရှ်များ ရွေးချယ်ထားသော အငြိမ်ပိုင်ဆိုင်မှုများ
- ပုံတူနှင့် အခင်းအကျင်းများကို ပံ့ပိုးပေးသည်။

## တပ်ဆင်ခြင်း။

အခြားစက်ပစ္စည်းရှိ ဆာဗာတစ်ခုအတွက် HTTPS လိပ်စာကို အသုံးပြုပါ။ ဆာဗာသည် စက်ပစ္စည်းတစ်ခုတည်းတွင် အလုပ်လုပ်သောအခါ၊ `http://localhost:20128` ဘရောက်ဆာထည့်သွင်းနိုင်မှုလိုအပ်ချက်များနှင့်လည်း ကိုက်ညီပါသည်။ ရိုးရိုး `http://YOUR_IP:20128` လိပ်စာသည် ထိုလိုအပ်ချက်များနှင့် မကိုက်ညီပါ။ ထည့်သွင်းမှု မီနူးများနှင့် အချက်ပြမှုများသည် ဘရောက်ဆာနှင့် လည်ပတ်မှုစနစ်ပေါ်တွင် မူတည်သည်။ [MDN၏ PWA တပ်ဆင်မှုလိုအပ်ချက်များကို](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable#https_localhost_or_loopback_are_required) ကြည့်ပါ။

### Android (Chrome)

1. သင်၏ OmniRoute HTTPS လိပ်စာ သို့မဟုတ် `http://localhost:20128` ကို ဖုန်းတစ်ခုတည်းရှိ ဆာဗာတစ်ခုအတွက် ဖွင့်ပါ။
2. ကိုဖွင့်ပါ။**⋮** menu ကိုရွေးပါ။** အက်ပ်ကို ထည့်သွင်းပါ။** သို့မဟုတ်** ပင်မစာမျက်နှာသို့ ထည့်ပါ။** ပူဇော်လျှင်။
3. အချက်ပြချက်ကို အတည်ပြုပါ။
4. ပင်မစခရင်မှ OmniRoute ဖွင့်ပါ။

### iOS (ဆာဖာရီ)

1. Safari တွင် သင်၏ OmniRoute HTTPS လိပ်စာကို ဖွင့်ပါ။
2. နှိပ်ပါ။** မျှဝေပါ။** →** ပင်မစခရင်သို့ ထည့်ပါ။** .
3. အမည်ကို အတည်ပြုပြီး နှိပ်ပါ။** ထည့်ပါ။** .
4. ပင်မစခရင်မှ OmniRoute ဖွင့်ပါ။

### ဒက်စ်တော့ (Chrome / Edge)

1. သင်၏ OmniRoute ဒက်ရှ်ဘုတ်ကိုဖွင့်ပါ။
2. ဘရောင်ဇာ၏ ထည့်သွင်းမှုအိုင်ကွန် သို့မဟုတ် အဆိုပါကို အသုံးပြုပါ။** အက်ပ်ကို ထည့်သွင်းပါ။** ကမ်းလှမ်းလျှင် menu entry ကို။
3. ၎င်း၏ကိုယ်ပိုင်ဝင်းဒိုးတွင် OmniRoute ဖွင့်ရန်အချက်ကိုအတည်ပြုပါ။

## အင်္ဂါရပ်များ

### Standalone Window

မန်နီးဖက်စ်တွင် `display: "standalone"` နှင့် `start_url: "/dashboard"` သတ်မှတ်သည်။ ထည့်သွင်းထားသောအက်ပ်သည် အက်ပ်ဝင်းဒိုးတွင် ဒက်ရှ်ဘုတ်ကိုဖွင့်သည်။ ဘရောက်ဆာနှင့် လည်ပတ်မှုစနစ် ထိန်းချုပ်မှုများ ပေါ်လာနိုင်သေးသည်။ မန်နီးဖက်စ်သည် မျက်နှာပြင်အပြည့်မုဒ်ကို တောင်းဆိုမည်မဟုတ်ပါ။

### သိမ်းဆည်းထားသော ပိုင်ဆိုင်မှုများနှင့် ကွန်ရက်လိုအပ်ချက်များ

[ဝန်ဆောင်မှုလုပ်သားသည်](../../public/sw.js) ရွေးချယ်ထားသည့် မူရင်းအရင်းအမြစ်များကို ကက်ရှ်လုပ်သည်-

| တောင်းဆိုခြင်း သို့မဟုတ် ပိုင်ဆိုင်မှု                        | ဗျူဟာ       | အနေအထိုင်                                                                                                                       |
| ------------------------------------------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------- |
| အချိန်အရင်းအမြစ်များကို ထည့်သွင်းပါ။                          | ကြိုရှ်     | `/`၊ `/manifest.webmanifest`၊ `/icon-512.png` နှင့် `/apple-touch-icon.png` ကို အလုပ်သမားတပ်ဆင်နေစဉ်အတွင်း သိမ်းဆည်းထားသည်။     |
| Next.js တည်ငြိမ်ပိုင်ဆိုင်မှု (`/_next/`)                     | ကွန်ရက်-ပထမ | အောင်မြင်သော တုံ့ပြန်မှုများသည် ကက်ရှ်ကို အပ်ဒိတ်လုပ်ပါ။ ကွန်ရက် အမှားတစ်ခုသည် ရှိပြီးသား ကက်ရှ် တုံ့ပြန်မှုသို့ ပြန်သွားပါသည်။ |
| အခြားသော static CSS၊ JS၊ ပုံများနှင့် ဖောင့်များ              | ကက်ရှ်-ပထမ  | ရှိပြီးသား ကက်ရှ် တုံ့ပြန်မှုကို ပြန်သုံးသည်။ အောင်မြင်သော ကွန်ရက်တုံ့ပြန်မှုများကို လွဲချော်မှုတွင် သိမ်းဆည်းထားသည်။           |
| စာမျက်နှာလမ်းညွှန်                                            | ရှောင်ကွင်း | ဘရောက်ဆာသည် စာမျက်နှာကို တိုက်ရိုက်ရယူသည်။ အော့ဖ်လိုင်း တုံ့ပြန်မှုကို ဆောင်ရွက်ပေးခြင်းမရှိပါ။                                 |
| API၊ ဒက်ရှ်ဘုတ်နှင့် စစ်မှန်ကြောင်းအထောက်အထား လမ်းကြောင်းများ | ရှောင်ကွင်း | အလုပ်သမားသည် ဤတောင်းဆိုချက်များကို ကြားဖြတ် သို့မဟုတ် ကက်ရှ်မလုပ်ပါ။                                                            |
| အငြိမ်မဟုတ်သော အခြားတောင်းဆိုမှုများ                          | ကွန်ရက်     | ကက်ရှ်ရှာဖွေခြင်း သို့မဟုတ် သိုလှောင်မှု မရှိပါ။                                                                                |

ဖယ်ထုတ်ထားသောလမ်းကြောင်းများသည် `/api`, `/a2a`, `/dashboard`, `/v1`, `/v1beta`, `/models`, `/chat`, `/responses`, `/codex`, `/callback` နှင့် `/login`၊ လမ်းကြောင်းနယ်နိမိတ်များတွင် case-insensitively တူညီပါသည်။ မူရင်းနှင့် GET မဟုတ်သော တောင်းဆိုချက်များသည်လည်း အလုပ်သမားကို ကျော်ဖြတ်နိုင်သည်။

### ချိတ်ဆက်မှုစာမျက်နှာ

`/offline` စာမျက်နှာသည် ချိတ်ဆက်မှုမက်ဆေ့ဂျ်၊ online/offline ညွှန်ပြချက်တစ်ခု၊ a** ချိတ်ဆက်မှုကို ပြန်ကြိုးစားပါ။** ခလုတ်နှင့် အခြေအနေစာမျက်နှာသို့ လင့်ခ်တစ်ခု။ ၎င်းသည်** pre-cached မဟုတ်ပါ။** ဝန်ဆောင်မှုဝန်ထမ်းလုပ်တယ်။** မဟုတ်ဘူး** မအောင်မြင်သော လမ်းကြောင်းများကို ၎င်းထံသို့ ပြန်ညွှန်းပါ။ ၎င်း၏တည်ရှိမှုသည် ဆာဗာမပါဘဲ စာမျက်နှာအသစ်များကို အသုံးပြုနိုင်စေမည်မဟုတ်ပေ။

### အက်ပ်အိုင်ကွန်များ

မန်နီးဖက်စ်တွင် ဤ PNG သင်္ကေတများကို ကြော်ငြာသည်-

| ဖို                    | အရွယ်အစား | သုံးပါ။                            |
| ---------------------- | --------- | ---------------------------------- |
| `icon-192.png`         | 192×192   | အထွေထွေအက်ပ်အိုင်ကွန်              |
| `icon-512.png`         | 512×512   | အထွေထွေနှင့် Maskable အက်ပ်သင်္ကေတ |
| `apple-touch-icon.png` | 180×180   | Apple ပင်မမျက်နှာပြင် အိုင်ကွန်    |

ဘရောက်ဆာသည် တပ်ဆင်မှုပစ်မှတ်အတွက် သင့်လျော်သော အိုင်ကွန်ကို ရွေးချယ်သည်။

### အလိုအလျောက်မှတ်ပုံတင်ခြင်း။

ဘရောက်ဆာသည် ဝန်ဆောင်မှုလုပ်သားများကို ပံ့ပိုးပေးသောအခါ`PwaRegister` ထုတ်လုပ်မှုတွင် အလုပ်သမားကို မှတ်ပုံတင်သည်။ ဖွံ့ဖြိုးတိုးတက်မှုမုဒ်သည် အလုပ်သမားများကို စာရင်းမသွင်းဘဲ ပြန်လည်စတင်ခြင်းကို အနှောင့်အယှက်ဖြစ်စေသော အဟောင်းပစ္စည်းများကို ရှောင်ရှားရန် ကက်ရှ်များကို ရှင်းလင်းစေသည်။ ထည့်သွင်းမှုသတိပေးချက်များသည် ဘရောက်ဆာ ဆုံးဖြတ်ချက်တစ်ခုအဖြစ် ရှိနေပါသည်။

## နည်းပညာဗိသုကာ

### ဝဘ်အက်ပ် မန်နီးဖက်စ်

Next.js `/manifest.webmanifest` [`src/app/manifest.ts`](../../src/app/manifest.ts) မှထုတ်ပေးသည်။ ၎င်း၏ အဓိက ဆက်တင်များမှာ-

| ဆက်တင်                            | တန်ဖိုး                                   |
| --------------------------------- | ----------------------------------------- |
| `short_name`                      | `OmniRoute`                               |
| `start_url`                       | `/dashboard`                              |
| `scope`                           | `/`                                       |
| `display`                         | `standalone`                              |
| `orientation`                     | `any`                                     |
| နောက်ခံနှင့် အပြင်အဆင် အရောင်များ | `PWA_THEME_COLORS` မှ မူရင်းအလင်း palette |

မန်နီးဖက်စ်၏အမည်နှင့် ဖော်ပြချက်သည် ထိုအရင်းအမြစ်ဖိုင်ရှိ တည်ငြိမ်တန်ဖိုးများဖြစ်သည်။ ထည့်သွင်းထားသော မန်နီးဖက်စ်သည် လည်ပတ်မှုတိုင်းတွင် ဥပမာ-အမည် ဆက်တင် သို့မဟုတ် တက်ကြွသော ပျဉ်ချပ်ကို မလိုက်နာပါ။

### ဝန်ဆောင်မှုဝန်ထမ်း

[`public/sw.js`](../../public/sw.js) တွင် ဝန်ဆောင်မှု-လုပ်သား မူဘောင် မှီခိုမှု မရှိပါ။

- **ထည့်သွင်းပါ-** အထက်တွင်ဖော်ပြထားသော အရင်းအမြစ်လေးခုကို ကြိုတင်ကက်ရှ်လုပ်ပြီး အလုပ်သမားအသစ်ကို အသက်သွင်းပါ။
- **အသက်သွင်းရန်-** ကက်ရှ် မျိုးဆက်ဟောင်းများကို ဖယ်ရှားပြီး သုံးစွဲသူများကို တောင်းဆိုသည်။
- **ထုတ်ယူမှု-** အပေါ်က static-asset ဗျူဟာများနှင့် လမ်းကြောင်းဖယ်ထုတ်မှုများကို အသုံးချပါ။
- **ဗားရှင်းထုတ်ခြင်း-** အရင်းအမြစ် ကက်ရှ် အမည်မှာ `omniroute-pwa-v3` ဖြစ်သည် . ထုတ်လုပ်မှုတည်ဆောက်မှုသည် ကက်ရှ်အထောက်အထားကို တံဆိပ်တုံးထုသည်။
- **အကြောင်းကြားချက်များ-** ဝင်လာသော `push` ဖြစ်ရပ်များကို ကိုင်တွယ်ပြီး အကြောင်းကြားချက်တစ်ခုကို နှိပ်သည့်အခါ ဝင်းဒိုးတစ်ခုကို အာရုံစိုက် သို့မဟုတ် ဖွင့်ပေးသည်။

Push event handlers တစ်ခုတည်းသည် တက်ကြွသော push subscription သို့မဟုတ် configured server delivery ကို မတည်ထောင်ပါ။ PWA ထည့်သွင်းထားသောကြောင့် အကြောင်းကြားချက်များကို ဖွင့်ထားသည်ဟု မယူဆပါနှင့်။

### Layout မက်တာဒေတာနှင့် မှတ်ပုံတင်ခြင်း။

[`src/app/layout.tsx`](../../src/app/layout.tsx) manifest လင့်ခ်၊ Apple သီးသန့် မက်တာဒေတာ၊ အပြင်အဆင် အရောင်များနှင့် `viewport-fit: cover` ကို ပံ့ပိုးပေးသည်။ စာမျက်နှာခေါင်းစဉ်နှင့် Apple ဝဘ်အက်ပ် ခေါင်းစဉ်သည် ဥပမာအမည်ကို အသုံးပြုသည်။ တိုက်ရိုက်ဘရောက်ဆာ ဆောင်ပုဒ်အရောင်သည် ပျဉ်ချပ်ကို လိုက်နာသည်။ ထည့်သွင်းမှုမန်နီးဖက်စ်သည် မူရင်းအလင်းအရောင်ကို အသုံးပြုသည်။

[`PwaRegister`](../../src/shared/components/PwaRegister.tsx) client ပေါ်တွင်အလုပ်လုပ်ပြီး `/sw.js` ၎င်း၏ URL တွင်တည်ဆောက်သော ID ဖြင့်စာရင်းသွင်းသည်။ ၎င်းသည် မကိုက်ညီသော ကက်ရှ်မျိုးဆက်များကို ရှာဖွေတွေ့ရှိပြီး လုပ်သားကို ပြန်လည်သတ်မှတ်ကာ အဟောင်းထည့်သွင်းမှုမှ ပြန်လည်ရယူရန် တစ်ကြိမ် ပြန်လည်စတင်နိုင်သည်။ မှတ်ပုံတင်ခြင်း မအောင်မြင်ပါက ဒက်ရှ်ဘုတ်ကို မပိတ်ဆို့ပါ။

## Termux (Android) ဖြင့် အသုံးပြုပါ

1. Termux- `npx -y omniroute@latest` တွင် OmniRoute စတင်ပါ။
2. ဖုန်းတစ်ခုတည်းတွင် Chrome ကိုဖွင့်ပါ- `http://localhost:20128`.
3. ဘရောက်ဆာ၏ထည့်သွင်းမှုမီနူးမှတဆင့် PWA ထည့်သွင်းပါ။
4. ဒက်ရှ်ဘုတ်ကို အသုံးပြုနေစဉ် Termux ဆာဗာကို လည်ပတ်နေပါစေ။

ဖုန်းသည် တံခါးပေါက်နှင့် ၎င်း၏ ဒက်ရှ်ဘုတ် နှစ်ခုလုံးကို လက်ခံဆောင်ရွက်ပေးသည်။ အဝေးမှ AI ဝန်ဆောင်မှုပေးသူများထံ တောင်းဆိုချက်များသည် ကွန်ရက်ဝင်ရောက်ခွင့် လိုအပ်နေသေးသည်။ စနစ်ထည့်သွင်းခြင်းနှင့် Android လုပ်ငန်းစဉ်တစ်သက်တာထည့်သွင်းစဉ်းစားခြင်းများအတွက် [Termux လမ်းညွှန်ကို](TERMUX_GUIDE.md) ကြည့်ပါ။

## အခြားစက်များမှ အသုံးပြုပါ။

ဖုန်း၊ တက်ဘလက် သို့မဟုတ် ဒက်စ်တော့တွင် ဆာဗာ၏ HTTPS လိပ်စာကိုဖွင့်ပါ၊ ထို့နောက် အဆိုပါဘရောက်ဆာ၏ ထည့်သွင်းမှုလုပ်ငန်းစဉ်ကို လိုက်နာပါ။ ဆာဗာသည် စက်တစ်ခုစီမှ လက်လှမ်းမီနိုင်ဆဲဖြစ်ရမည်။ အဝေးမှဝင်ရောက်ခွင့်ရွေးချယ်စရာများအတွက် [ဥမင်လမ်းညွှန်ကို](../ops/TUNNELS_GUIDE.md) ကြည့်ပါ။

## စိတ်ကြိုက်လုပ်ပါ။

### ဥပမာအမည်

ဟိ** ဥပမာအမည်** စာမျက်နှာခေါင်းစဉ်နှင့် Apple ဝဘ်အက်ပ်ခေါင်းစဉ်အပါအဝင် ဒက်ရှ်ဘုတ် မက်တာဒေတာကို ပြောင်းလဲပါသည်။ ထုတ်ပေးထားသော မန်နီးဖက်စ်သည် တည်ငြိမ်သောအမည်ကို အသုံးပြုထားသောကြောင့် ဤဆက်တင်တွင် ထည့်သွင်းပြီးသားအက်ပ်ကို အမည်ပြောင်းထားကြောင်း အာမမခံနိုင်ပါ။

### စိတ်ကြိုက် Favicon

စိတ်ကြိုက် favicon တစ်ခုသည် browser favicon ကိုပြောင်းလဲသည်။ ထည့်သွင်းသည့်မန်နီးဖက်စ်သည် အထက်ဖော်ပြပါ PNG ဖိုင်များကို ဆက်လက်ကြော်ငြာနေသေးသည်။ Favicon ကိုပြောင်းလဲခြင်းသည် ထိုပင်မစခရင်အိုင်ကွန်များကို အစားထိုးမည်မဟုတ်ပါ။

## ကန့်သတ်ချက်များ

- **ဆာဗာချိတ်ဆက်မှု လိုအပ်သည်-** စာမျက်နှာလမ်းညွှန်ခြင်း၊ ဒက်ရှ်ဘုတ်အခြေအနေ နှင့် API တောင်းဆိုချက်များသည် အော့ဖ်လိုင်း တုံ့ပြန်မှု မရှိပါ။
- **နောက်ခံစင့်ခ်မရှိပါ-** အော့ဖ်လိုင်းလုပ်ဆောင်ချက်များကို ပြန်လည်ပြသရန်အတွက် တန်းစီမထားပါ။
- **ဘရောက်ဆာ ကွာခြားချက်များ-** တပ်ဆင်မှုမီနူးများ၊ ဝင်းဒိုးတင်ပြချက်နှင့် အကြောင်းကြားချက် ပံ့ပိုးမှုတို့သည် ပလက်ဖောင်းအလိုက် ကွဲပြားသည်။
- **API တုံ့ပြန်မှု ကက်ရှ် မရှိပါ-** အလုပ်သမားသည် API၊ ဒက်ရှ်ဘုတ်နှင့် အထောက်အထားစိစစ်ခြင်းလမ်းကြောင်းများကို ဖယ်ထုတ်ထားသည်။
- **တည်ငြိမ်ထည့်သွင်းမှုသင်္ကေတများ-** ထိုအိုင်ကွန်များကို အပ်ဒိတ်လုပ်ခြင်းသည် ကြော်ငြာထားသောပိုင်ဆိုင်မှုများကို ပြောင်းလဲရန်လိုအပ်ပါသည်။ ဘရောက်ဆာများသည် ထည့်သွင်းထားသော မက်တာဒေတာကို ထိန်းသိမ်းထားနိုင်သည်။
