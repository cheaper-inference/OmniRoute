## Free Tiers ဆိုတာ ဘာလဲ။

AI ပံ့ပိုးပေးသူအများအပြားသည်အချို့သောပုံစံကိုကမ်းလှမ်းသည်။** အခမဲ့ဝင်ရောက်ခွင့်** . ဝန်ဆောင်မှုပေးသူပေါ် မူတည်၍ ၎င်းသည် အထောက်အထားမရှိသော အဆုံးမှတ်၊ ထပ်တလဲလဲ ခွဲတမ်း၊ နှုန်းထား-အကန့်အသတ်မရှိ ဝင်ရောက်ခွင့်၊ အကောင့်ဖွင့်ခွင့်၊ လူကိုယ်တိုင် ခွင့်ပြုချက် သို့မဟုတ် ယာယီပရိုမိုးရှင်းတစ်ခုဟု ဆိုလိုနိုင်သည်။ အချို့သောရွေးချယ်မှုများသည် အကောင့်တစ်ခု၊ API သော့၊ ခရက်ဒစ်ကတ်၊ KYC သို့မဟုတ် ဝန်ဆောင်မှုပေးသူ၏ သီးခြားစည်းမျဉ်းများကို လက်ခံမှု လိုအပ်သည်။

OmniRoute** စုစည်းမှု** ချိတ်ဆက်မှုများကို အဆုံးမှတ်တစ်ခုသို့ ပြင်ဆင်သတ်မှတ်ထားသည်။ အကောင့်တစ်ခုလိုအပ်သော ဝန်ဆောင်မှုပေးသူတိုင်းအတွက် သီးခြားအကောင့်ဖွင့်ပါသေးသည်။ ထိုအကောင့်များကို ချိတ်ဆက်ပြီး အရည်အချင်းပြည့်မီသော ပစ်မှတ်များကြားတွင် လမ်းကြောင်းပြောင်းရန်အတွက် `model: "auto"` အသုံးပြုပါ။ အသစ်တပ်ဆင်မှုတစ်ခုတွင် အကျုံးဝင်သောသော့မဲ့ပစ်မှတ်မရှိနိုင်ပါ။ OmniRoute ကိုထည့်သွင်းခြင်းတစ်ခုတည်းသည် အောင်မြင်သော ချတ်တုံ့ပြန်မှုကို အာမမခံနိုင်ပါ။

## Free Tiers တွေကို ဘယ်လိုစုမလဲ။

OmniRoute ၏ မှော်ဆန်သည်** အလွတ်တန်းများ တန်းစီခြင်း။** . ဝန်ဆောင်မှုပေးသူတစ်ဦးကို အားကိုးမည့်အစား သင်သည် အခမဲ့ဝန်ဆောင်မှုပေးသူအများအပြားကို ချိတ်ဆက်ပြီး တောင်းဆိုချက်တစ်ခုစီအတွက် အကောင်းဆုံးတစ်ခုကို OmniRoute အလိုအလျောက်ရွေးချယ်ခွင့်ပေးလိုက်ပါ။

### ဥပမာ- ပိုမိုကျယ်ပြန့်သော အခမဲ့အဆင့် လွှမ်းခြုံမှု

ခွဲတမ်းတစ်ခုတည်းအပေါ် မှီခိုမှုလျှော့ချရန် ဝန်ဆောင်မှုပေးသူအများအပြားကို ချိတ်ဆက်ပါ-

1. **Gemini** — ထပ်တလဲလဲ API-ကီးခွဲတမ်း
2. **Groq** — ထပ်တလဲလဲ API-ကီးခွဲတမ်း
3. **ဝတ်မှုန်ကူးခြင်း။** — သော့မဲ့၊ နှုန်းထား-ကန့်သတ်ဝင်ရောက်ခွင့်
4. **LongCat** — တစ်ကြိမ် အကောင့်ဖွင့်ခြင်း ထောက်ပံ့ကြေး ( KYC လိုအပ်သည်)

ထို့နောက် `model: "auto"` နှင့် OmniRoute သုံးပါ။

- အဆင့်အမြင့်ဆုံး သတ်မှတ်ချက်ပြည့်မီသော ချိတ်ဆက်မှုကို ဦးစွာ စမ်းသုံးကြည့်ပါ။
- ၎င်း၏ခွဲတမ်း သို့မဟုတ် ကျန်းမာရေးစစ်ဆေးခြင်း မအောင်မြင်ပါက → နောက်စီစဉ်ထားသော ဝန်ဆောင်မှုပေးသူကို စမ်းကြည့်ပါ။
- သော့မဲ့ဝန်ဆောင်မှုပေးသူ မရရှိနိုင်ပါက → ကျန်ရှိသောပစ်မှတ်များကို ဆက်လက်လုပ်ဆောင်ပါ။
- အကယ်၍ အရည်အချင်းပြည့်မီသော ချိတ်ဆက်မှု မအောင်မြင်ပါက → အမှားတစ်ခု ပြန်လာပါ။ အကောင့်ဖွင့်ခြင်း ခရက်ဒစ်များသည် တရားဝင် ရရှိနိုင်ချိန်တွင်သာ အသုံးပြုနိုင်သည်။

**ရလဒ်** : အကန့်အသတ်မရှိ စွမ်းရည်၏ အာမခံချက် မဟုတ်ဘဲ အလိုအလျောက် တုံ့ပြန်မှု — ဖြင့် ပိုမိုကျယ်ပြန့်သော အခမဲ့အဆင့် လွှမ်းခြုံမှု။

## အခမဲ့ဝန်ဆောင်မှုပေးသူများကို ချိတ်ဆက်နည်း

### အဆင့် 1: Dashboard ကိုဖွင့်ပါ။

သင်၏ဘရောက်ဆာရှိ `http://localhost:20128` သို့သွားပါ။

### အဆင့် 2- ဝန်ဆောင်မှုပေးသူများထံ သွားပါ။

နှိပ်ပါ။** ပံ့ပိုးပေးသည်။** sidebar ထဲမှာ။

### အဆင့် 3: Add Provider ကိုနှိပ်ပါ။

ကိုနှိပ်ပါ။**+ Add Provider** ခလုတ်

### အဆင့် 4: အခမဲ့ပံ့ပိုးပေးသူကိုရွေးချယ်ပါ။

ကတ်တလောက်ကို လှန်ကြည့်ပြီး ဝန်ဆောင်မှုပေးသူတိုင်း၏ လက်ရှိ `hasFree`၊ auth၊ ခွဲတမ်း၊ ကိုယ်ရေးကိုယ်တာနှင့် ToS မက်တာဒေတာကို စစ်ဆေးပါ။ ဝန်ဆောင်မှုပေးကတ်နှင့် [အခမဲ့အဆင့် အကိုးအကားများသည်](../reference/FREE_TIERS.md) ထပ်တလဲလဲဖြစ်နေသော ရေကူးကန်များ၊ uncapped/keyless ဝင်ရောက်မှု၊ အကောင့်ဖွင့်ခြင်း ခရက်ဒစ်များ၊ ဆက်မလုပ်တော့သည့် ထည့်သွင်းမှုများနှင့် အန္တရာယ်ပိုများသော အရင်းအမြစ်များကို ခွဲခြားထားသည်။

### အဆင့် 5: Connect ကိုနှိပ်ပါ။

`NOAUTH` ပံ့ပိုးပေးသူအတွက်၊ OmniRoute အထက်စီးကြောင်းအထောက်အထားကို မတောင်းဆိုပါ။ ၎င်းသည် အထက်စီးကြောင်းမှ ပြင်ပဖောက်သည်များကို လက်ခံခြင်း သို့မဟုတ် ရရှိနိုင်သော စွမ်းရည်ရှိကြောင်း အာမမခံနိုင်ပါ။ OAuth နှင့် API သော့ဝန်ဆောင်မှုပေးသူများသည် ၎င်းတို့၏ မှတ်တမ်းပြုစုထားသော အကောင့်စီးဆင်းမှုမှတစ်ဆင့် ချိတ်ဆက်ရပါမည်။ သင့်ဖောက်သည်သည် ဖန်တီးထားသည့် OmniRoute API သော့ကို အသုံးပြုဆဲဖြစ်သည်။** ဒက်ရှ်ဘုတ် → API သော့များ** Router စစ်မှန်ကြောင်းအထောက်အထားပြခြင်းကို ဖွင့်ထားသောအခါ (ဖန်တီးမှုတွင် တစ်ကြိမ်သာပြသသည်)။

### အဆင့် 6: ထပ်လုပ်ပါ။

သင့်အသုံးပြုမှုကိစ္စနှင့် ကိုက်ညီသော စည်းကမ်းချက်များနှင့် ကိုယ်ရေးကိုယ်တာမော်ဒယ်လ်များစွာရှိသည့် ဝန်ဆောင်မှုပေးသူများကို ချိတ်ဆက်ပါ။

## dsh "ကျွန်ုပ်တို့၏အခမဲ့မော်ဒယ်" မှဆင်းသက်လာ

dsh အေးဂျင့်လက်ခံသူအတွက် [dsh-ကျွန်ုပ်တို့၏-အခမဲ့-မော်ဒယ်](https://github.com/Ebony-Vinyl/dsh-our-free-model) ပလပ်အင်သည် အထက်ရေစီးကြောင်းနှစ်ခုသို့ ရောက်ရှိသည်။ OmniRoute တစ်ခုစီအတွက် ပံ့ပိုးပေးသူရှိပြီးသားဖြစ်သော်လည်း ၎င်းတို့အနက်မှ တစ်ခုသာ OmniRoute ရှိ အခမဲ့လမ်းကြောင်းဖြစ်သည်။

| Plugin လမ်းသွား | ရေဆန်                                          | OmniRoute ပံ့ပိုးပေးသူ      | OmniRoute မှာ အခမဲ့လား။ | ချိတ်ဆက်နည်း                                                                             |

| ကီလိုချန်နယ်    | Kilo AI တံခါးပေါက် (`api.kilo.ai/api/gateway`) | `kilo-gateway` (alias `kg`) | ဟုတ်ကဲ့                 | API သော့ကို ချန်လှပ်ထားနိုင်သည်- ဂိတ်ဝ၏အခမဲ့ရေကူးကန်ကို အသုံးပြုရန် ၎င်းကို ဗလာထားထားပါ။ |

**ကီလို။** အခမဲ့ရေကူးကန်ကို `kilo-gateway/<model>` သို့မဟုတ် `kg/<model>`၊ ဥပမာ `kg/kilo-auto/free` (Kilo ၏ အခမဲ့ အော်တို-ရောက်တာ) သို့မဟုတ် ဂိတ်ဝေး၏ `:free` မော်ဒယ်များထဲမှ တစ်ခုကို ခေါ်ပါ။ အခမဲ့အစုအလှည့်; `kilo-gateway` OmniRoute၏ built-in စာရင်းတွင်မပါသော မော်ဒယ်အိုင်ဒီများကို ဖြတ်သန်းသွားသည်၊ ထို့ကြောင့် ယနေ့ တံခါးပေါက်စာရင်းများတွင် မော်ဒယ်တစ်ခုကို ၎င်းမပါဝင်မီ ကတ်တလောက်တွင် ခေါ်နိုင်သည်။ Kilo ၏ အခမဲ့ မော်ဒယ်ကတ်များက အချက်ပြမှုများကို အထက်စီးကြောင်းဝန်ဆောင်မှုပေးသူမှ လော့ဂ်ယူထားနိုင်ပြီး ၎င်း၏ဝန်ဆောင်မှုများကို ပိုမိုကောင်းမွန်စေရန်အတွက် အသုံးပြုထားသောကြောင့် အရေးကြီးသောဒေတာကို မပို့ပါနှင့်။

**OpenCode** ပလပ်အင်၏ အခမဲ့လမ်းကြောင်းသည် OpenCode၏ သော့မပါဘဲ ကမ်းလှမ်းချက်ဖြစ်သည်။ OmniRoute အဆိုပါကမ်းလှမ်းချက်ကို အခမဲ့ဝင်ရောက်ခွင့်အဖြစ် မပေးဆောင်ထားပေ။

- OmniRoute၏သော့မဲ့ OpenCode ဝန်ဆောင်မှုပေးသူကို OpenCode၏အော်ပရေတာ၏တောင်းဆိုချက်အရ ဖယ်ရှားခဲ့သည် ( [ဖယ်ရှားထားသောပံ့ပိုးပေးသူများကို](../reference/REMOVED_PROVIDERS.md) ကြည့်ပါ)။
- OpenCode၏အ [ဆုံးမှတ်စာရွက်စာတမ်းသည်](https://opencode.ai/v2/docs/console/models/#endpoints) ၎င်း၏အခမဲ့ချတ်ကမ်းလှမ်းချက်များကို OpenCode၏ကိုယ်ပိုင်ဖောက်သည်နှင့်ချိတ်ဆက်ထားသောကြောင့် OmniRoute ၎င်းတို့အား အခမဲ့အဖြစ်ရေတွက်ခြင်း သို့မဟုတ် အမှတ်အသားပြုခြင်းမဟုတ်ပါ။

`deepseek-v4.1-flash-free`၊ `mimo-v2.6-flash-free` နှင့် `nemotron-3.5-lightning-free` ကဲ့သို့သော plugin တွင်ပြသထားသော model ids များသည် `opencode-zen` catalog တွင်ရှိသည်။ သင့် OpenCode အကောင့်၏ စည်းကမ်းချက်များအောက်တွင် ၎င်းတို့ကို အသုံးပြုရန်အတွက် `opencode-zen` သင့်ကိုယ်ပိုင် OpenCode သော့ဖြင့် ချိတ်ဆက်ပါ။

**ပလပ်အင်၏ ဒေသတွင်း ဆိပ်ကမ်း။** ပလပ်အင်သည် ၎င်း၏မော်ဒယ်များကို ဒေသတွင်း OpenAI-သဟဇာတဖြစ်သော ပို့တ် (မူလ `18899`) တွင် ဖော်ထုတ်နိုင်သည်။ အဆိုပါ အဆုံးမှတ်ကို [စိတ်ကြိုက် OpenAI-သဟဇာတဖြစ်သော ဝန်ဆောင်မှုပေးသူ](../guides/USER_GUIDE.md#custom-openai-compatible-providers) အဖြစ် ပေါင်းထည့်နိုင်သော်လည်း OmniRoute ပလပ်အင်ကို ထည့်သွင်းခြင်း၊ စတင်ခြင်း သို့မဟုတ် အပ်ဒိတ်မလုပ်ခြင်းတို့ကြောင့် တောင်းဆိုချက်တစ်ခုစီတိုင်းတွင် မည်သည့်ရေစီးကြောင်းကို ဆောင်ရွက်ပေးသည်ကို ပလပ်အင်က ဆုံးဖြတ်ပေးပါသည်။ အထက်ဖော်ပြပါ OpenCode န့်သတ်ချက်များသည် ကလိုင်းယင့် တောင်းဆိုချက်ပေးပို့သည့်တိုင်း OpenCode၏ကမ်းလှမ်းချက်တွင် သက်ရောက်သည်။

## Catalog ကို မှန်ကန်စွာဖတ်ပါ။

- `NOAUTH` ဆိုသည်မှာ OmniRoute ပံ့ပိုးပေးသူအထောက်အထားအတွက် သင့်အား မတောင်းဆိုပါ။ ၎င်းသည် အလုပ်ချိန်၊ ကိုယ်ရေးကိုယ်တာ သို့မဟုတ် အကန့်အသတ်မဲ့စွမ်းရည်ကို အာမခံချက်မရှိပါ။
- `hasFree` သည် ရှာဖွေမှု မက်တာဒေတာဖြစ်သည်။ ၎င်းသည် ထပ်တလဲလဲခွဲတမ်း၊ သော့မဲ့ဝင်ရောက်ခွင့်၊ အကောင့်ဖွင့်ခရက်ဒစ်၊ ခွင့်ပြုချက်အစီအစဉ် သို့မဟုတ် ပရိုမိုးရှင်းကို ကိုယ်စားပြုနိုင်သည်။
- `recurring-uncapped` ဆိုသည်မှာ ထုတ်ဝေထားသော တိုကင်မျက်နှာကျက်ကို မရနိုင်ပါ။ နှုန်းထားနှင့် တူညီသော ကန့်သတ်ချက်များသည် သက်ရောက်ဆဲဖြစ်သည်။
- အကောင့်ဖွင့်ပေးသော ထောက်ပံ့ကြေးကို သုံးစွဲပြီးနောက်`one-time-initial` ပြန်လည်ဖြစ်ပွားခြင်းမရှိပါ။
- `tos: avoid` ပံ့ပိုးပေးသူများကို ပုံသေ (`excludeTosAvoid`) အလိုအလျောက်လမ်းကြောင်းပေးခြင်းမှ ဖယ်ထုတ်ထားသည်။ အကောင့်တစ်ခုချိတ်ဆက်ခြင်းသည် ဤစစ်ထုတ်မှုကို ရှောင်လွှဲ၍မရပါ။ မည်သည့်အော်ပရေတာမဆို ဝန်ဆောင်မှုပေးသူစည်းမျဉ်းများနှင့် အကောင့်အန္တရာယ်ကို ပြန်လည်သုံးသပ်ခြင်းတို့ကို လိုက်နာသင့်သည်။
- `discontinued` ဟု အမှတ်အသားပြုထားသည့် စာတမ်းများသည် သမိုင်းဝင်အထောက်အထားများ ကျန်ရှိနေသေးပြီး လက်ရှိတွင် အခမဲ့အဖြစ် မတင်ပြရပါ။

## OmniRoute အခမဲ့အဆင့်များကို ပိုကောင်းအောင်ပြုလုပ်နည်း

### 1. အလိုအလျောက် လှည့်ပြန်ခြင်း။

အခမဲ့ဝန်ဆောင်မှုပေးသူတစ်ဦးသည် အလုပ်များနေပါက သို့မဟုတ် အလုပ်များနေပါက OmniRoute နောက်တစ်ခုအား အလိုအလျောက်ကြိုးစားသည်။ မင်းဘာမှလုပ်စရာမလိုဘူး။

### 2. Smart Routing

OmniRoute ရွေးတယ်။** အကောင်းဆုံးအခမဲ့ပံ့ပိုးပေး** တောင်းဆိုမှုတစ်ခုစီအတွက်-

- Speed — ဘယ်ဝန်ဆောင်မှုက အခုအမြန်ဆုံးလဲ။
- အရည်အသွေး — ဤလုပ်ငန်းအတွက် မည်သည့်ဝန်ဆောင်မှုပေးသူသည် အကောင်းဆုံးဖြစ်သနည်း။
- စွမ်းဆောင်ရည် — ဘယ်ဝန်ဆောင်မှုပေးသူမှာ ခွဲတမ်းကျန်ရှိမလဲ။

### 3. တိုကင်ချွေတာရေး

OmniRoute၏ ဖိသိပ်မှုပိုက်လိုင်းသည် သတ်မှတ်ချက်ပြည့်မီသော အချက်ပြမှုနှင့် ကိရိယာ-အထွက်တိုကင်များကို လျှော့ချနိုင်သည်။ အမှန်တကယ် စုဆောင်းငွေသည် အကြောင်းအရာ၊ ရွေးချယ်ထားသော အင်ဂျင်များ၊ ဝန်ဆောင်မှုပေးသူ စာရင်းအင်းနှင့် သစ္စာရှိမှု ဆက်တင်များပေါ်တွင် မူတည်ပါသည်။ compression သည် ပံ့ပိုးပေးသူ ခွဲတမ်းတိုင်းကို ပုံသေပမာဏဖြင့် မမြှောက်ပါ။

### 4. Multi-အကောင့်ပံ့ပိုးမှု

ဝန်ဆောင်မှုပေးသူစည်းမျဉ်းများသည် အကောင့်အများအပြား သို့မဟုတ် အထောက်အထားများကို ခွင့်ပြုပါက၊ OmniRoute ချိတ်ဆက်မှုတစ်ခုစီကို သီးခြားလမ်းကြောင်းသတ်မှတ်ပေးသူအဖြစ် သတ်မှတ်နိုင်သည်။ ဝန်ဆောင်မှုပေးသူ၏ခွဲတမ်း သို့မဟုတ် အသုံးပြုခွင့်မူဝါဒကို ရှောင်ရှားရန် အပိုအကောင့်များ မဖန်တီးပါနှင့်။

## ဘုံမေးခွန်းများ

### "ဒါက တကယ်အလကားလား?"

ကတ်တလောက်သည် ဝန်ဆောင်မှုပေးသူမှထုတ်ဝေသော စည်းကမ်းချက်များနှင့် ပရောဂျက်သုတေသနကို မှတ်တမ်းတင်ထားသော်လည်း ကမ်းလှမ်းချက်များသည် ပြောင်းလဲနိုင်သည်။ အသုံးမပြုမီ ဝန်ဆောင်မှုပေးသူ၏ လက်ရှိစျေးနှုန်း၊ ခွဲတမ်း၊ ကိုယ်ရေးကိုယ်တာမူဝါဒနှင့် အရည်အချင်းပြည့်မီမှုကို စစ်ဆေးပါ။

### "အလကားအဆင့်တွေ ကုန်သွားမှာလား။"

ဝန်ဆောင်မှုပေးသူတိုင်းသည် အဆင့်ကန့်သတ်ချက်၊ မော်ဒယ်များကို ပြောင်းလဲခြင်း၊ အသုံးပြုခွင့်ကို ဆိုင်းငံ့ထားနိုင်သည် သို့မဟုတ် အော့ဖ်လိုင်းသွားနိုင်သည်။ များစွာသောချိတ်ဆက်မှုများသည် နောက်ပြန်အကျုံးဝင်မှုကို ပိုမိုကောင်းမွန်စေသော်လည်း ရရှိနိုင်သော အခမဲ့လမ်းကြောင်းကို အာမမခံနိုင်ပါ။

### "ထုတ်လုပ်မှုအတွက် အခမဲ့ဝန်ဆောင်မှုပေးသူများကို ကျွန်ုပ်အသုံးပြုနိုင်ပါသလား။

ဝန်ဆောင်မှုပေးသူ၏ SLA၊ ဒေတာကိုင်တွယ်မှု၊ ကန့်သတ်ချက်များနှင့် စည်းကမ်းချက်များသည် သင့်ထုတ်လုပ်မှုလိုအပ်ချက်များနှင့် ကိုက်ညီမှသာ။ အရေးကြီးသော အလုပ်တာဝန်များကို စောင့်ကြည့်ပြီး စာချုပ်အရ သင့်လျော်သော နောက်ပြန်ဆုတ်မှု ရှိသင့်သည်။

### "ဘာဖမ်းတာလဲ။"

အရောင်းအ၀ယ်များတွင် တင်းကျပ်သောကန့်သတ်ချက်များ၊ စောင့်ဆိုင်းစာရင်းများ၊ KYC၊ ခရက်ဒစ်ကတ်အတည်ပြုခြင်း၊ လမ်းညွှန်ချက်များဆိုင်ရာ လေ့ကျင့်မှု၊ အားနည်းသောကိုယ်ရေးကိုယ်တာ၊ SLA မရှိ၊ မော်ဒယ်အပြောင်းအရွှေ့၊ ပထဝီဝင်ကန့်သတ်ချက်များ၊ အခကြေးငွေပိုလျှံမှု သို့မဟုတ် အကောင့်မူဝါဒအန္တရာယ်တို့ ပါဝင်နိုင်သည်။ OmniRoute ရရှိနိုင်သော မက်တာဒေတာကို ဖော်ပြသည်။ သင်ဖွင့်မည့်အရာကို ရွေးချယ်ပါ။

### "ပိုမိုအခမဲ့ခွဲတမ်းကို ဘယ်လိုရနိုင်မလဲ။"

1. နောက်ထပ် အခမဲ့ဝန်ဆောင်မှုပေးသူများကို ချိတ်ဆက်ပါ။
2. သင့်လျော်သော ဖိသိပ်မှုအင်ဂျင်များကို ဖွင့်ပြီး သင့်အလုပ်ဝန်အတွက် ချွေတာမှုကို တိုင်းတာပါ။
3. free/cheap ဝန်ဆောင်မှုပေးသူများကိုဦးစားပေးရန် `auto/cheap` သုံးပါ။
4. ဝန်ဆောင်မှုပေးသူစည်းမျဉ်းများကို မချိုးဖောက်ဘဲ နောက်ထပ်ခွင့်ပြုထားသော ဝန်ဆောင်မှုပေးသူများ သို့မဟုတ် အထောက်အထားများကို ပေါင်းထည့်ပါ။

### "အခမဲ့ဝန်ဆောင်မှုပေးသူများသည် အရည်အသွေးပိုဆိုးပါသလား?"

သေချာပေါက်။ အချို့သော ဝန်ဆောင်မှုပေးသူများသည် အခပေးလမ်းကြောင်းများမှတစ်ဆင့် ရရှိနိုင်သော တူညီသော မော်ဒယ်မိသားစုများကို ထုတ်ဖော်ပြသသော်လည်း ကန့်သတ်ချက်များ၊ latency၊ ကိုယ်ရေးကိုယ်တာ၊ ယုံကြည်စိတ်ချရမှုနှင့် မော်ဒယ်ဗားရှင်းများ ကွဲပြားနိုင်သည်။ အခမဲ့ဝန်ဆောင်မှုပေးသူ အဆင့်သတ်မှတ်ချက်များ စာမျက်နှာကို အရည်အသွေးအချက်ပြမှုတစ်ခုအဖြစ် အသုံးပြုပြီး အမှန်တကယ် ဆောင်ရွက်ပေးခဲ့သည့် မော်ဒယ်ကို အတည်ပြုပါ။
