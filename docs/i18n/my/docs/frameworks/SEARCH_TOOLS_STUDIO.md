## တဘ်များ

### ရှာဖွေရေး တဘ်

ရှိပြီးသား `SearchForm` + `ResultsPanel` + `RerankPanel` ကို တဘ်တစ်ခုအဖြစ် တိုးချဲ့ပြောင်းလဲသည်-

- ရှာဖွေမှု → ရလဒ်များ (ခေါင်းစဉ်၊ URL၊ အကျဉ်းချုပ်၊ ဆက်စပ်မှုရမှတ်)။
- Config အကန့်ရှိ ပံ့ပိုးသူ မက်တာဒေတာ (ကုန်ကျစရိတ်၊ အသုံးပြုခွင့်ပမာဏ၊ အခြေအနေ)။
- ပြန်လည်အဆင့်သတ်မှတ်သည့် အပိုင်း- ပြန်လည်အဆင့်သတ်မှတ်မှု မော်ဒယ်တစ်ခုကို ရွေးချယ်ခြင်း၊ ရလဒ်များကို အစီအစဉ်ပြန်စီခြင်းနှင့် `positionDelta` ကို ပြသခြင်း။
- ရှာဖွေရေးပံ့ပိုးသူများကို သတ်မှတ်မထားသည့်အခါ လုပ်ဆောင်ရန် တိုက်တွန်းချက်ပါသော အလွတ်အခြေအနေ။
- `SearchHistory.tsx` မှတစ်ဆင့် ရှာဖွေမှုမှတ်တမ်း။
- `POST /v1/search` ကို ခေါ်ဆိုသည် (ရှိပြီးသား endpoint ဖြစ်ပြီး ပြောင်းလဲမှုမရှိပါ)။

### အကြောင်းအရာ ထုတ်ယူရေး တဘ်

`POST /v1/web/fetch` (အစီအစဉ် 05 တွင် ဖန်တီးထားသည်) မှတစ်ဆင့် URL တစ်ခုမှ အကြောင်းအရာကို ထုတ်ယူရန် တဘ်အသစ်-

- ထည့်သွင်းမှု- URL + စာမျက်နှာအပြည့် ခလုတ် + ဖော်မတ်ရွေးချယ်ကိရိယာ (markdown / စာသား / HTML)။
- တင်သွင်းခြင်း → ရယူခြင်း → `ScrapeResult.tsx` ကို ဖော်ပြခြင်း။
- `ScrapeResult` သည် markdown အစမ်းကြည့်ရှုမှု + မူရင်းဒေတာ ခလုတ်ကို ဖော်ပြသည်။
- ကန့်သတ်ချက်- တုံ့ပြန်မှု body သည် **256 KB** ထက် ကြီးပါက UI တွင် `(ဖြတ်တောက်ထားသည်၊ မူရင်းဒေတာကို ကြည့်ရန်)` ဟု ပြသပြီး မူရင်းဒေတာကို Monaco modal (D21) ဖြင့် ဖွင့်ပေးသည်။
- မက်တာဒေတာအကန့်- ပံ့ပိုးသူ (firecrawl/jina-reader/tavily-search/tinyfish/nimble-search/anysearch-search/parallel-search)၊ ကြာချိန်၊ ကုန်ကျစရိတ်၊ တုံ့ပြန်မှုအရွယ်အစား၊ လင့်ခ်အရေအတွက်။
- `useScrapeFetch.ts` hook ကို အသုံးပြုသည်။

### နှိုင်းယှဉ်ရေး တဘ်

တူညီသော ရှာဖွေမှု/URL ကို ပံ့ပိုးသူ **4 ဦးအထိ အပြိုင်** လုပ်ဆောင်သည် (D22)-

- ပံ့ပိုးသူတစ်ဦးစီအတွက် ဘေးချင်းယှဉ် ကော်လံများ။
- တိုင်းတာချက်များ- ကြာချိန်၊ ကုန်ကျစရိတ်၊ ရလဒ်အရေအတွက်၊ တုံ့ပြန်မှုအရွယ်အစား။
- ရှာဖွေမှုအတွက် URL ထပ်တူကျမှု တွက်ချက်ခြင်း (ကနဦးရလဒ်နှင့် နှိုင်းယှဉ်ထားသော တူညီသည့် URL အရေအတွက်)။
- ပံ့ပိုးသူတစ်ဦးစီအတွက် `POST /v1/search` (ရှာဖွေမှု) သို့မဟုတ် `POST /v1/web/fetch` (အကြောင်းအရာထုတ်ယူမှု) ကို ခေါ်ဆိုသည်။

## SearchConceptCard

`SearchConceptCard.tsx` — အမြဲမြင်နိုင်ပြီး ခေါက်သိမ်းနိုင်သော accordion ဖြစ်သည်။ အောက်ပါတို့ကို ရှင်းပြထားသည်-

| အယူအဆ                           | အကျဉ်းချုပ်                                                                           |
| ------------------------------- | ------------------------------------------------------------------------------------- |
| **ရှာဖွေခြင်း**                 | ဝဘ်ရလဒ်များစာရင်းကို ရယူပေးသည် (ခေါင်းစဉ်၊ URL၊ အတိုချုံးဖော်ပြချက်၊ ဆက်စပ်မှုရမှတ်)  |
| **အကြောင်းအရာထုတ်ယူခြင်း**      | URL တစ်ခု၏ အကြောင်းအရာအပြည့်အစုံကို ထုတ်ယူပေးသည် (markdown၊ စာသား သို့မဟုတ် HTML)     |
| **နှိုင်းယှဉ်ခြင်း**            | တူညီသော query ကို provider N ခုတွင် ဘေးချင်းယှဉ်၍ လုပ်ဆောင်သည်                        |
| **ပြန်လည်အဆင့်သတ်မှတ်ခြင်း**    | query နှင့် ဆက်စပ်မှု ပိုမိုကောင်းမွန်စေရန် LLM မှတစ်ဆင့် ရလဒ်များကို ပြန်လည်စီစဉ်သည် |
| **အလိုအလျောက် (ဈေးအသက်သာဆုံး)** | ရရှိနိုင်သည့် ဈေးအသက်သာဆုံး provider ကို အလိုအလျောက် ရွေးချယ်သည်                      |

## Provider ကတ်တလောက်

`ProviderCatalog.tsx` သည် `GET /api/search/providers` မှ provider စာရင်းအပြည့်အစုံကို ဖော်ပြပေးသည်
(fetch provider များ ပါဝင်လာစေရန် F4 တွင် တိုးချဲ့ထားသည်)-

| `kind` | `"search"` (provider 20 ခု) သို့မဟုတ် `"fetch"` (firecrawl, jina-reader, tavily-search, tinyfish, nimble-search, anysearch-search, parallel-search) |

အထောက်အထားများ ရှိ၊ မရှိနှင့် key အားလုံးသည် လက်ရှိတွင် cooldown အခြေအနေ၌ ရှိ၊ မရှိကို စစ်ဆေးခြင်းဖြင့် တောင်းဆိုမှုပြုလုပ်သည့်အချိန်တွင် status ကို **တွက်ချက်သတ်မှတ်သည်**။

## Backend ပြောင်းလဲမှုများ

ဤလုပ်ဆောင်ချက်အတွက် Backend ပြောင်းလဲမှုတစ်ခုသာ လိုအပ်ခဲ့သည်-

### တိုးချဲ့ထားသော `GET /api/search/providers`

`src/app/api/search/providers/route.ts` ကို အောက်ပါအတိုင်း တိုးချဲ့ခဲ့သည်-

- Fetch provider အားလုံး (`firecrawl`, `jina-reader`, `tavily-search`, `tinyfish`, `nimble-search`, `anysearch-search`, `parallel-search`) ကို array ထဲတွင် ထည့်သွင်းထားသည်။
- Item တစ်ခုစီတွင် `kind: "search" | "fetch"` ကို ထည့်သွင်းထားသည်။
- လက်ရှိ credential အခြေအနေမှ ရယူသတ်မှတ်ထားသော `status: "configured" | "missing" | "rate_limited"` ကို ထည့်သွင်းထားသည်။
- နောက်ကြောင်းပြန်လိုက်ဖက်ညီမှုကို ဆက်လက်ထိန်းသိမ်းထားပြီး လက်ရှိ field များ (`id`, `name` စသည်) ကို မပြောင်းလဲထားပါ။
