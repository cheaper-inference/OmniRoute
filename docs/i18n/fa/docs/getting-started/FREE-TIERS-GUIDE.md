> **TL;DR** : حساب های ارائه دهنده واجد شرایط خود را بیاورید. OmniRoute اتصالاتی را که پیکربندی کرده اید ترکیب می کند. بودجه توکن تبلیغ شده را صادر نمی کند. دسترسی رایگان ممکن است به ثبت نام، کلید API ، تأیید یا روش پرداخت نیاز داشته باشد. محدودیتهای ارائهدهنده، خطمشیهای رازداری و شرایط همچنان اعمال میشوند.

---

## سطوح رایگان چیست؟

بسیاری از ارائه دهندگان AI نوعی از آن را ارائه می دهند** دسترسی رایگان** . بسته به ارائهدهنده، این ممکن است به معنای یک نقطه پایانی بدون مجوز، سهمیه تکرارشونده، دسترسی بدون محدودیت با نرخ محدود، کمک هزینه ثبتنام، تأیید دستی یا ارتقای موقت باشد. برخی از گزینهها به حساب، کلید API ، کارت اعتباری، KYC یا پذیرش شرایط خاص ارائهدهنده نیاز دارند.

OmniRoute** سنگدانه ها** اتصالات را در یک نقطه پایانی پیکربندی کرد. شما همچنان برای هر ارائه دهنده ای که نیاز به یک حساب کاربری دارد به طور جداگانه ثبت نام کنید. آن حساب ها را متصل کنید و `model: "auto"` برای مسیریابی در بین اهداف واجد شرایط استفاده کنید. یک نصب تازه نمی تواند هدف بدون کلید واجد شرایطی داشته باشد. نصب OmniRoute به تنهایی پاسخ موفقیت آمیز چت را تضمین نمی کند.

## نماینده ارائه دهندگان دسترسی آزاد

### دسترسی مکرر، بدون کلید یا بدون پوشش

این ارائه دهندگان یک مسیر دسترسی آزاد مکرر، بدون کلید یا بدون پوشش در کاتالوگ حسابرسی شده دارند. "Uncapped" به معنای عدم انتشار کلاه توکن است. محدودیتهای نرخ، همزمانی، حساب، منطقهای و سیاست همچنان میتوانند اعمال شوند:

| ارائه دهنده        | مدل ها                                                                         | سهمیه                                                                                                               | نحوه اتصال                                                                           |
| ------------------ | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| **Kiro AI**        | Claude Sonnet 4.5، Haiku 4.5، DeepSeek V3.2 و دیگران                           | کاتالوگ حسابرسی شده استخر مشترک ماهیانه 25 هزار توکن را تخمین می زند                                                | جریان OAuth/account ; ToS با پرچم `avoid` در کاتالوگ                                 |
| **گرده افشانی ها** | مجموعه مدل بدون کلید فعلی; برخی از مدلهای قبلی متوقف شده یا نیاز به کلید دارند | بدون کلید؛ بدون سرپوش توکن منتشر شده                                                                                | هیچ اعتبار ارائه دهنده ای برای مدل های بدون کلید وجود ندارد                          |
| **لگفر**           | kimi-k3، deepseek-v4-pro، glm-5.2، gpt-5 0.6-luna، minimax-m3 و موارد دیگر     | کلید API رایگان (بدون محدودیت نرخ، بدون کارت).** هر درخواست ثبت شده است** برای تحقیق (انصراف در logfare.ai/consent) | کلید فوری در logfare.ai/register; ToS/privacy در logfare.ai/tos و logfare.ai/privacy |

| **Gemini**         | خانواده فلش Gemini                                                             | محدودیت نرخ project/model متغیر؛ هیچ کمک هزینه ماهانه رمز ثابتی در عنوان درج نشده است                               | کلید Google AI استودیو API ; محدودیت های فعال پروژه را بررسی کنید                    |
| **Groq**           | مدلهای Llama، GPT-OSS و Qwen                                                   | استخر حسابرسی شده ~ 24M tokens/month را تخمین می زند (4 سرپوش برای هر مدل، کاتالوگ حسابرسی شده 23-11-2026)          | کلید Groq API ; محدودیت های نرخ اعمال می شود                                         |

### کمک های مالی ثبت نام و اعتبارات خاص ارائه دهنده

این ارائه دهندگان کمک هزینه ثبت نام یا اعتبارات تبلیغاتی را با توجه به قوانین واجد شرایط بودن خود ارائه می دهند. همانطور که در 08-10-2026 تأیید شد، [قیمتگذاری Cerebras](https://www.cerebras.ai/pricing) به یک روش پرداخت برای اعتبار یکباره 5 دلاری نیاز دارد که پس از 30 روز منقضی میشود. این یک سهمیه رمز تکراری نیست. [محدودیتهای نرخ Gemini](https://ai.google.dev/gemini-api/docs/rate-limits) بسته به پروژه، مدل و ردیف متفاوت است، بنابراین به کمک هزینه ماهانه تضمینی تبدیل نمیشوند.

| ارائه دهنده  | اعتبارات رایگان                                                              | مدل ها                | نحوه دریافت                                                       |
| ------------ | ---------------------------------------------------------------------------- | --------------------- | ----------------------------------------------------------------- |
| **Cerebras** | اعتبار تبلیغاتی 5 دلاری یکباره؛ پس از 30 روز منقضی می شود                    | کاتالوگ استنتاج فعلی  | حساب و روش پرداخت معتبر                                           |
| **DeepSeek** | 5 میلیون توکن رایگان                                                         | DeepSeek V4           | در platform.deepseek.com ثبت نام کنید                             |
| **LongCat**  | کمک هزینه یکباره 10 میلیونی                                                  | LongCat 2.0           | API key + KYC; پس از کمک هزینه پرداخت کنید                        |
| **AI**       | اعتبار ثبت نام 300 دلاری به عنوان توکن ~ 300M در مدل بودجه نشان داده شده است | مدل های Gemini و شریک | حساب ابری Google ; قوانین صورتحساب و واجد شرایط بودن اعمال می شود |

## چگونه لایه های رایگان را روی هم قرار دهیم

جادوی OmniRoute است** انباشتن طبقات آزاد** . بهجای تکیه بر یک ارائهدهنده، چندین ارائهدهنده رایگان را به هم متصل میکنید و به OmniRoute اجازه میدهید بهطور خودکار بهترین را برای هر درخواست انتخاب کند.

### مثال: پوشش سطح آزاد گسترده تر

برای کاهش وابستگی به هر سهمیه، چندین ارائه دهنده را به هم متصل کنید:

1. **Gemini** — مکرر سهمیه کلید API
2. **Groq** — مکرر سهمیه کلید API
3. **گرده افشانی ها** — بدون کلید، دسترسی با نرخ محدود
4. **LongCat** کمک هزینه ثبت نام یک بار — (به KYC نیاز دارد)

سپس `model: "auto"` و OmniRoute will استفاده کنید:

- ابتدا اتصال واجد شرایط با بالاترین رتبه را امتحان کنید
- اگر سهمیه یا بررسی سلامت آن موفق نشد → ارائه دهنده پیکربندی بعدی را امتحان کنید
- اگر ارائه دهنده بدون کلید در دسترس نباشد، → از طریق اهداف باقی مانده ادامه دهید
- اگر هیچ اتصال واجد شرایطی موفق نشد → یک خطا را بازگرداند. اعتبارات ثبت نام تنها زمانی که معتبر و در دسترس هستند قابل استفاده هستند

**نتیجه** : پوشش لایه آزاد گسترده تر با — بازگشتی خودکار تضمینی برای ظرفیت نامحدود نیست.

## نحوه اتصال ارائه دهندگان رایگان

### مرحله 1: داشبورد را باز کنید

در مرورگر خود به `http://localhost:20128` بروید.

### مرحله 2: به ارائه دهندگان بروید

کلیک کنید** ارائه دهندگان** در نوار کناری

### مرحله 3: روی افزودن ارائه دهنده کلیک کنید

را کلیک کنید**+ ارائه دهنده را اضافه کنید** دکمه

### مرحله 4: یک ارائه دهنده رایگان انتخاب کنید

فهرست را مرور کنید و ابردادههای `hasFree`، اعتبار، سهمیه، حریم خصوصی و ToS فعلی هر ارائهدهنده را بررسی کنید. کارت ارائهدهنده و [مرجع ردیفهای رایگان](../reference/FREE_TIERS.md) ، استخرهای تکرارشونده، دسترسی uncapped/keyless ، اعتبار ثبتنام، ورودیهای متوقفشده، و منابع پرخطر را متمایز میکنند.

### مرحله 5: روی Connect کلیک کنید

برای ارائهدهنده `NOAUTH` ، OmniRoute یک اعتبار بالادستی درخواست نمیکند. این تضمین نمی کند که بالادست مشتریان شخص ثالث را می پذیرد یا ظرفیت موجود را دارد. ارائه دهندگان کلید OAuth و API باید از طریق جریان حساب مستند خود به هم متصل شوند. مشتری شما همچنان از یک کلید OmniRoute API ایجاد شده در استفاده می کند** کلیدهای داشبورد → API** زمانی که احراز هویت روتر فعال است (فقط یک بار، در هنگام ایجاد نشان داده می شود).

### مرحله 6: تکرار کنید

چندین ارائهدهنده را که شرایط و مدل حریم خصوصی آنها متناسب با مورد استفاده شما است را به هم وصل کنید.

## از dsh "مدل رایگان ما"

افزونه [dsh-our-free-model](https://github.com/Ebony-Vinyl/dsh-our-free-model) برای میزبان عامل dsh به دو قسمت بالادستی می رسد. OmniRoute قبلاً برای هر یک ارائه دهنده دارد، اما تنها یکی از آنها یک مسیر رایگان در OmniRoute است:

| خط پلاگین    | بالادست                                    | ارائه دهنده OmniRoute        | رایگان در OmniRoute؟ | نحوه اتصال                                                                    |
| ------------ | ------------------------------------------ | ---------------------------- | -------------------- | ----------------------------------------------------------------------------- |
| کانال کیلویی | دروازه کیلو AI (`api.kilo.ai/api/gateway`) | `kilo-gateway` (مستعار `kg`) | بله                  | کلید API اختیاری است: برای استفاده از استخر رایگان دروازه، آن را خالی بگذارید |
| خط آزاد      | OpenCode Zen (`opencode.ai`)               | `opencode-zen`               | خیر                  | کلید OpenCode API خودتان از [opencode.ai/zen](https://opencode.ai/zen)        |

**کیلو.** استخر رایگان را `kilo-gateway/<model>` یا `kg/<model>` بنامید، برای مثال `kg/kilo-auto/free` (روتر خودکار رایگان Kilo) یا یکی از مدلهای `:free` دروازه. مجموعه آزاد می چرخد. `kilo-gateway` از شناسههای مدلی عبور میکند که در لیست داخلی OmniRoute نیستند، بنابراین میتوان مدلی را که امروز لیست دروازهها فهرست میکند، قبل از اینکه کاتالوگ شامل آن شود فراخوانی کرد. کارتهای مدل رایگان Kilo میگویند که درخواستها ممکن است توسط ارائهدهنده بالادستی ثبت شود و برای بهبود خدمات آن استفاده شود، بنابراین دادههای حساس را ارسال نکنید.

**OpenCode.** مسیر رایگان این افزونه، پیشنهاد بدون کلید OpenCode است. OmniRoute آن پیشنهاد را به عنوان دسترسی رایگان ارائه نمی دهد:

- ارائهدهنده OpenCode بدون کلید OmniRoute به درخواست اپراتور OpenCode حذف شد ( [به ارائهدهندگان حذف شده](../reference/REMOVED_PROVIDERS.md) مراجعه کنید).
- [مستندات نقطه پایانی](https://opencode.ai/v2/docs/console/models/#endpoints)OpenCode پیشنهادات چت رایگان خود را به مشتری خود OpenCode مرتبط می کند، بنابراین OmniRoute آنها را رایگان حساب نمی کند یا نشان نمی دهد.

شناسههای مدلی که افزونه نشان میدهد، مانند `deepseek-v4.1-flash-free`، `mimo-v2.6-flash-free` و `nemotron-3.5-lightning-free`، در کاتالوگ `opencode-zen` هستند. `opencode-zen` با کلید OpenCode خود وصل کنید تا از آنها تحت شرایط حساب OpenCode خود استفاده کنید.

**پورت محلی افزونه.** این افزونه میتواند مدلهای خود را در یک درگاه محلی سازگار با OpenAI (پیشفرض `18899`) نمایش دهد. چنین نقطه پایانی را میتوان به عنوان یک [ارائهدهنده سازگار با OpenAI سفارشی](../guides/USER_GUIDE.md#custom-openai-compatible-providers) اضافه کرد، اما OmniRoute افزونه را نصب، راهاندازی یا بهروزرسانی نمیکند، و افزونه تصمیم میگیرد که کدام یک از درخواستها به بالادستی ارائه شود. محدودیتهای OpenCode در بالا برای پیشنهاد OpenCode اعمال میشود که هر مشتری درخواستی را ارسال کند.

---

## خواندن کاتالوگ به درستی

- `NOAUTH` یعنی OmniRoute از شما اعتبار ارائه دهنده نمی خواهد. زمان کار، حریم خصوصی یا ظرفیت نامحدود را تضمین نمی کند.
- `hasFree` ابرداده کشف است. این می تواند سهمیه مکرر، دسترسی بدون کلید، اعتبار ثبت نام، برنامه تایید یا ارتقاء را نشان دهد.
- `recurring-uncapped` به این معنی است که سقف نشانه منتشر شده در دسترس نبود. محدودیت های نرخ و همزمانی همچنان اعمال می شود.
- `one-time-initial` پس از مصرف کمک هزینه ثبت نام تکرار نمی شود.
- ارائه دهندگان `tos: avoid` به طور پیش فرض از مسیریابی خودکار مستثنی هستند (`excludeTosAvoid`). اتصال یک حساب کاربری این فیلتر را دور نمی زند. هر نادیده گرفتن اپراتور باید به دنبال بررسی شرایط ارائه دهنده و ریسک حساب باشد.
- ورودی هایی که `discontinued` علامت گذاری شده اند، شواهد تاریخی باقی می مانند و نباید به عنوان رایگان ارائه شوند.

## چگونه OmniRoute سطوح رایگان را بهتر می کند

### 1. بازگشت خودکار

اگر یک ارائهدهنده رایگان مشغول یا خراب باشد، OmniRoute بهطور خودکار یکی دیگر را امتحان میکند. شما نیازی به انجام کاری ندارید.

### 2. مسیریابی هوشمند

OmniRoute را انتخاب می کند** بهترین ارائه دهنده رایگان** برای هر درخواست بر اساس:

- سرعت — کدام ارائه دهنده در حال حاضر سریعتر است؟
- کیفیت — کدام ارائه دهنده برای این کار بهتر است؟
- ظرفیت — سهمیه کدام ارائه دهنده باقی مانده است؟

### 3. پس انداز رمز

خط لوله فشرده سازی OmniRoute می تواند توکن های درخواستی واجد شرایط و خروجی ابزار را کاهش دهد. پس انداز واقعی به محتوا، موتورهای انتخاب شده، حسابداری ارائه دهنده و تنظیمات وفاداری بستگی دارد. فشرده سازی هر سهمیه ارائه دهنده را در یک مقدار ثابت ضرب نمی کند.

### 4. پشتیبانی از چند حساب

اگر شرایط ارائه دهنده اجازه چندین حساب یا اعتبار را بدهد، OmniRoute می تواند هر اتصال را به عنوان یک نامزد مسیریابی جداگانه در نظر بگیرد. برای فرار از سهمیه یا خط مشی دسترسی ارائه دهنده، حساب های اضافی ایجاد نکنید.

کاتالوگ زنده و بدون تکرار در حال حاضر گزارش می دهد:

| متریک                        |         ارزش فعلی حسابرسی شده | تفسیر                                                                             |
| ---------------------------- | ----------------------------: | --------------------------------------------------------------------------------- |
| کمک مالی تکراری              | **~ 90M tokens/month رایگان** | استخرهای مشترک یک بار شمارش می شوند. ارائه دهندگان بدون سقف را از مبلغ حذف می کند |
| ماه اول با کمک هزینه ثبت نام |     **~ 153M در ماه اول شما** | مجموع مکرر بعلاوه اعتبارات یک بار و مکرر                                          |

اینها برآوردهای کل کاتالوگ در حسابهای واجد شرایط جداگانه هستند، نه کمک هزینه ارائه شده توسط OmniRoute یا پیشبینی برای نصب جدید. ظرفیت قابل استفاده شما به ارائه دهندگانی که به آنها متصل می شوید و شرایط فعلی آنها بستگی دارد. مقادیر از `open-sse/config/freeModelCatalog.ts` محاسبه می شوند. برای کپی برداری از استخر، پرچم های ToS ، ورودی های متوقف شده و روش اعتبار ثبت نام، به [مرجع ردیف های رایگان](../reference/FREE_TIERS.md) مراجعه کنید.

## سوالات متداول

### "آیا این واقعا رایگان است؟"

کاتالوگ شرایط منتشر شده توسط ارائه دهنده و تحقیقات پروژه را ثبت می کند، اما پیشنهادات می توانند تغییر کنند. قبل از استفاده، قیمت، سهمیه، خط مشی رازداری و واجد شرایط بودن ارائه دهنده را بررسی کنید.

### "آیا ردیف آزاد تمام می شود؟"

هر ارائهدهندهای میتواند نرخ را محدود کند، مدلها را تغییر دهد، دسترسی را به حالت تعلیق درآورد یا آفلاین شود. اتصالات متعدد پوشش برگشتی را بهبود می بخشد اما مسیر رایگان موجود را تضمین نمی کند.

### "آیا می توانم از ارائه دهندگان رایگان برای تولید استفاده کنم؟"

فقط در صورتی که SLA، مدیریت داده، محدودیتها و شرایط ارائهدهنده نیازهای تولید شما را برآورده کند. بارهای کاری حیاتی باید دارای بازگردانی مناسب از نظر قراردادی نظارت شده باشند.

### "گرفتار چیست؟"

معاملات ممکن است شامل محدودیتهای سختگیرانه، فهرستهای انتظار، KYC، تأیید کارت اعتباری، آموزش در مورد اعلانها، حریم خصوصی ضعیفتر، بدون SLA، انحراف مدل، محدودیتهای جغرافیایی، اضافه پرداختی، یا ریسک خطمشی حساب باشد. OmniRoute ابرداده های موجود را نشان می دهد. شما انتخاب می کنید چه چیزی را فعال کنید.

### "چگونه سهمیه رایگان بیشتری دریافت کنم؟"

1. ارائه دهندگان رایگان بیشتری را متصل کنید
2. موتورهای فشرده سازی مناسب را فعال کنید و میزان صرفه جویی را برای حجم کاری خود اندازه گیری کنید
3. `auto/cheap` برای اولویت بندی ارائه دهندگان free/cheap استفاده کنید
4. ارائه دهندگان یا اعتبارنامه های مجاز اضافی را بدون نقض شرایط ارائه دهنده اضافه کنید

### "آیا ارائه دهندگان رایگان کیفیت بدتری دارند؟"

نه لزوما. برخی از ارائهدهندگان خانوادههای مدل یکسانی را که از طریق مسیرهای پولی در دسترس هستند، نشان میدهند، اما محدودیتها، تأخیر، حریم خصوصی، قابلیت اطمینان و نسخههای مدل میتوانند متفاوت باشند. از صفحه رتبه بندی ارائه دهنده رایگان به عنوان سیگنال کیفیت استفاده کنید و مدل واقعی ارائه شده را تأیید کنید.
