## دسته بندی ها

- **رایگان** لایه رایگان — با کلید API (پیکربندی شده از طریق داشبورد)
- **بدون احراز هویت** نقاط پایانی عمومی — که اصلاً نیازی به کلید یا ورود به سیستم ندارند
- **OAuth** جریان ورود به — توسط OmniRoute مدیریت می شود، کلید API مورد نیاز نیست
- **کوکی وب** — برنامه وب ارائه دهنده را از طریق احراز هویت کوکی بسته بندی می کند
- **کلید API** ارائهدهنده پولی — از طریق کلید API پیکربندی شده است (ممکن است اعتبار رایگان اعمال شود)
- **محلی** — روی دستگاه کاربر اجرا می شود (Ollama، LM Studio، vLLM، و غیره)
- **جستجو کنید** ارائه دهندگان جستجوی وب —
- **صوتی** ارائه دهندگان فقط صوتی — (TTS/STT)
- **پروکسی بالادست** ارائه دهندگان — که به ارائه دهندگان دیگر پروکسی می کنند
- **عامل ابری** عوامل برنامه نویسی طولانی مدت — (Codex Cloud، Devin، Jules)
- **سیستم** ارائه دهندگان داخلی — OmniRoute (Loopback و غیره)

برچسب های اضافی: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (جایی که نشان داده شده است): `native` — واقعی تابع فراخوانی API; `emulated` — آرایه `tools` از طریق `webTools.ts` (بلوکهای `<tool>{...}</tool>` تجزیهشده با regex) شبیهسازی میشود. `none` — `tools` در حال حاضر بی صدا حذف شده است. رجوع #7286 شود.

از داشبورد در `/dashboard/providers` برای فعال کردن، پیکربندی و آزمایش هر ارائه دهنده استفاده کنید.
