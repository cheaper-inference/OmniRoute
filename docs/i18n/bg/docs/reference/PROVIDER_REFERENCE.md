## Категории

- **Безплатни** — безплатно ниво с API ключ (конфигурира се чрез таблото за управление)
- **Без удостоверяване** — публични крайни точки, които изобщо не изискват ключ или влизане
- **OAuth** — процесът на влизане се управлява от OmniRoute, не е необходим API ключ
- **Уеб бисквитка** — обгръща уеб приложението на доставчика чрез удостоверяване с бисквитка
- **API ключ** — платен доставчик, конфигуриран чрез API ключ (може да се предоставят безплатни кредити)
- **Локални** — изпълняват се на машината на потребителя (Ollama, LM Studio, vLLM и др.)
- **Търсене** — доставчици за търсене в мрежата
- **Аудио** — доставчици само за аудио (TTS/STT)
- **Прокси към доставчик нагоре по веригата** — доставчици, които препращат заявки към други доставчици
- **Облачен агент** — дълготрайно работещи агенти за програмиране (Codex Cloud, Devin, Jules)
- **Системни** — вътрешни доставчици на OmniRoute (loopback и др.)

Допълнителни етикети: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (където е показано): `native` — реален API за извикване на функции; `emulated` — масивът `tools` се емулира чрез подкана посредством `webTools.ts` (блокове `<tool>{...}</tool>`, анализирани с регулярен израз); `none` — понастоящем `tools` се отхвърля без предупреждение. Вижте #7286.

Използвайте таблото за управление на `/dashboard/providers`, за да активирате, конфигурирате и тествате всеки доставчик.
