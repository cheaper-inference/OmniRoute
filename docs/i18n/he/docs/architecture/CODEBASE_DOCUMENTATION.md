## 1. סטאק טכנולוגי

| תחום          | בחירה                                                                                                                   |
| ------------- | ----------------------------------------------------------------------------------------------------------------------- |
| פריימוורק ווב | **Next.js 16** (App Router, פלט standalone, ללא middleware גלובלי)                                                      |
| שפה           | **TypeScript 6.0+** — target `ES2022`, `module: esnext`, `moduleResolution: bundler`, `strict: false`                   |
| סביבת ריצה    | **Node.js** `>=22.22.2 <23` או `>=24.0.0 <27` (נאכף באמצעות `engines` + `SUPPORTED_NODE_RANGE`)                         |
| מסד נתונים    | **SQLite** באמצעות `better-sqlite3` (singleton, journaling מסוג WAL)                                                    |
| דסקטופ        | **Electron 41** + `electron-builder` 26.10 (workspace נפרד ב-`electron/`)                                               |
| בדיקות        | **Node native test runner** (יחידה/אינטגרציה), **Vitest** (MCP, autoCombo, cache), **Playwright** (e2e + protocols-e2e) |
| בנייה         | Next.js standalone באמצעות `scripts/build/build-next-isolated.mjs`                                                      |
| Lint/עיצוב    | ESLint flat config + Prettier (`lint-staged` באמצעות Husky pre-commit)                                                  |
| מערכת מודולים | ESM בכל מקום (`"type": "module"`)                                                                                       |
| UI של דשבורד  | **Tailwind CSS 4** + **Keak CI UI Kit** מוטמע (vendored) (`packages/ui-kit`), אייקוני Lucide — ראה `DESIGN_SYSTEM.md`   |
| Workspaces    | npm workspaces — `open-sse`, `packages/browser-pool`, `packages/ui-kit`                                                 |

כינויי נתיב (`tsconfig.json`):

- `@/*` → `src/*`
- `@omniroute/open-sse` → `open-sse/index.ts`
- `@omniroute/open-sse/*` → `open-sse/*`
- `@omniroute/ui-kit` → `packages/ui-kit/src`, `@omniroute/ui-kit/*` → `packages/ui-kit/src/*`

פורט HTTP ברירת מחדל: **`20128`** (ה-API והדשבורד חולקים את אותו תהליך). תיקיית
הנתונים נקבעת על ידי משתנה הסביבה `DATA_DIR`, עם ברירת מחדל `~/.omniroute/`.

### 3.1 `src/app/` — App Router

ה-App Router חושף הן את ממשק המשתמש של לוח הבקרה והן את ממשק ה-HTTP API הציבורי/הניהולי.
**אין middleware גלובלי** — היירוט מתבצע ברמת כל נתיב בנפרד.

מקטעים ברמה העליונה תחת `src/app/`:

| נתיב                                                                          | מטרה                                          |
| ----------------------------------------------------------------------------- | --------------------------------------------- |
| `api/`                                                                        | כל נתיבי ה-HTTP API (ראו פירוט למטה)          |
| `a2a/`                                                                        | נקודת קצה של A2A JSON-RPC 2.0 (`POST /a2a`)   |
| `.well-known/agent.json/`                                                     | מסמך הגילוי A2A Agent Card                    |
| `(dashboard)/`                                                                | ממשק לוח הבקרה (קבוצת נתיבים, ללא קידומת URL) |
| `auth/`, `login/`, `forgot-password/`, `callback/`                            | זרימות אימות                                  |
| `landing/`                                                                    | דף שיווקי/נחיתה                               |
| `docs/`                                                                       | מציג מסמכי API מוטבע                          |
| `status/`, `maintenance/`, `offline/`                                         | דפים תפעוליים                                 |
| `privacy/`, `terms/`                                                          | דפים משפטיים                                  |
| `400/`, `401/`, `403/`, `408/`, `429/`, `500/`, `502/`, `503/`                | דפי שגיאה סטטיים                              |
| `error.tsx`, `global-error.tsx`, `not-found.tsx`, `forbidden/`, `loading.tsx` | גבולות שגיאה/טעינה של הפריימוורק              |
| `layout.tsx`, `page.tsx`, `globals.css`, `manifest.ts`                        | מעטפת השורש                                   |

## 11. מוסכמות

- **סגנון קוד**: הזחה של 2 רווחים, מירכאות כפולות, רוחב של 100 תווים, נקודה-פסיק,
  פסיקים סופיים בסגנון `es5` — נאכף על ידי Prettier באמצעות `lint-staged`.
- **ייבואים**: חיצוניים → פנימיים (`@/`, `@omniroute/open-sse`) → יחסיים.
- **מתן שמות**: קבצים ב-`camelCase` או `kebab-case`, רכיבים ב-`PascalCase`,
  קבועים ב-`UPPER_SNAKE`.
- **ESLint**:‏ `no-eval`,‏ `no-implied-eval`,‏ `no-new-func` =‏ `error` בכל מקום;
  `no-explicit-any` =‏ `warn` ב-`open-sse/` וב-`tests/`, ושגיאה במקומות אחרים.
- **TypeScript**:‏ `strict: false` (מצב תאימות למערכת ותיקה). העדיפו טיפוסים מפורשים על פני
  הסקת טיפוסים בגבולות שבין מודולים.
- **מסד נתונים**: לעולם אל תכתבו SQL גולמי בנתיבים או במטפלים — עברו תמיד דרך
  המודולים שב-`src/lib/db/`. לעולם אל תייבאו דרך barrel — השתמשו ישירות במודולי `src/lib/db/*` ספציפיים.
- **טיפוס ישויות מסד נתונים (#3512)**: פונקציה שכותבת או קוראת מבנה שורה של
  טבלת מסד נתונים צריכה לקבל/להחזיר ממשק TS בעל שם המשקף את עמודות הטבלה
  ביחס 1:1, ולא `any` או טיפוס אנונימי מוטבע בנקודת הקריאה. מקמו
  את הממשק לצד הפונקציה (למשל `export interface UsageEntry` בתוך
  `src/lib/usage/usageHistory.ts` מעל `saveRequestUsage`), השאירו שדות בודדים
  כאופציונליים/ניתנים ל-null כאשר כותבים שונים מאכלסים את השורה
  בהדרגה, והעדיפו `unknown` על פני `any` עבור שדה שמבנהו
  משתנה בין קוראים (מתועד בשדה, למשל `UsageEntry.tokens`
  מקבל הן נתוני שימוש גולמיים במבנה הספק והן את המבנה המנורמל). לאחר שמספר מופעי
  `any` בקובץ מגיע כך לאפס, הוסיפו אותו לרשימת ההיתרים של
  `check:any-budget:t11`‏ (`scripts/check/check-t11-any-budget.mjs`,
  `maxAny: 0`) כדי למנוע נסיגה. זוהי מוסכמה עבור השלב הראשוני — הניקוי
  הרחב יותר של "`any` אנונימי אסור" מתבצע באופן הדרגתי בשאר
  בסיס הקוד.
- **שגיאות**: השתמשו ב-try/catch עם טיפוסי שגיאות ספציפיים ורשמו ביומן עם הקשר של pino. לעולם אל
  תבלעו שגיאות ללא דיווח בזרמי SSE; השתמשו באותות ביטול לצורך ניקוי.
- **אבטחה**: לעולם אל תשתמשו ב-`eval()` / `new Function()` / הפעלה משתמעת של eval. אמתו
  את כל הקלטים באמצעות Zod. הצפינו פרטי גישה במנוחה (AES-256-GCM). שמרו על
  התאמה בין רשימת החסימה `src/shared/constants/upstreamHeaders.ts` לבין
  שכבת הטיהור/האימות.
- **קומיטים**: Conventional Commits —‏ `feat(scope): subject`. ההיקפים המותרים:

- **ענפים**: הקידומות `feat/`, `fix/`, `refactor/`, `docs/`, `test/`,

## 12. כללים מחייבים (מתוך CLAUDE.md)

1. לעולם אין לבצע commit של סודות או פרטי גישה.

4. לעולם אין לבצע commit ישירות אל `main`.
5. לעולם אין לכתוב SQL גולמי בנתיבים — יש לעבוד תמיד דרך המודולים שב-`src/lib/db/`.

8. יש לכלול תמיד בדיקות בעת שינוי קוד ייצור.
