התקן את לוח המחוונים OmniRoute כאפליקציית אינטרנט מתקדמת כדי לפתוח אותו ממסך הבית או משולחן העבודה שלך בחלון עצמאי. האפליקציה המותקנת עדיין זקוקה לחיבור לשרת OmniRoute שלך עבור ניווט, נתוני לוח מחוונים ובקשות API. נכסים סטטיים בקובץ שמור אינם מספקים שער לא מקוון או לוח מחוונים לא מקוון.

## מה זה PWA?

אפליקציית אינטרנט פרוגרסיבית משתמשת בלוח המחוונים של האינטרנט עם סמל אפליקציה וחלון נפרד. לאחר ההתקנה, OmniRoute:

- מופעל ממסך הבית או משולחן העבודה
- נפתח במצב עצמאי, ללא שורת הכתובת והכרטיסיות הרגילות של הדפדפן
- מטמון נכסים סטטיים נבחרים
- תומך בכיוון לאורך ולרוחב

## הַתקָנָה

השתמש בכתובת HTTPS עבור שרת במכשיר אחר. כאשר השרת פועל על אותו מכשיר, `http://localhost:20128` עומד גם בדרישות התקנת הדפדפן. כתובת `http://YOUR_IP:20128` רגילה אינה עומדת בדרישות אלו. תפריטי התקנה והנחיות תלויות בדפדפן ובמערכת ההפעלה. עיין [בדרישות ההתקנה של PWA של MDN](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable#https_localhost_or_loopback_are_required).

### אנדרואיד (Chrome)

1. פתח את כתובת HTTPS OmniRoute, או `http://localhost:20128` עבור שרת באותו טלפון.
2. פתח את**⋮** תפריט ובחר** התקן אפליקציה** אוֹ** הוסף למסך הבית** , אם יוצע.
3. אשר את ההנחיה.
4. פתח OmniRoute ממסך הבית.

### iOS (ספארי)

1. פתח את כתובת HTTPS OmniRoute בספארי.
2. בֶּרֶז** לַחֲלוֹק** →** הוסף למסך הבית** .
3. אשר את השם והקש** לְהוֹסִיף** .
4. פתח OmniRoute ממסך הבית.

### שולחן עבודה (Chrome / Edge)

1. פתח את לוח המחוונים OmniRoute שלך.
2. השתמש בסמל ההתקנה של הדפדפן או ב-** התקן אפליקציה** הזנת תפריט, אם מוצעת.
3. אשר את ההנחיה לפתוח OmniRoute בחלון משלו.

## תכונות

### חלון עצמאי

המניפסט קובע `display: "standalone"` ו- `start_url: "/dashboard"`. האפליקציה המותקנת פותחת את לוח המחוונים בחלון אפליקציה. בקרות הדפדפן ומערכת ההפעלה עדיין יכולות להופיע; המניפסט אינו מבקש מצב מסך מלא.

### נכסי מטמון ודרישות רשת

ה- [Service Worker](../../public/sw.js) שומר משאבים נבחרים מאותו מקור:

| בקשה או נכס                          | אִסטרָטֶגִיָה | הִתְנַהֲגוּת                                                                                            |
| ------------------------------------ | ------------- | ------------------------------------------------------------------------------------------------------- |
| משאבים בזמן ההתקנה                   | מטמון מראש    | `/`, `/manifest.webmanifest`, `/icon-512.png` ו- `/apple-touch-icon.png` נשמרים במטמון במהלך התקנת עובד |
| Next.js static assets (`/_next/`)    | רשת ראשונה    | תגובות מוצלחות מעדכנות את המטמון; שגיאת רשת נופלת בחזרה לתגובה קיימת במטמון                             |
| CSS, JS, תמונות וגופנים סטטיים אחרים | מטמון-ראשון   | נעשה שימוש חוזר בתגובה קיימת במטמון; תגובות רשת מוצלחות נשמרות במטמון על פספוס                          |
| ניווט בדף                            | לַעֲקוֹף      | הדפדפן מביא את הדף ישירות; לא מוצגת חילופין במצב לא מקוון                                               |
| API, לוח מחוונים ומסלולי אימות       | לַעֲקוֹף      | העובד אינו מיירט או מאחסן בקשות אלו                                                                     |
| בקשות אחרות שאינן סטטיות             | רֶשֶׁת        | אין חיפוש מטמון או אחסון                                                                                |

המסלולים הבלתי נכללים הם `/api`, `/a2a`, `/dashboard`, `/v1`, `/v1beta`, `/models`, `/chat`, `/responses`, `/codex`, `/callback` ו- `/login`, מותאמים ללא רגישות רישיות בגבולות הנתיבים. בקשות צולבות מוצא ולא GET עוקפות גם את העובד.

### דף קישוריות

דף `/offline` מספק הודעת קישוריות, מחוון online/offline, א** נסה שוב להתחבר** כפתור וקישור לעמוד הסטטוס. זה כן** לא שמור מראש** ועובד השירות עושה זאת** לֹא** הפניית ניווטים שנכשלו אליו. קיומו אינו מנגיש דפים חדשים ללא השרת.

### אייקוני אפליקציה

המניפסט מפרסם את הסמלים האלה PNG :

| קוֹבֶץ                 | גוֹדֶל  | לְהִשְׁתַמֵשׁ                  |
| ---------------------- | ------- | ------------------------------ |
| `icon-192.png`         | 192×192 | סמל אפליקציה כללי              |
| `icon-512.png`         | 512×512 | סמל אפליקציה כללי וניתן למסיכה |
| `apple-touch-icon.png` | 180×180 | סמל מסך הבית של אפל            |

הדפדפן בוחר את הסמל המתאים עבור יעד ההתקנה.

### רישום אוטומטי

`PwaRegister` רושם את העובד בייצור כאשר הדפדפן תומך בעובדי שירות. מצב פיתוח מבטל רישום של עובדים ומנקה מטמונים כדי למנוע נכסים מיושנים המפריעים לטעינה מחדש חמה. הנחיות להתקנה נשארות החלטה של הדפדפן.

## אדריכלות טכנית

### מניפסט אפליקציית אינטרנט

Next.js מייצר `/manifest.webmanifest` מ- [`src/app/manifest.ts`](../../src/app/manifest.ts). ההגדרות העיקריות שלו הן:

| סְבִיבָה       | עֵרֶך                                       |
| -------------- | ------------------------------------------- |
| `short_name`   | `OmniRoute`                                 |
| `start_url`    | `/dashboard`                                |
| `scope`        | `/`                                         |
| `display`      | `standalone`                                |
| `orientation`  | `any`                                       |
| צבעי רקע ונושא | פלטת האור ברירת המחדל של `PWA_THEME_COLORS` |

השם והתיאור של המניפסט הם ערכים סטטיים בקובץ המקור הזה. המניפסט המותקן אינו עוקב אחר הגדרת שם המופע או הפלטה הפעילה בכל ביקור.

### עובד שירות

[`public/sw.js`](../../public/sw.js) אין תלות במסגרת שירות-עובד:

- **לְהַתְקִין:** מאחסן מראש את ארבעת המשאבים המפורטים למעלה ומפעיל את העובד החדש.
- **לְהַפְעִיל:** מסיר דורות מטמון ישנים יותר ותובע לקוחות.
- **לְהָבִיא:** מיישמת את אסטרטגיות הנכסים הסטטיים והחרגות המסלולים לעיל.
- **גירסאות:** שם מטמון המקור הוא `omniroute-pwa-v3`; בניית ההפקה חותמת את זהות המטמון.
- **התראות:** מטפל באירועי `push` נכנסים וממקד או פותח חלון כאשר לוחצים על הודעה.

מטפלי אירועי Push לבדם אינם יוצרים מנוי דחיפה פעיל או מסירת שרת מוגדרת. אל תניח שההודעות מופעלות רק בגלל שה- PWA מותקן.

### מטא נתונים ורישום של פריסה

[`src/app/layout.tsx`](../../src/app/layout.tsx) מספק את קישור המניפסט, מטא נתונים עצמאיים של Apple, צבעי ערכת נושא ו- `viewport-fit: cover`. כותרת העמוד וכותרת אפליקציית האינטרנט של Apple משתמשים בשם המופע. צבע הנושא של הדפדפן החי עוקב אחר הפלטה; מניפסט ההתקנה משתמש בצבע האור ברירת המחדל.

[`PwaRegister`](../../src/shared/components/PwaRegister.tsx) פועל על הלקוח ורושם `/sw.js` עם build ID ב- URL שלו. הוא מזהה דורות מטמון לא תואמים ויכול לאפס את העובד ולטעון מחדש פעם אחת כדי להתאושש מהתקנה ישנה יותר. כשל ברישום אינו חוסם את לוח המחוונים.

## שימוש עם Termux (אנדרואיד)

1. התחל OmniRoute ב- Termux: `npx -y omniroute@latest`.
2. פתח את Chrome באותו טלפון: `http://localhost:20128`.
3. התקן את ה- PWA דרך תפריט ההתקנה של הדפדפן.
4. השאר את שרת Termux פועל בזמן השימוש בלוח המחוונים.

הטלפון מארח גם את השער וגם את לוח המחוונים שלו. בקשות לספקי AI מרוחקים עדיין זקוקות לגישה לרשת. עיין [במדריך Termux](TERMUX_GUIDE.md) לשיקולי הגדרה ושיקולי אנדרואיד לכל החיים.

## השתמש ממכשירים אחרים

פתח את כתובת HTTPS של השרת בטלפון, טאבלט או שולחן עבודה, ולאחר מכן עקוב אחר זרימת ההתקנה של הדפדפן. השרת חייב להישאר נגיש מכל מכשיר. עיין [במדריך המנהרה](../ops/TUNNELS_GUIDE.md) לאפשרויות גישה מרחוק.

## התאמה אישית

### שם מופע

ה** שם מופע** ההגדרה משנה את המטא נתונים של לוח המחוונים, כולל כותרת העמוד וכותרת אפליקציית האינטרנט של Apple. המניפסט שנוצר משתמש בשם סטטי, כך שהגדרה זו אינה מבטיחה ששמה של אפליקציה שכבר מותקנת ישתנה.

### Favicon מותאם אישית

סמל מותאם אישית משנה את סמל הדפדפן. מניפסט ההתקנה עדיין מפרסם את קבצי PNG למעלה; שינוי ה-favicon אינו מחליף את הסמלים של מסך הבית.

## מגבלות

- **נדרש חיבור לשרת:** לניווט בדף, מצב לוח המחוונים ובקשות API אין נפילה לא מקוונת.
- **אין סנכרון ברקע:** פעולות לא מקוונות אינן בתור להפעלה חוזרת.
- **הבדלים בדפדפן:** תפריטי התקנה, מצגת חלונות ותמיכה בהתראות משתנים בהתאם לפלטפורמה.
- **אין מטמון תגובות API :** העובד לא כולל API, לוח מחוונים ומסלולי אימות.
- **סמלי התקנה סטטיים:** עדכון סמלים אלה מחייב שינוי הנכסים המפורסמים; דפדפנים עשויים לשמור על מטא נתונים מותקנים.
