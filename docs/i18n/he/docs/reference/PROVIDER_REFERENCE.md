סך כל הספקים: **375**. ראו פירוט לפי קטגוריות למטה.

## קטגוריות

- **חינם** — שכבה חינמית עם מפתח API (מוגדר דרך לוח הבקרה)
- **ללא אימות** — נקודות קצה ציבוריות שאינן דורשות מפתח או כניסה כלל
- **OAuth** — תהליך כניסה המטופל על ידי OmniRoute, אין צורך במפתח API
- **קובץ Cookie אינטרנטי** — עוטף את יישום האינטרנט של הספק באמצעות אימות קובץ Cookie
- **מפתח API** — ספק בתשלום המוגדר באמצעות מפתח API (ייתכנו זיכויים חינם)
- **מקומי** — פועל על מכונת המשתמש (Ollama, LM Studio, vLLM, וכו')
- **חיפוש** — ספקי חיפוש אינטרנטי
- **שמע** — ספקים מבוססי שמע בלבד (TTS/STT)
- **פרוקסי עליון** — ספקים המבצעים פרוקסי לספקים אחרים
- **סוכן ענן** — סוכני קידוד ארוכי טווח (Codex Cloud, Devin, Jules)
- **מערכת** — ספקים פנימיים של OmniRoute (לולאת חזור, וכו')

תגיות נוספות: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (היכן שמוצג): `native` — API אמיתי לקריאת פונקציות; `emulated` — מערך ה-`tools` מדומה באמצעות הנחיה דרך `webTools.ts` (בלוקים של `<tool>{...}</tool>` המנותחים באמצעות ביטויים רגולריים); `none` — `tools` מושמט כרגע בשקט. ראה #7286.

השתמש בלוח הבקרה בכתובת `/dashboard/providers` כדי להפעיל, להגדיר ולבדוק כל ספק.
