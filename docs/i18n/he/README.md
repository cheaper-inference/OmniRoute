## אסימונים חינם לחודש: ~ 11.3B as Others Count · ~ 90M Real

</div>

> **~ 11.3B אסימונים בחינם לחודש**<br/> <sub> סופר כמו קטלוגים אחרים סופרים: כל שורה נוספה, הצעות שהסתיימו כללו </sub>
>
> **~ 90M אמיתי היום**<br/> <sub> כל מכסה משותפת נספרה פעם אחת: מה אתה באמת יכול להשתמש </sub>
>
> **הכל כאן בחינם. אין חומת תשלום.**<br/> ★ [אוהב את זה? סמן אותנו ב- GitHub](https://github.com/cheaper-inference/OmniRoute)

קטלוגים אחרים גובים מ- US$19 בשנה ל- US$49 עבור גישה לכל החיים לנתונים חיים. כאן הכל בחינם. מחירי <sub> נבדקו בתאריך 2026-11-18.</sub>

<sub>הקטלוג נבדק לאחרונה ב-23-11-2026. [איך אנחנו סופרים →](docs/reference/FREE_TIERS.md#how-we-count)</sub>

> **הביאו חשבונות ספק משלכם.** אלו הם שכבות חינם של צד שלישי, לא מענק סמלי מ- OmniRoute. הירשם, קבל אישורים היכן שספק מבקש אותם וחבר את אלה שאתה יכול להשתמש בהם. כל ספק מגדיר את המגבלות, הזמינות והתנאים שלו.
>
> ערימת שכבות חופשיות ביד משמעה עשרות SDKs, עשרות מגבלות תעריף ואין מושג ברור מה נשאר לך. OmniRoute שומר על 214 שורות קטלוג עם גישה חופשית ומחשב את הנתון האמיתי מ-12 בריכות עם מכסה שפורסמה, כל מאגר משותף נספר פעם אחת. מכסות שנפתחות רק לאחר בדיקת זהות אזורית (היום, ModelScope) מוצגות בנפרד, +~ 6M מאחורי אימות זהות אזורית, ולעולם לא מתווספות לנתון האמיתי. מה שנשאר מופיע בלוח המחוונים (`/dashboard/free-tiers`).

## התקן, חבר ספק ואז נתב דרך נקודת קצה אחת

<img src="./docs/diagrams/works-zero-config.svg" width="100%" alt="Four steps to use OmniRoute. Install with npm install -g omniroute, run omniroute, connect a provider and create an API key in the dashboard, then call http://localhost:20128/v1 with model auto."/>

```bash
# After connecting a provider, create your OmniRoute key in Dashboard → API Keys:
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer YOUR_OMNIROUTE_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"auto","messages":[{"role":"user","content":"Hello!"}]}'
```

<sub>`auto` צריך מסלול מתאים. להתקנה חדשה לא יכולה להיות יעדים מתאימים ללא מפתח, וספק ללא מפתח עשוי לדחות לקוחות צד שלישי. ספקים המסומנים `tos: avoid`, כולל Kiro, אינם נכללים בניתוב אוטומטי כברירת מחדל; חיבור חשבון אינו עוקף את ההגדרה הזו. עיין [במדריך השכבות החינמיות](docs/getting-started/FREE-TIERS-GUIDE.md) לפני בחירת ספק.</sub>

<sub>העתק והדבק סקריפטים להתחלה מהירה עבור** Python, Node.js, PHP ו- cURL** : [`examples/quickstart/`](examples/quickstart/). גרסה שלב אחר שלב: [התחלה מהירה](#quick-start).</sub>

## שילובים: ספינת הדגל

1. **התחל עם `auto`.** הגדר את הדגם בלקוח התואם OpenAI שלך. OmniRoute בונה משולבת וירטואלית מספקים מחוברים ומציינת מועמדים בשידור חי.
2. **שמור שילוב ליותר שליטה.** בחר שם, רשימת יעד ואסטרטגיה, ולאחר מכן השתמש בשם זה כמודל. האסטרטגיה קובעת איזו יעד הולך ראשון וכיצד מנסים את השאר.

שילוב מנותב בין דגמים באופן אוטומטי. על מיצוי המכסה, כשל ספק או נעילת מודל, הוא מנסה את היעד הבא כשיר, בריא.

### Zero-config: פשוט השתמש `auto`

```bash
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <your-omniroute-key>" \
  -H "Content-Type: application/json" \
  -d '{"model": "auto", "messages": [{"role": "user", "content": "Hello"}]}'
```

גרסאות מכוונות את המשקולות. הניתוב האחרון הידוע-טוב נשאר עם הספק האחרון המוצלח עד שהוא נכשל, ואז מבצע תוצאות חוזרות. `auto/fast` ו- `auto/cheap` מבטאים העדפות מבלי להבטיח את הדגם המהיר או הזול ביותר.

| דגם ID              | הִתְנַהֲגוּת                                                                                                                                                                                                                 |
| :------------------ | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `auto`              | משקלי ברירת מחדל מאוזנים.                                                                                                                                                                                                    |
| `auto/fast`         | מעדיף חביון נמוך ובריאות הספק.                                                                                                                                                                                               |
| `auto/cheap`        | בעד מחירים קטלוגיים נמוכים יותר.                                                                                                                                                                                             |
| `auto/coding`       | משקלים ראשונים באיכות ליצירת קוד.                                                                                                                                                                                            |
| `auto/smart`        | משקלים ראשונים באיכות עם 10% חקר (ברירת מחדל 5%).                                                                                                                                                                            |
| `auto/lkgp`         | ניתוב מפורש אחרון ידוע וטוב עם אותם משקלים כמו `auto`.                                                                                                                                                                       |
| `auto/subscription` | משתמש רק במכסת תוכנית מאומתת בזמן אמת. מחזיר את HTTP 503 כאשר אף אחד לא זמין ונמנע מחזר חיוב.                                                                                                                                |

| `auto/chaos`        | דגם אחד לכל ספק במקביל, עד חמישה כברירת מחדל או עשרה כאשר מוגדר. שיחה אחת במעלה הזרם לכל דגם. מחזירה את התשובה בדירוג העליון או את תגובת הפאנל המוצלחת האחרונה אם הדגם העליון נכשל. השתמש `fusion` כדי לסנתז תשובות עם שופט. |

דוגמאות של קטגוריות ושכבות אופציונליות כוללות `auto/coding:fast`, `auto/coding:free`, `auto/reasoning:pro` ו- `auto/vision`. אם אין מועמד מחובר תואם, הבקשה מחזירה HTTP 503 והמאגר נשאר צר. [מדריך אוטומטי קומבו](./docs/routing/AUTO-COMBO.md) · [ניתוב ראשון במנוי](./docs/routing/SUBSCRIPTION_LADDER.md)

### החוסן מובנה ב: 3 שכבות עצמאיות

כשלים מטופלים בשלושה היקפים, כך שדגם רע אחד לא מוריד את החשבון שלו, וחשבון רע אחד לא מוריד את הספק שלו.

<img src="./docs/diagrams/resilience-layers.svg" width="100%" alt="OmniRoute resilience: 3 independent self-healing layers, the right layer for the right failure. Layer 1, provider circuit breaker (whole provider): trips only on 408/500/502/503/504, opens after 8 failures for OAuth providers or 12 for API-key providers, resets after 60s or 30s into a HALF-OPEN probe, lazy recovery; while OPEN the combo reroutes to the next provider. Layer 2, connection cooldown (one key or account): base 5s OAuth or 3s API-key, exponential backoff with an anti-thundering-herd guard, success clears the error state; one cooling key is skipped while sibling keys keep serving. Layer 3, model lockout (one model): per-model 429, 404 or access denials lock just that model, never the whole connection. Terminal states (banned, expired, credits exhausted) wait for the operator; they are not cooldowns."/>

#### אם ספק שלם מושבת

ה** מפסק חשמל של ספק** נפתח לאחר 8 (OAuth) או 12 (API key) כשלים עם סטטוס 408, 500, 502, 503 או 504. שילובים מדלגים על ספק זה בזמן שהוא פתוח. לאחר 60 שניות או 30 שניות, בקשת בדיקה אחת מחליטה אם היא נסגרת.

#### אם מפתח אחד או חשבון אחד מוגבל בשיעור

ה** התקררות החיבור** ספסלים רק את החיבור הזה, עם החזרה אקספוננציאלית מ-5 s (OAuth) או 3 s (API key). מפתחות אחרים של אותו ספק ממשיכים לשרת.

#### אם דגם אחד יסרב

ה** נעילת דגם** חוסם רק את הדגם הזה בחיבור הזה לאחר דחיית גישה לכל דגם 429, 404 או דחיית גישה. דגמים אחרים באותו חיבור ממשיכים להגיש.

חיבורים אסורים, שפג תוקפם וחיבורים מחוץ לזכות הם מצבי קצה, לא התקררות: הם מחכים שתתקן אותם.

## סוכני CLIs & קידוד תואמים

רשימות קטלוג לוח המחוונים** 39 אינטגרציות** (28 כלי קידוד ו-11 סוכנים). המניפסט של CLI מוסיף Gemini CLI, המופעל עם `omniroute run`, וארבעה כלים שהוא יכול לזהות רק. מכולם,** 8** השקה עם `omniroute run`,** 12** ניתן להגדיר עם `omniroute configure`, ו** 16** יש פקודת `setup-*` ייעודית. בחר את הנתיב המתאים למה שאתה רוצה.

```bash
omniroute run claude   --model openai/gpt-5.4          # Claude Code
omniroute run codex    --model glm/glm-5.2             # Codex CLI
omniroute run aider    --model glm/glm-5.2 -- --message "reply OK"
omniroute run goose    --model glm/glm-5.2
omniroute run opencode --model glm/glm-5.2 -- run "reply OK"
omniroute run qwen     --model glm/glm-5.2 -- -p "reply OK"
omniroute run gemini   --model glm/glm-5.2 -- --skip-trust -p "reply OK"
omniroute setup-whycodes && omniroute run whycodes --model glm/glm-5.2

# Or pick provider and model interactively and write the tool's own config:
omniroute configure codex   # also: claude opencode qwen aider goose gemini whycodes cline continue kilo 5dive
```

כל פקודה מכבדת את ההקשר המרוחק הפעיל (`omniroute connect <host>`). `--dry-run` מדפיס את ה-env וה-args המדויק מבלי להפעיל דבר, ו- `--api-key-env NAME` שומר את המפתח מחוץ להיסטוריית המעטפת שלך. Qwen Code ו- Gemini CLI פועלים בבית זמני שנמחק ביציאה. WhyCodes קורא את הספק שלו רק מ- `config.toml`, אז הפעל `setup-whycodes` פעם אחת לפני `run whycodes`. → [CLI](docs/guides/CLI-INTEGRATIONS.md)

## מלא CLI, MCP ו- A2A

> OmniRoute שולחת עם לקוח שורת פקודה** 91 פקודות וקבוצות פקודות ברמה העליונה** (754 פקודות ספירת פקודות משנה), א** שרת MCP עם 110 כלים ו-33 היקפים** , ו-** סוכן A2A עם 6 כישורים** . סקריפטים, מסופים וסוכני AI יכולים כולם להפעיל את אותו שער.

### CLI אמיתי, לא רק `start`

```bash
omniroute                 # start the gateway and dashboard (port 20128)
omniroute setup           # guided first-run wizard
omniroute repl            # interactive chat in the terminal (/model /combo /skill /memory)
omniroute chat "hello"    # one-shot prompt; also reads --file or --stdin
omniroute doctor          # check config, database, ports, Node runtime and native deps
```

דגל `--output table|json|jsonl|csv` הגלובלי הופך את אותן פקודות לשימוש מסקריפטים ומ- CI.

### מצב מרוחק: CLI במחשב הנייד שלך, OmniRoute בשרת

היכנס פעם אחת לשרת מרוחק. ה- CLI שומר אותו בתור א** הֶקשֵׁר** , ופקודות מאוחרות יותר פועלות נגד השרת הזה עד שתעבור חזרה.

```bash
omniroute connect omniroute.example.com          # asks for the password, saves a scoped token as a context
omniroute models                                 # runs against the remote server
omniroute configure codex                        # picks a remote model, writes a local Codex profile
omniroute tokens create --name ci --scope read   # mint a narrower token for another machine
omniroute contexts use default                   # switch back to the local server
```

| היקף אסימון | <img width="2000" height="0" alt=""> מה זה מאפשר     |
| ----------- | ---------------------------------------------------- |
| `read`      | רשום ובדוק: דגמים, מצב, יומנים, שימוש                |
| `write`     | `read` plus להגדיר ולהחיל: הגדרת לקוח, מפתחות, תצורה |
| `admin`     | `write` plus לנהל: אסימונים, ספקים, שירותים, מדיניות |

מארח חשוף מקבל `http://` ופורט 20128; להעביר `https://` URL מלא כאשר השרת יושב מאחורי TLS. מסלולים שיכולים להוליד תהליכים נשארים ב-loopback בלבד, לא משנה מה האסימון.

## חסוך 15–95% אסימונים — באופן אוטומטי

### איך זה עובד — pipeline, אדריכלות וחיסכון מתמטיקה

<img src="./docs/diagrams/compression-pipeline.svg" width="100%" alt="OmniRoute compression pipeline: an illustrative 10,000-token client request passes through 12 composable engines — Session-Dedup, CCR, Lite, RTK, Responses Tool Output, Headroom, Relevance, Caveman, Aggressive, LLMLingua-2, Ultra and OmniGlyph — and can reach the provider at about 1,080 tokens in the documented stacked example. Structured content is protected by preservation guards and per-step fidelity gates; explicit lossy or experimental modes may transform eligible content."/>

שילוב מוערם המוגדר כברירת מחדל פועל `RTK → Caveman`. כאשר שניהם פועלים על אותו מטען tool/context, מתחם חיסכון:

```txt
combined = 1 − (1 − RTK) × (1 − Caveman_input)
average  = 1 − (1 − 0.80) × (1 − 0.46) = 89.2%
range    = 78.4 – 94.6%
```

בלוקי קוד, URLs, JSON ונתונים מובנים הם** מוגן תמיד** על ידי מנוע השימור.

> **למה להשתמש בהרבה אסימונים כאשר מעט אסימונים עושים את העבודה?** כל בקשה עוברת דרך צינור הדחיסה של OmniRoute** בשקיפות** — ללא שינויים בלקוח. עכשיו זה א** ערימה של 12 מנועים הניתנים לחיבור** שפועלים לפי הסדר ומערבבים ומתאימים לכל משולבת ניתוב — בונים על רעיונות מ- [RTK](https://github.com/rtk-ai/rtk), [Caveman](https://github.com/JuliusBrussee/caveman) (⭐ 90K +), [LLMLingua-2](https://github.com/microsoft/LLMLingua) ו- [Troglodita](https://github.com/leninejunior/troglodita) (PT-BR).

## שיטות התקנה נוספות — Docker, source, pnpm, Arch

**🐳 Docker**

```bash
docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 \
  -p 127.0.0.1:20128:20128 -v omniroute-data:/app/data cheaperinference/omniroute:latest
```

`:latest` עוקב אחר הגבוה ביותר** פורסם** יציב SemVer. זה לא עוקב אחר git `main`. Pin `:X.Y.Z` עבור GitOps. ראה [ערוצי שחרור Docker](docs/guides/DOCKER_GUIDE.md#release-channels).סיכות התמונה**`OMNIROUTE_MEMORY_MB=1024`** . זה מספיק ללוח המחוונים ולשיחה קלה.** סוכני קידוד** (`POST /v1/responses` מ- Claude Code, Codex, Grok, …) צריך ערימת V8 גדולה בהרבה או שהתהליך `FATAL ERROR` s ב- ~ 12 GiB תחת שני הקשרים ארוכים חופפים. גודל המיכל מעל הערימה (מאגרים מקוריים יושבים מחוץ ל-V8):

| עומס עבודה <img width="2000" height="0" alt=""> | ערימה (`-e OMNIROUTE_MEMORY_MB`) | מיכל (`--memory`) |
| ----------------------------------------------- | -------------------------------- | ----------------- |
| לוח מחוונים / צ'אט קל                           | `1024` (ברירת מחדל של תמונה)     | ≥ 2 גרם           |
| סוכן קידוד אחד                                  | `8192`                           | ≥ 10 גרם          |
| שני `/v1/responses` ארוכים במקביל               | `10240`–`12288`                  | ≥ 12-16 גרם       |

```bash
docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 \
  -e OMNIROUTE_MEMORY_MB=8192 --memory=10g \
  -p 127.0.0.1:20128:20128 -v omniroute-data:/app/data cheaperinference/omniroute:latest
```

טבלה מלאה: [Docker Guide — runtime RAM](docs/guides/DOCKER_GUIDE.md#runtime-ram-for-coding-agents).

> **ערוץ Docker בהוצאה מוקדמת:** `diegosouzapw/omniroute:next` ו- `diegosouzapw/omniroute:next-web` עוקבים אחר ענף ברירת המחדל הנוכחי `release/v*`. התגים הניתנים לשינוי נועדו רק לבדיקת תיקונים שטרם פורסמו והם נועדו** לא נתמך לייצור** . ראה [ערוצי שחרור Docker](docs/guides/DOCKER_GUIDE.md#release-channels).

**🥟 Bun**

`bun install` סטנדרטי והתקנה גלובלית (`bun install -g omniroute`) נתמכות באמצעות זיהוי זמן ריצה Bun :

- **`bun:sqlite` מובנה** : OmniRoute משתמש בדריבר `bun:sqlite` המובנה של Bun כאשר הוא פועל תחת Bun, נופל בחזרה ל- `better-sqlite3` ב- Node.js או `sql.js`.
- **בחירת Webpack Bunler אוטומטית ב-dev** : הפיתוח (`bun run dev`) מזהה אוטומטית Bun ומשבית Turbopack לטובת Webpack כדי למנוע אי-התאמה מקורית של קישור V8. ייצור ייצור (`bun run build`) עוקב אחר `OMNIROUTE_USE_TURBOPACK` בדיוק כמו ב-Node: Turbopack כברירת מחדל, `OMNIROUTE_USE_TURBOPACK=0` לבנייה עם Webpack (`Dockerfile.bun` חושף אותו כ- `--build-arg`).
- **Bun Dockerfile ייעודי** : `Dockerfile.bun` רב-שלבי עבור פריסות ייצור מקוריות Bun (`docker build -f Dockerfile.bun -t omniroute:bun .`).

```bash
# Install and run with Bun
bun install
bun run dev
```

ב- macOS או Windows, Podman משתמש ב-Podman Machine מרוחק: דלג על `podman unshare` ופעל לפי [הנחיות ספריית הנתונים הספציפיות לטופולוגיה](contrib/podman/README.md#data-directory-permissions-by-topology).

📖 [Podman Guide](contrib/podman/README.md) — Compose builds, Podman Machine והגדרת Linux/systemd Quadlet.

**⚡ התקנה מהירה / רזה יותר (דלג על המבנה המקורי)**

מנוע SQLite המקורי (`better-sqlite3`) הוא an** אופציונלי** תלות, כך שהתקנה גלובלית אף פעם לא חוסמת קומפילציה מהמקור: היא משתמשת בבינארי שנבנה מראש כאשר אחד תואם את platform/Node שלך, ובדרך אחרת נופלת בחזרה בשקיפות למנוע JS טהור (`node:sqlite` ב-Node 22 +, אחרת ה- `sql.js` WASM המצורף) — אין צורך בכלי בנייה.

כדי לדלג על לאחר ההתקנה** חימום מקומי** לחלוטין (מכונות CI, חסרות ראש או איטיות). הערה: זה מדלג רק על שלב החימום המקורי של SQLite (`scripts/postinstall.mjs`); ה- binary-copy/repair hook (`scripts/build/postinstall.mjs`) עדיין פועל כרגיל:

```bash
OMNIROUTE_SKIP_POSTINSTALL=1 npm install -g omniroute   # CI=1 also skips it
```

עבור ההתקנות המהירות ביותר העדיפו** pnpm** (חנות עם כתובת תוכן + hard links — ראה למעלה). לזמן ריצה ללא לוח מחוונים וללא ראש, השתמש בפרופיל Docker `base` (למעלה) או [במדריך Termux](docs/guides/TERMUX_GUIDE.md). ה- CLI ולוח המחוונים של האינטרנט משרתים באותו תהליך ביציאה אחת, כך שאין כיום חבילה נפרדת ל-CLI בלבד.

## תודות

OmniRoute עומד על כתפי ענקים. זה התחיל כמזלג של** [9 נתב](https://github.com/decolua/9router)** ויציאת TypeScript של פרויקט Go** [CLIProxyAPI](https://github.com/router-for-me/CLIProxyAPI)** — ומשם, כל תת-מערכת למטה נוצרה בהשראת פרויקט קוד פתוח שהגיע לשם ראשון. כל אחד מהם עיצב פיסת בטון של OmniRoute. זוהי התודה שלנו לכולן. 🙏

> ספירת כוכבי ⭐ מאומתת מ- REST API של GitHub ב-16 בנובמבר, 2026. — go תן כוכב לפרויקטים האלה. הספירות הן תמונת מצב מתוארכת מדויקת וישתנו באופן טבעי. GrokBridge החזיר את HTTP 404 באותו תאריך; ייחוסו נשמר.
