## Ilmaisia rahakkeita kuukaudessa: ~ 11.3B kuten muut määrät · ~ 90M Real

</div>

> **~ 11.3B ilmaisia tokeneita / kuukausi**<br/> <sub> laskettiin samalla tavalla kuin muut luettelot: jokainen rivi lasketaan yhteen, päättyneet tarjoukset sisällytettiin </sub>
>
> **~ 90M real tänään**<br/> <sub> Jokainen jaettu kiintiö lasketaan kerran: mitä voit todella käyttää </sub>
>
> **Kaikki täällä on ilmaista. Ei maksumuuria.**<br/> ★ [Pidätkö siitä? Merkitse meidät GitHub](https://github.com/cheaper-inference/OmniRoute)

Muut luettelot veloittavat US sta 19 dollaria vuodessa 49 dollariin US 49 dollariin elinikäisestä reaaliaikaisten tietojen käyttöoikeudesta. Täällä kaikki on ilmaista. <sub> Hinnat tarkistettu 18.11.2026.</sub>

<sub>Katalogi tarkastettu viimeksi 23.11.2026. [Kuinka laskemme →](docs/reference/FREE_TIERS.md#how-we-count)</sub>

> **Tuo omat palveluntarjoajan tilit.** Nämä ovat kolmannen osapuolen ilmaisia tasoja, eivät OmniRoute tunnuslahjoja. Rekisteröidy, hanki tunnistetiedot, jos palveluntarjoaja niitä pyytää, ja yhdistä ne, joita voit käyttää. Jokainen palveluntarjoaja asettaa omat rajansa, saatavuutensa ja ehdot.
>
> Ilmaisten tasojen pinoaminen käsin tarkoittaa kymmeniä SDKs, kymmeniä hintarajoja eikä selkeää käsitystä siitä, mitä sinulla on jäljellä. OmniRoute säilyttää 214 luetteloriviä vapaasti ja laskee todellisen luvun 12 poolista, joilla on julkaistu kiintiö, ja jokainen jaettu pooli lasketaan kerran. Kiintiöt, jotka avautuvat vasta alueellisen henkilöllisyyden tarkistuksen jälkeen (tänään, ModelScope), näytetään erillään, +~ 6M alueellisen henkilöllisyyden vahvistuksen takana, eikä niitä koskaan lisätä todelliseen lukuun. Jäljellä oleva näkyy kojelaudassa (`/dashboard/free-tiers`).

## Asenna, yhdistä palveluntarjoaja ja reititä sitten yhden päätepisteen kautta

<img src="./docs/diagrams/works-zero-config.svg" width="100%" alt="Four steps to use OmniRoute. Install with npm install -g omniroute, run omniroute, connect a provider and create an API key in the dashboard, then call http://localhost:20128/v1 with model auto."/>

```bash
# After connecting a provider, create your OmniRoute key in Dashboard → API Keys:
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer YOUR_OMNIROUTE_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"auto","messages":[{"role":"user","content":"Hello!"}]}'
```

<sub>`auto` tarvitsee kelvollisen reitin. Uudella asennuksella ei voi olla kelvollisia avaimettomia kohteita, ja avaimeton toimittaja voi hylätä kolmannen osapuolen asiakkaat. ## Yhdistelmät: lippulaiva

1. **Aloita `auto`.** Aseta malli OpenAI-yhteensopivassa asiakasohjelmassasi. OmniRoute rakentaa virtuaalisen yhdistelmän yhdistetyistä palveluntarjoajista ja tekee ehdokkaita livenä.
2. **Tallenna yhdistelmä saadaksesi enemmän hallintaa.** Valitse nimi, kohdeluettelo ja strategia ja käytä sitten sitä nimeä mallina. Strategia määrittää, mikä tavoite menee ensin ja miten loput yritetään.

Yhdistelmä reitittää mallien välillä automaattisesti. Kiintiön umpeutumisen, palveluntarjoajan epäonnistumisen tai mallin sulkemisen yhteydessä se yrittää seuraavaa kelvollista, tervettä kohdetta.

### Zero-config: käytä vain `auto`

```bash
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <your-omniroute-key>" \
  -H "Content-Type: application/json" \
  -d '{"model": "auto", "messages": [{"role": "user", "content": "Hello"}]}'
```

Vaihtoehdot säätelevät painoja. Viimeisin tunnettu-hyvä reititys pysyy viimeisellä onnistuneella palveluntarjoajalla, kunnes se epäonnistuu, ja tekee sitten pisteytyksen uudelleen. `auto/fast` ja `auto/cheap` ilmaisevat mieltymykset takaamatta nopeinta tai halvinta mallia.

| Malli ID            | Käyttäytyminen                                                                                                                                                                                                                                                                                              |
| :------------------ | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `auto`              | Tasapainotetut oletuspainot.                                                                                                                                                                                                                                                                                |
| `auto/fast`         | Suosii matalaa latenssia ja palveluntarjoajan terveyttä.                                                                                                                                                                                                                                                    |
| `auto/cheap`        | Suosii alempia luettelohintoja.                                                                                                                                                                                                                                                                             |
| `auto/coding`       | Laatu-ennen painot koodin luomiseen.                                                                                                                                                                                                                                                                        |
| `auto/smart`        | Laatu-ensisijaiset painot 10 %:n etsinnällä (oletusarvo 5%).                                                                                                                                                                                                                                                |
| `auto/lkgp`         | Selkeä viimeisin tunnettu-hyvä reititys samoilla painoarvoilla kuin `auto`.                                                                                                                                                                                                                                 |
| `auto/subscription` | Käyttää vain reaaliaikaisesti vahvistettua suunnitelmakiintiötä. Palauttaa HTTP 503:n, kun sellaista ei ole saatavilla, ja välttää laskutetun varaosan.                                                                                                                                                     |
| `auto/thrifty`      | Suunnittele → avaimeton → ilmainen → halpa → premium. Saattaa saavuttaa laskutetut mallit ja palata suunnitelmaan, kun kiintiö ja jäähdytys sen sallivat.                                                                                                                                                   |
| `auto/offline`      | Suosii kiintiötä ja korkorajoitusta. Pyynnöt menevät edelleen palveluntarjoajillesi.                                                                                                                                                                                                                        |
| `auto/chaos`        | Yksi malli palveluntarjoajaa kohden rinnakkain, oletusarvoisesti enintään viisi tai konfiguroituna kymmenen. Yksi alkusoitto per malli. Palauttaa parhaan vastauksen tai viimeisen onnistuneen paneelivastauksen, jos huippumalli epäonnistuu. Käytä `fusion` syntetisoidaksesi vastaukset tuomarin kanssa. |

Luokka- ja valinnaiset tasoesimerkit sisältävät `auto/coding:fast`, `auto/coding:free`, `auto/reasoning:pro` ja `auto/vision`. Jos yksikään yhdistetty ehdokas ei vastaa, pyyntö palauttaa HTTP 503 ja pooli pysyy kapeana. [Automaattinen yhdistelmäopas](./docs/routing/AUTO-COMBO.md) · [Tilauksen ensimmäinen reititys](./docs/routing/SUBSCRIPTION_LADDER.md)

### Tai rakenna oma: 22 reititysstrategiaa

```bash
omniroute combo create my-pool --strategy fill-first \
  --models "provider-a/model-1,provider-b/model-2"
```

CLI hyväksyy 15 strategiaa 22:sta. Kojelauta ja API -yhdistelmät hyväksyvät kaikki 22.

| strategia           | Käyttäytyminen                                                                                                                                                                                                                       |

### Joustavuus on sisäänrakennettu: 3 itsenäistä kerrosta

Vikoja käsitellään kolmella alueella, joten yksi huono malli ei poista tiliään ja yksi huono tili ei poista toimittajaansa.

<img src="./docs/diagrams/resilience-layers.svg" width="100%" alt="OmniRoute resilience: 3 independent self-healing layers, the right layer for the right failure. Layer 1, provider circuit breaker (whole provider): trips only on 408/500/502/503/504, opens after 8 failures for OAuth providers or 12 for API-key providers, resets after 60s or 30s into a HALF-OPEN probe, lazy recovery; while OPEN the combo reroutes to the next provider. Layer 2, connection cooldown (one key or account): base 5s OAuth or 3s API-key, exponential backoff with an anti-thundering-herd guard, success clears the error state; one cooling key is skipped while sibling keys keep serving. Layer 3, model lockout (one model): per-model 429, 404 or access denials lock just that model, never the whole connection. Terminal states (banned, expired, credits exhausted) wait for the operator; they are not cooldowns."/>

#### Jos koko palveluntarjoaja on kaatunut

The** toimittajan katkaisija** avautuu 8 (OAuth) tai 12 (API -näppäin) virheen jälkeen tilalla 408, 500, 502, 503 tai 504. Yhdistelmät ohittavat kyseisen tarjoajan sen ollessa auki. 60 s tai 30 s kuluttua yksi anturipyyntö päättää, sulkeutuuko se.

#### Jos yksi avain tai tili on korkorajoitettu

The** yhteyden jäähdytys** penkit vain tuon yhteyden eksponentiaalisella perääntymisellä 5 s (OAuth) tai 3 s (API näppäin). Muut saman palveluntarjoajan avaimet toimivat edelleen.

#### Jos yksi malli hylätään

The** mallin lukitus** estää vain kyseisen mallin kyseisessä yhteydessä mallikohtaisen 429-, 404- tai pääsykiellon jälkeen. Muut samassa liitännässä olevat mallit palvelevat edelleen.

Kielletyt, vanhentuneet ja luottokelpoiset yhteydet ovat päätetiloja, eivät viilennyksiä: ne odottavat, että korjaat ne.

## Täysi CLI, MCP ja A2A

> OmniRoute toimittaa komentoriviasiakkaan** 91 ylätason komentoa ja komentoryhmää** (754 komentoa alikomennot mukaan lukien), an**MCP palvelin, jossa on 110 työkalua ja 33 skooppia** , ja an**A2A -agentti, jolla on 6 taitoa** . Skriptit, päätteet ja AI -agentit voivat kaikki käyttää samaa yhdyskäytävää.

### Todellinen CLI, ei vain `start`

```bash
omniroute                 # start the gateway and dashboard (port 20128)
omniroute setup           # guided first-run wizard
omniroute repl            # interactive chat in the terminal (/model /combo /skill /memory)
omniroute chat "hello"    # one-shot prompt; also reads --file or --stdin
omniroute doctor          # check config, database, ports, Node runtime and native deps
```

Maailmanlaajuinen `--output table|json|jsonl|csv` lippu tekee samat komennot käytettäviksi skripteistä ja CI.

### Etätila: CLI kannettavassa tietokoneessa, OmniRoute palvelimella

Kirjaudu sisään kerran etäpalvelimelle. CLI tallentaa sen nimellä a** yhteydessä** , ja myöhemmät komennot toimivat kyseistä palvelinta vastaan, kunnes vaihdat takaisin.

```bash
omniroute connect omniroute.example.com          # asks for the password, saves a scoped token as a context
omniroute models                                 # runs against the remote server
omniroute configure codex                        # picks a remote model, writes a local Codex profile
omniroute tokens create --name ci --scope read   # mint a narrower token for another machine
omniroute contexts use default                   # switch back to the local server
```

| Token laajuus | <img width="2000" height="0" alt=""> Mitä se sallii                        |
| ------------- | -------------------------------------------------------------------------- |
| `read`        | Listaa ja tarkista: mallit, tila, lokit, käyttö                            |
| `write`       | `read` plus määritä ja käytä: asiakasasetukset, avaimet, konfigurointi     |
| `admin`       | `write` plus hallinnoi: tunnukset, palveluntarjoajat, palvelut, politiikka |

Paljas isäntä saa `http://` ja portin 20128; antaa täyden `https://` URL, kun palvelin on TLS takana. Reitit, jotka voivat synnyttää prosesseja, pysyvät vain silmukan kautta riippumatta tunnuksesta.

### Yhdistä agentti

Agentti tai oma koodisi voi ohjata reititystä, palveluntarjoajia, komboja, välimuistia, pakkausta ja muistia minkä tahansa näistä liitännöistä. HTTP polkuja palvelee yhdyskäytävä, oletuksena osoitteessa `http://localhost:20128`.

| Käyttöliittymä                 | Päätepiste tai komento     | Käytä sitä varten                                                                            |
| ------------------------------ | -------------------------- | -------------------------------------------------------------------------------------------- |
| MCP yli stdio                  | `omniroute --mcp`          | Claude Desktop, Cursor ja muut paikalliset MCP asiakkaat                                     |
| MCP suoratoiston HTTP n kautta | `/api/mcp/stream`          | Etä- MCP -asiakkaat: 110 työkalua, 33 laajuutta, jokainen tarkastuslokiin kirjoitettu puhelu |
| MCP yli SSE                    | `/api/mcp/sse`             | Asiakkaat, jotka edelleen käyttävät SSE -kuljetusta                                          |
| A2A löytö                      | `/.well-known/agent.json`  | Agenttikortti: kertoo muille agenteille, mitä OmniRoute voi tehdä                            |
| A2A teloitus                   | `POST /a2a`                | JSON-RPC 2.0 -tehtävät, synkroniset tai suoratoistetut SSE kautta, 6 taidolla                |
| REST API                       | `/v1/*`                    | OpenAI-yhteensopiva chat, vastaukset, upotukset, kuvat, ääni ja OCR                          |
| Webhooks                       | `/api/webhooks`            | Tapahtumat Slack, Discord, Telegram tai mihin tahansa URL HMAC - allekirjoituksella          |
| Kaukosäädin CLI                | `omniroute connect <host>` | Ohjaa etäilmentymää suojatuilla käyttöoikeuksilla                                            |

Kuusi A2A -taitoa ovat `smart-routing`, `quota-management`, `provider-discovery`, `cost-analysis`, `health-report` ja `list-capabilities`.

**Ennen yhteyden muodostamista:**

- **MCP over HTTP alkaa poissa käytöstä.** Ota se käyttöön `omniroute mcp enable --transport streamable-http` llä tai kojelaudan Päätepisteet-sivulta. Yksi HTTP -siirto on aktiivinen kerrallaan: `streamable-http` palvelee `/api/mcp/stream`, `sse` palvelee `/api/mcp/sse`.
- **A2A käynnistyy pois käytöstä.** Ota se käyttöön kojelaudan Päätepisteet-sivulla. `POST /a2a` noudattaa sitten samoja API-avainsääntöjä kuin `/v1`.
- **Kauko- MCP tarvitsee sopivan avaimen.** `/api/mcp/*` vastaa oletuksena vain loopbackiin. Lähetä avain toisesta isännästä `manage` llä tai `admin` (kaikki työkalut) tai `mcp:connect` llä plus tarvittavien työkalujen laajuudet. Näppäimillä, joissa ei ole `manage`/`admin`, työkalualueet pakotetaan aina.

```bash
# Give Claude Code the OmniRoute toolset over MCP:
omniroute mcp enable --transport streamable-http
claude mcp add --transport http omniroute http://localhost:20128/api/mcp/stream \
  --header "Authorization: Bearer <api-key-with-manage-scope>"
```

## Säästä 15–95 % Tokeneista — automaattisesti

### Kuinka se toimii — pipeline, arkkitehtuuri ja säästöjen matematiikka

<img src="./docs/diagrams/compression-pipeline.svg" width="100%" alt="OmniRoute compression pipeline: an illustrative 10,000-token client request passes through 12 composable engines — Session-Dedup, CCR, Lite, RTK, Responses Tool Output, Headroom, Relevance, Caveman, Aggressive, LLMLingua-2, Ultra and OmniGlyph — and can reach the provider at about 1,080 tokens in the documented stacked example. Structured content is protected by preservation guards and per-step fidelity gates; explicit lossy or experimental modes may transform eligible content."/>

Pinottu oletusyhdistelmä ajaa `RTK → Caveman`. Kun molemmat toimivat samalla tool/context -hyötykuormalla, säästöyhdiste:

```txt
combined = 1 − (1 − RTK) × (1 − Caveman_input)
average  = 1 − (1 − 0.80) × (1 − 0.46) = 89.2%
range    = 78.4 – 94.6%
```

Koodilohkot, URLs, JSON ja strukturoitu data ovat** aina suojattu** säilytysmoottorilla.

> **Miksi käyttää monia tokeneita, kun harvat rahakkeet tekevät tempun?** Jokainen pyyntö kulkee OmniRoute pakkausputken kautta** läpinäkyvästi** — ei asiakasmuutoksia. Se on nyt a** pino 12 komposoitavaa moottoria** jotka toimivat järjestyksessä ja yhdistelevät reititysyhdistelmää — joka perustuu [RTK](https://github.com/rtk-ai/rtk), [Cavemanin](https://github.com/JuliusBrussee/caveman) (⭐ 90K +), [LLMLingua-2](https://github.com/microsoft/LLMLingua) ja [Trogloditan](https://github.com/leninejunior/troglodita) (PT-BR) ideoihin.

**⚡ Nopeampi / kevyempi asennus (ohita alkuperäinen koontiversio)**

Alkuperäinen SQLite moottori (`better-sqlite3`) on** valinnainen** riippuvuus, joten globaali asennus ei koskaan estä kääntämistä lähteestä: se käyttää valmiiksi rakennettua binaaria, kun se vastaa platform/Node täsi, ja muutoin palaa läpinäkyvästi puhtaaseen JS-moottoriin (`node:sqlite` solmussa 22 +, muuten niputettu `sql.js` WASM) — ei vaadi rakennustyökaluja.

Jälkiasennuksen ohittaminen** natiivi lämmittely** kokonaan (CI, päättömät tai hitaat koneet). Huomautus: tämä ohittaa vain alkuperäisen SQLite -alennusvaiheen (`scripts/postinstall.mjs`); binary-copy/repair koukku (`scripts/build/postinstall.mjs`) toimii edelleen normaalisti:

```bash
OMNIROUTE_SKIP_POSTINSTALL=1 npm install -g omniroute   # CI=1 also skips it
```

Nopeimpia asennuksia varten** pnpm** (sisältöosoitteellinen kauppa + kovat linkit — katso yllä). Käytä Docker `base` -profiilia (yllä) tai [Termux-opasta](docs/guides/TERMUX_GUIDE.md) saadaksesi kojelautattoman, päättömän suoritusajan. CLI ja web-hallintapaneelia palvelee sama prosessi yhdessä portissa, joten erillistä vain CLI-pakettia ei ole olemassa.

### Kuinka osallistua

1. Haarukka arkiston
2. Haara alkaen** aktiivinen** `release/vX.Y.Z` kärki (ei `main`) — katso [Haaroitus- ja vapautusmalli](docs/ops/BRANCHING_MODEL.md)
3. Luo ominaisuushaara (`git checkout -b feat/amazing-feature`)
4. Tee muutokset (`git commit -m 'feat: add amazing feature'`)
5. Työnnä oksalle (`git push origin feat/amazing-feature`)
6. Avaa vetopyyntö sovelluksella** perusta = että `release/vX.Y.Z` haara**

Katso tarkemmat ohjeet kohdasta [CONTRIBUTING.md](CONTRIBUTING.md).

OmniRoute seisoo jättiläisten harteilla. Se alkoi haarukalla** [9 reititin](https://github.com/decolua/9router)** ja Go-projektin TypeScript portti** [CLIProxyAPI](https://github.com/router-for-me/CLIProxyAPI)** — ja sieltä jokainen alla oleva alijärjestelmä sai inspiraationsa avoimen lähdekoodin projektista, joka pääsi sinne ensin.
