## Luokat

- **Ilmainen** — ilmainen taso API-avaimella (määritetty hallintapaneelin kautta)
- **Ei-todennusta** — julkiset päätepisteet, jotka eivät vaadi avainta tai kirjautumista lainkaan
- **OAuth** — OmniRouten käsittelemä sisäänkirjautumisvirta, API-avainta ei tarvita
- **Verkkokeksi** — käärii palveluntarjoajan verkkosovelluksen evästetodennuksen kautta
- **API-avain** — maksullinen palveluntarjoaja, joka on määritetty API-avaimella (ilmaisia krediittejä voi olla saatavilla)
- **Paikallinen** — toimii käyttäjän koneella (Ollama, LM Studio, vLLM jne.)
- **Haku** — verkkohakupalveluntarjoajat
- **Ääni** — vain ääntä käyttävät palveluntarjoajat (TTS/STT)
- **Ylävirran välityspalvelin** — palveluntarjoajat, jotka välittävät pyyntöjä muille palveluntarjoajille
- **Pilviagentti** — pitkäkestoiset koodausagentit (Codex Cloud, Devin, Jules)
- **Järjestelmä** — OmniRouten sisäiset palveluntarjoajat (loopback jne.)

Lisätunnisteet: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Työkalukutsu` (jos näkyvissä): `native` — todellinen funktionkutsu-API; `emulated` — `tools`-taulukko emuloidaan kehotteella `webTools.ts`:n kautta (regex-jäsennetty `<tool>{...}</tool>`-lohkot); `none` — `tools` pudotetaan tällä hetkellä hiljaisesti. Katso #7286.

Käytä hallintapaneelia osoitteessa `/dashboard/providers` ottaaksesi käyttöön, määrittääksesi ja testataksesi jokaisen palveluntarjoajan.
