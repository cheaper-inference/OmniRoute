> **TL;DR** : 귀하의 적격 제공자 계정을 가져오십시오. OmniRoute 사용자가 구성한 연결을 결합합니다. 광고된 집계 토큰 예산을 발행하지 않습니다. 무료 액세스에는 가입, API 키, 승인 또는 결제 방법이 필요할 수 있습니다. 공급자 제한, 개인 정보 보호 정책 및 약관은 계속 적용됩니다.

## 프리 티어란 무엇입니까?

많은 AI 제공업체는 다음과 같은 형태의 서비스를 제공합니다.** 무료 이용** . 공급자에 따라 이는 인증 없는 엔드포인트, 반복 할당량, 비율 제한이 없는 무제한 액세스, 가입 승인, 수동 승인 또는 임시 프로모션을 의미할 수 있습니다. 일부 옵션에는 계정, API 키, 신용 카드, KYC 또는 공급자별 약관 동의가 필요합니다.

OmniRoute** 집합체** 하나의 끝점에 연결을 구성했습니다. 계정이 필요한 각 제공업체에 대해 별도로 가입해야 합니다. 해당 계정을 연결하고 `model: "auto"` 사용하여 적격한 대상 간에 라우팅합니다. 새로 설치하면 적합한 키리스 대상이 없을 수 있습니다. OmniRoute 만 설치한다고 해서 성공적인 채팅 응답이 보장되는 것은 아닙니다.

## 프리 티어를 쌓는 방법

OmniRoute 의 마법은** 무료 계층 누적** . 하나의 공급자에 의존하는 대신 여러 무료 공급자를 연결하고 OmniRoute 자동으로 각 요청에 가장 적합한 공급자를 선택하도록 할 수 있습니다.

### 예: 더 넓은 무료 등급 적용 범위

여러 공급자를 연결하여 단일 할당량에 대한 의존도를 줄입니다.

1. **Gemini** — 반복 API 키 할당량
2. **Groq** — 반복 API 키 할당량
3. **수분** — 키리스, 속도 제한 액세스
4. **LongCat** — 일회성 가입 승인( KYC 필요)

그런 다음 `model: "auto"` 사용하면 OmniRoute 는 다음을 수행합니다.

- 가장 높은 순위의 적격 연결을 먼저 시도하십시오.
- 할당량 또는 상태 확인이 실패하면 → 다음으로 구성된 공급자를 시도하십시오.
- 키 없는 공급자를 사용할 수 없는 경우 → 나머지 대상을 계속 진행합니다.
- 적합한 연결이 성공하지 못하면 → 오류를 반환합니다. 가입 크레딧은 유효하고 사용 가능한 동안에만 사용할 수 있습니다.

**결과** : 자동 폴백 — 를 통한 더 넓은 무료 계층 적용 범위는 무제한 용량을 보장하지 않습니다.

## 무료 공급자를 연결하는 방법

### 1단계: 대시보드 열기

브라우저에서 `http://localhost:20128` 로 이동하세요.

### 2단계: 제공업체로 이동

딸깍 하는 소리** 공급자** 사이드바에서.

### 3단계: 공급자 추가를 클릭합니다.

다음을 클릭하세요.**+ 공급자 추가** 단추.

### 4단계: 무료 제공업체 선택

카탈로그를 탐색하고 각 공급자의 현재 `hasFree`, 인증, 할당량, 개인정보 보호 및 ToS 메타데이터를 검사하세요. 공급자 카드와 [무료 계층 참조는](../reference/FREE_TIERS.md) 반복 풀, uncapped/keyless 액세스, 가입 크레딧, 중단된 항목 및 고위험 소스를 구별합니다.

### 5단계: 연결을 클릭하세요.

`NOAUTH` 공급자의 경우 OmniRoute 업스트림 자격 증명을 요청하지 않습니다. 이는 업스트림이 타사 클라이언트를 수락하거나 사용 가능한 용량이 있음을 보장하지 않습니다. OAuth 및 API 키 공급자는 문서화된 계정 흐름을 통해 연결되어야 합니다. 귀하의 클라이언트는 여전히 다음에서 생성된 OmniRoute API 키를 사용하고 있습니다.** 대시보드 → API 키** (생성 시 한 번만 표시됨) 라우터 인증이 활성화된 경우.

### 6단계: 반복

귀하의 사용 사례에 맞는 조건과 개인정보 보호 모델을 갖춘 여러 제공업체를 연결하세요.

## dsh "우리의 무료 모델"에서 따옴

dsh 에이전트 호스트용 [dsh-our-free-model](https://github.com/Ebony-Vinyl/dsh-our-free-model) 플러그인은 두 개의 업스트림에 도달합니다. OmniRoute 에는 이미 각각에 대한 공급자가 있지만 그 중 하나만 OmniRoute 의 무료 경로입니다.

| 플러그인 레인 | 업스트림                                      | OmniRoute 공급자           | OmniRoute 에서는 무료인가요? | 연결 방법                                                            |
| ------------- | --------------------------------------------- | -------------------------- | ---------------------------- | -------------------------------------------------------------------- |
| 킬로 채널     | 킬로 AI 게이트웨이(`api.kilo.ai/api/gateway`) | `kilo-gateway` (별칭 `kg`) | 예                           | API 키 선택 사항: 게이트웨이의 무료 풀을 사용하려면 비워 두세요.     |
| 무료 차선     | OpenCode 젠(`opencode.ai`)                    | `opencode-zen`             | 아니요                       | [opencode.ai/zen](https://opencode.ai/zen) 의 나만의 OpenCode API 키 |

**킬로.** 무료 풀을 `kilo-gateway/<model>` 또는 `kg/<model>` 로 호출합니다(예: `kg/kilo-auto/free` (Kilo의 무료 자동 라우터) 또는 게이트웨이의 `:free` 모델 중 하나). 무료 세트는 회전합니다. `kilo-gateway` OmniRoute 의 내장 목록에 없는 모델 ID를 통과하므로 현재 게이트웨이 목록에 있는 모델은 카탈로그에 포함되기 전에 호출될 수 있습니다. Kilo의 무료 모델 카드에는 업스트림 공급자가 프롬프트를 기록하고 서비스 개선을 위해 사용될 수 있으므로 민감한 데이터를 보내지 말라고 나와 있습니다.

**OpenCode.** 플러그인의 무료 차선은 OpenCode 의 키 프리 제공입니다. OmniRoute 해당 제안을 무료 액세스로 제공하지 않습니다.

- OmniRoute 의 키 없는 OpenCode 공급자는 OpenCode 운영자의 요청으로 제거되었습니다( [제거된 공급자](../reference/REMOVED_PROVIDERS.md) 참조).
- OpenCode 의 [엔드포인트 문서는](https://opencode.ai/v2/docs/console/models/#endpoints) 무료 채팅 제안을 OpenCode 의 자체 클라이언트와 연결하므로 OmniRoute 이를 무료로 계산하거나 배지를 지정하지 않습니다.

`deepseek-v4.1-flash-free`, `mimo-v2.6-flash-free` 및 `nemotron-3.5-lightning-free` 와 같이 플러그인이 표시하는 모델 ID는 `opencode-zen` 카탈로그에 있습니다. `opencode-zen` 자신의 OpenCode 키와 연결하여 OpenCode 계정 조건에 따라 사용하세요.

**플러그인의 로컬 포트입니다.** 플러그인은 로컬 OpenAI 호환 포트(기본값 `18899`)에 해당 모델을 노출할 수 있습니다. 이러한 엔드포인트는 [사용자 정의 OpenAI 호환 공급자](../guides/USER_GUIDE.md#custom-openai-compatible-providers) 로 추가될 수 있지만 OmniRoute 플러그인을 설치, 시작 또는 업데이트하지 않으며 플러그인은 각 요청을 처리할 업스트림을 결정합니다. 위의 OpenCode 제한 사항은 클라이언트가 요청을 보내는 OpenCode 의 제안에 적용됩니다.

## 카탈로그를 올바르게 읽으십시오

- `NOAUTH` OmniRoute 공급자 자격 증명을 요구하지 않는다는 것을 의미합니다. 가동 시간, 개인 정보 보호 또는 무제한 용량을 보장하지 않습니다.
- `hasFree` 는 검색 메타데이터입니다. 반복 할당량, 키 없는 액세스, 가입 크레딧, 승인 프로그램 또는 프로모션을 나타낼 수 있습니다.
- `recurring-uncapped` 게시된 토큰 한도가 없음을 의미합니다. 속도 및 동시성 제한은 계속 적용됩니다.
- 가입 권한이 소모된 후에는 `one-time-initial` 반복되지 않습니다.
- `tos: avoid` 공급자는 기본적으로 자동 라우팅에서 제외됩니다(`excludeTosAvoid`). 계정 연결은 이 필터를 우회하지 않습니다. 모든 운영자 재정의는 공급자 약관 및 계정 위험에 대한 검토를 따라야 합니다.
- `discontinued` 로 표시된 항목은 역사적 증거로 남아 있으며 현재 무료인 것으로 표시되어서는 안 됩니다.

## OmniRoute 무료 계층을 개선하는 방법

### 1. 자동 폴백

하나의 무료 제공자가 사용 중이거나 다운되면 OmniRoute 자동으로 다음 제공자를 시도합니다. 아무것도 할 필요가 없습니다.

### 2. 스마트 라우팅

OmniRoute 골라요** 최고의 무료 제공업체** 각 요청에 대해 다음을 기준으로 합니다.

- 속도 — 지금 어느 제공업체가 가장 빠른가요?
- 품질 — 이 작업에 가장 적합한 공급자는 무엇입니까?
- 용량 — 어떤 공급자에게 남은 할당량이 있습니까?

### 3. 토큰 절약

OmniRoute 의 압축 파이프라인은 적합한 프롬프트 및 도구 출력 토큰을 줄일 수 있습니다. 실제 절감액은 콘텐츠, 선택한 엔진, 공급자 계정 및 충실도 설정에 따라 다릅니다. 압축은 모든 공급자 할당량에 고정된 양을 곱하지 않습니다.

### 4. 다중 계정 지원

공급자 조건이 여러 계정이나 자격 증명을 허용하는 경우 OmniRoute 각 연결을 별도의 라우팅 후보로 처리할 수 있습니다. 공급자의 할당량이나 액세스 정책을 회피하기 위해 추가 계정을 만들지 마십시오.

실시간 풀 중복 제거 카탈로그는 현재 다음을 보고합니다.

| 미터법                       |                현재 감사된 값 | 해석                                                                      |
| ---------------------------- | ----------------------------: | ------------------------------------------------------------------------- |
| 반복적으로 정량화된 보조금   |   **~ 90M 무료 tokens/month** | 공유 풀은 한 번만 계산됩니다. 한도가 없는 제공업체는 합계에서 제외됩니다. |
| 가입 보조금이 제공되는 첫 달 | **첫 달에 ~ 1억 5300만 달러** | 반복 총액에 일회성 및 반복 크레딧을 더한 금액                             |

이는 OmniRoute 에서 제공한 허용량이나 신규 설치에 대한 예측이 아닌 별도의 적격 계정에 대한 카탈로그 전체 추정치입니다. 사용 가능한 용량은 연결하는 공급자와 현재 조건에 따라 다릅니다. 값은 `open-sse/config/freeModelCatalog.ts` 에서 계산됩니다. 풀 중복 제거, ToS 플래그, 중단된 항목 및 가입 크레딧 방법에 대해서는 [무료 계층 참조를](../reference/FREE_TIERS.md) 참조하세요.

## 일반적인 질문

### "이게 정말 무료인가요?"

카탈로그에는 공급자가 게시한 용어와 프로젝트 조사가 기록되어 있지만 제안은 변경될 수 있습니다. 사용하기 전에 공급자의 현재 가격, 할당량, 개인 정보 보호 정책 및 자격을 확인하십시오.

### "무료 등급이 만료되나요?"

모든 공급자는 속도 제한, 모델 변경, 액세스 일시 중지 또는 오프라인 전환을 할 수 있습니다. 다중 연결은 대체 적용 범위를 향상시키지만 사용 가능한 무료 경로를 보장하지는 않습니다.

### "프로덕션에 무료 공급자를 사용할 수 있나요?"

공급자의 SLA, 데이터 처리, 제한 및 조건이 프로덕션 요구 사항을 충족하는 경우에만 가능합니다. 중요한 워크로드는 계약상 적합한 폴백을 모니터링해야 합니다.

### "뭔가 문제야?"

트레이드오프에는 엄격한 한도, 대기자 명단, KYC, 신용 카드 확인, 프롬프트에 대한 교육, 약한 개인 정보 보호, SLA 없음, 모델 이탈, 지리적 제한, 유료 초과분 또는 계정 정책 위험이 포함될 수 있습니다. OmniRoute 사용 가능한 메타데이터를 표시합니다. 활성화할 항목을 선택합니다.

### "무료 할당량을 더 얻으려면 어떻게 해야 하나요?"

1. 더 많은 무료 공급자 연결
2. 적절한 압축 엔진을 활성화하고 워크로드에 대한 절감 효과를 측정하세요.
3. `auto/cheap` 사용하여 free/cheap 공급자의 우선순위 지정
4. 공급자 약관을 위반하지 않고 추가로 허용된 공급자 또는 자격 증명을 추가하세요.

### "무료 제공업체의 품질이 더 나쁩니까?"

반드시 그런 것은 아닙니다. 일부 공급자는 유료 경로를 통해 사용 가능한 동일한 모델 계열을 공개하지만 제한, 대기 시간, 개인 정보 보호, 안정성 및 모델 버전은 다를 수 있습니다. 무료 공급자 순위 페이지를 품질 신호로 사용하고 제공되는 실제 모델을 확인하세요.
