## OmniRoute를 선택해야 하는 경우

- 자체 호스팅을 사용하며 **최대한 넓은 프로바이더 지원 범위**가 필요한 경우 (376개 프로바이더, 155개 무료/인증 불필요 카탈로그 항목)
- **내장 MCP 서버**가 필요한 경우 (도구로 노출되는 LLM 도구, 메모리, 스킬)
- 에이전트 간 워크플로우를 위한 **A2A 프로토콜**이 필요한 경우
- 업스트림 CAPTCHA의 탐지를 피하기 위한 **핑거프린트 스텔스**(JA3/JA4)가 필요한 경우
- SaaS 비용 없이 **엔터프라이즈 기능**(가드레일, 평가, 감사 추적)이 필요한 경우

## LiteLLM을 선택해야 하는 경우

- **Python 중심**으로 작업하며 `litellm.completion()`과의 긴밀한 통합이 필요한 경우
- **성숙한 프로덕션 배포 레시피**(k8s, Helm 차트)가 필요한 경우
- 팀에서 이미 Python 마이크로서비스를 운영하고 있는 경우

## OpenRouter (SaaS)를 선택해야 하는 경우

- 셀프 호스팅을 원하지 않는 경우
- SaaS 마진이 포함된 토큰당 요금을 지불해도 괜찮은 경우
- 모든 프로바이더에서 사용할 수 있는 **단일 결제 수단**이 필요한 경우

## Portkey를 선택해야 하는 경우

- 가동 시간 보장이 포함된 **상용 SLA**가 필요한 경우
- 운영 오버헤드 없이 **관리형 대시보드**를 선호하는 경우
- 즉시 사용할 수 있는 **엔터프라이즈 규정 준수** 기능이 필요한 경우
