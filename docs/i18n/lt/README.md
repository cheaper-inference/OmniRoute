## Nemokami žetonai per mėnesį: ~ 11.3B kaip kiti skaičiuojami · ~ 90M Real

</div>

> **~ 11.3B nemokamų žetonų per mėnesį**<br/> <sub> skaičiuoja taip, kaip skaičiuoja kiti katalogai: kiekviena eilutė pridedama, pasibaigę pasiūlymai įtraukiami </sub>
>
> **~ 90M real šiandien**<br/> <sub> kiekviena bendrinama kvota skaičiuojama vieną kartą: ką iš tikrųjų galite naudoti </sub>
>
> **Viskas čia nemokama. Nėra mokamos sienos.**<br/> ★ [Patinka? Pažymėkite mus žvaigždute GitHub](https://github.com/cheaper-inference/OmniRoute)

Kituose kataloguose už visą gyvenimą trunkančią prieigą prie tiesioginių duomenų imamas mokestis nuo US USD per metus iki 49 US. Čia viskas nemokama. <sub> Kainos tikrintos 2026-11-18.</sub>

<sub>Katalogas paskutinį kartą tikrintas 2026-11-23. [Kaip mes skaičiuojame →](docs/reference/FREE_TIERS.md#how-we-count)</sub>

> **Atsineškite savo paslaugų teikėjo paskyras.** Tai yra nemokamos trečiųjų šalių pakopos, o ne simbolinė OmniRoute dotacija. Prisiregistruokite, gaukite kredencialus, kai paslaugų teikėjas jų prašo, ir prijunkite tuos, kuriuos galite naudoti. Kiekvienas teikėjas nustato savo apribojimus, prieinamumą ir sąlygas.
>
> Laisvų pakopų sudėjimas rankomis reiškia dešimtis SDKs, dešimtis normų limitų ir neaišku, kas jums liko. OmniRoute saugo 214 katalogo eilučių su nemokama prieiga ir apskaičiuoja tikrąjį skaičių iš 12 telkinių su paskelbta kvota, kiekvienas bendras telkinys skaičiuojamas vieną kartą. Kvotos, kurios atidaromos tik patikrinus regioninę tapatybę (šiandien, ModelScope), rodomos atskirai, 6 mln. +~ už regioninės tapatybės patvirtinimo ir niekada nepridedamos prie tikrojo skaičiaus. Tai, kas liko, rodoma prietaisų skydelyje (`/dashboard/free-tiers`).

## Įdiekite, prijunkite tiekėją, tada nukreipkite per vieną galinį tašką

<img src="./docs/diagrams/works-zero-config.svg" width="100%" alt="Four steps to use OmniRoute. Install with npm install -g omniroute, run omniroute, connect a provider and create an API key in the dashboard, then call http://localhost:20128/v1 with model auto."/>

```bash
# After connecting a provider, create your OmniRoute key in Dashboard → API Keys:
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer YOUR_OMNIROUTE_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"auto","messages":[{"role":"user","content":"Hello!"}]}'
```

## Kombinacijos: flagmanas

1. **Pradėkite nuo `auto`.** Nustatykite modelį su OpenAI suderinamame kliente. OmniRoute sukuria virtualų derinį iš prijungtų paslaugų teikėjų ir tiesiogiai vertina kandidatus.
2. **Išsaugokite kombinaciją, kad galėtumėte daugiau valdyti.** Pasirinkite pavadinimą, tikslų sąrašą ir strategiją, tada naudokite tą pavadinimą kaip modelį. Strategija nustato, kuris tikslas yra pirmas ir kaip kiti yra bandomi.

Kombinuotas maršrutas tarp modelių automatiškai. Išnaudojus kvotą, gedus teikėjui arba blokuojant modelį, jis bando kitą tinkamą, sveiką tikslą.

### Nulinė konfigūracija: tiesiog naudokite `auto`

```bash
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <your-omniroute-key>" \
  -H "Content-Type: application/json" \
  -d '{"model": "auto", "messages": [{"role": "user", "content": "Hello"}]}'
```

Variantai derina svorius. Paskutinis žinomas geras maršrutas lieka paskutiniam sėkmingam teikėjui, kol nepavyksta, tada iš naujo nustatomi rezultatai. `auto/fast` ir `auto/cheap` išreiškia pageidavimus negarantuojant greičiausio ar pigiausio modelio.

| Modelis ID          | Elgesys                                                                                                                                                                                                                                                                                                                    |
| :------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `auto`              | Subalansuoti numatytieji svoriai.                                                                                                                                                                                                                                                                                          |
| `auto/fast`         | Palankiai vertina mažą delsą ir paslaugų teikėjo sveikatą.                                                                                                                                                                                                                                                                 |
| `auto/cheap`        | Pritaria mažesnėms katalogo kainoms.                                                                                                                                                                                                                                                                                       |
| `auto/coding`       | Kodo generavimo svarmenys pirmiausia kokybei.                                                                                                                                                                                                                                                                              |
| `auto/smart`        | Kokybės svarmenys su 10 % tyrinėjimo (numatytasis 5 %).                                                                                                                                                                                                                                                                    |
| `auto/lkgp`         | Aiškus paskutinis žinomas geras maršrutas su tokiais pat svoriais kaip ir `auto`.                                                                                                                                                                                                                                          |
| `auto/subscription` | Naudoja tik gyvai patvirtintą plano kvotą. Grąžina HTTP 503, kai jo nėra, ir išvengiama atsarginio apmokestinimo.                                                                                                                                                                                                          |
| `auto/thrifty`      | Planuokite → beraktinį → nemokamai → pigų → premium. Gali pasiekti apmokestinamus modelius ir grįžti prie plano, kai leis kvota ir atvėsimas.                                                                                                                                                                              |
| `auto/offline`      | Pirmenybė teikiama kvotoms ir tarifų ribiniams dydžiams. Užklausos vis tiek siunčiamos jūsų teikėjams.                                                                                                                                                                                                                     |
| `auto/chaos`        | Vienas tiekėjas lygiagrečiai, iki penkių pagal numatytuosius nustatymus arba dešimt, kai sukonfigūruota. Vienas skambutis vienam modeliui. ### Atsparumas yra įmontuotas: 3 nepriklausomi sluoksniai

Gedimai tvarkomi trimis sritimis, todėl vienas blogas modelis nepanaikina savo paskyros, o viena bloga paskyra nepanaikina teikėjo.

<img src="./docs/diagrams/resilience-layers.svg" width="100%" alt="OmniRoute resilience: 3 independent self-healing layers, the right layer for the right failure. Layer 1, provider circuit breaker (whole provider): trips only on 408/500/502/503/504, opens after 8 failures for OAuth providers or 12 for API-key providers, resets after 60s or 30s into a HALF-OPEN probe, lazy recovery; while OPEN the combo reroutes to the next provider. Layer 2, connection cooldown (one key or account): base 5s OAuth or 3s API-key, exponential backoff with an anti-thundering-herd guard, success clears the error state; one cooling key is skipped while sibling keys keep serving. Layer 3, model lockout (one model): per-model 429, 404 or access denials lock just that model, never the whole connection. Terminal states (banned, expired, credits exhausted) wait for the operator; they are not cooldowns."/>

#### Jei neveikia visas paslaugų teikėjas

The** tiekėjo grandinės pertraukiklis** atsidaro po 8 (OAuth) arba 12 (API klavišas) gedimų, kurių būsena yra 408, 500, 502, 503 arba 504. Kombos praleidžia tą teikėją, kol jis atidarytas. Po 60 s arba 30 s viena zondo užklausa nusprendžia, ar jis užsidaro.

#### Jei vienas raktas arba sąskaita yra ribojama

The** ryšio aušinimas** suoliukai tik tą ryšį, su eksponenciniu atsitraukimu nuo 5 s (OAuth) arba 3 s (API klavišas). Kiti to paties teikėjo raktai toliau teikiami.

#### Jei vieno modelio atsisakoma

The** modelio blokavimas** blokuoja tik tą modelį tame ryšyje po 429, 404 modelio arba prieigos uždraudimo. Kiti tos pačios jungties modeliai toliau tarnauja.

Uždrausti, pasibaigę ir nebekredituoti ryšiai yra terminalo būsenos, o ne atšalimai: jie laukia, kol juos ištaisysite.

```bash
omniroute run codex    --model glm/glm-5.2             # Codex CLI
omniroute run aider    --model glm/glm-5.2 -- --message "reply OK"
omniroute run goose    --model glm/glm-5.2
omniroute run opencode --model glm/glm-5.2 -- run "reply OK"
omniroute run qwen     --model glm/glm-5.2 -- -p "reply OK"
omniroute run gemini   --model glm/glm-5.2 -- --skip-trust -p "reply OK"
omniroute setup-whycodes && omniroute run whycodes --model glm/glm-5.2

# Or pick provider and model interactively and write the tool's own config:
omniroute configure codex   # also: claude opencode qwen aider goose gemini whycodes cline continue kilo 5dive
```

Kiekviena komanda gerbia aktyvų nuotolinį kontekstą (`omniroute connect <host>`). `--dry-run` atspausdina tikslų env ir args nieko nepaleisdamas, o `--api-key-env NAME` saugo raktą iš jūsų apvalkalo istorijos. Qwen kodas ir Gemini CLI veikia laikinuose namuose, kurie ištrinami išėjus. WhyCodes skaito savo teikėją tik iš `config.toml`, todėl paleiskite `setup-whycodes` vieną kartą prieš `run whycodes`. → [CLI integracijos](docs/guides/CLI-INTEGRATIONS.md)

## Visas CLI, MCP ir A2A

> OmniRoute siunčia komandinės eilutės klientą su** 91 aukščiausio lygio komandos ir komandų grupės** (754 komandos skaičiuojant subkomandas), an**MCP serveris su 110 įrankių ir 33 taikikliais** , ir an**A2A agentas, turintis 6 įgūdžius** . Skriptai, terminalai ir AI agentai gali veikti tuo pačiu šliuzu.

### Tikras CLI, ne tik `start`

```bash
omniroute                 # start the gateway and dashboard (port 20128)
omniroute setup           # guided first-run wizard
omniroute repl            # interactive chat in the terminal (/model /combo /skill /memory)
omniroute chat "hello"    # one-shot prompt; also reads --file or --stdin
omniroute doctor          # check config, database, ports, Node runtime and native deps
```

Visuotinė `--output table|json|jsonl|csv` vėliavėlė leidžia naudoti tas pačias komandas iš scenarijų ir CI.

### Nuotolinis režimas: CLI nešiojamajame kompiuteryje, OmniRoute serveryje

Vieną kartą prisijunkite prie nuotolinio serverio. CLI išsaugo jį kaip a** kontekste** , o vėlesnės komandos veikia tame serveryje, kol neperjungiate atgal.

```bash
omniroute connect omniroute.example.com          # asks for the password, saves a scoped token as a context
omniroute models                                 # runs against the remote server
omniroute configure codex                        # picks a remote model, writes a local Codex profile
omniroute tokens create --name ci --scope read   # mint a narrower token for another machine
omniroute contexts use default                   # switch back to the local server
```

| Žetono apimtis | <img width="2000" height="0" alt=""> Ką tai leidžia                         |
| -------------- | --------------------------------------------------------------------------- |
| `read`         | Išvardykite ir patikrinkite: modeliai, būsena, žurnalai, naudojimas         |
| `write`        | `read` plus konfigūruoti ir taikyti: kliento sąranka, raktai, konfigūracija |
| `admin`        | `write` plus valdyti: žetonus, tiekėjus, paslaugas, politiką                |

Plikas šeimininkas gauna `http://` ir port 20128; perduoti visą `https://` URL kai serveris yra už TLS. Maršrutai, kurie gali sukelti procesus, lieka tik atgalinio ryšio, neatsižvelgiant į prieigos raktą.

### Prijunkite agentą

Agentas arba jūsų kodas gali valdyti maršrutą, teikėjus, derinius, talpyklą, glaudinimą ir atmintį per bet kurią iš šių sąsajų. HTTP kelius aptarnauja šliuzas, pagal numatytuosius nustatymus `http://localhost:20128`.

| Sąsaja                | Galinis taškas arba komanda | Naudokite jį                                                                                      |
| --------------------- | --------------------------- | ------------------------------------------------------------------------------------------------- |
| MCP per stdio         | `omniroute --mcp`           | Claude Desktop, Cursor ir kiti vietiniai MCP klientai                                             |
| MCP per srautinį HTTP | `/api/mcp/stream`           | Nuotoliniai MCP klientai: 110 įrankių, 33 apimtys, kiekvienas skambutis įrašytas į audito žurnalą |
| MCP per SSE           | `/api/mcp/sse`              | Klientai, kurie vis dar naudojasi SSE transportu                                                  |
| A2A atradimas         | `/.well-known/agent.json`   | Agento kortelė: nurodo kitiems agentams, ką OmniRoute gali padaryti                               |
| A2A egzekucija        | `POST /a2a`                 | JSON-RPC 2.0 užduotys, sinchroninės arba srautiniu būdu perduodamos per SSE, naudojant 6 įgūdžius |
| REST API              | `/v1/*`                     | Su OpenAI suderinamas pokalbis, atsakymai, įterpimai, vaizdai, garsas ir OCR                      |
| Webhooks              | `/api/webhooks`             | Įvykiai į Slack, Discord, Telegram arba bet kurį URL su HMAC parašu                               |
| Nuotolinis CLI        | `omniroute connect <host>`  | Vairuoti nuotolinį egzempliorių su priskirtais prieigos prieigos raktais                          |

Šeši A2A įgūdžiai yra `smart-routing`, `quota-management`, `provider-discovery`, `cost-analysis`, `health-report` ir `list-capabilities`.

**Prieš prisijungdami:**

- **MCP per HTTP paleidžiama išjungta.** Įjunkite jį naudodami `omniroute mcp enable --transport streamable-http` arba prietaisų skydelio Galinių taškų puslapyje. Vienu metu aktyvus vienas HTTP transportavimas: `streamable-http` aptarnauja `/api/mcp/stream`, `sse` aptarnauja `/api/mcp/sse`.
- **A2A paleidžiama išjungta.** Įgalinkite jį prietaisų skydelio puslapyje Galiniai taškai. Tada `POST /a2a` laikosi tų pačių API rakto taisyklių kaip ir `/v1`.
- **Nuotoliniam MCP reikia tinkamo rakto.** `/api/mcp/*` pagal numatytuosius nustatymus atsako tik atgalinis ryšys. Iš kito pagrindinio kompiuterio atsiųskite raktą su `manage` arba `admin` (visi įrankiai) arba su `mcp:connect` plius jums reikalingų įrankių apimtis. Klavišams be `manage`/`admin` įrankių apimtis visada vykdoma.

```bash
# Give Claude Code the OmniRoute toolset over MCP:
omniroute mcp enable --transport streamable-http
claude mcp add --transport http omniroute http://localhost:20128/api/mcp/stream \
  --header "Authorization: Bearer <api-key-with-manage-scope>"
```

### Kaip tai veikia — dujotiekis, architektūra ir taupymo matematika

<img src="./docs/diagrams/compression-pipeline.svg" width="100%" alt="OmniRoute compression pipeline: an illustrative 10,000-token client request passes through 12 composable engines — Session-Dedup, CCR, Lite, RTK, Responses Tool Output, Headroom, Relevance, Caveman, Aggressive, LLMLingua-2, Ultra and OmniGlyph — and can reach the provider at about 1,080 tokens in the documented stacked example. Structured content is protected by preservation guards and per-step fidelity gates; explicit lossy or experimental modes may transform eligible content."/>

Numatytoji sudėtinė kombinacija veikia `RTK → Caveman`. Kai abu veikia tą patį tool/context naudingąjį apkrovą, taupymo junginys:

```txt
combined = 1 − (1 − RTK) × (1 − Caveman_input)
average  = 1 − (1 − 0.80) × (1 − 0.46) = 89.2%
range    = 78.4 – 94.6%
```

Kodo blokai, URLs, JSON ir struktūriniai duomenys yra** visada apsaugotas** konservavimo varikliu.

> **Kam naudoti daug žetonų, kai tik nedaugelis žetonų?** Kiekviena užklausa eina per OmniRoute suspaudimo vamzdyną** skaidriai** — jokių klientų pakeitimų. Dabar tai a** 12 komponuojamų variklių krūva** kurios veikia eilės tvarka ir derinamos pagal maršruto parinkimo kombinaciją — remiantis [RTK](https://github.com/rtk-ai/rtk), [Caveman](https://github.com/JuliusBrussee/caveman) (⭐ 90K +), [LLMLingua-2](https://github.com/microsoft/LLMLingua) ir [Troglodita](https://github.com/leninejunior/troglodita) (PT-BR) idėjomis.

**🐳 Docker**

```bash
docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 \
  -p 127.0.0.1:20128:20128 -v omniroute-data:/app/data cheaperinference/omniroute:latest
```

`:latest` seka aukščiausią** paskelbta** stabilus SemVer. Jis neseka git `main`. Smeigtukas `:X.Y.Z` skirtas GitOps. Žr. [Docker išleidimo kanalus](docs/guides/DOCKER_GUIDE.md#release-channels). Vaizdo kaiščiai**`OMNIROUTE_MEMORY_MB=1024`** . To pakanka prietaisų skydeliui ir lengvam pokalbiui.** Kodavimo agentai** (`POST /v1/responses` iš Claude Code, Codex, Grok, …) reikia daug didesnės V8 krūvos arba proceso `FATAL ERROR` s esant ~ 12 GiB dviem persidengiančiais ilgais kontekstais. Nustatykite konteinerio dydį virš krūvos (savieji buferiai yra už V8):

| <img width="2000" height="0" alt=""> Darbo krūvis | krūva (`-e OMNIROUTE_MEMORY_MB`) | Konteineris (`--memory`) |
| ------------------------------------------------- | -------------------------------- | ------------------------ |
| Prietaisų skydelis / lengvas pokalbis             | `1024` (numatytasis vaizdas)     | ≥ 2 g                    |
| Vienas kodavimo agentas                           | `8192`                           | ≥ 10 g                   |
| Du kartu ilgi `/v1/responses`                     | `10240`–`12288`                  | ≥ 12–16 g                |

```bash
docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 \
  -e OMNIROUTE_MEMORY_MB=8192 --memory=10g \
  -p 127.0.0.1:20128:20128 -v omniroute-data:/app/data cheaperinference/omniroute:latest
```

Visa lentelė: [Docker vadovas — vykdymo laikas RAM](docs/guides/DOCKER_GUIDE.md#runtime-ram-for-coding-agents).

> **Išankstinis Docker kanalas:** `diegosouzapw/omniroute:next` ir `diegosouzapw/omniroute:next-web` seka dabartinę numatytąją `release/v*` šaką. Šios kintamos žymos skirtos tik neišleistoms pataisoms išbandyti ir yra** nepalaikoma gamybai** . Žr. [Docker išleidimo kanalus](docs/guides/DOCKER_GUIDE.md#release-channels).

**🥟 Bun**

Standartinis `bun install` ir visuotinis diegimas (`bun install -g omniroute`) palaikomi naudojant Bun vykdymo laiko aptikimą:

- **Integruotas `bun:sqlite`** : OmniRoute naudoja Bun integruotą `bun:sqlite` tvarkyklę, kai veikia pagal Bun, grįžta į `better-sqlite3` Node.js arba `sql.js`.
- **Automatinis žiniatinklio paketų rinktuvo pasirinkimas programoje dev** : plėtra (`bun run dev`) automatiškai aptinka Bun ir išjungia Turbopack Webpack naudai, kad būtų išvengta vietinio V8 susiejimo nesuderinamumo. Gamybos versijos (`bun run build`) seka `OMNIROUTE_USE_TURBOPACK` lygiai taip pat, kaip mazge: Turbopack pagal numatytuosius nustatymus, `OMNIROUTE_USE_TURBOPACK=0` kurti naudojant Webpack (`Dockerfile.bun` atskleidžia jį kaip `--build-arg`).
- **Dedikuotas Bun Dockerfile** : daugiapakopis `Dockerfile.bun`, skirtas vietiniam Bun gamybos diegimui (`docker build -f Dockerfile.bun -t omniroute:bun .`).

```bash
# Install and run with Bun
bun install
bun run dev
```

**⚡ Greitesnis / lengvesnis diegimas (praleiskite savąjį kūrimą)**

Vietinis SQLite variklis (`better-sqlite3`) yra an** neprivaloma** priklausomybė, todėl visuotinis diegimas niekada neblokuoja kompiliavimo iš šaltinio: jis naudoja iš anksto sukurtą dvejetainį failą, kai jis atitinka jūsų platform/Node, o kitu atveju skaidriai grįžta į gryną JS variklį (`node:sqlite` 22 mazge +, kitu atveju komplektuojamas `sql.js` WASM) — nereikia kūrimo įrankių.

Norėdami praleisti įdiegimą po įdiegimo** gimtoji apšilimas** visiškai (CI, be galvų arba lėtos mašinos). Pastaba: taip praleidžiamas tik vietinis SQLite apšilimo veiksmas (`scripts/postinstall.mjs`); binary-copy/repair kablys (`scripts/build/postinstall.mjs`) vis tiek veikia normaliai:

```bash
OMNIROUTE_SKIP_POSTINSTALL=1 npm install -g omniroute   # CI=1 also skips it
```

Greičiausiam diegimui pirmenybė teikiama** pnpm** (turiniui adresuota parduotuvė + kietosios nuorodos — žr. aukščiau). Jei norite, kad prietaisų skydelis būtų be galvos, naudokite Docker `base` profilį (aukščiau) arba [Termux vadovą](docs/guides/TERMUX_GUIDE.md). CLI ir žiniatinklio prietaisų skydelis aptarnaujami tuo pačiu procesu viename prievade, todėl šiandien nėra atskiro tik CLI paketo.
