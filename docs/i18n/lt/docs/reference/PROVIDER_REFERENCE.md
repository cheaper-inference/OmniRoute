## Kategorijos

- **Nemokama** nemokama — pakopa su API klavišu (konfigūruojama per prietaisų skydelį)
- **Neautor** — viešieji galiniai taškai, kuriems visiškai nereikia rakto ar prisijungimo
- **OAuth** — prisijungimo srautą tvarko OmniRoute, nereikia API rakto
- **Interneto slapukas** — apvynioja teikėjo žiniatinklio programą naudodama slapukų autentifikavimą
- **API raktas** — mokamas teikėjas, sukonfigūruotas naudojant API raktą (gali būti taikomi nemokami kreditai)
- **Vietinis** — veikia vartotojo kompiuteryje (Ollama, LM Studio, vLLM ir kt.)
- **Ieškoti** — žiniatinklio paieškos teikėjai
- **Garsas** — tik garso teikėjai (TTS/STT)
- **Prieš srovę tarpinis serveris** — teikėjai, kurie yra tarpiniai serveriai kitiems teikėjams
- **Debesų agentas** — ilgai veikiantys kodavimo agentai (Codex Cloud, Devin, Jules)
- **Sistema** — OmniRoute“ vidiniai teikėjai (atgalinis ryšys ir kt.)

Papildomos žymos: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (kur parodyta): `native` — tikrosios funkcijos iškvietimas API; `emulated` — `tools` masyvas yra greitai emuliuojamas per `webTools.ts` (regex analizuojami `<tool>{...}</tool>` blokai); `none` — `tools` šiuo metu tyliai nuleidžiamas. Žiūrėkite #7286.

Norėdami įjungti, sukonfigūruoti ir išbandyti kiekvieną teikėją, naudokite `/dashboard/providers` esančią prietaisų skydelį.
