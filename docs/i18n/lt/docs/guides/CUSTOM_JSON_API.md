Pasirinktinis JSON API mazgas sujungia JSON verslo galinį tašką, kuris nekalba OpenAI arba Anthropic protokolo. OmniRoute užpildo JSON užklausos šabloną, siunčia jį į visą galinį tašką URL, nuskaito atsakymą iš atsakymo kelio ir grąžina jį klientui kliento formatu (pokalbių užbaigimai, atsakymai, pranešimai ir kt.).

Tai su OpenAI suderinamas mazgas su `apiType: "custom-json"`; jo ID turi formą `openai-compatible-custom-json-<suffix>`. Prietaisų skydelio forma dar nepasiekiama. Kurkite ir redaguokite šiuos mazgus naudodami toliau pateiktą teikėjo mazgą API.

## Sukurkite mazgą

`POST /api/provider-nodes` (vadybos autentifikavimas):

```json
{
  "type": "openai-compatible",
  "apiType": "custom-json",
  "name": "Business API",
  "prefix": "biz",
  "baseUrl": "https://api.example.com/v1/answer",
  "customHeaders": { "X-Tenant": "demo" },
  "customJson": {
    "method": "POST",
    "authType": "api-key",
    "authHeader": "X-Service-Key",
    "requestTemplate": {
      "project_id": "demo-project",
      "question": "{{prompt}}",
      "history": "{{messages}}"
    },
    "responsePath": "data.answer"
  }
}
```

- `baseUrl` yra** užbaigti** galutinis taškas URL. Nieko nepridedama (be `/chat/completions`, be `/models`) ir, skirtingai nuo kitų su OpenAI suderinamų mazgų, nėra numatytojo URL. Jis turi būti `http(s)`, be įterptųjų kredencialų arba `#fragment`, ir jis turi perduoti tą pačią išeinančio URL apsaugą, kaip ir kiekvienas teikėjo mazgas, tiek išsaugant mazgą, tiek gavus kiekvieną užklausą.
- Mazgas, siunčiantis ryšio raktą (`authType` `bearer` arba `api-key`, įskaitant numatytąjį), turi naudoti `https://`. Paprastas `http://` priimamas tik grįžtamojo ryšio priegloboje (`localhost`, `127.0.0.0/8`, `::1`) arba su `authType: "none"`, kuris nesiunčia rakto. Privatūs LAN adresai (`10.x`, `172.16-31.x`, `192.168.x`) nėra atleisti: bet kas tame tinkle gali perskaityti raktą. Tokio mazgo išsaugoti nepavyksta naudojant `400`, o anksčiau išsaugotas mazgas uždaromas kiekvieną kartą su tuo pačiu pranešimu, prieš išsiunčiant bet kokią užklausą. Jei LAN raktas galinis taškas, padėkite jį už TLS (pvz., atvirkštinio tarpinio serverio).
- `customJson` patvirtintas Zod; nežinomi raktai atmetami. Kiekvienas laukas yra neprivalomas:

| Laukas            | Vertybės                                        | Numatytoji                                             |
| ----------------- | ----------------------------------------------- | ------------------------------------------------------ |
| `method`          | `POST`, `PUT`, `PATCH`                          | `POST`                                                 |
| `authType`        | `bearer`, `api-key`, `none`                     | `bearer`                                               |
| `authHeader`      | antraštės pavadinimas, naudojamas kai `api-key` | `X-API-Key`                                            |
| `requestTemplate` | JSON objektas (≤ 64 KB, gylis ≤ 32)             | `{ "model": "{{model}}", "messages": "{{messages}}" }` |
| `responsePath`    | lauko takas, arba `$` visam kūnui               | `choices[0].message.content`                           |

- Paslaptis lieka ryšio API rakte, o ne šablone. `bearer` siunčia `Authorization: Bearer <key>`; `api-key` siunčia `<authHeader>: <key>`. Auth antraštė negali būti `Host`, `Content-Type`, `Content-Length`, `Connection`, `Transfer-Encoding`, `Authorization`, `Cookie` arba šuolio po šuolio antraštė. Naudojant `none`, jungtims nereikia rakto.
- Papildomos statinės antraštės naudoja įprastą mazgo `customHeaders` (toks pat patvirtinimas kaip ir bet kuris kitas suderinamas mazgas; autentifikavimo antraštės ten neleidžiamos).

`PUT /api/provider-nodes/<id>` priima tą patį `customJson` ir perrašo `baseUrl` bei konfigūraciją kiekviename esamame mazgo jungtyje. Praleidus `customJson`, išsaugoma konfigūracija; perjungus `apiType` į `chat` arba `responses` jis pašalinamas iš mazgo ir jo jungčių.

Tada pridėkite ryšį su mazgu kaip įprasta (`POST /api/providers` su mazgo ID) ir paprašykite `<prefix>/<model>`, pavyzdžiui `biz/assistant-v1`. Galutinis taškas neparodo modelių sąrašo, todėl modelio ID pridėkite ranka.

## Prašymo šablonai

Šablonai yra paprasti JSON. Eilutės reikšmėje gali būti `{{placeholder}}` žymenų; niekas neįvertinamas ar nevykdomas, o objekto raktai niekada nepakeičiami.

| Vietos rezervuaras   | Vertė                                                                             |
| -------------------- | --------------------------------------------------------------------------------- |
| `{{prompt}}`         | Naujausio vartotojo pranešimo tekstas (teksto dalys sujungtos naujomis eilutėmis) |
| `{{messages}}`       | Pokalbis OpenAI pokalbių formatu                                                  |
| `{{model}}`          | Prašomas modelio ID be teikėjo priešdėlio                                         |
| `{{stream}}`         | Visada `false` — galutinis taškas atsako vienu JSON dokumentu                     |
| `{{request.<path>}}` | Išverstos (OpenAI pokalbių formato) užklausos laukas                              |

- Reikšmė, kuri yra tiksliai viena rezervuota vieta, išlaiko savo JSON tipą (`"{{messages}}"` tampa masyvu); kaip tekstas įterpiamas vietos rezervavimo ženklas ilgesnės eilutės viduje.
- Vietos rezervavimo priemonė, kuri nusprendžia nieko, neįvykdo užklausos su HTTP 400, o ne siunčia nebaigtą naudingą apkrovą.
- Keliai naudoja taškų žymėjimą ir skaitinius indeksus (`data.items[0].text`). `__proto__`, `prototype` ir `constructor` atmetami raktuose ir keliuose.

## Atsakymai

`responsePath` reikšmė tampa asistento atsakymu: eilutės praeina, kitos JSON reikšmės suskirstomos į seriją. Trūkstamas arba `null` laukas arba tekstas, kuris nėra JSON, grąžina HTTP 502. Perduodamos prieš srovę esančios klaidų būsenos. Srautinio perdavimo klientams OmniRoute laukia viso JSON atsakymo ir tada išsiunčia jį kaip vieną turinio dalį ir užbaigtą dalį; tai nėra prieigos raktas. Įrankių iškvietimai ir naudojimo laukai nėra susieti.

## Niekada neperžaista

Verslo užklausa gali turėti šalutinį poveikį, net jei ji nepavyksta. Todėl OmniRoute vieną kartą išsiunčia:

- jokio pakartotinio perdavimo ir peradresavimo;
- nebandoma kartoti kitu prisijungimu (paskyros atsarginė dalis) — gedimas grąžinamas toks, koks yra ir ryšys neatvėsinamas;
- negrįžtama prie kito kombinuoto tikslo, net jei atsakymas tuščias arba nepavyko.

Atskiros klientų užklausos ir sintezės skydeliai, kurie aiškiai iškviečia kelis modelius, vis tiek nepriklausomai iškviečia galutinį tašką.

## Mazgo testavimas

Ryšio išsaugojimas, ryšys** Testas** mygtukas ir fono būklės patikrinimai niekada neiškviečia galutinio taško: jie tik patvirtina išsaugotą konfigūraciją ir praneša, kad ryšys nėra patikrinamas.

`POST /api/provider-nodes/validate` su `"apiType": "custom-json"` ir mazgo laukais (`baseUrl`, `apiKey`, `customJson`, pasirinktinai `customHeaders` ir `modelId`) siunčia tiksliai vieną tikrą užklausą, o `ping` kaip naujausią vartotojo tekstą. Jis atsako į `{ "valid": true }` arba priešsrovės būseną (niekada prieš srovę).

## Sandėliavimas

Konfigūracija saugoma `provider_nodes.custom_json_config_json` (perkėlimas `240_provider_node_custom_json_config.sql`) ir nukopijuota į kiekvieno ryšio `providerSpecificData.customJson`.

Diegimas: `open-sse/utils/customJson.ts` (patvirtinimas ir šablonų sudarymas), `open-sse/executors/customJson.ts` (vykdytojas), `open-sse/services/combo/noReplayLatch.ts` ir `src/sse/handlers/chat/responsePolicies.ts` (nepakartojimas).
