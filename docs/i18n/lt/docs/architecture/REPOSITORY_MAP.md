## Aukščiausio lygio medis

```
OmniRoute/
├── src/                  # Next.js 16 programa (UI + API maršrutai + bibliotekos + domenas + serveris)
├── open-sse/             # Srautinio perdavimo variklio darbo sritis (dorokliai, vykdyklės, vertimo sluoksnis, MCP serveris)
├── packages/            # npm darbo sritys: ui-kit (integruotas Keak CI UI Kit) ir browser-pool
├── electron/             # Darbalaukio programos apvalkalas (Electron 41 + electron-builder 26.10)
├── bin/                  # CLI įėjimo taškas ir komandų dorokliai
├── scripts/              # Kompiliavimo, tikrinimo, sinchronizavimo ir vienkartiniai scenarijai
├── docs/                 # Vieša dokumentacija (esate čia)
├── tests/                # Visi testų rinkiniai (vienetų, integraciniai, e2e, protokolų klientų)
├── public/               # Next.js statiniai ištekliai, PWA manifestas, paslaugų darbininkas, piktogramos
├── config/               # Statinė konfigūracija + kokybės patikros būsena (i18n, payloadRules, quality/)
├── images/               # Rinkodaros / README vaizdų ištekliai
├── @omniroute/           # Publikuojami papildomi paketai (opencode-plugin, opencode-provider)
├── skills/               # CLI / agentų įgūdžių paketai (cli-* + omni-* + config-codex-cli)
├── examples/             # Pavyzdiniai papildiniai + omniroute-cmd-hello pradinis šablonas
├── contrib/              # Bendruomenės indėliai (podman/)
├── .source/              # Fumadocs šaltinio konfigūracija (source.config.mjs + server/browser/dynamic)
├── .github/              # GitHub Actions darbo eigos + problemų šablonai + PR šablonas
├── .husky/               # Git kabliai (pre-commit, pre-push)
├── .claude/              # Claude Code pasvirojo brūkšnio komandos (projekto lygmens)
├── .agents/              # Codex / bendrosios agentų darbo eigos + įgūdžiai (.claude/ kopija)
├── .vscode/              # VS Code darbo srities nuostatos
├── _ideia/               # Planavimo pastabos (neformalios; neplatinamos)

├── _references/          # Tik skaitomos susijusių OSS projektų nuorodinės kopijos
├── _tasks/               # Kiekvienos laidos užduočių stebėjimo failai (neformalūs)
├── .build/ .worktrees/ dist/   # Vietiniai kompiliavimo / git-worktree / kompiliavimo išvesties laikini duomenys (Git ignoruojami)
├── .issues/              # Vietinė problemų podėlio kopija (Git ignoruojama)
├── .playwright-mcp/      # Playwright MCP testų artefaktai
├── coverage/             # c8 testų aprėpties išvestis (Git ignoruojama)
├── logs/                 # Vykdymo žurnalai (Git ignoruojami)
├── node_modules/         # Priklausomybės (Git ignoruojamos)
├── package/              # npm pack paruošimo sritis (kompiliavimo artefaktas)
├── .next/                # Next.js kompiliavimo išvestis (Git ignoruojama)
└── (šakniniai failai — žr. toliau)
```

## `src/` — Next.js programa

```
src/
├── app/                 # „App Router“ (puslapiai + API maršrutai + būsenos puslapiai + pradinis puslapis)
├── lib/                 # Pagrindinės bibliotekos / domeno moduliai (80 pakatalogių + ~70 aukščiausio lygio failų)
├── domain/              # Grynoji domeno logika (strategijų variklis, atsarginė logika, sąnaudos, blokavimas, comboResolver, vertinimas)
├── server/              # Tik serveriui skirti moduliai (autorizavimo konvejeris, cors, autentifikavimo tarpinė programinė įranga) — negalima importuoti iš kliento
├── shared/              # Saugiai bendrinama tarp serverio ir kliento (konstantos, tipai, validavimas, sutartys, pagalbinės priemonės)
├── i18n/                # next-intl konfigūracija + kiekvienos lokalės pranešimų JSON (67 lokalės)
├── middleware/          # Next.js tarpinė programinė įranga (užklausų papildymas, lokalės aptikimas)
├── mitm/                # Pagrindinė MITM įgaliotojo serverio dalis: sertifikatų generavimas / diegimas, apdorojimo priemonės, paskirties vietos, inspektorius, kaukės, tiesioginis perdavimas
│   ├── handlers/        # 9 IDE agentų apdorojimo klasės, išplečiančios MitmHandlerBase (antigravity, kiro, copilot, codex, cursor, zed, claudeCode, openCode, trae)
│   └── inspector/       # Srauto fiksavimo sluoksnis: buferis (atmintyje esantis žiedinis buferis), sseMerger, conversationNormalizer, kindDetector, contextKey, httpProxyServer, systemProxyConfig
├── models/              # Modelio adapterio susiejimo kodas (senstelėjęs suderinamumo tarpinis sluoksnis)
├── scripts/             # Saugykloje laikomi priežiūros scenarijai (pvz., backfillAggregation)
├── sse/                 # Senstelėjusios SSE apdorojimo priemonės / paslaugos (chat.ts, chatHelpers.ts, services/auth.ts)
├── store/               # Senstelėjusi atmintyje esanti saugykla (palaipsniui keičiama į src/lib/db)
├── types/               # Bendrinami TS tipų failai
├── instrumentation.ts   # Next.js telemetrijos sąsaja (naršyklei + „edge“ aplinkai)
├── instrumentation-node.ts  # Tik Node skirta instrumentacija
└── proxy.ts             # HTTP įgaliotojo serverio įvesties suderinamumo tarpinis sluoksnis
```
