## 🎯 Foydalanish holatlari

### 1-holat: «Menda Claude Pro obunasi bor»

**Muammo:** Kvota ishlatilmay qolib ketadi, intensiv dasturlash vaqtida tezlik cheklovlariga duch kelinadi

```
Kombinatsiya: "maximize-claude"
  1. cc/claude-opus-4-7        (obunadan toʻliq foydalanish)
  2. glm/glm-4.7               (kvota tugaganda arzon zaxira)
  3. if/qwen3.8-max-preview       (favqulodda holat uchun bepul muqobil)

Oylik xarajat: $20 (obuna) + ~$5 (zaxira) = jami $25
$20 toʻlab, cheklovlarga duch kelish = hafsalasizlik
```

### 2-holat: «Xarajat nol boʻlishini xohlayman»

**Muammo:** Obunalarga imkonim yetmaydi, ishonchli AI yordamida dasturlash kerak

```
Kombinatsiya: "zero-cost"
  1. if/kimi-k2.7-code          (bepul kirish sifatida koʻrsatilgan; tezlik cheklovlari amal qilishi mumkin)
  2. kr/qwen3-coder-next        (Kiro bepul muqobili)

Oylik xarajat: $0
Sifat: ish yuklamangiz uchun model, cheklovlar, maxfiylik va SLA talablarini tekshiring
```

### 3-holat: «Uzilishlarsiz, 24/7 dasturlashim kerak»

**Muammo:** Muddatlar yaqin, toʻxtab qolishga yoʻl qoʻyib boʻlmaydi

```
Kombinatsiya: "always-on"
  1. cc/claude-opus-4-7        (eng yaxshi sifat)
  2. cx/gpt-5.5                (ikkinchi obuna)
  3. glm/glm-4.7               (arzon, har kuni yangilanadi)
  4. minimax/MiniMax-M2.1      (eng arzon, 5 soatda yangilanadi)
  5. if/deepseek-v4-flash       (bepul kirish sifatida koʻrsatilgan; tezlik cheklovlari amal qilishi mumkin)

Natija: 5 ta zaxira qatlam barqarorlikni oshiradi; yuqori darajadagi xizmatlar mavjudligi kafolatlanmaydi
Oylik xarajat: $20-200 (obunalar) + $10-20 (zaxira)
```

### 4-holat: «OpenClaw ichida BEPUL AI ishlatmoqchiman»

**Muammo:** Xabar almashish ilovalarida mutlaqo bepul AI yordamchisi kerak

```
Kombinatsiya: "openclaw-free"
  1. if/qwen3.8-max-preview     (bepul kirish sifatida koʻrsatilgan; tezlik cheklovlari amal qilishi mumkin)
  2. if/deepseek-v4-flash       (bepul kirish sifatida koʻrsatilgan; tezlik cheklovlari amal qilishi mumkin)
```

## 📖 Provayderni sozlash

CSV yoki JSON faylidan API-kalit ulanishlarini ommaviy qo‘shish uchun **Boshqaruv paneli → Provayderlar → Fayldan import qilish** bo‘limidan foydalaning. Ustunlar pozitsion tartibda beriladi (`provider,name,apiKey,baseUrl,priority`); `provider` boshqariladigan provayder yoki mos keluvchi tugun sifatida avvaldan mavjud bo‘lishi kerak. [Provayderlarni CSV yoki JSON faylidan import qilish](../providers/CSV-IMPORT.md) bo‘limiga qarang.

### 🔐 Obuna asosidagi provayderlar

#### Claude Code (Pro/Max)

```bash
Boshqaruv paneli → Provayderlar → Claude Code’ga ulanish
→ OAuth orqali kirish → Tokenni avtomatik yangilash
→ 5 soatlik + haftalik kvotani kuzatish

Modellar:
  cc/claude-opus-4-7
  cc/claude-sonnet-4-6
  cc/claude-haiku-4-5-20251001
```

**Foydali maslahat:** Murakkab vazifalar uchun Opus’dan, tezlik uchun esa Sonnet’dan foydalaning. OmniRoute kvotani har bir model bo‘yicha kuzatadi!

OmniRoute hostida brauzer mavjud emasmi? Claude Code tizimiga kirilgan istalgan joyda `claude setup-token` buyrug‘ini ishga tushiring va bir yillik tokenni **Setup Token** yorlig‘iga joylang. [Claude Code’da setup tokenidan foydalanish](../providers/CLAUDE_CODE_SETUP_TOKEN.md) bo‘limiga qarang.

Claude va Claude Code bilan mos yo‘nalishlar Opus va Sonnet
modellari uchun `max` fikrlash darajasini saqlab qoladi. Haiku modellari `max` fikrlash
darajasini qabul qilmaydi, shuning uchun OmniRoute bu so‘rovni yuqori fikrlash
budjetiga pasaytirib, keyin yuqori oqimga yuboradi.

#### OpenAI Codex (Plus/Pro)

```bash
Boshqaruv paneli → Provayderlar → Codex’ga ulanish
→ OAuth orqali kirish (1455-port)
→ 5 soatlik + haftalik tiklanish

Modellar:
  cx/gpt-5.5
  cx/gpt-5.4
  cx/gpt-5.3-codex
  cx/gpt-5.3-codex-spark
```

#### GitHub Copilot

```bash
Boshqaruv paneli → Provayderlar → GitHub’ga ulanish
→ GitHub orqali OAuth
→ Oylik tiklanish (oyning 1-kuni)

Modellar:
  gh/gpt-5.5
  gh/gpt-5.4
  gh/claude-sonnet-4.6
  gh/claude-opus-4.7
  gh/gemini-3.1-pro-preview
```

**AI kreditlari (token asosidagi hisob-kitob).** GitHub hisob uchun
`credits_used` qiymatini bildirganda, Provayder cheklovlari kartasida joriy hisob-kitob
davrida sarflangan kreditlar ko‘rsatilgan **AI Credits** qatori paydo bo‘ladi, bu
cheksiz tashkilot rejalariga ham tegishli.

**Mahalliy AI kreditlari cheklovi.** GitHub ulanishini tahrirlang va **Billing period
uchun AI Credits limiti** (`providerSpecificData.githubCreditLimit`) qiymatini belgilang.
Bo‘sh qoldirish bu cheklovni o‘chiradi; `0` ulanishni har doim o‘tkazib yuboradi. Oxirgi
foydalanish ko‘rsatkichi limitga teng yoki undan yuqori bo‘lsa, hisob tanlashda bu
ulanish o‘tkazib yuboriladi va yo‘naltirish kvota siyosati kesib qo‘yilgandagi kabi
boshqa ulanishlarga o‘tadi. Tekshiruv davriy kvota yangilanishi allaqachon to‘plagan
foydalanish ma’lumotlarini o‘qiydi — so‘rov yo‘lida GitHub’ga hech qachon murojaat
qilmaydi — va ochiq ishlash tamoyiliga amal qiladi: ma’lumot yetishmasa yoki eskirgan
bo‘lsa (15 daqiqadan eski yoki allaqachon tiklangan hisob-kitob davridan olingan bo‘lsa),
ulanish bloklanmaydi. Bu mahalliy himoya chorasi, **sarflashning kafolatlangan yuqori
chegarasi emas**: GitHub hisobotlaridagi kechikishlar, yangilanish oralig‘i, bajarilayotgan
so‘rovlar va OmniRoute’dan tashqaridagi foydalanish bu chegaradan oshib ketishi mumkin.
Qattiq limit uchun GitHub’ning o‘z sarflash nazoratlaridan foydalaning.

### 💰 Arzon provayderlar

#### GLM-4.7 (kunlik tiklanish, $0.6/1M)

1. Ro‘yxatdan o‘ting: [Zhipu AI](https://open.bigmodel.cn)
2. Coding Plan’dan API kalitini oling
3. Boshqaruv paneli → API kalitini qo‘shish: Provayder: `glm`, API kaliti: `your-key`

**Foydalanish:** `glm/glm-4.7` — **Foydali maslahat:** Coding Plan 1/7 narxda 3× kvotani taklif qiladi! Har kuni soat 10:00 da tiklanadi.

#### MiniMax M2.1 (5 soatlik tiklanish, $0.20/1M)

1. Ro‘yxatdan o‘ting: [MiniMax](https://www.minimax.io)
2. API kalitini oling → Boshqaruv paneli → API kalitini qo‘shish

**Foydalanish:** `minimax/MiniMax-M2.1` — **Foydali maslahat:** Uzoq kontekst uchun eng arzon variant (1M token)!

#### Kimi K2 ($9/oy qat’iy to‘lov)

1. Obuna bo‘ling: [Moonshot AI](https://platform.kimi.ai?aff=omniroute)
2. API kalitini oling → Boshqaruv paneli → API kalitini qo‘shish

**Foydalanish:** `kimi/kimi-k2.5` — **Foydali maslahat:** 10M token uchun oyiga qat’iy $9 = amaldagi xarajat $0.90/1M!

#### Baidu Qianfan / ERNIE

1. Ro‘yxatdan o‘ting: [Baidu AI Cloud Qianfan](https://cloud.baidu.com/product/wenxinworkshop)
2. Qianfan API kalitini yarating → Boshqaruv paneli → API kalitini qo‘shish: Provayder: `qianfan`

**Foydalanish:** `qianfan/ernie-5.1`, `qianfan/ernie-x1.1` yoki Qianfan bilan OpenAI’ga mos boshqa model identifikatori.

### 🆓 BEPUL provayderlar

Autentifikatsiyasiz bepul provayderlar sahifasida **Autentifikatsiya talab qilinmaydi**
yonida almashtirgichga ega. Uni o‘chirish provayderni o‘chiradi, uni Provayderlar
sozlangan/ixcham ko‘rinishlaridan olib tashlaydi va uning modellarini `/v1/models` dan
olib tashlaydi.

#### Qoder (9 ta BEPUL model)

```bash
Boshqaruv paneli → Qoder’ga ulanish → OAuth orqali kirish → Kirish amaldagi provayder cheklovlariga bog‘liq
```

## 🚀 joylashtirish

### Global npm o'rnatish (Tavsiya etiladi)

```bash
npm install -g omniroute

# Create config directory
mkdir -p ~/.omniroute

# Create .env file (see .env.example)
cp .env.example ~/.omniroute/.env

omniroute

```

CLI avtomatik ravishda `.env` `~/.omniroute/.env` yoki `./.env` dan yuklaydi. Ishchi katalogdagi `./.env` faqat kalitlarning qisqa ruxsat etilgan ro'yxatini o'rnatishi mumkin (portlar, `REQUIRE_API_KEY`, mahalliy va rang sozlamalari); qolgan hamma narsani `~/.omniroute/.env` ga qo'ying. [CLI ishga tushirish shartnomalariga](CLI-LAUNCH-CONTRACTS.md#working-directory-env) qarang.

### Tovoqlar rejimi

Tizim tepsisida OmniRoute ishga tushiring:

```bash
omniroute serve --tray
```

Buyruq server va laganda tayyor bo'lgandan keyin qaytadi.

Server terminalsiz davom etadi.

Tovoqlar rejimi macOS, Windows va grafik Linux seanslarini qo'llab-quvvatlaydi. Tovoqlar rejimi asboblar panelini avtomatik ravishda ochmaydi.

Ushbu amallar uchun laganda menyusidan foydalaning:

- Boshqaruv panelini oching.
- `/dashboard/logs` ni oching.
- Avtomatik ishga tushirishni o'zgartiring.
- OmniRoute to'xtating.

`--tray` quyidagi variantlar bilan birlashtirmang:

- `--daemon`
- `--log`
- `--no-recovery`

Bu rejimlar turli jarayon egaligini talab qiladi.

Keyingi tizimga kirishda ishga tushirishni yoqing:

```bash
omniroute autostart enable
```

Avtomatik ishga tushirish macOS, Windows va grafik Linux seanslarida laganda rejimidan foydalanadi. Headless Linux mavjud systemd foydalanuvchi xizmatidan foydalanadi.

Kirish paytida ishga tushirishni o'chirib qo'ying:

```bash
omniroute autostart disable
```

<summary><b>xbps-src shablonini ko'rish</b></summary>

```bash
# Template file for 'omniroute'
pkgname=omniroute
version=3.8.0
revision=1
hostmakedepends="nodejs python3 make"
depends="openssl"
short_desc="Universal AI gateway with smart routing for multiple LLM providers"
maintainer="zenobit <zenobit@disroot.org>"
license="MIT"
homepage="https://github.com/diegosouzapw/OmniRoute"

system_accounts="_omniroute"
omniroute_homedir="/var/lib/omniroute"
export NODE_ENV=production
export npm_config_engine_strict=false
export npm_config_loglevel=error
export npm_config_fund=false
export npm_config_audit=false

do_build() {
	# Determine target CPU arch for node-gyp
	local _gyp_arch
	case "$XBPS_TARGET_MACHINE" in
		aarch64*) _gyp_arch=arm64 ;;
		armv7*|armv6*) _gyp_arch=arm ;;
		i686*) _gyp_arch=ia32 ;;
		*) _gyp_arch=x64 ;;
	esac

	# 1) Install all deps – skip scripts
	NODE_ENV=development npm ci --ignore-scripts

	# 2) Build the Next.js standalone bundle
	npm run build

	# 3) Copy static assets into standalone
	cp -r .next/static .next/standalone/.next/static
	[ -d public ] && cp -r public .next/standalone/public || true

	# 4) Compile better-sqlite3 native binding
	local _node_gyp=/usr/lib/node_modules/npm/node_modules/node-gyp/bin/node-gyp.js
	(cd node_modules/better-sqlite3 && node "$_node_gyp" rebuild --arch="$_gyp_arch")

	# 5) Place the compiled binding into the standalone bundle
	local _bs3_release=.next/standalone/node_modules/better-sqlite3/build/Release
	mkdir -p "$_bs3_release"
	cp node_modules/better-sqlite3/build/Release/better_sqlite3.node "$_bs3_release/"

	# 6) Remove arch-specific sharp bundles
	rm -rf .next/standalone/node_modules/@img

	# 7) Copy pino runtime deps omitted by Next.js static analysis:
	for _mod in pino-abstract-transport split2 process-warning; do
		cp -r "node_modules/$_mod" .next/standalone/node_modules/
	done
}

do_check() {
	npm run test:unit
}

do_install() {
	vmkdir usr/lib/omniroute/.next
	vcopy .next/standalone/. usr/lib/omniroute/.next/standalone

	# Prevent removal of empty Next.js app router dirs by the post-install hook
	for _d in \
		.next/standalone/.next/server/app/dashboard \
		.next/standalone/.next/server/app/dashboard/settings \
		.next/standalone/.next/server/app/dashboard/providers; do
		touch "${DESTDIR}/usr/lib/omniroute/${_d}/.keep"
	done

	cat > "${WRKDIR}/omniroute" <<'EOF'
#!/bin/sh
export PORT="${PORT:-20128}"
export DATA_DIR="${DATA_DIR:-${XDG_DATA_HOME:-${HOME}/.local/share}/omniroute}"
export APP_LOG_TO_FILE="${APP_LOG_TO_FILE:-false}"
mkdir -p "${DATA_DIR}"
exec node /usr/lib/omniroute/.next/standalone/server.js "$@"
EOF
	vbin "${WRKDIR}/omniroute"
}

post_install() {
	vlicense LICENSE
}
```

### Marshrutlash strategiyalari

orqali sozlang** Boshqaruv paneli → sozlamalari → Routing** . Boshqaruv paneli eng ko'p ishlatiladigan oltita strategiyani ochib beradi; kombinatsiyalar va avtomatik router ichki kengroq to'plamni qo'llab-quvvatlaydi.

**Boshqaruv panelida ko'rinadigan strategiyalar (hisob darajasidagi marshrutlash):**

| Strategiya                      | Tavsif                                                                                                                             |
| ------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| **Avval to'ldirish**            | Hisoblardan ustuvor tartibda foydalanadi - asosiy hisob mavjud bo'lmaguncha barcha so'rovlarni bajaradi                            |
| **Round Robin**                 | Sozlanishi mumkin bo'lgan yopishqoq chegara bilan barcha hisoblar bo'ylab aylanish (standart: har bir hisob uchun 3 ta qo'ng'iroq) |
| **P2C (ikki tanlov kuchi)**     | 2 ta tasodifiy hisob va sog'lomroq bo'lgan yo'nalishni tanlaydi - salomatlik haqida xabardorlik bilan yukni muvozanatlashtiradi    |
| **Tasodifiy**                   | Fisher-Yates shuffle yordamida har bir so'rov uchun tasodifiy hisob qaydnomasini tanlaydi                                          |
| **Eng kam ishlatilgan**         | Trafikni teng ravishda taqsimlovchi eng qadimgi `lastUsedAt` vaqt tamg'asi bilan hisob qaydnomasiga yo'nalishlar                   |
| **Xarajat optimallashtirilgan** | Eng past ustuvor qiymatga ega hisob qaydnomasiga marshrutlar, eng arzon provayderlar uchun optimallashtirish                       |

**Kengaytirilgan kombinatsiyalangan va avtomatik strategiyalar** (har bir kombinatsiya yoki `auto/*` prefikslari orqali sozlanishi mumkin - [AUTO-COMBO.md](../routing/AUTO-COMBO.md) ga qarang):

- `priority` - qat'iy tartib, hech qachon round-robins
- `weighted` - har bir model og'irliklari bo'yicha proportsional trafik taqsimoti
- `fill-first` - chegaraga yetguncha birinchi modelni to'kib tashlang
- `round-robin` / `strict-random` / `random`
- `p2c` (ikki tanlov kuchi)
- `least-used` va `cost-optimized`
- `auto` - barcha nomzodlar bo'yicha ballga asoslangan
- `lkgp` (Oxirgi ma'lum bo'lgan yaxshi provayder) - oxirgi muvaffaqiyatli provayderni bog'laydi, keyin qoidalarga qaytadi
- `context-optimized` — eng katta bepul kontekst oynasiga ega modelni tanlaydi
- `context-relay` - keyingi burilishlar uchun zanjirlar uzoq kontekstli modellar

### Chidamlilik va o'chirish to'xtatuvchilari

orqali sozlang** Boshqaruv paneli → sozlamalari → Moslashuvchanlik** .

OmniRoute besh komponentdan iborat provayder darajasidagi chidamlilikni amalga oshiradi:

1. **Navbat va tezlikni soʻrash** - Tizim darajasidagi so'rovni shakllantirish:
   - **Daqiqada so'rovlar (RPM)** — Hisob uchun daqiqada maksimal so'rovlar

   - **Bir vaqtning o'zida maksimal so'rovlar** — Bir hisob uchun bir vaqtning o'zida maksimal so'rovlar

2. **Ulanishni sovutish** — Qayta urinib ko‘rish mumkin bo‘lgan nosozliklardan so‘ng bitta ulanish uchun autent turidagi konfiguratsiya:
   - **Asosiy sovutish** — Qayta urinish mumkin bo'lgan yuqori oqimdagi nosozliklar uchun standart sovutish oynasi
   - **Upstream qayta urinish boʻyicha maslahatlardan foydalaning** — Taqdim etilganda nufuzli `Retry-After` hurmat qiladi yoki maslahatlarni tiklash
   - **Maksimal orqaga qaytish qadamlari** — Takroriy nosozliklar uchun maksimal eksponensial orqaga qaytish darajasi

3. **Provayder o'chirgich** — Oxir-oqibat provayder nosozliklarini kuzatib boradi, sozlangan ogohlantirish chegarasida yomonlashgan provayderni belgilaydi va sozlangan nosozlik chegarasiga erishilganda to‘xtatuvchini ochadi:
   - **Degradatsiya chegarasi** — `DEGRADED` kirishdan oldin provayderning ketma-ket nosozliklari
   - **Muvaffaqiyatsizlik chegarasi** — `OPEN` kirishdan oldin provayderning ketma-ket nosozliklari
   - **Vaqt tugashini tiklash** — Provayder yana sinovdan o'tishidan oldingi vaqt oynasi
   - **CLOSED** (Sog'lom) - So'rovlar odatdagidek oqadi
   - **DEGRADED** — Yuqori nosozliklar kuzatilganda, so'rovlar davom etmoqda
   - **OPEN** — Takroriy nosozliklardan keyin provayder vaqtincha bloklanadi
   - **HALF_OPEN** — Provayder tiklanganligini tekshirish

   Ulanish doirasidagi `429` tarifi chegaralari saqlanib qoladi** Ulanishni sovutish** va provayder to'xtatuvchisi tomon hisoblamang.

   Provayderni to'xtatuvchining ish vaqti holati yoniqda ko'rsatiladi** Boshqarish paneli → Health** faqat.

4. **Sovutishni kuting** — Agar har bir nomzod aloqasi allaqachon sovigan bo'lsa, OmniRoute eng erta sovishini kutishi va xuddi shu mijoz so'rovini avtomatik ravishda qaytadan sinab ko'rishi mumkin.

| **Ma'lumotlar bazasini eksport qilish** | Joriy SQLite ma'lumotlar bazasini `.sqlite` fayli sifatida yuklaydi                                                                                                                 |
| **Hammasini eksport qilish (.tar.gz)**  | To'liq zaxira arxivini yuklab oladi, jumladan: ma'lumotlar bazasi, sozlamalar, kombinatsiyalar, provayder ulanishlari (hisob ma'lumotlari yo'q), API kalit metadata                 |
| **Import ma'lumotlar bazasi**           | Joriy ma'lumotlar bazasini almashtirish uchun `.sqlite` faylini yuklang. Importdan oldingi zahira nusxasi `DISABLE_SQLITE_AUTO_BACKUP=true` bo'lmasa, avtomatik ravishda yaratiladi |

```bash
# API: Export database
curl -o backup.sqlite http://localhost:20128/api/db-backups/export

# API: Export all (full archive)
curl -o backup.tar.gz http://localhost:20128/api/db-backups/exportAll

# API: Import database
curl -X POST http://localhost:20128/api/db-backups/import \
  -F "file=@backup.sqlite"
```

**Import tekshiruvi:** Import qilingan fayl yaxlitligi (SQLite pragma tekshiruvi), kerakli jadvallar (`provider_connections`, `provider_nodes`, `combos`, `api_keys`) va hajmi (maksimal 100MB) uchun tasdiqlangan.

- Mashinalar o'rtasida OmniRoute ko'chiring
- Favqulodda vaziyatlarni tiklash uchun tashqi zaxira nusxalarini yarating
