## Kategoriyalar

- **Bepul** API kalitli — bepul darajasi (boshqaruv paneli orqali sozlangan)
- **No-auth** — umumiy so'nggi nuqtalari kalit yoki tizimga kirishni talab qilmaydi
- **OAuth** — kirish oqimi OmniRoute tomonidan boshqariladi, API kaliti kerak emas
- **Veb-cookie** — provayderning veb-ilovasini cookie-fayllarni tasdiqlash orqali o'rab oladi
- **API kaliti** API kaliti orqali sozlangan — pullik provayder (bepul kreditlar qo'llanilishi mumkin)
- **Mahalliy** — foydalanuvchi mashinasida ishlaydi (Ollama, LM Studio, vLLM va boshqalar).
- **Qidiruv** — veb-qidiruv provayderlari
- **Audio** — faqat audio provayderlari (TTS/STT)
- **Yuqoridagi proksi-server** — provayderlari boshqa provayderlarga proksi-server
- **Bulutli agent** — uzoq muddatli kodlash agentlari (Codex Cloud, Devin, Jules)
- **Tizim** — OmniRoute-ichki provayderlar (loopback va boshqalar)

Qo'shimcha teglar: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (ko'rsatilgan joyda): `native` — real funktsiyani chaqiruvchi API; `emulated` — `tools` massivi `webTools.ts` (regex-parsed `<tool>{...}</tool>` bloklari) orqali tezkor emulyatsiya qilinadi; `none` — `tools` hozirda jimgina o'chirilgan. #7286 ga qarang.

Har bir provayderni yoqish, sozlash va sinab ko'rish uchun `/dashboard/providers` -dagi asboblar panelidan foydalaning.
