> OmniRoute xatti-harakatini **qayta joylashtirmasdan** oʻzgartiradigan ish vaqti almashtirgichlari.
> Bu yerda keltirilgan har bir bayroq
> [`src/shared/constants/featureFlagDefinitions.ts`](../../src/shared/constants/featureFlagDefinitions.ts)
> faylida belgilangan — bu yagona ishonchli manba. Boshqaruv paneli ham, REST API ham
> shu fayldan maʼlumot oladi, shuning uchun quyidagi jadval unga 1:1 mos ravishda yaratilgan.

---

## Funksiya bayroqlari nima

Funksiya bayrogʻi — qiymati ish vaqtida oʻzgartirilishi va maʼlumotlar bazasida
saqlanishi mumkin boʻlgan nomlangan almashtirgich (`boolean` yoki `enum`) boʻlib,
buning uchun jarayonni qayta joylashtirish talab qilinmaydi. Har bir bayroq `key`,
`label`, `description`, `category`, `defaultValue`, `type` va `requiresRestart`
koʻrsatmasiga ega `FeatureFlagDefinition` orqali tavsiflanadi.

### Aniqlash tartibi

Bayroqning **amal qiluvchi qiymati**
[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) tomonidan
quyidagi ustuvorlik asosida aniqlanadi (eng yuqori ustuvorlikdagi qiymat tanlanadi):

1. **DB ustuvor qiymati** — `feature_flags` nomlar makonidagi `key_value`
   jadvalida saqlanadigan qiymat (boshqaruv paneli yoki REST API orqali oʻrnatiladi).
2. **Muhit oʻzgaruvchisi** — agar oʻrnatilgan va boʻsh boʻlmasa,
   `process.env[<KEY>]`.
3. **Taʼrifdagi standart qiymat** — `featureFlagDefinitions.ts` faylidagi
   `defaultValue`.

Agar `boolean` bayroqning amal qiluvchi qiymati `"true"`, `"1"` yoki `"yes"`
boʻlsa, u **yoqilgan** hisoblanadi (`isFeatureFlagEnabled()`ga qarang).

> [!NOTE]
> Aksariyat bayroqlar uchun [`ENVIRONMENT.md`](./ENVIRONMENT.md) faylida
> hujjatlashtirilgan, **xuddi shu nomdagi** mos muhit oʻzgaruvchisi ham mavjud.
> Bayroqning DB ustuvor qiymati ushbu muhit oʻzgaruvchisidan ustun turadi.
> `requiresRestart: true` qiymatiga ega bayroq darhol saqlanadi, ammo faqat
> jarayon ishga tushirilganda qayta oʻqiladi — uni almashtirish boshqaruv panelida
> **"Serverni qayta ishga tushirish"** bannerini koʻrsatadi.

| `CREDENTIAL_GATE_AUTH_DIAGNOSES_ONLY`     | boolean | `false` | Kombinatsiyalangan credential gate’ni toraytiradi: keshlangan muvaffaqiyatsiz credential tekshiruvi faqat uning tashxisi noto‘g‘ri credential’larni isbotlagandagina ulanishni bloklaydi (`upstream_auth_error`, `auth_missing`, `token_expired`, `token_refresh_failed`, `reauth_required`, `account_deactivated`, `auth_required`). Transport tashxislari (`network_error`, `upstream_unavailable`, `upstream_rate_limited`) har doim noaniq bo‘lib qoladi va bu flag o‘chirilgan bo‘lsa ham dispatch’ni bloklamaydi. Yoqilganda, boshqa noaniq tashxislar (noaniq xatolar, qo‘llab-quvvatlanmaydigan tekshiruvlar va tiplanmagan scheduler xatolari) ham noma’lum deb hisoblanadi va trafik o‘tkaziladi. Sukut bo‘yicha o‘chirilgan: keshdagi boshqa tekshiruv xatolari cache TTL davomida (5 daqiqa) dispatch’ni bloklaydi. |

> [!NOTE]
> `INPUT_SANITIZER_BLOCK_THRESHOLD` va uning eski taxallusi
> `INJECTION_GUARD_BLOCK_THRESHOLD` `INJECTION_GUARD_MODE` ning
> `block` rejimini sozlaydi, biroq ular feature flag emas, balki
> [`src/shared/utils/injectionSeverity.ts`](../../src/shared/utils/injectionSeverity.ts)
> tomonidan o‘qiladigan oddiy muhit o‘zgaruvchilaridir: ular uchun DB override’i
> va dashboard tugmasi mavjud emas. [`ENVIRONMENT.md`](./ENVIRONMENT.md#4-security--authentication)
> ga qarang.

> [!NOTE]
> `Restart` ustuni `requiresRestart: true` bo‘lgan flag’larni bildiradi — qiymat
> darhol saqlanadi, biroq faqat jarayon qayta yuklangandan keyin kuchga kiradi. Enum
> flag’lar ruxsat etilgan to‘plamdan tashqaridagi har qanday qiymatni rad etadi

## Bayroqlarni yoqish/o‘chirish

### Boshqaruv paneli

**Dashboard → Sozlamalar → Funksiya bayroqlari**
(`/dashboard/settings/feature-flags`) bo‘limiga o‘ting. Grid
(`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`)
quyidagilarni qo‘llab-quvvatlaydi:

- Kalit yoki tavsif bo‘yicha **qidirish** va kategoriya bo‘yicha **filtrlash** (shuningdek, sun’iy
  **Qayta ishga tushirish talab etiladi** ko‘rinishi).
- Mantiqiy qiymatli bayroqlar uchun **almashtirgich** va enum bayroqlar uchun
  **ochiluvchi ro‘yxat**
  (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`).
- Har bir bayroq uchun — amaldagi qiymat qayerdan olinganini ko‘rsatuvchi
  `DB`, `ENV` yoki `DEF` **manba nishoni**.
- Faqat `DB` manbali bayroqlar uchun ko‘rsatiladigan **Tiklash** tugmasi
  (override’ni olib tashlash uchun) va pastda joylashgan **Barcha override’larni tiklash** tugmasi.
- `requiresRestart` bayrog‘i o‘zgartirilganda **Serverni qayta ishga tushirish** banneri.

### REST API

Barcha amallar yagona yo‘nalish orqali bajariladi:
[`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts).
Har bir metod autentifikatsiyadan o‘tgan boshqaruv paneli sessiyasini talab qiladi
(aks holda `401` qaytariladi).

#### `GET /api/settings/feature-flags`

Har bir bayroqni uning amaldagi qiymati, manbasi va jamlanma ma’lumotlari bilan qaytaradi.

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "API kalitini talab qilish",
      "description": "Barcha kiruvchi so‘rovlar uchun API kalitini talab qilish",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... barcha 115 ta bayroq
  ],
  "summary": {
    "total": 115,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

Bitta override’ni o‘rnatadi yoki olib tashlaydi. Body: `{ key: string; value?: string }`.
`value`ni kiritmaslik override’ni olib tashlaydi (env / standart qiymatni tiklaydi).

```bash
# DB override’ini o‘rnatish
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# Override’ni olib tashlash ("value"siz)
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

Javobda yangi `effectiveValue`/`source`, `previousValue`/
`previousSource` va `requiresRestart` qiymatlari qaytariladi. Noma’lum kalitlar va ruxsat
etilgan diapazondan tashqaridagi enum qiymatlar `400` xatosi bilan rad etiladi.

#### `DELETE /api/settings/feature-flags`

Barcha DB override’larini bir vaqtning o‘zida tozalaydi va har bir bayroq uchun env / standart
qiymatni tiklaydi. `{ cleared: <count>, message: "..." }` obyektini qaytaradi.

> [!NOTE]
> `requiresRestart: true` bo‘lgan bayroqlar faqat jarayon qayta yuklangandan keyin kuchga kiradi.
> Boshqaruv panelining qayta ishga tushirish oqimi `POST /api/restart` chaqiradi, so‘ng server qayta
> ishga tushguncha `GET /api/health/ping` orqali tekshiradi.

## Favqulodda byudjet zaxira mexanizmi

`OMNIROUTE_EMERGENCY_FALLBACK` (`runtime` toifasi, standart qiymati `true`)
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts)
faylidagi favqulodda bepul zaxira yoʻlini boshqaradi. U yoqilganida, byudjeti
tugagan soʻrovlar butunlay muvaffaqiyatsiz yakunlanish oʻrniga bepul zaxira
provayder/modelga yoʻnaltiriladi. Bu xatti-harakatni oʻchirib qoʻyish va byudjeti
tugagan soʻrovlarning muvaffaqiyatsiz yakunlanishiga ruxsat berish uchun boshqaruv
panelidagi almashtirgich, maʼlumotlar bazasidagi ustuvor sozlama yoki
`OMNIROUTE_EMERGENCY_FALLBACK` muhit oʻzgaruvchisi orqali uni `false` (yoki `0`)
qiymatiga oʻrnating. (PR #3741 / #3752 da boshqaruv paneli almashtirgichi
sifatida taqdim etilgan.)

Ushbu zaxira mexanizmi orqali taqdim etilgan javobda
`X-OmniRoute-Emergency-Fallback: from=<provider/model>; to=<provider/model>`
sarlavhasi boʻladi, shuning uchun mijoz `X-OmniRoute-Provider` qiymatini oʻz
soʻrovi bilan taqqoslamasdan turib, soʻrov qayta yoʻnaltirilganini aniqlay oladi.
Boshqa barcha javoblarda bu sarlavha mavjud boʻlmaydi.
