## Tasuta žetoonid kuus: ~ 11.3B, kuna teised loetakse · ~ 90M päris

</div>

> **~ 11.3B tasuta žetoone kuus**<br/> <sub> loendas nii, nagu loevad teised kataloogid: iga rida liideti, lõppenud pakkumised hõlmasid </sub>
>
> **~ 90M real täna**<br/> <sub> iga jagatud kvooti loetakse üks kord: mida saate </sub> tegelikult kasutada
>
> **Kõik siin on tasuta. Ei mingit maksemüüri.**<br/> ★ [Meeldib? Tähistage meid GitHub](https://github.com/cheaper-inference/OmniRoute)

Teised kataloogid nõuavad reaalajas andmetele juurdepääsu eest eluaegset juurdepääsu alates US 19 dollarist aastas kuni 49 US. Siin on kõik tasuta. <sub> Hinnad kontrollitud 18.11.2026.</sub>

<sub>Kataloogi viimati auditeeritud 2026-11-23. [Kuidas me loeme →](docs/reference/FREE_TIERS.md#how-we-count)</sub>

> **Tooge oma teenusepakkuja kontod.** Need on kolmanda osapoole tasuta tasemed, mitte OmniRoute sümboolne toetus. Registreeruge, hankige mandaadid, kui teenusepakkuja neid küsib, ja ühendage need, mida saate kasutada. Iga pakkuja määrab oma piirangud, saadavuse ja tingimused.
>
> Vabade tasandite käsitsi virnastamine tähendab kümneid SDKs, kümneid piiranguid ja selget ettekujutust sellest, mis teil alles on. OmniRoute säilitab 214 vaba juurdepääsuga kataloogirida ja arvutab välja tegeliku arvu 12 kogumi kohta avaldatud kvoodiga, kusjuures iga jagatud kogum arvestatakse üks kord. Kvoodid, mis avanevad alles pärast piirkondlikku identiteedikontrolli (täna, ModelScope), kuvatakse eraldi, piirkondliku identiteedi kontrollimise taga on 6 miljonit +~ ja neid ei lisata kunagi tegelikule arvule. Ülejäänud kuvatakse armatuurlaual (`/dashboard/free-tiers`).

```bash
# After connecting a provider, create your OmniRoute key in Dashboard → API Keys:
curl http://localhost:20128/v1/chat/completions \
```

## Kombinatsioonid: lipulaev

1. **Alusta `auto`.** Seadistage mudel oma OpenAI-ga ühilduvas kliendis. OmniRoute loob ühendatud pakkujatest virtuaalse kombinatsiooni ja hindab kandidaate otseülekandes.
2. **Suurema kontrolli jaoks salvestage kombinatsioon.** Valige nimi, sihtloend ja strateegia ning kasutage seda nime mudelina. Strateegia määrab, milline eesmärk läheb esimesena ja kuidas ülejäänuid proovitakse.

Kombineeritud marsruudid läbivad mudelid automaatselt. Kvoodi ammendumise, teenusepakkuja tõrke või mudeli lukustamise korral proovib see järgmist sobivat, tervislikku sihtmärki.

### Zero-config: kasutage lihtsalt `auto`

```bash
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <your-omniroute-key>" \
  -H "Content-Type: application/json" \
  -d '{"model": "auto", "messages": [{"role": "user", "content": "Hello"}]}'
```

Variandid häälestavad raskusi. Viimane teadaolevalt hea marsruutimine jääb viimase eduka teenusepakkuja juurde, kuni see ebaõnnestub, ja seejärel skoori uuesti. `auto/fast` ja `auto/cheap` väljendavad eelistusi ilma kiireimat või odavamat mudelit tagamata.

| Mudel ID            | Käitumine                                                                                                                                                                                                                                                                         |
| :------------------ | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `auto`              | Tasakaalustatud vaikekaalud.                                                                                                                                                                                                                                                      |
| `auto/fast`         | Soosib madalat latentsust ja teenusepakkuja tervist.                                                                                                                                                                                                                              |
| `auto/cheap`        | Soosib madalamaid kataloogihindu.                                                                                                                                                                                                                                                 |
| `auto/coding`       | Kvaliteedi esmatähtsad kaalud koodi genereerimiseks.                                                                                                                                                                                                                              |
| `auto/smart`        | Kvaliteet esikohal 10% uurimisega (vaikimisi 5%).                                                                                                                                                                                                                                 |
| `auto/lkgp`         | Selgesõnaline viimane teadaolevalt hea marsruutimine sama kaaluga kui `auto`.                                                                                                                                                                                                     |
| `auto/subscription` | Kasutab ainult reaalajas kinnitatud paketi kvooti. Tagastab HTTP 503, kui ükski pole saadaval, ja väldib arveldatud varu.                                                                                                                                                         |
| `auto/thrifty`      | Plaan → võtmeta → tasuta → odav → premium. Võib jõuda arveldatud mudeliteni ja naaseb plaani juurde, kui kvoot ja jahtumine seda võimaldavad.                                                                                                                                     |
| `auto/offline`      | Soosib kvooti ja intressipiirangut. Taotlused lähevad endiselt teie teenusepakkujatele.                                                                                                                                                                                           |
| `auto/chaos`        | Paralleelselt üks mudel pakkuja kohta, vaikimisi kuni viis või konfigureerimisel kümme. Üks ülesvoolu kõne mudeli kohta. Tagastab kõrgeima asetusega vastuse või viimase eduka paneeli vastuse, kui tippmudel ebaõnnestub. Kasutage `fusion`, et sünteesida vastused kohtunikuga. |

Kategooria ja valikuliste tasandite näited hõlmavad `auto/coding:fast`, `auto/coding:free`, `auto/reasoning:pro` ja `auto/vision`. Kui ükski ühendatud kandidaat ei vasta, tagastab päring HTTP 503 ja kogum jääb kitsaks. [Auto-Combo juhend](./docs/routing/AUTO-COMBO.md) · [Tellimuse esimene marsruutimine](./docs/routing/SUBSCRIPTION_LADDER.md)

### Või looge ise: 22 marsruutimisstrateegiat

```bash
omniroute combo create my-pool --strategy fill-first \
  --models "provider-a/model-1,provider-b/model-2"
```

CLI aktsepteerib 15 strateegiat 22-st. Armatuurlaud ja kombod API aktsepteerivad kõiki 22.

| strateegia          | Käitumine                                                                                                                                                                                                                                        |
| :------------------ | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `auto`              | Edetatavad kandidaadid teevad 16-tegurilise automaatkombinatsiooni skooritegija otseülekande.                                                                                                                                                    |
| `cache-optimized`   | Eelistage kontot, mis tõenäoliselt hoiab vahemälus viipa eesliidet.                                                                                                                                                                              |
| `context-optimized` | Proovige esmalt suurimat teadaolevat konteksti akent.                                                                                                                                                                                            |
| `context-relay`     | Hoidke oma tellimus alles ja edastage konto vahetamisel vestluse kokkuvõte.                                                                                                                                                                      |
| `cost-optimized`    | Sorteeri kataloogi sisend-märgi hind, teadmata viimane. Lõpliku taotluse maksumus võib erineda.                                                                                                                                                  |

### Vastupidavus on sisse ehitatud: 3 sõltumatut kihti

Tõrkeid käsitletakse kolmes ulatuses, nii et üks halb mudel ei võta oma kontot maha ja üks halb konto ei eemalda oma pakkujat.

<img src="./docs/diagrams/resilience-layers.svg" width="100%" alt="OmniRoute resilience: 3 independent self-healing layers, the right layer for the right failure. Layer 1, provider circuit breaker (whole provider): trips only on 408/500/502/503/504, opens after 8 failures for OAuth providers or 12 for API-key providers, resets after 60s or 30s into a HALF-OPEN probe, lazy recovery; while OPEN the combo reroutes to the next provider. Layer 2, connection cooldown (one key or account): base 5s OAuth or 3s API-key, exponential backoff with an anti-thundering-herd guard, success clears the error state; one cooling key is skipped while sibling keys keep serving. Layer 3, model lockout (one model): per-model 429, 404 or access denials lock just that model, never the whole connection. Terminal states (banned, expired, credits exhausted) wait for the operator; they are not cooldowns."/>

#### Kui terve teenusepakkuja on maas

The** pakkuja kaitselüliti** avaneb pärast 8 (OAuth) või 12 (API klahv) tõrget olekuga 408, 500, 502, 503 või 504. Kombod jätavad selle pakkuja vahele, kui see on avatud. 60 s või 30 s pärast otsustab üks proovipäring, kas see sulgub.

#### Kui üks võti või konto on intressimääraga

The** ühenduse jahtumine** pingid ainult selle ühendusega, eksponentsiaalse tagasilöögiga alates 5 s (OAuth) või 3 s (API klahv). Teised sama teenusepakkuja võtmed jätkavad teenindamist.

#### Kui ühest mudelist keeldutakse

The** mudeli lukustus** blokeerib ainult selle mudeli sellel ühendusel pärast mudelikohta 429, 404 või juurdepääsu keelamist. Teised sama ühenduse mudelid jätkavad teenindamist.

Keelatud, aegunud ja krediidiriski lõppenud ühendused on terminaliseisundid, mitte jahtumised: nad ootavad, kuni te need parandate.

## Täielik CLI, MCP ja A2A

> OmniRoute saadab käsurea kliendi koos** 91 tipptaseme käsku ja käsugruppe** (754 käsku loeb alamkäske), an**MCP server 110 tööriista ja 33 ulatusega** ja an**A2A agent 6 oskusega** . Skriptid, terminalid ja AI agendid võivad kõik töötada sama lüüsi.

### Tõeline CLI, mitte ainult `start`

```bash
omniroute                 # start the gateway and dashboard (port 20128)
omniroute setup           # guided first-run wizard
omniroute repl            # interactive chat in the terminal (/model /combo /skill /memory)
omniroute chat "hello"    # one-shot prompt; also reads --file or --stdin
omniroute doctor          # check config, database, ports, Node runtime and native deps
```

Globaalne `--output table|json|jsonl|csv` lipp muudab samad käsud kasutatavaks skriptidest ja CI.

### Kaugrežiim: CLI teie sülearvutis, OmniRoute serveris

Logige üks kord sisse kaugserverisse. CLI salvestab selle kui a** konteksti** , ja hilisemad käsud töötavad selle serveri vastu, kuni tagasi lülitate.

```bash
omniroute connect omniroute.example.com          # asks for the password, saves a scoped token as a context
omniroute models                                 # runs against the remote server
omniroute configure codex                        # picks a remote model, writes a local Codex profile
omniroute tokens create --name ci --scope read   # mint a narrower token for another machine
omniroute contexts use default                   # switch back to the local server
```

| Märgi ulatus | <img width="2000" height="0" alt=""> Mida see võimaldab                                    |
| ------------ | ------------------------------------------------------------------------------------------ |
| `read`       | Loetlege ja kontrollige: mudelid, olek, logid, kasutus                                     |
| `write`      | `read` plus konfigureerimine ja rakendamine: kliendi seadistamine, võtmed, konfiguratsioon |
| `admin`      | `write` plus haldab: märgid, pakkujad, teenused, poliitika                                 |

Paljas peremees saab `http://` ja port 20128; läbima täieliku `https://` URL, kui server istub TLS taga. Marsruudid, mis võivad protsesse esile kutsuda, jäävad ainult loopbacki, olenemata märgist.

### Ühendage agent

Agent või teie enda kood võib juhtida marsruutimist, pakkujaid, kombinatsioone, vahemälu, tihendamist ja mälu kõigi nende liideste kaudu. HTTP teid teenindab lüüs, vaikimisi aadressil `http://localhost:20128`.

| Liides                   | Lõpp-punkt või käsk        | Kasutage seda selleks                                                          |
| ------------------------ | -------------------------- | ------------------------------------------------------------------------------ |
| MCP üle stdio            | `omniroute --mcp`          | Claude Desktop, Cursor ja muud kohalikud MCP kliendid                          |
| MCP üle voogesituse HTTP | `/api/mcp/stream`          | MCP kaugkliendid: 110 tööriista, 33 ulatust, iga auditilogi kirjutatud kõne    |
| MCP üle SSE              | `/api/mcp/sse`             | Kliendid, kes kasutavad endiselt SSE transporti                                |
| A2A avastus              | `/.well-known/agent.json`  | Agendikaart: ütleb teistele agentidele, mida OmniRoute saab teha               |
| A2A hukkamine            | `POST /a2a`                | JSON-RPC 2.0 ülesanded, sünkroonsed või SSE kaudu voogesitatud, 6 oskuse kaudu |
| REST API                 | `/v1/*`                    | OpenAI-ga ühilduv vestlus, vastused, manustused, pildid, heli ja OCR           |
| Veebihaagid              | `/api/webhooks`            | Sündmused Slack, Discord, Telegram või mis tahes HMAC allkirjaga URL jaoks     |
| Kaugjuhtimispult CLI     | `omniroute connect <host>` | Juhtige kaugeksemplari hõlmatud juurdepääsulubadega                            |

Kuus A2A oskust on `smart-routing`, `quota-management`, `provider-discovery`, `cost-analysis`, `health-report` ja `list-capabilities`.

**Enne ühendamist:**

- **MCP over HTTP käivitub keelatud.** Lülitage see sisse `omniroute mcp enable --transport streamable-http` või armatuurlaua lõpp-punktide lehelt. Korraga on aktiivne üks HTTP transport: `streamable-http` teenindab `/api/mcp/stream`, `sse` teenindab `/api/mcp/sse`.
- **A2A käivitub keelatud.** Lubage see armatuurlaua lehel Lõpp-punktid. `POST /a2a` järgib seejärel samu API-võtme reegleid nagu `/v1`.
- **Kaug- MCP vajab sobivat võtit.** `/api/mcp/*` vastab vaikimisi ainult loopbackile. Saatke võti teisest hostist koos `manage` või `admin` (kõik tööriistad) või `mcp:connect` pluss vajalike tööriistade ulatustega. Ilma `manage`/`admin` võtmete puhul rakendatakse alati tööriista ulatust.

```bash
  --header "Authorization: Bearer <api-key-with-manage-scope>"
```

### Kuidas see töötab — torujuhtme, arhitektuuri ja säästumatemaatika

<img src="./docs/diagrams/compression-pipeline.svg" width="100%" alt="OmniRoute compression pipeline: an illustrative 10,000-token client request passes through 12 composable engines — Session-Dedup, CCR, Lite, RTK, Responses Tool Output, Headroom, Relevance, Caveman, Aggressive, LLMLingua-2, Ultra and OmniGlyph — and can reach the provider at about 1,080 tokens in the documented stacked example. Structured content is protected by preservation guards and per-step fidelity gates; explicit lossy or experimental modes may transform eligible content."/>

Vaikimisi virnastatud kombinatsioon töötab `RTK → Caveman`. Kui mõlemad toimivad sama tool/context kasuliku koormusega, on säästuühend:

```txt
combined = 1 − (1 − RTK) × (1 − Caveman_input)
average  = 1 − (1 − 0.80) × (1 − 0.46) = 89.2%
range    = 78.4 – 94.6%
```

## Rohkem installimeetodeid — Docker, allikas, pnpm, Arch

**🐳 Docker**

```bash
docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 \
  -p 127.0.0.1:20128:20128 -v omniroute-data:/app/data cheaperinference/omniroute:latest
```

`:latest` follows the highest** avaldatud** stable SemVer. See ei jälgi git `main`. Pin `:X.Y.Z` for GitOps. Vaadake jaotist [Docker Release Channels](docs/guides/DOCKER_GUIDE.md#release-channels). Kujutise tihvtid**`OMNIROUTE_MEMORY_MB=1024`** . Sellest piisab armatuurlauale ja kergeks vestluseks.** Coding agents** (`POST /v1/responses` koodist Claude Code, Codex, Grok, …) vajavad palju suuremat V8 hunnikut või protsessi `FATAL ERROR` s ~ 12 GiB juures kahe kattuva pika konteksti all. Määrake konteineri suurus kuhja kohal (natiivsed puhvrid asuvad väljaspool V8):

| <img width="2000" height="0" alt=""> töökoormus | hunnik (`-e OMNIROUTE_MEMORY_MB`) | konteiner (`--memory`) |

| Armatuurlaud / kerge vestlus                    | `1024` (pildi vaikeseade)         | ≥ 2 g                  |
| Üks kodeeriv agent                              | `8192`                            | ≥ 10 g                 |
| Kaks samaaegset pikka `/v1/responses`           | `10240`–`12288`                   | ≥ 12–16 g              |

### Kuidas panustada

1. Hark hoidla
2. Filiaal alates** aktiivne** `release/vX.Y.Z` tip (mitte `main`) — vt [Hargnemis- ja vabastamismudel](docs/ops/BRANCHING_MODEL.md)
3. Looge oma funktsioonide haru (`git checkout -b feat/amazing-feature`)

5. Lükake oksale (`git push origin feat/amazing-feature`)
6. Avage tõmbetaotlus rakendusega** alus = et `release/vX.Y.Z` haru**
