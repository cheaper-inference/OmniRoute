## Mis see on

OmniRoute ühendub **Obsidiani** hoidlaga kui **kontekstiallikaga** — kohaliku Markdowni
teadmusbaasiga, mida agendid loevad ja kirjutavad sisseehitatud MCP-serveri kaudu.
Integratsioon suhtleb töölauarakenduses töötava kogukonna lisandmooduli
**Obsidian Local REST API** kaudu, võimaldades agentidel otsida märkmeid, lugeda,
kirjutada ja paigata faile, kuvada hoidla sisu, töötada päeva- ja nädalapõhiste
perioodiliste märkmetega, hallata silte, käivitada Obsidiani käske ning (valikuliselt)
koordineerida kahesuunalist töölaua↔mobiilseadme hoidla sünkroonimist.

Klient (`src/lib/obsidian/api.ts`) ümbritseb Local REST API järgmiste funktsioonidega:

- **Eksponentsiaalse viivitusega korduskatsed** ajutiste `5xx` vigade korral ja
  **30-sekundiline ajalõpp** `AbortController`-i kaudu.
- **Tüübitud vigade klassifitseerimine** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`.
- **Kasutajasõbralik vihje „Obsidianiga ei saa ühendust”**, mis juhib tähelepanu
  levinud pordiveale (HTTP pordil `27123`, **mitte** MCP lõpp-punkt pordil `27124`)
  ja Tailscale’i vormingule.
- Hoidla suhtes **relatiivsete teede kodeerimine**, et tühikute ja kaldkriipsudega
  märkmete teed oleksid turvalised.

## Seadistamine

Obsidiani tokeni ega baas-URL-i jaoks **pole keskkonnamuutujat** — mõlemad
salvestatakse SQLite'i tabelisse `key_value` (nimeruum `obsidian`) faili
`src/lib/db/obsidian.ts` kaudu. Token on **jõudeolekus krüpteeritud** (AES-256-GCM,
tagasiühilduvuse tagamiseks on olemas lihtteksti varuvariant). Seadistage see lõpp-punkti
juhtpaneeli vahekaardil **Context Sources** (`ObsidianSourceCard`) või sätete REST API
kaudu.

> [!IMPORTANT]
> Plugin **Obsidian Local REST API** peab olema installitud ja töötama. Selle REST-liides
> kuulab aadressil **HTTP `127.0.0.1:27123`** (vaikimisi baas-URL). Port `27124` on
> _eraldi_ MCP/HTTPS-lõpp-punkt ja sätete marsruut lükkab selle selgesõnaliselt tagasi.
> Teisest seadmest ühenduse loomisel kasutage aadressi `http://<tailscale-ip>:27123`.

### Konfiguratsioonivõtmed (SQLite'i `key_value`, nimeruum `obsidian`)

| Võti              | Otstarve                                                  | Krüpteeritud |
| ----------------- | --------------------------------------------------------- | ------------ |
| `api_key`         | Local REST API kandjatoken                                | jah          |
| `base_url`        | REST-i baas-URL (vaikimisi `http://127.0.0.1:27123`)      | ei           |
| `vault_path`      | Hoidla kataloogi absoluutne tee (sünkroonimiseks)         | ei           |
| `webdav_username` | Genereeritud WebDAV-i kasutajanimi (hoidla sünkroonimine) | ei           |
| `webdav_password` | Genereeritud WebDAV-i parool (hoidla sünkroonimine)       | jah          |
| `webdav_enabled`  | Kas WebDAV-i hoidla sünkroonimine on lubatud              | ei           |

### Seadistamine REST-i kaudu

```bash
# Salvesta ja valideeri Local REST API token (POST valideerib olekukontrolliga)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# Kontrolli ühenduse olekut (tagastab connected, hasToken, baseUrl, vaultPath)
curl http://localhost:20128/api/settings/obsidian

# Katkesta ühendus (kustutab salvestatud tokeni)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

Kõik meetodid nõuavad juhtpaneeli autentimist. `POST` lükkab tagasi kõik pordil `27124`
olevad URL-id ja valideerib tokeni enne salvestamist, kutsudes Local REST API
olekulõpp-punkti.

### WebDAV-i hoidla sünkroonimine

`src/app/api/settings/obsidian/webdav/route.ts` haldab valikulist WebDAV-il põhinevat
hoidla sünkroonimist (mida juhib `src/lib/obsidianSync.ts`). Selle lubamisel suunatakse
OmniRoute kohaliku hoidla kataloogi ning luuakse juhuslik WebDAV-i kasutajanime ja parooli
paar:

```bash
# Luba hoidla kataloogi WebDAV-sünkroonimine (loob kasutajanime/parooli)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# Hangi WebDAV-sünkroonimise olek (mandaadid tagastatakse ainult siis, kui see on lubatud)
curl http://localhost:20128/api/settings/obsidian/webdav

# Keela WebDAV-sünkroonimine (kustutab mandaadid ja hallatava .stignore-faili)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### Turvalisus ja transport

WebDAV autentimine jõustab IP-põhise rikete jälgimise ja lukustamise (10 ebaõnnestunud katset 60-sekundilise akna jooksul käivitavad 5-minutilise lukustuse `429 Too Many Requests` ja `Retry-After` abil). Kuna WebDAV edastab põhiautentimismandaadid, on WebDAV lõpp-punktile juurdepääsul väljaspool tagasisilmust tungivalt soovitatav TLS lõpetamine (või marsruutimine üle turvalise tunneli, näiteks Tailscale või Cloudflare Tunnel).

### API-võtmepõhine kontekstiallikas (valikuline)

Obsidiani konfiguratsiooni saab tabeli `api_key_context_sources`
(`src/lib/db/apiKeyContextSources.ts`) kaudu piiritleda **API-võtme põhiselt**. Kui
MCP-kutse sisaldab autenditud API-võtme ID-d, eelistab `getObsidianConfigForApiKey()`
selle võtme enda tokenit, baas-URL-i ja hoidla teed (`source: "api_key"`), vastasel juhul
kasutatakse globaalset konfiguratsiooni (`source: "global"`).

Sünkroonimisega mitteseotud MCP-tööriistad nõuavad enne selle konfiguratsiooni lugemist
helistaja tuvastatud identiteeti. Identiteedita helistaja saab vastuse
`Obsidian API token not configured` ja hoidlapäringut ei saadeta. HTTP-helistajad
tuvastatakse nende päringu mandaatide kaudu; stdio-helistajaid saab tuvastada
`OMNIROUTE_API_KEY` või `ROUTER_API_KEY` kaudu. Tuvastamata HTTP-helistaja ei saa
pärida serveri keskkonnaidentiteeti. Ainult kohatäite-ID-d ei anna juurdepääsu;
endiselt toetatakse kehtivat keskkonnamandaati, mis lahendatakse väärtuseks `env-key`.
Autenditud võtmed, millel puudub võtmepõhine Obsidiani konfiguratsioon, kasutavad endiselt
globaalset varuvarianti. Neli tööriista `obsidian_sync_*` säilitavad oma eraldiseisva
sünkroonimistokeni käitumise.

## MCP tööriistad (22)

Määratletud keeles `open-sse/mcp-server/tools/obsidianTools.ts`. token/base-URL lahendatakse kõne kohta (kõigepealt API-võtme kohta, seejärel globaalselt). Tööriistad, mis tabasid OmniRoute** sünkroonimisserver** (neli `obsidian_sync_*` tööriista) nõuavad lisaks OmniRoute sätetes konfigureeritud sünkroonimise autentimisluba.

### Lugemistööriistad (`read:obsidian`)

| Tööriist                     | Kirjeldus                                                                                         |
| ---------------------------- | ------------------------------------------------------------------------------------------------- |
| `obsidian_check_status`      | Kontrollige, kas kohalik REST API on juurdepääsetav ja autenditud.                                |
| `obsidian_search_simple`     | Märkme sisu täistekstiotsing; tagastab failiteedega katkendid.                                    |
| `obsidian_search_structured` | Otsige JSON Logic avaldise (and/or/regex/path filtrid) abil.                                      |
| `obsidian_read_note`         | Märkme lugemine võlvi suhtelise tee järgi; valikuliselt konkreetne heading/block/frontmatter.     |
| `obsidian_list_vault`        | Loetlege hoidlas olevad failid ja kataloogid (kirjete puu).                                       |
| `obsidian_get_document_map`  | Hankige märkme päise struktuur pealkirjade → ridade numbrite kaardina.                            |
| `obsidian_get_note_metadata` | Hankige esikülg, sildid, lingid, char/word loend ilma täieliku sisuta.                            |
| `obsidian_get_active_file`   | Hangi + s praegu aktiivse faili tee Obsidian.                                                     |
| `obsidian_get_periodic_note` | Hankige kuupäeva kohta daily/weekly/monthly perioodiline märge (kui see välja jäetakse täna).     |
| `obsidian_get_tags`          | Loetlege kõik varahoidla sildid koos nende sagedustega.                                           |
| `obsidian_list_commands`     | Loetlege saadaolevad Obsidian käsud IDs (kasutage koos `obsidian_execute_command`).               |
| `obsidian_sync_status`       | OmniRoute sünkroonimisserveri olek: töötab, varahoidla nimi, port, tööaeg, viimane sünkroonimine. |
| `obsidian_sync_conflicts`    | Loetlege lahendamata sünkroonimise konfliktid (tee, konflikti tee, tuvastatud-at).                |

### Kirjutamisvahendid (`write:obsidian`)

| Tööriist                         | Kirjeldus                                                                                                      |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| `obsidian_write_note`            | Looge või kirjutage üle antud Markdowni sisuga märge.                                                          |
| `obsidian_append_note`           | Lisa märkmele sisu; valikuliselt konkreetsele heading/block.                                                   |
| `obsidian_patch_note`            | Kirurgiliselt append/prepend/replace kursi, ploki või esiosa väljal.                                           |
| `obsidian_delete_note`           | Kustutage märge varahoidlast jäädavalt.                                                                        |
| `obsidian_move_note`             | Märkme teisaldamine või ümbernimetamine hoidlas.                                                               |
| `obsidian_execute_command`       | Käivitage Obsidian käsk selle käsuga ID.                                                                       |
| `obsidian_open_file`             | Avage fail Obsidian (loob selle, kui seda pole olemas).                                                        |
| `obsidian_sync_trigger`          | Käivitage kohene kahesuunaline töölaua ↔ mobiilihoidla sünkroonimine.                                          |
| `obsidian_sync_resolve_conflict` | Sünkroonimiskonflikti lahendamine: jätke alles `local` (mobiiltelefon), `remote` (lauaarvuti) või `keep-both`. |

> [!NOTE]
> `obsidian_patch_note` sihtmärgid aktsepteerivad `targetType` `heading | block | frontmatter` ja `operation` `append | prepend | replace` koos valikulise `createTargetIfMissing`. Neli `obsidian_sync_*` -tööriista suhtlevad kohaliku sünkroonimisserveriga (vaikimisi `http://127.0.0.1:27781` ) ja nõuavad sünkroonimisluba.

### Ulatused

Lugemistööriistad nõuavad `read:obsidian`; kirjutamistööriistad nõuavad `write:obsidian`. Jõustamine on identne Notion — mida haldab `withScopeEnforcement()` failis `open-sse/mcp-server/server.ts`, mis on väratud `OMNIROUTE_MCP_ENFORCE_SCOPES=true` ja sunnitud sisse lülitama HTTP/SSE helistajatele, kelle API -klahvil puudub `manage`/`admin`, lubatud ulatustega, mis pärinevad `OMNIROUTE_MCP_SCOPES` või API -võtme ulatuse kontekstist. Vaadake [MCP-SERVER.md](./MCP-SERVER.md).

## Lõpp-punktid

| Meetod   | Tee                             | Otstarve                                                            |
| -------- | ------------------------------- | ------------------------------------------------------------------- |
| `GET`    | `/api/settings/obsidian`        | Tagastab `{ connected, hasToken, baseUrl, vaultPath }`.             |
| `POST`   | `/api/settings/obsidian`        | Salvestab ja valideerib pääsutõendi (keeldub pordist `27124`).      |
| `DELETE` | `/api/settings/obsidian`        | Katkestab ühenduse (kustutab salvestatud pääsutõendi).              |
| `GET`    | `/api/settings/obsidian/webdav` | WebDAV-i sünkroonimise olek ja identimisteave (kui see on lubatud). |
| `POST`   | `/api/settings/obsidian/webdav` | Lubab hoidla kataloogi WebDAV-i kaudu sünkroonida.                  |
| `DELETE` | `/api/settings/obsidian/webdav` | Keelab WebDAV-i kaudu sünkroonimise.                                |

> Need on töölaua seadete marsruudid. Hoidlale endale pääseb ligi Obsidiani
> kohaliku REST API (seadistatud `base_url`) ja ülaltoodud MCP-tööriistade kaudu —
> avalikku Obsidiani `/v1`-puhverserveri lõpp-punkti ei ole.

## Kasutusjuhud

- **Hoidlal põhinevad vastused** — `obsidian_search_simple` / `obsidian_search_structured`
  ja seejärel `obsidian_read_note`, et agent vastaks sinu tegelike märkmete põhjal.
- **Märkmete koostamine / päeviku pidamine** — `obsidian_write_note`, `obsidian_append_note` või
  täppismuutmiseks mõeldud `obsidian_patch_note`, et logida agendi väljund, kokkuvõtted või igapäevased märkmed
  (`obsidian_get_periodic_note`) hoidlasse.
- **Hoidlas navigeerimine** — `obsidian_list_vault`, `obsidian_get_document_map` ja
  `obsidian_get_tags`, et uurida struktuuri enne lugemist/kirjutamist.
- **Obsidiani automatiseerimine** — `obsidian_list_commands` + `obsidian_execute_command`, et
  käivitada agendi kaudu pistikprogramme/käske; `obsidian_open_file`, et kuvada märge kasutajaliideses.
- **Mobiilne sünkroonimine** — luba WebDAV-i kaudu sünkroonimine, seejärel kasuta funktsioone `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`,
  et koordineerida töölaua↔mobiilseadme sünkroonimist ja lahendada konflikte.
