`@omniroute/opencode-plugin-v2` udostępnia cały katalog OmniRoute — modele, kombinacje i
automatyczne kombinacje — w selektorze modeli OpenCode v2 wraz z nazwami wyświetlanymi, cenami
i limitami bezpłatnych warstw.

Jest to pakiet odrębny od `@omniroute/opencode-plugin`, ponieważ OpenCode v1 i v2 ładują
wtyczki za pośrednictwem różnych kontraktów. Wybierz pakiet odpowiadający głównej wersji OpenCode;
nie współdzielą one żadnych elementów, więc aktualizacja jednego nigdy nie wymusza aktualizacji drugiego.

## Wymagania

- OpenCode v2.
- Osiągalna brama OmniRoute (domyślnie `http://localhost:20128`).
- Node.js 22 lub 24.

## Instalacja

Dodaj wtyczkę do `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

Modele pojawią się jako `omniroute/<provider>/<model>`; `providerId` określa ten prefiks oraz
identyfikator integracji, pod którym OpenCode przechowuje dane uwierzytelniające.

## Dane uwierzytelniające

Wtyczka szuka klucza bramy w trzech miejscach, w następującej kolejności:

1. **Dane uwierzytelniające połączone w OpenCode.** Wtyczka rejestruje integrację, dzięki czemu
   własny proces uwierzytelniania OpenCode może przechowywać klucz. Nic nie trafia do `opencode.json` — ta opcja jest zalecana.
2. `apiKey` w opcjach wtyczki jako nadpisanie dla konkretnego projektu. Powoduje to zapisanie klucza w pliku,
   który może być umieszczany w repozytorium.
3. `OMNIROUTE_API_KEY` w środowisku.

Jeśli nie podano żadnej z tych trzech wartości, katalog jest pusty, a wtyczka informuje o tym raz podczas uruchamiania,
zamiast pozostawiać pusty selektor bez żadnego komunikatu.

### Token zarządzania jest innym kluczem

Kombinacje, stan dostawców i wzbogacanie danych (nazwy wyświetlane, ceny, limity bezpłatnych warstw) pochodzą
z punktów końcowych `/api/*` bramy, które w większości wdrożeń są chronione **tokenem zarządzania**,
a nie kluczem wnioskowania:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<management read token>"
}
```

Jeśli `managementReadToken` nie jest ustawiony, używana jest wartość `apiKey`. Gdy brama odrzuci tę wartość zastępczą,
katalog nadal zostanie opublikowany, ale z surowymi identyfikatorami modeli zamiast nazw wyświetlanych, bez
deduplikacji aliasów kanonicznych, cen i kombinacji. Wtyczka ostrzega o tym raz dla każdego punktu końcowego,
podając jego nazwę i wskazując utracone informacje — dzięki temu przyczyna ograniczonego selektora zawsze jest jasna.

## Opcje

| Klawisz                          | Domyślny                                                          | Notatki                                                                                                                                                                                                                                                                                                                                                                        |
| -------------------------------- | ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `providerId`                     | `"omniroute"`                                                     | Identyfikator dostawcy, identyfikator integracji i modele prefiksów pojawią się poniżej                                                                                                                                                                                                                                                                                        |
| `baseURL`                        | wymagany                                                          | Korzeń bramy, tylko `http(s)` ; w razie potrzeby dodawany jest przyrostek `/v1`                                                                                                                                                                                                                                                                                                |
| `apiKey`                         | połączone dane uwierzytelniające, a następnie `OMNIROUTE_API_KEY` | Klucz czatu dla `/v1/*`                                                                                                                                                                                                                                                                                                                                                        |
| `managementReadToken`            | wraca do `apiKey`                                                 | Klucz do `/api/*` — zwykle** nie** ten sam                                                                                                                                                                                                                                                                                                                                     |
| `displayName`                    | `"OmniRoute"`                                                     | Nazwa dostawcy w selektorze                                                                                                                                                                                                                                                                                                                                                    |
| `timeoutMs`                      | `10000`                                                           | Limit czasu pobierania na punkt końcowy (automatyczne kombinacje trwają 5 s)                                                                                                                                                                                                                                                                                                   |
| `modelCacheTtlMs`                | `300000`                                                          | Pamięć podręczna katalogu TTL; migawka dysku podgrzewa zimne starty                                                                                                                                                                                                                                                                                                            |
| `timeouts`                       | wraca do `timeoutMs`                                              | Budżety na punkt końcowy w ms: `models`, `combos`, `autoCombos`, `enrichment`                                                                                                                                                                                                                                                                                                  |
| `enrichment`                     | `true`                                                            | Pobierz nazwy, ceny i budżety bezpłatnych poziomów                                                                                                                                                                                                                                                                                                                             |
| `providerTag`                    | `true`                                                            | Przełącz końcowy nawias edytora: `Provider - Model (Editor)`. Dostawca (trasa obsługująca model) jest zawsze pokazywany; redaktor (który stworzył model) pojawia się tylko w nawiasie. Przykład: `Openrouter - MoonshotAI: Kimi K 3.1 Pro` -> `Openrouter - Kimi K 3.1 Pro (MoonshotAI)`. Pomijane, gdy redaktor i dostawca mają wspólną nazwę. Ustaw `false`, aby go upuścić. |
| `usableOnly`                     | `false`                                                           | Przechowuj tylko dostawców, aby raporty bramy były zgodne z udostępnieniem                                                                                                                                                                                                                                                                                                     |
| `combosSource`                   | `"api"`                                                           | `"models"` pomija `/api/combos` i publikuje wiersze kombinacji `/v1/models` ; filtry na poziomie członka zachowują `"api"`                                                                                                                                                                                                                                                     |
| `showcasePerOwner`               | `10`                                                              | Wpisy widoku domyślnego przechowywane dla każdego dostawcy                                                                                                                                                                                                                                                                                                                     |
| `freshPerOwner`                  | `10`                                                              | Domyślny widok świeżych wpisów przechowywanych według dostawcy                                                                                                                                                                                                                                                                                                                 |
| `freshWindowDays`                | `90`                                                              | Okno świeżości w dniach dla świeżej gałęzi                                                                                                                                                                                                                                                                                                                                     |
| `usageMemory`                    | `true`                                                            | Przywróć statycznie usunięte wpisy nazwane na podstawie 30-dniowej analizy użytkowania (wymaga tokena zarządzania)                                                                                                                                                                                                                                                             |
| `visibleModels` / `hiddenModels` | `[]`                                                              | Listy dozwolonych z dokładnością lub sufiksem; zaprzeczać zwycięstwom; `*` publikuje pełny katalog (inne filtry nadal obowiązują)                                                                                                                                                                                                                                              |
| `geminiSanitization`             | `true`                                                            | Usuń słowa kluczowe schematu JSON odrzucone Gemini ze schematów narzędzi (narzędzia `$ref` są przekazywane w nienaruszonym stanie)                                                                                                                                                                                                                                             |
| `apiFormat.allowAnthropic`       | `false`                                                           | Przekieruj identyfikatory z listy dozwolonych przez blok Anthropic API                                                                                                                                                                                                                                                                                                         |
| `apiFormat.anthropicModels`      | `[]`                                                              | Pełne identyfikatory modeli kierowane do Anthropic                                                                                                                                                                                                                                                                                                                             |
| `logLevel` / `startupDebug`      | `warn` / `false`                                                  | Szczegółowość rejestratora                                                                                                                                                                                                                                                                                                                                                     |

Pamięć użytkowania jest domyślnie włączona. Bez tokena zarządzającego pozostaje bezczynny (rejestrowane jest powiadomienie o uruchomieniu) i nic nie jest przywracane.

## Jak katalog pozostaje świeży

Katalog jest pobierany leniwie i buforowany dla `modelCacheTtlMs`, a migawka dysku utrzymuje ostatni znany katalog dostępny, gdy brama jest nieosiągalna. — awaria kosztuje Cię tylko świeżość. Modele i kombinacje są publikowane natychmiast po ich otrzymaniu; automatyczne kombinacje, lista dostawców i nakładka wzbogacająca składają się po wylądowaniu, więc jeden powolny punkt końcowy nie jest w stanie utrzymać całego selektora jako zakładnika.

Nazwy następują po `Provider - Model[ (Editor)][ · budget][ (route)]`: dostawca jest wyświetlany za każdym razem, gdy identyfikator go zawiera (identyfikator bez ukośnika jest renderowany bez przedrostka), wiodący `🆓` oznacza wolne wpisy, a budżet darmowego poziomu pozostaje sufiksem `· 1M tokens/month`, edytor jawnej nazwy `Editor: Model` przechodzi do nawiasu końcowego (żaden edytor nie jest odgadywany na podstawie innych nazw), a kombinacje są renderowane jako `combo - <slug>` bez darmowej ikony. Dwa wpisy o tej samej nazwie otrzymują przyrostek trasy — `(no-think)` — dzięki czemu można je odróżnić. `providerTag` (domyślnie `true`) przełącza końcowy nawias edytora.

Nie ma ręcznego polecenia odświeżania: polecenia OpenCode v2 są szablonami podpowiedzi, a nie wywołaniami zwrotnymi, więc wtyczka nie może ich ujawnić. Odświeża podążaj za TTL; host jest proszony o ponowne załadowanie tylko wtedy, gdy katalog lub nakładka faktycznie się zmienią, nigdy raz na odświeżenie.

## Wywoływanie narzędzi w Gemini

Gemini odrzuca całe żądanie, jeśli deklaracje narzędzi zawierają `$schema` lub
`additionalProperties`, odpowiadając błędem `400 INVALID_ARGUMENT`. Wtyczka usuwa te słowa kluczowe ze
schematów narzędzi przeznaczonych dla modelu Gemini tego dostawcy i pozostawia wszystkie pozostałe żądania bez zmian.
Narzędzie zawierające `$ref` jest przekazywane bez zmian zamiast poddawania usuwaniu, ponieważ usunięcie
odwołania rozszerzyłoby schemat tak, by „akceptował wszystko”.
Ustaw `"geminiSanitization": false`, aby to wyłączyć.

## Rozwiązywanie problemów

| Objaw                                                         | Przyczyna                                                                                                                           |
| ------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Picker nie pokazuje żadnego modelu OmniRoute                  | Nie rozwiązano żadnego klucza (sprawdź ostrzeżenie podczas uruchamiania) lub brama jest nieosiągalna                                |
| Surowe identyfikatory modeli, żadnych kombinacji, żadnych cen | Punkty końcowe zarządzania odrzuciły zestaw tokenów — `managementReadToken`                                                         |
| Krótki lub pusty katalog `freeOnly`                           | Brak tokenu zarządzania lub odrzucony token — odczytuje linię podsumowania odświeżania (liczba `unmatched-free` ) w dzienniku hosta |
| Sesja przypięta do `opencode-<id>/...`                        | Wtyczka v1 opublikowała `opencode-<id>`; v2 publikuje `<id>` bare, więc ponownie wybierz model w `<id>/...`                         |

Zmienne środowiskowe muszą dotrzeć do procesu serwera opencode: gdy host działa jako usługa, powłoka, na której działa `opencode models`, i środowisko serwera są różne, więc wyeksportuj klucz tam, gdzie serwer go odczytuje.
