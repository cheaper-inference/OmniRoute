## Darmowe tokeny miesięcznie: ~ 11,3B, jak liczą inni · ~ 90M Real

</div>

> **~ 11.3B darmowe tokeny / miesiąc**<br/> <sub> liczył tak samo, jak inne katalogi: każdy wiersz dodawany, zakończone oferty uwzględniały </sub>
>
> **~ 90M real dzisiaj**<br/> <sub> każdy współdzielony limit liczony jest raz: z czego faktycznie możesz skorzystać </sub>
>
> **Wszystko tutaj jest bezpłatne. Brak paywalla.**<br/> ★ [Podoba Ci się? Oznacz nas na GitHub](https://github.com/cheaper-inference/OmniRoute)

Inne katalogi pobierają opłaty od US 19 dolarów rocznie do US 49 dolarów za dożywotni dostęp do danych na żywo. Tutaj wszystko jest bezpłatne. <sub> Ceny sprawdzone 2026-11-18.</sub>

<sub>Katalog ostatni audytowany 23.11.2026. [Jak liczymy →](docs/reference/FREE_TIERS.md#how-we-count)</sub>

> **Przynieś własne konta dostawców.** Są to bezpłatne poziomy stron trzecich, a nie symboliczna dotacja od OmniRoute. Zarejestruj się, uzyskaj dane uwierzytelniające, gdy dostawca o nie poprosi, i połącz te, których możesz użyć. Każdy dostawca ustala własne limity, dostępność i warunki.
>
> Ręczne układanie darmowych poziomów oznacza dziesiątki SDKs, dziesiątki limitów stawek i brak jasnego pojęcia, co Ci pozostało. OmniRoute utrzymuje 214 wierszy katalogu z bezpłatnym dostępem i oblicza rzeczywistą liczbę z 12 pul z opublikowanym limitem, przy czym każda wspólna pula jest liczona raz. Kwoty, które otwierają się dopiero po regionalnej kontroli tożsamości (obecnie ModelScope), są pokazane osobno, 6 mln +~ za regionalną weryfikacją tożsamości i nigdy nie są dodawane do rzeczywistej liczby. To, co pozostało, pojawia się na desce rozdzielczej (`/dashboard/free-tiers`).

## Zainstaluj, podłącz dostawcę, a następnie kieruj przez jeden punkt końcowy

<img src="./docs/diagrams/works-zero-config.svg" width="100%" alt="Four steps to use OmniRoute. Install with npm install -g omniroute, run omniroute, connect a provider and create an API key in the dashboard, then call http://localhost:20128/v1 with model auto."/>

```bash
# After connecting a provider, create your OmniRoute key in Dashboard → API Keys:
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer YOUR_OMNIROUTE_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"auto","messages":[{"role":"user","content":"Hello!"}]}'
```

## Kombinacje: okręt flagowy

1. **Zacznij od `auto`.** Ustaw model w kliencie zgodnym z OpenAI. OmniRoute tworzy wirtualne połączenie od połączonych dostawców i ocenia kandydatów na żywo.
2. **Zapisz kombinację, aby uzyskać większą kontrolę.** Wybierz nazwę, listę docelową i strategię, a następnie użyj tej nazwy jako modelu. Strategia określa, który cel zostanie zrealizowany jako pierwszy i w jaki sposób zostaną wypróbowane pozostałe.

Kombinacja automatycznie kieruje pomiędzy modelami. W przypadku wyczerpania przydziału, awarii dostawcy lub blokady modelu wypróbowuje następny kwalifikujący się, zdrowy cel.

### Zero-config: po prostu użyj `auto`

```bash
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <your-omniroute-key>" \
  -H "Content-Type: application/json" \
  -d '{"model": "auto", "messages": [{"role": "user", "content": "Hello"}]}'
```

Warianty dostosowują ciężary. Trasa typu „ostatni znany dobry” jest wykonywana przez ostatniego dostawcę, który odniósł sukces, aż do awarii, po czym następuje ponowny wynik. preferencje `auto/fast` i `auto/cheap` express bez gwarantowania najszybszego lub najtańszego modelu.

| Model ID            | Zachowanie                                                                                                                                                                                                                                                                                                          |
| :------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `auto`              | Zrównoważone wagi domyślne.                                                                                                                                                                                                                                                                                         |
| `auto/fast`         | Sprzyja niskim opóźnieniom i zdrowiu dostawcy.                                                                                                                                                                                                                                                                      |
| `auto/cheap`        | Preferuje niższe ceny katalogowe.                                                                                                                                                                                                                                                                                   |
| `auto/coding`       | Wagi najwyższej jakości do generowania kodu.                                                                                                                                                                                                                                                                        |
| `auto/smart`        | Wagi na pierwszym miejscu z eksploracją 10% (domyślnie 5%).                                                                                                                                                                                                                                                         |
| `auto/lkgp`         | Jawny routing „ostatni znany dobry” z takimi samymi wagami jak `auto`.                                                                                                                                                                                                                                              |
| `auto/subscription` | Używa tylko limitu planu zweryfikowanego na żywo. Zwraca HTTP 503, gdy żadna nie jest dostępna, i pozwala uniknąć naliczania kosztów zastępczych.                                                                                                                                                                   |
| `auto/thrifty`      | Zaplanuj → Keyless → Free → Tanie → Premium. Może dotrzeć do modeli rozliczanych i powrócić do planu, gdy pozwala na to limit i czas odnowienia.                                                                                                                                                                    |
| `auto/offline`      | Preferuje rezerwę kwot i stawek. Żądania nadal trafiają do Twoich dostawców.                                                                                                                                                                                                                                        |
| `auto/chaos`        | Jeden model na dostawcę równolegle, do pięciu domyślnie lub dziesięciu po skonfigurowaniu. Jedno połączenie nadrzędne na model. Zwraca najwyżej ocenioną odpowiedź lub ostatnią pomyślną odpowiedź panelu, jeśli najwyższy model zakończy się niepowodzeniem. Użyj `fusion`, aby zsyntetyzować odpowiedzi z sędzią. |

Przykłady kategorii i opcjonalnych poziomów obejmują `auto/coding:fast`, `auto/coding:free`, `auto/reasoning:pro` i `auto/vision`. Jeśli żaden podłączony kandydat nie pasuje, żądanie zwraca wartość HTTP 503, a pula pozostaje wąska. [Przewodnik Auto-Combo](./docs/routing/AUTO-COMBO.md) · [Routing oparty na subskrypcji](./docs/routing/SUBSCRIPTION_LADDER.md)

### Wbudowana odporność: 3 niezależne warstwy

Awarie są obsługiwane w trzech zakresach, więc jeden zły model nie usunie swojego konta, a jedno złe konto nie usunie dostawcy.

<img src="./docs/diagrams/resilience-layers.svg" width="100%" alt="OmniRoute resilience: 3 independent self-healing layers, the right layer for the right failure. Layer 1, provider circuit breaker (whole provider): trips only on 408/500/502/503/504, opens after 8 failures for OAuth providers or 12 for API-key providers, resets after 60s or 30s into a HALF-OPEN probe, lazy recovery; while OPEN the combo reroutes to the next provider. Layer 2, connection cooldown (one key or account): base 5s OAuth or 3s API-key, exponential backoff with an anti-thundering-herd guard, success clears the error state; one cooling key is skipped while sibling keys keep serving. Layer 3, model lockout (one model): per-model 429, 404 or access denials lock just that model, never the whole connection. Terminal states (banned, expired, credits exhausted) wait for the operator; they are not cooldowns."/>

#### Jeśli cały dostawca nie działa

The** wyłącznik automatyczny dostawcy** otwiera się po 8 (OAuth) lub 12 (klucz API ) błędach ze statusem 408, 500, 502, 503 lub 504. Kombinacje pomijają tego dostawcę, gdy jest on otwarty. Po 60 s lub 30 s jedno żądanie sondy decyduje, czy zostanie zamknięte.

#### Jeśli jeden klucz lub konto ma ograniczoną stawkę

The** ochłodzenie połączenia** ławki tylko z tym połączeniem, z wykładniczym cofnięciem od 5 s (OAuth) lub 3 s ( klucz API ). Inne klucze tego samego dostawcy nadal się wyświetlają.

#### Jeśli jeden model zostanie odrzucony

The** blokada modelu** blokuje tylko ten model na tym połączeniu po odmowie dostępu dla danego modelu 429, 404 lub odmowie dostępu. Inne modele na tym samym połączeniu nadal działają.

Zablokowane, wygasłe i pozbawione środków połączenia to stany końcowe, a nie czasy odnowienia: czekają, aż je naprawisz.

WhyCodes czyta swojego dostawcę tylko z `config.toml`, więc uruchom `setup-whycodes` raz przed `run whycodes`. → [CLI Integracje](docs/guides/CLI-INTEGRATIONS.md)

## Pełne CLI, MCP i A2A

> OmniRoute dostarcza klienta wiersza poleceń z** 91 poleceń najwyższego poziomu i grup poleceń** (754 komendy licząc podkomendy), an** serwer MCP ze 110 narzędziami i 33 zakresami** , i** agent A2A z 6 umiejętnościami** . Skrypty, terminale i agenci AI mogą obsługiwać tę samą bramę.

### Prawdziwy CLI, nie tylko `start`

```bash
omniroute                 # start the gateway and dashboard (port 20128)
omniroute setup           # guided first-run wizard
omniroute repl            # interactive chat in the terminal (/model /combo /skill /memory)
omniroute chat "hello"    # one-shot prompt; also reads --file or --stdin
omniroute doctor          # check config, database, ports, Node runtime and native deps
```

Globalna flaga `--output table|json|jsonl|csv` umożliwia użycie tych samych poleceń ze skryptów i CI.

### Tryb zdalny: CLI na laptopie, OmniRoute na serwerze

Zaloguj się raz na zdalnym serwerze. CLI zapisuje to jako plik a** kontekst** , a późniejsze polecenia będą uruchamiane na tym serwerze, dopóki nie przełączysz się ponownie.

```bash
omniroute connect omniroute.example.com          # asks for the password, saves a scoped token as a context
omniroute models                                 # runs against the remote server
omniroute configure codex                        # picks a remote model, writes a local Codex profile
omniroute tokens create --name ci --scope read   # mint a narrower token for another machine
omniroute contexts use default                   # switch back to the local server
```

| Zakres tokena | <img width="2000" height="0" alt=""> Na co pozwala                             |
| ------------- | ------------------------------------------------------------------------------ |
| `read`        | Wypisz i sprawdź: modele, status, logi, użycie                                 |
| `write`       | `read` plus skonfiguruj i zastosuj: konfiguracja klienta, klucze, konfiguracja |
| `admin`       | `write` plus zarządzaj: tokenami, dostawcami, usługami, polityką               |

Nagi host otrzymuje `http://` i port 20128; przekaż pełne `https://` URL gdy serwer znajduje się za TLS. Trasy, które mogą odradzać procesy, pozostają wyłącznie w trybie pętli zwrotnej, niezależnie od tokena.

Agent lub Twój własny kod może sterować routingiem, dostawcami, kombinacjami, pamięcią podręczną, kompresją i pamięcią za pośrednictwem dowolnego z tych interfejsów. ścieżki HTTP są obsługiwane przez bramę, domyślnie w `http://localhost:20128`.

**Zanim się połączysz:**

- **MCP przez HTTP uruchamia się wyłączone.** Włącz go za pomocą `omniroute mcp enable --transport streamable-http` lub ze strony Punkty końcowe na pulpicie nawigacyjnym. W danym momencie aktywny jest jeden transport HTTP : `streamable-http` obsługuje `/api/mcp/stream`, `sse` obsługuje `/api/mcp/sse`.
- **A2A uruchamia się wyłączona.** Włącz tę opcję na stronie Punkty końcowe panelu kontrolnego. `POST /a2a` następnie stosuje się do tych samych zasad klucza API, co `/v1`.

Z innego hosta wyślij klucz za pomocą `manage` lub `admin` (wszystkie narzędzia) lub za pomocą `mcp:connect` plus zakresy potrzebnych narzędzi. # Give Claude Code the OmniRoute toolset over MCP:
```bash
omniroute mcp enable --transport streamable-http

  --header "Authorization: Bearer <api-key-with-manage-scope>"
```

### Jak to działa — Pipeline, architektura i matematyka oszczędności

<img src="./docs/diagrams/compression-pipeline.svg" width="100%" alt="OmniRoute compression pipeline: an illustrative 10,000-token client request passes through 12 composable engines — Session-Dedup, CCR, Lite, RTK, Responses Tool Output, Headroom, Relevance, Caveman, Aggressive, LLMLingua-2, Ultra and OmniGlyph — and can reach the provider at about 1,080 tokens in the documented stacked example. Structured content is protected by preservation guards and per-step fidelity gates; explicit lossy or experimental modes may transform eligible content."/>

Domyślna kombinacja skumulowana uruchamia `RTK → Caveman`. Gdy oba działają na tym samym ładunku tool/context, oszczędności są złożone:

```txt
combined = 1 − (1 − RTK) × (1 − Caveman_input)
average  = 1 − (1 − 0.80) × (1 − 0.46) = 89.2%
range    = 78.4 – 94.6%
```

Bloki kodu, URLs, JSON i dane strukturalne to** zawsze chroniony** przez silnik konserwujący.

> **Po co używać wielu tokenów, skoro kilka tokenów wystarczy?** Każde żądanie przechodzi przez potok kompresji OmniRoute** przejrzyście** — brak zmian klienta. To teraz A** stos 12 silników, które można komponować** które działają w kolejności i mieszaj i dopasowuj według kombinacji routingu — opierając się na pomysłach [RTK](https://github.com/rtk-ai/rtk), [Caveman](https://github.com/JuliusBrussee/caveman) (⭐ 90K +), [LLMLingua-2](https://github.com/microsoft/LLMLingua) i [Troglodita](https://github.com/leninejunior/troglodita) (PT-BR).

| Dwa jednoczesne długie `/v1/responses`                | `10240`–`12288`                 | ≥ 12–16 g             |

```bash
docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 \
  -e OMNIROUTE_MEMORY_MB=8192 --memory=10g \
  -p 127.0.0.1:20128:20128 -v omniroute-data:/app/data cheaperinference/omniroute:latest
```

**🥟 Bun**

Standardowa instalacja `bun install` i instalacja globalna (`bun install -g omniroute`) są obsługiwane poprzez wykrywanie środowiska wykonawczego Bun :

- **Wbudowany `bun:sqlite`** : OmniRoute używa wbudowanego sterownika Bun `bun:sqlite` podczas pracy pod Bun, powracając do `better-sqlite3` na Node.js lub `sql.js`.
- **Automatyczny wybór pakietu pakującego Webpack w dev** : Rozwój (`bun run dev`) automatycznie wykrywa Bun i wyłącza Turbopack na rzecz pakietu Webpack, aby zapobiec niezgodnościom natywnych wiązań V8. Kompilacje produkcyjne (`bun run build`) są zgodne `OMNIROUTE_USE_TURBOPACK` dokładnie tak, jak w węźle: domyślnie Turbopack, `OMNIROUTE_USE_TURBOPACK=0` do kompilacji za pomocą pakietu Webpack (`Dockerfile.bun` udostępnia to jako `--build-arg`).
- **Dedykowany Bun** : Wieloetapowy `Dockerfile.bun` do natywnych wdrożeń produkcyjnych Bun (`docker build -f Dockerfile.bun -t omniroute:bun .`).

```bash
# Install and run with Bun
bun install
bun run dev
```

**⚡ Szybsza/prostsza instalacja (pomiń natywną kompilację)**

Natywny silnik SQLite (`better-sqlite3`) to** fakultatywny** zależność, więc instalacja globalna nigdy nie blokuje kompilacji ze źródła: używa wstępnie skompilowanego pliku binarnego, gdy pasuje on do twojego platform/Node, a poza tym w sposób przezroczysty powraca do silnika czystego JS (`node:sqlite` na węźle 22 +, w przeciwnym razie dołączony `sql.js` WASM) — nie są wymagane żadne narzędzia do kompilacji.

Aby pominąć instalację poinstalacyjną** rodzima rozgrzewka** całkowicie (CI, maszyny bezgłowe lub wolne). Uwaga: pomija to tylko natywny etap rozgrzewki SQLite (`scripts/postinstall.mjs`); hak binary-copy/repair (`scripts/build/postinstall.mjs`) nadal działa normalnie:

```bash
OMNIROUTE_SKIP_POSTINSTALL=1 npm install -g omniroute   # CI=1 also skips it
```

Preferowane są najszybsze instalacje** pnpm** (sklep adresowany do treści + twarde linki — patrz wyżej). Aby uzyskać środowisko wykonawcze bez pulpitu nawigacyjnego, użyj profilu Docker `base` (powyżej) lub [przewodnika Termux](docs/guides/TERMUX_GUIDE.md). CLI i panel WWW są obsługiwane przez ten sam proces na jednym porcie, dlatego obecnie nie ma osobnego pakietu obsługującego wyłącznie interfejs CLI.
