## Kategorie

- **Zdarma** — bezplatná úroveň s API klíčem (konfiguruje se prostřednictvím řídicího panelu)
- **Bez ověření** — veřejné koncové body, které vůbec nevyžadují klíč ani přihlášení
- **OAuth** — přihlašovací proces zajišťuje OmniRoute, není potřeba API klíč
- **Webový soubor cookie** — zpřístupňuje webovou aplikaci poskytovatele prostřednictvím ověřování pomocí souboru cookie
- **API klíč** — placený poskytovatel konfigurovaný pomocí API klíče (mohou být k dispozici bezplatné kredity)
- **Lokální** — běží na počítači uživatele (Ollama, LM Studio, vLLM atd.)
- **Vyhledávání** — poskytovatelé webového vyhledávání
- **Zvuk** — poskytovatelé pouze pro zvuk (TTS/STT)
- **Nadřazený proxy server** — poskytovatelé, kteří zprostředkovávají přístup k jiným poskytovatelům
- **Cloudový agent** — dlouhodobě běžící agenti pro programování (Codex Cloud, Devin, Jules)
- **Systém** — interní poskytovatelé OmniRoute (loopback atd.)

Další štítky: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (je-li uvedeno): `native` — skutečné API pro volání funkcí; `emulated` — pole `tools` je emulováno v promptu prostřednictvím `webTools.ts` (bloky `<tool>{...}</tool>` analyzované pomocí regulárních výrazů); `none` — položka `tools` je v současnosti bez upozornění zahozena. Viz #7286.

Pomocí řídicího panelu na adrese `/dashboard/providers` můžete jednotlivé poskytovatele povolit, nakonfigurovat a otestovat.
