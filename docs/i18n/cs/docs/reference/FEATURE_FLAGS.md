> Přepínače za běhu, které mění chování OmniRoute **bez opětovného nasazení**.
> Každý zde uvedený příznak je definován v
> [`src/shared/constants/featureFlagDefinitions.ts`](../../src/shared/constants/featureFlagDefinitions.ts)
> — jediném zdroji pravdy. Řídicí panel i REST API čtou z
> tohoto souboru, takže níže uvedená tabulka je vygenerována tak, aby mu odpovídala 1:1.

---

## Co jsou příznaky funkcí

Příznak funkce je pojmenovaný přepínač (boolean nebo enum), jehož hodnotu lze změnit za
běhu a uložit do databáze, aniž by bylo nutné proces znovu nasadit. Každý
příznak je popsán pomocí `FeatureFlagDefinition` s položkami `key`, `label`,
`description`, `category`, `defaultValue`, `type` a nápovědou `requiresRestart`.

### Pořadí vyhodnocování

**Efektivní hodnota** příznaku je určena pomocí
[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) s následující
prioritou (vyšší má přednost):

1. **Přepsání z DB** — hodnota uložená v tabulce `key_value` v rámci
   jmenného prostoru `feature_flags` (nastavená prostřednictvím řídicího panelu nebo REST API).
2. **Proměnná prostředí** — `process.env[<KEY>]`, pokud je nastavena a není prázdná.
3. **Výchozí hodnota definice** — `defaultValue` z `featureFlagDefinitions.ts`.

Příznak typu boolean se považuje za **povolený**, pokud je jeho efektivní hodnota `"true"`,
`"1"` nebo `"yes"` (viz `isFeatureFlagEnabled()`).

> [!NOTE]
> Většina příznaků má také odpovídající proměnnou prostředí se **stejným názvem**,
> zdokumentovanou v souboru [`ENVIRONMENT.md`](./ENVIRONMENT.md). Přepsání příznaku z DB
> má před touto proměnnou prostředí přednost. Příznak s
> `requiresRestart: true` se uloží okamžitě, ale znovu se načte až při spuštění
> procesu — jeho přepnutí zobrazí na řídicím panelu banner **„Restartovat server“**.

použitá, pokud není přítomen ani přepsání v DB, ani proměnná prostředí.

> `INPUT_SANITIZER_BLOCK_THRESHOLD` a její legacy alias
> `INJECTION_GUARD_BLOCK_THRESHOLD` ladí režim `block`
> `INJECTION_GUARD_MODE`, ale jedná se o obyčejné proměnné prostředí čtené v
> [`src/shared/utils/injectionSeverity.ts`](../../src/shared/utils/injectionSeverity.ts),
> nikoli o přepínače funkcí: nemají překrytí v DB ani přepínač v přehledu. Viz
> [`ENVIRONMENT.md`](./ENVIRONMENT.md#4-security--authentication).

> [!NOTE]
> Sloupec `Restart` označuje přepínače s `requiresRestart: true` — hodnota se
> ukládá okamžitě, ale projeví se až po znovunačtení procesu. Přepínače s výčtem
> odmítají jakoukoli hodnotu mimo povolenou množinu (ověřeno na serverové straně
> jak v `setFeatureFlagOverride()`, tak v REST `PUT` procesoru).

## Přepínání příznaků

### Řídicí panel

Přejděte do **Řídicí panel → Nastavení → Příznaky funkcí**
(`/dashboard/settings/feature-flags`). Mřížka
(`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`)
podporuje:

- **Vyhledávání** podle klíče nebo popisu a **filtrování** podle kategorie (včetně syntetického zobrazení
  **Vyžaduje restart**).
- **Přepínač** pro příznaky typu boolean a **rozbalovací nabídku** pro příznaky typu enum
  (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`).
- Odznak zdroje pro každý příznak — `DB`, `ENV` nebo `DEF` — zobrazující, odkud pochází efektivní hodnota.
- Tlačítko **Obnovit** (zobrazené pouze u příznaků se zdrojem `DB`) pro zrušení přepsání a tlačítko **Obnovit všechna přepsání** dole.
- Banner **Restartovat server**, když se změní příznak `requiresRestart`.

### REST API

Všechny operace procházejí jedinou routou:
[`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts).
Každá metoda vyžaduje ověřenou relaci řídicího panelu (jinak `401`).

#### `GET /api/settings/feature-flags`

Vrací každý příznak s jeho efektivní hodnotou, zdrojem a souhrnem.

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Require API Key",
      "description": "Require an API key for all incoming requests",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... všech 120 příznaků
  ],
  "summary": {
    "total": 120,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

Nastaví nebo odebere jediné přepsání. Tělo: `{ key: string; value?: string }`.
Vynecháním `value` přepsání odeberete (obnoví se hodnota z prostředí / výchozí hodnota).

```bash
# Nastavení přepsání v DB
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# Odebrání přepsání (bez "value")
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

Odpověď zopakuje novou hodnotu `effectiveValue`/zdroj `source`, předchozí hodnotu `previousValue`/
předchozí zdroj `previousSource` a údaj `requiresRestart`. Neznámé klíče a hodnoty enum mimo povolený
rozsah jsou odmítnuty s chybou `400`.

#### `DELETE /api/settings/feature-flags`

Vymaže **všechna** přepsání v DB najednou a obnoví každý příznak na hodnotu z prostředí / výchozí
hodnotu. Vrací `{ cleared: <count>, message: "..." }`.

> [!NOTE]
> Příznaky s `requiresRestart: true` se projeví až po opětovném načtení procesu.
> Proces restartování z řídicího panelu zavolá `POST /api/restart` a poté dotazuje
> `GET /api/health/ping`, dokud server nebude znovu dostupný.

## Nouzový záložní mechanismus při vyčerpání rozpočtu

`OMNIROUTE_EMERGENCY_FALLBACK` (kategorie `runtime`, výchozí hodnota `true`) řídí
nouzové bezplatné záložní směrování v souboru
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts).
Je-li povoleno, požadavky, které vyčerpají svůj rozpočet, jsou namísto úplného
selhání směrovány k bezplatnému záložnímu poskytovateli/modelu. Chcete-li toto
chování zakázat a nechat požadavky s vyčerpaným rozpočtem selhat, nastavte hodnotu
na `false` (nebo `0`) — pomocí přepínače na řídicím panelu, přepsání v DB nebo
proměnné prostředí `OMNIROUTE_EMERGENCY_FALLBACK`. (Zpřístupněno jako přepínač
na řídicím panelu v PR #3741 / #3752.)

Odpověď obsloužená tímto záložním mechanismem obsahuje hlavičku
`X-OmniRoute-Emergency-Fallback: from=<provider/model>; to=<provider/model>`, takže
klient může zjistit, že byla přesměrována, aniž by musel porovnávat
`X-OmniRoute-Provider` s požadavkem. U všech ostatních odpovědí tato hlavička
chybí.
