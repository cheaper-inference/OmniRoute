> **Stav:** řídicí panel je postaven na **Keak CI UI Kit** (`@keak/cheaper-inference-ui-kit`), zahrnutém (vendored)
> jako workspace `packages/ui-kit` (`@omniroute/ui-kit`; upstream snapshot je připnut v
> `packages/ui-kit/UPSTREAM.md` a střežen příkazem `npm run check:ui-kit-snapshot`). Světlý režim je kanonické
> téma; výchozí preference je `system`. Akcentní barvou je Keak lime (`--ci-color-accent`). Inter
> (letter-spacing 0, `--ci-letter-spacing-ui`) je rodina písem pro UI, Instrument Serif pouze pro velký řídký
> zobrazovaný text (`.ci-dashboard-display`), IBM Plex Mono pro kód — vše je self-hostováno prostřednictvím
> importů `@fontsource/*` na začátku souboru `src/app/globals.css`. Každá ikona je glyf Lucide.

## 1. Kde co je

- **Kit.** `packages/ui-kit/src` je bajt po bajtu shodná kopie upstream `src/` z commitu připnutého v
  `packages/ui-kit/UPSTREAM.md` (který zároveň zaznamenává licenční oprávnění); `PATCHES.md` uvádí lokální
  patche (žádné). Používá se jako zdrojový kód, bez buildu: `next.config.mjs` jej transpiluje a
  `tsconfig.json` mapuje `@omniroute/ui-kit` → `packages/ui-kit/src` a `@omniroute/ui-kit/*` →
  `packages/ui-kit/src/*` (`vitest.config.ts` a `vitest.mcp.config.ts` nesou tentýž alias). Komponentu
  kitu importujte její subcestou (`@omniroute/ui-kit/table`, `@omniroute/ui-kit/page-header`…), nikdy
  přes barrel `@omniroute/ui-kit`: barrel zatáhne všechny komponenty (včetně date pickeru) do každého
  importujícího souboru. Stylesheet kitu vstupuje přes `src/app/globals.css`
  (`@import "../../packages/ui-kit/src/ci-ui.css"`).
- **Tokeny.** `packages/ui-kit/src/ci-tokens.css` deklaruje tokeny `--ci-*`; `src/app/globals.css`
  je přemostí na původní názvy OmniRoute (`--color-*`, `--radius-*`, `--font-sans`/`--font-mono`,
  `--table-*`, `--orch-status-*`, `--color-fd-*`), takže stávající čtení `var(--color-*)` a utility
  Tailwindu dál fungují. Nový kód používá utility Tailwindu (`bg-surface`, `text-text-muted`,
  `border-border`, `text-success`, `bg-success-bg`, `bg-chart-1`…) nebo třídy kitu — nikdy hex hodnotu
  (`tests/unit/design-kit-bridge.test.ts` přemostění vynucuje). `text-primary` se překládá na
  `--color-primary-ink` skrze `--text-color-primary` (lime-800 ve světlém, limetkový akcent v tmavém),
  takže primární text zůstává čitelný, zatímco `bg-primary`/`border-primary` si uchovávají limetkovou
  plochu. Série grafů používají `--color-chart-1` … `--color-chart-5`.
- **Témata.** `<html className="ci-theme">` (`src/app/layout.tsx`) přihlašuje dokument k tématu kitu.
  Preference je `light`, `dark` nebo `system` (`THEME_CONFIG.defaultTheme = "system"` v
  `src/shared/constants/appConfig.ts`; `system` se řídí `prefers-color-scheme`). `applyTheme()` v
  `src/store/themeStore.ts` (zrcadlená inline bootstrapovým skriptem v `src/app/layout.tsx`, který běží
  před hydratací) nastavuje `data-theme="dark"|"light"` a současně přepíná třídu `.dark` na `<html>`.
  Tmavá sada tokenů kitu je klíčována na `data-theme="dark"` (`packages/ui-kit/src/ci-tokens.css`);
  vlastní tmavá přepsání OmniRoute (blok `.dark` v `globals.css`) a původní utility Tailwindu `dark:`
  se klíčují na třídu `.dark`. Předvolby akcentových barev neexistují: akcent vždy pochází z kitu
  a předvolba perzistovaná ze staršího buildu se při načtení storu zahodí.
- **Komponenty (adaptéry).** `src/shared/components/index.tsx` zachovává komponentní API OmniRoute
  (stejné názvy, výchozí exporty a props) a primitivy za ním jsou adaptéry nad kitem: formuláře
  (`Button`, `Input`, `Textarea`, `Checkbox`, `Select`, `Toggle`, `Badge`, `Card`), překryvy a zpětná
  vazba (`Modal`/`ConfirmModal`, `Tooltip`/`InfoTooltip`, `NotificationToast`, `EmptyState`, `Loading`),
  struktura (`Collapsible`, `CollapsibleSection`, `SegmentedControl`, `Breadcrumbs`, `Avatar`) a tabulky
  (`DataTable`, `FilterBar`, `ColumnToggle`, `FilterPills`, `PresetSlider`). Adaptér importuje komponentu
  kitu její subcestou a mapuje na ni původní props — například `Button variant="primary"` je kit tlačítko
  `default` (`--ci-button-primary-*`: inverzní plocha ve světlém, akcent se svým inkoustem
  `--ci-color-accent-foreground` v tmavém), `danger` je `destructive` a `warning` je `outline` plus
  rozšíření `.ci-button--warning`. Pravidla `.ci-button--warning` a `.ci-badge[data-tone]` na konci
  `globals.css` (`@layer components`) jsou rozšíření OmniRoute postavená na třídách kitu.
  `tests/unit/ui/adapters/*.test.tsx` fixují každý adaptér.
- **Shell.** `src/app/(dashboard)/layout.tsx` vykresluje `DashboardLayout`, který vykresluje
  `src/shared/components/layouts/DashboardShell.tsx`: kit `SidebarProvider` / `Sidebar` /
  `SidebarInset` (`packages/ui-kit/src/sidebar.tsx`), s navigační logikou OmniRoute v
  `src/shared/components/Sidebar.tsx`. Odkaz „přeskočit na obsah" mířící na `#main-content` je prvním
  fokusovatelným prvkem. `src/shared/components/Header.tsx` obsahuje kit `SidebarTrigger` (jediný
  přepínač postranního panelu v shellu), Keak `ProductSwitcher` a otevírač palety příkazů; titulek trasy
  zobrazuje pouze tehdy, když uvnitř `#main-content` není namountován žádný kit `PageHeader`
  (`.ci-page-header`), takže stránka s vlastním `PageHeader` má jediný `h1`.
  `src/shared/components/CommandPalette.tsx` je kit `Dialog`.
- **Ikony.** `<Icon name="material_name">` (`src/shared/components/Icon.tsx`) překládá název (slovník
  Material Symbols, který obrazovky používají) přes `ICON_MAP` (`src/shared/constants/iconMap.ts`) na
  glyf Lucide. Font a balíček Material Symbols jsou pryč: název chybějící v mapě vykreslí neutrální
  zástupný glyf (`data-icon-missing="true"`) a mimo produkci zapíše varování do konzole.
  `npm run gen:icon-map` vypíše používané názvy, které v mapě chybí
  (`tests/unit/icon-map-coverage.test.ts` selže na jakémkoli názvu bez ikony Lucide;
  `tests/unit/icon-map-object-values.test.ts` pokrývá názvy uložené ve vyhledávacích objektech);
  `scripts/dev/codemod-material-icons.mjs <dir|file>... [--write]` přepisuje literální spany
  `<span className="material-symbols-outlined">` na `<Icon>`.
- **Značka.** `src/shared/components/OmniRouteLogo.tsx` obaluje kit: výchozí export `OmniRouteLogo`
  vykresluje `ProductIcon product="omniroute" variant="glyph"` (inline SVG, bezpečné vůči `basePath`)
  a `OmniRouteLockup` vykresluje `ProductLockup product="omniroute"` (přístupný název „Keak OmniRoute")
  nebo, pro white-label operátory, jejich vlastní `name`/`logoSrc`. Cíle přepínače produktů jsou
  definovány v `src/shared/constants/keakProducts.ts` (`KEAK_PRODUCT_LINKS`, `KEAK_ACTIVE_PRODUCT`).
  Samostatné obrazovky — `src/app/login/page.tsx`, `src/app/status/page.tsx`,
  `src/app/maintenance/page.tsx`, `src/app/offline/page.tsx`, `src/app/not-found.tsx` a
  `src/shared/components/ErrorPageScaffold.tsx` — zobrazují lockup;
  `tests/unit/brand-pages-static.test.ts` to hlídá.

## 2. Pravidla

1. Tokeny, nikdy literály. Výjimky ponechané záměrně: vždy tmavý konzolový terminál, tahy ReactFlow SVG
   přes `STATUS_HEX` (`src/shared/constants/statusColors.ts`) a kategorické palety
   `STRATEGY_COLORS` (`src/app/(dashboard)/dashboard/combos/live/nodes/StrategyNode.tsx`) a
   `LAYER_COLORS` (`src/app/(dashboard)/dashboard/compression/studio/nodes/EngineNode.tsx`).
2. Nikdy ručně nepatchujte `packages/ui-kit/src`: synchronizujte pomocí `scripts/dev/sync-ui-kit.sh <commit>`;
   pre-commit brána `npm run check:ui-kit-snapshot` (`.husky/pre-commit`) selže na jakýkoli bajt,
   který se liší od připnutého upstream commitu (přeskočí se s varováním, pokud upstream klon,
   `UI_KIT_CLONE` nebo `_references/cheaper-inference-ui-kit`, chybí). Když kitu něco chybí,
   obejděte to v adaptéru nebo na obrazovce a požádejte o to upstream.
3. Výchozí texty kitu jsou anglické (`label = "Loading"`, `loadingLabel = "Loading table"`…) — kdykoli
   komponenta kitu vykresluje text, předávejte jí přeložené řetězce z `useTranslations(...)`.
4. Utility Tailwindu mají přednost před třídami komponent kitu (kit deklaruje
   `@layer theme, base, components, utilities` a jeho pravidla žijí v `components`) — utility používejte
   pro odsazení a rozvržení, ne k přebarvování komponent kitu.
5. Nadpisy: `.ci-heading` (Inter, bez trackingu) pro titulky stránek a sekcí; `.ci-dashboard-display`
   (Instrument Serif) pouze pro velký, řídký display text, jako je stavový kód chybové stránky.
6. `tests/unit/dashboard-kit-sweep.test.ts` hlídá přijetí kitu: žádný span s ligaturou Material pod
   `src/app` nebo `src/shared/components`; ve stromu dashboardu (`src/app/(dashboard)` a
   `src/shared/components`) žádné holé `<select>`, `<textarea>` nebo `<table>` a žádný ručně vytvořený
   `role="dialog"` mimo uvedené výjimky (nativní větev adaptéru `Select`,
   `RequestLoggerDetail`); každý holý `<button>` nebo `<input>` tam potřebuje komentář obsahující
   `kit-exception:` (s důvodem) končící nejvýše 3 řádky nad ním; odstíny palety a varianty `dark:`
   pouze v souborech, které test uvádí.
7. Před PR ověřte oba motivy a viewport 390 px (snímky obrazovky); `tests/e2e/a11y.spec.ts` spouští
   axe.

## 3. Přidání obrazovky

1. Stránku začněte kitovým `PageHeader` (`@omniroute/ui-kit/page-header`, `compact` uvnitř
   dashboardu) — titulek, popis a `actions`. Hlavička shellu pak zahodí vlastní titulek.
2. Ovládací prvky stavte z `@/shared/components` (adaptérů) a kde adaptér neexistuje, používejte
   komponenty kitu přes podcestu (`Table`/`TableScrollArea`/`DataTableShell`, `Field`, `Alert`, `Tabs`,
   `RadioGroup`, `Slider`…).
3. Ikony: `<Icon name="…" />`. Nový název patří do `ICON_MAP` se sémanticky odpovídající komponentou
   Lucide; `npm run gen:icon-map` vypíše názvy, které ještě chybějí.
4. Barvy: sémantické utility (`text-success`, `bg-warning-bg`, `border-border`…) a
   `var(--color-chart-N)` pro série grafů; žádné hex hodnoty a žádné varianty `dark:`, které jen opakují
   barvu.
5. Text: každý řetězec, včetně popisků, které předáváte komponentám kitu, pochází z `useTranslations`.
   Nové klíče patří do `src/i18n/messages/en.json`, `pt-BR.json` a `vi.json` (vietnamský test parity
   fixuje každý anglický klíč); ostatní lokality doplní synchronizace i18n.
6. Před PR spusťte hlídače: `tests/unit/dashboard-kit-sweep.test.ts`,
   `tests/unit/icon-map-coverage.test.ts`, `tests/unit/icon-map-object-values.test.ts`,
   `npm run check:dashboard-typecheck` (jediná kontrola, která zachytí duplicitní import v `iconMap.ts`),
   `npm run check:ui-icu` a vlastní testy obrazovky.

## 4. Přidání nebo změna adaptéru

1. Zachovejte veřejné API souboru `src/shared/components/index.tsx`: stejné názvy exportů, výchozí exporty a
   přijímané props. Původní (legacy) props mapujte na kit uvnitř adaptéru (viz `Button.tsx`: `VARIANT_TO_KIT`,
   `SIZE_TO_KIT`).
2. Kit importujte pomocí podcesty (`@omniroute/ui-kit/<component>`).
3. Workaroundy pro mezery kitu patří do adaptéru (nebo do `globals.css` `@layer components`, pokud je opravou
   styl), nikdy do `packages/ui-kit/src`.
4. Přidejte nebo aktualizujte `tests/unit/ui/adapters/<name>.test.tsx`. U adaptéru s mnoha volajícími porovnejte
   vykreslené HTML před změnou a po ní — změny odsazení (padding) nebo obalových prvků se rozšíří na každou
   obrazovku.

## 5. Aktualizace kitu

`scripts/dev/sync-ui-kit.sh <commit> [clone]` zkopíruje upstreamový adresář `src/` z daného commitu do
`packages/ui-kit/src` a provede jedinou povolenou transformaci (odstraní příponu `.js` z relativních
importů). Poté: zkontrolujte `git diff packages/ui-kit`, vizuálně projděte poskytovatele, nastavení, kombinace,
využití a endpoint v obou motivech, spusťte `npm run check:ui-kit-snapshot` a `npm run test:vitest:ui` a
otevřete PR s changelogem upstreamu.
