Pravidla směrování uvažování rozšiřují stávající směrování modelů a kombinací. Pokud neodpovídá žádné aktivní pravidlo,
stávající chování pro přemýšlení, přípony, výchozí nastavení připojení a překlad poskytovatele zůstává
beze změny.

## Správa

Správa pravidel je dostupná v části **Nastavení → Globální směrování**. Editor API klíčů nabízí stejné
rozhraní pro správu filtrované podle vybraného klíče.

API pro správu je zpřístupněno prostřednictvím těchto tras:

- `GET` a `POST` na `/api/settings/reasoning-routing-rules`
- `GET`, `PATCH` a `DELETE` na `/api/settings/reasoning-routing-rules/[id]`
- `POST` na `/api/settings/reasoning-routing-rules/simulate`

Všechny trasy používají `requireManagementAuth`. Vstupy jsou validovány pomocí schémat v
`src/shared/validation/schemas/reasoningRouting.ts`. Simulátor nikdy neprovádí volání nadřazené služby.

## Vyhodnocování pravidel

Předběžné vyhodnocení vybere právě jedno pravidlo. Rozsahy jsou kontrolovány v tomto pořadí:

1. `apiKey`
2. `combo`
3. `model`
4. `global`

V rámci rozsahu nejprve vítězí vyšší `priority`, poté přesná shoda modelu před vzorem glob
a následně stabilní pořadí podle `createdAt` a `id`. `requestTags` se načítají výhradně z `metadata.tags`
a podporují porovnávání `any` nebo `all`.

Pravidlo `connection` se vyhodnocuje pouze tehdy, když nezvítězilo žádné předběžné pravidlo a již bylo
vybráno konkrétní připojení poskytovatele. Může změnit pouze míru úsilí a rozpočet.

## Úsilí a rozpočet

`sourceEffort` přijímá `any`, `missing`, `none`, `low`, `medium`, `high`, `xhigh`, `max` a `ultra`. `missing` znamená, že požadavek neobsahuje ani diskrétní úsilí, ani myšlenkový přepínač nebo myšlenkový rozpočet. Signál pouze pro rozpočet je tedy porovnáván pouze s `any`.

`effortMode` má tři varianty:

- `inherit` udržuje úsilí klienta a zároveň umožňuje změnu modelu nebo kombinace.
- `default` nastavuje `targetEffort` pouze v případě, že není přítomen žádný explicitní uvažovací signál.
- `force` nahrazuje diskrétní úsilí `targetEffort`.

Independently, `budgetAction` can be `preserve`, `remove`, or `set`. `force` with `none` removes all recognized effort and budget fields, then sets `reasoning_effort: "none"`, because some providers turn thinking on when the field is absent. Providers that reject the literal `none` are adjusted at dispatch in `open-sse/executors/base/reasoningEffort.ts`. Command Code maps it to `low`, except on Responses-shaped requests (`input` without `messages`), where it keeps `none`. On Cloudflare Workers AI (`cloudflare-ai`), the models that reject `none` (gpt-oss, qwen3.8, nemotron-3, glm-4.7-flash) get `low`; other Workers AI models keep `none`. Vypuštění pole zde není možné, protože nepřítomné úsilí spustí výchozí úroveň modelu. `none` together with `set` is invalid.

Požadavky zacílené na známé nekompatibilní modely jsou před upstreamovým voláním zamítnuty. U kombinovaných cílů jsou nekompatibilní položky odstraněny; pokud žádný nezůstane, požadavek vrátí stav `400`. Neznámá data schopnosti vygenerují varování a ponechá pravidlo aktivní.

## Zabezpečení a přenosové protokoly

Zdrojový a cílový model nebo zdrojová a cílová kombinace nadále podléhají stávajícím zásadám pro
API klíče. Pravidlo uvažování nikdy nerozšiřuje oprávnění k modelům, kombinacím ani kvótám.

Engine je integrován do Chat Completions, Responses, Anthropic Messages a interní cesty Codex
WebSocket. Cesta WebSocket přijímá pouze cílové modely Codex; cíle typu kombinace v ní nelze spustit.
Rozhodnutí pravidla se ukládá do stávajícího trasovacího záznamu bez tajných údajů.

## Perzistence

Migrace `src/lib/db/migrations/126_reasoning_routing_rules.sql` vytváří tabulku
`reasoning_routing_rules`. Pravidla odkazují na uložené API klíče, kombinace a připojení poskytovatelů.
Při odstranění se související pravidla vyčistí. Vrstva pro přístup k databázi v
`src/lib/db/reasoningRoutingRules.ts` udržuje pro cestu požadavku zneplatnitelnou mezipaměť.

Pravidla jsou zahrnuta v zálohách SQLite, úplném exportu databáze a balíčku pro synchronizaci
konfigurace. `reconcileReasoningRulesForSync` deaktivuje importovaná pravidla s chybějícími odkazy
a hlásí tyto konflikty.
