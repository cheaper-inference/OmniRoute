`@omniroute/opencode-plugin-v2` zpřístupní celý váš katalog OmniRoute — modely, komba a
automatická komba — ve výběru modelů OpenCode v2, včetně zobrazovaných názvů, cen a
limitů bezplatné úrovně.

Jedná se o samostatný balíček od `@omniroute/opencode-plugin`, protože OpenCode v1 a v2 načítají
pluginy prostřednictvím odlišných rozhraní. Vyberte ten, který odpovídá vaší hlavní verzi OpenCode;
nic mezi nimi není sdíleno, takže aktualizace jednoho nikdy nevynutí aktualizaci druhého.

## Požadavky

- OpenCode v2.
- Dostupná brána OmniRoute (ve výchozím nastavení `http://localhost:20128`).
- Node.js 22 nebo 24.

## Instalace

Přidejte plugin do `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

Modely se poté zobrazí jako `omniroute/<provider>/<model>`; `providerId` určuje tuto předponu
a id integrace, pod kterým OpenCode ukládá přihlašovací údaj.

## Přihlašovací údaje

Plugin hledá klíč brány na třech místech, a to v tomto pořadí:

1. **Přihlašovací údaj, který jste připojili v OpenCode.** Plugin registruje integraci, takže
   vlastní ověřovací proces OpenCode může klíč uložit. Nic se nezapíše do `opencode.json` — tuto možnost upřednostněte.
2. `apiKey` v možnostech pluginu pro přepsání na úrovni projektu. Klíč se tak uloží do souboru,
   který můžete zahrnout do commitu.
3. `OMNIROUTE_API_KEY` v prostředí.

Pokud není k dispozici žádná z těchto tří možností, katalog zůstane prázdný a plugin to při spuštění
jednou oznámí, místo aby vám bez upozornění zobrazil prázdný výběr.

### Token pro správu je jiný klíč

Komba, stav poskytovatelů a obohacení (zobrazované názvy, ceny a limity bezplatné úrovně) pocházejí
z endpointů brány `/api/*`, které většina nasazení chrání **správcovským** tokenem,
nikoli klíčem pro inferenci:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<správcovský token pro čtení>"
}
```

Pokud `managementReadToken` není nastaven, použije se jako náhradní hodnota `apiKey`. Když brána tuto
náhradní hodnotu odmítne, katalog se přesto zveřejní, ale s nezpracovanými id modelů namísto zobrazovaných
názvů, bez deduplikace kanonických aliasů, cen a komb. Plugin při takové situaci jednou pro každý endpoint
zobrazí varování s názvem endpointu a informací o tom, co chybí — zhoršená podoba výběru tak nikdy není záhadou.

## Možnosti

| Klíč                             | Výchozí                                     | Poznámky                                                                                                                                                                                                                                                                                                                                                                        |
| -------------------------------- | ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `providerId`                     | `"omniroute"`                               | Pod položkou se zobrazí ID poskytovatele, ID integrace a modely předpon                                                                                                                                                                                                                                                                                                         |
| `baseURL`                        | požadovaný                                  | Kořen brány, pouze `http(s)` ; v případě potřeby se přidá přípona `/v1`                                                                                                                                                                                                                                                                                                         |
| `apiKey`                         | připojené pověření, pak `OMNIROUTE_API_KEY` | Chat klíč pro `/v1/*`                                                                                                                                                                                                                                                                                                                                                           |
| `managementReadToken`            | spadá zpět do `apiKey`                      | Obvykle klíč pro `/api/*` —** ne** ten samý                                                                                                                                                                                                                                                                                                                                     |
| `displayName`                    | `"OmniRoute"`                               | Název poskytovatele ve výběru                                                                                                                                                                                                                                                                                                                                                   |
| `timeoutMs`                      | `10000`                                     | Časový limit načítání pro každý koncový bod (automatická komba používají 5 s)                                                                                                                                                                                                                                                                                                   |
| `modelCacheTtlMs`                | `300000`                                    | Katalogová cache TTL; snímek disku ohřívá studené starty                                                                                                                                                                                                                                                                                                                        |
| `timeouts`                       | spadá zpět do `timeoutMs`                   | Rozpočty na koncový bod v ms: `models`, `combos`, `autoCombos`, `enrichment`                                                                                                                                                                                                                                                                                                    |
| `enrichment`                     | `true`                                      | Získejte názvy, ceny a rozpočty volných vrstev                                                                                                                                                                                                                                                                                                                                  |
| `providerTag`                    | `true`                                      | Přepněte koncovou závorku editoru: `Provider - Model (Editor)`. Poskytovatel (trasa obsluhující model) je vždy zobrazen; editor (který vytvořil model) se objeví pouze v závorce. Příklad: `Openrouter - MoonshotAI: Kimi K 3.1 Pro` -> `Openrouter - Kimi K 3.1 Pro (MoonshotAI)`. Vynecháno, když editor a poskytovatel sdílejí jméno. Nastavte `false`, abyste jej upustili. |
| `usableOnly`                     | `false`                                     | Ponechat zprávy brány jako zřízené pouze pro poskytovatele                                                                                                                                                                                                                                                                                                                      |
| `combosSource`                   | `"api"`                                     | `"models"` přeskočí `/api/combos` a publikuje kombinované řádky `/v1/models` ; filtry na úrovni členů uchovávají `"api"`                                                                                                                                                                                                                                                        |
| `showcasePerOwner`               | `10`                                        | Položky výchozího zobrazení uchovávané podle poskytovatele                                                                                                                                                                                                                                                                                                                      |
| `freshPerOwner`                  | `10`                                        | Výchozí zobrazení nových záznamů uchovávaných podle poskytovatele                                                                                                                                                                                                                                                                                                               |
| `freshWindowDays`                | `90`                                        | Okno čerstvosti ve dnech pro čerstvou větev                                                                                                                                                                                                                                                                                                                                     |
| `usageMemory`                    | `true`                                      | Obnovit staticky zrušené položky pojmenované 30denní analýzou využití (vyžaduje token pro správu)                                                                                                                                                                                                                                                                               |
| `visibleModels` / `hiddenModels` | `[]`                                        | Přesné nebo příponové seznamy povolených; popírat výhry; `*` publikuje celý katalog (ostatní filtry stále platí)                                                                                                                                                                                                                                                                |
| `geminiSanitization`             | `true`                                      | Odstraňte klíčová slova JSON-Schema Gemini odmítá, ze schémat nástrojů (nástroje `$ref` jsou předávány nedotčené)                                                                                                                                                                                                                                                               |
| `apiFormat.allowAnthropic`       | `false`                                     | Směrujte ID na seznamu povolených přes blok Anthropic API                                                                                                                                                                                                                                                                                                                       |
| `apiFormat.anthropicModels`      | `[]`                                        | Úplná ID modelů přesměrována do Anthropic                                                                                                                                                                                                                                                                                                                                       |
| `logLevel` / `startupDebug`      | `warn` / `false`                            | Výřečnost loggeru                                                                                                                                                                                                                                                                                                                                                               |

Využití paměti je ve výchozím nastavení zapnuto. Bez tokenu pro správu zůstane inertní (zaznamená se oznámení o spuštění) a nic se neobnoví.

## Jak zůstává katalog čerstvý

Katalog se líně načítá a ukládá do mezipaměti pro `modelCacheTtlMs` a snímek disku udržuje poslední známý katalog dostupný, když je brána nedostupná — výpadek vás nestojí nic jiného než čerstvost. Modely a komba jsou publikovány, jakmile dorazí; automatická komba, seznam poskytovatelů a překryvná vrstva obohacení se po přistání složí, takže jeden pomalý koncový bod nemůže držet jako rukojmí celý výběr.

Názvy následují `Provider - Model[ (Editor)][ · budget][ (route)]`: poskytovatel se zobrazí vždy, když id nese jedno (id bez lomítka se vykresluje bez předpony), úvodní `🆓` označuje volné položky a jejich rozpočet na volné úrovni zůstává jako přípona `· 1M tokens/month`, editor explicitního názvu `Editor: Model` se přesune na koncovou závorku (žádný editor nelze uhodnout z jiných názvů) a komba se vykreslují zdarma jako `combo - <slug>` Dvě položky, které sdílejí název, získají příponu trasy — `(no-think)` — takže zůstanou rozlišitelné. `providerTag` (výchozí `true`) přepíná koncovou závorku editoru.

Neexistuje žádný ruční obnovovací příkaz: příkazy OpenCode v2 jsou šablony výzev, nikoli zpětná volání, takže plugin je nemůže odhalit. Obnovení následuje po TTL; hostitel je požádán o opětovné načtení pouze tehdy, když se katalog nebo překryv skutečně změnil, nikdy jednou za obnovení.

## Volání nástrojů v Gemini

Gemini odmítne celý požadavek, pokud deklarace nástrojů obsahují `$schema` nebo `additionalProperties`, a odpoví chybou `400 INVALID_ARGUMENT`. Plugin tyto klíčové výrazy odstraní ze schémat nástrojů určených pro model Gemini tohoto poskytovatele a všechny ostatní požadavky ponechá beze změny. Nástroj obsahující `$ref` se předá beze změny namísto odstranění těchto výrazů, protože odstranění odkazu by rozšířilo schéma tak, že by „přijímalo cokoli“.
Tuto funkci lze vypnout nastavením `"geminiSanitization": false`.

## Odstraňování problémů

| Příznak                                         | Příčina                                                                                                                       |
| ----------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| Picker neukazuje žádný model OmniRoute          | Nebyl vyřešen žádný klíč (zkontrolujte varování při spuštění) nebo je brána nedostupná                                        |
| Nezpracované ID modelů, žádná komba, žádné ceny | Koncové body správy odmítly token — set `managementReadToken`                                                                 |
| Krátký nebo prázdný katalog `freeOnly`          | Žádný token správy nebo odmítnutý token — nepřečetl řádek souhrnu aktualizace (počet `unmatched-free` ) v protokolu hostitele |
| Relace připnutá k `opencode-<id>/...`           | Plugin v1 publikoval `opencode-<id>`; v2 publikuje `<id>` holé, takže znovu vyberte model pod `<id>/...`                      |

Proměnné prostředí se musí dostat do procesu serveru s otevřeným kódem: když hostitel běží jako služba, prostředí, na kterém běží `opencode models`, a prostředí serveru se liší, takže exportujte klíč tam, kde jej server čte.
