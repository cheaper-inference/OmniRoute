> **Stručně**: OmniRoute řadí své **bezplatné** poskytovatele podle kvality modelů pomocí **ELO skóre
> z Arena AI (ve stylu LMArena)**. Otevřete v řídicím panelu stránku **Žebříček bezplatných poskytovatelů**
> a zjistěte, kteří bezplatní poskytovatelé nabízejí nejsilnější modely pro váš úkol —
> celkově nebo podle filtrované kategorie (programování, kontrola, dokumentace, ladění).

---

## Co to je

OmniRoute registruje 376 poskytovatelů, včetně 155 položek katalogu označených **free/no-auth**
(bez autentizace, OAuth s bezplatnou úrovní nebo API klíč s bezplatnou úrovní — viz
[Průvodce bezplatnými úrovněmi](../getting-started/FREE-TIERS-GUIDE.md) a kompletní
[adresář bezplatných úrovní](../reference/FREE_TIERS.md)). Háček spočívá v tom, že bezplatní
poskytovatelé se značně liší v kvalitě modelů. Poskytovatel bez autentizace nabízející
špičkový model je mnohem užitečnější než ten, který nabízí malý zastaralý model.

**Free Provider Rankings** odpovídá na otázku „**který bezplatný poskytovatel mi nabídne
nejlepší model?**“ spojením katalogu každého bezplatného poskytovatele s **crowdsourcingem
získanými skóre kvality** ze **žebříčku Arena AI** (ELO založené na lidských preferencích —
stejný princip, na kterém stojí chatbotová aréna LMArena). Poskytovatelé jsou poté seřazeni
podle síly svého **nejlepšího bezplatného modelu**.

Žebříček je vypočítán ze tří skutečných zdrojů:

1. Seznamy bezplatných poskytovatelů — `NOAUTH_PROVIDERS`, plus položky `OAUTH_PROVIDERS` /
   `APIKEY_PROVIDERS` označené příznakem `hasFree`
   (`src/shared/constants/providers.ts`).
2. Katalog modelů každého poskytovatele z registru poskytovatelů
   (`open-sse/config/providerRegistry.ts`).
3. Skóre vhodnosti pro úlohy odvozená z ELO, uložená v databázové tabulce `model_intelligence`
   synchronizačním enginem Arena ELO (`src/lib/arenaEloSync.ts`).

Logika spojování se nachází v `src/lib/freeProviderRankings.ts`.

## Jak získat přístup

### Stránka řídicího panelu

Otevřete řídicí panel a přejděte na **Náklady → Žebříček bezplatných poskytovatelů** nebo přejděte přímo na:

```
/dashboard/free-provider-rankings
```

Stránka (`src/app/(dashboard)/dashboard/free-provider-rankings/page.tsx`) zobrazuje:

- **Stupně vítězů pro první 3 místa** (🥇 🥈 🥉) nejlépe hodnocených bezplatných poskytovatelů.
- Úplnou **tabulku žebříčku** se sloupci: **Pořadí**, **Poskytovatel**, **Nejlepší model**,
  **Skóre**, **Průměrné skóre**, **Modely**, **Typ**.
- **Tlačítka pro filtrování kategorií**: _Všechny kategorie_, _Výchozí_, _Programování_, _Kontrola_,
  _Dokumentace_, _Ladění_.

Odznak **Typ** u každého poskytovatele uvádí, jakým způsobem je bezplatný:

| Odznak   | Význam                                                 |
| -------- | ------------------------------------------------------ |
| `NOAUTH` | Vždy zdarma, nejsou potřeba žádné přihlašovací údaje   |
| `OAUTH`  | Poskytovatel OAuth s bezplatnou úrovní (`hasFree`)     |
| `APIKEY` | Poskytovatel API klíče s bezplatnou úrovní (`hasFree`) |

Skóre se zobrazují jako snadno srozumitelné popisky (např. _Elitní_, _Vynikající_, _Velmi dobré_,
_Dobré_, _Průměrné_), nikoli jako nezpracovaná čísla, protože podkladová hodnota představuje relativní
hodnocení kvality, nikoli procento.

### Koncový bod API

Stránka používá veřejný koncový bod určený pro čtení
(`src/app/api/free-provider-rankings/route.ts`):

```
GET /api/free-provider-rankings
GET /api/free-provider-rankings?category=coding
GET /api/free-provider-rankings?category=coding&limit=20
```

Parametry dotazu (ověřované pomocí Zod):

| Parametr   | Typ    | Výchozí hodnota | Poznámky                                                                                                                |
| ---------- | ------ | --------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `category` | string | (žádná)         | Jedna z hodnot `default`, `coding`, `review`, `documentation`, `debugging`. Pro kombinovaný žebříček parametr vynechte. |
| `limit`    | number | `50`            | Omezeno na rozsah `1–100`.                                                                                              |

Struktura odpovědi:

```json
{
  "rankings": [
    {
      "id": "<provider-id>",
      "name": "<provider name>",
      "icon": "<icon>",
      "color": "<hex color>",
      "textIcon": "<short label>",
      "category": "noauth | oauth | apikey",
      "topModel": {
        "modelId": "<registry model id>",
        "modelName": "<model display name>",
        "score": 0.0,
        "eloRaw": 0,
        "confidence": "high | medium | low",
        "category": "<task category>"
      },
      "averageScore": 0.0,
      "modelCount": 0
    }
  ]
}
```

`eloRaw` je původní hodnota ELO z Arena; `score` je normalizovaná hodnota vhodnosti pro daný úkol
(viz níže). Poskytovatelé bez modelů s přiděleným skóre jsou z odpovědi vynecháni.

## Jak fungují skóre

### Zdroj: žebříček Arena AI

Synchronizační engine Arena ELO (`src/lib/arenaEloSync.ts`) načítá dva žebříčky — `text`
a `code` — z API žebříčku Arena AI
(`https://api.wulong.dev/arena-ai-leaderboards/v1/leaderboard`). Pokud toto API nevrátí
žádný použitelný žebříček, engine přejde na oficiální dataset `lmarena-ai/leaderboard-dataset`
na Hugging Face datasets-server (`src/lib/arenaEloHfSource.ts`, CC-BY-4.0; `overall` → `text`,
`coding` → `code`); `GET /api/intelligence/sync` hlásí `activeSource`, `lastError` a
`lastFailedAt`. Každá položka žebříčku
obsahuje název modelu, dodavatele, ELO `score`, interval spolehlivosti a počet hlasů.

Kategorie žebříčku se mapují na kategorie úloh OmniRoute:

| Žebříček Arena | Kategorie úloh OmniRoute                          |
| -------------- | ------------------------------------------------- |
| `text`         | `default`, `review`, `documentation`, `debugging` |
| `code`         | `coding`                                          |

### Normalizace (skóre vhodnosti pro úlohu)

Hrubé ELO skóre se normalizuje v rámci každého žebříčku na **hodnotu vhodnosti pro úlohu v intervalu `[0.4, 0.98]`**:

```
taskFit = 0.4 + 0.58 * ((elo - minElo) / (maxElo - minElo))
```

Skóre nikdy nedosáhne `0` ani `1`, čímž zůstává prostor pro uživatelská přepsání. Toto je
pole `score`, které vidíte v odpovědi API, a označení zobrazené na dashboardu.

### Spolehlivost

Každá položka získá úroveň spolehlivosti na základě počtu hlasů v Areně:

| Spolehlivost | Hlasy   |
| ------------ | ------- |
| `high`       | ≥ 5 000 |
| `medium`     | ≥ 1 000 |
| `low`        | < 1 000 |

### Ukládání a čerstvost

Normalizované položky se zapisují do databázové tabulky `model_intelligence` s
`source = "arena_elo"` (`src/lib/db/modelIntelligence.ts`). Položky **expirují po
7 dnech**, takže poskytovatel, který přestane synchronizovat, nakonec z výsledků vypadne,
místo aby poskytoval zastaralá data.

Synchronizace běží **ve výchozím nastavení zapnutá**:

- Spustí se jednou při startu serveru a poté v pravidelných intervalech
  (`src/lib/arenaEloSync.ts`, zapojeno z `src/instrumentation-node.ts`).
- Je **neblokující a nikdy není fatální** — pokud načtení z upstreamu selže, OmniRoute běží
  dál a žebříčky jednoduše zobrazují poslední platná data (nebo prázdný stav).

Řídí ji dvě proměnné prostředí (zdokumentované v
[`docs/reference/ENVIRONMENT.md`](../reference/ENVIRONMENT.md)):

| Proměnná                  | Výchozí       | Účel                                                       |
| ------------------------- | ------------- | ---------------------------------------------------------- |
| `ARENA_ELO_SYNC_ENABLED`  | `true`        | Nastavte na `false` pro odhlášení z odchozí synchronizace. |
| `ARENA_ELO_SYNC_INTERVAL` | `86400` (24h) | Interval synchronizace v sekundách.                        |

### Ruční synchronizace / stav / vymazání

Pro provozovatele je k dispozici autentizovaný management endpoint pro ruční ovládání
(`src/app/api/intelligence/sync/route.ts` — vyžaduje management autentizaci):

```
GET    /api/intelligence/sync          # aktuální stav synchronizace (enabled, lastSync, nextSync, intervalMs)
POST   /api/intelligence/sync          # spustí ruční synchronizaci; tělo: { "dryRun": true } pro náhled bez zápisu
DELETE /api/intelligence/sync          # vymaže všechny synchronizované položky intelligence arena_elo
```

Pokud je stránka žebříčků prázdná, ruční `POST /api/intelligence/sync` (nebo prostý
restart serveru) ji znovu naplní.

### Párování modelů se žebříčkem

ID modelů v registru a názvy modelů v Areně se ne vždy přesně shodují. Hodnocení používá
flexibilní párování (`findMatchingIntelligence` v `src/lib/freeProviderRankings.ts`):

1. Přesná shoda s normalizovaným ID modelu.
2. Shoda po odstranění koncového verzového sufixu (např. `kimi-k2.6` → `kimi-k2`).
3. Shoda prefixu (název modelu ze žebříčku je prefixem ID v registru).

Na straně synchronizace se odstraňují známé prefixy dodavatelů (`anthropic/`, `openai/`,
`google/`, …) a malá mapa aliasů rozšiřuje kanonické názvy na varianty, které OmniRoute
používá interně, takže modely zůstávají dohledatelné pod jakýmkoli názvem.

### Jak je hodnocen poskytovatel

Pro každého bezplatného poskytovatele engine ohodnotí každý model v jeho katalogu a poté:

- **Nejlepší model** = model poskytovatele s nejvyšším skóre.
- **Průměrné skóre** = průměr skóre všech hodnocených modelů daného poskytovatele.
- **Modely** = kolik modelů poskytovatele mělo skóre Arena.

Poskytovatelé jsou řazeni nejprve podle **skóre nejlepšího modelu**, poté podle průměrného
skóre. To odměňuje poskytovatele, který nabízí alespoň jeden silný bezplatný model.

## Jak vybrat bezplatné poskytovatele

1. **Vyberte správnou kategorii.** Pro agentní úlohy a programování použijte filtr **Coding**,
   pro obecný chat ponechte **All Categories** / **Default**. Stejný poskytovatel může
   mít v různých kategoriích odlišné pořadí, protože se jeho nejlepší model liší podle žebříčku.
2. **Pro jednoduché nastavení upřednostněte první tři příčky.** Pokud chcete připojit pouze
   jednoho nebo dva bezplatné poskytovatele, začněte těmi, kteří jsou ve vaší kategorii nejvýše.
3. **Zkontrolujte štítek Type.** Poskytovatele `NOAUTH` lze připojit nejrychleji (bez
   přihlašovacích údajů). Bezplatné úrovně `OAUTH` / `APIKEY` vyžadují rychlou registraci,
   ale často zpřístupňují výkonnější modely. Postup připojení najdete v dokumentu
   [Průvodce bezplatnými úrovněmi](../getting-started/FREE-TIERS-GUIDE.md).
4. **Připojte více poskytovatelů a nechte rozhodnout Auto-Combo.** Stejná data Arena ELO,
   která slouží této stránce, také vstupují do **faktoru vhodnosti pro úlohu** vyhodnocovacího
   mechanismu Auto-Combo (`open-sse/services/autoCombo/taskFitness.ts`, pořadí vyhodnocení
   `user_override → arena_elo → models_dev_tier → static table`). Jakmile tedy připojíte
   nejlepší bezplatné poskytovatele, směrování s `model: "auto"` (např. `auto/coding`)
   bude pro každý požadavek automaticky upřednostňovat kvalitnější bezplatné modely. Úplný
   popis všech 16 faktorů hodnocení najdete v dokumentu
   [Auto-Combo](../routing/AUTO-COMBO.md).
