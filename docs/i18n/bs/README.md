## Besplatni tokeni mjesečno: ~ 11.3B koliko drugi broje · ~ 90M Real

</div>

> **~ 11.3B besplatnih tokena / mjesec**<br/> <sub> broji način na koji broje drugi katalozi: svaki red se zbraja, završene ponude uključene </sub>
>
> **~ 90M real danas**<br/> <sub> svaka dijeljena kvota se broji jednom: šta zapravo možete koristiti </sub>
>
> **Ovdje je sve besplatno. Nema paywall.**<br/> ★ [Sviđa vam se? Zvezdi nam se na GitHub](https://github.com/cheaper-inference/OmniRoute)

Drugi katalozi naplaćuju od US$19 godišnje do US$49 za doživotni pristup podacima uživo. Ovdje je sve besplatno. <sub> Cijene provjerene 18.11.2026.</sub>

<sub>Katalog je posljednji put revidiran 23.11.2026. [Kako računamo →](docs/reference/FREE_TIERS.md#how-we-count)</sub>

> **Donesite svoje račune provajdera.** Ovo su besplatni nivoi trećih strana, a ne token grant od OmniRoute. Prijavite se, nabavite vjerodajnice tamo gdje ih provajder traži i povežite one koje možete koristiti. Svaki provajder postavlja svoja ograničenja, dostupnost i uslove.
>
> Ručno slaganje besplatnih nivoa znači desetine SDKs, desetine ograničenja stope i nema jasne ideje o tome šta vam je ostalo. OmniRoute čuva 214 kataloških redova sa slobodnim pristupom i izračunava stvarnu cifru iz 12 skupova s objavljenom kvotom, pri čemu se svaki zajednički skup računa jednom. Kvote koje se otvaraju samo nakon provjere regionalnog identiteta (danas, ModelScope) prikazane su odvojeno, +~ 6M iza provjere regionalnog identiteta, i nikada se ne dodaju stvarnoj cifri. Ono što je preostalo prikazuje se na kontrolnoj tabli (`/dashboard/free-tiers`).

## Instalirajte, povežite provajdera, a zatim usmjerite kroz jednu krajnju tačku

<img src="./docs/diagrams/works-zero-config.svg" width="100%" alt="Four steps to use OmniRoute. Install with npm install -g omniroute, run omniroute, connect a provider and create an API key in the dashboard, then call http://localhost:20128/v1 with model auto."/>

```bash
# After connecting a provider, create your OmniRoute key in Dashboard → API Keys:
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer YOUR_OMNIROUTE_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"auto","messages":[{"role":"user","content":"Hello!"}]}'
```

<sub>`auto` treba odgovarajuću rutu. Nova instalacija ne može imati prihvatljive ciljeve bez ključa, a dobavljač bez ključa može odbiti klijente treće strane. Pogledajte [Vodič za besplatne nivoe](docs/getting-started/FREE-TIERS-GUIDE.md) prije nego što odaberete provajdera.</sub>

## Kombinacije: vodeći

1. **Počnite sa `auto`.** Postavite model u svom OpenAI-kompatibilnom klijentu. OmniRoute pravi virtuelnu kombinaciju od povezanih provajdera i boduje kandidate uživo.
2. **Sačuvajte kombinaciju za veću kontrolu.** Odaberite ime, ciljnu listu i strategiju, a zatim koristite to ime kao model. Strategija određuje koji cilj ide prvi i kako će se ostali pokušati.

Kombinacija se automatski usmjerava kroz modele. Po iscrpljenju kvote, neuspjehu provajdera ili blokiranju modela, pokušava sljedeću prihvatljivu, zdravu metu.

### Zero-config: samo koristite `auto`

```bash
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <your-omniroute-key>" \
  -H "Content-Type: application/json" \
  -d '{"model": "auto", "messages": [{"role": "user", "content": "Hello"}]}'
```

Varijante podešavaju težine. Posljednje poznato-dobro rutiranje ostaje kod posljednjeg uspješnog provajdera sve dok ne uspije, a zatim se ponovno nalazi. `auto/fast` i `auto/cheap` izražavaju preferencije bez garancije najbržeg ili najjeftinijeg modela.

| Model ID            | Ponašanje                                                                                                                                                                                                                                                                                          |
| :------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `auto`              | Izbalansirane zadane težine.                                                                                                                                                                                                                                                                       |
| `auto/fast`         | Pogoduje malom kašnjenju i zdravlju dobavljača.                                                                                                                                                                                                                                                    |
| `auto/cheap`        | Favorizira niže kataloške cijene.                                                                                                                                                                                                                                                                  |
| `auto/coding`       | Ponderi kvaliteta na prvom mjestu za generiranje koda.                                                                                                                                                                                                                                             |
| `auto/smart`        | Kvalitet-prvi ponderi sa 10% istraživanja (zadano 5%).                                                                                                                                                                                                                                             |
| `auto/lkgp`         | Eksplicitno posljednje poznato-dobro rutiranje s istim težinama kao `auto`.                                                                                                                                                                                                                        |
| `auto/subscription` | Koristi samo kvotu plana potvrđenu uživo. Vraća HTTP 503 kada nijedan nije dostupan i izbjegava naplaćenu zamjenu.                                                                                                                                                                                 |
| `auto/thrifty`      | Planirajte → → bez ključa besplatno → jeftino → premium. Može doći do naplaćenih modela i vraća se na plan kada kvota i hlađenje dozvole.                                                                                                                                                          |
| `auto/offline`      | Favorizira kvotu i ograničenje brzine. Zahtjevi i dalje idu vašim provajderima.                                                                                                                                                                                                                    |
| `auto/chaos`        | Jedan model po dobavljaču paralelno, do pet prema zadanim postavkama ili deset kada se konfiguriše. Jedan upstream poziv po modelu. Vraća najbolje rangirani odgovor ili posljednji uspješan odgovor panela ako najbolji model ne uspije. Koristite `fusion` da sintetizirate odgovore sa sudijom. |

Primeri kategorija i opcionih nivoa uključuju `auto/coding:fast`, `auto/coding:free`, `auto/reasoning:pro` i `auto/vision`. Ako se nijedan povezani kandidat ne podudara, zahtjev vraća HTTP 503 i skup ostaje uski. [Auto-Combo vodič](./docs/routing/AUTO-COMBO.md) · [Pretplata na prvom mjestu](./docs/routing/SUBSCRIPTION_LADDER.md)

### Ili napravite vlastitu: 22 strategije usmjeravanja

```bash
omniroute combo create my-pool --strategy fill-first \
  --models "provider-a/model-1,provider-b/model-2"
```

CLI prihvata 15 od 22 strategije. Kontrolna tabla i kombinacije API prihvataju svih 22.

| Strategija          | Ponašanje                                                                                                                                                                                                           |
| :------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `auto`              | Rang kandidate uživo sa 16-faktorskim auto-kombo zapisnikom.                                                                                                                                                        |
| `cache-optimized`   | Preferirajte nalog koji će vjerovatno držati prompt prefiks u kešu.                                                                                                                                                 |
| `context-optimized` | Prvo isprobajte najveći poznati prozor konteksta.                                                                                                                                                                   |
| `context-relay`     | Zadržite svoju narudžbu i pošaljite sažetak razgovora prilikom promjene računa.                                                                                                                                     |
| `cost-optimized`    | Sortiraj po kataloškoj cijeni ulaznog tokena, nepoznate zadnje. Konačni trošak zahtjeva može se razlikovati.                                                                                                        |
| `expiry-first`      | Kvota potrošnje će vjerovatno isteći, najveći preostali dio po satu do prvog resetiranja.                                                                                                                           |

### Otpornost je ugrađena u: 3 nezavisna sloja

Greške se tretiraju u tri opsega, tako da jedan loš model ne uklanja svoj nalog, a jedan loš nalog ne uklanja svog provajdera.

<img src="./docs/diagrams/resilience-layers.svg" width="100%" alt="OmniRoute resilience: 3 independent self-healing layers, the right layer for the right failure. Layer 1, provider circuit breaker (whole provider): trips only on 408/500/502/503/504, opens after 8 failures for OAuth providers or 12 for API-key providers, resets after 60s or 30s into a HALF-OPEN probe, lazy recovery; while OPEN the combo reroutes to the next provider. Layer 2, connection cooldown (one key or account): base 5s OAuth or 3s API-key, exponential backoff with an anti-thundering-herd guard, success clears the error state; one cooling key is skipped while sibling keys keep serving. Layer 3, model lockout (one model): per-model 429, 404 or access denials lock just that model, never the whole connection. Terminal states (banned, expired, credits exhausted) wait for the operator; they are not cooldowns."/>

#### Ako cijeli provajder ne radi

The** provajderski prekidač** otvara se nakon 8 (OAuth) ili 12 (API ključ) grešaka sa statusom 408, 500, 502, 503 ili 504. Kombinacije preskaču tog provajdera dok je otvoren. Nakon 60 s ili 30 s, jedan zahtjev sonde odlučuje hoće li se zatvoriti.

#### Ako je jedan ključ ili račun ograničen na stopu

The** hlađenje veze** klupe samo tu vezu, sa eksponencijalnim povlačenjem od 5 s (OAuth) ili 3 s ( ključ API ). Ostali ključevi za istog provajdera nastavljaju da služe.

#### Ako je jedan model odbijen

The** zaključavanje modela** blokira samo taj model na toj vezi nakon po modelu 429, 404 ili odbijanja pristupa. Ostali modeli na istoj vezi nastavljaju da služe.

Zabranjene, istekle i vankreditne veze su terminalna stanja, a ne hlađenja: čekaju da ih popravite.

## Puni CLI, MCP i A2A

> OmniRoute isporučuje klijenta komandne linije sa** 91 naredba najvišeg nivoa i grupa komandi** (754 komande računajući podkomande), an**MCP server sa 110 alata i 33 opsega** , i an**A2A agent sa 6 vještina** . Skripte, terminali i AI agenti mogu upravljati istim gateway-om.

### Pravi CLI, ne samo `start`

```bash
omniroute                 # start the gateway and dashboard (port 20128)
omniroute setup           # guided first-run wizard
omniroute repl            # interactive chat in the terminal (/model /combo /skill /memory)
omniroute chat "hello"    # one-shot prompt; also reads --file or --stdin
omniroute doctor          # check config, database, ports, Node runtime and native deps
```

Globalna `--output table|json|jsonl|csv` zastavica čini iste komande upotrebljivim iz skripti i CI.

### Remote mode: CLI na vašem laptopu, OmniRoute na serveru

Prijavite se jednom na udaljeni server. CLI ga sprema kao a** kontekstu** , a kasnije naredbe rade na tom serveru dok se ne vratite nazad.

```bash
omniroute connect omniroute.example.com          # asks for the password, saves a scoped token as a context
omniroute models                                 # runs against the remote server
omniroute configure codex                        # picks a remote model, writes a local Codex profile
omniroute tokens create --name ci --scope read   # mint a narrower token for another machine
omniroute contexts use default                   # switch back to the local server
```

| Obim tokena | <img width="2000" height="0" alt=""> Šta dozvoljava                              |
| ----------- | -------------------------------------------------------------------------------- |
| `read`      | Popis i pregled: modeli, status, zapisi, upotreba                                |
| `write`     | `read` plus konfiguriši i primeni: podešavanje klijenta, ključevi, konfiguracija |
| `admin`     | `write` plus upravlja: tokeni, provajderi, usluge, politika                      |

Goli host dobija `http://` i port 20128; proslijediti puni `https://` URL kada server sjedi iza TLS. Rute koje mogu pokrenuti procese ostaju samo za petlju, bez obzira na token.

### Povežite agenta

Agent, ili vaš vlastiti kod, može pokretati rutiranje, provajdere, kombinacije, keš memoriju, kompresiju i memoriju kroz bilo koje od ovih sučelja. HTTP putanje opslužuje gateway, po defaultu na `http://localhost:20128`.

| Interface                 | Krajnja tačka ili komanda  | Koristite ga za                                                                    |
| ------------------------- | -------------------------- | ---------------------------------------------------------------------------------- |
| MCP preko stdio           | `omniroute --mcp`          | Claude Desktop, Cursor i drugi lokalni MCP klijenti                                |
| MCP preko Streamable HTTP | `/api/mcp/stream`          | Udaljeni MCP klijenti: 110 alata, 33 opsega, svaki poziv upisan u dnevnik revizije |
| MCP preko SSE             | `/api/mcp/sse`             | Klijenti koji i dalje koriste SSE transport                                        |
| A2A discovery             | `/.well-known/agent.json`  | Kartica agenta: govori drugim agentima šta OmniRoute može učiniti                  |
| A2A izvršenje             | `POST /a2a`                | JSON-RPC 2.0 zadaci, sinhroni ili streamovani preko SSE, preko 6 vještina          |
| REST API                  | `/v1/*`                    | OpenAI kompatibilan chat, odgovori, ugrađivanje, slike, audio i OCR                |
| Webhooks                  | `/api/webhooks`            | Događaji za Slack, Discord, Telegram ili bilo koji URL sa HMAC potpisom            |
| Remote CLI                | `omniroute connect <host>` | Pokrenite udaljenu instancu s tokenima pristupa u opsegu                           |

Šest A2A vještina su `smart-routing`, `quota-management`, `provider-discovery`, `cost-analysis`, `health-report` i `list-capabilities`.

**Prije povezivanja:**

- **MCP preko HTTP počinje onemogućeno.** Uključite ga pomoću `omniroute mcp enable --transport streamable-http` ili sa stranice Endpoints na kontrolnoj tabli. Jedan HTTP transport je aktivan istovremeno: `streamable-http` služi `/api/mcp/stream`, `sse` služi `/api/mcp/sse`.
- **A2A počinje onemogućen.** Omogućite ga na stranici Krajnje tačke na kontrolnoj tabli. `POST /a2a` zatim slijedi ista pravila API ključa kao `/v1`.
- **Daljinski MCP treba odgovarajući ključ.** `/api/mcp/*` podrazumevano odgovara samo na povratnu petlju. Sa drugog hosta pošaljite ključ sa `manage` ili `admin` (svi alati), ili sa `mcp:connect` plus opsegom alata koji su vam potrebni. Za ključeve bez `manage`/`admin`, opseg alata se uvijek primjenjuje.

```bash
# Give Claude Code the OmniRoute toolset over MCP:
omniroute mcp enable --transport streamable-http
claude mcp add --transport http omniroute http://localhost:20128/api/mcp/stream \
  --header "Authorization: Bearer <api-key-with-manage-scope>"
```

### Kako radi — pipeline, arhitektura i matematika uštede

<img src="./docs/diagrams/compression-pipeline.svg" width="100%" alt="OmniRoute compression pipeline: an illustrative 10,000-token client request passes through 12 composable engines — Session-Dedup, CCR, Lite, RTK, Responses Tool Output, Headroom, Relevance, Caveman, Aggressive, LLMLingua-2, Ultra and OmniGlyph — and can reach the provider at about 1,080 tokens in the documented stacked example. Structured content is protected by preservation guards and per-step fidelity gates; explicit lossy or experimental modes may transform eligible content."/>

Zadana složena kombinacija pokreće `RTK → Caveman`. Kada oba djeluju na isti tool/context nosivost, ušteda je:

```txt
combined = 1 − (1 − RTK) × (1 − Caveman_input)
average  = 1 − (1 − 0.80) × (1 − 0.46) = 89.2%
range    = 78.4 – 94.6%
```

Blokovi koda, URLs, JSON i strukturirani podaci su** uvek zaštićen** pomoću motora za očuvanje.

> **Zašto koristiti mnogo tokena kada malo tokena radi trik?** Svaki zahtjev prolazi kroz OmniRoute-in kompresijski cjevovod** transparentno** — nema promjena klijenta. Sada je a** hrpa od 12 kompozitnih motora** koji rade po redosledu i mešaju i poklapaju po rutnoj kombinaciji — na osnovu ideja iz [RTK](https://github.com/rtk-ai/rtk), [Caveman](https://github.com/JuliusBrussee/caveman) (⭐ 90K +), [LLMLingua-2](https://github.com/microsoft/LLMLingua) i [Troglodita](https://github.com/leninejunior/troglodita) (PT-BR).

## Više metoda instalacije — Docker, source, pnpm, Arch

**🐳 Docker**

```bash
docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 \
  -p 127.0.0.1:20128:20128 -v omniroute-data:/app/data cheaperinference/omniroute:latest
```

`:latest` slijedi najviši** objavljeno** stabilan SemVer. Ne prati git `main`. Pin `:X.Y.Z` za GitOps. Pogledajte [Docker Release Channels](docs/guides/DOCKER_GUIDE.md#release-channels). Igle za sliku**`OMNIROUTE_MEMORY_MB=1024`** . To je dovoljno za kontrolnu tablu i lagano ćaskanje.** Agenti za kodiranje** (`POST /v1/responses` iz koda Claude, Codex, Grok, …) potrebna je mnogo veća V8 hrpa ili proces `FATAL ERROR` s na ~ 12 GiB pod dva duga konteksta koji se preklapaju. Odredite veličinu spremnika iznad hrpe (nativni baferi se nalaze izvan V8):

| <img width="2000" height="0" alt=""> Workload | gomila (`-e OMNIROUTE_MEMORY_MB`) | Kontejner (`--memory`) |
| --------------------------------------------- | --------------------------------- | ---------------------- |
| Kontrolna tabla / svjetlo razgovor            | `1024` (zadana slika)             | ≥ 2 g                  |
| Jedan agent za kodiranje                      | `8192`                            | ≥ 10 g                 |
| Dvije istovremene duge `/v1/responses`        | `10240`–`12288`                   | ≥ 12–16 g              |

```bash
docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 \
  -e OMNIROUTE_MEMORY_MB=8192 --memory=10g \
  -p 127.0.0.1:20128:20128 -v omniroute-data:/app/data cheaperinference/omniroute:latest
```

Cijela tabela: [Docker Vodič — runtime RAM](docs/guides/DOCKER_GUIDE.md#runtime-ram-for-coding-agents).

> **Docker kanal prije objavljivanja:** `diegosouzapw/omniroute:next` i `diegosouzapw/omniroute:next-web` prate trenutnu zadanu granu `release/v*`. Ove promjenjive oznake namijenjene su samo za testiranje neobjavljenih popravaka i jesu** nije podržano za proizvodnju** . Pogledajte [Docker Release Channels](docs/guides/DOCKER_GUIDE.md#release-channels).

**🥟 Bun**

Standardna `bun install` i globalna instalacija (`bun install -g omniroute`) podržani su putem Bun detekcije vremena izvođenja:

- **Ugrađena `bun:sqlite`** : OmniRoute koristi ugrađeni Bun `bun:sqlite` kada radi pod Bun, vraćajući se na `better-sqlite3` na Node.js ili `sql.js`.
- **Automatski odabir paketa Webpack u dev** : Razvoj (`bun run dev`) automatski detektuje Bun i onemogućuje Turbopack u korist Webpack-a kako bi se spriječile izvorne nekompatibilnosti povezivanja V8. Produkcijske građe (`bun run build`) prate `OMNIROUTE_USE_TURBOPACK` tačno kao na čvoru: Turbopack po defaultu, `OMNIROUTE_USE_TURBOPACK=0` za izgradnju sa Webpackom (`Dockerfile.bun` ga izlaže kao `--build-arg`).
- **Namjenski Bun Dockerfile** : Višestepeni `Dockerfile.bun` za nativnu Bun proizvodnu implementaciju (`docker build -f Dockerfile.bun -t omniroute:bun .`).

**⚡ Brža / lakša instalacija (preskočite izvornu verziju)**

Izvorni SQLite motor (`better-sqlite3`) je an** opciono** ovisnost, tako da globalna instalacija nikada ne blokira kompajliranje iz izvora: koristi unaprijed izgrađenu binarnu datoteku kada se podudara s vašim platform/Node, a inače se vraća transparentno na čistu JS mašinu (`node:sqlite` na Node 22 +, inače u paketu `sql.js` WASM) — nisu potrebni alati za pravljenje.

Da preskočite postinstalaciju** nativno zagrevanje** u potpunosti (CI, bezglave ili spore mašine). Napomena: ovo samo preskače izvorni SQLite korak zagrijavanja (`scripts/postinstall.mjs`); binary-copy/repair kuka (`scripts/build/postinstall.mjs`) i dalje radi normalno:

```bash
OMNIROUTE_SKIP_POSTINSTALL=1 npm install -g omniroute   # CI=1 also skips it
```

Za najbrže instalacije prednost** pnpm** (Adresirano na sadržaj prodavnica + hard links — vidi gore). Za vrijeme rada bez kontrolne ploče, bez glave koristite Docker `base` profil (iznad) ili [Termux vodič](docs/guides/TERMUX_GUIDE.md). CLI i web nadzorna ploča se opslužuju istim procesom na jednom portu, tako da danas ne postoji poseban paket samo za CLI.

### Kako doprinijeti

1. Razdvojite spremište

3. Kreirajte svoju granu karakteristika (`git checkout -b feat/amazing-feature`)

6. Otvorite zahtjev za povlačenjem pomoću** baza = ta `release/vX.Y.Z` grana**

## Priznanja

OmniRoute stoji na ramenima divova. Počelo je kao viljuška** [9router](https://github.com/decolua/9router)** i TypeScript port projekta Go** [CLIProxyAPI](https://github.com/router-for-me/CLIProxyAPI)** — i odatle je svaki podsistem ispod bio inspirisan projektom otvorenog koda koji je prvi stigao tamo. Svaki je oblikovao betonski komad OmniRoute. Ovo je naša zahvalnost svima njima. 🙏
