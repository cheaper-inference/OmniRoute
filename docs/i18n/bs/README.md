## 💰 ~ 1.62B tokena/mjesec na besplatnim nivoima trećih strana

</div>

> **Donesite svoje račune provajdera.** Ovo je procijenjeni agregat na zasebno kvalifikovanim besplatnim nivoima trećih strana, a ne token grant od OmniRoute. Prijavite se, pribavite vjerodajnice gdje je potrebno i povežite provajdere koje možete koristiti; svaki provajder kontroliše svoja ograničenja, dostupnost i uslove.
>
> Ručno slaganje besplatnih nivoa je bolno — desetine SDKs, desetine ograničenja brzine, a nemate pojma koliko zapravo imate. OmniRoute katalozi **466 slobodnih ulaza u 34 ponavljajuća ključa bazena** i izračunava naslov tokena iz **17 pulova s objavljenim pozitivnim mjesečnim budžetom plus pet Groq kapa po modelu** , deduplicirano zajedničkim bazenom. Kvote koje se otvaraju samo nakon provjere regionalnog identiteta (danas: ModelScope) prikazane su odvojeno, +~ 6M iza verifikacije regionalnog identiteta, i nikada se ne sumiraju u naslovu. Rezultat ostaje vidljiv na kontrolnoj tabli (`/dashboard/free-tiers`).

<img src="./docs/diagrams/free-tier-budget.svg" width="100%" alt="OmniRoute free-tier budget card: ~1.62B free tokens per month steady, up to ~2.22B in the first month with signup credits, from 34 documented recurring pool keys covering 466 cataloged free-tier entries behind one endpoint. Honest pool-deduped math — each shared pool counted once, including 17 recurring pools with a published positive monthly token budget plus five per-model Groq caps; 12 providers are marked avoid in the terms-risk catalog so you decide. Budget bar includes Mistral 1B, Nara 210M, LLM7 150M, xKiro 150M, Groq 30M (five per-model caps) and smaller pools, plus first-month signup credits and permanently-free no-token-cap providers surfaced separately so they never inflate the headline. Live used/remaining on /dashboard/free-tiers."/>

> Animirani sažetak `/dashboard/free-tiers` stranice uživo. Potpuna metodologija (pool dedupe, kreditni nivoi, uslovi provajdera):**[docs/reference/FREE_TIERS.md](docs/reference/FREE_TIERS.md)** .
>
> <sub>Ove brojke se revidiraju svake dvije sedmice u odnosu na katalog uživo i **kretati se u oba smjera** — provajder prekida besplatni nivo i broj opada; novi sleti i penje se. Mi objavljujemo ono što katalog zapravo izračunava, nikad zaokruženi najbolji slučaj.</sub>

## 🆓 Instalirajte, povežite provajdera, a zatim usmjerite kroz jednu krajnju tačku

</div>

<img src="./docs/diagrams/works-zero-config.svg" width="100%" alt="Three steps: install and start OmniRoute, connect an eligible provider with your own account or API key, then point your tool at localhost:20128/v1 using an OmniRoute API key and model auto. Routing depends on available eligible connections and provider limits."/>

```bash
# After connecting a provider, copy your OmniRoute key from Dashboard → Endpoints:
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer YOUR_OMNIROUTE_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"auto","messages":[{"role":"user","content":"Hello!"}]}'
```

## 📡 OmniRoute Radar

Glavna brojka za besplatni nivo ostaje **~1,62 mlrd. tokena/mjesečno** iz gore navedenog dokumentovanog kataloga,
iz kojeg su uklonjeni duplikati među zajedničkim kvotama. Privremeni krediti pri registraciji kod pružalaca usluga mogu zasebno povećati prvi
mjesec na **~2,22 mlrd.** Radar je opcionalni, potpisani sloj kataloga za korisnike koji žele ažurniju
dostupnost besplatnih modela između OmniRoute izdanja; katalog zajednice i svaka postojeća besplatna
funkcija ostaju besplatni.

Podržavaoci mogu dobiti aktivni katalog i dodatne mogućnosti kod pružalaca usluga. Njegova zasebna,
promjenjiva gornja granica iznosi **najviše približno 3 mlrd. tokena/mjesečno**, zavisno od dostupnosti pružalaca usluga.
Ta gornja granica nije zagarantovana: pružaoci usluga mogu u bilo kojem trenutku promijeniti kvote, uslove ispunjavanja, modele ili regije.

Radar se koristi samo uz izričit pristanak i podržava isključivo GET zahtjeve. OmniRoute klijent ne prenosi upite, saobraćaj, konfiguraciju pružalaca
usluga, telemetriju korištenja niti lokalno stanje odbacivanja obavještenja. Saznajte više o uslovima ispunjavanja i
trenutnom katalogu na **[radar.omniroute.online/planos](https://radar.omniroute.online/planos)**.

## 🔌 Potpuni CLI + A2A i MCP

</div>

> Pored servera, OmniRoute je **potpuna komandna konzola** sa **više od 80 komandi**, kao i otvorenim protokolima za agente, tako da AI agent može njime upravljati **samostalno**.

### ⌨️ Pravi CLI (ne samo `start`)

```bash
omniroute               # pokreni pristupnik + kontrolnu ploču (port 20128)
omniroute chat          # interaktivni TUI klijent za razgovor (komande: /model /combo /skill /memory)
omniroute setup         # vođeni čarobnjak za prvo pokretanje
omniroute doctor        # dijagnosticiraj pružaoce usluga, portove i izvorne zavisnosti
```

### 🛰️ Udaljeni način rada — pokrenite CLI ovdje, a OmniRoute na VPS-u

OmniRoute je na serveru? Upravljajte njime sa svog laptopa koristeći **isti CLI**. Prijavite se jednom
pomoću pristupnog tokena ograničenog opsega; svaka komanda će se zatim izvršavati na udaljenom serveru.

```bash
omniroute connect 192.168.0.15            # lozinka → token ograničenog opsega, sačuvan kao kontekst
omniroute models                         # ← izvršava se na UDALJENOM serveru
omniroute configure codex                 # ← bira udaljeni model, zapisuje lokalni Codex profil
omniroute tokens create --name ci --scope read   # kreiraj tokene užeg opsega za druge uređaje
omniroute contexts use default            # ← prebaci se nazad na lokalni server
```

Tokeni imaju opseg `read` / `write` / `admin`; rute koje pokreću procese ostaju dostupne samo putem povratne petlje.

### 📖 Kako funkcioniše — pipeline, arhitektura i matematika uštede

<img src="./docs/diagrams/compression-pipeline.svg" width="100%" alt="OmniRoute kompresijski pipeline: ilustrativni zahtjev klijenta od 10.000 tokena prolazi kroz 12 kompozabilnih engine-a — Session-Dedup, CCR, Lite, RTK, Responses Tool Output, Headroom, Relevance, Caveman, Aggressive, LLMLingua-2, Ultra i OmniGlyph — i može stići do provajdera sa oko 1.080 tokena u dokumentovanom primjeru složenog režima. Strukturirani sadržaj je zaštićen čuvarima očuvanja i provjerama vjernosti po koracima; eksplicitni lossy ili eksperimentalni režimi mogu transformisati podoban sadržaj."/>

Podrazumijevana složena kombinacija pokreće `RTK → Caveman`. Kada oba djeluju na isti tool/context payload, uštede se sabiraju:

```txt
combined = 1 − (1 − RTK) × (1 − Caveman_input)
average  = 1 − (1 − 0.80) × (1 − 0.46) = 89.2%
range    = 78.4 – 94.6%
```

Kodni blokovi, URL-ovi, JSON i strukturirani podaci su **uvijek zaštićeni** pomoću engine-a za očuvanje.

> **Zašto koristiti mnogo tokena kada mali broj tokena radi posao?** Svaki zahtjev prolazi kroz OmniRoute kompresijski pipeline **transparentno** — bez izmjena na klijentu. To je sada **skup od 12 kompozabilnih engine-a** koji se izvršavaju po redu i kombinuju po routing kombinaciji — nadograđujući ideje iz [RTK](https://github.com/rtk-ai/rtk), [Caveman](https://github.com/JuliusBrussee/caveman) (⭐ 90K+), [LLMLingua-2](https://github.com/microsoft/LLMLingua) i [Troglodita](https://github.com/leninejunior/troglodita) (PT-BR).

### 🎚️ Iznad motora — izlaznih stilova, prilagodljivo biranje i kontrola po zahtjevu

Gornjih 12 motora smanjuju ono što ide **in** . Oblik još tri sloja **kako** ,**kada** , i šta dolazi **van** :

- **🪄 Izlazni stilovi** _(upravljanje izlaznom osovinom)_ — ubaciti determinističke instrukcije za oblikovanje odgovora bezbedne u keš memoriji; mogu se kombinovati, svaki pri `lite` / `full` / `ultra` intenzitetu. Dodavanje stila je unos u registru u jednom redu:
  - **Kratka proza** — drop punilo / artikli / ograda; održavati tačnost tehničke supstance.
  - **Manje koda** — "lazy senior dev" YAGNI: najmanja radna promjena, bez nezatraženih skela.
  - **konjski rep (lijeni stariji dev)** — se popne na YAGNI merdevine, popravi osnovni uzrok, najmanja radna razlika.
  - **Imam ADHD (prva akcija)** — sljedeća radnja vodi, koraci su numerirani, jedan konkretan sljedeći korak, bez preambule.
  - **Terse CJK (文言)** — klasično-kineski ultra šik stil (locale-gated to `zh`).
- **🎯 Prilagodljivi kontekst-budžet** _(brojčanik)_ — umjesto jednog praga on/off tokena, eskalirajte najjeftinije motore bez gubitaka samo onoliko koliko je potrebno za **odgovara prozoru konteksta modela** . Politika: `reserve-output` (zadano, svjestan modela) · `percentage` · `absolute`. Režim: `floor` (garancija odgovara) · `replace-autotrigger` (vaš eksplicitni izbor pobjeđuje) · `off` (naslijeđeni prag).
- **🎛️ Gdje se odlučuje o kompresiji** _(prednost, visok → nizak)_ — po zahtjevu `x-omniroute-compression` zaglavlje › ruting-combo nadjačavanje › aktivni imenovani profil › adaptivni / automatski okidač › panel zadano › isključeno. Primijenjeni plan odjekuje natrag u `X-OmniRoute-Compression: <mode>; source=<source>` zaglavlju odgovora.

Automatsko okidanje prema pragu tokena, okretanje prilagodljivog točkića, zakačenje imenovanog profila, postavljanje jednokratnog po zahtjevu ili dodjela cjevovoda po kombinaciji rutiranja — što god odgovara radnom opterećenju. Opt-in van mreže **eval harness** (`npm run eval:compression`) ocjenjuje vjernost u odnosu na uštedu na zakačenom korpusu prije nego što promovirate promjenu.

## 📦 Više načina instalacije — Docker, izvorni kod, pnpm, Arch

**🐳 Docker**

```bash
docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 \
  -p 127.0.0.1:20128:20128 -v omniroute-data:/app/data diegosouzapw/omniroute:latest
```

`:latest` prati najvišu **objavljenu** stabilnu SemVer verziju. Ne prati git `main`. Fiksirajte `:X.Y.Z` za GitOps. Pogledajte [Docker kanale izdanja](docs/guides/DOCKER_GUIDE.md#release-channels). Slika postavlja **`OMNIROUTE_MEMORY_MB=1024`**. To je dovoljno za kontrolnu ploču i lagani razgovor. **Agenti za programiranje** (`POST /v1/responses` iz Claude Codea, Codexa, Groka, …) zahtijevaju znatno veću V8 gomilu ili će proces prijaviti `FATAL ERROR` na približno 12 GiB pri dva preklapajuća duga konteksta. Dodijelite kontejneru više memorije od veličine gomile (izvorni međuspremnici nalaze se izvan V8):

| Radno opterećenje                    | Gomila (`-e OMNIROUTE_MEMORY_MB`) | Kontejner (`--memory`) |
| ------------------------------------ | --------------------------------- | ---------------------- |
| Kontrolna ploča / lagani razgovor    | `1024` (zadana vrijednost slike)  | ≥2 g                   |
| Jedan agent za programiranje         | `8192`                            | ≥10 g                  |
| Dva istovremena duga `/v1/responses` | `10240`–`12288`                   | ≥12–16 g               |

```bash
docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 \

  -p 127.0.0.1:20128:20128 -v omniroute-data:/app/data diegosouzapw/omniroute:latest
```

**⚡ Brža / jednostavnija instalacija (preskočite izvornu izgradnju)**

vašoj platformi/Nodeu, a u suprotnom neprimjetno prelazi na čisti JS mehanizam
(`node:sqlite` na Nodeu 22+, inače na uključeni `sql.js` WASM) — nisu potrebni alati za izgradnju.

Da biste u potpunosti preskočili **izvorno zagrijavanje** nakon instalacije (CI, sistemi bez grafičkog sučelja ili spori računari).
Napomena: ovime se preskače samo korak zagrijavanja izvornog SQLitea (`scripts/postinstall.mjs`);
skripta za kopiranje/popravku binarne datoteke (`scripts/build/postinstall.mjs`) i dalje se normalno izvršava:

```bash
OMNIROUTE_SKIP_POSTINSTALL=1 npm install -g omniroute   # CI=1 ga također preskače
```

Za najbrže instalacije koristite **pnpm** (spremište adresirano sadržajem + tvrde veze — pogledajte iznad).
Za izvršno okruženje bez kontrolne ploče i grafičkog sučelja koristite Docker profil `base` (iznad) ili
[Termux vodič](docs/guides/TERMUX_GUIDE.md). CLI i web-kontrolnu ploču poslužuje
isti proces na jednom portu, pa trenutno ne postoji zaseban paket samo za CLI.

### Kako doprinijeti

1. Napravite fork repozitorija
2. Kreirajte granu iz vrha **aktivne** grane `release/vX.Y.Z` (ne iz grane `main`) — pogledajte [Model grananja i izdanja](docs/ops/BRANCHING_MODEL.md)
3. Kreirajte svoju granu funkcionalnosti (`git checkout -b feat/amazing-feature`)
4. Commitujte promjene (`git commit -m 'feat: add amazing feature'`)
5. Pošaljite promjene na granu (`git push origin feat/amazing-feature`)
6. Otvorite Pull Request sa **osnovom = tom granom** `release/vX.Y.Z`

Pogledajte [CONTRIBUTING.md](CONTRIBUTING.md) za detaljne smjernice.

### Objavljivanje nove verzije

```bash
# Kreirajte izdanje — npm publish se izvršava automatski
VERSION=x.y.z
gh release create "v${VERSION}" --title "v${VERSION}" --generate-notes
```
