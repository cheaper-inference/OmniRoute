## Kategorije

- **Free** — besplatni nivo sa API ključem (konfigurisano putem dashboard-a)
- **No-auth** — javni endpoint-i koji uopšte ne zahtijevaju ključ ili prijavu
- **OAuth** — proces prijave upravlja OmniRoute, API ključ nije potreban
- **Web cookie** — obavija web aplikaciju provajdera putem cookie autentifikacije
- **API key** — plaćeni provajder konfigurisan putem API ključa (mogu se primijeniti besplatni krediti)
- **Local** — pokreće se na mašini korisnika (Ollama, LM Studio, vLLM, itd.)
- **Search** — provajderi za pretragu weba
- **Audio** — provajderi samo za audio (TTS/STT)
- **Upstream proxy** — provajderi koji proksiraju zahtjeve drugim provajderima
- **Cloud agent** — dugotrajni agenti za kodiranje (Codex Cloud, Devin, Jules)
- **System** — OmniRoute-interni provajderi (loopback, itd.)

Dodatne oznake: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (gdje je prikazano): `native` — pravi API za pozivanje funkcija; `emulated` — `tools` niz je emuliran putem prompta preko `webTools.ts` (regex-parsirani `<tool>{...}</tool>` blokovi); `none` — `tools` se trenutno tiho ignoriše. Pogledajte #7286.

Koristite dashboard na `/dashboard/providers` da omogućite, konfigurišete i testirate svaki provajder.
