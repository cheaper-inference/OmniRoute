## Setup

1. **Run OmniRoute** — `npm install -g omniroute && omniroute` (kontrolna tabla na `http://localhost:20128`).
2. **Instalirajte ekstenziju** — traži "OmniRoute" u prikazu proširenja.
3. **Povežite se** — zadržite zadani `http://localhost:20128` ili postavite svoj server URL i API ključ**OmniRoute: Upravljanje vezom** .
4. **Izaberite model** — Copilot Chat → birač modela →** Upravljajte modelima…** →**OmniRoute** , a zatim označite šta želite.

Za podešavanja veze otvorite**OmniRoute ikona na traci aktivnosti** (ili pokrenite `OmniRoute: Manage Connection`) i postavite:

- **Server URL** — korijen servera, npr. `http://omniroute.example.com:20128`. `/v1` sufiks se dodaje ekstenzijom; nemojte ga uključiti.
- **API key** — je potreban kada ga politika provjere autentičnosti zaključivanja zahtijeva. Čuva se preko VS koda SecretStorage, nikad u `settings.json`; dostupni su ključevi specifični za radni prostor. Koristite ključ ovlašten za modele koje želite izložiti.

Proširenje također pruža indikator veze, osvježavanje modela, kontekst modela i metapodatke o cijenama (uključene kombinacije), strimovano razmišljanje sa** Napor razmišljanja** meni na VS Code 1.120 +, indikator dnevnog ograničenja na statusnoj traci i panel upotrebe (OmniRoute 3.8.50 +), CLI konfiguraciju i opcionu karticu kontrolne table. Odabrani model i politika servera određuju mogućnosti koje možete koristiti.

## Šta će birač prikazati

Ekstenzija ne prikazuje sirovi `GET /v1/models` payload — ona ga oblikuje, a broj koji vidite je manji od veličine kataloga iz dva namjerna razloga.

### Traži jedan ID po modelu

`MODELS_CATALOG_PREFIX_MODE` je po zadanom **`dual`**, što reklamira svaki model dvaput — jednom pod kratkim alias prefiksom i jednom pod kanonskim prefiksom provajdera — tako da starije konfiguracije klijenata nastavljaju razrješavati oba oblika:

```
cc/claude-sonnet-4-6        ← alias prefiks
claude/claude-sonnet-4-6    ← kanonski prefiks, isti model
```

Ekstenzija zahtijeva **`GET /v1/models?prefix=alias`** tako da stiže jedan ID po modelu, bez promjene postavke na razini servera za vaše druge klijente. Na referentnoj instanci ovo je saželo **2345 unosa na 1396 — 949 duplikata, nula izgubljenih modela.**

Ako radije želite to popraviti na razini servera za _svakog_ klijenta, postavite `MODELS_CATALOG_PREFIX_MODE` feature flag na `alias` u kontrolnoj ploči. Pogledajte [API_REFERENCE → prefix](../reference/API_REFERENCE.md#model-id-prefixes-prefix) za parametar upita i tabelu po modovima.

### Skriva modele koji ne mogu chatati

Katalog također navodi modele za slike, video, audio, rerank, embedding i moderaciju. Oni se ionako odbijaju pri zahtjevu za chat:

```
HTTP 400 — Model '<id>' is an image-generation model and cannot be used on
/v1/chat/completions. Use POST /v1/images/generations instead.
```

pa se filtriraju prema njihovom `type` polju prije nego što stignu do birača. **Responses-API modeli su zadržani** — svaki Codex / GPT-5.x unos reklamira `supported_endpoints: ["responses"]`, a OmniRoute ih prevodi za `/v1/chat/completions`, tako da su savršeno upotrebljivi.

### Provajderi koje nikada niste konfigurirali

Katalog navodi modele od provajdera s **aktivnom vezom** _plus_ svakog **noAuth** provajdera — one bez ključa koji čine veći dio besplatnog nivoa. To je namjerno. Da biste ih sakrili, dodajte ih u `blockedProviders` u postavkama kontrolne ploče; ništa se ne mijenja u ekstenziji.

## Kontrolna tabla unutar VS Code kartice

`omnicopilot.dashboardOpen: "editor"` prikazuje OmniRoute kontrolnu tablu u kartici editora putem Simple Browser-a umjesto u eksternom pretraživaču. Ugrađivanje je **opciono na serveru** putem `DASHBOARD_ALLOW_EMBED=vscode`, što servira HTML stranice sa `frame-ancestors 'self' vscode-webview:` umjesto podrazumijevanog `frame-ancestors 'none'` + `X-Frame-Options: DENY`. API površina (`/api`, `/v1`, `/v1beta`, `/a2a`, `/healthz`) zadržava stroga zaglavlja u svakom slučaju.

> ⚠️ **Ovo je flag za vrijeme izgradnje (build-time), a ne za vrijeme izvršavanja (runtime).** Next.js kompajlira `headers()` u manifest rute, tako da `next.config.mjs` čita varijablu dok se bundle gradi (`next.config.mjs` → `resolveDashboardEmbedMode`, `scripts/build/dashboardEmbed.mjs`). Exportovanje iste ispred već izgrađenog servera ne mijenja ništa — zaglavlja su fiksirana.

```bash
# varijabla mora biti prisutna na BUILD komandi
DASHBOARD_ALLOW_EMBED=vscode npm run build        # ili npm run build:release
npm start
```

| Kako ste instalirali       | Možete li omogućiti ugrađivanje?                                                                                                                 |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Iz izvornog koda           | ✅ postavite varijablu na build komandi, kao iznad                                                                                               |
| `npm install -g omniroute` | ❌ objavljeni paket isporučuje već izgrađeni bundle — umjesto toga izgradite iz izvornog koda                                                    |
| Docker slika               | ✅ `docker build --build-arg DASHBOARD_ALLOW_EMBED=vscode -t omniroute:embed .` — već izgrađena slika na Docker Hub-u nema omogućeno ugrađivanje |

Bez build-a sa omogućenim ugrađivanjem, stranica odbija da se prikaže u okviru (frame), ekstenzija to detektuje iz zaglavlja odgovora i vraća se na eksterni pretraživač — ništa se ne kvari, i to se prijavi samo jednom. Pogledajte [`ENVIRONMENT.md`](../reference/ENVIRONMENT.md) i issue [#10273](https://github.com/diegosouzapw/OmniRoute/issues/10273).

## Konfiguriranje vaših ostalih alata iz VS koda

**`OmniRoute: Configure Coding CLI`** pokreće `omniroute` CLI za pisanje profila spremnih za upotrebu za 16 alata: Codex CLI, Claude Code, Cline, Continue, Cursor, Aider, OpenCode, Goose, Crush, Qwen Code, Kilo, Roo, Gemini CLI, Zed, WhyCodes i 5. Proširenje poziva `setup-*` komande u integriranom terminalu; instalirajte verziju OmniRoute CLI koja uključuje odabranu naredbu. Pogledajte [vodič za integraciju CLI](CLI-INTEGRATIONS.md) za datoteke i oznake koje svaki recept koristi i [registar alata ekstenzije](https://github.com/cheaper-inference/OmniCopilot/blob/main/src/cliBridge.ts).

Ključ API se predaje CLI preko `OMNIROUTE_API_KEY`, nikada na komandnoj liniji. Recepti za postavljanje mogu zadržati vjerodajnice u konfiguraciji ciljnog alata. Prilikom dijeljenja ključa specifičnog za radni prostor s konfiguracijom na korisničkom nivou alata, ekstenzija prvo traži potvrdu.

## Rješavanje problema

| Simptom                                                       | Uzrok / popravak                                                                                                                                                                                                                                                       |
| ------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Nema OmniRoute modela u biraču                                | Server nedostupan. Tačka statusne trake postaje siva; run `OmniRoute: Check Connection`. Discovery je tih po dizajnu i ne doprinosi modelima, a ne podsjetnicima.                                                                                                      |
| Svaki model se pojavljuje dva puta                            | Vi ste na OmniCopilot starijoj od 1.0.1 — ažuriranju. Ekstenzija sada zahtijeva `?prefix=alias`.                                                                                                                                                                       |
| image/audio model je bio na listi i nestao je                 | Namjerno od 1.0.1 — nikada nije mogao odgovoriti na zahtjev za ćaskanje.                                                                                                                                                                                               |
| Nedostaje ploča na traci aktivnosti                           | VS Code pomiče dodatne kontejnere pogleda u** "…"** prelivaju na dnu trake aktivnosti, a kontejner skriven desnim klikom ostaje skriven. Kliknite desnim tasterom miša na kvačicu Traka aktivnosti →**OmniRoute** , ili ga otvorite sa `OmniRoute: Manage Connection`. |
| Kontrolna tabla se otvara u pretraživaču uprkos `editor` modu | Server nije bio** izgrađen** sa `DASHBOARD_ALLOW_EMBED=vscode` (vidi gore) — postavljanjem pri pokretanju na unaprijed izgrađenoj instalaciji ne radi ništa. Zamjena je namjerna.                                                                                      |
| Lista modela je zastarjela nakon promjene provajdera          | `OmniRoute: Refresh Models` ili ↻ link na panelu.                                                                                                                                                                                                                      |
| Na ploči piše _Online (modeli blokirani)_, birač je prazan    | Server odbija ključ. Sačuvajte desni ključ sa** Sačuvaj i testiraj** . Ako je ključ umjesto toga fiksiran na serveru (omogućen ili dat pristup modelima), ekstenzija ne primjećuje sama po sebi: pokrenite `OmniRoute: Refresh Models` ili otvorite OmniRoute panel.   |
