# OpenCode v2 dodatak — instalacija i konfiguracija

`@omniroute/opencode-plugin-v2` postavlja vaš cijeli OmniRoute katalog — modele, kombinacije (combos) i automatske kombinacije (auto-combos) — u OpenCode v2 birač modela, sa prikazanim imenima, cijenama i budžetima za besplatni nivo.

Ovo je zaseban paket od `@omniroute/opencode-plugin` jer OpenCode v1 i v2 učitavaju dodatke kroz različite ugovore. Odaberite onaj koji odgovara vašoj OpenCode glavnoj verziji; ništa se ne dijeli između njih, tako da nadogradnja jednog nikada ne prisiljava nadogradnju drugog.

## Zahtjevi

- OpenCode v2.
- Dostupan OmniRoute gateway (`http://localhost:20128` po zadanim postavkama).
- Node.js 22 ili 24.

## Instalacija

Dodajte dodatak u `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

Modeli se tada pojavljuju kao `omniroute/<provider>/<model>`; `providerId` određuje taj prefiks i ID integracije pod kojim OpenCode pohranjuje vjerodajnice.

## Vjerodajnice

Dodatak traži ključ gateway-a na tri mjesta, ovim redoslijedom:

1. **Vjerodajnice koje ste povezali u OpenCode-u.** Dodatak registruje integraciju, tako da OpenCode-ov vlastiti proces autentifikacije može pohraniti ključ. Ništa ne završava u `opencode.json` — ovo je preporučeni način.
2. `apiKey` u opcijama dodatka, za nadjačavanje po projektu. Ovo postavlja ključ u datoteku koju možda commit-ujete.
3. `OMNIROUTE_API_KEY` u okruženju.

Ako nijedno od ovo troje nije prisutno, katalog je prazan i dodatak to javlja jednom prilikom pokretanja umjesto da vas ostavi sa tihim, praznim biračem.

### Upravljački token (management token) je drugačiji ključ

Kombinacije, zdravlje provajdera i obogaćivanje (prikazana imena, cijene, budžeti za besplatni nivo) dolaze sa `/api/*` krajnjih tačaka (endpoints) gateway-a, koje većina implementacija štiti **upravljačkim** (management) tokenom umjesto ključem za zaključivanje (inference key):

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<management read token>"
}
```

Ako nije postavljen, `managementReadToken` se vraća na `apiKey`. Kada gateway odbije taj rezervni ključ, katalog se i dalje objavljuje, ali sa sirovim ID-ovima modela umjesto prikazanih imena, bez deduplikacije kanonskih aliasa, bez cijena i bez kombinacija. Dodatak upozorava jednom po krajnjoj tački kada se to dogodi, navodeći krajnju tačku i šta je izgubljeno — tako da degradirani birač nikada nije misterija.

## Opcije

| -------------------------------- | ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `providerId`                     | `"omniroute"`                                  | ID provajdera, ID integracije i prefiks pod kojim se modeli pojavljuju                                                                                                                                                                                                                                                                                                                                 |
| `baseURL`                        | required                                       | Korijen gatewaya, samo `http(s)`; sufiks `/v1` se dodaje gdje je potrebno                                                                                                                                                                                                                                                                                                                              |

| `managementReadToken`            | falls back to `apiKey`                         | Ključ za `/api/*` — obično **nije isti**                                                                                                                                                                                                                                                                                                                                                               |
| `displayName`                    | `"OmniRoute"`                                  | Naziv provajdera u biraču                                                                                                                                                                                                                                                                                                                                                                              |
| `timeoutMs`                      | `10000`                                        | Vremensko ograničenje dohvaćanja po krajnjoj tački (automatske kombinacije koriste 5 s)                                                                                                                                                                                                                                                                                                                |

| `freshWindowDays`                | `90`                                           | Vremenski prozor svježine u danima za granu svježih stavki                                                                                                                                                                                                                                                                                                                                             |
| `usageMemory`                    | `true`                                         | Vraća statički uklonjene stavke imenovane analitikom korištenja za 30 dana (zahtijeva token za upravljanje)                                                                                                                                                                                                                                                                                            |

## Kako katalog ostaje ažuran

Katalog se dohvaća lijeno i kešira za `modelCacheTtlMs`, a snimak na disku održava
posljednji poznati katalog dostupnim kada gateway nije dostupan — prekid rada vas košta samo
svježine. Modeli i kombinacije objavljuju se čim stignu; automatske kombinacije, lista
pružalaca i sloj obogaćivanja uključuju se čim stignu, tako da jedna spora krajnja tačka ne
može zadržati cijeli birač.

Nazivi slijede format `Provider - Model[ (Editor)][ · budget][ (route)]`: pružalac se prikazuje
kad god ga ID sadrži (ID bez kose crte prikazuje se bez prefiksa), vodeći znak `🆓` označava
besplatne unose, a njihov budžet besplatnog nivoa ostaje kao sufiks `· 1M tokens/month`, editor
eksplicitnog naziva `Editor: Model` premješta se u završne zagrade (editor se ne pretpostavlja
na osnovu drugih naziva), a kombinacije se prikazuju kao `combo - <slug>` bez ikone za
besplatno. Dva unosa koji imaju isti naziv dobijaju sufiks rute — `(no-think)` — kako bi ostali
razlikovani. `providerTag` (zadano `true`) uključuje završne zagrade editora.

Ne postoji naredba za ručno osvježavanje: OpenCode v2 naredbe su predlošci upita, a ne povratni
pozivi, pa ih dodatak ne može izložiti. Osvježavanja prate TTL; od hosta se traži ponovno
učitavanje samo kada su se katalog ili sloj zaista promijenili, nikada jednom po osvježavanju.

## Pozivanje alata na Gemini

Gemini odbija cijeli zahtjev čije deklaracije alata sadrže `$schema` ili `additionalProperties`, odgovarajući sa `400 INVALID_ARGUMENT`. Dodatak uklanja te ključne riječi iz šema alata namijenjenih Gemini modelu ovog provajdera i ostavlja svaki drugi zahtjev netaknutim. Alat koji sadrži `$ref` se prosljeđuje netaknut umjesto da se ukloni, jer bi uklanjanje reference proširilo šemu na "prihvati bilo šta".
Postavite `"geminiSanitization": false` da biste to isključili.

## Otklanjanje problema

| Simptom                                        | Uzrok                                                                                                                            |
| ---------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| Birač ne prikazuje nijedan OmniRoute model     | Ključ nije razriješen (provjerite upozorenje pri pokretanju) ili gateway nije dostupan                                           |
| Sirovi ID-ovi modela, bez kombinacija i cijena | Upravljačke krajnje tačke odbile su token — postavite `managementReadToken`                                                      |
| Kratak ili prazan katalog `freeOnly`           | Nema upravljačkog tokena ili je token odbijen — pročitajte red sa sažetkom osvježavanja (broj `unmatched-free`) u dnevniku hosta |
| Sesija vezana za `opencode-<id>/...`           | Dodatak v1 objavio je `opencode-<id>`; v2 objavljuje samo `<id>`, zato ponovo odaberite model pod `<id>/...`                     |

Varijable okruženja moraju doseći proces servera opencode: kada host
radi kao servis, ljuska u kojoj se pokreće `opencode models` i okruženje servera
se razlikuju, zato izvezite ključ tamo gdje ga server čita.
