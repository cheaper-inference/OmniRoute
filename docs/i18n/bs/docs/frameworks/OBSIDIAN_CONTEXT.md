# Obsidian Context Source

> **Izvor istine:** `src/lib/obsidian/api.ts` (REST + sync klijent),
> `src/lib/db/obsidian.ts` (token / base-URL / WebDAV perzistencija),
> `src/lib/obsidianSync.ts` (WebDAV sinhronizacija trezora), `open-sse/mcp-server/tools/obsidianTools.ts`
> (22 MCP alata), `src/app/api/settings/obsidian/route.ts` +
> `src/app/api/settings/obsidian/webdav/route.ts` (API-ji za postavke). Registracija alata
> i povezivanje opsega se nalazi u `open-sse/mcp-server/server.ts`.

## Šta je to

OmniRoute se povezuje na **Obsidian** trezor kao **izvor konteksta** — lokalnu Markdown
bazu znanja koju agenti čitaju i pišu putem ugrađenog MCP servera.
Integracija komunicira sa **Obsidian Local REST API** zajedničkim dodatkom koji radi unutar
desktop aplikacije, tako da agenti mogu pretraživati bilješke, čitati/pisati/ažurirati datoteke, izlistati trezor, raditi sa dnevnim/sedmičnim periodičnim bilješkama, upravljati oznakama, pokretati Obsidian komande i (opciono) koordinirati dvosmjernu desktop↔mobilnu sinhronizaciju trezora.

Klijent (`src/lib/obsidian/api.ts`) obavija Local REST API sa:

- **Ponovnim pokušajem sa odgodom (backoff)** za prolazne `5xx` greške, **30-sekundni timeout** putem `AbortController`.
- **Tipiziranom klasifikacijom grešaka** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`.
- **Prijateljskim savjetom "ne mogu pristupiti Obsidianu"** koji ukazuje na čestu grešku sa portom
  (HTTP na `27123`, **ne** MCP krajnja tačka na `27124`) i Tailscale formu.
- Relativnim **kodiranjem putanje** trezora tako da su putanje bilješki sa razmacima/kosim crtama sigurne.

## Podešavanje

Ne postoji **varijabla okruženja** za Obsidian token ili osnovni URL — oboje se
čuvaju u SQLite tabeli `key_value` (imenski prostor `obsidian`) putem
`src/lib/db/obsidian.ts`. Token je **šifriran u stanju mirovanja** (AES-256-GCM, uz
rezervnu podršku za običan tekst radi kompatibilnosti unazad). Konfigurišite putem kartice **Context Sources** na
Endpoint nadzornoj ploči (`ObsidianSourceCard`) ili putem REST API-ja za postavke.

> [!IMPORTANT]
> Dodatak **Obsidian Local REST API** mora biti instaliran i pokrenut. Njegovo REST
> sučelje sluša na **HTTP `127.0.0.1:27123`** (zadani osnovni URL). Port `27124`
> je _zasebna_ MCP/HTTPS krajnja tačka i ruta za postavke ga izričito odbija.
> Ako se povezujete s drugog uređaja, koristite `http://<tailscale-ip>:27123`.

### Konfiguracijski ključevi (SQLite `key_value`, imenski prostor `obsidian`)

| Ključ             | Namjena                                                      | Šifrirano |
| ----------------- | ------------------------------------------------------------ | --------- |
| `api_key`         | Bearer token lokalnog REST API-ja                            | da        |
| `base_url`        | Osnovni REST URL (zadano `http://127.0.0.1:27123`)           | ne        |
| `vault_path`      | Apsolutna putanja do direktorija trezora (za sinhronizaciju) | ne        |
| `webdav_username` | Generisano WebDAV korisničko ime (sinhronizacija trezora)    | ne        |
| `webdav_password` | Generisana WebDAV lozinka (sinhronizacija trezora)           | da        |
| `webdav_enabled`  | Da li je omogućena WebDAV sinhronizacija trezora             | ne        |

### Konfiguracija putem REST-a

```bash
# Sačuvajte i provjerite token lokalnog REST API-ja (POST ga provjerava putem provjere statusa)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# Provjerite status veze (vraća connected, hasToken, baseUrl, vaultPath)
curl http://localhost:20128/api/settings/obsidian

# Prekinite vezu (briše sačuvani token)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

Sve metode zahtijevaju autentifikaciju na nadzornoj ploči. `POST` odbija svaki URL na portu `27124`
i provjerava token pozivanjem statusne krajnje tačke lokalnog REST API-ja prije pohranjivanja.

### WebDAV sinhronizacija trezora

`src/app/api/settings/obsidian/webdav/route.ts` upravlja opcionalnom sinhronizacijom
trezora podržanom WebDAV-om (koju pokreće `src/lib/obsidianSync.ts`). Omogućavanjem se OmniRoute usmjerava na
lokalni direktorij trezora i generiše se nasumični par WebDAV korisničkog imena i lozinke:

```bash
# Omogućite WebDAV sinhronizaciju za direktorij trezora (generiše korisničko ime/lozinku)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# Dohvatite status WebDAV sinhronizacije (pristupni podaci se vraćaju samo dok je omogućena)
curl http://localhost:20128/api/settings/obsidian/webdav

# Onemogućite WebDAV sinhronizaciju (briše pristupne podatke i upravljani .stignore)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### Sigurnost i transport

WebDAV autentikacija nameće praćenje neuspjeha po IP-u i zaključavanje (10 neuspjelih pokušaja unutar prozora od 60 sekundi pokreće 5-minutno zaključavanje sa `429 Too Many Requests` i `Retry-After`). Budući da WebDAV prenosi vjerodajnice za osnovnu provjeru autentičnosti, ukidanje TLS (ili usmjeravanje preko sigurnog tunela kao što je Tailscale ili Cloudflare Tunnel) se snažno preporučuje kada se pristupa WebDAV krajnjoj točki izvan povratne petlje.

### Izvor konteksta po API ključu (opcionalno)

Obsidian konfiguracija može biti ograničena **po API ključu** putem tabele `api_key_context_sources`
(`src/lib/db/apiKeyContextSources.ts`). Kada MCP poziv sadrži ID autentificiranog API
ključa, `getObsidianConfigForApiKey()` daje prednost tokenu/osnovnom URL-u/putanji trezora tog ključa
(`source: "api_key"`), a u suprotnom se vraća na globalnu konfiguraciju (`source: "global"`).

MCP alati koji nisu namijenjeni sinhronizaciji zahtijevaju razriješen identitet pozivaoca prije čitanja ove konfiguracije.
Pozivalac bez identiteta dobija `Obsidian API token not configured`, a zahtjev prema trezoru
se ne šalje. HTTP pozivaoci razrješavaju identitet putem svojih pristupnih podataka iz zahtjeva; stdio pozivaoci
ga mogu razriješiti putem `OMNIROUTE_API_KEY` ili `ROUTER_API_KEY`. Nerazriješeni HTTP pozivalac
ne može naslijediti identitet okruženja servera. Sami ID-ovi rezerviranih oznaka ne odobravaju
pristup; i dalje je podržan važeći pristupni podatak iz okruženja koji se razrješava kao `env-key`.
Autentificirani ključevi bez Obsidian konfiguracije po ključu zadržavaju globalnu rezervnu konfiguraciju.
Četiri alata `obsidian_sync_*` zadržavaju svoje zasebno ponašanje tokena za sinhronizaciju.

## MCP alati (22)

Definirano u `open-sse/mcp-server/tools/obsidianTools.ts`. token/base-URL se rješavaju po pozivu (prvo po API ključu, a zatim globalno). Alati koji pogađaju OmniRoute** server za sinhronizaciju** (četiri `obsidian_sync_*` alata) dodatno zahtijevaju sync auth token konfiguriran u postavkama OmniRoute.

### Alati za čitanje (`read:obsidian`)

| Alat                         | Opis                                                                                                   |
| ---------------------------- | ------------------------------------------------------------------------------------------------------ |
| `obsidian_check_status`      | Provjerite da li je lokalni REST API dostupan i autentificiran.                                        |
| `obsidian_search_simple`     | Pretraživanje sadržaja bilješke po cijelom tekstu; vraća isječke sa putanjama datoteke.                |
| `obsidian_search_structured` | Pretražujte koristeći JSON logički izraz (and/or/regex/path filteri).                                  |
| `obsidian_read_note`         | Pročitajte bilješku po putanji u odnosu na trezor; opciono određeni heading/block/frontmatter.         |
| `obsidian_list_vault`        | Lista datoteka i direktorija u trezoru (stablo unosa).                                                 |
| `obsidian_get_document_map`  | Dobijte strukturu naslova bilješke kao mapu brojeva → naslova.                                         |
| `obsidian_get_note_metadata` | Nabavite frontmatter, oznake, linkove, char/word count bez punog sadržaja.                             |
| `obsidian_get_active_file`   | Dobijte putanju + sadržaja trenutno aktivne datoteke u Obsidian.                                       |
| `obsidian_get_periodic_note` | Dobijte daily/weekly/monthly periodičnu bilješku za datum (danas ako se izostavi).                     |
| `obsidian_get_tags`          | Navedite sve oznake trezora sa njihovim frekvencijama.                                                 |
| `obsidian_list_commands`     | Navedite dostupnu Obsidian naredbu IDs (koristite sa `obsidian_execute_command`).                      |
| `obsidian_sync_status`       | Status OmniRoute sync servera: pokrenut, naziv trezora, port, vrijeme rada, posljednja sinhronizacija. |
| `obsidian_sync_conflicts`    | Navedite neriješene sukobe sinhronizacije (put, putanja sukoba, otkriveno-na).                         |

### Alati za pisanje (`write:obsidian`)

| Alat                             | Opis                                                                                           |
| -------------------------------- | ---------------------------------------------------------------------------------------------- |
| `obsidian_write_note`            | Kreirajte ili prepišite bilješku sa datim sadržajem Markdowna.                                 |
| `obsidian_append_note`           | Dodavanje sadržaja u bilješku; opciono na određeni heading/block.                              |
| `obsidian_patch_note`            | Hirurški append/prepend/replace u smjeru, bloku ili frontmatter polju.                         |
| `obsidian_delete_note`           | Trajno obrišite bilješku iz trezora.                                                           |
| `obsidian_move_note`             | Premjestite ili preimenujte bilješku unutar trezora.                                           |
| `obsidian_execute_command`       | Izvršite naredbu Obsidian pomoću njene naredbe ID.                                             |
| `obsidian_open_file`             | Otvorite datoteku u Obsidian (kreira je ako ne postoji).                                       |
| `obsidian_sync_trigger`          | Aktivirajte trenutnu dvosmjernu sinhronizaciju ↔ mobilnog trezora radne površine.              |
| `obsidian_sync_resolve_conflict` | Riješite sukob sinhronizacije: zadržite `local` (mobilni), `remote` (desktop) ili `keep-both`. |

> [!NOTE]
> `obsidian_patch_note` ciljevi prihvataju `targetType` od `heading | block | frontmatter` i `operation` od `append | prepend | replace`, sa opcionim `createTargetIfMissing`. Četiri `obsidian_sync_*` alata razgovaraju s lokalnim serverom za sinhronizaciju (`http://127.0.0.1:27781` po defaultu) i zahtijevaju token za sinhronizaciju.

### Opsegovi

Alati za čitanje zahtijevaju `read:obsidian`; alati za pisanje zahtijevaju `write:obsidian`. Sprovođenje je identično Notion — kojim rukuje `withScopeEnforcement()` u `open-sse/mcp-server/server.ts`, zatvoreno na `OMNIROUTE_MCP_ENFORCE_SCOPES=true` i prisilno uključeno za HTTP/SSE pozivaoce čiji API ključ nema `manage`/`admin`, sa dozvoljenim opsegom koji potiče iz `OMNIROUTE_MCP_SCOPES` ili konteksta opsega API ključa. Vidi [MCP-SERVER.md](./MCP-SERVER.md).

## Krajnje tačke

| Metoda   | Putanja                         | Svrha                                                           |
| -------- | ------------------------------- | --------------------------------------------------------------- |
| `GET`    | `/api/settings/obsidian`        | Vraća `{ connected, hasToken, baseUrl, vaultPath }`.            |
| `POST`   | `/api/settings/obsidian`        | Spremi + validiraj token (odbija port `27124`).                 |
| `DELETE` | `/api/settings/obsidian`        | Prekini vezu (briše pohranjeni token).                          |
| `GET`    | `/api/settings/obsidian/webdav` | Status WebDAV sinhronizacije + vjerodajnice (dok je omogućeno). |
| `POST`   | `/api/settings/obsidian/webdav` | Omogući WebDAV sinhronizaciju za direktorij trezora.            |
| `DELETE` | `/api/settings/obsidian/webdav` | Onemogući WebDAV sinhronizaciju.                                |

> Ovo su rute za postavke kontrolne ploče. Samom trezoru se pristupa putem Obsidian Local REST API-ja (konfigurisani `base_url`) i putem MCP alata iznad — ne postoji javna `/v1` Obsidian proxy krajnja tačka.

## Slučajevi upotrebe

- **Odgovori utemeljeni na trezoru** — `obsidian_search_simple` / `obsidian_search_structured`
  zatim `obsidian_read_note` kako bi agent odgovarao na osnovu vaših stvarnih bilješki.
- **Pisanje bilješki / vođenje dnevnika** — `obsidian_write_note`, `obsidian_append_note`, ili
  hirurški precizan `obsidian_patch_note` za bilježenje izlaza agenta, sažetaka ili dnevnih bilješki
  (`obsidian_get_periodic_note`) u trezor.
- **Navigacija kroz trezor** — `obsidian_list_vault`, `obsidian_get_document_map`, i
  `obsidian_get_tags` za istraživanje strukture prije čitanja/pisanja.
- **Obsidian automatizacija** — `obsidian_list_commands` + `obsidian_execute_command` za
  upravljanje dodacima/komandama od strane agenta; `obsidian_open_file` za prikaz bilješke u korisničkom interfejsu.
- **Mobilna sinhronizacija** — omogućite WebDAV sinhronizaciju, zatim `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`
  za koordinaciju desktop↔mobilni uređaj i rješavanje konflikata.
