> Scoránaigh ama rite a athraíonn iompar OmniRoute **gan ath-imscaradh**.
> Sainmhínítear gach bratach atá liostaithe anseo in
> [`src/shared/constants/featureFlagDefinitions.ts`](../../src/shared/constants/featureFlagDefinitions.ts)
> — an t-aon fhoinse fhírinne. Léann an deais agus an REST API araon ón
> gcomhad sin, mar sin gintear an tábla thíos chun é a mheaitseáil 1:1.

---

## Cad is Bratacha Gné ann

Is éard is bratach gné ann ná scorán ainmnithe (booleach nó enum) ar féidir a luach a athrú ag
am rite agus a bhuanú sa bhunachar sonraí, gan gá le hath-imscaradh próisis. Déantar cur síos ar gach
bratach le `FeatureFlagDefinition` ina bhfuil `key`, `label`,
`description`, `category`, `defaultValue`, `type`, agus leid `requiresRestart`.

### Ord Réitigh

Réitíonn
[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) **luach éifeachtach** brataí de réir na
tosaíochta seo (is ag an gceann is airde atá an bua):

1. **Sárú DB** — luach atá stóráilte sa tábla `key_value` faoin
   ainmspás `feature_flags` (socraithe tríd an deais nó an REST API).
2. **Athróg timpeallachta** — `process.env[<KEY>]`, má tá sí socraithe agus neamhfholamh.
3. **Réamhshocrú sainmhínithe** — an `defaultValue` ó `featureFlagDefinitions.ts`.

Meastar bratach bhooleach a bheith **cumasaithe** nuair is é `"true"`,
`"1"`, nó `"yes"` a luach éifeachtach (féach `isFeatureFlagEnabled()`).

> [!NOTE]
> Tá athróg timpeallachta mheaitseála den **ainm céanna** ag formhór na mbratach freisin,
> mar atá doiciméadaithe in [`ENVIRONMENT.md`](./ENVIRONMENT.md). Bíonn tosaíocht ag sárú DB na brataí
> ar an athróg timpeallachta sin. Déantar bratach a bhfuil
> `requiresRestart: true` aici a bhuanú láithreach ach ní athléitear í ach amháin ag am
> tosaithe an phróisis — má scorthaítear í, taispeántar meirge **"Atosaigh an Freastalaí"** sa deais.

## Bratacha a Scoránú

### Painéal

Téigh chuig **Painéal → Socruithe → Bratacha Gnéithe**
(`/dashboard/settings/feature-flags`). Tacaíonn an eangach
(`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`)
leis na nithe seo a leanas:

- **Cuardach** de réir eochair nó tuairisce, agus **scagadh** de réir catagóire (chomh maith le hamharc sintéiseach
  **Atosú Riachtanach**).
- **Scorán** do bhratacha Boole agus **roghchlár anuas** do bhratacha enum
  (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`).
- Suaitheantas **foinse** in aghaidh na brataí — `DB`, `ENV`, nó `DEF` — a thaispeánann cá bhfuarthas an luach éifeachtach.
- Cnaipe **Athshocraigh** (a thaispeántar do bhratacha a bhfuil foinse `DB` acu amháin) chun an sáraíocht a bhaint, agus cnaipe **Athshocraigh Gach Sáraíocht** ag an mbun.
- Meirge **Atosaigh an Freastalaí** nuair a athraítear bratach `requiresRestart`.

### API REST

Déantar gach oibríocht trí bhealach aonair:
[`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts).
Éilíonn gach modh seisiún fíordheimhnithe painéil (`401` murach sin).

#### `GET /api/settings/feature-flags`

Seolann sé gach bratach ar ais lena luach éifeachtach, foinse agus achoimre.

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Require API Key",
      "description": "Require an API key for all incoming requests",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... all 116 flags
  ],
  "summary": {
    "total": 116,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

Socraigh nó bain sáraíocht aonair. Corp: `{ key: string; value?: string }`.
Má fhágtar `value` ar lár, baintear an sáraíocht (agus athchóirítear env / réamhshocrú).

```bash
# Socraigh sáraíocht DB
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# Bain an sáraíocht (gan "value")
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

Macallaíonn an freagra an `effectiveValue`/`source` nua, an
`previousValue`/`previousSource`, agus `requiresRestart`. Diúltaítear eochracha anaithnide agus luachanna enum lasmuigh den raon le `400`.

#### `DELETE /api/settings/feature-flags`

Glanann sé **gach** sáraíocht DB láithreach, agus athchóirítear gach bratach chuig a luach env / réamhshocraithe. Seolann sé `{ cleared: <count>, message: "..." }` ar ais.

> [!NOTE]
> Ní chuirtear bratacha a bhfuil `requiresRestart: true` acu i bhfeidhm go dtí go n-athlódáiltear próiseas.
> Glaonn sreabhadh atosaithe an phainéil ar `POST /api/restart` agus ansin déanann sé pobalbhreith ar `GET /api/health/ping` go dtí go mbeidh an freastalaí ar ais ar bun.

## Cúltaca Éigeandála don Bhuiséad

Rialaíonn `OMNIROUTE_EMERGENCY_FALLBACK` (catagóir `runtime`, réamhshocrú `true`) an
chúlbhealach éigeandála saor in aisce in
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts).
Nuair atá sé cumasaithe, seoltar iarratais a bhfuil a mbuiséad ídithe acu chuig
soláthraí/samhail chúltaca saor in aisce in ionad teip iomlán. Socraigh é mar
`false` (nó `0`) — trí scorán an deais, sárú sa bhunachar sonraí, nó an athróg
timpeallachta `OMNIROUTE_EMERGENCY_FALLBACK` — chun an t-iompar seo a dhíchumasú
agus ligean d’iarratais a bhfuil a mbuiséad ídithe acu teip. (Léiríodh é mar
scorán deais in PRanna #3741 / #3752.)

Bíonn an ceanntásc
`X-OmniRoute-Emergency-Fallback: from=<provider/model>; to=<provider/model>` ar
fhreagra a sheachadtar tríd an gcúltaca seo, ionas gur féidir le cliant a
aithint gur atreoraíodh é gan `X-OmniRoute-Provider` a chur i gcomparáid lena
iarratas. Ní bhíonn an ceanntásc i láthair ar aon fhreagra eile.
