## Comhlánuithe Comhrá

```bash
POST /v1/chat/completions
Authorization: Bearer your-api-key
Content-Type: application/json

{
  "model": "cc/claude-opus-4-6",
  "messages": [
    {"role": "user", "content": "Write a function to..."}
  ],
  "stream": true
}
```

### Ceanntásca Saincheaptha

| Ceanntásc                | Treo      | Cur Síos                                                                                                                                                                                                                                                                              |
| ------------------------ | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| `x-omniroute-no-memory`  | Iarratas  | Socraigh go `true` é chun instealladh cuimhne + scileanna a scipeáil don iarratas seo (is ionann é agus gan taisce; seachnaíonn sé forchostas comharthaí/costais in aghaidh an ghlao)                                                                                                 |
| `X-OmniRoute-Progress`   | Iarratas  | Socraigh go `true` é le haghaidh teagmhais dul chun cinn                                                                                                                                                                                                                              |
| `X-Session-Id`           | Iarratas  | Eochair seisiúin ghreamaitheach le haghaidh cleamhnas seisiúin seachtrach                                                                                                                                                                                                             |
| `x_session_id`           | Iarratas  | Glactar leis an leagan le fostríoc freisin (HTTP díreach)                                                                                                                                                                                                                             |
| `X-OmniRoute-Session-Id` | Iarratas  | Clib seisiúin/comhrá arna soláthar ag an nglaoiteoir (cuireann sí leis an gcuimhne freisin). Nuair atá sí i láthair, déantar í a bhuanú focal ar fhocal in `call_logs.session_tag` chun costas a shannadh de réir seisiúin (#8249) — ní shintéisítear í riamh nuair atá sí as láthair |
| `Idempotency-Key`        | Iarratas  | Eochair dhí-dhúblála (fuinneog 5 shoicind)                                                                                                                                                                                                                                            |
| `X-Request-Id`           | Iarratas  | Eochair mhalartach dhí-dhúblála                                                                                                                                                                                                                                                       |
| `x-omniroute-connection` | Iarratas  | Ceangail iarratas aon-samhla le nasc soláthraí amháin (cuntas) de réir a aitheantais — féach [Cuntas a phionnáil de réir iarratais](#account-pinning-per-request)                                                                                                                     |
| `X-OmniRoute-Cache`      | Freagairt | `HIT` nó `MISS` (neamhshruthaithe)                                                                                                                                                                                                                                                    |
| `X-OmniRoute-Idempotent` | Freagairt | `true` má dí-dhúblaíodh é                                                                                                                                                                                                                                                             |
| `X-OmniRoute-Progress`   | Freagairt | `enabled` má tá rianú dul chun cinn ar siúl                                                                                                                                                                                                                                           |
| `X-OmniRoute-Session-Id` | Freagairt | ID éifeachtach an tseisiúin a d’úsáid OmniRoute                                                                                                                                                                                                                                       |
| `X-OmniRoute-Request-Id` | Freagairt | ID comhghaolúcháin an iarratais (nuair is eol é)                                                                                                                                                                                                                                      |
| `X-OmniRoute-Version`    | Freagairt | Leagan tiomsaithe OmniRoute (i láthair i gcónaí)                                                                                                                                                                                                                                      |
| `X-OmniRoute-Cost-Saved` | Freagairt | An méid USD a sábháladh leis an taisce ar `HIT` (amasanna taisce amháin)                                                                                                                                                                                                              |
| `X-OmniRoute-Decision`   | Freagairt | Rian ródúcháin: `strategy=<name>; provider=<alias>; latency_ms=<n>` (is é `<name>` straitéis an teaglama, nó `single` d’iarratas nach teaglama é) — i láthair i gcónaí ar fhreagairtí críochnaithe                                                                                    |

#### Cuntas a phionnáil in aghaidh na hiarrata

Nuair a bhíonn roinnt nasc (cuntas nó eochair) ag soláthraí, roghnaíonn OmniRoute ceann amháin de ghnáth
trína straitéis roghnúcháin cuntais. Ina ionad sin, is féidir le hiarraidh nasc sonrach amháin a phionnáil
leis an gceannteideal `x-omniroute-connection`:

```bash
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <your OmniRoute API key>" \
  -H "Content-Type: application/json" \
  -H "x-omniroute-connection: <connection id>" \
  -d '{"model": "codex/gpt-5.5", "messages": [{"role": "user", "content": "hi"}]}'
```

- **Cá bhfaightear an t-aitheantas.** Oscail leathanach an tsoláthraí sa phainéal
  (**Painéal → Soláthraithe → <provider>**) agus cliceáil an tslis aitheantais `xxxxxxxx…` ar ró naisc
  — cóipeálann sí aitheantas iomlán an naisc.
- **Cé na hiarrataí a thugann aird air.** Iarrataí aon mhúnla (`provider/model`) ar
  `/v1/chat/completions`, `/v1/messages` agus `/v1/responses`. Déanann teaglamaí neamhaird den cheannteideal: ina ionad sin,
  pionnáil cuntas do gach céim den teaglaim trí nasc na céime féin.
- **Tá an phionnáil docht, ní rogha thosaíochta í.** Úsáidtear an nasc pionnáilte amháin. I gcás
  teipe laistigh den iarraidh, taifeadtar tréimhse fuaraithe an chuntais ach **ní** aistrítear chuig
  cuntas eile de chuid an tsoláthraí chéanna.
- **Scaoileann fuarú agus cuóta an phionnáil.** Fad atá an nasc pionnáilte ag fuarú,
  a chuóta ídithe nó é blocáilte ag polasaí cuóta, filleann iarrataí ina dhiaidh sin ar naisc
  eile an tsoláthraí, díreach mar a dhéantar le trácht gan phionnáil.
- **Teipeann ar aitheantais anaithnide nó díchumasaithe.** Mura bhfuil aitheantas i linn ghníomhach an tsoláthraí (scriosta,
  díghníomhachtaithe, nó bainteach le soláthraí eile), ní bhíonn aon chuntas incháilithe fágtha, mar sin teipeann
  ar an iarraidh seachas í a ródú go háit eile go ciúin.

Seolann Claude Code ceanntásca saincheaptha trí `ANTHROPIC_CUSTOM_HEADERS`. Cuir é sa bhloc `env`
de `~/.claude/settings.json`, nó i `.claude/settings.json` ar leibhéal an tionscadail chun cuntas difriúil
a phionnáil do gach tionscadal:

```jsonc
{
  "env": {
    "ANTHROPIC_BASE_URL": "http://<your OmniRoute>:20128",
    "ANTHROPIC_AUTH_TOKEN": "<your OmniRoute API key>",
    "ANTHROPIC_CUSTOM_HEADERS": "x-omniroute-connection: <connection id>",
  },
}
```

Foinse: `src/sse/handlers/chat.ts` (léamh an cheanntásca), `src/sse/services/auth.ts` agus
`src/sse/services/sessionAffinityPin.ts` (scaoileadh na pionnála agus an tseiceáil nach bhfuil sé sa linn).

> **Ceanntásca teiliméadrachta costais:** bíonn tacar teiliméadrachta costais `X-OmniRoute-*` ar fhreagraí rathúla neamhshruthaithe freisin — `X-OmniRoute-Response-Cost` (USD, 10 n-ionad dheachúlacha seasta; `0.0000000000` le haghaidh seirbhísí saor in aisce/gan phraghas), `X-OmniRoute-Tokens-In` / `X-OmniRoute-Tokens-Out`, `X-OmniRoute-Model`, `X-OmniRoute-Provider`, `X-OmniRoute-Latency-Ms`, `X-OmniRoute-Cache-Hit`, agus `X-OmniRoute-Fallback-Attempts` (nuair atá sé > 0 amháin), chomh maith le `X-OmniRoute-Request-Id` agus `X-OmniRoute-Version`. Astaítear iad seo ag comhlánuithe comhrá, `/v1/responses`, `/v1/messages`, **agus ag na críochphointí meán** — `/v1/embeddings`, `/v1/images/generations`, `/v1/audio/speech`, `/v1/audio/transcriptions`, `/v1/rerank`, `/v1/videos/generations`, `/v1/music/generations`, agus `/v1/moderations` (costas `0` i gcónaí). Ríomhtar costas meán de réir módúlachta (in aghaidh na híomhá, an tsoicind, an charachtair, nó an aonaid chuardaigh) nuair atá praghsáil ar fáil; murach sin, is é `0` é (leanúint ar aghaidh i gcás teipe).

> **Séimeantaic chostais amais taisce:** nuair a bhíonn AMAS sa taisce shéimeantach (`X-OmniRoute-Cache-Hit: true`), ní dhéantar aon ghlao in aghaidh srutha, mar sin is é `0.0000000000` é `X-OmniRoute-Response-Cost` (an costas **incriminteach** a bhaineann leis an amas a riar). Tuairiscítear an costas bunaidh/an costas a bheadh ann ar leithligh in `X-OmniRoute-Cost-Saved`. Ba cheart do thomhaltóirí billeála suim `X-OmniRoute-Response-Cost` a ríomh (ní chosnaíonn amais aon rud); is féidir le hanailísíocht taisce `X-OmniRoute-Cost-Saved` a chomhiomlánú.

## Léasanna Eisiacha Seisiún Bainistithe

Is conradh ródaithe roghnach, neodrach ó thaobh an chliaint de é léasú eisiach seisiún bainistithe: coinníonn úinéir gníomhach amháin
nasc incháilithe amháin OmniRoute. Ní léasaíonn sé samhail, ní éilíonn sé OAuth, ní shainaithníonn sé
cliant ar leith, agus ní éilíonn sé soláthraí ar leith.

Ní mór raon feidhme `lease:exclusive` agus liosta sainráite neamhfholamh
`allowedConnections` a bheith ag an eochair API fíordheimhnithe. Forfheidhmíonn teorainn athraithe an bhunachair sonraí an dá réimse le chéile agus eochair
á cruthú agus nuashonruithe páirteacha á ndéanamh.

```http
POST /api/v1/session-leases
Authorization: Bearer <managed-api-key>
Content-Type: application/json
X-OmniRoute-Lease-Owner: vlo_<43-base64url-characters>

{"action":"acquire","model":"glm/glm-4.6"}
```

Nochtann freagraí rathúla ar fháil, athnuachan agus scaoileadh stampaí ama, `state`, agus an luach deimhneach beacht
`generation`, ach ní nochtann siad an nasc roghnaithe ná dintiúir riamh. Soláthraíonn athnuachan agus scaoileadh an
ghlúin i gcorp JSON:

```json
{ "action": "renew", "generation": 1 }
```

```json
{ "action": "release", "generation": 1, "reason": "OWNER_EXIT" }
```

Is féidir le húinéir léasa ghníomhaigh meiteashonraí taispeána atá sábháilte ó thaobh príobháideachais de a iarraidh go sainráite dá cheangal reatha:

```json
{ "action": "status", "generation": 1 }
```

```json
{
  "state": "ACTIVE",
  "generation": 1,
  "acquiredAt": "2026-08-28T12:00:00.000Z",
  "renewedAt": "2026-08-28T12:00:30.000Z",
  "expiresAt": "2026-08-28T12:02:30.000Z",
  "connection": {
    "displayName": "Primary Codex",
    "provider": "codex"
  }
}
```

Cuirtear fál timpeall ar an ngníomh stádais roghnach seo leis an úinéir teimhneach, an eochair API bhainistithe fhíordheimhnithe, agus an ghlúin ghníomhach bheacht
in idirbheart amháin bunachair sonraí. Níl in `displayName` ach ainm cumraithe an naisc agus é bearrtha;
is é `null` atá ann nuair nach bhfuil ainm cumraithe sábháilte ar fáil. Ní chuireann OmniRoute seoladh ríomhphoist ná
aitheantas cuntais ginte ina ionad riamh. Is lipéad taispeána neamhíogair é luach an tsoláthraí agus ní
aitheantóir ginte soláthraí chomhoiriúnaigh é riamh. Fágtar dintiúir, comharthaí, fianáin, aitheantóirí amha naisc nó eochrach
API, haiseanna úinéara, rúin fálaithe agus sonraí inmheánacha ródaithe ar lár.

Tugann cuardaigh le heochair mhícheart, úinéir mícheart, glúin sheanchaite, mír ar iarraidh, mír éagtha, mír scaoilte nó mír neamhbhailíochtaithe
an earráid chéanna `409 LEASE_FENCE_STALE` ar ais gan mheiteashonraí naisc. Níl aon cheangal gníomhach le hiniúchadh ag cliant a fuair an freagra feithimh ar acmhainn. Nuair a aistríonn an ródú léas gníomhach,
fanann an ghlúin chéanna bailí agus tugann an stádas an ceangal nua ar ais go hadamhach, seachas an seancheangal.
Ní athraítear cliaint atá ann cheana toisc go gcoinníonn na freagraí fála, athnuachana, scaoilte agus feithimh
na cruthanna a bhí acu roimhe seo.

Ní athraíonn an conradh freastalaí seo `/status` caighdeánach OpenAI Codex. Tuairiscíonn Codex caighdeánach a
sholáthraí samhla agus a staid ionsuite fíordheimhnithe/cuntais faoi láthair, ach ní dhéanann sé meiteashonraí treallacha cuntais
soláthraí shaincheaptha a rindreáil; ní mór do chomhtháthú cliaint amach anseo an gníomh seo a ghlaoch agus cinneadh a dhéanamh conas
`connection.displayName` a thaispeáint.

Ansin soláthraíonn gach iarratas tátail bhainistithe an dá cheanntásc rialaithe:

```http
X-OmniRoute-Lease-Owner: vlo_<43-base64url-characters>
X-OmniRoute-Lease-Generation: 1
```

Cuirtear fál timpeall ar an úinéir beacht, ar an nglúin, ar an nasc gníomhach agus ar an eochair API fhíordheimhnithe díreach
roimh gach iarracht réamhtheachtach a dtacaítear léi. Teipeann ar athsheinm an úinéara agus na glúine le heochair eile fiú
nuair a cheadaíonn an eochair sin an nasc céanna. Ní dhéantar úinéirí amha a bhuanú, a logáil, a choinneáil i
léargas an iarratais ná a chur ar aghaidh chuig an tseirbhís réamhtheachtach.

Tugann iomaíocht shealadach HTTP `429` ar ais mar aon le `Retry-After` agus:

```json
{
  "state": "WAITING_FOR_CAPACITY",
  "error": { "type": "lease_error", "code": "LEASE_CAPACITY_UNAVAILABLE" },
  "reason": "NO_FREE_ELIGIBLE_CONNECTION",
  "retryAfter": 30
}
```

Ní chiallaíonn an freagra seo ach nach raibh an gnáth-thacar incháilithe folamh agus go raibh gach iarrthóir saor
á choinneáil ag léas gníomhach le húinéir eile. Coinníonn samhlacha/soláthraithe nach dtacaítear leo, neamhréir bheartais, tréimhse mhoillithe, cuóta,
sláinte agus gnáth-theipeanna incháilitheachta eile na freagraí OmniRoute atá acu cheana.

### `x-omniroute-compression`

Sárú an phlean comhbhrúite in aghaidh an iarratais. An tosaíocht is airde — sáraíonn sé sárú an teaglaim ródaithe,
an phróifíl ghníomhach, an truicear uathoibríoch agus Réamhshocrú an phainéil. Luachanna:

| Luach         | Éifeacht                                                                                                                                |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `off`         | Gan aon chomhbhrú don iarratas seo.                                                                                                     |
| `default`     | Próifíl Réamhshocraithe atá díorthaithe ón bpainéal (déanann sí neamhaird den phróifíl ghníomhach). Fágtar innill chailliúnacha múchta. |
| `safe`        | Dí-dhúbláil agus comhdhlúthú spáis bháin amháin.                                                                                        |
| `allow-lossy` | Coinnigh plean an oibreora don iarratas seo, lena n-áirítear achoimrí agus athscríobh stíle.                                            |
| `engine:<id>` | Inneall aonair nuair atá sé cumasaithe, e.g. `engine:rtk`. Rogha in aghaidh an iarratais don inneall sin.                               |
| `<combo>`     | Teaglaim ainmnithe, a mheaitseáiltear de réir ainm ar dtús (gan beann ar chás), agus ansin de réir aitheantóra.                         |

Nótaí:

- Déantar neamhaird de luachanna anaithnide (ní dhiúltaítear don iarratas riamh); leanann an réiteach ar aghaidh chuig gnáthord tosaíochta an oibreora.
- Má tá an t-ainm céanna ar níos mó ná teaglaim amháin, tabhair aitheantóir na teaglaime **id** chun meaitseáil chinntitheach a fháil.
- Ní féidir teaglaim darb ainm `off` nó `default` a roghnú de réir ainm (léirmhínítear na heochairfhocail sin ar dtús); déan tagairt do theaglaim den sórt sin de réir a haitheantóra.
- Is geata docht é an máistirlasc comhbhrúite: nuair atá comhbhrú díchumasaithe go domhanda, ní féidir leis an gceanntásc seo é a chumasú.

Macallaítear an plean feidhmithe ar ais i gceanntásc an fhreagra:

```
X-OmniRoute-Compression: <mode>; source=<source>
```

áit a bhfuil `<source>` ar cheann de `request-header`, `routing-override`, `active-profile`, `auto-trigger`, `default`, nó `off`.

## Leabuithe

```bash
POST /v1/embeddings
Authorization: Bearer your-api-key
Content-Type: application/json

{
  "model": "nebius/Qwen/Qwen3-Embedding-8B",
  "input": "The food was delicious"
}
```

Soláthraithe atá ar fáil: Nebius, OpenAI, Mistral, Together AI, Fireworks, NVIDIA, **OpenRouter**, Jina AI.

Is iad `provider/model` aitheantais na catalóige (sampla: `jina-ai/jina-embeddings-v5-omni-small`). Réitítear freisin aitheantais lom samhlacha Jina atá sa chlárlann (mar shampla `jina-embeddings-v5-text-small`, `jina-reranker-v3.5`). Úsáideann leabú/athrangú/aicmiú/deighilt Jina dintiúir `jina-ai` an deais ar dtús; ní úsáidtear `JINA_AI_API_KEY` mar chúltaca ach amháin nuair nach ann d'eochair deaise. Is le haghaidh Reader / `r.jina.ai` amháin atá an cárta `jina-reader` (`POST /v1/web/fetch`) agus ní sholáthraíonn sé leabuithe ná athrangú riamh.

Glacann samhlacha clárlainne a fhógraíonn tacaíocht ilmhódach le suas le 32 mír struchtúrtha atá neamhspleách ar sholáthraí freisin. Is iad `text`, `image`, `audio`, `video`, agus `document` na cineálacha míre meán. Is é a `source` meán ná `{"type":"url","url":"https://..."}` nó `{"type":"base64","data":"...","media_type":"..."}`.

Glacann Jina v5 Omni (`jina-ai/jina-embeddings-v5-omni-small`, `jina-ai/jina-embeddings-v5-omni-nano`,
agus ailias an teaghlaigh `jina-ai/jina-embeddings-v5-omni` → omni-small) le doiciméid dhúchasacha
EmbeddingsV5Request de chuid Jina freisin agus **cuireann sé ar aghaidh gan athrú iad** chuig `https://api.jina.ai/v1/embeddings`:

```json
{
  "model": "jina-ai/jina-embeddings-v5-omni-small",
  "task": "retrieval.query",
  "normalized": true,
  "input": [
    { "text": "a red bicycle" },
    { "image": "https://example.com/bike.png" },
    { "content": [{ "text": "caption" }, { "image": "data:image/png;base64,..." }] }
  ]
}
```

Féadfaidh luachanna dúchasacha `{ image | audio | video | pdf }` a bheith ina URL poiblí HTTPS, ina URI `data:`, nó ina mbase64 amh. Ní dhéanann OmniRoute teaghránú ar na hoibiachtaí sin ná ní fhaigheann sé URLanna dúchasacha íomhánna — aisghabhann Jina na meáin phoiblí féin. Cuirtear réimsí breise Jina (`task`, `normalized`, `truncate`, `embedding_type`) ar aghaidh. Diúltaíonn SKUanna Jina téacs-amháin do dhoiciméid nach téacs iad fós.

Teorainneacha slándála agus iompair:

- Ní mór do URLanna cianda meán a bheith ina URLanna poiblí HTTPS. Faightear míreanna canónacha `{type,source:url}` ar thaobh an fhreastalaí (athbhailíochtú atreoruithe, teorainn ama, teorainneacha méide, DNS poiblí, pionnáil naisc) agus inlínítear iad roimh ghlao an tsoláthraí. Cuirtear míreanna dúchasacha Jina `{image:"https://..."}` ar aghaidh mar atá siad tar éis an tseiceáil chéanna maidir le HTTPS poiblí; faigheann Jina an URL.
- Tá meáin base64 inlíne teoranta do 8 MiB díchódaithe in aghaidh na míre agus 16 MiB díchódaithe ar fud na hiarrata.

Aistriú soláthraí (ní chuirtear míreanna canónacha ar aghaidh gan athrú riamh):

- Samhlacha ilmhódacha Jina: déantar oibiacht amháin a bhfuil eochair módúlachta aici de gach mír ardleibhéil (`text` / `image` / `audio` / `video` / `pdf`), agus URIanna sonraí á n-úsáid le haghaidh meáin inlíne; veicteoir amháin in aghaidh na míre ardleibhéil.
- Teaghlach Gemini Embedding 2: déantar iarratas dúchasach aonair `models/{model}:embedContent` d'eagar ardleibhéil amháin, le `content.parts` (`text` nó `inline_data`).
- llama.cpp (`llama-cpp/<model>`, samhail ar bith atá luchtaithe ag an bhfreastalaí áitiúil): déantar teaghráin shimplí de mhíreanna canónacha `text`, agus déantar oibiacht amháin `{"content": [part]}` an ceann de `image` / `audio` / `video`, ag úsáid codanna inneachair comhrá llama-server (`image_url`, `input_audio` leis an bhformáid `wav` / `mp3` / `flac`, `input_video`) le sonraí inlíne; veicteoir amháin in aghaidh na míre ardleibhéil. Ní mór don fhreastalaí rith le `--embedding --mmproj …`; gan teilgeoir, diúltaíonn sé féin do mheáin. Ní thacaítear le `document`.
- Diúltaíonn samhlacha anaithnide/dinimiciúla gan meiteashonraí sainráite módúlachta d'ionchur struchtúrtha le HTTP 400.

```json
{
  "model": "jina-ai/jina-embeddings-v5-omni-small",
  "input": [
    { "type": "text", "text": "A red bicycle" },
    {
      "type": "image",
      "source": { "type": "url", "url": "https://example.com/bicycle.png" }
    }
  ],
  "dimensions": 512,
  "encoding_format": "float"
}
```

Tugann teaglamaí samhla/módúlachta nach dtacaítear leo HTTP 400 ar ais seachas an mhír a chomhéigniú. Leanann réimsí sínte nach réimsí ionchuir iad ar iarratais oidhreachta teaghráin/comharthaí de bheith curtha ar aghaidh gan athrú.

```bash
# Liostaigh gach samhail leabaithe
GET /v1/embeddings
```

`SINGLE_IMAGE_FANOUT_FORMATS` in

### Sreabhadh pollála Azure Document Intelligence

Tá API `analyze` Azure Document Intelligence asincrónach: filleann an t-iarratas tosaigh
ceanntásc `Operation-Location` in ionad coirp, agus ní mór an toradh a pholláil. Déanann an láimhseálaí
(`open-sse/handlers/ocr.ts`) an URL sin a pholláil gach soicind ar feadh suas le 30 iarracht, teipeann sé láithreach (ní
leanann sé den pholláil) i gcás freagra pollála nach bhfuil `ok` nó stádas `"failed"`, agus filleann sé `504` má tá an
oibríocht fós ar siúl tar éis an líon ceadaithe iarrachtaí a ídiú. Déantar freagra deiridh Azure
a normalú sa chruth céanna `pages`/`markdown` a úsáideann Mistral sula bhfilltear ar an
nglaoiteoir é, ionas nach gá do chód an chliaint cás speisialta a dhéanamh den soláthraí.

### Fíordheimhniú agus réiteach críochphointe Vertex AI DeepSeek OCR

Athúsáideann `vertex-deepseek-ocr` an fíordheimhniú Vertex AI céanna a dtacaíonn OmniRoute leis cheana féin le haghaidh
tráchta comhrá/íomhá (`open-sse/executors/vertex.ts`): is é eochair API an naisc dintiúr JSON
Cuntais Seirbhíse (a mhalartaítear ar chomhartha rochtana OAuth gearrshaolach trí shreabhadh iompróra JWT)
nó comhartha rochtana OAuth a eisíodh cheana agus a úsáidtear mar atá. Is é URL an chríochphointe réamhtheachtaigh
críochphointe comhpháirtíochta cineálach Vertex `openapi/chat/completions`, a thógtar ó thionscadal agus
réigiún an naisc — tugtar tús áite i gcónaí do `providerSpecificData.project`/`providerSpecificData.region` sainráite;
murach sin, díorthaítear an tionscadal ó `project_id` JSON an Chuntais Seirbhíse agus úsáidtear
`us-central1` mar réigiún réamhshocraithe. Tarlaíonn an dá réiteach in `open-sse/handlers/ocr.ts`
(`resolveVertexOcrAccessToken`, `resolveVertexOcrBaseUrl`), agus úsáideann
`src/app/api/v1/ocr/route.ts` iad sula seoltar chuig `handleOcr` iad.

| Réimsí                                                          | Aonad                                             | Nótaí                                                                                                                                                                          |
| --------------------------------------------------------------- | ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `prompt`, `completion`, `input_cache_read`, `input_cache_write` | USD in aghaidh an chomhartha, teaghrán deachúlach | Comhoiriúnach le OpenRouter, agus ní bhíonn siad i nodaireacht easpónantúil riamh. Ní bhíonn an dá réimse taisce le feiceáil ach nuair atá praghas taisce ann.                 |
| `input`, `output`, `cached`, `cache_creation`                   | USD in aghaidh 1M comhartha, uimhir               | Réimsí ó leaganacha níos luaithe den chatalóg, coinnithe do chliaint atá ann cheana. Bíonn `reasoning` agus `long_context` le feiceáil freisin nuair atá siad sa ró praghsála. |

- Bíonn praghas a gcéad sprice infheicthe ag **teaglamaí**. Roghnaíonn teaglamaí ionsuite `auto/*`
  sprioc tráth na hiarrata, mar sin ní bhíonn `pricing` acu.
- Taispeánann **samhlacha saor in aisce** `"0"` (agus `0`) nuair atá a bpraghas cothrom le náid. Taispeánann samhail nach bhfuil ró praghsála aici
  `"0"` freisin nuair a mharcálann an chatalóg í mar shaor in aisce (`free: true`) nó nuair atá sí liostaithe sa chatalóg ionsuite
  de shamhlacha saor in aisce.
- **Praghas anaithnid:** níl eochair `pricing` san iontráil.
- Gearrann **soláthraithe a thomhaistear de réir creidmheasanna** (amhail Kiro) táille in aghaidh na hiarrata seachas in aghaidh an chomhartha. Coinníonn a
  n-iontrálacha na réimsí uimhriúla in aghaidh 1M a bhí acu roimhe seo agus ní bhíonn aon réimsí teaghráin in aghaidh an chomhartha acu.
- Cóipeálann **malairtí** (aitheantais iarrachta réasúnaithe, ailiasanna gan smaointeoireacht, agus scátháin fionnachtana agus geata)
  praghas na samhla a seolann siad chuici.
- Ní bhíonn ach bunrátaí sna réimsí. Ní athraíonn sraitheanna comhthéacs fhada (an réimse uimhriúil `long_context`) ná
  iolraitheoirí sraithe seirbhíse (mar shampla Codex tapa nó solúbtha) `prompt` ná
  `completion`.
- Bíonn an oibiacht mar an gcéanna do gach stíl fíordheimhnithe, lena n-áirítear
  iarratas de stíl Anthropic le `x-api-key` agus `anthropic-version` (fanann an freagra mar `{ "object": "list",
"data": [...] }`). Cur chun feidhme: `src/app/api/v1/models/catalogPricing.ts`.

### Réimíreanna aitheantais samhlacha (`?prefix=`)

Fógraítear formhór na samhlacha faoi **réimír soláthraí**. Rialaítear an réimír a fhaigheann tú leis an
mbratach ghné `MODELS_CATALOG_PREFIX_MODE`, agus is féidir í a shárú **in aghaidh na hiarrata** le
paraiméadar iarratais — áisiúil do chliant atá ag iarraidh liosta glan gan an socrú ar fud an fhreastalaí
a athrú do gach duine eile:

```bash
GET /v1/models?prefix=alias        # aitheantas amháin in aghaidh na samhla — an réimír ghearr ailias
GET /v1/models?prefix=dual         # an dá fhoirm (réamhshocrú an fhreastalaí)
GET /v1/models?prefix=canonical    # réimír iomlán aitheantas an tsoláthraí amháin
```

| Mód         | Aschur                                                     | Nótaí                                                                                                                                                                                                                                    |
| ----------- | ---------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `dual`      | `cc/claude-sonnet-4-6` **agus** `claude/claude-sonnet-4-6` | **Réamhshocrú.** Seolann an dá aitheantas chuig an tsamhail chéanna; coinnítear iad ionas go leanfaidh cumraíochtaí cliant a chruachódaigh ceachtar den dá fhoirm ag obair. Méadaíonn sé méid na catalóige faoi dhó, a bheag nó a mhór.  |
| `alias`     | `cc/claude-sonnet-4-6`                                     | Iontráil amháin in aghaidh na samhla. Eisíonn soláthraithe nach bhfuil ailias ar leith acu a n-iontráil fós, mar sin ní chailltear aon rud.                                                                                              |
| `canonical` | `claude/claude-sonnet-4-6`                                 | Iontráil amháin in aghaidh na samhla faoi réimír iomlán aitheantas an tsoláthraí. Eisíonn soláthraithe nach bhfuil ailias ar leith acu (m.sh. `antigravity/…`, `agy/…`) a n-aon aitheantas anseo freisin, mar sin ní chailltear aon rud. |

Is féidir scáthán sa mhód `dual` a aithint gan an paraiméadar iarratais freisin: bíonn réimse `parent`
aige a dhíríonn ar an bpríomhaithinteas.

Ba cheart do chliaint a thaispeánann roghnóir samhlacha `?prefix=alias` a iarraidh — is é seo a dhéanann
[síneadh OmniCopilot do VS Code](../guides/VSCODE-COPILOT.md).

### Scagairí fionnachtana (`?capability=`, `?min_context=`, `?kind=`, `?q=`)

Glacann `GET /v1/models` le scagairí fionnachtana roghnacha. Gan aon cheann acu, ní athraítear an
freagra. Cúngaíonn siad an chatalóg atá infheicthe ag an nglaoiteoir cheana féin (cuirtear ceadanna na heochrach API i bhfeidhm ar dtús),
agus ritear iad roimh an leathanachú de stíl OpenAI le `limit` / `after`:

```bash
GET /v1/models?capability=vision&capability=tool_calling   # caithfidh gach cumas liostaithe a bheith fíor
GET /v1/models?capability=vision,reasoning&min_context=200000
GET /v1/models?kind=embedding                              # `type` na catalóige; is `chat` iad rónna nach bhfuil ceann acu
GET /v1/models?q=sonnet&limit=10                           # meaitseáil nach ndéanann idirdhealú idir cásanna ar aitheantas nó ainm
```

| Paraiméadar   | Luachanna                                                                                           |
| ------------- | --------------------------------------------------------------------------------------------------- |
| `capability`  | `attachment`, `reasoning`, `structured_output`, `temperature`, `thinking`, `tool_calling`, `vision` |
| `min_context` | slánuimhir neamhdhiúltach, curtha i gcomparáid le `context_length`                                  |
| `kind`        | `chat`, `audio`, `embedding`, `image`, `moderation`, `music`, `rerank`, `video`                     |
| `q`           | 1–200 carachtar                                                                                     |

Má thugtar luach anaithnid, nó `min_context` nach slánuimhir neamhdhiúltach é (`1.5`, mar shampla),
seoltar HTTP `400` ar ais agus liostaítear na luachanna bailí sa teachtaireacht. Cur chun feidhme:
`src/app/api/v1/models/catalogFilters.ts`.

### Gearrliosta samhlacha (`POST /v1/models/query`)

Seolann `POST /v1/models/query` liosta gearr, cinntitheach ar ais ón gcatalóg chéanna, leis an
bhfíordheimhniú agus an infheictheacht chéanna in aghaidh na heochrach agus atá ag `GET /v1/models`:

```bash
POST /v1/models/query
Authorization: Bearer your-api-key
Content-Type: application/json

{ "capabilities": ["vision", "tool_calling"], "min_context": 128000, "max_output": 16000,
  "kind": "chat", "q": "gpt", "owned_by": "openai", "exclude": ["openai/gpt-4o"], "limit": 5 }

→ { "object": "list", "data": [ ...models ] }
```

Tá gach réimse roghnach. Glacann `capabilities` agus `exclude` le heagar nó le teaghrán deighilte le camóga;
cuirtear `max_output` i gcomparáid le `max_output_tokens`. Sórtáiltear na torthaí de réir `owned_by`, agus ansin de réir `id`.
Is é `20` luach réamhshocraithe `limit`, agus cuirtear teorainn `100` le luachanna os cionn `100`. Seoltar HTTP `400`
ar ais i gcás JSON neamhbhailí, réimse anaithnid nó luach neamhbhailí.

### Samhlacha comhrá atá folaithe ina n-aonar

Déantar samhail a bhfuil **Folaithe** marcáilte uirthi ar leathanach a soláthraí a eisiamh ón gcatalóg agus diúltaítear
di le HTTP `404` / `model_not_found` nuair a iarrtar go sainráite í. Úsáideann an tseiceáil an soláthraí agus an tsamhail
réitithe, lena n-áirítear ailiasanna soláthraithe, réimíreanna nóid soláthraithe chomhoiriúnacha, agus
luachanna réamhshocraithe naisc. Scipeálann teaglaim spriocanna folaithe agus féadann sí samhail ghaolmhar infheicthe a úsáid; nuair nach
bhfuil aon sprioc inrite fágtha, seolann sí an cód earráide céanna ar ais. Tagann baint na folaitheachta i bhfeidhm leis an gcéad
iarratas eile. Ní fholaíonn sáruithe infheictheachta íomhá-amháin an tsamhail chomhrá a bhfuil an t-aitheantóir céanna aici.

Tá socrú aonair na samhla seo ar leithligh ó na
[liostaí ceadaithe/coiscthe nochta samhlacha](../routing/MODEL_EXPOSURE_LIST.md), a dhéanann scagadh ar
fhógairt catalóige agus ar iarrthóirí uathródaithe agus seoladh sainráite á choinneáil acu. Leanann ceadanna samhlacha
eochrach API de bheith i bhfeidhm go neamhspleách. Is é `dual` fós mód réamhshocraithe réimír na catalóige.

### Leaganacha samhlacha gan smaoineamh

I gcás samhlacha Claude atá in ann smaoineamh, fógraíonn `/v1/models` leagan **gan smaoineamh** freisin, a bhfuil `claude-3-omniroute-no-thinking/` mar réimír ar a aitheantóir:

```
claude-3-omniroute-no-thinking/<provider>/<model>
```

Má roghnaítear an t-aitheantóir seo (mar shampla, i gcumraíocht Claude Code a cheanglaíonn bloc `thinking` i gcónaí), réitítear ar ais chuig an bhfíor-`<provider>/<model>` é agus réasúnú faoi chois — `thinking:{type:"disabled"}` ar chonair `/v1/messages`, nó baintear na réimsí `reasoning`/`reasoning_effort` ar chonair `/v1/chat/completions`. Ní liostaítear an leagan ach amháin i gcás samhlacha de theaghlach Claude a thacaíonn le smaoineamh **agus** a urramaíonn `disabled` (mar sin, mar shampla, eisiatar samhlacha oiriúnaitheacha amháin a dhiúltaíonn do `disabled`). Is féidir le hoibreoirí an leagan a chumasú nó a dhíchumasú go héigeantach do gach samhail trí `ModelSpec.noThinkingAlias`.

## Giniúint fuaime ElevenLabs

Cumraigh ceangal soláthraí `elevenlabs` in OmniRoute le d’eochair API ElevenLabs.
Fíordheimhníonn cliaint lena n-eochair **OmniRoute** (`Authorization: Bearer $OMNIROUTE_API_KEY`);
soláthraíonn an geata eochair stóráilte an tsoláthraí mar `xi-api-key`. Ná seol eochair ElevenLabs riamh
mar chomhartha iompróra an gheata.

| Modh | Conair                      | Freagra                                                 | Catagóir chríochphointe na heochrach API |
| ---- | --------------------------- | ------------------------------------------------------- | ---------------------------------------- |
| POST | `/v1/sound-generation`      | Bearta fuaime dúchasacha                                | `elevenlabs`                             |
| POST | `/v1/music`                 | Bearta fuaime dúchasacha                                | `music`                                  |
| POST | `/v1/music/stream`          | Bearta fuaime sruthaithe                                | `music`                                  |
| POST | `/v1/music/detailed`        | Fuaim ilpháirteach dhúchasach agus plean cumadóireachta | `music`                                  |
| POST | `/v1/music/detailed/stream` | Meiteashonraí SSE dúchasacha agus smutáin fuaime        | `music`                                  |
| POST | `/v1/music/plan`            | Plean cumadóireachta JSON                               | `music`                                  |

Comhlánaíonn na críochphointí seo na bealaí `/v1/audio/speech`, `/v1/audio/transcriptions`,
`/v1/voices`, `/v1/text-to-speech/{voiceId}` agus `/v1/speech-to-text` atá ann cheana. Caomhnaítear réimsí JSON
dúchasacha agus paraiméadair iarratais amhail `output_format` agus `enable_logging`.
Coinníonn freagraí `/v1/music/detailed` a dteorainneacha ilpháirteacha; parsáil mar ábhar ilpháirteach iad.
Filleann `/v1/music/detailed/stream` `text/event-stream` ina bhfuil meiteashonraí cumadóireachta agus
smutáin fuaime base64 in imeachtaí SSE. Tacaíonn na sé bhealach ar fad le réamheitilt CORS.

```bash
export OMNIROUTE_BASE_URL="http://localhost:20128"
export OMNIROUTE_API_KEY="your-omniroute-api-key"

# Maisíocht ghearr fuaime. Fad: 0.5 go 30 soicind.
curl --fail-with-body "$OMNIROUTE_BASE_URL/v1/sound-generation?output_format=mp3_44100_128" \
  -H "Authorization: Bearer $OMNIROUTE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"text":"A single soft bell chime","duration_seconds":1,"model_id":"eleven_text_to_sound_v2"}' \
  --output effect.mp3

# Sloinntear fad an cheoil i milleasoicindí: 3000 go 600000.
curl --fail-with-body "$OMNIROUTE_BASE_URL/v1/music?output_format=mp3_44100_128" \
  -H "Authorization: Bearer $OMNIROUTE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt":"Gentle instrumental piano","music_length_ms":10000,"force_instrumental":true,"model_id":"music_v1"}' \
  --output music.mp3
```

Úsáid `/v1/music/stream` leis an gcorp JSON céanna chun fuaim a sheachadadh de réir a chéile. Glacann an chumadóireacht
le ceann amháin go díreach de `prompt` nó `composition_plan`; éilíonn `/v1/music/plan` `prompt`
agus glacann sé go roghnach le `source_composition_plan`. Caomhnaíonn na scéimeanna dúchasacha réimsí breise
soláthraí ionas go sroichfidh leaganacha de phleananna cumadóireachta agus roghanna mionchoigeartaithe ElevenLabs.

Glacann an críochphointe aontaithe `/v1/music/generations` freisin le `elevenlabs/music_v1`,
`elevenlabs/music_v2` agus `elevenlabs/music_v2_5`. Nuair atá ceangal gníomhach ElevenLabs ann,
nochtar na samhlacha seo sa chatalóg cheoil. Filleann an críochphointe seo
`{"created":...,"data":[{"b64_json":"...","format":"mp3"}]}`. Tá a réimse `duration` i
soicindí agus mapáiltear é go `music_length_ms`; tugtar tús áite do `music_length_ms` sainráite.
Mapáiltear `instrumental` go `force_instrumental`, agus tugtar tús áite don réimse dúchasach.
Úsáid na críochphointí dúchasacha sruthaithe don sruthú agus an críochphointe dúchasach cumadóireachta
d’iarratais nach bhfuil á dtiomáint ach ag plean cumadóireachta.

```bash
curl --fail-with-body "$OMNIROUTE_BASE_URL/v1/music/generations" \
  -H "Authorization: Bearer $OMNIROUTE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"elevenlabs/music_v1","prompt":"Gentle instrumental piano","duration":10,"instrumental":true}'
```

Cuirtear srianta críochphointe, samhla, buiséid agus ceangail i bhfeidhm roimh ghlao réamhtheachtach. Filleann bealaí
dúchasacha cóid stádais agus coirp earráide réamhtheachtacha gan athrú, lena n-áirítear `402` le haghaidh sriain
plean agus `429` le haghaidh teorann cuóta. Caomhnaítear na ceanntásca `character-cost`, `song-id`, `request-id` agus `retry-after`
nuair atá siad i láthair. Ní ráthaíonn iarmhéid creidmheasa saor in aisce rochtain ar gach
samhail cheoil, formáid aschuir ná gné API: cinneann ElevenLabs an teidlíocht do gach iarratas.
Caomhnaíonn an críochphointe aontaithe cóid stádais earráide i gclúdach normalaithe earráide OmniRoute.

Conarthaí réamhtheachtacha: [maisíochtaí fuaime](https://elevenlabs.io/docs/api-reference/text-to-sound-effects/convert),
[cumadóireacht cheoil](https://elevenlabs.io/docs/api-reference/music/compose) agus
[sonraí ceoil sruthaithe](https://elevenlabs.io/docs/api-reference/music/compose-detailed-stream).

> sheachfhreastalaí pionnáilte naisc riamh). Ní bhíonn nóid ar aon

Oibríonn na heochracha comhréidh a úsáideann soláthraithe eile (`cx`, `depth`, ...) mar a bhí roimhe seo.

| Soláthraí | Réimsí barrleibhéil                                                                                                                                                                                                                                                                                                                                                       | neadaithe                                                                                                                                        |

| exa       | `type`, `category`, `userLocation`, `moderation`, `additionalQueries`, `objective`, `systemPrompt`, `compliance` (primitives árasán), `startPublishedDate`, `endPublishedDate`                                                                                                                                                                                            | `contents.{text, highlights, summary, extras, livecrawlTimeout, maxAgeHours}` chumasc thar an `{ text: true, highlights: true }` réamhshocraithe |

Taifeadtar costas cuardaigh Firecrawl in aghaidh an bhloc tosaithe de 10 dtorthaí a cuireadh ar ais, ag $0.002 (2 chreidmheas) an bloc agus bloc amháin ar a laghad in aghaidh an ghlao ( [Billeáil Firecrawl](https://docs.firecrawl.dev/billing) ): chosain 11 toradh $0.004.

Coinníonn torthaí exa `id`, `highlight_scores`, `summary`, `subpages`, `entities` agus `extras` i `provider_raw`. Coinníonn torthaí tavily `images` agus `favicon`.

Taifeadtar costas cuardaigh Linkup ag $0.005 le haghaidh `depth` `fast` agus `standard` agus $0.05 le haghaidh `deep` ( [Praghsáil Linkup](https://docs.linkup.so/pages/documentation/development/pricing) ), cibé an dtagann `depth` ó `provider_options` nó ó shocruithe an naisc.

Glacann Exa `type: "lite"` (Exa 3.0) le sraith réimsí níos lú agus diúltaíonn sé don iarratas iomlán nuair a shocraítear aon réimse eile. I gcás lite, scaoiltear `additionalQueries`, `systemPrompt` agus gach eochair `contents` seachas `text` agus `highlights` roimh an nglao. Ní chuirtear na `subpages`, `subpageTarget`, `highlights.numSentences` agus `highlights.highlightsPerUrl` ar aghaidh a thuilleadh.

Is éard atá i gcuntasaíocht chostais ná an clárlann árasán `costPerQuery`, ach amháin Exa, a leanann praghsáil Exa féin: $0.007 in aghaidh an ghlao ar `auto` (agus an `fast` oidhreachta) nó $0.004 le haghaidh `lite` (agus an oidhreacht `instant`), ag clúdach 10 dtorthaí; $0.001 do gach toradh eile; agus $0.001 in aghaidh an toraidh a tugadh ar ais nuair a shocraítear `contents.summary`. Taifeadtar Tavily ag 1 chreidmheas ($0.008) le haghaidh `search_depth` `basic`, `fast` agus `ultra-fast`, agus 2 chreidmheas ($0.016) le haghaidh `advanced` ( [creidmheasanna Tavily API](https://docs.tavily.com/documentation/api-credits) ). Tá glao le `auto_parameters: true` a uasghrádaíonn Tavily go hardleibhéal fós taifeadta ag 1 chreidmheas.

## API Aisghabhála Gréasáin

Bain ábhar as URL trí sholáthraí cumraithe aisghabhála gréasáin (Firecrawl, Jina
Reader, Tavily Extract, TinyFish Fetch, Nimble Extract, Parallel Extract).

Ní thugann Parallel Extract (`parallel-search`, an eochair API chéanna le Parallel Search) ach Markdown
ar ais — tugann aon `format` eile `400` — agus cuireann sé teorainn 100,000 carachtar ar an ábhar. Nuair
nach féidir an spriocleathanach féin a bhaint amach, tuairiscíonn an tseirbhís réamhtheachtach é laistigh de HTTP 200;
nochtann OmniRoute é sin mar `422` le teachtaireacht sheasta.

| Modh | Conair          | Cur síos                                                        |
| ---- | --------------- | --------------------------------------------------------------- |
| POST | `/v1/web/fetch` | Aisghabh/scríob URL — corp bailíochtaithe ag `v1WebFetchSchema` |

**Cúltaca atá feasach ar chuóta (#8297):** nuair nach dtugtar `provider` sainráite, téitear
tríd an linn (`firecrawl` → `jina-reader` → `tavily-search` → `tinyfish` → `nimble-search` →
`parallel-search`) in ord tosaíochta
seasta (líonadh an chéad chinn ar dtús) — scipeáiltear soláthraí cumraithe a bhfuil teorainn ráta curtha air
in ionad an t-iarratas a stopadh láithreach, agus i gcás teipe réamhtheachtaí
in-atriailte/a bhaineann le cuóta (HTTP 429 i gcónaí; 402/403 do shraitheanna saora de chineál cuóta
Firecrawl/Tavily/TinyFish — ach ní do Jina Reader, agus riamh do ghnáthdhrochiarratas 400),
téitear ar aghaidh chuig an gcéad soláthraí eile nár baineadh triail as agus a bhfuil dintiúir aige tráth an iarratais.
Nuair a bhíonn gach soláthraí sa linn ídithe, tugann an críochphointe `429` amháin ar ais
(le ceanntásc `Retry-After`) in ionad an `400` chineálaigh a bhí ann roimhe seo. Nuair a
iarrtar `provider` sainráite, **níl** aon chúltaca ciúin ann — nochtann soláthraí sainráite
a bhfuil teorainn ráta curtha air nó a bhfuil ag teip a earráid féin (`429` má tá teorainn ráta curtha air, nó stádas na
seirbhíse réamhtheachtaí murach sin).

## Úsáid féinseirbhíse (`/api/usage/om-usage`)

Is féidir le haon eochair API úsáid agus cuótaí **na heochrach féin** a léamh — níl údarú bainistíochta ag teastáil. Seo é an críochphointe a
úsáideann cliant (CLI, painéal OmniCopilot) chun a chaiteachas a thaispeáint do shealbhóir eochrach.

```bash
# Foirm téacs (an conradh stairiúil — gnáth-théacs do theirminéal)
curl -H "Authorization: Bearer <your-api-key>" \
  http://localhost:20128/api/usage/om-usage

# Foirm struchtúrtha — an ceann a úsáideann comhéadan úsáideora
curl -H "Authorization: Bearer <your-api-key>" \
  "http://localhost:20128/api/usage/om-usage?format=json"
```

Ní mór **`allowUsageCommand`** a bheith cumasaithe don eochair (díchumasaithe de réir réamhshocraithe — scoránaíonn
bainisteoir eochracha API an deais é do gach eochair). Gan é, freagraíonn an críochphointe le `403`.

Tugann `?format=json` struchtúr idirdhealaithe ar ais ionas nach léifidh glaoiteoir réimse sonraí ó
dhiúltú choíche. Ar rath:

```jsonc
{
  "allowed": true,
  // níl sé seo i láthair ach amháin nuair atá teorainneacha úsáide in aghaidh na heochrach roghnaithe don eochair (USD laethúil/seachtainiúil):
  "personal": {
    "dailySpentUsd": 1.25,
    "dailyLimitUsd": 5,
    "dailyResetAtIso": "…",
    "weeklySpentUsd": 8,
    "weeklyLimitUsd": 20,
    "weeklyResetAtIso": "…" /* … */,
  },
  // léargas cuóta an tsoláthraí roghnaithe, nó null nuair nach bhfuil aon rud sa taisce fós:
  "provider": { "connectionId": "…", "provider": "claude", "plan": "…", "quotas": {/* … */} },
  // léargas gach naisc, ionas gur féidir le comhéadan úsáideora roinnt soláthraithe a rindreáil taobh le taobh:
  "providers": [
    { "connectionId": "…", "provider": "claude" /* … */ },
    { "provider": "codex" /* … */ },
  ],
}
```

I gcás diúltaithe (`401` drocheochair / `403` gan chead), tugann an bealach céanna
`{ "allowed": false, "error": { "message": "…" } }` ar ais — is staid éagsúil é `personal`/`provider`
atá i láthair ach folamh (eochair ceadaithe, gan aon rud foghlamtha fós) ó dhiúltú, agus ní dhéanann ach an fhoirm JSON
idirdhealú eatarthu.

**Údarú:** eochair API Bearer an ghlaoiteora féin, bailíochtaithe le `isValidApiKey` — ní hé seo
an dromchla bainistíochta (`/api/keys/…`), a fhanann faoi chosaint `requireManagementAuth`.

### Céatadáin Chuóta Amha vs. Céatadáin Choigeartaithe de réir an Scoithphointe

Agus `/api/usage/om-usage` á úsáid, ba cheart do ghlaoiteoirí an t-idirdhealú idir na
céatadáin a chuirtear i láthair san **aschur gnáth-théacs** agus san **aschur struchtúrtha JSON** a thabhairt faoi deara:

| Gné                     | Formáid gnáth-théacs (`/api/usage/om-usage` / `@@om-usage`)                                                              | Formáid JSON (`?format=json`)                                                         |
| :---------------------- | :----------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------ |
| **Réimse aschuir**      | `NN% left` (m.sh., `20% left`)                                                                                           | `provider.quotas` / `providers[].quotas`                                              |
| **Tomhas**              | **Lamháltas inúsáidte coigeartaithe de réir an scoithphointe**: acmhainn atá fágtha os cionn thairseach an scoithphointe | **Amhchuóta ón soláthraí réamhtheachtach**: tomhas neamhchoigeartaithe an tsoláthraí  |
| **Scálú scoithphointe** | Scálaithe trí `effectiveRemainingPercent()` ionas go léirítear an cúlchiste cosanta mar `0% left`                        | Dada (amhluachanna an léargais mar a thuairiscíonn an soláthraí iad)                  |
| **Sonraí tairsí**       | Ionchorpraithe sa chéatadán a thaispeántar                                                                               | Stóráilte in `quotaWindowThresholds` do gach nasc (nó réamhshocruithe an fhreastalaí) |
| **Príomhúsáideoir**     | CLIanna idirghníomhacha, leideanna teirminéil, oibreoirí daonna                                                          | Comhtháthuithe ríomhchláraithe, deaiseanna, anailísíocht, rianairí billeála           |

#### Foirmle Coigeartaithe an Scoithphointe

Tacaíonn OmniRoute le scoithphointí réamhghníomhacha cuóta chun ídiú réamhtheachtach a chosc (cumraithe trí
`quotaWindowThresholds` an naisc, réamhshocruithe an tsoláthraí, nó socruithe athléimneachta domhanda). Nuair atá tairseach scoithphointe
(m.sh., `cutoff = 25%`) gníomhach ar fhuinneog chuóta, ríomhann an rindreálaí téacs an lamháltas atá fágtha mar seo:

- Más `remaining <= cutoff`: tugtar `0%` ar ais.
- Más `remaining > cutoff`: tugtar `((remaining - cutoff) / (100 - cutoff)) * 100` ar ais.

Slánaíonn an t-aschur téacs formáidithe é seo go dtí an tslánuimhir is gaire (`Math.round(...)`).

#### Sampla Léiritheach

Samhlaigh fuinneog soláthraí ina bhfuil **60% d'úsáid amh** (agus dá réir sin **40% d'amhchuóta fágtha**) agus tairseach chumraithe
**scoithphointe 25% den chuóta atá fágtha**:

| Léiriú                         | Ríomh                                              | Fágtha  |             Úsáid Intuigthe             |
| :----------------------------- | :------------------------------------------------- | :-----: | :-------------------------------------: |
| **JSON amh (`?format=json`)**  | Léargas réamhtheachtach (`quotas[window]`)         | **40%** |                 **60%**                 |
| **Formáid téacs (`NN% left`)** | `((40 - 25) / (100 - 25)) * 100 = (15 / 75) * 100` | **20%** | **80%** (má ríomhtar `100 - remaining`) |

- **An fáth a dtaispeánann an téacs 20% fágtha:** As an 40% de chuóta fisiciúil atá fágtha ar an gcuntas, tá 25% curtha in áirithe ag
  polasaí an scoithphointe. Níl ach 15% as 75% den lamháil inúsáidte fágtha ag an nglaoiteoir sula stopfaidh an ródaire
  de bheith ag ródú chuig an nasc seo. Cinntíonn an scálú go gcuireann an nasc ídiú in iúl (`0% left`) díreach nuair
  a chuirfear deireadh leis an ródú.
- **An fáth a gcoinníonn JSON amhluachanna:** Tugann pálasta JSON léargas cruinn an tsoláthraí (`UsageSnapshot`) ar ais
  ionas go mbeidh rochtain ag uirlisí seachtracha ar fhíorluachanna na húsáide réamhtheachtaí agus ar
  `quotaWindowThresholds` ar leibhéal an naisc gan scálú caillteach ar thaobh an fhreastalaí.

#### Treoir d'Aistriú Tomhaltóirí

Má rinne comhtháthú seachtrach (amhail breiseán eagarthóra nó síneadh gníomhaire) scríobadh ar an
gcríochphointe téacs (`NN% left`) roimhe seo agus má ríomh sé an céatadán úsáidte mar `100 - NN`, ciallaíonn aistriú chuig `?format=json`:

- Léireoidh léamh luachanna amha JSON **tomhaltas iarbhír réamhtheachtach** (60% úsáidte sa sampla thuas).
- Más mian leis an gcomhtháthú séimeantaic liúntais inúsáidte an chríochphointe téacs a chaomhnú, is féidir leis
  foirmle éifeachtach an mhéid atá fágtha a mheas ar thaobh an chliaint trí `quotaWindowThresholds` a úsáid le haghaidh sáruithe ar leibhéal an naisc.

### Tionchar ar an bhfola

Freastalaíonn AMAIS sa taisce shéimeantach an freagra ón taisce **gan glao réamhtheachtach
a dhéanamh**, mar sin bíonn an `X-OmniRoute-Response-Latency` tuairiscithe gar do nialas
(beag beann ar an bhfola réamhtheachtach bhunaidh). Ba cheart do chliaint atá íogair ó thaobh fola de
(tagarmharcáil, monatóireacht p50/p99) ceanntásc freagartha
`X-OmniRoute-Cache-Latency` a sheiceáil:

| Luach          | Brí                                                             |
| -------------- | --------------------------------------------------------------- |
| `synthetic`    | Freagra tugtha ón taisce; ní fíor-am réamhtheachtach í an fhola |
| _(as láthair)_ | Freagra ó fhíorghlao réamhtheachtach                            |

### Seachaint taisce de réir eochrach

Is féidir le heochracha API roghnú gan léamha ón taisce shéimeantach a úsáid trí `cacheDefaultMode`:

| Luach    | Iompar                                                                     |
| -------- | -------------------------------------------------------------------------- |
| `legacy` | Gnáthiompar taisce (réamhshocrú)                                           |
| `bypass` | Scipeáil cuardach na taisce go hiomlán; úsáid an réamhtheachtaigh i gcónaí |

Socraigh é agus eochair á cruthú (`POST /api/keys`) nó á nuashonrú (`PATCH /api/keys/[id]`):

```json
{ "cacheDefaultMode": "bypass" }
```

### Seachaint de réir iarratais

Is féidir le hiarraidh ar bith an taisce a sheachaint beag beann ar shocruithe na heochrach:

```
X-OmniRoute-No-Cache: true
```

I gcás samhlacha sioncronaithe/iompórtáilte, glacann `PUT /api/provider-models` le `provider`, `modelId`, agus
`maxOutputTokenOverride`: socraíonn slánuimhir dheimhneach an uasteorainn láimhe ar chomharthaí aschuir, agus glanann `null`

luachanna seo in `modelOutputOverrides`, lena n-áirítear samhlacha nach bhfuil ró samhla saincheaptha acu. Úsáideann an sárú
an cumas `max_output_tokens` ag am rite agus maireann sé tar éis athshioncronú samhla. Cuireann leathanach an tsoláthraí
atá comhoiriúnach le OpenAI na rialtáin chéanna eagarthóireachta/glanta ar fáil agus marcálann sé samhlacha a bhfuil tacaíocht fhollasach amhairc acu.

Cuireann nóid shaincheaptha Chat Completions díroghnuithe sainráite réasúnaíochta in oiriúint don inneall cúldeiridh réamhtheachtach. Roghnaíonn
tástáil rathúil naisc rialtáin teimpléid comhrá go huathoibríoch do gach ID beacht samhla
a gcruthaíonn a iontráil `/models` luach aitheanta `owned_by`: `vllm`, `sglang`, nó `llamacpp`.
Féadfaidh fillteáin thrédhearcacha atá comhoiriúnach le OpenAI an bhuniontráil samhla a chaomhnú laistigh d'oibiacht neadaithe
`openai`; leanann an bhrath suas le trí chlúdach den sórt sin. Coinníonn samhlacha a bhfuil úinéireacht in easnamh, anaithnid nó
contrártha acu gnáthiompar OpenAI. Athúsáideann an bhrath an t-iarratas catalóige atá ann cheana,
ní ghineann sé aon chomharthaí comhlánaithe, agus déantar é a neamhbhailíochtú nuair a athraíonn críochphointe an naisc.

Chun an t-iompar a shocrú d'inneall cúldeiridh nach nochtann na meiteashonraí sin, úsáid API nuashonraithe pháirtigh
an tsoláthraí atá ann cheana:

```json
{
  "providerSpecificData": {
    "reasoningControl": "chat-template"
  }
}
```

Seol an corp sin le `PUT /api/providers/<connection-id>`. Ar an nasc sin, seoltar iarracht
réasúnaíochta shainráite de `none` mar `chat_template_kwargs.thinking=false` agus
`chat_template_kwargs.enable_thinking=false`. Fanann luachanna sainráite dúchasacha teimpléid i gceannas
mura gcuireann riail réasúnaíochta ar thaobh an fhreastalaí iallach ar iarracht. Ní bhaineann an socrú ach amháin nuair a sheolann
nasc saincheaptha atá comhoiriúnach le OpenAI corp Chat Completions; coinníonn iarratais Responses agus gnáthsholáthraithe
a gcruth dúchasach iarratais. Socraigh `reasoningControl` mar `openai` chun gnáth-thraschur OpenAI
`reasoning_effort` a chur i bhfeidhm, nó fág ar lár é/socraigh mar `null` é chun brath uathoibríoch a úsáid.

Iarratais aicmitheora uathmhóid Claude Code, nuair nach mbíonn aon rialtáin shainráite réasúnaíochta iontu,
díchumasaíonn siad smaointeoireacht dhúchasach de réir réamhshocraithe. Úsáideann an bhrath marcóir córais an aicmitheora in iarratais i bhformáid Claude,
seachas ainmneacha samhlacha nó teorainneacha comhlánaithe. Coinníonn rialtáin shainráite coirp, ceanntásca iarrachta/smaointeoireachta
a dtacaítear leo, rialacha ródaithe, agus iarracht réitithe na samhla an tosaíocht atá acu cheana. Coinníonn an dá chéim den aicmitheoir
a gcuid leideanna, teorainneacha comhlánaithe, seichimh stad, agus fíorbhreithiúnais cheada ón gcóras réamhtheachtach;
is féidir leis an dara céim fós a réasúnaíocht infheicthe iarrtha a tháirgeadh mar ghnáth-théacs.

### Leagan agus Cainéal Eisiúna

```bash
GET /api/system/version
```

Bealach bainistíochta lúb-ais-amháin (fíordheimhniú riarthóra). Filleann sé an leagan atá á rith, an leagan is déanaí
a foilsíodh agus stádas an nuashonraithe uathoibríoch. Is réimsí breisitheacha iad `releaseChannel` agus `channels`
(rian 3.8.54); coinníonn `channel` a bhrí — an mód imlonnaithe a úsáideann nuashonraitheoir an deais
(`npm`, `source` nó `docker-compose`).

```json
{
  "current": "3.8.52",
  "latest": "3.8.52",
  "updateAvailable": false,
  "channel": "npm",
  "autoUpdateSupported": true,
  "autoUpdateError": null,
  "news": null,
  "releaseChannel": "latest",
  "channels": { "latest": "3.8.52", "next": "3.8.53-rc.1" }
}
```

- `releaseChannel` — cainéal npm na tógála atá á rith: `nightly` le haghaidh leaganacha `-nightly.*`,
  `next` le haghaidh réamheisiúintí eile (`-rc.*`, `-beta.*`, `-alpha.*`), `lts` le haghaidh leagan cobhsaí de
  mhórleagan atá níos sine ná `channels.latest`, agus `latest` i ngach cás eile. Na rialacha céanna agus atá ag
  `scripts/release/dist-tag.mjs`, a roghnaíonn an dist-tag npm tráth foilsithe.
- `channels` — ceann foilsithe gach dist-tag, ó `npm view omniroute dist-tags` (cúltaca HTTP na clárlainne),
  arna thaisceadh leis an TTL 10 nóiméad céanna agus atá ag `latest`. Bíonn `latest` ann i gcónaí
  (úsáidtear an réimse `latest` mar chúltaca, agus ansin `"unavailable"`); ní bhíonn `next`, `nightly` ná `lts`
  ann ach amháin nuair atá an dist-tag sin ann. Athnuaitear an dá chuardach le hiarratas `Cache-Control: no-cache`.

Déantar cur síos ar an tsamhail cainéal (`latest` = v3 go dtí 4.0 GA, `next` = rc, `nightly` = tógálacha `develop`,
`lts` = paistí v3 tar éis 4.0 GA) in `docs/ops/RELEASE_STRATEGY.md`.

## Teorainneacha Comharthaí

Buiséid **chomharthaí** in aghaidh na heochrach API (ar leith ón mBuiséad bunaithe ar USD thuas). Cuirtear i bhfeidhm iad go hinlíne ar chonair an iarratais: nuair a shroicheann úsáid fuinneoige reatha eochrach a teorainn, diúltaítear d’iarratais le `429 Too Many Requests`. Is féidir teorainneacha a theorannú do `model` sonrach, do `provider`, nó iad a chur i bhfeidhm go `global` ar fud na heochrach; nuair a mheaitseálann roinnt teorainneacha iarratas, bíonn an ceann is sriantaí i réim.

```bash
# Liostaigh teorainneacha comharthaí eochrach (úsáid bheo na fuinneoige san áireamh)
GET /api/usage/token-limits?apiKeyId=key-123

# Cruthaigh nó nuashonraigh teorainn chomharthaí
POST /api/usage/token-limits
Content-Type: application/json

{
  "apiKeyId": "key-123",
  "scopeType": "model",
  "scopeValue": "openai/gpt-4o",
  "tokenLimit": 1000000,
  "resetInterval": "monthly",
  "enabled": true
}

# Scrios teorainn chomharthaí de réir a haitheantais
DELETE /api/usage/token-limits?id=tl-abc
```

> **Nótaí scéime** (`setTokenLimitSchema`): tá `apiKeyId` agus `scopeType` (`model` | `provider` | `global`) riachtanach. Tá `scopeValue` riachtanach mura bhfuil `scopeType` cothrom le `global` (m.sh. aitheantas samhla do raon `model`, aitheantas soláthraí do raon `provider`). Ní mór do `tokenLimit` a bheith ina shlánuimhir dheimhneach (comhéignithe ó theaghrán). Roghnach: `id` (fág ar lár é chun ceann a chruthú, soláthair é chun ceann a nuashonrú), `resetInterval` (`daily` | `weekly` | `monthly`, réamhshocrú `monthly`), `resetTime` (`HH:MM`), `enabled` (réamhshocrú `true`). Saibhríonn freagraí `GET` gach teorainn le `tokensUsed`, `remaining`, `windowStart`, `periodStartAt`, agus `nextResetAt`. Is críochphointe d’aicme bainistíochta é seo (cuireann an phíblíne authz an fíordheimhniú i bhfeidhm go lárnach).

## Próiseáil Iarratais

1. Seolann an cliant iarratas chuig `/v1/*`
2. Glaonn láimhseálaí an bhealaigh ar `handleChat`, `handleEmbedding`, `handleAudioTranscription`, nó `handleImageGeneration`
3. Réitítear an tsamhail (soláthraí/samhail dhíreach nó ailias/teaglama)
4. Roghnaítear dintiúir ón DB áitiúil agus infhaighteacht cuntas á scagadh
5. Maidir le comhrá: seiceálann `handleChatCore` an taisce shéimeantach/sínithe agus réitíonn sé socruithe comhbhrúite an teaglama
6. Ritheann comhbhrú réamhghníomhach roimh aistriú an tsoláthraí nuair atá sé cumasaithe (`lite`, Caveman, RTK, nó i gcruach)
7. Seolann riteoir an tsoláthraí an t-iarratas suas srutha
8. Aistrítear an freagra ar ais go formáid an chliaint (comhrá) nó seoltar ar ais é mar atá (leabuithe/íomhánna/fuaim)
9. Taifeadtar úsáid, anailísíocht chomhbhrúite, agus logaí iarratais
10. Cuirtear cúl-aistriú i bhfeidhm i gcás earráidí de réir rialacha an teaglama

## Athléimneacht (leathnaithe)

Cuireann OmniRoute trí shásra neamhspleácha teipe sealadaí ar fáil; ligeann na críochphointí bainistíochta thíos d’oibreoirí iad a léamh agus a shárú:

| Raon                | Stóráil staide                                 | Léamh                                     | Athshocrú / glanadh                                      |
| ------------------- | ---------------------------------------------- | ----------------------------------------- | -------------------------------------------------------- |
| Scoradán soláthraí  | `domain_circuit_breakers` + sa chuimhne        | `/api/monitoring/health`                  | `POST /api/resilience/reset`                             |
| Maolú naisc         | `rateLimitedUntil` ar naisc soláthraithe       | `/api/rate-limits`, `/api/providers/[id]` | (athchumasaítear go leisciúil é; glan trí PUT soláthraí) |
| Frithdhúnadh samhla | Clárlann infhaighteachta samhlacha sa chuimhne | `GET /api/resilience/model-cooldowns`     | `DELETE /api/resilience/model-cooldowns`                 |

Glacann `PATCH /api/resilience` le sáruithe scoradáin soláthraí faoi `providerBreaker.oauth` agus `providerBreaker.apikey`. Tacaíonn gach próifíl le `degradationThreshold`, `failureThreshold`, agus `resetTimeoutMs`; tá na réimsí céanna ar fáil in Deais → Socruithe → Athléimneacht.

```bash
# Glan frithdhúnadh samhla amháin
curl -X DELETE http://localhost:20128/api/resilience/model-cooldowns \
  -H "Cookie: auth_token=..." \
  -H "Content-Type: application/json" \
  -d '{"provider":"openai","model":"gpt-4o-mini"}'

# Scrios gach frithdhúnadh
curl -X DELETE http://localhost:20128/api/resilience/model-cooldowns \
  -H "Cookie: auth_token=..." \
  -d '{"all":true}'
```

Le haghaidh na tagartha coincheapúla iomláine agus réamhshocruithe scoradáin: féach [`CLAUDE.md`](../../CLAUDE.md) → "Staid Ama Rite na hAthléimneachta" agus [`docs/architecture/RESILIENCE_GUIDE.md`](../architecture/RESILIENCE_GUIDE.md).

### Ciú Teorannaithe Ráta & Líontán Sábhála Uathchumasaithe

- **Conair scríofa lena dtacaítear**: Is é `POST /api/rate-limits` leis an gcorp `{"connectionId": "<id>", "enabled": true|false}` an críochphointe bainistíochta lena dtacaítear chun cosaint teorannaithe ráta do nasc a scoránú. Ní athraíonn ná ní scoránaíonn `PUT /api/providers/[id]` `rateLimitProtection` d’aon ghnó (#11278).
- **Séimeantaic `enabled: false`**: Má shocraítear `enabled: false`, baintear cosaint shainráite den nasc, ach **ní** dhíroghnaítear nasc gníomhach eochrach API ón líontán sábhála uathchumasaithe domhanda (`autoEnableApiKeyProviders = true`). In `reconcileEnabledConnections` (`open-sse/services/rateLimitManager.ts`), tá `false` agus `undefined` coibhéiseach; fanann naisc ghníomhacha eochrach API gan chosaint shainráite faoi chosaint an líontáin sábhála uathchumasaithe.
- **Díchumasú domhanda**: Chun naisc eochrach API a rith gan ciúnna teorannaithe ráta, díchumasaigh an líontán sábhála go domhanda trí `RATE_LIMIT_AUTO_ENABLE=false` (athróg timpeallachta) nó `resilienceSettings.requestQueue.autoEnableApiKeyProviders = false` (Socruithe → Athléimneacht / `PATCH /api/resilience`).

## Freastalaí MCP

Tagann OmniRoute le freastalaí leabaithe Model Context Protocol ina bhfuil 3 iompar (stdio, SSE, streamable-http) agus uirlisí a bhfuil raon feidhme sainithe acu. Léann críochphointí an deais thíos sonraí stádais/iniúchta agus déanann siad seachfhreastalaíocht ar na hiompar HTTP.

| Modh | Conair | Cur síos |
| ------ | ---------------------- | ------------------------------------------------------------------------------------------------ | -------------------- |
| GET | `/api/mcp/status` | Buille croí, iompar, staid ar líne, glao is déanaí, príomhuirlisí, ráta ratha 24 uair |
| GET | `/api/mcp/tools` | Liosta uirlisí MCP ina bhfuil `name`, `description`, `scopes`, `phase`, `auditLevel`, `sourceEndpoints` |
| GET | `/api/mcp/sse` | Oscail sruth SSE don iompar SSE (seoltar `503` ar ais má tá MCP díchumasaithe nó mura bhfuil an t-iompar comhoiriúnach) |
| POST | `/api/mcp/sse` | Seol fráma JSON-RPC ar an iompar SSE |
| GET | `/api/mcp/stream` | Oscail taobh SSE den iompar Streamable HTTP (teachtaireachtaí arna dtionscnamh ag an bhfreastalaí) |
| POST | `/api/mcp/stream` | Seol fráma JSON-RPC ar an iompar Streamable HTTP |
| DELETE | `/api/mcp/stream` | Cuir deireadh le seisiún Streamable HTTP |
| GET | `/api/mcp/audit` | Cuardaigh an loga iniúchta — `?limit=`, `?offset=`, `?tool=`, `?success=true                                | false`, `?apiKeyId=` |
| GET | `/api/mcp/audit/stats` | Staitisticí comhiomlána iniúchta (iomláin, ráta ratha, meánfhad, príomhuirlisí) |

**Fíordheimhniú:** cloíonn na hiompar `sse`/`stream` leis an gcomhéadan fíordheimhnithe a bhaineann go sonrach le MCP (eochair API Bearer le raon feidhme `mcp`); is féidir na bealaí `status`/`tools`/`audit*` a léamh ón deais (ní theastaíonn fíordheimhniú breise seachas rochtain a fháil ar óstach na deaise).

> Tá an dá iompar HTTP faoi rialú `settings.mcpEnabled` agus `settings.mcpTransport` — seoltar `400` ar ais mura bhfuil an t-iompar comhoiriúnach, agus seoltar `503` ar ais nuair atá MCP díchumasaithe.

## Freastalaí A2A

Cuireann OmniRoute críochphointe A2A (Gníomhaire le Gníomhaire) JSON-RPC 2.0 ar fáil, chomh maith le fillteán REST le haghaidh iniúchta agus úsáide deaise.

### JSON-RPC

```bash
POST /a2a
Authorization: Bearer your-api-key   # roghnach mura bhfuil OMNIROUTE_API_KEY socraithe
Content-Type: application/json

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "message/send",
  "params": {
    "skill": "smart-routing",
    "messages": [{"role": "user", "content": "Route this coding task"}]
  }
}
```

Modhanna a dtacaítear leo (iad uile faoi rialú `settings.a2aEnabled`):

| Modh             | Cur síos                                                            |
| ---------------- | ------------------------------------------------------------------- |
| `message/send`   | Rith sioncrónach scile; tugtar `{task, artifacts, metadata}` ar ais |
| `message/stream` | Rith sruthaithe SSE den tacar céanna scileanna                      |
| `tasks/get`      | Faigh tasc de réir `taskId`                                         |
| `tasks/cancel`   | Cealaigh tasc de réir `taskId`                                      |

Scileanna ionsuite: `smart-routing`, `quota-management`, `provider-discovery`, `cost-analysis`, `health-report`.

### Cárta Gníomhaire

```bash
GET /.well-known/agent.json
```

Tugtar an cárta poiblí gníomhaire A2A ar ais (ainm, cur síos, cumais, catalóg scileanna, scéim fíordheimhnithe) — taiscthe go poiblí ar feadh 1u. Ní theastaíonn fíordheimhniú.

### Cúntóirí REST

| Modh | Conair                       | Cur síos                                                                                                                |
| ---- | ---------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| GET  | `/api/a2a/status`            | A2A cumasaithe + staitisticí tascanna + achoimre thaiscthe ar chárta an ghníomhaire                                     |
| GET  | `/api/a2a/tasks`             | Liostaigh tascanna — `?state=submitted\|working\|completed\|failed\|cancelled`, `?skill=`, `?limit=` (≤200), `?offset=` |
| POST | `/api/a2a/tasks`             | (Níl sé curtha i bhfeidhm mar chúntóir REST — cruthaigh trí JSON-RPC `message/send`)                                    |
| GET  | `/api/a2a/tasks/[id]`        | Aisghabh tasc amháin                                                                                                    |
| POST | `/api/a2a/tasks/[id]/cancel` | Cealaigh tasc                                                                                                           |

**Fíordheimhniú:** ritheann na cúntóirí REST gan fíordheimhniú bainistíochta (is féidir leis an deais iad a léamh); úsáideann conair JSON-RPC `/a2a` Bearer `OMNIROUTE_API_KEY` má tá sé cumraithe.

## Fíordheimhniú

Féach [Fíordheimhniú Bainistíochta](../guides/MANAGEMENT-AUTH.md) chun eolas a fháil ar na ceithre
theaghlach dintiúr (seisiún deais, comhartha CLI áitiúil, Comhartha Rochtana
`oma_live_…`, eochair API le raon feidhme bainistíochta) agus ar an difríocht atá eatarthu agus eochracha tátail.

- Úsáideann bealaí deais (`/dashboard/*`) an fianán `auth_token`
- Úsáideann logáil isteach hais sábháilte an fhocail faire; úsáidtear `INITIAL_PASSWORD` mar chúltaca
- Is féidir `requireLogin` a scoránú trí `/api/settings/require-login`
- Féadfaidh eochair API Bearer a bheith riachtanach do bhealaí `/v1/*` nuair atá `REQUIRE_API_KEY=true`
- Ciallaíonn "comhartha bainistíochta" / "eochair API le raon feidhme bainistíochta" sa tagairt seo ceann de na teaghlaigh sa treoir sin — ní cineál rúin bhreise neamhshainithe

> **Athrú bristeach (v3.8.0)** — teastaíonn **fíordheimhniú bainistíochta** anois ó `/api/v1/agents/tasks/*` agus ó chríochphointí bainistíochta na tréimhse fuaraithe (fianán deais `auth_token` nó eochair API le raon feidhme bainistíochta). Gheobhaidh cliaint a ghlaoigh ar na bealaí seo roimhe seo gan fíordheimhniú `401 Unauthorized`. Féach gealltanas `588a0333` (`fix(auth): require management auth for agent and cooldown APIs`).
