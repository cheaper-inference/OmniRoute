## Catagóirí

- **Saor** sraith saor in aisce — le eochair API (cumraithe tríd an deais)
- **Ní headh** — críochphointí poiblí nach dteastaíonn eochair nó síniú isteach ar bith
- **OAuth** Sreabhadh síniú isteach — arna láimhseáil ag OmniRoute, níl eochair API ag teastáil
- **fianán gréasáin** Déanann — aip gréasáin an tsoláthraí a fhilleadh trí údar fianán
- **eochair API** soláthraí íoctha — cumraithe trí eochair API (d’fhéadfadh creidmheasanna saor in aisce a bheith i gceist)
- **Áitiúil** Ritheann — ar mheaisín an úsáideora (Ollama, LM Studio, vLLM, etc.)
- **Cuardach** soláthraithe cuardaigh gréasáin —
- **Fuaime** soláthraithe fuaime amháin — (TTS/STT)
- **seachfhreastalaí in aghaidh srutha** soláthraithe — a sheachvótálann soláthraithe eile
- **Gníomhaire scamall** gníomhairí códaithe fadreatha — (Codex Cloud, Devin, Jules)
- **Córas** — soláthraithe OmniRoute-inmheánacha (lúb siar, etc.)

Clibeanna breise: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (nuair a thaispeántar): `native` — fíorfheidhm ag glaoch API; `emulated` — déantar aithris phras ar an eagar `tools` trí `webTools.ts` (bloic `<tool>{...}</tool>` regex-parsáilte); Tá `none` — `tools` tite go ciúin faoi láthair. Féach #7286.

Úsáid an painéal ag `/dashboard/providers` chun gach soláthraí a chumasú, a chumrú agus a thástáil.
