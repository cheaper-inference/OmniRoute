## Catagóirí

- **Saor in aisce** — sraith saor in aisce le heochair API (cumraithe tríd an deais)
- **Gan fíordheimhniú** — críochphointí poiblí nach dteastaíonn eochair ná síniú isteach uathu ar chor ar bith
- **OAuth** — sreabhadh sínithe isteach arna láimhseáil ag OmniRoute, gan eochair API ag teastáil
- **Fianán gréasáin** — fillteán ar aip gréasáin an tsoláthraí trí fhíordheimhniú fianáin
- **Eochair API** — soláthraí íoctha arna chumrú trí eochair API (d’fhéadfadh creidmheasanna saor in aisce a bheith ar fáil)
- **Áitiúil** — ritheann sé ar ríomhaire an úsáideora (Ollama, LM Studio, vLLM, srl.)
- **Cuardach** — soláthraithe cuardaigh gréasáin
- **Fuaim** — soláthraithe fuaime amháin (TTS/STT)
- **Seachfhreastalaí réamhtheachtach** — soláthraithe a dhéanann seachfhreastal chuig soláthraithe eile
- **Gníomhaire néil** — gníomhairí códúcháin fadreatha (Codex Cloud, Devin, Jules)
- **Córas** — soláthraithe inmheánacha OmniRoute (aischúrsáil, srl.)

Clibeanna breise: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (nuair a thaispeántar é): `native` — fíor-API glao feidhme; `emulated` — déantar an t-eagar `tools` a aithris sa leid trí `webTools.ts` (bloic `<tool>{...}</tool>` a pharsáiltear le slonn ionadaíochta); `none` — fágtar `tools` ar lár go ciúin faoi láthair. Féach #7286.

Úsáid an deais ag `/dashboard/providers` chun gach soláthraí a chumasú, a chumrú agus a thástáil.
