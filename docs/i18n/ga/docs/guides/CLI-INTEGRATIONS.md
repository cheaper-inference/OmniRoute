Le haghaidh an léiriúcháin inrite roinnte, timpeallachtaí leanaí srianta agus socrú leanúnach Gemini, féach [conarthaí seolta CLI](./CLI-LAUNCH-CONTRACTS.md).

Cuireann OmniRoute teaghlach orduithe `setup-*` ar fáil a chumraíonn códú CLI (Codex, Claude Code , OpenCode, Cline, … ) chun OmniRoute a úsáid mar inneall — mar sin bíonn an uirlis ag caint leis** aon** bealaí críochphointe agus OmniRoute chuig an soláthraí ceart le auto-fallback. Léann gach ordú an** beo** catalóg samhail ó OmniRoute reatha (áitiúil nó cianda) agus scríobhann sé comhad cumraíochta na huirlise féin ar** do** meaisín. Déanann athróg timpeallachta tagairt don eochair API cibé áit a dtacaíonn an uirlis leis. Tugtar faoi deara thíos na horduithe a leanann comhad timpeallachta uirlis-áitiúil.

Tá tosaitheoir cineálach ann freisin — `omniroute run <target>` — a sceitheann `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen`, `gemini` nó `whycodes` leis an env ceart instealladh, gan aon chumraíocht a scríobh ar chor ar bith. Tagann na spriocanna agus a n-ailiasanna ón bhforléiriú canónach `bin/cli/cli-manifest.mjs` (`claude-code|cc|anthropic`, `codex-cli|openai-codex|openai`, `goose-cli`, `open-code`, `qwen-code`, `gemini-cli`, `why-codes|why`), agus cuireann `omniroute completion` na spriocfhocail léiritheacha céanna ar fáil. Tá na lainseálaithe oidhreachta in aghaidh an uirlis - `omniroute launch` (Claude Code ) agus `omniroute launch-codex` (Codex) - fós ar fáil.

Tá bordáil soláthraithe ar fáil ón gcomhthéacs local/remote céanna. Coinníonn na horduithe API-first thíos fíordheimhniú bainistíochta scartha ó dhintiúir an tsoláthraí agus ní phriontálann siad dintiúr in aschur struchtúrtha riamh:

```bash
omniroute providers add glm --credential-env GLM_API_KEY --name work
omniroute providers import ./providers.json --dry-run --json
omniroute providers auth openai
omniroute providers edit <connection-id> --default-model glm/glm-5.2
omniroute providers remove <connection-id> --yes
```

Maidir le scripteanna, is fearr `--credential-stdin` nó `--credential-env`; coinnítear `--credential` le haghaidh úsáid áitiúil rialaithe. Éilíonn `providers remove` `--yes` ar chríochfort neamh-idirghníomhach, agus onóir na cúig ordú go léir an comhthéacs gníomhach nó na roghanna domhanda `--base-url`/`--api-key`.

Diúltaíonn roghnóirí soláthraithe réimíreanna, ainmneacha nó ainmneacha soláthraithe ID débhríoch; bain úsáid as nasc iomlán ID nuair a mheaitseálann roinnt nasc. Cruthaigh agus cuir orduithe in eagar léigh an nasc sábháilte ar ais, agus deimhníonn baint amach nach bhfuil sé inléite a thuilleadh. Téann iompórtáil thar phéire provider/name atá ann cheana féin. Ní féidir le hiontrálacha iompórtáilte an críochphointe bainistíochta, an comhthéacs nó an dintiúir bhainistíochta a tugadh don CLI.

Maidir leis an mbunsraith aonuaire, lámhscríofa den dá chomhtháthú is saibhre, féach ar na tumthaí doimhne in aghaidh an uirlis:

- [cumraíocht cód Claude](./CLAUDE-CODE-CONFIGURATION.md)
- [cumraíocht Codex CLI](./CODEX-CLI-CONFIGURATION.md)
- [Mód Cianda](./REMOTE-MODE.md) - tiomáin OmniRoute cianda (VPS / Tailnet) ó do ríomhaire glúine
- [VS Cód Copilot Comhrá](./VSCODE-COPILOT.md) — an síneadh OmniCopilot ; is féidir leis na horduithe `setup-*` seo a rith duit ón taobh istigh den eagarthóir

Nótaí ar bhratacha (fíoraithe i bhfoinse na n-orduithe):

- `--remote <url>` — faigh an chatalóg ó OmniRoute iargúlta (sáraíonn sé `--port` agus an comhthéacs gníomhach). Soláthraíonn `--api-key <key>` an dintiúr don fhreastalaí sin (réamhshocraithe don `OMNIROUTE_API_KEY` env var, nó comhartha an chomhthéacs gníomhach).
- `--only <patterns>` — fo-theaghráin scartha le camóg; ná coimeád ach múnla IDs a mheaitseálann (m.sh. `--only glm,kimi`). Ar fáil ar `setup-codex`, `setup-claude`, `setup-opencode`, `setup-continue`, `setup-cursor`, `setup-crush`, `setup-zed`.
- `--dry-run` — priontáil go díreach cad a scríobhfaí gan teagmháil a dhéanamh leis an gcóras comhad. Ar fáil ar gach ordú `setup-*`** seachas** `setup-cursor` (nach scríobhann comhad riamh).
- `--model <id>` — ag teastáil (nó roghnaithe go hidirghníomhach) do na huirlisí nach bhfuil aon samhail auto-fionnachtain: Cline, Kilo, Roo, Goose, Qwen, Aider, 5dive, WhyCodes. Glacann na huirlisí sin `--yes` freisin le haghaidh ritheanna neamh-idirghníomhacha (a éilíonn ansin `--model`). Tógann `setup-opencode` `--model` chun an tsamhail barrleibhéil réamhshocraithe a shocrú.
- Leanann `--model <id>` ar `omniroute run` sreangú in aghaidh na sprice (`bin/cli/cli-manifest.mjs`):** cúntóir** fhaigheann `--model openai/<id>` agus** cód oscailte** `--model omniroute/<id>` (ní chuirtear an réimír leis ach amháin nuair nach bhfuil an t-aitheantas á iompar cheana féin);** qwen** agus** Cúpla** faigh an t-aitheantas focal ar fhocal;** claíomh** Faigheann sé trí `ANTHROPIC_MODEL`,** gé** trí `GOOSE_MODEL`,** cén fáth cóid** via `-P omniroute -m <id>`, agus** códx** via `-c model_providers.omniroute.*` args.** Is é Qwen an t-aon sprioc reatha a éilíonn `--model` go dian** — `omniroute run qwen` gan é fágann sé `2` le hearráid fhollasach.
- `--port <port>` — calafort OmniRoute áitiúil ( `20128` réamhshocraithe , neamhaird nuair a shocraítear `--remote` ). I láthair ar gach `setup-*` agus an dá lainseálaí.
- cóid scoir `omniroute run` : iomadaítear cód CLI an linbh féin focal ar fhocal; argóintí neamhbhailí `2` = (sprioc gan tacaíocht, `--model` ag teastáil , garda coimeádán); `127` = níl an spriocdhénártha in `PATH`; `130`/`143`/`129` nuair a chríochnaíonn an seoladh ag `SIGINT`/`SIGTERM`/`SIGHUP`; `1` = teip seolta am rite eile.
- Glacann an dá lainseálaí (`launch`, `launch-codex`) `--profile <name>` chun próifíl scríofa ag `setup-claude` / `setup-codex` a roghnú , móide arga pas-trí don dhénártha `claude` / `codex` bhunúsach.

Roinntear an roghnóir idirghníomhach freisin leis na hoidis socraithe:

```bash
# Pick from the active local or remote model catalog and configure the target.
omniroute configure claude
omniroute configure opencode --provider glm
omniroute configure qwen --model qwen/qwen3.8-max-preview --yes
```

Faoi láthair déanann `configure` toscairí chuig na hoidis thástáilte le haghaidh `codex`, `claude`, `opencode`, `qwen`, `aider`, `goose`, `cline`, `continue`, `kilo`, agus `5dive`. Fanann iontrálacha catalóige IDE-amháin, MITM, agus treoir-amháin ina sreafaí soiléire `setup-*`/láimhe agus ní chuirtear i láthair iad mar spriocanna inlainseála.

> Tá `setup-opencode` an** lightweight openai-comhoiriúnach** comhtháthú OpenCode. Tá comhtháthú breiseán níos saibhre ann freisin — `omniroute setup opencode` — a shuiteálann `@omniroute/opencode-plugin`. Is orduithe éagsúla iad; na doiciméid thuas `setup-opencode`.
>
> Tagann an breiseán i dhá phacáiste, ceann amháin in aghaidh OpenCode móra, toisc go bhfuil an dá lódóir ag súil le pointí iontrála éagsúla: `@omniroute/opencode-plugin` le haghaidh OpenCode v1 agus `@omniroute/opencode-plugin-v2` le haghaidh OpenCode v2. Tá an pacáiste v2 nua (`0.1.0`) agus leanann sé conradh óstach atá fós ag bogadh, mar sin léann sé an cruth síolta OpenCode isteach sa dréacht catalóg seachas glacadh leis. Suiteáil é trí iontráil `plugins` a chur le `opencode.json`; Déanann `omniroute setup opencode` an pacáiste v1 a shuiteáil fós. Tá na roghanna agus an t-ordú cuardaigh inchreidte sa phacáiste README.

## Úsáid áitiúil

Agus OmniRoute ag rith ar `localhost:20128`, níl le déanamh ach an t-ordú socraithe a rith do d’uirlis. Faightear an chatalóg ón bhfreastalaí áitiúil.

```bash
# Codex: scríobh próifíl do gach samhail mheaitseáilte isteach in ~/.codex/
omniroute setup-codex
codex --profile glm52            # úsáid próifíl ghinte

# Claude Code: scríobh próifílí de réir samhla, ansin seol ceann acu
omniroute setup-claude
omniroute launch --profile glm52

# OpenCode: scríobh an soláthraí atá comhoiriúnach le openai agus samhlacha uile na catalóige ann
omniroute setup-opencode
export OMNIROUTE_API_KEY=sk-...  # tagraítear dó trí {env:OMNIROUTE_API_KEY}, ní chuirtear ar diosca riamh é
opencode -m omniroute/glm/glm-5.2 "..."

# Teastaíonn samhail shainráite ó uirlisí nach bhfuil uathfhionnachtain acu:
omniroute setup-aider --model glm/glm-5.2
omniroute setup-qwen --model qwen/qwen3.8-max-preview

# Réamhamharc gan aon rud a scríobh:
omniroute setup-continue --dry-run
```

Seol gan aon chumraíocht a scríobh ar chor ar bith (instealladh timpeallachta amháin):

```bash
omniroute launch                 # Claude Code → OmniRoute áitiúil
omniroute launch-codex           # Codex CLI → OmniRoute áitiúil
omniroute launch-codex --profile glm52
omniroute run claude --model openai/gpt-5.4
omniroute run codex --model openai/gpt-5.4 --dry-run --json
omniroute run aider --model glm/glm-5.2 -- --message "reply OK"
omniroute run goose --model glm/glm-5.2
omniroute run opencode --model glm/glm-5.2 -- run "reply OK"

omniroute run claude -- --print-system-prompt "review this diff"
```

## Úsáid chianda

Dírigh aon ordú socraithe ar OmniRoute cianda le `--remote` + `--api-key`. Faightear an chatalóg ón gcianchóras; scríobhtar an chumraíocht ar do ríomhaire áitiúil.

```bash
# OpenCode i gcoinne VPS chianda, ná coinnigh ach samhlacha glm/kimi
omniroute setup-opencode --remote http://192.168.0.15:20128 --api-key oma_live_xxx \
  --only glm,kimi
opencode -m omniroute/glm/glm-5.2 "..."   # easpórtáil OMNIROUTE_API_KEY ar dtús

# Próifílí Codex ó chatalóg chianda
omniroute setup-codex --remote http://192.168.0.15:20128 --api-key oma_live_xxx

# Seol CLI go díreach i gcoinne an chianchórais
omniroute launch       --remote http://192.168.0.15:20128 --api-key oma_live_xxx
omniroute launch-codex --remote http://192.168.0.15:20128 --api-key oma_live_xxx
```

In ionad `--remote`/`--api-key` a thabhairt gach uair, logáil isteach uair amháin agus lig don **chomhthéacs gníomhach** iad a sholáthar go huathoibríoch:

```bash
omniroute connect 192.168.0.15        # gineann comhartha le raon feidhme agus stórálann sé an comhthéacs
omniroute setup-codex                 # ← úsáideann sé an chatalóg chianda anois
omniroute setup-opencode              # ← mar an gcéanna
omniroute launch                      # ← Claude Code i gcoinne an chianchórais
```

Féach [Mód Cianda](./REMOTE-MODE.md) le haghaidh comhthéacsanna, raonta feidhme agus bainistíocht comharthaí.

## Flíteanna gníomhairí 5dive

Ritheann [5dive](https://5dive.ai) flít de ghníomhairí códúcháin fadreatha, agus gach ceann acu ina aonad systemd faoina úsáideoir Unix féin. Ní CLI códúcháin é féin, mar sin níl aon rud ann a d’fhéadfadh `omniroute run` a sheoladh — is sprioc **chumraíochta amháin** é `5dive`.

```bash
omniroute configure 5dive --model failover-demo --yes
omniroute setup-5dive --model failover-demo --auth-profile omniroute --agent worker1
```

Scríobhann an dá fhoirm próifíl **fíordheimhnithe** amháin do 5dive, agus déanann gach suíochán `claude` atá ceangailte leis an bpróifíl sin cumarsáid le OmniRoute ansin. Baineann trí rud go sonrach leis an sprioc seo:

- **Ritheann sé ar óstríomhaire an fhlít, mar root.** Feidhmíonn briathra 5dive ar aonaid áitiúla systemd agus ar chomhadlann staide atá faoi úinéireacht root; níl aon mhód cianda ann. Athsheolann an t-oideas é féin trí `sudo` nuair nach bhfuil sé ag rith mar root cheana féin (múchann `--no-sudo` é sin agus priontálann sé an t-ordú ina ionad).
- **Ní mór don chríochphointe a bheith ina `https://` mura seoladh aislúibe é.** Seoltar eochair API an ghníomhaire leis an URL sin ar gach iarratas, agus diúltaíonn 5dive do chríochphointe neamhchriptithe lasmuigh den óstríomhaire. Ní eisceacht é seoladh príobháideach LAN.
- **Tá tosaíocht ag socrú seasta samhla gach suíocháin féin ar an bpróifíl.** Iompraíonn an phróifíl `ANTHROPIC_DEFAULT_{OPUS,SONNET,HAIKU}_MODEL`, ach teipeann ar shuíochán atá fós socraithe go seasta ar aitheantas samhla caighdeánach ar a chéad seal leis an teachtaireacht _"There's an issue with the selected model"_. Tabhair `--agent <name>` (is féidir é a athdhéanamh) chun na suíocháin a shocrú go seasta freisin; priontálann an t-oideas an t-ordú nuair nach ndéanann tú amhlaidh.

Tugtar an eochair API do 5dive ar **stdin** (`--api-key=-`), mar sin ní bhíonn sí le feiceáil riamh in aschur `ps`.

Tríd an bpróifíl a dhíriú ar **theaglaim** OmniRoute seachas ar shamhail aonair, faigheann an flít cúltaca soláthraí: nuair a thit an príomhchríochphointe go hiomlán i lár seala sa rith a taifeadadh ar [#11578](https://github.com/diegosouzapw/OmniRoute/issues/11578), chríochnaigh an gníomhaire na céimeanna a bhí fágtha aige ar an rogha chúltaca agus níor nocht sé an briseadh seirbhíse riamh.

## Spleáchais dhúchasacha a choinneáil le linn nuashonraithe: `--include=optional`

Nuair a dhéanann tú nuashonrú le `omniroute update` (tar éis deimhniú, nó le `--apply`),
ritheann OmniRoute an tsuiteáil agus `--include=optional` ionsuite inti:

```bash
npm install -g omniroute@latest --include=optional
```

**Ní** bratach í seo a chuireann tú ar aghaidh chuig `omniroute update` — cuireann an
nuashonraitheoir i bhfeidhm i gcónaí í. Cinntíonn sí go maireann na `optionalDependencies`
(`better-sqlite3`, `keytar`, `tls-client`, cruach SLM LLMLingua) an nuashonrú fiú má tá
`omit=optional` socraithe i do chumraíocht npm, rud a d’fhágfadh, murach sin, go mbainfí an
tiománaí dúchasach SQLite agus an ceangal le fáinne eochracha an chórais oibriúcháin go ciúin. Chun réamhamharc a fháil ar an ordú beacht gan é a chur i bhfeidhm:

```bash
omniroute update --dry-run
# [RITH TIRIM] Rithfí: npm install -g omniroute@latest --include=optional
```

Bratacha eile `omniroute update` (fíoraithe san fhoinse): `--check` (scoir le 1 má tá sé
as dáta), `--apply` (suiteáil gan leid), `--changelog`, `--no-backup`,
`--yes`.

## Google Gemini CLI trí `omniroute run gemini`

Conradh fíoraithe i gcoinne `@google/gemini-cli` 0.50.0: cloíonn an CLI le
`GOOGLE_GEMINI_BASE_URL` agus eisíonn sé `POST /v1beta/models/<model>:generateContent`
(agus `:streamGenerateContent?alt=sse`) chuige — dromchla dúchasach
Gemini OmniRoute (`/v1beta`) go díreach. Ceanglaíonn `omniroute run gemini` é sin go huathoibríoch:

- `GOOGLE_GEMINI_BASE_URL` → bun-URL gníomhach OmniRoute (fréamh, gan `/v1`);
- `GEMINI_API_KEY` → dintiúr OmniRoute a réitíodh (rogha/timpeallacht/comhthéacs);
- **`GEMINI_CLI_HOME` sealadach leithlisithe** a roghnaíonn a `.gemini/settings.json`
  fíordheimhniú `gemini-api-key`, ionas nach sáróidh seisiún stóráilte Google OAuth (Code Assist)
  an lainseáil atá dírithe ar OmniRoute choíche — baintear é tar éis scoir;
- **sláinteachas timpeallachta**: glantar `GOOGLE_API_KEY`,
  `GOOGLE_GENAI_USE_VERTEXAI` agus `GOOGLE_GENAI_USE_GCA` de thimpeallacht an phróisis linbh
  (a dhéanfadh fíordheimhniú a atreorú chuig Vertex/Code Assist), agus socraítear
  `GEMINI_DEFAULT_AUTH_TYPE=gemini-api-key` mar chúltaca breise — cuirtear an
  chóireáil chéanna ar na spriocanna `run` eile dá n-athróga contrártha féin;
- instealladh `--model <id>` ó `--provider`/`--model`.

```bash
omniroute run gemini --model glm/glm-5.2 -- --skip-trust -p "hello"
```

Tá cosaint iontaoibhe spáis oibre Gemini fós i bhfeidhm sa mhód gan chomhéadan — cuir
`--skip-trust` ar aghaidh (nó cuir muinín san eolaire go hidirghníomhach) tú féin; ní
sheachnaíonn an lainseálaí í d’aon ghnó. Tá an lainseálaí seo éagsúil leis an **gclárú
ACP** (`src/lib/acp/registry.ts`, `gemini --acp`), arb é fós an
comhtháthú prótacail gníomhaire do `/dashboard/acp-agents`.

## Fíor-scuabadh tástála deataigh (roghnach)

Ritear aischéimniú cinntitheach an phlean seolta in CI (`tests/unit/cli/run-command.test.ts`,
`tests/unit/cli/run-execution.test.ts`). Chun na FÍOR-dhénártha a bhailíochtú i gcoinne FÍORfhreastalaí
OmniRoute, tá creat tástála roghnach ar fáil ag
`tests/integration/upstream-cli-smoke.int.test.ts`. Ní ritear go huathoibríoch riamh é
(déantar gach fotheagmháil tástála a scipeáil mura bhfuil `RUN_CLI_SMOKE=1` ann), tugann sé ainm na hathróige timpeallachta
don dintiúr (ní an luach riamh), folaíonn sé teaghráin atá cosúil le heochracha ó aon aschur taifeadta, scipeálann sé
spriocanna nach bhfuil a ndénártha suiteáilte, agus aicmíonn sé teipeanna mar
fhíordheimhniú / réamhtheachta / cumraíocht seachas mar luach Boole lom:

```bash
RUN_CLI_SMOKE=1 \
OMNIROUTE_SMOKE_BASE_URL="http://localhost:20128" \
OMNIROUTE_SMOKE_MODEL="<provider/model>" \
OMNIROUTE_SMOKE_API_KEY_ENV="OMNIROUTE_API_KEY" \
node --import tsx/esm --test tests/integration/upstream-cli-smoke.int.test.ts
```

Roghnach: cuireann `OMNIROUTE_SMOKE_TARGETS="codex,opencode,qwen"` srian leis an scuabadh;
sáraíonn `OMNIROUTE_SMOKE_TIMEOUT_MS` an teorainn ama 120s in aghaidh na sprice.
