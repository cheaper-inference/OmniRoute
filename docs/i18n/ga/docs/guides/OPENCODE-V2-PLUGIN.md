Cuireann `@omniroute/opencode-plugin-v2` do chatalóg OmniRoute ar fad — samhlacha, teaglamaí agus
uath-theaglamaí — i roghnóir samhlacha OpenCode v2, mar aon le hainmneacha taispeána, praghsáil agus
buiséid sraithe saor in aisce.

Is pacáiste ar leith é ó `@omniroute/opencode-plugin` toisc go lódálann OpenCode v1 agus v2
breiseáin trí chonarthaí éagsúla. Roghnaigh an ceann a mheaitseálann do mhórleagan OpenCode; ní
roinntear aon rud eatarthu, mar sin ní chuireann uasghrádú ceann amháin iallach ort an ceann eile a uasghrádú.

## Riachtanais

- OpenCode v2.
- Geata OmniRoute atá inrochtana (`http://localhost:20128` de réir réamhshocraithe).
- Node.js 22 nó 24.

## Suiteáil

Cuir an breiseán le `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

Ansin feictear samhlacha mar `omniroute/<provider>/<model>`; socraíonn `providerId` an réimír sin agus
aitheantas an chomhtháthaithe faoina stórálann OpenCode an dintiúr.

## Dintiúir

Lorgaíonn an breiseán eochair gheata i dtrí áit, san ord seo:

1. **An dintiúr a nasc tú in OpenCode.** Cláraíonn an breiseán comhtháthú, ionas gur féidir le
   sreabhadh fíordheimhnithe OpenCode féin an eochair a stóráil. Ní chuirtear aon rud in `opencode.json` — tabhair tús áite dó seo.
2. `apiKey` i roghanna an bhreiseáin, mar shárú do gach tionscadal ar leith. Cuireann sé an eochair i gcomhad a
   d'fhéadfá a chur faoi rialú leaganacha.
3. `OMNIROUTE_API_KEY` sa timpeallacht.

Mura bhfuil aon cheann den triúr ann, bíonn an chatalóg folamh agus deir an breiseán é sin uair amháin ag am tosaithe seachas
roghnóir folamh ciúin a fhágáil agat.

### Is eochair eile é an comhartha bainistíochta

Tagann teaglamaí, sláinte soláthraithe agus saibhriú (ainmneacha taispeána, praghsáil, buiséid sraithe saor in aisce) ó
chríochphointí `/api/*` an gheata, a chosnaíonn formhór na n-imscaradh taobh thiar de chomhartha **bainistíochta**
seachas an eochair tátail:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<comhartha léite bainistíochta>"
}
```

Má fhágtar `managementReadToken` gan socrú, téann sé siar go `apiKey`. Nuair a dhiúltaíonn geata don rogha chúltaca sin
foilsítear an chatalóg fós, ach le hamhaitheantais samhlacha in ionad ainmneacha taispeána, gan dí-dhúbláil
ailiasanna canónacha, gan phraghsáil agus gan teaglamaí. Tugann an breiseán rabhadh uair amháin in aghaidh an chríochphointe nuair a tharlaíonn sé sin,
agus ainmníonn sé an críochphointe agus an méid a cailleadh — mar sin ní rúndiamhair riamh é roghnóir laghdaithe.

## Conas a fhanann an chatalóg úr

Faightear an chatalóg go leisciúil agus cuirtear i dtaisce le haghaidh `modelCacheTtlMs`, agus coimeádann pictiúr diosca an chatalóg dheireanach atá ar eolas ar fáil nuair nach féidir teacht ar an ngeata — Foilsítear múnlaí agus combos a luaithe a thagann siad; auto-combos, an liosta soláthraithe agus an forleagan saibhrithe fillte isteach nuair a thuirlingíonn siad, mar sin ní féidir le críochphointe mall amháin a choinneáil ar an ghiall roghnóir ar fad.

Leanann na hainmneacha `Provider - Model[ (Editor)][ · budget][ (route)]`: taispeántar an soláthraí nuair a iompraíonn an t-aitheantas ceann (rannálann aitheantas gan aon réimír), marcálann `🆓` tosaigh iontrálacha saor in aisce agus fanann a bhuiséad sraithe saor mar iarmhír `· 1M tokens/month`, bogann eagarthóir ainm sainráite `Editor: Model` chuig lúibín leanúnach (ní dhéantar aon eagarthóir a thomhas ó ainmneacha eile), agus `combo - <slug>` gan deilbhín saor in aisce. Faigheann dhá iontráil a roinneann ainm iarmhír bealaigh — `(no-think)` — ionas go bhfanann siad so-aitheanta. Déanann `providerTag` (réamhshocraithe `true`) lúibín an eagarthóra rianaithe a scoránú.

Níl aon ordú athnuachana láimhe ann: is teimpléid leide iad orduithe OpenCode v2, ní aisghlaonna, mar sin ní féidir le breiseán ceann a nochtadh. Athnuachan lean an TTL; iarrtar ar an óstach a athlódáil ach amháin nuair a d'athraigh an chatalóg nó an forleagan, gan aon uair amháin in aghaidh an athnuachana.

## Glaoch uirlisí ar Gemini

Diúltaíonn Gemini d’iarratas iomlán a bhfuil `$schema` nó `additionalProperties` ina dhearbhuithe uirlisí, agus freagraíonn sé le `400 INVALID_ARGUMENT`. Baineann an breiseán na heochairfhocail sin de scéimeanna uirlisí atá ceangailte do shamhail Gemini de chuid an tsoláthraí seo agus fágtar gach iarratas eile gan athrú. Cuirtear uirlis ina bhfuil `$ref` ar aghaidh gan athrú seachas é a bhaint, mar dá mbainfí an tagairt leathnófaí an scéim chun "glacadh le haon rud".
Socraigh `"geminiSanitization": false` chun é a mhúchadh.

## Fabhtcheartú

| Siomptóim                                                  | Cúis                                                                                                                                    |
| ---------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| Ní thaispeánann an roghnóir samhail OmniRoute              | Níl aon eochair réitithe (seiceáil an rabhadh tosaithe), nó tá an geata dosroichte                                                      |
| Aitheantas samhail amh, gan aon combos, gan aon phraghsáil | Dhiúltaigh críochphointí na bainistíochta don chomhartha — set `managementReadToken`                                                    |
| Catalóg `freeOnly` gearr nó folamh                         | Níl aon chomhartha bainistíochta nó dearbhán diúltaithe léigh — an líne achoimre athnuachana (`unmatched-free` count) i loga an óstaigh |
| Seisiún pinned go `opencode-<id>/...`                      | D'fhoilsigh an breiseán v1 `opencode-<id>`; Foilsíonn v2 `<id>` lom, mar sin athroghnaigh an tsamhail faoi `<id>/...`                   |

Ní mór d'athróga comhshaoil an próiseas freastalaí opencode a bhaint amach: nuair a ritheann an t-óstach mar sheirbhís, tá an bhlaosc a ritheann `opencode models` agus timpeallacht an fhreastalaí difriúil, mar sin déan an eochair a onnmhairiú nuair a léann an freastalaí é.
