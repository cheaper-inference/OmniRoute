Dearbhaíonn an conradh neodrach `config/cli-tools-manifest.json` IDs canonical , ailiasanna, iarrthóirí dénártha, oidis thus, argóintí samhail agus cumais. Léann an t-oiriúnóir Nód plain i `bin/cli/cli-manifest.mjs` agus an t-adapter TypeScript i `src/shared/constants/cliIntegrationManifest.ts` an comhad céanna. Seiceálann `tests/unit/cli/cli-manifest-drift.test.ts` am rite, catalóg, cumraíocht, críochnú, gineadóirí agus clárú inneall le chéile. Ní chiallaíonn catalógú gur féidir uirlis a sheoladh nó a chumrú. Go háirithe, tá 5dive fós cumraithe-amháin.

## Timpeallacht agus saolré an linbh

Bíonn `omniroute run`, `omniroute launch` agus `omniroute launch-codex` le hoidhreacht liosta ceadaithe comhoiriúnachta OS/terminal agus instealladh dintiúir an sprice roghnaithe. Ní fhaightear rúin nach mbaineann le soláthraí agus bunachar sonraí le hoidhreacht de réir réamhshocraithe. déanann `--inherit-env` oidhreacht iomlán tuismitheora-comhshaoil a athchóiriú go sainráite; ná bain úsáid as ach amháin nuair is ceart na luachanna sin a fháil don phróiseas tríú páirtí roghnaithe. Is scagadh timpeallachta é seo, ní bosca gainimh OS : ritheann an próiseas fós le ceadanna córas comhaid an ghlaoiteora.

Cuirtear comharthaí cur isteach agus foirceann ar aghaidh chuig an leanbh. Fanann an tosaitheoir ar theagmhas gar an linbh sula mbaintear an chumraíocht shealadach. rialaíonn `OMNIROUTE_CHILD_SIGNAL_TIMEOUT_MS` an tréimhse cairde roimh fhoirceannadh éigeantach (5000 milleasoicind mar réamhshocrú).

## Gemini socrú leanúnach

```bash
omniroute setup-gemini --remote https://omni.example --model provider/model --yes
omniroute configure gemini --model provider/model --yes
omniroute run gemini --model provider/model --dry-run --json
```

Cumraíonn an chéad dá ordú an meaisín seo don fhreastalaí áitiúil nó don chianfhreastalaí roghnaithe. Caomhnaíonn an tsuiteáil socruithe JSON neamhghaolmhara, roghnaíonn sé Gemini API-key auth, agus scríobhann an críochphointe agus an creidiúint chuig comhad `.gemini/.env` príobháideach. Diúltaíonn sé JSON neamhbhailí seachas é a fhorscríobh. Ní mór go mbeadh HTTP(S) ag críochphointe URLs, gan dintiúir leabaithe, paraiméadair cheist nó blúirí. Cosáin priontaí tirim-reatha, ní luachanna creidiúnacha.

roghnaíonn `GEMINI_CLI_HOME` nó `--gemini-home` an fhréamh leanúnach baile. Cruthaíonn `run gemini` iarbhír a bhaile sealadach féin agus ina dhiaidh sin baintear as. Ní sheachnaíonn ceachtar den dá mhodh seiceálacha iontaobhais spás oibre Gemini.

## próifílí Codex

scríobhann `configure codex` `<name>.config.toml` príobháideach le samhail agus críochphointe an tsoláthraí OmniRoute aige. Déantar tagairt do dhintiúir trí `OMNIROUTE_API_KEY`, ní neadaithe riamh. Socraíonn an t-ordú seolta an tsamhail roghnaithe ag an eochair `model` barrleibhéil, ní taobh istigh de `model_providers`.

Comhaid phróifíle ar leith is ea an conradh Codex atá doiciméadaithe faoi láthair; forleagan siad cumraíocht an úsáideora nuair a roghnaítear iad le `codex --profile <name>`. Féach [an tagairt próifíle oifigiúil](https://learn.chatgpt.com/docs/config-file/config-advanced#profiles) agus [an treoirleabhar OmniRoute Codex](./CODEX-CLI-CONFIGURATION.md).

## Forghníomhú ordú Hermetic

Le `DATA_DIR` sainráite , cuireann socrú `OMNIROUTE_CLI_SKIP_DEFAULT_DATA_ENV=1` cosc ar an am tosaithe ó titim isteach i dtimpeallacht dhintiúir an eolaire sonraí úsáideora réamhshocraithe. Tá sé seo úsáideach le haghaidh tástálacha iargúlta. Ní dhíchumasaíonn sé comhaid timpeallachta eile atá roghnaithe go sainráite.

## Eolaire oibre `.env`

Léann an CLI comhaid `.env` san ord seo, agus bhuaigh an chéad chomhad chun eochair a shocrú: an `DATA_DIR` sainráite, an t-eolaire sonraí réamhshocraithe, an t-eolaire oibre reatha, ansin an t-eolaire pacáiste. Athróga Shell bua i gcónaí.

Seans gur le duine éigin eile an t-eolaire oibre (stór clónáilte, cartlann neamhphacáil), agus cuireann `omniroute serve` an timpeallacht CLI ar aghaidh chuig an bhfreastalaí agus chuig gach uirlis a ritheann an freastalaí. Mar sin ní féidir le `.env` ann ach na heochracha seo a shocrú, atá liostaithe i `bin/cli/utils/untrustedCwdEnv.mjs`:

| eochair                         | Luachanna a nglactar leo                                                              |
| ------------------------------- | ------------------------------------------------------------------------------------- |
| `REQUIRE_API_KEY`               | `true`, `1` nó `yes` ar aon nós, na luachanna a láimhseálann an freastalaí mar atá ar |
| `LANG`, `LC_ALL`, `LC_MESSAGES` | suas le 64 litir, digit, `_`, `.`, `@` nó `-`                                         |
| `LANGUAGE`                      | mar an gcéanna, móide `:`                                                             |
| `TZ`                            | suas le 64 litir, digit, `_`, `+`, `-` nó `/`, gan tosú le `/`                        |
| `NO_COLOR`, `FORCE_COLOR`       | suas le 16 litir agus dhigit                                                          |

Cuireann gach luach a ghlacann `REQUIRE_API_KEY` an seic ar siúl, mar sin ní féidir leis an gcomhad an seic a mhúchadh féin. Ní chinneann sé an toradh, áfach: léann an freastalaí sáruithe `REQUIRE_API_KEY` atá stóráilte sa bhunachar sonraí roimh an timpeallacht, agus ní léann an rabhadh tosaithe faoi éisteacht ar gach comhéadain gan eochair API ach an timpeallacht. Nuair a sháraítear `false` stóráilte, fágann eolaire oibre `REQUIRE_API_KEY=true` an API ar oscailt agus cuireann sé an rabhadh sin i bhfolach. Tá an riail `TZ` níos cúinge ná POSIX: diúltaíonn sé `.`, `:`, `,` agus `<>`, mar sin ní mór an fhoirm `:Area/City` agus na rialacha mar `EST5EDT,M3.2.0,M11.1.0` a shocrú sa bhlaosc nó i `<DATA_DIR>/.env`.

Caithfidh na hainmneacha teacht go díreach, sa chás uachtair. Léirítear líne ar bith eile, luach nach dteipeann ar a sheic, agus ainm nach gnáthlitreacha ASCII, digití agus `_` (mar shampla ceann le beart NUL nó litir chomhchosúil). Priontálann an CLI rabhadh amháin a ainmníonn na heochracha nach féidir é a shocrú agus ceann a n-ainmníonn na heochracha a ndearna sé neamhaird orthu, agus gach ceann acu lena n-athruithe (`TZ (expected a zone name such as Europe/Berlin)`, `lang (write the name as LANG)`). Ní phrionnaíonn ceachtar acu na luachanna. Éalaítear cosáin comhaid sna teachtaireachtaí seo, agus tuairiscí cosán `.env` `omniroute doctor`, nuair a bhíonn carachtair rialaithe nó bidi iontu. Níl feidhm ag an srian nuair is eolaire sonraí nó eolaire pacáiste an t-eolaire oibre.

Níl `PORT`, `API_PORT` agus `DASHBOARD_PORT` ar an liosta. Gan bonn URL ó fhoinse tosaíochta níos airde, labhraíonn an CLI le `localhost:<PORT>`, agus cibé rud a éisteann ann faigheann sé eochair API an CLI, an comhartha comhthéacs agus an comhartha meaisín CLI (`x-omniroute-cli-token`, féach [CLI_TOKEN.md](../security/CLI_TOKEN.md) ), a ghlacann an freastalaí áitiúil le haghaidh glaonna bainistíochta ó loopback. Ligfeadh port ón eolaire oibre don chomhad sin an t-éisteoir a roghnú, mar sin socraigh na poirt sa bhlaosc, i `<DATA_DIR>/.env` nó leis an rogha `--port` d’orduithe a bhfuil ceann acu (`serve`, `launch`, `run`).

Níl aon chomhréir `export` ag an parsálaí. Ainmníonn líne mar `export LD_PRELOAD=...` athróg `export LD_PRELOAD`; as an eolaire oibre déantar é a dhéanamh, agus i gcomhaid `.env` eile socraíonn sé an t-ainm litriúil sin, rud nach léann aon rud.

Ní phéireálann an CLI comhartha stóráilte comhthéacs (comhartha rochtana nó eochair oidhreachta API ) ach le bunús an chomhthéacs sin féin: scéim, óstach agus port, i gcomparáid le `URL.origin`. Baineann sé seo le hiarratais a dhéantar trí chliant HTTP an CLI(`--base-url`, `OMNIROUTE_BASE_URL`, `omniroute connect <new-url>`) agus leis na horduithe `launch`, `launch codex`, `configure` agus `setup-*` a scríobh bonn URL agus eochair isteach i gcumraíocht uirlis eile. Dírithe ar fhreastalaí eile le `--remote`, úsáideann siad `--api-key` nó `OMNIROUTE_API_KEY` sainráite má tá ceann socraithe, agus gan aon comhartha comhthéacs. Tá an chomparáid chruinn, mar sin áirítear `localhost` agus `127.0.0.1`, nó óstach le ponc leanúnach agus gan é, mar fhreastalaithe éagsúla agus ní bhfaighidh tú comhartha comhthéacs. Ní mheaitseálann URL le userinfo, cúlslais nó spás bán, mar is féidir le parsálaithe URL eile (Python's `urllib` agus `httpx`, mar shampla) óstach difriúil a léamh uaidh. Maidir le hiarratais a sheolann an CLI féin, ní chlúdaíonn an tseiceáil sin ach an scéim agus an t-údarás, mar sin coinníonn aitheantas le spás sa chosán nó sa cheist an comhartha.
