Ceanglaíonn nód JSON API saincheaptha críochphointe gnó JSON nach labhraíonn an prótacal OpenAI nó Anthropic. Líonann OmniRoute teimpléad iarratais JSON, cuireann sé chuig an críochphointe iomlán URL, léann sé an freagra ó chonair freagartha agus cuireann sé ar ais chuig an gcliant é i bhformáid an chliaint féin (Críochnaithe Comhrá, Freagraí, Teachtaireachtaí, ...).

Is nód OpenAI-comhoiriúnach le `apiType: "custom-json"`; tá an fhoirm `openai-compatible-custom-json-<suffix>` ag a id. Níl foirm an deais ar fáil fós. Cruthaigh agus cuir na nóid seo in eagar tríd an soláthróir-nód API thíos.

## Cruthaigh nód

`POST /api/provider-nodes` (údar bainistíochta):

```json
{
  "type": "openai-compatible",
  "apiType": "custom-json",
  "name": "Business API",
  "prefix": "biz",
  "baseUrl": "https://api.example.com/v1/answer",
  "customHeaders": { "X-Tenant": "demo" },
  "customJson": {
    "method": "POST",
    "authType": "api-key",
    "authHeader": "X-Service-Key",
    "requestTemplate": {
      "project_id": "demo-project",
      "question": "{{prompt}}",
      "history": "{{messages}}"
    },
    "responsePath": "data.answer"
  }
}
```

- Tá `baseUrl` an** iomlán** críochphointe URL. Níl aon rud i gceangal leis (gan `/chat/completions`, gan `/models`) agus, murab ionann agus nóid eile atá comhoiriúnach le OpenAI, níl aon URL réamhshocraithe . Caithfidh sé a bheith `http(s)`, gan dintiúir leabaithe nó `#fragment`, agus téann sé an garda URL amach céanna le gach nód soláthraí, nuair a shábháiltear an nód agus ar gach iarratas.
- Caithfidh nód a sheolann an eochair cheangail (`authType` `bearer` nó `api-key`, an réamhshocrú san áireamh) úsáid a bhaint as `https://`. Glactar le `http://` plain ach amháin le haghaidh óstach loopback (`localhost`, `127.0.0.0/8`, `::1`) nó le `authType: "none"`, rud a sheolann gan eochair. Níl seoltaí príobháideacha LAN (`10.x`, `172.16-31.x`, `192.168.x`) díolmhaithe: d'fhéadfadh aon duine ar an líonra sin an eochair a léamh. Theipeann ar shábháil nód dá leithéid le `400`, agus theipeann ar nód a stóráiltear níos luaithe dúnta ar gach iarratas leis an teachtaireacht chéanna, sula seoltar aon iarratas. Le haghaidh críochphointe eochrach ar LAN, cuir taobh thiar TLS é (seachfhreastalaí droim ar ais mar shampla).
- déantar `customJson` a bhailíochtú le Zod; diúltaítear eochracha anaithnid. Tá gach réimse roghnach:

| Réimse            | Luachanna                                    | Réamhshocrú                                            |
| ----------------- | -------------------------------------------- | ------------------------------------------------------ |
| `method`          | `POST`, `PUT`, `PATCH`                       | `POST`                                                 |
| `authType`        | `bearer`, `api-key`, `none`                  | `bearer`                                               |
| `authHeader`      | ainm ceanntásc a úsáidtear nuair a `api-key` | `X-API-Key`                                            |
| `requestTemplate` | JSON (≤ 64 KB, doimhneacht ≤ 32)             | `{ "model": "{{model}}", "messages": "{{messages}}" }` |
| `responsePath`    | cosán réimse, nó `$` don chorp ar fad        | `choices[0].message.content`                           |

- Fanann an rún in eochair API an naisc, riamh sa teimpléad. cuireann `bearer` `Authorization: Bearer <key>`; Seolann `api-key` `<authHeader>: <key>`. Ní féidir `Host`, `Content-Type`, `Content-Length`, `Connection`, `Transfer-Encoding`, `Authorization`, `Cookie` nó hop-by-hop a bheith mar cheanntásc an údair. Le `none`, níl aon eochair ag teastáil ó naisc.
- Úsáideann ceanntásca breise statacha `customHeaders` rialta an nód (an bailíochtú céanna le gach nód comhoiriúnach eile; ní cheadaítear ceanntásca údaráis ann).

Glacann `PUT /api/provider-nodes/<id>` leis an `customJson` céanna agus athscríobhann sé `baseUrl` agus an cumraíocht ar gach nasc den nód atá ann cheana féin. Má fhágtar `customJson` ar lár coinnítear an cumraíocht stóráilte; Má aistrítear `apiType` go `chat` nó `responses` baintear é den nód agus óna naisc.

Ansin cuir nasc leis an nód mar is gnách (`POST /api/providers` leis an nód id ) agus iarr `<prefix>/<model>`, mar shampla `biz/assistant-v1`. Nochtann an críochphointe aon liosta samhlacha, mar sin cuir na haitheantas samhlacha de láimh.

## Teimpléid iarratais

Tá teimpléid simplí JSON. Féadfaidh marcóirí `{{placeholder}}` a bheith i luach teaghrán; ní dhéantar aon rud a mheas nó a fhorghníomhú, agus ní chuirtear eochracha oibiachta in ionad riamh.

| Áitsealbhóir         | Luach                                                                                   |
| -------------------- | --------------------------------------------------------------------------------------- |
| `{{prompt}}`         | Téacs na teachtaireachta úsáideora is déanaí (páirteanna téacs ceangailte le línte nua) |
| `{{messages}}`       | An comhrá i bhformáid OpenAI chat                                                       |
| `{{model}}`          | An t-aitheantas samhla iarrtha, gan an réimír soláthraí                                 |
| `{{stream}}`         | Freagraíonn `false` — an críochphointe i gcónaí le doiciméad JSON amháin                |
| `{{request.<path>}}` | Réimse den iarratas aistrithe (formáid comhrá OpenAI ).                                 |

- Coinníonn luach atá go díreach ar áitshealbhóir amháin a chineál JSON ( déantar `"{{messages}}"` mar eagar); cuirtear áitchoinneálaí taobh istigh de theaghrán níos faide isteach mar théacs.
- Teipeann ar áitshealbhóir a réiteoidh gan rud ar bith an t-iarratas le HTTP 400 in ionad pálasta neamhiomlán a sheoladh.
- Úsáideann cosáin nodaireacht poncanna agus innéacsanna uimhriúla (`data.items[0].text`). diúltaítear `__proto__`, `prototype` agus `constructor` in eochracha agus cosáin.

## Freagraí

Éiríonn an luach ag `responsePath` mar fhreagra an chúntóra: téann teaghráin tríd, déantar luachanna eile JSON a shraithiú. Filleann réimse ar iarraidh nó réimse `null`, nó comhlacht nach bhfuil JSON, HTTP 502. Cuirtear stádas earráide in aghaidh srutha trí. Do chliaint sruthaithe fanann OmniRoute leis an bhfreagra JSON iomlán agus ansin astaíonn sé mar smután ábhair amháin móide an smután bailchríoch; ní sruthú comhartha é seo. Níl glaonna uirlisí agus réimsí úsáide mapáilte.

## Ná replayed

Féadfaidh fo-iarmhairtí a bheith ag iarratas gnó fiú nuair a theipeann air. Mar sin seolann OmniRoute uair amháin é:

- gan atriail iompair agus gan aon atreorú ina dhiaidh;
- gan iarracht a dhéanamh ar nasc eile (aischur cuntais) — cuirtear an teip ar ais mar atá agus ní fhuaraítear an nasc;
- gan aon aisfhilleadh ar an gcéad sprioc teaglama eile, fiú i gcás freagra folamh nó freagra teipthe.

Iarrann cliant ar leith, agus painéil chomhleá a ghlaonn go sainráite ar roinnt samhlacha, an críochphointe go neamhspleách fós.

## Nód a thástáil

Sábháil nasc, an nasc** Tástáil** ní thugann seiceálacha sláinte cnaipe agus cúlra an críochphointe: ní dhéanann siad ach an cumraíocht stóráilte a bhailíochtú agus tuairiscíonn siad nach bhfuil an nasc infhíoraithe.

cuireann `POST /api/provider-nodes/validate` le `"apiType": "custom-json"` agus na réimsí nód (`baseUrl`, `apiKey`, `customJson`, `customHeaders` roghnach agus `modelId`) go díreach iarratas amháin fíor, le `ping` mar an téacs úsáideora is déanaí. Freagraíonn sé `{ "valid": true }` nó an stádas in aghaidh an tsrutha (ná an comhlacht in aghaidh an tsrutha).

## Stóráil

Stóráiltear an cumraíocht i `provider_nodes.custom_json_config_json` ( imirce `240_provider_node_custom_json_config.sql`) agus cóipeáiltear é isteach i `providerSpecificData.customJson` gach naisc .

Cur i bhfeidhm: `open-sse/utils/customJson.ts` (bailíochtú agus templating), `open-sse/executors/customJson.ts` (seiceadóir), `open-sse/services/combo/noReplayLatch.ts` agus `src/sse/handlers/chat/responsePolicies.ts` (gan aon athimirt).
