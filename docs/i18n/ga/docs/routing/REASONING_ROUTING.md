Leathnaíonn rialacha ródaithe réasúnaíochta an ródú samhla agus teaglama atá ann cheana. Nuair nach meaitseálann aon riail ghníomhach,
fanann an t-iompar reatha maidir le smaointeoireacht, iarmhír, réamhshocrú ceangail agus aistriú soláthraí
gan athrú.

## Bainistíocht

Tá bainistíocht rialacha ar fáil faoi **Socruithe → Ródú Domhanda**. Soláthraíonn eagarthóir na heochrach API an
comhéadan bainistíochta céanna agus é scagtha de réir na heochrach roghnaithe.

Nochtar an API bainistíochta trí na bealaí seo:

- `GET` agus `POST` ag `/api/settings/reasoning-routing-rules`
- `GET`, `PATCH`, agus `DELETE` ag `/api/settings/reasoning-routing-rules/[id]`
- `POST` ag `/api/settings/reasoning-routing-rules/simulate`

Úsáideann gach bealach `requireManagementAuth`. Déantar ionchuir a bhailíochtú leis na scéimeanna in
`src/shared/validation/schemas/reasoningRouting.ts`. Ní dhéanann an t-insamhlóir glao réamhtheachtach riamh.

## Réiteach Rialacha

Roghnaíonn an luathmheastóireacht riail amháin go díreach. Seiceáiltear scóip san ord seo:

1. `apiKey`
2. `combo`
3. `model`
4. `global`

Laistigh de scóip, bíonn bua ag `priority` níos airde ar dtús, agus ina dhiaidh sin ag meaitseáil bheacht samhla thar phatrún glob,
ansin ag ord cobhsaí `createdAt` agus `id`. Léitear `requestTags` go heisiach ó `metadata.tags`
agus tacaíonn siad le meaitseáil `any` nó `all`.

Ní mheastar riail `connection` ach amháin nuair nár bhuaigh aon riail luath agus nuair atá ceangal nithiúil soláthraí
roghnaithe cheana féin. Ní féidir léi ach an iarracht agus an buiséad a athrú.

## Iarracht agus Buiséad

Glacann `sourceEffort` `any`, `missing`, `none`, `low`, `medium`, `high`, `xhigh`, `max`, agus `ultra`. Ciallaíonn `missing` nach bhfuil iarracht scoite ná scorán smaointeoireachta nó buiséad smaointeoireachta san iarratas. Mar sin ní dhéantar comhartha buiséid amháin a mheaitseáil ach le `any`.

Tá trí leagan `effortMode` :

- Coinníonn `inherit` iarracht an chliaint agus é fós ag ligean don mhúnla nó don teaglama athrú.
- Ní shocraíonn `default` `targetEffort` ach amháin nuair nach bhfuil comhartha réasúnaíochta follasach ann.
- Cuirtear `force` in ionad na hiarrachta scoite `targetEffort`.

Go neamhspleách, is féidir `budgetAction` a bheith `preserve`, `remove`, nó `set`. Baineann `force` le `none` gach iarracht aitheanta agus réimsí buiséid, ansin socraíonn sé `reasoning_effort: "none"`, toisc go n-iompaíonn roinnt soláthraithe ag smaoineamh ar nuair a bhíonn an réimse as láthair. Coigeartaítear soláthraithe a dhiúltaíonn don `none` litriúil tráth seolta i `open-sse/executors/base/reasoningEffort.ts`. Mapálann an Cód Ordaithe go `low` é , ach amháin ar iarratais i gcruth Freagraí (`input` gan `messages`), áit a gcoinníonn sé `none`. Ar Oibrithe Cloudflare AI (`cloudflare-ai`), faigheann na samhlacha a dhiúltóidh `none` (gpt-oss, qwen3.8, nemotron-3, glm-4.7-flash) `low`; Oibrithe eile Coinníonn samhlacha AI `none`. Ní rogha é an réimse a scaoileadh ann, toisc go ritheann iarracht as láthair sraith réamhshocraithe an tsamhail. tá `none` mar aon le `set` neamhbhailí.

Diúltaítear iarratais a dhíríonn ar mhúnlaí aithnidiúla nach bhfuil comhoiriúnach leo roimh an nglao réamhtheachtacha. Maidir le spriocanna teaglama, baintear iontrálacha neamh-chomhoiriúnacha; mura bhfanann ceann ar bith, filleann an t-iarratas status `400`. Táirgeann sonraí cumais anaithnid rabhadh agus fágtar an riail gníomhach.

## Slándáil agus Iompar

Tá an tsamhail fhoinseach agus an tsamhail sprice, nó an teaglama foinseach agus an teaglama sprice, fós faoi réir pholasaí reatha na heochrach API.
Ní leathnaíonn riail réasúnaíochta ceadanna samhla, teaglama ná cuóta riamh.

Tá an t-inneall comhtháite le Chat Completions, Responses, Anthropic Messages, agus conair inmheánach
Codex WebSocket. Ní ghlacann conair WebSocket ach le spriocshamhlacha Codex; ní féidir spriocanna teaglama a
fhorghníomhú inti. Stóráiltear cinneadh na rialach sa rian bealaigh atá ann cheana gan rúin.

## Marthanacht

Cruthaíonn an t-aistriú `src/lib/db/migrations/126_reasoning_routing_rules.sql` an tábla
`reasoning_routing_rules`. Déanann rialacha tagairt d’eochracha API, teaglamaí agus ceangail soláthraí atá stóráilte.
Glanann scriosadh rialacha gaolmhara. Coinníonn an tsraith rochtana bunachar sonraí in
`src/lib/db/reasoningRoutingRules.ts` taisce in-neamhbhailithe do chonair an iarratais.

Cuirtear rialacha san áireamh i gcúltacaí SQLite, in easpórtáil iomlán an bhunachair sonraí, agus sa bheartán sioncrónaithe cumraíochta.
Díchumasaíonn `reconcileReasoningRulesForSync` rialacha iompórtáilte a bhfuil tagairtí in easnamh orthu agus tuairiscíonn sé na
coinbhleachtaí sin.
