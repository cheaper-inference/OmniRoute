seolann `copilot-m365-web` (alias `m365copilot`) iarratais chomhrá i bhformáid OpenAI trí sheisiún fíordheimhnithe Microsoft 365 Copilot ag `m365.cloud.microsoft/chat`. Is comhtháthú dúchasach neamhoifigiúil é seo: níl aon phróiseas seachfhreastalaí ar leith nó localhost in aghaidh an tsrutha ag teastáil. Níl aon athrú ar an soláthraí ID, ailias agus naisc allmhairithe atá ann cheana. Is soláthraí difriúil é `copilot-web` don tseirbhís do thomhaltóirí ag `copilot.microsoft.com`.

> **Nua do sholáthraithe Fianán Gréasáin?**
>
> Léigh**`docs/getting-started/WEB-COOKIE-GUIDE.md`** don phróiseas socraithe ginearálta, treoir fíordheimhnithe, teorainneacha, agus fabhtcheartú sula leanann tú an treoir seo a bhaineann go sonrach le soláthraí.
>
> **Le haghaidh allmhairí oidhreachta:** Is é an dintiúir don soláthraí seo** ní fianán** . Ná cóipeáil fianáin ó `m365.cloud.microsoft`. Is é an dintiúir paraiméadar ceiste WebSocket URL agus deighleog cosáin, an dá léamh ó chluaisín Líonra DevTools.

## Réamhriachtanais

- Cuntas Microsoft 365 le rochtain ar Copilot ag `m365.cloud.microsoft/chat`
- Brabhsálaí bunaithe ar chróimiam (Chrome, Edge) le haghaidh iniúchta DevTools WebSocket
- Rochtain ar an tsamhail iarrtha ar an gcuntas sin; athraíonn infhaighteacht de réir tionónta agus ceadúnais

## Síniú isteach dúchasach (cuntais oibre nó scoile)

Roghnaigh**Microsoft 365 Copilot → Ceangail** agus iarracht síniú isteach a ullmhú. Úsáideann an painéal sreabhadh cód údaraithe le PKCE; ní iarrann sé do phasfhocal Microsoft nó cód MFA.

1. Oscail a** cluaisín brabhsálaí bán** , ansin oscail**DevTools →** agus a chumasú** Caomhnaigh logáil** . Déan é seo sula dtéann tú chuig Microsoft: féadfaidh Windows SSO críochnú láithreach.
2. Cóipeáil an URL údaraithe atá léirithe ag an dialóg naisc agus nascleanúint chuige sa chluaisín ullmhaithe sin. Comhlánaigh roghnú cuntais Microsoft nó MFA má iarrtar é.
3. Sa loga líonra leasaithe, faigh an t-iarratas chun `https://login.microsoftonline.com/common/oauth2/nativeclient` agus cóip iomlán de** Iarratas URL** .
4. Greamaigh an URL sin isteach sa dialóg nasc agus ceangail. Ná greamaigh cód amh nó barra seoltaí `wrongplace` deiridh URL: is loingseoireacht neamhbhuan é an t-aisghlaoch a theastaíonn.

Téann gach iarracht in éag tar éis deich nóiméad agus ní féidir é a úsáid ach uair amháin. Seiceálann an freastalaí a staid, a fhíoraitheoir PKCE agus a sprioc athdheimhnithe sula malartaítear an cód. Tar éis dul in éag nó teip malairte, cuir tús le hiarracht nua. Ní féidir le hiarracht maireachtáil ar atosú freastalaí.

Úsáideann comharthaí an stór dintiúir naisc atá ann cheana agus an cosán athnuachana. Teastaíonn an t-aitheantas Microsoft tenant/object céanna, ní hamháin an ríomhphost céanna, chun nasc a athdheimhniú. Caomhnaíonn sé naming/settings oibreora agus cuireann sé ionad dintiúir allmhairithe as feidhm. Tá síniú isteach dúchasach do chuntais work/school ; tá an cosán iompórtála oidhreachta fós ar fáil do naisc reatha agus do chumraíochtaí sraithe tacaithe.

Is creidiúint aonuaire é an t-aisghlao iomlán URL. Ná cuir san áireamh i screenshots, logs, teachtaireachtaí tacaíochta nó gealltanais. Ní osclaíonn an sreabhadh seo brabhsálaí ar an bhfreastalaí, ní dhéanann sé iniúchadh ar stair do bhrabhsálaí, ná cuir tús le freastalaí aisghlaoite áitiúil.

## Gabháil dintiúir (modh WebSocket )

1. Sínigh isteach ag `https://m365.cloud.microsoft/chat` agus cuir tús le comhrá.
2. Oscail**DevTools →** .
3. Scag de réir**WS** (WebSocket).
4. Cliceáil ar an nasc Chathub WebSocket. Cuardaigh URL ag tosú le `wss://substrate.office.com/m365Copilot/Chathub/`.
5. Óna** Iarratas URL** , cóip:
   - Luach paraiméadar na ceiste `access_token` ( JWT gearrthéarmach).
   - Teascán cosán Chathub tar éis `/Chathub/` (m.sh. `<oid>@<tenant>`).

Tá an fhoirm ag an URL iomlán:

```
wss://substrate.office.com/m365Copilot/Chathub/<oid>@<tenant>?...&access_token=<jwt>
```

6. I OmniRoute, roghnaigh**Microsoft 365 Copilot** , roghnaigh an rogha oidhreacht API-key/import, agus greamaigh an dintiúir san fhormáid:

```
access_token=<jwt>; chathubPath=<oid>@<tenant>
```

7. Cliceáil** Ceangal Tástála** agus** Sábháil** .

## Gabháil dintiúir (iompórtáil HAR )

In ionad luachanna a chóipeáil de láimh ón WebSocket URL, is féidir leat comhad DevTools HAR a onnmhairiú:

1. Oscail**DevTools →** .
2. Tosaigh nó lean ar aghaidh le comhrá Microsoft 365 Copilot (spreagann sé seo an nasc WebSocket ).
3. Cliceáil ar dheis sa phainéal Líonra agus roghnaigh** Sábháil go léir mar HAR leis an ábhar** .
4. I OmniRoute, bain úsáid as an** Iompórtáil comhad .har** cnaipe ar an dialóg nasc soláthraí.

Déanann OmniRoute scanadh ar an HAR don Chathub WebSocket URL, sleachta as an `access_token` agus `chathubPath`, agus populates na réimsí inchreidte go huathoibríoch. Díchódaíonn an t-allmhairiú HAR an dul in éag JWT agus taispeánann sé an saolré chomhartha atá fágtha.

> **Ná déan fíor-onnmhairiú HAR, comhartha rochtana ná chomhartha athnuachana riamh.** Caithfidh luachanna tástála agus doiciméadaithe a bheith ina sealbhóirí áitribh i gcónaí.

## Comhartha saolré agus athnuachan

Tá an `access_token` gearr-chónaí (go hiondúil**~ 75 nóiméad** ). Gan chomhartha athnuachana inúsáidte, ní mór duit an dintiúr a ghabháil arís tar éis dul in éag.

### Athnuachan uathoibríoch le `refreshToken`

Sna soláthraí Microsoft 365** Cuir nasc leis** nó** Cuir nasc in eagar** dialóg, oscailte** Ardsocruithe → Athnuaigh comhartha (roghnach)** . Greamaigh comhartha athnuachana Microsoft OAuth don raon feidhme `substrate.office.com/sydney` agus sábháil. Déantar an t-ionchur a chumhdach agus ní chuirtear an comhartha stóráilte air roimh ré. Agus an eagarthóireacht á dhéanamh agat, fág bán é chun an comhartha reatha a choinneáil; greamaigh comhartha nua chun é a athsholáthar.

Faigheann síniú isteach dúchasach an comhartha athnuachana nuair a fhilleann Microsoft ceann. Maidir le hallmhairí oidhreachta, bain úsáid as deontas cód údaraithe Microsoft atá ag luí cheana féin; ní chuireann an soláthraí seo i bhfeidhm ná ní gheallann sé sreabhadh cód feiste. Le comhartha athnuachana cumraithe, seiceálann OmniRoute an `access_token` roimh iarratais agus ní athnuachan ach amháin nuair is gá é a athnuachan. Maireann athnuachan rathúil freisin ar an comhartha athnuachana rothlaithe, ag seachaint athghabháil láimhe fad is atá an comhartha athnuachana fós bailí.

Mura bhfuil `refreshToken` socraithe, ní mór duit an dintiúir WebSocket a athghabháil de láimh tar éis gach éaga.

### Roghnú sraithe

| Sraith       | Ailias              | Dromchla                |
| ------------ | ------------------- | ----------------------- |
| `individual` | _(réamhshocraithe)_ | Tomhaltóir M365 Copilot |
| `edu`        | `included`          | Oideachas M365 Copilot  |
| `enterprise` | `work`              | M365 Copilot don Obair  |

Socraigh an tsraith i** Ardsocruithe → Copilot tier** . Ní shocraíonn síniú isteach dúchasach é, mar sin ní mór do chuntas oibre `enterprise` ( alias `work`) agus cuntas oideachais `edu` a roghnú , freisin nuair a bhíonn múnla doiciméadaithe IDs á n-úsáid : roghnaíonn siad siúd a ton féin, a gcás agus a gcineál ceadúnais féin, ach tagann na roghanna gníomhaire agus agairt ón gciseal fós, agus is féidir go dteipeann ar thionónta oibre na mainneachtainí aonair. Ní dheonaítear ceadúnas eiseamláireach má dhéantar an tsraith a athrú. Tá tús áite ag sáruithe prótacail sainráite agus níor cheart iad a úsáid ach amháin nuair atá na luachanna sreinge riachtanacha ar eolas agat.

## Múnlaí agus ródú

Áirítear sa chatalóg dhúchasach gach IDs neamhspleách doiciméadaithe chomh maith leis na ceithre IDs dúchais bunaidh. Tá an chatalóg statach agus neamhspleách ar chuntas, ní fiosrú teidlíochta cuntais: fanann bealaí íoctha agus ailiasanna comhoiriúnachta liostaithe fiú nuair nach féidir le cuntas nasctha iad a úsáid. Fágann lipéid taispeána samhlacha ar lár an t-ainm soláthraí agus an pláta coire infhaighteachta in aghaidh an mhúnla; fanann an soláthraí**Microsoft 365 Copilot** . Lipéid marcáilte** Ailias** nó** Oidhreacht** a n-aitheantóirí reatha agus a mapálacha prótacail a choinneáil, ní ráthaíocht ar leagan samhail stairiúil. An seachfhreastalaí neamhspleách** Iompórtáil ó / samhlacha** ní bhaineann na treoracha leis an soláthraí dúchais WebSocket seo.

Cláraítear ailiasanna cosúil le `auto`, `quick`, `think-deeper`, agus ailiasanna leagan freisin. Tá na `copilot-m365`, `copilot-m365-claude-opus`, `copilot-m365-gpt-5-6-reasoning` agus `copilot-m365-gpt-5-5-chat` reatha fós bailí. Tá réimír an tsoláthraí (`copilot-m365-web/claude-opus` nó `m365copilot/claude-opus`) de dhíth ar an IDs doiciméadaithe : is focail chineálacha nó ainmneacha samhlacha díoltóirí eile iad go leor, mar sin coinníonn `claude-opus` lom ródú mar a dhéanann sé gan an soláthraí seo. Ní gealltanas é clárú go bhfreastalaíonn Microsoft an tsamhail sin do gach cuntas. Leanann an IDs neamhspleách [catalóg na bprótacail](https://github.com/cramt/m365-copilot-proxy/blob/main/packages/core/src/copilot.ts) phoiblí (an léarscáil múnla-go-ton easpórtáilte agus a meiteashonraí cásanna atá feasach ar mhúnla). Coinníonn gach próifíl dhúchasach `availability: "unverified"`; ní tástáil chuntais rathúil é cuimsiú sa chatalóg.

- Tugann eiseamláir shoiléir ar ais diúltú ceadúnais** 403** `m365_model_not_licensed`, not 502. Glais ródaithe a dhéanann péire connection/model, ag fágáil samhlacha ceadúnaithe ar an nasc inúsáidte.
- Is diúltú ceadúnais ar leibhéal cuntais é `InvalidCopilotLicense`, a thuairiscítear ar leithligh mar `m365_account_not_licensed`.
- Filleann scóigín in aghaidh an úsáideora** 429** `m365_throttled` agus fuaraíonn sé an nasc. Tuairisceáin ídithe rochtana tosaíochta** 429** `priority_access_exhausted` agus tá scóip shamhail aige. Toradh `OutOfCredits` le tuairisceáin `errorCode: "ReasoningTurnExhausted"`** 429** `reasoning_turns_exhausted` ina ionad sin, scóip samhail freisin, gan aon am athshocraithe á éileamh. Tuairiscíodh ar thionónta oibre amháin teorainn a chur leis na toin "Smaoinigh níos doimhne" fad is a bhí na toin Thapa ag freastal; breathnadóireacht tomhaltóra atá sa raon feidhme sin, ní rud atáirgeadh ag an stór seo. Mar sin tógann ródú na samhlacha doiciméadaithe eile Smaoinigh níos doimhne de `gpt-5.5` agus `gpt-5.6` as rothlú ar an nasc sin don fhuarú céanna, agus fágtar na toin Thapa agus gach teip eile ar a mhúnla féin. Coinnítear leideanna athiarrachta a chuirtear ar fáil; ní fhógraítear athshocrú ar iarraidh mar am athshocraithe aithnid.
- Tagann diúltú sábháilteachta Copilot (`Disengaged`) ar ais** 400** `provider_safety_rejection`, lipéad stop sábháilteachta an tsoláthraí roinnte. Ní chuirtear i gcoinne sláinte an naisc riamh é, ní bhainfidh cliant SDKs triail eile as 400, agus stopann ródú teaglama cumasaithe `PROVIDER_SAFETY_STOPS_TERMINAL` ann seachas an t-iarratas a athsheoladh i gcoinne sprice eile.
- Déantar iarratais ar nasc amháin a shraithiú tríd an seimeafóir cuntais reatha. B’fhearr cúl-ais tosaíochta seachas painéil chomhthreomhara; ní chuireann sraithiú amháin deireadh le teorainneacha ráta comhrá Microsoft.

## Iompar agus teorainneacha a iarraidh

- Tá uirlisí** pras-aithrise** , ní glaonna feidhm dúchais Microsoft. Úsáideann iarratas uirlis-chumasaithe giniúint mhaolánach amháin; ní chaitheann sé glúin eile ag roghnú uirlisí. Ní sheoltar ar ais mar ghlaonna ach uirlisí dearbhaithe a bhfuil cruthanna argóinte bailí tacaithe acu.
- Caomhnaítear freagra fada struchtúrtha agus sampla rianaithe amháin mar phrós. Is heorastúil é seo, ní cruthúnas ar intinn; caithfidh feidhmchláir a gceadanna uirlisí féin a fhorfheidhmiú fós.
- Oibríonn ionchur íomhá an bealach a sheolann an cliant gréasáin é. Uaslódáltar gach cuid íomhá (`image_url` mar sonraí URL nó URLHTTPS poiblí , nó Freagraí `input_image`) go `/m365Copilot/UploadFile` isteach i gcomhrá an cas leis an comhartha comhrá, agus díríonn an teachtaireacht uirthi le nóta `ImageFile` ; marcálann an téacs an áit a shuigh sé (`[image 1]`, …). Uaslódálann comhrá úrnua gach íomhá sa stair, ceann leanúnach ach íomhánna na dteachtaireachtaí nua. Suas le 10 íomhá PNG, JPEG, GIF nó WebP de 10 MiB an ceann ar a mhéad (40 MiB in aghaidh an iarratais); léitear an fhormáid ó na bearta. Faightear HTTPS URLs tríd an ngarda cianíomhá poiblí-amháin, pinnáilte DNS. Theip ar uaslódáil theip ar an iarratas (** 502** `m365_image_upload_failed`,** 400** `m365_image_rejected` nó `m365_image_invalid`); ní théann cas ar aghaidh gan íomhá a tugadh dó. Diúltaítear go sainráite do chodanna neamhthéacs eile (fuaime, comhaid), ní thittear go ciúin.
- Leanann iarratas leantach ar aghaidh leis an gcomhrá réamhtheachtacha céanna agus ní sheolann sé ach na teachtaireachtaí tar éis an fhreagra roimhe seo. Ní mór dó an freagra sin a leathnú go díreach: an nasc céanna, an phróifíl mhúnla agus an tacar uirlisí; stair gan athrú (slabhra sha256 thar gach teachtaireacht); agus aitheantais uirlis-ghlao an fhreagra, nó a théacs suas go spás bán. Cuireann aon rud eile (stair curtha in eagar, seisiún eile leis an gcéad teachtaireacht chéanna, freagra difriúil, comhrá díomhaoin ar feadh 30 nóiméad nó gar do chaipín 600 teachtaireacht Copilot, nasc gan aitheantas) tús le comhrá úr leis an stair iomlán. Ní atosaítear casadh ar theip air riamh, agus seolfar `InternalError` gan ábhar arís uair amháin i gcomhrá úr (** 502** `m365_internal_error` má theipeann air arís). Coinnítear leanúnachas i gcuimhne próisis: cuireann atosú tús le comhráite úra.
- Ritheann gach cas i gcomhrá sealadach Copilot(`disableMemory=1`): coinníonn an comhrá a chomhthéacs fad is a ritheann sé agus ní fheictear riamh é i stair chomhrá an chuntais. Mar sin d’fhéadfadh tástálacha múnla, Test All agus tástálacha teaglama an soláthraí seo a iniúchadh gan comhrá a fhágáil taobh thiar de.
- Tá spriocdháta díomhaoin 120 soicind ag baint le seal agus spriocdháta iomlán teoranta. Is é an transport/composer. dúchais a láimhseálann freagraí deiridh amháin, scagadh dul chun cinn agus cealú
- Coinníonn freagraí bunaithe ar an ngréasán a gcuid foinsí. marcálann Copilot lua ar aon dul le carachtair rialaithe úsáide príobháidí agus seolann sé na foinsí mar `references`; déantar nasc Markdown uimhrithe do gach marcóir (`[1](https://…)`, nó an URL lom nuair a d'úsáid Copilot an marcóir mar sprioc naisc) le nóta meaitseála `url_citation` (`message.annotations`, nó `delta.annotations` ar an smután ar a bhfuil an nasc). Ní thittear foinse nach dtagann choíche, agus mar sin ní shroicheann na marcóirí an cliant. Agus é á shruthú, fanann téacs tar éis lua go dtí go bhfuil a fhoinse sroichte.
- Cuirtear achoimre réasúnaíochta Copilot(`ChainOfThoughtSummary`), nuair a sheolann an tsamhail ceann, ar ais mar `reasoning_content`, ní mar chuid den fhreagra riamh. Achoimre a athscríobh féin stopann sruthú gan teip ar an cas.
- Roimh aon ábhar, coinníonn teipeanna licence/throttle HTTP 403/429 fiú nuair a iarradh sruthú. Tar éis don ábhar tosú, is imeachtaí earráide SSE iad teipeanna, ní bailchríoch rathúil riamh iad. Is earráid shoiléir srutha é athscríobh in aghaidh srutha nach féidir a léiriú le sruthú aguisín amháin; coinníonn freagairtí neamhshruthaithe agus uirlisí maolánacha an téacs deiridh.
- Nuair a dhiúltaíonn Copilot don nasc féin, tuairiscítear a fhreagra mar atá:** 401** `m365_unauthorized` le haghaidh síniú isteach diúltaithe nó imithe in éag (sínigh isteach arís),** 429** lena `Retry-After` do throttling, agus teip chroitheadh láimhe ar shlí eile, riamh teip nasc cineálach.

## Giniúint íomhá

Tarraingíonn `POST /v1/images/generations` le `model: "copilot-m365-web/m365-copilot-image"` (alias `m365copilot/m365-copilot-image`) leis an uirlis íomhá ionsuite Copilot, mar a dhéanann an cliant gréasáin. Is cas Copilot amháin atá i ngach íomhá: glacann sé leis na tacair rogha íomhá an chliaint gréasáin agus dearbhaíonn sé `GenerateGraphicArt`, agus tagann an íomhá ar iontráil dul chun cinn a dhíríonn ar dhéantán ar sheirbhís Dearthóir Microsoft. Diúltaíonn an déantán sin an comhartha comhrá, mar sin gearrann OmniRoute chomhartha Dearthóir ó chomhartha athnuachana an naisc agus íoslódálann sé na bearta; ní sheoltar an comhartha ach chuig `designerapp.officeapps.live.com` riamh.

- Teastaíonn nasc síniú isteach dúchasach (comhartha athnuachana); theipeann ar chomhartha pasted le** 400** sula gcaitear aon seal.
- Is é `n` 1–4, cas amháin an ceann. ní stiúrann `size` ach treoshuíomh (níos leithne, níos airde nó cearnógach), a léann Copilot ón leid; Roghnaíonn Copilot an méid rindreála.
- Seoltar íomhánna ar ais inlíne: `b64_json` de réir réamhshocraithe, URL sonraí le haghaidh `response_format: "url"`.
- Tarraingíonn íomhánna ginte ar bhuiséad beag laethúil, scartha ón gcomhrá. Nuair a úsáidtear suas é ní theipeann ar an iarratas** 429** . Theipeann ar sheal a fhreagraíonn gan íomhá** 502** (nó** 400** /** 503** nuair a léann téacs Copilot’ mar dhiúltú nó fadhb acmhainne); deir an teachtaireacht cé acu.

## Múnla slándála

- **Comhtháthú neamhoifigiúil.** Déanann an soláthraí seo an prótacal BizChat WebSocket a aisiompú. Féadfaidh sé briseadh gan fógra nuair a athraíonn Microsoft an críochphointe.
- Léiríonn an bhratach `subscriptionRisk: true` go mbraitheann an comhtháthú ar chríochphointe gan doiciméid. Is féidir srianta cuntais ach níl siad deimhnithe.
- Is JWT gearrchónaí é an comhartha rochtana. Caitheamh leis mar fhocal faire: ná geall leis, ná logáil isteach ná é a roinnt.
- Tugann an comhartha athnuachana rochtain leanúnach ar dhromchla Microsoft 365. Déan é a stóráil leis an gcúram céanna le heochair API.

## Fabhtcheartú

### Teipeann ar fhíordheimhniú láithreach

- Fíoraigh gur chóipeáil tú ón**WebSocket URL** , ní ó iarratas XHR/Fetch. Tá an dintiúir i bparaiméadar fiosrúcháin `access_token` den nasc Chathub WebSocket — nach bhfuil i gceanntásc `Authorization: Bearer`.
- Cinntigh go n-áirítear sa `chathubPath` an deighleog iomlán `<oid>@<tenant>` ón gcosán URL.

### Téann Token in éag tar éis ~ 75 nóiméad

Táthar ag súil leis seo. Gan `refreshToken`, tá an comhartha rochtana gearrthéarmach. Ceachtar:

- Athghabh an dintiúir ó DevTools, nó
- Cumraigh** Ardsocruithe → Athnuaigh comhartha (roghnach)** sa nasc Cuir leis nó Cuir in Eagar dialóg le haghaidh athnuachan uathoibríoch.

### Gabhann Tástáil Connect ach filleann comhrá 401

Chun nasc a cruthaíodh le** Sínigh isteach le Microsoft** , Seiceálann Test Connection dul in éag an chomhartha rochtana agus déanann sé chomhartha in éag a athnuachan leis an chomhartha athnuachana stóráilte, agus mar sin deimhníonn tástáil pas go bhfuil an comhartha athnuachana fós ag obair.

Le haghaidh dintiúir ghreamaithe, seiceálann Test Connection cruth an dintiúr agus, nuair a iompraíonn an comhartha dul in éag, nach bhfuil an comhartha a d’úsáidfeadh an soláthraí imithe in éag (buaigh chomhartha stóráilte an cheangail sean-ghreamú; áiríonn chomhartha athnuachana mar inathnuaite). Gabhann comhartha a chúlghairtear sula dtéann sé in éag sa tástáil; Filleann comhrá ansin** 401** `m365_unauthorized`. Úsáid** Sínigh isteach le Microsoft** arís, nó athghabháil dintiúir úr.

### Níl Copilot le feiceáil sa liosta soláthraithe

A chinntiú go bhfuil `copilot-m365-web` cumasaithe i** Soláthraithe Deais →** . Féadfaidh an soláthraí a bheith i bhfolach de réir réamhshocraithe i roinnt sraitheanna.
