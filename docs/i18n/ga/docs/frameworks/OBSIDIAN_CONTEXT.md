## Céard atá ann

Nascann OmniRoute le taisce **Obsidian** mar **fhoinse comhthéacs** — bunachar eolais
Markdown áitiúil a léann agus a scríobhann gníomhairí tríd an bhfreastalaí MCP ionsuite.
Déanann an comhtháthú cumarsáid leis an mbreiseán pobail **Obsidian Local REST API** atá
ag rith laistigh den aip deisce, ionas gur féidir le gníomhairí nótaí a chuardach,
comhaid a léamh/a scríobh/a phaisteáil, inneachar na taisce a liostú, oibriú le nótaí
tréimhsiúla laethúla/seachtainiúla, clibeanna a bhainistiú, orduithe Obsidian a rith,
agus (go roghnach) sioncronú déthreoch taisce idir ríomhaire deisce agus gléas móibíleach
a chomhordú.

Cuimsíonn an cliant (`src/lib/obsidian/api.ts`) an Local REST API leis na gnéithe seo:

- **Atriail le cúlú** i gcás earráidí sealadacha `5xx`, agus **teorainn ama 30 soicind**
  trí `AbortController`.
- **Aicmiú earráidí clóscríofa** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`.
- Leid sholéite **“ní féidir Obsidian a bhaint amach”** a luann an botún coitianta maidir
  leis an bport (HTTP ar `27123`, **ní** an críochphointe MCP ar `27124`) agus an
  fhoirm Tailscale.
- **Ionchódú conairí** i gcoibhneas leis an taisce, ionas go mbeidh conairí nótaí ina
  bhfuil spásanna/slais sábháilte.

## Socrú

Níl **aon athróg timpeallachta** ann do cheadchomhartha Obsidian ná don bhun-URL — stóráiltear
an dá cheann i dtábla SQLite `key_value` (ainmspás `obsidian`) trí
`src/lib/db/obsidian.ts`. Tá an ceadchomhartha **criptithe agus é stóráilte** (AES-256-GCM, le
cúltaca comhoiriúnachta siarghabhála i ngnáth-théacs). Cumraigh é ón gcluaisín **Foinsí Comhthéacs**
ar phainéal Endpoint (`ObsidianSourceCard`), nó trí REST API na socruithe.

> [!IMPORTANT]
> Ní mór an breiseán **Obsidian Local REST API** a bheith suiteáilte agus ag rith. Éisteann a chomhéadan
> REST ar **HTTP `127.0.0.1:27123`** (an bun-URL réamhshocraithe). Is críochphointe
> MCP/HTTPS _ar leith_ é port `27124`, agus diúltaíonn bealach na socruithe dó go sainráite.
> Má táthar ag nascadh ó ghléas eile, úsáid `http://<tailscale-ip>:27123`.

### Eochracha cumraíochta (SQLite `key_value`, ainmspás `obsidian`)

| Eochair           | Cuspóir                                                                      | Criptithe |
| ----------------- | ---------------------------------------------------------------------------- | --------- |
| `api_key`         | Ceadchomhartha iompróra don Local REST API                                   | tá        |
| `base_url`        | Bun-URL REST (réamhshocrú `http://127.0.0.1:27123`)                          | níl       |
| `vault_path`      | Conair absalóideach chuig eolaire an taisceadáin (le haghaidh sioncronaithe) | níl       |
| `webdav_username` | Ainm úsáideora WebDAV ginte (sioncronú taisceadáin)                          | níl       |
| `webdav_password` | Focal faire WebDAV ginte (sioncronú taisceadáin)                             | tá        |
| `webdav_enabled`  | Cé acu atá sioncronú taisceadáin WebDAV cumasaithe                           | níl       |

### Cumrú trí REST

```bash
# Sábháil + bailíochtaigh ceadchomhartha an Local REST API (bailíochtaíonn POST trí sheiceáil stádais)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# Seiceáil stádas an naisc (seoltar connected, hasToken, baseUrl, vaultPath ar ais)
curl http://localhost:20128/api/settings/obsidian

# Dícheangail (glanann sé an ceadchomhartha stóráilte)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

Éilíonn gach modh fíordheimhniú don phainéal. Diúltaíonn `POST` d'aon URL ar phort `27124`
agus bailíochtaíonn sé an ceadchomhartha trí chríochphointe stádais an Local REST API a ghlaoch sula ndéantar é a bhuanú.

### Sioncronú taisceadáin WebDAV

Bainistíonn `src/app/api/settings/obsidian/webdav/route.ts` sioncronú roghnach taisceadáin
le tacaíocht WebDAV (arna thiomáint ag `src/lib/obsidianSync.ts`). Nuair a chumasaítear é, dírítear OmniRoute ar
eolaire taisceadáin áitiúil agus gintear péire randamach ainm úsáideora/focal faire WebDAV:

```bash
# Cumasaigh sioncronú WebDAV d'eolaire taisceadáin (gintear ainm úsáideora/focal faire)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# Faigh stádas sioncronaithe WebDAV (ní sheoltar dintiúir ar ais ach nuair atá sé cumasaithe)
curl http://localhost:20128/api/settings/obsidian/webdav

# Díchumasaigh sioncronú WebDAV (glanann sé dintiúir + .stignore bainistithe)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### Slándáil & Iompar

forfheidhmíonn fíordheimhniú WebDAV rianú teip in aghaidh an IP agus frithdhúnadh (spreagann 10 n-iarracht theip laistigh d'fhuinneog 60 soicind frithdhúnadh 5 nóiméad le `429 Too Many Requests` agus `Retry-After`). Toisc go dtarchuireann WebDAV dintiúirí fíordheimhnithe Bunúsacha, moltar go láidir deireadh a chur le TLS (nó ródú thar thollán slán mar Tailscale nó Cloudflare Tunnel) agus rochtain á fháil ar an gcríochphointe WebDAV lasmuigh de loopback.

### Foinse chomhthéacs de réir eochair API (roghnach)

Is féidir cumraíocht Obsidian a scóipeáil **de réir eochair API** tríd an tábla `api_key_context_sources`
(`src/lib/db/apiKeyContextSources.ts`). Nuair a bhíonn aitheantas eochrach API fíordheimhnithe ag glao MCP,
tugann `getObsidianConfigForApiKey()` tús áite do cheadchomhartha/bhun-URL/conair-taisceadáin na heochrach sin féin
(`source: "api_key"`) agus, murach sin, téann sé ar ais chuig an gcumraíocht dhomhanda (`source: "global"`).

Éilíonn uirlisí MCP nach mbaineann le sioncronú aitheantas glaoiteora réitithe sula léitear an chumraíocht seo.
Faigheann glaoiteoir gan aitheantas `Obsidian API token not configured`, agus ní sheoltar aon iarratas chuig an taisceadán.
Réitíonn glaoiteoirí HTTP trí dhintiúir a n-iarratais; is féidir le glaoiteoirí stdio réiteach trí
`OMNIROUTE_API_KEY` nó `ROUTER_API_KEY`. Ní féidir le glaoiteoir HTTP neamhréitithe
aitheantas timpeallachta an fhreastalaí a oidhreacht. Ní údaraíonn aitheantais ionadchoinneála amháin
rochtain; tá tacaíocht fós ann do dhintiúr bailí timpeallachta a réitíonn go `env-key`.
Coinníonn eochracha fíordheimhnithe nach bhfuil cumraíocht Obsidian in aghaidh na heochrach acu an cúltaca domhanda.
Coinníonn na ceithre uirlis `obsidian_sync_*` a n-iompar ceadchomhartha sioncronaithe ar leith.

## uirlisí MCP (22)

Sainithe in `open-sse/mcp-server/tools/obsidianTools.ts`. Réitítear na token/base-URL in aghaidh an ghlao (in aghaidh an API-eochair ar dtús, ansin domhanda). Uirlisí a bhuaileann an OmniRoute** freastalaí sioncronaithe** (na ceithre uirlis `obsidian_sync_*` ) chomh maith leis sin teastaíonn an comhartha sync auth atá cumraithe i socruithe OmniRoute.

### Léigh uirlisí (`read:obsidian`)

| Uirlis                       | Cur síos                                                                                                     |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `obsidian_check_status`      | Seiceáil an bhfuil an logánta REST API insroichte agus fíordheimhnithe.                                      |
| `obsidian_search_simple`     | Cuardach téacs iomlán ar ábhar nótaí; filleann sé blúirí le conairí comhaid.                                 |
| `obsidian_search_structured` | Cuardaigh le slonn loighic JSON (scagairí and/or/regex/path ).                                               |
| `obsidian_read_note`         | Léigh nóta de réir cosán a bhaineann le cruinneachán; go roghnach heading/block/frontmatter. ar leith        |
| `obsidian_list_vault`        | Liostaigh comhaid agus eolairí sa cruinneachán (crann na n-iontrálacha).                                     |
| `obsidian_get_document_map`  | Faigh struchtúr ceannteidil an nóta mar léarscáil de na ceannteidil → line numbers.                          |
| `obsidian_get_note_metadata` | Faigh ábhar tosaigh, clibeanna, naisc, comhaireamh char/word gan an t-ábhar iomlán.                          |
| `obsidian_get_active_file`   | Faigh inneachar + cosán an chomhaid atá gníomhach faoi láthair i Obsidian.                                   |
| `obsidian_get_periodic_note` | Faigh an nóta tréimhsiúil daily/weekly/monthly le haghaidh dáta (inniu má fágtar ar lár é).                  |
| `obsidian_get_tags`          | Déan liosta de na clibeanna cruinneachán go léir agus a gcuid minicíochtaí.                                  |
| `obsidian_list_commands`     | Liostaigh ordú Obsidian IDs atá ar fáil (úsáid le `obsidian_execute_command`).                               |
| `obsidian_sync_status`       | OmniRoute stádas freastalaí sioncronaithe: rith, ainm cruinneachán, port, Aga fónaimh, sioncrónú deireanach. |
| `obsidian_sync_conflicts`    | Liostaigh coinbhleachtaí sioncronaithe gan réiteach (cosán, cosán coinbhleachta, braite-at).                 |

### Scríobh uirlisí (`write:obsidian`)

| Uirlis                           | Cur síos                                                                                               |
| -------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `obsidian_write_note`            | Cruthaigh nó scríobh nóta le hábhar Markdown tugtha.                                                   |
| `obsidian_append_note`           | Cuir ábhar le nóta; go roghnach chuig heading/block. ar leith                                          |
| `obsidian_patch_note`            | Máinliachta append/prepend/replace ag ceannteideal, bloc, nó réimse tosaigh.                           |
| `obsidian_delete_note`           | Scrios nóta as an cruinneachán go buan.                                                                |
| `obsidian_move_note`             | Bog nó athainmnigh nóta laistigh den chruinneachán.                                                    |
| `obsidian_execute_command`       | Rith ordú Obsidian trína ordú ID.                                                                      |
| `obsidian_open_file`             | Oscail comhad i Obsidian (cruthaítear é mura bhfuil sé ann).                                           |
| `obsidian_sync_trigger`          | Spreag sioncronú cruinneachán soghluaiste déthreo láithreach ↔.                                        |
| `obsidian_sync_resolve_conflict` | Réitigh coinbhleacht sioncronaithe: coinnigh `local` (soghluaiste), `remote` (deisce), nó `keep-both`. |

> [!NOTE]
> Glacann spriocanna `obsidian_patch_note` `targetType` de `heading | block | frontmatter` agus `operation` de `append | prepend | replace`, le `createTargetIfMissing` roghnach. Labhraíonn na ceithre uirlis `obsidian_sync_*` leis an bhfreastalaí sioncronaithe áitiúil (`http://127.0.0.1:27781` de réir réamhshocraithe) agus teastaíonn an comhartha sioncronaithe.

### Scóip

Éilíonn uirlisí Léigh `read:obsidian`; scríobh uirlisí gá `write:obsidian`. Tá an forfheidhmiú comhionann le Notion — láimhsithe ag `withScopeEnforcement()` in `open-sse/mcp-server/server.ts`, gated ar `OMNIROUTE_MCP_ENFORCE_SCOPES=true` agus iachall ar do ghlaoiteoirí HTTP/SSE a bhfuil easpa `manage`/`admin` ar a n-eochair API, le scóipeanna ceadaithe arna bhfoinsiú ó `OMNIROUTE_MCP_SCOPES` nó ó chomhthéacs scóip na heochrach API. Féach [MCP-SERVER.md](./MCP-SERVER.md).

## Críochphointí

| Modh     | Conair                          | Cuspóir                                                              |
| -------- | ------------------------------- | -------------------------------------------------------------------- |
| `GET`    | `/api/settings/obsidian`        | Seol `{ connected, hasToken, baseUrl, vaultPath }` ar ais.           |
| `POST`   | `/api/settings/obsidian`        | Sábháil + bailíochtaigh an comhartha (diúltaítear do phort `27124`). |
| `DELETE` | `/api/settings/obsidian`        | Dícheangail (glan an comhartha stóráilte).                           |
| `GET`    | `/api/settings/obsidian/webdav` | Stádas sioncronaithe WebDAV + dintiúir (fad atá sé cumasaithe).      |
| `POST`   | `/api/settings/obsidian/webdav` | Cumasaigh sioncronú WebDAV do chomhadlann taisce.                    |
| `DELETE` | `/api/settings/obsidian/webdav` | Díchumasaigh sioncronú WebDAV.                                       |

> Is bealaí socruithe don deais iad seo. Sroichtear an taisce féin trí Local REST API
> Obsidian (an `base_url` cumraithe) agus trí na huirlisí MCP thuas — níl aon
> chríochphointe seachfhreastalaí poiblí Obsidian `/v1` ann.

## Cásanna úsáide

- **Freagraí bunaithe ar an taisce** — `obsidian_search_simple` / `obsidian_search_structured`
  agus ansin `obsidian_read_note`, ionas go bhfreagraíonn gníomhaire ó do chuid nótaí féin.
- **Cumadh nótaí / iriseoireacht** — `obsidian_write_note`, `obsidian_append_note`, nó
  an uirlis bheacht `obsidian_patch_note` chun aschur gníomhaire, achoimrí, nó nótaí laethúla
  (`obsidian_get_periodic_note`) a thaifeadadh sa taisce.
- **Nascleanúint na taisce** — `obsidian_list_vault`, `obsidian_get_document_map`, agus
  `obsidian_get_tags` chun an struchtúr a iniúchadh roimh léamh/scríobh.
- **Uathoibriú Obsidian** — `obsidian_list_commands` + `obsidian_execute_command` chun
  breiseáin/orduithe a rialú ó ghníomhaire; `obsidian_open_file` chun nóta a thaispeáint sa chomhéadan úsáideora.
- **Sioncronú móibíleach** — cumasaigh sioncronú WebDAV, ansin `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`
  chun ríomhaire deisce↔gléas móibíleach a chomhordú agus coinbhleachtaí a réiteach.
