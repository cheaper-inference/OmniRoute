> **Foinse na fírinne:** `src/lib/plugins/` (`marketplace.ts`, `manager.ts`, `manifest.ts`,
> `scanner.ts`, `loader.ts`), `src/app/api/plugins/`, agus
> `src/app/(dashboard)/dashboard/plugins/`
> **Nuashonraithe go deireanach:** 2026-06-28 — v3.8.40

Tagann OmniRoute le córas breiseán ar nós WordPress. Is eolairí féinchuimsitheacha
iad na breiseáin — agus forléiriú `plugin.json` agus comhad iontrála ag gach ceann acu — a
nascann leis an bpíblíne iarratais (`onRequest` / `onResponse` / `onError`) agus le
teagmhais saolré (`onInstall` / `onActivate` / `onDeactivate` / `onUninstall`).

Is é **Margadh na mBreiseán** an tsraith aimsithe atá ar bharr an chórais sin. Cuireann sé
catalóg inbhrabhsáilte de bhreiseáin insuiteáilte ar fáil. De réir réamhshocraithe, is
clárlann síl bheag ionsuite í an chatalóg; is féidir le hoibreoir í a dhíriú ar URL clárlainne
cianda saincheaptha, agus sa chás sin déantar an t-aisghabháil a chruachan le cosantóir SSRF
a réitíonn DNS (féach [Slándáil](#security)).

Is **don lúb siar amháin** gach bealach breiseáin (Sraith 1 — `LOCAL_ONLY`): lódálann
agus ritheann breiseáin cód i bpróisis mhic, mar sin ní féidir na bealaí a bhaint amach ó
fhoinse nach lúb siar í, beag beann ar fhíordheimhniú. Féach
[`docs/security/ROUTE_GUARD_TIERS.md`](../security/ROUTE_GUARD_TIERS.md).

## Conas a oireann sé Together

```
Dashboard (/dashboard/plugins)
  ├─ "Installed" tab  → GET /api/plugins            (listPlugins)
  │                     POST /api/plugins/scan      (pluginManager.scan)
  │                     POST /api/plugins/{name}/activate|deactivate
  │                     DELETE /api/plugins/{name}   (uninstall)
  └─ "Marketplace" tab → GET /api/plugins/marketplace
                          → listMarketplacePlugins()
                            ├─ no custom URL → built-in SEED_REGISTRY
                            └─ custom URL → isSafeMarketplaceUrl() SSRF guard
                                          → safeOutboundFetch(guard:"public-only")
```

- **Ciseal clárlainne** — `src/lib/plugins/marketplace.ts`: liostaíonn / cuardaigh an chatalóg, ag titim ar ais go dtí an chlár síl ar aon teip.
- **Ciseal saolré** — `src/lib/plugins/manager.ts` (`pluginManager` singleton): suiteáil, uasghrádú, gníomhachtú, díghníomhachtú, díshuiteáil, scanadh, ualach tosaithe.
- **Ciseal follasach** — `src/lib/plugins/manifest.ts`: scéimre Zod + réamhshocraithe le haghaidh `plugin.json`.
- **Scanóir** — `src/lib/plugins/scanner.ts`: aimsíonn sé forlíontáin ar diosca faoin eolaire breiseán.
- **lódóir** — `src/lib/plugins/loader.ts`: sceitheann sé gach breiseán i bpróiseas linbh Node.js ar leith agus déanann bróicéirí glaonna thar IPC. Ní bosca gainimh é an leanbh (féach "Aonrú forghníomhaithe breiseán" thíos).

## Catalóg an Mhargaidh

Tugann `listMarketplacePlugins()` (`src/lib/plugins/marketplace.ts`) liosta de
réada `MarketplaceEntry` ar ais:

| Réimse        | Cineál   | Nótaí                                                 |
| ------------- | -------- | ----------------------------------------------------- |
| `name`        | string   | Ainm breiseáin i gcás kebab                           |
| `version`     | string   | semver                                                |
| `description` | string   | Achoimre ghairid                                      |
| `author`      | string   | Údar / eagraíocht                                     |
| `license`     | string   | Aitheantas ceadúnais ar nós SPDX                      |
| `downloadUrl` | string   | URL íoslódála foinse (d'fhéadfadh sé a bheith folamh) |
| `repository`  | string?  | URL roghnach stórtha                                  |
| `tags`        | string[] | Clibeanna cuardaigh/scagtha                           |
| `downloads`   | number   | Líon íoslódálacha                                     |
| `rating`      | number   | 0–5                                                   |
| `verified`    | boolean  | An bhfuil an iontráil marcáilte mar fhíoraithe        |
| `lastUpdated` | string   | Teaghrán dáta ar nós ISO                              |

Nuair nach bhfuil URL clárlainne saincheaptha cumraithe, is í an `SEED_REGISTRY`
ionsuite an chatalóg (`request-logger`, `rate-limiter`, `cost-tracker`, agus
`theme-manager` faoi láthair). Bíonn an chlárlann síl ar fáil i gcónaí — má tá clárlann
chianda chumraithe doshroichte, má thugann sí stádas nach `200` é ar ais, nó má thugann sí
corp neamhaitheanta ar ais, logálann `listMarketplacePlugins()` rabhadh agus téann sé ar
ais chuig an liosta síl.

> Nóta: tá **catalóg** an mhargaidh (brabhsáil/cuardach) ceangailte ó cheann ceann, ach
> níl **suiteáil** aonchliceáil ón gcatalóg curtha i bhfeidhm fós — taispeánann cnaipe
> "Suiteáil" na deaise ar iontráil sa mhargadh fógra "ag teacht go luath" faoi láthair.
> Déantar an tsuiteáil inniu trí shreabhadh suiteála an chosáin logánta
> (`POST /api/plugins`) agus trí aimsiú ar an diosca (`POST /api/plugins/scan`).

## REST API

Teastaíonn údarás bainistíochta (`requireManagementAuth`) ó gach críochphointe** agus** atá liostaithe in `/api/plugins` `src/server/authz/routeGuard.ts` `LOCAL_ONLY_API_PREFIXES` `/api/plugins/` — amháin.

| Críochphointe                      | Modh   | Cur síos                                                             |
| ---------------------------------- | ------ | -------------------------------------------------------------------- |
| `/api/plugins`                     | GET    | Liostaigh breiseán suiteáilte (scagaire `?status=` roghnach)         |
| `/api/plugins`                     | POST   | Suiteáil breiseán ón eolaire foinsí breiseán                         |
| `/api/plugins/scan`                | POST   | Scan an t-eolaire breiseán agus cláraigh forlíontáin nua             |
| `/api/plugins/marketplace`         | GET    | Liostaigh iontrálacha catalóg an mhargaidh                           |
| `/api/plugins/marketplace/install` | POST   | Suiteáil breiseán margadh de réir ainm                               |
| `/api/plugins/[name]`              | GET    | Faigh sonraí breiseán suiteáilte                                     |
| `/api/plugins/[name]`              | DELETE | Díshuiteáil breiseán                                                 |
| `/api/plugins/[name]/activate`     | POST   | Gníomhachtaigh (luchtaigh crúcaí clár + )                            |
| `/api/plugins/[name]/deactivate`   | POST   | Díghníomhachtaigh (fire `onDeactivate`, crúcaí díchláraigh)          |
| `/api/plugins/[name]/config`       | GET    | Faigh an breiseán config + config scéimre                            |
| `/api/plugins/[name]/config`       | PUT    | Nuashonraigh cumraíocht an bhreiseáin (deimhnithe i gcoinne scéimre) |

Glacann an scagaire `GET /api/plugins` `status` le ceann de `installed` / `active` / `inactive` / `error`. Filleann luach neamhbhailí `400`.

### Liosta breiseán suiteáilte

```bash
curl http://localhost:20128/api/plugins \
  -H "Cookie: auth_token=..."
```

### Suiteáil ó chosán áitiúil

```bash
curl -X POST http://localhost:20128/api/plugins \
  -H "Cookie: auth_token=..." \
  -H "Content-Type: application/json" \
  -d '{ "path": "/absolute/path/to/my-plugin" }'
```

Caithfidh an `path` a bheith ina** iomlán** cosán chuig eolaire** laistigh den eolaire foinsí breiseán** : `plugin-sources` in aice le fréamh an bhreiseáin, mar sin `~/.omniroute/plugin-sources/` de réir réamhshocraithe, nó `<parent of OMNIROUTE_PLUGINS_DIR>/plugin-sources/` nuair a bhíonn an athróg sin socraithe (`getPluginSourcesDir()` in `src/lib/plugins/installSource.ts`). Cóipeáil nó clónáil an breiseán ansin ar dtús. Diúltaítear don suiteáil le `400` nuair a bhíonn `..` nó beart null sa chonair, suite taobh amuigh den chomhadlann sin, réitíonn sé taobh amuigh de trí nasc simplí, nuair a bhíonn nasc nasc ann a bhfuil a sprioc lasmuigh de, nó nuair nach bhfuil an t-eolaire ann. Caithfidh `plugin.json` bailí (nó a bheith ina thuismitheoir ag duine amháin) a bheith san eolaire foinse. Nuair a éiríonn leis is é an freagra `201` leis an tsraith breiseán suiteáilte.

Murab ionann agus na bealaí breiseán eile, éilíonn an ceann seo an dintiúr bainistíochta (seisiún deais nó eochair API le scóip bhainistiú) fiú nuair a bhíonn logáil isteach díchumasaithe (`requireLogin=false`): ní gníomh anaithnid é an cód a shuiteáil riamh. Baineann an rud céanna le `POST /api/plugins/marketplace/install` ( comhlacht `{ "name": "<plugin>" }`).

### Brabhsáil an margadh

```bash
curl http://localhost:20128/api/plugins/marketplace \
  -H "Cookie: auth_token=..."
```

### Nuashonraigh config breiseán

```bash
curl -X PUT http://localhost:20128/api/plugins/my-plugin/config \
  -H "Cookie: auth_token=..." \
  -H "Content-Type: application/json" \
  -d '{ "config": { "level": "debug", "maxItems": 100 } }'
```

Déanann `PUT .../config` an comhlacht a bhailíochtú i gcoinne `configSchema` an bhreiseáin (arna dhearbhú sa léiriú) le `validatePluginConfig()` ó `src/lib/plugins/manifest.ts`: ní mór gach eochair a dhearbhú sa scéimre, ní mór luachanna a mheaitseáil leis an gcineál dearbhaithe, réimsí `number` honor `min`/`max`, agus ní mór do réimsí `select` mheaitseáil leis an `enum` dearbhaithe . Filleann aon sárú `400` agus ní stóráiltear aon rud. Níl aon eochracha inroghnaithe ag breiseán a dhearbhaíonn nach bhfuil `configSchema` ann, mar sin diúltaítear don iarratas le `400` ("Ní dhearbhaíonn an breiseán aon eochracha inchumraithe").

## Cumraíocht

### Eolaire breiseán

Tá breiseáin lonnaithe faoi eolaire sonraí OmniRoute:

```
~/.omniroute/plugins/<plugin-name>/
  ├─ plugin.json
  └─ index.js          # (nó cibé rud a ndíríonn manifest.main air)
```

Réitíonn `getDefaultPluginDir()` (`src/lib/plugins/scanner.ts`) an t-eolaire sin i
dtrí chéim:

1. **`OMNIROUTE_PLUGINS_DIR`**, nuair a bhíonn sé socraithe — úsáidtear é focal ar fhocal, is cuma cad a deir `HOME`. Seo é
   an rialtán sainráite do Docker/K8s, áit a bhfuil crann na mbreiseán nasctha isteach ag conair
   nach mbíonn baint ar bith aici le heolaire baile an choimeádáin de ghnáth (#11827).
2. `<home>/.omniroute/plugins`, áit a dtagann `<home>` ó na hathróga timpeallachta `HOME` / `USERPROFILE`.
3. `/tmp/.omniroute/plugins`, nuair nach n-easpórtálann an próiseas aon eolaire baile ar chor ar bith.

Logáiltear an t-eolaire réitithe uair amháin ag am tosaithe mar `scanner.dir_resolved`, agus luaitear an
t-ionchur a bhí i réim (`OMNIROUTE_PLUGINS_DIR`, `home`, nó `no-home-fallback`) — mar sin, má
thiteann íomhá go ciúin ar chéim 3, deirtear amhlaidh, seachas gan ach liosta folamh breiseán a thuairisciú.
Aimsíonn `POST /api/plugins/scan` aon fho-eolaire ansin ina bhfuil `plugin.json`
bailí agus cláraíonn sé é; is é an t-eolaire céanna an fhréamh a gcóipeálann
`pluginManager.install()` breiseáin isteach inti, mar sin bogann sárú an t-aimsiú agus an
tsuiteáil le chéile.

> **Ní hionann `OMNIROUTE_PLUGINS_DIR` agus `OMNIROUTE_PLUGIN_PATH`.** Ní léann ach
> lódálaí breiseán ordaithe na CLI (`bin/cli/plugins.mjs`) an dara ceann chun pacáistí npm
> `omniroute-cmd-*` a aimsiú a chuireann fo-orduithe `omniroute` leis — níl aon éifeacht aige ar an scanóir ama rite
> a bhfuil cur síos air anseo. Féach [PLUGINS.md](./PLUGINS.md) don taobh sin.

### URL saincheaptha do chlárlann an mhargaidh

Léitear foinse chatalóg an mhargaidh ón socrú `pluginMarketplaceUrl`
(léann `src/lib/plugins/marketplace.ts` `settings.pluginMarketplaceUrl`). Nuair a
shocraítear é mar URL `http(s)`, faigheann `listMarketplacePlugins()` an URL sin agus glacann sé
le heagar JSON iontrálacha ag an mbarrleibhéal nó le réad a bhfuil eagar `plugins` ann;
scagtar amach iontrálacha nach bhfuil `name` teaghráin iontu. Nuair nach mbíonn sé socraithe
(nó nuair nach n-éiríonn leis an iarratas mar gheall ar an gcosaint SSRF / nuair a sheoltar drochfhreagra ar ais),
úsáidtear an chlárlann síl ionsuite.

Taispeánann cluaisín "Marketplace" an deais réimse don URL seo (arna léamh ar ais ó
`GET /api/settings`).

> Nóta cur chun feidhme: seolann gníomh "Save" na deaise
> `pluginMarketplaceUrl` chuig `PATCH /api/settings`. Agus é seo á scríobh,
> níl an eochair seo dearbhaithe in `updateSettingsSchema`
> (`src/shared/validation/settingsSchemas.ts`), mar sin deimhnigh go bhfuil sí á buanú i d'eisiúint
> sula mbraitheann tú uirthi — cloíonn an chonair **léite** (`getSettings()` →
> `listMarketplacePlugins()`) leis an eochair a luaithe a bhíonn sí i stór na socruithe.

## Slándáil

### Sraith bealaigh — loopback amháin

Déanann forlíontáin cód a fhorghníomhú i bpróisis leanaí sceite, agus mar sin déantar an dromchla iomlán `/api/plugins` a rangú `LOCAL_ONLY` (Sraith 1). Ritheann forfheidhmiú loopback gan choinníoll** roimhe** aon seiceáil údaraithe, mar sin ní féidir le comhartha bainistíochta sceite a shroicheann an bosca thar thollán breiseán a shuiteáil, a ghníomhachtú ná a dhíshuiteáil. Féach [`docs/security/ROUTE_GUARD_TIERS.md`](../security/ROUTE_GUARD_TIERS.md) agus Rialacha Crua #15 / #17.

### Clárlann SSRF garda

Is cumraíocht a bhfuil tionchar ag an ionsaitheoir uirthi é clárlann saincheaptha URL, mar sin sula n-éiríonn leat é a fháil, ritheann `listMarketplacePlugins()` trí dhá shraith é:

1. **`isSafeMarketplaceUrl(url)`** (`src/lib/plugins/marketplace.ts`):
   - Diúltaíonn sé d' aon rud nach `http:` / `https:`.
   - Diúltaíonn sé óstaigh private/loopback/link-local/ULA litriúil (IPv4** agus** IPv6, lena n-áirítear IPv4-mapped) tríd an `isPrivateHost` canonical (`src/shared/network/outboundUrlGuard.ts`).
   - Réitíonn** araon** taifid `A` agus `AAAA` agus diúltaíonn má** ar bith** seoladh réitithe is private — an seachbhóthar public-hostname → private-IP a dhúnadh.
   - **Theipeann dúnta** : má dhiúltaíonn teip réitigh DNS an URL.
2. **`safeOutboundFetch(url, { guard: "public-only", timeoutMs: 5000 })`** (`src/shared/network/safeOutboundFetch.ts`): cuireann sé an garda URL poiblí amháin i bhfeidhm ag am beirithe agus** bloic athsheolaidh** (gan aon mhaighdeog `30x` príobháideach → poiblí).

Ní chuireann URL a theipeann ar cheachtar ciseal deireadh leis an iarratas titeann — the marketplace go ciúin ar ais go dtí an chlár síl ionsuite agus logálann sé rabhadh.

> Bhí an garda seo cruaite i PR #3774 go sonrach chun A + AAAA a réiteach agus an `isPrivateHost` canonical a úsáid in ionad seiceáil IPv4-only.

### Leithlisiú forghníomhaithe breiseán

> **Ní sandboxed breiseán de réir réamhshocraithe.** Is gnáthphróiseas Node.js é an leanbh a ritheann mar úsáideoir OmniRoute, gan comhthéacs VM agus gan aon bhratacha cead Node.js, mar sin is féidir le cód breiseán aon chomhad is féidir leis an úsáideoir a léamh agus a scríobh, cláir a rith agus an líonra a bhaint amach. ní chinneann `requires.permissions` ach cé na hathróga timpeallachta a fhaigheann an leanbh; ní chuirtear na ceadanna eile i bhfeidhm. Ritheann an bhratach gné `PLUGIN_PERMISSION_MODEL_ENABLED` rogha an diúltaithe (amach de réir réamhshocraithe) gach breiseán faoin tsamhail cead Node.js a tógadh ó na ceadanna sin, seachas `network`, nach féidir le Node.js srian a chur air (féach [`PLUGIN_SDK.md`](./PLUGIN_SDK.md#c%C3%B3ras-ceada) ). Suiteáil breiseán a bhfuil muinín agat astu. Tá tuairteanna agus crochta ag teorainn an phróisis thíos; ní teorainn slándála é.

- **Aonrú próisis** Scaipeann — `loadPlugin()` (`src/lib/plugins/loader.ts`) gach breiseán i bpróiseas páiste Node.js ar leith agus déanann sé cumarsáid thar IPC. Bíonn teorainn ama ag glaonna Hook le méadú `SIGTERM` → `SIGKILL`.
- **Liosta ceadaithe clúdaigh** — ní fhaigheann an leanbh ach sraith cheadaithe d’athróga timpeallachta; ní dheonaítear an tacar níos leithne ach amháin nuair a iarrann an forléiriú cead `env`.
- **Suiteáil srianadh foinse** Ní léann — `POST /api/plugins` ach ón eolaire foinsí breiseán (féach "Suiteáil ó chosán áitiúil"): tá an cosán canónachaithe le `realpath`, ní mór fanacht go docht laistigh den eolaire sin, agus diúltaítear crann foinse a bhfuil simplíink a éalaíonn uaidh sula ndéantar aon rud a chóipeáil.
- **Srianadh cosáin** Dearbhaíonn — install/upgrade/uninstall go réitíonn an t-eolaire breiseán agus `manifest.main`** laistigh** fréamh an bhreiseáin bainistithe roimh aon chóip nó scriosadh athchúrsach (cosanta i gcoinne cosáin a bhfuil cur isteach orthu DB agus traversal `../` i `manifest.main`). Réitíonn gníomhachtú symlinks trí `realpath` agus diúltaíonn sé pointe iontrála a lódáil a éalaíonn ón eolaire breiseán.
- **Bioráin sláine roghnach** Féadfaidh — a léiriú réimse `integrity` (`sha256-<base64>`, SRI format) a dhearbhú. Nuair a bhíonn sé i láthair, fíoraíonn an lódóir hash an chomhaid iontrála ag an am ualaigh agus diúltaíonn sé é a ghníomhachtú ar neamhréir. Is éard atá i gceist le rogha an diúltaithe isteach ná bac a bhrath,** nach bhfuil** teorainn slándála: ní chuireann sé teorainn leis an méid is féidir le breiseán luchtaithe a dhéanamh.
- **Níl aon dintiúir cliant sna crúcaí** — an comhthéacs a cuireadh ar aghaidh chuig `onRequest`, `onResponse` agus `onError` tá na ceanntásca `authorization`, `x-api-key`, `proxy-authorization` agus `cookie` bainte, agus níl aon luach eochrach ag taifead eochrach API (`redactPluginContext()` in `src/lib/plugins/hooks.ts`).

## Manifest (`plugin.json`)

Arna bhailíochtú ag `PluginManifestSchema` (`src/lib/plugins/manifest.ts`):

| Réimse             | Cineál      | Nótaí                                                                  |
| ------------------ | ----------- | ---------------------------------------------------------------------- |
| `name`             | teaghrán    | Riachtanach; cás ceibeab (`^[a-z0-9-]+$`), 1–100 chars                 |
| `version`          | teaghrán    | Riachtanach; semver (`MAJOR.MINOR.PATCH`)                              |
| `description`      | teaghrán?   | ≤ 500 charachtair                                                      |
| `author`           | teaghrán?   | ≤ 200 char                                                             |
| `license`          | teaghrán?   | Réamhshocruithe le `MIT`                                               |
| `main`             | teaghrán?   | Comhad iontrála; réamhshocraithe go `index.js`                         |
| `source`           | áim?        | `local` \| `marketplace` (réamhshocraithe go `local`)                  |
| `tags`             | teaghrán[]? | Cuardaigh clibeanna                                                    |
| `requires`         | réad?       | `{ omniroute?, permissions[] }`                                        |
| `hooks`            | réad?       | Booleans á dhearbhú cé acu crúcaí a fheidhmíonn an breiseán            |
| `skills`           | réad[]?     | Sainmhínithe scileanna roghnacha                                       |
| `enabledByDefault` | Boole?      | Uathghníomhachtú nuair a shuiteáil tú                                  |
| `configSchema`     | réad?       | Léarscáil na réimsí cumraíochta (`string`/`number`/`boolean`/`select`) |
| `integrity`        | teaghrán?   | Biorán comhaid iontrála `sha256-<base64>` roghnach                     |

Tarraingítear ceadanna ón enum `network` / `file-read` / `file-write` / `env` / `exec`. Níl ach éifeacht ama rite ag `env` (liosta ceadaithe timpeallachta-inathraithe beagán níos mó don leanbh); is dearbhuithe iad na cinn eile agus ní chuirtear i bhfeidhm iad.

## Sreabhadh Saolré

```
suiteáil (POST /api/plugins, conair)
  → scan manifest/bailíochtaigh é → cóipeáil chuig staging → dearbhaigh go bhfuil main laistigh den chomhadlann
  → athainmnigh go hadamhach isteach in ~/.omniroute/plugins/<name> → cuir ró leis an mbunachar sonraí
  → spreag onInstall → más enabledByDefault: gníomhachtaigh

gníomhachtaigh (POST /api/plugins/{name}/activate)
  → seiceáil coimeádta realpath → loadPlugin() (seol próiseas linbh)
  → cláraigh na crúcaí dearbhaithe → status = "active" → spreag onActivate

díghníomhachtaigh (POST /api/plugins/{name}/deactivate)
  → spreag onDeactivate (ROIMH dhíchlárú) → díchláraigh crúcaí
  → maraigh próiseas an linbh → status = "inactive"

díshuiteáil (DELETE /api/plugins/{name})
  → díghníomhachtaigh má tá sé gníomhach → spreag onUninstall
  → scrios athchúrsach, agus coimeád seiceáilte, ar chomhadlann an bhreiseáin → scrios ró an bhunachair sonraí
```

Má ritear `install` arís ar chomhadlann a bhfuil leagan a manifest **go docht
níos nuaí** ná an leagan suiteáilte, déantar uasghrádú uathoibríoch (athshuiteáil ghlan; athshocraítear an chumraíocht
chuig na réamhshocruithe). Diúltaítear do leagan atá mar an gcéanna nó níos sine.

## Deais

Soláthraíonn leathanach an deais ag `/dashboard/plugins` (`src/app/(dashboard)/dashboard/plugins/page.tsx`) dhá chluaisín:

- **Suiteáilte** Liostaíonn — breiseán suiteáilte lena gcrúcaí dearbhaithe, scoránaigh activate/deactivate, cnaipe díshuiteála, agus gníomh "Scan for plugins" (`POST /api/plugins/scan`).
- **Margadh** Taispeánann — an catalóg ó `GET /api/plugins/marketplace` le réimse chun an clárlann saincheaptha URL a shocrú .

Taispeánann an leathanach rabhadh i gcónaí go ritheann forlíontáin le pribhléidí iomlána an phróisis OmniRoute.

Tá leathanach cumraíochta in aghaidh an bhreiseáin ina chónaí ag `/dashboard/plugins/[name]/config` (`src/app/(dashboard)/dashboard/plugins/[name]/config/page.tsx`).
