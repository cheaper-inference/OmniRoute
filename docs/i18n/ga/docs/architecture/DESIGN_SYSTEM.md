> **Stádas:** tá an painéal tógtha ar an **Keak CI UI Kit** (`@keak/cheaper-inference-ui-kit`), cuimsithe
> mar an spás oibre `packages/ui-kit` (`@omniroute/ui-kit`; tá an seatadh uamach greamaithe i
> `packages/ui-kit/UPSTREAM.md` agus é á chosaint ag `npm run check:ui-kit-snapshot`). Is é an téama
> Éadrom an téama canónta; is é `system` an rogha réamhshocraithe. Is é lime Keak an dath béime
> (`--ci-color-accent`). Is í Inter (letter-spacing 0, `--ci-letter-spacing-ui`) clann chló an UI,
> Instrument Serif ach amháin do théacs taispeána mór tearc (`.ci-dashboard-display`), IBM Plex Mono
> don chód — ar fad féin-óstáilte trí na hiompórtálacha `@fontsource/*` ag barr
> `src/app/globals.css`. Is glif Lucide gach deilbhín.

## 1. Cá bhfuil rudaí suite

- **Trealamh.** Is cóip beart ar bheart é `packages/ui-kit/src` den `src/` réamhtheachtach ag an tiomantas atá socraithe in
  `packages/ui-kit/UPSTREAM.md` (ina dtaifeadtar údarú an cheadúnais freisin); liostaítear paistí áitiúla in `PATCHES.md`
  (níl aon cheann ann). Úsáidtear mar chód foinseach é, gan tógáil: tras-tiomsaíonn `next.config.mjs` é, agus
  mapálann `tsconfig.json` `@omniroute/ui-kit` → `packages/ui-kit/src` agus `@omniroute/ui-kit/*` →
  `packages/ui-kit/src/*` (tá an t-ailias céanna in `vitest.config.ts` agus `vitest.mcp.config.ts`). Iompórtáil
  comhpháirt trealaimh trína fochonair (`@omniroute/ui-kit/table`, `@omniroute/ui-kit/page-header`…), agus ná déan é
  riamh trí bhairille `@omniroute/ui-kit`: tarraingíonn an bairille gach comhpháirt (an roghnóir dáta san áireamh)
  isteach i ngach iompórtálaí. Tugtar stílbhileog an trealaimh isteach trí `src/app/globals.css`
  (`@import "../../packages/ui-kit/src/ci-ui.css"`).
- **Téacáin.** Fógraíonn `packages/ui-kit/src/ci-tokens.css` na téacáin `--ci-*`; nascann `src/app/globals.css`
  iad le hainmneacha oidhreachta OmniRoute (`--color-*`, `--radius-*`, `--font-sans`/`--font-mono`,
  `--table-*`, `--orch-status-*`, `--color-fd-*`), ionas go leanfaidh na húsáidí reatha de `var(--color-*)` agus
  áiseanna Tailwind ag obair. Úsáideann cód nua áiseanna Tailwind (`bg-surface`, `text-text-muted`,
  `border-border`, `text-success`, `bg-success-bg`, `bg-chart-1`…) nó aicmí an trealaimh — ní úsáidtear luach heicsidheachúlach
  riamh (`tests/unit/design-kit-bridge.test.ts` a fhorfheidhmíonn an nasc). Réitítear `text-primary` go
  `--color-primary-ink` trí `--text-color-primary` (aol-800 sa téama geal, an bhéim aoil sa téama dorcha), ionas
  go bhfanann an príomhthéacs inléite agus go gcoinníonn `bg-primary`/`border-primary` an dromchla aoil. Úsáideann sraitheanna cairte
  `--color-chart-1` … `--color-chart-5`.
- **Téamaí.** Cuireann `<html className="ci-theme">` (`src/app/layout.tsx`) an doiciméad faoi théama an trealaimh.
  Is é `light`, `dark` nó `system` an tsainrogha (`THEME_CONFIG.defaultTheme = "system"` in
  `src/shared/constants/appConfig.ts`; leanann `system` `prefers-color-scheme`). Socraíonn `applyTheme()` in
  `src/store/themeStore.ts` (agus déanann an script tosaithe inlíne in `src/app/layout.tsx`, a ritheann
  roimh hiodráitiú, an rud céanna) `data-theme="dark"|"light"` agus scoránaíonn sé an aicme `.dark` ar `<html>` ag an am céanna.
  Tá tacar téacán dorcha an trealaimh bunaithe ar `data-theme="dark"` (`packages/ui-kit/src/ci-tokens.css`);
  tá sáruithe dorcha OmniRoute féin (an bloc `.dark` in `globals.css`) agus áiseanna oidhreachta Tailwind `dark:`
  bunaithe ar an aicme `.dark`. Níl aon réamhshocruithe dathanna béime ann: tagann an dath béime ón
  trealamh i gcónaí, agus baintear réamhshocrú marthanach ó thógáil níos sine nuair a lódálann an stór.
- **Comhpháirteanna (cuibheoirí).** Coinníonn `src/shared/components/index.tsx` API comhpháirte OmniRoute (na hainmneacha,
  easpórtálacha réamhshocraithe agus airíonna céanna), agus is cuibheoirí thar chomhpháirteanna bunúsacha an trealaimh iad na comhpháirteanna taobh thiar de: foirmeacha
  (`Button`, `Input`, `Textarea`, `Checkbox`, `Select`, `Toggle`, `Badge`, `Card`), forleagan agus aiseolas
  (`Modal`/`ConfirmModal`, `Tooltip`/`InfoTooltip`, `NotificationToast`, `EmptyState`, `Loading`),
  struchtúr (`Collapsible`, `CollapsibleSection`, `SegmentedControl`, `Breadcrumbs`, `Avatar`) agus táblaí
  (`DataTable`, `FilterBar`, `ColumnToggle`, `FilterPills`, `PresetSlider`). Iompórtálann cuibheoir comhpháirt an trealaimh
  trí fhochonair agus mapálann sé na hairíonna oidhreachta chuici — mar shampla, is é `Button variant="primary"` cnaipe
  `default` an trealaimh (`--ci-button-primary-*`: an dromchla inbhéartach sa téama geal, an bhéim lena
  dúch `--ci-color-accent-foreground` sa téama dorcha), is é `danger` `destructive`, agus is é `warning` `outline` móide
  an síneadh `.ci-button--warning`. Is síntí OmniRoute iad na rialacha `.ci-button--warning` agus `.ci-badge[data-tone]` ag
  deireadh `globals.css` (`@layer components`) ar aicmí an trealaimh.
  Daingníonn `tests/unit/ui/adapters/*.test.tsx` gach cuibheoir.
- **Blaosc.** Rindreálann `src/app/(dashboard)/layout.tsx` `DashboardLayout`, a rindreálann
  `src/shared/components/layouts/DashboardShell.tsx`: `SidebarProvider` / `Sidebar` /
  `SidebarInset` an trealaimh (`packages/ui-kit/src/sidebar.tsx`), le loighic nascleanúna OmniRoute in
  `src/shared/components/Sidebar.tsx`. Is nasc “scipeáil chuig an ábhar” chuig `#main-content` an chéad eilimint
  infhócasaithe. Tá `SidebarTrigger` an trealaimh (an t-aon scorán barra taoibh sa bhlaosc),
  `ProductSwitcher` Keak agus oscailteoir an phailéid orduithe in `src/shared/components/Header.tsx`; ní thaispeánann sé teideal an bhealaigh ach
  nuair nach bhfuil `PageHeader` (`.ci-page-header`) de chuid an trealaimh gléasta laistigh de `#main-content`, ionas go mbíonn
  `h1` amháin ar leathanach a bhfuil a `PageHeader` féin aige. Is `Dialog` de chuid an trealaimh é `src/shared/components/CommandPalette.tsx`.
- **Deilbhíní.** Réitíonn `<Icon name="material_name">` (`src/shared/components/Icon.tsx`) an t-ainm (stór focal
  Material Symbols a úsáideann na scáileáin) trí `ICON_MAP` (`src/shared/constants/iconMap.ts`) go glif
  Lucide. Tá cló agus pacáiste Material Symbols bainte: má tá ainm ar iarraidh ón mapa, rindreáiltear
  glif ionadchoinneála neodrach (`data-icon-missing="true"`) agus logáiltear rabhadh consóil lasmuigh den timpeallacht táirgthe.
  Priontálann `npm run gen:icon-map` na hainmneacha atá in úsáid agus atá ar iarraidh ón mapa
  (teipeann ar `tests/unit/icon-map-coverage.test.ts` i gcás aon ainm nach bhfuil deilbhín Lucide aige;
  clúdaíonn `tests/unit/icon-map-object-values.test.ts` ainmneacha a stóráiltear in oibiachtaí cuardaigh);
  athscríobhann `scripts/dev/codemod-material-icons.mjs <dir|file>... [--write]` réisí litriúla
  `<span className="material-symbols-outlined">` mar `<Icon>`.
- **Branda.** Timfhilleann `src/shared/components/OmniRouteLogo.tsx` an trealamh: rindreálann an t-easpórtáil réamhshocraithe `OmniRouteLogo`
  `ProductIcon product="omniroute" variant="glyph"` (SVG inlíne, sábháilte do `basePath`) agus
  rindreálann `OmniRouteLockup` `ProductLockup product="omniroute"` (ainm inrochtana “Keak OmniRoute”) nó, i gcás
  oibreoirí lipéid bháin, a `name`/`logoSrc` féin. Tá cinn scríbe an lascaire táirgí in
  `src/shared/constants/keakProducts.ts` (`KEAK_PRODUCT_LINKS`, `KEAK_ACTIVE_PRODUCT`). Taispeánann na scáileáin
  neamhspleácha — `src/app/login/page.tsx`, `src/app/status/page.tsx`, `src/app/maintenance/page.tsx`,
  `src/app/offline/page.tsx`, `src/app/not-found.tsx` agus `src/shared/components/ErrorPageScaffold.tsx`
  — an glasáil branda; cosnaíonn `tests/unit/brand-pages-static.test.ts` í.

## 2. Rialacha

1. Comharthaí, riamh luachanna litriúla. Eisceachtaí coinnithe d'aon ghnó: an teirminéal consóil atá dorcha i gcónaí, strócanna SVG ReactFlow trí `STATUS_HEX` (`src/shared/constants/statusColors.ts`), agus na pailéadra catagóireacha `STRATEGY_COLORS` (`src/app/(dashboard)/dashboard/combos/live/nodes/StrategyNode.tsx`) agus `LAYER_COLORS` (`src/app/(dashboard)/dashboard/compression/studio/nodes/EngineNode.tsx`).
2. Ná paistigh `packages/ui-kit/src` de láimh choíche: sioncrónaigh le `scripts/dev/sync-ui-kit.sh <commit>`; theipeann ar an ngeata pre-commit `npm run check:ui-kit-snapshot` (`.husky/pre-commit`) ar aon bheart a bhíonn difriúil ón gcommit upstream prionáilte (scipeálann sé le rabhadh nuair nach bhfuil an clón upstream, `UI_KIT_CLONE` nó `_references/cheaper-inference-ui-kit`, i láthair). Nuair a bhíonn rud éigin in easnamh ar an kit, déan obair thart air san oiriúntóir nó ar an scáileán agus iarr ar upstream é.
3. Is i mBéarla atá réamhshocruithe téacs an kit (`label = "Loading"`, `loadingLabel = "Loading table"`…) — cuir teaghráin aistrithe ó `useTranslations(...)` ar aghaidh aon uair a rindreálann comhpháirt de chuid an kit téacs.
4. Buaann fóntais Tailwind ar aicmí comhpháirte an kit (fógraíonn an kit `@layer theme, base, components, utilities` agus tá a rialacha i `components`) — bain úsáid as fóntais le haghaidh spásála agus leagan amach, ní chun comhpháirteanna an kit a athdhathú.
5. Ceannteidil: `.ci-heading` (Inter, gan rianú) le haghaidh teidil leathanaigh agus rannóg; `.ci-dashboard-display` (Instrument Serif) do théacs taispeána mór, gann amháin ar nós cód stádais an leathanaigh earráide.
6. Cosnaíonn `tests/unit/dashboard-kit-sweep.test.ts` glacadh an kit: gan aon span ligatúr Material faoi `src/app` ná faoi `src/shared/components`; i gcrann an deais (`src/app/(dashboard)` agus `src/shared/components`) gan aon `<select>`, `<textarea>` ná `<table>` amh agus gan aon `role="dialog"` lámh-dhéanta lasmuigh de na heisceachtaí liostaithe (brainse dúchasach an oiriúntóra `Select`, `RequestLoggerDetail`); tá trácht ina bhfuil `kit-exception:` (leis an gcúis) de dhíth ar gach `<button>` nó `<input>` amh ann, trácht a chríochnaíonn 3 líne ar a mhéad os a chionn; datha na bpailéad agus leaganacha `dark:` sna comhaid a liostaíonn an tástáil amháin.
7. Fíoraigh an dá théama agus an radharcphort 390 px roimh PR (seatanna scáileáin); ritheann `tests/e2e/a11y.spec.ts` axe.

## 3. Scáileán a chur leis

1. Oscail an leathanach le `PageHeader` an kit (`@omniroute/ui-kit/page-header`, `compact` laistigh den deais) — teideal, tuairisc agus `actions`. Scaoileann ceannlíne na blaosce a theideal féin ansin.
2. Tóg rialuithe ó `@/shared/components` (na hoiriúntóirí) agus bain úsáid as comhpháirteanna kit trí fho-chosán nuair nach bhfuil oiriúntóir ann (`Table`/`TableScrollArea`/`DataTableShell`, `Field`, `Alert`, `Tabs`, `RadioGroup`, `Slider`…).
3. Deilbhíní: `<Icon name="…" />`. Téann ainm nua isteach in `ICON_MAP` leis an gcomhpháirt Lucide a fhreagraíonn go séimeantach dó; liostaíonn `npm run gen:icon-map` na hainmneacha atá fós ar iarraidh.
4. Dathanna: fóntais shéimeantacha (`text-success`, `bg-warning-bg`, `border-border`…) agus `var(--color-chart-N)` le haghaidh sraitheanna cairte; gan luachanna hex ná leaganacha `dark:` nach ndéanann ach dath a athdhéanamh.
5. Téacs: tagann gach teaghrán, lena n-áirítear na lipéid a chuireann tú ar aghaidh chuig comhpháirteanna kit, ó `useTranslations`. Téann eochracha nua isteach i `src/i18n/messages/en.json`, `pt-BR.json` agus `vi.json` (prionálaíonn tástáil chomhionannais na Vítneáime gach eochair Bhéarla); líontar na localeanna eile ag sioncrónú i18n.
6. Rith na gardaí roimh an PR: `tests/unit/dashboard-kit-sweep.test.ts`, `tests/unit/icon-map-coverage.test.ts`, `tests/unit/icon-map-object-values.test.ts`, `npm run check:dashboard-typecheck` (an t-aon sheic a ghabhann iompórtáil dhúblach in `iconMap.ts`), `npm run check:ui-icu`, agus tástálacha an scáileáin féin.

## 4. Oiriúntóir a chur leis nó a athrú

1. Coinnigh API poiblí `src/shared/components/index.tsx` mar atá: na hainmneacha easpórtála céanna, na heaspórtálacha réamhshocraithe agus na props a ghlactar leo. Mapáil na props oidhreachta chuig an kit laistigh den oiriúntóir (féach `Button.tsx`: `VARIANT_TO_KIT`,
   `SIZE_TO_KIT`).
2. Iompórtáil an kit trí fhochonair (`@omniroute/ui-kit/<component>`).
3. Coinnítear réitigh shealadacha le haghaidh bearnaí sa kit san oiriúntóir (nó i `globals.css` `@layer components` nuair is ceartú stíle atá i gceist), riamh i `packages/ui-kit/src`.
4. Cuir leis nó nuashonraigh `tests/unit/ui/adapters/<name>.test.tsx`. Maidir le hoiriúntóir a bhfuil go leor glaoiteoirí aige, déan comparáid idir an marcáil rindreáilte roimh an athrú agus ina dhiaidh — scaipeann athruithe ar an stuáil nó ar an bhfillteán chuig gach scáileán.

## 5. An kit a nuashonrú

Cóipeann `scripts/dev/sync-ui-kit.sh <commit> [clone]` an `src/` uasshrutha ag an gcoimid sin isteach i
`packages/ui-kit/src` agus cuireann sé an t-aon chlaochlú ceadaithe amháin i bhfeidhm (baineann sé an iarmhír `.js` de na
hiompórtálacha coibhneasta). Ansin: déan athbhreithniú ar `git diff packages/ui-kit`, tabhair breathnú amhairc ar sholáthraithe, socruithe, teaglamaí,
úsáid agus críochphointe sa dá théama, rith `npm run check:ui-kit-snapshot` agus `npm run test:vitest:ui`, agus
oscail an PR leis an loga athruithe uasshrutha.
