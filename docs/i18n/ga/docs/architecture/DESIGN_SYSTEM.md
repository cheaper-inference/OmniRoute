> **Stádas:** tá an painéal tógtha ar **Keak CI UI Kit** (`@keak/cheaper-inference-ui-kit`), atá cuachta
> mar an spás oibre `packages/ui-kit` (`@omniroute/ui-kit`; tá an léargas réamhtheachtach feistithe in
> `packages/ui-kit/UPSTREAM.md` agus cosanta ag `npm run check:ui-kit-snapshot`). Is é an téama geal an téama
> canónach; is é `system` an rogha réamhshocraithe. Is é cuma **Editions** na foirne an pailéad réamhshocraithe
> (neodracha teo páipéir agus an bhéim chopair `#e5ac82`, `packages/ui-kit/src/ci-editions.css`); Socruithe →
> Cuma → Pailéad dathanna, tairgtear **Classic**, comharthaí bonn na foirne leis an mbéim líoma.
> Is é Switzer an t-aon chlófhoireann amháin do théacs an chomhéadain, an taispeántais agus an chóid (`--ci-font-ui`; réitíonn `--ci-font-display` agus
> `--ci-font-mono` chuige), agus tá sé féinóstáilte ag an bhfoireann féin (`packages/ui-kit/src/ci-fonts.css`,
> arna iompórtáil ag `ci-tokens.css`). I gcás na gcóras scríbhneoireachta nach dtacaíonn Switzer leo, úsáidtear clófhoirne malartacha glife ar ghlife (`src/app/globals.css`):
> Inter don Choireallach, don Ghréigis agus don Vítneaimis agus, faoi `html[dir="rtl"]` amháin, Vazirmatn don script Arabach.
> Is glif Lucide é gach deilbhín.

## 1. Cá bhfuil rudaí lonnaithe

- **An Kit.** Is cóip beart ar bheart de `src/` upstream ag an commit atá pionnáilte in
  `packages/ui-kit/UPSTREAM.md` é `packages/ui-kit/src` (taifeadann sé údarú an cheadúnais freisin); liostaíonn
  `PATCHES.md` na paistí áitiúla (níl aon cheann ann). Úsáidtear é mar fhoinse, gan build: tras-chomhthiomsaíonn
  `next.config.mjs` é, agus mapálann `tsconfig.json` `@omniroute/ui-kit` → `packages/ui-kit/src` agus
  `@omniroute/ui-kit/*` → `packages/ui-kit/src/*` (tá an ailias céanna in `vitest.config.ts` agus
  `vitest.mcp.config.ts`). Iompórtáil comhpháirt kit trína fho-chonair (`@omniroute/ui-kit/table`, `@omniroute/ui-kit/page-header`…), ná húsáid bairille
  `@omniroute/ui-kit` riamh: tarraingíonn an bairille gach comhpháirt (an roghnóir dáta san áireamh)
  isteach i ngach iompórtálaí. Tagann stílbhileog an kit isteach trí `src/app/globals.css`
  (`@import "../../packages/ui-kit/src/ci-styles.css"`, an bhileog iomlán: an croí `ci-ui.css` móide gach teaghlach patrún).
- **Comharthaí.** Dearbhaíonn `packages/ui-kit/src/ci-tokens.css` na comharthaí `--ci-*`; nascann `src/app/globals.css`
  iad le seanainmneacha OmniRoute (`--color-*`, `--radius-*`, `--font-sans`/`--font-mono`,
  `--table-*`, `--orch-status-*`, `--color-fd-*`), ionas go leanfaidh na léamha `var(--color-*)` atá ann cheana agus
  fóntais Tailwind ag obair. Úsáideann cód nua na fóntais Tailwind (`bg-surface`, `text-text-muted`,
  `border-border`, `text-success`, `bg-success-bg`, `bg-chart-1`…) nó aicmí an kit — ná húsáid luach heicsidheachúlach
  riamh (`tests/unit/design-kit-bridge.test.ts` a chuireann an droichead i bhfeidhm). Réitíonn `text-primary`
  go `--color-primary-ink` trí `--text-color-primary`, mar sin fanann príomhthéacs inléite agus coinníonn
  `bg-primary`/`border-primary` dromchla na haicinte: faoi Editions is é `--ci-color-accent-active` an kit é
  (an copar domhain `#99562f` sa mhód éadrom, agus an aicint chopair sa mhód dorcha); faoi Classic,
  lime-800 sa mhód éadrom agus an aicint aoil sa mhód dorcha. Úsáideann sraitheanna na gcairteacha
  `--color-chart-1` … `--color-chart-8`, agus tá `--color-chart-N-ink` sábháilte ó thaobh téacs de agus
  tint sliseoige theimhneach `--color-chart-N-subtle` ag gabháil le gach ceann acu, san ord sraitheanna atá
  sannta ag an kit (`ciChartSeriesOrder`).
- **Téamaí.** Cuireann `<html className="ci-theme">` (`src/app/layout.tsx`) an doiciméad in oiriúint do théama an kit.
  Is é `light`, `dark` nó `system` an rogha (`THEME_CONFIG.defaultTheme = "system"` in
  `src/shared/constants/appConfig.ts`; leanann `system` `prefers-color-scheme`). Socraíonn
  `applyTheme()` in `src/store/themeStore.ts` (arna scáthánú ag `THEME_BOOT_SCRIPT`, atá inlíneáilte in `src/app/layout.tsx` agus a ritheann
  roimh hiodráitiú) `data-theme="dark"|"light"` agus scoránaíonn sé an aicme `.dark` ar `<html>` le chéile.
  Tá tacar comharthaí dorcha an kit bunaithe ar `data-theme="dark"` (`packages/ui-kit/src/ci-tokens.css`);
  tá sáruithe dorcha OmniRoute féin (an bloc `.dark` in `globals.css`) agus fóntais oidhreachta Tailwind `dark:`
  bunaithe ar an aicme `.dark`. Níl aon réamhshocruithe datha aicinte ann: tagann an aicint ón kit i gcónaí,
  agus caitear amach réamhshocrú leanúnach ó thógáil níos sine nuair a lódálann an stór.
- **Pailéid.** Dhá cheann atá ann, an dá cheann ón kit (`src/shared/constants/appearancePalette.ts`): `editions`, an
  réamhshocrú, agus `classic`. Is é Editions aitreabúid `data-ci-appearance="editions"` an kit ar `<html>`, a
  chomhcheanglaíonn `ci-editions.css` (arna iompórtáil ag `ci-ui.css`) le `data-theme`; is é Classic easpa na
  haiteiribúide. Rindreálann leagan amach fréimhe an aitreabúid ar an bhfreastalaí, mar sin faigheann cuairteoir nach bhfuil aon rud stóráilte aige (ná JavaScript)
  Editions ar gach dromchla — painéal, logáil isteach, `/status`, leathanaigh earráide, `/docs` agus an PWA. Coimeádtar
  an rogha in aice leis an téama sa stór `theme` céanna (`palette`, `setPalette()`, `applyPalette()` in
  `src/store/themeStore.ts`) agus cuirtear i bhfeidhm í roimh phéinteáil ag `THEME_BOOT_SCRIPT`
  (`src/shared/utils/themeBootScript.ts`, atá inlíneáilte i `<head>` an leagain amach), a bhaineann an aitreabúid
  amach nuair amháin atá an pailéad stóráilte `"classic"`; cuireann `src/app/global-error.tsx`, atá lasmuigh den leagan amach fréimhe,
  i bhfeidhm í ón stór céanna. Ná cuir `data-ci-appearance` ar aon eilimint eile: meaitseálann an kit é le
  `html:root:has([data-ci-appearance="editions"])`, mar sin athródh sliocht amháin an doiciméad iomlán.
  Tá an leagan Editions `data-ci-editions-variant="landing"` le haghaidh leathanaigh mhargaíochta, ní don phainéal.
  Chrome an bhrabhsálaí: rindreálann an freastalaí an réamhshocrú, Editions, in `viewport.themeColor` (clib amháin in aghaidh
  `prefers-color-scheme`) agus sa manifest — `PWA_THEME_COLORS` in
  `src/shared/constants/pwaThemeColors.ts`, an t-aon scáthán de chuid Editions `--ci-color-background`
  (`#f3f1e9` / `#11120f`), pionnáilte le `ci-editions.css` ag `tests/unit/pwa-theme-colors.test.ts`. Leanann an
  beo `<meta name="theme-color">` an pailéad agus an mód stóráilte ansin: athscríobhann `THEME_BOOT_SCRIPT` na
  clibeanna roimh phéinteáil agus déanann gníomhartha stór na dtéamaí amhlaidh ar gach athrú
  (`resolveThemeColor()` / `applyThemeColor()` in `src/shared/utils/themeColorMeta.ts`, le
  `CLASSIC_PAGE_BACKGROUND` léite ó `ciTokens` an kit). Socraíonn téama éadrom/dorcha follasach gach clib chuig an mód sin;
  coinníonn `system` dath amháin in aghaidh na scéime. Fanann an manifest mar Editions: faightear é uair amháin in aghaidh suiteála,
  gan an sainrogha. Léann Monaco a chuid dathanna ó thóireadóir (`monacoKitTheme.ts`);
  faoi Editions smeachann léamh an tóireadóra `data-theme` na fréimhe ar feadh pas sioncrónach amháin, toisc go réitíonn an kit
  Editions éadrom/dorcha ón bhfréamh.
- **Comhpháirteanna (cuibheoirí).** Coinníonn `src/shared/components/index.tsx` API comhpháirteanna OmniRoute (na hainmneacha,
  na honnmhairí réamhshocraithe agus na props chéanna), agus is cuibheoirí thar an kit iad na primitiveanna taobh thiar de:
  foirmeacha (`Button`, `Input`, `Textarea`, `Checkbox`, `Select`, `Toggle`, `Badge`, `Card`), forleagain agus aiseolas
  (`Modal`/`ConfirmModal`, `Tooltip`/`InfoTooltip`, `NotificationToast`, `EmptyState`, `Loading`),
  struchtúr (`Collapsible`, `CollapsibleSection`, `SegmentedControl`, `Breadcrumbs`, `Avatar`) agus táblaí
  (`DataTable`, `FilterBar`, `ColumnToggle`, `FilterPills`, `PresetSlider`). Iompórtálann cuibheoir comhpháirt an kit trí fho-chonair agus mapálann sé na props oidhreachta air — mar shampla is é
  `Button variant="primary"` cnaipe `default` an kit (`--ci-button-primary-*`: an dromchla inbhéartach sa mhód éadrom, an aicint lena
  dúch `--ci-color-accent-foreground` sa mhód dorcha), is é `danger` `destructive`, agus is é `warning` cnaipe `warning` an kit.
  Is toin an kit iad malairtí stádais `Badge`, agus rindreálann `Select` le leanaí `<option>` an kit
  `NativeSelect`.
  Iompórtáiltear dhá chuibheoir de réir conaire, ní ón innéacs: `InteractiveTableRow`
  (`src/shared/components/InteractiveTableRow.tsx`), `TableRow` de chuid an kit a ghlacann `onActivate` agus
  `selected` agus a fhreagraíonn do Tab, Enter agus Space, agus `CodePreview`
  (`src/shared/components/CodePreview.tsx`), bloc cód an kit agus a lipéid chóipeála aistrithe.
  Socraíonn `tests/unit/ui/adapters/*.test.tsx` gach cuibheoir.
- **Blaosc.** Déanann `src/app/(dashboard)/layout.tsx` `DashboardLayout` a rindreáil, rud a dhéanann
  `src/shared/components/layouts/DashboardShell.tsx` a rindreáil: an trealamh `SidebarProvider` / `Sidebar` /
  `SidebarInset` (`packages/ui-kit/src/sidebar.tsx`), le loighic nascleanúna OmniRoute in
  `src/shared/components/Sidebar.tsx`. Is nasc “scipeáil chuig an ábhar” é an chéad eilimint ar féidir díriú uirthi,
  agus díríonn sé ar `#main-content`. Tá `src/shared/components/Header.tsx` ina óstach ar an trealamh
  `SidebarTrigger` (an t-aon scorán taoibhe den bhlaosc), ar `ProductSwitcher` Keak agus ar oscailteoir an
  phailéid orduithe; taispeánann sé teideal an bhealaigh ach amháin nuair nach bhfuil aon `PageHeader` den
  trealamh (`.ci-page-header`) suite laistigh de `#main-content`, agus mar sin níl ach `h1` amháin ar leathanach
  a bhfuil a `PageHeader` féin aige. Is `Dialog` den trealamh é `src/shared/components/CommandPalette.tsx`.
- **Deilbhíní.** Réitíonn `<Icon name="material_name">` (`src/shared/components/Icon.tsx`) an t-ainm (an
  stór focal Material Symbols a úsáideann na scáileáin) trí `ICON_MAP` (`src/shared/constants/iconMap.ts`) go
  glif Lucide. Tá cló agus pacáiste Material Symbols bainte: má bhíonn ainm ar iarraidh ón léarscáil, rindreáiltear
  glif ionadach neodrach (`data-icon-missing="true"`) agus logáiltear rabhadh consóil lasmuigh den táirgeadh.
  Priontálann `npm run gen:icon-map` na hainmneacha atá in úsáid agus atá ar iarraidh ón léarscáil
  (`tests/unit/icon-map-coverage.test.ts` teipeann air maidir le haon ainm nach bhfuil deilbhín Lucide aige;
  clúdaíonn `tests/unit/icon-map-object-values.test.ts` na hainmneacha atá stóráilte i réada cuardaigh);
  déanann `scripts/dev/codemod-material-icons.mjs <dir|file>... [--write]` réimsí litriúla
  `<span className="material-symbols-outlined">` a athscríobh go `<Icon>`.
- **Brandáil.** Clúdaíonn `src/shared/components/OmniRouteLogo.tsx` an trealamh: déanann an t-easpórtáil
  réamhshocraithe `OmniRouteLogo` `ProductIcon product="omniroute" variant="glyph"` a rindreáil (SVG inlíne,
  sábháilte ó thaobh `basePath` de), agus déanann `OmniRouteLockup` `ProductLockup product="omniroute"` a
  rindreáil (ainm inrochtana "Keak OmniRoute") nó, i gcás oibreoirí le lipéad bán, a `name`/`logoSrc` féin.
  Tá cinn scríbe an lascóra táirgí in `src/shared/constants/keakProducts.ts`
  (`KEAK_PRODUCT_LINKS`, `KEAK_ACTIVE_PRODUCT`). Taispeánann na scáileáin neamhspleácha —
  `src/app/login/page.tsx`, `src/app/status/page.tsx`, `src/app/maintenance/page.tsx`,
  `src/app/offline/page.tsx`, `src/app/not-found.tsx` agus `src/shared/components/ErrorPageScaffold.tsx` —
  an comhcheangal lógó; cinntíonn `tests/unit/brand-pages-static.test.ts` go bhfuil sé ann.

## 2. Rialacha

1. Comharthaí, ná liteartha. Coinnítear na heisceachtaí d’aon ghnó: an teirminéal consóil atá dorcha i gcónaí agus
   `STATUS_HEX` (`src/shared/constants/statusColors.ts`), scáthán heicsidheachúlach réitithe phailéad
   stádais an kit do ghlaoiteoirí a dteastaíonn heicsidheachúl uathu. Ní eisceacht iad na pailéid chatagóireacha a
   thuilleadh: úsáideann siad ocht gcomhartha chairte an kit (`--color-chart-1..8`, móide `-ink`/`-subtle`),
   in ord na sraitheanna sa kit, trí
   `src/shared/utils/categoricalPalette.ts` agus, do straitéisí ródaithe,
   `src/app/(dashboard)/dashboard/combos/strategyPalette.ts`; léann imill ReactFlow agus an chanbhás
   ceolfhoirne na hathróga `--orch-status-*` atá feasach ar théama
   (`src/shared/components/flow/edgeStyles.ts`).
2. Ná déan `packages/ui-kit/src` a phaisteáil de láimh riamh: sioncrónaigh le `scripts/dev/sync-ui-kit.sh <commit>`; teipeann ar an
   gheata réamhdheimhnithe `npm run check:ui-kit-snapshot` (`.husky/pre-commit`) má bhíonn beart ar bith
   éagsúil ón gcommit réamhsocraithe (scipeann sé le rabhadh nuair nach bhfuil an chlónáil réamhtheachtach,
   `UI_KIT_CLONE` nó `_references/cheaper-inference-ui-kit`, ar fáil). Nuair nach bhfuil rud éigin ag an kit,
   seachain é san oiriúntóir nó ar an scáileán agus iarr ar an tionscadal réamhtheachtach é.
3. Is é an Béarla réamhshocrú do théacs an kit (`label = "Loading"`, `loadingLabel = "Loading table"`…) — cuir
   teaghráin aistrithe ó `useTranslations(...)` ar aghaidh aon uair a thaispeánann comhpháirt kit téacs.
4. Bíonn fóntais Tailwind níos láidre ná aicmí comhpháirteanna an kit (dearbhaíonn an kit
   `@layer theme, base, components, utilities` agus tá a rialacha in `components`) — bain úsáid as fóntais
   le haghaidh spásála agus leagan amach, seachas comhpháirteanna an kit a athdhathú. Is eisceacht í an
   tíopeagrafaíocht:
   allmhairítear `packages/ui-kit/src/ci-typography.css` lasmuigh d’aon tsraith, mar sin sáraíonn a rialacha clibe
   na fóntais. Níl aon éifeacht ag aicmí `weight`, `tracking-*` agus `leading-*` ar `h1`–`h6`, níl
   éifeacht ar bith ag `weight` agus `tracking-*` ar chealla tábla, agus níl éifeacht ag `weight` ar chnaipí
   (diúltaíonn `tests/unit/dead-typography-classes.test.ts` dóibh ansin); níl aon éifeacht ag `font-mono` ar
   `th`, `td`, `button`, `input` agus `textarea`. Bíonn feidhm fós ag fóntais méide, datha agus
   `uppercase`.
5. Ceannteidil: bain úsáid as `.ci-heading` le haghaidh teidil leathanaigh agus rannóige; bain úsáid as
   `.ci-dashboard-display` le haghaidh téacs taispeána mór, gann amháin, amhail cód stádais an leathanaigh earráide. Úsáideann an dá cheann Switzer.
6. Cosnaíonn `tests/unit/dashboard-kit-sweep.test.ts` glacadh an kit: gan aon réise ligature Material faoi
   `src/app` ná `src/shared/components`; i gcrann an deais (`src/app/(dashboard)` agus
   `src/shared/components`) gan aon `<select>`, `<textarea>` ná `<table>` amh agus gan aon
   `role="dialog"` déanta de láimh lasmuigh de na heisceachtaí liostaithe (brainse dúchasach an oiriúntóra
   `Select`, `RequestLoggerDetail`); teastaíonn trácht ina bhfuil `kit-exception:` (agus an chúis) ó gach
   `<button>` nó `<input>` amh ansin, trácht a chríochnaíonn tráth nach déanaí ná 3 líne os a chionn; ní cheadaítear

## 5. An trealamh a nuashonrú

Déanann `npm run check:ui-kit-upstream` comparáid idir an leagan atá pinned in `packages/ui-kit/UPSTREAM.md` leis an gclib `v*` is nuaí den repo in aghaidh an tsrutha agus priontaí an t-ordú sioncronaithe nuair a bhíonn scaoileadh amach.

Ritheann an sreabhadh oibre laethúil `UI Kit upstream watch` (`.github/workflows/ui-kit-upstream-watch.yml`) an tseiceáil chéanna. Cé go bhfuil an bioráin taobh thiar de, coinníonn `scripts/ci/ui-kit-sync-pr.sh` sync PR amháin ar oscailt i gcoinne an bhrainse `release/vX.Y.Z` is airde, ar an mbrainse rollta `chore/ui-kit-sync-latest`. Ní chumasc sé riamh: tá seiceáil amhairc ar an VPS áitiúil fós ag teastáil ó gach scaoileadh feiste. Déantar an brainse a atógáil nuair a bhíonn scaoileadh níos nuaí amach agus fágtar é ina aonar ar shlí eile. Ní fhorscríobhtar PR oscailte le gealltanais arna bhrú de láimh, agus fanann PR le haghaidh leagan a dhún cothaitheoir gan chumasc dúnta go dtí go scaoiltear amach níos nuaí é.

Nuair nach féidir aon PR a oscailt (tá an scaoileadh sprice reoite, tá an PR geallta a bhrú de láimh, dúnadh an PR, nó níl aon chomhartha PR socraithe) coinníonn an sreabhadh oibre saincheist rianaithe amháin oscailte a deir cén fáth.

Úsáideann an sreabhadh oibre dhá rún:

- `secrets.UI_KIT_READ_TOKEN`: comhartha inléite amháin don repo príobháideach réamhtheachtacha. Nuair nach féidir leis an sreabhadh oibre léamh in aghaidh an tsrutha (gan aon chomhartha, comhartha a stop ag obair, nó GitHub dosroichte) fanann an rith glas ach scríobhann sé rabhadh agus coinníonn sé saincheist ar leith amháin oscailte, a dhúnann é féin uair amháin sa rith níos déanaí is féidir léamh in aghaidh an tsrutha arís.
- `secrets.UI_KIT_SYNC_PR_TOKEN`: comhartha mín ar an stór seo le hiarratais ar Ábhar agus Tarraingt rochtain scríofa. Ní féidir leis an `GITHUB_TOKEN` réamhshocraithe PRs a chruthú anseo, agus ní spreagfadh PR a d'oscail sé CI. Gan an comhartha seo ní bhrúnn an sreabhadh oibre ach an brainse.

Déanann `scripts/dev/sync-ui-kit.sh <commit|latest> [clone]` an `src/` in aghaidh an tsrutha a chóipeáil ag an ngealltanas sin (`latest` = an chlib `v*` is nua) go `packages/ui-kit/src`, cuireann sé an claochlú aonair ceadaithe i bhfeidhm (titeann sé an iarmhír `.js` ó allmhairí coibhneasta), agus socraíonn sé an leagan spáis oibre i `packages/ui-kit/package.json` agus `package-lock.json` chuig an gceann in aghaidh an tsrutha. Ansin: athbhreithniú `git diff packages/ui-kit`, déan pas amhairc ar sholáthraithe, socruithe, teaglama, úsáid agus críochphointe sa dá théama, reáchtáil `npm run check:ui-kit-snapshot` agus `npm run test:vitest:ui`, agus oscail an PR leis an changelog in aghaidh an tsrutha.
