Is é an doiciméad seo an tagairt údarásach do gach geata cáilíochta CI in OmniRoute.
Déantar cur síos ann ar gach geata, ar a bhfíoraíonn sé, ar an jab CI ina ritear é, ar cé acu a úsáideann sé
bonnlíne raicéid nó polasaí pas/teip, agus ar cé acu a chuireann sé bac ar an tógáil nó atá sé comhairleach.

Le haghaidh achoimre ghairid agus pholasaí an liosta ceadaithe, féach an rannán "Geataí Cáilíochta & Raicéid"
in `AGENTS.md`. Le haghaidh an mheasúnaithe chriticiúil, an aicmithe aibíochta, agus an phlean macasamhlaithe
neamhspleách ar uirlisí don chóras céanna, féach an
[Leabhar Súgartha do Gheataí Cáilíochta](../ops/QUALITY_GATE_PLAYBOOK.md).

## Fardal geataí agus próifílí forghníomhaithe

### Glacadh iarrthóirí

Gineann sreafaí oibre CI agus Quality Gates breithiúnas cobhsaí an ceann: `Gate / CI` agus
`Gate / Quality`. Liostaíonn a mbeartas glactha le leagan gach post réamhtheachtach
mar riachtanach nó mar chomhairleach. Ní mór go n-éireodh le post riachtanach
infheidhme: ní féidir le torthaí atá ar iarraidh, curtha ar ceal, scipeáilte, ar feitheamh
ná anaithnid PASS a bhunú. Féadfaidh aicmiú bailí docs-only nó catalog-only lána cód a
dhéanamh neamhinfheidhme; ní iarrthóir inghlactha é PR dréachta. Ní tharscaoileann lipéad
`hotfix` an fhianaise.

Clúdaíonn an dá shreabhadh oibre PRanna isteach i mbrainsí main/release, brúiteanna chuig
`main`, seoladh de láimh agus imeachtaí merge-group. Reáchtálann brú, seoladh agus
merge-group an roghnú iomlán. Ní thosaíonn brúiteanna chuig `release/**` iad
(2026-10-18): reáchtáil gach athrú an mhaitrís ar a PR cheana féin agus is é obair
Release-Green an teaglaim chumaiscthe (`docs/ops/RUNNER_BOX.md` → Hosted lane).
Úsáideann forcanna agus grúpaí cumaiscthe riteoirí óstáilte le haghaidh post a roghnódh
riteoirí féin-óstáilte murach sin; ní mór acmhainn óstáilte leordhóthanach a fhíorú roimh
an rolladh amach.

Aithníonn gach admháil JSON an SHA seiceáilte amach, rith an tsreafa oibre agus an iarracht.
Diúltaíonn an CLI do mhí-oiriúnú idir SHA seiceála amach agus SHA imeachta. Ceanglaíonn
tástálacha sreafa oibre ballraíocht an bheartais le liosta `needs` an phoist bhreithiúnais
ionas nach n-imíonn lána nua nó bainte go ciúin. Clúdaíonn na hadmhálacha a sreabhadh
oibre féin, ní foilsiú, imscaradh ná inmheánach scanóra chomhairligh atá ann cheana.
Is athrú riaracháin ar leith é an dá ainm seiceála a ghníomhachtú i rialacha brainse;
ní chosnaíonn na poist seo brainse leo féin.

### Fardal scanadh statach

Tá an fardal ailiasanna npm le leagan agus ballraíocht an scanadh stataigh lonnaithe in
`config/quality/gate-manifest.json`. Rith `npm run check:gate-manifest` chun ainmneacha
na scripteanna agus na horduithe cruinne a bhailíochtú in aghaidh `package.json`; teipeann
ar bhreiseanna, baint agus imeacht orduithe sa hook logánta agus sna poist aicmithe athruithe
in CI araon. Ní post sreafa oibre, sampla maitríse ná cás tástála é ailias: ní ceadmhach
na comhaireamh seo a chur i láthair mar rudaí idirmhalartaithe.

Úsáid `npm run quality:scan -- --list` nó `npm run quality:scan:fast -- --list`
chun na hailiasanna roghnaithe a iniúchadh gan iad a fhorghníomhú. Glaonn an riteoir an
iontráil npm, agus mar sin coinnítear a am rite (Bun san áireamh nuair atá cumraithe).
Taifeadann an forléiriú ailiasanna lasmuigh de na próifílí sin mar ailiasanna a ghlaoitear
orthu ar leithligh, agus tá orduithe cothabhála toirmiscthe i bpróifílí scanadh
inléite amháin.

Ní chlúdaíonn na próifílí seo ach an scanadh statach. Ní dheimhníonn siad tástálacha
táirge, clúdach, pacáistiú, seiceálacha seachtracha ná glacadh iomlán iarrthóra le haghaidh
eisiúna. Úsáideann glacadh sreafa oibre `config/quality/admission-policy.json` nasctha agus
`scripts/quality/admission-verdict.mjs`. Fanann próifílí an bhreathnóra eisiúna ar leith;
iniúch a seiceálacha agus a n-admhálacha infheidhme go neamhspleách. Is tagairt é an
fardal próis thíos, ní cruthúnas gur ritheadh geata i ndáiríre.

Tá na scripteanna faoi `scripts/check/` (geataí beartais) agus `scripts/quality/`
(inneall ratchet). Is é `.github/workflows/ci.yml` foinse na fírinne do CI.

### Conair thapa PR eisiúna (`quality.yml`)

Comhlánaíonn `.github/workflows/quality.yml` CI ar PRanna main/release, brúiteanna chuig
`main`, seoladh agus grúpaí cumaiscthe. Úsáideann PRanna seiceálacha tapa scagtha de réir
cosáin. Baineadh an tógáil dhúblach a bhí díchumasaithe go buan; fanann na seiceálacha
fíor maidir le tógáil/pacáistiú/tosú in CI.

#### Tuairisc ar thástálacha deartháireacha dearmadta

Athúsáideann `npm run check:forgotten-sibling-tests` an réiteoir iompórtála atá taobh thiar de mhap tionchair na dtástálacha.
I gcás gach modúil táirgthe athraithe, tuairiscíonn sé slabhraí cinntitheacha
`changed module/symbol -> static consumer -> candidate sibling test` ó thomhaltóir statach go tástáil deirfiúr iarrthach nuair a bhíonn an tástáil iarrthach as láthair ón difríocht sa pull request. Coinnítear an achoimre Markdown agus toradh JSON mar dhéantán sreafa oibre `forgotten-sibling-tests` le haghaidh calabraithe roimh aon rolladh amach blocála.

Is diagnóisic réitigh amháin iad ath-onnmhairí bairille agus iompórtálacha dinimiciúla; ní chruthaíonn siad aon toradh blocála riamh. Tá na heisceachtaí athbhreithnithe in
`config/quality/forgotten-sibling-allowlist.json`. Ní mór do gach iontráil an tomhaltóir agus an tástáil iarrthach a ainmniú, réasúnaíocht shonrach a thabhairt, agus nasc a dhéanamh le saincheist nó pull request GitHub. Teipeann ar iontrálacha míchumtha ar bhealach dúnta. Ní féidir le heisceachtaí tástáil iarrthach scriosta ná difríocht a chuireann `.skip`/`.todo` leis a chosc; is faoin ngeata neamhspleách blocála `check:test-masking` a bhíonn lagú dearbhuithe agus cumasc eile.

#### `check-ui-value-drift` — geata aistriúchán seanchaite

Gabhann sé an t-aistarraingt i18n amháin nach féidir leis na geataí struchtúracha eile a fheiceáil: athscríobhtar luach Béarla agus fágtar na haistriúcháin a díorthaíodh ón mBéarla _roimhe sin_ ar gcúl, agus mar sin leanann úsáideoirí nach Béarla a labhraíonn orthu ag léamh téacs atá muiníneach ó thaobh na foclaíochta de, ach atá mícheart anois.

Seoladh é seo i ndáiríre. Athscríobhadh `oauthModal.googleOAuthWarning` nuair a cuireadh cúntóir logála isteach Antigravity leis (#5203); choinnigh **39 as 43 locale** téacs ag insint d’oibreoirí “cóipeáil an URL iomlán agus greamaigh thíos é” — sreabhadh nach féidir a chur i gcrích don soláthraí sin. Níor tugadh faoi deara é go dtí #8463 mar gheall ar:

- ní líonann `sync-ui-keys` ach eochracha atá **in easnamh**, ní eochracha atá **as dáta**;
- comhaireamh `check-ui-keys-coverage` láithreacht na heochrach, mar sin áirítear aistriúchán as dáta mar rud clúdaithe;
- rianaíonn `check-translation-drift` scátháin doiciméadúcháin `docs/i18n/<locale>/**.md` —
  ní léann sé `src/i18n/messages/*.json` riamh. Ag cur bac sa phost `docs-sync-strict` ón athshioncronú i 2026-09: cuir doiciméad lárnach in eagar → `npm run i18n:run -- --files=<doc>` (ar leibhéal na rannóige, saor).

**Feasach ar na difríochtaí, ní bunaithe ar bhunlíne.** Déanann sé comparáid idir `en.json` ag bun cumaisc agus an crann oibre; i gcás gach eochrach ar athraigh a luach Béarla, tá aon locale a bhfuil aistriúchán gan teagmháil fós aige as dáta. Déanann sé seo fiachas a bhí ann cheana a **reo d’aon ghnó** — ní féidir le difríocht a nochtadh cén sean-Bhéarla as ar tháinig aistriúchán seanbhunaithe, mar sin ní mheasann an geata ach an rud a mbaineann an t-athrú reatha leis. Bheadh an rogha eile (bunlíne hais de réir na heochrach) ina costas de chomhad ginte thart ar 600 KB, 3× níos mó ná an bhunlíne is mó atá ann cheana, agus athruithe torannacha ann le gach PR i18n.

Dhá bhealach chun é a shásamh:

1. nuashonraigh na haistriúcháin lena mbaineann, nó
2. socraigh iad mar `__MISSING__:<new english>` — freastalaíonn an runtime ar an mBéarla ceartaithe ansin
   (`src/i18n/request.ts::deepMergeFallback`, #7258) agus cuirtear an eochair sa scuaine le haistriú.

Má d’athraigh **brí** na teaghrán, b’fhearr an eochair a **athainmniú**: ní féidir le heochair nua aistriúchán as dáta a oidhreacht. Sin é an patrún a d’úsáid #8463.

```bash
npm run i18n:check-value-drift          # strict (what CI runs)
npm run i18n:check-value-drift:warn     # report only
BASE_REF=origin/release/vX.Y.Z npm run i18n:check-value-drift
```

Scoireann sé le 0 agus `SKIP reason=base-unresolved` nuair nach féidir catalóg na bunlíne a léamh (clón éadomhain gan an tagairt bhunlíne), rud a dhéanann aithris ar `check-openapi-breaking`.

### Raicín CodeQL: minicíocht athnuachana agus truicear láimhe

Léann `check:codeql-ratchet` **staid an stórtha, a athnuaitear de réir sceidil — ní do gach PR.**

## Laghduithe Raicín a Chur i dTaisce — an treo anuas (#8584)

Níl an raicín ach leath-uathoibríoch, agus is é an leath mícheart é. Is eagarthóireacht láimhe JSON é **uasteorainn a ardú**
a thógann deich soicind agus is é an bealach is tapúla é chun PR teipthe a dhíbhlocáil.
Chun ceann a **ísliú**, ní mór do dhuine `--update` a rith agus an toradh a chur i dtiomantas — agus go dtí
gur cuireadh an jab `bank-ratchet-shrinks` i bhfeidhm, níor rith aon sreabhadh oibre é. An iarmhairt thomhaiste
(2026-07-25): 18 gcomhad reoite a bhí cheana féin ag nó faoi bhun na huasteorann 800 líne do chomhad nua, an ceann is measa
ag 132× (`src/shared/validation/schemas.ts`, 19 líne agus uasteorainn 2,523 aige); d'ardaigh
uasteorainn na castachta `1794 → 2169` thar ~37 nóta athbhunaithe bunlíne agus laghdú amháin go díreach
(−1); agus scríobhadh "teannaigh trí `--update` sa chéad timthriall eile" 31 uair agus cloíodh leis
uair amháin. Déanann uasteorainn a mhaireann níos faide ná an cód a thuill í lamháltas fáis go ciúin de gach
dí-chomhdhéanamh críochnaithe don chéad duine eile a chuireann an comhad in eagar.

Dúnann `nightly-release-green.yml` → jab **`bank-ratchet-shrinks`** an lúb sin:

|             |                                                                                                                             |
| ----------- | --------------------------------------------------------------------------------------------------------------------------- |
| Ritheann ar | `schedule` (3×/lá) + `workflow_dispatch` — **ní** `push`, d'aon ghnó                                                        |
| Tomhaiseann | an `release/vX.Y.Z` is airde, leis an réiteach céanna + cosaint insteallta agus atá ag `release-green`                      |
| Scríobhann  | `check:file-size --update` agus `check:complexity-ratchets --update` (ní dhéanann ceachtar acu ach laghdú de réir dearaidh) |
| Fíoraíonn   | `npm run check:ratchet-bank` (`scripts/quality/verify-ratchet-bank.mjs`)                                                    |
| Seachadann  | PR amháin atá cothrom le dáta i gcónaí i gcoinne an bhrainse eisiúna — nuashonraithe le fórsa, gan turscar riamh            |

Déantar an cur i dtaisce i mbaisceanna seachas in aghaidh gach brú toisc nach bhfuil aon riachtanas aga folaigh aige (is leor laghdú
a chur i dtaisce laistigh de 8h), ach dhéanfadh rith in aghaidh gach cumaisc brainse an PR a atógáil arís agus arís eile
le linn feachtais chumaisc agus d'íocfadh sé as siúl iomlán ESLint gach uair. Fanann an brath ar
push (`release-green`); ní dhéantar ach an cur i dtaisce i mbaisceanna.

### An fíoraitheoir sábháilteachta

Scríobhann an jab chuig na bunlínte gan mhaoirseacht, mar sin is é `verify-ratchet-bank.mjs` a fhágann
go bhfuil sé sin inghlactha. Déanann sé diff den chrann tar éis `--update` i gcoinne `HEAD` agus **tobscoireann sé an jab
sula mbíonn aon tiomantas ann** — gan aon PR a oscailt — mura bhfuil gach athrú ar cheann díobh seo:

- iontráil uimhriúil `frozen` / `testFrozen` **íslithe** nó **bainte**
- `complexity-baseline.json` → `count` **íslithe**
- `quality-baseline.json` → `metrics.cognitiveComplexity.value` **íslithe**

Teipeann ar aon rud eile: uimhir a ardú, iontráil a chur leis, `cap`/`testCap` a athrú, nó
nóta `_rebaseline_*` a scriosadh/athscríobh (is iad na nótaí sin an rian iniúchta a mhíníonn cén fáth a bhfuil gach
uasteorainn ann agus stóráiltear iad laistigh den oibiacht `frozen` chéanna leis na hiontrálacha comhaid).
Bheadh bota a d'fhéadfadh uasteorainn a ardú i bhfad níos measa ná an staid reatha. Cosaint ar chúlchéimniú:
`tests/unit/verify-ratchet-bank.test.ts`.

Ní bhrúnn an jab chuig `release/*` riamh — cumascann duine an PR, mar sin ní féidir le droch-thomhas
teacht i bhfeidhm gan athbhreithniú.

## Beartas an Liosta Ceadaithe

Úsáideann gach geata nach féidir leis teip mar gheall ar sháruithe a bhí ann cheana liosta ceadaithe reoite
(m.sh., `KNOWN_STALE_DOC_REFS`, `KNOWN_MISSING`, `KNOWN_RAW_SQL`). Is é seo an beartas:

**Ceartaigh an bhunchúis; ná húsáid an liosta ceadaithe ach amháin nuair a bhí an sárú ann cheana agus
nach féidir é a cheartú san PR céanna.**

Agus iontráil á cur le liosta ceadaithe:

1. Cuir nóta tráchta san áireamh leis an údar.
2. Déan tagairt don tsaincheist rianaithe (m.sh., `// #3498 — Gné de Chéim 2, gan cur i bhfeidhm fós`).
3. Bain an iontráil san PR céanna a cheartaíonn an sárú — is fabht ann féin é iontráil as dáta nach
   gcuireann sárú gníomhach faoi chois a thuilleadh (cuirfidh forfheidhmiú um iontrálacha as dáta 6A.3
   faoi deara go dteipfidh ar an ngeata mar gheall ar iontráil dhílleachta sa liosta ceadaithe nuair a chuirfear i bhfeidhm é).

Ná cuir iontrálacha le liostaí ceadaithe chun go n-éireoidh le tástálacha níos tapúla. Tugann geata glas le liosta
ceadaithe atá ag fás tuiscint bhréagach ar cháilíocht.

### Nuair a theipeann ar gheata ar do PR

1. **Léigh aschur an gheata go cúramach** — insíonn sé duit go díreach cén comhad nó siombail a sháraigh
   an riail.
2. **Ceartaigh an sárú** — seiceálacha cinntitheacha ar an gcóras comhad iad formhór na ngeataí agus éiríonn leo a luaithe
   atá an cód ceart.
3. **Má bhí an sárú ann cheana** (is é sin, ní tusa a thug isteach é ach clúdaíonn an geata anois
   é): cuir iontráil leis an liosta ceadaithe mar aon le nóta tráchta údaraithe agus saincheist rianaithe.
4. **Más raicín é an geata** (clúdach, rabhaidh ESLint, dúbailt, castacht):
   rinne d'athrú an mhéadracht níos measa. Ceartaigh an bhunfhadhb, nó (go hannamh) rith
   `npm run quality:ratchet -- --update` má tá an t-athrú d'aon ghnó agus má tá meath na méadrachta
   inghlactha — ach mínigh an fáth i gcur síos an PR.
5. Is chun faisnéise iad **geataí comhairleacha** (`continue-on-error: true`) — ní chuireann siad bac ar
   chumasc ach bíonn siad le feiceáil in achoimre CI. Ceartaigh iad mar sin féin.
