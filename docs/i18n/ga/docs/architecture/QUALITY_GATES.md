Is é an doiciméad seo an tagairt údarásach do gach geata cáilíochta CI in OmniRoute.
Déantar cur síos ann ar gach geata, ar a bhfíoraíonn sé, ar an jab CI ina ritear é, ar cé acu a úsáideann sé
bonnlíne raicéid nó polasaí pas/teip, agus ar cé acu a chuireann sé bac ar an tógáil nó atá sé comhairleach.

Le haghaidh achoimre ghairid agus pholasaí an liosta ceadaithe, féach an rannán "Geataí Cáilíochta & Raicéid"
in `AGENTS.md`. Le haghaidh an mheasúnaithe chriticiúil, an aicmithe aibíochta, agus an phlean macasamhlaithe
neamhspleách ar uirlisí don chóras céanna, féach an
[Leabhar Súgartha do Gheataí Cáilíochta](../ops/QUALITY_GATE_PLAYBOOK.md).

## Fardal geataí agus próifílí forghníomhaithe

### Glacadh iarrthóra

Aschaileann sreafaí oibre CI agus Quality Gates breith chobhsaí an ceann acu: `Gate / CI` agus
`Gate / Quality`. Áiríonn a mbeartas iontrála leaganaithe gach jab suas srutha mar riachtanach nó comhairleach. Caithfidh jab riachtanach infheidhme a éirí: ní féidir le torthaí atá ar iarraidh,
cealaithe, scipeáilte, ar feitheamh agus anaithnid PASS a bhunú. Is féidir le haicmiú bailí
docs-only nó catalog-only lána cód a dhéanamh neamh-infheidhme; ní iarrthóir glactha é PR dréachta. Ní thugann lipéad `hotfix` faoiseamh ó fhianaise.

Clúdaíonn an dá shreabhadh oibre PRanna isteach i mbrainsí main/release, brúnna chuig `main`, seoladh láimhe
agus imeachtaí grúpa cumaiscthe. Ritheann brú, seoladh agus grúpa cumaiscthe an roghnú iomlán. Ní thosaíonn brúnna chuig
`release/**` iad (2026-10-18): rith gach athrú an mhaitrís ar a PR féin cheana agus is cúram Release-Green í an teaglaim chumaiscthe (`docs/ops/RUNNER_BOX.md` → Hosted lane). Baineann forcanna
agus grúpaí cumaiscthe úsáid as rithithe óstáilte do jabhanna a roghnaíonn rithithe féin-óstáilte
ar shlí eile; caithfear cumas óstála leordhóthanach a fhíorú roimh rolladh amach.

Sonraíonn gach admháil JSON an SHA seiceáilte amach, rith an tsreafa oibre agus an iarracht.
Diúltaíonn an CLI mímheaitseáil SHA idir an seiceáil amach agus an t-imeacht. Ceanglaíonn tástálacha sreafa oibre
ballraíocht an bheartais le liosta `needs` an jab bhreithiúnais ionas nach féidir le lána nua nó bainte imeacht go ciúin.
Clúdaíonn na hadmhálacha a sreabhadh oibre féin, ní foilseachán, imscaradh ná inmheánachtaí
scanaitheora comhairligh atá ann cheana féin. Is athrú riaracháin ar leith é an dá ainm seiceála a ghníomhachtú
i rialacha brainse; ní chosnaíonn cur leis na jabhanna seo brainse leis féin.

### Fardal an scanadh statach

Tá an fardal npm-alias leaganaithe agus ballraíocht an scanadh statach suite i
`config/quality/gate-manifest.json`. Rith `npm run check:gate-manifest` chun
ainmneacha scripteanna agus orduithe beachta a bhailíochtú i gcoinne `package.json`; fágann breiseanna, baint
agus seachrán ordaithe go dteipeann ar an hook áitiúil agus ar jabhanna aicmiú an athraithe in CI araon.
Ní jab sreafa oibre, sampla maitríse ná cás tástála é ailias: níor cheart na comhaireamha seo
a chur i láthair mar chinn inmhalartaithe.

Bain úsáid as `npm run quality:scan -- --list` nó `npm run quality:scan:fast -- --list`
chun na hailias roghnaithe a scrúdú gan iad a rith. Glaoíonn an rithire ar
phointe iontrála npm, mar sin caomhnaítear a runtime (Bun san áireamh nuair atá sé cumraithe).
Taifeadann an manifest ailias lasmuigh de na próifílí sin mar chinn a ghlaoitear ar leithligh orthu, agus
tá orduithe cothabhála coiscthe i bpróifílí scanadh inléite amháin.

Ní chlúdaíonn na próifílí seo ach an scanadh statach. Ní dheimhníonn siad tástálacha táirge,
clúdach, pacáistiú, seiceálacha seachtracha ná glacadh iomlán eisiúna d'iarrthóir.
Baineann iontráil an tsreafa oibre úsáid as an `config/quality/admission-policy.json` nasctha agus as
`scripts/quality/admission-verdict.mjs`. Fanann próifílí breathnóra eisiúna ar leithligh;
scrúdaigh a seiceálacha infheidhme agus a n-admhálacha go neamhspleách. Is tagairt é an fardal
próis thíos, ní cruthúnas gur rith geata i ndáiríre.

Tá scripteanna faoi `scripts/check/` (geataí beartais) agus faoi `scripts/quality/` (inneal racaid).
Is é `.github/workflows/ci.yml` foinse fhírinne CI.

### Conair thapa do PR eisiúna (`quality.yml`)

Comhlánaíonn `.github/workflows/quality.yml` CI ar PRanna main/release, brúnna chuig `main`,
seoladh agus grúpaí cumaiscthe. Baineann PRanna úsáid as seiceálacha tapa scagtha de réir conaire.
Baineadh an tógáil dhúblach a bhí díchumasaithe go buan; fanann na fíorsheiceálacha tógála/pacáistithe/tosaithe in CI.

#### Tuarascáil faoi thástálacha sibling dearmadta

Athúsáideann `npm run check:forgotten-sibling-tests` an réiteoir iompórtála atá taobh thiar de léarscáil tionchair na dtástálacha.
Do gach modúl táirgeachta athraithe, tuairiscíonn sé slabhraí cinnteoireachtúla
`changed module/symbol -> static consumer -> candidate sibling test` nuair atá an tástáil
iarrthóra as láthair ó dhifríocht an pull-request. Coimeádtar an achoimre Markdown agus an toradh
JSON mar chruthshaothar sreafa oibre `forgotten-sibling-tests` le haghaidh calabrúcháin roimh aon
rolladh amach blocála.

Is diagnóisic réitigh amháin iad ath-onnmhaircí barrel agus iompórtálacha dinimiciúla; ní
chruthaíonn siad fionnachtain bhlocála riamh. Tá eisceachtaí athbhreithnithe i
`config/quality/forgotten-sibling-allowlist.json`. Caithfidh gach iontráil an tomhaltóir agus an
tástáil iarrthóra a ainmniú, réasúnaíocht shonrach a thabhairt, agus nasc a chur le saincheist
GitHub nó le pull-request. Teipeann go dúnta ar iontrálacha míchumtha. Ní féidir le heisceachtaí
tástáil iarrthóra scriosta nó difríocht a chuireann `.skip`/`.todo` leis a chur faoi chois;
fanann lagú dearbhuithe agus maisciú eile faoi úinéireacht an gheata `check:test-masking` a
bhlocálann go neamhspleách.

#### `check-ui-value-drift` — geata i gcoinne aistriúchán as dáta

Gabhtar an t-aon chúlú i18n nach féidir leis na geataí eile a fheiceáil go struchtúrtha:
athscríobhtar luach Béarla agus fanann na haistriúcháin a d'aslaigh an Béarla _roimhe seo_
ina ndiaidh, agus mar sin leanann úsáideoirí neamh-Bhéarla orthu ag léamh téacs atá mícheart
anois cé gur scríobhadh go muiníneach é.

Seoladh é seo i ndáiríre. Athscríobhadh `oauthModal.googleOAuthWarning` nuair a seoladh
cuiditheoir logála isteach Antigravity (#5203); choimeád **39 as 43 logcháil** téacs ag rá le
hoibritheoirí "cóipeáil an URL iomlán agus greamaigh thíos é" — sreabhadh nach féidir a
thabhairt chun críche don sholáthraí sin. Níor tugadh faoi deara é go dtí #8463 mar:

- Ní líonann `sync-ui-keys` siar ach eochracha atá **as láthair**, riamh cinn atá **as dáta**;
- Áiríonn `check-ui-keys-coverage` _láithreacht_ na n-eochracha, mar sin faigheann aistriúchán
  as dáta marc amhail is go mbeadh sé clúdaithe;
- Rianaíonn `check-translation-drift` na scátháin doiciméadaithe `docs/i18n/<locale>/**.md` —
  ní léann sé `src/i18n/messages/*.json` riamh. Ag blocáil sa jab `docs-sync-strict` ón
  athshioncronú 2026-09: cuir croídhoiciméad in eagar → `npm run i18n:run -- --files=<doc>`
  (ar leibhéal na rannóige, saor).

**Feasach ar an diff, ní bunaithe ar bhunlíne.** Déanann sé `en.json` ag bunáit an chumaisc a
chur i gcomparáid leis an gcrann oibre; i gcás gach eochair ar athraigh a luach Béarla, tá aon
logcháil a bhfuil aistriúchán gan bhaint fós aici as dáta. Déanann sé seo **fiacha
réamhbheatha a reo** d'aon ghnó — ní féidir le diff a nochtadh cén sean-Bhéarla as a dtagann
aistriúchán fadsheasaimh, mar sin ní bhreithníonn an geata ach an méid a dhéanann an t-athrú
reatha teagmháil leis. Chosnódh an mhalairt rogha (bunlíne hais in aghaidh gach eochrach)
comhad ginte de ~600 KB, 3× méid an bhunlíne is mó atá ann cheana, agus é ag corraí ar gach
i18n PR.

Dhá bhealach chun é a shásamh:

1. nuashonraigh na haistriúcháin atá i gceist, nó
2. socraigh iad go `__MISSING__:<new english>` — seirbheálann an rith-am an Béarla ceartaithe
   ansin (`src/i18n/request.ts::deepMergeFallback`, #7258) agus cuirtear an eochair sa scuaine
   le haistriú.

Má d'athraigh **brí** an teaghráin, is fearr **an eochair a athainmniú**: ní féidir le heochair
nua aistriúchán as dáta a fháil le hoidhreacht. Sin é an patrún a d'úsáid #8463.

```bash
npm run i18n:check-value-drift          # docht (an rud a ritheann CI)
npm run i18n:check-value-drift:warn     # tuairisc amháin
BASE_REF=origin/release/vX.Y.Z npm run i18n:check-value-drift
```

Scoirfidh sé as le 0 in éineacht le `SKIP reason=base-unresolved` nuair nach féidir an catalóg
bonn a léamh (clón éadomhain gan an tagairt bonn), ar aon dul le `check-openapi-breaking`.

## Laghduithe Raicín a Chur i dTaisce — an treo anuas (#8584)

Níl an raicín ach leath-uathoibríoch, agus is é an leath mícheart é. Is eagarthóireacht láimhe JSON é **uasteorainn a ardú**
a thógann deich soicind agus is é an bealach is tapúla é chun PR teipthe a dhíbhlocáil.
Chun ceann a **ísliú**, ní mór do dhuine `--update` a rith agus an toradh a chur i dtiomantas — agus go dtí
gur cuireadh an jab `bank-ratchet-shrinks` i bhfeidhm, níor rith aon sreabhadh oibre é. An iarmhairt thomhaiste
(2026-07-25): 18 gcomhad reoite a bhí cheana féin ag nó faoi bhun na huasteorann 800 líne do chomhad nua, an ceann is measa
ag 132× (`src/shared/validation/schemas.ts`, 19 líne agus uasteorainn 2,523 aige); d'ardaigh
uasteorainn na castachta `1794 → 2169` thar ~37 nóta athbhunaithe bunlíne agus laghdú amháin go díreach
(−1); agus scríobhadh "teannaigh trí `--update` sa chéad timthriall eile" 31 uair agus cloíodh leis
uair amháin. Déanann uasteorainn a mhaireann níos faide ná an cód a thuill í lamháltas fáis go ciúin de gach
dí-chomhdhéanamh críochnaithe don chéad duine eile a chuireann an comhad in eagar.

Dúnann `nightly-release-green.yml` → jab **`bank-ratchet-shrinks`** an lúb sin:

|             |                                                                                                                             |
| ----------- | --------------------------------------------------------------------------------------------------------------------------- |
| Ritheann ar | `schedule` (3×/lá) + `workflow_dispatch` — **ní** `push`, d'aon ghnó                                                        |
| Tomhaiseann | an `release/vX.Y.Z` is airde, leis an réiteach céanna + cosaint insteallta agus atá ag `release-green`                      |
| Scríobhann  | `check:file-size --update` agus `check:complexity-ratchets --update` (ní dhéanann ceachtar acu ach laghdú de réir dearaidh) |
| Fíoraíonn   | `npm run check:ratchet-bank` (`scripts/quality/verify-ratchet-bank.mjs`)                                                    |
| Seachadann  | PR amháin atá cothrom le dáta i gcónaí i gcoinne an bhrainse eisiúna — nuashonraithe le fórsa, gan turscar riamh            |

Déantar an cur i dtaisce i mbaisceanna seachas in aghaidh gach brú toisc nach bhfuil aon riachtanas aga folaigh aige (is leor laghdú
a chur i dtaisce laistigh de 8h), ach dhéanfadh rith in aghaidh gach cumaisc brainse an PR a atógáil arís agus arís eile
le linn feachtais chumaisc agus d'íocfadh sé as siúl iomlán ESLint gach uair. Fanann an brath ar
push (`release-green`); ní dhéantar ach an cur i dtaisce i mbaisceanna.

### An fíoraitheoir sábháilteachta

Scríobhann an jab chuig na bunlínte gan mhaoirseacht, mar sin is é `verify-ratchet-bank.mjs` a fhágann
go bhfuil sé sin inghlactha. Déanann sé diff den chrann tar éis `--update` i gcoinne `HEAD` agus **tobscoireann sé an jab
sula mbíonn aon tiomantas ann** — gan aon PR a oscailt — mura bhfuil gach athrú ar cheann díobh seo:

- iontráil uimhriúil `frozen` / `testFrozen` **íslithe** nó **bainte**
- `complexity-baseline.json` → `count` **íslithe**
- `quality-baseline.json` → `metrics.cognitiveComplexity.value` **íslithe**

Teipeann ar aon rud eile: uimhir a ardú, iontráil a chur leis, `cap`/`testCap` a athrú, nó
nóta `_rebaseline_*` a scriosadh/athscríobh (is iad na nótaí sin an rian iniúchta a mhíníonn cén fáth a bhfuil gach
uasteorainn ann agus stóráiltear iad laistigh den oibiacht `frozen` chéanna leis na hiontrálacha comhaid).
Bheadh bota a d'fhéadfadh uasteorainn a ardú i bhfad níos measa ná an staid reatha. Cosaint ar chúlchéimniú:
`tests/unit/verify-ratchet-bank.test.ts`.

Ní bhrúnn an jab chuig `release/*` riamh — cumascann duine an PR, mar sin ní féidir le droch-thomhas
teacht i bhfeidhm gan athbhreithniú.

## Beartas an Liosta Ceadaithe

Úsáideann gach geata nach féidir leis teip mar gheall ar sháruithe a bhí ann cheana liosta ceadaithe reoite
(m.sh., `KNOWN_STALE_DOC_REFS`, `KNOWN_MISSING`, `KNOWN_RAW_SQL`). Is é seo an beartas:

**Ceartaigh an bhunchúis; ná húsáid an liosta ceadaithe ach amháin nuair a bhí an sárú ann cheana agus
nach féidir é a cheartú san PR céanna.**

Agus iontráil á cur le liosta ceadaithe:

1. Cuir nóta tráchta san áireamh leis an údar.
2. Déan tagairt don tsaincheist rianaithe (m.sh., `// #3498 — Gné de Chéim 2, gan cur i bhfeidhm fós`).
3. Bain an iontráil san PR céanna a cheartaíonn an sárú — is fabht ann féin é iontráil as dáta nach
   gcuireann sárú gníomhach faoi chois a thuilleadh (cuirfidh forfheidhmiú um iontrálacha as dáta 6A.3
   faoi deara go dteipfidh ar an ngeata mar gheall ar iontráil dhílleachta sa liosta ceadaithe nuair a chuirfear i bhfeidhm é).

Ná cuir iontrálacha le liostaí ceadaithe chun go n-éireoidh le tástálacha níos tapúla. Tugann geata glas le liosta
ceadaithe atá ag fás tuiscint bhréagach ar cháilíocht.

### Nuair a theipeann ar gheata ar do PR

1. **Léigh aschur an gheata go cúramach** — insíonn sé duit go díreach cén comhad nó siombail a sháraigh
   an riail.
2. **Ceartaigh an sárú** — seiceálacha cinntitheacha ar an gcóras comhad iad formhór na ngeataí agus éiríonn leo a luaithe
   atá an cód ceart.
3. **Má bhí an sárú ann cheana** (is é sin, ní tusa a thug isteach é ach clúdaíonn an geata anois
   é): cuir iontráil leis an liosta ceadaithe mar aon le nóta tráchta údaraithe agus saincheist rianaithe.
4. **Más raicín é an geata** (clúdach, rabhaidh ESLint, dúbailt, castacht):
   rinne d'athrú an mhéadracht níos measa. Ceartaigh an bhunfhadhb, nó (go hannamh) rith
   `npm run quality:ratchet -- --update` má tá an t-athrú d'aon ghnó agus má tá meath na méadrachta
   inghlactha — ach mínigh an fáth i gcur síos an PR.
5. Is chun faisnéise iad **geataí comhairleacha** (`continue-on-error: true`) — ní chuireann siad bac ar
   chumasc ach bíonn siad le feiceáil in achoimre CI. Ceartaigh iad mar sin féin.
