Is é an doiciméad seo an tagairt údarásach do gach geata cáilíochta CI in OmniRoute.
Déantar cur síos ann ar gach geata, ar a bhfíoraíonn sé, ar an jab CI ina ritear é, ar cé acu a úsáideann sé
bonnlíne raicéid nó polasaí pas/teip, agus ar cé acu a chuireann sé bac ar an tógáil nó atá sé comhairleach.

Le haghaidh achoimre ghairid agus pholasaí an liosta ceadaithe, féach an rannán "Geataí Cáilíochta & Raicéid"
in `AGENTS.md`. Le haghaidh an mheasúnaithe chriticiúil, an aicmithe aibíochta, agus an phlean macasamhlaithe
neamhspleách ar uirlisí don chóras céanna, féach an
[Leabhar Súgartha do Gheataí Cáilíochta](../ops/QUALITY_GATE_PLAYBOOK.md).

## Fardal na ngeataí agus próifílí forghníomhaithe

### Cead isteach iarrthóra

Scaoileann gach sreabhadh oibre CI agus Quality Gates fíorasc cobhsaí: `Gate / CI` agus `Gate / Quality`. Áiríonn a mbeartas iontrála leaganacha gach post réamhtheachtacha de réir mar is gá nó mar chomhairleach. Ní mór go n-éireodh le post riachtanach infheidhme: ní féidir torthaí in easnamh, curtha ar ceal, scipeála, ar feitheamh agus anaithnid a bhunú PASS. Is féidir le haicmiú bailí docs-amháin nó catalóg-amháin lána cóid a dhéanamh neamh-infheidhmithe; ní iarrthóir glactha le gnáthdhréacht PR. Ní tharscaoileann lipéad `hotfix` fianaise.

Clúdaíonn an dá shreabhadh oibre PRs isteach i mbrainsí main/release, brú go `main`, seolta láimhe agus imeachtaí cumaisc-ghrúpa. Brúigh, seol agus reáchtáil an grúpa cumaisc an rogha iomlán. Ritheann dréacht scuaine Mergify iontaofa freisin poist `full-code`/`full-code-e2e` infheidhme; gnáth PRs skip iad. Roimh chumasc láimhe, reáchtáil seoladh iomlán ar an iarrthóir cruinn. Ní chuireann brúnna chuig `release/**` tús leis na sreafaí oibre seo; Léiríonn Release-Green an bonn cumaiscthe ar leithligh (`docs/ops/RUNNER_BOX.md` → Hosted lána). Úsáideann forcanna agus grúpaí cumasc reathaithe óstaithe le haghaidh poist a roghnaíonn reathaithe féin-óstáilte; ní mór acmhainn ósta leordhóthanach a fhíorú roimh an rolladh amach.

Ritheann gnáth- PR an rogha tapa. Ní ritheann lánaí `full-code` agus `full-code-e2e` an bheartais iontrála (E2E, comhtháthú, déantán pacáiste, Electron smoke, Bun SQLite, éiceachórais agus cliaint prótacail) ach amháin ar dhréacht scuaine Mergify nó ar rith iomlán: `gh workflow run ci.yml --ref <branch>`.

Aithníonn gach admháil JSON an SHA, rith an tsreafa oibre agus an iarracht atá seiceáilte amach. Diúltaíonn an CLI do neamhréir checkout/event SHA. Ceanglaíonn tástálacha sreafa oibre an bhallraíocht i bpolasaí ar liosta `needs` an fhíoraisc mar sin ní féidir le lána nua nó lána a bhaintear imeacht as go ciúin. Clúdaíonn na hadmhálacha a sreabhadh oibre féin, ní foilsiú, imscaradh, nó inmheánach scanóirí comhairleacha atá ann cheana féin. Is athrú riaracháin ar leith é na seiceálacha is infheidhme a éilítear i rialacha brainse; ní chosnaíonn sainiú a bpoist brainse féin.

Is seiceáil neamhspleách sreafa oibre é `API Route Typecheck`, lasmuigh den dá fhíorasc comhiomlán agus de phróifíl statach iomlán an bhreathnóra áitiúil. Scrúdaigh a thoradh ar leithligh don iarrthóir cruinn. Ritheann `.github/workflows/api-route-typecheck.yml` ar PRs isteach i `main` nó `release/**`, brú chuig ceachtar den teaghlach brainse, seoladh láimhe, agus imeachtaí `merge_group` den chineál `checks_requested`. Níl aon scagaire cosáin aige. Seiceáil grúpaí Cumaisc amach `merge_group.head_sha`; imeachtaí eile seiceáil amach `github.sha`. Úsáideann gach imeacht na tástálacha diagnóiseacha API geata agus aonad geata céanna. iarrann retargets PR base seic nua; Úsáideann body/title edits an t-ainm breathnóireachta amháin `Admission not requested / API Route Typecheck` agus ní féidir leo an tseiceáil iontrála a athsholáthar.

### Fianaise choinnithe sa laghdaitheoir glactha

Laghdaíonn `scripts/quality/validate-release-acceptance.mjs` plean soláthraithe agus a
mhanifist; ní chruthaíonn sé go gclúdaíonn an plean an phíblíne eisiúna iomlán.
Socraíonn a thuarascálacha `releaseAcceptance: false` go sainráite, fiú nuair atá an
plean sin `VERIFIED`. Úsáideann sreabhadh oibre `release-acceptance.yml` daingneáin
scátha fós, seachas fíor-admhálacha tógála, pacáistithe, tosaithe nó cur chun cinn.

Éilíonn an CLI `--evidence-root` chun fianaise choinnithe a fhíorú. Réitítear comhaid
mar `<evidence-root>/<artifact_id>/<member>` agus haisítear iad mar SHA-256. Cuireann
taifead PASS gan fhianaise, comhad atá ar iarraidh nó athraithe, cosán neamhshábháilte
nó nasc siombalach cosc ar fhíorú. Ní hionann comhaid atá ar iarraidh agus logaí
rathúla folmha. Fanann seiceálacha SHA/rite/iarrachta atá ann cheana neamhspleách:
ní féidir le bearta comhoiriúnacha admháil atá as dáta a shábháil. Ní cruthúnas ar
bharántúlacht an fhorghníomhaithe ná ar chur chun cinn déantáin í sláine comhaid.

### Úsáideann DAST an tógáil CI fíoraithe

Glaonn an jab éigeantach CI `dast-smoke` ar `.github/workflows/dast-smoke.yml` tar éis `build`. Leanann sé an roghnú céanna cóid agus dréachtaí leis an tógáil, lena n-áirítear PRanna tacaithe ó forkanna, PRanna atá dírithe ar bhrainse eisiúna, agus grúpaí cumaisc. Cuireann jab DAST atá ar iarraidh, teipthe, curtha ar ceal nó scipeáilte gan choinne bac ar `Gate / CI`. Níl truicear neamhspleách PR ná seolta láimhe ag an sreabhadh oibre in-athúsáidte; úsáideann bailíochtú láimhe seoladh CI chun an tógáil agus an tomhaltóir a choinneáil san aon rith amháin.

Séalaíonn `scripts/ci/next-build-provenance.mjs` an déantán iomlán Next lena achoimre tar, stór/imeacht/rith, iarracht an táirgeora, head/base/checkout/tree, aitheantais sreafa oibre, comhad glasála, leagan beacht Node agus ABI, ardán agus cuachtaire. Roghnaíonn DAST ID do-athraithe an déantáin ó `needs.build.outputs`, éilíonn sé fíorú achoimre an íoslódála, agus ríomhann sé hais ZIP go neamhspleách lena cur i gcomparáid le hachoimre an táirgeora sula mbaintear an dá bhall ceadaithe amach trí `scripts/ci/unpack-ci-build.py`. Caithfidh an manifest agus an chartlann tar teacht le haschuir neamhspleácha an táirgeora freisin sula mbaintear crann Next amach. Ní lorgaíonn sé riamh an tógáil rathúil is déanaí ar an mbrainse. Féadfaidh athrith páirteach an iarracht chéanna ón táirgeoir a athúsáid má mheaitseálann a ID agus gach ionchur fós; taifeadann an admháil an dá iarracht.

Fanann an tomhaltóir ar reathaí Linux óstáilte le cead léite amháin don stór agus gan rúin an stóir. Suiteálann sé leagan beacht Node an táirgeora, ansin cuireann sé an CLI le chéile le `OMNIROUTE_REQUIRE_PREBUILT_NEXT=1`. Diúltaíonn `scripts/build/standaloneInput.mjs` do fhreastalaí neamhspleách atá ar iarraidh roimh aon tógáil chúltaca; coinníonn gnáth-thógálacha áitiúla CLI an cúltaca atá acu cheana. Caithfidh ullmhacht an fhreastalaí, Schemathesis agus promptfoo a bheith rathúil ar fad laistigh de theorainn neamhathraithe an jab de 25 nóiméad. Cruthaíonn admháil tionscnaimh aitheantas agus bearta na n-ionchur, seachas scanadh rathúil DAST. Fanann dul in éag an déantáin, briseadh an reathaí nó teip an scanóra mar fhianaise neamhiomlán nó theipthe; ní féidir le cumhdach comhairleach PASS a dhéanamh di.

### Acmhainn forghníomhaithe an chomhéadain úsáideora

Ritheann CI fardal iomlán an chomhéadain úsáideora mar cheithre sharda maitríse
`test-vitest`, agus dhá oibrí ar a mhéad i ngach sarda mar aon leis an sprioc-am jab
15 nóiméad atá ann cheana. Ritheann an chéad sarda foireann Vitest MCP/autoCombo freisin.
Clúdaíonn toradh an jab riachtanaigh gach géag den mhaitrís; ní féidir le teip nó cealú
sarda amháin glacadh an iarrthóra a bhunú.

Coinníonn an breathnóir oíche admháil ar leith don iarrthóir beacht le haghaidh gach
sarda comhéadain úsáideora, lena n-áirítear forghníomhú MCP sa chéad admháil. Tá na
ceithre admháil, na logaí agus na haitheantais forghníomhaithe chomhoiriúnacha ar fad
riachtanach. Roghnaíonn `npm run test:vitest:ui` go háitiúil an fhoireann iomlán fós;
níl i rith amháin `--shard` ach fianaise pháirteach.

### Bailiú cumhdaigh aonad

Bailíonn an dá sharda aonad déag cumhdach V8 le linn a bhforghníomhaithe tástála reatha.
Ritheann sarda rathúil `scripts/ci/compact-v8-coverage.mjs` chun na bunchomhaid a
chomhbhrú gan tuarascáil idirmheánach Istanbul a ghiniúint. Fíoraíonn jab deiridh
Coverage na dhá mhanifest déag ar fad i gcoinne SHA an iarrthóra, an ama rite, fréamh
na foinse agus haisí na sonraí, agus ansin ritheann sé tuairisceoirí c8 agus na
tairseacha cumhdaigh reatha. Coinníonn ionchuir ord domhanda c8 d'ainmneacha comhaid;
níl réamhchumasc de réir sarda sábháilte do chumhdach measctha feidhme/bloic. Má bhíonn
sardaí ar iarraidh, míchumtha nó neamh-chomhoiriúnach, teipeann ar an nglacadh.
Coinníonn sardaí tástála ar theip orthu cumhdach diagnóiseach amh ar leithligh; ní
féidir é a chur san áireamh sa chumasc deiridh.

### Admhálacha ar dhul chun cinn fhorghníomhú na n-aonad

Taifeadann an t-ordú comhroinnte `test:unit:ci:shard` na céimeanna `primary`, `dashboard` agus `serial`
trí `scripts/ci/unit-progress-reporter.mjs`. Bíonn an gnáth-thuairisc tástála ar fáil i gcónaí.
Taifeadann admháil ar leith, nach bhfuil inti ach meiteashonraí, tús agus críochnú gach comhaid,
agus liostaíonn comhartha beatha gach 30 soicind na comhaid atá fós gníomhach agus an t-am atá caite acu. Ní thaifeadann sí
ach meiteashonraí forghníomhaithe atá ar an liosta ceadaithe; ní dhéantar cur síos ar thástálacha, aschur, coirp earráide ná an
timpeallacht iomlán a shrathú.

Coinníonn CI na comhaid JSONL faoin ainm `unit-progress-ci-<run>-<attempt>-<shard>`. D’fhéadfadh teorainn ama poist cosc a chur ar an uaslódáil níos déanaí;
fanann comharthaí beatha a astaíodh cheana mar fhianaise dhiagnóiseach. D’fhéadfadh sé freisin go léireodh
comharthaí beatha atá ar iarraidh próiseas riteora atá blocáilte nó foirceanta. Caomhnaíonn na hadmhálacha seo an roghnú tástálacha,
an chomhreomhaireacht, na sprioc-amanna agus an stádas scortha atá ann cheana; ní breithiúnais iad maidir le hiarrthóirí a ligean isteach.

### Scuaine cumaisc

Cuireann an lipéad `queue` PR chuig scuaine Mergify (`.mergify.yml`). Osclaíonn Mergify dréacht-PR ar
bhrainse `mergify/merge-queue/`, ritheann CI an roghnú iomlán ansin, agus cumasctar an PR bunaidh
nuair a éiríonn le `Gate / CI`, `Gate / Quality` agus `Merge integrity (changelog + generated skills)`.

Scríobhann Mergify achoimre a scuaine isteach i gcur síos an dréachta, agus is féidir le haipeanna eile é a chur in eagar freisin.
Faigheann teagmhas `pull_request` `edited` ar dhréacht den sórt sin a ghrúpa comhthráthachta féin
(`-queue-edit-<run_id>`) ionas nach féidir leis fíor-rith an dréachta a chur ar ceal, agus scipeálann sé an geata agus an
mhaitrís. Ní ritheann ach `Merge integrity` fós. Bíonn ainm seiceála difriúil ar an jab geata a scipeáladh,
toisc go léann Mergify `Gate / CI` scipeáilte mar sheiceáil theipthe agus baineann sé an PR den scuaine.

Tar éis PR a bhaint den scuaine, ní chuireann brú an PR ar ais sa scuaine i gcónaí. Cuir an nóta tráchta `@mergifyio queue` air.

### Fardal scanadh statach

Tá an fardal leaganaithe d'ailiasanna npm agus ballraíocht an scanadh stataigh le fáil in
`config/quality/gate-manifest.json`. Rith `npm run check:gate-manifest` chun ainmneacha
scripte agus orduithe beachta a bhailíochtú i gcoinne `package.json`; má chuirtear
rudaí leis, má bhaintear iad nó má athraíonn orduithe de réir a chéile, teipeann ar an
duán áitiúil agus ar na jabanna aicmithe athruithe in CI araon. Ní jab sreafa oibre,
ásc maitríse ná cás tástála é ailias: níor cheart na comhairimh seo a chur i láthair
mar chinn atá inmhalartaithe.

Úsáid `npm run quality:scan -- --list` nó `npm run quality:scan:fast -- --list`
chun na hailiasanna roghnaithe a iniúchadh gan iad a fhorghníomhú. Agraíonn an riteoir
an pointe iontrála npm, mar sin caomhnaítear a am rite (Bun san áireamh nuair atá sé
cumraithe). Taifeadann an mhanifest ailiasanna lasmuigh de na próifílí sin mar chinn
a agraítear ar leithligh, agus tá cosc ar orduithe cothabhála i bpróifílí scanadh
inléite amháin.

Ní chlúdaíonn na próifílí seo ach an scanadh statach. Ní dheimhníonn siad tástálacha
táirge, cumhdach, pacáistiú, seiceálacha seachtracha ná glacadh iomlán iarrthóra le
haghaidh eisiúna. Úsáideann glacadh sreafa oibre an comhad nasctha
`config/quality/admission-policy.json` agus `scripts/quality/admission-verdict.mjs`.
Fanann próifílí breathnóra eisiúna ar leithligh; déan iniúchadh neamhspleách ar a
seiceálacha agus admhálacha infheidhme. Dearbhaítear orduithe statacha an bhreathnóra
iomláin in `config/quality/release-green-static-profile.json`, lena n-áirítear
`audit:deps`, roghnú tástálacha sócháin agus seiceálacha aistriúcháin. Bailíochtaíonn
an lódálaí orduithe npm i gcoinne package.json agus dearbhuithe samhaltaithe CI/Quality;
diúltaíonn sé d'athrú de réir a chéile seachas comharthaí blaoisce a fhorghníomhú mar
argóintí. Ní féidir le haschur SKIP/INCOMPLETE ó scanóir riachtanach PASS a bhunú.
Taifeadann an phróifíl a heisiaimh sheachtracha agus ní ghlacann sí áit cumhdaigh
óstáilte, maitrísí tástála, pacáiste ná fianaise imscartha. Is tagairt é an fardal
próis thíos, ní cruthúnas gur ritheadh geata i ndáiríre.

Tá scripteanna faoi `scripts/check/` (geataí beartais) agus `scripts/quality/`
(inneall raicéid). Is é `.github/workflows/ci.yml` foinse fhírinne CI.

### Sláinte doiciméadaithe foilsithe-bonn

Tugann `.github/workflows/i18n-base-health.yml` aird ar shláinte na ndoiciméad tar éis brúnna roghnaithe chuig `main` agus `release/v*`, agus ar sheoladh láimhe. Clúdaíonn a scagairí doiciméadú, fréamh Markdown, `llm.txt`, aistriúchán state/configuration agus an uirlis ábhartha i18n. Úsáideann an post `Published base documentation health` aonair Ubuntu óstáilte agus spriocdháta cúig nóiméad. Déanann sé bailíochtú inléite amháin agus scríobhann sé admháil dhiagnóiseach gan suiteáil spleáchais, aistriúchán nó glacadh stáit.

Éilíonn `scripts/i18n/check-base-health.mjs` neamhréireachtaí foinse-hash, sprioc-ar iarraidh, sprioc-hash, sean-aistriúchán agus alt-taisce. Déanann sé bailíochtú freisin ar raon feidhme lárnach document/locale reatha agus ar a bhunáit taifeadta. #### `check-ui-value-drift` — geata aistriúchán seanchaite

Aimsíonn sé an t-aon aischéimniú i18n nach féidir leis na geataí eile a fheiceáil ó thaobh struchtúir de: athscríobhtar luach Béarla
agus fágtar na haistriúcháin a díorthaíodh ón mBéarla _roimhe seo_ ina ndiaidh, agus mar sin
leanann úsáideoirí nach labhraíonn Béarla orthu ag léamh téacs atá muiníneach ach mícheart anois.

Tharla sé seo i ndáiríre. Athscríobhadh `oauthModal.googleOAuthWarning` nuair a cuireadh an
cúntóir logála isteach Antigravity leis (#5203); choinnigh **39 as 43 logchaighdeán** téacs a dúirt le hoibreoirí “an
URL iomlán a chóipeáil agus é a ghreamú thíos” — sreabhadh nach féidir a chríochnú don soláthraí sin. Níor
tugadh faoi deara é go dtí #8463 mar:

- ní dhéanann `sync-ui-keys` ach eochracha atá **in easnamh** a ais-líonadh, agus ní dhéanann sé sin riamh d’eochracha atá **as dáta**;
- comhaireann `check-ui-keys-coverage` _láithreacht_ eochrach, mar sin áirítear aistriúchán as dáta mar aistriúchán clúdaithe;
- rianaíonn `check-translation-drift` na scátháin doiciméadachta `docs/i18n/<locale>/**.md` —
  ní léann sé `src/i18n/messages/*.json` riamh. Blocála i jab `docs-sync-strict` ó rinneadh
  an t-athshioncronú 2026-09: cuir croídhoiciméad in eagar → `npm run i18n:run -- --files=<doc>` (ar leibhéal na rannóige, saor).

**Feasach ar dhiff, gan a bheith bunaithe ar bhonnlíne.** Cuireann sé `en.json` ag an mbonn cumaisc i gcomparáid leis an
gcrann oibre; i gcás gach eochrach ar athraigh a luach Béarla, tá aon logchaighdeán a bhfuil
aistriúchán gan athrú fós aige as dáta. Déanann sé seo **fiachas atá ann cheana a reo** d’aon ghnó — ní féidir le diff
a nochtadh cén sean-Bhéarla ónar tháinig aistriúchán fadbhunaithe, mar sin ní mheasann an geata
ach a mbaineann an t-athrú reatha leis. Chosnódh an rogha eile (bonnlíne haise in aghaidh na heochrach)
comhad ginte ~600 KB, 3× níos mó ná an bhonnlíne reatha is mó, agus d’athrófaí é ar gach PR i18n.

Tá dhá bhealach ann chun é a shásamh:

1. nuashonraigh na haistriúcháin lena mbaineann, nó
2. socraigh iad mar `__MISSING__:<new english>` — soláthraíonn an t-am rite an Béarla ceartaithe ansin
   (`src/i18n/request.ts::deepMergeFallback`, #7258) agus cuirtear an eochair sa chiú le haghaidh aistriúcháin.

Má d’athraigh **brí** na teaghrán, is fearr **an eochair a athainmniú**: ní féidir le heochair nua
aistriúchán as dáta a oidhreacht. Sin é an patrún a d’úsáid #8463.

```bash
npm run i18n:check-value-drift          # docht (an méid a ritheann CI)
npm run i18n:check-value-drift:warn     # tuairisc amháin
BASE_REF=origin/release/vX.Y.Z npm run i18n:check-value-drift
```

Comhroinneann na geataí um athrú luacha agus um eochracha nua aon chomparáid dhoshóinseáilte amháin ó
`scripts/i18n/resolve-ui-diff-base.mjs`. Cuireann an sreabhadh oibre na SHAanna bonn, barr an bhoinn agus
iarrthóra céanna ar aghaidh chuig an dá sheiceáil. Úsáideann riteanna PR/athspriocdhírithe boinn, brúite agus
grúpa cumaisc comhthéacs a dteagmhais. Chun brainse iarrthóra a sheoladh, teastaíonn a PR oscailte beacht nó
an t-ionchur sainráite `i18n_base_sha`. Nuair a sheoltar breathnóireacht nó nuair a dhéantar breathnóireacht sceidealaithe ar `main` nó `release/vX.Y.Z`
gan an t-ionchur sin, cuirtear an gealltanas deireanach i gcomparáid lena chéad tuismitheoir; ní iniúchadh é seo ar
an bhfiach aistriúcháin oidhreachtúil ar fad. Teastaíonn bonn comparáide sainráite le haghaidh agairt áitiúil,
mar shampla an t-ordú `BASE_REF` thuas.

Má bhíonn comhthéacs na comparáide in easnamh nó débhríoch, má bhíonn catalóg riachtanach neamh-inléite nó neamhbhailí, nó
má bhíonn iarrthóir athraithe, tugtar `INCOMPLETE` le cód scoir **2**, lena n-áirítear sa mhód rabhaidh.
Úsáideann léamha catalóige `scripts/i18n/read-ui-catalog.mjs`; ní chuirtear oibiachtaí folmha in ionad
teipeanna léite. Ní dhearbhaíonn bonn nach bhfuil ar fáil ná ionchur neamhiomlán PASS.

- **blocála** — chuir an PR sáruithe cioglamatacha/cognaíocha nó easpórtálacha marbha le comhaid a d’athraigh sé

  diallas oidhreachtúil PR neamhchiontach ar dearg riamh; déantar an diallas a rianú lena dheisiú le linn réiteach an eisiúna agus déanann an

oíche, agus coimeádann siad an chomparáid absalóideach (dhomhanda). Fanann cumhdach, dúbláil agus
cumhdach cineálacha domhanda faoi láthair (ní tháirgeann a n-uirlisí difríocht de réir comhaid ar
bhealach saor) — is iarrthóirí iad don chóireáil chéanna.

## Laghduithe Raicín a Chur i dTaisce — an treo anuas (#8584)

Níl an raicín ach leath-uathoibríoch, agus is é an leath mícheart é. Is eagarthóireacht láimhe JSON é **uasteorainn a ardú**
a thógann deich soicind agus is é an bealach is tapúla é chun PR teipthe a dhíbhlocáil.
Chun ceann a **ísliú**, ní mór do dhuine `--update` a rith agus an toradh a chur i dtiomantas — agus go dtí
gur cuireadh an jab `bank-ratchet-shrinks` i bhfeidhm, níor rith aon sreabhadh oibre é. An iarmhairt thomhaiste
(2026-07-25): 18 gcomhad reoite a bhí cheana féin ag nó faoi bhun na huasteorann 800 líne do chomhad nua, an ceann is measa
ag 132× (`src/shared/validation/schemas.ts`, 19 líne agus uasteorainn 2,523 aige); d'ardaigh
uasteorainn na castachta `1794 → 2169` thar ~37 nóta athbhunaithe bunlíne agus laghdú amháin go díreach
(−1); agus scríobhadh "teannaigh trí `--update` sa chéad timthriall eile" 31 uair agus cloíodh leis
uair amháin. Déanann uasteorainn a mhaireann níos faide ná an cód a thuill í lamháltas fáis go ciúin de gach
dí-chomhdhéanamh críochnaithe don chéad duine eile a chuireann an comhad in eagar.

Dúnann `nightly-release-green.yml` → jab **`bank-ratchet-shrinks`** an lúb sin:

|             |                                                                                                                             |
| ----------- | --------------------------------------------------------------------------------------------------------------------------- |
| Ritheann ar | `schedule` (3×/lá) + `workflow_dispatch` — **ní** `push`, d'aon ghnó                                                        |
| Tomhaiseann | an `release/vX.Y.Z` is airde, leis an réiteach céanna + cosaint insteallta agus atá ag `release-green`                      |
| Scríobhann  | `check:file-size --update` agus `check:complexity-ratchets --update` (ní dhéanann ceachtar acu ach laghdú de réir dearaidh) |
| Fíoraíonn   | `npm run check:ratchet-bank` (`scripts/quality/verify-ratchet-bank.mjs`)                                                    |
| Seachadann  | PR amháin atá cothrom le dáta i gcónaí i gcoinne an bhrainse eisiúna — nuashonraithe le fórsa, gan turscar riamh            |

Déantar an cur i dtaisce i mbaisceanna seachas in aghaidh gach brú toisc nach bhfuil aon riachtanas aga folaigh aige (is leor laghdú
a chur i dtaisce laistigh de 8h), ach dhéanfadh rith in aghaidh gach cumaisc brainse an PR a atógáil arís agus arís eile
le linn feachtais chumaisc agus d'íocfadh sé as siúl iomlán ESLint gach uair. Fanann an brath ar
push (`release-green`); ní dhéantar ach an cur i dtaisce i mbaisceanna.

### An fíoraitheoir sábháilteachta

Scríobhann an jab chuig na bunlínte gan mhaoirseacht, mar sin is é `verify-ratchet-bank.mjs` a fhágann
go bhfuil sé sin inghlactha. Déanann sé diff den chrann tar éis `--update` i gcoinne `HEAD` agus **tobscoireann sé an jab
sula mbíonn aon tiomantas ann** — gan aon PR a oscailt — mura bhfuil gach athrú ar cheann díobh seo:

- iontráil uimhriúil `frozen` / `testFrozen` **íslithe** nó **bainte**
- `complexity-baseline.json` → `count` **íslithe**
- `quality-baseline.json` → `metrics.cognitiveComplexity.value` **íslithe**

Teipeann ar aon rud eile: uimhir a ardú, iontráil a chur leis, `cap`/`testCap` a athrú, nó
nóta `_rebaseline_*` a scriosadh/athscríobh (is iad na nótaí sin an rian iniúchta a mhíníonn cén fáth a bhfuil gach
uasteorainn ann agus stóráiltear iad laistigh den oibiacht `frozen` chéanna leis na hiontrálacha comhaid).
Bheadh bota a d'fhéadfadh uasteorainn a ardú i bhfad níos measa ná an staid reatha. Cosaint ar chúlchéimniú:
`tests/unit/verify-ratchet-bank.test.ts`.

Ní bhrúnn an jab chuig `release/*` riamh — cumascann duine an PR, mar sin ní féidir le droch-thomhas
teacht i bhfeidhm gan athbhreithniú.

## Beartas an Liosta Ceadaithe

Úsáideann gach geata nach féidir leis teip mar gheall ar sháruithe atá ann cheana liosta ceadaithe reoite
(m.sh., `KNOWN_STALE_DOC_REFS`, `KNOWN_MISSING`, `KNOWN_RAW_SQL`). Seo é an beartas:

**Ceartaigh an bhunchúis; ná húsáid an liosta ceadaithe ach amháin nuair atá an sárú ann cheana agus
nach féidir é a cheartú san PR céanna.**

Agus iontráil á cur le liosta ceadaithe:

1. Cuir nóta tráchta san áireamh leis an údar.
2. Déan tagairt don tsaincheist rianaithe (m.sh., `// #3498 — Phase 2 feature, not yet implemented`).

3. **Má tá an sárú ann cheana** (is é sin, níor thug tusa isteach é ach clúdaíonn an geata anois é):
   cuir iontráil leis an liosta ceadaithe mar aon le nóta tráchta údaraithe agus saincheist rianaithe.
4. **Más raicín é an geata** (clúdach, rabhaidh ESLint, dúbláil, castacht):
   rinne d’athrú an mhéadracht níos measa. Ceartaigh an bhunfhadhb, nó (go hannamh) rith

5. Tá **geataí comhairleacha** (`continue-on-error: true`) faisnéiseach — ní chuireann siad bac ar
   chumasc ach bíonn siad le feiceáil san achoimre CI. Ceartaigh iad mar sin féin.
