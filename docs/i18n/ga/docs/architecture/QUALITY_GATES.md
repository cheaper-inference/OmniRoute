Is é an doiciméad seo an tagairt údarásach do gach geata cáilíochta CI in OmniRoute.
Déantar cur síos ann ar gach geata, ar a bhfíoraíonn sé, ar an jab CI ina ritear é, ar cé acu a úsáideann sé
bonnlíne raicéid nó polasaí pas/teip, agus ar cé acu a chuireann sé bac ar an tógáil nó atá sé comhairleach.

Le haghaidh achoimre ghairid agus pholasaí an liosta ceadaithe, féach an rannán "Geataí Cáilíochta & Raicéid"
in `AGENTS.md`. Le haghaidh an mheasúnaithe chriticiúil, an aicmithe aibíochta, agus an phlean macasamhlaithe
neamhspleách ar uirlisí don chóras céanna, féach an
[Leabhar Súgartha do Gheataí Cáilíochta](../ops/QUALITY_GATE_PLAYBOOK.md).

## Fardal geataí agus próifílí forghníomhaithe

### Ceadú iarrthóirí

Eisíonn na sreafaí oibre CI agus Quality Gates breithiúnas seasta an ceann: `Gate / CI` agus
`Gate / Quality`. Áiríonn a mbeartas ceadaithe leaganaithe gach jab uas srutha mar riachtanach nó
comhairleach. Ní mór go n-éireoidh le jab riachtanach infheidhme: ní féidir le torthaí atá in
easnamh, cealaithe, scipeáilte, ar feitheamh nó anaithnid PASS a bhunú. Is féidir le haicmiú bailí
docs-only nó catalog-only lána cód a dhéanamh neamh-infheidhme; ní iarrthóir inghlactha é PR
dréachta. Ní mhaolaíonn lipéad `hotfix` riachtanas na fianaise.

Clúdaíonn an dá shreabhadh oibre PRanna chuig brainse main/release, bruithe chuig `main`, seoladh
láimhe agus imeachtaí grúpa cumaisc. Ritheann brú, seoladh agus grúpa cumaisc an roghnú iomlán.
Ní thosnaíonn bruithe chuig `release/**` iad (2026-10-18): rith gach athrú an mhaitrís ar a PR
féin cheana agus is é jab Release-Green an teaglaim chumasctha (`docs/ops/RUNNER_BOX.md` → Hosted
lane). Úsáideann forcanna agus grúpaí cumaisc riththeoirí óstáilte do jabanna a roghnódh
riththeoirí féin-óstáilte a mhalairt; ní mór dóthain cumais óstáilte a fhíorú roimh rolladh amach.

Aithníonn gach admháil JSON an SHA atá seiceáilte amach, rith an tsreafa oibre agus an iarracht.
Diúltaíonn an CLI mímheaitseáil SHA idir an checkout agus an t-imeacht. Ceanglaíonn tástálacha
sreafa oibre ballraíocht bheartais le liosta `needs` jab an bhreithiúnais ionas nach bhféadfaidh
lána nua nó lána bainte imeacht go ciúin. Clúdaíonn na hadmhálacha a sreabhadh oibre féin, ní
foilsiú, imscaradh ná inmheáin scanóir chomhairleach atá ann cheana. Is athrú riaracháin ar leith
é an dá ainm seiceála a ghníomhachtú i rialacha brainse; ní chosnaíonn cur leis na jabanna seo
brainse astu féin.

### Fardal scanadh statach

Tá fardal leaganaithe na n-ailias npm agus ballraíocht an scanadh statach ina gcónaí i
`config/quality/gate-manifest.json`. Rith `npm run check:gate-manifest` chun ainmneacha scripte
agus orduithe beachta a bhailíochtú i gcoinne `package.json`; cuireann breiseáin, baint agus dreif
orduithe teip ar an hook áitiúil agus ar na jabanna aicmithe athruithe in CI araon. Ní jab sreafa
oibre, sampla maitríse ná cás tástála é ailias: níor cheart na líonta seo a chur i láthair mar
inmhalartaithe.

Úsáid `npm run quality:scan -- --list` nó `npm run quality:scan:fast -- --list` chun na hailias
roghnaithe a iniúchadh gan iad a fhorghníomhú. Glaonn an riththeoir ar phointe iontrála npm, mar
sin coinnítear a runtime (lena n-áirítear Bun nuair a chumraítear é). Taifeadann an manifest ailias
lasmuigh de na próifílí sin mar ghlaofa ar leith, agus tá orduithe cothabhála toirmiscthe i
bpróifílí scanadh inléite amháin.

Ní chlúdaíonn na próifílí seo ach an scanadh statach. Ní dheimhníonn siad tástálacha táirge,
clúdach, pacáistiú, seiceálacha seachtracha ná glacadh iomlán eisiúna iarrthóra. Úsáideann ceadú
sreafa oibre an `config/quality/admission-policy.json` nasctha agus
`scripts/quality/admission-verdict.mjs`. Fanann próifílí Release-observer ar leith; iniúch a
seiceálacha infheidhme agus a n-admhálacha go neamhspleách. Is tagairt é an fardal próis thíos, ní
cruthúnas go ritheadh geata go fírinneach.

Tá scripteanna faoi `scripts/check/` (geataí beartais) agus `scripts/quality/` (inneal raca). Is é
`.github/workflows/ci.yml` foinse fhírinne an CI.

### Cosán tapa PR eisiúna (`quality.yml`)

Comhlánaíonn `.github/workflows/quality.yml` an CI ar PRanna main/release, bruithe chuig `main`,
seoladh agus grúpaí cumaisc. Úsáideann PRanna seiceálacha tapa scagtha de réir cosáin. Baineadh an
tógáil dhúblach a bhí díchumasaithe go buan; fanann na seiceálacha fíor tógála/pacáistiú/tosaithe
sa CI.

#### Tuairisc ar thástálacha siblíneacha dearmadta

Athúsáideann `npm run check:forgotten-sibling-tests` an réiteoir allmhaire atá taobh thiar den léarscáil tionchair tástála.
Maidir le gach modúl táirgeachta athraithe, tuairiscíonn sé slabhraí deterministeacha
`changed module/symbol -> static consumer -> candidate sibling test` nuair nach bhfuil an tástáil
ionchasach i ndiff an iarratais tarraingthe. Coimeádtar an achoimre Markdown agus an toradh JSON mar
artefacht sreafa oibre `forgotten-sibling-tests` le haghaidh calabraithe sula ndéantar aon rolladh amach blocálach.

Níl sna hath-onnmhairithe barrel ná sna hallmhairithe dinimiciúla ach diagnóisic réitigh amháin; ní
chruthaíonn siad toradh blocálach riamh. Tá eisceachtaí athbhreithnithe in
`config/quality/forgotten-sibling-allowlist.json`. Caithfidh gach iontráil an tomhaltóir agus an
tástáil ionchasach a ainmniú, réasúnaíocht shonrach a thabhairt, agus nasc a sholáthar do cheist
GitHub nó d'iarratas tarraingthe. Má bhíonn iontrálacha míchumtha ann, teipeann orthu go dúnta. Ní
féidir le heisceachtaí tástáil ionchasach scriosta a chur faoi chois, ná diff a chuireann
`.skip`/`.todo` leis; fanann lagú dearbhuithe agus mascáil eile faoi úinéireacht an gheata
`check:test-masking` a bhlocálann go neamhspleách.

#### `check-ui-value-drift` — geata aistriúcháin as dáta

Ceapann sé an t-aon chúlú i18n nach féidir leis na geataí eile a fheiceáil go struchtúrtha: athscríobhtar luach Béarla agus fanann na haistriúcháin a díorthaíodh ón mBéarla _roimhe seo_ ina dhiaidh, rud a fhágann go leanann úsáideoirí neamh-Bhéarla ag léamh cóipe atá scríofa go muiníneach ach atá mícheart anois.

Seoladh é seo go fíor. Athscríobhadh `oauthModal.googleOAuthWarning` nuair a tháinig an cúntóir logála isteach Antigravity (#5203); choimeád **39 as 43 locale** téacs a d'inis d'oibreoirí "an URL iomlán a chóipeáil agus é a ghreamú thíos" — sreabhadh nach féidir a thabhairt chun críche don soláthraí sin. Níor tugadh faoi deara é go dtí #8463 mar:

- Ní chuireann `sync-ui-keys` isteach ach eochracha atá **as láthair**, riamh cinn atá **as dáta**;
- Áiríonn `check-ui-keys-coverage` _láithreacht_ na n-eochracha, mar sin faigheann aistriúchán as dáta scór mar chuid chlúdaithe;
- Rianaíonn `check-translation-drift` scátháin doiciméadta `docs/i18n/<locale>/**.md` — ní léann sé `src/i18n/messages/*.json` riamh. Ag blocáil i jab `docs-sync-strict` ón athshioncronú 2026-09: cuir príomhdhoiciméad in eagar → `npm run i18n:run -- --files=<doc>` (ar leibhéal an ailt, saor ar chostas).

**Feasach ar an difir, ní bunaithe ar bhunlíne.** Déanann sé `en.json` ag an mbonn cumaisc a chur i gcomparáid leis an gcrann oibre; i gcás gach eochrach ar athraíodh a luach Béarla, tá aon locale a bhfuil aistriúchán gan tadhall fós aige as dáta. Déanann sé seo **fiachas réamhbheithigh a reo** d'aon turas — ní féidir le difir a nochtadh cén sean-Bhéarla as ar tháinig aistriúchán fadsheasamhach, mar sin ní mheasann an geata ach an méid a bhaineann an t-athrú reatha leis. Chosnódh an rogha eile (bunlíne hash in aghaidh na heochrach) comhad ginte de ~600 KB, 3× an bhunlíne is mó atá ann cheana féin, ag athrú ar gach PR i18n.

Dhá bhealach chun é a shásamh:

1. nuashonraigh na haistriúcháin lena mbaineann, nó
2. socraigh iad go `__MISSING__:<new english>` — ansin cuirtear an Béarla ceartaithe ar fáil
   ag am rite (`src/i18n/request.ts::deepMergeFallback`, #7258) agus téann an eochair ar
   scuaine le haistriú.

Má d'athraigh **brí** an teaghráin, is fearr **an eochair a athainmniú**: ní thagann eochair
nua i oidhreacht ar aistriúchán as dáta. Sin an patrún a d'úsáid #8463.

```bash
npm run i18n:check-value-drift          # docht (an rud a ritheann CI)
npm run i18n:check-value-drift:warn     # tuairisc amháin
BASE_REF=origin/release/vX.Y.Z npm run i18n:check-value-drift
```

Scoirfidh sé le 0 le `SKIP reason=base-unresolved` nuair nach féidir an catalóg boinn a léamh
(clón éadomhain gan an ref boinn), ag macasamhlú `check-openapi-breaking`.

## Laghduithe Raicín a Chur i dTaisce — an treo anuas (#8584)

Níl an raicín ach leath-uathoibríoch, agus is é an leath mícheart é. Is eagarthóireacht láimhe JSON é **uasteorainn a ardú**
a thógann deich soicind agus is é an bealach is tapúla é chun PR teipthe a dhíbhlocáil.
Chun ceann a **ísliú**, ní mór do dhuine `--update` a rith agus an toradh a chur i dtiomantas — agus go dtí
gur cuireadh an jab `bank-ratchet-shrinks` i bhfeidhm, níor rith aon sreabhadh oibre é. An iarmhairt thomhaiste
(2026-07-25): 18 gcomhad reoite a bhí cheana féin ag nó faoi bhun na huasteorann 800 líne do chomhad nua, an ceann is measa
ag 132× (`src/shared/validation/schemas.ts`, 19 líne agus uasteorainn 2,523 aige); d'ardaigh
uasteorainn na castachta `1794 → 2169` thar ~37 nóta athbhunaithe bunlíne agus laghdú amháin go díreach
(−1); agus scríobhadh "teannaigh trí `--update` sa chéad timthriall eile" 31 uair agus cloíodh leis
uair amháin. Déanann uasteorainn a mhaireann níos faide ná an cód a thuill í lamháltas fáis go ciúin de gach
dí-chomhdhéanamh críochnaithe don chéad duine eile a chuireann an comhad in eagar.

Dúnann `nightly-release-green.yml` → jab **`bank-ratchet-shrinks`** an lúb sin:

|             |                                                                                                                             |
| ----------- | --------------------------------------------------------------------------------------------------------------------------- |
| Ritheann ar | `schedule` (3×/lá) + `workflow_dispatch` — **ní** `push`, d'aon ghnó                                                        |
| Tomhaiseann | an `release/vX.Y.Z` is airde, leis an réiteach céanna + cosaint insteallta agus atá ag `release-green`                      |
| Scríobhann  | `check:file-size --update` agus `check:complexity-ratchets --update` (ní dhéanann ceachtar acu ach laghdú de réir dearaidh) |
| Fíoraíonn   | `npm run check:ratchet-bank` (`scripts/quality/verify-ratchet-bank.mjs`)                                                    |
| Seachadann  | PR amháin atá cothrom le dáta i gcónaí i gcoinne an bhrainse eisiúna — nuashonraithe le fórsa, gan turscar riamh            |

Déantar an cur i dtaisce i mbaisceanna seachas in aghaidh gach brú toisc nach bhfuil aon riachtanas aga folaigh aige (is leor laghdú
a chur i dtaisce laistigh de 8h), ach dhéanfadh rith in aghaidh gach cumaisc brainse an PR a atógáil arís agus arís eile
le linn feachtais chumaisc agus d'íocfadh sé as siúl iomlán ESLint gach uair. Fanann an brath ar
push (`release-green`); ní dhéantar ach an cur i dtaisce i mbaisceanna.

## Beartas an Liosta Ceadaithe

Úsáideann gach geata nach féidir leis teip mar gheall ar sháruithe a bhí ann cheana liosta ceadaithe reoite
(m.sh., `KNOWN_STALE_DOC_REFS`, `KNOWN_MISSING`, `KNOWN_RAW_SQL`). Is é seo an beartas:

**Ceartaigh an bhunchúis; ná húsáid an liosta ceadaithe ach amháin nuair a bhí an sárú ann cheana agus
nach féidir é a cheartú san PR céanna.**

Agus iontráil á cur le liosta ceadaithe:

1. Cuir nóta tráchta san áireamh leis an údar.
2. Déan tagairt don tsaincheist rianaithe (m.sh., `// #3498 — Gné de Chéim 2, gan cur i bhfeidhm fós`).
3. Bain an iontráil san PR céanna a cheartaíonn an sárú — is fabht ann féin é iontráil as dáta nach
   gcuireann sárú gníomhach faoi chois a thuilleadh (cuirfidh forfheidhmiú um iontrálacha as dáta 6A.3
   faoi deara go dteipfidh ar an ngeata mar gheall ar iontráil dhílleachta sa liosta ceadaithe nuair a chuirfear i bhfeidhm é).

Ná cuir iontrálacha le liostaí ceadaithe chun go n-éireoidh le tástálacha níos tapúla. Tugann geata glas le liosta
ceadaithe atá ag fás tuiscint bhréagach ar cháilíocht.

### Nuair a theipeann ar gheata ar do PR

1. **Léigh aschur an gheata go cúramach** — insíonn sé duit go díreach cén comhad nó siombail a sháraigh
   an riail.
2. **Ceartaigh an sárú** — seiceálacha cinntitheacha ar an gcóras comhad iad formhór na ngeataí agus éiríonn leo a luaithe
   atá an cód ceart.
3. **Má bhí an sárú ann cheana** (is é sin, ní tusa a thug isteach é ach clúdaíonn an geata anois
   é): cuir iontráil leis an liosta ceadaithe mar aon le nóta tráchta údaraithe agus saincheist rianaithe.
4. **Más raicín é an geata** (clúdach, rabhaidh ESLint, dúbailt, castacht):
   rinne d'athrú an mhéadracht níos measa. Ceartaigh an bhunfhadhb, nó (go hannamh) rith
   `npm run quality:ratchet -- --update` má tá an t-athrú d'aon ghnó agus má tá meath na méadrachta
   inghlactha — ach mínigh an fáth i gcur síos an PR.
5. Is chun faisnéise iad **geataí comhairleacha** (`continue-on-error: true`) — ní chuireann siad bac ar
   chumasc ach bíonn siad le feiceáil in achoimre CI. Ceartaigh iad mar sin féin.
