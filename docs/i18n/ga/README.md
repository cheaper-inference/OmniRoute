## Comharthaí In Aisce in aghaidh na Míosa: ~ 11.3B de réir mar a Comhaireamh Daoine Eile · ~ 90M Real

</div>

> **~ 11.3B comharthaí / míosa saor in aisce**<br/> Rinne <sub> an chaoi a n-áirítear catalóga eile a chomhaireamh: gach sraith curtha suas, áirítear na tairiscintí dar críoch </sub>
>
> **~ 90M fíor inniu**<br/> <sub> comhaireamh gach cuóta roinnte uair amháin: cad is féidir leat a úsáid i ndáiríre </sub>
>
> **Tá gach rud anseo saor in aisce. Gan balla pá.**<br/> ★ [An maith leat? Cuir réalta linn ar GitHub](https://github.com/cheaper-inference/OmniRoute)

Gearrann catalóga eile ó US$ 19 in aghaidh na bliana go US$ 49 le haghaidh rochtain saoil ar shonraí beo. Anseo tá gach rud saor in aisce. <sub> Praghsanna seiceáilte ar 2026-11-18.</sub>

<sub>Iniúchadh ar an gcatalóg an uair dheireanach ar 2026-11-23. [Conas a dhéanaimid comhaireamh →](docs/reference/FREE_TIERS.md#how-we-count)</sub>

> **Beir leat do chuntais sholáthraí féin.** Is sraitheanna saor ó thríú páirtí iad seo, ní deontas comhartha ó OmniRoute. Cláraigh, faigh dintiúir nuair a iarrann soláthraí iad, agus ceangail na cinn is féidir leat a úsáid. Socraíonn gach soláthraí a theorainneacha, a infhaighteacht agus a théarmaí féin.
>
> Má dhéantar sraitheanna saor in aisce a chruachadh de láimh, ciallaíonn sé na mórán SDKs, an iliomad teorainneacha rátaí agus níl aon smaoineamh soiléir agat ar a bhfuil fágtha agat. Coinníonn OmniRoute 214 sraith chatalóg le rochtain saor in aisce agus ríomhann sé an fíorfhigiúr ó 12 linn le cuóta foilsithe, gach linn comhroinnte á chomhaireamh uair amháin. Taispeántar cuótaí nach n-osclaíonn ach amháin tar éis seiceáil aitheantais réigiúnach (lá atá inniu ann, ModelScope) óna chéile, +~ 6M taobh thiar de fhíorú aitheantais réigiúnach, agus níor cuireadh leis an bhfíorfhigiúr riamh iad. Taispeánann an méid atá fágtha ar an deais (`/dashboard/free-tiers`).

## Suiteáil, ceangail soláthraí, ansin bealach trí chríochphointe amháin

<img src="./docs/diagrams/works-zero-config.svg" width="100%" alt="Four steps to use OmniRoute. Install with npm install -g omniroute, run omniroute, connect a provider and create an API key in the dashboard, then call http://localhost:20128/v1 with model auto."/>

```bash
# After connecting a provider, create your OmniRoute key in Dashboard → API Keys:
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer YOUR_OMNIROUTE_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"auto","messages":[{"role":"user","content":"Hello!"}]}'
```

## Combos: an príomhthionscadal

1. **Tosaigh le `auto`.** Socraigh an tsamhail i do chliant OpenAI-comhoiriúnach. Tógann OmniRoute teaglama fíorúil ó sholáthraithe nasctha agus scórann sé iarrthóirí beo.
2. **Sábháil teaglama le haghaidh níos mó smachta.** Roghnaigh ainm, liosta sprice agus straitéis, ansin úsáid an t-ainm sin mar mhúnla. Socraíonn an straitéis an sprioc a théann ar dtús agus conas a thriailtear an chuid eile.

Téann teaglama trasna samhlacha go huathoibríoch. Maidir le hídiú cuóta, teip ar sholáthraí nó frithdhúnadh samhail, déanann sé iarracht an chéad sprioc shláintiúil incháilithe eile.

### Zero-config: bain úsáid as `auto`

```bash
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <your-omniroute-key>" \
  -H "Content-Type: application/json" \
  -d '{"model": "auto", "messages": [{"role": "user", "content": "Hello"}]}'
```

Leaganacha tune na meáchain. Fanann ródú deireanach-aitheanta-maith leis an soláthraí rathúil deiridh go dtí go dteipeann air, ansin athscóráil. `auto/fast` agus `auto/cheap` sainroghanna gan ráthaíocht a thabhairt ar an tsamhail is tapúla nó is saoire.

| Múnla ID            | Iompar                                                                                                                                                                                                                                                                                                                                                                                                |
| :------------------ | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `auto`              | Meáchain chothromaithe réamhshocraithe.                                                                                                                                                                                                                                                                                                                                                               |
| `auto/fast`         | Fabhrach latency íseal agus sláinte soláthraí.                                                                                                                                                                                                                                                                                                                                                        |
| `auto/cheap`        | Is fearr leis praghsanna catalóg níos ísle.                                                                                                                                                                                                                                                                                                                                                           |
| `auto/coding`       | Cáilíocht-an chéad meáchain do ghiniúint cód.                                                                                                                                                                                                                                                                                                                                                         |
| `auto/smart`        | Caighdeán-an chéad meáchain le taiscéalaíocht 10% (réamhshocraithe 5%).                                                                                                                                                                                                                                                                                                                               |
| `auto/lkgp`         | Ródú soiléir is déanaí ar a dtugtar go maith leis na meáchain chéanna le `auto`.                                                                                                                                                                                                                                                                                                                      |
| `auto/subscription` | Ní úsáideann ach cuóta plean beo-fhíoraithe. Filleann HTTP 503 nuair nach bhfuil aon cheann ar fáil agus seachnaíonn sé aisíocaíocht bille.                                                                                                                                                                                                                                                           |

### Tógtar athléimneacht i: 3 shraith neamhspleácha

Déantar teipeanna a láimhseáil ag trí scóip, mar sin ní chuireann droch-shamhail amháin síos ar a chuntas, agus ní chuireann droch-chuntas amháin síos ar a soláthraí.

<img src="./docs/diagrams/resilience-layers.svg" width="100%" alt="OmniRoute resilience: 3 independent self-healing layers, the right layer for the right failure. Layer 1, provider circuit breaker (whole provider): trips only on 408/500/502/503/504, opens after 8 failures for OAuth providers or 12 for API-key providers, resets after 60s or 30s into a HALF-OPEN probe, lazy recovery; while OPEN the combo reroutes to the next provider. Layer 2, connection cooldown (one key or account): base 5s OAuth or 3s API-key, exponential backoff with an anti-thundering-herd guard, success clears the error state; one cooling key is skipped while sibling keys keep serving. Layer 3, model lockout (one model): per-model 429, 404 or access denials lock just that model, never the whole connection. Terminal states (banned, expired, credits exhausted) wait for the operator; they are not cooldowns."/>

#### Má tá soláthraí iomlán síos

Tá an** soláthróir breaker ciorcad** osclaíonn sé tar éis teipeanna 8 (OAuth) nó 12 ( eochair API ) le stádas 408, 500, 502, 503 nó 504. Téann combos thar an soláthraí sin agus é ar oscailt. Tar éis 60 s nó 30 s, cinneann iarratas taiscéalaíochta amháin an ndúnann sé.

#### Má tá eochair nó cuntas amháin teoranta ó thaobh rátaí

Tá an** fuarú nasc** binsí an nasc sin amháin, le cúl-as easpónantúil ó 5 s (OAuth) nó 3 s ( eochair API ). Leanann eochracha eile don soláthraí céanna ag freastal.

#### Má dhiúltaítear múnla amháin

Tá an** frithdhúnadh samhail** ní dhéanann sé ach an tsamhail sin a bhlocáil ar an nasc sin tar éis séanadh in aghaidh an mhúnla 429, 404 nó rochtain a dhiúltú. Coinníonn samhlacha eile ar an nasc céanna ag freastal.

Is stáit chríochfoirt iad naisc atá curtha in éag, atá imithe in éag agus lasmuigh de chreidmheas: fanann siad leat chun iad a shocrú.

Every command honors the active remote context (`omniroute connect <host>`). `--dry-run` prints the exact env and args without running anything, and `--api-key-env NAME` keeps the key out of your shell history. Qwen Code and Gemini CLI run in a temporary home that is deleted on exit. ## Iomlán CLI, MCP agus A2A

> Cuireann OmniRoute cliant ordú-líne ar fáil le** 91 orduithe barrleibhéil agus grúpaí orduithe** (754 ordú ag comhaireamh fo-orduithe), an** freastalaí MCP le 110 uirlis agus 33 scóip** , agus an** gníomhaire A2A le 6 scileanna** . Is féidir le scripteanna, críochfoirt agus gníomhairí AI an geata céanna a oibriú.

### CLI fíor , ní hamháin `start`

```bash
omniroute                 # start the gateway and dashboard (port 20128)
omniroute setup           # guided first-run wizard
omniroute repl            # interactive chat in the terminal (/model /combo /skill /memory)
omniroute chat "hello"    # one-shot prompt; also reads --file or --stdin
omniroute doctor          # check config, database, ports, Node runtime and native deps
```

Déanann an bhratach `--output table|json|jsonl|csv` domhanda na horduithe céanna a úsáid ó scripteanna agus CI.

### Mód cianda: an CLI ar do ríomhaire glúine, OmniRoute ar fhreastalaí

Logáil isteach uair amháin chuig cianfhreastalaí. Sábhálann an CLI é mar a** comhthéacs** , agus ritheann orduithe níos déanaí in aghaidh an fhreastalaí sin go dtí go n-aistríonn tú ar ais.

```bash
omniroute connect omniroute.example.com          # asks for the password, saves a scoped token as a context
omniroute models                                 # runs against the remote server
omniroute configure codex                        # picks a remote model, writes a local Codex profile
omniroute tokens create --name ci --scope read   # mint a narrower token for another machine
omniroute contexts use default                   # switch back to the local server
```

| Scóip comhartha | <img width="2000" height="0" alt=""> Cad a cheadaíonn sé                        |
| --------------- | ------------------------------------------------------------------------------- |
| `read`          | Déan liosta agus iniúchadh: samhlacha, stádas, logaí, úsáid                     |
| `write`         | `read` móide cumraigh agus cuir i bhfeidhm: socrú cliant, eochracha, cumraíocht |
| `admin`         | `write` plus bainistigh: comharthaí, soláthraithe, seirbhísí, beartas           |

Faigheann óstach lom `http://` agus port 20128; pas URL `https://` iomlán nuair a shuíonn an freastalaí taobh thiar de TLS. Ní fhanann bealaí ar féidir leo próisis sceite ach lúb siar, is cuma cad é an comhartha.

### Ceangail gníomhaire

Is féidir le gníomhaire, nó le do chód féin, ródú, soláthraithe, teaglama, taisce, comhbhrú agus cuimhne a thiomáint trí aon cheann de na comhéadain seo. Freastalaíonn an geata ar chosáin HTTP, de réir réamhshocraithe ag `http://localhost:20128`.

| Comhéadan                | Críochphointe nó ordú      | Úsáid é le haghaidh                                                                    |
| ------------------------ | -------------------------- | -------------------------------------------------------------------------------------- |
| MCP thar stiúideo        | `omniroute --mcp`          | Claude Deisce, Cursor agus cliaint MCP áitiúla eile                                    |
| MCP thar HTTP Streamable | `/api/mcp/stream`          | Cliant cianda MCP : 110 uirlis, 33 scóip, gach glao scríofa chuig an loga iniúchta     |
| MCP thar SSE             | `/api/mcp/sse`             | Cliaint a úsáideann an t-iompar SSE fós                                                |
| fionnachtain A2A         | `/.well-known/agent.json`  | Cárta Gníomhaire: insíonn sé do ghníomhairí eile cad is féidir le OmniRoute a dhéanamh |
| forghníomhú A2A          | `POST /a2a`                | Tascanna JSON-RPC 2.0, sioncrónach nó sruthaithe thar SSE, thar 6 scil                 |
| REST API                 | `/v1/*`                    | Comhrá OpenAI-comhoiriúnach, Freagraí, leabaithe, íomhánna, fuaime agus OCR            |
| Crúcaí gréasáin          | `/api/webhooks`            | Imeachtaí chuig Slack, Discord, Telegram, nó aon URL le síniú HMAC                     |
| cianda CLI               | `omniroute connect <host>` | cianáis a thiomáint le comharthaí rochtana scóipe                                      |

Is iad na sé scil A2A ná `smart-routing`, `quota-management`, `provider-discovery`, `cost-analysis`, `health-report` agus `list-capabilities`.

**Sula nascann tú:**

- **MCP over HTTP thosaíonn díchumasaithe.** Cas air le `omniroute mcp enable --transport streamable-http` nó ó leathanach Críochphointí an deais. Tá iompar HTTP amháin gníomhach ag an am: feidhmíonn `streamable-http` `/api/mcp/stream`, feidhmíonn `sse` `/api/mcp/sse`.
- **Tosaíonn A2A díchumasaithe.** Cumasaigh é ar leathanach Críochphointí an deais. Leanann `POST /a2a` ansin na rialacha API-eochair céanna agus `/v1`.
- **Tá eochair oiriúnach de dhíth ar cianda MCP.** Ní fhreagraíonn `/api/mcp/*` ach loopback de réir réamhshocraithe. Ó óstach eile, seol eochair le `manage` nó `admin` (gach uirlis), nó le `mcp:connect` móide scóip na n-uirlisí atá uait. I gcás eochracha gan `manage`/`admin`, cuirtear scóip uirlisí i bhfeidhm i gcónaí.

```bash
# Give Claude Code the OmniRoute toolset over MCP:
omniroute mcp enable --transport streamable-http
claude mcp add --transport http omniroute http://localhost:20128/api/mcp/stream \
  --header "Authorization: Bearer <api-key-with-manage-scope>"
```

### Conas a oibríonn sé — píblíne, ailtireacht & coigiltis math

<img src="./docs/diagrams/compression-pipeline.svg" width="100%" alt="OmniRoute compression pipeline: an illustrative 10,000-token client request passes through 12 composable engines — Session-Dedup, CCR, Lite, RTK, Responses Tool Output, Headroom, Relevance, Caveman, Aggressive, LLMLingua-2, Ultra and OmniGlyph — and can reach the provider at about 1,080 tokens in the documented stacked example. Structured content is protected by preservation guards and per-step fidelity gates; explicit lossy or experimental modes may transform eligible content."/>

Ritheann teaglama cruachta réamhshocraithe `RTK → Caveman`. Nuair a fheidhmíonn an bheirt ar an bpálasta tool/context céanna, comhdhúil choigiltis:

```txt
combined = 1 − (1 − RTK) × (1 − Caveman_input)
average  = 1 − (1 − 0.80) × (1 − 0.46) = 89.2%
range    = 78.4 – 94.6%
```

## Tuilleadh modhanna suiteála — Docker, foinse, pnpm, Arch

**🐳 Docker**

```bash
docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 \
  -p 127.0.0.1:20128:20128 -v omniroute-data:/app/data cheaperinference/omniroute:latest
```

Leanann `:latest` an líon is airde** foilsithe** SemVer cobhsaí . Ní rianaíonn sé git `main`. Pin `:X.Y.Z` le haghaidh GitOps. Féach [Cainéil Eisiúna Docker](docs/guides/DOCKER_GUIDE.md#release-channels).Na bioráin íomhá**`OMNIROUTE_MEMORY_MB=1024`** . Is leor sin don deais agus do chomhrá éadrom.** Gníomhairí códaithe** (`POST /v1/responses` ó Chód Claude, Codex, Grok, …) gá le carn V8 i bhfad níos mó nó an próiseas `FATAL ERROR` s ag ~ 12 GiB faoi dhá chomhthéacs fada forluiteacha. Méid an choimeádáin os cionn an charn (suíonn maoláin dhúchasacha lasmuigh de V8):

| <img width="2000" height="0" alt=""> Ualach Oibre | carn (`-e OMNIROUTE_MEMORY_MB`) | Coimeádán (`--memory`) |
| ------------------------------------------------- | ------------------------------- | ---------------------- |
| Painéal / comhrá éadrom                           | `1024` (réamhshocraithe íomhá)  | ≥ 2 g                  |
| Gníomhaire códaithe amháin                        | `8192`                          | ≥ 10 g                 |
| Dhá `/v1/responses` fada comhthráthach            | `10240`–`12288`                 | ≥ 12–16 g              |

```bash
docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 \
  -e OMNIROUTE_MEMORY_MB=8192 --memory=10g \
  -p 127.0.0.1:20128:20128 -v omniroute-data:/app/data cheaperinference/omniroute:latest
```

Tábla iomlán: [Treoir Docker — runtime RAM](docs/guides/DOCKER_GUIDE.md#runtime-ram-for-coding-agents).

> **Cainéal Docker réamhscaoilte:** leanann `diegosouzapw/omniroute:next` agus `diegosouzapw/omniroute:next-web` an brainse `release/v*` réamhshocraithe reatha. Níl na clibeanna mutable seo ceaptha ach chun réitigh neamheisithe a thástáil agus tá siad** gan tacaíocht le haghaidh táirgeadh** . Féach [Cainéil Eisiúna Docker](docs/guides/DOCKER_GUIDE.md#release-channels).

**🥟 Bun**

Tacaítear le `bun install` caighdeánach agus suiteáil dhomhanda (`bun install -g omniroute`) trí bhrath am rite Bun :

- **Tógtha i `bun:sqlite`** : úsáideann OmniRoute tiománaí `bun:sqlite` ionsuite Bun agus é ag rith faoi Bun, ag titim ar ais go `better-sqlite3` ar Node.js nó `sql.js`.
- **Roghnú uathoibríoch cuachtair Webpack i dev** : Aimsíonn Forbairt (`bun run dev`) Bun go huathoibríoch agus díchumasaítear Turbopack i bhfabhar Webpack chun neamh-chomhoiriúnacht cheangailteach V8 dúchasach a chosc. Leanann tógálacha táirgeachta (`bun run build`) `OMNIROUTE_USE_TURBOPACK` díreach mar atá ar Nód: Turbopack de réir réamhshocraithe, `OMNIROUTE_USE_TURBOPACK=0` le tógáil le Webpack (nochtann `Dockerfile.bun` é mar `--build-arg`).
- **Bun Dockerfile tiomnaithe** : `Dockerfile.bun` ilchéime le haghaidh imscaradh táirgeachta Bun dúchais (`docker build -f Dockerfile.bun -t omniroute:bun .`).

```bash
# Install and run with Bun
bun install
bun run dev
```

**🦭 Podman**

```bash
# 1. Prepare the bind-mounted data directory
mkdir -p data

# 2. Linux + local rootless Podman only (never a remote Podman Machine client):
podman unshare chown 1000:1000 ./data

# 3. Set the runtime hint, build the local Compose image, and start
echo "CONTAINER_HOST=podman" >> .env
podman compose --profile base up -d --build
```

Ar macOS nó Windows, úsáideann Podman Meaisín Podman iargúlta: skip `podman unshare` agus lean an [treoir eolaire sonraí topology-shonrach](contrib/podman/README.md#data-directory-permissions-by-topology).

📖 [Podman Guide](contrib/podman/README.md) — Tógann Compose, Podman Machine, agus Linux/systemd Quadlet setup.

**⚡ Suiteáil níos tapúla / níos tanaí (scipeáil an tógáil dúchais)**

Is é an t-inneall dúchais SQLite (`better-sqlite3`) ná** roghnach** spleáchas, mar sin ní chuireann suiteáil dhomhanda bac ar thiomsú ón bhfoinse: úsáideann sé dénártha réamhthógtha nuair a mheaitseálann duine do platform/Node, agus ar shlí eile titeann sé ar ais go trédhearcach go hinneall JS íon (`node:sqlite` ar Nód 22 +, ar shlí eile an `sql.js` WASM cuachta ) — níl aon uirlisí tógála ag teastáil.

Chun an iar-shuiteáil a scipeáil** téamh suas dúchasach** go hiomlán (CI, gan cheann, nó meaisíní mall). Nóta: ní scipeann sé seo ach an chéim dhúchasach téamh SQLite (`scripts/postinstall.mjs`); ritheann an hook binary-copy/repair (`scripts/build/postinstall.mjs`) de ghnáth:

```bash
OMNIROUTE_SKIP_POSTINSTALL=1 npm install -g omniroute   # CI=1 also skips it
```

Maidir leis na suiteálacha is tapúla is fearr** pnpm** (siopa atá dírithe ar ábhar + hard links — féach thuas). Chun am rite gan cheann gan deais a fháil, úsáid an phróifíl Docker `base` (thuas) nó an [treoir Termux](docs/guides/TERMUX_GUIDE.md). Déantar an CLI agus an painéal gréasáin a sheirbheáil leis an bpróiseas céanna ar aon chalafort amháin, agus mar sin níl aon phacáiste CLI-amháin ar leith inniu.
