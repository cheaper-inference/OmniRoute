Esta guía cubre cómo eliminar limpiamente OmniRoute de su sistema.

## Revertir la configuración del cliente

El desinstalador detiene el proceso OmniRoute administrado por PM2, si está presente, y deja la configuración del cliente en su lugar. Los clientes que todavía apuntan a OmniRoute pierden su conexión una vez que se detiene. La eliminación completa también elimina el directorio de datos, `~/.omniroute` de forma predeterminada, junto con las copias de seguridad de la configuración del cliente.

### 1. Utilice el panel mientras OmniRoute se está ejecutando

Abierto** Código CLI** (`/dashboard/cli-code`) en el tablero y busque el** Código Claude** tarjeta.** Aplicar** escribe en el archivo de configuración de código Claude del host OmniRoute, `~/.claude/settings.json` de forma predeterminada. Si tiene una copia de seguridad de antes de aplicar la configuración OmniRoute, abra** Copias de seguridad** y restaurarlo. De lo contrario, seleccione** Reiniciar** para eliminar la configuración de la puerta de enlace de `env`. Aplicar y restablecer primero haga una copia de seguridad del archivo existente. Las copias de seguridad se almacenan en `<DATA_DIR>/backups`.

Si `CLI_ALLOW_CONFIG_WRITES=false` o el panel no están disponibles, revierta el archivo manualmente. Si OmniRoute se ejecuta en Docker y el cliente se ejecuta en el host, revierta la configuración del host. Los archivos en un contenedor principal desmontado no tienen ningún efecto en el cliente host.

### 2. Revertir los cambios restantes manualmente

Para el código Claude, verifique `~/.claude/settings.json`, `settings.json` en `CLAUDE_CONFIG_DIR` si está configurado y `.claude/settings.json` del proyecto. Restablecer elimina las siguientes claves de `env`. Elimine los valores que agregó para OmniRoute o restaure sus valores anteriores.

- `"ANTHROPIC_BASE_URL"`, `"ANTHROPIC_AUTH_TOKEN"` y `"ANTHROPIC_API_KEY"`
- `"ANTHROPIC_DEFAULT_OPUS_MODEL"`, `"ANTHROPIC_DEFAULT_SONNET_MODEL"` y `"ANTHROPIC_DEFAULT_HAIKU_MODEL"`
- `"API_TIMEOUT_MS"`

El reinicio deja `ANTHROPIC_MODEL` en `env` y las configuraciones de nivel superior `model` y `apiKeyHelper` en su lugar. Elimínelos o restáurelos manualmente si seleccionan un modelo o credencial OmniRoute. Deje de usar cualquier perfil OmniRoute creado por `omniroute setup-claude` en `~/.claude/profiles/<name>/` o revierta su `settings.json`. El comando de configuración escribe el perfil sin cambiar el archivo de configuración predeterminado ni guardar un token. Elimine o restaure las exportaciones coincidentes en los archivos de inicio de su shell y borre los valores antiguos del shell actual. `omniroute launch` y `omniroute run claude` configuran la puerta de enlace URL y el token solo para el proceso secundario.

Para Codex, restaure el proveedor y modelo anteriores en `~/.codex/config.toml` si contiene `model_provider = "omniroute"`. Elimine `[model_providers.omniroute]` si se agregó para esta puerta de enlace. Restaure o elimine `openai_base_url` si apunta a OmniRoute. Para clientes compatibles con OpenAI, restaure o borre `OPENAI_BASE_URL` dondequiera que lo haya configurado para OmniRoute.

### 3. Verificar que el cliente funcione con OmniRoute detenido

Verifique la configuración predeterminada del código Claude y el entorno de shell actual.

```bash
grep -n ANTHROPIC ~/.claude/settings.json
env | grep ANTHROPIC
```

Ninguna verificación debería mostrar `ANTHROPIC_BASE_URL` apuntando a OmniRoute. Si utiliza un perfil o configuración de proyecto, verifique esos archivos también. Con OmniRoute detenido y su autenticación habitual restaurada, ejecute Claude Code directamente.

```bash
claude -p "say hello"
```

El código Claude debería responder utilizando la configuración restaurada. Si todavía apunta a la puerta de enlace detenida, la solicitud falla con un error de conexión.

## Desinstalación rápida (v3.6.2 +)

> Primero [revierta la configuración del cliente](#revert-client-configuration), mientras OmniRoute todavía se está ejecutando.

OmniRoute proporciona dos scripts integrados para una eliminación limpia:

### Mantenga sus datos

```bash
npm run uninstall
```

Esto elimina la aplicación OmniRoute pero** conservas** su base de datos, configuraciones, claves API y configuraciones del proveedor en `~/.omniroute/`. Úselo si planea reinstalar más tarde y desea mantener su configuración.

### Eliminación completa

```bash
npm run uninstall:full
```

Esto elimina la aplicación.** y borra permanentemente** todos los datos:

- Base de datos (`storage.sqlite`)
- Configuraciones de proveedores y claves API
- Archivos de copia de seguridad
- Archivos de registro
- Todos los archivos en el directorio `~/.omniroute/`

> ⚠️** Advertencia:** `npm run uninstall:full` es irreversible. Todas las conexiones de su proveedor, combos, claves API e historial de uso se eliminarán permanentemente.

## Desinstalación manual

> Primero [revierta la configuración del cliente](#revert-client-configuration), mientras OmniRoute todavía se está ejecutando.

### Instalación global NPM

```bash
# Remove the global package
npm uninstall -g omniroute

# (Optional) Remove data directory
rm -rf ~/.omniroute
```

### Instalación global de pnpm

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# Stop and remove the container
docker stop omniroute
docker rm omniroute

# Remove the volume (deletes all data)
docker volume rm omniroute-data

# (Optional) Remove the image
docker rmi cheaperinference/omniroute:latest
# Older installs pulled the legacy name:
docker rmi diegosouzapw/omniroute:latest
```

### Docker componer

```bash
# Stop and remove containers
docker compose down

# Also remove volumes (deletes all data)
docker compose down -v
```

### Aplicación de escritorio Electron

**Windows:**

- abrir `Settings → Apps → OmniRoute → Uninstall`
- O ejecute el desinstalador NSIS desde el directorio de instalación

**macOS:**

- Arrastre `OmniRoute.app` desde `/Applications` a la Papelera
- Eliminar datos: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- Eliminar el archivo AppImage
- Eliminar datos: `rm -rf ~/.omniroute`

### Instalación de código fuente (clon de git)

```bash
# Remove the cloned directory
rm -rf /path/to/omniroute

# (Optional) Remove data directory
rm -rf ~/.omniroute
```

## Directorios de datos

De forma predeterminada, OmniRoute almacena los datos en las siguientes ubicaciones:

| Plataforma         | Ruta predeterminada            | Anulación                             |
| ------------------ | ------------------------------ | ------------------------------------- |
| Linux              | `~/.omniroute/`                | Variable de entorno `DATA_DIR`        |
| macOS              | `~/.omniroute/`                | Variable de entorno `DATA_DIR`        |
| Windows            | `%APPDATA%/omniroute/`         | Variable de entorno `DATA_DIR`        |
| Docker             | `/app/data/` (volumen montado) | Variable de entorno `DATA_DIR`        |
| Compatible con XDG | `$XDG_CONFIG_HOME/omniroute/`  | Variable de entorno `XDG_CONFIG_HOME` |

### Archivos del directorio de datos

| Archivo/Directorio   | Descripción                                                           |
| -------------------- | --------------------------------------------------------------------- |
| `storage.sqlite`     | Base de datos principal (proveedores, combinaciones, ajustes, claves) |
| `storage.sqlite-wal` | Registro de escritura anticipada de SQLite (temporal)                 |
| `storage.sqlite-shm` | Memoria compartida de SQLite (temporal)                               |
| `call_logs/`         | Archivos de cargas útiles de solicitudes                              |
| `backups/`           | Copias de seguridad automáticas de la base de datos                   |
| `log.txt`            | Registro de solicitudes heredado (opcional)                           |

## Verificar la eliminación completa

Después de desinstalar, verifique que no queden archivos:

```bash
# Comprobar el paquete global de npm
npm list -g omniroute 2>/dev/null

# Comprobar el directorio de datos
ls -la ~/.omniroute/ 2>/dev/null

# Comprobar si hay procesos en ejecución
pgrep -f omniroute
```

Si algún proceso sigue en ejecución, deténgalo:

```bash
pkill -f omniroute
```
