`@omniroute/opencode-plugin-v2` incorpora todo tu catálogo de OmniRoute —modelos, combos y
combos automáticos— al selector de modelos de OpenCode v2, con nombres para mostrar, precios y
límites del nivel gratuito.

Es un paquete independiente de `@omniroute/opencode-plugin` porque OpenCode v1 y v2 cargan
los plugins mediante contratos diferentes. Elige el que coincida con la versión principal de OpenCode; no se
comparte nada entre ambos, por lo que actualizar uno nunca obliga a actualizar el otro.

## Requisitos

- OpenCode v2.
- Una puerta de enlace de OmniRoute accesible (`http://localhost:20128` de forma predeterminada).
- Node.js 22 o 24.

## Instalación

Añade el plugin a `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

Los modelos aparecerán como `omniroute/<provider>/<model>`; `providerId` determina ese prefijo y
el id de la integración bajo la cual OpenCode almacena la credencial.

## Credenciales

El plugin busca una clave de la puerta de enlace en tres lugares, en este orden:

1. **La credencial que conectaste en OpenCode.** El plugin registra una integración, por lo que
   el propio flujo de autenticación de OpenCode puede almacenar la clave. Nada se guarda en `opencode.json`; esta es la opción preferida.
2. `apiKey` en las opciones del plugin, para una configuración específica del proyecto. Esto coloca la clave en un archivo que
   podrías estar incluyendo en el repositorio.
3. `OMNIROUTE_API_KEY` en el entorno.

Si no se encuentra ninguna de las tres, el catálogo queda vacío y el plugin lo indica una vez durante el inicio, en lugar de
dejarte con un selector vacío sin ninguna explicación.

### El token de administración es una clave diferente

Los combos, el estado de los proveedores y el enriquecimiento (nombres para mostrar, precios y límites del nivel gratuito) proceden de
los endpoints `/api/*` de la puerta de enlace, que en la mayoría de las implementaciones están protegidos por un token de **administración**
en lugar de la clave de inferencia:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<token de lectura de administración>"
}
```

Si no se configura, `managementReadToken` recurre a `apiKey`. Cuando una puerta de enlace rechaza esa alternativa,
el catálogo sigue publicándose, pero con ids de modelo sin procesar en lugar de nombres para mostrar, sin
deduplicación de alias canónicos, sin precios y sin combos. El plugin muestra una advertencia una vez por endpoint cuando esto sucede,
indicando el endpoint y qué se ha perdido, para que un selector degradado nunca sea un misterio.

## Opciones

| Llave                            | Por defecto                                     | Notas                                                                                                                                                                                                                                                                                                                                                                                            |
| -------------------------------- | ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `providerId`                     | `"omniroute"`                                   | La identificación del proveedor, la identificación de integración y los modelos de prefijo aparecen en                                                                                                                                                                                                                                                                                           |
| `baseURL`                        | requerido                                       | Raíz de puerta de enlace, solo `http(s)` ; el sufijo `/v1` se agrega donde sea necesario                                                                                                                                                                                                                                                                                                         |
| `apiKey`                         | credencial conectada, luego `OMNIROUTE_API_KEY` | Clave de chat para `/v1/*`                                                                                                                                                                                                                                                                                                                                                                       |
| `managementReadToken`            | vuelve a caer a `apiKey`                        | Clave para `/api/*` — normalmente** no** el mismo                                                                                                                                                                                                                                                                                                                                                |
| `displayName`                    | `"OmniRoute"`                                   | Nombre del proveedor en el selector                                                                                                                                                                                                                                                                                                                                                              |
| `timeoutMs`                      | `10000`                                         | Tiempo de espera de recuperación por punto final (los combos automáticos usan 5 segundos)                                                                                                                                                                                                                                                                                                        |
| `modelCacheTtlMs`                | `300000`                                        | Caché de catálogo TTL; una instantánea del disco calienta los arranques en frío                                                                                                                                                                                                                                                                                                                  |
| `timeouts`                       | vuelve a caer a `timeoutMs`                     | Presupuestos por punto final en ms: `models`, `combos`, `autoCombos`, `enrichment`                                                                                                                                                                                                                                                                                                               |
| `enrichment`                     | `true`                                          | Obtenga nombres, precios y presupuestos de nivel gratuito                                                                                                                                                                                                                                                                                                                                        |
| `providerTag`                    | `true`                                          | Alternar el paréntesis del editor final: `Provider - Model (Editor)`. El proveedor (ruta que sirve al modelo) siempre se muestra; el editor (que hizo el modelo) aparece solo entre paréntesis. Ejemplo: `Openrouter - MoonshotAI: Kimi K 3.1 Pro` -> `Openrouter - Kimi K 3.1 Pro (MoonshotAI)`. Se omite cuando el editor y el proveedor comparten un nombre. Configure `false` para soltarlo. |
| `usableOnly`                     | `false`                                         | Mantenga solo a los proveedores los informes de la puerta de enlace tal como están aprovisionados.                                                                                                                                                                                                                                                                                               |
| `combosSource`                   | `"api"`                                         | `"models"` omite `/api/combos` y publica las filas combinadas `/v1/models` ; los filtros a nivel de miembro mantienen `"api"`                                                                                                                                                                                                                                                                    |
| `showcasePerOwner`               | `10`                                            | Entradas de vista predeterminada mantenidas por proveedor                                                                                                                                                                                                                                                                                                                                        |
| `freshPerOwner`                  | `10`                                            | Vista predeterminada de entradas nuevas mantenidas por proveedor                                                                                                                                                                                                                                                                                                                                 |
| `freshWindowDays`                | `90`                                            | Ventana de frescura en días para la rama fresca                                                                                                                                                                                                                                                                                                                                                  |
| `usageMemory`                    | `true`                                          | Restaurar entradas eliminadas estáticamente nombradas por análisis de uso de 30 días (necesita un token de administración)                                                                                                                                                                                                                                                                       |
| `visibleModels` / `hiddenModels` | `[]`                                            | Listas permitidas exactas o con sufijos; negar gana; `*` publica el catálogo completo (aún se aplican otros filtros)                                                                                                                                                                                                                                                                             |
| `geminiSanitization`             | `true`                                          | Elimine las palabras clave del esquema JSON Gemini rechaza de los esquemas de herramientas (las herramientas `$ref` se reenvían intactas)                                                                                                                                                                                                                                                        |
| `apiFormat.allowAnthropic`       | `false`                                         | Enrutar los identificadores permitidos a través del bloque Anthropic API                                                                                                                                                                                                                                                                                                                         |
| `apiFormat.anthropicModels`      | `[]`                                            | ID de modelo completo enrutados a Anthropic                                                                                                                                                                                                                                                                                                                                                      |
| `logLevel` / `startupDebug`      | `warn` / `false`                                | Verbosidad del registrador                                                                                                                                                                                                                                                                                                                                                                       |

La memoria de uso está activada de forma predeterminada. Sin un token de administración, permanece inerte (se registra un aviso de inicio) y no se restaura nada.

## Cómo se mantiene actualizado el catálogo

El catálogo se recupera de forma diferida y se almacena en caché para `modelCacheTtlMs`, y una instantánea del disco mantiene disponible el último catálogo conocido cuando la puerta de enlace es inalcanzable. — una interrupción no le cuesta nada más que frescura. Los modelos y combos se publican apenas llegan; Los combos automáticos, la lista de proveedores y la superposición de enriquecimiento se pliegan cuando aterrizan, por lo que un punto final lento no puede mantener como rehén a todo el selector.

Los nombres siguen `Provider - Model[ (Editor)][ · budget][ (route)]`: el proveedor se muestra siempre que la identificación lleva uno (una identificación sin barra diagonal se representa sin prefijo), un `🆓` inicial marca las entradas gratuitas y su presupuesto de nivel gratuito permanece como un sufijo `· 1M tokens/month`, el editor de un nombre `Editor: Model` explícito se mueve a un paréntesis final (no se adivina ningún editor a partir de otros nombres) y los combos se representan como `combo - <slug>` sin un ícono gratuito. Dos entradas que comparten un nombre obtienen un sufijo de ruta — `(no-think)` — para que sigan siendo distinguibles. `providerTag` ( `true` predeterminado) alterna el paréntesis del editor final.

No existe un comando de actualización manual: los comandos OpenCode v2 son plantillas de aviso, no devoluciones de llamada, por lo que un complemento no puede exponer uno. Las actualizaciones siguen el TTL; Se solicita al host que recargue solo cuando el catálogo o la superposición realmente cambiaron, nunca una vez por actualización.

## Llamadas a herramientas en Gemini

Gemini rechaza cualquier solicitud completa cuyas declaraciones de herramientas contengan `$schema` o `additionalProperties`, y responde con `400 INVALID_ARGUMENT`. El plugin elimina esas palabras clave de los esquemas de herramientas destinados a un modelo Gemini de este proveedor y deja intactas todas las demás solicitudes. Una herramienta que contiene un `$ref` se reenvía intacta en lugar de eliminarlo, ya que quitar la referencia ampliaría el esquema para que «acepte cualquier cosa».
Establezca `"geminiSanitization": false` para desactivarlo.

## Solución de problemas

| Síntoma                                                                | Causa                                                                                                                                               |
| ---------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Picker no muestra ningún modelo OmniRoute                              | No se resolvió ninguna clave (verifique la advertencia de inicio) o no se puede acceder a la puerta de enlace                                       |
| Identificadores de modelo sin procesar, sin combinaciones, sin precios | Los puntos finales de administración rechazaron el token — set `managementReadToken`                                                                |
| Catálogo `freeOnly` corto o vacío                                      | Ningún token de administración o un token rechazado — lee la línea de resumen de actualización (recuento `unmatched-free` ) en el registro del host |
| Una sesión fijada en `opencode-<id>/...`                               | El complemento v1 publicó `opencode-<id>`; v2 publica `<id>` desnudo, así que vuelva a seleccionar el modelo en `<id>/...`                          |

Las variables de entorno deben llegar al proceso del servidor de código abierto: cuando el host se ejecuta como un servicio, el shell que ejecuta `opencode models` y el entorno del servidor son diferentes, así que exporte la clave donde la lee el servidor.
