> Conmutadores en tiempo de ejecución que cambian el comportamiento de OmniRoute **sin volver a desplegar**.
> Cada indicador enumerado aquí está definido en
> [`src/shared/constants/featureFlagDefinitions.ts`](../../src/shared/constants/featureFlagDefinitions.ts)
> — la única fuente de verdad. Tanto el panel como la API REST leen ese
> archivo, por lo que la tabla siguiente se genera para coincidir con él 1:1.

---

## Qué son los indicadores de funcionalidad

Un indicador de funcionalidad es un conmutador con nombre (booleano o enumeración) cuyo valor puede cambiarse en
tiempo de ejecución y conservarse en la base de datos, sin necesidad de volver a desplegar el proceso. Cada
indicador se describe mediante una `FeatureFlagDefinition` con una `key`, `label`,
`description`, `category`, `defaultValue`, `type` y una indicación `requiresRestart`.

### Orden de resolución

El **valor efectivo** de un indicador se resuelve mediante
[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) con esta
precedencia (gana la más alta):

1. **Anulación de la BD** — un valor almacenado en la tabla `key_value` bajo el
   espacio de nombres `feature_flags` (establecido mediante el panel o la API REST).
2. **Variable de entorno** — `process.env[<KEY>]`, si está definida y no está vacía.
3. **Valor predeterminado de la definición** — el `defaultValue` de `featureFlagDefinitions.ts`.

Un indicador booleano se considera **habilitado** cuando su valor efectivo es `"true"`,
`"1"` o `"yes"` (consulte `isFeatureFlagEnabled()`).

> [!NOTE]
> La mayoría de los indicadores también tienen una variable de entorno correspondiente con el **mismo nombre**
> documentada en [`ENVIRONMENT.md`](./ENVIRONMENT.md). La anulación del indicador en la BD
> tiene prioridad sobre esa variable de entorno. Un indicador con
> `requiresRestart: true` se conserva de inmediato, pero solo vuelve a leerse al iniciar el proceso;
> al cambiarlo, se muestra un aviso **"Reiniciar servidor"** en el panel.

## Alternar banderas

### Panel

Navega a **Panel → Configuración → Banderas de funcionalidades**
(`/dashboard/settings/feature-flags`). La cuadrícula
(`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`)
admite:

- **Búsqueda** por clave o descripción, y **filtrado** por categoría (además de una vista sintética de
  **Requiere reinicio**).
- Un **conmutador** para las banderas booleanas y un **menú desplegable** para las banderas enum
  (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`).
- Una insignia de **origen** por bandera — `DB`, `ENV` o `DEF` — que muestra de dónde provino el valor efectivo.
- Un botón **Restablecer** (que solo se muestra para las banderas cuyo origen es `DB`) para eliminar la sobrescritura, y un botón **Restablecer todas las sobrescrituras** en la parte inferior.
- Un banner de **Reiniciar servidor** cuando se cambia una bandera `requiresRestart`.

### API REST

Todas las operaciones pasan por una única ruta:
[`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts).
Todos los métodos requieren una sesión autenticada del panel (`401` en caso contrario).

#### `GET /api/settings/feature-flags`

Devuelve todas las banderas con su valor efectivo, origen y un resumen.

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Require API Key",
      "description": "Require an API key for all incoming requests",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... todas las 115 banderas
  ],
  "summary": {
    "total": 115,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

Establece o elimina una única sobrescritura. Cuerpo: `{ key: string; value?: string }`.
Omitir `value` elimina la sobrescritura (restaurando el valor de env / predeterminado).

```bash
# Establecer una sobrescritura de DB
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# Eliminar la sobrescritura (sin "value")
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

La respuesta incluye el nuevo `effectiveValue`/`source`, el `previousValue`/
`previousSource` y `requiresRestart`. Las claves desconocidas y los valores enum
fuera de rango se rechazan con `400`.

#### `DELETE /api/settings/feature-flags`

Borra **todas** las sobrescrituras de DB a la vez, restaurando cada bandera a su valor de env / predeterminado. Devuelve `{ cleared: <count>, message: "..." }`.

> [!NOTE]
> Las banderas con `requiresRestart: true` solo surten efecto después de recargar el proceso.
> El flujo de reinicio del panel llama a `POST /api/restart` y luego consulta periódicamente
> `GET /api/health/ping` hasta que el servidor vuelve a estar disponible.

## Alternativa de emergencia por presupuesto

`OMNIROUTE_EMERGENCY_FALLBACK` (categoría `runtime`, valor predeterminado `true`) controla la
ruta alternativa gratuita de emergencia en
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts).
Cuando está habilitada, las solicitudes que agotan su presupuesto se redirigen a un
proveedor/modelo alternativo gratuito en lugar de fallar directamente. Establézcala en `false` (o `0`) — mediante el
selector del panel de control, una sobrescritura en la base de datos o la variable de entorno
`OMNIROUTE_EMERGENCY_FALLBACK` — para deshabilitar este comportamiento y permitir que las solicitudes
que hayan agotado su presupuesto fallen. (Disponible como selector en el panel de control en las PR #3741 / #3752).

Una respuesta servida mediante esta alternativa incluye
`X-OmniRoute-Emergency-Fallback: from=<provider/model>; to=<provider/model>`, por lo que un
cliente puede saber que fue redirigida sin comparar `X-OmniRoute-Provider` con su
solicitud. El encabezado no está presente en ninguna otra respuesta.
