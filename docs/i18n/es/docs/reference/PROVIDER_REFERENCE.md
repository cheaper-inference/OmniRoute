## Categorías

- **Gratuito** — nivel gratuito con clave API (configurado a través del panel de control)
- **Sin autenticación** — puntos finales públicos que no requieren clave ni inicio de sesión
- **OAuth** — flujo de inicio de sesión gestionado por OmniRoute, no se necesita clave API
- **Cookie web** — envuelve la aplicación web del proveedor mediante autenticación por cookie
- **Clave API** — proveedor de pago configurado mediante clave API (pueden aplicarse créditos gratuitos)
- **Local** — se ejecuta en la máquina del usuario (Ollama, LM Studio, vLLM, etc.)
- **Búsqueda** — proveedores de búsqueda web
- **Audio** — proveedores solo de audio (TTS/STT)
- **Proxy ascendente** — proveedores que actúan como proxy para otros proveedores
- **Agente en la nube** — agentes de codificación de larga duración (Codex Cloud, Devin, Jules)
- **Sistema** — proveedores internos de OmniRoute (loopback, etc.)

Etiquetas adicionales: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Llamada a herramientas` (donde se muestra): `nativa` — API real de llamada a funciones; `emulada` — el array `tools` se emula mediante `webTools.ts` (bloques `<tool>{...}</tool>` analizados por expresiones regulares); `ninguna` — `tools` se descarta silenciosamente en la actualidad. Ver #7286.

Utilice el panel de control en `/dashboard/providers` para habilitar, configurar y probar cada proveedor.
