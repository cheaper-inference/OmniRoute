Ìwé yìí ni ìtọ́kasí aláṣẹ fún gbogbo àwọn ibodè dídánwò dídára CI nínú OmniRoute.
Ó ṣàpèjúwe ibodè kọ̀ọ̀kan, ohun tí ó ń fìdí rẹ̀ múlẹ̀, iṣẹ́ CI tí ó ti ń ṣiṣẹ́, bóyá ó ń lo
ìpìlẹ̀ ratchet tàbí ìlànà kọjá/kùnà, àti bóyá ó ń dí ìkọ́lé dúró tàbí ó jẹ́ ìmọ̀ràn.

Fún àkótán ṣókí àti ìlànà allowlist, wo abala "Àwọn Ibodè Dídára & Ratchets"
nínú `AGENTS.md`. Fún àyẹ̀wò pàtàkì, ìsọ̀rí ìpele ìdàgbàsókè, àti ètò ìṣàtúnṣe
tí kò sinmi lé irinṣẹ́ kan pàtó fún ètò kan náà, wo
[Ìwé Ìtọ́sọ́nà Ibodè Dídára](../ops/QUALITY_GATE_PLAYBOOK.md).

## Akójọ àwọn gate àti àwọn profaílì ìranṣẹ́

### Ìfàwọ̀lé àwọn olùdíje

Àwọn workflow CI àti Quality Gates kọ̀ọ̀kan ń ṣe ìdájọ́ kan tó dúró jáde: `Gate / CI` àti
`Gate / Quality`. Ètò ìfàwọ̀lé wọn tó ní ẹ̀yìn ṣàkójọ gbogbo iṣẹ́ upstream kọ̀ọ̀kan gẹ́gẹ́
bíi dandan tàbí ìmọ̀ràn. Iṣẹ́ dandan kan tó bá ṣe é gbọdọ̀ ṣàṣeyọrí: àìsí, fífagi lé,
fífò, dídúróde àti àwọn abẹ́lẹ̀ àìmọ̀ kò lè fi PASS fìdí. Ìpín sọ́tọ́ àwọ̀ docs-only
tàbí catalog-only lè jẹ́ kí ọ̀nà kóòdù kan má ṣe é ṣe; PR àkọ̀tọ́ (draft) kì í ṣe olùdíje
tó gbà. Àmì `hotfix` kò yọ ẹ̀rí kúrò.

Àwọn workflow méjèèjì bo àwọn PR tí wọ́n ń lọ sínú àwọn ẹ̀ka main/release, àwọn ìfípò
sí `main`, ìránṣẹ́ ọwọ́ àti àwọn ìṣẹ̀lẹ̀ merge-group. Ìfípò, ìránṣẹ́ àti merge-group ń
ṣe gbogbo àṣàyàn náà. Àwọn ìfípò sí `release/**` kò bẹ̀rẹ̀ wọn (2026-10-18): ìyípadà
kọ̀ọ̀kan ti ṣe matrix lórí PR rẹ̀, ìdàpapọ̀ tó ti parí sì jẹ́ iṣẹ́ Release-Green
(`docs/ops/RUNNER_BOX.md` → Hosted lane). Àwọn fork àti merge group ń lo àwọn runner
àlejò fún àwọn iṣẹ́ tí wọ́n bá ti ń yan àwọn runner ara-ẹni; ó gbọdọ̀ ṣàyẹ̀wò pé agbára
àlejò tó tó wà ṣáájú ìfìlọ́lẹ̀.

Ìrìsí JSON kọ̀ọ̀kan ṣàmìsí SHA tó jáde (checkout), ìranṣẹ́ workflow àti ìgbìyànjú.
CLI ń kọ̀ sí àìbáaramu SHA láàrin checkout àti ìṣẹ̀lẹ̀. Àwọn ìdánwò workflow so
ìjọ́ṣepọ̀ ètò mọ́ àkójọ `needs` ti iṣẹ́ ìdájọ́ kí ọ̀nà tuntun tàbí tó yọ kúrò má bà a
farapin lọ́nà pàtàkì. Àwọn ìrìsí bo workflow tirẹ̀ wọn nìkan, kì í ṣe ìtẹ̀jáde,
ìfìlọ́lẹ̀, tàbí àwọn ohun-inú scanner ìmọ̀ràn tó wà tẹ́lẹ̀. Ìmú àwọn orúkọ àyẹ̀wò
méjèèjì ṣiṣẹ́ nínú àwọn òfin ẹ̀ka jẹ́ ìyípadà ìṣàkóso tó yàtọ́; fífi àwọn iṣẹ́ wọ̀nyí
kún un kò daabobo ẹ̀ka fúnra rẹ̀.

### Akójọ ìwádìí ìdásílẹ̀

Akójọ npm-alias tó ní ẹ̀yìn àti ìjọ́ṣepọ̀ ìwádìí ìdásílẹ̀ wà nínú
`config/quality/gate-manifest.json`. Ṣe `npm run check:gate-manifest` láti fìdí àwọn
orúkọ script àti àwọn àṣẹ gangan lẹ́sẹ̀sì `package.json`; àwọn àfikún, yíyọkúrò àti
ìyípadà àṣẹ ń kùnà hook ibilẹ̀ àti àwọn iṣẹ́ ìpín ìyípadà nínú CI lọ́nà méjèèjì. Alias
kì í ṣe iṣẹ́ workflow, apẹẹrẹ matrix tàbí ọ̀rọ̀ ìdánwò: a kò gbọdọ̀ ṣàfihàn àwọn iṣiro
wọ̀nyí bí ohun tí a lè rọ́pò ara wọn.

Lo `npm run quality:scan -- --list` tàbí `npm run quality:scan:fast -- --list`
láti ṣàyẹ̀wò àwọn alias tí a yan láì ṣe wọn. Olùdarí ń pe ibi-ìwọlé npm, nítorí náà a
gbé àkókò-ìranṣẹ́ rẹ̀ (pẹ̀lú Bun ní ibi tí a ti ṣètò) kúlẹ̀. Manifest ń kọ àwọn alias
tí wọ́n wà lẹ́yìn àwọn profaílì yẹn sílẹ̀ gẹ́gẹ́ bí tí a pe wọn lọ́tọ̀, a sì dì àwọn àṣẹ
ìtọ́jú nínú àwọn profaílì ìwádìí kika-nìkan.

Àwọn profaílì wọ̀nyí bo ìwádìí ìdásílẹ̀ nìkan. Wọn kò jẹ́rìí sí àwọn ìdánwò ọjà,
coverage, ìkòkó, àwọn àyẹ̀wò òde tàbí ìgbàlá ìtúpalẹ̀ kikun ti olùdíje. Ìfàwọ̀lé
workflow ń lo `config/quality/admission-policy.json` àti
`scripts/quality/admission-verdict.mjs` tí a so mọ́ ọn. Àwọn profaílì release-observer
ṣì dúró lọ́tọ̀; ṣàyẹ̀wò àwọn àyẹ̀wò àti ìrìsí wọn tí ó ṣe é lọ́tọ̀. Akójọ ọ̀rọ̀ tó wà
ní ìsàlẹ̀ jẹ́ ìtọ́kasí, kì í ṣe ẹ̀rí pé gate kan ṣe é ní ti gidi.

Àwọn script wà ní abẹ́ `scripts/check/` (àwọn gate ètò) àti `scripts/quality/` (Ẹ̀rọ ratchet).
Orísun òtítọ́ CI ni `.github/workflows/ci.yml`.

### Ọ̀nà-kíákíá PR ìtúpalẹ̀ (`quality.yml`)

`.github/workflows/quality.yml` ń kún CI lórí àwọn PR main/release, àwọn ìfípò sí
`main`, ìránṣẹ́ àti àwọn merge group. Àwọn PR ń lo àwọn àyẹ̀wò kíákíá tí a ṣẹ nípasẹ̀
ọ̀nà. A ti yọ build ẹ̀mejì tí a dá lẹ́mọọ́ láé kúrò; àwọn àyẹ̀wò build/package/boot
gangan ṣì wà nínú CI.

| Iṣẹ́                                              | Àyíká                                                                                                                                                                                                                        | Ìdíwọ́                 |
| ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------- |
| `Docs Gates (fast-path)`                         | Àwọn PR docs/kóòdù; àwọn ìtọ́kasí API docs àti docs-all                                                                                                                                                                       | Bẹ́ẹ̀ni                 |
| `Fast Quality Gates`                             | Àwọn PR kóòdù; àwọn àyẹ̀wò ìdásílẹ̀, typecheck, typecheck dashboard, àwọn ìdánwò ẹyọkan tí ó kan                                                                                                                               | Bẹ́ẹ̀ni                 |
| `Forgotten sibling tests`                        | Àwọn PR kóòdù; a tọpinpin àwọn module tí a yí padà sí àwọn olùlò ìdásílẹ̀ àti àwọn ìdánwò ẹlẹ́gbẹ́ tó jẹ́ olùdíje; a ṣàfihàn àwọn ọ̀nà barrel àti dynamic-import gẹ́gẹ́ bí ìtúpalẹ̀ ìmọ̀ràn, pẹ̀lú àwọn àyà nínú allowlist tí a tọ́kasí | **Ìmọ̀ràn**            |

| `No new ESLint warnings`                         | Àwọn PR kóòdù; olùṣọ́ lint tó mọ̀ nípa àwọn ìdínkù                                                                                                                                                                             | Bẹ́ẹ̀ni, pẹ̀lú àwọn fork |
| `Merge integrity (changelog + generated skills)` | Àwọn PR tí kì í ṣe àkọ̀tọ́; ìṣọ́pọ̀ changelog àti àwọn skill tí a ṣẹ̀dá                                                                                                                                                           | Bẹ́ẹ̀ni, pẹ̀lú àwọn fork |

#### Ìròyìn àwọn ìdánwò ẹlẹ́gbẹ́ tí a gbàgbé

`npm run check:forgotten-sibling-tests` ń tún olùyanjú import tó wà lẹ́yìn àwòrán ipa ìdánwò lò. Fún gbogbo module iṣelọpọ̀ tó yí padà, ó ń jàbọ̀ àwọn ẹ̀wọ̀n tó dájú `changed module/symbol -> static consumer -> candidate sibling test` nígbà tí ìdánwò arákùnrin náà kò sí nínú diff pull-request. Àkótán Markdown àti èsì JSON jẹ́ mímọ́ sílẹ̀ gẹ́gẹ́ bí artifact ìṣàn-iṣẹ́ `forgotten-sibling-tests` fún ìwọ̀nsọ́wọ́n ṣáájú ìfilọ́lẹ̀ dídí kankan.

Àwọn barrel re-export àti dynamic import jẹ́ ìwádìí ìyanjú nìkan; wọn kò dá àwárí dídí sílẹ̀ rárá. Àwọn àyàfi tí wọ́n ti ṣàyẹ̀wò wà nínú `config/quality/forgotten-sibling-allowlist.json`. Gbogbo ìkọ̀sílẹ̀ gbọdọ̀ darúkọ consumer àti ìdánwò arákùnrin tí wọ́n dámọ̀, kí ó fúnni ní ìdí tó ṣe kedere, kí ó sì sopọ̀ mọ́ GitHub issue tàbí pull request kan. Àwọn ìkọ̀sílẹ̀ tí kò bàámu máa ń kùnà sí ipò dídí. Àwọn àyàfi kò lè sin ìdánwò arákùnrin tí wọ́n ti pa rẹ́ mọ́lẹ̀, tàbí diff tó ṣàfikún `.skip`/`.todo`; ìdínkù assertion àti àwọn ìbòjú mìíràn ṣì jẹ́ ti ẹ̀kun `check:test-masking` tó ń dí lọ́wọ́ fúnra rẹ̀.

Ó ń ṣiṣẹ́ lórí gbogbo PR tí ó lọ sí `main`. Ó ń dí ìdàpọ̀ lọ́wọ́ nígbà tí ó bá kùnà.

| `check-translation-ratio`         | Ìwí ìtúmọ̀ tòótọ́ fún locale kọ̀ọ̀kan (àwọn ewé tó jọ ti Gẹ̀ẹ́sì / àyè-dúró (placeholder) / tó sọnù tí ó wà níta àtòkọ ààyè) kò gbọdọ̀ kọjá `config/quality/i18n-translation-baseline.json` + slack | **Ìmọ̀ràn** |

Ó nílò `fetch-depth: 0` — ìlèkun value-drift ń ṣe àfiwé (diff) `en.json` pẹ̀lú ìpilẹ̀ ìdàpọ̀ (merge base).

#### `check-ui-value-drift` — ìlèkun ìtúmọ̀-àtijọ́

Ó ń mu ìpadàsẹ́yìn (regression) i18n kan ṣoṣo tí àwọn ìlèkun míì kò lè rí nípa ìṣọ́nà-ìlànà rẹ̀: a tún iye Gẹ̀ẹ́sì kan kọ, àwọn ìtúmọ̀ tí wọ́n yọ láti inú Gẹ̀ẹ́sì _tẹ́lẹ̀_ sì dúró lẹ́yìn, nítorí náà àwọn olùmúlò tí kò ṣe Gẹ̀ẹ́sì máa ń tẹ̀síwájú kíkà ọ̀rọ̀ tí a kọ pẹ̀lú ìgbẹ́kélé, ṣùgbọ́n tí ó ti yí padà sí àìtọ́ nísìnyí.

Èyí jáde ní tòótọ́. A tún `oauthModal.googleOAuthWarning` kọ nígbà tí olùrànlọ́wọ́ ìwọlé Antigravity wọlé (#5203); **39 lára àwọn locale 43** pa ọ̀rọ̀ náà mọ́ tí ó ń sọ fún àwọn olùṣàkóso pé kí wọ́n "da URL kíkún náà lò, kí wọ́n sì fi lé èyí ní ìsàlẹ̀" — ìṣàn-ìṣe (flow) tí kò lè parí fún olùpèsè yẹn. Kò sí ẹni tí ó ṣàkíyèsí rẹ̀ títí di #8463 nítorí pé:

- `sync-ui-keys` ń ṣe ìkíkpadà (backfill) àwọn kó̀kó̀ tí **kò sí** nìkan, kò kankan fi ẹ̀yìn ti àwọn tí ó ti **dàtijọ́ (stale)**;
- `check-ui-keys-coverage` ń ka _ìwàláyè_ kó̀kó̀, nítorí náà ìtúmọ̀ àtijọ́ ń gba àmì gẹ́gẹ́ bí ẹni tí a bo mọ́lẹ̀;
- `check-translation-drift` ń tẹ̀lé àwọn dígi (mirrors) àkọsílẹ̀ `docs/i18n/<locale>/**.md` — kò ká `src/i18n/messages/*.json` rárá. Ó dí lọ́wọ́ nínú iṣẹ́ `docs-sync-strict` láti ìgbà àtúnṣepọ̀ (re-sync) 2026-09: ṣàtúnṣe doc mọ́lẹ̀ kan → `npm run i18n:run -- --files=<doc>` (ní ìpele abala, kò náwó púpọ̀).

**Ó dá lórí àtìyàtò (diff), kì í ṣe ẹni tí ó dá lórí baseline.** Ó ṣe àfiwéra `en.json` ní merge base pẹ̀lú working tree; fún gbogbo kìkì tí iye Gẹ̀ẹ́sì rẹ̀ yí padà, èyíkéyìí locale tí ó ṣì ní ìtumọ̀ tí wọn kò tíì kàn ti di èyí tó ti kọjá àsìkò. Èyí **dá gbèsè tó wà tẹ́lẹ̀ dúró** ní èròjà — àtìyàtò kò lè fi hàn irú Gẹ̀ẹ́sì àtijọ́ wo tí ìtumọ̀ tó ti pẹ́ ti wá, ní torí náà àwòdíjì (gate) náà ṣe ìdájọ́ nǹkan tí àyípadà lọ́wọ́lọ́wọ́ kan nìkan. Àṣàyàn kejì (baseline hash fún kìkì kọ̀ọ̀kan) yóò gba fáìlì tí wọ́n ṣẹ̀dá tó fẹ̀rẹ̀ to 600 KB — ẹ̀ẹ̀mẹ́ta baseline tó tóbi jùlọ tó wà tẹ́lẹ̀ — tí yóò máa yí padà lórí gbogbo PR i18n.

Ọ̀nà méjì ni ló lè kó ọ́ lọ́kàn:

1. ṣe ìmúdójúìwọ̀n àwọn ìtumọ̀ tí ó kan, tàbí
2. fi wọ́n sílẹ̀ sí `__MISSING__:<new english>` — àkókò ìṣiṣẹ́ yóò máa ń pèsè Gẹ̀ẹ́sì
   tí wọ́n ti ṣe àtúnṣe (`src/i18n/request.ts::deepMergeFallback`, #7258) kí kìkì náà sì wọ inú àtòjọ ìtumọ̀.

Tí **ìtumọ̀** ọ̀rọ̀ náà bá yí padà, **sísọ kìkì náà ní orúkọ tuntun** ni ó dára ju: kìkì tuntun kò lè gba ìtumọ̀ tó ti kọjá àsìkò lẹ́yìn. Òhun ni àpẹẹrẹ tí #8463 lo.

```bash
npm run i18n:check-value-drift          # strict (ohun tí CI ń ṣe)
npm run i18n:check-value-drift:warn     # ìròyìn nìkan
BASE_REF=origin/release/vX.Y.Z npm run i18n:check-value-drift
```

Ó ń jáde pẹ̀lú 0 pẹ̀lú `SKIP reason=base-unresolved` nígbà tí kò ṣe é ka àkójọ ipilẹ̀ (shallow
clone láìsí base ref), ó jọ mọ́ `check-openapi-breaking`.

**Ìpo kóòdù tuntun (Clean-as-You-Code) — láti 2026-08-30, ọ̀nà yíyára PR nìkan**

Lórí àwọn ìṣẹ̀lẹ̀ `pull_request`, `quality.yml` ń fi `--base-ref <PR base SHA>` ránṣẹ́ sí `check:file-size`,
`check:complexity-ratchets` àti `check:dead-code`. Fún `check:complexity-ratchets` àti
`check:dead-code`, ẹnubodè náà ń fi HEAD wé merge-base **ní ààlà àwọn fáìlì tí PR náà fọwọ́ kàn
nìkan** (`scripts/check/newCodeMode.mjs`: a dá merge-base náà sílẹ̀ nínú
`git worktree` àkókò-kúkúrú, ESLint/knip ń ṣiṣẹ́ níbẹ̀ àti lórí HEAD, a sì ń ṣe ìyàtọ̀ àwọn iye fún fáìlì kọ̀ọ̀kan):

- **tí ń dí ìlọsíwájú** — PR náà fi àwọn ìrúfin cyclomatic/cognitive tàbí àwọn export tí kò lò kún àwọn fáìlì tí ó yí padà
  (`complexityNewCode=`, `cognitiveComplexityNewCode=`, `deadExportsNewCode=` nínú àkọsílẹ̀);
- **ìmọ̀ràn** — àpapọ̀ gbogbo rẹ̀ ní ìfiwéra pẹ̀lú ìpìlẹ̀ tí a ti dì mú. Ìyapa tí a jogún kì í sọ
  PR aláìlẹ́bi di pupa; a tún di ìyapa náà mú nígbà ìlaja ìtúsílẹ̀, iṣẹ́ headroom sì ń ṣọ́ ọ.

`check:file-size` ń lo base ref gẹ́gẹ́ bí òfin tirẹ̀ (`scripts/check/check-file-size.mjs`, #8522):
ó ń ṣàyẹ̀wò gbogbo fáìlì source àti test inú tree, ó ń ka iye ìlà fáìlì kọ̀ọ̀kan ní base PR
pẹ̀lú `git show`, ó sì ń mú fáìlì kan kùnà nìkan nígbà tí ó bá dàgbà kọjá èyí tó tóbi jù láàárín ààlà ìpìlẹ̀ rẹ̀
(`frozen` / `testFrozen`, tàbí `cap` / `testCap` fún fáìlì tí kò sí nínú ìpìlẹ̀) àti ìwọ̀n rẹ̀ ní base.
Nítorí náà, fáìlì tí ó ti yapa tẹ́lẹ̀ lórí base kì í sọ PR aláìlẹ́bi di pupa.

`check:boundary:ratchet` ń lo òfin kan náà sí nọ́ńbà ẹyọ rẹ̀
(`scripts/quality/measure-boundary.mjs --ratchet --base-ref <sha>`): lórí àwọn ìṣẹ̀lẹ̀ PR, àwọn
ẹnu-ọ̀nà yíyára `quality.yml` àti iṣẹ́ lint `ci.yml` méjèèjì máa ń fi SHA ìpìlẹ̀ PR ránṣẹ́, a máa
ń díwọ̀n commit ìpìlẹ̀ láti inú export `git archive`, PR náà sì máa kùnà nìkan nígbà tí iye edge
`open-sse → src` rẹ̀ bá ju èyí tó tóbi jù láàárín `metrics.boundaryOpenSseToSrc` àti iye tó wà lórí ìpìlẹ̀ lọ. A máa ń
jábọ̀ ìyípadà ìpìlẹ̀ tó ga ju òpin lọ (`base drift herdado`), ṣùgbọ́n kò jẹ́ kí PR aláìṣẹ̀ di pupa láé; push → main
ń pa òpin gígùn mọ́, SHA ìpìlẹ̀ tí kò ṣeé yanjú sì máa padà sí i pẹ̀lú ìkìlọ̀.

Àwọn ìṣiṣẹ́ `workflow_dispatch`, àyẹ̀wò release-green àti iṣẹ́ headroom alẹ́ kò ní ìpìlẹ̀ PR
wọ́n sì ń pa ìfiwéra gígùn (àgbáyé) mọ́. Coverage, duplication àti type-coverage ṣì jẹ́ ti àgbáyé
fún báyìí (àwọn irinṣẹ́ wọn kò lè ṣe diff fáìlì-kọ̀ọ̀kan lọ́nà tí kò gbówó púpọ̀) — wọ́n jẹ́ olùdíje fún ìtọ́jú kan náà.

**Pípa ìpele náà dé ní v4.0 (LTS = ó le koko ju ti tẹ́lẹ̀ lọ, kì í ṣe "padà sí bó ṣe máa ń rí")**

1. Lórí tip mímọ́ `release/v4.0.0`: `npm run quality:headroom --json` fún àkọsílẹ̀, lẹ́yìn náà
   `npm run quality:ratchet -- --update`, `check:file-size --update`,
   `check:complexity-ratchets --update`, `check:dead-code --update`, àti `--update` fún ẹnu-ọ̀nà typecheck kọ̀ọ̀kan — gbogbo baseline máa ń sọ̀kalẹ̀ sí iye tí a díwọ̀n.
2. Pa `_policy` rẹ́ kúrò nínú `quality-baseline.json` (ó tún `--require-tighten` àti ìfipamọ́
   alẹ́ mú ṣiṣẹ́), dá `THRESHOLD = 36` (tàbí tó ga jù bẹ́ẹ̀ lọ) padà sínú `check-openapi-coverage.mjs`.
3. Mú àwọn òpin le ju iye tí a díwọ̀n lọ níbi tí modularization ti ṣàǹfààní: dá `cap` file-size padà sí 1000
   (tàbí 800), fi 5 kún àwọn òkè-ilẹ̀ coverage, dead exports 0 fún àwọn package tí a ṣe modularization sí.

## Ìpìlẹ̀ Ratchet (`quality-baseline.json`)

Ẹ́ńjìnnì ratchet (`scripts/quality/check-quality-ratchet.mjs`) máa ń ka `quality-baseline.json`
ó sì máa ń fi wé `quality-metrics.json` tí a ṣẹ̀ṣẹ̀ kó jọ. Mẹ́tríìkì èyíkéyìí tí ó bá fà sẹ́yìn
kọjá epsilon rẹ̀ yóò mú kí build náà kùnà.

Àwọn mẹ́tríìkì tí a ń tọpinpin lọ́wọ́lọ́wọ́:

| Mẹ́tríìkì              | Ìtọ́sọ́nà | Ìtumọ̀                             |
| --------------------- | ------- | --------------------------------- |
| `eslintWarnings`      | `down`  | Iye ìkìlọ̀ ESLint kò gbọ́dọ̀ pọ̀ sí i |
| `coverage.statements` | `up`    | Ìbora gbólóhùn kò gbọ́dọ̀ dín kù    |
| `coverage.lines`      | `up`    | Ìbora ìlà kò gbọ́dọ̀ dín kù         |
| `coverage.functions`  | `up`    | Ìbora iṣẹ́ kò gbọ́dọ̀ dín kù         |
| `coverage.branches`   | `up`    | Ìbora ẹ̀ka kò gbọ́dọ̀ dín kù         |

Láti ṣe ìmúdójúìwọ̀n ìpìlẹ̀ lẹ́yìn ìlọsíwájú gidi kan:

```bash
npm run quality:ratchet -- --update
git add quality-baseline.json
```

Àmì `--update` máa ń kọ àwọn iye tí a wọ̀n lọ́wọ́lọ́wọ́ sínú `quality-baseline.json`.
Ṣe commit fáìlì yìí papọ̀ pẹ̀lú àyípadà tí ó mú mẹ́tríìkì náà sunwọ̀n sí i. PR tí ó mú
mẹ́tríìkì kan sunwọ̀n sí i láì ṣe ìmúdójúìwọ̀n ìpìlẹ̀ náà ni `--require-tighten` yóò rí
(Ìpele 6A.5, ìmúṣẹ rẹ̀ ṣì ń dúró).

### Ratchet CodeQL: àkókò ìtúnṣe àti ohun ìmúṣiṣẹ́ ọlọ́wọ́

`check:codeql-ratchet` máa ń ka **ipò repo, tí a ń sọ di tuntun gẹ́gẹ́ bí àkókò tí a ṣètò — kì í ṣe fún PR kọ̀ọ̀kan.**
`gh api repos/diegosouzapw/OmniRoute/code-scanning/default-setup` máa ń fi
`state: configured`, `schedule: weekly` hàn: ìṣàyẹ̀wò default-setup ti GitHub ni, kì í ṣe ìtúpalẹ̀
fún push kọ̀ọ̀kan. Àbájáde rẹ̀ ni pé: lẹ́yìn tí PR kan tí ó ṢÀTÚNṢE àwọn ìkìlọ̀ bá ti merge, ratchet náà ṣì máa ń ka
iye àtijọ́ tí ó ga jù títí ìṣàyẹ̀wò tí a ṣètò tókàn yóò fi ṣiṣẹ́ — nítorí náà, ó máa ń jabo ìfàsẹ́yìn
lórí gbogbo PR tí ó ṣí sílẹ̀, títí kan àwọn àtẹ̀lé PR tó ṣàtúnṣe náà fúnra rẹ̀, títí tí ìṣàyẹ̀wò yóò fi dé ipò tuntun.

**Ìtúnṣe ọlọ́wọ́**: `gh workflow run codeql.yml --ref release/vX.Y.Z` máa tún
ìtúpalẹ̀ náà ṣiṣẹ́, yóò sì tún tẹ àwọn ìkìlọ̀ jáde láàárín ìṣẹ́jú díẹ̀. Ka `.github/workflows/codeql.yml`
kọ́kọ́ — àkọlé rẹ̀ ṣàlàyé pé `workflow_dispatch` nìkan ni **nítorí pé ó tako
"default setup" ti GitHub** (`CodeQL analyses from advanced configurations cannot be
processed when the default setup is enabled`). Mímú àwọn ìmúṣiṣẹ́ `push`/`pull_request`/
`schedule` padà nílò **ìgbésẹ̀ láti ọ̀dọ̀ owner kọ́kọ́**: Settings → Code security →
CodeQL: Default → Advanced. Má ṣe fi ìmúṣiṣẹ́ `schedule:` kún un láì ṣe ìyípadà yẹn — ó
máa mú àwọn ìṣiṣẹ́ tí yóò kùnà jáde nìkan.

**Mú ìpìlẹ̀ náà le lẹ́yìn tí iye náà bá dín kù** — `node scripts/check/check-codeql-ratchet.mjs
--update` máa ń kọ iye tuntun tí a wọ̀n sínú `quality-baseline.json` →
`metrics.codeqlAlerts.value`, kí ratchet má bàa gba ìfàsẹ́yìn padà sí
ààlà àtijọ́ láì sọ. Àpẹẹrẹ tí a ti ṣe (2026-09-02/03): PR #12502 ṣàtúnṣe ìkìlọ̀ gidi 7
(13 → 6 tí a wọ̀n pé ó ṣí sílẹ̀); PR #12530 mú ìpìlẹ̀ tí a dì mú le láti 11 → 6 láti bá a mu; lẹ́yìn náà,
a kọ àwọn 6 tó kù sílẹ̀ pẹ̀lú ìdáláre fún ìkìlọ̀ kọ̀ọ̀kan títí iye tó ṣí sílẹ̀ fi di 0.

**Kíkọ ìkìlọ̀ sílẹ̀ jẹ́ ìpinnu operator (Òfin Líle #14)** — má ṣe kọ ìkìlọ̀ CodeQL kan
sílẹ̀ láì kọ ìdáláre ìmọ̀-ẹ̀rọ sínú àsọyé ìkọ̀sílẹ̀ náà: `won't fix` fún
ohun tí upstream-protocol béèrè, `used in tests` fún test fixture, `false positive`
fún sanitizer tí CodeQL kò lè rí (àpẹẹrẹ tẹ́lẹ̀: `docs/security/ERROR_SANITIZATION.md`).

## Fífipamọ́ Àwọn Ìdínkù Ratchet — ọ̀nà sísàlẹ̀ (#8584)

Ratchet náà jẹ́ aládàáṣe ní ìdajì nìkan, ìdajì tí kò tọ́ sì ni. **Gígbé** cap kan sókè jẹ́
àtúnṣe JSON ọwọ́ tí ó gba ìṣẹ́jú-àáyá mẹ́wàá, tó sì jẹ́ ọ̀nà tó yára jù láti ṣí PR pupa sílẹ̀.
**Sísọ** ọ̀kan kalẹ̀ nílò kí ẹnìkan ṣiṣẹ́ `--update` kí ó sì commit àbájáde náà — títí di ìgbà tí
job `bank-ratchet-shrinks` dé, kò sí workflow kankan tó ń ṣiṣẹ́ ẹ. Àbájáde tí a wọn
(2026-07-25): àwọn fáìlì frozen 18 ti wà ní tàbí lábẹ́ cap ila 800 fún fáìlì tuntun, èyí tó burú jù
wà ní 132× (`src/shared/validation/schemas.ts`, ila 19 tí ó ru cap 2,523); òrùlé
complexity rìn láti `1794 → 2169` kọjá àwọn àkọsílẹ̀ rebaseline bíi ~37 pẹ̀lú ìdínkù kan ṣoṣo
(−1); a sì kọ “mú un le sí i nípasẹ̀ `--update` ní cycle tó kàn” ní ìgbà 31, tí a sì ṣe é
lẹ́ẹ̀kan ṣoṣo. Cap kan tí ó pé ju kóòdù tó mú un wá lọ máa ń sọ gbogbo decomposition tí a ti parí
di ààyè ìdàgbàsókè fún ẹnikẹ́ni tó bá tún fáìlì náà ṣe lẹ́yìn náà, láìsí ariwo.

`nightly-release-green.yml` → job **`bank-ratchet-shrinks`** ń pa àyípo yẹn mọ́:

|            |                                                                                                              |
| ---------- | ------------------------------------------------------------------------------------------------------------ |
| Ṣiṣẹ́ lórí  | `schedule` (3×/ọjọ́) + `workflow_dispatch` — pẹ̀lú ìmọ̀ọ́mọ̀ **kì í ṣe** `push`                                   |
| Ń wọn      | `release/vX.Y.Z` tó ga jù, resolution kan náà + injection guard bí `release-green`                           |
| Ń kọ       | `check:file-size --update` àti `check:complexity-ratchets --update` (a kọ́ méjèèjì láti dín kù nìkan)         |
| Ń ṣàyẹ̀wò   | `npm run check:ratchet-bank` (`scripts/quality/verify-ratchet-bank.mjs`)                                     |
| Ń fi ránṣẹ́ | PR kan tí ó jẹ́ ti ìsinsìnyí nígbà gbogbo sí release branch — a máa ń ṣe force-update rẹ̀, a kì í fi í ṣe spam |

A ń ṣe fífipamọ́ náà ní àkójọpọ̀ dípò fún push kọ̀ọ̀kan nítorí kò ní ìbéèrè latency kankan (ìdínkù tí a
fi pamọ́ láàárín 8h dára) nígbà tí iṣẹ́ kan fún merge kọ̀ọ̀kan yóò tún PR branch kọ́ léraléra
lákòókò àwọn ìpolongo merge, yóò sì san owó fún ESLint walk kíkún ní gbogbo ìgbà. Ìṣàwárí ṣì wà lórí
push (`release-green`); fífipamọ́ nìkan ni a ń ṣe ní àkójọpọ̀.

### Olùṣàyẹ̀wò ààbò

Job náà ń kọ sínú àwọn baseline láìsí àbójútó, nítorí náà `verify-ratchet-bank.mjs` ni ohun tó mú
èyí ṣeé tẹ́wọ́ gbà. Ó ń ṣe diff igi lẹ́yìn `--update` pẹ̀lú `HEAD`, ó sì **dá job náà dúró
kí commit kankan tó wà** — láì ṣí PR kankan — àyàfi tí gbogbo ìyípadà bá jẹ́ ọ̀kan nínú:

- entry onínọ́mbà `frozen` / `testFrozen` tí a **dín kù** tàbí **yọ kúrò**
- `complexity-baseline.json` → `count` tí a **dín kù**
- `quality-baseline.json` → `metrics.cognitiveComplexity.value` tí a **dín kù**

Ohunkóhun mìíràn yóò kùnà: gbígbé nọ́ńbà kan sókè, fífi entry kan kún un, yíyí `cap`/`testCap` padà, tàbí
píparẹ́/àtúnkọ àkọsílẹ̀ `_rebaseline_*` kan (àwọn àkọsílẹ̀ wọ̀nyẹn ni ipa-ọ̀nà audit tó ṣàlàyé ìdí tí
òrùlé kọ̀ọ̀kan fi wà, a sì tọ́jú wọn sínú object `frozen` kan náà pẹ̀lú àwọn entry fáìlì).
Bot kan tó lè gbé cap sókè yóò burú ju ipò tó wà lọ dájúdájú. Regression
guard: `tests/unit/verify-ratchet-bank.test.ts`.

Job náà kì í push sí `release/*` láéláé — ènìyàn kan ló máa merge PR náà, nítorí náà ìwọ̀n búburú
kò lè wọlé láìsí àyẹ̀wò.

## Ìlànà Àtòjọ Ìyọ̀ǹda

Gbogbo ẹnu-ọ̀nà àyẹ̀wò tí kò lè kùnà nítorí àwọn ìrúfin tó ti wà tẹ́lẹ̀ máa ń lo àtòjọ ìyọ̀ǹda tí a ti dí múlẹ̀
(fún àpẹẹrẹ, `KNOWN_STALE_DOC_REFS`, `KNOWN_MISSING`, `KNOWN_RAW_SQL`). Ìlànà náà ni:

**Ṣàtúnṣe ìdí pàtàkì tó fa ìṣòro náà; lo àtòjọ ìyọ̀ǹda nìkan nígbà tí ìrúfin náà ti wà tẹ́lẹ̀ tí
kò sì ṣeé ṣàtúnṣe nínú PR kan náà.**

Nígbà tí o bá ń ṣàfikún àkọsílẹ̀ sí àtòjọ ìyọ̀ǹda:

1. Fi àlàyé sínú comment kan nípa ìdí rẹ̀.
2. Tọ́ka sí issue tí ń tọpinpin rẹ̀ (fún àpẹẹrẹ, `// #3498 — Phase 2 feature, not yet implemented`).
3. Yọ àkọsílẹ̀ náà kúrò nínú PR kan náà tó ṣàtúnṣe ìrúfin náà — àkọsílẹ̀ àtijọ́ tí kò tún
   ń fi ìrúfin tó ṣì ń ṣiṣẹ́ pamọ́ jẹ́ àbùkù fúnra rẹ̀ (ìmúlò stale-enforcement 6A.3 yóò
   mú kí ẹnu-ọ̀nà àyẹ̀wò kùnà lórí àkọsílẹ̀ àtòjọ ìyọ̀ǹda tí kò ní ìbáṣepọ̀ mọ́ nígbà tí a bá ti ṣàmúlò rẹ̀).

**Má ṣe** ṣàfikún àwọn àkọsílẹ̀ àtòjọ ìyọ̀ǹda láti mú kí àwọn ìdánwò kọjá ní kíákíá. Ẹnu-ọ̀nà àyẹ̀wò aláwọ̀ ewé pẹ̀lú
àtòjọ ìyọ̀ǹda tó ń pọ̀ sí i ń fúnni ní ìmọ̀lára èké nípa dídára.

### Nígbà tí ẹnu-ọ̀nà àyẹ̀wò kan bá kùnà lórí PR rẹ

1. **Ka àbájáde ẹnu-ọ̀nà àyẹ̀wò náà dáadáa** — ó máa sọ fáìlì tàbí àmì wo gan-an ló rú
   òfin náà fún ọ.
2. **Ṣàtúnṣe ìrúfin náà** — ọ̀pọ̀ àwọn ẹnu-ọ̀nà àyẹ̀wò jẹ́ àyẹ̀wò ètò-fáìlì tó ń fúnni ní àbájáde kan náà ní gbogbo ìgbà, tí yóò sì kọjá ní kété
   tí kóòdù náà bá tọ̀nà.
3. **Tí ìrúfin náà bá ti wà tẹ́lẹ̀** (ìyẹn ni pé, kì í ṣe ìwọ ló dá a sílẹ̀ ṣùgbọ́n ẹnu-ọ̀nà àyẹ̀wò náà ti
   bẹ̀rẹ̀ sí í bo ó): ṣàfikún àkọsílẹ̀ àtòjọ ìyọ̀ǹda pẹ̀lú comment ìdáláre àti issue ìtọpinpin.
4. **Tí ẹnu-ọ̀nà àyẹ̀wò náà bá jẹ́ ratchet** (coverage, àwọn ìkìlọ̀ ESLint, àtúnṣe, complexity):
   ìyípadà rẹ mú kí òṣùwọ̀n náà burú sí i. Ṣàtúnṣe ìṣòro tó fa á, tàbí (nígbà díẹ̀ gan-an) ṣiṣẹ́
   `npm run quality:ratchet -- --update` tí ìyípadà náà bá jẹ́ àmọ̀ọ́mọ̀ tí ìdínkù nínú òṣùwọ̀n náà
   sì jẹ́ ìtẹ́wọ́gbà — ṣùgbọ́n ṣàkọsílẹ̀ ìdí rẹ̀ sínú àpèjúwe PR.
5. **Àwọn ẹnu-ọ̀nà àyẹ̀wò ìmọ̀ràn** (`continue-on-error: true`) wà fún fífúnni ní ìsọfúnni — wọn kì í dí
   ìdapọ̀ dúró ṣùgbọ́n wọ́n máa hàn nínú àkótán CI. Ṣàtúnṣe wọn síbẹ̀.

## Irinṣẹ́ aṣojú: LSP-in-the-loop (àyàn-kíkópa)
