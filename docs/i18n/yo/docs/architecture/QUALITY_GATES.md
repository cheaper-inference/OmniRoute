## Oja ẹnu-bode ati awọn profaili ipaniyan

### Gbigba oludije

CI ati Didara Gates workflows kọọkan gbejade idajo iduroṣinṣin: `Gate / CI` ati `Gate / Quality`. Eto imulo gbigba wọn ti ikede ṣe iṣiro gbogbo iṣẹ oke bi o ṣe nilo tabi imọran. Iṣẹ ti o nilo gbọdọ ṣaṣeyọri: sonu, fagilee, fo, isunmọtosi ati awọn abajade aimọ ko le fi idi PASS mulẹ. Awọn iwe aṣẹ ti o wulo-nikan tabi katalogi-sọtọ le jẹ ki ọna koodu ko wulo; apẹrẹ lasan PR kii ṣe oludije ti o gba. Aami `hotfix` kan ko yọ ẹri kuro.

Awọn ṣiṣan iṣẹ mejeeji bo PRs sinu awọn ẹka main/release, titari si `main`, fifiranṣẹ afọwọṣe ati awọn iṣẹlẹ akojọpọ-ẹgbẹ. Titari, firanṣẹ ati dapọ-ẹgbẹ ṣiṣe aṣayan ni kikun. Akọsilẹ ti isinyi Mergify ti o gbẹkẹle tun nṣiṣẹ awọn iṣẹ `full-code`/`full-code-e2e` to wulo; arinrin PRs foo wọn. Ṣaaju iṣọpọ afọwọṣe kan, ṣiṣe fifiranṣẹ ni kikun lori oludije gangan. Titari si `release/**` ko bẹrẹ awọn iṣan-iṣẹ wọnyi; Tu-Alawọ ewe n ṣakiyesi ipilẹ ti o dapọ lọtọ (Ọna ti gbalejo `docs/ops/RUNNER_BOX.md` → ). Awọn orita ati awọn ẹgbẹ dapọ lo awọn asare ti a ti gbalejo fun awọn iṣẹ ti bibẹẹkọ yan awọn asare ti ara ẹni; Agbara gbigbalejo ti o to gbọdọ jẹ ijẹrisi ṣaaju yiyi.

Arinrin PR nṣiṣẹ awọn sare aṣayan. Awọn ọna `full-code` ati `full-code-e2e` ti eto imulo gbigba (E2E, iṣọkan, artifact package, Electron èéfín, Bun SQLite, ilolupo eda abemi ati awọn onibara ilana) ṣiṣe nikan lori Mergify queue draft tabi lori kikun: `gh workflow run ci.yml --ref <branch>`.

Iwe-ẹri JSON kọọkan n ṣe idanimọ SHA ti a ṣayẹwo, ṣiṣe ṣiṣiṣẹ ati igbiyanju. CLI naa kọ aiṣedeede checkout/event SHA kan. Awọn idanwo ṣiṣiṣẹsẹsẹ di ọmọ ẹgbẹ eto imulo si atokọ `needs` iṣẹ idajọ nitori ọna tuntun tabi yiyọ kuro ko le parẹ ni idakẹjẹ. Awọn owo-owo naa bo ṣiṣan iṣẹ tiwọn, kii ṣe titẹjade, imuṣiṣẹ, tabi awọn inu inu ẹrọ aṣayẹwo imọran ti o wa tẹlẹ. Ṣiṣe awọn sọwedowo to wulo ti o nilo ni awọn ofin ẹka jẹ iyipada iṣakoso lọtọ; asọye awọn iṣẹ wọn ko daabobo ẹka kan funrararẹ.

`API Route Typecheck` jẹ ayẹwo iṣan-iṣẹ ominira ti ominira, ni ita awọn idajọ apapọ apapọ ati profaili aimi oluwoye ni kikun agbegbe. Ṣayẹwo abajade rẹ lọtọ fun oludije gangan. `.github/workflows/api-route-typecheck.yml` nṣiṣẹ lori PRs sinu `main` tabi `release/**`, titari si boya ẹka ẹbi, fifiranṣẹ afọwọṣe, ati awọn iṣẹlẹ `merge_group` ti iru `checks_requested`. Ko ni àlẹmọ ọna. Dapọ awọn ẹgbẹ ṣayẹwo jade `merge_group.head_sha`; awọn iṣẹlẹ miiran ṣayẹwo jade `github.sha`. Gbogbo awọn iṣẹlẹ lo ẹnu-ọna iwadii API kanna ati awọn idanwo ẹyọ ẹnu-ọna. Awọn atunbere ipilẹ PR beere ayẹwo tuntun; Awọn atunṣe body/title lo orukọ akiyesi-nikan `Admission not requested / API Route Typecheck` ati pe ko le rọpo ayẹwo gbigba.

### Ẹri ti o ni idaduro ni idinku gbigba

`scripts/quality/validate-release-acceptance.mjs` dinku eto ti a pese ati awọn ifihan rẹ; ko ṣe fi idi rẹ mulẹ pe ero naa ni wiwa opo gigun ti itusilẹ pipe. Awọn ijabọ rẹ ṣeto `releaseAcceptance: false` ni gbangba, paapaa nigba ti ero yẹn jẹ `VERIFIED`. Ṣiṣan iṣẹ `release-acceptance.yml` tun nlo awọn imuduro ojiji, kii ṣe itumọ gidi, package, bata tabi awọn owo igbega.

CLI naa nilo `--evidence-root` lati jẹrisi ẹri ti o daduro. Awọn faili ti wa ni ipinnu bi `<evidence-root>/<artifact_id>/<member>` ati hashed bi SHA-256. Igbasilẹ PASS laisi ẹri, sonu tabi faili ti o yipada, ọna ti ko lewu tabi aami-ami kan ṣe idilọwọ ijẹrisi. Awọn faili ti o nsọnu ko ṣe deede si awọn akọọlẹ aṣeyọri ofo. Awọn sọwedowo SHA/run/attempt ti o wa tẹlẹ wa ni ominira: awọn baiti ti o baamu ko le gba iwe-ẹri ti o duro duro. Iduroṣinṣin fáìlì kii ṣe ẹ̀rí ìfójútó ipaniyan tabi igbega artifact.

### DAST n gba idaniloju CI kọ

Iṣẹ `dast-smoke` CI ti a beere pe `.github/workflows/dast-smoke.yml` lẹhin `build`. O tẹle yiyan code/draft kanna bi kikọ, pẹlu atilẹyin PRs orita, Tu-afojusun PRs ati awọn ẹgbẹ dapọ. Sonu, kuna, fagile tabi lairotẹlẹ fo DAST iṣẹ awọn bulọọki `Gate / CI`. Ṣiṣan iṣẹ atunṣe ko ni ominira PR/dispatch okunfa; Ifọwọsi afọwọṣe nlo fifiranṣẹ CI nitori kikọ ati alabara wa ni ṣiṣe kan.

`scripts/ci/next-build-provenance.mjs` edidi ni kikun Next artifact pẹlu awọn oniwe-tar digest, repository/event/run, olupilẹṣẹ igbiyanju, head/base/checkout/tree, bisesenlo idamo, lockfile, gangan Node version/ABI, Syeed ati bundler. DAST yan ID artifact ti ko yipada lati `needs.build.outputs`, nilo ijẹrisi daijesti igbasilẹ, ati ni ominira hashes ZIP lodi si iṣelọpọ iṣelọpọ ṣaaju yiyọ awọn ọmọ ẹgbẹ meji ti a gba laaye nipasẹ `scripts/ci/unpack-ci-build.py`. Afihan ati ibi ipamọ tar gbọdọ tun baamu awọn abajade iṣelọpọ ominira ṣaaju ki o to yọ igi Next jade. Ko ṣe wiwa fun kikọ ile-iṣẹ aṣeyọri tuntun. Atunse apa kan le tun lo igbiyanju olupilẹṣẹ kanna nigbati ID rẹ ati gbogbo awọn igbewọle tun baamu; iwe-ẹri gba awọn igbiyanju mejeeji.

Onibara duro lori olusare Linux ti o gbalejo pẹlu igbanilaaye ibi ipamọ kika-nikan ko si si awọn aṣiri ibi ipamọ. O nfi ẹya Node gangan ti olupilẹṣẹ sori ẹrọ, lẹhinna ṣajọ CLI pẹlu `OMNIROUTE_REQUIRE_PREBUILT_NEXT=1`. `scripts/build/standaloneInput.mjs` kọ olupin adaduro ti o padanu ṣaaju kikole eyikeyi; deede agbegbe CLI kọ idaduro wọn tẹlẹ fallback. Imurasilẹ olupin, Iṣeto-ọrọ ati kiakiafoo gbọdọ ṣaṣeyọri gbogbo laarin opin iṣẹ iṣẹju 25 ti ko yipada. Iwe-ẹri ijẹrisi jẹri idanimọ titẹ sii ati awọn baiti, kii ṣe ọlọjẹ DAST aṣeyọri. Ipari Artifact, idalọwọduro olusare tabi ọlọjẹ ti o kuna si wa pe tabi ẹri ti kuna; ko le di PASS nipasẹ ohun murasilẹ imọran.

### UI ipaniyan agbara

CI nṣiṣẹ ni kikun UI oja bi mẹrin `test-vitest` matrix shards, kọọkan pẹlu ni julọ meji osise fun shard ati awọn ti wa tẹlẹ 15-iseju iseju ipari. Shard akọkọ tun nṣiṣẹ MCP/autoCombo Vitest suite. Abajade iṣẹ ti o nilo ni wiwa gbogbo ẹsẹ matrix; ikuna tabi ifagile ti shard kan ko le fi idi igbasilẹ oludije mulẹ.

Oluwoye alẹ ṣe idaduro iwe-ẹri oludije gangan lọtọ fun shard UI kọọkan, pẹlu ipaniyan MCP ni gbigba akọkọ. Gbogbo awọn iwe-ẹri mẹrin, awọn akọọlẹ ati awọn idamọ ipaniyan ti o baamu ni a nilo. Agbegbe `npm run test:vitest:ui` tun yan pipe suite; ọkan `--shard` run jẹ nikan apa kan eri.

### Akojọpọ agbegbe kuro

Awọn shards ẹyọ mejila gba agbegbe V8 lakoko ipaniyan idanwo ti o wa tẹlẹ. Shard aṣeyọri nṣiṣẹ `scripts/ci/compact-v8-coverage.mjs` lati funmorawon awọn faili atilẹba laisi ipilẹṣẹ ijabọ agbedemeji Istanbul kan. Ipari Iṣẹ Ibori ṣe idaniloju gbogbo awọn ifihan mejila si oludije SHA, akoko asiko, gbongbo orisun ati hashes data, lẹhinna ṣiṣe awọn oniroyin c8 ati awọn iloro agbegbe ti o wa tẹlẹ. Awọn igbewọle ṣe idaduro aṣẹ orukọ faili agbaye c8; iṣaju iṣaju-shard ko lewu fun agbegbe function/block ti o dapọ. Sonu, aiṣedeede tabi awọn shards ti ko ni ibamu kuna gbigba wọle. Awọn shards idanwo ti o kuna ni idaduro agbegbe iwadii aise lọtọ; ko le wọ inu akojọpọ ikẹhin.

### Awọn sisanwo ilọsiwaju ipaniyan kuro

Aṣẹ `test:unit:ci:shard` ti o pin ṣe igbasilẹ awọn ipele `primary`, `dashboard` ati `serial` nipasẹ `scripts/ci/unit-progress-reporter.mjs`. Iroyin idanwo deede wa. Iwe-ẹri metadata-nikan ti o yatọ ṣe igbasilẹ ibẹrẹ ati ipari faili kọọkan, ati lilu ọkan iṣẹju-aaya 30 kan ṣe atokọ awọn faili ṣi ṣiṣẹ ati akoko ti o ti kọja. O ṣe igbasilẹ awọn metadata ipaniyan ti a gba laaye nikan; igbeyewo awọn apejuwe, o wu, aṣiṣe ara ati awọn kikun ayika ti wa ni ko serialized.

CI ṣe idaduro awọn faili JSONL bi `unit-progress-ci-<run>-<attempt>-<shard>`. Aago akoko iṣẹ le ṣe idiwọ ikojọpọ nigbamii; awọn lilu ọkan ti jade tẹlẹ jẹ ẹri iwadii aisan. Awọn lilu ọkan ti o padanu tun le ṣe afihan ilana ti dina tabi ti pari. Awọn owo-owo wọnyi ṣe itọju yiyan idanwo ti o wa, concurrency, awọn akoko ipari ati ipo ijade; wọn kii ṣe awọn idajọ gbigba oludije.

### Àkópọ̀ isinyi

Aami `queue` nfi PR ranṣẹ si isinyi Mergify (`.mergify.yml`). Mergify ṣii PR osere kan lori ẹka `mergify/merge-queue/`, CI nṣiṣẹ ni kikun aṣayan nibẹ, ati pe PR atilẹba dapọ nigbati `Gate / CI`, `Gate / Quality` ati `Merge integrity (changelog + generated skills)` kọja.

Mergify kọ akopọ isinyin rẹ sinu apejuwe osere naa. Awọn iṣẹlẹ Body/title-only `pull_request` `edited` lo ẹgbẹ isọsọ kan pato ati pe ko tun ṣe isọdi, awọn matiri idanwo, iṣotitọ apapọ tabi idajo gbigba. Awọn orukọ ayẹwo akiyesi-nikan ko le rọpo `Gate / CI` tabi `Gate / Quality`. Ṣatunkọ ti o yipada ipilẹ ibi-afẹde n beere ijẹrisi oludije tuntun.

Lẹhin ti a dequeue, titari ko ni nigbagbogbo beere awọn PR. Ọrọìwòye `@mergifyio queue` lori rẹ.

### Iṣiro ọlọjẹ aimi

Oja ọja npm-alias ti ikede ati awọn ọmọ ẹgbẹ ọlọjẹ-imi laaye ni `config/quality/gate-manifest.json`. Ṣiṣe `npm run check:gate-manifest` lati fọwọsi awọn orukọ iwe afọwọkọ ati awọn aṣẹ gangan lodi si `package.json`; awọn afikun, yiyọ kuro ati fiseete aṣẹ kuna mejeeji kio agbegbe ati awọn iṣẹ isọdi-iyipada ni CI. Inagijẹ kii ṣe iṣẹ iṣan-iṣẹ, apẹẹrẹ matrix tabi ọran idanwo: awọn iṣiro wọnyi ko gbọdọ gbekalẹ bi paarọ.

Lo `npm run quality:scan -- --list` tabi `npm run quality:scan:fast -- --list` lati ṣayẹwo awọn inagijẹ ti o yan laisi ṣiṣe wọn. Isare n pe aaye titẹsi npm, nitorinaa akoko asiko rẹ (pẹlu Bun nibiti a ti tunto) ti wa ni ipamọ. Awọn igbasilẹ ti o farahan ni ita awọn profaili wọnyẹn bi a ti pe ni lọtọ, ati pe awọn aṣẹ itọju jẹ eewọ ni awọn profaili ọlọjẹ kika-nikan.

Awọn profaili wọnyi bo ọlọjẹ aimi nikan. Wọn ko jẹri awọn idanwo ọja, agbegbe, apoti, awọn sọwedowo ita tabi gbigba idasilẹ ni kikun ti oludije. Gbigbawọle ṣiṣan iṣẹ nlo `config/quality/admission-policy.json` ti o sopọ ati `scripts/quality/admission-verdict.mjs`. Awọn profaili oluwoye itusilẹ wa lọtọ; ṣayẹwo awọn sọwedowo ti o wulo ati awọn iwe-ẹri ni ominira. Awọn aṣẹ aimi Oluwoye ni kikun ni a kede ni `config/quality/release-green-static-profile.json`, pẹlu `audit:deps`, yiyan-idanwo iyipada ati awọn sọwedowo itumọ. Agberu naa fọwọsi awọn aṣẹ npm lodi si package.json ati awọn ikede CI/Quality ti a ṣe awoṣe; o kọ fiseete dipo ti ṣiṣe awọn aami ikarahun bi awọn ariyanjiyan. Ti beere ọlọjẹ SKIP/INCOMPLETE iṣelọpọ ko le fi idi PASS mulẹ. Profaili naa ṣe igbasilẹ awọn imukuro ita ati pe ko rọpo agbegbe ti o gbalejo, awọn matiri idanwo, package tabi ẹri imuṣiṣẹ. Oja prose ti o wa ni isalẹ jẹ itọkasi, kii ṣe ẹri pe ẹnu-bode kan nṣiṣẹ gangan.

Awọn iwe afọwọkọ n gbe labẹ `scripts/check/` (awọn ẹnubode eto imulo) ati `scripts/quality/` (engine ratchet). Orisun otitọ CI ni `.github/workflows/ci.yml`.

### Atejade-mimọ ilera iwe aṣẹ

`.github/workflows/i18n-base-health.yml` ṣe akiyesi ilera iwe lẹhin titari ti o yan si `main` ati `release/v*`, ati lori fifiranṣẹ afọwọṣe. Ajọ rẹ awọn iwe ideri, root Markdown, `llm.txt`, itumọ state/configuration ati ohun elo i18n ti o yẹ. Iṣẹ `Published base documentation health` ẹyọkan lo Ubuntu ti gbalejo ati akoko ipari iṣẹju marun. O ṣe afọwọsi kika-nikan ati kọ iwe-ẹri iwadii laisi fifi sori ẹrọ igbẹkẹle, itumọ tabi isọdọmọ ipinlẹ.

`scripts/i18n/check-base-health.mjs` nbeere odo-hash orisun, sonu-afojusun, ibi-afẹde-hash, stale-itumọ ati awọn aiṣedeede kaṣe apakan. O tun fọwọsi aaye document/locale mojuto lọwọlọwọ ati ẹri ti o gbasilẹ. Ọrọ aiṣedeede, agbegbe ti ko pe tabi oluṣayẹwo idilọwọ mu `INCOMPLETE` jade; fiseete ti a fọwọsi gbejade `FAIL`. Mejeeji pada ipo ijade ti o kuna. Iwe-ẹri naa ni owun lati ṣayẹwo SHA, ṣiṣiṣẹsẹhin, ṣiṣe ati igbiyanju, ati pe o wa ni idaduro bi `i18n-base-health-<sha>-<run>-<attempt>`.

Eyi jẹ akiyesi ominira ti ipilẹ ti a tẹjade. Ko ṣe afikun PR tabi iṣẹlẹ akojọpọ-ẹgbẹ, ṣayẹwo PR ti o nilo, inagijẹ npm tabi ọmọ ẹgbẹ profaili ọlọjẹ-imi. Oluyẹwo ti o wa labẹ tun ṣe idiwọ gbogbo awọn kilasi marun ni ipo pipe. Arinrin igbaradi PR si maa wa lọtọ lati gbigba. Igbesoke aṣeyọri ko le yi abajade ilera ti o kuna sinu PASS.

PR lasan nlo `--preflight` pẹlu ijabọ ipilẹ ti ipilẹṣẹ nipasẹ `--baseline-evidence`. O le fi orisun Gẹẹsi silẹ ni isunmọ nikan nigbati igbasilẹ itumọ pipe ati awọn baiti ibi-afẹde gangan ko yipada lati ipilẹ gangan yẹn. Ibi-afẹde tuntun tabi awọn aiṣedeede kaṣe apakan ṣi dina, ati pe ẹri ti ko pe ko le fun ni aṣẹ igbaradi. Ijabọ naa ṣafihan `preparationPending` ati `mergeReady` lọtọ: igbaradi aṣeyọri ko ṣe awọn itumọ isunmọ lati dapọ. Sọ awọn digi ti o kan sọ ninu oludije ti o ṣajọ ṣaaju gbigba wọle. Oludije ti isinyi Mergify ti o gbẹkẹle, `merge_group`, awọn titari ẹka ati afọwọṣe CI nṣiṣẹ lo oluṣayẹwo pipe, laisi `--warn` tabi idariji-ikuna-jogun. Awọn hashes ibi-afẹde ti o padanu ati iwọn ti o dinku nipasẹ awọn faili ipilẹ ti o ti gbasilẹ ko le ṣe idajo pipe aṣeyọri kan.

### Tu ọna iyara PR silẹ (`quality.yml`)

#### Iroyin idanwo arakunrin ti o gbagbe

`npm run check:forgotten-sibling-tests` nṣiṣẹ bi igbesẹ imọran ti `Fast Quality Gates` o si tun lo ipinnu agbewọle lẹhin maapu ipa-idanwo. Akopọ Markdown ati abajade JSON ti wa ni idaduro bi iṣẹ-ṣiṣe iṣan-iṣẹ `forgotten-sibling-tests` fun isọdiwọn ṣaaju yiyọkuro eyikeyi.

Awọn agbewọle ilu okeere ati awọn agbewọle ti o ni agbara jẹ awọn iwadii ipinnu ipinnu nikan; nwọn kò ṣẹda a ìdènà wiwa. Awọn imukuro ti a ṣe ayẹwo n gbe ni `config/quality/forgotten-sibling-allowlist.json`. Titẹsi kọọkan gbọdọ lorukọ olumulo ati idanwo oludije, funni ni oye kan pato, ati sopọ ọrọ GitHub kan tabi ibeere fa. Awọn titẹ sii aiṣedeede kuna pipade. Awọn imukuro ko le dinku idanwo oludije ti paarẹ tabi iyatọ ti o ṣafikun `.skip`/`.todo`; irẹwẹsi irẹwẹsi ati iboju iparada miiran jẹ ohun ini nipasẹ ẹnu-ọna `check:test-masking` ti o dina ominira.

#### Awọn eto titẹ titẹ meji dahun oriṣiriṣi

`typecheck:core` (`noImplicitAny: false`) / `typecheck:noimplicit:core` (`noImplicitAny: true`) ati `check:build-typecheck` ṣe akopọ awọn eto oriṣiriṣi labẹ awọn aṣayan oriṣiriṣi, ati pe faili kanna le jẹ mimọ ni ọkan ati kun fun awọn aṣiṣe ni ekeji.

`tsconfig.build.json` ṣeto `"strict": false`, nitorinaa `noImplicitAny` wa ni pipa. Atunto mojuto ṣe akopọ atokọ iyọọda faili 27 ti a ti sọ di mimọ pẹlu awọn aṣayan ti o muna ati tẹle awọnya agbewọle titẹ sii kọọkan, nitorinaa awọn faili ti ko han ninu eto kikọ naa tun ṣayẹwo nibẹ.

Abajade naa ṣe pataki nigbati o ba ṣe idajọ boya ti tẹ faili kan:**Ayẹwo odo labẹ `check:build-typecheck` ko tumọ si odo** . Yiyọ `@ts-nocheck` lati awọn faili 26 fihan 23 ti wọn mọ ni eto kikọ; mẹrindilogun ti awon surfaced nipa 120 implicit-eyikeyi aṣiṣe ninu awọn ti o muna ọkan. Ṣayẹwo awọn mejeeji ṣaaju pipe faili ti o mọ.

#### `check-ui-value-drift` — stale-translation ẹnu-bode

Mu ọkan i18n ipadasẹhin awọn ẹnu-bode miiran ti iṣeto ko le rii: iye Gẹẹsi ti tun kọwe ati awọn itumọ ti o wa lati inu _previous_ Gẹẹsi duro lẹhin, nitorinaa awọn olumulo ti kii ṣe Gẹẹsi tẹsiwaju kika ni igboya-ọrọ, ẹda ti ko tọ.

Eleyi bawa fun gidi. `oauthModal.googleOAuthWarning` ti tun kọwe nigbati oluranlọwọ iwọle Antigravity ti de (#5203);**39 ti 43 agbegbe** pa ọrọ sọ fun awọn oniṣẹ lati "daakọ URL ni kikun ki o si lẹẹmọ si isalẹ" — sisan ti ko le pari fun olupese naa. Ko ṣe akiyesi titi #8463 nitori:

- `sync-ui-keys` nikan backfills awọn bọtini ti o jẹ **ti ko si** , kii ṣe awọn ti o jẹ **diduro** ;
- `check-ui-keys-coverage` ka bọtini _presence_, nitorinaa awọn iṣiro itumọ ti o duro bi o ti bo;
- `check-translation-drift` ṣe atẹle awọn digi iwe `docs/i18n/<locale>/**.md` — ko ka `src/i18n/messages/*.json` rara. Dinamọ ni iṣẹ `docs-sync-strict` lati atunṣiṣẹpọ 2026-09: ṣatunkọ doc mojuto → `npm run i18n:run -- --files=<doc>` (ipele-apakan, olowo poku).

**Iyatọ-mọ, kii ṣe atilẹyin ipilẹ.** O ṣe afiwe `en.json` ni ipilẹ iṣọpọ si igi iṣẹ; fun gbogbo bọtini ti iye Gẹẹsi rẹ yipada, eyikeyi agbegbe ti o tun di itumọ ti a ko fowo kan duro. Eyi mọọmọ **didi gbese ti o ti wa tẹlẹ** — a diff ko le fi han eyi ti atijọ English a gun-lawujọ translation wa lati, ki ẹnu-bode onidajọ nikan ohun ti isiyi ayipada fọwọkan. Yiyan (ipilẹṣẹ hash-bọtini kan) yoo jẹ idiyele faili ~ 600 KB ti ipilẹṣẹ, 3 × ipilẹ ti o tobi julọ ti o wa tẹlẹ, ti n rọ lori gbogbo i18n PR.

Awọn ọna meji lati ni itẹlọrun:

1. ṣe imudojuiwọn awọn itumọ ti o kan, tabi
2. ṣeto wọn si `__MISSING__:<new english>` — akoko asiko naa lẹhinna sin Gẹẹsi ti a ṣe atunṣe (`src/i18n/request.ts::deepMergeFallback`, #7258) ati awọn ila bọtini fun itumọ.

Ti o ba ti okun **itumo** yipada, fẹ **lorukọmii bọtini** : bọtini titun ko le jogun itumọ ti o duro. Iyẹn jẹ apẹrẹ #8463 ti a lo.

```bash
npm run i18n:check-value-drift          # strict (what CI runs)
npm run i18n:check-value-drift:warn     # report only
BASE_REF=origin/release/vX.Y.Z npm run i18n:check-value-drift
```

Iye-fiseete ati titun-bọtini ẹnu-bode pin ọkan aileyipada lafiwe lati `scripts/i18n/resolve-ui-diff-base.mjs`. Ṣiṣan iṣẹ naa kọja ipilẹ kanna, ipilẹ-ipilẹ ati oludije SHAs si awọn sọwedowo mejeeji. PR/base-retarget, titari ati awọn ṣiṣe akojọpọ-ẹgbẹ lo ipo iṣẹlẹ wọn. Fifiranṣẹ ẹka oludije nbeere PR ṣiṣi gangan rẹ tabi titẹ sii `i18n_base_sha` ti o fojuhan. Ifiranṣẹ tabi akiyesi eto `main` tabi `release/vX.Y.Z` laisi titẹ sii ṣe afiwe adehun ti o kẹhin pẹlu obi akọkọ rẹ; kii ṣe ayẹwo gbogbo gbese itumọ ti a jogun. Epe agbegbe nilo ipilẹ lafiwe ti o fojuhan, fun apẹẹrẹ aṣẹ `BASE_REF` loke.

Ọsọ ọrọ sisọnu tabi aibikita, katalogi ti ko le ka tabi aiṣedeede, ati oludije ti o yipada ṣe agbekalẹ `INCOMPLETE` pẹlu koodu ijade **2** , pẹlu ni ipo ikilọ. Katalogi ka lo `scripts/i18n/read-ui-catalog.mjs`; Awọn ikuna kika ko ni rọpo pẹlu awọn nkan ofo. Bẹni ipilẹ ti ko si tabi titẹ sii ti ko pe ni iṣeto PASS.

àdéhùn docs/env, ìbámu i18n, àwọn ìdánwò ẹyọ kọ̀ọ̀kan) kò yí padà — ìdánwò pupa ṣì jẹ́ ìdánwò pupa.

**Àwọn irinṣẹ́**

- `npm run quality:relax-baselines -- --pct 20 --note velocity_YYYY_MM_DD [--dry-run]` — ìtúsílẹ̀
  ìgbà-kan-náà (`scripts/quality/relax-baselines.mjs`); ó kọ̀ láti ṣiṣẹ́ lẹ́ẹ̀mejì pẹ̀lú
  àkọsílẹ̀ kan náà.
- `npm run quality:headroom [-- --only deadExports,fileSize] [--json out.json --md out.md]` —
  ó wọ̀n gbogbo ẹnubodè onínọ́mbà gẹ́gẹ́ bí CI ṣe ń ṣe, ó sì tẹ àyè àfikún tó kù fún ẹnubodè kọ̀ọ̀kan
  jáde (`scripts/quality/baseline-headroom.mjs`). Iṣẹ́ `baseline-headroom` alálẹ́ ń tẹ tábìlì náà
  jáde nínú àkótán ìṣiṣẹ́ workflow, ó sì ń gbé ìròyìn JSON/Markdown rẹ̀ sókè gẹ́gẹ́ bí
  `baseline-headroom-<run_id>`, tí a ń pa mọ́ fún ọjọ́ 90. Àwọn ìlà ìkìlọ̀ àti ewu ń tọ́ka sí àwọn ẹnubodè
  tó wà láàárín 10% sí ààlà gíga wọn tàbí tó ti kọjá a. Ṣàyẹ̀wò àwọn ìròyìn wọ̀nyí gẹ́gẹ́ bí ìkìlọ̀
  kutukutu pé a ń lo ìsúná náà; ṣàyẹ̀wò àwọn àkọsílẹ̀ `_rebaseline_*` ti ẹnubodè tó fa ìṣòro. Iṣẹ́ náà kò
  ṣẹ̀dá tàbí ṣe ìmúdójúìwọ̀n issue tó wà títí mọ́; #12149 pa ìtàn àwọn ìròyìn àtijọ́ mọ́.

**Ìpo kóòdù tuntun (Clean-as-You-Code) — láti 2026-08-30, ọ̀nà yíyára PR nìkan**

Lórí àwọn ìṣẹ̀lẹ̀ `pull_request`, `quality.yml` ń fi `--base-ref <PR base SHA>` ránṣẹ́ sí `check:file-size`,
`check:complexity-ratchets` àti `check:dead-code`. Fún `check:complexity-ratchets` àti
`check:dead-code`, ẹnubodè náà ń fi HEAD wé merge-base **ní ààlà àwọn fáìlì tí PR náà fọwọ́ kàn
nìkan** (`scripts/check/newCodeMode.mjs`: a dá merge-base náà sílẹ̀ nínú
`git worktree` àkókò-kúkúrú, ESLint/knip ń ṣiṣẹ́ níbẹ̀ àti lórí HEAD, a sì ń ṣe ìyàtọ̀ àwọn iye fún fáìlì kọ̀ọ̀kan):

- **tí ń dí ìlọsíwájú** — PR náà fi àwọn ìrúfin cyclomatic/cognitive tàbí àwọn export tí kò lò kún àwọn fáìlì tí ó yí padà
  (`complexityNewCode=`, `cognitiveComplexityNewCode=`, `deadExportsNewCode=` nínú àkọsílẹ̀);
- **ìkìlọ̀** — àpapọ̀ káríayé ní ìfiwéra pẹ̀lú ìpìlẹ̀ tí a ti dí mú. Ìyapa tí a jogún kì í fi
  àmì pupa sí PR tí kò mọwọ́-mẹsẹ̀; a máa ń tọpa ìyapa náà fún àtúnṣe nígbà ìbámu ìtújáde, iṣẹ́
  headroom sì máa ń ṣọ́ ọ.

`check:file-size` ń lo base ref gẹ́gẹ́ bí òfin tirẹ̀ (`scripts/check/check-file-size.mjs`, #8522):
ó ń ṣàyẹ̀wò gbogbo fáìlì source àti test inú tree, ó ń ka iye ìlà fáìlì kọ̀ọ̀kan ní base PR
pẹ̀lú `git show`, ó sì ń mú fáìlì kan kùnà nìkan nígbà tí ó bá dàgbà kọjá èyí tó tóbi jù láàárín ààlà ìpìlẹ̀ rẹ̀
(`frozen` / `testFrozen`, tàbí `cap` / `testCap` fún fáìlì tí kò sí nínú ìpìlẹ̀) àti ìwọ̀n rẹ̀ ní base.
Nítorí náà, fáìlì tí ó ti yapa tẹ́lẹ̀ lórí base kì í sọ PR aláìlẹ́bi di pupa.

`check:boundary:ratchet` ń lo òfin kan náà sí nọ́ńbà ẹyọ rẹ̀
(`scripts/quality/measure-boundary.mjs --ratchet --base-ref <sha>`): lórí àwọn ìṣẹ̀lẹ̀ PR, àwọn
ẹnu-ọ̀nà yíyára `quality.yml` àti iṣẹ́ lint `ci.yml` méjèèjì máa ń fi SHA ìpìlẹ̀ PR ránṣẹ́, a máa
ń díwọ̀n commit ìpìlẹ̀ láti inú export `git archive`, PR náà sì máa kùnà nìkan nígbà tí iye edge
`open-sse → src` rẹ̀ bá ju èyí tó tóbi jù láàárín `metrics.boundaryOpenSseToSrc` àti iye tó wà lórí ìpìlẹ̀ lọ. A máa ń
jábọ̀ ìyípadà ìpìlẹ̀ tó ga ju òpin lọ (`base drift herdado`), ṣùgbọ́n kò jẹ́ kí PR aláìṣẹ̀ di pupa láé; push → main
ń pa òpin gígùn mọ́, SHA ìpìlẹ̀ tí kò ṣeé yanjú sì máa padà sí i pẹ̀lú ìkìlọ̀.

Àwọn ìṣiṣẹ́ `workflow_dispatch`, àyẹ̀wò release-green àti iṣẹ́ headroom alẹ́ kò ní ìpìlẹ̀ PR
wọ́n sì ń pa ìfiwéra gígùn (àgbáyé) mọ́. Coverage, duplication àti type-coverage ṣì jẹ́ ti àgbáyé
fún báyìí (àwọn irinṣẹ́ wọn kò lè ṣe diff fáìlì-kọ̀ọ̀kan lọ́nà tí kò gbówó púpọ̀) — wọ́n jẹ́ olùdíje fún ìtọ́jú kan náà.

**Pípa ìpele náà dé ní v4.0 (LTS = ó le koko ju ti tẹ́lẹ̀ lọ, kì í ṣe "padà sí bó ṣe máa ń rí")**

1. Lórí tip mímọ́ `release/v4.0.0`: `npm run quality:headroom --json` fún àkọsílẹ̀, lẹ́yìn náà
   `npm run quality:ratchet -- --update`, `check:file-size --update`,
   `check:complexity-ratchets --update`, `check:dead-code --update`, àti `--update` fún ẹnu-ọ̀nà typecheck kọ̀ọ̀kan — gbogbo baseline máa ń sọ̀kalẹ̀ sí iye tí a díwọ̀n.
2. Pa `_policy` rẹ́ kúrò nínú `quality-baseline.json` (ó tún `--require-tighten` àti ìfipamọ́
   alẹ́ mú ṣiṣẹ́), dá `THRESHOLD = 36` (tàbí tó ga jù bẹ́ẹ̀ lọ) padà sínú `check-openapi-coverage.mjs`.
3. Mú àwọn òpin le ju iye tí a díwọ̀n lọ níbi tí modularization ti ṣàǹfààní: dá `cap` file-size padà sí 1000
   (tàbí 800), fi 5 kún àwọn òkè-ilẹ̀ coverage, dead exports 0 fún àwọn package tí a ṣe modularization sí.

## Ìpìlẹ̀ Ratchet (`quality-baseline.json`)

Ẹ́ńjìnnì ratchet (`scripts/quality/check-quality-ratchet.mjs`) máa ń ka `quality-baseline.json`
ó sì máa ń fi wé `quality-metrics.json` tí a ṣẹ̀ṣẹ̀ kó jọ. Mẹ́tríìkì èyíkéyìí tí ó bá fà sẹ́yìn
kọjá epsilon rẹ̀ yóò mú kí build náà kùnà.

Àwọn mẹ́tríìkì tí a ń tọpinpin lọ́wọ́lọ́wọ́:

| Mẹ́tríìkì              | Ìtọ́sọ́nà | Ìtumọ̀                             |
| --------------------- | ------- | --------------------------------- |
| `eslintWarnings`      | `down`  | Iye ìkìlọ̀ ESLint kò gbọ́dọ̀ pọ̀ sí i |
| `coverage.statements` | `up`    | Ìbora gbólóhùn kò gbọ́dọ̀ dín kù    |
| `coverage.lines`      | `up`    | Ìbora ìlà kò gbọ́dọ̀ dín kù         |
| `coverage.functions`  | `up`    | Ìbora iṣẹ́ kò gbọ́dọ̀ dín kù         |
| `coverage.branches`   | `up`    | Ìbora ẹ̀ka kò gbọ́dọ̀ dín kù         |

Láti ṣe ìmúdójúìwọ̀n ìpìlẹ̀ lẹ́yìn ìlọsíwájú gidi kan:

```bash
npm run quality:ratchet -- --update
git add quality-baseline.json
```

Àmì `--update` máa ń kọ àwọn iye tí a wọ̀n lọ́wọ́lọ́wọ́ sínú `quality-baseline.json`.
Ṣe commit fáìlì yìí papọ̀ pẹ̀lú àyípadà tí ó mú mẹ́tríìkì náà sunwọ̀n sí i. PR tí ó mú
mẹ́tríìkì kan sunwọ̀n sí i láì ṣe ìmúdójúìwọ̀n ìpìlẹ̀ náà ni `--require-tighten` yóò rí
(Ìpele 6A.5, ìmúṣẹ rẹ̀ ṣì ń dúró).

### CodeQL ratchet: gbigba oludije ati akojo oja ibi ipamọ

CI ni gbigba CodeQL oludije nipasẹ ẹwọn igbẹkẹle ti o fojuhan: `codeql-scan` pe matrix ede mẹrin ni `codeql.yml`, lẹhinna `codeql-admission` nṣiṣẹ `node scripts/check/check-codeql-ratchet.mjs --candidate`. `Gate / CI` nilo awọn abajade mejeeji. Didara ṣe idaduro awọn sọwedowo nọmba tirẹ ṣugbọn ko beere ọlọjẹ ṣaaju ki olupilẹṣẹ pari; `Gate / Quality` nikan kii ṣe igbasilẹ pipe. Awọn ku CodeQL nilo lori awọn oludije nikan-docs.

Eto imulo ni `config/quality/codeql-admission-policy.json` yan Awọn iṣe, C/C++, JavaScript/TypeScript ati Python, aiyipada suite ibeere, awoṣe irokeke latọna jijin ati kọ ipo ko si. Ọkọ ofurufu olupilẹṣẹ kọ igbasilẹ imuṣiṣẹ ni isunmọtosi ati awọn ẹka ni ita atokọ ibi-afẹde fojuhan. Awọn ibi-afẹde lọwọlọwọ jẹ akọkọ ati awọn idanwo adehun release/v3.8.54. ṣe afiwe atokọ ipari yii ati titari titari itọju pẹlu ẹya package; itusilẹ atẹle nilo atunyẹwo lori wiwọ. CI's itusilẹ gbooro ti o gbooro PR okunfa ti wa ni idaduro, ṣugbọn ibi-afẹde ti ko ni ibọwọ ṣe ijabọ HOLD ṣaaju isediwon dipo gbigba PASS ti ko ni iwọn.

Iṣẹ-ṣiṣe matrix kọọkan n ṣe igbasilẹ SARIF ti o ga julọ ID, ede, ẹka, ṣiṣe ati igbiyanju, idanimọ iṣan-iṣẹ olupe, iṣẹlẹ ref/head/base/merge SHA ati hash eto imulo. Awọn gbigba lati ayelujara iṣẹ ti o gbẹkẹle nikan awọn owo-iṣẹ ṣiṣe yii ati pe o jẹri awọn igbelewọn ohun-ọṣọ. O nilo gbogbo awọn ẹka mẹrin, olupilẹṣẹ aṣeyọri ati ṣiṣe ti pari ti ikojọpọ gangan kọọkan. O nlo àlẹmọ sarif_id API, kii ṣe itupalẹ tuntun ti a rii lori ẹka kan. Awọn atunṣe apa kan le tun lo awọn ẹka aṣeyọri lati igbiyanju iṣaaju ti ṣiṣe kanna ati oludije, titọju igbiyanju iṣelọpọ; olupilẹṣẹ lọwọlọwọ ti kuna ko le tun lo ẹri alawọ ewe ti tẹlẹ.

Iṣe CodeQL n duro de sisẹ, ṣugbọn imuse ti o pinni le kilo ati tẹsiwaju lẹhin ikuna kika ipo tabi idaduro ti o rẹwẹsi. Nitorina gbigba wọle jẹri sisẹ lẹẹkansii. Awọn ẹka ti o padanu, sisẹ isunmọ, kuna tabi awọn iṣẹ ti a fagilee, idanimọ ti o duro, pagination ti ko pe tabi APIs ti ko wa ni gbejade HOLD ati jade 2. Ko si iduro ti o wa titi fun ṣiṣan ọlọjẹ olominira ti o ku. PR ti ko ṣe ayẹwo ko le kọja nitori ibeere titaniji da pada 0. Iwọn ti o niwọn loke `metrics.codeqlAlerts.value` jade 1; ipilẹ ko ni dide lati fa awọn itaniji ti ẹka miiran. [Ipo ikojọpọ ati wiwa itupalẹ](https://docs.github.com/en/rest/code-scanning/code-scanning).

Awọn igbasilẹ igbasilẹ igbasilẹ ati itupalẹ IDs, awọn ẹka, awọn ẹya irinṣẹ, ref/SHA, ipilẹṣẹ ati awọn nọmba gbigbọn. Nọmba SARIF identity/result, awọn iṣiro ofin ti o kere ju ati awọn iṣẹlẹ itaniji gangan wa dandan. Awọn idanimọ PR/analysis jẹ atunyẹwo ṣaaju gbigba. Awọn sọwedowo wọnyi ṣe agbekalẹ agbegbe agbegbe atunto, kii ṣe akojo oja ti gbogbo faili orisun ti o fa jade. Iyọkuro C/C++ ko si pẹlu koodu ti ipilẹṣẹ lakoko kikọ iṣẹ akanṣe kan. Awọn iyọkuro orisun tun nilo atunyẹwo, ati ifarabalẹ olùkópa nilo ẹri ipilẹ-gangan afiwera.

`codeql-maintenance.yml` n pese awọn iwoye titari itusilẹ lọwọ ati iṣeto ọsẹ laisi pidánpidán awọn olupilẹṣẹ PR/main. `nightly-codeql-inventory.yml` ṣe itọju ipilẹ-ipilẹṣẹ jakejado lọtọ, pẹlu `--strict-measurement` ati ikuna nigbati wiwọn ko si. Rekọja oore-ọfẹ olu-ojo agbegbe kii ṣe gbigba wọle oludije. Titọpa jẹ `--update` ti o fojuhan lẹhin ti a ti rii daju kika isalẹ agbaye.

Ṣiṣan iṣẹ ilọsiwaju naa ko gbọdọ ṣe atẹjade lakoko ti iṣeto Aiyipada: GitHub kọ apapọ yẹn. Ilana ti ikede rẹ wa ni isunmọtosi titi iyipada iṣakoso ti atunyẹwo yoo ka pada. Ṣaaju ki o to titẹjade, oniṣẹ pin ibi ipamọ, head/base/tree, awọn hashes policy/patch/rollback ati ipo iṣeto ti a ṣe akiyesi; `node scripts/quality/codeql-producer.mjs verify-admin-readback` ṣayẹwo awọn ti a ti ṣe yẹ ati awọn igbasilẹ JSON gangan. Eyi jẹ ẹṣọ imọ-ẹrọ, kii ṣe ifọwọsi oniṣẹ tabi rirọpo fun mimu awọn atunkọ tuntun. Aami PR ko beere iraye si Isakoso. Yiyi pada ati iyipada aṣayẹwo eyikeyi nilo kika kika lọtọ pẹlu PR gidi, orita ati ẹri ibamu-ẹgbẹ.

Awọn orita lo awọn asare ti o gbalejo, isanwo laisi awọn iwe-ẹri ti o tẹsiwaju, ko si install/build akanṣe ninu olupilẹṣẹ, ko si si awọn aṣiri ibi-ipamọ jogun. GitHub ṣe atilẹyin ikojọpọ SARIF fun iṣẹlẹ pull_request pẹlu ami orita ti o dinku; alakosile ipaniyan idasi igba akọkọ jẹ eto imulo GitHub. Maṣe lo pull_request_target lati ṣiṣẹ koodu ti ko gbẹkẹle. Jẹrisi awọn igbanilaaye ami ami gangan, onínọmbà_key ati gbogbo awọn agbegbe ẹka ni canary iṣakoso ṣaaju ki o to gbero ijira naa ti pari. [Awọn ofin ikojọpọ orita](https://docs.github.com/en/code-security/reference/code-scanning/troubleshoot-analysis-errors/resource-not-accessible), [awọn ipo iṣeto ti o fi ori gbarawọn](https://docs.github.com/en/code-security/reference/code-scanning/troubleshoot-analysis-errors/two-codeql-workflows).

**Iyọkuro jẹ ipe onišẹ (Hard Rule #14)** — ko yọkuro titaniji CodeQL kan laisi gbigbasilẹ idalare imọ-ẹrọ ninu asọye ifasilẹ: `won't fix` fun ibeere ilana-oke, `used in tests` fun imuduro idanwo kan, `false positive` fun imototo CodeQL ko le rii (tẹlẹ: `docs/security/ERROR_SANITIZATION.md`).

## Ìyípadà Ratchet Ní Ìpele Ìtújáde (WS5.5, v3.8.49)

Nígbà tí ratchet kan (ìwọ̀n fáìlì, complexity, àwọn ìkìlọ̀ eslint) bá fà sẹ́yìn lórí
orí ìtújáde MÍMỌ́ — ìyẹn ni pé ÀKÓJỌ àwọn merge ló fà á sẹ́yìn, tí kò sì sí PR kan ṣoṣo
tó lè tún ìfàsẹ́yìn náà hàn lórí branch tirẹ̀ — ojúṣe àtúnṣe náà jẹ́ ti **release captain, lẹ́ẹ̀kan ṣoṣo, lórí
release branch**: yan yíyọ apá jáde/àtúnṣètò kóòdù; ṣe rebaseline nìkan pẹ̀lú àkọsílẹ̀ ìdáláre
tí a ti ṣàkọsílẹ̀. Má ṣe gbé ìyípadà àkójọpọ̀ lé PR olùkópa lórí láéláé, má sì ṣe
rebaseline fún PR kọ̀ọ̀kan (èyí ń fi àwọn ìfàsẹ́yìn gidi pamọ́). Kọ́kọ́ ṣe ìyàtọ̀: tún àbájáde pupa náà
hàn lórí orí mímọ́ nínú probe worktree kí o tó rò pé PR rẹ ló fà á.

## Fífipamọ́ Àwọn Ìdínkù Ratchet — ọ̀nà sísàlẹ̀ (#8584)

Ratchet náà jẹ́ aládàáṣe ní ìdajì nìkan, ìdajì tí kò tọ́ sì ni. **Gígbé** cap kan sókè jẹ́
àtúnṣe JSON ọwọ́ tí ó gba ìṣẹ́jú-àáyá mẹ́wàá, tó sì jẹ́ ọ̀nà tó yára jù láti ṣí PR pupa sílẹ̀.
**Sísọ** ọ̀kan kalẹ̀ nílò kí ẹnìkan ṣiṣẹ́ `--update` kí ó sì commit àbájáde náà — títí di ìgbà tí
job `bank-ratchet-shrinks` dé, kò sí workflow kankan tó ń ṣiṣẹ́ ẹ. Àbájáde tí a wọn
(2026-07-25): àwọn fáìlì frozen 18 ti wà ní tàbí lábẹ́ cap ila 800 fún fáìlì tuntun, èyí tó burú jù
wà ní 132× (`src/shared/validation/schemas.ts`, ila 19 tí ó ru cap 2,523); òrùlé
complexity rìn láti `1794 → 2169` kọjá àwọn àkọsílẹ̀ rebaseline bíi ~37 pẹ̀lú ìdínkù kan ṣoṣo
(−1); a sì kọ “mú un le sí i nípasẹ̀ `--update` ní cycle tó kàn” ní ìgbà 31, tí a sì ṣe é
lẹ́ẹ̀kan ṣoṣo. Cap kan tí ó pé ju kóòdù tó mú un wá lọ máa ń sọ gbogbo decomposition tí a ti parí
di ààyè ìdàgbàsókè fún ẹnikẹ́ni tó bá tún fáìlì náà ṣe lẹ́yìn náà, láìsí ariwo.

`nightly-release-green.yml` → job **`bank-ratchet-shrinks`** ń pa àyípo yẹn mọ́:

|            |                                                                                                              |
| ---------- | ------------------------------------------------------------------------------------------------------------ |
| Ṣiṣẹ́ lórí  | `schedule` (3×/ọjọ́) + `workflow_dispatch` — pẹ̀lú ìmọ̀ọ́mọ̀ **kì í ṣe** `push`                                   |
| Ń wọn      | `release/vX.Y.Z` tó ga jù, resolution kan náà + injection guard bí `release-green`                           |
| Ń kọ       | `check:file-size --update` àti `check:complexity-ratchets --update` (a kọ́ méjèèjì láti dín kù nìkan)         |
| Ń ṣàyẹ̀wò   | `npm run check:ratchet-bank` (`scripts/quality/verify-ratchet-bank.mjs`)                                     |
| Ń fi ránṣẹ́ | PR kan tí ó jẹ́ ti ìsinsìnyí nígbà gbogbo sí release branch — a máa ń ṣe force-update rẹ̀, a kì í fi í ṣe spam |

A ń ṣe fífipamọ́ náà ní àkójọpọ̀ dípò fún push kọ̀ọ̀kan nítorí kò ní ìbéèrè latency kankan (ìdínkù tí a
fi pamọ́ láàárín 8h dára) nígbà tí iṣẹ́ kan fún merge kọ̀ọ̀kan yóò tún PR branch kọ́ léraléra
lákòókò àwọn ìpolongo merge, yóò sì san owó fún ESLint walk kíkún ní gbogbo ìgbà. Ìṣàwárí ṣì wà lórí
push (`release-green`); fífipamọ́ nìkan ni a ń ṣe ní àkójọpọ̀.

### Olùṣàyẹ̀wò ààbò

Job náà ń kọ sínú àwọn baseline láìsí àbójútó, nítorí náà `verify-ratchet-bank.mjs` ni ohun tó mú
èyí ṣeé tẹ́wọ́ gbà. Ó ń ṣe diff igi lẹ́yìn `--update` pẹ̀lú `HEAD`, ó sì **dá job náà dúró
kí commit kankan tó wà** — láì ṣí PR kankan — àyàfi tí gbogbo ìyípadà bá jẹ́ ọ̀kan nínú:

- entry onínọ́mbà `frozen` / `testFrozen` tí a **dín kù** tàbí **yọ kúrò**
- `complexity-baseline.json` → `count` tí a **dín kù**
- `quality-baseline.json` → `metrics.cognitiveComplexity.value` tí a **dín kù**

Ohunkóhun mìíràn yóò kùnà: gbígbé nọ́ńbà kan sókè, fífi entry kan kún un, yíyí `cap`/`testCap` padà, tàbí
píparẹ́/àtúnkọ àkọsílẹ̀ `_rebaseline_*` kan (àwọn àkọsílẹ̀ wọ̀nyẹn ni ipa-ọ̀nà audit tó ṣàlàyé ìdí tí
òrùlé kọ̀ọ̀kan fi wà, a sì tọ́jú wọn sínú object `frozen` kan náà pẹ̀lú àwọn entry fáìlì).
Bot kan tó lè gbé cap sókè yóò burú ju ipò tó wà lọ dájúdájú. Regression
guard: `tests/unit/verify-ratchet-bank.test.ts`.

Job náà kì í push sí `release/*` láéláé — ènìyàn kan ló máa merge PR náà, nítorí náà ìwọ̀n búburú
kò lè wọlé láìsí àyẹ̀wò.

## Ìlànà Àtòjọ Ìyọ̀ǹda

Gbogbo ẹnu-ọ̀nà àyẹ̀wò tí kò lè kùnà nítorí àwọn ìrúfin tó ti wà tẹ́lẹ̀ máa ń lo àtòjọ ìyọ̀ǹda tí a ti dí múlẹ̀
(fún àpẹẹrẹ, `KNOWN_STALE_DOC_REFS`, `KNOWN_MISSING`, `KNOWN_RAW_SQL`). Ìlànà náà ni:

**Ṣàtúnṣe ìdí pàtàkì tó fa ìṣòro náà; lo àtòjọ ìyọ̀ǹda nìkan nígbà tí ìrúfin náà ti wà tẹ́lẹ̀ tí
kò sì ṣeé ṣàtúnṣe nínú PR kan náà.**

Nígbà tí o bá ń ṣàfikún àkọsílẹ̀ sí àtòjọ ìyọ̀ǹda:

1. Fi àlàyé sínú comment kan nípa ìdí rẹ̀.
2. Tọ́ka sí issue tí ń tọpinpin rẹ̀ (fún àpẹẹrẹ, `// #3498 — Phase 2 feature, not yet implemented`).
3. Yọ àkọsílẹ̀ náà kúrò nínú PR kan náà tó ṣàtúnṣe ìrúfin náà — àkọsílẹ̀ àtijọ́ tí kò tún
   ń fi ìrúfin tó ṣì ń ṣiṣẹ́ pamọ́ jẹ́ àbùkù fúnra rẹ̀ (ìmúlò stale-enforcement 6A.3 yóò
   mú kí ẹnu-ọ̀nà àyẹ̀wò kùnà lórí àkọsílẹ̀ àtòjọ ìyọ̀ǹda tí kò ní ìbáṣepọ̀ mọ́ nígbà tí a bá ti ṣàmúlò rẹ̀).

**Má ṣe** ṣàfikún àwọn àkọsílẹ̀ àtòjọ ìyọ̀ǹda láti mú kí àwọn ìdánwò kọjá ní kíákíá. Ẹnu-ọ̀nà àyẹ̀wò aláwọ̀ ewé pẹ̀lú
àtòjọ ìyọ̀ǹda tó ń pọ̀ sí i ń fúnni ní ìmọ̀lára èké nípa dídára.

### Nígbà tí ẹnu-ọ̀nà àyẹ̀wò kan bá kùnà lórí PR rẹ

1. **Ka àbájáde ẹnu-ọ̀nà àyẹ̀wò náà dáadáa** — ó máa sọ fáìlì tàbí àmì wo gan-an ló rú
   òfin náà fún ọ.
2. **Ṣàtúnṣe ìrúfin náà** — ọ̀pọ̀ àwọn ẹnu-ọ̀nà àyẹ̀wò jẹ́ àyẹ̀wò ètò-fáìlì tó ń fúnni ní àbájáde kan náà ní gbogbo ìgbà, tí yóò sì kọjá ní kété
   tí kóòdù náà bá tọ̀nà.
3. **Tí ìrúfin náà bá ti wà tẹ́lẹ̀** (ìyẹn ni pé, kì í ṣe ìwọ ló dá a sílẹ̀ ṣùgbọ́n ẹnu-ọ̀nà àyẹ̀wò náà ti
   bẹ̀rẹ̀ sí í bo ó): ṣàfikún àkọsílẹ̀ àtòjọ ìyọ̀ǹda pẹ̀lú comment ìdáláre àti issue ìtọpinpin.
4. **Tí ẹnu-ọ̀nà àyẹ̀wò náà bá jẹ́ ratchet** (coverage, àwọn ìkìlọ̀ ESLint, àtúnṣe, complexity):
   ìyípadà rẹ mú kí òṣùwọ̀n náà burú sí i. Ṣàtúnṣe ìṣòro tó fa á, tàbí (nígbà díẹ̀ gan-an) ṣiṣẹ́
   `npm run quality:ratchet -- --update` tí ìyípadà náà bá jẹ́ àmọ̀ọ́mọ̀ tí ìdínkù nínú òṣùwọ̀n náà
   sì jẹ́ ìtẹ́wọ́gbà — ṣùgbọ́n ṣàkọsílẹ̀ ìdí rẹ̀ sínú àpèjúwe PR.
5. **Àwọn ẹnu-ọ̀nà àyẹ̀wò ìmọ̀ràn** (`continue-on-error: true`) wà fún fífúnni ní ìsọfúnni — wọn kì í dí
   ìdapọ̀ dúró ṣùgbọ́n wọ́n máa hàn nínú àkótán CI. Ṣàtúnṣe wọn síbẹ̀.

## Ṣíṣàfikún Ẹnu-ọ̀nà Àyẹ̀wò Tuntun

1. Ṣẹ̀dá `scripts/check/check-<name>.mjs` (tàbí `.ts`). Àwọn ẹnu-ọ̀nà àyẹ̀wò ìlànà máa jáde pẹ̀lú 0/1.
   Àwọn ẹnu-ọ̀nà àyẹ̀wò irú ratchet máa ń fi òṣùwọ̀n kan ránṣẹ́ sí `quality-metrics.json` nípasẹ̀ `collect-metrics.mjs`.
2. Ṣàfikún `"check:<name>": "node scripts/check/check-<name>.mjs"` sí `package.json`, kí o sì
   mú alias náà àti àṣẹ rẹ̀ gan-an bá ara wọn mu nínú `config/quality/gate-manifest.json`.
   Lo ìmúṣiṣẹ́pọ̀ kan náà nígbà tí o bá ń yí alias ìfàṣẹsí tó ti wà padà tàbí tí o bá ń yọ ọ́ kúrò.
   Ṣiṣe `npm run check:gate-manifest`; hook pre-commit àti ìsọ̀rí ìyípadà CI
   ń mú kí àdéhùn yìí di dandan.
3. So ó pọ̀ sínú `.github/workflows/ci.yml` lábẹ́ iṣẹ́ tó yẹ
   (ìlànà → `lint` tàbí `docs-sync-strict`; ratchet → `quality-gate`).
4. Tí ó bá ní àtòjọ ìyọ̀ǹda, lo `reportStaleEntries()` láti
   `scripts/check/lib/allowlist.mjs` kí a lè ṣàwárí àwọn àkọsílẹ̀ àtijọ́ láìfọwọ́ṣe.
5. Kọ ìdánwò kan sínú `tests/unit/build/` tó ń bo ọgbọ́n ìṣàwárí ẹnu-ọ̀nà àyẹ̀wò náà.
6. Ṣàfikún ìmúdójúìwọ̀n sí ìwé yìí (ṣàfikún ìlà kan sí tábìlì iṣẹ́ tó yẹ).

- **`check:node-runtime` ń ṣiṣẹ́ nínú iṣẹ́ 11** — ⚠️ **ROI rẹ̀ kéré.** Ọ̀kọ̀ọ̀kan jẹ́ runner ọ̀tọ̀, àyẹ̀wò náà sì kéré ju ìṣẹ́jú-ààyá 1; àpapọ̀ ohun tí a lè fipamọ́ jẹ́ ~10s, ní ìfiwéra pẹ̀lú pípàdánù ìṣọ́ iṣẹ́-kọ̀ọ̀kan tó rọrùn tí kò sì náni púpọ̀. Kò yẹ fún ìyípadà àti ìdàrúdàpọ̀ náà.
- **`typecheck:noimplicit:core` lórí lint CI** — ✅ **a ti yọ ọ́ kúrò nínú iṣẹ́ lint** (ó jẹ́ ìmọ̀ràn `continue-on-error` tẹ́lẹ̀); àyè type tó ń dí ni `typecheck:core` + `check:type-coverage`. A pa script agbègbè mọ́.

### Yí padà / pinnu (ìlànà olùṣiṣẹ́)

locale mẹ́sàn-án àti ìdìpọ̀ 2 (#13660) pẹ̀lú àìní kọ́kọ́rọ́ 10 nínú mẹ́jọ (2026-09-15). Ṣàtúnṣe ìkùnà pẹ̀lú
