## Oja ẹnu-bode ati awọn profaili ipaniyan

### Gbigba oludije

CI ati Awọn Gates Didara n ṣiṣẹ ni ọkọọkan ṣe idajo iduroṣinṣin kan: `Gate / CI` ati `Gate / Quality`. Eto imulo gbigba wọn ti ikede ṣe iṣiro gbogbo iṣẹ oke bi o ṣe nilo tabi imọran. Iṣẹ ti o nilo gbọdọ ṣaṣeyọri: sonu, fagilee, fo, isunmọtosi ati awọn abajade aimọ ko le fi idi PASS mulẹ. Awọn iwe aṣẹ ti o wulo-nikan tabi katalogi-sọtọ le jẹ ki ọna koodu ko wulo; osere PR kii ṣe oludije ti o gba. Aami `hotfix` kan ko yọ ẹri kuro.

Awọn ṣiṣan iṣẹ mejeeji bo PRs sinu awọn ẹka main/release, titari si `main`, fifiranṣẹ afọwọṣe ati awọn iṣẹlẹ akojọpọ-ẹgbẹ. Titari, firanṣẹ ati dapọ-ẹgbẹ ṣiṣe aṣayan ni kikun. Titari si `release/**` ko bẹrẹ wọn (2026-10-18): iyipada kọọkan tẹlẹ ti ṣiṣẹ matrix naa lori PR rẹ ati apapọ apapọ jẹ iṣẹ Tu-Green (`docs/ops/RUNNER_BOX.md` → Hosted lene). Awọn orita ati awọn ẹgbẹ dapọ lo awọn asare ti a ti gbalejo fun awọn iṣẹ ti bibẹẹkọ yan awọn asare ti ara ẹni; Agbara gbigbalejo ti o to gbọdọ rii daju ṣaaju yiyi.

Arinrin PR nṣiṣẹ awọn sare aṣayan. Awọn ọna `full-code` ati `full-code-e2e` ti eto imulo gbigba (E2E, isọpọ, artifact package, Electron èéfín, Bun SQLite, ilolupo eda ati awọn alabara ilana) ṣiṣẹ nikan lori apẹrẹ isinyi Mergify tabi lori ṣiṣe ni kikun: `gh workflow run ci.yml --ref <branch>`.

Iwe-ẹri JSON kọọkan n ṣe idanimọ SHA ti a ṣayẹwo-jade, ṣiṣe ṣiṣiṣẹsiṣẹ ati igbiyanju. CLI na kọ aiṣedeede checkout/event SHA kan. Awọn idanwo ṣiṣiṣẹsiṣẹpọ di ọmọ ẹgbẹ eto imulo si atokọ `needs` iṣẹ idajo nitorina ọna tuntun tabi yiyọ kuro ko le parẹ ni idakẹjẹ. Awọn owo-owo naa bo ṣiṣan iṣẹ tiwọn, kii ṣe atẹjade, imuṣiṣẹ, tabi awọn inu inu ẹrọ ọlọjẹ imọran ti o wa tẹlẹ. Ṣiṣẹ awọn orukọ ayẹwo mejeeji ni awọn ofin ẹka jẹ iyipada iṣakoso lọtọ; fifi awọn iṣẹ wọnyi kun ko ṣe aabo fun ẹka kan funrararẹ.

### Àkópọ̀ isinyi

Aami `queue` nfi PR ranṣẹ si isinyi Mergify (`.mergify.yml`). Mergify ṣi PR osere kan lori ẹka `mergify/merge-queue/`, CI nṣiṣẹ yiyan ni kikun nibẹ, ati pe PR atilẹba dapọ nigbati `Gate / CI`, `Gate / Quality` ati `Merge integrity (changelog + generated skills)` kọja.

Mergify kọ akopọ isinyin rẹ sinu apejuwe yiyan, ati pe awọn ohun elo miiran le ṣatunkọ paapaa. Iṣẹlẹ `pull_request` `edited` kan lori iru apẹrẹ kan gba ẹgbẹ concurrency tirẹ (`-queue-edit-<run_id>`) nitori naa ko le fagilee ṣiṣe gidi ti osere naa, o si fo ẹnu-bode ati matrix naa. Nikan `Merge integrity` ṣi nṣiṣẹ. Iṣẹ ẹnu-ọna ti o fo naa n gbe orukọ ayẹwo ti o yatọ, nitori Mergify ka `Gate / CI` ti o fo bi ayẹwo ti o kuna ati pe o yọkuro PR naa.

Lẹhin isọdi, titari ko ni beere nigbagbogbo PR. Ọrọìwòye `@mergifyio queue` lori rẹ.

### Ẹri ti o ni idaduro ni idinku gbigba

`scripts/quality/validate-release-acceptance.mjs` dinku eto ti a pese ati awọn ifihan rẹ; ko ṣe fi idi rẹ mulẹ pe ero naa ni wiwa opo gigun ti itusilẹ pipe. Awọn ijabọ rẹ ṣeto `releaseAcceptance: false` ni gbangba, paapaa nigba ti ero yẹn jẹ `VERIFIED`. Ṣiṣan iṣẹ ṣiṣe `release-acceptance.yml` tun nlo awọn imuduro ojiji, kii ṣe itumọ gidi, package, bata tabi awọn owo igbega.

CLI naa nilo `--evidence-root` lati mọ daju ẹri ti o daduro. Awọn faili ti wa ni ipinnu bi `<evidence-root>/<artifact_id>/<member>` ati hashed bi SHA-256. Igbasilẹ PASS laisi ẹri, sonu tabi faili ti o yipada, ọna ti ko lewu tabi aami-ọna kan ṣe idilọwọ ijẹrisi. Awọn faili ti o nsọnu ko ṣe deede si awọn akọọlẹ aṣeyọri ofo. Awọn sọwedowo SHA/run/attempt ti o wa tẹlẹ wa ni ominira: awọn baiti ti o baamu ko le gba iwe-ẹri ti o duro duro. Iduroṣinṣin fáìlì kii ṣe ẹ̀rí ìfójútó ipaniyan tabi igbega artifact.

### Iṣiro ọlọjẹ aimi

Oja ọja npm-alias ti ikede ati awọn ọmọ ẹgbẹ ọlọjẹ-imi gbe ni `config/quality/gate-manifest.json`. Ṣiṣe `npm run check:gate-manifest` lati fọwọsi awọn orukọ iwe afọwọkọ ati awọn aṣẹ gangan lodi si `package.json`; awọn afikun, yiyọ kuro ati pipaṣẹ fiseete kuna mejeeji kio agbegbe ati awọn iṣẹ isọdi-iyipada ni CI. Inagijẹ kii ṣe iṣẹ iṣan-iṣẹ, apẹẹrẹ matrix tabi ọran idanwo: awọn iṣiro wọnyi ko gbọdọ gbekalẹ bi paarọ.

Lo `npm run quality:scan -- --list` tabi `npm run quality:scan:fast -- --list` lati ṣayẹwo awọn inagijẹ ti o yan laisi ṣiṣe wọn. Isare n pe aaye titẹsi npm, nitorinaa akoko asiko rẹ (pẹlu Bun nibiti a ti tunto) ti wa ni ipamọ. Awọn igbasilẹ ti o farahan ni ita awọn profaili wọnyẹn bi a ti pe ni lọtọ, ati awọn aṣẹ itọju jẹ eewọ ni awọn profaili ọlọjẹ kika-nikan.

Awọn profaili wọnyi bo ọlọjẹ aimi nikan. Wọn ko jẹri awọn idanwo ọja, agbegbe, apoti, awọn sọwedowo ita tabi gbigba idasilẹ ni kikun ti oludije. Gbigbawọle ṣiṣan iṣẹ nlo `config/quality/admission-policy.json` ti o sopọ ati `scripts/quality/admission-verdict.mjs`. Awọn profaili oluwoye itusilẹ wa lọtọ; ṣayẹwo awọn sọwedowo ti o wulo ati awọn iwe-ẹri ni ominira. Awọn aṣẹ aimi Oluwoye ni kikun jẹ ikede ni `config/quality/release-green-static-profile.json`, pẹlu `audit:deps`, yiyan-idanwo iyipada ati awọn sọwedowo itumọ. Agberu naa fọwọsi awọn aṣẹ npm lodi si package.json ati awọn ikede CI/Quality awoṣe; o kọ fiseete dipo ti ṣiṣe awọn aami ikarahun bi awọn ariyanjiyan. Iṣẹjade SKIP/INCOMPLETE scanner ti a beere ko le fi idi PASS mulẹ. Profaili naa ṣe igbasilẹ awọn imukuro ita ati pe ko rọpo agbegbe ti o gbalejo, awọn matiri idanwo, package tabi ẹri imuṣiṣẹ. Oja prose ti o wa ni isalẹ jẹ itọkasi, kii ṣe ẹri pe ẹnu-bode kan ti ṣiṣẹ gangan.

Awọn iwe afọwọkọ n gbe labẹ `scripts/check/` (awọn ẹnubode eto imulo) ati `scripts/quality/` (ẹnjini ratchet). Orisun otitọ CI ni `.github/workflows/ci.yml`.

### Tu PR -ọna-yara silẹ (`quality.yml`)

`.github/workflows/quality.yml` ṣe afikun CI lori main/release PRs, titari si `main`, fifiranṣẹ ati dapọ awọn ẹgbẹ. PRs lo awọn sọwedowo iyara ti a fiwe-ọna. Ikole ẹda-ara ti alaabo patapata ti yọkuro; awọn sọwedowo build/package/boot gidi wa ni CI. Suite ẹyọkan ati vitest nṣiṣẹ nikan ni CI (`Unit Tests (N/8)` ati `Vitest`).

| Job                                              | Ààlà                                                                                                                                     | Ìdènà             |
| ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- | ----------------- |
| `Docs Gates (fast-path)`                         | Docs/code PRs; API docs refs ati awọn docs-gbogbo                                                                                        | Bẹẹni             |
| `Fast Quality Gates`                             | koodu PRs; awọn sọwedowo aimi, sọwedowo oriṣi, titẹ dasibodu, awọn idanwo ẹyọkan ti o ni ipa, awọn idanwo arakunrin ti o gbagbe (imọran) |
| `No new ESLint warnings`                         | koodu PRs; suppressions-mọ lint oluso                                                                                                    | Bẹẹni, pẹlu orita |
| `Merge integrity (changelog + generated skills)` | PRs ti kii ṣe apamọ; changelog ati ti ipilẹṣẹ olorijori ìsiṣẹpọ                                                                          | Bẹẹni, pẹlu orita |

#### Iroyin idanwo arakunrin ti o gbagbe

`npm run check:forgotten-sibling-tests` nṣiṣẹ bi igbesẹ imọran ti `Fast Quality Gates` o si tun lo ipinnu agbewọle lẹhin maapu ipa-idanwo. Fun gbogbo module iṣelọpọ ti o yipada, o ṣe ijabọ awọn ẹwọn `changed module/symbol -> static consumer -> candidate sibling test` ipinnu ipinnu nigbati idanwo oludije ko si ni iyatọ ibeere-fa. Akopọ Markdown ati abajade JSON ti wa ni idaduro bi iṣẹ ọna iṣan-iṣẹ `forgotten-sibling-tests` fun isọdiwọn ṣaaju eyikeyi yiyọkuro idilọwọ.

Awọn agbewọle ilu okeere ati awọn agbewọle ti o ni agbara jẹ awọn iwadii ipinnu ipinnu nikan; nwọn kò ṣẹda a ìdènà wiwa. Awọn imukuro ti a ṣe ayẹwo n gbe ni `config/quality/forgotten-sibling-allowlist.json`. Titẹsi kọọkan gbọdọ lorukọ olumulo ati idanwo oludije, funni ni ọgbọn kan pato, ati sopọ ọrọ GitHub tabi ibeere fa. Awọn titẹ sii aiṣedeede kuna pipade. Awọn imukuro ko le dinku idanwo oludije ti paarẹ tabi iyatọ ti o ṣafikun `.skip`/`.todo`; irẹwẹsi irẹwẹsi ati iboju iparada miiran jẹ ohun ini nipasẹ ẹnu-ọna `check:test-masking` dina ominira.

#### Awọn eto titẹ titẹ meji dahun oriṣiriṣi

`typecheck:core` ati `check:build-typecheck` ṣe akojọpọ awọn eto oriṣiriṣi labẹ awọn aṣayan oriṣiriṣi, ati pe faili kanna le jẹ mimọ ni ọkan ati kun fun awọn aṣiṣe ni ekeji.

Yiyọ `@ts-nocheck` lati awọn faili 26 fihan 23 ninu wọn ti o mọ ni eto kikọ; mẹrindilogun ti awon surfaced nipa 120 implicit-eyikeyi aṣiṣe ninu awọn ti o muna ọkan. #### Awọn digi itumọ jẹ awọn faili ti a mu (ipo PR vs ipo itusilẹ)

Ẹya PR kan ṣatunkọ awọn orisun Gẹẹsi nikan. Awọn digi `docs/i18n/<locale>/**` (pẹlu awọn ẹda 66 `llm.txt` ati awọn faili `CHANGELOG.md` ti a tumọ) ati `.i18n-state.json` ni a tun kọ ni igbesẹ kan nipasẹ igbi itumọ (awọn ẹka `docs/i18n-*` / `chore/i18n-*`, `i18n-mirror-refresh.yml` ti a ṣeto) ati nipasẹ itusilẹ (`npm run release:sync-changelog-i18n`). Nitorina awọn ẹnu-ọna digi nṣiṣẹ ni awọn ipo meji, ipinnu nipasẹ `scripts/check/lib/gateMode.mjs` (`--mode=pr|release`, lẹhinna `OMNIROUTE_GATE_MODE`, lẹhinna iṣẹlẹ Awọn iṣẹ; ṣiṣe agbegbe kan jẹ `release`):

- `check:docs-sync` — ipo idasilẹ nṣiṣẹ gbogbo ayẹwo. ipo PR ntọju ẹya package.json/OpenAPI, awọn akọle CHANGELOG root ati oluso-docs superseded, ati tẹjade `SKIP reason=pr-mode` fun awọn ẹda digi `llm.txt` ati awọn apakan CHANGELOG ti a tumọ — ayafi ti PR kọ awọn digi: ẹka ori ti a sọ bi onkọwe ti idile `docs/i18n/**` ni `config/quality/derived-paths/*.json` ti o nṣiṣẹ mejeeji sọwedowo muna, ati pe, diff ti o yipada `docs/i18n/<locale>/llm.txt` ti ara rẹ `CHANGELOG.md` nṣiṣẹ ti o ṣayẹwo muna. Ipilẹ iyatọ ko yanju ni ibi isanwo depth-1 (iṣẹ `docs-sync-strict` ), nitorinaa ipo PR tun ṣe ayẹwo kan ti ko nilo ipilẹ: gbogbo digi `llm.txt` gbọdọ wa, tọju oluyatọ `---` rẹ ati gbe boya ara gbongbo tabi ara julọ awọn digi pin. A mimọ ti o gbe fi oju gbogbo awọn digi se stale ati ki o koja; a ọwọ satunkọ si ọkan digi kuna. Awọn faili `CHANGELOG.md` ti a tumọ ko ni iru ayẹwo ni ibi isanwo depth-1 PR kan.
- Awọn ami-ifaramọ kio nṣiṣẹ `check-docs-sync.mjs --mode=pr`: a ṣe idajọ lori ohun ti o ṣe. Laisi asia, ṣiṣe agbegbe ni ipo itusilẹ, ati ọkan ti dapọ PR ti o ṣatunkọ `llm.txt` root yoo dina gbogbo ṣiṣe nigbamii lori ipilẹ yẹn titi ti igbi naa yoo fi ṣiṣẹ. Ofin kanna ni o wa fun eyikeyi ẹnu-ọna ti o mọ ipo kan Husky kio nṣiṣẹ: kio naa kọja `--mode=pr`, ati pe idajo ti o muna duro pẹlu ipo idasilẹ (itusilẹ PR, titari si `main`, ṣiṣe agbegbe lasan).
- Awọn idanwo ẹyọ akoonu digi-digi (`tests/_helpers/mirrorFreshness.ts`: `cycle-docs-mirror-contract`, `resilience-pre-dispatch-docs-mirrors`, `cli-env-quality-docs-mirrors`, `docs/*-locales`) ipo itusilẹ — n ṣe afihan gbogbo agbegbe. ipo PR sọ awọn digi nikan ti o wa lọwọlọwọ pẹlu orisun Gẹẹsi ni ibamu si `.i18n-state.json` (hash gbogbo faili, tabi hash apakan ti o gbasilẹ ti apakan awọn pinni idanwo) ati fo awọn ti o duro pẹlu idi kan. Awọn sọwedowo provenance `target_hash` ṣiṣẹ fun gbogbo agbegbe ni awọn ipo mejeeji. Freshness jẹ fun abala `## `, ẹyọkan `run-translation.mjs` hashes; apakan gigun (akojoro ẹnu-bode ti faili yii jẹ nipa idaji rẹ) tumọ si eyikeyi atunṣe ninu rẹ fi oju awọn digi wọnyẹn duro, ati awọn iṣeduro ipo PR wọn fo titi di igbi ti o tẹle. Idaduro orisun Gẹẹsi ti ko si ninu rẹ ṣubu pada si lafiwe gbogbo faili.
- `i18n translation drift` — advisory on PRs, muna lori titari, nightly ati awọn Tu ge, ki a stale digi ko le gbe ni a Tu.

`scripts/i18n/sync-llm-mirrors.mjs` (tun gbejade bi `syncLlmMirrors()`, pẹlu `--dry-run`) tun awọn digi `llm.txt` kọ; Itusilẹ itusilẹ, igbi itumọ ati eto `i18n-mirror-refresh.yml` ṣiṣe rẹ (itura n ṣe awari awọn digi `llm.txt` ti o duro pẹlu ṣiṣe gbigbẹ, niwọn bi ijabọ fiseete ko ṣe atokọ wọn, o si mu wọn ṣiṣẹpọ ṣaaju `check:docs-all`).

Kọọkan ni o ni a baiti-afiwera kuro igbeyewo (`tests/unit/docs/readme-*-svg.test.ts`, job `test-unit`) ti o kuna nigbati awọn olufaraji faili ti wa ni stale ni Tu mode; ni a PR, `check:generated-artifacts` ṣe idajọ SVG awọn atunṣe PR ati fiseete ipilẹ ti wa ni osi si isọdọtun itusilẹ (wo [Awọn faili ti ipilẹṣẹ ati awọn ipilẹ ti a mu](#generated-files-and-derived-baselines-written-at-release) ) — ati `check:docs-counts` ka awọn nọmba canonical lati awọn nodes `<text>` wọn — eyiti o jẹ idi ti igbesẹ ilana ntọju gbogbo okun ti a ṣe ilana ninu faili bi `<text>` ti a ko rii. Awọn iṣiro awọn olupilẹṣẹ wọnyi fa (apapọ olupese, awọn irinṣẹ MCP, awọn ilana ipa-ọna, awọn olupese ọfẹ,…) wa lati oju aworan otitọ `docs/reference/derived-facts.json` nipasẹ `scripts/docs/readmeFacts.mjs`, kii ṣe lati awọn itumọ ọrọ gangan, nitorinaa atunbere aworan atọka lori ẹka eyikeyi n ṣe agbejade faili ifaramo naa. `free-tier-budget.svg` fa awọn ori ila rẹ lati aworan kanna (`code.freeTierBudget`, akopọ katalogi awọn igbasilẹ iwadii otitọ), nitorinaa iyipada si `FREE_MODEL_BUDGETS` de kaadi ni isọdọtun atẹle dipo titan CI pupa.

### Awọn iye ti ari: awọn ipo ẹnu-ọna `pr` ati `release`

Ẹya kan PR ko kọ iye kan ti o da lori ipo ipilẹ rẹ: olupese, ijira, MCP-tool ati awọn iṣiro ilana, awọn nọmba README SVG, fọtoyiya awọn otitọ. Igbesẹ kan ṣe iṣiro gbogbo wọn, `npm run release:refresh-derived`, ṣiṣe nipasẹ itusilẹ ati nipasẹ awọn alẹ ti ari-refresh PR. Nitorina** laarin awọn idasilẹ ipilẹ wa lẹhin koodu ifiwe nipasẹ apẹrẹ** , ati ẹnu-ọna tabi idanwo ti o ṣe afiwe igi pẹlu koodu ifiwe yoo jẹ pupa lori gbogbo PR lẹhin ti arakunrin kan ṣafikun olupese kan. Awọn ẹnu-ọna ti o ṣe idajọ awọn iye ti a mu jade nitorinaa ṣiṣẹ ni ọkan ninu awọn ipo meji, ti o yanju nipasẹ `scripts/check/lib/gateMode.mjs` (awọn bori baramu akọkọ):

1. `--mode=pr|release` lori laini aṣẹ;
2. oniyipada ayika `OMNIROUTE_GATE_MODE` (`pr` tabi `release`);
3. laifọwọyi, lati awọn iṣẹlẹ awọn iṣẹ GitHub : `pull_request` ti ori rẹ kii ṣe `release/v*`, a `merge_group`, tabi titari si `omni-queue/**` → `pr`; ohun gbogbo miiran (titari, iṣeto, fifiranṣẹ, itusilẹ PR `release/v* → main`, ṣiṣe eyikeyi agbegbe) → `release`.

Kini `check:docs-counts` (`scripts/check/check-docs-counts-sync.mjs`) kuna ni ipo kọọkan:

| Ipo       | Ikuna                                                                                                                                                                                                                                                                                                                                                       | Nilo awọn otitọ laaye |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------- |
| `release` | Gbogbo ayẹwo, dọgbadọgba ti o muna lodi si awọn otitọ ti a gba lati inu igi (iwa ti ẹnu-ọna nigbagbogbo ni): kika ti o duro, ẹya, ilẹ agbegbe tabi nọmba SVG jẹ fiseete STRICT                                                                                                                                                                              | Bẹẹni                 |
| `pr`      | Nikan ohun ti iyipada ṣe, yato si ipilẹ PR pẹlu awọn olutọpa ẹtọ kanna: (1) iye iṣakoso ti ko si ni ipilẹ fun ayẹwo ati faili ("PR satunkọ nọmba iṣakoso — mu ila pada si ọrọ ipilẹ"); (2) ẹtọ ti o nilo ipilẹ ti o gbe ati ori ti sọnu. Awọn iyipada akoonu ti ko nilo awọn otitọ ṣiṣe bi ni ipo idasilẹ; awọn sọwedowo itusilẹ nikan ni a ṣe akojọ ati fo | Rara                  |

Awọn faili aṣoju-itọnisọna gbe** rara** kika ti ari ni gbogbo: `AGENTS.md`, `llm.txt` (ati awọn ẹda `docs/i18n/*/llm.txt` rẹ), orita bs `AGENTS.md`, `open-sse/services/AGENTS.md`, `src/shared/constants/agentSkills.ts`, `skills/README.md` ati gbogbo `skills/*/SKILL.md` tọka si orisun (fun apẹẹrẹ `ROUTING_STRATEGY_VALUES` ni `src/shared/constants/routingStrategies.ts`) ati lati `npm run facts` dipo. Iyatọ “Ko si awọn iṣiro ti a mu (faili ilana-itọnisọna…)” kuna kika kan nibẹ (awọn olupese, awọn iṣipopada, awọn irinṣẹ MCP ati awọn aaye, awọn ilana ipa-ọna, awọn ifosiwewe igbelewọn, awọn akopọ ipo) ni awọn ipo mejeeji, nitorinaa isọdọtun itusilẹ ko ni lati tun atunkọ faili itọnisọna kan.

Ni ipo `pr` awọn ẹka onkọwe le ṣatunkọ awọn iye iṣakoso: `chore/derived-*` (itura alẹ PR), `release/v*`, ati awọn igbi itumọ `docs/i18n-*` ati `chore/i18n-*` (`scripts/check/lib/derivedClaimsDiff.mjs`). Awọn ipele Queue (`merge_group`, Mergify drafts, `omni-queue/**`) ko ṣe idajọ lẹẹkansi: wọn ṣe idajọ PRs ẹnu-ọna ti o ti ṣe idajọ ni ọkọọkan.

Awọn koodu ijade: `0` mọ · `1` STRICT fiseete (tabi rirọ rirọ pẹlu `--strict`) tabi irufin iye-iṣakoso · `2` amayederun — awọn otitọ koodu ko le ṣe gbigba (iwadii tsx kuna tabi ti akoko jade; akoko ipari jẹ `OMNIROUTE_FACTS_TIMEOUT_MS`, aiyipada 600000 ms) tabi, ni CI, ipilẹ PR ko le yanju. Ijade 2 kii ṣe iyatọ iwe rara: tun ṣiṣẹ iṣẹ naa tabi ṣatunṣe agbegbe naa.

Nibo ni ipo kọọkan nṣiṣẹ:

| Nibo                                                                                                  | Ipo                                                                                                                                                                                          |
| ----------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Ẹya PR — `ci.yml` iṣẹ `docs-sync-strict`, igbesẹ `quality.yml` "ipeye awọn iwe aṣẹ"                   | `pr` (laifọwọyi); iṣẹ naa kọja ipilẹ bi `BASE_SHA` ati ṣayẹwo pẹlu `fetch-depth: 2`                                                                                                          |
| `merge_group`, awọn oludije `omni-queue/**`, akojọpọ ẹnu-ọna ọkọ oju-irin apapọ                       | `pr`                                                                                                                                                                                         |
| Tu silẹ PR (`release/v* → main`), awọn titari, iṣeto ati awọn ṣiṣe afọwọṣe                            | `release`                                                                                                                                                                                    |
| Itusilẹ-Awọ ewe (`scripts/quality/validate-release-green.mjs`)                                        | awọn ohun HARD ṣiṣẹ pẹlu `OMNIROUTE_GATE_MODE=pr` ("Ṣe ipilẹ naa fọ?"); nkan DRIFT `derived-refresh` nṣiṣẹ `npm run release:refresh-derived -- --check` (iwo to muna, ko ṣi pupa-ipilẹ rara) |
| Itusilẹ (awọn ipele `/generate-release` 0a ati 1; wiwọ imọ-ẹrọ jẹ iyipada ti a fọwọsi ti oniwun lọtọ) | `npm run release:refresh-derived` kọ awọn faili ti a ti mu; awọn sọwedowo ti ara PR ti tu silẹ lẹhinna ṣiṣe ni ipo `release`                                                                 |
| `nightly-derived-refresh.yml` (ojoojumọ, `release/vX.Y.Z` ti o ga julọ, ti fo labẹ idasilẹ-didi)      | `npm run release:refresh-derived -- --profile=nightly`; lori iyatọ o jẹ ki ONE PR ṣii lati `chore/derived-refresh`; ko dapọ                                                                  |

Awọn aṣẹ lẹhin rẹ:

- `npm run facts` ṣe atẹjade gbogbo nọmba ti a mu bi JSON (`scripts/release/facts.mjs`). `--key=code.mcpTools` ṣe atẹjade iye kan, `--snapshot` ka aworan ifaramọ dipo igi laaye. Jade 2 nigbati awọn otitọ ko le gba.
- `npm run release:refresh-derived` (`scripts/release/refresh-derived.mjs`) ṣe iṣiro awọn faili ti a mu ni ọna gbigbe kan, ni aṣẹ yii (ids igbesẹ fun `--only=`): `provider-reference` (`docs/reference/PROVIDER_REFERENCE.md`), `facts` (aworan fọto), `numbers` (eto atunko ẹnu-ọna kika ti a lo si awọn iwe aṣẹ, lẹhinna gbe lọ si awọn digi `docs/i18n/` wọn), `readme-diagrams`, `skills` (ti ipilẹṣẹ `SKILL.md`) igi `e2e-timings`, `ui-keys` `syncE2eTimings` awọn bọtini prunes `en.json` silẹ ati, pẹlu `--rewritten-since=<ref>` — aiyipada `origin/main` — tun awọn iye Gẹẹsi ti a tun kọ lati igba idasilẹ ti o kẹhin), `llm-mirrors` ati `verify-generated` (lẹhin kikọ, `check:generated-artifacts` ati `check:agent-skills-sync` ni ipo idasilẹ gbọdọ kọja; fo ni `--check` ati nigbati `--only` ba fi silẹ; ikuna kan jade 2). Igbesẹ `changelog` jẹ ijade-inu (`--with-changelog`, profaili idasilẹ nikan). `--profile=nightly` kò fọwọkan kan ti ikede nipe. Pẹlu `-- --check` ko kọ nkankan ko si jade kuro ni 1 nigbati eyikeyi faili yoo yipada tabi iye iṣakoso nilo atunṣe afọwọṣe (akojọ mejeeji); jade 2 lori ohun amayederun ikuna. `--json` ṣe atẹjade abajade bi JSON.
- `docs/reference/derived-facts.json` ni aworan ti awọn otitọ isọdọtun ti o kẹhin ti a lo. Itura nikan ni o kọ ọ. Awọn olupilẹṣẹ README SVG ka rẹ, ati awọn idanwo ẹyọ-akoko PR ṣe afiwe awọn iwe adehun ti o ṣe ati ipilẹṣẹ awọn faili pẹlu — rara pẹlu koodu ifiwe. Ifiwewe ifiwe ẹyọkan ti suite naa ni “itura itusilẹ tilekun ọna” ni `tests/unit/check-docs-counts-sync.test.ts`: pẹlu awọn ododo laaye, ero atunto isọdọtun ti a lo ni iranti ko fi iṣipopada STRICT ko ṣe ijabọ, ati pe atungbero ko yipada ohunkohun.

Lati ṣe ẹda ni agbegbe (awọn aṣiṣe ṣiṣe agbegbe kan si `release`):

```bash
npm run check:docs-counts                                       # release: strict, live facts
node scripts/check/check-docs-counts-sync.mjs --mode=pr          # what a feature PR is judged on
OMNIROUTE_GATE_MODE=pr BASE_REF="origin/release/v$(node -p "require('./package.json').version")" npm run check:docs-counts
npm run release:refresh-derived -- --check                       # what the release would rewrite
```

Laisi ipilẹ ti o le yanju (ko si `BASE_SHA`/`BASE_REF`, ko si `origin/release/v<version>` agbegbe) agbegbe `pr` ṣiṣe tẹjade ikilọ kan ati fo iyatọ dipo ikuna.

### Job: `i18n-ui-coverage`

| `check-new-key-coverage` (ila) | A** titun** Bọtini Gẹẹsi jẹ itumọ ni gbogbo agbegbe — a kọ ami ami `__MISSING__:` kan                                                                                          | Bẹẹni (ipo itusilẹ nikan) |

Nilo `fetch-depth: 0` — ẹnu-ọna fiseete iye yato `en.json` si ipilẹ idapọ.

**Awọn ipo meji (lati ọdun 2026-11-13).** Ẹya PR kan ṣafikun tabi tun awọn bọtini kọ ni `en.json` (ati `bin/cli/locales/en.json`) ko si fọwọkan agbegbe miiran; `check:pr-derived-paths` (iṣẹ `pr-test-policy`, idile `config/quality/derived-paths/translation.json`) kuna ẹya PR ti o ṣe. Awọn agbegbe miiran ti pari ni ẹẹkan fun itusilẹ nipasẹ `release:refresh-derived`, eyiti o pe `syncUiKeys()` ni `scripts/i18n/sync-ui-keys.mjs` (fikun awọn bọtini ti o padanu, awọn ti a sọ piruni, samisi awọn itumọ Gẹẹsi ti a tun kọ pẹlu `rewrittenSinceRef`, tumọ), tabi nipasẹ igbi itumọ. Awọn ẹnu-bode naa ka ipo lati `scripts/check/lib/gateMode.mjs`: ni ipo `pr` (ẹya-ara PRs, `merge_group`, `omni-queue/**`) awọn ibode ipo idasilẹ loke `SKIP reason=pr-mode` titẹjade ati jade 0; ni ipo `release` (itusilẹ PR, titari si `main`, `workflow_dispatch`, awọn ṣiṣe agbegbe) wọn muna bi ti iṣaaju, ati lori itusilẹ PR awọn ti o mọ iyatọ gba `BASE_REF=origin/main`, nitorinaa wọn ṣe idajọ gbogbo bọtini ti a fi kun tabi tun-tun. Ṣe awotẹlẹ idajọ ẹya-PR ni agbegbe pẹlu `--mode=pr`.

PR ti o tun yi awọn iwe akọọlẹ agbegbe pada ni ipo `pr` (igbi itumọ kan, itusilẹ itusilẹ, atunṣe-itumọ nikan) ko fo: `check-key-completeness` ṣe idajọ katalogi kọọkan o yipada lodi si katalogi kanna ni ipilẹ iṣọpọ (`scripts/i18n/lib/touched-catalogs.mjs`) ti o kuna lori bọtini kan ti katalogi ti sọnu, bọtini `en.json` ko ni, itumọ gidi kan tabi ami ọrọ Gẹẹsi si `__MISSING__:` kan placeholders/tags ti English okun PR ko fi ọwọ kan. Katalogi tuntun ninu PR gbọdọ gbe gbogbo eto bọtini `en.json`. Iyẹn ni wiwa, fun awọn katalogi kan PR fọwọkan, kini ipin ati awọn ẹnu-ọna CLI-parity yoo rii.

Awọn idanwo ẹyọ-ipin agbegbe (`cli-i18n-catalog`, `i18n-pt-br`, `i18n-vi-completeness`, `i18n-placeholder-parity`) tẹle awọn ipo kanna nipasẹ `tests/_helpers/localeParityMode.ts`: ni ipo `pr` wọn fo awọn iṣeduro bọtini-parity ati fi silẹ si itusilẹ tun ṣe irẹwẹsi ipo ti awọn bọtini ti Gẹẹsi ti yipada lati ipilẹ idapọ (gbogbo bọtini nigbati iṣẹ idanwo aijinile ko le ka). Oluranlọwọ naa ni** nikan** ipo ijẹniniya-fojusi: `check:test-masking` ka `.skip(` ati `{ skip: true }` ṣugbọn kii ṣe iṣiro `{ skip: "<reason>" }` o pada, nitorinaa `tests/unit/locale-parity-mode.test.ts` pin atokọ ti awọn idanwo laaye lati lo — fifi ọkan jẹ atunyẹwo atunyẹwo si atokọ yẹn.

#### `check-ui-value-drift` — stale-translation ẹnu-bode

Mu ọkan i18n ipadasẹhin awọn ẹnu-bode miiran ti iṣeto ko le rii: iye Gẹẹsi ti tun kọwe ati awọn itumọ ti o wa lati inu _previous_ Gẹẹsi duro lẹhin, nitorinaa awọn olumulo ti kii ṣe Gẹẹsi tẹsiwaju kika ni igboya-ọrọ, ẹda ti ko tọ.

Eleyi bawa fun gidi. `oauthModal.googleOAuthWarning` ni a tun kọ nigbati oluranlọwọ iwọle Antigravity de (#5203);** 39 ti 43 agbegbe** pa ọrọ sọ fun awọn oniṣẹ lati "daakọ URL ni kikun ki o si lẹẹmọ si isalẹ" — sisan ti ko le pari fun olupese naa. Ko ṣe akiyesi titi #8463 nitori:

- `sync-ui-keys` nikan backfills awọn bọtini ti o jẹ** ti ko si** , kii ṣe awọn ti o jẹ** diduro** ;
- `check-ui-keys-coverage` ka bọtini _presence_, nitorinaa awọn iṣiro itumọ ti o duro bi o ti bo;
- `check-translation-drift` tọpa awọn digi awọn iwe aṣẹ `docs/i18n/<locale>/**.md` — ko ka `src/i18n/messages/*.json` rara. O nṣiṣẹ ni iṣẹ `docs-sync-strict`: imọran lori PRs, ti o muna lori titari ati ni alẹ; Ìgbì ìtúmọ̀ ń sọ àwọn dígí tu, kìí ṣe ẹ̀yà-ara PR.

**Iyatọ-mọ, kii ṣe atilẹyin ipilẹ.** O ṣe afiwe `en.json` ni ipilẹ idapọ si igi ti n ṣiṣẹ; fun gbogbo bọtini ti iye Gẹẹsi rẹ yipada, eyikeyi agbegbe ti o tun di itumọ ti a ko fi ọwọ kan mu. Eyi mọọmọ** didi gbese ti o ti wa tẹlẹ** — a diff ko le ṣafihan iru Gẹẹsi atijọ ti itumọ pipẹ ti wa lati, nitorinaa ẹnu-bode naa ṣe idajọ kini iyipada lọwọlọwọ kan. Yiyan (ipilẹṣẹ hash bọtini-fun-kọtini) yoo jẹ iye owo ~ 600 KB ti ipilẹṣẹ, 3 × ipilẹ ti o tobi julọ ti o wa tẹlẹ, ti n tẹ lori gbogbo i18n PR.

Awọn ọna meji lati ni itẹlọrun:

1. ṣe imudojuiwọn awọn itumọ ti o kan, tabi
2. ṣeto wọn si `__MISSING__:<new english>` — akoko asiko naa lẹhinna sin Gẹẹsi ti a ṣe atunṣe (`src/i18n/request.ts::deepMergeFallback`, #7258) ati awọn ila bọtini fun itumọ.

## Ipilẹ Ratchet (`quality-baseline.json`)

Enjini ratchet (`scripts/quality/check-quality-ratchet.mjs`) ka `quality-baseline.json` o si ṣe afiwe rẹ si `quality-metrics.json` ti a ṣẹṣẹ gba. Metiriki eyikeyi ti o tun kọja epsilon rẹ kuna kikọ.

Awọn metiriki tọpa lọwọlọwọ:

| Metiriki              | Itọsọna | Itumo                            |
| --------------------- | ------- | -------------------------------- |
| `eslintWarnings`      | `down`  | kika ikilọ ESLint ko gbọdọ dagba |
| `coverage.statements` | `up`    | Alaye agbegbe ko gbọdọ ṣubu      |
| `coverage.lines`      | `up`    | Agbegbe ila ko gbọdọ ṣubu        |
| `coverage.functions`  | `up`    | Iṣeduro iṣẹ ko gbọdọ ṣubu        |
| `coverage.branches`   | `up`    | Agbegbe ẹka ko gbọdọ ṣubu        |

Lati ṣe imudojuiwọn ipilẹ-ipilẹ lẹhin ilọsiwaju tootọ:

```bash
npm run quality:ratchet -- --update
git add quality-baseline.json
```

Asia `--update` kọ awọn iye iwọn lọwọlọwọ sinu `quality-baseline.json`. Ifowopamọ ilọsiwaju jẹ iṣẹ release/nightly, kii ṣe ẹya PR's: `--require-tighten` (Fase 6A.5) kuna ilọsiwaju ti ko ni banki nikan ni ipo idasilẹ (titari, iṣeto, idasilẹ PR, awọn ṣiṣe agbegbe). Ninu ẹya PR (ipo ẹnu-ọna `pr` ) o tẹ ilọsiwaju naa bi alaye ati kọja; ipadasẹhin kuna ni awọn ipo mejeeji. Lakoko ipele iyara o jẹ imọran nibi gbogbo (`_policy.requireTighten: false`). Wo [Awọn faili ti ipilẹṣẹ ati awọn ipilẹ ti a mu jade](#generated-files-and-derived-baselines-written-at-release).

### CodeQL ratchet: sọji cadence ati Afowoyi okunfa

`check:codeql-ratchet`** ipinle repo, ti a tu lori iṣeto — kii ṣe fun PR.** `gh api repos/diegosouzapw/OmniRoute/code-scanning/default-setup` ṣe ijabọ `state: configured`, `schedule: weekly`: ọlọjẹ iṣeto-aiyipada GitHub, kii ṣe itupalẹ titari-kọọkan. Nitori: lẹhin ti a PR ti FIXES titaniji dapọ, awọn ratchet ntọju kika awọn atijọ, ti o ga kika titi ti nigbamii ti eto ọlọjẹ nṣiṣẹ — ki o Ijabọ a padasehin lori gbogbo ìmọ PR, pẹlu awọn ojoro PR's ti ara telẹ-ups, titi ti ọlọjẹ yẹ soke.

**Atunse ọwọ** : `gh workflow run codeql.yml --ref release/vX.Y.Z` tun ṣe itupalẹ naa ati tun ṣe atunjade awọn itaniji laarin awọn iṣẹju. Ka `.github/workflows/codeql.yml` akọkọ — akọsori rẹ ṣe alaye pe o jẹ `workflow_dispatch` -only** nitori pe o lodi si “iṣagbekalẹ aiyipada” GitHub** (`CodeQL analyses from advanced configurations cannot be processed when the default setup is enabled`). mimu-pada sipo `push`/`pull_request`/ `schedule` okunfa nbeere ohun** igbese eni akọkọ** : Eto → koodu aabo → CodeQL: Aiyipada → To ti ni ilọsiwaju. Maṣe ṣafikun okunfa `schedule:` laisi iyipada — yẹn yoo ṣe awọn ṣiṣe ti kuna nikan.

**Mu ipilẹsẹ naa di lẹhin ti kika naa lọ silẹ** — `node scripts/check/check-codeql-ratchet.mjs --update` kọwe kika iwọnwọn tuntun sinu `quality-baseline.json` → `metrics.codeqlAlerts.value`, nitorinaa ratchet ko ni ipalọlọ laye ipadasẹhin pada si oke aja atijọ. Apeere ti a ṣiṣẹ (2026-09-02/03): PR #12502 titaniji 7 ti o wa titi (13 → 6 ni iwọn ṣiṣi); PR #12530 mu ipilẹ ti o tutunini di 11 → 6 lati baramu; 6 ti o ku lẹhinna ni a yọ kuro pẹlu idalare fun-ọtun si 0 ṣii.

**Iyọkuro jẹ ipe oniṣẹ (Hard Rule #14)** — maṣe yọ titaniji CodeQL kan silẹ laisi gbigbasilẹ idalare imọ-ẹrọ ninu asọye idasile: `won't fix` fun ibeere ilana-oke, `used in tests` fun imuduro idanwo, `false positive` fun sanitizer CodeQL ko le rii (tẹlẹ: `docs/security/ERROR_SANITIZATION.md`).

## Awọn faili ti a ti ipilẹṣẹ ati awọn ipilẹ ti o jẹri (ti a kọ ni itusilẹ)

Ko ṣe atunbi awọn faili ti a ṣe iṣiro lati orisun yẹn, ati pe ko ṣe banki ilọsiwaju ti iwọn sinu ipilẹ kan. Awọn faili wọnyẹn ni a tun kọ lẹẹkan, nipasẹ isọdọtun idasilẹ (`release:refresh-derived`) tabi nipasẹ isọdọtun alẹ PR. Ṣaaju eyi, gbogbo arakunrin PR gbe ẹda atunda tirẹ ati pe o ni ikọlu pẹlu iṣọpọ atẹle (2026-11-13: 30 ti 321 ṣiṣi PRs tunkọ `PROVIDER_REFERENCE.md`, 26–28 tun awọn aworan README kọ).

**Oluso.** `check:pr-derived-paths` (iṣẹ `pr-test-policy`) kuna ẹya PR ti o kan faili ti idile kan ni `config/quality/derived-paths/`:

| Idile       | Awọn faili                                                                                                                                                                           | Atunkọ nipasẹ                                                                                                                 |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------- |
| `generated` | `docs/reference/derived-facts.json`; `docs/reference/PROVIDER_REFERENCE.md`; awọn mejila ti ipilẹṣẹ README SVGs; `skills/*/references/**`; awọn faili `SKILL.md` ti ko ni bulọki aṣa | `release:refresh-derived` (awọn otitọ), `gen:provider-reference`, `docs:readme-diagrams`, `generate-agent-skills.mjs --apply` |
| `baselines` | `config/quality/e2e-timings.json`                                                                                                                                                    | `balance-e2e-shards.mjs --sync` (`syncE2eTimings()`)                                                                          |

Awọn onkọwe (`release/v*`, `chore/derived-*`, ati `chore/bank-ratchet-*` fun awọn ipilẹsẹ) jẹ alayokuro; bẹẹ ni PR kan ti o yipada idile kan pẹlu awọn ẹlẹgbẹ rẹ (fun `generated`: awọn iwe afọwọkọ monomono, awọn idanwo wọn, awọn igbewọle ogbon-aṣoju — `src/shared/constants/agentSkills.ts`, `skills/**` docs ti a fi ọwọ kọ, `docs/openapi.yaml` — ati `changelog.d/**`), fun apẹẹrẹ iṣeto akọni kan yipada pẹlu SVG ti a tun ṣe, tabi atunṣe ọgbọn ti idanwo rẹ ti ka awọn faili `SKILL.md` naa. `SKILL.md` kan pẹlu bulọọki `<!-- skill:custom-start -->` ti a fi ọwọ kọ ko si ninu ẹbi: Àkọsílẹ aṣa rẹ duro ṣiṣatunṣe lẹgbẹẹ ẹya kan.

**Awọn sọwedowo, fun ipo ẹnu-ọna** (`scripts/check/lib/gateMode.mjs`; oluranlọwọ `scripts/check/lib/derivedArtifactScope.mjs`):

| Ṣayẹwo                                                                     | `release` (titari, iṣeto, itusilẹ PR, agbegbe)                    | `pr` (ẹya-ara PR, ipele ti isinyi)                                                                                                                                                                              |
| -------------------------------------------------------------------------- | ----------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `check:agent-skills-sync`                                                  | gbogbo olorijori gbọdọ dogba monomono o wu                        | Awọn ọgbọn nikan ti ọrọ ti ipilẹṣẹ (ni ita bulọọki aṣa) tabi `references/` awọn atunṣe PR ; bibẹkọ `SKIP reason=pr-mode`                                                                                        |
| `check:generated-artifacts` (README SVGs + e2e timings; nilo itan kikun)   | gbogbo SVG dọgba si olupilẹṣẹ rẹ; gbogbo spec ni a timings titẹsi | nikan awọn onisebaye awọn atunṣe PR ; `SKIP reason=pr-mode` iyokù; ko si ipilẹ iyatọ → gbogbo artifact dajo (ikuna-pipade)                                                                                      |
| README SVG baiti-fiwe awọn idanwo (`tests/unit/docs/readme-*-svg.test.ts`) | gbogbo SVG                                                        | nikan SVG awọn satunkọ PR, nigbati ipilẹ ba pinnu; isanwo PR aijinile ti `test-unit` ko ni ipilẹ, nitorinaa nibẹ ni idanwo naa fo pẹlu `SKIP reason=base-unresolved` ati `check:generated-artifacts` ni afiwera |
| e2e timings pipe (`tests/unit/balance-e2e-shards.test.ts`)                 | gbogbo spec ni o ni ohun titẹsi                                   | Ofin kanna bi awọn idanwo SVG (apejuwe tuntun kan n ṣiṣẹ pẹlu iwuwo agbedemeji)                                                                                                                                 |
| `check-quality-ratchet.mjs --require-tighten`                              | Ilọsiwaju ti ko ni banki kuna (ayafi ti `_policy`)                | ilọsiwaju royin, kii ṣe ikuna; a padasehin si tun kuna                                                                                                                                                          |

Ipo idasilẹ ntọju awọn idajo, awọn koodu ijade ati awọn ifiranṣẹ awọn sọwedowo wọnyi ni ṣaaju pipin; ni pupọ julọ ila kan ti wa ni afikun, ti n sọ orukọ ipo ipinnu (`[agent-skills-sync] mode=release (auto: local run)`). Awọn idanwo naa fo nipasẹ node:aṣayan `{ skip: releaseOnlyUnlessTouched(...) }` idanwo, eyiti `check:test-masking` ṣe atokọ ni bulọọki ijabọ-nikan (kii ṣe `.skip(` tabi `{ skip: true }`, nitorinaa ko ka bi foo lile). `check:generated-artifacts` nṣiṣẹ ni ibi ti ipilẹ jẹ atunṣe: iṣẹ `lint` (`fetch-depth: 0`), ni kete lẹhin `check:agent-skills-sync`. Ni agbegbe, `npm run check:generated-artifacts -- --mode=pr` fihan ohun ti igbese naa ṣe idajọ lori PR kan. Olupese-apapọ ayẹwo-agbelebu ti `check:docs-counts` ("Lapapọ itọkasi Olupese (doc vs live modules)") jẹ apakan ti ẹnu-ọna kika ati tẹle awọn ipo ti ẹnu-ọna tirẹ.

Kii ṣe ninu ẹbi, ni idi: awọn faili eto imulo pinnu nipasẹ awọn eniyan (`gate-manifest.json`, awọn atokọ laaye, `admission-policy.json`, `provider-assets-provenance.jsonl`, `model-lifecycle.json`) ati awọn orule ẹya kan PR le ni lati ṣatunkọ papọ pẹlu koodu (awọn titẹ sii `quality-baseline.json` metric, awọn ipilẹ typecheck/file-size/complexity, `eslint-suppressions.json` — ti a ge nipasẹ iṣaju-ṣe ESLint ṣiṣe nigbati PR tunṣe kan tutunini). `src/i18n/routeNamespaces.generated.json` tun jẹ ipilẹṣẹ ṣugbọn o duro ni ẹya PRs: app naa gbe wọle ni akoko ṣiṣe, nitorinaa ko le duro fun isọdọtun.

## Fífipamọ́ Àwọn Ìdínkù Ratchet — ọ̀nà sísàlẹ̀ (#8584)

Ratchet náà jẹ́ aládàáṣe ní ìdajì nìkan, ìdajì tí kò tọ́ sì ni. **Gígbé** cap kan sókè jẹ́
àtúnṣe JSON ọwọ́ tí ó gba ìṣẹ́jú-àáyá mẹ́wàá, tó sì jẹ́ ọ̀nà tó yára jù láti ṣí PR pupa sílẹ̀.
**Sísọ** ọ̀kan kalẹ̀ nílò kí ẹnìkan ṣiṣẹ́ `--update` kí ó sì commit àbájáde náà — títí di ìgbà tí
job `bank-ratchet-shrinks` dé, kò sí workflow kankan tó ń ṣiṣẹ́ ẹ. Àbájáde tí a wọn
(2026-07-25): àwọn fáìlì frozen 18 ti wà ní tàbí lábẹ́ cap ila 800 fún fáìlì tuntun, èyí tó burú jù
wà ní 132× (`src/shared/validation/schemas.ts`, ila 19 tí ó ru cap 2,523); òrùlé
complexity rìn láti `1794 → 2169` kọjá àwọn àkọsílẹ̀ rebaseline bíi ~37 pẹ̀lú ìdínkù kan ṣoṣo
(−1); a sì kọ “mú un le sí i nípasẹ̀ `--update` ní cycle tó kàn” ní ìgbà 31, tí a sì ṣe é
lẹ́ẹ̀kan ṣoṣo. Cap kan tí ó pé ju kóòdù tó mú un wá lọ máa ń sọ gbogbo decomposition tí a ti parí
di ààyè ìdàgbàsókè fún ẹnikẹ́ni tó bá tún fáìlì náà ṣe lẹ́yìn náà, láìsí ariwo.

`nightly-release-green.yml` → job **`bank-ratchet-shrinks`** ń pa àyípo yẹn mọ́:

|            |                                                                                                              |
| ---------- | ------------------------------------------------------------------------------------------------------------ |
| Ṣiṣẹ́ lórí  | `schedule` (3×/ọjọ́) + `workflow_dispatch` — pẹ̀lú ìmọ̀ọ́mọ̀ **kì í ṣe** `push`                                   |
| Ń wọn      | `release/vX.Y.Z` tó ga jù, resolution kan náà + injection guard bí `release-green`                           |
| Ń kọ       | `check:file-size --update` àti `check:complexity-ratchets --update` (a kọ́ méjèèjì láti dín kù nìkan)         |
| Ń ṣàyẹ̀wò   | `npm run check:ratchet-bank` (`scripts/quality/verify-ratchet-bank.mjs`)                                     |
| Ń fi ránṣẹ́ | PR kan tí ó jẹ́ ti ìsinsìnyí nígbà gbogbo sí release branch — a máa ń ṣe force-update rẹ̀, a kì í fi í ṣe spam |

A ń ṣe fífipamọ́ náà ní àkójọpọ̀ dípò fún push kọ̀ọ̀kan nítorí kò ní ìbéèrè latency kankan (ìdínkù tí a
fi pamọ́ láàárín 8h dára) nígbà tí iṣẹ́ kan fún merge kọ̀ọ̀kan yóò tún PR branch kọ́ léraléra
lákòókò àwọn ìpolongo merge, yóò sì san owó fún ESLint walk kíkún ní gbogbo ìgbà. Ìṣàwárí ṣì wà lórí
push (`release-green`); fífipamọ́ nìkan ni a ń ṣe ní àkójọpọ̀.

### Olùṣàyẹ̀wò ààbò

Job náà ń kọ sínú àwọn baseline láìsí àbójútó, nítorí náà `verify-ratchet-bank.mjs` ni ohun tó mú
èyí ṣeé tẹ́wọ́ gbà. Ó ń ṣe diff igi lẹ́yìn `--update` pẹ̀lú `HEAD`, ó sì **dá job náà dúró
kí commit kankan tó wà** — láì ṣí PR kankan — àyàfi tí gbogbo ìyípadà bá jẹ́ ọ̀kan nínú:

- entry onínọ́mbà `frozen` / `testFrozen` tí a **dín kù** tàbí **yọ kúrò**
- `complexity-baseline.json` → `count` tí a **dín kù**
- `quality-baseline.json` → `metrics.cognitiveComplexity.value` tí a **dín kù**

Ohunkóhun mìíràn yóò kùnà: gbígbé nọ́ńbà kan sókè, fífi entry kan kún un, yíyí `cap`/`testCap` padà, tàbí
píparẹ́/àtúnkọ àkọsílẹ̀ `_rebaseline_*` kan (àwọn àkọsílẹ̀ wọ̀nyẹn ni ipa-ọ̀nà audit tó ṣàlàyé ìdí tí
òrùlé kọ̀ọ̀kan fi wà, a sì tọ́jú wọn sínú object `frozen` kan náà pẹ̀lú àwọn entry fáìlì).
Bot kan tó lè gbé cap sókè yóò burú ju ipò tó wà lọ dájúdájú. Regression
guard: `tests/unit/verify-ratchet-bank.test.ts`.

Job náà kì í push sí `release/*` láéláé — ènìyàn kan ló máa merge PR náà, nítorí náà ìwọ̀n búburú
kò lè wọlé láìsí àyẹ̀wò.

## Ìlànà Àtòjọ Ìyọ̀ǹda

Gbogbo ẹnu-ọ̀nà àyẹ̀wò tí kò lè kùnà nítorí àwọn ìrúfin tó ti wà tẹ́lẹ̀ máa ń lo àtòjọ ìyọ̀ǹda tí a ti dí múlẹ̀
(fún àpẹẹrẹ, `KNOWN_STALE_DOC_REFS`, `KNOWN_MISSING`, `KNOWN_RAW_SQL`). Ìlànà náà ni:

**Ṣàtúnṣe ìdí pàtàkì tó fa ìṣòro náà; lo àtòjọ ìyọ̀ǹda nìkan nígbà tí ìrúfin náà ti wà tẹ́lẹ̀ tí
kò sì ṣeé ṣàtúnṣe nínú PR kan náà.**

Nígbà tí o bá ń ṣàfikún àkọsílẹ̀ sí àtòjọ ìyọ̀ǹda:

1. Fi àlàyé sínú comment kan nípa ìdí rẹ̀.
2. Tọ́ka sí issue tí ń tọpinpin rẹ̀ (fún àpẹẹrẹ, `// #3498 — Phase 2 feature, not yet implemented`).
3. Yọ àkọsílẹ̀ náà kúrò nínú PR kan náà tó ṣàtúnṣe ìrúfin náà — àkọsílẹ̀ àtijọ́ tí kò tún
   ń fi ìrúfin tó ṣì ń ṣiṣẹ́ pamọ́ jẹ́ àbùkù fúnra rẹ̀ (ìmúlò stale-enforcement 6A.3 yóò
   mú kí ẹnu-ọ̀nà àyẹ̀wò kùnà lórí àkọsílẹ̀ àtòjọ ìyọ̀ǹda tí kò ní ìbáṣepọ̀ mọ́ nígbà tí a bá ti ṣàmúlò rẹ̀).

**Má ṣe** ṣàfikún àwọn àkọsílẹ̀ àtòjọ ìyọ̀ǹda láti mú kí àwọn ìdánwò kọjá ní kíákíá. Ẹnu-ọ̀nà àyẹ̀wò aláwọ̀ ewé pẹ̀lú
àtòjọ ìyọ̀ǹda tó ń pọ̀ sí i ń fúnni ní ìmọ̀lára èké nípa dídára.

### Nígbà tí ẹnu-ọ̀nà àyẹ̀wò kan bá kùnà lórí PR rẹ

1. **Ka àbájáde ẹnu-ọ̀nà àyẹ̀wò náà dáadáa** — ó máa sọ fáìlì tàbí àmì wo gan-an ló rú
   òfin náà fún ọ.
2. **Ṣàtúnṣe ìrúfin náà** — ọ̀pọ̀ àwọn ẹnu-ọ̀nà àyẹ̀wò jẹ́ àyẹ̀wò ètò-fáìlì tó ń fúnni ní àbájáde kan náà ní gbogbo ìgbà, tí yóò sì kọjá ní kété
   tí kóòdù náà bá tọ̀nà.
3. **Tí ìrúfin náà bá ti wà tẹ́lẹ̀** (ìyẹn ni pé, kì í ṣe ìwọ ló dá a sílẹ̀ ṣùgbọ́n ẹnu-ọ̀nà àyẹ̀wò náà ti
   bẹ̀rẹ̀ sí í bo ó): ṣàfikún àkọsílẹ̀ àtòjọ ìyọ̀ǹda pẹ̀lú comment ìdáláre àti issue ìtọpinpin.
4. **Tí ẹnu-ọ̀nà àyẹ̀wò náà bá jẹ́ ratchet** (coverage, àwọn ìkìlọ̀ ESLint, àtúnṣe, complexity):
   ìyípadà rẹ mú kí òṣùwọ̀n náà burú sí i. Ṣàtúnṣe ìṣòro tó fa á, tàbí (nígbà díẹ̀ gan-an) ṣiṣẹ́
   `npm run quality:ratchet -- --update` tí ìyípadà náà bá jẹ́ àmọ̀ọ́mọ̀ tí ìdínkù nínú òṣùwọ̀n náà
   sì jẹ́ ìtẹ́wọ́gbà — ṣùgbọ́n ṣàkọsílẹ̀ ìdí rẹ̀ sínú àpèjúwe PR.
5. **Àwọn ẹnu-ọ̀nà àyẹ̀wò ìmọ̀ràn** (`continue-on-error: true`) wà fún fífúnni ní ìsọfúnni — wọn kì í dí
   ìdapọ̀ dúró ṣùgbọ́n wọ́n máa hàn nínú àkótán CI. Ṣàtúnṣe wọn síbẹ̀.

### Darapọ / didasilẹ (ẹrọ, eewu kekere)

Oludije kọọkan jẹ ifọwọsi ni ilodi si ipo ẹnu-ọna ifiwe ni 2026-06-17 (igbekele-ṣugbọn-ṣayẹwo); orisirisi "kedere" merges ni tan-jade lati tọju gbese ati ki o jẹ** kii ṣe** mọ silẹ-ins.
