ìpìlẹ̀ ratchet tàbí ìlànà kọjá/kùnà, àti bóyá ó ń dí ìkọ́lé dúró tàbí ó jẹ́ ìmọ̀ràn.

## Oja ẹnu-bode ati awọn profaili ipaniyan

### Gbigba oludije

CI ati Awọn Gates Didara n ṣiṣẹ ni ọkọọkan ṣe idajo iduroṣinṣin kan: `Gate / CI` ati `Gate / Quality`. Eto imulo gbigba wọn ti ikede ṣe iṣiro gbogbo iṣẹ oke bi o ṣe nilo tabi imọran. Iṣẹ ti o nilo gbọdọ ṣaṣeyọri: sonu, fagilee, fo, isunmọtosi ati awọn abajade aimọ ko le fi idi PASS mulẹ. Awọn iwe aṣẹ ti o wulo-nikan tabi katalogi-sọtọ le jẹ ki ọna koodu ko wulo; lasan osere PR kii ṣe oludije ti o gba. Aami `hotfix` kan ko yọ ẹri kuro.

Awọn ṣiṣan iṣẹ mejeeji bo PRs sinu awọn ẹka main/release, titari si `main`, fifiranṣẹ afọwọṣe ati awọn iṣẹlẹ akojọpọ-ẹgbẹ. Titari, firanṣẹ ati dapọ-ẹgbẹ ṣiṣe aṣayan ni kikun. Akọsilẹ ti isinyi Mergify ti o gbẹkẹle tun nṣiṣẹ awọn iṣẹ `full-code`/`full-code-e2e` to wulo; arinrin PRs foo wọn. Ṣaaju iṣọpọ afọwọṣe kan, ṣiṣe fifiranṣẹ ni kikun lori oludije gangan. Titari si `release/**` ko bẹrẹ awọn iṣan-iṣẹ wọnyi; Tu-Alawọ ewe n ṣakiyesi ipilẹ ti o dapọ lọtọ (ọla ti gbalejo `docs/ops/RUNNER_BOX.md` → ). Awọn orita ati awọn ẹgbẹ dapọ lo awọn asare ti a ti gbalejo fun awọn iṣẹ ti bibẹẹkọ yan awọn asare ti ara ẹni; Agbara gbigbalejo ti o to gbọdọ jẹ ijẹrisi ṣaaju yiyi.

Arinrin PR nṣiṣẹ awọn sare aṣayan. Awọn ọna `full-code` ati `full-code-e2e` ti eto imulo gbigba (E2E, isọpọ, artifact package, Electron èéfín, Bun SQLite, ilolupo eda ati awọn alabara ilana) ṣiṣẹ nikan lori apẹrẹ isinyi Mergify tabi lori ṣiṣe ni kikun: `gh workflow run ci.yml --ref <branch>`.

Iwe-ẹri JSON kọọkan n ṣe idanimọ SHA ti a ṣayẹwo, ṣiṣe ṣiṣiṣẹ ati igbiyanju. CLI na kọ aiṣedeede checkout/event SHA kan. Awọn idanwo ṣiṣiṣẹsiṣẹpọ di ọmọ ẹgbẹ eto imulo si atokọ `needs` iṣẹ idajo nitorina ọna tuntun tabi yiyọ kuro ko le parẹ ni idakẹjẹ. Awọn owo-owo naa bo ṣiṣan iṣẹ tiwọn, kii ṣe titẹjade, imuṣiṣẹ, tabi awọn inu inu ẹrọ aṣayẹwo imọran ti o wa tẹlẹ. Ṣiṣe awọn sọwedowo to wulo ti o nilo ni awọn ofin ẹka jẹ iyipada iṣakoso lọtọ; asọye awọn iṣẹ wọn ko daabobo ẹka kan funrararẹ.

`API Route Typecheck` jẹ ayẹwo iṣan-iṣẹ ominira ti ominira, ni ita awọn idajọ apapọ apapọ ati profaili aimi oluwoye ni kikun agbegbe. Ṣayẹwo abajade rẹ lọtọ fun oludije gangan. `.github/workflows/api-route-typecheck.yml` nṣiṣẹ lori PRs sinu `main` tabi `release/**`, titari si boya ẹka ẹbi, fifiranṣẹ afọwọṣe, ati awọn iṣẹlẹ `merge_group` ti iru `checks_requested`. Ko ni àlẹmọ ọna. Dapọ awọn ẹgbẹ ṣayẹwo jade `merge_group.head_sha`; awọn iṣẹlẹ miiran ṣayẹwo `github.sha`. Gbogbo awọn iṣẹlẹ lo ẹnu-ọna iwadii API kanna ati awọn idanwo ẹyọ ẹnu-ọna. PR mimọ retargets beere a titun ayẹwo; awọn atunṣe body/title lo orukọ akiyesi-nikan `Admission not requested / API Route Typecheck` ati pe ko le rọpo ayẹwo gbigba.

### Ẹ̀rí tí a pa mọ́ nínú acceptance reducer

`scripts/quality/validate-release-acceptance.mjs` ń dín plan tí a pèsè àti àwọn
manifest rẹ̀ kù; kò fi ìdí múlẹ̀ pé plan náà bo gbogbo pipeline ìtújáde. Àwọn report rẹ̀
ṣètò `releaseAcceptance: false` ní kedere, àní nígbà tí plan náà jẹ́
`VERIFIED`. Ìṣàn iṣẹ́ `release-acceptance.yml` ṣì ń lo àwọn fixture ojiji, kì í ṣe
àwọn receipt build, package, boot tàbí promotion gidi.

CLI nílò `--evidence-root` láti ṣàyẹ̀wò ẹ̀rí tí a pa mọ́. A máa ń wá àwọn fáìlì
gẹ́gẹ́ bí `<evidence-root>/<artifact_id>/<member>` a sì máa ń ṣe hash wọn bí SHA-256. Àkọsílẹ̀ PASS
láìsí ẹ̀rí, fáìlì tí kò sí tàbí tí ó yí padà, path tí kò ní ààbò tàbí symlink máa ń dí
ìjẹ́rìísí lọ́wọ́. Àwọn fáìlì tí kò sí kò dọ́gba pẹ̀lú àwọn log àṣeyọrí òfìfo. Àwọn
àyẹ̀wò SHA/run/attempt tó ti wà ṣì dúró lọ́tọ̀: àwọn byte tó bá ara wọn mu kò lè gba
receipt tí ó ti pẹ́ sílẹ̀. Ìpéye fáìlì kì í ṣe ẹ̀rí òtítọ́ ìmúṣẹ tàbí promotion artifact.

### DAST ń lo build CI tí a ti fìdí rẹ̀ múlẹ̀

Iṣẹ́ CI dandan `dast-smoke` ń pe `.github/workflows/dast-smoke.yml` lẹ́yìn `build`. Ó tẹ̀lé yíyan kóòdù/àkọ́kọ́-àkọsílẹ̀ kan náà bí build, pẹ̀lú PR fork tí a ń ṣètìlẹ́yìn fún, PR tó dojú kọ release àti ẹgbẹ́ ìsopọ̀. Iṣẹ́ DAST tó sọnù, tó kùnà, tí a fagilé tàbí tí a fò láìròtẹ́lẹ̀ ń dí `Gate / CI`. Workflow tí a lè tún lò kò ní trigger PR/dispatch tirẹ̀; ìfìdímúlẹ̀ ọwọ́ ń lo dispatch CI kí build àti olùlò rẹ̀ wà nínú ìṣiṣẹ́ kan náà.

`scripts/ci/next-build-provenance.mjs` ń so artefakti Next pípé mọ́ digest tar, ibi ìpamọ́/ìṣẹ̀lẹ̀/ìṣiṣẹ́, ìgbìyànjú olùpèsè, head/base/checkout/tree, ìdánimọ̀ workflow, lockfile, ẹ̀yà Node/ABI pàtó, pẹpẹ àti bundler. DAST ń yan ID artefakti tí kò yípadà láti `needs.build.outputs`, ó béèrè ìfìdímúlẹ̀ digest ìgbasilẹ, ó sì ń ṣe hash ZIP lọ́tọ̀ láti fi wé digest olùpèsè kí ó tó ṣí ọmọ ẹgbẹ́ méjì tí a fàyè gba nípasẹ̀ `scripts/ci/unpack-ci-build.py`. Manifest àti àkójọpọ̀ tar gbọ́dọ̀ tún bá àbájáde olùpèsè olómìnira mu kí a tó ṣí igi Next. Kò wá build ẹ̀ka tó ṣẹ̀ṣẹ̀ ṣàṣeyọrí jù lọ rí. Àtúnṣiṣẹ́ apá kan lè lo ìgbìyànjú olùpèsè kan náà bí ID àti gbogbo ohun ìwọlé bá tún bá mu; àkọsílẹ̀ ẹ̀rí ń pa ìgbìyànjú méjèèjì mọ́.

Olùlò dúró lórí runner Linux tí a gbàlejò, pẹ̀lú àṣẹ kíkà ibi ìpamọ́ nìkan, láìsí àṣírí ibi ìpamọ́. Ó ń fi ẹ̀yà Node olùpèsè pàtó sílẹ̀, lẹ́yìn náà ó ń kọ CLI pẹ̀lú `OMNIROUTE_REQUIRE_PREBUILT_NEXT=1`. `scripts/build/standaloneInput.mjs` ń kọ àìsí standalone server kí build àfidípò kankan tó bẹ̀rẹ̀; build CLI àbẹ́lé déédéé ń pa ọ̀nà àfidípò wọn mọ́. Ìmúrasílẹ̀ server, Schemathesis àti promptfoo gbọ́dọ̀ ṣàṣeyọrí nínú ààlà iṣẹ́ ìṣẹ́jú 25 tí kò yípadà. Ẹ̀rí ìpilẹ̀ṣẹ̀ ń fi ìdánimọ̀ àti bytes ìwọlé múlẹ̀, kì í ṣe àṣeyọrí scan DAST. Ìparí àkókò artefakti, ìdádúró runner tàbí scanner tó kùnà ṣi jẹ́ ẹ̀rí tí kò pé tàbí tó kùnà; wrapper ìmọ̀ràn kò lè sọ ọ́ di PASS.

### Agbára ìmúṣẹ UI

CI máa ń ṣiṣẹ́ gbogbo àkójọ UI gẹ́gẹ́ bí shard matrix `test-vitest` mẹ́rin, tí ọ̀kọ̀ọ̀kan ní
worker tí kò ju méjì lọ fún shard kọ̀ọ̀kan àti àkókò ìparí iṣẹ́ ìṣẹ́jú 15 tó ti wà. Shard àkọ́kọ́ tún máa ń ṣiṣẹ́
suite Vitest MCP/autoCombo. Àbájáde iṣẹ́ dandan bo gbogbo ẹsẹ̀ matrix; ìkùnà
tàbí ìfagilé shard kan kò lè fi ìdí gbigba olùdíje wọlé múlẹ̀.

Observer alẹ́ máa ń pa receipt olùdíje pàtó ọ̀tọ̀ mọ́ fún shard UI kọ̀ọ̀kan,
pẹ̀lú ìmúṣẹ MCP nínú receipt àkọ́kọ́. Gbogbo receipt mẹ́rin, àwọn log àti àwọn
ìdánimọ̀ ìmúṣẹ tó bá ara wọn mu ni a nílò. `npm run test:vitest:ui` ti agbègbè ṣì ń yan
suite kíkún; run `--shard` kan jẹ́ ẹ̀rí apá kan nìkan.

### Ìkójọ coverage unit

Àwọn shard unit méjìlá ń kó coverage V8 jọ nígbà ìmúṣẹ ìdánwò wọn tó ti wà. Shard tó ṣàṣeyọrí
máa ń ṣiṣẹ́ `scripts/ci/compact-v8-coverage.mjs` láti rọ àwọn fáìlì àtilẹ̀wá pọ̀ láì dá
report Istanbul àárín sílẹ̀. Iṣẹ́ Coverage ìkẹyìn máa ń ṣàyẹ̀wò gbogbo manifest méjìlá pẹ̀lú
SHA olùdíje, runtime, source root àti àwọn hash data, lẹ́yìn náà yóò ṣiṣẹ́ àwọn reporter c8 àti
àwọn ààlà coverage tó ti wà. Àwọn input pa ìtòlẹ́sẹẹsẹ filename àgbáyé c8 mọ́; pre-merging
fún shard kọ̀ọ̀kan kò ní ààbò fún coverage function/block àdàpọ̀. Àwọn shard tí kò sí, tí ìṣètò wọn
bàjẹ́ tàbí tí kò bára mu máa ń fa ìkùnà gbigba wọlé. Àwọn shard ìdánwò tó kùnà máa ń pa
coverage àyẹ̀wò raw mọ́ lọ́tọ̀; kò lè wọ merge ìkẹyìn.

### Àwọn àkọsílẹ̀ ìtẹ̀síwájú ìṣiṣẹ́ unit

Àṣẹ `test:unit:ci:shard` tí a pín ń ṣàkọsílẹ̀ àwọn ìpele `primary`, `dashboard` àti `serial`
nípasẹ̀ `scripts/ci/unit-progress-reporter.mjs`. Ìjábọ̀ ìdánwò déédéé ṣì wà
fún lílò. Àkọsílẹ̀ ọ̀tọ̀ kan tí ó ní metadata nìkan ń ṣàkọsílẹ̀ ìbẹ̀rẹ̀ àti ìparí fáìlì kọ̀ọ̀kan,
heartbeat ọlọ́gbọ̀n-àáyá sì ń ṣe àkójọ àwọn fáìlì tí ó ṣì ń ṣiṣẹ́ àti iye àkókò tí wọ́n ti lò. Ó ń ṣàkọsílẹ̀
metadata ìṣiṣẹ́ tí a fọwọ́ sí nìkan; a kì í serialize àwọn àpèjúwe ìdánwò, àbájáde, àkóónú àṣìṣe àti gbogbo
environment náà.

CI ń pa àwọn fáìlì JSONL mọ́ gẹ́gẹ́ bí `unit-progress-ci-<run>-<attempt>-<shard>`. Timeout job kan lè dí upload tí ó yẹ kí ó wáyé lẹ́yìn;
àwọn heartbeat tí a ti fi jáde ṣì jẹ́ ẹ̀rí fún ìwádìí ìṣòro. Àìsí heartbeat tún lè túmọ̀ sí
pé process runner kan ti di tàbí pé a ti dá a dúró. Àwọn àkọsílẹ̀ wọ̀nyí ń pa yíyan ìdánwò,
concurrency, àwọn deadline àti exit status tó wà tẹ́lẹ̀ mọ́; wọn kì í ṣe àwọn ìdájọ́ candidate-admission.

### Àkópọ̀ isinyi

Aami `queue` nfi PR ranṣẹ si isinyi Mergify (`.mergify.yml`). Mergify ṣi PR osere kan lori ẹka `mergify/merge-queue/`, CI nṣiṣẹ yiyan ni kikun nibẹ, ati pe PR atilẹba dapọ nigbati `Gate / CI`, `Gate / Quality` ati `Merge integrity (changelog + generated skills)` kọja.

Mergify kọ akopọ isinyin rẹ sinu apejuwe yiyan, ati pe awọn ohun elo miiran le ṣatunkọ paapaa. Iṣẹlẹ `pull_request` `edited` kan lori iru apẹrẹ kan gba ẹgbẹ concurrency tirẹ (`-queue-edit-<run_id>`) nitori naa ko le fagilee ṣiṣe gidi ti osere naa, o si fo ẹnu-bode ati matrix naa. Nikan `Merge integrity` ṣi nṣiṣẹ. Iṣẹ ẹnu-ọna ti o fo naa n gbe orukọ ayẹwo ti o yatọ, nitori Mergify ka `Gate / CI` ti o fo silẹ gẹgẹbi ayẹwo ti o kuna ati pe o yọkuro PR naa.

Lẹhin isọdi, titari ko ni beere nigbagbogbo PR. Ọrọìwòye `@mergifyio queue` lori rẹ.

### Àkójọ static scan

Àkójọ npm-alias tó ní ẹ̀yà àti ọmọ ẹgbẹ́ static-scan wà nínú
`config/quality/gate-manifest.json`. Ṣiṣe `npm run check:gate-manifest` láti ṣàyẹ̀wò
àwọn orúkọ script àti àwọn command pàtó pẹ̀lú `package.json`; àwọn àfikún, ìyọkúrò àti
yíyí command padà máa ń fa ìkùnà hook agbègbè àti àwọn iṣẹ́ ìsọ̀rí ìyípadà nínú CI.
Alias kì í ṣe iṣẹ́ ìṣàn iṣẹ́, instance matrix tàbí test case: a kò gbọ́dọ̀ fi àwọn iye wọ̀nyí
hàn bí ohun tí a lè fi rọ́pò ara wọn.

Lo `npm run quality:scan -- --list` tàbí `npm run quality:scan:fast -- --list`
láti ṣàyẹ̀wò àwọn alias tí a yàn láì ṣiṣẹ́ wọn. Runner náà ń pe entrypoint npm,
nítorí náà runtime rẹ̀ (pẹ̀lú Bun níbi tí a ti ṣètò rẹ̀) wà bí ó ti rí.
Manifest náà ṣe àkọsílẹ̀ àwọn alias tó wà lẹ́yìn àwọn prófáìlì wọ̀nyí gẹ́gẹ́ bí ohun tí a pè lọ́tọ̀, àti
pé a fòfin de àwọn command ìtọju nínú àwọn prófáìlì scan read-only.

Àwọn prófáìlì wọ̀nyí bo static scan nìkan. Wọn kò jẹ́rìí sí àwọn ìdánwò ọjà,
coverage, packaging, àwọn check òde tàbí gbigba ìtújáde olùdíje ní kíkún.
Gbigba wọlé ìṣàn iṣẹ́ ń lo `config/quality/admission-policy.json` tí a so mọ́ àti
`scripts/quality/admission-verdict.mjs`. Àwọn prófáìlì release-observer ṣì wà lọ́tọ̀;
ṣàyẹ̀wò àwọn check àti receipt wọn tó kan ọ̀ràn náà lọ́tọ̀. Àwọn command static ti observer kíkún
ni a kéde nínú `config/quality/release-green-static-profile.json`, pẹ̀lú
`audit:deps`, àṣàyàn mutation-test àti àwọn check ìtumọ̀. Loader máa ń ṣàyẹ̀wò àwọn command npm
pẹ̀lú package.json àti àwọn ìkéde CI/Quality tí a ṣe àwòṣe; ó máa ń kọ drift
dípò ṣíṣe àwọn token shell gẹ́gẹ́ bí argument. Àbájáde SKIP/INCOMPLETE scanner tó jẹ́ dandan
kò lè fi ìdí PASS múlẹ̀. Prófáìlì náà ṣe àkọsílẹ̀ àwọn ohun òde tí kò kó sínú rẹ̀, kò sì rọ́pò
coverage tí a gbalejo, àwọn matrix ìdánwò, package tàbí ẹ̀rí ìmúlọ. Àkójọ àlàyé tó wà nísàlẹ̀
jẹ́ ìtọ́kasí, kì í ṣe ẹ̀rí pé gate kan ṣiṣẹ́ ní tòótọ́.

Àwọn script wà lábẹ́ `scripts/check/` (àwọn gate ìlànà) àti `scripts/quality/` (ẹ̀rọ ratchet).
Orísun òtítọ́ CI ni `.github/workflows/ci.yml`.

### Atejade-mimọ ilera iwe aṣẹ

`.github/workflows/i18n-base-health.yml` ṣe akiyesi ilera iwe lẹhin titari ti o yan si `main` ati `release/v*`, ati lori fifiranṣẹ afọwọṣe. Ajọ rẹ awọn iwe ideri, root Markdown, `llm.txt`, itumọ state/configuration ati ohun elo i18n ti o yẹ. Iṣẹ `Published base documentation health` ẹyọkan lo Ubuntu ti gbalejo ati akoko ipari iṣẹju marun. O ṣe afọwọsi kika-nikan ati kọ iwe-ẹri iwadii laisi fifi sori ẹrọ igbẹkẹle, itumọ tabi isọdọmọ ipinlẹ.

`scripts/i18n/check-base-health.mjs` nbeere odo-hash orisun, sonu-afojusun, ibi-afẹde-hash, stale-itumọ ati awọn aiṣedeede kaṣe apakan. O tun fọwọsi aaye document/locale mojuto lọwọlọwọ ati ẹri ti o gbasilẹ. Ọrọ aiṣedeede, agbegbe ti ko pe tabi oluṣayẹwo idilọwọ mu `INCOMPLETE` jade; fiseete ti a fọwọsi gbejade `FAIL`. Mejeeji pada ipo ijade ti o kuna. Iwe-ẹri naa ni owun lati ṣayẹwo SHA, ṣiṣiṣẹsẹhin, ṣiṣe ati igbiyanju, ati pe o wa ni idaduro bi `i18n-base-health-<sha>-<run>-<attempt>`.

Eyi jẹ akiyesi ominira ti ipilẹ ti a tẹjade. Ko ṣe afikun PR tabi iṣẹlẹ akojọpọ-ẹgbẹ, ṣayẹwo PR ti o nilo, inagijẹ npm tabi ọmọ ẹgbẹ profaili ọlọjẹ-imi. Oluyẹwo ti o wa labẹ tun ṣe idiwọ gbogbo awọn kilasi marun ni ipo pipe. Arinrin igbaradi PR si maa wa lọtọ lati gbigba. Igbesoke aṣeyọri ko le yi abajade ilera ti o kuna sinu PASS.

PR lasan nlo `--preflight` pẹlu ijabọ ipilẹ ti ipilẹṣẹ nipasẹ `--baseline-evidence`. O le fi orisun Gẹẹsi silẹ ni isunmọ nikan nigbati igbasilẹ itumọ pipe ati awọn baiti ibi-afẹde gangan ko yipada lati ipilẹ gangan yẹn. Ibi-afẹde tuntun tabi awọn aiṣedeede kaṣe apakan ṣi dina, ati pe ẹri ti ko pe ko le fun ni aṣẹ igbaradi. Ijabọ naa ṣafihan `preparationPending` ati `mergeReady` lọtọ: igbaradi aṣeyọri ko ṣe awọn itumọ isunmọ lati dapọ. Sọ awọn digi ti o kan sọ ninu oludije ti o ṣajọ ṣaaju gbigba wọle. Oludije ti isinyi Mergify ti o gbẹkẹle, `merge_group`, awọn titari ẹka ati afọwọṣe CI nṣiṣẹ lo oluṣayẹwo pipe, laisi `--warn` tabi idariji-ikuna-jogun. Awọn hashes ibi-afẹde ti o padanu ati iwọn ti o dinku nipasẹ awọn faili ipilẹ ti o ti gbasilẹ ko le ṣe idajo pipe aṣeyọri kan.

### Tu PR -ọna-yara silẹ (`quality.yml`)

`.github/workflows/quality.yml` ṣe afikun CI lori main/release PRs, titari si `main`, fifiranṣẹ ati dapọ awọn ẹgbẹ. PRs lo awọn sọwedowo iyara ti a fiwe-ọna. Ikole ẹda-ara ti alaabo patapata ti yọkuro; awọn sọwedowo build/package/boot gidi wa ni CI. Suite ẹyọkan ati vitest nṣiṣẹ nikan ni CI (`Unit Tests (N/8)` ati `Vitest`).

| Job                                              | Ààlà                                                                                                                                                                                                  | Ìdènà             |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------- |
| `Docs Gates (fast-path)`                         | Docs/code PRs; API docs refs ati awọn docs-gbogbo                                                                                                                                                     | Bẹẹni             |
| `Fast Quality Gates`                             | koodu PRs; awọn sọwedowo aimi, sọwedowo oriṣi, oriṣi dasibodu, awọn idanwo ẹyọkan ti o ni ipa                                                                                                         | Bẹẹni             |
| `Forgotten sibling tests`                        | koodu PRs; yi pada modulu itopase si aimi awọn onibara ati oludije sibling igbeyewo; agba ati awọn ipa-ọna agbewọle ti o ni agbara jẹ ijabọ bi awọn iwadii imọran, pẹlu awọn imukuro atokọ ti itọkasi | **Igbaninimoran** |
| `No new ESLint warnings`                         | koodu PRs; suppressions-mọ lint oluso                                                                                                                                                                 | Bẹẹni, pẹlu orita |

#### Iroyin idanwo arakunrin ti o gbagbe

`npm run check:forgotten-sibling-tests` nṣiṣẹ bi igbesẹ imọran ti `Fast Quality Gates` o si tun lo ipinnu agbewọle lẹhin maapu ipa-idanwo. Fun gbogbo module iṣelọpọ ti o yipada, o ṣe ijabọ awọn ẹwọn `changed module/symbol -> static consumer -> candidate sibling test` ipinnu ipinnu nigbati idanwo oludije ko si ni iyatọ ibeere-fa. Akopọ Markdown ati abajade JSON ti wa ni idaduro bi iṣẹ ọna iṣan-iṣẹ `forgotten-sibling-tests` fun isọdiwọn ṣaaju yiyọkuro eyikeyi.

Awọn agbewọle ilu okeere ati awọn agbewọle ti o ni agbara jẹ awọn iwadii ipinnu ipinnu nikan; nwọn kò ṣẹda a ìdènà wiwa. Awọn imukuro ti a ṣe ayẹwo n gbe ni `config/quality/forgotten-sibling-allowlist.json`. Titẹ sii kọọkan gbọdọ lorukọ olumulo ati idanwo oludije, funni ni oye kan pato, ati sopọ ọrọ GitHub kan tabi ibeere fa. Awọn titẹ sii aiṣedeede kuna pipade. Awọn imukuro ko le dinku idanwo oludije ti paarẹ tabi iyatọ ti o ṣafikun `.skip`/`.todo`; irẹwẹsi irẹwẹsi ati iboju iparada miiran jẹ ohun ini nipasẹ ẹnu-ọna `check:test-masking` dina ominira.

#### Àwọn eto typecheck méjì ń dáhùn lọ́nà yàtọ̀

`typecheck:core` (`noImplicitAny: false`) / `typecheck:noimplicit:core` (`noImplicitAny: true`) àti `check:build-typecheck` ń ṣàkójọpọ̀ àwọn ètò ọ̀tọ̀ọ̀tọ̀ lábẹ́
àwọn àṣàyàn ọ̀tọ̀ọ̀tọ̀, fáìlì kan náà sì lè mọ́ ní ọ̀kan, kí ó sì kún fún àṣìṣe ní èkejì.

`tsconfig.build.json` ṣètò `"strict": false`, nítorí náà `noImplicitAny` ti wa ni pipa. Àtòjọ
core ń ṣàkójọpọ̀ àtòjọ fáìlì 27 tí a ti yàn pẹ̀lú àwọn àṣàyàn tó muna jù, ó sì ń tẹ̀lé
àwòrán ìgbéwọlé ti àkọsílẹ̀ kọ̀ọ̀kan, nítorí náà àwọn fáìlì tí kò fara hàn nínú ètò
ìkọ́lé ṣì ń gba àyẹ̀wò níbẹ̀.

Àbájáde náà ṣe pàtàkì nígbà tí a bá ń pinnu bóyá a ti tẹ fáìlì kan dáadáa: **àìsí àyẹ̀wò
kankan lábẹ́ `check:build-typecheck` kò túmọ̀ sí àìsí àṣìṣe kankan**. Yíyọ
`@ts-nocheck` kúrò nínú fáìlì 26 fi hàn pé 23 nínú wọn mọ́ nínú ètò ìkọ́lé; mẹ́rìndínlógún
nínú àwọn wọ̀nyẹn sì ṣàfihàn tó fẹ́rẹ̀ẹ́ jẹ́ 120 àṣìṣe implicit-any nínú ètò tó muna.
Ṣàyẹ̀wò méjèèjì kí o tó pè fáìlì kan ní mímọ́.

#### `check-ui-value-drift` — stale-translation gate

Ó ń rí ìfàsẹ́yìn i18n kan ṣoṣo tí àwọn ẹnu-ọ̀nà yòókù kò lè rí ní ìṣètò: a tún iye Gẹ̀ẹ́sì kan
kọ, ṣùgbọ́n àwọn ìtumọ̀ tí a dá láti inú Gẹ̀ẹ́sì _tẹ́lẹ̀_ ṣì wà, nítorí náà
àwọn aṣàmúlò tí kì í lo Gẹ̀ẹ́sì ṣì ń ka ẹ̀dà tí a kọ pẹ̀lú ìdánilójú, ṣùgbọ́n tí kò tọ́ mọ́.

Èyí ṣẹlẹ̀ gan-an nínú ẹ̀yà tí a tú jáde. A tún `oauthModal.googleOAuthWarning` kọ nígbà tí olùrànlọ́wọ́
ìwọlé Antigravity dé (#5203); **39 nínú 43 locales** pa ọ̀rọ̀ tó ń sọ fún àwọn oniṣẹ́ láti “daakọ
URL kíkún kí wọ́n sì lẹ̀ ẹ́ sí ìsàlẹ̀” mọ́ — ìṣàn kan tí kò lè parí fún provider yẹn. A kò
ṣàkíyèsí rẹ̀ títí di #8463 nítorí pé:

- `sync-ui-keys` ń fi àwọn kọ́kọ́rọ́ tí ó **ṣàìsí** nìkan kún un, kì í ṣe àwọn tí ó **ti di àtijọ́**;
- `check-ui-keys-coverage` ń ka _wíwà_ kọ́kọ́rọ́, nítorí náà ìtumọ̀ tí ó ti di àtijọ́ ni a kà sí èyí tí a ti bo;
- `check-translation-drift` ń tọpinpin àwọn àwòkọ docs `docs/i18n/<locale>/**.md` —
  kò ka `src/i18n/messages/*.json` rárá. Ó ti ń dí nínú job `docs-sync-strict` láti ìmúdójúìwọ̀n
  2026-09: ṣàtúnṣe doc pàtàkì kan → `npm run i18n:run -- --files=<doc>` (ní ìpele section, kò ná púpọ̀).

**Ó mọ diff, kò gbára lé baseline.** Ó ń fi `en.json` ní merge base wé
working tree; fún gbogbo kọ́kọ́rọ́ tí iye Gẹ̀ẹ́sì rẹ̀ yí padà, locale èyíkéyìí tí ó ṣì ní
ìtumọ̀ tí a kò fọwọ́ kàn ti di àtijọ́. Èyí mọ̀ọ́mọ̀ **di gbèsè tó ti wà tẹ́lẹ̀ mọ́lẹ̀** — diff
kò lè fi hàn Gẹ̀ẹ́sì àtijọ́ wo ni ìtumọ̀ tó ti wà fún ìgbà pípẹ́ ti wá, nítorí náà ẹnu-ọ̀nà náà
ń ṣàyẹ̀wò ohun tí àyípadà lọ́wọ́lọ́wọ́ fọwọ́ kàn nìkan. Ọ̀nà míì (baseline hash fún kọ́kọ́rọ́ kọ̀ọ̀kan) yóò gba
fáìlì tí a ṣe jáde tó tó ~600 KB, ìlọ́po mẹ́ta baseline tó tóbi jù lọ tó wà, tí yóò sì máa yí padà lórí gbogbo i18n PR.

Ọ̀nà méjì ló wà láti mú un tẹ́lọ́rùn:

1. ṣe ìmúdójúìwọ̀n àwọn ìtumọ̀ tí ó kàn, tàbí
2. ṣètò wọn sí `__MISSING__:<new english>` — runtime yóò wá pèsè Gẹ̀ẹ́sì tí a ti ṣàtúnṣe
   (`src/i18n/request.ts::deepMergeFallback`, #7258), a ó sì fi kọ́kọ́rọ́ náà sínú ìlà fún ìtumọ̀.

Tí **ìtumọ̀** ọ̀rọ̀ náà bá yí padà, ó dára láti **tún kọ́kọ́rọ́ náà lorúkọ**: kọ́kọ́rọ́ tuntun kò lè jogún
ìtumọ̀ tí ó ti di àtijọ́. Èyí ni àpẹẹrẹ tí #8463 lò.

```bash
npm run i18n:check-value-drift          # ìmúṣẹ líle (èyí tí CI ń ṣiṣẹ́)
npm run i18n:check-value-drift:warn     # ìjábọ̀ nìkan
BASE_REF=origin/release/vX.Y.Z npm run i18n:check-value-drift
```

Àwọn ẹnubodè value-drift àti new-key ń lo ìfiwéra aláìṣeéyípadà kan náà láti inú
`scripts/i18n/resolve-ui-diff-base.mjs`. Workflow náà ń fi base, base-tip àti
candidate SHAs kan náà ránṣẹ́ sí àwọn àyẹ̀wò méjèèjì. Àwọn ìṣiṣẹ́ PR/base-retarget, push àti merge-group ń lo event
context wọn. Fífi candidate branch kan ránṣẹ́ nílò PR tí ó ṣí sílẹ̀ gan-an fún un tàbí input
`i18n_base_sha` tí a sọ ní pàtó. Dispatch tàbí scheduled observation ti `main` tàbí `release/vX.Y.Z`
láìsí input yẹn máa ń fi commit tó kẹ́yìn wé first parent rẹ̀; kì í ṣe audit fún
gbogbo gbèsè ìtumọ̀ tí a jogún. Local invocation nílò comparison base tí a sọ ní pàtó,
fún àpẹẹrẹ àṣẹ `BASE_REF` tó wà lókè.

Comparison context tí kò sí tàbí tí kò ṣe kedere, required catalog tí kò ṣeé kà tàbí tí kò bófin mu, àti
candidate tí ó yí padà máa ń ṣe àbájáde `INCOMPLETE` pẹ̀lú exit code **2**, títí kan ní warn mode.
Àwọn catalog read ń lo `scripts/i18n/read-ui-catalog.mjs`; a kì í fi empty objects
rọ́pò read failures. Bẹ́ẹ̀ ni unavailable base tàbí incomplete input kò lè fi ìdí PASS múlẹ̀.

  (`complexityNewCode=`, `cognitiveComplexityNewCode=`, `deadExportsNewCode=` nínú àkọsílẹ̀);
- **ìkìlọ̀** — àpapọ̀ káríayé ní ìfiwéra pẹ̀lú ìpìlẹ̀ tí a ti dí mú. Ìyapa tí a jogún kì í fi
  àmì pupa sí PR tí kò mọwọ́-mẹsẹ̀; a máa ń tọpa ìyapa náà fún àtúnṣe nígbà ìbámu ìtújáde, iṣẹ́
  headroom sì máa ń ṣọ́ ọ.

`check:file-size` ń lo base ref gẹ́gẹ́ bí òfin tirẹ̀ (`scripts/check/check-file-size.mjs`, #8522):
ó ń ṣàyẹ̀wò gbogbo fáìlì source àti test inú tree, ó ń ka iye ìlà fáìlì kọ̀ọ̀kan ní base PR
pẹ̀lú `git show`, ó sì ń mú fáìlì kan kùnà nìkan nígbà tí ó bá dàgbà kọjá èyí tó tóbi jù láàárín ààlà ìpìlẹ̀ rẹ̀
(`frozen` / `testFrozen`, tàbí `cap` / `testCap` fún fáìlì tí kò sí nínú ìpìlẹ̀) àti ìwọ̀n rẹ̀ ní base.
Nítorí náà, fáìlì tí ó ti yapa tẹ́lẹ̀ lórí base kì í sọ PR aláìlẹ́bi di pupa.

`check:boundary:ratchet` ń lo òfin kan náà sí nọ́ńbà ẹyọ rẹ̀
(`scripts/quality/measure-boundary.mjs --ratchet --base-ref <sha>`): lórí àwọn ìṣẹ̀lẹ̀ PR, àwọn
ẹnu-ọ̀nà yíyára `quality.yml` àti iṣẹ́ lint `ci.yml` méjèèjì máa ń fi SHA ìpìlẹ̀ PR ránṣẹ́, a máa
ń díwọ̀n commit ìpìlẹ̀ láti inú export `git archive`, PR náà sì máa kùnà nìkan nígbà tí iye edge
`open-sse → src` rẹ̀ bá ju èyí tó tóbi jù láàárín `metrics.boundaryOpenSseToSrc` àti iye tó wà lórí ìpìlẹ̀ lọ. A máa ń
jábọ̀ ìyípadà ìpìlẹ̀ tó ga ju òpin lọ (`base drift herdado`), ṣùgbọ́n kò jẹ́ kí PR aláìṣẹ̀ di pupa láé; push → main
ń pa òpin gígùn mọ́, SHA ìpìlẹ̀ tí kò ṣeé yanjú sì máa padà sí i pẹ̀lú ìkìlọ̀.

Àwọn ìṣiṣẹ́ `workflow_dispatch`, àyẹ̀wò release-green àti iṣẹ́ headroom alẹ́ kò ní ìpìlẹ̀ PR
wọ́n sì ń pa ìfiwéra gígùn (àgbáyé) mọ́. Coverage, duplication àti type-coverage ṣì jẹ́ ti àgbáyé
fún báyìí (àwọn irinṣẹ́ wọn kò lè ṣe diff fáìlì-kọ̀ọ̀kan lọ́nà tí kò gbówó púpọ̀) — wọ́n jẹ́ olùdíje fún ìtọ́jú kan náà.

**Pípa ìpele náà dé ní v4.0 (LTS = ó le koko ju ti tẹ́lẹ̀ lọ, kì í ṣe "padà sí bó ṣe máa ń rí")**

1. Lórí tip mímọ́ `release/v4.0.0`: `npm run quality:headroom --json` fún àkọsílẹ̀, lẹ́yìn náà
   `npm run quality:ratchet -- --update`, `check:file-size --update`,
   `check:complexity-ratchets --update`, `check:dead-code --update`, àti `--update` fún ẹnu-ọ̀nà typecheck kọ̀ọ̀kan — gbogbo baseline máa ń sọ̀kalẹ̀ sí iye tí a díwọ̀n.
2. Pa `_policy` rẹ́ kúrò nínú `quality-baseline.json` (ó tún `--require-tighten` àti ìfipamọ́
   alẹ́ mú ṣiṣẹ́), dá `THRESHOLD = 36` (tàbí tó ga jù bẹ́ẹ̀ lọ) padà sínú `check-openapi-coverage.mjs`.
3. Mú àwọn òpin le ju iye tí a díwọ̀n lọ níbi tí modularization ti ṣàǹfààní: dá `cap` file-size padà sí 1000
   (tàbí 800), fi 5 kún àwọn òkè-ilẹ̀ coverage, dead exports 0 fún àwọn package tí a ṣe modularization sí.

## Ìpìlẹ̀ Ratchet (`quality-baseline.json`)

Ẹ́ńjìnnì ratchet (`scripts/quality/check-quality-ratchet.mjs`) máa ń ka `quality-baseline.json`
ó sì máa ń fi wé `quality-metrics.json` tí a ṣẹ̀ṣẹ̀ kó jọ. Mẹ́tríìkì èyíkéyìí tí ó bá fà sẹ́yìn
kọjá epsilon rẹ̀ yóò mú kí build náà kùnà.

Àwọn mẹ́tríìkì tí a ń tọpinpin lọ́wọ́lọ́wọ́:

| Mẹ́tríìkì              | Ìtọ́sọ́nà | Ìtumọ̀                             |
| --------------------- | ------- | --------------------------------- |
| `eslintWarnings`      | `down`  | Iye ìkìlọ̀ ESLint kò gbọ́dọ̀ pọ̀ sí i |
| `coverage.statements` | `up`    | Ìbora gbólóhùn kò gbọ́dọ̀ dín kù    |
| `coverage.lines`      | `up`    | Ìbora ìlà kò gbọ́dọ̀ dín kù         |
| `coverage.functions`  | `up`    | Ìbora iṣẹ́ kò gbọ́dọ̀ dín kù         |
| `coverage.branches`   | `up`    | Ìbora ẹ̀ka kò gbọ́dọ̀ dín kù         |

Láti ṣe ìmúdójúìwọ̀n ìpìlẹ̀ lẹ́yìn ìlọsíwájú gidi kan:

```bash
npm run quality:ratchet -- --update
git add quality-baseline.json
```

Àmì `--update` máa ń kọ àwọn iye tí a wọ̀n lọ́wọ́lọ́wọ́ sínú `quality-baseline.json`.
Ṣe commit fáìlì yìí papọ̀ pẹ̀lú àyípadà tí ó mú mẹ́tríìkì náà sunwọ̀n sí i. PR tí ó mú
mẹ́tríìkì kan sunwọ̀n sí i láì ṣe ìmúdójúìwọ̀n ìpìlẹ̀ náà ni `--require-tighten` yóò rí
(Ìpele 6A.5, ìmúṣẹ rẹ̀ ṣì ń dúró).

### CodeQL ratchet: gbigba oludije ati akojo oja ibi ipamọ

CI ni gbigba CodeQL oludije nipasẹ ẹwọn igbẹkẹle ti o fojuhan: `codeql-scan` pe matrix ede mẹrin ni `codeql.yml`, lẹhinna `codeql-admission` nṣiṣẹ `node scripts/check/check-codeql-ratchet.mjs --candidate`. `Gate / CI` nilo awọn abajade mejeeji. Didara ṣe idaduro awọn sọwedowo nọmba tirẹ ṣugbọn ko beere ọlọjẹ ṣaaju ki olupilẹṣẹ pari; `Gate / Quality` nikan kii ṣe igbasilẹ pipe. Awọn ku CodeQL nilo lori awọn oludije nikan-docs.

Eto imulo ni `config/quality/codeql-admission-policy.json` yan Awọn iṣe, C/C++, JavaScript/TypeScript ati Python, aiyipada suite ibeere, awoṣe irokeke latọna jijin ati kọ ipo ko si. Ọkọ ofurufu olupilẹṣẹ kọ igbasilẹ imuṣiṣẹ ni isunmọtosi ati awọn ẹka ni ita atokọ ibi-afẹde fojuhan. Awọn ibi-afẹde lọwọlọwọ jẹ akọkọ ati awọn idanwo adehun release/v3.8.54. ṣe afiwe atokọ ipari yii ati titari titari itọju pẹlu ẹya package; itusilẹ atẹle nilo atunyẹwo lori wiwọ. CI's itusilẹ gbooro ti o gbooro PR okunfa ti wa ni idaduro, ṣugbọn ibi-afẹde ti ko ni ibọwọ ṣe ijabọ HOLD ṣaaju isediwon dipo gbigba PASS ti ko ni iwọn.

Iṣẹ-ṣiṣe matrix kọọkan n ṣe igbasilẹ SARIF ti o ga julọ ID, ede, ẹka, ṣiṣe ati igbiyanju, idanimọ iṣan-iṣẹ olupe, iṣẹlẹ ref/head/base/merge SHA ati hash eto imulo. Awọn gbigba lati ayelujara iṣẹ ti o gbẹkẹle nikan awọn owo-iṣẹ ṣiṣe yii ati pe o jẹri awọn igbelewọn ohun-ọṣọ. O nilo gbogbo awọn ẹka mẹrin, olupilẹṣẹ aṣeyọri ati ṣiṣe ti pari ti ikojọpọ gangan kọọkan. O nlo àlẹmọ sarif_id API, kii ṣe itupalẹ tuntun ti a rii lori ẹka kan. Awọn atunṣe apa kan le tun lo awọn ẹka aṣeyọri lati igbiyanju iṣaaju ti ṣiṣe kanna ati oludije, titọju igbiyanju iṣelọpọ; olupilẹṣẹ lọwọlọwọ ti kuna ko le tun lo ẹri alawọ ewe ti tẹlẹ.

Iṣe CodeQL n duro de sisẹ, ṣugbọn imuse ti o pinni le kilo ati tẹsiwaju lẹhin ikuna kika ipo tabi idaduro ti o rẹwẹsi. Nitorina gbigba wọle jẹri sisẹ lẹẹkansii. Awọn ẹka ti o padanu, sisẹ isunmọ, kuna tabi awọn iṣẹ ti a fagilee, idanimọ ti o duro, pagination ti ko pe tabi APIs ti ko wa ni gbejade HOLD ati jade 2. Ko si iduro ti o wa titi fun ṣiṣan ọlọjẹ olominira ti o ku. PR ti ko ṣe ayẹwo ko le kọja nitori ibeere titaniji da pada 0. Iwọn ti o niwọn loke `metrics.codeqlAlerts.value` jade 1; ipilẹ ko ni dide lati fa awọn itaniji ti ẹka miiran. [Ipo ikojọpọ ati wiwa itupalẹ](https://docs.github.com/en/rest/code-scanning/code-scanning).

Awọn igbasilẹ igbasilẹ igbasilẹ ati itupalẹ IDs, awọn ẹka, awọn ẹya irinṣẹ, ref/SHA, ipilẹṣẹ ati awọn nọmba gbigbọn. Nọmba SARIF identity/result, awọn iṣiro ofin ti o kere ju ati awọn iṣẹlẹ itaniji gangan wa dandan. Awọn idanimọ PR/analysis jẹ atunyẹwo ṣaaju gbigba. Awọn sọwedowo wọnyi ṣe agbekalẹ agbegbe agbegbe atunto, kii ṣe akojo oja ti gbogbo faili orisun ti o fa jade. Iyọkuro C/C++ ko si pẹlu koodu ti ipilẹṣẹ lakoko kikọ iṣẹ akanṣe kan. Awọn iyọkuro orisun tun nilo atunyẹwo, ati ifarabalẹ olùkópa nilo ẹri ipilẹ-gangan afiwera.

`codeql-maintenance.yml` n pese awọn iwoye titari itusilẹ lọwọ ati iṣeto ọsẹ laisi pidánpidán awọn olupilẹṣẹ PR/main. `nightly-codeql-inventory.yml` ṣe itọju ipilẹ-ipilẹṣẹ jakejado lọtọ, pẹlu `--strict-measurement` ati ikuna nigbati wiwọn ko si. Rekọja oore-ọfẹ olu-ojo agbegbe kii ṣe gbigba wọle oludije. Titọpa jẹ `--update` ti o fojuhan lẹhin ti a ti rii daju kika isalẹ agbaye.

Ṣiṣan iṣẹ ilọsiwaju naa ko gbọdọ ṣe atẹjade lakoko ti iṣeto Aiyipada: GitHub kọ apapọ yẹn. Ilana ti ikede rẹ wa ni isunmọtosi titi iyipada iṣakoso ti atunyẹwo yoo ka pada. Ṣaaju ki o to titẹjade, oniṣẹ pin ibi ipamọ, head/base/tree, awọn hashes policy/patch/rollback ati ipo iṣeto ti a ṣe akiyesi; `node scripts/quality/codeql-producer.mjs verify-admin-readback` ṣayẹwo awọn ti a ti ṣe yẹ ati awọn igbasilẹ JSON gangan. Eyi jẹ ẹṣọ imọ-ẹrọ, kii ṣe ifọwọsi oniṣẹ tabi rirọpo fun mimu awọn atunkọ tuntun. Aami PR ko beere iraye si Isakoso. Yiyi pada ati iyipada aṣayẹwo eyikeyi nilo kika kika lọtọ pẹlu PR gidi, orita ati ẹri ibamu-ẹgbẹ.

Awọn orita lo awọn asare ti o gbalejo, isanwo laisi awọn iwe-ẹri ti o tẹsiwaju, ko si install/build akanṣe ninu olupilẹṣẹ, ko si si awọn aṣiri ibi-ipamọ jogun. GitHub ṣe atilẹyin ikojọpọ SARIF fun iṣẹlẹ pull_request pẹlu ami orita ti o dinku; alakosile ipaniyan idasi igba akọkọ jẹ eto imulo GitHub. Maṣe lo pull_request_target lati ṣiṣẹ koodu ti ko gbẹkẹle. Jẹrisi awọn igbanilaaye ami ami gangan, onínọmbà_key ati gbogbo awọn agbegbe ẹka ni canary iṣakoso ṣaaju ki o to gbero ijira naa ti pari. [Awọn ofin ikojọpọ orita](https://docs.github.com/en/code-security/reference/code-scanning/troubleshoot-analysis-errors/resource-not-accessible), [awọn ipo iṣeto ti o fi ori gbarawọn](https://docs.github.com/en/code-security/reference/code-scanning/troubleshoot-analysis-errors/two-codeql-workflows).

**Iyọkuro jẹ ipe onišẹ (Hard Rule #14)** — ko yọkuro titaniji CodeQL kan laisi gbigbasilẹ idalare imọ-ẹrọ ninu asọye ifasilẹ: `won't fix` fun ibeere ilana-oke, `used in tests` fun imuduro idanwo kan, `false positive` fun imototo CodeQL ko le rii (tẹlẹ: `docs/security/ERROR_SANITIZATION.md`).

## Fífipamọ́ Àwọn Ìdínkù Ratchet — ọ̀nà sísàlẹ̀ (#8584)

Ratchet náà jẹ́ aládàáṣe ní ìdajì nìkan, ìdajì tí kò tọ́ sì ni. **Gígbé** cap kan sókè jẹ́
àtúnṣe JSON ọwọ́ tí ó gba ìṣẹ́jú-àáyá mẹ́wàá, tó sì jẹ́ ọ̀nà tó yára jù láti ṣí PR pupa sílẹ̀.
**Sísọ** ọ̀kan kalẹ̀ nílò kí ẹnìkan ṣiṣẹ́ `--update` kí ó sì commit àbájáde náà — títí di ìgbà tí
job `bank-ratchet-shrinks` dé, kò sí workflow kankan tó ń ṣiṣẹ́ ẹ. Àbájáde tí a wọn
(2026-07-25): àwọn fáìlì frozen 18 ti wà ní tàbí lábẹ́ cap ila 800 fún fáìlì tuntun, èyí tó burú jù
wà ní 132× (`src/shared/validation/schemas.ts`, ila 19 tí ó ru cap 2,523); òrùlé
complexity rìn láti `1794 → 2169` kọjá àwọn àkọsílẹ̀ rebaseline bíi ~37 pẹ̀lú ìdínkù kan ṣoṣo
(−1); a sì kọ “mú un le sí i nípasẹ̀ `--update` ní cycle tó kàn” ní ìgbà 31, tí a sì ṣe é
lẹ́ẹ̀kan ṣoṣo. Cap kan tí ó pé ju kóòdù tó mú un wá lọ máa ń sọ gbogbo decomposition tí a ti parí
di ààyè ìdàgbàsókè fún ẹnikẹ́ni tó bá tún fáìlì náà ṣe lẹ́yìn náà, láìsí ariwo.

`nightly-release-green.yml` → job **`bank-ratchet-shrinks`** ń pa àyípo yẹn mọ́:

|            |                                                                                                              |
| ---------- | ------------------------------------------------------------------------------------------------------------ |
| Ṣiṣẹ́ lórí  | `schedule` (3×/ọjọ́) + `workflow_dispatch` — pẹ̀lú ìmọ̀ọ́mọ̀ **kì í ṣe** `push`                                   |
| Ń wọn      | `release/vX.Y.Z` tó ga jù, resolution kan náà + injection guard bí `release-green`                           |
| Ń kọ       | `check:file-size --update` àti `check:complexity-ratchets --update` (a kọ́ méjèèjì láti dín kù nìkan)         |
| Ń ṣàyẹ̀wò   | `npm run check:ratchet-bank` (`scripts/quality/verify-ratchet-bank.mjs`)                                     |
| Ń fi ránṣẹ́ | PR kan tí ó jẹ́ ti ìsinsìnyí nígbà gbogbo sí release branch — a máa ń ṣe force-update rẹ̀, a kì í fi í ṣe spam |

A ń ṣe fífipamọ́ náà ní àkójọpọ̀ dípò fún push kọ̀ọ̀kan nítorí kò ní ìbéèrè latency kankan (ìdínkù tí a
fi pamọ́ láàárín 8h dára) nígbà tí iṣẹ́ kan fún merge kọ̀ọ̀kan yóò tún PR branch kọ́ léraléra
lákòókò àwọn ìpolongo merge, yóò sì san owó fún ESLint walk kíkún ní gbogbo ìgbà. Ìṣàwárí ṣì wà lórí
push (`release-green`); fífipamọ́ nìkan ni a ń ṣe ní àkójọpọ̀.

### Olùṣàyẹ̀wò ààbò

Job náà ń kọ sínú àwọn baseline láìsí àbójútó, nítorí náà `verify-ratchet-bank.mjs` ni ohun tó mú
èyí ṣeé tẹ́wọ́ gbà. Ó ń ṣe diff igi lẹ́yìn `--update` pẹ̀lú `HEAD`, ó sì **dá job náà dúró
kí commit kankan tó wà** — láì ṣí PR kankan — àyàfi tí gbogbo ìyípadà bá jẹ́ ọ̀kan nínú:

- entry onínọ́mbà `frozen` / `testFrozen` tí a **dín kù** tàbí **yọ kúrò**
- `complexity-baseline.json` → `count` tí a **dín kù**
- `quality-baseline.json` → `metrics.cognitiveComplexity.value` tí a **dín kù**

Ohunkóhun mìíràn yóò kùnà: gbígbé nọ́ńbà kan sókè, fífi entry kan kún un, yíyí `cap`/`testCap` padà, tàbí
píparẹ́/àtúnkọ àkọsílẹ̀ `_rebaseline_*` kan (àwọn àkọsílẹ̀ wọ̀nyẹn ni ipa-ọ̀nà audit tó ṣàlàyé ìdí tí
òrùlé kọ̀ọ̀kan fi wà, a sì tọ́jú wọn sínú object `frozen` kan náà pẹ̀lú àwọn entry fáìlì).
Bot kan tó lè gbé cap sókè yóò burú ju ipò tó wà lọ dájúdájú. Regression
guard: `tests/unit/verify-ratchet-bank.test.ts`.

Job náà kì í push sí `release/*` láéláé — ènìyàn kan ló máa merge PR náà, nítorí náà ìwọ̀n búburú
kò lè wọlé láìsí àyẹ̀wò.

## Ìlànà Àtòjọ Ìyọ̀ǹda

Gbogbo ẹnu-ọ̀nà àyẹ̀wò tí kò lè kùnà nítorí àwọn ìrúfin tó ti wà tẹ́lẹ̀ máa ń lo àtòjọ ìyọ̀ǹda tí a ti dí múlẹ̀
(fún àpẹẹrẹ, `KNOWN_STALE_DOC_REFS`, `KNOWN_MISSING`, `KNOWN_RAW_SQL`). Ìlànà náà ni:

**Ṣàtúnṣe ìdí pàtàkì tó fa ìṣòro náà; lo àtòjọ ìyọ̀ǹda nìkan nígbà tí ìrúfin náà ti wà tẹ́lẹ̀ tí
kò sì ṣeé ṣàtúnṣe nínú PR kan náà.**

Nígbà tí o bá ń ṣàfikún àkọsílẹ̀ sí àtòjọ ìyọ̀ǹda:

1. Fi àlàyé sínú comment kan nípa ìdí rẹ̀.
2. Tọ́ka sí issue tí ń tọpinpin rẹ̀ (fún àpẹẹrẹ, `// #3498 — Phase 2 feature, not yet implemented`).
3. Yọ àkọsílẹ̀ náà kúrò nínú PR kan náà tó ṣàtúnṣe ìrúfin náà — àkọsílẹ̀ àtijọ́ tí kò tún
   ń fi ìrúfin tó ṣì ń ṣiṣẹ́ pamọ́ jẹ́ àbùkù fúnra rẹ̀ (ìmúlò stale-enforcement 6A.3 yóò
   mú kí ẹnu-ọ̀nà àyẹ̀wò kùnà lórí àkọsílẹ̀ àtòjọ ìyọ̀ǹda tí kò ní ìbáṣepọ̀ mọ́ nígbà tí a bá ti ṣàmúlò rẹ̀).

**Má ṣe** ṣàfikún àwọn àkọsílẹ̀ àtòjọ ìyọ̀ǹda láti mú kí àwọn ìdánwò kọjá ní kíákíá. Ẹnu-ọ̀nà àyẹ̀wò aláwọ̀ ewé pẹ̀lú
àtòjọ ìyọ̀ǹda tó ń pọ̀ sí i ń fúnni ní ìmọ̀lára èké nípa dídára.

### Nígbà tí ẹnu-ọ̀nà àyẹ̀wò kan bá kùnà lórí PR rẹ

1. **Ka àbájáde ẹnu-ọ̀nà àyẹ̀wò náà dáadáa** — ó máa sọ fáìlì tàbí àmì wo gan-an ló rú
   òfin náà fún ọ.
2. **Ṣàtúnṣe ìrúfin náà** — ọ̀pọ̀ àwọn ẹnu-ọ̀nà àyẹ̀wò jẹ́ àyẹ̀wò ètò-fáìlì tó ń fúnni ní àbájáde kan náà ní gbogbo ìgbà, tí yóò sì kọjá ní kété
   tí kóòdù náà bá tọ̀nà.
3. **Tí ìrúfin náà bá ti wà tẹ́lẹ̀** (ìyẹn ni pé, kì í ṣe ìwọ ló dá a sílẹ̀ ṣùgbọ́n ẹnu-ọ̀nà àyẹ̀wò náà ti
   bẹ̀rẹ̀ sí í bo ó): ṣàfikún àkọsílẹ̀ àtòjọ ìyọ̀ǹda pẹ̀lú comment ìdáláre àti issue ìtọpinpin.
4. **Tí ẹnu-ọ̀nà àyẹ̀wò náà bá jẹ́ ratchet** (coverage, àwọn ìkìlọ̀ ESLint, àtúnṣe, complexity):
   ìyípadà rẹ mú kí òṣùwọ̀n náà burú sí i. Ṣàtúnṣe ìṣòro tó fa á, tàbí (nígbà díẹ̀ gan-an) ṣiṣẹ́
   `npm run quality:ratchet -- --update` tí ìyípadà náà bá jẹ́ àmọ̀ọ́mọ̀ tí ìdínkù nínú òṣùwọ̀n náà
   sì jẹ́ ìtẹ́wọ́gbà — ṣùgbọ́n ṣàkọsílẹ̀ ìdí rẹ̀ sínú àpèjúwe PR.
5. **Àwọn ẹnu-ọ̀nà àyẹ̀wò ìmọ̀ràn** (`continue-on-error: true`) wà fún fífúnni ní ìsọfúnni — wọn kì í dí
   ìdapọ̀ dúró ṣùgbọ́n wọ́n máa hàn nínú àkótán CI. Ṣàtúnṣe wọn síbẹ̀.

## Ṣíṣàfikún Ẹnu-ọ̀nà Àyẹ̀wò Tuntun

1. Ṣẹ̀dá `scripts/check/check-<name>.mjs` (tàbí `.ts`). Àwọn ẹnu-ọ̀nà àyẹ̀wò ìlànà máa jáde pẹ̀lú 0/1.
   Àwọn ẹnu-ọ̀nà àyẹ̀wò irú ratchet máa ń fi òṣùwọ̀n kan ránṣẹ́ sí `quality-metrics.json` nípasẹ̀ `collect-metrics.mjs`.
2. Ṣàfikún `"check:<name>": "node scripts/check/check-<name>.mjs"` sí `package.json`, kí o sì
   mú alias náà àti àṣẹ rẹ̀ gan-an bá ara wọn mu nínú `config/quality/gate-manifest.json`.
   Lo ìmúṣiṣẹ́pọ̀ kan náà nígbà tí o bá ń yí alias ìfàṣẹsí tó ti wà padà tàbí tí o bá ń yọ ọ́ kúrò.
   Ṣiṣe `npm run check:gate-manifest`; hook pre-commit àti ìsọ̀rí ìyípadà CI
   ń mú kí àdéhùn yìí di dandan.
3. So ó pọ̀ sínú `.github/workflows/ci.yml` lábẹ́ iṣẹ́ tó yẹ
   (ìlànà → `lint` tàbí `docs-sync-strict`; ratchet → `quality-gate`).
4. Tí ó bá ní àtòjọ ìyọ̀ǹda, lo `reportStaleEntries()` láti
   `scripts/check/lib/allowlist.mjs` kí a lè ṣàwárí àwọn àkọsílẹ̀ àtijọ́ láìfọwọ́ṣe.
5. Kọ ìdánwò kan sínú `tests/unit/build/` tó ń bo ọgbọ́n ìṣàwárí ẹnu-ọ̀nà àyẹ̀wò náà.
6. Ṣàfikún ìmúdójúìwọ̀n sí ìwé yìí (ṣàfikún ìlà kan sí tábìlì iṣẹ́ tó yẹ).

### Ìdapọ̀ / yíyọ àtúnṣe (aládàáṣe, ewu kékeré)

A fìdí olùdíje kọ̀ọ̀kan múlẹ̀ ní ìbámu pẹ̀lú ipò gate tó ń ṣiṣẹ́ ní 2026-06-17 (gbẹ́kẹ̀lé-ṣùgbọ́n-ṣàyẹ̀wò);

àwọn àrọ́pò tó mọ́.

- **`check:docs-sync` ń ṣiṣẹ́ lẹ́ẹ̀mejì** — lọ́tọ̀ nínú iṣẹ́ `lint` àti lẹ́ẹ̀kan sí i nínú `check:docs-all` (`docs-sync-strict`) àti hook husky pre-commit. ✅ **A TI ṢE É** — a yọ ìpè `lint` adádúró kúrò.
- **Àyẹ̀wò CVE** — ❌ **Kì í ṣe ìdapọ̀ tó mọ́.** `audit:deps` ń dí àwọn ìkìlọ̀ ewu tó ṣe pàtàkì àti àwọn audit tí kò pé kọjá gbogbo lockfile márùn-ún, nígbà tó ń ṣàfihàn àwọn ìkìlọ̀ ewu gíga gẹ́gẹ́ bí ìkìlọ̀ lábẹ́ ìlànà lọ́wọ́lọ́wọ́; `check:vuln-ratchet` (osv) máa ń kùnà nìkan nígbà tí _ìfàsẹ́yìn_ bá wà ní ìfiwéra pẹ̀lú baseline tí a commit sínú rẹ̀, ó sì ń kọ àwọn ìwọ̀n tí kò sí nígbà tí a bá béèrè wọn. Ìtumọ̀ wọn yàtọ̀ — yíyọ `audit:deps` kúrò yóò mú kí a pàdánù gate ewu-pàtàkì alákòóso àti àwọn ẹ̀rí audit package olómìnira. Jẹ́ kí àwọn méjèèjì wà.
- **Ìṣàwárí cycle** — ✅ **A TI ṢE É** (#15159 G-01/G-02). Ọ̀rọ̀ àtijọ́ níbí pe `check:cycles` ní gate “tó ń kọjá, tí a sì ti ṣàṣàyàn rẹ̀” ó sì ṣàlàyé pé kí ó máa dí nítorí `check:circular-deps` (dpdm) ṣàlàyé cycle 91. Ìkọjá yẹn jẹ́ **ìkọjá èké**: `check:cycles` ṣàyẹ̀wò subdirectory 5 (file 450), ó bá `import|export … from` aimi nìkan mu, ó sì sọ gbogbo specifier `@/` àti `@omniroute/open-sse/` nù, nítorí náà kò lè rí àwọn cycle dynamic-import + alias tí ó pọ̀ jù nínú repo. A ti tún un ṣe: gate náà ń rìn káàkiri `src` + `open-sse` (file 5023), ó ń kó àwọn specifier láti inú TypeScript AST (nítorí náà `import("…")` wúlò ṣùgbọ́n `typeof import("…")` tó wà ní ipò type kò wúlò), ó sì ń yanjú `paths` tsconfig.
