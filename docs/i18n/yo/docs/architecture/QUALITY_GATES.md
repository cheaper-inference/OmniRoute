## Oja ẹnu-bode ati awọn profaili ipaniyan

### Gbigba oludije

CI ati Awọn Gates Didara n ṣiṣẹ ni ọkọọkan ṣe idajo iduroṣinṣin kan: `Gate / CI` ati `Gate / Quality`. Eto imulo gbigba wọn ti ikede ṣe iṣiro gbogbo iṣẹ oke bi o ṣe nilo tabi imọran. Iṣẹ ti o nilo gbọdọ ṣaṣeyọri: sonu, fagilee, fo, isunmọtosi ati awọn abajade aimọ ko le fi idi PASS mulẹ. Awọn iwe aṣẹ ti o wulo-nikan tabi katalogi-sọtọ le jẹ ki ọna koodu ko wulo; osere PR kii ṣe oludije ti o gba. Aami `hotfix` kan ko yọ ẹri kuro.

Awọn ṣiṣan iṣẹ mejeeji bo PRs sinu awọn ẹka main/release, titari si `main`, fifiranṣẹ afọwọṣe ati awọn iṣẹlẹ akojọpọ-ẹgbẹ. Titari, firanṣẹ ati dapọ-ẹgbẹ ṣiṣe aṣayan ni kikun. Titari si `release/**` ko bẹrẹ wọn (2026-10-18): iyipada kọọkan tẹlẹ ti ṣiṣẹ matrix naa lori PR rẹ ati apapọ apapọ jẹ iṣẹ Tu-Green (`docs/ops/RUNNER_BOX.md` → Hosted lene). Awọn orita ati awọn ẹgbẹ dapọ lo awọn asare ti a ti gbalejo fun awọn iṣẹ ti bibẹẹkọ yan awọn asare ti ara ẹni; Agbara gbigbalejo ti o to gbọdọ jẹ ijẹrisi ṣaaju yiyi.

Arinrin PR nṣiṣẹ awọn sare aṣayan. Awọn ọna `full-code` ati `full-code-e2e` ti eto imulo gbigba (E2E, isọpọ, artifact package, Electron èéfín, Bun SQLite, ilolupo eda ati awọn alabara ilana) ṣiṣẹ nikan lori apẹrẹ isinyi Mergify tabi lori ṣiṣe ni kikun: `gh workflow run ci.yml --ref <branch>`.

Iwe-ẹri JSON kọọkan n ṣe idanimọ SHA ti a ṣayẹwo, ṣiṣe ṣiṣiṣẹ ati igbiyanju. CLI na kọ aiṣedeede checkout/event SHA kan. Awọn idanwo ṣiṣiṣẹsiṣẹpọ di ọmọ ẹgbẹ eto imulo si atokọ `needs` iṣẹ idajo nitorina ọna tuntun tabi yiyọ kuro ko le parẹ ni idakẹjẹ. Awọn owo-owo naa bo ṣiṣan iṣẹ tiwọn, kii ṣe titẹjade, imuṣiṣẹ, tabi awọn inu inu ẹrọ aṣayẹwo imọran ti o wa tẹlẹ. Ṣiṣẹ awọn orukọ ayẹwo mejeeji ni awọn ofin ẹka jẹ iyipada iṣakoso lọtọ; fifi awọn iṣẹ wọnyi kun ko ṣe aabo fun ẹka kan funrararẹ.

### Àkópọ̀ isinyi

Aami `queue` nfi PR ranṣẹ si isinyi Mergify (`.mergify.yml`). Mergify ṣi PR osere kan lori ẹka `mergify/merge-queue/`, CI nṣiṣẹ yiyan ni kikun nibẹ, ati pe PR atilẹba dapọ nigbati `Gate / CI`, `Gate / Quality` ati `Merge integrity (changelog + generated skills)` kọja.

Mergify kọ akopọ isinyin rẹ sinu apejuwe yiyan, ati pe awọn ohun elo miiran le ṣatunkọ paapaa. Iṣẹlẹ `pull_request` `edited` kan lori iru apẹrẹ kan gba ẹgbẹ concurrency tirẹ (`-queue-edit-<run_id>`) nitori naa ko le fagilee ṣiṣe gidi ti osere naa, o si fo ẹnu-bode ati matrix naa. Nikan `Merge integrity` ṣi nṣiṣẹ. Iṣẹ ẹnu-ọna ti o fo naa n gbe orukọ ayẹwo ti o yatọ, nitori Mergify ka `Gate / CI` ti o fo silẹ gẹgẹbi ayẹwo ti o kuna ati pe o yọkuro PR naa.

Lẹhin isọdi, titari ko ni beere nigbagbogbo PR. Ọrọìwòye `@mergifyio queue` lori rẹ.

### Iṣiro ọlọjẹ aimi

Oja ọja npm-alias ti ikede ati awọn ọmọ ẹgbẹ ọlọjẹ-imi gbe ni `config/quality/gate-manifest.json`. Ṣiṣe `npm run check:gate-manifest` lati fọwọsi awọn orukọ iwe afọwọkọ ati awọn aṣẹ gangan lodi si `package.json`; awọn afikun, yiyọ kuro ati pipaṣẹ fiseete kuna mejeeji kio agbegbe ati awọn iṣẹ isọdi-iyipada ni CI. Inagijẹ kii ṣe iṣẹ iṣan-iṣẹ, apẹẹrẹ matrix tabi ọran idanwo: awọn iṣiro wọnyi ko gbọdọ gbekalẹ bi paarọ.

Lo `npm run quality:scan -- --list` tabi `npm run quality:scan:fast -- --list` lati ṣayẹwo awọn inagijẹ ti o yan laisi ṣiṣe wọn. Isare n pe aaye titẹsi npm, nitorinaa akoko asiko rẹ (pẹlu Bun nibiti a ti tunto) ti wa ni ipamọ. Awọn igbasilẹ ti o farahan ni ita awọn profaili wọnyẹn bi a ti pe ni lọtọ, ati awọn aṣẹ itọju jẹ eewọ ni awọn profaili ọlọjẹ kika-nikan.

Awọn profaili wọnyi bo ọlọjẹ aimi nikan. Wọn ko jẹri awọn idanwo ọja, agbegbe, apoti, awọn sọwedowo ita tabi gbigba idasilẹ ni kikun ti oludije. Gbigbawọle ṣiṣan iṣẹ nlo `config/quality/admission-policy.json` ti o sopọ ati `scripts/quality/admission-verdict.mjs`. Awọn profaili oluwoye itusilẹ wa lọtọ; ṣayẹwo awọn sọwedowo ti o wulo ati awọn iwe-ẹri ni ominira. Oja prose ti o wa ni isalẹ jẹ itọkasi, kii ṣe ẹri pe ẹnu-bode kan nṣiṣẹ gangan.

Awọn iwe afọwọkọ n gbe labẹ `scripts/check/` (awọn ẹnubode eto imulo) ati `scripts/quality/` (ẹnjini ratchet). Orisun otitọ CI ni `.github/workflows/ci.yml`.

### Tu PR -ọna-yara silẹ (`quality.yml`)

`.github/workflows/quality.yml` ṣe afikun CI lori main/release PRs, titari si `main`, fifiranṣẹ ati dapọ awọn ẹgbẹ. PRs lo awọn sọwedowo iyara ti a fiwe-ọna. Ikole ẹda-ara ti alaabo patapata ti yọkuro; awọn sọwedowo build/package/boot gidi wa ni CI. Suite ẹyọkan ati vitest nṣiṣẹ nikan ni CI (`Unit Tests (N/8)` ati `Vitest`).

| Job                                              | Ààlà                                                                                                                                     | Ìdènà             |
| ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- | ----------------- |
| `Docs Gates (fast-path)`                         | Docs/code PRs; API docs refs ati awọn docs-gbogbo                                                                                        | Bẹẹni             |
| `Fast Quality Gates`                             | koodu PRs; awọn sọwedowo aimi, sọwedowo oriṣi, titẹ dasibodu, awọn idanwo ẹyọkan ti o ni ipa, awọn idanwo arakunrin ti o gbagbe (imọran) |
| `No new ESLint warnings`                         | koodu PRs; suppressions-mọ lint oluso                                                                                                    | Bẹẹni, pẹlu orita |
| `Merge integrity (changelog + generated skills)` | PRs ti kii ṣe apamọ; changelog ati ti ipilẹṣẹ olorijori ìsiṣẹpọ                                                                          | Bẹẹni, pẹlu orita |

#### Iroyin idanwo arakunrin ti o gbagbe

`npm run check:forgotten-sibling-tests` nṣiṣẹ bi igbesẹ imọran ti `Fast Quality Gates` o si tun lo ipinnu agbewọle lẹhin maapu ipa-idanwo. Fun gbogbo module iṣelọpọ ti o yipada, o ṣe ijabọ awọn ẹwọn `changed module/symbol -> static consumer -> candidate sibling test` ipinnu ipinnu nigbati idanwo oludije ko si ni iyatọ ibeere-fa. Akopọ Markdown ati abajade JSON ti wa ni idaduro bi iṣẹ ọna iṣan-iṣẹ `forgotten-sibling-tests` fun isọdiwọn ṣaaju yiyọkuro eyikeyi.

Awọn agbewọle ilu okeere ati awọn agbewọle ti o ni agbara jẹ awọn iwadii ipinnu ipinnu nikan; nwọn kò ṣẹda a ìdènà wiwa. Awọn imukuro ti a ṣe ayẹwo n gbe ni `config/quality/forgotten-sibling-allowlist.json`. Titẹ sii kọọkan gbọdọ lorukọ olumulo ati idanwo oludije, funni ni oye kan pato, ati sopọ ọrọ GitHub kan tabi ibeere fa. Awọn titẹ sii aiṣedeede kuna pipade. Awọn imukuro ko le dinku idanwo oludije ti paarẹ tabi iyatọ ti o ṣafikun `.skip`/`.todo`; irẹwẹsi irẹwẹsi ati iboju iparada miiran jẹ ohun ini nipasẹ ẹnu-ọna `check:test-masking` dina ominira.

#### `check-ui-value-drift` — stale-translation ẹnu-bode

Mu ọkan i18n ipadasẹhin awọn ẹnu-bode miiran ti iṣeto ko le rii: iye Gẹẹsi ti tun kọwe ati awọn itumọ ti o wa lati inu _previous_ Gẹẹsi duro lẹhin, nitorinaa awọn olumulo ti kii ṣe Gẹẹsi tẹsiwaju kika ni igboya-ọrọ, ẹda ti ko tọ.

Eleyi bawa fun gidi. `oauthModal.googleOAuthWarning` ni a tun kọ nigbati oluranlọwọ iwọle Antigravity de (#5203);** 39 ti 43 agbegbe** pa ọrọ sọ fun awọn oniṣẹ lati "daakọ URL ni kikun ki o si lẹẹmọ si isalẹ" — sisan ti ko le pari fun olupese naa. Ko ṣe akiyesi titi #8463 nitori:

- `sync-ui-keys` nikan backfills awọn bọtini ti o jẹ** ti ko si** , kii ṣe awọn ti o jẹ** diduro** ;
- `check-ui-keys-coverage` ka bọtini _presence_, nitorinaa awọn iṣiro itumọ ti o duro bi o ti bo;
- `check-translation-drift` tọpa awọn digi awọn iwe aṣẹ `docs/i18n/<locale>/**.md` — ko ka `src/i18n/messages/*.json` rara. Dinamọ ni `docs-sync-strict` iṣẹ lati igba imuṣiṣẹpọ 2026-09: ṣatunkọ doc mojuto → `npm run i18n:run -- --files=<doc>` (ipele-apakan, olowo poku).

**Iyatọ-mọ, kii ṣe atilẹyin ipilẹ.** O ṣe afiwe `en.json` ni ipilẹ idapọ si igi ti n ṣiṣẹ; fun gbogbo bọtini ti iye Gẹẹsi rẹ yipada, eyikeyi agbegbe ti o tun di itumọ ti a ko fowo kan duro. Eyi mọọmọ** didi gbese ti o ti wa tẹlẹ** — a diff ko le ṣe afihan iru Gẹẹsi atijọ ti itumọ pipẹ ti wa lati, nitorinaa ẹnu-ọna ṣe idajọ ohun ti iyipada lọwọlọwọ fọwọkan. Yiyan (ipilẹṣẹ hash bọtini-fun-kọtini) yoo jẹ iye owo ~ 600 KB ti ipilẹṣẹ, 3 × ipilẹ ti o tobi julọ ti o wa tẹlẹ, ti n tẹ lori gbogbo i18n PR.

Awọn ọna meji lati ni itẹlọrun:

1. ṣe imudojuiwọn awọn itumọ ti o kan, tabi
2. ṣeto wọn si `__MISSING__:<new english>` — asiko asiko naa lẹhinna sin Gẹẹsi ti a ṣe atunṣe (`src/i18n/request.ts::deepMergeFallback`, #7258) ati awọn ila bọtini fun itumọ.

Ti o ba ti okun** itumo** yipada, fẹ** lorukọmii bọtini** : bọtini titun ko le jogun itumọ ti o duro. Ilana #8463 ti a lo niyen.

```bash
npm run i18n:check-value-drift          # strict (what CI runs)
npm run i18n:check-value-drift:warn     # report only
BASE_REF=origin/release/vX.Y.Z npm run i18n:check-value-drift
```

**Ìpo kóòdù tuntun (Clean-as-You-Code) — láti 2026-08-30, ọ̀nà yíyára PR nìkan**

Lórí àwọn ìṣẹ̀lẹ̀ `pull_request`, `quality.yml` ń fi `--base-ref <PR base SHA>` ránṣẹ́ sí `check:file-size`,
`check:complexity-ratchets` àti `check:dead-code`. Fún `check:complexity-ratchets` àti
`check:dead-code`, ẹnubodè náà ń fi HEAD wé merge-base **ní ààlà àwọn fáìlì tí PR náà fọwọ́ kàn
nìkan** (`scripts/check/newCodeMode.mjs`: a dá merge-base náà sílẹ̀ nínú
`git worktree` àkókò-kúkúrú, ESLint/knip ń ṣiṣẹ́ níbẹ̀ àti lórí HEAD, a sì ń ṣe ìyàtọ̀ àwọn iye fún fáìlì kọ̀ọ̀kan):

- **tí ń dí ìlọsíwájú** — PR náà fi àwọn ìrúfin cyclomatic/cognitive tàbí àwọn export tí kò lò kún àwọn fáìlì tí ó yí padà
  (`complexityNewCode=`, `cognitiveComplexityNewCode=`, `deadExportsNewCode=` nínú àkọsílẹ̀);
- **ìmọ̀ràn** — àpapọ̀ gbogbo rẹ̀ ní ìfiwéra pẹ̀lú ìpìlẹ̀ tí a ti dì mú. Ìyapa tí a jogún kì í sọ
  PR aláìlẹ́bi di pupa; a tún di ìyapa náà mú nígbà ìlaja ìtúsílẹ̀, iṣẹ́ headroom sì ń ṣọ́ ọ.

`check:file-size` ń lo base ref gẹ́gẹ́ bí òfin tirẹ̀ (`scripts/check/check-file-size.mjs`, #8522):
ó ń ṣàyẹ̀wò gbogbo fáìlì source àti test inú tree, ó ń ka iye ìlà fáìlì kọ̀ọ̀kan ní base PR
pẹ̀lú `git show`, ó sì ń mú fáìlì kan kùnà nìkan nígbà tí ó bá dàgbà kọjá èyí tó tóbi jù láàárín ààlà ìpìlẹ̀ rẹ̀
(`frozen` / `testFrozen`, tàbí `cap` / `testCap` fún fáìlì tí kò sí nínú ìpìlẹ̀) àti ìwọ̀n rẹ̀ ní base.
Nítorí náà, fáìlì tí ó ti yapa tẹ́lẹ̀ lórí base kì í sọ PR aláìlẹ́bi di pupa.

`check:boundary:ratchet` ń lo òfin kan náà sí nọ́ńbà ẹyọ rẹ̀
(`scripts/quality/measure-boundary.mjs --ratchet --base-ref <sha>`): lórí àwọn ìṣẹ̀lẹ̀ PR, àwọn
ẹnu-ọ̀nà yíyára `quality.yml` àti iṣẹ́ lint `ci.yml` méjèèjì máa ń fi SHA ìpìlẹ̀ PR ránṣẹ́, a máa
ń díwọ̀n commit ìpìlẹ̀ láti inú export `git archive`, PR náà sì máa kùnà nìkan nígbà tí iye edge
`open-sse → src` rẹ̀ bá ju èyí tó tóbi jù láàárín `metrics.boundaryOpenSseToSrc` àti iye tó wà lórí ìpìlẹ̀ lọ. A máa ń
jábọ̀ ìyípadà ìpìlẹ̀ tó ga ju òpin lọ (`base drift herdado`), ṣùgbọ́n kò jẹ́ kí PR aláìṣẹ̀ di pupa láé; push → main
ń pa òpin gígùn mọ́, SHA ìpìlẹ̀ tí kò ṣeé yanjú sì máa padà sí i pẹ̀lú ìkìlọ̀.

Àwọn ìṣiṣẹ́ `workflow_dispatch`, àyẹ̀wò release-green àti iṣẹ́ headroom alẹ́ kò ní ìpìlẹ̀ PR
wọ́n sì ń pa ìfiwéra gígùn (àgbáyé) mọ́. Coverage, duplication àti type-coverage ṣì jẹ́ ti àgbáyé
fún báyìí (àwọn irinṣẹ́ wọn kò lè ṣe diff fáìlì-kọ̀ọ̀kan lọ́nà tí kò gbówó púpọ̀) — wọ́n jẹ́ olùdíje fún ìtọ́jú kan náà.

**Pípa ìpele náà dé ní v4.0 (LTS = ó le koko ju ti tẹ́lẹ̀ lọ, kì í ṣe "padà sí bó ṣe máa ń rí")**

1. Lórí tip mímọ́ `release/v4.0.0`: `npm run quality:headroom --json` fún àkọsílẹ̀, lẹ́yìn náà
   `npm run quality:ratchet -- --update`, `check:file-size --update`,
   `check:complexity-ratchets --update`, `check:dead-code --update`, àti `--update` fún ẹnu-ọ̀nà typecheck kọ̀ọ̀kan — gbogbo baseline máa ń sọ̀kalẹ̀ sí iye tí a díwọ̀n.
2. Pa `_policy` rẹ́ kúrò nínú `quality-baseline.json` (ó tún `--require-tighten` àti ìfipamọ́
   alẹ́ mú ṣiṣẹ́), dá `THRESHOLD = 36` (tàbí tó ga jù bẹ́ẹ̀ lọ) padà sínú `check-openapi-coverage.mjs`.
3. Mú àwọn òpin le ju iye tí a díwọ̀n lọ níbi tí modularization ti ṣàǹfààní: dá `cap` file-size padà sí 1000
   (tàbí 800), fi 5 kún àwọn òkè-ilẹ̀ coverage, dead exports 0 fún àwọn package tí a ṣe modularization sí.

## Ìpìlẹ̀ Ratchet (`quality-baseline.json`)

Ẹ́ńjìnnì ratchet (`scripts/quality/check-quality-ratchet.mjs`) máa ń ka `quality-baseline.json`
ó sì máa ń fi wé `quality-metrics.json` tí a ṣẹ̀ṣẹ̀ kó jọ. Mẹ́tríìkì èyíkéyìí tí ó bá fà sẹ́yìn
kọjá epsilon rẹ̀ yóò mú kí build náà kùnà.

Àwọn mẹ́tríìkì tí a ń tọpinpin lọ́wọ́lọ́wọ́:

| Mẹ́tríìkì              | Ìtọ́sọ́nà | Ìtumọ̀                             |
| --------------------- | ------- | --------------------------------- |
| `eslintWarnings`      | `down`  | Iye ìkìlọ̀ ESLint kò gbọ́dọ̀ pọ̀ sí i |
| `coverage.statements` | `up`    | Ìbora gbólóhùn kò gbọ́dọ̀ dín kù    |
| `coverage.lines`      | `up`    | Ìbora ìlà kò gbọ́dọ̀ dín kù         |
| `coverage.functions`  | `up`    | Ìbora iṣẹ́ kò gbọ́dọ̀ dín kù         |
| `coverage.branches`   | `up`    | Ìbora ẹ̀ka kò gbọ́dọ̀ dín kù         |

Láti ṣe ìmúdójúìwọ̀n ìpìlẹ̀ lẹ́yìn ìlọsíwájú gidi kan:

```bash
npm run quality:ratchet -- --update
git add quality-baseline.json
```

Àmì `--update` máa ń kọ àwọn iye tí a wọ̀n lọ́wọ́lọ́wọ́ sínú `quality-baseline.json`.
Ṣe commit fáìlì yìí papọ̀ pẹ̀lú àyípadà tí ó mú mẹ́tríìkì náà sunwọ̀n sí i. PR tí ó mú
mẹ́tríìkì kan sunwọ̀n sí i láì ṣe ìmúdójúìwọ̀n ìpìlẹ̀ náà ni `--require-tighten` yóò rí
(Ìpele 6A.5, ìmúṣẹ rẹ̀ ṣì ń dúró).

### Ratchet CodeQL: àkókò ìtúnṣe àti ohun ìmúṣiṣẹ́ ọlọ́wọ́

`check:codeql-ratchet` máa ń ka **ipò repo, tí a ń sọ di tuntun gẹ́gẹ́ bí àkókò tí a ṣètò — kì í ṣe fún PR kọ̀ọ̀kan.**
`gh api repos/diegosouzapw/OmniRoute/code-scanning/default-setup` máa ń fi
`state: configured`, `schedule: weekly` hàn: ìṣàyẹ̀wò default-setup ti GitHub ni, kì í ṣe ìtúpalẹ̀
fún push kọ̀ọ̀kan. Àbájáde rẹ̀ ni pé: lẹ́yìn tí PR kan tí ó ṢÀTÚNṢE àwọn ìkìlọ̀ bá ti merge, ratchet náà ṣì máa ń ka
iye àtijọ́ tí ó ga jù títí ìṣàyẹ̀wò tí a ṣètò tókàn yóò fi ṣiṣẹ́ — nítorí náà, ó máa ń jabo ìfàsẹ́yìn
lórí gbogbo PR tí ó ṣí sílẹ̀, títí kan àwọn àtẹ̀lé PR tó ṣàtúnṣe náà fúnra rẹ̀, títí tí ìṣàyẹ̀wò yóò fi dé ipò tuntun.

**Ìtúnṣe ọlọ́wọ́**: `gh workflow run codeql.yml --ref release/vX.Y.Z` máa tún
ìtúpalẹ̀ náà ṣiṣẹ́, yóò sì tún tẹ àwọn ìkìlọ̀ jáde láàárín ìṣẹ́jú díẹ̀. Ka `.github/workflows/codeql.yml`
kọ́kọ́ — àkọlé rẹ̀ ṣàlàyé pé `workflow_dispatch` nìkan ni **nítorí pé ó tako
"default setup" ti GitHub** (`CodeQL analyses from advanced configurations cannot be
processed when the default setup is enabled`). Mímú àwọn ìmúṣiṣẹ́ `push`/`pull_request`/
`schedule` padà nílò **ìgbésẹ̀ láti ọ̀dọ̀ owner kọ́kọ́**: Settings → Code security →
CodeQL: Default → Advanced. Má ṣe fi ìmúṣiṣẹ́ `schedule:` kún un láì ṣe ìyípadà yẹn — ó
máa mú àwọn ìṣiṣẹ́ tí yóò kùnà jáde nìkan.

**Mú ìpìlẹ̀ náà le lẹ́yìn tí iye náà bá dín kù** — `node scripts/check/check-codeql-ratchet.mjs
--update` máa ń kọ iye tuntun tí a wọ̀n sínú `quality-baseline.json` →
`metrics.codeqlAlerts.value`, kí ratchet má bàa gba ìfàsẹ́yìn padà sí
ààlà àtijọ́ láì sọ. Àpẹẹrẹ tí a ti ṣe (2026-09-02/03): PR #12502 ṣàtúnṣe ìkìlọ̀ gidi 7
(13 → 6 tí a wọ̀n pé ó ṣí sílẹ̀); PR #12530 mú ìpìlẹ̀ tí a dì mú le láti 11 → 6 láti bá a mu; lẹ́yìn náà,
a kọ àwọn 6 tó kù sílẹ̀ pẹ̀lú ìdáláre fún ìkìlọ̀ kọ̀ọ̀kan títí iye tó ṣí sílẹ̀ fi di 0.

**Kíkọ ìkìlọ̀ sílẹ̀ jẹ́ ìpinnu operator (Òfin Líle #14)** — má ṣe kọ ìkìlọ̀ CodeQL kan
sílẹ̀ láì kọ ìdáláre ìmọ̀-ẹ̀rọ sínú àsọyé ìkọ̀sílẹ̀ náà: `won't fix` fún
ohun tí upstream-protocol béèrè, `used in tests` fún test fixture, `false positive`
fún sanitizer tí CodeQL kò lè rí (àpẹẹrẹ tẹ́lẹ̀: `docs/security/ERROR_SANITIZATION.md`).

## Ìyípadà Ratchet Ní Ìpele Ìtújáde (WS5.5, v3.8.49)

Nígbà tí ratchet kan (ìwọ̀n fáìlì, complexity, àwọn ìkìlọ̀ eslint) bá fà sẹ́yìn lórí
orí ìtújáde MÍMỌ́ — ìyẹn ni pé ÀKÓJỌ àwọn merge ló fà á sẹ́yìn, tí kò sì sí PR kan ṣoṣo
tó lè tún ìfàsẹ́yìn náà hàn lórí branch tirẹ̀ — ojúṣe àtúnṣe náà jẹ́ ti **release captain, lẹ́ẹ̀kan ṣoṣo, lórí
release branch**: yan yíyọ apá jáde/àtúnṣètò kóòdù; ṣe rebaseline nìkan pẹ̀lú àkọsílẹ̀ ìdáláre
tí a ti ṣàkọsílẹ̀. Má ṣe gbé ìyípadà àkójọpọ̀ lé PR olùkópa lórí láéláé, má sì ṣe
rebaseline fún PR kọ̀ọ̀kan (èyí ń fi àwọn ìfàsẹ́yìn gidi pamọ́). Kọ́kọ́ ṣe ìyàtọ̀: tún àbájáde pupa náà
hàn lórí orí mímọ́ nínú probe worktree kí o tó rò pé PR rẹ ló fà á.

## Fífipamọ́ Àwọn Ìdínkù Ratchet — ọ̀nà sísàlẹ̀ (#8584)

Ratchet náà jẹ́ aládàáṣe ní ìdajì nìkan, ìdajì tí kò tọ́ sì ni. **Gígbé** cap kan sókè jẹ́
àtúnṣe JSON ọwọ́ tí ó gba ìṣẹ́jú-àáyá mẹ́wàá, tó sì jẹ́ ọ̀nà tó yára jù láti ṣí PR pupa sílẹ̀.
**Sísọ** ọ̀kan kalẹ̀ nílò kí ẹnìkan ṣiṣẹ́ `--update` kí ó sì commit àbájáde náà — títí di ìgbà tí
job `bank-ratchet-shrinks` dé, kò sí workflow kankan tó ń ṣiṣẹ́ ẹ. Àbájáde tí a wọn
(2026-07-25): àwọn fáìlì frozen 18 ti wà ní tàbí lábẹ́ cap ila 800 fún fáìlì tuntun, èyí tó burú jù
wà ní 132× (`src/shared/validation/schemas.ts`, ila 19 tí ó ru cap 2,523); òrùlé
complexity rìn láti `1794 → 2169` kọjá àwọn àkọsílẹ̀ rebaseline bíi ~37 pẹ̀lú ìdínkù kan ṣoṣo
(−1); a sì kọ “mú un le sí i nípasẹ̀ `--update` ní cycle tó kàn” ní ìgbà 31, tí a sì ṣe é
lẹ́ẹ̀kan ṣoṣo. Cap kan tí ó pé ju kóòdù tó mú un wá lọ máa ń sọ gbogbo decomposition tí a ti parí
di ààyè ìdàgbàsókè fún ẹnikẹ́ni tó bá tún fáìlì náà ṣe lẹ́yìn náà, láìsí ariwo.

`nightly-release-green.yml` → job **`bank-ratchet-shrinks`** ń pa àyípo yẹn mọ́:

|            |                                                                                                              |
| ---------- | ------------------------------------------------------------------------------------------------------------ |
| Ṣiṣẹ́ lórí  | `schedule` (3×/ọjọ́) + `workflow_dispatch` — pẹ̀lú ìmọ̀ọ́mọ̀ **kì í ṣe** `push`                                   |
| Ń wọn      | `release/vX.Y.Z` tó ga jù, resolution kan náà + injection guard bí `release-green`                           |
| Ń kọ       | `check:file-size --update` àti `check:complexity-ratchets --update` (a kọ́ méjèèjì láti dín kù nìkan)         |
| Ń ṣàyẹ̀wò   | `npm run check:ratchet-bank` (`scripts/quality/verify-ratchet-bank.mjs`)                                     |
| Ń fi ránṣẹ́ | PR kan tí ó jẹ́ ti ìsinsìnyí nígbà gbogbo sí release branch — a máa ń ṣe force-update rẹ̀, a kì í fi í ṣe spam |

A ń ṣe fífipamọ́ náà ní àkójọpọ̀ dípò fún push kọ̀ọ̀kan nítorí kò ní ìbéèrè latency kankan (ìdínkù tí a
fi pamọ́ láàárín 8h dára) nígbà tí iṣẹ́ kan fún merge kọ̀ọ̀kan yóò tún PR branch kọ́ léraléra
lákòókò àwọn ìpolongo merge, yóò sì san owó fún ESLint walk kíkún ní gbogbo ìgbà. Ìṣàwárí ṣì wà lórí
push (`release-green`); fífipamọ́ nìkan ni a ń ṣe ní àkójọpọ̀.

### Olùṣàyẹ̀wò ààbò

Job náà ń kọ sínú àwọn baseline láìsí àbójútó, nítorí náà `verify-ratchet-bank.mjs` ni ohun tó mú
èyí ṣeé tẹ́wọ́ gbà. Ó ń ṣe diff igi lẹ́yìn `--update` pẹ̀lú `HEAD`, ó sì **dá job náà dúró
kí commit kankan tó wà** — láì ṣí PR kankan — àyàfi tí gbogbo ìyípadà bá jẹ́ ọ̀kan nínú:

- entry onínọ́mbà `frozen` / `testFrozen` tí a **dín kù** tàbí **yọ kúrò**
- `complexity-baseline.json` → `count` tí a **dín kù**
- `quality-baseline.json` → `metrics.cognitiveComplexity.value` tí a **dín kù**

Ohunkóhun mìíràn yóò kùnà: gbígbé nọ́ńbà kan sókè, fífi entry kan kún un, yíyí `cap`/`testCap` padà, tàbí
píparẹ́/àtúnkọ àkọsílẹ̀ `_rebaseline_*` kan (àwọn àkọsílẹ̀ wọ̀nyẹn ni ipa-ọ̀nà audit tó ṣàlàyé ìdí tí
òrùlé kọ̀ọ̀kan fi wà, a sì tọ́jú wọn sínú object `frozen` kan náà pẹ̀lú àwọn entry fáìlì).
Bot kan tó lè gbé cap sókè yóò burú ju ipò tó wà lọ dájúdájú. Regression
guard: `tests/unit/verify-ratchet-bank.test.ts`.

Job náà kì í push sí `release/*` láéláé — ènìyàn kan ló máa merge PR náà, nítorí náà ìwọ̀n búburú
kò lè wọlé láìsí àyẹ̀wò.

## Ìlànà Àtòjọ Ìyọ̀ǹda

Gbogbo ẹnu-ọ̀nà àyẹ̀wò tí kò lè kùnà nítorí àwọn ìrúfin tó ti wà tẹ́lẹ̀ máa ń lo àtòjọ ìyọ̀ǹda tí a ti dí múlẹ̀
(fún àpẹẹrẹ, `KNOWN_STALE_DOC_REFS`, `KNOWN_MISSING`, `KNOWN_RAW_SQL`). Ìlànà náà ni:

**Ṣàtúnṣe ìdí pàtàkì tó fa ìṣòro náà; lo àtòjọ ìyọ̀ǹda nìkan nígbà tí ìrúfin náà ti wà tẹ́lẹ̀ tí
kò sì ṣeé ṣàtúnṣe nínú PR kan náà.**

Nígbà tí o bá ń ṣàfikún àkọsílẹ̀ sí àtòjọ ìyọ̀ǹda:

1. Fi àlàyé sínú comment kan nípa ìdí rẹ̀.
2. Tọ́ka sí issue tí ń tọpinpin rẹ̀ (fún àpẹẹrẹ, `// #3498 — Phase 2 feature, not yet implemented`).
3. Yọ àkọsílẹ̀ náà kúrò nínú PR kan náà tó ṣàtúnṣe ìrúfin náà — àkọsílẹ̀ àtijọ́ tí kò tún
   ń fi ìrúfin tó ṣì ń ṣiṣẹ́ pamọ́ jẹ́ àbùkù fúnra rẹ̀ (ìmúlò stale-enforcement 6A.3 yóò
   mú kí ẹnu-ọ̀nà àyẹ̀wò kùnà lórí àkọsílẹ̀ àtòjọ ìyọ̀ǹda tí kò ní ìbáṣepọ̀ mọ́ nígbà tí a bá ti ṣàmúlò rẹ̀).

**Má ṣe** ṣàfikún àwọn àkọsílẹ̀ àtòjọ ìyọ̀ǹda láti mú kí àwọn ìdánwò kọjá ní kíákíá. Ẹnu-ọ̀nà àyẹ̀wò aláwọ̀ ewé pẹ̀lú
àtòjọ ìyọ̀ǹda tó ń pọ̀ sí i ń fúnni ní ìmọ̀lára èké nípa dídára.

### Nígbà tí ẹnu-ọ̀nà àyẹ̀wò kan bá kùnà lórí PR rẹ

1. **Ka àbájáde ẹnu-ọ̀nà àyẹ̀wò náà dáadáa** — ó máa sọ fáìlì tàbí àmì wo gan-an ló rú
   òfin náà fún ọ.
2. **Ṣàtúnṣe ìrúfin náà** — ọ̀pọ̀ àwọn ẹnu-ọ̀nà àyẹ̀wò jẹ́ àyẹ̀wò ètò-fáìlì tó ń fúnni ní àbájáde kan náà ní gbogbo ìgbà, tí yóò sì kọjá ní kété
   tí kóòdù náà bá tọ̀nà.
3. **Tí ìrúfin náà bá ti wà tẹ́lẹ̀** (ìyẹn ni pé, kì í ṣe ìwọ ló dá a sílẹ̀ ṣùgbọ́n ẹnu-ọ̀nà àyẹ̀wò náà ti
   bẹ̀rẹ̀ sí í bo ó): ṣàfikún àkọsílẹ̀ àtòjọ ìyọ̀ǹda pẹ̀lú comment ìdáláre àti issue ìtọpinpin.
4. **Tí ẹnu-ọ̀nà àyẹ̀wò náà bá jẹ́ ratchet** (coverage, àwọn ìkìlọ̀ ESLint, àtúnṣe, complexity):
   ìyípadà rẹ mú kí òṣùwọ̀n náà burú sí i. Ṣàtúnṣe ìṣòro tó fa á, tàbí (nígbà díẹ̀ gan-an) ṣiṣẹ́
   `npm run quality:ratchet -- --update` tí ìyípadà náà bá jẹ́ àmọ̀ọ́mọ̀ tí ìdínkù nínú òṣùwọ̀n náà
   sì jẹ́ ìtẹ́wọ́gbà — ṣùgbọ́n ṣàkọsílẹ̀ ìdí rẹ̀ sínú àpèjúwe PR.
5. **Àwọn ẹnu-ọ̀nà àyẹ̀wò ìmọ̀ràn** (`continue-on-error: true`) wà fún fífúnni ní ìsọfúnni — wọn kì í dí
   ìdapọ̀ dúró ṣùgbọ́n wọ́n máa hàn nínú àkótán CI. Ṣàtúnṣe wọn síbẹ̀.

## Ṣíṣàfikún Ẹnu-ọ̀nà Àyẹ̀wò Tuntun

1. Ṣẹ̀dá `scripts/check/check-<name>.mjs` (tàbí `.ts`). Àwọn ẹnu-ọ̀nà àyẹ̀wò ìlànà máa jáde pẹ̀lú 0/1.
   Àwọn ẹnu-ọ̀nà àyẹ̀wò irú ratchet máa ń fi òṣùwọ̀n kan ránṣẹ́ sí `quality-metrics.json` nípasẹ̀ `collect-metrics.mjs`.
2. Ṣàfikún `"check:<name>": "node scripts/check/check-<name>.mjs"` sí `package.json`.
3. So ó pọ̀ sínú `.github/workflows/ci.yml` lábẹ́ iṣẹ́ tó yẹ
   (ìlànà → `lint` tàbí `docs-sync-strict`; ratchet → `quality-gate`).
4. Tí ó bá ní àtòjọ ìyọ̀ǹda, lo `reportStaleEntries()` láti
   `scripts/check/lib/allowlist.mjs` kí a lè ṣàwárí àwọn àkọsílẹ̀ àtijọ́ láìfọwọ́ṣe.
5. Kọ ìdánwò kan sínú `tests/unit/build/` tó ń bo ọgbọ́n ìṣàwárí ẹnu-ọ̀nà àyẹ̀wò náà.
6. Ṣàfikún ìmúdójúìwọ̀n sí ìwé yìí (ṣàfikún ìlà kan sí tábìlì iṣẹ́ tó yẹ).

## Irinṣẹ́ aṣojú: LSP-in-the-loop (àyàn-kíkópa)

Ní àfikún sí àwọn ẹnu-ọ̀nà àyẹ̀wò CI, OmniRoute ní àgbékalẹ̀ ìpilẹ̀ `agent-lsp` **àyàn-kíkópa**
(`.mcp.json` ti ìpele iṣẹ́-àkànṣe, Fase 7 Task 15). Ṣẹ̀dá `.mcp.json`
láti jẹ́ kí olupin èdè TypeScript wà fún àwọn aṣojú tó ń kọ kóòdù, kí wọ́n lè yanjú àwọn àmì /
àwọn àbájáde àyẹ̀wò **ṣáájú** kí wọ́n tó kọ kóòdù — alábàáṣiṣẹ́ compile-before-claim fún
`typecheck:core` tó ń dín àwọn àṣìṣe "àmì tí a ṣẹ̀dá lójú inú" kù láti orísun wọn. A mọ̀ọ́mọ̀
kò gbé e wọlé láìfọwọ́ṣe (ìwọ ni yóò yan afárá MCP↔LSP tí o sì jẹ́rìí sí i); àkọsílẹ̀ tó ti bàjẹ́ máa ń ṣàkọsílẹ̀
àṣìṣe ìsopọ̀ nìkan, kì í sì í ba àwọn sáẹ́ṣọ̀nù jẹ́.

kò ní ohun tí ó ń lò ó lọ́wọ́lọ́wọ́.

### Ṣọ̀kan / yọ àtúnsí kúrò (aláìlọ́gbọ́n-ọ̀nà, ewu kéré)

A fìdí olùdíje kọ̀ọ̀kan múlẹ̀ pẹ̀lú ipò ẹnu-ọ̀nà tó ń ṣiṣẹ́ ní 2026-06-17 (gbọ́kànlé-ṣùgbọ́n-ṣàyẹ̀wò);
ọ̀pọ̀ àwọn ìṣọ̀kan tí ó dàbí ẹni pé ó “hàn gbangba” fi hàn pé wọ́n ń fi gbèsè pamọ́, wọn kò sì jẹ́
àwọn àfidípò tààrà **rárá**.

- **`check:docs-sync` ń ṣiṣẹ́ lẹ́ẹ̀mejì** — gẹ́gẹ́ bí ohun olóminira nínú iṣẹ́ `lint` àti lẹ́ẹ̀kan sí i nínú `check:docs-all` (`docs-sync-strict`) àti ìkọ̀ husky pre-commit. ✅ **TI PARÍ** — a yọ ìpè `lint` olóminira náà kúrò.
- **Àyẹ̀wò CVE** — ❌ **KÌ Í ṢE ìṣọ̀kan tó mọ́ tónítóní.** `audit:deps` máa ń kùnà pátápátá lórí CVE èyíkéyìí tó ga/pàtàkì; `check:vuln-ratchet` (osv) máa ń kùnà nìkan lórí _ìfàsẹ́yìn_ ní ìfiwéra pẹ̀lú baseline (lọ́wọ́lọ́wọ́ 1 MODERATE). Ìtumọ̀ wọn yàtọ̀ — píparẹ́ `audit:deps` yóò mú kí ẹnu-ọ̀nà pípé fún ga/pàtàkì pàdánù. Ẹ jẹ́ kí àwọn méjèèjì wà.
- **Ìṣàwárí cycle** — ✅ **TI PARÍ** (#15159 G-01/G-02). Ọ̀rọ̀ àtijọ́ níbí pe `check:cycles` ní ẹnu-ọ̀nà “aláwọ̀ ewé, tí a ṣàyàn pẹ̀lú ìṣọ́ra” ó sì ṣàlàyé pé kí ó máa dí iṣẹ́ lọ́nà nítorí `check:circular-deps` (dpdm) ròyìn cycle 91. Àwọ̀ ewé yẹn jẹ́ **àwọ̀ ewé èké**: `check:cycles` ṣàyẹ̀wò àwọn subdirectory 5 (fáìlì 450), ó bá `import|export … from` aimi nìkan mu, ó sì sọ gbogbo specifier `@/` àti `@omniroute/open-sse/` nù, nítorí náà kò lè rí àwọn cycle dynamic-import + alias tí ó pọ̀ jù nínú repo. A ti tún un ṣe: ẹnu-ọ̀nà náà ń rìn ká `src` + `open-sse` báyìí (fáìlì 5023), ó ń kó àwọn specifier láti TypeScript AST (nítorí náà `import("…")` wúlò ṣùgbọ́n `typeof import("…")` ní ipò type kò wúlò), ó sì ń yanjú `paths` tsconfig. Ó rí cycle **14**, kì í ṣe 0. Nítorí pé a kò lè tún àwọn cycle 14 tó ti wà tẹ́lẹ̀ ṣe nínú PR ẹnu-ọ̀nà kan, `check:cycles` ti di **ratchet** báyìí (`--ratchet`, òrùlé `metrics.cycles.value = 14` nínú `quality-baseline.json`, `direction: down`) — ó ń dí _ìfàsẹ́yìn_ èyíkéyìí, iye náà sì lè dín kù nìkan. CI ń ṣiṣẹ́ `npm run check:cycles:ratchet`. Ìdínkù díẹ̀díẹ̀ máa lọ pẹ̀lú **A-01**. `check:circular-deps` (dpdm) ṣì jẹ́ ìmọ̀ràn gẹ́gẹ́ bí èrò kejì tó gbòòrò.
- **Ìdíjú** — ✅ **TI PARÍ** (`check:complexity-ratchets` / `eslint.complexity-ratchets.config.mjs`): ìrìn ESLint kan ṣoṣo, ó ń ka nípasẹ̀ ruleId kí baseline cyclomatic+max-lines àti cognitive lè dúró lọ́tọ̀ọ̀tọ̀; `check:complexity` / `check:cognitive-complexity` kọ̀ọ̀kan ṣì wà fún `--update` agbègbè.
- **Ìdènà ìròsọ `/api`** — ✅ **TI PARÍ** (`check:api-docs-refs` + `scripts/check/lib/apiRoutes.mjs`): àkójọ FS kan ṣoṣo ti `src/app/api`, openapi-routes + docs-symbols ṣì ń ròyìn lọ́tọ̀ọ̀tọ̀; àwọn ti ẹnìkọ̀ọ̀kan ṣì wà fún ṣíṣiṣẹ́ agbègbè.
- **`check:node-runtime` ń ṣiṣẹ́ nínú iṣẹ́ 11** — ⚠️ **ROI kéré.** Ọ̀kọ̀ọ̀kan jẹ́ runner lọ́tọ̀, àyẹ̀wò náà sì jẹ́ <1s; àpapọ̀ àkókò tí a lè fipamọ́ ~10s, ní ìfiwéra pẹ̀lú pípàdánù olùṣọ́ olówó-pọ́ọ́kú fún iṣẹ́ kọ̀ọ̀kan. Kò tọ́ ìrúkèrúdò náà.
- **`typecheck:noimplicit:core` lórí lint CI** — ✅ **a ti yọ ọ́ kúrò nínú iṣẹ́ lint** (ó jẹ́ `continue-on-error` ìmọ̀ràn); àyè type tó ń dí iṣẹ́ ni `typecheck:core` + `check:type-coverage`. A dá script agbègbè sílẹ̀.

### Yípadà / pinnu (ìlànà olùṣàkóso)

- `check:openapi-security-tiers` (ìmọ̀ràn) — ❌ **KÒ ṢEÉ yípadà ní mímọ́.** Ó jáde pẹ̀lú 0 ṣùgbọ́n ó kìlọ̀ pé ọ̀pọ̀ àwọn route `traffic-inspector` lábẹ́ `LOCAL_ONLY_API_PREFIXES` kò ní àkọsílẹ̀ `x-loopback-only: true`. Fífi agbára mú un nílò fífi àwọn àkọsílẹ̀ yẹn kún `openapi.yaml` lákọ̀ọ́kọ́.
- `typecheck:noimplicit:core` (ìmọ̀ràn) — ratchet `check:type-coverage` tó ń dí iṣẹ́ ti bo ọ́ púpọ̀. Yí i padà sí ratchet tàbí pa ìrìn `tsc` kejì tó tún ara rẹ̀ ṣe rẹ́.
- `test:vitest:ui` (tó jẹ́ **olùdènà** báyìí) — àwọn ìkùnà tó ti wà tẹ́lẹ̀ ni a yọ kúrò ní pàtó nínú `vitest.config.ts` pẹ̀lú àwọn àlàyé ìtọ́pasẹ̀ `// #8618`; àwọn ìkùnà tuntun máa ń mú kí iṣẹ́ náà kùnà.
- `check:secrets` (gitleaks, ratchet olùdènà tí a dì mọ́ àwọn false-positive 3 tí a ṣàkọsílẹ̀) — fi àwọn 3 náà sí allowlist láti dé 0, tàbí sọ ọ́ kalẹ̀ sí ìmọ̀ràn. Ó ní àgbélébùú pẹ̀lú secret-scanning abinibi GitHub + `check:public-creds`.
- `check:pr-evidence` (olùdènà, ń lo grep lórí ọ̀rọ̀ inú PR-body) — ewu false-positive ga; píparẹ́ rẹ̀ máa sọ ìmúlò Hard Rule #18 di aláìlágbára, nítorí náà èyí jẹ́ ìpinnu ìlànà gidi.
- `semgrep` (olóminira ìmọ̀ràn) — ó ní àgbélébùú pẹ̀lú CodeQL fún àwọn ẹbí OWASP; so baseline rẹ̀ mọ́ ratchet kan tàbí pa á rẹ́.

#### `check-key-completeness` — ìdènà ìbámu àkójọpọ̀ kọ́kọ́rọ́

`scripts/i18n/check-key-completeness.mjs` (`npm run i18n:check-keys`, iṣẹ́ `i18n-ui-coverage`).
Ó ń fi àkójọpọ̀ àwọn kọ́kọ́rọ́ ewé inú gbogbo `src/i18n/messages/<locale>.json` wé `en.json`, ó sì
máa ń kùnà lórí èyíkéyìí tí kò sí tàbí tí ó jẹ́ àfikún, láìka ìgbà tí a fi kọ́kọ́rọ́ náà kún un sí.
Àwọn ààyè ìdádúró `__MISSING__:` ni a kà sí èyí tó wà (àkóónú wọn jẹ́ ọ̀ràn ìdènà ìpín).
Ó jẹ́ alábàáṣe pípé fún àwọn ìdènà méjì tó dá lórí ìyàtọ̀/ìdá-ọgọ́rùn-ún: `check-ui-keys-coverage`
ń fipá mú ààlà ìsàlẹ̀ 80 % fún locale kọ̀ọ̀kan (àwọn kọ́kọ́rọ́ 43 tí kò sí nínú ~13,000 ṣì máa ń
fi 99.7 % hàn), `check-new-key-coverage` sì ń ṣàyẹ̀wò kìkì àwọn kọ́kọ́rọ́ tí PR kan fi kún
`en.json`. Àkójọpọ̀ locale kan ni a ń ṣẹ̀dá láti inú `en.json` ti ọjọ́ tí a gé ẹ̀ka rẹ̀, ó sì ń
túmọ̀ fún ọ̀pọ̀ ọjọ́ nígbà tí ìpìlẹ̀ ṣì ń fi àwọn kọ́kọ́rọ́ kún un; PR àkójọpọ̀ náà kò fi kọ́kọ́rọ́
kankan kún un fúnra rẹ̀, nítorí náà àwọn méjèèjì tó jọ ọ́ kò fi ìkìlọ̀ hàn nígbà tí àkójọpọ̀ 1
(#13044) wọlé pẹ̀lú àìní kọ́kọ́rọ́ 43 nínú locale mẹ́sàn-án àti àkójọpọ̀ 2 (#13660) pẹ̀lú àìní
kọ́kọ́rọ́ 10 nínú mẹ́jọ (2026-09-15). Ṣàtúnṣe ìkùnà pẹ̀lú
`node scripts/i18n/sync-ui-keys.mjs --locale=<codes> --translate-markers`; ewé `extra` túmọ̀ sí
pé orísun ti yọ ọ́ kúrò — pa á rẹ́ kúrò nínú locale náà. `--warn` máa ń ṣe ìròyìn láìkùnà.
`--catalog=cli` ń ṣe ìfiwéra kan náà lórí `bin/cli/locales` (`npm run i18n:check-keys:cli`);
àwọn ìgbésẹ̀ méjèèjì wà nínú iṣẹ́ `i18n-ui-coverage`.

#### `check-new-key-coverage` — ìdènà i18n fún kọ́kọ́rọ́ tuntun

Ẹgbẹ́ `check-ui-value-drift`. Èyí ń mú iye Gẹ̀ẹ́sì kan tí a **kọ ní ọ̀nà míràn**
nígbà tí a fi àwọn ìtumọ̀ rẹ̀ sílẹ̀ sẹ́yìn; èyí sì ń mú kọ́kọ́rọ́ Gẹ̀ẹ́sì kan tí a **fi kún un**
nígbà tí àwọn locale kan kò rí i gbà rárá.

`check-ui-keys-coverage` kò lè rí irú èyí: ó ń fipá mú ààlà ìdá-ọgọ́rùn-ún fún locale kọ̀ọ̀kan,
àti pé àìní kọ́kọ́rọ́ mọ́kànlá nínú ~13,000 fi àgbájọ ìborí sí 99.9%. Ìdá-ọgọ́rùn-ún fún èdè
kọ̀ọ̀kan kò lè ṣàlàyé pé “a ṣe ìtújáde ẹ̀yà yìí láìtumọ̀ rẹ̀” — gbogbo ẹ̀yà kan lè wọ inú locale
tuntun láìsí ọ̀rọ̀ kankan, láìsí ìyípadà kankan sí nọ́ńbà náà.

Ìṣẹ̀lẹ̀ tí ó dúró fún: Ìpele 3 ti Orchestration Canvas túmọ̀ àwọn kọ́kọ́rọ́ mọ́kànlá rẹ̀ káàkiri
àwọn locale 42 tó wà nígbà náà. Wákàtí díẹ̀ lẹ́yìn náà, àkójọpọ̀ èdè EU (#13044) mú ibi ìpamọ́ náà
dé locale 51, àwọn tuntun mẹ́sàn-án (`el`, `et`, `ga`, `hr`, `lt`, `lv`, `mt`, `sl`, `sr`) kò sì
rí wọn gbà rárá. `deepMergeFallback` ń fi Gẹ̀ẹ́sì rọ́pò kọ́kọ́rọ́ tí kò sí, nítorí náà ọ̀nà ìkùnà
náà jẹ́ UI tí a kò túmọ̀ dípò UI òfìfo — ó jẹ́ gidi, ó sì dákẹ́ nípasẹ̀ àpẹrẹ rẹ̀.

Gẹ́gẹ́ bí ẹgbẹ́ rẹ̀, ó **mọ ìyàtọ̀**, ó ń fi Gẹ̀ẹ́sì ní ìpìlẹ̀ ìdàpọ̀ wé igi iṣẹ́, nítorí náà
àwọn àlàfo tó ti wà tẹ́lẹ̀ dúró gẹ́gẹ́ bí wọ́n ṣe rí, ìdènà náà kò sì nílò ìṣíkiri kankan láti
ṣiṣẹ́.

**Àmì `__MISSING__:<english>` kò mú un ṣẹ mọ́ (láti 2026-09-17).** Ó ti jẹ́ ìdádúró tí ìwé
àkọsílẹ̀ sọ tẹ́lẹ̀ — àsìkò ìṣiṣẹ́ máa ń padà sí Gẹ̀ẹ́sì tó tọ́ — títí tí àwọn PR ẹ̀yà mẹ́jọ ní
2026-09-16 fi kún kọ́kọ́rọ́ 61, tí wọ́n sì tẹ àmì náà sínú gbogbo locale 65 dípò títúmọ̀ wọn:
ìdènà yìí gba gbogbo wọn, kò sí ohun tó dá àwọn PR náà dúró, lẹ́yìn náà ìdènà ìpín ìtumọ̀ gidi
tó ń dí iṣẹ́ kọ́ lórí òkè ìtújáde fún gbogbo ènìyàn (pt-BR 3.2 % > 2.5 % + 0.5). Ní báyìí,
a ń ṣe ìdájọ́ àmì kan gẹ́gẹ́ bí ìtumọ̀ tí kò sí. Ṣàtúnṣe ìkùnà pẹ̀lú
`node scripts/i18n/sync-ui-keys.mjs --locale=<codes> --translate-markers --batch-size=40`, tàbí
gbogbo locale lẹ́ẹ̀kan náà pẹ̀lú `npm run i18n:translate-new-keys`
(`scripts/i18n/translate-new-keys.sh`, ó láìléwu nígbà tí a yà á kúrò, kò ní bẹ̀rẹ̀ láìsí env
`OMNIROUTE_TRANSLATION_*`). Kọ́kọ́rọ́ kan tí ó gbọ́dọ̀ dúró ní Gẹ̀ẹ́sì (orúkọ
ọjà/engine/flag tí a dì mọ́lẹ̀) yẹ kí ó wà nínú `scripts/i18n/untranslatable-keys.json`,
kì í ṣe lẹ́yìn àmì kan. `vi` fòfin de àwọn àmì pátápátá
(`tests/unit/i18n-vi-completeness.test.ts`).

#### `check-vitest-exclusions` — ìdènà ìdánwò tí a dá dúró

Fáìlì kan nínú àkójọ `exclude` ti `vitest.config.ts` jẹ́ ìdánwò tí kò ṣiṣẹ́, ó sì dà bí
ìborí lójú ẹni tó bá ka igi náà. Fáìlì méjìlélọ́gọ́ta kójọ sẹ́yìn àlàyé
`// #8618 — ìkùnà tó ti wà tẹ́lẹ̀; yọ ìyọkúrò yìí nígbà tí a bá ṣàtúnṣe rẹ̀`. A ti pa Issue #8618
ní 2026-08-11 nígbà tí àkójọ tí ó ń tọ́pinpin dàgbà láti àwọn àkọsílẹ̀ 45 sí 62, tí ọ̀kọ̀ọ̀kan
tuntun sì jogún àlàyé tó tọ́ka sí issue tí kò ṣiṣẹ́ mọ́. Nígbà tí a wọn àkójọ náà ní fáìlì
kọ̀ọ̀kan níkẹyìn (#13204), **51 nínú 62 náà kọjá lórí igi lọ́wọ́lọ́wọ́ láìsí ìyípadà kankan
sí orísun**.

Ìdènà náà ń béèrè pé gbogbo ìyọkúrò tí ó tọ́ka sí fáìlì gidi gbọ́dọ̀ (a) dárúkọ issue
ìtọ́pinpin kan àti (b) hàn nínú `config/quality/vitest-exclusions.json` pẹ̀lú ipò rẹ̀ tí a ti
wọn, kí fífi ọ̀kan kún un lè jẹ́ ìyàtọ̀ tí a lè ṣàgbéyẹ̀wò nínú fáìlì àkànṣe, dípò kàn jẹ́ ìlà
míràn nínú àkójọpọ̀ oní-àkọsílẹ̀ 60. Ó mọ̀ọ́mọ̀ kò tún àwọn ìdánwò tí a yọ kúrò ṣiṣẹ́ — ìyẹn
ń gba ~10 ìṣẹ́jú, ó sì yẹ iṣẹ́ alákòókò; àkójọ ohun-ìní náà ń ṣàkọsílẹ̀ ìgbà tí a wọn ọ̀kọ̀ọ̀kan
wọn kẹ́yìn.
