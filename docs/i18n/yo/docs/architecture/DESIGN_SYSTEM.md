> **Ipo:** Dasibodu ti wa ni itumọ ti lori awọn **Keak CI UI Kit** (`@keak/cheaper-inference-ui-kit`), ti o wa ninu ibi ipamọ yii bi aaye iṣẹ `packages/ui-kit` (`@omniroute/ui-kit`; fọtoyiya ti oke ti wa ni pinni ni `packages/ui-kit/UPSTREAM.md` ati aabo nipasẹ `npm run check:ui-kit-snapshot`). Imọlẹ jẹ koko ọrọ-ọrọ; ààyò aiyipada ni `system`. Paleti aiyipada jẹ ti kit **Editions** irisi (awọn didoju iwe gbigbona ati asẹnti bàbà `#e5ac82`, `packages/ui-kit/src/ci-editions.css`); Eto → Irisi → Awọ paleti ipese **Classic** , awọn ami ipilẹ kit pẹlu ohun orombo wewe. Switzer jẹ idile akọkọ fun UI ati ọrọ ifihan (`--ci-font-ui`; `--ci-font-display` ati `--ci-font-mono` pinnu si rẹ), ti gbalejo funrararẹ nipasẹ ohun elo funrararẹ (`packages/ui-kit/src/ci-fonts.css`, ti a gbe wọle nipasẹ `ci-tokens.css`). Gbogbo aami jẹ glyph Lucide kan.
>
> Inter jẹ apadabọ fun awọn glyphs ti o padanu lati Switzer; awọn maapu `--font-mono` si akopọ monospace eto `--ci-font-code`.
>
> `src/app/globals.css` yan awọn nkọwe-pada sẹhin fun glyph nigbati `Switzer` ko ni glyph: `Inter` fun Cyrillic, Greek ati Vietnamese, ati `Vazirmatn` fun iwe afọwọkọ Larubawa nikan labẹ `html[dir="rtl"]`.

`src/app/globals.css`:

```css
:root,
.ci-theme {
  --ci-font-ui:
    "Switzer", "Inter", -apple-system, BlinkMacSystemFont, "Segoe UI", Arial, sans-serif;
  --ci-font-code: ui-monospace, SFMono-Regular, Menlo, Consolas, "Liberation Mono", monospace;
  --font-mono: var(--ci-font-code);
}
```

## 1. Nibiti ohun gbe

- **Kit.** `packages/ui-kit/src` jẹ ẹda baiti-fun-baiti ti `src/` ti o wa ni oke ni ṣiṣe pinned ni `packages/ui-kit/UPSTREAM.md` (eyiti o tun ṣe igbasilẹ aṣẹ aṣẹ); `PATCHES.md` ṣe atokọ awọn abulẹ agbegbe. O jẹ orisun bi orisun, ti ko si kikọ: `next.config.mjs` yi i pada, ati awọn maapu `tsconfig.json` `@omniroute/ui-kit` → `packages/ui-kit/src` ati `@omniroute/ui-kit/*` → `packages/ui-kit/src/*` (`vitest.config.ts` ati `vitest.mcp.config.ts` gbe inagijẹ kan naa). Ṣe agbewọle paati ohun elo nipasẹ ọna abẹlẹ rẹ (`@omniroute/ui-kit/table`, `@omniroute/ui-kit/page-header`…), rara nipasẹ agba `@omniroute/ui-kit` : agba naa fa gbogbo paati (pẹlu oluyan ọjọ) sinu agbewọle kọọkan. Iwe aṣa ohun elo naa nwọle nipasẹ `src/app/globals.css` (`@import "../../packages/ui-kit/src/ci-styles.css"`, iwe pipe: `ci-ui.css` mojuto pẹlu gbogbo idile apẹrẹ).
- **Awọn ami-ami.** `packages/ui-kit/src/ci-tokens.css` kede awọn ami `--ci-*` ; `src/app/globals.css` ṣe afara wọn si awọn orukọ OmniRoute julọ (`--color-*`, `--radius-*`, `--font-sans`/`--font-mono`, `--table-*`, `--orch-status-*`, `--color-fd-*`), nitorina `var(--color-*)` ti o wa tẹlẹ ati awọn ohun elo Tailwind tẹsiwaju ṣiṣẹ. Koodu titun nlo awọn ohun elo Tailwind (`bg-surface`, `text-text-muted`, `border-border`, `text-success`, `bg-success-bg`, `bg-chart-1`...) tabi kit kilasi — rara iye hex kan (`tests/unit/design-kit-bridge.test.ts` fi agbara mu afara). `text-primary` pinnu lati `--color-primary-ink` nipasẹ `--text-color-primary`, nitorina ọrọ akọkọ duro ni kika nigba ti `bg-primary`/`border-primary` tọju dada asẹnti: labẹ Editions o jẹ `--ci-color-accent-active` kit naa ( `#99562f` ti o jinlẹ ninu ina, asẹnti bàbà ni dudu); labẹ Classic, lime-800 ninu ina ati orombo wewe ninu okunkun. Ẹya aworan apẹrẹ lo `--color-chart-1` … `--color-chart-8`, ọkọọkan pẹlu ọrọ-ailewu `--color-chart-N-ink` ati tint chirún `--color-chart-N-subtle` akomo kan, ti a sọtọ ni aṣẹ lẹsẹsẹ kit (`ciChartSeriesOrder`).
- **Awọn akori.** `<html className="ci-theme">` (`src/app/layout.tsx`) yan iwe-ipamọ sinu akori kit. Iyanfẹ jẹ `light`, `dark` tabi `system` (`THEME_CONFIG.defaultTheme = "system"` ni `src/shared/constants/appConfig.ts`; `system` tẹle `prefers-color-scheme`). `applyTheme()` in `src/store/themeStore.ts` (digi nipasẹ `THEME_BOOT_SCRIPT`, inlined in `src/app/layout.tsx`, eyi ti o nṣiṣẹ ṣaaju ki o to hydration) ṣeto `data-theme="dark"|"light"` ati ki o yipo `.dark` kilasi lori `<html>` papo. Eto aami dudu ti kit naa jẹ bọtini lori `data-theme="dark"` (`packages/ui-kit/src/ci-tokens.css`); OmniRoute's ti ara dudu yi danu (awọn `.dark` Àkọsílẹ ni `globals.css`) ati awọn julọ Tailwind `dark:` awọn ohun elo bọtini lori `.dark` kilasi. Ko si awọn tito tẹlẹ awọ asẹnti: asẹnti nigbagbogbo wa lati inu ohun elo naa, ati pe tito tẹlẹ lati inu kikọ agbalagba ti lọ silẹ nigbati ile itaja ba di ẹru.
- **Awọn paleti.** Meji, mejeeji lati ohun elo (`src/shared/constants/appearancePalette.ts`): `editions`, aiyipada, ati `classic`. Editions jẹ ẹya `data-ci-appearance="editions"` ti kit lori `<html>`, eyiti `ci-editions.css` (ti a gbe wọle nipasẹ `ci-ui.css`) darapọ pẹlu `data-theme`; Classic ni isansa ti abuda naa. Olupin ipalẹmọ gbongbo-ṣe ẹda naa, nitorinaa alejo ti ko ni nkan ti o fipamọ (tabi ko si JS) gba Editions lori gbogbo dasibodu — dada, buwolu wọle, `/status`, awọn oju-iwe aṣiṣe, `/docs` ati PWA naa. Yiyan naa duro lẹgbẹẹ akori ni ile itaja `theme` kanna (`palette`, `setPalette()`, `applyPalette()` ni `src/store/themeStore.ts`) ati lo ṣaaju ki o to kun nipasẹ `THEME_BOOT_SCRIPT` (`src/shared/utils/themeBootScript.ts`, inlined in the layout's `<head>`), eyiti o yọ ẹda naa kuro nikan nigbati paleti ti o fipamọ jẹ `"classic"`; `src/app/global-error.tsx`, ni ita ipilẹ ipilẹ, lo lati ile itaja kanna. Maṣe fi `data-ci-appearance` sori eyikeyi nkan miiran: kit naa baamu pẹlu `html:root:has([data-ci-appearance="editions"])`, nitorinaa iru-ọmọ kan yoo yi gbogbo iwe pada. Iyatọ Editions `data-ci-editions-variant="landing"` wa fun awọn oju-iwe titaja, kii ṣe dasibodu naa. Chrome Browser: olupin naa ṣe aiyipada, Editions, ni `viewport.themeColor` (aami kan fun `prefers-color-scheme`) ati oju opo wẹẹbu iṣafihan — `PWA_THEME_COLORS` ni `src/shared/constants/pwaThemeColors.ts`, digi kan ti `--ci-color-background` Editions `#f3f1e9` / `#11120f`), ti a fi si `ci-editions.css` nipasẹ `tests/unit/pwa-theme-colors.test.ts`. `<meta name="theme-color">` laaye lẹhinna tẹle paleti ti o fipamọ ati ipo: `THEME_BOOT_SCRIPT` tun awọn afi kọ ṣaaju ki o to kun ati awọn iṣe ile itaja akori ṣe lori gbogbo iyipada (`resolveThemeColor()` / `applyThemeColor()` ni `src/shared/utils/themeColorMeta.ts`, pẹlu `CLASSIC_PAGE_BACKGROUND` ka lati `ciTokens` kit naa). Akori light/dark ti o fojuhan ṣeto gbogbo aami si ipo yẹn; `system` tọju awọ kan fun ero kan. Ifihan naa duro Editions: o ti mu ni ẹẹkan fun fifi sori ẹrọ, laisi ayanfẹ. Monaco ka awọn awọ rẹ pa a ibere (`monacoKitTheme.ts`); labẹ Editions awọn iwadi ka yi pada awọn root `data-theme` fun ọkan amuṣiṣẹpọ kọja, nitori awọn kit resolves Editions light/dark lati root.
- **Awọn paati (awọn alamuuṣẹ).** `src/shared/components/index.tsx` tọju paati OmniRoute API (awọn orukọ kanna, awọn okeere okeere ati awọn atilẹyin), ati awọn ipilẹṣẹ ti o wa lẹhin rẹ jẹ awọn oluyipada lori ohun elo: awọn fọọmu (`Button`, `Input`, `Textarea`, `Checkbox`, `Select`, `Toggle`, `Badge`, `Card`), overlays ati esi (`Modal`/`ConfirmModal`, `Tooltip`/ `EmptyState`), `NotificationToast` `InfoTooltip` zq (`Collapsible`, `CollapsibleSection`, `Loading`, `SegmentedControl`, `Avatar`) ati tabili (`DataTable`, `FilterBar`, `ColumnToggle`, `FilterPills`, `PresetSlider` `Breadcrumbs`. Ohun ti nmu badọgba ṣe agbewọle paati ohun elo nipasẹ ọna abẹ-ọna ati ṣe maapu awọn ohun elo ti ogún sori rẹ — fun apẹẹrẹ `Button variant="primary"` ni bọtini `default` kit (`--ci-button-primary-*`: dada onidakeji ninu ina, asẹnti pẹlu inki `--ci-color-accent-foreground` rẹ ninu okunkun), `danger` jẹ `destructive`, ati `warning` ni bọtini `warning` kit. awọn iyatọ ipo `Badge` jẹ awọn ohun orin kit, ati `Select` pẹlu awọn ọmọde `<option>` ṣe apẹrẹ ohun elo `NativeSelect`. `tests/unit/ui/adapters/*.test.tsx` pin kọọkan alamuuṣẹ.
- **Ikarahun.** `src/app/(dashboard)/layout.tsx` ṣe `DashboardLayout`, eyiti o tumọ `src/shared/components/layouts/DashboardShell.tsx`: kit `SidebarProvider` / `Sidebar` / `SidebarInset` (`packages/ui-kit/src/sidebar.tsx`), pẹlu ọgbọn lilọ kiri OmniRoute ni `src/shared/components/Sidebar.tsx`. Ọna asopọ “fo si akoonu” si `#main-content` jẹ ipin akọkọ ti a le fojusi. `src/shared/components/Header.tsx` di ohun elo `SidebarTrigger` mu (ayipada ikarahun nikan ti ikarahun), Keak `ProductSwitcher` ati ṣiṣi paleti-paleti; o ṣe afihan akọle ipa ọna nikan nigbati ko si kit `PageHeader` (`.ci-page-header`) ti o wa ninu `#main-content`, nitorina oju-iwe ti o ni `PageHeader` tirẹ ni `h1` kan. `src/shared/components/CommandPalette.tsx` jẹ ohun elo `Dialog`.
- **Awọn aami.** `<Icon name="material_name">` (`src/shared/components/Icon.tsx`) ṣe ipinnu orukọ naa (awọn ọrọ Awọn aami Awọn ohun elo ti awọn iboju lo) nipasẹ `ICON_MAP` (`src/shared/constants/iconMap.ts`) si glyph Lucide kan. Fọọmu Awọn aami ohun elo ati idii ti lọ: orukọ ti o padanu lati maapu naa ṣe afihan glyph ibi didoju didoju (`data-icon-missing="true"`) ati ṣe igbasilẹ ikilọ console ni ita iṣelọpọ. `npm run gen:icon-map` tẹ awọn orukọ ti o wa ni lilo ti o nsọnu lati maapu (`tests/unit/icon-map-coverage.test.ts` kuna lori eyikeyi orukọ laisi aami Lucide ; `tests/unit/icon-map-object-values.test.ts` bo awọn orukọ ti a fipamọ sinu awọn nkan wiwa); `scripts/dev/codemod-material-icons.mjs <dir|file>... [--write]` ṣe atunko awọn aaye gangan `<span className="material-symbols-outlined">` si `<Icon>`.
- **Brand.** `src/shared/components/OmniRouteLogo.tsx` fi ipari si ohun elo naa: okeere okeere `OmniRouteLogo` ṣe afihan `ProductIcon product="omniroute" variant="glyph"` (inline SVG, `basePath` -safe) ati `OmniRouteLockup` n ṣe `ProductLockup product="omniroute"` (orukọ wiwọle "Keak OmniRoute") tabi, fun awọn oniṣẹ aami funfun, `name`/`logoSrc` tiwọn. Awọn ibi-iyipada ọja n gbe ni `src/shared/constants/keakProducts.ts` (`KEAK_PRODUCT_LINKS`, `KEAK_ACTIVE_PRODUCT`). Awọn iboju imurasilẹ — `src/app/login/page.tsx`, `src/app/status/page.tsx`, `src/app/maintenance/page.tsx`, `src/app/offline/page.tsx`, `src/app/not-found.tsx` ati `src/shared/components/ErrorPageScaffold.tsx` — fihan titiipa; `tests/unit/brand-pages-static.test.ts` ṣọ rẹ.

## 2. Awọn ofin

1. Awọn ami-ami, kii ṣe gangan. Awọn imukuro wa ni idi: ebute console dudu nigbagbogbo ati `STATUS_HEX` (`src/shared/constants/statusColors.ts`), digi ti o yanju-hex ti paleti ipo kit fun awọn olupe ti o nilo hex gangan. Awọn paleti isọri kii ṣe iyatọ diẹ sii: wọn gùn lori awọn ami apẹrẹ iwe mẹjọ ti kit (`--color-chart-1..8`, plus `-ink`/`-subtle`), ni aṣẹ lẹsẹsẹ kit, nipasẹ `src/shared/utils/categoricalPalette.ts` ati, fun awọn ilana ipa ọna, `src/app/(dashboard)/dashboard/combos/strategyPalette.ts`; awọn egbegbe ReactFlow ati kanfasi orchestration ka akori-mọ `--orch-status-*` oniyipada (`src/shared/components/flow/edgeStyles.ts`).
2. Maṣe patch `packages/ui-kit/src` pẹlu ọwọ: muṣiṣẹpọ pẹlu `scripts/dev/sync-ui-kit.sh <commit>`; ẹnu-ọna ti a ti sọ tẹlẹ `npm run check:ui-kit-snapshot` (`.husky/pre-commit`) kuna lori eyikeyi baiti ti o yato si ipinnu oke ti a pin (o fo pẹlu ikilọ nigbati ẹda oniye ti oke, `UI_KIT_CLONE` tabi `_references/cheaper-inference-ui-kit`, ko si). Nigbati ohun elo ko ba ni nkan, ṣiṣẹ ni ayika rẹ ni ohun ti nmu badọgba tabi iboju ki o beere fun u ni oke.
3. Awọn aiyipada ọrọ kit jẹ Gẹẹsi (`label = "Loading"`, `loadingLabel = "Loading table"`…) — kọja awọn gbolohun ọrọ ti a tumọ lati `useTranslations(...)` nigbakugba ti paati ohun elo ba ṣe ọrọ.
4. awọn ohun elo Tailwind bori lori awọn kilasi paati ohun elo (ohun elo naa sọ `@layer theme, base, components, utilities` ati awọn ofin rẹ n gbe ni `components`) — lo awọn ohun elo fun aye ati ipilẹ, kii ṣe lati tun awọn ohun elo ohun elo awọ pada.
5. Awọn akọle: `.ci-heading` fun oju-iwe ati awọn akọle apakan; `.ci-dashboard-display` nikan fun titobi nla, ọrọ ifihan fọnka gẹgẹbi koodu ipo oju-iwe aṣiṣe. Mejeeji lo Swiss.
6. `tests/unit/dashboard-kit-sweep.test.ts` ṣe aabo fun igbasilẹ ohun elo: ko si akoko ligature ohun elo labẹ `src/app` tabi `src/shared/components`; ninu igi dasibodu (`src/app/(dashboard)` ati `src/shared/components`) ko si `<select>` aise, `<textarea>` tabi `<table>` ati pe ko si `role="dialog"` ti a fi ọwọ yiyi ni ita awọn imukuro ti a ṣe akojọ (ẹka abinibi `Select` ti nmu badọgba, `RequestLoggerDetail`); gbogbo `<button>` aise tabi `<input>` nibẹ nilo asọye ti o ni `kit-exception:` (pẹlu idi) ti o pari ni pupọ julọ awọn ila 3 loke rẹ; paleti hues ati `dark:` aba nikan ni awọn faili awọn akojọ igbeyewo.
7. Ṣe idaniloju awọn akori mejeeji ati iwoye 390 px ṣaaju PR kan (awọn sikirinisoti); `tests/e2e/a11y.spec.ts` nṣiṣẹ ake.

## 3. Ẹ̀kun Síkíríìnì Kan

1. Ṣí ojú-ìwé náà pẹ̀lú `PageHeader` ti kit (`@omniroute/ui-kit/page-header`, `compact` nínú
   dashboard) — àkópọ̀, àpèjúwe àti `actions`. Àkọ́pọ̀ shell nígbà náà máa fi àkópọ̀ tirẹ̀ sílẹ̀.
2. Kọ́ àwọn ìṣàkóso láti `@/shared/components` (àwọn adapter) kí o sì lo àwọn ẹ̀yà kit nípasẹ̀ subpath ní ibi tí kò
   sí adapter (`Table`/`TableScrollArea`/`DataTableShell`, `Field`, `Alert`, `Tabs`, `RadioGroup`,
   `Slider`…).
3. Àwọn àwòrán: `<Icon name="…" />`. Orúkọ tuntun máa wọ inú `ICON_MAP` pẹ̀lú ẹ̀yà Lucide tí ó bá ìtumọ̀ rẹ̀
   mu; `npm run gen:icon-map` máa kọ àwọn orúkọ tí ó ṣì kù sílẹ̀.
4. Àwọn àwọ: àwọn ohun èlò ìtumọ̀ (`text-success`, `bg-warning-bg`, `border-border`…) àti
   `var(--color-chart-N)` fún àwọn ìtẹ̀sí chart; kò sí àwọn iye hex, kò sí àwọn ìyàtọ̀ `dark:` tí ó ṣì ń tún àwọ kan sọ.
5. Ọrọ̀: gbogbo ìtẹ̀lé-ọrọ̀, pẹ̀lú àwọn àmì-ọrọ̀ tí o rán lọ sọ́dọ̀ àwọn ẹ̀yà kit, máa wá láti `useTranslations`. Àwọn
   kó̀kọ́rọ́ tuntun máa wọ inú `src/i18n/messages/en.json`, `pt-BR.json` àti `vi.json` (ìdánwò ìbáṣepọ̀ Vietnamese fi
   gbogbo kó̀kọ́rọ́ Gẹ̀ẹ́sì tẹ̀ lé); ìṣàmu i18n ni ó máa kún àwọn locale tókù.
6. Ṣe àwọn aláàbò lọ ṣáájú PR: `tests/unit/dashboard-kit-sweep.test.ts`,
   `tests/unit/icon-map-coverage.test.ts`, `tests/unit/icon-map-object-values.test.ts`,
   `npm run check:dashboard-typecheck` (àyẹ̀wò kan ṣoṣo tí ó ń mu import tí a ṣe lẹ́mejì nínú `iconMap.ts`),
   `npm run check:ui-icu`, àti àwọn ìdánwò tirẹ̀ ti síkíríìnì náà.

## 4. Ṣíṣàfikún tàbí yíyí adapter kan padà

1. Pa API gbogbogbò ti `src/shared/components/index.tsx` mọ́: orúkọ export kannáà, àwọn default export àti àwọn props tí wọ́n gba. So àwọn props àtijọ́ pọ̀ mọ́ kit láti inú adapter náà (wo `Button.tsx`: `VARIANT_TO_KIT`,
   `SIZE_TO_KIT`).
2. Ṣe import kit náà nípasẹ subpath (`@omniroute/ui-kit/<component>`).
3. Àwọn ìyanáà fún àwọn àlàfo kit gbọdọ̀ wà nínú adapter náà (tàbí nínú `globals.css` `@layer components` tí àtúnṣe náà bá jẹ́ style), kì í ṣe nínú `packages/ui-kit/src` rárá.
4. Ṣàfikún tàbí ṣe àtúnṣe `tests/unit/ui/adapters/<name>.test.tsx`. Fún adapter tí ó ní ọ̀pọ̀ olùpè, ṣe àfiwè markup tí a ṣe jáde ṣáájú àti lẹ́yìn àyípadà náà — àyípadà padding tàbí wrapper máa ń tàn ká sí gbogbo ojú-ìbòjú.

## 5. Ṣíṣe àtúnṣe kit náà

`npm run check:ui-kit-upstream` ṣe afiwe ẹya ti a pinni ni `packages/ui-kit/UPSTREAM.md` pẹlu aami `v*` tuntun ti repo oke ati ṣe atẹjade aṣẹ amuṣiṣẹpọ nigbati itusilẹ ba jade.

Ṣiṣan iṣẹ `UI Kit upstream watch` ojoojumọ (`.github/workflows/ui-kit-upstream-watch.yml`) nṣiṣẹ ayẹwo kanna. Lakoko ti pinni wa ni ẹhin, `scripts/ci/ui-kit-sync-pr.sh` ntọju PR amuṣiṣẹpọ kan ṣiṣi si ẹka `release/vX.Y.Z` ti o ga julọ, lori ẹka yiyi `chore/ui-kit-sync-latest`. Ko dapọ rara: gbogbo idasilẹ ohun elo tun nilo ayẹwo wiwo lori VPS agbegbe. Ẹka naa ni a tun kọ nigbati itusilẹ tuntun ba jade ti o fi silẹ nikan bibẹẹkọ. PR ti o ṣii pẹlu awọn iṣẹ titari nipasẹ ọwọ ko ni atunkọ, ati PR kan fun ẹya kan ti olutọju kan ti a ti pa ti ko dapọ duro ni pipade titi ti idasilẹ tuntun.

Nigbati ko ba si PR ti o le ṣii (itusilẹ ibi-afẹde ti di didi, PR ti ṣe titari nipasẹ ọwọ, PR ti wa ni pipade, tabi ko si ami ami PR ti a ṣeto) ṣiṣiṣẹ ṣiṣẹ jẹ ki ọran ipasẹ kan ṣii ti o sọ idi.

Ṣiṣẹ iṣẹ naa nlo awọn aṣiri meji:

- `secrets.UI_KIT_READ_TOKEN`: àmi kika-nikan fun repo oke ikọkọ. Nigbati ayẹwo oke ko le ka data (ko si ami ami, ami ami kan ti o da iṣẹ duro, tabi GitHub ti ko le de ọdọ), o ṣe ijabọ `unknown` ati jade pẹlu koodu `0`. Sisan-iṣẹ naa kọ ikilọ kan ati gbiyanju lati jẹ ki ọrọ ipasẹ lọtọ kan ṣii; a nigbamii aseyori run tilekun o lẹhin wiwọle pada. Ikuna ti ọrọ GitHub API kuna iṣẹ naa.
- `secrets.UI_KIT_SYNC_PR_TOKEN`: àmi-ọkà daradara kan lori ibi ipamọ yii pẹlu Awọn akoonu ati Awọn ibeere Fa kikọ wiwọle. Ṣiṣan iṣẹ ṣiṣe ṣi tabi ṣe imudojuiwọn PRs amuṣiṣẹpọ nikan nigbati a tunto ami iyasọtọ; laisi rẹ, iṣan-iṣẹ naa nfa ẹka naa ati awọn iroyin pe ko si PR ti a ṣii.

`scripts/dev/sync-ui-kit.sh <commit|latest> [clone]` daakọ `src/` ti o wa ni oke ni adehun yẹn (`latest` = tuntun `v*` tag) sinu `packages/ui-kit/src`, nlo iyipada ti a gba laaye nikan (o ju suffix `.js` silẹ lati agbewọle ojulumọ), o si ṣeto ẹya aaye iṣẹ ni `packages/ui-kit/package.json` ati `package-lock.json` si oke oke. Lẹhinna: atunwo `git diff packages/ui-kit`, ṣe iwe-iwoye wiwo lori awọn olupese, awọn eto, awọn akojọpọ, lilo ati aaye ipari ni awọn akori mejeeji, ṣiṣe `npm run check:ui-kit-snapshot` ati `npm run test:vitest:ui`, ati ṣii PR pẹlu iyipada iyipada oke.

## 6. Àwọn àwòrán README

Àwọn àwòrán méjìlá tí a fi sínú `README.md` ní gbòǹgbò (`docs/diagrams/*.svg`) ń lo kit fún àwòrán aláìrìn. A ń dá wọn sílẹ̀, a kì í fi ọwọ́ yà wọn: fáìlì amújáde 13 ní `scripts/docs/gen-readme-*.mjs` (àwòrán méjìlá àti olùdarí `gen-readme-diagrams.mjs`) àti ìdánwò 12 fún ohun tó ti di àtijọ́ ní `tests/unit/docs/readme-*-svg.test.ts`, ọ̀kan fún àwòrán kọ̀ọ̀kan. Ìdánwò kọ̀ọ̀kan ń fi fáìlì inú commit wé àbájáde amújáde rẹ̀ byte kọ̀ọ̀kan (iṣẹ́ `test-unit`).

- **Awọn ami-ami.** `scripts/docs/readme-diagram-theme.mjs` daakọ paleti Awọn ikede (iwo aiyipada) lati `packages/ui-kit/src/ci-editions.css` (ti a fi si faili yẹn nipasẹ `tests/unit/docs/readme-diagram-theme.test.ts`, eyiti o tun ṣe ayẹwo WCAG AA fun gbogbo awọ ọrọ lori gbogbo oju ni awọn ero mejeeji; iyasọtọ kan, ina `warn`, jẹ ikilọ kit ṣokunkun 10% nitori iye kit jẹ 4.46:1 lori kanfasi) ati asọye ọrọ `ci-tokens.css` ni iwọn kanfasi): awọn iwuwo kit (400/500/600, ifihan ni 500) ati ipasẹ fun ohun gbogbo, ayafi awọn ipa koodu (`.cmd`, `.term`, `.term-lg`, `.mono`, `.mono-sm`, `.mono-xs`), eyiti o jẹ IBM Plex Mono ati pe o wa fun awọn aṣẹ nikan, URLs, awọn idanimọ ati awọn iboju ebute. Awọn iye ina joko lori `:root`, awọn iye dudu lẹhin `prefers-color-scheme: dark`, inu faili naa, nitorinaa aworan kọọkan tẹle ero oluwo lori GitHub.
- **Awọn nkọwe.** GitHub Markdown ko gbe CSS ko si ati pe camo proxy dina gbogbo bulọọki ita, nitorinaa iru ohun elo ni lati rin irin-ajo sinu faili naa. `scripts/docs/readme-outline.mjs`, igbesẹ ti o kẹhin ti gbogbo olupilẹṣẹ, ṣe apẹrẹ awọn ipa Switzer pẹlu HarfBuzz ati fa wọn gẹgẹbi awọn ilana vector ( awọn ọna `<defs>` ati `<use>`), pẹlu awọn itọka ati awọn aami jiometirika Switzer ko ni iyaworan lori awọn metiriki tirẹ. Awọn ilana, kii ṣe fonti ti a fi sinu: Iwe-aṣẹ Switzer (`packages/ui-kit/src/fonts/FFL.txt`) ṣe idiwọ isọdọtun ati iyipada ọna kika laisi aṣẹ kikọ ati gba awọn iyaworan fekito laaye, nitorinaa ma ṣe tun Switzer `@font-face` tabi `data:` URI bẹrẹ. Fọọmu kan ti o ku ninu faili ni OFL IBM Plex Mono subset fun ohun ti o duro ọrọ koodu gidi (`scripts/docs/readme-fonts.mjs`), ti a ṣe lati awọn ohun kikọ wọnyẹn; eyikeyi glyph ko le fi sabe jiju.
- **Tuntun-pada.** `npm run docs:readme-diagrams` tun kọ gbogbo awọn mejila ni aṣẹ README ati tẹ laini kan fun faili pẹlu iwọn rẹ. Olupilẹṣẹ ẹyọkan tun nṣiṣẹ lori tirẹ (`node scripts/docs/gen-readme-<name>.mjs`; `free-tier-budget` nilo `node --import tsx/esm` nitori awọn eeka rẹ wa lati agberu katalogi laaye ni `open-sse/config/freeModelCatalog.ts`; abajade CI ti iyipada katalogi kan wa ni `docs/architecture/QUALITY_GATES.md` → `docs-sync-strict`). Fi monomono ati SVG naa papọ.
- **Ẹ̀rí.** `scripts/docs/readme-svg-shots.mjs <file.svg> <outdir>` ń fi fáìlì hàn nínú ìdánwò lórí ẹ̀rọ (tag `<img>`, `Content-Security-Policy` tó fi ààlà sílẹ̀ àti èsì `image/svg+xml`), ó ń ya àwòrán ìmọ́lẹ̀ àti òkùnkùn, ó sì ń ròyìn ìbéèrè font láti òde tí ojú ìwé ṣe; iye wọn gbọ́dọ̀ jẹ́ 0.

- **Isuna.** Labẹ 200 KB fun faili kan (idanwo staleness kọọkan jẹri rẹ); 500 KB jẹ fila lile fun aworan README eyikeyi (ofin SVG isise afọwọsi).
- **Ọ̀rọ̀ tí a jọ lò, nọ́mbà láti gate.** olupilẹṣẹ kọọkan n gbe ẹda aworan rẹ ni igbagbogbo `*_COPY` (tabi kọ ọ lati inu katalogi laaye) ti o jẹ mejeeji ọrọ ti o ya ati titẹ sii ti igbesẹ itọka. Awọn isiro Canonical duro ni awọn apa `<text>` (airi ti a ṣe alaye lẹkan, `fill-opacity:0`), kika nipasẹ `check:docs-counts` (`scripts/check/check-docs-counts-sync.mjs`); awọn idanwo iduroṣinṣin ti awọn aworan atọka ti ẹnu-ọna kika tun ṣiṣe awọn olufọwọsi rẹ lori faili ti ipilẹṣẹ, nitorinaa eeya kan ti o yọ kuro lati koodu naa kuna idanwo — ṣe atunṣe orisun ti ẹnu-ọna kika, kii ṣe nọmba ninu monomono.
