> Fún àwọn àwòrán atọ́ka ìṣètò ìmọ̀-ẹ̀rọ gbogbogbò àti ìrònú tó wà lẹ́yìn ẹ̀ka-iṣẹ́ kọ̀ọ̀kan, ka
> [ARCHITECTURE.md](./ARCHITECTURE.md). Fún àlàyé jíjinlẹ̀ nípa àwọn ẹ̀ka-iṣẹ́ kọ̀ọ̀kan
> (Auto Combo, MCP server, A2A server, Skills, Memory, Cloud Agents, Resilience,
> Compression, àti bẹ́ẹ̀ bẹ́ẹ̀ lọ), wo àwọn fáìlì tí a yàn fún wọn nínú àkójọpọ̀ `docs/` yìí.

Fáìlì yìí ṣàpèjúwe **ohun tó wà nínú ibi ìpamọ́ kóòdù náà lónìí** kí onímọ̀-ẹ̀rọ tuntun
lè lọ káàkiri ìṣètò igi náà, lóye bí àwọn ìpele runtime ṣe tò, kí ó sì mọ ibi tí yóò ti ṣàfikún kóòdù
láì dá àwọn module tuntun sílẹ̀.

## 1. Àkójọpọ̀ Ẹ̀rọ

| Kókó            | Àṣàyàn                                                                                                                     |
| --------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Ìlànà ayélujára | **Next.js 16** (App Router, àbájáde àdúróṣinṣin, láìsí middleware gbogbogbò)                                               |
| Èdè             | **TypeScript 6.0+** — target `ES2022`, `module: esnext`, `moduleResolution: bundler`, `strict: false`                      |
| Àyíká ìṣiṣẹ́     | **Node.js** `>=22.22.2 <23` tàbí `>=24.0.0 <27` (a fi lé ọgbà múlẹ̀ nípasẹ̀ `engines` + `SUPPORTED_NODE_RANGE`)              |
| Dátábéesì       | **SQLite** nípasẹ̀ `better-sqlite3` (singleton, ìkọ̀sílẹ̀ WAL)                                                                |
| Désítóòpù       | **Electron 41** + `electron-builder` 26.10 (ilé-iṣẹ́ ọtọ̀ọtọ̀ ní `electron/`)                                                 |
| Àwọn ìdánwò     | **Olùṣe ìdánwò abínibí ti Node** (ẹyọ/ìsopọ̀), **Vitest** (MCP, autoCombo, ìpamọ́), **Playwright** (e2e + protocols-e2e)     |
| Ìkọ́lẹ̀           | Next.js àdúróṣinṣin nípasẹ̀ `scripts/build/build-next-isolated.mjs`                                                         |
| Ìyẹ̀wò/ìbọ̀wọ́     | Ìṣètò píláàtì ESLint + Prettier (`lint-staged` nípasẹ̀ Husky pre-commit)                                                    |
| Ètò mójúùlì     | ESM ní gbogbo ibi (`"type": "module"`)                                                                                     |
| UI Dásùbọ́òdù    | **Tailwind CSS 4** + **Keak CI UI Kit** tí a fi kún inú àkópọ̀ (`packages/ui-kit`), àwọn àmì Lucide — wo `DESIGN_SYSTEM.md` |
| Àwọn ilé-iṣẹ́    | Àwọn ilé-iṣẹ́ npm — `open-sse`, `packages/browser-pool`, `packages/ui-kit`                                                  |

Àwọn orúkọ ẹlẹ́yà ọ̀nà (`tsconfig.json`):

- `@/*` → `src/*`
- `@omniroute/open-sse` → `open-sse/index.ts`
- `@omniroute/open-sse/*` → `open-sse/*`
- `@omniroute/ui-kit` → `packages/ui-kit/src`, `@omniroute/ui-kit/*` → `packages/ui-kit/src/*`

Póòtì HTTP àtìbátálẹ̀: **`20128`** (API àti dásùbọ́òdù ń pín ìlànà kannáá). Àkópọ̀
dátà ni àyípadà àyíká `DATA_DIR`, tí ó ń padà sí `~/.omniroute/` ní àtìbátálẹ̀.

### 3.1 `src/app/` — App Router

App Router ń gbé UI dasibodu àti HTTP API gbangba/ìṣàkóso jáde.
**Kò sí middleware gbogboògbò** — ìdíwọ́ ni wọ́n ń ṣe ní ọ̀nà kọ̀ọ̀kan.

Àwọn àbá ipò òkè lábẹ́ `src/app/`:

| Ọ̀nà                                                                           | Ète                                                     |
| ----------------------------------------------------------------------------- | ------------------------------------------------------- |
| `api/`                                                                        | Gbogbo àwọn ọ̀nà HTTP API (wo ṣíṣe pín rẹ̀ sípá ní ìsàlẹ̀) |
| `a2a/`                                                                        | Ópin A2A JSON-RPC 2.0 (`POST /a2a`)                     |
| `.well-known/agent.json/`                                                     | Ìwé ìṣàwárí Agent Card A2A                              |
| `(dashboard)/`                                                                | UI Dasibodu (ẹgbẹ́ ọ̀nà, kò sí àsáájú URL)                |
| `auth/`, `login/`, `forgot-password/`, `callback/`                            | Àwọn ìṣàn ìfàṣẹsì                                       |
| `landing/`                                                                    | Ojú-ìwé ìpolówó/landing                                 |
| `docs/`                                                                       | Olùwò ìwé API tó wà nínú rẹ̀                             |
| `status/`, `maintenance/`, `offline/`                                         | Àwọn ojú-ìwé ìṣiṣẹ́                                      |
| `privacy/`, `terms/`                                                          | Àwọn ojú-ìwé òfin                                       |
| `400/`, `401/`, `403/`, `408/`, `429/`, `500/`, `502/`, `503/`                | Àwọn ojú-ìwé àṣìṣe tó dúró                              |
| `error.tsx`, `global-error.tsx`, `not-found.tsx`, `forbidden/`, `loading.tsx` | Àwọn ààlà àṣìṣe/ìkójọpọ̀ framework                       |
| `layout.tsx`, `page.tsx`, `globals.css`, `manifest.ts`                        | Àgbo gbòngbo                                            |

## 10. Bí O Ṣe Lè Kópa

### Ṣàfikún olùpèsè tuntun

1. Forúkọsílẹ̀ rẹ̀ nínú `src/shared/constants/providers.ts` (Zod máa ń fọwọ́sí i nígbà ìkójọpọ̀).
2. Ṣàfikún olùṣiṣẹ́ kan nínú `open-sse/executors/` bí ọgbọ́n-àmúlò àkànṣe bá ṣe pàtàkì
   (fa `BaseExecutor` gùn).
3. Ṣàfikún olùtumọ̀ kan nínú `open-sse/translator/` bí kò bá lo ọ̀nà-kíkó OpenAI.
4. Bí ó bá dá lórí OAuth, ṣàfikún ààtò lábẹ́ `src/lib/oauth/providers/` àti
   `src/lib/oauth/services/`.
5. Forúkọsílẹ̀ àwọn model nínú `open-sse/config/providerRegistry.ts` (tàbí ibi ìforúkọsílẹ̀
   tó bá ọ̀nà-kíkó náà mu lábẹ́ `open-sse/config/`).
6. Kọ àwọn àdánwò lábẹ́ `tests/unit/`.

### Ṣàfikún ipa-ọ̀nà API tuntun

1. Ṣẹ̀dá `src/app/api/your-route/route.ts`.
2. Tẹ̀lé àpẹẹrẹ yìí: CORS → ìfọwọ́sí body pẹ̀lú Zod → ìjẹ́rìísí → fífi iṣẹ́ lé handler lọ́wọ́.
3. Bí request tuntun bá ní ìrísí tuntun: ṣàfikún schema Zod náà nínú `src/shared/validation/schemas.ts`.
4. Bí ó bá jẹ́ ti ìṣàkóso nìkan: ṣàfikún path náà sí `src/shared/constants/publicApiRoutes.ts`
   (denylist fún àyè API gbangba).
5. Ṣàfikún àwọn àdánwò lábẹ́ `tests/unit/`.
6. Ṣe àfikún sí `docs/reference/API_REFERENCE.md` àti `docs/openapi.yaml`.

### Ṣàfikún módùlù DB tuntun

1. Ṣẹ̀dá `src/lib/db/yourModule.ts`, kí o sì import `getDbInstance()` láti `./core.ts`.
2. Export àwọn iṣẹ́ CRUD fún domain rẹ.
3. Bí àwọn table tuntun bá wà: ṣàfikún migration lábẹ́ `src/lib/db/migrations/`, kí nọ́ńbà wọn
   tẹ̀lé ara wọn, kí wọ́n jẹ́ idempotent, kí wọ́n sì jẹ́ transactional.
4. Àwọn importer gbọ́dọ̀ lo direct imports láti `@/lib/db/yourModule` (kò sí barrel — a ti yọ layer re-export `localDb.ts` àtijọ́ kúrò).
5. Ṣàfikún àwọn àdánwò lábẹ́ `tests/unit/`.

### Ṣàfikún irinṣẹ́ MCP tuntun

1. Ṣàfikún ìtumọ̀ irinṣẹ́ náà lábẹ́ `open-sse/mcp-server/tools/` (tàbí fa
   `open-sse/mcp-server/schemas/tools.ts` gùn).
2. Yan scope tó yẹ (tàbí àwọn scope tó yẹ) nínú `src/shared/constants/mcpScopes.ts`.
3. Forúkọsílẹ̀ irinṣẹ́ náà nínú `open-sse/mcp-server/server.ts`.
4. Ṣàfikún àwọn àdánwò lábẹ́ `open-sse/mcp-server/__tests__/`.
5. Ṣe àfikún sí [MCP-SERVER.md](../frameworks/MCP-SERVER.md).

## 11. Àwọn Àṣà

- **Ọ̀nà-kíkọ code**: indent aláyè méjì, double quotes, ìbú character 100, semicolons,
  `es5` trailing commas — Prettier ń mú wọn ṣiṣẹ́ nípasẹ̀ `lint-staged`.
- **Àwọn import**: ti òde → ti inú (`@/`, `@omniroute/open-sse`) → relative.
- **Ìsọrúkọ**: àwọn file `camelCase` tàbí `kebab-case`, àwọn component `PascalCase`,
  àwọn constant `UPPER_SNAKE`.
- **ESLint**: `no-eval`, `no-implied-eval`, `no-new-func` = `error` níbi gbogbo;
  `no-explicit-any` = `warn` nínú `open-sse/` àti `tests/`, error ní àwọn ibòmíràn.
- **TypeScript**: `strict: false` (ìdúró àtijọ́). Yan àwọn type tó ṣe kedere dípò
  inference fún àwọn ààlà tó kọjá láàárín módùlù.
- **Database**: má ṣe kọ SQL tààrà nínú àwọn route tàbí handler — lo àwọn módùlù
  `src/lib/db/` nígbà gbogbo. Má ṣe barrel-import láéláé — lo àwọn módùlù `src/lib/db/*` pàtó ní tààrà.
- **Ìsọrúkọ entity DB (#3512)**: function tó ń kọ tàbí ka ìrísí row table DB
  gbọ́dọ̀ gba/dá TS interface tó ní orúkọ padà, tí ó ṣe àfihàn àwọn column table náà
  ní ìbámu 1:1, kì í ṣe `any` tàbí type aláìlórúkọ inline níbi ìpè náà. Fi
  interface náà sí lẹ́gbẹ̀ẹ́ function náà (fún àpẹẹrẹ, `export interface UsageEntry` nínú
  `src/lib/usage/usageHistory.ts` lókè `saveRequestUsage`), jẹ́ kí àwọn field kọ̀ọ̀kan
  jẹ́ optional/nullable nígbà tí àwọn writer ọ̀tọ̀ọ̀tọ̀ bá ń kún row náà
  díẹ̀díẹ̀, kí o sì yan `unknown` dípò `any` fún field tí ìrísí rẹ̀
  ń yàtọ̀ láàárín àwọn caller (ṣàkọsílẹ̀ rẹ̀ lórí field náà, fún àpẹẹrẹ `UsageEntry.tokens`
  gba usage ìrísí provider gangan àti ìrísí normalized). Nígbà tí iye `any`
  inú file kan bá dé òdo ní ọ̀nà yìí, ṣàfikún un sí allowlist
  `check:any-budget:t11` (`scripts/check/check-t11-any-budget.mjs`,
  `maxAny: 0`) kí ó má bàa padà sẹ́yìn. Èyí jẹ́ àṣà apá-àkọ́kọ́ — iṣẹ́ ìmótótó
  “kò sí `any` aláìlórúkọ” tó gbòòrò sí i ń tẹ̀síwájú ní ìpele káàkiri gbogbo
  codebase náà.
- **Àwọn error**: lo try/catch pẹ̀lú àwọn type error pàtó, kí o sì log pẹ̀lú context pino. Má ṣe
  pa àwọn error mọ́ ní ìdákẹ́jẹ nínú àwọn stream SSE; lo àwọn signal abort fún ìmótótó.
- **Ààbò**: má ṣe lo `eval()` / `new Function()` / implied eval láéláé. Fọwọ́sí
  gbogbo input pẹ̀lú Zod. Encrypt àwọn credential nígbà tí wọ́n wà ní ìpamọ́ (AES-256-GCM). Jẹ́ kí
  denylist `src/shared/constants/upstreamHeaders.ts` bá layer
  sanitize/validation mu.
- **Àwọn commit**: Conventional Commits — `feat(scope): subject`. Àwọn scope tí a gba:
  `db`, `sse`, `oauth`, `dashboard`, `api`, `cli`, `docker`, `ci`, `mcp`,
  `a2a`, `memory`, `skills`.
- **Àwọn branch**: prefix `feat/`, `fix/`, `refactor/`, `docs/`, `test/`,
  `chore/`. Má ṣe commit sí `main` ní tààrà láéláé.
- **Husky**: pre-commit máa ń ṣiṣẹ́ `lint-staged` + `check:docs-sync` +
  `check:any-budget:t11`; pre-push máa ń ṣiṣẹ́ `check:any-budget:t11` + `check:tracked-artifacts` (àwọn ìdánwò yíyára; kò fi `test:unit` sínú).

## 12. Àwọn Òfin Tí Kò Gbọdọ̀ Yípadà (láti inú CLAUDE.md)

1. Má ṣe fi àwọn àṣírí tàbí ẹ̀rí ìdánimọ̀ sínú commit láé.
2. Má ṣe lo barrel-import láé — lo àwọn module `src/lib/db/*` pàtó ní tààrà.
3. Má ṣe lo `eval()` / `new Function()` / eval tí a fi ọ̀nà àìṣe-taara hàn láé.
4. Má ṣe ṣe commit ní tààrà sí `main` láé.
5. Má ṣe kọ SQL aláìṣàtúnṣe sínú àwọn route láé — máa gba inú àwọn module `src/lib/db/` kọjá nígbà gbogbo.
6. Má ṣe fi ìdákẹ́jẹ́ gbé àwọn àṣìṣe mì nínú àwọn stream SSE láé.
7. Máa fìdí àwọn input múlẹ̀ pẹ̀lú àwọn schema Zod nígbà gbogbo.
8. Máa fi àwọn test kún un nígbà gbogbo tí o bá ń yí code production padà.
9. Coverage gbọ́dọ̀ dúró ní ≥ 60% (àwọn statement, line, function, àti branch).
