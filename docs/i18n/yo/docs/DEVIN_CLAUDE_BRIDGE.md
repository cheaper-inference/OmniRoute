`devin-cli-agentic` ń jẹ́ kí runtime Claude Code gidi lo endpoint Messages Anthropic ti
OmniRoute ti agbègbè, nígbà tí Devin CLI àṣẹ́fọwọ́sí ń pèsè àwọn ìdáhùn model nípasẹ̀ ACP stdio. Kò
ṣe àtúnṣe àwọn provider Anthropic, Claude OAuth, Claude Web, tàbí `devin-cli` tó ti wà tẹ́lẹ̀.

Fún àwọn tool call tí client ní, darí wọn gba `devin-cli-agentic` (alias `dva`), provider
tó lè lo tool ní ìrísí Claude. ACP executor `devin-cli` (`dv`) àtijọ́ jẹ́
text-only: ó ń ṣiṣẹ́ summarizer Devin tí kò ní tool, kò sì lè dá tool call padà. A ti
samisi metadata model rẹ̀ gẹ́gẹ́ bẹ́ẹ̀, kí combo routing tó nílò tool lè yẹra fún un.

> **Ipò lọ́wọ́lọ́wọ́: Claude Code `2.1.258` tí a pin mọ́; ìfọwọ́sí offline àti live tí a gbasilẹ kẹ́yìn
> wà lórí `2.1.220`.** Pin `2.1.220` parí àwọn scenario mẹ́ta tí a yà sọ́tọ̀ nípasẹ̀ Devin CLI
> `3000.2.17` àti model `swe-1-7-lightning`; live run ìkẹyìn yẹn fi hàn pé àwọn turn `Read`,
> `Edit`, àti `Bash` tí client ní ṣiṣẹ́, àwọn èsì `npm test` ṣàṣeyọrí, project command àti skill
> discovery ṣiṣẹ́, routing Devin-nìkan ṣẹlẹ̀, kò sì sí Claude egress rárá. Lẹ́yìn náà, a gbé pin náà sókè sí `2.1.258`
> (ìran CLI tí identity Claude ti OmniRoute ń fara wé, àti line àkọ́kọ́ tó ní
> tier Fable 5.1 lọ́nà abinibi). Lórí pin tuntun náà, a ti ṣàyẹ̀wò install layer àti `claude --version`
> lórí base image tí a pin mọ́, bridge unit suite, `compose config`, àti
> ẹ̀rí static isolation sì kọjá — ṣùgbọ́n a kò tíì tún offline mock scenario àti live three-scenario
> suite ṣiṣẹ́. Tún wọn ṣiṣẹ́ (wo "Ṣíṣe àfikún sí àwọn tool tí a pin mọ́") kí o tó gbára lé
> bridge náà pẹ̀lú pin yìí.

## Àwòrán-ẹ̀rọ

```text
Claude Code 2.1.258 (container Linux non-root tí a yà sọ́tọ̀)
  -> http://omniroute:20128/v1/messages
  -> devin-cli-agentic (ìrísí Claude, provider tí kò nílò ìfàṣẹsí)
  -> devin acp --agent-type summarizer (ACP stdio àṣẹ́fọwọ́sí, kò ní tool Devin)
  -> Account Devin nínú volume devin-auth tí a yà sọ́tọ̀
```

ACP agent àìyípadà ti CLI àṣẹ́fọwọ́sí lè ṣiṣẹ́ àwọn tool tirẹ̀, nítorí náà bridge yìí kò
lò ó. Ó ń bẹ̀rẹ̀ ACP agent `summarizer` tí a ti sọ di àìyípadà, èyí tí mode CLI àṣẹ́fọwọ́sí rẹ̀ kò ní tool, ó sì
ń ṣe request Anthropic tí a serialize sí execution trace. Nígbà tí action mìíràn tí
Claude ní bá pọndandan, response náà gbọ́dọ̀ ní client tool envelope kan ṣoṣo péré. ACP
`tool_call` tàbí `tool_call_update` èyíkéyìí ni a máa kọ̀ ṣáájú kí a tó lè jabo response kan
gẹ́gẹ́ bí èyí tó ṣàṣeyọrí.

Serializer inú `open-sse/executors/devin-agentic/serializer.ts` ń pa `system`,
`text`, `tool_use`, `tool_result`, `thinking`, `redacted_thinking`, `tool_choice`, àti àwọn
tool tí Claude Code pèsè mọ́. Àwọn image àti block àìmọ̀ máa kuna ní kedere. Àwọn èsì tool ńlá
ń lo àmì truncation tó ṣeé rí.

Parser náà ń gba envelope `<tool>{...}</tool>` kan ṣoṣo tó dúró lọ́tọ̀ fún model turn kọ̀ọ̀kan. Ó ń ṣàyẹ̀wò
name náà pẹ̀lú àkójọ tool inú request, ó ń fìdí àwọn argument múlẹ̀ pẹ̀lú JSON
Schema ti tool náà, ó ń kọ ìdàpọ̀ narrative/action, ó sì ń gba repair kan tó ní ààlà láyè. Lẹ́yìn náà, Claude Code
ń ṣiṣẹ́ Anthropic `tool_use` tó yọ jáde ní agbègbè, ó sì ń fi `tool_result` náà padà nípasẹ̀
OmniRoute.

## Routing aládàáṣe

Provider náà lè kópa nínú àwọn candidate pool `auto/*` ti OmniRoute nígbà tí a kò bá dènà rẹ̀.
Yíyẹ láti jẹ́ candidate kò ṣe ìdánilójú pé a ó yan án: routing strategy combo náà (fún àpẹẹrẹ,
last-known-good) lè fẹ́ provider mìíràn. Lo `dva/<model>` tàbí combo Devin-first nígbà tí
o bá fẹ́ kí gbogbo request gba Devin kọjá.

## Ìyàsọ́tọ̀ àti àwòṣe ewu

Fífìmọ́ Claude sórí olùgbàlejò, àkọọ́lẹ̀ rẹ̀, àti ìṣètò rẹ̀ kò sí láàárín ohun tí a ń bójú tó, a sì kà wọ́n sí ohun
tí a kọ̀ láti lò. Àwọn iṣẹ́ Compose:

- ń ṣiṣẹ́ gẹ́gẹ́ bí UID/GID `10001:10001`, pẹ̀lú ètò fáìlì gbòǹgbò tí a lè kà nìkan, àwọn agbára tí a ti yọ kúrò, àti
  `no-new-privileges`;
- ń lo `/home/bridge` aládàáni, volume ìṣètò Claude tí a yà sọ́tọ̀, dátà OmniRoute tí a dá sọ́tọ̀,
  àti volume `devin-auth` ọ̀tọ̀;
- ń mount àwọn workspace/ẹ̀rí `.sandbox` tí a lè sọ nù nìkan;
- kò mount home olùgbàlejò, Keychain, SSH, àwọn ìjẹ́rìísí cloud, tàbí socket Docker;
- ń kọ àwọn environment tí a sọ pàtó, wọ́n sì ń yọ àwọn variable API/OAuth/routing Anthropic kúrò;
- ń darí inference Claude Code sí `http://omniroute:20128` nìkan pẹ̀lú key tí a lò ní agbègbè náà nìkan.

Profile offline ń lo network inú. Nínú profile live, OmniRoute ń dé àwọn endpoint Devin
ìfọwọ́sowọ́pọ̀ nìkan nípasẹ̀ `network-guard`; a kọ àwọn ibi míì tí kò ní í ṣe pẹ̀lú rẹ̀.
Claude Code ní guard egress ọ̀tọ̀ tí ń kọ gbogbo ohun, ó sì lè dé iṣẹ́ OmniRoute agbègbè náà
nìkan nípasẹ̀ `NO_PROXY`. Àwọn fáìlì audit guard ni process guard wọn nìkan ń mount. Àwọn
script náà ń ṣàyẹ̀wò olúwa fáìlì, mode, iye link, àti gbogbo ìpinnu kí wọ́n tó export
ẹ̀rí tí kò ní token.

Ṣe àfihàn ìyàsọ́tọ̀ náà lọ́nà òmìnira:

```bash
./scripts/devin-bridge/verify-anthropic-isolation
```

Ó ń fìdí topology, àwọn mount tí a dárúkọ, àwọn ìṣètò non-root/read-only, routing agbègbè tí a sọ pàtó,
àìsí àwọn environment variable tó ní ìkọ̀kọ̀, àìsí socket Docker, dídènà ìráyè sí
`api.anthropic.com` àti `claude.ai`, yíyan olupèsè Devin-nìkan, àti ìkùnà tó ṣe kedere nígbà
tí backend ACP kò bá sí múlẹ̀.

## Ìṣètò ìgbà àkọ́kọ́ àti lílò déédéé

Build image tí a ti pin mọ́ ẹ̀yà kan:

```bash
./scripts/devin-bridge/build
```

Ṣe ìfàṣẹsí fún volume Devin tí a yà sọ́tọ̀ nìkan:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/login-devin
```

Àṣẹ login náà ń lo ìlànà manual-token ìfọwọ́sowọ́pọ̀ tí a pèsè fún àwọn environment
remote/container. A ń tẹ value náà tààrà sínú prompt CLI; a kò fi í ránṣẹ́ gẹ́gẹ́ bí
argument process, kọ ọ́ sínú Git, tàbí daakọ rẹ̀ láti ọ̀dọ̀ olùgbàlejò.

Ṣí runtime Claude Code tí a yà sọ́tọ̀:

```bash
./scripts/devin-bridge/launch
```

`launch` tún ń ṣàyẹ̀wò ìyàsọ́tọ̀, ìfàṣẹsí Devin, àti ìṣàwárí model kí ó tó bẹ̀rẹ̀
Claude Code inú container. Kò ṣiṣẹ́ executable Claude ti olùgbàlejò láéláé. A lè ṣètò
àwọn alias model nínú `.env.devin-bridge`; gbogbo value tí a ṣètò gbọ́dọ̀ pa
prefix `devin-cli-agentic/` mọ́.

## Àwọn àṣẹ ìfọwọ́sí

Ọ̀nà offline tí a lè tún ṣe kò nílò àkọọ́lẹ̀ Devin, kò sì ní Internet ní runtime:

```bash
./scripts/devin-bridge/test-unit
./scripts/devin-bridge/test-contract
./scripts/devin-bridge/test-e2e-mock
./scripts/devin-bridge/verify-anthropic-isolation
```

Ọ̀nà live ìfàṣẹsí tí a yan láti darapọ̀ mọ́ ni:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/test-live-devin
```

Runner live náà ń dúró láàárín àwọn scenario láti yàgò fún ṣíṣí àwọn session ACP lọ́pọ̀ lẹ́ẹ̀kan,
ó sì ń fìdí àwọn event stream Claude tó ní ìṣètò múlẹ̀ dípò gbígbẹ́kẹ̀lé àwọn àlàyé ọ̀rọ̀.
Àwọn scenario mẹ́ta rẹ̀ fi àwọn wọ̀nyí hàn:

1. kíkà project tààrà àti ìtúpalẹ̀ àbùkù;
2. `Edit` gidi kan, `Bash` `npm test` tí client ní, àti èsì terminal kan;
3. `/bridge-check` pẹ̀lú ìṣàwárí `bridge-proof`, kíkà project, `npm test` mìíràn tí client ní
   tó ṣàṣeyọrí, àti ìparí láìsí iṣẹ́ tó ṣì ń dúró.

Gate ìkẹyìn náà tún ń ṣàyẹ̀wò audit network Devin, ó sì ń béèrè pé kí audit egress Claude
wà ní òfo.

## Ṣíṣe ìmúdójúìwọ̀n àwọn irinṣẹ́ tí a ti ṣètò sí ẹ̀yà pàtó

Àwòrán náà ṣètò Node, Claude Code, àti Devin CLI sí àwọn ẹ̀yà pàtó nínú
`docker/devin-bridge/Dockerfile`. Láti ṣe ìmúdójúìwọ̀n:

1. yí àwọn ẹ̀yà tí a sọ ní pàtó padà;
2. rọ́pò àwọn checksum ibi-ipamọ́ Devin méjèèjì tó jẹ́ ti faaji kọ̀ọ̀kan pẹ̀lú àwọn iye fún artifact
   oníṣẹ́;
3. tún kọ́ ọ, kí o sì ṣiṣẹ́ gbogbo command ìfọwọ́sí aláìsílẹ̀-orí-ayelujara;
4. jẹ́rìí àwọn ẹ̀yà inú àwòrán náà;
5. tún suite aláràyé oníscenario mẹ́ta tó ní ìfàṣẹsí ṣiṣẹ́.

Má ṣe fi èyíkéyìí nínú àwọn CLI náà sílẹ̀ ní gbogbo agbègbè lórí host, má sì fi download tí a kò
fọwọ́sí rọ́pò ìjẹ́rìísí checksum.

## Ìṣàwárí ìṣòro àti ìmọ́tótó

- `docker compose -f docker/devin-bridge/compose.yml --profile offline logs omniroute`
  ń ṣàfihàn routing agbègbè àti àwọn aṣiṣe executor tí a ti sọ di àìléwu.
- `.sandbox/evidence/mock-acp.jsonl` ń ṣàkọsílẹ̀ àwọn ìgbésẹ̀ mock ACP tó máa ń fúnni ní àbájáde kan náà.
- `.sandbox/evidence/claude-stream.jsonl` ń ṣàkọsílẹ̀ ìṣiṣẹ́ aláìsílẹ̀-orí-ayelujara Claude Code gidi.
- `.sandbox/evidence/live-*.jsonl` ń ṣàkọsílẹ̀ àwọn stream aláràyé mẹ́ta tí a ti fọwọ́sí.
- `.sandbox/evidence/egress.jsonl` àti `.sandbox/evidence/claude-egress.jsonl` jẹ́ àwọn ẹ̀dà tí a ti
  fọwọ́sí, tí kò ní token, ti àwọn àyẹ̀wò guard.

Dá àwọn container àti network tí afárá náà ní dúró, nígbà tí o ń pa àwọn volume login/config mọ́:

```bash
./scripts/devin-bridge/clean
```

Yọ gbogbo àyíká tí afárá náà ní kúrò, pẹ̀lú àwọn volume olórúkọ:

```bash
./scripts/devin-bridge/clean --all
```

## Àwọn ààlà

- Afárá náà gbára lé role `summarizer` aláìní-irinṣẹ́ tí a ti dì mọ́ nítorí pé Devin CLI `3000.2.17`
  kò pèsè agent ACP aláìní-irinṣẹ́ tó jẹ́ aláìṣègbè. Adapter náà ń ṣàtúnṣe fún àwọn ìdáhùn
  àárín-ọ̀nà tó ní ìrísí àkótán, ṣùgbọ́n àtúnṣe kan tó ní ààlà ṣì lè kùnà ní kedere.
- Àwọn ìpè ACP aláràyé lè dá àwọn ìdáhùn `502`/`504` tó jẹ́ ti ìgbà díẹ̀ padà. Harness náà ń fi
  àkókò sí àárín àwọn scenario; ìkùnà tó ń bá a lọ máa ń pa mọ́ nígbà ìkùnà, kò sì ní yan
  olupèsè mìíràn láé.
- A tún context ACP ṣe láti inú request Anthropic kọ̀ọ̀kan; kò sí ìfararọ̀ process/session.
- Tool call kan ṣoṣo ni a ṣe àtìlẹ́yìn fún nínú ìdáhùn model kọ̀ọ̀kan; a kọ àwọn call tó ń ṣiṣẹ́
  ní ìfàra-ẹni-ní-àkókò-kan náà.
- A kò ṣe àtìlẹ́yìn fún àwọn àwòrán ní kedere. A kò polongo vision, àbájáde ìrònú, àwọn
  ìṣàkóso ìsapá, àti window context 1M.
- SSE ń lo àwọn ìṣẹ̀lẹ̀ iyípo ìgbésí-ayé Anthropic tó péye, ṣùgbọ́n a máa ń gbé e jáde lẹ́yìn
  tí a bá ti kó ìyípo ACP tó ní ààlà jọ; a kò fi àwọn chunk ACP ránṣẹ́ síwájú díẹ̀díẹ̀.
