Pool tí a gbàlejò fúnra wa ń ṣiṣẹ́ lórí ẹ̀rọ **.113** (`tomni-proxmox-113`). Láti 2026-10-18, runner
OmniRoute kọ̀ọ̀kan ní **ipa kan**, label kan, àti ìpín memory/CPU tí a ṣe ní ìwọ̀n iṣẹ́ tí workload rẹ̀
fi hàn. Slot Turbopack ń gba ohun tí build náà nílò; a ṣe àwọn slot yòókù ní ìwọ̀n peak tí a
wọn fún wọn. Ẹ̀rọ náà máa ń ṣe overcommit nìkan nígbà tí build Turbopack bá ṣẹlẹ̀ lẹ́ẹ̀kan náà pẹ̀lú build
webpack Release-Green àti iṣẹ́ lint kan; swap host (16 GB) ń gba èyí, àti nítorí pé àwọn Build pull-request ń ṣiṣẹ́
lórí hosted runner, slot Turbopack kì í ṣiṣẹ́ ní ọ̀pọ̀ jù lọ àkókò:

| runner               | label           | ipa                                                                                                                                               | `MemoryHigh` / `MemoryMax` | `CPUQuota`   |
| -------------------- | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------- | ------------ |
| `omniroute-113-5`    | `omni-build`    | Àwọn build Turbopack: `ci.yml` `Build` (push/dispatch nìkan), Docker amd64, `npm-publish`, `nightly-v4-build`, `preview-artifact`, build a11y alẹ́ | 56 GB / 60 GB (swap 0)     | 1600 %       |
| `omniroute-113-6`    | `omni-release`  | Release-Green (`release-green` + `main-green`), build webpack                                                                                     | 20 GB / 24 GB (swap 4 GB)  | 800 %        |
| `omniroute-113-2`    | `omni-light`    | àwọn iṣẹ́ alẹ́ (Schemathesis, promptfoo, garak, k6) àti `quality.yml` `lint-guard`                                                                  | 12 GB / 16 GB (swap 4 GB)  | 600 %        |
| `omniroute-113`      | `omni-light`    | pool kan náà bí èyí tó wà lókè                                                                                                                    | 8 GB / 12 GB               | 400 %        |
| OmniHeuris, OmniMind | (àwọn repo wọn) | Dependabot nìkan (peak 155 MB kọ̀ọ̀kan, 2026-10-18)                                                                                                 | 4 GB / 6 GB                | 200 % kọ̀ọ̀kan |

| ---------- | ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

Build Turbopack kan + build webpack kan lè wọ̀ papọ̀; build Turbopack méjì kò lè wọ̀ |
| swap       | 16 GB                        | `omniroute-113-5` ń ṣiṣẹ́ pẹ̀lú swap tí a pa (`MemorySwapMax=0`), nítorí náà build tí ó jáde kúrò ní ìṣàkóso ni a máa gé ní cap rẹ̀ dípò kí ó fi ẹ̀rọ náà ṣe swap                                                                                                                                                                                                          |
| `/tmp`     | **12 GB tmpfs = RAM**        | ohunkóhun tí a fi síbẹ̀ jẹ́ memory; a máa ń pa àwọn ohun tó ṣẹ́kù rẹ́ lẹ́yìn 3 h                                                                                                                                                                                                                                                                                            |
| CPU        | a rí load 60 lórí 32 cores   | ṣáájú àwọn quota náà, build Turbopack kan (~1166 % CPU) pẹ̀lú suite coverage kan lórí ẹ̀rọ kan náà mú kí àwọn heartbeat listener yòókù má rí resource tó tó (`The self-hosted runner lost communication`, #16853)                                                                                                                                                        |
| runners    | **7 listeners** (2026-10-28) | 5 OmniRoute + OmniHeuris + OmniMind; `omniroute-113-7` tún gbé `omni-build`; a ti pa `omniroute-113-3/-4/-8` rẹ́ kúrò nínú repository (2026-10-28)                                                                                                                                                                                                                      |

Àwọn limit náà wà nínú `/etc/systemd/system/actions.runner.<…>.service.d/override.conf` ti unit kọ̀ọ̀kan
(a pa àwọn iye tẹ́lẹ̀ mọ́ gẹ́gẹ́ bí `override.conf.bak-20261018`), a sì lò wọ́n láìdá iṣẹ́ dúró pẹ̀lú
`systemctl set-property --runtime … MemoryHigh=… MemoryMax=… CPUQuota=…` — kò sí restart, nítorí náà kò sí
iṣẹ́ tó ń ṣiṣẹ́ tí a fọwọ́ kàn. A ń yí àwọn label padà nípasẹ̀ API àwọn runner (`gh api -X DELETE repos/<repo>/actions/runners/<id>/labels/<label>` /
`gh api -X POST repos/<repo>/actions/runners/<id>/labels -f 'labels[]=<label>'`), láìdá iṣẹ́ dúró pẹ̀lú.

## Fi janitor sílẹ̀ (ẹ̀ẹ̀kan ṣoṣo, lórí ẹ̀rọ náà)

```bash
scp scripts/ops/runner-janitor.sh root@192.168.0.113:/opt/omniroute-ops/runner-janitor.sh
ssh root@192.168.0.113 'chmod +x /opt/omniroute-ops/runner-janitor.sh; apt-get install -y lsof'
# cron (root): ní gbogbo ìṣẹ́jú 30, kọ àkọsílẹ̀ sí /var/log/runner-janitor.log
*/30 * * * * MAX_ACTIVE_RUNNERS=8 /opt/omniroute-ops/runner-janitor.sh >> /var/log/runner-janitor.log 2>&1
```

A nílò `lsof`: janitor náà máa ń fi àwòrán-ipò kan ṣoṣo ti àwọn fáìlì tí ó ṣí sílẹ̀
jẹ́rìí pé path kan kò ṣiṣẹ́ mọ́ kí ó tó yọ ọ́ kúrò; láìsí irinṣẹ́ náà, kò ní yọ ohunkóhun
kúrò, yóò sì sọ bẹ́ẹ̀ (`exit 1`). Kọ́kọ́ dán gbogbo àyípadà wò pẹ̀lú `--dry-run` —
ó máa tẹ ohun tí yóò ṣe gan-an jáde, kò sì ní fọwọ́ kan ohunkóhun.

Ohun tí ó máa ń ṣe ní gbogbo ìṣiṣẹ́: ó máa ń gbá àwọn ohun tó ṣẹ́ kù tiwa kúrò
(`runner-*`, `omniroute-*`, `next-build*`, `e2e-build.tar.gz`) lẹ́yìn **wákàtí 3 lórí tmpfs**
àti wákàtí 24 lórí `_work/_temp` inú disk; ó máa ń pa `next-build` tí ó ti ju ìṣẹ́jú 75
lọ (kò sí job kankan tó máa ń ṣiṣẹ́ tó bẹ́ẹ̀ — ní 2026-08-27, ọ̀kan ṣiṣẹ́ fún ìṣẹ́jú 70
lẹ́yìn tí GitHub ti kéde pé job rẹ̀ ti sọnù); ó máa ń gé àwọn checkout tí ọjọ́-orí wọn
jẹ́ wákàtí 48 kúrò fún àwọn runner tí unit wọn ti **dúró**; ó máa ń fi ìkìlọ̀ ránṣẹ́
nígbà tí disk bá ≥ 85 %, memory PSI `full/avg60` bá ≥ 10 %, àti nígbà tí iye listener
bá pọ̀ ju `MAX_ACTIVE_RUNNERS` lọ (pẹ̀lú ìpín omniroute/òmíràn). `Exit 1` = a nílò
àkíyèsí; ka àkọsílẹ̀ náà.

Òfin ìṣẹ́jú 75 náà kò lè rí build kan tí GitHub ti fi sílẹ̀ tẹ́lẹ̀. Nígbà tí
`Runner.Listener` kò bá lè tún job rẹ̀ ṣe, `_diag/Runner_*.log` máa ń fi
`POST request to …/renewjob timed out after 100 seconds` hàn, API máa ń jẹ́rìí pé job náà ti
`completed` (failure) ní nǹkan bí ìṣẹ́jú mẹ́wàá lẹ́yìn ìtúnṣe tó ṣàṣeyọrí gbẹ̀yìn,
`next-build` sì máa ń bá iṣẹ́ lọ láìsí job tí a so mọ́ ọn (2026-10-18: Build ti #17066
kùnà ní 19:43, build rẹ̀ sì ṣì ń di 40 GB mú ní ìṣẹ́jú márùn-ún lẹ́yìn náà). Jẹ́rìí
ref náà nínú `_diag/Worker_*.log` tuntun jù lọ, lẹ́yìn náà lo PID láti fi SIGTERM pa
igi build náà nìkan — `next-build`, `npm run build`, `build-next-isolated.mjs` àti àwọn
worker inú `_work`. Má ṣe fọwọ́ kan `Runner.Listener`, `RunnerService.js` tàbí
`Runner.Worker` láé: worker máa ń jẹ́rìí pé a fagilé job náà, listener náà sì máa ń
padà sí online fúnra rẹ̀.

## Àwọn unit runner: KillMode

`KillMode=process` àtìlẹ́yìn runner máa ń fi `Runner.Worker → npm → next-build`
sílẹ̀ láàyè nígbà tí unit kan bá dúró tàbí tún bẹ̀rẹ̀ — build aláìní-olùtọ́jú náà
máa ń bá a lọ ní jíjẹ RAM àti CPU láìsí job tí a so mọ́ ọn. Gbogbo unit OmniRoute
ní drop-in kan
(`/etc/systemd/system/actions.runner.diegosouzapw-OmniRoute.<name>.service.d/10-killmode.conf`)
pẹ̀lú `KillMode=mixed`: SIGTERM sí listener lákọ̀ọ́kọ́, lẹ́yìn náà SIGKILL sí gbogbo
cgroup ní `TimeoutStop`. Yóò bẹ̀rẹ̀ sí í ṣiṣẹ́ nígbà tí unit náà bá tún bẹ̀rẹ̀ lẹ́ẹ̀kan
sí i — tún **runner kan ṣoṣo** bẹ̀rẹ̀ lẹ́ẹ̀kan, nígbà tí kò bá ṣiṣẹ́ nìkan, kí àyẹ̀wò
àìṣiṣẹ́ àti ìtún-bẹ̀rẹ̀ náà sì wà nínú command kan náà.

## Àwọn òfin ìṣiṣẹ́

- **Ìkọ́ Turbopack kan ṣoṣo lẹ́ẹ̀kan — a fi àmì àkọlé mú un ṣẹ.** Gbogbo iṣẹ́ tó ń ṣiṣẹ́
  `next build` Turbopack ní kíkún ni a darí sí `[self-hosted, omni-build]`, `omniroute-113-5`
  **nìkan** sì ni ó ní àmì àkọlé yẹn: `ci.yml` `Build`, `npm-publish.yml` `publish`,
  `nightly-v4-build`, `preview-artifact`, ìkọ́ a11y alẹ́ (#16853) àti **amd64**
  `docker-publish.yml` (webpack nínú BuildKit — Turbopack kọlu níbẹ̀, ìṣiṣẹ́ 33253576569).
  Ẹ̀ka Docker arm64 ṣì wà lórí `ubuntu-24.04-arm`. amd64 `docker-publish` ń pín ẹgbẹ́
  concurrency `heavy-build-main` pẹ̀lú `ci.yml` `Build` (`cancel-in-progress: false`).
  Docker Engine gbọ́dọ̀ wà lórí `omniroute-113-5`. Àyè Turbopack kejì kò lè gba inú 78 GB
  (2 × 33–37 GB pẹ̀lú ìyókù ohun tó wà lórí ẹ̀rọ náà); àyè kejì jẹ́ àìléwu fún àwọn ìkọ́
  webpack nìkan.
- **Àwọn Build pull-request ń ṣiṣẹ́ lórí hosted (2026-10-18).** `ci.yml` `Build` máa ń dé
  `omni-build` fún `push` àti `workflow_dispatch` nìkan; gbogbo Build `pull_request`
  (láti orísun tiwa tàbí fork) àti `merge_group` ń ṣiṣẹ́ lórí `ubuntu-latest` pẹ̀lú webpack.
  Nígbà tí gbogbo PR láti orísun tiwa ń lọ sí àyè náà, Build Turbopack kan máa ń dì í mú fún
  ìṣẹ́jú 29–58, Build 18 sì dúró ní ìlà títí dé wákàtí 18, Build push ti laini ìtújáde fúnra rẹ̀
  sì rí àyè náà lẹ́ẹ̀kan nínú iṣẹ́ 40. Lórí hosted, Build PR kan náà máa ń gba ìṣẹ́jú 8–12
  lẹ́gbẹ̀ẹ́ àwọn iṣẹ́ PR mìíràn. Turbopack, bundler tí `npm-publish` ń pín jáde, ṣì ń jẹ́
  dídánwò lórí laini ìtújáde nípasẹ̀ ìkọ́ a11y alẹ́ ti ẹ̀ka àkọ́kọ́ (04:41 UTC), nípasẹ̀ gbogbo
  Build push tàbí dispatch tó dé àyè náà, àti nípasẹ̀ `npm-publish` fúnra rẹ̀.
  `tests/unit/build/heavy-build-queue.test.ts` ń fi ẹnu-ọ̀nà onígbọ̀nwọ̀n mẹ́rin náà múlẹ̀.
- **Má ṣe dín àyè Turbopack kù sí ìwọ̀n tó kéré ju ohun tí a ti wọn pé ó nílò lọ.** Ní
  2026-10-18 ní 18:06, a dín àyè náà kù láti 56G/60G sí 40G/44G láti ṣe ààyè fún
  `omni-release`. Ìpele compile dúró ní `MemoryHigh` jálẹ̀ gbogbo ìṣiṣẹ́ rẹ̀ (memory PSI
  `full` 30–43 %), `Runner.Listener`, tó ń pín cgroup náà, kò sì lè tún iṣẹ́ rẹ̀ ṣe.
  A mú 56G/60G ti olówó rẹ̀ ti 2026-10-17 padà ní ọjọ́ kan náà. Ní ìsàlẹ̀ iye yẹn, ìkọ́ náà
  kì í kuna; ó máa ń yí ká láìlọ síwájú, iṣẹ́ náà sì máa ń sọnù.
- **Release-Green ní àyè tirẹ̀ (2026-10-18).** Títí di ìgbà yẹn, àwọn ìfọwọ́sí Release-Green
  méjèèjì ń ṣiṣẹ́ lórí `omni-build`: lórí gbogbo push (~10/wákàtí, 97 nínú ìṣiṣẹ́ push 100
  ni a fagilé ní àárín iṣẹ́ lọ́jọ́ kan) àti àwọn àyẹ̀wò kíkún mẹ́ta tó gba ~2 wákàtí lójúmọ́
  (àyẹ̀wò 05:29 dúró fún wákàtí 6 kí ó tó rí àyè náà) — a ń béèrè ohun tó ju agbára àyè ìkọ́
  kan ṣoṣo náà lọ ní ìlọ́po púpọ̀, àwọn Build PR láti orísun tiwa sì dúró fún ọ̀pọ̀ wákàtí.
  `release-green` àti `main-green` ń lọ sí `omni-release` báyìí (`omniroute-113-6` nìkan)
  pẹ̀lú `OMNIROUTE_USE_TURBOPACK=0`, ìṣiṣẹ́ tí ó ti bẹ̀rẹ̀ kì í sì í jẹ́ fífagilé mọ́ nípasẹ̀
  push tuntun (àyè tó ṣì ń dúró ṣì ń mú ìgbì iṣẹ́ náà kúrò).
  `tests/unit/build/runner-capacity-routing.test.ts` ń fi routing, ìyípadà webpack àti pé kò
  sí ohun kankan lórí `omni-release` tó ń kọ́ pẹ̀lú Turbopack múlẹ̀.
- **Pool fẹ́ẹ́rẹ́: `omni-light`.** `omniroute-113` àti `omniroute-113-2` ń ṣiṣẹ́ àwọn iṣẹ́ alẹ́
  tó nílò `next build` backend-nìkan (~5–6 GB; webpack) àti `quality.yml` `lint-guard`.
  `omniroute-113` ní `MemoryHigh=4G` títí di 2026-10-18 — ìkọ́ promptfoo fi ìṣẹ́jú 54 kọjá
  níbẹ̀ nípa jíjẹ́ kí a máa gba memory padà; 8 GB yọ ìdínwọ́ náà kúrò.
- **Àwọn listener díẹ̀ ní ìmọ̀ọ́mọ̀.** A pa unit OmniRoute mẹ́rin ní 2026-08-29 — listener
  àfikún kọ̀ọ̀kan jẹ́ tenant míràn fún ìṣúná memory tó wà lókè. Òpin janitor jẹ́ 8
  (`MAX_ACTIVE_RUNNERS=8` nínú cron): ó ń ka gbogbo `Runner.Listener` lórí ẹ̀rọ náà,
  OmniHeuris + OmniMind sì ń fi méjì kún márùn-ún tiwa.
- **Àwọn iṣẹ́ Unit àti Vitest ń wà lórí gbígbàlejò.** `ci.yml` máa ń fi àwọn shard unit rẹ̀ àti iṣẹ́ Vitest ránṣẹ́ sí
  `[self-hosted, omni-ci]` kìkì nígbà tí oniyipada repository `vars.USE_VPS_TEST_RUNNER` bá jẹ́
  `true`, àti nígbà náà pàápàá fún àwọn ìṣiṣẹ́ `pull_request` láti inú repository kan náà nìkan; àwọn fork, `merge_group`
  àti àwọn push ń wà lórí `ubuntu-latest` (`tests/unit/vps-runner-variable-scope.test.ts`). Oniyipada náà jẹ́
  `false`. Ní 2026-10-28, listeners `omni-ci` mẹ́ta tí ó ní core 4 gba 250–270 s fún `npm ci`, gbogbo
  shard unit sì dé òpin iṣẹ́ ìṣẹ́jú 30, ní ìfiwéra pẹ̀lú ~634 s fún shard gbígbàlejò, nígbà tí ẹrù ẹ̀rọ náà wà ní
  17–24. A ti pa àwọn listeners náà rẹ́. Má ṣe tan oniyipada náà padà láìsí listeners tí ìwọ̀n wọn tó fún
  shard unit kan.
- **Má ṣe fọ `/tmp` tàbí `_work` mọ́ pẹ̀lú ọwọ́ nígbà tí runner èyíkéyìí bá ń ṣiṣẹ́.**
  Ìlànà ṣíṣe àyẹ̀wò-lẹ́yìn-náà-píparẹ́ tó ní àlàfo láàárín àwọn ìgbésẹ̀ méjèèjì ni ó mú kí
  iṣẹ́ Build tó ń ṣiṣẹ́ pàdánù `_work` rẹ̀ ní 2026-08-27. Janitor ń ṣe àyẹ̀wò àti ìyọkúrò
  náà ní ìgbésẹ̀ kan; jẹ́ kí ó ṣe é.
- Dídá runner dúró ní àárín iṣẹ́ máa ń fagilé iṣẹ́ náà (a rí i ní tààrà): lo
  `systemctl stop` nígbà tí listener rẹ̀ kò ní ọmọ `Runner.Worker` nìkan — kí o sì ṣe é
  nínú àṣẹ kan.
- Àwọn workflow kò gbọ́dọ̀ kó àwọn artifact sí `/tmp` (RAM ni). Ṣe download sí
  `$RUNNER_TEMP` (lórí disk, fún runner kọ̀ọ̀kan) — artifact `next-build` 1.3 GB gba ìṣẹ́jú
  27–32 láti dé sórí tmpfs, ó sì gba ìṣẹ́jú 2 láti ṣe upload láti disk.
- VPS `.15` jẹ́ ti homologation nìkan — kò gbọdọ̀ ṣiṣẹ́ àwọn runner CI láé.
