## npm Igbẹkẹle Atẹjade (aiyipada lati v3.8.51) — ti ṣeto lori ibeere, taara bi ipadasẹhin

`npm-publish.yml` nkede nipasẹ** npm Titẹ Igbẹkẹle (OIDC)** nipa aiyipada: iṣẹ `stage-npm` (github-hosted) ṣe paṣipaarọ GitHub's id-token fun iwe-ẹri igba diẹ ti npm fun ṣiṣe yẹn — ko si ami npm ti o gun ni awọn aṣiri ibi ipamọ, ko si 2FA kiakia, ti o somọ. Iyẹn ni awọn ijẹniniya npm fori ni bayi pe awọn ami ti o fo 2FA ti wa ni ifẹhinti lẹnu iṣẹ; o restores ni kikun laifọwọyi sisan ise agbese ní soke si v3.8.48 nigba ti o pa WS1.3 lopolopo (a ti jo àmi ko le jade nikan — nibẹ ni ko si àmi).

**Iṣeto akoko-ọkan (ẹni):** npmjs.com → package `omniroute` → Eto → _Trusted Publisher_ → GitHub: eni `diegosouzapw`, repo `OmniRoute`, bisesenlo `npm-publish.yml` (agbegbe: ko si). Titi ti iyẹn yoo fi wa, igbesẹ adaṣe yoo kuna pẹlu `ENEEDAUTH`: tun-firanṣẹ pẹlu `publish_mode=staged` (isalẹ) tabi `direct`.

### Titẹjade ti o ṣeto (lori ibeere — `publish_mode=staged`)

Ṣiṣan iṣẹ atẹjade npm ko ṣe atẹjade taara: o bata bọọlu tarball (`check:pack-boot`) ati lẹhinna nṣiṣẹ `npm stage publish` — awọn baiti gangan ti wa ni gbesile lori iforukọsilẹ,** ko fi sori ẹrọ** titi eni to fi gba. Ẹnu-ọna 2FA eniyan gbe si AFTER ẹri, kii ṣe niwaju rẹ.

**Ṣiṣan oniwun lẹhin ṣiṣan iṣẹ n lọ alawọ ewe:**

1. `npm stage list omniroute` — wa id ipele (tun tẹ sita ninu akopọ iṣan-iṣẹ).
2. Daju awọn baiti ti a ṣeto (a ṣe iṣeduro): `npm stage download <id>`, lẹhinna fi tarball ti a gba lati ayelujara sinu asọtẹlẹ igba otutu kan ki o si bata (`npm run check:pack-boot` automates pack → kanna fi sori ẹrọ idajọ bata → ni CI).
3. `npm stage approve <id>` — awọn 2FA tọ IS awọn jade. `npm stage reject <id>` danu.
4. Nẹtiwọọki ti atẹjade: oluṣayẹwo ti atẹjade lẹhinjade (WS1.4 ti ero v3.8.49) fi ẹya ti a tẹjade sori ẹrọ lati iforukọsilẹ ti gbogbo eniyan ni apoti mimọ ati bata bata.

**Ipadabọ pajawiri:** `workflow_dispatch` pẹlu `publish_mode=direct` mu pada sipo `npm publish` lẹsẹkẹsẹ (lo nikan ti o ba ṣeto awọn iwa aiṣedeede; ṣe igbasilẹ idi).

**Lile akoko kan (oluni, npmjs.com):** tunto Olutẹwe Gbẹkẹle fun `omniroute` ni ipo ipele-nikan nitoribẹẹ ami ti o ti pẹ to ti jo ko le `npm publish` taara lati ibikibi — CI le ṣe ipele nikan; awọn idasilẹ 2FA ti eni nikan.

**Iwe-iṣere ti o bajẹ (ko yipada):** `npm deprecate omniroute@<bad> "<reason> — use <fixed>"` gẹgẹbi ifasilẹ aiyipada (awọn iṣẹju, iyipada); `npm unpublish` nikan inu awọn window 72h/no-dependents ati ki o ko bi akọkọ Gbe. Docker: maṣe tunkọ ẹya kan tag tag — rollback n ṣe atunto `latest` si arosọ ti o dara to kẹhin.

**Docker Hub `latest` (beere lori gbogbo atẹjade SemVer iduroṣinṣin):** iṣan-iṣẹ `docker-publish` gbọdọ tag** mejeeji** `X.Y.Z` ati, nigbati `should-promote-latest.sh` gba eyi ni iduroṣinṣin SemVer ti o ga julọ, `:latest` pẹlu awọn** kanna Daijesti** . Lẹhin iṣẹ naa: Hub `latest` daijesti dọgbadọgba SemVer daijesti tuntun ati gbigbe `last_updated`. Maṣe fi `:latest` silẹ lori kikọ agbalagba lakoko awọn akọsilẹ itusilẹ sọrọ nipa awọn atunṣe ti o wa lori git nikan. Kọ quickstarts lo `:latest`; GitOps yẹ ki o tọju pinning `X.Y.Z`. Wo [awọn ikanni itusilẹ Docker](../guides/DOCKER_GUIDE.md#release-channels) ati #10317.

**ibi ipamọ agbari Docker Hub (`cheaperinference/omniroute`):** Docker Hub ko le gbe ibi ipamọ kan laarin awọn aaye orukọ, nitorinaa `diegosouzapw/omniroute` tọju itan-akọọlẹ fifa rẹ ati gbogbo itusilẹ, ati iṣẹ `mirror-org-dockerhub` ti awọn ẹda `docker-publish` ẹya kọọkan ti o tu silẹ (ati `:latest` nigbati igbega) lati `ghcr.io/cheaper-inference/omniroute` si ibi ipamọ agbari. O nilo awọn asiri `DOCKERHUB_ORG_USERNAME` / `DOCKERHUB_ORG_TOKEN` ; laisi wọn iṣẹ naa duro alawọ ewe pẹlu ikilọ “Docker Hub org” ikilọ ati pe awọn iforukọsilẹ miiran ṣe atẹjade ni deede. Lati ṣe atẹjade ẹya ti o tu silẹ nibẹ nigbamii, ṣiṣe** Awọn iṣe → Digi Docker aworan si Docker Hub org → Ṣiṣe bisesenlo** pẹlu `version=X.Y.Z` (ati `promote_latest` fun ẹya iduroṣinṣin to ga julọ): o daakọ awọn aworan ti o wa, ko si atunṣe.

## Ọ̀nà-Yíyára Hotfix (àmì `hotfix`)

PR tí a fi àmì `hotfix` sí máa ré matrix CI tó wuwo (E2E shard-9, ratchet coverage,
quality-gate, quality-extended) kọjá, yóò sì pa àwọn gate tó yára, tí àmì wọn sì lágbára mọ́: build,
àwọn shard unit, integration, vitest, lint/typecheck, docs-sync, `check:pack-artifact`
àti boot-smoke tarball (`check:pack-boot`). Àfojúsùn: kí gbogbo rẹ̀ jẹ́ green ní ≤15min dípò ~33min.

**Ìlànà ìwọlé — gbogbo mẹ́rẹ̀ẹ̀rin ni a nílò (tí a ṣe àwòṣe rẹ̀ lórí àwọn ọ̀nà pàjáwìrì Chromium/VS Code/Node):**

1. **Ìpele ewu**: production ti bàjẹ́ — artifact tí a ti tẹ̀jáde ń crash nígbà boot / àtúnṣe
   ààbò / gbogbo olùlò release náà ni ọ̀ràn náà kan. “Pàtàkì” kò túmọ̀ sí “bàjẹ́”.
2. **Àṣẹ**: owner repository nìkan ló lè fi àmì `hotfix` sí. Àmì náà GAN-AN ni
   ìfọwọ́sí — má ṣe lo fún ara rẹ lórí PR campaign.
3. **Ẹ̀rí**: ara PR náà ní link sí heavy run tó green pátápátá tẹ́lẹ̀ (suite tí
   àwọn job tí a ré kọjá yóò tún validate) àti test àtúnṣe náà fúnra rẹ̀ tó kọ́kọ́ fail, tó sì wá pass.
4. **Ìwọ̀n iṣẹ́**: cherry-pick-only — àtúnṣe tó kéré jù, kò sí refactor, kò sì sí iṣẹ́ mìíràn tí a fi tọ́ ọ̀.

Full run tó tẹ̀lé lórí branch release yóò tún validate coverage/ratchet surface tí a ré kọjá
(continuous release-green) — ọ̀nà náà ń ré ÌDÚRÓ nìkan kọjá, kì í ré validation kọjá.
Àwọn diff test-only (gbogbo file lábẹ́ `tests/`, kò sí èyíkéyìí lábẹ́ `tests/e2e/`) máa ré matrix E2E
kọjá laifọwọ́yi, láìsí àmì kankan.

### Kọ Ìfilélẹ

Ibi-ipamọ naa nlo awọn ilana iṣelọpọ pato mẹta — ko da wọn pọ mọ:

| Itọsọna   | Idi                                                     | Tọpinpin?           |
| --------- | ------------------------------------------------------- | ------------------- |
| `src/`    | Orisun ohun elo (TypeScript / TSX)                      | Bẹẹni               |
| `.build/` | Kọ agbedemeji — `next build` igbejade (`distDir`)       | Rara (ti a kọ silẹ) |
| `dist/`   | Shippable npm lapapo — pejọ nipasẹ `assembleStandalone` | Rara (ti a kọ silẹ) |

> **Akọsilẹ oniṣẹ:** ilana aworan VPS latọna jijin ku `/usr/lib/node_modules/omniroute/app/`. Nikan ni** ni-repo** kọ iṣẹjade gbe (`app/` → `dist/`). Awọn imuṣiṣẹ awọn ọgbọn rsync `dist/` akoonu sinu `app/` dir — latọna jijin ko si awọn ayipada ọna VPS nilo.

**Sisan-itumọ kan:**

```
npm run build:release
  └─ rm -rf .build dist          (clean)
  └─ next build → .build/next/   (intermediates)
  └─ assembleStandalone          (copies standalone + static + public + natives → dist/)
  └─ writes dist/BUILD_SHA       (HEAD sentinel)
```

Ṣe NOT ṣiṣe `npm run build` atẹle nipasẹ `npm run build:cli` lọtọ fun imuṣiṣẹ — lo `npm run build:release` eyiti o ṣe atunṣe + sentinel mimọ ni aṣẹ kan.

### Ṣiṣe-gbẹ (ka-nikan, ailewu nigbakugba)

```bash
npm run release:dry-run-lts-cut                       # the real cut: 3.9.0 from HEAD, previous tag v3.8.59
npm run release:dry-run-lts-cut -- --from <3.9.0-tip> # pin the source commit
```

`scripts/release/dry-run-lts-cut.mjs` executes nothing: it reads git and `gh` and prints the whole sequence — preconditions (source resolves, the source repository has full history — a shallow clone cannot push `stable/v3`, the receiving side rejects the pack at the first grafted parent, so cut from a full clone or `git fetch --unshallow origin` first — previous tag exists, `package.json` is the target version, a `release-freeze` issue is open, no open `Release branch not green` issue on an existing release branch — a branch that does not exist reports `?` unknown, never green — omni-queue lands the release PRs (G11: `config/merge-queue/config.json` valid, its `bases` manage the release branch, `mode` `live`, its label exists), the `release/*` ruleset still blocks deletion and force-push, and `stable/v3` and `develop` do not exist yet), the two branch steps, which dormant-workflow triggers and `if:` conditions turn true (and which stay gated by a repository variable or pinned to the canonical repository), the expected dist-tags (`latest` → 3.9.0, `next` and `nightly` empty) and the rollback. Exit `0` = `RESULT: READY`, `1` = a blocking precondition failed (`✗`), `2` = usage error. `--advisory <id,...>` downgrades a check to a warning (`!`) without hiding it.

Ṣiṣe awọn gidi gige ti gbẹ-ṣiṣe nigba ti 3.9.0 itusilẹ didi ṣi ṣi — awọn ẹka ti ṣẹda lẹhin tag ati ṣaaju ki Alakoso 12c gbe didi naa soke.

4. Dabobo `stable/v3` ati `develop` (awọn ofin ti ila ilapọ + ) ṣaaju awọn ilẹ PR akọkọ.
5. Awọn iṣan-iṣẹ iṣẹ ti o wa ni isinmi yipada nipasẹ aye ti ẹka: `forward-port.yml` (titari si `stable/v3`), `validate-stable-pr.yml` (PRs si `stable/v3`) ati `nightly-v4-build.yml` (kọ `develop`). Ṣaaju ki o to lọ-ifiwe, ṣeto aṣiri ibi ipamọ `secrets.FORWARD_PORT_TOKEN` (nitorina CI nṣiṣẹ lori ibudo-iwaju PRs); Titẹjade alẹ alẹ duro ni pipa titi oniwun yoo ṣeto oniyipada ibi ipamọ `vars.NIGHTLY_PUBLISH` si `true` ati npm Titẹ Igbẹkẹle gba `nightly-v4-build.yml`. Ipinnu ikanni jẹ `scripts/release/dist-tag.mjs`, ipinnu kanna `npm-publish.yml` nlo.
6. Daju awọn ikanni: `npm view omniroute dist-tags --json` fihan `latest` = 3.9.0 ko si si `next` / `nightly` titi v4 ṣe atẹjade.
7. Yipada, ti o ba nilo: `git push origin --delete refs/heads/stable/v3 refs/heads/develop` ati `npm dist-tag add omniroute@3.8.59 latest`.

## Ìpadàsẹ́yìn

Tí ìtújáde bá ní ìṣòro tó ṣe pàtàkì:

1. `gh release edit vX.Y.Z --prerelease` (èyí ń sàmì sí i pé kì í ṣe èyí tuntun jù lọ)
2. `git tag -d vX.Y.Z && git push --delete origin vX.Y.Z` (kìkì tí àwọn aṣàmúlò kò bá tíì bẹ̀rẹ̀ sí í lò ó)
3. Tàbí: ṣe àtúnṣe kánkán lórí `release/vX.Y.0` → ìtújáde àtúnṣe `vX.Y.(Z+1)`
4. Ṣe ìfitónilétí lẹ́sẹ̀kẹsẹ̀ nínú GitHub Discussions àti Discord

## Àwọn Òfin Tí Kò Ṣe É Yí Padà

- Má ṣe commit tààrà sí `main`
- Má ṣe lo `git push --force` sí `main` tàbí àwọn ẹ̀ka `release/*`
- Má ṣe fo àwọn hook Husky (`--no-verify`) láé
- Má ṣe commit àwọn àṣírí, ẹ̀rí ìdánimọ̀, tàbí àwọn fáìlì `.env`
- Coverage gbọ́dọ̀ wà ní ≥60/60/60/60 (àwọn gbólóhùn/àwọn ìlà/àwọn iṣẹ́/àwọn ẹ̀ka)
- Fi àwọn àyẹ̀wò kún un tàbí ṣe ìmúdójúìwọ̀n wọn nígbà gbogbo tí o bá ń yí kóòdù ìṣelọpọ padà nínú `src/`, `open-sse/`, `electron/`, tàbí `bin/`
