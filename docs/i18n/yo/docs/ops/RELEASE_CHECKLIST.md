## npm Trusted Publishing (àiyipada láti v3.8.51) — staged nígbà tí a bá béèrè, direct gẹ́gẹ́ bí fallback

`npm-publish.yml` ń ṣe ìtẹ̀jáde nípasẹ̀ **npm Trusted Publishing (OIDC)** gẹ́gẹ́ bí àiyipada:
job `stage-npm` (tí github gbàlejò) ń pààrọ̀ id-token GitHub fún credential npm
ìgbà-kúkúrú fún ìṣiṣẹ́ yẹn — kò sí token npm ìgbà-pípẹ́ nínú àwọn secrets repository, kò sí ìbéèrè 2FA, a sì so provenance mọ́ ọn.
Èyí ni bypass tí npm fọwọ́ sí báyìí tí wọ́n ti ń fẹ̀yìn tì àwọn token tó ń fò 2FA;
ó ń mú ìṣàn aládàáṣiṣẹ́ kíkún tí project náà ní títí dé v3.8.48 padà, nígbà tó tún ń pa
ìdánilójú WS1.3 mọ́ (token tí ó tú síta kò lè tẹ̀jáde ní òun nìkan — kò sí token rárá).

**Ètò ẹ̀ẹ̀kan ṣoṣo (owner):** npmjs.com → package `omniroute` → Settings → _Trusted
Publisher_ → GitHub: owner `diegosouzapw`, repo `OmniRoute`, workflow `npm-publish.yml`
(environment: kò sí). Títí èyí yóò fi wà, ìgbésẹ̀ aládàáṣiṣẹ́ yóò kùnà pẹ̀lú `ENEEDAUTH`:
tún fi ránṣẹ́ pẹ̀lú `publish_mode=staged` (ní ìsàlẹ̀) tàbí `direct`.

### Ìtẹ̀jáde staged (nígbà tí a bá béèrè — `publish_mode=staged`)

Workflow npm-publish kò tún tẹ̀jáde tààrà mọ́: ó ń boot tarball tí a pack
(`check:pack-boot`), lẹ́yìn náà ó sì ń ṣiṣẹ́ `npm stage publish` — àwọn byte gangan ni a gbé dúró sórí
registry, **a kò lè install wọn** títí owner yóò fi fọwọ́ sí i. A ti gbé ẹnu-ọ̀nà 2FA tí ènìyàn ń bójú tó
sí LẸ́YÌN ẹ̀rí náà, kì í ṣe ṣáájú rẹ̀.

**Ìṣàn owner lẹ́yìn tí workflow bá di green:**

1. `npm stage list omniroute` — wá stage id (a tún máa ń tẹ̀ ẹ́ jáde nínú àkótán workflow).
2. Ṣàyẹ̀wò àwọn byte staged náà (a dábàá rẹ̀): `npm stage download <id>`, lẹ́yìn náà install
   tarball tí a download sínú temp prefix, kí o sì boot rẹ̀ (`npm run check:pack-boot` ń ṣe
   ìdájọ́ pack→install→boot kan náà ní CI ní aládàáṣiṣẹ́).
3. `npm stage approve <id>` — ìbéèrè 2FA náà GAN-AN ni publish. `npm stage reject <id>` ń sọ ọ́ nù.
4. Ààbò lẹ́yìn ìtẹ̀jáde: verifier lẹ́yìn ìtẹ̀jáde (WS1.4 ti ètò v3.8.49) ń install
   ẹ̀yà tí a tẹ̀jáde láti public registry sínú container mímọ́, ó sì ń boot rẹ̀.

**Fallback pàjáwìrì:** `workflow_dispatch` pẹ̀lú `publish_mode=direct` ń mú
`npm publish` lẹ́sẹ̀kẹsẹ̀ ti àtijọ́ padà (lò ó nìkan bí staging fúnra rẹ̀ kò bá ṣiṣẹ́ dáadáa; ṣàkọsílẹ̀ ìdí).

**Ìmúdìí-lẹ́ẹ̀kan-ṣoṣo (owner, npmjs.com):** ṣètò Trusted Publisher fún
`omniroute` ní mode stage-only kí token ìgbà-pípẹ́ tó tú síta má bàa lè ṣe `npm publish`
tààrà láti ibikíbi — CI lè ṣe stage nìkan; 2FA owner nìkan ló lè tú u jáde.

**Ìlànà fún artifact tó bàjẹ́ (kò yí padà):** `npm deprecate omniroute@<bad> "<reason> — use <fixed>"`
gẹ́gẹ́ bí ìgbésẹ̀ àkọ́kọ́ àiyipada (ìṣẹ́jú díẹ̀, a lè yí i padà); `npm unpublish` nìkan láàárín àkókò 72h/no-dependents,
kò sì gbọ́dọ̀ jẹ́ ìgbésẹ̀ àkọ́kọ́ láé. Docker: má ṣe tún version tag kọ láé — rollback ni
títọ́ka `latest` padà sí digest tó dáa tó kẹ́yìn.

**Docker Hub `latest` (ó pọndandan fún gbogbo ìtẹ̀jáde stable SemVer):**
workflow `docker-publish` gbọ́dọ̀ fi tag sí **méjèèjì** `X.Y.Z` àti, nígbà tí
`should-promote-latest.sh` bá fohùn ṣọ̀kan pé èyí ni stable SemVer tó ga jù lọ, `:latest`
pẹ̀lú **digest kan náà**. Lẹ́yìn job náà: digest `latest` lórí Hub dọ́gba pẹ̀lú digest SemVer tuntun,
`last_updated` sì ti yí padà. Má ṣe fi `:latest` sí build àtijọ́
nígbà tí release notes ń sọ̀rọ̀ nípa àwọn àtúnṣe tó wà lórí git nìkan. Àwọn
quickstart Compose ń lo `:latest`; GitOps gbọ́dọ̀ máa tẹ̀síwájú láti pin `X.Y.Z`. Wo
[Àwọn ikanni ìtújáde Docker](../guides/DOCKER_GUIDE.md#release-channels) àti #10317.

## Ọ̀nà-Yíyára Hotfix (àmì `hotfix`)

PR tí a fi àmì `hotfix` sí máa ré matrix CI tó wuwo (E2E shard-9, ratchet coverage,
quality-gate, quality-extended) kọjá, yóò sì pa àwọn gate tó yára, tí àmì wọn sì lágbára mọ́: build,
àwọn shard unit, integration, vitest, lint/typecheck, docs-sync, `check:pack-artifact`
àti boot-smoke tarball (`check:pack-boot`). Àfojúsùn: kí gbogbo rẹ̀ jẹ́ green ní ≤15min dípò ~33min.

**Ìlànà ìwọlé — gbogbo mẹ́rẹ̀ẹ̀rin ni a nílò (tí a ṣe àwòṣe rẹ̀ lórí àwọn ọ̀nà pàjáwìrì Chromium/VS Code/Node):**

1. **Ìpele ewu**: production ti bàjẹ́ — artifact tí a ti tẹ̀jáde ń crash nígbà boot / àtúnṣe
   ààbò / gbogbo olùlò release náà ni ọ̀ràn náà kan. “Pàtàkì” kò túmọ̀ sí “bàjẹ́”.
2. **Àṣẹ**: owner repository nìkan ló lè fi àmì `hotfix` sí. Àmì náà GAN-AN ni
   ìfọwọ́sí — má ṣe lo fún ara rẹ lórí PR campaign.
3. **Ẹ̀rí**: ara PR náà ní link sí heavy run tó green pátápátá tẹ́lẹ̀ (suite tí
   àwọn job tí a ré kọjá yóò tún validate) àti test àtúnṣe náà fúnra rẹ̀ tó kọ́kọ́ fail, tó sì wá pass.
4. **Ìwọ̀n iṣẹ́**: cherry-pick-only — àtúnṣe tó kéré jù, kò sí refactor, kò sì sí iṣẹ́ mìíràn tí a fi tọ́ ọ̀.

Full run tó tẹ̀lé lórí branch release yóò tún validate coverage/ratchet surface tí a ré kọjá
(continuous release-green) — ọ̀nà náà ń ré ÌDÚRÓ nìkan kọjá, kì í ré validation kọjá.
Àwọn diff test-only (gbogbo file lábẹ́ `tests/`, kò sí èyíkéyìí lábẹ́ `tests/e2e/`) máa ré matrix E2E
kọjá laifọwọ́yi, láìsí àmì kankan.

### Kọ Ìfilélẹ

Ibi-ipamọ naa nlo awọn ilana iṣelọpọ pato mẹta — ko da wọn pọ mọ:

| Itọsọna   | Idi                                                     | Tọpinpin?           |
| --------- | ------------------------------------------------------- | ------------------- |
| `src/`    | Orisun ohun elo (TypeScript / TSX)                      | Bẹẹni               |
| `.build/` | Kọ agbedemeji — `next build` igbejade (`distDir`)       | Rara (ti a kọ silẹ) |
| `dist/`   | Shippable npm lapapo — pejọ nipasẹ `assembleStandalone` | Rara (ti a kọ silẹ) |

> **Akọsilẹ oniṣẹ:** ilana aworan VPS latọna jijin ku `/usr/lib/node_modules/omniroute/app/`. Nikan ni** ni-repo** kọ iṣẹjade gbe (`app/` → `dist/`). Awọn imuṣiṣẹ awọn ọgbọn rsync `dist/` akoonu sinu `app/` dir — latọna jijin ko si awọn ayipada ọna VPS nilo.

**Sisan-itumọ kan:**

```
npm run build:release
  └─ rm -rf .build dist          (clean)
  └─ next build → .build/next/   (intermediates)
  └─ assembleStandalone          (copies standalone + static + public + natives → dist/)
  └─ writes dist/BUILD_SHA       (HEAD sentinel)
```

Ṣe NOT ṣiṣe `npm run build` atẹle nipasẹ `npm run build:cli` lọtọ fun imuṣiṣẹ — lo `npm run build:release` eyiti o ṣe atunṣe + sentinel mimọ ni aṣẹ kan.

A kọ commit ìgbésókè develop pẹ̀lú git plumbing (a kò fọwọ́ kan working tree kankan), ó sì
gbé àwọn fáìlì márùn-ún kan náà sókè bí commit ṣíṣí-cycle: `package.json`, `open-sse/package.json`,
`electron/package.json`, `package-lock.json` àti `docs/openapi.yaml`. A máa ṣí abala
CHANGELOG `[4.0.0]` àti àwọn àwòkọ i18n rẹ̀ lórí `develop` lẹ́yìn náà, ṣáájú PR àkọ́kọ́ rẹ̀.
Script náà kì í yí npm dist-tags padà láé — ṣe ìdánwò àwọn wọ̀nyẹn lórí package àdánwò kan.

### Artifact àwòrán-àkọ́kọ́ PR (kọ́ ọ lẹ́ẹ̀kan, gbé bytes kan náà ga)

`.github/workflows/preview-artifact.yml` kọ tarball production kan láti orí PR kan, ó sì
fọwọ́sí build náà gan-an (#8084 apá (a)). Àwọn PR láti ibi ìpamọ́ kan náà nìkan; kò sí ohun
tí a tẹ̀ jáde.

```bash
gh workflow run preview-artifact.yml -f pr_number=<N>   # tàbí fi àmì `preview-artifact` kún un
gh run download <run-id> --name preview-artifact-pr<N>-<sha7> --dir preview
cd preview && sha256sum -c SHA256SUMS
gh attestation verify omniroute-*.tgz --repo diegosouzapw/OmniRoute
npm install -g ./omniroute-*.tgz                          # fífi àwòrán-àkọ́kọ́ sori ẹrọ
```

Ìṣiṣẹ́ náà ṣe `npm ci`, `npm run build:release`, `npm run check:pack-artifact`, ó kó
tarball náà, ó ṣiṣẹ́ `npm run check:pack-boot` (àwọn secret èké, data dir fún ìgbà díẹ̀), ó
tún un kó, ó sì kùnà àyàfi tí digest náà bá jẹ́ ọ̀kan náà; lẹ́yìn náà ó ṣàkọsílẹ̀
`artifact-identity.json` (head SHA, base SHA, hash lockfile, platform, arch, node ABI,
bundler, ìlànà build — `scripts/release/artifact-identity.mjs`), ó sì jẹ́rìí sí tarball náà
nínú job ọ̀tọ̀. Gígbé àwòrán-àkọ́kọ́ ga túmọ̀ sí fífi tarball náà sori ẹrọ: má ṣe tún un kọ́
láti orísun láé.

### Gígé náà (3.9.0, lẹ́yìn GO)

1. A ṣàkọsílẹ̀ GO nínú [LTS_GO_NO_GO.md](./LTS_GO_NO_GO.md).
2. `npm run release:dry-run-lts-cut -- --from v3.9.0` tẹ `RESULT: READY` jáde.
3. Dá àwọn ẹ̀ka náà sílẹ̀ lórí `origin` pẹ̀lú ọwọ́ nípa àwọn àṣẹ tí ìdánwò ṣáájú tẹ̀ jáde —
   script náà kọ̀ láti push sí `origin`. Láti tún commit develop tí a ti ṣàyẹ̀wò lò, ṣiṣẹ́
   ìdánwò `--execute` lórí òkè 3.9.0 sí fork rẹ kọ́kọ́; ó tẹ SHA méjèèjì jáde, a sì lè push
   àwọn commit kan náà:

   ```bash
   git push origin <stable-sha>:refs/heads/stable/v3 <develop-sha>:refs/heads/develop
   ```

4. Dáàbò bo `stable/v3` àti `develop` (àwọn àkójọpọ̀ òfin + ìlà ìdapọ̀) kí PR àkọ́kọ́ tó wọlé.
5. Àwọn ìṣàn iṣẹ́ tí kò tíì ṣiṣẹ́ yóò bẹ̀rẹ̀ nípasẹ̀ wíwà ẹ̀ka náà: `forward-port.yml` (ìfìránṣẹ́ sí
   `stable/v3`), `validate-stable-pr.yml` (àwọn PR sí `stable/v3`) àti `nightly-v4-build.yml`
   (ń kọ́ `develop`). Kí ìfilọ́lẹ̀ tó bẹ̀rẹ̀, ṣètò àṣírí ibi ìpamọ́ `secrets.FORWARD_PORT_TOKEN` (kí CI lè ṣiṣẹ́ lórí
   àwọn PR forward-port); ìtẹ̀jáde alẹ́ kò ní ṣiṣẹ́ títí tí olówó yóò fi ṣètò oníyípadà ibi ìpamọ́
   `vars.NIGHTLY_PUBLISH` sí `true` tí npm Trusted Publishing sì gba
   `nightly-v4-build.yml`. Ìyanjú channel wà ní `scripts/release/dist-tag.mjs`, olùyanjú kan náà
   tí `npm-publish.yml` ń lò.
6. Ṣàyẹ̀wò àwọn channel náà: `npm view omniroute dist-tags --json` ń fi `latest` = 3.9.0 hàn, kò sì sí
   `next` / `nightly` títí v4 yóò fi tẹ̀jáde.
7. Ìpadà-sẹ́yìn, bí ó bá ṣe pàtàkì: `git push origin --delete refs/heads/stable/v3 refs/heads/develop`
   àti `npm dist-tag add omniroute@3.8.59 latest`.

## Ìpadàsẹ́yìn

Tí ìtújáde bá ní ìṣòro tó ṣe pàtàkì:

1. `gh release edit vX.Y.Z --prerelease` (èyí ń sàmì sí i pé kì í ṣe èyí tuntun jù lọ)
2. `git tag -d vX.Y.Z && git push --delete origin vX.Y.Z` (kìkì tí àwọn aṣàmúlò kò bá tíì bẹ̀rẹ̀ sí í lò ó)
3. Tàbí: ṣe àtúnṣe kánkán lórí `release/vX.Y.0` → ìtújáde àtúnṣe `vX.Y.(Z+1)`
4. Ṣe ìfitónilétí lẹ́sẹ̀kẹsẹ̀ nínú GitHub Discussions àti Discord

## Àwọn Òfin Tí Kò Ṣe É Yí Padà

- Má ṣe commit tààrà sí `main`
- Má ṣe lo `git push --force` sí `main` tàbí àwọn ẹ̀ka `release/*`
- Má ṣe fo àwọn hook Husky (`--no-verify`) láé
- Má ṣe commit àwọn àṣírí, ẹ̀rí ìdánimọ̀, tàbí àwọn fáìlì `.env`
- Coverage gbọ́dọ̀ wà ní ≥60/60/60/60 (àwọn gbólóhùn/àwọn ìlà/àwọn iṣẹ́/àwọn ẹ̀ka)
- Fi àwọn àyẹ̀wò kún un tàbí ṣe ìmúdójúìwọ̀n wọn nígbà gbogbo tí o bá ń yí kóòdù ìṣelọpọ padà nínú `src/`, `open-sse/`, `electron/`, tàbí `bin/`
