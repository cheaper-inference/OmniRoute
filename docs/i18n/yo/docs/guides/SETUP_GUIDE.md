## Awọn ọna Fi sori ẹrọ

### npm (a ṣe iṣeduro)

```bash
npm install -g omniroute
omniroute
```

Dasibodu ṣii ni `http://localhost:20128` ati ipilẹ URL API `http://localhost:20128/v1`.

> **npm:** Ti npm ba kilọ pe a ti dinamọ awọn iwe afọwọkọ sori ẹrọ (fun apẹẹrẹ, `omniroute`, `better-sqlite3`), wo [Laasigbotitusita — npm awọn iwe afọwọkọ fifi sori ẹrọ dina](./TROUBLESHOOTING.md#npm-install-scripts-blocked-warning-global-install).

### pnpm

```bash
pnpm add -g omniroute@latest --allow-build=better-sqlite3 --allow-build=@swc/core
omniroute
```

> **awọn olumulo pnpm:** asia `--allow-build` ni a nilo lati mu awọn iwe afọwọkọ kikọ abinibi ṣiṣẹ fun `better-sqlite3` ati `@swc/core`. Aṣẹ `pnpm approve-builds -g` ko ṣe atilẹyin fun awọn fifi sori ẹrọ agbaye lori pnpm v11.

### Arch Linux (AUR)

```bash
yay -S omniroute-bin
systemctl --user enable --now omniroute.service
```

[package AUR](https://aur.archlinux.org/packages/omniroute-bin) nfi OmniRoute sori ẹrọ ati pese iṣẹ olumulo ti eto kan.

### Lati Orisun

```bash
npm install
PORT=20128 DASHBOARD_PORT=20129 NEXT_PUBLIC_BASE_URL=http://localhost:20129 npm run dev
```

> **Windows akiyesi:** Nipa aiyipada, OmniRoute nlo `%APPDATA%\omniroute` nigbati itọsọna `%USERPROFILE%\.omniroute` julọ ko si. Ṣeto `DATA_DIR` lati yan ipo-itọsọna data ọtọtọ.

> **Akiyesi:** `npm install` laifọwọyi ṣe ipilẹṣẹ `.env` lati `.env.example` ni ṣiṣe akọkọ. Awọn fifi sori atẹle kii yoo tun kọ `.env` ti o wa tẹlẹ, nitorinaa awọn isọdi ti wa ni ipamọ. Lati tun-irugbin, pa `.env` ṣaaju ki o to tun nṣiṣẹ.

### Docker

Wo [Itọsọna Docker](./DOCKER_GUIDE.md) fun iṣeto Docker pipe pẹlu Ṣajọ awọn profaili ati Caddy HTTPS.

### Ohun elo Tabili (Electron)

OmniRoute gbe apẹrẹ tabili tabili kan ti a ṣe lori Electron 41 + elekitironi-akọle 26.10. Awọn iwe afọwọkọ ti o wa (gbòngbo aaye iṣẹ):

```bash
npm run electron:dev          # Run desktop with hot-reload
npm run electron:build        # Build for current OS (auto-detected)
npm run electron:build:win    # Windows installer (NSIS + portable)
npm run electron:build:mac    # macOS (dmg + zip, arm64+x64)
npm run electron:build:linux  # Linux (AppImage + deb + rpm)
npm run electron:smoke:packaged  # Smoke-test packaged build
```

Awọn idasilẹ ti awọn fifi sori tabili tabili ni asopọ si Awọn idasilẹ GitHub. Fun ni kikun Electron jin-besomi (fibuwọlu, IPC afara, distros), wo [`ELECTRON_GUIDE.md`](./ELECTRON_GUIDE.md) _(criado em fase ẹhin)_.

### olupin ti ko ni ori (CI/automation)

Fun awọn iṣeto ti a ko tọju (Docker, Kubernetes, CI), lo:

```bash
omniroute setup --non-interactive
omniroute providers test-batch
```

Ni idapọ pẹlu env vars (`INITIAL_PASSWORD`, `OMNIROUTE_WS_BRIDGE_SECRET`, ati bẹbẹ lọ), eyi n jẹ ki o yi apẹẹrẹ OmniRoute kan ni kikun iwe afọwọkọ.

### CLI Awọn aṣayan

| Òfin                    | Apejuwe                                                              |
| ----------------------- | -------------------------------------------------------------------- |
| `omniroute`             | Bẹrẹ olupin (`PORT=20128`, API ati dasibodu lori ibudo kanna)        |
| `omniroute setup`       | Itọsọna CLI lori wiwọ fun ọrọ igbaniwọle ati olupese akọkọ           |
| `omniroute doctor`      | Ṣiṣe awọn sọwedowo ilera agbegbe lai bẹrẹ olupin naa                 |
| `omniroute providers`   | Ṣawari, ṣe atokọ, fọwọsi, ati awọn olupese idanwo lati CLI           |
| `omniroute config`      | CLI irinṣẹ iṣeto ni — akojọ, gba, ṣeto, sooto awọn atunto            |
| `omniroute status`      | Aisinipo ipo dasibodu — ẹya, DB, irinṣẹ, konfigi                     |
| `omniroute logs`        | Awọn igbasilẹ lilo ṣiṣanwọle lati API (ṣe atilẹyin `--follow`)       |
| `omniroute update`      | Ṣayẹwo fun tabi lo awọn imudojuiwọn OmniRoute                        |
| `omniroute provider`    | Ṣakoso awọn asopọ olupese — ṣafikun, atokọ, yọkuro, idanwo, aiyipada |
| `omniroute --port 3000` | Ṣeto ibudo canonical/API si 3000                                     |
| `omniroute --mcp`       | Bẹrẹ olupin MCP (irinna stdio)                                       |
| `omniroute --no-open`   | Maṣe ṣii ẹrọ aṣawakiri laifọwọyi                                     |
| `omniroute --help`      | Ṣe afihan iranlọwọ                                                   |

Eto ti ko ni ori le jẹ kikọ pẹlu awọn asia tabi awọn oniyipada ayika:

```bash
omniroute setup --non-interactive --password "$OMNIROUTE_PASSWORD"
omniroute setup --non-interactive --add-provider --provider openai --api-key "$OPENAI_API_KEY"
omniroute setup --non-interactive --add-provider --provider openai --api-key "$OPENAI_API_KEY" --test-provider
```

Ṣiṣe awọn iwadii agbegbe laisi ṣiṣi dasibodu naa:

```bash
omniroute doctor
omniroute doctor --json
omniroute doctor --no-liveness
```

Ṣakoso awọn olupese lati SSH tabi awọn iwe afọwọkọ laisi ṣiṣi dasibodu naa:

```bash
omniroute providers available
omniroute providers available --search openai
omniroute providers available --category api-key
omniroute providers list
omniroute providers test <id-or-name>
omniroute providers test-all
omniroute providers validate
```

## Ìṣètò Ohun Èlò CLI

### 1) So Àwọn Olùpèsè pọ̀ kí o sì Ṣẹ̀dá API Key

1. Ṣí Dashboard → `Providers` kí o sì so ó kéré tán mọ́ olùpèsè kan (OAuth tàbí API key).
2. Ṣí Dashboard → `Endpoints` kí o sì ṣẹ̀dá API key kan.
3. (Àṣàyàn) Ṣí Dashboard → `Combos` kí o sì ṣètò ẹ̀wọ̀n ìpadà-sẹ́yìn rẹ.

### 2) Darí Ohun Èlò Ìkọ Kóòdù Rẹ

```txt
URL Ìpìlẹ̀: http://localhost:20128/v1
API Key:    [dà á kọ láti ojú-ìwé Endpoint]
Módẹ́lì:    if/qwen3.8-max-preview (tàbí ìpele ìbẹ̀rẹ̀ olùpèsè/módẹ́lì èyíkéyìí)
```

Tí olóòtú rẹ kò bá lè fi `Authorization: Bearer ...` ránṣẹ́, lo ìpìlẹ̀ ìbámu tí a fi token sí dípò rẹ:

```txt
URL Ìpìlẹ̀: http://localhost:20128/api/v1/vscode/YOUR_KEY/
URL Àwọn Módẹ́lì: http://localhost:20128/api/v1/vscode/YOUR_KEY/models
URL Ìfọ̀rọ̀wérọ̀: http://localhost:20128/api/v1/vscode/YOUR_KEY/chat/completions
URL Àwọn Tags Ollama: http://localhost:20128/api/v1/vscode/YOUR_KEY/api/tags
```

Ó ń ṣiṣẹ́ pẹ̀lú Claude Code, Codex CLI, Cursor, Cline, OpenClaw, OpenCode, àti àwọn SDK tó bá OpenAI mu.

#### Ṣètò rẹ̀ láìfọwọ́ṣe pẹ̀lú `setup-*`

Dípò lílẹ URL ìpìlẹ̀ àti kọ́kọ́rọ́ náà mọ́lẹ̀ lọ́wọ́, jẹ́ kí OmniRoute kọ
ìṣètò ohun èlò kọ̀ọ̀kan láti inú àkójọ àwọn módẹ́lì tó ń ṣiṣẹ́. Àṣẹ kan fún ohun èlò kọ̀ọ̀kan:

```bash
omniroute setup-codex        # àwọn prófáìlì ~/.codex/<name>.config.toml
omniroute setup-claude       # ~/.claude/profiles/<name>/settings.json
omniroute setup-opencode     # ~/.config/opencode/opencode.json (ó bá OpenAI mu)
omniroute setup-cline        # Àwọn ìṣètò Cline CLI + àfikún VS Code
omniroute setup-kilo         # Kilo Code
omniroute setup-continue     # ~/.continue/config.yaml (Continue / cn)
omniroute setup-cursor       # ń tẹ àwọn ìgbésẹ̀ inú ètò Cursor jáde
omniroute setup-roo          # Ìgbéwọlé Roo Code + atọ́ka autoImport
omniroute setup-crush        # ~/.config/crush/crush.json
omniroute setup-zed          # ~/.config/zed/settings.json (openai_compatible)
omniroute setup-goose        # ~/.config/goose/config.yaml
omniroute setup-aider        # ~/.aider.conf.yml
omniroute setup-qwen         # ~/.qwen/settings.json + ~/.qwen/.env
```

Ọ̀kọ̀ọ̀kan gba `--remote <url> --api-key <key>` láti ṣètò ohun èlò agbègbè kan láti ṣiṣẹ́ pẹ̀lú
OmniRoute **jíjìnnà**, àti `--dry-run` láti wo àgbéyẹ̀wò. Láti bẹ̀rẹ̀ CLI kan pẹ̀lú env tó tọ́
tí a ti fi sínú rẹ̀ láìkọ ìṣètò kankan rárá, lo olùbẹ̀rẹ̀ gbogbogbò
`omniroute run <target>` (claude, codex, aider, goose, opencode, qwen, gemini);
àwọn olùbẹ̀rẹ̀ ohun èlò kọ̀ọ̀kan ti àtijọ́ `omniroute launch` (Claude Code) àti
`omniroute launch-codex` (Codex) ṣì wà fún lílò.

Fún tábìlì kíkún (ohun tí àṣẹ kọ̀ọ̀kan ń kọ, gbogbo flag, agbègbè sí jíjìnnà, àwọn àṣà URL ìpìlẹ̀
`/v1`), wo **[Àwọn Ìṣọ̀kan CLI](./CLI-INTEGRATIONS.md)**.

Fún ìṣètò alálàyé ohun èlò kọ̀ọ̀kan (Claude Code, Codex CLI, Cursor, Cline, OpenClaw, Kilo Code, Copilot, àti àwọn mìíràn), wo **[Ìtọ́sọ́nà Àwọn Ohun Èlò CLI](../reference/CLI-TOOLS.md)** tí a yà sọ́tọ̀.

## Eto Ilana (MCP + A2A)

### Eto MCP (Awoṣe Ilana Ilana)

Bẹrẹ gbigbe MCP ni ipo sitẹrio:

```bash
omniroute --mcp
```

Ṣiṣan afọwọsi ti a ṣeduro:

```bash
# 1. Start MCP server
omniroute --mcp

# 2. From your MCP client, call:
omniroute_get_health        # Should return system health
omniroute_list_combos       # Should return active combos

# 3. Or run the full E2E suite:
npm run test:protocols:e2e
```

#### MCP Onibara iṣeto ni

**koodu Claude :**

koodu Claude so lori HTTP, eyiti `omniroute --mcp` (stdio) ko bẹrẹ. Gbigbe HTTP naa wa ni pipa nipasẹ aiyipada: mu ṣiṣẹ lori olupin nṣiṣẹ ni akọkọ. Nigbati iwọle dasibodu ba ṣiṣẹ, ibeere laisi iwe-ẹri gba `401`, nitorinaa gba bọtini API kan ti o di `mcp:connect` (tabi `manage`); bọtini laisi `manage`/`admin` tun nilo aaye irinṣẹ kọọkan (wo [MCP Server → MCP awọn aaye irinṣẹ](../frameworks/MCP-SERVER.md#mcp-tool-scopes) ).

```bash
omniroute mcp enable --transport streamable-http
claude mcp add --transport http omniroute http://localhost:20128/api/mcp/stream \
  --header "Authorization: Bearer your-key"
```

**Cursor / Cline:**

Ṣafikun awọn eto MCP rẹ (stdio, pẹlu bọtini ki olupe naa ni akọkọ):

```json
{
  "mcpServers": {
    "omniroute": {
      "command": "omniroute",
      "args": ["--mcp"],
      "env": {
        "OMNIROUTE_API_KEY": "your-key",
        "OMNIROUTE_BASE_URL": "http://localhost:20128"
      }
    }
  }
}
```

Tabi, nigbati `mcpTransport` jẹ `streamable-http` (ṣeto sori `/dashboard/mcp` tabi pẹlu `omniroute mcp enable --transport streamable-http`), tọka si titẹsi olupin MCP latọna jijin ti alabara ni `http://localhost:20128/api/mcp/stream`.

Bọtini naa rin irin-ajo bi `Authorization: Bearer <api-key>` (wo [MCP Server → Wiwọle jijin](../frameworks/MCP-SERVER.md#remote-access-manage-scope-bypass) fun awọn agbalejo latọna jijin; bọtini jijin nilo `mcp:connect` pẹlu awọn aaye read/write rẹ).

**Iwe MCP ni kikun:** [MCP Server README](../../open-sse/mcp-server/README.md) — 110 irinṣẹ, IDE atunto, Python/TS/Go ibara. Itọkasi onišẹ fun awọn irinṣẹ CCR/dedup funmorawon (awọn ami ami, awọn ohun pataki, awọn iwọn fun-ọpa, pagination igbapada, awọn iwadii aisan): [Awọn ẹrọ titẹkuro → Awọn ohun elo iṣaaju / itọsọna oniṣẹ](../compression/COMPRESSION_ENGINES.md#prerequisites--operator-guide-ccr--session-dedup).

### Eto A2A (Ilana Aṣoju-si-Aṣoju)

Ṣayẹwo kaadi Aṣoju naa:

```bash
curl http://localhost:20128/.well-known/agent.json
```

Fi iṣẹ-ṣiṣe ranṣẹ:

```bash
curl -X POST http://localhost:20128/a2a \
  -H 'content-type: application/json' \
  -d '{"jsonrpc":"2.0","id":"quickstart","method":"message/send","params":{"skill":"quota-management","messages":[{"role":"user","content":"Give me a short quota summary."}]}}'
```

**Iwe A2A ni kikun:** [A2A Server README](../../src/lib/a2a/README.md) — JSON-RPC 2.0, ogbon, ṣiṣanwọle, igbesi aye iṣẹ-ṣiṣe.

## Ìṣètò Àkókò Ìdádúró

### Àwọn Àkókò Ìdádúró Ìpìlẹ̀

Fún ọ̀pọ̀ jù lọ àwọn ìmúṣiṣẹ́, àwọn àyípadà méjì yìí nìkan ni o nílò:

| Àyípadà                  | Àìyípadà                   | Ète                                                                                                                                                                              |
| ------------------------ | -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `REQUEST_TIMEOUT_MS`     | `600000`                   | Ìwọ̀n ìpìlẹ̀ tí a pín fún àkókò ìdádúró ìbẹ̀rẹ̀-ìdáhùn láti upstream, àwọn àkókò ìdádúró Undici tí a fi pamọ́, àwọn ìbéèrè ìdánimọ̀ TLS, àti àwọn àkókò ìdádúró ìbéèrè/proxy afárá API |
| `STREAM_IDLE_TIMEOUT_MS` | jogún `REQUEST_TIMEOUT_MS` | Àlàfo tó pọ̀ jù láàárín àwọn ẹ̀ka ṣiṣàn kí OmniRoute tó fòpin sí ṣiṣàn SSE                                                                                                         |

Ìbámu sẹ́yìn ṣì wà: `FETCH_TIMEOUT_MS`, `API_BRIDGE_PROXY_TIMEOUT_MS`, àti àwọn àyípadà àkókò ìdádúró mìíràn fún ìpele kọ̀ọ̀kan tí ó ti wà tẹ́lẹ̀ ṣì ń ṣiṣẹ́, wọ́n sì máa borí ìwọ̀n ìpìlẹ̀ tí a pín.

### Àwọn Àkíyèsí Pàtó Fún Olùpèsè

Fún àwọn upstream tó bá Claude Code mu (`anthropic-compatible-cc-*`), OmniRoute máa ń ṣe àkọlé àbájáde `X-Stainless-Timeout` láti inú àkókò ìdádúró fetch tí a ti yanjú, kí àwọn àkókò ìdádúró kíkà ní ẹ̀gbẹ́ olùpèsè lè wà ní ìbámu pẹ̀lú ìṣètò env rẹ.

Fún àwọn reverse proxy ẹnikẹta tó bá Claude Code mu, OmniRoute máa ń jẹ́ kí àkójọpọ̀ `anthropic-beta` àìyípadà jẹ́ ti ìṣọ́ra, àti nígbà tí a bá fi `Client Cache Control` sílẹ̀ lórí `Auto`, ó máa ń fi àwọn àmì `cache_control` tí oníbàárà pèsè nìkan ránṣẹ́ síwájú. Mu aṣàyàn "Mú redact-thinking beta ṣiṣẹ́" fún àsopọ̀ kọ̀ọ̀kan ṣiṣẹ́ kìkì nígbà tí upstream bá béèrè pàtó fún àwọn ṣiṣàn ìrònú Claude tí a ti ṣàtúnṣe láti fi àṣírí pamọ́.

### Àwọn Àtúnṣe Àkókò Ìdádúró Onípele-gíga

| Àyípadà                                  | Àìyípadà                                   | Ète                                                                            |
| ---------------------------------------- | ------------------------------------------ | ------------------------------------------------------------------------------ |
| `FETCH_TIMEOUT_MS`                       | jogún `REQUEST_TIMEOUT_MS`                 | Àkókò ìdádúró ìbẹ̀rẹ̀-ìdáhùn upstream tí a ń lò títí àwọn àkọlé ìdáhùn yóò fi dé |
| `FETCH_HEADERS_TIMEOUT_MS`               | jogún `FETCH_TIMEOUT_MS`                   | Ààlà àkókò Undici fún gbígba àwọn àkọlé ìdáhùn upstream                        |
| `FETCH_BODY_TIMEOUT_MS`                  | jogún `FETCH_TIMEOUT_MS`                   | Ààlà àkókò Undici láàárín àwọn ẹ̀ka ara upstream (`0` máa ń pa á)               |
| `FETCH_CONNECT_TIMEOUT_MS`               | `30000`                                    | Àkókò ìdádúró àsopọ̀ TCP Undici                                                 |
| `FETCH_KEEPALIVE_TIMEOUT_MS`             | `4000`                                     | Àkókò ìdádúró socket keep-alive Undici nígbà àìṣiṣẹ́                            |
| `TLS_CLIENT_TIMEOUT_MS`                  | jogún `FETCH_TIMEOUT_MS`                   | Àkókò ìdádúró fún àwọn ìbéèrè ìdánimọ̀ TLS tí a ṣe nípasẹ̀ `wreq-js`             |
| `API_BRIDGE_PROXY_TIMEOUT_MS`            | jogún `REQUEST_TIMEOUT_MS` tàbí `600000`   | Àkókò ìdádúró fún fífi proxy `/v1` ránṣẹ́ láti port API sí port dashboard       |
| `API_BRIDGE_SERVER_REQUEST_TIMEOUT_MS`   | `max(API_BRIDGE_PROXY_TIMEOUT_MS, 300000)` | Àkókò ìdádúró ìbéèrè tó ń wọlé lórí server afárá API                           |
| `API_BRIDGE_SERVER_HEADERS_TIMEOUT_MS`   | `60000`                                    | Àkókò ìdádúró àkọlé tó ń wọlé lórí server afárá API                            |
| `API_BRIDGE_SERVER_KEEPALIVE_TIMEOUT_MS` | `5000`                                     | Àkókò ìdádúró keep-alive lórí server afárá API                                 |
| `API_BRIDGE_SERVER_SOCKET_TIMEOUT_MS`    | `0`                                        | Àkókò ìdádúró àìṣiṣẹ́ socket lórí server afárá API (`0` máa ń pa á)             |

> **Àkíyèsí:** Fún àwọn ìbéèrè ṣiṣàn, `FETCH_TIMEOUT_MS` bo ìṣètò àsopọ̀ / dídúró de ìdáhùn upstream àkọ́kọ́ nìkan. Ní kété tí ṣiṣàn bá ti ń ṣiṣẹ́, OmniRoute yóò fòpin sí i kìkì nígbà ìdúró gidi (`STREAM_IDLE_TIMEOUT_MS`) tàbí àìṣiṣẹ́ ara Undici (`FETCH_BODY_TIMEOUT_MS`).

### Ìbámu Reverse Proxy

Tí o bá ń ṣiṣẹ́ OmniRoute lẹ́yìn Nginx, Caddy, Cloudflare, tàbí reverse proxy mìíràn, rí i dájú pé àwọn àkókò ìdádúró proxy náà ga ju àwọn àkókò ìdádúró ṣiṣàn/fetch OmniRoute rẹ lọ.

## Ofo Linux (xbps-src) Àdàkọ

Fun awọn olumulo Linux ofo, o le kọ akojọpọ abinibi nipa lilo `xbps-src`. Ṣafipamọ bulọọki yii bi `srcpkgs/omniroute/template`:

```bash
# Template file for 'omniroute'
pkgname=omniroute
version=3.8.0
revision=1
hostmakedepends="nodejs python3 make"
depends="openssl"
short_desc="Universal AI gateway with smart routing for multiple LLM providers"
maintainer="zenobit <zenobit@disroot.org>"
license="MIT"
homepage="https://github.com/diegosouzapw/OmniRoute"
distfiles="https://github.com/diegosouzapw/OmniRoute/archive/refs/tags/v${version}.tar.gz"
# Regenerate the checksum for each release with:
#   curl -L -o /tmp/omniroute.tar.gz "https://github.com/diegosouzapw/OmniRoute/archive/refs/tags/v${version}.tar.gz" && sha256sum /tmp/omniroute.tar.gz
checksum=PLACEHOLDER_REGENERATE_PER_RELEASE
system_accounts="_omniroute"
omniroute_homedir="/var/lib/omniroute"
export NODE_ENV=production
export npm_config_engine_strict=false
export npm_config_loglevel=error
export npm_config_fund=false
export npm_config_audit=false

do_build() {
	local _gyp_arch
	case "$XBPS_TARGET_MACHINE" in
		aarch64*) _gyp_arch=arm64 ;;
		armv7*|armv6*) _gyp_arch=arm ;;
		i686*) _gyp_arch=ia32 ;;
		*) _gyp_arch=x64 ;;
	esac

	NODE_ENV=development npm ci --ignore-scripts
	npm run build
	cp -r .next/static .next/standalone/.next/static
	[ -d public ] && cp -r public .next/standalone/public || true

	local _node_gyp=/usr/lib/node_modules/npm/node_modules/node-gyp/bin/node-gyp.js
	(cd node_modules/better-sqlite3 && node "$_node_gyp" rebuild --arch="$_gyp_arch")

	local _bs3_release=.next/standalone/node_modules/better-sqlite3/build/Release
	mkdir -p "$_bs3_release"
	cp node_modules/better-sqlite3/build/Release/better_sqlite3.node "$_bs3_release/"

	rm -rf .next/standalone/node_modules/@img

	for _mod in pino-abstract-transport split2 process-warning; do
		cp -r "node_modules/$_mod" .next/standalone/node_modules/
	done
}

do_check() {
	npm run test:unit
}

do_install() {
	vmkdir usr/lib/omniroute/.next
	vcopy .next/standalone/. usr/lib/omniroute/.next/standalone

	for _d in \
		.next/standalone/.next/server/app/dashboard \
		.next/standalone/.next/server/app/dashboard/settings \
		.next/standalone/.next/server/app/dashboard/providers; do
		touch "${DESTDIR}/usr/lib/omniroute/${_d}/.keep"
	done

	cat > "${WRKDIR}/omniroute" <<'EOF'
#!/bin/sh
export PORT="${PORT:-20128}"
export DATA_DIR="${DATA_DIR:-${XDG_DATA_HOME:-${HOME}/.local/share}/omniroute}"
export APP_LOG_TO_FILE="${APP_LOG_TO_FILE:-false}"
mkdir -p "${DATA_DIR}"
exec node /usr/lib/omniroute/.next/standalone/server.js "$@"
EOF
	vbin "${WRKDIR}/omniroute"
}

post_install() {
	vlicense LICENSE
}
```
