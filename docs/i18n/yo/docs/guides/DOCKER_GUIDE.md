## Awọn ọna Ṣiṣe

> **Gbalejo ara-ẹni ni aṣẹ kan?** Wo [Itọsọna Olugbalejo ara-ẹni](../getting-started/SELF_HOST_GUIDE.md) — `docker compose -f docker-compose.selfhost.yml up -d` (aworan ti a tẹjade + Redis, loopback-nikan, ko si yiyan profaili). Ṣiṣe kiakia ni isalẹ ni ọna apo-ẹyọkan fun awọn olumulo ti o ti ṣiṣẹ Redis tẹlẹ ni ibomiiran.

```bash
docker run -d \
  --name omniroute \
  --restart unless-stopped \
  --stop-timeout 40 \
  -p 20128:20128 \
  -v omniroute-data:/app/data \
  cheaperinference/omniroute:latest
```

## Pẹlu Faili Ayika

```bash
# Copy and edit .env first
cp .env.example .env

docker run -d \
  --name omniroute \
  --restart unless-stopped \
  --stop-timeout 40 \
  --env-file .env \
  -p 20128:20128 \
  -v omniroute-data:/app/data \
  cheaperinference/omniroute:latest
```

## Docker Compose

```bash
# Profile ìpìlẹ̀ (kò ní àwọn irinṣẹ́ CLI)
docker compose --profile base up -d

# Profile CLI (Claude Code, Codex, OpenClaw wà nínú rẹ̀)
docker compose --profile cli up -d

# Profile host (Linux ní àkọ́kọ́; ó so àwọn binary CLI host pọ̀ gẹ́gẹ́ bí kíkà-nìkan)
docker compose --profile host up -d

# Profile wẹ́ẹ̀bù (Chromium/Playwright fún àwọn provider session wẹ́ẹ̀bù)
docker compose --profile web up -d

# Darapọ̀ CLI + CLIProxyAPI sidecar
docker compose --profile cli --profile cliproxyapi up -d
```

## Àwọn Profile Tó Wà

OmniRoute ní àwọn profile Compose fún àwọn ìrísí ìmúṣiṣẹ́ pàtàkì. Yan èyí tó bá àyíká rẹ mu.

| Profile           | Service          | Ìgbà tí o yẹ kí o lò ó                                                                                                                                        | Àṣẹ                                          |
| ----------------- | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| `base` (àìyípadà) | `omniroute-base` | Server aláìní interface / runtime kékeré jù, kò sí àwọn CLI provider tí a fi sínú rẹ̀                                                                          | `docker compose --profile base up -d`        |
| `cli`             | `omniroute-cli`  | Àwọn workflow agentic tó ń pe `omniroute providers/setup/doctor` àti àwọn CLI tí a fi sínú rẹ̀ (Codex, Claude Code, Droid, OpenClaw)                           | `docker compose --profile cli up -d`         |
| `host`            | `omniroute-host` | Àwọn host Linux tó fẹ́ ààyè ìráyèṣe bíi `network_mode` sí àwọn CLI host nípa sísopọ̀ `~/.local/bin`, `~/.codex`, `~/.claude`, àti bẹ́ẹ̀ bẹ́ẹ̀ lọ gẹ́gẹ́ bí kíkà-nìkan | `docker compose --profile host up -d`        |
| `cliproxyapi`     | `cliproxyapi`    | Ṣiṣẹ́ [CLIProxyAPI](https://github.com/router-for-me/CLIProxyAPI) sidecar lórí port `8317` fún proxy CLI upstream                                              | `docker compose --profile cliproxyapi up -d` |
| `web`             | `omniroute-web`  | Àwọn provider session wẹ́ẹ̀bù tó nílò browser: `gemini-web`, `claude-web`, `claude-turnstile` (ó build `runner-web`, Chromium wà nínú rẹ̀)                       | `docker compose --profile web up -d`         |

> A lè darapọ̀ ọ̀pọ̀ profile: `docker compose --profile cli --profile cliproxyapi up -d`.

## Ṣíṣètò àwọn irinṣẹ́ CLI ti host nígbà tí OmniRoute bá ń ṣiṣẹ́ nínú Docker

`omniroute setup-codex`, `setup-claude`, `config set <tool>` àti bọ́tìnì
**Fi àtòjọ-ẹ̀rọ pamọ́** ti dashboard, gbogbo wọn ni wọ́n ń kọ fáìlì bíi `~/.codex/*.config.toml`. Àwọn path wọ̀nyẹn
ní ìtumọ̀ lórí ẹ̀rọ tí CLI náà ti ń ṣiṣẹ́ nìkan. Tí o bá ṣiṣẹ́ wọn nínú
container, ohun tí a kọ yóò lọ sínú home ti container náà fúnra rẹ̀ (`/home/node` —
image náà ń ṣiṣẹ́ pẹ̀lú `USER node`), níbi tí CLI host kankan kò ti ní kà á láéláé, tí a ó sì
pa á rẹ́ ní kété tí a bá tún container náà ṣẹ̀dá.

OmniRoute máa ń ṣàwárí èyí, yóò sì kọ̀ láti kọ ọ́, nípa fífún ọ ní ìtọ́nisọ́nà dípò
jíjàbọ̀ àṣeyọrí tí o kò lè lò: CLI náà yóò jáde pẹ̀lú `2`, API náà yóò sì dáhùn `422`
pẹ̀lú `containerEphemeralTarget: true`.

### Ohun tí a dámọ̀ràn: ṣiṣẹ́ CLI lórí host, kí OmniRoute sì ṣiṣẹ́ nínú Docker

Container náà ń pèsè API; CLI náà ń ṣètò àwọn irinṣẹ́ host rẹ.

```bash
docker compose --profile base up -d

npm install -g omniroute
omniroute connect http://localhost:20128   # darí CLI sí container náà
omniroute setup-codex                      # kọ ~/.codex gidi sí host rẹ
```

Èyí ni àṣàyàn tó tọ́ nígbà tí Codex, Claude Code, Cursor tàbí irú wọn bá ń ṣiṣẹ́ lórí
laptop rẹ — èyí sì ni ìṣètò tí ó wọ́pọ̀.

### Àṣàyàn mìíràn: bind-mount àwọn directory àtòjọ-ẹ̀rọ host (profile `host`)

Tí o bá fẹ́ kí container náà fúnra rẹ̀ kọ àtòjọ-ẹ̀rọ host rẹ, mount àwọn
directory náà sínú rẹ̀, kí o sì darí `CLI_CONFIG_HOME` sí root mount náà. Profile `host`
ti ṣe èyí tẹ́lẹ̀:

```yaml
environment:
  - CLI_CONFIG_HOME=/host-home
  - CLI_ALLOW_CONFIG_WRITES=true
volumes:
  - ~/.codex:/host-home/.codex:rw
  - ~/.claude:/host-home/.claude:rw
```

Bind mount ni ó mú kí path náà ṣeé fọkàn tán: OmniRoute máa ń ka
`/proc/self/mountinfo`, yóò sì gba kí a kọ sí àwọn path tí a mount (àti sí àwọn directory
tí àwọn ọmọ wọn jẹ́ mount, èyí tí ó bá ìrísí `/host-home` lókè mu gan-an), nígbà tí
ó ṣì ń kọ̀ láti kọ sí àwọn tí a kò mount.

### Ọ̀nà àbáyọ: ṣètò àwọn CLI inú container fúnra rẹ̀ (má ṣe lò ó ju bó ṣe yẹ lọ)

Nígbà tí àwọn CLI bá ń gbé inú container náà ní ti gidi (profile `cli`), ìkọ̀wé náà
jẹ́ èyí tí a mọ̀ọ́mọ̀ ṣe. Fi `--allow-container-write` ránṣẹ́ sí àṣẹ `setup-*` èyíkéyìí, tàbí ṣètò
`OMNIROUTE_ALLOW_CONTAINER_CONFIG_WRITE=true` fún server náà. Ìkọ̀wé náà yóò tẹ̀síwájú
pẹ̀lú ìkìlọ̀ pé kò ní wà lẹ́yìn tí container náà bá parí.

> **Ìkìlọ̀ ààbò — profile `cli` + mount `docker.sock`.**
> Profile `cli` máa ń bind-mount `/var/run/docker.sock` kí auto-updater inú container
> lè tún stack náà ṣẹ̀dá láti daemon host
> (`src/lib/system/autoUpdate.ts` máa ń yẹ socket náà wò, yóò sì fò ipa-ọ̀nà
> Docker tí kò bá sí). Socket yẹn jẹ́ **ààlà ìgbẹ́kẹ̀lé root host**:
> ohunkóhun tó bá lè dé ọ̀dọ̀ rẹ̀ lè darí daemon Docker host gẹ́gẹ́ bí
> root — ó lè ṣẹ̀dá, yẹ̀wò, dá dúró, kí ó sì yọ container èyíkéyìí lórí host.
> Àwọn àbájáde rẹ̀:
>
> 1. **Má ṣe fi port profile `cli` hàn sí network láéláé.** Publish
>    rẹ̀ lórí `127.0.0.1` (`ports: "127.0.0.1:${DASHBOARD_PORT:-20128}:..."`)
>    — profile `cli` tí LAN lè dé sí yóò sọ RCE ipele-dashboard èyíkéyìí di
>    ìfọ́wọ́kọ host pátápátá.
> 2. **Má ṣe bind directory host àfikún kankan sínú profile `cli`.**
>    Socket Docker pẹ̀lú mount míì yóò fún container náà ní agbára kíkà/kíkọ
>    pátápátá sí filesystem àti àtòjọ-ẹ̀rọ host rẹ. Tí o bá nílò kí irinṣẹ́ kan
>    rí project kan, ṣiṣẹ́ rẹ̀ lórí ẹ̀rọ rẹ pẹ̀lú binary CLI — má ṣe mount rẹ̀
>    sínú container `cli`.
>
> Tí o kò bá nílò auto-update inú container, má ṣe tan profile `cli`
> (`COMPOSE_PROFILES=core,redis` tàbí èyí tó kúrú síi). Àwọn profile yòókù kò
> mount socket Docker.
>
> Wo `docs/security/MITM-TPROXY-DECRYPT.md` (git; a kò compile rẹ̀ sínú `/docs`) fún threat model tó ní í ṣe pẹ̀lú
> MITM, àti `docs/security/SUPPLY_CHAIN.md` fún
> provenance chain binary `codex`/`claude-code`/`droid`/`openclaw`.

## Redis Sidecar

OmniRoute gbára lé Redis láti ṣe àtìlẹ́yìn fún olùdínwọ̀n ìwọ̀n lílò tí a pín káàkiri àti cache tí a pín. A máa ń ṣàlàyé iṣẹ́ `redis` **ní gbogbo ìgbà** nínú `docker-compose.yml` (kò ní ìdènà profile kankan), ó sì máa ń bẹ̀rẹ̀ pẹ̀lú profile èyíkéyìí mìíràn.

| Àlàyé               | Iye                                         |
| ------------------- | ------------------------------------------- |
| Image               | `redis:7-alpine`                            |
| Orúkọ container     | `omniroute-redis`                           |
| Port inú            | `6379`                                      |
| Port host (àtúnṣe)  | `REDIS_PORT` (àkọ́kọ́ rẹ̀ ni `6379`)           |
| Ìsopọ̀ host (àtúnṣe) | `REDIS_BIND_HOST` (àkọ́kọ́ rẹ̀ ni `127.0.0.1`) |
| Volume              | `omniroute-redis-data` → `/data`            |
| Àyẹ̀wò ìlera         | `redis-cli ping` (àárín ìṣẹ́jú-àáyá 10)      |

Àwọn environment variable tó ní í ṣe pẹ̀lú rẹ̀:

- `REDIS_URL` — connection string tí a fi sínú app náà (`redis://redis:6379` nípa àkọ́kọ́).
- `REDIS_PORT` — ìtọ́ka port ní ẹ̀gbẹ́ host fún container Redis.
- `REDIS_BIND_HOST` — interface host tí a tẹ port náà jáde sí. Àkọ́kọ́ rẹ̀ ni `127.0.0.1`.

> **Ìdí tí loopback fi jẹ́ àkọ́kọ́:** sidecar náà ń ṣiṣẹ́ láìsí `requirepass`, àwọn
> container app sì ń dé ọ̀dọ̀ rẹ̀ lórí compose network (`redis:6379`) — port tí a tẹ̀ jáde
> wà fún àwọn irinṣẹ́ ẹ̀gbẹ́ host nìkan (`redis-cli`, `npm run dev` ti agbègbè). Títẹ̀ ẹ́ jáde lórí
> `0.0.0.0` yóò fi Redis tí kò ní ìfàṣẹsí hàn sí gbogbo host lórí LAN rẹ. Tí o bá ṣètò
> `REDIS_BIND_HOST=0.0.0.0`, tún fi `--requirepass` kun `command:` iṣẹ́ náà.

A kò dámọ̀ràn **pípa Redis** (olùdínwọ̀n ìwọ̀n lílò yóò sọ̀kalẹ̀ sí àṣàyàn àfirọ́pò inú memory). Tí o bá ní láti ṣe bẹ́ẹ̀, yọ tàbí sọ block iṣẹ́ `redis:` di comment nínú `docker-compose.yml`, tàbí ṣe scale rẹ̀ sí òdo:

```bash
docker compose up -d --scale redis=0
```

## Production Compose

Fún snapshot production tí a yà sọ́tọ̀, tí yóò máa ṣiṣẹ́ lẹ́gbẹ̀ẹ́ dev, lo `docker-compose.prod.yml`.

| Àlàyé                | Iye                                                                                  |
| -------------------- | ------------------------------------------------------------------------------------ |
| Fáìlì                | `docker-compose.prod.yml`                                                            |
| Port dashboard àkọ́kọ́ | `PROD_DASHBOARD_PORT=20130` (tí a tọ́ka sí `${DASHBOARD_PORT:-20128}` inú)            |
| Port API àkọ́kọ́       | `PROD_API_PORT=20131`                                                                |
| Image                | `omniroute:prod` (tí a kọ láti target `runner-cli`)                                  |
| Container Redis      | `omniroute-redis-prod` (`redis:8.6.2`, volume `redis-prod-data` àdáni)               |
| Volume data          | `omniroute-prod-data` (tí a fún ní orúkọ, tí ó sì dúró láàárín àwọn àtúnkọ́)          |
| Àwọn àyẹ̀wò ìlera     | `node healthcheck.mjs` + `redis-cli ping`, pẹ̀lú `depends_on` tí ìlera Redis ń ṣàkóso |

Bí a ṣe ń lò ó:

```bash
# Kọ́ stack production náà kí o sì bẹ̀rẹ̀ rẹ̀
docker compose -f docker-compose.prod.yml up -d --build

# Ṣàn àwọn log
docker compose -f docker-compose.prod.yml logs -f

# Dá a dúró (pa àwọn volume mọ́)
docker compose -f docker-compose.prod.yml down
```

Stack prod náà ń ṣiṣẹ́ ní ìṣọ̀kan pẹ̀lú compose dev (àwọn orúkọ container, port, àti volume wọn yàtọ̀), nítorí náà o lè máa bá ìmúdójúìwọ̀n agbègbè lọ nígbà tí production ṣì ń ṣiṣẹ́.

## Awọn ipele Dockerfile

Ibi ipamọ naa n gbe Dockerfile ipele-pupọ (`Dockerfile`). Awọn ipele mẹrin ti farahan; mu `target` ọtun fun ọran lilo rẹ.

| Ipele         | Aworan mimọ           | Idi                                                                                                                                                                                                                                                                                 |
| ------------- | --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `builder`     | `node:26-trixie-slim` | Ṣe fifi sori ẹrọ deps (`npm ci --legacy-peer-deps`) ati ṣiṣe `npm run build` (Turbopack nipasẹ aiyipada — wo awọn orisun akoko Kọ ni isalẹ)                                                                                                                                         |
| `runner-base` | `node:26-trixie-slim` | Akoko ṣiṣe iṣelọpọ pẹlu iṣelọpọ imurasilẹ Next.js.** Ko si olupese CLIs dipọ.**                                                                                                                                                                                                     |
| `runner-cli`  | `runner-base`         | Ṣe afikun `git`, `docker.io`, `docker-compose` ati CLIs agbaye: `@openai/codex`, `@anthropic-ai/claude-code`, `droid`, `openclaw`.** Yan eyi fun awọn ṣiṣan iṣẹ aṣoju.**                                                                                                            |
| `runner-web`  | `runner-base`         | Ṣafikun Playwright + aṣawakiri Chromium kan (`--with-deps`) fun awọn olupese igba wẹẹbu: `gemini-web`, `claude-web`, `claude-turnstile`.** Mu eyi nigbati o ba lo awọn olupese naa** — aworan itele naa kuna ni akoko ibeere laisi rẹ (wo akọsilẹ `-web` labẹ Awọn ikanni Tu silẹ). |

Kọ ibi-afẹde kan pato pẹlu ọwọ:

```bash
docker build --target runner-base -t omniroute:base .
docker build --target runner-cli  -t omniroute:cli  .
docker build --target runner-web  -t omniroute:web  .
```

### Kọ-akoko oro

Mẹta kọ awọn args ṣakoso kini awọn idiyele ipele `builder`. Wọn jẹ akoko-kikọ nikan — `OMNIROUTE_MEMORY_MB` (isalẹ) jẹ lọtọ, koko asiko.

| Kọ arg                      | Aiyipada | Ipa                                                                                           |
| --------------------------- | -------- | --------------------------------------------------------------------------------------------- |
| `OMNIROUTE_USE_TURBOPACK`   | `0`      | `0` kọ pẹlu apo-iwe wẹẹbu: iranti tente oke kekere, o lọra. `1` jade sinu Turbopack.          |
| `OMNIROUTE_BUILD_MEMORY_MB` | `6144`   | V8 òkìtì òkìtì (`--max-old-space-size`) fún `next build` ti a ti fọ́.                          |
| `OMNIROUTE_BUILD_WORKERS`   | `2`      | Awọn ifunni `CIRCLE_NODE_TOTAL`; Nigbamii ti n gba `workers = N - 1` fun gbigba data oju-iwe. |

`OMNIROUTE_BUILD_WORKERS` ni ẹni lati gbe soke lori akọle nla ati ọkan lati fura nigbati ile ti o ni ihamọ ba ku** lẹhin** `✓ Compiled successfully`. Oṣiṣẹ data oju-iwe kọọkan jẹ ilana tirẹ, ati bẹ naa obi `next build` funrararẹ; ẹda VPS laaye kan (ọrọ #7518) ṣe iwọn RSS ti ilana kọọkan ni ~ 4.5 GB ni ominira ti asia okiti `NODE_OPTIONS` (Turbopack ṣe akopọ ni iranti native/Rust ni ita òkiti V8). Aiyipada ti `2` (osise → 1, lapapọ awọn ilana 2) jẹ iwọn fun awọn asare 16 GB /4 vCPU GitHub ti o gbalejo ti nlo opo gigun ti epo. Ni `8` (awọn oṣiṣẹ → 7) ti olusare ti pari iranti ati buildkit kuna igbesẹ pẹlu `ResourceExhausted: ... cannot allocate memory`; `3` (awọn oṣiṣẹ → 2) ko ni ibamu ni kete ti a ti wọn RSS ilana fun-ila taara dipo ti oye. `tests/unit/docker-build-memory-budget.test.ts` ṣe isiro lodi si nọmba ti wọn wọn ko si kuna ti boya koko ba dagba ju olusare.

Turbopack ṣe akopọ ni iranti ipata abinibi ti o ngbe** ita** òkiti V8, nitorina `OMNIROUTE_BUILD_MEMORY_MB` ko ni dè e. Lori agbalejo kan pẹlu orule iranti itumọ naa jẹ SIGKILLed nipasẹ apaniyan OOM laisi ọrọ aṣiṣe ni gbogbo — o kan duro aarin-`Creating an optimized production build`, eyiti o ka bi idorikodo dipo iranti-jade. Ti o ni idi ti awọn aiyipada `Dockerfile` si webpack (`OMNIROUTE_USE_TURBOPACK=0`), ko dabi `npm run dev` / `npm run build`, nibiti Turbopack jẹ aiyipada koodu: `docker build .` igboro ti ko ni awọn args kọ (kini Railway ati awọn ọmọ-ogun titẹ-ọkan miiran nṣiṣẹ) ko gbọdọ ku ni ipalọlọ lori akọle ti o ni iranti. Awọn aworan ti a tẹjade tẹlẹ kọja `OMNIROUTE_USE_TURBOPACK=0` ni gbangba ni `docker-publish.yml`. Lori olupilẹṣẹ pẹlu ọpọlọpọ RAM, jade sinu Turbopack fun kikọ yiyara:

```bash
docker build --target runner-base \
  --build-arg OMNIROUTE_USE_TURBOPACK=1 \
  -t omniroute:base .
```

`webpackBuildWorker` ti ṣiṣẹ, nitorina `next build` nṣiṣẹ obi kan** ati** ilana oṣiṣẹ ati ọkọọkan ọlá `OMNIROUTE_BUILD_MEMORY_MB` lọtọ. Ṣe iwọn aja eiyan loke aijọju lẹmeji iye yẹn, kii ṣe lẹẹkan.

Tiwọn lori igi yii (`--target runner-base`, `OMNIROUTE_BUILD_MEMORY_MB=6144`):

| Bundler   | Eiyan orule    | Abajade                        |
| --------- | -------------- | ------------------------------ |
| Turbopack | 8 GiB / 16 GiB | OOM-pa ni mejeji, ipalọlọ      |
| apo wẹẹbu | 8 GiB          | kọ osise SIGKILLed             |
| apo wẹẹbu | 12 GiB         | ṣe aṣeyọri, peaked ni 11.1 GiB |

### Awọn aiyipada asiko-ṣiṣe

Awọn aiyipada ti a gbejade nipasẹ `runner-base`: `PORT=20128`, `HOSTNAME=0.0.0.0`, `OMNIROUTE_MEMORY_MB=1024`, `NODE_OPTIONS=--max-old-space-size=1024`, `DATA_DIR=/app/data`, `OMNIROUTE_MIGRATIONS_DIR=/app/migrations`.

Iwa iranti ni Docker:

- Aworan naa ṣeto `OMNIROUTE_MEMORY_MB=1024` o si gba `NODE_OPTIONS=--max-old-space-size=1024` lati ọdọ rẹ.
- Ilana olupin gangan ti bẹrẹ nipasẹ olupilẹṣẹ imurasilẹ, eyiti o ka `OMNIROUTE_MEMORY_MB` ati fikun `--max-old-space-size=<OMNIROUTE_MEMORY_MB>`.
- Node nlo iye `--max-old-space-size` ti o kẹhin ti o kẹhin, nitorina eto `OMNIROUTE_MEMORY_MB` n ṣakoso opin okiti Docker ti o munadoko.
- Nitoripe aworan nigbagbogbo ṣeto rẹ, ifilọlẹ ti ararẹ RAM-calibrated fallback ko kan labẹ Docker. Gbe soke ni gbangba fun fifuye iṣẹ (tabili ni isalẹ). `2048` tun kere ju fun aṣoju koodu `/v1/responses`.

### Akoko ṣiṣe RAM fun awọn aṣoju ifaminsi

1 GiB Docker aiyipada jẹ ilẹ dashboard/light-chat kan, kii ṣe iwọn iṣelọpọ kan. Awọn ara `POST /v1/responses` gigun (awọn ọgọọgọrun ti awọn ifiranṣẹ, awọn mewa ti awọn irinṣẹ) ṣe idaduro ọpọ awọn aworan inu-iranti lakoko funmorawon. Awọn ibeere ami-ami ~ 3 MiB / ~ 750k meji ti fagile V8 ni a** 12 GiB** aaye atijọ (`FATAL ERROR: Reached heap limit`) ati tun lu 16 GiB cgroup OOM. Wo [#7849](https://github.com/diegosouzapw/OmniRoute/issues/7849).

Iwọn** cgroup `--memory` loke okiti** — awọn buffers abinibi, SQLite, ati awọn agbedemeji funmorawon joko ni ita V8.

| Agbara iṣẹ                             | `OMNIROUTE_MEMORY_MB`    | Apoti / akojọpọ     | Awọn akọsilẹ                                                                                |
| -------------------------------------- | ------------------------ | ------------------- | ------------------------------------------------------------------------------------------- |
| Dasibodu, ọkan ina iwiregbe            | `1024` (aiyipada aworan) | ≥2 GiB              |                                                                                             |
| Aṣoju ifaminsi kan (Claude/Codex/Grok) | `8192`                   | ≥10 GiB             | Aṣoju igba-ọkan `/v1/responses`                                                             |
| Meji nigbakanna gun `/v1/responses`    | `10240`–`12288`          | ≥12–16 GiB          | Tiwọn V8 abort ni ~ 12 GiB òkiti                                                            |
| Meta + igbakanna gun àrà               | ma ṣe lori ilana kan     | serialize / diẹ RAM | Gbigba iwuwo iwuwo aiyipada jẹ 1 ninu ọkọ ofurufu; igbega o lai RAM reintroduces awọn abort |

`omniroute serve` lori awọn calibrates irin igboro ~ 35% ti RAM (clamped `[512, 4096]`) nigbati `OMNIROUTE_MEMORY_MB` jẹ** unset** . Docker nigbagbogbo ṣeto `1024`, ki odiwọn ko ṣiṣẹ ni aworan osise.

```bash
docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 \
  -e OMNIROUTE_MEMORY_MB=8192 --memory=10g \
  -p 127.0.0.1:20128:20128 -v omniroute-data:/app/data cheaperinference/omniroute:latest
```

## Aṣoju yiyipada lori ọna-ọna kan (Traefik / nginx)

Next.js `basePath` is compiled into the standalone bundle. OmniRoute records the baked value in a sentinel file at the app root (written during `npm run build`; read by `scripts/docker/ensure-docker-base-path.mjs`) and compares it with `OMNIROUTE_BASE_PATH` when the container starts. When they differ and the image was built for the domain root, the entrypoint rewrites the standalone manifests, the embedded `basePath`/`assetPrefix` literals (Next 16 renders SSR asset URLs from `assetPrefix` alone — the patcher mirrors the subpath into it), the baked `/_next/static` asset URLs (client-reference manifests, media imports, prerendered error pages) and the client `process.env` shim before `node dev/run-standalone.mjs` runs.

### Kọ kikọ (a ṣe iṣeduro)

Ṣeto awọn oniyipada mejeeji ni `.env`, lẹhinna tun ṣe ki aworan naa ati akoko asiko gba:

```bash
# .env
OMNIROUTE_BASE_PATH=/omniroute
NEXT_PUBLIC_BASE_URL=https://myhostname.example.com/omniroute
```

```bash
docker compose --profile base up -d --build
```

`docker-compose.yml` siwaju `OMNIROUTE_BASE_PATH` bi Docker Kọ-arg ati bi oniyipada ayika asiko.

### Aworan root ti a ti kọ tẹlẹ + asiko ṣiṣe subpath

Awọn aworan `cheaperinference/omniroute:*` ti a tẹjade jẹ itumọ fun gbongbo agbegbe naa. O tun le ṣeto `OMNIROUTE_BASE_PATH` ni akoko asiko; eiyan abulẹ awọn lapapo lẹẹkan lori ibẹrẹ. Papọ pẹlu orisun ti gbogbo eniyan ti o baamu:

```yaml
services:
  omniroute:
    image: cheaperinference/omniroute:latest
    environment:
      OMNIROUTE_BASE_PATH: /omniroute
      NEXT_PUBLIC_BASE_URL: https://myhostname.example.com/omniroute
```

Tunto aṣoju yiyipada lati dari awọn** kun** ona ita (maṣe yọ ìpele). Traefik yẹ ki o dari `PathPrefix(`/ omniroute `)` si apoti laisi `StripPrefix`, nitorina Next.js gba `/omniroute/...` ati ṣiṣe awọn ohun-ini lati `/omniroute/_next/...`.

Ṣiṣayẹwo ilera Docker ṣe iwadii aaye ipari ipari igbesi aye `/healthz` iwuwo fẹẹrẹ pẹlu `OMNIROUTE_BASE_PATH` ti nṣiṣe lọwọ. `/api/monitoring/health` wa fun awọn iwadii human/dashboard ; lati tọka apoti HEALTHCHECK pada si (fun apẹẹrẹ fun imuse ilera ti o jinlẹ), ṣeto `OMNIROUTE_HEALTHCHECK_PATH=/api/monitoring/health`. Ọna naa jẹ a** jin** ṣayẹwo (akojọ ibojuwo DB + ) — yẹ fun Docker `HEALTHCHECK` ti o ba jade pada, ṣugbọn** kii ṣe** fun Kubernetes `livenessProbe` awọn aaye arin.

Fun awọn akọrin (Kubernetes, Nomad, ati bẹbẹ lọ):

| Iwadi            | Fẹ                                                                      | Yẹra fun                                          |
| ---------------- | ----------------------------------------------------------------------- | ------------------------------------------------- |
| Igbesi aye       | HTTP `GET /livez`, tabi TCP lori ibudo akọkọ (`PORT`, aiyipada `20128`) | `/api/monitoring/health` bi liveness              |
| Imurasilẹ        | HTTP `GET /healthz`                                                     | Awọn akoko wiwọ ti o tọju iṣẹlẹ-lupu nšišẹ bi okú |
| Jin / apoti dudu | `/api/monitoring/health`                                                | —                                                 |

`/healthz` ṣe ijabọ ilana igbesi aye (`ok` / `starting` / `stopping`). `/livez` jẹ ilana-laaye nikan (200 nigbakugba ti olutọju le ṣiṣẹ; ko duro fun imurasilẹ). Awọn mejeeji tun ṣiṣẹ lori lupu iṣẹlẹ Node kanna bi mimu ibeere, nitorinaa katalogi ti o ni asopọ Sipiyu tabi iṣẹ funmorawon le ṣe idaduro wọn — nšišẹ ≠ ti ku. Fẹ igbesi aye TCP ti akoko ṣiṣewadii HTTP ba jade. Itọsọna iwadii ni kikun: [Itọsọna abojuto — Kubernetes awọn iṣeduro iwadii](../ops/MONITORING_GUIDE.md#kubernetes-probe-recommendations).

## Docker Kọ pẹlu Caddy (HTTPS Auto-TLS)

OmniRoute le ṣe afihan ni aabo ni lilo ipese SSL laifọwọyi ti Caddy. Rii daju pe DNS ti agbegbe rẹ Awọn aaye igbasilẹ kan si IP olupin rẹ.

```yaml
services:
  omniroute:
    image: cheaperinference/omniroute:latest
    container_name: omniroute
    restart: unless-stopped
    volumes:
      - omniroute-data:/app/data
    environment:
      - PORT=20128
      # Browser-facing origin for OAuth callbacks, dashboard links, and generated public URLs.
      - NEXT_PUBLIC_BASE_URL=https://your-domain.com
      # Internal server-to-server URL for scheduled jobs / self-fetches.
      - BASE_URL=http://omniroute:20128
      - AUTH_COOKIE_SECURE=true

  caddy:
    image: caddy:latest
    container_name: caddy
    restart: unless-stopped
    ports:
      - "80:80"
      - "443:443"
    command: caddy reverse-proxy --from https://your-domain.com --to http://omniroute:20128

volumes:
  omniroute-data:
```

Caddy ṣeto awọn akọle firanšẹ siwaju boṣewa fun eiyan ti oke. OmniRoute nlo `NEXT_PUBLIC_BASE_URL` gẹgẹbi ipilẹṣẹ gbangba ti canonical fun OAuth callbacks ati awọn ọna asopọ ti gbogbo eniyan ti ipilẹṣẹ; Dasibodu ti a fọwọsi kọwe lo awọn ibeere orisun-kanna pẹlu aabo CSRF igba-igba. Mu `OMNIROUTE_TRUST_PROXY` ṣiṣẹ nikan fun awọn imuṣiṣẹ ilọsiwaju nibiti o ti mọọmọ fẹ OmniRoute lati gba orisun ti gbogbo eniyan lati awọn akọle ti o gbẹkẹle dipo iṣeto ni gbangba.

## Cloudflare Quick Tunnel

Àtìlẹ́yìn dashboard fún àwọn ìmúṣiṣẹ́ Docker ní **Cloudflare Quick Tunnel** tí a lè ṣiṣẹ́ pẹ̀lú títẹ̀ ẹ̀ẹ̀kan ní `Dashboard → Endpoints`. Ṣíṣe é fún ìgbà àkọ́kọ́ yóò ṣe ìgbàsílẹ̀ `cloudflared` nígbà tí a bá nílò rẹ̀ nìkan, bẹ̀rẹ̀ tunnel ìgbà díẹ̀ sí endpoint `/v1` rẹ lọ́wọ́lọ́wọ́, yóò sì fi URL `https://*.trycloudflare.com/v1` tí a ṣẹ̀dá hàn ní tààrà lábẹ́ URL gbogbogbò rẹ déédéé.

A lè fi àwọn paneli tunnel endpoint (Cloudflare, Tailscale, ngrok) hàn tàbí fi wọ́n pamọ́ láti `Settings → Appearance` láìyí ipò tunnel tó ń ṣiṣẹ́ padà.

### Àwọn Àkíyèsí Tunnel

- Àwọn URL Quick Tunnel jẹ́ ti ìgbà díẹ̀, wọ́n sì máa ń yí padà lẹ́yìn gbogbo ìbẹ̀rẹ̀ tuntun.
- A kì í dá àwọn Quick Tunnel padà láìfọwọ́yí lẹ́yìn ìbẹ̀rẹ̀ tuntun OmniRoute tàbí container. Ṣe wọ́n ṣiṣẹ́ lẹ́ẹ̀kan sí i láti dashboard nígbà tí a bá nílò wọn.
- Ìfisórí tí a ń ṣàkóso ń ṣe àtìlẹ́yìn fún Linux, macOS, àti Windows lórí `x64` / `arm64` lọ́wọ́lọ́wọ́.
- Àwọn Quick Tunnel tí a ń ṣàkóso máa ń lo ìgbékalẹ̀ HTTP/2 gẹ́gẹ́ bí àtúnṣe àkọ́kọ́ láti yẹra fún àwọn ìkìlọ̀ buffer QUIC UDP aláriwo nínú àwọn àyíká container tí a ní ààlà. Ṣètò `CLOUDFLARED_PROTOCOL=quic` tàbí `auto` bí o bá fẹ́ ìgbékalẹ̀ mìíràn.
- Àwọn image Docker ní àwọn gbòǹgbò CA ètò nínú, wọ́n sì ń fi wọ́n ránṣẹ́ sí `cloudflared` tí a ń ṣàkóso, èyí tó ń dènà ìkùnà ìgbẹ́kẹ̀lé TLS nígbà tí tunnel bá ń bẹ̀rẹ̀ nínú container.
- Ṣètò `CLOUDFLARED_BIN=/absolute/path/to/cloudflared` bí o bá fẹ́ kí OmniRoute lo binary tó ti wà tẹ́lẹ̀ dípò ṣíṣe ìgbàsílẹ̀ tuntun.

Awọn aworan kanna ni a tẹjade si awọn ibi-ipamọ mẹta, pẹlu awọn idawọle ti ile-iṣọkan kanna: `cheaperinference/omniroute` (Docker Hub, agbari Inference ti o din owo, lati 3.8.53 lori), `ghcr.io/cheaper-inference/omniroute` ati ogún `diegosouzapw/omniroute`, eyiti o tọju itan-akọọlẹ fa rẹ ati tun gba gbogbo idasilẹ. Awọn imuṣiṣẹ `diegosouzapw/omniroute` ti o wa tẹlẹ tọju imudojuiwọn; yiyipada orukọ aworan jẹ iyan. ikanni itusilẹ ṣaaju `:next` / `:next-web` ni isalẹ jẹ atẹjade si `diegosouzapw/omniroute` ati GHCR nikan.

Afihan ọpọlọpọ-Syeed: `linux/amd64` + `linux/arm64` abinibi (Apple Silicon, AWS Graviton, Rasipibẹri Pi). Docker yan faaji ti o baamu laifọwọyi; kọja `--platform linux/amd64` ti o ba nilo lati fi agbara mu apẹẹrẹ AMD64 lori awọn ogun ARM.

### Tu awọn ikanni

OmniRoute ṣe atẹjade awọn ikanni Docker lọtọ fun awọn idasilẹ iduroṣinṣin, idanwo-itusilẹ ti nṣiṣe lọwọ, ati awọn kikọ idagbasoke.

| ikanni                          | Orisun                                      | Iyipada                     | Iṣeduro lilo                                                                                                                        |
| ------------------------------- | ------------------------------------------- | --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `:<version>` / `:<version>-web` | Signed/versioned silẹ                       | Aileyipada                  | Awọn imuṣiṣẹ iṣelọpọ ti o pin idasilẹ gangan                                                                                        |
| `:latest` / `:latest-web`       | Ti o ga julọ** atejade** SemVer idurosinsin | Atọka iduroṣinṣin mutable   | Tẹle awọn idasilẹ iduroṣinṣin** lẹhin** a SemVer atejade ise — ṣe** kii ṣe** orin `main` tabi awọn iṣẹ `release/v*` ti a ko tu silẹ |
| `:next` / `:next-web`           | Ẹka `release/v*` aiyipada lọwọlọwọ          | Atọka itusilẹ to ṣee yipada | Awọn atunṣe idanwo ti o ti de lori ẹka itusilẹ ti nṣiṣe lọwọ ṣugbọn ko tii wa ni idasilẹ iduroṣinṣin                                |
| `:main` / `:main-web`           | ẹka `main`                                  | Atọka idagbasoke iyipada    | Idagbasoke ati idanwo iṣọpọ nikan                                                                                                   |

#### Awọn olupese aaye ayelujara: awọn aworan `-web`

Gbogbo ikanni ti o wa loke ni ilọpo meji bi tag `-web` (`:latest-web`, `:<version>-web`, `:next-web`, `:main-web`), ti a ṣe lati ipele `runner-web` — aworan kanna pẹlu Playwright ati aṣawakiri Chromium kan. Awọn ọkọ oju-omi aworan itele** laisi** Chromium; `gemini-web`, `claude-web` ati `claude-turnstile` nilo rẹ.

Ikuna naa ti da duro, kii ṣe akoko ibẹrẹ: awọn olupese wọnyẹn ṣe atokọ awọn awoṣe wọn ati ṣafihan bi a ti sopọ ninu dasibodu, ati pe ibeere akọkọ nikan kuna pẹlu

```
[500]: Failed to load external module playwright: Error: Cannot find module
'/app/node_modules/playwright/node_modules/playwright-core/browsers.json'
```

Ti o ba lo awọn olupese wọnyẹn, fa aami `-web` ti ikanni ti o ti wa tẹlẹ lori — ko si ohun miiran ti o yipada. Lori fifi sori npm/CLI (ko si aworan Docker ), nkan ti o padanu deede ni alakomeji aṣawakiri: ṣiṣe `npx playwright install chromium` lori agbalejo naa.

#### Lilo ikanni iṣaaju-itusilẹ

Ikanni `next` ti tun ṣe lori gbogbo titari si ẹka aiyipada `release/v*` lọwọlọwọ ati pe o jẹ atẹjade fun mejeeji AMD64 ati ARM64. Awọn ẹka itọju agbalagba ko le ṣe atunkọ rẹ. Ikanni naa n pese aworan ti o le fa fun awọn atunṣe ti o ti dapọ si ẹka idasilẹ ti nṣiṣe lọwọ ṣaaju ki o to ge aami iduro ti o tẹle.

```bash
docker pull diegosouzapw/omniroute:next
docker pull diegosouzapw/omniroute:next-web
```

Fun Docker Ṣajọ, fagile aami aworan ti o lo nipasẹ profaili ti o yan, lẹhinna fa ati tun iṣẹ naa ṣe:

```yaml
services:
  omniroute:
    image: diegosouzapw/omniroute:next
```

```bash
docker compose pull
docker compose up -d
```

#### Ailewu ati rollback

`next` jẹ ikanni itusilẹ lilefoofo loju omi. O le yipada lori eyikeyi titari si ẹka idasilẹ ti nṣiṣe lọwọ ati pe o jẹ** ko ṣe atilẹyin fun lilo iṣelọpọ** . Pin ohun kikọ silẹ aworan lakoko ti o n ṣe iṣiro kikọ kan pato:

```bash
docker pull diegosouzapw/omniroute:next
docker image inspect diegosouzapw/omniroute:next --format '{{index .RepoDigests 0}}'
```

Ṣaaju idanwo, ṣe afẹyinti iwọn didun data OmniRoute tabi ilana data ti a fi dipọ. Lati yi pada, mu pada ẹya iduro ti o ti lo tẹlẹ tabi daajẹ ki o tun ṣe eiyan naa:

```bash
docker pull cheaperinference/omniroute:<stable-version>
docker compose up -d
```

Ẹka-itusilẹ ko le gbe `latest` lailai; Ẹya atunmọ iduro ti o yẹ nikan le ṣe igbega itọka iduroṣinṣin. Awọn aworan `next` ni idaduro ayewo aworan itusilẹ ati dinamọ ẹnu-ọna ailagbara-CIRITICAL.

**`latest` kii ṣe iṣeduro owo fun git.** Awọn atunṣe ti a dapọ lori `main` tabi lori ẹka `release/v*` ti nṣiṣe lọwọ jẹ** kii ṣe** ni `:latest` titi aworan SemVer iduroṣinṣin yoo fi gbejade ati pe iṣẹ atẹjade n ṣe agbega `:latest` (idasilẹ kanna bii SemVer yẹn). Ti `latest` ba dabi didi nigba ti GitHub ti ṣe afihan atunṣe tẹlẹ, fa `:next` lati ṣe idanwo ẹka idasilẹ tabi duro de aami SemVer.

| O fẹ                                                           | Lo                                  |
| -------------------------------------------------------------- | ----------------------------------- |
| GitOps / iṣelọpọ ti ko gbọdọ fiseete                           | Pin `:X.Y.Z` (tabi aworan daijesti) |
| Tẹle awọn iduro ti a tẹjade ati gba atunda lori itusilẹ kọọkan | `:latest`                           |
| Ṣe idanwo awọn iṣẹ `release/v*` ti a ko tu silẹ                | `:next` (kii ṣe iṣelọpọ)            |
| `main`                                                         | `:main` (kii ṣe iṣelọpọ)            |

## Àwọn ìmúdójúìwọ̀n Dashboard nínú Docker

Container àwòrán tí a ti tẹ̀jáde kò lè rọ́pò ara rẹ̀. Nígbà tí OmniRoute bá ṣàwárí pé òun ń ṣiṣẹ́ nínú
container kan (kò sí checkout `.git`, kì í ṣe ìfisórí npm), àsìá ìmúdójúìwọ̀n dashboard ojúlé yóò fi
àṣẹ host tí a ó ṣiṣẹ́ hàn dípò àwọn ìtọ́ni npm/git, pẹ̀lú bọ́tìnì ìṣàdàkọ:

```bash
docker compose pull omniroute && docker compose up -d --force-recreate omniroute
```

Orúkọ service náà wá láti `AUTO_UPDATE_SERVICE` (àkọ́kọ́bẹ̀rẹ̀ jẹ́ `omniroute`, service tó wà nínú
`docker-compose.selfhost.yml`). `pull` kàn ń ṣí àmì tó ń yípadà (`latest`, `next`); pẹ̀lú àmì
`:X.Y.Z` tí a ti dè mọ́ ẹ̀yà kan, kọ́kọ́ ṣàtúnṣe àmì náà.

### Àwọn ìmúdójúìwọ̀n ọlọ́kan-tẹ̀ pẹ̀lú fáìlì ìmúnṣiṣẹ́ host

Láti jẹ́ kí **Ṣe Ìmúdójúìwọ̀n Báyìí** máa ṣiṣẹ́ láì gbe `/var/run/docker.sock` sókè (èyí tó ń fún container
ní àṣẹ root lórí host — wo ìkìlọ̀ profile `cli` lókè), ṣètò `DOCKER_UPDATE_TRIGGER_FILE` lórí
service OmniRoute kí o sì ṣiṣẹ́ olùṣọ́ kan lórí host:

```yaml
services:
  omniroute:
    environment:
      DOCKER_UPDATE_TRIGGER_FILE: /app/data/update/docker-update.request
    volumes:
      - ./data:/app/data
```

Ọ̀nà náà gbọ́dọ̀ wà nínú `DATA_DIR` (àwọn iye ìbátan máa ń yanjú ní ìbámu pẹ̀lú rẹ̀); ohunkóhun mìíràn ni a
ó kọ̀. **Ṣe Ìmúdójúìwọ̀n Báyìí** yóò kọ `{ "requestedAt": "...", "targetVersion": "X.Y.Z" }` sínú
fáìlì náà, dáhùn pẹ̀lú `202`, dashboard náà yóò sì máa ṣàyẹ̀wò `/api/system/version` títí ẹ̀yà tuntun
yóò fi bẹ̀rẹ̀ sí í ṣiṣẹ́, lẹ́yìn náà yóò tún kojú. OmniRoute kì í ṣiṣẹ́ shell tàbí àṣẹ Docker rárá ní ipò yìí. Gẹ́gẹ́ bí gbogbo
ìgbésẹ̀ ìmúdójúìwọ̀n, àwọn client loopback/LAN nìkan ni a ti ń gba ìbéèrè náà lọ́wọ́ wọn.

Ìtọ́kasí data tí a so mọ́ bind ń fún host ní ọ̀nà tó dúró ṣinṣin láti máa ṣọ́. Àwọn unit `systemd` àpẹẹrẹ
(ṣàtúnṣe `/srv/omniroute` sí ìtọ́kasí tó ní fáìlì compose rẹ àti `data/`):

```ini
# /etc/systemd/system/omniroute-update.path
[Unit]
Description=Ṣọ́ àwọn ìbéèrè ìmúdójúìwọ̀n dashboard OmniRoute

[Path]
PathExists=/srv/omniroute/data/update/docker-update.request

[Install]
WantedBy=multi-user.target
```

```ini
# /etc/systemd/system/omniroute-update.service
[Unit]
Description=Fa container OmniRoute kalẹ̀ kí o sì tún un ṣẹ̀dá

[Service]
Type=oneshot
WorkingDirectory=/srv/omniroute
ExecStartPre=/usr/bin/rm -f /srv/omniroute/data/update/docker-update.request
ExecStart=/bin/sh -c 'docker compose pull omniroute || (sleep 15 && docker compose pull omniroute)'
ExecStart=/usr/bin/docker compose up -d --force-recreate omniroute
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now omniroute-update.path
```

Service náà máa ń yọ ìbéèrè náà kúrò kí ó tó fa àwòrán náà kalẹ̀, kí ìṣiṣẹ́ tó kùnà má bà á lọ sínú ìyípo. Láìsí
`DOCKER_UPDATE_TRIGGER_FILE`, dashboard náà yóò tẹ̀síwájú pẹ̀lú ìlànà àṣẹ ọwọ́.

## Wiwa: aiyipada SQLite jẹ ẹda-ẹyọkan

Iṣura Docker / Kubernetes OmniRoute jẹ** Ilana Node kan + ọkan SQLite onkqwe** . Ga wiwa ni** ko ni atilẹyin** lori topology yẹn.

| Ihamọ                           | Abajade                                                                                                                                                                                                                                                                                     |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Onkọwe nikan                    | Ṣe** kii ṣe** ṣiṣe ọpọlọpọ awọn ẹda lodi si faili SQLite kanna. Iyẹn ba DB jẹ.                                                                                                                                                                                                              |
| Tun / tun bẹrẹ / HEALTHCHECK pa | **Ilọkuro ni kikun** ti SSE in-flight, awọn akoko dasibodu, ati ipo iranti. Gbogbo ti sopọ ni ose silẹ. Awọn ibeere titun lakoko ferese opin-opin gba aṣoju-pada**`502 Bad Gateway: Unknown error`** , kii ṣe awọn onibara OmniRoute JSON — ko le ṣe iyatọ eyi lati ikuna olupese (#11015). |
| Lupu iṣẹlẹ kanna bi `/healthz`  | Katalogi ti o nšišẹ tabi ami titẹkuro le ṣe idaduro awọn iwadii; akoko kukuru kan lẹhinna tun bẹrẹ** nikan** ajọra.                                                                                                                                                                         |

**Matrix ibere** (wo tun [Kubernetes awọn iṣeduro iwadii](../ops/MONITORING_GUIDE.md#kubernetes-probe-recommendations) ):

| Iwadi        | Àfojúsùn                                                 | Maṣe lo                                           |
| ------------ | -------------------------------------------------------- | ------------------------------------------------- |
| Igbesi aye   | TCP on `PORT` (default `20128`), or soft HTTP `/healthz` | `/api/monitoring/health`                          |
| Imurasilẹ    | HTTP `GET /healthz`                                      | Awọn akoko wiwọ ti o tọju iṣẹlẹ-lupu nšišẹ bi okú |
| Jin / eniyan | `/api/monitoring/health`                                 | Aládàáṣiṣẹ kubelet liveness                       |

**Awọn ilọsiwaju:** reti gbogbo igba lati ju silẹ. Sisan awọn onibara ti o ba le; ko si imudojuiwọn yiyi lori aiyipada SQLite. Ṣajọ `restart: unless-stopped` pẹlu Docker `HEALTHCHECK` yoo tun rọpo ilana nikan nigbati eiyan naa jẹ Aini ilera — radius bugbamu kanna.

Awọn ifihan ti o ti ṣetan ati iwe aworan Helm kan n gbe ni `deploy/kubernetes/` ati `deploy/helm/omniroute/` — wo [itọsọna imuṣiṣẹ Kubernetes](../ops/KUBERNETES_DEPLOYMENT_GUIDE.md).

Kubernetes snippet fun a** nikan ajọra** (Atunse nilo; maṣe gbe `replicas` ga si faili SQLite kan):

```yaml
spec:
  replicas: 1
  strategy:
    type: Recreate
  template:
    spec:
      terminationGracePeriodSeconds: 90
      containers:
        - name: omniroute
          lifecycle:
            preStop:
              exec:
                command: ["/bin/sleep", "15"]
          readinessProbe:
            httpGet:
              path: /healthz
              port: 20128
            periodSeconds: 5
          livenessProbe:
            tcpSocket:
              port: 20128
            periodSeconds: 20
```

`preStop` sun jẹ ki kube ju awọn aaye ipari Iṣẹ silẹ ṣaaju SIGTERM bẹ** titun** ijabọ duro kọlu ilana ti o ku. Ninu ọkọ ofurufu `/v1/responses` SSE ti wa ni imugbẹ to `SHUTDOWN_TIMEOUT_MS` (aiyipada 30s) nipasẹ awọn iyalo gbigba iwuwo iwuwo (#11015). Awọn ibeere tuntun ti o tun de ilana naa gba `503` + `Retry-After: 5`. Tun aafo opin-ofo ti o ṣofo titi di igba ti rirọpo yoo Ti ṣetan maa wa jade kuro ni lile — ti o jẹ SQLite topology, kii ṣe ṣiṣapẹrẹ aṣiṣe.

Ita Postgres / olona-onkqwe HA ni** kii ṣe** ọna iṣura ti o ni akọsilẹ. Ti o ba nilo HA, tọju ajọra ẹyọkan tabi ṣiṣẹ topology ti iṣẹ akanṣe ti ni idanwo ati ti ṣe akọsilẹ lọtọ. Ise Postgres/MySQL n gbe ni [#8075](https://github.com/diegosouzapw/OmniRoute/issues/8075). Titi di awọn ọkọ oju omi yẹn, ọna atilẹyin nikan lati pọ si** nla** agbara `/v1/responses` jẹ awọn ilana ominira N (apakan atẹle), kii ṣe `replicas > 1` lori iwọn didun kan.

## Asekale-jade: N ominira lakọkọ

### Codex àmi iyipo nini

Awọn ẹda ti akọọlẹ Codex kan ko gbọdọ jẹ ni ominira lilo aami isọdọtun lilo ẹyọkan. Lori awọn iṣẹlẹ ti o jẹ awọn iwe-ẹri amuṣiṣẹpọ nikan, ṣeto `OMNIROUTE_TOKEN_REFRESH_PASSIVE_PROVIDERS=codex` (inagijẹ `cx`). Fi silẹ ni aifọwọyi lori oniyi iyipo ẹyọkan. Ilana kọọkan tun nilo `DATA_DIR` tirẹ; aṣayan yii ko pin SQLite tabi pese amuṣiṣẹpọ ami tabi titiipa pinpin.

Apeere palolo naa tun ka asopọ naa nigbati o nilo isọdọtun ati gba iyatọ nikan, ami iwọle ti ko pari. Bibẹẹkọ isọdọtun jẹ alaabo laisi ipari tabi mu asopọ ṣiṣẹ tabi kika ikuna isọdọtun. Awọn ikuna ifitonileti oke gidi tun lo iṣiro ikuna deede, itutu agbaiye ati aṣiṣe alabara deede; deactivation iroyin si maa wa yẹ. Muṣiṣẹpọ awọn ami yiyi ti oniwun ṣaaju ki awọn ami iraye si pari (asiwaju isọdọtun alafaramo aiyipada jẹ iṣẹju marun), tabi tun gbe faili Codex auth wọle. Awọn agbewọle agbewọle palolo tọju awọn ami ti a pese laisi ifọwọsi wọn ni aaye ipari ami. Afọwọṣe dashboard/API sọtun pada `409 refresh_disabled`; titun OAuth wiwọle ko yipada. Wo [itọkasi ayika](../reference/ENVIRONMENT.md#passive-codex-token-refresh).

Ilana Node kan jẹ** òkiti V8 kan** . Meji agbekọja ~ 3 MiB / ~ 750k-token ifaminsi-aṣoju `POST /v1/responses` (RTK + Caveman) abort ti okiti ni ~ 12 Gi (`FATAL ERROR: Reached heap limit`) ati ki o le OOM a 16 Gi akojọpọ. Wo [# #7849](https://github.com/diegosouzapw/OmniRoute/issues/7849). Wiwọn yẹn jẹ a** iranti-isuna** ikilọ, kii ṣe ọja lile-max ti meji ni igbakanna `/v1/responses`. Gbigbawọle iwiregbe iwuwo iwuwo jẹ titọ nipasẹ isuna-isuna ingest baiti ti a ṣe jade laifọwọyi (`OMNIROUTE_CHAT_MAX_INFLIGHT_BYTES`, `src/shared/middleware/admissionBudget.ts`) ti o ni iwọn lati oke V8/cgroup aja — ti o bori rẹ si oke (tabi ṣeto eto-ipamọ `OMNIROUTE_CHAT_MAX_HEAVY_IN_FLIGHT` ibeere-ka fila) lori ilana ti o ni iwọn tẹlẹ yoo tun bẹrẹ iṣẹyun naa. Awọn ibaraẹnisọrọ kekere, `/healthz`, `/v1/models`, ati MCP jẹ** kii ṣe** ninu fila yẹn.

### Ọkan-ilana: diẹ ẹ sii ju meji gun `/v1/responses`

A** ni ilera** ilana (òkiti ni isalẹ `OMNIROUTE_CHAT_ADMISSION_HEAP_SHED_RATIO`, aiyipada `0.75`)** le** ṣiṣe diẹ sii ju meji nigbakanna `POST /v1/responses` nigba ti ilana-jakejado inflight-baiti isuna (`OMNIROUTE_CHAT_MAX_INFLIGHT_BYTES` / #10110) si tun ni yara. Awọn ara ni tabi loke `OMNIROUTE_CHAT_LARGE_BODY_BYTES` (aiyipada 256 KiB) gba iyalo iwuwo iwuwo kanna gẹgẹbi awọn ibeere eto-eru ati lo ọna abayọ [#10437](https://github.com/diegosouzapw/OmniRoute/pull/10437) `tryAcquireHealthyHeadroom` kanna (`OMNIROUTE_CHAT_ADMISSION_HEALTHY_HEADROOM`). Awọn mewa ti awọn onibara SSE gigun nigbakanna (awọn oniṣẹ nigbagbogbo nilo 40-50) jẹ a** iranti-isuna** ibeere — iwọn òkiti + primary/headroom + `OMNIROUTE_CHAT_MAX_INFLIGHT_BYTES` — ko kan lile "max 2" ọja iye to. Okiti titẹ si tun ta silẹ pẹlu `503` ti a tun gbiyanju ki #7849 ko pada.

Si** isodipupo òkiti** (awọn aye atijọ V8 ominira)** loni** :

| Ṣe                                                                                                                                 | Maṣe ṣe                                           |
| ---------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| Ṣiṣe** N containers/pods** , kọọkan pẹlu awọn oniwe-** ti ara** `DATA_DIR` / iwọn didun                                            | Ṣeto `replicas > 1` lodi si faili SQLite kan      |
| Iwon eru ni-flight + ni ilera-headroom lati òkiti / inflight-baiti isuna; 1-2 jẹ aiyipada # #7849 Konsafetifu, kii ṣe max ọja lile | Fun ilana kan 8 × RAM ati fila kika ti ko ni opin |
| Yiyan: `QUOTA_STORE_DRIVER=redis` + `QUOTA_STORE_REDIS_URL` fun** pín ipin ounka**                                                 | Toju Redis bi pín SQLite — kii ṣe                 |
| Ṣe pidánpidán awọn aṣiri olupese sinu apẹẹrẹ kọọkan (tabi gba awọn dasibodu ti a pin)                                              | Reti dasibodu kan / ipe-ipe kan kọja awọn iṣẹlẹ   |
| Iwaju pẹlu eyikeyi fifuye iwọntunwọnsi; alalepo nipasẹ bọtini API tabi igba ti to                                                  | Beere ẹrọ agbedemeji onijaja kan pato iwọn-mọ     |

Ibaṣepọ-si-iroyin tun le pin nipasẹ Redis: ṣeto `OMNIROUTE_SESSION_AFFINITY_STORE=redis` ati `REDIS_URL` lori ilana kọọkan, pẹlu `REDIS_KEY_PREFIX` kanna ati eto `sessionAffinityTtlMs` rere kan. Awọn pinni yanju awọn idamọ lilo-iroyin hashed si asopọ agbegbe ti o yẹ fun ilana kọọkan, nitorinaa awọn akọọlẹ OAuth pẹlu metadata idanimo ti o baamu ko nilo asopọ IDs ti o baamu. Awọn idanimọ akọọlẹ ti a mọ ni iṣaaju lori ilodi si IDs agbegbe ni ipinnu pin ati itusilẹ idaabobo; awọn igbasilẹ laisi idanimọ (tabi awọn olupe ilekuro laisi idanimọ) ni idaduro ẹṣọ ID julọ. Awọn akọọlẹ laisi idanimọ lilo iduroṣinṣin tun nilo IDs ti o baamu. awọn aṣiṣe Redis tabi awọn ipe ti o ju 100 ms ṣubu pada si SQLite agbegbe. Ile-itaja ijora Redis kọọkan ni awọn iṣẹ ṣiṣe to dayato si ni 8, o kọja Redis lẹsẹkẹsẹ nigbati o ba kun, o si tu awọn iho silẹ nikan nigbati iṣẹ abẹlẹ ba yanju, kii ṣe ni akoko ipari olupe. Lakoko ijade Redis ko si otitọ pinpin: apẹẹrẹ kọọkan ṣubu si isunmọ agbegbe tirẹ, awọn akoko le tun pin lẹẹkan fun apẹẹrẹ, ati awọn iṣẹlẹ le yato. Lilepo tun-converges nipasẹ Redis nigbati o ba bọsipọ. Awọn aala akoko akoko idaduro, kii ṣe EVAL ti a firanṣẹ, eyiti o le de lẹhin isubu. Awọn kikọ ipa ọna ṣe afiwe iye deede ti a ṣe akiyesi nipasẹ ipinnu ipa-ọna, kii ṣe akoko iyipada-akoko tuntun ka; miss akiyesi tabi akiyesi fallback SQLite ṣe afiwe bi bọtini Redis ti ko si. Atijo pinni ti wa ni rọpo ninu ọkan CAS, ki a pẹ pipaṣẹ ko le ropo tabi pa a Opo, o yatọ si pin. Redis ka atomically da iye pada ati olupin ti o ku TTL; PTTL rere (tabi ko si ipari) pinnu igbesi aye, kii ṣe akoko JSON onkọwe tabi aago oluka. Awọn aworan aworan agbegbe ti o ku TTL si akoko ipari agbegbe; awọn bọtini JSON ti o wa tẹlẹ wa ni kika ati pe awọn baiti aise wọn wa ni idaduro fun CAS. Redis nikan ni orisun ti otitọ nigba ti o dahun. Awọn iṣagbega pinpin timo, awọn fọwọkan ati piparẹ kuro ni titẹsi agbegbe, ma fi sori ẹrọ tabi sọtun. SQLite lori ọna Redis nikan ni awọn ipinnu ifẹhinti ti ararẹ lati awọn aṣiṣe Redis, awọn akoko ipari tabi itẹlọrun gbigba, TTL-opin bi iṣaaju. Pinni agbegbe ti o nsọnu lori ijade nigbamii jẹ idiyele yiyan tuntun kan (apadanu kaṣe-kiakia kan), kii ṣe aṣiṣe tabi akọọlẹ jade kuro. Awọn iṣipopada ti a kọ silẹ da olubori ti o pin pada ati TTL to ku ni atomiki: yiyan lasan tun ṣayẹwo akoko ipari agbegbe ti o ya aworan ati lo olubori ti o yẹ laaye, lilo ifọwọkan ati wíwọlé fun akọọlẹ yẹn laisi kikọ pinpin miiran. Ti ko ba si, yiyan ntọju oludije agbegbe, fi PIN ti o pin silẹ ko yipada ati gbejade ifiranṣẹ yokokoro kan. CAS ti a kọ ko kọ SQLite; awọn aṣiṣe Redis, awọn akoko ipari tabi itẹlọrun gbigba wọle lo iṣẹ agbegbe ti o wa dipo. Ti idahun iyipada ti a fi ranṣẹ ba de lẹhin igbati akoko bati (gba, kọ tabi aṣiṣe), imuṣiṣẹpọ deede-iye serialized-afiwe-ati-paarẹ yọkuro nikan baiti-aami-ipin akoko isubu. Ko si idaduro laarin afiwe ati piparẹ naa; kikọ outage tuntun ti wa ni ipamọ. Iyọkuro ti o ni aabo yọkuro PIN ti agbegbe ti o kuna paapaa pẹlu Redis si isalẹ, o si sọ di mimọ lẹẹkansi lẹhin idasile pinpin pinpin. Ni isunmọtosi awọn idahun pinpin iṣaaju ko le mu pada pin agbegbe ti o jade kuro nitori awọn aṣeyọri pinpin ko kọ SQLite rara. A nigbamii outage fallback le repin ohun iroyin; kikọ pinpin ti o gba nigbamii wa nikan ni Redis. awọn padanu Redis ko ṣe kan si ipo idapada agbegbe. Pẹlu awakọ ti o wa ni pipa, awọn pinni tuntun ti a yan ni idaduro apẹrẹ aaye mẹrin SQLite JSON ; afisona Redis nikan ṣe afikun idanimọ hashed. Awọn pinni ti a ti ṣaju tẹlẹ jẹ ayẹwo ni opin opin ipari wọn. Redis yiyan ti kii ṣe iyalo tun ka ile itaja naa, ṣugbọn igbero yiyalo amuṣiṣẹpọ tun le lo PIN ti o jade laarin prefetch ati igbogun (winse igbiyanju ti o dara julọ ti o gba). Iwe adehun yiyalo ko le yi awọn akọọlẹ pada lẹhin ibeere ti o tọ: lori ifisilẹ ti a kọ silẹ o tọju oludije ti o beere fun ibeere yẹn nikan o fi olubori ti o pin silẹ laifọwọkan, nitorinaa adehun kọja awọn iṣẹlẹ jẹ opin si ọna yẹn. Awọn iyokù ti awọn tabili si tun kan: yi ko ni pin konbo igba stickiness, abinibi Codex tan pinni, semaphores iroyin, lockouts, na ifilelẹ, iṣeto ni tabi ipe àkọọlẹ.

Hardware: fun apẹẹrẹ nigbakanna gun `/v1/responses` jẹ a** iranti-isuna** ibeere (òkiti + inflight-baiti / # #10110). `N` ominira `DATA_DIR` s tun n pọ si awọn òkiti: alejo RAM gbọdọ bo `N × cgroup`, kii ṣe “ọkan 16 Gi pod pẹlu N = 8.” Maṣe `replicas > 1` rara lori faili SQLite kan.

Kọ apẹrẹ (òkiti meji, awọn ipele meji — kii ṣe `deploy.replicas: 2`):

```yaml
services:
  omniroute-a:
    image: diegosouzapw/omniroute:3.8.49
    environment:
      DATA_DIR: /app/data
      OMNIROUTE_MEMORY_MB: "12288"
      QUOTA_STORE_DRIVER: redis
      QUOTA_STORE_REDIS_URL: redis://redis:6379
    volumes: [omniroute-a-data:/app/data]
    ports: ["20128:20128"]
  omniroute-b:
    image: diegosouzapw/omniroute:3.8.49
    environment:
      DATA_DIR: /app/data
      OMNIROUTE_MEMORY_MB: "12288"
      QUOTA_STORE_DRIVER: redis
      QUOTA_STORE_REDIS_URL: redis://redis:6379
    volumes: [omniroute-b-data:/app/data]
    ports: ["20138:20128"]
volumes:
  omniroute-a-data:
  omniroute-b-data:
```

Ni-ilana iwuwo (funmorawon pa HTTP sọtọ) ni [# #11023](https://github.com/diegosouzapw/OmniRoute/issues/11023). Iṣupọ ọgbọn kan lori ipinlẹ ti o tọ pinpin jẹ [#8075](https://github.com/diegosouzapw/OmniRoute/issues/8075).

## Àwọn àṣìṣe ẹkùn Gemini nínú Docker

Google AI Studio / Gemini API lè dá HTTP 400 padà pẹ̀lú FAILED_PRECONDITION àti
`User location is not supported for the API use.` Ìbéèrè tó ṣàṣeyọrí lórí host
kò fi hàn pé container náà ń lo ipa-ọ̀nà àbájáde kan náà. Bí DNS ṣe to àwọn àbájáde lẹ́sẹẹsẹ,
àsopọ̀ IPv4/IPv6, ìtọ́sọ́nà VPN àti àwọn proxy tí a ti ṣètò lè yàtọ̀. Ṣàyẹ̀wò
[àwọn ẹkùn tí Google ń ṣe àtìlẹ́yìn fún](https://ai.google.dev/gemini-api/docs/available-regions)
pẹ̀lú ipa-ọ̀nà àsopọ̀ gangan; àṣìṣe yìí nìkan kò fi hàn pé API key náà kò dára.

### Yan proxy kan pàtó fún àsopọ̀

Lo [ètò proxy fún àsopọ̀ kọ̀ọ̀kan](../ops/PROXY_GUIDE.md#4-level-proxy-system) ti OmniRoute
fún àsopọ̀ Gemini tí ọ̀ràn náà kàn, lẹ́yìn náà tún **Test Connection** àti ìbéèrè kékeré kan ṣe
pẹ̀lú model kan náà. Èyí ń mú kí àyípadà ìtọ́sọ́nà náà mọ sí àsopọ̀ yẹn nìkan. Ṣàrídájú
pé container lè dé ọ̀dọ̀ proxy náà, àti pé àsopọ̀ náà yan án ní ti gidi.
Yíyí ipa-ọ̀nà padà kò ṣe ìdánilójú pé ẹkùn náà yẹ gẹ́gẹ́ bí upstream ṣe pinnu.

### Ṣe àfiwé nẹ́tíwọ́ọ̀kì host àti container

Jẹ́ kí key, model àti ìbéèrè jẹ́ ọ̀kan náà nígbà tí o bá ń fi àwọn àbájáde tí a ti fìdí ìdánimọ̀ múlẹ̀ wéra; má ṣe
fi credentials, ọ̀rọ̀ aṣínà proxy tàbí authorization headers kíkún sínú issue láé.
Kọ́kọ́ ṣàyẹ̀wò àwọn address families tí OS resolver ń pèsè, nípa lílo command kan náà
lórí host àti nínú container:

```bash
node -e 'require("node:dns").lookup("generativelanguage.googleapis.com", {all: true}, (error, addresses) => { if (error) { console.error(error.code); process.exitCode = 1; return; } console.log(addresses.map(({family}) => family)); })'
docker compose exec omniroute node -e 'require("node:dns").lookup("generativelanguage.googleapis.com", {all: true}, (error, addresses) => { if (error) { console.error(error.code); process.exitCode = 1; return; } console.log(addresses.map(({family}) => family)); })'
```

Rọ́pò `omniroute` pẹ̀lú service tí o ń ṣiṣẹ́ (fún àpẹẹrẹ, `omniroute-web`). Àwọn
command wọ̀nyí máa ń tẹ address families jáde láìsí credentials tàbí IP addresses. `6`
tí a dá padà fi àbájáde IPv6 DNS hàn nìkan: kò **fi ìdí rẹ̀ múlẹ̀** pé ipa-ọ̀nà IPv6 tó ṣeé lò tàbí ìráyè sí API wà.
Níbi tí a ti fi `curl` sí, fi `curl -4 -I https://generativelanguage.googleapis.com`
wé `curl -6 -I https://generativelanguage.googleapis.com` nínú àwọn àyíká méjèèjì.
Ìdáhùn HTTP fi hàn pé àsopọ̀ wà fún ìdánwò yẹn, kódà bí ó bá jẹ́ àṣìṣe
tí a kò fi ìdánimọ̀ múlẹ̀; ìbéèrè model tí a fi ìdánimọ̀ múlẹ̀ nìkan ló ń dán ìyẹ̀ Gemini wò.

### Àṣàyàn ìpele host: IPv6 tó ń ṣiṣẹ́ àti ìlànà resolver

Ẹni tó jabo [#12762](https://github.com/diegosouzapw/OmniRoute/issues/12762) mú
ìráyè padà bọ̀ sípò nínú àyíká wọn nípa ṣíṣe IPv6 container ṣiṣẹ́ àti yíyí bí glibc
ṣe ń yan address padà. Ka èyí sí àṣàyàn tó jẹ́ pàtó fún àyíká náà. Ṣàrídájú IPv6 host
tó ń ṣiṣẹ́, àbájáde/ìtọ́sọ́nà container àti àwọn òfin firewall kí o tó ṣàtúnṣe àwọn ààyò resolver.
Address ULA aládání kan nìkan kò fi ìdí àsopọ̀ IPv6 gbogbogbò múlẹ̀.

Fún àwọn service tí a ti so mọ́ default network ti Compose tẹ́lẹ̀, àjákù yìí ń mú
IPv6 ṣiṣẹ́ lórí network náà; pa ìyókù service, ports, volumes àti configuration rẹ mọ́:

```yaml
networks:
  default:
    enable_ipv6: true
```

Fún named network, mú un ṣiṣẹ́ lórí network tí service náà darapọ̀ mọ́ ní ti gidi. Docker lè
pín subnet ULA kan; yan subnet tó ṣe kedere, tí kò sì ní àgbélébùú pẹ̀lú òmíràn nígbà tí network rẹ
bá nílò rẹ̀ nìkan. Wo [Docker IPv6 networking](https://docs.docker.com/engine/daemon/ipv6/)
àti [Compose network options](https://docs.docker.com/reference/compose-file/networks/#enable_ipv6).

Lórí **image tó dá lórí glibc**, `/etc/gai.conf` lè yí bí a ṣe ń yan address padà. Dockerfile
repository lọ́wọ́lọ́wọ́ ń lo Debian; àwọn image àkànṣe tó dá lórí musl kò lo ọ̀nà yìí.
Àtúnṣe tí a jabo yí label ULA padà láti `label fc00::/7 6` sí
`label fc00::/7 1`. Bẹ̀rẹ̀ láti policy table kíkún ti image náà, kí o sì pa àwọn entry rẹ̀ yòókù mọ́:
fífi entry `label` tàbí `precedence` kún un máa rọ́pò default table yẹn, nítorí náà file
tó ní ìlà tí a yí padà nìkan kò tó.
[Àkọsílẹ̀ ìtọ́kasí configuration glibc](https://github.com/bminor/glibc/blob/master/posix/gai.conf)
ṣàlàyé àwọn ìlànà wọ̀nyẹn. Ṣe bind-mount file tí a ti ṣàyẹ̀wò gẹ́gẹ́ bí read-only sí `/etc/gai.conf`
kí o sì tún service náà dá láti fi àyípadà náà sílò.

Èyí ń yí bí OS ṣe ń yan address padà fún **gbogbo outbound traffic nínú container yẹn**.
Kò fipá mú gbogbo application láti yan IPv6: bí Node ṣe to DNS lẹ́sẹẹsẹ àti bí ó ṣe
ń yan àsopọ̀ tún ṣe pàtàkì. Ní pàtàkì, `--dns-result-order=ipv4first` fẹ́ràn IPv4 jù
kò sì jẹ́ ojútùú fún ìkùnà IPv4-nìkan. Wo [Node DNS ordering](https://nodejs.org/api/dns.html#dnssetdefaultresultorderorder).

Tún Gemini àti àwọn provider rẹ yòókù dán wò lẹ́yìn àyípadà èyíkéyìí ní ìpele host. Láti yí padà sí ti tẹ́lẹ̀,
yọ mount `gai.conf` àkànṣe náà kúrò, dá network configuration ti tẹ́lẹ̀ padà, kí o sì
tún service/network tí ọ̀ràn náà kàn dá ní àkókò maintenance window. Títún network kan dá
lè dá iṣẹ́ àwọn container mìíràn tí a so mọ́ ọn dúró; má ṣe pa persistent data volume rẹ́.

## Àwọn Àkíyèsí Pàtàkì

- **Ipo WAL SQLite:** Ó yẹ kí a jẹ́ kí `docker stop` parí kí OmniRoute lè ṣe checkpoint àwọn ìyípadà tuntun padà sínú `storage.sqlite`. Àwọn fáìlì Compose tí a ṣàkójọpọ̀ mọ́ ọn ti ṣètò àkókò ìdádúró-ọ̀fẹ́ sí 40s tẹ́lẹ̀. Tí o bá ń ṣiṣẹ́ image náà ní tààrà, fi `--stop-timeout 40` sílẹ̀.
- **`DISABLE_SQLITE_AUTO_BACKUP`:** Ṣètò rẹ̀ sí `true` tí a bá ń ṣàkóso àwọn backup àkókò-dé-àkókò/kíkọ-ṣáájú níta. Àwọn migration fún database tó ti wà ṣì nílò snapshot ààbò tó lágbára tiwọn àti guard fún mass-migration.
- **Ìtọ́jú Data:** Máa mount volume sí `/app/data` nígbà gbogbo láti tọ́jú database, àwọn key, àti àwọn configuration rẹ ní gbogbo ìgbà tí container bá tún bẹ̀rẹ̀.
- **Ìṣètò Port:** Ṣàtúnṣe environment variable `PORT` láti yí port àiyipada `20128` padà.
