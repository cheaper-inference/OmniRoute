Adehun `config/cli-tools-manifest.json` didoju ṣalaye IDs canonical, awọn inagijẹ, awọn oludije alakomeji, awọn ilana iṣeto, awọn ariyanjiyan awoṣe ati awọn agbara. Adaparọ Node pẹtẹlẹ ni `bin/cli/cli-manifest.mjs` ati ohun ti nmu badọgba TypeScript ni `src/shared/constants/cliIntegrationManifest.ts` ka faili kanna. Akoko ṣiṣe, katalogi, tunto, ipari, awọn olupilẹṣẹ ati iforukọsilẹ ẹhin ni a ṣayẹwo papọ nipasẹ `tests/unit/cli/cli-manifest-drift.test.ts`. Ti ṣe atokọ ko tumọ si pe irinṣẹ le ṣe ifilọlẹ tabi tunto. Ni pataki, 5dive maa wa ni atunto-nikan.

## Ayika ọmọde ati igbesi aye

`omniroute run`, `omniroute launch` ati `omniroute launch-codex` jogun akojọ iyọọda ibaramu OS/terminal ati ki o lọsi awọn iwe-ẹri ibi-afẹde ti o yan. Olupese ti ko ni ibatan ati awọn aṣiri aaye data ko ni jogun nipasẹ aiyipada. `--inherit-env` ṣe atunṣe ni kikun ogún ayika ti obi; lo nikan nigbati ilana ẹni-kẹta ti o yan yẹ ki o gba awọn iye wọnyẹn. Eyi jẹ sisẹ ayika, kii ṣe apoti iyanrin OS kan: ilana naa tun nṣiṣẹ pẹlu awọn igbanilaaye eto faili olupe.

Idilọwọ ati awọn ifihan agbara ifopinsi ti wa ni dari si omo. Ifilọlẹ n duro de iṣẹlẹ isunmọ ọmọde ṣaaju yiyọ iṣeto igba diẹ kuro. `OMNIROUTE_CHILD_SIGNAL_TIMEOUT_MS` n ṣakoso akoko oore-ọfẹ ṣaaju ifopinsi ifipabanilopo (aiyipada 5000 milliseconds).

## Gemini jubẹẹlo setup

```bash
omniroute setup-gemini --remote https://omni.example --model provider/model --yes
omniroute configure gemini --model provider/model --yes
omniroute run gemini --model provider/model --dry-run --json
```

Awọn aṣẹ meji akọkọ tunto ẹrọ yii fun agbegbe ti o yan tabi olupin latọna jijin. Iṣeto ṣe itọju awọn eto JSON ti ko ni ibatan, yan auth bọtini Gemini API, ati kọ aaye ipari ati iwe-ẹri si faili `.gemini/.env` ikọkọ. O kọ JSON ti ko tọ kuku ju kọkọ silẹ. Ipari URLs gbọdọ jẹ HTTP(S), laisi awọn iwe-ẹri ifibọ, awọn aye ibeere tabi awọn ajẹkù. Awọn ipa ọna titẹ-gbigbe, kii ṣe awọn iye ijẹrisi.

`GEMINI_CLI_HOME` tabi `--gemini-home` yan gbongbo ile ti o duro. Ohun gangan `run gemini` ṣẹda ati nigbamii yọ awọn oniwe-ara ibùgbé ile. Bẹni ipo ko kọja awọn sọwedowo igbẹkẹle aaye iṣẹ Gemini.

## Codex profaili

`configure codex` kọ `<name>.config.toml` ikọkọ pẹlu awoṣe kan ati aaye ipari olupese OmniRoute rẹ. Awọn iwe-ẹri jẹ itọkasi nipasẹ `OMNIROUTE_API_KEY`, ko fi sii rara. Aṣẹ ifilọlẹ ṣeto awoṣe ti o yan ni bọtini `model` ipele oke, kii ṣe inu `model_providers`.

Awọn faili profaili ọtọtọ jẹ iwe adehun Codex lọwọlọwọ; wọn bò iṣeto olumulo nigba ti a yan pẹlu `codex --profile <name>`. Wo [itọkasi profaili osise](https://learn.chatgpt.com/docs/config-file/config-advanced#profiles) ati [itọsọna OmniRoute Codex](./CODEX-CLI-CONFIGURATION.md).

## Hermetic pipaṣẹ

Pẹlu `DATA_DIR` ti o fojuhan, eto `OMNIROUTE_CLI_SKIP_DEFAULT_DATA_ENV=1` ṣe idilọwọ ibẹrẹ lati ja bo si agbegbe ijẹrisi data olumulo aiyipada. Eyi wulo fun awọn idanwo ti o ya sọtọ. Ko ṣe mu awọn faili ayika ti a yan ni gbangba.

## Ṣiṣẹ-liana `.env`

CLI naa ka awọn faili `.env` ni aṣẹ yii, ati pe faili akọkọ lati ṣeto bọtini kan bori: `DATA_DIR` ti o fojuhan, itọsọna data aiyipada, itọsọna iṣẹ lọwọlọwọ, lẹhinna itọsọna package. Awọn oniyipada ikarahun nigbagbogbo bori.

Itọsọna iṣẹ le jẹ ti ẹlomiran (ibi ipamọ ti cloned, ibi ipamọ ti ko ni idii), ati `omniroute serve` kọja agbegbe CLI si olupin ati si gbogbo ohun elo olupin naa nṣiṣẹ. Nitorina `.env` kan le ṣeto awọn bọtini wọnyi nikan, ti a ṣe akojọ si ni `bin/cli/utils/untrustedCwdEnv.mjs`:

| Bọtini                          | Awọn iye ti o gba                                                              |
| ------------------------------- | ------------------------------------------------------------------------------ |
| `REQUIRE_API_KEY`               | `true`, `1` tabi `yes` ni eyikeyi idiyele, awọn iye ti olupin ṣe itọju bi lori |
| `LANG`, `LC_ALL`, `LC_MESSAGES` | to awọn lẹta 64, awọn nọmba, `_`, `.`, `@` tabi `-`                            |
| `LANGUAGE`                      | kanna, plus `:`                                                                |
| `TZ`                            | to awọn lẹta 64, awọn nọmba, `_`, `+`, `-` tabi `/`, ko bẹrẹ pẹlu `/`          |
| `NO_COLOR`, `FORCE_COLOR`       | to 16 awọn lẹta ati awọn nọmba                                                 |

Gbogbo iye `REQUIRE_API_KEY` n gba sọwedowo si titan, nitorinaa faili ko le tan ayẹwo naa funrararẹ. Ko ṣe ipinnu abajade, botilẹjẹpe: olupin naa ka `REQUIRE_API_KEY` danu ti o fipamọ sinu aaye data ṣaaju agbegbe, lakoko ti ikilọ ibẹrẹ nipa gbigbọ lori gbogbo awọn atọkun laisi bọtini API kan ka agbegbe nikan. Pẹlu ifasilẹ ti `false` ti o fipamọ, ilana-itọnisọna `REQUIRE_API_KEY=true` fi API silẹ ni ṣiṣi ati fi ikilọ yẹn pamọ. Ilana `TZ` dín ju POSIX: o kọ `.`, `:`, `,` ati `<>`, nitorina fọọmu `:Area/City` ati awọn ofin gẹgẹbi `EST5EDT,M3.2.0,M11.1.0` ni lati ṣeto sinu ikarahun tabi ni `<DATA_DIR>/.env`.

Awọn orukọ gbọdọ baramu gangan, ni oke nla. Eyikeyi ila miiran, iye ti o kuna ayẹwo rẹ, ati orukọ ti kii ṣe awọn lẹta ASCII ti o han gbangba, awọn nọmba ati `_` (fun apẹẹrẹ ọkan pẹlu NUL baiti tabi lẹta ti o jọra) ti fo. CLI naa tẹjade ikilọ kan ti o darukọ awọn bọtini ti ko le ṣeto ati ọkan ti o jẹ orukọ awọn bọtini ti a gba laaye ti o kọju, ọkọọkan pẹlu kini kini lati yipada (`TZ (expected a zone name such as Europe/Berlin)`, `lang (write the name as LANG)`). Bẹni awọn titẹ sita awọn iye. Awọn ipa ọna faili ninu awọn ifiranṣẹ wọnyi, ati awọn ijabọ `.env` ọna `omniroute doctor`, salọ nigbati wọn ba ni iṣakoso tabi awọn ohun kikọ bidi ninu. Ihamọ naa ko lo nigbati itọsọna iṣẹ jẹ itọsọna data tabi itọsọna package.

`PORT`, `API_PORT` ati `DASHBOARD_PORT` ko si lori atokọ naa. Laisi ipilẹ URL lati orisun ti o ga julọ, CLI sọrọ si `localhost:<PORT>`, ati ohunkohun ti o gbọ nibẹ gba CLI's API bọtini, awọn ti o tọ token ati awọn CLI ẹrọ tokini (`x-omniroute-cli-token`, wo [CLI_TOKEN.md](../security/CLI_TOKEN.md) ), eyi ti olupin agbegbe gba fun awọn ipe iṣakoso lati loopback. Ibudo lati inu itọsọna iṣẹ yoo jẹ ki faili yẹn yan olutẹtisi, nitorinaa ṣeto awọn ebute oko oju omi inu ikarahun, ni `<DATA_DIR>/.env` tabi pẹlu aṣayan `--port` ti awọn aṣẹ ti o ni ọkan (`serve`, `launch`, `run`).

Awọn parser ko ni sintasi `export`. Laini bii `export LD_PRELOAD=...` lorukọ `export LD_PRELOAD` oniyipada; lati inu itọsọna iṣẹ o ti fo, ati ninu awọn faili `.env` miiran o ṣeto orukọ gangan yẹn, eyiti ko si nkankan ti o ka.

CLI naa so ami-ipamọ ọrọ-ọrọ kan pọ (aami-iwọle tabi bọtini API julọ) nikan pẹlu ipilẹṣẹ ọrọ-ọrọ yẹn: ero, agbalejo ati ibudo, ni akawe bi `URL.origin`. Eyi kan si awọn ibeere ti a ṣe nipasẹ alabara CLI's HTTP (`--base-url`, `OMNIROUTE_BASE_URL`, `omniroute connect <new-url>`) ati si awọn aṣẹ `launch`, `launch codex`, `configure` ati `setup-*` ti o kọ URL ipilẹ ati bọtini sinu atunto irinṣẹ miiran. Ti tọka si olupin miiran pẹlu `--remote`, wọn lo `--api-key` tabi `OMNIROUTE_API_KEY` ti o fojuhan ti ọkan ba ṣeto, ko si si ami-ọrọ ipo. Ifiwera naa jẹ deede, nitorinaa `localhost` ati `127.0.0.1`, tabi agbalejo kan pẹlu laisi aami itọpa, ka bi awọn olupin oriṣiriṣi ko si gba ami-ọrọ ipo. A URL pẹlu userinfo, ifẹhinti ẹhin tabi aaye funfun ko baramu, nitori awọn parsers URL miiran (Python's `urllib` ati `httpx`, fun apẹẹrẹ) le ka ogun ti o yatọ lati ọdọ rẹ. Fun awọn ibeere CLI fi ararẹ ranṣẹ, ayẹwo naa ni wiwa ero ati aṣẹ nikan, nitorinaa id pẹlu aaye kan ni ọna tabi ibeere n tọju ami naa.
