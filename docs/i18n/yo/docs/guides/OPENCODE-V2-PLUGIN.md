`@omniroute/opencode-plugin-v2` ń fi gbogbo àkójọ OmniRoute rẹ — àwọn awoṣe, àwọn àkójọpọ̀ àti
àwọn àkójọpọ̀ aládàáṣe — sínú olùyan awoṣe OpenCode v2, pẹ̀lú àwọn orúkọ àfihàn, iye owó àti
àwọn ìwọ̀n ìlò ọ̀fẹ́.

Ó jẹ́ package ọ̀tọ̀ sí `@omniroute/opencode-plugin` nítorí OpenCode v1 àti v2 ń gbé
àwọn plugin wọlé nípasẹ̀ àwọn àdéhùn tó yàtọ̀. Yan èyí tó bá ẹ̀dà pàtàkì OpenCode rẹ mu; kò sí
ohun tí wọ́n pín láàárín wọn, nítorí náà ṣíṣe ìgbésókè ọ̀kan kì í fipá mú ìgbésókè èkejì.

## Àwọn ohun tí a nílò

- OpenCode v2.
- Gateway OmniRoute tí a lè dé sí (`http://localhost:20128` nípa àìyípadà).
- Node.js 22 tàbí 24.

## Fífì sínú ẹ̀rọ

Fi plugin náà kún `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

Lẹ́yìn náà, àwọn awoṣe yóò hàn bí `omniroute/<provider>/<model>`; `providerId` ló ń pinnu ìṣáájú yẹn àti
id ìṣọ̀kan tí OpenCode fi ń tọ́jú ẹ̀rí ìwọlé náà.

## Àwọn ẹ̀rí ìwọlé

Plugin náà ń wá kọ́kọ́rọ́ gateway ní ibi mẹ́ta, ní ìtòlẹ́sẹẹsẹ yìí:

1. **Ẹ̀rí ìwọlé tí o so pọ̀ nínú OpenCode.** Plugin náà ń forúkọ ìṣọ̀kan kan sílẹ̀, kí
   ìṣàn ìfàṣẹsí ti OpenCode fúnra rẹ̀ lè tọ́jú kọ́kọ́rọ́ náà. Kò sí ohun tó wọ inú `opencode.json` — èyí ló yẹ kí o yàn.
2. `apiKey` nínú àwọn àṣàyàn plugin, fún ìyípadà pàtó fún iṣẹ́-àkànṣe kan. Èyí ń fi kọ́kọ́rọ́ náà sínú fáìlì kan tí
   o lè máa commit.
3. `OMNIROUTE_API_KEY` nínú àyíká.

Tí kò bá sí ọ̀kan nínú àwọn mẹ́tẹ̀ẹ̀ta, àkójọ náà yóò ṣófo, plugin náà yóò sì sọ bẹ́ẹ̀ lẹ́ẹ̀kan nígbà ìbẹ̀rẹ̀ dípò
kí ó fi olùyan tó ṣófo sílẹ̀ láìsí ìkìlọ̀.

### Token ìṣàkóso jẹ́ kọ́kọ́rọ́ mìíràn

Àwọn àkójọpọ̀, ìlera provider àti ìmúdára (àwọn orúkọ àfihàn, iye owó, àti àwọn ìwọ̀n ìlò ọ̀fẹ́) ń wá láti
àwọn endpoint `/api/*` ti gateway, èyí tí ọ̀pọ̀ deployment ń dáàbò bo pẹ̀lú token **ìṣàkóso**
dípò kọ́kọ́rọ́ inference:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<management read token>"
}
```

Tí a kò bá ṣètò rẹ̀, `managementReadToken` yóò lo `apiKey` gẹ́gẹ́ bí àṣàyàn ìpadà. Nígbà tí gateway kan bá kọ àṣàyàn ìpadà yẹn,
àkójọ náà ṣì máa jáde, ṣùgbọ́n yóò lo àwọn id awoṣe gidi dípò àwọn orúkọ àfihàn, kò ní ṣe
ìmúkúrò àwọn alias canonical tó ṣe àdáwòkọ, kò ní iye owó, kò sì ní àwọn àkójọpọ̀. Plugin náà máa ń kìlọ̀ lẹ́ẹ̀kan fún endpoint kọ̀ọ̀kan nígbà tí èyí bá ṣẹlẹ̀,
yóò sì dárúkọ endpoint náà àti ohun tí ó sọnù — nítorí náà olùyan tó dín agbára kù kì yóò jẹ́ àdììtú láé.

## Bawo ni katalogi duro alabapade

Awọn katalogi ti wa ni mu ọlẹ ati ki o cache fun `modelCacheTtlMs`, ati ki o kan disk fọtoyiya ntọju awọn ti o kẹhin mọ katalogi wa nigba ti ẹnu-ọna ni unreachable — ohun outage owo ti o nkankan sugbon freshness. Awọn awoṣe ati awọn combos ti wa ni atẹjade ni kete ti wọn ba de; auto-combos, awọn olupese akojọ ati awọn afikun agbekọja agbo ni nigba ti won de, ki ọkan lọra endpoint ko le mu gbogbo picker idimu.

Awọn orukọ tẹle `Provider - Model[ (Editor)][ · budget][ (route)]`: Olupese yoo han nigbakugba ti id ba gbe ọkan (id slash-less is renders without prefix), `🆓` asiwaju kan samisi awọn titẹ sii ọfẹ ati pe eto isuna-ọfẹ wọn duro bi suffix `· 1M tokens/month`, olootu orukọ `Editor: Model` ti o fojuhan gbe lọ si itọpa itọpa (ko si olootu ti a gboju laisi awọn orukọ ọfẹ) ati `combo - <slug>` Awọn titẹ sii meji ti o pin orukọ kan gba suffix ipa ọna — `(no-think)` — ki wọn wa ni iyatọ. `providerTag` (aiyipada `true`) yi akọmọ olootu itọpa pada.

Ko si aṣẹ isọdọtun afọwọṣe: awọn aṣẹ OpenCode v2 jẹ awọn awoṣe kiakia, kii ṣe awọn ipe pada, nitorinaa ohun itanna ko le fi ọkan han. Awọn isọdọtun tẹle TTL; A beere lọwọ agbalejo lati tun gbejade nikan nigbati katalogi tabi agbekọja ba yipada nitootọ, kii ṣe lẹẹkan fun isọdọtun.

## Pípe irinṣẹ́ lórí Gemini

Gemini máa ń kọ gbogbo ìbéèrè tí àwọn ìkéde irinṣẹ́ rẹ̀ ní `$schema` tàbí
`additionalProperties`, yóò sì dáhùn pẹ̀lú `400 INVALID_ARGUMENT`. Plugin náà máa ń yọ àwọn ọ̀rọ̀ pàtàkì wọ̀nyẹn kúrò nínú
àwọn schema irinṣẹ́ tí a ń fi ránṣẹ́ sí àwòṣe Gemini ti olùpèsè yìí, kò sì ní fọwọ́ kan gbogbo ìbéèrè yòókù.
A máa ń fi irinṣẹ́ tí ó ní `$ref` ránṣẹ́ láìfọwọ́ kàn án dípò kí a yọ nǹkan kúrò nínú rẹ̀, nítorí pé yíyọ
ìtọ́kasí náà kúrò yóò mú kí schema náà gbòòrò sí “gba ohunkóhun”.
Ṣètò `"geminiSanitization": false` láti pa á.
