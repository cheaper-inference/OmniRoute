Node JSON API aṣa kan so aaye ipari iṣowo JSON ti ko sọ ilana OpenAI tabi Anthropic. OmniRoute fọwọsi awoṣe ibeere JSON kan, firanṣẹ si ipari ipari URL, ka esi lati ọna esi ati da pada si alabara ni ọna kika ti alabara (Awọn Iwiregbe Ipari, Awọn idahun, Awọn ifiranṣẹ,…).

O jẹ oju ipade OpenAI-ibaramu pẹlu `apiType: "custom-json"`; id rẹ ni fọọmu `openai-compatible-custom-json-<suffix>`. Fọọmu dasibodu ko si sibẹsibẹ. Ṣẹda ati ṣatunkọ awọn apa wọnyi nipasẹ olupese-node API ni isalẹ.

## Ṣẹda ipade kan

`POST /api/provider-nodes` (Aṣẹ iṣakoso):

```json
{
  "type": "openai-compatible",
  "apiType": "custom-json",
  "name": "Business API",
  "prefix": "biz",
  "baseUrl": "https://api.example.com/v1/answer",
  "customHeaders": { "X-Tenant": "demo" },
  "customJson": {
    "method": "POST",
    "authType": "api-key",
    "authHeader": "X-Service-Key",
    "requestTemplate": {
      "project_id": "demo-project",
      "question": "{{prompt}}",
      "history": "{{messages}}"
    },
    "responsePath": "data.answer"
  }
}
```

- `baseUrl` ni** pari** ipari URL. Ko si ohun ti a fikun (ko si `/chat/completions`, ko si `/models`) ati, ko dabi awọn apa ibaramu OpenAI miiran, ko si URL aiyipada. O gbọdọ jẹ `http(s)`, laisi awọn iwe-ẹri ifibọ tabi `#fragment` kan, ati pe o kọja ẹṣọ URL ti njade kanna bi gbogbo ipade olupese, mejeeji nigbati ipade ti wa ni fipamọ ati lori gbogbo ibeere.
- Ipade ti o firanṣẹ bọtini asopọ (`authType` `bearer` tabi `api-key`, pẹlu aiyipada) gbọdọ lo `https://`. A gba `http://` pẹtẹlẹ nikan fun agbalejo loopback (`localhost`, `127.0.0.0/8`, `::1`) tabi pẹlu `authType: "none"`, eyiti ko fi bọtini ranṣẹ. Awọn adirẹsi LAN aladani (`10.x`, `172.16-31.x`, `192.168.x`) ko ni idasilẹ: ẹnikẹni ti o wa lori nẹtiwọki yẹn le ka bọtini naa. Fifipamọ iru ipade kan kuna pẹlu `400`, ati ipade ti o ti fipamọ tẹlẹ kuna ni pipade lori gbogbo ibeere pẹlu ifiranṣẹ kanna, ṣaaju fifiranṣẹ eyikeyi ibeere. Fun aaye ipari bọtini kan lori LAN, fi sii lẹhin TLS (fun apẹẹrẹ aṣoju yiyipada).
- `customJson` jẹ ifọwọsi pẹlu Zod; aimọ bọtini ti wa ni kọ. Gbogbo aaye jẹ iyan:

| Aaye              | Awọn iye                            | Aiyipada                                               |
| ----------------- | ----------------------------------- | ------------------------------------------------------ |
| `method`          | `POST`, `PUT`, `PATCH`              | `POST`                                                 |
| `authType`        | `bearer`, `api-key`, `none`         | `bearer`                                               |
| `authHeader`      | akọsori orukọ lo nigba ti `api-key` | `X-API-Key`                                            |
| `requestTemplate` | ohun JSON (≤ 64 KB, ijinle ≤ 32)    | `{ "model": "{{model}}", "messages": "{{messages}}" }` |
| `responsePath`    | ona oko, tabi `$` fun gbogbo ara    | `choices[0].message.content`                           |

- Aṣiri duro ni bọtini API asopọ, rara ninu awoṣe. `bearer` rán `Authorization: Bearer <key>`; `api-key` rán `<authHeader>: <key>`. Akọsori auth ko le jẹ `Host`, `Content-Type`, `Content-Length`, `Connection`, `Transfer-Encoding`, `Authorization`, `Cookie` tabi akọsori hop-nipasẹ-hop. Pẹlu `none`, awọn asopọ ko nilo bọtini.
- Awọn akọsori aimi ni afikun lo `customHeaders` deede ipade (ifọwọsi kanna gẹgẹbi gbogbo ipade ibaramu; awọn akọle auth ko gba laaye nibẹ).

`PUT /api/provider-nodes/<id>` gba `customJson` kanna ati tunkọ `baseUrl` ati atunto lori gbogbo asopọ ti o wa tẹlẹ ti ipade naa. Omitting `customJson` ntọju konfigi ti o fipamọ; yiyipada `apiType` si `chat` tabi `responses` yọ kuro lati oju ipade ati awọn asopọ rẹ.

Lẹhinna ṣafikun asopọ si ipade bi igbagbogbo (`POST /api/providers` pẹlu id node) ati beere `<prefix>/<model>`, fun apẹẹrẹ `biz/assistant-v1`. Ipari ipari ko ṣafihan atokọ awoṣe, nitorinaa ṣafikun ids awoṣe pẹlu ọwọ.

## Beere awọn awoṣe

Awọn awoṣe jẹ JSON lasan. Iye okun le ni awọn asami `{{placeholder}}` ninu; Ko si ohun ti a ṣe ayẹwo tabi ṣiṣẹ, ati awọn bọtini ohun ko ni rọpo rara.

| Ibi ipamọ            | Iye                                                                               |
| -------------------- | --------------------------------------------------------------------------------- |
| `{{prompt}}`         | Ọrọ ti ifiranṣẹ olumulo tuntun (awọn apakan ọrọ ti o darapọ mọ awọn laini tuntun) |
| `{{messages}}`       | Ibaraẹnisọrọ ni ọna kika iwiregbe OpenAI                                          |
| `{{model}}`          | ID awoṣe ti o beere, laisi ìpele olupese                                          |
| `{{stream}}`         | Nigbagbogbo `false` — awọn idahun ipari ipari pẹlu iwe JSON kan                   |
| `{{request.<path>}}` | Aaye ti ibeere ti itumọ ( ọna kika iwiregbe OpenAI ).                             |

- Iye kan ti o jẹ ipo ibi kan pato tọju iru JSON rẹ (`"{{messages}}"` di opo); ibi ipamọ inu okun to gun ni a fi sii bi ọrọ.
- Ibi ipamọ ti o pinnu si ohunkohun kuna ibeere naa pẹlu HTTP 400 dipo fifiranṣẹ fifuye isanwo ti ko pe.
- Awọn ipa ọna lo aami aami ati awọn atọka nọmba (`data.items[0].text`). `__proto__`, `prototype` ati `constructor` jẹ kọ ni awọn bọtini ati awọn ọna.

## Awọn idahun

Iye ni `responsePath` di idahun oluranlọwọ: awọn okun kọja, awọn iye JSON miiran ti wa ni lẹsẹsẹ. Aaye ti o padanu tabi `null`, tabi ara ti kii ṣe JSON, pada HTTP 502. Awọn ipo aṣiṣe ti oke ti kọja nipasẹ. Fun awọn alabara ṣiṣanwọle OmniRoute n duro de gbogbo idahun JSON ati lẹhinna gbejade bi chunk akoonu kan pẹlu ipari ipari; eyi kii ṣe ṣiṣanwọle àmi. Awọn ipe irinṣẹ ati awọn aaye lilo ko ṣe ya aworan.

## Ko tun ṣe

Ibeere iṣowo le ni awọn ipa ẹgbẹ paapaa nigbati o ba kuna. OmniRoute nitorina o fi ranṣẹ lẹẹkan:

- ko si atunda gbigbe ko si si àtúnjúwe wọnyi;
- ko si tun gbiyanju lori miiran asopọ (iroyin fallback) — ikuna ti wa ni pada bi-jẹ ati awọn asopọ ti wa ni ko tutu si isalẹ;
- ko si ipadabọ si ibi-afẹde konbo atẹle, paapaa fun idahun ofo tabi kuna.

Awọn ibeere alabara lọtọ, ati awọn panẹli idapọ ti o pe awọn awoṣe lọpọlọpọ, tun pe aaye ipari ni ominira.

## Idanwo ipade kan

Nfipamọ asopọ, asopọ** Idanwo** bọtini ati isale ilera sọwedowo kò pe awọn endpoint: nwọn nikan sooto awọn ti o ti fipamọ konfigi ati jabo asopọ bi ko verifiable.

`POST /api/provider-nodes/validate` pẹlu `"apiType": "custom-json"` ati awọn aaye ipade (`baseUrl`, `apiKey`, `customJson`, `customHeaders` iyan ati `modelId`) firanṣẹ ibeere gidi kan gangan, pẹlu `ping` gẹgẹbi ọrọ olumulo tuntun. O dahun `{ "valid": true }` tabi ipo oke (ko si ara ti oke).

## Ibi ipamọ

Atunto naa wa ni ipamọ ni `provider_nodes.custom_json_config_json` (migration `240_provider_node_custom_json_config.sql`) ati daakọ sinu `providerSpecificData.customJson` asopọ kọọkan.

Imuse: `open-sse/utils/customJson.ts` (afọwọsi ati awoṣe), `open-sse/executors/customJson.ts` (oluṣeto), `open-sse/services/combo/noReplayLatch.ts` ati `src/sse/handlers/chat/responsePolicies.ts` (ko si atunṣe).
