## Ohun tí ó jẹ́ (àti ohun tí kì í ṣe)

OmniRoute ń yan iye owó USD fún ìbéèrè kọ̀ọ̀kan sí gbogbo ìparí nípa sísọ iye àwọn token
di púpọ̀ mọ́ iye owó awoṣe kan. Àwọn nọ́mbà wọ̀nyí ni ó ń pèsè agbára fún dásíbọ́ọ̀dù **Àwọn Iye Owó**,
CLI `omniroute cost` / `omniroute usage`, àwọn ìkójáde CSV/JSON, àti àwọn ìnáwó tí a yàn fún kọ́kọ́rọ́ API kọ̀ọ̀kan.

> **“Iye owó” orí dásíbọ́ọ̀dù jẹ́ olùtọpinpin owó tí a fipamọ́, kì í ṣe owó tí a ń jẹ ọ́.** OmniRoute kò gba owó lọ́wọ́ rẹ rí
> — ó ń darí àwọn ìbéèrè rẹ sí àwọn olupèsè tí o ti sopọ̀ tẹ́lẹ̀ (àwọn
> ìforúkọsílẹ̀ tìrẹ, àwọn ìpele ọ̀fẹ́, àti àwọn kọ́kọ́rọ́ API). “Àpapọ̀ iye owó $290” tí ó kójọ lórí àwọn
> awoṣe ọ̀fẹ́ nìkan túmọ̀ sí pé ó fẹ́rẹ̀ẹ́ jẹ́ **$290 tí o _kò_ san** fún API olówó. Iye yìí jẹ́ _ìṣírò_
> ohun tí irú ìrìnàjò kan náà ì bá ná ní àwọn iye owó àtòjọ boṣewa, kí o lè rí ibi tí
> lílò rẹ pọ̀ sí jù àti iye owó tí yíyan àwọn olupèsè tí kò gbowó tàbí tí wọ́n jẹ́ ọ̀fẹ́ ń fipamọ́ fún ọ.

A sọ ìtumọ̀ yìí ní tààrà nínú [README](../../README.md) iṣẹ́ náà (“‘iye owó’ orí dásíbọ́ọ̀dù
jẹ́ olùtọpinpin owó tí a fipamọ́, kì í ṣe owó tí a ń jẹ ọ́”).

Nítorí pé nọ́mbà náà jẹ́ ìṣírò:

- Ó sinmi lórí tábìlì iye owó tí OmniRoute ní fún awoṣe kọ̀ọ̀kan. Awoṣe tí kò ní àkọsílẹ̀
  iye owó ń ṣàfikún iye owó `0` (ó máa ń hàn gẹ́gẹ́ bí ìlà “Àtijọ́ / Ọ̀fẹ́” nínú olùṣàwárí).
- Ìrìnàjò ìpele ọ̀fẹ́ àti ti ìforúkọsílẹ̀ ṣì ń kó iye owó _ìṣírò_ jọ — iye
  tí o ń fipamọ́ ni, kì í ṣe iye tí o jẹ.

## Bawo ni iye owo ti wa ni ifoju

### Orisun idiyele

Awọn idiyele wa lati tabili idiyele ti a dapọ ni [`src/lib/db/settings/pricing.ts`](../../src/lib/db/settings/pricing.ts), ni aṣẹ iṣaaju yii (** ti o ga julọ akọkọ** ):

1. **Olumulo dojuiwọn** awọn idiyele — ṣeto sinu dasibodu tabi nipasẹ `PATCH /api/pricing` (aaye orukọ `pricing` ).
2. **modeli.dev ìsiṣẹpọ** idiyele — ti a mu lati `https://models.dev/api.json` (aaye orukọ `models_dev_pricing` ).
3. **LiteLLM ìsiṣẹpọ** awọn idiyele — ti a mu lati LiteLLM ti gbogbo eniyan `model_prices_and_context_window.json` (aaye orukọ `pricing_synced` ).
4. **Hardcoded aseku** awọn oṣuwọn — ti a firanṣẹ ni [`src/shared/constants/pricing/`](../../src/shared/constants/pricing/).

Fun provider/model kanna, awọn iye lati awọn ipele ti o ni ayo ti o ga julọ ṣe atunkọ awọn aaye ti o baamu ni awọn ipele kekere; Awọn aaye ti ko si lati ipele oke le tun wa lati ipele kekere kan. Ilana naa wa titi paapaa nigbati awọn iṣẹ amuṣiṣẹpọ ominira mejeeji ṣiṣẹ ni akoko kanna. `GET /api/pricing?includeSources=1` da `pricing` ati `sourceMap` pada, eyiti awọn aami apẹrẹ fun-kọọkan (`user`, `modelsDev`, `litellm`, `default`) ṣe idanimọ Layer pataki-pataki ti o ni awoṣe yẹn.

**LiteLLM ìsiṣẹpọ** ti wa ni ijade, alaabo nipasẹ aiyipada. Awọn oniyipada ayika rẹ (wo [`.env.example`](../../.env.example) ) jẹ:

| Env var                 | Aiyipada  | Idi                                                                          |
| ----------------------- | --------- | ---------------------------------------------------------------------------- |
| `PRICING_SYNC_ENABLED`  | `false`   | Jeki ìsiṣẹpọ ifowoleri LiteLLM abẹlẹ.                                        |
| `PRICING_SYNC_INTERVAL` | `86400`   | Aago amuṣiṣẹpọ ni iṣẹju-aaya (ojoojumọ).                                     |
| `PRICING_SYNC_SOURCES`  | `litellm` | Aṣayan orisun fun amuṣiṣẹpọ yii nikan; Lọwọlọwọ `litellm` nikan ni atilẹyin. |

**modeli.dev ìsiṣẹpọ** yato si ìsiṣẹpọ LiteLLM ati pe o tun jẹ alaabo nipasẹ aiyipada. Mu ṣiṣẹ ni Eto (models.dev sync) tabi lo awọn oniyipada wọnyi:

| Env var                    | Aiyipada       | Idi                                                                                                                              |
| -------------------------- | -------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `MODELS_DEV_SYNC_ENABLED`  | _(a ko ṣeto) _ | Unset telẹ awọn Eto toggle; `1/true/on/yes` fi agbara mu ati ki o fi agbara mu `0/false/off/no` (paapaa ti Eto ba jẹ ki o ṣiṣẹ). |
| `MODELS_DEV_SYNC_INTERVAL` | `86400`        | Default model.dev sync aarin ni iṣẹju-aaya (ojoojumọ).                                                                           |

`PRICING_SYNC_SOURCES` ṣe** kii ṣe** jeki awọn modeli.dev; o nṣakoso ìsiṣẹpọ LiteLLM nikan. Piparẹ ifasilẹ olumulo kan ko ṣe ko boya aaye orukọ ti a muṣiṣẹpọ; Layer ifowoleri ti o wa atẹle yoo munadoko. Fun awoṣe ti ko ni idiyele, ṣayẹwo mejeeji awọn eto amuṣiṣẹpọ ati `sourceMap` ṣaaju ki o to ṣafikun ifasilẹ afọwọṣe kan.

### Ilana idiyele

A ṣe iṣiro idiyele fun ibeere lati awọn iṣiro ami-ami ati awọn oṣuwọn ami-miliọnu kan ni [`src/lib/usage/costCalculator.ts`](../../src/lib/usage/costCalculator.ts) (`computeCostFromPricing` / `calculateCost`):

- **Awọn ami igbewọle** (iyokuro kaṣe kika ati awọn ami idasile-ẹda) oṣuwọn × `input`.
- **Kaṣe-ka àmi** oṣuwọn × `cached` (ṣubu pada si iwọn titẹ sii).
- **Kaṣe-ẹda àmi** oṣuwọn × `cache_creation` (ṣubu pada si iwọn titẹ sii).
- **Awọn ami ijade** × `output` oṣuwọn.
- **Awọn ami idi** × `reasoning` oṣuwọn (ṣubu pada si awọn ti o wu oṣuwọn).

Gbogbo awọn oṣuwọn ni a tumọ bi USD fun awọn ami-ami 1,000,000. A Codex "yara"/" ayo" tabi "flex" ipele iṣẹ kan kan iye owo isodipupo (`getCodexFastCostMultiplier`) — fun apẹẹrẹ Flex ti wa ni idiyele ni ẹdinwo ami ami 50%, ti o farahan bi** Flex ifowopamọ** ninu Dasibodu.

Awọn orukọ awoṣe jẹ deede ni akọkọ (awọn ami-iṣaaju ti olupese-ọna bii `openai/` tabi `accounts/fireworks/models/` ti yọ kuro) nitorina awọn ila itan tun baamu idiyele kan.

### Bawo ni na ti wa ni gba silẹ

- Iye idiyele ibeere-kọọkan jẹ iṣiro ni ipari ibeere. Lilo ipin-pin jẹ eto lori ami iṣẹlẹ-lupu atẹle nipasẹ [`src/lib/quota/spendRecorder.ts`](../../src/lib/quota/spendRecorder.ts).
- Awọn inawo bọtini API jẹ ifipamọ ati ki o ṣan ni awọn ipele nipasẹ [`SpendBatchWriter`](../../src/lib/spend/batchWriter.ts) (aiyipada 60s aarin, ifipamọ-iwọle 1,000). Tunṣe nipasẹ:

  | Env var                             | Aiyipada | Idi                                       |
  | ----------------------------------- | -------- | ----------------------------------------- |
  | `OMNIROUTE_SPEND_FLUSH_INTERVAL_MS` | `60000`  | Fọ aarin ni milliseconds.                 |
  | `OMNIROUTE_SPEND_MAX_BUFFER_SIZE`   | `1000`   | Awọn titẹ sii ti o pọju ṣaaju ki o to fọ. |

Awọn idiyele fẹran idiyele ti olupese ti o royin (`provider_cost_usd`), lẹhinna fọto-ibeere ti o ni idiyele katalogi (`calculated_cost_usd`), lẹhinna atunṣe ami-ami lati katalogi lọwọlọwọ. Awọn idiyele ti o fipamọ ko ni idiyele lẹẹkansi nipasẹ awọn iṣiro ami-ami wọn. Legacy tokini-awọn ori ila nikan tun yipada nigbati idiyele katalogi wọn yipada.

### OCR ati awọn ifibọ

- Awọn ibeere `/v1/ocr` ti o ṣaṣeyọri lo `usage_info.pages_processed` oke, kii ṣe iwọn oju-iwe ti o beere tabi nọmba awọn nkan oju-iwe ti o pada. Iṣiro naa jẹ awọn oju-iwe × `ocr_cost_per_page` ( USD/page pipe,** kii ṣe** USD/million).
- Awọn ibeere pẹlu iwe-ipamọ tabi awọn asọye apoti-isopọ nilo idiyele `ocr_cost_per_annotated_page` lọtọ. Laisi rẹ, iye owo wa aimọ; Tarifu OCR lasan ko ni firọpo dakẹ.
- LiteLLM muṣiṣẹpọ awọn maapu aaye `annotation_cost_per_page` oke rẹ sinu `ocr_cost_per_annotated_page`, ni idaduro iye USD/page pipe ati awọn titẹ sii-akọsilẹ nikan, pẹlu odo ti o fojuhan. Aaye canonical ti a pese gba iṣaaju; awọn iye inagijẹ ti ko tọ ko bikita. Ifowoleri olumulo dojuiwọn ni idaduro pataki deede wọn. Wo [awọn bọtini idiyele LiteLLM's OCR](https://docs.litellm.ai/docs/providers/mistral_batches#batch-ocr-cost-tracking).
- lilo OCR tọju kika oju-iwe naa, idiyele ẹyọkan, idiyele USD iṣiro, bọtini API ati asopọ ti o yan. Awọn oju-iwe ko ni ipoduduro bi awọn ami-ami. Awọn akọọlẹ ipe ni metadata ìdíyelé, kii ṣe iwe URLs, PDF baiti tabi ọrọ ti a fa jade.
- Awọn ibeere `/v1/embeddings` ti o ṣaṣeyọri ṣe igbasilẹ laini lilo kan fun ipele ti ara, pẹlu awọn ipele lọtọ ti o pari ni millisecond kanna. Awọn idiyele ti o royin olupese jẹ iṣaaju lori awọn iṣiro ami; konbo wrappers ko fi kan idiyele.
- Itan-akọọlẹ lilo, awọn atupale Awọn idiyele, awọn window provider/account, awọn opin inawo bọtini API, iwe-ipamọ idiyele-ibere ati awọn iyipo lilo ojoojumọ pẹlu awọn idiyele wọnyi. Awọn bọtini iforukọsilẹ ko si ṣe idaduro iṣiro nọmba laisi idaduro ọrọ orisun.
- Sonu lilo tabi owo-ori jẹ** aimọ** , kii ṣe ọfẹ: akọsori idiyele idiyele ti yọkuro, ati pe eto imulo lilo-ailopin ti o wa tẹlẹ kan awọn bọtini API to lopin. Awọn oṣuwọn odo ti a tunto ni gbangba jẹ lilo iye owo odo to wulo.

Eleyi jẹ siwaju-nikan iṣiro. Awọn ipe OCR/embedding atijọ ti ko kọ itan-akọọlẹ lilo rara ko le ṣe atunto lati ijira yii. Awọn iṣiro katalogi jẹ awọn iṣiro USD, kii ṣe iwe-owo, ati pe ko pẹlu iyipada owo, owo-ori tabi awọn ẹdinwo.

### Ọrọ ati awọn aworan

- `/v1/audio/transcriptions` ti o ṣaṣeyọri, `/v1/audio/speech` ati awọn igbiyanju iran-aworan pin ṣiṣe iṣiro nọmba. Awọn ipe taara ati awọn konbo gbe bọtini API olupe ati asopọ ti o yan; a konbo wrapper kò fi kan keji debiti.
- USD ti o royin olupese bori lori iṣiro katalogi kan, pẹlu idiyele odo ti o fojuhan. OpenRouter's JSON `usage.cost` jẹ deede si `cost_usd`. Bibẹẹkọ, awọn ami wiwọn lo awọn idiyele ami, awọn iṣẹju-aaya transcription lo awọn idiyele iṣẹju-aaya, igbewọle ọrọ nlo awọn iṣiro ohun kikọ Unicode, ati awọn aworan idiyele alapin lo nọmba ti o da pada, kii ṣe `n` ti o beere.
- Alakomeji OpenRouter TTS ko ni ara lilo JSON. Lẹhin ti ohun ti pari tabi olupe ti fagile, OmniRoute yoo beere iran rẹ ID lori** kanna** tunto OpenRouter Oti. Ibeere EU kan ko ṣubu pada si ipilẹṣẹ agbaye. Eleyi jẹ kan didi, kika-nikan wiwa; kolaginni ti ko ba tun gbiyanju fun iṣiro. Awọn igbasilẹ ìdíyelé le han lẹhin ti ohun naa ti pari: awọn igbiyanju wiwa ṣiṣẹ ni abẹlẹ fun bii awọn aaya 52, pẹlu awọn akoko ipari nẹtiwọki.
- Lakoko wiwa yẹn, idahun ohun ni `X-OmniRoute-Cost-Status: pending` ko si si akọsori idiyele-idahun. Idiyele ipari rẹ han ninu itan-akọọlẹ lilo, awọn atupale ati iwe akọọlẹ bọtini lẹhin ilaja. Ti metadata ko ba si, aworan iwoye ti owo atunto ni a lo; bibẹkọ ti iye owo duro aimọ.
- Awọn iṣẹju-aaya, awọn kikọ ati awọn iṣiro aworan ni awọn aaye ipin-isanwo lọtọ, kii ṣe awọn iṣiro ami iro rara. Iṣiro ṣe idaduro lilo nọmba nikan, kii ṣe ọrọ ọrọ, awọn iwe afọwọkọ tabi awọn baiti aworan. Awọn imukuro aworan ti ko ni idiyele tẹlẹ ko yipada: idiyele aworan ti o padanu nitootọ ko ni titiipa bọtini ti o lopin tuntun, ati pe idahun fi akọsori iye owo kuku ju sisọ ipe naa lọfẹ. Ikuna ile-itaja idiyele ṣi daduro ẹri lilo fun imuṣeduro pipade-ikuna.

Ko si idiyele speech/image itan ti o ṣẹda tabi ti o kun. Idiyele olupese jẹ itọkasi fun awọn risiti ati fun awọn ipe ti idiyele wọn ko royin.

## Pátákó ìṣàkóso: ojú-ewé Àwọn Ìnáwó

Ojú-ewé **Àwọn Ìnáwó** wà ní `/dashboard/costs`
(`src/app/(dashboard)/dashboard/costs/`).
Ìwòye pàtàkì rẹ̀ ni táàbù **Àkópọ̀ Àwọn Ìnáwó**
(`src/app/(dashboard)/dashboard/costs/CostOverviewTab.tsx`),
èyí tí ń gba gbogbo nǹkan láti `GET /api/usage/analytics`.

Ohun tí ó ń ṣàfihàn:

- **Àwọn àpótí ìnáwó** — ìṣírò iye ìnáwó fún _Òní (1d)_, _7d_, _30d_, àti àkókò
  tí a yàn. Olùyan ààlà àkókò: `7d`, `30d`, `90d`, `all`.
- **Àwọn òṣùwọ̀n pàtàkì** — àwọn ìbéèrè láàárín àkókò náà, àwọn olùpèsè tó ń ṣiṣẹ́, àwọn àwòṣe tó ń ṣiṣẹ́, ìpíndọ́gba
  ìnáwó fún ìbéèrè kọ̀ọ̀kan.
- **Olùṣàwárí Ìnáwó** — tábìlì tí a lè tò tàbí ṣàsẹ̀, tí a sì pín sí ẹgbẹ́ nípasẹ̀ **olùpèsè**, **àwòṣe**,
  **kọ́kọ́rọ́ API**, **àkọọ́lẹ̀**, tàbí **ìpele iṣẹ́**, pẹ̀lú ìnáwó, àwọn ìbéèrè, àwọn token, ìpíndọ́gba
  ìnáwó/ìbéèrè, àti ìdá ọgọ́rùn-ún nínú àpapọ̀.
- **Lílo token** — àpapọ̀ / àwọlé / àbájáde àwọn token àti ìpín àwọlé:sí-àbájáde.
- **Ìmúṣẹ́ dáradára ti ìdarí ọ̀nà** — iye ìpadàsẹ́yìn, òṣùwọ̀n ìpadàsẹ́yìn, àti ìbúdó àwòṣe tí a béèrè.
- **Àsọtẹ́lẹ̀ oṣooṣù** — ń ṣírò ìnáwó ìparí oṣù láti inú ìpíndọ́gba ojoojúmọ́ láìpẹ́.
- **Ìfiwéra àkókò** — ìyípadà % láàárín ìdajì àkọ́kọ́ àti ìdajì kejì àkókò náà.
- **Àwọn àwòrán** — ìtẹ̀sí ìnáwó ojoojúmọ́, ìpín olùpèsè (àwòrán páì), àwọn olùpèsè tó ga jù, àwọn àwòṣe tó ga jù, ìnáwó
  nípa kọ́kọ́rọ́ API, ìnáwó nípa àkọọ́lẹ̀, àpẹẹrẹ lílo ọ̀sọ̀ọ̀sẹ̀, àti àwòrán gbígbóná ìgbòkègbodò.
- **Ìkójáde** — ṣe ìgbàsílẹ̀ àkókò lọ́wọ́lọ́wọ́ gẹ́gẹ́ bí **CSV** tàbí **JSON** (àwọn bọ́tìnì náà yóò hàn
  nígbà tí dátà ìnáwó bá ju òdo lọ).

Nígbà tí kò bá sí ìṣàn-lọ́nà tí a fi iye owó lé lórí, àwọn ìlà yóò fi àmì "Ogún / Ọ̀fẹ́" hàn dípò `$0`,
ní ìbámu pẹ̀lú àwòṣe olùtọpa ìfipamọ́.

### Àwọn ojú-ewé kékeré tó ní í ṣe pẹ̀lú Àwọn Ìnáwó

Agbègbè Àwọn Ìnáwó tún ní àwọn wọ̀nyí (gbogbo wọn wà lábẹ́ `/dashboard/costs/`):

- **Ìfowópamọ́** (`/dashboard/costs/pricing`) — wo kí o sì ṣàtúnṣe iye owó fún àwòṣe kọ̀ọ̀kan (ń ṣàfihàn
  táàbù Ìfowópamọ́ tí a jọ ń lò).
- **Ètò Ìnáwó** (`/dashboard/costs/budget`) — ṣètò òpin ìnáwó fún ààlà kọ̀ọ̀kan (ń ṣàfihàn
  táàbù Ètò Ìnáwó tí a jọ ń lò).
- **Pípín Ìpín Lílo** (`/dashboard/costs/quota-share`) — àwọn àkójọpọ̀ ìpín lílo tí a jọ ń lò àti àwọn ìwòye
  òṣùwọ̀n lílo.

## API opin

Gbogbo awọn wọnyi nilo auth iṣakoso (loopback/JWT, nipasẹ `requireManagementAuth`) ayafi ti akiyesi.

### Lilo & atupale iye owo

| Ọna   | Opin ojuami              | Idi                                                                                                                                                                 |
| ----- | ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GET` | `/api/usage/analytics`   | Awọn atupale cost/usage ni kikun: akopọ, aṣa ojoojumọ, nipasẹ provider/model/API key/account/tier. Ibeere: `range`, `startDate`, `endDate`, `apiKeyIds`, `presets`. |
| `GET` | `/api/usage/utilization` | Lilo ipin ipin-olupese lori akoko. Ibeere: `range` (`1h`/`24h`/`7d`/`30d`), `provider`.                                                                             |
| `GET` | `/api/usage/history`     | Awọn ori ila itan lilo aise.                                                                                                                                        |
| `GET` | `/api/usage/call-logs`   | Awọn iwe ipe fun-ibeere (awoṣe, awọn ami, iye owo, lairi, ipo).                                                                                                     |
| `GET` | `/api/usage/quota`       | Ipo ipin olupese.                                                                                                                                                   |
| `GET` | `/api/usage/proxy-logs`  | Aṣoju ìbéèrè àkọọlẹ.                                                                                                                                                |

### Awọn inawo

| Ọna    | Opin ojuami              | Idi                                                                                 |
| ------ | ------------------------ | ----------------------------------------------------------------------------------- |
| `GET`  | `/api/usage/budget`      | Akopọ iye owo + ayẹwo isuna fun bọtini API kan (awọn ibeere `apiKeyId` param nilo). |
| `POST` | `/api/usage/budget`      | Ṣeto daily/weekly/monthly USD fi opin si aaye ikilọ + fun bọtini API.               |
| `GET`  | `/api/usage/budget/bulk` | Awọn akopọ isuna olopobobo kọja awọn bọtini API.                                    |

> Awọn isuna API ti wa ni scoped fun**API bọtini** (`apiKeyId`). Awọn ifilelẹ ti a da pada nipasẹ `GET /api/usage/budget` pẹlu `dailyLimitUsd`, `weeklyLimitUsd`, `monthlyLimitUsd`, a `warningThreshold`, ati awọn lapapọ nṣiṣẹ (`totalCostToday`, `totalCostMonth`, …).

### Ifowoleri

| Ọna      | Opin ojuami             | Idi                                                                                                                                                        |
| -------- | ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GET`    | `/api/pricing`          | Merged four-layer pricing (user, models.dev, LiteLLM, defaults). `?includeSources=1` returns `pricing` + `sourceMap`.                                      |
| `PATCH`  | `/api/pricing`          | Daju idiyele fun `{ provider: { model: { input, output, cached, … } } }`.                                                                                  |
| `DELETE` | `/api/pricing`          | Yọ awọn idiyele idiyele olumulo kuro (aṣayan scoped nipasẹ `?provider=&model=`); awọn oṣuwọn amuṣiṣẹpọ tabi awọn aiyipada ti a ṣe sinu wa bi awọn apadabọ. |
| `GET`    | `/api/pricing/defaults` | Ṣe afihan awọn oṣuwọn isubu per-1M aiyipada.                                                                                                               |
| `GET`    | `/api/pricing/models`   | Ifowoleri keyed nipa awoṣe.                                                                                                                                |
| `POST`   | `/api/pricing/sync`     | Ṣe okunfa imuṣiṣẹpọ afọwọṣe lati awọn orisun ita (LiteLLM).                                                                                                |
| `GET`    | `/api/pricing/sync`     | Ipo amuṣiṣẹpọ lọwọlọwọ.                                                                                                                                    |
| `DELETE` | `/api/pricing/sync`     | Ko owo-owo ti a muṣiṣẹpọ mọ LiteLLM (`pricing_synced`); modeli.dev data jẹ lọtọ.                                                                           |

### Miiran iye owo-ti o yẹ endpoints

| Ọna   | Opin ojuami                   | Idi                                                            |
| ----- | ----------------------------- | -------------------------------------------------------------- |
| `GET` | `/api/free-tier/summary`      | Apapọ ami-ami awoṣe-ọfẹ, lilo-oṣu yii, ati iyọọda ọfẹ ti o ku. |

## CLI

CLI OmniRoute ń pèsè àwọn àṣẹ fún iye owó, lílò, àti ìdíyelé (tí a forúkọsílẹ̀ nínú
[`bin/cli/commands/registry.mjs`](../../bin/cli/commands/registry.mjs)).

### `omniroute cost`

Ìròyìn iye owó tí a ṣàkójọpọ̀ láti `/api/usage/analytics`.

```bash
omniroute cost                          # ọjọ́ 30 tó kọjá, tí a pín sí ẹgbẹ́ gẹ́gẹ́ bí olupèsè
omniroute cost --period 7d              # ọjọ́ 7 tó kọjá
omniroute cost --group-by model         # pín sí ẹgbẹ́ gẹ́gẹ́ bí provider | model | combo | api-key | day
omniroute cost --since 2026-06-01 --until 2026-06-13
omniroute cost --api-key <key> --limit 50
```

Àwọn ọ̀wọ̀n: ẹgbẹ́, àwọn ìbéèrè, àwọn token àbáwọlé/àbájáde, iye owó (USD), àti % àpapọ̀. A máa
tẹ ìlà àpapọ̀ gbogbo jáde ní ìparí (a kò ní fi hàn pẹ̀lú `--quiet` tàbí `--output json`).

### `omniroute usage`

```bash
omniroute usage analytics --period 30d [--provider <id>]   # àkótán iye owó fún olupèsè kọ̀ọ̀kan
omniroute usage logs [--limit 100] [--follow] [--api-key <k>] [--search <q>]
omniroute usage quota [--provider <id>] [--check]
omniroute usage utilization [--api-key <k>]
omniroute usage history [--limit 100]
omniroute usage proxy-logs [--limit 100]

# Àwọn ìnáwó ààlà
omniroute usage budget list
omniroute usage budget get [scope]
omniroute usage budget set <amount> [--scope global] [--period monthly]
omniroute usage budget reset [scope]
```

### `omniroute pricing`

```bash
omniroute pricing list [--provider <p>] [--model <m>] [--limit 200]
omniroute pricing get <model>
omniroute pricing sync [--provider <p>] [--force]   # POST /api/pricing/sync
omniroute pricing diff [--model <m>]
omniroute pricing defaults show
omniroute pricing defaults set [--input <p>] [--output <p>] [--cache-read <p>] [--cache-write <p>]
```

> `pricing defaults show` ń ka `GET /api/pricing/defaults`. Láti ṣàtúnṣe àwọn iye owó model
> kọ̀ọ̀kan dípò bẹ́ẹ̀, lo ojú-ewé dashboard **Pricing** tàbí `PATCH /api/pricing`.

## Yíyanjú àwọn ìṣòro

- **Gbogbo iye owó ń fi $0 / "Legacy / Free" hàn.** Àwọn model tí a ń lò kò ní àkọsílẹ̀ ìdíyelé.
  Mú ìmúdójúìwọ̀n ìta ṣiṣẹ́ (`PRICING_SYNC_ENABLED=true`) kí o sì ṣiṣẹ́ `omniroute pricing sync`, tàbí
  ṣètò àwọn iye owó fúnra rẹ nípasẹ̀ ojú-ewé Pricing / `PATCH /api/pricing`.
- **Iye owó model ìtàn kan kò tọ́.** Ṣàtúnṣe iye owó náà (ṣe override tàbí tún sync ṣe) — a máa
  tún iye owó ṣe ìṣirò láti inú iye àwọn token ní gbogbo ìgbà tí a bá ka analytics, nítorí náà àwọn àfojúsùn máa ń ṣe ìmúdójúìwọ̀n sẹ́yìn.
- **Ìnáwó ń pẹ́ lẹ́yìn àkókò gidi.** A máa ń ṣe ìnáwó fún key kọ̀ọ̀kan ní ìpele; dín
  `OMNIROUTE_SPEND_FLUSH_INTERVAL_MS` kù bí o bá nílò àwọn nọ́mbà tuntun síi.
