> **Orísun òtítọ́:** `src/lib/plugins/` (`marketplace.ts`, `manager.ts`, `manifest.ts`,
> `scanner.ts`, `loader.ts`), `src/app/api/plugins/`, àti
> `src/app/(dashboard)/dashboard/plugins/`
> **Ìgbà ìmúdójúìwọ̀n tó kẹ́yìn:** 2026-06-28 — v3.8.40

OmniRoute ní ètò plugin tó dà bí ti WordPress. Àwọn plugin jẹ́ àwọn àkójọpọ̀ fáìlì
olóminira — ọ̀kọ̀ọ̀kan ní manifest `plugin.json` àti fáìlì ìbẹ̀rẹ̀ — tí wọ́n ń so
ara wọn mọ́ ìṣàn ìbéèrè (`onRequest` / `onResponse` / `onError`) àti àwọn
ìṣẹ̀lẹ̀ ìgbésí-ayé (`onInstall` / `onActivate` / `onDeactivate` / `onUninstall`).

**Ọjà Plugin** ni ipele ìṣàwárí tó wà lórí ètò náà. Ó ń pèsè àkójọ àwọn plugin
tí a lè ṣàwárí tí a sì lè fi sí ẹrọ. Nípa àìṣe, àkójọ náà jẹ́ registry ìpilẹ̀ṣẹ̀
kékeré tó wà nínú ètò; olùṣàkóso lè darí rẹ̀ sí URL registry jíjìn àkànṣe, nígbà
náà ni a ó fi ìdábòbò SSRF tó ń yanjú DNS mú ìgbàjáde náà le
(wo [Ààbò](#security)).

Gbogbo ipa-ọ̀nà plugin jẹ́ **fún loopback nìkan** (Ìpele 1 — `LOCAL_ONLY`):
àwọn plugin ń ṣàkójọpọ̀ wọ́n sì ń ṣiṣẹ́ kóòdù nínú àwọn child process, nítorí náà
a kò lè dé àwọn ipa-ọ̀nà náà láti orísun tí kì í ṣe loopback láìka ìfàṣẹsí sí. Wo
[`docs/security/ROUTE_GUARD_TIERS.md`](../security/ROUTE_GUARD_TIERS.md).

## Bawo ni o ṣe baamu Together

```
Dashboard (/dashboard/plugins)
  ├─ "Installed" tab  → GET /api/plugins            (listPlugins)
  │                     POST /api/plugins/scan      (pluginManager.scan)
  │                     POST /api/plugins/{name}/activate|deactivate
  │                     DELETE /api/plugins/{name}   (uninstall)
  └─ "Marketplace" tab → GET /api/plugins/marketplace
                          → listMarketplacePlugins()
                            ├─ no custom URL → built-in SEED_REGISTRY
                            └─ custom URL → isSafeMarketplaceUrl() SSRF guard
                                          → safeOutboundFetch(guard:"public-only")
```

- **Layer iforukọsilẹ** — `src/lib/plugins/marketplace.ts`: awọn atokọ / ṣawari awọn katalogi, ti o pada sẹhin si iforukọsilẹ irugbin lori ikuna eyikeyi.
- **Lifecycle Layer** — `src/lib/plugins/manager.ts` (`pluginManager` singleton): fi sori ẹrọ, igbesoke, mu ṣiṣẹ, mu maṣiṣẹ, aifi sipo, ọlọjẹ, fifuye ibẹrẹ.
- **Layer afihan** — `src/lib/plugins/manifest.ts`: Zod schema + aiyipada fun `plugin.json`.
- **Scanner** — `src/lib/plugins/scanner.ts`: ṣe awari awọn afikun lori disiki labẹ itọsọna itanna.
- **Agberu** — `src/lib/plugins/loader.ts`: spawns kọọkan itanna ni lọtọ Node.js ọmọ ilana ati awọn alagbata kio ipe lori IPC. Ọmọ naa kii ṣe apoti iyanrin (wo “ipinya ipaniyan ohun itanna” ni isalẹ).

## Àkójọ Ọjà

`listMarketplacePlugins()` (`src/lib/plugins/marketplace.ts`) ń dá àkójọ àwọn
object `MarketplaceEntry` padà:

| Field         | Irú      | Àwọn àlàyé                                                |
| ------------- | -------- | --------------------------------------------------------- |
| `name`        | string   | Orúkọ plugin ní kebab-case                                |
| `version`     | string   | semver                                                    |
| `description` | string   | Àkótán kúkúrú                                             |
| `author`      | string   | Olùkọ̀wé / àjọ                                             |
| `license`     | string   | ID ìwé-àṣẹ ara SPDX                                       |
| `downloadUrl` | string   | URL ìgbàsílẹ̀ orísun (ó lè ṣófo)                           |
| `repository`  | string?  | URL repository àṣàyàn                                     |
| `tags`        | string[] | Àwọn tag ìṣàwárí/àsẹ                                      |
| `downloads`   | number   | Iye ìgbàsílẹ̀                                              |
| `rating`      | number   | 0–5                                                       |
| `verified`    | boolean  | Bóyá a ti samisi àkọsílẹ̀ náà gẹ́gẹ́ bí èyí tí a ti jẹ́rìí sí |
| `lastUpdated` | string   | Okùn ọ̀rọ̀ ọjọ́ tó dà bí ISO                                 |

Nígbà tí a kò bá ṣètò URL registry àkànṣe, àkójọ náà ni `SEED_REGISTRY` inú ètò
(lọ́wọ́lọ́wọ́ `request-logger`, `rate-limiter`, `cost-tracker`, àti
`theme-manager`). Registry ìpilẹ̀ṣẹ̀ náà wà nígbà gbogbo — tí registry jíjìn tí a
ṣètò kò bá ṣeé dé, tí ó bá dá status tí kì í ṣe `200` padà, tàbí tí ó bá dá body
tí a kò mọ̀ padà, `listMarketplacePlugins()` máa ń kọ ìkìlọ̀ sínú log, ó sì máa
padà sí àkójọ ìpilẹ̀ṣẹ̀.

> Àkíyèsí: **àkójọ** ọjà (wíwo/ṣíṣàwárí) ti ní ìsopọ̀ láti ìbẹ̀rẹ̀ dé òpin,
> ṣùgbọ́n fífi plugin **sí ẹrọ** pẹ̀lú ìtẹ̀ ẹ̀ẹ̀kan láti inú àkójọ náà kò tíì ṣeé
> lò — bọ́tìnì "Fi sí ẹrọ" lórí àkọsílẹ̀ ọjà kan nínú dasibodu ń ṣàfihàn ìfitónilétí
> "ń bọ̀ láìpẹ́" lọ́wọ́lọ́wọ́. Fífi sí ẹrọ lónìí ń gba inú ìṣàn fífi sí ẹrọ láti
> ipa-ọ̀nà agbègbè (`POST /api/plugins`) àti ìṣàwárí lórí disk
> (`POST /api/plugins/scan`).

## REST API

Gbogbo awọn aaye ipari nilo ijẹrisi iṣakoso (`requireManagementAuth`)** ati** jẹ loopback-nikan — `/api/plugins` ati `/api/plugins/` ti wa ni akojọ si ni `LOCAL_ONLY_API_PREFIXES` (`src/server/authz/routeGuard.ts`).

| Opin ojuami                        | Ọna    | Apejuwe                                                        |
| ---------------------------------- | ------ | -------------------------------------------------------------- |
| `/api/plugins`                     | GET    | Ṣe atokọ awọn afikun ti a fi sori ẹrọ (àlẹmọ `?status=` yiyan) |
| `/api/plugins`                     | POST   | Fi ohun itanna sori ẹrọ lati itọsọna awọn orisun itanna        |
| `/api/plugins/scan`                | POST   | Ṣe ayẹwo iwe ilana itanna ati forukọsilẹ awọn afikun tuntun    |
| `/api/plugins/marketplace`         | GET    | Ṣe atokọ awọn titẹ sii katalogi ibi ọja                        |
| `/api/plugins/marketplace/install` | POST   | Fi ohun itanna ọjà sori ẹrọ nipasẹ orukọ                       |
| `/api/plugins/[name]`              | GET    | Gba awọn alaye itanna ti a fi sori ẹrọ                         |
| `/api/plugins/[name]`              | DELETE | Yọ ohun itanna kan kuro                                        |
| `/api/plugins/[name]/activate`     | POST   | Mu ṣiṣẹ (firù awọn ìkọ iforukọsilẹ + )                         |
| `/api/plugins/[name]/deactivate`   | POST   | Muu ma ṣiṣẹ ( `onDeactivate` ina, awọn ìkọ ti ko forukọsilẹ)   |
| `/api/plugins/[name]/config`       | GET    | Gba eto itanna atunto + atunto atunto                          |
| `/api/plugins/[name]/config`       | PUT    | Ṣe imudojuiwọn atunto ohun itanna (ti a fọwọsi lodi si ero)    |

Ajọ `GET /api/plugins` `status` gba ọkan ninu `installed` / `active` / `inactive` / `error`. Iye aiṣedeede da `400` pada.

### Akojọ awọn afikun ti a fi sori ẹrọ

```bash
curl http://localhost:20128/api/plugins \
  -H "Cookie: auth_token=..."
```

### Fi sori ẹrọ lati ọna agbegbe kan

```bash
curl -X POST http://localhost:20128/api/plugins \
  -H "Cookie: auth_token=..." \
  -H "Content-Type: application/json" \
  -d '{ "path": "/absolute/path/to/my-plugin" }'
```

`path` gbọdọ jẹ ẹya** pipe** ona to a liana** inu awọn orisun itanna liana** : `plugin-sources` lẹgbẹẹ gbongbo itanna, nitorina `~/.omniroute/plugin-sources/` nipasẹ aiyipada, tabi `<parent of OMNIROUTE_PLUGINS_DIR>/plugin-sources/` nigbati a ṣeto oniyipada naa (`getPluginSourcesDir()` ni `src/lib/plugins/installSource.ts`). Daakọ tabi oniye ohun itanna nibẹ akọkọ. A kọ fifi sori ẹrọ pẹlu `400` nigbati ọna naa ni `..` tabi baiti asan kan, wa ni ita itọsọna yẹn, pinnu ni ita rẹ nipasẹ ọna asopọ kan, ni aami ọna asopọ ti ibi-afẹde rẹ wa ni ita rẹ, tabi nigbati itọsọna naa ko si. Itọsọna orisun gbọdọ ni `plugin.json` to wulo (tabi jẹ obi ti ọkan). Lori aṣeyọri idahun jẹ `201` pẹlu ọna itanna ti a fi sii.

Ko dabi awọn ipa-ọna itanna miiran, ọkan yii nilo ijẹrisi iṣakoso (akoko dasibodu kan tabi bọtini API ti iṣakoso-scoped) paapaa nigbati iwọle ba jẹ alaabo (`requireLogin=false`): fifi koodu kii ṣe iṣe iṣe ailorukọ rara. Kanna kan si `POST /api/plugins/marketplace/install` (ara `{ "name": "<plugin>" }`).

### Lọ kiri lori ọja naa

```bash
curl http://localhost:20128/api/plugins/marketplace \
  -H "Cookie: auth_token=..."
```

### Ṣe imudojuiwọn atunto itanna

```bash
curl -X PUT http://localhost:20128/api/plugins/my-plugin/config \
  -H "Cookie: auth_token=..." \
  -H "Content-Type: application/json" \
  -d '{ "config": { "level": "debug", "maxItems": 100 } }'
```

`PUT .../config` fọwọsi ara lodi si `configSchema` ohun itanna (ti a kede ni ifihan) pẹlu `validatePluginConfig()` lati `src/lib/plugins/manifest.ts`: gbogbo bọtini gbọdọ wa ni ikede ni ero, awọn iye gbọdọ baamu iru ikede, awọn aaye `number` ọlá `min`/`max`, ati awọn aaye `select` gbọdọ baramu `enum` ti a kede. Eyikeyi irufin da `400` pada ko si si ohun ti o wa ni ipamọ. Ohun itanna kan ti o sọ pe ko si `configSchema` ko ni awọn bọtini atunto, nitorinaa a kọ ibeere naa pẹlu `400` (“Afikun ko sọ awọn bọtini atunto eyikeyi”).

## Ìṣètò

### Àpò-ọ̀nà plugin

Àwọn plugin wà lábẹ́ àpò-ọ̀nà dátà OmniRoute:

```
~/.omniroute/plugins/<plugin-name>/
  ├─ plugin.json
  └─ index.js          # (tàbí ohunkóhun tí manifest.main tọ́ka sí)
```

`getDefaultPluginDir()` (`src/lib/plugins/scanner.ts`) ń yanjú àpò-ọ̀nà yẹn ní
ìgbésẹ̀ mẹ́ta:

1. **`OMNIROUTE_PLUGINS_DIR`**, nígbà tí a bá ṣètò rẹ̀ — a lò ó bí ó ṣe rí, láìka ohun tí `HOME` sọ. Èyí ni
   ìṣàkóso pàtó fún Docker/K8s, níbi tí a ti fi igi plugin mọ́lẹ̀ ní path kan
   tí kò sábà ní ohunkóhun ṣe pẹ̀lú àpò-ọ̀nà ilé container náà (#11827).
2. `<home>/.omniroute/plugins`, níbi tí `<home>` ti wá láti inú àwọn environment variable `HOME` / `USERPROFILE`.
3. `/tmp/.omniroute/plugins`, nígbà tí process náà kò bá export àpò-ọ̀nà ilé rárá.

A máa log àpò-ọ̀nà tí a yanjú lẹ́ẹ̀kan ní ìbẹ̀rẹ̀ gẹ́gẹ́ bí `scanner.dir_resolved`, nípa dídárúkọ
input tó borí (`OMNIROUTE_PLUGINS_DIR`, `home`, tàbí `no-home-fallback`) — nítorí náà image kan
tí ó dé ìgbésẹ̀ 3 láìsọ ohunkóhun máa sọ bẹ́ẹ̀, dípò kí ó kàn ròyìn àtòjọ plugin òfo.
`POST /api/plugins/scan` ń ṣàwárí subdirectory èyíkéyìí níbẹ̀ tí ó ní
`plugin.json` tó péye, ó sì ń forúkọsílẹ̀ rẹ̀; àpò-ọ̀nà kan náà ni root tí
`pluginManager.install()` ń da àwọn plugin sí, nítorí náà override máa ń gbé ìṣàwárí àti
ìfísílẹ̀ papọ̀.

> **`OMNIROUTE_PLUGINS_DIR` kì í ṣe `OMNIROUTE_PLUGIN_PATH`.** Olùkójọpọ̀ command-plugin CLI
> (`bin/cli/plugins.mjs`) nìkan ló ń ka èkejì láti rí àwọn package npm `omniroute-cmd-*`
> tí ń fi àwọn subcommand `omniroute` kún un — kò ní ipa kankan lórí scanner runtime
> tí a ṣàpèjúwe níbí. Wo [PLUGINS.md](./PLUGINS.md) fún apá yẹn.

### URL registry ọjà àkànṣe

A ń ka orísun katalogi ọjà láti inú setting `pluginMarketplaceUrl`
(`src/lib/plugins/marketplace.ts` ń ka `settings.pluginMarketplaceUrl`). Nígbà tí
a bá ṣètò rẹ̀ sí URL `http(s)`, `listMarketplacePlugins()` máa fetch URL náà, yóò sì gba
yálà JSON array àwọn àkọsílẹ̀ ní ipele òkè tàbí object kan tó ní array `plugins`;
a máa yọ àwọn àkọsílẹ̀ tí kò ní `name` tó jẹ́ string kúrò. Nígbà tí a kò bá ṣètò rẹ̀ (tàbí tí fetch
bá kọjá ààbò SSRF / dá ìdáhùn búburú padà), a máa lo seed registry tó wà nínú ètò náà.

Tab "Marketplace" lórí dashboard ń fi field kan hàn fún URL yìí (tí a tún ka padà láti
`GET /api/settings`).

> Àkíyèsí ìmúṣẹ: ìṣe "Save" lórí dashboard ń fi
> `pluginMarketplaceUrl` ránṣẹ́ sí `PATCH /api/settings`. Ní àkókò tí a ń kọ èyí,
> a kò tíì kéde key yìí nínú `updateSettingsSchema`
> (`src/shared/validation/settingsSchemas.ts`), nítorí náà ṣàyẹ̀wò pé ó dúró sínú release rẹ
> kí o tó gbára lé e — path **kíkà** (`getSettings()` →
> `listMarketplacePlugins()`) máa ń tẹ̀lé key náà lẹ́yìn tí ó bá ti wà nínú ibi ìpamọ́ settings.

## Aabo

### Ipa ọna — loopback nikan

Awọn afikun ṣiṣẹ koodu ni awọn ilana ọmọ ti o ni itọpa, nitorinaa gbogbo dada `/api/plugins` jẹ ipin `LOCAL_ONLY` (Ipele 1). Loopback imuse nṣiṣẹ lainidi** ṣaaju ki o to** ṣayẹwo eyikeyi auth, nitorinaa ami iṣakoso ti jo de apoti lori oju eefin kan ko le fi sii, mu ṣiṣẹ, tabi aifi si ẹrọ itanna kan. Wo [`docs/security/ROUTE_GUARD_TIERS.md`](../security/ROUTE_GUARD_TIERS.md) ati Awọn ofin Lile #15 / #17.

### Oja iforukọsilẹ SSRF oluso

Iforukọsilẹ aṣa URL jẹ atunto ti o ni ipa ti ikọlu, nitorinaa ṣaaju gbigba `listMarketplacePlugins()` o ṣiṣẹ nipasẹ awọn ipele meji:

1. **`isSafeMarketplaceUrl(url)`** (`src/lib/plugins/marketplace.ts`):
   - Kọ ohunkohun ti kii ṣe `http:` / `https:`.
   - Kọ awọn agbalejo private/loopback/link-local/ULA gangan (IPv4** ati** IPv6, pẹlu IPv4-mapped) nipasẹ canonical `isPrivateHost` (`src/shared/network/outboundUrlGuard.ts`).
   - Awọn ipinnu** mejeeji** `A` ati `AAAA` igbasilẹ ati kọ ti o ba ti** eyikeyi** adirẹsi ti o yanju jẹ — ikọkọ tilekun orukọ-olugbalegbe gbogbogbo → ikọkọ-IP fori.
   - **Ikuna ni pipade** : ikuna ipinnu DNS kan kọ URL.
2. **`safeOutboundFetch(url, { guard: "public-only", timeoutMs: 5000 })`** (`src/shared/network/safeOutboundFetch.ts`): tun-ṣiṣẹ ni gbangba-nikan URL oluso ni akoko bu ati** ohun amorindun àtúnjúwe** (ko si → ikọkọ `30x` pivot).

A URL ti o kuna boya Layer ko ni fa fifalẹ ibeere — aaye ọja ni idakẹjẹ ṣubu pada si iforukọsilẹ irugbin ti a ṣe sinu ati ṣe igbasilẹ ikilọ kan.

> Ẹṣọ yii ni lile ni PR #3774 pataki lati yanju A + AAAA ati lo `isPrivateHost` canonical dipo ayẹwo IPv4-only.

### Pilogi ipinya ipaniyan

> **Awọn afikun kii ṣe apoti iyanrin nipasẹ aiyipada.** Ọmọ naa jẹ ilana Node.js lasan ti n ṣiṣẹ bi olumulo OmniRoute, laisi ipo VM ko si awọn asia igbanilaaye Node.js, nitorinaa koodu itanna le ka ati kọ faili eyikeyi ti olumulo le, ṣiṣe awọn eto ati de nẹtiwọki. `requires.permissions` nikan pinnu iru awọn oniyipada ayika ti ọmọ gba; awọn igbanilaaye miiran ko ni ipa. Ijade-in `PLUGIN_PERMISSION_MODEL_ENABLED` ẹya asia (pa nipasẹ aiyipada) nṣiṣẹ ohun itanna kọọkan labẹ awoṣe igbanilaaye Node.js ti a ṣe lati awọn igbanilaaye wọnyẹn, ayafi `network`, eyiti Node.js ko le ni ihamọ (wo [`PLUGIN_SDK.md`](./PLUGIN_SDK.md#gbigbanilaaye-system) ). Fi sori ẹrọ awọn afikun nikan ti o gbẹkẹle. Aala ilana ni isalẹ ni awọn ipadanu ati awọn idorikodo; kì í ṣe ààlà ààbò.

- **Iyapa ilana** — `loadPlugin()` (`src/lib/plugins/loader.ts`) fa ohun itanna kọọkan sinu ilana ọmọ Node.js lọtọ ati ibaraẹnisọrọ lori IPC. Awọn ipe kio ni akoko idaduro pẹlu `SIGTERM` → `SIGKILL` escalation.
- **Env iyọọda akojọ** — ọmọ gba nikan ohun idasilẹ ṣeto ti ayika oniyipada; Eto ti o gbooro ni a funni nikan nigbati ifihan ba beere fun igbanilaaye `env`.
- **Fi sori ẹrọ akoonu orisun** — `POST /api/plugins` nikan ka lati inu itọsọna awọn orisun itanna (wo "Fi sori ẹrọ lati ọna agbegbe kan"): ọna naa jẹ ilana ofin pẹlu `realpath`, gbọdọ duro ni muna inu itọsọna yẹn, ati pe igi orisun kan ti o gbe aami asopọ ti o salọ o ti kọ ṣaaju ki o to daakọ ohunkohun.
- **Itọju ọna** — install/upgrade/uninstall sọ pe ilana itanna ati ipinnu `manifest.main`** laarin** gbongbo itanna ti a ṣakoso ṣaaju eyikeyi ẹda tabi paarẹ loorekoore (awọn olusona lodi si awọn ọna DB ti o bajẹ ati gbigbe `../` ni `manifest.main`). Imuṣiṣẹ ṣe ipinnu awọn ọna asopọ awọn aami nipasẹ `realpath` ati kọ lati gbe aaye titẹsi kan ti o salọ ilana itanna.
- **PIN iṣotitọ iyan** — farahan le sọ aaye `integrity` (`sha256-<base64>`, ọna kika SRI ) kan. Nigbati o ba wa, agberu naa jẹri hash faili iwọle ni akoko fifuye ati kọ lati muu ṣiṣẹ lori aiṣedeede. O jẹ ṣiṣawari-iṣawari-ifọwọyi,** kii ṣe** aala aabo: ko ṣe idinwo ohun ti ohun itanna ti kojọpọ le ṣe.
- **Ko si awọn iwe-ẹri alabara ni awọn kio** — ọrọ-ọrọ ti o kọja si `onRequest`, `onResponse` ati `onError` ti yọkuro `authorization`, `x-api-key`, `proxy-authorization` ati awọn akọle `cookie`, ati pe igbasilẹ bọtini API ko ni iye bọtini (`redactPluginContext()` ni `src/lib/plugins/hooks.ts`).

## Ifihan (`plugin.json`)

Ti fọwọsi nipasẹ `PluginManifestSchema` (`src/lib/plugins/manifest.ts`):

| Aaye               | Iru      | Awọn akọsilẹ                                                     |
| ------------------ | -------- | ---------------------------------------------------------------- |
| `name`             | okun     | Ti a beere; kebab-case (`^[a-z0-9-]+$`), 1-100 chars             |
| `version`          | okun     | Ti a beere; semver (`MAJOR.MINOR.PATCH`)                         |
| `description`      | okun?    | ≤ 500 chars                                                      |
| `author`           | okun?    | ≤ 200 chars                                                      |
| `license`          | okun?    | Awọn aiyipada si `MIT`                                           |
| `main`             | okun?    | Faili wiwọle; awọn aṣiṣe si `index.js`                           |
| `source`           | enum?    | `local` \| `marketplace` (aiyipada si `local`)                   |
| `tags`             | okun[]?  | Wa afi                                                           |
| `requires`         | ohun?    | `{ omniroute?, permissions[] }`                                  |
| `hooks`            | ohun?    | Booleans ti n kede eyi ti o ṣe awọn imuse ohun itanna naa        |
| `skills`           | nkan[]?  | Iyan olorijori itumo                                             |
| `enabledByDefault` | boolian? | Muu ṣiṣẹ laifọwọyi lori fifi sori ẹrọ                            |
| `configSchema`     | ohun?    | Maapu ti awọn aaye atunto (`string`/`number`/`boolean`/`select`) |
| `integrity`        | okun?    | Iyan `sha256-<base64>` pin-faili titẹsi                          |

Awọn igbanilaaye wa lati enum `network` / `file-read` / `file-write` / `env` / `exec`. `env` nikan ni o ni ipa asiko-ṣiṣe (agbegbe diẹ ti o tobi ju-ayipada akojọ iyọọda fun ọmọde); awọn miiran jẹ awọn ikede ati pe ko fi agbara mu.

## Ìṣàn Ìgbésí-ayé

```
fi sori ẹrọ (POST /api/plugins, ọ̀nà)
  → ṣàyẹ̀wò/fọwọ́sí manifest → daakọ sí staging → jẹ́rìí pé main wà nínú àpótí ìtọ́kasí
  → ṣe atomic rename sí ~/.omniroute/plugins/<name> → fi ìlà kún DB
  → ṣiṣẹ́ onInstall → tí enabledByDefault bá jẹ́ òótọ́: mú ṣiṣẹ́

mú ṣiṣẹ́ (POST /api/plugins/{name}/activate)
  → ṣe àyẹ̀wò pé realpath wà nínú ààlà → loadPlugin() (ṣẹ̀dá child process)
  → forúkọsílẹ̀ àwọn hook tí a kéde → status = "active" → ṣiṣẹ́ onActivate

mú kúrò ní ṣíṣiṣẹ́ (POST /api/plugins/{name}/deactivate)
  → ṣiṣẹ́ onDeactivate (ṢÁÁJÚ yíyọ kúrò nínú ìforúkọsílẹ̀) → yọ àwọn hook kúrò nínú ìforúkọsílẹ̀
  → dá child process dúró → status = "inactive"

yọ kúrò (DELETE /api/plugins/{name})
  → mú kúrò ní ṣíṣiṣẹ́ tí ó bá ń ṣiṣẹ́ → ṣiṣẹ́ onUninstall
  → pa àpótí ìtọ́kasí plugin rẹ́kọjá lẹ́yìn àyẹ̀wò ààlà → pa ìlà DB rẹ́
```

Ṣíṣe `install` lẹ́ẹ̀kansi lórí àpótí ìtọ́kasí kan tí ẹ̀yà manifest rẹ̀ jẹ́ **tuntun
gan-an** ju ẹ̀yà tí a ti fi sori ẹrọ lọ yóò ṣe àfikún ẹ̀yà laifọwọ́yi (fífi sori ẹrọ
mímọ́; config yóò padà sí àwọn iye àkọ́kọ́). Ẹ̀yà kan náà tàbí èyí tí ó ti pẹ́ ju ni a ó kọ̀.

## Dasibodu

Oju-iwe dasibodu ni `/dashboard/plugins` (`src/app/(dashboard)/dashboard/plugins/page.tsx`) pese awọn taabu meji:

- **Ti fi sori ẹrọ** — ṣe atokọ awọn afikun ti a fi sori ẹrọ pẹlu awọn iwọ ti wọn kede, yiyi activate/deactivate kan, bọtini yiyọ kuro, ati iṣe “Ṣawari fun awọn afikun” (`POST /api/plugins/scan`).
- **Ibi ọja** — ṣe afihan katalogi lati `GET /api/plugins/marketplace` pẹlu aaye kan lati ṣeto iforukọsilẹ aṣa URL.

Oju-iwe nigbagbogbo nfihan ikilọ kan ti awọn afikun nṣiṣẹ pẹlu awọn anfani kikun ti ilana OmniRoute.

Oju-iwe atunto ohun itanna kan n gbe ni `/dashboard/plugins/[name]/config` (`src/app/(dashboard)/dashboard/plugins/[name]/config/page.tsx`).
