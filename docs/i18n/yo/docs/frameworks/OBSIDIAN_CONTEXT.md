> **Orísun òtítọ́:** `src/lib/obsidian/api.ts` (REST + oníbàárà ìṣiṣẹ́pọ̀),
> `src/lib/db/obsidian.ts` (ìfipamọ́ token / base-URL / WebDAV),
> `src/lib/obsidianSync.ts` (ìṣiṣẹ́pọ̀ vault WebDAV), `open-sse/mcp-server/tools/obsidianTools.ts`
> (irinṣẹ́ MCP 22), `src/app/api/settings/obsidian/route.ts` +
> `src/app/api/settings/obsidian/webdav/route.ts` (àwọn API ètò). Ìforúkọsílẹ̀ irinṣẹ́
> àti àsopọ̀ scope wà nínú `open-sse/mcp-server/server.ts`.

## Ohun tí ó jẹ́

OmniRoute so mọ́ vault **Obsidian** gẹ́gẹ́ bí **orísun àyíká-ọ̀rọ̀** — ibi ìpamọ́ ìmọ̀
Markdown abẹ́lẹ̀ kan tí àwọn agent ń kà, tí wọ́n sì ń kọ sí nípasẹ̀ server MCP tí a kọ́ sínú rẹ̀.
Ìṣọ̀kan náà ń bá plugin àwùjọ **Obsidian Local REST API** tí ń ṣiṣẹ́ nínú app desktop
sọ̀rọ̀, kí àwọn agent lè ṣàwárí àwọn àkọsílẹ̀, kà/kọ́/ṣe àtúnṣe patch sí àwọn fáìlì,
ṣe àkójọ vault, ṣiṣẹ́ pẹ̀lú àwọn àkọsílẹ̀ àsìkò ojoojúmọ́/ọ̀sọ̀ọ̀sẹ̀, ṣàkóso àwọn tag,
ṣiṣẹ́ àwọn àṣẹ Obsidian, àti (bí a bá fẹ́) ṣètò ìṣiṣẹ́pọ̀ vault oníṣọ̀nà-méjì
desktop↔mobile.

Oníbàárà náà (`src/lib/obsidian/api.ts`) fi àwọ̀n yí Local REST API ká pẹ̀lú:

- **Àtúnìgbìyànjú pẹ̀lú backoff** fún `5xx` alákòókò, **àkókò ìdádúró ìṣẹ́jú-àáyá 30** nípasẹ̀ `AbortController`.
- **Ìsọ̀rí àṣìṣe oníirú** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`.
- **Ìtọ́kasí “a kò lè dé Obsidian” tó rọrùn láti lóye** tí ó ṣàlàyé àṣìṣe port tó wọ́pọ̀
  (HTTP lórí `27123`, **kì í ṣe** endpoint MCP lórí `27124`) àti fọ́ọ̀mù Tailscale.
- **Ìṣàkọsílẹ̀ path** tó jẹ́ ìbátan sí vault, kí àwọn path àkọsílẹ̀ tó ní àyè/slash lè ní ààbò.

## Ìṣètò

Kò sí **oníyí àyíká kankan** fún àmì ìdánimọ̀ Obsidian tàbí URL ìpìlẹ̀ — àwọn méjèèjì ni a
fi pamọ́ sínú tábìlì SQLite `key_value` (ààyè-orúkọ `obsidian`) nípasẹ̀
`src/lib/db/obsidian.ts`. A **parọ́ mọ́ àmì ìdánimọ̀ náà níbi ìpamọ́** (AES-256-GCM, pẹ̀lú
àsopọ̀ àfẹ́yìntì ìbámu fún ọ̀rọ̀ gbangba). Ṣètò rẹ̀ láti taabu **Context Sources** ti
pátákó ìdarí Endpoint (`ObsidianSourceCard`), tàbí nípasẹ̀ API REST ti àwọn ààtò.

> [!IMPORTANT]
> A gbọ́dọ̀ fi àfikún **Obsidian Local REST API** sí ẹ̀rọ, kí ó sì máa ṣiṣẹ́. Ojú-ọ̀nà REST
> rẹ̀ ń fetí sí **HTTP `127.0.0.1:27123`** (URL ìpìlẹ̀ àiyipada). Port `27124`
> jẹ́ ojú-ọ̀nà MCP/HTTPS _ọ̀tọ̀_, ipa-ọ̀nà àwọn ààtò sì kọ̀ ọ́ ní tààràtà.
> Bí o bá ń sopọ̀ láti ẹ̀rọ mìíràn, lo `http://<tailscale-ip>:27123`.

### Àwọn kọ́kọ́rọ́ ìṣètò (SQLite `key_value`, ààyè-orúkọ `obsidian`)

| Kọ́kọ́rọ́            | Ìdí                                                | Ti parọ́ mọ́ |
| ----------------- | -------------------------------------------------- | ---------- |
| `api_key`         | Àmì ìdánimọ̀ bearer ti Local REST API               | bẹ́ẹ̀ ni     |
| `base_url`        | URL ìpìlẹ̀ REST (àiyipada `http://127.0.0.1:27123`) | bẹ́ẹ̀ kọ́     |
| `vault_path`      | Ojú-ọ̀nà alákòóso sí àpò-ọ̀rọ̀ vault (fún ìmúdọ́gba)   | bẹ́ẹ̀ kọ́     |
| `webdav_username` | Orúkọ aṣàmúlò WebDAV tí a ṣẹ̀dá (ìmúdọ́gba vault)    | bẹ́ẹ̀ kọ́     |
| `webdav_password` | Ọ̀rọ̀ aṣínà WebDAV tí a ṣẹ̀dá (ìmúdọ́gba vault)        | bẹ́ẹ̀ ni     |
| `webdav_enabled`  | Bóyá ìmúdọ́gba vault WebDAV ti ṣiṣẹ́                 | bẹ́ẹ̀ kọ́     |

### Ṣètò nípasẹ̀ REST

```bash
# Fi àmì ìdánimọ̀ Local REST API pamọ́ + ṣàyẹ̀wò rẹ̀ (POST ń fìdí rẹ̀ múlẹ̀ nípasẹ̀ àyẹ̀wò ipò)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# Ṣàyẹ̀wò ipò àsopọ̀ (ó ń dá connected, hasToken, baseUrl, vaultPath padà)
curl http://localhost:20128/api/settings/obsidian

# Já àsopọ̀ (ó ń pa àmì ìdánimọ̀ tí a fi pamọ́ rẹ́)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

Gbogbo àwọn ọ̀nà nílò ìfàṣẹsí pátákó ìdarí. `POST` kọ gbogbo URL lórí port `27124`
ó sì ń fìdí àmì ìdánimọ̀ múlẹ̀ nípa pípe ojú-ọ̀nà ipò Local REST API kí ó tó fi í pamọ́.

### Ìmúdọ́gba vault WebDAV

`src/app/api/settings/obsidian/webdav/route.ts` ń ṣàkóso ìmúdọ́gba vault àṣàyàn kan
tí WebDAV ń ṣe àtìlẹ́yìn fún (tí `src/lib/obsidianSync.ts` ń darí). Ṣíṣiṣẹ́ rẹ̀ ń tọ́ka
OmniRoute sí àkójọpọ̀ vault agbègbè, ó sì ń ṣẹ̀dá orúkọ aṣàmúlò/ọ̀rọ̀ aṣínà WebDAV láìròtẹ́lẹ̀:

```bash
# Ṣí ìmúdọ́gba WebDAV ṣiṣẹ́ fún àkójọpọ̀ vault kan (ó ń ṣẹ̀dá orúkọ aṣàmúlò/ọ̀rọ̀ aṣínà)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# Gba ipò ìmúdọ́gba WebDAV (ìwé ẹ̀rí ni a máa dá padà nígbà tí ó bá ṣiṣẹ́ nìkan)
curl http://localhost:20128/api/settings/obsidian/webdav

# Pa ìmúdọ́gba WebDAV (ó ń pa ìwé ẹ̀rí + .stignore tí a ṣàkóso rẹ́)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### Aabo & Transport

ìfàṣẹsí WebDAV fi ipa mu ipasẹ ipasẹ ikuna fun-IP ati titiipa (awọn igbiyanju 10 ti o kuna laarin ferese iṣẹju-aaya 60 nfa titiipa iṣẹju 5 pẹlu `429 Too Many Requests` ati `Retry-After`). Nitori WebDAV n gbejade awọn iwe-ẹri Ipilẹ Ipilẹ, ipari TLS (tabi ipa ọna oju eefin to ni aabo gẹgẹbi Tailscale tabi Cloudflare Tunnel) ni a gbaniyanju gidigidi nigbati o ba wọle si aaye ipari WebDAV ni ita loopback.

### Orísun àyíká fún kọ́kọ́rọ́ API kọ̀ọ̀kan (àṣàyàn)

A lè fi ààlà sí ìṣètò Obsidian **fún kọ́kọ́rọ́ API kọ̀ọ̀kan** nípasẹ̀ tábìlì
`api_key_context_sources` (`src/lib/db/apiKeyContextSources.ts`). Nígbà tí ìpè MCP kan
bá gbé id kọ́kọ́rọ́ API tí a ti fìdí rẹ̀ múlẹ̀, `getObsidianConfigForApiKey()` máa kọ́kọ́
yan àmì ìdánimọ̀/URL-ìpìlẹ̀/ojú-ọ̀nà-vault tirẹ̀ (`source: "api_key"`), bí bẹ́ẹ̀ kọ́, yóò
padà lo ìṣètò àgbáyé (`source: "global"`).

Àwọn irinṣẹ́ MCP tí kì í ṣe ti ìmúdọ́gba nílò ìdánimọ̀ olùpè tí a ti yanjú kí wọ́n tó ka
ìṣètò yìí. Olùpè tí kò ní ìdánimọ̀ máa gba `Obsidian API token not configured`, kò sì ní
sí ìbéèrè vault tí a ó fi ránṣẹ́. Àwọn olùpè HTTP ń yanjú rẹ̀ nípasẹ̀ ìwé ẹ̀rí ìbéèrè wọn;
àwọn olùpè stdio lè yanjú rẹ̀ nípasẹ̀ `OMNIROUTE_API_KEY` tàbí `ROUTER_API_KEY`. Olùpè
HTTP tí a kò lè yanjú kò lè jogún ìdánimọ̀ àyíká olupèsè. Àwọn ID afidípò nìkan kò fúnni
láṣẹ láti wọlé; ìwé ẹ̀rí àyíká tó fẹsẹ̀ múlẹ̀, tí ó yanjú sí `env-key`, ṣì ń ṣiṣẹ́.
Àwọn kọ́kọ́rọ́ tí a ti fìdí wọn múlẹ̀ tí kò ní ìṣètò Obsidian ti kọ́kọ́rọ́ náà ṣì lè lo
àfẹ́yìntì àgbáyé. Àwọn irinṣẹ́ `obsidian_sync_*` mẹ́rin náà ṣì ń lo ìhùwàsí àmì ìdánimọ̀
ìmúdọ́gba ọ̀tọ̀ tiwọn.

## irinṣẹ MCP (22)

Ti tumọ si ni `open-sse/mcp-server/tools/obsidianTools.ts`. token/base-URL naa jẹ ipinnu fun ipe kan (fun-API-bọtini akọkọ, lẹhinna agbaye). Awọn irinṣẹ ti o lu OmniRoute** amuṣiṣẹpọ olupin** (awọn irinṣẹ `obsidian_sync_*` mẹrin) ni afikun nilo ami amuṣiṣẹpọ auth ti a tunto ni awọn eto OmniRoute.

### Awọn irinṣẹ kika (`read:obsidian`)

| Irinṣẹ                       | Apejuwe                                                                                      |
| ---------------------------- | -------------------------------------------------------------------------------------------- |
| `obsidian_check_status`      | Ṣayẹwo boya agbegbe REST API jẹ eyiti o le de ọdọ ati ti jẹri.                               |
| `obsidian_search_simple`     | Wiwa ọrọ-kikun ti akoonu akọsilẹ; pada snippets pẹlu awọn ọna faili.                         |
| `obsidian_search_structured` | Ṣewadii nipa lilo ikosile JSON Logic kan (awọn asẹ and/or/regex/path ).                      |
| `obsidian_read_note`         | Ka akọsilẹ nipasẹ ọna ifinkan-ojulumo; iyan kan pato heading/block/frontmatter.              |
| `obsidian_list_vault`        | Ṣe atokọ awọn faili ati awọn ilana ninu ifinkan (igi ti awọn titẹ sii).                      |
| `obsidian_get_document_map`  | Gba eto akọle akọsilẹ bi maapu awọn akọle → awọn nọmba laini.                                |
| `obsidian_get_note_metadata` | Gba ọrọ iwaju, awọn afi, awọn ọna asopọ, kika char/word laisi akoonu kikun.                  |
| `obsidian_get_active_file`   | Gba akoonu ọna + ti faili ti nṣiṣẹ lọwọlọwọ ni Obsidian.                                     |
| `obsidian_get_periodic_note` | Gba akọsilẹ igbakọọkan daily/weekly/monthly fun ọjọ kan (loni ti o ba yọkuro).               |
| `obsidian_get_tags`          | Ṣe atokọ gbogbo awọn aami ifinkan pẹlu awọn loorekoore wọn.                                  |
| `obsidian_list_commands`     | Atokọ ti o wa Obsidian pipaṣẹ IDs (lo pẹlu `obsidian_execute_command`).                      |
| `obsidian_sync_status`       | ipo olupin ìsiṣẹpọ OmniRoute : nṣiṣẹ, orukọ ifinkan, ibudo, akoko akoko, imuṣiṣẹpọ to kẹhin. |
| `obsidian_sync_conflicts`    | Ṣe atokọ awọn ija amuṣiṣẹpọ ti ko yanju (ọna, ipa-ọna ija, ti a rii-ni).                     |

### Awọn irinṣẹ kikọ (`write:obsidian`)

| Irinṣẹ                           | Apejuwe                                                                                   |
| -------------------------------- | ----------------------------------------------------------------------------------------- |
| `obsidian_write_note`            | Ṣẹda tabi tunkọ akọsilẹ pẹlu akoonu Markdown ti a fun.                                    |
| `obsidian_append_note`           | Fi akoonu kun si akọsilẹ; iyan si kan pato heading/block.                                 |
| `obsidian_patch_note`            | Ni abẹ append/prepend/replace ni aaye akọle, idina, tabi aaye iwaju.                      |
| `obsidian_delete_note`           | Pa akọsilẹ rẹ patapata lati inu ifinkan.                                                  |
| `obsidian_move_note`             | Gbe tabi fun lorukọ mii akọsilẹ laarin ile ifipamọ.                                       |
| `obsidian_execute_command`       | Ṣiṣe pipaṣẹ Obsidian kan nipasẹ aṣẹ rẹ ID.                                                |
| `obsidian_open_file`             | Ṣii faili ni Obsidian (ṣẹda rẹ ti ko ba si).                                              |
| `obsidian_sync_trigger`          | Ṣe okunfa tabili onidari-ọna lẹsẹkẹsẹ ↔ amuṣiṣẹpọ vault alagbeka.                         |
| `obsidian_sync_resolve_conflict` | Yanju rogbodiyan amuṣiṣẹpọ: tọju `local` (alagbeka), `remote` (tabili), tabi `keep-both`. |

> [!NOTE]
> awọn ibi-afẹde `obsidian_patch_note` gba `targetType` ti `heading | block | frontmatter` ati `operation` ti `append | prepend | replace`, pẹlu `createTargetIfMissing` yiyan. Awọn irinṣẹ `obsidian_sync_*` mẹrin naa sọrọ si olupin amuṣiṣẹpọ agbegbe (`http://127.0.0.1:27781` nipasẹ aiyipada) ati nilo ami amuṣiṣẹpọ.

### Awọn aaye

Awọn irinṣẹ kika nilo `read:obsidian`; Awọn irinṣẹ kọ nilo `write:obsidian`. Imudaniloju jẹ aami kanna si Notion — ti a ṣakoso nipasẹ `withScopeEnforcement()` ni `open-sse/mcp-server/server.ts`, ti a fi agbara mu lori `OMNIROUTE_MCP_ENFORCE_SCOPES=true` ati fi agbara mu fun awọn olupe HTTP/SSE ti bọtini API ko ni `manage`/`admin`, pẹlu awọn aaye ti a gba laaye ti o jade lati `OMNIROUTE_MCP_SCOPES` tabi aaye aaye aaye API naa. Wo [MCP-SERVER.md](./MCP-SERVER.md).

| `POST`   | `/api/settings/obsidian`        | Fi token pamọ́ + fìdí rẹ̀ múlẹ̀ (ó kọ port `27124`).         |
| `DELETE` | `/api/settings/obsidian`        | Já ìsopọ̀ (pa token tí a fi pamọ́ rẹ́).                      |
| `GET`    | `/api/settings/obsidian/webdav` | Ipò ìṣiṣẹ́pọ̀ WebDAV + àwọn ẹ̀rí ìwọlé (nígbà tí ó bá ṣiṣẹ́). |
| `POST`   | `/api/settings/obsidian/webdav` | Mú ìṣiṣẹ́pọ̀ WebDAV ṣiṣẹ́ fún àpò vault kan.                 |
| `DELETE` | `/api/settings/obsidian/webdav` | Pa ìṣiṣẹ́pọ̀ WebDAV.                                        |

> Àwọn wọ̀nyí jẹ́ àwọn route ètò dashboard. Vault fúnra rẹ̀ ni a ń dé sí nípasẹ̀ Obsidian
> Local REST API (`base_url` tí a ṣètò) àti nípasẹ̀ àwọn irinṣẹ́ MCP lókè — kò sí
> endpoint aṣojú Obsidian `/v1` fún gbogbo ènìyàn.

## Àwọn ọ̀nà lílò

- **Àwọn ìdáhùn tó dá lórí vault** — `obsidian_search_simple` / `obsidian_search_structured`
  lẹ́yìn náà `obsidian_read_note`, kí aṣojú lè dáhùn láti inú àwọn àkọsílẹ̀ gidi rẹ.
- **Kíkọ àkọsílẹ̀ / ìwé ìròyìn ojoojúmọ́** — `obsidian_write_note`, `obsidian_append_note`, tàbí
  `obsidian_patch_note` tó ń ṣe àtúnṣe pẹ̀lú ìṣọ́ra láti ṣàkọsílẹ̀ àbájáde aṣojú, àwọn àkótán, tàbí àwọn àkọsílẹ̀ ojoojúmọ́
  (`obsidian_get_periodic_note`) sínú vault.
- **Ìlọ kiri inú vault** — `obsidian_list_vault`, `obsidian_get_document_map`, àti
  `obsidian_get_tags` láti ṣàwárí ìṣètò rẹ̀ kí o tó kà/kọ.
- **Ìṣiṣẹ́ aládàáṣe Obsidian** — `obsidian_list_commands` + `obsidian_execute_command` láti
  ṣàkóso àwọn plugin/àṣẹ láti ọ̀dọ̀ aṣojú; `obsidian_open_file` láti fi àkọsílẹ̀ hàn nínú UI.
- **Ìṣiṣẹ́pọ̀ alágbèéká** — mú ìṣiṣẹ́pọ̀ WebDAV ṣiṣẹ́, lẹ́yìn náà `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`
  láti ṣètò ìṣiṣẹ́pọ̀ kọ̀ǹpútà tabili↔alágbèéká àti láti yanjú àwọn ìforígbárí.
