Traffic Inspector jẹ́ olùṣàwárí àṣìṣe ìṣàn HTTPS tí a kọ́ sínú OmniRoute — irinṣẹ́ bíi Charles Proxy / mitmweb / HTTP Toolkit tí ó **mọ nípa LLM** tí ó sì **mọ nípa agent**. Ó wà ní `/dashboard/tools/traffic-inspector`, ó sì ń gba ìṣàn alárìnà láti orísun ìgbàasilẹ tó tó 5 lẹ́ẹ̀kan náà.

**Ibi tó wà lórí dashboard:** `/dashboard/tools/traffic-inspector`
**Ẹgbẹ́ sidebar:** Àwọn irinṣẹ́ (lẹ́yìn AgentBridge)
**Tún wo:** [`AGENTBRIDGE.md`](./AGENTBRIDGE.md) — AgentBridge ni ipò ìgbàasilẹ 1.

### Àpẹrẹ ìṣètò rẹ̀ ní ìpínrọ̀ kan

`TrafficBuffer` (`src/mitm/inspector/buffer.ts`) jẹ́ ring buffer inú memory tí gbogbo apá ń lò (àìpéye rẹ̀ jẹ́ entries 1000, a lè ṣètò rẹ̀ nípasẹ̀ `INSPECTOR_BUFFER_SIZE`). Gbogbo àwọn orísun ìgbàasilẹ ló ń kọ sínú rẹ̀ nípasẹ̀ `push()`. Kiláàsì buffer náà ń pín entry kọ̀ọ̀kan sí ẹ̀ka nípa lílo `kindDetector.ts` (ó ń pinnu bóyá ìbéèrè LLM ni), ó ń ṣe ìṣirò `contextKey` kan (fingerprint SHA-256 ti system prompt), ó sì ń ṣe ìkéde sí gbogbo àwọn alabapin WebSocket nípasẹ̀ `globalTrafficBuffer.subscribe()`. Dashboard náà ń sopọ̀ nípasẹ̀ `GET /api/tools/traffic-inspector/ws`, ó sì ń gba snapshot nígbà tó bá sopọ̀, lẹ́yìn náà àwọn ìṣẹ̀lẹ̀ `new`/`update`/`clear` á tẹ̀ lé e.

## §2 Àwọn ìpo ìgbàwọ́

Traffic Inspector ṣe àtìlẹ́yìn fún **àwọn orísun ìgbàwọ́ 5 ní àkókò kan náà**. A lè tan tàbí pa ọ̀kọ̀ọ̀kan wọn lọ́tọ̀ọ̀tọ̀. Ààyè `source` lórí gbogbo `InterceptedRequest` (`src/mitm/inspector/types.ts`) jẹ́ ọ̀kan lára `"agent-bridge"`, `"custom-host"`, `"http-proxy"`, `"system-proxy"`, tàbí `"tproxy"`.

### Ìpo 1 — AgentBridge (àiyípadà, ó máa ń wà ní títàn nígbà gbogbo)

**Orísun:** Àwọn olùmúlò AgentBridge (`src/mitm/handlers/base.ts`)
**Ọ̀nà ìṣiṣẹ́:** Gbogbo ìpè `intercept()` nínú `MitmHandlerBase` máa ń pe `hookBufferStart()` kí ó tó fi ránṣẹ́ síwájú, ó sì máa ń pe `hookBufferUpdate()` nígbà tí ó bá parí. Kò nílò àfikún àtúnṣe kankan — ó bẹ̀rẹ̀ sí ṣiṣẹ́ lẹ́sẹ̀kẹsẹ̀ tí AgentBridge bá ti ń ṣiṣẹ́.
**Ìbùdó tí ó dé:** Àwọn aṣojú IDE 9 tí a ṣètò nínú AgentBridge
**Àkíyèsí:** Ààyè `source` nínú `InterceptedRequest` = `"agent-bridge"`

### Ìpo 2 — Àwọn Olùgbàlejò Àkànṣe (àtúnjúwe DNS)

**Orísun:** Àtòjọ olùgbàlejò tí olumulo ṣàlàyé (`inspector_custom_hosts` table)
**Ọ̀nà ìṣiṣẹ́:** Fífi olùgbàlejò kan kun nípasẹ̀ UI máa ń fi `127.0.0.1 <host>` kun `/etc/hosts` (ó nílò sudo). Sẹ́fà MITM AgentBridge tó ti wà tẹ́lẹ̀ (port 443) máa ń ṣe ìwé-ẹ̀rí SNI ní ìmúdàgba fún olùgbàlejò tuntun náà.
**Ìbùdó tí ó dé:** Ohun èlò èyíkéyìí tó ń lo olùgbàlejò tí a fikún — kò nílò ìyípadà àtúnṣe ohun èlò
**Àkíyèsí:** `source` = `"custom-host"`

Àwọn àpẹẹrẹ ibi tí a ti lè lò ó:

- Ṣàbójútó `api.openai.com` láti inú àwọn script Python
- Ṣàtúnṣe àṣìṣe `my-internal-llm.company.com`
- Gba ìrìn-ọ̀nà dátà láti àwọn ẹ̀rọ alágbèéká lórí nẹ́tíwọ́ọ̀kì kan náà (nípasẹ̀ ARP spoofing — ìpele gíga)

### Ìpo 3 — Olùgbọ́ HTTP_PROXY (port 8080)

**Orísun:** Àwọn ohun èlò tó ń lo àwọn environment variable `HTTP_PROXY`/`HTTPS_PROXY`
**Ọ̀nà ìṣiṣẹ́:** Olùgbọ́ kejì ní port 8080 (`src/mitm/inspector/httpProxyServer.ts`) tó ń ṣiṣẹ́ gẹ́gẹ́ bí proxy HTTP/HTTPS tí a ṣàlàyé ní tààrà. Ó gba àwọn tunnel `CONNECT` (HTTPS) àti àwọn ìbéèrè HTTP tààrà.
**Ìbùdó tí ó dé:** Ohun èlò èyíkéyìí tó ń tẹ̀lé env `HTTP_PROXY` — kò nílò ìyípadà DNS, kò sì nílò sudo
**Àkíyèsí:** `source` = `"http-proxy"`

```bash
# Ìgbàwọ́ kíákíá fún command kan ṣoṣo:
HTTPS_PROXY=http://127.0.0.1:8080 curl https://api.openai.com/v1/models

# Ìgbàwọ́ tí yóò máa bá a lọ nínú shell session kan:
export HTTP_PROXY=http://127.0.0.1:8080
export HTTPS_PROXY=http://127.0.0.1:8080
```

**Ìdíwọ̀n TLS:** HTTPS ń gba inú tunnel `CONNECT` lásán kọjá: olùgbọ́ náà máa ń ta àwọn byte tí a paroko síwájú láìfọwọ́ kàn wọ́n, yóò sì ṣe àkọsílẹ̀ metadata nìkan (olùgbàlejò, port, àkókò). Kì í tú ìparoko HTTPS láé, kò sì sí ètò kankan tó ń tan ìtúpalẹ̀ ìparoko fún ìpo yìí. Láti gba àwọn body HTTPS, darí olùgbàlejò náà gba Ìpo 1 (AgentBridge), Ìpo 2 (Àwọn Olùgbàlejò Àkànṣe) tàbí Ìpo 5 (ìtúpalẹ̀ ìparoko TPROXY).

**Ìforígbárí port:** Bí port 8080 bá wà ní lílò, AgentBridge máa dá 409 padà pẹ̀lú àṣìṣe tó ní ètò. Yí port náà padà nípasẹ̀ env var `INSPECTOR_HTTP_PROXY_PORT`.

### Ìpo 4 — Proxy jákèjádò ẹ̀rọ (ìpele gíga, yíyàn láti tan-an)

**Orísun:** Àwọn ètò proxy ní ìpele OS (ó kan gbogbo ohun èlò lórí ẹ̀rọ náà)
**Ọ̀nà ìṣiṣẹ́:** Ó ń lo àwọn API OS láti darí gbogbo ìrìn-ọ̀nà dátà HTTP/HTTPS gba inú olùgbọ́ HTTP_PROXY:

- **macOS:** `networksetup -setwebproxy / -setsecurewebproxy`
- **Linux:** `gsettings set org.gnome.system.proxy` + `/etc/environment`
- **Windows:** `netsh winhttp set proxy 127.0.0.1:8080`
  **Ìbùdó tí ó dé:** Gbogbo ohun èlò lórí ẹ̀rọ náà tó ń tẹ̀lé àwọn ètò proxy ẹ̀rọ
  **Àkíyèsí:** `source` = `"system-proxy"`

**Àwọn ìlànà ààbò:**

- Aago pípa aládàáṣe (ìyẹn jẹ́ ìṣẹ́jú 30 ní àiyípadà, a lè ṣètò rẹ̀ nípasẹ̀ `INSPECTOR_SYSTEM_PROXY_GUARD_MINUTES`)
- A máa ń fi ipò proxy ẹ̀rọ tẹ́lẹ̀ pamọ́ sínú DB, a sì máa ń mú un padà nígbà ìpadàsí
- Dashboard máa ń fi ìkìlọ̀ "Ń dá proxy ẹ̀rọ padà" hàn bí olumulo bá lọ kúrò ní ojú-ìwé nígbà tí ó ṣì ń ṣiṣẹ́
- UI máa ń fi àmì `⚠ Ìpele gíga` hàn + checkbox ìmúdájú tó ṣe kedere

### Ìpo 5 — Ìtúpalẹ̀ ìparoko transparent TPROXY (Linux, root, yíyàn láti tan-an)

**Orísun:** TPROXY kernel + policy routing (`src/mitm/tproxy/`)
**Ọ̀nà ìṣiṣẹ́:** Ó máa ń samisi àwọn ìsopọ̀ TCP tuntun tó ń jáde láti inú ẹ̀rọ lọ sí port àfojúsùn kan (àiyípadà `443`) nínú `mangle OUTPUT`, `ip rule` kan yóò tún darí àwọn packet tí a samisi lọ sí ìfijiṣẹ́ abẹ́nú, àfojúsùn `TPROXY` ti `mangle PREROUTING` yóò sì fi wọ́n lé olùgbọ́ transparent (**IP_TRANSPARENT**) kan lọ́wọ́ (port àiyípadà `8443`). Olùgbọ́ náà máa ń fòpin sí TLS pẹ̀lú ìwé-ẹ̀rí leaf tí CA ìmúdàgba kan pèsè **fún orúkọ olùgbàlejò SNI kọ̀ọ̀kan nígbà tí a bá nílò rẹ̀**, yóò gba pàṣípààrọ̀ tí a ti tú ìparoko rẹ̀, yóò sì fi ìbéèrè náà ránṣẹ́ síwájú, lẹ́yìn títún paroko rẹ̀, sí ibi àfojúsùn ìpilẹ̀ṣẹ̀.
**Ìbùdó tí ó dé:** Àwọn olùgbàlejò àfojúsùn **eyíkéyìí** lórí port àfojúsùn — kò nílò spoof `/etc/hosts`, env `HTTP_PROXY`, tàbí ìyípadà proxy jákèjádò ẹ̀rọ. Process tí a ń dènà kò nílò ìyípadà àtúnṣe kankan, ṣùgbọ́n ó gbọ́dọ̀ fọkàn tán CA ìmúdàgba náà.
**Àkíyèsí:** `source` = `"tproxy"`

**Àwọn ohun tí a nílò:** Linux nìkan (**IP_TRANSPARENT** wà fún Linux nìkan), agbára **CAP_NET_ADMIN** (root), àti addon N-API abinibi kan tí a gbọ́dọ̀ kọ́ pẹ̀lú C toolchain (`npm run build:native:tproxy`). Nígbà tí kò bá sí, a máa pa toggle dashboard náà pẹ̀lú tooltip "Ìtúpalẹ̀ ìparoko TPROXY nílò Linux + root + addon abinibi náà". Àwọn òfin firewall máa ń lò àti padà sí ipò tẹ́lẹ̀ gẹ́gẹ́ bí transaction (crash kò ní fi òfin `mangle` sílẹ̀ láé), wọ́n sì máa ń parẹ́ nígbà reboot. Anti-loop tó dá lórí SO_MARK ń dènà kí ìfiránṣẹ́-síwájú tí proxy fúnra rẹ̀ tún paroko má bàa tún jẹ́ dídènà.

Èyí jẹ́ subsystem ńlá kan tó ní ìtọ́sọ́nà olùdarí tirẹ̀ — wo `docs/security/MITM-TPROXY-DECRYPT.md` (git; a kò compile rẹ̀ sínú `/docs`) fún ẹ̀kúnrẹ́rẹ́ recipe firewall, CA ìmúdàgba fún SNI kọ̀ọ̀kan + olùfi trust-store sí ẹ̀rọ, route abẹ́nú nìkan, àwọn àlàyé anti-loop, àti schema àtúnṣe. `GET / POST / DELETE /api/tools/agent-bridge/tproxy` ni ó ń darí toggle náà (àkíyèsí: route náà wà lábẹ́ prefix AgentBridge, kì í ṣe prefix Traffic Inspector).

### 3.2 Àtòkọ ìbéèrè (pánẹ́ẹ̀lì òsì)

- **Tí a ṣe ní fọ́ọ̀mù afáráyé** (`useVirtualList` + `ResizeObserver`): ń bójú tó ohun 1000 láì di
- **Yíyí lọ fúnra rẹ̀** pẹ̀lú toggle láti dá a dúró nígbà àyẹ̀wò
- **Ipò tí a fi àwọ̀ yàtọ̀ síra**: àwọ̀ ewé (2xx), àwọ̀ ọ̀wọ̀ (3xx), pupa (4xx/5xx), eérú (tí ó ń lọ lọ́wọ́)
- **Emoji agent**: 🔵 Antigravity, 🟢 Copilot, 🟠 Kiro, 🟣 Codex, 🔷 Cursor, 🟤 Zed, 🟡 Claude Code, ⚫ Open Code, 🌐 host àkànṣe
- **Pẹpẹ àwọ̀ àyíká-ọ̀rọ̀**: ààlà òsì 1px tí a fi `contextKey` ṣe àwọ̀ rẹ̀ (SHA-256 ti system prompt) — ó ń ṣàkójọpọ̀ àwọn ìjíròrò tó jọra ní ojú
- **Body tí a ń gbé jáde nígbà tí a bá nílò rẹ̀**: body ìbéèrè tí a yàn nìkan ni a ń mú wá sínú àwọn taabu àlàyé (èyí dènà ṣíṣe render body 1000 × 1MB)

## §4 Àwọn ẹ̀ya tó mọ nípa LLM

### 4.1 Olùṣàwárí irú (`src/mitm/inspector/kindDetector.ts`)

Ó ń pín ìbéèrè kọ̀ọ̀kan sí `"llm"`, `"app"`, tàbí `"unknown"` nípa lílo àmì mẹ́rin:

1. **Àkọsílẹ̀ host** — ~18 orúkọ host API LLM tí a mọ̀ (OpenAI, Anthropic, Gemini, Groq, Mistral, Together, Fireworks, Cohere, Perplexity, Hugging Face, OpenRouter, xAI, Moonshot, àti bẹ́ẹ̀ bẹ́ẹ̀ lọ.)
2. **Àwọn àpẹẹrẹ path** — `/v1/chat/completions`, `/v1/messages`, `/generateContent`, `/v1/responses`, àti bẹ́ẹ̀ bẹ́ẹ̀ lọ.
3. **Ìrísí body** — ó ń ṣàwárí `messages[]` (OpenAI/Claude), `contents[]` (Gemini), àti àwọn field `prompt`, `input`
4. **Àwọn àmì user-agent** — `codex`, `claude`, `gemini`, `antigravity`, `kiro`, `copilot`, `cursor` nínú string UA

Àwọn host àkànṣe tí a fi kún un nípasẹ̀ Mode 2 máa ń jogún `kind` wọn láti inú input fọ́ọ̀mù (ìyẹn máa ń jẹ́ `"custom"` ní àìsí àtúnṣe).

### 4.2 Olùdapọ̀ SSE (`src/mitm/inspector/sseMerger.ts`)

**Ìmúṣẹ clean-room olómìnira.** Ṣíṣe parsing event tẹ̀lé
[alugoridimu event tí server ránṣẹ́ ti WHATWG](https://html.spec.whatwg.org/multipage/server-sent-events.html#parsing-an-event-stream),
nígbà tí àtúnkọ́ tẹ̀lé schema streaming gbangba ti [OpenAI](https://platform.openai.com/docs/api-reference/chat/create),
[Anthropic](https://platform.claude.com/docs/en/build-with-claude/streaming), àti
[Gemini](https://ai.google.dev/api/generate-content#method:-models.streamgeneratecontent).

Ó tún message ìkẹyìn ti assistant kọ́ láti inú àwọn event delta SSE àìṣẹ̀:

- **Anthropic**: ó ń kó `content_block_delta` jọ gẹ́gẹ́ bí index; ó ń bójú tó `text_delta`, `input_json_delta` (àwọn ìpè tool), `thinking_delta`
- **OpenAI**: ó ń kó àwọn choice/tool call Chat Completions àti àwọn output item Responses API jọ
  gẹ́gẹ́ bí index
- **Gemini**: ó ń kó `candidates[i].content.parts` jọ
- **Unknown**: ó dá àwọn event àìṣẹ̀ padà bí wọ́n ṣe rí

Tab Response fi toggle kan hàn: **"Àwọn event àìṣẹ̀ ↔ Tí a dapọ̀"**.

### 4.3 Olùṣe ìbánisọ̀rọ̀ di àwòṣe kan (`src/mitm/inspector/conversationNormalizer.ts`)

**Ìmúṣẹ clean-room olómìnira.** Àwọn contract black-box abẹ́nú àti schema message gbangba ti OpenAI, Anthropic, àti Gemini ni wọ́n ṣàlàyé normalization; a kò lo
source ìmúṣẹ upstream kankan.

Ó ń yí àwọn format message OpenAI, Anthropic, àti Gemini padà sí `NormalizedConversation` kan ṣoṣo kí rendering tó wáyé:

```ts
interface NormalizedConversation {
  request: NormalizedTurn[]; // àwọn message / content / prompt láti inú body ìbéèrè
  response: NormalizedTurn[]; // ìdáhùn assistant (tí a dapọ̀ nípasẹ̀ sseMerger)
  contextKey: string | null; // fingerprint SHA-256 ti system-prompt
}
```

Àwọn irú block: `text`, `tool_use`, `tool_result`. Tab Conversation máa ń lo ìrísí yìí láìka provider sí.

### 4.4 Fífi àwọ̀ sí context key (`src/mitm/inspector/contextKey.ts`)

- Ó ń ṣírò `SHA-256` ti system prompt (message `role:system` àkọ́kọ́, tàbí field `system`, tàbí `systemInstruction` Gemini)
- Ó ń dá prefix hex oníkọ̀ọ̀kan 12 padà (`"a3f9c2..."`)
- Frontend ń so key náà pọ̀ mọ́ àwọ̀ HSL tí kì í yí padà fún ọ̀pá ààlà òsì
- **Àlẹ̀mọ́ "context kan náà"**: títẹ chip `ctx #a3f` ń fi àlẹ̀mọ́ kan kún un láti fi àwọn ìbéèrè tó ní fingerprint kan náà nìkan hàn

Èyí mú kó rọrùn láti fi ojú ṣe ìyàtọ̀ láàárín onírúurú "persona" tàbí iṣẹ́ tó ń ṣiṣẹ́ nínú session agent kan náà.

### 4.5 Yíyọ metadata LLM jáde

Fún àwọn ìbéèrè LLM, tab LLM Details ń yọ àwọn wọ̀nyí jáde:

```ts
interface LlmMetadata {
  provider: string | null; // "openai" | "anthropic" | "gemini" | ...
  apiKind: string | null; // "chat.completions" | "messages" | "embeddings" | ...
  model: string | null; // láti inú body ìbéèrè tàbí ìdáhùn
  messages: number; // iye àwọn turn
  tokensIn: number | null; // usage.prompt_tokens / usage.input_tokens
  tokensOut: number | null; // usage.completion_tokens / usage.output_tokens
  streamed: boolean; // true bí ó bá jẹ́ ìdáhùn SSE
  mappedTo: string | null; // header x-omniroute-mapped
  costEstimateUsd: number | null; // ìṣírò owó tí a fojú díwọ̀n lórí ìdíyelé OmniRoute
}
```

### 4.6 Àlẹ̀mọ́ ìbéèrè in-flight lọ́wọ́lọ́wọ́

Field `status` ti ìbéèrè jẹ́ `number | "in-flight" | "error"` — a máa ń fi entry kan ránṣẹ́ gẹ́gẹ́ bí `"in-flight"` ní kété tí ìbéèrè bá bẹ̀rẹ̀, a sì máa ń **ṣe àfikún rẹ̀ ní ibi kan náà**
nígbà tí ìdáhùn (tàbí àṣìṣe) bá dé. Toggle **"Live"** inú toolbar
(`liveOnly`, key i18n `trafficInspector.liveOnly`) máa ń dí àtòkọ náà mọ́ àwọn entry
tí `status === "in-flight"` wọn, èyí tó ń jẹ́ kó o lè wo àwọn connection tó ṣí sílẹ̀ ní àkókò gidi.

Àlẹ̀mọ́ náà jẹ́ predicate client-side lásán nínú
`src/lib/inspector/matchesTrafficFilter.ts`:

```ts
if (f.liveOnly && req.status !== "in-flight") return false;
```

State toggle náà wà nínú `useTrafficFilters` (àwọn hook dashboard inspector), ó sì
ń darapọ̀ mọ́ àwọn àlẹ̀mọ́ yòókù (profile, host, agent, source, status, context).

### 4.7 Ìsọ̀rí process tó fa ìbéèrè (Linux)

Lórí Linux, a lè so ìbéèrè kọ̀ọ̀kan tí a dádúró mọ́ **process abẹ́nú tó pilẹ̀ rẹ̀**.
Àwọn field àṣàyàn méjì ni a fi kún `InterceptedRequest`:

```ts
pid?: number;          // id process tó pilẹ̀ rẹ̀ (Linux nìkan)
processName?: string;  // orúkọ process tó pilẹ̀ rẹ̀ (Linux nìkan)
```

`src/mitm/inspector/processAttribution.ts` ń so ephemeral port _client_ ti connection náà
mọ́ PID + orúkọ nípa:

1. Kíka `/proc/net/tcp` àti `/proc/net/tcp6` láti rí inode socket fún
   port náà (`parseProcNetTcpForInode`, parser mímọ́ tí a lè fi fixture dánwò).
2. Ṣíṣàyẹ̀wò `/proc/<pid>/fd/` fún symlink kan sí `socket:[<inode>]`.
3. Kíka orúkọ process láti `/proc/<pid>/comm`.

Cache TTL ìṣẹ́jú-àáyá 1 ń dín iye owó scan procfs kù lábẹ́ ẹrù. Ìsọ̀rí náà jẹ́
**ìgbìyànjú-tó-dára-jù** — ìkùnà èyíkéyìí máa ń yọrí sí `null`, kò sì ní dí capture dúró láé. Lórí
macOS/Windows, function náà ń dá `null` padà (stub; àtìlẹ́yìn `lsof`/`GetExtendedTcpTable`
jẹ́ iṣẹ́ tó máa tẹ̀lé).

- Àsíá kan yóò fi hàn: `Ń wo sáẹ́ṣọ̀nù tí a gbà sílẹ̀ "<name>" — [Padà sí ìṣàn aláàyè]`
- Táàbù Àwọn Ìṣirò yóò wà fún lílò pẹ̀lú àwọn àkójọpọ̀ Recharts

### 5.3 Àwọn ọ̀nà àgbéjáde

A lè gbé sáẹ́ṣọ̀nù kọ̀ọ̀kan jáde gẹ́gẹ́ bí:

| ------------------------ | ------------------------------------------------------------------------------ |
| **HAR** (Àpamọ́ HTTP 1.2) | Ó bá Chrome DevTools, Charles, Fiddler mu — gbé e wọlé fún ìtúpalẹ̀ láìsí àsopọ̀ |

## §6 Ààbò

Traffic Inspector ń ṣàfihàn **gbogbo ìbánisọ̀rọ̀ HTTPS tí a dáwọ́ dúró**, pẹ̀lú àwọn àkọlé ìfúniláṣẹ àti àwọn ara ìbéèrè. Àwọn ìṣàkóso wọ̀nyí wà ní mímúlò:

| Ìṣàkóso                          | Àwọn àlàyé                                                                                                                                                                |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **LOCAL_ONLY**                   | Gbogbo àwọn ipa-ọ̀nà àti ibi ìparí WebSocket jẹ́ fún loopback nìkan (a fipá mú un ṣiṣẹ́ nínú `routeGuard.ts` ṣáájú ìfàṣẹsí)                                                  |
| **Ìbòjú bo àṣírí**               | Ẹ̀rọ àyẹ̀wò Linear `maskSecret()` ń pa àwọn ẹ̀rí Bearer RFC 6750, àwọn kọ́kọ́rọ́ tí ìpele olùpèsè wà níwájú wọn àti àwọn token aláìṣèdámọ̀ gígùn mọ́ ṣáájú `TrafficBuffer.push()` |
| **Òpin ìwọ̀n ara**                | Àwọn ara > `INSPECTOR_MAX_BODY_KB` (àìyípadà 1024 KB) ni a ké kúrú pẹ̀lú àkíyèsí `"(a ké e kúrú fún ìṣiṣẹ́ tó dára)"`                                                       |
| **Ìsọdimímọ́ àkọlé**              | A sọ àwọn orúkọ di lẹ́tà kékeré; a yọ àwọn àkọlé framing/hop-by-hop àti proxy-auth kúrò; a pa àwọn cookie mọ́ pátápátá; àwọn iye ẹ̀rí ń fi iṣẹ́ lé `maskSecret()` lọ́wọ́        |
| **CSP**                          | Content Security Policy tó le lórí àwọn ojúewé Traffic Inspector láti dènà XSS nípasẹ̀ àwọn ara ìdáhùn tí a fi sínú rẹ̀                                                     |
| **Kò sí ìtọ́jú pípẹ́ ní àìyípadà** | `TrafficBuffer` wà nínú ìrántí, ó sì máa ń sọnù nígbà tí olupin bá tún bẹ̀rẹ̀. A máa ń tọ́jú àwọn session sí ibi pípẹ́ nígbà tí a bá ṣe àkọsílẹ̀ wọn ní pàtó nìkan             |

### Àwọn ààlà tí a mọ̀

- **Ìpo proxy jákèjádò ètò** ń ní ipa lórí gbogbo àwọn ohun èlò lórí ẹ̀rọ náà, pẹ̀lú àwọn client VPN àti SSO. Máa lò ó nígbà gbogbo pẹ̀lú aago ìdádúró aládàáṣiṣẹ́. Má ṣe lò ó lórí àwọn ẹ̀rọ tí ọ̀pọ̀ ènìyàn ń pín lò.
- **CONNECT tunnel HTTPS**: Ìpo 3 (HTTP_PROXY) ń gba metadata tunnel nìkan fún àwọn ibi-àfojúsùn HTTPS, kò sì ní tú ìfipamọ́ wọn láé. Èyí jẹ́ gẹ́gẹ́ bí a ṣe ṣe àpẹrẹ rẹ̀ — títú ìfipamọ́ yóò béèrè pé kí gbogbo client fọkàn tán ìwé-ẹ̀rí MITM kan, nítorí náà listener náà ń jẹ́ kí HTTPS wà ní ìfipamọ́ láti ìbẹ̀rẹ̀ dé òpin. Lo AgentBridge, Custom Hosts tàbí ìtú ìfipamọ́ TPROXY nígbà tí o bá nílò àwọn ara HTTPS.
- **Àwọn ọ̀rọ̀ tí a kọ taárata sínú àwọn component kan**: Àwọn component UI kan (F7/F8) ní iye díẹ̀ ti àwọn ọ̀rọ̀ tí a kọ taárata sínú wọn, tí àwọn kọ́kọ́rọ́ i18n kò tíì bo. A ṣàkọsílẹ̀ àwọn wọ̀nyí gẹ́gẹ́ bí Ààlà Tí A Mọ̀ nínú ìjábọ̀ àlàfo i18n; a ó ṣí wọn lọ ní ìpele iṣẹ́ àtẹ̀lé. Àwọn ọ̀rọ̀ tí èyí kan jẹ́ àwọn àmì ìṣọ̀ṣọ́ UI tí kò nílò ìtumọ̀ fún lílò iṣẹ́.

## §7 Yíyanjú ìṣòro

### Ìjáwọ́ WebSocket

Tí ìṣàn àyè-gidi bá fi "Asopọ̀ ti já" hàn:

1. Ṣàyẹ̀wò pé olupin ṣì ń ṣiṣẹ́: `GET /api/tools/traffic-inspector/capture-modes`
2. Tún ojúewé náà gbé — WebSocket yóò tún sopọ̀, yóò sì gba àwòrán-ipò tuntun
3. Tí a bá tún olupin náà bẹ̀rẹ̀, búfà inú ìrántí ti di mímọ́ — àwọn àkọọlẹ̀ àtijọ́ ti sọnù àyàfi tí a bá gba sáṣọ̀n kan sílẹ̀

### Ìforígbárí ibùdó 8080

Tí módù HTTP_PROXY kò bá le bẹ̀rẹ̀:

```bash
lsof -i :8080    # wá ìlànà iṣẹ́ náà
```

Yí ibùdó náà padà:

```bash
# .env
INSPECTOR_HTTP_PROXY_PORT=8888
```

### Aṣojú ẹ̀rọ tí a kò dá padà

Tí OmniRoute bá já lulẹ̀ nígbà tí módù aṣojú gbogbo ẹ̀rọ ń ṣiṣẹ́:

**macOS:**

```bash
networksetup -setwebproxystate Wi-Fi off
networksetup -setsecurewebproxystate Wi-Fi off
```

**Linux (GNOME):**

```bash
gsettings set org.gnome.system.proxy mode 'none'
```

**Windows:**

```cmd
netsh winhttp reset proxy
```

Dasibodu náà yóò tún fúnni ní "Dá aṣojú ẹ̀rọ padà" nígbà tí a bá tún gbé e lẹ́ẹ̀kan sí i, tí ó bá rí i pé ipò DB fi hàn pé aṣojú náà ń ṣiṣẹ́.

### Búfà ti kún

Nígbà tí búfà bá dé `INSPECTOR_BUFFER_SIZE` (àìyípadà rẹ̀ ni 1000), àwọn àkọọlẹ̀ tuntun yóò yọ àwọn èyí tí ó ti pé jù lọ kúrò. Tí àwọn ìbéèrè pàtàkì bá ń sọnù:

- Ṣàfikún `INSPECTOR_BUFFER_SIZE` (fún àpẹẹrẹ, 5000) — èyí ń fi ìrántí pàṣípààrọ̀ fún ìdádúró dátà
- Gba sáṣọ̀n kan sílẹ̀ láti tọ́jú àkókò tó yẹ sínú DB

## §8 Ìtọ́kasí API

Gbogbo àwọn route jẹ́ `LOCAL_ONLY` (loopback nìkan) àti `SPAWN_CAPABLE` (àwọn àṣẹ proxy ètò). Wo `src/server/authz/routeGuard.ts`.

Ọ̀nà ìpìlẹ̀: `/api/tools/traffic-inspector/`

### Ìṣàkóso ìbéèrè

| Ọ̀nà    | Path                        | Àpèjúwe                                                                                  |
| ------ | --------------------------- | ---------------------------------------------------------------------------------------- |
| GET    | `/requests`                 | Ṣàkójọ àwọn ìbéèrè (a lè ṣàlẹ̀mọ́: `?profile=llm&host=&agent=&status=&source=&sessionId=`) |
| GET    | `/requests/{id}`            | Àwọn àlàyé ìbéèrè kan ṣoṣo                                                               |
| DELETE | `/requests`                 | Pa buffer inú-memory rẹ́                                                                  |
| POST   | `/requests/{id}/replay`     | Ṣi ìbéèrè kan náà ṣiṣẹ́ lẹ́ẹ̀kan sí i nípasẹ̀ router OmniRoute                               |
| PUT    | `/requests/{id}/annotation` | Fi àkọsílẹ̀ kan lórí ìbéèrè pamọ́ tàbí ṣe àfikún rẹ̀                                        |
