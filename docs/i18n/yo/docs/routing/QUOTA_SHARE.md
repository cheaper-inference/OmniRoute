## Àkíyèsí gbogbogbò

Ẹ́ńjìnnì Pípín Ìwọ̀n-àyè ń pín ìwọ̀n-àyè tó dá lórí àkókò ti olupèsè kan (fún àpẹẹrẹ, Codex
fèrèsé wákàtí 5, Kimi 1500 req/h) lọ́nà tó dọ́gba láàárín ọ̀pọ̀ kọ́kọ́rọ́ API tí wọ́n ń lo
àsopọ̀ kan náà.

**Ìṣòro tí ó ń yanjú:** OmniRoute ń ṣe aṣojú ọ̀pọ̀ kọ́kọ́rọ́ API sí àkọọ́lẹ̀ olupèsè
ókè kan náà. Láìsí ọgbọ́n pípín, ìṣàn ńlá láti ọ̀dọ̀ kọ́kọ́rọ́ A lè lo gbogbo
ìwọ̀n-àyè olupèsè fún wákàtí náà tán, tí yóò sì mú kí àwọn kọ́kọ́rọ́ B àti C di dídènà títí fèrèsé náà yóò fi tún bẹ̀rẹ̀.
Ẹ́ńjìnnì náà ń dènà èyí nípa:

1. Títọpinpin ìlò yíyípo kọ́kọ́rọ́ kọ̀ọ̀kan fún ìwọ̀n kọ̀ọ̀kan (%, àwọn ìbéèrè, àwọn token, $).
2. Lílo algoridimu ìpín-dọ́gba tó ń lo gbogbo agbára tó wà: kọ́kọ́rọ́ kan lè yá láti inú àwọn ìpín
   tí a kò lò nígbà tí àkójọpọ̀ gbogbogbò kò tíì kún.
3. Mímú àbájáde náà ṣẹ ní ọ̀nà ìṣiṣẹ́ pàtàkì (`chatCore.ts`) kí ìbéèrè náà tó
   dé ọ̀dọ̀ olùṣiṣẹ́ òkè.

## Algoridimu: Fair-Pin Ise-Itọju

Ti ṣe ni `src/lib/quota/fairShare.ts`.

### Awọn ọna

| Ipo                                        | Ipo           | Iwa                                               |
| ------------------------------------------ | ------------- | ------------------------------------------------- |
| `globalUsedPercent < saturationThreshold`  | **Oninurere** | Bọtini le yawo titi di opin agbaye iyokuro lapapọ |
| `globalUsedPercent >= saturationThreshold` | **Ti o muna** | Fi ipa mu ipin itẹtọ ẹni kọọkan muna              |

`saturationThreshold = 0.5` aiyipada (env `QUOTA_SATURATION_THRESHOLD`).

Awọn ipo meji wọnyi ṣe apejuwe adagun-odo kan ni ipo yiya aiyipada, `saturation`. A pool ni ipo `consent` nigbagbogbo lo awọn ofin ti o muna, ohunkohun ti ekunrere. Wo [ayanilowo ti a gba (ijade-inu adagun-odo kọọkan)](#consented-lending-per-pool-opt-in).

### Fun-onisẹpo ipinnu

Fun iwọn kọọkan ti nṣiṣe lọwọ ninu adagun-odo, ẹrọ naa ṣe iṣiro:

```
fairShareAllowed = poolLimit × (allocationWeight / 100)
consumed        = current rolling value for this key (from QuotaStore.peek)
remaining       = fairShareAllowed - consumed
```

Fun awọn iwọn `percent`, `consumed` wa lati inu iwe iyasọtọ dipo (wo [Iwọn Ogorun: ikasi-bọtini](#percent-dimensions-per-key-attribution) ).

Lẹhinna:

- **`policy = hard`** : ti o ba `consumed > fairShareAllowed` ati mode jẹ ti o muna →** Àkọsílẹ** .
- **`policy = soft`** : ti o ba `consumed > fairShareAllowed` ati mode jẹ ti o muna →** ijiya** (deprioritize ni konbo; kò lile-Àkọsílẹ).
- **`policy = burst`** : gba nigba ti agbaye headroom wa laiwo ti itẹ ipin.

### Fila aboluto

`capValue` + `capUnit` lori ipin jẹ aja lile ti o ni ominira ti ipo tabi eto imulo. Eyikeyi apa miran ibi ti `consumed >= capValue` nigbagbogbo** ohun amorindun** ìbéèrè naa. Fun fila `percent`, `consumed` jẹ apakan nikan ti a da si bọtini.

### Ayẹwo iwọn-pupọ

A ìbéèrè ti wa ni dina ti o ba ti** eyikeyi** iwọn ninu awọn pool yoo dènà o. Awọn iwọn jẹ ominira — a 5h% exhaustion ko ni ipa lori iwọn-ọsẹ%% ni ọsẹ.

### Yiya

Ni ipo oninurere, bọtini kan ti ipin rẹ ti ko ni agbara le lo iyọkuro lati awọn ipin ti a ko pin si awọn bọtini miiran. Ilana naa jẹ:

```
maxAllowed = globalLimit - consumedByOtherKeys
```

nibiti `consumedByOtherKeys = consumedTotal - consumedByThisKey`. Teto agbaye (pool `limit` fun iwọn naa) nigbagbogbo jẹ aja lile.

### Yiya ti a gba (ijade-wọle fun adagun-odo kọọkan)

Kọọkan pool ni o ni a yiya mode. `saturation` jẹ aiyipada ati pe o tọju awọn ofin loke. Ni ipo `consent` bọtini `hard` kan kọja ipin rẹ nikan laarin agbara ti awọn bọtini miiran gba lati yani. Alakoso ṣeto ipo ti adagun-odo kọọkan. Olukọni bọtini dimu ṣeto igbanilaaye tiwọn nipasẹ [igbanilaaye Yiya](#lending-consent).

Iyọọda jẹ ipin kan lati 0 si 100 ati akoko ipari yiyan ni awọn milliseconds epoch. Bọtini naa ṣe awin ipin ogorun ti ipin laišišẹ lakoko ti akoko ipari wa ni ọjọ iwaju.

Fun iwọn kan, `L` jẹ opin ti o munadoko: eto iye akoko awọn akọọlẹ ninu adagun-odo. Ẹnu-ọna ṣe iṣiro, fun bọtini ti nbere:

```
share_k         = w_k / 100 × L
idle_k          = max(0, share_k − consumed_k)
lent            = Σ over the other keys of lend_k / 100 × idle_k
taken           = Σ over the other keys of max(0, consumed_k − share_k)
borrowAvailable = max(0, lent − taken)
```

`w_k` ni bọtini iwuwo, tabi `100 / n` fun gbogbo bọtini nigbati ko si àdánù jẹ loke 0. `lend_k` ni awọn bọtini ti nṣiṣe lọwọ ogorun, ati 0 ni kete ti awọn oniwe-ipari ti koja. Iyọọda ti bọtini ti n beere funrarẹ ko ṣe pataki. Bọtini `hard` kan kọ ni kete ti agbara rẹ ba de ipin rẹ pẹlu `borrowAvailable`.

Agbara ti ko si awọn ẹtọ ipinpin (100 iyokuro apapọ awọn iwuwo) kii ṣe ayanilowo. Ko si bọtini ti o gba lati yani.

**Apeere.** `L` jẹ 1000.

| Bọtini | Iwọn | Pin | Jeje | Awọn awin |
| ------ | ---- | --- | ---- | --------- |
| A      | 50   | 500 | 530  | 0%        |
| B      | 30   | 300 | 100  | 50%       |
| C      | 0    | 0   | 60   | 0%        |

- B lends 50% ti 200 laišišẹ, ti o jẹ 100. C tẹlẹ mu 60 loke ipin rẹ. A le yawo 40.
- A ṣe iranṣẹ ni 530 ati kọ ni kete ti agbara rẹ ba de 540.
- Ṣaaju ki C to lo ohunkohun, pẹlu A ni tabi labẹ ipin rẹ, C le yawo 100.
- Ṣaaju ki C to lo ohunkohun, pẹlu A ni 530, C le yawo 70.

**Iwọn odo.** Bọtini pẹlu iwuwo 0 ni ipin kan ti 0. O jẹ iṣẹ nikan nigbati agbara rẹ wa labẹ ohun ti awọn miiran ya. Nigbati ko si ẹnikan ti o yawo, a kọ lati ibeere akọkọ rẹ.

**Awọn akoko ipari.** Ko si iṣẹ abẹlẹ ti o pari aṣẹ kan. Ibeere kọọkan ṣe afiwe akoko ipari pẹlu akoko tirẹ, ati akoko ipari ti o dọgba si akoko yẹn ti kọja. Akoko ipari ti o fipamọ ti kii ṣe nọmba ti o lopin, tabi ti kọja ọjọ ti o tobi julọ ti `Date` le mu, ṣe iṣiro bi o ti kọja.

**`soft` ati `burst`.** Yiya ko ni idinwo wọn. Bọtini `soft` kan ti yọkuro ni kete ti o ti kọja ipin rẹ. Bọtini `burst` kan kọja lakoko ti adagun-odo ni yara. Aja pool si tun kọ gbogbo bọtini ni kete ti awọn pool ká lapapọ Gigun awọn oniwe-ipin.

**Iye owo lori ọna ibeere.** Adagun `saturation` kan ko ka nkankan ju ti iṣaaju lọ. Ninu adagun-odo `consent` kan, iwọn kika kika awọn bọtini miiran nikan fun bọtini `hard` ni tabi loke ipin rẹ nigba ti bọtini miiran yani. Lẹhinna o ṣe kika kan fun bọtini miiran, ni afiwe. Kika kika ti o kuna bi agbara 0 fun bọtini yẹn. Iwọn `percent` kan ko ṣe afikun kika, nitori pe iwe iyasọtọ di gbogbo bọtini mu.

**Nsatunkọ awọn a pool.** Ṣatunkọ ntọju igbanilaaye ti awọn bọtini ti o duro. Eyi duro fun awọn atunṣe ipin, awọn rirọpo jakejado ẹgbẹ ati awọn ipe `ensure`. Bọtini ti a yọ kuro npadanu igbanilaaye rẹ, ati bọtini ti a fi kun pada bẹrẹ ni 0. Awọn ipa-ọna abojuto pada iyọọda bọtini kọọkan ati pe ko kọ ọ rara. Yipada adagun-odo pada si `saturation` ntọju gbogbo igbanilaaye ti o fipamọ, eyiti ko ni ipa ni ipo yẹn. Yiyipada adagun-odo si `consent` lẹẹkansi tun mu awọn igbanilaaye ti o fipamọ ṣiṣẹ ti akoko ipari wọn ko ti kọja. Dimu bọtini kan le nu ifọkansi ti o fipamọ kuro ni ipo boya.

**Igbegasoke.** Ti awọn ọwọn `lending_percent` ati `lending_until` ti wa tẹlẹ, iṣiwa naa ṣafikun `borrow_mode` nikan , ati pe awọn ipin ogorun ti o fipamọ duro bi wọn ṣe wa. Gbogbo adagun bẹrẹ ni ipo `saturation`. Tan `consent` fun adagun-odo ni oluṣeto adagun-odo. Ko si ohun ti a ni oye lati awọn iye ti o fipamọ.

**Awọn idiwọn.**

- Oluyalowo le wa adagun omi ni aja rẹ ṣaaju lilo ipin tirẹ. Agbara ti awọn miiran yawo ni iye si apapọ adagun-odo naa.
- Ṣayẹwo naa n ṣiṣẹ ṣaaju ibeere ati pe ko ni ifipamọ ohunkohun. Awọn ibeere igbakọọkan ka agbara ṣaaju ki o to gbasilẹ eyikeyi, nitorinaa agbara yiya le ṣee lo diẹ sii ju ẹẹkan lọ, ni opin nipasẹ awọn ibeere ni ọkọ ofurufu. Ayẹwo ipin ti ipo `saturation` ni ohun-ini kanna.

## Ẹ̀rọ Ìṣírò Fèrèsé Yíyípo

A ṣe àgbékalẹ̀ rẹ̀ nínú `src/lib/quota/sqliteQuotaStore.ts` àti `redisQuotaStore.ts`.

Àpò méjì fún `(apiKeyId, dimensionKey)` kọ̀ọ̀kan:

- `curr`: àpò lọ́wọ́lọ́wọ́ (`floor(nowMs / windowMs)`)
- `prev`: àpò tó ṣáájú (`curr - 1`)

Iye yíyípo tó fẹsẹ̀ múlẹ̀:

```
effectiveBucketIndex = floor(nowMs / windowMs)
bucketStartMs        = effectiveBucketIndex × windowMs
elapsed              = nowMs - bucketStartMs
weight               = 1 - elapsed / windowMs

effective = prev × weight + curr
```

**Ìpéye**: ó pé tó ~99%. Àṣìṣe náà kò ju 1% ti ìwọ̀n fèrèsé lọ ní
ààlà láàárín àwọn àpò (èyí jẹ́ àbùdá àfojúsùn àpò méjì náà).

### Ìṣiṣẹ́ pọ̀ lẹ́ẹ̀kan náà

Díràìfà SQLite: mutex inú ìrántí fún kọ́kọ́rọ́ `(apiKeyId | dimensionKey)` kọ̀ọ̀kan ń dènà
ìjà read-modify-write. Àpẹẹrẹ náà dà bí ọgbọ́n anti-thundering-herd nínú `src/sse/services/auth.ts`.

Díràìfà Redis: Lua EVAL script fún ìfikún atomiki — ó ń ṣiṣẹ́ gẹ́gẹ́ bí àṣẹ Redis kan ṣoṣo.

## Àwọn awakọ̀

### SQLite (àìyípadà, kò nílò ìfiṣọ́lẹ̀)

- Tábìlì: `quota_consumption` (wo ìṣíkiri `073_quota_pools.sql` / `074_quota_consumption.sql`).
- Ó dára jù fún àwọn ìmúṣiṣẹ́lẹ̀ ẹ̀dà kan ṣoṣo.
- Gbogbo ìtọ́jú dátà wà nínú DB SQLite OmniRoute tó ti wà tẹ́lẹ̀ (`DATA_DIR/storage.sqlite`).

### Redis (àṣàyàn, ọ̀pọ̀ ẹ̀dà)

- Ó nílò package npm `ioredis`.
- Àwọn kàǹtà ni a tọ́jú sínú Redis; metadata (àwọn pool/allocation) ṣì wà nínú SQLite.
- Ó dára jù fún àwọn ìmúṣiṣẹ́lẹ̀ aláfẹ̀dà-púpọ̀ níbi tí àwọn kàǹtà gbọ́dọ̀ jẹ́ pínpín.

### Yíyí àwọn awakọ̀ padà

Nípasẹ̀ UI ètò (`/dashboard/settings` → Ibi Ìtọ́jú Quota), tàbí nípasẹ̀ àwọn env vars:

```bash
QUOTA_STORE_DRIVER=redis
QUOTA_STORE_REDIS_URL=redis://localhost:6379
```

Ètò DB ní ààyò ju env lọ. Bí `driver=redis` ṣùgbọ́n URL kò sí tàbí
a kò fi `ioredis` sílẹ̀, factory náà yóò padà sí SQLite, yóò sì ṣàkọsílẹ̀ ìkìlọ̀ kan.

Ètò àṣàyàn awakọ̀:

1. Ètò DB `quotaStore.driver`
2. Env `QUOTA_STORE_DRIVER`
3. Àìyípadà: `sqlite`

## Olona-Dimension

A pool le ni ọpọ iwọn. Iwọn kọọkan jẹ ominira:

```ts
QuotaDimension {
  unit: "percent" | "requests" | "tokens" | "usd",
  window: "5h" | "hourly" | "daily" | "weekly" | "monthly",
  limit: number,  // global pool ceiling for this dimension
}
```

**Apeere: Codex** (5h% + osẹ-ọsẹ%):

```json
[
  { "unit": "percent", "window": "5h", "limit": 100 },
  { "unit": "percent", "window": "weekly", "limit": 100 }
]
```

Ibeere gbọdọ ni itẹlọrun gbogbo awọn iwọn lati gba laaye.

### Iwọn ogorun: fun-bọtini ikalara

Eto ida kan ṣe ijabọ eeya lilo kan fun akọọlẹ kan ati window ero. Olupese ko funni ni counter fun bọtini API.

Lati pin eeya yẹn laarin awọn bọtini, adagun-odo kọọkan tọju iwe iyasọtọ fun akọọlẹ ati window ero. `src/lib/quota/percentLedger.ts` di awọn ofin iwe. `src/lib/quota/percentAttribution.ts` yi iwe pada sinu awọn nọmba ti agbofinro nlo. Abajade jẹ iṣiro ti a ṣe lati awọn ami ami kọọkan awọn ipa-ọna bọtini.

#### Awọn kika ti o gbe iwe naa

Iwe naa n gbe nikan lori nọmba ti olupese fun ferese ero ti o beere. Awọn asopọ wọnyi jabo ọkan:

| Olupese                        | Gbero windows  |
| ------------------------------ | -------------- |
| Claude, nipasẹ ọna asopọ OAuth | `5h`, `weekly` |
| Codex                          | `5h`, `weekly` |

Iwọnyi ko ka bi kika:

- esi ti awọn olupese ni ose samisi bi stale
- window Claude ti ipin ogorun olupese ko jabo
- eeya window miiran, tabi ọran ti o buru julọ kọja awọn window
- akọsori-opin-oṣuwọn fallback
- a kuna kika

Awọn olupese miiran, pẹlu Claude pẹlu bọtini API, ko ni iwe. Bọtini kọọkan ni idiyele 0 lori awọn iwọn ogorun wọn, bi ṣaaju iyipada yii.

Iwe kika kan pin kaṣe iṣẹju-aaya 30 ti ifihan itẹlọrun. Kika Claude kan jẹ ọjọ nipasẹ igba ti a ṣe akiyesi nọmba naa ni awọn akọle idahun tabi ka lati aaye ipari lilo, nigbati akoko yẹn ba mọ. Awọn iwe kika miiran jẹ ọjọ nipasẹ igba ti a ti kọ titẹsi kaṣe yẹn.

#### Ohun ti iwe ntọju

Ibeere kọọkan ti o gbasilẹ ṣafikun awọn ami rẹ, lẹẹkan, si counter fun adagun-odo, akọọlẹ ati bọtini. A counter nikan dagba. Iwe naa tọju awọn nkan mẹta:

- awọn ipetele: olusin nigbati awọn iwe la tabi awọn window kẹhin yipada
- kẹhin loo olusin
- fun bọtini, counter tokini rẹ ni akoko kanna, ti a npe ni ami rẹ

Iwe naa ti ni imudojuiwọn nigbati imuse tabi ipa ọna lilo ṣe iṣiro ifaramọ naa. Awọn kikọ ti wa ni afiwe-ati-ṣeto lori nọmba atunyẹwo. Onkọwe ti o padanu tun gbiyanju lẹẹkan lori kika tuntun.

#### Bawo ni apakan bọtini kan ṣe iṣiro

Apa bọtini kọọkan jẹ iṣiro nigbati a ba ka iwe naa. Idagba ti eeya naa lati igba ti ipilẹ ti pin laarin awọn bọtini ni ibamu si awọn ami ti ọkọọkan ti ipa-ọna lati aami rẹ.

Together, awọn ami wọnyi ṣe alaye ni pupọ julọ aaye kan ti nọmba fun awọn ami `QUOTA_PERCENT_MIN_TOKENS_PER_POINT` (aiyipada 1,000). Idagba ti wọn ko ṣe alaye jẹ ita. Ipilẹ jẹ ita paapaa.

Fun apẹẹrẹ, iwe kan ṣii ni 0. Key A lẹhinna awọn ọna 900,000 awọn ami-ami ati awọn ọna B bọtini 100,000. Ni nọmba kan ti 60, apakan A jẹ awọn aaye 54 ati apakan B jẹ 6.

Atako ti o wa ni isalẹ aami bọtini rẹ ti tun bẹrẹ o si ka ni kikun. Bọtini ti ko ni aami kan, gẹgẹbi bọtini ti o darapọ mọ adagun ni arin window kan, ka gbogbo awọn ami rẹ. A olusin ti o lags aami fa aṣiṣe ti o lọ kuro ni nigbamii ti kika. Ko kojọpọ.

`QUOTA_PERCENT_MIN_TOKENS_PER_POINT` ti wa ni ka lori gbogbo ikalara. Iye ti kii ṣe nọmba ipari ti o kere ju 1 ṣubu pada si 1,000.

#### Bawo ni kika ṣe yipada iwe naa

Ofin ibamu akọkọ kan:

1. **Ko si iwe sibẹsibẹ:** kika naa ṣi iwe naa. Nọmba rẹ jẹ ipilẹṣẹ ati gbogbo counter ti samisi.
2. **Iwe kika atijọ:** a kika dated ṣaaju ki o to kẹhin loo ọkan ti wa ni bikita. Bẹẹ ni kika ti akoko atunto jẹ diẹ sii ju 30 iṣẹju sẹyin ju eyi ti o fipamọ.
3. **Ferese olupese titun:** akoko atunto diẹ sii ju awọn iṣẹju 30 nigbamii ju eyi ti o fipamọ lọ yi iwe naa pada. Nọmba naa di ipilẹ ati gbogbo counter ti wa ni samisi lẹẹkansi. Awọn bọtini lai a counter fi iwe.
4. **Ferese ti o pari:** akoko atunto ti o fipamọ ti kii ṣe lẹhin akoko data kika tumọ si pe window ti pari. Kika naa yi iwe naa pada, ohunkohun ti nọmba rẹ.
5. **Nọmba ti o ga julọ:** nikan kẹhin olusin e. Ipilẹ ati awọn aami duro.
6. **Nọmba kanna:** olusin, ipetele ati aami duro. Nikan akoko atunto iwe ko ni ni kikọ.
7. **Nọmba kekere:** a kekere olusin ti wa ni ko loo bi iru. O yi iwe nikan nigbati awọn nkan mẹta ba mu. O kere ju iṣẹju meji tuntun ju kika ti o gbẹyin lọ. Ko si ohun ti o sọ pe window jẹ ṣiṣi kanna. O ju aaye kan lọ ni isalẹ.

Ferese naa ka bii ṣiṣi kanna nigbati awọn nkan mẹta ba mu. Mejeeji awọn akoko atunto ni a mọ. Wọn wa laarin ọgbọn iṣẹju ti ara wọn. Eyi ti o fipamọ si tun wa niwaju kika. Nọmba kekere ninu ferese yẹn ko yipada ohunkohun.

Akoko atunto ti wa ni ipamọ nikan nigbati o wa niwaju akoko data ti kika ti o gbe. Nọmba ti o ga julọ n tọju akoko atunto kika rẹ nigbati iyẹn ba ṣee lo, ati pe o tọju eyi ti o fipamọ bibẹẹkọ. Nọmba dogba ṣe igbasilẹ akoko atunto kika rẹ nikan nigbati iwe ko ni. Ko ṣe iyipada ohunkohun miiran. Nọmba ti o kere ju ti ko tan iwe igbasilẹ ko si akoko atunto.

#### Nigbati iwe ba lo

Lẹhin kika, iwe naa ni a lo ayafi ti akoko atunto ti o fipamọ ko lẹhin akoko lọwọlọwọ. Ọran yẹn dide nigbati kika ti o ya ni kete ṣaaju atunto, gẹgẹbi ọkan ti o ṣiṣẹ lati kaṣe, jẹ akiyesi ni kete lẹhin rẹ.

Laisi kika ohun elo, iwe ti o fipamọ ni lilo nikan nigbati o tun le jẹ iwe window lọwọlọwọ. Iyẹn duro ni awọn ọran meji:

- awọn oniwe-tunto akoko ti wa ni mọ ki o si tun wa niwaju
- ko ni akoko atunto, ati kika ti o kẹhin ti o yipada o jẹ julọ iṣẹju iṣẹju 15

Bibẹẹkọ ko si nkan ti a sọ, bi igba ti ko si iwe. Iwe ti akoko atunto ti o ti fipamọ ti kọja ko ni idiyele rara.

#### Imudaniloju

Lilo bọtini kan lori iwọn ipin kan jẹ apakan ti o jẹ iyasọtọ pẹlu ipin ti apakan ita. Apa ita akọkọ nlo agbara ko si awọn ẹtọ ipinpin (100 iyokuro apapọ awọn iwuwo). Nikan ni excess ti wa ni pín laarin awọn bọtini nipa àdánù.

Agbara yẹn jẹ akawe pẹlu ipin itẹtọ bọtini bi fun eyikeyi iwọn miiran. Ipo ti o muna si tun bẹrẹ nigbati ifihan itẹlọrun ba de `QUOTA_SATURATION_THRESHOLD` (aiyipada 0.5). Nọmba kọọkan jẹ iwọn nipasẹ opin ti o munadoko: opin-iroyin iye akoko iye awọn akọọlẹ ninu adagun-odo.

Fila pipe pẹlu `capUnit: "percent"` ka apakan nikan ti a sọ si bọtini, ti iwọn ni ọna kanna. Ya kan fun-iroyin iye to ti 100 ati k awọn iroyin. Fila ti N ti de nigba ti apakan bọtini ti nọmba akọọlẹ iṣẹ ti de awọn aaye N/k. A ṣayẹwo akọọlẹ kọọkan lodi si iwe tirẹ. Fun apẹẹrẹ, pẹlu awọn akọọlẹ meji, fila ti 10 ti de ni awọn aaye 5 ti nọmba akọọlẹ kan.

Nigbati ile itaja ko ba le ka, ko si nkankan ti a da ati pe gbogbo bọtini ni idiyele 0 lori iwọn yẹn. Nigbati iwe kikọ ba kuna, ifaramọ naa lo iwe naa bi o ti n ka. Àmi kikọ ti o kuna fi awọn ami ti ibeere silẹ kuro ninu iwe naa. Ko si ọkan ninu awọn ikuna wọnyi ti o ṣe idiwọ ibeere kan.

Ninu adagun `consent`, agbekalẹ ayanilowo nlo agbara bọtini kọọkan lori iwọn ipin bi a ti ṣalaye loke. Nigbati bọtini miiran ba yawo, iwe naa ni a ka ni ẹẹkan ati pe a da si gbogbo bọtini. Laisi iwe ohun elo gbogbo bọtini ti gba agbara 0. Bọtini pẹlu iwuwo lẹhinna kọja, ati bọtini pẹlu iwuwo 0 kọja nikan nigbati bọtini miiran ba ya.

#### Ọna lilo

`GET /api/quota/pools/{id}/usage` ṣe ijabọ awọn nọmba kanna nipasẹ iṣẹ kanna. Iwọn ogorun kan ni titẹsi kan fun asopọ adagun ni `accounts`. Awọn oniwe-oke-ipele `consumedTotal` ati `perKey` digi akọkọ titẹsi.

Ọna naa kan kika lọwọlọwọ paapaa, nitorinaa o le ṣe ilosiwaju iwe bi ibeere kan ṣe. `internal + external` le yato si `consumedTotal` nigbati ko ba si kika ohun elo, tabi nigbati nọmba kekere ko ba lo.

#### Ibi ipamọ ati idaduro

Mejeeji awọn ile itaja ipin pa iwe naa. Lori SQLite, isọdọmọ data aifọwọyi, nigbati o ba ṣiṣẹ, yọkuro awọn ori ila ti ko ni imudojuiwọn fun awọn ọjọ 60. Lori Redis, awọn iwe ati awọn iṣiro ti asopọ adagun kan pin bọtini kan. O dopin 60 ọjọ lẹhin kikọ ami-ami ti o kẹhin tabi iyipada iwe. Iwe ti ko yipada ko tun kọwe, nitorinaa gige gige ti ṣeto loke window ero to gunjulo. Iṣatunṣe itan-akọọlẹ lilo afọwọṣe naa tun nu awọn iwe kuro lori SQLite (wo Awọn idiwọn).

#### Awọn idiwọn

- Gbogbo idagba ti nọmba akọọlẹ lati igba ti ipilẹṣẹ ti pin nipasẹ awọn ami-ami bọtini kọọkan ti o ti ipa-ọna lati igba naa. Nigbati idagbasoke yẹn ba ṣẹlẹ ko ṣe pataki.
- Nitorinaa lilo ti a ṣe ni ita OmniRoute ni idiyele si awọn bọtini to ohun ti awọn ami-ami wọn gba laaye. Iyẹn pẹlu lilo ti a ṣe ṣaaju ibeere akọkọ bọtini kan ti window, nigbati iwe naa ti ṣii tẹlẹ.
- Fun apẹẹrẹ, lilo ita ji akọọlẹ naa ni awọn aaye 60 lakoko ti ko si awọn ipa-ọna bọtini. Bọtini kan lẹhinna awọn ọna awọn ami 30,000 ati nọmba naa de 60.6.
- Ti iwe naa ba ṣii ṣaaju lilo yẹn, apakan bọtini jẹ awọn aaye 30. O tun gbe 7.65 ti lilo ita, pẹlu awọn bọtini mẹrin ti iwuwo 25.
- Ti iwe ba ṣii lẹhin lilo yẹn, awọn aaye 60 jẹ ipilẹ. Apa bọtini jẹ awọn aaye 0.6, ati pe o gbe 15 ti lilo ita.
- Ibere tabi ibewo si ipa ọna lilo ṣi iwe naa. Nitorinaa boya iru lilo bẹ bii ipilẹ ti o da lori nigbati iwe naa ṣii.
- Pẹlu awọn ipilẹ pakà, a bọtini ti o ipa 60,000 àmi nigba ti ita lilo soke awọn iroyin 60 ojuami gba gbogbo 60 bi awọn oniwe-ara apakan.
- Pẹlu ilẹ ni 50,000, apakan tirẹ jẹ awọn aaye 1.2. 58.8 miiran jẹ ita ati gba agbara nipasẹ iwuwo, bii eyikeyi lilo ita.
- Ṣeto `QUOTA_PERCENT_MIN_TOKENS_PER_POINT` sunmọ kini idiyele aaye kan lori ero rẹ. Ita lilo pẹlu ijabọ lori kanna iroyin lati awọn bọtini ita awọn pool.
- Fila ogorun kan ni gbogbo ipo. Bọtini capped le jẹ kọ lakoko ti akọọlẹ naa wa ni isalẹ aaye itẹlọrun.
- Mu fila ti awọn aaye 10 ati 12 ti lilo ita ni iṣaaju ni window. Bọtini ti o tọ awọn ami-ami 20,000 lẹhinna kọ ni nọmba akọọlẹ kan ti 12.4%.
- Pipin jẹ iṣiro nipasẹ iwọn didun tokini. Ibere kan ka bi awọn ami itọka rẹ pẹlu awọn ami ipari rẹ. Awọn ẹdinwo kaṣe ati awọn idiyele awoṣe ko yipada kika yẹn.
- Ibeere ti ko pari pẹlu ipo 200 ko ṣe igbasilẹ awọn ami-ami. Awọn apẹẹrẹ jẹ ṣiṣan ti alabara ge asopọ ati aṣiṣe oke kan lẹhin lilo lilo.
- Lilo iru ibeere ti o ṣẹlẹ jẹ idiyele si awọn bọtini ti o ṣe igbasilẹ awọn ami, titi de ohun ti awọn ami-ami wọn gba laaye. Awọn iyokù jẹ ita. Ko gbe pada. Idahun ti o ṣe ijabọ ko si lilo ami-ami ko ṣe igbasilẹ ko si awọn ami boya.
- Lilo ibeere ti nlọ lọwọ le ṣafihan ni apakan bọtini miiran ti nṣiṣe lọwọ fun gbogbo ibeere naa. O yi pada nikan nigbati ibeere ba pari pẹlu ipo 200.
- Lilo tẹlẹ lori akọọlẹ nigbati iwe ba ṣii awọn iṣiro bi ita. Eyi ni wiwa igbesoke, adagun-odo tuntun ati akọọlẹ tuntun kan. Lilo ni window tuntun ṣaaju kika kika akọkọ bi ita paapaa.
- Bọtini kọọkan bẹrẹ pẹlu ipin iwuwo rẹ ti lilo yẹn, lẹhin agbara ko si awọn ẹtọ ipin. Pẹlu akọọlẹ kan ni 85% ati awọn bọtini marun ti iwuwo 20, ọkọọkan bẹrẹ pẹlu 17 ti 20 ti a lo.
- Ninu adagun-odo kan pẹlu awọn akọọlẹ pupọ, nọmba akọọlẹ iṣẹ iranṣẹ ni a lo si isuna ti a ṣe akojọpọ. Eyi ko yipada nipasẹ iwe naa.
- Nọmba kekere kan ninu ferese ti olupese n ṣe ijabọ bi ṣiṣi ko lo. Akoko atunṣe ti o lọ sẹhin nipasẹ diẹ ẹ sii ju awọn iṣẹju 30 ni a ṣe itọju bi kika atijọ.
- Ni awọn ọran mejeeji iwe naa tọju ipo rẹ titi akoko atunto ti o fipamọ yoo fi kọja. Lẹhin iyẹn, iwe naa ko ni idiyele titi kika kika yoo fi yipada.
- Atunṣe ni afọwọṣe ilo-itan atunto (`POST /api/settings/purge-usage-history`). O ṣe imukuro awọn iwe iyasọtọ ati awọn iṣiro ami-ami wọn ninu aaye data SQLite.
- Akoko `all` ko gbogbo iwe ati counter. Akoko kukuru ni akọkọ ko awọn iwe ti a ko kọ sinu rẹ kuro. Lẹhinna o ṣalaye awọn iṣiro ti a ko kọ sinu rẹ, ṣugbọn fun asopọ adagun kan ti ko ni iwe ti o ku. A pa iwe si tun aami kọọkan bọtini lodi si awọn oniwe-counter.
- Iwe ti nọmba rẹ ko ti gbe ni ko tun kọ, nitorina akoko kukuru kan tun le ko iwe window ti o wa lọwọlọwọ kuro. Kika atẹle lẹhinna ṣii iwe tuntun ni eeya lọwọlọwọ.
- Atunto naa ko fi ọwọ kan ile-itaja ipin Redis. Nibẹ ni iwe kan pari pẹlu ferese rẹ, tabi pari ni 60 ọjọ lẹhin kikọ rẹ kẹhin.
- Nigbati olupese ko ba firanṣẹ akoko atunto, window ti o tunto ti o tun kun loke nọmba atijọ laarin awọn kika meji dabi nọmba ti o ga julọ. Iwe naa ntọju ipilẹ atijọ ati awọn ami.
- Awọn kika ti wa ni ọjọ nipasẹ aago agbegbe. Nigbati o ba ṣiṣẹ niwaju ti olupese, tabi orisun kan ṣe ijabọ akoko atunto ni kutukutu diẹ, iwe naa le yipada si iyatọ yẹn ni kutukutu.
- Idagba ni akoko kukuru yẹn ti pin nipasẹ awọn ami-ami ti a fipa sinu rẹ. Kika akọkọ window ti o tẹle ṣe atunṣe rẹ. Nigbati iwe yiyi ko ba ni akoko atunto, atunṣe naa nilo eeya kekere o kere ju iṣẹju meji tuntun ju kika ti o gbẹyin lọ.
- Awọn apẹẹrẹ ti o pin awọn kika ọjọ itaja Redis pẹlu awọn aago tiwọn, nitorinaa jẹ ki awọn aago yẹn ṣiṣẹpọ. Awọn kika ti apẹẹrẹ ti aago rẹ nṣiṣẹ lẹhin wo ti dagba ati pe a ko bikita.
- Nigbati ko ba si kika ohun elo ti o de lẹhin akoko atunto ti o fipamọ, awọn ipin ipin-bọọlu-kọọkan ati awọn fila ogorun ko ni fi agbara mu titi ti kika yoo fi pada. Laisi akoko atunto, eyi bẹrẹ awọn iṣẹju 15 lẹhin kika ti o kẹhin ti o yi iwe pada.
- Lori ile itaja Redis, iwe kan laišišẹ fun 60 ọjọ le pari laarin ayẹwo onkqwe ati kikọ rẹ. Lẹhinna o tun ṣẹda ni atunyẹwo loke 1, eyiti o jẹ ipo to wulo.

## Pipeline Integration

### ìkọ PRE (`open-sse/handlers/chatCore.ts`)

Ṣiṣẹ ṣaaju alaṣẹ ti oke, lẹhin auth ati awọn sọwedowo eto imulo:

```
resolveComboTargets / handleSingleModel
  → enforceQuotaShare(apiKeyId, connectionId, provider, estimatedCost)
      → getQuotaStore().peek() per dimension
      → fairShare.decideFairShare()
      → if block → return 429 (buildErrorBody, Hard Rule #12)
      → if allow + deprioritize → set quotaSoftPenalty=true on candidate
  → executor.execute()
```

**Ikuna-ṣii** : ti `enforceQuotaShare` ba jabọ, ibeere naa ni a gba laaye nipasẹ pẹlu iwe `pino.warn` kan. Eyi ṣe idilọwọ kokoro-ẹnjini ipin lati dinamọ gbogbo ijabọ.

**Nigbati agbara ba pada.** Kiko ni ipin bọtini tabi ni aja adagun-odo dopin pẹlu ọkan ninu awọn gbolohun ọrọ meji, ni awọn ipo yiya mejeeji:

- window `percent` : `. The <window> window resets at <time>.` Akoko ni atunto awọn ijabọ olupese.
- Ẹka kika: `. Enough <window> usage is expected to clear by <time>.` Akoko naa jẹ opin oke lati ferese sisun, ti bọtini ko ba fi nkan miiran ranṣẹ.

`<time>` jẹ ISO 8601 lẹsẹkẹsẹ ni UTC. Ijusilẹ lẹhinna gbe `Retry-After`: gbogbo iṣẹju-aaya titi di akoko yẹn, pẹlu ọkan. Onibara ti o duro de igba pipẹ yoo gbiyanju ni pupọ julọ iṣẹju-aaya kan lẹhin lẹsẹkẹsẹ. Nigbati a ko ba mọ lẹsẹkẹsẹ, kiko naa ko gbe gbolohun tabi akọsori. Ohun idi fila kiko gbejade bẹni. Awọn àkọsílẹ koodu duro `quota_share_blocked`.

Kiko ipin ko kan asopọ ti o pin. Ko ṣeto itutu agbaiye, ko si titiipa awoṣe ko si si ikuna fifọ olupese, ati awọn bọtini miiran ti adagun-odo naa n tẹsiwaju lati ṣiṣẹ. Nigbati gbogbo ibi-afẹde ti konbo ba kọ bọtini fun ipin rẹ, konbo naa dahun 429 laisi iduro. Idahun rẹ gbe itọka bi `Retry-After`. Ona ifibọ dopin kiko rẹ pẹlu gbolohun kanna ko si firanṣẹ `Retry-After`.

### POST ìkọ (gbigba igbasilẹ)

Lẹhin esi aṣeyọri:

```
executor returns success
  → spendRecorder.recordConsumption(apiKeyId, connectionId, provider, actualCost)
      → getQuotaStore().consume() per dimension
      → fail-open: errors logged as pino.warn, never propagated to client
```

**Akọsilẹ fiseete** : ti o ba ti `consume` kuna ranse si-esi, awọn sẹsẹ counter labẹ-ka. Ifihan agbara itẹlọrun lati ọdọ olupese (fun apẹẹrẹ `anthropic-ratelimit-unified-5h-utilization`) ṣe atunṣe iṣiro agbaye lori ibeere atẹle.

### Konbo rirọ gbamabinu (`open-sse/services/combo.ts`)

Nigbati `decision.deprioritize === true`:

```ts
if (candidate.quotaSoftPenalty) {
  score *= QUOTA_SOFT_DEPRIORITIZE_FACTOR; // default 0.7
}
```

A lo ijiya naa lẹhin gbogbo awọn ifosiwewe igbelewọn miiran. O dinku iṣeeṣe konbo adaṣe ti yiyan bọtini ti o kun laisi idilọwọ lile.

## API Iṣẹ-Iṣẹ-ara-ẹni (jade-wọle)

`GET /api/v1/me/quota/{provider}` (tun ṣiṣẹ ni `/v1/me/quota/{provider}`) jẹ ki olumu bọtini API kan ka, pẹlu bọtini tiwọn, melo ni ṣiṣe alabapin pín jẹ tiwọn ati ohun ti n dina wọn. Ọna naa jẹ ikarahun tinrin lori `src/server/selfService/quotaHandler.ts`; wiwo naa jẹ itumọ nipasẹ `src/lib/quota/selfView.ts` ati adehun idahun rẹ jẹ `src/shared/schemas/selfQuota.ts` (`SelfQuotaView` ni `docs/openapi.yaml`).

### Muu ṣiṣẹ ati ìfàṣẹsí

- Ẹya asia `QUOTA_SELF_PANEL`, aiyipada `false`. Lakoko ti o wa ni pipa, ibeere ti o de ipa ọna n gba 404. Pẹlu `REQUIRE_API_KEY=true`, eto imulo API onibara kọ bọtini ti o padanu tabi invalid pẹlu 401 ṣaaju ki ipa ọna naa lọ, ohunkohun ti asia. Ibeere ti ko ni bọtini ṣugbọn igba idasibodu ti o wọle kọja ilana yẹn ati gba idahun ti ara rẹ. Awọn asia pinnu bi gbogbo asia miiran (dasibodu tabi REST danu, lẹhinna iyipada ayika ti orukọ kanna); wo [`FEATURE_FLAGS.md`](../reference/FEATURE_FLAGS.md).
- Orukọ ifihan adagun-odo kọọkan ati aami iṣeto kọọkan ni a da pada si awọn dimu bọtini adagun naa ni deede bi oluṣakoso kọ wọn. Ṣaaju ki o to tan asia, ṣayẹwo pe wọn yẹ lati ka nipasẹ awọn dimu bọtini.
- Bọtini naa jẹ kika lati awọn akọle nikan: `Authorization: Bearer <key>` tabi `x-api-key: <key>`. Nigbati awọn mejeeji ba firanṣẹ, akọkọ ti o fọwọsi ni lilo. Bọtini kan ninu okun ibeere tabi kuki ni a kọbikita. A kọ bọtini ayika olupin naa (401).
- Bọtini naa nilo aaye `self:usage` (403 laisi rẹ).
- Apa ti olupese ti ge, ti wa ni kekere ati ṣayẹwo lodi si `^[a-z0-9][a-z0-9._-]{0,63}$` (400 bibẹẹkọ), lẹhinna yanju nipasẹ iforukọsilẹ olupese, nitorinaa inagijẹ bii `cc` ka awọn adagun-odo `claude`. `claude` ati `anthropic` ka awọn adagun kanna.

### Ohun ti kọọkan hihan fihan

| Hihan        | Nbeere                                                                            | Awọn aaye                                                                                                                                                                                                                                                              |
| ------------ | --------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Pipin ti ara | `self:usage`                                                                      | `pools[]` (ref, orukọ, olupese, eto imulo, iwuwo, fila), `dimensions[].yourShare`, `accounts[]` pẹlu `yourShare` (lori ferese `percent` laisi `attributed` ati `external`), `blocks`, `availableModels`, `expiresAt`, `apiBaseUrl`                                     |
| ipele iroyin | `self:usage` + `self:account-quota`, ati olupese ni bọtini `sharedQuotaProviders` | ṣe afikun `dimensions[].total`, `accounts[].dimensions[].account` ati `accounts[].modelWindows`, `attributed` ati `external` lori `yourShare` ti ferese `percent` kan, ati `members` lori adagun-omi pẹlu lilo ọmọ ẹgbẹ lori (wo [lilo Awọn ọmọ ẹgbẹ](#member-usage) ) |

- `sharedQuotaProviders` is a per-key settings (`PUT /api/keys/[id]/self-service`): `null`, aiyipada, tumo si gbogbo olupese bọtini de; `[]` tumo si ko si. Kọọkan pool ká `accountVisible` sọ eyi ti hihan loo si o.
- Awọn ifi akọọlẹ ati awọn ferese awoṣe jẹ afihan fun awọn akọọlẹ nikan ti bọtini asopọ wọn le lo. Nigbati bọtini ba ni atokọ ti awọn asopọ ti a gba laaye, akọọlẹ kan ni ita rẹ n tọju titẹsi `Account N` rẹ laisi `account` tabi `modelWindows`. Akojọ ofo tumọ si pe ko si ihamọ, bi fun `/v1/me/status`. Lapapọ adagun-odo (`dimensions[].total`) ko da lori atokọ yẹn.
- Awọn eeya meji ti o han pẹlu `self:usage` nikan wa lati lilo awọn bọtini miiran. Eto isuna iṣeto `exhausted` ṣe afihan agbara ti gbogbo bọtini labẹ iṣeto yẹn. Ninu adagun-omi ti gbogbo rẹ jẹ odo, `weight` bọtini jẹ `100 / number of members`. Mejeji ni ohun ti imuse kan si bọtini.
- Adágún omi kan jẹ idanimọ nipasẹ `ref` nikan, iye akomo ti o so mọ bọtini ipe. Orukọ ifihan rẹ (`name`) wa ninu bi alabojuto ti kọ ọ. `ref` kan jẹ lati inu bọtini ati adagun omi pẹlu aṣiri API-bọtini olupin (`API_KEY_SECRET`). Awọn alabara ko gbọdọ tẹsiwaju: o yipada ti aṣiri yẹn ba yiyi.
- Awọn akọọlẹ jẹ akojọ si bi `Account 1`, `Account 2`, … ni aṣẹ adagun-odo. Ko si id adagun, id asopọ, imeeli iroyin tabi orukọ akọọlẹ ti pada, ati pe idahun naa lọ nipasẹ eto adehun, eyiti o ṣubu eyikeyi aaye ni ita rẹ.
- Awọn ipin ti a le ka (`requests`, `tokens`, `usd`) ni a royin bi garawa adagun ti ẹnu-ọna ipin ti o fi agbara mu: `limit` = gbero opin awọn akọọlẹ × ninu adagun-odo, iwuwo `fairShare` = / 100 × `limit` (yapa deede nigbati gbogbo iwuwo jẹ 0), `consumed` = bọtini tirẹ funrararẹ, ibi-itaja `remaining` = ninu ibi-itaja − `fairShare` `consumed` ni 0.
- `blocks.schedules` ṣe atokọ awọn window iṣeto bọtini (`open`/`closed`, `blackout` tabi `outside-window`, `retryAfterSeconds`, awọn ilẹ ipakà, ati boya isuna ti window ti lo); `blocks.modelCaps` ṣe atokọ awọn bọtini wakati-fun-awoṣe rẹ pẹlu agbara.
- Bọtini ita gbogbo adagun ti olupese n gba 200 pẹlu `pools: []`; `availableModels` (awọn ids `qtSd/` ti o rii ni `/v1/models`), `expiresAt` ati `apiBaseUrl` tun kun.
- `apiBaseUrl` jẹ `OMNIROUTE_PUBLIC_API_BASE_URL`, lẹhinna `OMNIROUTE_PUBLIC_BASE_URL`, miiran `null`. Kii ṣe ipilẹṣẹ ibeere naa rara.

### `status` ati `reason`

| `status`      | Itumo                                                                                                                                                                                                                                                                                                                                    |

Ferese awoṣe kan ti akoko atunto ti kọja jẹ aami gbogbo ẹgbẹ `modelWindows` `stale`. Fun ipin bọtini tirẹ ti window `percent` kan: iwe naa ni a ka laisi kika akọọlẹ ninu kaṣe ẹnu-ọna lati jẹrisi rẹ. |
| `unavailable` | Ko si kika; awọn nọmba jẹ `null`, ko `0`. `reason` sọ idi.                                                                                                                                                                                                                                                                               |

| --------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |

| `percent_attribution_unavailable` | Ipin bọtini funrararẹ ti ferese `percent` : ko si iwe ikaṣe sibẹ fun akọọlẹ yẹn ati window, tabi iwe naa ko ṣe atokọ bọtini naa. |

| `window_not_reported`             | Kaṣe olupese ko ni kika fun ferese ero yẹn.                                                                                      |
| `connection_lookup_failed`        | Asopọmọra akọọlẹ naa ko le ka.                                                                                                   |

### Gbigbanilaaye yiya

`PATCH /api/v1/me/quota/{provider}` ṣe igbasilẹ aṣẹ ti ara ẹni bọtini ipe fun adagun-odo kan. O nlo asia, awọn akọle ati awọn ofin olupese ti `GET`. Iwọn `self:usage` fun ni aṣẹ kikọ kan, botilẹjẹpe orukọ rẹ ka bi kika-nikan.

```json
{
  "pool": "qpr_0123456789abcdef0123456789abcdef",
  "lendingPercent": 30,
  "lendingUntil": 1893456000000
}
```

- `pool` ni `ref` awọn `GET` pada fun awọn pool.
- `lendingPercent` jẹ nomba odidi lati 0 si 100. Iye kan ti 0 ko ifojusọna ati akoko ipari rẹ kuro. Ara kan pẹlu `lendingPercent` 0 ni a gba ni boya ipo.
- `lendingUntil` jẹ iyan: epoch milliseconds, tabi `null` fun ko si akoko ipari. O gbọdọ jẹ ni ojo iwaju ati ni julọ 86400000000000. Iye kan ti o wa ni isalẹ 10000000000 ka bi awọn aaya ati pe a kọ.
- Eyikeyi miiran aaye ti wa ni kọ. Ara to gun ju 4096 baiti kọ. Kika naa duro ni iwọn yẹn, nitorinaa ara ti o gun ko ni di odidi rara.

Awọn sọwedowo ṣiṣe ni aṣẹ ti tabili yii. Gbogbo ijusile nlo ara aṣiṣe boṣewa pẹlu ifiranṣẹ ti o wa titi. Kiko nipasẹ ọkan ninu awọn sọwedowo wọnyi ko kọ nkankan.

| Ipo | Ifiranṣẹ                                                                                           | Nigbawo                                                                 |
| --- | -------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| 404 | `Not found`                                                                                        | Asia `QUOTA_SELF_PANEL` wa ni pipa.                                     |
| 401 | `Valid API key required`                                                                           | Bọtini naa sonu tabi ko wulo, tabi jẹ bọtini ayika olupin naa.          |
| 403 | `API key lacks the self:usage scope`                                                               | Bọtini ko ni `self:usage`.                                              |
| 400 | `Invalid provider`                                                                                 | Apa olupese ko wulo.                                                    |
| 429 | `Too many lending changes. Retry later.`                                                           | Bọtini naa kọja opin rẹ. Idahun si gbe `Retry-After`.                   |
| 400 | `Body must be { pool, lendingPercent, lendingUntil }. lendingPercent is an integer from 0 to 100.` | Ara kii ṣe JSON, o gun ju, tabi ko baramu ero-ọrọ naa.                  |
| 400 | `lendingUntil must be a Unix time in milliseconds`                                                 | Akoko ipari ka bi iṣẹju-aaya.                                           |
| 400 | `lendingUntil must be in the future`                                                               | Akoko ipari wa ni tabi ṣaaju akoko ibeere naa.                          |
| 404 | `Pool not found`                                                                                   | Awọn orukọ `ref` ko si adagun-odo ti bọtini yii fun olupese yii.        |
| 403 | `Lending is not enabled for this pool`                                                             | Adagun adagun wa ni ipo `saturation` ati pe `lendingPercent` wa loke 0. |
| 500 | `Failed to build quota view`                                                                       | Eyikeyi miiran ikuna. Idi rẹ ti wọle lori olupin naa.                   |

Idiwọn jẹ awọn ibeere 20 fun iṣẹju-aaya 60 fun bọtini kọọkan. Gbogbo ibeere ti o kọja ayẹwo olupese olupese ni iye, paapaa ọkan kọ nigbamii tabi ọkan ti ko yipada ohunkohun. O ni counter tirẹ, yato si opin oṣuwọn ibeere bọtini.

Ibere ti o yipada ifọkansi ti o fipamọ kọ igbasilẹ iṣayẹwo `quota.pool.lending.updated` kan. O lorukọ bọtini pẹlu atijọ ati awọn iye tuntun. Kanna ara rán lemeji Levin lẹẹkan ati audits lẹẹkan. Idahun si jẹ 200 pẹlu wiwo `GET` ni kikun, ti a ṣe lẹhin kikọ.

`GET` wo awọn ijabọ awin bi atẹle:

- Adagun-omi kọọkan n gbe `borrowMode` (`saturation` tabi `consent`), ati `lendingPercent` ati `lendingUntil` ti kọkọrọ naa.
- `lendingActive` jẹ `true` nikan ni adagun `consent`, pẹlu ipin kan loke 0 ati akoko ipari ti ko de.
- Ninu adagun `consent`, `dimensions[].yourShare` kọọkan ti o le ka gbe `borrowAvailable`. O jẹ ohun ti bọtini le lo loke ipin rẹ ni bayi, yiya nipasẹ awọn bọtini miiran.
- `borrowAvailable` nlo ilana ẹnu-ọna. O ka gbogbo bọtini miiran, paapaa lakoko ti bọtini wa labẹ ipin rẹ. Fun bọtini `hard` kan ti o jẹ afikun kika fun bọtini miiran ati iwọn kika, ni afiwe.
- `borrowAvailable` jẹ `null` fun bọtini `soft` tabi `burst`, ati `null` nigbati kika ba kuna.
- `borrowAvailable` jẹ eeya kan fun gbogbo awọn bọtini miiran papọ. Ninu adagun ti awọn bọtini meji o jẹ nọmba ara bọtini miiran.
- `borrowAvailable` ko ṣe ijabọ fun awọn window `percent` tabi ni `accounts[]` sibẹsibẹ.
- Ninu adagun `saturation` wiwo naa ṣe ijabọ ifọkansi ti o fipamọ pẹlu `lendingActive: false` ko si si `borrowAvailable`.

### Awọn aṣiṣe

Gbogbo esi ti ipa ọna yii, aṣeyọri tabi aṣiṣe, gbe `Cache-Control: no-store`. Kiko ti o ṣẹlẹ ṣaaju ki awọn ipa ọna gbalaye ko ni gbe o, fun apẹẹrẹ awọn ose API imulo ká 401 tabi IP àlẹmọ 403. Awọn ašiše ti awọn ipa ọna lo awọn boṣewa aṣiṣe ara pẹlu kan ti o wa titi ifiranṣẹ: 400 (invalid olupese), 401 (sonu tabi invalid bọtini), 403 (sonu `self:usage`), 5g0 40 pa (`Failed to build quota view`). 500 naa bo ikuna eyikeyi ni kete ti ibeere ba de ipa ọna, pẹlu wiwa bọtini funrararẹ; idi rẹ ti wọle lori olupin ko si pada. Awọn aṣiṣe ti `PATCH` wa ni akojọ si ni [igbanilaaye Yiyalo](#lending-consent).

### Awọn idiwọn

- `remaining` jẹ apakan ti ipin itẹtọ bọtini ti ko lo. O ti wa ni ko kan lopolopo. Bọtini kan le tun ṣe iranṣẹ ni ikọja rẹ lakoko ti adagun-odo naa ni yara. Ni kete ti apapọ adagun-odo naa ba de `limit`, gbogbo bọtini ti adagun naa ni a kọ, ohunkohun ti `remaining` tirẹ, ati bọtini laisi `self:account-quota` ko le rii lapapọ yẹn.
- `remaining` ko gba `cap` pipe ipin sinu akoto. Imudaniloju kọ bọtini ni kete ti agbara tirẹ ni ferese ti ẹyọ fila ti de iye fila naa.
- Pẹpẹ ipele akọọlẹ wa lati kaṣe ti o fi opin si olupese ati pe o le fa ipinnu imuṣiṣẹ duro nipasẹ iṣẹju diẹ. Iwe kika ti akoko atunto ti kọja jẹ ijabọ bi `stale`.
- Per-awoṣe windows (`modelWindows`) ti wa ni royin nikan fun awọn olupese ti o ni eto-window maapu: Claude ati Codex loni. Fun awọn olupese miiran `modelWindows` ṣi wa nigbati data akọọlẹ han, pẹlu atokọ `windows` ti o ṣofo.
- Ipin bọtini tirẹ ti window `percent` jẹ iṣiro. O wa lati inu iwe iyasọtọ ati gbejade gbogbo aropin ti a ṣe akojọ labẹ “Awọn iwọn ogorun: ipin-bọtini” loke.
- `consumed` ni imuse nọmba ti a ṣe afiwe pẹlu ipin itẹ. O ti wa ni `attributed` plus `external`, gangan. `attributed` jẹ apakan ti iwe naa funni ni bọtini fun awọn ami-ami ti o da. `external` jẹ apakan bọtini ti lilo akọọlẹ ti awọn bọtini adagun ko ṣe akọọlẹ fun.
- Awọn ẹya mejeeji ni a firanṣẹ nikan nigbati `accountVisible` adagun-odo jẹ otitọ: bọtini naa ni `self:account-quota` ati pe olupese wa ni `sharedQuotaProviders` rẹ. Bọtini laisi rẹ gba `consumed` nikan, pẹlu `status` ati `reason` kanna.
- Pẹlu awọn ẹya mejeeji ati iwuwo tirẹ, dimu le ṣiṣẹ lilo ti a ṣe ni ita adagun adagun ti o gba agbara si awọn bọtini adagun-odo naa. Ẹniti o dimu pẹlu aaye akọọlẹ ti rii lapapọ lapapọ.
- Bọtini ti o ta ohunkohun ninu ferese tun le ka idiyele ita rẹ lati `consumed`, nitori pe apakan ti o ni nkan jẹ lẹhinna 0.
- Fun apẹẹrẹ, iwe kan ṣii ni 0, pẹlu awọn bọtini A ati B ni iwuwo 50 kọọkan. Key A ipa-900.000 àmi ati bọtini B 100.000. Iwe akọọlẹ naa de 60% ti opin ti 100. Lẹhinna `attributed` jẹ 54 fun bọtini A ati 6 fun bọtini B, ati `external` jẹ 0 fun awọn mejeeji.
- Wiwo naa ka iwe naa ko kọ ipinlẹ rẹ rara. Ko ṣii iwe kan, ati pe ko beere lọwọ olupese fun kika. Pẹlu ile itaja Redis, kika kan yọkuro awọn aaye atunyẹwo ti o rọpo ni abẹlẹ, gẹgẹ bi kika ẹnu-bode ṣe.
- Pipin naa jẹ `ok` nikan nigbati kaṣe ẹnu-bode di kika ti akọọlẹ naa. Laisi ọkan o jẹ `stale`, nitorinaa ninu adagun-omi kan ti ko ni ibeere aipẹ o fihan bi o ṣee ṣe pe ko ti pẹ.
- Titi ti ibeere yoo fi kọja adagun-odo, ipin naa ko si. Ibeere yẹn ṣii iwe naa, ati pe nọmba akọọlẹ naa ni akoko yẹn ka bi lilo ti a ṣe ni ita adagun-odo naa.
- Ninu adagun-odo pẹlu awọn akọọlẹ pupọ, titẹ sii akọọlẹ kọọkan nlo iwe tirẹ ati opin akọọlẹ kan. Awọn irẹjẹ imuṣiṣẹ ni ẹgbẹ mejeeji nipasẹ nọmba awọn akọọlẹ, nitorinaa ipin jẹ kanna.
- Fun-awoṣe windows ko gbe ipin fun bọtini. Awọn iwe ntọju ko si fun-awoṣe data.
- Awọn ilẹ ipakà ti iṣeto ni a ko ṣe ayẹwo nipasẹ wiwo: iṣeto le fihan bi `open` lakoko ti a kọ ibeere pẹlu idi `schedule-reserve`.
- Nigbati awọn adagun omi meji ti bọtini kanna ba pin asopọ kan, imuṣiṣẹ yoo kan ọkan ninu wọn, ati wiwo awọn atokọ mejeeji.
- Ko si opin-adirẹsi fun awọn igbiyanju bọtini ti o kuna: lẹhin awọn olupe aṣoju yiyipada le pin adirẹsi kan (o da lori boya awọn adirẹsi alabara ti firanṣẹ siwaju jẹ igbẹkẹle), nitorinaa titiipa le kọ ipa-ọna si gbogbo bọtini dimu. Pẹlu `REQUIRE_API_KEY=true`, bọtini invalid jẹ kọ nipasẹ eto API onibara ṣaaju ki ipa ọna naa to ṣiṣẹ, pẹlu eto imulo 401 ara dipo ipa ọna yii.

### Lilo omo egbe

Alakoso le jẹ ki awọn dimu bọtini wo bi lilo window kan ṣe pin laarin awọn ọmọ ẹgbẹ adagun-odo naa. Aṣayan naa jẹ `memberBreakdown` adagun-odo, pipa nipasẹ aiyipada. O ti ṣeto ni oluṣeto adagun-odo tabi pẹlu `PATCH /api/quota/pools/{id}`. `GET /api/quota/pools` ati `GET /api/quota/pools/{id}` jabo o.

Iwọn ti wiwo n gbe `members` nikan nigbati gbogbo awọn wọnyi ba di:

- awọn pool ká aṣayan jẹ lori
- adagun-odo naa ni o pọ julọ awọn bọtini ipin 20, ati pe o kere ju mẹta ninu wọn le ṣe awọn ibeere: ṣiṣẹ, ko fagile, ko ni idinamọ ati pe ko kọja ipari wọn.
- `accountVisible` adagun jẹ otitọ: bọtini naa ni `self:account-quota` ati pe olupese wa ni `sharedQuotaProviders` rẹ
- Lori ferese `percent`, asopọ akọọlẹ jẹ ọkan ti bọtini le lo
- ipin bọtini ara ti ferese yẹn ni a ka: `status` rẹ kii ṣe `unavailable`

Bibẹẹkọ `members` ko si. Kii ṣe atokọ ṣofo rara.

- Ege kọọkan jẹ `{ slot, consumed, isYou }`. Eto idahun kọ eyikeyi ohun-ini miiran lori bibẹ pẹlẹbẹ, ati atokọ diẹ sii ju awọn ege 20 lọ. Awọn ege ti wa ni akojọ ni ibere Iho.
- Bibẹ pẹlẹbẹ kan wa fun bọtini ti a pin, pẹlu bọtini kan ti ko le ṣe awọn ibeere mọ. Ọmọ ẹgbẹ ti ko ni lilo fihan odo gidi kan.
- Iho 1 jẹ nigbagbogbo bọtini ibeere, pẹlu `isYou` otitọ. Awọn nọmba iho miiran jẹ awọn ipo ti hash keyed. O jẹ bọtini pẹlu `API_KEY_SECRET` o si bo adagun-odo, bọtini ibeere ati ọmọ ẹgbẹ.
- Nitorina awọn nọmba ko ni laini laarin awọn dimu. Fun dimu kan wọn duro kanna laarin awọn abẹwo. Wọn le yipada nigbati bọtini kan ba darapọ mọ tabi lọ kuro ni adagun omi, tabi nigbati aṣiri yẹn ba yiyi.
- Lori ferese ti o le ka bibẹẹ kan ni counter ọmọ ẹgbẹ ninu ile itaja ipin, counter kanna bi `consumed` tirẹ.
- Lori ferese `percent` kan bibẹ ni apakan `attributed` ọmọ ẹgbẹ, lati inu iwe kanna ti a ka bi ipin bọtini tirẹ. Lilo ti a ṣe ni ita adagun-odo ko pin si awọn ege. Idiyele yẹn pin nipasẹ iwuwo, nitorinaa awọn ege ti o gbe yoo ṣafihan awọn iwuwo.
- Wiwo kọọkan ka iye kan fun ẹgbẹ miiran ati window kika, ni afiwe. Lori ferese `percent` awọn ege naa ko ni kika ni ikọja iwe ti ara ẹni ti a ka. Nigbati iye kan ko ba le ka, window yẹn ko ni `members`, ati pe bọtini ti ara rẹ duro.
- Aṣayan ati nọmba awọn bọtini lilo ni a ka ni ẹẹkan fun adagun-odo, ati fun bọtini kan ti o le rii data akọọlẹ. Ikuna kika aṣayan tabi ti kika bọtini lilo ti o wa ni pipa fun adagun-odo yẹn. Awọn olupin wọle a Ikilọ, ati awọn iyokù ti awọn wiwo ti wa ni itumọ ti.

Awọn ifi ko gbe awọn orukọ tabi ids. Wọn tun sọ awọn nkan dimu bọtini kan nipa awọn ọmọ ẹgbẹ miiran:

- Awọn dimu tun le baramu awọn ege nipasẹ awọn iye wọn.
- Nọmba iduroṣinṣin jẹ ki dimu kan tẹle ọmọ ẹgbẹ kan ni akoko pupọ.
- Awọn nọmba ti ege fihan bi ọpọlọpọ awọn bọtini ti wa ni soto ninu awọn pool.
- Ninu adagun ti awọn bọtini mẹta, ẹnikan ti o mọ kini bọtini kan ti a lo le sọ kini bọtini ti o kẹhin ti o lo.
- Nigbati adagun kan ba ṣubu ni isalẹ awọn bọtini lilo mẹta, awọn ifi parẹ. Awọn iwo ti o ya tẹlẹ tun ṣafihan kini ọmọ ẹgbẹ kọọkan lo.
- Lori ferese kika, adagun-odo lapapọ iyokuro awọn ege le ṣafihan lilo awọn bọtini ti a ko pin si.
- Ọmọ ẹgbẹ ti o fihan odo lori akọọlẹ kan ati lilo lori omiiran le ṣafihan iru ọmọ ẹgbẹ wo ni o lo akọọlẹ.
- Ninu adagun-odo ti o le ka pẹlu eto imulo `hard`, bibẹ pẹlẹbẹ ti o dẹkun idagbasoke ni ipin itẹtọ ọmọ ẹgbẹ kan tọka si iwuwo ọmọ ẹgbẹ yẹn.

### Ilana lilo (`GET /api/v1/me/usage`)

`GET /api/v1/me/usage?range=<range>` (tun ṣe iranṣẹ ni `/v1/me/usage`) dapada lilo ati idiyele ti awọn ibeere bọtini ipe tirẹ: lapapọ, titẹ sii kan fun ọjọ UTC, fun ọjọ kan ati awoṣe, fun awoṣe ati olupese kọọkan. O pin asia, awọn ofin ijẹrisi, aaye `self:usage`, `Cache-Control: no-store` ati ihuwasi aṣiṣe ti ọna ipin loke. Bọtini naa jẹ ayẹwo ṣaaju `range`. Awọn aṣiṣe jẹ 400 (`Invalid range`), 401, 403, 404 ati 500 (`Failed to build usage`).

- `range` jẹ ọkan ninu `1d`, `7d`, `30d` (aiyipada) tabi `90d`. Eyikeyi iye miiran, iye ti o ṣofo tabi paramita atunwi jẹ 400. Eto naa duro ni `90d` lati dè iye owo ipe kan. Wiwo naa ka itan-akọọlẹ lilo aise nikan, kii ṣe awọn akopọ ojoojumọ, eyiti ko ni bọtini.
- Awọn ori ila ni a yan nipasẹ id bọtini ipe. Iwe orukọ bọtini ko baramu rara, ati pe awọn ori ila ti o gbasilẹ laisi id bọtini ko ni ka rara.
- Ṣiṣeto lẹsẹsẹ nṣiṣẹ awọn ibeere akojọpọ marun lori awọn ori ila bọtini ni window. Atunlo jara ti a ṣe fun awọn aaya 60 fun bọtini ati sakani, ati pe ipe ti a tun lo ko ṣiṣẹ. `generatedAt` rẹ funni ni ọjọ-ori rẹ.
- Awọn window dopin nigbati awọn jara ti wa ni itumọ ti. Kana ti o ni ontẹ nigbamii, fun apẹẹrẹ nipasẹ aago skew, ko ni ka.
- `coverage.retentionDays` jẹ eto idaduro lilo aise ti oniṣẹ ẹrọ (`retention.usageHistory` ninu awọn eto data data). `coverage.truncatedByRetention` jẹ otitọ nigbati ibiti o beere fun gun ju eto naa lọ. O ṣe afiwe awọn nọmba meji ati pe ko ṣayẹwo boya awọn ori ila ti nsọnu.
- Olupese ti pada bi o ṣe gbasilẹ fun awọn ibeere ti bọtini tirẹ. Awoṣe jẹ orukọ ti o gbasilẹ lẹhin `/` ti o kẹhin, ati awọn ori ila ti wa ni akojọpọ nipasẹ rẹ. Ibeere konbo ti gbogbo ibi-afẹde rẹ kọ ni a gbasilẹ pẹlu aami afisona bi olupese (orukọ konbo, `auto` tabi `combo`) ati okun awoṣe ti alabara firanṣẹ. Awọn ibeere miiran ti a kọ, fun apẹẹrẹ nipasẹ ẹrọ fifọ Circuit ṣiṣi, itutu awoṣe kan tabi foki-ipin kan, tọju olupese ibi-afẹde ati awoṣe.
- Yato si awọn iṣiro ati awọn idiyele, idahun gbejade lairi apapọ, awọn oṣuwọn aṣeyọri ati awọn akoko ti ibeere akọkọ ati ikẹhin.
- `byModel` ṣe atokọ awọn orisii olupese ati awoṣe 50 pẹlu awọn ibeere pupọ julọ. Pẹlu awọn orisii diẹ sii awọn titẹ sii rẹ ko ṣe afikun si `summary`, ati pe `summary.uniqueModels` ka gbogbo akọtọ awoṣe ti o gbasilẹ. `byModelTruncated` jẹ otitọ lẹhinna, ati awoṣe ti awọn orisii rẹ ṣubu ni ẹgbẹ mejeeji ti gige naa fihan lapapọ lapapọ.
- Meji owo ti wa ni royin. `costUsd` jẹ idiyele idiyele, bi awọn atupale lilo ṣe fihan. Awọn olupese ṣiṣe alabapin alapin, gẹgẹbi ero koodu Claude, ka $0 nibẹ. `listPriceUsd` jẹ idiyele lilo kanna ni idiyele atokọ, awọn ṣiṣe alabapin pẹlu. Ibeere ti awoṣe ko ni laini idiyele ka iye owo ti o fipamọ: idiyele ti olupese ṣe ijabọ, tabi iṣiro kan nigbati ibeere naa ti gbasilẹ. Nikan kan ìbéèrè pẹlu bẹni awọn kika 0, pẹlu ko si asami, ki a lapapọ le jẹ apa kan.
- Iwe adehun idahun jẹ `src/shared/schemas/selfUsage.ts` (`SelfUsageSeries` ni `docs/openapi.yaml`).

### Oju-iwe iṣẹ ti ara ẹni

Pẹlu `QUOTA_SELF_PANEL` lori, `/quota/{provider}` jẹ oju-iwe ti gbogbo eniyan. Dimu bọtini kan tẹ bọtini API kan nibẹ ati pe o rii awọn adagun omi bọtini naa fun olupese. Kọọkan pool fihan ọkan kaadi fun pool window, pẹlu awọn pool ká lilo fun gbogbo eniyan ati awọn bọtini ile ti ara ipin. Iwe akọọlẹ kọọkan ti adagun-odo ni awọn kaadi tirẹ, pẹlu lilo akọọlẹ naa ati ipin bọtini. Lilo akọọlẹ naa yoo han nikan nigbati bọtini le rii data akọọlẹ. Oju-iwe naa tun ṣe atokọ awọn opin-awoṣe fun akọọlẹ kọọkan ati lilo bọtini tirẹ. Akiyesi kan han nigbati iṣeto ba di bọtini ni bayi. Kaadi kan ṣe atokọ gbogbo fila-apẹẹrẹ ti bọtini pẹlu lilo rẹ, o si samisi awọn ti o de. `{provider}` jẹ id olupese tabi inagijẹ rẹ (`/quota/claude`, `/quota/cc`). Olupese aimọ, ati gbogbo ọna `/quota/*` nigba ti asia wa ni pipa, dahun 404. Awọn adagun omi lori aṣa OpenAI- tabi oju-ibaramu Anthropic ko ni oju-iwe. Awọn API si tun dahun fun wọn.

Oju-iwe naa ko ni igba. Bọtini naa jẹ fifiranṣẹ nikan ni akọsori `Authorization` ti `GET /api/v1/me/quota/{provider}`, `PATCH /api/v1/me/quota/{provider}` ati `GET /api/v1/me/usage`, rara ni URL kan. Bọtini ti olupin gba wa ni ipamọ `sessionStorage` taabu. Pẹlu "Ranti lori ẹrọ yii" o wa ni ipamọ `localStorage` dipo, ati "Gbagbe bọtini" yọ kuro lati awọn mejeeji. Bọtini ti olupin kọ ni a yọkuro lati ibi ipamọ.

Adagun adagun ni ipo `consent` fihan kaadi ayanilowo kan. Nibẹ ni dimu bọtini ṣeto odidi ogorun lati 0 si 100 ti ipin laišišẹ bọtini lati yani. Ẹniti o dimu tun mu bi igbanilaaye yoo ṣe pẹ to: titi ti a fi pa a, wakati 1, wakati 8, wakati 24, ọjọ 7 tabi 30 ọjọ. Iye akoko kan lati akoko fifipamọ. Lakoko ti akoko ipari kan wa ni agbara, dimu le tọju dipo. Ti akoko ipari yẹn ba kọja ṣaaju Fipamọ, kaadi naa ko firanṣẹ ohunkohun ko beere fun yiyan miiran. Pẹlu 0% ko si akoko ipari ti a firanṣẹ. Kaadi naa fihan akoko ipari ti o fipamọ pẹlu agbegbe aago rẹ ti a darukọ. Ifọwọsi ti akoko ipari rẹ ti kọja ti han bi ti pari.

Fun bọtini `hard` kaadi naa tun ṣe atokọ, fun ferese adagun-odo, kini awọn bọtini miiran ya si bọtini ni bayi. Ọna kọọkan jẹ nọmba kan fun gbogbo awọn bọtini miiran papọ. Ninu adagun ti awọn bọtini meji o jẹ nọmba ara bọtini miiran. Nọmba ti wiwo naa ko ṣe ijabọ ka bi ko si, kii ṣe bi odo. Fun bọtini `soft` tabi `burst` kaadi sọ pe ko si eeya kan.

Adagun adagun ni ipo `saturation` eyiti bọtini rẹ tọju ipin ogorun loke 0 fihan yiyọkuro nikan. O sọ pe ipin ti o fipamọ ko ni ipa nibẹ. Bọtini Yiyọ rẹ nfiranṣẹ 0 laisi akoko ipari. Adagun adagun ni ipo `saturation` pẹlu 0 ti o fipamọ ko fihan kaadi ayanilowo. Lẹhin fifipamọ, kaadi ti wiwo ti o pada ko nilo duro pẹlu ifiranṣẹ rẹ titi wiwo oju-iwe yoo yipada lẹẹkansi.

Ko si ohun ti o fipamọ titi dimu yoo tẹ Fipamọ tabi Yọọ kuro. Kọọkan tẹ rán ọkan `PATCH /api/v1/me/quota/{provider}` ìbéèrè, ati ki o kan keji tẹ rán ohunkohun nigba ti akọkọ ni isunmọtosi ni. Ara naa n gbe `ref` akomo adagun lati wiwo, ipin ati akoko ipari. Idahun si jẹ wiwo ipin ipin ti a tunṣe, ati pe oju-iwe naa fihan laisi kika keji. Nigbati awọn ifipamọ meji ba ni lqkan, oju-iwe naa ka ipin ni ẹẹkan lẹhin idahun ti o kẹhin. Oju-iwe naa ko tọju igbanilaaye ni ibi ipamọ ẹrọ aṣawakiri.

Iyipada ti o kọ ni alaye lori kaadi nipasẹ ọrọ ti a yan lati ipo HTTP. Ara aṣiṣe ko ka. A 401 sọ pe bọtini naa ko gba ati tun gbe ipin naa. A 403 sọ pe adagun ko gba awọn ayipada awin, ati pe 404 kan sọ pe adagun-odo ti lọ. Awọn mejeeji nfunni ni bọtini kan ti o tun gbe ipin naa. Idahun 400 tabi 4xx miiran beere lọwọ dimu lati ṣayẹwo ipin ogorun ati akoko ipari. A 429 beere lọwọ dimu lati duro, pẹlu awọn iṣẹju-aaya ti `Retry-After` nigbati idahun ba fun wọn. Idahun 5xx, 408 tabi ikuna nẹtiwọọki kan sọ pe iyipada le ma ti fipamọ, ati pe o tọju awọn iye ti a tẹ. Idahun ni ita adehun naa tun gbe ipin naa. Ifipamọ ti o kuna ko yọ bọtini kuro funrararẹ. Nigbati atungbejade lẹhin ti o ti kọ, oju-iwe naa yoo yọ bọtini kuro bi lori eyikeyi kika ti a kọ.

Ni kete ti bọtini kan ti gba, oju-iwe naa tun fihan kaadi “Ṣeto awọn irinṣẹ rẹ” pẹlu awọn taabu mẹta. "Koodu Claude " n fun `env` Àkọsílẹ fun `~/.claude/settings.json`. "Ikarahun" yoo fun awọn oniyipada kanna bi awọn ila `export`. "Ojú-iṣẹ Claude " n fun awọn iyeye fun window atọka ẹni-kẹta. Awọn awoṣe jẹ awọn awoṣe ipin ipin-ipin ti bọtini le pe fun olupese naa. Nigbati iru atokọ bẹ ko ba wa pẹlu bọtini, bulọki naa tan wiwa awoṣe ẹnu-ọna dipo. Adirẹsi ẹnu-ọna jẹ orisun API ti gbogbo eniyan ti awọn ijabọ olupin (`OMNIROUTE_PUBLIC_API_BASE_URL`, lẹhinna `OMNIROUTE_PUBLIC_BASE_URL`). Nigbati ko ba ṣeto bẹni, kaadi naa fihan ibi ipamọ ati sọ fun dimu lati beere lọwọ alabojuto naa. Bọtini naa han bi ibi ipamọ. "Fi bọtini mi kun" fi gbogbo bọtini sinu ọrọ lori iboju ati ninu kini awọn ẹda bọtini ẹda kan. Ti o wa titi ti apoti ti wa ni nso, awọn bọtini ti wa ni gbagbe tabi rọpo, tabi awọn iwe ti wa ni osi. Kaadi naa ko firanṣẹ ibeere ko si funni ni igbasilẹ faili.

Kika awọn aami API `stale` han bi o ti ṣee ṣe pe ko ti lọ. Kika ti o samisi `unavailable` han pẹlu idi rẹ, kii ṣe bi odo.

Lori awọn ero ipin ogorun oju-iwe naa fa ipin ti bọtini tirẹ nigbati API n ṣe ijabọ rẹ. O sọ pe nọmba naa jẹ iṣiro ati pe awọn ẹya meji rẹ lorukọ. Awọn opin-awoṣe fihan akọọlẹ nikan.

Nigbati window kan ba gbe `members`, kaadi rẹ tun fihan igi kan pẹlu apakan kan fun ọmọ ẹgbẹ kan, ni aṣẹ iho. Apa bọtini ibeere naa nlo awọ asẹnti naa. Awọn apa miiran yiyipo nipasẹ awọn awọ aworan apẹrẹ akori. Àlàyé ọrọ kan ṣe atokọ gbogbo apakan pẹlu iye rẹ, nitorinaa ko si ohun ti o da lori awọ. Awọn apa ti wa ni aami `You` tabi `Member N`, nibiti N jẹ Iho.

### Dedicated ibudo fun iwe

`QUOTA_PANEL_PORT` ṣii olutẹtisi keji ti o nṣe iranṣẹ nikan oju-iwe iṣẹ ti ara ẹni. O wa ni pipa ayafi ti o ba ṣeto oniyipada. `QUOTA_PANEL_HOST` jẹ adiresi dipọ ati awọn aiṣiṣe si `127.0.0.1`.

Olutẹtisi ṣe awọn ọna wọnyi si ibudo akọkọ ati awọn idahun 404 fun gbogbo ọna miiran:

| Ona                                                                      | Sin                                             |
| ------------------------------------------------------------------------ | ----------------------------------------------- |
| `/quota/{provider}`                                                      | Oju-iwe naa                                     |
| `/api/v1/me/quota/{provider}`, `/v1/me/quota/{provider}`                 | Wiwo ipin oju-iwe naa ka                        |
| `/api/v1/me/usage`, `/v1/me/usage`                                       | Ilana lilo oju-iwe naa ka                       |
| `/_next/static/`                                                         | Awọn iwe afọwọkọ, awọn aza ati awọn nkọwe ti Kọ |
| `/favicon.ico`, `/favicon.svg`, `/icon-512.png`, `/apple-touch-icon.png` | Awọn aami                                       |

`GET` ati `HEAD` ti wa ni titan laisi ara. Ibeere kan pẹlu ara ni a tun tan: `PATCH` kan ti ọna wiwo ipin, eyiti oju-iwe naa firanṣẹ lati fipamọ yiyan ayanilowo kan. Ọna eyikeyi miiran dahun 404, ayafi ibeere CONNECT, eyiti asopọ rẹ ti wa ni pipade pẹlu ko si idahun. Eyikeyi ibeere miiran ti o sọ ara kan dahun 404 ati asopọ rẹ ti wa ni pipade. Awọn ibeere iṣagbega kọ ati asopọ wọn ti wa ni pipade. Ọna kan pẹlu apakan aami kan tabi ami ami ajẹkù ti kọ, bi lori ibudo API. Bẹẹ ni ibi-afẹde kan pẹlu ohun kikọ kan ni ita ASCII titẹjade. Ohun kikọ iṣakoso aise ni ibi-afẹde ni idahun 400 nipasẹ olutọpa HTTP, ṣaaju iṣayẹwo ti ibudo yii. Beere awọn akọsori ti ilana naa ni ifipamọ fun lilo tirẹ ko jẹ titan: awọn orukọ ti o bẹrẹ pẹlu `x-middleware-`, `x-invoke-`, `x-nextjs-`, `x-now-` tabi `x-next-`, ati awọn orukọ `x-matched-path` ati `next-resume`. Awọn ibeere ti wa ni relayed lai wọn. Dasibodu naa, oju-iwe iwọle, API iṣakoso ati awọn ipa-ọna itọkasi ko le de ọdọ ibudo yii.

`PATCH` gbọdọ gbe `Content-Type: application/json`, laisi paramita tabi pẹlu `charset=utf-8` nikan. Ó gbọ́dọ̀ gbé `Content-Length` kan láti 1 sí 4096, tí a kọ gẹ́gẹ́ bí àwọn nọ́ńbà lásán, kò sì sí `Transfer-Encoding`. A `PATCH` ti o ṣẹ ọkan ninu awọn ofin wọnyi dahun 404. Diẹ ninu awọn ipari ti ko dara, gẹgẹbi ami ti o fowo si tabi ti a tun ṣe, ni idahun 400 nipasẹ HTTP parser ṣaaju ayẹwo ti ibudo yii. Ibudo naa ka awọn baiti ti a kede ṣaaju ki o kan si ibudo akọkọ, o duro ni pupọ julọ awọn aaya 5 fun wọn. Ara ti ko pari lẹhinna dahun 404 ati asopọ rẹ ti wa ni pipade. Ko si ohun ti o de ibudo akọkọ ni ọran yẹn, tabi nigbati alabara ba kọkọ lọ. Ibudo naa tun ṣe deede awọn baiti ti a kede, pẹlu `Content-Length` kanna. Awọn baiti lẹhin wọn ni a ka bi ibeere atẹle lori asopọ. Aṣoju yiyipada TLS ni iwaju gbọdọ siwaju `Content-Length` ati pe ko gbọdọ tun-pa ara ibeere naa pada. Ibudo akọkọ n ṣayẹwo bọtini API ninu akọsori `Authorization`, bi fun `GET`.

Ara 404 ni `{"error":"not_found","message":"Not found."}`. Awọn idahun atunṣe ti kuna 502 (`api_bridge_unavailable`) tabi 504 (`api_bridge_timeout`) laisi aaye `detail`.

Olutẹtisi ko ka `QUOTA_SELF_PANEL`, ko si tan oju-iwe naa. Lakoko ti asia naa wa ni pipa, oju-iwe naa ati API rẹ dahun 404 lori ibudo akọkọ, ati olutẹtisi ṣe atunṣe idahun yẹn.

Labẹ olupin idagbasoke (`next dev`), oju-iwe naa ko ni ibaraenisọrọ nipasẹ ibudo yii. Soketi atungbejade igbona idagbasoke jẹ ibeere igbesoke, ati ibudo naa kọ. Lo ibudo akọkọ lakoko idagbasoke.

Ibudo naa n ṣe iranṣẹ HTTP lasan ati oju-iwe naa nfi awọn bọtini API ranṣẹ. Tọju adiresi dipọ aiyipada ki o fi aṣoju yiyipada pẹlu TLS si iwaju rẹ. Adirẹsi dipọ miiran ju loopback ṣe igbasilẹ akiyesi yii:

```text
[Quota Panel] Bound to <host>. This port serves plain HTTP and the page sends API keys. Put a TLS reverse proxy in front of it.
```

Ẹlẹgbẹ loopback ti ko firanṣẹ akọsori firanšẹ siwaju ka bi agbegbe lori ibudo akọkọ. Nitorina aṣoju lori agbalejo kanna gbọdọ fi `X-Forwarded-For` ranṣẹ. Aṣoju lori adirẹsi ikọkọ jẹ igbẹkẹle fun akọsori yẹn nikan pẹlu `OMNIROUTE_TRUST_PROXY=private` (tabi `lan`). Eyikeyi ẹlẹgbẹ miiran jẹ ijabọ nipasẹ adirẹsi ti asopọ rẹ, ati awọn akọle ti o firanṣẹ siwaju ti lọ silẹ.

Olutẹtisi di pupọ julọ awọn asopọ 256 ni akoko kan. Onibara ni iṣẹju-aaya 10 lati firanṣẹ awọn akọle ibeere ati awọn aaya 30 lati firanṣẹ gbogbo ibeere naa. Asopọ ti o wa laaye laišišẹ tilekun lẹhin bii iṣẹju-aaya 5. Asopọ pẹlu ko si aṣayan iṣẹ-ṣiṣe fun 60 aaya ti wa ni pipade. Awọn iye wọnyi wa titi. Ṣeto asopọ ati awọn opin oṣuwọn lori aṣoju yiyipada ni iwaju bakanna. Aṣoju yiyipada ni iwaju yẹ ki o tọju awọn asopọ oke ti ko ṣiṣẹ fun o kere ju iṣẹju-aaya 5, tabi ko tun lo wọn. Yiyi si ibudo akọkọ nlo awọn akoko ti oke ti ibudo API (`API_BRIDGE_*`).

Olutẹtisi tun bẹrẹ nigbati `API_PORT` ko ṣeto. `QUOTA_PANEL_PORT` gbọdọ jẹ ibudo lati 1 si 65535, ti a kọ sinu awọn nọmba nikan. O gbọdọ yato si ibudo dasibodu ati ibudo API. Lakoko ti olupin WebSocket laaye wa ni titan, o gbọdọ tun yatọ si `LIVE_WS_PORT` (aiyipada 20132). Eyikeyi iye miiran ṣi ohunkohun ko si ṣe igbasilẹ ikilọ kan. Ikilọ nipa iye ti a kọ orukọ oniyipada ati pe ko tun ṣe iye naa. Ibudo ti o ti wa ni lilo tẹlẹ ṣii nkankan ko si ṣe igbasilẹ ikilọ yii:

```text
[Quota Panel] Port <port> is already in use. The quota panel port stays off.
```

Pẹlu `OMNIROUTE_BASE_PATH` ṣeto, olutẹtisi nreti gbogbo ọna loke labẹ asọtẹlẹ yẹn. Lo `OMNIROUTE_BASE_PATH` kanna ni akoko kikọ ati ni akoko ṣiṣe. Kọ pẹlu slash asiwaju ati pe ko si slash itọpa, fun apẹẹrẹ `/omniroute`. Apẹrẹ miiran, pẹlu `/` ati `/omniroute/`, fi ibudo silẹ pẹlu ikilọ kan, botilẹjẹpe kọ gba awọn fọọmu yẹn. Bakanna ni ọna ipilẹ ti apakan akọkọ ti sọ orukọ ipa ọna ohun elo: `api`, `v1`, `v1beta`, `_next`, `quota`, `dashboard`, `docs`, `login`, `codex`, `responses`, `anthropic`, `openai`, `v0` tabi `connect`, ni eyikeyi ọran.

Awọn idiwọn:

- `/quota/{provider}/` pẹlu itọpa idinku awọn idahun 404 lori ibudo yii.
- Osise iṣẹ ati ifihan ohun elo wẹẹbu ko ṣiṣẹ lori ibudo yii.
- Eto favicon aṣa kan ninu dasibodu ko han lori ibudo yii.
- Awọn aami ko han nigbati ohun elo nṣiṣẹ labẹ ọna ipilẹ.
- Ibudo soro HTTP/1.1.
- Asopọ ti o kuna ko ni tun gbiyanju titi ilana naa yoo tun bẹrẹ.
- Olutẹtisi ko ni asopọ tabi opin oṣuwọn fun adirẹsi alabara.
- Awọn iṣeto apoti ko ni aabo nipasẹ apakan yii.

## Yíyanjú Ìṣòro

### A ti ṣètò Redis ṣùgbọ́n kò sopọ̀

Ṣàyẹ̀wò pé a ti fi `ioredis` sílẹ̀ (`npm ls ioredis`) àti pé a lè dé
`QUOTA_STORE_REDIS_URL`. Nígbà tí àsopọ̀ bá kùnà, factory náà máa padà lo SQLite
(a máa ṣe àkọsílẹ̀ rẹ̀ ní `warn`).

### `peek` ń dá data àtijọ́ padà / fail-open

Tí `peek` bá ju àṣìṣe jáde, `enforceQuotaShare` máa ka èsì náà sí "fàyè gba"
(fail-open). Ṣàyẹ̀wò àwọn àkọsílẹ̀ `pino` fún àwọn àkọọlẹ̀ `quota:enforce` àti
`quota:factory` láti mọ ohun tó fa ìṣòro náà.

### Yíyapa counter lílò

Tí lílò olupèsè gangan bá yàtọ̀ sí àwọn counter, ohun tí a retí ni — sliding
window oníbucket méjì ní àṣìṣe tó tó ~1% ní àwọn ààlà window, àti pé `consume`
jẹ́ iṣẹ́ post-response tí kò dúró de èsì. Àmì saturation (`saturationSignals.ts`)
ń ka lílò olupèsè gangan pẹ̀lú TTL 30s, ó sì ń ṣàtúnṣe `globalUsedPercent`
gẹ́gẹ́ bí ó ṣe yẹ.

### Pool ń fi "kò sí data" hàn fún burn rate

`computeBurnRate` nílò ó kéré tán àwọn sample ìtàn méjì. Àwọn pool tuntun tí kò ní
àwọn ìpè `consume` tẹ́lẹ̀ yóò fi `tokensPerSecond: 0` àti `timeToExhaustionMs: null`
hàn.

## Ìṣípadà láti localStorage

Nígbà tí `/dashboard/costs/quota-share` bá kọ́kọ́ ṣí, ìkọ̀ `useLocalStoragePoolMigration`
máa ṣàyẹ̀wò pé:

1. `localStorage.getItem("omniroute:quota-share:pools")` kò ṣófo.
2. `GET /api/quota/pools` dá `[]` padà (DB ṣófo).

Tí àwọn méjèèjì bá jẹ́ òótọ́, yóò fi ọ̀kọ̀ọ̀kan àwọn pool àtijọ́ ránṣẹ́ sí `POST /api/quota/pools` ní ìdìpọ̀,
lẹ́yìn náà yóò yọ́ kọ́kọ́rọ́ localStorage náà kúrò. Ìṣípadà náà jẹ́ idempotent: ipò 2 ń dènà
àtún-ṣíṣípadà.

## Ìsọ̀rí Ọgbọ́n Inú Ẹ̀rọ

`quota-share` jẹ́ ọgbọ́n ìdarí ipa-ọ̀nà **tí a lò nínú ẹ̀rọ nìkan** (`INTERNAL_ROUTING_STRATEGY_VALUES` nínú

## DB Schema Lakotan

Awọn tabili mẹta ti a ṣafikun nipasẹ awọn iṣikiri `078`, `079` ati `085`:

- `quota_pools` + `quota_allocations` — pool itumo ati fun-bọtini ipin.
- `quota_consumption` — yiyi 2-garawa ounka fun `(apiKeyId, dimensionKey)`.
- `provider_plans` — afọwọṣe olupese ètò ìparun (awọn iwọn JSON fun connectionId).

Gbogbo awọn tabili ti a ṣafikun nipasẹ awọn iṣiwa `CREATE TABLE IF NOT EXISTS` idempotent.

Yiyawo ti a fọwọsi ṣe afikun awọn ọwọn mẹta: `quota_allocations.lending_percent` (odidi, aiyipada 0), `quota_allocations.lending_until` (epoch milliseconds, tabi `NULL` fun ko si akoko ipari) ati `quota_pools.borrow_mode` (aiyipada `saturation`). Iṣiwa rẹ nikan ṣe afikun awọn ọwọn wọnyi ko si kọ ila ti o wa tẹlẹ.

Iwe idawọle ogorun ṣafikun `quota_percent_ledger` (ila kan fun adagun-odo, akọọlẹ ati window eto) ati `quota_percent_ledger_tokens` (counter ami kan fun adagun-odo, akọọlẹ ati bọtini API ). `src/lib/db/quotaPercentLedger.ts` ka ati kọ wọn.
