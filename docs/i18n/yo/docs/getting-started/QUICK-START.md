## Ìgbésẹ̀ 1: Fi OmniRoute Sílẹ̀

Yan ọ̀nà tí o fẹ́:

### Àṣàyàn A: npm (A Dábàá)

```bash
npm install -g omniroute
```

### Àṣàyàn B: Docker

```bash
docker run -d --name omniroute -p 20128:20128 diegosouzapw/omniroute:latest
```

`:latest` ni SemVer tó dúró ṣinṣin tó ga jù lọ tí a ti **tẹ̀ jáde**. Kò **tẹ̀lé** git `main`. Lo `diegosouzapw/omniroute:X.Y.Z` gẹ́gẹ́ bí ẹ̀yà pàtó fún GitOps. Wo [Àwọn Àmì Image / Àwọn Ikanni Ìtẹ̀jáde](../guides/DOCKER_GUIDE.md#release-channels).

### Àṣàyàn C: Láti Source

```bash
git clone https://github.com/diegosouzapw/OmniRoute.git
cd OmniRoute
npm install
npm run dev
```

---

## Ìgbésẹ̀ 2: Bẹ̀rẹ̀ OmniRoute

```bash
omniroute
```

OmniRoute máa bẹ̀rẹ̀ ní `http://localhost:20128`. Pátákó ìdarí náà máa ṣí fúnra rẹ̀.

---

## Ìgbésẹ̀ 3: So Olùpèsè Tó Yẹ Pọ̀

Yan olùpèsè kan tí àwọn òfin àti ìwọ̀n lílò rẹ̀ bá àwọn àìní rẹ mu. Nínú **Pátákó Ìṣàkóso → Àwọn Olùpèsè**, so àkọọ́lẹ̀ tàbí kọ́kọ́rọ́ API tìrẹ pọ̀, lẹ́yìn náà dán àsopọ̀ náà wò. A kò ṣe ìdánilójú pé ìwọ̀le ọ̀fẹ́ àti lílò láìsí kọ́kọ́rọ́ yóò wà.

`auto` kì í fi àwọn olùpèsè tí a sàmì sí `tos: avoid` kún, títí kan Kiro, gẹ́gẹ́ bí ìṣètò àkọ́kọ́. Sísopọ̀ àkọọ́lẹ̀ kan kò ní yí ìlànà yẹn padà. Ìforúkọsílẹ̀ àfẹ́nú nínú **Pátákó Ìṣàkóso → Àwọn Àkójọpọ̀** kan gbogbo àwọn àkójọpọ̀ aládàáṣiṣẹ́. Ṣàyẹ̀wò [Ìtọ́sọ́nà Àwọn Ìpele Ọ̀fẹ́](./FREE-TIERS-GUIDE.md) kí o tó yan olùpèsè kan.

---

## Ìgbésẹ̀ 4: Ṣàyẹ̀wò Pé Ó Ń Ṣiṣẹ́

Láti [Àwọn Kọ́kọ́rọ́ API](http://localhost:20128/dashboard/api-manager), ṣẹ̀dá kọ́kọ́rọ́ tuntun. Fi kọ́kọ́rọ́ yìí pamọ́ nítorí kò ní hàn lẹ́ẹ̀kan sí i. Ṣàkíyèsí pé kọ́kọ́rọ́ yìí jẹ́ fún àwọn irinṣẹ́ láti wọ OmniRoute, kì í ṣe láti wọ àwọn olùpèsè upstream.

```bash
curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"
```

Ó yẹ kí o rí àtòjọ àwọn model tí o ti sopọ̀.

## Ìgbésẹ̀ 5: Darí IDE tàbí CLI Rẹ sí OmniRoute

Nínú IDE tàbí irinṣẹ́ CLI rẹ, ṣètò:

```
Base URL: http://localhost:20128/v1
API Key:  [copy from Dashboard → Endpoints]
Model:    auto
```

Ó parí! IDE rẹ ń lo OmniRoute pẹ̀lú yíyan olùpèsè láìfọwọ́ṣe báyìí.

### Àpẹẹrẹ IDE: VSCode/Continue.dev

1. Nínú VSCode, fi extension [Continue.dev](https://marketplace.visualstudio.com/items?itemName=Continue.continue) sílẹ̀.
2. Ṣàfikún àwọn ìlà wọ̀nyí sí `~/.continue/config.yaml` rẹ:

```
  - name: OmniRoute - Auto
    provider: openai
    model: auto
    apiBase: http://localhost:20128/v1
    apiKey: <YOUR_KEY>
```

3. Nínú páànù ìjíròrò Continue.dev, yan `OmniRoute - Auto`, ìwọ yóò sì fi àwọn ìbéèrè ránṣẹ́ sí OmniRoute.
4. (Àṣàyàn) Ìdánwò fún òǹkàwé — jẹ́ kí IDE rẹ ṣàfikún gbogbo àwọn ìṣètò mìíràn tí a ti kọ́ tẹ́lẹ̀ sí `config.yaml` 😊

### Àpẹẹrẹ CLI: Codex CLI

1. Nínú ẹ̀rọ ìṣiṣẹ́ rẹ, ṣètò environment variable náà lọ́nà tí yóò dúró pẹ́.
   Fún macOS/Linux (ṣàfikún un sí `~/.bashrc` tàbí `~/.zshrc` rẹ):

```bash
export OMNIROUTE_API_KEY="<YOUR_KEY>"
```

Fún Windows (Command Prompt):

```
setx OMNIROUTE_API_KEY <YOUR_KEY>
```

2. Ní báyìí, ẹ jẹ́ ká bẹ̀rẹ̀ Codex, ṣùgbọ́n pẹ̀lú ìṣètò fún OmniRoute. Ṣiṣe:

```
omniroute launch-codex --model auto
```

O lè ṣe èyí lọ́wọ́ nípasẹ̀ `codex` àti àwọn parameter command line láti pàtó endpoint àti kọ́kọ́rọ́ API, ṣùgbọ́n pẹ̀lú command tó wà lókè, OmniRoute máa bójú tó ohun gbogbo fún ọ.

Ìbẹ̀rẹ̀ pẹ̀lú command kan náà tún ń ṣiṣẹ́ fún àwọn CLI mìíràn nípasẹ̀ generic launcher — `omniroute run <target>` ń ṣe àtìlẹ́yìn fún `claude`, `codex`, `aider`, `goose`, `opencode`, `qwen`, àti `gemini` (wo [Àwọn Ìsopọ̀ CLI](../guides/CLI-INTEGRATIONS.md)).

3. Ó yẹ kí CLI náà máa fi àwọn ìbéèrè ránṣẹ́ sí OmniRoute báyìí.

### Jẹ́rìí pé irinṣẹ́ rẹ ń darí ìbéèrè sí OmniRoute

O lè rí àwọn kúlẹ̀kúlẹ̀ ìbéèrè náà nípa títẹ [Àbójútó/Àwọn Àkọsílẹ̀](http://localhost:20128/dashboard/logs) láti sidebar òsì. Títẹ̀ síwájú yóò fi àwọn kúlẹ̀kúlẹ̀ sí i hàn ọ́. Gẹ́gẹ́ bí àfikún, o lè rí irú àlàyé tí harness ayanfẹ́ rẹ ń fi ránṣẹ́. Èyí wúlò fún ẹ̀kọ́ àti ṣíṣe àwárí àṣìṣe.

## Àwọn Ìbéèrè Tí A Máa Ń Béèrè

### "Ṣé mo nílò kọ́kọ́rọ́ API?"

Kọ́kọ́rọ́ API OmniRoute ń jẹ́rìí sí àwọn irinṣẹ́ rẹ. Àwọn ìwé-ẹ̀rí upstream dá lórí olùpèsè: àwọn kan nílò kọ́kọ́rọ́ API tàbí wíwọlé sí àkọọ́lẹ̀. A kò ṣe ìdánilójú pé ìwọlé ọ̀fẹ́ yóò wà.

### "Kí ni `auto`?"

`auto` sọ fún OmniRoute láti yan olùpèsè tó dára jù lọ fún ìbéèrè kọ̀ọ̀kan láìfọwọ́ṣe. Ó máa ń gbé iyára, iye owó, dídára, àti ìwàláàyè iṣẹ́ yẹ̀ wò. Wo [Ìtọ́sọ́nà Auto-Combo](./AUTO-COMBO-GUIDE.md) fún àlàyé.

### "Eélòó ni ó ń ná?"

OmniRoute fúnra rẹ̀ jẹ́ **ọ̀fẹ́ àti orísun-ṣíṣí**. Àwọn olùpèsè tí o bá lò nìkan ni o máa sanwó fún. Ọ̀pọ̀ àwọn olùpèsè ní àwọn ìpele ọ̀fẹ́ — wo [Ìtọ́sọ́nà Àwọn Ìpele Ọ̀fẹ́](./FREE-TIERS-GUIDE.md).

### "Ṣé mo lè lò ó pẹ̀lú Claude Code / Cursor / Copilot?"

**Bẹ́ẹ̀ ni!** OmniRoute ń ṣiṣẹ́ pẹ̀lú irinṣẹ́ èyíkéyìí tó ṣàtìlẹ́yìn fún ọ̀nà ìṣètò OpenAI. Kàn ṣètò URL ìpìlẹ̀ sí `http://localhost:20128/v1`. Wo [Ìtọ́sọ́nà Àwọn Irinṣẹ́ CLI](../reference/CLI-TOOLS.md) fún àwọn ìlànà ìṣètò pàtó.

### "Kí ló máa ṣẹlẹ̀ bí iṣẹ́ olùpèsè kan bá dáwọ́ dúró?"

OmniRoute máa ń fo àwọn olùpèsè tí wọ́n kùnà láìfọwọ́ṣe, yóò sì gbìyànjú èyí tó kàn. O kò nílò láti ṣe ohunkóhun. Wo [Ìtọ́sọ́nà Auto-Combo](./AUTO-COMBO-GUIDE.md) fún àlàyé.
