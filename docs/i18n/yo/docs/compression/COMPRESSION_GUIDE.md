> Fipamọ́ 15-95% lórí àyíká ọ̀rọ̀ tó yẹ láìfọwọ́sí. Fún àkótán kíákíá, wo [abala Ìfúnpọ̀ README](../README.md#%EF%B8%8F-prompt-compression--save-15-95-eligible-tokens-automatically).

## Àkótán

OmniRoute ń ṣe ìlànà ìfúnpọ̀ prompt onímodulu kan tí ń ṣiṣẹ́ **ṣáájú láìdúró** kí àwọn ìbéèrè tó dé ọ̀dọ̀ àwọn olupèsè upstream. Èyí túmọ̀ sí pé fífi token rẹ pamọ́ máa ń ṣẹlẹ̀ láìfarahàn — kò sí ìyípadà tí o nílò láti ṣe sí ìṣàn iṣẹ́ rẹ.

```
Ìbéèrè Oníbàárà
  → Olùyan Ìlànà Ìfúnpọ̀
    → Àtúnṣe combo? → Lo ètò combo
    → Ààlà ìmúṣiṣẹ́ aládàáṣe? → Lo ipò auto
    → Ipò àìyípadà? → Lo ètò àgbáyé
    → Pípa? → Fò ìfúnpọ̀ kọjá
  → Ipò Ìfúnpọ̀ Tí a Yàn
    → Pípa: Kò sí ìfúnpọ̀
    → Fúyẹ́: Ìmúṣẹ̀dá àyè òfìfo/ìṣètò tó ní ààbò (~15%)
    → Déédéé: Yíyọ ọ̀rọ̀ àfikún ara Caveman kúrò (~30%)
    → Líle: Ìsọ̀rọ̀ ìtàn di àtijọ́ + àkópọ̀ (~50%)
    → Gíga Jù: Ìyọkúrò oníheuristic + dídín àwọn ìdípọ̀ kóòdù kù (~75%)
    → RTK: Àlẹ̀mọ́ àbájáde terminal/irinṣẹ́ tó mọ àṣẹ (ìwọ̀n upstream 60-90%)
    → Títòpọ̀: Ìlànà ọ̀pọ̀ engine tí a tò lẹ́sẹẹsẹ, RTK lẹ́yìn náà Caveman ní ọ̀pọ̀ ìgbà (ìwọ̀n tó yẹ 78-95%)
  → Ìbéèrè Tí a Fúnpọ̀ → Olùpèsè
```

## Àwọn Ìpo Ìdínkù

### Pípa

A kò lo ìdínkù kankan. Gbogbo àwọn ifiranṣẹ ń kọjá láìyípadà.

### Ìpo Lite (~15% ìfipamọ́, <1ms ìdádúró)

Ìpo tó ní ààbò jù lọ — ìmótótó ìṣètò. Ìkúrú abajade ọ̀pa rẹ̀ máa ń pàdánù díẹ̀, nítorí náà ọ̀nà àiyipada
(láìsí `allow-lossy`, `engine:lite` tàbí ìfẹ́sí àkópọ̀ tí a dárúkọ) máa ń ṣiṣẹ́ Lite pẹ̀lú
`compressToolResults: false`: àwọn abajade ọ̀pa ìṣáájú dé ọ̀dọ̀ olùpèsè láìyípadà.

| Ọ̀nà                      | Àlàyé                                                                                |
| ------------------------ | ------------------------------------------------------------------------------------ |
| `collapseWhitespace`     | Darapọ̀ àwọn laini òfo tó tẹ̀lé ara wọn àti àwọn ààyè tó wà ní òpin                    |
| `dedupSystemPrompt`      | Yọ àwọn ifiranṣẹ ètò tí ó tún ṣe lẹ́ẹ̀kan síi                                          |
| `compressToolResults`    | Kúrú àwọn abajade ọ̀pa ìṣáájú sí ààlà Lite (ó máa ń pàdánù díẹ̀: kìkì pẹ̀lú ìbéèrè àṣẹ) |
| `removeRedundantContent` | Yọ àwọn ìtọ́ni tí a tún ṣe lẹ́ẹ̀kan síi                                                 |
| `replaceImageUrls`       | Kúrú àwọn URI data àwòrán base64                                                     |

**Ó dára jù fún:** Ìlò tí ó máa ń ṣiṣẹ́ nígbà gbogbo, àti àwọn ìṣàn iṣẹ́ tó ṣe pàtàkì sí ààbò.

### Ìpo Standard (~30% ìfipamọ́)

A ṣe àpẹẹrẹ rẹ̀ lórí [Caveman](https://github.com/JuliusBrussee/caveman) — ó ń yọ àwọn ọ̀rọ̀ àfikún àti àwọn gbólóhùn tó gùn kúrò nígbà tí ó ń pa ìtumọ̀ mọ́:

- Ó ń yọ àwọn ọ̀rọ̀ àfikún kúrò ("please", "I think", "basically", "actually")
- Ó ń kó àwọn gbólóhùn tó gùn jọ ("in order to" → "to", "as a result of" → "because")
- Ó ń yọ ìṣọ́ra oníwà-bí-ìrẹ̀lẹ̀ kúrò ("Would you mind...", "If you could possibly...")
- Ó ní àwọn òfin regex tó lé ní 30 tí a ṣàtúnṣe fún àwọn ìbéèrè kóòdù

**Ó dára jù fún:** Àwọn ìṣàn iṣẹ́ kóòdù ojoojúmọ́ àti àwọn ẹgbẹ́ tó ń fiyè sí iye owó.

### Ìpo Aggressive (~50% ìfipamọ́)

Ìṣàkóso ìtàn ọlọ́gbọ́n fún àwọn ìpàdé tó gùn:

- **Mímú Àwọn Ifiranṣẹ Dàgbà** — àwọn ifiranṣẹ àgbà máa ń gba ìdínkù díẹ̀díẹ̀
- **Ìdínkù Abajade Ọ̀pa** — àwọn àbájáde ọ̀pa tó gùn máa ń dínkù tàbí farasin (àwọn laini àkọ́kọ́/ìkẹyìn,
  yíyan àwọn laini tó bá mu, ìkó àwọn kọ́kọ́rọ́ JSON jọ)
- **Àwọn Ààbò Ìdúróṣinṣin Ìṣètò** — ó ń rí i dájú pé àwọn ìpá `tool_use` + `tool_result` máa ń bá ara wọn mu
- **Ìmọ̀ Àyè Àyíká** — ó ń bọ̀wọ̀ fún àwọn ààlà àmì-ọrọ̀ fún àwòkọ́ṣe kọ̀ọ̀kan

**Ó dára jù fún:** Àwọn ìpàdé ìwádìí-àṣìṣe tó gùn àti àwọn ibi-kóòdù ńlá.

### Ìpo Ultra (~75% ìfipamọ́)

Ìdínkù tó pọ̀ jù fún àwọn ipò tí àmì-ọrọ̀ ṣe pàtàkì:

- **Pípá Àwọn Àkóónú Nipa Ìfojúsùn** — pípá àwọn àmì-ọrọ̀ nínú prose nípa lílo ìṣirò
- **Pípa Ìṣètò Mọ́** — àwọn àkọsílẹ̀ kóòdù tó wà láàárín fences, kóòdù inú laini, URLs àti àwọn ìdánimọ̀
  ni a máa fi sí àkójọ àkànṣe, a sì tún wọn ránṣẹ́ ní ti gidi; a kì í pípá wọn láé
- **Àyẹ̀wò SLM Àṣàyàn** — àwòkọ́ṣe kékeré àdúgbò lè tún ìpá náà ṣe nígbà tí a bá ṣètò rẹ̀
- Ó yàtọ̀ sí ìpo Aggressive: kò ṣiṣẹ́ pẹ̀lú dídàgbà àwọn ifiranṣẹ, ìdínkù abajade ọ̀pa
  tàbí àkótán ìpadàbọ̀ (kìkì ìkùnà ipele SLM lè darí ìṣàn sí ìpá Aggressive)

**Ó dára jù fún:** Nígbà tí o bá ń kọlu àwọn ààlà àyíká léraléra.

### Ìpo RTK (ààlà òkè 60-90%)

A ṣe àtúnṣe ìpo RTK fún àwọn abajade ọ̀pa tó gùn tí ó máa ń hàn nínú àwọn ìpàdé aṣojú kóòdù:

- Ó ń dá àwọn kíláàsì àṣẹ/abajade mọ̀ bí `git status`, `git diff`, `git log`, àwọn olùṣàyẹ̀wò,
  àwọn ìkọ́lé TypeScript/Vite/Webpack, ESLint/Biome/Prettier, npm audit/installs, àwọn log Docker, àbájáde infra,
  àti àbájáde shell gbogbogbò
- Ó ń lo àwọn àkójọpọ̀ àlẹ̀ JSON láti `open-sse/services/compression/engines/rtk/filters/`
- Ó ń kó àwọn àlẹ̀ TOML RTK schema v1 wọlé láti inú àwọn fáìlì `filters.toml` iṣẹ́-ìṣe tàbí àgbáyé, pẹ̀lú ìmúdájú inline-test àti ìṣàkóso ìgbẹ́kẹ̀lé fún àwọn fáìlì iṣẹ́-ìṣe
- Ó ní àwọn àlẹ̀ tí a kọ́ sínú rẹ̀ 56 pẹ̀lú àwọn àpẹẹrẹ ìmúdájú inline
- Ó ń yọ àwọn ìlànà ìṣàkóso ANSI, àwọn pẹpẹ ìlọsíwájú, àwọn laini tí a tún ṣe, àti ariwo tí kò ṣeé ṣe
- Ó ń pa àwọn ìkùnà, aṣìṣe, ìkìlọ̀, àwọn fáìlì tó yípadà, àwọn àkótán, àti ìrù abajade tó gùn mọ́
- Ó ń ṣe àtìlẹ́yìn fún àwọn àlẹ̀ iṣẹ́-ìṣe tí a ṣàkóso nípa ìgbẹ́kẹ̀lé, àwọn àlẹ̀ àgbáyé, àti ìmúpadàbọ̀ abajade aise tí a lè yọ ìdánimọ̀ kúrò nínú rẹ̀

**Ó dára jù fún:** Àwọn ìpàdé aṣojú pẹ̀lú shell, ìkọ́lé, ìdánwò, git, grep, àti àwọn àkọsílẹ̀ àbájáde fáìlì.

### Ìpo Stacked (ààlà tó yẹ 78-95%)

Ìpo Stacked ń ṣiṣẹ́ pẹ̀lú ọ̀pọ̀ ẹ́ńjìnnì ìdínkù ní àṣẹ tí a pinnu. Pipeline àiyipada ni:

```txt
RTK -> Caveman
```

Àṣẹ yẹn ń jẹ́ kí àbájáde ebute/ọ̀pa kéré ní àkọ́kọ́, lẹ́yìn náà ó ń lo ìkó ìtumọ̀ Caveman sí
ìbéèrè èdè àdánidá tó kù. A lè ṣètò àwọn pipeline Stacked ní gbogbogbò tàbí nípasẹ̀ àwọn àkópọ̀ ìdínkù tí a yàn sí àwọn àkópọ̀ ìdarí.

**Ó dára jù fún:** Àkóónú àdàpọ̀ pẹ̀lú àwọn log ọ̀pa tó gùn àti àwọn ìtọ́ni ènìyàn tàbí àwọn àkótán olùrànlọ́wọ́.

## Ìṣirò Ìfipamọ́ Láti Orísun Ìṣáájú

OmniRoute ṣàkọsílẹ̀ àwọn ìfipamọ́ ìfúnpọ̀ láti orísun méjì: àwọn ìwọ̀n ìdánwò iṣẹ́ akanṣe ìpilẹ̀ṣẹ̀ àti
àkójọpọ̀ ẹ̀rọ OmniRoute fúnra rẹ̀.

| Orísun  | Nọ́mbà README ìpilẹ̀ṣẹ̀ tí a lò níbí                                                                                       |
| ------- | ----------------------------------------------------------------------------------------------------------------------- |
| Caveman | `~75%` tóóki àbájáde díẹ̀, `65%` ìfipamọ́ àbájáde ní ìpíndọ́gba ìwọ̀n ìdánwò, ààlà `22-87%`, àti irinṣẹ́ ìfúnpọ̀ ìwọlé `~46%` |
| RTK     | Ìfipamọ́ `60-90%` lórí àbájáde àṣẹ; àpẹẹrẹ sáà `~118,000 -> ~23,900` tóóki, tàbí `79.7%` tí a fipamọ́ (`~80%`)            |

Fún àwọn ẹrù irinṣẹ́/àyíká-ọ̀rọ̀ tí ó ní àbárí, àkójọpọ̀ aiyipada OmniRoute to àwọn ẹ̀rọ náà léraléra:

```txt
RTK -> Caveman
```

Àwọn ìfipamọ́ àpapọ̀ jẹ́ ti ìsọdipúpọ̀, kì í ṣe ti àfikún:

```txt
combined = 1 - (1 - RTK savings) * (1 - Caveman input savings)
average  = 1 - (1 - 0.80) * (1 - 0.46) = 89.2%
range    = 1 - (1 - 0.60..0.90) * (1 - 0.46) = 78.4-94.6%
```

Nọ́mbà `78-95%` yẹn wúlò nígbà tí RTK àti Caveman méjèèjì bá lè dín ẹrù ìwọlé/àyíká-ọ̀rọ̀ kan náà kù.
Ipo àbájáde ìdáhùn Caveman yàtọ̀: nígbà tí a bá mú un ṣiṣẹ́, lo ìfipamọ́ àbájáde Caveman fúnra rẹ̀ (`65%`
ní ìpíndọ́gba, `~75%` gẹ́gẹ́ bí àkọlé pàtàkì, ààlà `22-87%`). Àpapọ̀ ìfipamọ́ owó ìlò sinmi lórí àkópọ̀ ìbéèrè/àbájáde rẹ.

### Ohun tí “ó yẹ” túmọ̀ sí gan-an

Ààlà àkọlé `15-95%` jẹ́ òótọ́, ṣùgbọ́n ó kan àkóónú **àṣejù tàbí aláìnídìí** nìkan — àwọn ìlà
àṣìṣe tí a tún sọ, àkọsílẹ̀ ìkọ́lé tí ń tún ìkìlọ̀ kan náà ránṣẹ́ lemọ́lemọ́, àkójọ àbájáde `grep`/ìkà-fáìlì tí ó tóbi jù. Kò
**túmọ̀ sí** pé gbogbo ìbéèrè yóò fipamọ́ tó bẹ́ẹ̀.

A ti fìdí rẹ̀ múlẹ̀ nípasẹ̀ ìdánwò gidi (`tests/unit/compression/stacked-compression-tool-result-savings.test.ts`): ìṣiṣẹ́
`stacked` (RTK + Caveman) lórí búlọ́ọ̀kù `tool_result` onírísí-Anthropic tí ó ní àwọn ìlà àṣìṣe tó jọra 300
ṣẹ̀dá **ìfipamọ́ tóóki 95.93% / ìfipamọ́ àmì-ọ̀rọ̀ 96.26%** — gan-an láàárín ààlà tí a polówó.
Ṣùgbọ́n ìṣiṣẹ́ pipeline kan náà lórí àbájáde irinṣẹ́ deede tí kò ní àtúnṣe àṣejù (àtòjọ àwọn ìbámu `grep` tó mọ́,
ìkà-fáìlì kúkúrú, ọ̀rọ̀ ìjíròrò lasán) máa ń ṣẹ̀dá **ìfipamọ́ tó fẹ́rẹ̀ẹ́ jẹ́ òdo** lọ́nà tó tọ́, nítorí
kò sí ohun àtúnsọ láti yọ, `validateCompression()` (`validation.ts`) kò sì ní gba àtúnkọ tí yóò yọ
tàbí yí àwọn búlọ́ọ̀kù kóòdù, URL, àkọlé, ẹ̀yà, tàbí àwọn àmì ìdánimọ̀ constant onílẹ́tà ńlá nìkan padà.

Èyí ni ìhùwàsí àìléwu tí a retí, kì í ṣe àbùkù: sáà ìkọ-kóòdù kan tí ó sábà máa ń ka/ṣe `grep` àwọn fáìlì tó mọ́ yóò
rí ìfipamọ́ àpapọ̀ kékeré bí ìfúnpọ̀ tilẹ̀ ṣiṣẹ́ ní kíkún, nígbà tí sáà kan tí ó bá pàdé
iyípo ìkùnà tàbí linter aláṣejù yóò rí gbogbo ààlà `78-95%` lórí ìṣàn yẹn. Má ṣe lo
ìdá ìfipamọ́ àpapọ̀ kékeré ti sáà kan ṣoṣo gẹ́gẹ́ bí ẹ̀rí pé a ṣètò ìfúnpọ̀ lọ́nà tí kò tọ́ — kọ́kọ́ ṣàyẹ̀wò bóyá
àbájáde irinṣẹ́ abẹ́lẹ̀ náà ní àtúnsọ àṣejù ní tòótọ́.

## Ìṣètò

### Pẹpẹ Iṣakoso

Lọ sí `Dashboard → Context & Cache`:

- **Caveman** — yíyan mode, àwọn akójọpọ̀ èdè, àyẹ̀wò ṣáájú, àti àwọn àiyípada àgbáyé
- **RTK** — àyẹ̀wò àlẹ̀ àṣẹ, àwọn ìṣètò ààbò RTK, àti katalogi àlẹ̀
- **Compression Combos** — àwọn pipeline engine tí a dárúkọ tí a yàn sí àwọn ìdàpọ̀ routing
- **Auto-Trigger Threshold** — máa bẹ̀rẹ̀ ìfúnpọ̀ fúnra rẹ̀ nígbà tí iye token bá kọjá ààlà

### Àyípadà fún Ìdàpọ̀ Kọọkan

Ní `Dashboard → Context & Cache → Compression Combos`, yan ìdàpọ̀ ìfúnpọ̀ kan fún
ìdàpọ̀ routing kan:

```txt
Combo: "free-tier-fallback"
  Compression Combo: "coding-agent-stack"
  Pipeline: RTK -> Caveman
  Targets:
    1. if/kimi-k2.7-code
    2. if/qwen3.8-max-preview
```

Èyí ń jẹ́ kí o lo ìfúnpọ̀ tí a kójọpọ̀ fún àwọn olupèsè ọ̀fẹ́/ìkọ́kọ́ kóòdù, nígbà tí o ń pa mode lite mọ́ lórí
àwọn ìforúkọsílẹ̀ tí a ń sanwó.

Àyànfẹ́ “Per-Combo Override” yìí yàtọ̀ sí àyípadà **routing-combo compression
mode** (Default/Off/Lite/Standard/Aggressive/Ultra/Codex Responses — schema pápá náà tún gba
`rtk`, `stacked` àti `omniglyph`) — àyípadà yẹn kì í yan pipeline compression-combo tí a dárúkọ; ó kan ń ṣètò pápá
`compressionMode` tí `resolveCompressionPlan` máa ń lò. A lè ṣètò rẹ̀ bóyá lórí káàdì combo (`Dashboard → Combos`) tàbí, láti #6760,
fún routing combo kọ̀ọ̀kan nínú àtòkọ “Assign to routing” ní
`Dashboard → Context & Cache → Compression Combos`, lẹ́gbẹ̀ẹ́ àpótí àyẹ̀wò fífi pipeline sílẹ̀
tí a ṣàlàyé lókè. Àwọn ojú-ìwé méjèèjì ń pamọ́ àwọn àyípadà wọn nípasẹ̀ endpoint `PUT /api/combos/{id}` kan náà.

### Àyípadà fún ìbéèrè kọ̀ọ̀kan

Rán akọsori ìbéèrè `x-omniroute-compression` kí o lè yí ètò ìfúnpọ̀ padà fún ìbéèrè kan ṣoṣo. Ó ní ààyè àṣẹ tó ga jù lọ — ó borí àyípadà routing-combo, profaili tó ń ṣiṣẹ́,
auto-trigger, àti Default pánẹ́ẹ̀lì. Àwọn iye tí a kò mọ̀ ni a kọ̀ sílẹ̀ (a kì í kọ ìbéèrè náà) àti
àyípadà àgbáyé ṣì ń ṣàkóso gbogbo rẹ̀: nígbà tí ìfúnpọ̀ bá wà ní pipa ní àgbáyé, akọsori náà kò lè
tan-an. Àwọn iye:

| Value         | Effect                                                                                                                    |
| ------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `off`         | Kò sí ìfúnpọ̀ fún ìbéèrè yìí.                                                                                              |
| `default`     | Profaili Default tí a yọ jáde láti pánẹ́ẹ̀lì (ó kọ profaili tó ń ṣiṣẹ́ sílẹ̀). A máa fi àwọn engine tó máa ń fa ìpàdánù sílẹ̀. |
| `safe`        | Kanna pẹ̀lú bí a kò bá fi akọsori náà ránṣẹ́.                                                                               |
| `allow-lossy` | Pa ètò oniṣẹ́ ìbéèrè yìí mọ́, pẹ̀lú àwọn àkótán, àwọn àlẹ̀ ìbámu, àti àwọn àtúnkọ̀wé ara.                                      |
| `engine:<id>` | Engine kan ṣoṣo nígbà tí a bá ti ṣiṣẹ́ ẹ́, bí `engine:rtk`. Èyí ni opt-in fún ìbéèrè yìí fún engine náà.                    |
| `<combo>`     | Combo tí a dárúkọ, tí a bá orúkọ mu ní àkọ́kọ́ (laibikita lẹ́tà ńlá tàbí kékeré), lẹ́yìn náà nípasẹ̀ id.                       |

Láìsí `allow-lossy`, `engine:<id>`, tàbí combo tí a dárúkọ, a kì í lo àwọn engine tó máa ń fa
ìpàdánù. Nígbà tí a bá dín Default, auto-trigger, tàbí àyípadà routing tí ó máa ń fa ìpàdánù kù, OmniRoute máa ń pa àwọn ìgbésẹ̀ tí a mọ̀ pé kò fa ìpàdánù láti pipeline tí a kójọpọ̀ tí a ṣètò mọ́, ní ìtòlẹ́sẹẹsẹ̀ tí a ṣètò. Ó máa padà sí
`session-dedup → lite` nìkan nígbà tí kò bá sí ìgbésẹ̀ tí kò fa ìpàdánù kankan nínú àwọn ìgbésẹ̀ tí a ṣètò.

Àyẹ̀wò **Effective pipeline** ti pánẹ́ẹ̀lì Settings ń fi ètò ìṣe-deede hàn. Nígbà tí auto-trigger bá lè ṣiṣẹ́, àyẹ̀wò kan náà tún máa ń fi pipeline ìṣe tó ní ààlà rẹ̀ hàn, kí ìpinnu runtime tí kò ní akọsori àti pánẹ́ẹ̀lì náà lè bá ara wọn mu.

A máa dá ètò tí a lò padà nínú akọsori ìdáhùn
`X-OmniRoute-Compression: <mode>; source=<source>`, níbi tí `<source>` ti jẹ́ ọ̀kan lára
`request-header`, `routing-override`, `active-profile`,
`auto-trigger`, `default`, tàbí `off`.

## To ti ni ilọsiwaju funmorawon Systems

Ni ikọja awọn ipo 7 ti a ṣalaye loke (orisun naa tun gba awọn ipo `codex-responses` ati awọn ipo `omniglyph`, eyiti itọsọna yii ko bo), awọn apakan ti o wa ni isalẹ awọn ẹya ideri ti o ṣiṣẹ inu tabi lẹgbẹẹ awọn ipo wọnyẹn: Imudanu Abajade Ọpa ati Ilọsiwaju Aging jẹ awọn igbesẹ 1 ati 2 ti ẹrọ ibinu (Ipo ibinu ati igbesẹ `aggressive` kan ti opo gigun ti epo ti a tolera, ipo isakoṣo ti paipu ti a ti tolera), bi o ṣe jẹ Stacked-Compression. downgrades `aggressive` ati `ultra` to `standard` fun caching awọn olupese nigba ti funmorawon wa ni titan, ati Caveman o wu Ipo ati Output Styles ti wa ni ijade-ni eto-kia awọn ilana, pipa nipa aiyipada, ti o apẹrẹ awọn awoṣe ká o wu dipo ti compressing awọn ìbéèrè.

### Kaṣe-mọ funmorawon

Diẹ ninu awọn olupese (bii Anthropic pẹlu caching kiakia) atilẹyin** kiakia caching** , eyi ti o jẹ ki wọn kaṣe awọn ẹya ara ti kiakia lati dinku awọn idiyele ati lairi. Nigba ti caching ti wa ni sise, ibinu funmorawon le kosi** farapa** iṣẹ nitori pe o yipada awọn ami ti a fipamọ, ti o sọ kaṣe di alaimọ.

Module `cachingAware.ts` yanju eyi nipasẹ** wiwa ọrọ caching** ati** Siṣàtúnṣe iwọn nwon.Mirza funmorawon** ni ibamu.

#### Bawo ni o ṣe n ṣiṣẹ

1. **Ṣewadii ọrọ-ọrọ caching** — Ṣiṣayẹwo ara ibeere fun awọn ami `cache_control`
2. **Ṣe idanimọ awọn olupese caching** — Ṣayẹwo ti olupese ibi-afẹde ba ṣe atilẹyin caching
3. **Satunṣe nwon.Mirza** — Downgrades `aggressive`/`ultra` si `standard` fun awọn olupese caching
4. **Rekọja ọna eto** — Awọn ilana eto nigbagbogbo jẹ cache, nitorinaa ma ṣe rọpọ wọn

Oluranlọwọ ilana naa tun da asia `deterministicOnly` pada, ṣugbọn olupilẹṣẹ ero n gba ilana — nikan ko si nkankan ti o ka asia loni.

#### Apeere koodu

```ts
import {
  detectCachingContext,
  getCacheAwareStrategy,
} from "@omniroute/open-sse/services/compression/cachingAware";

const body = {
  model: "anthropic/claude-sonnet-4.5",
  messages: [{ role: "user", content: "Hello" }],
  cache_control: { type: "ephemeral" }, // ← Cache marker
};

const ctx = detectCachingContext(body, { provider: "anthropic" });
// → { hasCacheControl: true, provider: "anthropic", targetFormat: null, isCachingProvider: true }

const strategy = getCacheAwareStrategy("aggressive", ctx);
// → { strategy: "standard", skipSystemPrompt: true, deterministicOnly: true }
```

#### Nigbati lati lo

Kaṣe-mọ funmorawon ni** nigbagbogbo lori** — ko si iṣeto ni ti nilo. O bẹrẹ ni nigbakugba ti funmorawon ba wa ni titan ati pe olupese ibi-afẹde ṣe atilẹyin caching kiakia (Anthropic, OpenAI, bbl); Awọn asami `cache_control` ti o fojuhan ko nilo — olupese caching nikan nfa idinku, ati awọn asami nikan ko ṣe (iṣawari awọn kikọ sii kaṣe telemetry, kii ṣe ipinnu ilana).

OpenRouter ka bi olupese caching nikan fun awọn awoṣe `anthropic/*` : Awọn ibeere koodu Claude tọju awọn aaye fifọ `cache_control` wọn (4 ni pupọ julọ) ati pe ẹṣọ ṣe aabo ìpele, lakoko ti gbogbo idile OpenRouter miiran (`openai/`, `google/`, `qwen/`,…) duro ni ṣi kuro ati aisi aabo.

### Onitẹsiwaju ti ogbo

Awọn ibaraẹnisọrọ gigun kojọpọ ọpọlọpọ awọn iyipada ifiranṣẹ, ṣugbọn awọn iyipada ti ogbo di kere si ibaramu. module `progressiveAging.ts`** degrades awọn ifiranṣẹ nipa Tan ijinna** (ijinna wọn lati opin ibaraẹnisọrọ). Pẹlu awọn aiyipada gbigbe (`verbatim: 2, light: 2, moderate: 3`):

- **Awọn iyipada 2 kẹhin (ijinna ≤ 2)** : Pa verbatim
- **Ijinna 3** : Caveman funmorawon (yiyọ kikun)
- **Ijinna 4 +** : Awọn ifiranṣẹ iranlọwọ ni ṣoki; awọn ifiranšẹ olumulo dinku si laini akọkọ wọn, ti o ni awọn ohun kikọ 120; miiran ipa untouched. Awọn ifilọlẹ eto, awọn ifiranṣẹ ti o ti dagba tẹlẹ ati ifiranṣẹ olumulo tuntun nigbagbogbo ni a tọju ni ọrọ-ọrọ laibikita ijinna. Ko si ohun ti o lọ silẹ taara, ati pe ẹgbẹ `light` ko le de ọdọ pẹlu awọn aṣiṣe ti a firanṣẹ (`light` dogba `verbatim`).

#### Apeere koodu

```ts
import { applyAging } from "@omniroute/open-sse/services/compression/progressiveAging";

const messages = [
  { role: "system", content: "You are a helpful assistant" },
  { role: "user", content: "What is 2+2?" },
  { role: "assistant", content: "4" },
  // ... 50 more turns ...
];

const { messages: aged, saved } = applyAging(messages, {
  verbatim: 3, // last 3 turns: verbatim
  light: 8, // distance <= 8: lite compression
  moderate: 20, // distance <= 20: caveman compression
  fullSummary: 5, // required by the type, not read by the banding code
  // distance > 20: summarized (assistant) / first line kept (user)
});

// saved = number of tokens saved
```

#### Nigbati lati lo

Ilọsiwaju ti ogbo ni** nigbagbogbo lori** fun ipo `aggressive` — o jẹ igbesẹ 2 ti `compressAggressive()`. Ipo Ultra ko ṣiṣẹ. O wulo ni pataki fun:

- Awọn akoko ifaminsi igba pipẹ
- Olona-ọjọ awọn ibaraẹnisọrọ
- Awọn ṣiṣan iṣẹ aṣoju pẹlu ọpọlọpọ awọn ipe irinṣẹ

### Caveman o wu Ipo

Caveman o wu mode afikun** awọn ilana kiakia eto** ti o beere awọn awoṣe ara fun terse o wu — awọn `lite` ipele béèrè fun ṣoki ti idahun ti o pa ni kikun awọn gbolohun ọrọ, `full` béèrè o lati "dahun terse bi smart caveman", ati `ultra` béèrè fun telegraphic o wu; Awọn ilana nikan beere, wọn ko le ṣe ẹri. Awọn ibeere gba wọn nipasẹ `applyOutputStyles()` (`open-sse/services/compression/outputStyles/apply.ts`): `open-sse/handlers/chatCore.ts` akọkọ ṣe ipinnu yiyan pẹlu ẹhin-compat shim (`resolveOutputStyleSelection()` in `open-sse/services/compression/outputStyles/backCompat.ts`), eyiti, lakoko ti `outputStyles` ti ṣofo, maapu `cavemanOutputMode` ti o ṣiṣẹ si aṣa iṣelọpọ `terse-prose` ni `cavemanOutputMode.intensity` (wo Back-compat ni isalẹ); yiyan `outputStyles` ti ko ṣofo ni a lo bi o ti ri, ati `cavemanOutputMode.enabled` ati `intensity` ko ni ipa kankan, nigba ti yiyi `autoClarity` rẹ si tun wa. `outputMode.ts` di awọn ọrọ itọnisọna mu (`CAVEMAN_INSTRUCTION_BY_LANGUAGE`), ipadabọ akoonu ati oluranlọwọ ibi ti abẹrẹ nlo; injector `applyCavemanOutputMode()` tirẹ ko ni olupe iṣelọpọ.

#### Bawo ni o ṣe n ṣiṣẹ

Ipo yii kii ṣe titẹ titẹ sii. O ṣe afikun ohun amorindun itọnisọna si tọ eto (wo Bawo ni abẹrẹ ṣe n ṣiṣẹ ni isalẹ), ati eyikeyi ipo funmorawon titẹ sii ti a yan fun ibeere naa tun nṣiṣẹ lẹhinna, lori ara ti o gbe bulọọki bayi. Ṣaaju gbolohun awọn aala ti o pin ti gbogbo ipele pari pẹlu, ipele `full` Gẹẹsi ka:

> "Dahun terse bi smart caveman. Ju ìwé (a/an/the), filler (just/really/basically/actually/simply), pleasantries, hedging. Fragments OK. Kukuru synonyms (nla ko sanlalu, fix ko muse). Jeki gbogbo imọ nkan na, koodu, aṣiṣe, URLs, identifiers gangan. "

#### Bawo ni abẹrẹ ṣiṣẹ

`applyOutputStyles()` (`open-sse/services/compression/outputStyles/apply.ts`) ṣe ipinnu yiyan lodi si katalogi naa (ids ti a ko mọ ati awọn aṣa ti ko baamu agbegbe ti lọ silẹ, kii ṣe aṣiṣe; yiyan ti o pinnu si ara ko fi ara silẹ ni iyipada, fo bi `no_styles`), ṣajọpọ awọn ilana ti o yan ni ilana katalogi, fikun gbolohun awọn aala.** lẹẹkan** (pẹlu gbolohun ọrọ ailewu, `SAFETY_BOUNDARIES` tabi itumọ rẹ, nigbati `less-code` tabi `ponytail` ti yan), ati bẹrẹ bulọki pẹlu ami-ami arapotency kan (`[OmniRoute Output Styles]`), nitorinaa atunbere jẹ ko si-op. Nigbati ede ti o yanju (wo yiyan Ede ni isalẹ) ni itumọ kan, itọnisọna ti agbegbe jẹ itasi dipo Gẹẹsi.

On a body with a non-empty `messages` array, the idempotency check runs before the content bypass: when the `[OmniRoute Output Styles]` marker is already in the top-level `system` field (a string or a content-block array) or in a system message with string content, the body is left unchanged as `already_applied` and no keyword check runs. Otherwise a content bypass (`shouldBypassCavemanOutputMode()` in `open-sse/services/compression/outputMode.ts`) checks the text of the last three messages, whatever their role, and skips the styles for the whole turn when that text matches its security, irreversible-action or clarification keywords, or an order-sensitive sequence: `first`, `then`, `after that`, `before`, `rollback` or `backup` followed within 240 characters by `delete`, `drop`, `migrate`, `deploy` or `release`. The bypass runs while the **Auto-Clarity Bypass** toggle (`cavemanOutputMode.autoClarity`, on by default) is on; turning the toggle off skips the keyword check.

Nigbati ọna-ọna ba jẹ ki ọna yii kọja, `placeSystemInstruction()` (faili kanna), eyiti ko ṣẹda `messages[0]` tuntun, gbe bulọọki naa si akọkọ ninu iwọnyi o rii:

1. Ifiranṣẹ eto oludari pẹlu akoonu okun: bulọki ti wa ni afikun lẹhin ọrọ rẹ.
2. Aaye `system` ti o ga julọ: bulọki naa ti wa ni ifikun lẹhin ọrọ ti okun kan, tabi ṣafikun bi idinaki ọrọ tuntun si ọna idina akoonu.
3. Ifiranṣẹ eto akọkọ nigbamii pẹlu akoonu okun: bulọki naa ti wa ni afikun lẹhin ọrọ rẹ.
4. Ko si ọkan ninu awọn loke: Àkọsílẹ lọ sinu ifiranṣẹ eto titun ni opin `messages`.

Lori ara ti ko ni eto `messages` (tabi pẹlu eyi ti o ṣofo), ko si akoonu fori gbalaye ati aaye `system` ipele-oke ko ni imọran. Bulọọki naa ti wa ni ifikun lẹhin ọrọ ti aaye `instructions` okun kan, ayafi ti aaye yẹn ti ni ami ami `[OmniRoute Output Styles]` tẹlẹ ninu, ninu ọran ti ara ti wa ni iyipada laisi iyipada bi `already_applied`. ### Pipeline tolera

Awọn tolera mode nṣiṣẹ** ọpọ enjini ni ọkọọkan** — nigbagbogbo RTK akọkọ (60-90% awọn ifowopamọ lori iṣelọpọ irinṣẹ), lẹhinna Caveman lori ọrọ ti o ku (~ 46% awọn ifowopamọ titẹ sii). Ti a kọ, iyẹn ni** 78-95% yẹ ibiti** (wo Iṣiro Awọn ifowopamọ Igbesoke oke): awọn aropin `1 - (1 - 0.60..0.90) × (1 - 0.46)` ≈ 89%.

#### Bawo ni o ṣe n ṣiṣẹ

```
Input (1000 tokens)
  → RTK (command-aware filter) → 200 tokens
    → Caveman (filler removal) → 108 tokens
  → Output (108 tokens, ~89% savings)
```

#### Nigbati lati lo

Lo ipo tolera fun:

- Awọn iṣan-iṣẹ iṣẹ ti o wuwo (iforukọsilẹ aṣoju, iwadii)
- Iṣatunṣe ipele iye owo-kókó
- Nigbati o ba nilo awọn ifowopamọ ami ti o pọju

Awọn opo gigun ti o tolera ni a tunto nipasẹ eto funmorawon `stackedPipeline` agbaye, tabi nipasẹ konbo funmorawon ti a npè ni ti a yàn si konbo ipa-ọna kan (wo Per-Combo Yipadanu loke) — kii ṣe nipasẹ `modePack` auto-combo (aaye yẹn nikan tun-aṣayan awoṣe konbo adaṣe, ati `stacked` kii ṣe orukọ idii to wulo).

- **Àwọn combo ìbéèrè àti ìdáhùn kíákíá**: Lo ipò `lite` fún àwọn ìdáhùn yíyára
- **Àwọn combo tó ń lo irinṣẹ́ púpọ̀**: Lo ipò `stacked` fún ìfipamọ́ tó pọ̀ jù
- **Àwọn combo iṣelọpọ**: má ṣe tan ìkọ̀kọ̀ọ̀ náà fún àwọn olùpèsè ìfipamọ́ — àtúnṣe
  tó mọ ìfipamọ́, tí ó máa ń ṣiṣẹ́ nígbà gbogbo, yóò sọ `aggressive`/`ultra` kalẹ̀ sí `standard` láìfọwọ́sí
  (kò sí ipò `cache-aware` tí a lè yàn)
