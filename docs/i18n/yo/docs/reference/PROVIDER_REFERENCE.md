## Awọn ẹka

- **Ọfẹ** ipele — ọfẹ pẹlu bọtini API (ti a tunto nipasẹ dasibodu)
- **Ko si-ifọwọsi** — awọn aaye ipari gbangba ti ko nilo bọtini tabi wọlé rara
- **OAuth** Ṣiṣan wọle — ti a ṣakoso nipasẹ OmniRoute, ko si bọtini API ti o nilo
- **Kuki wẹẹbu** — murasilẹ ohun elo wẹẹbu olupese nipasẹ auth kuki
- **bọtini API** Olupese isanwo — tunto nipasẹ bọtini API (awọn kirẹditi ọfẹ le lo)
- **Agbegbe** — nṣiṣẹ lori ẹrọ olumulo (Ollama, LM Studio, vLLM, ati bẹbẹ lọ)
- **Wa** — ayelujara search
- **Ohun** — awọn olupese ohun nikan (TTS/STT)
- **Aṣoju oke** awọn olupese — ti o jẹ aṣoju si awọn olupese miiran
- **Awọsanma oluranlowo** — awọn aṣoju ifaminsi igba pipẹ (Codex Cloud, Devin, Jules)
- **Eto** — OmniRoute-olupese inu (loopback, ati bẹbẹ lọ)

Afikun afi: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (nibi ti o ti han): `native` — iṣẹ gidi-pipe API; `emulated` — `tools` ti wa ni kiakia-farawe nipasẹ `webTools.ts` (regex-parsed `<tool>{...}</tool>` blocks); `none` — `tools` ti lọ silẹ ni idakẹjẹ lọwọlọwọ. Wo #7286.

Lo dasibodu ni `/dashboard/providers` lati mu ṣiṣẹ, tunto, ati idanwo olupese kọọkan.
