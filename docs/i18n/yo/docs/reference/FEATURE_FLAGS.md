> Àwọn tógù àsìkò-ṣiṣe tí ń yí ìhùwàsí OmniRoute padà **láìṣe àtúnkóṣiṣẹ́**.
> Gbogbo àmì tí a tò síbí ni a ṣàlàyé nínú
> [`src/shared/constants/featureFlagDefinitions.ts`](../../src/shared/constants/featureFlagDefinitions.ts)
> — orísun òtítọ́ kan ṣoṣo. Dásíbọ́ọ̀dù àti REST API méjèèjì ń kà láti inú
> fáìlì yẹn, nítorí náà a ṣe àgbéjáde tábìlì tó wà nísàlẹ̀ láti bá a mu ní 1:1.

## Kí Ni Àwọn Àmì Ẹ̀yà

Àmì ẹ̀yà jẹ́ tógù tó ní orúkọ (boolean tàbí enum) tí a lè yí iye rẹ̀ padà ní
àsìkò-ṣiṣe, tí a sì lè fi pamọ́ sínú dátábésì, láìní láti tún ìlànà ṣiṣẹ́. A
ṣàpèjúwe àmì kọ̀ọ̀kan pẹ̀lú `FeatureFlagDefinition` kan tó ní `key`, `label`,
`description`, `category`, `defaultValue`, `type`, àti ìtọ́kasí `requiresRestart`.

### Ètò Ìpinnu

[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) ló ń pinnu
**iye tó ń ṣiṣẹ́** fún àmì kan gẹ́gẹ́ bí àtòlẹ́sẹẹsẹ yìí (èyí tó ga jù ló borí):

1. **Ìṣàkóso láti DB** — iye tí a fi pamọ́ sínú tábìlì `key_value` lábẹ́
   àyè-orúkọ `feature_flags` (tí a ṣètò nípasẹ̀ dásíbọ́ọ̀dù tàbí REST API).
2. **Àyípadà àyíká** — `process.env[<KEY>]`, bí a bá ṣètò rẹ̀ tí kò sì ṣófo.
3. **Àìròtẹ́lẹ̀ ìtumọ̀** — `defaultValue` láti inú `featureFlagDefinitions.ts`.

A ka àmì boolean sí **tí a ti mú ṣiṣẹ́** nígbà tí iye tó ń ṣiṣẹ́ rẹ̀ bá jẹ́ `"true"`,
`"1"`, tàbí `"yes"` (wo `isFeatureFlagEnabled()`).

> [!NOTE]
> Ọ̀pọ̀ jù lọ àwọn àmì náà tún ní àyípadà àyíká tó bá wọn mu, pẹ̀lú **orúkọ kan náà**,
> tí a ṣàkọsílẹ̀ rẹ̀ nínú [`ENVIRONMENT.md`](./ENVIRONMENT.md). Ìṣàkóso àmì láti DB
> ní ipò gíga ju àyípadà àyíká yẹn lọ. A máa fi àmì tó ní
> `requiresRestart: true` pamọ́ lẹ́sẹ̀kẹsẹ̀, ṣùgbọ́n a kàn tún un kà nígbà tí ìlànà
> bá bẹ̀rẹ̀ — yíyí i padà máa ń fi àsíá **"Tún Sẹ́fà Bẹ̀rẹ̀"** hàn lórí dásíbọ́ọ̀dù.

Pípà á jẹ́ àṣàyàn àìyípadà: àwọn àṣìṣe probe mìíràn tí a fipamọ́ ṣì máa dí dispatch dúró fún àkókò TTL cache (ìṣẹ́jú márùn-ún). |

> [!NOTE]
> `INPUT_SANITIZER_BLOCK_THRESHOLD` àti alias àtọ̀runwá rẹ̀
> `INJECTION_GUARD_BLOCK_THRESHOLD` máa ń ṣàtúnṣe mode `block` ti
> `INJECTION_GUARD_MODE`, ṣùgbọ́n wọ́n jẹ́ environment variables lasan tí a kà nípasẹ̀
> [`src/shared/utils/injectionSeverity.ts`](../../src/shared/utils/injectionSeverity.ts),
> wọn kì í ṣe feature flags: wọn kò ní àyípadà DB tàbí toggle dashboard. Wo
> [`ENVIRONMENT.md`](./ENVIRONMENT.md#4-security--authentication).

> [!NOTE]
> Column `Restart` máa ń samisi àwọn flags tí ó ní `requiresRestart: true` — iye náà
> máa ń wa ní fipamọ́ lẹ́sẹ̀kẹsẹ̀, ṣùgbọ́n ó máa bẹ̀rẹ̀ sí í ṣiṣẹ́ lẹ́yìn tí process bá tún rù. Àwọn
> flags Enum máa kọ iye èyíkéyìí tí kò bá sí nínú àkójọ àwọn iye tí a yọ̀ǹda (a máa ń fọwọ́sí wọn ní server-side nínú
> `setFeatureFlagOverride()` àti REST `PUT` handler).

## Yíyí Ààmì Padà

### Pẹpẹ Ìṣàkóso

Lọ sí **Pẹpẹ Ìṣàkóso → Ètò → Ààmì Ẹ̀yà**
(`/dashboard/settings/feature-flags`). Grid náà
(`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`)
ń ṣe àtìlẹ́yìn fún:

- **Wíwá** nípa kọ́kọ́rọ́ tàbí àlàyé, àti **yíyan** nípa ẹ̀ka (pẹ̀lú
  ìwò **Ó Nílò Àtúnbẹ̀rẹ̀** tí a ṣe àfikún).
- **Yíyí** fún àwọn àmì boolean àti **àtòjọ yíyan** fún àwọn àmì enum
  (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`).
- Ààmì orísun fún àmì kọ̀ọ̀kan — `DB`, `ENV`, tàbí `DEF` — tó ń fi hàn ibi tí
  iye tó ń ṣiṣẹ́ ti wá.
- Bọ́tìnì **Tún Ètò Ṣètò Padà** (tí a máa ń fi hàn fún àwọn àmì orísun `DB` nìkan)
  láti yọ àyípadà náà kúrò, àti bọ́tìnì **Tún Gbogbo Àyípadà Ṣètò Padà** ní ìsàlẹ̀.
- Bánà **Àtúnbẹ̀rẹ̀ Olùpèsè** nígbà tí a bá yí àmì `requiresRestart` padà.

### REST API

Gbogbo iṣẹ́ ń lọ nípasẹ̀ ọ̀nà kan ṣoṣo:
[`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts).
Ọ̀nà kọ̀ọ̀kan nílò ìpàdé dashboard tí a ti jẹ́rìí (`401` bí kò bá sí).

#### `GET /api/settings/feature-flags`

Ó máa dá gbogbo àmì padà pẹ̀lú iye tó ń ṣiṣẹ́, orísun, àti àkótán.

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Require API Key",
      "description": "Require an API key for all incoming requests",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... gbogbo àmì 114
  ],
  "summary": {
    "total": 114,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

Ṣètò tàbí yọ àyípadà kan ṣoṣo kúrò. Ara ìbéèrè: `{ key: string; value?: string }`.
Tí a bá fi `value` sílẹ̀, ó máa yọ àyípadà náà kúrò (ó sì máa dá iye env / àìpẹ̀yà padà).

```bash
# Ṣètò àyípadà DB
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# Yọ àyípadà náà kúrò (láìsí "value")
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

Ìdáhùn náà máa tún `effectiveValue`/`source` tuntun jáde, pẹ̀lú
`previousValue`/`previousSource`, àti `requiresRestart`. A máa kọ́ àwọn kọ́kọ́rọ́
tí a kò mọ̀ àti àwọn iye enum tí kò sí láàárín ààlà pẹ̀lú `400`.

#### `DELETE /api/settings/feature-flags`

Ó máa pa gbogbo àyípadà DB rẹ́ lẹ́ẹ̀kan ṣoṣo, ó sì máa dá gbogbo àmì padà sí iye
env / àìpẹ̀yà wọn. Ó máa dá `{ cleared: <count>, message: "..." }` padà.

> [!NOTE]
> Àwọn àmì tí `requiresRestart: true` máa ń ṣiṣẹ́ lẹ́yìn tí a bá tún ètò náà
> gbé jáde. Ìṣàn àtúnbẹ̀rẹ̀ dashboard máa ń pè `POST /api/restart`, lẹ́yìn náà
> ó máa ń ṣe ìbéèrè léraléra sí `GET /api/health/ping` títí tí olùpèsè yóò fi padà wá.

## Ọ̀nà Àfẹ́yinti Pajawiri fún Ìnáwó

`OMNIROUTE_EMERGENCY_FALLBACK` (ẹ̀ka `runtime`, àìpé `true`) ń ṣàkóso
ọ̀nà àfẹ́yinti ọ̀fẹ́ pajawiri nínú
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts).
Nígbà tí a bá mú un ṣiṣẹ́, àwọn ìbéèrè tí ìnáwó wọn bá tán ni a máa darí sí
olùpèsè/àwòṣe àfẹ́yinti ọ̀fẹ́ dípò kí wọ́n kùnà pátápátá. Ṣètò rẹ̀ sí `false` (tàbí `0`) — nípasẹ̀
bọ́tìnì ìṣàkóso lórí dashboard, àtúnṣe DB, tàbí oníyí àyíká
`OMNIROUTE_EMERGENCY_FALLBACK` — láti pa ìhùwàsí náà, kí àwọn ìbéèrè tí
ìnáwó wọn ti tán sì kùnà. (A ṣàfihàn rẹ̀ gẹ́gẹ́ bí bọ́tìnì ìṣàkóso lórí dashboard nínú PRs #3741 / #3752.)

Ìdáhùn tí ọ̀nà àfẹ́yinti yìí pèsè ní
`X-OmniRoute-Emergency-Fallback: from=<provider/model>; to=<provider/model>`, nítorí náà
oníbàárà lè mọ̀ pé a tún darí rẹ̀ láìfi `X-OmniRoute-Provider` wé
ìbéèrè rẹ̀ láti wá ìyàtọ̀. Àkọlé yìí kò sí nínú gbogbo ìdáhùn mìíràn.
