## TL;DR — iye ìṣírò AI ọ̀fẹ́ mélòó ni OmniRoute ń kó jọ ní tòótọ́?

Àwọn iye wọ̀nyí ṣàpèjúwe àwọn àkọọ́lẹ̀ ẹni-kẹta ọ̀tọ̀ọ̀tọ̀ àti àwọn à条件 ìyẹ́sí káàkiri àkójọ náà. OmniRoute kì í fún ọ ní ìnáwó yìí: o gbọ́dọ̀ gba àwọn àkọọ́lẹ̀ tàbí ẹ̀rí ìdánimọ̀ tí a nílò, so àwọn olùpèsè tó yẹ pọ̀, kí o sì tẹ̀lé àwọn ààlà wọn. Agbára tí o lè lò ní tòótọ́ lè dín kù, ó sì lè jẹ́ òdo lórí ìfisílẹ̀ tuntun tí kò ní ọ̀nà tó yẹ kankan. Àwọn olùpèsè tí a samisi `tos: avoid` ni a yọ kúrò nínú yíyan ọ̀nà aládàáṣiṣẹ́ ní àìyípadà.

**A ṣàyẹ̀wò ní 2026-10-08:** [Cerebras](https://www.cerebras.ai/pricing) ń fúnni ní kirẹditi ìpolówó $5 lẹ́ẹ̀kan ṣoṣo, tó nílò ọ̀nà ìsanwó, tí yóò sì parí lẹ́yìn ọjọ́ 30. > **Pẹ̀lú xKiro (2026-09-03):** pool `xkiro-free` tuntun (150M/mo) fi kọ́kọ́rọ́ pool tó ń tún wá kọkànlélọ́gbọ̀n kún un. Àwọn olùkópa **tí a ṣàkọsílẹ̀** tó tóbi jù lọ: `mistral` 1.00B, `nara` 210M, `llm7` 150M, `xkiro` 150M, `groq` 30M (àwọn òpin márùn-ún fún model kọ̀ọ̀kan), `cloudflare-ai` 30M, `api-airforce` 24M. > ⚠️ Òkè ààlà àròsọ (~10B) ga ju bó ṣe yẹ lọ nítorí àwọn olupèsè tó ní òpin oṣùwọ̀n nìkan, tí **kò ní òpin token tí a tẹ̀ jáde** (`tencent`, `nvidia`, `baidu`, `glm-cn`, `sparkdesk`), tí nọ́mbà wọn yóò jẹ́ `RPM/TPM × 24/7 × 30d` — iye tó pọ̀ jù lọ nípa àròsọ tí kò sí àkọọ́lẹ̀ ẹyọ kan tó lè máa dúró lórí rẹ̀. ## Àtúnṣe model ọ̀fẹ́ SiliconFlow 2026-10-18 (#17028)

Model àkọ́kọ́ SiliconFlow mẹ́wàá tí wọ́n ní iye owó rere fún token kọ̀ọ̀kan tí a tẹ̀ jáde ni a fi ránṣẹ́ ní àṣìṣe gẹ́gẹ́ bí ìráyè ọ̀fẹ́ `recurring-uncapped`. A ti **yọ** àwọn ìlà mẹ́wàá yẹn kúrò nínú àkójọ aimi, èyí tó ní **àwọn àkọsílẹ̀ 467** báyìí. SiliconFlow kò tún ní ìlà model ọ̀fẹ́ láìsí àdéhùn tàbí olùpèsè ọ̀fẹ́-títí-láé nínú àpapọ̀ aimi mọ́.

Èyí **kò** túmọ̀ sí pé SiliconFlow kò ní model ọ̀fẹ́. Ìgbéwọlé ọ̀fẹ́-nìkan àti baaji Ọ̀fẹ́ nílò **ẹ̀rí rere fún model kọ̀ọ̀kan láti inú payload model olùpèsè tó ń ṣiṣẹ́ lọ́wọ́lọ́wọ́** báyìí, bíi àmì boolean tó sọ ọ́ ní kedere pé ó jẹ́ ọ̀fẹ́ tàbí kí iye owó token méjèèjì jẹ́ odo. Àmì sísan tó ṣe kedere tàbí iye nọ́ńbà rere èyíkéyìí ní àṣẹ ju àmì ọ̀fẹ́ onírètí lọ. Model tí kò ní ẹ̀rí tó ń ṣiṣẹ́ lọ́wọ́lọ́wọ́ **kò** jẹ́ èyí tí a máa kà sí ọ̀fẹ́; kirẹditi ẹ̀ẹ̀kan ṣoṣo fún àkọọ́lẹ̀ tuntun kò lè fi ìfúnni ọ̀fẹ́ tó ń tún ṣẹlẹ̀ múlẹ̀. Bí API olùpèsè lọ́wọ́lọ́wọ́ kò bá lè pèsè ìsọ̀rí iye owó tó ṣeé gbẹ́kẹ̀ lé ní ìpele model, jẹ́risi rẹ̀ nínú console olùpèsè kí o tó darí ìbéèrè. Yíyàn oníṣọ̀ra yìí ń dènà àwọn owó àìròtẹ́lẹ̀ nípasẹ̀ àwọn ìgbéwọlé ọ̀fẹ́-nìkan àti àwọn àkópọ̀ aládàáṣiṣẹ́.

Tábìlì olùpèsè ìtàn tó wà ní ìsàlẹ̀ kì í ṣe ìlérí wíwà nílẹ̀ lọ́wọ́lọ́wọ́. Àkọsílẹ̀ SiliconFlow tẹ́lẹ̀ rí fún model 10/láìsí-ààlà kò sí níbẹ̀ ní ìmọ̀ọ́mọ̀ nítorí kò tún dúró fún ìfúnni ọ̀fẹ́ tó ń tún ṣẹlẹ̀ tí a ti fi ìdí rẹ̀ múlẹ̀.

## Ọ̀nà ìṣe àti àwọn ìkìlọ̀

- Àwọn nọ́mbà jẹ́ **àwọn àfojúsùn ààlà òkè** láti inú ààlà free-tier tí provider kọ̀ọ̀kan ṣàkọsílẹ̀ títí di **2026-06-17**, tí a kójọ nípasẹ̀ ìwádìí lórí wẹ́ẹ̀bù. Àwọn free tier máa ń yí padà nígbà gbogbo — tún un ṣàyẹ̀wò kí o tó gbára lé iye kan.
- **Ohun tí àkọsílẹ̀ kan ń jẹ́rìí sí gan-an.** Kò sí àkọsílẹ̀ kankan tó ní ìwọ̀n ìgbẹ́kẹ̀lé fún row kọ̀ọ̀kan, API náà kò sì pèsè èyíkéyìí — ka gbogbo iye tó wà lókè sí àfojúsùn tó ní dídára kan náà tí a kò sọ. Àwọn òtítọ́ méjì yàtọ̀, nítorí pé a fi ọwọ́ ṣètò wọn dípò fífi ìfojúrí gbé wọn kalẹ̀: àkọsílẹ̀ 44 ní ìdádúró líle tí a ṣe àkọsílẹ̀ rẹ̀ lọ́tọ̀ (39 lára wọn ni àwọn row xKiro, tí gbogbo wọn ń lo allowance ojoojúmọ́ kan náà), àkọsílẹ̀ 20 sì ní ìṣípayá nípa lílo prompt fún training. A máa ń ṣètò `hardStopGuaranteed` nígbà tí àwọn òfin provider fúnra rẹ̀ sọ pé bí a bá kọjá allowance ọ̀fẹ́, request náà yóò kọ̀ dípò kí ó bẹ̀rẹ̀ sí í gba owó lọ́kọ̀ọ̀kan láìsọ, pẹ̀lú orísun nínú comment lẹ́gbẹ̀ẹ́ àkọsílẹ̀ náà; a kì í ṣètò rẹ̀ sí `true` gẹ́gẹ́ bí default, àkọsílẹ̀ tí ẹnikẹ́ni kò sì tíì ṣàyẹ̀wò yóò dúró láìjẹ́ ṣíṣètò. Nítorí náà, àìsí àmì ìdádúró líle túmọ̀ sí “a kò tíì fi ìdí rẹ̀ múlẹ̀”, kì í ṣe “a mọ̀ pé yóò gba owó lọ́wọ́ rẹ”. **Ìpo STRICT** (routing guard `freeAccessPolicy=strict` tí a yàn láti lo) gbẹ́kẹ̀lé àwọn àkọsílẹ̀ tó ní àmì náà nìkan; gbogbo free tier mìíràn ni a yọ kúrò gẹ́gẹ́ bí `no-hard-stop` (wo `open-sse/services/autoCombo/strictZeroCostFilter.ts`). Nígbà tí guard bá ṣe filter pool kan, log tí operator lè rí máa ń jabo iye àwọn tí a yọ kúrò àti ìpín `no-hard-stop` wọn.
- `estMonthlyFreeTokens` = àwọn token oṣooṣù tó ń tún padà nìkan. **Àwọn credit ìforúkọsílẹ̀ ìgbà kan ṣoṣo kì í tún padà**, wọ́n sì jẹ́ 0 nínú ìṣírò. Àwọn tier tí a ti dáwọ́ dúró tún jẹ́ 0.
- Ààlà token ojoojúmọ́ → `monthly = daily × 30`. Bí RPD nìkan ni a ṣe àkọsílẹ̀ → `RPD × ~800 output tokens × 30`. Bí RPM/TPM nìkan ni ó wà (láìsí ààlà ojoojúmọ́) → **láìsí ààlà** (wo ìsàlẹ̀).
- **Ọ̀fẹ́ títí láé, ṣùgbọ́n láìsí ààlà token tí a tẹ̀ jáde** (`glm-cn`, `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud`): wọ̀nyí jẹ́ ààyè ọ̀fẹ́ gidi tó ń tún padà, tí rate/concurrency ní ààlà lórí. A pín wọn sí `recurring-uncapped`, a sì **kì í ṣàpapọ̀ wọn láé** — ṣíṣe ìṣirò `RPM × 24/7 × 30d` yóò mú ààlà àròsọ jáde (ìfẹ̀sí iye sókè tí a kọ̀). A ṣe àkójọ wọn kí o lè mọ̀ pé wọ́n wà.
- **Ìmúgbòòrò tí deposit ń ṣí:** top-up kékeré ìgbà kan ṣoṣo tí ó máa ń gbé quota ọ̀fẹ́ sókè títí láé (OpenRouter: $10 → 1000 req/day ≈ +24M/mo). A jabo rẹ̀ gẹ́gẹ́ bí iye lọ́tọ̀, a sì yọ ọ́ kúrò nínú headline tó dúró ṣinṣin.
- **Àwọn quota tó dá lórí yíyẹ** (`eligibilityGate: "regional-identity"`): quota gidi tó ń tún padà, tí yóò ṣí lẹ́yìn ìṣàyẹ̀wò ìdánimọ̀ tó so mọ́ ẹkùn kan nìkan (ìjẹ́rìísí orúkọ gidi ní ilẹ̀ China lónìí). A kà á pẹ̀lú òfin yíyọ duplicate kúrò nínú pool kan náà sí iye lọ́tọ̀ (`gatedRecurringTokens`), kò sì ní wọ headline tó dúró ṣinṣin láé. Ìlànà náà (`freeType`) kò yí padà, nítorí náà routing náà kò yí padà.
- **Àwọn ẹ̀ka ẹ̀rí.** Òfin náà ni pé: nọ́mbà kan nínú catalog máa ń tọ́ka sí orísun rẹ̀ nínú comment `// evidence:` lẹ́gbẹ̀ẹ́ àkọsílẹ̀ náà — `public-page` (ojú-ewé provider tí ẹnikẹ́ni lè kà), `api-public` (endpoint provider tí kò nílò authentication, fún àpẹẹrẹ endpoint àwọn ètò gbogbogbòò NaraRouter ní router.bynara.id), tàbí `console-verified <date> por <who>` (iye náà hàn nínú console account nìkan; comment náà ṣàkọsílẹ̀ ẹni tó rí i àti ìgbà tó rí i, àti ojú-ewé gbogbogbòò tó sọ pé ààlà náà wà). Ipò lónìí: àwọn block márùn-ún tí a tún ṣàyẹ̀wò ní 2026-09-02 ní i (`gemini`, `groq`, `mistral`, `ollama-cloud`, `nara`); àwọn àkọsílẹ̀ tó ti wà ṣáájú àtúnṣàyẹ̀wò 2026-09-02 jogún ìwádìí ìṣáájú títí a ó fi tún fọwọ́ kàn wọ́n; nọ́mbà **tuntun tàbí tí a yí padà** láìsí comment ẹ̀rí jẹ́ bug. Lónìí, `mistral` nìkan ni console ti jẹ́rìí sí.

## Ìdí tí iye tiwa fi kéré ju ti àwọn olùṣàkójọpọ̀ míì lọ

Ọ̀pọ̀ jù lọ àwọn iye “token ọ̀fẹ́ fún oṣù kan” ní ààyè yìí jẹ́ àpapọ̀ àwọn iye tí a kọ sí ẹ̀gbẹ́ ọ̀kọ̀ọ̀kan model. Tiwa kò rí bẹ́ẹ̀, a sì mọ̀ọ́mọ̀ ṣe bẹ́ẹ̀:

- **A ka pool àjọpín kọ̀ọ̀kan lẹ́ẹ̀kan ṣoṣo.** Ètò ọ̀fẹ́ Mistral jẹ́ ààyè 1B/oṣù kan fún organization kọ̀ọ̀kan; fífi í sí abẹ́ model márùn-ún kò sọ ọ́ di 5B. Tí a bá ṣàkójọpọ̀ rẹ̀ fún model kọ̀ọ̀kan, catalog tiwa fúnra rẹ̀ yóò jẹ́ **~7.4B** (a tún ṣírò rẹ̀ ní 2026-09-03; CI kò fi òfin mú iye yìí — tún wọn ọ́ nígbàkigbà tí catalog bá yí padà) — àkọlé náà sọ **~1.47B** nítorí pé ìyẹn ni iye tí account kan láti ọ̀dọ̀ provider kọ̀ọ̀kan lè ná ní ti gidi.
- **A máa ń yí àwọn òpin ojoojúmọ́ padà, kì í ṣe àwọn rate.** Òpin tokens/day tí a ṣàkọsílẹ̀ di `× 30`; òpin requests/day tí a ṣàkọsílẹ̀ di `RPD × ~800 tokens × 30`; provider tí ó bá ṣe atẹ̀jáde requests-per-minute nìkan kò ní iye oṣooṣù, a sì máa ń kọ ọ́ sílẹ̀ gẹ́gẹ́ bí _aláìlópin_, a kì í sì í fi kún àpapọ̀. Ìsọdipúpọ̀ rate limit pẹ̀lú 24/7 ni ìfikún iye àṣejù tí a kọ̀ láti ṣe.
- **A fi àwọn quota tí ó nílò àyẹ̀wò ìdánimọ̀ agbègbè hàn lọ́tọ̀** (`+~6M behind regional identity verification`), nítorí pé ọ̀pọ̀ àwọn òǹkàwé kò lè lò wọ́n.
- **Àwọn credit ìforúkọsílẹ̀ wà fún oṣù àkọ́kọ́ nìkan**, a sì máa ń jùmọ̀ wọn gẹ́gẹ́ bí iye kejì; a kì í da wọn pọ̀ mọ́ iye tí ó dúró ṣinṣin.
- **CI ń fipá mú iye náà.** `npm run check:docs-counts` tún máa ń ṣírò àpapọ̀ láti inú catalog, yóò sì mú kí build kùnà nígbà tí file yìí, README tàbí budget card bá yà kúrò nínú wọn.

## Tábìlì àwọn ohun tó yẹ ká kíyè sí nínú ToS

> **Àmì ToS jẹ́ ìmọ̀ràn, kì í ṣe ẹnu-ọ̀nà ìdarí-ọ̀nà.** Àwọn provider tí a sàmì sí `tos` ṣì wà nínú routing àti combo/fallback ní ìbẹ̀rẹ̀; àmì náà wulẹ̀ fara hàn lórí `/dashboard/free-tiers` àti `/api/free-tier/summary`. Query parameter `excludeTosAvoid` kan summary view nìkan, kì í ṣe global routing. Ìpinnu náà wà nínú `open-sse/config/freeTierCatalog.ts` (fún ìfitónilétí, àwọn routing engine kì í kà á).

> Àkótán yára nípa àwọn ìlànà provider kọ̀ọ̀kan fún proxy àdáni tí ẹni kan ṣoṣo ń lò, tí ẹni náà sì gbàlejò fúnra rẹ̀. `caution` = gbólóhùn nípa lílò ara ẹni tàbí proxy tí ó yẹ kí a yẹ̀ wò; `ambiguous` = kò ṣe kedere; `ok` = a fàyè gbà á ní kedere. Èyí jẹ́ ìfitónilétí, kì í ṣe ìmọ̀ràn òfin — ìwọ ni yóò pinnu.
