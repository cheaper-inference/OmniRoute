## Token Percuma Sebulan: ~ 11.3B seperti Dikira Orang Lain · ~ 90J Real

</div>

> **~ 11.3B token percuma / bulan**<br/> <sub> mengira cara katalog lain mengira: setiap baris ditambah, tawaran tamat disertakan </sub>
>
> **~ 90M real hari ini**<br/> <sub> setiap kuota dikongsi dikira sekali: perkara yang sebenarnya boleh anda gunakan </sub>
>
> **Semuanya di sini adalah percuma. Tiada paywall.**<br/> ★ [Suka? Bintangi kami di GitHub](https://github.com/cheaper-inference/OmniRoute)

Katalog lain mengenakan bayaran dari US$ 19 setahun kepada US$ 49 untuk akses seumur hidup kepada data langsung. Di sini semuanya percuma. <sub> Harga disemak pada 18-11-2026.</sub>

<sub>Katalog diaudit terakhir pada 2026-11-23. [Bagaimana kita mengira →](docs/reference/FREE_TIERS.md#how-we-count)</sub>

> **Bawa akaun pembekal anda sendiri.** Ini adalah peringkat percuma pihak ketiga, bukan pemberian token daripada OmniRoute. Daftar, dapatkan bukti kelayakan yang diminta oleh pembekal dan sambungkan kelayakan yang boleh anda gunakan. Setiap pembekal menetapkan had, ketersediaan dan syaratnya sendiri.
>
> Menyusun peringkat percuma dengan tangan bermakna berpuluh-puluh SDKs, berpuluh-puluh had kadar dan tiada idea yang jelas tentang apa yang anda tinggalkan. OmniRoute menyimpan 214 baris katalog dengan akses percuma dan mengira angka sebenar daripada 12 kumpulan dengan kuota yang diterbitkan, setiap kumpulan kongsi dikira sekali. Kuota yang hanya dibuka selepas semakan identiti serantau (hari ini, ModelScope) ditunjukkan secara berasingan, +~ 6M di belakang pengesahan identiti serantau dan tidak pernah ditambahkan pada angka sebenar. Perkara yang tinggal dipaparkan pada papan pemuka (`/dashboard/free-tiers`).

## Pasang, sambungkan pembekal, kemudian laluan melalui satu titik akhir

<img src="./docs/diagrams/works-zero-config.svg" width="100%" alt="Four steps to use OmniRoute. Install with npm install -g omniroute, run omniroute, connect a provider and create an API key in the dashboard, then call http://localhost:20128/v1 with model auto."/>

```bash
# After connecting a provider, create your OmniRoute key in Dashboard → API Keys:
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer YOUR_OMNIROUTE_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"auto","messages":[{"role":"user","content":"Hello!"}]}'
```

## Kombo: perdana

1. **Mulakan dengan `auto`.** Tetapkan model dalam klien serasi OpenAI anda. OmniRoute membina kombo maya daripada pembekal yang berkaitan dan menjaringkan calon secara langsung.
2. **Simpan kombo untuk lebih kawalan.** Pilih nama, senarai sasaran dan strategi, kemudian gunakan nama itu sebagai model. Strategi menetapkan sasaran mana yang didahulukan dan bagaimana yang lain dicuba.

Laluan kombo merentas model secara automatik. Atas keletihan kuota, kegagalan pembekal atau model terkunci, ia mencuba sasaran seterusnya yang layak dan sihat.

### Zero-config: hanya gunakan `auto`

```bash
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <your-omniroute-key>" \
  -H "Content-Type: application/json" \
  -d '{"model": "auto", "messages": [{"role": "user", "content": "Hello"}]}'
```

Varian menala berat. Penghalaan yang terkenal terakhir kekal dengan penyedia terakhir yang berjaya sehingga ia gagal, kemudian menjaringkan semula. `auto/fast` dan `auto/cheap` menyatakan keutamaan tanpa menjamin model terpantas atau termurah.

| Model ID            | Tingkah laku                                                                                                                                                                                                                                                                                                                  |
| :------------------ | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `auto`              | Berat lalai yang seimbang.                                                                                                                                                                                                                                                                                                    |
| `auto/fast`         | Mengutamakan kependaman rendah dan kesihatan pembekal.                                                                                                                                                                                                                                                                        |
| `auto/cheap`        | Mengutamakan harga katalog yang lebih rendah.                                                                                                                                                                                                                                                                                 |
| `auto/coding`       | Pemberat kualiti diutamakan untuk penjanaan kod.                                                                                                                                                                                                                                                                              |
| `auto/smart`        | Berat kualiti diutamakan dengan penerokaan 10% (lalai 5%).                                                                                                                                                                                                                                                                    |
| `auto/lkgp`         | Penghalaan eksplisit terakhir diketahui dengan berat yang sama seperti `auto`.                                                                                                                                                                                                                                                |
| `auto/subscription` | Hanya menggunakan kuota pelan yang disahkan secara langsung. Mengembalikan HTTP 503 apabila tiada yang tersedia dan mengelakkan sandaran yang dibilkan.                                                                                                                                                                       |
| `auto/thrifty`      | Pelan → tanpa kunci → percuma → murah → premium. Boleh mencapai model yang dibilkan dan kembali kepada pelan apabila kuota dan tempoh bertenang dibenarkan.                                                                                                                                                                   |
| `auto/offline`      | Mengutamakan kuota dan ruang kepala had kadar. Permintaan masih dihantar kepada pembekal anda.                                                                                                                                                                                                                                |
| `auto/chaos`        | Satu model bagi setiap pembekal secara selari, sehingga lima secara lalai atau sepuluh apabila dikonfigurasikan. Satu panggilan huluan bagi setiap model. Mengembalikan balasan kedudukan teratas atau balasan panel terakhir yang berjaya jika model teratas gagal. Gunakan `fusion` untuk mensintesis balasan dengan hakim. |

Contoh kategori dan peringkat pilihan termasuk `auto/coding:fast`, `auto/coding:free`, `auto/reasoning:pro` dan `auto/vision`. Jika tiada calon yang disambungkan sepadan, permintaan mengembalikan HTTP 503 dan kolam kekal sempit. [Panduan Auto-Kombo](./docs/routing/AUTO-COMBO.md) · [Laluan pertama langganan](./docs/routing/SUBSCRIPTION_LADDER.md)

### Atau bina sendiri: 22 strategi penghalaan

```bash
omniroute combo create my-pool --strategy fill-first \
  --models "provider-a/model-1,provider-b/model-2"
```

CLI menerima 15 daripada 22 strategi. Papan pemuka dan kombo API menerima kesemua 22.

| Strategi            | Tingkah laku                                                                                                                                                                                                                          |
| :------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `auto`              | Kedudukan calon secara langsung dengan penjaring Auto-Kombo 16 faktor.                                                                                                                                                                |
| `cache-optimized`   | Lebih suka akaun yang mungkin menyimpan awalan gesaan dalam cache.                                                                                                                                                                    |
| `context-optimized` | Cuba tetingkap konteks terbesar yang diketahui dahulu.                                                                                                                                                                                |
| `context-relay`     | Simpan pesanan anda dan lulus ringkasan perbualan apabila menukar akaun.                                                                                                                                                              |
| `cost-optimized`    | Isih mengikut harga token input katalog, yang tidak diketahui terakhir. Kos permintaan akhir mungkin berbeza.                                                                                                                         |
| `expiry-first`      | Kuota perbelanjaan mungkin akan tamat tempoh, baki tertinggi setiap jam sehingga ditetapkan semula terlebih dahulu.                                                                                                                   |
| `fill-first`        | Kekal pada sasaran pertama yang tersedia sehingga ia habis atau gagal, kemudian teruskan.                                                                                                                                             |
| `fusion`            | Soal panel secara selari dan minta hakim mensintesis satu jawapan.                                                                                                                                                                    |
| `headroom`          | Pilih kapasiti paling banyak percuma merentas tingkap 5 jam dan mingguan.                                                                                                                                                             |

| `least-used`        | Pilih sasaran dengan permintaan yang direkodkan paling sedikit dalam kombo ini.                                                                                                                                                       |
| `lkgp`              | Cuba penyedia terakhir yang berjaya dahulu, jika tidak, simpan pesanan anda.                                                                                                                                                          |
| `p2c`               | Contohi dua sasaran dan pilih mengikut kadar kejayaan dan kependaman.                                                                                                                                                                 |
| `pipeline`          | Suapkan output setiap langkah ke sasaran seterusnya mengikut urutan dan pulangkan hanya jawapan akhir.                                                                                                                                |
| `priority`          | Cuba sasaran dalam pesanan anda. Kelekatan sesi mengekalkannya.                                                                                                                                                                       |

### Ketahanan terbina dalam: 3 lapisan bebas

Kegagalan dikendalikan pada tiga skop, jadi satu model yang buruk tidak memadam akaunnya dan satu akaun yang buruk tidak mengalih keluar penyedianya.

<img src="./docs/diagrams/resilience-layers.svg" width="100%" alt="OmniRoute resilience: 3 independent self-healing layers, the right layer for the right failure. Layer 1, provider circuit breaker (whole provider): trips only on 408/500/502/503/504, opens after 8 failures for OAuth providers or 12 for API-key providers, resets after 60s or 30s into a HALF-OPEN probe, lazy recovery; while OPEN the combo reroutes to the next provider. Layer 2, connection cooldown (one key or account): base 5s OAuth or 3s API-key, exponential backoff with an anti-thundering-herd guard, success clears the error state; one cooling key is skipped while sibling keys keep serving. Layer 3, model lockout (one model): per-model 429, 404 or access denials lock just that model, never the whole connection. Terminal states (banned, expired, credits exhausted) wait for the operator; they are not cooldowns."/>

#### Jika keseluruhan pembekal tidak berfungsi

The** pemutus litar pembekal** dibuka selepas kegagalan 8 (OAuth) atau 12 ( kunci API ) dengan status 408, 500, 502, 503 atau 504. Kombo langkau pembekal itu semasa ia dibuka. Selepas 60 s atau 30 s, satu permintaan siasatan memutuskan sama ada ia ditutup.

#### Jika satu kunci atau akaun dihadkan kadar

The** sambungan cooldown** bangku sahaja sambungan itu, dengan mundur eksponen daripada 5 s (OAuth) atau 3 s ( kunci API ). Kunci lain untuk pembekal yang sama terus berkhidmat.

#### Jika satu model ditolak

The** model lockout** hanya menyekat model itu pada sambungan itu selepas setiap model 429, 404 atau penafian akses. Model lain pada sambungan yang sama terus berkhidmat.

Sambungan yang diharamkan, tamat tempoh dan di luar kredit adalah keadaan terminal, bukan tempoh bertenang: mereka menunggu anda untuk membetulkannya.

## CLI penuh, MCP dan A2A

> OmniRoute menghantar pelanggan baris arahan dengan** 91 arahan dan kumpulan arahan peringkat atasan** (754 arahan mengira subperintah), an** pelayan MCP dengan 110 alat dan 33 skop** , dan an** ejen A2A dengan 6 kemahiran** . Skrip, terminal dan ejen AI semuanya boleh mengendalikan gerbang yang sama.

### CLI sebenar, bukan hanya `start`

```bash
omniroute                 # start the gateway and dashboard (port 20128)
omniroute setup           # guided first-run wizard
omniroute repl            # interactive chat in the terminal (/model /combo /skill /memory)
omniroute chat "hello"    # one-shot prompt; also reads --file or --stdin
omniroute doctor          # check config, database, ports, Node runtime and native deps
```

Bendera `--output table|json|jsonl|csv` global menjadikan perintah yang sama boleh digunakan daripada skrip dan CI.

### Mod jauh: CLI pada komputer riba anda, OmniRoute pada pelayan

Log masuk sekali ke pelayan jauh. CLI menyimpannya sebagai a** konteks** , dan arahan kemudian dijalankan terhadap pelayan itu sehingga anda bertukar kembali.

```bash
omniroute connect omniroute.example.com          # asks for the password, saves a scoped token as a context
omniroute models                                 # runs against the remote server
omniroute configure codex                        # picks a remote model, writes a local Codex profile
omniroute tokens create --name ci --scope read   # mint a narrower token for another machine
omniroute contexts use default                   # switch back to the local server
```

| Skop token | <img width="2000" height="0" alt=""> Apa yang dibenarkan                  |
| ---------- | ------------------------------------------------------------------------- |
| `read`     | Senaraikan dan periksa: model, status, log, penggunaan                    |
| `write`    | `read` plus konfigurasi dan gunakan: persediaan klien, kunci, konfigurasi |
| `admin`    | `write` plus urus: token, pembekal, perkhidmatan, polisi                  |

Hos kosong mendapat `http://` dan port 20128; melepasi `https://` URL penuh apabila pelayan duduk di belakang TLS. Laluan yang boleh menghasilkan proses kekal gelung balik sahaja, walau apa pun tandanya.

### Sambungkan ejen

Ejen, atau kod anda sendiri, boleh memacu penghalaan, pembekal, kombo, cache, mampatan dan memori melalui mana-mana antara muka ini. laluan HTTP disediakan oleh gerbang, secara lalai di `http://localhost:20128`.

| Antara muka               | Titik akhir atau arahan    | Gunakannya untuk                                                                 |
| ------------------------- | -------------------------- | -------------------------------------------------------------------------------- |
| MCP over stdio            | `omniroute --mcp`          | Claude Desktop, Cursor dan pelanggan MCP tempatan yang lain                      |
| MCP atas HTTP Boleh strim | `/api/mcp/stream`          | Pelanggan MCP jauh: 110 alat, 33 skop, setiap panggilan ditulis pada log audit   |
| MCP atas SSE              | `/api/mcp/sse`             | Pelanggan yang masih menggunakan pengangkutan SSE                                |
| penemuan A2A              | `/.well-known/agent.json`  | Kad Ejen: memberitahu ejen lain apa yang OmniRoute boleh lakukan                 |
| pelaksanaan A2A           | `POST /a2a`                | Tugasan JSON-RPC 2.0, segerak atau distrim melalui SSE, merentas 6 kemahiran     |
| REST API                  | `/v1/*`                    | Sembang serasi OpenAI, Respons, benam, imej, audio dan OCR                       |
| Webhooks                  | `/api/webhooks`            | Acara kepada Slack, Discord, Telegram atau mana-mana URL dengan tandatangan HMAC |
| CLI jauh                  | `omniroute connect <host>` | Pandu tika jauh dengan token akses berskop                                       |

Enam kemahiran A2A ialah `smart-routing`, `quota-management`, `provider-discovery`, `cost-analysis`, `health-report` dan `list-capabilities`.

**Sebelum anda menyambung:**

- **MCP over HTTP mula dilumpuhkan.** Hidupkannya dengan `omniroute mcp enable --transport streamable-http` atau dari halaman Endpoints papan pemuka. Satu pengangkutan HTTP aktif pada satu masa: `streamable-http` berkhidmat `/api/mcp/stream`, `sse` berkhidmat `/api/mcp/sse`.
- **A2A mula dilumpuhkan.** Dayakannya pada halaman Endpoints papan pemuka. `POST /a2a` kemudian mengikut peraturan kunci API yang sama seperti `/v1`.
- **MCP jauh memerlukan kunci yang sesuai.** `/api/mcp/*` hanya menjawab loopback secara lalai. Daripada hos lain, hantar kunci dengan `manage` atau `admin` (semua alatan), atau dengan `mcp:connect` serta skop alatan yang anda perlukan. Untuk kunci tanpa `manage`/`admin`, skop alat sentiasa dikuatkuasakan.

```bash
# Give Claude Code the OmniRoute toolset over MCP:
omniroute mcp enable --transport streamable-http
claude mcp add --transport http omniroute http://localhost:20128/api/mcp/stream \
  --header "Authorization: Bearer <api-key-with-manage-scope>"
```

## Simpan 15–95% Token — Secara Automatik

### Cara ia berfungsi saluran paip —, seni bina & matematik penjimatan

<img src="./docs/diagrams/compression-pipeline.svg" width="100%" alt="OmniRoute compression pipeline: an illustrative 10,000-token client request passes through 12 composable engines — Session-Dedup, CCR, Lite, RTK, Responses Tool Output, Headroom, Relevance, Caveman, Aggressive, LLMLingua-2, Ultra and OmniGlyph — and can reach the provider at about 1,080 tokens in the documented stacked example. Structured content is protected by preservation guards and per-step fidelity gates; explicit lossy or experimental modes may transform eligible content."/>

Kombo tindanan lalai menjalankan `RTK → Caveman`. Apabila kedua-duanya bertindak pada muatan tool/context yang sama, kompaun penjimatan:

```txt
combined = 1 − (1 − RTK) × (1 − Caveman_input)
average  = 1 − (1 − 0.80) × (1 − 0.46) = 89.2%
range    = 78.4 – 94.6%
```

Blok kod, URLs, JSON dan data berstruktur ialah** sentiasa dilindungi** oleh enjin pemuliharaan.

> **Mengapa menggunakan banyak token apabila beberapa token berjaya?** Setiap permintaan melalui saluran paip mampatan OmniRoute** secara telus** — tiada perubahan pelanggan. Ia kini a** timbunan 12 enjin boleh gubah** yang berjalan mengikut tertib dan mencampur & memadankan setiap kombo laluan — membina idea daripada [RTK](https://github.com/rtk-ai/rtk), [Caveman](https://github.com/JuliusBrussee/caveman) (⭐ 90K +), [LLMLingua-2](https://github.com/microsoft/LLMLingua), dan [Troglodita](https://github.com/leninejunior/troglodita) (PT-BR).

## Lebih banyak kaedah pemasangan — Docker, sumber, pnpm, Arch

**🐳 Docker**

```bash
docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 \
  -p 127.0.0.1:20128:20128 -v omniroute-data:/app/data cheaperinference/omniroute:latest
```

`:latest` ikut tertinggi** diterbitkan** SemVer yang stabil. Ia tidak menjejaki git `main`. Sematkan `:X.Y.Z` untuk GitOps. Lihat [Saluran Keluaran Docker](docs/guides/DOCKER_GUIDE.md#release-channels). Pin imej**`OMNIROUTE_MEMORY_MB=1024`** . Itu sudah cukup untuk papan pemuka dan sembang ringan.** Ejen pengekodan** (`POST /v1/responses` daripada Kod Claude, Codex, Grok, …) memerlukan timbunan V8 yang lebih besar atau proses `FATAL ERROR` s pada ~ 12 GiB di bawah dua konteks panjang yang bertindih. Saiz bekas di atas timbunan (penampan asli terletak di luar V8):

| <img width="2000" height="0" alt=""> Beban Kerja | Timbunan (`-e OMNIROUTE_MEMORY_MB`) | Bekas (`--memory`) |
| ------------------------------------------------ | ----------------------------------- | ------------------ |
| Papan pemuka / sembang ringan                    | `1024` (imej lalai)                 | ≥ 2 g              |
| Satu ejen pengekodan                             | `8192`                              | ≥ 10 g             |
| Dua `/v1/responses` panjang serentak             | `10240`–`12288`                     | ≥ 12–16 g          |

```bash
docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 \
  -e OMNIROUTE_MEMORY_MB=8192 --memory=10g \
  -p 127.0.0.1:20128:20128 -v omniroute-data:/app/data cheaperinference/omniroute:latest
```

Jadual penuh: [Docker Guide — runtime RAM](docs/guides/DOCKER_GUIDE.md#runtime-ram-for-coding-agents).

> **Saluran Docker prakeluaran:** `diegosouzapw/omniroute:next` dan `diegosouzapw/omniroute:next-web` ikut cawangan `release/v*` lalai semasa. Teg boleh ubah ini hanya bertujuan untuk menguji pembetulan yang belum dikeluarkan dan adalah** tidak disokong untuk pengeluaran** . Lihat [Saluran Keluaran Docker](docs/guides/DOCKER_GUIDE.md#release-channels).

**🥟 Bun**

`bun install` standard dan pemasangan global (`bun install -g omniroute`) disokong melalui pengesanan masa jalan Bun :

- **`bun:sqlite` terbina dalam** : OmniRoute menggunakan pemacu Bun terbina dalam `bun:sqlite` apabila berjalan di bawah Bun, kembali ke `better-sqlite3` pada Node.js atau `sql.js`.
- **Pemilihan pengikat Webpack automatik dalam dev** : Pembangunan (`bun run dev`) secara automatik mengesan Bun dan melumpuhkan Turbopack memihak kepada Webpack untuk mengelakkan ketidakserasian pengikatan V8 asli. Binaan pengeluaran (`bun run build`) mengikut `OMNIROUTE_USE_TURBOPACK` sama seperti pada Node: Turbopack secara lalai, `OMNIROUTE_USE_TURBOPACK=0` untuk membina dengan Webpack (`Dockerfile.bun` mendedahkannya sebagai `--build-arg`).
- **Bun Dockerfile yang berdedikasi** : `Dockerfile.bun` berbilang peringkat untuk penempatan pengeluaran Bun asli (`docker build -f Dockerfile.bun -t omniroute:bun .`).

```bash
# Install and run with Bun
bun install
bun run dev
```

**⚡ Pemasangan yang lebih pantas / lebih ramping (langkau binaan asli)**

Enjin SQLite asli (`better-sqlite3`) ialah sebuah** pilihan** kebergantungan, jadi pemasangan global tidak pernah menghalang penyusunan daripada sumber: ia menggunakan binari terbina apabila ia sepadan dengan platform/Node anda, dan sebaliknya akan kembali secara telus kepada enjin JS tulen (`node:sqlite` pada Node 22 +, jika tidak, `sql.js` WASM) — tiada alat binaan diperlukan.

Untuk melangkau pasca pemasangan** memanaskan badan asli** sepenuhnya ( mesin CI, tanpa kepala atau perlahan). Nota: ini hanya melangkau langkah memanaskan badan SQLite asli (`scripts/postinstall.mjs`); cangkuk binary-copy/repair (`scripts/build/postinstall.mjs`) masih berjalan seperti biasa:

```bash
OMNIROUTE_SKIP_POSTINSTALL=1 npm install -g omniroute   # CI=1 also skips it
```

Untuk pemasangan terpantas lebih suka** pnpm** (simpan beralamat kandungan + pautan keras — lihat di atas). Untuk masa jalan tanpa papan pemuka dan tanpa kepala gunakan profil Docker `base` (di atas) atau [panduan Termux](docs/guides/TERMUX_GUIDE.md). CLI dan papan pemuka web disediakan oleh proses yang sama pada satu port, jadi tiada pakej CLI sahaja yang berasingan hari ini.

## Timbunan Teknologi

Dengan apa OmniRoute dibina, seperti yang diisytiharkan dalam [`package.json`](package.json) pada `release/v3.8.55`.

<table>
  <tr><th align="left">Lapisan</th><th align="left">Teknologi</th></tr>
  <tr><td nowrap><b>Masa jalan</b></td><td>Node.js <code>&gt;=22.22.2 &lt;23 || &gt;=24.0.0 &lt;27</code> (22.x daripada 22.22.2 dan 24.x hingga 26.x). Bun 1.4.2 disematkan hanya untuk menjalankan beberapa skrip binaan dan laluan keserasian usaha terbaik; ia bukan masa jalan yang disokong</td></tr>
  <tr><td nowrap><b>Bahasa</b></td><td>TypeScript 6 untuk apl dan enjin penstriman (<code>src/</code> dan <code>open-sse/</code>); <code>omniroute</code> CLI dalam <code>bin/</code> ialah ES-modul JavaScript</td></tr>
  <tr><td nowrap><b>Rangka kerja</b></td><td>Next.js 16 + React 19 + Tailwind CSS 4, dengan Keak CI UI Kit yang dijual (<code>packages/ui-kit</code>)</td></tr>
  <tr><td nowrap><b>Pangkalan data</b></td><td>SQLite dengan WAL membuat jurnal melalui better-sqlite3, dengan rantai sandaran pemandu — 178 modul dalam <code>src/lib/db/</code>, 252 migrasi</td></tr>
  <tr><td nowrap><b>Ingatan</b></td><td>SQLite FTS5 carian teks penuh + int8-quantized vektor benam dengan pereputan ditaip; Qdrant pilihan</td></tr>
  <tr><td nowrap><b>Skema</b></td><td>kontrak Zod 4 — API dan pengesahan input/output alat MCP</td></tr>
  <tr><td nowrap><b>Protokol</b></td><td>MCP (stdio / SSE / HTTP boleh strim , 110 alatan) + A2A v0.3 (JSON-RPC 2.0 + SSE) dengan keserasian pelanggan A2A v1.0</td></tr>
  <tr><td nowrap><b>Penstriman</b></td><td>Acara Dihantar Pelayan (SSE) + WebSocket bridge (<code>/v1/ws</code>)</td></tr>
  <tr><td nowrap><b>Mampatan</b></td><td>15 enjin terbina dalam, termasuk RTK, Caveman, LLMLingua-2 (ONNX, TinyBERT secara lalai), ruang kepala dan OmniGlyph</td></tr>
  <tr><td nowrap><b>Auth &amp; keselamatan</b></td><td>OAuth 2.0 (PKCE) + JWT + API + MCP skop pengesahan · pilihan Masuk ID, OIDC dan TOTP log masuk · AES-256-GCM pada rehat · DOMPurify</td></tr>
  <tr><td nowrap><b>Siluman</b></td><td>wreq-js — JA3 / JA4 TLS cap jari penyamaran, proksi 3 peringkat</td></tr>
  <tr><td nowrap><b>Ketahanan</b></td><td>Pemutus litar pembekal, tempoh sambungan, kunci keluar model, pengunduran eksponen, kemasukan adaptif</td></tr>
  <tr><td nowrap><b>Pembalakan</b></td><td>log JSON berstruktur pino — dengan konteks permintaan</td></tr>
  <tr><td nowrap><b>Menguji</b></td><td>pelari ujian Node.js + Vitest + Playwright — 9,500 fail ujian + di bawah <code>tests/</code> (unit, penyepaduan, E2E, keselamatan, ekosistem)</td></tr>
  <tr><td nowrap><b>Platform</b></td><td>npm (Windows / macOS / Linux) · Docker (linux/amd64, linux/arm64) · Kubernetes (Kustomize + Helm) · Desktop (Electron) · Android (Termux) · PWA</td></tr>

### Cara Menyumbang

1. Garpu repositori
2. Cawangan daripada** aktif** `release/vX.Y.Z` tip (bukan `main`) — lihat [Model Cawangan & Pelepasan](docs/ops/BRANCHING_MODEL.md)
3. Buat cawangan ciri anda (`git checkout -b feat/amazing-feature`)
4. Lakukan perubahan anda (`git commit -m 'feat: add amazing feature'`)
5. Tolak ke dahan (`git push origin feat/amazing-feature`)
6. Buka Permintaan Tarik dengan** asas = bahawa cawangan `release/vX.Y.Z`**

Lihat [CONTRIBUTING.md](CONTRIBUTING.md) untuk garis panduan terperinci.

### Mengeluarkan Versi Baharu

```bash
# Create a release — npm publish happens automatically
VERSION=x.y.z
gh release create "v${VERSION}" --title "v${VERSION}" --generate-notes
```
