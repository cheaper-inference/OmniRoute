`@omniroute/opencode-plugin-v2` memasukkan keseluruhan katalog OmniRoute anda — model, kombo dan
kombo automatik — ke dalam pemilih model OpenCode v2, lengkap dengan nama paparan, harga dan bajet
peringkat percuma.

Ia merupakan pakej yang berasingan daripada `@omniroute/opencode-plugin` kerana OpenCode v1 dan v2 memuatkan
pemalam melalui kontrak yang berbeza. Pilih pakej yang sepadan dengan versi utama OpenCode anda; tiada apa-apa yang
dikongsi antara kedua-duanya, jadi menaik taraf satu pakej tidak akan memaksa pakej yang satu lagi dinaik taraf.

## Keperluan

- OpenCode v2.
- Gerbang OmniRoute yang boleh dicapai (`http://localhost:20128` secara lalai).
- Node.js 22 atau 24.

## Pemasangan

Tambahkan pemalam pada `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

Model kemudiannya muncul sebagai `omniroute/<provider>/<model>`; `providerId` menentukan awalan tersebut dan
id integrasi yang digunakan oleh OpenCode untuk menyimpan kelayakan.

## Kelayakan

Pemalam mencari kunci gerbang di tiga tempat mengikut turutan berikut:

1. **Kelayakan yang anda sambungkan dalam OpenCode.** Pemalam mendaftarkan satu integrasi supaya
   aliran pengesahan OpenCode sendiri boleh menyimpan kunci tersebut. Tiada apa-apa disimpan dalam `opencode.json` — utamakan kaedah ini.
2. `apiKey` dalam pilihan pemalam, untuk penggantian bagi setiap projek. Kaedah ini meletakkan kunci dalam fail yang
   mungkin anda komitkan.
3. `OMNIROUTE_API_KEY` dalam persekitaran.

Jika ketiga-tiganya tiada, katalog akan kosong dan pemalam akan memaklumkannya sekali semasa permulaan, bukannya
membiarkan anda dengan pemilih kosong tanpa sebarang pemberitahuan.

### Token pengurusan ialah kunci yang berbeza

Kombo, kesihatan penyedia dan pengayaan (nama paparan, harga, bajet peringkat percuma) diperoleh daripada
titik akhir `/api/*` gerbang, yang dalam kebanyakan penggunaan dilindungi oleh token **pengurusan**
dan bukannya kunci inferens:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<token baca pengurusan>"
}
```

Jika tidak ditetapkan, `managementReadToken` akan menggunakan `apiKey` sebagai sandaran. Apabila gerbang menolak penggunaan sandaran tersebut,
katalog masih diterbitkan, tetapi dengan id model mentah dan bukannya nama paparan, tanpa penyahduplikasian
alias kanonik, tanpa harga dan tanpa kombo. Pemalam memberi amaran sekali bagi setiap titik akhir apabila hal itu berlaku,
dengan menyatakan titik akhir dan perkara yang hilang — supaya sebab pemilih berfungsi secara terhad sentiasa jelas.

| kunci                            | Lalai                                           | Nota                                                                                                                                                                                                                                                                                                                                                                                |
| -------------------------------- | ----------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| `baseURL`                        | diperlukan                                      | Akar pintu masuk, `http(s)` sahaja; akhiran `/v1` ditambah jika perlu                                                                                                                                                                                                                                                                                                               |
| `apiKey`                         | sambung kelayakan, kemudian `OMNIROUTE_API_KEY` | Kunci sembang untuk `/v1/*`                                                                                                                                                                                                                                                                                                                                                         |
| `managementReadToken`            | jatuh balik pada `apiKey`                       | Kunci untuk `/api/*` — biasanya** bukan** yang sama                                                                                                                                                                                                                                                                                                                                 |
| `displayName`                    | `"OmniRoute"`                                   | Nama pembekal dalam pemilih                                                                                                                                                                                                                                                                                                                                                         |
| `timeoutMs`                      | `10000`                                         | Tamat masa pengambilan setiap titik (kombo automatik menggunakan 5s)                                                                                                                                                                                                                                                                                                                |
| `modelCacheTtlMs`                | `300000`                                        | Cache katalog TTL; syot kilat cakera memanaskan sejuk bermula                                                                                                                                                                                                                                                                                                                       |
| `timeouts`                       | jatuh balik pada `timeoutMs`                    | Belanjawan setiap titik akhir dalam ms: `models`, `combos`, `autoCombos`, `enrichment`                                                                                                                                                                                                                                                                                              |

| `combosSource`                   | `"api"`                                         | `"models"` melangkau `/api/combos` dan menerbitkan baris kombo `/v1/models` ; penapis peringkat ahli mengekalkan `"api"`                                                                                                                                                                                                                                                            |
| `showcasePerOwner`               | `10`                                            | Entri paparan lalai disimpan bagi setiap pembekal                                                                                                                                                                                                                                                                                                                                   |
| `freshPerOwner`                  | `10`                                            | Paparan lalai entri baharu disimpan bagi setiap pembekal                                                                                                                                                                                                                                                                                                                            |
| `freshWindowDays`                | `90`                                            | Tetingkap kesegaran dalam beberapa hari untuk cawangan segar                                                                                                                                                                                                                                                                                                                        |
| `usageMemory`                    | `true`                                          | Pulihkan entri yang digugurkan secara statik yang dinamakan oleh analitis penggunaan 30 hari (memerlukan token pengurusan)                                                                                                                                                                                                                                                          |
| `visibleModels` / `hiddenModels` | `[]`                                            | Senarai dibenarkan tepat-atau-akhiran; menafikan kemenangan; `*` menerbitkan katalog penuh (penapis lain masih digunakan)                                                                                                                                                                                                                                                           |
| `geminiSanitization`             | `true`                                          | Keluarkan kata kunci JSON-Skema yang ditolak Gemini daripada skema alat ( alatan `$ref` dimajukan tanpa disentuh)                                                                                                                                                                                                                                                                   |

## Bagaimana katalog kekal segar

Katalog diambil secara malas dan dicache untuk `modelCacheTtlMs`, dan petikan cakera menyimpan katalog terakhir yang diketahui tersedia apabila pintu masuk tidak dapat dicapai — dan gangguan tidak memerlukan anda melainkan kesegaran. Model dan kombo diterbitkan sebaik sahaja ia tiba; gabungan automatik, senarai penyedia dan tindanan pengayaan dilipat masuk apabila ia mendarat, jadi satu titik akhir yang perlahan tidak dapat menahan keseluruhan pemilih sebagai tebusan.

Nama mengikut `Provider - Model[ (Editor)][ · budget][ (route)]`: pembekal ditunjukkan apabila id membawa satu (id tanpa garis miring dipaparkan tanpa awalan), `🆓` terkemuka menandakan penyertaan percuma dan belanjawan peringkat bebas mereka kekal sebagai akhiran `· 1M tokens/month`, editor nama `Editor: Model` eksplisit berpindah ke kurungan belakang (tiada editor diteka daripada ikon render lain), dan kombo `combo - <slug>` tanpa nama lain. Dua entri yang berkongsi nama mendapat akhiran laluan — `(no-think)` — supaya ia kekal dibezakan. `providerTag` ( `true` lalai ) menogol kurungan editor mengekori.

Tiada arahan muat semula manual: perintah OpenCode v2 ialah templat segera, bukan panggilan balik, jadi pemalam tidak boleh mendedahkannya. Muat semula ikut TTL; hos diminta untuk memuat semula hanya apabila katalog atau tindanan benar-benar berubah, tidak sekali-kali setiap muat semula.

## Panggilan alat pada Gemini

Gemini menolak keseluruhan permintaan yang pengisytiharan alatnya mengandungi `$schema` atau
`additionalProperties`, dengan respons `400 INVALID_ARGUMENT`. Pemalam membuang kata kunci tersebut daripada
skema alat yang ditujukan kepada model Gemini daripada penyedia ini dan membiarkan setiap permintaan lain tanpa perubahan.
Alat yang mengandungi `$ref` dimajukan tanpa perubahan dan bukannya dibuang, kerana mengalih keluar
rujukan tersebut akan meluaskan skema kepada "terima apa sahaja".
Tetapkan `"geminiSanitization": false` untuk mematikannya.

## Menyelesaikan masalah

| simptom                                   | sebab                                                                                                                          |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Picker tidak menunjukkan model OmniRoute  | Tiada kunci diselesaikan (semak amaran permulaan) atau get laluan tidak dapat dicapai                                          |
| Id model mentah, tiada kombo, tiada harga | Titik akhir pengurusan menolak token — set `managementReadToken`                                                               |
| Katalog `freeOnly` pendek atau kosong     | Tiada token pengurusan atau token yang ditolak — membaca baris ringkasan muat semula ( kiraan `unmatched-free` ) dalam log hos |
| Sesi disematkan pada `opencode-<id>/...`  | Pemalam v1 menerbitkan `opencode-<id>`; v2 menerbitkan `<id>` bare, jadi pilih semula model di bawah `<id>/...`                |

Pembolehubah persekitaran mesti mencapai proses pelayan kod terbuka: apabila hos berjalan sebagai perkhidmatan, shell yang menjalankan `opencode models` dan persekitaran pelayan adalah berbeza, jadi eksport kunci tempat pelayan membacanya.
