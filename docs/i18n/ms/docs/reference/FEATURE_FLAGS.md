> Togol masa jalan yang mengubah tingkah laku OmniRoute **tanpa penggunaan semula**.
> Setiap bendera yang disenaraikan di sini ditakrifkan dalam
> [`src/shared/constants/featureFlagDefinitions.ts`](../../src/shared/constants/featureFlagDefinitions.ts)
> — satu-satunya sumber rujukan. Papan pemuka dan REST API kedua-duanya membaca daripada
> fail tersebut, maka jadual di bawah dijana agar sepadan dengannya secara 1:1.

---

## Apakah Itu Bendera Ciri

Bendera ciri ialah togol bernama (boolean atau enum) yang nilainya boleh diubah pada
masa jalan dan dikekalkan dalam pangkalan data, tanpa memerlukan penggunaan semula proses. Setiap
bendera diterangkan oleh `FeatureFlagDefinition` dengan `key`, `label`,
`description`, `category`, `defaultValue`, `type` dan petunjuk `requiresRestart`.

### Turutan Resolusi

**Nilai berkuat kuasa** bagi sesuatu bendera ditentukan oleh
[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) mengikut
keutamaan ini (yang tertinggi diutamakan):

1. **Penggantian DB** — nilai yang disimpan dalam jadual `key_value` di bawah ruang nama
   `feature_flags` (ditetapkan melalui papan pemuka atau REST API).
2. **Pemboleh ubah persekitaran** — `process.env[<KEY>]`, jika ditetapkan dan tidak kosong.
3. **Lalai definisi** — `defaultValue` daripada `featureFlagDefinitions.ts`.

Bendera boolean dianggap **didayakan** apabila nilai berkuat kuasanya ialah `"true"`,
`"1"` atau `"yes"` (lihat `isFeatureFlagEnabled()`).

> [!NOTE]
> Kebanyakan bendera turut mempunyai pemboleh ubah persekitaran yang sepadan dengan **nama yang sama**
> dan didokumentasikan dalam [`ENVIRONMENT.md`](./ENVIRONMENT.md). Penggantian DB bendera
> diutamakan berbanding pemboleh ubah persekitaran tersebut. Bendera dengan
> `requiresRestart: true` dikekalkan serta-merta tetapi hanya dibaca semula ketika proses
> dimulakan — menogolnya memaparkan sepanduk **"Mulakan Semula Pelayan"** dalam papan pemuka.

## Togol Bendera

### Papan pemuka

Navigasi ke** Papan pemuka → Tetapan → Ciri Bendera** (`/dashboard/settings/feature-flags`). Grid (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`) menyokong:

- **Cari** dengan kunci atau penerangan, dan** penapis** mengikut kategori (tambah sintetik** Memerlukan Mulakan Semula** pandangan).
- A** togol** untuk bendera boolean dan a** jatuh turun** untuk bendera enum (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`).
- A** lencana sumber** setiap bendera — `DB`, `ENV`, atau `DEF` — menunjukkan dari mana datangnya nilai berkesan.
- A** Tetapkan semula** butang (ditunjukkan hanya untuk bendera `DB` -sourced ) untuk menggugurkan penggantian, dan a** Tetapkan Semula Semua Penggantian** butang di bahagian bawah.
- A** Mulakan semula Pelayan** banner apabila bendera `requiresRestart` ditukar.

### REST API

Semua operasi melalui satu laluan: [`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts). Setiap kaedah memerlukan sesi papan pemuka yang disahkan (`401` sebaliknya).

#### `GET /api/settings/feature-flags`

Mengembalikan setiap bendera dengan nilai berkesan, sumber dan ringkasannya.

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Require API Key",
      "description": "Require an API key for all incoming requests",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... all 113 flags
  ],
  "summary": {
    "total": 56,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

Tetapkan atau alih keluar satu penggantian. Badan: `{ key: string; value?: string }`. Mengeluarkan `value` mengalih keluar override (memulihkan env / lalai).

```bash
# Set a DB override
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# Remove the override (no "value")
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

Respons itu menggemakan `effectiveValue`/`source` baharu , `previousValue`/ `previousSource` dan `requiresRestart`. Kekunci tidak diketahui dan nilai enum di luar julat ditolak dengan `400`.

#### `DELETE /api/settings/feature-flags`

Membersihkan** semua** DB menimpa sekaligus, memulihkan setiap bendera kepada nilai env / lalainya. Mengembalikan `{ cleared: <count>, message: "..." }`.

> [!NOTE]
> Bendera dengan `requiresRestart: true` hanya berkuat kuasa selepas proses muat semula. Aliran mula semula papan pemuka memanggil `POST /api/restart` dan kemudian mengundi `GET /api/health/ping` sehingga pelayan disandarkan.

## Sandaran Bajet Kecemasan

`OMNIROUTE_EMERGENCY_FALLBACK` (kategori `runtime`, lalai `true`) mengawal laluan
sandaran percuma kecemasan dalam
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts).
Apabila didayakan, permintaan yang telah menghabiskan bajetnya dihalakan kepada
penyedia/model sandaran percuma dan bukannya terus gagal. Tetapkannya kepada
`false` (atau `0`) — melalui togol papan pemuka, penggantian DB, atau pemboleh ubah
persekitaran `OMNIROUTE_EMERGENCY_FALLBACK` — untuk menyahdayakan tingkah laku ini
dan membiarkan permintaan yang telah kehabisan bajet gagal. (Dipaparkan sebagai
togol papan pemuka dalam PR #3741 / #3752.)

Respons yang disediakan oleh sandaran ini mengandungi
`X-OmniRoute-Emergency-Fallback: from=<provider/model>; to=<provider/model>`, supaya
klien dapat mengetahui bahawa ia telah dihalakan semula tanpa membandingkan
`X-OmniRoute-Provider` dengan permintaannya. Pengepala ini tidak terdapat dalam
semua respons lain.
