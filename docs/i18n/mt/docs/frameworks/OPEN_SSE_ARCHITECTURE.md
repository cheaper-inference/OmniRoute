## Għaliex Pakkett Separat tal-Workspace?

`open-sse/` huwa **workspace awtonomu** fil-monorepo ta’ OmniRoute għal diversi raġunijiet:

1. **Użu mill-ġdid** — `open-sse` jiġi ppubblikat bħala `@omniroute/open-sse` fuq npm, għalhekk proġetti oħra jistgħu jużawh b’mod indipendenti
2. **Konfini ċari** — il-magna tal-istreaming hija diżakkoppjata mis-saff tal-UI/DB speċifiku għal OmniRoute
3. **Prestazzjoni** — il-magna m’għandha l-ebda dipendenza fuq Next.js, u b’hekk tippermetti bidu kiesaħ aktar rapidu f’kuntesti CLI/serverless
4. **Verżjonar** — `open-sse` jista’ joħroġ rilaxxi bir-ritmu tiegħu stess

```json
// package.json
"workspaces": ["open-sse"]
```

## Il-Pipeline tat-Talbiet

Kull talba LLM tgħaddi minn **pipeline ta’ 5 stadji**:

```
                              ┌──────────────┐
   Talba HTTP                  │  1. ROUTE    │   riżoluzzjoni tal-combo, għażla tal-mudell
   (route ta’ Next.js)         └──────┬───────┘
                                     │
                                     ▼
                              ┌──────────────┐
                              │  2. TRANSLATE│   konverżjoni tal-format (OpenAI ↔ Claude ↔ Gemini)
                              └──────┬───────┘
                                     │
                                     ▼
                              ┌──────────────┐
                              │  3. EXECUTE  │   eżekutur tal-fornitur, HTTP, tentattiv mill-ġdid, breaker
                              └──────┬───────┘
                                     │
                                     ▼
                              ┌──────────────┐
                              │  4. STREAM   │   trasformazzjoni SSE, backpressure
                              └──────┬───────┘
                                     │
                                     ▼
                              ┌──────────────┐
                              │  5. RECORD   │   traċċar tal-użu, reġistru tas-sejħiet, klassifikazzjoni tal-iżbalji
                              └──────┬───────┘
                                     │
                                     ▼
                              Rispons HTTP (SSE jew JSON)
```

### Stadju 1: Routing (services/combo.ts)

**Punt tad-dħul**: `handleComboChat()` f’`services/combo.ts`

Jirriżolvi t-talba għal tuple konkret `(provider, model, account, credentials)`:

- Fittex il-combo permezz tal-ID (jew ibni combo virtwali għall-mudelli `auto/*`)
- Applika l-istrateġija tar-routing (prijorità, ponderata, round-robin, eċċ.)
- Iffiltra l-fornituri li mhumiex f’saħħithom (circuit breaker)
- Agħżel il-mira vijabbli li jmiss

Għall-mudelli `auto/*`, dan l-istadju wkoll:

- Iħaddem l-algoritmu ta’ **punteġġ ibbażat fuq 16-il fattur** (`services/autoCombo/`)
- Jagħżel par `provider+model` abbażi tas-saħħa, l-ispiża, il-latenza, eċċ.

### Stadju 2: Traduzzjoni (translator/)

Jekk il-format tas-sors (eż., OpenAI) ikun differenti mill-format fil-mira (eż., Claude), it-talba tiġi **tradotta**:

- Prompt tas-sistema → messaġġ tas-sistema
- Definizzjonijiet tal-għodod → format tal-għodod speċifiku għall-fornitur
- Parametri tar-raġunament/ħsieb → ekwivalenti speċifiċi għall-fornitur
- Normalizzazzjoni tar-rwoli tal-messaġġi (`developer` → `system` għal dawk li mhumiex OpenAI)

`translator/index.ts` jesponi:

```ts
translateRequest(body, sourceFormat, targetFormat): TranslatedRequest
needsTranslation(source, target): boolean
```

### Stadju 3: Eżekuzzjoni (executors/)

**Punt tad-dħul**: `getExecutor(providerId).execute(request, options)`

Il-fornituri kollha jużaw `DefaultExecutor` (`executors/default.ts`) permezz tal-fallback tal-factory `getExecutor()`. L-eżekutur:

- Jibni l-URL upstream (`buildUrl()`)
- Iżid headers speċifiċi għall-fornitur (`buildHeaders()`)
- Jittrasforma l-body tat-talba (`transformRequest()`)
- Jibgħat it-talba HTTP b’tentattivi mill-ġdid + dewmien esponenzjali
- Jittratta l-aġġornament tal-awtentikazzjoni meta jkun meħtieġ (fornituri OAuth)

L-eżekuturi kollha jestendu `BaseExecutor` (`executors/base.ts`, 1170 LOC), li jipprovdi:

- Loġika komuni għat-tentattivi mill-ġdid
- Integrazzjoni ma’ proxy
- Integrazzjoni ma’ circuit breaker
- Hooks għar-reġistrazzjoni tal-użu

### Stadju 4: Streaming (utils/stream.ts)

Għal risponsi bi streaming, l-eżekutur jirritorna **ReadableStream**. Il-handler:

- Jgħaddi minn trasformazzjoni SSE (`createSSETransformStreamWithLogger`)
- Japplika pings heartbeat biex jinduna b’konnessjonijiet inattivi
- Jittratta l-iskonnessjoni tal-klijent b’mod xieraq (`pipeWithDisconnect`)
- Jittrasforma SSE → JSON għal klijenti li ma jużawx streaming

Għal risponsi mingħajr streaming, l-eżekutur jirritorna oġġett JSON parsed li jgħaddi mingħajr tibdil.

### Stadju 5: Reġistrazzjoni (services/usage.ts)

Wara r-rispons (kemm jekk jirnexxi kif ukoll jekk ifalli), jiġi rreġistrat l-użu:

- `prompt_tokens`, `completion_tokens`, `cached_tokens` mir-rispons
- `cost_usd` ikkalkulat mid-data tal-ipprezzar
- `latency_ms`, `status`, `error_class` jekk ifalli
- Jinżamm fit-tabella `usage_history`

L-artefatti tar-reġistru tas-sejħiet (jekk attivati) jinkitbu f’`${DATA_DIR}/call_logs/`.

## Fajls Ewlenin Deep-Dive

### chatCore.ts (5977 linji)

Il-** handler prinċipali tar-rikjesti** . Minkejja d-daqs tagħha, għandha struttura ċara:

```ts
// Pseudo-structure of chatCore.ts
export async function handleChat(request: NextRequest) {
  // 1. Auth + CORS
  await authenticateRequest(request);
  applyCorsHeaders(response);

  // 2. Body validation
  const body = await parseRequestBody(request);

  // 3. Format detection + translation
  const sourceFormat = detectFormat(request);
  const targetFormat = getTargetFormat(providerId);
  if (needsTranslation(sourceFormat, targetFormat)) {
    body = translateRequest(body, sourceFormat, targetFormat);
  }

  // 4. Combo routing
  const targets = await resolveComboTargets(comboId, body);
  for (const target of targets) {
    try {
      const result = await executeOnTarget(target, body);
      await recordUsage(result);
      return result;
    } catch (err) {
      // Continue to next target
    }
  }

  // 5. Emergency fallback
  return await emergencyFallback(body);
}
```

Minkejja li hija funzjoni ġgant waħda, hija organizzata fi** sezzjonijiet ikkummentati** dik il-mappa għall-pipeline f'5 stadji.

## Eżekuturi (150 modulu)

L-aktar fajl wieħed għal kull fornitur. Il-klassijiet eżekutur kollha jestendu `BaseExecutor` u jegħlbu dak li huwa differenti; il-moduli l-oħra huma helpers għal kull fornitur (skemi tal-għodda, adapters fetch/TTS, quirk handlers).

### Mudelli Komuni

Il-fornituri jiġu solvuti permezz ta `getExecutor(providerId)`, li jirritorna l-eżekutur konfigurat. Il-fornituri OpenAI/Anthropic-compatible jużaw `DefaultExecutor` (`executors/default.ts`). L-imġieba speċifika għall-fornitur (bażi URL, awth headers, verżjoni API ) hija kkonfigurata `open-sse/config/providers/`, filwaqt li t-trasformazzjonijiet tal-korp tat-talba jiġu ttrattati `open-sse/translator/`.

**Custom URL** huwa stabbilit permezz tal-konfigurazzjoni tal-fornitur:

```ts
// Provider config in open-sse/config/providers/
export default {
  id: "together",
  baseURL: "https://api.together.xyz/v1/chat/completions",
}
````

**Awtorizzazzjoni tad-dwana** tiġi ttrattata permezz tal-konfigurazzjoni ta' awtentikazzjoni tar-reġistru tal-fornitur (ċavetta API, OAuth, profili ta' header).

**Korp talba tad-dwana** trasformazzjonijiet (eż., Anthropic li jissepara `system` minn `messages`) huma rreġistrati għal kull fornitur `open-sse/translator/`.

### The Executor Factory

`executors/index.ts` exports `getExecutor(providerId)`:

```ts
import { getExecutor } from "@omniroute/open-sse/executors";

const executor = getExecutor("anthropic");
const result = await executor.execute({
  model: "claude-sonnet-4-5",
  messages: [...],
});
````

Ir-riżoluzzjoni tgħaddi mill- `ExecutorRegistry` (`executors/registry.ts`): kull eżekutur speċjalizzat huwa ddikjarat fit-tabella integrata ta ' `executors/index.ts` u rreġistrata permezz ta `registerExecutor(alias, instance)` fit-tagħbija tal-modulu; `getExecutor()` jikkonsulta r-reġistru u jaqa' lura għal `DefaultExecutor` memoized għal kwalunkwe fornitur mingħajr dħul speċjalizzat. L-immappjar sħiħ tal-eżekutur tal-alias → huwa kkaratterizzat mit-test tad-deheb `tests/unit/executor-map-golden.test.ts`.

## Tradutturi

Ittraduċi bejn **3 formats**: OpenAI, Anthropic, Gemini, flimkien mal-Responses API l-ġdida.

### Meta Sseħħ it-Traduzzjoni

```ts
import { needsTranslation, translateRequest } from "@omniroute/open-sse/translator";

if (needsTranslation(sourceFormat, targetFormat)) {
  body = translateRequest(body, sourceFormat, targetFormat);
}
```

Traduzzjonijiet komuni:

- `OpenAI → Anthropic`: field `system` separat, header `x-api-key`
- `OpenAI → Gemini`: `contents` minflok `messages`, `systemInstruction`
- `OpenAI → Responses API`: array `input`, stat `previous_response_id`

### Każijiet Speċjali Ttrattati

- Ir-rwol `developer` → `system` għal dawk li mhumiex OpenAI
- Ir-rwol `system` → jingħaqad mal-ewwel messaġġ tal-utent għal GLM/ERNIE
- `json_schema` → `responseMimeType` + `responseSchema` ta' Gemini
- `tools` → format tal-għodod speċifiku għall-fornitur
- Parametri tal-ħsieb (o1, Claude) → ekwivalenti speċifiċi għall-fornitur

## Server MCP

`open-sse/mcp-server/` jimplimenta s-server tal-**Model Context Protocol**:

- **110 għodod** (ġestjoni tal-fornituri, combos, memorja, cache, kompressjoni, proxy, ħiliet, gamification, plugins, Notion, Obsidian, corpus lokali)
- **3 transports**: stdio, SSE, Streamable HTTP
- **33 scopes** għal awtorizzazzjoni granulari

### Reġistrazzjoni tal-Għodod

L-għodod jiġu rreġistrati bħala files awtonomi f'`open-sse/mcp-server/tools/`, u kull wieħed jesporta isem, schema, handler, u scope:

```ts
// open-sse/mcp-server/tools/getHealth.ts
import { z } from "zod";
export default {
  name: "omniroute_get_health",
  description: "Get system health snapshot",
  scope: "read:health",
  inputSchema: z.object({}),
  handler: async (_args, ctx) => {
    return await getSystemHealth();
  },
};
```

### Transports

```ts
// stdio (użu tas-CLI)
startMcpStdio(server);

// SSE (streaming ibbażat fuq HTTP)
startMcpSse(server, port);

// Streamable HTTP (MCP modern)
startMcpStreamable(server, port);
```

### Awtorizzazzjoni

Kull sejħa lil għodda tgħaddi minn kontrolli tal-scope (`open-sse/mcp-server/auth/`):

```ts
if (!hasScope(apiKey, "providers:read")) {
  throw new Error("Insufficient scope");
}
```

## Transformers

`open-sse/transformer/` jikkonverti bejn il-formats **Chat Completions** u **Responses API**.

### Għaliex Transformer Separat?

Ir-Responses API hija l-format il-ġdid ta' OpenAI b'**konverżazzjonijiet bi stat** (`previous_response_id`). Meta klijent jibgħat talba Responses, OmniRoute:

1. Jikkonverti Responses → Chat Completions internament
2. Jibgħat lill-fornitur (kwalunkwe fornitur li jappoġġja Chat Completions)
3. Jikkonverti t-tweġiba lura għall-format Responses
4. Jibgħat it-tweġiba kkonvertita bħala stream lill-klijent

It-transformer (`transformer/responsesTransformer.ts`) jipprovdi:

```ts
createResponsesApiTransformStream(): TransformStream
```

Dan jittratta:

- Avvenimenti `response.output_item.added`
- Avvenimenti `response.output_text.delta`
- Avveniment `response.completed`
- Immappjar tas-sejħiet tal-għodod (`function_call` ↔ `tool_calls`)

## Limitazzjonijiet tal-Prestazzjoni

Il-magna tar-routing għandha baġits stretti tal-prestazzjoni:

| Operazzjoni                                                | Mira  | Kejl                                   |
| ---------------------------------------------------------- | ----- | -------------------------------------- |
| Riżoluzzjoni tal-combo                                     | <10ms | Għal 50 mira                           |
| Verifika tal-limitu tar-rata                               | <1ms  | Token bucket fil-memorja               |
| Fallback tal-familja tal-mudelli                           | <5ms  | Definizzjonijiet tal-familji fil-cache |
| Distribuzzjoni tar-routing tat-talba                       | <2ms  | Mogħdija kritika                       |
| **Ebda I/O li jimblokka fil-mogħdija kritika tar-routing** | —     | Kollox asinkronu                       |

## Anti-Patterns

❌ **Sejħiet sinkroniċi lid-DB f’`combo.ts`** — ikkalkula minn qabel u aħżen fil-cache
❌ **Loġika ta’ tentattiv mill-ġdid fil-handlers** — uża `retry()` mis-servizz tar-reżiljenza
❌ **Aċċess dirett għall-konfigurazzjoni tal-fornitur** — uża l-getters ta’ `providerRegistry`
❌ **Ktajjen ta’ fallback miktuba direttament fil-kodiċi** — iddefinixxihom f’`modelFamilyFallback.ts`
❌ **Mutazzjonijiet tal-istat bejn talbiet konkorrenti** — uża biss kuntest speċifiku għat-talba

## Żieda ta’ Komponent Ġdid

### Żieda ta’ Servizz Ġdid

1. Oħloq `open-sse/services/[serviceName].ts` b’responsabbiltà ffukata
2. Esporta l-funzjoni prinċipali tal-handler u kwalunkwe kostanti
3. Żid testijiet unitarji f’`tests/unit/services/[serviceName].test.mjs`
4. Integrah fil-pipeline tat-talbiet f’`handlers/chatCore.ts` (jekk ikun relatat mar-routing)
5. Aġġorna l-loġika tar-routing f’`combo.ts` jekk is-servizz jaffettwa l-għażla tal-mira
6. Iddokumentah f’dan il-fajl

### Żieda ta’ Executor Ġdid

1. Oħloq `open-sse/executors/[provider].ts` li jestendi `BaseExecutor`
2. Irreġistrah f’`config/providerRegistry.ts`
3. Żidu mal-factory ta’ `executors/index.ts`
4. Żid testijiet unitarji għall-executor
5. Iddokumentah f’`docs/architecture/ARCHITECTURE.md`

### Żieda ta’ Għodda MCP Ġdida

1. Oħloq jew aġġorna `open-sse/mcp-server/tools/[category]Tools.ts`
2. Iddefinixxi schema Zod għall-inputs
3. Irreġistra l-għodda f’`mcp-server/index.ts`
4. Żidha mal-matriċi tal-ambiti f’`mcp-server/auth/`
5. Żid testijiet unitarji
