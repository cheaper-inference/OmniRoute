`devin-cli-agentic` jippermetti lir-runtime reali ta’ Claude Code juża l-endpoint lokali ta’
Anthropic Messages ta’ OmniRoute filwaqt li l-CLI uffiċjali ta’ Devin jipprovdi t-tweġibiet
tal-mudell permezz ta’ ACP stdio. Dan ma jimmodifikax il-fornituri eżistenti Anthropic,
Claude OAuth, Claude Web, jew `devin-cli`.

Għal sejħiet tal-għodod ikkontrollati mill-klijent, idderieġi permezz ta’
`devin-cli-agentic` (alias `dva`), il-fornitur bil-format Claude li jappoġġja l-għodod.
L-eżekutur ACP preċedenti `devin-cli` (`dv`) jaħdem bit-test biss: iħaddem is-sommarizzatur
ta’ Devin mingħajr għodod u ma jistax jirritorna sejħiet tal-għodod. Il-metadata tal-mudell
tiegħu hija mmarkata skont dan sabiex id-direzzjonament ikkombinat li jeħtieġ l-għodod jevitah.

> **Status attwali: Claude Code ffissat fuq `2.1.258`; il-validazzjoni offline u live ġiet
> irreġistrata l-aħħar fuq `2.1.220`.** Il-verżjoni ffissata `2.1.220` lestiet tliet xenarji
> iżolati permezz ta’ Devin CLI `3000.2.17` u l-mudell `swe-1-7-lightning`; dik l-aħħar
> eżekuzzjoni live ppruvat ċikli ta’ `Read`, `Edit`, u `Bash` ikkontrollati mill-klijent,
> riżultati ta’ `npm test` li rnexxew, is-sejbien tal-kmandi u l-ħiliet tal-proġett,
> direzzjonament permezz ta’ Devin biss, u ebda traffiku ħiereġ lejn Claude. Imbagħad
> il-verżjoni ffissata żdiedet għal `2.1.258` (il-ġenerazzjoni tal-CLI li tissimula l-identità
> Claude ta’ OmniRoute, u l-ewwel linja li tinkludi b’mod nattiv il-livell Fable 5.1). Fuq
> il-verżjoni l-ġdida ġew ivverifikati s-saff tal-installazzjoni u `claude --version` fuq
> l-immaġni bażi ffissata, u jgħaddu s-sett ta’ testijiet unitarji tal-bridge, `compose config`
> u l-prova statika tal-iżolament — iżda x-xenarju mock offline u s-sett live ta’ tliet
> xenarji għadhom ma reġgħux ġew eżegwiti. Erġa’ eżegwihom (ara "Aġġornament tal-għodod
> iffissati") qabel ma tiddependi fuq il-bridge b’din il-verżjoni ffissata.

## Arkitettura

```text
Claude Code 2.1.258 (kontenitur Linux iżolat mhux root)
  -> http://omniroute:20128/v1/messages
  -> devin-cli-agentic (format Claude, fornitur mingħajr awtentikazzjoni)
  -> devin acp --agent-type summarizer (ACP stdio uffiċjali, mingħajr għodod Devin)
  -> Kont Devin fil-volum iddedikat devin-auth
```

L-aġent ACP default tal-CLI uffiċjali jista’ jeżegwixxi l-għodod tiegħu stess, għalhekk dan
il-bridge ma jużahx. Huwa jibda l-aġent ACP fiss `summarizer`, li l-modalità uffiċjali tiegħu
fil-CLI m’għandhiex għodod, u jinkwadra t-talba Anthropic serjalizzata bħala traċċa
tal-eżekuzzjoni. Meta tkun meħtieġa azzjoni oħra kkontrollata minn Claude, it-tweġiba trid
tinkludi eżattament invilopp wieħed ta’ għodda tal-klijent. Kwalunkwe `tool_call` jew
`tool_call_update` ta’ ACP jiġi rrifjutat qabel ma tweġiba tkun tista’ tiġi rrappurtata
bħala waħda li rnexxiet.

Is-serializer f’`open-sse/executors/devin-agentic/serializer.ts` jippreserva `system`,
`text`, `tool_use`, `tool_result`, `thinking`, `redacted_thinking`, `tool_choice`, u
l-għodod ipprovduti minn Claude Code. L-immaġnijiet u l-blokok mhux magħrufa jfallu b’mod
espliċitu. Riżultati kbar tal-għodod jużaw markatur viżibbli tat-tronkament.

Il-parser jaċċetta invilopp wieħed indipendenti `<tool>{...}</tool>` għal kull ċiklu
tal-mudell. Huwa jqabbel l-isem mal-lista tal-għodod tat-talba, jivvalida l-argumenti
mal-JSON Schema ta’ dik l-għodda, jirrifjuta taħlit ta’ narrattiva u azzjonijiet, u
jippermetti tentattiv wieħed limitat ta’ tiswija. Imbagħad Claude Code jeżegwixxi lokalment
it-`tool_use` Anthropic li jirriżulta u jibgħat it-`tool_result` lura permezz ta’ OmniRoute.

## Direzzjonament awtomatiku

Il-fornitur huwa eliġibbli fil-gruppi ta’ kandidati `auto/*` ta’ OmniRoute meta ma jkunx
imblukkat. L-eliġibbiltà bħala kandidat ma tiggarantix l-għażla: l-istrateġija ta’
direzzjonament tal-kombinazzjoni (pereżempju, l-aħħar waħda magħrufa li taħdem) tista’
tippreferi fornitur ieħor. Uża `dva/<model>` jew kombinazzjoni li tagħti prijorità lil Devin
meta teħtieġ li kull talba tgħaddi minn Devin.

## Iżolament u mudell tat-theddid

L-installazzjoni, il-kont u l-konfigurazzjoni ta’ Claude fuq il-host huma barra mill-ambitu u jitqiesu
pprojbiti. Is-servizzi Compose:

- jaħdmu bħala UID/GID `10001:10001`, b’sistema tal-fajls root għall-qari biss, kapaċitajiet
  imneħħija, u `no-new-privileges`;
- jużaw `/home/bridge` privat, volum iddedikat għall-konfigurazzjoni ta’ Claude, data OmniRoute iżolata,
  u volum `devin-auth` separat;
- jimmontaw biss spazji tax-xogħol/evidenza `.sandbox` li jistgħu jintremew;
- ma jimmontawx id-direttorju home tal-host, Keychain, kredenzjali SSH jew tal-cloud, jew is-socket ta’ Docker;
- jibnu ambjenti espliċiti u jneħħu l-varjabbli tal-API/OAuth/routing ta’ Anthropic;
- jidderieġu l-inferenza ta’ Claude Code biss lejn `http://omniroute:20128` b’ċavetta lokali biss.

Il-profil offline juża network intern. Fil-profil live, OmniRoute jilħaq l-endpoints
uffiċjali ta’ Devin biss permezz ta’ `network-guard`; destinazzjonijiet mhux relatati jiġu miċħuda.
Claude Code għandu gwardja tal-egress separata li tiċħad kollox u jista’ jilħaq biss is-servizz
OmniRoute lokali permezz ta’ `NO_PROXY`. Il-fajls tal-awditjar tal-gwardji jiġu mmontati biss
mill-proċess tal-gwardja rispettiv tagħhom. L-iskripts jivverifikaw is-sjieda tal-fajls, il-modalità,
l-għadd tal-links, u kull deċiżjoni qabel jesportaw evidenza mingħajr tokens.

Ħaddem il-prova tal-iżolament b’mod indipendenti:

```bash
./scripts/devin-bridge/verify-anthropic-isolation
```

Din tivvalida t-topoloġija, il-mounts imsemmija, is-settings ta’ utent mhux root/għall-qari biss,
ir-routing lokali espliċitu, in-nuqqas ta’ varjabbli ambjentali sensittivi, in-nuqqas tas-socket
ta’ Docker, l-aċċess imblukkat għal `api.anthropic.com` u `claude.ai`, l-għażla ta’ fornitur
Devin biss, u falliment espliċitu meta l-backend ACP ma jkunx disponibbli.

## Konfigurazzjoni inizjali u użu normali

Ibni l-image iffissata:

```bash
./scripts/devin-bridge/build
```

Awtentika biss il-volum iżolat ta’ Devin:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/login-devin
```

Il-kmand tal-login juża l-fluss uffiċjali ta’ token manwali maħsub għal ambjenti
remoti/f’containers. Il-valur jiddaħħal direttament fil-prompt tas-CLI; ma jiġix mgħoddi bħala
argument tal-proċess, miktub f’Git, jew ikkupjat mill-host.

Niedi l-ambjent ta’ eżekuzzjoni iżolat ta’ Claude Code:

```bash
./scripts/devin-bridge/launch
```

`launch` jerġa’ jiċċekkja l-iżolament, l-awtentikazzjoni ta’ Devin, u l-iskoperta tal-mudelli qabel
jibda Claude Code f’container. Qatt ma jħaddem l-eżekutibbli Claude tal-host. Il-psewdonimi
tal-mudelli jistgħu jiġu ssettjati f’`.env.devin-bridge`; kull valur ikkonfigurat irid iżomm
il-prefiss `devin-cli-agentic/`.

## Kmandi ta’ validazzjoni

Il-perkors offline riproduċibbli ma jeħtieġ l-ebda kont Devin u ma għandu l-ebda aċċess għall-Internet waqt l-eżekuzzjoni:

```bash
./scripts/devin-bridge/test-unit
./scripts/devin-bridge/test-contract
./scripts/devin-bridge/test-e2e-mock
./scripts/devin-bridge/verify-anthropic-isolation
```

Il-perkors live awtentikat u attivat b’għażla huwa:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/test-live-devin
```

Ir-runner live jistenna bejn ix-xenarji biex jevita li jiftaħ sessjonijiet ACP f’daqqa u
jivvalida avvenimenti strutturati tal-fluss ta’ Claude minflok jafda dikjarazzjonijiet testwali. It-tliet
xenarji tiegħu jagħtu prova ta’:

1. qari dirett tal-proġett u analiżi tad-difetti;
2. `Edit` reali, `Bash` `npm test` ikkontrollat mill-klijent, u riżultat terminali;
3. `/bridge-check` flimkien mal-iskoperta ta’ `bridge-proof`, qari tal-proġett, `npm test` ieħor
   ikkontrollat mill-klijent li jirnexxi, u tlestija mingħajr xogħol pendenti.

Il-kontroll finali jiċċekkja wkoll l-awditjar tan-network ta’ Devin u jeħtieġ li l-awditjar tal-egress ta’
Claude jibqa’ vojt.

## Aġġornament tal-għodod b’verżjonijiet iffissati

L-immaġni tiffissa l-verżjonijiet ta’ Node, Claude Code, u Devin CLI fi
`docker/devin-bridge/Dockerfile`. Biex taġġornahom:

1. ibdel il-verżjonijiet espliċiti;
2. ibdel iż-żewġ checksums tal-arkivju Devin speċifiċi għall-arkitettura b’valuri għall-artefatt
   uffiċjali;
3. erġa’ ibni u ħaddem kull kmand ta’ validazzjoni offline;
4. ikkonferma l-verżjonijiet ġewwa l-immaġni;
5. erġa’ ħaddem is-sett live awtentikat tat-tliet xenarji.

Tinstallax l-ebda waħda miż-żewġ CLI globalment fuq il-host u tissostitwixxix il-verifika taċ-checksum
b’download mhux ivverifikat.

## Dijanjosi u tindif

- `docker compose -f docker/devin-bridge/compose.yml --profile offline logs omniroute`
  juri r-routing lokali u żbalji sanizzati tal-eżekutur.
- `.sandbox/evidence/mock-acp.jsonl` jirreġistra azzjonijiet mock ACP deterministiċi.
- `.sandbox/evidence/claude-stream.jsonl` jirreġistra l-eżekuzzjoni offline reali ta’ Claude Code.
- `.sandbox/evidence/live-*.jsonl` jirreġistra t-tliet streams live vvalidati.
- `.sandbox/evidence/egress.jsonl` u `.sandbox/evidence/claude-egress.jsonl` huma kopji vvalidati,
  mingħajr tokens, tal-awditi tal-guard.

Waqqaf il-containers u n-networks proprjetà tal-bridge filwaqt li tippreserva l-volumes tal-login/konfigurazzjoni:

```bash
./scripts/devin-bridge/clean
```

Neħħi l-ambjent kollu proprjetà tal-bridge, inklużi l-volumes imsemmija:

```bash
./scripts/devin-bridge/clean --all
```

## Limitazzjonijiet

- Il-bridge jiddependi fuq ir-rwol fiss `summarizer` mingħajr għodod minħabba li Devin CLI `3000.2.17`
  ma jesponix aġent ACP newtrali mingħajr għodod. L-adapter jikkumpensa għal risposti intermedji
  f’forma ta’ sommarju, iżda tentattiv wieħed limitat ta’ tiswija xorta jista’ jfalli b’mod espliċitu.
- Sejħiet ACP live jistgħu jirritornaw risposti tranżitorji `502`/`504`. Il-harness iħalli intervall bejn ix-xenarji;
  falliment persistenti jibqa’ magħluq f’każ ta’ falliment u qatt ma jagħżel provider ieħor.
- Il-kuntest ACP jiġi rikostruwit minn kull talba Anthropic; ma hemm l-ebda affinità
  ta’ proċess/sessjoni.
- Sejħa waħda ta’ għodda hija appoġġjata għal kull risposta tal-mudell; sejħiet paralleli jiġu rrifjutati.
- L-immaġnijiet espliċitament mhumiex appoġġjati. Vision, output tal-ħsieb, kontrolli tal-isforz, u tieqa tal-kuntest ta’ 1M
  mhumiex reklamati.
- SSE juża avvenimenti validi taċ-ċiklu tal-ħajja ta’ Anthropic iżda jiġi emess wara li jinġabar it-turn ACP
  limitat; iċ-chunks ACP ma jintbagħtux progressivament.
