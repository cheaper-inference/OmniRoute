## Kategoriji

- **B’xejn** — livell bla ħlas b’ċavetta API (ikkonfigurat permezz tad-dashboard)
- **Mingħajr awtentikazzjoni** — endpoints pubbliċi li ma jeħtieġu ebda ċavetta jew dħul fil-kont
- **OAuth** — proċess ta’ dħul fil-kont immaniġġjat minn OmniRoute, mingħajr il-ħtieġa ta’ ċavetta API
- **Cookie tal-web** — jinkapsula l-app tal-web tal-fornitur permezz ta’ awtentikazzjoni bil-cookie
- **Ċavetta API** — fornitur bi ħlas ikkonfigurat permezz ta’ ċavetta API (jistgħu japplikaw krediti bla ħlas)
- **Lokali** — jaħdem fuq il-magna tal-utent (Ollama, LM Studio, vLLM, eċċ.)
- **Tiftix** — fornituri tat-tiftix fuq il-web
- **Awdjo** — fornituri tal-awdjo biss (TTS/STT)
- **Proxy upstream** — fornituri li jagħmlu proxy għal fornituri oħra
- **Aġent tal-cloud** — aġenti tal-ipprogrammar li jaħdmu għal żmien twil (Codex Cloud, Devin, Jules)
- **Sistema** — fornituri interni ta’ OmniRoute (loopback, eċċ.)

Tikketti addizzjonali: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (fejn jidher): `native` — API reali għas-sejħiet tal-funzjonijiet; `emulated` — l-array `tools` jiġi emulat fil-prompt permezz ta’ `webTools.ts` (blokki `<tool>{...}</tool>` analizzati b’espressjonijiet regolari); `none` — bħalissa `tools` jitwarrab mingħajr ebda avviż. Ara #7286.

Uża d-dashboard f’`/dashboard/providers` biex tattiva, tikkonfigura u tittestja kull fornitur.
