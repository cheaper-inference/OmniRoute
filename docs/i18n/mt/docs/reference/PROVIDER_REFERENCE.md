## Kategoriji

- **Ħieles** — free saff b'ċavetta API (konfigurat permezz tad-dashboard)
- **Nru-awth** — endpoints pubbliċi li ma jeħtieġu l-ebda ċavetta jew sign-in
- **OAuth** — sign-in flow mmaniġġjat minn OmniRoute, l-ebda ċavetta API meħtieġa
- **Web cookie** — jdaħħal l-app tal-web tal-fornitur permezz tal-cookie auth
- **API key** fornitur imħallas — ikkonfigurat permezz taċ-ċavetta API (jistgħu japplikaw krediti b'xejn)
- **Lokali** — jaħdem fuq il-magna tal-utent (Ollama, LM Studio, vLLM, eċċ.)
- **Fittex** — web search providers
- **Awdjo** fornituri tal-awdjo biss — (TTS/STT)
- **Prokura upstream** — providers li prokura lil fornituri oħra
- **Aġent tas-sħab** — aġenti tal-kodifikazzjoni li ilhom għaddejjin (Codex Cloud, Devin, Jules)
- **Sistema** — OmniRoute-fornituri interni (loopback, eċċ.)

Tags addizzjonali: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (fejn muri): `native` — funzjoni reali li ssejjaħ API; `emulated` — l-array `tools` huwa emulat fil-pront permezz ta `webTools.ts` (blokki `<tool>{...}</tool>` parsed regex); `none` — `tools` bħalissa huwa waqa 'skiet. Ara #7286.

Uża d-dashboard `/dashboard/providers` biex tattiva, tikkonfigura, u tittestja kull fornitur.
