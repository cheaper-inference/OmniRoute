## Tlestijiet taċ-Chat

```bash
POST /v1/chat/completions
Authorization: Bearer your-api-key
Content-Type: application/json

{
  "model": "cc/claude-opus-4-6",
  "messages": [
    {"role": "user", "content": "Write a function to..."}
  ],
  "stream": true
}
```

### Headers Personalizzati

| Header                   | Direzzjoni | Deskrizzjoni                                                                                                                                                                                                                                                                   |
| ------------------------ | ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `X-OmniRoute-No-Cache`   | Talba      | Issettja għal `true` biex taqbeż il-cache                                                                                                                                                                                                                                      |
| `x-omniroute-no-memory`  | Talba      | Issettja għal `true` biex taqbeż l-injezzjoni tal-memorja u tal-ħiliet għal din it-talba (tirrifletti no-cache; tevita l-ispiża addizzjonali ta’ tokens/kost għal kull sejħa)                                                                                                  |
| `X-OmniRoute-Progress`   | Talba      | Issettja għal `true` għal avvenimenti tal-progress                                                                                                                                                                                                                             |
| `X-Session-Id`           | Talba      | Ċavetta persistenti tas-sessjoni għall-affinità ma’ sessjoni esterna                                                                                                                                                                                                           |
| `x_session_id`           | Talba      | Il-varjant bil-linja ta’ taħt huwa aċċettat ukoll (HTTP dirett)                                                                                                                                                                                                                |
| `X-OmniRoute-Session-Id` | Talba      | Tikketta tas-sessjoni/konverżazzjoni pprovduta minn min jagħmel is-sejħa (tintuża wkoll mill-memorja). Meta tkun preżenti, tinħażen eżatt kif inhi f’`call_logs.session_tag` għall-attribuzzjoni tal-kost għal kull sessjoni (#8249) — qatt ma tiġi ġġenerata meta tkun nieqsa |
| `Idempotency-Key`        | Talba      | Ċavetta għad-deduplikazzjoni (tieqa ta’ 5 sekondi)                                                                                                                                                                                                                             |
| `X-Request-Id`           | Talba      | Ċavetta alternattiva għad-deduplikazzjoni                                                                                                                                                                                                                                      |
| `x-omniroute-connection` | Talba      | Waħħal talba għal mudell wieħed ma’ konnessjoni waħda ta’ fornitur (kont) permezz tal-id tagħha — ara [L-iffissar ta’ kont għal kull talba](#account-pinning-per-request)                                                                                                      |
| `X-OmniRoute-Cache`      | Tweġiba    | `HIT` jew `MISS` (mingħajr streaming)                                                                                                                                                                                                                                          |
| `X-OmniRoute-Idempotent` | Tweġiba    | `true` jekk tkun ġiet deduplikata                                                                                                                                                                                                                                              |
| `X-OmniRoute-Progress`   | Tweġiba    | `enabled` jekk it-traċċar tal-progress ikun attiv                                                                                                                                                                                                                              |
| `X-OmniRoute-Session-Id` | Tweġiba    | L-ID effettiv tas-sessjoni użat minn OmniRoute                                                                                                                                                                                                                                 |
| `X-OmniRoute-Request-Id` | Tweġiba    | L-id tal-korrelazzjoni tat-talba (meta jkun magħruf)                                                                                                                                                                                                                           |
| `X-OmniRoute-Version`    | Tweġiba    | Il-verżjoni tal-build ta’ OmniRoute (dejjem preżenti)                                                                                                                                                                                                                          |
| `X-OmniRoute-Cost-Saved` | Tweġiba    | L-ammont f’USD li l-cache evita fuq HIT (għal hits tal-cache biss)                                                                                                                                                                                                             |
| `X-OmniRoute-Decision`   | Tweġiba    | Traċċa tar-routing: `strategy=<name>; provider=<alias>; latency_ms=<n>` (`<name>` hija l-istrateġija tal-kombinazzjoni, jew `single` għal talba li mhijiex kombinazzjoni) — dejjem preżenti fit-tweġibiet tat-tlestija                                                         |

#### Iffissar ta’ kont għal kull talba

Meta fornitur ikollu diversi konnessjonijiet (kontijiet jew ċwievet), OmniRoute normalment jagħżel waħda
permezz tal-istrateġija tiegħu għall-għażla tal-kontijiet. Minflok, talba tista’ tintrabat ma’ konnessjoni
speċifika waħda bl-intestazzjoni `x-omniroute-connection`:

```bash
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <your OmniRoute API key>" \
  -H "Content-Type: application/json" \
  -H "x-omniroute-connection: <connection id>" \
  -d '{"model": "codex/gpt-5.5", "messages": [{"role": "user", "content": "hi"}]}'
```

- **Fejn issib l-ID.** Iftaħ il-paġna tal-fornitur fid-dashboard
  (**Dashboard → Fornituri → <provider>**) u kklikkja ċ-ċippa tal-ID `xxxxxxxx…` fir-ringiela ta’ konnessjoni
  — din tikkopja l-ID sħiħ tal-konnessjoni.
- **Liema talbiet jirrispettawh.** Talbiet b’mudell wieħed (`provider/model`) fuq
  `/v1/chat/completions`, `/v1/messages` u `/v1/responses`. Il-kombinazzjonijiet jinjoraw l-intestazzjoni: orbot
  kont għal kull pass tal-kombinazzjoni permezz tal-konnessjoni tal-pass innifsu.
- **L-irbit huwa strett, mhux preferenza.** Il-konnessjoni marbuta tintuża esklussivament. Ħsara
  waqt it-talba tirreġistra l-perjodu ta’ stennija tal-kont iżda **ma** taqlebx għal
  kont ieħor tal-istess fornitur.
- **Il-perjodu ta’ stennija u l-kwota jneħħu l-irbit.** Waqt li l-konnessjoni marbuta tkun fil-perjodu ta’ stennija,
  tkun eżawriet il-kwota jew tkun imblukkata minn politika tal-kwoti, talbiet sussegwenti jaqgħu lura fuq il-
  konnessjonijiet l-oħra tal-fornitur, eżattament bħal traffiku mhux marbut.
- **IDs mhux magħrufa jew diżattivati jfallu.** ID li ma jkunx fil-ġabra attiva tal-fornitur (imħassar,
  diżattivat, jew li jappartjeni lil fornitur ieħor) ma jħalli ebda kont eliġibbli, għalhekk it-talba
  tfalli minflok ma tiġi diretta x’imkien ieħor mingħajr avviż.

Claude Code jibgħat intestazzjonijiet personalizzati permezz ta’ `ANTHROPIC_CUSTOM_HEADERS`. Poġġih fil-blokka `env`
ta’ `~/.claude/settings.json`, jew f’`.claude/settings.json` fil-livell tal-proġett biex torbot kont differenti
għal kull proġett:

```jsonc
{
  "env": {
    "ANTHROPIC_BASE_URL": "http://<your OmniRoute>:20128",
    "ANTHROPIC_AUTH_TOKEN": "<your OmniRoute API key>",
    "ANTHROPIC_CUSTOM_HEADERS": "x-omniroute-connection: <connection id>",
  },
}
```

Sors: `src/sse/handlers/chat.ts` (qari tal-intestazzjoni), `src/sse/services/auth.ts` u
`src/sse/services/sessionAffinityPin.ts` (it-tneħħija tal-irbit u l-verifika ta’ nuqqas mill-ġabra).

> **Intestazzjonijiet tat-telemetrija tal-ispejjeż:** tweġibiet ta’ suċċess mhux imxandra wkoll jinkludu s-sett ta’ telemetrija tal-ispejjeż `X-OmniRoute-*` — `X-OmniRoute-Response-Cost` (USD, b’10 postijiet deċimali fissi; `0.0000000000` għal dawk bla ħlas/mingħajr prezz), `X-OmniRoute-Tokens-In` / `X-OmniRoute-Tokens-Out`, `X-OmniRoute-Model`, `X-OmniRoute-Provider`, `X-OmniRoute-Latency-Ms`, `X-OmniRoute-Cache-Hit`, u `X-OmniRoute-Fallback-Attempts` (biss meta > 0), flimkien ma’ `X-OmniRoute-Request-Id` u `X-OmniRoute-Version`. Dawn jiġu ġġenerati mit-tlestijiet taċ-chat, `/v1/responses`, `/v1/messages`, **u mill-endpoints tal-media** — `/v1/embeddings`, `/v1/images/generations`, `/v1/audio/speech`, `/v1/audio/transcriptions`, `/v1/rerank`, `/v1/videos/generations`, `/v1/music/generations`, u `/v1/moderations` (dejjem bi spiża `0`). L-ispiża tal-media tiġi kkalkolata skont il-modalità (għal kull immaġni, għal kull sekonda, għal kull karattru, għal kull unità ta’ tfittxija) meta l-ipprezzar ikun disponibbli; inkella tkun `0` (fail-open).

> **Semantika tal-ispiża meta tintlaqat il-cache:** meta jkun hemm HIT fil-cache semantiku (`X-OmniRoute-Cache-Hit: true`) ma ssir ebda sejħa upstream, għalhekk `X-OmniRoute-Response-Cost` ikun `0.0000000000` (l-ispiża **inkrementali** biex tiġi servuta l-hit). L-ispiża oriġinali/li kieku kienet tiġġarrab tiġi rrappurtata separatament f’`X-OmniRoute-Cost-Saved`. Il-konsumaturi tad-dejta tal-fatturazzjoni għandhom jagħmlu s-somma ta’ `X-OmniRoute-Response-Cost` (il-hits ma jiswew xejn); l-analitika tal-cache tista’ taggrega `X-OmniRoute-Cost-Saved`.

## Kiri Esklużiv ta’ Sessjonijiet Immaniġġjati

Il-kiri esklużiv ta’ sessjonijiet immaniġġjati huwa kuntratt ta’ rottaġġ fakultattiv u newtrali għall-klijent: sid attiv wieħed iżomm konnessjoni OmniRoute eliġibbli waħda. Dan ma jikrix mudell, ma jeħtieġx OAuth, ma jidentifikax klijent partikolari, u ma jeħtieġx fornitur partikolari.

Iċ-ċavetta API li tawtentika jrid ikollha l-ambitu `lease:exclusive` u lista espliċita mhux vojta ta’ `allowedConnections`. Il-konfini tal-mutazzjoni tad-database jinforza ż-żewġ oqsma flimkien waqt il-ħolqien taċ-ċavetta u l-aġġornamenti parzjali.

```http
POST /api/v1/session-leases
Authorization: Bearer <managed-api-key>
Content-Type: application/json
X-OmniRoute-Lease-Owner: vlo_<43-base64url-characters>

{"action":"acquire","model":"glm/glm-4.6"}
```

It-tweġibiet li jirnexxu għall-akkwist, it-tiġdid u r-rilaxx juru l-marki tal-ħin, `state`, u l-`generation` pożittiva eżatta, iżda qatt il-konnessjoni magħżula jew il-kredenzjali. It-tiġdid u r-rilaxx jipprovdu l-ġenerazzjoni fil-korp JSON:

```json
{ "action": "renew", "generation": 1 }
```

```json
{ "action": "release", "generation": 1, "reason": "OWNER_EXIT" }
```

Sid ta’ kiri attiv jista’ jitlob b’mod espliċitu metadata għall-wiri li tipproteġi l-privatezza għall-irbit attwali tiegħu:

```json
{ "action": "status", "generation": 1 }
```

```json
{
  "state": "ACTIVE",
  "generation": 1,
  "acquiredAt": "2026-08-28T12:00:00.000Z",
  "renewedAt": "2026-08-28T12:00:30.000Z",
  "expiresAt": "2026-08-28T12:02:30.000Z",
  "connection": {
    "displayName": "Primary Codex",
    "provider": "codex"
  }
}
```

Din l-azzjoni tal-istatus fakultattiva hija protetta mis-sid opak, miċ-ċavetta API mmaniġġjata u awtentikata, u mill-ġenerazzjoni attiva eżatta fi tranżazzjoni waħda tad-database. `displayName` huwa biss l-isem ikkonfigurat u mirqum tal-konnessjoni; ikun `null` meta ma jkun jeżisti ebda isem ikkonfigurat sigur. OmniRoute qatt ma jissostitwixxi indirizz tal-email jew identità tal-kont iġġenerata. Il-valur tal-fornitur huwa tikketta tal-wiri mhux sensittiva u qatt ma huwa identifikatur iġġenerat ta’ fornitur kompatibbli. Il-kredenzjali, it-tokens, il-cookies, l-IDs mhux ipproċessati tal-konnessjoni jew taċ-ċavetta API, il-hashes tas-sidien, is-sigrieti tal-ilqugħ u d-data interna tar-rottaġġ huma esklużi.

It-tiftix b’ċavetta żbaljata, sid żbaljat, ġenerazzjoni skaduta, kiri nieqes, skadut, rilaxxat jew invalidat ilkoll jirritornaw l-istess żball `409 LEASE_FENCE_STALE` mingħajr metadata tal-konnessjoni. Klijent li rċieva t-tweġiba ta’ stennija għall-kapaċità ma għandu ebda rbit attiv x’jispezzjona. Meta r-rottaġġ jittrasferixxi kiri attiv, l-istess ġenerazzjoni tibqa’ valida u l-istatus jirritorna atomikament l-irbit il-ġdid, qatt il-qadim. Il-klijenti eżistenti jibqgħu l-istess minħabba li t-tweġibiet tal-akkwist, it-tiġdid, ir-rilaxx u l-istennija jżommu l-forom preċedenti tagħhom.

Dan il-kuntratt tas-server ma jibdilx `/status` tal-OpenAI Codex standard. Bħalissa, Codex standard jirrapporta l-fornitur tal-mudell u l-istat integrat tal-awtentikazzjoni/kont tiegħu, iżda ma jurix metadata arbitrarja ta’ kontijiet ta’ fornituri personalizzati; integrazzjoni futura tal-klijent trid issejjaħ din l-azzjoni u tiddeċiedi kif turi `connection.displayName`.

Kull talba ta’ inferenza mmaniġġjata mbagħad tipprovdi ż-żewġ headers ta’ kontroll:

```http
X-OmniRoute-Lease-Owner: vlo_<43-base64url-characters>
X-OmniRoute-Lease-Generation: 1
```

Is-sid eżatt, il-ġenerazzjoni, il-konnessjoni attiva u ċ-ċavetta API awtentikata jiġu vverifikati immedjatament qabel kull tentattiv appoġġjat lejn servizz upstream. Ir-ripetizzjoni tas-sid u tal-ġenerazzjoni b’ċavetta oħra tfalli anke meta dik iċ-ċavetta tippermetti l-istess konnessjoni. Is-sidien mhux ipproċessati ma jinħażnux b’mod persistenti, ma jiġux irreġistrati fil-logs, ma jinżammux fl-istampa istantanja tat-talba, u ma jiġux mgħoddija upstream.

Kontenzjoni temporanja tirritorna HTTP `429` b’`Retry-After` u:

```json
{
  "state": "WAITING_FOR_CAPACITY",
  "error": { "type": "lease_error", "code": "LEASE_CAPACITY_UNAVAILABLE" },
  "reason": "NO_FREE_ELIGIBLE_CONNECTION",
  "retryAfter": 30
}
```

Din it-tweġiba tfisser biss li s-sett eliġibbli ordinarju ma kienx vojt u li kull kandidat disponibbli kien miżmum minn kiri attiv barrani. Mudelli/fornituri mhux appoġġjati, nuqqas ta’ qbil mal-politika, perjodu ta’ stennija, kwota, stat tas-servizz u fallimenti ordinarji oħra tal-eliġibbiltà jżommu t-tweġibiet OmniRoute eżistenti tagħhom.

### `x-omniroute-compression`

Sovrastruttura għal kull talba tal-pjan tal-kompressjoni. Għandha l-ogħla preċedenza — tieħu preċedenza fuq is-sovrastruttura tal-kombinazzjoni tar-rottaġġ, il-profil attiv, l-attivazzjoni awtomatika u l-valur Default tal-pannell. Valuri:

| Valur         | Effett                                                                                                                     |
| ------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `off`         | Ebda kompressjoni għal din it-talba.                                                                                       |
| `default`     | Il-profil Default derivat mill-pannell (jinjora l-profil attiv). Il-magni b’telf jibqgħu mitfija.                          |
| `safe`        | Dedup u tiwi tal-ispazji bojod biss.                                                                                       |
| `allow-lossy` | Żomm il-pjan tal-operatur għal din it-talba, inklużi s-sommarji u l-kitbiet mill-ġdid tal-istil.                           |
| `engine:<id>` | Magna waħda meta tkun attivata, eż. `engine:rtk`. Attivazzjoni fakultattiva għal kull talba għal dik il-magna.             |
| `<combo>`     | Kombinazzjoni msemmija, imqabbla l-ewwel skont l-isem (mingħajr distinzjoni bejn ittri kbar u żgħar), imbagħad skont l-id. |

Noti:

- Valuri mhux magħrufa jiġu injorati (it-talba qatt ma tiġi miċħuda); ir-riżoluzzjoni tkompli skont il-preċedenza normali tal-operatur.
- Jekk diversi kombinazzjonijiet ikollhom l-istess isem, għaddi l-**id** tal-kombinazzjoni għal tqabbil deterministiku.
- Kombinazzjoni li isimha huwa `off` jew `default` ma tistax tintgħażel skont l-isem (dawk il-kliem ewlenin jiġu interpretati l-ewwel); irreferi għal tali kombinazzjoni permezz tal-id tagħha.
- Is-swiċċ ewlieni tal-kompressjoni huwa ostaklu assolut: meta l-kompressjoni tkun diżattivata globalment, dan il-header ma jistax jattivaha.

Il-pjan applikat jintwera lura fil-header tat-tweġiba:

```
X-OmniRoute-Compression: <mode>; source=<source>
```

fejn `<source>` huwa wieħed minn `request-header`, `routing-override`, `active-profile`, `auto-trigger`, `default`, jew `off`.

## Embeddings

```bash
POST /v1/embeddings
Authorization: Bearer your-api-key
Content-Type: application/json

{
  "model": "nebius/Qwen/Qwen3-Embedding-8B",
  "input": "The food was delicious"
}
```

Fornituri disponibbli: Nebius, OpenAI, Mistral, Together AI, Fireworks, NVIDIA, **OpenRouter**, Jina AI.

L-identifikaturi tal-katalgu huma `provider/model` (eżempju: `jina-ai/jina-embeddings-v5-omni-small`). L-identifikaturi tal-mudelli Jina mingħajr prefiss li jidhru fir-reġistru (pereżempju `jina-embeddings-v5-text-small`, `jina-reranker-v3.5`) jiġu riżolti wkoll. L-operazzjonijiet ta’ embedding/rerank/classify/segment ta’ Jina jużaw l-ewwel il-kredenzjali `jina-ai` tal-pannell; `JINA_AI_API_KEY` jintuża bħala alternattiva biss meta ma teżisti ebda ċavetta fil-pannell. Il-kard `jina-reader` hija biss għal Reader / `r.jina.ai` (`POST /v1/web/fetch`) u qatt ma tipprovdi embeddings jew rerank.

Il-mudelli fir-reġistru li jiddikjaraw appoġġ multimodali jaċċettaw ukoll sa 32 oġġett strutturat
newtrali għall-fornitur. It-tipi ta’ elementi tal-midja huma `text`, `image`, `audio`, `video`, u `document`. Is-`source`
tal-midja tagħhom tkun jew `{"type":"url","url":"https://..."}` jew
`{"type":"base64","data":"...","media_type":"..."}`.

Jina v5 Omni (`jina-ai/jina-embeddings-v5-omni-small`, `jina-ai/jina-embeddings-v5-omni-nano`,
u l-alias tal-familja `jina-ai/jina-embeddings-v5-omni` → omni-small) jaċċetta wkoll id-dokumenti nattivi
EmbeddingsV5Request ta’ Jina u **jgħaddihom bla tibdil** lil `https://api.jina.ai/v1/embeddings`:

```json
{
  "model": "jina-ai/jina-embeddings-v5-omni-small",
  "task": "retrieval.query",
  "normalized": true,
  "input": [
    { "text": "a red bicycle" },
    { "image": "https://example.com/bike.png" },
    { "content": [{ "text": "caption" }, { "image": "data:image/png;base64,..." }] }
  ]
}
```

Il-valuri nattivi `{ image | audio | video | pdf }` jistgħu jkunu URL HTTPS pubbliku, URI `data:`, jew
base64 mhux ipproċessat. OmniRoute ma jikkonvertix dawk l-oġġetti għal strings u lanqas ma jġib l-URLs nattivi tal-immaġnijiet — Jina
jġib il-midja pubblika waħdu. Il-kampijiet addizzjonali ta’ Jina (`task`, `normalized`, `truncate`, `embedding_type`) jiġu
mgħoddija. L-SKUs ta’ Jina li jaċċettaw biss test xorta jirrifjutaw dokumenti li mhumiex test.

Limiti tas-sigurtà u tat-trasport:

- L-URLs remoti tal-midja jridu jkunu HTTPS pubbliċi. L-elementi kanoniċi `{type,source:url}` jinġiebu
  min-naħa tas-server (b’validazzjoni mill-ġdid tar-ridirezzjonijiet, timeout, limiti tad-daqs, DNS pubbliku u
  ffissar tal-konnessjoni) u jiġu inklużi inline qabel is-sejħa lill-fornitur. L-elementi nattivi ta’ Jina `{image:"https://..."}`
  jiġu mgħoddija kif inhuma wara l-istess verifika tal-HTTPS pubbliku; Jina jġib il-URL.
- Il-midja base64 inline hija limitata għal 8 MiB dekodifikati għal kull element u 16 MiB dekodifikati fit-talba kollha.

Trasformazzjoni skont il-fornitur (l-elementi kanoniċi qatt ma jiġu mgħoddija mingħajr tibdil):

- Mudelli multimodali ta’ Jina: kull element tal-ogħla livell isir oġġett wieħed b’ċavetta skont il-modalità
  (`text` / `image` / `audio` / `video` / `pdf`) bl-użu ta’ URIs tad-data għal midja inline; vettur wieħed għal kull
  element tal-ogħla livell.
- Il-familja Gemini Embedding 2: array wieħed tal-ogħla livell isir talba nattiva waħda
  `models/{model}:embedContent` b’`content.parts` (`text` jew `inline_data`).
- llama.cpp (`llama-cpp/<model>`, kwalunkwe mudell li tella’ s-server lokali): l-elementi kanoniċi `text`
  jsiru strings sempliċi, filwaqt li `image` / `audio` / `video` isiru oġġett wieħed
  `{"content": [part]}` kull wieħed, bl-użu tal-partijiet tal-kontenut taċ-chat ta’ llama-server (`image_url`,
  `input_audio` bil-format `wav` / `mp3` / `flac`, `input_video`) b’data inline; vettur wieħed
  għal kull element tal-ogħla livell. Is-server irid jitħaddem b’`--embedding --mmproj …`; mingħajr projector
  jirrifjuta l-midja huwa stess. `document` mhuwiex appoġġat.
- Mudelli mhux magħrufa/dinamiċi mingħajr metadata espliċita tal-modalità jirrifjutaw input strutturat b’HTTP 400.

```json
{
  "model": "jina-ai/jina-embeddings-v5-omni-small",
  "input": [
    { "type": "text", "text": "A red bicycle" },
    {
      "type": "image",
      "source": { "type": "url", "url": "https://example.com/bicycle.png" }
    }
  ],
  "dimensions": 512,
  "encoding_format": "float"
}
```

Kombinazzjonijiet ta’ mudell/modalità mhux appoġġati jirritornaw HTTP 400 minflok ma jikkonvertu l-element. Il-kampijiet ta’
estensjoni li mhumiex input f’talbiet storiċi bi strings/tokens jibqgħu jiġu mgħoddija mingħajr tibdil.

```bash
# Elenka l-mudelli kollha tal-embedding
GET /v1/embeddings
```


Il-fornituri disponibbli jinkludu OpenAI (GPT Image 2), xAI (Grok Image), Together AI (FLUX), Fireworks AI, Nebius (FLUX), Hyperbolic, NanoBanana, **OpenRouter**, **ZenMux**, SD WebUI (lokali), ComfyUI (lokali).

`n` jirritorna `n` immaġnijiet f’`data[]`. Il-fornituri li l-API upstream tagħhom tirritorna immaġni waħda għal kull sejħa

tal-formati ta’ fan-out tinsab f’`SINGLE_IMAGE_FANOUT_FORMATS` ġewwa
`open-sse/handlers/imageGeneration/fanOut.ts`.

ZenMux jerġa’ juża l-konnessjoni eżistenti taċ-ċavetta API u jaċċetta l-prefissi `zenmux/` jew `zm/`:

Din l-integrazzjoni tappoġġja l-ġenerazzjoni minn test għal immaġni, mhux l-editjar ta’ immaġni ta’ referenza. L-output ta’ Vertex

jiġi normalizzat għall-istess struttura `pages`/`markdown` użata minn Mistral qabel ma jiġi rritornat lil min għamel
is-sejħa, għalhekk il-kodiċi tal-klijent ma għandux għalfejn jittratta lill-fornitur bħala każ speċjali.

### Awtentikazzjoni u riżoluzzjoni tal-endpoint tal-OCR DeepSeek ta’ Vertex AI

`vertex-deepseek-ocr` jerġa’ juża l-istess awtentikazzjoni ta’ Vertex AI li OmniRoute diġà jappoġġja għat-traffiku

(`resolveVertexOcrAccessToken`, `resolveVertexOcrBaseUrl`), u jintużaw minn
`src/app/api/v1/ocr/route.ts` qabel id-dispaċċ lejn `handleOcr`.

Entrata tinkludi oġġett `pricing` meta OmniRoute jkun jaf il-prezz tal-mudell. Il-prezz jiġi
mit-tabella tal-prezzijiet li tuża l-kontabbiltà tal-ispejjeż: valuri prestabbiliti integrati, prezzijiet sinkronizzati u
sostituzzjonijiet stabbiliti permezz ta' `/api/pricing`. Dawn huma prezzijiet tal-lista, għalhekk il-fornituri b'abbonament ukoll
juru prezz għal kull token.

```json
"pricing": {
  "prompt": "0.000005",
  "completion": "0.000025",
  "input_cache_read": "0.0000005",
  "input_cache_write": "0.00000625",
  "input": 5,
  "output": 25,
  "cached": 0.5,
  "cache_creation": 6.25
}
```

| Oqsma                                                           | Unità                                  | Noti                                                                                                                                                                    |
| --------------------------------------------------------------- | -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`, `completion`, `input_cache_read`, `input_cache_write` | USD għal kull token, sekwenza deċimali | Kompatibbli ma' OpenRouter, qatt f'notazzjoni esponenzjali. Iż-żewġ oqsma tal-cache jidhru biss meta jkun hemm prezz tal-cache.                                         |
| `input`, `output`, `cached`, `cache_creation`                   | USD għal kull miljun token, numru      | Oqsma minn verżjonijiet preċedenti tal-katalgu, miżmuma għall-klijenti eżistenti. `reasoning` u `long_context` jidhru wkoll meta r-ringiela tal-prezzijiet tinkludihom. |

- **Il-kombinazzjonijiet** jinkludu l-prezz tal-ewwel mira viżibbli tagħhom. Il-kombinazzjonijiet integrati `auto/*` jagħżlu
  mira fil-ħin tat-talba, għalhekk ma għandhomx `pricing`.
- **Mudelli bla ħlas** juru `"0"` (u `0`) meta l-prezz tagħhom ikun żero. Mudell mingħajr ringiela tal-prezzijiet
  juri wkoll `"0"` meta l-katalgu jimmarkah bħala bla ħlas (`free: true`) jew meta jkun elenkat fil-katalgu integrat
  tal-mudelli bla ħlas.
- **Prezz mhux magħruf:** l-entrata ma għandhiex ċavetta `pricing`.
- **Fornituri mkejla bil-krediti** (bħal Kiro) jitolbu ħlas għal kull talba minflok għal kull token. L-entrati
  tagħhom iżommu l-oqsma numeriċi għal kull miljun li kellhom qabel u ma jinkludux oqsma ta' sekwenza għal kull token.
- **Varjanti** (IDs tal-livell ta' sforz tar-raġunament, aliases mingħajr ħsieb, mirja tal-iskoperta u tal-gateway)
  jikkopjaw il-prezz tal-mudell li lejh jidderieġu.
- L-oqsma jinkludu r-rati bażi biss. Il-livelli ta' kuntest twil (il-qasam numeriku `long_context`) u
  l-multiplikaturi tal-livell tas-servizz (pereżempju Codex fast jew flex) ma jbiddlux `prompt` jew
  `completion`.
- L-oġġett huwa l-istess għal kull stil ta' awtentikazzjoni, inkluża talba bl-istil ta' Anthropic
  b'`x-api-key` u `anthropic-version` (ir-rispons jibqa' `{ "object": "list",
"data": [...] }`). Implimentazzjoni: `src/app/api/v1/models/catalogPricing.ts`.

### Prefissi tal-ID tal-mudell (`?prefix=`)

Il-biċċa l-kbira tal-mudelli jintwerew taħt **prefiss tal-fornitur**. Il-prefiss li tikseb huwa kkontrollat
mill-bandiera tal-karatteristika `MODELS_CATALOG_PREFIX_MODE`, u jista' jiġi sostitwit **għal kull talba** permezz ta'
parametru tal-query — utli għal klijent li jrid lista nadifa mingħajr ma jibdel l-issettjar tas-server kollu
għal kulħadd:

```bash
GET /v1/models?prefix=alias        # ID wieħed għal kull mudell — il-prefiss qasir tal-alias
GET /v1/models?prefix=dual         # iż-żewġ forom (il-valur prestabbilit tas-server)
GET /v1/models?prefix=canonical    # il-prefiss sħiħ tal-ID tal-fornitur biss
```

| Modalità    | Joħroġ                                                  | Noti                                                                                                                                                                                                                        |
| ----------- | ------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `dual`      | `cc/claude-sonnet-4-6` **u** `claude/claude-sonnet-4-6` | **Valur prestabbilit.** Iż-żewġ IDs jidderieġu lejn l-istess mudell; jinżammu sabiex il-konfigurazzjonijiet tal-klijenti li kkodifikaw waħda mill-forom b'mod fiss jibqgħu jaħdmu. Bejn wieħed u ieħor jirdoppja l-katalgu. |
| `alias`     | `cc/claude-sonnet-4-6`                                  | Entrata waħda għal kull mudell. Il-fornituri mingħajr alias distint xorta joħorġu l-entrata tagħhom, għalhekk ma jintilef xejn.                                                                                             |
| `canonical` | `claude/claude-sonnet-4-6`                              | Entrata waħda għal kull mudell taħt il-prefiss sħiħ tal-ID tal-fornitur. Il-fornituri mingħajr alias distint (eż. `antigravity/…`, `agy/…`) joħorġu wkoll l-ID uniku tagħhom hawnhekk, għalhekk ma jintilef xejn.           |

Mera fil-modalità `dual` tista' tingħaraf ukoll mingħajr il-parametru tal-query: tinkludi qasam `parent`
li jindika l-ID primarju.

Il-klijenti li juru selettur tal-mudelli għandhom jitolbu `?prefix=alias` — dan huwa dak li tagħmel
[l-estensjoni OmniCopilot għal VS Code](../guides/VSCODE-COPILOT.md).

### Filtri tal-iskoperta (`?capability=`, `?min_context=`, `?kind=`, `?q=`)

`GET /v1/models` jaċċetta filtri fakultattivi tal-iskoperta. Mingħajr ebda wieħed minnhom, ir-rispons
ma jinbidilx. Dawn jirrestrinġu l-katalgu li min jagħmel it-talba diġà jista' jara (il-permessi taċ-ċavetta tal-API japplikaw l-ewwel),
u jitħaddmu qabel il-paġinazzjoni bl-istil ta' OpenAI permezz ta' `limit` / `after`:

```bash
GET /v1/models?capability=vision&capability=tool_calling   # kull kapaċità elenkata trid tkun vera
GET /v1/models?capability=vision,reasoning&min_context=200000
GET /v1/models?kind=embedding                              # `type` tal-katalgu; ringieli mingħajru huma `chat`
GET /v1/models?q=sonnet&limit=10                           # taqbila li ma tiddistingwix bejn ittri kbar u żgħar fuq l-ID jew l-isem
```

| Parametru     | Valuri                                                                                              |
| ------------- | --------------------------------------------------------------------------------------------------- |
| `capability`  | `attachment`, `reasoning`, `structured_output`, `temperature`, `thinking`, `tool_calling`, `vision` |
| `min_context` | numru sħiħ mhux negattiv, imqabbel ma’ `context_length`                                             |
| `kind`        | `chat`, `audio`, `embedding`, `image`, `moderation`, `music`, `rerank`, `video`                     |
| `q`           | 1–200 karattru                                                                                      |

Valur mhux magħruf, jew `min_context` li mhuwiex numru sħiħ mhux negattiv (pereżempju `1.5`),
jirritorna HTTP `400` u l-messaġġ jelenka l-valuri validi. Implimentazzjoni:
`src/app/api/v1/models/catalogFilters.ts`.

### Lista qasira ta’ mudelli (`POST /v1/models/query`)

`POST /v1/models/query` jirritorna lista qasira u deterministika mill-istess katalgu, bl-istess
awtentikazzjoni u viżibbiltà għal kull ċavetta bħal `GET /v1/models`:

```bash
POST /v1/models/query
Authorization: Bearer your-api-key
Content-Type: application/json

{ "capabilities": ["vision", "tool_calling"], "min_context": 128000, "max_output": 16000,
  "kind": "chat", "q": "gpt", "owned_by": "openai", "exclude": ["openai/gpt-4o"], "limit": 5 }

→ { "object": "list", "data": [ ...models ] }
```

Kull kamp huwa fakultattiv. `capabilities` u `exclude` jaċċettaw array jew string separata b’virgoli;
`max_output` jitqabbel ma’ `max_output_tokens`. Ir-riżultati jiġu magħżula skont `owned_by`, imbagħad `id`.
`limit` għandu valur predefinit ta’ `20` u valuri ogħla minn `100` jiġu limitati għal `100`. JSON invalidu, kamp
mhux magħruf jew valur invalidu jirritorna HTTP `400`.

### Mudelli taċ-chat moħbija individwalment

Mudell immarkat bħala **Moħbi** fil-paġna tal-fornitur tiegħu jiġi eskluż mill-katalgu u miċħud
b’HTTP `404` / `model_not_found` meta jintalab espliċitament. Il-verifika tuża l-fornitur u l-mudell
riżolti, inklużi l-aliases tal-fornituri, il-prefissi tan-nodi ta’ fornituri kompatibbli, u l-valuri
predefiniti tal-konnessjoni. Combo taqbeż miri moħbija u tista’ tuża mudell ieħor viżibbli; meta ma
jibqa’ ebda mira eżegwibbli, tirritorna l-istess kodiċi ta’ żball. It-tneħħija tal-istat moħbi tidħol
fis-seħħ mat-talba li jmiss. Is-sostituzzjonijiet tal-viżibbiltà għall-immaġnijiet biss ma jaħbux
il-mudell taċ-chat bl-istess ID.

Dan l-issettjar ta’ mudell individwali huwa separat mil-
[listi ta’ permessi/projbizzjonijiet għall-esponiment tal-mudelli](../routing/MODEL_EXPOSURE_LIST.md), li jiffiltraw ir-reklamar fil-katalgu
u l-kandidati għar-routing awtomatiku filwaqt li jżommu d-dispaċċ espliċitu. Il-permessi tal-mudelli
għaċ-ċwievet tal-API jibqgħu japplikaw b’mod indipendenti. Il-modalità predefinita tal-prefiss
tal-katalgu tibqa’ `dual`.

### Varjanti ta’ mudelli mingħajr ħsieb

Għall-mudelli Claude li kapaċi jaħsbu, `/v1/models` jirreklama wkoll varjant **mingħajr ħsieb** li l-id tiegħu għandu l-prefiss `claude-3-omniroute-no-thinking/`:

```
claude-3-omniroute-no-thinking/<provider>/<model>
```

L-għażla ta’ dan l-id (eż. f’konfigurazzjoni ta’ Claude Code li dejjem tehmeż blokka `thinking`) tiġi riżolta lura għall-`<provider>/<model>` reali bir-raġunament imrażżan — `thinking:{type:"disabled"}` fil-perkors `/v1/messages`, jew bil-kampi `reasoning`/`reasoning_effort` imneħħija fil-perkors `/v1/chat/completions`. Il-varjant jiġi elenkat biss għal mudelli tal-familja Claude li jappoġġjaw il-ħsieb **u** jirrispettaw `disabled` (għalhekk, pereżempju, mudelli adattivi biss li jirrifjutaw `disabled` jiġu esklużi). L-operaturi jistgħu jisfurzaw il-varjant biex ikun attivat jew diżattivat għal kull mudell permezz ta’ `ModelSpec.noThinkingAlias`.

## Ġenerazzjoni tal-awdjo b’ElevenLabs

Ikkonfigura konnessjoni tal-fornitur `elevenlabs` f’OmniRoute biċ-ċavetta API tiegħek ta’ ElevenLabs.
Il-klijenti jawtentikaw biċ-ċavetta **OmniRoute** tagħhom (`Authorization: Bearer $OMNIROUTE_API_KEY`);
il-gateway jipprovdi ċ-ċavetta maħżuna tal-fornitur bħala `xi-api-key`. Qatt tibgħat ċavetta ta’
ElevenLabs bħala t-token bearer tal-gateway.

| Metodu | Mogħdija                    | Rispons                                         | Kategorija tal-endpoint taċ-ċavetta API |
| ------ | --------------------------- | ----------------------------------------------- | --------------------------------------- |
| POST   | `/v1/sound-generation`      | Bytes tal-awdjo nattivi                         | `elevenlabs`                            |
| POST   | `/v1/music`                 | Bytes tal-awdjo nattivi                         | `music`                                 |
| POST   | `/v1/music/stream`          | Bytes tal-awdjo bi streaming                    | `music`                                 |
| POST   | `/v1/music/detailed`        | Awdjo multipart nattiv u pjan ta’ kompożizzjoni | `music`                                 |
| POST   | `/v1/music/detailed/stream` | Metadata SSE nattiva u blokok tal-awdjo         | `music`                                 |
| POST   | `/v1/music/plan`            | Pjan ta’ kompożizzjoni JSON                     | `music`                                 |

Dawn l-endpoints jikkomplementaw ir-rotot eżistenti `/v1/audio/speech`, `/v1/audio/transcriptions`,
`/v1/voices`, `/v1/text-to-speech/{voiceId}` u `/v1/speech-to-text`. Il-fields JSON nattivi
u l-parametri tal-query bħal `output_format` u `enable_logging` jinżammu.
Ir-risponsi minn `/v1/music/detailed` iżommu l-konfini multipart tagħhom; ipproċessahom bħala multipart.
`/v1/music/detailed/stream` jirritorna `text/event-stream` b’metadata tal-kompożizzjoni u
blokok tal-awdjo base64 f’avvenimenti SSE. Is-sitt rotot kollha jappoġġjaw il-preflight ta’ CORS.

```bash
export OMNIROUTE_BASE_URL="http://localhost:20128"
export OMNIROUTE_API_KEY="your-omniroute-api-key"

# Effett qasir tal-ħoss. Tul: minn 0.5 sa 30 sekonda.
curl --fail-with-body "$OMNIROUTE_BASE_URL/v1/sound-generation?output_format=mp3_44100_128" \
  -H "Authorization: Bearer $OMNIROUTE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"text":"A single soft bell chime","duration_seconds":1,"model_id":"eleven_text_to_sound_v2"}' \
  --output effect.mp3

# It-tul tal-mużika huwa espress f’millisekondi: minn 3000 sa 600000.
curl --fail-with-body "$OMNIROUTE_BASE_URL/v1/music?output_format=mp3_44100_128" \
  -H "Authorization: Bearer $OMNIROUTE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt":"Gentle instrumental piano","music_length_ms":10000,"force_instrumental":true,"model_id":"music_v1"}' \
  --output music.mp3
```

Uża `/v1/music/stream` bl-istess body JSON biex twassal l-awdjo b’mod inkrementali. Il-kompożizzjoni
taċċetta eżattament wieħed minn `prompt` jew `composition_plan`; `/v1/music/plan` jeħtieġ `prompt`
u b’mod fakultattiv jaċċetta `source_composition_plan`. L-iskemi nattivi jżommu fields addizzjonali
tal-fornitur sabiex il-verżjonijiet tal-pjan ta’ kompożizzjoni u l-għażliet ta’ rfinar jaslu għand ElevenLabs.

L-endpoint unifikat `/v1/music/generations` jaċċetta wkoll `elevenlabs/music_v1`,
`elevenlabs/music_v2` u `elevenlabs/music_v2_5`. B’konnessjoni ElevenLabs attiva,
dawn il-mudelli jiġu esposti mill-katalgu tal-mużika. Dan l-endpoint jirritorna
`{"created":...,"data":[{"b64_json":"...","format":"mp3"}]}`. Il-field `duration` tiegħu huwa
f’sekondi u jiġi mmappjat għal `music_length_ms`; valur espliċitu ta’ `music_length_ms` jieħu preċedenza.
`instrumental` jiġi mmappjat għal `force_instrumental`, bil-field nattiv jieħu preċedenza.
Uża l-endpoints nattivi tal-istreaming għall-istreaming u l-endpoint nattiv tal-kompożizzjoni
għal talbiet ibbażati biss fuq pjan ta’ kompożizzjoni.

```bash
curl --fail-with-body "$OMNIROUTE_BASE_URL/v1/music/generations" \
  -H "Authorization: Bearer $OMNIROUTE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"elevenlabs/music_v1","prompt":"Gentle instrumental piano","duration":10,"instrumental":true}'
```

Ir-restrizzjonijiet tal-endpoint, tal-mudell, tal-baġit u tal-konnessjoni japplikaw qabel sejħa upstream.
Ir-rotot nattivi jirritornaw il-kodiċijiet tal-istatus u l-bodies tal-iżbalji upstream mingħajr tibdil,
inkluż `402` għal restrizzjoni tal-pjan u `429` għal limitu tal-kwota. L-headers `character-cost`,
`song-id`, `request-id` u `retry-after` jinżammu meta jkunu preżenti. Bilanċ ta’ kreditu bla ħlas
ma jiggarantixxix aċċess għal kull mudell tal-mużika, format tal-output jew funzjonalità tal-API:
ElevenLabs jiddeċiedi l-intitolament għal kull talba. L-endpoint unifikat iżomm il-kodiċijiet tal-istatus
tal-iżbalji fl-envelope normalizzat tal-iżbalji ta’ OmniRoute.

Kuntratti upstream: [effetti tal-ħoss](https://elevenlabs.io/docs/api-reference/text-to-sound-effects/convert),
[kompożizzjoni tal-mużika](https://elevenlabs.io/docs/api-reference/music/compose) u
[dettalji tal-mużika bi streaming](https://elevenlabs.io/docs/api-reference/music/compose-detailed-stream).


> **Nodi tal-fornitur għar-reranking:** `POST /v1/rerank` jidderieġi wkoll lejn nodi ta’ fornituri kompatibbli ma’ OpenAI
> (oMLX, vLLM, Infinity, TEI wara gateway, …) indirizzati bħala `<node-prefix>/<model>`. In-nodi
> loopback (`localhost`, `127.0.0.1`, `172.16.0.0/12`) huma dejjem eliġibbli, kif ukoll l-ismijiet tal-hosts li
> l-operatur jelenka f’`OMNIROUTE_LOCAL_PROVIDER_NODE_HOSTS` (eż. isem ta’ servizz Docker/Compose bħal
> `http://reranker:8080/v1`; dawn jiġu kkuntattjati direttament, u qatt permezz ta’ `HTTP(S)_PROXY` jew
> proxy fiss tal-konnessjoni). Nodi fuq kwalunkwe
> host ieħor — magna fuq LAN jew peer ta’ Tailscale — ikunu eliġibbli biss meta l-operatur jattiva l-flag tal-karatteristika
> `RERANK_REMOTE_PROVIDER_NODES` **u** l-URL bażi tan-nodu jgħaddi mill-politika tal-URLs ħerġin tal-fornitur
> (`OMNIROUTE_ALLOW_LOCAL_PROVIDER_URLS` / `OMNIROUTE_ALLOW_PRIVATE_PROVIDER_URLS`).
> Il-pass tar-reranking tal-magna tal-memorja jsejjaħ din ir-rotta permezz tal-
> loopback, għalhekk l-istess regola tirregola `rerankProviderModel` fis-settings tal-Memorja.
>
> **Forom tas-server lokali:** in-nodu jissejjaħ f’`<base>/v1/rerank` u, jekk jingħata 404, f’`<base>/rerank`
> (Infinity, TEI). Il-body upstream iġorr kemm l-ortografija ta’ Cohere/OpenAI (`documents`,
> `return_documents`) kif ukoll dik ta’ TEI (`texts`, `return_text`), u r-rispons upstream jiġi
> normalizzat għall-envelope ta’ Cohere: l-array vojt ta’ TEI `[{index, score, text}]`, `{results: [{index, score}]}`
> minn gateways ħfief, u `{data: [...]}` fl-istil ta’ Voyage kollha jintbagħtu lura lill-klijent bħala
> `{results: [{index, relevance_score, document?}]}`, magħżula skont il-punteġġ u limitati għal `top_n`.

> **Skoperta tan-nodi tal-fornitur:** il-mudelli fuq nodu ta’ fornitur kompatibbli ma’ OpenAI jidhru f’`GET /v1/models`
> taħt il-prefiss tan-nodu. Ir-ringieli li ma jkollhomx metadata tal-endpoint (kif tipikament jiġri fil-listi lokali ta’ `/v1/models`)
> jirtu l-`apiType` tan-nodu, għalhekk il-mudelli ta’ nodu `embeddings` ikunu `type: "embedding"` u dawk ta’
> nodu `rerank` ikunu `type: "rerank"` minflok ma jieħdu chat bħala l-valur awtomatiku; valur espliċitu ta’
> `supportedEndpoints` fuq ringiela sinkronizzata jew miżjuda manwalment xorta jieħu preċedenza.

### Exa u Tavily `provider_options`

Exa u Tavily jaqraw oqsma speċifiċi għall-fornitur minn borża spazjata bl-isem: `provider_options.exa` (jew `provider_options["exa-search"]`) u `provider_options.tavily` (jew `provider_options["tavily-search"]`). Iċ-ċwievet ta' hawn taħt biss jintbagħtu. Kull wieħed huwa ċċekkjat mal-iskema Zod tiegħu stess `open-sse/handlers/search/providerOptionsPassthrough.ts`, u ċavetta bit-tip ħażin tinżel. Kwalunkwe ċavetta oħra tiġi injorata, inklużi auth, base URL, `stream` u `outputSchema`. Iċ-ċwievet ċatti użati minn fornituri oħra (`cx`, `depth`, ...) jaħdmu bħal qabel.

| Fornitur | Oqsma tal-ogħla livell                                                                                                                                                                                                                                                                                                                                                    | Nedjati                                                                                                                               |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| Exa      | `type`, `category`, `userLocation`, `moderation`, `additionalQueries`, `objective`, `systemPrompt`, `compliance` (flat primitives), `startPublishedDate`, `endPublishedDate`                                                                                                                                                                                              | `contents.{text, highlights, summary, extras, livecrawlTimeout, maxAgeHours}` magħquda fuq `{ text: true, highlights: true }` default |
| Tavily   | `search_depth`, `chunks_per_source`, `time_range`, `start_date`, `end_date`, `include_published_date`, `filter_by_published_date`, `include_answer`, `include_raw_content`, `include_images`, `include_image_descriptions`, `include_favicon`, `include_domains_mode`, `language`, `filter_by_language`, `auto_parameters`, `exact_match`, `include_usage`, `safe_search` | —                                                                                                                                     |

L-oqsma ġeneriċi dejjem jirbħu: `query`, `max_results`, `filters` (dominji), `country` u s-suġġett derivat minn `search_type`. Fuq Exa, `search_type: "news"` iżomm `category: "news"`. Tavily jaċċetta wkoll `search_type: "finance"` (`topic: "finance"`).

L-ispiża tat-tfittxija Firecrawl hija rreġistrata għal kull blokka mibdija ta’ 10 riżultati rritornati, għal $0.002 (2 krediti) blokka u mill-inqas blokka waħda għal kull sejħa ( [Billing Firecrawl](https://docs.firecrawl.dev/billing) ): 11-il riżultat jiswew $0.004.

Iż- `time_range` ġeneriku issa jilħaq iż-żewġ fornituri: Exa gets `startPublishedDate` (ISO timestamp ) u Tavily gets `start_date` (`YYYY-MM-DD`). Data espliċita `provider_options` tipprevali dik mappata.

Ir-riżultati Exa jżommu `id`, `highlight_scores`, `summary`, `subpages`, `entities` u `extras` `provider_raw`. Ir-riżultati tavily iżommu `images` u `favicon`.

L-ispiża tat-tfittxija tal-linkup hija rreġistrata għal $0.005 għal `depth` `fast` u `standard` u $0.05 għal `deep` ( [prezzijiet tal-Linkup](https://docs.linkup.so/pages/documentation/development/pricing) ), kemm jekk `depth` ġej minn `provider_options` jew mis-settings tal-konnessjoni.

Exa `type: "lite"` (Exa 3.0) jaċċetta sett iżgħar ta' oqsma u jirrifjuta t-talba kollha meta jkun issettjat kwalunkwe qasam ieħor. Għal lite, `additionalQueries`, `systemPrompt` u kull ċavetta `contents` ħlief `text` u `highlights` jintefgħu qabel is-sejħa. `subpages`, `subpageTarget`, `highlights.numSentences` u `highlights.highlightsPerUrl` deprecati m'għadhomx jintbagħtu.

Il-kontabilità tal-ispejjeż hija r-reġistru ċatt `costPerQuery`, ħlief għal Exa, li jsegwi l-ipprezzar ta 'Exa stess: $0.007 għal kull sejħa għal `auto` (u l-legacy `fast`) jew $0.004 għal `lite` (u l-legacy `instant`), li jkopri 10 riżultati; $0.001 għal kull riżultat ieħor; u $0.001 għal kull riżultat ritornat meta `contents.summary` huwa stabbilit. Tavily huwa rreġistrat f'kreditu 1 ($0.008) għal `search_depth` `basic`, `fast` u `ultra-fast`, u 2 krediti ($0.016) għal `advanced` ( [krediti Tavily API](https://docs.tavily.com/documentation/api-credits) ). Sejħa `auto_parameters: true` li Tavily jaġġorna għal avvanzat għadha rreġistrata bi kreditu 1.

Estratta kontenut minn URL permezz ta’ fornitur web-fetch ikkonfigurat (Firecrawl, Jina

Parallel Extract (`parallel-search`, l-istess API key bħal Parallel Search) jirritorna Markdown
biss — kwalunkwe `format` ieħor jagħti `400` — u jillimita l-kontenut għal 100,000 karattru. Meta
l-paġna fil-mira nnifisha ma tkunx tista’ tiġi estratta, is-servizz upstream jirrapportaha fi HTTP 200;
OmniRoute jesponi dan bħala `422` b’messaġġ fiss.

**Fallback konxju tal-kwota (#8297):** meta ma jingħata l-ebda `provider` espliċitu, il-pool
(`firecrawl` → `jina-reader` → `tavily-search` → `tinyfish` → `nimble-search` →
`parallel-search`) jiġi
eżaminat f’ordni ta’ prijorità
fissa (fill-first) — fornitur ikkonfigurat iżda limitat fir-rata jinqabeż
minflok ma jwaqqaf it-talba immedjatament, u falliment upstream li jista’ jerġa’ jiġi ppruvat/tal-kwota

mhux għal Jina Reader, u qatt għal talba ħażina sempliċi 400) jgħaddi
għall-fornitur li jmiss b’kredenzjali li jkun għadu ma ġiex ippruvat fil-ħin tat-talba. Meta kull fornitur fil-
pool ikun eżawrit, l-endpoint jirritorna `429` wieħed (b’header `Retry-After`)
minflok il-`400` ġeneriku preċedenti. Meta jintalab `provider`
espliċitu, **ma jkun hemm l-ebda** fallback silenzjuż — fornitur espliċitu limitat fir-rata jew li qed ifalli
jesponi l-iżball tiegħu stess (`429` jekk ikun limitat fir-rata, inkella l-istatus
upstream).

Jivvalida handshake ta’ upgrade għal WebSocket u jirritorna l-messaġġi ta’ eżempju tal-protokoll fuq il-wire (`request`, `cancel`). Il-frames WS reali jiġu ġestiti mis-server WS inkluż barra mit-tabella tar-routes ta’ Next.js.

### Responses API fuq WebSocket (codex biss)

```bash
# L-istess host:port bħall-API HTTP (default 20128); aġġorna l-konnessjoni:
wscat -c "ws://localhost:20128/v1/responses?api_key=<OMNIROUTE_API_KEY>"
# (jew: -H "Authorization: Bearer <OMNIROUTE_API_KEY>")

# L-ewwel frame GĦANDU jkun response.create:
{ "type": "response.create", "model": "gpt-5.5", "input": [ { "role": "user", "content": "hi" } ] }
```

Proxy ta’ Responses-API-over-WebSocket huwa mqabbad **esklussivament ma’ `codex`** (il-backend ta’
ChatGPT). Huwa jisma’ fuq l-istess port tal-API/dashboard fil-mogħdijiet `/v1/responses`,
`/responses`, u `/api/v1/responses`. Mal-ewwel frame `response.create`, huwa
jawtentika + jipprepara permezz tal-bridge intern `codex-responses-ws`, jagħżel
konnessjoni OAuth ta’ codex, u joħloq tunnel lejn `wss://chatgpt.com/backend-api/codex/responses`
permezz tat-trasport `wreq-js`. **Mudelli mhux codex jiġu rrifjutati** (`codex_ws_provider_required`).
Għar-routing b’kondiviżjoni tal-kwota uża `model: "qtSd/<group>/codex/<model>"`. Implimentat fi
`app/server-ws.mjs` + `scripts/dev/responses-ws-proxy.mjs` + `src/app/api/internal/codex-responses-ws/route.ts`.

**Awtentikazzjoni:** Bearer API key waqt il-handshake. Is-server HTTP inkluż (`server-ws.mjs`)
irid ikun l-entrypoint attiv (u jkun hekk, b’mod default, meta `app/server-ws.mjs` ikun jeżisti).

#### ID tal-mudell: uża l-ID bażiku ta’ ChatGPT (mingħajr il-prefiss `codex/`)

L-OpenAI **Codex CLI** jivvalida l-isem tal-mudell fuq in-naħa tal-klijent meta
`supports_websockets = true` u **jirrifjuta IDs bi prefiss tal-fornitur** bħal
`codex/gpt-5.5` (`The 'codex/gpt-5.5' model is not supported when using Codex with
a ChatGPT account`). Ibgħat l-ID **bażiku** (eż. `gpt-5.5`). Il-bridge ta’ OmniRoute huwa
għal codex biss, għalhekk jerġa’ jirriżolvi ID bażiku bħala mudell codex
(`resolveCodexWsModelInfo`) qabel ma joħloq tunnel upstream — minkejja li
`gpt-5.5` bażiku kieku jiġi rrotta lejn fornitur ieħor permezz ta’ HTTP.

#### Konfigurazzjoni tal-OpenAI Codex CLI

Orjenta l-Codex CLI lejn OmniRoute billi żżid fornitur personalizzat b’appoġġ għal WebSocket
ma’ `~/.codex/config.toml` (uża `CODEX_HOME` separat biex tevita li tibdel
konfigurazzjoni eżistenti):

```toml
model = "gpt-5.5"                 # ID bażiku — MHUX "codex/gpt-5.5"
model_provider = "omniroute"

[model_providers.omniroute]
name = "OmniRoute (WS)"
base_url = "http://localhost:20128/v1"   # mingħajr slash finali; il-URL WS jiġi dderivat (uża https/wss fil-produzzjoni)
wire_api = "responses"                    # l-uniku valur appoġġat minn Frar 2026
supports_websockets = true                # jattiva t-trasport Responses-over-WS
env_key = "OMNIROUTE_API_KEY"             # iżomm l-API key ta’ OmniRoute (Bearer)
```

```bash
export OMNIROUTE_API_KEY=sk-...           # API key ta’ OmniRoute (kwalunkwe key jekk REQUIRE_API_KEY=false)
codex exec "Responda apenas: PONG"
```

Il-CLI jaġġorna `base_url + /responses` għal WebSocket u OmniRoute joħloq tunnel għalih
lejn il-konnessjoni OAuth ta’ codex magħżula. Ivvalidat minn tarf sa tarf mas-server
lokali: ChatGPT jirritorna `codex.rate_limits` + `response.created` u jibgħat il-
kompletament bħala stream.

## Użu b'awtoservizz (`/api/usage/om-usage`)

Kwalunkwe ċavetta API tista' taqra l-użu u l-kwoti **tagħha stess** — mingħajr awtentikazzjoni tal-ġestjoni. Dan huwa l-endpoint li
klijent (CLI, il-pannell OmniCopilot) juża biex juri lid-detentur taċ-ċavetta kemm nefaq.

```bash
# Forma testwali (il-kuntratt storiku — test sempliċi għal terminal)
curl -H "Authorization: Bearer <your-api-key>" \
  http://localhost:20128/api/usage/om-usage

# Forma strutturata — dik li tikkonsma UI
curl -H "Authorization: Bearer <your-api-key>" \
  "http://localhost:20128/api/usage/om-usage?format=json"
```

Iċ-ċavetta jrid ikollha **`allowUsageCommand`** attivat (diżattivat b'mod awtomatiku — il-maniġer taċ-ċwievet API
tad-dashboard jaqilbu għal kull ċavetta). Mingħajru, l-endpoint iwieġeb `403`.

`?format=json` jirritorna struttura diskriminata sabiex min isejjaħ qatt ma jaqra qasam tad-data minn
rifjut. F'każ ta' suċċess:

```jsonc
{
  "allowed": true,
  // preżenti biss meta ċ-ċavetta tkun għażlet limiti tal-użu għal kull ċavetta (USD kuljum/kull ġimgħa):
  "personal": {
    "dailySpentUsd": 1.25,
    "dailyLimitUsd": 5,
    "dailyResetAtIso": "…",
    "weeklySpentUsd": 8,
    "weeklyLimitUsd": 20,
    "weeklyResetAtIso": "…" /* … */,
  },
  // l-istampa tal-kwota tal-fornitur magħżul, jew null meta jkun għadu ma ġie kkaċċjat xejn:
  "provider": { "connectionId": "…", "provider": "claude", "plan": "…", "quotas": {/* … */} },
  // l-istampa ta' kull konnessjoni, sabiex UI tkun tista' tirrendi diversi fornituri maġenb xulxin:
  "providers": [
    { "connectionId": "…", "provider": "claude" /* … */ },
    { "provider": "codex" /* … */ },
  ],
}
```

F'każ ta' rifjut (`401` ċavetta ħażina / `403` mhux permess), l-istess rotta tirritorna
`{ "allowed": false, "error": { "message": "…" } }` — `personal`/`provider` preżenti iżda vojt
(iċ-ċavetta hija permessa, iżda għadu ma nkiseb xejn) huwa stat differenti minn rifjut, u l-forma JSON biss
tiddistingwihom.

**Awtentikazzjoni:** iċ-ċavetta API Bearer ta' min isejjaħ stess, ivvalidata b'`isValidApiKey` — din _mhijiex_ is-superfiċje
tal-ġestjoni (`/api/keys/…`), li tibqa' protetta minn `requireManagementAuth`.

| **Kejl**                        | **Allokazzjoni użabbli aġġustata skont il-limitu ta' qtugħ**: il-kapaċità li fadal 'il fuq mil-livell limitu | **Kwota mhux ipproċessata mis-sors**: kejl mhux aġġustat tal-fornitur                         |
| **Skalar tal-limitu ta' qtugħ** | Skalata permezz ta' `effectiveRemainingPercent()` sabiex ir-riżerva protetta tidher bħala `0% left`          | L-ebda wieħed (valuri mhux ipproċessati tal-istampa kif irrappurtati mill-fornitur)           |
| **Data tal-limitu**             | Inkorporata fil-perċentwal muri                                                                              | Maħżuna f'`quotaWindowThresholds` għal kull konnessjoni (jew il-valuri awtomatiċi tas-server) |
| **Konsumatur primarju**         | CLIs interattivi, prompts tat-terminal, operaturi umani                                                      | Integrazzjonijiet programmatiċi, dashboards, analitika, sistemi ta' traċċar tal-kontijiet     |

#### Il-Formula tal-Aġġustament tal-Limitu ta' Qtugħ

OmniRoute jappoġġa limiti proattivi ta' qtugħ tal-kwota biex jipprevjeni l-eżawriment tas-sors (ikkonfigurati permezz tal-
`quotaWindowThresholds` tal-konnessjoni, il-valuri awtomatiċi tal-fornitur, jew is-settings globali tar-reżiljenza). Meta limitu ta' qtugħ
(eż., `cutoff = 25%`) ikun attiv fuq tieqa tal-kwota, ir-renderer tat-test jikkalkula l-allokazzjoni li fadal hekk:

- Jekk `remaining <= cutoff`: jirritorna `0%`.
- Jekk `remaining > cutoff`: jirritorna `((remaining - cutoff) / (100 - cutoff)) * 100`.

L-output testwali fformattjat jarrotonda dan għall-eqreb numru sħiħ (`Math.round(...)`).

#### Eżempju Illustrattiv

Ikkunsidra tieqa ta' fornitur b'**60% użu mhux ipproċessat** (għalhekk **40% tal-kwota mhux ipproċessata li fadal**) u
limitu kkonfigurat ta' **25% bħala qtugħ tal-kwota li fadal**:

| Rappreżentazzjoni                          | Kalkolu                                            | Li Fadal |                  Użu Impliċitu                  |
| :----------------------------------------- | :------------------------------------------------- | :------: | :---------------------------------------------: |
| **JSON mhux ipproċessat (`?format=json`)** | Stampa tas-sors (`quotas[window]`)                 | **40%**  |                     **60%**                     |
| **Format testwali (`NN% left`)**           | `((40 - 25) / (100 - 25)) * 100 = (15 / 75) * 100` | **20%**  | **80%** (jekk jiġi kkalkulat `100 - remaining`) |

- **Għaliex it-test juri 20% li fadal:** Mill-40% tal-kwota fiżika li fadal fil-kont, 25% hija rriżervata mill-
  politika tal-qtugħ. Min isejjaħ għandu biss 15% minn 75% tal-marġni użabbli li jifdal qabel ir-router jieqaf
  jidderieġi lejn din il-konnessjoni. L-iskalar jiżgura li l-konnessjoni tindika l-eżawriment (`0% left`) eżatt meta
  jieqaf id-direzzjonar.
- **Għaliex JSON iżomm il-valuri mhux ipproċessati:** Il-payload JSON jirritorna l-istampa eżatta tal-fornitur (`UsageSnapshot`)
  sabiex l-għodod esterni jkollhom aċċess għall-utilizzazzjoni reali tas-sors u għal
  `quotaWindowThresholds` fil-livell tal-konnessjoni mingħajr skalar b'telf min-naħa tas-server.

#### Gwida għall-Migrazzjoni tal-Konsumaturi

Jekk integrazzjoni esterna (bħal plugin ta’ editur jew estensjoni ta’ aġent) preċedentement kienet tiġbor it-test mill-
endpoint (`NN% left`) u tikkalkula l-perċentwal użat bħala `100 - NN`, il-migrazzjoni għal `?format=json` tfisser:

- Il-qari tal-valuri JSON mhux ipproċessati se jirrifletti l-**konsum upstream attwali** (60% użat fl-eżempju ta’ hawn fuq).
- Jekk l-integrazzjoni tkun tixtieq tippreserva s-semantika tal-allowance li jista’ jintuża tal-endpoint tat-test, tista’ tevalwa
  l-formula effettiva tal-bqija min-naħa tal-klijent billi tuża `quotaWindowThresholds` għal sostituzzjonijiet fil-livell tal-konnessjoni.

### Impatt fuq il-latenza

HIT fil-cache semantika jipprovdi r-rispons mill-cache **mingħajr sejħa
upstream**, għalhekk il-`X-OmniRoute-Response-Latency` irrappurtata tkun kważi
żero (irrispettivament mil-latenza upstream oriġinali). Klijenti sensittivi
għal-latenza (benchmarking, monitoraġġ ta’ p50/p99) għandhom jiċċekkjaw
il-header tar-rispons `X-OmniRoute-Cache-Latency`:

| Valur       | Tifsira                                                             |
| ----------- | ------------------------------------------------------------------- |
| `synthetic` | Rispons ipprovdut mill-cache; il-latenza mhijiex ħin upstream reali |
| _(assenti)_ | Rispons minn sejħa upstream reali                                   |

### Qbiż tal-cache għal kull ċavetta

Iċ-ċwievet API jistgħu jagħżlu li ma jużawx il-qari mill-cache semantika permezz ta’ `cacheDefaultMode`:

| Valur    | Imġiba                                                        |
| -------- | ------------------------------------------------------------- |
| `legacy` | Imġiba normali tal-cache (default)                            |
| `bypass` | Aqbeż kompletament it-tiftix fil-cache; dejjem uża l-upstream |

Issettjah meta tinħoloq iċ-ċavetta (`POST /api/keys`) jew meta tiġi aġġornata (`PATCH /api/keys/[id]`):

```json
{ "cacheDefaultMode": "bypass" }
```

### Qbiż għal kull talba

Kwalunkwe talba tista’ taqbeż il-cache irrispettivament mis-settings taċ-ċavetta:

```
X-OmniRoute-No-Cache: true
```

Għal mudelli sinkronizzati/importati, `PUT /api/provider-models` jaċċetta `provider`, `modelId`, u
`maxOutputTokenOverride`: numru sħiħ pożittiv jistabbilixxi l-limitu manwali tat-tokens tal-output, u `null`

tuża l-kapaċità `max_output_tokens` waqt it-tħaddim u tibqa’ teżisti wara sinkronizzazzjoni mill-ġdid tal-mudell. Il-paġna
tal-fornitur kompatibbli ma’ OpenAI toffri l-istess kontrolli ta’ editjar/tneħħija u timmarka mudelli b’appoġġ espliċitu għall-viżjoni.

In-nodi personalizzati ta’ Chat Completions jadattaw l-għażliet espliċiti li jiddiżattivaw ir-raġunament għall-backend upstream. Test
tal-konnessjoni li jirnexxi jagħżel awtomatikament il-kontrolli tal-mudell taċ-chat għal kull ID eżatt tal-mudell
li l-entrata tiegħu f’`/models` turi valur rikonoxxut ta’ `owned_by`: `vllm`, `sglang`, jew `llamacpp`.
Wrappers trasparenti kompatibbli ma’ OpenAI jistgħu jżommu l-entrata oriġinali tal-mudell ġewwa oġġett
`openai` annidat; id-detezzjoni ssegwi sa tliet livelli bħal dawn. Mudelli bi sjieda nieqsa, mhux magħrufa, jew
f’kunflitt iżommu l-imġiba ordinarja ta’ OpenAI. Id-detezzjoni terġa’ tuża t-talba eżistenti tal-katalgu,
ma tiġġenera ebda token ta’ tlestija, u tiġi invalidata meta jinbidel il-punt tat-tmiem tal-konnessjoni.

Biex tiffissa l-imġiba għal backend li ma jesponix dik il-metadata, uża l-API eżistenti
għall-aġġornament parzjali tal-fornitur:

```json
{
  "providerSpecificData": {
    "reasoningControl": "chat-template"
  }
}
```

Ibgħat dak il-body permezz ta’ `PUT /api/providers/<connection-id>`. Fuq dik il-konnessjoni, livell espliċitu
ta’ sforz ta’ raġunament ta’ `none` jintbagħat bħala `chat_template_kwargs.thinking=false` u
`chat_template_kwargs.enable_thinking=false`. Il-valuri espliċiti u nattivi tal-mudell jibqgħu awtoritattivi
sakemm regola ta’ raġunament min-naħa tas-server ma timponix livell ta’ sforz. Is-setting japplika biss meta konnessjoni
personalizzata kompatibbli ma’ OpenAI tibgħat body ta’ Chat Completions; it-talbiet ta’ Responses u l-fornituri
ordinarji jżommu l-forma nattiva tat-talba tagħhom. Issettja `reasoningControl` għal `openai` biex timponi t-trażmissjoni
ordinarja ta’ `reasoning_effort` ta’ OpenAI, jew ħallih barra/issettjah għal `null` biex tuża d-detezzjoni awtomatika.

It-talbiet tal-klassifikatur fil-modalità awtomatika ta’ Claude Code jużaw b’mod predefinit ħsieb nattiv diżattivat meta ma jkun fihom
ebda kontroll espliċitu tar-raġunament. Id-detezzjoni tuża l-markatur tas-sistema tal-klassifikatur fit-talbiet bil-format ta’ Claude,
mhux l-ismijiet tal-mudelli jew il-limiti tat-tlestija. Il-kontrolli espliċiti tal-body, l-headers appoġġjati tal-isforz/ħsieb,
ir-regoli tar-routing, u l-livell ta’ sforz riżolt tal-mudell iżommu l-prijorità eżistenti tagħhom. Iż-żewġ stadji tal-klassifikatur
iżommu l-prompts, il-limiti tat-tlestija, is-sekwenzi ta’ waqfien, u l-verdett reali tal-permessi upstream tagħhom;
it-tieni stadju xorta jista’ jipproduċi r-raġunament viżibbli mitlub tiegħu bħala test ordinarju.

### Verżjoni u Kanal tar-Rilaxx

```bash
GET /api/system/version
```

Rotta ta’ ġestjoni aċċessibbli biss permezz ta’ loopback (awtentikazzjoni ta’ amministratur). Tirritorna l-verżjoni li qed titħaddem, l-aħħar
verżjoni ppubblikata u l-istatus tal-aġġornament awtomatiku. `releaseChannel` u `channels` huma oqsma
addittivi (linja 3.8.54); `channel` iżomm it-tifsira tiegħu — il-modalità tal-iskjerament li juża l-aġġornatur
tad-dashboard (`npm`, `source` jew `docker-compose`).

```json
{
  "current": "3.8.52",
  "latest": "3.8.52",
  "updateAvailable": false,
  "channel": "npm",
  "autoUpdateSupported": true,
  "autoUpdateError": null,
  "news": null,
  "releaseChannel": "latest",
  "channels": { "latest": "3.8.52", "next": "3.8.53-rc.1" }
}
```

- `releaseChannel` — il-kanal npm tal-build li qed jitħaddem: `nightly` għal verżjonijiet `-nightly.*`,
  `next` għal pre-rilaxxi oħra (`-rc.*`, `-beta.*`, `-alpha.*`), `lts` għal verżjoni stabbli ta’
  major eqdem minn `channels.latest`, inkella `latest`. L-istess regoli bħal
  `scripts/release/dist-tag.mjs`, li jagħżel id-dist-tag ta’ npm fil-ħin tal-pubblikazzjoni.
- `channels` — il-verżjoni ewlenija ppubblikata ta’ kull dist-tag, minn `npm view omniroute dist-tags` (b’alternattiva
  HTTP tar-reġistru), miżmuma fil-cache bl-istess TTL ta’ 10 minuti bħal `latest`. `latest` ikun dejjem preżenti
  (jirrikorri għall-qasam `latest`, imbagħad għal `"unavailable"`); `next`, `nightly` u `lts` jidhru
  biss meta dak id-dist-tag ikun jeżisti. Talba `Cache-Control: no-cache` taġġorna ż-żewġ tfittxijiet.

Il-mudell tal-kanali (`latest` = v3 sal-GA ta’ 4.0, `next` = rc, `nightly` = builds ta’ `develop`,
`lts` = patches ta’ v3 wara l-GA ta’ 4.0) huwa deskritt f’`docs/ops/RELEASE_STRATEGY.md`.

## Limiti tat-Tokens

Baġits ta’ **tokens** għal kull ċavetta API (distinti mill-Baġit ibbażat fuq l-USD hawn fuq). Dawn jiġu infurzati direttament fil-fluss tat-talba: meta l-użu ta’ ċavetta fit-tieqa attwali jilħaq il-limitu tagħha, it-talbiet jiġu miċħuda b’`429 Too Many Requests`. Il-limiti jistgħu jiġu ristretti għal `model` speċifiku, `provider`, jew applikati `global`ment għaċ-ċavetta kollha; meta diversi limiti jaqblu ma’ talba, japplika l-aktar wieħed restrittiv.

```bash
# Elenka l-limiti tat-tokens ta’ ċavetta (jinkludi l-użu attwali tat-tieqa)
GET /api/usage/token-limits?apiKeyId=key-123

# Oħloq jew aġġorna limitu tat-tokens
POST /api/usage/token-limits
Content-Type: application/json

{
  "apiKeyId": "key-123",
  "scopeType": "model",
  "scopeValue": "openai/gpt-4o",
  "tokenLimit": 1000000,
  "resetInterval": "monthly",
  "enabled": true
}

# Ħassar limitu tat-tokens skont l-id
DELETE /api/usage/token-limits?id=tl-abc
```

> **Noti dwar l-iskema** (`setTokenLimitSchema`): `apiKeyId` u `scopeType` (`model` | `provider` | `global`) huma meħtieġa. `scopeValue` huwa meħtieġ sakemm `scopeType` ma jkunx `global` (eż. id ta’ mudell għall-ambitu `model`, jew id ta’ fornitur għall-ambitu `provider`). `tokenLimit` irid ikun numru sħiħ pożittiv (ikkonvertit minn string). Fakultattivi: `id` (ħallih barra biex toħloq, ipprovdih biex taġġorna), `resetInterval` (`daily` | `weekly` | `monthly`, valur predefinit `monthly`), `resetTime` (`HH:MM`), `enabled` (valur predefinit `true`). It-tweġibiet `GET` jarrikkixxu kull limitu b’`tokensUsed`, `remaining`, `windowStart`, `periodStartAt`, u `nextResetAt`. Dan huwa endpoint tal-klassi tal-ġestjoni (l-awtentikazzjoni tiġi infurzata ċentralment mill-pipeline authz).

## Ipproċessar tat-Talbiet

1. Il-klijent jibgħat talba lil `/v1/*`
2. Il-handler tar-rotta jsejjaħ `handleChat`, `handleEmbedding`, `handleAudioTranscription`, jew `handleImageGeneration`

4. Il-kredenzjali jintgħażlu mid-DB lokali b’filtrazzjoni skont id-disponibbiltà tal-kont
5. Għaċ-chat: `handleChatCore` jiċċekkja l-cache semantika/tal-firma u jirriżolvi s-settings tal-kompressjoni tal-combo
6. Il-kompressjoni proattiva titħaddem qabel it-traduzzjoni tal-fornitur meta tkun attivata (`lite`, Caveman, RTK, jew f’munzell)
7. L-eżekutur tal-fornitur jibgħat it-talba upstream
8. It-tweġiba tiġi tradotta lura għall-format tal-klijent (chat) jew irritornata kif inhi (embeddings/immaġnijiet/awdjo)
9. L-użu, l-analitika tal-kompressjoni, u r-reġistri tat-talbiet jiġu rreġistrati
10. Il-fallback japplika meta jseħħu żbalji skont ir-regoli tal-combo

Referenza sħiħa tal-arkitettura: [`ARCHITECTURE.md`](../architecture/ARCHITECTURE.md)

## Reżiljenza (estiża)

OmniRoute jipprovdi tliet mekkaniżmi indipendenti għal fallimenti temporanji; l-endpoints ta’ ġestjoni hawn taħt jippermettu lill-operaturi jaqrawhom u jissostitwixxu l-konfigurazzjoni tagħhom:

| Ambitu                   | Ħażna tal-istat                                         | Qari                                      | Irrisettjar / tneħħija                                                    |
| ------------------------ | ------------------------------------------------------- | ----------------------------------------- | ------------------------------------------------------------------------- |
| Interruttur tal-fornitur | `domain_circuit_breakers` + fil-memorja                 | `/api/monitoring/health`                  | `POST /api/resilience/reset`                                              |
| Stennija tal-konnessjoni | `rateLimitedUntil` fuq il-konnessjonijiet tal-fornituri | `/api/rate-limits`, `/api/providers/[id]` | (jerġa’ jiġi attivat b’mod għażżien; neħħih permezz ta’ PUT tal-fornitur) |
| Imblukkar tal-mudell     | Reġistru tad-disponibbiltà tal-mudelli fil-memorja      | `GET /api/resilience/model-cooldowns`     | `DELETE /api/resilience/model-cooldowns`                                  |

`PATCH /api/resilience` jaċċetta sostituzzjonijiet tal-interruttur tal-fornitur taħt `providerBreaker.oauth` u `providerBreaker.apikey`. Kull profil jappoġġja `degradationThreshold`, `failureThreshold`, u `resetTimeoutMs`; l-istess oqsma huma disponibbli f’Dashboard → Settings → Resilience.

```bash
# Neħħi imblukkar ta’ mudell wieħed
curl -X DELETE http://localhost:20128/api/resilience/model-cooldowns \
  -H "Cookie: auth_token=..." \
  -H "Content-Type: application/json" \
  -d '{"provider":"openai","model":"gpt-4o-mini"}'

# Neħħi l-imblokkar kollu
curl -X DELETE http://localhost:20128/api/resilience/model-cooldowns \
  -H "Cookie: auth_token=..." \
  -d '{"all":true}'
```

Għar-referenza kunċettwali sħiħa u l-valuri predefiniti tal-interruttur: ara [`CLAUDE.md`](../../CLAUDE.md) → "Stat ta’ Eżekuzzjoni tar-Reżiljenza" u [`docs/architecture/RESILIENCE_GUIDE.md`](../architecture/RESILIENCE_GUIDE.md).

### Kju tal-Limitu tar-Rata u Xibka ta’ Sikurezza għall-Attivazzjoni Awtomatika

- **Rotta ta’ kitba appoġġjata**: `POST /api/rate-limits` bil-body `{"connectionId": "<id>", "enabled": true|false}` huwa l-endpoint ta’ ġestjoni appoġġjat biex jixgħel jew jitfi l-protezzjoni mil-limitu tar-rata għal konnessjoni. `PUT /api/providers/[id]` intenzjonalment ma jimmodifikax jew jaqleb `rateLimitProtection` (#11278).
- **Semantika ta’ `enabled: false`**: L-issettjar ta’ `enabled: false` ineħħi l-protezzjoni espliċita għall-konnessjoni, iżda **ma jeskludix** konnessjoni attiva b’API key mix-xibka ta’ sikurezza globali għall-attivazzjoni awtomatika (`autoEnableApiKeyProviders = true`). F’`reconcileEnabledConnections` (`open-sse/services/rateLimitManager.ts`), `false` u `undefined` huma ekwivalenti; konnessjonijiet attivi b’API key mingħajr protezzjoni espliċita jibqgħu protetti taħt ix-xibka ta’ sikurezza għall-attivazzjoni awtomatika.
- **Diżattivazzjoni globali**: Biex tħaddem konnessjonijiet b’API key mingħajr kjuwijiet tal-limitu tar-rata, iddiżattiva x-xibka ta’ sikurezza globalment permezz ta’ `RATE_LIMIT_AUTO_ENABLE=false` (varjabbli tal-ambjent) jew `resilienceSettings.requestQueue.autoEnableApiKeyProviders = false` (Settings → Resilience / `PATCH /api/resilience`).

## Server A2A

OmniRoute jesponi punt ta' tmiem A2A (Minn Aġent għal Aġent) JSON-RPC 2.0 flimkien ma' wrapper REST għall-ispezzjoni/użu fid-dashboard.

### JSON-RPC

```bash
POST /a2a
Authorization: Bearer your-api-key   # fakultattiv sakemm OMNIROUTE_API_KEY ma jkunx issettjat
Content-Type: application/json

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "message/send",
  "params": {
    "skill": "smart-routing",
    "messages": [{"role": "user", "content": "Route this coding task"}]
  }
}
```

Metodi appoġġjati (kollha jiddependu fuq `settings.a2aEnabled`):

| Metodu           | Deskrizzjoni                                                              |
| ---------------- | ------------------------------------------------------------------------- |
| `message/send`   | Eżekuzzjoni sinkronika tal-ħila; tirritorna `{task, artifacts, metadata}` |
| `message/stream` | Eżekuzzjoni SSE bi streaming tal-istess sett ta' ħiliet                   |
| `tasks/get`      | Iġib kompitu permezz ta' `taskId`                                         |
| `tasks/cancel`   | Jikkanċella kompitu permezz ta' `taskId`                                  |

Ħiliet inkorporati: `smart-routing`, `quota-management`, `provider-discovery`, `cost-analysis`, `health-report`.

### Kard tal-Aġent

```bash
GET /.well-known/agent.json
```

Jirritorna l-kard pubblika tal-aġent A2A (isem, deskrizzjoni, kapaċitajiet, katalogu tal-ħiliet, skema tal-awtentikazzjoni) — maħżuna fil-cache pubblikament għal siegħa. Ma hija meħtieġa ebda awtentikazzjoni.

### Għodod awżiljarji REST

| Metodu | Mogħdija                     | Deskrizzjoni                                                                                                           |
| ------ | ---------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| GET    | `/api/a2a/status`            | A2A attivat + statistika tal-kompiti + sommarju tal-kard tal-aġent maħżuna fil-cache                                   |
| GET    | `/api/a2a/tasks`             | Jelenka l-kompiti — `?state=submitted\|working\|completed\|failed\|cancelled`, `?skill=`, `?limit=` (≤200), `?offset=` |
| POST   | `/api/a2a/tasks`             | (Mhux implimentat bħala għodda awżiljarja REST — oħloq permezz ta' JSON-RPC `message/send`)                            |
| GET    | `/api/a2a/tasks/[id]`        | Jirkupra kompitu wieħed                                                                                                |
| POST   | `/api/a2a/tasks/[id]/cancel` | Jikkanċella kompitu                                                                                                    |

**Awtentikazzjoni:** l-għodod awżiljarji REST jaħdmu mingħajr awtentikazzjoni ta' ġestjoni (jistgħu jinqraw mid-dashboard); ir-rotta JSON-RPC `/a2a` tuża Bearer `OMNIROUTE_API_KEY` jekk tkun ikkonfigurata.

## Awtentikazzjoni

Ara [Awtentikazzjoni tal-Ġestjoni](../guides/MANAGEMENT-AUTH.md) għall-erba’
familji ta’ kredenzjali (sessjoni tad-dashboard, token lokali tas-CLI, Token
ta’ Aċċess `oma_live_…`, ċavetta API bl-ambitu tal-ġestjoni) u kif dawn huma differenti miċ-ċwievet tal-inferenza.

- Ir-rotot tad-dashboard (`/dashboard/*`) jużaw il-cookie `auth_token`
- Il-login juża l-hash tal-password issejvjat; bħala alternattiva juża `INITIAL_PASSWORD`
- `requireLogin` jista’ jiġi attivat jew diżattivat permezz ta’ `/api/settings/require-login`
- Ir-rotot `/v1/*` jistgħu jeħtieġu b’mod fakultattiv ċavetta API Bearer meta `REQUIRE_API_KEY=true`
- “token tal-ġestjoni” / “ċavetta API bl-ambitu tal-ġestjoni” f’din ir-referenza tfisser waħda mill-familji f’dik il-gwida — mhux tip addizzjonali ta’ sigriet mhux definit

> **Bidla inkompatibbli (v3.8.0)** — `/api/v1/agents/tasks/*` u l-endpoints tal-ġestjoni tal-cooldown issa jeħtieġu **awtentikazzjoni tal-ġestjoni** (cookie `auth_token` tad-dashboard jew ċavetta API bl-ambitu tal-ġestjoni). Il-klijenti li qabel kienu jsejħu dawn ir-rotot mingħajr awtentikazzjoni se jirċievu `401 Unauthorized`. Ara l-commit `588a0333` (`fix(auth): require management auth for agent and cooldown APIs`).
