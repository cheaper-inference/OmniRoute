> Toggles runtime li jibdlu l-imġieba ta' OmniRoute **mingħajr redeploy**.
> Kull flag elenkat hawnhekk huwa definit fi
> [`src/shared/constants/featureFlagDefinitions.ts`](../../src/shared/constants/featureFlagDefinitions.ts)

## X'inhuma l-Feature Flags

Feature flag huwa toggle imsemmi (boolean jew enum) li l-valur tiegħu jista' jinbidel waqt l-eżekuzzjoni u jiġi ppersistut fid-database, mingħajr ma jkun meħtieġ redeploy tal-proċess. Kull flag huwa deskritt minn `FeatureFlagDefinition` b' `key`, `label`, `description`, `category`, `defaultValue`, `type`, u `requiresRestart` hint.

### Ordni ta' Riżoluzzjoni

Il-**valur effettiv** ta' flag jiġi riżolt minn
[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) b'din il-preċedenza (l-ogħla tirbaħ):

1.  **DB override** — valur maħżun fit-tabella `key_value` taħt in-namespace `feature_flags` (issettjat permezz tad-dashboard jew il-REST API).
2.  **Varjabbli tal-ambjent** — `process.env[<KEY>]`, jekk issettjat u mhux vojt.
3.  **Default tad-definizzjoni** — il-`defaultValue` minn `featureFlagDefinitions.ts`.

Flag boolean huwa kkunsidrat **attivat** meta l-valur effettiv tiegħu jkun `"true"`, `"1"`, jew `"yes"` (ara `isFeatureFlagEnabled()`).

> [!NOTE]
> Ħafna flags għandhom ukoll varjabbli tal-ambjent korrispondenti tal-**istess isem**
> dokumentata f'[`ENVIRONMENT.md`](./ENVIRONMENT.md). L-override tad-DB tal-flag
> tieħu preċedenza fuq dik il-varjabbli tal-ambjent. Flag b'
> `requiresRestart: true` jiġi ppersistut immedjatament iżda jerġa' jinqara biss mal-bidu tal-proċess
> — it-toggle tiegħu juri banner ta' **"Restart Server"** fid-dashboard.

## Toggling Bnadar

### Dashboard

Innaviga lejn** Dashboard → Settings → Feature Flags** (`/dashboard/settings/feature-flags`). Il-grilja (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`) tappoġġja:

- **Fittex** biċ-ċavetta jew deskrizzjoni, u** filtru** skond il-kategorija (flimkien ma' sintetiku** Jeħtieġ Irristartja** ħsieb).
- A** toggle** għall-bnadar boolean u a** dropdown** for enum flags (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`).
- A** badge tas-sors** kull bandiera — `DB`, `ENV`, jew `DEF` — li turi minn fejn ġie l-valur effettiv.
- A** Irrisettja** buttuna (muri biss għall-bnadar `DB` -sourced ) biex twaqqa 'l-override, u a** Irrisettja Kollha Overrides** buttuna fil-qiegħ.
- A** Ibda mill-ġdid Server** banner meta tinbidel bandiera `requiresRestart`.

### REST API

L-operazzjonijiet kollha jgħaddu minn rotta waħda: [`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts). Kull metodu jeħtieġ sessjoni dashboard awtentikata (`401` mod ieħor).

Bil-login diżattivat (`requireLogin=false`) ir-rotta hija miftuħa, ħlief għall-bnadar protetti: kull bandiera fil-kategorija tas-Sigurtà flimkien ma `OMNIROUTE_ALLOW_PRIVATE_PROVIDER_URLS`, `OMNIROUTE_ALLOW_LOCAL_PROVIDER_URLS`, `MITM_DISABLE_TLS_VERIFY`, `OMNIROUTE_MCP_ENFORCE_SCOPES` u `SKILLS_SANDBOX_NETWORK_ENABLED` (`isProtectedFeatureFlag()` fi `protectedFeatureFlags.ts`). A `PUT` fuq waħda minnhom, u `DELETE` filwaqt li wieħed minnhom għandu DB override, xorta jeħtieġ sessjoni dashboard, `manage` -scope API key, token ta 'aċċess `oma_` b'ambitu ta' kitba jew ogħla, jew it-token CLI jew token tas-servizz intern mibgħut minn loopback. Dak is-sett huwa usa' milli bil-login mixgħul, fejn ir-rotta taċċetta biss sessjoni jew ċavetta `manage` -scope.

#### `GET /api/settings/feature-flags`

Jirritorna kull bandiera bil-valur effettiv tagħha, is-sors, u sommarju.

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Require API Key",
      "description": "Require an API key for all incoming requests",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... all 119 flags
  ],
  "summary": {
    "total": 119,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

Issettja jew neħħi override wieħed. Body: `{ key: string; value?: string }`. Li tħalli barra `value` tneħħi l-override (irrestawra env / default).

```bash
# Set a DB override
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# Remove the override (no "value")
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

Ir-rispons itenni `effectiveValue`/`source` il-ġdid, iż `previousValue`/ `previousSource`, u `requiresRestart`. Ċwievet mhux magħrufa u valuri enum barra mill-firxa huma rrifjutati `400`.

#### `DELETE /api/settings/feature-flags`

Jiċċara** kollha** DB jegħleb f'daqqa, u jirrestawra kull bandiera għall-valur env / default tagħha. Ritorni `{ cleared: <count>, message: "..." }`.

> [!NOTE]
> Bnadar bi `requiresRestart: true` jidħlu fis-seħħ biss wara proċess reload. Il-fluss mill-ġdid tad-dashboard isejjaħ `POST /api/restart` u mbagħad istħarriġ `GET /api/health/ping` sakemm is-server ikun lura.

## Alternattiva ta' Emerġenza għall-Baġit

`OMNIROUTE_EMERGENCY_FALLBACK` (kategorija `runtime`, valur predefinit `true`) jikkontrolla l-mogħdija alternattiva bla ħlas ta' emerġenza f'
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts).
Meta tkun attivata, it-talbiet li jeżawrixxu l-baġit tagħhom jiġu diretti lejn
fornitur/mudell alternattiv bla ħlas minflok ma jfallu għalkollox. Issettjaha għal `false` (jew `0`) — permezz tal-
buttuna fid-dashboard, override fid-DB, jew il-varjabbli ambjentali
`OMNIROUTE_EMERGENCY_FALLBACK` — biex tiddiżattiva din l-imġiba u tħalli t-talbiet
li jkunu eżawrew il-baġit ifallu. (Murija bħala buttuna fid-dashboard fil-PRs #3741 / #3752.)

Risposta pprovduta minn din l-alternattiva jkollha
`X-OmniRoute-Emergency-Fallback: from=<provider/model>; to=<provider/model>`, sabiex
klijent ikun jista' jagħraf li ġiet diretta mill-ġdid mingħajr ma jqabbel `X-OmniRoute-Provider` mat-
talba tiegħu. L-header ma jkun preżenti fl-ebda risposta oħra.
