`@omniroute/opencode-plugin-v2` iqiegħed il-katalgu kollu tiegħek ta’ OmniRoute — mudelli, combos u
auto-combos — fis-selettur tal-mudelli ta’ OpenCode v2, b’ismijiet għall-wiri, prezzijiet u
baġits tal-livell bla ħlas.

Dan huwa pakkett separat minn `@omniroute/opencode-plugin` għax OpenCode v1 u v2 jgħabbu
l-plugins permezz ta’ kuntratti differenti. Agħżel dak li jaqbel mal-verżjoni ewlenija ta’ OpenCode tiegħek; ma
jaqsmu xejn bejniethom, għalhekk l-aġġornament ta’ wieħed qatt ma jobbligak taġġorna lill-ieħor.

## Rekwiżiti

- OpenCode v2.
- Gateway ta’ OmniRoute li jista’ jintlaħaq (`http://localhost:20128` b’mod awtomatiku).
- Node.js 22 jew 24.

## Installazzjoni

Żid il-plugin ma’ `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

Il-mudelli mbagħad jidhru bħala `omniroute/<provider>/<model>`; `providerId` jiddetermina dak il-prefiss u
l-id tal-integrazzjoni li taħtu OpenCode jaħżen il-kredenzjali.

## Kredenzjali

Il-plugin ifittex ċavetta tal-gateway fi tliet postijiet, f’din l-ordni:

1. **Il-kredenzjali li kkonnettjajt f’OpenCode.** Il-plugin jirreġistra integrazzjoni, għalhekk
   il-fluss ta’ awtentikazzjoni ta’ OpenCode stess jista’ jaħżen iċ-ċavetta. Xejn ma jidħol f’`opencode.json` — ippreferi dan.
2. `apiKey` fl-għażliet tal-plugin, għal override għal kull proġett. Dan ipoġġi ċ-ċavetta f’fajl li
   tista’ tkun qed tikkommetti.
3. `OMNIROUTE_API_KEY` fl-ambjent.

Jekk ma jkun hemm l-ebda waħda mit-tlieta, il-katalgu jkun vojt u l-plugin jgħidlek dan darba waqt l-istartjar minflok
iħallik b’selettur vojt mingħajr ebda twissija.

### It-token tal-ġestjoni huwa ċavetta differenti

Il-combos, is-saħħa tal-fornituri u l-arrikkiment (ismijiet għall-wiri, prezzijiet, baġits tal-livell bla ħlas) jiġu
mill-endpoints `/api/*` tal-gateway, li fil-biċċa l-kbira tad-deployments ikunu protetti b’token tal-**ġestjoni**
minflok biċ-ċavetta tal-inferenza:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<token tal-qari tal-ġestjoni>"
}
```

Jekk `managementReadToken` ma jiġix issettjat, jaqa’ lura fuq `apiKey`. Meta gateway jirrifjuta dan il-fallback,
il-katalgu xorta jiġi ppubblikat, iżda b’ids mhux ipproċessati tal-mudelli minflok ismijiet għall-wiri, mingħajr
tneħħija ta’ duplikati ta’ aliases kanoniċi, mingħajr prezzijiet u mingħajr combos. Il-plugin iwissi darba għal kull endpoint meta jiġri dan,
billi jsemmi l-endpoint u x’intilef — għalhekk selettur degradat qatt ma jkun misteru.

## Kif il-katalgu jibqa frisk

Il-katalgu jinġabar bil-għażż u fil-cache għal `modelCacheTtlMs`, u snapshot disk iżomm l-aħħar katalgu magħruf disponibbli meta l-gateway ma jkunx jista' jintlaħaq — qtugħ ma jiswik xejn ħlief freskezza. Mudelli u combos jiġu ppubblikati hekk kif jaslu; auto-combos, il-lista tal-fornituri u l-overlay tal-arrikkiment jintemmu meta jinżlu, għalhekk punt wieħed bil-mod ma jistax iżomm ostaġġ tal-picker kollu.

L-ismijiet isegwu `Provider - Model[ (Editor)][ · budget][ (route)]`: il-fornitur jintwera kull meta l-id iġorr wieħed (id mingħajr slash mingħajr prefiss), `🆓` ewlieni jimmarka entrati b’xejn u l-baġit ta’ saff ħieles tagħhom jibqa’ bħala suffiss `· 1M tokens/month`, l-editur ta’ isem `Editor: Model` `combo - <slug>` jmur għal parentesi ta’ wara (l-ebda editur ma huwa guessed minn ikona oħra mingħajr ismijiet). Żewġ entrati li jaqsmu isem jiksbu suffiss tar-rotta — `(no-think)` — sabiex jibqgħu jintgħarfu. `providerTag` (default `true`) jibdel il-parentesi tal-editur ta' wara.

M'hemm l-ebda kmand ta 'aġġornament manwali: il-kmandi OpenCode v2 huma mudelli fil-pront, mhux callbacks, għalhekk plugin ma jistax jesponi wieħed. Refreshes isegwu l TTL; l-ospitant jintalab jerġa' jgħabbi biss meta l-katalgu jew is-superpożizzjoni fil-fatt inbidel, qatt darba għal kull aġġornament.

## Sejħiet ta’ għodod fuq Gemini

Gemini jirrifjuta talba sħiħa li d-dikjarazzjonijiet tal-għodod tagħha jkun fihom `$schema` jew `additionalProperties`, u jwieġeb b’`400 INVALID_ARGUMENT`. Il-plugin ineħħi dawk il-kliem ewlieni mill-iskemi tal-għodod maħsuba għal mudell Gemini ta’ dan il-fornitur u jħalli kull talba oħra mhux mittiefsa. Għodda li jkun fiha `$ref` tintbagħat kif inhi minflok ma titneħħielha xi ħaġa, peress li t-tneħħija tar-referenza twessa’ l-iskema biex “taċċetta kollox”.
Issettja `"geminiSanitization": false` biex titfiha.

## Issolvi l-problemi

| Sintomu                                                      | Kawża                                                                                                                                   |
| ------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------- |
| Picker ma juri l-ebda mudell OmniRoute                       | L-ebda ċavetta ma ġiet solvuta (iċċekkja t-twissija tal-istartjar), jew il-portal ma jistax jintlaħaq                                   |
| Ids tal-mudell mhux maħdum, l-ebda combos, l-ebda prezzijiet | L-endpoints tal-ġestjoni rrifjutaw it-token — set `managementReadToken`                                                                 |
| Katalgu `freeOnly` qasir jew vojt                            | L-ebda token tal-ġestjoni jew token miċħud — aqra l-linja sommarja tal-aġġornament (għadd `unmatched-free` ) fir-reġistru tal-ospitanti |
| Sessjoni pinnjata `opencode-<id>/...`                        | Il-plugin v1 ippubblikat `opencode-<id>`; v2 tippubblika `<id>` bare, għalhekk agħżel mill-ġdid il-mudell taħt `<id>/...`               |

Il-varjabbli tal-ambjent għandhom jilħqu l-proċess tas-server tal-opencode: meta l-host jaħdem bħala servizz, il-qoxra li tmexxi `opencode models` u l-ambjent tas-server huma differenti, għalhekk esporta ċ-ċavetta fejn is-server jaqrah.
