Il-kuntratt `config/cli-tools-manifest.json` newtrali jiddikjara IDs kanoniku , psewdonimi, kandidati binarji, riċetti ta 'setup, argumenti mudell u kapaċitajiet. L-adapter Node sempliċi `bin/cli/cli-manifest.mjs` u l-adapter TypeScript `src/shared/constants/cliIntegrationManifest.ts` jaqraw l-istess fajl. Runtime, katalogu, konfigurazzjoni, tlestija, ġeneraturi u reġistrazzjoni backend huma ċċekkjati flimkien minn `tests/unit/cli/cli-manifest-drift.test.ts`. Li tkun ikkatalogata ma jfissirx li għodda tista' tiġi mnedija jew konfigurata. B'mod partikolari, 5dive jibqa' kkonfigurat biss.

## L-ambjent tat-tfal u ċ-ċiklu tal-ħajja

`omniroute run`, `omniroute launch` u `omniroute launch-codex` jirtu lista ta' permessi ta' kompatibilità OS/terminal u injetta l-kredenzjali tal-mira magħżula. Is-sigrieti tal-fornitur u tad-database mhux relatati ma jintirtux awtomatikament. `--inherit-env` espliċitament tirrestawra l-wirt sħiħ tal-ġenitur-ambjent; użah biss meta l-proċess magħżul ta 'parti terza għandu jirċievi dawk il-valuri. Dan huwa filtrazzjoni tal-ambjent, mhux sandbox OS : il-proċess għadu jaħdem bil-permessi tas-sistema tal-fajls ta' min iċempel.

Sinjali ta' interruzzjoni u terminazzjoni jintbagħtu lit-tifel. Il-lanċjar jistenna l-avveniment mill-qrib tat-tifel qabel ma jneħħi l-konfigurazzjoni temporanja. `OMNIROUTE_CHILD_SIGNAL_TIMEOUT_MS` jikkontrolla l-perjodu ta 'grazzja qabel it-terminazzjoni sfurzata (default 5000 millisekondi).

## Gemini setup persistenti

```bash
omniroute setup-gemini --remote https://omni.example --model provider/model --yes
omniroute configure gemini --model provider/model --yes
omniroute run gemini --model provider/model --dry-run --json
```

L-ewwel żewġ kmandi jikkonfiguraw din il-magna għas-server lokali jew remot magħżul. Is-setup tippreserva settings JSON mhux relatati, tagħżel Gemini API-key auth, u tikteb l-endpoint u l-kredenzjali f'fajl `.gemini/.env` privat. Jirrifjuta JSON invalidu aktar milli jikteb fuqu. Endpoint URLs għandu jkun HTTP(S), mingħajr kredenzjali inkorporati, parametri ta' mistoqsija jew frammenti. Dry-run prints mogħdijiet, mhux valuri kredenzjali.

`GEMINI_CLI_HOME` jew `--gemini-home` jagħżel l-għerq persistenti tad-dar. `run gemini` attwali joħloq u aktar tard ineħħi d-dar temporanja tiegħu stess. L-ebda modalità ma tevita l-kontrolli tal-ispazju tax-xogħol ta' Gemini.

## Codex profiles

`configure codex` jikteb `<name>.config.toml` privat b'mudell u l-endpoint tal-fornitur OmniRoute tiegħu. Il-kredenzjali huma referenzjati permezz ta' `OMNIROUTE_API_KEY`, qatt inkorporati. Il-kmand tat-tnedija jistabbilixxi l-mudell magħżul fiċ-ċavetta `model` tal-ogħla livell, mhux ġewwa `model_providers`.

Fajls tal-profili separati huma l-kuntratt Codex dokumentat kurrenti; huma overlay il-konfigurazzjoni tal-utent meta magħżula `codex --profile <name>`. Ara [r-referenza tal-profil uffiċjali](https://learn.chatgpt.com/docs/config-file/config-advanced#profiles) u [l-gwida OmniRoute Codex](./CODEX-CLI-CONFIGURATION.md).

## Eżekuzzjoni ta' kmand ermetiku

`DATA_DIR` espliċita , l-issettjar `OMNIROUTE_CLI_SKIP_DEFAULT_DATA_ENV=1` jipprevjeni l-istartjar milli jaqa' fl-ambjent tal-kredenzjali tad-direttorju tad-dejta tal-utent default. Dan huwa utli għal testijiet iżolati. Ma tiddiżattivax fajls oħra tal-ambjent magħżula b'mod espliċitu.

## Working-directory `.env`

Iż- CLI jaqra fajls `.env` f'din l-ordni, u l-ewwel fajl li jistabbilixxi ċavetta jirbaħ: iż- `DATA_DIR` espliċitu, id-direttorju tad-dejta default, id-direttorju tax-xogħol kurrenti, imbagħad id-direttorju tal-pakkett. Shell varjabbli dejjem jirbħu.

Id-direttorju tax-xogħol jista' jappartjeni lil xi ħadd ieħor (repożitorju kklonat, arkivju mhux ippakkjat), u `omniroute serve` jgħaddi l-ambjent CLI lis-server u lil kull għodda li jħaddem is-server. Allura `.env` hemm jista' jissettja biss dawn iċ-ċwievet, elenkati `bin/cli/utils/untrustedCwdEnv.mjs`:

| Ewlenin                         | Valuri aċċettati                                                                  |
| ------------------------------- | --------------------------------------------------------------------------------- |
| `REQUIRE_API_KEY`               | `true`, `1` jew `yes` fi kwalunkwe każ, il-valuri li s-server jittratta bħala fuq |
| `LANG`, `LC_ALL`, `LC_MESSAGES` | sa 64 ittra, ċifra, `_`, `.`, `@` jew `-`                                         |
| `LANGUAGE`                      | l-istess, flimkien `:`                                                            |
| `TZ`                            | sa 64 ittra, ċifra, `_`, `+`, `-` jew `/`, li ma jibdewx `/`                      |
| `NO_COLOR`, `FORCE_COLOR`       | sa 16-il ittra u ċifra                                                            |

Kull valur `REQUIRE_API_KEY` jaċċetta jixgħel iċ-ċekk, u għalhekk il-fajl ma jistax jitfi l-kontroll innifsu. Iżda ma jiddeċidix ir-riżultat: is-server jaqra `REQUIRE_API_KEY` override maħżuna fid-database qabel l-ambjent, filwaqt li t-twissija tal-istartjar dwar is-smigħ fuq l-interfaces kollha mingħajr ċavetta API taqra biss l-ambjent. B'override maħżun ta' `false`, `REQUIRE_API_KEY=true` -direttorju tax-xogħol iħalli l- API miftuħ u jaħbi dik it-twissija. Ir-regola `TZ` hija idjaq minn POSIX: tirrifjuta `.`, `:`, `,` u `<>`, għalhekk il-forma `:Area/City` u r-regoli bħal `EST5EDT,M3.2.0,M11.1.0` għandhom jiġu stabbiliti fil-qoxra jew `<DATA_DIR>/.env`.

L-ismijiet għandhom jaqblu eżattament, f'ittri kbar. Kwalunkwe linja oħra, valur li jfalli l-kontroll tiegħu, u isem li mhux sempliċi ASCII ittri, ċifri u `_` (per eżempju wieħed b'byte NUL jew ittra li tixbah) huma maqbuża. L CLI jistampa twissija waħda li ssemmi ċ-ċwievet li ma jistax jissettja u waħda li ssemmi ċwievet permessi li injora, kull waħda b'x'għandu tibdel (`TZ (expected a zone name such as Europe/Berlin)`, `lang (write the name as LANG)`). La jistampa l-valuri. Il-mogħdijiet tal-fajls f'dawn il-messaġġi, u r-rapporti `.env` path `omniroute doctor`, jinħarbu meta jkun fihom karattri ta' kontroll jew bidi. Ir-restrizzjoni ma tapplikax meta d-direttorju tax-xogħol ikun id-direttorju tad-dejta jew id-direttorju tal-pakketti.

`PORT`, `API_PORT` u `DASHBOARD_PORT` mhumiex fil-lista. Mingħajr bażi URL minn sors ta’ preċedenza ogħla, iż- CLI jitkellem ma’ `localhost:<PORT>`, u dak kollu li jisma’ hemm jirċievi ċ-ċavetta API taż- CLI, it-token tal-kuntest u t-token tal-magna CLI (`x-omniroute-cli-token`, ara [CLI_TOKEN.md](../security/CLI_TOKEN.md) ), li s-server lokali jaċċetta għal sejħiet ta’ ġestjoni minn loopback. Port mid-direttorju tax-xogħol iħalli dak il-fajl jagħżel is-semmiegħ, għalhekk issettja l-portijiet fil-qoxra, `<DATA_DIR>/.env` jew bl-għażla `--port` ta' kmandi li għandhom wieħed (`serve`, `launch`, `run`).

Il-parser m'għandux sintassi `export`. Linja bħal `export LD_PRELOAD=...` ismijiet varjabbli `export LD_PRELOAD`; mid-direttorju tax-xogħol jinqabeż, u f'fajls `.env` oħra jistabbilixxi dak l-isem letterali, li xejn ma jaqra.

Iż CLI jgħaqqad token maħżun ta' kuntest (token ta' aċċess jew ċavetta API legacy) biss mal-oriġini ta' dak il-kuntest stess: skema, host u port, meta mqabbla ma' `URL.origin`. Dan japplika għal talbiet magħmula permezz tal-klijent HTTP ta' CLI(`--base-url`, `OMNIROUTE_BASE_URL`, `omniroute connect <new-url>`) u għall-kmandi `launch`, `launch codex`, `configure` u `setup-*` li jiktbu bażi URL u ċavetta fil-konfigurazzjoni ta' għodda oħra. Ippuntati lejn server ieħor `--remote`, huma jużaw `--api-key` espliċitu jew `OMNIROUTE_API_KEY` jekk wieħed ikun issettjat, u l-ebda token tal-kuntest. It-tqabbil huwa eżatt, għalhekk `localhost` u `127.0.0.1`, jew ospitanti bi u mingħajr punt ta' wara, jgħoddu bħala servers differenti u ma jġibu l-ebda token tal-kuntest. A URL b'informazzjoni għall-utent, backslash jew whitespace qatt ma jaqbel, minħabba li parsers URL oħra ( `urllib` u `httpx` ta' Python, pereżempju) jistgħu jaqraw host differenti minnu. Għal talbiet l- CLI jibgħat innifsu, dak il-kontroll ikopri biss l-iskema u l-awtorità, għalhekk id bi spazju fil-mogħdija jew mistoqsija żżomm it-token.
