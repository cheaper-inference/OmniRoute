> **Fil-qosor**: OmniRoute jikklassifika l-fornituri **bla ħlas** tiegħu skont il-kwalità tal-mudell billi juża **punteġġi ELO ta’ Arena AI
> (stil LMArena)**. Iftaħ il-paġna **Klassifikazzjonijiet tal-Fornituri Bla Ħlas** fid-
> dashboard biex tara liema fornituri bla ħlas joffru l-aktar mudelli b’saħħithom għall-kompitu tiegħek —
> b’mod ġenerali, jew iffiltrati skont il-kategorija (kodifikazzjoni, reviżjoni, dokumentazzjoni, debugging).

## X'Inhu

OmniRoute tirreġistra 376 fornitur, inklużi 155 entrata fil-katalgu mmarkata **free/no-auth**
(no-auth,
OAuth b'livell b'xejn, jew API key b'livell b'xejn — ara l-
[Gwida dwar il-Livelli B'xejn](../getting-started/FREE-TIERS-GUIDE.md) u d-
[direttorju sħiħ tal-Livelli B'xejn](../reference/FREE_TIERS.md)). Il-kwistjoni: il-fornituri b'xejn jvarjaw
ħafna fil-kwalità tal-mudell. Fornitur no-auth li jservi mudell frontier huwa ħafna aktar utli
minn wieħed li jservi mudell legacy żgħir.

**Free Provider Rankings** jwieġeb il-mistoqsija "**liem fornitur b'xejn jagħtini l-aħjar mudell?**" billi
jgħaqqad il-katalgu ta' kull fornitur b'xejn ma' **punteġġi ta' kwalità miġbura mill-massa** mil-
**leaderboard ta' Arena AI** (ELO bbażat fuq il-preferenzi umani, l-istess idea wara l-arena
tal-chatbot LMArena). Il-fornituri imbagħad jiġu rrankjati skont is-saħħa tal-**aħjar mudell b'xejn** tagħhom.

Ir-ranking jiġi kkalkulat minn tliet sorsi reali:

1. Il-listi tal-fornituri b'xejn — `NOAUTH_PROVIDERS`, flimkien ma' entrati ta'
   `OAUTH_PROVIDERS` / `APIKEY_PROVIDERS` bil-flag `hasFree`
   (`src/shared/constants/providers.ts`).
2. Il-katalgu tal-mudelli ta' kull fornitur mir-reġistru tal-fornituri
   (`open-sse/config/providerRegistry.ts`).
3. Punteġġi ta' idoneità għall-kompiti derivati mill-ELO, maħżuna fit-tabella
   `model_intelligence` tad-DB mill-magna ta' sinkronizzazzjoni tal-Arena ELO
   (`src/lib/arenaEloSync.ts`).

Il-loġika tal-join tinsab fi `src/lib/freeProviderRankings.ts`.

## Kif Taċċessah

### Paġna tad-dashboard

Iftaħ id-dashboard u mur fuq **Spejjeż → Klassifikazzjonijiet tal-Fornituri Bla Ħlas**, jew innaviga direttament lejn:

```
/dashboard/free-provider-rankings
```

Il-paġna (`src/app/(dashboard)/dashboard/free-provider-rankings/page.tsx`) turi:

- **Podju tal-aqwa 3** (🥇 🥈 🥉) fornituri bla ħlas bl-ogħla klassifikazzjoni.
- **Tabella tal-klassifikazzjoni** sħiħa bil-kolonni: **Pożizzjoni**, **Fornitur**, **L-Aqwa Mudell**,
  **Punteġġ**, **Punteġġ Medju**, **Mudelli**, **Tip**.
- **Buttuni tal-filtru tal-kategoriji**: _Il-Kategoriji Kollha_, _Predefinita_, _Kodifikazzjoni_, _Reviżjoni_,
  _Dokumentazzjoni_, _Debugging_.

Il-badge tat-**Tip** ta’ kull fornitur tindika kif dan huwa bla ħlas:

| Badge    | Tifsira                                            |
| -------- | -------------------------------------------------- |
| `NOAUTH` | Dejjem bla ħlas, ma huma meħtieġa ebda kredenzjali |
| `OAUTH`  | Fornitur OAuth b’livell bla ħlas (`hasFree`)       |
| `APIKEY` | Fornitur b’API key u b’livell bla ħlas (`hasFree`) |

Il-punteġġi jintwerew bħala tikketti li jinqraw faċilment mill-bniedem (eż. _Elite_, _Eċċellenti_, _Tajjeb Ħafna_,
_Tajjeb_, _Medju_) minflok bħala numri mhux ipproċessati, għax il-valur sottostanti huwa kwalità relattiva
tal-klassifikazzjoni, mhux perċentwal.

### Endpoint tal-API

Il-paġna hija appoġġata minn endpoint pubbliku tal-qari
(`src/app/api/free-provider-rankings/route.ts`):

```
GET /api/free-provider-rankings
GET /api/free-provider-rankings?category=coding
GET /api/free-provider-rankings?category=coding&limit=20
```

Parametri tal-query (ivvalidati b’Zod):

| Parametru  | Tip    | Predefinit | Noti                                                                                                                     |
| ---------- | ------ | ---------- | ------------------------------------------------------------------------------------------------------------------------ |
| `category` | string | (xejn)     | Wieħed minn `default`, `coding`, `review`, `documentation`, `debugging`. Ħallih barra għall-klassifikazzjoni kkombinata. |
| `limit`    | number | `50`       | Limitat għall-firxa `1–100`.                                                                                             |

Struttura tar-rispons:

```json
{
  "rankings": [
    {
      "id": "<provider-id>",
      "name": "<provider name>",
      "icon": "<icon>",
      "color": "<hex color>",
      "textIcon": "<short label>",
      "category": "noauth | oauth | apikey",
      "topModel": {
        "modelId": "<registry model id>",
        "modelName": "<model display name>",
        "score": 0.0,
        "eloRaw": 0,
        "confidence": "high | medium | low",
        "category": "<task category>"
      },
      "averageScore": 0.0,
      "modelCount": 0
    }
  ]
}
```

`eloRaw` huwa l-valur ELO oriġinali ta’ Arena; `score` huwa l-valur normalizzat tal-adegwatezza
għall-kompitu (ara hawn taħt). Il-fornituri mingħajr mudelli b’punteġġ jitħallew barra mir-rispons.

## Kif Jaħdmu l-Punteġġi

### Sors: il-leaderboard ta' Arena AI

Il-magna tas-sinkronizzazzjoni tal-ELO ta' Arena (`src/lib/arenaEloSync.ts`) ġġib żewġ leaderboards — `text` u `code` — mill-API tal-leaderboard ta' Arena AI (`https://api.wulong.dev/arena-ai-leaderboards/v1/leaderboard`). Meta dik l-API ma tirritorna l-ebda leaderboard utilizabbli, il-magna taqbad l-alternattiva tad-dataset uffiċjali `lmarena-ai/leaderboard-dataset` fuq id-datasets-server ta' Hugging Face (`src/lib/arenaEloHfSource.ts`, CC-BY-4.0; `overall` → `text`, `coding` → `code`); `GET /api/intelligence/sync` jirrapporta `activeSource`, `lastError` u `lastFailedAt`. Kull daħla fil-leaderboard għandha isem tal-mudell, bejjiegħ, `score` ELO, intervall ta' kunfidenza, u għadd ta' voti.

Il-kategoriji tal-leaderboard jimmapjaw ma' kategoriji ta' kompiti ta' OmniRoute:

| Leaderboard ta' Arena | Kategoriji ta' kompiti ta' OmniRoute              |
| --------------------- | ------------------------------------------------- |
| `text`                | `default`, `review`, `documentation`, `debugging` |
| `code`                | `coding`                                          |

### Normalizzazzjoni (punteġġ ta' adegwatezza għall-kompitu)

Il-punteġġi ELO grezzi jiġu normalizzati għal kull leaderboard f'**valur ta' adegwatezza għall-kompitu fi `[0.4, 0.98]`**:

```
taskFit = 0.4 + 0.58 * ((elo - minElo) / (maxElo - minElo))
```

Il-punteġġ qatt ma jilħaq `0` jew `1`, u b'hekk jibqa' marġni għal sostituzzjonijiet (overrides) mill-utent. Dan huwa l-qasam `score` li tara fir-risposta tal-API u t-tikketta murija fuq id-dashboard.

### Kunfidenza

Kull daħla tingħata livell ta' kunfidenza bbażat fuq il-għadd tal-voti ta' Arena:

| Kunfidenza | Voti    |
| ---------- | ------- |
| `high`     | ≥ 5,000 |
| `medium`   | ≥ 1,000 |
| `low`      | < 1,000 |

### Ħażna u friskezza

Id-dħul innormalizzat jinkiteb fit-tabella `model_intelligence` tad-DB b'`source = "arena_elo"` (`src/lib/db/modelIntelligence.ts`). Id-dħul **jiskadi wara 7 ijiem**, sabiex fornitur li jieqaf isinkronizza eventwalment joħroġ mill-lista minflok ma jservi dejta skaduta.

Is-sinkronizzazzjoni taħdem **mixgħula by default**:

- Taħdem darba meta jibda s-server u mbagħad fuq timer perjodiku
  (`src/lib/arenaEloSync.ts`, imqabbad minn `src/instrumentation-node.ts`).
- Hija **mhux blokkanti u qatt fatali** — jekk il-fetch upstream ifalli, OmniRoute
  ikompli jaħdem u r-rankings sempliċement juru l-aħħar dejta tajba (jew stat vojt).

Żewġ varjabbli ambjentali jikkontrollawha (dokumentati fi
[`docs/reference/ENVIRONMENT.md`](../reference/ENVIRONMENT.md)):

| Varjabbli                 | Default       | Skop                                                                         |
| ------------------------- | ------------- | ---------------------------------------------------------------------------- |
| `ARENA_ELO_SYNC_ENABLED`  | `true`        | Issettjaha `false` biex tagħżel li ma issirx is-sinkronizzazzjoni 'il barra. |
| `ARENA_ELO_SYNC_INTERVAL` | `86400` (24h) | L-intervall tas-sinkronizzazzjoni, f'sekondi.                                |

### Sinkronizzazzjoni manwali / status / tħassir

Għall-operaturi, endpoint maniġerjali awtentikat jesponi kontroll manwali
(`src/app/api/intelligence/sync/route.ts` — jeħtieġ awtentikazzjoni maniġerjali):

```
GET    /api/intelligence/sync          # l-istatus attwali tas-sinkronizzazzjoni (enabled, lastSync, nextSync, intervalMs)
POST   /api/intelligence/sync          # ibda sinkronizzazzjoni manwali; body: { "dryRun": true } biex tipprevedi mingħajr ma tikteb
DELETE /api/intelligence/sync          # ħassar id-dħul kollu ta' intelligence arena_elo misinkronizzat
```

Jekk il-paġna tar-rankings tkun vojta, `POST /api/intelligence/sync` manwali (jew
sempliċement li terġa' tibda s-server) terġa' timliha.

### It-tqabbid tal-mudelli mal-leaderboard

L-IDs tal-mudelli fir-reġistru u l-ismijiet tal-mudelli ta' Arena mhux dejjem jaqblu eżattament. Ir-ranking juża tqabbid flessibbli (`findMatchingIntelligence` fi `src/lib/freeProviderRankings.ts`):

1. Tqabbid eżatt fuq l-ID normalizzat tal-mudell.
2. Tqabbid wara li jitneħħa suffiss ta' verżjoni fi tmiem l-isem (eż. `kimi-k2.6` → `kimi-k2`).
3. Tqabbid ta' prefiss (isem ta' mudell fil-leaderboard huwa prefiss tal-ID fir-reġistru).

Fin-naħa tas-sinkronizzazzjoni, il-prefissi magħrufa tal-bejjiegħa (`anthropic/`, `openai/`, `google/`, …) jitneħħew u mappa żgħira ta' alias tespandi l-ismijiet kanoniċi fil-varjanti li OmniRoute juża internament, sabiex il-mudelli jibqgħu jinstabu taħt kwalunkwe isem.

### Kif jiġi rrankjat fornitur

Għal kull fornitur b'xejn, il-magna tagħti punteġġ lil kull mudell fil-katalgu tiegħu, u mbagħad:

- **L-Aqwa Mudell** = il-mudell bl-ogħla punteġġ tal-fornitur.
- **Punteġġ Medju** = il-punteġġ medju fuq il-mudelli kollha skorjati ta' dak il-fornitur.
- **Mudelli** = kemm-il mudell tal-fornitur kellu punteġġ ta' Arena.

Il-fornituri jiġu rrankjati l-ewwel skont il-**punteġġ tal-aqwa mudell**, u mbagħad skont il-punteġġ medju. Dan jippremja fornitur li joffri mill-inqas mudell wieħed qawwi b'xejn.

## Kif Tużah biex Tagħżel Fornituri Bla Ħlas

1. **Agħżel il-kategorija t-tajba.** Uża l-filtru **Coding** għal xogħlijiet aġentiċi/ta' kodifikazzjoni, jew
   ħallih fuq **All Categories** / **Default** għal konverżazzjoni ġenerali. L-istess fornitur jista'
   jikklassifika b'mod differenti bejn il-kategoriji għax l-aqwa mudell tiegħu jvarja skont il-klassifika.
2. **Ippreferi l-podju għal konfigurazzjonijiet ta' darba.** Jekk trid tikkonnettja biss fornitur wieħed jew tnejn bla
   ħlas, ibda b'dawk fl-ogħla pożizzjonijiet għall-kategorija tiegħek.
3. **Iċċekkja l-badge tat-Tip.** Il-fornituri `NOAUTH` huma l-aktar veloċi biex tikkonnettjahom (mingħajr
   kredenzjali). Il-pjanijiet bla ħlas `OAUTH` / `APIKEY` jeħtieġu reġistrazzjoni malajr iżda spiss joffru
   mudelli aktar b'saħħithom. Ara l-[Gwida għall-Pjanijiet Bla Ħlas](../getting-started/FREE-TIERS-GUIDE.md) għall-
   passi tal-konnessjoni.
4. **Ikkonnettja diversi fornituri u ħalli lil Auto-Combo jiddeċiedi.** L-istess data ta' Arena ELO li tħaddem
   din il-paġna tintuża wkoll mill-**fattur tal-adegwatezza għall-kompitu** tal-magna ta' punteġġ Auto-Combo
   (`open-sse/services/autoCombo/taskFitness.ts`, ordni tar-
   riżoluzzjoni `user_override → arena_elo → models_dev_tier → static table`). Għalhekk, wara li tikkonnettja
   l-aqwa fornituri bla ħlas, ir-routing b'`model: "auto"` (eż. `auto/coding`) awtomatikament
   jippreferi l-mudelli bla ħlas ta' kwalità ogħla għal kull talba. Ara
   [Auto-Combo](../routing/AUTO-COMBO.md) għall-punteġġ sħiħ b'16-il fattur.
