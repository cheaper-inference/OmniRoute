> **Fil-qosor**: OmniRoute jikklassifika l-fornituri **bla ħlas** tiegħu skont il-kwalità tal-mudell billi juża **punteġġi ELO ta’ Arena AI
> (stil LMArena)**. Iftaħ il-paġna **Klassifikazzjonijiet tal-Fornituri Bla Ħlas** fid-
> dashboard biex tara liema fornituri bla ħlas joffru l-aktar mudelli b’saħħithom għall-kompitu tiegħek —
> b’mod ġenerali, jew iffiltrati skont il-kategorija (kodifikazzjoni, reviżjoni, dokumentazzjoni, debugging).

## X'Inhu

OmniRoute jirreġistra 376 fornitur, inklużi 155 entrata fil-katalgu mmarkati bħala **b'xejn/mingħajr awtentikazzjoni**
(mingħajr awtentikazzjoni,
OAuth b'livell bla ħlas, jew kjavi tal-API b'livell bla ħlas — ara l-
[Gwida għal-Livelli Bla Ħlas](../getting-started/FREE-TIERS-GUIDE.md) u d-
[Direttorju sħiħ tal-Livelli Bla Ħlas](../reference/FREE_TIERS.md)). Il-problema: il-fornituri bla ħlas ivarjaw
ħafna fil-kwalità tal-mudelli. Fornitur mingħajr awtentikazzjoni li joffri mudell mill-aktar avvanzat huwa ferm aktar utli
minn wieħed li joffri mudell żgħir u antik.

**Klassifiki tal-Fornituri Bla Ħlas** iwieġeb il-mistoqsija "**liema fornitur bla ħlas jagħtini l-aħjar mudell?**" billi
jgħaqqad il-katalgu ta' kull fornitur bla ħlas ma' **punteġġi tal-kwalità miġbura mill-komunità** mil-
**leaderboard ta' Arena AI** (ELO ibbażat fuq il-preferenzi tal-bnedmin, l-istess idea wara l-arena taċ-chatbots
LMArena). Il-fornituri mbagħad jiġu kklassifikati skont il-kapaċità tal-**aħjar mudell bla ħlas** tagħhom.

Il-klassifika tiġi kkalkolata minn tliet sorsi reali:

1. Il-listi tal-fornituri bla ħlas — `NOAUTH_PROVIDERS`, flimkien mal-entrati ta' `OAUTH_PROVIDERS` /
   `APIKEY_PROVIDERS` immarkati b'`hasFree`
   (`src/shared/constants/providers.ts`).
2. Il-katalgu tal-mudelli ta' kull fornitur mir-reġistru tal-fornituri
   (`open-sse/config/providerRegistry.ts`).
3. Punteġġi tal-adegwatezza għall-kompiti derivati mill-ELO u maħżuna fit-tabella `model_intelligence` tad-DB mill-
   magna tas-sinkronizzazzjoni tal-ELO ta' Arena (`src/lib/arenaEloSync.ts`).

Il-loġika tal-unjoni tinsab f'`src/lib/freeProviderRankings.ts`.

## Kif Taċċessah

### Paġna tad-dashboard

Iftaħ id-dashboard u mur fuq **Spejjeż → Klassifikazzjonijiet tal-Fornituri Bla Ħlas**, jew innaviga direttament lejn:

```
/dashboard/free-provider-rankings
```

Il-paġna (`src/app/(dashboard)/dashboard/free-provider-rankings/page.tsx`) turi:

- **Podju tal-aqwa 3** (🥇 🥈 🥉) fornituri bla ħlas bl-ogħla klassifikazzjoni.
- **Tabella tal-klassifikazzjoni** sħiħa bil-kolonni: **Pożizzjoni**, **Fornitur**, **L-Aqwa Mudell**,
  **Punteġġ**, **Punteġġ Medju**, **Mudelli**, **Tip**.
- **Buttuni tal-filtru tal-kategoriji**: _Il-Kategoriji Kollha_, _Predefinita_, _Kodifikazzjoni_, _Reviżjoni_,
  _Dokumentazzjoni_, _Debugging_.

Il-badge tat-**Tip** ta’ kull fornitur tindika kif dan huwa bla ħlas:

| Badge    | Tifsira                                            |
| -------- | -------------------------------------------------- |
| `NOAUTH` | Dejjem bla ħlas, ma huma meħtieġa ebda kredenzjali |
| `OAUTH`  | Fornitur OAuth b’livell bla ħlas (`hasFree`)       |
| `APIKEY` | Fornitur b’API key u b’livell bla ħlas (`hasFree`) |

Il-punteġġi jintwerew bħala tikketti li jinqraw faċilment mill-bniedem (eż. _Elite_, _Eċċellenti_, _Tajjeb Ħafna_,
_Tajjeb_, _Medju_) minflok bħala numri mhux ipproċessati, għax il-valur sottostanti huwa kwalità relattiva
tal-klassifikazzjoni, mhux perċentwal.

### Endpoint tal-API

Il-paġna hija appoġġata minn endpoint pubbliku tal-qari
(`src/app/api/free-provider-rankings/route.ts`):

```
GET /api/free-provider-rankings
GET /api/free-provider-rankings?category=coding
GET /api/free-provider-rankings?category=coding&limit=20
```

Parametri tal-query (ivvalidati b’Zod):

| Parametru  | Tip    | Predefinit | Noti                                                                                                                     |
| ---------- | ------ | ---------- | ------------------------------------------------------------------------------------------------------------------------ |
| `category` | string | (xejn)     | Wieħed minn `default`, `coding`, `review`, `documentation`, `debugging`. Ħallih barra għall-klassifikazzjoni kkombinata. |
| `limit`    | number | `50`       | Limitat għall-firxa `1–100`.                                                                                             |

Struttura tar-rispons:

```json
{
  "rankings": [
    {
      "id": "<provider-id>",
      "name": "<provider name>",
      "icon": "<icon>",
      "color": "<hex color>",
      "textIcon": "<short label>",
      "category": "noauth | oauth | apikey",
      "topModel": {
        "modelId": "<registry model id>",
        "modelName": "<model display name>",
        "score": 0.0,
        "eloRaw": 0,
        "confidence": "high | medium | low",
        "category": "<task category>"
      },
      "averageScore": 0.0,
      "modelCount": 0
    }
  ]
}
```

`eloRaw` huwa l-valur ELO oriġinali ta’ Arena; `score` huwa l-valur normalizzat tal-adegwatezza
għall-kompitu (ara hawn taħt). Il-fornituri mingħajr mudelli b’punteġġ jitħallew barra mir-rispons.

## Kif Jaħdmu l-Punteġġi

### Sors: il-leaderboard ta' Arena AI

Il-magna tas-sync tal-ELO ta' Arena (`src/lib/arenaEloSync.ts`) ġġib żewġ leaderboards —
`text` u `code` — mill-API tal-leaderboard ta' Arena AI
(`https://api.wulong.dev/arena-ai-leaderboards/v1/leaderboard`). Meta dik l-API ma
tirritorna l-ebda bord utilizzabbli, il-magna terġa' lura għall-`lmarena-ai/leaderboard-dataset`
uffiċjali fuq id-datasets-server ta' Hugging Face (`src/lib/arenaEloHfSource.ts`, CC-BY-4.0;
`overall` → `text`, `coding` → `code`); `GET /api/intelligence/sync` jirrapporta
`activeSource`, `lastError` u `lastFailedAt`. Kull daħla tal-leaderboard
ġġorr isem tal-mudell, vendor, `score` ELO, intervall ta' kunfidjenza, u għadd ta' voti.

Il-kategoriji tal-leaderboard jiġu mapped għall-kategoriji tal-kompiti ta' OmniRoute:

| Leaderboard ta' Arena | Kategoriji tal-kompiti ta' OmniRoute              |
| --------------------- | ------------------------------------------------- |
| `text`                | `default`, `review`, `documentation`, `debugging` |
| `code`                | `coding`                                          |

### Normalizzazzjoni (punteġġ tas-suitabilità għall-kompit)

Il-punteġġi ELO grezzi jiġu normalizzati għal kull leaderboard f'**valur ta' suitabilità
għall-kompit f'`[0.4, 0.98]`**:

```
taskFit = 0.4 + 0.58 * ((elo - minElo) / (maxElo - minElo))
```

Il-punteġġ qatt ma jilħaq `0` jew `1`, u b'hekk jħalli spazju għal overrides mill-utent.
Dan huwa l-kamp `score` li tara fir-rispons tal-API u t-tikketta murija fuq id-dashboard.

### Kunfidjenza

Kull daħla tirċievi livell ta' kunfidjenza ibbażat fuq l-għadd ta' voti ta' Arena:

| Kunfidjenza | Voti    |
| ----------- | ------- |
| `high`      | ≥ 5,000 |
| `medium`    | ≥ 1,000 |
| `low`       | < 1,000 |

### Ħażna u friskatezza

Id-dħul normalizzat jinkiteb fit-tabella DB `model_intelligence` b'`source = "arena_elo"`
(`src/lib/db/modelIntelligence.ts`). Id-dħul **jiskadi wara 7 ijiem**, għalhekk provider li
jieqaf is-sync eventwalment joħroġ milli jitfa' minflok iservi dejta skaduta.

Is-sync jaħdem **mixgħul b'mod awtomatiku**:

- Jaħdem darba fl-istartjar tas-server u mbagħad fuq timer perjodiku
  (`src/lib/arenaEloSync.ts`, imqabbad minn `src/instrumentation-node.ts`).
- Huwa **mhux blokkanti u qatt mhux fatali** — jekk il-fetch mill-upstream ifalli, OmniRoute
  ikompli jaħdem u r-ankings sempliċement juru l-aħħar dejta tajba (jew stat vojt).

Żewġ varjabbli ambjentali jikkontrollawh (dokumentati f'
[`docs/reference/ENVIRONMENT.md`](../reference/ENVIRONMENT.md)):

| Varjabbli                 | Default       | Skop                                                 |
| ------------------------- | ------------- | ---------------------------------------------------- |
| `ARENA_ELO_SYNC_ENABLED`  | `true`        | Issettja għal `false` biex toħroġ mis-sync outbound. |
| `ARENA_ELO_SYNC_INTERVAL` | `86400` (24h) | Intervall tas-sync, f'sekondi.                       |

### Sync manwali / status / tneħħija

Għall-operaturi, endpoint ta' ġestjoni awtentikat jesponi kontroll manwali
(`src/app/api/intelligence/sync/route.ts` — jeħtieġ awtentikazzjoni ta' ġestjoni):

```
GET    /api/intelligence/sync          # status attwali tas-sync (enabled, lastSync, nextSync, intervalMs)
POST   /api/intelligence/sync          # iqajjem sync manwali; body: { "dryRun": true } biex tara mingħajr ma tikteb
DELETE /api/intelligence/sync          # neħħi d-dħul kollha ta' arena_elo issinkronizzat
```

Jekk il-paġna tar-rankings tkun vojta, `POST /api/intelligence/sync` manwali (jew
sempliċement terġa' tibda s-server) jimlaha mill-ġdid.

### Tqabbil tal-mudelli mal-leaderboard

L-IDs tal-mudelli tar-reġistru u l-ismijiet tal-mudelli ta' Arena mhux dejjem jaqblu
eżattament. Ir-ranking juża tqabbil flessibbli (`findMatchingIntelligence` f'
`src/lib/freeProviderRankings.ts`):

1. Tqabbil eżatt fuq l-ID tal-mudell normalizzat.
2. Tqabbil wara t-tneħħija ta' suffiss ta' verżjoni fit-tmiem (eż. `kimi-k2.6` → `kimi-k2`).
3. Tqabbil b'prefiss (isem ta' mudell fil-leaderboard huwa prefiss tal-ID tar-reġistru).

Min-naħa tas-sync, prefissi magħrufa ta' vendors (`anthropic/`, `openai/`, `google/`, …)
jitneħħew u mappa żgħira ta' alias tespandi l-ismijiet kanoniċi fil-varjanti li OmniRoute
juża internament, sabiex il-mudelli jibqgħu jinstabu taħt kwalunkwe isem.

### Kif jiġi rrankat provider

Għal kull provider b'xejn, il-magna tagħti punteġġ lil kull mudell fil-katalgu tiegħu, u mbagħad:

- **Top Model** = il-mudell bl-ogħla punteġġ tal-provider.
- **Avg Score** = il-medja tal-punteġġi fost il-mudelli kollha skorjati ta' dak il-provider.
- **Models** = kemm mudelli tal-provider kellhom punteġġ ta' Arena.

Il-providers jiġu rranġati bl-**punteġġ tal-aqwa mudell** l-ewwel, u mbagħad bil-punteġġ
medju. Dan jippremja provider li joffri mill-inqas mudell wieħed b'xejn u b'saħħtu.

## Kif Tużah biex Tagħżel Fornituri Bla Ħlas

1. **Agħżel il-kategorija t-tajba.** Uża l-filtru **Coding** għal xogħlijiet aġentiċi/ta' kodifikazzjoni, jew
   ħallih fuq **All Categories** / **Default** għal konverżazzjoni ġenerali. L-istess fornitur jista'
   jikklassifika b'mod differenti bejn il-kategoriji għax l-aqwa mudell tiegħu jvarja skont il-klassifika.
2. **Ippreferi l-podju għal konfigurazzjonijiet ta' darba.** Jekk trid tikkonnettja biss fornitur wieħed jew tnejn bla
   ħlas, ibda b'dawk fl-ogħla pożizzjonijiet għall-kategorija tiegħek.
3. **Iċċekkja l-badge tat-Tip.** Il-fornituri `NOAUTH` huma l-aktar veloċi biex tikkonnettjahom (mingħajr
   kredenzjali). Il-pjanijiet bla ħlas `OAUTH` / `APIKEY` jeħtieġu reġistrazzjoni malajr iżda spiss joffru
   mudelli aktar b'saħħithom. Ara l-[Gwida għall-Pjanijiet Bla Ħlas](../getting-started/FREE-TIERS-GUIDE.md) għall-
   passi tal-konnessjoni.
4. **Ikkonnettja diversi fornituri u ħalli lil Auto-Combo jiddeċiedi.** L-istess data ta' Arena ELO li tħaddem
   din il-paġna tintuża wkoll mill-**fattur tal-adegwatezza għall-kompitu** tal-magna ta' punteġġ Auto-Combo
   (`open-sse/services/autoCombo/taskFitness.ts`, ordni tar-
   riżoluzzjoni `user_override → arena_elo → models_dev_tier → static table`). Għalhekk, wara li tikkonnettja
   l-aqwa fornituri bla ħlas, ir-routing b'`model: "auto"` (eż. `auto/coding`) awtomatikament
   jippreferi l-mudelli bla ħlas ta' kwalità ogħla għal kull talba. Ara
   [Auto-Combo](../routing/AUTO-COMBO.md) għall-punteġġ sħiħ b'16-il fattur.
