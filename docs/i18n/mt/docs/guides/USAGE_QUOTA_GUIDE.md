## Ħarsa Ġenerali

Kull talba li tgħaddi minn OmniRoute tiġġenera **rekord tal-użu** li jiġbor:

- **Identità**: liema ċavetta API, fornitur, mudell u kombinazzjoni
- **Tokens**: tokens tal-prompt, tokens tat-tlestija, tokens fil-cache u t-total
- **Spiża**: ammont f’USD (ikkalkulat mid-data tal-prezzijiet)
- **Ħinijiet**: latenza u timestamps tal-bidu/tmiem
- **Status**: suċċess, żball, limitazzjoni tar-rata, eċċ.

Dawn ir-rekords jiġu aggregati f’**analitika**, maħżuna bħala **snapshots tal-kwota**, u użati biex jiġu infurzati **limiti tal-baġit għal kull ċavetta**.

```
Talba ──▶ chatCore ──▶ usage.record() ──▶ SQLite
                                  │
                          ┌───────┼───────┐
                          ▼       ▼       ▼
                    analitika  kwota   fatturazzjoni
                    (dashboard) (infurzar) (esportazzjoni)
```

### Minn Fejn Jiġu t-Tokens

It-tokens jiġu estratti mit-tweġiba tal-fornitur upstream fil-**handler tat-tweġiba**:

```ts
// Minn open-sse/handlers/chatCore.ts
const response = await providerExecutor.execute(provider, request);
const usage = response.usage || {
  prompt_tokens: 0,
  completion_tokens: 0,
  cached_tokens: 0,
};
```

Għall-fornituri li ma jirritornawx data dwar l-użu (xi fornituri web-cookie), OmniRoute **jistma** t-tokens permezz tal-ewristika `~4 chars per token` (ara `open-sse/services/autoCombo/pipelineRouter.ts`).

### Tokens fil-Cache

OmniRoute jsegwi `cached_tokens` separatament minn `prompt_tokens` għaliex:

- Il-caching tal-prompts ta’ Anthropic jiġi ċċarġjat b’rata mnaqqsa għat-tokens fil-cache (10% tar-rata normali)
- Xi fornituri jirritornaw `cache_read_input_tokens` li għandhom jiġu pprezzati b’mod differenti
- L-analitika tista’ turi r-**rata ta’ suċċess tal-cache** = `cached_tokens / prompt_tokens`

### Dijanjostika tal-livelli tal-kitbiet fil-cache

Il-pannell tas-saħħa tal-cache tal-prompts fid-dashboard tal-Analitika jiddistingwi bejn
kitbiet fil-cache ta’ 5 minuti u ta’ siegħa rrapportati mill-fornitur. Il-valuri ta’ Anthropic
`usage.cache_creation.ephemeral_5m_input_tokens` u
`usage.cache_creation.ephemeral_1h_input_tokens` jinżammu matul it-traduzzjoni tad-data tal-użu bi streaming u
mingħajr streaming u jinħażnu mas-sommarji tar-reġistru tas-sejħiet. It-total ikkombinat
tal-kitbiet fil-cache ma jiżdiedx ma’ dawk il-kategoriji għat-tieni darba.

Sejħiet li għandhom biss kontatur ikkombinat tal-kitbiet, inklużi rekords eqdem, għandhom livell
mhux magħruf. Tqassim parzjali jżomm il-bqija mhux assenjat bħala mhux magħruf; kontaturi invalidi jew
konfliġġenti jiġu mmarkati minflok ma jiġu assenjati TTL mingħajr avviż. Markaturi tat-TTL min-naħa tat-talba
mhumiex evidenza ta’ livell fatturat.

L-istima tal-kitbiet ekwivalenti għall-API fil-pannell tkopri biss livelli rrapportati u pprezzati, mhux
it-talba kollha. Għall-ipprezzar nattiv tal-mudelli Claude/Anthropic, tuża 1.25 darbiet
ir-rata tal-input għal kitbiet ta’ 5 minuti u d-doppju tar-rata tal-input għal kitbiet ta’ siegħa. Prezzijiet
neqsin jitqiesu bħala mhux disponibbli, mhux żero. Il-prezzijiet jinqabdu meta tiġi rreġistrata kull sejħa ġdida;
ir-rekords storiċi ma jerġgħux jiġu pprezzati. Għalhekk, kontijiet b’abbonament jista’ jkollhom
stima ekwivalenti għall-API mingħajr ma jġarrbu dak l-ammont bħala spiża fi flus jew bħala kwota
tal-abbonament. Il-kalkoli eżistenti tal-kwota, tal-baġit u tal-ispejjeż eżatti tal-fornitur jibqgħu l-istess.

Din id-dijanjostika tuża s-sommarju eżistenti tas-saħħa tal-cache b’limiti definiti u ż-żamma
tar-reġistru tas-sejħiet. Ma tbiddilx il-valuri prestabbiliti tat-TTL tat-talbiet, ir-routing jew l-għażla tal-kont.
Il-qbid tat-TTL mitlub mill-klijent meta mqabbel mat-TTL effettiv li joħroġ fil-punt
fejn tintbagħat it-talba lill-fornitur huwa pospost; dan il-pannell jirrapporta l-livelli skont l-irċevuti, mhux it-TTL effettiv li joħroġ.

Implimentazzjoni: `src/lib/usage/cacheWriteEstimate.ts`,
`src/lib/usage/cacheHealth.ts`, u `open-sse/utils/cacheWriteUsage.ts`.

## Kalkolu tal-Ispejjeż

L-ispejjeż jiġu kkalkolati minn **data tal-ipprezzar** sinkronizzata minn LiteLLM (`src/lib/pricingSync.ts`):

| Mudell            | Input $/1M | Output $/1M | Fil-cache $/1M |
| ----------------- | ---------- | ----------- | -------------- |
| gpt-5             | $2.50      | $10.00      | —              |
| claude-opus-4-6   | $15.00     | $75.00      | $1.50          |
| claude-sonnet-4-5 | $3.00      | $15.00      | $0.30          |
| gemini-2.5-pro    | $1.25      | $10.00      | —              |

Il-formula tal-ispiża (`src/lib/usage/costCalculator.ts`):

```ts
cost =
  (prompt_tokens - cached_tokens) * input_price +
  cached_tokens * cached_price +
  completion_tokens * output_price;
```

> **Għaliex jitnaqqsu t-tokens fil-cache mill-prompt?** Il-porzjon fil-cache għandu prezz separat; jekk jiġi applikat il-prezz tal-input għall-prompt kollu, l-ispiża tingħadd iżżejjed.

### Sinkronizzazzjoni tal-Ipprezzar

Id-data tal-ipprezzar tiġi sinkronizzata awtomatikament minn LiteLLM permezz tal-endpoint `/api/pricing/sync` (attivat mill-kompitu cron integrat, mhux minn varjabbli tal-ambjent għall-utent):

```bash
# Attivazzjoni manwali
curl -X POST http://localhost:20128/api/pricing/sync
```

Għal mudelli mingħajr data tal-ipprezzar, OmniRoute jirrikorri għal **stima tal-ispiża** bl-użu ta’ rati medji interni (meħuda mid-data tal-ipprezzar ta’ LiteLLM).

## Infurzar tal-Kwota

Il-kwota għal kull ċavetta API tiġi infurzata f’żewġ postijiet:

1. **Limitu ta’ twissija** (`quotaWarnAt`): twissija fid-dashboard meta l-użu jaqbeż is-soll
2. **Limitu strett** (`quotaLimit`): it-talba tiġi miċħuda b’HTTP 429 meta jinqabeż

### Konfigurazzjoni

```ts
// Għal kull ċavetta API
await updateApiKey(keyId, {
  quotaWarnAt: 5_00,    // $5.00 — uri twissija
  quotaLimit: 10_00,    // $10.00 — waqfien strett
  quotaWindow: "month", // "day" | "week" | "month" | "all"
});
````

### Fluss tal-Infurzar

```
Request ──▶ quotaCheck()
              │
              ├── Within limit?  ──▶ allow
              │
              └── Over limit?  ──▶ 429 Too Many Requests
                                   with Retry-After header
```

### Istantanji tal-Kwota

It-tabella `quotaSnapshots` taħżen **l-istat storiku tal-kwota** għall-analiżi tax-xejriet:

| Qasam | Deskrizzjoni |
| ----------- | -------------------------------- | ------ | ------- |
| `apiKeyId` | Iċ-ċavetta li qed tiġi mmonitorjata |
| `window` | "day" | "week" | "month" |
| `used` | Spiża użata f’dan il-perjodu (ċenteżmi) |
| `limit` | Il-limitu (ċenteżmi) |
| `resetAt` | Meta l-perjodu jerġa’ jibda |
| `createdAt` | Meta ttieħdet l-istantanja |

Jittieħdu istantanji **għal kull talba** li tuża spiża > 0, u jintużaw biex:

- Tintwera l-istrixxa tal-progress tal-kwota fid-dashboard
- Jintwerew grafiki tax-xejra tal-kwota fuq 30 jum
- Jiġu attivati twissijiet meta l-użu joqrob lejn il-limitu

## Żamma u Tindif

Id-data tal-użu tikber b'~1-10KB għal kull talba. Fuq skala kbira, dan jista' jkun sinifikanti.

### Settings taż-Żamma

Iż-żamma tal-istorja tal-użu tiġi kkonfigurata permezz tas-Settings tad-Database fl-UI jew permezz ta' `/api/settings/database`.

B'mod awtomatiku, l-istorja tal-użu tinżamm għal **90 jum**.

### Tindif

Ir-rekords qodma jitnaddfu minn `src/lib/db/cleanup.ts`:

- Jiġi attivat mill-proċess cron fl-isfond
- Iħassar rekords minn `usage_history` li jkunu eqdem mill-perjodu taż-żamma kkonfigurat fis-setting `usageHistory`

### Stima tal-Ħażna

| Rata tat-talbiet  | Ħażna għal 30 jum | Ħażna għal 90 jum |
| ----------------- | ----------------- | ----------------- |
| 100 talba/jum     | ~3MB              | ~9MB              |
| 1,000 talba/jum   | ~30MB             | ~90MB             |
| 10,000 talba/jum  | ~300MB            | ~900MB            |
| 100,000 talba/jum | ~3GB              | ~9GB              |

Għal traffiku għoli ħafna, ikkunsidra:

- Li tnaqqas il-perjodu taż-żamma permezz tas-Settings tad-Database
- Li tuża `aggregated_metrics` minflok rekords mhux ipproċessati (għall-analitika biss)

## Suġġerimenti għall-Ottimizzazzjoni tal-Ispejjeż

### 1. Uża l-Mudell it-Tajjeb

```bash
# Tweġiba malajr — uża mudell irħis + veloċi
curl -d '{"model":"auto/fast","messages":[...]}'

# Kompitu kumpless — uża mudell ta’ kwalità
curl -d '{"model":"auto/smart","messages":[...]}'
```

### 2. Attiva l-Caching

Il-caching tal-prompts ta’ Anthropic jiffranka **90% fuq kuntest ripetut**:

```ts
// Il-caching huwa awtomatiku — sempliċement inkludi l-istess prompt kbir tas-sistema
const response = await openai.chat({
  model: "claude-sonnet-4-5",
  system: longSystemPrompt, // Jinħażen fil-cache awtomatikament
  messages: [{ role: "user", content: "..." }],
});
```

### 3. Uża l-Kompressjoni

Il-kompressjoni RTK + Caveman tiffranka **15-95% fuq sessjonijiet b’użu intensiv ta’ għodod**:

```ts
const config = {
  compression: {
    engine: "rtk",
    intensity: "aggressive",
  },
};
```

### 4. Issettja Kwoti għal Kull Ċavetta

Dejjem issettja `quotaLimit` biex tevita spejjeż bla kontroll:

```ts
await updateApiKey(keyId, { quotaLimit: 10_00 }); // Limitu ta’ $10 fix-xahar
```

### 5. Ivverifika l-Akbar Konsumaturi

Uża d-dashboard jew **`/api/usage/analytics`** biex tiġbor skont iċ-ċavetta tal-API u tordna skont l-ispiża:

```bash
GET /api/usage/analytics?groupBy=apiKey
```

## Soluzzjoni tal-Problemi

### "L-ispiża hija ogħla milli mistenni"

1. Iċċekkja **`/api/usage/analytics?groupBy=model`** — sib il-mudell għali
2. Iċċekkja **`/api/usage/analytics?groupBy=apiKey`** — sib il-konsumatur b’użu intensiv
3. Ivverifika li d-data tal-prezzijiet hija aġġornata: `POST /api/pricing/sync`

### "Rekords neqsin"

- Iċċekkja s-settings taż-żamma tad-data fid-DB taħt Dashboard → Database → Tindif — ir-rekords qodma jitħassru mill-kompitu tat-tindif perjodiku (`src/lib/db/cleanup.ts`)
- Iċċekkja għal żbalji f’`src/lib/db/usage*.ts` — il-fallimenti tal-kitba fid-DB jiġu rreġistrati iżda ma jintwerewx
- Ivverifika li t-talba fil-fatt waslet għand `chatCore` — iċċekkja r-routing tal-combo

### "Il-kwota mhijiex qed tiġi infurzata"

- Iċċekkja s-setting `quotaLimit` taċ-ċavetta
- Ivverifika li `quotaWindow` huwa ssettjat sew
- Fittex rekords `quotaSnapshots` — għandhom jinħolqu ma’ kull talba
