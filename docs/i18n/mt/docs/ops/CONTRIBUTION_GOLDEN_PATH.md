Uża din il-gwida biex tagħżel l-iżgħar ċiklu ta’ żvilupp affidabbli għal pull request. Din ma
tissostitwixxix id-dokumenti tal-arkitettura u tas-sigurtà speċifiċi għall-qasam marbuta hawn taħt; tgħaqqad kull tip komuni
ta’ bidla mal-kuntratti tiegħu, mal-kontrolli mmirati, u mal-kopertura tas-CI.

## It-triq li ssegwi kull bidla

1. **Agħżel il-bażi qabel ma teditja.** Sib l-ogħla fergħa attiva `release/v*` u oħloq fergħa mill-aħħar
   commit tagħha. Immira lejn dik il-fergħa, mhux lejn `main`. Jekk ikun hemm waqfien temporanju ta’ release, timmirax lejn il-fergħa
   ffriżata; uża ċ-ċiklu attiv li jmiss deskritt f’
   [Mudell tal-Fergħat u tar-Release](BRANCHING_MODEL.md).
2. **Semmi l-kuntratti.** Identifika kull katalgu, schema, artifact iġġenerat, API pubblika, jew
   interfaċċa tal-utent li taffettwa l-bidla. It-tabella ta’ hawn taħt tagħti s-sett inizjali minimu.
3. **Ikteb jew aġġorna testijiet immirati.** Bidliet fil-produzzjoni f’`src/`, `open-sse/`, `electron/`, jew
   `bin/` jeħtieġu test awtomatizzat fl-istess PR. Ħaddem l-iżgħar fajls tat-test li jagħtu prova tal-
   imġiba, imbagħad il-kontrolli mmirati elenkati.
4. **Ħalli lis-CI jħaddem il-matriċi wiesgħa.** Is-shards kompluti tal-unit tests, Vitest, ir-ratchet tal-kopertura, u
   l-build tal-produzzjoni jitħaddmu fuq il-PR. Ħaddem suite wiesgħa lokalment biss meta falliment immirat jindika
   impatt usa’ jew meta l-bidla tinvolvi diversi sottosistemi.
5. **Irrikonċilja qabel ir-rieżami.** Iġbed il-bażi attiva, spezzjona l-commits ġodda tagħha u d-diff tiegħek meta mqabbel
   magħha, imbagħad agħmel rebase jew merge tal-bażi skont il-fluss tax-xogħol tal-kontributuri. Solvi l-kunflitti tal-fajls
   iġġenerati u tal-katalgi mis-sors tagħhom, iġġenerahom mill-ġdid, erġa’ ħaddem iċ-ċiklu mmirat, u kkonferma li l-
   PR għadu jimmira lejn il-fergħa tar-release attiva.
6. **Irreġistra l-evidenza.** Fit-template tal-PR, elenka l-kmandi mħaddma, kull fajl tat-test miżjud jew mibdul,
   il-migrazzjonijiet jew il-feature flags, u kwalunkwe validazzjoni li għadha pendenti u ssir biss fis-CI.

## Mogħdijiet rakkomandati skont it-tip ta’ bidla

Il-kmandi ta’ hawn taħt huma kontrolli mmirati minimi, mhux permess biex taqbeż test li jkopri direttament l-
imġiba li bdilt.

### Provider

**Kuntratti**

- Id-definizzjoni tal-provider f’`src/shared/constants/providers/` u l-kompożizzjoni tagħha f’
  `src/shared/constants/providers.ts`.
- Il-mudelli u l-kapaċitajiet f’`open-sse/config/providerRegistry.ts` jew fil-fajls tar-reġistru estratti minnu.
- L-għażla tal-executor/translator, il-konfigurazzjoni tal-OAuth jew tal-API key, l-assets tad-dashboard, u r-referenza
  tal-provider iġġenerata fejn applikabbli.
- Il-kredenzjali pubbliċi jridu jużaw `resolvePublicCred()`; it-tweġibiet ta’ żball iridu jużaw il-helpers kondiviżi
  għas-sanitizzazzjoni tal-iżbalji. Ara `docs/security/PUBLIC_CREDS.md` (git; mhux ikkompilat f’`/docs`) u
  [Sanitizzazzjoni tal-Iżbalji](../security/ERROR_SANITIZATION.md).

**Ċiklu mmirat**

```bash
npm run check:provider-consistency
npm run check:provider-assets
node --import tsx/esm --test tests/unit/provider-translate-path-golden.test.ts
node --import tsx/esm --test tests/unit/<provider-or-executor>.test.ts
npm run gen:provider-reference   # meta jinbidel il-katalgu; ikkommetti d-diff iġġenerat
npm run lint
```

Ittestja wkoll kull familja ta’ requests affettwata: chat, Responses, images, embeddings, audio, jew video.
Irrevedi d-diffs tal-katalgu ġġenerat u dawk golden bħala bidliet fil-kuntratt; taċċettahomx bl-addoċċ.

### Routing

**Kuntratti**

- Il-valuri pubbliċi tal-istrateġiji u l-metadata tal-UI f’`src/shared/constants/routingStrategies.ts`.
- Id-dispatch u l-ordni taħt `open-sse/services/combo.ts` u `open-sse/services/combo/`.
- L-iskemi tal-combo, il-persistenza, l-istat tar-reżiljenza, il-kapaċitajiet tal-mudelli, u l-kontrolli tal-API/UI.
- [Magna Auto-Combo](../routing/AUTO-COMBO.md) u d-dokumentazzjoni dwar ir-reżiljenza meta tinbidel l-imġiba.

**Ċiklu mmirat**

```bash
node --import tsx/esm --test tests/unit/combo-<behavior>.test.ts
npm run test:combo:matrix        # bidliet fl-istrateġija jew fid-dispatch
npm run check:known-symbols      # bidliet fir-reġistrazzjoni tal-istrateġija
npm run lint
```

Uża lokalment testijiet deterministiċi b’upstream simulat. Smoke tests live tal-combo jeħtieġu kredenzjali u huma
manwali, mhux sostituti għas-CI.

### UI / UX

**Kuntratti**

- Ir-route/page ta’ Next.js u l-konfini tal-komponenti kondiviżi taħt `src/app/` u
  `src/shared/components/`.
- Il-forom tat-tweġibiet tal-API, l-istati ta’ loading/vojt/żball, l-imġiba tat-tastiera u tal-screen reader,
  il-layout responsiv, it-theming, u l-espansjoni tal-locale.
- Is-strings sors tal-UI bl-Ingliż f’`src/i18n/messages/en.json`; tagħmilx hard-coding ta’ copy ġdid għall-utent.

**Ċiklu mmirat**

```bash
node --import tsx --test tests/unit/dashboard/<feature>.test.ts
npx vitest run --config vitest.config.ts tests/unit/ui/<component>.test.tsx
npm run check:dashboard-typecheck
npm run lint
```

Ħaddem l-app għal bidliet fl-interazzjoni jew viżwali u ċċekkja kemm viewports dojoq kif ukoll wesgħin. Is-CI tħaddem il-
build tal-produzzjoni u suites usa’; l-imġiba viżwali xorta teħtieġ komponent immirat, Playwright,
jew kontroll manwali dokumentat adattat għall-bidla.

### i18n

**Kuntratti**

- `src/i18n/messages/en.json` huwa s-sors tal-UI; `config/i18n.json` huwa s-sors tal-locale.
- Il-katalgi tas-CLI jinsabu separatament taħt `bin/cli/locales/`.
- Żomm il-placeholders u t-tags tal-ICU eżattament kif inhuma. Tittraduċix ismijiet ta’ prodotti/providers/mudelli,
  ismijiet ta’ protokolli u headers, kmandi, identifikaturi ta’ code/JSON, URLs, varjabbli tal-ambjent, jew
  termini protetti bħal `OmniRoute`, `OAuth`, `MCP`, u `A2A`. Il-lista sors attwali tinsab f’
  `scripts/i18n/glossary/protected-terms.json`.

**Ċiklu mmirat**

```bash
npm run i18n:sync-ui:dry
npm run i18n:check-ui-coverage
npm run i18n:check-value-drift
npm run i18n:check-glossary
npm run check:cli-i18n          # meta jinbidlu strings/katalgi tas-CLI
npm run lint
```

Din hija gwida għas-sistema eżistenti, mhux stedina biex tespandi l-għodod jew il-mudell tal-keys tagħha.
Żomm il-patches tal-i18n limitati u preċiżi waqt li tkun qed titfassal is-sistema sostituttiva. Tħaddimx kmandi tat-traduzzjoni
li jsejħu servizzi esterni sakemm il-kompitu ma jkunx jeħtieġ b’mod espliċitu traduzzjonijiet iġġenerati u
tkun irrevedejt id-diff li jirriżulta.

### CLI

**Kuntratti**

- Kmandi u flags pubbliċi f’`bin/cli/`, kmandi API ġġenerati, kodiċijiet tal-ħruġ, stdout/stderr u
  strutturi tal-output JSON, l-imġiba tal-konfigurazzjoni/ambjent, u fajls inklużi fil-pakkett.
- Strings tas-CLI li jarahom l-utent iridu jużaw is-saff i18n tas-CLI u jżommu l-katalgi `en`/`pt-BR` allinjati.
- Żomm Node bħala l-ambjent ta’ eżekuzzjoni appoġġjat u ppreserva l-kuntratt tal-binarju ppubblikat.

**Ċiklu ffukat**

```bash
node --import tsx/esm --test tests/unit/cli/<command>.test.ts
npm run check:cli-i18n
npm run build:cli             # bidliet fis-CLI ġġenerat/ippakkjat
npm run check:pack-policy     # bidliet fl-interfaċċa tal-pakkett
npm run lint
```

Uża l-kmand eżatt f’direttorju temporanju tad-data meta l-imġiba tiddependi mill-parsing, mill-fajls, jew mill-istatus
tal-ħruġ. CI jwettaq il-verifiki usa’ tal-artefatt tal-pakkett u tal-ekosistema.

### Bażi tad-data

**Kuntratti**

- Moduli tad-dominju taħt `src/lib/db/`; importa moduli speċifiċi direttament (is-saff l-antik ta’ esportazzjoni mill-ġdid `localDb.ts` tneħħa).
- Migrazzjonijiet SQL innumerati u idempotenti taħt `src/lib/db/migrations/`, sikurezza tat-tranżazzjonijiet, imġiba
  tal-aġġornament, indiċijiet, u kull min isejjaħ u huwa affettwat mill-iskema.
- Ir-rotot u l-handlers qatt ma joħorġu SQL mhux ipproċessat direttament.

**Ċiklu ffukat**

```bash
npm run check:migration-numbering
npm run check:db-rules
node --import tsx/esm --test tests/unit/db/<domain>.test.ts
node --import tsx/esm --test tests/unit/db/migration-<number>.test.ts
npm run lint
```

Meta żżid migrazzjoni, ittestja kemm bażi tad-data ġdida kif ukoll aġġornament mill-iskema preċedenti. It-testijiet tal-bażi tad-data
jridu jagħlqu l-handles u jsejħu `resetDbInstance()` waqt it-tindif. Ħaddem `npm run test:bun:db` biss meta
tinbidel il-mogħdija tal-adapter Bun bl-aħjar sforz possibbli; Node jibqa’ l-awtorità.

### Bini / skjerament

**Kuntratti**

- Manifests/lockfile tal-għerq u tal-workspace, `scripts/build/`, assemblaġġ standalone ta’ Next.js, kontenut tal-pakkett
  `dist/`, metadata tal-pjattaforma Electron, workflows tas-CI, u sentinelli tal-iskjerament.
- Il-firxiet appoġġjati ta’ Node u l-użu ta’ Bun fil-lista ta’ permessi f’`CLAUDE.md` iridu jibqgħu intatti.
- L-artefatti tal-bini jibqgħu mhux traċċati; japplikaw il-politiki tad-dipendenzi, tal-liċenzji, tal-workflows, u tal-pakketti.

**Ċiklu ffukat**

```bash
node --import tsx/esm --test tests/unit/build/<behavior>.test.ts
npm run check:build-scope
npm run check:lockfile         # bidliet fid-dipendenzi jew fil-lockfile
npm run check:pack-policy      # bidliet fl-interfaċċa tal-pakkett ippubblikat
npm run lint
```

Uża `npm run build` lokalment biss meta l-bidla taffettwa l-kompilazzjoni, l-assemblaġġ standalone, l-assi,
jew l-ippakkjar waqt l-eżekuzzjoni. Uża `npm run build:release` biss għall-validazzjoni tar-rilaxx/skjerament. Il-build tas-CI huwa
s-sinjal finali bejn il-pjattaformi; bidliet ta’ Electron speċifiċi għal pjattaforma jeħtieġu l-build iffukat korrispondenti
jew evidenza minn test bażiku.

## Skripts għall-iżviluppaturi għal magna kondiviża

Żewġ għodod ta’ għajnuna f’`scripts/dev/` jikkodifikaw iċ-ċiklu lokali fuq devbox fejn ikunu attivi sessjonijiet oħra:

```bash
scripts/dev/typecheck-touched.sh --base release/vX.Y.Z   # fajls minn merge-base(HEAD, base)..HEAD
scripts/dev/typecheck-touched.sh src/a.ts tests/unit/b.test.ts   # eżattament dawn il-fajls
scripts/dev/new-worktree.sh fix/1234-slug release/vX.Y.Z  # worktree iżolat, sikur b’mod parallel
```

- `typecheck-touched.sh` jagħmel typecheck biss tal-fajls `.ts/.tsx` li ntmessu permezz ta’
  `tsconfig.touched.tmp.json` temporanju (`extends ./tsconfig.json`, `types: ["node"]`, `noEmit`,
  `incremental: false`) taħt heap ta’ 6 GB, għalhekk jissostitwixxi l-`tsc -p tsconfig.json`
  għall-proġett kollu li jispiċċa OOM fuq magna mgħobbija. Jistampa l-iżbalji fil-fajls li ntmessu
  flimkien ma’ linja waħda ta’ sommarju u joħroġ b’`1` għal żbalji fil-fajls li ntmessu, b’`2`
  meta l-uniċi żbalji jkunu f’fajls importati jew meta tsc ikun waqaf mingħajr dijanjostika
  (aqra l-log li jsemmi taħt `_artifacts/typecheck-touched/`), u b’`0` meta kollox ikun nadif.
  It-tsconfig temporanju dejjem jitneħħa; qatt tikkommettja wieħed.
- `new-worktree.sh` jissekwenzjalizza eżekuzzjonijiet konkorrenti fuq
  `<git-common-dir>/omniroute-new-worktree.lock` (jistenna sa 600 s b’mod awtomatiku, b’messaġġ
  viżibbli; l-intestatura tal-iskript tiddokumenta kif dan jista’ jiġi sostitwit) u jreġġa’
  lura l-branch li jkun ħoloq meta `git worktree add` ifalli qabel ma jkun jeżisti l-worktree,
  għalhekk tentattiv mill-ġdid ma jeħtieġx `git branch -D` manwali. Il-`node_modules` marbut
  b’hard link u l-kopja ta’ `.husky/_` jibqgħu l-istess.

## Ċiklu lokali tal-kandidat

It-testijiet tas-sors ma jistgħux jagħtu prova li l-artifatt ippakkjat jibda: il-listi tal-ippakkjar,
id-dipendenzi mnaqqsa u l-binarji nattivi jfallu biss wara li t-tarball jiġi installat u jinbeda.
`npm run dev:candidate` (`scripts/dev/candidate.mjs`) huwa n-naħa lokali tal-fluss ibni darba /
ivvalida / ippromwovi minn RFC #8084: jibni kandidat wieħed, jivvalida dak l-artifatt eżatt,
jippromwovih billi jibdel l-ismijiet tad-direttorji, u jreġġgħu lura meta l-islott promoss ifalli
l-kontroll tas-saħħa tiegħu.

```bash
npm run dev:candidate -- run --dry-run --json  # ipprintja l-pjan, tibdel xejn
npm run dev:candidate -- run                   # ibni + ivvalida + ippromwovi, treġġigħ lura awtomatiku
npm run dev:candidate -- build                 # npm pack + installa f’_artifacts/candidate/<id>/
npm run dev:candidate -- validate --id <id>    # ibda fuq port liberu, /api/health + /v1/models
npm run dev:candidate -- promote --id <id>     # <id> → current, current → previous
npm run dev:candidate -- rollback              # skambja current u previous
npm run dev:candidate -- run --from-tarball <file.tgz>  # erġa’ uża tarball mibni band’oħra (CI)
```

- **Ibni darba.** `build` jippakkja s-siġra attwali (jeħtieġ `dist/server.js`, għalhekk l-ewwel
  ħaddem `npm run build:release`) jew jikkopja `--from-tarball`, imbagħad jinstalla t-tarball
  f’prefix npm iżolat, minħabba li t-tarball ma fihx `node_modules`. L-id huwa x-sha qasir ta’
  `HEAD` (`-dirty` meta s-siġra jkollha bidliet lokali) jew `tgz-<sha256>` għal tarball. Id nadif
  li jkun diġà nbena jerġa’ jintuża minflok jinbena mill-ġdid; għaddi `--force` biex terġa’ tibnih.
- **Ivvalida l-pakkett, mhux is-sors.** `validate` jibda s-CLI installat
  (`serve --port <free port>`) b’`DATA_DIR=<candidate>/data` ġdid, sigrieti foloz, u
  `OMNIROUTE_API_KEY`, `STORAGE_ENCRYPTION_KEY` u `INITIAL_PASSWORD` tal-operatur imneħħija
  mill-ambjent, sabiex jivverifika l-qagħda keyless loopback ta’ installazzjoni ġdida. Jistenna li
  `GET /api/health` jirritorna 200, jirrikjedi li `GET /v1/models` jirritorna 200, iwaqqaf il-grupp
  tal-proċessi, u jirreġistra l-verdett f’`validation.json` flimkien mal-hash tat-tarball.
- **Ippromwovi l-istess artifatt.** `promote` jirrifjuta kandidat mingħajr validazzjoni li għaddiet
  għall-hash attwali tat-tarball tiegħu. L-islott attiv awtomatiku huwa
  `_artifacts/candidate/current`; `--target <dir>` jagħżel direttorju ieħor fuq l-istess filesystem,
  u l-islott preċedenti tiegħu jkun `<dir>.previous`. Kull bidla fl-isem hija atomika, u ħsara
  f’nofs il-proċess treġġa’ lura l-bidliet fl-ismijiet li jkunu diġà saru.
- **Erġa’ lura.** `run` jerġa’ jivvalida l-islott promoss u jerġa’ jiskambja `current` u `previous`
  meta dak il-kontroll ifalli. Kandidat li jfalli l-ewwel validazzjoni qatt ma jiġi promoss.

Kollox jinkiteb taħt `_artifacts/candidate/`, li huwa injorat minn git; installazzjoni eżistenti
ta’ OmniRoute u d-direttorju tad-data tagħha qatt ma jintmessu. Is-CLI promoss huwa
`_artifacts/candidate/current/prefix/bin/omniroute`; meta tużah, ibdieh bid-`DATA_DIR` tiegħek.
Kodiċijiet tal-ħruġ: `0` suċċess, `1` validazzjoni jew promozzjoni falluta, `2` żball fl-użu jew
build nieqes.

## Ċiklu lokali kontra CI

| Ħaddem lokalment għal kull patch                                                            | CI jipprovdi s-sinjal wiesa’                                                                           |
| ------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| Testijiet diretti tal-imġiba u l-punti ta’ kontroll tal-kategoriji t’hawn fuq               | Sett sħiħ ta’ testijiet unit maqsuma f’partijiet u testijiet sekwenzjali                               |
| `npm run lint`                                                                              | Settijiet ta’ Vitest u limiti progressivi tal-kopertura/kwalità                                        |
| Iċċekkja t-tipi jew ibni biss meta l-kuntratt affettwat jitlob dan                          | Bini għall-produzzjoni, sigurtà, dokumentazzjoni, dipendenzi, u punti ta’ kontroll tal-politika tal-PR |
| Interazzjoni manwali/kontrolli diretti biss meta l-awtomazzjoni ma tistax tipprova l-imġiba | Integrazzjoni bejn jobs u kontrolli tal-pjattaforma kkonfigurati mill-workflow                         |

Ċiklu ffukat li jirnexxi huwa evidenza dwar il-kuntratt mibdul, mhux prova li l-kontrolli mhux relatati tas-CI
se jgħaddu. Min-naħa l-oħra, tagħmilx kull bidla lokali tistenna l-matriċi sħiħa tar-repożitorju.

## Lista ta’ kontroll għar-rikonċiljazzjoni

Qabel ma titlob rieżami:

- Ikkonferma li l-bażi tal-PR għadha l-ogħla branch attiva `release/v*`.
- Niżżel l-aħħar aġġornamenti ta’ dik il-bażi u eżamina l-commits li daħlu minn mindu ħloqt il-branch tiegħek.
- Eżamina `git diff <active-base>...HEAD` għal tibdil aċċidentali jew iġġenerat.
- Solvi l-kunflitti fil-katalgu u fid-dokumenti ġġenerati billi taġġorna s-sors u terġa’ tiġġenera l-output.
- Erġa’ ħaddem kull test/punt ta’ kontroll iffukat elenkat fid-deskrizzjoni tal-PR wara r-rikonċiljazzjoni.
- Qatt iddgħajjef l-asserzjonijiet jew tneħħi testijiet meħtieġa sempliċement biex taqbel ma’ bażi li nbidlet.

Għar-regoli dwar l-iffriżar tar-rilaxx u r-ritargetjar, uża
[Il-Mudell tal-Branches u tar-Rilaxxi](BRANCHING_MODEL.md). Għall-inventarju sħiħ tas-CI, uża
[Referenza tal-Punti ta’ Kontroll tal-Kwalità](../architecture/QUALITY_GATES.md).
