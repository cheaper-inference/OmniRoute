> **Status:** id-dashboard huwa mibni fuq il-**Keak CI UI Kit** (`@keak/cheaper-inference-ui-kit`), integrat
> bħala l-workspace `packages/ui-kit` (`@omniroute/ui-kit`; is-snapshot upstream huwa mwaħħal f'
> `packages/ui-kit/UPSTREAM.md` u mħares minn `npm run check:ui-kit-snapshot`). Dawl hija t-tema
> kanonika; il-preferenza default hija `system`. L-aċċent huwa Keak lime (`--ci-color-accent`). Inter
> (letter-spacing 0, `--ci-letter-spacing-ui`) hija l-familja tal-UI, Instrument Serif biss għal test
> display kbir u sparġ (`.ci-dashboard-display`), IBM Plex Mono għall-kodiċi — kollha mospita lokalment
> permezz tal-imports `@fontsource/*` fil-bidu ta' `src/app/globals.css`. Kull ikona hija glif Lucide.

## 1. Fejn jinsabu l-affarijiet

- **Kit.** `packages/ui-kit/src` hija kopja byte-għal-byte tal-`src/` upstream fil-commit imfisser f'
  `packages/ui-kit/UPSTREAM.md` (li jirreġistra wkoll l-awtorizzazzjoni tal-liċenzja); `PATCHES.md` jelenka
  l-patches lokali (l-ebda). Jikkonsmaha bħala sors, bla build: `next.config.mjs` jittranspilaha, u
  `tsconfig.json` jimmapja `@omniroute/ui-kit` → `packages/ui-kit/src` u `@omniroute/ui-kit/*` →
  `packages/ui-kit/src/*` (`vitest.config.ts` u `vitest.mcp.config.ts` jġorru l-istess alias). Importa
  komponent tal-kit bis-subpath tiegħu (`@omniroute/ui-kit/table`, `@omniroute/ui-kit/page-header`…), qatt
  permezz tal-barrel `@omniroute/ui-kit`: il-barrel iġib kull komponent (inkluż id-date picker) f'kull
  importer. Il-stylesheet tal-kit tidħol permezz ta' `src/app/globals.css`
  (`@import "../../packages/ui-kit/src/ci-ui.css"`).
- **Tokens.** `packages/ui-kit/src/ci-tokens.css` jiddikjara t-tokens `--ci-*`; `src/app/globals.css`
  jgħaqqadhom man-nomi legacy ta' OmniRoute (`--color-*`, `--radius-*`, `--font-sans`/`--font-mono`,
  `--table-*`, `--orch-status-*`, `--color-fd-*`), sabiex il-qari eżistenti ta' `var(--color-*)` u
  l-utilities ta' Tailwind jibqgħu jaħdmu. Il-kodiċi l-ġdid juża l-utilities ta' Tailwind (`bg-surface`,
  `text-text-muted`, `border-border`, `text-success`, `bg-success-bg`, `bg-chart-1`…) jew klassijiet tal-kit
  — qatt valur hex (`tests/unit/design-kit-bridge.test.ts` jinfurza dan il-bridge). `text-primary`
  jirriżolvi għal `--color-primary-ink` permezz ta' `--text-color-primary` (lime-800 fil-modalità ċara,
  l-aċċent lime fil-modalità skura), sabiex it-test primarju jibqa' jinqara filwaqt li
  `bg-primary`/`border-primary` jżommu s-superfiċje lime. Is-serje tal-grafki jużaw `--color-chart-1` …
  `--color-chart-5`.
- **Temi.** `<html className="ci-theme">` (`src/app/layout.tsx`) jagħmel li d-dokument jadotta t-tema
  tal-kit. Il-preferenza hija `light`, `dark` jew `system` (`THEME_CONFIG.defaultTheme = "system"` f'
  `src/shared/constants/appConfig.ts`; `system` isegwi `prefers-color-scheme`). `applyTheme()` f'
  `src/store/themeStore.ts` (mirjata mill-iskript bootstrap inline f' `src/app/layout.tsx`, li jaħdem qabel
  l-hydration) tissettja `data-theme="dark"|"light"` u tbiddel il-klassi `.dark` fuq `<html>` fl-istess ħin.
  Is-sett ta' tokens skuri tal-kit huwa mmexxi minn `data-theme="dark"`
  (`packages/ui-kit/src/ci-tokens.css`); l-overrides skuri ta' OmniRoute innifsu (il-blokk `.dark` f'
  `globals.css`) u l-utilities legacy `dark:` ta' Tailwind huma mmexxija mill-klassi `.dark`. M'hemm l-ebda
  presets tal-kulur tal-aċċent: l-aċċent dejjem jiġi mill-kit, u preset persisted minn build eqdem jintrema
  meta l-store jitgħabba.
- **Komponenti (adapters).** `src/shared/components/index.tsx` iżomm l-API tal-komponenti ta' OmniRoute
  (l-istess ismijiet, default exports u props), u l-primitives wara huma adapters fuq il-kit: forms
  (`Button`, `Input`, `Textarea`, `Checkbox`, `Select`, `Toggle`, `Badge`, `Card`), overlays u feedback
  (`Modal`/`ConfirmModal`, `Tooltip`/`InfoTooltip`, `NotificationToast`, `EmptyState`, `Loading`), struttura
  (`Collapsible`, `CollapsibleSection`, `SegmentedControl`, `Breadcrumbs`, `Avatar`) u tabelli (`DataTable`,
  `FilterBar`, `ColumnToggle`, `FilterPills`, `PresetSlider`). Adapter jimporta l-komponent tal-kit
  bis-subpath u jimmapja l-props legacy fuqu — per eżempju `Button variant="primary"` huwa l-buttuna
  `default` tal-kit (`--ci-button-primary-*`: is-superfiċje inversa fil-modalità ċara, l-aċċent bil-linka
  `--ci-color-accent-foreground` tiegħu fil-modalità skura), `danger` huwa `destructive`, u `warning` huwa
  `outline` flimkien mal-estensjoni `.ci-button--warning`. Ir-regoli `.ci-button--warning` u
  `.ci-badge[data-tone]` fit-tarf ta' `globals.css` (`@layer components`) huma estensjonijiet ta' OmniRoute
  fuq il-klassijiet tal-kit. `tests/unit/ui/adapters/*.test.tsx` jwaħħlu kull adapter.
- **Shell.** `src/app/(dashboard)/layout.tsx` jirrendi `DashboardLayout`, li jirrendi
  `src/shared/components/layouts/DashboardShell.tsx`: il-`SidebarProvider` / `Sidebar` / `SidebarInset`
  tal-kit (`packages/ui-kit/src/sidebar.tsx`), bil-loġika tan-navigazzjoni ta' OmniRoute f'
  `src/shared/components/Sidebar.tsx`. Link "skip to content" lejn `#main-content` hija l-ewwel element li
  jista' jirċievi l-fokus. `src/shared/components/Header.tsx` fiha l-`SidebarTrigger` tal-kit (l-unika
  toggle tas-sidebar fis-shell), il-`ProductSwitcher` ta' Keak u l-element li jiftaħ il-command palette;
  turi t-titlu tar-rotta biss sakemm ma jkunx hemm `PageHeader` tal-kit (`.ci-page-header`) immuntat ġewwa
  `#main-content`, sabiex paġna bl-`PageHeader` tagħha stess ikollha `h1` wieħed biss.
  `src/shared/components/CommandPalette.tsx` huwa `Dialog` tal-kit.
- **Ikoni.** `<Icon name="material_name">` (`src/shared/components/Icon.tsx`) jirriżolvi l-isem
  (il-vokabularju ta' Material Symbols li jużaw l-iskrins) permezz ta' `ICON_MAP`
  (`src/shared/constants/iconMap.ts`) għal glif ta' Lucide. Il-font u l-pakkett ta' Material Symbols
  m'għadhomx: isem nieqes mill-mappa jirrendi glif placeholder newtrali (`data-icon-missing="true"`) u
  jirreġistra twissija fil-console barra mill-produzzjoni. `npm run gen:icon-map` jistampa l-ismijiet li qed
  jintużaw u li huma nieqsa mill-mappa (`tests/unit/icon-map-coverage.test.ts` ifalli fuq kwalunkwe isem
  mingħajr ikona ta' Lucide; `tests/unit/icon-map-object-values.test.ts` jkopri ismijiet maħżuna f'oġġetti
  ta' lookup); `scripts/dev/codemod-material-icons.mjs <dir|file>... [--write]` jikteb mill-ġdid l-ispans
  letterali `<span className="material-symbols-outlined">` għal `<Icon>`.
- **Brand.** `src/shared/components/OmniRouteLogo.tsx` huwa wrapper għall-kit: il-default export
  `OmniRouteLogo` jirrendi `ProductIcon product="omniroute" variant="glyph"` (SVG inline, sigur għal
  `basePath`) u `OmniRouteLockup` jirrendi `ProductLockup product="omniroute"` (isem aċċessibbli "Keak
  OmniRoute") jew, għal operaturi white-label, il-`name`/`logoSrc` tagħhom stess. Id-destinazzjonijiet
  tal-product switcher jinsabu f' `src/shared/constants/keakProducts.ts` (`KEAK_PRODUCT_LINKS`,
  `KEAK_ACTIVE_PRODUCT`). L-iskrins standalone — `src/app/login/page.tsx`, `src/app/status/page.tsx`,
  `src/app/maintenance/page.tsx`, `src/app/offline/page.tsx`, `src/app/not-found.tsx` u
  `src/shared/components/ErrorPageScaffold.tsx` — juru l-lockup; `tests/unit/brand-pages-static.test.ts`
  jħaris dan.

## 2. Regoli

1. Tokens, qatt literals. Eċċezzjonijiet miżmuma apposta: it-terminal tal-console li jibqa' dejjem
   skur, l-istrokes SVG ta' ReactFlow permezz ta' `STATUS_HEX`
   (`src/shared/constants/statusColors.ts`), u l-palettes kategorikali
   `STRATEGY_COLORS` (`src/app/(dashboard)/dashboard/combos/live/nodes/StrategyNode.tsx`) u
   `LAYER_COLORS` (`src/app/(dashboard)/dashboard/compression/studio/nodes/EngineNode.tsx`).
2. Qatt tagħmel patch manwalment f'`packages/ui-kit/src`: issinkronizza ma'
   `scripts/dev/sync-ui-kit.sh <commit>`; il-gate pre-commit `npm run check:ui-kit-snapshot`
   (`.husky/pre-commit`) ifalli fuq kwalunkwe byte li jkun differenti mill-commit upstream iffissat
   (jinqabeż bi twissija meta l-klon upstream, `UI_KIT_CLONE` jew
   `_references/cheaper-inference-ui-kit`, ikun assenti). Meta l-kit jonqos xi ħaġa, agħmel
   workaround fl-adapter jew fl-iskrin u itlob lill-upstream għaliha.
3. Il-valuri default tat-test tal-kit huma bl-Ingliż (`label = "Loading"`,
   `loadingLabel = "Loading table"`…) — għaddi strings ittraduċati minn `useTranslations(...)`
   kull meta komponent tal-kit juri test.
4. L-utilities ta' Tailwind jipprevalew fuq il-klassijiet tal-komponenti tal-kit (il-kit jidikjara
   `@layer theme, base, components, utilities` u r-regoli tiegħu jinsabu f'`components`) — uża
   l-utilities għall-ispazjar u l-layout, mhux biex terġa' tikkulurizza l-komponenti tal-kit.
5. Intestazzjonijiet: `.ci-heading` (Inter, mingħajr tracking) għat-titli tal-paġna u
   tas-sezzjonijiet; `.ci-dashboard-display` (Instrument Serif) biss għal test display kbir u
   skars, bħall-kodiċi tal-istatus tal-paġna ta' żball.
6. `tests/unit/dashboard-kit-sweep.test.ts` jħares l-adozzjoni tal-kit: l-ebda span ta' ligatura
   Material taħt `src/app` jew `src/shared/components`; fis-siġra tad-dashboard
   (`src/app/(dashboard)` u `src/shared/components`) l-ebda `<select>`, `<textarea>` jew `<table>`
   grexx u l-ebda `role="dialog"` magħmul bl-idejn barra l-eċċezzjonijiet elenkati (il-fergħa
   nattiva tal-adapter `Select`, `RequestLoggerDetail`); kull `<button>` jew `<input>` grexx hemm
   jeħtieġ kumment li jkun fih `kit-exception:` (bir-raġuni) li jispiċċa mhux aktar minn 3 linji
   fuqu; il-hues tal-paletta u l-varjanti `dark:` biss fil-fajls li jelenka t-test.
7. Ivverifika ż-żewġ temi u l-viewport ta' 390 px qabel PR (screenshots); `tests/e2e/a11y.spec.ts`
   imexxi l-axe.

## 3. Kif iżżid skrin

1. Ibda l-paġna bil-`PageHeader` tal-kit (`@omniroute/ui-kit/page-header`, `compact` ġewwa
   d-dashboard) — titlu, deskrizzjoni u `actions`. L-header tas-shell imbagħad iħalli t-titlu
   tiegħu stess.
2. Ibni l-kontrolli minn `@/shared/components` (l-adapters) u uża l-komponenti tal-kit b'subpath
   fejn ma jeżistix adapter (`Table`/`TableScrollArea`/`DataTableShell`, `Field`, `Alert`, `Tabs`,
   `RadioGroup`, `Slider`…).
3. Ikoni: `<Icon name="…" />`. Isem ġdid imur f'`ICON_MAP` mal-komponent Lucide li jikkorrispondi
   semantikament; `npm run gen:icon-map` jelenka l-ismijiet li għadhom nieqsa.
4. Kuluri: utilities semantiċi (`text-success`, `bg-warning-bg`, `border-border`…) u
   `var(--color-chart-N)` għas-serjijiet tal-grafiċi; l-ebda valuri hex u l-ebda varjanti `dark:`
   li jirrepetu biss kulur.
5. Test: kull string, inkluż it-tikketti li tgħaddi lill-komponenti tal-kit, għandha tiġi minn
   `useTranslations`. Ċwievet ġodda jmorru f'`src/i18n/messages/en.json`, `pt-BR.json` u `vi.json`
   (it-test tal-parità Vjetnamiż jifissa kull ċavetta Ingliża); il-locales l-oħra jimtlew
   mis-sinkronizzazzjoni tal-i18n.
6. Ħaddem il-gwardji qabel il-PR: `tests/unit/dashboard-kit-sweep.test.ts`,
   `tests/unit/icon-map-coverage.test.ts`, `tests/unit/icon-map-object-values.test.ts`,
   `npm run check:dashboard-typecheck` (l-unika verifika li taqbad import duplikat f'`iconMap.ts`),
   `npm run check:ui-icu`, u t-testijiet tal-iskrin innifsu.

## 4. Iż-żieda jew it-tibdil ta' adapter

1. Żomm l-API pubblika ta' `src/shared/components/index.tsx`: l-istess ismijiet tal-export, default exports u
   props aċċettati. Immappa l-props legacy fuq il-kit ġewwa l-adapter (ara `Button.tsx`: `VARIANT_TO_KIT`,
   `SIZE_TO_KIT`).
2. Importa l-kit permezz ta' subpath (`@omniroute/ui-kit/<component>`).
3. Il-workarounds għan-nuqqasijiet tal-kit jgħixu fl-adapter (jew f'`globals.css` `@layer components` meta
   l-iffissar ikun stil), qatt f'`packages/ui-kit/src`.
4. Żid jew aġġorna `tests/unit/ui/adapters/<name>.test.tsx`. Għal adapter b'ħafna callers, qabbel il-markup
   rindut qabel u wara t-tibdil — bidliet fil-padding jew fil-wrapper jinfirxu fuq kull skrin.

## 5. L-aġġornament tal-kit

`scripts/dev/sync-ui-kit.sh <commit> [clone]` jikkopja s-`src/` upstream ta' dak il-commit ġo
`packages/ui-kit/src` u japplika l-unika trasformazzjoni permessa (ineħħi s-suffiss `.js` mill-imports
relattivi). Imbagħad: irrevedi `git diff packages/ui-kit`, agħmel pass viżwali fuq providers, settings,
combos, usage u endpoint fiż-żewġ temi, mexxi `npm run check:ui-kit-snapshot` u `npm run test:vitest:ui`, u
iftaħ il-PR mal-changelog upstream.
