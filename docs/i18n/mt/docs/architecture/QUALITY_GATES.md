## Inventarju tal-bieb u profili ta 'eżekuzzjoni

### Dħul tal-kandidat

Il-flussi tax-xogħol CI u Quality Gates kull wieħed jarmu verdett stabbli: `Gate / CI` u `Gate / Quality`. Il-politika ta' ammissjoni verġjonata tagħhom tinnumera kull xogħol upstream kif meħtieġ jew konsultattiv. Xogħol meħtieġ applikabbli għandu jirnexxi: riżultati nieqes, ikkanċellati, maqbuż, pendenti u mhux magħrufa ma jistgħux jistabbilixxu PASS. Klassifikazzjoni valida ta' docs-only jew ta' katalgu biss tista' tagħmel korsija tal-kodiċi inapplikabbli; abbozz PR mhux kandidat a//ettat. Tikketta `hotfix` ma tirrinunzjax evidenza.

Iż-żewġ flussi tax-xogħol ikopru PRs f'fergħat main/release, pushes to `main`, dispaċċ manwali u avvenimenti ta' grupp ta' amalgamazzjoni. Imbotta, dispaċċ u merge-group imexxu l-għażla sħiħa. Pushes għal `release/**` ma jibdewhom (2026-10-18): kull bidla diġà dam il-matriċi fuq PR tagħha u l-kombinazzjoni magħquda hija l-impjieg ta 'Release-Green (`docs/ops/RUNNER_BOX.md` → Hosted lane). Il-frieket u l-gruppi jingħaqdu jużaw runners ospitati għal impjiegi li inkella jagħżlu runners li jospitaw lilhom infushom; kapaċità ospitata suffiċjenti għandha tiġi vverifikata qabel it-tnedija.

PR ordinarja tmexxi l-għażla veloċi. Il-korsiji `full-code` u `full-code-e2e` tal-politika tad-dħul (E2E, integrazzjoni, pakkett artifact, Electron smoke, Bun SQLite, ekosystem and protocol clients) jimxu biss fuq Mergify queue draft jew fuq run sħiħa: `gh workflow run ci.yml --ref <branch>`.

Kull irċevuta JSON tidentifika l- SHA iċċekkjat, il-fluss tax-xogħol u t-tentattiv. CLI jirrifjuta nuqqas ta' checkout/event SHA. It-testijiet tal-fluss tax-xogħol jorbtu s-sħubija tal-politika mal-lista `needs` tax-xogħol tal-verdett sabiex korsija ġdida jew imneħħija ma tistax tisparixxi fis-skiet. L-irċevuti jkopru l-fluss tax-xogħol tagħhom stess, mhux il-pubblikazzjoni, l-iskjerament, jew l-intern ta 'skaner konsultattiv eżistenti. L-attivazzjoni taż-żewġ ismijiet tal-kontroll fir-regoli tal-fergħat hija bidla amministrattiva separata; iż-żieda ta’ dawn l-impjiegi ma tipproteġix fergħa hi stess.

### Merge kju

It-tikketta `queue` tibgħat PR lill-kju Mergify (`.mergify.yml`). Mergify tiftaħ abbozz PR fuq fergħa `mergify/merge-queue/`, CI imexxi l-għażla sħiħa hemmhekk, u l- PR oriġinali jingħaqad meta jgħaddu `Gate / CI`, `Gate / Quality` u `Merge integrity (changelog + generated skills)`.

Mergify jikteb is-sommarju tal-kju tiegħu fid-deskrizzjoni tal-abbozz, u apps oħra jistgħu jeditjawh ukoll. Avveniment `pull_request` `edited` fuq abbozz bħal dan jieħu l-grupp tal-konkorrenza tiegħu stess (`-queue-edit-<run_id>`) u għalhekk ma jistax jikkanċella l-ġirja reali tal-abbozz, u taqbeż il-bieb u l-matriċi. Biss `Merge integrity` ghadu jigri. Ix-xogħol ta' gate skipped għandu isem ta' kontroll differenti, minħabba li Mergify jaqra `Gate / CI` skipped bħala verifika falluta u tneħħi PR.

Wara dequeue, push mhux dejjem jerġa' jpoġġi l- PR. Ikkummenta `@mergifyio queue` fuqha.

### Evidenza miżmuma fir-reducer ta 'aċċettazzjoni

`scripts/quality/validate-release-acceptance.mjs` tnaqqas pjan fornut u l-manifesti taghha; ma jistabbilixxix li l-pjan ikopri l-pipeline tar-rilaxx sħiħ. Ir-rapporti tagħha jistabbilixxu b'mod espliċitu `releaseAcceptance: false`, anki meta dak il-pjan huwa `VERIFIED`. Il-fluss tax-xogħol `release-acceptance.yml` għadu juża shadow fixtures, mhux irċevuti ta 'bini reali, pakkett, boot jew promozzjoni.

Iż CLI teħtieġ `--evidence-root` tivverifika l-evidenza miżmuma. Fajls jiġu solvuti bħala `<evidence-root>/<artifact_id>/<member>` u hashed bħala SHA-256. Rekord PASS mingħajr evidenza, fajl nieqes jew mibdul, passaġġ mhux sikur jew symlink jipprevjeni l-verifika. Fajls neqsin mhumiex ekwivalenti għal zkuk ta' suċċess vojta. Il-kontrolli SHA/run/attempt eżistenti jibqgħu indipendenti: bytes li jaqblu ma jistgħux isalvaw irċevuta skaduta. L-integrità tal-fajl mhijiex prova tal-awtentiċità tal-eżekuzzjoni jew il-promozzjoni tal-artifact.

### Inventarju ta 'skannjar statiku

L-inventarju verżjoni npm-alias u s-sħubija static-scan jgħixu `config/quality/gate-manifest.json`. Mexxi `npm run check:gate-manifest` biex tivvalida l-ismijiet tal-iskript u l-kmandi eżatti kontra `package.json`; iż-żidiet, it-tneħħija u d-drift tal-kmand ifallu kemm il-ganċ lokali kif ukoll l-impjiegi tal-klassifikazzjoni tal-bidla CI. Psewdonimu mhuwiex xogħol ta' fluss tax-xogħol, istanza ta' matriċi jew każ ta' test: dawn l-għadd m'għandhomx jiġu ppreżentati bħala interkambjabbli.

Uża `npm run quality:scan -- --list` jew `npm run quality:scan:fast -- --list` biex tispezzjona l-psewdonimi magħżula mingħajr ma tesegwihom. Ir-runner jinvoka l-punt tad-dħul npm, għalhekk ir-runtime tiegħu (inkluż Bun fejn ikkonfigurat) huwa ppreservat. Il-manifest jirreġistra psewdonimi barra dawk il-profili kif invokati separatament, u l-kmandi tal-manutenzjoni huma pprojbiti fil-profili tal-iskannjar li jinqraw biss.

Dawn il-profili jkopru l-iskan statiku biss. Ma jiċċertifikawx it-testijiet tal-prodott, il-kopertura, l-ippakkjar, il-kontrolli esterni jew l-aċċettazzjoni tar-rilaxx sħiħ tal-kandidat. Id-dħul tal-fluss tax-xogħol juża `config/quality/admission-policy.json` u `scripts/quality/admission-verdict.mjs` konnessi. Il-profili tal-osservatur tar-rilaxx jibqgħu separati; jispezzjonaw il-kontrolli u l-irċevuti applikabbli tagħhom b'mod indipendenti. Il-kmandi statiċi sħaħ tal-osservatur huma ddikjarati `config/quality/release-green-static-profile.json`, inklużi `audit:deps`, l-għażla tat-test tal-mutazzjoni u l-kontrolli tat-traduzzjoni. Il-loader jivvalida kmandi npm kontra dikjarazzjonijiet package.json u CI/Quality immudellati; tirrifjuta drift minflok tesegwixxi shell tokens bħala argumenti. L-output SKIP/INCOMPLETE tal-iskaner meħtieġ ma jistax jistabbilixxi PASS. Il-profil jirreġistra l-esklużjonijiet esterni tiegħu u ma jissostitwixxix il-kopertura ospitata, il-matriċi tat-test, il-pakkett jew l-evidenza tal-iskjerament. L-inventarju tal-proża hawn taħt huwa referenza, mhux prova li gate fil-fatt dam.

Skripts jgħixu taħt `scripts/check/` (policy gates) u `scripts/quality/` (ratchet engine). Is-sors CI tal-verità huwa `.github/workflows/ci.yml`.

### Eħles PR fast-path (`quality.yml`)

`.github/workflows/quality.yml` tikkumplimenta CI fuq main/release PRs, timbotta għal `main`, tibgħat u tgħaqqad gruppi. PRs juża kontrolli veloċi ffiltrati mill-mogħdija. Il-bini duplikat b'diżabbiltà permanenti tneħħa; il-kontrolli build/package/boot reali jibqgħu CI. L-unità suite u vitest jimxu biss CI (`Unit Tests (N/8)` u `Vitest`).

| Job                                              | Ambitu                                                                                                                                                | Imblukkar            |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------- |
| `Docs Gates (fast-path)`                         | Docs/code PRs; API docs refs u docs-all                                                                                                               | Iva                  |
| `Fast Quality Gates`                             | Code PRs; kontrolli statiċi, verifika tat-tip, verifika tat-tip tad-dashboard, testijiet tal-unità milquta, testijiet ta' aħwa minsija (konsultattiv) |
| `No new ESLint warnings`                         | Code PRs; gwardja tal-lint konxja tas-soppressjonijiet                                                                                                | Iva, inklużi frieket |
| `Merge integrity (changelog + generated skills)` | Non-draft PRs; changelog u s-sinkronizzazzjoni tal-ħiliet ġġenerati                                                                                   | Iva, inklużi frieket |

#### Rapport tat-testijiet tal-aħwa minsija

`npm run check:forgotten-sibling-tests` jimxi bħala pass konsultattiv ta' `Fast Quality Gates` u juża mill-ġdid is-solvent tal-importazzjoni wara l-mappa tal-impatt tat-test. Għal kull modulu ta 'produzzjoni mibdul, jirrapporta ktajjen `changed module/symbol -> static consumer -> candidate sibling test` deterministiċi meta t-test tal-kandidat ikun assenti mid-diff tat-talba tal-ġibda. Is-sommarju tal-Markdown u r-riżultat JSON jinżammu bħala l-artifact tal-fluss tax-xogħol `forgotten-sibling-tests` għall-kalibrazzjoni qabel kwalunkwe rollout li jimblokka.

L-esportazzjoni mill-ġdid tal-barmil u l-importazzjonijiet dinamiċi huma dijanjostiċi tar-riżoluzzjoni biss; huma qatt ma joħolqu sejba imblukkata. Eccezzjonijiet riveduti live in `config/quality/forgotten-sibling-allowlist.json`. Kull entrata trid issemmi t-test tal-konsumatur u l-kandidat, tagħti raġunament speċifiku, u torbot kwistjoni GitHub jew pull request. L-entrati fformati ħażin ma jingħalqu. Eċċezzjonijiet ma jistgħux jrażżnu test tal-kandidati mħassra jew diff li jżid `.skip`/`.todo`; asserzjoni tiddgħajjef u maskra oħra jibqgħu proprjetà tal-bieb `check:test-masking` li jimblokka b'mod indipendenti.

#### Il-mirja tat-traduzzjoni huma fajls derivati (mod PR vs modalità rilaxx)

Feature PR teditja sorsi bl-Ingliż biss. Il-mirja `docs/i18n/<locale>/**` (inklużi s-66 kopja `llm.txt` u l-fajls `CHANGELOG.md` tradotti) u `.i18n-state.json` jinkitbu mill-ġdid f'pass wieħed mill-mewġa tat-traduzzjoni ( fergħat `docs/i18n-*` / `chore/i18n-*`, iż- `i18n-mirror-refresh.yml` skedat ) u bir-rilaxx (`npm run release:sync-changelog-i18n`). Il-gradi tal-mera għalhekk jimxu f'żewġ modi, solvuti `scripts/check/lib/gateMode.mjs` (`--mode=pr|release`, imbagħad `OMNIROUTE_GATE_MODE`, imbagħad l-avveniment Azzjonijiet; ġirja lokali hija `release`):

- `check:docs-sync` — release mode runs every check. PR mode keeps the package.json/OpenAPI version, the root CHANGELOG headings and the superseded-docs guard, and prints `SKIP reason=pr-mode` for the `llm.txt` mirror copies and the translated CHANGELOG sections — unless the PR writes mirrors: a head branch declared as a writer of the `docs/i18n/**` family in `config/quality/derived-paths/*.json` runs both checks strictly, and, when the diff base resolves, a change whose own diff edits `docs/i18n/<locale>/llm.txt` or `CHANGELOG.md` runs that check strictly. The diff base does not resolve in a depth-1 checkout (the `docs-sync-strict` job), so PR mode also runs one check that needs no base: every `llm.txt` mirror must exist, keep its `---` separator and carry either the root body or the body most mirrors share. A base that moved leaves all mirrors equally stale and passes; a hand edit to one mirror fails. The translated `CHANGELOG.md` files have no such check in a depth-1 PR checkout.
- Il-ganċ pre-commit runs `check-docs-sync.mjs --mode=pr`: commit jiġi ġġudikat fuq dak li jagħmel. Mingħajr il-bandiera ġirja lokali hija modalità ta 'rilaxx, u PR wieħed magħqud li jeditja l-għerq `llm.txt` jimblokka kull impenn aktar tard fuq dik il-bażi sakemm il-mewġa dam. L-istess regola tgħodd għal kwalunkwe bieb konxju mill-modalità ta 'Husky hook runs: il-ganċ jgħaddi `--mode=pr`, u l-verdett strett jibqa' mal-runs tal-modalità ta 'rilaxx (ir-rilaxx PR, pushes to `main`, ġirja lokali sempliċi).
- Mirror-content unit tests (`tests/_helpers/mirrorFreshness.ts`: `cycle-docs-mirror-contract`, `resilience-pre-dispatch-docs-mirrors`, `cli-env-quality-docs-mirrors`, `docs/*-locales`) — release mode jasserixxi kull lokalità. Il-mod PR jasserixxi biss il-mirja li huma kurrenti mas-sors Ingliż skont `.i18n-state.json` (hash tal-fajl kollu, jew is-sezzjoni reġistrata hash tas-sezzjoni tal-pinnijiet tat-test) u taqbeż dawk skaduti b'raġuni. Il-kontrolli tal-provenjenza `target_hash` jimxu għal kull lokalità fiż-żewġ modi. Il-freskezza hija għal kull taqsima `## `, l-unità `run-translation.mjs` hashes; sezzjoni twila (l-inventarju tal-bieb ta 'dan il-fajl huwa madwar nofsu) ifisser li kwalunkwe editja fiha tħalli dawk il-mirja friski, u l-asserzjonijiet tal-modalità PR tagħhom jaqbżu sal-mewġa li jmiss. Ankra li s-sors Ingliż m'għadux fih taqa' lura għall-paragun tal-fajl kollu.
- `i18n translation drift` — konsultattiv fuq PRs, stretta fuq l-imbottatura, filgħaxija u r-rilaxx maqtugħ, għalhekk mera stale ma tistax tintbagħat f'rilaxx.

`scripts/i18n/sync-llm-mirrors.mjs` (esportat ukoll bħala `syncLlmMirrors()`, bi `--dry-run`) jikteb mill-ġdid il-mirja `llm.txt` ; l-aġġornament tar-rilaxx, il-mewġa tat-traduzzjoni u l- `i18n-mirror-refresh.yml` skedat imexxuh (l-aġġornament jiskopri mirja `llm.txt` friski b'ġirja niexfa, peress li r-rapport tad-drift ma jelenkaxhom, u jissinkronizzahom qabel `check:docs-all`).

It-tnax- README SVGs taħt `docs/diagrams/` huma ġġenerati (`scripts/docs/gen-readme-<name>.mjs`; `npm run docs:readme-diagrams` jirriġenerahom kollha). Kull wieħed għandu byte-compare unit test (`tests/unit/docs/readme-*-svg.test.ts`, job `test-unit`) li jfalli meta l-fajl kommess ikun skadut fil-modalità rilaxx; fi PR, `check:generated-artifacts` jiġġudika an SVG l- PR edits u drift tal-bażi titħalla għall-aġġornament tar-rilaxx (ara [Fajls ġenerati u linji bażi derivati](#generated-files-and-derived-baselines-written-at-release) ) — u `check:docs-counts` jaqra numri kanoniċi min-nodi `<text>` tagħhom — u huwa għalhekk li l-pass tal-kontorn iżomm kull string inviżibbli fil- `<text>`. Il-kontroll SVG canonical-numri jaqra l-fajls elenkati fi `SVG_DIAGRAM_FILES` (`scripts/check/check-docs-counts-sync.mjs`): `docs/diagrams/readme-hero.svg`, `free-tier-budget.svg`, `promise-pillars.svg`, `comparison-table.svg`, `cli-terminal.svg`, `tier-cascade.svg`, plus `public/images/tier-flow-dark.svg` and `tier-flow-light.svg`; il-pretensjonijiet ta 'free-forever, catalog-entry, rikorrenti-pool u scoring-factors jaqraw ukoll `promise-pillars.svg`, `free-tier-budget.svg` u `strategies-grid.svg`. L-għadd li jiġbdu dawn il-ġeneraturi (total tal-fornitur, għodod MCP, strateġiji ta’ rotta, fornituri b’xejn għal dejjem, …) ġejjin mill-istampa tal-fatti `docs/reference/derived-facts.json` sa `scripts/docs/readmeFacts.mjs`, mhux minn letterali, għalhekk ir-riġenerazzjoni ta’ dijagramma fuq kwalunkwe fergħa tirriproduċi l-fajl impenjat. `free-tier-budget.svg` jiġbed ir-ringieli tiegħu mill-istess snapshot (`code.freeTierBudget`, is-sommarju tal-katalgu tar-rekords tas-sonda tal-fatti), għalhekk bidla għal `FREE_MODEL_BUDGETS` tilħaq il-karta fl-aġġornament li jmiss minflok ma tinbidel CI aħmar.

### Valuri derivati: il-modi tal-bieb `pr` u `release`

Karatteristika PR qatt ma tikteb valur li jiddependi fuq l-istat tal-bażi tagħha: il-fornitur, il-migrazzjoni, l-għadd tal-għodda MCP u l-istrateġija, in-numri README SVG, l-istampa tal-fatti. Pass wieħed jerġa' jikkalkulahom kollha, `npm run release:refresh-derived`, immexxija mir-rilaxx u mill-derivat-refresh filgħaxija PR. Allura** bejn ir-rilaxxi l-bażi hija wara l-kodiċi ħajjin bid-disinn** , u gate jew test li qabbel is-siġra mal-kodiċi ħajjin ikun aħmar fuq kull PR wara li aħwa żied fornitur. **Mod ta' kodiċi ġdid (Clean-as-You-Code) — mill-2026-08-30, PR fast-path biss**

Fuq avvenimenti `pull_request` `quality.yml` jgħaddi `--base-ref <PR base SHA>` għal `check:file-size`, `check:complexity-ratchets` u `check:dead-code`. Għal `check:complexity-ratchets` u `check:dead-code` il-bieb iqabbel HEAD mal-merge-base** ristrett għall-fajls li l PR mimsus** (`scripts/check/newCodeMode.mjs`: il-merge-base hija mmaterjalizzata fi `git worktree` throwaway , ESLint/knip run hemm u fuq HEAD, l-għadd għal kull fajl huma differenti):

- **imblukkar** — l- PR miżjud vjolazzjonijiet cyclomatic/cognitive jew esportazzjonijiet mejta fil-fajls li nbidlet (`complexityNewCode=`, `cognitiveComplexityNewCode=`, `deadExportsNewCode=` fil-log);
- **konsultattiv** — it-total globali vs il-linja bażi ffriżata. Inherited drift qatt reds an innocent PR; id-drift jiġi ffriżat mill-ġdid fir-rikonċiljazzjoni tar-rilaxx u jarah mill-impjieg headroom.

`check:file-size` uses the base ref on its own terms (`scripts/check/check-file-size.mjs`, #8522): it checks every source and test file in the tree, reads each one's line count at the PR base with `git show`, and fails a file only when it grows past the larger of its baseline ceiling (`frozen` / `testFrozen`, or `cap` / `testCap` for a file outside the baseline) and its base size. A file that already drifted on the base therefore never reds an innocent PR.

`check:boundary:ratchet` tapplika l-istess regola għan-numru uniku tagħha (`scripts/quality/measure-boundary.mjs --ratchet --base-ref <sha>`): fuq avvenimenti PR kemm `quality.yml` fast-gates kif ukoll ix-xogħol lint `ci.yml` jgħaddu l-bażi PR SHA, il-commit bażi jitkejjel minn esportazzjoni `git archive`, u PR jonqos biss meta `open-sse → src` edge għadd tiegħu jaqbeż l-akbar u l-għadd tal-bażi `metrics.boundaryOpenSseToSrc`. Id-drift tal-bażi 'l fuq mis-saqaf huwa rrappurtat (`base drift herdado`) iżda qatt ma ħamra PR innoċenti; push → main iżomm il-limitu assolut, u bażi mhux solvabbli SHA jaqa lura għaliha bi twissija.

Kandidat omni-queue (a push to `omni-queue/**`, ara [OMNI_QUEUE.md](../ops/OMNI_QUEUE.md) ) jieħu l-istess trattament bħal pull request: iż-żewġ flussi tax-xogħol jgħaddu l-bażi tal-kandidati (`needs.changes.outputs.candidateBase`) bħala `--base-ref`, u `check:ts7-diagnostics-ratchet` tmur kontriha wkoll. Għaż-żewġ xtiebi ta 'kodiċi ġdid il-bażi tat-tqabbil hija li SHA innifsu, mhux l-ewwel ġenitur tal-top merge commit, għalhekk kull talba tal-ġibda tal-lott tiġi ġġudikata.

`workflow_dispatch` runs, ir-rilaxx-green sweep u l-impjieg headroom ta 'filgħaxija m'għandhom l-ebda bażi PR u jżommu l-paragun assolut (globali). Kopertura, duplikazzjoni u kopertura tat-tip jibqgħu globali għal issa (l-għodod tagħhom ma jipproduċux diff għal kull fajl bl-irħis) — kandidati għall-istess trattament.

## Politika tal-lista ta' permessi

Kull bieb li ma jistax ifalli fuq vjolazzjonijiet pre-eżistenti juża lista ta' permess iffriżata (eż., `KNOWN_STALE_DOC_REFS`, `KNOWN_MISSING`, `KNOWN_RAW_SQL`). Il-politika hija:

Meta żżid dħul għal lista ta' permessi:

1. Inkludi kumment mal-ġustifikazzjoni.
2. Irreferi għall-kwistjoni tat-traċċar (eż., `// #3498 — Phase 2 feature, not yet implemented`).
3. Neħħi l-iskrizzjoni fl-istess PR li tiffissa l-ksur — dħul qadim li ma jibqax trażżan vjolazzjoni attiva hija nnifisha difett (6A.3 stale-enforcement se tfalli l-gate fuq dħul orfni fil-lista ta' permessi ladarba jiġi implimentat).

Do** le** żid entrati tal-lista ta' permessi biex it-testijiet jgħaddu aktar malajr. Xatba aħdar b'lista ta 'permessi li qed tikber hija sens falz ta' kwalità.

### Meta gate jonqos fuq PR tieghek

1. **Aqra bir-reqqa l-output tal-bieb** — jgħidlek eżattament liema fajl jew simbolu kiser ir-regola.
2. **Waħħal il-ksur** — l-biċċa l-kbira tal-gradi huma kontrolli tas-sistema tal-fajls deterministiċi li jgħaddu hekk kif il-kodiċi huwa korrett.
3. **Jekk il-ksur ikun pre-eżistenti** (jiġifieri, ma daħħalhiex imma l-bieb issa jkopriha): żid entrata tal-lista ta' permessi b'kumment ta' ġustifikazzjoni u kwistjoni ta' traċċar.
4. **Jekk il-bieb huwa ratchet** (kopertura, twissijiet ESLint, duplikazzjoni, kumplessità): il-bidla tiegħek għamlet il-metrika agħar. Waħħal il-kwistjoni sottostanti, jew (rari) ħaddem `npm run quality:ratchet -- --update` jekk il-bidla hija intenzjonata u d-degradazzjoni metrika hija aċċettabbli — iżda ddokumenta għaliex fid-deskrizzjoni PR.
5. **Xtiebi ta' konsulenza** (`continue-on-error: true`) huma informattivi — ma jimblukkawx merge imma jidhru fis-sommarju CI. Waħħalhom xorta waħda.
