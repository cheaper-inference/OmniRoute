Elekeza **Claude Code** CLI (`claude`) kwenye OmniRoute — ya ndani au VPS ya mbali —
kwa kutumia wasifu maalumu kwa kila modeli, kwa kuakisi usanidi wa Codex.

---

## Kuanza haraka

```bash
# Zindua Claude Code dhidi ya OmniRoute ya ndani (hutambua muktadha unaotumika kiotomatiki)
omniroute launch

# Dhidi ya OmniRoute ya mbali (baada ya `omniroute connect <host>`, hii hufanyika kiotomatiki)
omniroute launch --remote http://192.168.0.15:20128 --api-key oma_live_xxx

# Tengeneza wasifu wa kila modeli, kisha uzindue mmoja
omniroute setup-claude            # huandika ~/.claude/profiles/<name>/settings.json
omniroute launch --profile glm52  # Claude Code ikitumia glm/glm-5.2 kupitia OmniRoute
```

## Jinsi Claude Code inavyounganishwa na lango

Claude Code huwasiliana na **Anthropic Messages API** na huelekezwa kwenye endpoint maalumu
kupitia vigezo vya mazingira (haina chaguo la `--base-url`):

| Kigezo                                       | Madhumuni                                                                                            |
| -------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| `ANTHROPIC_BASE_URL`                         | URL ya msingi ya lango (Claude Code huongeza `/v1/messages`). **Bila kiambishi `/v1`.**              |
| `ANTHROPIC_AUTH_TOKEN`                       | Hutumwa kama `Authorization: Bearer …` — tumia tokeni yako ya ufikiaji / ufunguo wa API wa OmniRoute |
| `ANTHROPIC_API_KEY`                          | Mbadala: hutumwa kama `x-api-key`. Vyote viwekwa, `ANTHROPIC_AUTH_TOKEN` hutangulia                  |
| `ANTHROPIC_MODEL`                            | Lazimisha modeli maalumu (hubatilisha chaguo-msingi la kiteuzi cha `/model`)                         |
| `CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY` | `1` → kiteuzi asilia cha `/model` huorodhesha modeli za `claude*`/`anthropic*` kutoka `/v1/models`   |
| `CLAUDE_CODE_MAX_OUTPUT_TOKENS`              | Weka kikomo cha tokeni za matokeo kwa kila jibu (k.m. `65536`)                                       |
| `CLAUDE_CODE_AUTO_COMPACT_WINDOW`            | Kizingiti cha tokeni kwa ajili ya ubanaji wa kiotomatiki                                             |

> Vigezo vya mazingira husomwa **mara moja wakati wa kuanza** — anzisha upya Claude Code baada ya kuvibadilisha.

`omniroute launch` hukuwekea vyote hivi: hutatua URL ya msingi + tokeni
kutoka kwenye muktadha unaotumika (kwa hivyo `omniroute connect <vps>` kisha `omniroute launch`
hufanya kazi moja kwa moja), hukagua afya ya seva, na hutekeleza `claude`.

## Majina mbadala ya ugunduzi — kuonyesha modeli zisizo za Claude katika kichaguzi cha `/model`

Ugunduzi wa modeli wa lango la Claude Code huorodhesha tu vitambulisho vinavyoanza na `claude`
au `anthropic`, kwa hivyo kwa `CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1` kichaguzi
cha asili cha `/model` kwa kawaida huonyesha modeli za Claude/Anthropic za OmniRoute **pekee** —
`kimi/kimi-k2.6` au `glm/glm-5.2` kamwe haionekani, hata kama huelekezwa vyema.

OmniRoute inaweza kuakisi modeli yoyote iliyowezeshwa (na combo) chini ya kitambulisho cha `claude/…`
ili kupita kichujio hicho na kuonekana katika kichaguzi:

```
kimi/kimi-k2.6            →  claude/kimi/kimi-k2.6      "Kimi K2.6 (OmniRoute)"
glm/glm-5.2              →  claude/glm/glm-5.2         "GLM 5.2 (OmniRoute)"
<combo "custo-otimizado"> →  claude/combo/custo-otimizado
```

Unapochagua mojawapo ya hizi katika Claude Code, OmniRoute huondoa kifuniko cha `claude/`
na kurudisha kitambulisho halisi kabla ya kuelekeza — kitambulisho halisi cha
`claude/<real-claude-model>` (mtoa huduma halisi wa Claude OAuth) hubaki bila kuguswa.

Kwa chaguo-msingi, ni vitambulisho vya msingi pekee vinavyoakisiwa. Kwa bendera ya kipengele
cha kujiunga `CATALOG_MIRROR_REFINEMENTS_ENABLED` ikiwa imewashwa, tofauti za kiwango cha
juhudi za ufikiraji ambazo orodha tayari huziorodhesha (km. `codex/gpt-6-sol-high`) huakisiwa
kama kitambulisho kingine chochote, hivyo Claude Code inaweza kuchagua kiwango mahususi cha
juhudi, na vitambulisho vya ndani vya `auto/*` ambavyo njia ya ombi haiwezi kuvitimiliza
haviakisiwi. Ikiwa tofauti za juhudi zitaorodheshwa kabisa bado hudhibitiwa na
`OMNIROUTE_DISABLE_THINKING_LEVEL_VARIANTS` — kioo kamwe hakiongezi tofauti ambayo orodha
ya msingi haina.

**Hii imezimwa kwa chaguo-msingi** na hudhibitiwa na lango la ngazi tatu (mahususi zaidi
ndio hushinda), ili OmniRoute ya kawaida isiongeze orodha yake mara mbili kwa wateja
ambao hawatumii Claude Code:

| Ngazi       | Wapi                                                                                              |
| ----------- | ------------------------------------------------------------------------------------------------- |
| Modeli      | Ukurasa wa maelezo ya mtoa huduma → kitufe cha "Onyesha katika Claude Code" kwa kila modeli       |
| Mtoa huduma | Ukurasa wa maelezo ya mtoa huduma → kitufe cha ngazi ya mtoa huduma (huzingatia modeli zake zote) |
| Kimataifa   | Mipangilio → Bendera za Vipengele → `EXPOSE_CC_DISCOVERY_ALIASES` (imezimwa kwa chaguo-msingi)    |

Kibadilishaji cha mazingira `EXPOSE_CC_DISCOVERY_ALIASES` hudumu ngazi ya kimataifa iwe
imewashwa na hupata kipaumbele juu ya ubatilishaji wa dashibodi (skrini ya Bendera za
Vipengele huonyesha dokezo la "limeamilishwa kupitia kibadilishaji cha mazingira" inapofanya
hivyo). Vifufe vya kila mtoa huduma na kila modeli huboresha kutoka hapo — km. kimataifa
kimezimwa + mtoa huduma Kimi amewashwa huonyesha modeli za Kimi pekee.

> ⚠️ **Ulinganifu mbaya wa dirisha kwenye modeli zisizo za Claude.** Claude Code huchukulia
> dirisha la muktadha la 200K kwa kitambulisho chochote ambacho haikitambui (haiwezi kusoma
> dirisha halisi kutoka `/v1/models`). Kwa modeli yenye dirisha kubwa zaidi (km. 256K ya
> Kimi K2), weka `CLAUDE_CODE_AUTO_COMPACT_WINDOW` kwa thamani iliyo chini ya dirisha halisi
> la modeli ili ujazaji wa kiotomatiki usiamilishwe mapema. Profaili zilizotengenezwa hapo
> juu tayari hufanya hivi kwa kila modeli.

## Sehemu ya uanzishaji kwenye dashibodi

Kadi ya zana ya Claude (**Dashibodi → Msimbo wa CLI**) huonyesha kipande kamili cha `settings.json`
cha instansi hii, kando ya kitufe cha taarifa za lakabu ya ugunduzi, pamoja na kitufe cha kunakili:

```jsonc
{
  "env": {
    "ANTHROPIC_BASE_URL": "http://<OmniRoute yako>:20128",
    "ANTHROPIC_AUTH_TOKEN": "<ufunguo wako wa API wa OmniRoute>",
    "CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY": "1",
  },
}
```

URL ya msingi ndiyo iliyotambuliwa na kadi (ikiwemo thamani maalum ya kubatilisha uliyoandika), na tayari
imesawazishwa — haina kiambishi tamati cha `/v1` wala mkwaju wa mwisho. **Ufunguo hauonyeshwi kamwe**: sehemu hiyo huja na
kishika nafasi, kwa hivyo picha ya skrini au kipande kilichobandikwa hakiwezi kuuvujisha. Bandika ufunguo wako juu yake.

Ongeza `CLAUDE_CODE_AUTO_COMPACT_WINDOW` chini ya sehemu hiyo hiyo ya `env` kwa modeli yoyote ambayo dirisha lake halisi
la muktadha si 200K — Claude Code huchukulia 200K kwa kila kitambulisho isichokitambua, kwa hivyo
ufupishaji wa kiotomatiki vinginevyo huanza katika hatua isiyofaa (tazama onyo katika sehemu iliyotangulia).
Kiundaji cha kipande pia hukubali thamani hiyo, kwa hivyo mwitaji anayejua ukubwa wa dirisha la modeli lengwa
anaweza kuitoa moja kwa moja.

Chanzo: `src/shared/services/claudeCliConfig.ts::buildClaudeDiscoverySettingsSnippet` (kiundaji kisicho na
athari za pembeni, kilichojaribiwa kwa majaribio ya kitengo) kinachoonyeshwa na `ClaudeGatewayOnboardingBlock`.

### Bandika akaunti moja (si lazima)

Ili kutuma kila ombi la Claude Code kupitia akaunti moja mahususi ya mtoa huduma, ongeza kichwa cha
`x-omniroute-connection` kupitia `ANTHROPIC_CUSTOM_HEADERS` katika sehemu hiyo hiyo ya `env`:

```jsonc
"ANTHROPIC_CUSTOM_HEADERS": "x-omniroute-connection: <connection id>"
```

Nakili kitambulisho kutoka kwenye chipu ya `xxxxxxxx…` katika safu ya muunganisho kwenye ukurasa wa mtoa huduma. Ubandikaji huo
hutumika tu kwa vitambulisho vya modeli moja (`provider/model`), si kwa mikusanyiko. Tazama
[Ubandikaji wa akaunti kwa kila ombi](../reference/API_REFERENCE.md#account-pinning-per-request) kwa
tabia kamili ya mbadala.

## Wasifu (`CLAUDE_CONFIG_DIR`)

Claude Code **haina faili asilia za wasifu** (tofauti na `~/.codex/<name>.config.toml` ya Codex).
Utaratibu unaopendekezwa ni `CLAUDE_CONFIG_DIR` — saraka tofauti ya usanidi kwa kila
wasifu, kila moja ikiwa na `settings.json`, vitambulisho, historia na akiba yake.

`omniroute setup-claude` huchukua katalogi ya moja kwa moja ya `/v1/models` na kuandika
wasifu mmoja kwa kila modeli katika `~/.claude/profiles/<name>/settings.json`, ikitumia tena
**majina sawa na `setup-codex`** (`glm52`, `kimi-k27`, `deepseek-pro`, …):

```jsonc
// ~/.claude/profiles/glm52/settings.json
{
  "$schema": "https://json.schemastore.org/claude-code-settings.json",
  "model": "glm/glm-5.2",
  "effortLevel": "xhigh",
  "env": {
    "ANTHROPIC_BASE_URL": "http://192.168.0.15:20128",
    "ANTHROPIC_MODEL": "glm/glm-5.2",
    "CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY": "1",
    "CLAUDE_CODE_AUTO_COMPACT_WINDOW": "190000",
  },
}
```

> **Tokeni ya uthibitishaji haiandikwi kamwe kwenye wasifu.** Anzisha kwa
> `omniroute launch --profile <name>` (huingiza `ANTHROPIC_AUTH_TOKEN` kutoka kwenye
> muktadha unaotumika), au hamisha `ANTHROPIC_AUTH_TOKEN` mwenyewe na utekeleze
> `CLAUDE_CONFIG_DIR=~/.claude/profiles/<name> claude`.

**Usawazishaji otomatiki baada ya ugunduzi wa modeli (kwa hiari).** OmniRoute inaweza kutengeneza upya faili hizi hizi za
`~/.claude/profiles/<name>/settings.json` kiotomatiki wakati wowote usawazishaji wa modeli za mtoa huduma
unapobadilisha katalogi ya moja kwa moja — hivyo modeli mpya/zilizobadilishwa majina hupata wasifu bila kutekeleza tena
amri. Kipengele hiki **kimezimwa kwa chaguo-msingi**: kiwashe kutoka kwenye **dashibodi ya CLI Code** ("Usawazishaji
otomatiki wa wasifu wa CLI" → Claude Code), au weka `OMNIROUTE_AUTO_SYNC_CLAUDE_PROFILES=true` (pia huheshimu
`CLI_ALLOW_CONFIG_WRITES`, ambayo imewashwa kwa chaguo-msingi). Kikiwashwa, huandika faili za wasifu pekee; kamwe
hakibadilishi usanidi unaotumika/chaguo-msingi wa Claude, uthibitishaji, au `~/.claude/settings.json`.

### Kutengeneza + kutumia wasifu

```bash
# OmniRoute ya ndani
omniroute setup-claude

# VPS ya mbali (hupachika URL ya VPS kwenye kila wasifu)
omniroute setup-claude --remote http://192.168.0.15:20128 --api-key oma_live_xxx

# Baadhi tu ya watoa huduma
omniroute setup-claude --only glm,kimi

# Pia andika wasifu kwa watoa huduma wa CLI ya ndani (zcode, auggie, devin-cli-agentic,
# codex-app-server) ambao hawakugunduliwa kwenye seva hii (hurukwa kwa chaguo-msingi kwa lengwa la ndani)
omniroute setup-claude --include-local

# Hakiki bila kuandika
omniroute setup-claude --dry-run

# Anzisha wasifu
omniroute launch --profile kimi-k27
```

## Viwango vya modeli (si lazima)

Claude Code huelekeza maombi kwenye viwango vya uwezo. Oanisha kila kiwango na modeli ya OmniRoute kupitia env /
mipangilio ikiwa unataka watoa huduma tofauti kwa kila kiwango:

```bash
export ANTHROPIC_DEFAULT_OPUS_MODEL="glm/glm-5.2"
export ANTHROPIC_DEFAULT_SONNET_MODEL="kmc/kimi-k2.6"
export ANTHROPIC_DEFAULT_HAIKU_MODEL="glm/glm-4.7-flash"
```

Vinginevyo, `ANTHROPIC_MODEL` moja (ambayo wasifu huweka) hutumika kwa kila kitu.

## Hali ya mbali

Baada ya kuendesha `omniroute connect <host>` (angalia
[Hali ya Mbali](./REMOTE-MODE.md)), `omniroute launch` na `omniroute setup-claude`
hulenga seva hiyo ya mbali kiotomatiki na kutumia tokeni yake ya ufikiaji yenye upeo maalum — hakuna
alama za ziada zinazohitajika. Badilisha kwa kila utekelezaji ukitumia `--remote` / `--api-key`.

## Utatuzi wa matatizo

**Claude Code inapuuza lango** — thibitisha kuwa `ANTHROPIC_BASE_URL` **haina
`/v1`** na uanzishe upya `claude` (env husomwa mara moja wakati wa kuanza). `omniroute launch`
hushughulikia hili kwa niaba yako.

**Kiteuzi cha `/model` ni tupu / hakina modeli za lango** — kinahitaji Claude Code
v2.1.219+ na `CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1`. Ni vitambulisho vya modeli vya `claude*` /
`anthropic*` pekee vinavyoonekana kwenye kiteuzi; lazimisha modeli nyingine yoyote kwa
`ANTHROPIC_MODEL=<id>` (hivi ndivyo wasifu hufanya).

**`400 Ambiguous model 'claude-…'`** — Claude Code daima hutuma vitambulisho vya modeli **visivyo na kiambishi awali**
(k.m. `claude-opus-4-8`), kwa hivyo wakati watoa huduma wa Claude Code (`cc/…`) na
Claude (`claude/…`) wote wameunganishwa, kitambulisho kisicho na kiambishi awali hulingana na njia mbili na
OmniRoute hukataa kukisia. Rekebisha kwa mojawapo ya njia hizi: bainisha kitambulisho chenye kiambishi awali kwa
`ANTHROPIC_MODEL=cc/claude-opus-4-8`, au washa **Pendelea Claude Code kwa
modeli za Claude zisizo na viambishi awali** — swichi kwenye ukurasa wa mtoa huduma wa Claude, au
`OMNIROUTE_PREFER_CLAUDE_CODE_FOR_UNPREFIXED_CLAUDE_MODELS=true` (imezimwa kwa chaguo-msingi;
angalia [Mazingira](../reference/ENVIRONMENT.md)) — ambayo huelekeza vitambulisho vya `claude-*`
visivyo na viambishi awali kwa Claude Code badala yake. Viambishi awali vilivyobainishwa vya watoa huduma hupewa kipaumbele kila wakati.

**Hitilafu za uthibitishaji** — wasifu hauna tokeni. Tumia `omniroute launch --profile`
(huiingiza) au hamisha `ANTHROPIC_AUTH_TOKEN`.

**Wasifu hautengani** — kila wasifu ni `CLAUDE_CONFIG_DIR` tofauti;
thibitisha kuwa `echo $CLAUDE_CONFIG_DIR` ndani ya kipindi inaelekeza kwenye
`~/.claude/profiles/<name>`.
