## 🎯 Matumizi

### Hali ya 1: "Nina usajili wa Claude Pro"

**Tatizo:** Mgao unaisha muda bila kutumika, na vikomo vya kiwango cha matumizi hutokea wakati wa uandishi mzito wa msimbo

```
Mchanganyiko: "maximize-claude"
  1. cc/claude-opus-4-7        (tumia usajili kikamilifu)
  2. glm/glm-4.7               (mbadala wa bei nafuu mgao unapoisha)
  3. if/qwen3.8-max-preview       (mbadala wa dharura usiolipishwa)

Gharama ya kila mwezi: $20 (usajili) + ~$5 (mbadala) = jumla ya $25
dhidi ya $20 + kufikia vikomo = kufadhaika
```

### Hali ya 2: "Nataka kutotumia gharama yoyote"

**Tatizo:** Siwezi kumudu usajili, ninahitaji AI ya kuandika msimbo inayotegemeka

```
Mchanganyiko: "zero-cost"
  1. if/kimi-k2.7-code          (imeorodheshwa kuwa na ufikiaji bila malipo; vikomo vya kiwango vinaweza kutumika)
  2. kr/qwen3-coder-next        (mbadala wa Kiro usiolipishwa)

Gharama ya kila mwezi: $0
Ubora: thibitisha modeli, vikomo, faragha na SLA kwa mzigo wako wa kazi
```

### Hali ya 3: "Ninahitaji kuandika msimbo saa 24/7 bila kukatizwa"

**Tatizo:** Nina makataa, siwezi kumudu muda wa kutopatikana kwa huduma

```
Mchanganyiko: "always-on"
  1. cc/claude-opus-4-7        (ubora bora zaidi)
  2. cx/gpt-5.5                (usajili wa pili)
  3. glm/glm-4.7               (nafuu, huwekwa upya kila siku)
  4. minimax/MiniMax-M2.1      (nafuu zaidi, huwekwa upya baada ya saa 5)
  5. if/deepseek-v4-flash       (imeorodheshwa kuwa na ufikiaji bila malipo; vikomo vya kiwango vinaweza kutumika)

Matokeo: Ngazi 5 za mbadala huongeza uthabiti; upatikanaji wa huduma za chanzo haujahakikishwa
Gharama ya kila mwezi: $20-200 (usajili) + $10-20 (mbadala)
```

### Hali ya 4: "Nataka AI ya BURE katika OpenClaw"

**Tatizo:** Ninahitaji msaidizi wa AI katika programu za ujumbe, bila malipo kabisa

```
Mchanganyiko: "openclaw-free"
  1. if/qwen3.8-max-preview     (imeorodheshwa kuwa na ufikiaji bila malipo; vikomo vya kiwango vinaweza kutumika)
  2. if/deepseek-v4-flash       (imeorodheshwa kuwa na ufikiaji bila malipo; vikomo vya kiwango vinaweza kutumika)
  3. if/kimi-k2.7-code          (imeorodheshwa kuwa na ufikiaji bila malipo; vikomo vya kiwango vinaweza kutumika)

Gharama ya kila mwezi: $0
Ufikiaji kupitia: WhatsApp, Telegram, Slack, Discord, iMessage, Signal...
```

## 📖 Usanidi wa Watoa Huduma

Ili kuongeza kwa wingi miunganisho ya funguo za API kutoka kwenye faili la CSV au JSON, tumia **Dashibodi → Watoa Huduma → Leta kutoka kwenye faili**. Safu wima hufuata mpangilio maalum (`provider,name,apiKey,baseUrl,priority`); `provider` lazima iwe tayari ipo kama mtoa huduma anayesimamiwa au nodi inayooana. Tazama [Kuleta watoa huduma kutoka kwenye faili la CSV au JSON](../providers/CSV-IMPORT.md).

### 🔐 Watoa Huduma wa Usajili

#### Claude Code (Pro/Max)

```bash
Dashibodi → Watoa Huduma → Unganisha Claude Code
→ Kuingia kwa OAuth → Uonyeshaji upya wa tokeni kiotomatiki
→ Ufuatiliaji wa mgao wa saa 5 + wa kila wiki

Miundo:
  cc/claude-opus-4-7
  cc/claude-sonnet-4-6
  cc/claude-haiku-4-5-20251001
```

**Kidokezo cha Kitaalamu:** Tumia Opus kwa kazi changamano, na Sonnet kwa kasi. OmniRoute hufuatilia mgao kwa kila muundo!

Hakuna kivinjari kwenye seva pangishi ya OmniRoute? Endesha `claude setup-token` mahali popote ambapo Claude Code imeingia, kisha ubandike tokeni ya mwaka mmoja kwenye kichupo cha **Setup Token**. Tazama [Claude Code kwa kutumia tokeni ya usanidi](../providers/CLAUDE_CODE_SETUP_TOKEN.md).

Njia zinazooana na Claude na Claude Code huhifadhi kiwango cha juhudi ya kufikiri cha `max` kwa miundo ya Opus na Sonnet. Miundo ya Haiku haikubali kiwango cha juhudi cha `max`, kwa hivyo OmniRoute hushusha ombi hilo hadi kwenye bajeti ya juu ya kufikiri kabla ya kulituma kwa mtoa huduma wa juu.

#### OpenAI Codex (Plus/Pro)

```bash
Dashibodi → Watoa Huduma → Unganisha Codex
→ Kuingia kwa OAuth (bandari 1455)
→ Uwekaji upya baada ya saa 5 + kila wiki

Miundo:
  cx/gpt-5.5
  cx/gpt-5.4
  cx/gpt-5.3-codex
  cx/gpt-5.3-codex-spark
```

#### GitHub Copilot

```bash
Dashibodi → Watoa Huduma → Unganisha GitHub
→ OAuth kupitia GitHub
→ Uwekaji upya wa kila mwezi (tarehe 1 ya mwezi)

Miundo:
  gh/gpt-5.5
  gh/gpt-5.4
  gh/claude-sonnet-4.6
  gh/claude-opus-4.7
  gh/gemini-3.1-pro-preview
```

### 💰 Watoa Huduma wa Bei Nafuu

#### GLM-4.7 (Uwekaji upya wa kila siku, $0.6/1M)

1. Jisajili: [Zhipu AI](https://open.bigmodel.cn)
2. Pata ufunguo wa API kutoka Coding Plan
3. Dashibodi → Ongeza Ufunguo wa API: Mtoa Huduma: `glm`, Ufunguo wa API: `your-key`

**Matumizi:** `glm/glm-4.7` — **Kidokezo cha Kitaalamu:** Coding Plan hutoa mgao mara 3 kwa gharama ya 1/7! Huwekwa upya kila siku saa 10:00 asubuhi.

#### MiniMax M2.1 (Uwekaji upya baada ya saa 5, $0.20/1M)

1. Jisajili: [MiniMax](https://www.minimax.io)
2. Pata ufunguo wa API → Dashibodi → Ongeza Ufunguo wa API

**Matumizi:** `minimax/MiniMax-M2.1` — **Kidokezo cha Kitaalamu:** Chaguo la bei nafuu zaidi kwa muktadha mrefu (tokeni 1M)!

#### Kimi K2 ($9/mwezi kwa kiwango kisichobadilika)

1. Jisajili: [Moonshot AI](https://platform.kimi.ai?aff=omniroute)
2. Pata ufunguo wa API → Dashibodi → Ongeza Ufunguo wa API

**Matumizi:** `kimi/kimi-k2.5` — **Kidokezo cha Kitaalamu:** Kiwango kisichobadilika cha $9/mwezi kwa tokeni 10M = gharama halisi ya $0.90/1M!

#### Baidu Qianfan / ERNIE

1. Jisajili: [Baidu AI Cloud Qianfan](https://cloud.baidu.com/product/wenxinworkshop)
2. Unda ufunguo wa API wa Qianfan → Dashibodi → Ongeza Ufunguo wa API: Mtoa Huduma: `qianfan`

**Matumizi:** `qianfan/ernie-5.1`, `qianfan/ernie-x1.1`, au kitambulisho kingine cha muundo wa Qianfan kinachooana na OpenAI.

### 🆓 Watoa Huduma BILA MALIPO

Watoa huduma wasiolipishwa ambao hawahitaji uthibitishaji wana swichi kando ya **Hakuna uthibitishaji unaohitajika** kwenye ukurasa wao wa mtoa huduma.
Kuizima humlemaza mtoa huduma huyo, humwondoa kwenye mionekano ya Watoa Huduma iliyosanidiwa/iliyofupishwa, na
huondoa miundo yake kutoka `/v1/models`.

#### Qoder (miundo 9 BILA MALIPO)

```bash
Dashibodi → Unganisha Qoder → Kuingia kwa OAuth → Ufikiaji unategemea vikomo vya sasa vya mtoa huduma

Miundo: if/qwen3.8-max-preview, if/qwen3.7-max, if/qwen3.7-plus, if/kimi-k3, if/kimi-k2.7-code, if/glm-5.2, if/deepseek-v4-pro, if/deepseek-v4-flash, if/minimax-m3
```

#### Kiro (Claude BILA MALIPO)

```bash
Dashibodi → Unganisha Kiro → AWS Builder ID au Google/GitHub → ~salio 50/mwezi

Miundo: kr/claude-sonnet-4.5, kr/claude-haiku-4.5
```

## 🎨 Michanganyiko

Unaweza kupanga upya kadi za michanganyiko moja kwa moja katika **Dashibodi → Michanganyiko** kwa kuburuta kishikio kwenye kila kadi. Mpangilio huhifadhiwa katika SQLite na kurejeshwa wakati wa kupakia upya.

```
Dashibodi → Michanganyiko → Unda Mpya

Jina: premium-coding
Miundo:
  1. cc/claude-opus-4-7 (Usajili wa msingi)
  2. glm/glm-4.7 (Nakala mbadala ya bei nafuu, $0.6/1M)
  3. minimax/MiniMax-M2.7 (Chaguo la mwisho la bei nafuu zaidi, $0.3/1M)

Tumia katika CLI: premium-coding
```

### Mfano wa 2: Bila Malipo Pekee (Gharama Sifuri)

```
Jina: free-combo
Miundo:
  1. if/kimi-k2.7-code (ufikiaji umeorodheshwa kuwa bila malipo; vikomo vya mtoa huduma vinaweza kutumika)
  2. kr/qwen3-coder-next (chaguo la mwisho lisilo na malipo la Kiro)

Gharama: kwa sasa imeorodheshwa kama $0; masharti na upatikanaji vinaweza kubadilika
```

## 🚀 Usambazaji

### Usakinishaji wa kimataifa wa npm (Unapendekezwa)

```bash
npm install -g omniroute

# Unda saraka ya usanidi
mkdir -p ~/.omniroute

# Unda faili la .env (angalia .env.example)
cp .env.example ~/.omniroute/.env

# Anzisha seva
omniroute
# Au kwa port maalum:
omniroute --port 3000
```

CLI hupakia `.env` kiotomatiki kutoka `~/.omniroute/.env` au `./.env`.

### Hali ya trei

Anzisha OmniRoute katika trei ya mfumo:

```bash
omniroute serve --tray
```

Amri hukamilika baada ya seva na trei kuwa tayari.

Seva huendelea kufanya kazi bila terminali.

Hali ya trei inatumia macOS, Windows na vipindi vya Linux vyenye kiolesura cha picha. Hali ya trei haifungui dashibodi kiotomatiki.

Tumia menyu ya trei kutekeleza vitendo hivi:

- Fungua dashibodi.
- Fungua `/dashboard/logs`.
- Badilisha uanzishaji otomatiki.
- Simamisha OmniRoute.

Usichanganye `--tray` na chaguo hizi:

- `--daemon`
- `--log`
- `--no-recovery`

Hali hizi zinahitaji umiliki tofauti wa mchakato.

Washa uanzishaji wakati wa kuingia kwenye mashine mara inayofuata:

```bash
omniroute autostart enable
```

Uanzishaji otomatiki hutumia hali ya trei kwenye macOS, Windows na vipindi vya Linux vyenye kiolesura cha picha. Linux isiyo na kiolesura cha picha hutumia huduma iliyopo ya mtumiaji ya systemd.

Zima uanzishaji wakati wa kuingia:

```bash
omniroute autostart disable
```

```bash
checksum=009400afee90a9f32599d8fe734145cfd84098140b7287990183dde45ae2245b
system_accounts="_omniroute"
omniroute_homedir="/var/lib/omniroute"

export npm_config_loglevel=error
export npm_config_fund=false

	# Tambua usanifu lengwa wa CPU kwa node-gyp

		aarch64*) _gyp_arch=arm64 ;;
		armv7*|armv6*) _gyp_arch=arm ;;
		i686*) _gyp_arch=ia32 ;;
		*) _gyp_arch=x64 ;;

	NODE_ENV=development npm ci --ignore-scripts

	local _bs3_release=.next/standalone/node_modules/better-sqlite3/build/Release

	rm -rf .next/standalone/node_modules/@img

	for _mod in pino-abstract-transport split2 process-warning; do
		cp -r "node_modules/$_mod" .next/standalone/node_modules/
	done
}

do_check() {
	npm run test:unit
}

do_install() {
	vmkdir usr/lib/omniroute/.next
	vcopy .next/standalone/. usr/lib/omniroute/.next/standalone

	# Zuia uondoaji wa saraka tupu za kipanga njia cha programu cha Next.js na kitendo cha baada ya usakinishaji
	for _d in \
		.next/standalone/.next/server/app/dashboard \
		.next/standalone/.next/server/app/dashboard/settings \
		.next/standalone/.next/server/app/dashboard/providers; do
		touch "${DESTDIR}/usr/lib/omniroute/${_d}/.keep"
	done

#!/bin/sh
export PORT="${PORT:-20128}"
export DATA_DIR="${DATA_DIR:-${XDG_DATA_HOME:-${HOME}/.local/share}/omniroute}"
export APP_LOG_TO_FILE="${APP_LOG_TO_FILE:-false}"

exec node /usr/lib/omniroute/.next/standalone/server.js "$@"
EOF
	vbin "${WRKDIR}/omniroute"
}

post_install() {
	vlicense LICENSE
}
```

```bash
# Ondoa: curl -X DELETE "http://localhost:20128/api/provider-models?provider=openai&model=gpt-5.2"
```

### Watoa Huduma Maalum Wanaooana na OpenAI

Lango lolote linalozungumza API ya OpenAI (proksi inayojipangisha, vLLM, mkusanyaji wa mtu wa tatu)
linaweza kuongezwa kama nodi yake mwenyewe ya mtoa huduma:

1. **Watoa Huduma → Ongeza Inayooana na OpenAI**.
2. **Jina**: lebo ya kuonyesha kwa nodi.
3. **Kiambishi awali**: jina la uelekezaji. Wateja huita mifano kama `<prefix>/<model>`, kwa hiyo nodi yenye
   kiambishi awali `mygw` hutoa `mygw/gpt-4o-mini`. Inahitajika; hakuna kikomo cha herufi.
4. **Aina ya API**: familia ya endpoint ambayo lango hutoa (Chat Completions, Responses,
   Embeddings, audio, images).
5. **URL Msingi**: mzizi wa API, hadi na ikijumuisha `/v1` (kwa mfano
   `https://gateway.example.com/v1`), si njia kamili ya `/chat/completions`. Milango yenye
   njia zisizo za kawaida huziweka chini ya **Mipangilio ya Kina** (njia ya chat, njia ya mifano).
6. Uga wa **API Key (kwa Ukaguzi)** hupima tu muunganisho. Baada ya kuunda nodi,
   ifungue na utumie **Ongeza Muunganisho** kuhifadhi ufunguo ambao maombi yatatumia.

Nodi hupata kitambulisho cha ndani cha umbo `openai-compatible-<apiType>-<uuid>`; huhitaji
kukiandika kamwe, kiambishi awali ndicho jina la umma.

#### Viambishi awali vilivyohifadhiwa

Kiambishi awali hakiwezi kuwa kitambulisho au jina la utani (alias) la mtoa huduma wa ndani (kwa mfano `openai`, `cf`), wala
kitambulisho cha mtoa huduma aliyestaafishwa. Kisuluhishi cha mifano huchunguza vitambulisho na majina ya utani vya ndani kabla ya
nodi maalum, kwa hiyo nodi inayotumia kimojawapo cha viambishi hivyo haitapokea trafiki kamwe:
`<prefix>/model` ingeenda kwa mtoa huduma wa ndani badala yake, au kufeli kwa kufungwa (fail closed) ikiwa mtoa huduma huyo
amestaafishwa. Kuunda au kuhariri nodi yenye kiambishi kama hicho hukataliwa kwa:

```text
prefix: "<prefix>" is a reserved provider prefix — choose a different prefix (reserved ids/aliases cannot be used for custom nodes because requests like <prefix>/model route to a built-in provider or fail closed when retired)
```

Chagua kiambishi awali tofauti kabisa (`mygw`, `acme-proxy`). Ikiwa maombi kwa nodi maalum yanafeli na
kosa linalotaja mtoa huduma wa ndani au vitambulisho vyake, angalia kama kiambishi awali cha nodi
kimehifadhiwa: nodi zilizohifadhiwa kabla ya kanuni hii kuwepo bado zimehifadhiwa, lakini kiambishi chao
cha awali huelekeza kwa mtoa huduma wa ndani. Hariri nodi na ukipe kiambishi awali kipya.

#### Chaguo za lango kwa kila muunganisho

Funguo hizi huenda kwenye `providerSpecificData` ya muunganisho (kwa mfano kupitia
`PUT /api/providers/{id}`):

- `toolNameMaxLength` (nambari kamili, 1–1024) — kwa miunganisho inayooana na umbizo la chat la OpenAI ambayo
  lango lake hukataa majina marefu ya zana. Majina marefu hutumwa kama majina mafupi ya badala na kurejeshwa katika

- `quotaEndpoint` — endpoint ya kiasi/mikopo ya lango, inayosomwa kwa ajili ya mkanda wa kiasi wa dashibodi na
  uelekezaji unaojali kiasi. Hufanya kazi kwenye miunganisho inayooana na OpenAI na Anthropic; umbo kamili
  limeandikishwa katika `open-sse/services/usage/openaiCompatible.ts`.

### Kuunganisha Wenza wa OmniRoute katika Mlolongo

Lango lingine la OmniRoute linaweza kuongezwa kama mtoa huduma **Maalum Anayooana na OpenAI**. Tumia
URL msingi ya `/v1` ya mwenza na ufunguo maalum wa API wenye ruhusa za chini kabisa uliootolewa na mwenza huyo.

Kwa minyororo ya kurudiana au ya hopi nyingi, washa ulinzi wa mzunguko unaowashwa kwa hiari kwenye kila lango:

```bash
# gateway-a
OMNIROUTE_INSTANCE_ID=gateway-a
OMNIROUTE_PEER_URLS=http://gateway-b:20128/v1
OMNIROUTE_PEER_MAX_HOPS=4
```

```bash
# gateway-b
OMNIROUTE_INSTANCE_ID=gateway-b
OMNIROUTE_PEER_URLS=http://gateway-a:20128/v1
OMNIROUTE_PEER_MAX_HOPS=4
```

Ni maombi yaliyotumwa kwa URL ya mwenza iliyoorodheshwa kwa wazi pekee yanayopokea
kichwa `X-OmniRoute-Peer-Trace`. Lango hukataa kitambulisho cha instansi kilichorudiwa au bajeti
ya hopi iliyokwisha na HTTP `508 Loop Detected`; watoa huduma wa kawaida wa upstream hawapokei metadata ya wenza.

Kuunganisha wenza katika mlolongo si unakisi wa hifadhidata wala failover wa mwenyeji. Kila
lango huhifadhi hali huru ya SQLite, akiba, vihesabio vya viwango, na vikao. Tumia reverse proxy yenye
ukaguzi wa afya au failover ya mteja kwa upatikano wa active/passive au active/active, na usiwahi
kupakia hifadhidata moja ya SQLite kwenye instansi nyingi za OmniRoute zinazoendeshwa.

### Cloudflare Quick Tunnel

- Inapatikana katika **Dashibodi → Endpoints** kwa Docker na usakinishaji mwingine wa kujihudumia (self-hosted)
- Huunda URL ya muda ya `https://*.trycloudflare.com` inayoelekeza kwa endpoint yako ya sasa ya `/v1` inayooana na OpenAI
- Uwezeshaji wa kwanza hufunga `cloudflared` tu inapohitajika; uanzishwaji upya wa baadaye hutumia tena binary hiyo hiyo inayodhibitiwa
- Quick Tunnels hazirudishwi kiotomatiki baada ya OmniRoute au kontena kuanzishwa upya; ziwazeshe tena kutoka kwenye dashibodi unapohitaji
- URL za tunnel ni za muda na hubadilika kila unaposimamisha/kuanzisha tunnel
- Quick Tunnels zinazodhibitiwa hutumia HTTP/2 transport kwa chaguo-msingi ili kuepuka onyo zenye kelele za QUIC UDP buffer katika kontena zenye vikwazo
- Weka `CLOUDFLARED_PROTOCOL=quic` au `auto` ikiwa unataka kubatilisha chaguo la transport linalodhibitiwa
- Weka `CLOUDFLARED_BIN` ikiwa unapendelea kutumia binary ya `cloudflared` iliyofungwa tayari badala ya upakuaji unaodhibitiwa
- Paneli za Cloudflare Quick Tunnel, Tailscale Funnel, na ngrok Tunnel zinaweza kuonyeshwa au kufichwa katika **Mipangilio → Muonekano**. Kuficha paneli hakusimamishi tunnel inayofanya kazi.

### Mikakati ya Uelekezaji

Sanidi kupitia **Dashibodi → Mipangilio → Uelekezaji**. Dashibodi huonyesha mikakati sita inayotumika zaidi; combo na auto-router zinasaidia seti pana zaidi ndani.

**Mikakati inayoonekana kwenye dashibodi (uelekezaji wa kiwango cha akaunti):**

| Mkakati                        | Maelezo                                                                                                       |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------- |
| **Fill First**                 | Hutumia akaunti kwa mpangilio wa kipaumbele — akaunti kuu hushughulikia maombi yote hadi isipopatikana        |
| **Round Robin**                | Huzunguka akaunti zote na kikomo cha sticky kinachoweza kusanidiwa (chaguo-msingi: miito 3 kwa kila akaunti)  |
| **P2C (Power of Two Choices)** | Huchagua akaunti 2 kwa nasibu na kuelekeza kwa iliyo na afya bora — husawazisha mzigo kwa kuzingatia afya     |
| **Random**                     | Huchagua akaunti kwa nasibu kwa kila ombi kwa kutumia Fisher-Yates shuffle                                    |
| **Least Used**                 | Huelekeza kwa akaunti yenye muhuri wa muda wa `lastUsedAt` wa zamani zaidi, ikisambaza trafiki sawasawa       |
| **Cost Optimized**             | Huelekeza kwa akaunti yenye thamani ya chini kabisa ya kipaumbele, ikiboresha kwa watoaji wa gharama ya chini |

**Mikakati ya hali ya juu ya combo na auto** (inayoweza kusanidiwa kwa kila combo au kupitia viambishi `auto/*` — angalia [AUTO-COMBO.md](../routing/AUTO-COMBO.md)):

- `priority` — mpangilio madhubuti, haifanyi round-robin kamwe
- `weighted` — mgawanyo wa trafiki kwa uwiano kulingana na uzani wa kila muundo
- `fill-first` — tumia muundo wa kwanza hadi vikomo vifikiwe
- `round-robin` / `strict-random` / `random`
- `p2c` (Power of Two Choices)
- `least-used` na `cost-optimized`
- `auto` — inayoongozwa na alama katika wagombea wote
- `lkgp` (Last Known Good Provider) — hubandikwa kwa mtoaji wa mwisho aliyefanikiwa, kisha hurejea kwenye sheria
- `context-optimized` — huchagua muundo wenye dirisha kubwa zaidi la muktadha huru
- `context-relay` — huunganisha miundo ya muktadha mrefu kwa zamu za ufuatiliaji

#### Header ya Sticky Session ya Nje

Kwa uhusiano wa kipindi wa nje (kwa mfano, mawakala wa Claude Code/Codex nyuma ya reverse proxies), tuma:

```http
X-Session-Id: your-session-key
```

OmniRoute pia hukubali `x_session_id` na hurejesha ufunguo wa kipindi unaotumika katika `X-OmniRoute-Session-Id`.

Ikiwa unatumia Nginx na kutuma header za umbizo la underscore, wezesha:

```nginx
underscores_in_headers on;
```

#### Majina Mbadala ya Miundo ya Wildcard

Unda ruwaza za wildcard ili kubadilisha upya majina ya miundo:


Wildcard zinasaidia `*` (herufi zozote) na `?` (herufi moja).

### Ustahimilivu na Vizunza Mzunguko

Sanidi kupitia **Dashibodi → Mipangilio → Ustahimilivu**.

OmniRoute hutekeleza ustahimilivu wa kiwango cha mtoa huduma kwa vipengele vitano:

1. **Foleni ya Maombi na Kupiga Hatua** — Uumbaji wa maombi wa kiwango cha mfumo:
   - **Maombi kwa Dakika (RPM)** — Maombi ya juu kabisa kwa dakika kwa kila akaunti
   - **Muda wa Chini Kati ya Maombi** — Nafasi ya chini katika millisekunde kati ya maombi
   - **Maombi ya Juu kwa Wakati Mmoja** — Maombi ya juu kabisa yanayofanyika kwa wakati mmoja kwa kila akaunti

2. **Ubaridishaji wa Muunganisho** — Usanidi wa kila aina ya uthibitishaji kwa muunganisho mmoja baada ya kushindwa kunakoweza kurudiwa:
   - **Ubaridishaji wa Msingi** — Dirisha chaguomsingi la ubaridishaji kwa kushindwa kwa ngazi ya juu kunakoweza kurudiwa
   - **Tumia Vidokezo vya Kurudia vya Ngazi ya Juu** — Huheshimu vidokezo rasmi vya `Retry-After` au vya kuweka upya vinapotolewa
   - **Hatua za Juu za Kusogea Nyuma** — Kiwango cha juu cha kusogea nyuma kwa kiasi cha kipeua kwa kushindwa kunakorudiarudia

3. **Kizunza Mzunguko cha Mtoa Huduma** — Hufuatilia kushindwa kwa mtoa huduma kutoka mwanzo hadi mwisho, humweka alama mtoa huduma kama ameharibika kwenye kizingiti cha onyo kilichosanidiwa, na hufungua kizunza kizingiti cha kushindwa kilichosanidiwa kinapofikiwa:
   - **Kizingiti cha Uharibifu** — Kushindwa kwa mtoa huduma kwa mfululizo kabla ya kuingia `DEGRADED`
   - **Kizingiti cha Kushindwa** — Kushindwa kwa mtoa huduma kwa mfululizo kabla ya kuingia `OPEN`
   - **Muda wa Kuisha wa Kuweka Upya** — Dirisha la muda kabla mtoa huduma hajajaribiwa tena
   - **CLOSED** (Nzima) — Maombi hutiririka kawaida
   - **DEGRADED** — Maombi bado hutiririka huku kushindwa kwa ongezeko kunafuatiliwa
   - **OPEN** — Mtoa huduma amezuiwa kwa muda baada ya kushindwa kwa mara kwa mara
   - **HALF_OPEN** — Inajaribu ikiwa mtoa huduma amepona

   Viwango vya `429` vya upeo wa muunganisho hubaki katika **Ubaridishaji wa Muunganisho** na havihesabiwi kwenye kizunza cha mtoa huduma.

   Hali ya wakati wa utekelezaji wa kizunza cha mtoa huduma huonyeshwa kwenye **Dashibodi → Afya** pekee.

4. **Subiri Ubaridishaji** — Ikiwa kila muunganisho mgombea tayari unapoa, OmniRoute inaweza kusubiri ubaridishaji wa mapema zaidi na kurudia ombi lile lile la mteja kiotomatiki.

5. **Utambuzi Kiotomatiki wa Kikomo cha Kiwango** — Watoa huduma wa ngazi ya juu wanaporejesha madirisha ya kusubiri ya wazi, vidokezo hivyo vinabatilisha ubaridishaji wa muunganisho wa ndani mpangilio huo unapowashwa.

**Kidokezo cha Kitaalamu:** Tumia ukurasa wa **Afya** kuchunguza na kuweka upya vizunza vya watoa huduma vilivyo hai baada ya kukatizwa kwa huduma. Ukurasa wa Ustahimilivu hubadilisha usanidi pekee.

### Kuhamisha Hifadhidata Nje / Ndani

Dhibiti nakala rudufu za hifadhidata katika **Dashibodi → Mipangilio → Mfumo na Hifadhi**.

| Kitendo                        | Maelezo                                                                                                                                                              |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Hamisha Hifadhidata Nje**    | Hupakua hifadhidata ya sasa ya SQLite kama faili ya `.sqlite`                                                                                                        |
| **Hamisha Yote Nje (.tar.gz)** | Hupakua kumbukumbu kamili ya nakala rudufu ikijumuisha: hifadhidata, mipangilio, combos, miunganisho ya watoa huduma (bila vitambulisho), metadata ya ufunguo wa API |
| **Hamisha Hifadhidata Ndani**  | Pakia faili ya `.sqlite` kubadilisha hifadhidata ya sasa. Nakala rudufu ya kabla ya uhamishaji huundwa kiotomatiki isipokuwa `DISABLE_SQLITE_AUTO_BACKUP=true`       |

```bash
# API: Hamisha hifadhidata nje
curl -o backup.sqlite http://localhost:20128/api/db-backups/export

# API: Hamisha yote nje (kumbukumbu kamili)
curl -o backup.tar.gz http://localhost:20128/api/db-backups/exportAll

# API: Hamisha hifadhidata ndani
curl -X POST http://localhost:20128/api/db-backups/import \
  -F "file=@backup.sqlite"
```

**Uthibitishaji wa Uhamishaji wa Ndani:** Faili iliyohamishwa ndani huthibitishwa kwa uadilifu (ukaguzi wa SQLite pragma), majedwali yanayohitajika (`provider_connections`, `provider_nodes`, `combos`, `api_keys`), na ukubwa (kiwango cha juu 100MB).

**Matumizi:**

- Hamisha OmniRoute kati ya mashine
- Unda nakala rudufu za nje kwa ajili ya kupona janga
- Shiriki usanidi kati ya wanachama wa timu (hamisha yote nje → shiriki kumbukumbu)

| **AI**           | Bajeti ya kufikiri (passthrough / auto-strip / custom / adaptive — angalia [THINKING_BUDGET.md](./THINKING_BUDGET.md)), agizo la mfumo la jumla, takwimu za akiba ya maagizo                    |
| **Usalama**      | Mipangilio ya Kuingia/Nenosiri, Udhibiti wa Ufikiaji wa IP, uthibitishaji wa API kwa `/models`, Kuzuia Watoa Huduma, ulinzi dhidi ya sindikizaji la maagizo                                     |
| **Uelekezaji**   | Mkakati wa uelekezaji wa jumla (Fill First / Round Robin / P2C / Random / Least Used / Cost Optimized), majina bandia ya modeli ya wildcard, minyororo ya mbadala, chaguomsingi za mchanganyiko |
| **Ustahimilivu** | Foleni ya maombi, kipindi cha kupoa kwa muunganisho, usanidi wa kivunjaji cha mtoa huduma, na tabia ya kusubiri kipindi cha kupoa                                                               |
| **Kina**         | Usanidi wa proxy wa jumla (HTTP/SOCKS5), ubatilishaji wa proxy kwa kila mtoa huduma                                                                                                             |

Jumla hajarudii tena maelezo ya kumbukumbu na akiba yanayosomeka tu. Mipangilio ya uhifadhi na
uboreshaji wa hifadhidata huhifadhiwa kupitia `/api/settings/database`; uondoaji wa akiba kwa mkono hutumia
`DELETE /api/cache`. Mipaka ya safu za kumbukumbu za maombi na proxy hudhibitiwa na
`CALL_LOGS_TABLE_MAX_ROWS` na `PROXY_LOGS_TABLE_MAX_ROWS`.

### Mikakati ya Usawazishaji wa Mchanganyiko

Sanidi usawazishaji wa kila mchanganyiko katika **Dashibodi → Mchanganyiko → Unda/Hariri → Mkakati**.

| Mkakati            | Maelezo                                                                                             |
| ------------------ | --------------------------------------------------------------------------------------------------- |
| **Round-Robin**    | Huzunguka kati ya modeli kwa mpangilio                                                              |
| **Priority**       | Hujaribu daima modeli ya kwanza; hurejea kwa mbadala tu inapotokea hitilafu                         |
| **Random**         | Huchagua modeli kwa nasibu kutoka kwenye mchanganyiko kwa kila ombi                                 |
| **Weighted**       | Huelekeza kwa uwiano kulingana na uzani uliowekwa kwa kila modeli                                   |
| **Least-Used**     | Huelekeza kwa modeli yenye maombi machache zaidi ya hivi karibuni (hutumia vipimo vya mchanganyiko) |
| **Cost-Optimized** | Huelekeza kwa modeli ya gharama nafuu zaidi inayopatikana (hutumia jedwali la bei)                  |

Chaguomsingi za jumla za mchanganyiko zinaweza kuwekwa katika **Dashibodi → Mipangilio → Uelekezaji → Chaguomsingi za Mchanganyiko**.
Muda wa kuisha kwa malengo ya mchanganyiko huperithi muda wa kuisha wa ombi la sasa kwa chaguomsingi. Tumia **Muda wa
kuisha kwa lengo (sekunde)** kwenye chaguomsingi za mchanganyiko au mchanganyiko binafsi tu inapohitajika
kikomo kifupi zaidi kwa kila lengo ili kuchochea mbadala wa haraka zaidi.

Uboreshaji wa mchanganyiko wa ucheleweshaji wa sifuri ni wa kuchagua kujiunga. Acha **Uboreshaji wa
ucheleweshaji wa sifuri** umezimwa ili kuzuia vipengele hivi vya ucheleweshaji kushindana na malengo
ya mbadala, kuruka malengo kulingana na historia ya TTFT, au kubana maombi ya mbadala; kuviwasha
kunaruhusu hedging iliyosanidiwa, kuruka kwa TTFT kwa utabiri, na ubanaaji wa mbadala wa kuchukua
hatua mapema kubadilisha uaminifu wa uelekezaji/maombi kwa ucheleweshaji mdogo zaidi wa mkia.

Zima **Hifadhi ya Tokeni za Kufikiri** wakati watoa huduma wa upstream wanahitaji vikwazo kamili vya `max_tokens` / `maxOutputTokens`. Inapowashwa, uelekezaji wa combo huongeza tu nafasi ya ziada ya modeli za kufikiri kwa modeli zenye kikomo cha pato kinachojulikana, na huacha kikomo cha tokeni cha mteja kisichobadilishwa wakati thamani salama iliyohifadhiwa ingezidi kikomo hicho. Ikiwa kikomo cha mteja tayari kiko juu ya kikomo kinachojulikana, OmniRoute hukipunguza hadi kikomo hicho kabla ya kutuma ombi la upstream.

## 🤖 Uelekezaji Otomatiki (Usanidi-sifuri)

OmniRoute huja na **kielekezaji otomatiki kinachoendeshwa na alama** ambacho huchagua modeli bora kwa kila ombi katika kila mtoa huduma aliyeunganishwa — hakuna mchanganyiko wa kudumisha. Tuma tu ombi ukitumia mojawapo ya viambishi awali vya `auto/*`, na OmniRoute itaunda mchanganyiko pepe papo hapo, huku ikiwapa watahiniwa alama kulingana na muda wa kusubiri, gharama, kiwango cha mafanikio, kufaa kwa muktadha, ufaafu wa modeli kwa kazi, kushindwa kwa hivi karibuni, mgao, na hali ya kivunja mzunguko.

| Kiambishi awali | Huboresha kwa ajili ya                                                                                               |
| --------------- | -------------------------------------------------------------------------------------------------------------------- |
| `auto`          | Chaguo-msingi lenye uwiano (muda wa kusubiri × gharama × kiwango cha mafanikio)                                      |
| `auto/coding`   | Kazi za uandishi wa msimbo: hupendelea Claude, GPT-5, GLM, Kimi, Qwen Coder, DeepSeek coders                         |
| `auto/cheap`    | $/token ya chini zaidi, hukubali muda mrefu zaidi wa kusubiri                                                        |
| `auto/fast`     | Muda mfupi zaidi wa kusubiri, hupuuza gharama                                                                        |
| `auto/offline`  | Watoa huduma wa ndani pekee (Ollama, vLLM, llama.cpp) — muhimu kwa usanidi usio na mtandao                           |
| `auto/smart`    | Ubora wa kufikiri kwanza (Opus, GPT-5 xhigh, R1, GLM 5.1 reasoning)                                                  |
| `auto/lkgp`     | "Mtoa Huduma Mzuri wa Mwisho Kujulikana" — humfungamanisha mtoa huduma aliyefaulu mwisho, kisha hurudi kwenye kanuni |

Mfano:

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer $OMNIROUTE_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "auto/coding",
    "messages": [{ "role": "user", "content": "Panga upya kitendakazi hiki cha Python" }],
    "stream": true
  }'
```

Kielekezaji otomatiki kimefafanuliwa kikamilifu katika [AUTO-COMBO.md](../routing/AUTO-COMBO.md) — ikijumuisha jinsi ya kurekebisha uzito wa alama, kuweka watoa huduma kwenye orodha nyeusi, na kukagua maamuzi ya uelekezaji katika **Dashibodi → Mchanganyiko Otomatiki**.

## 🔌 Muunganisho wa MCP na A2A

OmniRoute ni **seva ya MCP** (Itifaki ya Muktadha wa Modeli) na pia **seva ya A2A** (JSON-RPC 2.0 ya Wakala-kwa-Wakala). IDE yoyote inayooana na MCP au kipangishi cha wakala kinaweza kuita zana za OmniRoute moja kwa moja — hakuna kifungashio cha ziada kinachohitajika.

### Njia za usafirishaji za MCP

- **SSE**: `http://localhost:20128/api/mcp/sse`
- **HTTP inayoweza kutiririshwa**: `http://localhost:20128/api/mcp/stream`
- **stdio**: `omniroute --mcp` (kwa programu-jalizi za IDE zinazopendelea stdio)

### Unganisha Claude Desktop

Hariri `~/Library/Application Support/Claude/claude_desktop_config.json` (macOS) au faili inayolingana kwenye Windows/Linux:

```json
{
  "mcpServers": {
    "omniroute": {
      "command": "omniroute",
      "args": ["--mcp"]
    }
  }
}
```

### Unganisha Cursor / Continue / VS Code MCP

Tumia URL ya SSE `http://localhost:20128/api/mcp/sse` na ufunguo wa API wa Bearer uliozalishwa katika **Dashibodi → Funguo za API**.

### Mawanda

Kwa sasa MCP inafafanua mawanda 32 yenye majina. Kila ufunguo wa Bearer unaweza kuwekewa kikomo cha mawanda mahususi — angalia [MCP-SERVER.md](../frameworks/MCP-SERVER.md) kwa orodha rasmi ya mawanda na zana, na [A2A-SERVER.md](../frameworks/A2A-SERVER.md) kwa skema ya JSON-RPC.

## 💻 CLI ya Ndani

OmniRoute huja na CLI ya ndani (`omniroute …`) kwa ajili ya usanidi, uchunguzi na udhibiti wakati wa utekelezaji. Hii ni **tofauti na ukurasa wa "Zana za CLI" kwenye dashibodi**, ambao husanidi CLI za wahusika wengine (Claude Code, Cursor, Codex, Cline, …) ili ziweze kuwasiliana na OmniRoute.

```bash
omniroute setup                    # Mchawi shirikishi (nenosiri, watoa huduma, michanganyiko)
omniroute setup --non-interactive  # Inafaa kwa CI
omniroute doctor                   # Uchunguzi wa afya (saraka ya data, DB, watoa huduma, porti)
omniroute providers available      # Orodhesha watoa huduma wanaotumika
omniroute providers list           # Orodhesha miunganisho iliyosanidiwa
omniroute providers test <id>      # Jaribu moja kwa moja muunganisho wa mtoa huduma
omniroute combos list              # Orodhesha michanganyiko
omniroute combos switch <name>     # Weka mchanganyiko chaguo-msingi
omniroute models                   # Orodhesha modeli zinazopatikana (--json, --search)
omniroute keys add | list | remove # Dhibiti funguo za API kutoka kwenye terminali
omniroute backup                   # Hifadhi picha ya muda ya usanidi + DB
omniroute restore [<timestamp>]    # Rejesha kutoka kwenye picha ya muda
omniroute health                   # Afya ya kina (vikataji, akiba, kumbukumbu)
omniroute quota                    # Matumizi ya kiwango cha mtoa huduma
omniroute mcp status               # Hali ya seva ya MCP
omniroute a2a status               # Hali ya seva ya A2A
omniroute tunnel list|create|stop  # Vichuguu vya Cloudflare/Tailscale/ngrok
omniroute reset-password           # Weka upya nenosiri la msimamizi
omniroute --mcp                    # Anzisha seva ya MCP kupitia stdio
omniroute --port 3000              # Anzisha seva kwenye porti maalum
```

Kidokezo: unganisha `omniroute doctor --json` na zana yako ya ufuatiliaji ili kutoa arifa kuhusu miunganisho ya watoa huduma isiyo na afya.
