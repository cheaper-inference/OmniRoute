## `src/` — Programu ya Next.js

```
src/
├── app/                 # App Router (kurasa + njia za API + kurasa za hali + ukurasa wa kutua)
├── lib/                 # Maktaba za msingi / moduli za kikoa (sarakasi ndogo 80 + takriban faili 70 za kiwango cha juu)
├── domain/              # Mantiki halisi ya kikoa (injini ya sera, mbadala, gharama, kufungiwa nje, comboResolver, tathmini)
├── server/              # Moduli za seva pekee (mtiririko wa authz, cors, middleware ya uthibitishaji) — haziwezi kuingizwa kutoka kwa kiteja
├── shared/              # Zinazoshirikiwa kati ya seva na kiteja inapokuwa salama (thamani thabiti, aina, uthibitishaji, mikataba, zana)
├── i18n/                # Usanidi wa next-intl + JSON ya ujumbe kwa kila lugha (lugha 67)
├── middleware/          # Middleware ya Next.js (uboreshaji wa ombi, utambuzi wa lugha)
├── mitm/                # Kiini cha proksi ya MITM: utengenezaji/usakinishaji wa cheti, vishughulikiaji, malengo, kikaguzi, vinyago, upitishaji wa moja kwa moja
│   ├── handlers/        # Madarasa 9 ya vishughulikiaji vya wakala wa IDE yanayopanua MitmHandlerBase (antigravity, kiro, copilot, codex, cursor, zed, claudeCode, openCode, trae)
│   └── inspector/       # Tabaka la kunasa trafiki: buffer (mzunguko wa kumbukumbu), sseMerger, conversationNormalizer, kindDetector, contextKey, httpProxyServer, systemProxyConfig
├── models/              # Kiunganishi cha adapta za modeli (shim ya zamani)
├── scripts/             # Hati za matengenezo ndani ya mti (k.m., backfillAggregation)
├── sse/                 # Vishughulikiaji/huduma za zamani za SSE (chat.ts, chatHelpers.ts, services/auth.ts)
├── store/               # Hifadhi ya zamani ndani ya kumbukumbu (inaondolewa hatua kwa hatua ili kutumia src/lib/db)
├── types/               # Faili za aina za TS zinazoshirikiwa
├── instrumentation.ts   # Hook ya telemetria ya Next.js (kivinjari + edge)
├── instrumentation-node.ts  # Ufuatiliaji wa Node pekee
└── proxy.ts             # Shim ya ingizo la HTTP-proxy
```
