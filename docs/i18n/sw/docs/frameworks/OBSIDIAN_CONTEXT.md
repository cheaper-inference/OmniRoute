> **Chanzo rasmi:** `src/lib/obsidian/api.ts` (kiteja cha REST + usawazishaji),
> `src/lib/db/obsidian.ts` (uhifadhi wa tokeni / URL-msingi / WebDAV),

> (zana 22 za MCP), `src/app/api/settings/obsidian/route.ts` +
> `src/app/api/settings/obsidian/webdav/route.ts` (API za mipangilio). Usajili wa zana
> na uunganishaji wa mawanda hupatikana katika `open-sse/mcp-server/server.ts`.

## Ni nini

OmniRoute huunganishwa na vault ya **Obsidian** kama **chanzo cha muktadha** — hifadhi ya maarifa
ya ndani ya Markdown ambayo mawakala huisoma na kuiandikia kupitia seva ya MCP iliyojengewa ndani.
Muunganisho huu huwasiliana na programu-jalizi ya jumuiya ya **Obsidian Local REST API** inayoendeshwa
ndani ya programu ya eneo-kazi, ili mawakala waweze kutafuta madokezo, kusoma/kuandika/kurekebisha faili,
kuorodhesha vault, kufanya kazi na madokezo ya mara kwa mara ya kila siku/kila wiki, kudhibiti tagi,
kutekeleza amri za Obsidian, na (kwa hiari) kuratibu usawazishaji wa vault wa pande mbili
eneo-kazi↔simu.

Kiteja (`src/lib/obsidian/api.ts`) hufunika Local REST API kwa:

- **Kujaribu tena kwa muda wa kusubiri unaoongezeka** kwa hitilafu za muda za `5xx`, **muda wa mwisho wa sekunde 30** kupitia `AbortController`.
- **Uainishaji wa hitilafu wenye aina maalumu** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`.
- **Kidokezo rahisi cha "haiwezi kufikia Obsidian"** kinachoeleza kosa la kawaida la porti
  (HTTP kwenye `27123`, **si** endpoint ya MCP kwenye `27124`) na muundo wa Tailscale.
- **Usimbaji wa njia zinazohusiana na vault** ili njia za madokezo zenye nafasi/mikwaruzo ziwe salama.

## Usanidi

Hakuna **kigeu cha mazingira** cha tokeni ya Obsidian au URL ya msingi — vyote
vinahifadhiwa katika jedwali la SQLite `key_value` (nafasi ya majina `obsidian`) kupitia
`src/lib/db/obsidian.ts`. Tokeni **imesimbwa fiche inapohifadhiwa** (AES-256-GCM, ikiwa na
utaratibu mbadala wa uoanifu wa nyuma wa maandishi wazi). Sanidi kupitia kichupo cha **Vyanzo vya Muktadha** cha
dashibodi ya Endpoint (`ObsidianSourceCard`), au kupitia API ya REST ya mipangilio.

> [!IMPORTANT]
> Programu-jalizi ya **Obsidian Local REST API** lazima iwe imesakinishwa na inaendeshwa. Kiolesura chake cha REST
> husikiliza kwenye **HTTP `127.0.0.1:27123`** (URL chaguomsingi ya msingi). Porti `27124`
> ni endpoint tofauti ya MCP/HTTPS na inakataliwa waziwazi na njia ya mipangilio.
> Ikiwa unaunganisha kutoka kifaa kingine, tumia `http://<tailscale-ip>:27123`.

### Vifunguo vya usanidi (SQLite `key_value`, nafasi ya majina `obsidian`)

| Ufunguo           | Madhumuni                                                         | Imesimbwa fiche |
| ----------------- | ----------------------------------------------------------------- | --------------- |
| `api_key`         | Tokeni ya bearer ya Local REST API                                | ndiyo           |
| `base_url`        | URL ya msingi ya REST (chaguomsingi `http://127.0.0.1:27123`)     | hapana          |
| `vault_path`      | Njia kamili ya saraka ya vault (kwa ulandanishi)                  | hapana          |
| `webdav_username` | Jina la mtumiaji la WebDAV lililozalishwa (ulandanisaji wa vault) | hapana          |
| `webdav_password` | Nenosiri la WebDAV lililozalishwa (ulandanisaji wa vault)         | ndiyo           |
| `webdav_enabled`  | Ikiwa ulandanishaji wa vault wa WebDAV umewezeshwa                | hapana          |

### Sanidi kupitia REST

```bash
# Hifadhi + thibitisha tokeni ya Local REST API (POST huthibitisha kupitia ukaguzi wa hali)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# Kagua hali ya muunganisho (hurejesha connected, hasToken, baseUrl, vaultPath)
curl http://localhost:20128/api/settings/obsidian

# Kata muunganisho (hufuta tokeni iliyohifadhiwa)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

Mbinu zote zinahitaji uthibitishaji wa dashibodi. `POST` hukataa URL yoyote kwenye porti `27124`
na huthibitisha tokeni kwa kuita endpoint ya hali ya Local REST API kabla ya kuihifadhi.

### Ulandanishaji wa vault wa WebDAV

`src/app/api/settings/obsidian/webdav/route.ts` hudhibiti ulandanishaji wa hiari wa
vault unaotumia WebDAV (unaoendeshwa na `src/lib/obsidianSync.ts`). Kuuwezesha huielekeza OmniRoute kwenye
saraka ya vault ya ndani na huzalisha jozi nasibu ya jina la mtumiaji/nenosiri la WebDAV:

```bash
# Wezesha ulandanishaji wa WebDAV kwa saraka ya vault (huzalisha jina la mtumiaji/nenosiri)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# Pata hali ya ulandanishaji wa WebDAV (vitambulisho hurejeshwa tu wakati umewezeshwa)
curl http://localhost:20128/api/settings/obsidian/webdav

# Lemaza ulandanishaji wa WebDAV (hufuta vitambulisho + .stignore inayodhibitiwa)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### Chanzo cha muktadha kwa kila ufunguo wa API (hiari)

Usanidi wa Obsidian unaweza kuwekewa upeo **kwa kila ufunguo wa API** kupitia jedwali la `api_key_context_sources`
(`src/lib/db/apiKeyContextSources.ts`). Wakati mwito wa MCP unapokuwa na kitambulisho cha ufunguo wa API
kilichothibitishwa, `getObsidianConfigForApiKey()` hupendelea tokeni/URL-msingi/njia-ya-vault
ya ufunguo huo (`source: "api_key"`) na vinginevyo hutumia usanidi wa jumla kama mbadala (`source: "global"`).

Zana za MCP zisizo za ulandanishaji zinahitaji utambulisho wa mwitaji uliotambuliwa kabla ya kusoma usanidi huu.
Mwitaji asiye na utambulisho hupokea `Obsidian API token not configured`, na hakuna ombi la vault
linalotumwa. Wapigaji wa HTTP hutambuliwa kupitia vitambulisho vya maombi yao; wapigaji wa stdio
wanaweza kutambuliwa kupitia `OMNIROUTE_API_KEY` au `ROUTER_API_KEY`. Mwitaji wa HTTP ambaye
hajatambuliwa hawezi kurithi utambulisho wa mazingira wa seva. Vitambulisho vya kishikilia-nafasi pekee haviidhinishi
ufikiaji; kitambulisho halali cha mazingira kinachotambuliwa kama `env-key` bado kinaauniwa.
Funguo zilizothibitishwa bila usanidi wa Obsidian wa kila ufunguo huendelea kutumia usanidi wa jumla kama mbadala.
Zana nne za `obsidian_sync_*` hudumisha tabia yake tofauti ya tokeni ya ulandanishaji.

## Zana za MCP (22)

Zimefafanuliwa katika `open-sse/mcp-server/tools/obsidianTools.ts`. Tokeni/URL-msingi hutatuliwa
kwa kila mwito (ya ufunguo wa API kwanza, kisha ya jumla). Zana zinazofikia **seva ya usawazishaji**
ya OmniRoute (zana nne za `obsidian_sync_*`) pia zinahitaji tokeni ya uthibitishaji wa usawazishaji iliyosanidiwa
katika mipangilio ya OmniRoute.

### Zana za kusoma (`read:obsidian`)

| Zana                         | Maelezo                                                                                                                     |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `obsidian_check_status`      | Angalia kama Local REST API inaweza kufikiwa na imethibitishwa.                                                             |
| `obsidian_search_simple`     | Utafutaji wa maandishi yote katika maudhui ya madokezo; hurejesha vijisehemu pamoja na njia za faili.                       |
| `obsidian_search_structured` | Tafuta kwa kutumia usemi wa JSON Logic (vichujio vya and/or/regex/path).                                                    |
| `obsidian_read_note`         | Soma dokezo kwa njia inayohusiana na vault; kwa hiari kichwa/sehemu/frontmatter mahususi.                                   |
| `obsidian_list_vault`        | Orodhesha faili na saraka katika vault (mti wa vipengee).                                                                   |
| `obsidian_get_document_map`  | Pata muundo wa vichwa wa dokezo kama ramani ya vichwa → nambari za mistari.                                                 |
| `obsidian_get_note_metadata` | Pata frontmatter, lebo, viungo, na idadi ya herufi/maneno bila maudhui kamili.                                              |
| `obsidian_get_active_file`   | Pata njia + maudhui ya faili inayotumika kwa sasa katika Obsidian.                                                          |
| `obsidian_get_periodic_note` | Pata dokezo la mara kwa mara la kila siku/kila wiki/kila mwezi kwa tarehe fulani (leo ikiwa imeachwa).                      |
| `obsidian_get_tags`          | Orodhesha lebo zote za vault pamoja na masafa yake.                                                                         |
| `obsidian_list_commands`     | Orodhesha vitambulisho vya amri vya Obsidian vinavyopatikana (tumia pamoja na `obsidian_execute_command`).                  |
| `obsidian_sync_status`       | Hali ya seva ya usawazishaji ya OmniRoute: inaendeshwa, jina la vault, porti, muda wa kufanya kazi, usawazishaji wa mwisho. |
| `obsidian_sync_conflicts`    | Orodhesha migongano ya usawazishaji ambayo haijatatuliwa (njia, njia ya mgongano, muda wa kugunduliwa).                     |

### Zana za kuandika (`write:obsidian`)

| Zana                             | Maelezo                                                                                             |
| -------------------------------- | --------------------------------------------------------------------------------------------------- |
| `obsidian_write_note`            | Unda au andika upya dokezo kwa maudhui yaliyotolewa ya Markdown.                                    |
| `obsidian_append_note`           | Ongeza maudhui kwenye dokezo; kwa hiari kwenye kichwa/sehemu mahususi.                              |
| `obsidian_patch_note`            | Ongeza mwishoni/ongeza mwanzoni/badilisha kwa usahihi kwenye kichwa, sehemu, au uga wa frontmatter. |
| `obsidian_delete_note`           | Futa dokezo kabisa kutoka kwenye vault.                                                             |
| `obsidian_move_note`             | Hamisha au badilisha jina la dokezo ndani ya vault.                                                 |
| `obsidian_execute_command`       | Tekeleza amri ya Obsidian kwa kitambulisho chake cha amri.                                          |
| `obsidian_open_file`             | Fungua faili katika Obsidian (huiunda ikiwa haipo).                                                 |
| `obsidian_sync_trigger`          | Anzisha usawazishaji wa pande mbili wa vault wa desktop↔simu mara moja.                             |
| `obsidian_sync_resolve_conflict` | Tatua mgongano wa usawazishaji: hifadhi `local` (simu), `remote` (desktop), au `keep-both`.         |

> [!NOTE]
> Malengo ya `obsidian_patch_note` yanakubali `targetType` ya `heading | block | frontmatter`
> na `operation` ya `append | prepend | replace`, pamoja na `createTargetIfMissing`
> ya hiari. Zana nne za `obsidian_sync_*` huwasiliana na seva ya usawazishaji ya ndani
> (`http://127.0.0.1:27781` kwa chaguo-msingi) na zinahitaji tokeni ya usawazishaji.

### Wigo

Zana za kusoma zinahitaji `read:obsidian`; zana za kuandika zinahitaji `write:obsidian`. Utekelezaji
unafanana na wa Notion — hushughulikiwa na `withScopeEnforcement()` katika
`open-sse/mcp-server/server.ts`, ukiwezeshwa na `OMNIROUTE_MCP_ENFORCE_SCOPES=true`, huku
wigo unaoruhusiwa ukitolewa kutoka `OMNIROUTE_MCP_SCOPES` au muktadha wa wigo wa ufunguo wa API. Tazama
[MCP-SERVER.md](./MCP-SERVER.md).

## Vituo vya mwisho

| Mbinu    | Njia                            | Madhumuni                                                         |
| -------- | ------------------------------- | ----------------------------------------------------------------- |
| `GET`    | `/api/settings/obsidian`        | Hurejesha `{ connected, hasToken, baseUrl, vaultPath }`.          |
| `POST`   | `/api/settings/obsidian`        | Huhifadhi na kuthibitisha tokeni (hukataa porti `27124`).         |
| `DELETE` | `/api/settings/obsidian`        | Hukata muunganisho (hufuta tokeni iliyohifadhiwa).                |
| `GET`    | `/api/settings/obsidian/webdav` | Hali ya usawazishaji wa WebDAV na vitambulisho (ikiwa umewashwa). |
| `POST`   | `/api/settings/obsidian/webdav` | Huwasha usawazishaji wa WebDAV kwa saraka ya vault.               |
| `DELETE` | `/api/settings/obsidian/webdav` | Huzima usawazishaji wa WebDAV.                                    |

> Hizi ni njia za mipangilio ya dashibodi. Vault yenyewe hufikiwa kupitia API ya REST ya
> ndani ya Obsidian (`base_url` iliyosanidiwa) na kupitia zana za MCP zilizo hapo juu —
> hakuna kituo cha wakala cha umma cha Obsidian cha `/v1`.

## Matumizi

- **Majibu yanayotegemea vault** — `obsidian_search_simple` / `obsidian_search_structured`
  kisha `obsidian_read_note` ili ajenti ajibu kwa kutumia madokezo yako halisi.
- **Uandishi wa madokezo / shajara** — `obsidian_write_note`, `obsidian_append_note`, au
  `obsidian_patch_note` yenye usahihi wa hali ya juu ili kurekodi matokeo ya ajenti, muhtasari, au madokezo ya kila siku
  (`obsidian_get_periodic_note`) kwenye vault.
- **Uabiri wa vault** — `obsidian_list_vault`, `obsidian_get_document_map`, na
  `obsidian_get_tags` ili kuchunguza muundo kabla ya kusoma/kuandika.
- **Uendeshaji otomatiki wa Obsidian** — `obsidian_list_commands` + `obsidian_execute_command` ili
  kuendesha programu-jalizi/amri kupitia ajenti; `obsidian_open_file` ili kuonyesha dokezo kwenye UI.
- **Usawazishaji wa simu** — washa usawazishaji wa WebDAV, kisha `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`
  ili kuratibu kompyuta ya mezani↔simu na kutatua migongano.
