## جائزہ

سرچ ٹولز اسٹوڈیو `/dashboard/search-tools` کو ایک بنیادی سرچ پلے گراؤنڈ سے تین ٹیب والے اسٹوڈیو میں تبدیل کرتا ہے، جو ویب سرچ، ویب اسکریپنگ، اور فراہم کنندگان کے شانہ بہ شانہ موازنے کو یکجا کرتا ہے۔

```
┌ سرچ ٹولز ─────────────────────────────────────────────────────────────┐
│ [🔍 سرچ] [📄 اسکریپ] [⚖ موازنہ]                142ms · $0.001  </>    │
│ ⓘ [موڈیلٹیز کی رہنمائی]                                               │
├──────────────────────────────────────────┬─────────────────────────────┤
│  {فعال ٹیب کا مواد}                      │ ─ کنفیگ                     │
│                                          │ فراہم کنندہ [خودکار ∨]      │
│                                          │   🟢 Serper  $0.001         │
│                                          │   🟢 Tavily  $0.008         │
│                                          │   🔥 Firecrawl (fetch)      │
│                                          │ قسم   [web | news]          │
│                                          │ مکمل صفحہ [ ] (اسکریپ)      │
│                                          │ فارمیٹ [md|text|html]       │
│                                          │ ری رینک ماڈل [∨]            │
└──────────────────────────────────────────┴─────────────────────────────┘
```

## ٹیبز

### تلاش ٹیب

موجودہ `SearchForm` + `ResultsPanel` + `RerankPanel` ایک ٹیب میں تیار کرتا ہے:

- → نتائج سے استفسار کریں (عنوان، URL، ٹکڑا، متعلقہ سکور)۔
- کنفیگ پین میں فراہم کنندہ کا میٹا ڈیٹا (لاگت، کوٹہ، حیثیت)۔
- رینک سیکشن: دوبارہ رینک ماڈل منتخب کریں، نتائج کو دوبارہ ترتیب دیں، `positionDelta` دکھائیں۔
- CTA کے ساتھ خالی حالت جب کوئی تلاش فراہم کنندہ کنفیگر نہ ہو۔
- `SearchHistory.tsx` کے ذریعے تاریخ تلاش کریں۔
- کالز `POST /v1/search` (موجودہ اختتامی نقطہ، کوئی تبدیلی نہیں)۔

### سکریپ ٹیب

URL سے `POST /v1/web/fetch` کے ذریعے مواد نکالنے کے لیے نیا ٹیب (پلان 05 میں بنایا گیا):

- ان پٹ: URL + پورے صفحہ کو ٹوگل کریں + فارمیٹ سلیکٹر (مارک ڈاؤن / ٹیکسٹ / HTML)۔
- → fetch → رینڈر `ScrapeResult.tsx` جمع کروائیں۔
- `ScrapeResult` مارک ڈاؤن پیش نظارہ + را ٹوگل پیش کرتا ہے۔
- ٹوپی: اگر جواب جسم >** 256 KB** ، UI `(truncated, view raw)` دکھاتا ہے اور موناکو موڈل (D21) میں خام کھولتا ہے۔
- میٹا ڈیٹا پینل: فراہم کنندہ (firecrawl/jina-reader/tavily-search/tinyfish/nimble-search/anysearch-search/parallel-search/keenable-search)، تاخیر، لاگت، رسپانس سائز، لنکس شمار۔
- `useScrapeFetch.ts` ہک استعمال کرتا ہے۔

### ٹیب کا موازنہ کریں۔

تک ایک ہی query/URL چلاتا ہے۔** متوازی طور پر 4 فراہم کنندگان** (D22):

- فی فراہم کنندہ کے ساتھ ساتھ کالم۔
- میٹرکس: تاخیر، لاگت، نتائج کی گنتی، ردعمل کا سائز۔
- تلاش کے لیے URL اوورلیپ کیلکولیشن (مشترکہ URLs بمقابلہ ابتدائی نتیجہ کی تعداد)۔
- `POST /v1/search` (تلاش) یا `POST /v1/web/fetch` (سکریپ) فی فراہم کنندہ کو کال کرتا ہے۔

## کنفیگ پین (مشترکہ)

`SearchToolsConfigPane.tsx` — ہمیشہ نظر آتا ہے، سمیٹا جا سکتا ہے۔

| فیلڈ         | نوٹس                                                                        |
| ------------ | --------------------------------------------------------------------------- |
| فراہم کنندہ  | حالت کے بیج کے ساتھ ڈراپ ڈاؤن (کنفیگر شدہ / غائب / شرح کی حد عائد)          |
| قسم          | `web` یا `news` (صرف سرچ)                                                   |
| مکمل صفحہ    | اسکریپ کے لیے ٹوگل — پہلے نظر آنے والے مواد کے بجائے پورا صفحہ حاصل کرتا ہے |
| فارمیٹ       | `markdown`، `text`، یا `html` (صرف اسکریپ)                                  |
| ری رینک ماڈل | سرچ کے بعد دوبارہ درجہ بندی کے لیے اختیاری ماڈل                             |
| ہسٹری        | سمیٹا جا سکنے والا سرچ ہسٹری سیکشن                                          |

## SearchConceptCard

`SearchConceptCard.tsx` — ہمیشہ نظر آنے والا، سمیٹا جا سکنے والا accordion۔ وضاحت کرتا ہے:

| تصور                   | مختصر وضاحت                                                                  |
| ---------------------- | ---------------------------------------------------------------------------- |
| **تلاش**               | ویب نتائج کی فہرست حاصل کرتا ہے (عنوان، URL، اقتباس، مطابقت کا اسکور)        |
| **اسکریپ**             | کسی URL کا مکمل مواد اخذ کرتا ہے (markdown، متن یا HTML)                     |
| **موازنہ**             | ایک ہی query کو N providers میں ساتھ ساتھ چلاتا ہے                           |
| **دوبارہ درجہ بندی**   | query کی مطابقت بہتر بنانے کے لیے LLM کے ذریعے نتائج کو دوبارہ ترتیب دیتا ہے |
| **خودکار (سستا ترین)** | خودکار طور پر سب سے سستا دستیاب provider منتخب کرتا ہے                       |

## فراہم کنندہ کیٹلاگ

`ProviderCatalog.tsx` `GET /api/search/providers` سے فراہم کنندگان کی مکمل فہرست کو ظاہر کرتا ہے (F4 میں توسیع فراہم کرنے والوں کو شامل کرنے کے لیے):

| `kind` | `"search"` (24 فراہم کنندگان) یا `"fetch"` (فائر کرال، جینا ریڈر، ٹیویلی-سرچ، ٹنی فش، فرتیلا-تلاش، کوئی بھی تلاش-تلاش، متوازی-تلاش، قابل تلاش-تلاش) |

حیثیت ہے۔** درخواست کے وقت اخذ کیا گیا۔** چیک کر کے کہ آیا اسناد موجود ہیں اور کیا تمام چابیاں اس وقت کولڈاؤن میں ہیں۔

`codex-search` (Codex ویب تلاش) کی اپنی کوئی کلید نہیں ہے: یہ ایک منسلک Codex (ChatGPT) اکاؤنٹ کو دوبارہ استعمال کرتا ہے، لہذا ہر تلاش ChatGPT سبسکرپشن کوٹہ خرچ کرتی ہے اور تقریباً 10–40 سیکنڈ لیتی ہے۔ جب کوئی درخواست اس کا نام لیتا ہے تو یہ چلتا ہے۔ خودکار انتخاب کو `CODEX_SEARCH_AUTO_FALLBACK_ENABLED` فیچر فلیگ کی ضرورت ہے (بذریعہ ڈیفالٹ آف)۔

## بیک اینڈ تبدیلیاں

اس خصوصیت کے لیے صرف ایک بیک اینڈ تبدیلی کی ضرورت تھی:

### توسیع شدہ `GET /api/search/providers`

`src/app/api/search/providers/route.ts` کو بڑھا دیا گیا تھا:

- ہر بازیافت فراہم کنندہ (`firecrawl`, `jina-reader`, `tavily-search`, `tinyfish`, `nimble-search`, `anysearch-search`, `parallel-search`, `keenable-search`) کو صف میں شامل کریں۔
- ہر آئٹم میں `kind: "search" | "fetch"` شامل کریں۔
- لائیو اسناد کی حالت سے اخذ کردہ `status: "configured" | "missing" | "rate_limited"` شامل کریں۔
- پسماندہ مطابقت کو برقرار رکھیں — موجودہ فیلڈز (`id`, `name`, وغیرہ) میں کوئی تبدیلی نہیں ہے۔
