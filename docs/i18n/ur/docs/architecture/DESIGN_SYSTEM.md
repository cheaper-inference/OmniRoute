> **حیثیت:** ڈیش بورڈ پر بنایا گیا ہے۔**Keak CI UI Kit** (`@keak/cheaper-inference-ui-kit`)، اس ریپوزٹری میں بطور ورک اسپیس `packages/ui-kit` (`@omniroute/ui-kit`؛ اپ اسٹریم اسنیپ شاٹ کو `packages/ui-kit/UPSTREAM.md` میں پن کیا جاتا ہے اور `npm run check:ui-kit-snapshot` کے ذریعے محفوظ کیا جاتا ہے)۔ روشنی کیننیکل تھیم ہے۔ پہلے سے طے شدہ ترجیح `system` ہے۔ پہلے سے طے شدہ پیلیٹ کٹ کا ہے۔**Editions** ظاہری شکل (گرم کاغذ کے غیر جانبدار اور تانبے کا لہجہ `#e5ac82`, `packages/ui-kit/src/ci-editions.css`)؛ ترتیبات → ظاہری شکل → رنگ پیلیٹ پیش کرتا ہے۔**Classic** , چونے کے لہجے کے ساتھ کٹ کے بیس ٹوکن۔ Switzer UI اور ڈسپلے ٹیکسٹ کے لیے بنیادی فیملی ہے (`--ci-font-ui`؛ `--ci-font-display` اور `--ci-font-mono` اس کا حل)، خود کٹ کے ذریعہ خود میزبانی کی گئی ہے (`packages/ui-kit/src/ci-fonts.css`، درآمد شدہ بذریعہ `ci-tokens.css`)۔ ہر آئیکن ایک Lucide glyph ہے۔
>
> Inter Switzer سے غائب گلیفس کے لیے فال بیک ہے۔ `--font-mono` سسٹم مونو اسپیس اسٹیک `--ci-font-code` کے نقشے
>
> `src/app/globals.css` فال بیک فونٹس فی glyph منتخب کرتا ہے جب `Switzer` گلائف کی کمی ہوتی ہے: سیریلک، یونانی اور ویتنامی کے لیے `Inter` ، اور صرف `html[dir="rtl"]` کے تحت عربی رسم الخط کے لیے `Vazirmatn` ۔

`src/app/globals.css`:

```css
:root,
.ci-theme {
  --ci-font-ui:
    "Switzer", "Inter", -apple-system, BlinkMacSystemFont, "Segoe UI", Arial, sans-serif;
  --ci-font-code: ui-monospace, SFMono-Regular, Menlo, Consolas, "Liberation Mono", monospace;
  --font-mono: var(--ci-font-code);
}
```

## 1. جہاں چیزیں رہتی ہیں۔

- **کٹ** `packages/ui-kit/src` `packages/ui-kit/UPSTREAM.md` میں پن کی گئی کمٹ پر upstream `src/` کی بائٹ فی بائٹ کاپی ہے (جو لائسنس کی اجازت کو بھی ریکارڈ کرتی ہے)؛ `PATCHES.md` مقامی پیچ کی فہرست دیتا ہے۔ اسے ماخذ کے طور پر استعمال کیا جاتا ہے، بغیر کسی تعمیر کے: `next.config.mjs` اسے منتقل کرتا ہے، اور `tsconfig.json` نقشے `@omniroute/ui-kit` → `packages/ui-kit/src` اور `@omniroute/ui-kit/*` → `packages/ui-kit/src/*` (`vitest.config.ts` اور `vitest.mcp.config.ts` ایک ہی عرف کے ساتھ ہیں)۔ کٹ کے اجزاء کو اس کے سب پاتھ (`@omniroute/ui-kit/table`, `@omniroute/ui-kit/page-header`…) کے ذریعے درآمد کریں، کبھی بھی `@omniroute/ui-kit` بیرل کے ذریعے نہیں: بیرل ہر جزو (بشمول تاریخ چننے والے) کو ہر درآمد کنندہ میں کھینچتا ہے۔ کٹ اسٹائل شیٹ `src/app/globals.css` (`@import "../../packages/ui-kit/src/ci-styles.css"`، مکمل شیٹ: بنیادی `ci-ui.css` پلس ہر پیٹرن فیملی) کے ذریعے داخل ہوتی ہے۔
- **ٹوکنز۔** `packages/ui-kit/src/ci-tokens.css` `--ci-*` ٹوکنز کا اعلان کرتا ہے۔ `src/app/globals.css` انہیں OmniRoute ناموں (`--color-*`، `--radius-*`، `--font-sans`/`--font-mono`، `--table-*`، `--orch-status-*`، `--color-fd-*`) تک لے جاتا ہے، لہذا موجودہ `var(--color-*)` reads اور Tailwind افادیتیں کام کرتی رہیں۔ نیا کوڈ Tailwind افادیت (`bg-surface`, `text-text-muted`, `border-border`, `text-success`, `bg-success-bg`, `bg-chart-1`…) یا کٹ کلاسز — کبھی بھی ہیکس ویلیو نہیں استعمال کرتا ہے (`tests/unit/design-kit-bridge.test.ts` پل کو نافذ کرتا ہے)۔ `text-primary` `--text-color-primary` کے ذریعے `--color-primary-ink` کو حل کرتا ہے، لہذا بنیادی متن پڑھنے کے قابل رہتا ہے جب کہ `bg-primary`/`border-primary` لہجے کی سطح کو برقرار رکھتا ہے: Editions کے تحت یہ کٹ کا `--ci-color-accent-active` ہے (روشنی میں گہرا تانبے کا `#99562f` ، اندھیرے میں تانبے کا لہجہ)؛ Classic کے تحت، روشنی میں lime-800 اور اندھیرے میں چونے کا لہجہ۔ چارٹ سیریز `--color-chart-1` … `--color-chart-8` استعمال کرتی ہے، ہر ایک متن سے محفوظ `--color-chart-N-ink` اور ایک مبہم `--color-chart-N-subtle` چپ ٹنٹ کے ساتھ، کٹ سیریز کے آرڈر میں تفویض کردہ (`ciChartSeriesOrder`)۔
- **تھیمز** `<html className="ci-theme">` (`src/app/layout.tsx`) دستاویز کو کٹ تھیم میں منتخب کرتا ہے۔ ترجیح `light`، `dark` یا `system` ہے ( `src/shared/constants/appConfig.ts` میں `THEME_CONFIG.defaultTheme = "system"` ؛ `system` `prefers-color-scheme` پیروی کرتا ہے)۔ `applyTheme()` in `src/store/themeStore.ts` ( `THEME_BOOT_SCRIPT` کی طرف سے آئینہ دار، `src/app/layout.tsx` میں ان لائن کیا گیا، جو ہائیڈریشن سے پہلے چلتا ہے) `data-theme="dark"|"light"` سیٹ کرتا ہے اور `<html>` پر `.dark` کلاس کو ایک ساتھ ٹوگل کرتا ہے۔ کٹ کا گہرا ٹوکن سیٹ `data-theme="dark"` (`packages/ui-kit/src/ci-tokens.css`) پر کیا جاتا ہے۔ OmniRoute کی اپنی ڈارک اوور رائیڈز ( `globals.css` میں `.dark` بلاک) اور `.dark` کلاس پر لیگیسی Tailwind `dark:` یوٹیلیٹیز کلید۔ کوئی تلفظ رنگ کے پیش سیٹ نہیں ہیں: تلفظ ہمیشہ کٹ سے آتا ہے، اور اسٹور کے لوڈ ہونے پر پرانی تعمیر سے ایک مستقل پیش سیٹ کو گرا دیا جاتا ہے۔
- **پیلیٹس۔** دو، دونوں کٹ (`src/shared/constants/appearancePalette.ts`): `editions`، ڈیفالٹ، اور `classic`۔ Editions `<html>` پر کٹ کا `data-ci-appearance="editions"` وصف ہے، جو `ci-editions.css` ( `ci-ui.css` کے ذریعے درآمد کیا گیا) `data-theme` کے ساتھ جوڑتا ہے۔ Classic وصف کی غیر موجودگی ہے۔ روٹ لے آؤٹ سرور انتساب کو پیش کرتا ہے، اس لیے ایک وزیٹر جس میں کچھ بھی ذخیرہ نہیں ہوتا ہے (یا کوئی JS) ہر سطح کے — ڈیش بورڈ، لاگ ان، `/status`، ایرر پیجز، `/docs` اور PWA پر Editions حاصل کرتا ہے۔ انتخاب اسی `theme` اسٹور میں تھیم کے آگے برقرار رہتا ہے (`palette`, `setPalette()`, `applyPalette()` میں `src/store/themeStore.ts`) اور پینٹ سے پہلے `THEME_BOOT_SCRIPT` (`src/shared/utils/themeBootScript.ts`, ترتیب کے `<head>` میں ان لائن کیا جاتا ہے) کا اطلاق ہوتا ہے، جو صرف اس وصف کو ہٹاتا ہے جب ذخیرہ شدہ پیلیٹ `"classic"` ہو؛ `src/app/global-error.tsx`، روٹ لے آؤٹ سے باہر، اسی اسٹور سے لاگو ہوتا ہے۔ کسی دوسرے عنصر پر `data-ci-appearance` نہ لگائیں: کٹ اس سے `html:root:has([data-ci-appearance="editions"])` سے مماثل ہے، لہذا ایک اولاد پوری دستاویز کو بدل دے گی۔ Editions `data-ci-editions-variant="landing"` ویرینٹ مارکیٹنگ کے صفحات کے لیے ہے، ڈیش بورڈ کے لیے نہیں۔ براؤزر کروم: سرور ڈیفالٹ، Editions، `viewport.themeColor` میں (ایک ٹیگ فی `prefers-color-scheme`) اور ویب مینی فیسٹ — `PWA_THEME_COLORS` `src/shared/constants/pwaThemeColors.ts` میں، Editions `--ci-color-background` کا ایک آئینہ (`#f3f1e9` / `#11120f` to `ci-editions.css` ) `tests/unit/pwa-theme-colors.test.ts` لائیو `<meta name="theme-color">` پھر ذخیرہ شدہ پیلیٹ اور موڈ کی پیروی کرتا ہے: `THEME_BOOT_SCRIPT` پینٹ سے پہلے ٹیگز کو دوبارہ لکھتا ہے اور تھیم اسٹور کے اعمال ہر تبدیلی پر کرتے ہیں ( `src/shared/utils/themeColorMeta.ts` میں `resolveThemeColor()` / `applyThemeColor()` ، `CLASSIC_PAGE_BACKGROUND` کے ساتھ کٹ کے `ciTokens` سے پڑھا جاتا ہے)۔ ایک واضح light/dark تھیم ہر ٹیگ کو اس موڈ پر سیٹ کرتا ہے۔ `system` ہر اسکیم میں ایک رنگ رکھتا ہے۔ مینی فیسٹ Editions رہتا ہے: یہ ترجیح کے بغیر، فی انسٹال پر ایک بار حاصل کیا جاتا ہے۔ موناکو تحقیقات سے اپنے رنگ پڑھتا ہے (`monacoKitTheme.ts`); Editions کے تحت پروب ریڈ ایک سنکرونس پاس کے لیے روٹ `data-theme` پلٹ دیتی ہے، کیونکہ کٹ Editions light/dark جڑ سے حل کرتی ہے۔
- **اجزاء (اڈیپٹر)۔** `src/shared/components/index.tsx` OmniRoute جزو API (ایک جیسے نام، پہلے سے طے شدہ برآمدات اور پروپس) کو رکھتا ہے، اور اس کے پیچھے پرائمیٹوز کٹ کے اوپر اڈاپٹر ہیں: فارمز (`Button` `Loading` `Input`, `Textarea`, `Checkbox`, `Select`, `Toggle`, `Badge`/ `Card`)،`Modal`,`ConfirmModal`/ `Tooltip`,`InfoTooltip`, `NotificationToast`, `EmptyState`)، ساخت (`Collapsible`, `CollapsibleSection`, `SegmentedControl`, `Breadcrumbs`, `Avatar`) اور میزیں (`DataTable`, `FilterBar`, `ColumnToggle`, `FilterPills`, `PresetSlider`) ایک اڈاپٹر کٹ کے اجزاء کو سب پاتھ کے ذریعے درآمد کرتا ہے اور اس پر لیگیسی پرپس کا نقشہ — کرتا ہے مثال کے طور پر `Button variant="primary"` کٹ `default` بٹن ہے (`--ci-button-primary-*`: روشنی میں الٹی سطح، اندھیرے میں اس کی `--ci-color-accent-foreground` سیاہی کے ساتھ لہجہ)، `danger` `destructive` ہے، اور `warning` بٹن ہے `warning` `Badge` اسٹیٹس ویریئنٹس کٹ ٹونز ہیں، اور `<option>` بچوں کے ساتھ `Select` کٹ کو `NativeSelect` پیش کرتا ہے۔ `tests/unit/ui/adapters/*.test.tsx` ہر اڈاپٹر کو پن کریں۔
- **شیل.** `src/app/(dashboard)/layout.tsx` `DashboardLayout` رینڈر کرتا ہے، جو `src/shared/components/layouts/DashboardShell.tsx` رینڈر کرتا ہے: kit `SidebarProvider` / `Sidebar` / `SidebarInset` (`packages/ui-kit/src/sidebar.tsx`)، `src/shared/components/Sidebar.tsx` میں OmniRoute کی نیویگیشن منطق کے ساتھ۔ `#main-content` کا "مواد پر جائیں" کا لنک پہلا فوکس ایبل عنصر ہے۔ `src/shared/components/Header.tsx` کٹ `SidebarTrigger` (شیل کا واحد سائڈبار ٹوگل)، Keak `ProductSwitcher` اور کمانڈ پیلیٹ اوپنر رکھتا ہے۔ یہ روٹ ٹائٹل صرف اس وقت دکھاتا ہے جب کہ `#main-content` کے اندر کوئی کٹ `PageHeader` (`.ci-page-header`) نصب نہیں ہے، اس لیے اس کے اپنے `PageHeader` والے صفحہ میں ایک `h1` ہوتا ہے۔ `src/shared/components/CommandPalette.tsx` ایک کٹ `Dialog` ہے۔

## 5. kit کو اپڈیٹ کرنا

`npm run check:ui-kit-upstream` اپ اسٹریم ریپو کے تازہ ترین `v*` ٹیگ کے ساتھ `packages/ui-kit/UPSTREAM.md` میں پن کیے ہوئے ورژن کا موازنہ کرتا ہے اور جب کوئی ریلیز ختم ہوتا ہے تو sync کمانڈ پرنٹ کرتا ہے۔

روزانہ `UI Kit upstream watch` ورک فلو (`.github/workflows/ui-kit-upstream-watch.yml`) ایک ہی چیک چلاتا ہے۔ جب پن پیچھے ہے، `scripts/ci/ui-kit-sync-pr.sh` ایک سنک PR سب سے زیادہ `release/vX.Y.Z` برانچ کے خلاف، رولنگ برانچ `chore/ui-kit-sync-latest` پر کھلا رکھتا ہے۔ یہ کبھی ضم نہیں ہوتا ہے: ہر کٹ ریلیز کو اب بھی مقامی VPS پر ایک بصری جانچ کی ضرورت ہے۔ برانچ کو دوبارہ تعمیر کیا جاتا ہے جب ایک نئی ریلیز باہر ہوتی ہے اور دوسری صورت میں اسے تنہا چھوڑ دیا جاتا ہے۔ ہاتھ سے دھکیلنے والے کمٹ کے ساتھ ایک کھلا PR اوور رائٹ نہیں ہوتا ہے، اور ایک ایسے ورژن کے لیے PR جسے دیکھ بھال کرنے والے نے غیر انضمام شدہ بند کر دیا ہے، نئی ریلیز تک بند رہتا ہے۔

جب کوئی PR نہیں کھولا جا سکتا ہے (ٹارگٹ ریلیز منجمد ہے، PR نے ہاتھ سے دھکیل دیا ہے، PR بند کر دیا گیا ہے، یا کوئی PR ٹوکن سیٹ نہیں ہے) ورک فلو ایک ٹریکنگ ایشو کو کھلا رکھتا ہے جو کہتا ہے۔

ورک فلو دو راز استعمال کرتا ہے:

- `secrets.UI_KIT_READ_TOKEN`: نجی اپ اسٹریم ریپو کے لیے صرف پڑھنے کے لیے ٹوکن۔ جب اپ اسٹریم چیک ڈیٹا کو نہیں پڑھ سکتا ہے (کوئی ٹوکن نہیں، ایسا ٹوکن جس نے کام کرنا بند کردیا، یا GitHub ناقابل رسائی)، یہ `unknown` اطلاع دیتا ہے اور کوڈ `0` کے ساتھ باہر نکلتا ہے۔ ورک فلو ایک انتباہ لکھتا ہے اور ٹریکنگ کے ایک الگ مسئلے کو کھلا رکھنے کی کوشش کرتا ہے۔ بعد میں کامیاب رن رسائی کی واپسی کے بعد اسے بند کر دیتا ہے۔ GitHub ایشو کی ناکامی API کام کو ناکام کر دیتی ہے۔
- `secrets.UI_KIT_SYNC_PR_TOKEN`: اس ریپوزٹری پر ایک عمدہ ٹوکن جس میں مواد اور پل کی درخواستیں تحریری رسائی ہے۔ یہ ورک فلو مطابقت پذیری PRs کھولتا ہے یا اپ ڈیٹ کرتا ہے جب وقف شدہ ٹوکن کنفیگر ہو جاتا ہے۔ اس کے بغیر، ورک فلو برانچ کو آگے بڑھاتا ہے اور رپورٹ کرتا ہے کہ کوئی PR نہیں کھولا گیا۔

`scripts/dev/sync-ui-kit.sh <commit|latest> [clone]` upstream `src/` اس کمٹ پر کاپی کرتا ہے (`latest` = جدید ترین `v*` ٹیگ) `packages/ui-kit/src` میں، واحد اجازت شدہ تبدیلی کو لاگو کرتا ہے (یہ متعلقہ درآمدات سے `.js` لاحقہ گرتا ہے)، اور `packages/ui-kit/package.json` اور `package-lock.json` میں ورک اسپیس ورژن کو اپ اسٹریم والے پر سیٹ کرتا ہے۔ پھر: `git diff packages/ui-kit` کا جائزہ لیں، دونوں تھیمز میں فراہم کنندگان، ترتیبات، کومبوز، استعمال اور اختتامی نقطہ پر ایک بصری پاس کریں، `npm run check:ui-kit-snapshot` اور `npm run test:vitest:ui` چلائیں، اور PR اپ اسٹریم چینج لاگ کے ساتھ کھولیں۔
