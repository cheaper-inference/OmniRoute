## زمرہ جات

- **مفت** — فری ٹائر API کلید کے ساتھ (ڈیش بورڈ کے ذریعے تشکیل شدہ)
- **No-auth** — پبلک اینڈ پوائنٹس جن کے لیے کسی کلید یا سائن ان کی ضرورت نہیں ہے۔
- **OAuth** — سائن ان فلو OmniRoute کے ذریعے ہینڈل کیا جاتا ہے، API کلید کی ضرورت نہیں ہے۔
- **ویب کوکی** — کوکی auth کے ذریعے فراہم کنندہ کی ویب ایپ کو لپیٹ دیتا ہے۔
- **API کلید** — ادا شدہ فراہم کنندہ کو API کلید کے ذریعے ترتیب دیا گیا ہے (مفت کریڈٹ لاگو ہو سکتے ہیں)
- **مقامی** — صارف کی مشین پر چلتا ہے (Ollama، LM اسٹوڈیو، vLLM، وغیرہ)
- **تلاش کریں۔** — ویب تلاش فراہم کرنے والے
- **آڈیو** — صرف آڈیو فراہم کرنے والے (TTS/STT)
- **اپ اسٹریم پراکسی** — فراہم کرنے والے جو دوسرے فراہم کنندگان کو پراکسی کرتے ہیں۔
- **کلاؤڈ ایجنٹ** — طویل عرصے سے چلنے والے کوڈنگ ایجنٹس (Codex کلاؤڈ، Devin، Jules)
- **سسٹم** — OmniRoute-اندرونی فراہم کنندگان (لوپ بیک، وغیرہ)

اضافی ٹیگز: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (جہاں دکھایا گیا ہے): `native` — اصلی فنکشن کالنگ API; `emulated` — `tools` سرنی کو `webTools.ts` (regex-parsed `<tool>{...}</tool>` بلاکس) کے ذریعے فوری طور پر نقل کیا جاتا ہے؛ `none` — `tools` فی الحال خاموشی سے چھوڑ دیا گیا ہے۔ #7286 دیکھیں۔

ہر فراہم کنندہ کو فعال کرنے، ترتیب دینے اور جانچنے کے لیے `/dashboard/providers` پر ڈیش بورڈ کا استعمال کریں۔
