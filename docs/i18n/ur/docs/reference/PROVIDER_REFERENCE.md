کل فراہم کنندگان: **376**۔ ذیل میں زمرہ وار تفصیل دیکھیں۔

## زمرے

- **مفت** — API کلید کے ساتھ مفت درجہ (ڈیش بورڈ کے ذریعے ترتیب دیا جاتا ہے)
- **بلا توثیق** — عوامی اینڈ پوائنٹس جن کے لیے کسی کلید یا سائن اِن کی بالکل ضرورت نہیں
- **OAuth** — سائن اِن کا عمل OmniRoute سنبھالتا ہے، API کلید درکار نہیں
- **ویب کوکی** — کوکی توثیق کے ذریعے فراہم کنندہ کی ویب ایپ کو ریپ کرتا ہے
- **API کلید** — API کلید کے ذریعے ترتیب دیا گیا بامعاوضہ فراہم کنندہ (مفت کریڈٹس لاگو ہو سکتے ہیں)
- **مقامی** — صارف کی مشین پر چلتا ہے (Ollama، LM Studio، vLLM وغیرہ)
- **تلاش** — ویب تلاش کے فراہم کنندگان
- **آڈیو** — صرف آڈیو فراہم کنندگان (TTS/STT)
- **اپ اسٹریم پراکسی** — وہ فراہم کنندگان جو دوسرے فراہم کنندگان کے لیے پراکسی کا کام کرتے ہیں
- **کلاؤڈ ایجنٹ** — طویل عرصے تک چلنے والے کوڈنگ ایجنٹس (Codex Cloud، Devin، Jules)
- **سسٹم** — OmniRoute کے داخلی فراہم کنندگان (loopback وغیرہ)

اضافی ٹیگز: `image`، `video`، `aggregator`، `enterprise`، `embed/rerank`، `self-hosted`۔

`ٹول کالنگ` (جہاں دکھائی گئی ہو): `native` — حقیقی فنکشن کالنگ API؛ `emulated` — `tools` ارے کو `webTools.ts` کے ذریعے پرامپٹ میں نقل کیا جاتا ہے (regex کے ذریعے پارس کیے گئے `<tool>{...}</tool>` بلاکس)؛ `none` — فی الحال `tools` کو خاموشی سے نظر انداز کر دیا جاتا ہے۔ #7286 دیکھیں۔

ہر فراہم کنندہ کو فعال، ترتیب دینے اور جانچنے کے لیے `/dashboard/providers` پر موجود ڈیش بورڈ استعمال کریں۔
