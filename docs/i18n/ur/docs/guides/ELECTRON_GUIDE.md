> **سچائی کا ماخذ:** `electron/` کام کی جگہ** آخری اپ ڈیٹ:** 2026-06-28 — v3.8.40

OmniRoute ایک کراس پلیٹ فارم ڈیسک ٹاپ ایپ (Windows / macOS / Linux) بھیجتا ہے**Electron 41** +** الیکٹران بلڈر 26.10** . ڈیسک ٹاپ ایپ ایک چائلڈ پروسیس کے طور پر Next.js اسٹینڈ اسٹون سرور کو جنم دیتی ہے، اس پر `BrowserWindow` کی نشاندہی کرتی ہے، اور سسٹم ٹرے، آٹو اپڈیٹر، IPC برج، اور زیرو کنفگ سیکرٹ بوٹسٹریپ شامل کرتی ہے۔

## فن تعمیر

```
┌──────────────────────────────────────────────┐
│ Electron main process (electron/main.js)     │
│ ├─ Single-instance lock                       │
│ ├─ Child process: Next.js standalone server  │
│ │   (spawned with Electron's Node runtime)   │
│ ├─ BrowserWindow → http://localhost:PORT     │
│ ├─ System tray + context menu                │
│ ├─ Auto-update via electron-updater          │
│ ├─ Content Security Policy (session headers) │
│ └─ Secret bootstrap (JWT / API_KEY_SECRET)   │
└──────────────────────────────────────────────┘
            ↕ IPC bridge (electron/preload.js)
┌──────────────────────────────────────────────┐
│ Renderer (Next.js dashboard)                  │
│   window.electronAPI.* (contextIsolation)     │
└──────────────────────────────────────────────┘
```

## اختیاری رن ٹائم پیک

ڈیسک ٹاپ بلڈز اپنے انسٹالرز کے ساتھ اختیاری رن ٹائم آرکائیوز شائع کر سکتے ہیں۔ انسٹال شدہ سرور پے لوڈ میں `optional-packs.index.json` ( Windows اور Linux پر `resources/app` کے تحت) ہوتا ہے۔ `browser-runtime` اندراج کے لیے، `packs[].tarball` پڑھیں اور ڈاؤن لوڈ کریں۔** اسی ریلیز سے عین مطابق فائل کا نام** . آرکائیو کے ناموں میں ایک SHA-256 ڈائجسٹ شامل ہے۔ مختلف تعمیرات کو مختلف آرکائیوز کی ضرورت ہو سکتی ہے۔ ڈاؤن لوڈ کردہ فائل کا نام تبدیل نہ کریں۔

انسٹال کردہ ایپ کے انڈیکس اور منتخب شدہ آرکائیو کو ایک ڈائرکٹری میں کاپی کریں، پھر اسی ریلیز سے CLI استعمال کریں:

```bash
omniroute packs list --source /path/to/packs
omniroute packs install browser-runtime --source /path/to/packs
```

`packs list` انسٹالیشن اور تصدیقی حالت کو ظاہر کرتا ہے، آرکائیو فائل کا نام نہیں۔ بنڈل انڈیکس آرکائیو کو منتخب کرتا ہے۔ انسٹالیشن نکالنے سے پہلے اپنے آرکائیو چیکسم کی تصدیق کرتی ہے اور انسٹال شدہ پیک کو تبدیل کرنے سے پہلے اس کے پیکج چیکسم کی تصدیق کرتی ہے۔ یہ مقامی فائلوں کو پڑھتا ہے۔ یہ گمشدہ آرکائیوز کو ڈاؤن لوڈ نہیں کرتا ہے۔ تنصیب کے بعد ایپلیکیشن کو دوبارہ شروع کریں۔ اگر ریلیز کا کوئی مماثل اثاثہ نہیں ہے، تو اختیاری پیک اس ریلیز کے اثاثوں کے ذریعے دستیاب نہیں ہے۔

## IPC پل (`preload.js`)

پری لوڈ `contextIsolation: true` اور `nodeIntegration: false` کے ساتھ `contextBridge` کا استعمال کرتے ہوئے `window.electronAPI` پر وائٹ لسٹ شدہ API ظاہر کرتا ہے۔

```javascript
const VALID_CHANNELS = {
  invoke: [
    "get-app-info",
    "open-external",
    "get-data-dir",
    "restart-server",
    "check-for-updates",
    "download-update",
    "install-update",
    "get-app-version",
  ],
  send: ["window-minimize", "window-maximize", "window-close"],
  receive: ["server-status", "port-changed", "update-status"],
};
```

بے نقاب طریقے:

| پیش کنندہ کال                                                     | قسم                      |
| ----------------------------------------------------------------- | ------------------------ |
| `getAppInfo()` → `{ name, version, platform, isDev, port }`       | پکارنا                   |
| `openExternal(url)`                                               | پکارنا                   |
| `getDataDir()`                                                    | پکارنا                   |
| `restartServer()`                                                 | پکارنا                   |
| `getAppVersion()`                                                 | پکارنا                   |
| `checkForUpdates()` / `downloadUpdate()` / `installUpdate()`      | پکارنا                   |
| `minimizeWindow()` / `maximizeWindow()` / `closeWindow()`         | بھیجیں                   |
| `onServerStatus(cb)` / `onPortChanged(cb)` / `onUpdateStatus(cb)` | وصول کریں (واپسی ڈسپوزر) |

وصول کنندگان کی واپسی a** ڈسپوزر فنکشن** `removeAllListeners` — پر بھروسہ کرنے کے بجائے یہ سننے والوں کو جمع ہونے سے روکتا ہے جب React اجزاء دوبارہ ماؤنٹ ہوتے ہیں۔

## سرور لائف سائیکل

`main.js` نظام نوڈ کے ساتھ مقامی ماڈیول ABI مماثلت سے بچنے کے لیے براہ راست Electron نوڈ رن ٹائم کے ساتھ Next.js اسٹینڈ اسٹون بنڈل تیار کرتا ہے:

```js
spawn(process.execPath, [serverScript], {
  cwd: NEXT_SERVER_PATH,
  env: { ...serverEnv, PORT, NODE_ENV: "production", ELECTRON_RUN_AS_NODE: "1", NODE_PATH },
  stdio: "pipe",
});
```

جھلکیاں:

- `waitForServer()` ونڈو دکھانے سے پہلے URL کو 30 سیکنڈ تک پول کرتا ہے (کولڈ اسٹارٹ پر کوئی خالی اسکرین نہیں)۔
- `stdio: "pipe"` stdout/stderr پر قبضہ کرتا ہے؛ تیار جملے (`Ready` / `listening`) IPC پر `server-status: running` خارج کرتے ہیں۔
- `before-quit` خوبصورت SIGTERM (WAL چیک پوائنٹ) کے لیے 5 s تک انتظار کرتا ہے پھر SIGKILL بھیجتا ہے۔
- ٹرے میں پورٹ سوئچر (`20128`, `3000`, `8080`) رک جاتا ہے اور سرور کو دوبارہ شروع کرتا ہے، پھر BrowserWindow کو دوبارہ لوڈ کرتا ہے۔

## زیرو تشکیل خفیہ بوٹسٹریپ

پہلی لانچ پر، مرکزی عمل خود کار طریقے سے پیدا کرتا ہے اور گمشدہ رازوں کو برقرار رکھتا ہے:

| خفیہ                     | ماخذ                                                                                             |
| ------------------------ | ------------------------------------------------------------------------------------------------ |
| `JWT_SECRET`             | `crypto.randomBytes(64).toString("hex")`                                                         |
| `STORAGE_ENCRYPTION_KEY` | `crypto.randomBytes(32).toString("hex")` (انکرپٹ شدہ کریڈٹس پہلے سے موجود ہونے سے انکار کرتا ہے) |
| `API_KEY_SECRET`         | `crypto.randomBytes(32).toString("hex")`                                                         |

`<DATA_DIR>/server.env` پر قائم رہا۔ `DATA_DIR` حل کرتا ہے:

- Windows: `%APPDATA%\omniroute`
- Linux: `$XDG_CONFIG_HOME/omniroute` یا `~/.omniroute`
- macOS: `~/.omniroute`

## ماحولیاتی فائل کی تلاش

سرور پیدا کرنے سے پہلے، مرکزی عمل (`getPreferredEnvFilePath()` in `electron/main.js`) چنتا ہے۔** ایک** `.env` فائل: ان میں سے پہلی جو موجود ہے۔

1. `$DATA_DIR/.env`، جب `DATA_DIR` ماحول میں سیٹ ہوتا ہے تو اس ایپ کو لانچ کیا گیا تھا۔
2. `<resolved DATA_DIR>/.env`، اوپر کی طرح ڈیفالٹس کا استعمال کرتے ہوئے: Windows پر `%APPDATA%\omniroute\.env` ، `$XDG_CONFIG_HOME/omniroute/.env` یا `~/.omniroute/.env` Linux اور macOS پر۔
3. پروسیس ورکنگ ڈائرکٹری میں `.env` ۔

مرکزی عمل صرف اس فائل کو پڑھتا ہے۔ بعد میں امیدواروں کو ضم نہیں کیا جاتا۔ پھر سرور کا ماحول اس ترجیح کے ساتھ بنایا جاتا ہے (سب سے زیادہ پہلے):

1. Electron عمل کا ماحول (متغیرات جو بھی ایپ لانچ کیا اس سے وراثت میں ملے)۔
2. منتخب کردہ `.env` فائل۔
3. `<DATA_DIR>/server.env` (اوپر بوٹسٹریپ راز)۔

جب ایپ شروع ہوتی ہے تو عمل کا ماحول پکڑا جاتا ہے، اس لیے ایپ کے چلنے کے دوران سسٹم یا صارف کے ماحول کا متغیر سیٹ ہوتا ہے (بشمول اس کے ونڈو بند ہونے کے بعد ٹرے میں بیٹھنے کے دوران) سرور تک نہیں پہنچتا جب تک کہ ایپ مکمل طور پر بند نہ ہو جائے اور دوبارہ لانچ نہ ہو۔ رن ٹائم نوبس جیسے کہ `CONTEXT_LENGTH_<PROVIDER>` کے لیے ( [ماحولیاتی متغیرات دیکھیں: فی فراہم کنندہ سیاق و سباق کی لمبائی](../reference/ENVIRONMENT.md#per-provider-context-length-context_length_provider) )، `.env` فائل کو ترجیح دیں، پھر مکمل طور پر چھوڑ دیں (ٹرے،** چھوڑو** ) اور دوبارہ لانچ کریں۔

## ونڈو اور ٹرے

- `BrowserWindow`: 1400 × 900 (min 1024 × 700), `backgroundColor: "#0a0a0a"`
- macOS: `titleBarStyle: "hiddenInset"`، `{ x: 16, y: 16 }` پر ٹریفک لائٹ۔
- Windows/Linux: مقامی ٹائٹل بار۔
- بند کریں بٹن ٹرے کو کم سے کم کرتا ہے۔ ٹرے مینو ہے** OmniRoute کھولیں۔** ،** ڈیش بورڈ کھولیں۔** (بیرونی براؤزر)** سرور پورٹ** ذیلی مینیو** اپ ڈیٹس کی جانچ کریں۔** ،** چھوڑو** .

## مواد کی حفاظت کی پالیسی

`session.defaultSession.webRequest.onHeadersReceived` کے ذریعے سیٹ کریں۔ قابل ذکر ہدایات:

- `frame-ancestors 'none'`, `object-src 'none'`, `child-src 'none'`
- `connect-src 'self' http://localhost:* http://127.0.0.1:* ws://localhost:* ws://127.0.0.1:* https://*.omniroute.online https://*.omniroute.dev`
- ڈیو موڈ `'unsafe-eval'` کو صرف `script-src` میں شامل کرتا ہے۔

## خودکار اپ ڈیٹ

`electron-updater` GitHub فراہم کنندہ (`diegosouzapw/OmniRoute`) کے ساتھ استعمال کرتا ہے۔

- `autoDownload = false`, `autoInstallOnAppQuit = true`
- واقعات `update-status` IPC کے ذریعے پیش کنندہ کو بھیجے گئے: `checking`, `available`, `not-available`, `downloading` ( `percent` کے ساتھ), `downloaded`, `error`
- `installUpdate()` سرور کو مار ڈالتا ہے پھر `autoUpdater.quitAndInstall()` کو کال کرتا ہے۔
- دیو موڈ میں چھوڑ دیا گیا (`!app.isPackaged`)

## پائپ لائن بنائیں

1. `npm run build` → Next.js اسٹینڈ `.next/standalone` میں
2. `prepare-electron-standalone.mjs` → `.next/electron-standalone` میں دوبارہ مراحل طے کرتا ہے اور `server.js` + `required-server-files.json` کے اندر مطلق راستوں کو دوبارہ لکھتا ہے تاکہ بنڈل کو دوبارہ منتقل کیا جا سکے۔
3. `electron-builder` پیکیجز `main.js`, `preload.js`, `node_modules`, اور `extraResources: { ../.next/electron-standalone → app }`

### اہداف بنائیں

| OS      | اہداف                                    |
| ------- | ---------------------------------------- |
| Windows | NSIS انسٹالر + پورٹیبل (x64)             |
| macOS   | DMG (Intel + arm64، ڈریگ ٹو ایپلی کیشنز) |
| Linux   | AppImage + DEB (x64 + arm64)             |

NSIS ترتیبات: `oneClick: false`، صارف کو انسٹال ڈائرکٹری کا انتخاب کرنے دیتا ہے، ڈیسک ٹاپ اور اسٹارٹ مینو شارٹ کٹ بناتا ہے۔

## سموک ٹیسٹنگ پیکڈ بلڈ

```bash
npm run electron:smoke:packaged
```

`scripts/dev/smoke-electron-packaged.mjs`:

- موجودہ پلیٹ فارم کے لیے `electron/dist-electron/` میں پیک شدہ بائنری کو خود بخود دریافت کرتا ہے۔
- الگ تھلگ `HOME`/`APPDATA`/`XDG_*` ڈائریکٹریز کے ساتھ لانچ ہوتا ہے تاکہ یہ ڈویلپر ڈیٹا کو نہ چھوئے۔
- 45 سیکنڈ کے اندر HTTP 200 کے لیے پولز `http://127.0.0.1:20128/login` ۔
- مہلک نمونوں (`Cannot find module`، `MODULE_NOT_FOUND`، `ERR_DLOPEN_FAILED`، `Failed to start server`، وغیرہ) کے لیے stderr/stdout گھڑیاں۔
- تیاری کے بعد 2 سیکنڈ کے مستحکم رن ٹائم کا انتظار کرتا ہے، پھر SIGTERM جاری کرتا ہے اور پورٹ کے خالی ہونے کا انتظار کرتا ہے۔
- CI میں، خود بخود `--no-sandbox --disable-gpu` (اور Linux پر `--disable-dev-shm-usage` ) گزر جاتا ہے۔

Env اوور رائیڈز: `ELECTRON_SMOKE_APP_EXECUTABLE`, `ELECTRON_SMOKE_URL`, `ELECTRON_SMOKE_TIMEOUT_MS`, `ELECTRON_SMOKE_SETTLE_MS`, `ELECTRON_SMOKE_DATA_DIR`, `ELECTRON_SMOKE_KEEP_DATA`, `ELECTRON_SMOKE_STREAM_LOGS`۔

## کوڈ پر دستخط کرنا

`electron/package.json` کرتا ہے۔** نہیں** تار پر دستخط کرنے کی اسناد براہ راست۔ انہیں env vars کے ذریعے `electron-builder` میں منتقل کریں :

### macOS

```bash
export APPLE_ID=<email>
export APPLE_APP_SPECIFIC_PASSWORD=<password>
export APPLE_TEAM_ID=<id>
export CSC_LINK=path/to/cert.p12
export CSC_KEY_PASSWORD=<cert-password>
npm run electron:build:mac
```

### Windows

```bash
export CSC_LINK=path/to/cert.pfx
export CSC_KEY_PASSWORD=<cert-password>
npm run electron:build:win
```

### Linux

AppImage دستخط اختیاری ہے — سیٹ `LINUX_GPG_KEY` اگر دستخط کرتے ہیں۔

## تقسیم

نمونے `electron/dist-electron/` میں اترتے ہیں:

- `OmniRoute.Setup.X.Y.Z.exe`, `OmniRoute X.Y.Z.exe` (Windows)
- `OmniRoute-X.Y.Z-mac.dmg`, `OmniRoute-X.Y.Z-arm64-mac.dmg` (macOS)
- `OmniRoute-X.Y.Z.AppImage`, `omniroute-desktop_X.Y.Z_amd64.deb` (Linux)

ریلیزز GitHub ریلیزز (`diegosouzapw/OmniRoute`) پر شائع کی جاتی ہیں، یہ وہ جگہ ہے جہاں `electron-updater` نئے ورژن کی جانچ کرتا ہے۔

## خرابی کا سراغ لگانا

| علامت                                                            | درست کریں۔                                                                                                                                                                    |
| ---------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Cannot find module 'better-sqlite3'` کے بعد Electron اہم ٹکرانا | better-sqlite3 v13 ships Node-API — کو پہلے سے بناتا ہے `npm install` جڑ میں دوبارہ چلاتا ہے اور `prepare:bundle` (یہ موجودہ پلیٹ فارم کے لیے پہلے سے تعمیر کی تصدیق کرتا ہے) |
| مقامی ماڈیول کے لیے `ERR_DLOPEN_FAILED`                          | `prepare:bundle` — دوبارہ چلائیں یہ تیزی سے ناکام ہو جاتا ہے جب موجودہ پلیٹ فارم کے لیے نوڈ-API پری بلڈ غائب ہو                                                               |
| Linux پر ونڈو خالی نظر آتی ہے۔                                   | تصدیق کریں کہ Next.js سرور اصل میں PORT کا پابند ہے ( `[Server]` لاگز چیک کریں)                                                                                               |
| macOS نوٹرائزیشن اسٹالز                                          | یقینی بنائیں کہ `APPLE_*` vars برآمد کیے گئے ہیں، نہ کہ صرف `.env` میں                                                                                                        |
| Windows SmartScreen وارننگ                                       | EV سرٹیفکیٹ کے ساتھ سائن کریں، یا صارفین → دائیں کلک کریں "بہرحال چلائیں"                                                                                                     |
| پورٹ میں استعمال کے ساتھ دھواں ٹیسٹ ناکام ہوجاتا ہے۔             | `electron:smoke:packaged` چلانے سے پہلے 20128 پر کسی بھی لوکل ڈیو سرور کو روک دیں۔                                                                                            |
