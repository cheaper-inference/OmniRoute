`@omniroute/opencode-plugin-v2` آپ کے پورے OmniRoute کیٹلاگ — ماڈلز، کومبوز اور
آٹو کومبوز — کو OpenCode v2 کے ماڈل پیکر میں ڈسپلے ناموں، قیمتوں اور فری ٹائر
بجٹس کے ساتھ شامل کرتا ہے۔

یہ `@omniroute/opencode-plugin` سے الگ پیکیج ہے کیونکہ OpenCode v1 اور v2 پلگ اِنز کو
مختلف معاہدوں کے ذریعے لوڈ کرتے ہیں۔ اپنے OpenCode کے میجر ورژن سے مطابقت رکھنے والا پیکیج
منتخب کریں؛ ان کے درمیان کچھ بھی مشترک نہیں، اس لیے ایک کو اپ گریڈ کرنے سے دوسرے کو اپ گریڈ
کرنا لازم نہیں ہوتا۔

## تقاضے

- OpenCode v2۔
- قابلِ رسائی OmniRoute گیٹ وے (ڈیفالٹ طور پر `http://localhost:20128`)۔
- Node.js 22 یا 24۔

## انسٹالیشن

پلگ اِن کو `opencode.json` میں شامل کریں:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

اس کے بعد ماڈلز `omniroute/<provider>/<model>` کے طور پر ظاہر ہوتے ہیں؛ `providerId` اس سابقے
اور اس انٹیگریشن کی id کا تعین کرتا ہے جس کے تحت OpenCode اسناد محفوظ کرتا ہے۔

## اسناد

پلگ اِن درج ذیل تین مقامات پر، اسی ترتیب سے، گیٹ وے کلید تلاش کرتا ہے:

1. **وہ سند جسے آپ نے OpenCode میں منسلک کیا ہے۔** پلگ اِن ایک انٹیگریشن رجسٹر کرتا ہے، لہٰذا
   OpenCode کا اپنا تصدیقی عمل کلید محفوظ کر سکتا ہے۔ `opencode.json` میں کچھ بھی درج نہیں ہوتا — اسے ترجیح دیں۔
2. پلگ اِن کے آپشنز میں `apiKey`، فی پروجیکٹ اوور رائیڈ کے لیے۔ اس سے کلید ایک ایسی فائل میں
   آ جاتی ہے جسے آپ ممکنہ طور پر کمیٹ کر رہے ہوں۔
3. ماحول میں `OMNIROUTE_API_KEY`۔

اگر ان تینوں میں سے کوئی بھی موجود نہ ہو تو کیٹلاگ خالی رہتا ہے، اور پلگ اِن خاموشی سے خالی پیکر
چھوڑنے کے بجائے آغاز پر ایک بار اس کی اطلاع دیتا ہے۔

### مینجمنٹ ٹوکن ایک مختلف کلید ہے

کومبوز، فراہم کنندہ کی صحت، اور افزودگی (ڈسپلے نام، قیمتیں، فری ٹائر بجٹس) گیٹ وے کے
`/api/*` اینڈ پوائنٹس سے آتے ہیں، جنہیں زیادہ تر تعیناتیاں اِنفرنس کلید کے بجائے ایک **مینجمنٹ** ٹوکن
کے ذریعے محفوظ کرتی ہیں:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<management read token>"
}
```

اگر `managementReadToken` سیٹ نہ ہو تو یہ `apiKey` کو متبادل کے طور پر استعمال کرتا ہے۔ جب کوئی گیٹ وے اس متبادل
کو مسترد کرتا ہے تو کیٹلاگ پھر بھی شائع ہوتا ہے، لیکن ڈسپلے ناموں کے بجائے خام ماڈل ids کے ساتھ،
کینونیکل عرف کی تکرار ختم کیے بغیر، قیمتوں کے بغیر، اور کومبوز کے بغیر۔ ایسا ہونے پر پلگ اِن ہر اینڈ پوائنٹ کے لیے
ایک بار تنبیہ کرتا ہے، جس میں اینڈ پوائنٹ اور ضائع ہونے والی معلومات کا نام شامل ہوتا ہے — اس لیے محدود پیکر کبھی معمہ نہیں رہتا۔

## کیٹلاگ تازہ کیسے رہتا ہے۔

کیٹلاگ کو سستی سے حاصل کیا جاتا ہے اور `modelCacheTtlMs` کے لیے کیش کیا جاتا ہے، اور ایک ڈسک اسنیپ شاٹ آخری معلوم کیٹلاگ کو اس وقت دستیاب رکھتا ہے جب گیٹ وے — تک رسائی کے قابل نہ ہو اور بند ہونے سے آپ کو تازگی کے سوا کچھ نہیں پڑتا۔ ماڈل اور کمبوس آتے ہی شائع ہو جاتے ہیں۔ آٹو کمبوس، فراہم کنندہ کی فہرست اور افزودگی اوورلے جب وہ اترتے ہیں تو اس میں فولڈ ہوجاتے ہیں، لہذا ایک سست اختتامی نقطہ پورے چننے والے کو یرغمال نہیں بنا سکتا۔

نام `Provider - Model[ (Editor)][ · budget][ (route)]` کی پیروی کرتے ہیں : فراہم کنندہ کو دکھایا جاتا ہے جب بھی id میں ایک ہوتا ہے (ایک سلیش لیس id بغیر کسی سابقہ کے پیش کرتا ہے)، ایک سرکردہ `🆓` مفت اندراجات کو نشان زد کرتا ہے اور ان کا مفت درجے کا بجٹ `· 1M tokens/month` لاحقہ کے طور پر رہتا ہے، ایک واضح `Editor: Model` نام کا ایڈیٹر ٹریلنگ نام کی طرف منتقل ہوتا ہے اور دیگر کورینتھیسز میں ترمیم کرتا ہے بطور مفت آئیکن کے بغیر `combo - <slug>` ۔ دو اندراجات جو ایک نام کا اشتراک کرتے ہیں ایک روٹ لاحقہ — `(no-think)` — حاصل کرتے ہیں تاکہ وہ ممتاز رہیں۔ `providerTag` (پہلے سے طے شدہ `true`) ٹریلنگ ایڈیٹر قوسین کو ٹوگل کرتا ہے۔

کوئی دستی ریفریش کمانڈ نہیں ہے: OpenCode v2 کمانڈز پرامپٹ ٹیمپلیٹس ہیں، کال بیکس نہیں، اس لیے پلگ ان کسی کو بے نقاب نہیں کر سکتا۔ تازہ کاری TTL کی پیروی کرتی ہے۔ میزبان سے صرف اس وقت دوبارہ لوڈ کرنے کے لیے کہا جاتا ہے جب کیٹلاگ یا اوورلے حقیقت میں تبدیل ہوا ہو، کبھی بھی فی ریفریش نہیں۔

## Gemini پر ٹول کالنگ

Gemini ایسی پوری درخواست مسترد کر دیتا ہے جس کے ٹول ڈیکلریشنز میں `$schema` یا `additionalProperties` موجود ہوں، اور جواب میں `400 INVALID_ARGUMENT` دیتا ہے۔ پلگ اِن اس فراہم کنندہ کے Gemini ماڈل کو بھیجے جانے والے ٹول اسکیماؤں سے ان کلیدی الفاظ کو ہٹا دیتا ہے اور باقی ہر درخواست کو بغیر تبدیلی کے چھوڑ دیتا ہے۔ `$ref` رکھنے والا ٹول حذف و ترمیم کے بغیر آگے بھیج دیا جاتا ہے، کیونکہ ریفرنس ہٹانے سے اسکیما وسیع ہو کر "کچھ بھی قبول کریں" بن جائے گا۔
اسے بند کرنے کے لیے `"geminiSanitization": false` مقرر کریں۔

## خرابی کا سراغ لگانا

| علامت                                           | وجہ                                                                                                            |
| ----------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| چننے والا کوئی OmniRoute ماڈل نہیں دکھاتا ہے۔   | کوئی کلید حل نہیں ہوئی (اسٹارٹ اپ وارننگ چیک کریں)، یا گیٹ وے ناقابل رسائی ہے۔                                 |
| را ماڈل آئی ڈیز، کوئی کمبوز، کوئی قیمت نہیں ہے۔ | انتظامیہ اینڈ پوائنٹس نے ٹوکن — سیٹ `managementReadToken` سے انکار کر دیا۔                                     |
| مختصر یا خالی `freeOnly` کیٹلاگ                 | کوئی انتظامی ٹوکن یا انکار شدہ ٹوکن — میزبان لاگ میں ریفریش سمری لائن (`unmatched-free` شمار) نہیں پڑھتا ہے۔   |
| ایک سیشن `opencode-<id>/...` پر پن کیا گیا۔     | v1 پلگ ان شائع `opencode-<id>`; v2 `<id>` bare شائع کرتا ہے، لہذا `<id>/...` کے تحت ماڈل کو دوبارہ منتخب کریں۔ |

ماحولیاتی متغیرات کو اوپن کوڈ سرور کے عمل تک پہنچنا ضروری ہے: جب میزبان بطور سروس چلتا ہے، تو وہ شیل جو `opencode models` چلاتا ہے اور سرور کا ماحول مختلف ہوتا ہے، اس لیے کلید کو جہاں سرور پڑھتا ہے برآمد کریں۔
