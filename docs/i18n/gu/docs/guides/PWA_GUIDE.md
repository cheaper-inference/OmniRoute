OmniRoute ડેશબોર્ડને તમારી હોમ સ્ક્રીન અથવા ડેસ્કટોપ પરથી એક સ્વતંત્ર વિન્ડોમાં ખોલવા માટે પ્રોગ્રેસિવ વેબ એપ્લિકેશન તરીકે ઇન્સ્ટોલ કરો. ઇન્સ્ટોલ કરેલ એપ્લિકેશનને હજુ પણ નેવિગેશન, ડેશબોર્ડ ડેટા અને API વિનંતીઓ માટે તમારા OmniRoute સર્વર સાથે કનેક્શનની જરૂર છે. કેશ્ડ સ્ટેટિક એસેટ્સ ઑફલાઇન ગેટવે અથવા ઑફલાઇન ડેશબોર્ડ પ્રદાન કરતી નથી.

## PWA શું છે?

પ્રોગ્રેસિવ વેબ એપ એપ આઇકોન અને અલગ વિન્ડો સાથે વેબ ડેશબોર્ડનો ઉપયોગ કરે છે. એકવાર ઇન્સ્ટોલ થઈ જાય, OmniRoute:

- તમારી હોમ સ્ક્રીન અથવા ડેસ્કટોપ પરથી લોંચ થાય છે
- બ્રાઉઝરના સામાન્ય સરનામાં બાર અને ટેબ વિના, એકલ મોડમાં ખુલે છે
- કેશ પસંદ કરેલ સ્થિર સંપત્તિ
- પોટ્રેટ અને લેન્ડસ્કેપ ઓરિએન્ટેશનને સપોર્ટ કરે છે

## સ્થાપન

બીજા ઉપકરણ પર સર્વર માટે HTTPS સરનામાંનો ઉપયોગ કરો. જ્યારે સર્વર સમાન ઉપકરણ પર ચાલે છે, ત્યારે `http://localhost:20128` બ્રાઉઝર ઇન્સ્ટોલ કરવાની આવશ્યકતાઓને પણ પૂર્ણ કરે છે. સાદા `http://YOUR_IP:20128` સરનામું તે જરૂરિયાતોને પૂર્ણ કરતું નથી. ઇન્સ્ટોલેશન મેનુ અને પ્રોમ્પ્ટ બ્રાઉઝર અને ઓપરેટિંગ સિસ્ટમ પર આધાર રાખે છે. [MDN ની PWA ઇન્સ્ટોલેશન આવશ્યકતાઓ](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable#https_localhost_or_loopback_are_required) જુઓ.

### એન્ડ્રોઇડ (ક્રોમ)

1. તમારું OmniRoute HTTPS સરનામું ખોલો, અથવા સમાન ફોન પર સર્વર માટે `http://localhost:20128`.
2. ખોલો**⋮** મેનુ અને પસંદ કરો** એપ્લિકેશન ઇન્સ્ટોલ કરો** અથવા** હોમ સ્ક્રીન પર ઉમેરો** જો ઓફર કરવામાં આવે તો.
3. પ્રોમ્પ્ટની પુષ્ટિ કરો.
4. હોમ સ્ક્રીન પરથી OmniRoute ખોલો.

### iOS (સફારી)

1. સફારીમાં તમારું OmniRoute HTTPS સરનામું ખોલો.
2. ટેપ કરો** શેર કરો** →** હોમ સ્ક્રીન પર ઉમેરો** .
3. નામની પુષ્ટિ કરો અને ટેપ કરો** ઉમેરો** .
4. હોમ સ્ક્રીન પરથી OmniRoute ખોલો.

### ડેસ્કટૉપ (Chrome / Edge)

1. તમારું OmniRoute ડેશબોર્ડ ખોલો.
2. બ્રાઉઝરના ઇન્સ્ટોલ આઇકનનો ઉપયોગ કરો અથવા** એપ્લિકેશન ઇન્સ્ટોલ કરો** મેનુ એન્ટ્રી, જો ઓફર કરવામાં આવે તો.
3. OmniRoute તેની પોતાની વિન્ડોમાં ખોલવા માટે પ્રોમ્પ્ટની પુષ્ટિ કરો.

## લક્ષણો

### એકલ વિન્ડો

મેનિફેસ્ટ `display: "standalone"` અને `start_url: "/dashboard"` સેટ કરે છે. ઇન્સ્ટોલ કરેલ એપ્લિકેશન એપ્લિકેશન વિંડોમાં ડેશબોર્ડ ખોલે છે. બ્રાઉઝર અને ઓપરેટિંગ-સિસ્ટમ નિયંત્રણો હજુ પણ દેખાઈ શકે છે; મેનિફેસ્ટ પૂર્ણસ્ક્રીન મોડની વિનંતી કરતું નથી.

### કેશ્ડ અસ્કયામતો અને નેટવર્ક આવશ્યકતાઓ

[સેવા કાર્યકર](../../public/sw.js) પસંદ કરેલ સમાન-મૂળ સંસાધનો કેશ કરે છે:

| વિનંતી અથવા સંપત્તિ                  | વ્યૂહરચના       | વર્તન                                                                                                                  |
| ------------------------------------ | --------------- | ---------------------------------------------------------------------------------------------------------------------- |
| ઇન્સ્ટોલ-સમય સંસાધનો                 | પ્રી-કેશ        | `/`, `/manifest.webmanifest`, `/icon-512.png` અને `/apple-touch-icon.png` વર્કર ઇન્સ્ટોલેશન દરમિયાન કેશ કરવામાં આવે છે |
| Next.js સ્ટેટિક એસેટ (`/_next/`)     | નેટવર્ક - પ્રથમ | સફળ પ્રતિસાદો કેશ અપડેટ કરે છે; નેટવર્ક ભૂલ હાલના કેશ્ડ પ્રતિભાવમાં પાછી આવે છે                                        |
| અન્ય સ્થિર CSS, JS, છબીઓ અને ફોન્ટ્સ | કેશ-પ્રથમ       | હાલના કેશ્ડ પ્રતિસાદનો ફરીથી ઉપયોગ કરવામાં આવે છે; સફળ નેટવર્ક પ્રતિસાદો ચૂકી જવા પર કેશ કરવામાં આવે છે                |
| પૃષ્ઠ નેવિગેશન                       | બાયપાસ          | બ્રાઉઝર સીધું પૃષ્ઠ મેળવે છે; કોઈ ઑફલાઇન ફૉલબૅક આપવામાં આવતું નથી                                                      |
| API, ડેશબોર્ડ અને પ્રમાણીકરણ માર્ગો  | બાયપાસ          | કાર્યકર આ વિનંતીઓને અટકાવતો નથી અથવા કેશ કરતો નથી                                                                      |
| અન્ય બિન-સ્થિર વિનંતીઓ               | નેટવર્ક         | કોઈ કેશ લુકઅપ અથવા સ્ટોરેજ નથી                                                                                         |

બાકાત કરાયેલા માર્ગો છે `/api`, `/a2a`, `/dashboard`, `/v1`, `/v1beta`, `/models`, `/chat`, `/responses`, `/codex`, `/callback` અને `/login`, પાથની સીમાઓ પર કેસ-અસંવેદનશીલ રીતે મેળ ખાતા. ક્રોસ-ઓરિજિન અને બિન-GET વિનંતીઓ પણ કાર્યકરને બાયપાસ કરે છે.

### કનેક્ટિવિટી પેજ

`/offline` પેજ કનેક્ટિવિટી સંદેશ, online/offline સૂચક, એ** કનેક્શનનો ફરીથી પ્રયાસ કરો** બટન અને સ્ટેટસ પેજની લિંક. તે છે** પૂર્વ કેશ્ડ નથી** અને સેવા કાર્યકર કરે છે** નથી** નિષ્ફળ નેવિગેશનને તેના પર રીડાયરેક્ટ કરો. તેનું અસ્તિત્વ સર્વર વિના નવા પૃષ્ઠોને સુલભ બનાવતું નથી.

### એપ્લિકેશન ચિહ્નો

મેનિફેસ્ટ આ PNG ચિહ્નોની જાહેરાત કરે છે:

| ફાઈલ                   | કદ      | ઉપયોગ કરો                                   |
| ---------------------- | ------- | ------------------------------------------- |
| `icon-192.png`         | 192×192 | સામાન્ય એપ્લિકેશન આયકન                      |
| `icon-512.png`         | 512×512 | સામાન્ય અને માસ્ક કરવા યોગ્ય એપ્લિકેશન આયકન |
| `apple-touch-icon.png` | 180×180 | Apple હોમ સ્ક્રીન આયકન                      |

બ્રાઉઝર ઇન્સ્ટોલેશન લક્ષ્ય માટે યોગ્ય આયકન પસંદ કરે છે.

### આપોઆપ નોંધણી

જ્યારે બ્રાઉઝર સર્વિસ વર્કર્સને સપોર્ટ કરે છે ત્યારે`PwaRegister` વર્કરને પ્રોડક્શનમાં રજીસ્ટર કરે છે. ડેવલપમેન્ટ મોડ કામદારોની નોંધણીને રદ કરે છે અને વાસી અસ્કયામતોને હોટ રીલોડમાં દખલ ન કરવા માટે કેશ સાફ કરે છે. પ્રોમ્પ્ટ ઇન્સ્ટોલ કરવું એ બ્રાઉઝરનો નિર્ણય છે.

## ટેકનિકલ આર્કિટેક્ચર

### વેબ એપ્લિકેશન મેનિફેસ્ટ

Next.js [`src/app/manifest.ts`](../../src/app/manifest.ts) માંથી `/manifest.webmanifest` જનરેટ કરે છે. તેની મુખ્ય સેટિંગ્સ છે:

| સેટિંગ                 | મૂલ્ય                                       |
| ---------------------- | ------------------------------------------- |
| `short_name`           | `OmniRoute`                                 |
| `start_url`            | `/dashboard`                                |
| `scope`                | `/`                                         |
| `display`              | `standalone`                                |
| `orientation`          | `any`                                       |
| પૃષ્ઠભૂમિ અને થીમ રંગો | `PWA_THEME_COLORS` તરફથી ડિફોલ્ટ લાઇટ પેલેટ |

મેનિફેસ્ટનું નામ અને વર્ણન એ સ્રોત ફાઇલમાં સ્થિર મૂલ્યો છે. ઇન્સ્ટોલ કરેલ મેનિફેસ્ટ દરેક મુલાકાત પર ઇન્સ્ટન્સ-નામ સેટિંગ અથવા સક્રિય પેલેટને અનુસરતું નથી.

### સેવા કાર્યકર

[`public/sw.js`](../../public/sw.js) પાસે કોઈ સર્વિસ-વર્કર ફ્રેમવર્ક ડિપેન્ડન્સી નથી:

- **ઇન્સ્ટોલ કરો:** ઉપર સૂચિબદ્ધ ચાર સંસાધનોને પૂર્વ-કેશ કરે છે અને નવા કાર્યકરને સક્રિય કરે છે.
- **સક્રિય કરો:** જૂની કેશ પેઢીઓને દૂર કરે છે અને ક્લાયંટનો દાવો કરે છે.
- **મેળવો:** ઉપરોક્ત સ્ટેટિક-એસેટ વ્યૂહરચના અને માર્ગ બાકાત લાગુ કરે છે.
- **સંસ્કરણ:** સ્ત્રોત કેશ નામ `omniroute-pwa-v3` છે; પ્રોડક્શન બિલ્ડ કેશ ઓળખને સ્ટેમ્પ કરે છે.
- **સૂચનાઓ:** ઇનકમિંગ `push` ઇવેન્ટ્સ હેન્ડલ કરે છે અને જ્યારે નોટિફિકેશન ક્લિક કરવામાં આવે ત્યારે ફોકસ કરે છે અથવા વિન્ડો ખોલે છે.

એકલા પુશ ઇવેન્ટ હેન્ડલર્સ સક્રિય પુશ સબ્સ્ક્રિપ્શન અથવા રૂપરેખાંકિત સર્વર ડિલિવરી સ્થાપિત કરતા નથી. એવું ન માનો કે સૂચનાઓ ફક્ત PWA ઇન્સ્ટોલ કરેલી હોવાથી સક્ષમ છે.

### લેઆઉટ મેટાડેટા અને નોંધણી

[`src/app/layout.tsx`](../../src/app/layout.tsx) મેનિફેસ્ટ લિંક, Apple સ્ટેન્ડઅલોન મેટાડેટા, થીમ રંગો અને `viewport-fit: cover` પ્રદાન કરે છે. પૃષ્ઠ શીર્ષક અને Apple વેબ-એપ શીર્ષક ઉદાહરણ નામનો ઉપયોગ કરે છે. લાઇવ બ્રાઉઝર થીમ રંગ પેલેટને અનુસરે છે; ઇન્સ્ટોલ મેનિફેસ્ટ મૂળભૂત પ્રકાશ રંગનો ઉપયોગ કરે છે.

[`PwaRegister`](../../src/shared/components/PwaRegister.tsx) ક્લાયન્ટ પર ચાલે છે અને `/sw.js` તેના URL માં બિલ્ડ ID સાથે રજીસ્ટર કરે છે. તે મેળ ન ખાતી કેશ પેઢીઓ શોધે છે અને કાર્યકરને રીસેટ કરી શકે છે અને જૂના ઇન્સ્ટોલેશનમાંથી પુનઃપ્રાપ્ત કરવા માટે એકવાર ફરીથી લોડ કરી શકે છે. નોંધણી નિષ્ફળતા ડેશબોર્ડને અવરોધિત કરતી નથી.

## Termux (Android) સાથે ઉપયોગ કરો

1. ટર્મક્સમાં OmniRoute શરૂ કરો: `npx -y omniroute@latest`.
2. સમાન ફોન પર Chrome ખોલો: `http://localhost:20128`.
3. બ્રાઉઝરના ઇન્સ્ટોલેશન મેનૂ દ્વારા PWA ઇન્સ્ટોલ કરો.
4. ડેશબોર્ડનો ઉપયોગ કરતી વખતે ટર્મક્સ સર્વરને ચાલુ રાખો.

ફોન ગેટવે અને તેના ડેશબોર્ડ બંનેને હોસ્ટ કરે છે. રિમોટ AI પ્રદાતાઓની વિનંતીઓને હજી પણ નેટવર્ક ઍક્સેસની જરૂર છે. સેટઅપ અને Android પ્રક્રિયા-આજીવન વિચારણાઓ માટે [Termux માર્ગદર્શિકા](TERMUX_GUIDE.md) જુઓ.

## અન્ય ઉપકરણોમાંથી ઉપયોગ કરો

ફોન, ટેબ્લેટ અથવા ડેસ્કટોપ પર સર્વરનું HTTPS સરનામું ખોલો, પછી તે બ્રાઉઝરના ઇન્સ્ટોલેશન ફ્લોને અનુસરો. સર્વર દરેક ઉપકરણથી પહોંચી શકાય તેવું હોવું જોઈએ. દૂરસ્થ ઍક્સેસ વિકલ્પો માટે [ટનલ માર્ગદર્શિકા](../ops/TUNNELS_GUIDE.md) જુઓ.

## કસ્ટમાઇઝેશન

### દાખલાનું નામ

આ** દાખલાનું નામ** સેટિંગ ડેશબોર્ડ મેટાડેટામાં ફેરફાર કરે છે, જેમાં પેજ શીર્ષક અને Apple વેબ-એપ શીર્ષકનો સમાવેશ થાય છે. જનરેટ કરેલ મેનિફેસ્ટ સ્થિર નામનો ઉપયોગ કરે છે, તેથી આ સેટિંગ બાંહેધરી આપતું નથી કે પહેલેથી ઇન્સ્ટોલ કરેલ એપ્લિકેશનનું નામ બદલાઈ ગયું છે.

### કસ્ટમ ફેવિકોન

કસ્ટમ ફેવિકોન બ્રાઉઝર ફેવિકોનને બદલે છે. ઇન્સ્ટોલ મેનિફેસ્ટ હજી પણ ઉપરની PNG ફાઇલોની જાહેરાત કરે છે; ફેવિકોન બદલવાથી તે હોમ-સ્ક્રીન ચિહ્નો બદલાતા નથી.

## મર્યાદાઓ

- **સર્વર કનેક્શન આવશ્યક છે:** પૃષ્ઠ સંશોધક, ડેશબોર્ડ સ્થિતિ અને API વિનંતીઓમાં ઑફલાઇન ફોલબેક નથી.
- **કોઈ પૃષ્ઠભૂમિ સમન્વયન નથી:** ઑફલાઇન ક્રિયાઓ રિપ્લે માટે કતારમાં નથી.
- **બ્રાઉઝર તફાવતો:** ઇન્સ્ટોલેશન મેનુ, વિન્ડો પ્રેઝન્ટેશન અને નોટિફિકેશન સપોર્ટ પ્લેટફોર્મ પ્રમાણે બદલાય છે.
- **કોઈ API પ્રતિસાદ કેશ નથી:** કાર્યકર API, ડેશબોર્ડ અને પ્રમાણીકરણ માર્ગોને બાકાત રાખે છે.
- **સ્થિર સ્થાપન ચિહ્નો:** તે ચિહ્નોને અપડેટ કરવા માટે જાહેરાત કરેલ સંપત્તિઓ બદલવાની જરૂર છે; બ્રાઉઝર્સ ઇન્સ્ટોલ કરેલ મેટાડેટા જાળવી શકે છે.
