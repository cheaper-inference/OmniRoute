> **સ્થિતિ:** ડેશબોર્ડ **Keak CI UI Kit** (`@keak/cheaper-inference-ui-kit`) પર બનાવવામાં આવ્યું છે, જેને વર્કસ્પેસ `packages/ui-kit` (`@omniroute/ui-kit`; અપસ્ટ્રીમ સ્નેપશોટ `packages/ui-kit/UPSTREAM.md` માં પિન કરેલો છે અને `npm run check:ui-kit-snapshot` દ્વારા સુરક્ષિત છે) તરીકે વેન્ડર કરવામાં આવ્યું છે. લાઇટ એ કેનોનિકલ થીમ છે; ડિફૉલ્ટ પસંદગી `system` છે. એક્સેન્ટ Keak lime (`--ci-color-accent`) છે. Inter (letter-spacing 0, `--ci-letter-spacing-ui`) UI ફેમિલી છે, Instrument Serif ફક્ત મોટા વિરલ ડિસ્પ્લે ટેક્સ્ટ માટે (`.ci-dashboard-display`), IBM Plex Mono કોડ માટે — આ બધા `src/app/globals.css` ની શરૂઆતમાં રહેલા `@fontsource/*` ઇમ્પોર્ટ્સ દ્વારા સેલ્ફ-હોસ્ટેડ છે. દરેક આયકન Lucide ગ્લિફ છે.

## 1. વસ્તુઓ ક્યાં રહે છે

- **કિટ.** `packages/ui-kit/src` એ `packages/ui-kit/UPSTREAM.md` માં પિન કરેલા કમિટ પરની upstream `src/` ની બાઇટ-ફોર-બાઇટ નકલ છે (જે લાઇસન્સ અધિકૃતિ પણ નોંધે છે); `PATCHES.md` સ્થાનિક પૅચોની સૂચિ આપે છે (કોઈ નહીં). તે બિલ્ડ વિના સોર્સ તરીકે વપરાય છે: `next.config.mjs` તેને ટ્રાન્સપાઇલ કરે છે, અને `tsconfig.json` `@omniroute/ui-kit` → `packages/ui-kit/src` અને `@omniroute/ui-kit/*` → `packages/ui-kit/src/*` મેપ કરે છે (`vitest.config.ts` અને `vitest.mcp.config.ts` પણ સમાન એલિયસ ધરાવે છે). કિટ કમ્પોનન્ટને તેના સબપાથથી (`@omniroute/ui-kit/table`, `@omniroute/ui-kit/page-header`…) ઇમ્પોર્ટ કરો, ક્યારેય `@omniroute/ui-kit` બૅરલ દ્વારા નહીં: બૅરલ દરેક ઇમ્પોર્ટરમાં દરેક કમ્પોનન્ટ (ડેટ પિકર સહિત) ખેંચી લાવે છે. કિટ સ્ટાઇલશીટ `src/app/globals.css` મારફતે આવે છે (`@import "../../packages/ui-kit/src/ci-ui.css"`).
- **ટોકન્સ.** `packages/ui-kit/src/ci-tokens.css` `--ci-*` ટોકન્સ જાહેર કરે છે; `src/app/globals.css` તેમને લિગસી OmniRoute નામો (`--color-*`, `--radius-*`, `--font-sans`/`--font-mono`, `--table-*`, `--orch-status-*`, `--color-fd-*`) સાથે બ્રિજ કરે છે, જેથી હાલના `var(--color-*)` વાંચન અને Tailwind યુટિલિટીઝ ચાલુ રહે. નવો કોડ Tailwind યુટિલિટીઝ (`bg-surface`, `text-text-muted`, `border-border`, `text-success`, `bg-success-bg`, `bg-chart-1`…) અથવા કિટ ક્લાસીસ વાપરે છે — ક્યારેય hex વેલ્યુ નહીં (`tests/unit/design-kit-bridge.test.ts` આ બ્રિજ લાગુ પાડે છે). `text-primary` `--text-color-primary` મારફતે `--color-primary-ink` પર રિઝોલ્વ થાય છે (લાઇટમાં lime-800, ડાર્કમાં લાઇમ એક્સન્ટ), જેથી પ્રાઇમરી ટેક્સ્ટ વાંચનીય રહે જ્યારે `bg-primary`/`border-primary` લાઇમ સરફેસ જાળવી રાખે છે. ચાર્ટ સિરીઝ `--color-chart-1` … `--color-chart-5` વાપરે છે.
- **થીમ્સ.** `<html className="ci-theme">` (`src/app/layout.tsx`) ડોક્યુમેન્ટને કિટ થીમમાં ઓપ્ટ-ઇન કરે છે. પસંદગી `light`, `dark` અથવા `system` છે (`src/shared/constants/appConfig.ts` માં `THEME_CONFIG.defaultTheme = "system"`; `system` `prefers-color-scheme` ને અનુસરે છે). `src/store/themeStore.ts` માંનું `applyTheme()` (જેને `src/app/layout.tsx` માંની ઇનલાઇન બૂટસ્ટ્રૅપ સ્ક્રિપ્ટ મિરર કરે છે, જે હાઇડ્રેશન પહેલાં ચાલે છે) `data-theme="dark"|"light"` સેટ કરે છે અને `<html>` પર `.dark` ક્લાસને સાથે ટોગલ કરે છે. કિટનો ડાર્ક ટોકન સેટ `data-theme="dark"` પર કી થયેલો છે (`packages/ui-kit/src/ci-tokens.css`); OmniRoute ના પોતાના ડાર્ક ઓવરરાઇડ્સ (`globals.css` માંનો `.dark` બ્લોક) અને લિગસી Tailwind `dark:` યુટિલિટીઝ `.dark` ક્લાસ પર કી થાય છે. કોઈ એક્સન્ટ કલર પ્રીસેટ્સ નથી: એક્સન્ટ હંમેશા કિટમાંથી જ આવે છે, અને જૂના બિલ્ડથી સાચવેલો પ્રીસેટ સ્ટોર લોડ થાય ત્યારે કાઢી નાખવામાં આવે છે.
- **કમ્પોનન્ટ્સ (એડાપ્ટર્સ).** `src/shared/components/index.tsx` OmniRoute કમ્પોનન્ટ API (સમાન નામો, ડિફોલ્ટ એક્સપોર્ટ્સ અને પ્રોપ્સ) જાળવી રાખે છે, અને તેની પાછળના પ્રિમિટિવ્ઝ કિટ પરના એડાપ્ટર્સ છે: ફોર્મ્સ (`Button`, `Input`, `Textarea`, `Checkbox`, `Select`, `Toggle`, `Badge`, `Card`), ઓવરલેઝ અને ફીડબૅક (`Modal`/`ConfirmModal`, `Tooltip`/`InfoTooltip`, `NotificationToast`, `EmptyState`, `Loading`), સ્ટ્રક્ચર (`Collapsible`, `CollapsibleSection`, `SegmentedControl`, `Breadcrumbs`, `Avatar`) અને ટેબલ્સ (`DataTable`, `FilterBar`, `ColumnToggle`, `FilterPills`, `PresetSlider`). એડાપ્ટર કિટ કમ્પોનન્ટને સબપાથથી ઇમ્પોર્ટ કરે છે અને લિગસી પ્રોપ્સને તેના પર મેપ કરે છે — ઉદાહરણ તરીકે `Button variant="primary"` એ કિટનું `default` બટન છે (`--ci-button-primary-*`: લાઇટમાં ઇન્વર્સ સરફેસ, ડાર્કમાં તેની `--ci-color-accent-foreground` ઇંક સાથેનું એક્સન્ટ), `danger` એ `destructive` છે, અને `warning` એ `outline` વત્તા `.ci-button--warning` એક્સ્ટેન્શન છે. `globals.css` ના અંતે આવેલા (`@layer components`) `.ci-button--warning` અને `.ci-badge[data-tone]` નિયમો કિટ ક્લાસીસ પરના OmniRoute એક્સ્ટેન્શન્સ છે. `tests/unit/ui/adapters/*.test.tsx` દરેક એડાપ્ટરને પિન કરે છે.
- **શેલ.** `src/app/(dashboard)/layout.tsx` `DashboardLayout` રેન્ડર કરે છે, જે `src/shared/components/layouts/DashboardShell.tsx` રેન્ડર કરે છે: કિટ `SidebarProvider` / `Sidebar` / `SidebarInset` (`packages/ui-kit/src/sidebar.tsx`), જેમાં OmniRoute નું નેવિગેશન લોજિક `src/shared/components/Sidebar.tsx` માં છે. `#main-content` તરફ દોરતી "કન્ટેન્ટ પર જાઓ" લિંક પ્રથમ ફોકસેબલ એલિમેન્ટ છે. `src/shared/components/Header.tsx` કિટ `SidebarTrigger` (શેલનું એકમાત્ર સાઇડબાર ટોગલ), Keak `ProductSwitcher` અને કમાન્ડ-પેલેટ ઓપનર ધરાવે છે; તે રૂટ ટાઇટલ ફક્ત ત્યારે જ બતાવે છે જ્યારે `#main-content` ની અંદર કોઈ કિટ `PageHeader` (`.ci-page-header`) માઉન્ટ થયેલો ન હોય, જેથી પોતાનો `PageHeader` ધરાવતા પેજ પર એક જ `h1` હોય. `src/shared/components/CommandPalette.tsx` એ કિટ `Dialog` છે.
- **આયકન્સ.** `<Icon name="material_name">` (`src/shared/components/Icon.tsx`) નામને (સ્ક્રીન્સ જે Material Symbols શબ્દસંગ્રહ વાપરે છે) `ICON_MAP` (`src/shared/constants/iconMap.ts`) મારફતે Lucide ગ્લિફ પર રિઝોલ્વ કરે છે. Material Symbols ફોન્ટ અને પૅકેજ હવે નથી: મેપમાંથી ખૂટતું નામ ન્યુટ્રલ પ્લેસહોલ્ડર ગ્લિફ (`data-icon-missing="true"`) રેન્ડર કરે છે અને પ્રોડક્શનની બહાર કન્સોલ ચેતવણી લોગ કરે છે. `npm run gen:icon-map` વપરાશમાં રહેલા પણ મેપમાંથી ખૂટતા નામો છાપે છે (`tests/unit/icon-map-coverage.test.ts` Lucide આયકન વિનાના કોઈપણ નામ પર નિષ્ફળ થાય છે; `tests/unit/icon-map-object-values.test.ts` લુકઅપ ઓબ્જેક્ટ્સમાં સંગ્રહિત નામોને આવરી લે છે); `scripts/dev/codemod-material-icons.mjs <dir|file>... [--write]` લિટરલ `<span className="material-symbols-outlined">` સ્પાન્સને `<Icon>` માં ફરીથી લખે છે.
- **બ્રાન્ડ.** `src/shared/components/OmniRouteLogo.tsx` કિટને રૅપ કરે છે: ડિફોલ્ટ એક્સપોર્ટ `OmniRouteLogo` `ProductIcon product="omniroute" variant="glyph"` રેન્ડર કરે છે (ઇનલાઇન SVG, `basePath`-સેફ) અને `OmniRouteLockup` `ProductLockup product="omniroute"` (એક્સેસિબલ નામ "Keak OmniRoute") અથવા, વ્હાઇટ-લેબલ ઓપરેટર્સ માટે, તેમનું પોતાનું `name`/`logoSrc` રેન્ડર કરે છે. પ્રોડક્ટ-સ્વિચર ડેસ્ટિનેશન્સ `src/shared/constants/keakProducts.ts` (`KEAK_PRODUCT_LINKS`, `KEAK_ACTIVE_PRODUCT`) માં રહે છે. સ્ટૅન્ડઅલોન સ્ક્રીન્સ — `src/app/login/page.tsx`, `src/app/status/page.tsx`, `src/app/maintenance/page.tsx`, `src/app/offline/page.tsx`, `src/app/not-found.tsx` અને `src/shared/components/ErrorPageScaffold.tsx` — લોકઅપ બતાવે છે; `tests/unit/brand-pages-static.test.ts` તેને ગાર્ડ કરે છે.

## 2. નિયમો

1. ટોકન્સ, ક્યારેય લિટરલ્સ નહીં. જાણીજોઈને રાખવામાં આવેલા અપવાદો: હંમેશા-ડાર્ક કન્સોલ ટર્મિનલ, `STATUS_HEX` (`src/shared/constants/statusColors.ts`) દ્વારા ReactFlow SVG સ્ટ્રોક્સ, અને કેટેગોરિકલ પેલેટ્સ `STRATEGY_COLORS` (`src/app/(dashboard)/dashboard/combos/live/nodes/StrategyNode.tsx`) અને `LAYER_COLORS` (`src/app/(dashboard)/dashboard/compression/studio/nodes/EngineNode.tsx`).
2. `packages/ui-kit/src` ને જાતે ક્યારેય પેચ કરશો નહીં: `scripts/dev/sync-ui-kit.sh <commit>` સાથે સિંક કરો; પ્રી-કમિટ ગેટ `npm run check:ui-kit-snapshot` (`.husky/pre-commit`) પિન કરેલા અપસ્ટ્રીમ કમિટથી અલગ પડતી કોઈપણ બાઇટ પર નિષ્ફળ જાય છે (જ્યારે અપસ્ટ્રીમ ક્લોન, `UI_KIT_CLONE` અથવા `_references/cheaper-inference-ui-kit`, ગેરહાજર હોય ત્યારે તે ચેતવણી સાથે સ્કિપ થાય છે). જ્યારે કિટમાં કંઈક ખૂટતું હોય, ત્યારે એડેપ્ટર અથવા સ્ક્રીનમાં વર્કઅરાઉન્ડ કરો અને અપસ્ટ્રીમ પાસે તેની માંગણી કરો.
3. કિટના ટેક્સ્ટ ડિફોલ્ટ્સ અંગ્રેજી છે (`label = "Loading"`, `loadingLabel = "Loading table"`…) — જ્યારે પણ કોઈ કિટ કોમ્પોનન્ટ ટેક્સ્ટ રેન્ડર કરે ત્યારે `useTranslations(...)` થી અનુવાદિત સ્ટ્રિંગ્સ પાસ કરો.
4. Tailwind યુટિલિટીઝ કિટ કોમ્પોનન્ટ ક્લાસીસ પર જીતે છે (કિટ `@layer theme, base, components, utilities` જાહેર કરે છે અને તેના નિયમો `components` માં રહે છે) — સ્પેસિંગ અને લેઆઉટ માટે યુટિલિટીઝ વાપરો, કિટ કોમ્પોનન્ટ્સનો કલર બદલવા માટે નહીં.
5. હેડિંગ્સ: પેજ અને સેક્શન ટાઇટલ્સ માટે `.ci-heading` (Inter, ટ્રેકિંગ વિના); `.ci-dashboard-display` (Instrument Serif) ફક્ત મોટા, વિરળ ડિસ્પ્લે ટેક્સ્ટ માટે, જેમ કે એરર-પેજનો સ્ટેટસ કોડ.
6. `tests/unit/dashboard-kit-sweep.test.ts` કિટ અપનાવણીનું રક્ષણ કરે છે: `src/app` અથવા `src/shared/components` હેઠળ કોઈ Material ligature span નહીં; ડેશબોર્ડ ટ્રીમાં (`src/app/(dashboard)` અને `src/shared/components`) કોઈ કાચા `<select>`, `<textarea>` અથવા `<table>` નહીં અને સૂચિબદ્ધ અપવાદોની બહાર કોઈ હાથથી-બનાવેલ `role="dialog"` નહીં (`Select` એડેપ્ટરની નેટિવ બ્રાન્ચ, `RequestLoggerDetail`); ત્યાંના દરેક કાચા `<button>` અથવા `<input>` ને `kit-exception:` (કારણ સાથે) ધરાવતી કોમેન્ટ જોઈએ છે જે તેનાથી વધુમાં વધુ 3 લાઇન ઉપર સમાપ્ત થાય છે; પેલેટ હ્યૂઝ અને `dark:` વેરિઅન્ટ્સ ફક્ત ટેસ્ટ દ્વારા સૂચિબદ્ધ ફાઇલોમાં જ.
7. PR પહેલાં બંને થીમ્સ અને 390 px વ્યુપોર્ટ ચકાસો (સ્ક્રીનશોટ્સ); `tests/e2e/a11y.spec.ts` axe ચલાવે છે.

## 3. સ્ક્રીન ઉમેરવી

1. પેજને કિટ `PageHeader` (`@omniroute/ui-kit/page-header`, ડેશબોર્ડની અંદર `compact`) થી શરૂ કરો — ટાઇટલ, વર્ણન અને `actions`. પછી શેલ હેડર તેનું પોતાનું ટાઇટલ છોડી દે છે.
2. `@/shared/components` (એડેપ્ટર્સ) માંથી કંટ્રોલ્સ બનાવો અને જ્યાં કોઈ એડેપ્ટર નથી ત્યાં સબપાથ દ્વારા કિટ કોમ્પોનન્ટ્સ વાપરો (`Table`/`TableScrollArea`/`DataTableShell`, `Field`, `Alert`, `Tabs`, `RadioGroup`, `Slider`…).
3. આયકન્સ: `<Icon name="…" />`. નવું નામ સેમાન્ટિક રીતે મેળ ખાતા Lucide કોમ્પોનન્ટ સાથે `ICON_MAP` માં ઉમેરાય છે; `npm run gen:icon-map` હજુ ખૂટતા નામોની સૂચિ બતાવે છે.
4. કલર્સ: સેમાન્ટિક યુટિલિટીઝ (`text-success`, `bg-warning-bg`, `border-border`…) અને ચાર્ટ સિરીઝ માટે `var(--color-chart-N)`; કોઈ હેક્સ વેલ્યુઝ નહીં અને કોઈ એવા `dark:` વેરિઅન્ટ્સ નહીં જે ફક્ત કલરનું પુનરાવર્તન કરે છે.
5. ટેક્સ્ટ: તમે કિટ કોમ્પોનન્ટ્સને પાસ કરતા લેબલ્સ સહિત દરેક સ્ટ્રિંગ `useTranslations` માંથી આવે છે. નવી કીઝ `src/i18n/messages/en.json`, `pt-BR.json` અને `vi.json` માં જાય છે (વિયેતનામીસ પેરિટી ટેસ્ટ દરેક અંગ્રેજી કીને પિન કરે છે); બાકીના લોકેલ્સ i18n સિંક દ્વારા ભરાય છે.
6. PR પહેલાં ગાર્ડ્સ ચલાવો: `tests/unit/dashboard-kit-sweep.test.ts`, `tests/unit/icon-map-coverage.test.ts`, `tests/unit/icon-map-object-values.test.ts`, `npm run check:dashboard-typecheck` (એકમાત્ર તપાસ જે `iconMap.ts` માં ડુપ્લિકેટ ઇમ્પોર્ટ પકડે છે), `npm run check:ui-icu`, અને સ્ક્રીનના પોતાના ટેસ્ટ્સ.

## 4. એડેપ્ટર ઉમેરવું અથવા બદલવું

1. `src/shared/components/index.tsx` નું પબ્લિક API જાળવી રાખો: સમાન export નામો, default exports અને
   સ્વીકારાતા props. એડેપ્ટરની અંદર લેગસી props ને kit પર મેપ કરો (`Button.tsx` જુઓ: `VARIANT_TO_KIT`,
   `SIZE_TO_KIT`).
2. kit ને સબપાથ (`@omniroute/ui-kit/<component>`) દ્વારા ઇમ્પોર્ટ કરો.
3. kit ની ખાલી જગ્યાઓ માટેના વર્કઅરાઉન્ડ એડેપ્ટરમાં રહે છે (અથવા જ્યારે ફિક્સ સ્ટાઇલ હોય ત્યારે
   `globals.css` `@layer components` માં), ક્યારેય `packages/ui-kit/src` માં નહીં.
4. `tests/unit/ui/adapters/<name>.test.tsx` ઉમેરો અથવા અપડેટ કરો. ઘણા કોલર્સ ધરાવતા એડેપ્ટર માટે,
   ફેરફાર પહેલાં અને પછીનું રેન્ડર થયેલ માર્કઅપ સરખાવો — પેડિંગ અથવા રેપરના ફેરફારો દરેક સ્ક્રીન પર ફેલાય છે.

## 5. kit અપડેટ કરવી

`scripts/dev/sync-ui-kit.sh <commit> [clone]` તે કમિટ પરના અપસ્ટ્રીમ `src/` ને
`packages/ui-kit/src` માં કોપી કરે છે અને એકમાત્ર મંજૂર ટ્રાન્સફોર્મેશન લાગુ કરે છે (તે રિલેટિવ
ઇમ્પોર્ટ્સમાંથી `.js` સફિક્સ દૂર કરે છે). પછી: `git diff packages/ui-kit` ની સમીક્ષા કરો, બંને થીમ્સમાં
providers, settings, combos, usage અને endpoint પર વિઝ્યુઅલ પાસ કરો, `npm run check:ui-kit-snapshot` અને
`npm run test:vitest:ui` ચલાવો, અને અપસ્ટ્રીમ ચેન્જલોગ સાથે PR ખોલો.
