> **TL;DR** : તમારા પોતાના પાત્ર પ્રદાતા એકાઉન્ટ્સ લાવો. OmniRoute તમે રૂપરેખાંકિત કરેલ જોડાણોને જોડે છે; તે જાહેરાત કરેલ કુલ ટોકન બજેટ જારી કરતું નથી. મફત ઍક્સેસ માટે સાઇનઅપ, API કી, મંજૂરી અથવા ચુકવણી પદ્ધતિની જરૂર પડી શકે છે. પ્રદાતાની મર્યાદાઓ, ગોપનીયતા નીતિઓ અને શરતો હજુ પણ લાગુ થાય છે.

## ફ્રી ટિયર્સ શું છે?

ઘણા AI પ્રદાતાઓ અમુક સ્વરૂપ ઓફર કરે છે** મફત પ્રવેશ** . પ્રદાતા પર આધાર રાખીને, તેનો અર્થ નો-ઓથ એન્ડપોઇન્ટ, રિકરિંગ ક્વોટા, રેટ-મર્યાદિત અનકેપ્ડ એક્સેસ, સાઇનઅપ ગ્રાન્ટ, મેન્યુઅલ મંજૂરી અથવા અસ્થાયી પ્રમોશન હોઈ શકે છે. કેટલાક વિકલ્પો માટે એકાઉન્ટ, API કી, ક્રેડિટ કાર્ડ, KYC અથવા પ્રદાતા-વિશિષ્ટ શરતોની સ્વીકૃતિ જરૂરી છે.

OmniRoute** એકંદર** કનેક્શન્સને એક એન્ડપોઇન્ટમાં ગોઠવેલ છે. તમે હજુ પણ દરેક પ્રદાતા માટે અલગથી સાઇન અપ કરો કે જેને એકાઉન્ટની જરૂર છે. તે એકાઉન્ટ્સને કનેક્ટ કરો અને લાયક લક્ષ્યો વચ્ચે રૂટ કરવા માટે `model: "auto"` ઉપયોગ કરો. તાજા ઇન્સ્ટોલેશનમાં કોઈ યોગ્ય ચાવી વિનાનું લક્ષ્ય હોઈ શકે નહીં; એકલા OmniRoute ઇન્સ્ટોલ કરવાથી સફળ ચેટ પ્રતિસાદની બાંયધરી આપતું નથી.

## પ્રતિનિધિ ફ્રી-ઍક્સેસ પ્રદાતાઓ

### રિકરિંગ, કીલેસ અથવા અનકેપ્ડ એક્સેસ

આ પ્રદાતાઓ પાસે ઓડિટેડ કેટલોગમાં રિકરિંગ, કીલેસ અથવા અનકેપ્ડ ફ્રી-એક્સેસ પાથ છે. "અનકેપ્ડ" નો અર્થ કોઈ પ્રકાશિત ટોકન કેપ નથી; દર, સંમતિ, એકાઉન્ટ, પ્રાદેશિક અને નીતિ મર્યાદા હજુ પણ લાગુ થઈ શકે છે:

| પ્રદાતા           | મોડલ્સ                                                               | ક્વોટા                                                                                                                   | કેવી રીતે કનેક્ટ કરવું                                                                    |
| ----------------- | -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------- |
| **Kiro AI**       | Claude સોનેટ 4.5, હાઈકુ 4.5, DeepSeek V3.2, અને અન્ય                 | ઓડિટેડ કેટલોગ 25K-ટોકન શેર કરેલ માસિક પૂલનો અંદાજ આપે છે                                                                 | OAuth/account પ્રવાહ; સૂચિમાં ToS ફ્લેગ કરેલ `avoid`                                      |
| **પરાગનયન**       | વર્તમાન કીલેસ મોડલ સેટ; કેટલાક ભૂતપૂર્વ મોડલ બંધ અથવા કી-જરૂરી છે    | ચાવી વિનાનું; કોઈ પ્રકાશિત ટોકન કેપ નથી                                                                                  | કીલેસ મોડલ્સ માટે કોઈ પ્રદાતા ઓળખપત્ર નથી                                                 |
| **લોગફેર**        | kimi-k3, deepseek-v4-pro, glm-5.2, gpt-5.6-luna, minimax-m3, અને વધુ | મફત API કી (કોઈ દર મર્યાદા નથી, કોઈ કાર્ડ નથી);** દરેક વિનંતી લોગ થયેલ છે** સંશોધન માટે ( logfare.ai/consent નાપસંદ કરો) | logfare.ai/register પર ઇન્સ્ટન્ટ કી; logfare.ai/tos અને logfare.ai/privacy પર ToS/privacy |
| **Cloudflare AI** | કામદારો AI કેટલોગ                                                    | ઓડિટેડ પૂલ પ્રકાશિત ઉપયોગ એકમોમાંથી ~ 23M tokens/month અંદાજ આપે છે (કેટલોગ ઓડિટેડ 2026-11-23)                           | Cloudflare એકાઉન્ટ અને API ઓળખપત્રો                                                       |
| **Gemini**        | Gemini ફ્લેશ કુટુંબ                                                  | ચલ project/model દર મર્યાદા; હેડલાઇનમાં કોઈ નિશ્ચિત માસિક ટોકન અનુદાન શામેલ નથી                                          | Google AI સ્ટુડિયો API કી; પ્રોજેક્ટની સક્રિય મર્યાદા તપાસો                               |
| **Groq**          | Llama, GPT-OSS અને Qwen મોડલ્સ                                       | ઓડિટેડ પૂલ અંદાજ ~ 24M tokens/month (4 પ્રતિ-મોડલ કેપ્સ, કેટલોગ ઓડિટ 2026-11-23)                                         | Groq API કી; દર મર્યાદા લાગુ                                                              |

### સાઇનઅપ અનુદાન અને પ્રદાતા-વિશિષ્ટ ક્રેડિટ્સ

આ પ્રદાતાઓ તેમના પાત્રતા નિયમોને આધીન સાઇનઅપ અનુદાન અથવા પ્રમોશનલ ક્રેડિટ ઓફર કરે છે. 2026-10-08ના રોજ ચકાસવામાં આવ્યા મુજબ, [Cerebras કિંમતને](https://www.cerebras.ai/pricing) 30 દિવસ પછી સમાપ્ત થતી વન-ટાઇમ $5 ક્રેડિટ માટે ચુકવણી પદ્ધતિની જરૂર છે; તે રિકરિંગ ટોકન ક્વોટા નથી. [Gemini દરની મર્યાદા](https://ai.google.dev/gemini-api/docs/rate-limits) પ્રોજેક્ટ, મોડલ અને ટાયર દ્વારા બદલાય છે, તેથી તે બાંયધરીકૃત માસિક ટોકન અનુદાનમાં રૂપાંતરિત થતી નથી.

| પ્રદાતા          | મફત ક્રેડિટ્સ                                                    | મોડલ્સ                  | કેવી રીતે મેળવવું                                    |

### અન્ય મર્યાદિત ઍક્સેસ

આ પ્રદાતાઓ પાસે છે** મફત સ્તરો** ચોક્કસ મર્યાદાઓ સાથે:

## ફ્રી ટિયર્સને કેવી રીતે સ્ટેક કરવું

OmniRoute નો જાદુ છે** મુક્ત સ્તરો સ્ટેકીંગ** . એક પ્રદાતા પર આધાર રાખવાને બદલે, તમે બહુવિધ મફત પ્રદાતાઓને કનેક્ટ કરો અને દરેક વિનંતી માટે OmniRoute આપમેળે શ્રેષ્ઠ પસંદ કરવા દો.

### ઉદાહરણ: વ્યાપક ફ્રી-ટાયર કવરેજ

કોઈપણ એક ક્વોટા પર નિર્ભરતા ઘટાડવા માટે ઘણા પ્રદાતાઓને કનેક્ટ કરો:

1. **Gemini** — રિકરિંગ API-કી ક્વોટા
2. **Groq** — રિકરિંગ API-કી ક્વોટા
3. **પરાગનયન** — કીલેસ, દર-મર્યાદિત ઍક્સેસ
4. **LongCat** — વન-ટાઇમ સાઇનઅપ ગ્રાન્ટ ( KYC જરૂરી છે)

પછી `model: "auto"` ઉપયોગ કરો અને OmniRoute કરશે:

- પ્રથમ ઉચ્ચ-ક્રમાંકિત પાત્ર કનેક્શનનો પ્રયાસ કરો
- જો તેનો ક્વોટા અથવા આરોગ્ય તપાસ નિષ્ફળ જાય તો → આગલા રૂપરેખાંકિત પ્રદાતાનો પ્રયાસ કરો
- જો કીલેસ પ્રદાતા અનુપલબ્ધ હોય તો → બાકીના લક્ષ્યો દ્વારા ચાલુ રાખો
- જો કોઈ યોગ્ય જોડાણ સફળ ન થાય તો → ભૂલ પરત કરો; સાઇનઅપ ક્રેડિટ્સ માન્ય અને ઉપલબ્ધ હોય ત્યારે જ ઉપયોગી છે

**પરિણામ** : ઓટોમેટિક ફોલબેક — સાથે વ્યાપક ફ્રી-ટાયર કવરેજ અમર્યાદિત ક્ષમતાની ગેરંટી નથી.

## મફત પ્રદાતાઓને કેવી રીતે કનેક્ટ કરવું

### પગલું 1: ડેશબોર્ડ ખોલો

તમારા બ્રાઉઝરમાં `http://localhost:20128` પર જાઓ.

### પગલું 2: પ્રદાતાઓ પર જાઓ

ક્લિક કરો** પ્રદાતાઓ** સાઇડબારમાં.

### પગલું 3: પ્રદાતા ઉમેરો પર ક્લિક કરો

ક્લિક કરો**+ પ્રદાતા ઉમેરો** બટન

### પગલું 4: મફત પ્રદાતા પસંદ કરો

કેટલોગ બ્રાઉઝ કરો અને દરેક પ્રદાતાના વર્તમાન `hasFree`, auth, ક્વોટા, ગોપનીયતા અને ToS મેટાડેટાનું નિરીક્ષણ કરો. પ્રદાતા કાર્ડ અને [ફ્રી ટિયર્સ રેફરન્સ](../reference/FREE_TIERS.md) રિકરિંગ પૂલ, uncapped/keyless એક્સેસ, સાઇનઅપ ક્રેડિટ્સ, બંધ થયેલી એન્ટ્રીઓ અને ઉચ્ચ જોખમના સ્ત્રોતોને અલગ પાડે છે.

### પગલું 5: કનેક્ટ પર ક્લિક કરો

`NOAUTH` પ્રદાતા માટે, OmniRoute અપસ્ટ્રીમ ઓળખપત્રની વિનંતી કરતું નથી. આ બાંહેધરી આપતું નથી કે અપસ્ટ્રીમ તૃતીય-પક્ષ ગ્રાહકોને સ્વીકારે છે અથવા ઉપલબ્ધ ક્ષમતા ધરાવે છે. OAuth અને API-કી પ્રદાતાઓ તેમના દસ્તાવેજીકૃત એકાઉન્ટ પ્રવાહ દ્વારા જોડાયેલા હોવા જોઈએ. તમારો ક્લાયંટ હજી પણ માં બનાવેલ OmniRoute API કીનો ઉપયોગ કરે છે** ડેશબોર્ડ → API કી** (બનાવતી વખતે માત્ર એક જ વાર બતાવવામાં આવે છે) જ્યારે રાઉટર પ્રમાણીકરણ સક્ષમ હોય.

### પગલું 6: પુનરાવર્તન કરો

ઘણા પ્રદાતાઓને કનેક્ટ કરો કે જેમની શરતો અને ગોપનીયતા મોડેલ તમારા ઉપયોગના કેસમાં બંધબેસે છે.

## dsh "અમારું ફ્રી મોડલ" તરફથી આવે છે

dsh એજન્ટ હોસ્ટ માટે [dsh-our-free-model](https://github.com/Ebony-Vinyl/dsh-our-free-model) પ્લગઇન બે અપસ્ટ્રીમ સુધી પહોંચે છે. OmniRoute પાસે પહેલાથી જ દરેક માટે પ્રદાતા છે, પરંતુ તેમાંથી માત્ર એક જ OmniRoute માં મફત માર્ગ છે:

| પ્લગઇન લેન | અપસ્ટ્રીમ                                 | OmniRoute પ્રદાતા           | OmniRoute માં મફત? | કેવી રીતે કનેક્ટ કરવું                                                     |
| ---------- | ----------------------------------------- | --------------------------- | ------------------ | -------------------------------------------------------------------------- |
| કિલો ચેનલ  | કિલો AI ગેટવે (`api.kilo.ai/api/gateway`) | `kilo-gateway` (ઉર્ફે `kg`) | હા                 | API કી વૈકલ્પિક: ગેટવેના ફ્રી પૂલનો ઉપયોગ કરવા માટે તેને ખાલી છોડી દો      |
| ફ્રી લેન   | OpenCode Zen (`opencode.ai`)              | `opencode-zen`              | ના                 | [opencode.ai/zen](https://opencode.ai/zen) થી તમારી પોતાની OpenCode API કી |

**કિલો.** ફ્રી પૂલને `kilo-gateway/<model>` અથવા `kg/<model>` તરીકે કૉલ કરો, ઉદાહરણ તરીકે `kg/kilo-auto/free` (કિલોનું ફ્રી ઑટો-રાઉટર) અથવા ગેટવેના `:free` મોડલ્સમાંથી એક. મફત સમૂહ ફરે છે; `kilo-gateway` એ મોડેલ આઈડીમાંથી પસાર થાય છે જે OmniRoute ની બિલ્ટ-ઇન સૂચિમાં નથી, તેથી કૅટેલોગમાં શામેલ થાય તે પહેલાં આજે ગેટવે સૂચિઓ જે મોડેલને કૉલ કરી શકાય છે. કિલોના ફ્રી મોડલ કાર્ડ્સ કહે છે કે પ્રોમ્પ્ટ અપસ્ટ્રીમ પ્રદાતા દ્વારા લૉગ કરવામાં આવી શકે છે અને તેનો ઉપયોગ તેની સેવાઓ સુધારવા માટે થાય છે, તેથી સંવેદનશીલ ડેટા મોકલશો નહીં.

**OpenCode** પ્લગઇનની ફ્રી લેન એ OpenCode ની કી-ફ્રી ઓફર છે. OmniRoute તે ઑફરને મફત ઍક્સેસ તરીકે પ્રદાન કરતું નથી:

- OmniRoute ના કીલેસ OpenCode પ્રદાતાને OpenCode ના ઓપરેટરની વિનંતી પર દૂર કરવામાં આવ્યું હતું (જુઓ [દૂર કરેલ પ્રદાતાઓ](../reference/REMOVED_PROVIDERS.md) ).
- OpenCode ના [એન્ડપોઇન્ટ દસ્તાવેજીકરણ](https://opencode.ai/v2/docs/console/models/#endpoints) તેની મફત ચેટ ઓફરને OpenCode ના પોતાના ક્લાયન્ટ સાથે જોડે છે, તેથી OmniRoute તેમને મફત તરીકે ગણતું નથી અથવા બેજ કરતું નથી.

મોડેલ પ્લગઇન શોને દર્શાવે છે, જેમ કે `deepseek-v4.1-flash-free`, `mimo-v2.6-flash-free` અને `nemotron-3.5-lightning-free`, `opencode-zen` કેટલોગમાં છે. તમારા OpenCode એકાઉન્ટની શરતો હેઠળ તેનો ઉપયોગ કરવા માટે તમારી પોતાની OpenCode કી સાથે `opencode-zen` કનેક્ટ કરો.

**પ્લગઇનનું સ્થાનિક પોર્ટ.** પ્લગઇન તેના મોડલ્સને સ્થાનિક OpenAI- સુસંગત પોર્ટ (ડિફોલ્ટ `18899`) પર ઉજાગર કરી શકે છે. આવા કોઈપણ એન્ડપોઈન્ટને [કસ્ટમ OpenAI-સુસંગત પ્રદાતા](../guides/USER_GUIDE.md#custom-openai-compatible-providers) તરીકે ઉમેરી શકાય છે, પરંતુ OmniRoute પ્લગઈનને ઈન્સ્ટોલ, સ્ટાર્ટ કે અપડેટ કરતું નથી અને પ્લગઈન નક્કી કરે છે કે કઈ અપસ્ટ્રીમ દરેક વિનંતીને સેવા આપે છે. ઉપરોક્ત OpenCode પ્રતિબંધો OpenCode ની ઓફર પર લાગુ થાય છે જે પણ ક્લાયન્ટ વિનંતી મોકલે છે.

## કેટલોગ યોગ્ય રીતે વાંચો

- `NOAUTH` એટલે OmniRoute તમને પ્રદાતા ઓળખપત્ર માટે પૂછતું નથી; તે અપટાઇમ, ગોપનીયતા અથવા અમર્યાદિત ક્ષમતાની બાંયધરી આપતું નથી.
- `hasFree` એ શોધ મેટાડેટા છે. તે રિકરિંગ ક્વોટા, કીલેસ એક્સેસ, સાઇનઅપ ક્રેડિટ, મંજૂરી પ્રોગ્રામ અથવા પ્રમોશનનું પ્રતિનિધિત્વ કરી શકે છે.
- `recurring-uncapped` એટલે કોઈ પ્રકાશિત ટોકન સીલિંગ ઉપલબ્ધ ન હતી; દર અને સહવર્તી મર્યાદા હજુ પણ લાગુ પડે છે.
- સાઇનઅપ ગ્રાન્ટનો વપરાશ થઈ જાય પછી`one-time-initial` પુનરાવર્તિત થતો નથી.
- `tos: avoid` પ્રદાતાઓને મૂળભૂત રીતે સ્વચાલિત રૂટીંગમાંથી બાકાત રાખવામાં આવ્યા છે (`excludeTosAvoid`). એકાઉન્ટને કનેક્ટ કરવું આ ફિલ્ટરને બાયપાસ કરતું નથી. કોઈપણ ઓપરેટર ઓવરરાઇડે પ્રદાતાની શરતો અને એકાઉન્ટ જોખમની સમીક્ષાને અનુસરવી જોઈએ.
- `discontinued` ચિહ્નિત એન્ટ્રીઓ ઐતિહાસિક પુરાવા રહે છે અને હાલમાં મફત તરીકે રજૂ થવી જોઈએ નહીં.

## કેવી રીતે OmniRoute ફ્રી ટિયર્સને બહેતર બનાવે છે

### 1. આપોઆપ ફોલબેક

જો એક મફત પ્રદાતા વ્યસ્ત અથવા બંધ હોય, તો OmniRoute આપમેળે આગલાનો પ્રયાસ કરે છે. તમારે કંઈ કરવાની જરૂર નથી.

### 2. સ્માર્ટ રૂટીંગ

OmniRoute પસંદ કરે છે** શ્રેષ્ઠ મફત પ્રદાતા** આના આધારે દરેક વિનંતી માટે:

- Speed — અત્યારે કયું પ્રદાતા સૌથી ઝડપી છે?
- ગુણવત્તા — આ કાર્ય માટે કયું પ્રદાતા શ્રેષ્ઠ છે?
- ક્ષમતા — કયા પ્રદાતા પાસે ક્વોટા બાકી છે?

### 3. ટોકન બચત

OmniRoute ની કમ્પ્રેશન પાઇપલાઇન પાત્ર પ્રોમ્પ્ટ અને ટૂલ-આઉટપુટ ટોકન્સ ઘટાડી શકે છે. વાસ્તવિક બચત સામગ્રી, પસંદ કરેલ એન્જિન, પ્રદાતા એકાઉન્ટિંગ અને વફાદારી સેટિંગ્સ પર આધારિત છે; કમ્પ્રેશન દરેક પ્રદાતાના ક્વોટાને નિશ્ચિત રકમથી ગુણાકાર કરતું નથી.

### 4. મલ્ટી-એકાઉન્ટ સપોર્ટ

જો પ્રદાતાની શરતો બહુવિધ એકાઉન્ટ્સ અથવા ઓળખપત્રોને પરવાનગી આપે છે, તો OmniRoute દરેક કનેક્શનને અલગ રૂટીંગ ઉમેદવાર તરીકે ગણી શકે છે. પ્રદાતાના ક્વોટા અથવા ઍક્સેસ નીતિને ટાળવા માટે વધારાના એકાઉન્ટ્સ બનાવશો નહીં.

આ અલગ-અલગ પાત્ર ખાતાઓમાં કેટલોગ-વ્યાપી અંદાજો છે, OmniRoute દ્વારા પૂરા પાડવામાં આવેલ ભથ્થું અથવા નવા ઇન્સ્ટોલેશન માટેનું અનુમાન નથી. તમારી ઉપયોગી ક્ષમતા તમે કનેક્ટ કરો છો તે પ્રદાતાઓ અને તેમની વર્તમાન પરિસ્થિતિઓ પર આધાર રાખે છે. મૂલ્યોની ગણતરી `open-sse/config/freeModelCatalog.ts` થી કરવામાં આવે છે; પૂલ ડિડુપ્લિકેશન, ToS ફ્લેગ્સ, બંધ કરેલ એન્ટ્રીઓ અને સાઇનઅપ-ક્રેડિટ પદ્ધતિ માટે [ફ્રી ટિયર્સ સંદર્ભ](../reference/FREE_TIERS.md) જુઓ.

## સામાન્ય પ્રશ્નો

### "શું આ ખરેખર મફત છે?"

સૂચિ પ્રદાતા-પ્રકાશિત શરતો અને પ્રોજેક્ટ સંશોધનને રેકોર્ડ કરે છે, પરંતુ ઑફરો બદલાઈ શકે છે. ઉપયોગ કરતા પહેલા પ્રદાતાની વર્તમાન કિંમત, ક્વોટા, ગોપનીયતા નીતિ અને પાત્રતા ચકાસો.

### "શું ફ્રી ટાયર સમાપ્ત થઈ જશે?"

દરેક પ્રદાતા રેટ-લિમિટ કરી શકે છે, મૉડલ બદલી શકે છે, ઍક્સેસ સસ્પેન્ડ કરી શકે છે અથવા ઑફલાઇન જઈ શકે છે. બહુવિધ કનેક્શન્સ ફોલબેક કવરેજમાં સુધારો કરે છે પરંતુ ઉપલબ્ધ મફત રૂટની બાંયધરી આપતા નથી.

### "શું હું ઉત્પાદન માટે મફત પ્રદાતાઓનો ઉપયોગ કરી શકું?"

જો પ્રદાતાના SLA, ડેટા હેન્ડલિંગ, મર્યાદાઓ અને શરતો તમારી ઉત્પાદન જરૂરિયાતોને પૂર્ણ કરે તો જ. જટિલ વર્કલોડ પર દેખરેખ રાખવી જોઈએ, કરાર મુજબ યોગ્ય ફોલબેક.

### "કેચ શું છે?"

ટ્રેડઓફમાં કડક મર્યાદા, વેઇટલિસ્ટ, KYC, ક્રેડિટ કાર્ડ વેરિફિકેશન, પ્રોમ્પ્ટ પર તાલીમ, નબળી ગોપનીયતા, નો SLA, મોડલ મંથન, ભૌગોલિક પ્રતિબંધો, પેઇડ ઓવરેજ અથવા એકાઉન્ટ-પોલીસી જોખમ શામેલ હોઈ શકે છે. OmniRoute ઉપલબ્ધ મેટાડેટાને સરફેસ કરે છે; તમે શું સક્ષમ કરવું તે પસંદ કરો.

### "હું વધુ મફત ક્વોટા કેવી રીતે મેળવી શકું?"

1. વધુ મફત પ્રદાતાઓને કનેક્ટ કરો
2. યોગ્ય કમ્પ્રેશન એન્જિનને સક્ષમ કરો અને તમારા વર્કલોડ માટે બચતને માપો
3. free/cheap પ્રદાતાઓને પ્રાધાન્ય આપવા માટે `auto/cheap` ઉપયોગ કરો
4. પ્રદાતાની શરતોનું ઉલ્લંઘન કર્યા વિના વધારાની પરવાનગી પ્રદાતાઓ અથવા ઓળખપત્રો ઉમેરો

### "શું મફત પ્રદાતાઓની ગુણવત્તા વધુ ખરાબ છે?"

જરૂરી નથી. કેટલાક પ્રદાતાઓ પેઇડ રૂટ દ્વારા ઉપલબ્ધ સમાન મોડેલ પરિવારોને જાહેર કરે છે, પરંતુ મર્યાદા, વિલંબ, ગોપનીયતા, વિશ્વસનીયતા અને મોડેલ સંસ્કરણો અલગ હોઈ શકે છે. ગુણવત્તા સિગ્નલ તરીકે મફત પ્રદાતા રેન્કિંગ પૃષ્ઠનો ઉપયોગ કરો અને વાસ્તવિક મોડેલની ચકાસણી કરો.
