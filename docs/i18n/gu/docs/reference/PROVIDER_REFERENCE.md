કુલ પ્રદાતાઓ:** 394** . નીચે કેટેગરી બ્રેકડાઉન જુઓ.

## શ્રેણીઓ

- **મફત** API કી સાથે — ફ્રી ટાયર (ડૅશબોર્ડ દ્વારા ગોઠવેલ)
- **નો-ઓથ** — સાર્વજનિક અંતિમ બિંદુઓ કે જેને કોઈ કી અથવા સાઇન-ઇનની જરૂર નથી
- **OAuth** — સાઇન-ઇન ફ્લો OmniRoute દ્વારા નિયંત્રિત થાય છે, API કીની જરૂર નથી
- **વેબ કૂકી** — કૂકી ઓથ દ્વારા પ્રદાતાની વેબ એપ્લિકેશનને લપેટી લે છે
- **API કી** — પેઇડ પ્રદાતા API કી દ્વારા ગોઠવેલ છે (મફત ક્રેડિટ્સ લાગુ થઈ શકે છે)
- **સ્થાનિક** — વપરાશકર્તાના મશીન પર ચાલે છે (Ollama, LM સ્ટુડિયો, vLLM, વગેરે.)
- **શોધો** — વેબ શોધ પ્રદાતાઓ
- **ઓડિયો** — માત્ર ઑડિયો પ્રદાતાઓ (TTS/STT)
- **અપસ્ટ્રીમ પ્રોક્સી** — પ્રદાતાઓ કે જે અન્ય પ્રદાતાઓને પ્રોક્સી આપે છે
- **ક્લાઉડ એજન્ટ** — લાંબા સમયથી ચાલતા કોડિંગ એજન્ટ્સ (Codex ક્લાઉડ, Devin, Jules)
- **સિસ્ટમ** — OmniRoute-આંતરિક પ્રદાતાઓ (લૂપબેક, વગેરે)

વધારાના ટૅગ્સ: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (જ્યાં બતાવેલ છે): `native` — વાસ્તવિક કાર્ય-કોલિંગ API; `emulated` — `tools` એરે `webTools.ts` (રેજેક્સ-પાર્સ્ડ `<tool>{...}</tool>` બ્લોક્સ) દ્વારા પ્રોમ્પ્ટ-ઇમ્યુલેટેડ છે; `none` — `tools` હાલમાં ચુપચાપ છોડી દેવામાં આવ્યું છે. #7286 જુઓ.

દરેક પ્રદાતાને સક્ષમ કરવા, ગોઠવવા અને પરીક્ષણ કરવા માટે `/dashboard/providers` પર ડેશબોર્ડનો ઉપયોગ કરો.
