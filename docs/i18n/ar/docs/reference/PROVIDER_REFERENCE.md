## الفئات

- **مجاني** — فئة مجانية باستخدام مفتاح API (يُضبط عبر لوحة التحكم)
- **بلا مصادقة** — نقاط نهاية عامة لا تتطلب مفتاحًا أو تسجيل دخول على الإطلاق
- **OAuth** — تدفق تسجيل الدخول تديره OmniRoute، ولا يلزم مفتاح API
- **ملف تعريف ارتباط للويب** — يغلّف تطبيق الويب الخاص بالمزوّد باستخدام مصادقة ملفات تعريف الارتباط
- **مفتاح API** — مزوّد مدفوع يُضبط باستخدام مفتاح API (قد تتوفر أرصدة مجانية)
- **محلي** — يعمل على جهاز المستخدم (Ollama وLM Studio وvLLM وغيرها)
- **بحث** — مزوّدو البحث على الويب
- **صوت** — مزوّدو الصوت فقط (TTS/STT)
- **وكيل وسيط علوي** — مزوّدون يعملون كوكلاء لمزوّدين آخرين
- **وكيل سحابي** — وكلاء برمجة يعملون لفترات طويلة (Codex Cloud وDevin وJules)
- **النظام** — مزوّدون داخليون في OmniRoute (الاسترجاع الحلقي، وغيرها)

وسوم إضافية: `image`، و`video`، و`aggregator`، و`enterprise`، و`embed/rerank`، و`self-hosted`.

`Tool calling` (حيثما يظهر): `native` — واجهة API حقيقية لاستدعاء الدوال؛ `emulated` — تُحاكى مصفوفة `tools` عبر المطالبات باستخدام `webTools.ts` (كتل `<tool>{...}</tool>` محلّلة بالتعبيرات النمطية)؛ `none` — يجري حاليًا تجاهل `tools` بصمت. راجع #7286.

استخدم لوحة التحكم على `/dashboard/providers` لتمكين كل مزوّد وضبطه واختباره.
