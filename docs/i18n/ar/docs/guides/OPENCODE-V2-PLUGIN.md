تضع الحزمة `@omniroute/opencode-plugin-v2` كتالوج OmniRoute بالكامل — النماذج، والتركيبات، والتركيبات التلقائية — في منتقي النماذج في OpenCode v2، مع أسماء العرض، والتسعير، وحصص الفئة المجانية.

وهي حزمة منفصلة عن `@omniroute/opencode-plugin` لأن OpenCode v1 وv2 يحمّلان المكونات الإضافية من خلال عقود مختلفة. اختر الحزمة المطابقة للإصدار الرئيسي من OpenCode لديك؛ فلا شيء مشترك بينهما، لذا لا تفرض ترقية إحداهما ترقية الأخرى مطلقًا.

## المتطلبات

- OpenCode v2.
- بوابة OmniRoute يمكن الوصول إليها (`http://localhost:20128` افتراضيًا).
- Node.js 22 أو 24.

## التثبيت

أضف المكون الإضافي إلى `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

ستظهر النماذج بعد ذلك بالصيغة `omniroute/<provider>/<model>`؛ وتحدد `providerId` هذه البادئة ومعرّف التكامل الذي يخزّن OpenCode بيانات الاعتماد تحته.

## بيانات الاعتماد

يبحث المكون الإضافي عن مفتاح البوابة في ثلاثة مواضع، بالترتيب التالي:

1. **بيانات الاعتماد التي ربطتها في OpenCode.** يسجّل المكون الإضافي تكاملًا، بحيث يمكن لمسار المصادقة الخاص بـ OpenCode تخزين المفتاح. لا يُكتب أي شيء في `opencode.json` — وهذا هو الخيار المفضّل.
2. `apiKey` ضمن خيارات المكون الإضافي، لتجاوز خاص بكل مشروع. يؤدي ذلك إلى وضع المفتاح في ملف قد تقوم بإيداعه في مستودعك.
3. `OMNIROUTE_API_KEY` في البيئة.

في حال عدم توفر أي من هذه الخيارات الثلاثة، يكون الكتالوج فارغًا ويُبلغ المكون الإضافي بذلك مرة واحدة عند بدء التشغيل، بدلًا من ترك منتقي فارغ دون أي تنبيه.

### رمز الإدارة هو مفتاح مختلف

تأتي التركيبات، وحالة المزوّد، والإثراء (أسماء العرض، والتسعير، وحصص الفئة المجانية) من نقاط النهاية `/api/*` الخاصة بالبوابة، والتي تحميها معظم عمليات النشر برمز **إدارة** بدلًا من مفتاح الاستدلال:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<رمز قراءة الإدارة>"
}
```

إذا لم تُضبط `managementReadToken`، فستعود إلى استخدام `apiKey`. عندما ترفض البوابة هذا الخيار الاحتياطي، يظل الكتالوج منشورًا، ولكن بمعرّفات النماذج الخام بدلًا من أسماء العرض، ومن دون إزالة التكرار للأسماء المستعارة القياسية، ومن دون تسعير أو تركيبات. يحذّر المكون الإضافي مرة واحدة لكل نقطة نهاية عند حدوث ذلك، مع ذكر نقطة النهاية وما فُقد — بحيث لا يكون سبب تراجع إمكانات المنتقي غامضًا أبدًا.

## خيارات

| مفتاح                            | تقصير                                           | ملحوظات                                                                                                                                                                                                                                                                                                               |
| -------------------------------- | ----------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `providerId`                     | `"omniroute"`                                   | يظهر معرف الموفر ومعرف التكامل ونماذج البادئة أسفل                                                                                                                                                                                                                                                                    |
| `baseURL`                        | مطلوب                                           | جذر البوابة، `http(s)` فقط؛ تتم إضافة لاحقة `/v1` عند الحاجة                                                                                                                                                                                                                                                          |
| `apiKey`                         | بيانات الاعتماد المتصلة، ثم `OMNIROUTE_API_KEY` | مفتاح الدردشة لـ `/v1/*`                                                                                                                                                                                                                                                                                              |
| `managementReadToken`            | يعود إلى `apiKey`                               | مفتاح `/api/*` — عادة** لا** نفس الشيء                                                                                                                                                                                                                                                                                |
| `displayName`                    | `"OmniRoute"`                                   | اسم الموفر في المنتقي                                                                                                                                                                                                                                                                                                 |
| `timeoutMs`                      | `10000`                                         | انتهت مهلة الجلب لكل نقطة نهاية (تستخدم المجموعات التلقائية 5 ثوانٍ)                                                                                                                                                                                                                                                  |
| `modelCacheTtlMs`                | `300000`                                        | كتالوج ذاكرة التخزين المؤقت TTL; لقطة القرص تسخن وتبدأ باردة                                                                                                                                                                                                                                                          |
| `timeouts`                       | يعود إلى `timeoutMs`                            | ميزانيات كل نقطة نهاية بالمللي ثانية: `models`, `combos`, `autoCombos`, `enrichment`                                                                                                                                                                                                                                  |
| `enrichment`                     | `true`                                          | جلب الأسماء والأسعار وميزانيات الطبقة المجانية                                                                                                                                                                                                                                                                        |
| `providerTag`                    | `true`                                          | قم بتبديل قوس المحرر اللاحق: `Provider - Model (Editor)`. يظهر دائمًا الموفر (الطريق الذي يخدم النموذج)؛ يظهر المحرر (الذي صنع النموذج) بين قوسين فقط. مثال: `Openrouter - MoonshotAI: Kimi K 3.1 Pro` -> `Openrouter - Kimi K 3.1 Pro (MoonshotAI)`. تم حذفه عندما يشارك المحرر والموفر الاسم. اضبط `false` لإسقاطه. |
| `usableOnly`                     | `false`                                         | احتفظ بمقدمي الخدمة فقط بتقارير البوابة كما تم توفيرها                                                                                                                                                                                                                                                                |
| `combosSource`                   | `"api"`                                         | `"models"` يتخطى `/api/combos` وينشر صفوف التحرير والسرد `/v1/models` ؛ تحافظ المرشحات على مستوى الأعضاء على `"api"`                                                                                                                                                                                                  |
| `showcasePerOwner`               | `10`                                            | يتم الاحتفاظ بإدخالات العرض الافتراضية لكل مزود                                                                                                                                                                                                                                                                       |
| `freshPerOwner`                  | `10`                                            | العرض الافتراضي للإدخالات الجديدة المحفوظة لكل مزود                                                                                                                                                                                                                                                                   |
| `freshWindowDays`                | `90`                                            | نافذة نضارة في أيام للفرع الطازج                                                                                                                                                                                                                                                                                      |
| `usageMemory`                    | `true`                                          | استعادة الإدخالات التي تم إسقاطها بشكل ثابت والتي تم تحديدها بواسطة تحليلات الاستخدام لمدة 30 يومًا (تحتاج إلى رمز مميز للإدارة)                                                                                                                                                                                      |
| `visibleModels` / `hiddenModels` | `[]`                                            | القوائم المسموح بها تمامًا أو لاحقة؛ إنكار الانتصارات؛ `*` تنشر الكتالوج الكامل (لا تزال هناك عوامل تصفية أخرى مطبقة)                                                                                                                                                                                                 |
| `geminiSanitization`             | `true`                                          | قم بإزالة الكلمات الأساسية التي يرفضها Gemini في JSON-Schema من مخططات الأداة (تتم إعادة توجيه أدوات `$ref` دون تغيير)                                                                                                                                                                                                |
| `apiFormat.allowAnthropic`       | `false`                                         | قم بتوجيه المعرفات المدرجة في القائمة المسموح بها من خلال كتلة Anthropic API                                                                                                                                                                                                                                          |
| `apiFormat.anthropicModels`      | `[]`                                            | تم توجيه معرفات النماذج الكاملة إلى Anthropic                                                                                                                                                                                                                                                                         |
| `logLevel` / `startupDebug`      | `warn` / `false`                                | الإسهاب المسجل                                                                                                                                                                                                                                                                                                        |

ذاكرة الاستخدام قيد التشغيل بشكل افتراضي. بدون رمز الإدارة، يظل خاملاً (يتم تسجيل إشعار بدء التشغيل) ولا تتم استعادة أي شيء.

## كيف يبقى الكتالوج جديدًا

يتم جلب الكتالوج بتكاسل وتخزينه مؤقتًا لـ `modelCacheTtlMs`، كما أن لقطة القرص تحافظ على آخر كتالوج معروف متاحًا عندما لا يمكن الوصول إلى البوابة — يكلفك انقطاع الخدمة شيئًا سوى الحداثة. يتم نشر النماذج والمجموعات بمجرد وصولها؛ يتم طي المجموعات التلقائية وقائمة الموفرين وتراكب الإثراء عند هبوطهم، لذلك لا يمكن لنقطة نهاية بطيئة واحدة أن تحتجز المنتقي بأكمله كرهينة.

تتبع الأسماء `Provider - Model[ (Editor)][ · budget][ (route)]`: يتم عرض الموفر عندما يحمل المعرف واحدًا (يتم عرض معرف بدون شرطة مائلة بدون بادئة)، ويحدد `🆓` البادئ الإدخالات المجانية وتبقى ميزانية الطبقة المجانية الخاصة به كلاحقة `· 1M tokens/month` ، وينتقل محرر اسم `Editor: Model` الصريح إلى قوس زائد (لا يتم تخمين أي محرر من الأسماء الأخرى)، ويتم عرض المجموعات كـ `combo - <slug>` بدون رمز مجاني. يحصل الإدخالان اللذان يشتركان في الاسم على لاحقة مسار — `(no-think)` — حتى يظلا مميزين. يقوم `providerTag` (افتراضي `true`) بتبديل قوس المحرر اللاحق.

لا يوجد أمر تحديث يدوي: أوامر OpenCode v2 عبارة عن قوالب سريعة، وليست عمليات رد اتصال، لذا لا يمكن للمكون الإضافي الكشف عنها. تحديثات اتبع TTL; يُطلب من المضيف إعادة التحميل فقط عندما يتغير الكتالوج أو التراكب فعليًا، وليس مرة واحدة في كل تحديث.

## استدعاء الأدوات على Gemini

يرفض Gemini الطلب بالكامل إذا كانت تعريفات أدواته تحتوي على `$schema` أو
`additionalProperties`، ويردّ بـ `400 INVALID_ARGUMENT`. تزيل الإضافة هاتين الكلمتين المفتاحيتين من
مخططات الأدوات المتجهة إلى نموذج Gemini لدى موفر الخدمة هذا، وتترك جميع الطلبات الأخرى دون تغيير.
تُمرَّر الأداة التي تحتوي على `$ref` دون تغيير بدلًا من إزالة هذه العناصر منها، لأن إزالة
المرجع ستوسّع المخطط ليصبح «قبول أي شيء».
اضبط `"geminiSanitization": false` لتعطيل ذلك.

## استكشاف الأخطاء وإصلاحها

| أعراض                                            | سبب                                                                                                              |
| ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| لا يظهر المنتقي أي نموذج OmniRoute               | لم يتم حل أي مفتاح (تحقق من تحذير بدء التشغيل)، أو أن البوابة غير قابلة للوصول                                   |
| معرفات النماذج الأولية، لا المجموعات، لا التسعير | رفضت نقاط نهاية الإدارة الرمز المميز — الذي تم تعيينه `managementReadToken`                                      |
| كتالوج `freeOnly` قصير أو فارغ                   | لا يوجد رمز مميز للإدارة أو رمز مميز مرفوض — يقرأ سطر ملخص التحديث (عدد `unmatched-free` ) في سجل المضيف         |
| جلسة مثبتة على `opencode-<id>/...`               | تم نشر البرنامج المساعد v1 `opencode-<id>`؛ ينشر الإصدار الثاني `<id>` فقط، لذا أعد تحديد النموذج ضمن `<id>/...` |

يجب أن تصل متغيرات البيئة إلى عملية خادم الكود المفتوح: عندما يعمل المضيف كخدمة، فإن الغلاف الذي يقوم بتشغيل `opencode models` يختلف عن بيئة الخادم، لذا قم بتصدير المفتاح حيث يقرأه الخادم.
