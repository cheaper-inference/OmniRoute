**OmniCopilot** يضيف نماذج ومجموعات دردشة OmniRoute الخاصة بك إلى منتقي نماذج Copilot Chat الأصلي. استخدم مسارات عمل الدردشة والوكيل الحالية للمحرر، مع استدعاء الأداة والرؤية عندما يكون مدعومًا بالنموذج المحدد.

لا يؤدي توفر VSX المفتوح في حد ذاته إلى إنشاء التوافق مع كل محرر يستخدم هذا السجل. تحقق من دعم دردشة المحرر ونموذج اللغة API.

> **ليست هناك حاجة إلى اشتراك Copilot لدردشة BYOK في كود VS 1.122 +.** يدعم Microsoft الدردشة والأدوات و MCP بدون تسجيل الدخول إلى GitHub عند تكوين الموفر. في VS Code 1.104–1.121، لا يزال الامتداد يعمل، لكن VS Code يتطلب خطة Copilot مسجلة الدخول. تظل الاقتراحات المضمّنة والميزات المستندة إلى التضمينات خارج الموفر API ولا تزال تتطلب Copilot؛ يمكن لمسؤولي Copilot Business/Enterprise تعطيل موفري نماذج الطرف الثالث حسب السياسة؛ تُظهر الشوكة النماذج فقط إذا كانت تنفذ موفر الدردشة API. لا يزال من الممكن أن يؤدي استخدام موفر الخدمة الأولية إلى فرض رسوم. راجع [ملاحظات الإصدار VS Code 1.122](https://code.visualstudio.com/updates/v1_122#_use-byok-without-a-github-sign-in) [ودليل نموذج اللغة](https://code.visualstudio.com/docs/agent-customization/language-models).

## يثبت

1. **تشغيل OmniRoute** — `npm install -g omniroute && omniroute` (لوحة المعلومات على `http://localhost:20128`).
2. **قم بتثبيت الامتداد** — ابحث عن "OmniRoute" في عرض الامتدادات.
3. **يتصل** احتفظ — `http://localhost:20128` الافتراضي أو قم بتعيين مفتاح URL و API لخادمك**OmniRoute: إدارة الاتصال** .
4. **اختر نموذجًا** — Copilot دردشة → منتقي النماذج →** إدارة النماذج...** →**OmniRoute** ، ثم حدد ما تريد.

لإعدادات الاتصال، افتح** أيقونة OmniRoute في شريط الأنشطة** (أو قم بتشغيل `OmniRoute: Manage Connection`) وقم بتعيين:

- **خادم URL** — جذر الخادم، على سبيل المثال `http://omniroute.example.com:20128`. يتم إلحاق اللاحقة `/v1` بالملحق؛ لا تشمل ذلك.
- **مفتاح API** — مطلوب عندما تتطلب سياسة مصادقة الاستدلال الخاصة بالخادم ذلك. يتم تخزينها من خلال رمز VS SecretStorage، ولا يتم تخزينها أبدًا في `settings.json`؛ تتوفر مفاتيح خاصة بمساحة العمل. استخدم مفتاحًا معتمدًا للنماذج التي تريد كشفها.

يوفر الامتداد أيضًا مؤشر اتصال، وتحديث النموذج، وسياق النموذج، وبيانات تعريف التسعير (المجموعات متضمنة)، والتفكير المتدفق مع** جهد التفكير** القائمة الموجودة على VS Code 1.120 + ومؤشر الحد اليومي لشريط الحالة ولوحة الاستخدام (OmniRoute 3.8.50 +) وتكوين CLI وعلامة تبويب لوحة القيادة الاختيارية. يحدد النموذج المحدد وسياسة الخادم الإمكانات التي يمكنك استخدامها.

## ما سيعرضه المنتقي

لا يعرض الامتداد حمولة `GET /v1/models` الأولية — بل يعيد تشكيلها، ولذلك يكون العدد الذي
تراه أقل من حجم الكتالوج لسببين مقصودين.

### يطلب معرّفًا واحدًا لكل نموذج

الوضع الافتراضي لـ `MODELS_CATALOG_PREFIX_MODE` هو **`dual`**، ما يعلن عن كل نموذج مرتين — مرة
باستخدام بادئة الاسم المستعار المختصرة، ومرة باستخدام بادئة الموفّر القياسية — بحيث تظل إعدادات
العملاء الأقدم قادرة على تحليل الصيغتين:

```
cc/claude-sonnet-4-6        ← بادئة الاسم المستعار
claude/claude-sonnet-4-6    ← البادئة القياسية، النموذج نفسه
```

يطلب الامتداد **`GET /v1/models?prefix=alias`** بحيث يصل معرّف واحد لكل نموذج، من دون
تغيير الإعداد العام للخادم لدى عملائك الآخرين. في مثيل مرجعي، أدى ذلك إلى تقليص
**2345 إدخالًا إلى 1396 — أي 949 نسخة مكررة، من دون فقدان أي نموذج.**

إذا كنت تفضّل معالجة ذلك على مستوى الخادم _لكل_ عميل، فاضبط علامة الميزة
`MODELS_CATALOG_PREFIX_MODE` على `alias` في لوحة المعلومات. راجع
[API_REFERENCE ← البادئة](../reference/API_REFERENCE.md#model-id-prefixes-prefix) للاطلاع على
معامل الاستعلام والجدول الخاص بكل وضع.

### يخفي النماذج التي لا يمكنها إجراء الدردشة

يسرد الكتالوج أيضًا نماذج الصور والفيديو والصوت وإعادة الترتيب والتضمين والإشراف. وهذه
تُرفض على أي حال عند إرسال طلب دردشة:

```
HTTP 400 — النموذج '<id>' هو نموذج لتوليد الصور ولا يمكن استخدامه على
/v1/chat/completions. استخدم POST /v1/images/generations بدلًا منه.
```

ولذلك تُرشَّح استنادًا إلى حقل `type` الخاص بها قبل وصولها إلى المنتقي. **يتم الاحتفاظ بنماذج
Responses-API** — يعلن كل إدخال Codex / GPT-5.x عن `supported_endpoints: ["responses"]`،
ويحوّل OmniRoute هذه الطلبات لاستخدام `/v1/chat/completions`، لذا فهي قابلة للاستخدام بشكل كامل.

### الموفّرون الذين لم تضبطهم مطلقًا

يسرد الكتالوج نماذج الموفّرين الذين لديهم **اتصال نشط** _بالإضافة إلى_ كل موفّري **noAuth**
— وهم الموفّرون الذين لا يتطلبون مفتاحًا ويشكّلون جزءًا كبيرًا من الفئة المجانية. هذا مقصود. لإخفائهم،
أضفهم إلى `blockedProviders` في إعدادات لوحة المعلومات؛ لا يتغير أي شيء في
الامتداد.

## لوحة المعلومات داخل علامة تبويب في VS Code

يعرض `omnicopilot.dashboardOpen: "editor"` لوحة معلومات OmniRoute في علامة تبويب للمحرر عبر
Simple Browser بدلًا من متصفح خارجي. التضمين **يتطلب تفعيلًا صريحًا على الخادم** من خلال
`DASHBOARD_ALLOW_EMBED=vscode`، ما يؤدي إلى تقديم صفحات HTML باستخدام
`frame-ancestors 'self' vscode-webview:` بدلًا من الإعداد الافتراضي `frame-ancestors 'none'` +
`X-Frame-Options: DENY`. وتحتفظ واجهات API (`/api`، و`/v1`، و`/v1beta`، و`/a2a`، و`/healthz`)
بالترويسات الصارمة في كلتا الحالتين.

> ⚠️ **هذه علامة خاصة بوقت البناء، وليست بوقت التشغيل.** يترجم Next.js الدالة `headers()` إلى بيان
> المسارات، لذا يقرأ `next.config.mjs` المتغير أثناء بناء الحزمة
> (`next.config.mjs` → `resolveDashboardEmbedMode`، و`scripts/build/dashboardEmbed.mjs`).
> لن يؤدي تصديره قبل تشغيل خادم مبني مسبقًا إلى تغيير أي شيء — فالترويسات مضمّنة في البناء.

```bash
# يجب أن يكون المتغير موجودًا في أمر البناء
DASHBOARD_ALLOW_EMBED=vscode npm run build        # أو npm run build:release
npm start
```

| كيفية التثبيت              | هل يمكنك تمكين التضمين؟                                                                                                            |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| من المصدر                  | ✅ اضبط المتغير في أمر البناء، كما هو موضح أعلاه                                                                                   |
| `npm install -g omniroute` | ❌ تتضمن الحزمة المنشورة حزمةً مبنية مسبقًا — ابنِ من المصدر بدلًا من ذلك                                                          |
| صورة Docker                | ✅ `docker build --build-arg DASHBOARD_ALLOW_EMBED=vscode -t omniroute:embed .` — صورة Docker Hub المبنية مسبقًا غير مهيأة للتضمين |

من دون بناء مهيأ للتضمين، سترفض الصفحة العرض داخل إطار، وستكتشف الإضافة ذلك من
ترويسات الاستجابة وتعود إلى استخدام المتصفح الخارجي — لن يتعطل شيء، وستعرض إشعارًا بذلك مرة واحدة.
راجع [`ENVIRONMENT.md`](../reference/ENVIRONMENT.md) والمشكلة
[#10273](https://github.com/diegosouzapw/OmniRoute/issues/10273).

## تكوين أدواتك الأخرى من داخل VS Code

**`OmniRoute: Configure Coding CLI`** يدفع `omniroute` CLI لكتابة ملفات تعريف جاهزة للاستخدام لـ 16 أداة: Codex CLI و Claude Code و Cline continue و Cursor و Aider و OpenCode و Goose و Crush و Qwen Code و Kilo و Roo و Gemini CLI و Zed و WhyCodes و 5dive. يستدعي الامتداد أوامر `setup-*` في المحطة المتكاملة؛ تثبيت نسخة من OmniRoute CLI تتضمن الأمر المحدد. راجع [دليل تكامل CLI](CLI-INTEGRATIONS.md) للتعرف على الملفات والإشارات التي تستخدمها كل وصفة [وسجل أداة الامتداد](https://github.com/cheaper-inference/OmniCopilot/blob/main/src/cliBridge.ts).

يتم تسليم مفتاح API إلى CLI من خلال `OMNIROUTE_API_KEY`، وليس في سطر الأوامر أبدًا. يمكن أن تستمر وصفات الإعداد في الاحتفاظ ببيانات الاعتماد في تكوين الأداة المستهدفة. عند مشاركة مفتاح خاص بمساحة عمل مع تكوين على مستوى المستخدم للأداة، يطلب الامتداد التأكيد أولاً.

## استكشاف الأخطاء وإصلاحها

| أعراض                                                    | السبب / الإصلاح                                                                                                                                                                                                                                                  |
| -------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| لا توجد نماذج OmniRoute في المنتقي                       | الخادم غير قابل للوصول. تتحول نقطة شريط الحالة إلى اللون الرمادي؛ تشغيل `OmniRoute: Check Connection`. الاكتشاف صامت حسب التصميم ولا يساهم بأي نماذج بدلاً من التحفيز.                                                                                           |
| يظهر كل نموذج مرتين                                      | أنت تستخدم تحديث OmniCopilot الأقدم من 1.0.1 —. يطلب الامتداد الآن `?prefix=alias`.                                                                                                                                                                              |
| تم إدراج نموذج image/audio وقد اختفى                     | مقصود منذ 1.0.1 — لا يمكنه أبدًا الرد على طلب الدردشة.                                                                                                                                                                                                           |
| اللوحة مفقودة من شريط الأنشطة                            | يقوم VS Code بنقل حاويات العرض الإضافية إلى ملف** "..."** في الجزء السفلي من شريط الأنشطة، وتظل الحاوية المخفية عبر النقر بزر الماوس الأيمن مخفية. انقر بزر الماوس الأيمن فوق علامة شريط النشاط →**OmniRoute** أو افتحه باستخدام `OmniRoute: Manage Connection`. |
| يتم فتح لوحة المعلومات في المتصفح بالرغم من وضع `editor` | الخادم لم يكن** بنيت** مع `DASHBOARD_ALLOW_EMBED=vscode` (انظر أعلاه) فإن تعيين — عند بدء التشغيل على تثبيت مُعد مسبقًا لا يفعل شيئًا. التراجع متعمد.                                                                                                            |
| قائمة النماذج قديمة بعد تغيير مقدمي الخدمة               | `OmniRoute: Refresh Models` أو رابط ↻ الموجود في اللوحة.                                                                                                                                                                                                         |
| تقول اللوحة _متصل (النماذج محظورة)_، المنتقي فارغ        | يرفض الخادم المفتاح. احفظ المفتاح الصحيح مع** حفظ واختبار** . إذا تم إصلاح المفتاح على الخادم بدلاً من ذلك (ممكّنًا أو مُتاحًا للوصول إلى النماذج)، فلن يلاحظ الامتداد من تلقاء نفسه: قم بتشغيل `OmniRoute: Refresh Models` أو افتح لوحة OmniRoute.              |
