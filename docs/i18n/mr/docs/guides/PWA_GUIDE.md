OmniRoute डॅशबोर्डला प्रोग्रेसिव्ह वेब ॲप म्हणून इंस्टॉल करा ते तुमच्या होम स्क्रीनवरून किंवा डेस्कटॉपवरून स्वतंत्र विंडोमध्ये उघडण्यासाठी. नेव्हिगेशन, डॅशबोर्ड डेटा आणि API विनंत्यांसाठी स्थापित ॲपला अजूनही तुमच्या OmniRoute सर्व्हरशी कनेक्शन आवश्यक आहे. कॅश्ड स्टॅटिक मालमत्ता ऑफलाइन गेटवे किंवा ऑफलाइन डॅशबोर्ड प्रदान करत नाहीत.

## PWA म्हणजे काय?

प्रोग्रेसिव्ह वेब ॲप ॲप चिन्ह आणि स्वतंत्र विंडोसह वेब डॅशबोर्ड वापरते. एकदा स्थापित केल्यानंतर, OmniRoute:

- तुमच्या होम स्क्रीन किंवा डेस्कटॉपवरून लाँच होते
- ब्राउझरच्या नेहमीच्या ॲड्रेस बार आणि टॅबशिवाय स्टँडअलोन मोडमध्ये उघडते
- कॅशे निवडलेल्या स्थिर मालमत्ता
- पोर्ट्रेट आणि लँडस्केप अभिमुखतेचे समर्थन करते

## स्थापना

दुसऱ्या डिव्हाइसवरील सर्व्हरसाठी HTTPS पत्ता वापरा. जेव्हा सर्व्हर त्याच डिव्हाइसवर चालतो, तेव्हा `http://localhost:20128` ब्राउझरच्या स्थापनेची आवश्यकता देखील पूर्ण करते. साधा `http://YOUR_IP:20128` पत्ता त्या आवश्यकता पूर्ण करत नाही. इंस्टॉलेशन मेनू आणि प्रॉम्प्ट ब्राउझर आणि ऑपरेटिंग सिस्टमवर अवलंबून असतात. [MDN च्या PWA प्रतिष्ठापन आवश्यकता](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable#https_localhost_or_loopback_are_required) पहा.

### Android (Chrome)

1. तुमचा OmniRoute HTTPS पत्ता उघडा, किंवा त्याच फोनवरील सर्व्हरसाठी `http://localhost:20128`.
2. उघडा**⋮** मेनू आणि निवडा** ॲप स्थापित करा** किंवा** होम स्क्रीनवर जोडा** , ऑफर केल्यास.
3. प्रॉम्प्टची पुष्टी करा.
4. होम स्क्रीनवरून OmniRoute उघडा.

### iOS (सफारी)

1. सफारीमध्ये तुमचा OmniRoute HTTPS पत्ता उघडा.
2. टॅप करा** शेअर करा** →** होम स्क्रीनवर जोडा** .
3. नावाची पुष्टी करा आणि टॅप करा** ॲड** .
4. होम स्क्रीनवरून OmniRoute उघडा.

### डेस्कटॉप (Chrome / Edge)

1. तुमचा OmniRoute डॅशबोर्ड उघडा.
2. ब्राउझरचे इंस्टॉल आयकॉन किंवा वापरा** ॲप स्थापित करा** मेनू एंट्री, ऑफर केल्यास.
3. OmniRoute त्याच्या स्वतःच्या विंडोमध्ये उघडण्यासाठी प्रॉम्प्टची पुष्टी करा.

## वैशिष्ट्ये

### स्टँडअलोन विंडो

मॅनिफेस्ट `display: "standalone"` आणि `start_url: "/dashboard"` सेट करते. इंस्टॉल केलेले ॲप ॲप विंडोमध्ये डॅशबोर्ड उघडते. ब्राउझर आणि ऑपरेटिंग-सिस्टम नियंत्रणे अद्याप दिसू शकतात; मॅनिफेस्ट पूर्णस्क्रीन मोडची विनंती करत नाही.

### कॅश्ड मालमत्ता आणि नेटवर्क आवश्यकता

[सेवा कर्मचारी](../../public/sw.js) निवडलेल्या समान-मूळ संसाधने कॅश करतो:

| विनंती किंवा मालमत्ता                | रणनीती        | वागणूक                                                                                                                |
| ------------------------------------ | ------------- | --------------------------------------------------------------------------------------------------------------------- |
| इन्स्टॉल-टाइम संसाधने                | प्री-कॅशे     | `/`, `/manifest.webmanifest`, `/icon-512.png` आणि `/apple-touch-icon.png` कामगारांच्या स्थापनेदरम्यान कॅशे केले जातात |
| Next.js स्थिर मालमत्ता (`/_next/`)   | नेटवर्क-प्रथम | यशस्वी प्रतिसाद कॅशे अद्यतनित करतात; नेटवर्क त्रुटी विद्यमान कॅश्ड प्रतिसादावर परत येते                               |
| इतर स्थिर CSS, JS, प्रतिमा आणि फॉन्ट | कॅशे-प्रथम    | विद्यमान कॅश केलेला प्रतिसाद पुन्हा वापरला जातो; यशस्वी नेटवर्क प्रतिसाद चुकल्यावर कॅश केले जातात                     |
| पृष्ठ नेव्हिगेशन                     | बायपास        | ब्राउझर थेट पृष्ठ आणतो; कोणताही ऑफलाइन फॉलबॅक दिला जात नाही                                                           |
| API, डॅशबोर्ड आणि प्रमाणीकरण मार्ग   | बायपास        | कार्यकर्ता या विनंत्या रोखत नाही किंवा कॅशे करत नाही                                                                  |
| इतर नॉन-स्टॅटिक विनंत्या             | नेटवर्क       | कॅशे लुकअप किंवा स्टोरेज नाही                                                                                         |

वगळलेले मार्ग `/api`, `/a2a`, `/dashboard`, `/v1`, `/v1beta`, `/models`, `/chat`, `/responses`, `/codex`, `/callback` आणि `/login`, मार्ग सीमांवर केस-संवेदनशीलपणे जुळलेले आहेत. क्रॉस-ओरिजिन आणि गैर-GET विनंत्या देखील कामगाराला बायपास करतात.

### कनेक्टिव्हिटी पृष्ठ

`/offline` पेज कनेक्टिव्हिटी मेसेज, online/offline इंडिकेटर, ए** कनेक्शनचा पुन्हा प्रयत्न करा** बटण आणि स्थिती पृष्ठाचा दुवा. आहे** प्री-कॅश केलेले नाही** आणि सेवा कर्मचारी करतो** नाही** त्यावर अयशस्वी नेव्हिगेशन पुनर्निर्देशित करा. त्याचे अस्तित्व सर्व्हरशिवाय नवीन पृष्ठे प्रवेशयोग्य बनवत नाही.

### ॲप चिन्ह

मॅनिफेस्ट या PNG चिन्हांची जाहिरात करतो:

| फाईल                   | आकार    | वापरा                                  |
| ---------------------- | ------- | -------------------------------------- |
| `icon-192.png`         | 192×192 | सामान्य ॲप चिन्ह                       |
| `icon-512.png`         | 512×512 | सामान्य आणि मास्क करण्यायोग्य ॲप चिन्ह |
| `apple-touch-icon.png` | 180×180 | ऍपल होम स्क्रीन चिन्ह                  |

ब्राउझर इंस्टॉलेशन लक्ष्यासाठी योग्य चिन्ह निवडतो.

### स्वयंचलित नोंदणी

जेव्हा ब्राउझर सेवा कर्मचाऱ्यांना समर्थन देतो तेव्हा`PwaRegister` कामगाराची उत्पादनामध्ये नोंदणी करते. डेव्हलपमेंट मोड कामगारांची नोंदणी रद्द करतो आणि जुन्या मालमत्तेचा हॉट रीलोडमध्ये हस्तक्षेप टाळण्यासाठी कॅशे साफ करतो. प्रॉम्प्ट स्थापित करणे हा ब्राउझरचा निर्णय आहे.

## तांत्रिक आर्किटेक्चर

### वेब ॲप मॅनिफेस्ट

Next.js [`src/app/manifest.ts`](../../src/app/manifest.ts) वरून `/manifest.webmanifest` व्युत्पन्न करते. त्याची मुख्य सेटिंग्ज आहेत:

| सेटिंग                  | मूल्य                                      |
| ----------------------- | ------------------------------------------ |
| `short_name`            | `OmniRoute`                                |
| `start_url`             | `/dashboard`                               |
| `scope`                 | `/`                                        |
| `display`               | `standalone`                               |
| `orientation`           | `any`                                      |
| पार्श्वभूमी आणि थीम रंग | `PWA_THEME_COLORS` मधील डीफॉल्ट लाइट पॅलेट |

मॅनिफेस्टचे नाव आणि वर्णन ही त्या स्त्रोत फाइलमधील स्थिर मूल्ये आहेत. इन्स्टॉल केलेले मॅनिफेस्ट प्रत्येक भेटीतील उदाहरण-नाव सेटिंग किंवा सक्रिय पॅलेटचे अनुसरण करत नाही.

### सेवा कार्यकर्ता

[`public/sw.js`](../../public/sw.js) मध्ये सेवा-कार्यकर्ता फ्रेमवर्क अवलंबित्व नाही:

- **स्थापित करा:** वर सूचीबद्ध केलेल्या चार संसाधनांना पूर्व-कॅश करते आणि नवीन कार्यकर्ता सक्रिय करते.
- **सक्रिय करा:** जुन्या कॅशे पिढ्या काढून टाकते आणि क्लायंटचा दावा करते.
- **आणणे:** वरील स्थिर-मालमत्ता धोरणे आणि मार्ग बहिष्कार लागू करते.
- **आवृत्ती:** स्त्रोत कॅशेचे नाव `omniroute-pwa-v3` आहे; उत्पादन बिल्ड कॅशे ओळख स्टॅम्प.
- **सूचना:** इनकमिंग `push` इव्हेंट्स हाताळते आणि नोटिफिकेशन क्लिक केल्यावर फोकस करते किंवा विंडो उघडते.

केवळ पुश इव्हेंट हँडलर्स सक्रिय पुश सबस्क्रिप्शन किंवा कॉन्फिगर केलेले सर्व्हर वितरण स्थापित करत नाहीत. केवळ PWA स्थापित केल्यामुळे सूचना सक्षम केल्या आहेत असे समजू नका.

### लेआउट मेटाडेटा आणि नोंदणी

[`src/app/layout.tsx`](../../src/app/layout.tsx) मॅनिफेस्ट लिंक, Apple स्टँडअलोन मेटाडेटा, थीम रंग आणि `viewport-fit: cover` प्रदान करते. पृष्ठ शीर्षक आणि Apple वेब-ॲप शीर्षक उदाहरणाचे नाव वापरतात. थेट ब्राउझर थीम रंग पॅलेटचे अनुसरण करते; इंस्टॉल मॅनिफेस्ट डीफॉल्ट हलका रंग वापरतो.

[`PwaRegister`](../../src/shared/components/PwaRegister.tsx) क्लायंटवर चालते आणि `/sw.js` त्याच्या URL मध्ये बिल्ड ID सह नोंदणी करते. हे न जुळलेल्या कॅशे पिढ्या शोधते आणि वर्कर रीसेट करू शकते आणि जुन्या इंस्टॉलेशनमधून पुनर्प्राप्त करण्यासाठी एकदा रीलोड करू शकते. नोंदणी अयशस्वी झाल्यामुळे डॅशबोर्ड ब्लॉक होत नाही.

## Termux (Android) सह वापरा

1. टर्मक्समध्ये OmniRoute सुरू करा: `npx -y omniroute@latest`.
2. त्याच फोनवर Chrome उघडा: `http://localhost:20128`.
3. ब्राउझरच्या इंस्टॉलेशन मेनूद्वारे PWA स्थापित करा.
4. डॅशबोर्ड वापरत असताना टर्मक्स सर्व्हर चालू ठेवा.

फोन गेटवे आणि त्याचा डॅशबोर्ड दोन्ही होस्ट करतो. रिमोट AI प्रदात्यांना विनंत्यांसाठी अद्याप नेटवर्क प्रवेश आवश्यक आहे. सेटअप आणि Android प्रक्रिया-आजीवन विचारांसाठी [Termux मार्गदर्शक](TERMUX_GUIDE.md) पहा.

## इतर उपकरणांमधून वापरा

फोन, टॅबलेट किंवा डेस्कटॉपवर सर्व्हरचा HTTPS पत्ता उघडा, नंतर त्या ब्राउझरच्या इंस्टॉलेशन प्रवाहाचे अनुसरण करा. प्रत्येक डिव्हाइसवरून सर्व्हर पोहोचण्यायोग्य असणे आवश्यक आहे. दूरस्थ प्रवेश पर्यायांसाठी [बोगदा मार्गदर्शक](../ops/TUNNELS_GUIDE.md) पहा.

## सानुकूलन

### उदाहरणाचे नाव

द** उदाहरणाचे नाव** सेटिंग पृष्ठ शीर्षक आणि Apple वेब-ॲप शीर्षकासह डॅशबोर्ड मेटाडेटा बदलते. व्युत्पन्न केलेला मॅनिफेस्ट एक स्थिर नाव वापरतो, त्यामुळे ही सेटिंग आधीपासून स्थापित केलेल्या ॲपचे नाव बदलण्याची हमी देत नाही.

### सानुकूल फेविकॉन

सानुकूल फेविकॉन ब्राउझर फेविकॉन बदलतो. इन्स्टॉल मॅनिफेस्ट अजूनही वरील PNG फाइल्सची जाहिरात करते; फेविकॉन बदलल्याने ते होम-स्क्रीन आयकॉन बदलत नाहीत.

## मर्यादा

- **सर्व्हर कनेक्शन आवश्यक आहे:** पृष्ठ नेव्हिगेशन, डॅशबोर्ड स्थिती आणि API विनंत्यांना ऑफलाइन फॉलबॅक नाही.
- **पार्श्वभूमी समक्रमण नाही:** ऑफलाइन क्रिया रीप्लेसाठी रांगेत नाहीत.
- **ब्राउझर फरक:** प्रतिष्ठापन मेनू, विंडो सादरीकरण आणि सूचना समर्थन प्लॅटफॉर्मनुसार बदलतात.
- **कोणतेही API प्रतिसाद कॅशे नाही:** कार्यकर्ता API, डॅशबोर्ड आणि प्रमाणीकरण मार्ग वगळतो.
- **स्थिर प्रतिष्ठापन चिन्ह:** ती चिन्हे अद्यतनित करण्यासाठी जाहिरात केलेली मालमत्ता बदलणे आवश्यक आहे; ब्राउझर स्थापित मेटाडेटा राखून ठेवू शकतात.
