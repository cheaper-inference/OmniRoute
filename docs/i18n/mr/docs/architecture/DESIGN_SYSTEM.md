> **स्थिती:** हे डॅशबोर्ड **Keak CI UI Kit** (`@keak/cheaper-inference-ui-kit`) वर बांधले गेले आहे, जे
> वर्कस्पेस `packages/ui-kit` (`@omniroute/ui-kit`; अपस्ट्रीम स्नॅपशॉट
> `packages/ui-kit/UPSTREAM.md` मध्ये पिन केलेला आहे आणि `npm run check:ui-kit-snapshot` द्वारे संरक्षित आहे) म्हणून व्हेंडर केलेले आहे. Light ही कॅनॉनिकल
> थीम आहे; डीफॉल्ट प्राधान्य `system` आहे. अॅक्सेंट Keak lime (`--ci-color-accent`) आहे. Inter
> (letter-spacing 0, `--ci-letter-spacing-ui`) हे UI फॅमिली आहे, Instrument Serif फक्त मोठ्या विरळ
> डिस्प्ले मजकुरासाठी (`.ci-dashboard-display`), कोडसाठी IBM Plex Mono — हे सर्व
> `src/app/globals.css` च्या सुरुवातीला असलेल्या `@fontsource/*` इम्पोर्ट्सद्वारे सेल्फ-होस्ट केलेले आहे. प्रत्येक आयकॉन हा Lucide ग्लिफ आहे.

## 1. गोष्टी कुठे आहेत

- **किट.** `packages/ui-kit/src` ही `packages/ui-kit/UPSTREAM.md` मध्ये पिन केलेल्या कमिटवरील अपस्ट्रीम
  `src/` ची बाइट-दर-बाइट नक्कल आहे (जी परवाना मंजुरीही नोंदवते); `PATCHES.md` स्थानिक पॅचेसची यादी करते
  (कोणतेही नाही). ते स्रोत म्हणून, बिल्डशिवाय, वापरले जाते: `next.config.mjs` ते ट्रान्सपाइल करते आणि
  `tsconfig.json` `@omniroute/ui-kit` → `packages/ui-kit/src` आणि `@omniroute/ui-kit/*` →
  `packages/ui-kit/src/*` मॅप करते (`vitest.config.ts` आणि `vitest.mcp.config.ts` मध्येही तोच उपनाम आहे).
  किट घटक त्याच्या सबपाथने (`@omniroute/ui-kit/table`, `@omniroute/ui-kit/page-header`…) इम्पोर्ट करा,
  `@omniroute/ui-kit` बॅरलमधून कधीही नाही: बॅरल प्रत्येक घटकाला (दिनांक निवडकासह) प्रत्येक इम्पोर्टरमध्ये
  खेचते. किट स्टाइलशीट `src/app/globals.css` मधून येते
  (`@import "../../packages/ui-kit/src/ci-ui.css"`).
- **टोकन्स.** `packages/ui-kit/src/ci-tokens.css` `--ci-*` टोकन्स घोषित करते; `src/app/globals.css`
  त्यांना लेगसी OmniRoute नावांशी (`--color-*`, `--radius-*`, `--font-sans`/`--font-mono`, `--table-*`,
  `--orch-status-*`, `--color-fd-*`) जोडते, त्यामुळे विद्यमान `var(--color-*)` वाचने आणि Tailwind
  उपयुक्तता कार्यरत राहतात. नवीन कोड Tailwind उपयुक्तता (`bg-surface`, `text-text-muted`, `border-border`,
  `text-success`, `bg-success-bg`, `bg-chart-1`…) किंवा किट क्लासेस वापरतो — कधीही हेक्स मूल्य नाही
  (`tests/unit/design-kit-bridge.test.ts` हा ब्रिज लागू करते). `text-primary` `--text-color-primary` मार्गे
  `--color-primary-ink` वर रिझॉल्व्ह होते (लाइटमध्ये lime-800, डार्कमध्ये लाइम अॅक्सेंट), त्यामुळे
  `bg-primary`/`border-primary` लाइम पृष्ठभाग कायम ठेवत असताना प्राथमिक मजकूर वाचनीय राहतो. चार्ट मालिका
  `--color-chart-1` … `--color-chart-5` वापरतात.
- **थीम्स.** `<html className="ci-theme">` (`src/app/layout.tsx`) दस्तऐवजाला किट थीममध्ये सामील करते.
  प्राधान्य `light`, `dark` किंवा `system` आहे (`src/shared/constants/appConfig.ts` मध्ये
  `THEME_CONFIG.defaultTheme = "system"`; `system` `prefers-color-scheme` चे अनुसरण करते).
  `src/store/themeStore.ts` मधील `applyTheme()` (ज्याची प्रत `src/app/layout.tsx` मधील इनलाइन बूटस्ट्रॅप
  स्क्रिप्टमध्ये आहे, जी हायड्रेशनपूर्वी चालते) `data-theme="dark"|"light"` सेट करते आणि `<html>` वरील
  `.dark` क्लास एकत्र टॉगल करते. किटचा डार्क टोकन संच `data-theme="dark"` वर आधारित आहे
  (`packages/ui-kit/src/ci-tokens.css`); OmniRoute चे स्वतःचे डार्क ओव्हरराइड्स (`globals.css` मधील `.dark`
  ब्लॉक) आणि लेगसी Tailwind `dark:` उपयुक्तता `.dark` क्लासवर आधारित आहेत. अॅक्सेंट रंगांचे कोणतेही
  प्रीसेट नाहीत: अॅक्सेंट नेहमी किटमधूनच येते आणि जुन्या बिल्डमधून टिकवलेला प्रीसेट स्टोअर लोड झाल्यावर
  काढून टाकला जातो.
- **घटक (अडॅप्टर).** `src/shared/components/index.tsx` OmniRoute घटक API कायम ठेवते (समान नावे, डीफॉल्ट
  एक्सपोर्ट्स आणि प्रॉप्स) आणि त्यामागील प्रिमिटिव्ह्ज किटवरील अडॅप्टर आहेत: फॉर्म (`Button`, `Input`,
  `Textarea`, `Checkbox`, `Select`, `Toggle`, `Badge`, `Card`), ओव्हरले आणि फीडबॅक (`Modal`/`ConfirmModal`,
  `Tooltip`/`InfoTooltip`, `NotificationToast`, `EmptyState`, `Loading`), रचना (`Collapsible`,
  `CollapsibleSection`, `SegmentedControl`, `Breadcrumbs`, `Avatar`) आणि टेबल्स (`DataTable`, `FilterBar`,
  `ColumnToggle`, `FilterPills`, `PresetSlider`). अडॅप्टर किट घटक सबपाथने इम्पोर्ट करतो आणि लेगसी प्रॉप्स
  त्यावर मॅप करतो — उदाहरणार्थ `Button variant="primary"` म्हणजे किटचे `default` बटण
  (`--ci-button-primary-*`: लाइटमध्ये उलट पृष्ठभाग, डार्कमध्ये त्याच्या `--ci-color-accent-foreground`
  शाईसह अॅक्सेंट), `danger` म्हणजे `destructive` आणि `warning` म्हणजे `outline` अधिक
  `.ci-button--warning` विस्तार. `globals.css` च्या शेवटी असलेले `.ci-button--warning` आणि
  `.ci-badge[data-tone]` नियम (`@layer components`) हे किट क्लासेसवरील OmniRoute विस्तार आहेत.
  `tests/unit/ui/adapters/*.test.tsx` प्रत्येक अडॅप्टर पिन करतात.
- **शेल.** `src/app/(dashboard)/layout.tsx` `DashboardLayout` रेंडर करते, जे
  `src/shared/components/layouts/DashboardShell.tsx` रेंडर करते: किट `SidebarProvider` / `Sidebar` /
  `SidebarInset` (`packages/ui-kit/src/sidebar.tsx`), ज्यात OmniRoute चे नेव्हिगेशन लॉजिक
  `src/shared/components/Sidebar.tsx` मध्ये आहे. `#main-content` वर जाणारी "मजकुराकडे जा" लिंक हा पहिला
  फोकसयोग्य घटक आहे. `src/shared/components/Header.tsx` मध्ये किट `SidebarTrigger` (शेलचा एकमेव साइडबार
  टॉगल), Keak `ProductSwitcher` आणि कमांड-पॅलेट ओपनर आहे; `#main-content` मध्ये कोणताही किट `PageHeader`
  (`.ci-page-header`) माउंट नसतानाच तो रूट शीर्षक दाखवतो, त्यामुळे स्वतःच्या `PageHeader` असलेल्या
  पृष्ठाला एकच `h1` असतो. `src/shared/components/CommandPalette.tsx` हा किट `Dialog` आहे.
- **आयकॉन्स.** `<Icon name="material_name">` (`src/shared/components/Icon.tsx`) नाव (स्क्रीन वापरत
  असलेली Material Symbols शब्दसूची) `ICON_MAP` (`src/shared/constants/iconMap.ts`) मार्गे Lucide ग्लिफवर
  रिझॉल्व्ह करते. Material Symbols फॉन्ट आणि पॅकेज आता नाहीत: नकाशात नसलेले नाव तटस्थ प्लेसहोल्डर ग्लिफ

  Lucide आयकॉन नसलेल्या कोणत्याही नावावर अयशस्वी होते; `tests/unit/icon-map-object-values.test.ts` लुकअप
  ऑब्जेक्ट्समध्ये साठवलेली नावे कव्हर करते);
  `scripts/dev/codemod-material-icons.mjs <dir|file>... [--write]` लिटरल
  `<span className="material-symbols-outlined">` स्पॅन्सचे `<Icon>` मध्ये पुनर्लेखन करते.
- **ब्रँड.** `src/shared/components/OmniRouteLogo.tsx` किटला रॅप करते: डीफॉल्ट एक्सपोर्ट `OmniRouteLogo`

  लॉकअप दाखवतात; `tests/unit/brand-pages-static.test.ts` त्याचे रक्षण करते.

## 2. नियम

1. टोकन वापरा, कधीही लिटरल नाही. जाणीवपूर्वक ठेवलेले अपवाद: नेहमी-गडद कन्सोल टर्मिनल, `STATUS_HEX` (`src/shared/constants/statusColors.ts`) द्वारे ReactFlow SVG स्ट्रोक्स, आणि वर्गवारीनुसारच्या पॅलेट्स `STRATEGY_COLORS` (`src/app/(dashboard)/dashboard/combos/live/nodes/StrategyNode.tsx`) व `LAYER_COLORS` (`src/app/(dashboard)/dashboard/compression/studio/nodes/EngineNode.tsx`).
2. `packages/ui-kit/src` मध्ये हाताने कधीही पॅच करू नका: `scripts/dev/sync-ui-kit.sh <commit>` ने समक्रमित करा; पिन केलेल्या अपस्ट्रीम कमिटपेक्षा वेगळा असलेला कोणताही बाइट आढळल्यास प्री-कमिट गेट `npm run check:ui-kit-snapshot` (`.husky/pre-commit`) अयशस्वी होते (अपस्ट्रीम क्लोन, `UI_KIT_CLONE` किंवा `_references/cheaper-inference-ui-kit`, अनुपस्थित असल्यास ते इशाऱ्यासह वगळते). किटमध्ये काही कमी असल्यास, अडॅप्टर किंवा स्क्रीनमध्ये त्यावर मात करून काम करा आणि अपस्ट्रीमकडे त्याची मागणी करा.
3. किटचे मजकूर डीफॉल्ट इंग्रजी आहेत (`label = "Loading"`, `loadingLabel = "Loading table"`…) — किट घटक जेव्हा जेव्हा मजकूर रेंडर करतो तेव्हा तेव्हा `useTranslations(...)` मधून अनुवादित स्ट्रिंग्ज पास करा.
4. Tailwind युटिलिटीज किट घटक क्लासेसपेक्षा जिंकतात (किट `@layer theme, base, components, utilities` घोषित करते आणि तिचे नियम `components` मध्ये राहतात) — अंतर आणि लेआउटसाठी युटिलिटीज वापरा, किट घटकांना पुन्हा रंग देण्यासाठी नाही.
5. शीर्षके: पृष्ठ व विभाग शीर्षकांसाठी `.ci-heading` (Inter, ट्रॅकिंग नाही); `.ci-dashboard-display` (Instrument Serif) फक्त मोठ्या, विरळ डिस्प्ले मजकुरासाठी, जसे की त्रुटी-पृष्ठावरील स्थिती कोड.
6. `tests/unit/dashboard-kit-sweep.test.ts` किटच्या अवलंबाचे रक्षण करते: `src/app` किंवा `src/shared/components` खाली Material ligature स्पॅन नाही; डॅशबोर्ड ट्रीमध्ये (`src/app/(dashboard)` आणि `src/shared/components`) सूचीबद्ध अपवादांच्या (`Select` अडॅप्टरची नेटिव्ह शाखा, `RequestLoggerDetail`) बाहेर कच्चे `<select>`, `<textarea>` किंवा `<table>` नाही आणि हाताने बनवलेला `role="dialog"` नाही; तिथे प्रत्येक कच्च्या `<button>` किंवा `<input>` ला `kit-exception:` असलेली (कारणासह) टिप्पणी त्याच्या जास्तीत जास्त 3 ओळींवर संपणारी आवश्यक आहे; पॅलेट ह्यूज आणि `dark:` व्हेरिएंट्स फक्त चाचणी ज्या फाइल्स सूचीबद्ध करते त्यांच्यातच.
7. PR पूर्वी दोन्ही थीम आणि 390 px व्ह्यूपोर्ट सत्यापित करा (स्क्रीनशॉट); `tests/e2e/a11y.spec.ts` axe चालवते.

## 3. स्क्रीन जोडणे

1. किट `PageHeader` (`@omniroute/ui-kit/page-header`, डॅशबोर्डमध्ये `compact`) ने पृष्ठ उघडा — शीर्षक, वर्णन आणि `actions`. शेल हेडर नंतर स्वतःचे शीर्षक काढून टाकते.
2. `@/shared/components` (अडॅप्टर्स) मधून कंट्रोल्स तयार करा आणि जिथे अडॅप्टर नाही तिथे सबपाथनुसार किट घटक वापरा (`Table`/`TableScrollArea`/`DataTableShell`, `Field`, `Alert`, `Tabs`, `RadioGroup`, `Slider`…).
3. चिन्हे: `<Icon name="…" />`. नवीन नाव अर्थाने जुळणाऱ्या Lucide घटकासह `ICON_MAP` मध्ये जाते; `npm run gen:icon-map` अजूनही हरवलेली नावे सूचीबद्ध करते.
4. रंग: अर्थपूर्ण युटिलिटीज (`text-success`, `bg-warning-bg`, `border-border`…) आणि चार्ट मालिकांसाठी `var(--color-chart-N)`; हेक्स मूल्ये नाहीत आणि फक्त रंगाची पुनरावृत्ती करणारे `dark:` व्हेरिएंट्सही नाहीत.
5. मजकूर: किट घटकांना तुम्ही पास करत असलेल्या लेबलांसह प्रत्येक स्ट्रिंग `useTranslations` मधून येते. नवीन की `src/i18n/messages/en.json`, `pt-BR.json` आणि `vi.json` मध्ये जातात (व्हिएतनामी समानता चाचणी प्रत्येक इंग्रजी की पिन करते); इतर लोकेल्स i18n समक्रमणाने भरले जातात.
6. PR पूर्वी गार्ड्स चालवा: `tests/unit/dashboard-kit-sweep.test.ts`, `tests/unit/icon-map-coverage.test.ts`, `tests/unit/icon-map-object-values.test.ts`, `npm run check:dashboard-typecheck` (`iconMap.ts` मधील डुप्लिकेट इम्पोर्ट पकडणारी एकमेव तपासणी), `npm run check:ui-icu`, आणि स्क्रीनच्या स्वतःच्या चाचण्या.

## 4. ॲडॉप्टर जोडणे किंवा बदलणे

1. `src/shared/components/index.tsx` चे सार्वजनिक API टिकवा: समान एक्स्पोर्ट नावे, डीफॉल्ट एक्स्पोर्ट्स आणि
   स्वीकारलेले props. ॲडॉप्टरमध्ये लेगसी props किटवर मॅप करा (पहा `Button.tsx`: `VARIANT_TO_KIT`,
   `SIZE_TO_KIT`).
2. सबपाथद्वारे किट इम्पोर्ट करा (`@omniroute/ui-kit/<component>`).
3. किटमधील अंतरांसाठी वर्कअराउन्ड ॲडॉप्टरमध्ये राहतात (किंवा फिक्स स्टाइल असेल तेव्हा `globals.css`
   `@layer components` मध्ये), कधीही `packages/ui-kit/src` मध्ये नाही.
4. `tests/unit/ui/adapters/<name>.test.tsx` जोडा किंवा अपडेट करा. अनेक कॉलर्स असलेल्या ॲडॉप्टरसाठी, बदलापूर्वी
   आणि नंतरचे रेंडर केलेले मार्कअप तुलना करा — पॅडिंग किंवा रॅपर बदल प्रत्येक स्क्रीनवर पसरतात.

## 5. किट अपडेट करणे

`scripts/dev/sync-ui-kit.sh <commit> [clone]` त्या कमिटवरील अपस्ट्रीम `src/` ला `packages/ui-kit/src`
मध्ये कॉपी करते आणि एकल अनुमत रूपांतर लागू करते (हे रिलेटिव्ह इम्पोर्ट्समधून `.js` प्रत्यय काढून
टाकते). नंतर: `git diff packages/ui-kit` चे पुनरावलोकन करा, दोन्ही थीम्समध्ये प्रोव्हायडर्स, सेटिंग्ज, कॉम्बोज,
वापर आणि एन्डपॉइंटची व्हिज्युअल तपासणी करा, `npm run check:ui-kit-snapshot` आणि `npm run test:vitest:ui`
चालवा, आणि अपस्ट्रीम चेंजलॉगसह PR उघडा.
