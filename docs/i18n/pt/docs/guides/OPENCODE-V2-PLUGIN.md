`@omniroute/opencode-plugin-v2` disponibiliza todo o seu catálogo OmniRoute — modelos, combos e
auto-combos — no seletor de modelos do OpenCode v2, com nomes de apresentação, preços e limites
do nível gratuito.

É um pacote separado de `@omniroute/opencode-plugin`, porque o OpenCode v1 e o v2 carregam
plugins através de contratos diferentes. Escolha o que corresponde à versão principal do seu
OpenCode; nada é partilhado entre ambos, pelo que atualizar um nunca obriga a atualizar o outro.

## Requisitos

- OpenCode v2.
- Um gateway OmniRoute acessível (`http://localhost:20128` por predefinição).
- Node.js 22 ou 24.

## Instalação

Adicione o plugin a `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

Os modelos aparecem então como `omniroute/<provider>/<model>`; `providerId` determina esse prefixo e
o id da integração sob o qual o OpenCode armazena a credencial.

## Credenciais

O plugin procura uma chave do gateway em três locais, por esta ordem:

1. **A credencial que associou no OpenCode.** O plugin regista uma integração, pelo que
   o próprio fluxo de autenticação do OpenCode pode armazenar a chave. Nada é guardado em `opencode.json` — prefira esta opção.
2. `apiKey` nas opções do plugin, para uma substituição específica do projeto. Isto coloca a chave num ficheiro que
   poderá estar a incluir no repositório.
3. `OMNIROUTE_API_KEY` no ambiente.

Sem nenhuma das três, o catálogo fica vazio e o plugin informa-o uma vez no arranque, em vez de
deixar silenciosamente um seletor vazio.

### O token de gestão é uma chave diferente

Os combos, o estado dos fornecedores e o enriquecimento (nomes de apresentação, preços e limites do nível gratuito) provêm dos
endpoints `/api/*` do gateway, que a maioria das implementações protege com um token de **gestão**
em vez da chave de inferência:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<token de leitura de gestão>"
}
```

Se `managementReadToken` não estiver definido, é usado `apiKey` como alternativa. Quando um gateway rejeita essa alternativa,
o catálogo continua a ser publicado, mas com ids de modelos em bruto em vez de nomes de apresentação, sem
eliminação de duplicados por alias canónico, sem preços e sem combos. O plugin apresenta um aviso uma vez por endpoint quando isso acontece,
indicando o endpoint e o que foi perdido — para que um seletor degradado nunca seja um mistério.

## Opções

| Chave                            | Predefinição                                 | Notas                                                                                                                                                                                                                                                                                                                                                                                      |
| -------------------------------- | -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `providerId`                     | `"omniroute"`                                | O ID do fornecedor, o ID de integração e os modelos de prefixo aparecem em                                                                                                                                                                                                                                                                                                                 |
| `baseURL`                        | obrigatório                                  | Raiz do gateway, apenas `http(s)` ; o sufixo `/v1` é adicionado quando necessário                                                                                                                                                                                                                                                                                                          |
| `apiKey`                         | credencial ligada, então `OMNIROUTE_API_KEY` | Chave de chat para `/v1/*`                                                                                                                                                                                                                                                                                                                                                                 |
| `managementReadToken`            | voltar para `apiKey`                         | Chave para `/api/*` — normalmente** não** o mesmo                                                                                                                                                                                                                                                                                                                                          |
| `displayName`                    | `"OmniRoute"`                                | Nome do fornecedor no seletor                                                                                                                                                                                                                                                                                                                                                              |
| `timeoutMs`                      | `10000`                                      | Tempo limite de pesquisa por endpoint (os combos automáticos usam 5s)                                                                                                                                                                                                                                                                                                                      |
| `modelCacheTtlMs`                | `300000`                                     | Cache de catálogo TTL; um instantâneo de disco aquece arranques a frio                                                                                                                                                                                                                                                                                                                     |
| `timeouts`                       | voltar para `timeoutMs`                      | Orçamentos por endpoint em ms: `models`, `combos`, `autoCombos`, `enrichment`                                                                                                                                                                                                                                                                                                              |
| `enrichment`                     | `true`                                       | Pesquise nomes, preços e orçamentos de nível gratuito                                                                                                                                                                                                                                                                                                                                      |
| `providerTag`                    | `true`                                       | Alterne o parêntesis do editor final: `Provider - Model (Editor)`. O fornecedor (percurso que serve o modelo) é sempre mostrado; o editor (que fez o modelo) aparece apenas entre parêntesis. Exemplo: `Openrouter - MoonshotAI: Kimi K 3.1 Pro` -> `Openrouter - Kimi K 3.1 Pro (MoonshotAI)`. Omitido quando o editor e o fornecedor partilham um nome. Defina `false` para o descartar. |
| `usableOnly`                     | `false`                                      | Mantenha apenas os fornecedores dos relatórios de gateway conforme provisionados                                                                                                                                                                                                                                                                                                           |
| `combosSource`                   | `"api"`                                      | `"models"` ignora `/api/combos` e publica as linhas combinadas `/v1/models` ; os filtros ao nível do membro mantêm `"api"`                                                                                                                                                                                                                                                                 |
| `showcasePerOwner`               | `10`                                         | Entradas de visualização padrão mantidas por fornecedor                                                                                                                                                                                                                                                                                                                                    |
| `freshPerOwner`                  | `10`                                         | Visualização padrão de novas entradas mantidas por fornecedor                                                                                                                                                                                                                                                                                                                              |
| `freshWindowDays`                | `90`                                         | Janela de frescura em dias para o galho fresco                                                                                                                                                                                                                                                                                                                                             |
| `usageMemory`                    | `true`                                       | Restaurar entradas descartadas estaticamente nomeadas pela análise de utilização de 30 dias (necessita de um token de gestão)                                                                                                                                                                                                                                                              |
| `visibleModels` / `hiddenModels` | `[]`                                         | Listas de permissões exatas ou com sufixo; negar vitórias; `*` publica o catálogo completo (outros filtros ainda se aplicam)                                                                                                                                                                                                                                                               |
| `geminiSanitization`             | `true`                                       | Retire as palavras-chave JSON-Schema Gemini rejeita dos esquemas de ferramentas (as ferramentas `$ref` são encaminhadas intactas)                                                                                                                                                                                                                                                          |
| `apiFormat.allowAnthropic`       | `false`                                      | Encaminhar IDs permitidos através do bloco Anthropic API                                                                                                                                                                                                                                                                                                                                   |
| `apiFormat.anthropicModels`      | `[]`                                         | IDs completos do modelo encaminhados para Anthropic                                                                                                                                                                                                                                                                                                                                        |
| `logLevel` / `startupDebug`      | `warn` / `false`                             | Detalhamento do registador                                                                                                                                                                                                                                                                                                                                                                 |

O uso da memória está ativado por defeito. Sem um token de gestão permanece inerte (é registado um aviso de arranque) e nada é restaurado.

## Como o catálogo se mantém atualizado

O catálogo é pesquisado lentamente e armazenado em cache para `modelCacheTtlMs`, e um instantâneo de disco mantém o último catálogo conhecido disponível quando o gateway está inacessível — uma interrupção não custa nada além de atualização. Os modelos e os combos são publicados assim que chegam; os combos automáticos, a lista de fornecedores e a sobreposição de enriquecimento duplicam quando chegam, pelo que um endpoint lento não pode manter todo o selecionador como refém.

Os nomes seguem `Provider - Model[ (Editor)][ · budget][ (route)]`: o fornecedor é mostrado sempre que o id carrega um (um id sem barra é renderizado sem um prefixo), um `🆓` inicial marca entradas gratuitas e o seu orçamento de nível gratuito permanece como um sufixo `· 1M tokens/month`, o editor de um nome `Editor: Model` explícito move-se para um parêntese final (nenhum editor é adivinhado a partir de outros nomes) e os combos são renderizados como `combo - <slug>` sem um ícone livre. Duas entradas que partilham um nome recebem um sufixo de rota — `(no-think)` — para que permaneçam distinguíveis. `providerTag` (padrão `true`) alterna os parênteses finais do editor.

Não existe comando de atualização manual: os comandos OpenCode v2 são modelos de prompt, não são callbacks, pelo que um plug-in não pode expor um. As atualizações seguem o TTL; o host é solicitado a recarregar apenas quando o catálogo ou a sobreposição são realmente alterados, nunca uma vez por atualização.

## Chamadas de ferramentas no Gemini

O Gemini rejeita qualquer pedido cujas declarações de ferramentas incluam `$schema` ou
`additionalProperties`, respondendo com `400 INVALID_ARGUMENT`. O plugin remove essas palavras-chave dos
esquemas de ferramentas destinados a um modelo Gemini deste fornecedor e deixa todos os outros pedidos inalterados.
Uma ferramenta que inclua um `$ref` é reencaminhada sem alterações em vez de ser modificada, uma vez que remover a
referência alargaria o esquema para «aceitar qualquer coisa».
Defina `"geminiSanitization": false` para desativar esta funcionalidade.

## Solução de problemas

| Sintoma                                           | Causa                                                                                                                          |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| O selecionador não mostra nenhum modelo OmniRoute | Nenhuma chave foi resolvida (verificar o aviso de arranque) ou o gateway está inacessível                                      |
| IDs de modelo em bruto, sem combos, sem preços    | Os endpoints de gestão recusaram o token — set `managementReadToken`                                                           |
| Catálogo `freeOnly` curto ou vazio                | Nenhum token de gestão ou um token recusado — leu a linha de resumo de atualização (`unmatched-free` count) no registo do host |
| Uma sessão fixada em `opencode-<id>/...`          | O plugin v1 publicou `opencode-<id>`; v2 publica `<id>` bare, depois selecciona novamente o modelo em `<id>/...`               |

As variáveis de ambiente devem atingir o processo do servidor opencode: quando o host é executado como um serviço, o shell que executa `opencode models` e o ambiente do servidor são diferentes, então exporte a chave onde o servidor a lê.
