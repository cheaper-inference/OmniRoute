## Vrati konfiguraciju klijenta

Program za deinstalaciju zaustavlja OmniRoute proces kojim upravlja PM2, ako postoji, i ostavlja konfiguraciju klijenta na mjestu. Klijenti koji i dalje upućuju na OmniRoute gube vezu nakon što ona prestane. Potpuno uklanjanje također briše direktorij podataka, `~/.omniroute` prema zadanim postavkama, zajedno sa sigurnosnim kopijama konfiguracije klijenta.

### 1. Koristite nadzornu ploču dok OmniRoute radi

Otvoriti**CLI kod** (`/dashboard/cli-code`) na nadzornoj ploči i pronađite**Claude kod** kartica.** primijeniti** piše u datoteku postavki Claude koda OmniRoute hosta, `~/.claude/settings.json` prema zadanim postavkama. Ako imate sigurnosnu kopiju od prije primjene OmniRoute postavki, otvorite** Sigurnosne kopije** i obnoviti ga. U suprotnom odaberite** Resetiraj** za uklanjanje postavki pristupnika iz `env`. Primijeni i ponovno postavi sigurnosnu kopiju postojeće datoteke. Sigurnosne kopije pohranjuju se pod `<DATA_DIR>/backups`.

Ako `CLI_ALLOW_CONFIG_WRITES=false` ili nadzorna ploča nisu dostupni, vratite datoteku ručno. Ako se OmniRoute izvodi u Docker, a klijent radi na glavnom računalu, vratite konfiguraciju glavnog računala. Datoteke u nemontiranom početnom spremniku nemaju utjecaja na glavnog klijenta.

### 2. Ručno vratite preostale promjene

Za Claude kod provjerite `~/.claude/settings.json`, `settings.json` u `CLAUDE_CONFIG_DIR` ako je postavljen i `.claude/settings.json` projekta. Resetiranje uklanja sljedeće ključeve iz `env`. Uklonite vrijednosti koje ste dodali za OmniRoute ili vratite svoje prethodne vrijednosti.

- `"ANTHROPIC_BASE_URL"`, `"ANTHROPIC_AUTH_TOKEN"` i `"ANTHROPIC_API_KEY"`
- `"ANTHROPIC_DEFAULT_OPUS_MODEL"`, `"ANTHROPIC_DEFAULT_SONNET_MODEL"` i `"ANTHROPIC_DEFAULT_HAIKU_MODEL"`
- `"API_TIMEOUT_MS"`

Reset ostavlja `ANTHROPIC_MODEL` u `env` i postavke `model` i `apiKeyHelper` najviše razine na mjestu. Uklonite ih ili vratite ručno ako odaberu OmniRoute model ili vjerodajnicu. Prestanite koristiti bilo koji OmniRoute profil koji je stvorio `omniroute setup-claude` pod `~/.claude/profiles/<name>/` ili vratite njegov `settings.json`. Naredba za postavljanje piše profil bez mijenjanja zadane datoteke postavki ili spremanja tokena. Uklonite ili vratite odgovarajuće izvoze u datoteke za pokretanje ljuske i izbrišite stare vrijednosti iz trenutne ljuske. `omniroute launch` i `omniroute run claude` postavljaju gateway URL i token samo za proces dijete.

Za Codex, vratite prethodnog pružatelja i model u `~/.codex/config.toml` ako sadrži `model_provider = "omniroute"`. Uklonite `[model_providers.omniroute]` ako je dodan za ovaj pristupnik. Vratite ili uklonite `openai_base_url` ako pokazuje na OmniRoute. Za OpenAI-kompatibilne klijente, vratite ili obrišite `OPENAI_BASE_URL` gdje god ga postavite za OmniRoute.

### 3. Provjerite radi li klijent sa zaustavljenim OmniRoute

Provjerite zadane postavke Claude koda i trenutno okruženje ljuske.

```bash
grep -n ANTHROPIC ~/.claude/settings.json
env | grep ANTHROPIC
```

Nijedna provjera ne bi trebala pokazati `ANTHROPIC_BASE_URL` koji pokazuje na OmniRoute. Ako koristite postavke profila ili projekta, provjerite i te datoteke. Kada je OmniRoute zaustavljen i vaša uobičajena autentifikacija vraćena, pokrenite Claude kod izravno.

```bash
claude -p "say hello"
```

Claude kod bi trebao odgovoriti korištenjem obnovljene konfiguracije. Ako i dalje pokazuje na zaustavljeni pristupnik, zahtjev ne uspijeva uz pogrešku veze.

## Brza deinstalacija (v3.6.2 +)

> Prvo [vratite konfiguraciju klijenta](#revert-client-configuration), dok OmniRoute još radi.

OmniRoute nudi dvije ugrađene skripte za čisto uklanjanje:

### Čuvajte svoje podatke

```bash
npm run uninstall
```

Ovo uklanja OmniRoute aplikaciju, ali** čuva** vaša baza podataka, konfiguracije, API ključevi i postavke pružatelja usluga u `~/.omniroute/`. Koristite ovo ako planirate kasnije ponovno instalirati i želite zadržati svoje postavke.

### Potpuno uklanjanje

```bash
npm run uninstall:full
```

Ovo uklanja aplikaciju** i trajno briše** svi podaci:

- Baza podataka (`storage.sqlite`)
- Konfiguracije pružatelja usluga i API ključevi
- Sigurnosne kopije datoteka
- Log datoteke
- Sve datoteke u direktoriju `~/.omniroute/`

> ⚠️** Upozorenje:** `npm run uninstall:full` je nepovratan. Sve vaše veze pružatelja usluga, kombinacije, API ključevi i povijest korištenja bit će trajno izbrisani.

## Ručna deinstalacija

> Prvo [vratite konfiguraciju klijenta](#revert-client-configuration), dok OmniRoute još radi.

### NPM Globalna instalacija

```bash
# Remove the global package
npm uninstall -g omniroute

# (Optional) Remove data directory
rm -rf ~/.omniroute
```

### pnpm Globalna instalacija

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# Stop and remove the container
docker stop omniroute
docker rm omniroute

# Remove the volume (deletes all data)
docker volume rm omniroute-data

# (Optional) Remove the image
docker rmi cheaperinference/omniroute:latest
# Older installs pulled the legacy name:
docker rmi diegosouzapw/omniroute:latest
```

### Docker Sastavi

```bash
# Stop and remove containers
docker compose down

# Also remove volumes (deletes all data)
docker compose down -v
```

### Electron aplikacija za stolna računala

**Windows:**

- Otvori `Settings → Apps → OmniRoute → Uninstall`
- Ili pokrenite NSIS uninstaller iz instalacijskog direktorija

**macOS:**

- Povucite `OmniRoute.app` iz `/Applications` u smeće
- Ukloni podatke: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- Uklonite AppImage datoteku
- Ukloni podatke: `rm -rf ~/.omniroute`

### Izvorna instalacija (git klon)

```bash
# Remove the cloned directory
rm -rf /path/to/omniroute

# (Optional) Remove data directory
rm -rf ~/.omniroute
```

## Direktoriji s podacima

OmniRoute pohranjuje podatke na sljedećim lokacijama prema zadanim postavkama:

| Platforma      | Zadana putanja                  | Zamjena                         |
| -------------- | ------------------------------- | ------------------------------- |
| Linux          | `~/.omniroute/`                 | `DATA_DIR` env varijabla        |
| macOS          | `~/.omniroute/`                 | `DATA_DIR` env varijabla        |
| Windows        | `%APPDATA%/omniroute/`          | `DATA_DIR` env varijabla        |
| Docker         | `/app/data/` (montirani volume) | `DATA_DIR` env varijabla        |
| Sukladno s XDG | `$XDG_CONFIG_HOME/omniroute/`   | `XDG_CONFIG_HOME` env varijabla |

### Datoteke u direktoriju s podacima

| Datoteka/Direktorij  | Opis                                                               |
| -------------------- | ------------------------------------------------------------------ |
| `storage.sqlite`     | Glavna baza podataka (dobavljači, kombinacije, postavke, ključevi) |
| `storage.sqlite-wal` | SQLite write-ahead log (privremeno)                                |
| `storage.sqlite-shm` | SQLite shared memory (privremeno)                                  |
| `call_logs/`         | Arhive tereta zahtjeva                                             |
| `backups/`           | Automatske sigurnosne kopije baze podataka                         |
| `log.txt`            | Naslijeđeni zapisnik zahtjeva (neobavezno)                         |

## Provjera potpunog uklanjanja

Nakon deinstalacije, provjerite da nisu preostale nikakve datoteke:

```bash
# Provjeri postoji li globalni npm paket
npm list -g omniroute 2>/dev/null

# Provjeri postoji li direktorij s podacima
ls -la ~/.omniroute/ 2>/dev/null

# Provjeri postoje li aktivni procesi
pgrep -f omniroute
```

Ako je bilo koji proces još aktivan, zaustavite ga:

```bash
pkill -f omniroute
```
