> **Ukratko**: OmniRoute rangira svoje **besplatne** pružatelje prema kvaliteti modela koristeći **Arena AI
> ELO rezultate (u stilu LMArene)**. Otvorite stranicu **Rangiranje besplatnih pružatelja** na
> nadzornoj ploči kako biste vidjeli koji besplatni pružatelji nude najbolje modele za vaš zadatak —
> ukupno ili filtrirano prema kategoriji (programiranje, pregled, dokumentacija, otklanjanje pogrešaka).

---

## Što je to

OmniRoute registrira 377 ponuđača, uključujući 155 označenih kataloških zapisa**free/no-auth** (no-auth, free-tier OAuth ili free-tier API ključ — pogledajte [Vodič za besplatne razine](../getting-started/FREE-TIERS-GUIDE.md) i cijeli [imenik besplatnih razina](../reference/FREE_TIERS.md) ). Kvaka: besplatni pružatelji jako variraju u kvaliteti modela. Davatelj bez autentifikacije koji poslužuje granični model mnogo je korisniji od onog koji služi malom naslijeđenom modelu.

**Rangiranje besplatnih pružatelja usluga** odgovori "** koji mi besplatni pružatelj nudi najbolji model?** " pridruživanjem katalogu svakog besplatnog pružatelja usluge** ocjene kvalitete dobivene iz mnoštva** iz** Arena AI ljestvica** (human-preference ELO, ista ideja iza LMArena chatbot arene). Pružatelji se zatim rangiraju prema snazi svojih** najbolji besplatni model** .

Poredak se izračunava iz tri stvarna izvora:

1. Popisi besplatnih pružatelja — `NOAUTH_PROVIDERS`, plus `OAUTH_PROVIDERS` / `APIKEY_PROVIDERS` unosi označeni `hasFree` (`src/shared/constants/providers.ts`).
2. Katalog modela svakog pružatelja iz registra pružatelja (`open-sse/config/providerRegistry.ts`).
3. Rezultati prilagođeni zadatku izvedeni iz ELO-a pohranjeni u `model_intelligence` DB tablici od strane Arena ELO sync engine (`src/lib/arenaEloSync.ts`).

Logika spajanja živi u `src/lib/freeProviderRankings.ts`.

## Kako pristupiti

### Stranica nadzorne ploče

Otvorite nadzornu ploču i idite na **Troškovi → Rangiranje besplatnih pružatelja** ili izravno otvorite:

```
/dashboard/free-provider-rankings
```

Stranica (`src/app/(dashboard)/dashboard/free-provider-rankings/page.tsx`) prikazuje:

- **Postolje za prva 3 mjesta** (🥇 🥈 🥉) najbolje rangiranih besplatnih pružatelja.
- Potpunu **tablicu rangiranja** sa stupcima: **Rang**, **Pružatelj**, **Najbolji model**,
  **Rezultat**, **Prosječni rezultat**, **Modeli**, **Vrsta**.
- **Gumbe za filtriranje kategorija**: _Sve kategorije_, _Zadano_, _Programiranje_, _Pregled_,
  _Dokumentacija_, _Otklanjanje pogrešaka_.

Oznaka **Vrsta** svakog pružatelja pokazuje na koji je način besplatan:

| Oznaka   | Značenje                                              |
| -------- | ----------------------------------------------------- |
| `NOAUTH` | Uvijek besplatan, vjerodajnice nisu potrebne          |
| `OAUTH`  | OAuth pružatelj s besplatnom razinom (`hasFree`)      |
| `APIKEY` | Pružatelj API ključa s besplatnom razinom (`hasFree`) |

Rezultati se prikazuju kao lako razumljive oznake (npr. _Elitan_, _Izvrstan_, _Vrlo dobar_,
_Dobar_, _Prosječan_), a ne kao neobrađeni brojevi jer je temeljna vrijednost relativna
ocjena kvalitete, a ne postotak.

### API krajnja točka

Stranica se temelji na javnoj krajnjoj točki za čitanje
(`src/app/api/free-provider-rankings/route.ts`):

```
GET /api/free-provider-rankings
GET /api/free-provider-rankings?category=coding
GET /api/free-provider-rankings?category=coding&limit=20
```

Parametri upita (validirani pomoću Zoda):

| Parametar  | Vrsta  | Zadano | Napomene                                                                                                    |
| ---------- | ------ | ------ | ----------------------------------------------------------------------------------------------------------- |
| `category` | string | (nema) | Jedno od `default`, `coding`, `review`, `documentation`, `debugging`. Izostavite za kombinirano rangiranje. |
| `limit`    | number | `50`   | Ograničeno na raspon `1–100`.                                                                               |

Struktura odgovora:

```json
{
  "rankings": [
    {
      "id": "<provider-id>",
      "name": "<provider name>",
      "icon": "<icon>",
      "color": "<hex color>",
      "textIcon": "<short label>",
      "category": "noauth | oauth | apikey",
      "topModel": {
        "modelId": "<registry model id>",
        "modelName": "<model display name>",
        "score": 0.0,
        "eloRaw": 0,
        "confidence": "high | medium | low",
        "category": "<task category>"
      },
      "averageScore": 0.0,
      "modelCount": 0
    }
  ]
}
```

`eloRaw` je izvorna Arena ELO vrijednost; `score` je normalizirana vrijednost prikladnosti za zadatak
(pogledajte u nastavku). Pružatelji bez ocijenjenih modela izostavljaju se iz odgovora.

## Kako funkcioniraju ocjene

### Izvor: Arena AI ljestvica

Mehanizam za sinkronizaciju Arena ELO (`src/lib/arenaEloSync.ts`) dohvaća dvije ljestvice — `text` i `code` — s Arena AI leaderboard API-ja (`https://api.wulong.dev/arena-ai-leaderboards/v1/leaderboard`). Kada taj API ne vrati upotrebljivu ljestvicu, mehanizam se prebacuje na službeni `lmarena-ai/leaderboard-dataset` na Hugging Face datasets-serveru (`src/lib/arenaEloHfSource.ts`, CC-BY-4.0; `overall` → `text`, `coding` → `code`); `GET /api/intelligence/sync` prijavljuje `activeSource`, `lastError` i `lastFailedAt`. Svaki unos na ljestvici nosi naziv modela, proizvođača, ELO `score`, interval pouzdanosti i broj glasova.

Kategorije ljestvice preslikavaju se na OmniRoute kategorije zadataka:

| Arena ljestvica | OmniRoute kategorije zadataka                     |
| --------------- | ------------------------------------------------- |
| `text`          | `default`, `review`, `documentation`, `debugging` |
| `code`          | `coding`                                          |

### Normalizacija (rezultat prikladnosti za zadatak)

Sirovi ELO rezultati normaliziraju se po ljestvici u **vrijednost prikladnosti za zadatak u rasponu `[0.4, 0.98]`**:

```
taskFit = 0.4 + 0.58 * ((elo - minElo) / (maxElo - minElo))
```

Rezultat nikada ne doseže `0` ili `1`, čime se ostavlja prostor za korisnička nadjačavanja. Ovo je polje `score` koje vidite u odgovoru API-ja i oznaka prikazana na nadzornoj ploči.

### Pouzdanost

Svaki unos dobiva razinu pouzdanosti na temelju broja glasova na Areni:

| Pouzdanost | Glasovi |
| ---------- | ------- |
| `high`     | ≥ 5,000 |
| `medium`   | ≥ 1,000 |
| `low`      | < 1,000 |

### Pohrana i svježina podataka

Normalizirani unosi zapisuju se u DB tablicu `model_intelligence` s `source = "arena_elo"` (`src/lib/db/modelIntelligence.ts`). Unosi **isteču nakon 7 dana**, pa pružatelj koji prestane sinkronizirati na kraju ispada, umjesto da poslužuje zastarjele podatke.

Sinkronizacija je **prema zadanim postavkama uključena**:

- Pokreće se jednom pri pokretanju poslužitelja, a zatim u periodičkim intervalima (`src/lib/arenaEloSync.ts`, povezano iz `src/instrumentation-node.ts`).
- **Neblokirajuća je i nikada nije kobna** — ako dohvat s izvorišta ne uspije, OmniRoute nastavlja raditi, a rangiranja jednostavno prikazuju posljednje ispravne podatke (ili prazno stanje).

Dvije varijable okruženja njome upravljaju (dokumentirane u [`docs/reference/ENVIRONMENT.md`](../reference/ENVIRONMENT.md)):

| Varijabla                 | Zadano        | Svrha                                                              |
| ------------------------- | ------------- | ------------------------------------------------------------------ |
| `ARENA_ELO_SYNC_ENABLED`  | `true`        | Postavite na `false` kako biste isključili odlaznu sinkronizaciju. |
| `ARENA_ELO_SYNC_INTERVAL` | `86400` (24h) | Interval sinkronizacije, u sekundama.                              |

### Ručna sinkronizacija / status / brisanje

Za operatere, autentificirana upravljačka krajnja točka izlaže ručnu kontrolu (`src/app/api/intelligence/sync/route.ts` — zahtijeva upravljačku autentifikaciju):

```
GET    /api/intelligence/sync          # trenutni status sinkronizacije (enabled, lastSync, nextSync, intervalMs)
POST   /api/intelligence/sync          # pokreće ručnu sinkronizaciju; tijelo: { "dryRun": true } za pregled bez zapisivanja
DELETE /api/intelligence/sync          # briše sve sinkronizirane arena_elo unose inteligencije
```

Ako je stranica s rangiranjem prazna, ručni `POST /api/intelligence/sync` (ili jednostavno ponovno pokretanje poslužitelja) ponovno je popunjava.

### Usparivanje modela s ljestvicom

ID-ovi modela u registru i nazivi modela na Areni ne podudaraju se uvijek točno. Rangiranje koristi fleksibilno usparivanje (`findMatchingIntelligence` u `src/lib/freeProviderRankings.ts`):

1. Točno podudaranje s normaliziranim ID-om modela.
2. Podudaranje nakon uklanjanja završnog sufiksa verzije (npr. `kimi-k2.6` → `kimi-k2`).
3. Podudaranje prefiksa (naziv modela s ljestvice prefiks je ID-a u registru).

Na strani sinkronizacije uklanjaju se poznati prefiksi proizvođača (`anthropic/`, `openai/`, `google/`, …), a mala mapa aliasa proširuje kanonske nazive u varijante koje OmniRoute interno koristi, pa modeli ostaju pronađivi pod bilo kojim nazivom.

### Kako se pružatelj rangira

Za svakog besplatnog pružatelja mehanizam ocjenjuje svaki model u njegovom katalogu, a zatim:

- **Najbolji model** = model tog pružatelja s najvišom ocjenom.
- **Prosj. ocjena** = prosječna ocjena svih ocijenjenih modela tog pružatelja.
- **Modeli** = koliko je modela tog pružatelja imalo Arena ocjenu.

Pružatelji se sortiraju prvo prema **ocjeni najboljeg modela**, a zatim prema prosječnoj ocjeni. Time se nagrađuje pružatelj koji nudi barem jedan snažan besplatni model.

## Kako ga koristiti za odabir besplatnih pružatelja usluga

1. **Odaberite odgovarajuću kategoriju.** Upotrijebite filtar **Coding** za agentska/programerska radna opterećenja ili
   ostavite **All Categories** / **Default** za opći razgovor. Isti pružatelj usluga može
   biti različito rangiran u različitim kategorijama jer se njegov najbolji model razlikuje ovisno o ljestvici.
2. **Za jednokratne postavke preferirajte vodeća mjesta.** Ako želite povezati samo jednog ili dva besplatna
   pružatelja usluga, započnite s najbolje rangiranima u svojoj kategoriji.
3. **Provjerite oznaku Type.** Pružatelji usluga `NOAUTH` najbrže se povezuju (bez
   vjerodajnica). Besplatne razine `OAUTH` / `APIKEY` zahtijevaju brzu registraciju, ali često nude
   naprednije modele. Korake za povezivanje potražite u [Vodiču za besplatne razine](../getting-started/FREE-TIERS-GUIDE.md).
4. **Povežite nekoliko pružatelja i prepustite odabir značajci Auto-Combo.** Isti podaci Arena ELO koji pokreću
   ovu stranicu također se koriste za **faktor prikladnosti za zadatak** mehanizma bodovanja Auto-Combo
   (`open-sse/services/autoCombo/taskFitness.ts`, redoslijed razrješavanja:
   `user_override → arena_elo → models_dev_tier → static table`). Nakon što povežete
   najbolje besplatne pružatelje usluga, usmjeravanje s `model: "auto"` (npr. `auto/coding`) automatski će
   davati prednost kvalitetnijim besplatnim modelima za svaki zahtjev. Potpuni sustav bodovanja sa 16 faktora
   potražite u dokumentu [Auto-Combo](../routing/AUTO-COMBO.md).
