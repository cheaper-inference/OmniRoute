`@omniroute/opencode-plugin-v2` dodaje cijeli vaš OmniRoute katalog — modele, kombinacije i
automatske kombinacije — u OpenCode v2 odabirnik modela, zajedno s nazivima za prikaz, cijenama i
ograničenjima besplatne razine.

To je zaseban paket od paketa `@omniroute/opencode-plugin` jer OpenCode v1 i v2 učitavaju
dodatke putem različitih ugovora. Odaberite onaj koji odgovara vašoj glavnoj verziji OpenCodea; ništa se
ne dijeli između njih, pa nadogradnja jednog nikada ne zahtijeva nadogradnju drugog.

## Preduvjeti

- OpenCode v2.
- Dostupan OmniRoute pristupnik (`http://localhost:20128` prema zadanim postavkama).
- Node.js 22 ili 24.

## Instalacija

Dodajte dodatak u `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

Modeli će se zatim prikazivati kao `omniroute/<provider>/<model>`; `providerId` određuje taj prefiks i
ID integracije pod kojim OpenCode pohranjuje vjerodajnicu.

## Vjerodajnice

Dodatak traži ključ pristupnika na tri mjesta, ovim redoslijedom:

1. **Vjerodajnica koju ste povezali u OpenCodeu.** Dodatak registrira integraciju kako bi
   OpenCodeov vlastiti tijek autentifikacije mogao pohraniti ključ. Ništa se ne sprema u `opencode.json` — preporučuje se ova mogućnost.
2. `apiKey` u opcijama dodatka, za nadjačavanje po projektu. Time se ključ stavlja u datoteku koju
   možda predajete u repozitorij.
3. `OMNIROUTE_API_KEY` u okruženju.

Ako nije navedena nijedna od te tri mogućnosti, katalog je prazan i dodatak to jednom navodi pri pokretanju, umjesto
da vam ostavi prazan odabirnik bez objašnjenja.

### Token za upravljanje zaseban je ključ

Kombinacije, stanje pružatelja i obogaćivanje (nazivi za prikaz, cijene i ograničenja besplatne razine) dolaze s
krajnjih točaka pristupnika `/api/*`, koje većina implementacija štiti **upravljačkim** tokenom,
a ne ključem za zaključivanje:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<upravljački token za čitanje>"
}
```

Ako nije postavljen, `managementReadToken` vraća se na `apiKey`. Kada pristupnik odbije tu zamjensku vrijednost,
katalog se i dalje objavljuje, ali sa sirovim ID-ovima modela umjesto naziva za prikaz, bez uklanjanja duplikata
kanonskih pseudonima, bez cijena i bez kombinacija. Dodatak jednom upozorava za svaku krajnju točku kada se to dogodi,
navodeći krajnju točku i što je izgubljeno — tako degradirani odabirnik nikada nije zagonetka.

## Mogućnosti

| Ključ                            | Zadano                                           | Bilješke                                                                                                                                                                                                                                                                                                                                                                     |
| -------------------------------- | ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `providerId`                     | `"omniroute"`                                    | ID pružatelja usluga, ID integracije i modeli prefiksa pojavljuju se ispod                                                                                                                                                                                                                                                                                                   |
| `baseURL`                        | potreban                                         | Gateway root, samo `http(s)` ; gdje je potrebno dodaje se sufiks `/v1`                                                                                                                                                                                                                                                                                                       |
| `apiKey`                         | povezana vjerodajnica, zatim `OMNIROUTE_API_KEY` | Ključ za chat za `/v1/*`                                                                                                                                                                                                                                                                                                                                                     |
| `managementReadToken`            | pada natrag na `apiKey`                          | Ključ za `/api/*` — obično** ne** onaj isti                                                                                                                                                                                                                                                                                                                                  |
| `displayName`                    | `"OmniRoute"`                                    | Naziv pružatelja usluga u alatu za odabir                                                                                                                                                                                                                                                                                                                                    |
| `timeoutMs`                      | `10000`                                          | Vremensko ograničenje dohvaćanja po krajnjoj točki (automatske kombinacije koriste 5 s)                                                                                                                                                                                                                                                                                      |
| `modelCacheTtlMs`                | `300000`                                         | Predmemorija kataloga TTL; snimka diska zagrijava hladno počinje                                                                                                                                                                                                                                                                                                             |
| `timeouts`                       | pada natrag na `timeoutMs`                       | Proračuni po krajnjim točkama u ms: `models`, `combos`, `autoCombos`, `enrichment`                                                                                                                                                                                                                                                                                           |
| `enrichment`                     | `true`                                           | Dohvatite imena, cijene i proračune besplatnih razina                                                                                                                                                                                                                                                                                                                        |
| `providerTag`                    | `true`                                           | Uključite zagradu uređivača na kraju: `Provider - Model (Editor)`. Davatelj (ruta koja služi modelu) je uvijek prikazan; urednik (koji je napravio model) pojavljuje se samo u zagradi. Primjer: `Openrouter - MoonshotAI: Kimi K 3.1 Pro` -> `Openrouter - Kimi K 3.1 Pro (MoonshotAI)`. Izostavljeno kada urednik i pružatelj dijele ime. Postavite `false` da ga ispusti. |
| `usableOnly`                     | `false`                                          | Zadrži samo pružatelje usluga pristupnika izvješćima kako je predviđeno                                                                                                                                                                                                                                                                                                      |
| `combosSource`                   | `"api"`                                          | `"models"` preskače `/api/combos` i objavljuje `/v1/models` kombinirane retke; filtri na razini člana čuvaju `"api"`                                                                                                                                                                                                                                                         |
| `showcasePerOwner`               | `10`                                             | Unosi zadanog prikaza čuvaju se po pružatelju usluga                                                                                                                                                                                                                                                                                                                         |
| `freshPerOwner`                  | `10`                                             | Zadani prikaz svježih unosa koji se čuvaju po pružatelju usluga                                                                                                                                                                                                                                                                                                              |
| `freshWindowDays`                | `90`                                             | Prozor svježine u danima za svježu granu                                                                                                                                                                                                                                                                                                                                     |
| `usageMemory`                    | `true`                                           | Vraćanje statički ispuštenih unosa imenovanih pomoću analitike 30-dnevne upotrebe (potreban je token za upravljanje)                                                                                                                                                                                                                                                         |
| `visibleModels` / `hiddenModels` | `[]`                                             | Popisi dopuštenih točnih ili sufiksa; uskratiti pobjede; `*` objavljuje cijeli katalog (ostali filteri i dalje vrijede)                                                                                                                                                                                                                                                      |
| `geminiSanitization`             | `true`                                           | Ukloni ključne riječi JSON-sheme koje Gemini odbija iz shema alata (`$ref` alati prosljeđuju se netaknuti)                                                                                                                                                                                                                                                                   |
| `apiFormat.allowAnthropic`       | `false`                                          | Usmjerite dopuštene ID-ove kroz Anthropic API blok                                                                                                                                                                                                                                                                                                                           |
| `apiFormat.anthropicModels`      | `[]`                                             | Puni ID-ovi modela usmjereni na Anthropic                                                                                                                                                                                                                                                                                                                                    |
| `logLevel` / `startupDebug`      | `warn` / `false`                                 | Opširnost zapisivača                                                                                                                                                                                                                                                                                                                                                         |

Memorija upotrebe uključena je prema zadanim postavkama. Bez tokena upravljanja ostaje inertan (bilježi se obavijest o pokretanju) i ništa se ne vraća.

## Kako katalog ostaje svjež

Katalog se lijeno dohvaća i sprema u predmemoriju za `modelCacheTtlMs`, a snimka diska čuva posljednji poznati katalog dostupnim kada je pristupnik nedostupan — prekid vas košta ništa osim svježine. Modeli i kombinacije objavljuju se čim stignu; automatske kombinacije, popis pružatelja usluga i sloj za obogaćivanje preklapaju se kada slete, tako da jedna spora krajnja točka ne može držati cijeli birač kao taoca.

Imena slijede `Provider - Model[ (Editor)][ · budget][ (route)]`: pružatelj se prikazuje svaki put kada ID nosi jedan (id bez kose crte prikazuje se bez prefiksa), vodeći `🆓` označava besplatne unose i njihov proračun besplatne razine ostaje kao sufiks `· 1M tokens/month`, uređivač eksplicitnog naziva `Editor: Model` pomiče se u zagradu na kraju (nijedan uređivač se ne pogađa iz drugih imena), a kombinacije se prikazuju kao `combo - <slug>` bez besplatne ikone. Dva unosa koji dijele ime dobivaju sufiks rute — `(no-think)` — tako da se mogu razlikovati. `providerTag` (zadano `true`) uključuje/isključuje zagradu uređivača na kraju.

Ne postoji ručna naredba za osvježavanje: OpenCode v2 naredbe su promptni predlošci, a ne povratni pozivi, tako da ih dodatak ne može otkriti. Osvježenja slijede TTL; od hosta se traži ponovno učitavanje samo kada se katalog ili preklapanje stvarno promijene, nikada jednom po osvježavanju.

## Pozivanje alata na Geminiju

Gemini odbija cijeli zahtjev čije deklaracije alata sadrže `$schema` ili
`additionalProperties`, odgovarajući s `400 INVALID_ARGUMENT`. Dodatak uklanja te ključne riječi iz
shema alata namijenjenih Gemini modelu ovog pružatelja, a svaki drugi zahtjev ostavlja netaknutim.
Alat koji sadrži `$ref` prosljeđuje se netaknut umjesto da se iz njega uklanjaju ključne riječi jer bi uklanjanje
reference proširilo shemu tako da „prihvaća bilo što”.
Postavite `"geminiSanitization": false` da biste to isključili.

## Rješavanje problema

| Simptom                                           | Uzrok                                                                                                       |
| ------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| Birač ne prikazuje OmniRoute model                | Nijedan ključ nije riješen (provjerite upozorenje pri pokretanju) ili pristupnik nije dostupan              |
| Sirovi ID-ovi modela, bez kombinacija, bez cijena | Krajnje točke upravljanja odbile su token — postavljen `managementReadToken`                                |
| Kratki ili prazan `freeOnly` katalog              | Nema `unmatched-free` za upravljanje ili — token odbijen                                                    |
| Sesija prikvačena na `opencode-<id>/...`          | Dodatak v1 objavio je `opencode-<id>`; v2 objavljuje goli `<id>`, pa ponovno odaberite model pod `<id>/...` |

Varijable okruženja moraju doći do procesa poslužitelja otvorenog koda: kada se host izvodi kao usluga, ljuska koja pokreće `opencode models` i okruženje poslužitelja su različiti, stoga izvezite ključ tamo gdje ga poslužitelj čita.
