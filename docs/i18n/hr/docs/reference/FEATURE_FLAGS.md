> Prekidači za vrijeme izvođenja koji mijenjaju ponašanje OmniRoutea **bez ponovnog postavljanja**.
> Svaki ovdje navedeni zastavica definirana je u
> [`src/shared/constants/featureFlagDefinitions.ts`](../../src/shared/constants/featureFlagDefinitions.ts)
> — jedinom izvoru istine. Nadzorna ploča i REST API čitaju iz
> te datoteke, tako da je donja tablica generirana da joj odgovara 1:1.

---

## Što su značajke (Feature Flags)

Značajka (feature flag) je imenovani prekidač (boolean ili enum) čija se vrijednost može mijenjati tijekom
izvođenja i pohraniti u bazu podataka, bez potrebe za ponovnim postavljanjem procesa. Svaka
zastavica je opisana `FeatureFlagDefinition` s `key`, `label`,
`description`, `category`, `defaultValue`, `type` i `requiresRestart` savjetom.

### Redoslijed razrješavanja

**Efektivna vrijednost** zastavice razrješava se pomoću
[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) s ovim
redoslijedom prioriteta (najviši pobjeđuje):

1.  **Premošćivanje baze podataka (DB override)** — vrijednost pohranjena u tablici `key_value` pod
    imenikom `feature_flags` (postavljeno putem nadzorne ploče ili REST API-ja).
2.  **Varijabla okoline** — `process.env[<KEY>]`, ako je postavljena i nije prazna.
3.  **Zadana vrijednost definicije** — `defaultValue` iz `featureFlagDefinitions.ts`.

Boolean zastavica smatra se **omogućenom** kada je njezina efektivna vrijednost `"true"`,
`"1"` ili `"yes"` (vidi `isFeatureFlagEnabled()`).

> [!NOTE]
> Većina zastavica također ima odgovarajuću varijablu okoline **istog naziva**
> dokumentiranu u [`ENVIRONMENT.md`](./ENVIRONMENT.md). Premošćivanje zastavice u bazi podataka
> ima prednost nad tom varijablom okoline. Zastavica s
> `requiresRestart: true` odmah se pohranjuje, ali se ponovno čita tek pri pokretanju procesa — prebacivanje
> iste prikazuje natpis **"Ponovno pokreni poslužitelj"** na nadzornoj ploči.

Kada je omogućena, i druge neuvjerljive dijagnoze (dvosmislene pogreške, nepodržane provjere i netipizirane pogreške planera) također se tretiraju kao nepoznate, što omogućuje promet. Prema zadanim postavkama isključeno: druge predmemorirane pogreške provjere i dalje blokiraju slanje tijekom TTL-a predmemorije (5 minuta). |

> [!NOTE]
> `INPUT_SANITIZER_BLOCK_THRESHOLD` i njegov naslijeđeni alias
> `INJECTION_GUARD_BLOCK_THRESHOLD` podešavaju način rada `block` za
> `INJECTION_GUARD_MODE`, ali to su obične varijable okruženja koje čita
> [`src/shared/utils/injectionSeverity.ts`](../../src/shared/utils/injectionSeverity.ts),
> a ne zastavice značajki: nemaju nadjačavanje u bazi podataka ni prekidač na nadzornoj ploči. Pogledajte
> [`ENVIRONMENT.md`](./ENVIRONMENT.md#4-security--authentication).

> [!NOTE]
> Stupac `Restart` označava zastavice s `requiresRestart: true` — vrijednost se
> odmah pohranjuje, ali počinje djelovati tek nakon ponovnog učitavanja procesa. Enum zastavice odbijaju svaku vrijednost izvan dopuštenog skupa (provjera se obavlja na strani poslužitelja i u `setFeatureFlagOverride()` i u REST rukovatelju `PUT`).

## Prebacivanje zastavica

### Nadzorna ploča

Idite na **Nadzorna ploča → Postavke → Zastavice značajki**
(`/dashboard/settings/feature-flags`). Mreža
(`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`)
podržava:

- **Pretraživanje** prema ključu ili opisu te **filtriranje** prema kategoriji (uz sintetički prikaz
  **Zahtijeva ponovno pokretanje**).
- **Prekidač** za Booleove zastavice i **padajući izbornik** za zastavice enum
  (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`).
- Bedž izvora za svaku zastavicu — `DB`, `ENV` ili `DEF` — koji prikazuje odakle dolazi efektivna vrijednost.
- Gumb **Poništi** (prikazuje se samo za zastavice iz izvora `DB`) za uklanjanje nadjačavanja i gumb **Poništi sva nadjačavanja** pri dnu.
- Natpis **Ponovno pokreni poslužitelj** kada se promijeni zastavica `requiresRestart`.

### REST API

Sve operacije prolaze kroz jednu rutu:
[`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts).
Svaka metoda zahtijeva autentificiranu sesiju nadzorne ploče (`401` u suprotnom).

#### `GET /api/settings/feature-flags`

Vraća svaku zastavicu s efektivnom vrijednošću, izvorom i sažetkom.

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Zahtijevaj API ključ",
      "description": "Zahtijevaj API ključ za sve dolazne zahtjeve",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... svih 116 zastavica
  ],
  "summary": {
    "total": 116,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

Postavlja ili uklanja jedno nadjačavanje. Tijelo: `{ key: string; value?: string }`.
Izostavljanjem `value` uklanja se nadjačavanje (vraćanje na vrijednost iz okruženja / zadanu vrijednost).

```bash
# Postavi nadjačavanje u DB-u
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# Ukloni nadjačavanje (bez "value")
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

Odgovor vraća nove vrijednosti `effectiveValue`/`source`, prethodne vrijednosti `previousValue`/
`previousSource` i vrijednost `requiresRestart`. Nepoznati ključevi i enum
vrijednosti izvan dopuštenog raspona odbijaju se s `400`.

#### `DELETE /api/settings/feature-flags`

Odjednom uklanja **sva** nadjačavanja iz DB-a i vraća svaku zastavicu na vrijednost iz okruženja / zadanu
vrijednost. Vraća `{ cleared: <count>, message: "..." }`.

> [!NOTE]
> Zastavice s `requiresRestart: true` stupaju na snagu tek nakon ponovnog učitavanja procesa.
> Tijek ponovnog pokretanja na nadzornoj ploči poziva `POST /api/restart`, a zatim šalje upite
> `GET /api/health/ping` dok poslužitelj ponovno ne bude dostupan.

## Rezervna opcija za hitne slučajeve pri iscrpljenju proračuna

`OMNIROUTE_EMERGENCY_FALLBACK` (kategorija `runtime`, zadana vrijednost `true`) kontrolira
besplatni rezervni put za hitne slučajeve u
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts).
Kada je omogućena, zahtjevi koji iscrpe svoj proračun usmjeravaju se na besplatnog rezervnog
pružatelja/model umjesto da odmah ne uspiju. Postavite je na `false` (ili `0`) — putem
prekidača na nadzornoj ploči, nadjačavanja u bazi podataka ili varijable okruženja
`OMNIROUTE_EMERGENCY_FALLBACK` — kako biste onemogućili to ponašanje i dopustili da zahtjevi
s iscrpljenim proračunom ne uspiju. (Prikazano kao prekidač na nadzornoj ploči u PR-ovima #3741 / #3752.)

Odgovor poslužen putem ove rezervne opcije sadrži
`X-OmniRoute-Emergency-Fallback: from=<provider/model>; to=<provider/model>`, tako da klijent
može utvrditi da je zahtjev preusmjeren bez uspoređivanja zaglavlja `X-OmniRoute-Provider` sa svojim
zahtjevom. Ovo zaglavlje nije prisutno ni u jednom drugom odgovoru.
