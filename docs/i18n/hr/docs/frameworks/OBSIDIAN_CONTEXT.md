> `src/lib/db/obsidian.ts` (pohrana tokena / osnovnog URL-a / WebDAV-a),

> `src/app/api/settings/obsidian/webdav/route.ts` (API-ji postavki). Registracija alata
> i povezivanje opsega nalaze se u `open-sse/mcp-server/server.ts`.

## Što je to

OmniRoute povezuje se s **Obsidian** trezorom kao **izvorom konteksta** — lokalnom bazom
znanja u Markdownu koju agenti čitaju i zapisuju putem ugrađenog MCP poslužitelja.
Integracija komunicira s dodatkom zajednice **Obsidian Local REST API** koji se izvodi
unutar aplikacije za stolna računala, pa agenti mogu pretraživati bilješke, čitati,
zapisivati i parcijalno mijenjati datoteke, pregledavati sadržaj trezora, raditi s
dnevnim i tjednim periodičnim bilješkama, upravljati oznakama, pokretati naredbe
Obsidiana te, opcionalno, koordinirati dvosmjernu sinkronizaciju trezora između
stolnog i mobilnog uređaja.

Klijent (`src/lib/obsidian/api.ts`) obavija Local REST API sljedećim mogućnostima:

- **Ponovni pokušaj uz odgodu** za privremene pogreške `5xx`, **istek nakon 30 sekundi** putem `AbortController`.
- **Klasifikacija pogrešaka prema tipu** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`.
- **Razumljiva uputa za slučaj kada „nije moguće pristupiti Obsidianu”** koja upozorava
  na čestu pogrešku s priključkom (HTTP na `27123`, **ne** MCP krajnja točka na `27124`)
  i navodi oblik adrese za Tailscale.
- **Kodiranje putanja** relativnih u odnosu na trezor kako bi putanje bilješki s razmacima i kosim crtama bile sigurne.

## Postavljanje

Ne postoji **varijabla okruženja** za Obsidian token ni osnovni URL — oboje se
pohranjuje u SQLite tablici `key_value` (imenski prostor `obsidian`) putem
`src/lib/db/obsidian.ts`. Token je **šifriran u mirovanju** (AES-256-GCM, uz
rezervnu kompatibilnost s običnim tekstom). Konfigurirajte ga na kartici **Izvori konteksta**
nadzorne ploče krajnje točke (`ObsidianSourceCard`) ili putem REST API-ja za postavke.

> [!IMPORTANT]
> Dodatak **Obsidian Local REST API** mora biti instaliran i pokrenut. Njegovo REST
> sučelje sluša na **HTTP `127.0.0.1:27123`** (zadani osnovni URL). Port `27124`
> je _zasebna_ MCP/HTTPS krajnja točka i ruta postavki izričito ga odbija.
> Ako se povezujete s drugog uređaja, upotrijebite `http://<tailscale-ip>:27123`.

### Konfiguracijski ključevi (SQLite `key_value`, imenski prostor `obsidian`)

| Ključ             | Svrha                                                        | Šifrirano |
| ----------------- | ------------------------------------------------------------ | --------- |
| `api_key`         | Bearer token lokalnog REST API-ja                            | da        |
| `base_url`        | Osnovni REST URL (zadano `http://127.0.0.1:27123`)           | ne        |
| `vault_path`      | Apsolutna putanja do direktorija trezora (za sinkronizaciju) | ne        |
| `webdav_username` | Generirano WebDAV korisničko ime (sinkronizacija trezora)    | ne        |
| `webdav_password` | Generirana WebDAV lozinka (sinkronizacija trezora)           | da        |
| `webdav_enabled`  | Je li omogućena WebDAV sinkronizacija trezora                | ne        |

### Konfiguriranje putem REST-a

```bash
# Spremi i provjeri token lokalnog REST API-ja (POST provjerava putem provjere statusa)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# Provjeri status veze (vraća connected, hasToken, baseUrl, vaultPath)
curl http://localhost:20128/api/settings/obsidian

# Prekini vezu (briše pohranjeni token)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

Sve metode zahtijevaju autentifikaciju na nadzornoj ploči. `POST` odbija svaki URL na
portu `27124` i provjerava token pozivanjem statusne krajnje točke lokalnog REST API-ja
prije pohrane.

### WebDAV sinkronizacija trezora

`src/app/api/settings/obsidian/webdav/route.ts` upravlja neobaveznom sinkronizacijom
trezora putem WebDAV-a (koju pokreće `src/lib/obsidianSync.ts`). Omogućavanjem se
OmniRoute usmjerava na lokalni direktorij trezora te se generira nasumični par
WebDAV korisničkog imena i lozinke:

```bash
# Omogući WebDAV sinkronizaciju za direktorij trezora (generira korisničko ime/lozinku)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# Dohvati status WebDAV sinkronizacije (vjerodajnice se vraćaju samo dok je omogućena)
curl http://localhost:20128/api/settings/obsidian/webdav

# Onemogući WebDAV sinkronizaciju (briše vjerodajnice i upravljani .stignore)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### Sigurnost i prijevoz

WebDAV provjera autentičnosti nameće praćenje grešaka po IP-u i zaključavanje (10 neuspjelih pokušaja unutar prozora od 60 sekundi pokreće 5-minutno zaključavanje sa `429 Too Many Requests` i `Retry-After`). Budući da WebDAV prenosi osnovne vjerodajnice za provjeru autentičnosti, prekid TLS (ili usmjeravanje preko sigurnog tunela kao što je Tailscale ili Cloudflare Tunnel) snažno se preporučuje kada se pristupa WebDAV krajnjoj točki izvan povratne petlje.

### Izvor konteksta po API ključu (neobavezno)

Konfiguracija Obsidiana može se ograničiti **po API ključu** putem tablice
`api_key_context_sources` (`src/lib/db/apiKeyContextSources.ts`). Kada MCP poziv sadrži
ID autentificiranog API ključa, `getObsidianConfigForApiKey()` daje prednost vlastitom
tokenu, osnovnom URL-u i putanji trezora tog ključa (`source: "api_key"`), a u suprotnom
se vraća na globalnu konfiguraciju (`source: "global"`).

MCP alati koji nisu namijenjeni sinkronizaciji zahtijevaju razriješen identitet
pozivatelja prije čitanja ove konfiguracije. Pozivatelj bez identiteta prima
`Obsidian API token not configured` i ne šalje se nikakav zahtjev trezoru. HTTP
pozivatelji razrješavaju identitet putem vjerodajnica svojeg zahtjeva; stdio
pozivatelji mogu ga razriješiti putem `OMNIROUTE_API_KEY` ili `ROUTER_API_KEY`.
Nerazriješeni HTTP pozivatelj ne može naslijediti identitet poslužiteljeva okruženja.
Sami ID-jevi rezerviranih mjesta ne odobravaju pristup; valjana vjerodajnica okruženja
koja se razrješava kao `env-key` i dalje je podržana. Autentificirani ključevi bez
konfiguracije Obsidiana po ključu zadržavaju globalnu pričuvnu konfiguraciju. Četiri
alata `obsidian_sync_*` zadržavaju svoje zasebno ponašanje tokena za sinkronizaciju.

## MCP alati (22)

Definirano u `open-sse/mcp-server/tools/obsidianTools.ts`. token/base-URL se rješavaju po pozivu (prvo po ključu API-ja, a zatim globalno). Alati koji pogađaju OmniRoute** poslužitelj za sinkronizaciju** (četiri `obsidian_sync_*` alata) dodatno zahtijevaju autentičan token za sinkronizaciju konfiguriran u OmniRoute postavkama.

### Alati za čitanje (`read:obsidian`)

| Alat                         | Opis                                                                                                      |
| ---------------------------- | --------------------------------------------------------------------------------------------------------- |
| `obsidian_check_status`      | Provjerite je li lokalni REST API dostupan i autentificiran.                                              |
| `obsidian_search_simple`     | Pretraživanje cijelog teksta sadržaja bilješke; vraća isječke sa stazama datoteka.                        |
| `obsidian_search_structured` | Pretraživanje pomoću JSON logičkog izraza (and/or/regex/path filtri).                                     |
| `obsidian_read_note`         | Čitanje bilješke putem relativnog trezora; izborno određeni heading/block/frontmatter.                    |
| `obsidian_list_vault`        | Popis datoteka i direktorija u trezoru (stablo unosa).                                                    |
| `obsidian_get_document_map`  | Dobijte strukturu naslova bilješke kao mapu naslova → brojeva redaka.                                     |
| `obsidian_get_note_metadata` | Dobijte frontmatter, oznake, veze, char/word broj bez punog sadržaja.                                     |
| `obsidian_get_active_file`   | Dobijte stazu + sadržaja trenutno aktivne datoteke u Obsidian.                                            |
| `obsidian_get_periodic_note` | Dobijte daily/weekly/monthly periodičnu bilješku za datum (današnji ako je izostavljen).                  |
| `obsidian_get_tags`          | Navedite sve oznake trezora s njihovim učestalostima.                                                     |
| `obsidian_list_commands`     | Popis dostupnih Obsidian naredbi IDs (koristite sa `obsidian_execute_command`).                           |
| `obsidian_sync_status`       | status OmniRoute servera za sinkronizaciju: radi, ime trezora, port, vrijeme rada, zadnja sinkronizacija. |
| `obsidian_sync_conflicts`    | Popis neriješenih sukoba sinkronizacije (put, put sukoba, detektirano-at).                                |

### Alati za pisanje (`write:obsidian`)

| Alat                             | Opis                                                                                                   |
| -------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `obsidian_write_note`            | Stvorite ili prebrišite bilješku s danim Markdown sadržajem.                                           |
| `obsidian_append_note`           | Dodavanje sadržaja bilješci; izborno na određeni heading/block.                                        |
| `obsidian_patch_note`            | Kirurški append/prepend/replace na polju naslova, bloka ili prednjeg materijala.                       |
| `obsidian_delete_note`           | Trajno brisanje bilješke iz trezora.                                                                   |
| `obsidian_move_note`             | Premjestite ili preimenujte bilješku unutar trezora.                                                   |
| `obsidian_execute_command`       | Izvršite Obsidian naredbu njenom naredbom ID.                                                          |
| `obsidian_open_file`             | Otvorite datoteku u Obsidian (stvara je ako ne postoji).                                               |
| `obsidian_sync_trigger`          | Pokreni trenutnu dvosmjernu sinkronizaciju ↔ mobilnog trezora za radnu površinu.                       |
| `obsidian_sync_resolve_conflict` | Riješite sukob sinkronizacije: zadržite `local` (mobilno), `remote` (stolno računalo) ili `keep-both`. |

> [!NOTE]
> `obsidian_patch_note` ciljevi prihvaćaju `targetType` od `heading | block | frontmatter` i `operation` od `append | prepend | replace`, uz izborni `createTargetIfMissing`. Četiri `obsidian_sync_*` alata razgovaraju s lokalnim poslužiteljem za sinkronizaciju (`http://127.0.0.1:27781` prema zadanim postavkama) i zahtijevaju token za sinkronizaciju.

### Opsezi

Alati za čitanje zahtijevaju `read:obsidian`; alati za pisanje zahtijevaju `write:obsidian`. Provedba je identična Notion — kojom rukuje `withScopeEnforcement()` u `open-sse/mcp-server/server.ts`, zatvorena na `OMNIROUTE_MCP_ENFORCE_SCOPES=true` i prisilno uključena za HTTP/SSE pozivatelje čiji API ključ nema `manage`/`admin`, s dopuštenim opsezima izvorno iz `OMNIROUTE_MCP_SCOPES` ili konteksta opsega API ključa. Vidi [MCP-SERVER.md](./MCP-SERVER.md).

## Krajnje točke

| Metoda   | Putanja                         | Svrha                                                                   |
| -------- | ------------------------------- | ----------------------------------------------------------------------- |
| `GET`    | `/api/settings/obsidian`        | Vraća `{ connected, hasToken, baseUrl, vaultPath }`.                    |
| `POST`   | `/api/settings/obsidian`        | Sprema i provjerava token (odbija port `27124`).                        |
| `DELETE` | `/api/settings/obsidian`        | Prekida vezu (briše spremljeni token).                                  |
| `GET`    | `/api/settings/obsidian/webdav` | Status sinkronizacije putem WebDAV-a i vjerodajnice (dok je omogućena). |
| `POST`   | `/api/settings/obsidian/webdav` | Omogućuje sinkronizaciju putem WebDAV-a za direktorij trezora.          |
| `DELETE` | `/api/settings/obsidian/webdav` | Onemogućuje sinkronizaciju putem WebDAV-a.                              |

> Ovo su rute postavki nadzorne ploče. Samom se trezoru pristupa putem lokalnog REST API-ja
> Obsidiana (konfiguriranog `base_url`) i putem gore navedenih MCP alata — ne postoji
> javna krajnja točka Obsidian proxyja `/v1`.

## Slučajevi upotrebe

- **Odgovori utemeljeni na trezoru** — `obsidian_search_simple` / `obsidian_search_structured`,
  a zatim `obsidian_read_note`, kako bi agent odgovarao na temelju vaših stvarnih bilješki.
- **Pisanje bilješki / vođenje dnevnika** — `obsidian_write_note`, `obsidian_append_note` ili
  precizni `obsidian_patch_note` za zapisivanje rezultata rada agenta, sažetaka ili dnevnih bilješki
  (`obsidian_get_periodic_note`) u trezor.
- **Navigacija trezorom** — `obsidian_list_vault`, `obsidian_get_document_map` i
  `obsidian_get_tags` za istraživanje strukture prije čitanja/pisanja.
- **Automatizacija Obsidiana** — `obsidian_list_commands` + `obsidian_execute_command` za
  pokretanje dodataka/naredbi putem agenta; `obsidian_open_file` za prikaz bilješke u korisničkom sučelju.
- **Mobilna sinkronizacija** — omogućite sinkronizaciju putem WebDAV-a, a zatim upotrijebite `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`
  za koordinaciju između stolnog i mobilnog uređaja te rješavanje sukoba.
