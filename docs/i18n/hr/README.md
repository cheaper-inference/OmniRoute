## Besplatni tokeni mjesečno: ~ 11,3B koliko drugi broje · ~ 90M Real

</div>

> **~ 11,3B besplatnih tokena mjesečno**<br/> <sub> je računao na način na koji drugi katalozi broje: svaki red je zbrojen, završene ponude uključene </sub>
>
> **~ 90M stvarno danas**<br/> <sub> svaka dijeljena kvota se broji jednom: što zapravo možete koristiti </sub>
>
> **Ovdje je sve besplatno. Nema paywalla.**<br/> ★ [Sviđa vam se? Zvjezdica nas na GitHub](https://github.com/cheaper-inference/OmniRoute)

Drugi katalozi naplaćuju od US 19 $ godišnje do US 49 $ za doživotni pristup podacima uživo. Ovdje je sve besplatno. <sub> Cijene provjerene 2026-11-18.</sub>

<sub>Posljednja revizija kataloga 2026-11-23. [Kako brojimo →](docs/reference/FREE_TIERS.md#how-we-count)</sub>

>
> Ručno slaganje besplatnih razina znači desetke SDKs, desetke ograničenja stope i nema jasne ideje o tome što vam preostaje. OmniRoute čuva 214 redaka kataloga s besplatnim pristupom i izračunava stvarnu brojku iz 12 skupova s objavljenom kvotom, pri čemu se svaki zajednički skup broji jednom. Ono što je ostalo prikazuje se na kontrolnoj ploči (`/dashboard/free-tiers`).

## Instalirajte, povežite davatelja usluga, zatim usmjerite kroz jednu krajnju točku

<img src="./docs/diagrams/works-zero-config.svg" width="100%" alt="Four steps to use OmniRoute. Install with npm install -g omniroute, run omniroute, connect a provider and create an API key in the dashboard, then call http://localhost:20128/v1 with model auto."/>

```bash
# After connecting a provider, create your OmniRoute key in Dashboard → API Keys:
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer YOUR_OMNIROUTE_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"auto","messages":[{"role":"user","content":"Hello!"}]}'
```

<sub>`auto` treba odgovarajuću rutu. Nova instalacija ne može imati prihvatljive ciljeve bez ključa, a pružatelj usluga bez ključa može odbiti klijente treće strane. Pružatelji označeni `tos: avoid`, uključujući Kiro, isključeni su iz automatskog usmjeravanja prema zadanim postavkama; povezivanje računa ne poništava tu postavku. Prije odabira pružatelja pogledajte [Vodič za besplatne razine](docs/getting-started/FREE-TIERS-GUIDE.md).</sub>

## Kombinacije: vodeći

1. **Počnite sa `auto`.** Postavite model u vašem OpenAI-kompatibilnom klijentu. OmniRoute gradi virtualnu kombinaciju od povezanih pružatelja usluga i ocjenjuje kandidate uživo.
2. **Spremite kombinaciju za veću kontrolu.** Odaberite ime, ciljni popis i strategiju, a zatim upotrijebite to ime kao model. Strategija određuje koja će meta biti prva i kako će se isprobati ostali.

Kombinacija automatski usmjerava modele. U slučaju iscrpljenosti kvote, kvara pružatelja ili zaključavanja modela, pokušava sa sljedećim prihvatljivim, zdravim ciljem.

### Zero-config: samo koristite `auto`

```bash
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <your-omniroute-key>" \
  -H "Content-Type: application/json" \
  -d '{"model": "auto", "messages": [{"role": "user", "content": "Hello"}]}'
```

Varijante ugađaju težine. Zadnje poznato dobro usmjeravanje ostaje kod zadnjeg uspješnog pružatelja dok ne zakaže, a zatim se ponovno ocjenjuje. `auto/fast` i `auto/cheap` izražavaju preferencije bez jamstva najbržeg ili najjeftinijeg modela.

| Model ID            | Ponašanje                                                                                                                                                                                                                                                                                      |
| :------------------ | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `auto`              | Uravnotežene zadane težine.                                                                                                                                                                                                                                                                    |
| `auto/fast`         | Favorizira nisku latenciju i zdravlje pružatelja usluga.                                                                                                                                                                                                                                       |
| `auto/cheap`        | Prednost ima niže kataloške cijene.                                                                                                                                                                                                                                                            |
| `auto/coding`       | Ponderi kvalitete na prvom mjestu za generiranje koda.                                                                                                                                                                                                                                         |
| `auto/smart`        | Težine na prvom mjestu kvalitete s 10% istraživanja (zadano 5%).                                                                                                                                                                                                                               |
| `auto/lkgp`         | Eksplicitno zadnje poznato dobro usmjeravanje s istim težinama kao `auto`.                                                                                                                                                                                                                     |
| `auto/subscription` | Koristi samo uživo potvrđenu kvotu plana. Vraća HTTP 503 kada nijedan nije dostupan i izbjegava naplaćenu zamjenu.                                                                                                                                                                             |
| `auto/thrifty`      | Planirajte → bez ključa → besplatno → jeftino → premium. Može dosegnuti naplaćene modele i vratiti se na plan kada to dopuste kvota i hlađenje.                                                                                                                                                |
| `auto/offline`      | Favorizira prostor za kvotu i ograničenje brzine. Zahtjevi i dalje idu vašim pružateljima usluga.                                                                                                                                                                                              |
| `auto/chaos`        | Jedan model po pružatelju paralelno, do pet prema zadanim postavkama ili deset kada je konfigurirano. Jedan uzvodni poziv po modelu. Vraća najbolje rangirani odgovor ili zadnji uspješni odgovor panela ako vrhunski model ne uspije. Koristite `fusion` za sintetiziranje odgovora sa sucem. |

Primjeri kategorija i izbornih razina uključuju `auto/coding:fast`, `auto/coding:free`, `auto/reasoning:pro` i `auto/vision`. Ako se nijedan povezani kandidat ne podudara, zahtjev vraća HTTP 503 i skup ostaje uzak. [Auto-Combo vodič](./docs/routing/AUTO-COMBO.md) · [Pretplatničko usmjeravanje](./docs/routing/SUBSCRIPTION_LADDER.md)

```bash
omniroute combo create my-pool --strategy fill-first \

```

### Otpornost je ugrađena u: 3 neovisna sloja

Kvarovi se rješavaju u tri opsega, tako da jedan loš model ne skida svoj račun, a jedan loš račun ne skida svog davatelja.

<img src="./docs/diagrams/resilience-layers.svg" width="100%" alt="OmniRoute resilience: 3 independent self-healing layers, the right layer for the right failure. Layer 1, provider circuit breaker (whole provider): trips only on 408/500/502/503/504, opens after 8 failures for OAuth providers or 12 for API-key providers, resets after 60s or 30s into a HALF-OPEN probe, lazy recovery; while OPEN the combo reroutes to the next provider. Layer 2, connection cooldown (one key or account): base 5s OAuth or 3s API-key, exponential backoff with an anti-thundering-herd guard, success clears the error state; one cooling key is skipped while sibling keys keep serving. Layer 3, model lockout (one model): per-model 429, 404 or access denials lock just that model, never the whole connection. Terminal states (banned, expired, credits exhausted) wait for the operator; they are not cooldowns."/>

#### Ako cijeli pružatelj ne radi

The** osigurač prekidač** otvara se nakon 8 (OAuth) ili 12 (API ključ) kvarova sa statusom 408, 500, 502, 503 ili 504. Kombinacije preskaču tog pružatelja dok je otvoren. Nakon 60 s ili 30 s, jedan zahtjev sonde odlučuje hoće li se zatvoriti.

#### Ako je jedan ključ ili račun ograničen stopom

The** hlađenje veze** klupe samo tu vezu, s eksponencijalnim odmakom od 5 s (OAuth) ili 3 s (tipka API ). Drugi ključevi za istog davatelja nastavljaju posluživati.

#### Ako se jedan model odbije

The** zaključavanje modela** blokira samo taj model na toj vezi nakon 429, 404 po modelu ili odbijanja pristupa. Drugi modeli na istoj vezi nastavljaju posluživati.

Zabranjene, istekle veze i veze bez kredita terminalna su stanja, a ne hlađenja: čekaju da ih popravite.

## Puni CLI, MCP i A2A

> OmniRoute isporučuje klijenta naredbenog retka** 91 naredbe najviše razine i grupe naredbi** (754 naredbe računajući podnaredbe), an**MCP server sa 110 alata i 33 opsega** , i an**A2A agent sa 6 vještina** . Skripte, terminali i AI agenti mogu upravljati istim pristupnikom.

### Pravi CLI, ne samo `start`

```bash
omniroute                 # start the gateway and dashboard (port 20128)
omniroute setup           # guided first-run wizard
omniroute repl            # interactive chat in the terminal (/model /combo /skill /memory)
omniroute chat "hello"    # one-shot prompt; also reads --file or --stdin
omniroute doctor          # check config, database, ports, Node runtime and native deps
```

Globalna zastavica `--output table|json|jsonl|csv` čini iste naredbe upotrebljivima iz skripti i CI.

### Udaljeni način rada: CLI na vašem prijenosnom računalu, OmniRoute na poslužitelju

Prijavite se jednom na udaljeni poslužitelj. CLI ga sprema kao a** kontekst** , a kasnije se naredbe pokreću protiv tog poslužitelja dok se ne vratite natrag.

```bash
omniroute connect omniroute.example.com          # asks for the password, saves a scoped token as a context
omniroute models                                 # runs against the remote server
omniroute configure codex                        # picks a remote model, writes a local Codex profile
omniroute tokens create --name ci --scope read   # mint a narrower token for another machine
omniroute contexts use default                   # switch back to the local server
```

| Opseg tokena | <img width="2000" height="0" alt=""> Što dopušta                             |
| ------------ | ---------------------------------------------------------------------------- |
| `read`       | Navedite i pregledajte: modele, status, zapisnike, korištenje                |
| `write`      | `read` plus konfigurirati i primijeniti: postavke klijenta, ključevi, konfig |
| `admin`      | `write` plus upravlja: tokenima, pružateljima, uslugama, politikom           |

Goli host dobiva `http://` i port 20128; proći puni `https://` URL kada poslužitelj sjedi iza TLS. Rute koje mogu pokrenuti procese ostaju samo povratne petlje, bez obzira na token.

| MCP preko SSE             | `/api/mcp/sse`             | Klijenti koji još uvijek koriste SSE transport                                      |
| A2A otkriće               | `/.well-known/agent.json`  | Kartica agenta: govori drugim agentima što OmniRoute može učiniti                   |
| A2A izvršenje             | `POST /a2a`                | JSON-RPC 2.0 zadaci, sinkroni ili strujani preko SSE, kroz 6 vještina               |
| REST API                  | `/v1/*`                    | Chat kompatibilan s OpenAI-jem, odgovori, ugradnje, slike, zvuk i OCR               |
| Web-dojavice              | `/api/webhooks`            | Događaji za Slack, Discord, Telegram ili bilo koji URL s potpisom HMAC              |
| Daljinski CLI             | `omniroute connect <host>` | Upravljajte udaljenom instancom s ograničenim pristupnim tokenima                   |

Šest A2A vještina su `smart-routing`, `quota-management`, `provider-discovery`, `cost-analysis`, `health-report` i `list-capabilities`.

**Prije povezivanja:**

- **MCP preko HTTP počinje onemogućeno.** Uključite ga pomoću `omniroute mcp enable --transport streamable-http` ili na stranici Krajnje točke nadzorne ploče. Jedan HTTP prijenos je aktivan u jednom trenutku: `streamable-http` služi `/api/mcp/stream`, `sse` služi `/api/mcp/sse`.
- **A2A počinje onemogućeno.** Omogućite ga na stranici Krajnje točke nadzorne ploče. `POST /a2a` tada slijedi ista pravila API ključa kao `/v1`.
- **Daljinski MCP treba odgovarajući ključ.** `/api/mcp/*` prema zadanim postavkama odgovara samo povratnoj petlji. S drugog hosta pošaljite ključ sa `manage` ili `admin` (svi alati), ili sa `mcp:connect` plus opseg alata koji su vam potrebni. Za ključeve bez `manage`/`admin`, opseg alata se uvijek primjenjuje.

```bash

omniroute mcp enable --transport streamable-http
claude mcp add --transport http omniroute http://localhost:20128/api/mcp/stream \
  --header "Authorization: Bearer <api-key-with-manage-scope>"
```

## Uštedite 15–95% tokena — automatski

### Kako to radi — cjevovod, arhitektura i matematika ušteda

<img src="./docs/diagrams/compression-pipeline.svg" width="100%" alt="OmniRoute compression pipeline: an illustrative 10,000-token client request passes through 12 composable engines — Session-Dedup, CCR, Lite, RTK, Responses Tool Output, Headroom, Relevance, Caveman, Aggressive, LLMLingua-2, Ultra and OmniGlyph — and can reach the provider at about 1,080 tokens in the documented stacked example. Structured content is protected by preservation guards and per-step fidelity gates; explicit lossy or experimental modes may transform eligible content."/>

Zadana složena kombinacija pokreće `RTK → Caveman`. Kada oboje djeluju na isti tool/context korisni teret, ušteda se sastoji od:

```txt
combined = 1 − (1 − RTK) × (1 − Caveman_input)
average  = 1 − (1 − 0.80) × (1 − 0.46) = 89.2%
range    = 78.4 – 94.6%
```

Blokovi koda, URLs, JSON i strukturirani podaci su** uvijek zaštićeni** motorom za očuvanje.

> **Zašto koristiti mnogo tokena kada malo tokena čini trik?** Svaki zahtjev prolazi kroz OmniRoute kompresijski cjevovod** prozirno** — nema promjena klijenta. Sada je a** hrpa od 12 kompozitnih motora** koji rade redom i miješaju se i usklađuju po kombinaciji usmjeravanja — na temelju ideja iz [RTK](https://github.com/rtk-ai/rtk), [Caveman](https://github.com/JuliusBrussee/caveman) (⭐ 90K +), [LLMLingua-2](https://github.com/microsoft/LLMLingua) i [Troglodita](https://github.com/leninejunior/troglodita) (PT-BR).

## Više instalacijskih metoda — Docker, izvor, pnpm, Arch

**🐳 Docker**

```bash
docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 \
  -p 127.0.0.1:20128:20128 -v omniroute-data:/app/data cheaperinference/omniroute:latest
```

`:latest` slijedi najviše** objavljeno** stabilan SemVer. Ne prati git `main`. Prikvači `:X.Y.Z` za GitOps. Pogledajte [kanale izdanja Docker](docs/guides/DOCKER_GUIDE.md#release-channels). Pribadače slike**`OMNIROUTE_MEMORY_MB=1024`** . To je dovoljno za nadzornu ploču i lagani razgovor.** Agenti za kodiranje** (`POST /v1/responses` iz Claude koda, Codex, Grok, …) trebaju mnogo veću hrpu V8 ili proces `FATAL ERROR` s na ~ 12 GiB pod dva preklapajuća duga konteksta. Odredite veličinu spremnika iznad hrpe (nativni međuspremnici nalaze se izvan V8):

| <img width="2000" height="0" alt=""> opterećenje | hrpa (`-e OMNIROUTE_MEMORY_MB`) | Spremnik (`--memory`) |
| ------------------------------------------------ | ------------------------------- | --------------------- |
| Nadzorna ploča / lagani chat                     | `1024` (zadana slika)           | ≥ 2 g                 |
| Jedan agent za kodiranje                         | `8192`                          | ≥ 10 g                |
| Dva istovremena duga `/v1/responses`             | `10240`–`12288`                 | ≥ 12-16 g             |

```bash
docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 \
  -e OMNIROUTE_MEMORY_MB=8192 --memory=10g \
  -p 127.0.0.1:20128:20128 -v omniroute-data:/app/data cheaperinference/omniroute:latest
```

[Vodič](contrib/podman/README.md)📖 Podman — Compose builds, Podman Machine i postavljanje Linux/systemd Quadleta.

**⚡ Brža/jednostavnija instalacija (preskoči izvornu verziju)**

Izvorni SQLite motor (`better-sqlite3`) je an** neobavezan** ovisnost, tako da globalna instalacija nikada ne blokira kompajliranje iz izvora: koristi unaprijed izgrađenu binarnu datoteku kada odgovara vašem platform/Node, au suprotnom se transparentno vraća na čisti JS mehanizam (`node:sqlite` na čvoru 22 +, inače paket `sql.js` WASM) — nisu potrebni alati za izgradnju.

Za preskakanje naknadne instalacije** nativno zagrijavanje** u potpunosti (CI, bezglavi ili spori strojevi). Napomena: ovo preskače samo izvorni SQLite korak zagrijavanja (`scripts/postinstall.mjs`); binary-copy/repair kuka (`scripts/build/postinstall.mjs`) i dalje radi normalno:

```bash
OMNIROUTE_SKIP_POSTINSTALL=1 npm install -g omniroute   # CI=1 also skips it
```

Za najbrže instalacije prednost** pnpm** (sadržajno adresirana trgovina + tvrde veze — vidi gore). Za bezglavo izvođenje bez nadzorne ploče koristite Docker `base` profil (iznad) ili [Termux vodič](docs/guides/TERMUX_GUIDE.md). CLI i web nadzorna ploča poslužuju se istim procesom na jednom portu, tako da danas ne postoji zasebni paket samo za CLI.

### Kako doprinijeti

1. Račvajte spremište
2. Podružnica iz** aktivan** `release/vX.Y.Z` savjet (ne `main`) — vidi [model grananja i otpuštanja](docs/ops/BRANCHING_MODEL.md)
3. Napravite granu svoje značajke (`git checkout -b feat/amazing-feature`)
4. Obavijestite svoje promjene (`git commit -m 'feat: add amazing feature'`)
5. Gurni do grane (`git push origin feat/amazing-feature`)
6. Otvorite zahtjev za povlačenje pomoću** baza = ta `release/vX.Y.Z` grana**

Pogledajte [CONTRIBUTING.md](CONTRIBUTING.md) za detaljne smjernice.

```bash
# Create a release — npm publish happens automatically
VERSION=x.y.z
gh release create "v${VERSION}" --title "v${VERSION}" --generate-notes
```
