Ընդհանուր մատակարարներ.** 381 թ** . Տես ստորև կատեգորիայի բաժանումը:

## Կատեգորիաներ

- **Անվճար** — API բանալիով անվճար մակարդակ (կարգավորվում է կառավարման վահանակի միջոցով)
- **Առանց նույնականացման** — հանրային վերջնակետեր, որոնք ընդհանրապես բանալի կամ մուտք չեն պահանջում
- **OAuth** — մուտքի գործընթացը մշակվում է OmniRoute-ի կողմից, API բանալի անհրաժեշտ չէ
- **Վեբ cookie** — cookie-ով նույնականացման միջոցով փաթաթում է պրովայդերի վեբ հավելվածը
- **API բանալի** — վճարովի պրովայդեր, որը կարգավորվում է API բանալիով (կարող են տրամադրվել անվճար կրեդիտներ)
- **Տեղային** — աշխատում է օգտատիրոջ համակարգչում (Ollama, LM Studio, vLLM և այլն)
- **Որոնում** — վեբ որոնման պրովայդերներ
- **Աուդիո** — միայն աուդիոյի համար նախատեսված պրովայդերներ (TTS/STT)
- **Վերադաս պրոքսի** — պրովայդերներ, որոնք հարցումները փոխանցում են այլ պրովայդերների
- **Ամպային գործակալ** — երկարատև աշխատող ծրագրավորման գործակալներ (Codex Cloud, Devin, Jules)
- **Համակարգային** — OmniRoute-ի ներքին պրովայդերներ (loopback և այլն)

Լրացուցիչ պիտակներ՝ `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`։

`Գործիքների կանչում` (որտեղ նշված է)՝ `native` — գործառույթների կանչման իրական API, `emulated` — `tools` զանգվածը նմանակվում է հուշման միջոցով՝ `webTools.ts`-ի օգնությամբ (regex-ով վերլուծվող `<tool>{...}</tool>` բլոկներ), `none` — ներկայումս `tools`-ը լուռ անտեսվում է։ Տե՛ս #7286։

Յուրաքանչյուր պրովայդեր միացնելու, կարգավորելու և փորձարկելու համար օգտագործեք `/dashboard/providers` հասցեի կառավարման վահանակը։
