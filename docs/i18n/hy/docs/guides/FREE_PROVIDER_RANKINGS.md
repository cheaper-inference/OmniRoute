> **Կարճ ասած**․ OmniRoute-ը դասակարգում է իր **անվճար** մատակարարներին ըստ մոդելների որակի՝ օգտագործելով **Arena AI-ի
> (LMArena-ի ոճով) ELO միավորները**։ Վահանակում բացեք **Անվճար մատակարարների դասակարգում** էջը՝ տեսնելու, թե որ անվճար մատակարարներն են առաջարկում ձեր առաջադրանքի համար ամենաուժեղ մոդելները՝
> ընդհանուր առմամբ կամ ըստ կատեգորիայի զտված (կոդավորում, վերանայում, փաստաթղթավորում, վրիպազերծում)։

## Ինչ է սա

OmniRoute-ը գրանցում է 376 մատակարար, ներառյալ **անվճար/առանց նույնականացման** նշումով 155 կատալոգային գրառում
(առանց նույնականացման,
անվճար մակարդակի OAuth կամ անվճար մակարդակի API բանալի — տե՛ս
[Անվճար մակարդակների ուղեցույցը](../getting-started/FREE-TIERS-GUIDE.md) և ամբողջական
[Անվճար մակարդակների ցանկը](../reference/FREE_TIERS.md))։ Սակայն անվճար մատակարարների
մոդելների որակը խիստ տարբերվում է։ Առանց նույնականացման մատակարարը, որն առաջարկում է
առաջատար մոդել, շատ ավելի օգտակար է, քան փոքր, հնացած մոդել առաջարկողը։

**Անվճար մատակարարների վարկանիշները** պատասխանում է «**ո՞ր անվճար մատակարարն է ինձ առաջարկում լավագույն մոդելը**» հարցին՝
յուրաքանչյուր անվճար մատակարարի կատալոգը համադրելով **օգտատերերի համատեղ գնահատումներով ձևավորված որակի միավորների** հետ՝ վերցված
**Arena AI առաջատարների աղյուսակից** (մարդկային նախապատվությունների վրա հիմնված ELO՝ նույն գաղափարը, որն ընկած է LMArena
չատբոտների արենայի հիմքում)։ Այնուհետև մատակարարները դասակարգվում են ըստ իրենց **լավագույն անվճար մոդելի** հզորության։

Վարկանիշը հաշվարկվում է երեք իրական աղբյուրներից՝

1. Անվճար մատակարարների ցուցակները՝ `NOAUTH_PROVIDERS`, ինչպես նաև `OAUTH_PROVIDERS` /
   `APIKEY_PROVIDERS` գրառումները, որոնք նշված են `hasFree` դրոշակով
   (`src/shared/constants/providers.ts`)։
2. Յուրաքանչյուր մատակարարի մոդելների կատալոգը՝ մատակարարների ռեեստրից
   (`open-sse/config/providerRegistry.ts`)։
3. ELO-ից ստացված՝ առաջադրանքին համապատասխանության միավորները, որոնք Arena ELO համաժամացման շարժիչը պահպանում է `model_intelligence` տվյալների բազայի աղյուսակում
   (`src/lib/arenaEloSync.ts`)։

Համադրման տրամաբանությունը գտնվում է `src/lib/freeProviderRankings.ts` ֆայլում։

## Ինչպես մուտք գործել

### Վահանակի էջը

Բացեք վահանակը և անցեք **Ծախսեր → Անվճար մատակարարների դասակարգում** բաժին կամ անմիջապես անցեք հետևյալ հասցեով՝

```
/dashboard/free-provider-rankings
```

Էջը (`src/app/(dashboard)/dashboard/free-provider-rankings/page.tsx`) ցուցադրում է՝

- Լավագույն դասակարգված անվճար մատակարարների **առաջին եռյակի պատվանդանը** (🥇 🥈 🥉)։
- Ամբողջական **դասակարգման աղյուսակ**՝ հետևյալ սյունակներով․ **Դիրք**, **Մատակարար**, **Լավագույն մոդել**,
  **Միավոր**, **Միջին միավոր**, **Մոդելներ**, **Տեսակ**։
- **Կատեգորիաների զտիչ կոճակներ**՝ _Բոլոր կատեգորիաները_, _Լռելյայն_, _Կոդավորում_, _Վերանայում_,
  _Փաստաթղթավորում_, _Վրիպազերծում_։

Յուրաքանչյուր մատակարարի **Տեսակ** նշանը ցույց է տալիս, թե ինչ եղանակով է այն անվճար՝

| Նշան     | Նշանակություն                                                 |
| -------- | ------------------------------------------------------------- |
| `NOAUTH` | Միշտ անվճար է, հավատարմագրեր չեն պահանջվում                   |
| `OAUTH`  | Անվճար մակարդակով OAuth մատակարար (`hasFree`)                 |
| `APIKEY` | Անվճար մակարդակով API բանալի օգտագործող մատակարար (`hasFree`) |

Միավորները ցուցադրվում են մարդկանց համար ընթեռնելի պիտակներով (օրինակ՝ _Էլիտար_, _Գերազանց_, _Շատ լավ_,
_Լավ_, _Միջին_), այլ ոչ թե չմշակված թվերով, քանի որ հիմքում ընկած արժեքը հարաբերական
որակական դասակարգում է, ոչ թե տոկոսային ցուցանիշ։

### API վերջնակետ

Էջը հիմնված է հրապարակային ընթերցման վերջնակետի վրա
(`src/app/api/free-provider-rankings/route.ts`)՝

```
GET /api/free-provider-rankings
GET /api/free-provider-rankings?category=coding
GET /api/free-provider-rankings?category=coding&limit=20
```

Հարցման պարամետրերը (վավերացվում են Zod-ի միջոցով)՝

| Պարամետր   | Տեսակ  | Լռելյայն | Նշումներ                                                                                                                          |
| ---------- | ------ | -------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `category` | string | (չկա)    | `default`, `coding`, `review`, `documentation`, `debugging` տարբերակներից մեկը։ Բաց թողեք՝ համակցված դասակարգումն ստանալու համար։ |
| `limit`    | number | `50`     | Սահմանափակվում է `1–100` միջակայքով։                                                                                              |

Պատասխանի կառուցվածքը՝

```json
{
  "rankings": [
    {
      "id": "<provider-id>",
      "name": "<provider name>",
      "icon": "<icon>",
      "color": "<hex color>",
      "textIcon": "<short label>",
      "category": "noauth | oauth | apikey",
      "topModel": {
        "modelId": "<registry model id>",
        "modelName": "<model display name>",
        "score": 0.0,
        "eloRaw": 0,
        "confidence": "high | medium | low",
        "category": "<task category>"
      },
      "averageScore": 0.0,
      "modelCount": 0
    }
  ]
}
```

`eloRaw`-ը Arena ELO-ի սկզբնական արժեքն է, իսկ `score`-ը՝ առաջադրանքին համապատասխանության նորմալացված արժեքը
(տե՛ս ստորև)։ Գնահատված մոդելներ չունեցող մատակարարները չեն ներառվում պատասխանում։

## Ինչպես են աշխատում միավորները

### Աղբյուր՝ Arena AI leaderboard

Arena ELO սինք շարժիչը (`src/lib/arenaEloSync.ts`) Arena AI leaderboard API-ից
(`https://api.wulong.dev/arena-ai-leaderboards/v1/leaderboard`) ստանում է երկու առաջատարների
աղյուսակ — `text` և `code`: Երբ այդ API-ն չի վերադարձնում օգտագործելի աղյուսակ, շարժիչը որպես
պահուստային աղբյուր օգտագործում է Hugging Face datasets-server-ի պաշտոնական
`lmarena-ai/leaderboard-dataset` հավաքածուն (`src/lib/arenaEloHfSource.ts`, CC-BY-4.0;
`overall` → `text`, `coding` → `code`). `GET /api/intelligence/sync`-ը հաղորդում է
`activeSource`, `lastError` և `lastFailedAt` դաշտերը: Առաջատարների աղյուսակի յուրաքանչյուր
գրառում պարունակում է մոդելի անուն, արտադրող, ELO `score`, վստահության միջակայք և ձայների քանակ:

Առաջատարների աղյուսակի կատեգորիաները համապատասխանում են OmniRoute առաջադրանքների կատեգորիաներին.

| Arena leaderboard | OmniRoute առաջադրանքների կատեգորիաներ             |
| ----------------- | ------------------------------------------------- |
| `text`            | `default`, `review`, `documentation`, `debugging` |
| `code`            | `coding`                                          |

### Նորմավորում (task-fit միավոր)

Հում ELO միավորները նորմավորվում են յուրաքանչյուր առաջատարների աղյուսակի համար՝ վերածվելով
**task-fit արժեքի `[0.4, 0.98]` միջակայքում**.

```
taskFit = 0.4 + 0.58 * ((elo - minElo) / (maxElo - minElo))
```

Միավորը երբեք չի հասնում `0`-ի կամ `1`-ի՝ թողնելով տարածք օգտատիրոջ կողմից փոփոխումների համար:
Սա `score` դաշտն է, որը դուք տեսնում եք API պատասխանում, և պիտակը, որն ցուցադրվում է
վահանակի վրա:

### Վստահություն

Յուրաքանչյուր գրառում ստանում է վստահության մակարդակ՝ հիմնված Arena-ի ձայների քանակի վրա.

| Վստահություն | Ձայներ  |
| ------------ | ------- |
| `high`       | ≥ 5,000 |
| `medium`     | ≥ 1,000 |
| `low`        | < 1,000 |

### Պահպանում և թարմություն

Նորմավորված գրառումները գրվում են `model_intelligence` տվյալների բազայի աղյուսակում
`source = "arena_elo"` արժեքով (`src/lib/db/modelIntelligence.ts`): Գրառումները **ժամկետանց
են դառնում 7 օր հետո**, այնպես որ մատակարարը, որը դադարում է սինք անել, ի վերջո դուրս է մնում
ցուցակից՝ հնացած տվյալներ մատուցելու փոխարեն:

Սինքը **լռելյայն միացված է**.

- Այն գործարկվում է մեկ անգամ սերվերի մեկնարկի ժամանակ, ապա՝ պարբերական ժամաչափով
  (`src/lib/arenaEloSync.ts`, կապակցված `src/instrumentation-node.ts`-ից):
- Այն **ոչ արգելափակող է և երբեք կրիտիկական չէ** — եթե վերին աղբյուրից տվյալների ստացումը
  ձախողվում է, OmniRoute-ը շարունակում է աշխատել, իսկ վարկանիշները պարզապես ցույց են տալիս
  վերջին հաջողված տվյալները (կամ դատարկ վիճակ):

Այն կառավարվում է երկու միջավայրի փոփոխականներով (փաստաթղթավորված է
[`docs/reference/ENVIRONMENT.md`](../reference/ENVIRONMENT.md)-ում).

| Փոփոխական                 | Լռելյայն         | Նպատակ                                              |
| ------------------------- | ---------------- | --------------------------------------------------- |
| `ARENA_ELO_SYNC_ENABLED`  | `true`           | Սահմանեք `false`՝ ելքային սինքից հրաժարվելու համար: |
| `ARENA_ELO_SYNC_INTERVAL` | `86400` (24 ժամ) | Սինքի պարբերությունը՝ վայրկյաններով:                |

### Ձեռքով սինք / կարգավիճակ / մաքրում

Օպերատորների համար վավերացված կառավարման endpoint-ը տրամադրում է ձեռքով կառավարում
(`src/app/api/intelligence/sync/route.ts` — պահանջում է կառավարման վավերացում).

```
GET    /api/intelligence/sync          # սինքի ընթացիկ կարգավիճակը (enabled, lastSync, nextSync, intervalMs)
POST   /api/intelligence/sync          # ձեռքով սինքի գործարկում. մարմին՝ { "dryRun": true }՝ առանց գրանցման նախադիտման համար
DELETE /api/intelligence/sync          # մաքրել սինք արված բոլոր arena_elo intelligence գրառումները
```

Եթե վարկանիշների էջը դատարկ է, ձեռքով `POST /api/intelligence/sync`-ը (կամ պարզապես սերվերի
վերագործարկումը) կվերալրացնի այն:

### Մոդելների համապատասխանեցում առաջատարների աղյուսակին

Ռեեստրի մոդելի ID-ները և Arena մոդելի անունները միշտ չէ, որ ճշգրիտ համընկնում են: Վարկանիշումն
օգտագործում է ճկուն համապատասխանեցում (`findMatchingIntelligence`՝ `src/lib/freeProviderRankings.ts`-ում).

1. Ճշգրիտ համընկնում նորմավորված մոդելի ID-ի հետ:
2. Համընկնում՝ վերջի տարբերակի վերջածանցի հեռացումից հետո (օր. `kimi-k2.6` → `kimi-k2`):
3. Նախածանցային համընկնում (առաջատարների աղյուսակի մոդելի անունը ռեեստրի ID-ի նախածանցն է):

Սինքի կողմում հայտնի արտադրողի նախածանցները (`anthropic/`, `openai/`, `google/`, …) հեռացվում
են, իսկ փոքր կեղծանունների քարտեզը (alias map) ընդլայնում է կանոնական անունները դեպի այն
տարբերակները, որոնք OmniRoute-ն օգտագործում է ներքուստ, այնպես որ մոդելները որոնելի են մնում
ցանկացած անվան տակ:

### Ինչպես է վարկանիշվում մատակարարը

Յուրաքանչյուր անվճար մատակարարի համար շարժիչը միավոր է տալիս նրա կատալոգի յուրաքանչյուր
մոդելին, ապա՝

- **Top Model** = մատակարարի ամենաբարձր միավոր ունեցող մոդելը:
- **Avg Score** = տվյալ մատակարարի բոլոր միավորված մոդելների միջին միավորը:
- **Models** = մատակարարի քանի՞ մոդել ուներ Arena միավոր:

Մատակարարները տեսակավորվում են նախ՝ **լավագույն մոդելի միավորով**, ապա՝ միջին միավորով: Սա
պարգևատրում է այն մատակարարին, ով առաջարկում է առնվազն մեկ ուժեղ անվճար մոդել:

## Դրա օգտագործումը՝ անվճար մատակարարներ ընտրելու համար

1. **Ընտրեք ճիշտ կատեգորիան։** Գործակալային/կոդային աշխատանքային ծանրաբեռնվածությունների համար օգտագործեք **Coding** զտիչը, իսկ
   ընդհանուր զրույցի համար թողեք **All Categories** / **Default** տարբերակը։ Նույն մատակարարը կարող է
   տարբեր կատեգորիաներում տարբեր դիրք զբաղեցնել, քանի որ դրա լավագույն մոդելը տարբերվում է ըստ վարկանիշային աղյուսակի։
2. **Մեկանգամյա կարգավորումների համար նախապատվությունը տվեք առաջատար եռյակին։** Եթե ցանկանում եք միացնել ընդամենը մեկ կամ երկու անվճար
   մատակարար, սկսեք ձեր կատեգորիայում ամենաբարձր վարկանիշ ունեցողներից։
3. **Ստուգեք Type նշանը։** `NOAUTH` մատակարարներն ամենաարագն են միացվում (առանց
   նույնականացման տվյալների)։ `OAUTH` / `APIKEY` անվճար մակարդակները պահանջում են արագ գրանցում, սակայն հաճախ հասանելի են դարձնում
   ավելի հզոր մոդելներ։ Միացման քայլերի համար տե՛ս [Անվճար մակարդակների ուղեցույցը](../getting-started/FREE-TIERS-GUIDE.md)։
4. **Միացրեք մի քանիսը և թույլ տվեք, որ Auto-Combo-ն որոշի։** Arena ELO-ի նույն տվյալները, որոնցով աշխատում է
   այս էջը, նաև տրամադրվում են Auto-Combo գնահատման շարժիչի **առաջադրանքին համապատասխանության գործոնին**
   (`open-sse/services/autoCombo/taskFitness.ts`, որոշման հերթականությունը՝
   `user_override → arena_elo → models_dev_tier → static table`)։ Այսպիսով, լավագույն անվճար մատակարարները միացնելուց
   հետո `model: "auto"`-ով երթուղավորումը (օրինակ՝ `auto/coding`) յուրաքանչյուր հարցման համար
   ինքնաբերաբար նախապատվություն կտա ավելի բարձր որակի անվճար մոդելներին։ 16 գործոնով ամբողջական գնահատման մասին տե՛ս
   [Auto-Combo](../routing/AUTO-COMBO.md) բաժինը։
