> (LMArena-ի ոճով) ELO միավորները**։ Վահանակում բացեք **Անվճար մատակարարների դասակարգում** էջը՝ տեսնելու, թե որ անվճար մատակարարներն են առաջարկում ձեր առաջադրանքի համար ամենաուժեղ մոդելները՝
> ընդհանուր առմամբ կամ ըստ կատեգորիայի զտված (կոդավորում, վերանայում, փաստաթղթավորում, վրիպազերծում)։

**free/no-auth** (առանց ավտորիզացիայի, անվճար մակարդակի OAuth կամ անվճար մակարդակի API
բանալի — տե՛ս
[Անվճար մակարդակների ուղեցույցը](../getting-started/FREE-TIERS-GUIDE.md) և
[Անվճար մակարդակների](../reference/FREE_TIERS.md) ամբողջական տեղեկատուն): Բարդությունն այն
է, որ անվճար մատակարարների մոդելների որակը մեծապես տարբերվում է: Առանց ավտորիզացիայի
մատակարարը, որն առաջարկում է առաջատար մոդել, շատ ավելի օգտակար է, քան այն մատակարարը, որն
առաջարկում է փոքր, հնացած մոդել:

**Անվճար մատակարարների վարկանիշները** պատասխանում են «**ո՞ր անվճար մատակարարն է ինձ
տրամադրում լավագույն մոդելը**» հարցին՝ միավորելով յուրաքանչյուր անվճար մատակարարի
կատալոգը **Arena AI leaderboard**-ից ստացված **համայնքի կողմից հավաքված որակի
գնահատականների** հետ (մարդկային նախապատվության ELO — նույն գաղափարը, որն ընկած է LMArena
chatbot arena-ի հիմքում): Այնուհետև մատակարարները դասակարգվում են իրենց **լավագույն անվճար
մոդելի** հզորության համաձայն:

Վարկանիշը հաշվարկվում է երեք իրական աղբյուրներից՝

1. Անվճար մատակարարների ցանկերից — `NOAUTH_PROVIDERS`, ինչպես նաև `OAUTH_PROVIDERS` /
   `APIKEY_PROVIDERS` գրառումներից, որոնք նշված են `hasFree` դրոշակով

## Ինչպես մուտք գործել

### Վահանակի էջը

Բացեք վահանակը և անցեք **Ծախսեր → Անվճար մատակարարների դասակարգում** բաժին կամ անմիջապես անցեք հետևյալ հասցեով՝

```
/dashboard/free-provider-rankings
```

Էջը (`src/app/(dashboard)/dashboard/free-provider-rankings/page.tsx`) ցուցադրում է՝

- Լավագույն դասակարգված անվճար մատակարարների **առաջին եռյակի պատվանդանը** (🥇 🥈 🥉)։
- Ամբողջական **դասակարգման աղյուսակ**՝ հետևյալ սյունակներով․ **Դիրք**, **Մատակարար**, **Լավագույն մոդել**,
  **Միավոր**, **Միջին միավոր**, **Մոդելներ**, **Տեսակ**։
- **Կատեգորիաների զտիչ կոճակներ**՝ _Բոլոր կատեգորիաները_, _Լռելյայն_, _Կոդավորում_, _Վերանայում_,
  _Փաստաթղթավորում_, _Վրիպազերծում_։

Յուրաքանչյուր մատակարարի **Տեսակ** նշանը ցույց է տալիս, թե ինչ եղանակով է այն անվճար՝

| Նշան     | Նշանակություն                                                 |
| -------- | ------------------------------------------------------------- |
| `NOAUTH` | Միշտ անվճար է, հավատարմագրեր չեն պահանջվում                   |
| `OAUTH`  | Անվճար մակարդակով OAuth մատակարար (`hasFree`)                 |
| `APIKEY` | Անվճար մակարդակով API բանալի օգտագործող մատակարար (`hasFree`) |

Միավորները ցուցադրվում են մարդկանց համար ընթեռնելի պիտակներով (օրինակ՝ _Էլիտար_, _Գերազանց_, _Շատ լավ_,
_Լավ_, _Միջին_), այլ ոչ թե չմշակված թվերով, քանի որ հիմքում ընկած արժեքը հարաբերական
որակական դասակարգում է, ոչ թե տոկոսային ցուցանիշ։

### API վերջնակետ

Էջը հիմնված է հրապարակային ընթերցման վերջնակետի վրա
(`src/app/api/free-provider-rankings/route.ts`)՝

```
GET /api/free-provider-rankings
GET /api/free-provider-rankings?category=coding
GET /api/free-provider-rankings?category=coding&limit=20
```

Հարցման պարամետրերը (վավերացվում են Zod-ի միջոցով)՝

| Պարամետր   | Տեսակ  | Լռելյայն | Նշումներ                                                                                                                          |
| ---------- | ------ | -------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `category` | string | (չկա)    | `default`, `coding`, `review`, `documentation`, `debugging` տարբերակներից մեկը։ Բաց թողեք՝ համակցված դասակարգումն ստանալու համար։ |
| `limit`    | number | `50`     | Սահմանափակվում է `1–100` միջակայքով։                                                                                              |

Պատասխանի կառուցվածքը՝

```json
{
  "rankings": [
    {
      "id": "<provider-id>",
      "name": "<provider name>",
      "icon": "<icon>",
      "color": "<hex color>",
      "textIcon": "<short label>",
      "category": "noauth | oauth | apikey",
      "topModel": {
        "modelId": "<registry model id>",
        "modelName": "<model display name>",
        "score": 0.0,
        "eloRaw": 0,
        "confidence": "high | medium | low",
        "category": "<task category>"
      },
      "averageScore": 0.0,
      "modelCount": 0
    }
  ]
}
```

`eloRaw`-ը Arena ELO-ի սկզբնական արժեքն է, իսկ `score`-ը՝ առաջադրանքին համապատասխանության նորմալացված արժեքը
(տե՛ս ստորև)։ Գնահատված մոդելներ չունեցող մատակարարները չեն ներառվում պատասխանում։

## Ինչպես են աշխատում միավորները

### Աղբյուր՝ Arena AI առաջատարների ցանկ

Arena ELO համաժամեցման մեխանիզմը (`src/lib/arenaEloSync.ts`) ստանում է երկու առաջատարների ցանկ՝ `text`
և `code`, Arena AI առաջատարների ցանկի API-ից
(`https://api.wulong.dev/arena-ai-leaderboards/v1/leaderboard`): Երբ այդ API-ն չի վերադարձնում
օգտագործելի ցանկ, մեխանիզմն անցում է կատարում պաշտոնական `lmarena-ai/leaderboard-dataset`-ին՝
Hugging Face datasets-server-ում (`src/lib/arenaEloHfSource.ts`, CC-BY-4.0; `overall` → `text`,
`coding` → `code`); `GET /api/intelligence/sync`-ը հաղորդում է `activeSource`, `lastError` և
`lastFailedAt` արժեքները։ Առաջատարների ցանկի յուրաքանչյուր գրառում
պարունակում է մոդելի անուն, արտադրող, ELO `score`, վստահության միջակայք և ձայների քանակ։

Առաջատարների ցանկի կատեգորիաները համապատասխանում են OmniRoute առաջադրանքների կատեգորիաներին․

| Arena առաջատարների ցանկ | OmniRoute առաջադրանքների կատեգորիաներ             |
| ----------------------- | ------------------------------------------------- |
| `text`                  | `default`, `review`, `documentation`, `debugging` |
| `code`                  | `coding`                                          |

### Նորմալացում (առաջադրանքի համապատասխանության միավոր)

Հում ELO միավորները նորմալացվում են յուրաքանչյուր առաջատարների ցանկի համար՝ վերածվելով **`[0.4, 0.98]` միջակայքում գտնվող առաջադրանքի համապատասխանության արժեքի**.

```
taskFit = 0.4 + 0.58 * ((elo - minElo) / (maxElo - minElo))
```

Միավորն երբեք չի հասնում `0`-ի կամ `1`-ի՝ թողնելով ազատ տարածություն օգտատիրոջ վերասահմանումների համար։ Սա այն
`score` դաշտն է, որը դուք տեսնում եք API-ի պատասխանում, և պիտակը, որ ցուցադրվում է վահանակում։

### Վստահություն

Յուրաքանչյուր գրառում ստանում է վստահության մակարդակ՝ հիմնված Arena-ի ձայների քանակի վրա․

| Վստահություն | Ձայներ  |
| ------------ | ------- |
| `high`       | ≥ 5,000 |
| `medium`     | ≥ 1,000 |
| `low`        | < 1,000 |

### Պահպանում և թարմություն

Նորմալացված գրառումները գրվում են `model_intelligence` DB աղյուսակում՝
`source = "arena_elo"` արժեքով (`src/lib/db/modelIntelligence.ts`)։ Գրառումների **ժամկետը լրանում է
7 օր հետո**, այնպես որ համաժամեցումը դադարեցնող մատակարարը ի վերջո դուրս է մնում ցանկից՝
այլ ոչ թե մատուցելով հնացած տվյալներ։

Համաժամեցումը **լռելյայնորեն միացած է**․

- Այն աշխատում է մեկ անգամ սերվերի մեկնարկի ժամանակ, ապա՝ պարբերական ժամանակացույցով
  (`src/lib/arenaEloSync.ts`, միացված `src/instrumentation-node.ts`-ից)։
- Այն **ոչ արգելափակող է և երբեք վթարային չէ**․ եթե վերևի աղբյուրից ստացումը ձախողվում է, OmniRoute-ը շարունակում է
  աշխատել, իսկ վարկանիշները պարզապես ցույց են տալիս վերջին հաջողված տվյալները (կամ դատարկ վիճակ)։

Այն կառավարվում է երկու միջավայրի փոփոխականներով (փաստաճղթավորված է
[`docs/reference/ENVIRONMENT.md`](../reference/ENVIRONMENT.md)-ում)․

| Փոփոխական                 | Լռելյայն      | Նպատակ                                                      |
| ------------------------- | ------------- | ----------------------------------------------------------- |
| `ARENA_ELO_SYNC_ENABLED`  | `true`        | Սահմանեք `false`՝ ելքային համաժամեցումից հրաժարվելու համար։ |
| `ARENA_ELO_SYNC_INTERVAL` | `86400` (24ժ) | Համաժամեցման միջակայքը՝ վայրկյաններով։                      |

### Ձեռքով համաժամեցում / կարգավիճակ / մաքրում

Օպերատորների համար վավերացված կառավարման վերջակետը տրամադրում է ձեռքով կառավարում
(`src/app/api/intelligence/sync/route.ts` — պահանջում է կառավարման վավերացում)․

```
GET    /api/intelligence/sync          # ընթացիկ համաժամեցման կարգավիճակը (enabled, lastSync, nextSync, intervalMs)
POST   /api/intelligence/sync          # գործարկել ձեռքով համաժամեցում; մարմին՝ { "dryRun": true }՝ առանց գրանցման նախադիտման համար
DELETE /api/intelligence/sync          # մաքրել բոլոր համաժամեցված arena_elo հետախուզության գրառումները
```

Եթե վարկանիշների էջը դատարկ է, ձեռքով `POST /api/intelligence/sync`-ը (կամ պարզապես
սերվերի վերագործարկումը) կվերալցնի այն։

### Մոդելների համապատասխանեցում առաջատարների ցանկին

Գրանցամատյանի մոդելի ID-ները և Arena մոդելների անունները միշտ չէ, որ ճշգրիտ համընկնում են։ Վարկանիշումն
օգտագործում է ճկուն համապատասխանեցում (`findMatchingIntelligence` `src/lib/freeProviderRankings.ts`-ում)․

1. Ճշգրիտ համընկնում նորմալացված մոդելի ID-ի հետ։
2. Համընկնում վերջի տարբերակի վերջածանցը հեռացնելուց հետո (օր. `kimi-k2.6` → `kimi-k2`)։
3. Նախածանցի համընկնում (առաջատարների ցանկի մոդելի անունը գրանցամատյանի ID-ի նախածանցն է)։

Համաժամեցման կողմում հայտնի արտադրողի նախածանցները (`anthropic/`, `openai/`, `google/`, …)
հեռացվում են, իսկ մականունների փոքր քարտեզը կանոնական անունները վերածում է այն տարբերակների, որոնք OmniRoute-ն
օգտագործում է ներքինորեն, այնպես որ մոդելները մնում են գտնելի ցանկացած անվան տակ։

### Ինչպես է դասակարգվում մատակարարը

Յուրաքանչյուր անվճար մատակարարի համար մեխանիզմը միավորում է նրա կատալոգի յուրաքանչյուր մոդել, ապա․

- **Լավագույն մոդել** = մատակարարի ամենաբարձր միավոր ունեցող մոդելը։
- **Միջին միավոր** = միջին միավորը մատակարարի բոլոր միավորված մոդելների համար։
- **Մոդելներ** = մատակարարի քանի մոդելն ուներ Arena միավոր։

Մատակարարները դասավորվում են նախ **լավագույն մոդելի միավորով**, ապա միջին միավորով։ Սա շահավետ է դարձնում
այն մատակարարին, որն առաջարկում է առնվազն մեկ ուժեղ անվճար մոդել։

## Դրա օգտագործումը՝ անվճար մատակարարներ ընտրելու համար

1. **Ընտրեք ճիշտ կատեգորիան։** Գործակալային/կոդային աշխատանքային ծանրաբեռնվածությունների համար օգտագործեք **Coding** զտիչը, իսկ
   ընդհանուր զրույցի համար թողեք **All Categories** / **Default** տարբերակը։ Նույն մատակարարը կարող է
   տարբեր կատեգորիաներում տարբեր դիրք զբաղեցնել, քանի որ դրա լավագույն մոդելը տարբերվում է ըստ վարկանիշային աղյուսակի։
2. **Մեկանգամյա կարգավորումների համար նախապատվությունը տվեք առաջատար եռյակին։** Եթե ցանկանում եք միացնել ընդամենը մեկ կամ երկու անվճար
   մատակարար, սկսեք ձեր կատեգորիայում ամենաբարձր վարկանիշ ունեցողներից։
3. **Ստուգեք Type նշանը։** `NOAUTH` մատակարարներն ամենաարագն են միացվում (առանց
   նույնականացման տվյալների)։ `OAUTH` / `APIKEY` անվճար մակարդակները պահանջում են արագ գրանցում, սակայն հաճախ հասանելի են դարձնում
   ավելի հզոր մոդելներ։ Միացման քայլերի համար տե՛ս [Անվճար մակարդակների ուղեցույցը](../getting-started/FREE-TIERS-GUIDE.md)։
4. **Միացրեք մի քանիսը և թույլ տվեք, որ Auto-Combo-ն որոշի։** Arena ELO-ի նույն տվյալները, որոնցով աշխատում է
   այս էջը, նաև տրամադրվում են Auto-Combo գնահատման շարժիչի **առաջադրանքին համապատասխանության գործոնին**
   (`open-sse/services/autoCombo/taskFitness.ts`, որոշման հերթականությունը՝
   `user_override → arena_elo → models_dev_tier → static table`)։ Այսպիսով, լավագույն անվճար մատակարարները միացնելուց
   հետո `model: "auto"`-ով երթուղավորումը (օրինակ՝ `auto/coding`) յուրաքանչյուր հարցման համար
   ինքնաբերաբար նախապատվություն կտա ավելի բարձր որակի անվճար մոդելներին։ 16 գործոնով ամբողջական գնահատման մասին տե՛ս
   [Auto-Combo](../routing/AUTO-COMBO.md) բաժինը։
