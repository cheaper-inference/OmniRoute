Տեղադրեք OmniRoute վահանակը որպես առաջադեմ վեբ հավելված՝ այն բացելու ձեր հիմնական էկրանից կամ աշխատասեղանից անկախ պատուհանում: Տեղադրված հավելվածը դեռևս կարիք ունի կապի ձեր OmniRoute սերվերին՝ նավիգացիայի, վահանակի տվյալների և API հարցումների համար: Քեշավորված ստատիկ ակտիվները չեն ապահովում անցանց դարպաս կամ անցանց վահանակ:

## Ի՞նչ է PWA:

Պրոգրեսիվ վեբ հավելվածն օգտագործում է վեբ վահանակը՝ հավելվածի պատկերակով և առանձին պատուհանով: Տեղադրվելուց հետո OmniRoute:

- Գործարկում է ձեր հիմնական էկրանից կամ աշխատասեղանից
- Բացվում է ինքնուրույն ռեժիմում՝ առանց դիտարկիչի սովորական հասցեագոտու և ներդիրների
- Քեշում է ընտրված ստատիկ ակտիվները
- Աջակցում է դիմանկարային և լանդշաֆտային կողմնորոշումներին

## Տեղադրում

Օգտագործեք HTTPS հասցե այլ սարքի սերվերի համար: Երբ սերվերն աշխատում է նույն սարքի վրա, `http://localhost:20128` նաև համապատասխանում է բրաուզերի տեղադրման պահանջներին: Պարզ `http://YOUR_IP:20128` հասցեն չի համապատասխանում այդ պահանջներին: Տեղադրման ընտրացանկերը և հրահանգները կախված են դիտարկիչից և օպերացիոն համակարգից: Տես [MDN- ի PWA տեղադրման պահանջները](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable#https_localhost_or_loopback_are_required) :

### Android (Chrome)

1. Բացեք ձեր OmniRoute HTTPS հասցեն կամ `http://localhost:20128` սերվերի համար նույն հեռախոսով:
2. Բացեք**⋮** մենյու և ընտրեք** Տեղադրեք հավելվածը** կամ** Ավելացնել հիմնական էկրանին** , եթե առաջարկվի։
3. Հաստատեք հուշումը:
4. Բացեք OmniRoute հիմնական էկրանից:

### iOS (Safari)

1. Բացեք ձեր OmniRoute HTTPS հասցեն Safari-ում:
2. Հպեք** Կիսվել** →** Ավելացնել հիմնական էկրանին** .
3. Հաստատեք անունը և հպեք** Ավելացնել** .
4. Բացեք OmniRoute հիմնական էկրանից:

### Աշխատասեղան (Chrome / Edge)

1. Բացեք ձեր OmniRoute վահանակը:
2. Օգտագործեք բրաուզերի տեղադրման պատկերակը կամ** Տեղադրեք հավելվածը** ցանկի մուտքագրում, եթե առաջարկվում է:
3. Հաստատեք OmniRoute իր սեփական պատուհանում բացելու հուշումը:

## Առանձնահատկություններ

### Անկախ պատուհան

Մանիֆեստը սահմանում է `display: "standalone"` և `start_url: "/dashboard"`: Տեղադրված հավելվածը բացում է վահանակը հավելվածի պատուհանում: Դիտարկիչի և օպերացիոն համակարգի վերահսկիչները դեռ կարող են հայտնվել. մանիֆեստը չի պահանջում լիաէկրան ռեժիմ:

### Քեշավորված ակտիվներ և ցանցի պահանջներ

[Ծառայության աշխատողը](../../public/sw.js) պահում է ընտրված նույն ծագման ռեսուրսները.

| Հարցում կամ ակտիվ                            | Ռազմավարություն | Վարքագիծ                                                                                                              |
| -------------------------------------------- | --------------- | --------------------------------------------------------------------------------------------------------------------- |
| Տեղադրման ժամանակի ռեսուրսներ                | Նախնական քեշ    | `/`, `/manifest.webmanifest`, `/icon-512.png` և `/apple-touch-icon.png` պահվում են աշխատողների տեղադրման ժամանակ      |
| Next.js ստատիկ ակտիվներ (`/_next/`)          | Ցանցը՝ առաջինը  | Հաջող պատասխանները թարմացնում են քեշը; ցանցի սխալը վերադառնում է գոյություն ունեցող քեշավորված պատասխանին             |
| Այլ ստատիկ CSS, JS, պատկերներ և տառատեսակներ | Cache-նախ       | Գոյություն ունեցող քեշավորված պատասխանը կրկին օգտագործվում է. ցանցի հաջող պատասխանները պահվում են բաց թողնված ժամանակ |
| Էջի նավարկություն                            | Շրջանցում       | Զննարկիչը ուղղակիորեն վերցնում է էջը. անցանց հետադարձ կապ չի մատուցվում                                               |
| API, վահանակ և նույնականացման երթուղիներ     | Շրջանցում       | Աշխատողը չի գաղտնալսում կամ պահում է այդ հարցումները                                                                  |
| Այլ ոչ ստատիկ հարցումներ                     | Ցանց            | Քեշի որոնում կամ պահեստավորում չկա                                                                                    |

Բացառված երթուղիներն են `/api`, `/a2a`, `/dashboard`, `/v1`, `/v1beta`, `/models`, `/chat`, `/responses`, `/codex`, `/callback` և `/login`, որոնք համընկնում են ուղու սահմաններում տառերի անզգայուն կերպով: Խաչաձև ծագման և ոչ GET հարցումները նույնպես շրջանցում են աշխատողին:

### Միացման էջ

`/offline` էջը տրամադրում է կապի հաղորդագրություն, online/offline ցուցիչ, ա** Կրկին փորձեք միացումը** կոճակ և հղում դեպի կարգավիճակի էջի: Դա է** նախապես պահված չէ** իսկ սպասարկողն անում է** ոչ** վերահղել ձախողված նավարկությունները դրան: Դրա գոյությունը նոր էջերը հասանելի չի դարձնում առանց սերվերի:

### Հավելվածի պատկերակներ

Մանիֆեստը գովազդում է այս PNG պատկերակները.

| Ֆայլ                   | Չափը    | Օգտագործեք                               |
| ---------------------- | ------- | ---------------------------------------- |
| `icon-192.png`         | 192×192 | Ընդհանուր հավելվածի պատկերակ             |
| `icon-512.png`         | 512×512 | Ընդհանուր և դիմակավոր հավելվածի պատկերակ |
| `apple-touch-icon.png` | 180×180 | Apple-ի հիմնական էկրանի պատկերակը        |

Զննարկիչը ընտրում է տեղադրման թիրախի համապատասխան պատկերակը:

### Ավտոմատ գրանցում

`PwaRegister` գրանցում է աշխատողին արտադրության մեջ, երբ զննարկիչը աջակցում է սպասարկման աշխատողներին: Զարգացման ռեժիմը չգրանցում է աշխատողներին և մաքրում է պահոցները, որպեսզի չխանգարեն հնացած ակտիվները թեժ վերաբեռնմանը: Տեղադրման հուշումները մնում են դիտարկիչի որոշում:

## Տեխնիկական ճարտարապետություն

### Վեբ հավելվածի մանիֆեստ

Next.js առաջացնում է `/manifest.webmanifest` [`src/app/manifest.ts`](../../src/app/manifest.ts) ից: Դրա հիմնական պարամետրերն են.

| Կարգավորում            | Արժեք                                             |
| ---------------------- | ------------------------------------------------- |
| `short_name`           | `OmniRoute`                                       |
| `start_url`            | `/dashboard`                                      |
| `scope`                | `/`                                               |
| `display`              | `standalone`                                      |
| `orientation`          | `any`                                             |
| Ֆոնի և թեմայի գույները | Նախնական լուսային գունապնակ `PWA_THEME_COLORS` ից |

Մանիֆեստի անունը և նկարագրությունը ստատիկ արժեքներ են այդ սկզբնաղբյուր ֆայլում: Տեղադրված մանիֆեստը չի հետևում օրինակի անվան կարգավորումներին կամ ակտիվ գունապնակին ամեն այցելության ժամանակ:

### Սպասարկման աշխատող

[`public/sw.js`](../../public/sw.js) չունի սպասարկող աշխատողի շրջանակային կախվածություն.

- **Տեղադրել:** նախապես պահում է վերը թվարկված չորս ռեսուրսները և ակտիվացնում նոր աշխատողին:
- **Ակտիվացնել.** հեռացնում է հին քեշի սերունդները և պահանջում հաճախորդներին:
- **Բերել:** կիրառում է ստատիկ ակտիվների ռազմավարությունները և վերը նշված երթուղիների բացառումները:
- **Տարբերակում՝** աղբյուրի քեշի անունը `omniroute-pwa-v3` է; արտադրության կառուցումը նշում է քեշի ինքնությունը:
- **Ծանուցումներ.** կառավարում է `push` մուտքային իրադարձությունները և կենտրոնացնում կամ բացում է պատուհանը, երբ սեղմվում է ծանուցումը:

Միայն Push իրադարձությունների մշակողները չեն ստեղծում ակտիվ push բաժանորդագրություն կամ կազմաձևված սերվերի առաքում: Մի ենթադրեք, որ ծանուցումները միացված են զուտ այն պատճառով, որ PWA տեղադրված է:

### Դասավորության մետատվյալներ և գրանցում

[`src/app/layout.tsx`](../../src/app/layout.tsx) տրամադրում է մանիֆեստի հղումը, Apple-ի առանձին մետատվյալները, թեմայի գույները և `viewport-fit: cover`: Էջի անվանումը և Apple վեբ հավելվածի անվանումը օգտագործում են օրինակի անվանումը: Զննարկչի կենդանի թեմայի գույնը հետևում է ներկապնակին. տեղադրման մանիֆեստն օգտագործում է լռելյայն բաց գույնը:

[`PwaRegister`](../../src/shared/components/PwaRegister.tsx) աշխատում է հաճախորդի վրա և գրանցում `/sw.js` իր URL ում build ID ով: Այն հայտնաբերում է քեշի անհամապատասխան սերունդները և կարող է վերակայել աշխատողին և մեկ անգամ վերբեռնել՝ հին տեղադրումից հետո վերականգնելու համար: Գրանցման ձախողումը չի արգելափակում վահանակը:

## Օգտագործեք Termux-ի հետ (Android)

1. Սկսեք OmniRoute Termux-ում՝ `npx -y omniroute@latest`:
2. Բացեք Chrome-ը նույն հեռախոսում՝ `http://localhost:20128`:
3. Տեղադրեք PWA բրաուզերի տեղադրման ընտրացանկի միջոցով:
4. Պահպանեք Termux սերվերը աշխատատեղից օգտվելիս:

Հեռախոսը հյուրընկալում է և՛ դարպասը, և՛ դրա վահանակը: Հեռավոր AI մատակարարներին ուղղված հարցումները դեռևս կարիք ունեն ցանցի հասանելիության: Տեղադրման և Android գործընթացի կյանքի տեւողության նկատառումների համար տե՛ս [Termux ուղեցույցը](TERMUX_GUIDE.md) :

## Օգտագործեք այլ սարքերից

Բացեք սերվերի HTTPS հասցեն հեռախոսի, պլանշետի կամ աշխատասեղանի վրա, այնուհետև հետևեք այդ բրաուզերի տեղադրման ընթացքին: Սերվերը պետք է հասանելի մնա յուրաքանչյուր սարքից: Հեռակա մուտքի տարբերակների համար տե՛ս [թունելի ուղեցույցը](../ops/TUNNELS_GUIDE.md) :

## Անհատականացում

### Օրինակի անվանումը

Այն** Օրինակի անվանումը** կարգավորումը փոխում է վահանակի մետատվյալները, ներառյալ էջի անվանումը և Apple-ի վեբ հավելվածի անվանումը: Ստեղծված մանիֆեստն օգտագործում է ստատիկ անուն, ուստի այս կարգավորումը չի երաշխավորում, որ արդեն տեղադրված հավելվածը վերանվանվի:

### Պատվերով Favicon

Հատուկ ֆավիկոնը փոխում է դիտարկիչի ֆավիկոնը: Տեղադրման մանիֆեստը դեռ գովազդում է վերևում գտնվող PNG ֆայլերը. Favicon-ը փոխելը չի փոխարինում հիմնական էկրանի այդ պատկերակներին:

## Սահմանափակումներ

- **Պահանջվում է սերվերի միացում.** Էջի նավիգացիան, վահանակի վիճակը և API հարցումները չունեն անցանց հետադարձ կապ:
- **Ֆոնային համաժամացում չկա՝** օֆլայն գործողությունները հերթագրված չեն կրկնվելու համար:
- **Բրաուզերի տարբերությունները.** տեղադրման ընտրացանկերը, պատուհանների ներկայացումը և ծանուցման աջակցությունը տարբերվում են ըստ հարթակի:
- **API պատասխանի քեշ չկա.** աշխատողը բացառում է API, վահանակը և նույնականացման երթուղիները:
- **Ստատիկ տեղադրման պատկերակներ.** այդ պատկերակների թարմացումը պահանջում է գովազդվող ակտիվների փոփոխություն. բրաուզերները կարող են պահպանել տեղադրված մետատվյալները:
