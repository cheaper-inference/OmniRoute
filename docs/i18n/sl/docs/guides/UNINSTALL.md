Ta priročnik opisuje, kako čisto odstraniti OmniRoute iz vašega sistema.

## Razveljavi konfiguracijo odjemalca

Odstranjevalnik ustavi proces OmniRoute, ki ga upravlja PM2, če je prisoten, in pusti konfiguracijo odjemalca na mestu. Odjemalci, ki še vedno kažejo na OmniRoute izgubijo povezavo, ko se prekine. Popolna odstranitev izbriše tudi podatkovni imenik, privzeto `~/.omniroute`, skupaj z varnostnimi kopijami konfiguracije odjemalca.

### 1. Uporabite nadzorno ploščo, medtem ko OmniRoute deluje

Odpri** koda CLI** (`/dashboard/cli-code`) na nadzorni plošči in poiščite** koda Claude** kartico.** Prijavite se** piše v datoteko z nastavitvami kode Claude gostitelja OmniRoute, privzeto `~/.claude/settings.json`. Če imate varnostno kopijo pred uporabo nastavitev OmniRoute, odprite** Varnostne kopije** in ga obnovite. V nasprotnem primeru izberite** Ponastavi** za odstranitev nastavitev prehoda iz `env`. Najprej uporabite in ponastavite varnostno kopijo obstoječe datoteke. Varnostne kopije so shranjene pod `<DATA_DIR>/backups`.

Če `CLI_ALLOW_CONFIG_WRITES=false` ali nadzorna plošča nista na voljo, ročno razveljavite datoteko. Če se OmniRoute izvaja v Docker in odjemalec deluje na gostitelju, razveljavite konfiguracijo gostitelja. Datoteke v nemontiranem domačem vsebniku ne vplivajo na gostiteljskega odjemalca.

### 2. Ročno razveljavite preostale spremembe

Za kodo Claude preverite `~/.claude/settings.json`, `settings.json` v `CLAUDE_CONFIG_DIR`, če je nastavljen, in `.claude/settings.json` projekta. Reset odstrani naslednje ključe iz `env`. Odstranite vrednosti, ki ste jih dodali za OmniRoute, ali obnovite prejšnje vrednosti.

- `"ANTHROPIC_BASE_URL"`, `"ANTHROPIC_AUTH_TOKEN"` in `"ANTHROPIC_API_KEY"`
- `"ANTHROPIC_DEFAULT_OPUS_MODEL"`, `"ANTHROPIC_DEFAULT_SONNET_MODEL"` in `"ANTHROPIC_DEFAULT_HAIKU_MODEL"`
- `"API_TIMEOUT_MS"`

Reset pusti `ANTHROPIC_MODEL` v `env` in nastavitve `model` in `apiKeyHelper` na najvišji ravni na mestu. Odstranite ali obnovite jih ročno, če izberejo model OmniRoute ali poverilnico. Nehajte uporabljati kateri koli profil OmniRoute, ki ga je ustvaril `omniroute setup-claude` pod `~/.claude/profiles/<name>/`, ali povrnite njegov `settings.json`. Ukaz za nastavitev zapiše profil, ne da bi spremenil privzeto datoteko z nastavitvami ali shranil žeton. Odstranite ali obnovite ustrezne izvoze v zagonskih datotekah lupine in počistite stare vrednosti iz trenutne lupine. `omniroute launch` in `omniroute run claude` nastavita prehod URL in žeton samo za podrejeni proces.

Za Codex obnovite prejšnjega ponudnika in model v `~/.codex/config.toml`, če vsebuje `model_provider = "omniroute"`. Odstranite `[model_providers.omniroute]`, če je bil dodan za ta prehod. Obnovite ali odstranite `openai_base_url`, če kaže na OmniRoute. Za odjemalce, združljive z OpenAI, obnovite ali počistite `OPENAI_BASE_URL` kjer koli ga nastavite za OmniRoute.

### 3. Preverite, ali odjemalec deluje z ustavljenim OmniRoute

Preverite privzete nastavitve kode Claude in trenutno okolje lupine.

```bash
grep -n ANTHROPIC ~/.claude/settings.json
env | grep ANTHROPIC
```

Nobeno preverjanje ne bi smelo pokazati, da `ANTHROPIC_BASE_URL` kaže na OmniRoute. Če uporabljate nastavitve profila ali projekta, preverite tudi te datoteke. Ko je OmniRoute ustavljen in je vaša običajna avtentikacija obnovljena, neposredno zaženite kodo Claude.

```bash
claude -p "say hello"
```

Koda Claude bi se morala odzvati z obnovljeno konfiguracijo. Če še vedno kaže na ustavljeni prehod, zahteva ne uspe z napako pri povezavi.

## Hitra odstranitev (v3.6.2 +)

> Najprej [razveljavite konfiguracijo odjemalca](#revert-client-configuration), medtem ko OmniRoute še deluje.

OmniRoute ponuja dva vgrajena skripta za čisto odstranitev:

### Hranite svoje podatke

```bash
npm run uninstall
```

To odstrani aplikacijo OmniRoute vendar** konzerve** vašo bazo podatkov, konfiguracije, ključe API in nastavitve ponudnika v `~/.omniroute/`. To uporabite, če nameravate pozneje znova namestiti in želite obdržati nastavitev.

### Popolna odstranitev

```bash
npm run uninstall:full
```

S tem odstranite aplikacijo** in trajno izbriše** vsi podatki:

- Baza podatkov (`storage.sqlite`)
- Konfiguracije ponudnika in ključi API
- Varnostne kopije datotek
- Dnevniške datoteke
- Vse datoteke v imeniku `~/.omniroute/`

> ⚠️** Opozorilo:** `npm run uninstall:full` je nepovraten. Vse vaše povezave ponudnika, kombinacije, ključi API in zgodovina uporabe bodo trajno izbrisani.

## Ročna odstranitev

> Najprej [razveljavite konfiguracijo odjemalca](#revert-client-configuration), medtem ko OmniRoute še deluje.

### Globalna namestitev NPM

```bash
# Remove the global package
npm uninstall -g omniroute

# (Optional) Remove data directory
rm -rf ~/.omniroute
```

### pnpm Globalna namestitev

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# Stop and remove the container
docker stop omniroute
docker rm omniroute

# Remove the volume (deletes all data)
docker volume rm omniroute-data

# (Optional) Remove the image
docker rmi cheaperinference/omniroute:latest
# Older installs pulled the legacy name:
docker rmi diegosouzapw/omniroute:latest
```

### Docker Sestavi

```bash
# Stop and remove containers
docker compose down

# Also remove volumes (deletes all data)
docker compose down -v
```

### namizna aplikacija Electron

**Windows:**

- Odprite `Settings → Apps → OmniRoute → Uninstall`
- Ali pa zaženite program za odstranjevanje NSIS iz namestitvenega imenika

**macOS:**

- Povlecite `OmniRoute.app` iz `/Applications` v koš
- Odstrani podatke: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- Odstranite datoteko AppImage
- Odstrani podatke: `rm -rf ~/.omniroute`

### Izvorna namestitev (klon git)

```bash
# Remove the cloned directory
rm -rf /path/to/omniroute

# (Optional) Remove data directory
rm -rf ~/.omniroute
```

## Podatkovni imeniki

OmniRoute privzeto shranjuje podatke na naslednjih mestih:

| Platforma        | Privzeta pot                  | Preglasitev                              |
| ---------------- | ----------------------------- | ---------------------------------------- |
| Linux            | `~/.omniroute/`               | okoljska spremenljivka `DATA_DIR`        |
| macOS            | `~/.omniroute/`               | okoljska spremenljivka `DATA_DIR`        |
| Windows          | `%APPDATA%/omniroute/`        | okoljska spremenljivka `DATA_DIR`        |
| Docker           | `/app/data/` (vpeti nosilec)  | okoljska spremenljivka `DATA_DIR`        |
| Združljivo z XDG | `$XDG_CONFIG_HOME/omniroute/` | okoljska spremenljivka `XDG_CONFIG_HOME` |

### Datoteke v podatkovnem imeniku

| Datoteka/imenik      | Opis                                                                  |
| -------------------- | --------------------------------------------------------------------- |
| `storage.sqlite`     | Glavna podatkovna zbirka (ponudniki, kombinacije, nastavitve, ključi) |
| `storage.sqlite-wal` | Dnevnik vnaprejšnjega zapisovanja SQLite (začasno)                    |
| `storage.sqlite-shm` | Deljeni pomnilnik SQLite (začasno)                                    |
| `call_logs/`         | Arhivi vsebin zahtev                                                  |
| `backups/`           | Samodejne varnostne kopije podatkovne zbirke                          |
| `log.txt`            | Podedovani dnevnik zahtev (izbirno)                                   |

## Preverjanje popolne odstranitve

Po odstranitvi preverite, ali ni ostala nobena datoteka:

```bash
# Preverite globalni paket npm
npm list -g omniroute 2>/dev/null

# Preverite podatkovni imenik
ls -la ~/.omniroute/ 2>/dev/null

# Preverite izvajajoče se procese
pgrep -f omniroute
```

Če se kateri koli proces še vedno izvaja, ga ustavite:

```bash
pkill -f omniroute
```
