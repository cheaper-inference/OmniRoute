> Stikala med izvajanjem, ki spreminjajo vedenje sistema OmniRoute **brez ponovne uvedbe**.
> Vsaka tukaj navedena zastavica je opredeljena v datoteki
> [`src/shared/constants/featureFlagDefinitions.ts`](../../src/shared/constants/featureFlagDefinitions.ts)
> — edinem viru resnice. Nadzorna plošča in REST API podatke bereta iz
> te datoteke, zato je spodnja tabela ustvarjena tako, da se z njo ujema v razmerju 1 : 1.

---

## Kaj so funkcijske zastavice

Funkcijska zastavica je poimenovano stikalo (logična vrednost ali naštevanje), katerega vrednost je mogoče spremeniti med
izvajanjem in trajno shraniti v podatkovni zbirki, ne da bi bila potrebna ponovna uvedba procesa. Vsaka
zastavica je opisana z objektom `FeatureFlagDefinition`, ki vsebuje `key`, `label`,
`description`, `category`, `defaultValue`, `type` in namig `requiresRestart`.

### Vrstni red razreševanja

**Dejanska vrednost** zastavice se razreši s funkcijo
[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) po naslednjem
prednostnem vrstnem redu (višja prednost prevlada):

1. **Preglasitev v podatkovni zbirki** — vrednost, shranjena v tabeli `key_value` v imenskem prostoru
   `feature_flags` (nastavljena prek nadzorne plošče ali REST API-ja).
2. **Okoljska spremenljivka** — `process.env[<KEY>]`, če je nastavljena in ni prazna.
3. **Privzeta vrednost definicije** — `defaultValue` iz datoteke `featureFlagDefinitions.ts`.

Logična zastavica se šteje za **omogočeno**, kadar je njena dejanska vrednost `"true"`,
`"1"` ali `"yes"` (glejte `isFeatureFlagEnabled()`).

> [!NOTE]
> Večina zastavic ima tudi ustrezno okoljsko spremenljivko z **enakim imenom**,
> dokumentirano v datoteki [`ENVIRONMENT.md`](./ENVIRONMENT.md). Preglasitev zastavice v podatkovni zbirki
> ima prednost pred to okoljsko spremenljivko. Zastavica z
> `requiresRestart: true` se takoj trajno shrani, vendar se znova prebere šele ob
> zagonu procesa — njen preklop na nadzorni plošči prikaže pasico **»Ponovno zaženi strežnik«**.

Ko je omogočeno, se tudi druge nedokončne diagnoze (dvoumne napake, nepodprte sonde in netipizirane napake razporejevalnika) obravnavajo kot neznane, kar omogoča promet. Privzeto izklopljeno: druge predpomnjene napake sonde še vedno blokirajo pošiljanje za predpomnilnik TTL (5 minut). |

> [!NOTE]
> `INPUT_SANITIZER_BLOCK_THRESHOLD` in njegov podedovani vzdevek `INJECTION_GUARD_BLOCK_THRESHOLD` prilagodita način `block` za `INJECTION_GUARD_MODE`, vendar sta navadni spremenljivki okolja, ki jih bere [`src/shared/utils/injectionSeverity.ts`](../../src/shared/utils/injectionSeverity.ts), in ne zastavice funkcij: nimata preglasitve DB in preklopa na nadzorni plošči. Glej [`ENVIRONMENT.md`](./ENVIRONMENT.md#4-security--authentication).

> [!NOTE]
> Stolpec `Restart` označuje zastavice z `requiresRestart: true` — vrednost se ohrani takoj, vendar začne veljati šele po ponovnem nalaganju procesa. Zastavice enum zavračajo katero koli vrednost zunaj njihovega dovoljenega nabora (potrjeno na strežniški strani v `setFeatureFlagOverride()` in REST `PUT` handlerju).

## Preklapljanje zastavic

### Nadzorna plošča

Pojdite na** Nadzorna plošča → Nastavitve → Zastavice funkcij** (`/dashboard/settings/feature-flags`). Mreža (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`) podpira:

- **Iskanje** po ključu ali opisu in** filter** po kategoriji (plus sintetični** Zahteva ponovni zagon** pogled).
- A** preklop** za logične zastavice in a** spustni meni** za oznake enum (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`).
- A** značka vira** na zastavico — `DB`, `ENV` ali `DEF` — prikazuje, od kod izvira efektivna vrednost.
- A** Ponastavi** gumb (prikazan samo za zastavice `DB` -sourced ), da opustite preglasitev, in a** Ponastavi vse preglasitve** gumb na dnu.
- A** Ponovno zaženite strežnik** pasica, ko se spremeni zastavica `requiresRestart`.

### REST API

Vse operacije potekajo po eni sami poti: [`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts). Vsaka metoda zahteva overjeno sejo nadzorne plošče (`401` sicer).

Ko je prijava onemogočena (`requireLogin=false`), je pot odprta, razen zaščitenih zastavic: vsaka zastavica v kategoriji Varnost plus `OMNIROUTE_ALLOW_PRIVATE_PROVIDER_URLS`, `OMNIROUTE_ALLOW_LOCAL_PROVIDER_URLS`, `MITM_DISABLE_TLS_VERIFY`, `OMNIROUTE_MCP_ENFORCE_SCOPES` in `SKILLS_SANDBOX_NETWORK_ENABLED` (`isProtectedFeatureFlag()` in `protectedFeatureFlags.ts`). `PUT` na enem od njih in `DELETE`, medtem ko ima eden od njiju preglasitev DB, še vedno potrebuje sejo nadzorne plošče, ključ `manage` -scope API, žeton za dostop `oma_` z obsegom pisanja ali višjim ali žeton CLI ali žeton notranje storitve, poslan iz povratne zanke. Ta niz je širši kot pri prijavi, kjer pot sprejme samo sejo ali ključ `manage` -scope.

#### `GET /api/settings/feature-flags`

Vrne vsako zastavico z njeno dejansko vrednostjo, virom in povzetkom.

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Require API Key",
      "description": "Require an API key for all incoming requests",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... all 121 flags
  ],
  "summary": {
    "total": 121,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

Nastavite ali odstranite posamezno preglasitev. Telo: `{ key: string; value?: string }`. Če izpustite `value`, odstranite preglasitev (obnovitev env / default).

```bash
# Set a DB override
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# Remove the override (no "value")
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

Odziv odmeva z novimi `effectiveValue`/`source`, `previousValue`/ `previousSource` in `requiresRestart`. Neznani ključi in enum vrednosti zunaj obsega so zavrnjeni z `400`.

#### `DELETE /api/settings/feature-flags`

Počisti** vse** DB preglasi naenkrat in obnovi vsako zastavico na njeno env/privzeto vrednost. Vrne `{ cleared: <count>, message: "..." }`.

> [!NOTE]
> Zastavice z `requiresRestart: true` začnejo veljati šele po ponovnem nalaganju procesa. Tok ponovnega zagona nadzorne plošče pokliče `POST /api/restart` in nato anketira `GET /api/health/ping` dokler strežnik ni ponovno zagnan.

## Nadomestna rešitev za prekoračitev proračuna v sili

`OMNIROUTE_EMERGENCY_FALLBACK` (kategorija `runtime`, privzeto `true`) nadzoruje
brezplačno nadomestno pot v sili v
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts).
Ko je omogočena, se zahteve, ki izčrpajo svoj proračun, preusmerijo k brezplačnemu
nadomestnemu ponudniku/modelu, namesto da bi bile takoj neuspešne. Nastavite jo na
`false` (ali `0`) — prek stikala na nadzorni plošči, preglasitve v zbirki podatkov
ali okoljske spremenljivke `OMNIROUTE_EMERGENCY_FALLBACK` — da onemogočite to
vedenje in omogočite, da zahteve z izčrpanim proračunom ne uspejo. (Na nadzorni
plošči je prikazano kot stikalo v zahtevah PR #3741 / #3752.)

Odgovor, posredovan prek te nadomestne rešitve, vsebuje
`X-OmniRoute-Emergency-Fallback: from=<provider/model>; to=<provider/model>`, zato
lahko odjemalec ugotovi, da je bil preusmerjen, ne da bi moral primerjati
`X-OmniRoute-Provider` s svojo zahtevo. Pri vseh drugih odgovorih ta glava ni
prisotna.
