## Kategorije

- **Brezplačno** — brezplačni nivo z API ključem (konfiguriran preko nadzorne plošče)
- **Brez avtentikacije** — javne končne točke, ki ne zahtevajo ključa ali prijave
- **OAuth** — postopek prijave, ki ga obravnava OmniRoute, API ključ ni potreben
- **Spletni piškotek** — ovije spletno aplikacijo ponudnika preko avtentikacije s piškotki
- **API ključ** — plačljiv ponudnik, konfiguriran preko API ključa (lahko veljajo brezplačni krediti)
- **Lokalno** — deluje na uporabnikovem računalniku (Ollama, LM Studio, vLLM itd.)
- **Iskanje** — ponudniki spletnega iskanja
- **Avdio** — samo avdio ponudniki (TTS/STT)
- **Upstream proxy** — ponudniki, ki posredujejo drugim ponudnikom
- **Agent v oblaku** — dolgotrajni kodirni agenti (Codex Cloud, Devin, Jules)
- **Sistem** — notranji ponudniki OmniRoute (povratna zanka itd.)

Dodatne oznake: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Klic orodja` (kjer je prikazano): `native` — pravi API za klicanje funkcij; `emulated` — polje `tools` je emulirano s pozivom preko `webTools.ts` (regex-razčlenjeni bloki `<tool>{...}</tool>`); `none` — `tools` se trenutno tiho opusti. Glejte #7286.

Uporabite nadzorno ploščo na `/dashboard/providers` za omogočanje, konfiguracijo in testiranje vsakega ponudnika.
