`devin-cli-agentic` omogoča, da dejansko izvajalno okolje Claude Code uporablja lokalno
končno točko Anthropic Messages storitve OmniRoute, medtem ko uradni Devin CLI posreduje
odzive modela prek ACP stdio. Ne spreminja obstoječih ponudnikov Anthropic, Claude OAuth,
Claude Web ali `devin-cli`.

Za klice orodij, ki jih upravlja odjemalec, uporabite `devin-cli-agentic` (vzdevek `dva`),
ponudnika v obliki Claude s podporo za orodja. Podedovani izvajalnik ACP `devin-cli` (`dv`)
podpira samo besedilo: izvaja Devinov povzemalnik brez orodij in ne more vračati klicev
orodij. Njegovi metapodatki modela so ustrezno označeni, zato se mu bo kombinirano usmerjanje,
ki zahteva orodja, izognilo.

> **Trenutno stanje: pripeta različica Claude Code `2.1.258`; preverjanje brez povezave in
> preverjanje v živo sta bila nazadnje zabeležena pri različici `2.1.220`.** Pripeta različica
> `2.1.220` je uspešno izvedla tri izolirane scenarije prek Devin CLI `3000.2.17` in modela
> `swe-1-7-lightning`; ta končni preizkus v živo je potrdil korake `Read`, `Edit` in `Bash`,
> ki jih upravlja odjemalec, uspešne rezultate `npm test`, odkrivanje projektnih ukazov in
> veščin, usmerjanje izključno prek Devina ter odsotnost izhodnega prometa do storitve Claude.
> Pripeta različica je bila nato zvišana na `2.1.258` (generacijo CLI-ja, za katero se izdaja
> identiteta Claude storitve OmniRoute, in prvo različico, ki izvorno vključuje raven Fable
> 5.1). Pri novi pripeti različici sta bila na pripeti osnovni sliki preverjena namestitvena
> plast in `claude --version`, uspešno pa se izvedejo tudi zbirka testov enot mostu, `compose
config` in statični dokaz izolacije — vendar lažni scenarij brez povezave in zbirka treh
> scenarijev v živo še nista bila ponovno izvedena. Preden se zanesete na most s to pripeto
> različico, ju ponovno izvedite (glejte »Posodabljanje pripetih orodij«).

## Arhitektura

```text
Claude Code 2.1.258 (izoliran vsebnik Linux brez korenskih pravic)
  -> http://omniroute:20128/v1/messages
  -> devin-cli-agentic (oblika Claude, ponudnik brez preverjanja pristnosti)
  -> devin acp --agent-type summarizer (uradni ACP stdio, brez Devinovih orodij)
  -> račun Devin v namenskem nosilcu devin-auth
```

Privzeti agent ACP uradnega CLI-ja lahko izvaja lastna orodja, zato ga ta most ne uporablja.
Zažene fiksnega agenta ACP `summarizer`, katerega uradni način CLI nima orodij, in serializirano
zahtevo Anthropic oblikuje kot sled izvajanja. Ko je potrebno drugo dejanje, ki ga upravlja
Claude, mora odziv vsebovati natanko eno odjemalčevo ovojnico orodja. Vsak ACP `tool_call` ali
`tool_call_update` je zavrnjen, preden je mogoče odziv označiti kot uspešen.

Serializator v `open-sse/executors/devin-agentic/serializer.ts` ohrani `system`, `text`,
`tool_use`, `tool_result`, `thinking`, `redacted_thinking`, `tool_choice` in orodja, ki jih
posreduje Claude Code. Slike in neznani bloki povzročijo izrecno napako. Veliki rezultati
orodij uporabljajo vidno oznako skrajšanja.

Razčlenjevalnik sprejme eno samostojno ovojnico `<tool>{...}</tool>` na korak modela. Ime
preveri glede na seznam orodij v zahtevi, argumente preveri glede na JSON Schema tega orodja,
zavrne mešanje pripovednega besedila in dejanj ter omogoča en omejen poskus popravila. Claude
Code nato lokalno izvede nastali Anthropic `tool_use` in pošlje `tool_result` nazaj prek
storitve OmniRoute.

## Samodejno usmerjanje

Ponudnik je upravičen do vključitve v nabore kandidatov `auto/*` storitve OmniRoute, kadar ni
blokiran. Upravičenost kandidata ne zagotavlja izbire: strategija usmerjanja kombinacije (na
primer zadnji znani uspešni ponudnik) lahko daje prednost drugemu ponudniku. Kadar mora vsaka
zahteva potekati prek Devina, uporabite `dva/<model>` ali kombinacijo, ki daje prednost Devinu.

## Izolacija in model groženj

Namestitev, račun in konfiguracija Claude na gostitelju niso vključeni v obseg in se
obravnavajo kot prepovedani. Storitve Compose:

- se izvajajo kot UID/GID `10001:10001`, z datotečnim sistemom korena samo za branje, odstranjenimi zmogljivostmi in
  možnostjo `no-new-privileges`;
- uporabljajo zasebni `/home/bridge`, namenski nosilec za konfiguracijo Claude, izolirane podatke OmniRoute
  in ločen nosilec `devin-auth`;
- priklapljajo samo začasne delovne prostore/dokazila `.sandbox`;
- ne priklapljajo domače mape gostitelja, Keychaina, poverilnic SSH, poverilnic za storitve v oblaku ali vtičnice Docker;
- ustvarjajo eksplicitna okolja in odstranijo spremenljivke za API/OAuth/usmerjanje Anthropic;
- usmerjajo sklepanje Claude Code izključno na `http://omniroute:20128` z lokalnim ključem.

Profil brez povezave uporablja notranje omrežje. V profilu v živo OmniRoute dostopa do
uradnih končnih točk Devin samo prek `network-guard`; nepovezani cilji so zavrnjeni.
Claude Code ima ločeno zaščito izhodnega prometa, ki zavrača ves promet, in lahko doseže samo lokalno storitev OmniRoute
prek `NO_PROXY`. Datoteke revizije zaščit so priklopljene samo v njihov proces zaščite.
Skripti preverijo lastništvo datotek, način, število povezav in vsako odločitev, preden izvozijo
dokazila brez žetonov.

Dokaz izolacije zaženite neodvisno:

```bash
./scripts/devin-bridge/verify-anthropic-isolation
```

Preveri topologijo, imenovane priklope, nastavitve za nekorenskega uporabnika in samo za branje, eksplicitno lokalno usmerjanje,
odsotnost občutljivih okoljskih spremenljivk, odsotnost vtičnice Docker, blokiran dostop do
`api.anthropic.com` in `claude.ai`, izbiro ponudnika izključno Devin ter eksplicitno napako, ko
zaledni sistem ACP ni na voljo.

## Prva nastavitev in običajna uporaba

Zgradite pripeto sliko:

```bash
./scripts/devin-bridge/build
```

Overite samo izolirani nosilec Devin:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/login-devin
```

Ukaz za prijavo uporablja uradni postopek z ročnim žetonom, namenjen oddaljenim/vsebniškim
okoljem. Vrednost se vnese neposredno v poziv CLI; ni posredovana kot
argument procesa, zapisana v Git ali kopirana z gostitelja.

Zaženite izolirano izvajalno okolje Claude Code:

```bash
./scripts/devin-bridge/launch
```

`launch` pred zagonom vsebniškega okolja Claude Code ponovno preveri izolacijo, overjanje Devin in odkrivanje modelov.
Nikoli ne zažene izvršljive datoteke Claude na gostitelju. Vzdevke modelov je mogoče
nastaviti v `.env.devin-bridge`; vsaka konfigurirana vrednost mora ohraniti
predpono `devin-cli-agentic/`.

## Ukazi za preverjanje

Ponovljiva pot brez povezave ne zahteva računa Devin in med izvajanjem ne uporablja interneta:

```bash
./scripts/devin-bridge/test-unit
./scripts/devin-bridge/test-contract
./scripts/devin-bridge/test-e2e-mock
./scripts/devin-bridge/verify-anthropic-isolation
```

Overjena pot v živo, ki zahteva izrecno vključitev, je:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/test-live-devin
```

Izvajalnik v živo med scenariji počaka, da prepreči množično odpiranje sej ACP, in
preverja strukturirane dogodke toka Claude, namesto da bi zaupal besedilnim trditvam. Njegovi trije
scenariji dokazujejo:

1. neposredno branje projekta in analizo napak;
2. dejanski `Edit`, odjemalčevo izvajanje `Bash` `npm test` in končni rezultat;
3. odkrivanje `/bridge-check` in `bridge-proof`, branje projekta, še eno uspešno
   odjemalčevo izvajanje `npm test` ter dokončanje brez čakajočega dela.

Končni prehod preveri tudi revizijo omrežja Devin in zahteva, da revizija izhodnega prometa Claude
ostane prazna.

## Posodabljanje pripetih orodij

Slika pripne različice Node, Claude Code in Devin CLI v datoteki
`docker/devin-bridge/Dockerfile`. Za posodobitev:

1. spremenite izrecno navedene različice;
2. zamenjajte kontrolni vsoti arhivov Devin za obe arhitekturi z vrednostma za uradni
   artefakt;
3. znova zgradite sliko in zaženite vse ukaze za preverjanje brez povezave;
4. potrdite različice znotraj slike;
5. znova zaženite overjeno živo zbirko treh scenarijev.

Nobenega od obeh orodij CLI ne nameščajte globalno v gostiteljskem sistemu in preverjanja
kontrolne vsote ne nadomestite z nepreverjenim prenosom.

## Diagnostika in čiščenje

- `docker compose -f docker/devin-bridge/compose.yml --profile offline logs omniroute`
  prikazuje lokalno usmerjanje in prečiščene napake izvajalnika.
- `.sandbox/evidence/mock-acp.jsonl` beleži deterministična simulirana dejanja ACP.
- `.sandbox/evidence/claude-stream.jsonl` beleži dejanski zagon Claude Code brez povezave.
- `.sandbox/evidence/live-*.jsonl` beleži tri preverjene žive tokove.
- `.sandbox/evidence/egress.jsonl` in `.sandbox/evidence/claude-egress.jsonl` sta preverjeni
  kopiji revizij varovala brez žetonov.

Ustavite pripadajoče vsebnike in omrežja, pri tem pa ohranite nosilce za prijavo in konfiguracijo:

```bash
./scripts/devin-bridge/clean
```

Odstranite celotno okolje, ki pripada mostu, vključno z imenovanimi nosilci:

```bash
./scripts/devin-bridge/clean --all
```

## Omejitve

- Most uporablja nespremenljivo vlogo `summarizer` brez orodij, ker Devin CLI `3000.2.17`
  ne ponuja nevtralnega agenta ACP brez orodij. Vmesnik prilagodi vmesne odgovore v obliki
  povzetkov, vendar lahko en omejen poskus popravljanja še vedno izrecno spodleti.
- Živi klici ACP lahko vrnejo prehodne odzive `502`/`504`. Ogrodje razmakne scenarije;
  ob trajni napaki sistem ostane varno zaprt in nikoli ne izbere drugega ponudnika.
- Kontekst ACP se znova sestavi iz vsake zahteve Anthropic; vezave na proces ali sejo ni.
- Podprt je en klic orodja na odziv modela; vzporedni klici so zavrnjeni.
- Slike izrecno niso podprte. Zmogljivosti vida, izpis razmišljanja, kontrolniki napora in
  kontekstno okno velikosti 1M niso oglaševani.
- SSE uporablja veljavne dogodke življenjskega cikla Anthropic, vendar se odda šele po tem,
  ko je zbran omejeni obrat ACP; fragmenti ACP se ne posredujejo sproti.
