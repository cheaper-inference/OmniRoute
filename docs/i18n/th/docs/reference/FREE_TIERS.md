## สรุปย่อ — OmniRoute รวบรวมการอนุมานฟรีได้มากเพียงใดกันแน่?

ตัวเลขเหล่านี้อธิบายบัญชีบุคคลที่สามและเงื่อนไขคุณสมบัติที่แยกจากกันทั่วทั้งแค็ตตาล็อก OmniRoute ไม่ได้เป็นผู้มอบงบประมาณนี้: คุณต้องมีบัญชีหรือข้อมูลประจำตัวที่จำเป็น เชื่อมต่อผู้ให้บริการที่มีสิทธิ์ และปฏิบัติตามขีดจำกัดของผู้ให้บริการเหล่านั้น ความจุที่ใช้งานได้จริงอาจต่ำกว่านี้ รวมถึงอาจเป็นศูนย์สำหรับการติดตั้งใหม่ที่ยังไม่มีเส้นทางซึ่งมีสิทธิ์ ระบบจะไม่นำผู้ให้บริการที่กำกับด้วย `tos: avoid` มาใช้ในการกำหนดเส้นทางอัตโนมัติโดยค่าเริ่มต้น

**ตรวจสอบเมื่อ 2026-10-08:** [Cerebras](https://www.cerebras.ai/pricing) มอบเครดิตส่งเสริมการขายแบบครั้งเดียวมูลค่า $5 ซึ่งต้องใช้วิธีการชำระเงินและหมดอายุหลังจาก 30 วัน [Gemini](https://ai.google.dev/gemini-api/docs/rate-limits) เผยแพร่ขีดจำกัดอัตราการใช้งานแยกตามโปรเจกต์/โมเดล/ระดับบริการ และยังคงไม่รวมอยู่ในตัวเลขพาดหัวรายเดือนที่ระบุเป็นปริมาณ

**พาดหัวที่ตรงไปตรงมา:** _OmniRoute รวบรวมโทเค็นฟรีที่มีเอกสารยืนยันได้ **~1.62B ต่อเดือน** (สูงสุด ~2.22B ในเดือนแรกเมื่อรวมเครดิตสมัครใช้งาน) จากพูลแพ็กเกจฟรี 34 พูล — พร้อมผู้ให้บริการฟรีถาวรแบบไม่มีเพดานอีกมากมาย — และการบีบอัดด้วย RTK + Caveman (ประหยัดโทเค็น 15–95%) ช่วยให้ใช้งานได้ยาวนานยิ่งขึ้น_

> **เหตุใดตัวเลขนี้จึงลดลงจากเดิมที่ ~1.94B** การรีเฟรชเมื่อ 2026-06-17 เป็นการปรับแก้เพื่อความตรงไปตรงมา ไม่ใช่การสูญเสีย: ตอนนี้ `gemini` ถูกขจัดการนับซ้ำในระดับพูลแล้ว (ก่อนหน้านี้ตัวเลขสูงเกินจริงจากการนับ Flash แต่ละเวอร์ชันแยกกัน 462M → 60M), `cloudflare-ai` ถูกแก้ไขให้ตรงกับโควตาจริง 10k-Neurons/วัน (122M → 30M), `doubao` ถูกจัดประเภทใหม่เป็นเครดิตฟรีครั้งเดียวเมื่อลงทะเบียน (ไม่ใช่เครดิตแบบต่ออายุ) และนำระดับบริการที่ปิดตัวแล้วออก (`chutes`/`phind`/`kluster` ยุติให้บริการ) โดยได้รับการชดเชยบางส่วนจาก `llm7` (แก้เป็น 5M/วัน → 150M) และผู้ให้บริการฟรีรายใหม่ (Kilo, OpenCode Zen, Z.AI GLM-Flash)
>
> **แก้ไขเพิ่มเติมเป็น ~1.37B ใน v3.8.42:** `longcat` ถูกจัดประเภทใหม่จากสิทธิ์แบบต่ออายุ 150M/เดือน เป็นเครดิตฟรีครั้งเดียว 10M เมื่อลงทะเบียน หลังจากช่วงทดลองใช้ฟรีสิ้นสุดลง ใช้หลักความตรงไปตรงมาเดียวกัน — ไม่มีผู้ให้บริการรายใดถูกนำออกโดยผิดพลาด
>
> **อัปเดตเมื่อ 2026-08-26 หลังจากยุติ Felo Web:** Felo Web ถูกตัดออก ขณะที่แหล่งที่มา/การให้สิทธิ์ใช้งานซึ่งสืบเนื่องจาก GPL ยังคงอยู่ในสถานะ HOLD; ณ เวลานั้นซอร์สรายงานว่ามีคีย์พูล 38 รายการ จำนวนพูลเป็นข้อมูลสดและถูกควบคุมโดย CI (`check:docs-counts` จะทำให้บิลด์ล้มเหลว หากตัวเลขด้านบนคลาดเคลื่อนจาก `computeFreeModelTotals()`)
>
> **ตรวจสอบซ้ำเมื่อ 2026-09-02 โดยเทียบกับหน้าเว็บของผู้ให้บริการโดยตรง** (แหล่งที่มา: ความคิดเห็น `// evidence:` ถัดจากแต่ละรายการที่ตรวจสอบซ้ำใน `open-sse/config/freeModelCatalog.data.ts`): `gemini` และ `ollama-cloud` ไม่เผยแพร่จำนวนโทเค็นอีกต่อไป (Google นำตารางระดับฟรีแยกตามโมเดลออกเมื่อ 2025-12-23; แผน Free ของ Ollama คือ "เครดิตฟรีสำหรับการใช้งานเริ่มต้น") และตอนนี้จะแสดงเป็น **ไม่มีเพดาน** โดยไม่นำมารวมยอด (−80M); `groq` มีเพดาน 200K-TPD แบบ **แยกตามโมเดล** ห้ารายการ (รายการละ 6M, +15M) พร้อมนำ ID ที่ยุติให้บริการแล้วสามรายการออก; `nara` มีบัคเก็ตเดียวขนาด 7M/วัน (+60M, 210M) ส่วน 1B ของ `mistral` มองเห็นได้เฉพาะในคอนโซลบัญชี — ดู _ประเภทหลักฐาน_ ในส่วนระเบียบวิธี

>

## การแก้ไขโมเดลฟรีของ SiliconFlow เมื่อ 2026-10-18 (#17028)

โมเดลเรือธงของ SiliconFlow จำนวนสิบโมเดลซึ่งมีการเผยแพร่ราคาต่อโทเค็นเป็นจำนวนบวก ถูกจัดส่ง
อย่างไม่ถูกต้องในฐานะสิทธิ์ใช้งานฟรีแบบ `recurring-uncapped` แถวทั้งสิบดังกล่าวถูก **นำออก** จาก
แค็ตตาล็อกแบบคงที่แล้ว ซึ่งขณะนี้มี **467 รายการ** SiliconFlow จึงไม่มีรายการโมเดลฟรี
แบบไม่มีเงื่อนไขหรือสถานะผู้ให้บริการฟรีถาวรที่นำมารวมในยอดรวมแบบคงที่อีกต่อไป

กรณีนี้ **ไม่ได้** หมายความว่า SiliconFlow ไม่มีโมเดลฟรี ขณะนี้การนำเข้าเฉพาะรายการฟรีและป้าย Free
ต้องมี **หลักฐานเชิงบวกระดับโมเดลจากเพย์โหลดโมเดลแบบสดของผู้ให้บริการ** เช่น ตัวบ่งชี้แบบบูลีน
ที่ระบุชัดเจนว่าใช้งานฟรี หรือราคาของโทเค็นทั้งสองประเภทเป็นศูนย์ แฟล็กแบบชำระเงินที่ระบุไว้อย่างชัดเจน
หรือราคาตัวเลขใดๆ ที่เป็นจำนวนบวก จะมีลำดับความสำคัญเหนือกว่าตัวบ่งชี้ว่าใช้งานฟรีในเชิงคาดการณ์
โมเดลที่ไม่มีหลักฐานแบบสดให้ตรวจสอบจะ **ไม่** ถูกสันนิษฐานว่าใช้งานฟรี เครดิตครั้งเดียวสำหรับบัญชีใหม่
ไม่สามารถใช้เป็นหลักฐานว่ามีสิทธิ์ใช้งานฟรีแบบต่ออายุได้ หาก API ปัจจุบันของผู้ให้บริการไม่สามารถให้ข้อมูล
ราคาระดับโมเดลที่เชื่อถือได้ โปรดยืนยันในคอนโซลของผู้ให้บริการก่อนกำหนดเส้นทาง ตัวเลือกแบบอนุรักษนิยมนี้
ช่วยป้องกันค่าใช้จ่ายที่ไม่คาดคิดจากการนำเข้าเฉพาะรายการฟรีและการรวมแบบอัตโนมัติ

ตารางผู้ให้บริการย้อนหลังด้านล่างไม่ใช่คำรับรองความพร้อมใช้งานแบบสด รายการเดิมของ SiliconFlow
ที่ระบุว่าไม่จำกัดเพดาน/10 โมเดลถูกละออกโดยเจตนา เนื่องจากไม่ได้แสดงถึงสิทธิ์ใช้งานฟรี
แบบต่ออายุที่ได้รับการยืนยันอีกต่อไป

## สองระบอบ — การนับเทียบกับการตัดสินใจ

OmniRoute ตอบคำถามว่า "ฟรีหรือไม่?" ผ่านสองระบอบที่จงใจอ่าน
ข้อมูลจากแหล่งที่แตกต่างกัน:

| ระบอบ                  | แหล่งข้อมูลจริง                                                                                                                                                                                       | จุดที่นำไปใช้                                                                                                                            |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **การนับ / การแสดงผล** | แค็ตตาล็อกที่ผ่านการแก้ผลแล้ว — ข้อมูลพื้นฐานที่จัดส่งมาพร้อมระบบ ซึ่งซ้อนทับด้วยฟีด Radar (`getRadarCatalog`)                                                                                        | ยอดรวมระดับฟรี การ์ดงบประมาณ แดชบอร์ด                                                                                                    |
| **การตัดสินใจ**        | เฉพาะแค็ตตาล็อกที่จัดส่งมาพร้อมระบบ (`FREE_MODEL_BUDGETS` ใน `open-sse/config/freeModelCatalog.data.ts`) รวมกับฮิวริสติกภายในเครื่อง (คำต่อท้าย `:free` การกำหนดราคาเป็นศูนย์ และ `grantsFreeAccess`) | ทุกส่วนที่ใช้ `src/shared/utils/freeModels.ts`: การนำเข้าโมเดล การกำหนดเส้นทาง `auto/*`, `GET /v1/models` และตัวอย่างแสดงผลในเบราว์เซอร์ |

การนับสามารถปรับปรุงได้ทุกครั้งที่มีฟีดพร้อมใช้งาน ส่วนการตัดสินใจยังคงอิง
อาร์ติแฟกต์ของรุ่นที่เผยแพร่ ดังนั้นคำตอบจึงเหมือนกันทั้งในเบราว์เซอร์และบนเซิร์ฟเวอร์
ทำซ้ำแบบออฟไลน์ได้ และทดสอบได้โดยไม่ต้องมีฐานข้อมูล หากปล่อยให้ตัวอย่างแสดงผล
ในเบราว์เซอร์อ่านจากแหล่งหนึ่ง ขณะที่การนำเข้าบนเซิร์ฟเวอร์อ่านจากอีกแหล่งหนึ่ง
ตัวอย่างแสดงผลอาจไม่ตรงกับสิ่งที่เกิดขึ้นเมื่อคลิก — จึงตั้งใจคงการแบ่งนี้ไว้

- **รายการใดที่รับรองได้จริง** ไม่มีรายการใดที่มีระดับความเชื่อมั่นต่อแถว และ API ไม่แสดงค่าใดเลย — จะถือว่าทุกตัวเลขด้านบนเป็นการประมาณคุณภาพที่เหมือนกันและไม่ได้ระบุ ข้อเท็จจริงสองข้อมีความแตกต่างกัน เนื่องจากมีการดูแลจัดการด้วยมือแทนที่จะอนุมาน: รายการ 44 รายการมีจุดหยุดที่จัดทำเป็นเอกสารแยกกัน (39 รายการในแถว xKiro ซึ่งทั้งหมดแบ่งปันเบี้ยเลี้ยงรายวันหนึ่งรายการ) และ 21 รายการมีการเปิดเผยการฝึกอบรมทันที `hardStopGuaranteed` จะถูกตั้งค่าเฉพาะเมื่อเงื่อนไขของผู้ให้บริการระบุว่า เกินขีดจำกัดฟรีจะปฏิเสธคำขอ แทนที่จะเริ่มเรียกเก็บเงินจากคุณอย่างเงียบๆ โดยมีแหล่งที่มาในความคิดเห็นถัดจากรายการ ไม่เคยตั้งค่าเริ่มต้นเป็น `true` และรายการที่ไม่มีใครตรวจสอบจะไม่ได้รับการตั้งค่า ดังนั้น เครื่องหมายหยุดถาวรที่ขาดหายไปจึงหมายถึง "ไม่เป็นที่ยอมรับ" ไม่ใช่ "ทราบว่าเรียกเก็บเงินจากคุณ"** โหมด STRICT** (ตัวป้องกันการกำหนดเส้นทาง `freeAccessPolicy=strict` ที่เลือกใช้) จะเชื่อถือเฉพาะรายการที่มีการตั้งค่าสถานะเท่านั้น Free Tier อื่นๆ ทั้งหมดจะไม่รวมเป็น `no-hard-stop` (ดู `open-sse/services/autoCombo/strictZeroCostFilter.ts`) เมื่อตัวป้องกันกรองพูล บันทึกที่ผู้ปฏิบัติงานมองเห็นจะรายงานทั้งจำนวนการแยกและส่วนแบ่ง `no-hard-stop`
- `estMonthlyFreeTokens` = โทเค็นรายเดือนที่เกิดซ้ำเท่านั้น** เครดิตการลงทะเบียนครั้งเดียวจะไม่เกิดขึ้นอีก** และนับเป็น 0 ระดับที่ถูกยกเลิกก็เป็น 0 เช่นกัน
- โทเค็นแคปรายวัน → `monthly = daily × 30` เฉพาะเอกสาร RPD → `RPD × ~800 output tokens × 30` เฉพาะ RPM/TPM (ไม่มีขีดจำกัดรายวัน) →** ไม่ได้ต่อยอด** (ดูด้านล่าง)
- **ฟรีถาวร แต่ไม่มีโทเค็นแคปที่เผยแพร่** (`glm-cn`, `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud`): สิ่งเหล่านี้เป็นการเข้าถึงฟรีที่เกิดขึ้นจริง rate/concurrency-limited. เราจำแนกพวกเขา `recurring-uncapped` และ** ไม่เคยรวมพวกเขา** — การคูณ `RPM × 24/7 × 30d` จะทำให้เกิดเพดานแฟนตาซี (อัตราเงินเฟ้อที่เราปฏิเสธ) มีการระบุไว้เพื่อให้คุณรู้ว่ามีอยู่จริง
- **เพิ่มการฝาก-ปลดล็อค:** การเติมเงินเล็กๆ น้อยๆ เพียงครั้งเดียวซึ่งจะเพิ่มโควต้าฟรีอย่างถาวร (OpenRouter: $10 → 1,000 req/day ≈ +24M/mo) รายงานเป็นตัวเลขแยกต่างหาก ไม่พาดหัวข่าวคงที่
- **โควต้าที่มีการควบคุมสิทธิ์** (`eligibilityGate: "regional-identity"`): โควต้าที่เกิดซ้ำจริงซึ่งจะเปิดหลังจากการตรวจสอบตัวตนที่ผูกกับภูมิภาคเท่านั้น (ปัจจุบันมีการยืนยันชื่อจริงในจีนแผ่นดินใหญ่) นับด้วยกฎ pool-dedupe เดียวกันให้เป็นตัวเลขที่แยกจากกัน (`gatedRecurringTokens`) ไม่เคยรวมอยู่ในพาดหัวข่าวคงที่ ระบอบการปกครอง (`freeType`) ไม่มีการเปลี่ยนแปลง ดังนั้นการกำหนดเส้นทางจึงไม่เปลี่ยนแปลง
- **ชั้นเรียนหลักฐาน** กฎ: ตัวเลขในแค็ตตาล็อกอ้างอิงแหล่งที่มาในความคิดเห็น `// evidence:` ถัดจากรายการ — `public-page` (หน้าผู้ให้บริการที่ใครๆ ก็สามารถอ่านได้), `api-public` (จุดสิ้นสุดที่ไม่ได้รับการรับรองความถูกต้องของผู้ให้บริการ เช่น NaraRouter'จุดสิ้นสุดแผนสาธารณะของ router.bynara.id) หรือ `console-verified <date> por <who>` (ตัวเลขจะปรากฏให้เห็นเฉพาะในคอนโซลบัญชีเท่านั้น ความคิดเห็นจะบันทึกว่าใครเห็นและเมื่อใด และหน้าสาธารณะที่ระบุว่ามี cap อยู่) รัฐในปัจจุบัน: ห้าช่วงตึกได้รับการตรวจสอบอีกครั้งในวันที่ 2026-09-02 ดำเนินการ (`gemini`, `groq`, `mistral`, `ollama-cloud`, `nara`); รายการที่เกิดขึ้นก่อนการตรวจสอบซ้ำประจำปี 2569-09-02 จะสืบทอดการวิจัยก่อนหน้านี้จนกว่าจะได้รับการแก้ไข ใดๆ** ใหม่หรือเปลี่ยนแปลง** หมายเลขที่ไม่มีหลักฐาน ความคิดเห็นถือเป็นจุดบกพร่อง วันนี้มีเพียง `mistral` เท่านั้นที่ได้รับการยืนยันจากคอนโซล

## เหตุใดตัวเลขของเราจึงน้อยกว่าของผู้รวบรวมรายอื่น

ตัวเลข "โทเค็นฟรีต่อเดือน" ส่วนใหญ่ในแวดวงนี้เกิดจากการรวมตัวเลขที่ระบุแยกตามโมเดล แต่ของเราตั้งใจไม่คำนวณเช่นนั้น:

- **แต่ละพูลที่ใช้ร่วมกันจะถูกนับเพียงครั้งเดียว** แผนฟรีของ Mistral มีโควตา 1B/เดือนหนึ่งชุดต่อองค์กร การแสดงโควตานี้ไว้ใต้ห้าโมเดลไม่ได้ทำให้กลายเป็น 5B หากรวมแยกตามโมเดล แค็ตตาล็อกของเราเองจะแสดงเป็น **~7.4B** (คำนวณใหม่เมื่อ 2026-09-03; ตัวเลขนี้ไม่ได้ถูกควบคุมโดย CI — ให้วัดใหม่ทุกครั้งที่แค็ตตาล็อกเปลี่ยนแปลง) — แต่พาดหัวระบุ **~1.47B** เพราะนั่นคือจำนวนที่หนึ่งบัญชีจากผู้ให้บริการแต่ละรายสามารถใช้ได้จริง
- **เพดานรายวันจะถูกแปลง แต่ขีดจำกัดอัตราจะไม่ถูกแปลง** เพดานโทเค็น/วันที่มีเอกสารกำกับจะคำนวณเป็น `× 30`; เพดานคำขอ/วันที่มีเอกสารกำกับจะคำนวณเป็น `RPD × ~800 tokens × 30`; ผู้ให้บริการที่เผยแพร่เพียงจำนวนคำขอต่อนาทีจะ **ไม่มี** ตัวเลขรายเดือนและถูกระบุว่า _ไม่มีเพดาน_ โดยจะไม่นำมารวม การนำขีดจำกัดอัตราไปคูณด้วยการใช้งาน 24/7 คือการปั่นตัวเลขที่เราปฏิเสธจะทำ
- **โควตาที่ต้องผ่านการยืนยันตัวตนตามภูมิภาคจะแสดงแยกต่างหาก** (`+~6M behind regional identity verification`) เพราะผู้อ่านส่วนใหญ่ไม่สามารถใช้โควตาเหล่านั้นได้
- **เครดิตสมัครใช้งานมีเฉพาะเดือนแรก** และรายงานเป็นตัวเลขที่สอง โดยจะไม่นำไปรวมกับตัวเลขการใช้งานต่อเนื่อง
- **ตัวเลขนี้ถูกบังคับใช้โดย CI** `npm run check:docs-counts` จะคำนวณยอดรวมใหม่จากแค็ตตาล็อก และทำให้บิลด์ล้มเหลวเมื่อไฟล์นี้ README หรือการ์ดงบประมาณมีตัวเลขไม่ตรงกัน

## ตารางข้อควรพิจารณาเกี่ยวกับ ToS

> **แฟล็ก ToS เป็นเพียงคำแนะนำ ไม่ใช่เงื่อนไขควบคุมการกำหนดเส้นทาง** ผู้ให้บริการที่ทำเครื่องหมาย `tos` ยังคงถูกรวมในการกำหนดเส้นทางและ combo/fallback ตามค่าเริ่มต้น แฟล็กจะแสดงเฉพาะบน `/dashboard/free-tiers` และ `/api/free-tier/summary` เท่านั้น พารามิเตอร์คำค้น `excludeTosAvoid` มีผลเฉพาะกับมุมมองสรุป ไม่ส่งผลต่อการกำหนดเส้นทางส่วนกลาง ข้อสรุปอยู่ใน `open-sse/config/freeTierCatalog.ts` (ใช้เพื่อให้ข้อมูลเท่านั้น และเอนจินกำหนดเส้นทางจะไม่อ่านค่านี้)

> ข้อมูลโดยสรุปเกี่ยวกับข้อกำหนดของผู้ให้บริการแต่ละรายสำหรับพร็อกซีส่วนบุคคลแบบโฮสต์เองและมีผู้ใช้คนเดียว `caution` = มีข้อกำหนดเกี่ยวกับการใช้งานส่วนบุคคลหรือพร็อกซีที่ควรตรวจสอบ; `ambiguous` = ไม่ชัดเจน; `ok` = อนุญาตไว้อย่างชัดแจ้ง ข้อมูลนี้มีไว้เพื่อให้ข้อมูล ไม่ใช่คำแนะนำทางกฎหมาย — คุณเป็นผู้ตัดสินใจ

- **`uncloseai`** — ตรงกันเป็นส่วนใหญ่ — ยังคงฟรีตลอดไปโดยไม่ต้องลงทะเบียน อย่างไรก็ตาม ToS (terms-of-use.html) ชี้แจงว่ามีการจำกัดตาม IP สำหรับการใช้งานที่มากเกินไป และห้ามสร้างบริการ ML ที่แข่งขันกันโดยไม่มี…
- **`veoaifree-web`** — `freeNote` ที่มาพร้อมแพ็กเกจระบุว่า "6 requests/hour" แต่ปัจจุบันไม่มีการระบุขีดจำกัดดังกล่าวอย่างชัดเจนที่ใดบน veoaifree.com เว็บไซต์ระบุว่าสามารถสร้างเนื้อหาได้ฟรีแบบไม่จำกัดโดยไม่ต้องเข้าสู่ระบบ โมเดลที่แสดงรายการไว้ …
- **`voyage-ai`** — `freeNote` ที่มาพร้อมแพ็กเกจระบุว่า "200M free tokens for embeddings and reranking" ซึ่งถูกต้องในแง่จำนวนโทเค็น แต่ทำให้เข้าใจผิด — เนื่องจากไม่ได้ระบุว่านี่เป็นโควตาที่จัดสรรให้ต่อบัญชีเพียงครั้งเดียว ไม่ใช่โควตาที่ได้รับซ้ำ…
- **`yi`** — `freeNote` ที่มาพร้อมแพ็กเกจระบุว่า "Free Yi-Light models" ซึ่งอ้างถึงชื่อโมเดล ("Yi-Light") ที่ไม่ปรากฏในเอกสารหรือแค็ตตาล็อกโมเดลปัจจุบันของ 01.AI — ไม่มีโมเดลดังกล่าวแสดงอยู่บน platform.01.ai, …
