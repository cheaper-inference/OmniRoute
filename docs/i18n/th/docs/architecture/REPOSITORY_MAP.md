## โครงสร้างระดับบนสุด

```
OmniRoute/
├── src/                  # แอปพลิเคชัน Next.js 16 (UI + เส้นทาง API + ไลบรารี + โดเมน + เซิร์ฟเวอร์)
├── open-sse/             # เวิร์กสเปซเอนจินสตรีมมิง (ตัวจัดการ ตัวดำเนินการ ตัวแปล และเซิร์ฟเวอร์ MCP)
├── packages/            # เวิร์กสเปซ npm: ui-kit (Keak CI UI Kit ที่รวมมากับโปรเจกต์) และ browser-pool
├── electron/             # ตัวห่อหุ้มเดสก์ท็อป (Electron 41 + electron-builder 26.10)
├── bin/                  # จุดเริ่มต้น CLI และตัวจัดการคำสั่ง
├── scripts/              # สคริปต์สำหรับบิลด์ ตรวจสอบ ซิงก์ และงานเฉพาะกิจ
├── docs/                 # เอกสารสาธารณะ (คุณอยู่ที่นี่)
├── tests/                # ชุดการทดสอบทั้งหมด (ยูนิต อินทิเกรชัน e2e และไคลเอนต์โปรโตคอล)
├── public/               # แอสเซตแบบสแตติกของ Next.js, ไฟล์ manifest ของ PWA, service worker และไอคอน
├── config/               # การกำหนดค่าแบบสแตติก + สถานะเกณฑ์คุณภาพ (i18n, payloadRules, quality/)
├── images/               # แอสเซตภาพสำหรับการตลาด / README
├── @omniroute/           # แพ็กเกจเสริมที่เผยแพร่ได้ (opencode-plugin, opencode-provider)
├── skills/               # ชุดทักษะสำหรับ CLI/เอเจนต์ (cli-* + omni-* + config-codex-cli)
├── examples/             # ปลั๊กอินตัวอย่าง + โปรเจกต์เริ่มต้น omniroute-cmd-hello
├── contrib/              # ผลงานที่ชุมชนมีส่วนร่วม (podman/)
├── .source/              # การกำหนดค่าซอร์ส Fumadocs (source.config.mjs + server/browser/dynamic)
├── .github/              # เวิร์กโฟลว์ GitHub Actions + เทมเพลต issue + เทมเพลต PR
├── .husky/               # Git hooks (pre-commit, pre-push)
├── .claude/              # คำสั่ง slash ของ Claude Code (ขอบเขตระดับโปรเจกต์)
├── .agents/              # เวิร์กโฟลว์และทักษะสำหรับ Codex / เอเจนต์ทั่วไป (สำเนาของ .claude/)
├── .vscode/              # การตั้งค่าเวิร์กสเปซ VS Code
├── _ideia/               # บันทึกการวางแผน (ไม่เป็นทางการ และไม่รวมในการเผยแพร่)
├── _mono_repo/           # โปรเจกต์ย่อยในอดีต (cloud, site, vscode-extension)
├── _references/          # โคลนอ้างอิงแบบอ่านอย่างเดียวจากโปรเจกต์ OSS ที่เกี่ยวข้อง
├── _tasks/               # ไฟล์ติดตามงานของแต่ละรีลีส (ไม่เป็นทางการ)
├── .build/ .worktrees/ dist/   # พื้นที่ชั่วคราวสำหรับบิลด์ภายในเครื่อง / git-worktree / เอาต์พุตจากการบิลด์ (ถูกละเว้นโดย git)
├── .issues/              # แคช issue ภายในเครื่อง (ถูกละเว้นโดย git)
├── .playwright-mcp/      # อาร์ติแฟกต์การทดสอบ Playwright MCP
├── coverage/             # เอาต์พุตความครอบคลุมของ c8 (ถูกละเว้นโดย git)
├── logs/                 # บันทึกการทำงานขณะรัน (ถูกละเว้นโดย git)
├── node_modules/         # ดีเพนเดนซี (ถูกละเว้นโดย git)
├── package/              # พื้นที่เตรียมแพ็กเกจ npm (อาร์ติแฟกต์จากการบิลด์)
├── .next/                # เอาต์พุตจากการบิลด์ Next.js (ถูกละเว้นโดย git)
└── (ไฟล์ในรูท — ดูด้านล่าง)
```

## `src/` — แอปพลิเคชัน Next.js

```
src/
├── app/                 # App Router (หน้าเว็บ + เส้นทาง API + หน้าสถานะ + หน้า Landing)
├── lib/                 # ไลบรารีหลัก / โมดูลโดเมน (80 ไดเรกทอรีย่อย + ไฟล์ระดับบนสุดประมาณ 70 ไฟล์)
├── domain/              # ลอจิกโดเมนล้วน (กลไกนโยบาย, การสำรอง, ต้นทุน, การล็อก, comboResolver, การประเมิน)
├── server/              # โมดูลเฉพาะเซิร์ฟเวอร์ (ไปป์ไลน์การอนุญาต, cors, มิดเดิลแวร์การยืนยันตัวตน) — ไม่สามารถนำเข้าจากไคลเอนต์ได้
├── shared/              # ใช้ร่วมกันระหว่างเซิร์ฟเวอร์และไคลเอนต์เมื่อปลอดภัย (ค่าคงที่, ชนิดข้อมูล, การตรวจสอบความถูกต้อง, สัญญา, ยูทิลิตี)
```

## `_ideia/`, `_mono_repo/`, `_references/`, `_tasks/` — นอกโครงสร้างหลัก
