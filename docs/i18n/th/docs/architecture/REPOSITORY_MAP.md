## ต้นไม้ระดับบนสุด

```
OmniRoute/
├── src/              # Next.js 16 app: dashboard, /api and /v1 routes, server libs, domain, i18n
├── open-sse/         # Streaming engine workspace (@omniroute/open-sse): handlers, executors, translator, services, MCP server
├── packages/         # npm workspaces: ui-kit (vendored Keak CI UI Kit) and browser-pool
├── @omniroute/       # Separately published npm packages (OpenCode plugins and provider)
├── bin/              # Published `omniroute` CLI, MCP/bridge entry points, self-host ops scripts (*.sh)
├── electron/         # Desktop app (Electron main/preload + helpers + icons)
├── public/           # Static assets served by Next.js (provider logos, PWA icons, sw.js, openapi.yaml copy)
├── skills/           # Agent Skills (SKILL.md) served by /api/agent-skills, MCP and A2A
├── tests/            # All test suites: unit, integration, e2e, homolog, fixtures, snapshots
├── scripts/          # Build, quality gates, i18n, release, ops, perf and one-off scripts (allow-listed subfolders)
├── config/           # Versioned config: i18n, payload rules, CLI manifest, quality-gate baselines, release inventories
├── changelog.d/      # Per-PR changelog fragments, aggregated into CHANGELOG.md at release time
├── docs/             # Public documentation (served at /docs via Fumadocs) + translated mirrors in docs/i18n/
├── examples/         # Example plugins and quickstart clients
├── deploy/           # Kubernetes deployment: Helm chart + Kustomize base/overlays
├── docker/           # Auxiliary container images (not the main image, which is the root Dockerfile)
├── contrib/          # Community recipes: Podman quadlets, VPS compose, Windows launchers, session-sync note
├── .github/          # GitHub Actions workflows, composite actions, issue/PR templates, CODEOWNERS, labels
├── .husky/           # Tracked git hooks: commit-msg, pre-commit, pre-push
├── .vale/            # Vale prose-lint vocabulary (styles/Vocab/OmniRoute/accept.txt)
├── .vscode/          # Shared VS Code workspace settings (settings.json)
└── (root files — see below)
```

เส้นทางท้องถิ่น สร้าง หรือส่วนตัว (gitignor ทั้งหมด ไม่เคยคอมมิต ไม่ได้อธิบายเพิ่มเติม):

```
node_modules/            # npm dependencies
.build/                  # Next.js build output (default distDir .build/next, see next.config.mjs)
dist/                    # npm staging directory assembled by scripts/build/prepublish.ts
.source/                 # fumadocs-mdx output that feeds the /docs viewer
.husky/_/                # Husky runtime generated on install (core.hooksPath target)
coverage/ logs/ test-results/ playwright-report/   # coverage, runtime logs, Playwright output
.env                     # local secrets generated from .env.example
_*/                      # private local-only folders (anchored /_* ignore); never tracked
.claude/ .agents/        # local AI-assistant state and skills; never tracked
```

## ไฟล์รูท

ไฟล์ที่ถูกติดตามทั้งหมดที่รูทที่เก็บ (`git ls-files | grep -v /`) ซึ่งจัดกลุ่มตามฟังก์ชัน

### เอกสารประกอบโครงการ

| ไฟล์                     | วัตถุประสงค์                                                                 |
| ------------------------ | ---------------------------------------------------------------------------- |
| `README.md`              | หน้า Landing Page: ภาพรวมคุณลักษณะ เริ่มต้นอย่างรวดเร็ว วิธีการติดตั้ง       |
| `CHANGELOG.md`           | บันทึกการเปลี่ยนแปลงต่อรุ่น (แฟรกเมนต์จาก `changelog.d/` ถูกพับอยู่ที่นี่)   |
| `ROADMAP.md`             | แผนงานสาธารณะ                                                                |
| `LICENSE`                | ใบอนุญาต MIT                                                                 |
| `THIRD_PARTY_NOTICES.md` | ประกาศสำหรับโค้ดของบุคคลที่สามแบบรวม (เช่น การเชื่อมโยง wreq-js)             |
| `CONTRIBUTING.md`        | คู่มือผู้ร่วมให้ข้อมูล: การตั้งค่า, คอมมิตแบบธรรมดา, เมทริกซ์ทดสอบ, โฟลว์ PR |
| `SECURITY.md`            | นโยบายการรายงานช่องโหว่                                                      |
| `CODE_OF_CONDUCT.md`     | ความคาดหวังด้านพฤติกรรมของชุมชน                                              |
| `llm.txt`                | สรุปโปรเจ็กต์ข้อความธรรมดาสำหรับโปรแกรมรวบรวมข้อมูลและผู้ช่วย LLM            |

| ไฟล์        | วัตถุประสงค์                                                            |

| `AGENTS.md` | แหล่งความจริงแหล่งเดียวสำหรับผู้ช่วย AI ทุกคน: แบบแผน ประตูคุณภาพ กฎยาก |

### รายการแพ็คเกจและ Node toolchain

| ไฟล์                       | วัตถุประสงค์                                                                         |
| -------------------------- | ------------------------------------------------------------------------------------ |
| `package.json`             | รายการ NPM: สคริปต์, การอ้างอิง, `engines`, `workspaces`, `files` ที่เผยแพร่         |
| `package-lock.json`        | แผนผังการพึ่งพาที่ถูกล็อค                                                            |
| `pnpm-workspace.yaml`      | รายการพื้นที่ทำงาน pnpm (`packages/*`, `open-sse`) และรายการที่อนุญาตในการสร้างเนทิฟ |
| `.npmrc` / `.npmignore`    | กำหนดค่า npm และเผยแพร่การยกเว้น                                                     |
| `.node-version` / `.nvmrc` | หมุดเวอร์ชันโหนดสำหรับผู้จัดการเวอร์ชัน                                              |
| `flake.nix` / `flake.lock` | Nix dev shell และล็อคของมัน                                                          |
| `Makefile`                 | ทางลัด `make` ที่มอบหมายให้กับสคริปต์ npm                                            |

## `scripts/` — งานสร้าง ประตู และเครื่องมือ

ไฟล์ที่ถูกติดตามประมาณ 435 ไฟล์ สคริปต์ใหม่ไปอยู่ในโฟลเดอร์ย่อยโฟลเดอร์ใดโฟลเดอร์หนึ่งที่อนุญาตโดย `AGENTS.md`; รหัสแบบใช้ครั้งเดียวจะไปใน `scripts/ad-hoc/`

```
scripts/
├── check-permissions.sh   # Container ENTRYPOINT (copied to /app by the Dockerfile)
├── postinstall.mjs        # Native-runtime warm-up run after scripts/build/postinstall.mjs
├── start-ws-server.mjs    # Starts the live-dashboard WebSocket server as a separate process
├── build/                 # Build, standalone assembly, npm pack/publish, postinstall, MITM, Electron prep
├── check/                 # Quality gates behind most `npm run check:*` scripts; lib/ holds shared helpers
├── quality/               # Ratchets, gate manifest, impact map, mutation tooling, release acceptance
├── ci/                    # Steps invoked only by workflows (Docker publish, Release-Green, scanners)
├── dev/                   # Dev runners (run-next, Playwright/protocol/ecosystem runners) and runtime helpers shipped in the package
├── docs/                  # README SVG/diagram generators, OpenAPI module, provider reference, wiki sync
├── i18n/                  # UI and docs translation pipeline, coverage checks, glossary/, lib/
├── release/               # Changelog aggregation, contributors, merge train, LTS cut, publish verification
├── ops/                   # Canary deploy, OpenCode free relay, runner janitor, allowlist sync
├── perf/                  # Benchmarks and one-off performance A/B scripts
├── cli/                   # CLI tooling (API-command generator, SSO, CLI smoke tests, media MCP)
├── homolog/               # Homologation against a running instance + promptfoo config generation
├── features/              # Feature-triage engine and its lib/
├── router-eval/           # Offline router evaluation (`npm run eval:router*`)
├── compression/           # Compression benchmark (`npm run bench:compression`, runs on Bun)
├── compression-eval/      # Compression quality evaluation (`npm run eval:compression`)
├── devin-bridge/          # Shell entry points for the Devin bridge (build, launch, tests)
├── docker/                # Base-path patching for the standalone server inside containers
├── integrations/          # MarkItDown MCP launchers — see docs/integrations/MARKITDOWN_MCP.md
├── launchers/             # Double-click launchers and desktop-shortcut creators (Windows/macOS/Linux)
├── packs/                 # Optional-pack manifest and installer (shipped in the npm package)
├── test/                  # Live smoke scripts (combo-live, OpenCode/ChatGPT Web)
├── sre/                   # On-call rotation, log redaction, TCP close analyzer
├── vps/                   # Start/stop the release runner
├── skills/                # Agent Skills generator CLI
├── research/              # Free-tier budget card SVG generator
└── ad-hoc/                # One-shot diagnostics and migrations
```

## ชิ้นส่วนบันทึกการเปลี่ยนแปลง `changelog.d/` —

PR เพิ่มหนึ่งแฟรกเมนต์แทนการแก้ไข `CHANGELOG.md`: `features/`, `fixes/` หรือ `maintenance/` ชื่อ `<PR-number>-<slug>.md` เมื่อถึงเวลารีลีส `scripts/release/aggregate-changelog.mjs` จะพับพวกมันเป็น `CHANGELOG.md` แล้วลบทิ้ง `npm run check:changelog-integrity` ตรวจสอบพวกเขา รายละเอียดใน `changelog.d/README.md`.
