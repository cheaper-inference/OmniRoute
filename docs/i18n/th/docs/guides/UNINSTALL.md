## เปลี่ยนกลับการกำหนดค่าไคลเอ็นต์

โปรแกรมถอนการติดตั้งจะหยุดกระบวนการ OmniRoute ที่จัดการโดย PM2 ถ้ามี และปล่อยให้คอนฟิกูเรชันไคลเอ็นต์ยังคงอยู่ ไคลเอนต์ที่ยังชี้ไปที่ OmniRoute จะสูญเสียการเชื่อมต่อเมื่อหยุด การลบแบบเต็มยังลบไดเร็กทอรีข้อมูลด้วย `~/.omniroute` ตามค่าเริ่มต้น พร้อมด้วยการสำรองข้อมูลการกำหนดค่าไคลเอ็นต์

### 1. ใช้แดชบอร์ดในขณะที่ OmniRoute กำลังทำงาน

เปิด** รหัส CLI** (`/dashboard/cli-code`) ในแดชบอร์ดและค้นหาไฟล์** รหัส Claude** การ์ด.** นำมาใช้** เขียนไปยังไฟล์การตั้งค่ารหัส Claude ของโฮสต์ OmniRoute `~/.claude/settings.json` ตามค่าเริ่มต้น หากคุณมีข้อมูลสำรองก่อนที่จะใช้การตั้งค่า OmniRoute ให้เปิด** การสำรองข้อมูล** และคืนค่ามัน มิฉะนั้น ให้เลือก** รีเซ็ต** เพื่อลบการตั้งค่าเกตเวย์ออกจาก `env` ใช้และรีเซ็ตสำรองไฟล์ที่มีอยู่ก่อน ข้อมูลสำรองจะถูกเก็บไว้ภายใต้ `<DATA_DIR>/backups`

หาก `CLI_ALLOW_CONFIG_WRITES=false` หรือแดชบอร์ดไม่พร้อมใช้งาน ให้แปลงไฟล์กลับด้วยตนเอง หาก OmniRoute ทำงานใน Docker และไคลเอ็นต์ทำงานบนโฮสต์ ให้คืนค่าการกำหนดค่าโฮสต์ ไฟล์ในบ้านคอนเทนเนอร์ที่ไม่ได้ประกอบเข้าไม่มีผลกับโฮสต์ไคลเอ็นต์

### 2. ย้อนกลับการเปลี่ยนแปลงที่เหลือด้วยมือ

สำหรับรหัส Claude ให้ตรวจสอบ `~/.claude/settings.json`, `settings.json` ใน `CLAUDE_CONFIG_DIR` หากตั้งค่าไว้ และ `.claude/settings.json` ของโครงการ Reset จะลบคีย์ต่อไปนี้ออกจาก `env` ลบค่าที่คุณเพิ่มสำหรับ OmniRoute หรือคืนค่าค่าก่อนหน้าของคุณ

- `"ANTHROPIC_BASE_URL"`, `"ANTHROPIC_AUTH_TOKEN"` และ `"ANTHROPIC_API_KEY"`
- `"ANTHROPIC_DEFAULT_OPUS_MODEL"`, `"ANTHROPIC_DEFAULT_SONNET_MODEL"` และ `"ANTHROPIC_DEFAULT_HAIKU_MODEL"`
- `"API_TIMEOUT_MS"`

การรีเซ็ตจะปล่อยให้ `ANTHROPIC_MODEL` อยู่ใน `env` และการตั้งค่า `model` และ `apiKeyHelper` ระดับบนสุดยังคงอยู่ ลบหรือกู้คืนข้อมูลเหล่านั้นด้วยตนเอง หากเลือกโมเดล OmniRoute หรือข้อมูลประจำตัว หยุดใช้โปรไฟล์ OmniRoute ใด ๆ ที่สร้างโดย `omniroute setup-claude` ภายใต้ `~/.claude/profiles/<name>/` หรือเปลี่ยนกลับ `settings.json` คำสั่งการตั้งค่าจะเขียนโปรไฟล์โดยไม่ต้องเปลี่ยนไฟล์การตั้งค่าเริ่มต้นหรือบันทึกโทเค็น ลบหรือกู้คืนการส่งออกที่ตรงกันในไฟล์เริ่มต้นเชลล์ของคุณและล้างค่าเก่าออกจากเชลล์ปัจจุบัน `omniroute launch` และ `omniroute run claude` ตั้งค่าเกตเวย์ URL และโทเค็นสำหรับกระบวนการลูกเท่านั้น

สำหรับ Codex ให้กู้คืนผู้ให้บริการและโมเดลก่อนหน้าใน `~/.codex/config.toml` หากมี `model_provider = "omniroute"` ลบ `[model_providers.omniroute]` หากมีการเพิ่มสำหรับเกตเวย์นี้ คืนค่าหรือลบ `openai_base_url` หากชี้ไปที่ OmniRoute สำหรับไคลเอนต์ที่เข้ากันได้กับ OpenAI ให้กู้คืนหรือล้าง `OPENAI_BASE_URL` ทุกที่ที่คุณตั้งค่าไว้สำหรับ OmniRoute

### 3. ตรวจสอบว่าไคลเอ็นต์ใช้งานได้เมื่อ OmniRoute หยุดทำงานแล้ว

ตรวจสอบการตั้งค่ารหัส Claude เริ่มต้นและสภาพแวดล้อมเชลล์ปัจจุบัน

```bash
grep -n ANTHROPIC ~/.claude/settings.json
env | grep ANTHROPIC
```

การตรวจสอบไม่ควรแสดง `ANTHROPIC_BASE_URL` ชี้ไปที่ OmniRoute หากคุณใช้การตั้งค่าโปรไฟล์หรือโปรเจ็กต์ ให้ตรวจสอบไฟล์เหล่านั้นด้วย เมื่อ OmniRoute หยุดทำงานและกู้คืนการรับรองความถูกต้องตามปกติของคุณแล้ว ให้เรียกใช้ Claude Code โดยตรง

```bash
claude -p "say hello"
```

รหัส Claude ควรตอบสนองโดยใช้การกำหนดค่าที่กู้คืน หากยังคงชี้ไปที่เกตเวย์ที่หยุด แสดงว่าคำขอล้มเหลวโดยมีข้อผิดพลาดในการเชื่อมต่อ

## ถอนการติดตั้งอย่างรวดเร็ว (v3.6.2 +)

> [คืนค่าการกำหนดค่าไคลเอ็นต์](#revert-client-configuration) ก่อน ขณะที่ OmniRoute ยังคงทำงานอยู่

OmniRoute มีสคริปต์ในตัวสองตัวสำหรับการลบออกทั้งหมด:

### เก็บข้อมูลของคุณ

```bash
npm run uninstall
```

สิ่งนี้จะลบแอปพลิเค OmniRoute แต่** เก็บรักษา** ฐานข้อมูล การกำหนดค่า คีย์ API และการตั้งค่าผู้ให้บริการใน `~/.omniroute/` ใช้สิ่งนี้หากคุณวางแผนที่จะติดตั้งใหม่ในภายหลังและต้องการรักษาการตั้งค่าของคุณไว้

### การกำจัดแบบเต็ม

```bash
npm run uninstall:full
```

สิ่งนี้จะลบแอปพลิเคชัน** และลบล้างอย่างถาวร** ข้อมูลทั้งหมด:

- ฐานข้อมูล (`storage.sqlite`)
- การกำหนดค่าผู้ให้บริการและคีย์ API
- ไฟล์สำรอง
- ไฟล์บันทึก
- ไฟล์ทั้งหมดในไดเร็กทอรี `~/.omniroute/`

> ⚠️** คำเตือน:** `npm run uninstall:full` ไม่สามารถย้อนกลับได้ การเชื่อมต่อผู้ให้บริการ คอมโบ คีย์ API และประวัติการใช้งานทั้งหมดของคุณจะถูกลบอย่างถาวร

## ถอนการติดตั้งด้วยตนเอง

> [คืนค่าการกำหนดค่าไคลเอ็นต์](#revert-client-configuration) ก่อน ขณะที่ OmniRoute ยังคงทำงานอยู่

### การติดตั้ง NPM ทั่วโลก

```bash
# Remove the global package
npm uninstall -g omniroute

# (Optional) Remove data directory
rm -rf ~/.omniroute
```

### pnpm การติดตั้งทั่วโลก

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# Stop and remove the container
docker stop omniroute
docker rm omniroute

# Remove the volume (deletes all data)
docker volume rm omniroute-data

# (Optional) Remove the image
docker rmi cheaperinference/omniroute:latest
# Older installs pulled the legacy name:
docker rmi diegosouzapw/omniroute:latest
```

### Docker เขียน

```bash
# Stop and remove containers
docker compose down

# Also remove volumes (deletes all data)
docker compose down -v
```

### แอปเดสก์ท็อป Electron

**Windows:**

- เปิด `Settings → Apps → OmniRoute → Uninstall`
- หรือเรียกใช้โปรแกรมถอนการติดตั้ง NSIS จากไดเร็กทอรีการติดตั้ง

**macOS:**

- ลาก `OmniRoute.app` จาก `/Applications` ไปที่ถังขยะ
- ลบข้อมูล: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- ลบไฟล์ AppImage
- ลบข้อมูล: `rm -rf ~/.omniroute`

### การติดตั้งแหล่งที่มา (โคลน git)

```bash
# Remove the cloned directory
rm -rf /path/to/omniroute

# (Optional) Remove data directory
rm -rf ~/.omniroute
```

## ไดเรกทอรีข้อมูล

ตามค่าเริ่มต้น OmniRoute จะจัดเก็บข้อมูลไว้ในตำแหน่งต่อไปนี้:

| แพลตฟอร์ม  | พาธเริ่มต้น                       | การกำหนดทับ                         |
| ---------- | --------------------------------- | ----------------------------------- |
| Linux      | `~/.omniroute/`                   | ตัวแปรสภาพแวดล้อม `DATA_DIR`        |
| macOS      | `~/.omniroute/`                   | ตัวแปรสภาพแวดล้อม `DATA_DIR`        |
| Windows    | `%APPDATA%/omniroute/`            | ตัวแปรสภาพแวดล้อม `DATA_DIR`        |
| Docker     | `/app/data/` (โวลุ่มที่เมานต์ไว้) | ตัวแปรสภาพแวดล้อม `DATA_DIR`        |
| รองรับ XDG | `$XDG_CONFIG_HOME/omniroute/`     | ตัวแปรสภาพแวดล้อม `XDG_CONFIG_HOME` |

### ไฟล์ในไดเรกทอรีข้อมูล

| ไฟล์/ไดเรกทอรี       | คำอธิบาย                                           |
| -------------------- | -------------------------------------------------- |
| `storage.sqlite`     | ฐานข้อมูลหลัก (ผู้ให้บริการ คอมโบ การตั้งค่า คีย์) |
| `storage.sqlite-wal` | บันทึกการเขียนล่วงหน้าของ SQLite (ชั่วคราว)        |
| `storage.sqlite-shm` | หน่วยความจำที่ใช้ร่วมกันของ SQLite (ชั่วคราว)      |
| `call_logs/`         | คลังเพย์โหลดของคำขอ                                |
| `backups/`           | ข้อมูลสำรองของฐานข้อมูลอัตโนมัติ                   |
| `log.txt`            | บันทึกคำขอแบบเดิม (ไม่บังคับ)                      |

## ตรวจสอบว่าลบออกโดยสมบูรณ์

หลังจากถอนการติดตั้ง ให้ตรวจสอบว่าไม่มีไฟล์ใดหลงเหลืออยู่:

```bash
# ตรวจสอบแพ็กเกจ npm ที่ติดตั้งแบบส่วนกลาง
npm list -g omniroute 2>/dev/null

# ตรวจสอบไดเรกทอรีข้อมูล
ls -la ~/.omniroute/ 2>/dev/null

# ตรวจสอบโปรเซสที่กำลังทำงาน
pgrep -f omniroute
```

หากยังมีโปรเซสใดกำลังทำงานอยู่ ให้หยุดโปรเซสนั้น:

```bash
pkill -f omniroute
```
