ติดตั้งแดชบอร์ด OmniRoute เป็น Progressive Web App เพื่อเปิดจากหน้าจอหลักหรือเดสก์ท็อปในหน้าต่างแบบสแตนด์อโลน แอปที่ติดตั้งยังคงต้องการการเชื่อมต่อกับเซิร์ฟเวอร์ OmniRoute ของคุณเพื่อการนำทาง ข้อมูลแดชบอร์ด และคำขอ API สินทรัพย์คงที่ที่แคชไว้ไม่มีเกตเวย์ออฟไลน์หรือแดชบอร์ดออฟไลน์

## PWA คืออะไร?

Progressive Web App ใช้เว็บแดชบอร์ดพร้อมไอคอนแอพและหน้าต่างแยกต่างหาก เมื่อติดตั้งแล้ว OmniRoute:

- เปิดตัวจากหน้าจอหลักหรือเดสก์ท็อปของคุณ
- เปิดในโหมดสแตนด์อโลน โดยไม่มีแถบที่อยู่และแท็บตามปกติของเบราว์เซอร์
- แคชสินทรัพย์คงที่ที่เลือก
- รองรับแนวตั้งและแนวนอน

## การติดตั้ง

ใช้ที่อยู่ HTTPS สำหรับเซิร์ฟเวอร์บนอุปกรณ์อื่น เมื่อเซิร์ฟเวอร์ทำงานบนอุปกรณ์เดียวกัน `http://localhost:20128` จะมีคุณสมบัติตรงตามข้อกำหนดในการติดตั้งเบราว์เซอร์ด้วย ที่อยู่ `http://YOUR_IP:20128` ธรรมดาไม่ตรงตามข้อกำหนดเหล่านั้น เมนูการติดตั้งและข้อความแจ้งจะขึ้นอยู่กับเบราว์เซอร์และระบบปฏิบัติการ ดู [ข้อกำหนดการติดตั้ง PWA ของ MDN](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable#https_localhost_or_loopback_are_required)

### แอนดรอยด์ (โครม)

1. เปิดที่อยู่ OmniRoute HTTPS ของคุณหรือ `http://localhost:20128` สำหรับเซิร์ฟเวอร์บนโทรศัพท์เครื่องเดียวกัน
2. เปิด**⋮** เมนูแล้วเลือก** ติดตั้งแอป** หรือ** เพิ่มไปที่หน้าจอหลัก** ถ้ามีการนำเสนอ
3. ยืนยันข้อความแจ้ง
4. เปิด OmniRoute จากหน้าจอหลัก

### iOS (ซาฟารี)

1. เปิดที่อยู่ OmniRoute HTTPS ของคุณใน Safari
2. แตะ** แบ่งปัน** →** เพิ่มไปที่หน้าจอหลัก** .
3. ยืนยันชื่อแล้วแตะ** เพิ่ม** .
4. เปิด OmniRoute จากหน้าจอหลัก

### เดสก์ท็อป (Chrome / Edge)

1. เปิดแดชบอร์ด OmniRoute ของคุณ
2. ใช้ไอคอนการติดตั้งของเบราว์เซอร์หรือ** ติดตั้งแอป** รายการเมนูหากมีการเสนอ
3. ยืนยันข้อความแจ้งให้เปิด OmniRoute ในหน้าต่างของตัวเอง

## คุณสมบัติ

### หน้าต่างแบบสแตนด์อโลน

รายการตั้งค่า `display: "standalone"` และ `start_url: "/dashboard"` แอปที่ติดตั้งจะเปิดแดชบอร์ดในหน้าต่างแอป ส่วนควบคุมเบราว์เซอร์และระบบปฏิบัติการยังคงปรากฏอยู่ ไฟล์ Manifest ไม่ได้ขอโหมดเต็มหน้าจอ

### สินทรัพย์แคชและข้อกำหนดเครือข่าย

[พนักงานบริการ](../../public/sw.js) แคชทรัพยากรที่มีต้นกำเนิดเดียวกันที่เลือก:

| คำขอหรือทรัพย์สิน                        | กลยุทธ์                | พฤติกรรม                                                                                                       |
| ---------------------------------------- | ---------------------- | -------------------------------------------------------------------------------------------------------------- |
| ทรัพยากรเวลาติดตั้ง                      | แคชล่วงหน้า            | `/`, `/manifest.webmanifest`, `/icon-512.png` และ `/apple-touch-icon.png` ถูกแคชระหว่างการติดตั้งผู้ปฏิบัติงาน |
| สินทรัพย์คงที่Next.js (`/_next/`)        | เครือข่ายเป็นอันดับแรก | การตอบกลับที่สำเร็จจะอัปเดตแคช ข้อผิดพลาดของเครือข่ายกลับไปเป็นการตอบกลับที่แคชไว้ที่มีอยู่                    |
| CSS, JS, รูปภาพและแบบอักษรแบบคงที่อื่น ๆ | แคชก่อน                | การตอบสนองที่แคชไว้ที่มีอยู่จะถูกนำมาใช้ซ้ำ การตอบสนองของเครือข่ายที่ประสบความสำเร็จจะถูกแคชไว้โดยพลาด         |
| การนำทางหน้า                             | บายพาส                 | เบราว์เซอร์ดึงข้อมูลเพจโดยตรง ไม่มีการแสดงทางเลือกแบบออฟไลน์                                                   |
| API แดชบอร์ด และเส้นทางการตรวจสอบสิทธิ์  | บายพาส                 | ผู้ปฏิบัติงานไม่ขัดขวางหรือแคชคำขอเหล่านี้                                                                     |
| คำขออื่นๆ ที่ไม่คงที่                    | เครือข่าย              | ไม่มีการค้นหาแคชหรือที่เก็บข้อมูล                                                                              |

เส้นทางที่ยกเว้นคือ `/api`, `/a2a`, `/dashboard`, `/v1`, `/v1beta`, `/models`, `/chat`, `/responses`, `/codex`, `/callback` และ `/login` จับคู่ตัวพิมพ์เล็กและตัวพิมพ์ใหญ่ที่ขอบเขตเส้นทาง คำขอข้ามต้นทางและคำขอที่ไม่ใช่ GET จะข้ามผู้ปฏิบัติงานเช่นกัน

### หน้าการเชื่อมต่อ

หน้า `/offline` จะแสดงข้อความการเชื่อมต่อ ตัวบ่งชี้ online/offline เช่น** ลองเชื่อมต่ออีกครั้ง** ปุ่มและลิงค์ไปยังหน้าสถานะ มันคือ** ไม่ใช่แคชล่วงหน้า** และพนักงานบริการทำ** ไม่** เปลี่ยนเส้นทางการนำทางล้มเหลวไป การมีอยู่ของมันไม่ได้ทำให้เพจใหม่สามารถเข้าถึงได้โดยไม่มีเซิร์ฟเวอร์

### ไอคอนแอพ

รายการโฆษณาไอคอน PNG เหล่านี้:

| ไฟล์                   | ขนาด    | ใช้                       |
| ---------------------- | ------- | ------------------------- |
| `icon-192.png`         | 192×192 | ไอคอนแอปทั่วไป            |
| `icon-512.png`         | 512×512 | ไอคอนแอปทั่วไปและมาสก์ได้ |
| `apple-touch-icon.png` | 180×180 | ไอคอนหน้าจอโฮมของ Apple   |

เบราว์เซอร์เลือกไอคอนที่เหมาะสมสำหรับเป้าหมายการติดตั้ง

### การลงทะเบียนอัตโนมัติ

`PwaRegister` จะลงทะเบียนผู้ปฏิบัติงานในการผลิตเมื่อเบราว์เซอร์รองรับผู้ปฏิบัติงานบริการ โหมดการพัฒนาจะยกเลิกการลงทะเบียนผู้ปฏิบัติงานและล้างแคชเพื่อหลีกเลี่ยงเนื้อหาเก่าที่รบกวนการโหลดซ้ำแบบร้อน ข้อความแจ้งการติดตั้งยังคงเป็นการตัดสินใจของเบราว์เซอร์

## สถาปัตยกรรมทางเทคนิค

### รายการแอปพลิเคชันบนเว็บ

Next.js สร้าง `/manifest.webmanifest` จาก [`src/app/manifest.ts`](../../src/app/manifest.ts) การตั้งค่าที่สำคัญคือ:

| การตั้งค่า       | ค่า                                    |
| ---------------- | -------------------------------------- |
| `short_name`     | `OmniRoute`                            |
| `start_url`      | `/dashboard`                           |
| `scope`          | `/`                                    |
| `display`        | `standalone`                           |
| `orientation`    | `any`                                  |
| สีพื้นหลังและธีม | จานสีแสงเริ่มต้นจาก `PWA_THEME_COLORS` |

ชื่อและคำอธิบายของรายการเป็นค่าคงที่ในไฟล์ต้นฉบับนั้น รายการที่ติดตั้งไม่เป็นไปตามการตั้งค่าชื่ออินสแตนซ์หรือจานสีที่ใช้งานอยู่ในการเข้าชมทุกครั้ง

### พนักงานบริการ

[`public/sw.js`](../../public/sw.js) ไม่มีการพึ่งพากรอบงานบริการ:

- **ติดตั้ง:** แคชทรัพยากรสี่รายการที่ระบุไว้ข้างต้นล่วงหน้าและเปิดใช้งานผู้ปฏิบัติงานใหม่
- **เปิดใช้งาน:** ลบแคชรุ่นเก่าและไคลเอ็นต์การอ้างสิทธิ์
- **ดึงข้อมูล:** ใช้กลยุทธ์สินทรัพย์คงที่และการยกเว้นเส้นทางด้านบน
- **การกำหนดเวอร์ชัน:** ชื่อแคชต้นทางคือ `omniroute-pwa-v3`; บิลด์การผลิตจะประทับตราข้อมูลเฉพาะตัวของแคช
- **การแจ้งเตือน:** จัดการเหตุการณ์ `push` ที่เข้ามา และเน้นหรือเปิดหน้าต่างเมื่อมีการคลิกการแจ้งเตือน

ตัวจัดการเหตุการณ์พุชเพียงอย่างเดียวไม่ได้สร้างการสมัครสมาชิกพุชที่ใช้งานอยู่หรือการส่งมอบเซิร์ฟเวอร์ที่กำหนดค่าไว้ อย่าถือว่าการแจ้งเตือนถูกเปิดใช้งานเพียงเพราะมีการติดตั้ง PWA

### เค้าโครงข้อมูลเมตาและการลงทะเบียน

[`src/app/layout.tsx`](../../src/app/layout.tsx) มีลิงก์รายการ, ข้อมูลเมตาแบบสแตนด์อโลนของ Apple, สีของธีม และ `viewport-fit: cover` ชื่อหน้าและชื่อเว็บแอป Apple ใช้ชื่ออินสแตนซ์ สีของธีมเบราว์เซอร์สดเป็นไปตามจานสี รายการการติดตั้งใช้สีอ่อนเริ่มต้น

[`PwaRegister`](../../src/shared/components/PwaRegister.tsx) ทำงานบนไคลเอนต์และลงทะเบียน `/sw.js` ด้วย build ID ใน URL ตรวจพบการสร้างแคชที่ไม่ตรงกันและสามารถรีเซ็ตผู้ปฏิบัติงานและโหลดซ้ำหนึ่งครั้งเพื่อกู้คืนจากการติดตั้งแบบเก่า การลงทะเบียนล้มเหลวไม่ได้ปิดกั้นแดชบอร์ด

## ใช้กับ Termux (Android)

1. เริ่ม OmniRoute ใน Termux: `npx -y omniroute@latest`
2. เปิด Chrome บนโทรศัพท์เครื่องเดียวกัน: `http://localhost:20128`
3. ติดตั้ง PWA ผ่านเมนูการติดตั้งของเบราว์เซอร์
4. ให้เซิร์ฟเวอร์ Termux ทำงานในขณะที่ใช้แดชบอร์ด

โทรศัพท์โฮสต์ทั้งเกตเวย์และแดชบอร์ด คำขอไปยังผู้ให้บริการ AI ระยะไกลยังคงต้องมีการเข้าถึงเครือข่าย ดู [คู่มือ Termux](TERMUX_GUIDE.md) สำหรับการตั้งค่าและข้อควรพิจารณาตลอดอายุการใช้งานกระบวนการ Android

## ใช้จากอุปกรณ์อื่น

เปิดที่อยู่ HTTPS ของเซิร์ฟเวอร์บนโทรศัพท์ แท็บเล็ต หรือเดสก์ท็อป จากนั้นทำตามขั้นตอนการติดตั้งของเบราว์เซอร์นั้น เซิร์ฟเวอร์จะต้องสามารถเข้าถึงได้จากแต่ละอุปกรณ์ ดู [คำแนะนำอุโมงค์](../ops/TUNNELS_GUIDE.md) สำหรับตัวเลือกการเข้าถึงระยะไกล

## การปรับแต่ง

### ชื่ออินสแตนซ์

ที่** ชื่ออินสแตนซ์** การตั้งค่าจะเปลี่ยนข้อมูลเมตาของแดชบอร์ด รวมถึงชื่อหน้าและชื่อเว็บแอปของ Apple ไฟล์ Manifest ที่สร้างขึ้นจะใช้ชื่อคงที่ ดังนั้นการตั้งค่านี้จึงไม่รับประกันว่าจะเปลี่ยนชื่อแอปที่ติดตั้งไว้แล้ว

### Favicon แบบกำหนดเอง

favicon แบบกำหนดเองจะเปลี่ยน favicon ของเบราว์เซอร์ รายการการติดตั้งยังคงโฆษณาไฟล์ PNG ด้านบน การเปลี่ยน favicon ไม่ได้แทนที่ไอคอนบนหน้าจอหลักเหล่านั้น

## ข้อจำกัด

- **จำเป็นต้องเชื่อมต่อเซิร์ฟเวอร์:** การนำทางหน้า สถานะแดชบอร์ด และคำขอ API ไม่มีทางเลือกแบบออฟไลน์
- **ไม่มีการซิงค์พื้นหลัง:** การกระทำแบบออฟไลน์ไม่ได้ถูกจัดคิวเพื่อเล่นซ้ำ
- **ความแตกต่างของเบราว์เซอร์:** เมนูการติดตั้ง การนำเสนอหน้าต่าง และการสนับสนุนการแจ้งเตือนจะแตกต่างกันไปตามแพลตฟอร์ม
- **ไม่มีแคชการตอบสนอง API :** ผู้ปฏิบัติงานไม่รวมเส้นทาง API, แดชบอร์ด และการตรวจสอบสิทธิ์
- **ไอคอนการติดตั้งแบบคงที่:** การอัปเดตไอคอนเหล่านั้นจำเป็นต้องเปลี่ยนเนื้อหาที่โฆษณา เบราว์เซอร์อาจเก็บข้อมูลเมตาที่ติดตั้งไว้
