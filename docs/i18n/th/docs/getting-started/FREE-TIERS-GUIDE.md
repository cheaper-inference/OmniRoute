> **TL;DR** : นำบัญชีผู้ให้บริการที่มีสิทธิ์มาเอง OmniRoute รวมการเชื่อมต่อที่คุณกำหนดค่าไว้ มันไม่ได้ออกงบประมาณโทเค็นรวมที่โฆษณาไว้ การเข้าถึงแบบฟรีอาจต้องมีการลงชื่อสมัครใช้ รหัส API การอนุมัติ หรือวิธีการชำระเงิน ข้อจำกัดของผู้ให้บริการ นโยบายความเป็นส่วนตัว และข้อกำหนดยังคงมีผลบังคับใช้

## ระดับฟรีคืออะไร?

ผู้ให้บริการ AI หลายรายเสนอรูปแบบบางอย่างของ** เข้าถึงได้ฟรี** . นั่นอาจหมายถึงจุดสิ้นสุดที่ไม่มีการตรวจสอบสิทธิ์ โควต้าที่เกิดซ้ำ การเข้าถึงแบบไม่จำกัดอัตรา การอนุญาตให้ลงทะเบียน การอนุมัติด้วยตนเอง หรือการเลื่อนตำแหน่งชั่วคราว ทั้งนี้ขึ้นอยู่กับผู้ให้บริการ ตัวเลือกบางอย่างจำเป็นต้องมีบัญชี, รหัส API, บัตรเครดิต, KYC หรือการยอมรับข้อกำหนดเฉพาะของผู้ให้บริการ

OmniRoute** มวลรวม** กำหนดค่าการเชื่อมต่อไว้ในปลายทางเดียว คุณยังคงลงทะเบียนแยกกันสำหรับผู้ให้บริการแต่ละรายที่ต้องมีบัญชี เชื่อมต่อบัญชีเหล่านั้นและใช้ `model: "auto"` เพื่อกำหนดเส้นทางระหว่างเป้าหมายที่มีสิทธิ์ การติดตั้งใหม่ต้องไม่มีเป้าหมายแบบไร้กุญแจที่เข้าเกณฑ์ การติดตั้ง OmniRoute เพียงอย่างเดียวไม่ได้รับประกันว่าการแชทจะตอบกลับได้สำเร็จ

## วิธีซ้อน Tiers ฟรี

ความมหัศจรรย์ของ OmniRoute คือ** ซ้อนชั้นฟรี** . แทนที่จะพึ่งพาผู้ให้บริการรายเดียว คุณสามารถเชื่อมต่อผู้ให้บริการฟรีหลายรายและให้ OmniRoute เลือกผู้ให้บริการที่ดีที่สุดสำหรับแต่ละคำขอโดยอัตโนมัติ

### ตัวอย่าง: การครอบคลุม Free-Tier ที่กว้างขึ้น

เชื่อมต่อผู้ให้บริการหลายรายเพื่อลดการพึ่งพาโควต้าเดียว:

1. **Gemini** โควต้าคีย์ API ที่เกิดซ้ำ —
2. **Groq** โควต้าคีย์ API ที่เกิดซ้ำ —
3. **การผสมเกสร** — keyless การเข้าถึงแบบจำกัดอัตรา
4. **LongCat** — ให้สิทธิ์ในการสมัครเพียงครั้งเดียว (ต้องใช้ KYC)

จากนั้นใช้ `model: "auto"` และ OmniRoute จะ:

- ลองใช้การเชื่อมต่อที่มีสิทธิ์อันดับสูงสุดก่อน
- หากโควต้าหรือการตรวจสอบสภาพล้มเหลว → ลองใช้ผู้ให้บริการที่กำหนดค่าถัดไป
- หากผู้ให้บริการแบบไร้กุญแจไม่พร้อมใช้งาน → ให้ดำเนินการต่อผ่านเป้าหมายที่เหลือ
- หากไม่มีการเชื่อมต่อที่มีสิทธิ์สำเร็จ → จะส่งคืนข้อผิดพลาด เครดิตการสมัครใช้งานได้เฉพาะในขณะที่ยังใช้ได้และพร้อมใช้งานเท่านั้น

**ผลลัพธ์** : การครอบคลุม Free Tier ที่กว้างขึ้นพร้อมทางเลือกสำรองอัตโนมัติ — ไม่รับประกันความจุแบบไม่จำกัด

## วิธีเชื่อมต่อผู้ให้บริการฟรี

### ขั้นตอนที่ 1: เปิดแดชบอร์ด

ไปที่ `http://localhost:20128` ในเบราว์เซอร์ของคุณ

### ขั้นตอนที่ 2: ไปที่ผู้ให้บริการ

คลิก** ผู้ให้บริการ** ในแถบด้านข้าง

### ขั้นตอนที่ 3: คลิกเพิ่มผู้ให้บริการ

คลิกที่**+ เพิ่มผู้ให้บริการ** ปุ่ม.

### ขั้นตอนที่ 4: เลือกผู้ให้บริการฟรี

เรียกดูแค็ตตาล็อกและตรวจสอบข้อมูล `hasFree`, auth, โควต้า ความเป็นส่วนตัว และข้อมูลเมตา ToS ของผู้ให้บริการแต่ละราย บัตรผู้ให้บริการและ [การอ้างอิง Free Tiers](../reference/FREE_TIERS.md) จะแยกแยะความแตกต่างระหว่างพูลที่เกิดซ้ำ การเข้าถึง uncapped/keyless เครดิตการลงทะเบียน รายการที่ถูกยกเลิก และแหล่งที่มาที่มีความเสี่ยงสูงกว่า

### ขั้นตอนที่ 5: คลิก เชื่อมต่อ

สำหรับผู้ให้บริการ `NOAUTH` นั้น OmniRoute จะไม่ขอข้อมูลรับรองอัปสตรีม สิ่งนี้ไม่ได้รับประกันว่าอัพสตรีมจะยอมรับไคลเอนต์บุคคลที่สามหรือมีความจุที่พร้อมใช้งาน ผู้ให้บริการ OAuth และคีย์ API ต้องเชื่อมต่อผ่านโฟลว์บัญชีที่บันทึกไว้ ลูกค้าของคุณยังคงใช้คีย์ OmniRoute API ที่สร้างขึ้น** แดชบอร์ด → API คีย์** (แสดงเพียงครั้งเดียวตอนสร้าง) เมื่อเปิดใช้งานการรับรองความถูกต้องของเราเตอร์

### ขั้นตอนที่ 6: ทำซ้ำ

เชื่อมต่อผู้ให้บริการหลายรายที่มีข้อกำหนดและรูปแบบความเป็นส่วนตัวที่เหมาะกับกรณีการใช้งานของคุณ

## มาจาก dsh "โมเดลฟรีของเรา"

ปลั๊กอิน [dsh-our-free-model](https://github.com/Ebony-Vinyl/dsh-our-free-model) สำหรับโฮสต์เอเจนต์ dsh มาถึงสองอัปสตรีม OmniRoute มีผู้ให้บริการสำหรับแต่ละรายอยู่แล้ว แต่มีเพียงหนึ่งในนั้นเท่านั้นที่เป็นเส้นทางอิสระใน OmniRoute:

| เลนปลั๊กอิน | ต้นน้ำ                                     | ผู้ให้บริการ OmniRoute       | ฟรีใน OmniRoute? | วิธีการเชื่อมต่อ                                                          |
| ----------- | ------------------------------------------ | ---------------------------- | ---------------- | ------------------------------------------------------------------------- |
| ช่องกิโล    | เกตเวย์กิโล AI (`api.kilo.ai/api/gateway`) | `kilo-gateway` (นามแฝง `kg`) | ใช่              | คีย์API เป็นทางเลือก: ปล่อยว่างไว้เพื่อใช้พูลฟรีของเกตเวย์                |
| เลนฟรี      | OpenCode เซน (`opencode.ai`)               | `opencode-zen`               | เลขที่           | คีย์ OpenCode API ของคุณเองจาก [opencode.ai/zen](https://opencode.ai/zen) |

**กิโล.** เรียกพูลฟรีเป็น `kilo-gateway/<model>` หรือ `kg/<model>` เช่น `kg/kilo-auto/free` (เราเตอร์อัตโนมัติฟรีของ Kilo) หรือหนึ่งในโมเดล `:free` ของเกตเวย์ ชุดอิสระหมุน; `kilo-gateway` ส่งผ่านรหัสโมเดลที่ไม่อยู่ในรายการบิวท์อินของ OmniRoute ดังนั้นจึงสามารถเรียกโมเดลรายการเกตเวย์ในปัจจุบันได้ก่อนที่แค็ตตาล็อกจะรวมไว้ การ์ดโมเดลฟรีของ Kilo บอกว่าผู้ให้บริการอัปสตรีมอาจบันทึกข้อความเตือนไว้ และใช้เพื่อปรับปรุงบริการ ดังนั้นอย่าส่งข้อมูลที่ละเอียดอ่อน

**OpenCode** เลนฟรีของปลั๊กอินคือข้อเสนอแบบไม่มีคีย์ของ OpenCodeOmniRoute ไม่ได้ให้ข้อเสนอดังกล่าวเป็นการเข้าถึงฟรี:

- ผู้ให้บริการ OpenCode แบบไม่มีคีย์ของ OmniRoute ถูกลบออกตามคำขอของผู้ดำเนินการของ OpenCode(ดูที่ [Removed Providers](../reference/REMOVED_PROVIDERS.md) )
- [เอกสารปลายทาง](https://opencode.ai/v2/docs/console/models/#endpoints) ของ OpenCode เชื่อมโยงข้อเสนอการแชทฟรีกับไคลเอนต์ของ OpenCode ดังนั้น OmniRoute จะไม่นับหรือติดป้ายว่าฟรี

รหัสโมเดลที่ปลั๊กอินแสดง เช่น `deepseek-v4.1-flash-free`, `mimo-v2.6-flash-free` และ `nemotron-3.5-lightning-free` อยู่ในแค็ตตาล็อก `opencode-zen` เชื่อมต่อ `opencode-zen` กับคีย์ OpenCode ของคุณเองเพื่อใช้ภายใต้เงื่อนไขของบัญชี OpenCode ของคุณ

**พอร์ตท้องถิ่นของปลั๊กอิน** ปลั๊กอินสามารถเปิดเผยโมเดลบนพอร์ตที่เข้ากันได้กับ OpenAI ในเครื่อง (ค่าเริ่มต้น `18899`) จุดสิ้นสุดใดๆ ดังกล่าวสามารถเพิ่มเป็น [ผู้ให้บริการที่เข้ากันได้กับ OpenAI แบบกำหนดเองได้](../guides/USER_GUIDE.md#custom-openai-compatible-providers) แต่ OmniRoute จะไม่ติดตั้ง เริ่มต้น หรืออัปเดตปลั๊กอิน และปลั๊กอินจะตัดสินใจว่าอัปสตรีมใดให้บริการแต่ละคำขอ ข้อจำกัด OpenCode ข้างต้นใช้กับข้อเสนอของ OpenCode ไม่ว่าลูกค้ารายใดจะส่งคำขอ

## การอ่านแคตตาล็อกอย่างถูกต้อง

- `NOAUTH` หมายถึง OmniRoute ไม่ได้ขอข้อมูลรับรองผู้ให้บริการจากคุณ ไม่รับประกันความพร้อมใช้งาน ความเป็นส่วนตัว หรือความจุไม่จำกัด
- `hasFree` คือข้อมูลเมตาการค้นพบ ซึ่งอาจแสดงถึงโควต้าที่เกิดซ้ำ การเข้าถึงแบบไม่ใช้คีย์ เครดิตในการสมัคร โปรแกรมการอนุมัติ หรือการส่งเสริมการขาย
- `recurring-uncapped` หมายถึงไม่มีเพดานโทเค็นที่เผยแพร่; ยังคงมีการใช้ข้อจำกัดอัตราและการทำงานพร้อมกัน
- `one-time-initial` จะไม่เกิดขึ้นอีกหลังจากใช้สิทธิ์การสมัครใช้งานหมดแล้ว
- ผู้ให้บริการ `tos: avoid` จะไม่รวมอยู่ในการกำหนดเส้นทางอัตโนมัติตามค่าเริ่มต้น (`excludeTosAvoid`) การเชื่อมต่อบัญชีไม่ได้ข้ามตัวกรองนี้ การแทนที่ตัวดำเนินการใดๆ ควรเป็นไปตามการทบทวนข้อกำหนดของผู้ให้บริการและความเสี่ยงของบัญชี
- รายการที่ทำเครื่องหมาย `discontinued` ยังคงเป็นหลักฐานทางประวัติศาสตร์ และต้องไม่นำเสนอว่าฟรีในปัจจุบัน

## OmniRoute ทำให้ Free Tiers ดีขึ้นได้อย่างไร

### 1. ทางเลือกสำรองอัตโนมัติ

หากผู้ให้บริการฟรีรายหนึ่งไม่ว่างหรือล่ม OmniRoute จะพยายามให้บริการรายถัดไปโดยอัตโนมัติ คุณไม่จำเป็นต้องทำอะไรเลย

### 2. การกำหนดเส้นทางอัจฉริยะ

OmniRoute เลือกไฟล์** ผู้ให้บริการฟรีที่ดีที่สุด** สำหรับแต่ละคำขอตาม:

- ความเร็ว — ผู้ให้บริการรายใดที่เร็วที่สุดในขณะนี้?
- คุณภาพ — ผู้ให้บริการรายใดดีที่สุดสำหรับงานนี้?
- ความจุ — ผู้ให้บริการรายใดมีโควต้าเหลืออยู่

### 3. การออมโทเค็น

ไปป์ไลน์การบีบอัดของ OmniRoute สามารถลดโทเค็น prompt และ tool-output ที่มีสิทธิ์ได้ การประหยัดจริงขึ้นอยู่กับเนื้อหา เอ็นจิ้นที่เลือก การบัญชีของผู้ให้บริการ และการตั้งค่าความเที่ยงตรง การบีบอัดไม่ได้คูณโควต้าของผู้ให้บริการทุกรายด้วยจำนวนคงที่

### 4. การสนับสนุนหลายบัญชี

หากข้อกำหนดของผู้ให้บริการอนุญาตให้มีบัญชีหรือข้อมูลประจำตัวหลายบัญชี OmniRoute สามารถถือว่าการเชื่อมต่อแต่ละรายการเป็นตัวเลือกการกำหนดเส้นทางที่แยกจากกัน อย่าสร้างบัญชีเพิ่มเติมเพื่อหลีกเลี่ยงโควต้าหรือนโยบายการเข้าถึงของผู้ให้บริการ

## คณิตศาสตร์ระดับฟรี

แค็ตตาล็อกสดที่กรองข้อมูลซ้ำซ้อนออกจากพูลรายงานในปัจจุบัน:

| เมตริก                                  |  มูลค่าที่ตรวจสอบในปัจจุบัน | การตีความ                                                                 |
| --------------------------------------- | --------------------------: | ------------------------------------------------------------------------- |
| เงินช่วยเหลือเชิงปริมาณที่เกิดขึ้นประจำ |  **~ 90M ฟรี tokens/month** | พูลที่ใช้ร่วมกันนับหนึ่งครั้ง ไม่รวมผู้ให้บริการที่ไม่ได้จำกัดไว้จากผลรวม |
| เดือนแรกพร้อมเงินช่วยเหลือในการสมัคร    | **~ 153M ในเดือนแรกของคุณ** | ยอดรวมที่เกิดซ้ำบวกเครดิตแบบครั้งเดียวและแบบเกิดซ้ำ                       |

เป็นการประมาณการทั่วทั้งแค็ตตาล็อกสำหรับบัญชีที่มีสิทธิ์แยกกัน ไม่ใช่ค่าเผื่อที่ OmniRoute มอบให้หรือการคาดการณ์สำหรับการติดตั้งใหม่ ความจุที่ใช้ได้ของคุณขึ้นอยู่กับผู้ให้บริการที่คุณเชื่อมต่อและเงื่อนไขปัจจุบัน ค่าจะถูกคำนวณจาก `open-sse/config/freeModelCatalog.ts`; ดู [การอ้างอิง Free Tiers](../reference/FREE_TIERS.md) สำหรับการขจัดข้อมูลซ้ำซ้อนของพูล แฟล็ก ToS รายการที่ถูกยกเลิก และวิธีการลงทะเบียนเครดิต

## คำถามทั่วไป

### “นี่ฟรีจริงๆ เหรอ?”

แค็ตตาล็อกจะบันทึกข้อกำหนดที่ผู้ให้บริการเผยแพร่และการวิจัยโครงการ แต่ข้อเสนอสามารถเปลี่ยนแปลงได้ ตรวจสอบราคา โควต้า นโยบายความเป็นส่วนตัว และคุณสมบัติปัจจุบันของผู้ให้บริการก่อนใช้งาน

### “ฟรีเทียร์จะหมดหรือเปล่า?”

ผู้ให้บริการทุกรายสามารถจำกัดอัตรา เปลี่ยนโมเดล ระงับการเข้าถึง หรือออฟไลน์ได้ การเชื่อมต่อหลายรายการปรับปรุงความครอบคลุมทางเลือก แต่ไม่รับประกันเส้นทางฟรีที่ใช้งานได้

### "ฉันสามารถใช้ผู้ให้บริการฟรีในการผลิตได้หรือไม่"

เฉพาะในกรณีที่ SLA การจัดการข้อมูล ขีดจำกัด และข้อกำหนดของผู้ให้บริการตรงตามข้อกำหนดในการใช้งานจริงของคุณเท่านั้น ปริมาณงานที่สำคัญควรมีการตรวจสอบทางเลือกที่เหมาะสมตามสัญญา

### "จับอะไร?"

การแลกเปลี่ยนอาจรวมถึงข้อจำกัดที่เข้มงวด รายการรอ KYC การตรวจสอบบัตรเครดิต การฝึกอบรมเกี่ยวกับการแจ้งเตือน ความเป็นส่วนตัวที่อ่อนแอลง ไม่มี SLA การเลิกใช้งานโมเดล ข้อจำกัดทางภูมิศาสตร์ การชำระเงินส่วนเกิน หรือความเสี่ยงด้านนโยบายบัญชี OmniRoute แสดงข้อมูลเมตาที่มีอยู่ คุณเลือกสิ่งที่จะเปิดใช้งาน

### "ฉันจะได้รับโควต้าฟรีมากขึ้นได้อย่างไร"

1. เชื่อมต่อผู้ให้บริการฟรีมากขึ้น
2. เปิดใช้งานเอ็นจิ้นการบีบอัดที่เหมาะสมและวัดการประหยัดสำหรับปริมาณงานของคุณ
3. ใช้ `auto/cheap` เพื่อจัดลำดับความสำคัญของผู้ให้บริการ free/cheap
4. เพิ่มผู้ให้บริการหรือข้อมูลรับรองที่ได้รับอนุญาตเพิ่มเติมโดยไม่ละเมิดข้อกำหนดของผู้ให้บริการ

### "ผู้ให้บริการฟรีมีคุณภาพแย่ลงหรือไม่"

ไม่จำเป็น. ผู้ให้บริการบางรายเปิดเผยตระกูลโมเดลเดียวกันที่มีให้บริการผ่านเส้นทางแบบชำระเงิน แต่ขีดจำกัด เวลาแฝง ความเป็นส่วนตัว ความน่าเชื่อถือ และเวอร์ชันของโมเดลอาจแตกต่างกัน ใช้หน้าอันดับผู้ให้บริการฟรีเป็นสัญญาณด้านคุณภาพและตรวจสอบโมเดลที่ให้บริการจริง
