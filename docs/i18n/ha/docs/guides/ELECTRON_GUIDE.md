> **Tushen gaskiya:** `electron/` wurin aiki** An sabunta ta ƙarshe:** 2026-06-28 — v3.8.40

OmniRoute tana jigilar ƙa'idar tebur ta giciye (Windows / macOS / Linux) wanda aka gina akansa**Electron 41** +** Mai ginin lantarki 26.10** . Aikace-aikacen tebur yana haifar da uwar garken Next.js na tsaye azaman tsari na yara, yana nuna `BrowserWindow` akansa, kuma yana ƙara tsarin tire, mai sabunta atomatik, gadar IPC, da sifili-config bootstrap.

## Gine-gine

```
┌──────────────────────────────────────────────┐
│ Electron main process (electron/main.js)     │
│ ├─ Single-instance lock                       │
│ ├─ Child process: Next.js standalone server  │
│ │   (spawned with Electron's Node runtime)   │
│ ├─ BrowserWindow → http://localhost:PORT     │
│ ├─ System tray + context menu                │
│ ├─ Auto-update via electron-updater          │
│ ├─ Content Security Policy (session headers) │
│ └─ Secret bootstrap (JWT / API_KEY_SECRET)   │
└──────────────────────────────────────────────┘
            ↕ IPC bridge (electron/preload.js)
┌──────────────────────────────────────────────┐
│ Renderer (Next.js dashboard)                  │
│   window.electronAPI.* (contextIsolation)     │
└──────────────────────────────────────────────┘
```

## Rubutun (tushen `package.json`)

| Rubutun                           | Manufar                                                                         |
| --------------------------------- | ------------------------------------------------------------------------------- |
| `npm run electron:dev`            | Fara `npm run dev` + yana jiran `localhost:20128` + ya ƙaddamar da Electron     |
| `npm run electron:build`          | Yana gina Next.js sannan yana gudanar da `electron-builder` don OS na yanzu     |
| `npm run electron:build:win`      | Yana Gina Windows NSIS mai sakawa + mai ɗaukuwa (x64)                           |
| `npm run electron:build:mac`      | Yana Gina macOS DMG (Intel + Apple Silicon)                                     |
| `npm run electron:build:linux`    | Gina Linux AppImage + DEB (x64 + hannu64)                                       |
| `npm run electron:smoke:packaged` | Ya ƙaddamar da kunshin binary da bincike `/login` akan HTTP 200, sannan ya rufe |

Wurin aikin `electron/` kuma yana fallasa:

- `npm run prepare:bundle` — gudu `scripts/build/prepare-electron-standalone.mjs`
- `npm run build:mac-x64` / `build:mac-arm64` — guda-baki macOS yana ginawa
- `npm run pack` — directory-kawai ginawa don gwaji na gida (babu mai sakawa)

## Fakitin lokacin aiki na zaɓi

Gine-ginen Desktop na iya buga rumbun adana lokaci na zaɓi tare da masu saka su. Adadin sabar uwar garken ya ƙunshi `optional-packs.index.json` (a ƙarƙashin `resources/app` akan Windows da Linux). Don shigarwar `browser-runtime`, karanta `packs[].tarball` kuma zazzage** ainihin sunan fayil daga wannan sakin** . Sunayen tarihin sun haɗa da narke SHA-256 ; gini daban-daban na iya buƙatar rumbun adana bayanai daban-daban. Rike sunan fayil ɗin da aka sauke baya canzawa.

Kwafi fihirisar ƙa'idar da aka shigar da zaɓaɓɓen tarihin zuwa cikin shugabanci ɗaya, sannan yi amfani da CLI daga wannan sakin:

```bash
omniroute packs list --source /path/to/packs
omniroute packs install browser-runtime --source /path/to/packs
```

`packs list` yana nuna yanayin shigarwa da tabbatarwa, ba sunan fayil ɗin ajiya ba. Fihirisar da aka haɗe tana zaɓin tarihin. Shigarwa yana tabbatar da kimar ajiyar ajiyar ta kafin cirewa da kuma adadin fakitinsa kafin maye gurbin fakitin da aka shigar. Yana karanta fayilolin gida; ba ya zazzage bayanan da suka ɓace. Sake kunna aikace-aikacen bayan shigarwa. Idan sakin ba shi da kadara mai dacewa, fakitin zaɓin ba ya samuwa ta hanyar kadarorin sakin.

## gadar IPC (`preload.js`)

Abubuwan da aka riga aka shigar suna fallasa jerin zaɓaɓɓun API akan `window.electronAPI` ta amfani da `contextBridge` tare da `contextIsolation: true` da `nodeIntegration: false`.

```javascript
const VALID_CHANNELS = {
  invoke: [
    "get-app-info",
    "open-external",
    "get-data-dir",
    "restart-server",
    "check-for-updates",
    "download-update",
    "install-update",
    "get-app-version",
  ],
  send: ["window-minimize", "window-maximize", "window-close"],
  receive: ["server-status", "port-changed", "update-status"],
};
```

Hanyoyin da aka fallasa:

| Kira mai sakewa                                                   | Nau'in              |
| ----------------------------------------------------------------- | ------------------- |
| `getAppInfo()` → `{ name, version, platform, isDev, port }`       | kira                |
| `openExternal(url)`                                               | kira                |
| `getDataDir()`                                                    | kira                |
| `restartServer()`                                                 | kira                |
| `getAppVersion()`                                                 | kira                |
| `checkForUpdates()` / `downloadUpdate()` / `installUpdate()`      | kira                |
| `minimizeWindow()` / `maximizeWindow()` / `closeWindow()`         | aika                |
| `onServerStatus(cb)` / `onPortChanged(cb)` / `onUpdateStatus(cb)` | karba (mai bayarwa) |

Mataimakan da aka karɓa sun dawo a** aikin watsawa** maimakon dogaro da `removeAllListeners` — wannan yana hana taruwar mai sauraro lokacin da abubuwan React suka sake hawa.

## Sabis na Rayuwa

`main.js` yana haifar da gunkin Next.js na tsaye kai tsaye tare da lokacin aikin Node Electron don gujewa rashin daidaituwar tsarin ABI -module tare da tsarin Node:

```js
spawn(process.execPath, [serverScript], {
  cwd: NEXT_SERVER_PATH,
  env: { ...serverEnv, PORT, NODE_ENV: "production", ELECTRON_RUN_AS_NODE: "1", NODE_PATH },
  stdio: "pipe",
});
```

Bambance-bambance:

- `waitForServer()` zaɓen URL har zuwa 30 s kafin a nuna taga (babu blank allo a farkon sanyi).
- `stdio: "pipe"` ta kama stdout/stderr; shirye-shiryen jimloli (`Ready` / `listening`) fitar da `server-status: running` akan IPC.
- `before-quit` tana jira har zuwa 5 s don kyakkyawan SIGTERM (WAL checkpoint) sannan aika SIGKILL.
- Port switcher a cikin tire (`20128`, `3000`, `8080`) yana tsayawa ya sake kunna uwar garken, sannan ya sake loda BrowserWindow.

## Sirrin Bootstrap na Sifili

A lokacin ƙaddamarwa na farko, babban tsari yana haifar da atomatik kuma yana ci gaba da ɓacewar sirrin:

| Sirrin                   | Source                                                                                  |
| ------------------------ | --------------------------------------------------------------------------------------- |
| `JWT_SECRET`             | `crypto.randomBytes(64).toString("hex")`                                                |
| `STORAGE_ENCRYPTION_KEY` | `crypto.randomBytes(32).toString("hex")` (ya ƙi idan an riga an ɓoye bayanan ƙididdiga) |
| `API_KEY_SECRET`         | `crypto.randomBytes(32).toString("hex")`                                                |

Nace da `<DATA_DIR>/server.env`. `DATA_DIR` ya yanke shawarar zuwa:

- Windows: `%APPDATA%\omniroute`
- Linux: `$XDG_CONFIG_HOME/omniroute` or `~/.omniroute`
- macOS: `~/.omniroute`

## Duban fayil ɗin muhalli

Kafin zubar da uwar garken, babban tsari (`getPreferredEnvFilePath()` a cikin `electron/main.js`) yana ɗauka** daya** `.env` fayil: farkon waɗannan da ke akwai.

1. `$DATA_DIR/.env`, lokacin da aka saita `DATA_DIR` a cikin mahallin da app ɗin ya ƙaddamar da shi.
2. `<resolved DATA_DIR>/.env`, ta yin amfani da kuskure iri ɗaya kamar na sama: `%APPDATA%\omniroute\.env` akan Windows, `$XDG_CONFIG_HOME/omniroute/.env` ko `~/.omniroute/.env` akan Linux da macOS.
3. `.env` a cikin tsarin aiki directory.

Babban tsari yana karanta wannan fayil ɗin kawai; Daga baya ba a haɗa 'yan takara a ciki ba. An gina mahallin uwar garke tare da wannan fifiko (mafi girma na farko):

1. Yanayin tsarin Electron (masu-bambancin da aka gada daga duk abin da aka ƙaddamar da app).
2. Fayil ɗin `.env` da aka zaɓa.
3. `<DATA_DIR>/server.env` (asirin takalmin da ke sama).

Ana ɗaukar yanayin tsari lokacin da app ɗin ya fara, don haka saitin tsarin ko mahallin mai amfani da aka saita yayin da app ɗin ke gudana (ciki har da lokacin da yake zaune a cikin tire bayan an rufe tagansa) baya isa uwar garken har sai app ɗin ya ƙare gabaɗaya kuma an sake buɗe shi. Don ƙwanƙwasa lokacin aiki kamar `CONTEXT_LENGTH_<PROVIDER>` (duba [Canje-canje na Muhalli: Tsawon mahallin kowane mai bayarwa](../reference/ENVIRONMENT.md#per-provider-context-length-context_length_provider) ), zaɓi fayil ɗin `.env`, sannan a bar cikakken (tire,** Bar** ) da sake farawa.

## Taga & Tire

- `BrowserWindow`: 1400 × 900 (min 1024 × 700), `backgroundColor: "#0a0a0a"`.
- macOS: `titleBarStyle: "hiddenInset"`, zirga-zirga a `{ x: 16, y: 16 }`.
- Windows/Linux: sandar take na asali.
- Maɓallin rufe yana rage girman zuwa tire; menu na tire yana da** Bude OmniRoute** ,** Bude Dashboard** (External browser),** Port Port** submenu,** Duba Sabuntawa** ,** Bar** .

## Manufar Tsaron Abun ciki

Saita ta hanyar `session.defaultSession.webRequest.onHeadersReceived`. Sanannen umarni:

- `frame-ancestors 'none'`, `object-src 'none'`, `child-src 'none'`
- `connect-src 'self' http://localhost:* http://127.0.0.1:* ws://localhost:* ws://127.0.0.1:* https://*.omniroute.online https://*.omniroute.dev`
- Yanayin Dev yana ƙara `'unsafe-eval'` zuwa `script-src` kawai

## Sabuntawa ta atomatik

Yana amfani da `electron-updater` tare da mai bada GitHub (`diegosouzapw/OmniRoute`).

- `autoDownload = false`, `autoInstallOnAppQuit = true`
- Abubuwan da aka tura zuwa mai gabatarwa ta IPC `update-status` `checking` `available` `not-available`, `downloading` (tare da `percent`), `downloaded`, `error`
- `installUpdate()` ya kashe uwar garken sannan ya kira `autoUpdater.quitAndInstall()`
- An tsallake shi cikin yanayin dev (`!app.isPackaged`)

## Gina Bututu

1. `npm run build` → Next.js tsaye a cikin `.next/standalone`.
2. `prepare-electron-standalone.mjs` → ya sake shiga cikin `.next/electron-standalone` kuma yana sake rubuta cikakkun hanyoyi a cikin `server.js` + `required-server-files.json` don haka za'a iya sake matsuguni.
3. kunshin `electron-builder` `main.js`, `preload.js`, `node_modules`, da `extraResources: { ../.next/electron-standalone → app }`.

### Gina manufa

| OS      | Makasudi                                   |
| ------- | ------------------------------------------ |
| Windows | NSIS mai sakawa + mai ɗaukuwa (x64)        |
| macOS   | DMG (Intel + arm64, ja-zuwa-Aikace-aikace) |

saitunan NSIS : `oneClick: false`, yana barin mai amfani ya zaɓi tsarin shigarwa, ƙirƙirar gajerun hanyoyin Desktop da Fara-Menu.

## Gina Kunshin Gwajin Hayaki

```bash
npm run electron:smoke:packaged
```

`scripts/dev/smoke-electron-packaged.mjs`:

- Ta atomatik yana gano kunshin binary a cikin `electron/dist-electron/` don dandamali na yanzu.
- Yana ƙaddamar da keɓaɓɓen kundayen adireshi na `HOME`/`APPDATA`/`XDG_*` don kada ya taɓa bayanan haɓakawa.
- Zaben `http://127.0.0.1:20128/login` na HTTP 200 a cikin s45.
- Kallon stderr/stdout don alamu masu mutuwa (`Cannot find module`, `MODULE_NOT_FOUND`, `ERR_DLOPEN_FAILED`, `Failed to start server`, da sauransu).
- Yana jira 2 s na tsayayyen lokacin gudu bayan shiri, sannan ya fitar da SIGTERM kuma yana jiran tashar jiragen ruwa ta kyauta.
- A cikin CI, ta atomatik wuce `--no-sandbox --disable-gpu` (kuma `--disable-dev-shm-usage` akan Linux).

Env ya soke: `ELECTRON_SMOKE_APP_EXECUTABLE`, `ELECTRON_SMOKE_URL`, `ELECTRON_SMOKE_TIMEOUT_MS`, `ELECTRON_SMOKE_SETTLE_MS`, `ELECTRON_SMOKE_DATA_DIR`, `ELECTRON_SMOKE_KEEP_DATA`, `ELECTRON_SMOKE_STREAM_LOGS`.

## Shiga Code

`electron/package.json` yi** ba** waya sa hannu takardun shaidarka kai tsaye. Sanya su ta hanyar env vars zuwa `electron-builder`:

### macOS

```bash
export APPLE_ID=<email>
export APPLE_APP_SPECIFIC_PASSWORD=<password>
export APPLE_TEAM_ID=<id>
export CSC_LINK=path/to/cert.p12
export CSC_KEY_PASSWORD=<cert-password>
npm run electron:build:mac
```

### Windows

```bash
export CSC_LINK=path/to/cert.pfx
export CSC_KEY_PASSWORD=<cert-password>
npm run electron:build:win
```

### Linux

sa hannun AppImage zaɓin — saita `LINUX_GPG_KEY` idan an sa hannu.
