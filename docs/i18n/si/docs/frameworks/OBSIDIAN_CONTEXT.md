## එය කුමක්ද

OmniRoute විසින් **Obsidian** vault එකක් **සන්දර්භ මූලාශ්රයක්** ලෙස සම්බන්ධ කරයි — එය
නියෝජිතයන් විසින් ගොඩනඟා ඇති MCP සේවාදායකය හරහා කියවන සහ ලියන දේශීය Markdown
දැනුම් සමුදායකි. මෙම ඒකාබද්ධකරණය ඩෙස්ක්ටොප් යෙදුම තුළ ධාවනය වන
**Obsidian Local REST API** ප්රජා ප්ලගිනය සමඟ සන්නිවේදනය කරන බැවින්, නියෝජිතයන්ට
සටහන් සෙවීමට, ගොනු කියවීමට/ලිවීමට/සංශෝධනය කිරීමට, vault එකේ අන්තර්ගතය ලැයිස්තුගත
කිරීමට, දෛනික/සතිපතා ආවර්තිතා සටහන් සමඟ කටයුතු කිරීමට, ටැග් කළමනාකරණය කිරීමට,
Obsidian විධාන ධාවනය කිරීමට සහ (විකල්පයක් ලෙස) ද්විදිශානුගත
ඩෙස්ක්ටොප්↔ජංගම vault සමමුහුර්තකරණයක් සම්බන්ධීකරණය කිරීමට හැකිය.

සේවාලාභියා (`src/lib/obsidian/api.ts`) Local REST API එක පහත පහසුකම් සමඟ ආවරණය කරයි:

- තාවකාලික `5xx` දෝෂ සඳහා **පසුබැසීමක් සහිත නැවත උත්සාහ කිරීම**, `AbortController` හරහා **තත්පර 30ක කාල සීමාවක්**.
- **වර්ගීකෘත දෝෂ වර්ගීකරණය** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`.
- සාමාන්යයෙන් සිදුවන port වරද (HTTP සඳහා `27123`, `27124` හි MCP අන්ත ලක්ෂ්යය
  **නොවේ**) සහ Tailscale ආකෘතිය පැහැදිලි කරන, මිත්රශීලී **"Obsidian වෙත ළඟා විය නොහැක" ඉඟියක්**.
- ඉඩ සහ slash අඩංගු සටහන් මාර්ග ආරක්ෂිත කිරීම සඳහා vault එකට සාපේක්ෂ **මාර්ග කේතනය**.

## පිහිටුවීම

Obsidian ටෝකනය හෝ මූලික URL සඳහා **පරිසර විචල්යයක් නොමැත** — ඒ දෙකම
`src/lib/db/obsidian.ts` හරහා SQLite `key_value` වගුවේ (`obsidian` නාම අවකාශය යටතේ)
ගබඩා කෙරේ. ටෝකනය **ගබඩා කර ඇති විට සංකේතනය කර ඇත** (AES-256-GCM, සාමාන්ය පෙළ
පසුගාමී-අනුකූලතා fallback එකක් සමඟ). Endpoint උපකරණ පුවරුවේ **Context Sources** පටිත්තෙන්
(`ObsidianSourceCard`) හෝ සැකසුම් REST API එක හරහා වින්යාස කරන්න.

> [!IMPORTANT]
> **Obsidian Local REST API** ප්ලගිනය ස්ථාපනය කර ක්රියාත්මක කර තිබිය යුතුය. එහි REST
> අතුරුමුහුණත **HTTP `127.0.0.1:27123`** මත සවන් දෙයි (පෙරනිමි මූලික URL එක). `27124`
> වරාය _වෙනම_ MCP/HTTPS අන්ත ලක්ෂ්යයක් වන අතර, සැකසුම් මාර්ගය මඟින් එය පැහැදිලිවම ප්රතික්ෂේප කරයි.
> වෙනත් උපාංගයකින් සම්බන්ධ වන්නේ නම්, `http://<tailscale-ip>:27123` භාවිත කරන්න.

### REST හරහා වින්යාස කිරීම

```bash
# Local REST API ටෝකනය සුරකින්න + වලංගු කරන්න (POST විසින් තත්ත්ව පරීක්ෂාවක් හරහා වලංගු කරයි)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# සම්බන්ධතා තත්ත්වය පරීක්ෂා කරන්න (connected, hasToken, baseUrl, vaultPath ආපසු ලබා දෙයි)
curl http://localhost:20128/api/settings/obsidian

# විසන්ධි කරන්න (ගබඩා කළ ටෝකනය ඉවත් කරයි)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

සියලු ක්රම සඳහා උපකරණ පුවරු සත්යාපනය අවශ්ය වේ. `POST` විසින් `27124` වරායේ ඇති ඕනෑම URL එකක්
ප්රතික්ෂේප කරන අතර, දත්ත ස්ථිරව ගබඩා කිරීමට පෙර Local REST API තත්ත්ව අන්ත ලක්ෂ්යය ඇමතීමෙන් ටෝකනය වලංගු කරයි.

### WebDAV vault සමමුහුර්ත කිරීම

curl http://localhost:20128/api/settings/obsidian/webdav

# WebDAV සමමුහුර්ත කිරීම අබල කරන්න (අක්තපත්ර + කළමනාකරණය කළ .stignore ඉවත් කරයි)

### ආරක්ෂාව සහ ප්‍රවාහනය

WebDAV සත්‍යාපනය එක් IP අසාර්ථක ලුහුබැඳීම සහ අගුලු දැමීම බලාත්මක කරයි (තත්පර 60 ක කවුළුවක් තුළ අසාර්ථක උත්සාහයන් 10 ක් `429 Too Many Requests` සහ `Retry-After` සමඟ මිනිත්තු 5 ක අගුලු දැමීමක් සිදු කරයි). WebDAV මූලික සත්‍යාපන අක්තපත්‍ර සම්ප්‍රේෂණය කරන බැවින්, TLS අවසන් කිරීම (හෝ Tailscale හෝ Cloudflare Tunnel වැනි ආරක්ෂිත උමගක් හරහා ගමන් කිරීම) ලූප්බැක් පිටතින් WebDAV අන්ත ලක්ෂ්‍යයට ප්‍රවේශ වීමේදී දැඩි ලෙස නිර්දේශ කෙරේ.
