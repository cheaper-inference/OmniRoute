## ඉක්මන් ආරම්භය

```ts
import { definePlugin } from "omniroute/plugins/sdk";

export default definePlugin({
  name: "my-plugin",
  priority: 50,
  onRequest: async (ctx) => {
    console.log(`Request ${ctx.requestId} for ${ctx.model}`);
  },
  onResponse: async (ctx, response) => {
    console.log(`Response for ${ctx.requestId}`);
    return response;
  },
  onError: async (ctx, error) => {
    console.error(`Error: ${error.message}`);
  },
});
```

## API යොමුව

### `definePlugin(def: PluginDefinition): Plugin`

පෙරනිමියෙන් ප්ලගින වස්තුවක් සාදන කර්මාන්තශාලා ශ්‍රිතය.

**පරාමිතීන්:**

- `name` (string, අවශ්‍ය) — ප්ලගින නම kebab-case
- `priority` (අංකය, විකල්ප, පෙරනිමිය: 100) — පහළ පළමුව ධාවනය වේ
- `enabled` (බූලියන්, විකල්ප, පෙරනිමිය: සත්‍ය) — ආරම්භය සබල කර තිබේද?
- `onRequest` (ක්‍රියාකාරීත්වය, විකල්ප) — චැට් හසුරුවන්නාට පෙර ධාවනය වේ
- `onResponse` (ක්‍රියාකාරීත්වය, විකල්ප) — කතාබස් හසුරුවන්නාට පසුව ධාවනය වේ
- `onError` (ක්‍රියාකාරීත්වය, විකල්ප) — හසුරුවන්නෙහි දෝෂය මත ධාවනය වේ

### `blockRequest(response?): BlockingHookResult`

ඉල්ලීම අවහිර කර විකල්ප වශයෙන් අභිරුචි ප්‍රතිචාරයක් ලබා දෙන්න.

```ts
onRequest: (ctx) => {
  if (!ctx.headers?.["x-client-team"]) {
    return blockRequest({ error: "Missing x-client-team header", status: 400 });
  }
};
```

### `modifyBody(body): PluginResult`

ඉල්ලුම් පත්‍රය සැපයුම්කරු වෙත ළඟා වීමට පෙර එය වෙනස් කරන්න.

```ts
onRequest: (ctx) => {
  return modifyBody({ ...ctx.body, temperature: 0.7 });
};
```

### `addMetadata(metadata): PluginResult`

ඉල්ලීම් සන්දර්භයට පාරදත්ත අමුණන්න.

```ts
onRequest: (ctx) => {
  return addMetadata({ source: "my-plugin", version: "1.0.0" });
};
```

## ප්ලගින සන්දර්භය (`PluginContext`)

| ක්ෂේත්රය     | ටයිප් කරන්න               | විස්තරය                        |
| ------------ | ------------------------- | ------------------------------ |
| `requestId`  | `string`                  | අද්විතීය ඉල්ලීම් හඳුනාගැනීම    |
| `model`      | `string`                  | ඉල්ලූ මාදිලියේ නම              |
| `provider`   | `string`                  | ඉලක්ක සපයන්නා ID               |
| `body`       | `Record<string, unknown>` | ශරීරය ඉල්ලන්න                  |
| `headers`    | `Record<string, string>`  | ඉල්ලීම් ශීර්ෂ (සටහන බලන්න)     |
| `metadata`   | `Record<string, unknown>` | විකෘති පාරදත්ත                 |
| `timestamp`  | `number`                  | කාල මුද්‍රාව ඉල්ලන්න           |
| `apiKeyInfo` | `object` (විකල්ප)         | API යතුරු පාරදත්ත (සටහන බලන්න) |

සන්දර්භය කිසිවිටක සේවාලාභියාගේ අක්තපත්‍ර රැගෙන නොයයි: `authorization`, `x-api-key`, `proxy-authorization` සහ `cookie` ශීර්ෂ ඉවත් කරනු ලැබේ (ඕනෑම ආවරණයක්), සහ `apiKeyInfo` යතුරේ පාර-දත්ත ( `id`, `name` සහ `scopes` වැනි) තබා ගනී නමුත් ප්‍රධාන අගය හෝ එහි ඇඟිලි සලකුණ `src/lib/plugins/hooks.ts` `redactPluginContext()` තුළ නොවේ. මෙය `onRequest`, `onResponse` සහ `onError` සඳහා අදාළ වේ.

## Manifest (`plugin.json`)

```json
{
  "name": "my-plugin",
  "version": "1.0.0",
  "description": "A sample plugin",
  "author": "your-name",
  "main": "index.js",
  "hooks": {
    "onRequest": { "enabled": true, "priority": 50 },
    "onResponse": true,
    "onError": false
  },
  "requires": {
    "permissions": ["network", "file-read"]
  },
  "enabledByDefault": false,
  "configSchema": {
    "apiKey": {
      "type": "string",
      "description": "API key for external service"
    },
    "maxRetries": { "type": "number", "min": 1, "max": 10, "default": 3 },
    "debug": { "type": "boolean", "default": false },
    "mode": { "type": "string", "enum": ["fast", "slow"], "default": "fast" }
  }
}
```

### Hook ප්රමුඛතාව

Hooks ප්රමුඛතාවක් සමඟ වින්යාස කළ හැකිය (අඩු අගය = පළමුව ක්රියාත්මක වේ):

```json
{
  "hooks": {
    "onRequest": { "enabled": true, "priority": 10 },
    "onResponse": { "enabled": true, "priority": 100 }
  }
}
```

නැතහොත් සරල boolean අගයන් ලෙස (පෙරනිමි ප්රමුඛතාව 100):

```json
{
  "hooks": {
    "onRequest": true,
    "onResponse": true
  }
}
```

## අවසර පද්ධතිය

පෙරනිමියෙන් ප්ලගින වේ** වැලි පෙට්ටිය දමා නැත** . සෑම සක්‍රිය ප්ලගිනයක්ම වෙනම සාමාන්‍ය Node.js ළමා ක්‍රියාවලියක් ලෙස ක්‍රියා කරයි ( `src/lib/plugins/loader.ts` හි`loadPlugin()` ) OmniRoute ලෙස එකම මෙහෙයුම් පද්ධති පරිශීලකයෙකු යටතේ, VM සන්දර්භය සහ Node.js අවසර ධජ නොමැතිව. ප්ලගින කේතයට `node:fs`, `node:child_process`, `fetch` සහ අනෙකුත් සෑම Node.js API භාවිතා කළ හැක : එය OmniRoute පරිශීලකයාට (දත්ත නාමාවලිය ඇතුළුව), වැඩසටහන් ක්‍රියාත්මක කර ජාලයට ළඟා විය හැකි ඕනෑම ගොනුවක් කියවීමට සහ ලිවීමට හැකිය.

මැනිෆෙස්ටයේ `requires.permissions` `network`, `file-read`, `file-write`, `env` සහ `exec` පිළිගනී. පෙරනිමි සැකසුම් සමඟින් `env` පමණක් ක්රියාත්මක වන විට ක්රියාත්මක වේ.

### ඇතුළත් වීමේ අවසර ආකෘතිය (`PLUGIN_PERMISSION_MODEL_ENABLED`)

`PLUGIN_PERMISSION_MODEL_ENABLED` විශේෂාංග ධජය ( `security` කාණ්ඩය,** පෙරනිමියෙන් අක්රිය** ) සෑම ප්ලගින ක්‍රියාවලියක්ම [Node.js අවසර ආකෘතියෙන්](https://nodejs.org/api/permissions.html) ආරම්භ කරයි (`--permission`, සහාය දක්වන සෑම Node.js රේඛාවකින්ම පිළිගනු ලැබේ: 22.22 +, 24 සහ 26). කොඩි `src/lib/plugins/permissionModel.ts` හි `buildPermissionModelArgs()` මගින් මැනිෆෙස්ටයෙන් ගොඩනගා ඇත. ප්ලගිනයක් සක්‍රිය වූ විට ධජය කියවනු ලැබේ, එබැවින් එය වෙනස් කිරීමෙන් පසුව සක්‍රිය කරන ලද ප්ලගීන සඳහා අදාළ වේ; එය යෙදීම සඳහා ධාවනය වන ප්ලගිනයක් අක්‍රිය කර සක්‍රිය කරන්න.

ප්ලගින දත්ත නාමාවලිය ප්ලගින මූලය අසල `plugin-data/<plugin-name>` වේ (පෙරනිමියෙන්`~/.omniroute/plugin-data/<plugin-name>`, `getPluginDataDir()`). ධජය ක්‍රියාත්මක වීමත් සමඟ, එහි මාර්ගය `PLUGIN_DATA_DIR` ලෙස ප්ලගිනය වෙත යවනු ලැබේ.

## වින්යාස යෝජනා ක්රමය

වින්යාස කළ හැකි සැකසුම් `configSchema` තුළ අර්ථ දක්වන්න:

```json
{
  "configSchema": {
    "apiKey": { "type": "string", "description": "බාහිර API යතුර" },
    "maxRetries": { "type": "number", "min": 1, "max": 10, "default": 3 },
    "debug": { "type": "boolean", "default": false },
    "mode": { "type": "string", "enum": ["fast", "slow"], "default": "fast" }
  }
}
```

ක්ෂේත්ර වර්ග: `string`, `number`, `boolean`, `select`

ක්ෂේත්ර විකල්ප: `default`, `min`, `max`, `enum`, `description`

වින්යාස අගයන් දත්ත සමුදාය තුළ සුරැකෙන අතර උපකරණ පුවරුවේ වින්යාස පිටුව හරහා ප්රවේශ විය හැක.

## උදාහරණ

### ලොගර් ඉල්ලන්න

```ts
import { definePlugin } from "omniroute/plugins/sdk";

export default definePlugin({
  name: "request-logger",
  onRequest: async (ctx) => {
    console.log(`[${new Date().toISOString()}] ${ctx.method} ${ctx.model} -> ${ctx.provider}`);
  },
});
```

### අනුපාත සීමාව

```ts
import { definePlugin, blockRequest } from "omniroute/plugins/sdk";

const requests = new Map<string, number[]>();

export default definePlugin({
  name: "rate-limiter",
  priority: 10,
  onRequest: async (ctx) => {
    const key = ctx.apiKeyInfo?.id || "anonymous";
    const now = Date.now();
    const window = 60000; // 1 minute
    const maxRequests = 100;

    const timestamps = (requests.get(key) || []).filter((t) => t > now - window);
    timestamps.push(now);
    requests.set(key, timestamps);

    if (timestamps.length > maxRequests) {
      return blockRequest({ error: "Rate limit exceeded", status: 429 });
    }
  },
});
```

### ප්‍රතිචාර ට්‍රාන්ස්ෆෝමරය

```ts
import { definePlugin } from "omniroute/plugins/sdk";

export default definePlugin({
  name: "response-transformer",
  onResponse: async (ctx, response) => {
    if (response.choices) {
      response.choices = response.choices.map((c: any) => ({
        ...c,
        message: { ...c.message, content: c.message.content.trim() },
      }));
    }
    return response;
  },
});
```
