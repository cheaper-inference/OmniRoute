## විශේෂාංග ෆ්ලෑග් යනු මොනවාද

විශේෂාංග ෆ්ලෑගයක් යනු ධාවනකාලයේදී අගය වෙනස් කර දත්ත සමුදායේ සුරැකිය හැකි,
ක්රියාවලිය නැවත යෙදවීමක් අවශ්ය නොවන, නමක් සහිත ටොගලයකි (boolean හෝ enum).
සෑම ෆ්ලෑගයක්ම `key`, `label`, `description`, `category`, `defaultValue`,
`type`, සහ `requiresRestart` ඉඟියක් සහිත `FeatureFlagDefinition` එකකින් විස්තර කෙරේ.

### නිරාකරණ අනුපිළිවෙළ

ෆ්ලෑගයක **බලපැවැත්වෙන අගය**
[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) මඟින් පහත
ප්රමුඛතා අනුපිළිවෙළට අනුව නිරාකරණය කෙරේ (ඉහළම ප්රමුඛතාව ජය ගනී):

1. **DB අතික්රමණය** — `feature_flags` නාම අවකාශය යටතේ `key_value` වගුවේ
   ගබඩා කර ඇති අගයක් (උපකරණ පුවරුව හෝ REST API එක හරහා සකසා ඇත).
2. **පරිසර විචල්යය** — සකසා ඇති සහ හිස් නොවන විට `process.env[<KEY>]`.
3. **අර්ථ දැක්වීමේ පෙරනිමිය** — `featureFlagDefinitions.ts` හි `defaultValue`.

boolean ෆ්ලෑගයක බලපැවැත්වෙන අගය `"true"`, `"1"`, හෝ `"yes"` වන විට එය
**සක්රීය** ලෙස සැලකේ (`isFeatureFlagEnabled()` බලන්න).

> [!NOTE]
> බොහෝ ෆ්ලෑග් සඳහා [`ENVIRONMENT.md`](./ENVIRONMENT.md) හි ලේඛනගත කර ඇති
> **එම නමින්ම** යුත් ගැළපෙන පරිසර විචල්යයක් ද ඇත. ෆ්ලෑගයේ DB අතික්රමණයට
> එම පරිසර විචල්යයට වඩා ප්රමුඛතාව ලැබේ. `requiresRestart: true` සහිත
> ෆ්ලෑගයක් වහාම සුරැකෙන නමුත් එය නැවත කියවනු ලබන්නේ ක්රියාවලිය ආරම්භ වන
> අවස්ථාවේදී පමණි — එය ටොගල් කිරීමෙන් උපකරණ පුවරුවේ **"සේවාදායකය නැවත අරඹන්න"**
> බැනරයක් දිස් වේ.

## ධජ මාරු කිරීම

### ඩෑෂ්බෝඩ්

**Dashboard → Settings → Feature Flags** වෙත යන්න
(`/dashboard/settings/feature-flags`). මෙම ග්රිඩය
(`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`)
සහාය දක්වන්නේ:

- යතුර හෝ විස්තරය අනුව **සෙවීම**, සහ කාණ්ඩය අනුව **පෙරීම** (කෘත්රිම
  **Requires Restart** දසුනක්ද ඇතුළුව).
- බූලීය ධජ සඳහා **ටොගලයක්** සහ enum ධජ සඳහා **පතන මෙනුවක්**
  (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`).
- සෑම ධජයක් සඳහාම **මූලාශ්ර බැජයක්** — `DB`, `ENV`, හෝ `DEF` — ඵලදායී අගය පැමිණියේ කොහෙන්දැයි පෙන්වයි.
- අභිබවා සැකසීම ඉවත් කිරීමට (මූලාශ්රය `DB` වන ධජ සඳහා පමණක් පෙන්වන) **Reset** බොත්තමක් සහ පහළින් **Reset All Overrides** බොත්තමක්.
- `requiresRestart` ධජයක් වෙනස් කළ විට **Restart Server** බැනරයක්.

### REST API

සියලු මෙහෙයුම් තනි route එකක් හරහා සිදු වේ:
[`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts).
සෑම method එකකටම සත්යාපිත ඩෑෂ්බෝඩ් session එකක් අවශ්ය වේ (එසේ නොමැතිනම් `401`).

#### `GET /api/settings/feature-flags`

සෑම ධජයක්ම එහි ඵලදායී අගය, මූලාශ්රය සහ සාරාංශයක් සමඟ ලබා දෙයි.

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Require API Key",
      "description": "Require an API key for all incoming requests",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... ධජ 116 ම
  ],
  "summary": {
    "total": 116,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

තනි අභිබවා සැකසීමක් සකසන්න හෝ ඉවත් කරන්න. Body: `{ key: string; value?: string }`.
`value` නොදැක්වීමෙන් අභිබවා සැකසීම ඉවත් වේ (env / default ප්රතිසාධනය කරමින්).

```bash
# DB අභිබවා සැකසීමක් සකසන්න
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# අභිබවා සැකසීම ඉවත් කරන්න ("value" නොමැත)
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

ප්රතිචාරය නව `effectiveValue`/`source`, පෙර `previousValue`/
`previousSource`, සහ `requiresRestart` නැවත ලබා දෙයි. නොදන්නා යතුරු සහ පරාසයෙන් පිටත enum
අගයන් `400` සමඟ ප්රතික්ෂේප කෙරේ.

#### `DELETE /api/settings/feature-flags`

සියලුම DB අභිබවා සැකසුම් එකවර හිස් කරමින්, සෑම ධජයක්ම එහි env / default
අගයට ප්රතිසාධනය කරයි. `{ cleared: <count>, message: "..." }` ලබා දෙයි.

> [!NOTE]
> `requiresRestart: true` සහිත ධජ ක්රියාවට නැංවෙන්නේ process එක reload කළ පසුව පමණි.
