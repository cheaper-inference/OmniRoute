## අපගේ සංඛ්‍යාව අනෙකුත් එකතු කරන්නන්ට වඩා කුඩා වන්නේ ඇයි?

මෙම අවකාශයේ ඇති බොහෝ "මාසයකට නොමිලේ ටෝකන" සංඛ්‍යා එක් මාදිලියේ ලේබලවල එකතුවකි. අපේ එක අරමුණක් මත නොවේ:

- **සෑම හවුල් සංචිතයක්ම එක් වරක් ගණනය කෙරේ.** Mistral හි නිදහස් සැලැස්ම ආයතනයකට එක් 1B/month දීමනාවකි; එය ආකෘති පහක් යටතේ ලැයිස්තුගත කිරීමෙන් එය 5B බවට පත් නොවේ. ආකෘතියකට සාරාංශගත කළහොත්, අපගේම නාමාවලිය කියවනු ඇත**~ 7.4B** (2026-09-03 නැවත ගණනය කරන ලදී; මෙම අගය CI-gated — නොවේ නාමාවලිය වෙනස් වන සෑම විටම එය නැවත මැන බලන්න) — සිරස්තලය කියයි**~ 1.47B** මක්නිසාද යත්, එක් එක් සැපයුම්කරුගේ එක් ගිණුමක් ඇත්ත වශයෙන්ම වියදම් කළ හැක්කේ එයයි.
- **දෛනික සීමාවන් පරිවර්තනය කරනු ලැබේ, අනුපාත නොවේ.** ලේඛනගත tokens/day කැප් එකක් `× 30` බවට පත් වේ; ලේඛනගත requests/day කැප් එකක් `RPD × ~800 tokens × 30` බවට පත් වේ; මිනිත්තුවකට ඉල්ලීම් පමණක් ප්‍රකාශයට පත් කරන සැපයුම්කරුවෙකු සතුව ඇත** නැත** මාසික අගය සහ _uncapped_ ලෙස ලැයිස්තුගත කර ඇත, කිසිදා සාරාංශ කර නැත. අනුපාත සීමාවක් 24/7 මගින් ගුණ කිරීම අප ප්‍රතික්ෂේප කරන උද්ධමනයයි.
- **කලාපීය අනන්‍යතා පරීක්‍ෂණයක් පිටුපස ඇති කෝටා වෙන් වෙන්ව පෙන්වා ඇත** (`+~6M behind regional identity verification`), බොහෝ පාඨකයන්ට ඒවා භාවිතා කළ නොහැකි නිසා.
- **ලියාපදිංචි වීමේ ණය පළමු මාසය පමණි** සහ දෙවන රූපයක් ලෙස වාර්තා කර ඇත, කිසි විටෙක ස්ථාවර අංකයට මුසු නොවීය.
- **රූපය CI මගින් බලාත්මක කර ඇත.** `npm run check:docs-counts` නාමාවලියෙන් එකතුව නැවත ගණනය කරන අතර මෙම ගොනුව, README හෝ බජට් කාඩ්පත ඒවායින් ඉවතට ගිය විට ගොඩනැගීම අසාර්ථක වේ.

## ToS අවධානය යොමු කිරීමේ වගුව

> **ToS ධජය උපදේශනයකි, මාර්ගගත කිරීමේ දොරටුවක් නොවේ.** `tos` ලෙස සලකුණු කරන ලද සපයන්නන් තවමත් මාර්ගගත කිරීම සහ combo/fallback පෙරනිමියෙන් ඇතුළත් කර ඇත; කොඩිය `/dashboard/free-tiers` සහ `/api/free-tier/summary` මත පමණක් මතුපිටින් දිස්වේ. `excludeTosAvoid` විමසුම් පරාමිතිය බලපාන්නේ සාරාංශ දර්ශනයට මිස ගෝලීය මාර්ගගත කිරීමට නොවේ. තීන්දුව `open-sse/config/freeTierCatalog.ts` හි ජීවත් වේ (තොරතුරු, මාර්ගගත එන්ජින් මගින් කියවා නැත).

> ස්වයං-සත්කාරක, තනි-පරිශීලක පුද්ගලික ප්‍රොක්සි සඳහා එක් එක් සැපයුම්කරුගේ නියමයන් පිළිබඳ ඉක්මන් කියවීමක්. `caution` = පරීක්ෂා කළ යුතු පුද්ගලික භාවිතය හෝ ප්‍රොක්සි වගන්තියක්; `ambiguous` = අපැහැදිලි; `ok` = පැහැදිලිවම අවසර දී ඇත. තොරතුරු, නීති උපදෙස් නොවේ — ඔබ තීරණය කරන්න.
