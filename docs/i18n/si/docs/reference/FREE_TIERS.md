## කෙටියෙන් — OmniRoute සැබවින්ම කොපමණ නොමිලේ inference ප්රමාණයක් එක්රැස් කරන්නේද?

මෙම ක්ෂේත්රයේ බොහෝ "මසකට නොමිලේ ලැබෙන ටෝකන" සංඛ්යා, එක් එක් මාදිලියට අදාළ අගයන්ගේ එකතුවකි. අපගේ සංඛ්යාව එසේ නොවන්නේ හිතාමතාමයි:

- **සෑම හවුල් සංචිතයක්ම ගණන් කරන්නේ එක් වරක් පමණි.** Mistral හි නොමිලේ සැලැස්ම යනු එක් සංවිධානයකට මසකට ලැබෙන 1B දීමනාවකි; එය මාදිලි පහක් යටතේ ලැයිස්තුගත කිරීමෙන් එය 5B බවට පත් නොවේ. එක් එක් මාදිලිය අනුව එකතු කළහොත්, අපගේම නාමාවලියෙහි අගය **~7.4B** ලෙස දිස්වනු ඇත (2026-09-03 දින නැවත ගණනය කරන ලදී; මෙම අගය CI මඟින් පාලනය නොවේ — නාමාවලිය වෙනස් වන සෑම අවස්ථාවකම එය නැවත මනින්න) — ප්රධාන ශීර්ෂයේ **~1.47B** ලෙස දැක්වෙන්නේ එක් එක් සපයන්නාගේ එක් ගිණුමකට සැබවින්ම වැය කළ හැක්කේ එපමණක් වන බැවිනි.
- **දෛනික සීමා පරිවර්තනය කරයි, අනුපාත එසේ නොකරයි.** ලේඛනගත tokens/day සීමාවක් `× 30` බවට පත් කරයි; ලේඛනගත requests/day සීමාවක් `RPD × ~800 tokens × 30` බවට පත් කරයි; මිනිත්තුවකට ඉල්ලීම් සංඛ්යාව පමණක් ප්රකාශයට පත් කරන සපයන්නෙකුට මාසික සංඛ්යාවක් **නොමැති** අතර, එය _සීමා නොකළ_ ලෙස ලැයිස්තුගත කරයි, කිසිවිටෙකත් එකතුවට එක් නොකරයි. අනුපාත සීමාවක් 24/7 කින් ගුණ කිරීම අප ප්රතික්ෂේප කරන කෘත්රිම වැඩි කිරීමයි.
- **කලාපීය අනන්යතා පරීක්ෂාවක් පසුපස ඇති කෝටා වෙනම පෙන්වයි** (`+~6M behind regional identity verification`), මන්ද බොහෝ පාඨකයන්ට ඒවා භාවිත කළ නොහැකි බැවිනි.
- **ලියාපදිංචි වීමේ ක්රෙඩිට් පළමු මාසයට පමණි** සහ ඒවා ස්ථාවර සංඛ්යාව සමඟ කිසිවිටෙකත් මිශ්ර නොකර, දෙවන සංඛ්යාවක් ලෙස වාර්තා කරයි.
- **මෙම සංඛ්යාව CI මඟින් බලාත්මක කරයි.** `npm run check:docs-counts` නාමාවලියෙන් එකතුව නැවත ගණනය කරන අතර, මෙම ගොනුව, README හෝ අයවැය කාඩ්පත එම අගයන්ගෙන් වෙනස් වූ විට ගොඩනැගීම අසාර්ථක කරයි.

## ToS අවධානය යොමු කිරීමේ වගුව

> **ToS සලකුණ උපදේශාත්මක එකක් මිස රවුටින් අවහිරයක් නොවේ.** `tos` ලෙස සලකුණු කළ සපයන්නන් පෙරනිමියෙන් තවමත් රවුටින් සහ combo/fallback සඳහා ඇතුළත් වේ; සලකුණ දිස්වන්නේ `/dashboard/free-tiers` සහ `/api/free-tier/summary` මත පමණි. `excludeTosAvoid` විමසුම් පරාමිතිය බලපාන්නේ සාරාංශ දසුනට පමණක් වන අතර, සමස්ත රවුටින් ක්රියාවලියට නොවේ. තීරණය `open-sse/config/freeTierCatalog.ts` තුළ පවතී (තොරතුරු සඳහා පමණි, රවුටින් යන්ත්ර මඟින් කියවනු නොලැබේ).

> ස්වයං-සත්කාරක, තනි පරිශීලක පුද්ගලික ප්රොක්සියක් සඳහා එක් එක් සපයන්නාගේ නියමයන් පිළිබඳ කෙටි විමසුමක්. `caution` = පරීක්ෂා කිරීම වටිනා පුද්ගලික භාවිතය හෝ ප්රොක්සි වගන්තියක්; `ambiguous` = අපැහැදිලියි; `ok` = පැහැදිලිව අවසර දී ඇත. තොරතුරු සඳහා පමණි, නීති උපදෙස් නොවේ — තීරණය ඔබ සතුය.
