`copilot-m365-web` (අන්වර්ථ `m365copilot`) `m365.cloud.microsoft/chat` හිදී සත්‍යාපනය කළ Microsoft 365 Copilot සැසියක් හරහා OpenAI ආකෘතියේ කතාබස් ඉල්ලීම් යවයි. මෙය නිල නොවන ස්වදේශීය අනුකලනයකි: වෙනම ප්‍රොක්සි ක්‍රියාවලියක් හෝ Localhost upstream අවශ්‍ය නොවේ. සපයන්නා ID, අන්වර්ථය සහ පවතින ආනයනික සම්බන්ධතා නොවෙනස්ව පවතී. `copilot-web` යනු `copilot.microsoft.com` හි පාරිභෝගික සේවාව සඳහා වෙනස් සැපයුම්කරුවෙකි.

> **වෙබ් කුකී සපයන්නන්ට අලුත්ද?**
>
> කියවන්න**`docs/getting-started/WEB-COOKIE-GUIDE.md`** මෙම සැපයුම්කරු-විශේෂිත මාර්ගෝපදේශය අනුගමනය කිරීමට පෙර සාමාන්‍ය සැකසුම් ක්‍රියාවලිය, සත්‍යාපන මාර්ගෝපදේශය, සීමාවන් සහ දෝශ නිරාකරණය සඳහා.
>
> **උරුම ආනයන සඳහා:** මෙම සැපයුම්කරු සඳහා අක්තපත්‍රය වේ** කුකීස් නොවේ** . `m365.cloud.microsoft` වෙතින් කුකීස් පිටපත් නොකරන්න. අක්තපත්‍රය යනු WebSocket URL විමසුම් පරාමිතිය සහ මාර්ග කොටසකි, දෙකම DevTools Network පටිත්තෙන් කියවා ඇත.

## පූර්වාවශ්යතාවයන්

- `m365.cloud.microsoft/chat` හි Copilot වෙත ප්‍රවේශය සහිත Microsoft 365 ගිණුමක්
- DevTools WebSocket පරීක්ෂාව සඳහා Chromium-පාදක බ්‍රවුසරයක් (Chrome, Edge).
- එම ගිණුමේ ඉල්ලූ ආකෘතියට ප්‍රවේශය; ලබා ගැනීමේ හැකියාව කුලී නිවැසියන් සහ බලපත්‍රය අනුව වෙනස් වේ

## ස්වදේශීය පුරනය (වැඩ හෝ පාසල් ගිණුම්)

තෝරන්න**Microsoft 365 Copilot → සම්බන්ධ කරන්න** සහ පුරනය වීමේ උත්සාහයක් සූදානම් කරන්න. උපකරණ පුවරුව PKCE සමඟ අවසර-කේත ප්රවාහයක් භාවිතා කරයි; එය ඔබගේ Microsoft මුරපදය හෝ MFA කේතය ඉල්ලන්නේ නැත.

1. a විවෘත කරන්න** හිස් බ්‍රව්සර් ටැබය** , පසුව විවෘත කරන්න**DevTools → ජාලය** සහ සක්රිය කරන්න** ලොගය සංරක්ෂණය කරන්න** . Microsoft වෙත සංචාලනය කිරීමට පෙර මෙය කරන්න : Windows SSO වහාම අවසන් විය හැක.
2. සම්බන්ධතා සංවාදයෙන් පෙන්වන අවසර URL පිටපත් කර එම සකස් කළ ටැබය තුළට යන්න. Microsoft හි ගිණුම් තේරීම හෝ MFA ඉල්ලා සිටින්නේ නම් සම්පූර්ණ කරන්න.
3. සංරක්ෂිත ජාල ලොගය තුළ, `https://login.microsoftonline.com/common/oauth2/nativeclient` සඳහා වන ඉල්ලීම සොයාගෙන එහි සම්පූර්ණ පිටපත පිටපත් කරන්න** URL ඉල්ලන්න** .
4. එම URL සම්බන්ධතා සංවාදයට අලවා සම්බන්ධ කරන්න. අමු කේතයක් හෝ අවසාන `wrongplace` ලිපින තීරුව URL අලවන්න එපා : අවශ්‍ය ආපසු කැඳවීම තාවකාලික සංචලනයකි.

සෑම උත්සාහයක්ම මිනිත්තු දහයකට පසු කල් ඉකුත් වන අතර භාවිතා කළ හැක්කේ එක් වරක් පමණි. කේතය හුවමාරු කිරීමට පෙර සේවාදායකය එහි තත්වය, PKCE සත්‍යාපනය සහ නැවත සත්‍යාපන ඉලක්කය පරීක්ෂා කරයි. කල් ඉකුත්වීමෙන් හෝ හුවමාරු අසාර්ථක වීමෙන් පසුව, නව උත්සාහයක් ආරම්භ කරන්න. උත්සාහයක් සේවාදායකය නැවත ආරම්භ කිරීම නොනැසී පැවතිය නොහැක.

ටෝකන පවතින සම්බන්ධතා අක්තපත්‍ර ගබඩාව සහ මාර්ගය නැවුම් කරයි. සම්බන්ධතාවයක් නැවත සත්‍යාපනය කිරීම සඳහා එකම Microsoft tenant/object අනන්‍යතාවය අවශ්‍ය වේ, හුදෙක් එකම විද්‍යුත් තැපෑල නොවේ. එය ක්‍රියාකරු naming/settings සංරක්ෂණය කරන අතර යල් පැන ගිය ආනයනික අක්තපත්‍ර ප්‍රතිස්ථාපනය කරයි. ස්වදේශික පුරනය work/school ගිණුම් සඳහා වේ; පවතින සම්බන්ධතා සහ සහාය දක්වන ස්ථර වින්‍යාසයන් සඳහා උරුම ආනයන මාර්ගය පවතී.

සම්පූර්ණ ආපසු ඇමතුම් URL එක් වරක් අක්තපත්‍රයකි. එය කිසිවිටෙක තිරපිටපත්, ලොග, ආධාරක පණිවිඩ හෝ කැපවීම්වල ඇතුළත් නොකරන්න. මෙම ප්‍රවාහය සේවාදායකයේ බ්‍රවුසරයක් විවෘත නොකරයි, ඔබේ බ්‍රවුසර ඉතිහාසය පරීක්ෂා නොකරයි, හෝ දේශීය ඇමතුම් සේවාදායකයක් ආරම්භ නොකරයි.

## අක්තපත්‍ර ග්‍රහණය (WebSocket ක්‍රමය)

1. `https://m365.cloud.microsoft/chat` හි පුරනය වී සංවාදයක් ආරම්භ කරන්න.
2. විවෘත කරන්න**DevTools → ජාලය** .
3. පෙරහන් කරන්න**WS** (WebSocket)
4. Chathub WebSocket සම්බන්ධතාවය ක්ලික් කරන්න. `wss://substrate.office.com/m365Copilot/Chathub/` වලින් ආරම්භ වන URL එකක් සොයන්න.
5. එහි සිට** URL ඉල්ලන්න** , පිටපත:
   - `access_token` විමසුම් පරාමිති අගය (කෙටි කාලීන JWT).
   - `/Chathub/` ට පසු Chathub path කොටස (උදා `<oid>@<tenant>`).

සම්පූර්ණ URL හි පෝරමය ඇත:

```
wss://substrate.office.com/m365Copilot/Chathub/<oid>@<tenant>?...&access_token=<jwt>
```

6. OmniRoute හි, තෝරන්න**Microsoft 365 Copilot** , ලෙගසි API-key/import විකල්පය තෝරා, අක්තපත්‍රය ආකෘතියෙන් අලවන්න:

```
access_token=<jwt>; chathubPath=<oid>@<tenant>
```

7. ක්ලික් කරන්න** පරීක්ෂණ සම්බන්ධතාවය** සහ** සුරකින්න** .

## අක්තපත්‍ර ග්‍රහණය (HAR ආනයනය)

WebSocket URL වෙතින් අගයන් අතින් පිටපත් කරනවා වෙනුවට, ඔබට DevTools HAR ගොනුවක් අපනයනය කළ හැක:

1. විවෘත කරන්න**DevTools → ජාලය** .
2. Microsoft 365 Copilot සංවාදයක් ආරම්භ කරන්න හෝ දිගටම කරගෙන යන්න (මෙය WebSocket සම්බන්ධතාවය අවුලුවයි).
3. ජාල පැනලය මත දකුණු-ක්ලික් කර තෝරන්න** අන්තර්ගතය සමඟ සියල්ල HAR ලෙස සුරකින්න** .
4. OmniRoute, භාවිතා කරන්න** .har ගොනුව ආයාත කරන්න** සැපයුම්කරු සම්බන්ධතා සංවාදයේ බොත්තම.

OmniRoute Chathub WebSocket URL සඳහා HAR පරිලෝකනය කරයි, `access_token` සහ `chathubPath` උපුටා ගනී, සහ අක්තපත්‍ර ක්ෂේත්‍ර ස්වයංක්‍රීයව පුරවයි. HAR ආයාත කිරීම JWT කල් ඉකුත්වීම විකේතනය කර ඉතිරි ටෝකන් ආයු කාලය පෙන්වයි.

> **කිසිවිටෙක සැබෑ HAR අපනයනය, ප්‍රවේශ ටෝකනය හෝ නැවුම් ටෝකනයක් සිදු නොකරන්න.** පරීක්ෂණ සහ ලේඛන අගයන් සෑම විටම ස්ථාන දරණ විය යුතුය.

## ටෝකන් ආයු කාලය සහ නැවුම් කරන්න

`access_token` කෙටි කාලීන (සාමාන්‍යයෙන්**~ විනාඩි 75 යි** ) භාවිතා කළ හැකි නැවුම් ටෝකනයක් නොමැතිව, ඔබ කල් ඉකුත් වූ පසු අක්තපත්‍රය නැවත ලබා ගත යුතුය.

### `refreshToken` සමඟ ස්වයංක්‍රීය නැවුම් කිරීම

Microsoft 365 සපයන්නන් තුළ** සම්බන්ධතාවය එක් කරන්න** හෝ** සම්බන්ධතාවය සංස්කරණය කරන්න** සංවාදය, විවෘත** උසස් සැකසුම් → නැවුම් ටෝකනය (විකල්ප)** . `substrate.office.com/sydney` විෂය පථය සඳහා Microsoft OAuth නැවුම් ටෝකනයක් අලවා සුරකින්න. ආදානය ආවරණය කර ඇති අතර ගබඩා කර ඇති ටෝකනය සමඟ කිසි විටෙක පුරවා නැත. සංස්කරණය කරන විට, පවතින ටෝකනය තබා ගැනීමට එය හිස්ව තබන්න; එය ප්‍රතිස්ථාපනය කිරීමට නව ටෝකනයක් අලවන්න.

Microsoft එකක් ආපසු ලබා දෙන විට දේශීය පුරනය වීම නැවුම් ටෝකනය ලබා ගනී. උරුම ආයාත සඳහා, පවතින ගැළපෙන Microsoft අවසර-කේත ප්‍රදානයක් භාවිතා කරන්න; මෙම සැපයුම්කරු උපාංග-කේත ප්‍රවාහයක් ක්‍රියාත්මක කිරීම හෝ පොරොන්දු නොවේ. වින්‍යාස කර ඇති නැවුම් ටෝකනයක් සමඟින්, OmniRoute ඉල්ලීම් වලට පෙර `access_token` පරීක්ෂා කර එය නැවුම් කිරීමට අවශ්‍ය වූ විට පමණක් එය නැවුම් කරයි. සාර්ථක නැවුම් කිරීමක් ද කරකවන ලද නැවුම් ටෝකනය පවතිනු ඇත, නැවුම් ටෝකනය වලංගුව පවතින අතරම අතින් නැවත ග්‍රහණය කර ගැනීම වළක්වයි.

## හැසිරීම සහ සීමාවන් ඉල්ලන්න

- මෙවලම් වේ** ක්ෂණික-අනුකරණය** , ස්වදේශික Microsoft ශ්‍රිත ඇමතුම් නොවේ. මෙවලම්-සක්‍රීය ඉල්ලීමක් එක් බෆරගත පරම්පරාවක් භාවිතා කරයි; එය මෙවලම් තෝරාගැනීමට තවත් පරම්පරාවක් වැය නොකරයි. වලංගු සහාය දක්වන තර්ක හැඩතල සහිත ප්‍රකාශිත මෙවලම් පමණක් ඇමතුම් ලෙස ආපසු ලබා දෙනු ලැබේ.
- තනි පසුපස ආදර්ශයක් සහිත දිගු ව්‍යුහගත පිළිතුරක් ගද්‍ය ලෙස සංරක්ෂණය කර ඇත. මෙය අභිප්‍රාය පිළිබඳ සාක්ෂියක් නොව හූරිස්ටික් ය; යෙදුම් තවමත් තමන්ගේම මෙවලම් අවසර බලාත්මක කළ යුතුය.

- ජනනය කරන ලද පින්තූර කතාබස් වලින් වෙන්වූ කුඩා දෛනික අයවැයක් මත අඳින්න. එය භාවිතා කරන විට ඉල්ලීම අසාර්ථක වේ** 429** . රූපයක් නොමැතිව පිළිතුරු දෙන හැරීමක් අසාර්ථක වේ** 502** (හෝ** 400** /** 503** Copilot හි පාඨය ප්‍රතික්ෂේප කිරීමක් හෝ ධාරිතා ගැටලුවක් ලෙස කියවන විට); පණිවිඩයේ සඳහන් වේ.
