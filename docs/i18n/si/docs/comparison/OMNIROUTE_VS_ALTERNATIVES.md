## OmniRoute තෝරාගත යුත්තේ කවදාද?

- ඔබ ස්වයං-සත්කාරක සහ අවශ්ය** උපරිම සැපයුම්කරු ආවරණය** (සපයන්නන් 394, free/no-auth නාමාවලි ඇතුළත් කිරීම් 155)
- ඔබට අවශ්ය a** බිල්ට් MCP සේවාදායකය** (LLM මෙවලම්, මතකය, මෙවලම් ලෙස නිරාවරණය වන කුසලතා)
- ඔබට අවශ්යයි**A2A ප්රොටෝකෝලය** නියෝජිත-නියෝජිත වැඩ ප්‍රවාහ සඳහා
- ඔබට අවශ්යයි** ඇඟිලි සලකුණු රහසිගතව** (JA3/JA4) උඩු ගංවතුර CAPTCHAs මගින් අනාවරණය වීම වැළැක්වීමට
- ඔබට අවශ්යයි** ව්යවසාය විශේෂාංග** (ආරක්ෂක, ඊවාල්, විගණන මංපෙත්) SaaS බිල්පතක් නොමැතිව

## LiteLLM තෝරාගත යුත්තේ කවදාද

- ඔබ **Python-ප්රමුඛ** වන අතර `litellm.completion()` සමඟ දැඩි ඒකාබද්ධකරණයක් අවශ්ය විට
- ඔබට **පරිණත නිෂ්පාදන යෙදවුම් ක්රමවේද** (k8s, Helm ප්රස්ථාර) අවශ්ය විට
- ඔබේ කණ්ඩායම දැනටමත් Python ක්ෂුද්ර සේවා ධාවනය කරන විට

## OpenRouter (SaaS) තෝරාගත යුත්තේ කවදාද

- ඔබට ස්වයං-සත්කාරක කිරීමට අවශ්ය නොවන විට
- SaaS අධිමිල සමඟ එක් ටෝකනයකට ගෙවීමට ඔබ එකඟ විට
- සියලු සපයන්නන් සඳහා ඔබට **එක් ගෙවීම් ක්රමයක්** අවශ්ය විට

## Portkey තෝරාගත යුත්තේ කවදාද
