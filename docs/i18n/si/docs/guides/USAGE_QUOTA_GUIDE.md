## දළ විශ්ලේෂණය

OmniRoute හරහා ගලා යන සෑම ඉල්ලීමක්ම පහත තොරතුරු ග්රහණය කරන **භාවිත වාර්තාවක්** ජනනය කරයි:

- **අනන්යතාව**: කුමන API යතුර, සැපයුම්කරු, මොඩලය සහ සංයෝජනයද යන්න
- **ටෝකන**: ප්රේරක ටෝකන, සම්පූර්ණ කිරීමේ ටෝකන, හැඹිලිගත ටෝකන සහ එකතුව
- **පිරිවැය**: USD මුදල (මිලකරණ දත්තවලින් ගණනය කෙරේ)
- **කාල දත්ත**: ප්රමාදය, ආරම්භක/අවසන් වේලා මුද්රා
- **තත්ත්වය**: සාර්ථක, දෝෂ, අනුපාත-සීමා කළ, ආදිය.

මෙම වාර්තා **විශ්ලේෂණ** ලෙස සමූහනය කර, **කෝටා සැණරූ** ලෙස ස්ථිරව ගබඩා කර, **එක් එක් යතුර සඳහා වන අයවැය සීමා** බලාත්මක කිරීමට භාවිත කරයි.

```
ඉල්ලීම ──▶ chatCore ──▶ usage.record() ──▶ SQLite
                                  │
                          ┌───────┼───────┐
                          ▼       ▼       ▼
                    විශ්ලේෂණ  කෝටාව  බිල්කරණය
                 (උපකරණ පුවරුව) (බලාත්මක) (අපනයනය)
```

## වාර්තා කෙරෙන දේ

`usage.ts` සේවාව සෑම ඉල්ලීමක් සඳහාම **භාවිත සිදුවීමක්** සටහන් කරයි:

| ක්ෂේත්‍රය          | වර්ගය   | මූලාශ්‍රය                                                          |
| ------------------ | ------- | ------------------------------------------------------------------ |
| `id`               | string  | වාර්තා කිරීමේදී ජනනය කරන UUID                                      |
| `apiKeyId`         | string  | ඉල්ලීම ආරම්භ කළ API යතුර                                           |
| `provider`         | string  | සැපයුම්කරුගේ ID (openai, anthropic, ආදිය)                          |
| `model`            | string  | මාදිලියේ ID (gpt-5, claude-opus-4-6, ආදිය)                         |
| `comboId`          | string? | combo එකක් හරහා යොමු කළේ නම් එහි ID                                |
| `promptTokens`     | number  | ඉහළ ප්‍රවාහයේ ප්‍රතිචාරයෙන්                                        |
| `completionTokens` | number  | ඉහළ ප්‍රවාහයේ ප්‍රතිචාරයෙන්                                        |
| `cachedTokens`     | number  | හැඹිලියෙන් හමු වූ ටෝකන (Anthropic ප්‍රොම්ප්ට් හැඹිලිගත කිරීම ආදිය) |
| `totalTokens`      | number  | ප්‍රොම්ප්ට් + සම්පූර්ණකිරීම                                        |
| `costUsd`          | number  | මිල දත්තවලින් ගණනය කෙරේ                                            |
| `latencyMs`        | number  | ඉල්ලීමේ ආරම්භයේ සිට අවසානය දක්වා කාලය                              |
| `status`           | enum    | `success`, `error`, `rate_limited`, `timeout`, `cancelled`         |
| `errorClass`       | string? | තත්ත්වය success නොවේ නම් දෝෂ පන්තිය                                |
| `timestamp`        | string  | ISO 8601 UTC                                                       |
| `metadata`         | object  | අභිරුචි ප්ලගින මගින් ඇතුළු කළ දත්ත                                 |

### ටෝකන ලැබෙන්නේ කොහෙන්ද

**ප්‍රතිචාර හසුරුවනය** තුළදී ඉහළ ප්‍රවාහයේ සැපයුම්කරුගේ ප්‍රතිචාරයෙන් ටෝකන උපුටා ගනී:

```ts
// open-sse/handlers/chatCore.ts වෙතින්
const response = await providerExecutor.execute(provider, request);
const usage = response.usage || {
  prompt_tokens: 0,
  completion_tokens: 0,
  cached_tokens: 0,
};
```

භාවිත දත්ත ආපසු නොදෙන සැපයුම්කරුවන් සඳහා (ඇතැම් වෙබ්-කුකී සැපයුම්කරුවන්), OmniRoute විසින් `~4 chars per token` ආසන්නකරණ නියමය භාවිතයෙන් ටෝකන **ඇස්තමේන්තු කරයි** (`open-sse/services/autoCombo/pipelineRouter.ts` බලන්න).

### හැඹිලිගත ටෝකන

OmniRoute විසින් `cached_tokens`, `prompt_tokens` වෙතින් වෙන්ව සටහන් කරන්නේ පහත හේතු නිසාය:

- Anthropic ප්‍රොම්ප්ට් හැඹිලිගත කිරීමේදී හැඹිලිගත ටෝකන සඳහා අඩු ගාස්තුවක් අය කරයි (සාමාන්‍ය ගාස්තුවෙන් 10%)
- සමහර සැපයුම්කරුවන් වෙනස් මිලක් යෙදිය යුතු `cache_read_input_tokens` ආපසු ලබා දෙයි
- විශ්ලේෂණ මගින් **හැඹිලි හමුවීම් අනුපාතය** = `cached_tokens / prompt_tokens` පෙන්විය හැක

| **දෝෂ විශ්ලේෂණය**             | කාලයත් සමඟ දෝෂ අනුපාතය, ප්‍රධාන දෝෂ පන්ති              |

### ක්‍රමලේඛනමය ප්‍රවේශය

````ts

const analytics = await computeAnalytics(

    endDate: "2025-06-01",   // විකල්පයි: "custom" පරාසය සඳහා
  }

## කෝටා බලාත්මක කිරීම

එක් එක් API යතුර සඳහා කෝටාව ස්ථාන දෙකකදී බලාත්මක කෙරේ:

1. **මෘදු සීමාව** (`quotaWarnAt`): භාවිතය සීමා අගය ඉක්මවන විට උපකරණ පුවරුවේ අනතුරු ඇඟවීමක්
2. **දෘඪ සීමාව** (`quotaLimit`): සීමාව ඉක්මවූ විට HTTP 429 සමඟ ඉල්ලීම ප්‍රතික්ෂේප කෙරේ

### වින්‍යාසය

```ts
// එක් එක් API යතුර සඳහා
await updateApiKey(keyId, {
  quotaWarnAt: 5_00,    // $5.00 — අනතුරු ඇඟවීම පෙන්වන්න
  quotaLimit: 10_00,    // $10.00 — අනිවාර්ය නැවැත්වීම
  quotaWindow: "month", // "day" | "week" | "month" | "all"
});
````

### බලාත්මක කිරීමේ ප්‍රවාහය

```
Request ──▶ quotaCheck()
              │
              ├── Within limit?  ──▶ allow
              │
              └── Over limit?  ──▶ 429 Too Many Requests
                                   with Retry-After header
```

### කෝටා තත්ත්ව ඡායාරූප

ප්‍රවණතා විශ්ලේෂණය සඳහා `quotaSnapshots` වගුව **ඓතිහාසික කෝටා තත්ත්වය** ගබඩා කරයි:

| ක්ෂේත්‍රය | විස්තරය |
| ----------- | -------------------------------- | ------ | ------- |
| `apiKeyId` | නිරීක්ෂණය කරන යතුර |
| `window` | "day" | "week" | "month" |
| `used` | මෙම කාල සීමාව තුළ වැය වූ වියදම (සත) |
| `limit` | සීමාව (සත) |
| `resetAt` | කාල සීමාව යළි සැකසෙන වේලාව |
| `createdAt` | තත්ත්ව ඡායාරූපය ගත් වේලාව |

වියදම > 0 වන **සෑම ඉල්ලීමකදීම** තත්ත්ව ඡායාරූප ගනු ලබන අතර, ඒවා පහත දෑ සඳහා භාවිත කෙරේ:

- උපකරණ පුවරුවේ කෝටා ප්‍රගති තීරුව පෙන්වීම
- දින 30ක කෝටා ප්‍රවණතා ප්‍රස්තාර පෙන්වීම
- භාවිතය සීමාවට ළඟා වන විට ඇඟවීම් ක්‍රියාත්මක කිරීම

## රඳවා තබා ගැනීම සහ පිරිසිදු කිරීම

භාවිත ඉතිහාසය රඳවා තබා ගැනීම UI හි දත්ත සමුදා සැකසුම් හරහා හෝ `/api/settings/database` හරහා වින්‍යාස කෙරේ.

පෙරනිමියෙන්, භාවිත ඉතිහාසය **දින 90ක්** රඳවා තබා ගැනේ.

### ගබඩා අවශ්‍යතා ඇස්තමේන්තුව

### 2. හැඹිලිගත කිරීම සක්‍රිය කරන්න

Anthropic ප්‍රොම්ප්ට් හැඹිලිගත කිරීමෙන් **නැවත භාවිත වන සන්දර්භය සඳහා පිරිවැයෙන් 90%ක්** ඉතිරි වේ:

```ts
// හැඹිලිගත කිරීම ස්වයංක්‍රීයයි — එකම විශාල පද්ධති ප්‍රොම්ප්ට් එක ඇතුළත් කරන්න
const response = await openai.chat({
  model: "claude-sonnet-4-5",
  system: longSystemPrompt, // ස්වයංක්‍රීයව හැඹිලිගත කෙරේ
  messages: [{ role: "user", content: "..." }],
});
```

### 3. සම්පීඩනය භාවිත කරන්න

RTK + Caveman සම්පීඩනයෙන් **මෙවලම් බහුලව භාවිත වන සැසිවල පිරිවැයෙන් 15-95%ක්** ඉතිරි වේ:

```ts
const config = {
  compression: {
    engine: "rtk",
    intensity: "aggressive",
  },
};
```

### 4. එක් එක් යතුර සඳහා කෝටා සකසන්න

පාලනයකින් තොරව පිරිවැය ඉහළ යාම වැළැක්වීමට සැමවිටම `quotaLimit` සකසන්න:

```ts
await updateApiKey(keyId, { quotaLimit: 10_00 }); // මසකට $10 සීමාව
```

### 5. වැඩිපුරම භාවිත කරන අය විගණනය කරන්න

API යතුර අනුව කාණ්ඩ කිරීමට සහ පිරිවැය අනුව අනුපිළිවෙළට සැකසීමට උපකරණ පුවරුව හෝ **`/api/usage/analytics`** භාවිත කරන්න:

```bash
GET /api/usage/analytics?groupBy=apiKey
```

## දෝෂ නිරාකරණය

### "පිරිවැය අපේක්ෂිත ප්‍රමාණයට වඩා වැඩියි"

1. **`/api/usage/analytics?groupBy=model`** පරීක්ෂා කරන්න — මිල අධික මාදිලිය සොයාගන්න
2. **`/api/usage/analytics?groupBy=apiKey`** පරීක්ෂා කරන්න — වැඩිපුර භාවිත කරන අය සොයාගන්න
3. මිල දත්ත යාවත්කාලීන බව තහවුරු කරන්න: `POST /api/pricing/sync`

### "වාර්තා අස්ථානගත වී ඇත"

- උපකරණ පුවරුව → දත්ත සමුදාය → පිරිසිදු කිරීම යටතේ DB රඳවාගැනීමේ සැකසුම් පරීක්ෂා කරන්න — කාලාන්තර පිරිසිදු කිරීමේ කාර්යය මඟින් පැරණි වාර්තා මකා දමනු ලැබේ (`src/lib/db/cleanup.ts`)
- `src/lib/db/usage*.ts` තුළ දෝෂ තිබේදැයි පරීක්ෂා කරන්න — DB ලිවීමේ අසාර්ථකවීම් ලොග්ගත කෙරෙන නමුත් මතු කර නොපෙන්වයි
- ඉල්ලීම සැබවින්ම `chatCore` වෙත ළඟා වූ බව තහවුරු කරන්න — සංයුක්ත මාර්ගගත කිරීම පරීක්ෂා කරන්න

### "කෝටාව බලාත්මක නොවේ"

- යතුරේ `quotaLimit` සැකසුම පරීක්ෂා කරන්න
- `quotaWindow` නිවැරදිව සකසා ඇති බව තහවුරු කරන්න
- `quotaSnapshots` වාර්තා සොයන්න — සෑම ඉල්ලීමකදීම ඒවා නිර්මාණය විය යුතුය
