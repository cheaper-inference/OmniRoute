## එය කුමක්ද

OmniRoute විසින් සපයන්නන් 377ක් ලියාපදිංචි කරන අතර, නාමාවලි ඇතුළත් කිරීම් 155ක් සලකුණු කර ඇත**free/no-auth** (no-auth, free-tier OAuth, or free-tier API key — [Free Tiers Guide](../getting-started/FREE-TIERS-GUIDE.md) සහ සම්පූර්ණ [Free Tiers බහලුම](../reference/FREE_TIERS.md) බලන්න ). අල්ලා ගැනීම: නොමිලේ සපයන්නන් මාදිලියේ ගුණාත්මක භාවයෙන් විශාල ලෙස වෙනස් වේ. මායිම් ආකෘතියකට සේවය කරන සහතික නොවන සැපයුම්කරුවෙකු කුඩා ලෙගසි මාදිලියකට සේවය කරන කෙනෙකුට වඩා ප්‍රයෝජනවත් වේ.

**නොමිලේ සපයන්නන්ගේ ශ්‍රේණිගත කිරීම්** පිළිතුරු "** මට හොඳම ආකෘතිය ලබා දෙන්නේ කුමන නොමිලේ සපයන්නාද?** "එක් එක් නොමිලේ සපයන්නාගේ නාමාවලියට සම්බන්ධ වීමෙන්** සමූහයා පදනම් කරගත් ගුණාත්මක ලකුණු** සිට** Arena AI ප්‍රමුඛ පුවරුව** (human-preference ELO, LMArena chatbot Arena පිටුපස එකම අදහස). එවිට සැපයුම්කරුවන් ඔවුන්ගේ ශක්තියෙන් ශ්‍රේණිගත කරනු ලැබේ** හොඳම නිදහස් ආකෘතිය** .

ශ්‍රේණිගත කිරීම සැබෑ මූලාශ්‍ර තුනකින් ගණනය කෙරේ:

1. නොමිලේ සපයන්නා ලැයිස්තු — `NOAUTH_PROVIDERS`, plus `OAUTH_PROVIDERS` / `APIKEY_PROVIDERS` ඇතුළත් කිරීම් සලකුණු කර ඇත `hasFree` (`src/shared/constants/providers.ts`).
2. සපයන්නාගේ රෙජිස්ට්‍රි (`open-sse/config/providerRegistry.ts`) වෙතින් සෑම සැපයුම්කරුවෙකුගේම ආකෘති නාමාවලිය.
3. Arena ELO සමමුහුර්ත එන්ජිම (`src/lib/arenaEloSync.ts`) මගින් `model_intelligence` DB වගුවේ ගබඩා කර ඇති ELO-ව්‍යුත්පන්න කාර්ය යෝග්‍යතා ලකුණු.

සම්බන්ධ වීමේ තර්කය `src/lib/freeProviderRankings.ts` හි ජීවත් වේ.

### සාමාන්යකරණය (task-fit ලකුණ)

අමු ELO ලකුණු සෑම ප්රමුඛ පුවරුවක් සඳහාම **`[0.4, 0.98]` තුළ ඇති task-fit අගයකට** සාමාන්යකරණය කෙරේ:

```
taskFit = 0.4 + 0.58 * ((elo - minElo) / (maxElo - minElo))
```

ලකුණ කිසිවිටෙක `0` හෝ `1` වෙත නොපැමිණේ; මෙය පරිශීලක අභිරුචිකරණ (user overrides) සඳහා ඉඩක් තබයි. API ප්රතිචාරයේ ඔබ දකින
`score` ක්ෂේත්රය සහ උපකරණ පුවරුවේ පෙන්වන ලේබලය මෙයයි.

සෑම නොමිලේ සැපයුම්කරුවෙකු සඳහාම, එන්ජිම එහි නාමාවලියේ සිටින සෑම ආකෘතියක්ම ලකුණු කරයි, ඉන්පසු:

- **Top Model (ඉහළම ආකෘතිය)** = සැපයුම්කරුගේ වැඩිම ලකුණු ලත් ආකෘතිය.
- **Avg Score (සාමාන්ය ලකුණ)** = එම සැපයුම්කරුගේ ලකුණු ලත් සියලුම ආකෘති හරහා මධ්යන්ය ලකුණ.
- **Models (ආකෘති)** = සැපයුම්කරුගේ ආකෘති කීයකට Arena ලකුණක් තිබුණේද යන්න.

සැපයුම්කරුවන් පළමුව **ඉහළම-ආකෘති ලකුණ** අනුවද, ඉන්පසු සාමාන්ය ලකුණ අනුවද වර්ග කෙරේ. අවම වශයෙන්
එක් ශක්තිමත් නොමිලේ ආකෘතියක්වත් නිකුත් කරන සැපයුම්කරුවෙකුට මෙය ප්රතිලාභයක් සලසයි.

## නොමිලේ සපයන්නන් තෝරාගැනීමට එය භාවිත කිරීම

1. **නිවැරදි ප්රවර්ගය තෝරන්න.** නියෝජිතමය/කේත වැඩභාර සඳහා **Coding** පෙරහන භාවිත කරන්න, නැතහොත්
   සාමාන්ය කතාබස් සඳහා එය **All Categories** / **Default** ලෙස තබන්න. එක් එක් ප්රමුඛතා ලැයිස්තුවේ එහි ඉහළම මාදිලිය වෙනස් වන බැවින්, එකම සපයන්නා
   ප්රවර්ග අතර වෙනස් ලෙස ශ්රේණිගත විය හැක.
2. **එක්වරක් පමණක් සකසන වින්යාස සඳහා ඉහළම ස්ථාන තුනට ප්රමුඛත්වය දෙන්න.** ඔබට සම්බන්ධ කිරීමට අවශ්ය වන්නේ නොමිලේ
   සපයන්නන් එක් අයෙකු හෝ දෙදෙනෙකු පමණක් නම්, ඔබේ ප්රවර්ගයේ ඉහළම ශ්රේණිගත සපයන්නන්ගෙන් ආරම්භ කරන්න.
3. **Type ලාංඡනය පරීක්ෂා කරන්න.** `NOAUTH` සපයන්නන් සම්බන්ධ කිරීමට වේගවත්ම ඒවාය (අක්තපත්ර
   අවශ්ය නොවේ). `OAUTH` / `APIKEY` නොමිලේ ස්තර සඳහා ඉක්මන් ලියාපදිංචියක් අවශ්ය වුවද, ඒවා බොහෝ විට
   වඩා ප්රබල මාදිලි ලබා දෙයි. සම්බන්ධ කිරීමේ පියවර සඳහා [නොමිලේ ස්තර මාර්ගෝපදේශය](../getting-started/FREE-TIERS-GUIDE.md) බලන්න.
4. **කිහිපයක් සම්බන්ධ කර Auto-Combo හට තීරණය කිරීමට ඉඩ දෙන්න.** මෙම පිටුව බලගන්වන එම Arena ELO දත්තම
   Auto-Combo ලකුණුකරණ එන්ජිමේ **කාර්ය-යෝග්යතා සාධකය** සඳහාද භාවිත වේ
   (`open-sse/services/autoCombo/taskFitness.ts`, නිරාකරණ අනුපිළිවෙළ
   `user_override → arena_elo → models_dev_tier → static table`). එබැවින් ඉහළම නොමිලේ සපයන්නන්
   සම්බන්ධ කළ පසු, `model: "auto"` (උදා. `auto/coding`) සමඟ මාර්ගගත කිරීම මඟින්
   එක් එක් ඉල්ලීම සඳහා උසස් තත්ත්වයේ නොමිලේ මාදිලිවලට ස්වයංක්රීයව ප්රමුඛත්වය දෙනු ඇත. සම්පූර්ණ සාධක 16ක ලකුණුකරණය සඳහා
   [Auto-Combo](../routing/AUTO-COMBO.md) බලන්න.
