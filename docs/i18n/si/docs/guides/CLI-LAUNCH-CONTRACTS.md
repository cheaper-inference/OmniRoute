උදාසීන `config/cli-tools-manifest.json` කොන්ත්‍රාත්තුව කැනොනිකල් IDs, අන්වර්ථ, ද්විමය අපේක්ෂකයන්, සැකසුම් වට්ටෝරු, ආකෘති තර්ක සහ හැකියාවන් ප්‍රකාශ කරයි. `bin/cli/cli-manifest.mjs` හි සරල Node ඇඩැප්ටරය සහ `src/shared/constants/cliIntegrationManifest.ts` හි TypeScript ඇඩැප්ටරය එකම ගොනුව කියවයි. ධාවන කාලය, නාමාවලිය, වින්‍යාස කිරීම, සම්පූර්ණ කිරීම, උත්පාදක යන්ත්‍ර සහ පසුපෙළ ලියාපදිංචිය `tests/unit/cli/cli-manifest-drift.test.ts` මගින් පරීක්ෂා කරනු ලැබේ. කැටලොග් කිරීම යනු මෙවලමක් දියත් කළ හැකි හෝ වින්‍යාස කළ හැකි බව නොවේ. විශේෂයෙන්ම, 5dive වින්‍යාස කිරීමට පමණක් පවතී.

## ළමා පරිසරය සහ ජීවන චක්රය

`omniroute run`, `omniroute launch` සහ `omniroute launch-codex` OS/terminal අනුකූලතා අවසර ලැයිස්තුවක් උරුම කර ගත් අතර තෝරාගත් ඉලක්කයේ අක්තපත්‍ර එන්නත් කරන්න. අසම්බන්ධිත සැපයුම්කරු සහ දත්ත සමුදා රහස් පෙරනිමියෙන් උරුම නොවේ. `--inherit-env` පූර්ණ මාපිය-පරිසර උරුමය පැහැදිලිවම ප්‍රතිෂ්ඨාපනය කරයි; තෝරාගත් තෙවන පාර්ශවීය ක්‍රියාවලියට එම අගයන් ලැබිය යුතු විට පමණක් එය භාවිතා කරන්න. මෙය පරිසර පෙරහනක් මිස OS වැලිපිල්ලක් නොවේ: ක්‍රියාවලිය තවමත් ඇමතුම්කරුගේ ගොනු පද්ධති අවසරයන් සමඟින් ක්‍රියාත්මක වේ.

බාධා කිරීම් සහ අවසන් කිරීමේ සංඥා දරුවා වෙත යොමු කරනු ලැබේ. තාවකාලික වින්‍යාසය ඉවත් කිරීමට පෙර දියත් කිරීම දරුවාගේ සමීප සිදුවීම බලා සිටියි. `OMNIROUTE_CHILD_SIGNAL_TIMEOUT_MS` බලහත්කාරයෙන් අවසන් කිරීමට පෙර සහන කාලය පාලනය කරයි (පෙරනිමිය මිලි තත්පර 5000).

## Gemini ස්ථීර සැකසුම

```bash
omniroute setup-gemini --remote https://omni.example --model provider/model --yes
omniroute configure gemini --model provider/model --yes
omniroute run gemini --model provider/model --dry-run --json
```

පළමු විධාන දෙක තෝරාගත් දේශීය හෝ දුරස්ථ සේවාදායකය සඳහා මෙම යන්ත්‍රය වින්‍යාස කරයි. සැකසුම අසම්බන්ධ JSON සිටුවම් ආරක්ෂා කරයි, Gemini API-key auth තෝරා, සහ පුද්ගලික `.gemini/.env` ගොනුවකට අවසාන ලක්ෂ්‍යය සහ අක්තපත්‍රය ලියයි. එය උඩින් ලිවීමට වඩා අවලංගු JSON ප්‍රතික්ෂේප කරයි. එබ්බවූ අක්තපත්‍ර, විමසුම් පරාමිති හෝ කොටස් නොමැතිව අවසන් ලක්ෂ්‍යය URLs HTTP(S) විය යුතුය. අක්තපත්‍ර අගයන් නොව වියළි ධාවන මුද්‍රණ මාර්ග.

`GEMINI_CLI_HOME` හෝ `--gemini-home` ස්ථීර මුල් මූලය තෝරා ගනී. සැබෑ `run gemini` එහිම තාවකාලික නිවසක් නිර්මාණය කර පසුව ඉවත් කරයි. කිසිදු මාදිලියක් Gemini හි කාර්ය ඉඩ-විශ්වාස පිරික්සුම් මඟ හරින්නේ නැත.

## Codex පැතිකඩ

`configure codex` ආකෘතියක් සහ එහි OmniRoute සපයන්නාගේ අන්ත ලක්ෂ්‍යය සමඟ පුද්ගලික `<name>.config.toml` ලියයි. අක්තපත්‍ර `OMNIROUTE_API_KEY` හරහා යොමු කර ඇත, කිසි විටෙක කාවැද්දුවේ නැත. දියත් කිරීමේ විධානය තෝරාගත් ආකෘතිය `model_providers` තුළ නොව ඉහළ මට්ටමේ `model` යතුරෙහි සකසයි.

වෙනම පැතිකඩ ගොනු යනු වත්මන් ලේඛනගත Codex ගිවිසුමයි; ඒවා `codex --profile <name>` සමඟ තෝරාගත් විට පරිශීලක වින්‍යාසය ආවරණය කරයි. [නිල පැතිකඩ යොමුව](https://learn.chatgpt.com/docs/config-file/config-advanced#profiles) සහ [OmniRoute Codex මාර්ගෝපදේශය](./CODEX-CLI-CONFIGURATION.md) බලන්න.

## හර්මෙටික් විධානය ක්රියාත්මක කිරීම

පැහැදිලි `DATA_DIR` සමඟින්, `OMNIROUTE_CLI_SKIP_DEFAULT_DATA_ENV=1` සැකසීම පෙරනිමි පරිශීලක දත්ත නාමාවලියෙහි අක්තපත්‍ර පරිසරයට වැටීමෙන් ආරම්භය වළක්වයි. මෙය හුදකලා පරීක්ෂණ සඳහා ප්රයෝජනවත් වේ. එය පැහැදිලිව තෝරාගත් වෙනත් පරිසර ගොනු අක්‍රිය නොකරයි.

## වැඩ කරන නාමාවලිය `.env`

CLI මෙම අනුපිළිවෙලෙහි `.env` ගොනු කියවන අතර, යතුරක් සකසන පළමු ගොනුව ජය ගනී: පැහැදිලි `DATA_DIR`, පෙරනිමි දත්ත නාමාවලිය, වත්මන් ක්‍රියාකාරී නාමාවලිය, පසුව පැකේජ නාමාවලිය. Shell විචල්‍යයන් සැමවිටම ජය ගනී.

වැඩ කරන නාමාවලිය වෙනත් කෙනෙකුට (ක්ලෝන කරන ලද ගබඩාවක්, ඇසුරුම් නොකළ සංරක්ෂිතයක්) අයත් විය හැකි අතර, `omniroute serve` CLI පරිසරය සේවාදායකයට සහ සේවාදායකය ක්‍රියාත්මක කරන සෑම මෙවලමකටම ලබා දෙයි. එබැවින් එහි ඇති `.env` එකකට සැකසිය හැක්කේ `bin/cli/utils/untrustedCwdEnv.mjs` හි ලැයිස්තුගත කර ඇති මෙම යතුරු පමණි:

| යතුර                            | පිළිගත් අගයන්                                                       |
| ------------------------------- | ------------------------------------------------------------------- |
| `REQUIRE_API_KEY`               | `true`, `1` හෝ `yes` ඕනෑම අවස්ථාවක, සේවාදායකය සලකන අගයන්            |
| `LANG`, `LC_ALL`, `LC_MESSAGES` | අකුරු 64 දක්වා, ඉලක්කම්, `_`, `.`, `@` හෝ `-`                       |
| `LANGUAGE`                      | එකම, ප්ලස් `:`                                                      |
| `TZ`                            | අකුරු 64 දක්වා, ඉලක්කම්, `_`, `+`, `-` හෝ `/`, `/` වලින් ආරම්භ නොවේ |
| `NO_COLOR`, `FORCE_COLOR`       | අකුරු සහ ඉලක්කම් 16 දක්වා                                           |

`REQUIRE_API_KEY` පිළිගන්නා සෑම අගයක්ම චෙක්පත සක්‍රිය කරයි, එබැවින් ගොනුවට චෙක්පත අක්‍රිය කළ නොහැක. එය ප්‍රතිඵලය තීරණය නොකරයි, කෙසේ වෙතත්: සේවාදායකයා පරිසරයට පෙර දත්ත ගබඩාවේ ගබඩා කර ඇති `REQUIRE_API_KEY` අභිබවා යාමක් කියවයි, API යතුරකින් තොරව සියලුම අතුරුමුහුණත්වල සවන්දීම පිළිබඳ ආරම්භක අනතුරු ඇඟවීම පරිසරය පමණක් කියවයි. `false` හි ගබඩා කර ඇති ප්‍රතික්‍ෂේපයක් සමඟින්, වැඩ කරන නාමාවලි `REQUIRE_API_KEY=true` API විවෘත කර එම අනතුරු ඇඟවීම සඟවයි. `TZ` නියමය POSIX ට වඩා පටු ය : එය `.`, `:`, `,` සහ `<>` ප්‍රතික්ෂේප කරයි , එබැවින් `:Area/City` ආකෘතිය සහ `EST5EDT,M3.2.0,M11.1.0` වැනි රීති කවචයේ හෝ `<DATA_DIR>/.env` හි සැකසිය යුතුය.

ලොකු අකුරින් නම් හරියටම ගැළපිය යුතුය. වෙනත් ඕනෑම පේළියක්, එහි චෙක්පත අසමත් වන අගයක් සහ සරල ASCII අකුරු නොවන නමක්, ඉලක්කම් සහ `_` (උදාහරණයක් ලෙස NUL බයිටයක් හෝ පෙනුමට සමාන අකුරක් සහිත එකක්) මඟ හරිනු ලැබේ. CLI විසින් එක් අනතුරු ඇඟවීමක් මුද්‍රණය කරන අතර එය තමන්ට සැකසිය නොහැකි යතුරු නම් කරන අතර එය නොසලකා හරින ලද අවසර ලත් යතුරු නම් කරයි, ඒ සෑම එකක්ම වෙනස් කළ යුතු දේ (`TZ (expected a zone name such as Europe/Berlin)`, `lang (write the name as LANG)`). අගයන් මුද්‍රණය කරන්නේද නැත. මෙම පණිවිඩවල ගොනු මාර්ග සහ `.env` මාර්ග `omniroute doctor` වාර්තා, ඒවායේ පාලන හෝ Bidi අක්ෂර අඩංගු වූ විට ගැලවී යයි. වැඩ කරන නාමාවලිය දත්ත නාමාවලිය හෝ පැකේජ නාමාවලිය වන විට සීමා කිරීම අදාළ නොවේ.

`PORT`, `API_PORT` සහ `DASHBOARD_PORT` ලැයිස්තුවේ නැත. ඉහළ ප්‍රමුඛතා මූලාශ්‍රයකින් URL පදනමක් නොමැතිව, CLI `localhost:<PORT>` සමඟ කතා කරයි, සහ එහි සවන් දෙන ඕනෑම දෙයකට CLI හි API යතුර, සන්දර්භය ටෝකනය සහ CLI යන්ත්‍ර ටෝකනය (`x-omniroute-cli-token`, [CLI_TOKEN.md](../security/CLI_TOKEN.md) බලන්න) ලැබේ, එය දේශීය සේවාදායකය විසින් loopback කළමනාකාරිත්වය සඳහා ඇමතුම් ලබා ගනී. වැඩ කරන බහලුමේ ඇති තොටක් මඟින් එම ගොනුවට ශ්‍රාවකයා තෝරා ගැනීමට ඉඩ සලසයි, එබැවින් ෂෙල් එකෙහි ඇති වරායන් `<DATA_DIR>/.env` හෝ `--port` විකල්පය සහිත විධාන එකක් (`serve`, `launch`, `run`) සකසන්න.

විග්‍රහයට `export` වාක්‍ය ඛණ්ඩයක් නොමැත. `export LD_PRELOAD=...` වැනි රේඛාවක් විචල්‍යයක් නම් කරයි `export LD_PRELOAD`; වැඩ කරන ඩිරෙක්ටරියෙන් එය මඟ හරිනු ලබන අතර, අනෙකුත් `.env` ගොනු වලදී එය කිසිවක් නොකියවන එම වචනාර්ථ නාමය සකසයි.

CLI සන්දර්භයක ගබඩා කර ඇති ටෝකනය (ප්‍රවේශ ටෝකනය හෝ ලෙගසි API යතුර) එම සන්දර්භයේම සම්භවය සමඟ පමණක් යුගල කරයි: යෝජනා ක්‍රමය, සත්කාරක සහ වරාය, `URL.origin` ලෙස සසඳන විට. මෙය CLI හි HTTP සේවාලාභියා (`--base-url`, `OMNIROUTE_BASE_URL`, `omniroute connect <new-url>`) හරහා කරන ලද ඉල්ලීම් සහ වෙනත් මෙවලමක වින්‍යාසයකට පාදක URL සහ යතුරක් ලියන `launch`, `launch codex`, `configure` සහ `setup-*` විධාන සඳහා අදාළ වේ. `--remote` සමඟ වෙනත් සේවාදායකයක් වෙත යොමු කර ඇති අතර, ඒවා සකසන්නේ නම් පැහැදිලි `--api-key` හෝ `OMNIROUTE_API_KEY` භාවිතා කරයි, සහ සන්දර්භය ටෝකනයක් නොමැත. සංසන්දනය නිවැරදියි, එබැවින් `localhost` සහ `127.0.0.1`, හෝ පසුපස තිතක් සහිත සහ රහිත ධාරකයක්, විවිධ සේවාදායකයන් ලෙස ගණන් කරන අතර සන්දර්භය ටෝකනයක් ලබා නොගන්න. පරිශීලක තොරතුරු සහිත URL, backslash හෝ whitespace කිසිවිටක නොගැලපේ, මන්ද අනෙකුත් URL parsers (Python's `urllib` සහ `httpx`, උදාහරණයක් ලෙස) එයින් වෙනස් සත්කාරකයක් කියවිය හැක. ඉල්ලීම් සඳහා CLI විසින්ම යවනු ලැබේ, එම චෙක්පත ආවරණය කරන්නේ යෝජනා ක්‍රමය සහ අධිකාරිය පමණි, එබැවින් මාර්ගයේ හෝ විමසුමේ ඉඩක් සහිත හැඳුනුම්පතක් ටෝකනය තබා ගනී.
