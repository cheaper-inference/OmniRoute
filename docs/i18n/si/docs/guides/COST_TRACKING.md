## වියදම් ඇස්තමේන්තු කරන ආකාරය

### මිලකරණ මූලාශ්රය

මෙම ප්‍රමුඛතා අනුපිළිවෙලෙහි [`src/lib/db/settings/pricing.ts`](../../src/lib/db/settings/pricing.ts) හි ඒකාබද්ධ කළ මිල වගුවෙන් පිරිවැය පැමිණේ (** ඉහළම පළමු** ):

1. **පරිශීලක අභිබවා යයි** — මිල උපකරණ පුවරුවේ හෝ `PATCH /api/pricing` ( `pricing` namespace) හරහා සකසා ඇත.
2. **models.dev සමමුහුර්තකරණය** — මිලකරණය `https://models.dev/api.json` ( `models_dev_pricing` namespace) වෙතින් ලබා ගන්නා ලදී.
3. **LiteLLM සමමුහුර්ත කිරීම** — මිල LiteLLM හි පොදු `model_prices_and_context_window.json` ( `pricing_synced` නාම අවකාශය) වෙතින් ලබා ගන්නා ලදී.
4. **දෘඪ කේත පෙරනිමි** — ගාස්තු [`src/shared/constants/pricing/`](../../src/shared/constants/pricing/) වලින් නැව්ගත කර ඇත.

එකම provider/model සඳහා, ඉහළ ප්‍රමුඛතා ස්ථර වලින් ලැබෙන අගයන් පහළ ස්ථරවල ගැළපෙන ක්ෂේත්‍ර උඩින් ලියයි; ඉහළ ස්ථරයකින් නොමැති ක්ෂේත්‍ර තවමත් පහළ ස්ථරයකින් පැමිණිය හැක. ස්වාධීන සමමුහුර්ත රැකියා දෙකම එකවර ක්‍රියාත්මක වන විට පවා ඇණවුම ස්ථාවර වේ. `GET /api/pricing?includeSources=1` `pricing` සහ `sourceMap` නැවත ලබා දෙයි, එහි එක් මාදිලියේ ලේබල් (`user`, `modelsDev`, `litellm`, `default`) එම ආකෘතිය අඩංගු ඉහළම ප්‍රමුඛතා ස්ථරය හඳුනා ගනී.

**LiteLLM සමමුහුර්ත කිරීම** තෝරාගෙන ඇත, පෙරනිමියෙන් අබල කර ඇත. එහි පරිසර විචල්‍යයන් ( [`.env.example`](../../.env.example) බලන්න):

| Env var                 | පෙරනිමිය  | අරමුණ                                                                            |
| ----------------------- | --------- | -------------------------------------------------------------------------------- |
| `PRICING_SYNC_ENABLED`  | `false`   | පසුබිම් LiteLLM මිල සමමුහුර්ත කිරීම සබල කරන්න.                                   |
| `PRICING_SYNC_INTERVAL` | `86400`   | සමමුහුර්ත පරතරය තත්පර වලින් (දිනපතා).                                            |
| `PRICING_SYNC_SOURCES`  | `litellm` | මෙම සමමුහුර්ත කිරීම සඳහා පමණක් මූලාශ්‍ර තේරීම; දැනට සහය දක්වන්නේ `litellm` පමණි. |

**models.dev සමමුහුර්තකරණය** LiteLLM සමමුහුර්තකරණයෙන් වෙන් වී ඇති අතර පෙරනිමියෙන් අක්‍රිය කර ඇත. එය සැකසීම් (models.dev සමමුහුර්තකරණය) තුළ සබල කරන්න හෝ මෙම විචල්‍ය භාවිතා කරන්න:

### පිරිවැය සූත්රය

[`src/lib/usage/costCalculator.ts`](../../src/lib/usage/costCalculator.ts) (`computeCostFromPricing` / `calculateCost`) හි ටෝකන් ගණන් සහ මිලියනයකට-ටෝකන් ගාස්තු වලින් ඉල්ලීමක් අනුව පිරිවැය ගණනය කෙරේ:

- **ආදාන ටෝකන** (අඩු හැඹිලි කියවීම් සහ හැඹිලි-නිර්මාණය ටෝකන) × `input` අනුපාතය.
- **හැඹිලි-කියවන ටෝකන** × `cached` අනුපාතය (ආදාන අනුපාතයට ආපසු වැටේ).
- **හැඹිලි නිර්මාණය ටෝකන** × `cache_creation` අනුපාතය (ආදාන අනුපාතයට ආපසු වැටේ).
- **ප්රතිදාන ටෝකන** × `output` අනුපාතය.
- **තර්ක කිරීමේ සංකේත** × `reasoning` අනුපාතය (ප්‍රතිදාන අනුපාතයට ආපසු වැටේ).

සියලුම ගාස්තු ටෝකන් 1,000,000කට USD ලෙස අර්ථ දැක්වේ. Codex "වේගවත්"/"ප්‍රමුඛතාවය" හෝ "flex" සේවා ස්ථරයක් පිරිවැය ගුණකය (`getCodexFastCostMultiplier`) — යෙදේ උදා: flex 50% ටෝකන් වට්ටමක් මත බිල් කරනු ලැබේ,** flex ඉතුරුම්** උපකරණ පුවරුවේ.

ආදර්ශ නම් පළමුව සාමාන්‍යකරණය කර ඇත ( `openai/` හෝ `accounts/fireworks/models/` වැනි සැපයුම්කරු-මාර්ග උපසර්ග ඉවත් කර ඇත) එබැවින් ඓතිහාසික පේළි තවමත් මිලකට ගැලපේ.

- **පිරිවැය ගවේෂකය** — **සපයන්නා**, **ආකෘතිය**, **API යතුර**, **ගිණුම**, හෝ **සේවා මට්ටම** අනුව කාණ්ඩගත කළ හැකි, අනුපිළිවෙළට සැකසිය හැකි/පෙරහන් කළ හැකි වගුවක්; එහි පිරිවැය, ඉල්ලීම්, ටෝකන, එක් ඉල්ලීමකට සාමාන්ය පිරිවැය, සහ මුළු එකතුවෙන් ප්රතිශත කොටස ඇතුළත් වේ.

OmniRoute හි CLI මඟින් පිරිවැය, භාවිතය සහ මිලකරණ විධාන නිරාවරණය කරයි ([`bin/cli/commands/registry.mjs`](../../bin/cli/commands/registry.mjs) හි ලියාපදිංචි කර ඇත).

### `omniroute cost`

`/api/usage/analytics` වෙතින් සමුච්චිත කළ පිරිවැය වාර්තාවක්.

```bash
omniroute cost                          # අවසන් දින 30, සැපයුම්කරු අනුව කාණ්ඩගත කර ඇත
omniroute cost --period 7d              # අවසන් දින 7
omniroute cost --group-by model         # provider | model | combo | api-key | day අනුව කාණ්ඩගත කරන්න
omniroute cost --since 2026-06-01 --until 2026-06-13
omniroute cost --api-key <key> --limit 50
```

තීරු: කාණ්ඩය, ඉල්ලීම්, ආදාන/ප්රතිදාන ටෝකන, පිරිවැය (USD), සහ සමස්තයේ %. අවසානයේ සමස්ත එකතුවක් සහිත පේළියක් මුද්රණය කෙරේ (`--quiet` හෝ `--output json` සමඟ එය යටපත් කෙරේ).

### `omniroute usage`

```bash
omniroute usage analytics --period 30d [--provider <id>]   # එක් එක් සැපයුම්කරු සඳහා පිරිවැය සාරාංශය
omniroute usage logs [--limit 100] [--follow] [--api-key <k>] [--search <q>]
omniroute usage quota [--provider <id>] [--check]
omniroute usage utilization [--api-key <k>]
omniroute usage history [--limit 100]
omniroute usage proxy-logs [--limit 100]

# අයවැය
omniroute usage budget list
omniroute usage budget get [scope]
omniroute usage budget set <amount> [--scope global] [--period monthly]
omniroute usage budget reset [scope]
```

### `omniroute pricing`

```bash
omniroute pricing list [--provider <p>] [--model <m>] [--limit 200]
omniroute pricing get <model>
omniroute pricing sync [--provider <p>] [--force]   # POST /api/pricing/sync
omniroute pricing diff [--model <m>]
omniroute pricing defaults show
omniroute pricing defaults set [--input <p>] [--output <p>] [--cache-read <p>] [--cache-write <p>]
```

> `pricing defaults show` මඟින් `GET /api/pricing/defaults` කියවයි. ඒ වෙනුවට තනි මාදිලිවල
> මිල සංස්කරණය කිරීමට, **Pricing** උපකරණ පුවරු පිටුව හෝ `PATCH /api/pricing` භාවිත කරන්න.
