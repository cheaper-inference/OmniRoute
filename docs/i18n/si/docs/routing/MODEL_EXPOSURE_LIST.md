## මෙය පවතින්නේ ඇයි

`hidePaidModels` පිළිතුරු දෙයි "මෙම ආකෘතිය නොමිලේද?" සහ `hideAutoCombos` පිළිතුරු " `auto/*` අතථ්‍ය හැඳුනුම්පත් කිසිසේත් ප්‍රචාරණය කළ යුතුද?" — හෝ ක්‍රියාකරුවෙකුට අත්තනෝමතික මාදිලියේ උප කුලකයක් පාලනය කිරීමට ඉඩ නොදේ (උදා: දී ඇති Claude කේතය / OpenCode සේවාලාභියා විසින් දැකිය යුතු ආකෘති හරියටම ඉදිරිපත් කිරීම, මිලකරණයෙන් ස්වාධීනව). #11481 එය ස්වාධීන, තේරීම් තන්තු-අරා සිටුවම් දෙකක් ලෙස එක් කරයි.

## චොක්පොයින්ට් දෙකක්, එකක් නොවේ

#6512 වෙතින් පාඩම ( `hidePaidModels` -only නාමාවලි පෙරහනක් තවමත් `auto/*` ගෙවුම් ආකෘතියකට යාමට ඉඩ දෙයි, මන්ද සංයෝජන අපේක්ෂක සංචිතය ස්වාධීනව ගොඩනගා ඇති බැවින්) මෙහි සමානව අදාළ වේ. ගැළපෙන පුරෝකථනය `isModelExposureAllowed()` (`src/shared/utils/modelExposureList.ts`) BOTH වෙතින් හැඳින්වේ:

- `src/app/api/v1/models/catalog.ts` — `/v1/models` ලැයිස්තුගත කර ඇත, එකම මූලාශ්‍ර 5 කින් chokepoints `shouldHidePaid()` දැනටමත් ගේට්ටු (ස්ථිතික `PROVIDER_MODELS`, සමමුහුර්ත කරන ලද සැපයුම්කරු පේළි, අභිරුචි පේළි, අන්වර්ථ පිටුබලය සහිත පේළි, කළමනාකරණය කරන ලද-පසුබැසීම පේළි).
- `open-sse/services/autoCombo/modelExposureFilter.ts::filterModelExposureCandidates()` — `virtualFactory.ts::buildPreparedPool` වෙතින් කැඳවනු ලැබේ, සමාන `filterPaidOnlyCandidates()` ඇමතුමෙන් පසු වහාම, එබැවින් ප්‍රතික්ෂේප කළ ආකෘතියක් කිසි විටෙකත් `auto/*` අපේක්ෂක සංචිතයකට තෝරා ගත නොහැක.

## NOT පෙරන ලද දේ

දර්පණ `hideAutoCombos` හි පවතින හැසිරීම: ආකෘති හැඳුනුම්පතක් යවන ලදී** පැහැදිලිවම** ( `auto/*` හරහා නොවේ , සහ නාමාවලි ලැයිස්තුගත කිරීම හරහා අනාවරණය නොවේ) යැවීමේදී කිසිවිටක අවහිර නොවේ — පමණක් advertisement/candidate-pool සාමාජිකත්වය පෙරා ඇත. මෙය `hidePaidModels` වලින් ස්වාධීන වේ; පිරිවැය සමඟ කිසිදු සම්බන්ධයක් නොමැති හේතු නිසා ක්‍රියාකරුවෙකුට සංවෘත කට්ටලයක් අවශ්‍ය විය හැක, එබැවින් සැකසීම් දෙකම ස්වාධීන සහ සංස්කරණ පෙරහන් ලෙස සම්පාදනය කරයි, `catalog.ts` හි පවතින බහු-ධජ සංයුතියට සමාන වේ.

Settings export (`GET /api/settings/export-json`) හි අරා දෙකම වාචිකව ඇතුළත් වේ, `hidePaidModels` හි combo-step export පෙරහන මෙන් නොව, වෙනත් ඕනෑම සැකසුම් ක්ෂේත්‍රයක් — මෙන්, මෙහි නැවත සජලනය වීමේ අවදානමක් නොමැත: අපනයනය කරන ලද combo පියවරක කාවැද්දූ ප්‍රතික්ෂේප කරන ලද id ක්‍රියාකරුගේම පැහැදිලි මාර්ගගත තේරීමක් මිස අපනයනය කිරීමට අවශ්‍ය දෙයක් නොවේ.

## සංයෝජන-පමණි ලැයිස්තුගත කිරීම (`exposeCombosOnly`)

වෙනම boolean, ද පෙරනිමියෙන් තෝරා ගැනීම සහ `false`, සංයෝජන පොදු ආකෘති මතුපිට සහ සපයන්නන් පසුබිම් පමණක් වන යෙදවීම් සඳහා. එය `true` වන විට, පොදු ලැයිස්තුගත කිරීම (`GET /v1/models`, `GET /v1`, සහ `getUnifiedModelsResponse()` මත ගොඩනගා ඇති අනෙකුත් `/v1` සොයාගැනීම් මාර්ග) `owned_by: "combo"` සමඟ පේළි පමණක් තබා ගනී : පරිශීලක සංයෝජන සහ බිල්ට් `auto/*` සංයෝජන ( `hideAutoCombos` ඒවා සඟවන්නේ නම් මිස). එය `catalogScope: "combos"` යතුරකට සමාන පේළි පරීක්ෂණයක් භාවිතා කරයි, සහ යතුරක ම allow/deny/scope පෙරහන් තවමත් ඉහළින් අදාළ වේ.

එය ටොගල් කරන්න** සැකසීම් → මාර්ගගත කිරීම → මාදිලි API ලැයිස්තුගත කිරීම** , හෝ `PATCH /api/settings {"exposeCombosOnly": true}` සමඟ .

ඉහත ලැයිස්තු මෙන්, එය වෙළඳ දැන්වීම් පමණක් වෙනස් කරයි:

- පැහැදිලි `provider/model` id තවමත් යවන අතර `GET /v1/models/{id}` තවමත් එය විසඳයි;
- උපකරණ පුවරු නාමාවලිය (`GET /api/models/catalog`, ආදර්ශ තෝරා ගන්නන් විසින් භාවිතා කරනු ලැබේ) පටු නොවේ;
- එය `auto/*` අපේක්ෂක සංචිතවලට පිළිබිඹු නොවේ, එබැවින් `auto/*` සංයෝජන ඔවුන්ගේ සම්පූර්ණ සංචිතය තබා ගනී.
