# ආරම්භ කිරීමට පෙර

> **වැදගත්:** අක්තපත්ර සැමවිටම **සජීවී ජාල ඉල්ලීමකින්** පිටපත් කරන්න, ඔබගේ බ්රවුසරයේ කුකී ගබඩාවෙන් **නොවේ**.

බොහෝ සත්යාපන ගැටලු ඇති වන්නේ වැරදි ස්ථානයෙන් කුකී පිටපත් කිරීම නිසාය.

## Cookie Storage වෙතින් පිටපත් නොකරන්න

බොහෝ බ්රවුසරවල ගබඩා කළ කුකී පහත මාර්ගයෙන් පෙන්වයි:

```
DevTools
→ Application (හෝ Storage)
→ Cookies
```

මෙම කුකී නිවැරදි ලෙස පෙනුණද, ඒවා:

- කල් ඉකුත් වූ ඒවා විය හැක
- අසම්පූර්ණ විය හැක
- සත්යාපිත ඉල්ලීම් සමඟ පමණක් යවන කුකී අඩංගු නොවිය හැක

මෙම අගයන් වලංගු ලෙස පෙනුණද, ඒවා භාවිත කිරීමෙන් සත්යාපන අසාර්ථක වීම් ඇති විය හැක.

## සජීවී ඉල්ලීමකින් පිටපත් කරන්න

ඒ වෙනුවට, සාර්ථක ඉල්ලීමකින් ලැබෙන කුකී භාවිත කරන්න:

```
DevTools
→ Network
→ පිටුව නැවුම් කරන්න
→ කතාබහක් හෝ සංවාද ඉල්ලීමක් විවෘත කරන්න
→ Request Headers
→ Cookie
```

`Cookie` ඉල්ලීම් ශීර්ෂයේ ඔබගේ බ්රවුසරය සාර්ථකව භාවිත කළ නිශ්චිත සත්යාපන තොරතුරු අඩංගු වේ.

බොහෝ වෙබ් කුකී සපයන්නන් සඳහා, OmniRoute වෙත ඇලවිය යුතු අගය මෙයයි.

# සාමාන්ය සැකසුම

බොහෝ වෙබ් කුකී සපයන්නන් සඳහා සැකසුම් ක්රියාවලිය සමාන වේ.

1. සපයන්නාගේ වෙබ් අඩවියට පුරන්න.
2. බ්රවුසරයේ සංවර්ධක මෙවලම් විවෘත කරන්න.
3. **Network** ටැබය විවෘත කරන්න.
4. පිටුව නැවුම් කරන්න.
5. සත්යාපිත කතාබහක් හෝ සංවාද ඉල්ලීමක් විවෘත කරන්න.
6. අවශ්ය සත්යාපන අක්තපත්ර පිටපත් කරන්න.
7. OmniRoute විවෘත කරන්න.
8. **Providers → Add Provider** වෙත යන්න.
9. ඔබගේ වෙබ් කුකී සපයන්නා තෝරන්න.
10. අක්තපත්ර අලවන්න.
11. **Test Connection** ක්ලික් කරන්න.
12. සපයන්නා සුරකින්න.

අවශ්ය නිශ්චිත අක්තපත්ර සපයන්නා අනුව වෙනස් වේ.

## NoTrack (notrack-web)

NoTrack ([notrack.ai](https://notrack.ai)) යනු ලියාපදිංචි වීමක් අවශ්ය නොවන නොමිලේ පාරිභෝගික කතාබස් වේදිකාවකි — පළමු පිවිසුමේදී සැසිය නිර්නාමිකව සාදනු ලබන අතර, එය `uid`, `si_usr_id`, සහ `si_ses_id` යන කුකී තුන හරහා පවත්වාගෙන යයි. OmniRoute එකම `/api/dispatch` අන්ත ලක්ෂ්යය තනි මොඩල් හැඳුනුම්කාරකයක් (`notrack-c`, අන්වර්ථ නාමය `ntw`) හරහා ප්රොක්සි කරයි.

### සම්බන්ධ වීමේ පියවර

1. ඔබේ බ්රවුසරයෙන් [notrack.ai](https://notrack.ai) විවෘත කර නිර්නාමික සැසි කුකිය සැකසීමට ඉඩ දෙන්න.
2. **සංවර්ධක මෙවලම් → ජාලය** විවෘත කර, පිටුව නැවුම් කර, ඕනෑම `/api` ඉල්ලීමක් ක්ලික් කරන්න.
3. **ඉල්ලීම් ශීර්ෂ** තුළ, සම්පූර්ණ `Cookie` ශීර්ෂ අගය පිටපත් කරන්න.
4. OmniRoute තුළ, **සපයන්නන් → සපයන්නා එක් කරන්න → NoTrack Web (නොමිලේ)** වෙත යන්න.
5. කුකී පෙළ `apiKey` ක්ෂේත්රයට අලවා **සුරකින්න**.

OmniRoute අලවන ලද පෙළෙන් `uid`, `si_usr_id`, සහ `si_ses_id` උපුටාගෙන, එම යුගල පමණක් සහිත පිරිසිදු `Cookie` ශීර්ෂයක් නැවත ගොඩනඟයි — එමෙන්ම, තිබේ නම් `nt_session` (පිවිසී ඇති ගිණුම් සඳහා සකසා ඇති `ntk_…` ටෝකනය) ද එක් කරයි. එම තුනෙන් එකක් හෝ නොමැති නම්, ක්රියාකරුවන්ට විකල්ප ආකෘති අත්හදා බැලීමට හැකි වන පරිදි අලවන ලද මුල් පෙළ කිසිදු වෙනසකින් තොරව යොමු කෙරේ.

### හැකියාවන්

- **ප්රවාහ සහ ප්රවාහ නොවන** කතාබස් සම්පූර්ණ කිරීම්.
- **මෙවලම් ඇමතීම** — ඉල්ලීම මත `tools: [...]` සකසන්න; ක්රියාත්මක කරන්නා ඒවා මෙවලම්-ඇමතුම් ආවරණ ගිවිසුමකට ශ්රේණිගත කර, මොඩලයේ ප්රතිචාර නැවත OpenAI `tool_calls` බවට විග්රහ කරයි.
- **`response_format`** — `json_object` සහ `json_schema` සඳහා සහාය දක්වයි. ක්රියාත්මක කරන්නා මොඩලයේ පිළිතුරෙන් පළමු JSON වස්තුව උපුටාගෙන, ආපසු ලබා දීමට පෙර එය පෙළක් බවට පරිවර්තනය කරයි.
- **තර්ක ඉඟිය** — ඉහළ මට්ටමේ සේවාව `thinking` සිදුවීමක් යවන විට ක්රියාත්මක කරන්නා `reasoning` ඩෙල්ටාවක් නිකුත් කරයි.

# වෙබ් කුකී සපයන්නන්ට කළ හැකි සහ කළ නොහැකි දේ

වෙබ් කුකී සපයන්නන් වෙබ් අඩවියක කතාබස් අතුරුමුහුණත නැවත භාවිත කරයි. ඔවුන් නිල API මඟින් ලැබෙන හැකියාවන්ට සමාන හැකියාවන් **සපයන්නේ නැත**.

## සහාය දක්වන දෑ

- ඔබගේ පවතින බ්රවුසර සැසිය භාවිතයෙන් සත්යාපනය කිරීම
- ඔබගේ ගිණුම හරහා ලබාගත හැකි මාදිලි වෙත ප්රවේශ වීම
- කතාබස් ප්රතිචාර ප්රවාහ කිරීම
- API යතුරක් අවශ්ය නොවේ

## සහාය නොදක්වන දෑ

- ශ්රිත ඇමතීම
- මෙවලම් ඇමතීම
- ස්වයංක්රීය ගොනු සංස්කරණය
- නියෝජිත-පාදක IDE කාර්ය ප්රවාහ
