> **Единый источник истины:** все правила проекта для ИИ-ассистентов находятся в
> [`AGENTS.md`](AGENTS.md). Перед внесением любых изменений прочитайте его полностью — он содержит 23 строгих правила,
> критерии качества, соглашения по коду, правила размещения файлов и поддержания чистоты корня репозитория, карту репозитория
> и примечания по доступу к локальной среде разработки, которые ранее находились в этом файле.

Примечания, относящиеся к Gemini:

- Навыки активируются с помощью инструмента `activate_skill` (метаданные навыков загружаются при запуске сеанса,
  а полное содержимое активируется по требованию).
- В настоящее время других правил, относящихся только к Gemini, нет. Не добавляйте правила проекта сюда повторно — вместо этого редактируйте
  `AGENTS.md`, чтобы все ассистенты видели одинаковые инструкции.
