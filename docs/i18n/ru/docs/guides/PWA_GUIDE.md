Установите панель мониторинга OmniRoute как прогрессивное веб-приложение, чтобы открывать ее с главного экрана или рабочего стола в отдельном окне. Установленному приложению по-прежнему требуется подключение к вашему серверу OmniRoute для навигации, данных информационной панели и запросов API. Кэшированные статические ресурсы не предоставляют автономный шлюз или автономную панель мониторинга.

## Что такое PWA?

Прогрессивное веб-приложение использует веб-панель со значком приложения и отдельным окном. После установки OmniRoute:

- Запускается с главного экрана или рабочего стола
- Открывается в автономном режиме, без привычной для браузера адресной строки и вкладок.
- Кэширует выбранные статические ресурсы
- Поддерживает портретную и альбомную ориентацию.

## Установка

Используйте адрес HTTPS для сервера на другом устройстве. Когда сервер работает на том же устройстве, `http://localhost:20128` также соответствует требованиям к установке в браузере. Простой адрес `http://YOUR_IP:20128` не соответствует этим требованиям. Меню и подсказки установки зависят от браузера и операционной системы. См. [требования к установке PWA для MDN](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable#https_localhost_or_loopback_are_required).

### Андроид (Хром)

1. Откройте свой адрес OmniRoute HTTPS или `http://localhost:20128` для сервера на том же телефоне.
2. Откройте**⋮** меню и выберите** Установить приложение** или** Добавить на главный экран** , если предложат.
3. Подтвердите запрос.
4. Откройте OmniRoute с главного экрана.

### iOS (Сафари)

1. Откройте свой адрес OmniRoute HTTPS в Safari.
2. Кран** Делиться** →** Добавить на главный экран** .
3. Подтвердите имя и нажмите** Добавлять** .
4. Откройте OmniRoute с главного экрана.

### Рабочий стол (Chrome/Edge)

1. Откройте панель управления OmniRoute.
2. Используйте значок установки браузера или** Установить приложение** пункт меню, если он предлагается.
3. Подтвердите запрос на открытие OmniRoute в отдельном окне.

## Функции

### Автономное окно

Манифест устанавливает `display: "standalone"` и `start_url: "/dashboard"`. Установленное приложение открывает панель мониторинга в окне приложения. Элементы управления браузера и операционной системы по-прежнему могут отображаться; манифест не запрашивает полноэкранный режим.

### Кэшированные ресурсы и требования к сети

[Сервис-воркер](../../public/sw.js) кэширует выбранные ресурсы того же происхождения:

| Запрос или актив                                  | Стратегия                   | Поведение                                                                                                        |
| ------------------------------------------------- | --------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| Ресурсы времени установки                         | Предварительное кэширование | `/`, `/manifest.webmanifest`, `/icon-512.png` и `/apple-touch-icon.png` кэшируются во время установки работника. |
| статические ресурсы Next.js (`/_next/`)           | Сеть прежде всего           | Успешные ответы обновляют кеш; сетевая ошибка возвращается к существующему кэшированному ответу                  |
| Другие статические CSS, JS, изображения и шрифты  | Кэш-сначала                 | Существующий кэшированный ответ используется повторно; успешные сетевые ответы кэшируются при промахе            |
| Навигация по страницам                            | Обход                       | Браузер получает страницу напрямую; офлайн-резервный вариант не предоставляется                                  |
| API, панель мониторинга и маршруты аутентификации | Обход                       | Рабочий не перехватывает и не кэширует эти запросы.                                                              |
| Другие нестатические запросы                      | Сеть                        | Нет поиска или хранения в кеше                                                                                   |

Исключенные маршруты: `/api`, `/a2a`, `/dashboard`, `/v1`, `/v1beta`, `/models`, `/chat`, `/responses`, `/codex`, `/callback` и `/login`, сопоставленные на границах пути без учета регистра. Запросы между источниками и запросы, отличные от GET, также обходят рабочий процесс.

### Страница подключения

На странице `/offline` отображается сообщение о подключении, индикатор online/offline,** Повторить попытку подключения** кнопку и ссылку на страницу статуса. Это** не кэшируется заранее** и сервисный работник делает** нет** перенаправить на него неудачные переходы. Его существование не делает новые страницы доступными без сервера.

### Иконки приложений

В манифесте рекламируются следующие значки PNG :

| Файл                   | Размер  | Использовать                          |
| ---------------------- | ------- | ------------------------------------- |
| `icon-192.png`         | 192×192 | Общий значок приложения               |
| `icon-512.png`         | 512×512 | Общий и маскируемый значок приложения |
| `apple-touch-icon.png` | 180×180 | Значок главного экрана Apple          |

Браузер выбирает соответствующий значок для цели установки.

### Автоматическая регистрация

`PwaRegister` регистрирует работника в производстве, если браузер поддерживает сервис-воркеров. В режиме разработки отменяется регистрация рабочих процессов и очищаются кеши, чтобы устаревшие ресурсы не мешали горячей перезагрузке. Запросы на установку остаются на усмотрение браузера.

## Техническая Архитектура

### Манифест веб-приложения

Next.js генерирует `/manifest.webmanifest` из [`src/app/manifest.ts`](../../src/app/manifest.ts). Его ключевые настройки:

| Параметр          | Ценить                                              |
| ----------------- | --------------------------------------------------- |
| `short_name`      | `OmniRoute`                                         |
| `start_url`       | `/dashboard`                                        |
| `scope`           | `/`                                                 |
| `display`         | `standalone`                                        |
| `orientation`     | `any`                                               |
| Цвета фона и темы | Световая палитра по умолчанию от `PWA_THEME_COLORS` |

Имя и описание манифеста являются статическими значениями в этом исходном файле. Установленный манифест не соответствует настройке имени экземпляра или активной палитре при каждом посещении.

### Сервисный работник

[`public/sw.js`](../../public/sw.js) не имеет зависимости от платформы сервис-воркеров:

- **Установить:** предварительно кэширует четыре ресурса, перечисленные выше, и активирует нового работника.
- **Активировать:** удаляет старые поколения кэша и запрашивает клиентов.
- **Принести:** применяет стратегии статических активов и исключения маршрутов, описанные выше.
- **Управление версиями:** имя исходного кэша — `omniroute-pwa-v3`; производственная сборка отмечает идентичность кэша.
- **Уведомления:** обрабатывает входящие события `push` и фокусирует или открывает окно при нажатии на уведомление.

Обработчики push-событий сами по себе не устанавливают активную push-подписку или настроенную доставку на сервер. Не думайте, что уведомления включены только потому, что PWA установлен.

### Метаданные макета и регистрация

[`src/app/layout.tsx`](../../src/app/layout.tsx) предоставляет ссылку на манифест, автономные метаданные Apple, цвета темы и `viewport-fit: cover`. В заголовке страницы и названии веб-приложения Apple используется имя экземпляра. Цвет живой темы браузера соответствует палитре; в манифесте установки используется цвет освещения по умолчанию.

[`PwaRegister`](../../src/shared/components/PwaRegister.tsx) запускается на клиенте и регистрирует `/sw.js` со сборкой ID в своем URL. Он обнаруживает несовпадающие поколения кэша и может сбросить рабочий процесс и один раз перезагрузить его для восстановления из более старой установки. Ошибка регистрации не блокирует панель управления.

## Использовать с Termux (Android)

1. Запустите OmniRoute в Termux: `npx -y omniroute@latest`.
2. Откройте Chrome на том же телефоне: `http://localhost:20128`.
3. Установите PWA через меню установки браузера.
4. Поддерживайте работу сервера Termux при использовании панели управления.

На телефоне размещены как шлюз, так и панель управления. Запросы к удаленным поставщикам AI по-прежнему требуют доступа к сети. См. [руководство Termux](TERMUX_GUIDE.md) для получения информации по настройке и вопросам жизненного цикла Android.

## Использование с других устройств

Откройте адрес HTTPS сервера на телефоне, планшете или настольном компьютере, а затем следуйте инструкциям по установке этого браузера. Сервер должен оставаться доступным с каждого устройства. См. [руководство по туннелю](../ops/TUNNELS_GUIDE.md) для получения информации о вариантах удаленного доступа.

## Кастомизация

### Имя экземпляра

**Имя экземпляра** настройка меняет метаданные панели управления, включая заголовок страницы и заголовок веб-приложения Apple. В созданном манифесте используется статическое имя, поэтому этот параметр не гарантирует переименование уже установленного приложения.

### Пользовательский значок

Пользовательский значок меняет значок браузера. Манифест установки по-прежнему рекламирует файлы PNG, указанные выше; изменение значка не заменяет эти значки на главном экране.

## Ограничения

- **Требуется подключение к серверу:** навигация по страницам, состояние информационной панели и запросы API не имеют резервного варианта в автономном режиме.
- **Нет фоновой синхронизации:** автономные действия не ставятся в очередь для повтора.
- **Отличия браузеров:** Меню установки, представление окон и поддержка уведомлений различаются в зависимости от платформы.
- **Нет кеша ответов API :** рабочий исключает маршруты API, приборной панели и аутентификации.
- **Статические значки установки:** обновление этих значков требует изменения рекламируемых ресурсов; браузеры могут сохранять установленные метаданные.
