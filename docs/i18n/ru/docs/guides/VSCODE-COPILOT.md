**OmniCopilot** добавляет ваши модели и комбинации чата OmniRoute в встроенный инструмент выбора моделей чата Copilot. Используйте существующие чаты и рабочие процессы редактора, а также вызов инструментов и видение, если они поддерживаются выбранной моделью.

## Настраивать

1. **Запустить OmniRoute** — `npm install -g omniroute && omniroute` (панель мониторинга на `http://localhost:20128`).
2. **Установите расширение** — поиск «OmniRoute» в представлении «Расширения».
3. **Соединять** — сохраните `http://localhost:20128` по умолчанию или установите ключ URL и API вашего сервера через**OmniRoute: Управление соединением** .
4. **Выберите модель** — Copilot Чат → Выбор модели →** Управление моделями…** →**OmniRoute** , затем отметьте желаемое.

Для настройки подключения откройте** Значок OmniRoute на панели действий** (или запустите `OmniRoute: Manage Connection`) и установите:

- **Сервер URL** — корень сервера, например `http://omniroute.example.com:20128`. Суффикс `/v1` добавляется к расширению; не включайте его.
- **ключ API** — требуется, если этого требует политика аутентификации вывода сервера. Хранится через код VS SecretStorage, никогда в `settings.json`; доступны ключи, специфичные для рабочей области. Используйте ключ, авторизованный для моделей, которые вы хотите предоставить.

Расширение также предоставляет индикатор подключения, обновление модели, контекст модели и метаданные о ценах (включая комбинации), потоковую аргументацию с** Мыслительное усилие** меню в VS Code 1.120 +, индикатор дневного лимита в строке состояния и панель использования (OmniRoute 3.8.50 +), конфигурация CLI и дополнительная вкладка информационной панели. Выбранная модель и политика сервера определяют возможности, которые вы можете использовать.

## Что будет отображаться в средстве выбора

Расширение не отображает необработанные данные `GET /v1/models` — оно преобразует их, поэтому отображаемое
количество меньше размера каталога по двум намеренно предусмотренным причинам.

### Для каждой модели запрашивается один идентификатор

По умолчанию `MODELS_CATALOG_PREFIX_MODE` имеет значение **`dual`**, при котором каждая модель публикуется дважды —
один раз с коротким префиксом псевдонима и один раз с каноническим префиксом поставщика, — чтобы старые конфигурации
клиентов могли разрешать обе формы:

```
cc/claude-sonnet-4-6        ← префикс псевдонима
claude/claude-sonnet-4-6    ← канонический префикс, та же модель
```

Расширение запрашивает **`GET /v1/models?prefix=alias`**, поэтому для каждой модели поступает один идентификатор,
а общесерверная настройка для других клиентов не изменяется. На эталонном экземпляре это сократило
**2345 записей до 1396 — 949 дубликатов, ни одной потерянной модели.**

Если вы предпочитаете исправить это на уровне сервера для _каждого_ клиента, установите для флага функции
`MODELS_CATALOG_PREFIX_MODE` значение `alias` на панели управления. О параметре
запроса и таблице для каждого режима см. в разделе
[API_REFERENCE → prefix](../reference/API_REFERENCE.md#model-id-prefixes-prefix).

### Модели, не поддерживающие чат, скрываются

В каталоге также перечислены модели для изображений, видео, аудио, переранжирования, эмбеддингов и модерации.
Запросы чата к ним всё равно отклоняются:

```
HTTP 400 — Модель '<id>' предназначена для генерации изображений и не может использоваться с
/v1/chat/completions. Вместо этого используйте POST /v1/images/generations.
```

поэтому они отфильтровываются по полю `type` до попадания в средство выбора. **Модели Responses API
сохраняются** — каждая запись Codex / GPT-5.x объявляет `supported_endpoints: ["responses"]`,
а OmniRoute преобразует их для `/v1/chat/completions`, поэтому они полностью пригодны для использования.

### Поставщики, которых вы не настраивали

В каталоге перечислены модели от поставщиков с **активным подключением**, а также от всех поставщиков **noAuth** —
то есть поставщиков без ключей, составляющих значительную часть бесплатного уровня. Это сделано намеренно. Чтобы скрыть
их, добавьте их в `blockedProviders` в настройках панели управления; в расширении ничего не изменится.

## Панель управления во вкладке VS Code

`omnicopilot.dashboardOpen: "editor"` отображает панель управления OmniRoute во вкладке редактора через
Simple Browser вместо внешнего браузера. Встраивание необходимо **явно разрешить на сервере** с помощью
`DASHBOARD_ALLOW_EMBED=vscode`: в этом случае HTML-страницы отдаются с
`frame-ancestors 'self' vscode-webview:` вместо используемых по умолчанию `frame-ancestors 'none'` +
`X-Frame-Options: DENY`. Для интерфейсов API (`/api`, `/v1`, `/v1beta`, `/a2a`, `/healthz`) строгие
заголовки сохраняются в любом случае.

> ⚠️ **Это флаг времени сборки, а не времени выполнения.** Next.js компилирует `headers()` в манифест
> маршрутов, поэтому `next.config.mjs` считывает переменную во время сборки пакета
> (`next.config.mjs` → `resolveDashboardEmbedMode`, `scripts/build/dashboardEmbed.mjs`).
> Экспорт этой переменной перед запуском уже собранного сервера ничего не изменит — заголовки встроены в сборку.

```bash
# переменная должна быть задана в команде СБОРКИ
DASHBOARD_ALLOW_EMBED=vscode npm run build        # или npm run build:release
npm start
```

| Способ установки           | Можно ли включить встраивание?                                                                                                                             |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Из исходного кода          | ✅ задайте переменную в команде сборки, как показано выше                                                                                                  |
| `npm install -g omniroute` | ❌ опубликованный пакет содержит предварительно собранный пакет — вместо этого выполните сборку из исходного кода                                          |
| Образ Docker               | ✅ `docker build --build-arg DASHBOARD_ALLOW_EMBED=vscode -t omniroute:embed .` — предварительно собранный образ на Docker Hub не поддерживает встраивание |

Без сборки с поддержкой встраивания страница запрещает отображение во фрейме, расширение определяет это по
заголовкам ответа и переключается на внешний браузер — ничего не ломается, а уведомление об этом выводится один раз.
См. [`ENVIRONMENT.md`](../reference/ENVIRONMENT.md) и обсуждение
[#10273](https://github.com/diegosouzapw/OmniRoute/issues/10273).

## Настройка других инструментов изнутри VS Code

**`OmniRoute: Configure Coding CLI`** управляет `omniroute` CLI для написания готовых к использованию профилей для 16 инструментов: Codex CLI, Claude Code, Cline, Continue, Cursor, Aider, OpenCode, Goose, Crush, Qwen Code, Kilo, Roo, Gemini CLI, Zed, WhyCodes и 5dive. Расширение вызывает команды `setup-*` во встроенном терминале; установите версию OmniRoute CLI, включающую выбранную команду. См. [руководство по интеграции CLI](CLI-INTEGRATIONS.md) для файлов и флагов, которые использует каждый рецепт, а также [реестр инструментов расширения](https://github.com/cheaper-inference/OmniCopilot/blob/main/src/cliBridge.ts).

Ключ API передается CLI через `OMNIROUTE_API_KEY`, а не через командную строку. Рецепты установки могут сохранять учетные данные в конфигурации целевого инструмента. При совместном использовании ключа, специфичного для рабочей области, с конфигурацией инструмента на уровне пользователя расширение сначала запрашивает подтверждение.

## Поиск неисправностей

| Симптом                                                                    | Причина/устранение                                                                                                                                                                                                                                                                                                       |
| -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| В средстве выбора нет моделей OmniRoute                                    | Сервер недоступен. Точка в строке состояния станет серой; запустить `OmniRoute: Check Connection`. Discovery по своей конструкции молчит и не предлагает моделей, а лишь подсказывает.                                                                                                                                   |
| Каждая модель появляется дважды                                            | Вы используете обновление OmniCopilot старше 1.0.1 —. Расширение теперь запрашивает `?prefix=alias`.                                                                                                                                                                                                                     |
| Модель image/audio раньше была в списке, но ее больше нет                  | Намеренно, начиная с версии 1.0.1 — он никогда не мог ответить на запрос в чате.                                                                                                                                                                                                                                         |
| Панель отсутствует на панели действий                                      | Код VS перемещает дополнительные контейнеры представлений в** «…»** переполнение в нижней части панели действий, а контейнер, скрытый щелчком правой кнопки мыши, остается скрытым. Щелкните правой кнопкой мыши галочку → на панели активности.**OmniRoute** или откройте его с помощью `OmniRoute: Manage Connection`. |
| Панель мониторинга открывается в браузере, несмотря на режим `editor`      | Сервера не было** построен** с `DASHBOARD_ALLOW_EMBED=vscode` (см. выше) установка — при запуске предварительно созданной установки ничего не дает. Откат является преднамеренным.                                                                                                                                       |
| Список моделей устарел после смены поставщика.                             | `OmniRoute: Refresh Models` или ссылку ↻ на панели.                                                                                                                                                                                                                                                                      |
| На панели отображается _Онлайн (модели заблокированы)_, окно выбора пусто. | Сервер отклоняет ключ. Сохраните правильный ключ с помощью** Сохранить и протестировать** . Если вместо этого ключ был закреплен на сервере (включен или предоставлен доступ к моделям), расширение само не замечает: запустите `OmniRoute: Refresh Models` или откройте панель OmniRoute.                               |
