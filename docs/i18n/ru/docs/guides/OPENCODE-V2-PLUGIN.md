`@omniroute/opencode-plugin-v2` добавляет весь ваш каталог OmniRoute — модели, комбо и
автокомбо — в средство выбора моделей OpenCode v2 вместе с отображаемыми именами, ценами и
лимитами бесплатного уровня.

Это отдельный пакет, не связанный с `@omniroute/opencode-plugin`, поскольку OpenCode v1 и v2 загружают
плагины через разные контракты. Выберите пакет, соответствующий основной версии OpenCode; между
ними нет общих компонентов, поэтому обновление одного никогда не требует обновления другого.

## Требования

- OpenCode v2.
- Доступный шлюз OmniRoute (`http://localhost:20128` по умолчанию).
- Node.js 22 или 24.

## Установка

Добавьте плагин в `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

После этого модели появятся в виде `omniroute/<provider>/<model>`; `providerId` определяет этот префикс и
идентификатор интеграции, под которым OpenCode хранит учётные данные.

## Учётные данные

Плагин ищет ключ шлюза в трёх местах в следующем порядке:

1. **Учётные данные, подключённые в OpenCode.** Плагин регистрирует интеграцию, поэтому
   собственный механизм аутентификации OpenCode может сохранить ключ. В `opencode.json` ничего не записывается — предпочитайте этот вариант.
2. `apiKey` в параметрах плагина для переопределения на уровне проекта. При этом ключ помещается в файл,
   который вы можете фиксировать в системе контроля версий.
3. `OMNIROUTE_API_KEY` в окружении.

Если ключ не найден ни в одном из этих мест, каталог будет пуст, и плагин один раз сообщит об этом при запуске,
вместо того чтобы молча оставить средство выбора пустым.

### Токен управления — это другой ключ

Комбо, состояние провайдеров и обогащение данных (отображаемые имена, цены, лимиты бесплатного уровня) поступают
из конечных точек шлюза `/api/*`, которые в большинстве развёртываний защищены **управляющим** токеном,
а не ключом для инференса:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<management read token>"
}
```

Если `managementReadToken` не задан, вместо него используется `apiKey`. Если шлюз отклоняет такой резервный вариант,
каталог всё равно публикуется, но с исходными идентификаторами моделей вместо отображаемых имён, без устранения
дубликатов канонических псевдонимов, без цен и без комбо. Плагин выводит предупреждение по одному разу для каждой
конечной точки, когда это происходит, указывая конечную точку и какие данные были потеряны, — поэтому причина
ограниченной функциональности средства выбора всегда будет понятна.

## Параметры

| Ключ                             | По умолчанию                                           | Примечания                                                                                                                                                                                                                                                                                                                                                                                    |
| -------------------------------- | ------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `providerId`                     | `"omniroute"`                                          | Идентификатор поставщика, идентификатор интеграции и модели префикса отображаются в разделе                                                                                                                                                                                                                                                                                                   |
| `baseURL`                        | необходимый                                            | Корневой шлюз, только `http(s)` ; суффикс `/v1` добавляется там, где необходимо                                                                                                                                                                                                                                                                                                               |
| `apiKey`                         | подключенные учетные данные, затем `OMNIROUTE_API_KEY` | Ключ чата для `/v1/*`                                                                                                                                                                                                                                                                                                                                                                         |
| `managementReadToken`            | возвращается к `apiKey`                                | Ключ для `/api/*` — обычно** нет** тот же самый                                                                                                                                                                                                                                                                                                                                               |
| `displayName`                    | `"OmniRoute"`                                          | Имя провайдера в средстве выбора                                                                                                                                                                                                                                                                                                                                                              |
| `timeoutMs`                      | `10000`                                                | Тайм-аут выборки для каждой конечной точки (автоматические комбинации используют 5 с)                                                                                                                                                                                                                                                                                                         |
| `modelCacheTtlMs`                | `300000`                                               | Кэш каталога TTL; снимок диска согревает холодный запуск                                                                                                                                                                                                                                                                                                                                      |
| `timeouts`                       | возвращается к `timeoutMs`                             | Бюджеты на каждую конечную точку в мс: `models`, `combos`, `autoCombos`, `enrichment`                                                                                                                                                                                                                                                                                                         |
| `enrichment`                     | `true`                                                 | Получите названия, цены и бюджеты бесплатного уровня.                                                                                                                                                                                                                                                                                                                                         |
| `providerTag`                    | `true`                                                 | Переключить конечную скобку редактора: `Provider - Model (Editor)`. Поставщик (маршрут, обслуживающий модель) всегда отображается; редактор (создавший модель) указан только в скобках. Пример: `Openrouter - MoonshotAI: Kimi K 3.1 Pro` -> `Openrouter - Kimi K 3.1 Pro (MoonshotAI)`. Пропускается, если редактор и поставщик имеют одинаковое имя. Установите `false`, чтобы удалить его. |
| `usableOnly`                     | `false`                                                | Оставлять только поставщикам отчеты шлюза в том виде, в каком они предоставлены.                                                                                                                                                                                                                                                                                                              |
| `combosSource`                   | `"api"`                                                | `"models"` пропускает `/api/combos` и публикует комбинированные строки `/v1/models` ; фильтры на уровне участников сохраняют `"api"`                                                                                                                                                                                                                                                          |
| `showcasePerOwner`               | `10`                                                   | Записи просмотра по умолчанию сохраняются для каждого поставщика                                                                                                                                                                                                                                                                                                                              |
| `freshPerOwner`                  | `10`                                                   | Свежие записи по умолчанию сохраняются для каждого поставщика.                                                                                                                                                                                                                                                                                                                                |
| `freshWindowDays`                | `90`                                                   | Окно свежести в днях для свежей ветки                                                                                                                                                                                                                                                                                                                                                         |
| `usageMemory`                    | `true`                                                 | Восстановление статически удаленных записей, названных в результате 30-дневной аналитики использования (требуется токен управления)                                                                                                                                                                                                                                                           |
| `visibleModels` / `hiddenModels` | `[]`                                                   | Белые списки с точными или суффиксными значениями; отрицать победы; `*` публикует полный каталог (остальные фильтры по-прежнему применяются)                                                                                                                                                                                                                                                  |
| `geminiSanitization`             | `true`                                                 | Удалите ключевые слова JSON-Schema, Gemini отклоняет, из схем инструментов (инструменты `$ref` пересылаются без изменений).                                                                                                                                                                                                                                                                   |
| `apiFormat.allowAnthropic`       | `false`                                                | Направлять идентификаторы из белого списка через блок Anthropic API                                                                                                                                                                                                                                                                                                                           |
| `apiFormat.anthropicModels`      | `[]`                                                   | Полные идентификаторы моделей перенаправлены в Anthropic                                                                                                                                                                                                                                                                                                                                      |
| `logLevel` / `startupDebug`      | `warn` / `false`                                       | Многословность регистратора                                                                                                                                                                                                                                                                                                                                                                   |

Использование памяти включено по умолчанию. Без токена управления он остается инертным (регистрируется уведомление о запуске), и ничего не восстанавливается.

## Как каталог остается свежим

Каталог лениво извлекается и кэшируется для `modelCacheTtlMs`, а снимок диска сохраняет последний известный каталог доступным, когда шлюз недоступен. — сбой не будет стоить вам ничего, кроме свежести. Модели и комбо публикуются по мере их поступления; автоматические комбинации, список поставщиков и наложение обогащения складываются при приземлении, поэтому одна медленная конечная точка не может держать в заложниках весь сборщик.

Имена следуют за `Provider - Model[ (Editor)][ · budget][ (route)]`: поставщик отображается всякий раз, когда идентификатор содержит его (идентификатор без косой черты отображается без префикса), ведущий `🆓` отмечает свободные записи, а их бюджет бесплатного уровня остается в виде суффикса `· 1M tokens/month`, редактор явного имени `Editor: Model` перемещается в конечную скобку (ни один редактор не угадывается из других имен), а комбинации отображаются как `combo - <slug>` без свободного значка. Две записи с одинаковым именем получают суффикс маршрута — `(no-think)` —, чтобы они оставались различимыми. `providerTag` (по умолчанию `true`) переключает конечную скобку редактора.

Команды ручного обновления нет: команды OpenCode v2 представляют собой шаблоны приглашений, а не обратные вызовы, поэтому плагин не может их предоставить. Обновления следуют за TTL; хосту предлагается перезагрузить только тогда, когда каталог или наложение действительно изменились, а не один раз за обновление.

## Вызов инструментов в Gemini

Gemini отклоняет весь запрос, если объявления инструментов содержат `$schema` или
`additionalProperties`, отвечая `400 INVALID_ARGUMENT`. Плагин удаляет эти ключевые слова из схем
инструментов, предназначенных для модели Gemini этого провайдера, и не изменяет остальные запросы.
Инструмент, содержащий `$ref`, пересылается без изменений, поскольку удаление ссылки расширило бы
схему до «принимать что угодно».
Установите `"geminiSanitization": false`, чтобы отключить эту функцию.

## Поиск неисправностей

| Симптом                                                         | Причина                                                                                                                      |
| --------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| Средство выбора не показывает модель OmniRoute                  | Ключ не разрешен (проверьте предупреждение при запуске), или шлюз недоступен.                                                |
| Необработанные идентификаторы моделей, без комбинаций, без цен. | Конечные точки управления отказались от токена — set `managementReadToken`                                                   |
| Короткий или пустой каталог `freeOnly`                          | Нет токена управления или отклоненный токен. — читает сводную строку обновления (счетчик `unmatched-free` ) в журнале хоста. |
| Сеанс, закрепленный на `opencode-<id>/...`                      | Плагин v1 опубликовал `opencode-<id>`; v2 публикует голый `<id>`, поэтому повторно выберите модель в `<id>/...`              |

Переменные среды должны достигать процесса сервера с открытым кодом: когда хост работает как служба, оболочка, на которой работает `opencode models`, и среда сервера различаются, поэтому экспортируйте ключ туда, где его читает сервер.
