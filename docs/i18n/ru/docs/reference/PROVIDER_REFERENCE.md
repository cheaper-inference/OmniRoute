## Категории

- **Бесплатные** — бесплатный тариф с API-ключом (настраивается через панель управления)
- **Без аутентификации** — общедоступные конечные точки, для которых не требуется ключ или вход в систему
- **OAuth** — процесс входа обрабатывается OmniRoute, API-ключ не требуется
- **Веб-cookie** — предоставляет доступ к веб-приложению провайдера с помощью аутентификации через cookie
- **API-ключ** — платный провайдер, настраиваемый с помощью API-ключа (могут предоставляться бесплатные кредиты)
- **Локальные** — работают на компьютере пользователя (Ollama, LM Studio, vLLM и т. д.)
- **Поиск** — провайдеры веб-поиска
- **Аудио** — провайдеры только для аудио (TTS/STT)
- **Вышестоящий прокси** — провайдеры, проксирующие запросы к другим провайдерам
- **Облачный агент** — долго работающие агенты для программирования (Codex Cloud, Devin, Jules)
- **Системные** — внутренние провайдеры OmniRoute (loopback и т. д.)

Дополнительные теги: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Вызов инструментов` (если указан): `native` — настоящий API вызова функций; `emulated` — массив `tools` эмулируется через промпт с помощью `webTools.ts` (блоки `<tool>{...}</tool>` разбираются регулярным выражением); `none` — в настоящее время `tools` молча отбрасывается. См. #7286.

Используйте панель управления по адресу `/dashboard/providers`, чтобы включать, настраивать и тестировать каждого провайдера.
