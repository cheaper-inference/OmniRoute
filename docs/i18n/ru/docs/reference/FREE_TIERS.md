## Кратко — какой объём бесплатного инференса фактически агрегирует OmniRoute?

Эти цифры относятся к отдельным учётным записям сторонних сервисов и условиям участия в рамках всего каталога. OmniRoute не предоставляет этот бюджет: вам необходимо получить требуемые учётные записи или учётные данные, подключить подходящих провайдеров и соблюдать их ограничения. Фактически доступный объём может быть меньше, вплоть до нуля при новой установке без подходящего маршрута. Провайдеры с пометкой `tos: avoid` по умолчанию исключены из автоматической маршрутизации.

**Проверено 2026-10-08:** [Cerebras](https://www.cerebras.ai/pricing) предлагает единовременный промокредит в размере $5, для получения которого требуется указать способ оплаты; срок его действия истекает через 30 дней. [Gemini](https://ai.google.dev/gemini-api/docs/rate-limits) публикует ограничения частоты запросов по проектам, моделям и тарифам; он по-прежнему не включён в количественную ежемесячную оценку.

Реальная регулярная квота, представленная как `gatedRecurringTokens` / `gatedProviders` и отображаемая на панели управления. Никогда не включается в итоговую цифру: +~6M после региональной проверки личности.                                                 |
| Теоретический максимум (все ограничения частоты, 24/7) | ~10B                                 | Сумма ограничений частоты всех провайдеров, экстраполированная на непрерывное использование. **Не является гарантией** — не выносите это значение в заголовок.                                                                                                                                                                                              |

**Честный заголовок:** _OmniRoute агрегирует **~1.62B документированных бесплатных токенов в месяц** (до ~2.22B в первый месяц с учётом кредитов за регистрацию) в 34 пулах бесплатных тарифов, а также предоставляет длинный хвост бесплатных навсегда провайдеров без лимита; сжатие RTK + Caveman (экономия токенов на 15–95%) позволяет увеличить этот объём ещё больше._

> **Почему показатель снизился с прежних ~1,94B.** Обновление от 2026-06-17 — это корректировка ради достоверности, а не потеря: для `gemini` теперь устранено дублирование на уровне пула (ранее показатель был завышен из-за отдельного учёта каждого варианта Flash, 462M → 60M), значение `cloudflare-ai` исправлено в соответствии с реальным лимитом 10 тыс. нейронов в день (122M → 30M), `doubao` переклассифицирован как разовый кредит за регистрацию (а не возобновляемый), а закрытые тарифы удалены (`chutes`/`phind`/`kluster` прекратили работу). Это частично компенсировано `llm7` (корректные 5M/день → 150M) и новыми бесплатными провайдерами (Kilo, OpenCode Zen, Z.AI GLM-Flash).
>
> **Дополнительно скорректировано до ~1,37B в v3.8.42:** `longcat` был переклассифицирован с возобновляемого гранта 150M/мес. на разовый кредит 10M за регистрацию после завершения бесплатного ознакомительного периода. Применяется то же правило достоверности — ни один провайдер не был удалён по ошибке.
>
> **Обновлено 2026-08-26 после вывода Felo Web из эксплуатации:** Felo Web исключён, пока происхождение и лицензирование производного от GPL кода остаются в статусе HOLD; на тот момент источник сообщал о 38 ключах пулов. Число пулов рассчитывается динамически и контролируется CI (`check:docs-counts` завершает сборку с ошибкой, если приведённые выше числа расходятся с `computeFreeModelTotals()`).
>
> **Повторно проверено 2026-09-02 по собственным страницам провайдеров** (источники: комментарии `// evidence:` рядом с каждой повторно проверенной записью в `open-sse/config/freeModelCatalog.data.ts`): `gemini` и `ollama-cloud` больше не публикуют объём токенов (Google удалил бесплатную таблицу по моделям 2025-12-23; бесплатный план Ollama предоставляет «стартовые кредиты на использование») и теперь указаны как **безлимитные**, поэтому никогда не суммируются (−80M); у `groq` есть пять **отдельных для каждой модели** лимитов по 200K TPD (по 6M каждый, +15M), а три выведенных из эксплуатации идентификатора удалены; у `nara` один пул на 7M/день (+60M, 210M). Значение 1B для `mistral` отображается только в консоли учётной записи — см. раздел _Классы доказательств_ в Методологии.
>
> **Исправлено 2026-09-03 (#11773):** `cerebras` был переклассифицирован с возобновляемого гранта 30M/мес. (прежний пробный период без карты с 1M токенов в день) на разовый кредит $5 за регистрацию, для которого требуется способ оплаты. Применяется то же правило достоверности, что и для LongCat.
>
> **Плюс xKiro (2026-09-03):** новый пул `xkiro-free` (150M/мес.) добавляет 35-й возобновляемый ключ пула. Felo Web остаётся исключённым, пока происхождение и лицензирование производного от GPL кода остаются в статусе HOLD. Теперь источник сообщает о **34 возобновляемых ключах пулов** и **~1,62B стабильного объёма** — это актуальное число, контролируемое CI (`check:docs-counts` завершает сборку с ошибкой, если оно расходится с `computeFreeModelTotals()`).

Крупнейшие **документально подтверждённые** источники: `mistral` 1,00B, `nara` 210M, `llm7` 150M, `xkiro` 150M, `groq` 30M (пять отдельных лимитов для моделей), `cloudflare-ai` 30M, `api-airforce` 24M. (`longcat` исключён — его грант LongCat-2.0 на 10M является разовым кредитом за регистрацию, требующим прохождения KYC, а не возобновляемым ежемесячным бюджетом.)

> ⚠️ Теоретический потолок (~10B) завышен из-за провайдеров, ограниченных только частотой запросов и **не публикующих лимит токенов** (`tencent`, `nvidia`, `baidu`, `glm-cn`, `sparkdesk`), чьи показатели рассчитывались бы как `RPM/TPM × 24/7 × 30d` — это теоретический максимум, который не сможет стабильно поддерживать ни одна учётная запись. Они **исключены** из обоснованного показателя (вместо этого приведены в строке «навсегда бесплатно, без лимита»). Именно такое завышение делает многомиллиардные заявления конкурентов недостоверными.

Весь каталог был обновлён по результатам веб-исследования с участием 50 агентов (официальная документация + новости за последние 7 дней, проверенные с применением состязательного подхода). Основные изменения:

- **Gemini** — `2.0 Flash` / `2.0 Flash-Lite` отключены 2026-06-01, а `2.5 Pro` исключён из бесплатного уровня (2026-04); теперь на бесплатном уровне доступны **только модели семейства Flash** (2.5/3/3.1/3.5 Flash + Gemma). Теперь в каталоге семейство Flash **объединено в один пул** (ранее объём был завышен из-за отдельного учёта каждого варианта: 462M → 60M).
- **Исправленные показатели:** `cloudflare-ai` 122M → **30M** (фактически 10k нейронов в день), `doubao` переклассифицирован как однократный бонус за регистрацию (а не возобновляемый), `llm7` 4M → **150M** (документированный лимит — 5M токенов в день), бесплатные эндпоинты `together` с суффиксом «-Free» закрыты → бонус $25 за регистрацию также удалён (требуется покупка минимум на $5, бесплатного пробного периода нет), период Preview для `longcat` завершён + модели Flash выведены из эксплуатации → остался только **LongCat-2.0**, переклассифицированный как однократный бонус за регистрацию в размере **10M** токенов (требуется KYC, бонус не возобновляется).
- **Обнаружены новые бесплатные провайдеры:** ⭐ **Kilo Code** (`kilo-gateway` — ротируемый набор «Auto Free»: семейство NVIDIA Nemotron 3, StepFun, Poolside, Nex-N2-Pro), ⭐ **OpenCode Zen** (`opencode-zen` — 10 ротируемых бесплатных моделей для программирования, обновлено 2026-10-20), ⭐ **Z.AI / Zhipu** (`glm-cn` — GLM-4-Flash / 4.5-Flash / 4.7-Flash навсегда бесплатны + бонус 20M за регистрацию), а также Trinity Large Preview от `arcee-ai`.
- **Новые прозрачные категории** (см. раздел «Методология»): категория _навсегда бесплатных, но без фиксированного лимита_ (реальный возобновляемый доступ без поддающегося учёту лимита токенов) и _увеличение лимита после внесения депозита_ (OpenRouter: $10 → +24M/мес.); обе отображаются **отдельно**, чтобы они никогда не завышали основной показатель.

## Исправление бесплатных моделей SiliconFlow от 2026-10-18 (#17028)

Десять флагманских моделей SiliconFlow с опубликованными положительными ценами за токен были ошибочно
представлены как бесплатный доступ `recurring-uncapped`. Эти десять строк были **удалены** из
статического каталога, в котором теперь **467 записей**. SiliconFlow больше не добавляет
в статические итоги ни строку с безусловно бесплатной моделью, ни постоянно бесплатного провайдера.

Это **не** означает, что у SiliconFlow нет бесплатных моделей. Импорт только бесплатных моделей и значок Free
теперь требуют **положительного подтверждения для каждой модели из актуальных данных о моделях провайдера**, например
явного логического маркера бесплатности или нулевых цен как на входные, так и на выходные токены. Явный
маркер платности или любое положительное числовое значение цены имеет приоритет над оптимистичным маркером бесплатности. Модель без
доступного актуального подтверждения **не** считается бесплатной; разовый кредит для нового аккаунта не может
считаться возобновляемой бесплатной квотой. Если текущий API провайдера не может предоставить достоверные
цены на уровне моделей, подтвердите их в консоли провайдера перед маршрутизацией. Этот консервативный
подход предотвращает непредвиденные списания при импорте только бесплатных моделей и автоматическом комбинировании.

Приведённая ниже историческая таблица провайдеров не гарантирует актуальную доступность. Прежняя
запись SiliconFlow о безлимитном доступе к 10 моделям намеренно отсутствует, поскольку она больше не

## 2026-10-15 Исправления для Bytez и Nous

[Биллинг Bytez](https://docs.bytez.com/model-api/docs/billing) ограничивает открытые
модели на тарифе Free 7 млрд параметров. Записи для моделей с 70 и 72 млрд
параметров требуют разблокировки с помощью приобретённых кредитов и были удалены.
Mistral-7B остаётся `recurring-credit`: кредиты обновляются каждые четыре недели,
но оплата рассчитывается за секунду инференса, а объём доступных токенов не
публикуется. Счётчики токенов для этой модели равны нулю, чтобы обозначить
неизвестное количество, и заменяют неподтверждённую оценку в 1 млн токенов; это
не означает отсутствие бесплатных кредитов. Изменения Nous подробно описаны в
примечании о провайдере ниже.

## Два режима — подсчёт и принятие решений

OmniRoute отвечает на вопрос «бесплатно ли это?» с помощью двух режимов, которые
намеренно используют разные источники:

| Режим                     | Источник истины                                                                                                                                                           | Области применения                                                                                                                   |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| **Подсчёт / отображение** | Итоговый каталог — поставляемая базовая версия с наложенными данными Radar (`getRadarCatalog`)                                                                            | Итоги бесплатного уровня, карточка бюджета, панели мониторинга                                                                       |
| **Принятие решений**      | Только поставляемый каталог (`FREE_MODEL_BUDGETS` в `open-sse/config/freeModelCatalog.data.ts`) и локальные эвристики (суффикс `:free`, нулевая цена, `grantsFreeAccess`) | Все потребители `src/shared/utils/freeModels.ts`: импорт моделей, маршрутизация `auto/*`, `GET /v1/models` и предпросмотр в браузере |

Результаты подсчёта могут улучшаться всякий раз, когда доступен поток данных.
Принятие решений остаётся привязанным к артефакту релиза, поэтому ответ одинаков
в браузере и на сервере, воспроизводим в автономном режиме и тестируем без базы
данных. Если бы предпросмотр в браузере использовал один источник, а импорт на
сервере — другой, предпросмотр расходился бы с тем, что происходит после
нажатия, поэтому такое разделение сохранено намеренно.

## Методология и оговорки

- Числа представляют собой **оценки верхней границы**, основанные на документированных ограничениях бесплатного уровня каждого провайдера по состоянию на **2026-06-17** и собранные путём веб-исследования. Бесплатные уровни постоянно меняются — перепроверяйте данные, прежде чем полагаться на конкретное значение.
- **Что в действительности подтверждает запись.** Ни одна запись не содержит отдельной оценки достоверности, и API её также не предоставляет — считайте каждое приведённое выше значение оценкой одинакового, неуказанного качества. Два факта отличаются, поскольку они курируются вручную, а не выводятся автоматически: 44 записи содержат независимо задокументированный жёсткий предел (39 из них — строки xKiro, у которых общий суточный лимит), а 12 записей содержат уведомление об использовании запросов для обучения. `hardStopGuaranteed` задаётся только тогда, когда в собственных условиях провайдера указано, что при превышении бесплатного лимита запрос будет отклонён, а не приведёт к незаметному началу списания средств; источник приводится в комментарии рядом с записью. Значение никогда не устанавливается в `true` по умолчанию, а у записи, которую никто не проверил, оно остаётся незаданным. Таким образом, отсутствие флага жёсткого ограничения означает «не установлено», а не «известно, что начнётся списание средств». **Строгий режим** (включаемая отдельно защита маршрутизации `freeAccessPolicy=strict`) доверяет только записям с этим флагом; все остальные бесплатные уровни исключаются как `no-hard-stop` (см. `open-sse/services/autoCombo/strictZeroCostFilter.ts`). Когда защита фильтрует пул, видимый оператору журнал сообщает как количество исключений, так и долю `no-hard-stop` среди них.
- `estMonthlyFreeTokens` = только ежемесячно возобновляемые токены. **Разовые кредиты за регистрацию не возобновляются** и учитываются как 0. Прекращённые тарифы также учитываются как 0.
- Суточный лимит токенов → `monthly = daily × 30`. Если задокументировано только RPD → `RPD × ~800 выходных токенов × 30`. Если указаны только RPM/TPM (без суточного лимита) → **без ограничения** (см. ниже).
- **Постоянно бесплатно, но без опубликованного лимита токенов** (`glm-cn`, `tencent`, `baidu`, `kilo-gateway`, `opencode-zen`, `gemini`, `ollama-cloud`): это реальный регулярно возобновляемый бесплатный доступ, ограниченный частотой запросов или параллелизмом. Мы классифицируем такие записи как `recurring-uncapped` и **никогда не суммируем их** — умножение `RPM × 24/7 × 30d` дало бы вымышленный верхний предел (именно такое завышение мы отвергаем). Они перечислены, чтобы вы знали об их существовании.
- **Повышение лимита после пополнения:** небольшое разовое пополнение, которое навсегда увеличивает бесплатную квоту (OpenRouter: $10 → 1000 запросов в день ≈ +24 млн в месяц). Указывается как отдельное значение и не включается в основной стабильный показатель.
- **Квоты с проверкой соответствия требованиям** (`eligibilityGate: "regional-identity"`): реальная регулярно возобновляемая квота, которая становится доступна только после привязанной к региону проверки личности (сейчас — подтверждение личности в материковом Китае). Рассчитывается по тому же правилу дедупликации пулов в отдельный показатель (`gatedRecurringTokens`) и никогда не включается в основной стабильный показатель. Режим (`freeType`) не меняется, поэтому маршрутизация также остаётся неизменной.
- **Классы доказательств.** Правило: число в каталоге сопровождается ссылкой на источник в комментарии `// evidence:` рядом с записью — `public-page` (страница провайдера, доступная всем), `api-public` (не требующая аутентификации конечная точка провайдера, например общедоступная конечная точка тарифов NaraRouter по адресу router.bynara.id) или `console-verified <date> por <who>` (значение видно только в консоли учётной записи; в комментарии указано, кто и когда его видел, а также приведена общедоступная страница, подтверждающая существование лимита). Текущее состояние: пять блоков, повторно проверенных 2026-09-02, содержат такие комментарии (`gemini`, `groq`, `mistral`, `ollama-cloud`, `nara`); записи, созданные до повторной проверки 2026-09-02, используют результаты предыдущего исследования до тех пор, пока не будут изменены; любое **новое или изменённое** число без комментария с доказательством является ошибкой. На данный момент только `mistral` имеет статус console-verified.

## Почему наше число меньше, чем у других агрегаторов

Большинство показателей «бесплатных токенов в месяц» в этой сфере представляют собой суммы лимитов, указанных отдельно для каждой модели. Мы намеренно считаем иначе:

- **Каждый общий пул учитывается один раз.** Бесплатный план Mistral предоставляет один лимит в 1B токенов в месяц на организацию; перечисление этого лимита для пяти моделей не превращает его в 5B. Если суммировать по моделям, наш собственный каталог показывал бы **~7.4B** (пересчитано 2026-09-03; этот показатель не контролируется CI — пересчитывайте его при каждом изменении каталога), однако в заголовке указано **~1.47B**, поскольку именно столько фактически может потратить одна учётная запись у каждого провайдера.
- **Дневные ограничения пересчитываются, ограничения скорости — нет.** Документированный лимит токенов в день преобразуется по формуле `× 30`; документированный лимит запросов в день — по формуле `RPD × ~800 tokens × 30`; если провайдер публикует только число запросов в минуту, месячный показатель **не** рассчитывается, а лимит указывается как _неограниченный_ и никогда не включается в сумму. Умножение ограничения скорости на режим 24/7 — это искусственное завышение, от которого мы отказываемся.
- **Квоты, доступные только после региональной проверки личности, указываются отдельно** (`+~6M после региональной проверки личности`), поскольку большинство читателей не могут ими воспользоваться.
- **Кредиты за регистрацию действуют только в первый месяц** и указываются отдельным вторым показателем, никогда не смешиваясь с постоянным значением.
- **Показатель контролируется CI.** `npm run check:docs-counts` пересчитывает итоговые значения по каталогу и завершает сборку с ошибкой, если данные в этом файле, README или карточке бюджета расходятся с ними.

## Таблица особенностей ToS

> **Флаг ToS носит рекомендательный характер и не блокирует маршрутизацию.** Провайдеры с отметкой `tos` по умолчанию по-прежнему участвуют в маршрутизации и комбинациях/резервных маршрутах; флаг отображается только на `/dashboard/free-tiers` и `/api/free-tier/summary`. Параметр запроса `excludeTosAvoid` влияет только на сводное представление, а не на глобальную маршрутизацию. Оценка хранится в `open-sse/config/freeTierCatalog.ts` (носит информационный характер и не используется механизмами маршрутизации).

> Краткий обзор условий каждого провайдера применительно к самостоятельно размещённому персональному прокси для одного пользователя. `caution` = условие о личном использовании или прокси, которое стоит проверить; `ambiguous` = неясно; `ok` = явно разрешено. Информация не является юридической консультацией — решение принимаете вы.

## Глоссарий

| Термин                      | Значение                                                                       |
| --------------------------- | ------------------------------------------------------------------------------ |
| **RPM / RPD / RPH**         | Запросы в минуту / день / час                                                  |
| **TPM / TPD**               | Токены в минуту / день                                                         |
| **Документированный лимит** | Провайдер публикует явный дневной/месячный лимит токенов (обоснованный бюджет) |
| **Теоретический максимум**  | `rate-limit × 24/7 × 30d` — максимум, а не гарантированный бюджет              |
| **Нейрон**                  | Единица вычислений Cloudflare (~1 выходной токен)                              |
