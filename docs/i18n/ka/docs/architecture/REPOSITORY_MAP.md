## `_ideia/`, `_mono_repo/`, `_references/`, `_tasks/` — ძირითადი ხის მიღმა

ქვედატირით დაწყებულ ამ დირექტორიებში ინახება კონტენტი, რომელიც გავრცელებისთვის არ არის განკუთვნილი:
