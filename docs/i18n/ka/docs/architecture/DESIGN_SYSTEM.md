## 1. სად რა მდებარეობს

- **კიტი.** `packages/ui-kit/src` არის აღმავალი (upstream) `src/`-ის ბაიტ-ბაიტში ზუსტი ასლი იმ კომიტზე, რომელიც დაფიქსირებულია

  (`@import "../../packages/ui-kit/src/ci-ui.css"`).
