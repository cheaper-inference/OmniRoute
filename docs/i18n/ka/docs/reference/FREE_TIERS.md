## TL;DR — რამდენ უფასო დასკვნას აგროვებს OmniRoute რეალურად?

ეს ციფრები აღწერს მესამე მხარის ცალკეულ ანგარიშებს და შესაბამისობის პირობებს კატალოგში. OmniRoute არ გასცემს ამ ბიუჯეტს: თქვენ უნდა მიიღოთ საჭირო ანგარიშები ან სერთიფიკატები, დააკავშიროთ უფლებამოსილი პროვაიდერები და დაიცვან მათი ლიმიტები. ფაქტობრივი გამოსაყენებელი სიმძლავრე შეიძლება იყოს უფრო დაბალი, მათ შორის ნულოვანი ახალ ინსტალაციაზე დაშვებული მარშრუტის გარეშე. `tos: avoid` მონიშნული პროვაიდერები ნაგულისხმევად გამორიცხულია ავტომატური მარშრუტიზაციისგან.

**შემოწმებულია 2026-10-08:** [Cerebras](https://www.cerebras.ai/pricing) გთავაზობთ ერთჯერად 5$-ის სარეკლამო კრედიტს, რომელიც მოითხოვს გადახდის მეთოდს და ვადა იწურება 30 დღის შემდეგ. [Gemini](https://ai.google.dev/gemini-api/docs/rate-limits) აქვეყნებს project/model/tier განაკვეთის ლიმიტებს; ის რჩება რაოდენობრივი ყოველთვიური სათაურის მიღმა.
