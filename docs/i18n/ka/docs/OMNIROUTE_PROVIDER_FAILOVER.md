წარუმატებლობები კლასიფიცირდება განმეორებითი გადაწყვეტილების მიღებამდე.

გარდამავალი წარუმატებლობები, როგორიცაა დროის ამოწურვა, ქსელის შეცდომები, ტარიფის ლიმიტები და პროვაიდერის 5xx პასუხები, შესაძლოა ვერ განხორციელდეს. ამოწურული კვოტა ან კრედიტი (კვოტა 429, ან 402 საჭიროა გადახდა) არასოდეს განმეორდება იმავე პროვაიდერზე, მაგრამ ვერ გადადის სხვა პროვაიდერზე, რომლის კვოტა ცალკეა. ავტორიზაციის შეცდომები, ნებართვის შეცდომები, არასწორი მოთხოვნები, მიუწვდომელი მოდელები და უცნობი წარუმატებლობები არ განმეორდება ბრმად.

ნაგულისხმევი ჯვარედინი პროვაიდერების პოლიტიკა იძლევა პროვაიდერის მაქსიმუმ სამ მცდელობას, ხელახლა ცდის სიჩქარის ლიმიტებს და ვადის ამოწურვას, წარუმატებლობას ამოწურულ კვოტაზე და ინახავს ადმინისტრაციულ გათიშვას დამოუკიდებლად ჩართვის დროებითი მდგომარეობიდან.

## სადაც ეს ეხება

- **კომბინაციები** წარუმატებლობა მათ სამიზნეებს შორის კომბინაციის საკუთარი სტრატეგიისა და პარამეტრების მიხედვით.
- **შიშველი მოდელის ID** ( `provider/` პრეფიქსის გარეშე), რომელსაც რამდენიმე აქტიური პროვაიდერი ემსახურება, ამ ზუსტი სახელის კომბინაციის გარეშე, პირველად იგზავნება პროვაიდერის დასკვნების არჩევაში. თუ ეს მცდელობა წარუმატებელია ისე, რომ პოლიტიკა ვერ განხორციელდება, იგივე მოთხოვნა ეგზავნება შემდეგ აქტიურ პროვაიდერს, რომელიც ემსახურება ID-ს. პასუხი შეიცავს `x-omniroute-fallback-attempts` პროვაიდერთა რაოდენობას, ვინც უპასუხა.
  - თითოეული ალტერნატიული უფლებამოსილია ზუსტად ისე, თითქოს დასკვნამ ის აირჩია. სამიზნე, რომელიც API კლავიშს ბლოკავს ან არ აღიარებს, გამოტოვებულია ზემო დინებაში ზარის გარეშე და კლიენტი იღებს რეალურ ზედა დინების შეცდომას და არა პოლიტიკის უარყოფას სამიზნეზე, რომელიც არასოდეს დაუსახელებია.
  - მხოლოდ წარუმატებელი პასუხი გრძელდება: არაფერი არ წყდება პირველი ნაკადის ბაიტის შემდეგ.
  - გადაუდებელი სარეზერვო მოდელის შეცვლა მოქმედებს მხოლოდ მას შემდეგ, რაც მოთხოვნილი მოდელის ყველა პროვაიდერი წარუმატებელია.
  - კავშირზე (`x-omniroute-connection`) მიმაგრებული მოთხოვნა მასზე რჩება.
  - პრეფიქსის id (`provider/model`) არასოდეს გადამისამართდება სხვა პროვაიდერზე.

წრიული მდგომარეობაა `closed`, `open` და `half_open`. გაგრილება გეგმავს შეზღუდულ ზონდს; წარმატებული ზონდი ხურავს წრეს და წარუმატებელი ზონდი ხელახლა ხსნის მას.
