## რა არის პროვაიდერი?

წარმოიდგინეთ პროვაიდერი, როგორც **მობილური ოპერატორი**. ისევე, როგორც ზარების განსახორციელებლად მობილური ოპერატორი გჭირდებათ, AI მოდელების გამოსაყენებლად AI პროვაიდერი გჭირდებათ. OmniRoute ჰგავს ტელეფონს, რომელიც **ყველა ოპერატორთან** მუშაობს — მათ შორის ავტომატურად გადართვა შეგიძლიათ.

### პროვაიდერების ტიპები

| ტიპი             | რას წარმოადგენს                 | მაგალითები                      | ღირებულება                   |
| ---------------- | ------------------------------- | ------------------------------- | ---------------------------- |
| **უფასო**        | გადახდა არ არის საჭირო          | Kiro, Pollinations              | $0                           |
| **API გასაღები** | გჭირდებათ API გასაღები          | OpenAI, Anthropic, Google       | გამოყენების მიხედვით         |
| **OAuth**        | შედით თქვენი ანგარიშით          | Claude Code, GitHub Copilot     | გამოწერა                     |
| **ვებ-ქუქი**     | იყენებს თქვენი ბრაუზერის სესიას | ChatGPT Web (Codex), Gemini Web | $0 (იყენებს თქვენს ანგარიშს) |

### ვებ-ქუქის პროვაიდერები

ზოგადი დაყენების ინსტრუქციებისთვის, შეზღუდვებისთვის, პრობლემების აღმოფხვრისა და კონკრეტული პროვაიდერების ავთენტიფიკაციის მითითებებისთვის იხილეთ **[WEB-COOKIE-GUIDE.md](./WEB-COOKIE-GUIDE.md)**.

## სწრაფი დაწყება: დააკავშირეთ თქვენი პირველი პროვაიდერი

### პირველი გაშვებისას უფასო პროვაიდერების არასავალდებულო დაყენება

პირველი გაშვების ოსტატი გთავაზობთ ცალკე ბარათს — **უფასო პროვაიდერების დაყენება**. ის მიმდინარე
შესაფერის სიას OmniRoute-ის ავტორიზაციის არმომთხოვნი პროვაიდერების რეესტრიდან იღებს, შემდეგ კი საშუალებას გაძლევთ, დადასტურებამდე გადახედოთ თითოეულ
პროვაიდერს და გააუქმოთ მისი არჩევა. OmniRoute აჩვენებს პროვაიდერის გაფრთხილებას და მისი საიტის ბმულს,
რათა წინასწარ გაეცნოთ მესამე მხარის პირობებს, კონფიდენციალურობის პოლიტიკას, ხელმისაწვდომობასა და მოთხოვნების სიხშირის ლიმიტებს.

ეს მოქმედება არასავალდებულოა: ოსტატის დასრულება უფასო პროვაიდერებთან კავშირებს არასდროს ქმნის ფარულად.
ის ქმნის მხოლოდ იმ პროვაიდერებს, რომლებიც ჯერ კიდევ არ არის დამატებული, ხელუხლებლად ტოვებს არსებულ, მორგებულ კავშირებს
და ცალ-ცალკე გაჩვენებთ შექმნილ, უკვე კონფიგურირებულ და წარუმატებელ პროვაიდერებს. ნაწილობრივი შედეგის მიღების შემდეგ შეგიძლიათ
უსაფრთხოდ გაიმეოროთ მხოლოდ წარუმატებელი მცდელობები.

### ვარიანტი A: უფასო პროვაიდერი (საკრედიტო ბარათი არ არის საჭირო)

1. გახსენით მართვის პანელი მისამართზე `http://localhost:20128`
2. გადადით **პროვაიდერები** → **პროვაიდერის დამატება**
3. აირჩიეთ ამ უფასო პროვაიდერებიდან ერთ-ერთი:
   - **Kiro AI** — უფასო Claude მოდელები (ავტორიზაცია არ არის საჭირო)
   - **Pollinations** — უფასო GPT-5, Claude, Gemini (გასაღები არ არის საჭირო)
   - **LongCat** — 10M უფასო ტოკენი (ერთჯერადი პაკეტი, საჭიროა ანგარიში + KYC)
   - **Cloudflare AI** — 50+ მოდელი, 10K ნეირონი/დღეში
   - **MLX Gemma 26B** — ლოკალური Apple Silicon მოდელი (~38.5 ტოკენი/წმ, ~15.9GB RAM)
   - **MLX Qwen 3.8 27B** — ლოკალური Apple Silicon მოდელი (~9.1 ტოკენი/წმ, ~13.1GB RAM)
4. დააწკაპუნეთ **დაკავშირება**
5. მზადაა! ახლა უფასო AI-ზე წვდომა გაქვთ.

### ვარიანტი B: API-გასაღების პროვაიდერი (ფასიანი)

1. მიიღეთ API-გასაღები პროვაიდერის ვებსაიტიდან:

2. გახსენით მართვის პანელი მისამართზე `http://localhost:20128`
3. გადადით **პროვაიდერები** → **პროვაიდერის დამატება**
4. აირჩიეთ თქვენი პროვაიდერი
5. ჩასვით თქვენი API-გასაღები
6. დააწკაპუნეთ **დაკავშირება**
7. მზადაა! ახლა ამ პროვაიდერის მოდელებზე წვდომა გაქვთ.

### ვარიანტი C: OAuth პროვაიდერი (გამოწერა)

1. გახსენით მართვის პანელი მისამართზე `http://localhost:20128`
2. გადადით **პროვაიდერები** → **პროვაიდერის დამატება**
3. აირჩიეთ თქვენი პროვაიდერი (მაგ., Claude Code, GitHub Copilot)

5. შედით თქვენი ანგარიშით
6. მზადაა! ახლა თქვენი გამოწერის მოდელებზე წვდომა გაქვთ.

### ვარიანტი D: ლოკალური MLX მოდელები (Apple Silicon)

ერთიანი მეხსიერების მქონე Apple Silicon Mac-ებისთვის OmniRoute მხარს უჭერს `mlx-lm.server`-ის მეშვეობით გაშვებულ ლოკალურ MLX მოდელებთან დაკავშირებას, როგორც ჩვეულებრივ, OpenAI-თან თავსებად ლოკალურ პროვაიდერებთან.

#### წინაპირობები

- **Apple Silicon Mac** (M1/M2/M3/M4), რეკომენდებულია 24GB+ ერთიანი მეხსიერება
- **uv** პაკეტების მენეჯერი: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**: `uv pip install mlx-lm`

#### სწრაფი დაწყება

1. **დააყენეთ დამოკიდებულებები**:

   ```bash
   # დააყენეთ uv, თუ ის უკვე არ არის დაყენებული
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # დააყენეთ mlx-lm
   uv pip install mlx-lm
   ```

2. **ხელით გაუშვით MLX სერვერები** (ცალკეულ ტერმინალებში):

   ```bash
   # ტერმინალი 1: Gemma 4 26B A4B IT-QAT (პორტი 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # ტერმინალი 2: Qwen 3.8 27B MLX Mixed (პორტი 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **დააკავშირეთ OmniRoute-ის მართვის პანელში**:
   - გადადით **პროვაიდერები** → **პროვაიდერის დამატება**
   - აირჩიეთ **MLX Gemma 26B** ან **MLX Qwen 3.8 27B**
   - დააწკაპუნეთ **დაკავშირება** (API-გასაღები არ არის საჭირო)

4. **გამოიყენეთ OpenCode-თან ერთად**:
   ```bash
   # დააკონფიგურირეთ OpenCode OmniRoute-ის გამოსაყენებლად
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <your-omniroute-api-key>

   # გამოიყენეთ MLX მოდელები
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

#### მეხსიერების მართვა

**მნიშვნელოვანია**: 24GB ერთიანი მეხსიერების შემთხვევაში ერთდროულად მხოლოდ **ერთი დიდი MLX მოდელის გაშვებაა შესაძლებელი**.

- Gemma 26B: ~15.9GB მეხსიერების პიკური მოხმარება
- Qwen 3.8 27B: ~13.1GB მეხსიერების პიკური მოხმარება

ეს ხელით უნდა მართოთ:

- ერთდროულად გაუშვით მხოლოდ ერთი MLX სერვერი, ან
- ორივე ცალკეულ კომპიუტერზე გაუშვით, ან
- მეორის გაშვებამდე პირველი გააჩერეთ

OmniRoute ავტომატურად არ მართავს MLX სერვერის პროცესებს — ის მხოლოდ მოთხოვნებს გადაამისამართებს თქვენს მიერ კონფიგურირებულ OpenAI-თან თავსებად საბოლოო წერტილებზე.

#### ხელსაწყოების გამოძახების მხარდაჭერა

ორივე მოდელს აქვს OpenAI-თან თავსებადი ხელსაწყოების გამოძახების მხარდაჭერა. შეამოწმეთ შემდეგი ბრძანებით:

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mlx-gemma/gemma-4-26b",
    "messages": [{"role": "user", "content": "What is 2+2? Use the calculator tool."}],
    "tools": [{"type": "function", "function": {"name": "calculator", "description": "Calculate", "parameters": {"type": "object", "properties": {"expression": {"type": "string"}}, "required": ["expression"]}}}]
  }'
```

PAT-ისთვის დააინსტალირეთ Qoder CLI იმავე ჰოსტზე ან კონტეინერში, სადაც OmniRoute მუშაობს. შესრულებადი ფაილი აღმოჩენადი უნდა იყოს როგორც `qodercli`, ან მიუთითეთ მისი გზა `CLI_QODER_BIN`-ში. მხოლოდ Docker-ის ჰოსტზე დაინსტალირებული CLI ავტომატურად ხელმისაწვდომი არ არის კონტეინერში. შესრულებადი ფაილების არარსებობა წარმოქმნის მკაფიო შეცდომას, რომელიც ინსტალაციისკენ ან გზის მითითებისკენ მიგითითებთ.

CLI-ის ვალიდაცია/მოდელების ჩამონათვალის მიღება ცალკე 20-წამიან დროის ლიმიტს იყენებს. ეს კოდის მიმდინარე ნაგულისხმევი მნიშვნელობებია და არა მართვის პანელში კონფიგურირებადი პარამეტრები.

PAT შემსრულებლისადმი პირდაპირი გამოძახებებიც CLI-ის გაშვებამდე მკაფიო შეცდომით სრულდება, ნაცვლად იმისა, რომ ხელსაწყოების განსაზღვრებები ჩუმად უგულებელყოს. ეს შეზღუდვა ეხება API-ის გამომძახებლის მიერ მიწოდებულ ხელსაწყოებს და არა ნებისმიერ შიდა ხელსაწყოს, რომელსაც თავად Qoder CLI შეიძლება იყენებდეს. HTTP გასაღები არ იძლევა გარანტიას, რომ ყველა მოდელი ხელსაწყოებს უჭერს მხარს; მოდელის შესაძლებლობების ჩვეულებრივი შემოწმებები კვლავ მოქმედებს.

## ხშირად დასმული კითხვები

### „OmniRoute-ის გამოყენებისთვის გადახდა მჭირდება?“

**არა!** OmniRoute უფასო და ღია კოდის მქონე პროგრამაა. შეგიძლიათ უფასო პროვაიდერები (Kiro, Pollinations) ყოველგვარი გადახდის გარეშე გამოიყენოთ. თანხას მხოლოდ იმ შემთხვევაში გადაიხდით, თუ ფასიანი პროვაიდერების გამოყენებას გადაწყვეტთ.

### „რომელი პროვაიდერით დავიწყო?“

დაიწყეთ **Kiro AI**-ით — ის უფასოა, API გასაღებს არ საჭიროებს და Claude-ის მოდელებზე წვდომას გაძლევთ. შემდეგ, საჭიროებისამებრ, სხვა პროვაიდერებიც დაამატეთ.

### „შემიძლია ერთდროულად რამდენიმე პროვაიდერი გამოვიყენო?“

**დიახ!** სწორედ ეს არის OmniRoute-ის მთავარი დანიშნულება. დააკავშირეთ რამდენიმე პროვაიდერი და გამოიყენეთ `model: "auto"`, რათა OmniRoute-მა თითოეული მოთხოვნისთვის საუკეთესო პროვაიდერი შეარჩიოს.

### „რა მოხდება, თუ პროვაიდერი გაითიშება?“

OmniRoute ავტომატურად გამოტოვებს გაუმართავ პროვაიდერებს და შემდეგს სცდის. თქვენ არაფრის გაკეთება არ გჭირდებათ.

### „როგორ გავთიშო პროვაიდერი?“

გადადით Providers-ზე → დააწკაპუნეთ პროვაიდერზე → დააწკაპუნეთ **Disconnect**-ზე.

### „შემიძლია ჩემი არსებული API გასაღებების გამოყენება?“

**დიახ!** თუ უკვე გაქვთ OpenAI-ის, Anthropic-ის, Google-ის და სხვა პროვაიდერების API გასაღებები, მათი გამოყენება OmniRoute-ში შეგიძლიათ. პროვაიდერის დაკავშირებისას უბრალოდ ჩასვით ისინი.
