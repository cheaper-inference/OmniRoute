## რა არის უფასო დონეები?

ბევრი AI პროვაიდერი გვთავაზობს რაიმე ფორმას** უფასო წვდომა** . პროვაიდერიდან გამომდინარე, ეს შეიძლება ნიშნავდეს ავტორიზაციის გარეშე საბოლოო წერტილს, განმეორებით კვოტას, განაკვეთით შეზღუდული შეუზღუდავი წვდომას, რეგისტრაციის გრანტს, ხელით დამტკიცებას ან დროებით დაწინაურებას. ზოგიერთ ვარიანტს სჭირდება ანგარიში, API გასაღები, საკრედიტო ბარათი, KYC ან პროვაიდერის სპეციფიკური პირობების მიღება.

OmniRoute** აგრეგატები** კონფიგურირებული კავშირები ერთ ბოლო წერტილში. თქვენ მაინც დარეგისტრირდით ცალ-ცალკე თითოეული პროვაიდერისთვის, რომელიც საჭიროებს ანგარიშს. დააკავშირეთ ეს ანგარიშები და გამოიყენეთ `model: "auto"` დასაშვებ მიზნებს შორის მარშრუტისთვის. ახალ ინსტალაციას არ შეიძლება ჰქონდეს ნებადართული უკვანძო სამიზნე; მარტო OmniRoute დაყენება არ იძლევა წარმატებული ჩატის პასუხის გარანტიას.

## როგორ დავაწყოთ უფასო დონეები

OmniRoute მაგია არის** თავისუფალი იარუსების დაწყობა** . იმის ნაცვლად, რომ დაეყრდნოთ ერთ პროვაიდერს, თქვენ აკავშირებთ რამდენიმე უფასო პროვაიდერს და ნებას რთავთ OmniRoute ავტომატურად აირჩიოს საუკეთესო თითოეული მოთხოვნისთვის.

### მაგალითი: უფრო ფართო თავისუფალი დონის დაფარვა

დააკავშირეთ რამდენიმე პროვაიდერი, რათა შეამციროთ დამოკიდებულება რომელიმე ერთ კვოტაზე:

1. **Gemini** — განმეორებადი API-გასაღების კვოტა
2. **Groq** — განმეორებადი API-გასაღების კვოტა
3. **დამტვერვა** — ღილაკების გარეშე, განაკვეთით შეზღუდული წვდომა
4. **LongCat** — ერთჯერადი რეგისტრაციის გრანტი (საჭიროებს KYC)

შემდეგ გამოიყენეთ `model: "auto"` და OmniRoute will:

- ჯერ სცადეთ ყველაზე მაღალი რანგის შესაბამისი კავშირი
- თუ მისი კვოტა ან ჯანმრთელობის შემოწმება ვერ მოხერხდა → სცადეთ შემდეგი კონფიგურირებული პროვაიდერი
- თუ გასაღების გარეშე პროვაიდერი მიუწვდომელია → გააგრძელეთ დარჩენილი სამიზნეების გავლით
- თუ ვერცერთი შესაბამისი კავშირი ვერ მოხერხდა → დააბრუნეთ შეცდომა; სარეგისტრაციო კრედიტები მხოლოდ მოქმედი და ხელმისაწვდომია

**შედეგი** : უფრო ფართო თავისუფალი დონის დაფარვა ავტომატური სარეზერვო — არ არის შეუზღუდავი სიმძლავრის გარანტია.

## მოდის dsh "ჩვენი უფასო მოდელი"

| დანამატის ხაზი  | დინების ზემოთ                               | OmniRoute პროვაიდერი              | უფასო OmniRoute ში? | როგორ დაკავშირება                                                                    |
| --------------- | ------------------------------------------- | --------------------------------- | ------------------- | ------------------------------------------------------------------------------------ |
| კილო არხი       | Kilo AI კარიბჭე (`api.kilo.ai/api/gateway`) | `kilo-gateway` (სხვა სახელი `kg`) | დიახ                | API გასაღები სურვილისამებრ: დატოვეთ იგი ცარიელი კარიბჭის უფასო აუზის გამოსაყენებლად  |
| თავისუფალი ჩიხი | OpenCode Zen (`opencode.ai`)                | `opencode-zen`                    | არა                 | თქვენი საკუთარი OpenCode API გასაღები [opencode.ai/zen](https://opencode.ai/zen) დან |

**კილო.** დარეკეთ უფასო აუზს, როგორც `kilo-gateway/<model>` ან `kg/<model>`, მაგალითად `kg/kilo-auto/free` (Kilo-ს უფასო ავტო-როუტერი) ან კარიბჭის ერთ-ერთი `:free` მოდელი. თავისუფალი ნაკრები ბრუნავს; `kilo-gateway` გადის მოდელის იდენტიფიკატორებს, რომლებიც არ არის OmniRoute ის ჩაშენებულ სიაში, ასე რომ, მოდელი, რომელსაც დღეს კარიბჭე სიაში აქვს, შეიძლება გამოიძახოს კატალოგში შესვლამდე. Kilo-ს უფასო მოდელის ბარათებში ნათქვამია, რომ მოთხოვნილებები შეიძლება დარეგისტრირდეს ზედა ნაკადის პროვაიდერმა და გამოიყენოს მისი სერვისების გასაუმჯობესებლად, ამიტომ არ გაგზავნოთ მგრძნობიარე მონაცემები.

**OpenCode.** მოდულის უფასო ზოლი არის OpenCode ის შეთავაზება გასაღების გარეშე. OmniRoute არ უზრუნველყოფს ამ შეთავაზებას, როგორც უფასო წვდომას:

- OmniRoute's keyless OpenCode პროვაიდერი წაიშალა OpenCode ოპერატორის მოთხოვნით (იხ. [წაშლილი პროვაიდერები](../reference/REMOVED_PROVIDERS.md) ).
- OpenCode ს [საბოლოო წერტილის დოკუმენტაცია](https://opencode.ai/v2/docs/console/models/#endpoints) აკავშირებს მის უფასო ჩეთის შეთავაზებებს OpenCode ის საკუთარ კლიენტთან, ამიტომ OmniRoute არ ითვლის ან არ ასახელებს მათ, როგორც უფასო.

მოდულის მიერ ნაჩვენები მოდელის ID, როგორიცაა `deepseek-v4.1-flash-free`, `mimo-v2.6-flash-free` და `nemotron-3.5-lightning-free`, არის `opencode-zen` კატალოგში. დააკავშირეთ `opencode-zen` თქვენი საკუთარი OpenCode გასაღებით, რომ გამოიყენოთ ისინი თქვენი OpenCode ანგარიშის პირობებით.

**მოდულის ლოკალური პორტი.** დანამატს შეუძლია გამოავლინოს თავისი მოდელები ადგილობრივ OpenAI-თან თავსებად პორტზე (ნაგულისხმევი `18899`). ნებისმიერი ასეთი საბოლოო წერტილი შეიძლება დაემატოს, როგორც [მორგებული OpenAI-თან თავსებადი პროვაიდერი](../guides/USER_GUIDE.md#custom-openai-compatible-providers), მაგრამ OmniRoute არ აინსტალირებს, არ იწყებს ან განაახლებს დანამატს და დანამატი წყვეტს, თუ რომელი ემსახურება თითოეულ მოთხოვნას. ზემოთ მოყვანილი OpenCode შეზღუდვები ვრცელდება OpenCode ის შეთავაზებაზე, რომელი კლიენტი აგზავნის მოთხოვნას.

## კატალოგის სწორად კითხვა

- `NOAUTH` ნიშნავს, რომ OmniRoute არ გთხოვს პროვაიდერის სერთიფიკატს; ის არ იძლევა გარანტიას დროის, კონფიდენციალურობის ან შეუზღუდავი შესაძლებლობების შესახებ.
- `hasFree` არის აღმოჩენის მეტამონაცემები. მას შეუძლია წარმოადგინოს განმეორებადი კვოტა, უსადენო წვდომა, რეგისტრაციის კრედიტი, დამტკიცების პროგრამა ან დაწინაურება.
- `recurring-uncapped` ნიშნავს, რომ არ იყო გამოქვეყნებული სიმბოლური ჭერი; განაკვეთის და კონკურენტულობის ლიმიტები კვლავ მოქმედებს.
- `one-time-initial` არ განმეორდება რეგისტრაციის გრანტის მოხმარების შემდეგ.
- `tos: avoid` პროვაიდერები ნაგულისხმევად გამორიცხულია ავტომატური მარშრუტიზაციისგან (`excludeTosAvoid`). ანგარიშის დაკავშირება არ გადალახავს ამ ფილტრს. ნებისმიერი ოპერატორის უგულებელყოფა უნდა მოჰყვეს პროვაიდერის პირობებისა და ანგარიშის რისკის განხილვას.
- ჩანაწერები მონიშნული `discontinued` რჩება ისტორიულ მტკიცებულებად და არ უნდა იყოს წარმოდგენილი როგორც ამჟამად თავისუფალი.

## საერთო კითხვები

### "ეს ნამდვილად უფასოა?"

კატალოგში იწერება პროვაიდერის მიერ გამოქვეყნებული პირობები და პროექტის კვლევა, მაგრამ შეთავაზებები შეიძლება შეიცვალოს. გამოყენებამდე შეამოწმეთ პროვაიდერის მიმდინარე ფასები, კვოტა, კონფიდენციალურობის პოლიტიკა და უფლებამოსილება.

### "თავისუფალი იარუსი ამოიწურება?"

ყველა პროვაიდერს შეუძლია შეაფასოს ლიმიტი, შეცვალოს მოდელები, შეაჩეროს წვდომა ან ხაზგარეშე. მრავალი კავშირი აუმჯობესებს სარეზერვო დაფარვას, მაგრამ არ იძლევა გარანტიას ხელმისაწვდომი უფასო მარშრუტის შესახებ.

### "შემიძლია გამოვიყენო უფასო პროვაიდერები წარმოებისთვის?"

მხოლოდ იმ შემთხვევაში, თუ პროვაიდერის SLA, მონაცემთა დამუშავება, ლიმიტები და პირობები აკმაყოფილებს თქვენს წარმოების მოთხოვნებს. კრიტიკულ დატვირთვას უნდა ჰქონდეთ მონიტორინგი, კონტრაქტით შესაფერისი სარეზერვო.

### "რა არის დაჭერა?"

გაცვლა შეიძლება მოიცავდეს მკაცრ ლიმიტებს, მოლოდინების სიას, KYC, საკრედიტო ბარათის გადამოწმებას, მოთხოვნის ტრენინგს, უფრო სუსტ კონფიდენციალურობას, SLA გარეშე, მოდელის შეზღუდვას, გეოგრაფიულ შეზღუდვებს, გადახდილ ზედმეტობას ან ანგარიშის პოლიტიკის რისკს. OmniRoute ასახავს ხელმისაწვდომ მეტამონაცემებს; თქვენ ირჩევთ რა ჩართოთ.

### "როგორ მივიღო მეტი თავისუფალი კვოტა?"

1. დააკავშირეთ მეტი უფასო პროვაიდერი
2. ჩართეთ შესაბამისი შეკუმშვის ძრავები და გაზომეთ დანაზოგი თქვენი დატვირთვისთვის
3. გამოიყენეთ `auto/cheap` free/cheap პროვაიდერების პრიორიტეტებისთვის
4. დაამატეთ დამატებითი ნებადართული პროვაიდერები ან რწმუნებათა სიგელები პროვაიდერის პირობების დარღვევის გარეშე

### "უფასო პროვაიდერებს აქვთ უარესი ხარისხი?"

არ არის აუცილებელი. ზოგიერთი პროვაიდერი ავლენს იმავე მოდელის ოჯახებს, რომლებიც ხელმისაწვდომია ფასიანი მარშრუტების საშუალებით, მაგრამ ლიმიტები, შეყოვნება, კონფიდენციალურობა, საიმედოობა და მოდელის ვერსიები შეიძლება განსხვავდებოდეს. გამოიყენეთ უფასო პროვაიდერის რეიტინგების გვერდი, როგორც ხარისხის სიგნალი და გადაამოწმეთ რეალურად მოწოდებული მოდელი.
