დააინსტალირეთ OmniRoute დაფა, როგორც პროგრესული ვებ აპი, რომ გახსნათ იგი თქვენი საწყისი ეკრანიდან ან დესკტოპიდან დამოუკიდებელ ფანჯარაში. დაინსტალირებული აპს კვლავ სჭირდება კავშირი თქვენს OmniRoute სერვერთან ნავიგაციისთვის, დაფის მონაცემებისა და API მოთხოვნებისთვის. ქეშირებული სტატიკური აქტივები არ იძლევა ხაზგარეშე კარიბჭეს ან ოფლაინ საინფორმაციო დაფას.

## რა არის PWA?

პროგრესული ვებ აპი იყენებს ვებ დაფის აპის ხატულას და ცალკე ფანჯარას. დაინსტალირების შემდეგ, OmniRoute:

- გაშვება თქვენი საწყისი ეკრანიდან ან დესკტოპიდან
- იხსნება დამოუკიდებელ რეჟიმში, ბრაუზერის ჩვეულებრივი მისამართის ზოლისა და ჩანართების გარეშე
- არჩეული სტატიკური აქტივების ქეშირება
- მხარს უჭერს პორტრეტულ და ლანდშაფტის ორიენტაციას

## ინსტალაცია

გამოიყენეთ HTTPS მისამართი სერვერისთვის სხვა მოწყობილობაზე. როდესაც სერვერი მუშაობს იმავე მოწყობილობაზე, `http://localhost:20128` ასევე აკმაყოფილებს ბრაუზერის ინსტალაციის მოთხოვნებს. ჩვეულებრივი `http://YOUR_IP:20128` მისამართი არ აკმაყოფილებს ამ მოთხოვნებს. ინსტალაციის მენიუები და მოთხოვნები დამოკიდებულია ბრაუზერზე და ოპერაციულ სისტემაზე. იხილეთ [MDN's PWA ინსტალაციის მოთხოვნები](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable#https_localhost_or_loopback_are_required).

### Android (Chrome)

1. გახსენით თქვენი OmniRoute HTTPS მისამართი, ან `http://localhost:20128` სერვერისთვის იმავე ტელეფონზე.
2. გახსენით**⋮** მენიუ და აირჩიეთ** დააინსტალირეთ აპლიკაცია** ან** დამატება მთავარ ეკრანზე** , თუ შესთავაზებენ.
3. დაადასტურეთ მოთხოვნა.
4. გახსენით OmniRoute საწყისი ეკრანიდან.

### iOS (Safari)

1. გახსენით თქვენი OmniRoute HTTPS მისამართი Safari-ში.
2. შეეხეთ** გააზიარეთ** →** დამატება მთავარ ეკრანზე** .
3. დაადასტურეთ სახელი და შეეხეთ** დამატება** .
4. გახსენით OmniRoute საწყისი ეკრანიდან.

### სამუშაო მაგიდა (Chrome / Edge)

1. გახსენით თქვენი OmniRoute დაფა.
2. გამოიყენეთ ბრაუზერის ინსტალაციის ხატულა ან** დააინსტალირეთ აპლიკაცია** მენიუს შეყვანა, თუ შემოთავაზებულია.
3. დაადასტურეთ მოთხოვნა OmniRoute გახსნის შესახებ საკუთარ ფანჯარაში.

## მახასიათებლები

### დამოუკიდებელი ფანჯარა

მანიფესტი ადგენს `display: "standalone"` და `start_url: "/dashboard"`. დაინსტალირებული აპლიკაცია ხსნის საინფორმაციო დაფას აპის ფანჯარაში. ბრაუზერისა და ოპერაციული სისტემის კონტროლი კვლავ შეიძლება გამოჩნდეს; manifest არ ითხოვს სრულეკრანიან რეჟიმს.

### დაკავშირების გვერდი

`/offline` გვერდი უზრუნველყოფს დაკავშირების შეტყობინებას, online/offline ინდიკატორს, ა** ხელახლა სცადეთ კავშირი** ღილაკი და სტატუსის გვერდის ბმული. ეს არის** არ არის წინასწარ ქეშირებული** და მომსახურე მუშა აკეთებს** არა** წარუმატებელი ნავიგაციები მასზე გადამისამართება. მისი არსებობა არ ხდის ახალ გვერდებს ხელმისაწვდომს სერვერის გარეშე.

### ავტომატური რეგისტრაცია

`PwaRegister` აღრიცხავს მუშაკს წარმოებაში, როდესაც ბრაუზერი მხარს უჭერს სერვისის მუშაკებს. განვითარების რეჟიმი არღვევს მუშაკებს რეგისტრაციას და ასუფთავებს ქეშებს, რათა თავიდან აიცილოს ძველი აქტივები, რომლებიც ხელს უშლის ცხელ გადატვირთვას. ინსტალაციის მოთხოვნები ბრაუზერის გადაწყვეტილებად რჩება.

## ტექნიკური არქიტექტურა

### ვებ აპლიკაციის მანიფესტი

Next.js წარმოქმნის `/manifest.webmanifest` [`src/app/manifest.ts`](../../src/app/manifest.ts) დან. მისი ძირითადი პარამეტრებია:

| დაყენება              | ღირებულება                                           |
| --------------------- | ---------------------------------------------------- |
| `short_name`          | `OmniRoute`                                          |
| `start_url`           | `/dashboard`                                         |
| `scope`               | `/`                                                  |
| `display`             | `standalone`                                         |
| `orientation`         | `any`                                                |
| ფონის და თემის ფერები | ნაგულისხმევი სინათლის პალიტრა `PWA_THEME_COLORS` დან |

manifest-ის სახელი და აღწერა არის სტატიკური მნიშვნელობები ამ წყაროს ფაილში. დაინსტალირებული manifest არ მიჰყვება მაგალითის სახელის პარამეტრს ან აქტიურ პალიტრას ყოველი ვიზიტისას.

### მომსახურე მუშაკი

[`public/sw.js`](../../public/sw.js) არ აქვს სერვის-მუშაკის ჩარჩო დამოკიდებულება:

- **დააინსტალირეთ:** წინასწარ ინახავს ზემოთ ჩამოთვლილ ოთხ რესურსს და ააქტიურებს ახალ მუშაკს.
- **გააქტიურება:** შლის ძველი ქეშის თაობებს და აცხადებს კლიენტებს.
- **მიღება:** იყენებს სტატიკური აქტივების სტრატეგიებს და მარშრუტების გამორიცხვას ზემოთ.
- **ვერსია:** წყაროს ქეშის სახელია `omniroute-pwa-v3`; წარმოების კონსტრუქცია აფიქსირებს ქეშის იდენტურობას.
- **შეტყობინებები:** ამუშავებს შემომავალ `push` მოვლენებს და ფოკუსირებს ან ხსნის ფანჯარას, როდესაც შეტყობინებაზე დაწკაპუნება ხდება.

Push ღონისძიებების დამმუშავებლები მარტო არ ადგენენ აქტიურ Push გამოწერას ან კონფიგურირებულ სერვერის მიწოდებას. არ იფიქროთ, რომ შეტყობინებები ჩართულია მხოლოდ იმიტომ, რომ PWA დაინსტალირებულია.

### განლაგება მეტამონაცემები და რეგისტრაცია

[`src/app/layout.tsx`](../../src/app/layout.tsx) უზრუნველყოფს მანიფესტის ბმულს, Apple-ის დამოუკიდებელ მეტამონაცემებს, თემის ფერებს და `viewport-fit: cover`. გვერდის სათაური და Apple ვებ-აპის სათაური იყენებს ინსტანციის სახელს. ცოცხალი ბრაუზერის თემის ფერი მიჰყვება პალიტრას; ინსტალაციის მანიფესტი იყენებს ნაგულისხმევ ღია ფერს.

[`PwaRegister`](../../src/shared/components/PwaRegister.tsx) მუშაობს კლიენტზე და აღრიცხავს `/sw.js` build ID ით მის URL ში. ის აღმოაჩენს შეუსაბამო ქეშის თაობებს და შეუძლია გადააყენოს მუშაკი და გადატვირთოს ერთხელ ძველი ინსტალაციის შემდეგ. რეგისტრაციის წარუმატებლობა არ ბლოკავს პანელს.

## გამოყენება Termux-თან (Android)

1. დაიწყეთ OmniRoute Termux-ში: `npx -y omniroute@latest`.
2. გახსენით Chrome იმავე ტელეფონზე: `http://localhost:20128`.
3. დააინსტალირეთ PWA ბრაუზერის ინსტალაციის მენიუდან.
4. შეინახეთ Termux სერვერის გაშვება დაფის გამოყენებისას.

ტელეფონს აქვს როგორც კარიბჭე, ასევე მისი დაფა. მოთხოვნებს დისტანციური AI პროვაიდერებისთვის ჯერ კიდევ სჭირდება ქსელში წვდომა. იხილეთ [Termux-ის სახელმძღვანელო](TERMUX_GUIDE.md) დაყენებისა და Android-ის პროცესის სიცოცხლის მოსაზრებებისთვის.

## გამოიყენეთ სხვა მოწყობილობებიდან

გახსენით სერვერის HTTPS მისამართი ტელეფონზე, ტაბლეტზე ან დესკტოპზე, შემდეგ მიჰყევით ბრაუზერის ინსტალაციის პროცესს. სერვერი უნდა იყოს ხელმისაწვდომი თითოეული მოწყობილობიდან. იხილეთ [გვირაბის სახელმძღვანელო](../ops/TUNNELS_GUIDE.md) დისტანციური წვდომის ვარიანტებისთვის.

### ინსტანციის სახელი

The** ინსტანციის სახელი** დაფაზე მეტამონაცემების ცვლილებების პარამეტრი, გვერდის სათაურის და Apple-ის ვებ-აპის სათაურის ჩათვლით. გენერირებული მანიფესტი იყენებს სტატიკურ სახელს, ამიტომ ეს პარამეტრი არ იძლევა გარანტიას, რომ უკვე დაინსტალირებული აპს სახელი გადაერქვა.

### მორგებული Favicon

მორგებული ფავიკონი ცვლის ბრაუზერის ფავიკონს. ინსტალაციის მანიფესტი კვლავ აქვეყნებს ზემოთ მოცემულ PNG ფაილებს; ფავიკონის შეცვლა არ ცვლის საწყისი ეკრანის ხატულებს.
