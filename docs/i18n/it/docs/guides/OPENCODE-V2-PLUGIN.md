`@omniroute/opencode-plugin-v2` rende disponibile l'intero catalogo OmniRoute — modelli, combo e
auto-combo — nel selettore di modelli di OpenCode v2, con nomi visualizzati, prezzi e budget
del piano gratuito.

È un pacchetto separato da `@omniroute/opencode-plugin` perché OpenCode v1 e v2 caricano
i plugin tramite contratti differenti. Scegli quello corrispondente alla versione principale di OpenCode in uso; non vi è
nulla di condiviso tra i due, quindi l'aggiornamento dell'uno non impone mai quello dell'altro.

## Requisiti

- OpenCode v2.
- Un gateway OmniRoute raggiungibile (`http://localhost:20128` per impostazione predefinita).
- Node.js 22 o 24.

## Installazione

Aggiungi il plugin a `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

I modelli vengono quindi visualizzati come `omniroute/<provider>/<model>`; `providerId` determina tale prefisso e
l'id dell'integrazione sotto cui OpenCode memorizza la credenziale.

## Credenziali

Il plugin cerca una chiave del gateway in tre posizioni, nel seguente ordine:

1. **La credenziale collegata in OpenCode.** Il plugin registra un'integrazione, consentendo
   al flusso di autenticazione di OpenCode di memorizzare la chiave. Nulla viene salvato in `opencode.json`: questa è l'opzione consigliata.
2. `apiKey` nelle opzioni del plugin, per una sostituzione specifica del progetto. In questo modo la chiave viene inserita in un file che
   potrebbe essere incluso nei commit.
3. `OMNIROUTE_API_KEY` nell'ambiente.

Se nessuna delle tre è presente, il catalogo è vuoto e il plugin lo segnala una volta all'avvio, anziché
lasciare un selettore vuoto senza alcuna spiegazione.

### Il token di gestione è una chiave diversa

Le combo, lo stato dei provider e l'arricchimento (nomi visualizzati, prezzi e budget del piano gratuito) provengono
dagli endpoint `/api/*` del gateway, che nella maggior parte delle distribuzioni sono protetti da un token di **gestione**
anziché dalla chiave di inferenza:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<token di lettura per la gestione>"
}
```

Se non è impostato, `managementReadToken` utilizza come ripiego `apiKey`. Quando un gateway rifiuta tale ripiego,
il catalogo viene comunque pubblicato, ma con gli id grezzi dei modelli anziché i nomi visualizzati, senza
deduplicazione degli alias canonici, senza prezzi e senza combo. Il plugin emette un avviso una volta per ciascun endpoint quando ciò accade,
indicando il nome dell'endpoint e ciò che è andato perso, affinché un selettore degradato non rimanga mai inspiegabile.

## Opzioni

| Chiave                           | Predefinito                                      | Note                                                                                                                                                                                                                                                                                                                                                                                                                 |
| -------------------------------- | ------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `providerId`                     | `"omniroute"`                                    | L'ID provider, l'ID integrazione e i modelli di prefisso vengono visualizzati sotto                                                                                                                                                                                                                                                                                                                                  |
| `baseURL`                        | necessario                                       | Radice gateway, solo `http(s)` ; il suffisso `/v1` viene aggiunto dove necessario                                                                                                                                                                                                                                                                                                                                    |
| `apiKey`                         | credenziale connessa, quindi `OMNIROUTE_API_KEY` | Tasto chat per `/v1/*`                                                                                                                                                                                                                                                                                                                                                                                               |
| `managementReadToken`            | ricade su `apiKey`                               | Chiave per `/api/*` — di solito** non** lo stesso                                                                                                                                                                                                                                                                                                                                                                    |
| `displayName`                    | `"OmniRoute"`                                    | Nome del provider nel selettore                                                                                                                                                                                                                                                                                                                                                                                      |
| `timeoutMs`                      | `10000`                                          | Timeout di recupero per endpoint (le combo automatiche utilizzano 5 secondi)                                                                                                                                                                                                                                                                                                                                         |
| `modelCacheTtlMs`                | `300000`                                         | Cache del catalogo TTL; uno snapshot del disco riscalda gli avviamenti a freddo                                                                                                                                                                                                                                                                                                                                      |
| `timeouts`                       | ricade su `timeoutMs`                            | Budget per endpoint in ms: `models`, `combos`, `autoCombos`, `enrichment`                                                                                                                                                                                                                                                                                                                                            |
| `enrichment`                     | `true`                                           | Recupera nomi, prezzi e budget del livello gratuito                                                                                                                                                                                                                                                                                                                                                                  |
| `providerTag`                    | `true`                                           | Attiva/disattiva la parentesi dell'editor finale: `Provider - Model (Editor)`. Il fornitore (percorso che serve il modello) viene sempre mostrato; l'editore (che ha realizzato il modello) appare solo tra parentesi. Esempio: `Openrouter - MoonshotAI: Kimi K 3.1 Pro` -> `Openrouter - Kimi K 3.1 Pro (MoonshotAI)`. Omesso quando l'editor e il fornitore condividono un nome. Imposta `false` per rilasciarlo. |
| `usableOnly`                     | `false`                                          | Mantieni solo i provider segnalati dal gateway come forniti                                                                                                                                                                                                                                                                                                                                                          |
| `combosSource`                   | `"api"`                                          | `"models"` salta `/api/combos` e pubblica le righe combinate `/v1/models` ; i filtri a livello di membro mantengono `"api"`                                                                                                                                                                                                                                                                                          |
| `showcasePerOwner`               | `10`                                             | Voci con visualizzazione predefinita mantenute per fornitore                                                                                                                                                                                                                                                                                                                                                         |
| `freshPerOwner`                  | `10`                                             | Nuove voci con visualizzazione predefinita conservate per fornitore                                                                                                                                                                                                                                                                                                                                                  |
| `freshWindowDays`                | `90`                                             | Finestra di freschezza in giorni per il ramo fresco                                                                                                                                                                                                                                                                                                                                                                  |
| `usageMemory`                    | `true`                                           | Ripristina le voci eliminate staticamente denominate dall'analisi di utilizzo di 30 giorni (è necessario un token di gestione)                                                                                                                                                                                                                                                                                       |
| `visibleModels` / `hiddenModels` | `[]`                                             | Liste consentite esatte o suffisso; negare le vittorie; `*` pubblica il catalogo completo (si applicano ancora altri filtri)                                                                                                                                                                                                                                                                                         |
| `geminiSanitization`             | `true`                                           | Rimuovi le parole chiave dello schema JSON Gemini rifiutate dagli schemi degli strumenti (gli strumenti `$ref` vengono inoltrati intatti)                                                                                                                                                                                                                                                                            |
| `apiFormat.allowAnthropic`       | `false`                                          | Instrada gli ID consentiti attraverso il blocco Anthropic API                                                                                                                                                                                                                                                                                                                                                        |
| `apiFormat.anthropicModels`      | `[]`                                             | ID modello completi indirizzati a Anthropic                                                                                                                                                                                                                                                                                                                                                                          |
| `logLevel` / `startupDebug`      | `warn` / `false`                                 | Verbosità del registratore                                                                                                                                                                                                                                                                                                                                                                                           |

La memoria di utilizzo è attiva per impostazione predefinita. Senza un token di gestione rimane inerte (viene registrato un avviso di avvio) e non viene ripristinato nulla.

## Come il catalogo rimane aggiornato

Il catalogo viene recuperato pigramente e memorizzato nella cache per `modelCacheTtlMs` e uno snapshot del disco mantiene disponibile l'ultimo catalogo noto quando il gateway è irraggiungibile — un'interruzione non ti costa altro che freschezza. Modelli e combo vengono pubblicati non appena arrivano; le combo automatiche, l'elenco dei fornitori e la sovrapposizione di arricchimento si ripiegano quando atterrano, quindi un endpoint lento non può tenere in ostaggio l'intero selettore.

I nomi seguono `Provider - Model[ (Editor)][ · budget][ (route)]`: il provider viene mostrato ogni volta che l'id ne porta uno (un id senza barra viene visualizzato senza prefisso), uno `🆓` iniziale contrassegna le voci gratuite e il loro budget del livello gratuito rimane come suffisso `· 1M tokens/month`, l'editor di un nome `Editor: Model` esplicito si sposta su una parentesi finale (nessun editor viene indovinato da altri nomi) e le combo vengono visualizzate come `combo - <slug>` senza un'icona gratuita. Due voci che condividono un nome ottengono un suffisso di percorso — `(no-think)` — in modo che rimangano distinguibili. `providerTag` (default `true`) attiva/disattiva la parentesi finale dell'editor.

Non esiste un comando di aggiornamento manuale: i comandi OpenCode v2 sono modelli di prompt, non callback, quindi un plug-in non può esporne uno. Gli aggiornamenti seguono TTL; all'host viene chiesto di ricaricare solo quando il catalogo o l'overlay vengono effettivamente modificati, mai una volta per aggiornamento.

## Chiamata degli strumenti su Gemini

Gemini rifiuta un'intera richiesta le cui dichiarazioni degli strumenti contengono `$schema` o `additionalProperties`, rispondendo con `400 INVALID_ARGUMENT`. Il plugin rimuove queste parole chiave dagli schemi degli strumenti destinati a un modello Gemini di questo provider e lascia inalterate tutte le altre richieste. Uno strumento contenente un `$ref` viene inoltrato senza modifiche anziché essere ripulito, poiché la rimozione del riferimento amplierebbe lo schema facendogli «accettare qualsiasi cosa».
Imposta `"geminiSanitization": false` per disattivare questa funzionalità.

## Risoluzione dei problemi

| Sintomo                                                | Causa                                                                                                                                              |
| ------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| Il selettore non mostra alcun modello OmniRoute        | Nessuna chiave risolta (controllare l'avviso di avvio) oppure il gateway non è raggiungibile                                                       |
| ID modello grezzi, nessuna combinazione, nessun prezzo | Gli endpoint di gestione hanno rifiutato il token — set `managementReadToken`                                                                      |
| Catalogo `freeOnly` corto o vuoto                      | Nessun token di gestione o un token rifiutato — legge la riga di riepilogo dell'aggiornamento (conteggio `unmatched-free` ) nel registro dell'host |
| Una sessione fissata su `opencode-<id>/...`            | Il plugin v1 ha pubblicato `opencode-<id>`; v2 pubblica `<id>` bare, quindi riseleziona il modello sotto `<id>/...`                                |

Le variabili di ambiente devono raggiungere il processo del server opencode: quando l'host viene eseguito come servizio, la shell che esegue `opencode models` e l'ambiente del server sono diversi, quindi esporta la chiave dove il server la legge.
