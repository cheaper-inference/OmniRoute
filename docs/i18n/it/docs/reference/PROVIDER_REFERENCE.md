## Categorie

- **Gratuito** Livello gratuito — con chiave API (configurata tramite dashboard)
- **Nessuna autenticazione** — endpoint pubblici che non richiedono alcuna chiave o accesso
- **OAuth** Flusso di accesso — gestito da OmniRoute, non è necessaria alcuna chiave API
- **Biscotto Web** — avvolge l'app Web del provider tramite cookie auth
- **API** Fornitore a pagamento — configurato tramite chiave API (potrebbero essere applicati crediti gratuiti)
- **Locale** — viene eseguito sul computer dell'utente (Ollama, LM Studio, vLLM, ecc.)
- **Ricerca** — fornitori di ricerca web
- **Audio** — fornitori solo audio (TTS/STT)
- **Procura a monte** fornitori — che delegano ad altri fornitori
- **Agente cloud** — agenti di codifica a lunga esecuzione (Codex Cloud, Devin, Jules)
- **Sistema** — Provider interni a OmniRoute (loopback, ecc.)

Tag aggiuntivi: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (dove mostrato): `native` — chiamata di funzione reale API; `emulated` — l'array `tools` viene emulato al prompt tramite `webTools.ts` (blocchi `<tool>{...}</tool>` analizzati con regex); `none` — `tools` è attualmente eliminato in modo silenzioso. Vedi #7286.

Utilizza la dashboard di `/dashboard/providers` per abilitare, configurare e testare ciascun provider.
