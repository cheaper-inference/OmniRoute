`@omniroute/opencode-plugin-v2` pievieno visu jūsu OmniRoute katalogu — modeļus, kombinācijas un
automātiskās kombinācijas — OpenCode v2 modeļu atlasītājam, iekļaujot attēlojamos nosaukumus, cenas un bezmaksas līmeņa
limitus.

Tā ir atsevišķa pakotne no `@omniroute/opencode-plugin`, jo OpenCode v1 un v2 ielādē
spraudņus, izmantojot atšķirīgus līgumus. Izvēlieties savai OpenCode pamata versijai atbilstošo pakotni; starp
tām nekas netiek koplietots, tāpēc vienas jaunināšana nekad neietekmē otru.

## Prasības

- OpenCode v2.
- Sasniedzama OmniRoute vārteja (pēc noklusējuma `http://localhost:20128`).
- Node.js 22 vai 24.

## Instalēšana

Pievienojiet spraudni failam `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

Pēc tam modeļi tiek parādīti kā `omniroute/<provider>/<model>`; `providerId` nosaka šo prefiksu un
tās integrācijas identifikatoru, ar kuru OpenCode saglabā akreditācijas datus.

## Akreditācijas dati

Spraudnis meklē vārtejas atslēgu trīs vietās šādā secībā:

1. **Akreditācijas dati, kurus savienojāt pakalpojumā OpenCode.** Spraudnis reģistrē integrāciju, tāpēc
   OpenCode autentifikācijas plūsma var saglabāt atslēgu. Failā `opencode.json` nekas nenonāk — dodiet priekšroku šim variantam.
2. `apiKey` spraudņa opcijās katram projektam paredzētai aizstāšanai. Tādējādi atslēga tiek ievietota failā, kuru
   jūs, iespējams, pievienojat repozitorijam.
3. `OMNIROUTE_API_KEY` vidē.

Ja nav norādīts neviens no trim, katalogs ir tukšs, un spraudnis par to vienreiz paziņo palaišanas laikā, nevis
atstāj jūs ar klusi tukšu atlasītāju.

### Pārvaldības marķieris ir cita atslēga

Kombinācijas, nodrošinātāju darbspējas informācija un bagātināšana (attēlojamie nosaukumi, cenas, bezmaksas līmeņa limiti) tiek iegūta no
vārtejas `/api/*` galapunktiem, kurus vairums izvietojumu aizsargā ar **pārvaldības** marķieri,
nevis secinājumu veikšanas atslēgu:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<pārvaldības lasīšanas marķieris>"
}
```

Ja `managementReadToken` nav iestatīts, tas izmanto `apiKey`. Ja vārteja noraida šo rezerves variantu,
katalogs joprojām tiek publicēts, taču ar neapstrādātiem modeļu identifikatoriem attēlojamo nosaukumu vietā, bez kanonisko
aizstājvārdu dublikātu novēršanas, cenām un kombinācijām. Spraudnis vienreiz brīdina par katru galapunktu, kad tas notiek,
norādot galapunktu un zaudēto informāciju — tādēļ pasliktinātas funkcionalitātes atlasītājs nekad nav mīkla.

## Opcijas

| Atslēga                          | Noklusējums                                                 | Piezīmes                                                                                                                                                   |
| -------------------------------- | ----------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `providerId`                     | `"omniroute"`                                               | Pakalpojuma sniedzēja ID, integrācijas ID un prefikss, zem kura tiek rādīti modeļi                                                                         |
| `baseURL`                        | obligāts                                                    | Vārtejas saknes URL, tikai `http(s)`; sufikss `/v1` tiek pievienots, kur nepieciešams                                                                      |
| `apiKey`                         | pievienotie akreditācijas dati, pēc tam `OMNIROUTE_API_KEY` | Tērzēšanas atslēga ceļiem `/v1/*`                                                                                                                          |
| `managementReadToken`            | izmanto `apiKey`, ja nav norādīts                           | Atslēga ceļiem `/api/*` — parasti tā **nav** tā pati                                                                                                       |
| `displayName`                    | `"OmniRoute"`                                               | Pakalpojuma sniedzēja nosaukums izvēlnē                                                                                                                    |
| `timeoutMs`                      | `10000`                                                     | Katra galapunkta pieprasījuma noildze (automātiskajām kombinācijām tiek izmantotas 5 s)                                                                    |
| `modelCacheTtlMs`                | `300000`                                                    | Kataloga kešatmiņas TTL; diska momentuzņēmums paātrina auksto palaišanu                                                                                    |
| `timeouts`                       | izmanto `timeoutMs`, ja nav norādīts                        | Katra galapunkta laika ierobežojumi milisekundēs: `models`, `combos`, `autoCombos`, `enrichment`                                                           |
| `enrichment`                     | `true`                                                      | Iegūt nosaukumus, cenas un bezmaksas līmeņa limitus                                                                                                        |
| `providerTag`                    | `true`                                                      | Pievienot attēlojamā nosaukuma sākumā augšupstraumes pakalpojuma sniedzēju, uz kuru tas maršrutē                                                           |
| `usableOnly`                     | `false`                                                     | Paturēt tikai tos pakalpojuma sniedzējus, kurus vārteja norāda kā nodrošinātus                                                                             |
| `combosSource`                   | `"api"`                                                     | `"models"` izlaiž `/api/combos` un publicē `/v1/models` kombināciju rindas; dalībnieku līmeņa filtri saglabā `"api"`                                       |
| `showcasePerOwner`               | `10`                                                        | Noklusējuma skatā paturēto ierakstu skaits katram pakalpojuma sniedzējam                                                                                   |
| `freshPerOwner`                  | `10`                                                        | Noklusējuma skatā paturēto jauno ierakstu skaits katram pakalpojuma sniedzējam                                                                             |
| `freshWindowDays`                | `90`                                                        | Jaunuma laika periods dienās jauno ierakstu atzaram                                                                                                        |
| `usageMemory`                    | `true`                                                      | Atjaunot statiski atmestos ierakstus, kas minēti 30 dienu lietojuma analītikā (nepieciešams pārvaldības marķieris)                                         |
| `visibleModels` / `hiddenModels` | `[]`                                                        | Precīzas vai pēc sufiksa atbilstošas atļauto vērtību saraksti; aizliegums ir prioritārs; `*` publicē pilnu katalogu (pārējie filtri joprojām tiek lietoti) |
| `geminiSanitization`             | `true`                                                      | Noņemt JSON Schema atslēgvārdus, kurus Gemini noraida, no rīku shēmām (rīki ar `$ref` tiek pārsūtīti nemainīti)                                            |
| `apiFormat.allowAnthropic`       | `false`                                                     | Maršrutēt atļauto ID sarakstā iekļautos ID caur Anthropic API bloku                                                                                        |
| `apiFormat.anthropicModels`      | `[]`                                                        | Pilnie modeļu ID, kas tiek maršrutēti uz Anthropic                                                                                                         |
| `logLevel` / `startupDebug`      | `warn` / `false`                                            | Žurnāla detalizācijas līmenis                                                                                                                              |

Lietojuma atmiņa pēc noklusējuma ir ieslēgta. Bez pārvaldības marķiera tā paliek neaktīva
(palaišanas laikā žurnālā tiek ierakstīts paziņojums), un nekas netiek atjaunots.

## Kā katalogs saglabā aktualitāti

Katalogs tiek ielādēts tikai pēc vajadzības un kešots uz `modelCacheTtlMs`, savukārt diska momentuzņēmums nodrošina pēdējā zināmā kataloga pieejamību, kad vārteja nav sasniedzama — darbības pārtraukuma dēļ jūs zaudējat tikai aktualitāti. Modeļi un kombinācijas tiek publicēti, tiklīdz tie kļūst pieejami; automātiskās kombinācijas, nodrošinātāju saraksts un bagātināšanas pārklājums tiek iekļauti pēc to saņemšanas, tādēļ viens lēns galapunkts nevar aizkavēt visu modeļu atlasītāju.

Nosaukumos ir ietverta vārtejai zināmā informācija: augšupstraumes nodrošinātājs, pie kura tiek maršrutēts modelis, atzīme `[Free]` un tai piešķirtais budžets — tādējādi divi savienojumi, kas piedāvā vienu un to pašu modeli, joprojām ir atšķirami. Izslēdziet prefiksu ar `"providerTag": false`.

Manuālas atsvaidzināšanas komandas nav: OpenCode v2 komandas ir uzvedņu veidnes, nevis atzvanīšanas funkcijas, tādēļ spraudnis nevar šādu komandu nodrošināt. Atsvaidzināšana notiek atbilstoši TTL; resursdatoram tiek pieprasīta atkārtota ielāde tikai tad, kad katalogs vai pārklājums patiešām ir mainījies, nevis pēc katras atsvaidzināšanas.

## Rīku izsaukšana Gemini vidē

Gemini noraida visu pieprasījumu, ja tā rīku deklarācijās ir `$schema` vai
`additionalProperties`, atbildot ar `400 INVALID_ARGUMENT`. Spraudnis noņem šos atslēgvārdus no
rīku shēmām, kas paredzētas šī nodrošinātāja Gemini modelim, un visus pārējos pieprasījumus atstāj nemainītus.
Rīks, kas satur `$ref`, tiek pārsūtīts nemainīts, nevis attīrīts, jo atsauces noņemšana paplašinātu
shēmu līdz «pieņemt jebko».
Lai to izslēgtu, iestatiet `"geminiSanitization": false`.

## Problēmu novēršana

| Simptoms                                                     | Cēlonis                                                                                                                                    |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Atlasītājā nav redzams neviens OmniRoute modelis             | Nav atrasta neviena atslēga (pārbaudiet brīdinājumu startēšanas laikā), vai arī vārteja nav sasniedzama                                    |
| Neapstrādāti modeļu ID, nav kombināciju un cenu informācijas | Pārvaldības galapunkti noraidīja pilnvaru — iestatiet `managementReadToken`                                                                |
| Īss vai tukšs `freeOnly` katalogs                            | Nav pārvaldības pilnvaras vai tā ir noraidīta — resursdatora žurnālā skatiet atsvaidzināšanas kopsavilkuma rindu (`unmatched-free` skaitu) |
| Sesija ir piesaistīta `opencode-<id>/…`                      | v1 spraudnis publicēja `opencode-<id>`; v2 publicē tikai `<id>`, tāpēc atkārtoti atlasiet modeli sadaļā `<id>/…`                           |

Vides mainīgajiem ir jāsasniedz opencode servera process: ja resursdators
darbojas kā pakalpojums, čaulas, kurā tiek izpildīta komanda `opencode models`,
un servera vides atšķiras, tāpēc eksportējiet atslēgu tur, kur serveris to nolasa.
