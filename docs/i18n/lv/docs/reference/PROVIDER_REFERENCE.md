## Kategorijas

- **Bezmaksas** — bezmaksas līmenis ar API atslēgu (konfigurējams informācijas panelī)
- **Bez autentifikācijas** — publiski galapunkti, kuriem vispār nav nepieciešama atslēga vai pierakstīšanās
- **OAuth** — pierakstīšanās plūsmu apstrādā OmniRoute, API atslēga nav nepieciešama
- **Tīmekļa sīkdatne** — nodrošina piekļuvi pakalpojumu sniedzēja tīmekļa lietotnei, izmantojot autentifikācijas sīkdatni
- **API atslēga** — maksas pakalpojumu sniedzējs, kas konfigurējams ar API atslēgu (var būt pieejami bezmaksas kredīti)
- **Lokāls** — darbojas lietotāja datorā (Ollama, LM Studio, vLLM u.c.)
- **Meklēšana** — tīmekļa meklēšanas pakalpojumu sniedzēji
- **Audio** — tikai audio pakalpojumu sniedzēji (TTS/STT)
- **Augšupstraumes starpniekserveris** — pakalpojumu sniedzēji, kas pārsūta pieprasījumus citiem pakalpojumu sniedzējiem
- **Mākoņa aģents** — ilgstoši darbojošies programmēšanas aģenti (Codex Cloud, Devin, Jules)
- **Sistēma** — OmniRoute iekšējie pakalpojumu sniedzēji (atgriezeniskā cilpa u.c.)

Papildu tagi: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Rīku izsaukšana` (ja norādīta): `native` — īsta funkciju izsaukšanas API; `emulated` — `tools` masīvs tiek emulēts uzvednē, izmantojot `webTools.ts` (ar regulāro izteiksmju palīdzību parsēti `<tool>{...}</tool>` bloki); `none` — `tools` pašlaik tiek nemanāmi atmests. Skatiet #7286.

Izmantojiet informācijas paneli adresē `/dashboard/providers`, lai iespējotu, konfigurētu un testētu katru pakalpojumu sniedzēju.
