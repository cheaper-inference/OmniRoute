> **Patiesības avots:** `src/lib/obsidian/api.ts` (REST + sinhronizācijas klients),
> `src/lib/db/obsidian.ts` (pilnvaras / bāzes URL / WebDAV pastāvīgā glabāšana),
> `src/lib/obsidianSync.ts` (WebDAV krātuves sinhronizācija), `open-sse/mcp-server/tools/obsidianTools.ts`
> (22 MCP rīki), `src/app/api/settings/obsidian/route.ts` +
> `src/app/api/settings/obsidian/webdav/route.ts` (iestatījumu API). Rīku reģistrācija
> un tvērumu sasaiste atrodas `open-sse/mcp-server/server.ts`.

## Kas tas ir

OmniRoute izveido savienojumu ar **Obsidian** krātuvi kā **konteksta avotu** — lokālu Markdown
zināšanu bāzi, kuru aģenti lasa un raksta, izmantojot iebūvēto MCP serveri. Integrācija
sazinās ar kopienas spraudni **Obsidian Local REST API**, kas darbojas darbvirsmas
lietotnē, tādēļ aģenti var meklēt piezīmes, lasīt/rakstīt/labot failus, uzskaitīt krātuves
saturu, strādāt ar dienas/nedēļas periodiskajām piezīmēm, pārvaldīt tagus, izpildīt
Obsidian komandas un (pēc izvēles) koordinēt divvirzienu darbvirsmas↔mobilās ierīces
krātuves sinhronizāciju.

Klients (`src/lib/obsidian/api.ts`) ietver Local REST API ar:

- **Atkārtotiem mēģinājumiem ar pieaugošu aizkavi** pārejošām `5xx` kļūdām un **30 sekunžu taimautu**, izmantojot `AbortController`.
- **Tipizētu kļūdu klasifikāciju** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`.
- **Saprotamu norādi “nevar sasniegt Obsidian”**, kas izceļ bieži sastopamo porta kļūdu
  (HTTP portā `27123`, **nevis** MCP galapunktā portā `27124`) un Tailscale formātu.
- Krātuvei relatīvu **ceļu kodēšanu**, lai piezīmju ceļus ar atstarpēm/slīpsvītrām varētu droši izmantot.

## Iestatīšana

Obsidian pilnvarai vai bāzes URL **nav vides mainīgā** — abi tiek
glabāti SQLite tabulā `key_value` (nosaukumvietā `obsidian`), izmantojot
`src/lib/db/obsidian.ts`. Pilnvara glabāšanas laikā ir **šifrēta** (AES-256-GCM ar
atpakaļsaderības atkāpšanos uz vienkāršu tekstu). Konfigurējiet Endpoint informācijas paneļa
cilnē **Konteksta avoti** (`ObsidianSourceCard`) vai izmantojot iestatījumu REST API.

> [!IMPORTANT]
> Spraudnim **Obsidian Local REST API** jābūt instalētam un palaistam. Tā REST
> saskarne klausās adresē **HTTP `127.0.0.1:27123`** (noklusējuma bāzes URL). Ports `27124`
> ir _atsevišķs_ MCP/HTTPS galapunkts, un iestatījumu maršruts to nepārprotami noraida.
> Ja veidojat savienojumu no citas ierīces, izmantojiet `http://<tailscale-ip>:27123`.

### Konfigurācijas atslēgas (SQLite `key_value`, nosaukumvieta `obsidian`)

| Atslēga           | Nolūks                                                       | Šifrēts |
| ----------------- | ------------------------------------------------------------ | ------- |
| `api_key`         | Local REST API nesēja pilnvara                               | jā      |
| `base_url`        | REST bāzes URL (noklusējums `http://127.0.0.1:27123`)        | nē      |
| `vault_path`      | Absolūtais ceļš uz glabātuves direktoriju (sinhronizācijai)  | nē      |
| `webdav_username` | Ģenerētais WebDAV lietotājvārds (glabātuves sinhronizācijai) | nē      |
| `webdav_password` | Ģenerētā WebDAV parole (glabātuves sinhronizācijai)          | jā      |
| `webdav_enabled`  | Vai WebDAV glabātuves sinhronizācija ir iespējota            | nē      |

### Konfigurēšana, izmantojot REST

```bash
# Saglabā un validē Local REST API pilnvaru (POST validē, veicot statusa pārbaudi)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# Pārbauda savienojuma statusu (atgriež connected, hasToken, baseUrl, vaultPath)
curl http://localhost:20128/api/settings/obsidian

# Atvieno (notīra saglabāto pilnvaru)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

Visām metodēm nepieciešama informācijas paneļa autentifikācija. `POST` noraida jebkuru URL ar portu `27124`
un pirms saglabāšanas validē pilnvaru, izsaucot Local REST API statusa galapunktu.

### WebDAV glabātuves sinhronizācija

`src/app/api/settings/obsidian/webdav/route.ts` pārvalda neobligātu, uz WebDAV balstītu
glabātuves sinhronizāciju (ko darbina `src/lib/obsidianSync.ts`). To iespējojot, OmniRoute tiek norādīts
lokāls glabātuves direktorijs un tiek ģenerēts nejaušs WebDAV lietotājvārda/paroles pāris:

```bash
# Iespējo WebDAV sinhronizāciju glabātuves direktorijam (ģenerē lietotājvārdu/paroli)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# Iegūst WebDAV sinhronizācijas statusu (akreditācijas dati tiek atgriezti tikai tad, kad tā ir iespējota)
curl http://localhost:20128/api/settings/obsidian/webdav

# Atspējo WebDAV sinhronizāciju (notīra akreditācijas datus un pārvaldīto .stignore)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### Drošība un transports

WebDAV autentifikācija nodrošina katra IP kļūmju izsekošanu un bloķēšanu (10 neveiksmīgi mēģinājumi 60 sekunžu logā aktivizē 5 minūšu bloķēšanu ar `429 Too Many Requests` un `Retry-After`). Tā kā WebDAV pārsūta pamata autentifikācijas akreditācijas datus, ir ļoti ieteicams pārtraukt TLS (vai maršrutēšanu pa drošu tuneli, piemēram, Tailscale vai Cloudflare Tunnel), piekļūstot WebDAV galapunktam ārpus atpakaļcilpas.

### Katras API atslēgas konteksta avots (neobligāts)

Obsidian konfigurācijas tvērumu var noteikt **katrai API atslēgai** atsevišķi, izmantojot tabulu `api_key_context_sources`
(`src/lib/db/apiKeyContextSources.ts`). Kad MCP izsaukums ietver autentificētu API
atslēgas ID, `getObsidianConfigForApiKey()` dod priekšroku šīs atslēgas pilnvarai/bāzes URL/glabātuves ceļam
(`source: "api_key"`), bet pretējā gadījumā izmanto globālo konfigurāciju (`source: "global"`).

MCP rīkiem, kas nav paredzēti sinhronizācijai, pirms šīs konfigurācijas nolasīšanas ir nepieciešama noskaidrota izsaucēja identitāte.
Izsaucējs bez identitātes saņem `Obsidian API token not configured`, un neviens glabātuves
pieprasījums netiek nosūtīts. HTTP izsaucēju identitāte tiek noskaidrota, izmantojot to pieprasījuma akreditācijas datus; stdio izsaucēju
identitāti var noskaidrot, izmantojot `OMNIROUTE_API_KEY` vai `ROUTER_API_KEY`. Neatpazīts HTTP izsaucējs
nevar mantot servera vides identitāti. Ar viettura ID vien nepietiek, lai autorizētu
piekļuvi; joprojām tiek atbalstīti derīgi vides akreditācijas dati, kas tiek sasaistīti ar `env-key`.
Autentificētām atslēgām bez katrai atslēgai specifiskas Obsidian konfigurācijas tiek saglabāta atkāpšanās uz globālo konfigurāciju.
Četri `obsidian_sync_*` rīki saglabā savu atsevišķo sinhronizācijas pilnvaru darbību.

## MCP instrumenti (22)

Definēts `open-sse/mcp-server/tools/obsidianTools.ts`. token/base-URL tiek atrisināti katram zvanam (vispirms katrai API atslēgai, pēc tam globālajai). Rīki, kas sasniedz OmniRoute** sinhronizācijas serveris** (četriem `obsidian_sync_*` rīkiem) papildus ir nepieciešama sinhronizācijas autentifikācijas pilnvara, kas konfigurēta OmniRoute iestatījumos.

### Lasīšanas rīki (`read:obsidian`)

| Rīks                         | Apraksts                                                                                                                   |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `obsidian_check_status`      | Pārbaudiet, vai vietējais REST API ir sasniedzams un autentificēts.                                                        |
| `obsidian_search_simple`     | Piezīmju satura pilna teksta meklēšana; atgriež fragmentus ar faila ceļiem.                                                |
| `obsidian_search_structured` | Meklējiet, izmantojot JSON Logic izteiksmi (and/or/regex/path filtri).                                                     |
| `obsidian_read_note`         | Izlasiet piezīmi pēc velves relatīvā ceļa; pēc izvēles konkrētu heading/block/frontmatter.                                 |
| `obsidian_list_vault`        | Saraksta failus un direktorijus glabātavā (ierakstu koks).                                                                 |
| `obsidian_get_document_map`  | Iegūstiet piezīmes virsrakstu struktūru kā virsrakstu → līniju numuru karti.                                               |
| `obsidian_get_note_metadata` | Iegūstiet frontmatter, atzīmes, saites, char/word skaitu bez visa satura.                                                  |
| `obsidian_get_active_file`   | Iegūstiet pašlaik aktīvā faila ceļu + saturu programmā Obsidian.                                                           |
| `obsidian_get_periodic_note` | Saņemiet daily/weekly/monthly periodisko piezīmi datumam (šodien, ja tas ir izlaists).                                     |
| `obsidian_get_tags`          | Uzskaitiet visus glabātuves tagus ar to frekvencēm.                                                                        |
| `obsidian_list_commands`     | Norādiet pieejamo Obsidian komandu IDs (izmantojiet kopā ar `obsidian_execute_command`).                                   |
| `obsidian_sync_status`       | OmniRoute sinhronizācijas servera statuss: darbojas, glabātuves nosaukums, ports, darbspējas laiks, pēdējā sinhronizācija. |
| `obsidian_sync_conflicts`    | Norādiet neatrisinātos sinhronizācijas konfliktus (ceļš, konflikta ceļš, konstatēts-at).                                   |

### Rakstīšanas rīki (`write:obsidian`)

| Rīks                             | Apraksts                                                                                                            |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `obsidian_write_note`            | Izveidojiet vai pārrakstiet piezīmi ar norādīto Markdown saturu.                                                    |
| `obsidian_append_note`           | Pievienot piezīmei saturu; pēc izvēles uz konkrētu heading/block.                                                   |
| `obsidian_patch_note`            | Ķirurģiski append/prepend/replace virziena, bloka vai frontmatter laukā.                                            |
| `obsidian_delete_note`           | Neatgriezeniski dzēst piezīmi no glabātuves.                                                                        |
| `obsidian_move_note`             | Pārvietojiet vai pārdēvējiet piezīmi glabātuvē.                                                                     |
| `obsidian_execute_command`       | Izpildiet Obsidian komandu ar tās komandu ID.                                                                       |
| `obsidian_open_file`             | Atveriet failu programmā Obsidian (izveido to, ja tas neeksistē).                                                   |
| `obsidian_sync_trigger`          | Aktivizējiet tūlītēju divvirzienu darbvirsmas ↔ mobilās glabātuves sinhronizāciju.                                  |
| `obsidian_sync_resolve_conflict` | Atrisiniet sinhronizācijas konfliktu: saglabājiet `local` (mobilajā ierīcē), `remote` (galddatorā) vai `keep-both`. |

> [!NOTE]
> `obsidian_patch_note` mērķi pieņem `targetType` no `heading | block | frontmatter` un `operation` no `append | prepend | replace` ar izvēles `createTargetIfMissing`. Četri `obsidian_sync_*` rīki sazinās ar vietējo sinhronizācijas serveri (pēc noklusējuma `http://127.0.0.1:27781` ) un pieprasa sinhronizācijas pilnvaru.

### Darbības jomas

Lasīšanas rīkiem ir nepieciešams `read:obsidian`; rakstīšanas rīkiem ir nepieciešams `write:obsidian`. Izpilde ir identiska Notion — ko apstrādā `withScopeEnforcement()` `open-sse/mcp-server/server.ts`, ar `OMNIROUTE_MCP_ENFORCE_SCOPES=true` vārtiem un piespiedu kārtā HTTP/SSE zvanītājiem, kuru API atslēgai nav `manage`/`admin`, ar atļautajiem tvērumiem, kas iegūti no `OMNIROUTE_MCP_SCOPES` vai API atslēgas tvēruma konteksta. Skatiet [MCP-SERVER.md](./MCP-SERVER.md).

## Galapunkti

| Metode   | Ceļš                            | Mērķis                                                                  |
| -------- | ------------------------------- | ----------------------------------------------------------------------- |
| `GET`    | `/api/settings/obsidian`        | Atgriež `{ connected, hasToken, baseUrl, vaultPath }`.                  |
| `POST`   | `/api/settings/obsidian`        | Saglabā un pārbauda pilnvaru (noraida portu `27124`).                   |
| `DELETE` | `/api/settings/obsidian`        | Atvieno (notīra saglabāto pilnvaru).                                    |
| `GET`    | `/api/settings/obsidian/webdav` | WebDAV sinhronizācijas statuss un akreditācijas dati (kamēr iespējota). |
| `POST`   | `/api/settings/obsidian/webdav` | Iespējo WebDAV sinhronizāciju glabātuves direktorijam.                  |
| `DELETE` | `/api/settings/obsidian/webdav` | Atspējo WebDAV sinhronizāciju.                                          |

> Šie ir informācijas paneļa iestatījumu maršruti. Pašai glabātuvei var piekļūt, izmantojot Obsidian
> Local REST API (konfigurēto `base_url`) un iepriekš minētos MCP rīkus — publiska
> Obsidian `/v1` starpniekservera galapunkta nav.

## Lietošanas gadījumi

- **Atbildes, kas balstītas glabātuvē** — `obsidian_search_simple` / `obsidian_search_structured`,
  pēc tam `obsidian_read_note`, lai aģents atbildētu, izmantojot jūsu faktiskās piezīmes.
- **Piezīmju veidošana / dienasgrāmatas rakstīšana** — `obsidian_write_note`, `obsidian_append_note` vai
  precīzais `obsidian_patch_note`, lai glabātuvē ierakstītu aģenta izvadi, kopsavilkumus vai dienas piezīmes
  (`obsidian_get_periodic_note`).
- **Glabātuves navigācija** — `obsidian_list_vault`, `obsidian_get_document_map` un
  `obsidian_get_tags`, lai pirms lasīšanas/rakstīšanas izpētītu struktūru.
- **Obsidian automatizācija** — `obsidian_list_commands` + `obsidian_execute_command`, lai
  aģents varētu darbināt spraudņus/komandas; `obsidian_open_file`, lai lietotāja saskarnē parādītu piezīmi.
- **Mobilā sinhronizācija** — iespējojiet WebDAV sinhronizāciju, pēc tam izmantojiet `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`,
  lai koordinētu sinhronizāciju starp datoru un mobilo ierīci un atrisinātu konfliktus.
