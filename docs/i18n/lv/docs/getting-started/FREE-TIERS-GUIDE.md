> **TL;DR** : ņemiet līdzi savus piemērotos pakalpojumu sniedzēja kontus. OmniRoute apvieno jūsu konfigurētos savienojumus; tas neizdod reklamēto kopējo marķiera budžetu. Bezmaksas piekļuvei var būt nepieciešama reģistrēšanās, API atslēga, apstiprinājums vai maksājuma veids. Joprojām ir spēkā pakalpojumu sniedzēju ierobežojumi, konfidencialitātes politikas un noteikumi.

---

## Kas ir bezmaksas līmeņi?

Daudzi AI pakalpojumu sniedzēji piedāvā sava veida** bezmaksas pieeja** . Atkarībā no pakalpojumu sniedzēja tas var nozīmēt galapunktu bez autorizācijas, atkārtotu kvotu, ātruma ierobežotu neierobežotu piekļuvi, reģistrēšanās atļauju, manuālu apstiprinājumu vai pagaidu paaugstināšanu. Dažām opcijām ir nepieciešams konts, API atslēga, kredītkarte, KYC vai pakalpojumu sniedzēja īpašu noteikumu pieņemšana.

OmniRoute** agregāti** konfigurēti savienojumi vienā gala punktā. Jūs joprojām reģistrējaties atsevišķi katram pakalpojumu sniedzējam, kuram nepieciešams konts. Savienojiet šos kontus un izmantojiet `model: "auto"`, lai maršrutētu starp piemērotiem mērķiem. Jaunai instalācijai nevar būt piemērota bezatslēgas mērķa; OmniRoute instalēšana vien negarantē veiksmīgu tērzēšanas atbildi.

## Kā sakraut bezmaksas līmeņus

OmniRoute burvība ir** bezmaksas līmeņu sakraušana** . Tā vietā, lai paļautos uz vienu pakalpojumu sniedzēju, jūs savienojat vairākus bezmaksas pakalpojumu sniedzējus un ļaujat OmniRoute automātiski izvēlēties labāko katram pieprasījumam.

### Piemērs: plašāks bezmaksas līmeņa pārklājums

Savienojiet vairākus pakalpojumu sniedzējus, lai samazinātu atkarību no vienas kvotas:

1. **Gemini** — periodiskā API atslēgas kvota
2. **Groq** — periodiskā API atslēgas kvota
3. **Apputeksnēšana** — bezatslēgas, ierobežota piekļuve
4. **LongCat** — vienreizēja pierakstīšanās dotācija (nepieciešams KYC)

Pēc tam izmantojiet `model: "auto"` un OmniRoute :

- Vispirms izmēģiniet augstākā ranga piemēroto savienojumu
- Ja tā kvota vai veselības pārbaude neizdodas, → izmēģiniet nākamo konfigurēto pakalpojumu sniedzēju
- Ja bezatslēgas pakalpojumu sniedzējs nav pieejams, → turpiniet apskatīt atlikušos mērķus
- Ja neviens piemērots savienojums neizdodas → atgriezt kļūdu; reģistrēšanās kredīti ir izmantojami tikai tad, kad tie ir derīgi un pieejami

**Rezultāts** : plašāks brīvā līmeņa pārklājums ar automātisku rezerves — negarantē neierobežotu jaudu.

## Kā savienot bezmaksas pakalpojumu sniedzējus

### 1. darbība. Atveriet informācijas paneli

Pārlūkprogrammā atveriet vietni `http://localhost:20128`.

### 2. darbība. Dodieties uz sadaļu Providers

Noklikšķiniet** Pakalpojumu sniedzēji** sānjoslā.

### 3. darbība: noklikšķiniet uz Pievienot nodrošinātāju

Noklikšķiniet uz**+ Pievienot nodrošinātāju** pogu.

### 4. darbība: atlasiet bezmaksas pakalpojumu sniedzēju

Pārlūkojiet katalogu un pārbaudiet katra pakalpojumu sniedzēja pašreizējos `hasFree`, autentifikācijas, kvotas, konfidencialitātes un ToS metadatus. Pakalpojumu sniedzēja karte un [bezmaksas līmeņu atsauce](../reference/FREE_TIERS.md) atšķir periodiskus kopumus, uncapped/keyless piekļuvi, reģistrēšanās kredītus, pārtrauktos ierakstus un augstāka riska avotus.

### 5. darbība. Noklikšķiniet uz Savienot

`NOAUTH` nodrošinātājam OmniRoute nepieprasa augšpuses akreditācijas datus. Tas negarantē, ka augšpuse pieņem trešo pušu klientus vai tai ir pieejama jauda. OAuth un API atslēgas nodrošinātājiem ir jābūt savienotiem, izmantojot to dokumentēto konta plūsmu. Jūsu klients joprojām izmanto OmniRoute API atslēgu, kas izveidota** Informācijas paneļa → API taustiņi** (tiek rādīts tikai vienu reizi, izveidojot), ja ir iespējota maršrutētāja autentifikācija.

### 6. darbība: atkārtojiet

Savienojiet vairākus pakalpojumu sniedzējus, kuru noteikumi un konfidencialitātes modelis atbilst jūsu lietošanas gadījumam.

## No dsh "Mūsu bezmaksas modelis"

[dsh-our-free-model](https://github.com/Ebony-Vinyl/dsh-our-free-model) spraudnis dsh aģenta saimniekdatoram sasniedz divus augšupvērstus. OmniRoute katram jau ir nodrošinātājs, taču tikai viens no tiem ir brīvs ceļš OmniRoute:

| Spraudņa josla | Augštecē                                    | OmniRoute nodrošinātājs     | Bezmaksas OmniRoute? | Kā izveidot savienojumu                                                                |
| -------------- | ------------------------------------------- | --------------------------- | -------------------- | -------------------------------------------------------------------------------------- |
| Kilo kanāls    | Kilo AI vārteja (`api.kilo.ai/api/gateway`) | `kilo-gateway` (alias `kg`) | Jā                   | API atslēga nav obligāta: atstājiet to tukšu, lai izmantotu vārtejas bezmaksas baseinu |
| Brīva josla    | OpenCode Zen (`opencode.ai`)                | `opencode-zen`              | Nē                   | Jūsu OpenCode API atslēga no [opencode.ai/zen](https://opencode.ai/zen)                |

**Kilo.** Nosauciet bezmaksas kopu kā `kilo-gateway/<model>` vai `kg/<model>`, piemēram, `kg/kilo-auto/free` (Kilo bezmaksas automātiskais maršrutētājs) vai kādu no vārtejas `:free` modeļiem. Brīvais komplekts griežas; `kilo-gateway` iziet cauri modeļu ID, kas nav iekļauti OmniRoute iebūvētajā sarakstā, tāpēc modeli, kas šodien ir vārtejas sarakstos, var izsaukt, pirms tas ir iekļauts katalogā. Kilo bezmaksas modeļu kartēs teikts, ka iepriekšējais pakalpojumu sniedzējs var reģistrēt uzvednes un izmantot tās pakalpojumu uzlabošanai, tāpēc nesūtiet sensitīvus datus.

**OpenCode.** Spraudņa bezmaksas josla ir OpenCode piedāvājums bez atslēgas. OmniRoute nenodrošina šo piedāvājumu kā bezmaksas piekļuvi:

- OmniRoute bezatslēgas OpenCode nodrošinātājs tika noņemts pēc OpenCode operatora pieprasījuma (skatiet [Noņemtie pakalpojumu sniedzēji](../reference/REMOVED_PROVIDERS.md) ).
- OpenCode[galapunkta dokumentācija](https://opencode.ai/v2/docs/console/models/#endpoints) saista savus bezmaksas tērzēšanas piedāvājumus ar paša OpenCode klientu, tāpēc OmniRoute tos neuzskaita un neapzīmē kā bezmaksas.

Modeļu ID, ko parāda spraudnis, piemēram `deepseek-v4.1-flash-free`, `mimo-v2.6-flash-free` un `nemotron-3.5-lightning-free`, ir `opencode-zen` katalogā. Savienojiet `opencode-zen` ar savu OpenCode atslēgu, lai tos izmantotu saskaņā ar sava OpenCode konta noteikumiem.

**Spraudņa vietējais ports.** Spraudnis var parādīt savus modeļus vietējā ar OpenAI saderīgā portā (noklusējuma `18899`). Jebkuru šādu galapunktu var pievienot kā [pielāgotu ar OpenAI saderīgu nodrošinātāju](../guides/USER_GUIDE.md#custom-openai-compatible-providers), taču OmniRoute neinstalē, nesāk un neatjaunina spraudni, un spraudnis izlemj, kurš augšējais punkts apkalpo katru pieprasījumu. Iepriekš minētie OpenCode ierobežojumi attiecas uz OpenCode piedāvājumu neatkarīgi no tā, kurš klients nosūta pieprasījumu.

## Pareiza kataloga lasīšana

- `NOAUTH` nozīmē, ka OmniRoute neprasa nodrošinātāja akreditācijas datus; tas negarantē darbības laiku, privātumu vai neierobežotu jaudu.
- `hasFree` ir atklāšanas metadati. Tā var būt atkārtota kvota, bezatslēgas piekļuve, reģistrēšanās kredīts, apstiprināšanas programma vai veicināšana.
- `recurring-uncapped` nozīmē, ka nebija pieejami publicēti marķiera griesti; likmes un vienlaicīguma ierobežojumi joprojām ir spēkā.
- `one-time-initial` neatkārtojas pēc reģistrēšanās dotācijas iztērēšanas.
- `tos: avoid` nodrošinātāji pēc noklusējuma ir izslēgti no automātiskās maršrutēšanas (`excludeTosAvoid`). Savienojot kontu, šis filtrs netiek apiets. Jebkura operatora ignorēšana jāveic pēc pakalpojumu sniedzēja noteikumu un konta riska pārskatīšanas.
- Ieraksti, kas apzīmēti ar atzīmi `discontinued` paliek vēsturiski pierādījumi, un tos nedrīkst uzrādīt kā pašlaik bezmaksas.

## Kā OmniRoute uzlabo bezmaksas līmeņus

### 1. Automātiska atkāpšanās

Ja viens bezmaksas pakalpojumu sniedzējs ir aizņemts vai nedarbojas, OmniRoute automātiski izmēģina nākamo. Jums nekas nav jādara.

### 2. Viedā maršrutēšana

OmniRoute izvēlas** labākais bezmaksas pakalpojumu sniedzējs** katram pieprasījumam, pamatojoties uz:

- Ātrums — Kurš pakalpojumu sniedzējs šobrīd ir ātrākais?
- Kvalitāte — Kurš pakalpojumu sniedzējs ir vislabākais šim uzdevumam?
- Jauda — Kuram pakalpojumu sniedzējam ir atlikuša kvota?

### 3. Žetonu ietaupījumi

OmniRoute saspiešanas cauruļvads var samazināt piemērotos uzvednes un rīku izvades marķierus. Faktiskie ietaupījumi ir atkarīgi no satura, atlasītajiem dzinējiem, pakalpojumu sniedzēja uzskaites un uzticamības iestatījumiem; saspiešana nereizina katru pakalpojumu sniedzēja kvotu ar noteiktu summu.

### 4. Vairāku kontu atbalsts

Ja pakalpojumu sniedzēja noteikumi atļauj vairākus kontus vai akreditācijas datus, OmniRoute var uzskatīt katru savienojumu kā atsevišķu maršrutēšanas kandidātu. Neveidojiet papildu kontus, lai izvairītos no pakalpojumu sniedzēja kvotas vai piekļuves politikas.

Tie ir kataloga mēroga aprēķini atsevišķos piemērotos kontos, nevis OmniRoute nodrošinātā kvota vai jaunas instalācijas prognozes. Jūsu izmantojamā jauda ir atkarīga no pakalpojumu sniedzējiem, ar kuriem izveidojat savienojumu, un to pašreizējiem nosacījumiem. Vērtības tiek aprēķinātas no `open-sse/config/freeModelCatalog.ts`; skatiet [bezmaksas līmeņu atsauci,](../reference/FREE_TIERS.md) lai uzzinātu par pūla dedublikāciju, ToS karodziņiem, pārtrauktajiem ierakstiem un pierakstīšanās kredīta metodiku.

## Bieži uzdotie jautājumi

### "Vai tas tiešām ir bez maksas?"

Katalogā ir ierakstīti pakalpojumu sniedzēja publicētie termini un projektu izpēte, taču piedāvājumi var mainīties. Pirms lietošanas pārbaudiet pakalpojumu sniedzēja pašreizējo cenu, kvotu, konfidencialitātes politiku un piemērotību.

### "Vai brīvais līmenis beigsies?"

Katrs pakalpojumu sniedzējs var ierobežot tarifu, mainīt modeļus, apturēt piekļuvi vai doties bezsaistē. Vairāki savienojumi uzlabo rezerves pārklājumu, taču negarantē pieejamu bezmaksas maršrutu.

### "Vai ražošanai var izmantot bezmaksas pakalpojumu sniedzējus?"

Tikai tad, ja pakalpojumu sniedzēja SLA, datu apstrāde, ierobežojumi un noteikumi atbilst jūsu ražošanas prasībām. Kritiskajām darba slodzēm jābūt uzraudzītām, līgumā paredzētajām atkāpšanās iespējām.

### "Kas ir loms?"

Kompromisi var ietvert stingrus ierobežojumus, gaidīšanas sarakstus, KYC, kredītkartes verifikāciju, apmācību par uzvednēm, vājāku privātumu, bez SLA, modeļa atteikšanos, ģeogrāfiskos ierobežojumus, apmaksātu pārsniegumu vai konta politikas risku. OmniRoute atklāj pieejamos metadatus; jūs izvēlaties, ko iespējot.

### "Kā es varu iegūt vairāk bezmaksas kvotu?"

1. Pievienojiet vairāk bezmaksas pakalpojumu sniedzēju
2. Iespējojiet atbilstošus kompresijas dzinējus un izmēriet ietaupījumus jūsu darba slodzei
3. Izmantojiet `auto/cheap`, lai piešķirtu prioritāti free/cheap pakalpojumu sniedzējiem
4. Pievienojiet papildu atļautos pakalpojumu sniedzējus vai akreditācijas datus, nepārkāpjot pakalpojumu sniedzēja noteikumus

### "Vai bezmaksas pakalpojumu sniedzējiem ir sliktāka kvalitāte?"

Nav obligāti. Daži pakalpojumu sniedzēji piedāvā vienas un tās pašas modeļu saimes, kas pieejamas maksas maršrutos, taču ierobežojumi, latentums, privātums, uzticamība un modeļu versijas var atšķirties. Izmantojiet lapu Bezmaksas pakalpojumu sniedzēju klasifikācija kā kvalitātes signālu un pārbaudiet faktisko piedāvāto modeli.
