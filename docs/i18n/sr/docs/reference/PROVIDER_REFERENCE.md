## Категорије

- **Бесплатно** — бесплатни ниво са API кључем (подешава се преко контролне табле)
- **Без аутентификације** — јавне крајње тачке које уопште не захтевају кључ нити пријављивање
- **OAuth** — ток пријављивања којим управља OmniRoute, без потребе за API кључем
- **Веб-колачић** — омотава веб-апликацију добављача користећи аутентификацију путем колачића
- **API кључ** — плаћени добављач који се подешава путем API кључа (могу бити доступни бесплатни кредити)
- **Локално** — покреће се на корисниковом рачунару (Ollama, LM Studio, vLLM итд.)
- **Претрага** — добављачи веб-претраге
- **Аудио** — добављачи искључиво за аудио (TTS/STT)
- **Посреднички прокси** — добављачи који прослеђују захтеве другим добављачима
- **Агент у облаку** — дуготрајни агенти за програмирање (Codex Cloud, Devin, Jules)
- **Систем** — интерни добављачи система OmniRoute (loopback итд.)

Додатне ознаке: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (Позивање алата) (када је приказано): `native` — стварни API за позивање функција; `emulated` — низ `tools` се емулира у упиту путем `webTools.ts` (блокови `<tool>{...}</tool>` се рашчлањују регуларним изразима); `none` — `tools` се тренутно прећутно одбацује. Погледајте #7286.

Користите контролну таблу на `/dashboard/providers` да бисте омогућили, подесили и тестирали сваког добављача.
