## Категорије

- **Бесплатно** — бесплатни ниво са API кључем (конфигурисан преко контролне табле)
- **Но-аутх** — јавне крајње тачке које уопште не захтевају кључ или пријаву
- **OAuth** — ток пријаве којим управља OmniRoute, није потребан API кључ
- **Веб колачић** — обмотава веб апликацију провајдера путем аутентификације колачића
- **API кеи** — плаћени провајдер конфигурисан преко API кључа (могу се применити бесплатни кредити)
- **Локални** — ради на машини корисника (Ollama, LM Студио, vLLM, итд.)
- **Тражи** — провајдери веб претраге
- **Аудио** — провајдери само за аудио (TTS/STT)
- **Упстреам проки** — провајдери који проки другим провајдерима
- **Цлоуд агент** — агенти за дуготрајно кодирање (Codex Цлоуд, Devin, Jules)
- **Систем** — ОмниРоуте-интерни провајдери (лоопбацк, итд.)

Додатне ознаке: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (где је приказано): `native` — реално позивање функција API; `emulated` — `tools` низ је промпт-емулиран преко `webTools.ts` ( `<tool>{...}</tool>` блокови рашчлањени регуларним изразом); `none` — `tools` је тренутно тихо испуштен. Види #7286.

Користите контролну таблу на `/dashboard/providers` да бисте омогућили, конфигурисали и тестирали сваког провајдера.
