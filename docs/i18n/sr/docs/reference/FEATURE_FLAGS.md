> Прекидачи током извршавања који мењају понашање OmniRoute-а **без поновног постављања**.
> Свака овде наведена заставица дефинисана је у
> [`src/shared/constants/featureFlagDefinitions.ts`](../../src/shared/constants/featureFlagDefinitions.ts)
> — једином извору истине. Контролна табла и REST API читају из
> те датотеке, тако да је табела испод генерисана тако да јој одговара 1:1.

---

## Шта су заставице функција

Заставица функције је именовани прекидач (логичка вредност или набрајање) чија се вредност може мењати током
извршавања и трајно чувати у бази података, без потребе за поновним постављањем процеса. Свака
заставица је описана помоћу `FeatureFlagDefinition` са пољима `key`, `label`,
`description`, `category`, `defaultValue`, `type` и назнаком `requiresRestart`.

### Редослед разрешавања

**Ефективну вредност** заставице разрешава
[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) према следећем
редоследу приоритета (највиши има предност):

1. **Замена из базе података** — вредност сачувана у табели `key_value` у оквиру именског простора
   `feature_flags` (подешена преко контролне табле или REST API-ја).
2. **Променљива окружења** — `process.env[<KEY>]`, ако је постављена и није празна.
3. **Подразумевана вредност дефиниције** — `defaultValue` из `featureFlagDefinitions.ts`.

Логичка заставица се сматра **омогућеном** када је њена ефективна вредност `"true"`,
`"1"` или `"yes"` (погледајте `isFeatureFlagEnabled()`).

> [!NOTE]
> Већина заставица такође има одговарајућу променљиву окружења **истог имена**
> документовану у [`ENVIRONMENT.md`](./ENVIRONMENT.md). Замена заставице из базе података
> има предност над том променљивом окружења. Заставица са
> `requiresRestart: true` одмах се трајно чува, али се поново чита само при
> покретању процеса — њено пребацивање приказује натпис **„Поново покрени сервер“** на контролној табли.

## Промена заставица

### Контролна табла

Идите на **Контролна табла → Подешавања → Заставице функција**
(`/dashboard/settings/feature-flags`). Мрежа
(`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`)
подржава:

- **Претрагу** по кључу или опису и **филтрирање** по категорији (уз синтетички приказ **Захтева поновно покретање**).
- **Преклопник** за логичке заставице и **падајући мени** за enum заставице
  (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`).
- Значку извора за сваку заставицу — `DB`, `ENV` или `DEF` — која приказује одакле потиче ефективна вредност.
- Дугме **Врати на подразумевано** (приказује се само за заставице чији је извор `DB`) за уклањање замене и дугме **Уклони све замене** на дну.
- Банер **Поново покрени сервер** када се промени заставица `requiresRestart`.

### REST API

Све операције пролазе кроз једну руту:
[`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts).
Сваки метод захтева аутентификовану сесију контролне табле (у супротном се враћа `401`).

#### `GET /api/settings/feature-flags`

Враћа сваку заставицу са ефективном вредношћу, извором и сажетком.

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Захтевај API кључ",
      "description": "Захтевај API кључ за све долазне захтеве",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... свих 115 заставица
  ],
  "summary": {
    "total": 115,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

Поставља или уклања једну замену. Тело: `{ key: string; value?: string }`.
Изостављање `value` уклања замену (враћа вредност из окружења / подразумевану вредност).

```bash
# Постављање DB замене
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# Уклањање замене (без "value")
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

Одговор садржи нове вредности `effectiveValue`/`source`, претходне вредности
`previousValue`/`previousSource` и `requiresRestart`. Непознати кључеви и вредности enum-а ван дозвољеног опсега одбијају се са `400`.

#### `DELETE /api/settings/feature-flags`

Уклања све DB замене одједном и враћа сваку заставицу на вредност из окружења / подразумевану вредност. Враћа `{ cleared: <count>, message: "..." }`.

> [!NOTE]
> Заставице са `requiresRestart: true` ступају на снагу тек након поновног учитавања процеса.
> Ток поновног покретања на контролној табли позива `POST /api/restart`, а затим периодично позива `GET /api/health/ping` док сервер поново не буде доступан.

## Резервни механизам за прекорачење буџета у хитним случајевима

`OMNIROUTE_EMERGENCY_FALLBACK` (категорија `runtime`, подразумевана вредност `true`) контролише
бесплатни резервни механизам за хитне случајеве у
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts).
Када је омогућен, захтеви који исцрпе свој буџет усмеравају се ка бесплатном резервном
добављачу/моделу уместо да одмах не успеју. Поставите га на `false` (или `0`) — преко
прекидача на контролној табли, замене вредности у бази података или променљиве окружења
`OMNIROUTE_EMERGENCY_FALLBACK` — да бисте онемогућили ово понашање и дозволили да захтеви
са исцрпљеним буџетом не успеју. (Приказано као прекидач на контролној табли у PR-овима #3741 / #3752.)

Одговор послужен путем овог резервног механизма садржи
`X-OmniRoute-Emergency-Fallback: from=<provider/model>; to=<provider/model>`, тако да
клијент може да утврди да је захтев преусмерен без поређења `X-OmniRoute-Provider` са својим
захтевом. Ово заглавље не постоји ни у једном другом одговору.
