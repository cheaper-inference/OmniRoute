## Шта је провајдер?

Замислите провајдера као **мобилног оператера**. Као што вам је потребан мобилни оператер да бисте упућивали позиве, потребан вам је и AI провајдер да бисте користили AI моделе. OmniRoute је попут телефона који ради са **свим оператерима** — можете аутоматски да се пребацујете са једног на други.

### Врсте провајдера

| Врста           | Шта представља                   | Примери                         | Цена                   |
| --------------- | -------------------------------- | ------------------------------- | ---------------------- |
| **Бесплатни**   | Није потребно плаћање            | Kiro, Pollinations              | $0                     |
| **API кључ**    | Потребан вам је API кључ         | OpenAI, Anthropic, Google       | Плаћање према употреби |
| **OAuth**       | Пријављивање помоћу вашег налога | Claude Code, GitHub Copilot     | Претплата              |
| **Web колачић** | Користи вашу сесију у прегледачу | ChatGPT Web (Codex), Gemini Web | $0 (користи ваш налог) |

### Провајдери са Web колачићима

Погледајте **[WEB-COOKIE-GUIDE.md](./WEB-COOKIE-GUIDE.md)** за општа упутства за подешавање, ограничења, решавање проблема и смернице за потврду идентитета специфичне за сваког провајдера.

## Брзи почетак: Повежите свог првог добављача

### Опционално подешавање бесплатних добављача при првом покретању

Чаробњак за прво покретање нуди посебну картицу **Подеси бесплатне добављаче**. Он из регистра OmniRoute добављача који не захтевају аутентификацију издваја тренутну листу доступних добављача, а затим вам омогућава да прегледате сваког од њих и поништите избор пре потврде. OmniRoute приказује упозорење добављача и везу ка његовом сајту како бисте најпре могли да прегледате услове коришћења треће стране, приватност, доступност и ограничења брзине.

Ова радња је опционална: завршетак чаробњака никада не креира везе са бесплатним добављачима без вашег знања. Креирају се само добављачи који још увек недостају, постојеће прилагођене везе остају непромењене, а креирани, већ конфигурисани и неуспешни добављачи пријављују се појединачно. Након делимичног резултата можете безбедно поновити покушај само за неуспешне добављаче.

### Опција A: Бесплатни добављач (без кредитне картице)

1. Отворите контролну таблу на `http://localhost:20128`
2. Идите на **Добављачи** → **Додај добављача**
3. Изаберите једног од ових бесплатних добављача:
   - **Kiro AI** — Бесплатни Claude модели (аутентификација није потребна)
   - **Pollinations** — Бесплатни GPT-5, Claude, Gemini (кључ није потребан)
   - **LongCat** — 10M бесплатних токена (једнократна додела, захтева налог + KYC)
   - **Cloudflare AI** — Више од 50 модела, 10K неурона дневно
   - **MLX Gemma 26B** — Локални модел за Apple Silicon (~38.5 токена/с, ~15.9GB RAM-а)
   - **MLX Qwen 3.8 27B** — Локални модел за Apple Silicon (~9.1 токена/с, ~13.1GB RAM-а)
4. Кликните на **Повежи**
5. Готово! Сада имате бесплатан приступ вештачкој интелигенцији.

### Опција B: Добављач са API кључем (плаћено)

1. Преузмите API кључ са веб-сајта добављача:
   - **OpenAI**: https://platform.openai.com/api-keys
   - **Anthropic**: https://console.anthropic.com/
   - **Google**: https://aistudio.google.com/apikey
   - **DeepSeek**: https://platform.deepseek.com/
   - **Groq**: https://console.groq.com/
2. Отворите контролну таблу на `http://localhost:20128`
3. Идите на **Добављачи** → **Додај добављача**
4. Изаберите свог добављача
5. Налепите свој API кључ
6. Кликните на **Повежи**
7. Готово! Сада имате приступ моделима тог добављача.

### Опција C: OAuth добављач (претплата)

1. Отворите контролну таблу на `http://localhost:20128`
2. Идите на **Добављачи** → **Додај добављача**
3. Изаберите свог добављача (нпр. Claude Code, GitHub Copilot)
4. Кликните на **Повежи помоћу OAuth-а**
5. Пријавите се помоћу свог налога
6. Готово! Сада имате приступ моделима обухваћеним вашом претплатом.

### Опција D: Локални MLX модели (Apple Silicon)

За Apple Silicon Mac рачунаре са обједињеном меморијом, OmniRoute подржава повезивање са локалним MLX моделима који се покрећу преко `mlx-lm.server` као стандардни локални добављачи компатибилни са OpenAI-јем.

#### Предуслови

- **Apple Silicon Mac** (M1/M2/M3/M4), препоручује се 24GB или више обједињене меморије
- Управљач пакетима **uv**: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **mlx-lm**: `uv pip install mlx-lm`

#### Брзи почетак

1. **Инсталирајте зависности**:

   ```bash
   # Инсталирајте uv ако већ није инсталиран
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # Инсталирајте mlx-lm
   uv pip install mlx-lm
   ```

2. **Ручно покрените MLX сервере** (у засебним терминалима):

   ```bash
   # Терминал 1: Gemma 4 26B A4B IT-QAT (порт 11435)
   uv run mlx_lm.server --model mlx-community/gemma-4-26B-A4B-it-qat-q4_0-mlx-aligned --port 11435 --host 127.0.0.1

   # Терминал 2: Qwen 3.8 27B MLX Mixed (порт 11436)
   uv run mlx_lm.server --model maglun/Qwen3.8-27B-MLX-Mixed-3.80bpw --port 11436 --host 127.0.0.1
   ```

3. **Повежите се преко OmniRoute контролне табле**:
   - Идите на **Добављачи** → **Додај добављача**
   - Изаберите **MLX Gemma 26B** или **MLX Qwen 3.8 27B**
   - Кликните на **Повежи** (API кључ није потребан)

4. **Користите са OpenCode-ом**:
   ```bash
   # Конфигуришите OpenCode да користи OmniRoute
   opencode config set api.base_url http://localhost:20128/v1
   opencode config set api.key <your-omniroute-api-key>

   # Користите MLX моделе
   opencode run --model mlx-gemma/gemma-4-26b
   opencode run --model mlx-qwen/qwen3.8-27b
   ```

#### Управљање меморијом

**Важно**: Са 24GB обједињене меморије, истовремено може да ради само **један велики MLX модел**.

- Gemma 26B: ~15.9GB меморије при вршном оптерећењу
- Qwen 3.8 27B: ~13.1GB меморије при вршном оптерећењу

Овим морате управљати ручно:

- Покрећите само један MLX сервер истовремено или
- Покрените оба на засебним рачунарима или
- Зауставите један пре покретања другог

OmniRoute не управља аутоматски процесима MLX сервера — он само усмерава захтеве ка крајњим тачкама компатибилним са OpenAI-јем које конфигуришете.

#### Подршка за позивање алата

Оба модела подржавају позивање алата компатибилно са OpenAI-јем. Тестирајте помоћу:

```bash
curl -X POST http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <key>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mlx-gemma/gemma-4-26b",
    "messages": [{"role": "user", "content": "What is 2+2? Use the calculator tool."}],
    "tools": [{"type": "function", "function": {"name": "calculator", "description": "Calculate", "parameters": {"type": "object", "properties": {"expression": {"type": "string"}}, "required": ["expression"]}}}]
  }'
```

#### Решавање проблема

| Проблем                  | Решење                                                                                      |
| ------------------------ | ------------------------------------------------------------------------------------------- |
| Сервер се не покреће     | Проверите `uv run mlx_lm.server --help` и потврдите ID-ове модела                           |
| Нема довољно меморије    | Уверите се да ради само један модел; затворите друге апликације; проверите Activity Monitor |
| Веза је одбијена         | Проверите да ли сервер ради на одговарајућем порту (11435/11436)                            |
| Спори одговори           | Први захтев учитава модел у меморију (~30-60с); наредни захтеви су брзи                     |
| Позивање алата не успева | Уверите се да модел подржава алате; проверите OmniRoute евиденције за грешке при превођењу  |

## Како повезати провајдера (корак по корак)

### Корак 1: Отворите контролну таблу

У прегледачу идите на `http://localhost:20128`.

### Корак 2: Идите на Провајдери

На бочној траци кликните на **Провајдери**.

### Корак 3: Кликните на Додај провајдера

Кликните на дугме **+ Додај провајдера**.

### Корак 4: Изаберите провајдера

Прегледајте листу или потражите свог провајдера. Кликните на њега.

### Корак 5: Унесите приступне податке

- **Бесплатни провајдери**: Приступни подаци нису потребни — само кликните на **Повежи**
- **Провајдери са API кључем**: Налепите свој API кључ
- **OAuth провајдери**: Кликните на **Повежи помоћу OAuth-а** и пријавите се

### Корак 6: Тестирајте везу

Кликните на **Тестирај везу** да бисте проверили да ли ради.

### Корак 7: Готово!

Ваш провајдер је сада повезан. Можете га користити са `model: "auto"` или директно навести провајдера.

## Коришћење више провајдера

OmniRoute најбоље функционише са **више провајдера**. То вам пружа:

- **Аутоматско пребацивање** — Ако један провајдер откаже, OmniRoute покушава са следећим
- **Оптимизацију трошкова** — OmniRoute бира најјефтинијег провајдера за сваки захтев
- **Оптимизацију брзине** — OmniRoute бира најбржег провајдера за сваки захтев
- **Оптимизацију квалитета** — OmniRoute бира најбољег провајдера за сваки задатак

### Препоручено подешавање

Повежите најмање **3 провајдера** за најбоље искуство:

1. **Један бесплатан провајдер** (Kiro или Pollinations) — Увек доступан
2. **Један брз провајдер** (Groq, Cerebras) — За брзе одговоре
3. **Један квалитетан провајдер** (OpenAI, Anthropic, Google) — За сложене задатке

Затим користите `model: "auto"` и OmniRoute ће аутоматски изабрати најбољег провајдера за сваки захтев.

### Qoder: изаберите начин преноса акредитива

Qoder захтева акредитиве. Његова два начина преноса имају различите могућности; сам назив модела
не одређује шта одређена веза може да уради.

| Акредитив                                  | OmniRoute начин преноса                                | Позивање алатки од стране позиваоца                           | Стримовање                                                     |
| ------------------------------------------ | ------------------------------------------------------ | ------------------------------------------------------------- | -------------------------------------------------------------- |
| PAT који почиње са `pt-`                   | Локални `qodercli` процес на OmniRoute хосту           | Није подржано                                                 | Баферовано: SSE се емитује тек након што CLI врати цео одговор |
| Приступни токен који није PAT или API кључ | DashScope HTTP крајња тачка компатибилна са OpenAI-јем | Прослеђује се, у складу са ограничењима изворног модела/кључа | Изворна HTTP/SSE путања                                        |

За PAT, инсталирајте Qoder CLI на истом хосту или у истом контејнеру као OmniRoute. Извршна датотека
мора бити доступна као `qodercli` или поставите `CLI_QODER_BIN` на путању до њене извршне датотеке. CLI
инсталиран само на Docker хосту није аутоматски присутан у контејнеру. Недостајуће
бинарне датотеке изазивају експлицитну грешку која вас упућује на инсталацију или подешавање путање.

PAT путања за ћаскање има временско ограничење процеса од 45 секунди. Она претвара разговор у
један промпт и позива CLI у нестримујућем режиму исписа. Захтев за `stream: true` мења
омотач одговора у SSE; не обезбеђује постепену испоруку токена из изворног система.
Валидација CLI-ја/приказ листе модела користи засебно временско ограничење од 20 секунди. Ово су тренутне подразумеване
вредности кода, а не подешавања која се могу конфигурисати на контролној табли.

Користите PAT везе за обично ћаскање. Захтеви агента који садрже `tools` или застареле `functions`
искључују PAT налоге током избора акредитива, укључујући закачене комбиноване циљеве. Мешовити
Qoder скуп и даље може да изабере свој HTTP налог. Директни позиви PAT извршиоцу такође се
експлицитно завршавају неуспехом пре покретања CLI-ја, уместо да неприметно одбаце дефиниције алатки. Ово
ограничење се односи на алатке које прослеђује позивалац API-ја, а не на интерне алатке које Qoder
CLI може сам да користи. HTTP кључ не гарантује да сваки модел подржава алатке; уобичајене
провере могућности модела и даље се примењују.

OAuth преко прегледача доступан је само када администратор конфигурише свих пет подешавања:
`QODER_OAUTH_AUTHORIZE_URL`, `QODER_OAUTH_TOKEN_URL`, `QODER_OAUTH_USERINFO_URL`,
`QODER_OAUTH_CLIENT_ID` и `QODER_OAUTH_CLIENT_SECRET`. Њихове подразумеване вредности су празне; код
неконфигурисане инсталације треба користити подржани увоз акредитива, уместо претпоставке
да је ток пријављивања преко прегледача спреман.

Референце имплементације: [Qoder извршилац](../../open-sse/executors/qoder.ts),
[CLI окружење за извршавање](../../open-sse/services/qoderCli.ts) и
[OAuth конфигурација](../../src/lib/oauth/constants/oauth.ts). Постепено PAT стримовање
и подесиво временско ограничење су засебна побољшања; ово понашање их не обећава.

## Честа питања

### „Да ли морам да платим да бих користио OmniRoute?“

**Не!** OmniRoute је бесплатан и отвореног кода. Можете користити бесплатне провајдере (Kiro, Pollinations) без икаквог плаћања. Плаћате само ако одлучите да користите провајдере који се плаћају.

### „Са којим провајдером би требало да почнем?“

Почните са **Kiro AI** — бесплатан је, не захтева API кључ и омогућава вам приступ Claude моделима. Затим додајте још провајдера по потреби.

### „Могу ли да користим више провајдера истовремено?“

**Да!** То је главна сврха OmniRoute-а. Повежите више провајдера и користите `model: "auto"` како би OmniRoute изабрао најбољег за сваки захтев.

### „Шта ако провајдер престане да ради?“

OmniRoute аутоматски прескаче провајдере који нису доступни и покушава са следећим. Не морате ништа да радите.

### „Како да прекинем везу са провајдером?“

Идите на Providers → кликните на провајдера → кликните на **Disconnect**.

### „Могу ли да користим своје постојеће API кључеве?“

**Да!** Ако већ имате API кључеве за OpenAI, Anthropic, Google итд., можете их користити у OmniRoute-у. Само их налепите приликом повезивања провајдера.
