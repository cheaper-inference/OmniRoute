## Вратите конфигурацију клијента

Програм за деинсталацију зауставља OmniRoute процес којим управља PM2, ако постоји, и оставља конфигурацију клијента на месту. Клијенти који и даље упућују на OmniRoute губе везу када се она заустави. Потпуно уклањање такође брише директоријум података, подразумевано `~/.omniroute`, заједно са резервним копијама конфигурације клијента.

### 1. Користите контролну таблу док OmniRoute ради

Отвори**CLI Цоде** (`/dashboard/cli-code`) на контролној табли и пронађите**Claude Цоде** картица.** Пријавите се** уписује у датотеку подешавања Claude кода OmniRoute хоста, `~/.claude/settings.json` подразумевано. Ако имате резервну копију од пре примене OmniRoute подешавања, отворите** Резервне копије** и обновити га. У супротном, изаберите** Ресетуј** да бисте уклонили подешавања мрежног пролаза из `env`. Прво примените и ресетујте резервну копију постојеће датотеке. Резервне копије се чувају под `<DATA_DIR>/backups`.

Ако `CLI_ALLOW_CONFIG_WRITES=false` или контролна табла нису доступни, вратите датотеку ручно. Ако OmniRoute ради у Docker, а клијент ради на хосту, вратите конфигурацију хоста. Датотеке у немонтираној кући контејнера немају утицаја на клијента домаћина.

### 2. Ручно вратите преостале промене

За Claude код, проверите `~/.claude/settings.json`, `settings.json` у `CLAUDE_CONFIG_DIR` ако је постављен, и `.claude/settings.json` пројекта. Ресетовање уклања следеће кључеве из `env`. Уклоните вредности које сте додали за OmniRoute или вратите претходне вредности.

- `"ANTHROPIC_BASE_URL"`, `"ANTHROPIC_AUTH_TOKEN"` и `"ANTHROPIC_API_KEY"`
- `"ANTHROPIC_DEFAULT_OPUS_MODEL"`, `"ANTHROPIC_DEFAULT_SONNET_MODEL"` и `"ANTHROPIC_DEFAULT_HAIKU_MODEL"`
- `"API_TIMEOUT_MS"`

Ресетовање оставља `ANTHROPIC_MODEL` у `env` и `model` и `apiKeyHelper` подешавања највишег нивоа на месту. Уклоните или вратите их ручно ако одаберу OmniRoute модел или акредитиве. Престаните да користите било који OmniRoute профил који је направио `omniroute setup-claude` под `~/.claude/profiles/<name>/`, или вратите његов `settings.json`. Команда за подешавање уписује профил без промене подразумеване датотеке поставки или чувања токена. Уклоните или вратите подударне извозе у вашим датотекама за покретање љуске и обришите старе вредности из тренутне љуске. `omniroute launch` и `omniroute run claude` постављају мрежни пролаз URL и токен само за подређени процес.

За Codex, вратите претходни добављач и модел у `~/.codex/config.toml` ако садржи `model_provider = "omniroute"`. Уклоните `[model_providers.omniroute]` ако је додат за овај мрежни пролаз. Вратите или уклоните `openai_base_url` ако указује на OmniRoute. За клијенте компатибилне са ОпенАИ, вратите или обришите `OPENAI_BASE_URL` где год да га подесите за OmniRoute.

### 3. Проверите да клијент ради са OmniRoute заустављеним

Проверите подразумеване поставке Claude кода и тренутно окружење љуске.

```bash
grep -n ANTHROPIC ~/.claude/settings.json
env | grep ANTHROPIC
```

Ниједна провера не би требало да покаже `ANTHROPIC_BASE_URL` која показује на OmniRoute. Ако користите поставке профила или пројекта, проверите и те датотеке. Када је OmniRoute заустављен и ваша уобичајена аутентификација враћена, покрените Claude Цоде директно.

```bash
claude -p "say hello"
```

Claude код треба да одговори користећи враћену конфигурацију. Ако и даље указује на заустављени мрежни пролаз, захтев не успева са грешком у вези.

## Брза деинсталација (в3.6.2 +)

> Прво [вратите конфигурацију клијента](#revert-client-configuration), док OmniRoute још увек ради.

OmniRoute пружа две уграђене скрипте за чисто уклањање:

### Чувајте своје податке

```bash
npm run uninstall
```

Ово уклања OmniRoute апликацију, али** чува** вашу базу података, конфигурације, API кључеве и подешавања провајдера у `~/.omniroute/`. Користите ово ако планирате да поново инсталирате касније и желите да задржите подешавања.

### Потпуно уклањање

```bash
npm run uninstall:full
```

Ово уклања апликацију** и трајно брише** сви подаци:

- База података (`storage.sqlite`)
- Конфигурације провајдера и API кључеви
- Резервне копије датотека
- Лог датотеке
- Све датотеке у `~/.omniroute/` директоријуму

> ⚠️** Упозорење:** `npm run uninstall:full` је неповратан. Све везе вашег провајдера, комбинације, API кључеви и историја коришћења биће трајно избрисани.

## Ручна деинсталација

> Прво [вратите конфигурацију клијента](#revert-client-configuration), док OmniRoute још увек ради.

### NPM Глобал Инсталл

```bash
# Remove the global package
npm uninstall -g omniroute

# (Optional) Remove data directory
rm -rf ~/.omniroute
```

### пнпм Глобал Инсталл

```bash
pnpm uninstall -g omniroute
rm -rf ~/.omniroute
```

### Docker

```bash
# Stop and remove the container
docker stop omniroute
docker rm omniroute

# Remove the volume (deletes all data)
docker volume rm omniroute-data

# (Optional) Remove the image
docker rmi cheaperinference/omniroute:latest
# Older installs pulled the legacy name:
docker rmi diegosouzapw/omniroute:latest
```

### Docker Цомпосе

```bash
# Stop and remove containers
docker compose down

# Also remove volumes (deletes all data)
docker compose down -v
```

### Electron Десктоп апликација

**Windows:**

- Отвори `Settings → Apps → OmniRoute → Uninstall`
- Или покрените NSIS деинсталатор из инсталационог директоријума

**macOS:**

- Превуците `OmniRoute.app` из `/Applications` у отпад
- Уклоните податке: `rm -rf ~/Library/Application Support/omniroute`

**Linux:**

- Уклоните AppImage
- Уклоните податке: `rm -rf ~/.omniroute`

### Инсталација извора (гит клон)

```bash
# Remove the cloned directory
rm -rf /path/to/omniroute

# (Optional) Remove data directory
rm -rf ~/.omniroute
```

## Директоријуми са подацима

OmniRoute подразумевано чува податке на следећим локацијама:

| Платформа        | Подразумевана путања             | Преклапање                      |
| ---------------- | -------------------------------- | ------------------------------- |
| Linux            | `~/.omniroute/`                  | `DATA_DIR` env варијабла        |
| macOS            | `~/.omniroute/`                  | `DATA_DIR` env варијабла        |
| Windows          | `%APPDATA%/omniroute/`           | `DATA_DIR` env варијабла        |
| Docker           | `/app/data/` (монтирани волумен) | `DATA_DIR` env варијабла        |
| XDG-компатибилно | `$XDG_CONFIG_HOME/omniroute/`    | `XDG_CONFIG_HOME` env варијабла |

### Фајлови у директоријуму са подацима

| Фајл/Директоријум    | Опис                                                                |
| -------------------- | ------------------------------------------------------------------- |
| `storage.sqlite`     | Главна база података (провајдери, комбинације, подешавања, кључеви) |
| `storage.sqlite-wal` | SQLite write-ahead лог (привремено)                                 |
| `storage.sqlite-shm` | SQLite дељена меморија (привремено)                                 |
| `call_logs/`         | Архиве садржаја захтева                                             |
| `backups/`           | Аутоматске резервне копије базе података                            |
| `log.txt`            | Застарели лог захтева (опционо)                                     |

## Провера потпуног уклањања

Након деинсталације, проверите да нема заостатих фајлова:

```bash
# Провера глобалног npm пакета
npm list -g omniroute 2>/dev/null

# Провера директоријума са подацима
ls -la ~/.omniroute/ 2>/dev/null

# Провера покренутих процеса
pgrep -f omniroute
```

Ако је неки процес још покренут, зауставите га:

```bash
pkill -f omniroute
```
