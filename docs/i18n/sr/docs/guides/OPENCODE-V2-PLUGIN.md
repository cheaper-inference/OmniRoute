`@omniroute/opencode-plugin-v2` додаје цео ваш OmniRoute каталог — моделе, комбинације и
аутоматске комбинације — у OpenCode v2 бирач модела, заједно са називима за приказ, ценама и
ограничењима бесплатног нивоа.

То је засебан пакет у односу на `@omniroute/opencode-plugin` зато што OpenCode v1 и v2 учитавају
додатке преко различитих уговора. Изаберите онај који одговара главној верзији вашег OpenCode-а;
ништа се не дели између њих, тако да надоградња једног никада не захтева надоградњу другог.

## Захтеви

- OpenCode v2.
- Доступан OmniRoute мрежни пролаз (подразумевано `http://localhost:20128`).
- Node.js 22 или 24.

## Инсталација

Додајте додатак у `opencode.json`:

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

Модели ће се затим појавити као `omniroute/<provider>/<model>`; `providerId` одређује тај префикс и
ID интеграције под којим OpenCode чува акредитив.

## Акредитиви

Додатак тражи кључ мрежног пролаза на три места, следећим редоследом:

1. **Акредитив који сте повезали у OpenCode-у.** Додатак региструје интеграцију, тако да
   OpenCode-ов сопствени ток аутентификације може да сачува кључ. Ништа се не уписује у `opencode.json` — ово је пожељна опција.
2. `apiKey` у опцијама додатка, за замену подешавања на нивоу пројекта. Тако се кључ смешта у датотеку
   коју можда шаљете у репозиторијум.
3. `OMNIROUTE_API_KEY` у окружењу.

Ако ниједна од ове три опције није доступна, каталог је празан и додатак то једном саопштава при покретању,
уместо да вам остави неприметно празан бирач.

### Токен за управљање је засебан кључ

Комбинације, стање добављача и обогаћивање података (називи за приказ, цене и ограничења бесплатног нивоа) долазе са
`/api/*` крајњих тачака мрежног пролаза, које већина инсталација штити **управљачким** токеном,
а не кључем за извршавање закључивања:

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<токен за управљачки приступ за читање>"
}
```

Ако није подешен, `managementReadToken` се враћа на `apiKey`. Када мрежни пролаз одбије ту резервну
вредност, каталог се и даље објављује, али са сировим ID-овима модела уместо назива за приказ, без
уклањања дупликата канонских алијаса, цена и комбинација. Додатак упозорава једном по крајњој тачки када се то догоди,
наводећи крајњу тачку и шта је изгубљено — тако да разлог осиромашеног бирача никада није нејасан.

## Опције

| Кључ                             | Подразумевано                                 | Напомене                                                                                                                                                                                                                                                                                                                                                                      |
| -------------------------------- | --------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `providerId`                     | `"omniroute"`                                 | Испод се појављују ИД добављача, ИД интеграције и модели префикса                                                                                                                                                                                                                                                                                                             |
| `baseURL`                        | потребно                                      | Роот приступника, само `http(s)` ; `/v1` суфикс се додаје тамо где је потребно                                                                                                                                                                                                                                                                                                |
| `apiKey`                         | повезани акредитив, затим `OMNIROUTE_API_KEY` | Тастер за ћаскање за `/v1/*`                                                                                                                                                                                                                                                                                                                                                  |
| `managementReadToken`            | пада назад у `apiKey`                         | Кључ за `/api/*` — обично** не** исти онај                                                                                                                                                                                                                                                                                                                                    |
| `displayName`                    | `"OmniRoute"`                                 | Име провајдера у бирачу                                                                                                                                                                                                                                                                                                                                                       |
| `timeoutMs`                      | `10000`                                       | Временско ограничење преузимања по крајњој тачки (ауто-комбо користе 5 с)                                                                                                                                                                                                                                                                                                     |
| `modelCacheTtlMs`                | `300000`                                      | Каталог кеш TTL; снимак диска загрева хладне стартове                                                                                                                                                                                                                                                                                                                         |
| `timeouts`                       | пада назад у `timeoutMs`                      | Буџети по крајњој тачки у мс: `models`, `combos`, `autoCombos`, `enrichment`                                                                                                                                                                                                                                                                                                  |
| `enrichment`                     | `true`                                        | Дохватите имена, цене и буџете бесплатног нивоа                                                                                                                                                                                                                                                                                                                               |
| `providerTag`                    | `true`                                        | Укључи/искључи заграде завршног уређивача: `Provider - Model (Editor)`. Провајдер (рута која опслужује модел) је увек приказан; уредник (који је направио модел) се појављује само у загради. Пример: `Openrouter - MoonshotAI: Kimi K 3.1 Pro` -> `Openrouter - Kimi K 3.1 Pro (MoonshotAI)`. Изоставља се када уредник и добављач деле име. Подесите `false` да га испусти. |
| `usableOnly`                     | `false`                                       | Задржите само провајдере које извештаје мрежног пролаза обезбеђују                                                                                                                                                                                                                                                                                                            |
| `combosSource`                   | `"api"`                                       | `"models"` прескаче `/api/combos` и објављује `/v1/models` комбиноване редове; филтери на нивоу чланова задржавају `"api"`                                                                                                                                                                                                                                                    |
| `showcasePerOwner`               | `10`                                          | Уноси подразумеваног приказа чувају се по добављачу                                                                                                                                                                                                                                                                                                                           |
| `freshPerOwner`                  | `10`                                          | Свежи уноси за подразумевани приказ чувају се по добављачу                                                                                                                                                                                                                                                                                                                    |
| `freshWindowDays`                | `90`                                          | Прозор свежине у данима за свежу грану                                                                                                                                                                                                                                                                                                                                        |
| `usageMemory`                    | `true`                                        | Врати статички испуштене уносе именоване 30-дневном аналитиком коришћења (потребан је токен за управљање)                                                                                                                                                                                                                                                                     |
| `visibleModels` / `hiddenModels` | `[]`                                          | Листе дозвољених тачних или суфиксних; дени винс; `*` објављује цео каталог (други филтери и даље важе)                                                                                                                                                                                                                                                                       |
| `geminiSanitization`             | `true`                                        | Уклоните кључне речи ЈСОН-шеме Gemini одбија из шема алата (`$ref` алати се прослеђују нетакнути)                                                                                                                                                                                                                                                                             |
| `apiFormat.allowAnthropic`       | `false`                                       | Рутирајте дозвољене ИД-ове кроз блок Anthropic API                                                                                                                                                                                                                                                                                                                            |
| `apiFormat.anthropicModels`      | `[]`                                          | Пуни ИД-ови модела преусмерени на Anthropic                                                                                                                                                                                                                                                                                                                                   |
| `logLevel` / `startupDebug`      | `warn` / `false`                              | Логгер вербосити                                                                                                                                                                                                                                                                                                                                                              |

Меморија за коришћење је подразумевано укључена. Без токена управљања остаје инертан (обавештење о покретању се евидентира) и ништа се не враћа.

## Како каталог остаје свеж

Каталог се лењо преузима и кешује за `modelCacheTtlMs`, а снимак диска држи последњи познати каталог доступним када је мрежни пролаз недоступан — испад вас кошта ништа осим свежине. Модели и комбинације се објављују чим стигну; ауто-комбо, листа провајдера и слој за обогаћивање се преклапају када слете, тако да једна спора крајња тачка не може да држи цео бирач као таоца.

Имена прате `Provider - Model[ (Editor)][ · budget][ (route)]`: провајдер се приказује кад год га ид носи (ид без косе црте се приказује без префикса), водећи `🆓` означава бесплатне уносе и њихов бесплатни буџет остаје као `· 1M tokens/month` суфикс, уредник експлицитног `Editor: Model` имена се помера у заграду на крају (ниједан уредник ниједног уредника се не погађа као слободан з), а зкб име се поново не `combo - <slug>` икона. Два уноса који деле име добијају наставак руте — `(no-think)` — тако да остају препознатљиви. `providerTag` (подразумевано `true`) искључује заграде уређивача на крају.

Не постоји ручна наредба за освежавање: OpenCode в2 команде су промпт шаблони, а не повратни позиви, тако да додатак не може да их открије. Освежавања прате TTL; од хоста се тражи да поново учита само када се каталог или прекривач заиста промени, никада једном по освежавању.

## Позивање алата на Gemini-ју

Gemini одбацује цео захтев чије декларације алата садрже `$schema` или
`additionalProperties`, уз одговор `400 INVALID_ARGUMENT`. Додатак уклања те кључне речи из
шема алата намењених Gemini моделу овог добављача и не мења ниједан други захтев.
Алат који садржи `$ref` прослеђује се непромењен уместо да буде очишћен, јер би уклањање
референце проширило шему тако да „прихвата било шта“.
Подесите `"geminiSanitization": false` да бисте то искључили.

## Решавање проблема

| Симптом                                             | Узрок                                                                                                             |
| --------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Бирач не приказује модел OmniRoute                  | Ниједан кључ није решен (проверите упозорење о покретању) или је мрежни пролаз недоступан                         |
| Необрађени ИД-ови модела, без комбинација, без цена | Крајње тачке управљања одбиле су токен — скуп `managementReadToken`                                               |
| Кратак или празан `freeOnly` каталог                | Нема токен управљања или одбијен токен — чита линију сажетка освежавања (`unmatched-free` цоунт) у дневнику хоста |
| Сесија закачена за `opencode-<id>/...`              | Додатак в1 је објавио `opencode-<id>`; в2 објављује `<id>` голи, па поново изаберите модел под `<id>/...`         |

Променљиве окружења морају да достигну серверски процес отвореног кода: када се хост покреће као услуга, љуска која покреће `opencode models` и окружење сервера су различити, па извезите кључ тамо где га сервер чита.
