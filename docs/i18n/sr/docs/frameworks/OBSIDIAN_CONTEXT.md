> `src/lib/db/obsidian.ts` (чување токена / основног URL-а / WebDAV података),
> `src/lib/obsidianSync.ts` (WebDAV синхронизација трезора), `open-sse/mcp-server/tools/obsidianTools.ts`

> `src/app/api/settings/obsidian/webdav/route.ts` (API-ји за подешавања). Регистрација алатки
> и повезивање опсега налазе се у `open-sse/mcp-server/server.ts`.

## Шта је ово

OmniRoute се повезује са **Obsidian** трезором као **извором контекста** — локалном Markdown
базом знања коју агенти читају и у коју уписују преко уграђеног MCP сервера.
Интеграција комуницира са додатком заједнице **Obsidian Local REST API** који се извршава у
десктоп апликацији, тако да агенти могу да претражују белешке, читају/пишу/мењају датотеке, излиставају трезор, раде
са дневним/недељним периодичним белешкама, управљају ознакама, покрећу Obsidian команде и (опционо)
координишу двосмерну синхронизацију трезора између десктопа и мобилног уређаја.

Клијент (`src/lib/obsidian/api.ts`) обавија Local REST API и пружа:

- **Поновне покушаје са одлагањем** за привремене `5xx` грешке, **временско ограничење од 30 секунди** преко `AbortController`.
- **Типизирану класификацију грешака** — `ObsidianAuthError` (401/403),
  `ObsidianNotFoundError` (404), `ObsidianServerError` (5xx), `ObsidianTimeoutError`.
- **Разумљив савет „није могуће приступити Obsidian-у“** који указује на честу грешку са портом
  (HTTP на `27123`, **не** MCP крајња тачка на `27124`) и Tailscale облик адресе.
- **Кодирање путања** релативних у односу на трезор, како би путање бележака са размацима/косим цртама биле безбедне.

## Подешавање

**Не постоји променљива окружења** за Obsidian токен или основни URL — оба се
чувају у SQLite табели `key_value` (простор имена `obsidian`) преко
`src/lib/db/obsidian.ts`. Токен је **шифрован при складиштењу** (AES-256-GCM, уз
резервну подршку за нешифровани текст ради компатибилности уназад). Подесите га на картици **Извори контекста** контролне табле
крајње тачке (`ObsidianSourceCard`) или путем REST API-ја за подешавања.

> [!IMPORTANT]
> Додатак **Obsidian Local REST API** мора бити инсталиран и покренут. Његов REST
> интерфејс ослушкује на **HTTP `127.0.0.1:27123`** (подразумевани основни URL). Порт `27124`
> је _засебна_ MCP/HTTPS крајња тачка и рута за подешавања га изричито одбија.
> Ако се повезујете са другог уређаја, користите `http://<tailscale-ip>:27123`.

### Конфигурациони кључеви (SQLite `key_value`, простор имена `obsidian`)

| Кључ              | Намена                                                        | Шифровано |
| ----------------- | ------------------------------------------------------------- | --------- |
| `api_key`         | Bearer токен локалног REST API-ја                             | да        |
| `base_url`        | Основни REST URL (подразумевано `http://127.0.0.1:27123`)     | не        |
| `vault_path`      | Апсолутна путања до директоријума трезора (за синхронизацију) | не        |
| `webdav_username` | Генерисано WebDAV корисничко име (синхронизација трезора)     | не        |
| `webdav_password` | Генерисана WebDAV лозинка (синхронизација трезора)            | да        |
| `webdav_enabled`  | Да ли је WebDAV синхронизација трезора омогућена              | не        |

### Подешавање путем REST-а

```bash
# Сачувајте и проверите Local REST API токен (POST га проверава путем провере статуса)
curl -X POST http://localhost:20128/api/settings/obsidian \
  -H "Content-Type: application/json" \
  -d '{"token":"<obsidian-rest-api-key>","baseUrl":"http://127.0.0.1:27123"}'

# Проверите статус везе (враћа connected, hasToken, baseUrl, vaultPath)
curl http://localhost:20128/api/settings/obsidian

# Прекините везу (брише сачувани токен)
curl -X DELETE http://localhost:20128/api/settings/obsidian
```

Све методе захтевају аутентификацију на контролној табли. `POST` одбија сваки URL на порту `27124`
и проверава токен позивањем статусне крајње тачке локалног REST API-ја пре чувања.

### WebDAV синхронизација трезора

`src/app/api/settings/obsidian/webdav/route.ts` управља опционом синхронизацијом
трезора преко WebDAV-а (коју покреће `src/lib/obsidianSync.ts`). Њеним омогућавањем OmniRoute се усмерава на
локални директоријум трезора и генерише се насумичан пар WebDAV корисничког имена и лозинке:

```bash
# Омогућите WebDAV синхронизацију за директоријум трезора (генерише корисничко име/лозинку)
curl -X POST http://localhost:20128/api/settings/obsidian/webdav \
  -H "Content-Type: application/json" \
  -d '{"vaultPath":"/home/me/MyVault"}'

# Преузмите статус WebDAV синхронизације (акредитиви се враћају само док је омогућена)
curl http://localhost:20128/api/settings/obsidian/webdav

# Онемогућите WebDAV синхронизацију (брише акредитиве и управљану датотеку .stignore)
curl -X DELETE http://localhost:20128/api/settings/obsidian/webdav
```

### Безбедност и транспорт

WebDAV аутентификација спроводи праћење и закључавање грешака по ИП-у (10 неуспешних покушаја у року од 60 секунди покреће 5-минутно закључавање са `429 Too Many Requests` и `Retry-After`). Пошто WebDAV преноси основне акредитиве за аутентификацију, укидање TLS (или рутирање преко безбедног тунела као што је Tailscale или Cloudflare Tunnel) се снажно препоручује када се приступа WebDAV крајњој тачки изван повратне петље.

### Извор контекста по API кључу (опционо)

Obsidian конфигурација може бити ограничена **по API кључу** путем табеле `api_key_context_sources`
(`src/lib/db/apiKeyContextSources.ts`). Када MCP позив садржи ID аутентификованог API
кључа, `getObsidianConfigForApiKey()` даје предност сопственом токену, основном URL-у и путањи до трезора тог кључа
(`source: "api_key"`), а у супротном користи глобалну конфигурацију (`source: "global"`).

MCP алати који нису намењени синхронизацији захтевају разрешен идентитет позиваоца пре читања ове конфигурације.
Позивалац без идентитета добија поруку `Obsidian API token not configured` и ниједан захтев ка трезору
се не шаље. Идентитет HTTP позивалаца разрешава се путем њихових акредитива захтева; идентитет stdio позивалаца
може се разрешити путем `OMNIROUTE_API_KEY` или `ROUTER_API_KEY`. Неразрешени HTTP позивалац
не може наследити идентитет окружења сервера. Сами ID-ови чувара места не одобравају
приступ; и даље је подржан важећи акредитив окружења који се разрешава у `env-key`.
Аутентификовани кључеви без Obsidian конфигурације по кључу задржавају глобалну резервну конфигурацију.
Четири алата `obsidian_sync_*` задржавају своје засебно понашање токена за синхронизацију.

## MCP алати (22)

Дефинисано у `open-sse/mcp-server/tools/obsidianTools.ts`. token/base-URL се решавају по позиву (прво по АПИ кључу, а затим глобално). Алати који погађају OmniRoute** сервер за синхронизацију** (четири `obsidian_sync_*` алата) додатно захтевају токен аутх за синхронизацију конфигурисан у поставкама OmniRoute.

### Алати за читање (`read:obsidian`)

| Алат                         | Опис                                                                                                                     |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `obsidian_check_status`      | Проверите да ли је локални REST API доступан и аутентификован.                                                           |
| `obsidian_search_simple`     | Претраживање садржаја белешке по целом тексту; враћа исечке са путањама датотеке.                                        |
| `obsidian_search_structured` | Претражујте помоћу JSON логичког израза (and/or/regex/path филтери).                                                     |
| `obsidian_read_note`         | Прочитајте белешку по путањи у односу на трезор; опционо одређени heading/block/frontmatter.                             |
| `obsidian_list_vault`        | Наведите датотеке и директоријуме у трезору (стабло уноса).                                                              |
| `obsidian_get_document_map`  | Добијте структуру наслова белешке као мапу бројева → редова наслова.                                                     |
| `obsidian_get_note_metadata` | Добијте фронтматер, ознаке, везе, char/word цоунт без пуног садржаја.                                                    |
| `obsidian_get_active_file`   | Добијте путању + садржаја тренутно активне датотеке у Obsidian.                                                          |
| `obsidian_get_periodic_note` | Набавите daily/weekly/monthly периодичну белешку за датум (данас ако је изостављен).                                     |
| `obsidian_get_tags`          | Наведите све ознаке трезора са њиховим фреквенцијама.                                                                    |
| `obsidian_list_commands`     | Наведите доступну Obsidian команду IDs (користите са `obsidian_execute_command`).                                        |
| `obsidian_sync_status`       | Статус OmniRoute синхронизационог сервера: покренут, име трезора, порт, време непрекидног рада, последња синхронизација. |
| `obsidian_sync_conflicts`    | Наведите нерешене конфликте синхронизације (путања, путања конфликта, откривено-на).                                     |

### Алати за писање (`write:obsidian`)

| Алат                             | Опис                                                                                            |
| -------------------------------- | ----------------------------------------------------------------------------------------------- |
| `obsidian_write_note`            | Направите или замените белешку са датим садржајем Маркдовн-а.                                   |
| `obsidian_append_note`           | Додајте садржај белешци; опционо на одређени heading/block.                                     |
| `obsidian_patch_note`            | Хируршки append/prepend/replace у правцу, блоку или пољу предње материје.                       |
| `obsidian_delete_note`           | Трајно избришите белешку из трезора.                                                            |
| `obsidian_move_note`             | Померите или преименујте белешку у трезору.                                                     |
| `obsidian_execute_command`       | Извршите команду Obsidian помоћу њене команде ID.                                               |
| `obsidian_open_file`             | Отворите датотеку у Obsidian (креира је ако не постоји).                                        |
| `obsidian_sync_trigger`          | Активирајте тренутну двосмерну синхронизацију ↔ мобилног трезора за десктоп рачунаре.           |
| `obsidian_sync_resolve_conflict` | Решите конфликт синхронизације: задржите `local` (мобилни), `remote` (десктоп) или `keep-both`. |

> [!NOTE]
> `obsidian_patch_note` циљеви прихватају `targetType` од `heading | block | frontmatter` и `operation` од `append | prepend | replace`, са опционим `createTargetIfMissing`. Четири `obsidian_sync_*` алата разговарају са локалним сервером за синхронизацију (`http://127.0.0.1:27781` подразумевано) и захтевају токен за синхронизацију.

### Сцопес

Алати за читање захтевају `read:obsidian`; алати за писање захтевају `write:obsidian`. Спровођење је идентично Notion — којим управља `withScopeEnforcement()` у `open-sse/mcp-server/server.ts`, затворено на `OMNIROUTE_MCP_ENFORCE_SCOPES=true` и принудно укључено за HTTP/SSE позиваоце чији API кључ нема `manage`/`admin`, са дозвољеним обимима који потичу из `OMNIROUTE_MCP_SCOPES` или контекста опсега API кључа. Види [MCP-SERVER.md](./MCP-SERVER.md).

## Крајње тачке

| Метод    | Путања                          | Намена                                                        |
| -------- | ------------------------------- | ------------------------------------------------------------- |
| `GET`    | `/api/settings/obsidian`        | Враћа `{ connected, hasToken, baseUrl, vaultPath }`.          |
| `POST`   | `/api/settings/obsidian`        | Чува и проверава токен (одбија порт `27124`).                 |
| `DELETE` | `/api/settings/obsidian`        | Прекида везу (брише сачувани токен).                          |
| `GET`    | `/api/settings/obsidian/webdav` | Статус WebDAV синхронизације и акредитиви (док је омогућена). |
| `POST`   | `/api/settings/obsidian/webdav` | Омогућава WebDAV синхронизацију за директоријум трезора.      |
| `DELETE` | `/api/settings/obsidian/webdav` | Онемогућава WebDAV синхронизацију.                            |

> Ово су руте подешавања контролне табле. Самом трезору се приступа преко Obsidian
> Local REST API-ја (конфигурисаног `base_url`) и путем горенаведених MCP алата — не
> постоји јавна Obsidian прокси крајња тачка `/v1`.

## Случајеви употребе

- **Одговори засновани на трезору** — `obsidian_search_simple` / `obsidian_search_structured`,
  а затим `obsidian_read_note`, како би агент одговарао на основу ваших стварних белешки.
- **Писање белешки / вођење дневника** — `obsidian_write_note`, `obsidian_append_note` или
  прецизни `obsidian_patch_note` за уписивање излаза агента, сажетака или дневних белешки
  (`obsidian_get_periodic_note`) у трезор.
- **Навигација кроз трезор** — `obsidian_list_vault`, `obsidian_get_document_map` и
  `obsidian_get_tags` за истраживање структуре пре читања/писања.
- **Obsidian аутоматизација** — `obsidian_list_commands` + `obsidian_execute_command` за
  покретање додатака/команди преко агента; `obsidian_open_file` за приказ белешке у корисничком интерфејсу.
- **Мобилна синхронизација** — омогућите WebDAV синхронизацију, а затим користите `obsidian_sync_trigger` /
  `obsidian_sync_status` / `obsidian_sync_conflicts` / `obsidian_sync_resolve_conflict`
  за координацију између десктоп и мобилног уређаја и решавање конфликата.
