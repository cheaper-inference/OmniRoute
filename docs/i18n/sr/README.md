## Бесплатни токени месечно: ~ 11.3Б колико други броје · ~ 90М Реал

</div>

> **~ 11.3Б бесплатних токена месечно**<br/> <sub> је рачунао начин на који се броје други каталози: сваки ред се збраја, завршене понуде су укључене </sub>
>
> **~ 90М реал данас**<br/> <sub> свака дељена квота се рачуна једном: шта заправо можете да користите </sub>
>
> **Овде је све бесплатно. Нема паивалл-а.**<br/> ★ [Свиђа вам се? Звезда нам на GitHub](https://github.com/cheaper-inference/OmniRoute)

Други каталози наплаћују од US$19 годишње до US$49 за доживотни приступ подацима уживо. Овде је све бесплатно. <sub> Цене проверене 18.11.2026.</sub>

<sub>Каталог је последњи пут ревидиран 23.11.2026. [Како рачунамо →](docs/reference/FREE_TIERS.md#how-we-count)</sub>

> **Донесите своје налоге провајдера.** Ово су бесплатни нивои трећих страна, а не токен грант од OmniRoute. Региструјте се, набавите акредитиве тамо где их провајдер тражи и повежите оне које можете да користите. Сваки провајдер поставља своја ограничења, доступност и услове.
>
> Ручно слагање бесплатних нивоа значи десетине SDKs, десетине ограничења стопе и нема јасне идеје шта вам је остало. OmniRoute чува 214 каталошких редова са слободним приступом и израчунава стварну цифру из 12 скупова са објављеном квотом, при чему се сваки заједнички скуп рачуна једном. Квоте које се отварају тек након регионалне провере идентитета (данас, ModelScope) приказане су одвојено, +~ 6М иза верификације регионалног идентитета и никада се не додају стварној цифри. Оно што је остало појављује се на контролној табли (`/dashboard/free-tiers`).

## Инсталирајте, повежите провајдера, а затим усмерите кроз једну крајњу тачку

<img src="./docs/diagrams/works-zero-config.svg" width="100%" alt="Four steps to use OmniRoute. Install with npm install -g omniroute, run omniroute, connect a provider and create an API key in the dashboard, then call http://localhost:20128/v1 with model auto."/>

```bash
# After connecting a provider, create your OmniRoute key in Dashboard → API Keys:
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer YOUR_OMNIROUTE_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"auto","messages":[{"role":"user","content":"Hello!"}]}'
```

<sub>`auto` треба одговарајућу руту. Нова инсталација не може имати прихватљиве циљеве без кључа, а добављач без кључа може одбити клијенте треће стране. Провајдери означени `tos: avoid`, укључујући Kiro, подразумевано су искључени из аутоматског рутирања; повезивање налога не замењује то подешавање. Погледајте [Водич за бесплатне нивое](docs/getting-started/FREE-TIERS-GUIDE.md) пре него што изаберете добављача.</sub>

## Комбинације: водећи

1. **Почните са `auto`.** Поставите модел у свом ОпенАИ-компатибилном клијенту. OmniRoute прави виртуелну комбинацију од повезаних провајдера и оцењује кандидате уживо.
2. **Сачувајте комбинацију за већу контролу.** Изаберите име, циљну листу и стратегију, а затим користите то име као модел. Стратегија одређује који циљ иде први и како ће се остали покушати.

Комбинација аутоматски пролази кроз моделе. У случају исцрпљивања квоте, отказа провајдера или блокаде модела, покушава следећу прихватљиву, здраву мету.

### Зеро-цонфиг: само користите `auto`

```bash
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <your-omniroute-key>" \
  -H "Content-Type: application/json" \
  -d '{"model": "auto", "messages": [{"role": "user", "content": "Hello"}]}'
```

Варијанте подешавају тежине. Последње познато-добро рутирање остаје код последњег успешног провајдера док не успе, а затим се поново оцењује. `auto/fast` и `auto/cheap` изражавају преференције без гарантовања најбржег или најјефтинијег модела.

| `auto/subscription` | Користи само квоту плана верификовану уживо. Враћа HTTP 503 када ниједан није доступан и избегава наплаћену резервну вредност.                                                                                                                                                |

### Отпорност је уграђена у: 3 независна слоја

Грешке се третирају у три опсега, тако да један лош модел не уклања свој налог, а један лош налог не уклања свог провајдера.

<img src="./docs/diagrams/resilience-layers.svg" width="100%" alt="OmniRoute resilience: 3 independent self-healing layers, the right layer for the right failure. Layer 1, provider circuit breaker (whole provider): trips only on 408/500/502/503/504, opens after 8 failures for OAuth providers or 12 for API-key providers, resets after 60s or 30s into a HALF-OPEN probe, lazy recovery; while OPEN the combo reroutes to the next provider. Layer 2, connection cooldown (one key or account): base 5s OAuth or 3s API-key, exponential backoff with an anti-thundering-herd guard, success clears the error state; one cooling key is skipped while sibling keys keep serving. Layer 3, model lockout (one model): per-model 429, 404 or access denials lock just that model, never the whole connection. Terminal states (banned, expired, credits exhausted) wait for the operator; they are not cooldowns."/>

#### Ако цео провајдер не ради

Тхе** провајдерски прекидач** отвара се након 8 (OAuth) или 12 (API кључ) грешака са статусом 408, 500, 502, 503 или 504. Комбинације прескачу тог провајдера док је отворен. После 60 с или 30 с, један захтев сонде одлучује да ли се затвара.

#### Ако је један кључ или налог ограничен на стопу

Тхе** хлађење везе** клупе само ту везу, са експоненцијалним повлачењем од 5 с (OAuth) или 3 с (API кључ). Остали кључеви за истог провајдера настављају да служе.

#### Ако је један модел одбијен

Тхе** закључавање модела** блокира само тај модел на тој вези након по моделу 429, 404 или одбијања приступа. Остали модели на истој вези настављају да служе.

Забрањене, истекле и ван кредитне везе су терминална стања, а не хлађења: чекају да их поправите.

У уређивачу такође можете отворити** Екстензије** погледајте, претражите** "OmniRoute"** и кликните** Инсталирај** .

## Пун CLI, MCP и A2A

> OmniRoute испоручује клијента командне линије са** 91 команде највишег нивоа и командне групе** (754 команде рачунајући подкоманде), ан**MCP сервер са 110 алата и 33 опсега** , и ан**A2A агент са 6 вештина** . Скрипте, терминали и AI агенти могу да раде на истом мрежном пролазу.

### Права CLI, не само `start`

```bash
omniroute                 # start the gateway and dashboard (port 20128)
omniroute setup           # guided first-run wizard
omniroute repl            # interactive chat in the terminal (/model /combo /skill /memory)
omniroute chat "hello"    # one-shot prompt; also reads --file or --stdin
omniroute doctor          # check config, database, ports, Node runtime and native deps
```

Глобална `--output table|json|jsonl|csv` заставица чини исте команде употребљивим из скрипти и CI.

### Удаљени режим: CLI на вашем лаптопу, OmniRoute на серверу

Пријавите се једном на удаљени сервер. CLI га чува као а** контексту** , а касније команде раде на том серверу док се не вратите назад.

```bash
omniroute connect omniroute.example.com          # asks for the password, saves a scoped token as a context
omniroute models                                 # runs against the remote server
omniroute configure codex                        # picks a remote model, writes a local Codex profile
omniroute tokens create --name ci --scope read   # mint a narrower token for another machine
omniroute contexts use default                   # switch back to the local server
```

| Обим токена | <img width="2000" height="0" alt=""> Шта дозвољава                                 |
| ----------- | ---------------------------------------------------------------------------------- |
| `read`      | Листајте и прегледајте: модели, статус, евиденције, употреба                       |
| `write`     | `read` плус конфигуришите и примените: подешавање клијента, кључеве, конфигурацију |
| `admin`     | `write` плус управља: токени, провајдери, услуге, политика                         |

Голи хост добија `http://` и порт 20128; проследи пун `https://` URL када сервер седи иза TLS. Руте које могу покренути процесе остају само за петљу, без обзира на токен.

### Повежите агента

Агент, или ваш сопствени код, може да покреће рутирање, провајдере, комбинације, кеш меморију, компресију и меморију кроз било који од ових интерфејса. HTTP путање опслужује гатеваи, подразумевано на `http://localhost:20128`.

| Интерфејс                 | Крајња тачка или команда   | Користите га за                                                                   |
| ------------------------- | -------------------------- | --------------------------------------------------------------------------------- |
| MCP преко стдио           | `omniroute --mcp`          | Claude Десктоп, Cursor и други локални MCP клијенти                               |
| MCP преко Стреамабле HTTP | `/api/mcp/stream`          | Удаљени MCP клијенти: 110 алата, 33 опсега, сваки позив уписан у дневник ревизије |
| MCP преко SSE             | `/api/mcp/sse`             | Клијенти који још увек користе SSE транспорт                                      |
| A2A дисцовери             | `/.well-known/agent.json`  | Картица агента: говори другим агентима шта OmniRoute може да уради                |
| A2A екецутион             | `POST /a2a`                | ЈСОН-РПЦ 2.0 задаци, синхрони или стримовани преко SSE, преко 6 вештина           |
| REST API                  | `/v1/*`                    | ОпенАИ-компатибилно ћаскање, одговори, уградње, слике, аудио и OCR                |
| Вебхоокс                  | `/api/webhooks`            | Догађаји за Slack, Discord, Telegram или било који URL са HMAC потписивањем       |
| Ремоте CLI                | `omniroute connect <host>` | Управљајте удаљеном инстанцом са токенима приступа у опсегу                       |

Шест A2A вештина су `smart-routing`, `quota-management`, `provider-discovery`, `cost-analysis`, `health-report` и `list-capabilities`.

**Пре него што се повежете:**

- **MCP преко HTTP почиње онемогућено.** Укључите га помоћу `omniroute mcp enable --transport streamable-http` или са странице Крајње тачке на контролној табли. Један HTTP транспорт је активан истовремено: `streamable-http` служи `/api/mcp/stream`, `sse` служи `/api/mcp/sse`.
- **A2A почиње онемогућен.** Омогућите га на страници Крајње тачке на контролној табли. `POST /a2a` затим следи иста правила АПИ кључева као `/v1`.
- **Даљинском MCP је потребан одговарајући кључ.** `/api/mcp/*` подразумевано одговара само на повратну петљу. Са другог хоста пошаљите кључ са `manage` или `admin` (сви алати), или са `mcp:connect` плус опсегом алата који су вам потребни. За кључеве без `manage`/`admin`, опсег алата се увек примењује.

```bash
# Give Claude Code the OmniRoute toolset over MCP:
omniroute mcp enable --transport streamable-http
claude mcp add --transport http omniroute http://localhost:20128/api/mcp/stream \
  --header "Authorization: Bearer <api-key-with-manage-scope>"
```

## Аутоматски уштедите 15–95% токена —

### Како функционише — цевовод, архитектура и математика уштеде

<img src="./docs/diagrams/compression-pipeline.svg" width="100%" alt="OmniRoute compression pipeline: an illustrative 10,000-token client request passes through 12 composable engines — Session-Dedup, CCR, Lite, RTK, Responses Tool Output, Headroom, Relevance, Caveman, Aggressive, LLMLingua-2, Ultra and OmniGlyph — and can reach the provider at about 1,080 tokens in the documented stacked example. Structured content is protected by preservation guards and per-step fidelity gates; explicit lossy or experimental modes may transform eligible content."/>

Подразумевана наслагана комбинација покреће `RTK → Caveman`. Када оба делују на исти tool/context носивост, уштеда је:

```txt
combined = 1 − (1 − RTK) × (1 − Caveman_input)
average  = 1 − (1 − 0.80) × (1 − 0.46) = 89.2%
range    = 78.4 – 94.6%
```

Блокови кода, URLs, JSON и структурирани подаци су** увек заштићен** помоћу мотора за очување.

Сада је а** сноп од 12 композитних мотора** који раде по редоследу и мешају и поклапају по рутној комбинацији — на основу идеја [RTK](https://github.com/rtk-ai/rtk), [Цавеман](https://github.com/JuliusBrussee/caveman) (⭐ 90К +), [LLMLingua-2](https://github.com/microsoft/LLMLingua) и [Троглодита](https://github.com/leninejunior/troglodita) (ПТ-БР).

### Поред — излазних стилова мотора, прилагодљивог точкића и контроле по захтеву

Обликујте одговор, циљајте контекстни прозор модела или изаберите план компресије по захтеву.

#### Излазни стилови

| Стиле                               | <img width="2000" height="0" alt=""> Шта ради                                         |
| ----------------------------------- | ------------------------------------------------------------------------------------- |
| Кратка проза                        | Сече пунило и ограду уз очување техничких детаља.                                     |
| Мање кода                           | Тражи најмању радну промену и поново користи постојећи код.                           |
| коњски реп (лењи старији програмер) | Проверава шта се може поново користити или уклонити и тражи исправку основног узрока. |
| Имам ADHD (прва акција)             | Води са акцијом, нумерише кораке и завршава једним конкретним следећим кораком.       |
| Терсе CJK (文言)                    | Користи сажет класични кинески. Доступно за `zh`.                                     |

Сваки стил има интензитет `lite`, `full` и `ultra`. Додајте стил са уносом у регистар излазних стилова.

#### Адаптивни буџет за контекст

| Подешавање | Опције                                                                                                                                                                                    |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Полици     | `reserve-output` (подразумевано) оставља простор за одговор и сигурносну маргину. `percentage` користи део контекстног прозора. `absolute` поставља фиксни циљ токена.                    |
| Моде       | `floor` може ескалирати изабрани план како би се уклопио у прозор контекста. `replace-autotrigger` користи буџет за аутоматску ескалацију. `off` задржава аутоматски окидач прага токена. |

#### Где се одлучује о компресији

| Ред | <img width="2000" height="0" alt=""> Соурце                      |
| --- | ---------------------------------------------------------------- |
| 1   | Препознато `x-omniroute-compression` заглавље захтева            |
| 2   | Замена комбинације рутирања                                      |
| 3   | Активан именовани профил                                         |
| 4   | Прилагодљиви контекстни буџет или аутоматски окидач прага токена |
| 5   | Подразумевана плоча за компресију                                |
| 6   | Искључено када се не примењује план                              |

Прекидач глобалне компресије има приоритет у односу на ову табелу. Заглавље `X-OmniRoute-Compression` одговора извештава `<mode>; source=<source>`.

[Водич за компресију](docs/compression/COMPRESSION_GUIDE.md) · [RTK компресија](docs/compression/RTK_COMPRESSION.md) · [Компресијски мотори](docs/compression/COMPRESSION_ENGINES.md)

## Више метода инсталације — Docker, соурце, пнпм, Арцх

**🐳 Docker**

```bash
docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 \
  -p 127.0.0.1:20128:20128 -v omniroute-data:/app/data cheaperinference/omniroute:latest
```

`:latest` прати највиши** објављено** стабилан SemVer. Не прати гит `main`. Пин `:X.Y.Z` за GitOps. Погледајте [Docker Релеасе Цханнелс](docs/guides/DOCKER_GUIDE.md#release-channels). Игле за слику**`OMNIROUTE_MEMORY_MB=1024`** . То је довољно за контролну таблу и лагано ћаскање.** Агенти за кодирање** (`POST /v1/responses` из кода Claude, Codex, Grok, …) потребна је много већа В8 хрпа или процес `FATAL ERROR` с на ~ 12 GiB под два дуга контекста који се преклапају. Одредите величину контејнера изнад гомиле (природни бафери се налазе изван В8):

| <img width="2000" height="0" alt=""> Ворклоад | гомила (`-e OMNIROUTE_MEMORY_MB`) | Контејнер (`--memory`) |
| --------------------------------------------- | --------------------------------- | ---------------------- |
| Контролна табла / светло ћаскање              | `1024` (подразумевана слика)      | ≥ 2 г                  |
| Један агент за кодирање                       | `8192`                            | ≥ 10 г                 |
| Два истовремена дуга `/v1/responses`          | `10240`–`12288`                   | ≥ 12–16 г              |

```bash
docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 \
  -e OMNIROUTE_MEMORY_MB=8192 --memory=10g \
  -p 127.0.0.1:20128:20128 -v omniroute-data:/app/data cheaperinference/omniroute:latest
```

Цела табела: [Docker Водич — рунтиме RAM](docs/guides/DOCKER_GUIDE.md#runtime-ram-for-coding-agents).

> **Docker канал пре објављивања:** `diegosouzapw/omniroute:next` и `diegosouzapw/omniroute:next-web` прате тренутну подразумевану грану `release/v*`. Ове променљиве ознаке су намењене само за тестирање необјављених поправки и јесу** није подржано за производњу** . Погледајте [Docker Релеасе Цханнелс](docs/guides/DOCKER_GUIDE.md#release-channels).

**🥟 Bun**

Стандардна `bun install` и глобална инсталација (`bun install -g omniroute`) су подржане преко Bun детекције времена извршавања:

- **Уграђени `bun:sqlite`** : OmniRoute користи уграђени Bun `bun:sqlite` када ради под Bun, враћајући се на `better-sqlite3` на Node.js или `sql.js`.
- **Аутоматски избор пакета Вебпацк у дев** : Развој (`bun run dev`) аутоматски детектује Bun и онемогућава Turbopack у корист Вебпацк-а да би спречио некомпатибилност повезивања изворног В8. Продукцијске грађе (`bun run build`) прате `OMNIROUTE_USE_TURBOPACK` тачно као на чвору: Turbopack подразумевано, `OMNIROUTE_USE_TURBOPACK=0` за изградњу са Вебпацк-ом (`Dockerfile.bun` га излаже као `--build-arg`).
- **Наменски Bun Доцкерфиле** : Вишестепени `Dockerfile.bun` за примену Bun производње (`docker build -f Dockerfile.bun -t omniroute:bun .`).

```bash
# Install and run with Bun
bun install
bun run dev
```

**⚡ Бржа / лакша инсталација (прескочите изворну верзију)**

Изворни SQLite мотор (`better-sqlite3`) је ан** опционо** зависност, тако да глобална инсталација никада не блокира компајлирање из извора: користи унапред изграђену бинарну датотеку када се подудара са вашим platform/Node, а иначе се враћа транспарентно на чист ЈС мотор (`node:sqlite` на Ноде 22 +, иначе у пакету `sql.js` WASM) — нису потребни алати за прављење.

Да бисте прескочили пост-инсталацију** родно загревање** у потпуности (CI, безглаве или споре машине). Напомена: ово само прескаче изворни SQLite корак загревања (`scripts/postinstall.mjs`); binary-copy/repair кука (`scripts/build/postinstall.mjs`) и даље ради нормално:

```bash
OMNIROUTE_SKIP_POSTINSTALL=1 npm install -g omniroute   # CI=1 also skips it
```

За најбрже инсталације преферирајте** пнпм** (Адресирано на садржају продавница + хард линкс — види горе). За време рада без контролне табле, користите Docker `base` профил (изнад) или [Термук водич](docs/guides/TERMUX_GUIDE.md). CLI и веб контролна табла се опслужују истим процесом на једном порту, тако да данас не постоји посебан пакет само за ЦЛИ.

## Признања

OmniRoute стоји на раменима дивова. Почело је као виљушка** [9роутер](https://github.com/decolua/9router)** и TypeScript порт пројекта Го** [CLIProxyAPI](https://github.com/router-for-me/CLIProxyAPI)** — и одатле је сваки подсистем испод био инспирисан пројектом отвореног кода који је први стигао тамо. Сваки је обликовао бетонски комад OmniRoute. Ово је наша захвалност свима њима. 🙏

> ⭐ број звездица верификован са GitHub- REST API 16. новембра 2026. — иди дај овим пројектима звездицу. Бројеви су тачан датумски снимак и природно ће се променити. GrokBridge је вратио HTTP 404 тог датума; чува се њена атрибуција.
