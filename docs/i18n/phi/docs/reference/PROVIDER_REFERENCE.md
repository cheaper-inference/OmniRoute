## Mga Kategorya

- **Libre** — libreng tier na may API key (kino-configure sa pamamagitan ng dashboard)
- **Walang auth** — mga pampublikong endpoint na hindi nangangailangan ng key o pag-sign in
- **OAuth** — daloy ng pag-sign in na pinangangasiwaan ng OmniRoute, hindi kailangan ng API key
- **Web cookie** — bino-wrap ang web app ng provider sa pamamagitan ng cookie auth
- **API key** — bayad na provider na kino-configure sa pamamagitan ng API key (maaaring may libreng credits)
- **Lokal** — tumatakbo sa makina ng user (Ollama, LM Studio, vLLM, atbp.)
- **Paghahanap** — mga provider ng paghahanap sa web
- **Audio** — mga provider na para lang sa audio (TTS/STT)
- **Upstream proxy** — mga provider na nagsisilbing proxy sa ibang mga provider
- **Cloud agent** — mga matagal na tumatakbong coding agent (Codex Cloud, Devin, Jules)
- **System** — mga internal na provider ng OmniRoute (loopback, atbp.)

Mga karagdagang tag: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (kung ipinapakita): `native` — tunay na function-calling API; `emulated` — ang `tools` array ay ginagaya sa pamamagitan ng prompt gamit ang `webTools.ts` (mga `<tool>{...}</tool>` block na pina-parse gamit ang regex); `none` — kasalukuyang tahimik na inaalis ang `tools`. Tingnan ang #7286.

Gamitin ang dashboard sa `/dashboard/providers` upang i-enable, i-configure, at subukan ang bawat provider.
