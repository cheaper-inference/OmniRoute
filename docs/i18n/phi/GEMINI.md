> **Nag-iisang pinagmumulan ng katotohanan:** nasa
> [`AGENTS.md`](AGENTS.md) ang lahat ng panuntunan ng proyekto para sa mga AI assistant. Basahin ito nang buo bago gumawa ng anumang pagbabago — nilalaman nito ang 23 Mahigpit na Panuntunan,
> mga quality gate, kombensiyon sa code, mga panuntunan sa paglalagay ng file / kalinisan ng repo root, mapa ng repository,
> at mga tala sa pag-access sa lokal na development na dating nasa file na ito.

Mga talang partikular sa Gemini:

- Ina-activate ang mga skill sa pamamagitan ng tool na `activate_skill` (nilo-load ang metadata ng skill sa pagsisimula ng session at
  ina-activate ang buong nilalaman kapag kinakailangan).
- Wala nang iba pang panuntunang para lamang sa Gemini sa ngayon. Huwag muling idagdag dito ang mga panuntunan ng proyekto — sa halip, i-edit
  ang `AGENTS.md` upang makita ng bawat assistant ang parehong mga tagubilin.
