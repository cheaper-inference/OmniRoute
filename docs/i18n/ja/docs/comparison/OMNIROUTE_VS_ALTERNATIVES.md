## OmniRouteを選ぶべき場合

- セルフホスト環境で**最大限のプロバイダーカバレッジ**が必要な場合（375プロバイダー、155件の無料/認証不要のカタログエントリ）
- **組み込みMCPサーバー**が必要な場合（LLMツール、メモリ、ツールとして公開されるスキル）
- エージェント間ワークフローのための**A2Aプロトコル**が必要な場合
- アップストリームのCAPTCHAによる検出を回避するための**フィンガープリントステルス**（JA3/JA4）が必要な場合
- SaaSの費用をかけずに**エンタープライズ機能**（ガードレール、評価、監査証跡）が必要な場合

## LiteLLMを選ぶべき場合

- **Pythonファースト**で、`litellm.completion()`との緊密な連携が必要
- **成熟した本番環境向けデプロイ手順**（k8s、Helm charts）が必要
- チームですでにPythonマイクロサービスを運用している

## OpenRouter（SaaS）を選ぶべき場合

- セルフホストしたくない
- SaaSの上乗せ料金を含むトークン単位の課金を許容できる
- すべてのプロバイダーに対して**単一の支払い方法**を使用したい

## Portkeyを選ぶべき場合

- 稼働率保証付きの**商用SLA**が必要
- 運用負荷のない**マネージドダッシュボード**を希望する
- すぐに使える**エンタープライズコンプライアンス**機能が必要
