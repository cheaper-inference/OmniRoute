## OmniRouteを選択する場合

- あなたはセルフホストをしたいと思っています**プロバイダーの最大カバレッジ**(394 プロバイダー、155 free/no-authカタログ エントリ)
- 必要なのは、**組み込みのMCPサーバー**(LLMツール、メモリ、ツールとして公開されるスキル)
- 必要です**A2Aプロトコル**エージェント間のワークフローの場合
- あなたが欲しいのは**指紋ステルス**(JA3/JA4) 上流のCAPTCHAsによる検出を回避します。
- 必要です**エンタープライズ機能**(ガードレール、評価、監査証跡) SaaS請求なし

## LiteLLMを選ぶべき場合

- **Pythonファースト**で、`litellm.completion()`との緊密な連携が必要
- **成熟した本番環境向けデプロイ手順**（k8s、Helm charts）が必要
- チームですでにPythonマイクロサービスを運用している

## OpenRouter（SaaS）を選ぶべき場合

- セルフホストしたくない
- SaaSの上乗せ料金を含むトークン単位の課金を許容できる
- すべてのプロバイダーに対して**単一の支払い方法**を使用したい

## Portkeyを選ぶべき場合

- 稼働率保証付きの**商用SLA**が必要
- 運用負荷のない**マネージドダッシュボード**を希望する
- すぐに使える**エンタープライズコンプライアンス**機能が必要
