`@omniroute/opencode-plugin-v2` は、OmniRoute のカタログ全体（モデル、コンボ、オートコンボ）を、表示名、料金、無料利用枠の予算とともに OpenCode v2 のモデルピッカーへ追加します。

OpenCode v1 と v2 では異なる契約を通じてプラグインを読み込むため、これは `@omniroute/opencode-plugin` とは別のパッケージです。使用している OpenCode のメジャーバージョンに合うものを選択してください。両者の間で共有されるものはないため、一方をアップグレードしても、もう一方のアップグレードを強制されることはありません。

## 要件

- OpenCode v2。
- 接続可能な OmniRoute ゲートウェイ（デフォルトでは `http://localhost:20128`）。
- Node.js 22 または 24。

## インストール

`opencode.json` にプラグインを追加します。

```json
{
  "plugins": [
    {
      "package": "@omniroute/opencode-plugin-v2",
      "options": {
        "providerId": "omniroute",
        "baseURL": "http://localhost:20128"
      }
    }
  ]
}
```

モデルは `omniroute/<provider>/<model>` として表示されます。`providerId` はこのプレフィックスと、OpenCode が認証情報を保存する統合の ID を決定します。

## 認証情報

プラグインは、次の3か所から以下の順序でゲートウェイキーを探します。

1. **OpenCode で接続した認証情報。** プラグインは統合を登録するため、OpenCode 独自の認証フローでキーを保存できます。`opencode.json` には何も保存されません。この方法を推奨します。
2. プロジェクト単位で上書きするための、プラグインオプション内の `apiKey`。コミットする可能性があるファイルにキーが保存されます。
3. 環境内の `OMNIROUTE_API_KEY`。

この3つのいずれも設定されていない場合、カタログは空になります。プラグインは、何の通知もなく空のピッカーを表示する代わりに、起動時にその旨を一度だけ通知します。

### 管理トークンは別のキーです

コンボ、プロバイダーの状態、エンリッチメント（表示名、料金、無料利用枠の予算）は、ゲートウェイの `/api/*` エンドポイントから取得されます。ほとんどのデプロイでは、これらは推論キーではなく、**管理**トークンによって保護されています。

```json
"options": {
  "baseURL": "http://localhost:20128",
  "managementReadToken": "<管理用読み取りトークン>"
}
```

`managementReadToken` が未設定の場合、`apiKey` にフォールバックします。ゲートウェイがこのフォールバックを拒否した場合でもカタログは公開されますが、表示名の代わりに生のモデル ID が使用され、正規エイリアスの重複排除、料金、コンボは提供されません。この場合、プラグインはエンドポイントごとに一度だけ警告し、対象のエンドポイントと利用できなくなった情報を示します。そのため、ピッカーの機能が低下している理由が不明なままになることはありません。

## オプション

| 鍵                               | デフォルト                                  | 注意事項                                                                                                                                                                                                                                                                                                                                                               |
| -------------------------------- | ------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `providerId`                     | `"omniroute"`                               | プロバイダー ID、統合 ID、およびプレフィックス モデルが以下に表示されます。                                                                                                                                                                                                                                                                                            |
| `baseURL`                        | 必須                                        | ゲートウェイ ルート、 `http(s)`のみ。必要に応じて`/v1`サフィックスが追加されます                                                                                                                                                                                                                                                                                       |
| `apiKey`                         | 接続された認証情報、次に`OMNIROUTE_API_KEY` | `/v1/*`のチャットキー                                                                                                                                                                                                                                                                                                                                                  |
| `managementReadToken`            | `apiKey`に戻ります                          | 通常、 `/api/*` —のキー**ない**同じもの                                                                                                                                                                                                                                                                                                                                |
| `displayName`                    | `"OmniRoute"`                               | ピッカーのプロバイダー名                                                                                                                                                                                                                                                                                                                                               |
| `timeoutMs`                      | `10000`                                     | エンドポイントごとのフェッチ タイムアウト (自動コンボでは 5 秒を使用)                                                                                                                                                                                                                                                                                                  |
| `modelCacheTtlMs`                | `300000`                                    | カタログキャッシュTTL;ディスクスナップショットがコールドスタートをウォームアップする                                                                                                                                                                                                                                                                                   |
| `timeouts`                       | `timeoutMs`に戻ります                       | エンドポイントごとのバジェット (ミリ秒単位): `models`、 `combos`、 `autoCombos`、 `enrichment`                                                                                                                                                                                                                                                                         |
| `enrichment`                     | `true`                                      | 名前、価格、無料枠の予算を取得する                                                                                                                                                                                                                                                                                                                                     |
| `providerTag`                    | `true`                                      | 末尾のエディターの括弧を切り替えます: `Provider - Model (Editor)`。プロバイダー (モデルを提供するルート) は常に表示されます。編集者 (モデルを作成した人) は括弧内にのみ表示されます。例: `Openrouter - MoonshotAI: Kimi K 3.1 Pro` -> `Openrouter - Kimi K 3.1 Pro (MoonshotAI)`。編集者と提供者が名前を共有する場合は省略されます。 `false`を設定してドロップします。 |
| `usableOnly`                     | `false`                                     | ゲートウェイがプロビジョニング済みとして報告するプロバイダーのみを保持します                                                                                                                                                                                                                                                                                           |
| `combosSource`                   | `"api"`                                     | `"models"` `/api/combos`をスキップし、 `/v1/models`コンボ行をパブリッシュします。メンバーレベルのフィルターは`"api"`を保持します                                                                                                                                                                                                                                       |
| `showcasePerOwner`               | `10`                                        | プロバイダーごとに保持されるデフォルト ビュー エントリ                                                                                                                                                                                                                                                                                                                 |
| `freshPerOwner`                  | `10`                                        | デフォルトビューの新しいエントリはプロバイダーごとに保持されます                                                                                                                                                                                                                                                                                                       |
| `freshWindowDays`                | `90`                                        | 新鮮な枝の鮮度期間は数日                                                                                                                                                                                                                                                                                                                                               |
| `usageMemory`                    | `true`                                      | 30 日間の使用状況分析によって指定された、静的に削除されたエントリを復元します (管理トークンが必要です)                                                                                                                                                                                                                                                                 |
| `visibleModels` / `hiddenModels` | `[]`                                        | 完全一致または接尾辞の許可リスト。勝利を否定する。 `*`完全なカタログを公開します (他のフィルターは引き続き適用されます)                                                                                                                                                                                                                                                |
| `geminiSanitization`             | `true`                                      | Gemini拒否した JSON スキーマ キーワードをツール スキーマから削除します (`$ref`ツールはそのまま転送されます)                                                                                                                                                                                                                                                            |
| `apiFormat.allowAnthropic`       | `false`                                     | ホワイトリストに登録された ID をAnthropic APIブロック経由でルーティングする                                                                                                                                                                                                                                                                                            |
| `apiFormat.anthropicModels`      | `[]`                                        | 完全なモデル ID がAnthropicにルーティングされました                                                                                                                                                                                                                                                                                                                    |
| `logLevel` / `startupDebug`      | `warn` / `false`                            | ロガーの冗長性                                                                                                                                                                                                                                                                                                                                                         |

使用量メモリはデフォルトでオンになっています。管理トークンがないと、不活性状態のままになり (起動通知がログに記録されます)、何も復元されません。

## カタログの鮮度を保つ方法

カタログは遅延フェッチされて`modelCacheTtlMs`用にキャッシュされ、ゲートウェイが到達不能な場合でもディスク スナップショットによって利用可能な最新の既知のカタログが保持されます—停止によりコストがかかるのは、最新性だけです。モデルとコンボは到着次第公開されます。自動コンボ、プロバイダー リスト、エンリッチメント オーバーレイは、それらが着地したときに組み込まれるため、1 つの遅いエンドポイントがピッカー全体を人質に取ることはできません。

名前は`Provider - Model[ (Editor)][ · budget][ (route)]`に従います。ID にプロバイダーが付いている場合は常にプロバイダーが表示され (スラッシュのない ID はプレフィックスなしでレンダリングされます)、先頭の`🆓`無料エントリーをマークし、その無料枠予算は`· 1M tokens/month`サフィックスとして残り、明示的な`Editor: Model`名のエディターは末尾の括弧に移動し (他の名前から推測されるエディターはありません)、コンボは無料アイコンなしで`combo - <slug>`としてレンダリングされます。名前を共有する 2 つのエントリには、区別できるようにルート サフィックス— `(no-think)` —が付けられます。 `providerTag` (デフォルトは`true`) は、末尾のエディターの括弧を切り替えます。

手動更新コマンドはありませんOpenCode v2 コマンドはコールバックではなくプロンプト テンプレートであるため、プラグインはこれを公開できません。更新はTTLの後に続きます。ホストは、カタログまたはオーバーレイが実際に変更された場合にのみ再ロードを要求され、更新ごとに一度は再ロードを要求されません。

## Gemini でのツール呼び出し

Gemini は、ツール宣言に `$schema` または `additionalProperties` が含まれているリクエスト全体を拒否し、`400 INVALID_ARGUMENT` を返します。プラグインは、このプロバイダーの Gemini モデル宛てのツールスキーマからこれらのキーワードを削除し、それ以外のリクエストには変更を加えません。`$ref` を含むツールは、参照を削除するとスキーマが「何でも受け入れる」ように拡張されてしまうため、削除処理を行わず、そのまま転送されます。
無効にするには、`"geminiSanitization": false` を設定します。

## トラブルシューティング

| 症状                                      | 原因                                                                                                                  |
| ----------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| ピッカーにOmniRouteモデルが表示されない   | キーが解決されていない (起動警告を確認してください)、またはゲートウェイに到達できません                               |
| 生のモデル ID、コンボなし、価格設定なし   | 管理エンドポイントがトークン—セット`managementReadToken`拒否しました                                                  |
| 短いまたは空の`freeOnly`カタログ          | 管理トークンがないか、トークンが拒否されました—ホスト ログの更新概要行 (`unmatched-free` count) を読み取りました。    |
| `opencode-<id>/...`に固定されたセッション | v1 プラグインは`opencode-<id>`を公開しました。 v2 は`<id>`ベアを公開するため、 `<id>/...`の下のモデルを再選択します。 |

環境変数は、opencode サーバー プロセスに到達する必要があります。ホストがサービスとして実行される場合、 `opencode models`実行するシェルとサーバー環境は異なるため、サーバーが読み取るキーをエクスポートします。
