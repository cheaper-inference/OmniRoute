## カテゴリ

- **Free** — APIキー付きの無料ティア（ダッシュボード経由で設定）
- **No-auth** — キーやサインインが一切不要な公開エンドポイント
- **OAuth** — OmniRouteが処理するサインインフロー、APIキー不要
- **Web cookie** — クッキー認証を介してプロバイダーのウェブアプリをラップ
- **API key** — APIキー経由で設定される有料プロバイダー（無料クレジットが適用される場合あり）
- **Local** — ユーザーのマシン上で実行される（Ollama、LM Studio、vLLMなど）
- **Search** — ウェブ検索プロバイダー
- **Audio** — オーディオ専用プロバイダー（TTS/STT）
- **Upstream proxy** — 他のプロバイダーにプロキシするプロバイダー
- **Cloud agent** — 長時間実行されるコーディングエージェント（Codex Cloud、Devin、Jules）
- **System** — OmniRoute内部プロバイダー（ループバックなど）

追加タグ: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`。

`Tool calling`（表示されている場合）: `native` — 実際の関数呼び出しAPI; `emulated` — `tools` 配列は `webTools.ts` を介してプロンプトエミュレートされます（正規表現で解析された `<tool>{...}</tool>` ブロック）; `none` — `tools` は現在、サイレントに破棄されます。#7286 を参照してください。
