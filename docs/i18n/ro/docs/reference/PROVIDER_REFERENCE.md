## Categorii

- **Gratuit** — nivel gratuit cu cheie API (configurat prin tablou de bord)
- **Fără autentificare** — puncte finale publice care nu necesită nicio cheie sau autentificare
- **OAuth** — flux de autentificare gestionat de OmniRoute, nu este necesară cheie API
- **Cookie web** — încapsulează aplicația web a furnizorului prin autentificare cu cookie
- **Cheie API** — furnizor plătit configurat prin cheie API (se pot aplica credite gratuite)
- **Local** — rulează pe mașina utilizatorului (Ollama, LM Studio, vLLM, etc.)
- **Căutare** — furnizori de căutare web
- **Audio** — furnizori doar audio (TTS/STT)
- **Proxy upstream** — furnizori care acționează ca proxy pentru alți furnizori
- **Agent cloud** — agenți de codare de lungă durată (Codex Cloud, Devin, Jules)
- **Sistem** — furnizori interni OmniRoute (loopback, etc.)

Etichete suplimentare: `imagine`, `video`, `agregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Apelare instrumente` (unde este afișat): `nativ` — API real de apelare a funcțiilor; `emulat` — matricea `tools` este emulată prin prompt prin `webTools.ts` (blocuri `<tool>{...}</tool>` analizate prin regex); `niciunul` — `tools` este în prezent ignorat în tăcere. Vezi #7286.

Utilizați tabloul de bord la `/dashboard/providers` pentru a activa, configura și testa fiecare furnizor.
