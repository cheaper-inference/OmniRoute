## Categorii

- **Gratuit** — nivel gratuit cu cheie API (configurată prin intermediul panoului de control)
- **Fără autentificare** — endpointuri publice care nu necesită nicio cheie și nicio autentificare
- **OAuth** — flux de autentificare gestionat de OmniRoute, fără a fi necesară o cheie API
- **Cookie web** — încapsulează aplicația web a furnizorului folosind autentificarea prin cookie
- **Cheie API** — furnizor cu plată configurat prin cheie API (pot fi disponibile credite gratuite)
- **Local** — rulează pe dispozitivul utilizatorului (Ollama, LM Studio, vLLM etc.)
- **Căutare** — furnizori de căutare web
- **Audio** — furnizori exclusiv audio (TTS/STT)
- **Proxy upstream** — furnizori care redirecționează către alți furnizori
- **Agent cloud** — agenți de programare cu execuție îndelungată (Codex Cloud, Devin, Jules)
- **Sistem** — furnizori interni OmniRoute (loopback etc.)

Etichete suplimentare: `image`, `video`, `aggregator`, `enterprise`, `embed/rerank`, `self-hosted`.

`Tool calling` (acolo unde este afișat): `native` — API real pentru apelarea funcțiilor; `emulated` — matricea `tools` este emulată prin prompt folosind `webTools.ts` (blocuri `<tool>{...}</tool>` analizate cu expresii regulate); `none` — `tools` este în prezent eliminată în mod silențios. Consultați #7286.

Utilizați panoul de control de la `/dashboard/providers` pentru a activa, configura și testa fiecare furnizor.
