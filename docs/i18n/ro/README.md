## Jetoane gratuite pe lună: ~ 11.3B după cum contează alții · ~ 90M Real

</div>

> **~ 11.3B jetoane gratuite/lună**<br/> <sub> a numărat așa cum contează alte cataloage: fiecare rând adunat, ofertele încheiate incluse </sub>
>
> **~ 90M real astăzi**<br/> <sub> fiecare cotă partajată a fost numărată o dată: ceea ce puteți utiliza de fapt </sub>
>
> **Totul aici este gratuit. Fără paywall.**<br/> ★ [Îți place? Afișează-ne pe GitHub](https://github.com/cheaper-inference/OmniRoute)

Alte cataloage taxează de la US 19 USD pe an la US 49 USD pentru acces pe viață la date live. Aici totul este gratuit. <sub> Preturi verificate pe 2026-11-18.</sub>

<sub>Catalog auditat ultima dată pe 2026-11-23. [Cum numărăm →](docs/reference/FREE_TIERS.md#how-we-count)</sub>

> **Aduceți-vă propriile conturi de furnizor.** Acestea sunt niveluri gratuite de la terți, nu o acordare simbol de OmniRoute. Înscrieți-vă, obțineți acreditări acolo unde un furnizor le solicită și conectați-le pe cele pe care le puteți utiliza. Fiecare furnizor își stabilește propriile limite, disponibilitate și termeni.
>
> Stivuirea manuală a nivelurilor gratuite înseamnă zeci de SDKs, zeci de limite de tarif și nicio idee clară despre ceea ce ai rămas. OmniRoute păstrează 214 rânduri de catalog cu acces gratuit și calculează cifra reală din 12 pool-uri cu o cotă publicată, fiecare pool partajat numărând o dată. Cotele care se deschid numai după o verificare a identității regionale (azi, ModelScope) sunt afișate separat, +~ 6M în spatele verificării identității regionale și nu se adaugă niciodată la cifra reală. Ce a mai rămas apare pe tabloul de bord (`/dashboard/free-tiers`).

## Instalați, conectați un furnizor, apoi rutați printr-un punct final

<img src="./docs/diagrams/works-zero-config.svg" width="100%" alt="Four steps to use OmniRoute. Install with npm install -g omniroute, run omniroute, connect a provider and create an API key in the dashboard, then call http://localhost:20128/v1 with model auto."/>

```bash
# After connecting a provider, create your OmniRoute key in Dashboard → API Keys:
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer YOUR_OMNIROUTE_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"auto","messages":[{"role":"user","content":"Hello!"}]}'
```

## Combo: nava amiral

1. **Începeți cu `auto`.** Setați modelul în clientul dvs. compatibil OpenAI. OmniRoute creează un combo virtual de la furnizorii conectați și punctează candidații în direct.
2. **Salvați un combo pentru mai mult control.** Alegeți un nume, o listă de ținte și o strategie, apoi utilizați numele respectiv ca model. Strategia stabilește care țintă merge prima și cum sunt încercate celelalte.

Un combo parcurge automat modele. La epuizarea cotei, la eșecul furnizorului sau la blocarea modelului, încearcă următoarea țintă eligibilă, sănătoasă.

### Zero-config: utilizați doar `auto`

```bash
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <your-omniroute-key>" \
  -H "Content-Type: application/json" \
  -d '{"model": "auto", "messages": [{"role": "user", "content": "Hello"}]}'
```

Variantele reglează greutățile. Ultimul rutare cunoscută rămâne la ultimul furnizor de succes până când eșuează, apoi revine. `auto/fast` și `auto/cheap` exprimă preferințe fără a garanta cel mai rapid sau mai ieftin model.

| Model ID            | Comportament                                                                                                                                                                                                                                                                                                      |
| :------------------ | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `auto`              | Greutăți implicite echilibrate.                                                                                                                                                                                                                                                                                   |
| `auto/fast`         | Favorizează latența scăzută și sănătatea furnizorului.                                                                                                                                                                                                                                                            |
| `auto/cheap`        | Favorizează prețuri de catalog mai mici.                                                                                                                                                                                                                                                                          |
| `auto/coding`       | Calitatea pe primul loc ponderi pentru generarea de cod.                                                                                                                                                                                                                                                          |
| `auto/smart`        | Ponderi de calitate pe primul loc cu 10% explorare (implicit 5%).                                                                                                                                                                                                                                                 |
| `auto/lkgp`         | Rutarea explicită a ultimului bun cunoscut cu aceleași ponderi ca `auto`.                                                                                                                                                                                                                                         |
| `auto/subscription` | Utilizează numai cota de plan verificată în direct. Returnează HTTP 503 atunci când niciunul nu este disponibil și evită rezerva facturată.                                                                                                                                                                       |
| `auto/thrifty`      | Plan → keyless → free → ieftin → premium. Poate ajunge la modelele facturate și se întoarce la plan atunci când cota și timpul de răcire permit.                                                                                                                                                                  |
| `auto/offline`      | Favorizează cota și limita de tarif. Solicitările ajung în continuare la furnizorii dvs.                                                                                                                                                                                                                          |
| `auto/chaos`        | Un model pentru fiecare furnizor în paralel, până la cinci implicit sau zece când este configurat. Un apel în amonte per model. Returnează răspunsul cel mai bine clasat sau ultimul răspuns reușit la panou dacă modelul de top nu reușește. Utilizați `fusion` pentru a sintetiza răspunsurile cu un judecător. |

Exemplele de categorii și niveluri opționale includ `auto/coding:fast`, `auto/coding:free`, `auto/reasoning:pro` și `auto/vision`. Dacă niciun candidat conectat nu se potrivește, cererea returnează HTTP 503 și grupul rămâne restrâns. [Ghid Auto-Combo](./docs/routing/AUTO-COMBO.md) · [Dirijare primul abonament](./docs/routing/SUBSCRIPTION_LADDER.md)

### Sau construiește-ți propriul tău: 22 de strategii de rutare

```bash
omniroute combo create my-pool --strategy fill-first \
  --models "provider-a/model-1,provider-b/model-2"
```

CLI acceptă 15 din 22 de strategii. Tabloul de bord și combo-urile API acceptă toate cele 22.

| Strategie           | Comportament                                                                                                                                                                                                                 |
| :------------------ | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `auto`              | Candidații de clasare trăiesc cu marcatorul Auto-Combo cu 16 factori.                                                                                                                                                        |
| `cache-optimized`   | Preferați contul care probabil să dețină prefixul prompt în cache.                                                                                                                                                           |
| `context-optimized` | Încercați mai întâi cea mai mare fereastră de context cunoscută.                                                                                                                                                             |
| `context-relay`     | Păstrați comanda și transmiteți un rezumat al conversației atunci când schimbați conturile.                                                                                                                                  |
| `cost-optimized`    | Sortați după prețul jetonului de intrare din catalog, ultimele necunoscute. Costul cererii finale poate diferi.                                                                                                              |
| `expiry-first`      | Cheltuiți cota probabil să expire, cel mai mare rămas pe oră până la resetare.                                                                                                                                               |
| `fill-first`        | Rămâneți pe prima țintă disponibilă până când se epuizează sau eșuează, apoi treceți mai departe.                                                                                                                            |
| `fusion`            | Interogați un grup în paralel și cereți unui judecător să sintetizeze un răspuns.                                                                                                                                            |
| `headroom`          | Alegeți cea mai liberă capacitate în ferestre de 5 ore și săptămânale.                                                                                                                                                       |

### Reziliența este construită în: 3 straturi independente

Eșecurile sunt tratate la trei domenii, astfel încât un model prost nu își dă jos contul și un cont prost nu își dezactivează furnizorul.

<img src="./docs/diagrams/resilience-layers.svg" width="100%" alt="OmniRoute resilience: 3 independent self-healing layers, the right layer for the right failure. Layer 1, provider circuit breaker (whole provider): trips only on 408/500/502/503/504, opens after 8 failures for OAuth providers or 12 for API-key providers, resets after 60s or 30s into a HALF-OPEN probe, lazy recovery; while OPEN the combo reroutes to the next provider. Layer 2, connection cooldown (one key or account): base 5s OAuth or 3s API-key, exponential backoff with an anti-thundering-herd guard, success clears the error state; one cooling key is skipped while sibling keys keep serving. Layer 3, model lockout (one model): per-model 429, 404 or access denials lock just that model, never the whole connection. Terminal states (banned, expired, credits exhausted) wait for the operator; they are not cooldowns."/>

#### Dacă un întreg furnizor este în jos

The** întrerupător de circuit al furnizorului** se deschide după 8 (OAuth) sau 12 ( cheie API ) eșecuri cu starea 408, 500, 502, 503 sau 504. Combo-urile omit acel furnizor în timp ce acesta este deschis. După 60 s sau 30 s, o cerere de sondă decide dacă se închide.

#### Dacă o cheie sau un cont este limitat la tarif

The** răcire a conexiunii** bancă doar acea conexiune, cu backoff exponențial de la 5 s (OAuth) sau 3 s ( tasta API ). Alte chei pentru același furnizor continuă să funcționeze.

#### Dacă un model este refuzat

The** blocarea modelului** blochează doar acel model pe acea conexiune după un model 429, 404 sau refuz acces. Alte modele pe aceeași conexiune continuă să servească.

Conexiunile interzise, expirate și în afara creditului sunt stări terminale, nu cooldown-uri: așteaptă ca tu să le repari.

## CLI completă, MCP și A2A

> OmniRoute livrează un client de linie de comandă cu** 91 de comenzi și grupuri de comenzi de nivel superior** (754 de comenzi numărând subcomenzi), an** server MCP cu 110 instrumente și 33 de lunete** , și un** agent A2A cu 6 aptitudini** . Scripturile, terminalele și agenții AI pot opera cu toții același gateway.

### Un adevărat CLI, nu doar `start`

```bash
omniroute                 # start the gateway and dashboard (port 20128)
omniroute setup           # guided first-run wizard
omniroute repl            # interactive chat in the terminal (/model /combo /skill /memory)
omniroute chat "hello"    # one-shot prompt; also reads --file or --stdin
omniroute doctor          # check config, database, ports, Node runtime and native deps
```

Indicatorul global `--output table|json|jsonl|csv` face ca aceleași comenzi să fie utilizabile din scripturi și CI.

### Modul la distanță: CLI pe laptop, OmniRoute pe un server

Conectați-vă o dată la un server la distanță. CLI îl salvează ca a** context** , iar comenzile ulterioare rulează pe acel server până când comutați înapoi.

```bash
omniroute connect omniroute.example.com          # asks for the password, saves a scoped token as a context
omniroute models                                 # runs against the remote server
omniroute configure codex                        # picks a remote model, writes a local Codex profile
omniroute tokens create --name ci --scope read   # mint a narrower token for another machine
omniroute contexts use default                   # switch back to the local server
```

| --------------------------------- | ---------------------------------------------------------------- |
| `read`                            | Listați și inspectați: modele, stare, jurnale, utilizare         |

### Conectați un agent

Un agent sau propriul dvs. cod poate conduce rutarea, furnizorii, combo-urile, memoria cache, compresia și memoria prin oricare dintre aceste interfețe. Căile HTTP sunt deservite de gateway, implicit la `http://localhost:20128`.

| Interfață                 | Punct final sau comandă    | Folosește-l pentru                                                                               |
| ------------------------- | -------------------------- | ------------------------------------------------------------------------------------------------ |
| MCP peste stdio           | `omniroute --mcp`          | Claude Desktop, Cursor și alți clienți locali MCP                                                |
| MCP peste HTTP Streamable | `/api/mcp/stream`          | Clienți MCP la distanță: 110 instrumente, 33 de domenii, fiecare apel scris în jurnalul de audit |
| MCP peste SSE             | `/api/mcp/sse`             | Clienții care încă folosesc transportul SSE                                                      |
| A2A descoperire           | `/.well-known/agent.json`  | Card de agent: le spune altor agenți ce poate face OmniRoute                                     |
| execuție A2A              | `POST /a2a`                | Sarcini JSON-RPC 2.0, sincrone sau transmise în flux prin SSE, în 6 abilități                    |
| REST API                  | `/v1/*`                    | Chat compatibil OpenAI, răspunsuri, încorporare, imagini, audio și OCR                           |
| Webhook-uri               | `/api/webhooks`            | Evenimente la Slack, Discord, Telegram sau orice URL cu semnare HMAC                             |
| Telecomanda CLI           | `omniroute connect <host>` | Conduceți o instanță de la distanță cu indicative de acces limitate                              |

Cele șase abilități A2A sunt `smart-routing`, `quota-management`, `provider-discovery`, `cost-analysis`, `health-report` și `list-capabilities`.

**Înainte de a vă conecta:**

- **MCP peste HTTP începe dezactivat.** Porniți-l cu `omniroute mcp enable --transport streamable-http` sau din pagina Endpoints a tabloului de bord. Un transport HTTP este activ o dată: `streamable-http` servește `/api/mcp/stream`, `sse` servește `/api/mcp/sse`.
- **A2A începe dezactivat.** Activați-l pe pagina Endpoints a tabloului de bord. `POST /a2a` urmează aceleași reguli de cheie API ca și `/v1`.
- **Telecomanda MCP are nevoie de o cheie adecvată.** `/api/mcp/*` răspunde implicit numai la loopback. De la o altă gazdă, trimiteți o cheie cu `manage` sau `admin` (toate instrumentele) sau cu `mcp:connect` plus domeniile instrumentelor de care aveți nevoie. Pentru cheile fără `manage`/`admin`, domeniile instrumentului sunt întotdeauna aplicate.

```bash
# Give Claude Code the OmniRoute toolset over MCP:
omniroute mcp enable --transport streamable-http
claude mcp add --transport http omniroute http://localhost:20128/api/mcp/stream \
  --header "Authorization: Bearer <api-key-with-manage-scope>"
```

## Economisiți 15–95% jetoane — automat

### Cum funcționează — pipeline, arhitectură și matematică economii

<img src="./docs/diagrams/compression-pipeline.svg" width="100%" alt="OmniRoute compression pipeline: an illustrative 10,000-token client request passes through 12 composable engines — Session-Dedup, CCR, Lite, RTK, Responses Tool Output, Headroom, Relevance, Caveman, Aggressive, LLMLingua-2, Ultra and OmniGlyph — and can reach the provider at about 1,080 tokens in the documented stacked example. Structured content is protected by preservation guards and per-step fidelity gates; explicit lossy or experimental modes may transform eligible content."/>

Combo stivuit implicit rulează `RTK → Caveman`. Când ambele acționează asupra aceleiași sarcini utile tool/context, economiile sunt compuse:

```txt
combined = 1 − (1 − RTK) × (1 − Caveman_input)
average  = 1 − (1 − 0.80) × (1 − 0.46) = 89.2%
range    = 78.4 – 94.6%
```

Blocurile de cod, URLs, JSON și datele structurate sunt** mereu protejat** de motorul de conservare.

> **De ce să folosiți multe jetoane când puține jetoane fac truc?** Fiecare cerere trece prin conducta de compresie a OmniRoute** în mod transparent** — nu se modifică clientul. Acum este o** teanc de 12 motoare componabile** care rulează în ordine și se amestecă și se potrivesc pe combo de rutare — bazându-se pe idei de la [RTK](https://github.com/rtk-ai/rtk), [Caveman](https://github.com/JuliusBrussee/caveman) (⭐ 90K +), [LLMLingua-2](https://github.com/microsoft/LLMLingua) și [Troglodita](https://github.com/leninejunior/troglodita) (PT-BR).

### Dincolo de stilurile de ieșire ale motoarelor —, cadranul adaptiv și controlul la cerere

Modelați răspunsul, vizați fereastra de context a modelului sau alegeți un plan de compresie pentru fiecare cerere.

#### Stiluri de ieșire

| Stil                                    | <img width="2000" height="0" alt=""> Ce face                                                 |
| --------------------------------------- | -------------------------------------------------------------------------------------------- |
| proză concisă                           | Taie umplutura și acoperirea vii, păstrând în același timp detaliile tehnice.                |
| Mai puțin cod                           | Solicită cea mai mică modificare de lucru și reutiliza codul existent.                       |
| Coada de cal (dezvoltator senior leneș) | Verifică ceea ce poate fi reutilizat sau eliminat și solicită o remediere a cauzei rădăcină. |
| Am ADHD (în primul rând acțiunea)       | Conduce cu acțiunea, numerotează pașii și se încheie cu un pas concret următor.              |
| Terse CJK (文言)                        | Folosește chineză clasică concisă. Disponibil pentru `zh`.                                   |

Fiecare stil are intensități `lite`, `full` și `ultra`. Adăugați un stil cu o intrare în registrul de stil de ieșire.

#### Bugetul adaptiv al contextului

| Setare   | Opțiuni                                                                                                                                                                                                             |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Politică | `reserve-output` (implicit) rezervă spațiu pentru răspuns și o marjă de siguranță. `percentage` folosește o parte din fereastra de context. `absolute` stabilește o țintă fixă de simbol.                           |
| Modul    | `floor` poate escalada planul selectat pentru a se potrivi cu fereastra de context. `replace-autotrigger` folosește bugetul pentru escaladarea automată. `off` păstrează declanșarea automată a pragului de simbol. |

#### Unde se decide compresia

| Comanda | <img width="2000" height="0" alt=""> Sursa                                  |
| ------- | --------------------------------------------------------------------------- |
| 1       | Antet de solicitare `x-omniroute-compression` recunoscut                    |
| 2       | Ignorare combo de rutare                                                    |
| 3       | Profil denumit activ                                                        |
| 4       | Declanșare automată a bugetului de context adaptiv sau a pragului indicativ |
| 5       | Panoul de compresie implicit                                                |
| 6       | Dezactivat când nu se aplică niciun plan                                    |

Comutatorul global de compresie are prioritate față de acest tabel. Antetul răspunsului `X-OmniRoute-Compression` raportează `<mode>; source=<source>`.

[Ghid de compresie](docs/compression/COMPRESSION_GUIDE.md) · [compresie RTK](docs/compression/RTK_COMPRESSION.md) · [Motoare de compresie](docs/compression/COMPRESSION_ENGINES.md)

## Mai multe metode de instalare — Docker, source, pnpm, Arch

**🐳 Docker**

```bash
docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 \
  -p 127.0.0.1:20128:20128 -v omniroute-data:/app/data cheaperinference/omniroute:latest
```

`:latest` urmează cel mai înalt** publicat** SemVer stabil . Nu urmărește git `main`. Pin `:X.Y.Z` pentru GitOps. A se vedea [Docker Release Channels](docs/guides/DOCKER_GUIDE.md#release-channels). Pinii de imagine**`OMNIROUTE_MEMORY_MB=1024`** . Este suficient pentru tabloul de bord și un chat ușor.** Agenți de codificare** (`POST /v1/responses` din Claude Code, Codex, Grok, …) au nevoie de un heap V8 mult mai mare sau de procesul `FATAL ERROR` s la ~ 12 GiB sub două contexte lungi suprapuse. Măriți containerul deasupra mormanului (tamponele native stau în afara V8):

| <img width="2000" height="0" alt=""> Sarcina de lucru | Heap (`-e OMNIROUTE_MEMORY_MB`) | Container (`--memory`) |
| ----------------------------------------------------- | ------------------------------- | ---------------------- |
| Tabloul de bord / chat ușor                           | `1024` (imagine implicită)      | ≥ 2 g                  |
| Un singur agent de codare                             | `8192`                          | ≥ 10 g                 |
| Două `/v1/responses` lungi simultane                  | `10240`–`12288`                 | ≥ 12–16 g              |

```bash
docker run -d --name omniroute --restart unless-stopped --stop-timeout 40 \
  -e OMNIROUTE_MEMORY_MB=8192 --memory=10g \
  -p 127.0.0.1:20128:20128 -v omniroute-data:/app/data cheaperinference/omniroute:latest
```

Tabel complet: [Docker Guide — runtime RAM](docs/guides/DOCKER_GUIDE.md#runtime-ram-for-coding-agents).

> **Canalul Docker pre-lansare:** `diegosouzapw/omniroute:next` și `diegosouzapw/omniroute:next-web` urmează ramura curentă implicită `release/v*`. Aceste etichete modificabile sunt destinate numai pentru testarea corecțiilor nelansate și sunt** nu este acceptat pentru producție** . Vedeți [Canale de lansare Docker](docs/guides/DOCKER_GUIDE.md#release-channels).

**🥟 Bun**

`bun install` standard și instalarea globală (`bun install -g omniroute`) sunt acceptate prin Bun runtime detection:

- **`bun:sqlite` încorporat** : OmniRoute folosește driverul `bun:sqlite` Bun rulează sub Bun, revenind la `better-sqlite3` pe Node.js sau `sql.js`.
- **Selectarea automată a pachetului Webpack în dev** : Dezvoltarea (`bun run dev`) detectează automat Bun și dezactivează Turbopack în favoarea Webpack pentru a preveni incompatibilitățile native de legare V8. Versiunile de producție (`bun run build`) urmează `OMNIROUTE_USE_TURBOPACK` exact ca pe Node: Turbopack în mod implicit, `OMNIROUTE_USE_TURBOPACK=0` pentru a construi cu Webpack (`Dockerfile.bun` îl expune ca `--build-arg`).
- **Dockerfile Bun dedicat** : `Dockerfile.bun` în mai multe etape pentru implementări native de producție Bun (`docker build -f Dockerfile.bun -t omniroute:bun .`).

```bash
# Install and run with Bun
bun install
bun run dev
```

**⚡ Instalare mai rapidă / mai slabă (sări peste versiunea nativă)**

Motorul nativ SQLite (`better-sqlite3`) este an** opțional** dependență, deci o instalare globală nu blochează niciodată compilarea din sursă: folosește un binar preconstruit atunci când unul se potrivește cu platform/Node dvs. și, în caz contrar, revine transparent la un motor pur-JS (`node:sqlite` pe Nodul 22 +, altfel `sql.js` WASM inclus) — nu sunt necesare instrumente de compilare.

Pentru a sări peste post-instalare** încălzire nativă** complet (mașini CI, fără cap sau lente). Notă: aceasta omite doar pasul nativ de încălzire SQLite (`scripts/postinstall.mjs`); cârligul binary-copy/repair (`scripts/build/postinstall.mjs`) încă rulează normal:

```bash
OMNIROUTE_SKIP_POSTINSTALL=1 npm install -g omniroute   # CI=1 also skips it
```

Pentru cele mai rapide instalări preferați** pnpm** (magazinul adresat conținutului + hard links — vezi mai sus). Pentru un timp de rulare fără tablou de bord, fără cap, utilizați profilul Docker `base` (mai sus) sau [ghidul Termux](docs/guides/TERMUX_GUIDE.md). CLI și tabloul de bord web sunt deservite de același proces pe un singur port, așa că nu există astăzi un pachet separat doar pentru CLI.

### Cum să contribui

1. Bifurcați depozitul
2. Ramura din** activ** sfat `release/vX.Y.Z` (nu `main`) — consultați [modelul de ramificare și eliberare](docs/ops/BRANCHING_MODEL.md)
3. Creați-vă ramura caracteristică (`git checkout -b feat/amazing-feature`)
4. Commiteți modificările (`git commit -m 'feat: add amazing feature'`)
5. Împingeți la ramură (`git push origin feat/amazing-feature`)
6. Deschideți o cerere de tragere cu** baza = acea ramura `release/vX.Y.Z`**

Consultați [CONTRIBUTING.md](CONTRIBUTING.md) pentru instrucțiuni detaliate.

### Lansarea unei noi versiuni

```bash
# Create a release — npm publish happens automatically
VERSION=x.y.z
gh release create "v${VERSION}" --title "v${VERSION}" --generate-notes
```

## Mulțumiri

OmniRoute stă pe umerii giganților.
